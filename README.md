## 下载

### Docker

```

docker run -tid -p <port>:80 apachecn0/cs-notes-pt3-zh
# 访问 http://localhost:{port} 查看文档
```

### NPM

```
npm install -g cs-notes-pt3-zh
cs-notes-pt3-zh <port>
# 访问 http://localhost:{port} 查看文档
```
