# 016：数组变量与多值存储 📦

在本节课中，我们将要学习数组（Array）的概念。数组是编程中一种强大的存储机制，它允许我们在一个变量中存储多个相关的值。这与我们之前学习的“不要重复自己”（DRY）设计原则紧密相连，正如方法封装了代码一样，数组帮助我们更好地封装和组织数据。

---

## 数组简介与DRY设计

上一节我们介绍了方法，它让我们能够封装和重用代码块。本节中，我们来看看另一种实现DRY设计的重要机制：数组。

数组本质上是一种存储操作。在算法设计中，我们有五种基本构建块：存储、输入、输出、处理和**控制操作**。数组就属于**存储操作**。与我们之前学习的只能存储单个值的变量不同，数组允许一个变量存储**多个值**。

数组之所以契合DRY设计，是因为它允许我们更好地**封装数据**。方法封装了一组相关的代码语句，类封装了一组相关的方法和字段，而数组则封装了一组**相关的数据**。

---

## 数组的定义与Java实现

数组的核心概念是：它是一个可以包含多个值的变量。

在Java中，我们通过在数据类型后使用**方括号 `[]`** 来声明一个数组变量。实际上，我们一直在使用数组变量——每次创建 `main` 方法时：

```java
public static void main(String[] args)
```
这里的 `String[] args` 就是一个字符串数组变量。

在计算机内部，声明数组时，会在内存中预留一块**连续的空间**来存储这些值。空间大小等于**单个值所需字节数**乘以**要存储的值的数量**。例如，一个 `int` 类型占4字节。要存储3个 `int` 值，数组就需要预留 `4 * 3 = 12` 字节的内存空间。

---

## 现实类比：购物清单 🛒

为了更好地理解数组，让我们看一个现实世界的例子：购物清单。

假设我的购物清单上有以下物品：
*   鸡蛋
*   牛奶
*   面包
*   冷切肉
*   饼干
*   冰淇淋

如果我想和朋友确认清单上的某样东西，一个很自然的方式是使用**编号**。我们会说“面包是清单上的第2项”。这种通过编号来访问列表中单个元素的方式，在编程中称为**索引（Indexing）**。

在Java中，我们做同样的事情，只是索引编号从 **0** 开始。

以下是购物清单的索引映射：
*   索引 0: 鸡蛋
*   索引 1: 牛奶
*   索引 2: 面包
*   索引 3: 冷切肉
*   索引 4: 饼干
*   索引 5: 冰淇淋

请注意，清单上有6个元素，但最大的索引号是5。这是因为我们从0开始计数，这是使用数组时必须牢记的重要规则。

数组由一组**相同数据类型**的相关数据值组成。这意味着，如果你声明了一个字符串数组，那么其中的每一个值都必须是字符串类型。

## Java数组示例

现在，让我们将购物清单的例子转化为Java代码。

首先，我们可以声明并创建一个指定大小的空数组：

```java
// 1. 声明一个字符串数组变量
String[] groceryArray;

// 2. 创建一个可以容纳6个字符串的空数组，并将其赋值给变量
groceryArray = new String[6];
```

创建数组时，我们使用 `new` 关键字，并必须在方括号中指定数组的**长度**（即能容纳多少个元素），因为Java需要知道要为它预留多少内存空间。

创建数组后，我们可以通过索引向其中写入值：

```java
// 通过索引向数组写入值
groceryArray[0] = "鸡蛋";
groceryArray[1] = "牛奶";
groceryArray[2] = "面包";
groceryArray[3] = "冷切肉";
groceryArray[4] = "饼干";
groceryArray[5] = "冰淇淋";
```

要读取数组中的值，同样使用索引：

```java
// 通过索引从数组读取值
String firstItem = groceryArray[0]; // 读取索引0的值：“鸡蛋”
```

由于我们经常需要遍历数组中的所有元素，`for` 循环是绝佳的搭档：

```java
// 使用 for 循环遍历数组
for (int i = 0; i < groceryArray.length; i++) {
    String item = groceryArray[i];
    System.out.println("索引 " + i + ": " + item);
}
```
注意循环条件 `i < groceryArray.length`。`length` 是数组的一个**只读字段**，它告诉我们数组的长度。我们使用 `<` 而不是 `<=`，因为最大有效索引是 `length - 1`。

---

## 数组字面量（初始化列表）

如果我们已经提前知道数组的所有元素，可以使用更简洁的**数组字面量**或称为**数组初始化列表**的方式来创建并填充数组。

```java
// 使用数组字面量声明并初始化数组
String[] groceryArray = {"鸡蛋", "牛奶", "面包", "冷切肉", "饼干", "冰淇淋"};
```
这种方式只能在**初始化**（即声明和赋值在同一行）时使用，不能用于已存在数组的重新赋值。使用数组字面量时，我们无需指定长度，Java会自动根据元素个数确定数组长度。

---

## 增强型 for 循环

遍历数组以读取所有值是非常常见的操作，因此Java提供了**增强型 for 循环**（也称为“for-each”循环）来简化语法。

```java
// 使用增强型 for 循环读取数组
for (String item : groceryArray) {
    System.out.println(item);
}
```
语法是：`for (数据类型 局部变量名 : 数组变量名)`。在每次循环中，`item` 变量会被自动赋值为数组中的下一个元素。

**重要限制**：增强型 for 循环**只能用于读取**数组元素，不能用于写入或修改数组。因为它操作的是元素的**副本**（一个局部变量），修改这个副本不会影响原始数组。如果需要修改数组元素，必须使用传统的 `for` 循环和索引。

## 数组与DRY设计实践

数组通过将相关数据分组，帮助保持代码的DRY。让我们看两个例子。

**示例1：计算平均分**
假设我们要计算一组已知分数的平均值。

*非DRY方式（不使用数组）*：
```java
int grade1 = 90;
int grade2 = 85;
int grade3 = 92;
int count = 3;
int sum = grade1 + grade2 + grade3;
double average = (double) sum / count;
```
每增加一个分数，就需要多声明一个变量并手动更新求和计算。

*DRY方式（使用数组）*：
```java
int[] grades = {90, 85, 92};
int sum = 0;
for (int grade : grades) {
    sum += grade;
}
double average = (double) sum / grades.length;
```
使用数组后，无论有多少个分数，求和与计算的逻辑都保持不变，代码更简洁、更易扩展。

**示例2：模拟骰子频率测试**
回顾我们之前测试六面骰子均匀性的代码，当时我们为每个可能的点数（1到6）都声明了一个独立的计数器变量。

使用数组可以极大地改进这段代码：

```java
// 创建一个长度为7的数组，索引0不使用，索引1-6对应骰子点数1-6
int[] frequency = new int[7];

// 模拟投掷骰子多次
for (int i = 0; i < 6_000_000; i++) {
    int dieRoll = d6.roll(); // 假设d6.roll()返回1-6
    frequency[dieRoll]++; // 直接使用骰子点数作为索引
}

// 输出结果
for (int face = 1; face < frequency.length; face++) {
    System.out.println("点数 " + face + " 出现了 " + frequency[face] + " 次");
}
```
这种方式的优势在于：
1.  **代码更简洁**：无需为每个点数声明单独的变量。
2.  **更健壮和可扩展**：如果想测试两个骰子之和的分布（结果范围是2到12），只需将数组长度改为13，并修改循环逻辑即可，而无需声明11个不同的计数器。这完美体现了DRY设计原则和避免使用“魔数”的好处。

## 总结

本节课中我们一起学习了数组这一核心概念。我们了解到数组是一种特殊的变量，可以存储**多个相同类型**的值。我们学习了如何在Java中**声明**、**创建**（使用 `new` 或字面量）、**写入**和**读取**数组元素，并理解了数组**索引从0开始**的规则。

我们探讨了如何使用传统的 `for` 循环和**增强型 for 循环**来遍历数组，并明确了后者仅用于读取。最后，我们通过计算平均分和优化骰子模拟器两个实例，看到了数组如何帮助我们实践**DRY设计原则**，使代码更简洁、更易维护和扩展。
