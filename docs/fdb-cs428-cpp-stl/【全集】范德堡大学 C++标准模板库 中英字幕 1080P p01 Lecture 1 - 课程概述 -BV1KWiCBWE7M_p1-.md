Hi， my name is Doug Schmidt and I'm a computer science professor at Vanderbilt University。

Over the past three decades， I've written millions of lines of widely used open source software with C++。

And have long enjoyed its powerful blend of abstraction and efficiency。

Which enhances both programmer productivity and computing performance。

Nowhere is this blend more evident than the C++ Standard Temp library or STL。

 which is a subset of the C++ standard library consisting of header files that define container。

 function， and iterator classes， along with algorithms and other utilities that work with these classes。

SDL classes are written in a generic way to support both existing C++ built in data types。

 as well as user defined objects。The STL is not really object oriented since there are no virtual functions and few related classes。

😡，Instead， SDO classes are designed according to the principles of generic programming。

Which is a programming paradigm in which algorithms are written in terms generic types。

Which are then instantiated when needed for specific types provided as parameters。
