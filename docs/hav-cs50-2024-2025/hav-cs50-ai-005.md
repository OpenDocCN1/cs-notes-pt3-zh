## 概述

在本节课中，我们将学习一类新的问题——优化问题。优化问题的核心是从一组可能的选项中选出最佳方案。我们将探讨几种解决优化问题的算法，包括局部搜索、线性规划和约束满足问题。

## 局部搜索算法

![](img/ce17708e240a17c4ad2017322eb352de_10.png)

上一节我们介绍了不同类型的搜索问题。本节中，我们来看看**局部搜索**算法。与之前维护多条路径的搜索算法（如广度优先搜索、A*搜索）不同，局部搜索算法只维护一个节点（即一个状态），并在搜索过程中移动到相邻节点。

这种方法适用于我们不关心具体路径，只关心最终解决方案的问题。例如，在迷宫求解中，我们关心的是到达目标的路径；而在医院选址问题中，我们只关心医院的最佳位置。

### 状态空间与优化目标

![](img/ce17708e240a17c4ad2017322eb352de_12.png)

我们可以将问题抽象为一个**状态空间**。状态空间中的每个状态都有一个对应的值，这个值由**目标函数**（求最大值时）或**成本函数**（求最小值时）计算得出。

![](img/ce17708e240a17c4ad2017322eb352de_14.png)

![](img/ce17708e240a17c4ad2017322eb352de_15.png)

![](img/ce17708e240a17c4ad2017322eb352de_17.png)

*   **目标函数**：衡量状态“好坏”的函数，值越高越好。寻找**全局最大值**。
*   **成本函数**：衡量状态“代价”的函数，值越低越好。寻找**全局最小值**。

### 爬山算法

**爬山算法**是最简单的局部搜索算法。其基本思想是：从当前状态出发，查看所有邻居状态，并移动到值更优的邻居（求最大值时移动到值最高的邻居，求最小值时移动到值最低的邻居）。重复此过程，直到当前状态的值优于所有邻居，此时算法终止，当前状态即为找到的（局部）最优解。

![](img/ce17708e240a17c4ad2017322eb352de_19.png)

以下是爬山算法的伪代码：

![](img/ce17708e240a17c4ad2017322eb352de_21.png)

![](img/ce17708e240a17c4ad2017322eb352de_22.png)

```python
function HILL-CLIMB(problem):
    current = problem.INITIAL_STATE
    loop:
        neighbor = highest-valued neighbor of current
        if neighbor.VALUE <= current.VALUE:
            return current
        current = neighbor
```

![](img/ce17708e240a17c4ad2017322eb352de_26.png)

#### 爬山算法的局限性

![](img/ce17708e240a17c4ad2017322eb352de_28.png)

![](img/ce17708e240a17c4ad2017322eb352de_30.png)

爬山算法可能陷入**局部最优解**（局部最大值或局部最小值），而无法找到**全局最优解**。此外，它还可能遇到**高原**（一片值相同的区域）或**山肩**（平坦但可进步的区域）等问题。

![](img/ce17708e240a17c4ad2017322eb352de_32.png)

#### 爬山算法的变体

![](img/ce17708e240a17c4ad2017322eb352de_34.png)

![](img/ce17708e240a17c4ad2017322eb352de_35.png)

为了克服标准爬山算法的局限性，有以下几种变体：

![](img/ce17708e240a17c4ad2017322eb352de_37.png)

*   **最陡上升爬山法**：总是选择值最高的邻居。
*   **随机爬山法**：随机选择一个优于当前状态的邻居。
*   **首选爬山法**：选择第一个遇到的优于当前状态的邻居。
*   **随机重启爬山法**：多次运行爬山算法，每次从随机初始状态开始，最后选择最佳结果。
*   **局部束搜索**：同时跟踪`k`个最佳状态，而不仅仅是一个。

### 模拟退火算法

**模拟退火算法**通过允许算法有时移动到更差的状态，来帮助跳出局部最优解。其灵感来源于退火物理过程：系统初始时“温度”高，更可能接受差解；随着“温度”降低，接受差解的概率减小。

算法在每一步随机选择一个邻居。如果邻居优于当前状态，则总是移动过去。如果邻居更差，则以一定概率`p`接受这个更差的移动。概率`p`取决于“温度”`T`和成本差`ΔE`，常用公式为：
`p = e^(ΔE / T)`
其中，`ΔE`为邻居与当前状态的成本差（在最小化问题中，`ΔE`为负值）。温度`T`随时间推移而降低。

### 示例：医院选址问题

![](img/ce17708e240a17c4ad2017322eb352de_39.png)

考虑一个网格地图，上面有若干房屋。我们需要放置两家医院，目标是使所有房屋到其最近医院的**曼哈顿距离**之和最小。这是一个最小化成本的问题。

![](img/ce17708e240a17c4ad2017322eb352de_41.png)

![](img/ce17708e240a17c4ad2017322eb352de_43.png)

![](img/ce17708e240a17c4ad2017322eb352de_45.png)

我们可以使用爬山算法或模拟退火算法来求解。算法从一个随机的医院配置开始，通过移动一家医院到相邻格子来生成邻居状态，并计算每种配置的总距离成本。算法不断移动到成本更低的邻居，直到找到局部最优解。随机重启或模拟退火有助于找到更好的全局解。

## 线性规划

**线性规划**是另一类优化问题，其目标是在一组**线性约束**下，最小化（或最大化）一个**线性成本函数**。

![](img/ce17708e240a17c4ad2017322eb352de_51.png)

### 问题形式化

![](img/ce17708e240a17c4ad2017322eb352de_53.png)

一个线性规划问题通常表示为：
*   **最小化**成本函数：`c₁x₁ + c₂x₂ + ... + cₙxₙ`
*   **满足约束**：`a₁₁x₁ + a₁₂x₂ + ... + a₁ₙxₙ ≤ b₁`
                     `a₂₁x₁ + a₂₂x₂ + ... + a₂ₙxₙ ≤ b₂`
                     ...
                     `aₘ₁x₁ + aₘ₂x₂ + ... + aₘₙxₙ ≤ bₘ`
*   以及变量的非负约束等。

![](img/ce17708e240a17c4ad2017322eb352de_55.png)

![](img/ce17708e240a17c4ad2017322eb352de_56.png)

![](img/ce17708e240a17c4ad2017322eb352de_57.png)

![](img/ce17708e240a17c4ad2017322eb352de_58.png)

### 示例：生产优化

假设一家工厂有两台机器X1和X2。
*   X1运行成本为50美元/小时，X2为80美元/小时。**目标**是最小化总成本：`50*x1 + 80*x2`。
*   **约束1（劳动力）**：X1需要5单位劳动/小时，X2需要2单位劳动/小时，总共有20单位劳动可用：`5*x1 + 2*x2 ≤ 20`。
*   **约束2（产量）**：X1产量为10单位/小时，X2为12单位/小时，需要至少90单位总产量：`10*x1 + 12*x2 ≥ 90`。可转换为 `-10*x1 -12*x2 ≤ -90`。

使用Python的`scipy.optimize.linprog`等库可以高效求解此类问题，算法包括**单纯形法**和**内点法**。

## 约束满足问题

![](img/ce17708e240a17c4ad2017322eb352de_67.png)

**约束满足问题**涉及为一组变量赋值，使得所有给定的约束条件得到满足。变量、值域和约束是CSP的三个核心组成部分。

### 问题形式化

![](img/ce17708e240a17c4ad2017322eb352de_69.png)

一个CSP定义为：
*   **变量集合**：`{X₁, X₂, ..., Xₙ}`
*   **值域集合**：每个变量`Xᵢ`有一个可能取值的集合`Dᵢ`。
*   **约束集合**：限制变量值组合的规则。

![](img/ce17708e240a17c4ad2017322eb352de_71.png)

![](img/ce17708e240a17c4ad2017322eb352de_73.png)

### 示例：考试安排

![](img/ce17708e240a17c4ad2017322eb352de_75.png)

有若干课程（变量）需要在周一、周二、周三（值域）安排考试。约束条件是：任何学生选修的两门课程不能安排在同一天（即变量值不能相同）。我们可以用**约束图**来表示，节点是课程，边表示两门课程有冲突。

### 求解方法：回溯搜索

**回溯搜索**是一种用于求解CSP的经典搜索算法。它递归地尝试为变量赋值，如果当前赋值导致后续无法满足约束（遇到死胡同），则回溯到上一个决策点尝试其他赋值。

基本回溯算法伪代码如下：
```python
function BACKTRACK(assignment, csp):
    if assignment is complete:
        return assignment
    var = SELECT-UNASSIGNED-VARIABLE(csp)
    for value in ORDER-DOMAIN-VALUES(var, assignment, csp):
        if value is consistent with assignment:
            add {var = value} to assignment
            result = BACKTRACK(assignment, csp)
            if result != failure:
                return result
            remove {var = value} from assignment
    return failure
```

### 提高效率：推理与启发式

![](img/ce17708e240a17c4ad2017322eb352de_79.png)

![](img/ce17708e240a17c4ad2017322eb352de_81.png)

单纯的回溯搜索可能效率低下。我们可以通过**推理**（在搜索过程中维持某种一致性）和**启发式**来加速。

![](img/ce17708e240a17c4ad2017322eb352de_83.png)

![](img/ce17708e240a17c4ad2017322eb352de_84.png)

![](img/ce17708e240a17c4ad2017322eb352de_86.png)

#### 1. 一致性检查
*   **节点一致性**：确保变量的每个取值都满足其自身的**一元约束**。
*   **弧一致性**：对于变量`X`的每个取值，都存在变量`Y`的一个取值，使得`X`和`Y`之间的**二元约束**得到满足。**AC-3算法**可用于在整个CSP中强制执行弧一致性。

![](img/ce17708e240a17c4ad2017322eb352de_88.png)

![](img/ce17708e240a17c4ad2017322eb352de_89.png)

在回溯搜索中**维持弧一致性**意味着每次赋值后，都运行AC-3算法来缩小其他变量的值域，从而提前发现矛盾，减少不必要的搜索。

#### 2. 变量选择启发式
*   **最少剩余值（MRV）启发式**：选择值域最小的变量。这能最快导致成功或失败，从而剪枝。
*   **度启发式**：在MRV平局时，选择涉及约束最多的变量（度数最高）。这能更强地约束剩余变量。

#### 3. 值排序启发式
*   **最少约束值启发式**：为当前变量尝试赋值时，优先选择给邻居变量留下最多选择的值。这增加了找到解的机会，减少了回溯的需要。

## 总结

本节课我们一起学习了人工智能中的优化技术。我们探讨了：
1.  **局部搜索算法**，如爬山法和模拟退火法，适用于寻找最优配置而不关心路径的问题。
2.  **线性规划**，用于在线性约束下优化线性目标函数，可通过现有库高效求解。
3.  **约束满足问题**，通过回溯搜索结合一致性维护和智能启发式（如MRV、度启发式、最少约束值）来求解。

![](img/ce17708e240a17c4ad2017322eb352de_91.png)

这些方法为我们提供了强大的工具，可以将许多实际问题（如资源分配、调度、路线规划等）形式化为可计算的优化问题，并利用已知算法寻找解决方案。
