再次查看我们刚才看到的网页。这里的第一行 `<!DOCTYPE html>` 是我们可能称之为文档类型声明的东西。这是一种告诉 Web 浏览器我们在此特定网页中使用的 HTML 版本的方式，因为根据 HTML 的版本，Web 浏览器可能希望显示不同的信息，或者可能需要以略有不同的方式解析页面。HTML 的每个版本都有略微不同的方式来指示该版本，但这里的这一行 `<!DOCTYPE html>` 是我们表示此 HTML 页面是使用 HTML5（最新版本的 HTML）编写的方式。

之后，我们的 HTML 页面被构造为一系列嵌套的 HTML 元素，其中 HTML 元素描述了页面上的某些内容，并且我们可能有位于其他元素内部的元素。这些元素中的每一个都由我们称之为 HTML 标签的东西表示，使用尖括号括起来。在这里，我们将看到 HTML 标签的开始，这意味着这是我们页面 HTML 内容的开始。在下面，`</html>` 意味着这是页面 HTML 内容的结束，中间是页面的实际 HTML 内容，其中可能包括其他 HTML 元素。

您可能还会注意到，在这个 HTML 标签中，我们指定了我们称之为 HTML 属性的东西，即我们给这个标签的一些附加信息。特别是，我们给了它一个 `lang` 或语言属性，它等于 `en` 或英语。这只是告诉 Web 浏览器或任何查看此页面 HTML 的人，此页面是用一种语言编写的，并且它编写的语言是英语。这对于搜索引擎等很有帮助，例如，当它们浏览许多不同的网页，试图找出每个网页使用什么语言时，我们可以直接告诉搜索引擎或任何其他查看页面的人，此页面是用英语编写的。

现在，在页面的 HTML 主体内部，我们有许多不同的元素来描述我们在此页面上想要的内容，从网页的头部部分开始，它描述了不在网页主体（用户看到的网页部分）中的内容，而是 Web 浏览器需要了解的有关网页的其他有用或有益的信息。例如，Web 浏览器需要知道的一件重要事情是网页的标题是什么。在这里，我们再次看到一个标题标签，由尖括号中的单词 `title` 表示，后面是标题标签的结束，由 `title` 前的斜杠表示。在两个标题标签之间是单词 `hello`，这意味着此页面的标题应该是单词 `hello`。

接下来是页面的主体，再次由 `body` 标签表示，并以带有斜杠 `body` 的标签结束，这意味着这是页面主体的结束。页面的主体再次是用户可以看到的页面的可见部分。我们希望在页面主体内部有什么？目前，我们只想要文本 `Hello world`。这就是当有人访问此网页时将显示的信息。

所以这就是这个 HTML 页面的全部内容。我们在标题中指定了页面有一个名为 `hello` 的标题，在主体内部，我们说页面应该说单词 `hello world`。如果您想以视觉方式思考所有这些 HTML 元素的结构方式，有时将 HTML 页面视为我们称之为文档对象模型或 DOM 的树状结构会很有帮助。

例如，这是此网页的 DOM 可能看起来的样子。左边是我们刚才看到的 HTML 内容，右边是 DOM，即文档对象模型，描述所有这些 HTML 元素如何相互关联的树状结构。我们从这里的 HTML 元素开始。这个父元素，可以说，有两个子元素：一个 `head` 元素和一个 `body` 元素。正如我们在这里看到的，在 HTML 内部，我们有一个头部部分和一个主体部分。我们在 HTML 中包含的缩进并不是严格必需的。Web 浏览器不关心缩进是什么，但对于阅读页面的人来说，查看缩进以直观地理解头部在 HTML 元素内部，主体也在 HTML 元素内部会很有帮助。
