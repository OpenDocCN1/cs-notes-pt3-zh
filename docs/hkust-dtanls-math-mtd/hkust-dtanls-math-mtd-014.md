# 014：矩阵范数





在本节课中，我们将学习如何为矩阵定义范数。我们已经知道，大小为 M × N 的矩阵本身构成一个向量空间。本节中，我们将探讨基于对矩阵的不同理解，如何引入不同的矩阵范数。


## 将矩阵视为长向量



上一节我们介绍了矩阵空间的概念。本节中我们来看看第一种理解方式：将矩阵视为一个很长的向量。

具体来说，对于一个属于 R^(M×N) 的矩阵 A，我们可以将其所有列依次堆叠起来，形成一个属于 R^(MN) 的长向量。



以下是基于这种“向量化”思想定义的范数，我们称之为**向量 p 范数**。我们将矩阵 A 向量化后得到的向量记作 vec(A)，然后对其应用 R^(MN) 空间中的 p 范数：


**公式：** ||A||_p = ||vec(A)||_p



根据 p 取值的不同，我们可以得到几种常见的范数：


*   **向量 1 范数 (p=1):** 定义为向量化后所有元素绝对值的和。这等价于矩阵 A 所有元素绝对值的和。
    **公式：** ||A||_1 = Σ_i Σ_j |a_ij|
*   **向量 2 范数 (p=2):** 定义为向量化后所有元素平方和的平方根。这等价于矩阵 A 所有元素平方和的平方根。这个范数非常特殊且常用，被称为 **Frobenius 范数**。
    **公式：** ||A||_F = √( Σ_i Σ_j |a_ij|² )
*   **向量无穷范数 (p=∞):** 定义为向量化后所有元素绝对值的最大值。这等价于矩阵 A 所有元素绝对值的最大值。
    **公式：** ||A||_∞ = max_{i,j} |a_ij|



以上便是通过将矩阵视为长向量来定义矩阵范数的一种方法。
