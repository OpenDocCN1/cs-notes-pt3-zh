![](img/baafe0e0c9494c2eb52f08c8f35b9a54_0.png)

![](img/baafe0e0c9494c2eb52f08c8f35b9a54_2.png)

在本节课中，我们将学习如何将范数的概念从离散的向量空间（如欧几里得空间或矩阵空间）推广到连续的**函数空间**。我们将重点介绍在连续函数空间 `C[a, b]` 上定义的几种常见范数，并理解它们如何衡量两个函数之间的距离。

## 函数空间与无穷范数

上一节我们介绍了向量和矩阵上的范数。本节中，我们来看看范数如何应用于函数。

首先，考虑定义在闭区间 `[a, b]` 上的所有连续函数构成的集合，记作 `C[a, b]`。这个集合在函数的加法和数乘运算下构成一个向量空间。我们可以在这个空间上定义范数。

![](img/baafe0e0c9494c2eb52f08c8f35b9a54_4.png)

第一个重要的范数是**无穷范数**（或最大模范数）。对于任意函数 `f ∈ C[a, b]`，其无穷范数定义为该函数在区间 `[a, b]` 上绝对值的最大值：

![](img/baafe0e0c9494c2eb52f08c8f35b9a54_6.png)

**公式：** `||f||_∞ = max_{t ∈ [a, b]} |f(t)|`

![](img/baafe0e0c9494c2eb52f08c8f35b9a54_8.png)

可以验证，这个定义满足范数的所有公理。有了这个范数，我们就可以衡量两个连续函数 `f` 和 `g` 之间的“距离”：

![](img/baafe0e0c9494c2eb52f08c8f35b9a54_10.png)

![](img/baafe0e0c9494c2eb52f08c8f35b9a54_12.png)

**公式：** `d(f, g) = ||f - g||_∞ = max_{t ∈ [a, b]} |f(t) - g(t)|`

这个距离的几何意义是：对于两个函数图像，我们计算它们在每一点 `t` 处的垂直距离 `|f(t) - g(t)|`，然后取所有这些距离中的最大值。如果这个最大距离为0，则意味着两个函数在每一点都相等，即 `f = g`。

## 函数空间上的 p-范数

![](img/baafe0e0c9494c2eb52f08c8f35b9a54_14.png)

![](img/baafe0e0c9494c2eb52f08c8f35b9a54_16.png)

除了无穷范数，我们还可以像在欧几里得空间中定义 p-范数一样，为函数空间定义一系列 p-范数。

![](img/baafe0e0c9494c2eb52f08c8f35b9a54_18.png)

![](img/baafe0e0c9494c2eb52f08c8f35b9a54_20.png)

以下是几种常见的 p-范数定义：

*   **1-范数**：函数绝对值的积分。
    **公式：** `||f||_1 = ∫_a^b |f(t)| dt`

*   **2-范数**：函数平方的积分再开方，类似于欧几里得空间中的长度。
    **公式：** `||f||_2 = (∫_a^b |f(t)|^2 dt)^(1/2)`

![](img/baafe0e0c9494c2eb52f08c8f35b9a54_22.png)

*   **p-范数**（p ≥ 1）：更一般的形式。
    **公式：** `||f||_p = (∫_a^b |f(t)|^p dt)^(1/p)`

一个有趣的现象是，当 `p` 趋向于无穷大时，p-范数的极限就是前面定义的无穷范数：

**公式：** `lim_{p→∞} ||f||_p = ||f||_∞`

![](img/baafe0e0c9494c2eb52f08c8f35b9a54_24.png)

![](img/baafe0e0c9494c2eb52f08c8f35b9a54_26.png)

因此，无穷范数可以看作是 p-范数家族在 `p→∞` 时的特例。

![](img/baafe0e0c9494c2eb52f08c8f35b9a54_28.png)

![](img/baafe0e0c9494c2eb52f08c8f35b9a54_30.png)

## 总结

![](img/baafe0e0c9494c2eb52f08c8f35b9a54_33.png)

![](img/baafe0e0c9494c2eb52f08c8f35b9a54_35.png)

本节课中我们一起学习了范数概念在连续函数空间 `C[a, b]` 上的扩展。我们介绍了关键的**无穷范数**，它通过函数值的最大绝对差来衡量函数的大小和函数间的距离。此外，我们还定义了一系列**p-范数**（包括1-范数和2-范数），它们通过积分来度量函数，并且无穷范数是p-范数在 `p→∞` 时的极限。这些工具使我们能够量化并比较连续函数，是函数分析和逼近理论中的重要基础。
