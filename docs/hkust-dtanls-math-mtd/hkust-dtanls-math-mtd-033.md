# 033：内积的性质与柯西-施瓦茨不等式 🔍

在本节中，我们将探讨内积的一个重要性质——柯西-施瓦茨不等式。这个不等式是内积空间理论中最基本且最有趣的性质之一，它描述了向量内积与其自身内积之间的关系。

![](img/9cd2be3a5b27bf81af34bf34c3ee6a3c_1.png)

## 柯西-施瓦茨不等式

柯西-施瓦茨不等式指出，对于任意向量 **x** 和 **y**，其内积的绝对值平方小于或等于它们各自与自身内积的乘积。具体公式如下：

**|⟨x, y⟩|² ≤ ⟨x, x⟩ · ⟨y, y⟩**

![](img/9cd2be3a5b27bf81af34bf34c3ee6a3c_3.png)

当且仅当向量 **x** 和 **y** 线性相关（即存在标量 α 使得 **x = αy** 或 **y = αx**）时，等号成立。

![](img/9cd2be3a5b27bf81af34bf34c3ee6a3c_5.png)

![](img/9cd2be3a5b27bf81af34bf34c3ee6a3c_6.png)

![](img/9cd2be3a5b27bf81af34bf34c3ee6a3c_8.png)

## 不等式证明

![](img/9cd2be3a5b27bf81af34bf34c3ee6a3c_10.png)

接下来，我们将分步骤证明柯西-施瓦茨不等式。证明过程分为两个主要部分：处理 **y = 0** 的特殊情况，以及处理 **y ≠ 0** 的一般情况。

![](img/9cd2be3a5b27bf81af34bf34c3ee6a3c_12.png)

### 第一部分：当 y = 0 时

![](img/9cd2be3a5b27bf81af34bf34c3ee6a3c_14.png)

首先，我们证明一个引理：对于任意向量 **x**，有 ⟨x, 0⟩ = 0。

![](img/9cd2be3a5b27bf81af34bf34c3ee6a3c_16.png)

**证明**：
根据内积定义中的线性性质（关于第二个变量），我们有：
⟨x, 0⟩ = ⟨x, a - a⟩ = ⟨x, a⟩ - ⟨x, a⟩ = 0
同理可证 ⟨0, x⟩ = 0。

![](img/9cd2be3a5b27bf81af34bf34c3ee6a3c_18.png)

当 **y = 0** 时，不等式左边为 |⟨x, 0⟩|² = 0。根据内积定义的第一条性质，⟨y, y⟩ = ⟨0, 0⟩ = 0，因此不等式右边也为 0。此时，0 ≤ 0 成立，不等式得证。

### 第二部分：当 y ≠ 0 时

现在考虑 **y ≠ 0** 的情况。我们构造一个关于标量 λ 的二次函数 **F(λ)**。

![](img/9cd2be3a5b27bf81af34bf34c3ee6a3c_20.png)

**定义函数**：
**F(λ) = ⟨x + λy, x + λy⟩**

![](img/9cd2be3a5b27bf81af34bf34c3ee6a3c_22.png)

![](img/9cd2be3a5b27bf81af34bf34c3ee6a3c_24.png)

根据内积定义的第一条性质，任何向量与自身的内积都大于等于零，因此对于任意 λ，都有 **F(λ) ≥ 0**。

![](img/9cd2be3a5b27bf81af34bf34c3ee6a3c_26.png)

我们利用内积的线性性质（双线性）来展开 **F(λ)**：

**F(λ) = ⟨x, x⟩ + λ⟨x, y⟩ + λ⟨y, x⟩ + λ²⟨y, y⟩**

再利用内积的对称性 ⟨x, y⟩ = ⟨y, x⟩，合并中间两项：

![](img/9cd2be3a5b27bf81af34bf34c3ee6a3c_28.png)

![](img/9cd2be3a5b27bf81af34bf34c3ee6a3c_30.png)

**F(λ) = ⟨x, x⟩ + 2λ⟨x, y⟩ + λ²⟨y, y⟩**

由于 **y ≠ 0**，根据内积定义，⟨y, y⟩ > 0。因此，**F(λ)** 是一个开口向上的二次函数（二次项系数为正）。

![](img/9cd2be3a5b27bf81af34bf34c3ee6a3c_32.png)

![](img/9cd2be3a5b27bf81af34bf34c3ee6a3c_34.png)

因为 **F(λ) ≥ 0** 对任意 λ 都成立，这意味着该二次函数的图像（抛物线）必须位于或接触横轴上方。因此，其判别式必须小于或等于零。

![](img/9cd2be3a5b27bf81af34bf34c3ee6a3c_36.png)

**判别式条件**：
对于二次方程 **aλ² + bλ + c = 0**，判别式 Δ = b² - 4ac ≤ 0。
在我们的函数中：
*   a = ⟨y, y⟩
*   b = 2⟨x, y⟩
*   c = ⟨x, x⟩

代入判别式：
**(2⟨x, y⟩)² - 4 · ⟨y, y⟩ · ⟨x, x⟩ ≤ 0**

![](img/9cd2be3a5b27bf81af34bf34c3ee6a3c_38.png)

化简后得到：
**4⟨x, y⟩² ≤ 4⟨x, x⟩⟨y, y⟩**

两边同时除以 4，即得到柯西-施瓦茨不等式：
**⟨x, y⟩² ≤ ⟨x, x⟩⟨y, y⟩**

### 等号成立条件

上一部分我们证明了不等式本身，现在我们来探讨等号成立的条件。

![](img/9cd2be3a5b27bf81af34bf34c3ee6a3c_40.png)

**1. 如果等号成立，则向量线性相关**
*   若 **y = 0**，则显然有 **y = 0 · x**。
*   若 **y ≠ 0**，则判别式 Δ = 0。这意味着存在某个 λ₀ 使得 **F(λ₀) = 0**。即：
    **⟨x + λ₀y, x + λ₀y⟩ = 0**
    根据内积定义，这等价于 **x + λ₀y = 0**，即 **x = -λ₀y**。令 α = -λ₀，则有 **x = αy**。

**2. 如果向量线性相关，则等号成立**
反之，如果 **x = αy**，则将其代入不等式两边：
*   左边：⟨x, y⟩² = ⟨αy, y⟩² = α²⟨y, y⟩²
*   右边：⟨x, x⟩⟨y, y⟩ = ⟨αy, αy⟩⟨y, y⟩ = α²⟨y, y⟩⟨y, y⟩ = α²⟨y, y⟩²
两边相等，等号成立。**y = αx** 的情况同理可证。

![](img/9cd2be3a5b27bf81af34bf34c3ee6a3c_42.png)

## 总结

![](img/9cd2be3a5b27bf81af34bf34c3ee6a3c_44.png)

![](img/9cd2be3a5b27bf81af34bf34c3ee6a3c_45.png)

本节课我们一起学习了内积的核心性质——柯西-施瓦茨不等式。我们通过严谨的证明，展示了对于任意两个向量，其内积的平方不会超过它们各自模长平方的乘积。更重要的是，我们明确了等号成立当且仅当两个向量共线（线性相关）。这个不等式是定义向量长度和角度的基础，在数据分析的众多算法中（如衡量相似性、进行正交分解）都扮演着至关重要的角色。
