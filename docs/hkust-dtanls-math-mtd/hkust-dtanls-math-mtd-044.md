# 044：线性函数的性质 🔍

![](img/dac4bd83ff562512e6b62c3f78b8e9c1_1.png)

在本节课中，我们将学习线性函数的三个核心性质：齐次性、可加性以及它们对任意多个向量线性组合的推广。理解这些性质是掌握线性代数在数据分析中应用的基础。

---

![](img/dac4bd83ff562512e6b62c3f78b8e9c1_3.png)

上一节我们介绍了线性函数的定义，本节中我们来看看由定义直接推导出的几个重要性质。

## 齐次性

![](img/dac4bd83ff562512e6b62c3f78b8e9c1_5.png)

线性函数的第一个性质是齐次性。这意味着，将一个向量乘以一个标量后再应用函数，等同于先应用函数再将结果乘以该标量。

![](img/dac4bd83ff562512e6b62c3f78b8e9c1_7.png)

其**公式**表示为：
对于任意实数 α 和任意向量 **x**，有：
**F(αx) = αF(x)**

![](img/dac4bd83ff562512e6b62c3f78b8e9c1_9.png)

![](img/dac4bd83ff562512e6b62c3f78b8e9c1_11.png)

这个性质很容易证明。我们可以将 α**x** 看作是 **x** 和 **x** 自身的一个线性组合，系数分别为 α 和 0。根据线性函数的定义：
**F(αx) = F(αx + 0x) = αF(x) + 0F(x) = αF(x)**

![](img/dac4bd83ff562512e6b62c3f78b8e9c1_13.png)

![](img/dac4bd83ff562512e6b62c3f78b8e9c1_15.png)

特别地，如果我们选择 α = 0，那么 0***x** 就是零向量。由此我们得到一个重要推论：
**F(0) = 0**
这表明，线性函数必然将零向量映射到数字零。

![](img/dac4bd83ff562512e6b62c3f78b8e9c1_17.png)

## 可加性

线性函数的第二个性质是可加性。这意味着，对两个向量的和应用函数，等同于分别对每个向量应用函数后再将结果相加。

其**公式**表示为：
对于任意向量 **x** 和 **y**，有：
**F(x + y) = F(x) + F(y)**

![](img/dac4bd83ff562512e6b62c3f78b8e9c1_19.png)

![](img/dac4bd83ff562512e6b62c3f78b8e9c1_20.png)

这个性质同样可以直接从定义推导。在线性函数的定义 **F(αx + βy) = αF(x) + βF(y)** 中，我们只需令 α = β = 1，即可得到：
**F(1*x + 1*y) = 1*F(x) + 1*F(y)**，即 **F(x + y) = F(x) + F(y)**。

以上两个性质是线性函数定义的直接推论。事实上，在某些教材中，线性函数正是通过同时满足**齐次性**和**可加性**来定义的。可以证明，这两个条件合在一起，与原始的线性函数定义是等价的。

![](img/dac4bd83ff562512e6b62c3f78b8e9c1_22.png)

## 对任意多个向量的推广

![](img/dac4bd83ff562512e6b62c3f78b8e9c1_24.png)

线性函数的定义最初只涉及两个向量的线性组合。一个自然的问题是：对于更多向量的线性组合，这个性质是否依然成立？

![](img/dac4bd83ff562512e6b62c3f78b8e9c1_26.png)

答案是肯定的。线性函数与线性组合的“可交换性”可以推广到任意有限多个向量。

![](img/dac4bd83ff562512e6b62c3f78b8e9c1_28.png)

![](img/dac4bd83ff562512e6b62c3f78b8e9c1_30.png)

考虑 **k** 个向量 **x₁, x₂, ..., xₖ** 和标量 α₁, α₂, ..., αₖ 的线性组合。应用函数 **F** 的结果如下：

**F(α₁x₁ + α₂x₂ + ... + αₖxₖ) = α₁F(x₁) + α₂F(x₂) + ... + αₖF(xₖ)**

![](img/dac4bd83ff562512e6b62c3f78b8e9c1_32.png)

我们可以通过递归应用线性函数的定义来证明这一点。首先，将线性组合视为第一个向量与剩余向量的组合：
**F(α₁x₁ + (α₂x₂ + ... + αₖxₖ)) = α₁F(x₁) + F(α₂x₂ + ... + αₖxₖ)**
然后，对剩余部分继续应用定义，最终得到所有项的线性组合。

![](img/dac4bd83ff562512e6b62c3f78b8e9c1_34.png)

![](img/dac4bd83ff562512e6b62c3f78b8e9c1_35.png)

这意味着，对任意多个向量的线性组合应用函数 **F**，其结果等于这些向量的函数值以相同系数进行的线性组合。这是一个非常强大的工具。

![](img/dac4bd83ff562512e6b62c3f78b8e9c1_37.png)

---

本节课中我们一起学习了线性函数的三个核心性质：
1.  **齐次性**：**F(αx) = αF(x)**，特别地 **F(0) = 0**。
2.  **可加性**：**F(x + y) = F(x) + F(y)**。
3.  **对任意线性组合的推广**：函数 **F** 可以与任意有限多个向量的线性组合进行“交换”。

![](img/dac4bd83ff562512e6b62c3f78b8e9c1_39.png)

![](img/dac4bd83ff562512e6b62c3f78b8e9c1_41.png)

理解这些性质有助于我们更深入地把握线性结构的本质，并为后续学习矩阵、线性变换等概念打下坚实基础。
