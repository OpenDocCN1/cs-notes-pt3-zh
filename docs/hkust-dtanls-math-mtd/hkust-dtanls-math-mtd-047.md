# 047：超平面 🧮

![](img/364771f3d659373fe53ad1750d34ef84_0.png)

在本节课中，我们将要学习希尔伯特空间中的一个基本几何对象——超平面。我们将从定义出发，探讨其作为线性方程解集的性质，并理解其几何结构。

---

## 超平面的定义

现在，我们考虑一个由线性函数定义的简单几何对象。具体来说，我们考虑**超平面**。

设 **H** 是一个希尔伯特空间。设 **a** 是 **H** 空间中的一个向量。我们考虑一个集合 **Sₐ₀**，其定义为 **H** 中所有满足以下条件的 **x** 的集合：

![](img/364771f3d659373fe53ad1750d34ef84_2.png)

**⟨a, x⟩ = 0**

![](img/364771f3d659373fe53ad1750d34ef84_4.png)

这无疑是希尔伯特空间中的一个子集。下标中的 **a** 指的是内积中的向量，**0** 指的是方程的右侧常数项。

---

## 超平面是一个子空间

接下来，我们验证这个集合 **Sₐ₀** 的结构。

对于任意标量 **α** 和 **β**，以及任意属于 **Sₐ₀** 的向量 **x** 和 **y**，我们考虑 **a** 与它们的线性组合的内积：

**⟨a, (αx + βy)⟩**

根据线性函数的性质，这等于：

**α⟨a, x⟩ + β⟨a, y⟩**

![](img/364771f3d659373fe53ad1750d34ef84_6.png)

由于 **x** 和 **y** 都在 **Sₐ₀** 中，所以 **⟨a, x⟩ = 0** 且 **⟨a, y⟩ = 0**。因此，上述内积结果为 **0**。

![](img/364771f3d659373fe53ad1750d34ef84_8.png)

由此可知，**αx + βy** 也属于 **Sₐ₀**。这表明，给定 **Sₐ₀** 中任意两个向量，它们的任意线性组合仍然在 **Sₐ₀** 中。可以轻易验证，无限多个向量的线性组合也仍在 **Sₐ₀** 中。这告诉我们，**Sₐ₀** 在线性组合操作下是封闭的。

因此，**Sₐ₀** 本身构成一个线性空间，即一个向量子空间。我们称其为 **H** 的一个**子空间**。

从几何上看，在三维空间中，**Sₐ₀** 看起来像一个穿过原点的平面。显然，零向量 **0** 属于这个空间，因为 **⟨a, 0⟩ = 0**。

![](img/364771f3d659373fe53ad1750d34ef84_10.png)

## 推广到一般超平面

![](img/364771f3d659373fe53ad1750d34ef84_14.png)

上一节我们介绍了通过原点的超平面（即子空间），本节中我们来看看更一般的情况。

现在，我们将方程右侧的 **0** 改为任意常数 **b**。我们考虑集合 **Sₐᵦ**，其定义为：

**Sₐᵦ = { x ∈ H | ⟨a, x⟩ = b }**

这同样是 **H** 中的一个子集。我们来分析 **Sₐᵦ** 的结构。

设 **x₀** 是 **Sₐᵦ** 中的任意一点。根据定义，有 **⟨a, x₀⟩ = b**。

对于 **Sₐᵦ** 中的任意 **x**，我们考虑 **⟨a, (x - x₀)⟩**：

**⟨a, (x - x₀)⟩ = ⟨a, x⟩ - ⟨a, x₀⟩ = b - b = 0**

![](img/364771f3d659373fe53ad1750d34ef84_16.png)

由此可知，**x - x₀** 属于 **Sₐ₀**（即我们之前定义的子空间）。因此，**x** 可以表示为 **x₀** 加上一个 **Sₐ₀** 中的向量：

**x ∈ x₀ + Sₐ₀**

由于 **x** 是 **Sₐᵦ** 中的任意元素，我们可以得出：

**Sₐᵦ ⊆ x₀ + Sₐ₀**  (1)

![](img/364771f3d659373fe53ad1750d34ef84_18.png)

反之，考虑 **Sₐ₀** 中的任意元素 **x**。那么对于 **x + x₀**，有：

**⟨a, (x + x₀)⟩ = ⟨a, x⟩ + ⟨a, x₀⟩ = 0 + b = b**

![](img/364771f3d659373fe53ad1750d34ef84_20.png)

因此，**x + x₀** 属于 **Sₐᵦ**。由于 **x** 是 **Sₐ₀** 中的任意元素，我们可以得出：

**x₀ + Sₐ₀ ⊆ Sₐᵦ**  (2)

![](img/364771f3d659373fe53ad1750d34ef84_22.png)

综合 (1) 和 (2)，我们得到：

![](img/364771f3d659373fe53ad1750d34ef84_24.png)

**Sₐᵦ = x₀ + Sₐ₀**

## 超平面的几何意义

![](img/364771f3d659373fe53ad1750d34ef84_29.png)

现在，**Sₐ₀** 是一个子空间（向量空间），而 **Sₐᵦ** 是这个子空间的一个平移。

![](img/364771f3d659373fe53ad1750d34ef84_31.png)

从几何上看，我们有一个向量 **x₀**，将子空间 **Sₐ₀** 平移 **x₀** 就得到了 **Sₐᵦ**。这个平移不会改变集合的形状，因为 **Sₐ₀** 本身是“平坦”的（一个子空间，一个平面）。因此，**Sₐᵦ** 虽然不是一个子空间，但它仍然是平坦的，仍然是一个平面。

所以，**Sₐᵦ** 是 **H** 空间中的一个平面。

此外，集合 **Sₐᵦ** 由一个线性方程定义，这意味着 **H** 中所有向量的参数个数由于这个约束条件而减少了一个。我们称其**余维数**为 1。

![](img/364771f3d659373fe53ad1750d34ef84_33.png)

因此，我们称 **Sₐᵦ** 为一个**超平面**。

![](img/364771f3d659373fe53ad1750d34ef84_35.png)

---

## 核心总结

![](img/364771f3d659373fe53ad1750d34ef84_37.png)

简而言之，一个超平面就是以下列方式定义的集合：

![](img/364771f3d659373fe53ad1750d34ef84_38.png)

**{ x ∈ H | ⟨a, x⟩ = b }**

![](img/364771f3d659373fe53ad1750d34ef84_40.png)

它是线性方程 **⟨a, x⟩ = b** 的解集。

![](img/364771f3d659373fe53ad1750d34ef84_42.png)

其几何结构是子空间 **Sₐ₀** 的一个平移，即 **x₀ + Sₐ₀**。

---

![](img/364771f3d659373fe53ad1750d34ef84_44.png)

本节课中，我们一起学习了超平面的定义、数学结构及其几何解释。我们了解到，超平面是希尔伯特空间中由一个线性方程定义的平坦子集，它可以被视为一个子空间的平移，其几何直观类似于我们熟悉的三维空间中的平面。
