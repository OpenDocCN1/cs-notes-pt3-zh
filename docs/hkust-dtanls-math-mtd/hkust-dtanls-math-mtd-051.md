# 051：线性函数的应用与表示 🧮

在本节课中，我们将学习线性函数的具体应用及其表示方法。我们将重点研究**线性回归**和**线性分类器**这两种核心模型。我们将使用线性函数来完成回归任务，同样也使用线性函数来完成分类任务。

## 线性回归模型 📈

![](img/7f4500ad58ebccb0146bc01950a4882e_1.png)

上一节我们介绍了线性函数的基本概念，本节中我们来看看它在回归问题中的应用。

![](img/7f4500ad58ebccb0146bc01950a4882e_3.png)

线性回归的任务描述如下：给定一组数据对，形式为 `(x1, y1), (x2, y2), ..., (xN, yN)`。这里，我们假设有 `N` 对数据。其中，`xi` 是输入向量，通常属于 `R^n` 空间；`yi` 是对应的输出或标签，为简化起见，我们假设它是实数。我们的目标是进行预测：给定一个新的输入 `x`，我们想要预测其对应的输出 `y`。

![](img/7f4500ad58ebccb0146bc01950a4882e_5.png)

![](img/7f4500ad58ebccb0146bc01950a4882e_7.png)

为了解决这个问题，我们首先需要将其转化为一个数学问题。在数学中，我们使用函数来描述输入与输出之间的关系。因此，我们需要找到一个函数 `f: R^n -> R`，使得这个函数能够反映训练数据集中输入与输出对之间的关系。这意味着我们希望对于所有 `i`，都有 `f(xi) ≈ yi`。一旦我们找到了这个函数 `f`，就可以将其应用于新的输入 `x` 来获得预测值 `f(x)`。

![](img/7f4500ad58ebccb0146bc01950a4882e_9.png)

## 函数类的选择 🤔

![](img/7f4500ad58ebccb0146bc01950a4882e_11.png)

![](img/7f4500ad58ebccb0146bc01950a4882e_13.png)

然而，如何找到这样一个函数呢？上述描述非常模糊，缺乏数学上的严谨性。首先，所有从 `R^n` 到 `R` 的函数的集合过于庞大。这会导致两个主要问题：

1.  **自由度问题**：我们只拥有有限的数据对（`N` 个）。如果函数过于任意，其包含的自由度可能超过数据量 `N`，那么我们就无法唯一地确定这个函数 `f`。可能会有许多不同的 `f` 都能精确满足 `f(xi) = yi`。
2.  **预测能力问题**：庞大的函数集合中包含了许多“奇怪”的函数，它们不适合用于预测。我们的任务是预测，新的输入 `x` 通常不会完全等于任何一个 `xi`，而是位于其邻域内。如果函数 `f` 对 `x` 的微小扰动过于敏感，那么即使 `x` 非常接近某个 `xi`，`f(x)` 也可能与 `f(xi)` 相差甚远，导致预测能力很差。这关系到函数的平滑性。

![](img/7f4500ad58ebccb0146bc01950a4882e_15.png)

因此，我们不能在所有函数中寻找 `f`，而必须在一个更小的子集 `Φ` 中寻找。选择这个子集 `Φ` 是关键，也是机器学习中的一个基本问题。

*   如果 `Φ` 太大（包含太多函数），我们可能没有足够的数据来唯一确定一个函数，并且集合中可能包含许多不适合预测的奇怪函数。
*   如果 `Φ` 太小，其近似能力可能太弱，以至于无法很好地逼近数据背后真实的关系函数。

![](img/7f4500ad58ebccb0146bc01950a4882e_17.png)

![](img/7f4500ad58ebccb0146bc01950a4882e_19.png)

我们需要选择一个大小合适的 `Φ` 来平衡这些问题。在本课程中，我们不深入讨论如何选择 `Φ`，而是考察一个特殊的、常用的选择：我们将 `Φ` 选择为所有**仿射函数**的集合。按照惯例，我们通常称仿射函数为线性函数。

![](img/7f4500ad58ebccb0146bc01950a4882e_21.png)

![](img/7f4500ad58ebccb0146bc01950a4882e_23.png)

## 线性回归的数学形式 📐

![](img/7f4500ad58ebccb0146bc01950a4882e_25.png)

![](img/7f4500ad58ebccb0146bc01950a4882e_26.png)

如果我们选择 `Φ` 为所有仿射函数的集合，就得到了所谓的**线性模型**。将其应用于回归问题，就得到了**线性回归**。

![](img/7f4500ad58ebccb0146bc01950a4882e_28.png)

根据表示定理，任何仿射函数都可以写成以下形式：
`f(x) = a^T * x + b`
其中，`a` 是一个 `n` 维向量，`b` 是一个实数。因此，一个仿射函数由向量 `a` 和标量 `b` 唯一确定。

![](img/7f4500ad58ebccb0146bc01950a4882e_30.png)

于是，寻找函数 `f` 的问题就转化为寻找参数 `a` 和 `b`，使得对于所有 `i`，有 `a^T * xi + b ≈ yi`。我们需要一个严谨的标准来衡量“近似”。这里我们采用最常用的一种标准：**最小二乘法**。

![](img/7f4500ad58ebccb0146bc01950a4882e_32.png)

![](img/7f4500ad58ebccb0146bc01950a4882e_34.png)

在最小二乘法中，我们定义每个数据点的误差为 `(a^T * xi + b - yi)`。我们希望所有数据点的总误差平方和最小。因此，线性回归问题转化为以下优化问题：
`min_{a, b} Σ_{i=1}^{N} (a^T * xi + b - yi)^2`

## 最小二乘的标准矩阵形式 ⚙️

![](img/7f4500ad58ebccb0146bc01950a4882e_36.png)

![](img/7f4500ad58ebccb0146bc01950a4882e_37.png)

![](img/7f4500ad58ebccb0146bc01950a4882e_39.png)

为了更简洁地求解，我们将上述问题写成标准矩阵形式。

首先，定义以下矩阵和向量：
*   设计矩阵 `X`：一个 `N x (n+1)` 的矩阵，其第 `i` 行为 `[xi^T, 1]`。
*   参数向量 `β`：一个 `(n+1)` 维向量，`β = [a; b]`（即将 `a` 和 `b` 拼接成一个列向量）。
*   输出向量 `y`：一个 `N` 维向量，`y = [y1, y2, ..., yN]^T`。

利用这些定义，所有数据点的预测值可以表示为 `Xβ`。那么，误差向量就是 `Xβ - y`。最小二乘的目标函数——误差平方和——恰好是这个误差向量的 **L2 范数的平方**。

因此，线性回归的最小二乘问题等价于：
`min_{β} ||Xβ - y||^2`

![](img/7f4500ad58ebccb0146bc01950a4882e_41.png)

这是一个关于 `β` 的无约束优化问题，可以通过求导等数学方法得到解析解（当 `X^T X` 可逆时，解为 `β = (X^T X)^{-1} X^T y`），也可以通过梯度下降等数值方法求解。

## 预测过程 🎯

求解上述优化问题后，我们得到了最优的参数 `β`，即得到了 `a` 和 `b`。于是，我们的预测函数为：
`f(x) = a^T * x + b`

对于任何一个新的输入向量 `x`，我们只需计算 `a^T * x + b`，其结果就是我们对输出 `y` 的预测值。

![](img/7f4500ad58ebccb0146bc01950a4882e_43.png)

![](img/7f4500ad58ebccb0146bc01950a4882e_45.png)

本节课中我们一起学习了线性回归模型。我们从回归问题的定义出发，讨论了为何需要限制函数类，并选择了仿射函数作为我们的模型。接着，我们将问题转化为寻找最优参数 `a` 和 `b` 的最小二乘优化问题，并将其表示为简洁的矩阵形式 `min ||Xβ - y||^2`。最后，我们了解了如何使用求解得到的参数进行预测。线性回归是数据分析中最基础、最重要的工具之一。
