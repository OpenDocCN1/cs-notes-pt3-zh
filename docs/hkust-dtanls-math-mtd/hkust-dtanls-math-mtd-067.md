# 067：Fréchet 导数的性质（一）📈

在本节课中，我们将要学习 Fréchet 导数的一个重要性质：**线性性**。我们将通过严谨的数学推导来证明，对于两个可微函数的线性组合，其导数等于各自导数的线性组合。

---

上一节我们介绍了 Fréchet 导数的基本定义，本节中我们来看看它的第一个核心性质。

Fréchet 导数是线性的。这意味着，对于任意实数 **α** 和 **β**，以及任意两个从向量空间 **V** 映射到实数 **R** 的函数 **F** 和 **G**，只要它们在点 **x** 处可微（即梯度存在），就有以下公式成立：

**∇(αF + βG)(x) = α∇F(x) + β∇G(x)**


换句话说，先对函数进行线性组合再求导，等价于先分别求导再进行同样的线性组合。

---


为了证明这个性质，我们需要从 Fréchet 导数的定义出发。


首先，根据 **F** 在 **x** 处可微的定义，存在一个线性逼近，使得当 **y** 趋近于 **x** 时，逼近误差与 **‖y - x‖** 的比值极限为零。用公式表示如下：

**lim_{‖y-x‖→0} [ F(y) - (F(x) + ∇F(x)ᵀ(y - x)) ] / ‖y - x‖ = 0**

同理，对于函数 **G**，也有类似的定义：


**lim_{‖y-x‖→0} [ G(y) - (G(x) + ∇G(x)ᵀ(y - x)) ] / ‖y - x‖ = 0**

我们的目标是证明，对于组合函数 **αF + βG**，其导数就是 **α∇F(x) + β∇G(x)**。为此，我们需要考察以下极限是否为零：


**lim_{‖y-x‖→0} [ (αF+βG)(y) - ((αF+βG)(x) + [α∇F(x)+β∇G(x)]ᵀ(y-x)) ] / ‖y - x‖**

---


以下是证明的主要步骤：




1.  **展开分子**：将上述极限的分子展开并重新分组。
    *   原分子 = **α[F(y) - F(x) - ∇F(x)ᵀ(y-x)] + β[G(y) - G(x) - ∇G(x)ᵀ(y-x)]**



2.  **应用三角不等式**：利用绝对值不等式，我们可以得到该极限表达式的一个上界。
    *   原式 ≤ **|α| * |F(y) - F(x) - ∇F(x)ᵀ(y-x)| / ‖y-x‖ + |β| * |G(y) - G(x) - ∇G(x)ᵀ(y-x)| / ‖y-x‖**



3.  **利用可微性**：根据 **F** 和 **G** 在 **x** 处可微的定义，当 **‖y-x‖→0** 时，上一步中的两项分别趋近于 0。
    *   因此，整个表达式的上界趋近于 0。



4.  **得出结论**：由于该极限表达式本身（作为绝对值比）始终大于等于 0，同时我们又证明了它的上界趋近于 0，根据夹逼定理，该极限必须等于 0。
    *   这恰好满足了 **αF + βG** 在 **x** 处可微，且其梯度为 **α∇F(x) + β∇G(x)** 的定义。

本节课中我们一起学习了 Fréchet 导数的线性性质。我们通过严格的极限定义和不等式推导，证明了 **∇(αF + βG)(x) = α∇F(x) + β∇G(x)**。这个性质是后续许多微分运算规则的基础，它保证了导数运算可以与线性运算自由交换顺序，极大地简化了复杂函数的求导过程。
