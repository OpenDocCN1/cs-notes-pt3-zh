在本节课中，我们将学习如何运用线性近似与微分来解决优化问题。我们将探讨如何利用微分和线性近似为优化理论奠定基础，并如何基于它们开发优化算法。

![](img/32705b42755083dc6c186975cdead1fa_3.png)

## 概述

![](img/32705b42755083dc6c186975cdead1fa_5.png)

优化是机器学习的关键组成部分之一。机器学习可以表示为：**机器学习 = 表示 + 评估 + 优化**。大多数机器学习任务最终都通过优化来解决。在本节中，我们考虑所谓的**无约束优化**问题，即最小化函数 **F(x)**，其中 **x** 属于希尔伯特空间 **V**。我们将这个问题称为 **OPT** 问题。在这个优化问题中，我们对 **x** 没有任何约束，**x** 可以是 **V** 中的任意向量。

![](img/32705b42755083dc6c186975cdead1fa_7.png)

## 优化问题的解与最优性

![](img/32705b42755083dc6c186975cdead1fa_9.png)

![](img/32705b42755083dc6c186975cdead1fa_11.png)

![](img/32705b42755083dc6c186975cdead1fa_13.png)

首先，我们讨论优化问题 **OPT** 的可解性与最优性。我们将探讨这个问题是否可解，以及如果可解，如何刻画这个最小化问题的解。

![](img/32705b42755083dc6c186975cdead1fa_15.png)

我们定义 **x*** 是此优化问题的一个解，如果 **F(x*)** 在所有向量 **x ∈ V** 中取得最小值。我们希望 **F(x*) ≤ F(x)** 对所有 **x ∈ V** 成立。这个条件被称为**零阶最优性条件**，因为它只涉及函数值，而函数值是零阶导数。

![](img/32705b42755083dc6c186975cdead1fa_17.png)

![](img/32705b42755083dc6c186975cdead1fa_19.png)

这个 **x*** 也被称为**极小值点**或**全局极小值点**。我们称 **x*** 为 **F** 的全局极小值点，记作 **argmin F(x), x ∈ V**。这意味着对于所有 **x ∈ V**，都有 **F(x*) ≤ F(x)**。

![](img/32705b42755083dc6c186975cdead1fa_21.png)

![](img/32705b42755083dc6c186975cdead1fa_23.png)

## 解的存在性

![](img/32705b42755083dc6c186975cdead1fa_25.png)

![](img/32705b42755083dc6c186975cdead1fa_27.png)

尽管我们定义了优化问题的解，但我们并不知道它是否存在。实际上，这个优化问题解的存在性并非自动保证的。

![](img/32705b42755083dc6c186975cdead1fa_29.png)

![](img/32705b42755083dc6c186975cdead1fa_31.png)

以下是几个解可能不存在的例子：

![](img/32705b42755083dc6c186975cdead1fa_33.png)

**示例一：多项式函数**
考虑函数 **F: R → R**，定义为 **F(x) = x(x-1)(x+1)**。这是一个三次多项式。当 **x → -∞** 时，函数值 **F(x) → -∞**。因此，我们无法找到一个 **x*** 使得 **F(x*)** 小于所有其他的 **F(x)**，因为对于任何有限的 **x***，总存在更小的 **x** 使得函数值趋向负无穷。

![](img/32705b42755083dc6c186975cdead1fa_35.png)

**示例二：线性函数**
考虑函数 **F: V → R**，定义为 **F(x) = A·x**，其中 **A** 是 **V** 中的一个非零向量。这是一个线性函数。如果取 **x = cA**，其中 **c** 是实数，则 **F(x) = c||A||²**。当 **c → -∞** 时，**F(x) → -∞**。因此，只要 **A** 是非零向量，这个线性函数就没有极小值点。

![](img/32705b42755083dc6c186975cdead1fa_37.png)

**示例三：有界但无解的函数**
考虑函数 **F: R → R**，定义为 **F(x) = 1/x**，其中 **x > 0**。这个函数的值趋近于0，但永远不会等于0。这意味着对于任何有限的 **x**，函数值都是非零的，我们总能找到一个更大的 **x** 使得 **F(x)** 更接近0（即更小），因此也不存在一个确定的极小值点。

![](img/32705b42755083dc6c186975cdead1fa_39.png)

![](img/32705b42755083dc6c186975cdead1fa_40.png)

![](img/32705b42755083dc6c186975cdead1fa_42.png)

## 总结

![](img/32705b42755083dc6c186975cdead1fa_44.png)

本节课中，我们一起学习了无约束优化问题的基本概念。我们定义了优化问题的解（全局极小值点）和零阶最优性条件。更重要的是，我们通过几个例子认识到，优化问题的解并不总是存在的。函数值可能趋向负无穷，或者虽然函数值有下界但无法达到，都可能导致解不存在。因此，在着手解决一个最小化问题时，第一步通常是检查该问题解的存在性。我们将在后续课程中进一步讨论解的存在性条件。
