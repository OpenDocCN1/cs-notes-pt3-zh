数据分析的数学方法：14-03-02：梯度为零的必要性与非充分性 🔍

![](img/eb546a777fdad0d0d88c3d008a5ff8bd_0.png)

在本节课中，我们将要学习一个关于函数最优化的重要概念：梯度为零是全局最小值的必要条件，但通常不是充分条件。我们将通过直观的例子和严谨的定义来理解这一点。

![](img/eb546a777fdad0d0d88c3d008a5ff8bd_2.png)

![](img/eb546a777fdad0d0d88c3d008a5ff8bd_4.png)

上一节我们介绍了梯度为零是全局最小值的必要条件。本节中我们来看看为什么这个条件通常不是充分的。

我们已证明，若 **x*** 是函数 **f(x)** 的一个全局最小化点，则其梯度必须为零向量，即：
**∇f(x*) = 0**

![](img/eb546a777fdad0d0d88c3d008a5ff8bd_6.png)

然而，这个必要条件通常不是充分的。这意味着其逆命题不成立。

![](img/eb546a777fdad0d0d88c3d008a5ff8bd_8.png)

具体来说，如果 **∇f(x*) = 0**，并不能保证 **x*** 是 **f(x)** 的全局最小化点。这个逆命题在一般情况下不成立。

![](img/eb546a777fdad0d0d88c3d008a5ff8bd_10.png)

以下是一个一维函数 **f: ℝ → ℝ** 的简单例子，用以说明这一点。

![](img/eb546a777fdad0d0d88c3d008a5ff8bd_12.png)

![](img/eb546a777fdad0d0d88c3d008a5ff8bd_6.png)

这是自变量 **x**。该函数的图像如下所示。

![](img/eb546a777fdad0d0d88c3d008a5ff8bd_8.png)

可以看到，有许多点的梯度（即导数）等于零。

![](img/eb546a777fdad0d0d88c3d008a5ff8bd_10.png)

这个点（记为 **x₁**），其线性近似是平坦的，所以导数为零。
这个点（记为 **x₂**）。
以及这个点（记为 **x₃**）。
我们称它们为 **x₁**, **x₂**, **x₃**。

![](img/eb546a777fdad0d0d88c3d008a5ff8bd_14.png)

在这个例子中，所有 **xᵢ** 都满足 **f** 在 **xᵢ** 处的梯度为零，因为其仿射近似是平坦的。

![](img/eb546a777fdad0d0d88c3d008a5ff8bd_16.png)

![](img/eb546a777fdad0d0d88c3d008a5ff8bd_12.png)

![](img/eb546a777fdad0d0d88c3d008a5ff8bd_18.png)

但只有 **x₁** 是全局最小化点，即：
**x₁ = argmin f(x), x ∈ ℝ**

对于 **x₁**，它是全局最小化点。
对于 **x₂**，它只是一个局部最大值点。
对于 **x₃**，它是一个局部最小值点，因为仅在 **x₃** 的邻域内它是最小值，但全局来看 **x₁** 的函数值更小。
对于 **x₄**，它既非最小值也非最大值，我们无法从该点获得关于最小化的信息。
对于 **x₅**，它是一个全局最大值点。

![](img/eb546a777fdad0d0d88c3d008a5ff8bd_20.png)

![](img/eb546a777fdad0d0d88c3d008a5ff8bd_22.png)

因此，从这个简单的例子可以看出，**∇f(x) = 0** 可能对应多种不同的情况。只有 **x₁** 是全局最小化点，其余的点可能是局部最小值点、全局最大值点、局部最大值点，或者无法提供信息。

![](img/eb546a777fdad0d0d88c3d008a5ff8bd_24.png)

所以，一般来说，**∇f(x*) = 0** 并不能保证 **x*** 是全局最小化点。

![](img/eb546a777fdad0d0d88c3d008a5ff8bd_26.png)

![](img/eb546a777fdad0d0d88c3d008a5ff8bd_28.png)

实际上，满足 **∇f(x*) = 0** 的点 **x*** 可能是以下几种情况：

![](img/eb546a777fdad0d0d88c3d008a5ff8bd_30.png)

以下是满足梯度为零的点的所有可能类型：

![](img/eb546a777fdad0d0d88c3d008a5ff8bd_32.png)

*   **全局最小化点**：如例子中的 **x₁**。
*   **局部最小化点**：如例子中的 **x₃**。更精确地说，我们可以找到一个邻域，使得对于所有满足 **||x - x*|| ≤ ε** 的 **x**，都有 **f(x*) ≤ f(x)**。因此，**f(x*)** 仅在 **x*** 的一个小邻域内是最小值。
*   **局部最大化点**：如例子中的 **x₂**。同样，我们可以找到一个邻域，使得对于所有满足 **||x - x*|| ≤ ε** 的 **x**，都有 **f(x*) ≥ f(x)**。在这个小邻域内，**f(x*)** 是最大值。
*   **全局最大化点**：这意味着对于所有 **x**，都有 **f(x*) ≥ f(x)**。
*   **无信息点**：如例子中的 **x₄**。该点的函数值既非局部最小，也非局部最大，其线性近似是平坦的。在这种情况下，我们无法对该点 **x*** 得出任何关于最优化的结论。

此外，在高维空间中，我们还可能遇到**鞍点**。鞍点仅出现在维度大于或等于 2 的空间 **V** 中。在一维函数的情况下，我们无法观察到鞍点。

![](img/eb546a777fdad0d0d88c3d008a5ff8bd_34.png)

鞍点意味着，从一个方向看它是局部最小值点，而从另一个方向看它是局部最大值点。

![](img/eb546a777fdad0d0d88c3d008a5ff8bd_36.png)

![](img/eb546a777fdad0d0d88c3d008a5ff8bd_36.png)

![](img/eb546a777fdad0d0d88c3d008a5ff8bd_37.png)

![](img/eb546a777fdad0d0d88c3d008a5ff8bd_37.png)

![](img/eb546a777fdad0d0d88c3d008a5ff8bd_39.png)

我画一张图来演示。我们有两个方向，**u** 和 **v**。沿着 **u** 方向，函数图像如下所示（呈现局部最大）。而沿着 **v** 方向，它呈现局部最小。

![](img/eb546a777fdad0d0d88c3d008a5ff8bd_39.png)

蓝色曲线是函数图像与 **v** 轴的交线。因此，对于这个点，它在 **u** 方向上是局部最大值点，在 **v** 方向上是局部最小值点。其形状类似马鞍，故称为鞍点。

更精确地说，我们可以找到方向 **u** 和 **v**，使得：
**f(x*) ≥ f(x* + t u)** 且 **f(x*) ≤ f(x* + t v)**，对于所有满足 **|t| ≤ ε** 的 **t** 成立。

由此我们看到，沿着 **u** 方向改变 **x***，**f(x*)** 大于其他函数值，是局部最大；而沿着 **v** 方向改变 **x***，**f(x*)** 是最小值。这种在不同方向上具有相反极值性质的点称为鞍点，它仅出现在高维空间（至少二维）中。

![](img/eb546a777fdad0d0d88c3d008a5ff8bd_41.png)

![](img/eb546a777fdad0d0d88c3d008a5ff8bd_41.png)

本节课中我们一起学习了梯度为零作为最优解条件的局限性。我们明确了梯度为零是全局最小值的必要条件，但远非充分条件。满足该条件的点可能是全局/局部最小点、全局/局部最大点、无信息点，甚至在高维情况下是鞍点。理解这些不同类型的临界点对于后续分析更复杂的优化问题至关重要。
