![](img/6e3b8816783678254e341b20a827f5bb_2.png)

![](img/6e3b8816783678254e341b20a827f5bb_4.png)

在本节课中，我们将要学习如何判断一个点是否为函数的最小值点。之前我们了解到，梯度为零是全局最小化点的必要条件，但并非充分条件。本节我们将引入“凸性”这一函数性质，并探讨在凸函数中，梯度为零如何成为全局最小化点的充分条件。

## 凸函数的定义 📐

![](img/6e3b8816783678254e341b20a827f5bb_6.png)

![](img/6e3b8816783678254e341b20a827f5bb_7.png)

上一节我们介绍了梯度为零的必要性，本节中我们来看看如何通过函数的性质来保证这个条件也是充分的。这个关键性质就是凸性。

一个从希尔伯特空间映射到实数域的函数 **F**，被称为**凸函数**，如果对于定义域内的任意两点 **x** 和 **y**，以及任意属于区间 **[0, 1]** 的标量 **α**，都满足以下不等式：

**F(αx + (1-α)y) ≤ αF(x) + (1-α)F(y)**

![](img/6e3b8816783678254e341b20a827f5bb_9.png)

我们可以发现，这个定义与线性函数的定义非常相似，但存在两个主要区别。

以下是凸函数与线性函数定义的核心差异：

![](img/6e3b8816783678254e341b20a827f5bb_11.png)

1.  **不等式 vs. 等式**：线性函数要求等式成立，而凸函数只要求不等式成立。这种“小于等于”的关系被称为**次线性**。
2.  **权重限制**：在线性函数中，组合系数 **α** 和 **β** 可以是任意实数。而在凸函数中，**α** 被限制在 0 到 1 之间，且 **β = 1 - α**，这保证了组合点是 **x** 和 **y** 之间的一个**凸组合**。

![](img/6e3b8816783678254e341b20a827f5bb_13.png)

因此，凸性可以看作是一种带有权重限制的次线性性质。

## 凸函数的几何意义 📈

![](img/6e3b8816783678254e341b20a827f5bb_15.png)

从几何角度来看，凸函数的定义意味着什么？

![](img/6e3b8816783678254e341b20a827f5bb_17.png)

![](img/6e3b8816783678254e341b20a827f5bb_18.png)

考虑一个典型的凸函数，例如二次函数 **F(x) = x²**。在函数图像上取两点：**(x, F(x))** 和 **(y, F(y))**。连接这两点的线段称为**弦**。

![](img/6e3b8816783678254e341b20a827f5bb_20.png)

![](img/6e3b8816783678254e341b20a827f5bb_22.png)

根据凸函数的定义，对于 **x** 和 **y** 之间的任意点 **z = αx + (1-α)y**，函数值 **F(z)** 必须小于或等于弦在该点的高度 **αF(x) + (1-α)F(y)**。

以下是凸函数的几何解释：

*   对于凸函数，其图像上任意两点连成的**弦**，总是位于这两点之间的函数图像**之上**（或恰好重合）。
*   反之，如果一个函数图像上存在两点，使得连接它们的弦有一部分位于函数图像**之下**，那么这个函数就是**非凸**的。

例如，一个“U形”的抛物线是凸的，因为任何弦都在曲线上方。而一个“波浪形”或存在“凹陷”的函数（例如 **F(x) = sin(x)** 在某些区间）则是非凸的，因为你可以找到一条弦穿过函数的“山谷”，从而位于图像下方。

## 凸函数与最优化 🎯

![](img/6e3b8816783678254e341b20a827f5bb_24.png)

![](img/6e3b8816783678254e341b20a827f5bb_26.png)

现在，我们回到最优化问题。凸函数有一个极其重要的性质，这使得它在数据分析的数学方法中占据核心地位。

对于一个**凸函数 F**，如果在其定义域内某点 **x*** 处梯度为零，即：

![](img/6e3b8816783678254e341b20a827f5bb_28.png)

**∇F(x\*) = 0**

![](img/6e3b8816783678254e341b20a827f5bb_30.png)

![](img/6e3b8816783678254e341b20a827f5bb_32.png)

那么这个点 **x*** 不仅是局部最小化点，而且一定是**全局最小化点**。

![](img/6e3b8816783678254e341b20a827f5bb_34.png)

这是因为凸函数的形状决定了它只有一个“低谷”。梯度为零的点就是这个低谷的最低点，不存在其他位置比它更低。因此，在凸优化问题中，找到梯度为零的点就等价于找到了全局最优解。

![](img/6e3b8816783678254e341b20a827f5bb_36.png)

本节课中我们一起学习了凸函数的定义、几何意义及其在最优化中的关键作用。我们了解到，凸函数具有“弦在图像之上”的几何特性。最重要的是，对于凸函数而言，梯度为零 **∇F(x\*) = 0** 是 **x*** 成为全局最小化点的**充分条件**。这为解决许多数据分析中的优化问题提供了坚实的理论基础和实用的判断准则。
