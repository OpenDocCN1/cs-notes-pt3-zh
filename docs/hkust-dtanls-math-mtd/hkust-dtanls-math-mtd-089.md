数据分析的数学方法：15-03-02：线性算子的范数及其性质 🔢

在本节课中，我们将学习线性算子范数的定义及其两个关键性质：与向量乘积的相容性，以及两个算子乘积的范数不等式。

---

![](img/547906503425ebab42a1319654e31eb0_1.png)

由于其特殊的定义和结构，这种范数不仅是一个范数，它还具有一些额外的性质。除了满足范数的三个基本公理外，它还满足第四条性质：对于任意向量 **x**，有 **\|A x\|_{V2} ≤ \|A\| \|x\|_{V1}**。这意味着算子与向量乘积的范数，小于等于算子范数与向量范数的乘积。

上一节我们介绍了算子范数的定义，本节中我们来看看如何证明这个性质。

**证明过程如下：**

1.  如果 **x = 0**，那么 **\|A x\|_{V2} = 0**。因为零向量的范数为0，所以 `0 ≤ \|A\| * 0` 成立。
2.  如果 **x ≠ 0**，我们可以将其单位化。令 **z = x / \|x\|_{V1}**，则 **\|z\|_{V1} = 1**。
3.  根据算子范数的定义，**\|A\|** 是所有单位向量 **z** 中 **\|A z\|_{V2}** 的上确界。因此，对于这个特定的 **z**，有 **\|A\| ≥ \|A z\|_{V2}**。
4.  将 **z** 的表达式代入，得到 **\|A\| ≥ \|A (x / \|x\|_{V1})\|_{V2}**。
5.  利用范数的齐次性，可以将常数提出：**\|A\| ≥ (1 / \|x\|_{V1}) \|A x\|_{V2}**。
6.  整理不等式，最终得到 **\|A x\|_{V2} ≤ \|A\| \|x\|_{V1}**。

![](img/547906503425ebab42a1319654e31eb0_3.png)

这个性质体现了线性算子作用的一致性。

![](img/547906503425ebab42a1319654e31eb0_5.png)

---

现在，我们考虑两个线性算子的复合。设有算子 **A: V2 → V3** 和 **B: V1 → V2**。它们的复合 **AB** 定义为从 **V1** 到 **V3** 的线性算子，作用方式为 **(AB)(x) = A(B(x))**。这也就是两个线性算子的乘积定义。

![](img/547906503425ebab42a1319654e31eb0_7.png)

![](img/547906503425ebab42a1319654e31eb0_9.png)

接下来，我们可以证明算子乘积的范数满足不等式：**\|AB\| ≤ \|A\| \|B\|**。

![](img/547906503425ebab42a1319654e31eb0_11.png)

![](img/547906503425ebab42a1319654e31eb0_13.png)

**证明步骤如下：**

![](img/547906503425ebab42a1319654e31eb0_15.png)

1.  对于任意满足 **\|x\|_{V1} = 1** 的向量 **x**，考虑 **\|A B x\|_{V3}**。
2.  将 **Bx** 视为 **V2** 中的一个向量，根据上一条性质（性质4），有 **\|A (Bx)\|_{V3} ≤ \|A\| \|Bx\|_{V2}**。
3.  因此，**\|A B x\|_{V3} ≤ \|A\| \|Bx\|_{V2}**。
4.  现在，对左边取上确界：**sup_{\|x\|=1} \|A B x\|_{V3} ≤ sup_{\|x\|=1} (\|A\| \|Bx\|_{V2})**。
5.  由于 **\|A\|** 是常数，可以提到上确界外面：**≤ \|A\| * sup_{\|x\|=1} \|Bx\|_{V2}**。
6.  根据定义，**sup_{\|x\|=1} \|Bx\|_{V2}** 正是算子 **B** 的范数 **\|B\|**。
7.  所以，**\|AB\| ≤ \|A\| \|B\|**。

![](img/547906503425ebab42a1319654e31eb0_17.png)

这个不等式与向量乘积的性质非常相似，但这里处理的是两个算子的乘积。这两个不等式在许多算法的理论分析中非常有用。

![](img/547906503425ebab42a1319654e31eb0_19.png)

对于线性算子集合，我们可以定义加法和数乘，从而赋予其线性结构。在此基础上，我们可以定义其上的范数，即单位球像集的最大范数。

![](img/547906503425ebab42a1319654e31eb0_28.png)

![](img/547906503425ebab42a1319654e31eb0_29.png)

![](img/547906503425ebab42a1319654e31eb0_30.png)

这种算子范数不仅是一个范数，还满足与向量乘积的相容性，以及两个算子乘积的范数不等式。

---

**示例**

![](img/547906503425ebab42a1319654e31eb0_32.png)

![](img/547906503425ebab42a1319654e31eb0_34.png)

以下是几个具体的例子：

*   **矩阵的2-范数**：对于矩阵 **A ∈ R^{m×n}**，将其视为从 **R^n** 到 **R^m** 的线性变换，并分别在定义域和值域上使用向量2-范数。其算子2-范数定义为：
    ```
    \|A\|_2 = max_{\|x\|_2=1} \|A x\|_2
    ```
    它满足 **\|A x\|_2 ≤ \|A\|_2 \|x\|_2** 以及 **\|AB\|_2 ≤ \|A\|_2 \|B\|_2**。

*   **矩阵的1-范数与∞-范数**：类似地，可以定义矩阵的1-范数和无穷范数作为算子范数，它们同样满足上述两个性质。

![](img/547906503425ebab42a1319654e31eb0_36.png)

![](img/547906503425ebab42a1319654e31eb0_38.png)

*   **矩阵的Frobenius范数**：定义为矩阵所有元素平方和的平方根，即 **\|A\|_F = sqrt(Σ_{i,j} a_{ij}^2)**。需要注意的是，Frobenius范数**不是**一个算子范数，它不满足算子范数定义中的上确界形式。

![](img/547906503425ebab42a1319654e31eb0_40.png)

![](img/547906503425ebab42a1319654e31eb0_42.png)
