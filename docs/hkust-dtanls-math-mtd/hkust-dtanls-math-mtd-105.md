## 引入新符号

为了简化梯度表达式，我们首先定义两个关键变量：**预激活输出** 和 **反向传播向量**。

![](img/60a74d1bcaf653d50e77d1c53c377f05_10.png)

*   **预激活输出**：记作 **P_L**。它表示第 L 层在应用激活函数 **σ** 之前的输出。
    *   公式：`P_L = W_L * V_(L-1)`
    *   激活后的输出为：`V_L = σ(P_L)`
*   **反向传播向量**：记作 **Z_L**。它是一个关键的中间变量，用于递归地计算梯度。

![](img/60a74d1bcaf653d50e77d1c53c377f05_12.png)

![](img/60a74d1bcaf653d50e77d1c53c377f05_14.png)

## 简化梯度递归关系

![](img/60a74d1bcaf653d50e77d1c53c377f05_16.png)

![](img/60a74d1bcaf653d50e77d1c53c377f05_18.png)

根据多层神经网络的结构，我们可以推导出 **Z_L** 的递归关系。

![](img/60a74d1bcaf653d50e77d1c53c377f05_20.png)

![](img/60a74d1bcaf653d50e77d1c53c377f05_22.png)

以下是 **Z_L** 的递归定义：
```
Z_L = σ'(P_L) ⊙ (W_(L+1)^T * Z_(L+1))
```
其中，符号 **⊙** 表示向量的逐元素乘法（哈达玛积）。

![](img/60a74d1bcaf653d50e77d1c53c377f05_24.png)

这个递归关系非常重要。它意味着第 L 层的 **Z_L** 可以通过第 L+1 层的 **Z_(L+1)** 计算得到。我们可以从最后一层开始，逐层向前（反向）计算。

## 反向传播算法流程

![](img/60a74d1bcaf653d50e77d1c53c377f05_26.png)

基于上述递归关系，我们可以将梯度计算分解为两个清晰的步骤：**前向传播** 和 **反向传播**。

以下是完整的算法步骤：

1.  **前向传播**：从输入层开始，逐层计算每一层的输出和预激活输出。
    *   输入：`V_0 = X` (输入数据)
    *   对于每一层 `L = 1` 到 `L_total`：
        *   计算预激活：`P_L = W_L * V_(L-1)`
        *   计算激活后输出：`V_L = σ(P_L)`
    *   最终得到网络输出：`A = U^T * V_(L_total)`

![](img/60a74d1bcaf653d50e77d1c53c377f05_28.png)

![](img/60a74d1bcaf653d50e77d1c53c377f05_30.png)

![](img/60a74d1bcaf653d50e77d1c53c377f05_31.png)

2.  **计算最终误差**：
    *   计算残差：`δ = 2 * (A - Y)`，其中 Y 是真实标签。

3.  **反向传播**：从最后一层开始，反向计算每一层权重的梯度。
    *   计算最后一层的 **Z**：`Z_(L_total) = σ'(P_(L_total)) ⊙ U`
    *   计算最后一层权重 `W_(L_total)` 的梯度：
        *   `∇F_W_(L_total) = δ * Z_(L_total) * V_(L_total-1)^T`
    *   对于层 `L = L_total-1` 递减到 `1`：
        *   递归计算 **Z_L**：`Z_L = σ'(P_L) ⊙ (W_(L+1)^T * Z_(L+1))`
        *   计算该层权重 `W_L` 的梯度：
            *   `∇F_W_L = δ * Z_L * V_(L-1)^T`

![](img/60a74d1bcaf653d50e77d1c53c377f05_33.png)

![](img/60a74d1bcaf653d50e77d1c53c377f05_35.png)

## 算法核心：前向与反向

![](img/60a74d1bcaf653d50e77d1c53c377f05_37.png)

这个流程清晰地分为两部分：
*   **前向传播**：从输入到输出，计算并保存每一层的 `P_L` 和 `V_L`。
*   **反向传播**：从输出误差开始，利用链式法则和保存的中间结果，反向计算每一层参数的梯度。

![](img/60a74d1bcaf653d50e77d1c53c377f05_39.png)

这种高效计算神经网络梯度的方法，就被称为 **反向传播算法**。
