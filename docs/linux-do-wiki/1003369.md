# Astro Refined主题发布啦！



本主题由[hexo-theme-concise](https://github.com/sanonz/hexo-theme-concise)迁移而来，保留其UI理念核心但是进行了完全重构，可以兼容2022年往后的主流浏览器，并保持原有项目的MIT协议
