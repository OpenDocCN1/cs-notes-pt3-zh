# L站话题详解



常规话题:



**请优先考虑搞七捻三是不是更加合适（水帖的话）**



wiki: 有一些指南，包括和本站相关的说明可以去看



快问快答:仅限**技术相关**的问题询问



人工智能: 讨论人工智能，如果是**怎么C号**，那请**不要**发到这里来



周周热点: 等待该版主总结一周的高质量热点帖子



精华神贴&高阶秘辛: 本来应该存放加精华的内容，但是现在感觉没什么特别的，更多的是**限制一级和二级权限**的作用

读书成诗: 无子版块，**仅限**读书笔记

配置调优:考虑参数和系统、软件优化

网络安全:网络安全、服务器攻防、服务器被黑求助等

软件分享: 好用的软件，或者网页（PWA怎么不是应用）分享

软件开发 : 下属嵌入式和机器学习，前者是嵌入式硬件，如树莓派、单片机等；后者开发大模型的交流，其他常规开发放在主板块下

代码审查: 仅限 new-api的合并代码审查

一机难求：一机难求和速来拼车板块，相当于是交易服务器、vps的区域；素来拼车相当于合租

非我莫属: 仅招聘和求职

赏金猎人:悬赏任务

搞七捻三: 水区



碎碎念:始皇的博客（micro）版本



金融经济:基金 股票之类的话题



新闻 ： 最近的新消息



旅行：世界这么大，可以去看看



美食：厨娘在这里发美食，老饕可以晒图



健身:健身经验还有八块腹肌



音乐: 音乐交流，挂出歌单，以及分享音乐



游戏: 3A可以，独立游戏也可以，可以找人联机，也可以推荐小众游戏，还有游戏资源什么的



羊毛: 我的区，主要是分享怎样买东西便宜（低价的订阅等），以及赚到一些福利（web3空投等），可以分享同时赚返利，但是需要表明含返利行为（aff），禁止为了拉人头而拉人头（比如刚注册就发返利，还是首帖这种）



树洞: 情感上，需要帮助， 抑郁等发在这里，佬友会尽可能安慰你的



深海: 不可视，不可听，不可知，不上信息流，不能搜索，想藏起来的内容



病友： 唯一合理发癫指定区，kfc等只能发这里



职场： 职场吐槽，薪资待遇，等等



断舍离 ： 你们找不到的出闲置二手区，建议都走平台担保（某鱼之类的）



二次元: 为了热爱，cos， asmr， galgame，轻小说，番剧，漫画 等等



老干部养老院： 三级可见，有福利！ 快快升级

运营反馈:给本站的建议，错误回报等



活动:站务组发起的活动，参加可以发到这里

网络记忆:锁区板块
