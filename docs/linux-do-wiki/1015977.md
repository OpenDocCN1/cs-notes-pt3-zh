# OBS的安装和设置
## 安装必要的组件
我害怕系统环境被搞乱，所以自然还是喜欢flatpak。 ![:laughing:](https://cdn.ldstatic.com/images/emoji/twemoji/laughing.png?v=15)
```
flatpak install com.obsproject.Studio com.obsproject.Studio.Plugin.OBSVkCapture com.obsproject.Studio.Plugin.BackgroundRemoval com.obsproject.Studio.Plugin.InputOverlay org.freedesktop.Platform.VulkanLayer.OBSVkCapture org.freedesktop.Platform.VulkanLayer.MangoHud
```
宿主机也需要安装一些工具，不然只能捕抓flatpak容器里面的游戏。
用您的任何包管理器安装mangohud，这个软件官方源就有，可以用于检查游戏的VulkanLayer注入状态和游戏帧率，由于这些捕抓工具都是基于VulkanLayer的，排除故障的时候很有用。

**它默认就会显示HUD帧率窗口，安装goverlay工具可以让它默认隐藏。默认情况下按下F12+右Shift可以开启/关闭显示HUD帧率窗口。**
构建并且安装obs-capture
### [GitHub - nowrep/obs-vkcapture: OBS Linux Vulkan/OpenGL game capture](https://github.com/nowrep/obs-vkcapture)
OBS Linux Vulkan/OpenGL game capture
```
git clone https://github.com/nowrep/obs-vkcapture
cd obs-vkcapture
mkdir build && cd build
cmake -DCMAKE_INSTALL_PREFIX=/usr -DCMAKE_BUILD_TYPE=Release ..
make && make install
```
## 环境变量
我图方便省事，直接编辑 `/etc/environment`，添加如下的内容。为全部的应用程序注入捕获工具，这样我就不用每次都用脚本或者命令启动游戏了。
**注意：这是不安全的，为全部应用注入捕获插件意味着比如浏览器密码管理器等使用硬件加速的程序都会被注入捕抓工具（不过其实X11下无所谓的反正录屏不需要任何权限），我这只是图方便，如果为了绝对的安全，应当只为了特定的游戏设置环境变量。**
```
# MANGOHUD=1 # 按需要打开mangohud
OBS_VKCAPTURE=1
```
打开flatseal，为**全部应用程序**添加和前文一样的环境变量，注意变量后面存在空格是不生效的，务必检查变量前后是否存在空格。

## Flatpak/Minecraft/OpenGL
Flatpak就稍微麻烦一点了，因为启动命令不好改写。

我以prismlauncher作为例子。

首先进入prismlauncher的容器环境，检查它的启动命令是什么。
```
flatpak run --command=bash org.prismlauncher.PrismLauncher
```
检查/app/bin/目录，一般程序的启动位置都是这里。
```
[📦 org.prismlauncher.PrismLauncher ~]$ ls /app/bin/prismlauncher
/app/bin/prismlauncher
[📦 org.prismlauncher.PrismLauncher ~]$
```
创建一个目录，并且编写启动脚本：
```
mkdir .mcje
vim .mcje/start.sh
chmod 777 .mcje/start.sh
```
start.sh:
```
#!/bin/bash
/lib/extensions/vulkan/OBSVkCapture/bin/obs-gamecapture /app/bin/prismlauncher
```
打开flatseal，把脚本路径挂载进去。
