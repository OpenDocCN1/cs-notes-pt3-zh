# 向着更舒适的开发环境迈进——配置字体

## 1. 挑选适合自己的字体文件
这里给大家推荐几款楼主自己使用比较多的两款字体
- [Google Sans Code](https://fonts.google.com/specimen/Google+Sans+Code)（看起来很舒服，但不支持中文。

[Google Sans Code1541×785 79.3 KB](https://cdn3.ldstatic.com/original/4X/0/b/f/0bf6eff7ed82759cc70cb534256d02f60b505980.png)
- [Maple Mono](https://font.subf.dev/zh-cn/)（一款开源等宽字体，专注于优化编码体验。它提供了好几个版本可供选择。楼主使用的是`Maple Mono Normal NL NF CN` 对中文也有较好适配。通过修改配置文件还可以自定义一些样式。

[Maple Mono710×795 27.7 KB](https://cdn3.ldstatic.com/original/4X/d/9/b/d9ba86dd7ab5a351600418f198848f6c2b2d69da.png)
## 2. 在系统上安装字体文件
### 2.1 以Windows11系统为例
- 安装之前肯定要先下载好字体文件(
- `Win + i`打开Windows设置
- 依次点击`个性化`、`字体`
- 把下载好的字体文件拖入即可在设备上安装字体
- 删除记得也在这里哦！！！直接删除字体文件不可取
## 3. 配置字体
### 3.1 配置Vscode
- `ctrl + ,`打开设置
- 依次选择`文本编辑器`、`字体`(或者搜索 Font Family)
- 在`Font Family`部分可以修改字体，把刚安装的字体加上就好。

[字体设置656×210 5.8 KB](https://cdn3.ldstatic.com/original/4X/5/3/9/53967dbff723f0e75eb27b67f790ebb0eda573cb.png)
### 3.2 配置本地终端
- `win + s`打开搜索框，输入 `powershell`，打开`Windows PowerShell`。
- 在终端框顶部右键，点击`设置`
- 选择左侧的`Windows PowerShell`或`命令提示符`进行配置

[image1469×831 64.4 KB](https://cdn3.ldstatic.com/original/4X/6/a/5/6a55e8b376f07b0a6022cc0c922a1058ce43c0ea.png)
- 比如点击`Windows PowerShell`后，再点击`外观`，在字体部分可以选择刚刚安装的字体。
