# HTMLy CMS的迁移体验？无数据库、轻量、极简的博客平台？

Halo对我的博客来说还是太重了。慢，太慢了。进管理员面板得5秒起步，而且部分vip功能搁哪横着实在是看着隔应。
尝试寻找替代品，遂找到了一款相当简单的博客系统：HTMLy。
这玩意基于PHP。无需任何数据库即可部署，备份的话只需要给网站目录打个包就能跑。对我这种懒家伙而言实在是方便。而且这玩意是真正的FOSS，没有恶心的VIP限定功能，或者各种奇怪的许可证限制。

# 1、安装
详细安装请参考：[Installations - HTMLy Docs](https://docs.htmly.com/basic/installations)
---
## 1.1 配置环境和容器
HTMLy并不像Halo那样，在1panel里开箱即用。我们得手动给它整理好可供使用的PHP环境。
HTMLy对PHP的版本和插件有所要求。你需要确保启用了以下扩展：
```
xml,zip,intl,mbstring,gd
```
1panel默认没有HTMLy的PHP扩展模板预设。我们可以在`运行环境 > PHP > 扩展模板`里，手动添加扩展模板：
[图片512×368 15.3 KB](https://cdn3.ldstatic.com/original/4X/2/7/2/272a1c74ce66bb742d2117acd70d80fac5a5f3a9.png)
> 实际上，默认的 Default 扩展模板似乎已经足够。如果你不嫌默认的模板编译慢，你可以省略该步骤，扩展模板里直接选择Default即可。

## 1.2 修改配置
务必手动配置OpenResty的该网站的配置！
务必在网站设置里添加该动态路由fallback规则段。否则，访问很多子路径时会遇到404错误。
```
location / {
    try_files $uri $uri/ /index.php?query_string;
}
```
[图片1388×752 109 KB](https://cdn3.ldstatic.com/original/4X/5/b/1/5b11abb2c62fa083c88f396e3645556a225c3771.png)

## 1.3 安装HTMLy
HTMLy支持在线安装或者离线安装。我推荐使用在线安装方式（如果你的VPS位于国外）。
从github下载安装用PHP文件：[Release HTMLy v3.1.1 · danpros/htmly · GitHub](https://github.com/danpros/htmly/releases/latest)
把该php移动到网站根目录。访问域名名称 [https://example.com/online-installer.php](https://example.com/online-installer.php)
即可进入安装面板。

只需要确保用户名和密码配置好了即可。不需要配置其他东西。其他东西稍后可以在设置界面里设置。
> 注意：倘若点击安装后，你进入了某个404界面，那说明你没有修改该网站的配置文件。请重新阅读 `1.2` 部分。
完毕后，倘若一切无误，即可进入HTMLy的控制面板了。
> 安装完毕后默认为英文，你可以手动修改为简体中文，以及手动配置时区。
