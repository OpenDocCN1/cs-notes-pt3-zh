# 分享一个高速同步QQ/Tim/微信聊天记录的办法

分享一个高速同步QQ/Tim/微信聊天记录的办法，一台设备开热点，另一台设备（有聊天记录那台）连热点，大概速率能跑到60MB/s以上，上限可以大约90MB/s，wifi-5G Hz的同步速率大概是20MB/s左右。
![:warning:](https://linux.do/images/emoji/twemoji/warning.png?v=15)这个方法是不消耗任何流量的，走局域网，同时最好关闭开热点手机的wifi，因为如果开了wifi，两个手机共享的就是由路由器组建的局域网，而不是手机组建的局域网。
