# 主观客观？主体客体？



一直爱幻想，大概源于小时候对没有得到的、认知不全的事物的各种想象。长久以来，脑海中总是不断地思考，从现实中看到的事物想象它的用途、制造背景，从看到的人物想象他的经历、后续发展，等等。

于是世界观就由这些真实世界的碎片加上想象的胶水粘合而成，从而变成了一个按照“想当然”去行动的人。常常以偏概全，认为事情是绝对的，因为已经“思考”过了，事情就应该是按照这个样子发展。



印象很深的有两件事。

第一件事是拿到一副三国杀卡牌。大家当时都在研究「无懈可击」的效果，便直接把

> “抵消任意锦囊（生效时）将对任意一名玩家造成的影響”

理解成了

> “抵消任意效果并对一名玩家造成伤害”。

于是，无懈可击就变成了上帝卡牌，可以抵消杀、闪、桃等任何卡牌——除了另一张无懈可击。

这是多年后再次接触三国杀才回想起的。下面这件事则是当场意识到的，因为冲击来得非常及时：

当时正在学习一项技术，负责人请了一位专家来指导，每个人都可以提问。由于基础很差，思路也不清晰，大概是想问关于学习方法论和系统性学习路线的问题，结果脱口而出：

> “你是怎么知道有那么多知识的？”

那专家大怒，吼道：

> “我比你早生不知道多少年了！”

他这一吼像把眼前的雾一下子吹散了，突然被真实了一下。负责人过来找补，还愣在那里。

一直活在想象与现实的交汇处，犹如雾里看花。这影响到了性格——因为看到关于内向、自卑的人的特征描写，经过脑海中严谨的“思考”与“推理”后，便将这些标签贴到自己身上，自顾扮演起一个内向自卑的人。

可以看到，在对现实与幻想的选择时，更愿意相信脑子里的世界。在轻而易举可以验证的事实面前，放弃思考。这是在自己世界里无所不能的幻想投射到现实的结果。即使被问到贴有标签的树叫什么的时候，也要假装专家猜测的冒名顶替综合征。

直到我不知道从哪里看到这么一句话：

> [!note]

>

> “大脑只是你头上的一个器官而已，并不是你。观察大脑在思考什么，而不是顺着念头走。”

好像突然被植入的认知。一个补丁？一个break？把我从思 考>思考>执行>思考 的循环里跳出。

这种难以言表的感觉，像是看了很多年窗外的那棵树，它就长在那里，树枝飘动。
