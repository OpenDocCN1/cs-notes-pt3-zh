# DataGrip 完整迁移新机器教程



## 背景

DataGrip 作为 JetBrains 全家桶中的数据库管理利器，在日常开发中积累了大量数据库连接配置。

**正所谓全家桶一时爽，换机器火葬场 **

换机时面临的核心痛点：**数十个连接配置无法批量导出，且密码已加密存储无法直接查看**。

逐个重新配置，效率极低且容易出错，下面梳理了（我已经验证走通了这个流程）网上的迁移教程给大家参考，帮助大家实现配置、连接、Console 历史的**完全无损迁移**。

---

## 解决方案

### 第一步：配置密码管理器

[image295×351 9.17 KB](https://cdn3.ldstatic.com/original/4X/c/4/f/c4f33fec9d9240cd0f02f424d3ec0eade0c12bbd.png)

[image1398×401 33.3 KB](https://cdn3.ldstatic.com/original/4X/2/9/4/2941371c2eea0701cc89cedbccf21a6a72a40145.png)

**操作路径：** Settings → 搜索 `password` → Passwords

**关键配置：**

- 勾选 `In KeePass`（DataGrip 内置的密码管理方案）

- 记录 Database 路径，通常为：`C:\Users\<用户名>\AppData\Roaming\JetBrains\DataGrip<版本>\c.kdbx`

- 点击 Database 右侧齿轮图标，选择 `Set Master Password`

- **务必妥善保管此 Master Password**，它是解密所有数据库连接密码的唯一凭证

> **提示：** 如果已设置过 Master Password，直接使用原密码即可，无需重复设置。

---

### 第二步：打包迁移核心目录

需要迁移两个关键目录：

**① 项目目录**

```
C:\Users\<用户名>\DataGripProjects
```

包含所有项目文件、SQL 脚本、Console 历史等用户数据。

**② 配置目录**

```
C:\Users\<用户名>\AppData\Roaming\JetBrains\DataGrip<版本>
```

包含数据库连接配置、密码库、IDE 设置等核心配置文件。

**迁移步骤：**

1. 将上述两个目录分别打包压缩

2. 传输至新机器

3. 解压至新机器的**对应路径**（保持目录结构一致）

4. 遇到文件冲突时，选择**全部覆盖**

> **注意：** `<版本>` 为具体版本号，如 `DataGrip2025.2`。

---

### 第三步：导入配置并激活

在新机器上启动 DataGrip，执行以下操作：

1. **定位密码管理器配置**

Settings → 搜索 `password` → 勾选 `In KeePass`

2. **指定密码库文件**

Database 路径选择刚才解压的 `c.kdbx` 文件

3. **输入 Master Password**

系统弹窗时输入第一步设置的主密码

完成后，DataGrip 会自动加载所有配置。无需任何额外操作。

## 补充说明

**Q: 忘记 Master Password 怎么办？**

A: 无解。这是 KeePass 的安全机制。只能一个一个重新添加数据库连接了。

**Q: 新旧机器 DataGrip 版本不一致会怎样？**

A: 个人建议先在旧电脑升级至新电脑相同的版本，保证两边配置结构完全一致，尽可能避免兼容问题产生。
