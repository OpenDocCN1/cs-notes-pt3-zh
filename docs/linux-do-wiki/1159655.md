# EasyTier搭配内网穿透frp

## 前因后果

因为国外服务器延迟高，串流游戏不方便；国内服务器带宽贵，串流游戏玩不起。因此想着用内网穿透开一个公网端口……

## 准备

任意内网穿透服务，只需要一个端口即可，此处以公网`1.1.1.1:12345`举例。

**注意**：内网穿透的本地`<IP:PORT>`务必注意不要用`127.0.0.1`、`localhost`，可以使用网卡绑定的其他内网地址，例如`192.168.1.23`。否则会报错回环地址什么的，端口用EasyTier监听的端口即可，默认是`11010`。

那么最终就是：

```
1.1.1.1:12345 -> 192.168.1.23:11010
```

## 操作步骤

### EasyTier CLI

**推荐方法**：本地开启内网穿透后，什么都不用改，其他设备要连到此设备，增加一个共享节点配置即可`-p "tcp://1.1.1.1:12345"`。

此外还发现一个参数可以在本地设置：`--mapped-listeners tcp://1.1.1.1:12345`，此时其他设备不需要新增共享节点配置，似乎会自动识别到该公网地址，不过未经严格认证，暂且蒙在鼓里。

### EasyTier 图形客户端

本地开启内网穿透后，软件里：**网络方式**——**独立**，然后同样操作，其他设备要连到此设备，增加一个共享节点配置即可`tcp://1.1.1.1:12345`。

此外也发现一个配置：**高级设置**——**监听映射**，和`--mapped-listeners`似乎是同一个功能，但是这个没连成功，不知道是不是配置问题。
