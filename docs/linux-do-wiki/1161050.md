# frp内网穿透配置

# `frp`是什么？ 能干什么
[frp](https://github.com/fatedier/frp)是一款开源的内网穿透工具。它可以用于远程内网服务。对于我来说最常用的就是可以在家远程访问公司内网的服务器（通过`frp`转发`ssh`)
frp分为客户端和服务端。
# FRPC 配置指南
---
## 1. 下载 FRP
获取最新版本（示例：0.64.0）：
```
wget https://github.com/fatedier/frp/releases/download/v0.64.0/frp_0.64.0_linux_amd64.tar.gz
```
---
## 2. 解压文件
```
tar -zxvf frp_0.64.0_linux_amd64.tar.gz
cd frp_0.64.0_linux_amd64
```
解压后目录包含：
- `frpc` → 客户端可执行文件
- `frpc.toml` → 客户端配置文件示例
- `frps`、`frps.toml` → 服务端可执行文件和示例配置
---
## 3. 编辑配置文件
```
vim frpc.toml
```
示例配置：
```
serverAddr = "<服务器公网IP>"
serverPort = 7000
[auth]
method = "token"
token = "vZCYLkUUwzL3CpCwZ6Qc"

[[proxies]]
name = "ssh"
type = "tcp"
localIP = "127.0.0.1"
localPort = 22
remotePort = 6000
```
说明：
- `name`→ FRP 服务的唯一标识，不能重复。
- `serverAddr` → FRP 服务端公网 IP
- `serverPort` → FRP 服务端监听端口（默认 7000）
- `proxies` → 配置转发规则，例如将本地 SSH 服务映射到服务端的 6000 端口
- `auth` 我们指定认证的方式通过 `token`。`auth.token`此处密码仅为实例，建议使用强密码
---
## 4. 开放本地端口
通常客户端无需开放公网端口，但需确保本地服务（如 SSH 的 22 端口）可被 frpc 访问。如果有本地防火墙，执行：
```
sudo ufw allow 22/tcp
```
---
## 5. 启动客户端（临时测试）
```
./frpc -c ./frpc.toml
```
启动成功后，可通过服务端公网 IP 和映射端口访问本地服务，例如：
```
ssh user@<服务器公网IP> -p 6000
```
---
## 6. 配置为系统服务（可选，规范化）
### 6.1 移动文件到规范目录
```
sudo mkdir -p /etc/frp
sudo mv frp_0.64.0_linux_amd64/frpc.toml /etc/frp
sudo mv frp_0.64.0_linux_amd64/frpc /usr/local/bin
```
---
### 6.2 创建 systemd 服务文件
```
sudo vim /etc/systemd/system/frpc.service
```
内容如下：
```
[Unit]
Description=FRP Client
After=network.target

[Service]
Type=simple
ExecStart=/usr/local/bin/frpc -c /etc/frp/frpc.toml
Restart=on-failure
RestartSec=5s
User=root
WorkingDirectory=/etc/frp

[Install]
WantedBy=multi-user.target
```
---
### 6.3 启用并启动服务
```
sudo systemctl daemon-reload
sudo systemctl enable frpc
sudo systemctl start frpc
```
查看状态：
```
sudo systemctl status frpc
```
示例输出：

# FRPS 配置指南
---
## 1. 下载 FRP
获取最新版本（示例：0.64.0）：
```
wget https://github.com/fatedier/frp/releases/download/v0.64.0/frp_0.64.0_linux_amd64.tar.gz
```
---
## 2. 解压文件
```
tar -zxvf frp_0.64.0_linux_amd64.tar.gz
cd frp_0.64.0_linux_amd64
```
解压后目录包含：
- `frps` → 服务端可执行文件
- `frps.toml` → 服务端配置文件示例
- `frpc`、`frpc.ini` → 客户端可执行文件和示例配置
---
## 3. 编辑配置文件
```
vim frps.toml
```
示例配置：
```
bindPort = 7000

auth.method = "token"
auth.token = "xxxx"
# Dashboard (可选)
webServer.addr = "0.0.0.0"
webServer.port = 7500
webServer.user = "admin"
webServer.password = "admin"
```
说明：
- `bindPort` → frpc 连接 frps 的端口
- `webServer.*` → Web 面板相关，可选
- `auth.token` 应与`client`中配置的相同
---
## 4. 开放端口
确保服务器防火墙放行以下 TCP 端口：
```
sudo ufw allow 7000/tcp
sudo ufw allow 7500/tcp
```
> ![:warning:](https://linux.do/images/emoji/twemoji/warning.png?v=15) 如果是云服务器，还需在云控制台网络/安全组中开放端口。
---
## 5. 启动服务（临时测试）
```
./frps -c ./frps.toml
```
启动成功后可以访问 Web 面板：
```
http://<服务器公网IP>:7500
账号 / 密码: admin / admin
```

### **TLS 支持说明**
根据 **FRP 官方 README**（[fatedier/frp](https://github.com/fatedier/frp)）：
> “Since v0.50.0, the default value of transport.tls.enable and transport.tls.disableCustomTLSFirstByte has been changed to true, which means that TLS is enabled by default.”
自 **v0.50.0** 起，frpc 与 frps 之间的通信默认启用 **TLS 加密**，无需额外配置即可获得加密保护。
在我们的配置中，**FRP 已启用默认的 TLS 传输加密** ，因此：
- 所有数据均通过安全通道传输；
- 不需要手动提供证书文件；
- 有效防止中间人攻击和明文泄露。
若需进一步增强安全性，可在配置文件中启用自定义证书校验（tls.certFile、tls.keyFile、tls.trustedCaFile），以实现双向身份验证。
