# 什么是双拼？为什么我推荐学习双拼？



# 声明

首先我只是输入法圈的小白，只会使用简单的双拼，不会五笔、虎码、音形码、辅助码等等。本帖的目的是科普一下双拼输入法的优势并推广，在本帖下的讨论可以围绕你学习其他输入法的经验，禁止输入法鄙视链和拉踩引战，欢迎友好交流，遇到拉踩欢迎及时举报。

# 正文

## 什么是双拼？以及为什么推荐

双拼实际上就是全拼的简化版。比如你要输入“上海”，全拼你需要输入`shanghai`，双拼只需要输入`uhhd`（我用的是小鹤双拼），可以看到，声母`sh`=`u`，韵母`ang`=`h`、`ai`=`d`。对于两个字的词语来说，双拼只需要摁四个字符，而全拼普遍都大于等于四个字符（当然`啊哦`这种只需要两个字符的是极少数的存在），这样的映射让双拼在输入效率上可以大幅提升，重码率又可以低于全拼。

> *这里引用网上别人举的例子：*

>

> 双拼的重码比全拼低，在打单字的时候，双拼完全就是全拼的映射，两者重码一样。但是打词就不一样了，打词的时候双拼重码低于全拼。举个例子niao双拼只可能有一个读音就是鸟（nn）或尼奥（ni’ao）而全拼可以是鸟（niao）也可以是尼奥（niao），类似的还有linan临安、李楠，lian莲、李安。在双拼里是绝对不会出现这样的重码的，而在全拼里比比皆是。

同时与五笔的学习门槛相比，双拼的学习门槛是比较低的，看了对比帖大概是学习时间是五笔的1/3？也有说1/10的，我没有学过五笔，但无疑五笔是更有难度的。

就我自己的学习经验而言，双拼的学习时间大概是两周左右（日常打字两周），最痛苦的是学习到一半时全拼的肌肉记忆还在，但双拼的肌肉记忆又还没有形成。当肌肉记忆形成之后，它能够让你的打字速度进步神速。双拼最大的门槛就是记住韵母所对应的字符，但实际上根本不需要去记忆，你只需要去更多的去输入，让手指记住韵母所对应的字符所在的位置，形成肌肉记忆就好了（你可以把键盘的皮肤换成对应的）。

## 缺点

- 当然双拼也不是十全十美，有个缺点是，比如要输入“抑扬顿挫”这种成语或者某个诗句，全拼可能只需要输入首字母，但双拼每个字都要嗯两次。这个缺点可以通过字典或自定义短语来弥补。

- 小鹤双拼还有另一个缺点，windows没有原生支持，需要自己导入注册表，或手动映射。
