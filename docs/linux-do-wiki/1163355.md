# 贴链接的时候，如果你的链接后面有文字，要用空格隔开



创建话题或写回帖中，贴链接的时候，如果你的链接后面有文字，要用空格隔开，否则会被解析到一起，就像这样：



[https://linux.do这个论坛真不错](https://linux.xn--do-0v2cle942cco0c7e4ad5g0jm)。



就像这样，所以一定要加空格：



[https://linux.do](https://linux.do) 这个论坛真不错。



或者加反斜杠：



[https://linux.do](https://linux.do)\这个论坛真不错。
