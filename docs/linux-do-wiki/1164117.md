# [笔记] TailwindCSS 非侵入式集成

## 说明
不知道该发些啥帖子, 就干脆发一些工作中的笔记吧.
**各位佬友们注意, 该方案不适合生产环境使用**
> 该方案建议选择一些靠谱的 CDN 进行引入, 之前一直用的字节的([cdn.bytedance.com](http://cdn.bytedance.com)), 奈何因灰黑下线了.
## 实现
**自执行函数**
```
(function () {
  const link = document.createElement("script");
  link.src = "https://cdn.tailwindcss.com";
  document.body.appendChild(link);
})();
```
**或是非侵入式引入各类 CSS / JS 资源**
```
const cssCdnUrlList: Array<string> = [];
const jsCdnUrlList: Array<string> = [];

function setCssCdn(): boolean | undefined {
  if (cssCdnUrlList.length <= 0) return false;
  cssCdnUrlList.map((v: string): void => {
    const link: HTMLLinkElement = document.createElement('link');
    link.rel = 'stylesheet';
    link.href = v;
    link.crossOrigin = 'anonymous';
    document.getElementsByTagName('head')[0].appendChild(link);
  });
}

function setJsCdn(): boolean | undefined {
  if (jsCdnUrlList.length <= 0) return false;
  jsCdnUrlList.map((v: string): void => {
    const link: HTMLScriptElement = document.createElement('script');
    link.src = v;
    document.body.appendChild(link);
  });
}

const setIntroduction = {
  cssCdn: (): void => {
    setCssCdn();
  },

  jsCdn: (): void => {
    setJsCdn();
  },
};

export default setIntroduction;
```
