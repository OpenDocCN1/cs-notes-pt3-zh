# 总结征集一些有趣/有用的Github开源项目，拯救你的吃灰小鸡（VPS）

正如标题所说，这个话题中会持续汇集一些Github的开源项目，大多数是我有一定的了解的，这些服务也都是坛里的各位用的上的或有人用过的，看到之前有一个类似的话题，不过只贴了一个GIthub的链接，内容两年未更新了，且总结的项目对于L站的各位没有针对性，不是自己搓的网站不香。于是开一个话题来进行收集和我的分享。（帖子转为了wiki形式，各位有想法可以自行按照格式进行添加）
**注意：这不仅是我的总结，还需要各位你们的分享，欢迎在评论区留言，留下我的总结中没有但是你觉得有用、有趣的项目，我会持续更新到帖子中**
**值得注意的是，此话题主要征集可以自部署的项目，即在自己的vps上跑起来的项目**
- 探针/监控服务
当你的闲置小鸡多了起来，部署的项目多了起来，那么一个监控服务是必不可少的，恰好我在前几天发了一篇总结汇集这类服务的话题，这里不多赘述，将[链接放在这里](https://linux.do/t/topic/115012)有需要自行查看
- 1panel/宝塔
1p作为新兴的面板控制端，个人认为界面设计和使用都对小白更为友好，刚开始研究Linux的小白使用面板都可以大大简化操作和节省时间。对于接触时间较长的就是可选项了。
- 博客
买了服务器博客肯定是必不可少的，虽然不写但不能没有。这里列举几个我知道的且有对应社区的博客项目

WordPress
hexo
Typecho
Ghost
Halo（比较吃内存）

不同项目各有特点，自行选择喜欢的即可
- RustDesk自建中转
有时想要远程操作，但是QQ、向日葵一类的远程不满足需求，或者是延迟太高，又或者是担心数据安全，那么开源的RustDesk可以满足需求，自建服务器让延迟和远程控制传输质量由自己控制，经过我自己的测试，延迟可以控制在两位数。
- 私有网盘
这一点我感觉对于大部分人必要性不大，大多数人购置的服务器配置有限，传输速度和存储空间都不大，而我的需要主要是一个能够让我进行直链传输的网盘，方便不同设备之间快速的传输小文件。这里我使用的是cloudreve，对接了onedrive进行储存（还是要依托于第三方网盘，自己的小鸡吃不消）。
- 图床
上面搭建了博客之后，有些情况下会需要图床来托管图片，同时一些论坛里面不支持上传图片的也需要自行使用图床托管。这里我使用过兰空和EasyImage，都很不错，自行选择。
- [keepassxc](https://github.com/keepassxreboot/keepassxc)、[bitwarden](https://github.com/bitwarden/server)、[vaultwarden](https://github.com/dani-garcia/vaultwarden)
两款开源的跨平台密码管理器，如果你认为账号密码不重要还在用弱密码，那这条你可以忽略，但是你要清楚目前各类平台扫号的不计其数，如果你所有平台使用相同的密码，一旦有一个平台数据库泄露或者被扫出来，那你其他平台账号也会跟着沦陷。因此建议你去想一个好办法来让不同平台密码不同且强密码，这里的密码管理器只是其中之一的解决方案并不是唯一。两款各有优点，后者支持IOS，前者不支持。但是都支持使用自己搭建的服务端来保存，所有内容都掌握在自己手里。

二遍补充一下：vaultwarden是基于bitwarden的API进行开发的，bitwarden的服务一般的小鸡跑不动，2c2g直接给我卡死机了。而vaultwarden保留了后者特性兼容后者的客户端的同时，使用rust重写，大大降低内容消耗，普通的小内存的小鸡也可以放心运行
- 邮箱服务
这一点仁者见仁智者见智，如果你有一个商业性平台、大型论坛博客，那么一个由自己网站域名为后缀的邮箱无疑显得更专业（注意用词-显得），不过这个服务对于小白来说是十分困难的，建议不要轻易进行尝试。
- 对上面两点进行补充，这个文章是我写了几天的，但是在写完上面两个之后发生了“小粉兔”的事件，因此我觉得正好可以作为对于各位的安全警示，务必注重自己的账号、信息安全，虽然防不住一切，但能防住大多数总归是好的。
- emby服务
这个东西，看个人需求吧，单纯用购买的小鸡搭建不太现实，建议有群晖NAS一类的喜欢折腾去可以琢磨一下，打造一个自己私人影库。
- alist服务
这个不必多说，在很多地方都能用上，支持挂载大多数的网盘服务，不知道的我把介绍贴在这里：Alist是一个轻量级、跨平台的文件浏览和分享服务，支持将多种云存储和本地存储资源集中管理和访问，提供了一个简洁且高效的方式来整理和共享文件。 Alist支持挂载国内常见网盘，如：阿里云盘/夸克网盘/百度网盘等，非常适合NAS用户或大带宽用户安装使用
- 在线观影网站（适合小范围朋友间）
这个项目应该知道的比较少，[SyncTV](https://github.com/synctv-org/synctv)，这里是介绍：SyncTV 是一个允许您远程一起观看电影和直播的程序。它提供了同步观看、剧院和代理功能。使用 SyncTV，您可以与朋友和家人一起观看视频和直播，无论他们在哪里。SyncTV 的同步观看功能确保所有观看视频的人都在同一点上。这意味着您可以暂停、倒带或快进视频，其他人也会同步到同一点。SyncTV 还支持实时直播，因此您可以一起实时观看直播事件。剧院功能提供了聊天和弹幕功能，让您在观看视频时与朋友和家人交流。代理功能允许您观看在您连接到源服务器缓慢的视频和直播。
补充一下：支持挂载emby、alist、b站，搭配上面提到的就很方便了。
- 青龙面板
好用，功能强大，有很多定时任务类的项目都是基于青龙的功能进行开发的。这是介绍：这是一个多功能的定时任务管理平台，支持Python3、JavaScript、Shell和Typescript。用户可以管理多个账号，创建和调度各种任务，并通过详细的日志记录追踪任务执行情况。平台提供灵活的环境配置和多种通知方式，确保任务顺利完成并及时反馈执行结果。
- 众多AI项目
这个更不必多介绍了，都在这里看到这个文章了，都是有一定了解的。例如ChatGPT-Next-Web，Lobe—chat，New-API，都是很优秀的开源项目，坛里也有很多佬自主开发的优质项目，欢迎补充。
- 论坛
搭建一个始皇同款论坛，成为下一个始皇
- 搭建游戏服务
例如Minecraft、饥荒、泰拉瑞亚等游戏服务，回应上一条，刚好mcbbs跑路了，下一个mcbbs的创始人就是你。
- vps虚拟化
你要是实在没得做，又觉得吃灰浪费，可以把vps虚拟化，做成虚拟主机，然后在坛里搞抽奖发一发（记得做好网页内容审查）。
- 搭建在线聊天服务
不知道有什么用，但是作为无聊时打发时间去折腾一下，或者朋友之间临时用一用都可以。
- 导航站
搭建一个导航站，收录各类站点，流量大了接个广告创造营收，有兴趣的可以做一下，指路几个项目，[van-nav](https://github.com/Mereithhh/van-nav)，[WebStackPage.github.io](https://github.com/WebStackPage/WebStackPage.github.io)，以及别人整理的导航站项目合集仓库[awesome-navigation](https://github.com/eryajf/awesome-navigation)。
- 工具站
这个范围十分大，但是又不能把每个单独摘出来说，还是放在一起说比较好，指的是，提供各类公共服务，例如站长之家、itdog、图片去水印这类的服务。比较多且繁杂，就不列举具体项目了。同样欢迎评论区补充，我进行编辑。
- 搭建一个Bot
同样比较宽泛（指平台较多）的项目，搭建一个QQ Bot、微信Bot、TG BOT，搭建之后可以对接ChatGPT、各类公共API，例如现在的YunZai_QQBot框架，在这方面做的十分完善了，各类功能很齐全。提醒：如果你打算部署QQBot，这是一个打发时间的好选择，因为光是风控就能折磨你几周。
- 搭建节点
需要大带宽的小鸡才能进行搭建，一般的建站小鸡是性能均衡，带宽有限，搭建这项服务起码有个500M带宽起步吧，而且自己建节点不做中转的话其实体验大都还不如机场的（延迟方面），如果你是富哥买月付20刀+的优质线路小鸡当我没说，优点是安全、节点干净。
