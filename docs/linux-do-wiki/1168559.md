# A guideline for foreign friends on how to post a lottery



When posting a lottery, you can use the hashtag [抽奖](/tag/10-tag/10). This gives you self-moderation privileges over the post, and the same time comments under it will be limited to a certain number per person per day (manually adjustable) to keep the lottery fair.

Self-moderation privileges allow you to delete users’ duplicate posts, silence specific users, limit the interval between repeated posts, and more.

For more details about self-moderation privileges, please refer to this post.
