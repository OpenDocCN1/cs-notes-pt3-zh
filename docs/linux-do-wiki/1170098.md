# 【教程分享】Windows安全中心不知道什么时候没了



## 网上教程挺多的

1. 安装 `appx` 文件：![浏览已知内部版本 - UUP dump](https://uupdump.net/known.php) 里面搜索`系统版本号`+`SecHealthUI` [图片1896×699 52.7 KB](https://cdn3.ldstatic.com/original/4X/1/0/8/10800fbaf652851895410e562c0e9ed810932456.png)



![图片2037×781 74.8 KB](https://cdn3.ldstatic.com/original/4X/4/4/2/442db36620a9f3bff5620aa007e1b52cbe05492e.png)

2. [windows11 的windows 安全中心被卸载了，求找回，在系统设置里的应用程序那里卸载掉的 - Microsoft Q&A](https://learn.microsoft.com/zh-cn/answers/questions/5519578/windows11-windows)

3. [DefenderUI](https://www.cyberlock.global/defenderui.aspx) 选择国家 `China`

4. 使用 Windows 更新修复问题
