# Linux.do论坛官方福利汇总



该文档汇总[Linux.do](https://linux.do/)论坛福利汇总，包括官方的福利汇总和官方授权第三方福利汇总。

## **请直接参考**[官方福利汇总网页版](https://nav.linux.do/)

## 官方福利汇总（文字版）

- 1.定制@linux.do邮箱。（早期三级用户；因VPS服务商不允许，后期三级用户目前无法定制邮箱。）

- 2.SharedChat：[https://shared.oaifree.com/dashboard](https://shared.oaifree.com/dashboard) ，为Linux.do用户免费提供ChatGPT4、ChatGPT-4o、ChatGPT 3.5服务。

- 3.DeepLX Api Key：

获取方法：登录Linux.do账号，点击[Connect](https://connect.linux.do/) 即可获取一串显示为UUID的DeepLX Api Key:

[a6d1c8e731f46b11e4691bf486db232c5f9f149d.png1903×241 17.1 KB](https://cdn3.ldstatic.com/original/3X/8/a/8a838d99d40288ba988b8be3d51d169bf340fb0b.png)

使用方法：在浏览器中选择[沉浸式翻译](https://immersivetranslate.com/)  插件——选择开发者模式——选项——翻译服务——选择DeepLX（Alpha）——在API URL处填写`https://api.deeplx.org/Your DeepLX Api Key/translate`，将你的UUID替换Your DeepLX Api Key填入沉浸式翻译插件即可。

[e64ec0a82a67c8984f717cc580ada67a5a68236e.png1920×941 76.3 KB](https://cdn3.ldstatic.com/original/3X/8/5/851df4d986aa8815a197bb12177685830dde4deb.png)

详细教程： [FakeOpen：DeepLX使用教程](https://fakeopen.org/DeepLX) （By [@neo](/u/neo) 代理地址需要更新）；  [沉浸式翻译 Deeplx ](https://linux.do/t/topic/40146) （ by [@MrLeo](/u/mrleo) ）

- 4.OAIfree。参考[ OAIFree 相关服务文档](https://linux.do/t/topic/117134) 和[Wiki.oaifree ](https://linux.do/t/topic/99623)
