## 三.测试环境搭建

### 1.启动对应区块链节点

### 2.拉取并配置测试脚本（多群组测试配置见：多群组配置指南.md文件）

```
### 构建测试代码

# 1.通过git命令将测试代码拉取道本地
git clone https://github.com/flyingcoding/java-sdk-demo
# 2.进入对应目录并将代码切换到main-2.0分支（对应Fisco 2.x）
cd java-sdk-demo
git checkout main-2.0
# 3.使用gradle编译代码（注意：测试代码要求系统安装有Java环境： JDK 8～11）
# 注意: 此处如果出现报错（即无权限），请尝试使用 'sudo ...' 以root权限执行，后续步骤同理
./gradlew build

### 添加区块链连接证书及相关配置

# Copy the certificate (suppose the SDK certificate is located in ~/fisco/nodes/127.0.0.1/sdk directory)
cp -r ~/fisco/chain0/127.0.0.1/sdk/* dist/conf
# 创建配置
cp dist/conf/config-example.toml dist/conf/config.toml

## 修改 config.toml 中的节点地址（请与搭建区块链时指定的节点IP、通讯端口保持一致)
## [network]
## peers=["127.0.0.1:20200"]

## 根据cpu核心数，可选配置
channelProcessorThreadSize = "32" # The size of the thread pool to process channel callback
# Default is the number of cpu cores

receiptProcessorThreadSize = "32" # The size of the thread pool to process transaction receipt notification
# Default is the number of cpu cores
```

## 四.执行测试

### 1.使用快速脚本执行单群组测试（测试前请确保输入群组ID、测试参数无误）

```
bash quick-perf.sh [groupId] [userCount] [transferCount] [tps]
# e.g. bash quick-perf.sh 1 500 5000 100
# 各参数请根据服务器配置合理设置，TPS 参数可尝试逐次累加，直至实际 TPS 达到瓶颈
```

### 2.通过java代码执行多群组测试（测试前请确保输入群组ID、测试参数无误）

多群组节点连接配置见仓库分支main-2.0：多群组配置指南.md

```
cd dist
java -cp 'conf/:lib/*:apps/*' org.fisco.bcos.sdk.demo.perf.AutoParallelOkMultiGroupPerf [groupIds] [userCount] [transferCount] [tps]

# 示例：群组1、2并发，每组1000用户、10000交易、TPS=200
# java -cp 'conf/:lib/*:apps/*' org.fisco.bcos.sdk.demo.perf.AutoParallelOkMultiGroupPerf 1,2 1000 10000 200
```
