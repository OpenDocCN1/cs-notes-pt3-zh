# 整理已有 AI IDE 的教程(IDE 综述)

如题，最近各种 AI IDE 如雨后春笋般冒出来。自从 Cursor 和 Augment 封号之后，大家也开始尝试更多替代品。不过很多朋友还不太清楚如何入门，比如能不能绑虚拟卡、是否有免费试用、如何白嫖等。
因此开这个帖子，方便大家一起整理目前已知的各类白嫖方案、使用技巧，以及对各家 IDE 的简单介绍，大家使用体验等。也欢迎大家实时更新最新动态，让信息更集中、更好找。
