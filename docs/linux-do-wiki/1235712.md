# 【共建文档】Gemini学生认证Pro会员使用权益



最近跟着站内大佬成功薅到Gemini学生会员，整理了一下可以使用的权益

## 一、Gemini网页版

**可用模型**：Gemini 3.0 Pro、Banana Pro



**使用方式**：直接访问官网即用



**次数限制**：暂未明确，日常使用基本无感



**直达链接**：[Gemini网页版](https://gemini.google.com/app)

---

## 二、Gemini CLI 工具

### 核心权益

Gemini 2.5 Pro、Gemini 2.5 flash



Pro会员可通过表单申请Gemini 3.0 Pro使用权限

### 申请方式

1. 填写官方申请表单：[点我填写](https://docs.google.com/forms/d/e/1FAIpQLScQBMmnXxIYDnZhPtTP3xr5IwHNzKW4nLomuQ1tGOO-UldMdQ/viewform)

2. **重要提醒**：申请通过后谷歌**不会发送邮件通知**，需自行在CLI中关注3.0 Pro模型是否生效

### 2api

可通过CLI Proxy API将Gemini CLI反代为API调用
