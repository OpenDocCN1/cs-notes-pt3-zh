# 为路由器打造最小化的Tailscale



好久没写文章了，水一文 ![:grin:](https://linux.do/images/emoji/twemoji/grin.png?v=15)

> Tailscale作为一款非常好用的内网穿透工具，在路由器上配置，更能够做到多个内网间设备互访。官方发布了各个平台的版本，在Openwrt等软件源中也有tailscale软件包。但由于官方版本文件偏大(27M以上)，Openwrt软件源中版本不够新，所以有必要来自己构建最新版本，又小型化的tailscale。

以我在用的京东云一代为例，已经安装了`immortalwrt` 软件源中的 1.58.2-1 版本，落后官方太多，出现连接不成功的情况。

同时由于EMMC坏掉，只有16M的NORFlash可用，官方下载的运行文件需要50M左右空间，所以，在Openwrt的文档中找到了下面的方式。

# ![:memo:](https://linux.do/images/emoji/twemoji/memo.png?v=15) 构建最小化的tailscale

## 编译最小化tailscale

> 需要使用到 golang 环境，这里不再赘述安装方式，询问AI或搜索引擎找到最适合自己的方法。

克隆代码并选择合适的版本:

```
git clone <https://github.com/tailscale/tailscale.git>
cd tailscale
# 拉取指定的版本
git checkout tags/v1.90.9 -b v1.90.9
```

移除使用不到的模块，减小编译后大小

```
GOOS=linux GOARCH=mipsle GOMIPS=softfloat go build -o tailscale.combined -tags ts_include_cli,ts_omit_aws,ts_omit_bird,ts_omit_tap,ts_omit_kube,ts_omit_completion -trimpath -ldflags="-s -w" ./cmd/tailscaled
```

参数解释：

`GOARCH=mipsle`: MT7621平台mips小端序`mipsle`，更多的架构参见Golang **platform

`-tags`: 功能裁剪，默认包含很多云平台和高级功能的检测代码，这里去掉

- `ts_include_cli`: 合并 `tailscale` / `tailscaled` 两个成为一个运行文件

- `ts_omit_aws`: 移除 AWS 云环境的检测代码（你的路由器不在亚马逊云上）。

- `ts_omit_bird`: 移除 BIRD 路由协议集成（通常用于复杂的 BGP 路由，家用不需要）。

- `ts_omit_tap`: 移除对 TAP 模式的支持（通常只需要 TUN 模式）。

- `ts_omit_kube`: 移除 Kubernetes 相关的代码（路由器上没跑 K8s）。

- `ts_omit_completion`: 移除 Shell 自动补全代码（节省体积，且嵌入式 Shell 可能不支持）。

其他可裁剪的功能有: ts_omit_ssh(SSH服务端)， ts_omit_drive(网盘文件共享)， ts_omit_funnel(公网服务暴露)， ts_omit_tpm(TPM硬件支持)， ts_omit_doctor(网络诊断命令)， ts_omit_identityfederation(云身份自动认证)。

编译完成后，在代码目录下生成了 `tailscale.combined` 文件，目前文件大小仍然有 32MB。

## 进一步减小

最后，借助 upx，一个著名的可执行文件压缩器，进一步的压缩运行文件`tailscale.combined`，以减小体积，应用到路由器中。

```
# 安装 upx，以macos为例
brew install upx

# 最大压缩比
upx --lzma --best tailscale.combined
```

执行时会有进度和提示，最终执行后，`tailscale.combined`被压缩到了6.3M：

## 安装到路由器

通过scp或其他工具，上传 `tailscale.combined` 文件到路由器中，代替原有的文件。

由于这是一个二合一的运行文件，最后再做一个软链，实现`tailscale`命令。

```
# 这里先上传tailscale.combined到/tmp目录下
cp /tmp/tailscale.combined /usr/sbin/tailscaled
ln -s /usr/sbin/tailscaled /usr/sbin/tailscale

# 测试&使用 tailscale
tailscale version
```

# 附

## 软件源安装

1. 通过Openwrt/Immortalwrt 中软件包，搜索tailescale下载

2. 在Github搜索 tailscale.ipk 下载后安装

## 官方安装

访问 [https://pkgs.tailscale.com/stable/#static](https://pkgs.tailscale.com/stable/#static) 链接，根据自己的设备类型即可下载到官方发布的版本。

比如最新的：

- arm64: [tailscale_1.90.9_arm64.tgz](https://pkgs.tailscale.com/stable/tailscale_1.90.9_arm64.tgz)

- mips: [tailscale_1.90.9_mips.tgz](https://pkgs.tailscale.com/stable/tailscale_1.90.9_mips.tgz)

压缩包中包含了 `tailscale` 和 `tailscaled` 两个运行文件，以及`systemd` 配置。
