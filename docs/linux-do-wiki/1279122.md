### 一、基础设置

> 建议全程开启 VPN 使用 Termux

#### 1. 安装命令及基础软件包

```
# 每日好习惯
pkg update && pkg upgrade # 更新软件包
# 初次更新时，一路 Y 即可
# 开启 VPN 无需考虑更换源

# 安装命令
pkg install xxx

# 基础软件包
pkg install mandoc # 用于渲染手册页的轻量级工具
pkg install tree # 递归显示目录结构的命令行工具
pkg install vim # 文本编辑器，支持模式化操作
pkg install curl # 传输数据的命令行工具
pkg install git # 分布式版本控制系统
pkg install wget # 非交互式下载工具

# 一次性安装
pkg install tree vim curl git wget -y
```

#### 2. 编程语言

```
pkg install python
pkg install clang make # C / C++
pkg install nodejs
pkg install rust
pkg install golang
pkg install ruby
pkg install lua54
pkg install openjdk-17
pkg install kotline

npm install typescript # 注意是 npm install
npm install tsx # 用于运行 typescript 脚本，tsx xxx.ts

pkg install uv
```

#### 3. （可选）使用 zsh

> 如果你想使用 zsh，Termux 中用得最多的是 termux-ohmyzsh

**安装命令**：

```
sh -c "$(curl -fsSL https://github.com/Cabbagec/termux-ohmyzsh/raw/master/install.sh)"

# 安装过程中会提示申请文件访问权限
# 可以手动开启：termux-setup-storage
```

#### 4. 字体

个人比较推荐使用 Nerd Font 字体。

![:link:](img/b4a2bdf55da20064e573d1dd2d9837c2.png) 下载地址：[0xProto Nerd Font](https://github.com/ryanoasis/nerd-fonts/releases/download/v3.4.0/0xProto.zip)

将字体文件（如 0xProtoNerdFontMono-Regular.ttf）复制到 `/data/data/com.termux/files/home/.termux` 目录下，并重命名为 font.ttf 即可。

> 如果你已经改用了 termux-ohmyzsh，可以把字体文件复制到 `.zsh` 文件夹下。

> **注意**：

>

> 如果不重命名文件名，你需要执行 `chfont` 命令，并从中选择复制过来的字体

> 如果重命名为 font.ttf，则默认生效

#### 5. 修改问候语

编辑该文件：

```
vim $PREFIX/etc/motd
```

#### 6. 定制软键盘

编辑该文件：

```
vim ~/.termux/termux.properties
```

### 二、Python 及依赖

> Python 用得多，这里重点说一下。

#### 1. 需要通过 pkg 安装的常用 Python 包及依赖

> 建议不管用不用，都装上。

```
# 重要依赖
pkg install build-essential
pkg install pkg-config
pkg install cmake
pkg install binutils
pkg install libtool
pip install cython # 这里是 pip

pkg install python-numpy
pkg install electrum
pkg install opencv-python（这个不装问题不大）
pkg install asciinema
pkg install matplotlib
pkg install python-cryptography
pkg install python-pyarrow

# 忘记这俩哪个需要 pkg 安装了，应该是 scipy
# 问题不大，pip 安装失败的，就是要用 pkg 安装的
pkg install scipy / sympy
```

#### 2. 部分特殊包

> 建议不管用不用，都装上。

```
# 安装 gmpy2
pkg install libgmp libmpc libmpfr # 依赖
pip install gmpy2

# 安装 lxml
pkg install libxml2 libxslt # 依赖
pip install lxml

# 安装 pandas
# 先执行以下命令
export CFLAGS="-Wno-deprecated-declarations -Wno-unreachable-code"
pip install pandas

# 安装 pynacl（这个不装问题不大）
pkg install libsodium # 依赖
pip install pynacl

# 安装 pillow（这个不装问题不大）
# 64 位执行如下命令
export LDFLAGS="-L/system/lib64"
pip install pillow

# 安装 pyzmq
pkg install libzmq # 依赖
pip install pyzmq
```

#### 3. 安装 OpenAI Python SDK

前面两个完成后，理论上就可以正常安装 OpenAI Python SDK。

但是要把 VPN 节点切换到美国，因为会涉及 rust 包的下载安装，需要美国节点，否则会超时报错。

#### 4. 安装 scikit-learn

```
pip install meson-python
pip install scikit-learn --no-build-isolation
```

### 三、将 Termux 作为 MCP 服务器

> 这里只是简单提一下，不涉及 MCP Server 的具体开发。

- 对于可以变更 transport 类型的 MCP Server，可以拉到本地进行更改，然后直接运行。

- 对于不支持变更 transport 类型的，可以借助 supergateway 来运行，示例：



`npx -y supergateway --stdio "xxx" --port xxxx`

`"xxx"` 部分是 MCP Server 原本的运行命令，如 `python server.py`、`npx -y xxx` 等

`--port xxxx` 指定端口，默认为 8000，多服务同时运行，可自行指定端口号，如 8001

- 如果 Termux 自带的 session 窗口不够用，可以安装 tmux



`pkg install tmux`

`tmux new -s xxx`：新建 tmux 会话

`tmux attach -t xxx`：进入该 tmux 会话

`tmux kill-session -t xxx`：删除该 tmux 会话

快捷键 `Ctrl+b d`：退出 tmux 会话（后台挂起）

- **注意**：通过 supergateway 运行服务时，如果服务端退出过，重新连接时需要重新启动服务（个别服务可能有连接超时的情况）

### 五、便利性设置

可在 `.bashrc` 或 `.zshrc` 文件中设置指令别名，示例：

```
alias ll='ls -la'
```

记得使修改生效：`source ~/.bashrc` 或 `source ~/.zshrc`
