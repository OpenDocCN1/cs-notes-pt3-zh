# LaTex 数学符号与式子

一些可能常用的 LaTeX 数学符号与式子。
LaTeX 格式有两种：
```
第一种：`\( ... \)`

第二种：`$ ... $`
```
上面是行内公式的格式，行间公式的格式如下：
```
\[
......
\]

$$
......
$$
```
> [!info]
>
> LinuxDo 上支持渲染带美元符号 `$` 的这种。
---
