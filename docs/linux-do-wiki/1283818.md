# Context

## Morphllm-Flst-Apply 500次、输入30w输出10w/月

基于语义搜索的文件选择（File List Selection Tool, FLST）机制，服务范围更广，也更加结构化。

```
claude mcp add filesystem-with-morph -e MORPH_API_KEY=key --scope user npx @morphllm/morphmcp
```

# sequential-thinking

# Tavily Remote MCP 2000/月

高质量、结构化、适合 AI/LLM 后续处理／RAG／研究／事实核实／多源聚合

```
claude mcp add --transport http tavily-remote-mcp --scope user https://mcp.tavily.com/mcp/?tavilyApiKey=key
```

# Serena

编程持久化会话与记忆 [http://127.0.0.1:24282/dashboard/index.html](http://127.0.0.1:24282/dashboard/index.html) 极其复杂在Claude code 无法启动，加载配置失败

```
claude mcp add serena --scope user uvx git+https://github.com/oraios/serena serena start-mcp-server
```
