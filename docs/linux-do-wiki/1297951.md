## 1 闭环/开环 零极点关系

符号定义

G(s) := \frac{N_G(s)}{D_G(s)} , H(s) := \frac{N_H(s)}{D_H(s)}

计算如下表达式：

\boxed{

\begin{aligned}

G(s)H(s) &= \frac{N_G(s) N_H(s)}{D_G(s) D_H(s)}, \\

1 + G(s)H(s) &= \frac{D_G(s) D_H(s) + N_G(s) N_H(s)}{D_G(s) D_H(s)},\\

\frac{G(s)}{1+G(s)H(s)} &= \frac{N_G(s) D_H(s)}{D_G(s) D_H(s) + N_G(s) N_H(s)}

\end{aligned}

}

发现有如下关系

P(1+GH) = P(GH)\\

Z(1+GH) = P(\frac{G}{1+GH})

其中P表示极点，Z表示零点

## 2 Nyquist稳定判据推导

**引理**



Cauchy辐角原理:对于解析函数 F(s) ，在某个闭合曲线 \Gamma 所包围的区域内的零点与极点数量的差，等于 F(s) 将 \Gamma 映射到复值平面后所得曲线对原点的绕行次数。因此，确定区域内零点和极点个数的问题，可以等价地转化为计算映射曲线相对于原点的净环绕次数。

稳定性的关键在于闭环传函的极点，由于闭环传函的极点可以转化成(1 + GH)的零点问题，而零点数量问题，根据辐角原理转化成了映射围线绕原点的圈数问题。

**做法**



为了统计闭环特征方程 1+G(s)H(s) 在右半平面 (RHP) 的零点个数，我们取一个足够大的 Nyquist 围线 C ，使其包围整个右半平面。根据 Cauchy 辅角原理，右半平面内的零极点个数差，会转化为围线 C 经过映射 F(s)=1+G(s)H(s) 后绕原点的圈数。



工程中，无需写出围线的显式解析式：当系统是适当的（严格真有理），右半平面的无穷大半圆在映射下收缩到原点附近，可忽略不计；负频率部分又是正频率的共轭镜像。因此围线映射的主要贡献等价于扫描虚轴 s=j\omega （ \omega:0\to\infty ）。



于是只需令 s=j\omega ，绘出 1+G(j\omega)H(j\omega) 的轨迹，即通常所称的 Nyquist 图，观察其绕原点的圈数即可，而这又等价于观察 G(j\omega)H(j\omega) 绕点 -1+0j 的圈数。



定义映射后绕原点的圈数

N(1+GH,C):=\frac{1}{2\pi}\Delta_{C}arg(1 +GH)

由Cauchy辐角原理，有

N(1+GH,C):=\frac{1}{2\pi}\Delta_{C}arg(1 +GH) = Z(1 +GH,C) - P(1 +GH,C)

\begin{aligned}

    \text{系统稳定}&\iff P(\frac{G}{1+GH},C) = 0\\

    &\iff Z(1+GH,C) = 0,\text{且}N(1+GH) = Z(1 + GH,C) - P(1+GH,C)\\

    &\iff N + P(1+GH,C) = 0,\text{且}P(GH,C) = P(1+GH,C)\\

    &\iff N = -P(GH,C)

\end{aligned}

因此稳定性条件就变成了

把 RHP 中 1+ GH 的零点个数转化成了映射曲线 GH 绕点 -1+0j 的圈数。
