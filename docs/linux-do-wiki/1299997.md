### 基本信息

GPT5.1刚发布29天，就发布了GPT5.2，完全不符合行业通常3个月以上的升级周期，显然是感受到gemini-3-pro的巨大压力

#### gpt-5.2-chat

API gpt-5.2-chat= ChatGPT‑5.2 Instant



API上下文128k，最大输出16k，输入$1.75，输出$14

#### gpt-5.2

API gpt-5.2-medium = ChatGPT‑5.2



API gpt-5.2-high



API gpt‑5.2-xhigh



API上下文400k，最大输出128k（含思维链），输入$1.75，输出$14，涨价40%



Chat上下文和最大输出通常远小于API

#### gpt-5.2-pro

貌似对应关系（待确定）



API gpt-5.2-pro-medium = ChatGPT‑5.2 Pro Standard



API gpt-5.2-pro-high = ChatGPT‑5.2 Pro Extended



API gpt‑5.2-pro-xhigh，这个API里没有，官方评测里也没有这档



API上下文400k，最大输出128k，输入$21，输出$168，涨价40%



Chat可能需要Pro会员
