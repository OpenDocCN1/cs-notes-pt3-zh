# 白嫖ESA加速vaultwarden记录



情景简介：一台1H0.5G的辣鸡ECS通过docker部署Vaultwarden，端口使用8800，通过Nginx反向代理并绑定域名`bwd.example.com`，同时开启302强制https。已经在N多个设备上登录了自建vaultwarden，不想一台设备一台设备的修改配置，如何享受ESA带来的全球访问加速呢。。。

## 前提条件：白嫖一下ESA免费版

[https://linux.do/t/topic/1300477?u=_ooo](https://linux.do/t/topic/1300477)

## 步骤一、改造

1、删除原域名解析，添加新的解析`bwd-source.example.com`，记录值为辣鸡ECS的ip

2、修改Nginx配置，绑定到新的域名`bwd-source.example.com`，同时调整SSL证书配置。

## 步骤二、配置ESA

1、用CNAME的方式添加域名到ESA中

![image-202512121713385661865×926 54.3 KB](img/8261eb6ee00066907bdde35bfa83f2ca.png)

2、在ESA中添加一条DNS记录`bwd.example.com`，通过CNAME的方式，记录值`bwd-source.example.com`开启源站代理加速

![image-202512121716286461865×926 66.7 KB](img/d799e456683c7dee1cee8afe235e98d7.png)

3、申请SSL证书并开启代理加速站点强制https访问
