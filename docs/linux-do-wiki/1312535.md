# 如何让虚拟机网络和Clash TUN代理共存？

先放几个关键词以便后来人搜索：Clash，Mihomo，VMware，Hyper V，TUN，虚拟机，断网
相信各位佬友或多或少都遇到过类似这样的问题：如果主机的网络代理软件开启了TUN模式，那么，通过NAT模式来上网的虚拟机网络就会变得很奇怪。怎么说呢，大概就是每隔几分钟，就会有几分钟无法访问公共网络（和主机的通信、虚拟机之间的通信不受影响），且问题随机性很高，完全没办法稳定复现，但是把TUN一关就一定不会出现问题。
这应该是虚拟机的网卡和TUN网卡这俩东西不怎么和谐的缘故。但TUN网卡是不可能关的，所以：
给个解决方案，不要使用Hyper-V或者VMware提供的默认的虚拟网络交换机。创建一个新的网卡，并指定这个网卡共享TUN网卡（或者物理网卡）的网络。下面以Hyper-V为示例。
按照下图操作，创建一个新的交换机（内部）。并命名，我就叫作`Meta-Bridge`了，简单直接。
[image1829×1081 196 KB](https://cdn3.ldstatic.com/original/4X/6/6/c/66cbb711d2f834bd2e8d3fec6ad71e4a6fd14a18.jpeg)
然后，将这个交换机添加到虚拟机里边。**并把默认的Default Switch从虚拟机中删去。**
[image1829×1081 200 KB](https://cdn3.ldstatic.com/original/4X/f/d/d/fdd27dc7f4c92e6536aa2376d25e469b3e624930.jpeg)
接下来，Win+R打开`ncpa.cpl`，打开你的TUN网卡的属性，把它和`Meta-Bridge`共享。
[SnowShot_2025-12-15_00-31-261698×907 132 KB](https://cdn3.ldstatic.com/original/4X/7/6/d/76da41011857a68e1a013a6b4bc620629b0cc8e2.png)
最后，前往你的虚拟机，配置静态IP和DNS地址。一般来讲，你的物理机的`Meta-Bridge`会被Windows 默认分配到`192.168.137.1`这个IP地址，那么你给虚拟的静态IP应该是`192.168.137.*`这样的形式。虚拟机的网关和DNS服务器都填写`192.168.137.1`，物理机的网关留白即可。
