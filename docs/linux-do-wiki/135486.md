# 甲骨文ubuntu重装系统后个人操作总结

## 重装系统(系统为甲骨文Arm  Ubuntu-20.04)
1. 访问[Oracle所有镜像系列](https://docs.oracle.com/en-us/iaas/images/)找到需要安装的版本，复制对应区域OCID
2. 在实例详细信息里面选择替换引导卷，建议替换前先看下引导卷容量，**引导卷只能替换为使用相同 Linux 发行版的块卷和映像**

[替换引导卷路径1920×879 84.1 KB](https://cdn3.ldstatic.com/original/3X/f/c/fc44059f11856f2440484129cdb10aadc94ca59e.webp)
1. 输入OCID，**注意引导卷总量不超过200G**，`user_data` 是一个可选的参数，通常用于传递启动脚本或配置信息，以便在实例首次启动时执行，`user_data`的值即下面的脚本需要进行base64编码后再填写上去，填写完保存就会进行替换(不知道为什么就成功一次，后面多次重装就失联了)，建议直接生成密钥传`ssh_authorized_keys`后面再手动改root登陆
```
#!/bin/bash
echo root:你的密码 | chpasswd root
sed -i 's/^#\?PermitRootLogin.*/PermitRootLogin yes/g' /etc/ssh/sshd_config
sed -i 's/^#\?PasswordAuthentication.*/PasswordAuthentication yes/g' /etc/ssh/sshd_config
rm -rf /etc/ssh/sshd_config.d/* && rm -rf /etc/ssh/ssh_config.d/*
/etc/init.d/ssh* restart
```

## 开启root登陆
```
sudo -i
echo root:你的密码 | chpasswd root
sed -i 's/^#\?PermitRootLogin.*/PermitRootLogin yes/g' /etc/ssh/sshd_config
sed -i 's/^#\?PasswordAuthentication.*/PasswordAuthentication yes/g' /etc/ssh/sshd_config
rm -rf /etc/ssh/sshd_config.d/* && rm -rf /etc/ssh/ssh_config.d/*
/etc/init.d/ssh* restart
```
## 卸载甲骨文云官方后台监控程序
```
sudo snap remove oracle-cloud-agent
```
## 修改主机名
```
sudo vim /etc/hostname
sudo reboot
```
## 防火墙相关

iptables -P INPUT ACCEPT

## BBR加速
```
echo "net.core.default_qdisc=fq" >> /etc/sysctl.conf
echo "net.ipv4.tcp_congestion_control=bbr" >> /etc/sysctl.conf

sysctl -p

sysctl net.ipv4.tcp_available_congestion_control

lsmod | grep bbr
```
