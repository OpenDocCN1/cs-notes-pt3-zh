# Credit分数下降的几种可能



两种比较确定的情况：

1. 你自己发的主帖被移除了，获得的积分扣除，删帖有三种情况

- 静默删帖，不太严重的，不计入connect

- 同意删除，会收到通知，不计入connect

- 删帖，会收到通知，计入connect

1. 别人发的帖子被移除了，你在该帖中获得的积分也会被扣除（点赞之类的），你不会收到删帖通知

还有一种是我的猜测，目前credit站已经在维护了：

- 由于昨天 leaderboard 机制更改，不太确定之前的发帖获得的分数是否被扣除了。如果相关分数被扣除，则会导致你的积分比注册credit的分数还低，某大水怪被扣了500多分属实有点惨…
