# Gemini cli使用中转API的配置教程



> 先提示一下，是使用Gemini cli，接入中转的API，不是把Gemini cli to API放到其他地方用。

论坛搜索了下，好像有零星的佬友在问，我今天试着玩Zed编辑器的时候，想要用Gemini cli，折腾半天发现免费的Google账号没有Gemini 3 Pro可以用了，就想着接入中转商的API吧，结果不知道咋个设置，不像是codex和Claude code论坛好多的教程，从侧面反应出Gemini cli的真实用户其实不多呀。

大家要么是用中转的Claude 模型，要么是直接用antigravity。

首先是在 ~/.gemini/settings.json （Windows就在你的user用户目录下）设置selectedType为gemini-api-key，这样才会使用API方式调用：

```
{
  "security": {
    "auth": {
      "selectedType": "gemini-api-key"
    }
  }
}
```

然后是在.gemini/ 目录创建一个 .env 文件，填写基础信息：

```
GOOGLE_GEMINI_BASE_URL=https://api-proxy-url
GEMINI_API_KEY=xxx
GEMINI_MODEL=gemini-3-pro-preview
```

这样就可以使用外部中转商的API来使用Gemini cli了。
