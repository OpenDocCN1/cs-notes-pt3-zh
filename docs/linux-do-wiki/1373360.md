# 分享一个《docker部署verdaccio》的经验



之前在虚机机使用linux部署verdaccio都很简单和顺利，但是后面用了docker部署，就遇到不少问题，在这里分享一下

## 安装Podman

因为docker比较占用资源，所以我们这里使用`podman` 作为虚机机平台，podman兼容docker和docker-compose，所以直接用来平替也没什么问题。

### 更新wsl环境

```
# 将wsl升级到最新
wsl --update
# 设置默认为wsl2
wsl --set-default-version 2
```

### 下载podman

[Podman](https://github.com/containers/podman/blob/main/docs/tutorials/podman-for-windows.md)

我们选择安装podman wsl2,进行安装。安装后，系统会多一个`podman-machine-default`的linux子系统应用，双击打开它，或者在window terminal中新增一个终端类型来使用它，后面所有关于容器的操作都在该应用中执行，而不是在cmd或者powershell中。

### 设置podman

1. 解决权限问题

```
vi /etc/wsl.conf

## 添加以下配置
[boot]
systemd=true
```

1. 解决网络问题

```
## wsl2默认与宿主环境网络是隔离的，不方便我们通信访问，所以我们需要设置wsl的网络为镜像网络
## 与宿主共享

vi ~/.wslconfig

## 添加以下配置
[wsl2]
networkingMode=mirrored
firewall=false

### 在powshell中重启wsl
wsl --shutdown
```

1. 更换源

```
## 修改源配置
vi /etc/containers/registries.conf

## 添加以下配置
unqualified-search-registries = ["docker.io"]
[[registry]]
prefix = "docker.io"
location = "docker.m.daocloud.io"
```

1. 配置别名

我们可以在alias中配置podman的别名为docker，podman兼容docker，还是习惯使用docker的话，配置一下比较顺手。podman-compose需要单独安装，不包含在cli中。

```
alais docker=podman
alias docker-compose=podman-compose
```

## 部署 Verdaccio

### 拉取镜像

```
docker pull verdaccio/verdaccio
```

### 复制配置

1. 为了复制`verdaccio` 的默认配置，我们先创建一个容器

```
docker run -d --name verdaccio -p 4873:4873 verdaccio/verdaccio
```

1. 使用`docker cp` 命令复制配置

```
docker cp verdaccio:/verdaccio/plugins /home/user/verdaccio/plugins
docker cp verdaccio:/verdaccio/conf /home/user/verdaccio/conf
docker cp verdaccio:/verdaccio/storage /home/user/verdaccio/storage
```

把`verdaccio` 三个主要的目录都复制出来，方便我们做目录映射

### 创建容器

1. 编写`docker-compose.yml`

```
version: '3'
services:
  verdaccio:
    image: verdaccio/verdaccio
    container_name: "verdaccio"
    user: root #使用root用户启动verdaccio，这个非常重要，不然没有权限修改目录
    network--mode: "bridge"
    environment:
      - VERDACCIO_PORT=4873
    ports:
      - "4873:4873"
    volumes:
      - "/home/user/verdaccio/storage:/verdaccio/storage"
      - "/home/user/verdaccio/conf:/verdaccio/conf"
      - "/home/user/verdaccio/plugins:/verdaccio/plugins"
```

该配置放在~/verdaccio目录下，方便启动

1. 设置映射目录storage的权限

```
sudo chown -R 1000:65533 /home/user/verdaccio/storage
```

1. 启动容器

```
docker-compose up -d
```

### 创建用户

`verdaccio` 使用htpasswd来管理账号密码，我们可以使用 [在线htpasswd](https://tool.oschina.net/htpasswd) 生成，然后在~/verdaccio/storage/htpasswd中写入该账号密码

## 客户端发布

### 登录npm私服

```
npm login --registry=http://localhost:4873
```

### 配置npm包

```
{
  "private": false,
  "main": "lib/index.js",  // 指定库入口
  "publishConfig": {
    "registry": "http://127.0.0.1:4873/"  // 指定npm源地址
  },
}
```

### 发布npm包

如果是monorepo方式管理的项目，需要进入到子包的根目录中

```
npm publish --registry=http://localhost:4873
```

### 取消发布npm包

```
npm unpublish --force --registry=http://localhost:4873
```
