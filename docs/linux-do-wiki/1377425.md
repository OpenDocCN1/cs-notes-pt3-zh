# 做中学ai 01:提示词篇章



# 提示词心法

提示词没有什么神秘技巧。

大家都在研究"怎么写提示词"，这个方向搞反了。提示词写不好，不是表达问题，是你自己都没想清楚要什么。

高手的做法很简单：先想清楚需求，提示词自然就会写了。

这其实就是做任何事的通用方法：规划、执行、反馈、迭代。

写提示词之前，先问自己三件事：我到底要说什么？我想要什么风格？这东西给谁看、用在哪？这三个问题答清楚，后面的迭代也有方向。

AI有个常被忽视的价值：它逼你把模糊的想法变成具体的话。当你发现很难向AI描述清楚需求时，说明你自己也没想明白。这个被迫思考的过程，才是AI真正帮到你的地方。

说白了就是做中学。别光想，动手试，看结果，不对就调，循环往复。

这就是真相大法。
