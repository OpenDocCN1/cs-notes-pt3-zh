# 古董旁路由轻NAS终极改造笔记



本次玩的是：GL-SFT1200 (Opal) 老古董128mb内存吃灰软路由

魔改原因：smb上传速度仅1mb，无法使用主路由看片，古董机网速慢不适合做主路由下载文件仅8mb速率，主路由载文件可达50mb/s

改后效果：smb上传速度提升至12mb，达到性能顶峰，改fpt旁路由观影模式秒加载。

核心逻辑：

1. 网络架构： 路由器变身“客户端 (Client)”，像手机一样连入家里主路由，只做 NAS 和下载机，不发射 WiFi。

2. 性能优化： 必须用 Ext4 格式 + Async 异步加速，否则 128MB 内存必卡。

3. 看片方案：FTP 看片（极速不卡），SMB 管理文件。

【第一章：找回消失的路由器 (IP 查找大法)】



做完旁路设置后，没宽带路由器 IP 变了，进不去后台怎么办？



方法 A：电脑 CMD 大法 (最快)

1. 电脑连上家里的主路由 WiFi (或者插网线)。

2. 按键盘 Win + R，输入 cmd，回车。

3. 在黑框里输入：arp -a，回车。

4. 找凶手： 在列表里找物理地址 (MAC) 是 94:83:C4 (GL.iNet 前缀) 开头的那个。

5. 它左边的 192.168.xxx.xxx 就是你路由器现在的真 IP。



方法 B：手机扫描法 (不用电脑)

6. 手机连主路由 WiFi。

7. 下载 App：Fing (或者“网络百宝箱”)。

8. 点击“扫描网络”，找到名字叫 GL-Technologies 或者 Unknown 的设备，记下 IP。

【第二章：电脑端工具准备 (必读)】

1. 格式化 U 盘 (解决卡顿根源)



Windows 自带格式化没用，必须用这个！



● 工具：DiskGenius (免费版即可)



● 操作： 插上 U 盘 -> 打开软件 -> 右键 U 盘 -> 删除分区 -> 新建分区。



○ 文件系统：选 Ext4 (Linux Data)。



○ 对齐：勾选 4096 扇区 (4K对齐)。



○ 保存更改，等进度条跑完。

2. 连接“黑框框” (SSH)



● 工具： 电脑自带的 CMD。



● 指令： 复制下面这行（防报错版），在 CMD 里右键粘贴：



ssh -o HostKeyAlgorithms=+ssh-rsa -o PubkeyAcceptedKeyTypes=+ssh-rsa root@192.168.xxx.xxx



(把 xxx 换成第一章查到的 IP)



● 小白卡点：



○ 提示 Are you sure…? -> 输入 yes 回车。



○ 提示 password: -> 输入后台密码。注意：输入时屏幕上什么都不显示，光标不动是正常的！ 输完直接回车。

3. 图形化管理文件 (WinSCP)



● 工具：WinSCP



● 登录设置 (填错必连不上)：



○ 文件协议：SCP (一定要选 SCP，别选 SFTP)。



○ 主机名： 你的路由器 IP。



○ 端口： 22



○ 用户名： root / 密码： 后台密码。

【第三章：性能榨干 (开启 Async 加速)】



这一步不做，看片必卡。

1. 获取 U 盘身份证 (UUID)：



○ 在 CMD 黑框里输入：block info



○ 复制 /mnt/sda1 后面引号里的那一长串字符 (如 96030e20-xxxx…)。

2. 修改配置：



○ 用 WinSCP 进入 /etc/config/ 目录，双击打开文件 fstab。



○ 找到 config ‘mount‘ 这段，全部删掉，替换成下面这段（填入你的 UUID）：



代码段



config ‘mount‘



option target ‘/mnt/sda1‘



option uuid ‘把你的UUID粘贴在这里‘



option enabled ‘1‘



option options ‘rw,noatime,async‘



○ 点保存，然后重启路由器。

【第四章：服务配置 (复制粘贴即可)】



![:open_file_folder:](img/801a523098f88dee1d78a4632e175b93.png) 魔改章节：FTP 的安装与纯命令行配置



如果你重置了路由器，或者发现机器里根本没有 FTP，请按这个步骤操作。全过程不需要打开网页后台，只需要在 CMD 黑框 (SSH) 里复制粘贴。

1. 安装 FTP 核心程序



即使提示 unknown package 也不用慌，只要显示 Installing vsftpd… 就是成功。



复制下面这两行命令执行：



Bash

# 1. 更新软件列表 (必须先做，否则找不到安装包)

opkg update

# 2. 安装 FTP 主程序 (我们不需要 luci 图形界面，只装核心)

opkg install vsftpd



(注意：如果提示 Package vsftpd is already installed，说明出厂自带了，直接跳到下一步即可。)



2. 写入“防报错”完美配置文件 (纯命令版)



这一步直接用代码生成配置文件，解决了“无法上传”、“根目录不对”、“IPv6冲突”等所有常见问题。



一次性复制下面这一整大段，粘贴进黑框回车：



Bash

# 1. 先强制停止可能卡死的进程

killall vsftpd

# 2. 写入配置 (这是最关键的一步)

echo “listen=YES



listen_ipv6=NO



anonymous_enable=NO



local_enable=YES



write_enable=YES



local_umask=022



dirmessage_enable=YES



use_localtime=YES



xferlog_enable=YES



connect_from_port_20=YES



chroot_local_user=NO



check_shell=NO



local_root=/mnt



pam_service_name=vsftpd



“ > /etc/vsftpd.conf



3. 修复 OpenWrt 祖传 Bug (空目录问题)



很多 FTP 装好启动不了，就是因为缺这个文件夹。



复制下面这两行执行：



Bash

# 1. 创建缺失的空目录

mkdir -p /var/run/vsftpd/empty

# 2. 把修复命令写入开机脚本 (防止重启后又失效)

sed -i ‘/PROG/a mkdir -p /var/run/vsftpd/empty‘ /etc/init.d/vsftpd



4. 启动服务并设置开机自启



做完这一步，FTP 也就正式开始工作了。



复制下面这两行执行：



Bash



/etc/init.d/vsftpd enable



/etc/init.d/vsftpd restart



5. 验证是否成功 (查岗)



输入：



Bash



netstat -lanp | grep 21



● 成功信号： 看到屏幕显示 0.0.0.0:21 … LISTEN。



● 失败信号： 什么都没显示（空白）。

1. 修复 FTP (用于 nPlayer 极速看片)



解决“连不上”、“空文件夹报错”、“无法写入”三大坑。



在 CMD 黑框里，一次性复制粘贴下面所有代码，回车：



Bash

# 1. 清理残留进程

killall vsftpd

# 2. 写入完美配置

echo “listen=YES



listen_ipv6=NO



anonymous_enable=NO



local_enable=YES



write_enable=YES



local_umask=022



dirmessage_enable=YES



use_localtime=YES



xferlog_enable=YES



connect_from_port_20=YES



chroot_local_user=NO



check_shell=NO



local_root=/mnt



pam_service_name=vsftpd



“ > /etc/vsftpd.conf

# 3. 修复空目录 Bug (关键)

mkdir -p /var/run/vsftpd/empty



sed -i ‘/PROG/a mkdir -p /var/run/vsftpd/empty‘ /etc/init.d/vsftpd

# 4. 启动服务

/etc/init.d/vsftpd enable



/etc/init.d/vsftpd restart



2. 修复 SMB (用于文件管理)



解决“Client模式连不上”、“104 错误”、“拒绝访问”。

1. 用 WinSCP 打开 /etc/config/samba，清空内容，填入：



代码段



config samba



option name ‘GL-SFT1200‘



option workgroup ‘WORKGROUP‘



option description ‘GL-iNet NAS‘



option homes ‘1‘



option interface ‘‘         # 空着代表监听所有接口



option bind_interfaces_only ‘no‘ # 必须为 no，否则 Client 模式连不上

config sambashare



option name ‘G-Drive‘



option path ‘/mnt/sda1‘



option read_only ‘0‘



option guest_ok ‘1‘         # 开启免密访问，省事



option create_mask ‘0777‘



option dir_mask ‘0777‘



2. 回到 CMD 黑框，输入重启命令：



/etc/init.d/samba restart

【第五章：手机怎么连 (保姆级)】

1. nPlayer (看片专用)



● 新建连接： 选 FTP (别选 SMB，SMB 拉进度条慢)。



● 主机： 填路由器的 IP。



● 用户：root



● 密码： 后台密码。



● 端口：21



● 设置： 进 App 设置 -> 网络 -> 缓存大小 -> 拉到 50MB 以上。

2. 猫头鹰 Owlfiles / ES文件浏览器 (管理文件)



● 新建连接： 选 SMB (macOS/Linux NAS)。



● 主机： 填路由器的 IP。



● 端口：445



● 用户/密码： 留空 (因为我们在配置里开了 guest_ok)。



● 协议版本： 如果有选项，选 SMB 2.0 (不要选 Auto 或 1.0)。
