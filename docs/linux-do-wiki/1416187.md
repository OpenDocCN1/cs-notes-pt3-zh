# 罗技Master3s鼠标换壳经验分享



替换的部位为亲肤部分。

由于我的鼠标是浅色的，亲肤部分永久了会发黄发黏，使用酒精/水等清理后又容易出现亲肤部分掉皮。所以最后在过保后换了3D打印的外壳。如果有同样问题的可以参考本经验分享（非原创，换壳方案也非唯一）

风险提示：

1. 会撕掉原来的亲肤层，必定损坏亲肤的皮（因为是胶粘的）

2. 3D打印不能保证完全贴合，但贴合度还是挺高的

3. 3D打印的较硬材质可能会影响最左侧的按键，可能需要自行开活动槽。

4. 粘胶有风险，避免滴入鼠标缝隙影响鼠标功能

步骤：

1. 嘉立创3D打印的模型库下载模型。[开槽模型（未试过）](https://model.jlc-3dp.cn/modelDetail/3a5220b995994065b47e2d8de9ab70d2.html) 和 [未开槽模型（我用的，也是最早有的模型）](https://model.jlc-3dp.cn/modelDetail/aefca615dce446b283a723a16aac4c0b.html)

2. 进入嘉立创3D打印下单对应的模型，使用的材料为`PA12S`（其他材料未尝试），图中的其实是灰白色，然后用一段时间吸油汗后就有点黑亮（不是脏。材料本身颜色）

3. 购买`B7000`胶水，该胶水粘的不会和502那么快，但比502会更适合粘贴鼠标，是手机维修常用的胶水。10ml带针头的就行。

4. 撕掉原来的亲肤外壳，清理干净。

5. 涂胶水，贴上3D打印的外壳（这一步尤其注意：在涂滚轮附近的时候准备好吸胶水的纸巾，避免胶水流入滚轮、微动按键）

6. 刀片修整一下按钮和滚轮附近的残胶和3D打印的外壳，避免影响到鼠标。

优点：不会发黏，价格便宜，手感出色

缺点：毁坏亲肤层会无保修，大拇指侧边底部按钮会受到壳的影响（开槽版本未测试，可能可以改善）；虽然模型已经尽可能的贴合，但毕竟不是原厂也不是柔性材料，所以会有一定的间隙在。
