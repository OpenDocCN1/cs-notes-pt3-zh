# 【72 的开发工具 004】【2/6 更新】OpenCode 安装 oh-my-opencode 并配置 CLIProxyAPI、MCP



2026-02-06 更新 oh-my-opencode 3.2 配置，新增参考文档 [https://linux.do/t/topic/1553729](https://linux.do/t/topic/1553729)

# 1、安装 [OpenCode](https://opencode.ai)

```
pnpm install -g opencode-ai
```

# 2、打开 OpenCode

```
opencode
```

> [!tip]如果输入之后无法启动，看看是不是配置文件 JSON 格式错误。

# 3、安装 [oh-my-opencode](https://github.com/code-yeongyu/oh-my-opencode/blob/dev/README.zh-cn.md) 插件

> [!tip]官方推荐，把这个提示词粘贴到 opencode 会话里，让它自己动：

```
按照以下说明安装和配置 oh-my-opencode：
https://raw.githubusercontent.com/code-yeongyu/oh-my-opencode/refs/heads/master/docs/guide/installation.md
```

# 6、常用命令

## opencode

更新：`opencode upgrade`

执行命令：`! ls`

退出终端：`Ctrl + Z`

切换最近使用过的模型：`F2`

切换 Plan/Build 模式：`tab`

> **Plan 模式**：规划和设计阶段，**Build 模式**：实现和执行阶段

## 斜杠命令

| 命令 | 说明 |

| --- | --- |

| `/init` | 初始化项目 |

| `/models` | 切换模型 |

| `/new` | 新建会话 |

| `/session` | 查看会话（Ctrl + D 删除） |

| `/undo` | 撤销更改 |

| `/share` | 分享会话 |

| `/commands` | 所有命令 |

| `/exit` | 退出 OpenCode |

## @ 命令

直接调用对应 Agent，如 `@frontend-ui-ux-engineer 设计一个登录页面`
