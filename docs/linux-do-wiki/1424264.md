### NVIDIA显卡的架构代号及特点

| 架构名称 | 游戏显卡 (GeForce) | 数据中心/专业卡 (Tesla/A/H/B系列) | 备注与特殊型号 |

| --- | --- | --- | --- |

| Fermi 费米 | GTX 400/500 系列 (如 GTX 580) | Tesla M2090, Quadro 6000 | 上古卡，忘掉它吧 |

| Kepler 开普勒 | GTX 600/700 系列 (如 GTX 780 Ti) | Tesla K10/K40/K80 | 战术核显卡，现在还有少部分垃圾佬捡来Tesla K系列卡来玩。然而开普勒只能画图用了 |

| Maxwell 麦克斯韦 | GTX 750 (v1), GTX 900 系列 (v2) | Tesla M4/M40/M60 | 极大提升了能效比；M40也是小部分垃圾佬会玩的卡，但本质上并没有比K40/K80好哪去，都是画图或者做vGPU的命 |

| Pascal 帕斯卡 | GTX 1000 系列 (如 GTX 1080 Ti) | Tesla P4/P40/P100 | 这代全是神，P4刀卡适合进NAS里蹲着，P40有24G版本，P100是首个Tesla HBM卡，和其他两位不太一样 |

| Volta 伏打 | 无 | Tesla V100, Titan V | 目前垃圾佬新宠，V100 16G上转接卡性价比很高。不过这代的Tensor属于过渡，功耗也很高 |

| Turing 图灵 | RTX 20 / GTX 16 系 | Tesla T4/T10, Quadro RTX 8000 | T4是当年Kaggle/Huggingface/Colab上标配推理卡，能耗比非常出色，Tensor计算给力，不过现在不便宜。更划算的是Tesla T10这张云游戏拆机卡，更好的性能，同样有16G版本。还有支持NVLink的2080Ti 22G魔改，是我学习大模型的入门卡。图灵支持许多现代特性（BF16除外） |

| Ampere 安培 | RTX 30 系 (如 RTX 3090) | A100, A10/A40/, RTX A6000 | 支持BF16，支持Marlin，3090还可以上NVLink，是很多穷组首选。算是现代卡里最便宜的选项，除了FP8支持以外基本都能跑跑，训练推理都很合适 |

| Hopper 霍珀 | 无 | H100, H200, H20 | 训练常用的卡，通常出现在大公司的组里或者AutoDL之类的算力平台上 |

| Blackwell 布莱克威尔 | RTX 5000 系列 (如 RTX 5090) | B100, B200, GB200 | 50系前期断货问题严重以至于社区的支持都不太好，最近几个月才逐渐跟上。目前主力还是在30/40系上 |

### 认识算力单位

| 指标 | 全称 | 主要数据类型 | 典型应用场景 | NVIDIA语境下的详细解读 |

| --- | --- | --- | --- | --- |

| TFLOPS | Tera Floating-point Operations Per Second | FP64 (双精度), FP32 (单精度), FP16 (半精度), BF16, TF32 | 科学计算 (HPC)、图形渲染 (游戏/专业绘图)、深度学习训练 | 这是GPU最传统的性能指标。前期主要宣传FP32能力，用于光栅化和着色；从Turing开始则强调Tensor Core带来的FP16/BF16/FP8性能，这直接决定了AI模型的训练速度。FP64主要用于气象模拟等高精度科学计算 |

| TOPS | Tera Operations Per Second | INT8, INT4, FP8 (部分语境下) | 深度学习推理 (Inference)、边缘计算、视频分析 | 随着大模型的量化技术普及，TOPS变得极其重要。它衡量的是每秒能进行多少万亿次操作，通常指低精度整数运算。在RTX 40系和H100/B200中，AI算力(AI TOPS)常指利用稀疏性(Sparsity)和Tensor Core加速后的INT8或FP8性能，是衡量生成Token速度的关键 |

| TIPS | Tera Instructions Per Second | Integer Instructions (整数指令) | 逻辑判断、地址跳转、控制流 | 很少在GPU宣传中出现。在GPU中，TIPS通常指CUDA核心中的INT32管线性能。虽然GPU可以独立执行整数指令而不阻塞浮点单元，但在AI和图形宣传中，更多地使用TOPS来描述算力，TIPS几乎不作为营销指标出现 |

### CUDA算力、Tensor算力与AI算力

FP32算力的基本计算公式是：算力=核心总数×核心运行频率 (GHz)×单核每周期指令数 (Ops/Cycle)×2(FMA)。这也是我们常说的实打实的算力，用于通用计算。对于NVIDIA显卡来说，每周期指令数=1。

下文中我们将这个公式的计算结果定为基线1.0倍率。

这里按架构演进来讲解一下。**注：笔者本人也仅是略懂。如有问题请各位及时指正，谢谢**

#### Fermi

- FP64：专业卡=1/2，游戏卡=1/8或1/12

- FP16：无硬件加速

#### Kepler

- FP64：K40/K80/TItan等=1/3，游戏卡=1/24

- FP16同费米

#### Maxwell

- FP64=1/32

- FP16=1/64

非常神秘的一代卡，双精度和半精度都拉完了，不过那个年代确实玩的就是FP32。

#### Pascal

Tesla P100是Pascal的例外，引入了快速FP16。

- FP64：P100=1/2，游戏卡=1/32

- FP16：P100=2，游戏卡=1/64

然而，牢黄并非给了P100全部。还记得前文的数据精度部分吗？P40引入了DP4A，即：

- INT8：P40=4

P100是没有INT8(DP4A)的，P40是没有快速FP16的。这是GP100和GP102核心的主要差别之一。

#### Volta

伏打引入了初代Tensor Core，非常适合矩阵乘法的计算。此时FP16算力有了巨大变化。从这里开始暂不讨论FP64，因为已经无太大意义。

- FP16：V100/Titan V=8

#### Turing

图灵架构为了适配AI推理的场景，增加了整数加速。从这里开始，以下倍率均相对于基线FP32的Tensor Core性能。

- FP16：8

- INT8：16

- INT4：32

这里以经典的Tesla T4为例，讲解一下算力宣称的花招。我们首先在Techpowerup上查询T4的规格：[NVIDIA Tesla T4 Specs | TechPowerUp GPU Database](https://www.techpowerup.com/gpu-specs/tesla-t4.c3316)

可以看到算力标注：

| 精度 | 算力 |

| --- | --- |

| FP16 (half) | 65.13 TFLOPS (8:1) |

| FP32 (float) | 8.141 TFLOPS |

| FP64 (double) | 254.4 GFLOPS (1:32) |

我们简单计算一下：T4有2560个CUDA核心，Boost频率是1590Mhz，按FP32算力公式计算可得：

`2560*1590*1*2=8,140,800 `

与标称的FP32算力是一致的。根据倍率计算也对得上。但为什么官网资料声称的是`混合精度 (FP16/FP32)：65 FP16 TFLOPS`呢？

##### 累加精度/混合精度

Tensor Core在处理矩阵乘法时，允许输入低精度（如FP16），但输出和累加使用高精度（FP32），以保证训练收敛。

在这里就是：输入FP16，计算和输出FP32，计算速度还是FP16的。

#### Ampere（RTX）

安培架构变得更加复杂了，满满的都是坑。

先从安培游戏卡说起。看起来30系的显卡CUDA暴涨，但实际上每个SM中有4个计算分区，每分区16个CUDA核心专用于FP32，另外16个CUDA核心既能处理FP32又能处理INT32。这导致 30 系卡的纸面算力虽然看起来翻倍了，但在实际游戏中由于仍需要处理大量 INT32 ，其性能提升幅度远没有纸面算力标称的那么大。

##### TF32混合精度

TF32=FP16的精度 + FP32的范围（8位尾数+8位指数）

- TF32：1（稠密），2（稀疏）

- FP16 / BF16（FP32累加）：2（稠密），4（稀疏）  // 训练常用

- FP16：4（稠密），8（稀疏）  // 推理常用

- INT8：8（稠密），16（稀疏）

- INT4：16（稠密），32（稀疏）

#### Ampere（数据中心）

数据中心卡则不太一样，比如A100。

##### 结构化稀疏

如果矩阵里有一半是 0（4个连续元素中有2个是0），硬件会自动跳过0值的计算，性能再翻倍。这也就是为什么所谓的“AI算力”数大到离谱，先稀疏再量化，一路套娃一路翻倍。

- TF32：8（稠密），16（稀疏）

- FP16 / BF16：16（稠密），32（稀疏）

- INT8：32（稠密），64（稀疏）

- INT4：64（稠密），128（稀疏）

#### Ada Lovelace

新增了FP8精度（E4M3/E5M2）。需要注意的是，从本代开始，图形卡和计算卡彻底被拆开了。

- TF32：1（稠密），2（稀疏）

- FP16 / BF16（FP32累加）：2（稠密），4（稀疏）

- FP16：4（稠密），8（稀疏）

- FP8（FP32累加）：4（稠密），8（稀疏）

- FP8：8（稠密），16（稀疏）

- INT8：8（稠密），16（稀疏）

- INT4：16（稠密），32（稀疏）

#### Hopper（数据中心）

用Hopper的人想必不再需要看这张表了罢。

#### Blackwell（RTX）

- TF32：1（稠密），2（稀疏）

- FP16 / BF16（FP32累加）：2（稠密），4（稀疏）

- FP16：4（稠密），8（稀疏）

- FP8（FP32累加）：4（稠密），8（稀疏）

- FP8：8（稠密），16（稀疏）

- FP4：16（稠密），32（稀疏）  // 所谓FP4 AI TOPS

- INT8：8（稠密），16（稀疏）

- INT4：16（稠密），32（稀疏）

#### Blackwell（数据中心）

需要注意的是，Blackwell的计算卡和RTX卡也不是一码事。此处略，理由同Hopper。

### 显存的进化

#### GDDR3 - GDDR5

- **技术特点**：高频率，位宽较窄（通常256-bit或384-bit）

- **代表架构**：Fermi, Kepler, Maxwell

#### GDDR5X / GDDR6 / GDDR6X

- **技术特点**：通过PAM4信号编码（GDDR6X）大幅提升频率

- **代表显卡**：RTX 3090 (24GB GDDR6X), RTX 4090 (24GB GDDR6X)

- **对推理/训练的影响**：由于3090性能很强且支持NVLink，对于个人或者穷组来说非常香，推理和微调都够用。但在训练中，GDDR6X的带宽远低于HBM，导致训练效率低得多

#### 初代HBM - P100

- **技术特点**：将存储芯片垂直堆叠，直接封装在GPU核心旁，位宽极大

- **代表显卡**：Tesla P100 (16GB HBM2)

- **对训练的影响**：高带宽让GPU核心不再长时间等待数据，训练速度飞跃

#### HBM2 / HBM2e - V100 (Volta) 与 A100 (Ampere)

- **技术特点**：A100使用了40GB/80GB HBM2e，又大又快

- **对训练的影响**：大显存使得其允许训练更大的Batch Size

- **对推理的影响**：显存带宽决定了LLM的推理速度（Token/s）

#### HBM3、HBM3e - Hopper、Blackwell

更大更快更强，没了

### 显存位宽、带宽、AI训练与牢黄刀法

如果把显卡比作一个工厂，那么：

- 算力=生产的速度。算力越高，处理复杂计算（如画图、矩阵乘法）就越快。

- 显存位宽=公路的车道数。连接仓库（显存）和车间（核心）的公路有几条车道就是位宽数。牢黄非常爱在位宽上动刀子，这样可以立竿见影地在AI计算上面对显卡做出区分。

- 显存带宽=公路的总运输能力。带宽 = 显存频率 × 位宽 / 8，即使位宽再大，如果显存频率上不去也白给。如果带宽不够，核心算力再强也得停下来等数据，这就是为什么HBM非常重要。在挖矿时代一个常见操作就是猛拉显存频率以获得更大的带宽，这样可以尽量压榨算力。

对于打游戏而言，每从显存里读一次数据，核心就可以反复用这些数据算很多次。所以一般来说限制游戏性能的瓶颈在算力上，核心越强打游戏就越强。顺便一提，高分辨率下游戏所需的数据也很大块，所以位宽被砍在越高的分辨率下越能显出影响，直到碰到核心算力瓶颈为止。

但到了LLM上就完全相反了：

- 推理：大模型本质上是巨大的矩阵乘法，推理时为了生成下一个token，必须把模型的所有参数从显存搬到核心里走一遍。每搬运一个参数，往往只进行一次乘法和一次加法

- 训练：比推理压力更大，不仅要读参数，还要读中间激活值、计算梯度、回写梯度、更新参数。时间基本上都花在显存搬运数据上，核心算一下歇一下

这就是为什么牢黄只需略动刀法，就能大幅降低AI算力而不怎么影响游戏性能的原因之一。

到了Ada这代，刀法更加精准了。拿4060Ti举例子，这货被丧心病狂地砍到了128bit位宽，导致16G显存虽然看起来美丽但实际上用于AI的时候屁用没有。但为什么游戏性能没受太大影响呢？因为L2缓存量大幅提高了，这样可以尽可能地在内部缓存热数据（AMD的X3D CPU打网游显著优势也是类似的意思），但大模型动辄几十G，L2瞬间就被塞爆了。所以说光看核心算力和显存大小也不能作为评判这张卡AI性能的唯一标准，像40系游戏卡这种抽象东西还是尽可能地避开为好。

### SLI、NVLink、推理与训练

NVLink的刀法比核心和显存还要复杂。

| 型号 | 架构 | NVLink 代数 | 桥接器物理形态 | 双向总带宽 | 备注 |

| --- | --- | --- | --- | --- | --- |

| Titan X / XP / 1080 Ti | Pascal | SLI HB，非NVLink | 双指接口 | 2-4 GB/s | 仅加速游戏用（虽然实际上也没几款游戏支持），所谓四路泰坦 |

| Tesla P100 | Pascal | 1.0 | PCIE或板载 | 80-160GB/s | 4条通道，一条20G。SMX接口的P100速度翻倍 |

| Tesla V100 | Volta | 2.0 | PCIE或NVSwitch | 100-300GB/s | PCIE版本带宽和Turing的一样，都是100GB/s。SXM版本出现了NVS，速率提升到300GB/s |

| Titan V | Volta | 2.0 (阉割版) | Titan V 专用桥 | 100 GB/s | 市面上几乎找不到这个桥，而且很贵 |

| Titan RTX / RTX 2080 Ti | Turing | 2.0 (阉割版) | Turing 桥 (接口较长) | 100 GB/s | 20系专用。Tesla T10上虽然有金手指但好像无法开启相关特性。之前买两张2080Ti魔改送桥，现在好像都单卖了 |

| RTX 3090 / 3090 Ti | Ampere | 3.0 (阉割版) | Ampere 桥 (接口较短) | 112.5 GB/s | 30系专用，因为散热器巨大，通常需要4-slot宽度的桥 |

| RTX A6000 | Ampere | 3.0 (阉割版) | Ampere 桥 (专业卡版) | 112.5 GB/s | 核心与3090类似，带宽一致，但物理高度不同 |

| RTX 4090 | Ada | 无 | 无 | 无 | 3090给了NVLink疑似影响Ampere计算卡市场，40系全给砍了 |

| A100 SXM | Ampere | 3.0 | 主板集成 (NVSwitch) | 600 GB/s | 真·NVLink |

注：本人差点踩坑，A6000和3090虽然都是Ampere卡，但NVLink桥不通用，买前一定要看好。
