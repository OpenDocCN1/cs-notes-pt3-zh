# Claude Code 小白教程 安装+使用 教程



![:one:](img/4203fcb91b550c137818c51434b2b96b.png) 安装 Node.js

下载并安装 Node.js：

```
https://nodejs.org/dist/v24.12.0/node-v24.12.0-x64.msi
```

![:two:](img/3b2dea1916913e0af5103f751bb15498.png) 安装 Claude Code

打开 CMD，运行：

```
npm install -g @anthropic-ai/claude-code
```

安装完成后验证：

```
claude --version
```

应该会输出版本号

![:three:](img/e6f11ac2b9bda66e86f7ad743b2eafaf.png) 关闭联网验证

先别启动 Claude，先运行这个命令关闭联网验证：

```
setx CLAUDE_CODE_DISABLE_NONESSENTIAL_TRAFFIC 1
```

![:four:](img/857bbd4aabb1baa174c95bb49791c015.png) 配置 settings.json

编辑配置文件：

```
C:\Users\你的用户名\.claude\settings.json
```

写入以下内容：

```
{
  "env": {
    "ANTHROPIC_BASE_URL": "你自己的API URL",
    "ANTHROPIC_AUTH_TOKEN": "你自己的API Key",
    "ANTHROPIC_DEFAULT_OPUS_MODEL": "claude-opus-4-5-20251101"
  },
  "model": "opus",
  "alwaysThinkingEnabled": false
}
}
```

```
⚠️ 注意：把 你的用户名 替换成你 Windows 的实际用户名，把 API Key 替换成你自己的密钥
```

![:five:](img/dfa6dd8697bd004e5a10df68ca11519b.png) 启动 Claude Code

配置完成后，在 CMD 中输入：

claude

就可以开始使用了 ![:grin:](img/1768c37c3e56e1f7e2b42893ac39f105.png)
