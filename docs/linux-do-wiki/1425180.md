# Claude Code 小白教程 安装+使用 教程



![:one:](https://linux.do/images/emoji/twemoji/one.png?v=15) 安装 Node.js

下载并安装 Node.js：

```
https://nodejs.org/dist/v24.12.0/node-v24.12.0-x64.msi
```

![:two:](https://linux.do/images/emoji/twemoji/two.png?v=15) 安装 Claude Code

打开 CMD，运行：

```
npm install -g @anthropic-ai/claude-code
```

安装完成后验证：

```
claude --version
```

应该会输出版本号

![:three:](https://linux.do/images/emoji/twemoji/three.png?v=15) 关闭联网验证

先别启动 Claude，先运行这个命令关闭联网验证：

```
setx CLAUDE_CODE_DISABLE_NONESSENTIAL_TRAFFIC 1
```

![:four:](https://linux.do/images/emoji/twemoji/four.png?v=15) 配置 settings.json

编辑配置文件：

```
C:\Users\你的用户名\.claude\settings.json
```

写入以下内容：

```
{
  "env": {
    "ANTHROPIC_BASE_URL": "你自己的API URL",
    "ANTHROPIC_AUTH_TOKEN": "你自己的API Key",
    "ANTHROPIC_DEFAULT_OPUS_MODEL": "claude-opus-4-5-20251101"
  },
  "model": "opus",
  "alwaysThinkingEnabled": false
}
}
```

```
⚠️ 注意：把 你的用户名 替换成你 Windows 的实际用户名，把 API Key 替换成你自己的密钥
```

![:five:](https://linux.do/images/emoji/twemoji/five.png?v=15) 启动 Claude Code

配置完成后，在 CMD 中输入：

claude

就可以开始使用了 ![:grin:](https://linux.do/images/emoji/twemoji/grin.png?v=15)
