# 风萧萧机场的小tip



看到不少佬对购买和抽奖的流量有疑问，做个小说明。以下是个人亲自试验后的结果，仅供各位佬参考：






2、购买 非酋佬的可靠流量途径，但是要注意，如果要抽奖，请先购买再抽，不然抽奖的流量会被覆盖 ![:joy:](img/2b0b6072de755040344c1e8fe952e35e.png)



3、使用 获得流量后直接导入自己的机场软件就可以，具体就是点击左侧“Dashboard”，然后页面下方会有个“Quick Subscription”，点一下选择对应项就ok。
