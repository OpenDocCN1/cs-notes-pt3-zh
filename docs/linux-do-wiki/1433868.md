# 风萧萧机场的小tip



看到不少佬对购买和抽奖的流量有疑问，做个小说明。以下是个人亲自试验后的结果，仅供各位佬参考：



1、抽奖 概率不可说，13次总共抽到20G+，欧皇佬请无视 ![:joy:](https://cdn.ldstatic.com/images/emoji/twemoji/joy.png?v=15)



2、购买 非酋佬的可靠流量途径，但是要注意，如果要抽奖，请先购买再抽，不然抽奖的流量会被覆盖 ![:joy:](https://cdn.ldstatic.com/images/emoji/twemoji/joy.png?v=15)



3、使用 获得流量后直接导入自己的机场软件就可以，具体就是点击左侧“Dashboard”，然后页面下方会有个“Quick Subscription”，点一下选择对应项就ok。
