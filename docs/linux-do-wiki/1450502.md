# 【软件教程】文件夹多标签页自动合并 ExplorerTabUtility



效率软件

## 简介

> 软件官网：[GitHub - w4po/ExplorerTabUtility: 🚀 Supercharge Windows 11's File Explorer: Auto-convert windows to tabs, duplicate tabs, reopen closed ones, and more!](https://github.com/w4po/ExplorerTabUtility)

一个文件夹标签页功能，Windows从xp到win10一直没有提供多标签页功能。终于，在Win11推出了多标签页功能。相信很多人和我一样：

- 第一眼：哇哦！看着真不错，官方多标签页终于出来啦

- 第二眼：打开多个文件夹，为什么不能自动合并？？？



![image631×338 51.8 KB](img/12de5536998b78391485aac44b5d39be.png)

理想情况下，打开新文件夹都会在同一个文件夹窗口的新标签页打开，和浏览器一样



那么，有什么办法呢？嘻嘻![:smiling_face_with_three_hearts:](img/ec0a683b4207e2a88babd1072de6da50.png)![:smiling_face_with_three_hearts:](img/ec0a683b4207e2a88babd1072de6da50.png)有的，用ExplorerTabUtility软件，效果如下



![ExplorerTabUtility软件演示](img/928d67603254179d34bdd34279727ec5.png)

## 操作教程

### 恢复异常关闭窗口

有时候不小心关闭了整个窗口，可以通过这个开关，立刻恢复窗口


### 拷贝、重新打开刚刚删除的标签页

快捷键方面，软件具有非常高的自定义功能。

- 拷贝当前标签页（我设置的 Ctrl+D）

- 重新打开刚删除的标签页（我设置的 Shift+X）



![image852×402 45.6 KB](img/d2f8cda3ba78f98e530f5e4f42fdfac3.png)

### 更多快捷键

还有很多（搜索标签页、前进、后退、设置窗口布局位置），感觉就搜索有一点用

![image167×511 3.75 KB](img/d648549a278f225005fc047272c812e5.png)

例如，可以定义快捷键设置窗口位置在各个位置（感觉鸡肋，很少用到）

![image852×402 35.3 KB](img/8fa9e13be521c51c8e283cd8da3eeb4d.png)

配置文件路径： `%APPDATA%\ExplorerTabUtility\settings.json`
