# 【软件教程】文件夹多标签页自动合并 ExplorerTabUtility

效率软件
## 简介
> 软件官网：[GitHub - w4po/ExplorerTabUtility: 🚀 Supercharge Windows 11's File Explorer: Auto-convert windows to tabs, duplicate tabs, reopen closed ones, and more!](https://github.com/w4po/ExplorerTabUtility)
一个文件夹标签页功能，Windows从xp到win10一直没有提供多标签页功能。终于，在Win11推出了多标签页功能。相信很多人和我一样：
- 第一眼：哇哦！看着真不错，官方多标签页终于出来啦
- 第二眼：打开多个文件夹，为什么不能自动合并？？？

[image631×338 51.8 KB](https://cdn3.ldstatic.com/original/4X/d/e/8/de87adb658e115ae9d0e9426a2930d8e0ce1a483.jpeg)
理想情况下，打开新文件夹都会在同一个文件夹窗口的新标签页打开，和浏览器一样

那么，有什么办法呢？嘻嘻![:smiling_face_with_three_hearts:](https://linux.do/images/emoji/twemoji/smiling_face_with_three_hearts.png?v=15)![:smiling_face_with_three_hearts:](https://linux.do/images/emoji/twemoji/smiling_face_with_three_hearts.png?v=15)有的，用ExplorerTabUtility软件，效果如下

![ExplorerTabUtility软件演示](https://cdn3.ldstatic.com/original/4X/d/d/e/dde1b481aa480cabe30e803011b4068fd9019929.gif)
## 操作教程
### 恢复异常关闭窗口
有时候不小心关闭了整个窗口，可以通过这个开关，立刻恢复窗口
[image852×402 31.5 KB](https://cdn3.ldstatic.com/original/4X/f/d/f/fdf4982536afbc8ff69ac982587a9c7de5c6c848.png)
### 拷贝、重新打开刚刚删除的标签页
快捷键方面，软件具有非常高的自定义功能。
- 拷贝当前标签页（我设置的 Ctrl+D）
- 重新打开刚删除的标签页（我设置的 Shift+X）

[image852×402 45.6 KB](https://cdn3.ldstatic.com/original/4X/f/7/8/f789be1e117e0df2871ffcf65ca2f620a90cfe5b.png)
### 更多快捷键
还有很多（搜索标签页、前进、后退、设置窗口布局位置），感觉就搜索有一点用
[image167×511 3.75 KB](https://cdn3.ldstatic.com/original/4X/f/9/b/f9bcee45b4434b1c79964a183def7c9a92705d47.png)
例如，可以定义快捷键设置窗口位置在各个位置（感觉鸡肋，很少用到）
[image852×402 35.3 KB](https://cdn3.ldstatic.com/original/4X/1/4/b/14bbd5f238c0cf8604d29d8789d92920da5a3db4.png)
配置文件路径： `%APPDATA%\ExplorerTabUtility\settings.json`
