# 批判--人性论，一个马克思主义学习者的视角

从马克思主义唯物史观、实践观与阶级分析方法出发，以性善论、性恶论为代表的中国古代人性论，是植根于封建生产关系的先验主义唯心学说，其理论建构与价值取向，与马克思主义科学人性论存在本质对立，如下：

一、 违背唯物史观：将人性抽象化为超历史、超阶级的先天属性

马克思主义的核心论断是：“人的本质不是单个人所固有的抽象物，在其现实性上，它是一切社会关系的总和”。这一论断揭示了人性的历史性与阶级性——人性的形成与发展，始终受制于特定历史阶段的生产力水平与生产关系性质，不存在脱离社会现实的“先天人性”。

而中国古代人性论的根本缺陷，正是将人性从社会关系中抽离，赋予其先验的善恶属性。孟子将“恻隐、羞恶、辞让、是非”四端视为与生俱来的道德萌芽，认为这是人区别于动物的先天本质；荀子则将“好利、疾恶、好声色”的本能欲望定义为先天之“恶”。二者看似对立，实则遵循同一逻辑：将特定历史条件下的道德规范与人性特征，上升为超历史、超阶级的普遍准则。

在封建小农经济与等级制度下，统治阶级将“安分守礼”“重义轻利”定义为“善”，将“争利僭越”“反抗压迫”定义为“恶”。古代人性论的善恶预设，本质上是封建统治阶级的意识形态投射，却被包装成适用于所有时代、所有阶级的“先天人性”，完全忽视了人性的阶级差异——封建地主的“人性”与农民的“人性”，因所处生产关系的对立而截然不同，绝不可能用统一的“善”或“恶”来概括。

二、 背离实践观点：否定实践对人性的塑造与改造作用

马克思主义认为，实践是认识世界、改造世界的根本途径，也是人性形成与发展的唯一基础。人性不是先天注定的“模板”，而是在物质生产实践、社会革命实践中不断生成的动态过程；改造人性的根本路径，不是精神内省或外在礼法约束，而是通过实践变革不合理的社会制度，推动生产关系与生产力的适配。

古代先验主义人性论，恰恰走向了实践的反面：

1. 性善论的内省路径：孟子主张“求其放心”，即通过自我反省找回被私欲遮蔽的先天善性，将人性的完善寄托于个人道德修养。这种路径完全脱离物质生产实践，忽视了封建剥削制度对人性的扭曲——在土地兼并、苛捐杂税的压迫下，农民的私欲本质上是生存权的诉求，绝非需要克制的恶！



2. 性恶论的外在约束路径：荀子提出“化性起伪”，主张以礼法教化约束先天恶性。但他所推崇的“礼法”，是维护封建等级秩序的工具，而非基于社会实践的制度革新。其本质是让被统治阶级顺从既定秩序，而非通过实践推翻剥削制度，实现人性的真正解放。

无论是内省还是礼法约束，古代人性论都将人性视为需要“修正”的先天存在，而非需要通过实践发展的动态本质，这与马克思主义“实践塑造人性”的核心观点完全相悖。

三、 服务于封建统治：具有鲜明的阶级局限性

马克思主义阶级分析方法指出，任何意识形态都不是超阶级的“普遍真理”，而是特定阶级利益的集中体现。中国古代先验主义人性论，本质上是封建统治阶级的意识形态工具，其最终目的是论证封建等级制度的合法性，维护统治阶级的剥削利益。

1. 性善论为君主专制背书：孟子的“性善论”延伸出“仁政”思想，主张君主凭借先天善性推行德治。这一观点将封建君主的统治权力归因于“先天善性”，掩盖了君主专制的阶级压迫本质，让被统治阶级将希望寄托于“明君”，而非主动反抗剥削。



2. 性恶论为礼法统治提供依据：荀子的“性恶论”为封建礼法的强制性提供了理论支撑——正因为人性本恶，才需要统治阶级制定礼法加以约束。这一逻辑将封建礼法的阶级属性（维护地主阶级利益）掩盖为“普世的人性规范”，剥夺了被统治阶级反抗不合理制度的正当性。



3. 性三品说固化封建等级：董仲舒、韩愈的“性三品说”，直接将人性划分为“上品之善”“中品可塑”“下品之恶”，对应封建统治阶级、中间阶层与被统治阶级。这种划分将封建等级制度归因于“先天人性差异”，论证了剥削制度的“合理性”，是典型的阶级固化理论。

四、 与马克思主义科学人性论的本质对立

马克思主义科学人性论，以实践为核心、以社会关系为维度，与古代先验主义人性论形成根本性分野！

五、 辩证看待其历史价值与根本局限

1. 历史价值：在先秦时期，这些人性论突破了宗教神学对人性的神化，将人性讨论聚焦于人本身，推动了古代伦理思想的发展；其强调的道德修养、社会秩序理念，也对维系封建社会稳定起到了一定的历史作用。



2. 根本局限：先验主义的理论内核，决定了它无法揭示人性的真实起源与发展规律，更无法为实现人的解放提供科学路径。在现代社会，这种脱离实践、掩盖阶级矛盾的人性观，已无法解释复杂的社会现象与人性多样性，必须被马克思主义科学人性论所超越。
