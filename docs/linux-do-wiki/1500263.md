# 基于pytorch的推荐算法框架



向大家推荐自己负责维护的社区框架：  [datawhalechina/torch-rechub: A Lighting Pytorch Framework for Recommendation Models](https://github.com/datawhalechina/torch-rechub) ，目前700star了，代码风格采用机器学习时最爱的scikit-learn的风格。目前主要支持的功能和采用的模块如框架图所示：

![image1680×713 270 KB](https://cdn3.ldstatic.com/original/4X/a/a/a/aaaee7aca3bafe5a30b5d378b90413aa3703c9ff.jpeg)

之前就在我前司用这个框架上线了双塔模型，嘎嘎好用。除去数据处理部分，10 行代码实现工业级推荐系统。30+ 主流模型开箱即用，支持一键 ONNX 部署，让你专注于业务而非工程。

使用手册在这里：[torch-rechub](https://datawhalechina.github.io/torch-rechub/) 手册基本还算完善，期待有贡献者愿意补充。欢迎各位会用Torch，并且对推荐算法感兴趣的小伙伴加入我们~

那么具体有哪些特性呢？在README都有写：

- **模块化设计:** 易于添加新的模型、数据集和评估指标。

- **基于 PyTorch:** 利用 PyTorch 的动态图和 GPU 加速能力。

- **丰富的模型库:** 涵盖 **30+** 经典和前沿推荐算法（召回、排序、多任务、生成式推荐等）。

- **标准化流程:** 提供统一的数据加载、训练和评估流程。

- **易于配置:** 通过配置文件或命令行参数轻松调整实验设置。

- **可复现性:** 旨在确保实验结果的可复现性。

- **ONNX 导出:** 支持将训练好的模型导出为 ONNX 格式，便于部署到生产环境。

- **跨引擎数据处理:** 现已支持基于 PySpark 的数据处理与转换，方便在大数据管道中落地。

- **实验可视化与跟踪:** 内置 WandB、SwanLab、TensorBoardX 三种可视化/追踪工具的统一集成。
