# 项目推荐：webvm

先上地址： [leaningtech/webvm: Virtual Machine for the Web (github.com)](https://github.com/leaningtech/webvm)

这个项目的名字，我们可以把它拆成2部分：[web][vm]

web，就是网络

vm，就是虚拟机、沙盒

运行在网络上的沙盒？那是什么

OvO……

揭晓答案，这个项目是实现**在浏览器中运行 Linux 虚拟机**

哈哈，很新颖！
这个虚拟机是一个无需服务器、客户端的虚拟环境。基于 CheerpX 虚拟化引擎，提供了一个安全、沙盒的 x86 虚拟环境，可运行二进制文件、命令行工具、文本编辑器、编译脚本，登录后还能访问互联网，适用于演示和快速访问 Linux 开发环境等场景。
