# 基金转换你懂了吗？



在交易日15:00前操作转换，转出和转入的基金，统统按当天的净值计算！

![:memo:](img/4b68861d2b497d70ac8001bb2d1325b7.png)举个例子（假设周一14:30操作）：

- T日（周一）：你提交转换申请。

- 转出基金：按周一晚上的净值卖出。

- 转入基金：按周一晚上的净值买入。



（相当于用旧份额直接换了新份额，价格都是按周一收盘价算的）

- T+1日（周二）：基金公司确认份额。

- 你可以在账户里看到转换成功了。

![:glowing_star:](img/db8294e389b64250d0d97a2b489a1cb9.png)为什么推荐转换？



比起“先赎回再申购”，转换能帮你省手续费，还能无缝衔接，避免资金空窗期，效率拉满！

![:warning:](img/3dc0bc5a5f64005058108870be0dfbeb.png)避坑指南：



千万别卡在15:00后操作！否则会顺延到下一个交易日计算，可能就错过了当天的行情！此外QDII、FOF和港美股基金的确认时间可能比普通基金晚1个交易日甚至更长，具体以基金公司提示为准。
