# 小白向Komari搭建及配置图文教程

## 1. 前言
Komari 是一个服务器监控/探针面板，github地址为 [https://github.com/komari-monitor/komari](https://github.com/komari-monitor/komari)
本文基于 Komari 1.1.3 版本，Purcarte主题 1.2.5 版本，KomariBeautify 0.4.2 版本
本文中搭建Komari使用的是腾讯云轻量应用服务器可以参加腾讯云活动 [https://cloud.tencent.com/act/pro/double12-2025](https://cloud.tencent.com/act/pro/double12-2025) 进行购买，4核4G服务器新客38元/年起，当然买不买都无所谓，毕竟我也没有AFF

## 2. 部署搭建Komari
首先是部署Komari，这里我们介绍docker compose 部署和 1panel 部署两种方式（2.1与2.2两种方式二选一即可）
如果想要使用更多部署方式（例如一键脚本）可以参考Komari官方文档 [https://www.komari.wiki/install/quick-start.html](https://www.komari.wiki/install/quick-start.html)
### 2.1 docker compose 部署
首先确保你的服务器安装了 Docker ，安装 Docker 的教程遍地都是，这里就不多赘述了（建议使用 [https://linuxmirrors.cn/](https://linuxmirrors.cn/) ）
另外只要不是非常久远版本的 Docker 都是自带 compose 的，所以一般来说不需要额外安装 docker-compose
确定安装好 Docker 了以后，就可以找一个目录来部署和保存Komari的数据了（本文中使用 `/data/komari` ）
在 /data/komari 目录下新建文件 `compose.yaml`
[513×339 16.1 KB](https://cdn3.ldstatic.com/original/4X/d/0/c/d0c8b6b19154aa128a91a4e2b9318ab934bfab1c.png)
将以下内容复制粘贴进`compose.yaml`
```
services:
  komari:
    image: ghcr.io/komari-monitor/komari:latest
    container_name: komari
    ports:
      - 25774:25774
    volumes:
      - ./data:/app/data
    environment:
      # 可选：自定义初始管理员账号
      # ADMIN_USERNAME: admin
      # ADMIN_PASSWORD: yourpassword
    restart: unless-stopped
```
[1344×639 24.8 KB](https://cdn3.ldstatic.com/original/4X/c/a/3/ca3e046dd4936346930b1f42d41ff943392a1494.png)
接下来进行修改
首先，如果你的服务器位于大陆，可以将 `ghcr.io/komari-monitor/komari:latest` 替换为 `ghcr.1ms.run/komari-monitor/komari:latest` （1ms.run加速镜像）
其次，可以将 `- 25774:25774` 中**前面的**那个25774修改为其它端口（这个也可以不修改，默认即可）
然后，将 `# ADMIN_USERNAME` 和 `# ADMIN_PASSWORD` 前面的 `#` 删除，并分别修改后面的值为你要给komari设置的账号 密码（要修改）
我的服务器位于大陆，不修改端口，设置了账号密码，修改后的示例：
[1344×640 30.9 KB](https://cdn3.ldstatic.com/original/4X/8/d/2/8d21f89bdecde66e35228b77a9edd22a8ce7ad6e.png)
保存后，在 /data/komari 目录下运行命令 `docker compose up -d` ，如下图，容器启动即成功
[1593×464 16.9 KB](https://cdn3.ldstatic.com/original/4X/9/1/e/91eac480b728464bd656681096e5ef5f25e98b74.png)
### 2.2 1panel部署
如果你的服务器在使用1panel面板，那么可以使用更简单的部署方式
**（！！！目前komari已经上架了1panel官方应用商店，可以跳过运行脚本和同步本地应用的步骤了）**

首先在服务器上运行脚本
`bash -c "$(curl -sSL https://1panel.komari.wiki/install.sh)"`
[626×405 6.81 KB](https://cdn3.ldstatic.com/original/4X/7/e/6/7e68dbe728997407039469f17b3f4587a5fa4c9e.png)
接下来 来到1panel面板，点击 应用商店 - 同步本地应用 然后关闭弹窗
[1920×927 119 KB](https://cdn3.ldstatic.com/original/4X/f/b/4/fb462b6effb93d9db798df1d13b468fedf445d4f.png)
**（！！！目前komari已经上架了1panel官方应用商店，可以直接从下面的步骤开始了）**

接下来输入 komari ，点击搜索，点击安装
[1920×927 91.2 KB](https://cdn3.ldstatic.com/original/4X/f/1/c/f1c4a3b891ff8e9a8c57c2a95b6e8ca9fb0410d7.png)
然后 可选修改端口（一般默认即可），修改管理员用户名和密码，如果不配置反代或需要端口访问，则将 `端口外部访问` 勾选
[1920×927 103 KB](https://cdn3.ldstatic.com/original/4X/a/f/3/af378be7642b44bd6acf9b5a7604c54fa7f7ff71.png)
如果你的服务器位于境外，直接点击确认即可

如果你的服务器位于大陆，那么下拉到底部，勾选 `编辑 compose 文件` ，然后在下方框内将 `ghcr.io/komari-monitor/komari` 替换为 `ghcr.1ms.run/komari-monitor/komari` （1ms.run加速镜像），点击确认
[1920×927 106 KB](https://cdn3.ldstatic.com/original/4X/d/6/f/d6f4cb1dc86d2fcdddbb7621a814da0f15c73199.png)
安装完成，关闭弹窗即可
[960×614 36.5 KB](https://cdn3.ldstatic.com/original/4X/6/8/7/6870946395a86a277622755511cc3e809ebcb231.png)
已经可以在应用商店看到刚刚安装的komari了
[1920×927 110 KB](https://cdn3.ldstatic.com/original/4X/6/6/d/66df8a9e5f8400c2a2692e1e5ee70129344f84d7.png)
### 2.3 （可选）配置反代
1panel面板的反代模板内容很全面，所以为了方便，这里我使用1panel配置反代
点击网站 - 网站 - 创建网站
[1920×927 138 KB](https://cdn3.ldstatic.com/original/4X/8/4/2/842ef8c1232f639a490105363aa7e7e0f1cf686b.png)
选择 反向代理 ，填写你反代komari的域名
如果你是1panel部署的komari，则点击下拉框，点击komari，点击确认
如果你是其它方式部署的komari，则在代理地址里填 `127.0.0.1:25774` （如果你自定义了其它端口则将25774修改为你的端口），点击确认
[1920×927 126 KB](https://cdn3.ldstatic.com/original/4X/4/b/c/4bc7fba9605c65295c1286b1fb888b505291a0ae.png)
如果需要为刚刚创建的网站域名配置证书，则点击配置 - HTTPS - 启用HTTPS，可以在里面配置你的证书，本文不再赘述
[1920×927 138 KB](https://cdn3.ldstatic.com/original/4X/7/e/9/7e93612902780c7955a46fe4f2a8095892d0d951.png)

## 3. 配置 Komari
已经部署完成了，接下来就可以访问并配置komari了
### 3.1 访问komari
如果你配置了反代，则访问你的域名

如果你没有配置反代，则访问 `服务器IP:25774` （如果你自定义了其它端口则将25774修改为你的端口）
点击右上角登录，输入你刚刚设置的账号密码，点击登录
[1920×927 49.8 KB](https://cdn3.ldstatic.com/original/4X/c/8/0/c80eae91034281c3d95d198bf3306460917d24a7.png)

### 3.4 添加服务器节点
进入后台，点击服务器 - 添加节点，可选填写节点名称，点击添加节点
[1920×927 45.1 KB](https://cdn3.ldstatic.com/original/4X/1/0/5/1057d15386ed132bdb1e848c0c070f6503289834.png)
点击一键部署指令按钮，根据服务器的类型和自己所需自行选择安装选项，如果是大陆机器，可以勾选**Github代理**，然后填写 `https://ghfast.top/` （目前可用，可能随时不可用，建议自己寻找），点击复制
[1920×927 68.2 KB](https://cdn3.ldstatic.com/original/4X/5/c/5/5c5006d88dee101e76280bad788980fd4fbd3d2b.png)
