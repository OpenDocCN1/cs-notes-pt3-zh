## 1.2 简单的神经网络

### 1.2.2 非线性神经网络

正文部分我们只讲一种非线性神经网络，即最经典、最容易理解的**多层感知机(Multi-layer Perceptron, MLP)**。

我们依然从一个最简单、层数最少的3层感知机出发，便于大家理解MLP的概念。

[image356×187 26.1 KB](https://cdn3.ldstatic.com/original/4X/6/1/c/61c83a1cd766c30179ab0289b68cd5d88fa3207d.png)

从图([图源](https://zh.d2l.ai/chapter_multilayer-perceptrons/mlp.html))中可以看出，MLP分为3层：输入层，隐藏层、输出层。我们记：

- 输入层变量 X \in \mathbb{R} ^ {1 \times p} ，表示 p 维特征

- 隐藏层变量 H \in \mathbb{R} ^ {1 \times h} ，表示 h 维的隐藏层中的信息

- 输出层变量 O \in \mathbb{R} ^ {1 \times q}  ，表示 q 维的MLP输出

- 其中，隐藏层、输出层的每个维度的变量，都是该神经网络中的一个**神经元**

注：

- 为什么最简单的MLP为3层？因为只有一个隐藏层，而输入层、输出层又是必不可少的，因此为 1+1+1 = 3 层

- 还有一种记法，是输入层不计入层数，那么此时最简单MLP为2层

它的计算过程为：

- H = \sigma(W_1 X + b_1) ，其中， W_1, b_1 分别为输入层到隐藏层的权重、偏置，**函数 \sigma(\cdot) 为激活函数**

- O = W_2 H + b_2，其中， W_2, b_2 分别为隐藏层到输出层的权重、偏置

可以看出，它和2层线性神经网络的计算是极为相似的，仅仅是在隐藏层参数计算时多了一个激活函数 \sigma(\cdot) 。它是一个非线性的函数，为了便于理解，我们可以先认为 \sigma(x) = max(0 ,x) 。

那么，其实n层的MLP也是一样的， 1 个输入层，1 个输出层， n-2 个隐藏层。（图源）

[image850×675 100 KB](https://cdn3.ldstatic.com/original/4X/1/8/6/1866dca8474f979b4c75f74b5808bc4cab6f993c.jpeg)

接下来，我们解释为什么要有激活函数。

#### 激活函数

让我们想想线性神经网络有什么缺陷，它的计算过程是完全线性的。而现实中的很多规律是非线性的，仅通过对特征进行简单的线性变换，无法建模出符合该规律的模型。因此，我们希望**通过非线性的激活函数，使得神经网络能够建模出更复杂的非线性规律**。

**例子——GPT juice值质量检测**

判别方法见，[ChatGPT降智检测方法(依旧为Juice)](https://linux.do/t/topic/1245012)

如果简单地认为 juice < 24 为降智模型，反之则为正常模型，那么我们可以轻易地用线性神经网络做判别模型：

y=juice-24

这里，权重、偏置分别为 1, -24 ；



当 y \ge 0 时，我们判别该GPT模型为正常的；



当 y \le 0 时，我们判别该GPT模型被降智了。

而我们知道，实际上juice值越大，GPT智商未必越好,见 [微软E3的gpt5.2 juice值8192，有人超越吗？](https://linux.do/t/topic/1303140)

假设 24 \le juice \le 1024 时，才认为GPT表现正常，否则降智。那么此时，没有任何一个线性神经网络能够建模出juice智商判别准则。

此时，我们使用阶跃激活函数 \sigma(x) = \mathrm{step}(x)= \begin{cases} 1,& x\ge 0\\ 0,& x<0 \end{cases}



易构建出一个3层感知机：

\begin{bmatrix}h_1\\h_2\end{bmatrix} =\mathrm{step}\Big( \begin{bmatrix}1\\-1\end{bmatrix}x+ \begin{bmatrix}-24\\1024\end{bmatrix} \Big),\quad y=h_1+h_2-1.5

当 y>0 时，我们判别GPT表现正常；反之，GPT降智。

**常见激活函数**

刚才我们提到了两个激活函数，分别是

- ReLU 激活函数 relu(x) = max(0, x)

- 阶跃激活函数 \mathrm{step}(x)= \begin{cases} 1,& x\ge 0\\ 0,& x<0 \end{cases}

实际上，常用的激活函数还有

- Sigmoid函数 sigmoid(x) = \frac{1}{1+e^{-x}}

- Tanh函数 \tanh(x)=\frac{e^x-e^{-x}}{e^x+e^{-x}}

- …

## 拓展阅读

### 线性神经网络缺陷的另一种理解

除了干瘪的说无法表示非线性之外，这里我们给出线性网络表达能力不足的另一种视角。

考虑一个2层线性神经网络，有：

O = W_2 (W_1 X + b_1) + b_2 = O = W_2 W_1 X + W_2 b_1 + b_2

令 W = W_2 W_1,\quad b = W_2 b_1 + b_2，有

O = W X + b

我们可以发现，2层线性变换，可以转化为1层线性变换。

依次类推，n层的线性神经网络，其实也等价于某个1层的线性网络。

反之，加上激活函数的非线性网络则不存在这种问题。

### 通用近似定理（万能近似定理）

这个定理描述的是：非线性神经网络的上限很高，哪怕只有一个隐藏层，只要神经元数量够多，就可以对任意的函数进行逼近。

理论上3层MLP就可以拟合任意函数，那为什么还需要叠加更多的层数、设计不同结构的神经网络呢？

- 该定理只给出了非线性神经网络的效果的上界，并没有考虑到效果的收敛效率、参数量、下游任务的契合程度与泛化性。

数学表述：



令 K\subset \mathbb{R}^d 为非空紧集，\sigma:\mathbb{R}\to\mathbb{R} 为**连续**且**在某个区间上不等于任何多项式**的函数。考虑函数类

\mathcal{N}=\left\{x\mapsto \sum_{j=1}^m a_j\,\sigma(w_j^\top x+b_j)\;:\; m\in\mathbb{N},\ a_j\in\mathbb{R},\ w_j\in\mathbb{R}^d,\ b_j\in\mathbb{R}\right\}

则 \mathcal{N} 在 C(K) 中稠密：对任意 f\in C(K) 与任意 \varepsilon>0，存在 g\in\mathcal{N} 使得

\sup_{x\in K}|f(x)-g(x)|<\varepsilon

感兴趣的话，可以阅读《Multilayer feedforward networks with a nonpolynomial activation function can approximate any function》，这篇论文中有该定理的详细证明，最早给出并证明了通用近似器的充要条件。
