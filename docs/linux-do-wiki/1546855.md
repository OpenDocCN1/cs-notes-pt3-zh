# [教程]无需本地上传，Netcup 服务器安装自定义 ISO 镜像

> 以 Debian 13 为例，本文详细记录在 Netcup 服务器控制面板（SCP）中，上传并挂载自定义 ISO 镜像重装系统的操作步骤。
>
> **原文链接** [Netcup 服务器安装自定义 ISO 镜像 | Dejavu's Blog](https://blog.dejavu.moe/posts/reinstall-netcup-server-using-custom-iso/)
## 上传 ISO 镜像
登录 Netcup SCP 控制台，点开虚拟 DVD 驱动器 (DVD Drive)
[dvd-drive2000×699 53.1 KB](https://cdn3.ldstatic.com/original/4X/8/8/9/8893ccc3a9bfacfa402c5a0ff2a8791d0d183898.webp)
以 Debian 13 为例，在官网获取最新镜像下载地址：
```
https://cdimage.debian.org/debian-cd/current/amd64/iso-cd/debian-13.3.0-amd64-netinst.iso
```
在服务器上下载 ISO 文件
```
wget https://cdimage.debian.org/debian-cd/current/amd64/iso-cd/debian-13.3.0-amd64-netinst.iso
```
填入文件名 `debian-13.3.0-amd64-netinst.iso`，点击 **Generate URL** 生成上传通道。
[iso-filename2000×760 48.2 KB](https://cdn3.ldstatic.com/original/4X/b/a/c/bac871c6dd37b94998857103418a0b3d91492f27.webp)
复制生成的链接，在刚才下载镜像的服务器中执行上传
[copy-upload-url2606×1267 96.1 KB](https://cdn3.ldstatic.com/original/4X/d/0/5/d05ee3a960bd69a5a7a73d1cab643962b0bf9dff.webp)
## 引导自定义镜像
在菜单中选中上传的 ISO 文件，设为启动项
[select-iso2595×1046 54.3 KB](https://cdn3.ldstatic.com/original/4X/8/a/d/8ad59ca2ac8308d8493d93c536f48b9a8c1bc9da.webp)
重启服务器，系统将从该自定义镜像引导启动
[reboot-iso2200×770 63 KB](https://cdn3.ldstatic.com/original/4X/4/9/1/49117d64092d6504cc00c55faf6730ff5e404ae1.webp)
## 开始安装
打开网页版 VNC，开始安装系统
[start-vnc2200×1125 70.5 KB](https://cdn3.ldstatic.com/original/4X/4/c/2/4c2ed7c0b1277aa1251779bd164e55e73ec0866a.webp)
选择「Install」进入纯文本安装模式
[text-install1671×1267 37.3 KB](https://cdn3.ldstatic.com/original/4X/d/a/1/da1e66aa389e45b52e10ef232c747aa618ab42e7.webp)
## 配置步骤
常规选项（语言、区域、键盘、网络、主机名、账户、时区）按需选择或填写，重点关注：
- **分区向导：** 一般选择 `Guided - use entire disk`，方案选择 `All files in one partition` 比较省事
- **分区表微调：**

删除 swap 分区，安装后手动配置更灵活

保留 ESP 引导分区

剩余空间都分配给根目录

确认无误，写入修改

[partition-done2591×862 54.9 KB](https://cdn3.ldstatic.com/original/4X/d/f/4/df4aa386b9fd3e7a660f0f76613a1f34487f7742.webp)
- **软件包选择：**

`SSH server`
`standard system utilities`
安装完成后，记得先卸载虚拟光驱，然后再重启系统。
[detach-dvd3233×1104 85.3 KB](https://cdn3.ldstatic.com/original/4X/0/f/8/0f8d5ad344d798901776099ce4c05344ed70aece.webp)
