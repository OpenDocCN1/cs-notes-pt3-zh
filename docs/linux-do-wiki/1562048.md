# 【IDE系列1】Antigravity运行Codex插件无法登录403，提问Reconnecting解决办法



为了比较gemini-3-pro，opus-4.5，5.2-codex-xhigh的效果，我在Antigravity里装了Codex插件

闲鱼几块钱买个ChatGPT business试用号月抛测试

Codex插件如果在市场里找不到，就到这里下载[Open VSX Registry](https://open-vsx.org/extension/openai/chatgpt)

---

### 登录403问题

Antigravity登录codex插件时显示Token exchange failed: token endpoint returned status 403 Forbidden

Cursor里登录codex无此问题

### 原因

Antigravity是运行在沙盒环境中的，导致localhost被Windows的网络隔离策略拦截了。

### 办法

Windows搜索栏搜Terminal → 以管理员权限运行



CheckNetIsolation LoopbackExempt -a -n=“Antigravity_pzq3xp76mxafg”



然后再登录就可以了

---

### 提问reconnecting问题

原因：是插件里的codex.exe没有走vpn

办法1：梯子开Global模式就好了。



注：pac.txt添加chatgpt.com没用

办法2：Antigravity → Preference → Online Service Settings → 搜索http.proxy → 填[http://127.0.0.1](http://127.0.0.1):xxxx → 重启Antigravity



xxxx是你的vpn端口，一般触碰vpn图标或设置会显示



设置后不管vpn是否开global，都可以用codex
