# 在论坛，我能得到什么？

- 你的论坛账号可以登录接入了 LINUX DO Connect 的站点！例如：



[Shared Oaifree](https://shared.oaifree.com)：ChatGPT 账号共享站点，无限 `gpt-4o` 使用

[New Oaifree](https://new.oaifree.com)：[你以为OAIFree只是帮你免梯吗？](https://linux.do/t/topic/122674)

[DeepLX](https://connect.linux.do)：免费的 DeepL API 服务，可用于沉浸式翻译 [DeepLX已切换至 LINUX DO Connect 认证](https://linux.do/t/topic/111737)

【前面的区域，以后再来探索吧】

- 论坛有非常多热心的大佬，能帮助你解决从技术到生活中的许多问题

- 论坛虽然叫 LINUX DO，但不仅仅是技术论坛，更是一个开放包容、鼓励**可能性**的社区。你可以分享自己遇到的好的软件、生活中的挫折等等，一切内容都可以存在。

- 论坛实行 Discourse 的等级制度，又称为信任等级（Trust Level），一级、二级、三级分别有一个分区，存放一些好东西！不想错过的话请尽快升级。详情请见 [Discourse 论坛权限等级表](https://linux.do/t/topic/18797)

# 在论坛，我需要注意什么？

- **链接带 aff 需要说明；禁止在聊天频道打卡；AIGC的文字需截图，不能直接引用。**

- **约法三章**：[https://linux.do/faq](https://linux.do/faq)

- **真诚**：回帖时真心相助，拒绝回复既不利于解决问题，又不利于活跃氛围和顶贴的垃圾内容，尽量不要水贴

- **友善**：拒绝所有恶意回复、阴阳怪气（非恶意开玩笑除外）、煽动仇恨、群体对立、引站内容

- **团结**：不拉帮结派，不搞左右两派，坚持民主集中制的原则，对领导（始皇）有意见的，在坚决执行的前提下可以保留

- **专业**：在提问前，务必使用搜索引擎或生成式人工智能技术先检索一遍，不要把非常简单的一搜就知道怎么做的问题搬上来问！很少人会有耐心回答 除非为了水贴。同时，请不断学习并提高自己的能力，不要觉得什么事一挂论坛就能解决，**应自觉提升论坛整体技术水平，为实现论坛高质量发展而做出贡献**。

- **守法**：坚持党的领导，爱党爱国。为了论坛长久存在，不能讨论涉及国内政治、违法、犯罪、色情、毒品、暴力等内容
