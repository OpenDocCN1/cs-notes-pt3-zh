# 飞牛OS 笔记本 合盖关屏保持运行，设置屏幕关闭不休眠



打开NAS中的SSH功能

[image1523×304 9.42 KB](https://cdn3.ldstatic.com/original/4X/6/0/d/60dbb1502ffa4c0dd23535a4873c93ed10fb02b2.png)

# 编辑电源管理配置文件

sudo nano /etc/systemd/logind.conf

# 修改以下参数：

1. `HandleLidSwitch=ignore`：无论何时合盖，都忽略该动作（不休眠）。

2. `HandleLidSwitchExternalPower=ignore`：接电源时合盖不休眠。

3. `HandleLidSwitchDocked=ignore`：连接扩展坞时合盖不休眠。

# 保存后重启服务

sudo systemctl restart systemd-logind

# 或者直接重启NAS

reboot

建议**不要完全合死屏幕**，可以在中间夹一个小东西留一条缝，以免过热导致硬件降频或关机。
