# 3 参与

恭喜佬，成功加了LINUX DO社区。接下来，佬需要知道点“知识”才能更好地“参与”LINUX DO社区。

首先，LINUX DO社区基于Discourse论坛建立，而其中信任系统是Discourse的重要基石。

简单理解，参与并活跃在社区，对社区有所贡献，就可以获取信任，提升等级。

## 3.1 LINUX DO的信任体系

### 3.1.1 成员等级

在Discourse论坛下，成员的信任等级又叫成员等级。当佬刚进入社区时，您是新用户，等级为0，即LV0；当佬进入社区一段时间，阅读贴子，满足条件后就可以升到LV1，经过一段时间，持续的参与并活跃在社区，可以逐步升级到LV2，LV3…

(PS:请留意，如果不活跃在社区的话，LV3等级的成员会降回LV2，LV3等级用户需要持续满足LV3用户的晋升条件)。

### 3.1.2 关于信任体系的补充说明

信任体系实际上由如下两部分构成。

一部分是以“硬性条件”为代表的等级体系，另一部分是以“软性条件”为代表的以徽章及违规数计算的“*社区分数*”及评价活跃程度的*Leaderboard点数*。其中“硬性条件”就是下文的“成员等级晋升条件”，此外“软性条件”是指的获取的徽章数量，请参考下文“社区分数”。

更多相关信任体系的说明可以参考如下链接：

站内关于信任等级的说明：[信任体系参考|【新人请看】了解Discourse信任度](https://linux.do/t/topic/2460)

（PS:关于上文的补充说明原文可以参考：[信任体系官方说明|Understanding Discourse Trust Levels](https://blog.discourse.org/2018/06/understanding-discourse-trust-levels/)）

站内关于信任等级的具体权限说明：[信任等级权限说明|Discourse 论坛权限等级表](https://linux.do/t/topic/18797)

## 3.2 成员等级晋升条件（硬性条件）

从LV0到LV3的“升级”都有需要满足一定的“硬性条件”，需要长时间的参与社区。



具体可以参看：[信任体系参考|【新人请看】了解Discourse信任度](https://linux.do/t/topic/2460)

### 3.2.1 从LV0达到LV1

从LV0升级到LV1需要满足如下条件：

- 进入至少**5**个话题

- 阅读至少**30**篇帖子

- 总共花费**10**分钟阅读帖子

### 3.2.2 从LV1达到LV2

从LV1到LV2需要满足如下条件：

- 至少访问**15**天，不必连续

- 至少点赞**1**次

- 至少收到**1**次点赞

- 回复至少**3**个不同的话题

- 进入至少**20**个话题

- 阅读至少**100**篇帖子

- 总共花费**60**分钟阅读帖子

（PS：最快也需要15天）

### 3.2.3 从LV2达到LV3

从LV2到LV3需要满足如下条件：

- 必须至少访问了 **50%** 的天数（过去100天内）

- 必须至少在**10**个不同的非私信话题上进行了回复

- 在过去100天内创建的话题中，必须浏览了**25%**（上限为500）

- 在过去100天内创建的帖子中，必须阅读了**25%**（上限为20k）

- 必须收到**20**个点赞，并送出**30**个点赞。*

- 不得收到超过5个垃圾邮件或冒犯性标记（每个都需不同的帖子和不同的用户，并由版主确认）

- 过去6个月内不能被暂停或禁言

（PS：最快也需要连续登录50天，每日凌晨4.00统计升级到LV3的资格）

### 3.2.4 LV3及以上

暂无“自动”升级，需要“管理者”用“手动”的方式晋升。

## 3.3 查看自己的等级状态

### 3.3.1 通过徽章

每升一级社区都会给佬发放一份身份徽章同时系统会以消息的形式提示信任等级提升，当达到LV1等级后，获得基本用户徽章；当达到LV2等级后，获得成员徽章；当达到LV3等级后，获得活跃用户徽章；之后的等级徽章为领导者徽章。

### 3.3.2 通过Connect

在等级LV0、LV1时，您只能通过[查看等级|LINUX CONNECT](https://connect.linux.do?u=slixdo)查看自己具体的等级，如有升级需求，可以参考“成员等级晋升条件”结合“个人信息-总结栏”一一判断。

当佬达到LV2时，同样可以通过[查看等级|LINUX CONNECT](https://connect.linux.do?u=slixdo)查看自己等级，初次之外，下方还实时展示达到LV3的进度。

### 3.3.3 通过插件

如果佬也想在LV1时实时查看自己达到LV2时的一个进度，可以考虑佬友开发的插件，如佬开发LDStatus Pro…

## 3.4 社区分数（软性条件）

信用体系的另一个方面是以计量的方式综合活跃及贡献进行评价的软性方面，其指标一个为*社区分数*，它代表了社区对佬的信任分数，它主要以获取的徽章来衡量，简单来说，徽章数量越多，社区分数也就越高。另一个指标为*Leaderboard点数*。

### 3.4.1 社区分数查看

关于社区分数的定义其实只在CDK（社区内容分发平台）中有提及，通过元宇宙下的分发站可以访问CDK平台。

访问链接[社区分数查看|CDK分发站](https://cdk.linux.do?u=slixdo)，进入CDK站后查看个人信息，可以查询到社区分数。

### 3.4.2 作用

佬有时候通过CDK发布批量的“兑换码”，但不是每位佬都能顺利领取，因为佬在发布时对领取的佬做了限制，只有满足条件的佬才能领取。

这个条件一般是三个方面：最低用户分数、信任等级、IP限制。其中的最低信用分数就是指的社区分数。

### 3.4.3 增长方式

最有效的方式就是通过获取徽章的方式，获取的徽章越多，增加得就越快。

具体可以参考社区内佬的[徽章获取方式|盘点L站的徽章 长期更新！](https://linux.do/t/topic/342888)

## 3.5 Leaderboard 点数（软性条件）

Leaderboard点数，又可以称“社区点数”，是以量化的方式评价佬的活跃度及对社区的贡献。

### 3.5.1 查看点数

- 通过Leaderboard排行榜可以查看佬自己的点数（位于：左侧栏-更多-Leaderboard）

- 通过社区个人信息栏，在顶部用户右侧有个展开按钮，点看后，可以看到点数。

根据始皇的20260105发布的最新政策，最新点数获取方式以为社区做贡献为主，否则只有“低保”。参考链接[Leaderboard点数最新获取方式|别刷了，别刷了，服务器顶不住了](https://linux.do/t/topic/1409175)，只有如下方式可以获取点数。

## 4.1 LUNIX DO社区“福利”

### 4.1.1 LDC积分

#### ①LDC积分用户

LDC，全称为“LINUX DO Credit”，是基于社区孵化的通用交易点数。使用LDC可以在积分乐园和其余佬换取所需，另外各位佬也在社区开启了LDC小店，使用LDC进行交易。可以换取如API额度、Gemini成品号…

更多“玩法”等待佬去探索。

#### ②LDC的获取

LDC是基于Leaderboard点数但是又不完全等同。

首先，只有参与了LDC系统，之后才可以获取LDC积分。

首次注册LDC，可以获取50LDC点数，LDC系统注册地址[LDC系统链接](https://cdk.linux.do/dashboard?u=slixdo)。

注册时，LDC系统会记录佬当前状态的Leaderboard点数，之后每天凌晨会把前一天变化的Leaderboard点数转换为LDC积分划入个人系统中。

更多关于LDC系统，请参考[「LINUX DO Credit」正式发布！](https://linux.do/t/topic/1353336)

### 4.1.2 DeepLX 翻译密钥

这是由社区，也可以叫由始皇为各位佬提供的“福利”。

### 4.3.2 公益站管理-ALL API HUB

是否苦恼于自己一时注册了太多公益站，而之后回过头会忘记注册了哪个公益站？这个问题早有佬想到并进行了解决，社区的佬基于此开发了“ALL API HUB”——浏览器扩展插件。

#### 功能说明

详细功能参考：[All-API-Hub：开源AI中转站集中管理和自己的New API增强管理，基于 one-api-hub 大幅重构增强](https://linux.do/t/topic/1001042)

## 5.1 一些建议

#### 5.1.1 关于“富可敌国”——甄别

佬，会看到一些API站话题中带有“富可敌国”字样，同时带有“高级推广”的标签，发帖人戴“富可敌国”的头衔。这表示这个API站是以盈利为目的；而非社区的佬“用爱发电”的公益站。简单来说，“高级推广”的API站是由商家运营的，他们的贴子是在LINUX DO社区做广告（请理解，这是社区运转资金的来源）；同时请注意社区并不对该商家负责，请注意自行甄别。



（PS：根据[社区准则](https://linux.do/guidelines)，社区禁止发放邀请码AFF推广，同时注意遵守社区准则进行公益及非公益推广；违规推广，账号会被举报或封号处理）

#### 5.1.2 “已认证”——获取徽章

当佬注册成功进入论坛后，会收到系统发送的通知消息，提示和机器人互动完成新用户教程，请参与互动。这可以帮助佬获得“已认证”徽章，该徽章可以提高佬的社区分数，越过一些门槛，同时一旦在当前等级错过后，（即社区等级提升）之后无法再获取。

### 5.1.3 “CDK”注册——获取积分

当佬成功注册LINUX DO后，建议优先直接注册“CDK系统”，链接为[LDC系统链接](https://cdk.linux.do/dashboard?u=slixdo)，之后佬的每次“有效操作”都可以转换为“LDC”。(LDC积分可以理解为社区通用价值兑换物)

### 5.1.4 “邮箱回复”——接受or拒绝

在默认情况下，其他佬回复给您的贴子都会发送到佬注册的邮箱中。



如果觉得此类邮件回复接受太多，可以手动关闭，该设置位于个人中心-偏好设置-电子邮件，具体设置可参考下图。

![邮件相关设置1343×568 30.4 KB](img/be8517955df58973e98a639b248a496d.png)

- 一、回复到对方邮箱地址需要包含一段hash值，该回复才会正确回复显示。

- 二、如果使用网易邮箱大师或其他邮箱软件回复，存在直接暴露您的注册邮箱的风险，请注意。
