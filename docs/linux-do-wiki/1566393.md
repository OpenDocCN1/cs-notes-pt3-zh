# 飞牛OS 防火墙错误设置无法访问

[飞牛OS 关闭公网访问，只允许局域网访问](https://linux.do/t/topic/1566342)
需要在物理机上操作，给飞牛主机接上**显示器和键盘**。输入用户名和密码登录。
如果不知道密码可以grub引导下按e，重置密码。
> Grub编辑界面中，找到以Linux开头最长的行，在这行的末尾添加init=/bin/bash，行中的ro改为rw。然后按Ctrl+x启动系统。使用passwd root命令重置root密码。先输入passwd，然后按提示输入新密码并确认。长按电源键重启就可以生效。
执行以下命令立即终止防火墙进程，此时 Web 界面应该可以打开了
```
systemctl stop security_service.service
```
**备份防火墙配置原文件**：
```
cp /usr/trim/etc/fw.conf /usr/trim/etc/fw.conf.bak
```
**清空配置文件**： 执行编辑命令：
```
nano /usr/trim/etc/fw.conf
```
- 删除所有字符，Ctrl + S保存内容，Ctrl + X退出编辑器。
**重启防火墙服务**：
```
systemctl restart security_service.service
```
1. 系统重启后，浏览器访问飞牛OS后台。
2. 进入 **“防火墙设置”**。
3. 此时防火墙默认为 **“关闭”** 状态，原错误规则已清除。
4. 点击 **“开启”** 重新配置规则。
