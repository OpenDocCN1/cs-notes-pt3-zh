## 服务器初期配置

大致流程



DD服务器 → 修改云服务商安全组策略 → 换源 → 简单配置并记录一个快照



中间可能会出现命令缺失导致执行失败的情况，自行安装即可

如果需要下载什么github脚本



可搜索cdn、ghfast.top或站内socks5代理，如 [socks5](https://linux.do/t/topic/1556878)

---

From [GitHub - bin456789/reinstall: 一键DD/重装脚本 (One-click reinstall OS on VPS)](https://github.com/bin456789/reinstall)

修改下方的`bash reinstall.sh`的端口、公钥及密码

执行完记得reboot，即可开始重装



可在云服务商的*救援系统*界面或者在上一步指定`--web-port xxx`参数来观察重装进度

```
curl -O https://cnb.cool/bin456789/reinstall/-/git/raw/main/reinstall.sh || wget -O ${_##*/} $_

chmod u+x reinstall.sh

bash reinstall.sh debian 12 --ssh-port xxx --ssh-key "" --password xxxx
```
