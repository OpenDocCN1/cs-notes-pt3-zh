# 以人话理解 Claude Opus 4.6 计费模型/其他模型！

首先，Claude Opus 4.6 100万（1M) 上下文窗口是用来做什么的？
答：是为了更容易理解，你可以想象他能一次性读取你系统的所有代码/更多代码。
这时候充满智慧的您，会问什么是token？
很简单哈，1个token 大约相当于3~4个字符 (character)
所以 1000个token 大约相当于700~800个单词
1M就是大约为75万字或1500页A4
Nah, 理解了这些那什么是上下文窗口 (Context Window) ？

当他说 Context Windows上下文是100万时。这意味着他可以接受并处理1m token 处理。
哈哈懂了吗？最后就是您关心的费用又如何计算？
例如Claude Opus 4.6 的计费是$5/$25 per Mtok，也就是说每 1m 个 Token 收费 $5（输入）。
简蛋理解就是你输入指的是你发送给 AI 的内容（文字或指令）
然后每1m Token收费$25，输出是 AI 返回给你的内容，例如它写给你的回复或生成的代码
