# LOL台服/国际服直连方法



不少佬友可能会玩LOL台服/国际服，但是受锁区影响，通常只有港澳台坡的网络能够登陆游戏，而且会限制机房IP，主流的云服务商基本都被锁了，这就导致通常需要专门的加速器才能游玩游戏。

由于LOL目前具有有两个特点：（1）云服务容器化+统一入口anycast；（2）IP限制，锁登陆，不锁游戏对局。因此可以通过“TUN模式 + 绕过大陆通用规则 + 对局直连规则”的方式，实现LOL台服的顺畅游玩。

唯一需要的，就是非主流云服务大厂的港澳台坡节点。

下面用V2rayN作为演示：



(1)打开“设置-路由设置”，双击“V4-绕过大陆(Whitelist)”，添加规则让“151.106.0.0/16,13.214.0.0/16”走udp直连。如下图

![image1796×1256 200 KB](https://cdn3.ldstatic.com/original/4X/3/2/e/32e51cd3c9f391a054805300af43053e83a54a83.png)

这样设置好以后，就能顺畅登陆和游玩LOL台服。武汉移动实测延迟45ms，对于日常休闲已经完全够用。希望对有需要的佬友有帮助。
