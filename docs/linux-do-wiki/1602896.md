# 技术封建主义介绍--不一样的资本世界

技术封建主义是近年来西方学术界，特别是左翼学者提出的一个批判性概念，用来描述数字资本主义中出现的、类似封建社会的经济剥削和权力控制关系
简单来说，它指的是以谷歌、亚马逊、苹果等为代表的少数科技巨头 ，凭借对数据、算法和平台的垄断 ，建立起类似封建领主的经济和政治统治，普通用户和依附于平台的小企业，则成为提供数据和劳动的数字农奴
早期：概念最早可追溯至1990年代赛博朋克文化，用于描述企业权力膨胀、公共领域瓦解的未来图景

成型：2020年，法国经济学家塞德里克·迪朗出版《技术封建主义》一书，首次从政治经济学角度系统阐述，2024年，希腊前财政部长雅尼斯·瓦鲁法基斯的同名著作引发广泛热议

思想背景：这一概念也源于对加州意识形态的批判，也就是硅谷将技术发展与个人自由、市场至上简单捆绑的新自由主义技术观
我的想法：

资本主义现代化时的退化，利用数据，算力等生产资料，重现了农奴时期，封建时期的等级制度和剥削
其本质，就是资本主义在数字时代的一种退化形态。它并未走向其宣扬的更自由、更开放的未来，反而借助数据、算法、算力等新型生产资料，重构了一种类似封建时代的社会结构，少数垄断了数字基础设施和平台的科技巨头，扮演了类似封建领主的角色，它们通过占有用户产生的海量数据这一核心资产，并控制处理这些数据的算法与算力，建立起封闭的数字领地，广大用户和依附于平台的中小企业，则在不平等的规则下沦为数字农奴，通过无偿或低偿的数据劳动维系系统运转，并接受平台以流量分配、服务抽成等形式进行的数字租金剥削，这一过程不再是传统的、追求效率与创新的工业资本主义剥削，而更像是一种基于数字土地垄断的、稳固的等级制权力依附与经济榨取，标志着资本主义发展中出现了一种反现代性的退化趋势
我认为：

资本主义世界正显示出强烈的技术封建主义发展倾向，这是资本在数字时代寻求垄断固化、将一切社会关系降维为可榨取租金的数据关系的自然结果
然而，历史从来不是线性发展的，我认为：这一趋势必然遭遇来自国家主权、社会运动、资本内部矛盾以及人类对自主性根本需求的多重抵抗，未来更可能是一个技术封建主义逻辑与国家干预、社会反抗、残余的市场竞争和去中心化理想持续博弈和混杂的漫长过程，而我们正身处决定这场斗争走向的关键历史节点之中
**但请同志们放心，未来的世界必将是赤旗的世界！**
