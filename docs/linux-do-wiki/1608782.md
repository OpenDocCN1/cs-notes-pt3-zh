# LINUX-DO-WIKI OpenCode Skill

Linux Do 社区的官方 Wiki 文档站，在线地址：[wiki.linux.do](https://wiki.linux.do)

## Quick Start

```
# 克隆仓库
git clone https://github.com/chenyme/LINUX-DO-WIKI.git
cd LINUX-DO-WIKI

# 安装依赖 (需要 pnpm 10+)
pnpm install

# 开发模式 (端口 3001, 启用 Turbopack)
pnpm dev

# 构建生产版本 (含 Pagefind 索引生成)
pnpm build

# 启动生产服务
pnpm start
```

## Overview

LINUX-DO-WIKI 是 [Linux Do](https://linux.do) 社区的知识库项目，采用社区共建模式维护。内容涵盖社区介绍、服务导航、AI 镜像服务文档、社区百科等。

## Tech Stack

| 层级 | 技术 |

| --- | --- |

| 框架 | Next.js 15 (App Router, Turbopack) |

| 文档引擎 | Nextra 4 (`nextra-theme-docs`) |

| UI | ShadcnUI, AnimateUI (motion), Radix UI |

| 样式 | Tailwind CSS v4, `tw-animate-css` |

| 搜索 | Pagefind (静态搜索索引) |

| 语言 | TypeScript, MDX |

| 运行时 | React 19 |

| 包管理 | pnpm 10 |

### Adding Content

1. 在 `content/` 对应目录下创建 `.mdx` 文件

2. 在对应目录的 `_meta.ts` 中注册页面

3. MDX 中可直接使用 `components/` 下的 React 组件

### Nextra MDX Features

- 支持标准 Markdown + JSX

- 自动生成侧边栏和目录

- 内置代码高亮 (Shiki)

- `_meta.ts` 控制页面顺序和分组

## Key Features

### OAuth2 Login

通过 Linux Do 社区 OAuth2 实现用户登录：

- `app/api/oauth2/route.ts` — 发起授权跳转

- `app/api/oauth2/callback/route.ts` — 处理回调

### Data Proxy APIs

代理 Linux Do 社区数据，用于悬浮卡片等组件：

- `GET /api/topics/[topicId]` — 获取话题信息

- `GET /api/users/[username]` — 获取用户信息

### Interactive Components

- **TopicHoverCard** — 鼠标悬浮显示话题详情

- **UserHoverCard** — 鼠标悬浮显示用户信息

- **CardGrid** — 可复用卡片网格布局

- **ScrollProgress** — 全局阅读进度条

- **AnimateUI** — 基于 motion 的动画组件集

### Search

使用 Pagefind 实现静态全文搜索，构建时自动生成索引：

```
# postbuild 脚本自动执行
pagefind --site .next/server/app --output-path public/_pagefind
```

## Configuration

### Next.js Config (`next.config.mjs`)

```
import nextra from 'nextra'

const withNextra = nextra({ contentDirBasePath: '/' })

export default withNextra({
  images: {
    remotePatterns: [{
      protocol: 'https',
      hostname: 'linux.do',
      pathname: '/**',
    }],
  }
})
```

### Layout Config

在 `app/layout.tsx` 中配置 Nextra 主题：

- `darkMode: true` — 深色模式

- `sidebar.defaultMenuCollapseLevel: 2` — 侧边栏默认展开层级

- `docsRepositoryBase` — 编辑链接指向 GitHub

- 中文本地化 (搜索、更新时间、主题切换等)

## Troubleshooting

| 问题 | 解决方案 |

| --- | --- |

| `pnpm install` 失败 | 确认 pnpm 版本 >= 10，运行 `corepack enable` |

| 搜索不工作 | 需先 `pnpm build` 生成 Pagefind 索引 |

| 图片加载失败 | 检查 `next.config.mjs` 的 `images.remotePatterns` 配置 |

| MDX 组件未渲染 | 确认 `mdx-components.js` 中已注册组件 |
