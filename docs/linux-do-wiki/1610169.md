# Wine的安装和使用

> [!INFO]
>
> Note: [XLY23333](https://blog.xlyz.top)
> OS: Ubuntu 24 LTS
## 安装Wine
### 准备工作
更新apt
```
sudo apt update
```
启动32位系统架构支持
```
sudo dpkg --add-architecture i386
```
### 添加wine源并下载
```
sudo mkdir -pm755 /etc/apt/keyrings
sudo wget -O /etc/apt/keyrings/winehq-archive.key https://dl.winehq.org/wine-builds/winehq.key
```
常见三版本安装
- Ubuntu24：`sudo wget -NP /etc/apt/sources.list.d/ https://dl.winehq.org/wine-builds/ubuntu/dists/noble/winehq-noble.sources`
- Ubuntu22：`sudo wget -NP /etc/apt/sources.list.d/ https://dl.winehq.org/wine-builds/ubuntu/dists/jammy/winehq-jammy.sources`
- Ubuntu20：`sudo wget -NP /etc/apt/sources.list.d/ https://dl.winehq.org/wine-builds/ubuntu/dists/focal/winehq-focal.sources`
更新apt
![:warning:](https://linux.do/images/emoji/twemoji/warning.png?v=15)注意，这里请保证网络畅通，并打开TUN模式
```
sudo apt update
```
下载稳定版wine
```
sudo apt install --install-recommends winehq-stable
```
检查版本是否安装完成
```
wine --version
```
安装Wine的辅助工具Winetricks
```
sudo apt install winetricks
```
## 配置wine
### 自动安装wine-mono
使用`winecfg`启动配置工具，并按照引导安装wine-mono
### 手动安装wine-gecko
在[wine-gecko清华源](https://mirrors.tuna.tsinghua.edu.cn/winehq/wine/wine-gecko/)中选择2.47.4版本(非RC版)，下载其msi格式的32位x86的和64位x86_64的安装包
切换到下载目录并执行下面的命令进行安装
```
wine start /i wine-gecko-2.47.4-x86.msi
wine start /i wine-gecko-2.47.4-x86_64.msi
```
### 检查wine状态
使用`winetricks`，并选择"选择默认的wine容器"->“运行卸载程序”，检查是否成功安装了wine-mono和wine-gecko
[image-20260210003656907505×422 14.6 KB](https://cdn3.ldstatic.com/original/4X/6/f/1/6f1e7aa9367df064a8fdbd74bc3d197e9c53a709.webp)
### 安装其他依赖
安装常用字体和DirectX
```
winetricks allfonts corefonts cjkfonts
winetricks d3dx9 d3dx10
```
