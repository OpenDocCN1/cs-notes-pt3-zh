# build tunnel for（你局域網常用的那個設備）

for install cf

```
sudo pacman -S cloudflared
```

login your account

```
cloudflared tunnel login
```

create tunnel

```
cloudflared tunnel create home-arch
```

run tunnel (當然這裡你可以讓她持久運行）

```
cloudflared tunnel run home-arch
```

for long run (不是很重要就不解釋了 可以問問ai 怎麼做到的）

```
sudo cloudflared service install "$(cloudflared tunnel
  token home-arch)" && sudo systemctl enable --now
  cloudflared
```
