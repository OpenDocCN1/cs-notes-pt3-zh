35.terminal输入以下命令

```
$cfg = @'
{
  "type": "stdio",
  "command": "uvx",
  "args": [
    "--from",
    "git+https://github.com/GuDaStudio/GrokSearch@grok-with-tavily",
    "grok-search"
  ],
  "env": {
    "GROK_API_URL": "在这里粘贴你的url",
    "GROK_API_KEY": "在这里粘贴你的_GROK_API_KEY",
    "TAVILY_API_KEY": "tvly-在这里粘贴你的_TAVILY_API_KEY",
    "TAVILY_API_URL": "在这里粘贴你的tavily url"
  }
}
'@

claude mcp add-json grok-search --scope user $cfg
```
