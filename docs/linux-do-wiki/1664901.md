# V2RayN macOS初次安装报错的解决方案记录



（试图把L站当成笔记，顺便也可能帮到一些刚上手Mac或者像我一样试图从clash verge rev换成v2rayN的佬友）

在从

### [GitHub - 2dust/v2rayN: A GUI client for Windows, Linux and macOS, support...](https://github.com/2dust/v2rayN)

A GUI client for Windows, Linux and macOS, support Xray and sing-box and others

下载安装.dmg之后，第一次运行会提醒已经损坏，要不要移到垃圾桶，这时候不要移动，在终端输入`sudo xattr -d com.apple.quarantine /Applications/v2rayN.app`就可以打开了，然后如果要启动TUN模式的时候，又会报关于singbox和xray的错，这时候继续使用命令 `sudo xattr -d com.apple.quarantine /Users/XXXXX（你的用户名）/Library/Application\ Support/v2rayN/bin/sing_box/sing-box`和`sudo xattr -d com.apple.quarantine /Users/XXXX（你的用户名）/Library/Application\ Support/v2rayN/bin/xray/xray`就能解决问题了～【叠甲：本帖不涉及任何不合规内容】
