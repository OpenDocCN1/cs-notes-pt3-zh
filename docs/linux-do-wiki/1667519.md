### 回到Cloudflare后端Workers配置参数

#### TELEGRAM_BOT_TOKEN

参数类型：文本

```
843XXXX:AAF2XXXXXXXXXXXXXXXXXXXXXX
```

解释：就是从上面获取的Bot Token，不要外泄啦！

---

#### TG_MAX_ADDRESS

参数类型：文本

```
2
```

**我这里出于安全原因只给了两个，佬友们可以根据自己需求改**

解释：每个 TG 用户最多绑定几个邮箱，不配则不限

---

### TG_BOT_INFO

通过接口获取一下：[https://api.telegram.org/bot](https://api.telegram.org/bot)<你的BOT_TOKEN>/getMe

**注意：https://api.telegram.org/bot<这里填token不要删前面的bot>/getMe**

示例：

> [https://api.telegram.org/bot7123456789:AAF1234567890abcdefghijklmnop/getMe](https://api.telegram.org/bot7123456789:AAF1234567890abcdefghijklmnop/getMe)

参数类型：JSON

```
{
  "ok": true,
  "result": {
    "id": XXXXXX,
    "is_bot": true,
    "first_name": "临时邮箱机器人",
    "username": "XXXX去获取你自己机器人的信息",
    "can_join_groups": true,
    "can_read_all_group_messages": false,
    "supports_inline_queries": false,
    "can_connect_to_business": false,
    "has_main_web_app": false,
    "has_topics_enabled": false,
    "allows_users_to_create_topics": false
  }
}
```

作用：预定义 Bot 信息，减少 Webhook 延迟

---

#### TG_ALLOW_USER_LANG

参数类型：文本

```
true
```

解释：允许用户用 /lang 命令切换语言
