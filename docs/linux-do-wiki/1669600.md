# windows系统用inter显卡玩ComfyUI

> 由于我的电脑是Intel B580显卡，而这类显卡无法直接使用NVIDIA的CUDA加速ComfyUI。为了能体验和运行ComfyUI，我记录了这套基于Anaconda部署，并利用Intel官方优化PyTorch版本的完整流程。
>
> [image520×341 13.7 KB](https://cdn3.ldstatic.com/original/4X/d/b/c/dbcf3ea7c5436052c42cae2e88bdb56a5073b5c3.png)
> 本帖旨在帮助使用Intel显卡 (如Intel Arc或集成显卡) 的用户，通过Anaconda部署ComfyUI，并配置Intel官方优化的PyTorch版本，以充分利用GPU性能。
## 前置条件
在开始部署 ComfyUI 之前，请确保您的系统已安装以下必要的软件工具。它们是后续所有步骤的基础。
> [!note]- 必要条件
>
> **Anaconda**: 用于创建和管理 Python 虚拟环境，确保 ComfyUI 运行环境的独立性和稳定性。
> **Git**: 用于从 GitHub 克隆 ComfyUI 官方仓库。当然也可以手动下载
---
## 安装前置软件
### 安装 Git
1. 访问 [Git 官方网站](https://git-scm.com/downloads)
2. 根据您的操作系统下载对应的安装包（通常是 Windows 64-bit Git for Windows Setup）
3. 安装Git，无脑下一步即可
### 安装 Anaconda
1. 访问 [Anaconda 官方网站](https://www.anaconda.com/download/success)
2. 下载适用于您操作系统的最新版本Anaconda安装包
3. 在安装过程中，建议勾选“Add Anaconda to my PATH environment variable”，以便后续在任何命令行中都能直接使用`conda`命令。
---
## 下载 ComfyUI
1. 选择一个希望安装 ComfyUI 的磁盘和目录，例如 `D:\` 盘下的某个文件夹。
2. 按下 Win + R 组合键，输入 `cmd` 并回车，打开命令提示符。
3. 在 `cmd` 窗口中，首先切换到您计划安装 ComfyUI 的盘符。例如，如果要在 `D:` 盘安装，输入 `D:` 并回车。
4. 然后，执行以下 `git clone` 命令将 ComfyUI 官方仓库克隆到本地：
`git clone https://github.com/comfyanonymous/ComfyUI `

[!tip]

完成后，您将在 `D:\ComfyUI` 下看到一个名为 `ComfyUI` 的文件夹。后续操作都将在此目录下进行。
---
## 创建并配置 ComfyUI 虚拟环境
为了避免潜在的依赖冲突，强烈建议为 ComfyUI 创建一个独立的 Python 虚拟环境。
1. 从 Windows 开始菜单中搜索并打开 `Anaconda Prompt`。
2. 在 `Anaconda Prompt` 中，执行以下命令创建一个名为 `venv` 的虚拟环境，并指定 Python 版本为 `3.12`。请务必将 `D:\ComfyUI` 替换为您实际的 ComfyUI 安装路径：
`conda create --prefix D:\ComfyUI\venv python=3.12 -y `

[!note]

`--prefix` 参数指定了虚拟环境的安装路径，这里我们将其放置在 ComfyUI 文件夹内部，便于管理。`-y` 选项表示自动确认所有安装提示。
3. 虚拟环境创建完成后，激活它：
`conda activate D:\ComfyUI\venv `
激活成功后，`Anaconda Prompt` 的命令行提示符前会显示 `(D:\ComfyUI\venv)` 字样。
4. 导航到 ComfyUI 的根目录：
`cd D:\ComfyUI `

[!tip]

如果您在步骤 3 中已经位于 `D:` 盘，可以直接输入 `cd ComfyUI`。
5. 安装 ComfyUI 的基础依赖包：
`pip install -r requirements.txt `
这一步将安装 ComfyUI 运行所需的通用 Python 库。
---
## 初次启动 ComfyUI
在尚未安装 Intel 专用 PyTorch 之前，我们可以先以 CPU 模式启动 ComfyUI，以验证环境是否配置正确且基础功能可用。
1. 在 **已激活 ComfyUI 虚拟环境** 并位于 ComfyUI 根目录的 `Anaconda Prompt` 中，执行以下命令：
`python main.py --cpu `
ComfyUI 将会在您的 CPU 上运行，并在浏览器中自动打开其用户界面。这可以确认基础环境和 ComfyUI 文件都已准备就绪。
2. 确认 ComfyUI 界面正常显示后，您可以关闭浏览器页面和当前的 `Anaconda Prompt` 窗口。
---
## 安装 Intel 显卡专用 PyTorch
> [!tip] 在ComfyUI的仓库里我们可以看到
>
> [file-20260228130617991790×224 13.6 KB](https://cdn3.ldstatic.com/original/4X/1/1/2/1123e2d370f022d7f114945c6c30369599f85407.png)
> 能充分利用Intel 显卡进行加速的关键步骤。我们需要安装 PyTorch 官方为 Intel XPU (包括 Arc 和集成显卡) 优化的版本。
1. **关闭并重新打开** 一个 `Anaconda Prompt` 窗口。

[!warning] 重要

务必关闭之前所有的 `Anaconda Prompt` 窗口，然后重新打开一个，以确保环境路径得到正确刷新，避免安装冲突。
2. 再次激活 ComfyUI 的虚拟环境：
`conda activate D:\ComfyUI\venv `
3. 导航到 ComfyUI 的根目录：
`cd D:\ComfyUI `
4. 访问 [Intel PyTorch 官方安装页面](https://pytorch-extension.intel.com/installation?request=platform)。

您会看到类似于以下内容的安装指南：

[file-202602281314470311105×237 11.1 KB](https://cdn3.ldstatic.com/original/4X/a/d/3/ad3d66a928c68e3e8fdc6983a194beda1740d8dd.png)
5. 在 `Anaconda Prompt` 中，复制并执行页面中 `3. Installation` 部分提供的命令：

[image1130×472 25.7 KB](https://cdn3.ldstatic.com/original/4X/5/3/a/53a0e736bdede006c11d38965c961fc1b91a7e7c.png)
`python -m pip install torch==2.8.0 torchvision==0.23.0 torchaudio==2.8.0 --index-url https://download.pytorch.org/whl/xpu `
这个命令将下载并安装支持 Intel XPU 的 PyTorch 及其相关组件。安装过程可能需要一些时间
---
## 启动 ComfyUI
完成 Intel PyTorch 的安装后，您现在可以启动 ComfyUI 并利用您的 Intel 显卡进行计算了。
1. 确保您仍在 **已激活 ComfyUI 虚拟环境** 且当前目录为 ComfyUI 根目录的 `Anaconda Prompt` 中。
2. 执行以下命令启动 ComfyUI：
`python main.py `
此时，ComfyUI 将尝试检测并利用您的 Intel GPU进行加速。您可以在 `Anaconda Prompt` 的输出日志中观察是否有 `XPU` 或 `Intel` 相关的字样，以此确认 GPU 是否被正确识别和使用。
