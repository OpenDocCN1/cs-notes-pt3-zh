## 2.搭建

我这里是用一台已经使用过的服务器，重装系统并搭建，如果你是新购买的服务器，可以直接在购买时选择 OpenClaw 镜像，并跳过此步骤

## 3. 使用腾讯云控制台简要配置

### 3.1 创建QQ机器人

访问 QQ 开放平台 [https://q.qq.com/](https://q.qq.com/) ，如果你尚未注册过，需要先注册账号（需要实名信息，扫脸，以及一个 QQ 号作为管理员 QQ 号），非常简单，这里就不赘述了

![1920×927 166 KB](https://cdn3.ldstatic.com/original/4X/1/6/1/1617372f0c7a306271976b30ed0c26ad1d9ceee4.jpeg)

登录你的 QQ 开放平台账号，进入后台后，点击机器人，点击创建机器人

![1920×927 32.3 KB](https://cdn3.ldstatic.com/original/4X/9/b/f/9bfb2338446694b56f792363437297d98b2a4a90.png)

填写机器人名称，上传机器人头像，填写机器人描述，点击确认

![1920×926 47 KB](https://cdn3.ldstatic.com/original/4X/3/f/1/3f108644d74670e1fab2756153445edf536ae9fd.png)

点击提交创建

### 3.2 通过腾讯云控制台配置 模型API 和 QQ 通道

回到腾讯控制台，点击应用管理，点击模型下拉框，选择自定义模型（这里我要使用的是前面教程反代出来的自建 API，如果你有其他官方 API，也可以直接在这里接入，这里不做赘述）

![1920×929 132 KB](https://cdn3.ldstatic.com/original/4X/4/c/c/4cc3df503240a3a155d64b78139ec3f49ee04053.png)

复制以下 JSON 代码，并按照自己的实际情况进行修改

（ provider 是提供商名称，随意即可；base_url 为自建项目的 服务器IP:端口 或是为项目反代的 域名（结尾一定要带`/v1`）；api 为协议类型，无需改动；api_key 为在自建项目里创建的 API Key ；model id 为模型的唯一标识符，也就是在自建项目里获取到的模型名称，选择其中一个；model name 为模型的显示名称，随意或者与 Model ID 一样即可）

```
{
  "provider": "myapi",
  "base_url": "http://127.8.9.10:3480/v1",
  "api": "openai-completions",
  "api_key": "sk-xxxxxxxxxxxx",
  "model": {
    "id": "gemini-3-flash-preview",
    "name": "gemini3flash"
  }
}
```

将修改好的 JSON 代码填入在 模型 输入框中，点击添加并应用；然后在 通道 输入框中填写上面复制的QQ机器人的 App ID 和 App Secret ，点击添加并应用（可以看到右面也是能很方便的安装部分Skills，不过本文就不演示了）

![1920×929 136 KB](https://cdn3.ldstatic.com/original/4X/1/b/d/1bd3cd0ff9af3a32fdf3a63ac52180684cb8ccf2.png)

点击确定

![1920×927 102 KB](https://cdn3.ldstatic.com/original/4X/d/d/d/ddd448ea17b384c26940f17272822bdf5ed5162d.png)

下拉，可以看到，我们刚刚的配置都已经应用上了

![1920×929 118 KB](https://cdn3.ldstatic.com/original/4X/3/8/5/3859f491a3cb323d8d74be51f2ffb5929b7e6487.png)
