## 2.搭建

我这里是用一台已经使用过的服务器，重装系统并搭建，如果你是新购买的服务器，可以直接在购买时选择 OpenClaw 镜像，并跳过此步骤

进入腾讯云轻量云控制台，（这里我使用这台名为“测试鸡”的机器进行搭建），点击机器卡片右上角的更多，点击重装系统

![1920×929 119 KB](img/128dbcb10d9ff0de0ee589b227050853.png)

选择使用应用模板，点击 OpenClaw

![1920×929 125 KB](img/e312e3e45707e4d6a015c1130af951b4.png)

下拉在此处设置服务器密码，也可以设置 SSH 密钥，这里不做演示；如果没有重要数据，可以选择无需备份直接重装，否则建议备份后重装；勾选下方 确认已了解以上内容 ，点击确定

![1920×929 92.7 KB](img/40a5cb25a3e2d80ca9d2756cf67d54b7.png)

正在重装，等待重装完成

![1920×929 185 KB](img/88191d245ad8bd4d7da8c9e1bf9ecd83.png)

接下来放通防火墙，点击防火墙，点击添加规则。应用类型选择 All，来源选择全部 IPv4 和 IPv6 地址，点击确定（这里演示的是全部端口、全地址放通，如果有安全顾虑，可以自行放通指定端口）

## 3. 使用腾讯云控制台简要配置

### 3.1 创建QQ机器人

访问 QQ 开放平台 [https://q.qq.com/](https://q.qq.com/) ，如果你尚未注册过，需要先注册账号（需要实名信息，扫脸，以及一个 QQ 号作为管理员 QQ 号），非常简单，这里就不赘述了

![1920×927 166 KB](img/dd1565eeebfd6818851a9cfa1f6ef4cf.png)

登录你的 QQ 开放平台账号，进入后台后，点击机器人，点击创建机器人

![1920×927 32.3 KB](img/5913d8eec714ba24083c5b4fbf6a0954.png)

填写机器人名称，上传机器人头像，填写机器人描述，点击确认

![1920×926 47 KB](img/125b92ee102e160baa14a5f60ac52efa.png)

点击提交创建

![1920×927 35.5 KB](img/b30d78077eb3638b1662e08318b34ac0.png)

点击刚刚创建的机器人

![1920×927 30.3 KB](img/390cdecf8fb8d5f4f446bb7eb7dd901f.png)

点击开发管理，复制 App ID，生成 App Secret

![1920×929 56.2 KB](img/426d71c4571c97356787fc749e461e7b.png)

扫码认证后，复制 App Secret，勾选，点击关闭

![1920×927 62.4 KB](img/a5103f5f736c14528e22ccf9fa7d7701.png)

点击沙箱配置，点击添加成员，把自己勾选上，点击确认

![1920×927 83.5 KB](img/cbea3ace6d232edfa05ce22909c47c8e.png)

点击这个二维码的图标，使用自己的 QQ 扫描弹出的二维码，在手机上添加使用

![1920×927 77.8 KB](img/0ef4634ab896ad79b17e50d5dbbbecdd.png)

### 3.2 通过腾讯云控制台配置 模型API 和 QQ 通道

回到腾讯控制台，点击应用管理，点击模型下拉框，选择自定义模型（这里我要使用的是前面教程反代出来的自建 API，如果你有其他官方 API，也可以直接在这里接入，这里不做赘述）

![1920×929 132 KB](img/86623db48e3c1c8bc79e1f8b4b4c90c8.png)

复制以下 JSON 代码，并按照自己的实际情况进行修改

（ provider 是提供商名称，随意即可；base_url 为自建项目的 服务器IP:端口 或是为项目反代的 域名（结尾一定要带`/v1`）；api 为协议类型，无需改动；api_key 为在自建项目里创建的 API Key ；model id 为模型的唯一标识符，也就是在自建项目里获取到的模型名称，选择其中一个；model name 为模型的显示名称，随意或者与 Model ID 一样即可）

```
{
  "provider": "myapi",
  "base_url": "http://127.8.9.10:3480/v1",
  "api": "openai-completions",
  "api_key": "sk-xxxxxxxxxxxx",
  "model": {
    "id": "gemini-3-flash-preview",
    "name": "gemini3flash"
  }
}
```

将修改好的 JSON 代码填入在 模型 输入框中，点击添加并应用；然后在 通道 输入框中填写上面复制的QQ机器人的 App ID 和 App Secret ，点击添加并应用（可以看到右面也是能很方便的安装部分Skills，不过本文就不演示了）

![1920×929 136 KB](img/b8ac333f2ca17080b2867e3f92df20f4.png)

点击确定

![1920×927 102 KB](img/341894124c1a7c61676da6518673442e.png)

下拉，可以看到，我们刚刚的配置都已经应用上了

![1920×929 118 KB](img/6d4006941fc2a19ea41966b5d17af2aa.png)
