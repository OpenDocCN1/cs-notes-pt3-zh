本文隶属于 OpenClaw 龙虾系列教程文章，建议按顺序阅读，可以访问OpenClaw龙虾系列教程文章目录 [https://iloli.love/archives/1766849996690](https://iloli.love/archives/1766849996690) 查看其它文章

## 2.搭建并配置

进入宝塔面板，点击 Docker ，点击立即安装

![1910×929 202 KB](img/9d8c887bef5bb0c1bfff5f9ba5b5ee3b.png)

点击确定，等待安装成功

![1920×927 151 KB](img/e1bd955b041bff2f781a7504dae06f0f.png)

安装完成后，点击软件商店，搜索 openclaw ，点击安装

![1920×929 67.7 KB](img/bea1019afb448d6b038ae723c53cafdb.png)

点击立即安装

![1920×927 70 KB](img/5c189b13ec94c856b142e84d6f65c52a.png)

安装完成后，点击设置

![1920×929 65.3 KB](img/317e2da0bc247f5105733e41f27bb321.png)

根据自己的实际情况，填写相关信息，点击安装应用（这里我要使用的是前面教程反代出来的自建 API，如果你有其他官方 API，请自行设置接入，这里不做赘述）

（ 大模型API地址 为自建项目的 服务器IP:端口 或是为项目反代的 域名（结尾一定要带`/v1`）；大模型API密钥 为在自建项目里创建的 API Key ；默认模型 为在自建项目里获取到的模型名称，选择其中一个）

![1920×927 86.1 KB](img/9eef44de9324a82a828f46d545ad111d.png)

等待一会，完成后会自动跳转到应用状态，显示如下

![1920×927 66.8 KB](img/b330a44096f78848d6dd315d96457f8e.png)

点击机器人配置，添加机器人

![1920×927 64.5 KB](img/342f8ed6893060946a102c66e642485a.png)

选择机器人类型，选择 QQ 机器人（本文中仅演示 QQ 机器人接入）

![1920×927 74.9 KB](img/fa9ded2be5f4da3f9566f3343249a27b.png)

访问 QQ 开放平台 [https://q.qq.com/](https://q.qq.com/) ，如果你尚未注册过，需要先注册账号（需要实名信息，扫脸，以及一个 QQ 号作为管理员 QQ 号），非常简单，这里就不赘述了

![1920×927 166 KB](img/dd1565eeebfd6818851a9cfa1f6ef4cf.png)

登录你的 QQ 开放平台账号，进入后台后，点击机器人，点击创建机器人

![1920×927 32.3 KB](img/5913d8eec714ba24083c5b4fbf6a0954.png)

填写机器人名称，上传机器人头像，填写机器人描述，点击确认

![1920×926 47 KB](img/125b92ee102e160baa14a5f60ac52efa.png)

点击提交创建

![1920×927 35.5 KB](img/b30d78077eb3638b1662e08318b34ac0.png)

点击刚刚创建的机器人

![1920×927 30.3 KB](img/390cdecf8fb8d5f4f446bb7eb7dd901f.png)

点击开发管理，复制 App ID，生成 App Secret

![1920×929 56.2 KB](img/426d71c4571c97356787fc749e461e7b.png)

扫码认证后，复制 App Secret，勾选，点击关闭

![1920×927 62.4 KB](img/a5103f5f736c14528e22ccf9fa7d7701.png)

点击沙箱配置，点击添加成员，把自己勾选上，点击确认

![1920×927 83.5 KB](img/cbea3ace6d232edfa05ce22909c47c8e.png)

点击这个二维码的图标，使用自己的 QQ 扫描弹出的二维码，在手机上添加使用

![1920×927 77.8 KB](img/0ef4634ab896ad79b17e50d5dbbbecdd.png)

回到宝塔面板，填入上面复制的 App ID 和 App Secret，点击启用，点击确定

![1920×927 75.2 KB](img/45375510c91a7bb08fc261fe08b66f7b.png)

点击保存配置

![1920×927 66.4 KB](img/e1b58e7b6e4717efc765e82df65e232f.png)

点击确定

![1920×927 75 KB](img/e72a69e2fa23bcaf7bcee9af9418141d.png)

等待安装完成后，点击访问信息，复制如图所示的地址，在浏览器访问

![1920×927 67 KB](img/2cb56588a6acd8102245248d94abee9c.png)

重定向到了 WebUI 界面

![1920×929 44.3 KB](img/b21526bc02174a5410b32795eb3ffa0b.png)

## 3. 开始使用

接下来就可以愉快地开始使用了

可以前往QQ，和我们上面扫码添加的机器人进行对话

![1920×1048 120 KB](img/aa051085c59b25380ae158dfc58c0826.png)

亦或者是在 WebUI 里进行其他配置与聊天

![1920×929 85.1 KB](img/7d90776fac0409dacc473a42bfa0eaf1.png)
