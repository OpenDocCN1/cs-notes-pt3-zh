# 使用宝塔面板搭建OpenClaw图文教程



本文作者：猫猫摸大鱼

## 1. 前言

本文隶属于 OpenClaw 龙虾系列教程文章，建议按顺序阅读，可以访问OpenClaw龙虾系列教程文章目录 [https://iloli.love/archives/1766849996690](https://iloli.love/archives/1766849996690) 查看其它文章

本文基于 宝塔面板v11.5.0 版本以及宝塔面板插件 OpenClaw v1.1.0 版本

本文中安装的是由 BTPanel 构建的 Docker 版本，非官方直装版本

本系列教程全程使用腾讯云轻量应用服务器，可以参加腾讯云OpenClaw专属活动进行购买，新客68/年起，老客99/年起

## 2.搭建并配置

进入宝塔面板，点击 Docker ，点击立即安装

![1910×929 202 KB](https://cdn3.ldstatic.com/original/4X/4/7/a/47a4ddcc4f6dfd9403920c2dec24f6f785561825.png)

点击确定，等待安装成功

![1920×927 151 KB](https://cdn3.ldstatic.com/original/4X/3/e/e/3ee7e8233d7e44522ee86fb3f2d42c2d881b2991.jpeg)

安装完成后，点击软件商店，搜索 openclaw ，点击安装

![1920×929 67.7 KB](https://cdn3.ldstatic.com/original/4X/d/8/6/d86729fb525cd5054b87dfcb4364213910cce87c.png)

点击立即安装

![1920×927 70 KB](https://cdn3.ldstatic.com/original/4X/1/2/9/129c33751aca9679cd08054d560da39c58d5332e.png)

安装完成后，点击设置

![1920×929 65.3 KB](https://cdn3.ldstatic.com/original/4X/4/d/0/4d0b4bfb78e89fea623d18e7eaedd03386c4269b.png)

根据自己的实际情况，填写相关信息，点击安装应用（这里我要使用的是前面教程反代出来的自建 API，如果你有其他官方 API，请自行设置接入，这里不做赘述）

（ 大模型API地址 为自建项目的 服务器IP:端口 或是为项目反代的 域名（结尾一定要带`/v1`）；大模型API密钥 为在自建项目里创建的 API Key ；默认模型 为在自建项目里获取到的模型名称，选择其中一个）

![1920×927 86.1 KB](https://cdn3.ldstatic.com/original/4X/c/7/d/c7df8f2ba37aeee5b8151ddf547131bb1b619c0f.png)

等待一会，完成后会自动跳转到应用状态，显示如下

![1920×927 66.8 KB](https://cdn3.ldstatic.com/original/4X/e/f/6/ef6e781eb4f32d967300abd372f625583135ec50.png)

点击机器人配置，添加机器人

![1920×927 64.5 KB](https://cdn3.ldstatic.com/original/4X/c/e/6/ce62a03319d1f9e8a0e77e1acd998589fbc294f1.png)

选择机器人类型，选择 QQ 机器人（本文中仅演示 QQ 机器人接入）

![1920×927 74.9 KB](https://cdn3.ldstatic.com/original/4X/f/e/e/feeeb544d6fcb16fb91777b904382831e02f2047.png)

访问 QQ 开放平台 [https://q.qq.com/](https://q.qq.com/) ，如果你尚未注册过，需要先注册账号（需要实名信息，扫脸，以及一个 QQ 号作为管理员 QQ 号），非常简单，这里就不赘述了

![1920×927 166 KB](https://cdn3.ldstatic.com/original/4X/1/6/1/1617372f0c7a306271976b30ed0c26ad1d9ceee4.jpeg)

登录你的 QQ 开放平台账号，进入后台后，点击机器人，点击创建机器人

![1920×927 32.3 KB](https://cdn3.ldstatic.com/original/4X/9/b/f/9bfb2338446694b56f792363437297d98b2a4a90.png)

填写机器人名称，上传机器人头像，填写机器人描述，点击确认

![1920×926 47 KB](https://cdn3.ldstatic.com/original/4X/3/f/1/3f108644d74670e1fab2756153445edf536ae9fd.png)

点击提交创建

![1920×927 35.5 KB](https://cdn3.ldstatic.com/original/4X/8/3/4/834533abfc5e0f0e1f3aa9dc87eaadec26ab7c46.png)

点击刚刚创建的机器人

![1920×927 30.3 KB](https://cdn3.ldstatic.com/original/4X/a/e/5/ae5fd49a022b82123affba5f02b1c8adbf30e17b.png)

点击开发管理，复制 App ID，生成 App Secret

![1920×929 56.2 KB](https://cdn3.ldstatic.com/original/4X/e/e/0/ee0f883298ba92c014ee966736ca56b3d19a91e2.png)

扫码认证后，复制 App Secret，勾选，点击关闭

![1920×927 62.4 KB](https://cdn3.ldstatic.com/original/4X/a/7/9/a796c7daca5f7687043f805d0fae7a99614e4164.png)

点击沙箱配置，点击添加成员，把自己勾选上，点击确认

![1920×927 83.5 KB](https://cdn3.ldstatic.com/original/4X/b/1/a/b1a4479e4979c2767316e21ad087f56a53c5322a.png)

点击这个二维码的图标，使用自己的 QQ 扫描弹出的二维码，在手机上添加使用

![1920×927 77.8 KB](https://cdn3.ldstatic.com/original/4X/3/5/3/3532918e17dde0f1d2e44ba9976d342ba37e8e24.png)

回到宝塔面板，填入上面复制的 App ID 和 App Secret，点击启用，点击确定

![1920×927 75.2 KB](https://cdn3.ldstatic.com/original/4X/4/8/a/48a6cf775854cdfe2a4e602be8b602a0db4b8a1b.png)

点击保存配置

![1920×927 66.4 KB](https://cdn3.ldstatic.com/original/4X/0/e/1/0e1df4c765d6e2dc1797229f67146e813edf2665.png)

点击确定

![1920×927 75 KB](https://cdn3.ldstatic.com/original/4X/d/4/6/d462f89ffd0c02eee8baa38d98132d9955c0dc73.png)

等待安装完成后，点击访问信息，复制如图所示的地址，在浏览器访问

![1920×927 67 KB](https://cdn3.ldstatic.com/original/4X/a/7/6/a765e9dfecccd98df1dbd42eeb7105208768ad4e.png)

重定向到了 WebUI 界面

![1920×929 44.3 KB](https://cdn3.ldstatic.com/original/4X/4/6/4/464a095b3a5e87a8f778978b659ba4ecb90ac026.png)

## 3. 开始使用

接下来就可以愉快地开始使用了

可以前往QQ，和我们上面扫码添加的机器人进行对话

![1920×1048 120 KB](https://cdn3.ldstatic.com/original/4X/e/d/4/ed4fe29d78f3cb26ea9e6a9f3ac4f9eaa88415b2.png)

亦或者是在 WebUI 里进行其他配置与聊天

![1920×929 85.1 KB](https://cdn3.ldstatic.com/original/4X/8/1/f/81f85ca25f34a3e030c8deda6a988e35dd5b6a1d.png)
