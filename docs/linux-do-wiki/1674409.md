# 关于LD士多
`LD士多`**是一个LDC积分兑换信息中心，致力于打造一个全站物品/服务信息集中地。**
- **多种服务：** `外链物品（后续会逐渐淘汰）`、`CDK自动分发`、`求购广场`、`自建小店入驻`等等
- **为爱发电：** **纯公益**服务，无任何中间手续费，兑换者和提供者直接通过LDC平台进行积分流转
- **一键上架、一键兑换：** 上架物品和兑换都很容易
- **信息集中、曝光度高：** 截至26年3月1日，累积促成交易7000+，促进LDC积分流动170w+。日均pv 1w~2w
- **隐私安全：** 所有信息均有严格加密和防护，网页部署在CF Pages上，服务器数据每日备份，安全有保障。

# ![:light_bulb:](https://cdn.ldstatic.com/images/emoji/twemoji/light_bulb.png?v=15)常见问题解答
## ![:ticket:](https://cdn.ldstatic.com/images/emoji/twemoji/ticket.png?v=15)士多收交易手续费吗？
LD士多属于社区公益服务![:heart:](https://cdn.ldstatic.com/images/emoji/twemoji/heart.png?v=15)不收取任何中间手续费，用户和用户直接通过LDC官方链接进行积分易流转。

LD士多的主要积分收入来源：![:heart:](https://cdn.ldstatic.com/images/emoji/twemoji/heart.png?v=15)各位佬的[打赏支持](https://ldcstore.com/support)；[士多图床](https://ldcstore.com/ld-image)（使用R2存储，收取极少积分）；士多甄选（物品额外曝光服务）。

所有积分收入均用于分摊士多运营和开发消耗。
## ![:coin:](https://cdn.ldstatic.com/images/emoji/twemoji/coin.png?v=15)如何进行订单退款？
1. 如果有交易纠纷，优先在L站私信卖家进行售后处理。
2. 如果协商一致or卖家不愿协商，可以在 [credit.linux.do](http://credit.linux.do) 对相关交易发起争议进行退款。
[image1180×524 57.1 KB](https://cdn3.ldstatic.com/original/4X/3/1/9/319e359ade1a9a10c4f3062b98ec084f4217afb2.png)
## ![:scream:](https://cdn.ldstatic.com/images/emoji/twemoji/scream.png?v=15)积分流转成功但还是显示`待支付`？
通常是因为卖家没有在LDC正确配置应用的通知地址和回调地址为LD士多要求的链接，导致LD士多无法收到支付成功的回调。

**正确处理姿势：**
1. 携带支付凭证直接在L站私信卖家获取服务，或直接在LDC发起争议退积分。
2. 举报该物品或L站私信我对该物品进行下架处理。
配置教程：[使用文档 - LD士多](https://ldcstore.com/docs/publish-cdk)
