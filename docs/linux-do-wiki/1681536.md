# Gemini CLI 安装指南（解决始终出现的：command not found: gemini）

# Gemini CLI 安装指南
## 安装环境
- 操作系统：macOS (Darwin 24.5.0)
- Shell：zsh
- 包管理器：npm
## 安装步骤
### 1. 查找官方包
首先确认 npm 上有官方的 Gemini CLI 包：
```
npm search @google/gemini-cli
```
输出结果：
```
@google/gemini-cli
Gemini CLI
Version 0.31.0 published 2026-02-27 by google-wombot
https://npm.im/@google/gemini-cli
```
### 2. 全局安装
```
npm install -g @google/gemini-cli
```
安装成功输出：
```
changed 627 packages in 15s
175 packages are looking funding available
```
## 遇到的问题
### 问题现象
安装成功后，执行 `gemini --version` 报错：
```
$ gemini --version
zsh: command not found: gemini
```
## 问题排查思路
### 1. 确认包已安装
检查 npm 全局模块路径：
```
npm root -g
# 输出: /Users/xxx/.npm-global/lib/node_modules
```
确认 Gemini CLI 包存在：
```
ls -la /Users/xxx/.npm-global/lib/node_modules/@google/gemini-cli/
```
输出：
```
total 56
drwxr-xr-x@   7 xxxx  staff    224  3  3 10:46 .
drwxr-xr-x@   3 xxxx  staff     96  3  3 10:46 ..
drwxr-xr-x@   9 xxxx  staff    288  3  3 10:46 dist
-rw-r--r--@   1 xxxx  staff    11357  3  3 10:46 LICENSE
drwxr-xr-x@ 421 xxxx  staff    13472  3  3 10:46 node_modules
-rw-r--r--@   1 xxxx  staff    2416  3  3 10:46 package.json
-rw-r--r--@   1 xxxx  staff    12215  3  3 10:46 README.md
```
### 2. 检查可执行文件名称
查看 package.json 中的 bin 配置：
```
cat /Users/xxx/.npm-global/lib/node_modules/@google/gemini-cli/package.json | grep -A 5 '"bin"'
```
输出：
```
"bin": {
  "gemini": "dist/index.js"
}
```
确认命令名称是 `gemini`。
### 3. 检查符号链接
查看 npm 全局 bin 目录：
```
ls -la /Users/xxx/.npm-global/bin/ | grep gemini
```
输出：
```
lrwxr-xr-x@ 1 xxxx  staff   52  3  3 10:46 gemini -> ../lib/node_modules/@google/gemini-cli/dist/index.js
```
符号链接已正确创建。
### 4. 验证命令可用性
使用完整路径测试：
```
/Users/xxx/.npm-global/bin/gemini --version
# 输出: 0.31.0
```
命令本身是正常的。
### 5. 检查 PATH 环境变量
```
echo $PATH | tr ':' '\n' | grep npm
# 无输出
```
**问题定位**：npm 全局 bin 目录 `~/.npm-global/bin` 不在 PATH 环境变量中。
## 解决方案
将 npm 全局 bin 目录添加到 PATH 中。
### 方法一：修改 ~/.zshrc（推荐，永久生效）
```
echo 'export PATH="$HOME/.npm-global/bin:$PATH"' >> ~/.zshrc
source ~/.zshrc
```
### 方法二：临时生效（仅当前终端会话）
```
export PATH="$HOME/.npm-global/bin:$PATH"
```
## 验证安装
```
gemini --version
# 输出: 0.31.0
```
## 总结
### 问题根因
npm 全局安装时使用了自定义路径 `~/.npm-global`，但该路径的 bin 目录未被添加到 PATH 环境变量中，导致 shell 无法找到 `gemini` 命令。

### 通用排查命令
遇到类似的 `command not found` 问题时，可以按以下步骤排查：
```
# 1. 查找 npm 全局路径
npm root -g

# 2. 确认包存在
ls $(npm root -g)/<package-name>

# 3. 查看可执行文件名
cat $(npm root -g)/<package-name>/package.json | grep -A 5 '"bin"'

# 4. 确认符号链接
ls $(dirname $(npm root -g))/bin/

# 5. 检查 PATH
echo $PATH

# 6. 全路径测试
$(dirname $(npm root -g))/bin/<command> --version
```
## 后续使用
首次运行 `gemini` 命令时，可能需要登录 Google 账号进行认证授权。
