# 做了个公众号排版工具，Vibe Coding 两天搓出来的

写公众号有一段时间了，最头疼的不是写稿，是发稿前那段时间。
图片十有八九显示"此图片来自第三方"，复制过来的内容格式全乱，调来调去半小时没了。每次发稿都要耗在这上面，烦透了，就自己做了一个工具。
我习惯用 Markdown 写东西，但经常需要给别人 Word 或 PDF，格式还要看得过去。主要解决这几个问题：
- 外链图片复制到公众号时自动转 Base64，不再出现"此图片来自第三方"的报错
- Markdown 直接写，排版自动处理
- 导出 PDF 或 Word 给不用 Markdown 的人，格式不会崩
- 主题方面，内置了 Claude / 公众号原生 / Notion / GitHub 四套开箱即用，也可以自定义主色和风格（简约、聚焦、精致、醒目），还有更多预设可选
- 纯本地运行，数据不出网
- 手机/平板预览，所见即所得
启动方式：
**Windows**：双击 `start.bat` 直接跑
**Mac / Linux**：
```
pnpm install && pnpm dev

npm install && npm run dev
```
访问 `http://127.0.0.1:5173/` 就行。
