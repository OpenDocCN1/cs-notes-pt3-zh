搞七捻三](/c/gossip/11)

> 使用openclaw第三方，发现一个问题就是修改baseUrl是不生效的，需要同时修改cpa2这个名字为其他名字才行，否则一直请求之前填写的baseUrl。

> 不懂这个问题是怎么发生的，是其他配置参数导致保存了cpa2/coder-model的baseUrl，导致单纯修改baseUrl是不生效？

>   "models": {

>     "mode": "merge",

>     "providers"…

关于使用第三方的配置，可以参考上面坑点1的配置，我还进行下面修改



删除 `auth` 字段,将`$.plugins.entries.qwen-portal-auth.enabled=false`

### 修改配置

修改配置，修改后运行`openclaw gateway restart`

1. 直接修改`.openclaw/openclaw.json`

2. 通过 [http://127.0.0.1:18789/config](http://127.0.0.1:18789/config) 进行修改

3. 通过命令修改

4. `openclaw configure`

使用ssh 隧道打开 Gateway Dashboard 页面，我使用`finalshell->连接属性->隧道->本地类型`

也可以通过输入命令 `openclaw dashboard` 获取相应命令

修改权限



`$.tools.profile="full" 或 "coding"`
