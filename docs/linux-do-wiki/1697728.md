# :fire:【图像视频系列5】Ultra会员NotebookLM视频预览新增Cinematic模式【更新实测体验】



NotebookLM昨天出了个视频概览的cinematic 模式

### 新版与老版视频概览的区别

新版90%带缩放的幻灯片+10%视频，长度5分钟左右



里面有5段左右8s长veo视频，其余都是Nano Banana Pro幻灯



老版幻灯没有缩放，没有视频，就是新版相对更像视频一些（虽然本质还是幻灯）

新版现在貌似只支持英文，老版支持中文

新版风格电影化，深色为主，老版卡通化，浅色为主

新版暂时Ultra会员可用，每天20次，老版Ultra普通视频预览额度是200次，Pro会员20次

新版使用Gemini3 + Nano Banana Pro + Veo3 等模型生成流畅动画、丰富细节视觉、动态叙事和故事化呈现。



老版没有veo3

生成比较慢，但可以多个视频同时生成，具体限几个同时暂不确定

官方介绍：[NotebookLM adds Cinematic Video Overviews](https://blog.google/innovation-and-ai/products/notebooklm/generate-your-own-cinematic-video-overviews-in-notebooklm/)

### 使用方法

如果没有Cinematic选项：在google账号设置里把语言改成英文就有了
