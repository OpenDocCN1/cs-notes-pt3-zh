## 第一部分：
### 1. 服务器与个人PC的区别：
服务器是专门用于长期运行，为多用户或服务提供资源的计算机，与个人PC相比，区别如下：
| 特点 | 服务器 | 个人PC |
| --- | --- | --- |
| 运行时间 | 长时间运行（一般为7*24小时） | 运行时间通常不超过一周 |
| 稳定性 | 高稳定性 | 一般 |
| 用户数量 | 通常为多用户共同使用 | 通常为单用户使用 |
| 硬件配置 | ECC内存，RAID，多CPU等 | 普通硬件 |
| 管理方式 | 日常为远程管理 | 本地操作 |
例如：
- 超算服务器：为多用户提供大规模高性能计算能力
- web服务器：提供网站访问服务
可通过`uptime`查看服务器运行时间（现场演示环节一）
### 2. 服务器端常用Linux发行版：
服务器通常使用Linux作为操作系统，主要因为其开源，稳定，占用率低，安全等特性，其中，常见的发行版为：Debian；Ubuntu；CentOS等
可以使用`cat /etc/os-release`来查看系统版本（现场演示环节二）
### 3. 用户与权限管理：
Linux是一个多用户系统，每个用户拥有：用户名，UID，用户组。
#### 3.1：用户&用户组相关命令：
- 创建用户：`sudo useradd username`
- 创建用户密码：`sudo passwd username`;参数`-m`表示自动创建家目录，`-d /path/to/home`表示指定用户家目录，后面路径是用户家目录的绝对路径，`-s /bin/bash`表示指定用户的默认shell为bash，也可换成zsh等，完整命令类似`sudo useradd -m -d /path/to/home -s /bin/bash username`
- 删除用户：`sudo userdel username`;参数`-r`表示同时删除用户家目录`sudo userdel -r username`
- 创建用户组：`sudo groupadd groupname`
- 将用户加入某一用户组：`sudo usermod -aG groupname username`
- 查看用户所在组：`groups username`
#### 3.2：sudo相关概念与命令
通常，普通用户没有权限进行高权限操作，例如`apt update`，如果使用普通用户运行，会提示权限不足（现场演示环节三）

我们可以使用`sudo`来临时获取管理员权限（前提是账户在sudo组内），由于`/etc/sudoers`的默认配置中的`Defaults        env_reset`，sudo会重置所有非白名单环境变量，所以会出现环境变量丢失的问题，在Ubuntu22.04中，可以使用`-E`来保留当前用户的环境变量（现场演示环节四，命令：`export TEST_VAR="hello_linux" ; echo $TEST_VAR ; echo "-user_path-" ;  env | grep TEST_VAR ; echo "-sudo_path-" ; sudo env | grep TEST_VAR ; echo "-sudo_hold_path" ; sudo -E env | grep TEST_VAR`）

sudo的详细配置通常位于`/etc/sudoers`,我们可以通过`sudo visudo`来安全编辑该文件，使用编辑器直接打开该文件，即使使用sudo权限，也依然为只读状态（现场演示环节五）
### 4：进程与资源管理
#### 4.1：什么是进程
进程，是正在运行的程序，每个进程拥有：PID，所属用户，资源占用
#### 4.2：进程与资源管理相关命令
- 查看所有进程：`ps aux`
- 查看系统资源信息与进程信息等：`top`或`htop（需安装）`
- 结束进程：`kill PID`
- 强制结束进程：`kill -9 PID`
- 按名称结束所有匹配进程：`pkill process_name`
#### 4.3：进程优先级
Linux使用nice值来控制进程的优先级，范围为[-20,19]其中-20为最高优先级，0为默认优先级，19为最低优先级，我们使用`renice -n nice_number -p PID`来更改进程的优先级
### 5：磁盘与文件系统
#### 5.1：查看磁盘/目录大小相关命令
- 查看磁盘使用情况`df -h`，其中`-h`是以人类可读形式（Kb，Mb，Gb，…）显示
- 查看目录大小`du -sh /path`，其中`-s`表示只显示总大小，后面路径可为绝对路径或相对路径，为空时统计当前文件夹
#### 5.2：inode
linux系统使用inode记录文件信息，包括文件类型，所有者，权限等，对于ext系列文件系统，我们可以使用`sudo tune2fs -l /dev/sdd | grep "Inode size"`来查看每个inode占用多少空间。我们可以使用`df -i`命令查看inode总数量，有时磁盘空间足够但无法创建文件就是因为inode耗尽
#### 5.3：挂载
linux使用挂载来管理文件系统，我们可以使用`mount`来查看挂载，使用`mount /dev/sdbx /path`来挂载新磁盘，NFS（Network File System）可以实现多服务器共享存储，常用来实现HPC集群的共享目录（现场演示环节六）
### 6：日志系统
linux日志通常存储在`/var/log`，可以使用`tail`或`cat`查看日志。journalctl，是systemd的日志工具，可以使用`journalctl -u service_name`查看指定服务的日志，`journalctl -n 50`查看最近50条日志，`journalctl -f`查看实时日志
### 7：服务器常见问题
#### 7.1：CPU占用过高
使用`top`或类似命令进行排查
#### 7.2：内存不足（OOM）
使用`dmesg | grep -i oom`进行查看
#### 7.3：磁盘满
使用`df -h`检查，`du -sh`查找大文件
#### 7.4：进程卡死
使用`ps aux`查看，`kill -9`结束
