# :fire:【提智降智系列1】未预训练内容造成严重降智，与各模型搜索能力研究

### 新挖个大坑，提智降智系列，估计能写几十到上百篇，慢慢填坑
以下纯个人主观判断，每人挑剔程度不同，问题难度/主题不同，如有体感不符，也完全正常，如有错误，感谢指正
这个系列里“提智”指通过提示词工程，上下文工程，IDE或CLI，本地知识库，Skills，MCP等提升AI智力极限
这个系列里“降智”专指AI因为某种原因，智力明显低于应有水准，例如本节讨论因为搜索问题引起的严重降智。

本系列不讨论类似ChatGPT那种故意针对某些ip/人群/指纹等降智
最近经常被所谓旗舰模型，回答2025年后未训练过的内容，蠢哭了

实在受不了，自己研究降智原因，改进方案
深入研究各模型和渠道的搜索能力
以下智商不代表绝对智力，只是为了方便对比相对智力，或者说相当于智力排序的序号，无需纠结于具体分数
### 为什么大模型一遇到2025年之后发生的问题，智商就立即减半？
因为大模型通常从google，bing，brave三家搜索引擎api搜索，获取到比如10个来源，每个来源30~40字的摘要，标题和原文地址，没了。
谷歌搜索api，甚至连原始网址都不给，只给一个临时重定向网址，可能是为了防止别人爬他
这300字里，其实不重复，真正相关的内容可能只有100字，大模型就靠这100字摘要 + **自己瞎编900字**，给你回答1000字，能不幻觉，就见鬼了
以下是谷歌搜索截图，你搜索能看到的摘要，和大模型搜索能看到的摘要，是完全相同的

### AI搜索方案层级
#### 以提问2024年及之前，预训练过的内容，智商基线为100的话
以下是提问2025年及之后，未预训练过的内容，AI现学现卖(in-context-leaning)的智商
#### 第一梯队：智商80，自有搜索引擎 + 获取全文 + 溯源到句子
**NotebookLM-web**：fast-research下载10多条，deep-research可下载100多网址全文
youtube只有google能爬到字幕(原视频没字幕也行)
reddit只有google能搜索/爬到回帖，因为google每年向reddit买断独家搜索权，连reddit官网搜索和官方api都搜不到回帖，只能搜主贴
对x，公众号等有反爬措施的网站无效
**Perplexity-api**：25年9月开放，可获取全文
#### 第二梯队：智商70，获取全文 + 溯源到原文开头
gemini-deep-research-web

gpt-deep-research-web

claude-research-web

manus-wide-research-web
#### 第三梯队：智商60，及格线，别人搜索引擎 + 获取全文 + 溯源到原文开头
tavily-extract-api：google等搜索引擎+它爬全文
jina-reader-api：google等搜索引擎+它爬全文
exa-api：google等搜索引擎+它爬全文
grok-web：自家搜索引擎，可能获取全文，不对外开放api
#### 第四梯队：智商50，返回真实网址 + 只能获取30字摘要 + 溯源到句子
gemini-web：回答智商并没有更高，但因为带溯源到句子的链接，你可以方便地跳转到原始句子，人工验证是否幻觉，变相提高了智商

跳转到句子的网址例子，可以点击试试，如果卡住没跳转到具体可以点地址栏按回车： [Python Framework Guide 2026: Best Frameworks for Every Use Case](https://softjourn.com/insights/best-python-frameworks#:~:text=streaming%20data%20platforms.-,Sanic%3A%20Async%20Speed%20Without%20Compromise,response%20time%20directly%20impacts%20revenue).
下图谷歌普通chat，溯源中大部分url含有`:text=`参数，就是跳转到具体句子，其他绝大多数api和app搜索都不会带这个参数

#### 第五梯队：智商40，返回真实网址 + 只能获取30字摘要 + 溯源到原文开头
gpt-api，gpt-web，gpt-pro-web，codex，使用微软爸爸的bing搜索api
claude-api，claude-web，claude-code，使用brave搜索api
gemini-deep-think-web，使用Google搜索api
OpenRouter：模型名后加:online，实际用的是exa
#### 第六梯队：智商30，返回临时重定向网址，不给真实溯源，强制溯源就瞎编一个网址
重定向网址几小时失效，人工点击或者写程序解析，才能跳转到真实网址
Antigravity：固定使用google搜索api，不用模型自带搜索，选opus-4.6也是一样
gemini-api，gemini-cli
#### 第七梯队：智商30，只能搜索国内网站
国内所有web/api国内版官方搜索都是这种，这不是技术问题，因为法规禁止国产模型web或api翻墙搜国外网站
国产模型的国外版官方web或api，与国内版用的不是不同的搜索api，没有墙的问题
智商30只是针对科技，AI等英文内容远胜于中文内容的题材，搜一般内容没这么大差距
一般是用bing-cn-api，百度为了垄断，是不开放搜索api的
