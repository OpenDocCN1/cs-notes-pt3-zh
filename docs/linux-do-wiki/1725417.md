## DriveMind —— 一个让 Agent 更有分寸的 AI 可靠性层

做这个东西源于一个真实的痛点：用 agent 处理稍复杂的任务时，它要么遇到阻碍就停、要么边界模糊时乱做决策、要么任务结束后什么经验都不留下。

DriveMind 不是要让 agent 跑得更猛，而是让它**更有分寸**：

- **坚持有据**：有证据才继续推进，没证据先问人，不固执硬撑

- **边界清晰**：任务模糊、风险升高时主动交回给人判断，不擅自取舍

- **经验沉淀**：每次执行后留下 diary / review / distill，下次不从零开始

---

## 装上之后有什么不同

同样一个任务遇到报错或边界模糊：

**没有 DriveMind：**

> agent 静默失败、无限重试，或者自己做了个你完全不知道的决策，任务结束后什么都没留下

**有了 DriveMind：**

> agent 停下来告诉你"我遇到了什么、需要你判断什么"，任务结束后自动生成本次执行日志，下次同类任务直接复用经验
