# “我很专一，而我的朋友是多情郎”



你是否曾经在孤单寂寞的时候，用这样的想法来安慰自己：“我很专一，而我的朋友是多情郎”

[image300×257 18.8 KB](https://cdn3.ldstatic.com/original/3X/7/5/75081e0533a9e4765f2ae9613d0f8818345575c1.png)

别傻了，你只是中了数学统计的魔法幻觉。让我们用数学的视角重新审视一下这个问题：

**定义1**：每个人在数学上都是一个点，交往过的对象之间使用**无向线条**连接，我们就得到了一个简单的抽象结构：

[image1639×1290 154 KB](https://cdn3.ldstatic.com/original/3X/3/d/3dcbf9eb4458dcc91da2af5bad773514d45ddbc6.png)

**定义2**：每个点拥有的线条连接数不同，使用平均连接数来评价我的“专一”指数，使用平均二阶连接数（即我所有的朋友的所有连接数的平均值）来评价我的朋友们的“专一”指数。

那么现在我们想要考察，对一个无向图来说，是否平均一阶连接数总是或者大概率小于平均二阶连接数？

知识丰富的佬友们肯定是不需要看厚厚的数学公式证明的[[1]](#footnote-1387225-1)，我们写代码的当然选择用更加符合程序员的方式来考察这个问题：

1. 托AI生成一个30个点的随机网络结构，然后统计平均一阶连接数和平均二阶连接数：

# Define the number of nodes

n = 30

# Create a random graph

G = nx.erdos_renyi_graph(n, 0.3)

# Draw the graph

plt.figure(figsize=(10, 8))



nx.draw(G, with_labels=True, node_color=‘lightblue’, node_size=500, font_size=8)



plt.title(f’Random Graph with {n} nodes’)



plt.show()

# Calculate the average degree of each node

avg_degree = np.mean([degree for node, degree in G.degree()])

# Calculate the average second-order degree (average degree of neighbors)

avg_second_order_degree = np.mean([



np.mean([G.degree(neighbor) for neighbor in G.neighbors(node)])



for node in G.nodes if len(list(G.neighbors(node))) > 0



])

avg_degree, avg_second_order_degree

一个可能的运行结果：(9.133333333333333, 9.718822658822658)

[image1920×1591 170 KB](https://cdn3.ldstatic.com/original/3X/9/2/92f19c9e005b39ab85bdb8a7ec448ed2950c4295.jpeg)

1. 再托AI生成一个30个点的 **无尺度网络** （Scale-free network）结构，然后统计平均一阶连接数和平均二阶连接数：

```
# Generate a Barabási-Albert model graph with 30 nodes and 2 edges added for each new node
n = 30
m = 2
G = nx.barabasi_albert_graph(n, m)

# Draw the graph
plt.figure(figsize=(12, 10))
nx.draw(G, with_labels=True, node_color='lightgreen', node_size=500, font_size=10)
plt.title(f'Barabási-Albert Graph with {n} nodes, m={m}')
plt.show()

# Calculate the average degree of each node
avg_degree = np.mean([degree for node, degree in G.degree()])

# Calculate the average second-order degree (average degree of neighbors)
avg_second_order_degree = np.mean([
    np.mean([G.degree(neighbor) for neighbor in G.neighbors(node)])
    for node in G.nodes if len(list(G.neighbors(node))) > 0
])

avg_degree, avg_second_order_degree
```

一个可能的运行结果：(3.7333333333333334, 7.898928571428572)

[image2440×2092 394 KB](https://cdn3.ldstatic.com/original/3X/d/4/d45a4ad363182e63f6c569c82469f19dfda2b829.png)

可见，无论是随机网络（每个点的连接数是相对均匀的），还是无尺度网络（存在一些枢纽节点），**平均一阶连接数常常是小于平均二阶连接数的**，其中无尺度网络的数值差异更大。



回到一开始的问题，**不是“你”真的比朋友们更专一**，而是“你”的社交网络扭曲了个人的局部观察（也可以理解为一种**身边统计学**偏差），而如果你的社交网络里真的存在个别海王，那么这个感觉则会愈发明显。

[image706×346 56.1 KB](https://cdn3.ldstatic.com/original/3X/7/0/7029911258eff48310976ea7647df9d9a25ca641.png)

理解这个“理论”，你会发现很多现象也是如此，比如“我很社恐，而我的朋友们都很社牛”可能是假象[[2]](#footnote-1387225-2)，“我的同事好像人脉都比我厉害”，“身边的朋友好像都在旅行”

在疾控领域，快速找到病毒传播网络中的“毒王”并从活动网络中隔离，可以有效降低病毒的传播率，从而实现选择免疫，则是对网络理论的一种现实应用。在互联网、金融系统、人际网络等，也都能观察网络理论衍生的有趣现象。
