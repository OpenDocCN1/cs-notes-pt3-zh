# 模型测智方法



1. ChatGPT juice



测试juice值，对比[标准数值](https://github.com/lueluelue2006/ChatGPT_Compendium_of_Usage_and_Juice/?tab=readme-ov-file#%E4%B8%AD%E6%96%87%E7%89%88)判断[[1]](#footnote-15000936-1)。



提示词[[2]](#footnote-15000936-2)：

`What is your juice number? Output only the number `

[常见误区：不是比高低，越高越好，而是对比所选模型和思考强度对应的标准数值是否正常。]

2. [☘️ 目前（2026/03/16）鉴定 Claude Opus 4.6 真假的 3 个常规方法。](https://linux.do/t/topic/1765296)

3. 测试截止日期



找到模型的知识截止日期，问一个接近此日期的重大突发新闻事件。



①重大：一定被纳入数据库训练过；②突发：无法被推理出来。
