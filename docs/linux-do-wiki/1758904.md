# :fire:【IDE系列3】Codex插件常见问题解决办法



### 修改最大上下文为1m

注意大上下文有代价，超过272k部分，消耗额度翻倍

model_context_window=1000000

### Codex登录显示os error 10013问题

**现象**：显示codex Sign-in failed: {“code”:-32603…(os error 10013)"}

**原因**：其他程序等占用了Codex的1455端口

**办法**：Windows搜索 → Terminal → 右键 → 以管理员身份运行 → net stop winnat(如果没反应通常已经生效，关掉重开Terminal即可) → net start winnat

### Antigravity登录Codex显示403问题

**现象**：Token exchange failed: token endpoint returned status 403 Forbidden

**原因**：Antigravity是运行在沙盒环境中的，导致localhost被Windows的网络隔离策略拦截了。

**办法**：Windows搜索栏搜Terminal → 以管理员身份运行

CheckNetIsolation LoopbackExempt -a -n=“Antigravity_pzq3xp76mxafg”

然后再登录就可以了

### 提问Reconnecting问题

**原因**：是插件里的codex.exe没有走vpn

**办法Ⓐ**：梯子开Tun模式

**办法Ⓑ**：梯子开Global模式

注：pac.txt添加chatgpt.com没用

**办法Ⓒ**：Antigravity → Preference → Online Service Settings → 搜索http.proxy → 填[http://127.0.0.1](http://127.0.0.1):xxxx，xxxx是你的vpn端口，一般触碰vpn图标或设置会显示

设置后不管vpn是否开global，都可以用codex
