# pointnext复现遇见问题（自用）



环境配置：①win11 WSL2 Ubuntu24.04 gcc 9.0.0 NVIDIA577.12

②cuda11.3 python=3.7 numpy=1.20 pytorch=1.11.1

设备：gtx 3070

遇见的问题和解决方法

主要参考以下文章

[PointNet++升级版——PointNeXt 复现语义分割（全网最全）_pointnext复现-CSDN博客](https://blog.csdn.net/weixin_44189056/article/details/139420524)

【1】通过pip 或conda指令下载的cuda不完整，需要手动下载安装吧，进行安装tooklist11.3

【2】AttributeError: module ‘distutils’ has no attribute ‘version’

[Python AttributeError: module ‘distutils‘ has no attribute ‘version‘_attributeerror: module ‘distutils’ has no attribut-CSDN博客](https://blog.csdn.net/Alexa_/article/details/132686602)

```
# If you use pip:

pip install torch==1.11.0

# For pip3:

pip3 install torch==1.11.0

# If you use conda:

conda install pytorch=1.11.0
```

【3】ModuleNotFoundError: No module named ‘torch_scatter’

通过手动下载安装，对应torch和cuda版本的文件，通过在虚拟环境里通过以下指令安装。

# 需要下列为对应文件

```
pip install torch_scatter-2.1.0+pt112cu113-cp39-cp39-linux_x86_64.whl
```

【4】ModuleNotFoundError: No module named ‘pointnet2_batch_cuda’

要解决这个的前提是先解决问题【1】，主要是找到不到对应头文件导致的

①先确保有对应的头文件，且是否与nvcc版本对应

```
ls $CUDA_HOME/include/cuda.h
```

/usr/local/cuda-11.3/include/cuda.h

```
nvcc --version
```

nvcc: NVIDIA (R) Cuda compiler driver

Copyright (c) 2005-2021 NVIDIA Corporation

Built on Sun_Mar_21_19:15:46_PDT_2021

Cuda compilation tools, release 11.3, V11.3.58

Build cuda_11.3.r11.3/compiler.29745058_0

②清除残留的编译文件

```
rm -rf build/ dist/ *.egg-info
```

③保持指向正确coda路径

```
export CUDA_HOME=/usr/local/cuda-11.3

export PATH=$CUDA_HOME/bin:$PATH

export LD_LIBRARY_PATH=$CUDA_HOME/lib64:$LD_LIBRARY_PATH
```

④通过**pip install .** 安装路径下的setup.py文件（conda方式已经失效了）

【5】chamfer_dist 安装，出现一个 error: expected initializer before ‘__s128’错误

[NVCC版本与Linux版本不兼容问题 - 李你干嘛 - 博客园](https://www.cnblogs.com/liniganma/p/18608149)

①下载linux-5.4版本

```

cd /usr/local/src

wget https://cdn.kernel.org/pub/linux/kernel/v5.x/linux-5.4.tar.xz

tar -xf linux-5.4.tar.xz

cd linux-5.4

make headers_install INSTALL_HDR_PATH=/usr/local/linux-headers-5.4

```

②仍然不行，在原始的setup.py文件进行修改

```
from setuptools import setup

from torch.utils.cpp_extension import BuildExtension, CUDAExtension

setup(name='chamfer',

      version='2.0.0',

      ext_modules=[

          CUDAExtension('chamfer', [

              'chamfer_cuda.cpp',

              'chamfer.cu',

          ],

          # 新增下面这段 extra_compile_args 配置

          extra_compile_args={

              'cxx': ['-O3', '-isystem', '/usr/local/linux-headers-5.4/include'],

              'nvcc': [

                  '-O3',

                  '--expt-relaxed-constexpr',

                  '-isystem=/usr/local/linux-headers-5.4/include'

              ]

          }),

      ],

      cmdclass={'build_ext': BuildExtension})
```

③通过**pip install .** 安装

也有帖子说可以注释掉这一行可解决，但是并未尝试。

[ubuntu上python setup.py install报错：error: expected initializer before ‘__s128’_error: expected initializer before ‘installfailure-CSDN博客](https://blog.csdn.net/FL1623863129/article/details/145346958)

【6】运行时提示没有找到数据集相关，下载数据，创建date文件夹，然后将文件路径改成对应的绝对路径，如：

```
CUDA_VISIBLE_DEVICES=0 python examples/classification/main.py \

--cfg cfgs/modelnet40ply2048/pointnext-s.yaml \

dataset.common.data_dir=/home/xxx/projects/PointNeXt/data/modelnet40ply2048
```
