## **3.vmware相关设置**

### **3.1设置虚拟机保存位置**

在菜单中点击 “编辑”，然后点击 “首选项“。

![image-20260317005943431681×477 21.7 KB](https://cdn3.ldstatic.com/original/4X/0/d/9/0d91f49f677c81b764bd3fef40d2304d57bb328e.png)

软件默认情况会把虚拟机保存到C盘，需要尽心更改，点击浏览进行配置。

![image-20260317111928923891×177 17.5 KB](https://cdn3.ldstatic.com/original/4X/3/9/7/3975965706794dd50b26c77ccb9f2cd4e1aa6f40.png)

此处我们需要创建一个新的文件夹，下面是详细步骤：

![image-202603170122251252355×614 97.9 KB](https://cdn3.ldstatic.com/original/4X/9/2/8/928e2cf2ba7108cc3b98bbc899f511462f0d0e68.png)

### **3.2设置虚拟机ip地址**

#### **1.进入编辑器菜单**

点击菜单中 ”编辑“，弹出的菜单中选中”虚拟网络编辑器“

![image-20260317012616060438×269 10.3 KB](https://cdn3.ldstatic.com/original/4X/3/b/6/3b648ee73ce5bd831ff50c5805577bee27b4fdf1.png)

#### **2.更改设置**

点击VMnet8，此处会有一个现成地址，这个地址是后续虚拟机选择NAT模式的时候，自动配置的ip地址。要更改选择下面的”更改配置“。

![image-20260317012759828899×819 29.9 KB](https://cdn3.ldstatic.com/original/4X/e/5/c/e5c8644feb4afea610d0ea5653ae8a2341e550c5.png)

#### **3.修改子网ip**

点击后会弹出新的窗口。虚拟机多数情况下使用NAT模式。此处我们更改为VMnet8.默认勾选的不用改动，根据自己喜欢修改子网ip地址。此处为192.168.1.0.子网掩码255.255.255.0。

![image-20260317100752467899×777 41.3 KB](https://cdn3.ldstatic.com/original/4X/2/9/b/29b2b8ab5ab25fb0dc6208565b53b394afe8c57e.png)

#### **4.修改网关**

点击NAT设置，进入后将网关改成”254“。

![image-202603171012040721636×760 44.1 KB](https://cdn3.ldstatic.com/original/4X/6/7/c/67c78dc8f41f3d4091886b81994f22cea29e0b60.png)

完成后最后点确定

![image-20260317101350902899×777 27.2 KB](https://cdn3.ldstatic.com/original/4X/9/5/e/95e5178ac87cb7d4fcf5b547406a46e6fe5e91eb.png)

等待2-5s即可。

#### **5.设置磁盘大小**

此处填写的为最大的磁盘大小，系统并不会立刻从你的磁盘里面划分100G给到虚拟机，所以即使电脑D盘只有20G空间，这里也可以填写100G（精简置备），完成后点击下一步。

### **4.2linux安装**

#### **1.开机进入引导界面**

当勾选了”创建后开启此虚拟机“，点击完成后，linux操作系统会进行安装。

备注：如果没有勾选，在菜单中点击虚拟机开机，同样会进入安装界面。

![image-20260317103429009720×400 7.33 KB](https://cdn3.ldstatic.com/original/4X/3/f/6/3f6708be0542bb24fb1b79e22c21939922238de0.png)

进入后，默认情况会在第二个选项，将鼠标移动到这个框里面，你会先看到一个小手图标–>![:backhand_index_pointing_up:](img/ffb8cf6eaa3b8f85eb3315205a57ba4c.png)，然后点击，点击后小手消失，此时你通过方向键上下进行选择，选择第一个选项”Install Rocky Linux 10.1“（10.1是我当前的版本，其他镜像会显示其他），然后敲击回车键（Enter）

备注：鼠标如果在虚拟机内，按下”Ctrl+Alt“，会从虚拟机回到你的电脑。

等待

## **5.登录系统**

### **5.1进入系统**

系统开机后，会进入登录界面，此处安装的是最小化版本，没有桌面。

linux login → 此处等待用户登录

![image-20260317114303066672×308 2.98 KB](https://cdn3.ldstatic.com/original/4X/c/e/e/cee22040a6948911721995ba9db29dabeec4e186.png)

输入root，输入你设置的密码，如下显示即为登录成功。

![image-20260317114128084840×376 5.2 KB](https://cdn3.ldstatic.com/original/4X/f/f/0/ff0ca311f072b103e22db1e3ea41921dc546b1fd.png)

### **5.2获取ip地址**

输入

```
ip a
```

查看ip地址。

![image-202603171147118451094×403 7.05 KB](https://cdn3.ldstatic.com/original/4X/7/4/2/7424bbf65597c7823c2d72312cdd6a5867d7c849.png)

此处查看到ip为192.168.1.128

### **5.3 网络连通性测试**

win+r 打开windows运行命令窗口，输入cmd打开命令行,将ip改成你的虚拟机ip地址。

```
ping 192.168.1.128
```

确保能ping通。

![image-20260317114903463946×367 12.5 KB](https://cdn3.ldstatic.com/original/4X/d/a/c/dac525fbb057fa74e73d258d91003f3d32a5000a.png)

### **5.4远程连接**

打开MobaXterm工具，点击Session，点击ssh配置，输入虚拟机对应的ip地址，用户，点击OK

![image-202603171152504102298×1275 146 KB](https://cdn3.ldstatic.com/original/4X/7/5/9/75985f88d218a8f7a068595eb5854b385e92bf9e.png)

输入对应密码，按回车确认。

![image-20260317115504082967×610 5.28 KB](https://cdn3.ldstatic.com/original/4X/a/b/c/abcbc7bb201c9bfe62965597c9eec2da40f290aa.png)

弹出是否保存密码，个人选择即可，以下为登录成功。

![image-20260317115708437967×571 18.5 KB](https://cdn3.ldstatic.com/original/4X/c/3/a/c3a89f4cf8378e7f803791d11541e34cba58e5a1.png)
