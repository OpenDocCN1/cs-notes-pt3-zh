## **3.vmware相关设置**

### **3.1设置虚拟机保存位置**

在菜单中点击 “编辑”，然后点击 “首选项“。

![image-20260317005943431681×477 21.7 KB](img/541d336fdec9281ea6658d120c34688e.png)

软件默认情况会把虚拟机保存到C盘，需要尽心更改，点击浏览进行配置。

![image-20260317111928923891×177 17.5 KB](img/219d324d3a088b3e3fbd620ca8c0bdec.png)

此处我们需要创建一个新的文件夹，下面是详细步骤：

![image-202603170122251252355×614 97.9 KB](img/da9bdd1a4aa1f7016efeb391ff324642.png)

### **3.2设置虚拟机ip地址**

#### **1.进入编辑器菜单**

点击菜单中 ”编辑“，弹出的菜单中选中”虚拟网络编辑器“

![image-20260317012616060438×269 10.3 KB](img/c933a586618321c80d06750118f577ee.png)

#### **2.更改设置**

点击VMnet8，此处会有一个现成地址，这个地址是后续虚拟机选择NAT模式的时候，自动配置的ip地址。要更改选择下面的”更改配置“。

![image-20260317012759828899×819 29.9 KB](img/49970fa90906ccfbc5983c908d0452a7.png)

#### **3.修改子网ip**

点击后会弹出新的窗口。虚拟机多数情况下使用NAT模式。此处我们更改为VMnet8.默认勾选的不用改动，根据自己喜欢修改子网ip地址。此处为192.168.1.0.子网掩码255.255.255.0。

![image-20260317100752467899×777 41.3 KB](img/ffe6cd458529522bc3ca2825651e7675.png)

#### **4.修改网关**

点击NAT设置，进入后将网关改成”254“。

![image-202603171012040721636×760 44.1 KB](img/5bf677e3e83211a941b98213ab1b2774.png)

完成后最后点确定

![image-20260317101350902899×777 27.2 KB](img/9028925a7662861efc3bd2ec051b876b.png)

等待2-5s即可。

## **4.安装linux**

### **4.1 创建虚拟机**

#### **1.创建新的虚拟机**

![image-202603171016205391583×594 24.6 KB](img/5812b59b4b0829c280f1c6c5c58b6673.png)

#### **2.选择 ”典型“**

然后下一步

![image-20260317101801207714×674 39.1 KB](img/168decdb1c254842255836de0dd9268a.png)

#### **3.选择镜像**

点击浏览，在弹出的窗口中，选择下载好的linux镜像，点击打开，完成后点击下一步。

![image-202603171021276111637×674 78.7 KB](img/9e63231ffbf8e234e668b07805cf761b.png)

#### **4.修改虚拟机名称**

虚拟机默认为当前镜像的识别到的中文名称，名称最好简介不带中文，设置后点击下一步。

![image-202603171024525181446×674 41.5 KB](img/5c1097a9611a514b714faf5af7322d2a.png)

#### **5.设置磁盘大小**

此处填写的为最大的磁盘大小，系统并不会立刻从你的磁盘里面划分100G给到虚拟机，所以即使电脑D盘只有20G空间，这里也可以填写100G（精简置备），完成后点击下一步。


#### **6.完成配置**

当前17版本的vmware默认是2个核心，2G 内存，这个可以后续改动，此处不操作。

![image-20260317103201965714×674 35 KB](img/4a6fb89c3e603fb30c9bebad146268d8.png)

### **4.2linux安装**

#### **1.开机进入引导界面**

当勾选了”创建后开启此虚拟机“，点击完成后，linux操作系统会进行安装。

备注：如果没有勾选，在菜单中点击虚拟机开机，同样会进入安装界面。

![image-20260317103429009720×400 7.33 KB](img/16f8dada9ea017d63860a1446f4af5e4.png)

进入后，默认情况会在第二个选项，将鼠标移动到这个框里面，你会先看到一个小手图标–>![:backhand_index_pointing_up:](img/ffb8cf6eaa3b8f85eb3315205a57ba4c.png)，然后点击，点击后小手消失，此时你通过方向键上下进行选择，选择第一个选项”Install Rocky Linux 10.1“（10.1是我当前的版本，其他镜像会显示其他），然后敲击回车键（Enter）

备注：鼠标如果在虚拟机内，按下”Ctrl+Alt“，会从虚拟机回到你的电脑。

等待

![image-202603171040314821280×800 12.6 KB](img/953badbfaa4d91415ceed711a6c5a4f6.png)

等待语言选择界面，选择”English“，点击Continue进入下一步。


配置界面

配置虚拟机主机名

设置Root Account

## **5.登录系统**

### **5.1进入系统**

系统开机后，会进入登录界面，此处安装的是最小化版本，没有桌面。

linux login → 此处等待用户登录

![image-20260317114303066672×308 2.98 KB](img/491af4bd07e8851c7e613bb874c0a7a0.png)

输入root，输入你设置的密码，如下显示即为登录成功。

![image-20260317114128084840×376 5.2 KB](img/11215a73194d30cc2f08176be79be1b8.png)

### **5.2获取ip地址**

输入

```
ip a
```

查看ip地址。

![image-202603171147118451094×403 7.05 KB](img/1b36b04fe9994c1d4d8bfe6b0744f44d.png)

此处查看到ip为192.168.1.128

### **5.3 网络连通性测试**

win+r 打开windows运行命令窗口，输入cmd打开命令行,将ip改成你的虚拟机ip地址。

```
ping 192.168.1.128
```

确保能ping通。

![image-20260317114903463946×367 12.5 KB](img/7b2c5820039820dda9c8bbbb65c8433e.png)

### **5.4远程连接**

打开MobaXterm工具，点击Session，点击ssh配置，输入虚拟机对应的ip地址，用户，点击OK

![image-202603171152504102298×1275 146 KB](img/1f0326cf65f330e6d051cc1d56554b43.png)

输入对应密码，按回车确认。

![image-20260317115504082967×610 5.28 KB](img/7c3e96c56b654838a241bad434e68cff.png)

弹出是否保存密码，个人选择即可，以下为登录成功。

![image-20260317115708437967×571 18.5 KB](img/ce69d154923b5751f199057ce5b0e189.png)

至此，linux虚拟机安装完成。
