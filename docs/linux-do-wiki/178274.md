# Azure 在大陆的网络连接情况说明

目前Azure与中国大陆的连接主要通过日本和新加坡两个地区实现。香港地区的连接已于2022年底至2023年初中断。
微软的路由发布策略导致流量尽早进入微软骨干网，可能会出现去新加坡绕日本或去日本绕新加坡的情况。
trace结果（仅代表部分地区）

大多数结果：

新加坡：国内（大概率广州）-新加坡

东京：国内-新加坡-东京

欧洲地区：国内-新加坡-巴黎-其他地区

美西：国内-东京-加州
部分特殊情况：

中国移动可直连东京，不绕新加坡

部分中国联通到美西会走 国内-东京-迪拜-美西
总而言之：国内连azure第一站一定是新加坡或者东京
