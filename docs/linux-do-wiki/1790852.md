# 新时代爽文（0）



新时代是AI的。爽文是抽离的。我串联一些关键词得到了一篇可能逆天的yy小说（让AI写的，但下面的文字我手打的梗概，有删改，随便看看就行）。情节纯属虚构，仅因提到本论坛故发出来。

C1 LM无敌了

主人公——LM，在窗外飞来的大货车把他手中的笔记本电脑撞成了碎片，他懵逼了。于是，他有了一个名为链接（Linking）的功能，他将电脑碎片与人类拼尽一切的概念链接了起来，得到了很厉害的笔记本电脑。

通过网络，LM发现他什么都不缺了，只需要通过链接在现实具现物，甚至不需要完全理解原理。极大富裕后，他无聊极了。

某天，LM百无聊赖地打开了知名论坛[LINUX DO](https://linux.do)，看着佬们说着这里那里的免费资源、这里那里的模型降智，忽然有了一个有趣的想法。

他找出了OpenAI、Anthropic、Google等多个供应商发布过的所有模型，包含那些弃用的模型，将它们与当前版本的最优链接，同时把几年后与现在链接，将GPT-6、Claude 5、Gemini 4实体化。

C2 失落的API

LM为此专门注册了一个新账号@Observer_0，在夜深人静时发了一个帖子。

标题：【福利】一个个人用的API，随便玩，别搞事



内容：Base URL: [https://arc.void.zone/](https://arc.void.zone/)



API Key: LM-42-Is-Just-A-Game

没了，仅仅这两行。

最初，没有人当回事，都以为只是一个新人发的用不了太久的公益站。

当人们发现/v1/models里还有内部实验模型和已下架的模型时，它已经以不可思议的稳定性和免费不降智传播了开来。

C3 人们都疯了

LM的生活一如既往，每天睡到自然醒，吃着链接来的美食，玩玩游戏，时不时潜水窥屏。

他看着这个API从新兴的小众论坛扩散到了V*、G*、R*、H*等等，最后被新闻报道。

整个世界都疯了——一个免费、无限并发、性能强悍的API带给这个世界只有荒谬。有人拿它完成了艺术，有人拿它代替了工作，有人拿它谋取了利益，有人拿它进行了欺诈。

AI巨头们则陷入了慌不择路的境地——营收下降了。CEO对CSO质问：“为什么内部的项目代号会泄露？”巨头们想问责，可却连arc.void.zone的服务器IP都无法追踪到，它在全球各地跳来跳去。

最后各国政府和情报机构也紧急建立了专案组，一个来历不明、超出时代、免费开放的超级AI，其潜在的威胁和价值无可估量。

而LM呢？他正一边喝着无糖可乐，一边看着Github上的一个对神秘API进行逆向工程分析的项目。

C4 看花开花落

LM关闭了互联网的链接，觉得有些乏了。看人类的反应，恐惧、崇拜、贪婪、开拓……太多了，他只是丢下微末的祝福，就引发了混乱。
