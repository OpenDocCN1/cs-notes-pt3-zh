# 国内的御三家各自有各自的优缺点~



仅个人感觉 ![:melting_face:](https://cdn.ldstatic.com/images/emoji/twemoji/melting_face.png?v=15)

glm

1. 便宜套餐目前似乎不支持 glm5，现在支持glm5.1，glm4.7能力太弱，勉强和 sonnet4.5打平吧

2. 图片理解能力一般，但是好处是有云端的mcp不用去安装插件

3. 价格太贵了



PS: 包月顶级套餐受害者~

kimi

1. 能力一般，速率限制太狠，价格太贵(不包含 0.99$套餐)



PS: 简单测试过，没有购买过更大的套餐尝试

MiniMax

1. Claude code 兼容差劲，上下文长度未兼容，多模态MCP未兼容(需要单独安装plugin)

2. 指令遵循有点差(CC) 我让他开启Plan模式，他问我什么是Plan模式 ![:melting_face:](https://cdn.ldstatic.com/images/emoji/twemoji/melting_face.png?v=15)

3. 项目稍微一大，就感觉有点蠢了，对于大项目没有很好的理解能力以及问题挖掘能力



PS: 199 Plus包月套餐 用的 2.7

最近新星，小米的模型，官方充钱用起来感觉还是不错的，我冲了几十块钱测试了一下，一上午用完了，不知道是不是因为目前用的人不是特别的多，算力还够



然后下午开始用 openclaw的2api渠道，然后就立马感觉到了差距~
