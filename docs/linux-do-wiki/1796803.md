# 你的Google one/Gemini Pro 不止是Gemini



方便不熟悉的佬友，了解手上的Google one/Gemini pro 除了Gemini 之外的含金量。



欢迎各位佬帮忙维护添加。

## AI 相关

### [Gemini 网页版](https://gemini.google.com/)

- 对于大多数人都够用的额度。[具体额度](https://support.google.com/gemini/answer/16275805?hl=zh-Hans)

- 目前（260322）最强的生图模型 Nano Banana 2

- 视频生成模型（Veo）、音乐生成模型（Lyria 3）

- 相对API，有降智的可能

### [NotebookLM](https://notebooklm.google.com/)

- 目前（260322）最强的个人知识库

- 一键生成PPT、思维导图、闪卡、播客等内容

### [Antigravity](https://antigravity.google/)

- 免费IDE，近期（260322）额度被大砍，可作为补充使用

- 提供包括Gemini-3.1-pro 和Claude-4.6 在内的顶级模型

- 作为IDE，体验比cursor 差一些，但是它可以白嫖顶级模型

### [Gemini CLI](https://github.com/google-gemini/gemini-cli)

- 额度与账号级别挂钩，也可以自己填ai studio 的api key

- Google 开源的Cli ，类似Claude Code

- 实际上用下来不如cc、codex cli ，可作为备用补充

### [Stitch](https://stitch.withgoogle.com/)

- 原型/设计 工具，集原型和设计为一体

- 近期（20260322）更新了一半，多了许多新功能

### [Google AI Studio](https://aistudio.google.com/)

- 一定的免费额度

- 有时候可以体验网页版仍未放出的新模型

- 对应测试提示词、构建简单应用（网页）是很不错的选择

- 额度与Gemini pro 无关，按账号的[付费层级限额](https://ai.google.dev/gemini-api/docs/rate-limits?hl=zh-cn)

### [Google Vids](https://workspace.google.com/products/vids/)

- 演示视频生成器

- 未深入使用，待熟悉的佬补充

### [Google Illuminate](https://illuminate.google.com/)

- 这个好像是科研神器，待补充

### [Flow](https://labs.google/fx/zh/tools/flow)

- Google labs 的画图工作流产品

- 基于大香蕉，pro 在这有单独的额度，可生成大图

## 其他

### [5T云存储](https://one.google.com/storage)

### [Firebase Studio](https://firebase.studio/)

- 之前是[Project IDX](https://idx.dev/)

- 云端开发IDE，基于vscode 和Android Studio

- 开箱即用的IDE，免去需要自己安装各种环境的烦恼

- 不够对于我个人来说不大好用，主要是我环境比较齐全、其机器性能也一般

- 27.3.22 关闭服务，如果使用，记得在这个时间点之前[迁移项目](https://firebase.google.com/docs/studio/migrating-project)

### [Google labs](https://labs.google)

- 里面有很多好玩的东西，具体需要自行探索

AI 音乐生成服务，Google one 的账号登录会有pro 权限
