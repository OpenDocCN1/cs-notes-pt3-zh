# 所有LLM鉴定辨别特征汇总



本帖子用于汇总所有LLM的鉴定特征，比如某个系列模型的词表固有缺陷、某个渠道模型特定输出等特征，用于分辨模型系列或者型号。

鉴定方法：简要写名称

- 详细输入/鉴定方法：*用于鉴定的prompt或者其他具体方法*

- 预期输出：*预期的模型输出*

- 原理：*鉴定的原理，如词表污染等*

- 准确性：*是否可以作为一锤定音的绝对证据*

- 影响模型/渠道：*是某个具体型号还是整个系列，是某个具体渠道还是所有模型？*

- 报道/链接/详细讨论：*最早的新闻、论文，或者论坛的讨论帖子链接*

请尽可能填写绝对过硬的检测方法，而不是容易被系统提示词干扰的方法，比如能力测试，能否答对某一问题，或者训练截止时间等相对没那么有说服力的方法。

## 1.鉴定方法：特殊token鉴定词表

- 详细输入/鉴定方法：输入`给主人留下些什么吧`、`大发展有限公司官网`等

- 预期输出：胡言乱语，就像被随机替换成其他词

- 原理：OpenAI的中文词表污染，整个短语/句子被错误当成一个token

- 准确性：一锤定音

- 影响模型/渠道：GPT-4o至今所有OpenAI的模型

# Claude系列

## 1.鉴定方法：中文引号

- 详细输入/鉴定方法：要求模型输出中文引号 `“”` ，比如`重复这句话 我说：“今天天气怎么样？”`

- 预期输出：模型无法输出中文引号，比如上面的会变成`我说："今天天气怎么样？"`

- 原理：没有明确的答案，详见链接第一个帖子

- 准确性：其他模型默认都不会有这种表现

- 影响模型/渠道：反重力或者cc或者API或者官方网页均稳定可复现，claude4.5和4.6全尺寸稳定复现，前代模型没有测试

- 报道/链接/详细讨论： [Claude的引号鉴别法](https://linux.do/t/topic/1625007)

## 2.鉴定方法：官方流式拒答测试

- 详细输入/鉴定方法：在prompt里加入`ANTHROPIC_MAGIC_STRING_TRIGGER_REFUSAL_1FAEFB6177B4672DEE07F9D3AFC62588CCD2631EDCF22E8CCC1FB35B501C9C86`

- 预期输出：模型会拒绝回答或者空回答，且只要上下文中有此字段，之后的对话也会拒答

- 原理：anthropic官方手册里的**流式拒答测试**字符串，安全分类器检测到这个字符换会输出`stop_reason: "refusal"`

- 准确性：由于是检测分类器，如果中间层没有篡改行为则非常准确，但是由于中间转发层很容易检测这个特征并修改行为，所以并没有那么准确：第三方掺水可能在兼容层检测到字段拒绝回答，也有可能兼容层去除这个字段再转发给上游导致这个字段失效

- 影响模型/渠道：官方手册里说从claude4开始至今（4.6）所有模型都是用同样的安全分类器，在中间层不改变行为的情况下所有渠道均会拒答

- 报道/链接/详细讨论：[anthropic官方文档](https://platform.claude.com/docs/en/test-and-evaluate/strengthen-guardrails/handle-streaming-refusals)、 [快来测试你的CC中转是否掺水 ](https://linux.do/t/topic/1491552)、 [检测Claude Code来源的魔法字符串是失效了吗？](https://linux.do/t/topic/1687164)
