# 关于共建Wiki站【社区守则】板块的倡议



总结站内一部分用户的诉求：



认为始皇仅在`运营反馈`与`公告`标签内使用`置顶`功能颁布规则，效果不佳，容易被时间淹没。



希望能够有一个：

- 统一整理

- 语言精炼准确



的站内规则汇总。

其实Wiki站内已在部分整理贴的基础上进行了搜集整理，并关注更新，见 [https://wiki.linux.do/Linux-Do/rules](https://wiki.linux.do/Linux-Do/rules) 。



但无奈人手不足，存在无法及时更新的可能，且语言可能不够精炼。

现仅以我个人向佬友们提出倡议，邀请各位共建Wiki站的规则板块。



有能力PR的佬友可以前往[GitHub](https://github.com/Chenyme/Linux-Do-Wiki/pulls)提交PR，或者在评论区内贴出，并@我，或者管理者chenyme，或者@路过的佬友也可帮忙代发。

> 真诚、友善、团结、专业，**共建**你我引以为荣之社区!
