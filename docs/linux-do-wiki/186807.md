# 有没有研究未来史学的同道

1.自由发帖

2.本帖主要讨论关于未来是如何发展，或者说按照怎样的规律发展

3.尽可能发挥直接想象，但一定要根据现有的技术和政策、国际局势来推算

4.数字沙盘，推算，演化

5.未来史学家我第一次接触是阿西莫夫的小说《银河帝国》

6.我来开个头，此猜想来自三年前与朋友喝酒闲谈：

2042年后进入元宇宙时代

2050年达到顶峰 世界上百分之95的人口进入元宇宙生活与工作

2080-2100年 元宇宙进入平和低谷期 部分人类想要恢复现实生活 营养液维持 大约有百分之30的人口进入现实生活 属于时代的落幕者

同时期 地球周边行星 如 金星 火星 月球 已建立基础生存基地
2100年后 元宇宙的第二次顶峰 人口被控制 禁止个人私下生育 人类在元宇宙拥有了几乎无限的生命 人造人通过 主流现实世界由机器人维系

地球政权控制人口出生死亡  元宇宙忠实拥蹵者被称为数据派 主流现实世界在改造周围行星卫星
2120年 由21世纪存活来的现实地球原住民开始抗议元宇宙内的生活方式 监管级别严重 想要恢复人身自主权 长达二十年的内乱 伙同部分现实派同数据派做争斗
2150年 元宇宙落幕 人类分为两极化 数据派与移民派 从元宇宙搬迁至现实世界属于移民派 移民派主要分布地区为金星  地球政权控制移民派在地球上的人口  同时 移民派分为两大政权 火星现实政权与元宇宙控制政权 移民派拥有自主生育及生存权
