## 内网穿透

如果要本机给服务器用的话



要注意本机的Windows 防火墙要关掉，不然服务器连不上这边。也有可能是机器上还有别的安全软件/网络过滤层在拦。

还有个思路是用 SSH 隧道，把服务器本地端口转到本机电脑的 8317



在服务器连接本机



`ssh -N -4 -L 127.0.0.1:8317:127.0.0.1:8317 本机用户名@本机的ip`



那服务器填的就是配置填的就是127.0.0.1:8317



如果只是开放端口，要填本机的ip

failed to start callback server 。 1455端口被vscode占用，需要把vscode都给关了。



[VS Code Codex 登录失败（1455 端口占用）处理说明_登录失败:failed to start login server: port 127.0.0.1:-CSDN博客](https://blog.csdn.net/qq_39665253/article/details/157939257)

远程浏览器要打开同样的cpa网站，因此需要内网穿透。如果只在本机添加远程浏览器认证的auth的话，会出现oauth flow is not pending。要远程浏览器自己添加。添加到回调栏里面。

额度获取失败：timeout of 30000ms exceeded 一般是网络的问题，换个节点
