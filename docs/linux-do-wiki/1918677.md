# ✨ 论坛排版魔法小课堂 ✨
---
大家平时发帖是不是经常觉得排版有些单调呀~ 刚才测试发现，咱们论坛其实默默支持了很多超棒的 HTML 魔法标签
今天就给大家整理了一份「排版美化指南」，只要复制下面代码块里的内容，就能立刻实现各种神奇的效果😇
有时候咱们想要在帖子结尾署名，或者把重要的标题居中，就可以用到这两个小魔法：
我是居中的乖宝宝
我是悄悄跑到右边的署名君
```
<div align="center">你要居中的文字</div>
<div align="right">你要放在右边的文字</div>
```
想要开个小玩笑的时候，删除线就派上用场啦
这是一句一句说错的话
```
<s>这是一句说错的话</s>
```
如果帖子里有长长的名单，或者想放个惊喜彩蛋，这个折叠面板简直是神器！点一下才会打开哦
锵锵！恭喜你发现了隐藏的宝藏！
```
<details>
  <summary>点击我，看看里面藏了什么~</summary>
  <p>锵锵！恭喜你发现了隐藏的宝藏！</p>
</details>
```
这里有个一定要注意的「大坑」！标题标签（也就是 hn n为1 2 3 4 5等不同的标题大小~ 1最大）非常调皮，千万**不要**把它夹在一句话的中间
如果你不小心把它混在句子里，甚至只是用代码块把它包起来，它不仅会自己隐身，还会把后面的所有文字都变成巨大的标题！如果非要用，记得一定要像这样让它单独待在一行：
```
<h1>我是遵纪守法单独一行的标题~</h1>
```
为了方便大家随时查阅，我把今天学到的常用标签都整理在这个表格里啦
| 想要的效果 | 使用的代码 | 小提示 |
| --- | --- | --- |
| 居中对齐 | <div align="center"> | 可以配合换行标签 <br> 一起用 |
| 右对齐 | <div align="right"> | 署名专用好帮手 |
| 文字加粗 | <b> | 基础款强调 |
| 删除线 | <s> | 适合用来吐槽和开玩笑 |
| 折叠面板 | <details> 和 <summary> | 防长文、藏彩蛋的绝对神器 |
| 大标题 | h1 标签 | 千万别夹在句子里用！必须单独占一行！ |
今天的魔法课堂就到这里啦，在今后的互动水帖中大显身手吧 😇
