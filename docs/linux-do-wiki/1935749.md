# 如何优雅的使用X



X官方客户端现在由于时间线上充斥着各种广告，推广，机器人，涩涩，B圈等内容，实际体验来说基本属于不可看的状态，刚上去其实已经很难搜索到有用的信息了，需要自己不断关注一些优质账号才行。我这里提供一些方法，来过滤掉一些糟糕的内容，保证X的信息能回归到过去的正常一些的体验。

1. 自动屏蔽广告账号



手机上可以安装GKD程序，GKD不止可以过滤开屏广告，也可以自动屏蔽官方客户端的广告账号。Web浏览器上可以安装AdGuard插件，也可以过滤广告。但是有时候这些广告账号还是层出不穷，使用官方客户端还是无法完全屏蔽掉。所以还是需要使用第三方客户端。

2. 第三方客户端



我这边使用的是这款第三方客户端，[GitHub - crimera/twitter-apk: Apk builds of piko patches · GitHub](https://github.com/crimera/twitter-apk)



基于 [piko](https://github.com/crimera/piko) patches来重新打包的程序，可以直接过滤掉所有X上的广告。这款打包程序直接登录X是无法正常登录的，需要先用Proton Pass程序登录官方客户端并保存密钥，然后在官方上开启密匙登录，卸载官方客户端后，选择用Proton Pass才能正常登录。

3. 关键词屏蔽



使用这些去广告手段之外，X上还充斥着大量机器人，瑟瑟、政府雇佣的机器人或水军账号，这些账号会发送大量垃圾信息来稀释你的时间线，保证他们的垃圾信息淹没你有用的信息，以此来达到他们的目的。



这些大量机器人账号你是封禁不过来的，屏蔽多了，还可能被X本身风控导致你自己的账号被封禁。所以关键词屏蔽是有效的手段来屏蔽这些内容。



进入X设置-隐私安全-隐藏和屏蔽-隐藏词，在这里添加相关屏蔽词，推荐用英文冒号来设置屏蔽词，这样屏蔽效果更好。比如设置"万达广场"、“蹲一个”、“线下”

1. 隐私泄露保护设置



最后就是隐私泄露设置，在x设置中，广告偏好设置里面取消个性化广告，推断身份取消推断身份，取消共享数据和位置信息，允许认识的人找到我当中，取消勾选通过电子邮件和手机号找到你，并取消勾选同步通讯录联系人。

2. 通过AI agent进行访问



可以安装这个项目：[GitHub - Panniantong/Agent-Reach: Give your AI agent eyes to see the entire internet. Read & search Twitter, Reddit, YouTube, GitHub, Bilibili, XiaoHongShu — one CLI, zero API fees. · GitHub](https://github.com/Panniantong/Agent-Reach) 里面有twitter cli，帮你抓取推文，或者查询时间线，并让AI汇总。

现在互联网环境比过去几年已经大范围的降低质量了，无论是国内还是国外，所以作为当代数字人，需要更多的精力来解决遇到的问题，这也真是没什么更好的办法。现在只能寄希望于下几代的人们，有更高的智慧来做事情吧。
