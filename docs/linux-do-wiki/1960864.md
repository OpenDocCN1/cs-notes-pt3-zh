# 使用Dante在VPS上搭建SOCKS5代理服务详细教程



1. 选择VPS提供商：您需要选择一家可靠的VPS服务商。建议选择网络连接稳定、带宽充足的VPS，特别是如果需要特定地区IP（如美国IP）时。

2. 操作系统选择：大多数SOCKS5代理服务器都支持Linux系统，推荐使用Ubuntu或CentOS。本教程以Ubuntu为例。

3. SSH工具：准备SSH客户端（如PuTTY或终端）用于远程连接VPS。

###安装Dante SOCKS5服务器

1. 连接到VPS：使用SSH客户端连接到您的VPS服务器：



`ssh root@VPS_IP_ADDRESS`



输入密码后即可成功连接。

2. 更新系统软件包：



`sudo apt update && sudo apt upgrade -y`



这一步确保系统所有软件包都是最新版本。

3. 安装Dante服务器：



`sudo apt install dante-server -y`



这将安装Dante SOCKS5代理服务器软件。



配置Dante服务器

4. 编辑配置文件：



Dante的配置文件通常位于`/etc/danted.conf`，使用文本编辑器打开：



`sudo vi /etc/danted.conf`

5. 基本配置示例：



将以下内容添加到配置文件中（根据实际情况调整）：

```
# /etc/danted.conf - Dante SOCKS Proxy 配置文件

# 安全、稳定、可运行的完整配置

# 请根据您的实际网络接口和 IP 地址修改 internal 和 external 字段。

# ===== 基本设置 =====

# 监听的内部接口和端口（必须指定真实接口或 IP）

# 查看接口：ip a

# 或使用具体 IP（推荐用于多 IP 服务器）：

# internal: 23.27.24.228 port = 1080

# 示例（特定网卡）：internal: eth0 port = 1080

# 示例（所有网卡）：internal: 0.0.0.0 port = 1080

internal: 0.0.0.0 port = 41080
internal: :: port = 41080

# 出站流量使用的外部 IP 地址（不能是 0.0.0.0）

# 必须是服务器的真实公网或内网 IP

external: 2400:8d60:9:0000:0000:0000:f804:398c

# 指定运行权限（必须）

user.privileged: root
user.notprivileged: nobody

# ===== 认证方式（关键！避免被拒绝所有连接）=====

# 启用用户名密码认证（推荐）或允许无需认证（仅限内网信任环境）

# 可选：username, pam, none

socksmethod: username none

# 如果您希望某些 IP 不需要认证，可设置多个规则（见下方 socks block/pass）

# 客户端认证方式

clientmethod: none

# ===== 日志配置 =====

# 确保路径存在且可写（解决 “Read-only file system” 错误）

logoutput: /var/log/danted.log

# ===== 访问控制规则 =====

# 客户端连接规则（允许谁连接到 SOCKS 代理）

client pass {
from: 0.0.0.0/0 to: 0.0.0.0/0
log: connect disconnect error
}

client block {
from: 0.0.0.0/0 to: 0.0.0.0/0
log: connect error
}

# SOCKS 服务规则（允许通过代理访问哪些目标）

socks pass {
from: 0.0.0.0/0 to: 0.0.0.0/0
command: connect
method: username none
log: connect disconnect error
}

socks pass {
from: 0.0.0.0/0 to: 0.0.0.0/0
command: bind
method: username none
log: connect disconnect error
}

socks pass {
from: 0.0.0.0/0 to: 0.0.0.0/0
command: udpassociate
protocol: tcp udp
method: username none
log: connect disconnect error
}

# 拒绝其他所有请求

socks block {
from: 0.0.0.0/0 to: 0.0.0.0/0
log: connect error
}
```

注意：



• eth0可能需要替换为您的VPS实际网卡名称（使用ip a命令查看）



• port = 41080是默认SOCKS5端口，可根据需要修改



• method: username none表示不需要用户名密码认证，如需认证请参考后续章节



3. 保存并退出编辑器：



在vi编辑器中，按 ESC ，然后按 :wq 确认保存退出。



启动和管理Dante服务

1. 启动Dante服务：



`sudo systemctl start danted`

2. 设置开机自启：



`sudo systemctl enable danted`

3. 检查服务状态：



`sudo systemctl status danted`



如果显示"active (running)"则表示服务已成功启动。

4. 检查端口监听：



`netstat -tulnp | grep danted`



应该能看到1080端口正在监听。



防火墙配置



确保防火墙允许SOCKS5代理端口的流量：

5. Ubuntu使用ufw：



`sudo ufw allow 41080/tcp`

6. CentOS使用firewalld：



`sudo firewall-cmd --add-port=41080/tcp --permanent`



`sudo firewall-cmd --reload`



添加用户名密码认证（可选）



如需增加安全性，可以设置用户名密码认证：

7. 修改配置文件：



将method: username none改为method: username。

8. 创建系统用户：



`sudo useradd lopins`



`sudo passwd lopins`



设置密码并记住，客户端连接时需要提供。

9. 重启Dante服务：



`sudo systemctl restart danted`



客户端配置



搭建完成后，您可以在各种客户端上使用SOCKS5代理：

10. 浏览器配置：



• 在代理设置中输入VPS的IP地址和端口号(1080)



• 如果设置了认证，输入用户名和密码

11. curl测试：



`curl --socks5-hostname VPS_IP:41080 https://www.example.com/`



如需使用认证：



`curl --socks5-hostname username:password@VPS_IP:41080 https://www.example.com/`

12. 全局代理设置（Linux）：



编辑/etc/environment文件，添加：

```
    http_proxy=“socks5://VPS_IP:41080”
    https_proxy=“socks5://VPS_IP:41080”
```

```
常见问题解决
```

1. 无法连接到VPS：



• 检查VPS的IP地址和SSH端口是否正确



• 确保VPS提供商没有限制SSH访问

2. Dante服务无法启动：



• 检查配置文件是否有语法错误



• 查看系统日志获取详细错误信息：journalctl -xe

3. 客户端无法连接到代理：



• 检查VPS防火墙设置，确保代理端口已开放



• 确认客户端输入的IP、端口、用户名和密码正确

4. 代理速度慢：



• 可能是服务器性能不足，考虑升级VPS配置



• 检查网络连接质量，选择地理位置更近的VPS



高级配置

5. 多IP支持（站群）：



对于有多个IP的VPS，可以使用自动设置网卡规则的脚本：



`wget -q -N --no-check-certificate https://raw.githubusercontent.com/wyx176/Socks5/master/install.sh && bash install.sh`



安装后可通过命令管理用户：` /etc/init.d/sockd adduser USERNAME PASSWORD`

6. 日志管理：



可以配置Dante将日志输出到特定文件，便于监控：



`logoutput: /var/log/danted.log`

7. UDP支持：



在socks pass部分添加protocol: tcp udp以支持UDP协议。



安全注意事项

8. 使用强密码：如果启用认证，务必使用复杂密码。

9. 限制访问IP：可以在配置文件中修改from: 0.0.0.0/0为特定IP范围，限制访问。

10. 定期更新：保持系统和Dante软件更新到最新版本。

11. 合规使用：SOCKS5代理本身是透明代理，请勿用于任何违法用途。
