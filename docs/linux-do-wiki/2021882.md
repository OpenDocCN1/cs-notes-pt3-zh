# [合集] 关于我打算周更这件事...



先来自我介绍一下，我是白芸汐，一个秃头老登程序员，未来一定会被裁员然后去卖炒粉的那种。

我是一个经典的河南农村出来的小镇做题家，上大学的时候什么都做过，不管是保洁、打螺丝、**卖炒粉炒面**以及代课接单等等基本上都干过，也去过山村支教，干了一个学期加一个暑假。

后面工作了，就是经典大厂牛马，干的受不了了跑路换了几家公司到了现在的小厂，这中间我还接过私活，打过数据标注，送过外卖，当过保安，代写过公众号等等。

虽然我这个人知识没多少，大概就是半文盲的水平，但是我喜欢吹牛逼表达一点观点，所以现在也是混成了项目经理加程序员的双重职位（无双倍工资，只有奖金）。

自从来到L站之后，我发现这里个个都是人才，说话又好听，所以我打算每个周更新一点吹水的文章，望各位佬友可以忍受我的碎碎念和闲聊吹水，我在这里先给各个佬友道个歉 ![:distorted_face:](img/704374cc3bdbbb947740876b464e0c74.png)

本篇主题也作为所有瞎扯淡的文章合集和监督我更新的地方，如果我有哪一周没有更新（春节除外，判定时间为发布时间不在本周内，即周日晚十二点），前三位佬友来催更的佬友我愿意提供各1000LDC作为监督催更的辛苦费（如果有其他意外情况我会提前说明），并且专门开主题来让所有佬友严厉批评这种拖更行为。

所有的文章都会发在 [搞七捻三](/c/gossip/11) 的0级区，希望各位佬友可以不要嫌弃我生产垃圾废料，我也会不断充实自己，希望早日追上各位佬友的步伐，尽量不吹牛，如果有错可以尽情的批判，欢迎交流 ![:distorted_face:](img/704374cc3bdbbb947740876b464e0c74.png)
