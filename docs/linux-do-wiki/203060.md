# 应用数据目录设置思路分享，拯救你的 C 盘空间



**声明：本文面向新手用户，大佬可以无视。**



众所周知，程序的默认安装目录和数据目录一般默认在 C 盘，比如微信、QQ 等软件的聊天数据，包含文件视频动辄几十 G。本文介绍几个思路，旨在将应用的数据目录存储在自己想要的磁盘或分区。

- **一、使用解压即用的绿色软件**

部分绿色软件的数据目录就在当前软件的目录，如果将软件解压至非系统盘，自然避免上述问题。

- **二、手动指定软件的数据目录**



这要求软件提供了相关设置，可以手动将目录指定到非系统盘，也可实现需求。

- **三、创建目录软链接**



即使前两种方法可能解决了一部分的问题，但是因为需要进入软件额外配置，甚至有些软件没有设置数据目录的地方，比如 Chrome 浏览器原版。其目录默认就在 %USERPROFILE%\AppData\Local\Google\Chrome\User Data 目录下。这个时候我们可以通过创建软链接的方式实现数据目录保存在非系统盘。以 Chrome 原版为例，迁移思路如下：

1. 将原始数据目录（`%USERPROFILE%\AppData\Local\Google\Chrome\User Data`）拷贝到期望的磁盘或分区，比如 `D:\Data\Chrome`

2. 重命名或者删除原始数据目录，这里将 `%USERPROFILE%\AppData\Local\Google\Chrome\User Data` 的 User Data 文件夹重命名为 `User Data1 `，防止迁移失败导致的数据丢失。

3. 使用终端执行以下命令创建软链接。

```
if not exist "%USERPROFILE%\AppData\Local\Google\Chrome" mkdir "%USERPROFILE%\AppData\Local\Google\Chrome"
mklink /D "%USERPROFILE%\AppData\Local\Google\Chrome\User Data" "D:\Data\Chrome"
```

第一行命令确保目标目录的上级目录已被创建，第二条执行软链接创建。

1. 检查目录是否创建，软件运行是否正常，数据是否丢失。



通过以上几种方式，可以将软件数据目录存放在非系统盘内。解决了两大问题：一个是 C 盘空间可能有限，避免 C 盘空间用尽，另一个是如果想要重装系统，可以保留数据或快速初始化软件，减轻重装后的配置还原工作。



另外创建软链接的方式还可以手动简单管理软件版本，比如同时安装了 JDK 8、JDK 11、JDK 17，可以创建一个 JDK 的软链接目录，并配置环境变量为该目录，想切换版本，就执行删除软链接和创建软链接命令，就能无缝切换 JDK 版本。如果不想使用 vfox、sdkman 等工具，这也不失为一种方法。
