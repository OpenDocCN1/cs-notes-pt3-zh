# 从 0 到 1 搭建自己的脚手架，求佬指教

## 一、脚手架是什么
脚手架是一种基础设施工具，用于快速生成项目的框架代码和文件结构。它是一种标准化的开发工具，使开发人员能够在项目的早期阶段快速搭建出一个具备基本功能和结构的系统。
