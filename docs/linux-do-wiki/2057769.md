# 【更新Wise入金】关于Timon尼区付款的一点详细说法



[IMG09501320×2868 221 KB](https://cdn3.ldstatic.com/original/4X/f/9/4/f94fa29633ac7c42925616f7914f09252a5fa714.jpeg)

已经成功开了，详细说一下：

Timon是有美元银行账户和奈拉银行账户的，但是因为你的这个是小黑认证的，而开美元银行账户对小黑来说是国际账户，所以需要小黑的护照，但是小黑一般都是没有护照的，所以默认美元银行账户都是开不了的。因此只能通过crypto入金，推荐是USDC，像是Base链这种的话gas是很少的，所以不用担心。

奈拉银行账户是可以直接开的，但是入金是个问题，因为奈拉账户上小黑的名字不是你的名字，所以如果用Wise入金是非同名转账，两边都是有封控的风险的。

至于银行卡，是有Blue和Black两种，Black的地址是美国的地址，Blue的地址是小黑当地的尼日利亚地址，这也是为什么只开Blue卡，因为其他的卡地区不是尼区的。

Blue卡除了这张Timon Blue美元货币卡，还有一个Timon Blue Verve奈拉卡，这是两张卡，另一张的开卡费是3000奈拉（十几块），这个美元卡则是5美元。另一张尼区卡应该也是能用的，如果你有直接入奈拉的渠道用那张卡肯定是更好。

[IMG09511320×2868 217 KB](https://cdn3.ldstatic.com/original/4X/9/3/2/932194878ec2ea10f4d4252b0be15dc89896ff79.jpeg)

如果只有加密货币入金的方法，推荐是只开美元卡就行了，因为花的时候直接按国际汇率转换的。不然你在Timon上换成奈拉，汇率比较差，用美元卡直接花的话就是有国际汇率转换费还有一点手续费。

如果有人试了可以用Wise或者国际转账（每家银行都可以转，就是到账慢手续费多而已）直接转奈拉的话，那么我觉得直接开奈拉卡用和付就行。

总结一下就是如果只有美金入金方式就用美元卡，有奈拉入账方式就用奈拉卡，因为Timon的汇率太宰客了，能不用就不用。
