# 【键盘科普】关于键盘你可能需要知道的那些事(轴体篇)

本帖是作为玩了键盘4年的键圈新人写的键盘轴体科普，也是站在机械键盘吧诸多科普贴肩膀上的作品，算是一个省流版，如果想要详细了解相关知识，建议去机械键盘吧详细了解。
如果佬友们有键盘选购的需求，可以在此贴留言，也建议去机械键盘吧发帖询问，里面广告还是较少的。
# 1 键盘的定义与分类
## 1.1 什么是键盘
键盘最简单的定义是：一种把人的动作转换成输入信号的输入设备。最早源自于打字机，后来演变成了机械键盘、薄膜键盘、静电容键盘等等。
## 1.2 键盘分类
目前市面上的键盘可以大致分为：机械键盘、静电容键盘、薄膜键盘、光轴键盘、磁轴键盘。它们的名字来源也是最核心的区别就是触发方式，即：按键被按下后，如何判断这个键被触发。由此而来，形成了不同的声音、手感和性能。
### 1.2.1 机械键盘
机械键盘的触发依靠每个按键下方的机械开关（switches），即机械轴。轴体内部有两个金属弹片，当按键按下，触点接触，就会导通形成电路，控制芯片识别到电平变化，就会判断该按键被触发。
机械轴体通常包含轴心、弹簧、上盖、底壳、金属弹片五个部分，润轴就是针对这五个部分涂上润滑剂，使得手感丝滑，声音好听。基于此结构，诞生了直上直下的线性轴与修改了轴心小脚或加入发声结构的段落轴。
### 1.2.2 静电容键盘
静电容通过电容量的变化来判断按键是否按下，即按键下压后，内部的锥簧发生形变，键盘检测到的电容量就会变化，控制芯片以此判断触发。
一个静电容轴通常包含推杆、（橡）胶碗、弹簧。里面还有可能具有橡胶圈。静电容键盘的手感十分独特，按下时具有沙沙的手感和声音，因此受到不少人的喜欢。
### 1.2.3 薄膜键盘
薄膜键盘是目前最常见且成本最低的一类键盘了。
它的核心特征就是按键下方并非独立的开关，而是多层具有电路的薄膜，包括上层电路薄膜、下层电路薄膜、以及中间的隔离层。
当按键按下后，胶碗或其他回弹结构（结构不同，薄膜键盘的手感也有差别）下压，上下两层薄膜的导电触点接触，电路就会导通，控制芯片因此判断触发。
### 1.2.4 光轴键盘
光轴键盘的外观、很多轴体结构与机械键盘的MX轴结构相似，但是触发方式为光信号的变化。即发光元件发出光线、传感器检测光线状态，按键按下后会改变光路，于是控制芯片就有依据判断按键是否触发。
### 1.2.5 磁轴键盘
近年热度因竞技游戏的需求而陡增，通过磁场变化来检测按键位置。
在传统机械键盘的基础上，磁轴键盘在轴心下面嵌入磁铁，PCB上的轴座换成霍尔传感器，当按键上下运动时，磁铁与霍尔传感器的距离发生变化，磁场强度也随之变化，于是控制芯片可以实时判断按键按下的线程。相较于机械轴弹片接触的固定触发行程，磁轴可以通过软件更改触发行程，因此可以做到急停等操作。*电容、电感轴理论上也有这种能力，但是因为磁轴概念火得早加上行业内卷，因此技术上代差较大，开发成本高，所以大家都在做磁轴键盘。*
# 2 机械键盘的轴体
为什么只谈机械轴呢，因为机械轴种类多、厂商多、市场大，而其他轴市场小，磁轴又是看精度参数和声音手感就能选的，且结构大差不差，所以不提及。
## 2.1 轴体基础
轴体在作为触发结构的同时，也决定了按键的手感、触发行程、回弹和很大程度的决定了声音。
对于机械键盘，声音由轴体、键帽、外壳、定位板、填充、PCB所形成的整体声学结构决定。因此不少填充很满的键盘会形成声音的同质化，配上便宜轴声音不一定难听，但是手感是一定由轴体决定的，选购一个喜欢的轴体是选一把自己喜欢的键盘的重中之重。
## 2.2 机械轴的类型
目前轴体大致由樱桃研发且专利到期的 MX轴/类MX轴 和 凯华具备专利的 BOX轴 两种类型。
### 2.2.1 MX轴
MX轴是目前市场上最主流的轴体结构，由德国Cherry公司推出，故Cherry自家的MX轴也叫原厂/樱桃轴。其专利轴心为十字轴心，也有在四周加入防尘壁的轴心，一般而言十字轴心更容易实现HIFI的声音。
自从专利到期后，Cherry固步自封，樱桃轴保持稳定性差（按下轴心时有摇晃的感觉）、弹片声响（润滑少或无润滑）、价格贵，因此被国产快速迭代的MX轴占据国内大部分市场。
### 2.2.2 BOX轴
BOX轴的形状到轴心都和MX轴区别很大，触点用的是卧式触点，轴心周围有一圈圆形防尘壁，优点是稳定性好且防尘能力强。其手感、声音自成一派，XX冰淇淋轴系列均为BOX轴。
## 2.3 轴体手感与声音
轴体更多详细的介绍略。大家更注重的肯定是声音手感这一块的，所以直接介绍手感和声音，详情可以去查阅参考文献。段落轴和线性轴在这方面存在区别，还有静音轴不让发出声音，这些会在后面的讲到。
### 2.3.1 轴体手感的来源
前面提到，轴体包含轴心、弹簧、上盖、底壳、金属弹片五个部分，正是这五个部分决定了轴体手感。
在我看来，轴体的手感可以概括为：按压手感、触发时机、触底手感和回弹手感四个部分。

按压手感：主要由模具精度和润滑共同决定。因为机械轴的触发机制是键帽带动轴心上下移动，因此会存在：轴心侧壁和上盖接触摩擦、轴心柱和弹簧接触摩擦、弹簧和底壳摩擦，通过适当的润滑，可尽可能减少这些摩擦，便会使得下压阻力集中在弹簧弹力上，产生丝滑的手感。反之，会在按压过程中产生沙沙的声音以及沙沙的手感。
触发时机：由于机械轴是弹片触发的，因此触发行程是固定的，按键刚按下就触发和快按到底就触发，所产生的手感差别还是挺大的，这一点根据个人喜好去查询轴体压力曲线和触发行程等参数即可。
触底手感：轴体触底，指的是按键被按到底时，轴心的某个部位与轴体底壳发生碰撞接触。这个接触位置会直接影响按键的声音、手感和反馈强度。根据轴心设计，分为轴心触底和轴壁触底。轴壁触底是轴心两侧与底壳碰撞，声音会更散；轴心柱触底则是加长轴心柱，使得轴心柱提前接触底壳，声音会更集中、更符合HIFI的概念。
回弹手感：回弹速度和力度十分关键，不同弹簧会影响这一点，对于克数大/长度长的弹簧，会感到回弹十分有力且快，而对于克数小/长度短的弹簧，则回弹会更缓慢。这一感觉十分重要！
实际上按压时弹簧也参与了按压手感，但是由于按压时是手指施加力度下压，回弹时是弹簧的弹力推着手指上抬，因此回弹时的感知会更加明显。
### 2.3.2 轴体声音的来源
手感和声音都是触发结构决定的，分不开家。按触发整个过程来讲：
首先是轴体按下时，轴心侧壁会和上盖/底壳接触、轴心柱和弹簧接触，润滑少就会产生沙沙的声音，弹簧也可能产生弹簧音。
其次是轴心和弹片接触、触点和触点接触时，会有弹片音产生，润滑后也会减弱。
接着是触底时，轴心和底壳碰撞会产生声音。
最后是回弹时，轴心和上盖碰撞产生声音。
轴体声音的控制无外乎调配不同声音的比例，这一点各花入各眼，选择自己喜欢的声音即可。
## 2.4 线性轴、段落轴与静音轴
之前红轴、青轴、茶轴、黑轴等划分来源于cherry樱桃垄断时期的cherry自家轴体的定义，现在随着国产轴百花齐放，需要更加广义的划分来便于定位厂家自己的轴体。
如果按手感来分，机械轴大致可以分为两大类：线性轴和段落轴。如果再细分，段落轴里又可以分出发声段落轴、类茶段落轴、提前大段落轴等类型；而静音轴则不是一种独立的手感大类，更像是在原有线性轴或段落轴基础上加入静音结构后的特殊版本。
判断轴体手感，最直观的方法是看压力曲线。所谓压力曲线，就是轴体从开始按压到触底过程中，压力如何变化。不同轴体的压力变化不同，最终就会形成不同的手感。一般来说，商家在轴体的详情界面会写多少g触发，多少g触底，更详细的会贴上图，即压力曲线图。
### 2.4.1 线性轴
线性轴是目前市场上最常见的一类轴体。它的特点是按压过程中没有明显的段落感，整体阻力随着按压逐渐增加，手感顺滑、直接。
线性轴本质就是：*按下去一路到底，中间没有明显“咔哒”或“顿一下”的反馈。*
从压力曲线上看，线性轴的压力一般会随着按压行程逐步增加。理想情况下，它的阻力主要来自弹簧本身，手指感受到的是比较干净的下压和回弹。
常见的红轴、黑轴，以及现在市面上大量所谓 HIFI 线性轴，都属于线性轴的大类。不同线性轴之间的差别，主要来自键程、压力、触发位置、触底方式、润滑程度、材料和弹簧设计。
线性轴可以继续从几个角度来根据用户需求细化。
第一是键程。传统 MX 轴的标准总行程一般在4mm左右。如果轴体总行程短于4mm，通常就可以看作提前触底轴。提前触底轴按到底更快，触底反馈来得更早，因此会显得更干脆，但也可能让一些人觉得键程偏短、按压不到位。
第二是触底方式。前面已经提到，触底方式主要分为轴壁触底和轴心柱触底。轴壁触底更接近传统 MX 轴的感觉，声音相对分散；轴心柱触底则通过加长轴心柱，让轴心柱优先接触底壳，声音可以做到更集中、更清脆或者更闷，也更容易做出现在玩家常说的HIFI声音。
第三是压力大小。一般可以把45gf左右触发压力理解为红轴压力，是比较常见、比较大众的轻中压力。低于45gf的轴体通常可以认为是轻压力轴，低于35gf则可以称为超轻压力轴。60gf左右触发压力接近传统黑轴压力，45gf到 60gf之间可以认为是相对重压力，高于60gf就属于比较重的轴体。
压力并不是越轻越好，也不是越重越高级。轻压力轴打字省力，但容易误触；重压力轴反馈更扎实，但长时间输入可能更累。比较适合自己的压力，还是要看个人手指力度、输入习惯和使用场景。
第四是触发行程。传统MX轴常见触发行程约为2mm，如果触发行程明显短于2mm，比如1.5mm左右，就可以认为是提前触发。提前触发会让按键更快被识别，游戏中可能更灵敏，但打字时也可能增加误触概率。
### 2.4.2 发声段落轴
发声段落轴是段落轴中最有辨识度的一类。它不仅有明显段落感，还会在按压过程中产生清晰的声音。樱桃青轴就是最典型的发声段落轴。
这类轴体的特点是：*按下去时会有明显的段落反馈，同时伴随“咔哒”一类的点击声。*
发声段落轴的声音通常不是简单来自轴心触底，而是来自轴体内部的特殊发声结构。以类青轴为例，它常常通过两段式轴心、点击套筒或类似结构制造段落和声音。也有一些轴体会通过侧面的拨片结构发声。
因此，发声段落轴和普通段落轴的区别在于：普通段落轴主要追求按压中的阻力变化，而发声段落轴还会专门设计发声结构，让段落反馈更加明显。
它的优点是输入确认感很强，按起来很有存在感；缺点也很明显，就是声音大，不太适合宿舍、办公室、图书馆等安静环境。
### 2.4.3 类茶段落轴
类茶段落轴可以理解为模仿传统Cherry茶轴手感的一类轻段落轴。它的段落感不像青轴那么强烈，也不会像青轴那样有明显点击声，而是在按压行程中部出现一个相对轻微的压力变化。
它的手感大概是：*按下去时中间轻轻顿一下，然后继续进入比较线性的键程，最后触底。*
类茶段落轴的段落压力差通常不大，所以它不会给人特别强烈的确认感，而是介于线性轴和强段落轴之间。对于一些人来说，这种手感比较均衡，既有一点反馈，又不会太吵、太累；但对于另一些人来说，它的段落感可能会显得不够干脆，甚至有点“刮”或者“不明确”。
类茶段落轴的触底方式通常更接近传统MX结构，很多是轴壁触底，因此声音也不会像现代轴心柱触底线性轴那样集中。
当然，现在市面上的类茶段落轴已经有很多变体。有些会加强段落，有些会减弱段落，有些会通过材料和润滑让它更顺滑。因此，“类茶”更多指一种手感方向，而不是严格的结构定义。
### 2.4.4 提前大段落轴
提前大段落轴是近几年比较有代表性的一类段落轴。它和类茶段落轴最大的区别在于：段落出现得更早，段落压力更大，反馈更强。
这类轴体一般在按压刚开始时就会出现明显压力峰值，手指会立刻感受到一个较大的阻力变化。通过这个段落点之后，后半段通常会进入比较线性的行程，最后触底。
它的典型手感可以概括为：*一开始就有一个很大的段落，过了这个段落之后直接到底。*
很多提前大段落轴的压力峰值会达到60gf左右，甚至更高，因此按压初段的确认感非常强。和类茶段落轴相比，它不是在行程中部轻轻顿一下，而是在按压开始阶段就给出强反馈。
提前大段落轴常见的一类代表是HP类轴心结构，也就是常说的Holy Panda类手感。这类轴体通常会采用更明显的段落小脚设计，并且很多会搭配轴心柱提前触底，使得触底声音更集中，整体反馈更强。
不过提前大段落轴内部也有很多变体。有些轴体会降低段落压力，让它不那么顶手；有些会缩短段落后的线性键程，让反馈更紧凑；也有些会调整触底方式，使声音更集中或更柔和。
这里需要注意一个边界问题：类茶段落和提前大段落不只是段落强弱不同，触底方式和整体结构取向也常常不同。一般来说，类茶段落更偏传统中段小段落，很多是轴壁触底；提前大段落则更强调初段强反馈，并且常见轴心柱提前触底。至于一些轴壁触底但段落较强的轴体，有时会被归入类 C 白一类的手感体系。
### 2.4.5 静音轴
静音轴并不是和线性轴、段落轴并列的第三种基础手感类型。更准确地说，静音轴是在原有手感类型上加入静音结构后的结果。
也就是说，可以有静音线性轴，也可以有静音段落轴。理论上甚至可以做静音青轴，让它保留段落结构，但尽量减少触底和回弹声音。
目前常见静音轴的静音方案主要有两类。
第一类是在轴心上加入硅胶或类似软质缓冲材料。触底或回弹时，不再是硬塑料直接撞击底壳或上盖，而是由软质材料先接触，吸收一部分冲击力，从而降低声音。
第二类是通过软质突起或特殊轴心结构实现缓冲。这类设计同样是利用材料变形来吸收冲击，让触底声和回弹声变小。
所以静音轴的本质是：
用软质结构替代硬碰硬，减少触底和回弹时的撞击声。
静音轴的优点很明确，就是声音小，适合办公室、宿舍、夜间使用，也适合不希望键盘打扰别人的场景。但它的缺点也很明显：由于缓冲材料会吸收冲击，触底和回弹会变得不那么干脆，很多人会觉得手感发肉、偏软、反馈不清晰。
# 3 机械键盘的结构与填充
实际上目前量产键盘大部分的结构都是Gasket结构或其变体，这也是目前经过市场检验的结构。此外还有部分船壳/Top结构。
而就填充而言，大部分量产都会填充满，即开槽 PC/FR4 定位板、poron夹心棉、IXPE轴下垫、PET声优垫、轴座棉、PET垫。
这一套丝滑小连招下来，无论什么轴体，声音都会趋向于变成麻将音。缺点是造成了同质化，轴体本身的差异化设计被缩小。
因此如果不想自己折腾且声音要求不大的话，选一个喜欢的键盘外观加上满意的轴体就足够了。
