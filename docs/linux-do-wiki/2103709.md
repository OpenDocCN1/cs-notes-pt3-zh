# 租房避坑不完全指南



第一次租房子，在抖音上看了几十个相关视频，将视频内容信息聚合在一起后整理了一下。希望能帮到有需求的佬友们吧(我也不知道这内容到底实不实用 ![:joy:](https://cdn.ldstatic.com/images/emoji/twemoji/joy.png?v=15)，只是想先分享出来一下)。

## 一、什么是串串房？（必须避开！）

> **核心警告**：租房子贵点或便宜点没关系，一定要避开串串房，健康要紧！串串房甲醛超标，住久可能得白血病。

### 串串房的特征

1. **老小区新装修**：小区环境破烂但屋内装修全新

2. **小面积做多房**：空间不合理分割

3. **网红拼色劣质窗帘**

4. **高能耗杂牌小家电**：家电是杂牌子且能耗高，说明装修其他地方可能也没用贵材料

5. **鲜艳的墙布或者墙纸**

6. **廉价劣质衣柜**

7. **没有长大的小马桶，没有挡板的淋浴间**

8. **厨房和厕所风格与客厅、卧室差异大**

### 辨别串串房的具体细节

| 检查项 | 串串房特征 |

| --- | --- |

| 气味 | 进屋闻到刺鼻气味（甲醛超标） |

| 踢脚线 | 缝隙没做好 |

| 门 | 非实木门，如零美合金门较薄、重量轻 |

| 花洒 | 内部是镀芯塑料材质 |

| 五金件 | 一看就很廉价，无品牌 |

| 关门声音 | 声音异常 |

| 施工工期 | 去物业询问，不到一个月完工 |

### 警惕中介/房东话术

> 当听到 **“精装修，首次出租拎包入住，业主着急租所以便宜”** 等话术时要小心。

### 分辨技巧：看水表

用水吨数除以2再除以12计算居住时间，时间越久串串房概率越小。

## 二、找房阶段

### 先选小区再选房子

打开地图软件，定位工作或生活区域，筛选预期范围内小区，查看：

- 周边交通、商场、菜市场配套

- 小区平均租售价格

锁定理想小区后集中找房，比盲目乱看效率高。

### 推荐小区类型

- **优先选小区**：民用电，四五毛钱一度

- **避开公寓**：商用电一块起步，冬夏开空调每月差好几百

- **楼层选择**：别选一楼（潮湿有蚊虫）和顶楼（夏天热）

- **重点关注**：房龄10-20年、管理成熟的居民小区，生活氛围浓、配套完善

### 找房途径对比

| 方式 | 优点 | 缺点 | 适合人群 |

| --- | --- | --- | --- |

| 小区内部找（门卫、保安、布告栏、物业） | 省中介费 | 费时，女生不建议 | 较社牛的人 |

| 租房平台（如海某居小程序） | 省时间、有第三方保障 | 费钱 | 大多数人 |

| 去小区附近找大爷大妈询问 | 可能找到一手房东、省中介费 | 信息不一定准确 | 愿意花时间的人 |

> **反驳野路子**：房东为出租房子，会选择曝光量大的租房软件，而非让老人去村口招揽租客。

### 查看房源信息

- 有视频优先看视频，检查基本配置

- 若房源只有照片且只拍局部特写，不敢拍全景视频 → 房子可能小或有硬伤

### 学会谈判

中介费、租金、起租日期、房间配置设施、物业费等都可谈，别被 **“好房不等人”** 话术催促。

### 价格与价值认知

> **世上不存在物美价廉的东西**，房子贵有贵的道理，便宜也有原因。很多租客被坑是因一开始想贪小便宜。

## 三、看房阶段

### 分时段看房

有时间白天、晚上各看一次房：

- **白天**：看采光、通风和小区环境

- **晚上**：听隔音、看遮光，感受小区夜间氛围（对睡眠浅的人重要）

### 房屋内部检查清单

- 查看墙角、天花板、角落有无**长霉**迹象和**渗水痕迹**

- 拉开各种抽屉，检查有无**蟑螂或蟑螂屎**

- 检查**马桶**是否堵塞（看旁边有无吸马桶工具，或自己放纸冲水测试）

- 打开**花洒测试水压**（尤其住高楼）

- 查看电器、空调是否为**一级节能**，至少两级节能

- 检查**家具、墙壁、瓷砖**有无损坏，若有损坏让房东在合同上写清楚

- 检查**磕碰划痕**并拍照录像，让房东或中介入境确认

- 所有电器开一遍听有无异常声响

### 水电检查

- 试试水压、出水速度

- 询问电费、水费价格（民水民电一般五六毛一度，水电费过高的房子慎选）

- 确定是自己交水电费还是房东代缴

### 电井水井房水表检查（非常重要！）

> 进入电井水井房查看水表，若房子为控制房，正常水表不应转动。若看到水表转动，需留心可能是**泡水房**。

**泡水房情况**：泡水后维修困难或费用高，不少房主会选择抛售。房主可能通过关闭水表、掩盖墙体等方式掩盖漏水问题，较难察觉。

**检查方法**：

1. 进入房子第一时间打开水表查看是否空转

2. 确保房子无人用水时，若水表仍在转 → 大概率是漏水房

3. 强调此类漏水房踩坑人数多，且维权困难

### 观察邻里环境

留意楼上楼下及左右邻居门口，若有：

- 特别多鞋子、乱七八糟堆放物

- 小孩子玩具、车扔在外面

住进去可能较吵。

### 安全提醒

> 女生单独看房最好有男性朋友陪同，顺便观察邻居和楼道环境。

## 四、签约前必问清单

### 房租及押金问题

| 问题 | 说明 |

| --- | --- |

| 房租如何支付？ | 押一付一还是押一付三？ |

| 押金退还标准 | 是否会二次检查恶意扣押金？自然损耗会不会被扣除？ |

| 退租时全额退押金需满足什么条件？ | 需写进合同 |

| 是否存在清洁费、折损费等额外费用？ | 提前问清楚 |

### 租期相关问题

- 是否接受短租？

- 中途退租、转租是否可行？

- 提前退租是否需支付违约金？

### 费用相关问题

- 每个月租金以及水电费什么时间交？

- 水、电、燃气是民用标准还是商用标准？（参考：水费5.1/吨、电费0.5/度）

- 自己交还是房东代缴？若代缴，要求出具缴费凭证

- 除租金、水电外，还有没有其他额外收费？（物业费、卫生费、服务费、损耗费等）

- 网费和宽带费用是房东免费提供还是需自己支付？

### 维修责任问题

- 电器损坏谁来维修负责？

- 维修费沟通清楚并写明在合同上

- 自然损耗是否由房东负责？（灯泡、开关等）

### 其他问题

- 是否允许养宠物？

- 是否允许贴墙纸？

- 上一个租客的费用有没有结清？

## 五、签合同注意事项

### 合同核心条款——千万不能签的字！

> **如果合同里写着“自然损耗由租客承担”，一定要当场用红笔划掉。**

可补充注明：

> **非人为损坏产生的维修费用，由房东负责。**

>

> 如果房东不同意这条，这套房子真的没必要租。

### 核实房东身份（最重要！）

- 查看房东身份证信息，确认姓名、电话是否一致

- 确认房屋产权确实属于房东本人

- 查看房产证凭证

- **建议直接与房东签合同**，避免租金支付、房屋维修责任、不退押金等纠纷

- 尽量不与中介或二房东签

> **二房东情况**：需看其与原房东合同并确认有转租权，确保纠纷时能找到当事人。

### 合同双方信息必须补齐

出租方（房东或中介）个人信息需包括：

- 姓名

- 身份证号

- 电话

- 住址

（以便后续维权）

### 房屋位置信息

第一条要写清房子具体位置，精确到房间号。

### 租赁期限和租金

租期与租金挂钩，建议**签半年以内**，避免因住不满约定租期导致押金不退。

### 租期内租金涨幅

合同中要写清楚：**租期内不能随意涨租**。如果允许上涨，也要注明每年最高涨幅。

### 违约责任要写明

- 如果房东提前收房，需要赔你多少钱

- 如果你提前退租，又该怎么处理

- 不能只写你的违约责任，房东的责任也要对等写进去

### 押金相关条款

押金常出现不退或乱扣问题：

1. **列房屋交割清单**：床、门把手、马桶冲水、淋浴头等，检查并写清家具情况、损耗程度、是否损坏

2. **明确退押金条件**：退租后多少天内，只要房屋和物品没有损坏，房东必须退还押金

3. **警惕各种扣费理由**：在签约阶段就写清楚什么情况下可以扣，什么情况下不能扣

### 物业费问题

问清楚房租是否包含物业费：

- 如果包含，要写进合同

- 如果不包含，要写清楚单价以及面积计算方式

### 合同留存

- **必须要纸质合同**，房东或中介签字并盖章，个人房东需按手印

- **每页都要签字**，防止中介换页

- 自己留存一份**合同原件**，并拍摄清晰照片保存（电子版易被篡改）

### 拒绝口头承诺

> 如“下周换新冰箱、安装洗衣机”等需**白纸黑字写进合同**并写明完成时间。

### 谨慎提供身份证

- 如果房东要求你**手持身份证拍照，千万别给**！租房根本不需要这个操作

- 提供身份证复印件时，最好注明：**“仅用于租房”**

## 六、入住当天必做事项

### 拍照留痕（非常重要！）

> 入住前把全部情况**拍照留视频**，包括：

>

> 电器、插座、马桶、水管

> 墙面渗水、家具损坏等

**具体操作**：

1. 对房屋进行**全方位、无死角录像**，重点拍清楚墙面、家具、电器等区域

2. 拍完把视频发给房东并备注说明，确认当前状态完好

3. 这些视频一定要保存好，是以后退房的重要凭证

### 水路检查

> 带两个矿泉水瓶，洗手间和厨房各接一瓶水，静止一晚上观察：

>

> 看水路是否干净

> 若有沉淀物或色差，说明水管脏

> 入住后清洗水管要花大价钱且可能和房东扯皮

### 马桶清洁

> 入住当天，把马桶彻底清洁一遍。因为马桶是退房时最容易被挑毛病、被扣钱的地方。

### 水电燃气把控

入住当天跟房东要户号，在支付宝或微信绑定自己缴费，透明消费，防止房东动手脚。

### 确认费用结清

确定租房时核对水费、电费、燃气费是否结清，确定物业费支付方。

### 钥匙门禁交接

制作清单，记录领取的钥匙、门禁卡数量（如七八把钥匙、几个门禁卡等）。双方在清单上签字，备注“完好无损”。退租时按清单交还。

## 七、入住期间

### 房屋瑕疵确认

1. 对门窗松动、家电异响等房屋小问题单独拍摄照片

2. 将照片发给房东，说明入住时就存在这些问题

3. 等待房东回复同意，防止退租时被认定为是自己造成的损坏

### 交费凭证保留

> 押金、房租、中介费等每一笔钱都**通过转账支付，不使用现金**。

- 转账备注：**“XX房，某月房租”**

- 收款方要与合同甲方一致

- 收好发票、收据

## 八、退租阶段

### 退租还原现场

退租前按入住时拍摄的照片或视频将家具归位并彻底清洁，邀请房东共同验收或拍照发房东确认。

### 房东不退押金的维权方法

| 步骤 | 方法 |

| --- | --- |

| 1 | 拨打**12366**投诉房东偷税漏税，核查其纳税情况 |

| 2 | 通过**国家信访局**微信公众号或小程序提交投诉，上传事情经过、合同、聊天记录 |

| 3 | 微信搜索**人民法院在线服务**小程序，选择我要立案走民事，诉讼费25元。立案后房子背上官司难出租 |

> 退租时如果房东开始找茬、各种挑问题，直接拿出入住视频，并结合 **《民法典》第710条** 和房东沟通。遇到恶意克扣押金或拒不退还的情况，可以直接拨打 **12345** 进行投诉。

## 九、找到靠谱房东的方法

### 问房子优缺点

问房东房子有无不好之处或是否会坑人：

- 若房东好坏都说 → 大概率靠谱

- 若只说优点 → 需小心

### 问租客限制

问房东是否对租客有限制：

- 若表明不租给特殊职业或不三不四的人 → 大概率靠谱

- 若来者不拒 → 需警惕

> 靠谱房东会询问租客工作并登记，对酒吧、KTV等场所工作的租客不租，认为是对其他租客负责。

### 与房东同住的房子

和房东住在一起的房子较好，房东不会自己坑自己，且水电费标准一致，避免乱收费。

## 十、南北通透的概念及好处

> **判断方法**：打开手机指南针，南边和北边都有窗口的房子是南北通透。

**好处**：通风好。如在家里吃有味道的食物，开窗一两分钟味道就消失。

---

## 十一、周边配套设施

了解附近是否有：

- 超市

- 便利店

- 药店

- 快递点

距离住的地方**500米左右**较合适。

---

## 十二、交通情况

打开地图看居住地方距公交站和地铁站距离，一般接受范围为**一公里左右**。

注意坐地铁**转线次数**，转线太多会增加通勤时间和劳累度。

## 十四、总结：不要怕麻烦

> **现在嫌麻烦，以后会吃亏。**

租房要靠规则保护自己。入住当天花一小时留存证据，退租时若遇扯皮，这些证据能保护自己的血汗钱。它们是退租时的护身符。
