# 人机验证 Captcha方式 简介 - 更新于5/16



> 最后更新于 2026/5/16，更新了阿里云Captcha。

>

> 2026/5/15，更新了网易智企、顶象、极验、数美科技。

# 关键词

国内 网页 Web端 人机验证 Captcha方式 简介 。

# 起因

当我们自建某些网站的时候，总想着保护一下。

但是因为众所周知的网络环境，某验证方式就会像疯狗一样不断循环，又或者加载过于缓慢，因此不禁想用国内企业的Captcha方式。

在我查询网络资料多次后了解了下面这几种验证方法，于是有了本文来简单汇总一下，并希望佬友提供其他验证方式的建议。

**警告：我并没有被攻击过，所以 完全不能 指出他们的防护效果。**

# 正文

## [Anubis](https://github.com/TecharoHQ/anubis) - 使用过 -  ★★★

免费（付费版提供某些自定义文本功能，在功能上没有区别）。一种PoW的验证方式，搭建较为简易。

评分理由：免费，社区丰富，易搭建。

## [Cloudflare Turnstile](https://www.cloudflare-cn.com/application-services/products/turnstile/) - 使用过 - ★★☆

免费。集成较为简易，也有丰富的社区，但是对于国内网络环境支持还是较慢，需要转圈数秒钟。

我从Anubis替换到了CF Turnstile，但是他实在是对于国内无梯用户不友好（某些人反应说进不去，服了），遂放弃。

而且它似乎判所有的QQ内置浏览器为异常，无法通过，我没找到原因。

评分理由：免费，社区丰富，易接入，但是对国内网络支持还是不行，且有时候会出不明问题。

## [T-Sec 天御 验证码](https://cloud.tencent.com/product/captcha) - 没有用过

用量计费 付费。看起来很好，我很想体验他的图形点选验证码。

部分价格表如下（用量包有效期1年）：

| 次数 | 价格（元） |

| 8万次 | 600 |

| 100万次 | 2000 |

还有数量更多的包请参考 [购买页面](https://buy.cloud.tencent.com/captcha) ，超量后0.005元/次。

## [极验产品](https://auth.geetest.com/product) - 使用过 - ★☆☆

套餐 付费。

注册后会给一个体验版账户，如果不用他们的服务的话好像就可以一直开着，但是一旦用了就会暂停（我就是开了50多天没用，一直没暂停，然后接入后用了几天就验证码接口暂停了）。

这时候需要找客服申请转其他类型，但是因为只支持套餐服务所以我没怎么聊。

我并没能获取到他的价格表，这是因为他们的报价需要由他们的销售给用户打电话，然而我不接陌生电话，所以完全没了解到，可惜。

需要注意的是，试用版账户只提供 **滑块图片功能** 。且我曾在本站看到有人指出滑块图片极其容易破解，所以他的安全性存疑。（不过我想总该比Turnstile好点吧）

## [阿里云验证码](https://yundun.console.aliyun.com/?p=captcha) - 使用过 - ★★★

用量&套餐&资源包 计费 付费。

比较喜欢它的图像复原验证码功能，感觉比较新颖。但根据 [ 【公告】图像复原公测发布](https://www.alibabacloud.com/help/zh/captcha/captcha2-0/product-overview/public-preview-and-release-of-restoration-images) 公告来看，此功能仍然为测试版，所以对于攻防安全性存疑。希望以后能用AI生成一堆样本，增强对抗能力。

计费方式请查阅 [阿里云验证码2.0如何计算费用 - 阿里云验证码 - 阿里云](https://www.alibabacloud.com/help/zh/captcha/captcha2-0/billing)，由于是公开的，这里不再贴图片。

我的Wiki站点正在使用 图像复原 方式，可以体验一下： [NS WIKI](https://nswiki.cn/%E9%A6%96%E9%A1%B5) 。
