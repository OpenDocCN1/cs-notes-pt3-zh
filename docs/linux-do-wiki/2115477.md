## 二、先理解 VPS、域名、宝塔、WordPress 分别是什么

很多新人一开始会混乱，是因为 VPS、域名、宝塔、WordPress、主题、页面这些概念混在一起了。

先这样理解。

### 1. VPS 是什么

VPS 可以理解成一台远程服务器。

你的网站文件、数据库、Web 服务、PHP、WordPress 都可以放在这台服务器上。

别人访问你的网站，本质上是访问这台服务器提供出来的内容。

### 2. 域名是什么

域名是给人看的地址。

服务器本身有 IP，比如：

```
1.2.3.4
```

但 IP 不好记，所以我们会用域名指向服务器。

比如：

```
example.com
```

浏览器访问域名后，域名解析会把请求指向对应服务器。

### 3. 宝塔面板是什么

宝塔不是网站本身。

它更像一个服务器管理面板，可以用图形界面管理：

- 网站

- Nginx

- PHP

- MySQL

- SSL

- 文件

- 数据库

- 备份

- 日志

- 终端

新手用宝塔的好处是，不需要一开始就全靠命令行操作服务器。

### 4. WordPress 是什么

WordPress 是网站程序。

它负责让你在后台：

- 创建页面

- 写文章

- 换主题

- 做导航

- 管理分类和标签

- 上传图片

- 安装插件

- 编辑页眉页脚

### 5. 主题是什么

主题决定网站的基础外观和结构。

但主题不是网站本身。主题只是材料。

最后还要你自己改：

- 首页

- 页面

- 导航

- 页脚

- 搜索页

- 404 页面

- 移动端显示

- 默认英文内容

## 三、先分清楚你会遇到哪些账号和密码

新手最容易混乱的地方不是安装，而是各种账号密码混在一起。

这里先分清楚。

### 1. VPS / SSH 账号密码

这是登录服务器用的。

常见形式是：

- 服务器 IP

- SSH 端口，默认一般是 22，也可能被改过

- 用户名，常见是 root

- 密码，VPS 商家给你的服务器密码

这个账号是用来管理服务器的，不是 WordPress 后台账号。

### 2. 宝塔面板账号密码

这是登录宝塔面板用的。

宝塔面板一般会有一个独立入口，比如：

```
http://服务器IP:宝塔端口/随机路径
```

进入宝塔时，需要宝塔自己的账号和密码。

宝塔账号不是 WordPress 账号，也不是数据库账号。

### 3. 数据库账号密码

WordPress 需要数据库保存文章、页面、设置、分类等内容。

数据库一般会有：

- 数据库名

- 数据库用户名

- 数据库密码

数据库账号不是你平时登录网站后台用的。

它主要是给 WordPress 程序连接数据库用的。

### 4. WordPress 后台账号密码

这是你真正进入网站后台用的。

后台地址一般是：

```
https://你的域名/wp-admin
```

登录时需要：

- WordPress 管理员用户名

- WordPress 管理员密码

- 管理员邮箱

这个账号用来写文章、建页面、换主题、改导航、装插件。

### 5. 一句话记住

```
VPS 账号：管服务器
宝塔账号：管服务器面板
数据库账号：给 WordPress 连接数据库
WordPress 管理员账号：管网站后台
```

这几个不是一个东西，不要混。

## 四、VPS 配置建议：1C1G 能跑，但长期不舒服

这里单独说一下 VPS 配置。

如果只是短期测试，低配 VPS 也能跑起来。但如果准备长期折腾 WordPress，不太建议直接买 1C1G。

我自己的实际感受是：1C1G 能跑，但体验比较紧。装了宝塔、WordPress、数据库、PHP，再加上一两个插件、主题编辑器或者后台操作，很容易明显卡顿。

预算允许的话，更推荐从这些配置开始：

- 2C2G

- 2C4G

- 4C4G

2C2G 可以作为比较基础的练习配置。



2C4G 或 4C4G 会更舒服一些。

简单说：

> 能跑 ≠ 好用。

>

> 低配 VPS 可以练流程，但长期折腾 WordPress，配置最好别太极限。

另外，新人不要一开始就装太多插件。插件越多，后台越重，冲突概率也越高。先把网站跑通、页面结构做出来，再按需加插件。

## 六、宝塔建站和 WordPress 建站不是同一层

这里很容易混。

宝塔里的“添加站点”，是在服务器上创建一个网站运行环境。

它负责：

- 绑定域名

- 创建网站目录

- 选择 PHP

- 创建数据库

- 配置 SSL

- 配置 Nginx

WordPress 是放在这个站点环境里的程序。

也就是说：

```
宝塔负责让服务器能承载网站。
WordPress 负责让你管理网站内容。
```

可以这样理解：

```
宝塔 = 管服务器和运行环境
WordPress = 管网站内容和页面
```

所以流程一般是：

1. 先在宝塔里创建一个站点环境

2. 再把 WordPress 放到这个站点目录里

3. 再创建数据库

4. 再通过浏览器访问域名，进入 WordPress 安装向导

5. 最后进入 WordPress 后台编辑网站

## 七、在宝塔里创建网站

进入：

```
宝塔 → 网站 → 添加站点
```

一般会看到这些选项：

- 域名

- 网站目录

- PHP 版本

- 数据库

- SSL

- 备注

### 1. 域名

这里填写你要绑定的网站域名。

比如：

```
example.com
```

如果有 www，也可以加：

```
www.example.com
```

### 2. 网站目录

宝塔一般会默认给你生成一个目录，比如：

```
/www/wwwroot/example.com/
```

这个目录就是网站根目录。

后面 WordPress 文件就要放到这里。

### 3. PHP 版本

WordPress 需要 PHP 运行。

新手可以选较新的稳定版本，比如 PHP 8.2 或 PHP 8.3。具体以你服务器环境和主题插件兼容为准。

### 4. 数据库

如果你准备用宝塔同时创建数据库，可以在添加站点时勾选创建数据库。

如果你想后面手动创建，也可以后面去：

```
宝塔 → 数据库 → 添加数据库
```

### 5. SSL

SSL 是 HTTPS 证书。

刚开始可以先把网站跑起来，后面再配置 SSL。



如果已经有域名解析，并且宝塔支持申请证书，也可以直接申请。

## 八、WordPress 从哪里下载

WordPress 建议从官方下载，不要去乱七八糟的网站下载。

官方下载页：

```
https://wordpress.org/download/
```

最新版压缩包地址一般是：

```
https://wordpress.org/latest.zip
```

打开官方下载页后，找到下载按钮。

如果你是在自己电脑上操作，可以直接点击下载，把 WordPress 压缩包下载到本地。

如果你想让服务器直接下载，可以：

1. 打开 WordPress 官方下载页

2. 找到 Download WordPress 按钮

3. 鼠标右键

4. 选择“复制链接地址”

5. 拿到类似这样的链接：

```
https://wordpress.org/latest.zip
```

## 十一、解压 WordPress 压缩包

在宝塔文件管理器里选中：

```
latest.zip
```

点击：

```
解压
```

解压后，通常会出现一个文件夹：

```
wordpress
```

这一步很关键。

很多新人以为解压完就结束了，但其实还没结束。

如果你现在的网站根目录结构是这样：

```
/www/wwwroot/example.com/
└── wordpress/
    ├── wp-admin/
    ├── wp-content/
    ├── wp-includes/
    ├── index.php
    └── wp-config-sample.php
```

那么你访问域名时，WordPress 可能不在根目录，而是在：

```
example.com/wordpress/
```

这通常不是我们想要的结果。

我们一般希望 WordPress 核心文件直接放在网站根目录里。

正确结构应该是：

```
/www/wwwroot/example.com/
├── wp-admin/
├── wp-content/
├── wp-includes/
├── index.php
├── wp-config-sample.php
└── 其他 WordPress 文件
```

```

```


## 十六、填写数据库信息

WordPress 会让你填写数据库信息。

一般需要：

- 数据库名

- 数据库用户名

- 数据库密码

- 数据库主机

- 表前缀

数据库主机一般是：

```
localhost
```

表前缀默认是：

```
wp_
```

新手可以先不改。

这里填的是你刚才在宝塔数据库里创建的数据库信息。

![QQ20260505-215224990×742 50 KB](https://cdn3.ldstatic.com/original/4X/8/b/9/8b9d39159179d471b7a1408b89887bfc8cd77acf.png)

如果数据库信息正确，WordPress 会提示可以继续安装。

如果提示连接数据库失败，要检查：

- 数据库名有没有写错

- 数据库用户名有没有写错

- 数据库密码有没有写错

- 数据库主机是不是 localhost

- MySQL 是否正常运行

## 十七、设置 WordPress 后台账号

数据库连接成功后，WordPress 会让你设置网站信息。

这里会填写：

- 站点标题

- 管理员用户名

## 二十一、固定链接和宝塔伪静态：文章页打开 404 怎么办

这里是新手高频坑。

WordPress 后台固定链接设置好了，文章也发布了，但前台点文章、页面、分类，或者测试一个不存在的地址时，可能直接出现 404。

这时候不一定是 WordPress 坏了，也不一定是主题坏了。

很多时候是宝塔 / Nginx 的伪静态没有配置好。

如果你用的是宝塔 + Nginx，可以这样检查：

```
宝塔 → 网站 → 找到对应站点 → 设置 → 伪静态
```

然后选择 WordPress 规则并保存。

如果没有现成选项，可以参考类似规则：

```
location / {
    try_files $uri $uri/ /index.php?$args;
}
```

这段规则的意思是：

如果访问的地址不是服务器上真实存在的文件，也不是一个真实目录，就把请求交给 WordPress 的 index.php 处理。

这样 WordPress 才能正确识别：

- 文章链接

- 页面链接

- 分类链接

- 搜索页

- 404 页面

这里要记住：

```
固定链接是 WordPress 后台里的设置。
伪静态是服务器 / Nginx 层面的配合。
两边都正常，漂亮链接才会正常工作。
```

## 三十二、我踩过的一些坑

### 1. 各种账号密码混在一起

VPS、宝塔、数据库、WordPress 后台账号不是一个东西。

一开始一定要分清楚。

### 2. WordPress 文件放错目录

解压后如果没有把 `wordpress` 文件夹里面的内容移动到网站根目录，可能访问路径会变成：

```
你的域名/wordpress/
```

更推荐让网站根目录直接出现：

```
wp-admin
wp-content
wp-includes
index.php
```

### 3. 只上传文件，忘了数据库

WordPress 不是纯静态网页。

它需要数据库保存文章、页面、分类、设置等内容。

### 4. 后台能进，但文章页打开 404

这通常要检查固定链接和宝塔伪静态。

WordPress 后台设置固定链接，宝塔里配置 WordPress 伪静态规则，两边要配合。

### 5. 一开始只盯首页

后来发现首页只是入口，真正完整的网站还包括内页、搜索、404、页脚、移动端。

### 6. 太早想写 CSS

CSS 应该是最后收口用的，不应该一开始就拿来救结构问题。

如果前面结构错了，CSS 只是给错误化妆。

### 7. 主题选错会很痛苦

有些主题看起来好看，但不适合当前网站类型，或者页眉页脚不好改，后面会很难受。

### 8. 忘记删默认内容

WordPress 默认文章、示例页面、默认评论如果不删，可能会在搜索页、404 页或首页查询循环里冒出来。

### 9. 页面和文章分不清

页面适合固定内容，文章适合持续更新。



分类是主结构，标签是补充关键词。

### 10. 1C1G 跑 WordPress 容易吃紧

低配 VPS 能跑 WordPress，但不代表体验好。

WordPress + 宝塔 + 数据库 + PHP 本身就会占用资源，再装几个插件、换主题、进编辑器操作，很容易卡。

如果只是学习流程，1C1G 可以凑合测试。



如果想长期做 WordPress 训练，更建议 2C2G 起步，有条件可以 2C4G 或 4C4G。

不要只看“能安装成功”，还要看后台操作、保存页面、打开编辑器、搜索和备份时是否稳定。

## 三十三、完整流程总结

新人可以按这个顺序来：

1. 准备 VPS 和域名

2. 登录宝塔面板

3. 在宝塔里创建网站

4. 进入网站根目录

5. 去 WordPress 官方下载页复制下载链接

6. 在宝塔文件管理器里远程下载 WordPress

7. 解压 WordPress 压缩包

8. 进入 wordpress 文件夹，全选里面的内容

9. 剪切并移动到网站根目录

10. 删除空的 wordpress 文件夹和压缩包

11. 在宝塔里创建数据库

12. 浏览器访问域名，进入 WordPress 安装向导

13. 填写数据库信息

14. 设置 WordPress 管理员账号和密码

15. 登录 `/wp-admin`

16. 设置站点标题、语言、时区

17. 设置固定链接为文章名

18. 在宝塔里配置 WordPress 伪静态

19. 创建首页、关于、联系、博客等基础页面

20. 设置静态首页

21. 设置导航

22. 安装并启用主题

23. 写第一篇文章

24. 检查搜索页

25. 检查 404 页

26. 检查移动端

27. 备份网站文件和数据库
