# 如何优雅地创建话题😁



水帖嘛，是大多佬友的共同爱好，咱水就得水的与众不同、水的优雅！这里鹅鹅总结几条悠亚秘笈，供佬友们把玩 ![:innocent:](https://linux.do/images/emoji/twemoji/innocent.png?v=15)

# 快捷创建

通常情况下，我们想创建新话题，需要回到首页，然后点击 `新建话题` 来创建，但是如果我们需要参考其他佬友文章中的一些内容，还需要再次打开文章，这样一来二去的很麻烦，其实，我们可以**使用快捷键 C 来随时随地开始创建新话题**，这样就免去了许多步骤！

# 打好标签

在分区与标签改版之后，打好标签变得更加重要了，这是一个好习惯，方便自己帖子推送给关注特殊标签的佬友，也方便佬友能更直观地了解帖子大概意图。一举两得，岂不美哉！[查看全部标签](https://linux.do/tags)

# 主题清晰

任何话题总得有个主题是不是，咱得让佬友们知道我要干啥，例如：

- 问问题。列出你的困惑，期望如何，做过哪些尝试

- 解BUG。尝试BUG描述、使用的版本、复现方式

- 求资源。资源基本信息、有啥特别需求

- …

这里只是打个样，旨在说明我们需要知道帖主要干啥，就算是纯水，那也得开个场不是，总不能一进来就是：大家开始吧~ 我开始咩呀  （对于一些特殊内容的针对特定群体而不便明言的另当别论）

## 使用方法

将你的图片使用 `grid` 包裹即可

```
[grid]
img1 img2 img3 ... imgN
[/grid]
```

移动端的话，点击预览后，好像有个小图标，点一下就会自动完成，可以自行摸索一下。

# 突出重点

对于一些长文，我们可以适当对其中的重点进行区分，例如

- 使用 **粗体** 或者 *斜体*



**粗体**   *斜体*



__粗体__   _斜体_

- 增大字号



`<big> 内容 </big>`  虽然这个标签处于废弃，但还能用

你也可以使用 `h1~h5`，但不优雅

BBCode的 `size` 也可达到效果

- 使用其他颜色 (使用空链接蓝色就很好，其他的自行探索)



`<a>重点文本</a>`

`[重点文本]()`

> 以上一些效果，实现方式不唯一。

>

>

> ![:warning:](https://linux.do/images/emoji/twemoji/warning.png?v=15) 请在需要的时候合理使用，不要滥用大字体和颜色，导致污染帖子，遇到滥用可以举报。

# 善用隐藏

对于一些代码、提示词等内容，如果内容过长，直接显示就很不雅，我们可以使用 `隐藏详细信息` 来将其收缩隐藏，按需展开即可

## 方式一

在编辑器内点击齿轮图标，选择 `隐藏详细信息`

[image228×346 9.49 KB](https://cdn3.ldstatic.com/original/3X/2/9/299af30f7c61343c5852dacadb34c4e96c0bc59f.png)

## 方式二

粘贴下列代码，修改里面的标题和内容即可

```
[details="你的标题"]
需要隐藏的内容
[/details]
```

> ![:tieba_040:](https://cdn3.ldstatic.com/original/3X/3/a/3a5fcb80663d73c1f116527c17de7cad37b72c49.png?v=15) 隐藏详细内容不仅仅只是为了压缩长文而生，在一些包含对特定人群不和谐的图片、视频等内容，还可以起到提前警告作用。

>

> 例如：密恐人群、癫痫患者等，如图片/视频可能会有相关刺激，还请能提前告知，多点关爱 ![:lark_022:](https://cdn3.ldstatic.com/original/3X/4/3/43624b871be03779cb426e65d9ad4279c822c622.png?v=15)

# 引用与圈人

在发表话题时，如果有相同想表达或者是从某个话题继续（始皇常用），我们不需要手打，而是**从原话题回复，选择 作为链接回复话题 即可**。

![image](https://cdn3.ldstatic.com/original/3X/4/1/41fe654cdbdee643e706f5d5871645ce0fd23f13.png)

在发表长篇文本话题时，我们也可以**使用 块引用 来做一些分割，避免长文本导致的视觉疲劳**，一看就晕。

艾特人这个功能，佬友们应该都有使用过，但是我们 `@` 的时候，通常是使用用户名，容易记住的倒还好，若是一个复杂的，那就很麻烦了！这里我们其实也可以**使用昵称来圈人**，是不是容易多了！

> 例如，我们 在召唤大帅哥时，我们通常是 [@handsome](/u/handsome) ,但是，我们也可以试试 **@大帅哥** 或者 **@帅哥** 就会出现选项，第一项完全匹配的话，直接Tab选取就OK啦！

>

>

> [image404×164 13.7 KB](https://cdn3.ldstatic.com/original/3X/a/7/a7496c34f8bb55e561d2cd331b8ea25e9d2900e8.png)

如果你的话题更新某一些内容之后，想要通知帖子内的其他人知晓，可以使用 @here，虽然只能召唤10个~。功能虽好，请勿滥用。
