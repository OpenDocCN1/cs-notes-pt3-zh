# 在Android手机里tailscale与VPN出国软件同时（勉强）生效的方法



情况：

> 我一般出国用的是clash meta, 它用的是VPN，而tailscale用的也是VPN，然后手机同时只能有一个VPN，这两个不能兼容，开一个就必需先关另一个，这样日常使用太烦索了。

> 佬友们的分享，我没成功我没法写，也可翻看尝试

简单，可用：

用Shelter开第二个工作资料，两个工作资料的VPN是能互不干扰的。然后需要回家的软件就放到另一个工作资料里安装

- 优点：简单，无任何配置，只用到现成软件

- 缺点：多工作资料会有些许资源浪费，另外后台可能会掉等等

[tailscale-socks5-Android](https://github.com/0xKrito/tailscale-socks5-Android)我也不知道原理但这个软件就是登陆tailscale不用占用VPN，软件安好然后到VPN软件做好分流就能用了，VPN软件我就用的他介绍里的flclash因为它给了现成覆写脚本，当然据哈基米说clash meta也行但是要写配置：

- 缺点： 可能是需要自己手动fork然后用action去build一下？作者没发版，以及如果不想用flclash的话就要自己去做分流
