# 幫大家整理了一下GPT封號原因（歡迎追加）



目前的GPT封號原因整理一下

- 虛擬卡, 禮品卡, 低價卡, 代開, 代充 [ 非官方直充, 正規禮品卡外都有中高風險 ]

- 反代 [ 少看到，但是還是有風險 (還有反代出去的使用者除了你，其他人無法掌握) ]

- 破限多次, Cyber Abuse [ 看到這個警告時，請倒數，三次後爆炸不退款 ]

- kyc 實名認證 [ 不推薦海鮮市場認證，同一人多重認證基本爆炸不退款 ]

- api 充值 [ 虛擬卡被檢知都是封號, 請勿輕易嘗試, 實體卡沒有問題 ]

- 過去羊毛過 0元購（token充值） 帳號 [ 同一域名，同一支付都是連坐 ]

- 註冊機，低價不明渠道的帳號 [ 日拋1~7日封號 ]

- Free 域名信箱 [ 看到很多人都在羊毛同一個域名時，封號風險高 ]

- 同一支付方式過多次支付 [ 有案例，連坐封號 ]

- webToApi 網頁反代api [ 1~3日封號 ]

- 百人龍貓公車team [ 出帳單炸車 ]
