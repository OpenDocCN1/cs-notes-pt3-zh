# 基于特定用户画像的“十五五”规划纲要解读（AI辅助）



“十五五”规划纲要是一份指导性的文件，覆盖面太广，于是我借助于ai针对一个用户画像“中西部 + 互联网/体制内”为起点，分析一下可以从国家规划纲要中获得一些与自己息息相关的信息。

> **是什么**：把《中华人民共和国国民经济和社会发展第十五个五年规划纲要》当作一份"未来五年的国家行为蓝图"来读，从中提取对一个具体的人（中西部上班族，关注互联网+体制内两条赛道，最关心职业发展和养老医疗）有用的判断。

## 个人的看法

每个人的学习、工作与国家的安排息息相关，但是可能苦于难以突破自身的眼界，现在借助ai可能可以帮助我们从自身的角度了解一下国家的规划。



大家完全可以以这份文件为模板，基于自身的特点来让ai进行一下分析。



不过ai毕竟只能提供一些信息，甚至可能出错，当作参考性、方向性的文件应该是比较合适的学习态度。



将这样的文件解读当成“接口设计”，“具体实现”还是需要进一步了解和学习与实际相关的信息。
