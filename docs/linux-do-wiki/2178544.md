## 二、先搞清楚"块编辑器"是什么

WordPress 现在默认用的是"块编辑器"，也叫 Gutenberg。

**什么是块？**

块就是编辑器里的每一个独立元素。

比如：

- 一个段落 = 一个段落块

- 一个标题 = 一个标题块

- 一张图片 = 一个图片块

- 一个列表 = 一个列表块

- 一行引用 = 一个引用块

整篇文章就是由一个一个块堆起来的。

**块编辑器和 Word 有什么区别？**

在 Word 里，你是一直打字，打完一段按回车继续打下一段，整篇文章是一个整体。

在块编辑器里，每一段、每一个标题、每一张图片，都是独立的"块"。你可以单独移动、删除、复制、设置某一个块，不影响其他块。

**块编辑器的好处：**

- 每个块独立控制，排版更灵活

- 可以拖拽调整块的顺序

- 可以给不同块设置不同样式

- 可以插入各种类型的块（图片、视频、引用、代码、按钮……）

**块编辑器的坏处：**

- 新手上手需要适应，不像 Word 那么直观

- 块太多时，文章结构会显得复杂

这篇就是帮你适应块编辑器的。

## 五、如何插入新块：两种方法

在正文区域，你想插入新块，有两种方法：

### 5.1 方法一：点击加号按钮

编辑器里有两个地方可以点击加号：

- **左上角的加号**：点击后弹出所有块列表

- **当前块旁边的加号**：点击后弹出块列表，新块会插入在当前块下面

点击加号后，会弹出一个面板，里面列出了所有可用的块。

你可以：

- 直接在列表里找想要的块

- 在搜索框里输入块名称搜索

![QQ20260514-2350332476×1004 120 KB](https://cdn3.ldstatic.com/original/4X/0/7/d/07d70f70f8e12a14e7ff6ad4c86ffb0b8b20386d.png)

### 5.2 方法二：用斜杠命令（推荐）

在编辑器正文区域，直接输入一个斜杠 `/`，会弹出块列表。

然后继续输入块名称的关键词，列表会自动筛选。

比如：

- 输入 `/标题` 或 `/h2` → 会筛选出标题块

- 输入 `/图片` 或 `/image` → 会筛选出图片块

- 输入 `/列表` 或 `/list` → 会筛选出列表块

找到想要的块后，按回车，块就会插入。

这个方法熟练后非常快，不用鼠标点来点去。

![QQ20260514-2349592559×1077 143 KB](https://cdn3.ldstatic.com/original/4X/6/2/9/6293775b109dceb59f8b64dcf74c9a17b6e1fb99.png)

## 六、段落块：最基础的块

段落块是编辑器里最常用的块，默认正文区域就是一个段落块。

### 6.1 输入段落内容

点击正文区域，直接打字。

比如：

```
这是我用 WordPress 块编辑器写的第一段话。我想试试看这个编辑器到底怎么用。
```

打完这一段，如果你想开始新的一段：

**按回车键**

编辑器会自动创建一个新的段落块，光标跳到新段落里，你可以继续打字。

![QQ20260514-2350572559×882 110 KB](https://cdn3.ldstatic.com/original/4X/8/e/8/8e804e1d239092d51839f50c3f6e120556b6c176.png)

### 6.2 段落块的工具栏

当你点击一个段落块时，块上方会出现一个工具栏。

工具栏从左到右依次是：

1. **块类型图标**：显示当前是段落块，点击可以切换成其他类型

2. **对齐方式**：左对齐、居中、右对齐

3. **加粗**：B 图标

4. **斜体**：I 图标

5. **链接**：链条图标

6. **更多选项**：三个点，点击弹出更多操作

![QQ20260514-2351472524×865 85.5 KB](https://cdn3.ldstatic.com/original/4X/a/d/3/ad37087e6ad9092cc89c3abcf31b2d15c45818e2.png)

### 6.3 段落块的设置面板

选中段落块后，编辑器右侧会出现设置面板。

设置面板有两个标签页：

- **块**：设置这个段落块的属性

- **文章**：设置整篇文章的属性（分类、标签等）

在"块"标签页里，可以设置：

- **排版**：字号大小、行高、字间距、段落间距

- **颜色**：文字颜色、背景颜色、链接颜色

- **尺寸**：最小高度、内边距

这些设置会影响整个段落块，不是只影响选中的文字。

![QQ20260514-2353552550×1031 162 KB](https://cdn3.ldstatic.com/original/4X/3/2/b/32b69ec6bdfb303efb80f768272ccf3fea791197.png)

### 6.4 段落块切换成其他类型

如果你想把当前段落块变成其他类型（比如标题、列表），不用删除重建。

点击工具栏最左边的"段落"图标，会弹出一个列表，可以选择：

- 标题

- 列表

- 引用

- 等等

选择后，当前块就会变成你选的类型，内容保留。

![QQ20260514-2354222559×1024 185 KB](https://cdn3.ldstatic.com/original/4X/2/a/f/2af5f8320a56ffc097f64238a0723c4e950f4294.png)

## 七、标题块：给文章分层级

文章不能只有正文，还需要标题来分层级。

### 7.1 插入标题块

**方法一：斜杠命令**

输入 `/标题` 或 `/h2`，按回车。

**方法二：点击加号**

点击加号，在块列表里找到"标题"，点击。

![QQ20260514-2354572559×636 56.5 KB](https://cdn3.ldstatic.com/original/4X/c/0/4/c04d132bfec283b70fabbec7381a8c84cdd0b464.png)

### 7.2 选择标题级别

WordPress 支持 H1 到 H6 六个级别的标题。

- **H1**：文章主标题，一般一篇文章只用一次（文章标题已经用了 H1，正文里一般从 H2 开始）

- **H2**：大章节标题

- **H3**：章节下的小节标题

- **H4**：更细的标题

- **H5、H6**：很少用到

插入标题块后，在标题块上方工具栏里，可以看到一个下拉菜单，默认显示 H2。

点击这个下拉菜单，可以选择 H1 到 H6。

![QQ20260514-2355222109×703 52.2 KB](https://cdn3.ldstatic.com/original/4X/c/e/c/cec03f270efb7333ac35396a5d7f751eb22a84d5.png)

### 7.3 输入标题内容

选择好级别后，直接输入标题文字。

比如：

```
一、什么是块编辑器
```

输入完后，按回车会创建新的段落块，继续写正文。

### 7.4 标题块的使用建议

**层级要清晰：**

- 文章标题是 H1

- 正文里的大章节用 H2

- H2 下的小节用 H3

- H3 下更细的内容用 H4

**不要跳级：**

- 不要从 H2 直接跳到 H4，中间要有 H3

- 层级跳跃会让文章结构混乱，也不利于 SEO

**示例结构：**

```
文章标题（H1）

一、什么是块编辑器（H2）
  1.1 块的概念（H3）
  1.2 块的类型（H3）

二、常用块介绍（H2）
  2.1 段落块（H3）
  2.2 标题块（H3）
  2.3 列表块（H3）
```

### 7.5 标题块的设置面板

选中标题块后，右侧设置面板可以设置：

- **排版**：字号大小、行高

- **颜色**：文字颜色、背景颜色

注意：标题的字号大小一般由主题控制，不建议手动改太大或太小，保持默认样式最统一。

## 八、列表块：有序列表和无序列表

列表是文章里很常用的元素，用来列举要点、步骤、选项等。

### 8.1 插入列表块

**方法一：斜杠命令**

输入 `/列表` 或 `/list`，按回车。

**方法二：点击加号**

点击加号，在块列表里找到"列表"，点击。

![QQ20260515-0000241289×672 35.4 KB](https://cdn3.ldstatic.com/original/4X/f/a/f/faf191a07ce526f2ddf08f9edb9825ebdd213937.png)

### 8.2 选择列表类型

插入列表块后，在工具栏里可以看到两个图标：

- **无序列表图标**：三条横线，每行前面有小圆点

- **有序列表图标**：三条横线带数字，每行前面是序号

点击切换你想要的类型。

默认是无序列表。

![QQ20260515-0001031483×631 21.8 KB](https://cdn3.ldstatic.com/original/4X/8/c/4/8c489be84a6d30f688c9a7825682d802217252aa.png)

![QQ20260515-0001101301×729 24.8 KB](https://cdn3.ldstatic.com/original/4X/1/2/9/12932ce9ab71d1310fa45bd9704d24155e6b6c86.png)

### 8.3 输入列表内容

点击列表块，输入第一项内容。

比如：

```
第一项内容
```

输入完后，**按回车**，会自动创建新的一项，序号或圆点自动添加。

继续输入下一项：

```
第二项内容
```

再按回车，继续输入。

### 8.4 结束列表

如果你想结束列表，不再添加新项：

**按两次回车**

或者：

按退格键删除空的列表项，光标会跳出列表块，下面会自动创建新的段落块。

![QQ20260515-0002151309×709 17.4 KB](https://cdn3.ldstatic.com/original/4X/2/7/2/272aabf5d75dc7a7728da307c0fcae7be858cb13.png)

### 8.5 列表缩进（子列表）

如果你想在列表里创建子列表，形成层级结构：

**方法一：按 Tab 键**

在输入某项内容后，按 **Tab 键**，这一项会缩进，变成上一项的子项。

**方法二：点击工具栏按钮**

点击工具栏里的"缩进"按钮（向右的箭头图标）。

如果想取消缩进，让子项变回同级：

**按 Shift + Tab**

或者点击工具栏里的"取消缩进"按钮（向左的箭头图标）。

**示例效果：**

```

    - 苹果
    - 香蕉
二、蔬菜
    - 西红柿
    - 黄瓜
```

## 十一、简码块：插入 WordPress 简码（重要）

**简码块和代码块是两回事，一定要分清楚。**

### 11.1 代码块 vs 简码块的区别

|  | 代码块 | 简码块 |

| --- | --- | --- |

| 用途 | 展示代码给读者看 | 执行 WordPress 简码，显示实际功能 |

| 例子 | 显示一段 Python 代码 | 插入画廊、表单、地图等 |

| 效果 | 读者看到代码文本 | 读者看到渲染后的功能组件 |

### 11.2 什么是简码

简码是 WordPress 的一种特殊语法，用方括号包裹，比如：

- `[gallery]` → 显示图片画廊

- `[contact-form-7]` → 显示联系表单

- `[wpforms id="123"]` → 显示指定 ID 的 WPForms 表单

- `[latest_posts]` → 显示最新文章列表

简码会被 WordPress 解析并替换成实际的功能组件。

### 11.3 插入简码块

**方法一：斜杠命令**

输入 `/简码` 或 `/shortcode`，按回车。

**方法二：点击加号**

点击加号，在块列表里找到"简码"，点击。

![QQ20260515-0020011050×603 23.4 KB](https://cdn3.ldstatic.com/original/4X/0/1/4/01481e12c725fb571cd0450b7c7047b08b9b1ea6.png)

### 11.4 输入简码

点击简码块，输入简码内容。

比如，如果你想插入一个画廊：

```
[gallery ids="1,2,3,4,5"]
```

其中 `ids` 是图片的 ID，可以在媒体库里查看。

或者，如果你装了 Contact Form 7，可以插入：

```
[contact-form-7 id="123" title="联系表单"]
```

或者，如果你装了 WPForms，可以插入：

```
[wpforms id="123"]
```

### 11.5 简码块的效果

简码块在编辑器里只显示简码文本本身，但在前台访问文章时，简码会被解析并显示实际的功能组件。

比如 `[gallery]` 在前台会显示一个图片画廊，而不是显示 `[gallery]` 这几个字。

![QQ20260515-0020251065×644 20.6 KB](https://cdn3.ldstatic.com/original/4X/0/0/c/00cb7e9daf9926c0dd4b65e6d8ef7914bbcf9e40.png)

### 11.6 常用简码举例

| 简码 | 作用 |

| --- | --- |

| `[gallery]` | 显示图片画廊 |

选中段落块，在右侧设置面板里找到"字号大小"，可以选择：

- 小（12px 左右）

- 正常（16px 左右）

- 中（20px 左右）

- 大（24px 左右）

- 巨大（36px 左右）

或者输入自定义数值。

### 25.1 打开文章设置面板

点击编辑器右上角的"文章"图标（齿轮形状），或者直接看右侧面板。

- **块**：当前选中块的设置

- **文章**：整篇文章的设置

点击"文章"标签页。

## 二十七、常见问题排查

### 27.1 块无法选中或操作

可能是编辑器卡住了，尝试：

- 刷新页面

- 清除浏览器缓存

- 换一个浏览器试试

### 27.2 图片上传失败

可能原因：

- 图片文件太大（超过服务器上传限制）

- 文件格式不支持

- 服务器存储空间不足

- 文件权限问题

解决方法：

- 压缩图片后再上传

- 检查文件格式是否是 jpg、png、gif、webp

- 在宝塔里检查网站目录权限

### 27.3 前台显示和编辑器预览不一致

可能原因：

- 主题样式覆盖了块编辑器样式

- 插件冲突

解决方法：

- 在前台实际查看，以实际效果为准

- 尝试切换默认主题看是否正常

### 27.4 简码不生效

可能原因：

- 简码拼写错误

- 对应的插件未安装或未启用

- 简码参数错误

解决方法：

- 检查简码拼写

- 确认对应插件已启用

- 查看插件文档确认简码格式

## 二十八、完整流程回顾

在块编辑器里写一篇排版整齐的文章，可以按这个流程：

1. 新建文章，输入标题

2. 用标题块（H2、H3）规划文章结构

3. 用段落块写正文内容

4. 用列表块列举要点

5. 用图片块或画廊块插入配图

6. 用引用块突出重要内容

7. 用分隔线划分区域

8. 用列块或媒体和文字块做并排布局（如需要）

9. 用简码块插入功能组件（如画廊、表单）

10. 设置文字样式（加粗、链接等）

11. 设置分类、标签、摘要、特色图片

12. 预览检查排版效果

13. 发布文章
