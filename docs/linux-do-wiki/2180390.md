# 解决Apple ID登录商店后被“送中”的问题

先说背景，前两天看到这么一个帖子
> 四、清除 App Store 账户缓存
> 这是非常重要的一步。没操作可能导致 App Store 登录后账号自动被设置为国区。
> 使用 Safari 浏览器访问以下链接：
> `itms-apps://itunes.apple.com/WebObjects/MZStore.woa/wa/resetAndRedirect?dsf=143480&cc=tr `
> 这个链接用于清除 App Store 的账户缓存，并切换到土耳其区相关配置。
现在GPT的低价渠道变成日抛，不少佬友都跑去土区避难，目前封号的案例还比较少（除了几位似乎在站内找了其他佬友过kyc，结果付了钱也被封），算是一个比较稳定的渠道。目前土区80左右的500里拉礼品卡就可以订一个月的Plus，也算是比较便宜了；除此以外还有些比如pixiv的会员，Apple One、Google One或者Youtube好像是也便宜一些。
很多佬在注册好了土区或者其他低价区的id，换区登录的时候总是被“送中”，登上以后发现国家/地区是中国大陆，还改不回去、一改就报错。这个最简单的方法就是上面帖子的链接，也就是商店退出前一个id后，先在Safari浏览器输入一个链接清理缓存并切换商店地区，系统会提示是否在“App Store”中打开，点击“允许”或“打开”。跳转到 App Store 后，界面通常会刷新（有时会变成英文），这代表缓存已清除且环境已切换为对应的区，此时再在 App Store 中输入新的Apple ID和密码进行登录即可。
不过这里就还有一个问题，以土区的链接为例
```
itms-apps://itunes.apple.com/WebObjects/MZStore.woa/wa/resetAndRedirect?dsf=143480&cc=tr
```
这里的dsf和cc分别是商店前端编号和国家代码，不同的区是不一样的。所以除了提醒，这里也列一些常用的外区链接
| 国家/地区 | 国家代码 (cc) | 商店前端编号 (dsf) | 对应的锁区清理链接尾部 |
| --- | --- | --- | --- |
| 中国大陆 | cn | 143465 | dsf=143465&cc=cn |
| 美国 | us | 143441 | dsf=143441&cc=us |
| 土耳其 | tr | 143480 | dsf=143480&cc=tr |
| 尼日利亚 | ng | 143561 | dsf=143561&cc=ng |
| 日本 | jp | 143462 | dsf=143462&cc=jp |
| 中国香港 | hk | 143463 | dsf=143463&cc=hk |
| 中国台湾 | tw | 143470 | dsf=143470&cc=tw |
| 韩国 | kr | 143466 | dsf=143466&cc=kr |
| 新加坡 | sg | 143464 | dsf=143464&cc=sg |
| 英国 | gb | 143444 | dsf=143444&cc=gb |
用的时候，在`itms-apps://itunes.apple.com/WebObjects/MZStore.woa/wa/resetAndRedirect?`后面粘贴对应的这一串就好了。
