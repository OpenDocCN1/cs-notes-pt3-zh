# 大学生外币卡推荐



注意：上海已测试，可以申请，别的地方需要看具体zc（来上海旅游？ 或者试试看转运？没折腾过。。。实在不行就只能用父母的 visa 副卡了，有担心可以设置 0 额度）

由于学生身份加上zc原因，很难申请信用卡。基本上就是储蓄卡，或者零额度的信用卡。。。（外币应该可以简单分为银联， visa， master吧？）
