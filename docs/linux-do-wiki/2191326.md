# 关于虚拟卡和各家监管



首先不推荐任何人办理非国家金融机构监管的。



推荐平台



1.krak,海妖交易所旗下，介绍欧洲地区监管，需要kyc会同步税务信息，允许一个身份在多个不同地区开户,特点为:支持虚拟货币转向法币，显然不占用便捷换汇额度。支持iban可以提供欧洲地区入金出金，由爱尔兰中央银行 CBI监管



2.wise，不必多说，请开中国区真实信息不要造假，中国区拿不到卡而已，这个账号非常珍贵，不要造假不要造假，由英国金融行为监管局 FCA，比利时国家银行 NBB监管



3.n26，目前只有部分地区能下卡，可以通过wise和krak入金，他虽然提供虚拟卡但他是比较传统的不提供虚拟货币转法币服务，由德国联邦金融监管局 BaFin监管



4.fiat24以及他的分发机构比如safepal或者ur，由瑞士金融市场监督管理局 FINMA监管



剩下很多都是持牌合作伙伴监管，但是也还是基本可信



比如ready，kast等等，还有某几家可以开很多卡的，但是注册最好要在国外完成注册



另外有个小招数提供任何地区的账单当地址证明



wise的新号填个姓名和地址不进行kyc什么都不干，就可以打印对账单。
