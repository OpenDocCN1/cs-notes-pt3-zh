### gemini-3.5-flash

价格：输入$1.5/输出$9，涨价3倍



上下文：1m不变



最大输出：64k不变



训练数据截止日期：25年1月



速度：300tps，现在算力充足实际远高于300tps

### gemini-3.5-pro

6月上线



个人估计价格至少翻倍，$4/$24

### Gemini-omni-flash

视频模型/世界模型，每次消耗10-30积分，pro会员每月1000积分



优点：自拍角色(类似Sora Character)，可编辑性，可4-10s（3.1只有8s）



缺点：暂不支持首尾帧，整体性能比seedance2差很远



会员：plus及以上，Free没有



Gemini app平台：已上线，5h约4条/flow已上线/



Flow平台：[Flow](https://labs.google/fx/zh/tools/flow/)



Youtube short平台：暂未上线



模型主页：[Gemini Omni — Google DeepMind](https://deepmind.google/models/gemini-omni/)



提示词指南：[How to create effective prompts with Gemini Omni — Google DeepMind](https://deepmind.google/models/gemini-omni/prompt-guide/)

### Antigravity 2.0 已上线

是个独立App，类似Codex App，不是以前的VSCode Fork



另计划有安卓/AIStudio等多个版本，陆续上线



注意装了2.0，可能导致老版本IDE无法登录：[https://linux.do/t/topic/2209543/](https://linux.do/t/topic/2209543/)



官方文：[Google Antigravity](https://antigravity.google/product/antigravity-2)



下载：[Google Antigravity](https://antigravity.google/download)



可能现在登的人太多，2.0貌似很难登上，多试几次能登上



另外老版Antigravity IDE与2.0不要同时开，貌似会互相影响登录

### Antigravity CLI已上线

代替Gemini CLI的，Gemini CLI从六月份开始就停服了



win安装

```
irm https://antigravity.google/cli/install.ps1 | iex
```

mac安装

```
curl -fsSL https://antigravity.google/cli/install.sh | bash
```
