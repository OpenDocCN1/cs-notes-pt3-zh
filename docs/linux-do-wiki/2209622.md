# :fire:【图像视频系列8】关于Gemini-omni-flash，你想知道的一切



## Gemini-omni-flash在5月19日Google IO 26大会上发布

模型主页：[Gemini Omni — Google DeepMind](https://deepmind.google/models/gemini-omni/)



提示词指南：[How to create effective prompts with Gemini Omni — Google DeepMind](https://deepmind.google/models/gemini-omni/prompt-guide/)

### Gemini app平台：已上线

Pro会员5h约4条，与聊天公用额度



一个提示词只能生成一个视频



不能用Agent功能



入口：[https://gemini.google.com/](https://gemini.google.com/) 点加号 → 选制作视频

### Flow平台：已上线

每次消耗10(4s)~30(10s)积分，



pro会员每月有1000积分



一个提示词可以同时生成4个视频



可以用Agent功能



入口：[Flow](https://labs.google/fx/zh/tools/flow/)

### Youtube short平台：暂未上线

### 优点

可自拍角色(类似Sora Character)



可编辑性，类似Kling O1



可4-10s（3.1只有8s）

### 缺点

暂不支持首尾帧



涨价了，omni-flash8s25积分，3.1-fast是20积分，3.1-lite是10积分



整体性能比seedance2差很远



会员：plus及以上，Free没有
