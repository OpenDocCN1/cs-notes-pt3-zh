# 在实践中探寻AI能力的边界



## 问题的背景

> 先简单介绍，我是一名软件工程师，大约在gpt2问世的时候开始使用ai辅助编程，刚开始主要是用ai来帮助我回忆实现某种功能的写法，后来ai能力一直在增强，直到现在我的工作中90%的代码都是由ai生成的

> 但我也会一直会思考：拥有强悍逻辑能力的生成式ai（基于transformer架构的LLM）和我们人类相比，它的能力边界是什么，人类有什么目前ai没有的能力或难以做到的事（目前阶段）

于是在这种动机的驱动下，我一边生活一边找机会进行探索，包括在各种论坛&群里向大家提问，看看能不能从中获取什么启发，还有就是继续使用ai去做各种各样的事：

- 包括实现不同领域的软件工具，为各类开源项目写pr；

- 跟不熟悉ai的人介绍它是什么，如何用它来改善生活；

- 使用ai来帮助学习一个领域，一本pdf教材可能是一个引子；

- 使用ai来辅助我编写文档/教程/制作动画（因为我有一个兴趣就是用b站制作cs教程）

- 生活中的十万个为什么

- …

我心底一直认为思考/探索ai的能力边界对我们会有很大帮助：

- 找到自己的核心价值

- 更好地使用ai来达到目标

我在各种提问中获得了不少启发，不过我认为他们都是一些简单阐述，将他们的核心观点抽象/总结出来才能具备使用价值，于是我考虑用建一个帖子并不断对齐更新的方式来将他们具象下来，并且尽可能地定量/定性分析，我认为这也是一个梳理自己思路极好的方法，这就是这篇帖子的由来，我会在本帖下的每一个回帖中确立一项**ai能力上的缺陷/局限性**，并讲述这种判断的由来，和llm底层的关系，如何在实践中更好地克服这些局限等内容

Let’s go~
