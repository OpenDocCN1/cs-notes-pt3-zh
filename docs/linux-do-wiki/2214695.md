# 苹果手机Gmail登录多个账号方法



我前面使用Gmail登录google账号的时候，登录10个就无法继续登录了，提示超过了最大限制，后面偶然一次发现一个方法：

1. 先正常登录，当后面继续登录的时候，提示超过了最大数量的时候

2. 打开Safari浏览器，[打开google.com](http://xn--google-oi2ls3t.com)，点击右上角头像

3. 可以看到有很多登录状态的账号，基本跟你的Gmail邮箱登录的账号一样

4. 点击退出全部账号【不影响Gmail已经登录的账号状态】，然后点击删除账号，将上面登录了的账号都删除掉 【直接去safari设置里清除历史记录与网站数据也行，比较快，不介意历史记录的可以操作】

5. 返回Gmail App，重新添加Google账号，即可继续添加了

6. 楼主目前登录了30几个，我看到有佬友登录50多个的
