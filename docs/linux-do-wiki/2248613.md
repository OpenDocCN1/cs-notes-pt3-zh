# 光猫 / Modem / ONT

先说光猫，也就是运营商送的那台。

传统意义上的 Modem 叫调制解调器，负责在模拟信号和数字信号之间转换。但现在很多地区已经换成了速度更快的光纤入户，所有我们一般将其叫做光猫。

名字什么的不太重要，这个就是用于连接到运营商网络的硬件入口。

![Snapzy2026-05-2615-45-025551532×494 51.7 KB](https://cdn3.ldstatic.com/original/4X/f/6/4/f64c070d6ac6f51008688ad277c9301e416fd7d5.jpeg)

不过随着时代的发展，现在运营商给出的光猫是一体机：它聚合了多个硬件的功能——光猫，拨号，做路由器，还提供 WIFI 网络。

这也是有人容易弄混的原因。

在 Homelab[[1]](#footnote-18258828-1) 或稍复杂的家庭网络里，我们一般会把光猫改成桥接模式，让它只提供线路接入，后面的路由器负责拨号和管理内网。

![Snapzy2026-05-2615-50-001521502×478 73.2 KB](https://cdn3.ldstatic.com/original/4X/2/b/0/2b0d1fbb9a048087ae06daf7a0e5df59e34b3eeb.jpeg)

# 路由器 router

很多人看到路由器上的天线，就简单的将路由器简单的理解为提供 WIFI 的硬件，但事实上路由器的主要功能不是提供 WIFI。

路由器的主要功能是连接不同的网络。

正如我们之前提到：光猫是用于接入运营商网络的设备。



而路由器则是连接光猫和你家庭内网的设备。



路由器将两个网络连接起来了。

![Snapzy2026-05-2615-54-017241568×574 60.9 KB](https://cdn3.ldstatic.com/original/4X/5/a/5/5a5521329427eb6ba211e4c0221edd91200092cd.jpeg)

举个例子，你家里可能是这样：

| 设备 | IP 地址示例 | 作用 |

| --- | --- | --- |

| 路由器 | 192.168.1.1 | 默认网关 |

| 台式机 | 192.168.1.10 | 有线终端 |

| 手机 | 192.168.1.23 | 无线终端 |

| NAS | 192.168.1.50 | 局域网存储 |

| 打印机 | 192.168.1.80 | 局域网设备 |

这些设备访问互联网时，通常都会先把流量交给 `192.168.1.1`，也就是路由器。

这里顺便提一下：双重 NAT。

可以简单理解为，一个“计算”被重复计算了。

先说 NAT。NAT 是 Network Address Translation，网络地址转换。

家里很多设备都有内网 IP，比如：

```
手机：192.168.1.23
电脑：192.168.1.30
NAS：192.168.1.50
```

这些地址只能在你家里用，不能直接出现在公网。路由器会把它们转换成一个外部地址去访问互联网。

可以简单理解成：

```
内网设备：192.168.1.30:50000
↓
NAT路由器外侧地址：100.64.12.34:62001
↓
互联网
```

外部网站看到的不是 `192.168.1.30`，而是你路由器外侧的地址。返回数据回来时，路由器再根据 NAT 记录表，把数据还给对应的内网设备。

![Snapzy2026-05-2615-55-165001624×612 88.7 KB](https://cdn3.ldstatic.com/original/4X/e/2/8/e28c97dc7222e92e2f0f3f0872881aec98fa0bcd.jpeg)

于是一般我们会选择光猫进行桥接，而路由器进行拨号。

# 交换机

在交换机出现之前，还有很多设备：中继器，Hub，网桥。



这些都是为了解决一些网络上的问题。

中继器避免了信号在长距离传输时的衰减，而 HUB 就是有多个端口的中继器，而网桥就是对于信息有选择性的转发。

![Snapzy2026-05-2616-03-046391556×712 79.6 KB](https://cdn3.ldstatic.com/original/4X/4/8/9/4892a87f89c5c33af078476aa3dc1fce8bed52cd.jpeg)

当我们家中需要有线连接的设备越来越多时，路由器自带的一些 LAN 口不够用时，我们就得想办法扩展它。这是就是我们购买交换机的时候。

交换机和传统的集线器有区别，购买的时候也需要明确。

![Snapzy2026-05-2616-05-267491554×552 68.9 KB](https://cdn3.ldstatic.com/original/4X/4/3/d/43dc7c46efabcca10f2def520d634b802ce20516.jpeg)

交换机常见几类：

| 类型 |  | 典型用途 |

| --- | --- | --- |

| 非管理型交换机 | 普通家庭、小办公室 | 插上就用，扩展网口 |

| 管理型交换机 | Homelab、企业、小型机房 | VLAN、QoS、端口镜像、链路聚合 |

| PoE 交换机 | 有 AP、摄像头、IP 电话的环境 | 网线同时传数据和供电 |

| 2.5G / 10G 交换机 | NAS、工作站、虚拟化用户 | 提升内网传输速度 |

| 三层交换机 | 企业网络 | 不同 VLAN / 网段之间转发 |

如果是简单的设备对网速没有要求，千兆的交换机就可以了。



如果有 NAS 等那就考虑 PoE 交换机。

![Snapzy2026-05-2616-06-372801552×478 80 KB](https://cdn3.ldstatic.com/original/4X/a/7/0/a700a628aab2656d29996d9b571d14749c216382.jpeg)

# AP

AP 是 Wireless Access Point，无线接入点。



通过网线接入已有网络，然后发出 Wi-Fi，让手机、笔记本、平板这些无线设备连接。

![Snapzy2026-05-2616-07-151271698×640 76.8 KB](https://cdn3.ldstatic.com/original/4X/e/6/8/e68411a7eaf56d2e7f636002be678a3da168f7e5.jpeg)

家用无线路由器通常把“路由器 + 交换机 + AP”做在一起，所以大家才会把 Wi-Fi 和路由器混在一起。

但在专业一点的网络里，路由和无线覆盖往往是分开的。

| 方案 | 效果 | 说明 |

| --- | --- | --- |

| 单台无线路由器 | 一般 | 小户型够用 |

| 普通无线中继 | 看情况 | 便宜，但容易牺牲速度 |

| Mesh 无线回程 | 中等 | 部署方便，但受距离和墙体影响 |

| Mesh 有线回程 | 较好 | 每个节点有网线，体验更稳定 |

| 多个有线 AP | 很好 | 新装修或有布线条件时推荐 |

有网线的位置尽量上有线 AP 或有线 Mesh。

# 防火墙

这个其实也很重要，防火墙设备接入在网络入口前面，进行流量检测。

如果检测到不符合你所设置的条件，这个流量就无法通过。

![Snapzy2026-05-2616-09-314241650×502 57.6 KB](https://cdn3.ldstatic.com/original/4X/5/c/9/5c94349eb77b097b052507c8ae8c9ce1d0c5908c.jpeg)

# 网卡

网卡，英文叫 NIC，Network Interface Card。

它是设备接入网络的硬件接口。有线网口是网卡，无线 Wi-Fi 模块也是网卡。所有能连接互联网的设备里都有网卡。

![Snapzy2026-05-2616-10-085911652×508 61.1 KB](https://cdn3.ldstatic.com/original/4X/d/1/d/d1d781d42144754ea8483a6ca4bd54d964104de3.jpeg)

这也是为什么玩 NAS 的人尤其注意网卡能力。

| 网卡规格 | 理论带宽 | 理论换算 |

| --- | --- | --- |

| 百兆 | 100 Mbps | 约 12.5 MB/s |

| 千兆 | 1 Gbps | 约 125 MB/s |

| 2.5G | 2.5 Gbps | 约 312.5 MB/s |

| 10G | 10 Gbps | 约 1250 MB/s |

这些速度都是理论值，还需要考虑协议开销，硬盘读写性能，CPU，线材等等。

常见的有双绞线、同轴电缆、光纤，无线网络则使用无线电波。

# 总结

| 设备 |  |

| --- | --- |

| 光猫 / ONT | 把运营商线路接入你家 |

| 路由器 | 连接公网和家庭内网，负责网关、NAT、DHCP 等 |

| 交换机 | 扩展有线网口，让局域网设备互联 |

| AP | 提供 Wi-Fi 覆盖 |

| 防火墙 | 控制哪些流量能进出网络 |

| 网卡 | 设备接入网络的硬件接口 |

| 网线 / 光纤 | 网络信号传输介质 |
