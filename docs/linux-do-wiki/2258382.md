# :fire:【AI大战系列10】用非洲草原生态解释中美AI竞争（狮子王版）



我写了个中美AI在非洲大草原的故事，让image2画成图，理解的还挺准确的 ![:rofl:](https://cdn.ldstatic.com/images/emoji/twemoji/rofl.png?v=15)

[image1672×941 831 KB](https://cdn3.ldstatic.com/original/4X/3/0/e/30e4285b328aa4927bc3cda8ece00778e80d8e76.jpeg)

另外发现这个image2每次针对上一张改版，图像都会劣化5~10%(变脏有黑印)，尤其是文字劣化10-20%，会变乱码，一般接力改三四版后乱码就很严重了

办法Ⓐ，先改几版测试出成熟满意提示词，不管劣化问题 → 合并所有提示词，从零开始生成抽卡(0次劣化)

对于字特别多的图，最好用这种方法一步到位

办法Ⓑ，先抽卡得到第一版 → 改几版找到成熟提示词，不管劣化问题 → 合并提示词从第一版生成(1次劣化乱不严重)

如果字不多，第一版效果也不错，可以用这种方法
