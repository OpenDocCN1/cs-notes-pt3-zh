# giffgaff 实体卡转esim教程



# 本教程用于论坛内给激活码，但是不给实体卡的用户使用，并且不支持esim的手机

## 前提条件

1. giffgaff实体卡激活码

2. giffgaff官网注册账号

3. visa卡用于充值

4. 小白卡

## 操作步骤

1. 实体卡激活到充值步骤参考:[GitHub - ssnhd/giffgaff · GitHub](https://github.com/ssnhd/giffgaff)

2. 当前准备工作已完成，已经有激活并且充值好的实体卡，并且可以登陆官网

3. 登陆官网后，打开F12，获取最新的Cookie

4. 进入[https://esim.kim/giffgaff/](https://esim.kim/giffgaff/) ，然后填入Cookie，验证Cookie有效性，会有验证码发送到实体卡，找给激活码的要一下验证码填入，然后按照步骤就可以获取到esim的相关信息

5. 下载 [版本发布 - PeterCxy/OpenEUICC - Angry.Im Software Forge](https://gitea.angry.im/PeterCxy/OpenEUICC/releases) 最新版本的EasyEUICC,手机插入小白卡，然后扫描网站获取到的二维码，或者手动填入信息，然后就可以进行激活，点击启用就完成了。

备注：我也试了网上通过postman脚本转esim，但是会报错Invalid CORS request，我也没有找到方案，所以把自己的方案分享给大家。

另外苹果手机在插入卡之前关闭imessage/facetime，要不然会自动发一条短信0.3，会有一个流量验证消费0.01，如果接不到码，把手机语言改成英语，ip换成英国ip，应该就可以了。欢迎各位大佬进行相关补充。
