# Vaultwarden 自建方案



看到另一个帖子发的备份方案，我也分享下我的方案。

---

Google Cloud 的免费层级中有一台 e2-micro 机器，其中包含 1 GB 出站流量，但目的不包括中国和澳大利亚。

![](https://cdn3.ldstatic.com/optimized/3X/f/7/f74dbc6eb29149f30e5241925000cd050ff4594f_2_690x362.png)

### [Free cloud features and trial offer  |  Google Cloud Free Program](https://cloud.google.com/free/docs/free-cloud-features)

Discover the free cloud features that come with the Google Cloud trial offer and more information on how to upgrade your account.

如果想利用这台机器，那么就不能直接在上面提供服务，不然就全是亚洲流量了。所以我们得套一层 Cloudflare Tunnel 来规避亚洲流量。

那么备份呢？使用 GitHub 来做就可以了。带版本记录，无更新时，不会重复上传。

---

```
# docker-compose.yml
version: '3'

services:
  bitwarden:
    image: vaultwarden/server:latest-alpine
    container_name: bitwarden
    restart: always
    volumes:
      - /bitwarden/data:/data
    environment:
      LOG_FILE: '/data/bitwarden.log'
      DATABASE_URL: '/data/bitwarden.db'
      ROCKET_WORKERS: '10'
      WEB_VAULT_ENABLED: 'true'
      WEBSOCKET_ENABLED: 'true'
      IP_HEADER: 'CF-Connecting-IP'

  proxy:
    image: nginx:stable-alpine
    restart: always
    container_name: proxy
    depends_on:
      - bitwarden
    volumes:
      - /bitwarden/nginx/nginx.conf:/etc/nginx/nginx.conf:ro

  cloudflared:
    image: cloudflare/cloudflared:latest
    restart: always
    user: root
    container_name: cloudflared
    depends_on:
      - proxy

  watchtower:
    image: containrrr/watchtower:latest
    restart: always
    container_name: watchtower
    volumes:
      - /var/run/docker.sock:/var/run/docker.sock
    environment:
      - WATCHTOWER_CLEANUP=true
      - WATCHTOWER_SCHEDULE=0 0 3 ? * 1
      - TZ
```

```
# nginx.conf
user root;
worker_processes auto;
pid /run/nginx.pid;
include /etc/nginx/modules-enabled/*.conf;

events {
        worker_connections 768;
}

http {
        sendfile on;
        tcp_nopush on;
        tcp_nodelay on;
        keepalive_timeout 65;
        types_hash_max_size 2048;

        include /etc/nginx/mime.types;
        default_type application/octet-stream;

        ssl_protocols TLSv1 TLSv1.1 TLSv1.2 TLSv1.3; # Dropping SSLv3, ref: POODLE
        ssl_prefer_server_ciphers on;

        access_log /dev/stdout;
        error_log /dev/sederr;

        gzip on;

        server {
                listen [::]:80;
                listen 80;
                server_name _;

                location / {
                        proxy_http_version 1.1;
                        proxy_pass http://bitwarden:80;
                        proxy_set_header Host $host;
                        proxy_set_header X-Real-IP $remote_addr;
                        proxy_set_header Upgrade $http_upgrade;
                        proxy_set_header Connection "upgrade";
                        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
                        proxy_set_header X-Forwarded-Proto $scheme;
                }

		location /robots.txt {
			default_type text/html;
			add_header Content-Type "text/plain; charset=UTF-8";
			return 200 "User-Agent: *\nDisallow: /";
		}
        }
}
```

然后我们开启一个定时任务 `*/15 * * * * /bitwarden/backup.sh`

```
# backup.sh

#!/bin/sh

# Path
cd "/bitwarden"
TZ='Asia/Shanghai'; export TZ

# SQL
rm backup.db
sqlite3 /bitwarden/data/bitwarden.db "VACUUM INTO 'backup.db'"
sqlite3 backup.db .dump > backup.sql

# git init
# git config user.name "AutoServer"
# git config user.email "auto@server"

git add .
git commit -m "Backup $(date '+%F-%H%M%S')"
git push "https://token@github.com/user/bwdata.git" main:main
```

---

这个方案，基本上每个月可能会有几美分的开销。可以降低备份频率来规避。

但是 Google Cloud 的稳定性非常好，19 年部署到现在，一次问题都没出过。
