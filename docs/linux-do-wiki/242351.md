# 密钥的生成、使用及配置



# SSH密钥

## 生成密钥

```
# 一种是生成ed25519
ssh-keygen -t ed25519 -C "your_email@example.com"

# 一种是生成rsa
ssh-keygen -t rsa -b 4096 -C "your_email@example.com"
```

## 密钥的使用

先查看公钥的内容，写入到需要验证的服务器的~/.ssh/authorized_keys

然后设置权限

```
chmod 600 ~/.ssh/authorized_keys
```

## 密钥的配置

一般来说没有重命名不需要配置，当涉及到不是标准22端口



或者密钥的文件名是自定义的时候，需要配置config，config文件一般在~/.ssh/config下面。

```
nano ~/.ssh/config
# 增加
Host git.abc.com
    HostName git.abc.com
    Port 2222
    IdentityFile /path/to/my_private_key
```

# GPG加密

补充比较称用的GPG密钥管理和使用办法。

## 基本介绍

`GPG` :（全称 `GnuPG` ) 是一款非对称加密(PGP)的免费软件，非对称加密方式简单讲就是指用公钥加密文件，用私钥解密文件。如果你想给谁发送加密信息，首先你要得到他的公钥，然后通过该公钥加密后传给他，对方利用自已的私钥就可解密并读取文件了。



`GnuPG`有几个配置文件，一般存储在主目录`~`下的`.gnupg`目录下。



几个配置文件如下：

```
~/.gnupg/gpg.conf – 配置文件
~/.gnupg/trustdb.gpg – 信任库
~/.gnupg/pubring.gpg – 公钥库
~/.gnupg/secring.gpg – 私钥库
```

命令行使用：

- 生成密钥对



使用`gpg --gen-key`命令可以生成一个密钥对。



也可以使用`gpg --full-generate-key`开启一个更完整的对话框。



按照软件的需求填写一些信息最后设置一个密码就可以生成随机的密钥了，生成密钥对时来自软件的提示：

```

发生器有更好的机会获得足够的熵。

```

生成后可以使用`gpg -k`查看机器上的所有公钥，也可以使用`-K`选项卡来查看所有的私钥。

- 迁移公钥



那么为了避免像我这样换了电脑之后就要重新生成key，需要学习下如何导出你自己的公钥，以后就可以迁移它了。



使用命令`gpg --export --armor mykeyID > gpgkey.pub.asc`可以迁移你的公钥，`mykeyID`的地方写前面设置的名字或者邮箱，以导出对应的key。



如果你有密钥服务器那么直接使用`gpg --keyserver keyserverAddress --send mykeyID`也是可以的。



对应的获取公钥只需要使用`gpg --keyserver keyserverAddress --search-keys keyid/name/Email`命令就可以。

- 导入公钥



使用`gpg --import gpgkey.pub.asc`导入。



使用`gpg --keyserver keyserverAddress --recv-keys pubkeyID`从服务器导入。

- 私钥的迁移



使用命令`gpg -oa seckey.asc --export-secret-keys mykeyID`可以导出你现在的私钥，这样就可以备份了。



使用命令`gpg --import seckey.asc`来导入私钥。

- 公钥回收



当你的机器丢失，或者遭到黑客入侵导致你的公钥被盗窃了，那么及时声明公钥无效是重要的事情，在这之前你要先创建一个回收证书：



使用命令`gpg --output revoke.asc --gen-revoke mykeyID` 创建一个回收证书。



使用命令`gpg --import revoke.asc`来导入一个回收证书。



使用命令`gpg --keyserver keyserverAddress --send mykeyID`将你的回收证书发送到证书服务器上，声明它无效了。

- 加密



使用命令`gpg --symmetric filename`来加密你的文件。



使用命令`gpg -d filename.gpg`来解密你的文件，如果需要保存，记得使用重定向符。

- 数字签名



使用`-o`选项卡来对文件进行数字签名，`gpg -o file.sig -s file`，其中的file是本身的文件，另一个是签名后的文件。



使用命令`gpg -o file.sig -ser mykeyID file`来签名并加密你的文件mykeyID和前文一样是生成密钥时填写的姓名，这个加密后的数据同样可以使用`-d`解密。

- 文本签名



使用命令`gpg -o file.sig --clearsign file`进行文本签名，这个时候生成的内容是下面这样的：

```
-----BEGIN PGP SIGNED MESSAGE-----
Hash: SHA256

hello world
-----BEGIN PGP SIGNATURE-----
xxxxxx
-----END PGP SIGNATURE-----
```

- 分离式签名



使用命令`gpg -o file.sig -ab file`进行分离式签名，这个时候`sig`文件中只有签名。



使用命令`gpg --verify file.sig file`来验证签名，如果不是这个文件的签名就会提示已损坏的签名。

- 续期



gpg密钥会过期，在过期之后可以选择续期操作如下：



`gpg --list-keys`列出key



`gpg --edit-key <keyID>`编辑key



`key 1`选择子密钥



`expire`续期



`save`保存

## 在GitHub中使用

上文中的导出公钥导出的内容复制以下，如果没有导出就不用输出到文件了，直接使用命令`gpg --export --armor mykeyID`导出，然后粘贴到`GitHub` 的设置那块就ok。

1. 设置签名时用的key：` git config --global user.signingkey {key ID}`或者`gpg config user.signingkey {key ID}`

2. 开启GPG签名： `commit：git config commit.gpgsign true`

3. 关闭GPG签名：`git config commit.gpgsign false`

4. 全局配置开启GPG签名：`git config --global commit.gpgsign true`

5. 也可以不配置，在commit的时候加上`-S`参数来加密你的提交。
