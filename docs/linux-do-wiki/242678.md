# 通过fail2ban全自动封禁攻击者IP



放置在公网的服务器时刻面临全球的端口扫描和攻击尝试。除了配置好防火墙策略。以下是种简单方法来增强VPS 的安全性，通过日志检测自动封禁潜在的攻击者。核心是采用iptables跟fail2ban联动。

1. 配置 iptables 日志：



首先，确保 iptables 记录被拒绝的连接尝试：

```
sudo iptables -A INPUT -m limit --limit 5/min --limit-burst 10 -j LOG --log-prefix "IPTables-Dropped: " --log-level 4
sudo netfilter-persistent save
```

这会将所有被拒绝的连接记录到系统日志中。这里的 `--limit-burst 10` 表示最初允许 10个日志条目快速记录，之后才开始应用每分钟5 条的限制。避免在遭受大规模攻击时导致大量日志写入。

1. 配置 rsyslog 以分离 iptables 日志：



编辑 /etc/rsyslog.d/10-iptables.conf 文件：

```
sudo nano /etc/rsyslog.d/10-iptables.conf
```

添加以下内容：

```
:msg,contains,"IPTables-Dropped: " /var/log/iptables.log
& ~
```

重启 rsyslog 服务：

```
sudo systemctl restart rsyslog
```

1. 配置 Fail2ban 以监控 iptables 日志：



创建一个新的 Fail2ban 过滤器。编辑 /etc/fail2ban/filter.d/iptables-custom.conf：

```
sudo nano /etc/fail2ban/filter.d/iptables-custom.conf
```

添加以下内容：

```
[Definition]
failregex = IPTables-Dropped: .* SRC=<HOST> .*
ignoreregex =
```

1. 创建一个新的 Fail2ban jail。编辑 /etc/fail2ban/jail.local：

```
sudo nano /etc/fail2ban/jail.local
```

添加以下内容：

```
[iptables-custom]
enabled = true
filter = iptables-custom
logpath = /var/log/iptables.log
maxretry = 2
findtime = 3h
bantime = 1d
action = iptables-allports[name=iptables-custom]
```

这将创建一个新的 jail，如果在 3小时 内检测到 2 次失败尝试，就会封禁 IP 地址 1天。



这里务必注意把自己经常访问的IP地址加入到默认豁免地址列表里。否则一不小心自己被封禁就会丧失VPS远程连接权力。

```
[DEFAULT]
ignoreip = 127.0.0.1/8 10.0.0.0/8 192.168.0.0/16
```

1. 重启 Fail2ban：

```
sudo systemctl restart fail2ban
```

1. 监控日志：



您可以使用以下命令实时监控 iptables 日志：

```
sudo tail -f /var/log/iptables.log
```

1. 检查 Fail2ban 状态：

```
sudo fail2ban-client status iptables-custom
```

这将显示当前被封禁的 IP 地址和统计信息。

通过这些步骤，应该能够检测到端口扫描和其他潜在的攻击，并自动封禁攻击者的 IP 地址。请记住定期检查日志和 Fail2ban 状态，以确保一切正常运行。
