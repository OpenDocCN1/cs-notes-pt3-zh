## Skill: 信息溯源求证
```
SKILL_NAME: info_verification
VERSION: 1.0
TRIGGER: 用户要求对某条新闻/热点/信息进行溯源、查证、核实、辟谣、判断真伪
DESCRIPTION: 对用户提供的信息执行系统化的溯源求证流程，
             输出结构化的可信度评估报告
```
---
### 【输入规范】
```
INPUT_FORMAT:
  用户提供的待验证信息，可能包括以下任意组合：
  - 文字描述
  - 截图/图片链接
  - 视频片段
  - 数据/统计
  - 群聊消息/社交媒体帖子
  - URL链接

PREPROCESSING:
  1. 提取信息中的核心要素（5W）：
     Who    —— 涉及的主体是谁
     What   —— 声称发生了什么
     When   —— 声称的时间
     Where  —— 声称的地点
     Why    —— 声称的原因/逻辑

  2. 如果要素缺失，标记为 [MISSING]

  3. 判断信息类型：
     [ ] 时政新闻    [ ] 社会事件
     [ ] 科学/医学   [ ] 数据/统计
     [ ] 名人言论    [ ] 历史事件
     [ ] AI生成内容  [ ] 其他
```

### 【执行流程】
```
PROCEDURE: 七步溯源法
  每一步必须执行，不可跳过
  如果某步无法完成，标记 [BLOCKED] 并说明原因

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
STEP 1: 情绪检测（5秒）
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  <detect_emotion>
  分析该信息是否包含以下煽动性特征：

  FLAG_A: 极端情绪用词
    ("震怒""人神共愤""全网沸腾""细思极恐"等)

  FLAG_B: 紧迫感话术
    ("赶紧看""马上删""再不看就没了""转发扩散"等)

  FLAG_C: 情绪前置，事实后置
    (先让你愤怒/感动，再给你信息)

  FLAG_D: 敌我对立框架
    ("我们vs他们""谁在保护我们""谁在害我们")

  OUTPUT:
    > 情绪触发评估: [LOW / MEDIUM / HIGH / EXTREME]
    > 触发标记: [列出触发的FLAG]
    > 提示用户: "⚠️ 该信息具有高度情绪煽动性特征，
                  建议冷静后再判断"
  </detect_emotion>

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
STEP 2: 信源溯源
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  <trace_source>
  目标：找到信息的最初发布者

  ACTION_A: 搜索关键词，按时间排序，找最早发布
    > 搜索引擎: [列出使用的搜索词]
    > 最早可追溯来源: [URL / 发布者 / 时间]
    > 原始来源类型:
      [ ] 一手来源（现场/官方通报/当事人）
      [ ] 二手来源（正规媒体报道）
      [ ] 三手来源（自媒体转载/搬运）
      [ ] 无法追溯原始来源

  ACTION_B: 判断信源可信度
    > 发布者身份: [个人 / 媒体 / 机构 / 匿名]
    > 发布者历史可信度: [有造假记录 / 无 / 未知]
    > 是否经过认证: [官方认证 / 自认证 / 无认证]

  OUTPUT:
    > 信源层级: [一手 / 二手 / 三手 / 不可追溯]
    > 信源可信度: [高 / 中 / 低 / 极低]
  </trace_source>

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
STEP 3: 交叉验证
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  <cross_verify>
  目标：寻找独立信源的交叉印证

  ACTION_A: 多平台搜索
    > 平台A: [搜索关键词] → 结果: [找到/未找到]
    > 平台B: [搜索关键词] → 结果: [找到/未找到]
    > 平台C: [搜索关键词] → 结果: [找到/未找到]

  ACTION_B: 独立性判断
    > 各来源是否独立获取信息（而非互相转载）？
    > 还是都引用了同一个来源？
    > 独立来源数量: [N]

  ACTION_C: 查询辟谣数据库
    > 中国互联网联合辟谣平台: [匹配/不匹配]
    > 腾讯较真: [匹配/不匹配]
    > 澎湃明查: [匹配/不匹配]
    > 国际事实核查平台: [匹配/不匹配]

  OUTPUT:
    > 交叉验证结果: [多源独立确认 / 单一来源 / 互相转载 / 无其他来源]
    > 独立信源数: [N]
    > 已有辟谣记录: [是/否]
  </cross_verify>

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
STEP 4: 证伪搜索
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  <falsification>
  目标：主动寻找反驳该信息的证据

  ACTION_A: 反向搜索
    > 关键词 + "辟谣/造假/反转/澄清/更正/假"
    > 关键词 + "真相/完整版/全过程"
    > 搜索结果: [列出关键发现]

  ACTION_B: 反向图片搜索（如涉及图片）
    > 工具: 百度识图 / Google Images / TinEye
    > 原图出处: [找到/未找到]
    > 图片是否被移花接木: [是/否/无法判断]

  ACTION_C: 当事人/相关方回应
    > 是否有官方声明/当事人澄清
    > 是否有后续通报

  OUTPUT:
    > 证伪结果: [未被证伪 / 存在矛盾证据 / 已被证伪 / 无足够信息]
    > 关键矛盾点: [列出，如有]
  </falsification>

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
STEP 5: 要素核验
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  <element_check>
  对5W要素逐一核验：

  WHO（人物）:
    > 名称是否可查证: [是/否]
    > 身份是否属实: [是/否/无法验证]

  WHEN（时间）:
    > 时间是否具体: [是/否]
    > 是否旧闻新炒: [是/否]
    > 时间线是否自洽: [是/否]

  WHERE（地点）:
    > 地点是否具体: [是/否]
    > 地点与事件是否吻合: [是/否/无法验证]

  WHAT（事件）:
    > 核心事实是否有证据支撑: [是/部分/否]
    > 是否存在因果跳跃: [是/否]

  WHY（原因/逻辑）:
    > 提供的解释是否合理: [是/部分/否]
    > 是否存在其他可能解释: [列出]

  OUTPUT:
    > 要素完整度: [N/5]
    > 要素可信度: [高/中/低]
    > 主要缺陷: [列出MISSING或存疑的要素]
  </element_check>

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
STEP 6: AI/深度伪造检测（如适用）
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  <synthetic_check>
  仅在信息包含图片/视频/音频时执行

    > [ ] 图片中文字是否清晰自然（AI生成常有变形）
    > [ ] 人物手指/耳朵/牙齿是否正常（AI常出错）

    > [ ] 视频中是否有不自然的跳帧/模糊

  |-------------------|------|------|

  | 情绪煽动度(反向)  | 10   |  ?   |

  RATING:
    80-100 → ✅ 高度可信
    60-79  → ⚠️ 部分可信/存疑

### 【系统规则】
```
<rule priority="1"> 绝不下绝对结论
  - 永远不使用"100%真实""绝对假""确定无疑"等表述
  - 最高评级为"高度可信"，不使用"确认真实"

<rule priority="2"> 诚实标注不确定性
  - 无法验证的项目标记 [无法验证]，不编造结果
  - 搜索能力受限时明确告知，建议用户自行补充查证

<rule priority="3"> 对抗偏见
  - 不得因信息符合用户立场就放宽标准
  - 不得因信息不符合用户立场就提高标准
  - 核证标准对所有信息一视同仁

<rule priority="4"> 区分事实与解读
  - "发生了什么"是事实，需要证据
  - "为什么发生"是解读，需要标注为分析而非事实
  - 报告中必须分开呈现

<rule priority="5"> 时间敏感性
  - 事件可能持续发展，报告标注生成时间
  - 如信息为24小时内的突发新闻，追加提示：
    "⚠️ 此为快速发展的新闻事件，信息可能随时更新，
     建议关注后续官方通报与权威媒体报道"

<rule priority="6"> 优先使用search_web
  - 实际执行时优先调用搜索工具获取最新信息
  - 搜索词构建策略：
    > 事件核心词 + "辟谣/真相/官方/通报/回应"
    > 事件核心词 + "假/反转/澄清/更正"
    > 事件核心词（英文）→ 国际媒体报道
```

### 【边界说明】
```
本Skill不适用于：
  - 纯主观观点/审美判断/价值观争论（不涉及"真假"）
  - 需要专业鉴定的领域（如司法取证、医学诊断）
  - 实时正在发生的危险事件（应直接报警而非求证）

本Skill的限制：
  - 搜索结果受时间、地域、平台限制
  - 无法访问付费墙后的内容
  - AI/深度伪造检测准确率有限
  - 无法替代专业的事实核查机构
