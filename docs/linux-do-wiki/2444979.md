> **前情提要**
>
> [Linux.do IDEA插件](https://linux.do/t/topic/1317106)
>
> [Linux.do VSCode插件](https://linux.do/t/topic/1264288)
> 继 VSCode 版和 IDEA 版相继发布后，收到了很多佬友们的回复
>
> 经过几天的努力，CLI 版本的 linuxdo-explorer 终于和大家见面了
使用教程
第一步：[下载可执行文件](https://github.com/TooAme/linuxdo-explorer/releases/tag/CLI1.0.2)
第二步：linux 需要授权，其他跳过这一步
```
# 具体看自己文件名设置
chmod +x ./linuxdo-cli
```
第三步：创建一个配置文件 config.json
第四步：填写 cookie 和 user-agent 到配置文件
```
{
// cookie必须转义为json字符串，不然会报错
    "cookie": "",
    "user_agent": ""
}
```
第五步：启动可执行文件
```
# 具体看自己文件名再执行
./linuxdo-cli.exe
```

## NO.4 基于 Go 开发 LinuxDO CLI
作者：[@hellow0rld](/u/hellow0rld)
![:bili_024:](https://cdn3.ldstatic.com/original/3X/8/0/8072649ac02f8017cdc096a32a6c2d2896da5e88.png?v=15) 基于 go 语言开发，测试了一下是需要验证的，所以用 ai 修了一下，采用 cookie 和 user-agent 方式登录，如果大家使用的话，遇到登录失败情况下，多试一下，修有点粗糙，我测试了一下上下不能翻页，支持回复，点赞。
[image1644×901 68.3 KB](https://cdn3.ldstatic.com/original/4X/5/b/1/5b17588f5ccb64f467e9735baf92a5b823f8942e.png)
> 在终端里的 L 站客户端，golang 实现，目前已经实现了浏览、回帖、搜索功能，后续会继续丰富，支持摸鱼模式，欢迎各位佬友来体验，提 bug 和贡献
>
> 同时将一些功能封装成了 Mcp Server。![:heart:](https://cdn.ldstatic.com/images/emoji/twemoji/heart.png?v=15)
源码：[ldo.7z](/uploads/short-url/58rcE4yFfckWNoYHejuSlVhVXTk.7z) (25.3 KB)
1. 下载源码包并解压上传到 linux 环境
2. 下载 go 语言
```
# 1.下载安装包
wget https://dl.google.com/go/go1.23.0.linux-amd64.tar.gz
# 2.解压
sudo tar -zxvf go1.23.0.linux-amd64.tar.gz -C /usr/local

# 3.设置环境变量
sudo vim /etc/profile
# 写入
export GOROOT=/usr/local/go
export PATH=$PATH:$GOROOT/bin
# 刷新
source /etc/profile
```
1. 切换到 ldo 目录下，切记不要进入 cmd / ldo，打包项目
```
// 打包
go build -o ldo cmd/ldo/main.go

// 不打包直接运行
go run cmd/ldo/main.go
```
1. 修改文件权限，让其是可执行文件
```
chmod +x ldo
```
1. 运行
```
./ldo
```
