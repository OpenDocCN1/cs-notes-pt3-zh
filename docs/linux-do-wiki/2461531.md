### 结构
```
{
  "PaiMian": {
    "huaSe": 2,
    "number": 1,
    "feng": 0,
    "jian": 0
  },
  "DeltaBaseScore": 0.0,
  "BaoId": 0,
  "LingId": 10031
}
```
### 字段
`PaiMian{}`：牌面
- huase 花色（1万 2饼 3索）
- number 数字（1~9）
- feng 风牌（1~4 东南西北？）
- jian 三元牌（1中 2发 3白）
> 这么写太不优雅了，`1m 2p 3s 4z`直接当key多省事
`DeltaBaseScore`：牌面分增幅（Float；基础分为5，实际分数为n+5；例如该值为10.0，则牌面分为15）
`BaoId`：宝牌ID
- 1：红宝牌
- 2：蓝宝牌
- 3：绿宝牌
