# 自建公网 paseo relay 管理内网 linux 和 windows



# 缘起

不想使用paseo 官方的 relay

# 准备

- 一台公网服务器

- 域名+证书（可选）

# docker 部署 paseo relay

使用下面的 compose 文件 up

```
services:
  paseo:
    container_name: paseo
    hostname: paseo
    image: ghcr.io/zenghongtu/paseo-relay
    ports:
      - "8411:8411"
    restart: always
    labels:
      com.centurylinklabs.watchtower.enable: 'true'
```

> 镜像下载慢可以使用 [https://1ms.run/](https://1ms.run/) 配置镜像加速

up 成功之后，配置域名和反向代理，这里就不写了，假设我暴露的公网域名是 `https://relay.xxx.com`

# 更新 paseo daemon 配置

先追加下面的配置，若暴露的公网支持 https，则需要增加 `"useTls": true`

```
{
    "daemon": {
        "cors": {
            "allowedOrigins": [
                "https://relay.jxxx.com"
            ]
        },
        "relay": {
            "enabled": true,
            "endpoint": "relay.xxx.com:443",
            "publicEndpoint": "relay.xxx.com:443",
            "useTls": true
        }
    },
  "app": {
    "baseUrl": "https://relay.xxx.com"
  },
}
```

配置好之后重启 daemon

```
paseo daemon restart
```

获取最新的  pair 链接

```
 paseo daemon pair
```
