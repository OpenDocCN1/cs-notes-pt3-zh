# 高考如何选择大学和专业（L站特供版本）



本文针对18岁以前就能进入L站论坛的有志青年男女老少。



将以提问的方式带着大家思考

# 第一问：你是北京、江浙沪、珠三角的本地人吗？

## 如果是这三个地方的本地人，不建议出省。

出省意味着同样分数，你只能上一个不如本省的学校，周末很难回家，谈恋爱大概率毕业分手，节假日来回车票，实习还不如自己本地爸妈上班的同事人脉丰富。

# 第二问：你打算从事医生，老师，财经，水力等地域性高校专业吗？

（欢迎佬友补充还有什么专业是地域性的）



此类专业主打一个当地学校，医院有一定的本地的就业岗位倾斜，属于是保就业派。

# 第三问：你打算深造读研究生硕士吗？

如果有，那我建议你保研，现在211高校的保研额度能有18%及以上（从2025年开始扩）



如果你真的想深造你至少要选211高校，专业其次，城市其次。（比如兰州大学这种鸟不拉屎的地方是真挺合适本科猥琐发育的）



而所谓的北上广深的双非保研率估计也就3%（这里不统计地方特殊专业院校）

## 保研的核心逻辑：本科在读学校的竞争中拿到保研资格（保研率）——出去找北上广深或者喜欢的城市去海投夏令营九推等

前者211保研率18%双非3%



后者拿到你简历的985老师大概率是个行政老师初筛简历，先看你是不是211本科，再看你的专业排名



如果你本科是双非保研上985叫逆袭，本科是211保研上985那叫正常晋升。

# 第四问：你想赚钱吗？

在我国，想赚钱，未来5年内不会改变的事就是，你得学工科，你得去大城市。

# 第五问：你喜欢体制内吗？

如果一开始就奔着体制内，那就梭哈985吧。有一种打法叫：清华系。



所以学历层次就是最重要的没有之一了，个人能力不是啥重点了，需要的能力都是工作中积累的。

我举一个例子：



我是张三，我家在小县城，我们省只有211，我排名不错，省内省外都能上211，我想赚钱，我想深造，我不想进体制内。

那我的选择就是：



如果我能上985的工科专业那就去，等保研回到北上广深。



如果我上不了985的工科专业，那我就去211的工科专业，如果可以选择城市那就选大城市，保研去985。
