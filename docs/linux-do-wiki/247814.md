# 小鹤双拼音形入门指北

- 介绍
- 中文没办法像英文那样直接输入字母, 只能先根据读音筛选出一批同音字, 再用数字加上翻页键不断寻找, 最终完成输入
- 不过目前的的拼音输入法靠着词库联想功能, 输入已经很快了. 中文的拼音长度一般在1-6个字母之间, 而双拼把声明和韵母分别用两个字母映射, 这样每个字都可以稳定用2个字母打出来. 双形则是在这个基础上, 靠部件笔画, 进一步过滤, 在4个字母内唯一确定一个汉字, 不需要翻页寻找了
- 双拼
- 双拼有很多种输入方案, 个人推荐小鹤双拼–鹤仙流, 键位相比其他输入方案更合理
- 双拼就是把`zh, ch, sh` 这样的多音节声母分别用`v, i, u` 代替, 把`ou, ia, ao` 这样的韵母用`z, x, c` 代替
- 双拼可以大大减少按键次数. 比如"床前明月光"这句话, 正常全拼要输入"chuang qian ming yue guang", 而双拼只需要输入"il qm mk yt gl"
- 不过像"啊" 这样的单音节字原本全拼用一个字母a 就可以了, 双拼要输入两个a

- 每天念诵和练习一遍, 正常三天可以盲打, 一周就可以达到全拼的速度, 后面将会越来越快, 越来越轻松. 另外搜狗输入法支持全拼双拼混输, 这样在前期不熟练的时候, 不会误事. Windows 自带的微软拼音没有内置小鹤双拼, 不过支持自定义方案, 执行一下官网提供的注册表, 或者根据上面的键位映射图自己手动添加就行了
- 双形
- 正常双拼就满足一般人的需求了, 但是双形还能更快! 另外如果你也像我一样有提笔忘字的毛病, 双形可以大大缓解症状
- 前面说过, 拼音输入法因为同音字的关系, 字母输入完经常还需要进行一轮人工筛选
- 而双形则是把一个字拆分成两部分, 然后取这两部分的发音的声母, 跟双拼合在一起, 用4个字母准确打出一个字
- 比如"环保"的环, 输入hr(双拼) 以后, 继续输入wb, 就可以唯一确定"环" 了. 这里之所以输入"wb", 是因为"环" 可以拆分成"王" 和 “不”, 它们的声母分别是"w" 和"b". 所以输入"hrwb" 可以直接输出"环", 这就是双形, 四码上屏
- 但不是所有的汉字都是这么简单拆分, 主要有三种拆分规则:

有的是按照小字(不再包含字或者部件的字)-拆分成多个字, 取首尾两个字: 例如上述的"环", 拆成了"王" 和"不", 通过"hrwb" 输入
有的直接是特例(部件), 用特定字母代表某个部首, 或者残字: w-亠, d-冫氵
有的是按照笔画(取第一笔和最后一笔): a-横 l-竖 p-撇 d-点 v-折 n-捺, 比如"里", 拆成了"|和-“, 通过"lila” 输入
有的是上述混合(首部用部件, 尾部用小字), 比如"就", 拆成了"亠" 和"尤", 通过"jqwy" 输入
- 有时候一个字会有多种拆分, 主要遵循以下拆分规律:

字大优先: “鞍” 字可以拆成"廿女", 也可以拆成"革女", 但是"革"笔画多, 优先拆, 所以通过"angn" 输入
相交不拆: 比如前面的例子"里"字, 虽然可以拆成"甲二", 但是二与甲有交叉
插隔不取: 字根只要被一个结构（可能是字也可能不是）隔离，那拆分时就不被认为是字根，如“办”字的“八”因为被“力”隔离， 则只能取“力点”，而不是“力八”，木→十捺、半→点竖，等字同理
廴辶优先: 以这两个部件为部首的字先取此部件，因为这两个部件特征明显，优先取更直观。部件并非字的部首时，则按照常规顺序拆分，如：筵，其部首为“⺮”，“廴”部件并非部首，故常规首末取“⺮廴”，又如“健→亻廴”
