## 1. 部署建议

**核心建议：Hermes 在单独虚拟机上部署，最好不用 Docker。**

### 说明

单独虚拟机部署的好处：

- 资源隔离，不影响宿主机环境,docker不是很方便

- 权限更多

- 性能更强

> 如果确实要用 Docker，也需要注意：Docker 版在修改配置时可能因自带的安全准则限制而改不了，此时需要通过 SSH 连接到自身机器来执行。

## 2. AI 新闻推送（RSS 定时推送）

### 用途

每天早上自动推送 AI 相关新闻到你的聊天平台（QQ / Telegram）。

### 提示词模板

```
AI新闻推送:

每日检测 RSS: https://daily.juya.uk/rss.xml
从八点到十点，每十分钟检测一次，第一次推送后标记为已读状态不再推送，
推送的时候要确认好是否内容是当天日期的，不是则丢弃。
请把这个做成定时任务
```

## 3. NewAPI 公益站定时签到

### 用途

每天定时签到 NewAPI 公益站点，获取免费 API 额度。

### 提示词模板

```
newapi公益站定时签到:

newapi站点: [站点URL]
令牌: [你的令牌]
用户ID: [你的用户ID]

请帮我创建定时任务，每天早 7 点签到站点
```

### 说明

- 只需提供站点 URL、令牌（Token）、用户 ID，Hermes 自动生成定时签到任务

- 签到脚本设计为 no_agent 看门狗模式：成功签到则通知，已签到则静默，失败则报错

- 并非所有公益站都支持定时签到，部分魔改版可能不行,我就测了2个我用的jiujiu的和朋友的,有的站去掉签到或者签到有pow什么的不能用

## 4. 服务器监控与 Docker 部署

### 用途

让 Hermes 记住你的服务器信息，帮你监控服务器状态、管理 Docker 部署。

### 提示词模板

```
我的服务器 [IP地址] 账号是 [账号]，密码是 [密码]，SSH 端口是 [端口]，Docker 的路径是 [路径]，
请记住，当要你部署 Docker 的时候在 [路径] 部署。
```

### 说明

- 将服务器信息直接告知 Hermes，它会记住并在需要时使用

- 适用于需要经常在服务器上部署项目、管理容器的场景

- 不过建议让他写到记忆力然后docker啥最好补充你的习惯比如,docker要部署什么目录,偏好docker run还是compose,喜欢本地映射还是持久卷

## 5. 修改自身配置（SSH 自身技巧）

### 用途

解决 Hermes 自带的执行限制如hermes gateway restart，让他ssh自己所在的机器可直接执行。

### 提示词模板

```
你所在的机器的 IP 是 [IP]，账号和密码是 [账号]，Root 的账号和密码是 [密码]，
你要修改配置的时候 SSH 自己所在的机器直接执行或修改配置。
```

### 背后的原因

> 他有时候修改或者执行因为自带的啥安全准则或者限制改不了，SSH 就能改，离谱。

## 6. 智能家居控制（通过 Home Assistant）

### 用途

通过 Hermes 语音/文字控制家里的智能设备（小米灯具、开关等）。

### 前提条件

1. 部署 Home Assistant（可以让 Hermes 自行安装）

2. 安装 HACS（同样可让 Hermes 完成）

3. 安装 Xiaomi Home 集成

### 操作流程

1. 在 Home Assistant 中创建令牌（Token）

2. 将令牌提供给 Hermes 进行配置

### 说明

只要设备能接入 Home Assistant，就可以通过 Hermes 控制（如小米智能灯具、开关、插座、风扇等）。Hermes 配置好 HA 后，你只需要说"开灯""关灯"之类的自然语言指令。不过你把插座修改成电脑这种建议先让他输出你有什么设备名字叫啥让他记住并注册成skill,否则可能会有你让他开电脑他去想着 wake on lan什么的

## 7. 跨会话记忆存储（Honcho）

### 用途

使用 Honcho 作为跨会话记忆层，让 Hermes 拥有长期记忆，不再每次对话都"失忆"。

### 提示词模板

```
查看 Honcho: https://github.com/plastic-labs/honcho 这个项目，
尝试 SSH 到你所在的机器并部署，
使用 Honcho 作为跨会话记忆层接入 Hermes，启用后重启网关。

检查 built-in memory 里的凭据信息以及 system prompt 中的条目，
把全部凭证迁移过来，列举出其他记忆条目让我选择是否删除。
```

### 说明

- Honcho 是一个外部记忆存储项目，比 Hermes 自带的记忆功能更灵活

- 部署后需要将原有的凭证信息迁移到 Honcho

- 旧的 built-in memory 条目可以选择性删除

- 迁移后，Hermes 就能跨会话记住你的偏好、凭据、配置

### 记忆整理自动化

建议配合定时任务，每天自动整理 Honcho 中的记忆：

> 设置每天 6:00 自动整理记忆，重要的登录凭证、定时任务、智能家居配置等信息保留在 Honcho 中。

>

> 记得补充说明让他每次对话前记得查一下记忆

## 8. 邮箱验证码自动转发

### 用途

让 Hermes 监控邮箱，自动提取验证码和认证链接并转发给你。

### 步骤

#### 第一步：注册 Agent 邮箱

在 [agent.qq.com](https://agent.qq.com) 注册 Agent 邮箱。

#### 第二步：安装 Agent Mail CLI

向 Hermes 发送：

```
请阅读 https://agent.qq.com/doc/cli-setup.md 文档，
按照步骤为我安装并配置 Agent Mail CLI。
```

#### 第三步：配置邮件转发

在其他邮箱（如 Gmail）中设置邮件转发到该 Agent 邮箱。

#### 第四步：设置自动筛选

对 Hermes 发送：

```
以后检查收到的邮件，如果是接受的验证码、Token 以及需要认证的链接，
请把邮件内容发送给我，其他内容忽略。
```

### 轮询频率

推荐每 2–3 分钟检查一次，可以及时收到验证码。
