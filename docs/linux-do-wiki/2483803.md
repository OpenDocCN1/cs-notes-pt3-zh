# 平邮/平信收件u卡/或者wise实体卡/港卡注意事项



邮箱，收发室，邮局

小时候的信件寄送，邮差，非文件快递。

挂号信，就是增加类似快递单号查询的功能。

- [bybit eu 申领实体卡实操，绕开地址报错](https://linux.do/t/topic/2771324)



**邮路测试**



1.电商平台搜索邮路测试/明信片，填写地址【与u卡收件地址一致】，选择挂号信可以避免平信投递时邮递员不打电话导致下一步没法进行



2.获取邮政派送网点+派送方式+派送员电话加上微信



3.提前告知+发红包，u卡实体卡信封样式，预计达到时间

**地址填写，ai翻译为英文全大写**

1. street line:1，街道+门牌号【具体到房子的蓝牌号】+TEL（联系电话）【避免地址不具体和没有手机号派送不了／联系不到而退回】

2. street line:2，镇/区+县+市（有city栏可以不写）+省份

3. street line:3，P.R.CHINA

4. POSTAL CODE:具体到所在小区的邮编

5. CITY:市

```
- Street Line 1： NO. 102 LINGJIANG VILLAGE, TEL: 13800138000
- Street Line 2： TUOCHENG TOWN, LONGCHUAN COUNTY,GUANGDONG PROVINCE
- Street Line 3： P.R.CHINA
- CITY:HEYUAN
- Postal Code： 517388
```

## 重要不能出错，遗漏的

1. 邮路测试，一方面检查自己地址是否正确，另一方面是加上邮差微信，你不能保证对方是否负责任或者出现意外及时沟通

2. 手机号，十分重要，联系不到直接退回。

3. P.R.CHINA,十分重要，决定能否寄往中国

4. 邮编，十分重要，必须具体到所在小区/镇，寄往异地邮局就很糟糕，决定能否寄往居住地，所以第一步的测试很重要。

5. 地址一般具体到蓝牌号。有辨识度。

6. 标点符号英文半角逗号，拿不准，也可以不写。
