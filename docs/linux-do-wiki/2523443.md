# :fire:【大模型系列36.1】Fable5 vs Opus vs Sonnet5写作测试: 消耗速度是opus的5倍而不是API价格的2倍



### Max消耗速率

测试同样文章，让AI回答12个小标题

sonnet5max用了5x5h的8%，

opus4.8max用了30%，

fable5用了156%(就是一个5x5h不够，答案字数还更少)

fable xhigh消耗是opus4.8max的5倍，而不是按api价格的2倍

fable xhigh消耗是sonnet5max的20倍，而不是按api价格的5倍

这意味着7月7日后,如果按约定取消max使用fable的权限,按照api付费, 爽用fable的开销要到达每月$5000级别

### Sonnet5

但是sonnet5虽然便宜，回答质量很拉，不合逻辑

fable5质量最高，opus其次，都明显好于sonnet5

sonnet5编程可能不错，写作我感觉不行

### fable5搜索很积极

sonnet搜索13次，45个url
