# Skill / MCP 推荐



我有时候需要一些 AI 扩展能力的时候，发现让 AI 搓一个比较耗费时间和 token，网络上找半天又不知道哪个比较好用。



因此建立这个文档，欢迎大家在下面留下觉得好用的 Skill / MCP，我会基于实用性和评价更新进文档里面。废话少说，我先列一些我个人觉得还不错的 Skill / MCP。

> 2026-07-07 新增 “学术 / 科研” 大类以及补充若干工具推荐

>

> 2026-07-06 新增 “审美/去AI味” 和 “安全/防注入检测” 两大类以及补充若干工具推荐
