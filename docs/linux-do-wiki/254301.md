微软的 Microsoft Graph服务就 提供了一个统一的 API，可用于访问存储在 Microsoft 365 和其他服务中的数据和各种接口。
用户自己创建的应用（Application），会先通过 Microsoft Identity Platform 进行认证，认证通过后，才可以通过 Microsoft Graph 服务来获取 数据（Email,文件等等）。
