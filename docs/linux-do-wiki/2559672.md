首先，我先创建bond和bridge
```
#创建bond
nmcil c a type bond mode active-backup ifname bond1 con-name bond1 miimon 1000 antoconnect yes;
#将物理网卡绑定到bond
nmcil c a type bond-slave ifname eth0 con-name eth0 master bond1;
nmcil c a type bond-slave ifname eth1 con-name eth1 master bond1;
#创建bridge
nmcil c a type bridge ifname br0 con-name br0 ipv4.method auto autoconnect yes;
```
接下来怎么绑定我其实能想到的有三种写法
```

#第二种,他的type符合真的可以适配吗？

#第三种，如果改了type，他还是bond吗？
```
