# 解决fcitx5在Electron、vscode、obsidian中偶发按键直接上屏导致输入中文缺字漏字的问题



Wayland下，输入法就有一些奇怪的漏字现象。



具体表现为，输入一句汉字后，会有一些拼音的字母跳过输入法直接进入程序。形成类似于 `我说` => `我s活` 这样的奇怪句子。



[ArchWiki](https://fcitx-im.org/wiki/Using_Fcitx_5_on_Wayland#Chromium_.2F_Electron)，发现已经有现成的修复方案了。

如果是 Fcitx5+Wayland 的搭配，编辑Chrome、obsidian、vscode的 `.desktop` 文件，在命令后添加以下参数即可。 `--enable-features=UseOzonePlatform --ozone-platform=wayland --enable-wayland-ime`

这种方法对于一些仅`X11`的系统无效，会警告没有`--enable-*`的参数，可以添加如下参数**强制VSCode运行在XWayland下**，实测对我的系统无效（可能降低了一点概率？），我是用`flathub`安装的Fcitx5，因为apt自带的版本太老了……

```
--ozone-platform=x11
```

但是我找到了有效的方案，`apt`安装如下Fcitx5前端包：

```
apt install fcitx5-frontend-gtk2 fcitx5-frontend-gtk3 fcitx5-frontend-gtk4 fcitx5-frontend-qt5
```
