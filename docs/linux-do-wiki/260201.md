# powershell 初始化报错Microsoft.PowerShell_profile.ps1:11 解决办法

# 报错信息：
Import-Module: E:\OneDrive - n1ko\文档\PowerShell\Microsoft.PowerShell_profile.ps1:11
Line |
11 | Import-Module -Name Microsoft.WinGet.CommandNotFound
| ~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~
| Object reference not set to an instance of an object.
系统已安装相关模块， WinGet 版本正常
# 解决办法：
编辑Microsoft.PowerShell_profile.ps1 ，注释掉Import-Module -Name Microsoft.WinGet.CommandNotFound 这一行
