# Linux进程管理-学习笔记



进程是正在运行的程序实例

在Linux中，运行某个命令或者启动服务都会有一个进程

每一个进程在系统中都会分配一个唯一的PID号

当程序结束的时候，PID会被回收，PID是循环使用的

进程的权限来自于用户权限，继承自用户权限

在Linux中使用 `ps` 命令可以查看进程

## 静态进程

`ps` 查看静态进程

```
`PID`：进程ID号（PID
`TTY`：得到终端的方式（`pts`代表伪终端，远程模式或图形化伪终端；`tty`代表直连；`?`代表没有终端，为内核进程）
`TIME`：表示进程的持续时间
`CMD`：表示运行的命令（进程名）
```

`-a`查看所有终端运行的进程

`-x`可以查看不属于终端的进程，x是查看不属于终端的进程，内核进程等

`-o`指定选项，搭配 `-a`使用

`-u`查看进程详细信息，包括用户名，pid，占用信息等

`-e`查看所有进程

`-f`查看用户PID PPID cpu占用等

`--sort`指定排序参数

```
ps -aux --sort=%cpu #以cpu升序排序
ps -aux --sort=-%cpu #以cpu降序排序
ps -aux --sort=%cpu | tail #以cpu升序排序，展示末尾10行（展示占用最高的进程
```

常用的组合用法：

`ps -aux` 偏系统占用

`ps -ef`偏进程关系

### 孤儿进程和僵尸进程

孤儿进程：子进程在运行过程中，父进程因各种原因关闭。（会有PID为1的系统进程接管关闭）

僵尸进程：子进程在运行过程中，父进程因各种原因不回复子进程的消息，疯狂占用资源

### `pgrep`通过信息查询进程

`-U`通过用户名查询进行

`-G`通过用户组查询

`-u`通过用户的UID查询

`-g`通过GID查询

`-P`通过父进程查询子进程

`-l`打印命令

`-o`如果后台同时有多个相同的进程，查找最早运行的进程

```

```

`-n`如果后台同时有多个相同的进程，查找最后运行的进程

`-d`指定分隔符（shell常用

### `pidof`根据进程名进行查询

`pgrep` 模糊查询

`pidof` 精确查询

## 进程之间的通信方式

管道、**信号**、消息队列、共享内存、socket套接字等

Linux中默认使用信号进行通信

当进程接收到信号后，优先执行信号的操作

内核产生信号；用户手动产生的信号

`kill`命令是一个信号工具，他不只是能干掉进程，默认使用kill使用的是15号信号也就是干掉进程

`kill -l`可以列出所有信息

`kill -15 1510`向1510程序发送15号信号

`singnal 15` 默认，关闭程序

`singnal 9` 强制退出（会导致文件损坏

`singnal 1`重新加载配置文件

`killall [进程名]`会一并关闭所有同名的进程，例如vim

### pkill

可以结束一个终端、一个用户的所有进程

`pkill -kill -t tty/2` 踢掉一个用户

`pkill -9 -t tty/2` 踢掉一个用户

`pkill -t tty/2`结束一个终端的所有进程

`pkil -u [用户名]`结束一个用户的所有进程

`pkill -9 vim`强制结束进程

## 进程的优先级

在系统繁忙的时候，高优先级的进程优先分配cpu资源，优先级越高越优先分配cpu资源

Linux中有两种优先级：

- `PR`动态优先级（内核自动调整

- `NI`静态优先级（用户手动调整

`NI`静态优先级的范围：`-20~19`（数字越小，优先级越高）

**只有root用户可以调整NI静态优先级**

### `renice`命令

修改已经启动的进程的静态优先级

`renice -n [优先级] [PID]`

### `nice`命令

在启动时调整进程的静态优先级

`nice -n [优先级] [执行的命令]`

## 后台作业

将一个进程放入到后台执行，让前端终端能够输入命令，不被进程占用

**后台作业仅用于本终端，不可跨终端**

使用 `&`符号，即可放入后台执行

`ping baidu.com &`

`jobs` 查看当前终端运行的作业

`kill %[作业号]`结束作业

`Ctrl + z`将前台运行的作业放入后台并停止 或 `kill -19`这个我没理解

`bg %[作业号]`后台运行作业

`fg %[作业号]`前台运行作业
