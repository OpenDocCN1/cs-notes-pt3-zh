## 项目功能：
- 支持在线编辑、新建、上传和管理自定义模板，内置 Windows、Linux 国内、Linux 国外三套模板
- 支持同时添加多条机场订阅，自动生成 proxy-providers 和对应策略组
- 支持 URI、proxies: YAML、裸 YAML 节点列表导入
- 支持 URI ↔ YAML 节点双向转换
- 支持批量改写节点地址、IP 和备注
