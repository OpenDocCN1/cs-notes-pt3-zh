# 人体工学椅交流贴，和各位老讨论一下有什么性价比比较高的人体工学椅



想和各位佬讨论一下关于人体工学椅相关的一些内容，然后共建一个文档来给，避雷也好，或者推荐也好一下人体工学椅

本人现在买了两种人体工学椅，都是enova家的，一个是合金大师的S版本二代，一个是智慧家Pro的一代。个人感觉合金大师S版本的二代坐起来比智慧家Pro版本的一代舒服很多。但是呢，S版本二代的扶手框量很大，会前后有一部分运动，然后旋转的地方框量很大，无法准确的锁定。

智慧家Pro的一代呢，就是后背分体腰靠的部分，上面容易硌腰，网布弹性有点怪怪的，上面很软，然后往后一靠就会硌到后面的塑料，合金大师S版本二代就没有这个问题。

考虑到600块钱的价位，可能会有比智慧家Pro更好的人体工学椅，所以想和大家一起交流，看一下有没有更好的人体工学椅，性价比更高的，来给各位佬们一些推荐和避雷
