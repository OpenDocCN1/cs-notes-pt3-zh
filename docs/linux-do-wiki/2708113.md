# 【科普贴】收集佬站常用的黑话（术语、名词）



进站也快两个月了。社区的帖子量是越来越多，各种专业词汇（黑话）层出不穷。对于刚入门或者还在门槛外的小白来说。有些帖子看的是云里雾里。所以在此列出一些我这段时间自己理解掌握的一些黑话词汇，希望能帮助和我一样相同层次的小白。如果有理解的不对的地方，也希望其它佬友给予指正。缺失的常用词汇，也欢迎大家一起补充。

首先是 本站的黑话： L站、佬站



然后是 始皇  创始人  下面这个账号

![image932×592 84.9 KB](https://cdn3.ldstatic.com/original/4X/3/6/d/36d39b258969a077f36a8b023712c93f57344c89.png)

以下



X佬、某某佬        这个应该是特定的老成员。比如鸭佬、哈雷佬



隔壁站           左侧列表的IDC Flare



CPA             CLIProxyAPI  一个可以聚合API的开源代理工具



CC              Claude code



CCS             cc-switch可以配置多渠道账号代理给codex或Claude code使用的开源软件，支持一键切换账号和模型



A÷、A/、A畜       统一指Anthropic（没找到那个表情包）。



直卡              直接绑定银行卡进行订阅激活的账号（通常是指0元购的卡，感觉和直充有点混乱）



直充、官充         通过官方渠道进行正常支付，订阅激活的账号



0刀、零刀          零美元、但是在公益站的换算，好像，1刀都是等于1RMB，不知道为什么。



手搓              不依赖自动脚本和注册机，采用人工操作的方式完成相应步骤。



拉闸              通常指某个薅羊毛的渠道挂了



蹬，猛蹬           指快速消耗Token



公益站            可以通过社区积分购买权益的站点。新来的同学一定要先到（[积分站](https://credit.linux.do/)）激活账号，开始不知道，感觉亏了好多积分。



反代              将官方订阅账号通过代理工具代理给其它客户端使用



sub2             Sub2API 订阅中转与账号分发管理平台 区别于CPA多了用户额度管理和资源分发功能。



瓦工              BandwagonHost 加拿大的一家VPS（虚拟服务器）的厂商，类似阿里云、腾讯云



机场、节点         这个不说了，能进佬站的肯定都懂



破限、越狱         指绕过大模型的限制



哈基咪、美国豆包    gemini模型



大善人            谷歌



御三家            OpenAI、Google、Anthropic



反重力            Antigravity 谷歌的vibe coding工具



焚诀              指好用的教程
