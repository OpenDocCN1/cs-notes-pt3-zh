# 分享在帖子中使用删除文字符号的方法

在帖子中使用删除文字的符号，可以方便地展示你的修改或想法。只需在需要删除的文字前后加上以下符号：
```
~~
```
或者用以下的形式来呈现内容
```
[s]内容[/s]
```
