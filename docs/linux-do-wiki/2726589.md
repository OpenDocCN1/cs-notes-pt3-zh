# 记一次手动为Pixel 8a将LineageOS更新到高版本



> 这只是我根据我这次刷机写的一次记录，你可以在这里看看真实操作可能会遇到的坑（不过这些坑官方的文档里好像也都写过了），但不能完全当教程。详细教程见官方页面：

>

> [Info about akita | LineageOS Wiki](https://wiki.lineageos.org/devices/akita/)

上次给Pixel 8a刷入LineageOS22时，启动了GMS但没有刷入Play Store。这次更新到23版本，打算把Gapps也都装上，并且使用APatch获取Root权限。

本次操作用到的硬件设备：

- 一台搭载ArchLinux的笔记本（理论上只要是台能安装adb和fastboot的设备就行）

- 一根接触良好的数据线

- 一台已解锁的且刷入了LineageOS官方Recovery的Pixel 8a

- 一台运行了代理软件的软路由

- 时间充足的白天，最好是早上，反正不要在晚上刷机

官方的[安装教程](https://wiki.lineageos.org/devices/akita/install/#basic-requirements)中提示在从新安装LineageOS时需要删除已登录的Google账户以避免“Factory reset protection”，虽然在手动更新教程中没有提到这一点，但保险期间，我在操作前也删除了所有的Google账户。由于我是个新手，为了保证万无一失，虽然文档中没有提及e-sim会对刷机造成的影响，但我仍把设备上已有的e-sim也删除了。

根据[官方文档](https://wiki.lineageos.org/devices/akita/upgrade/#manually-upgrading-lineageos)，想要再额外刷入Gapps必须把设备恢复到「没有用户修改」的状态，即清除所有用户数据。

开启USB调试，并始终允许你连接的这台电脑对设备的调试。使用`adb devices`测试能否对设备进行操作，也可以试试`adb reboot`这些命令来看看能否正常操控设备。

使用`adb reboot recovery`进入recovery，之后用音量键和电源键选择`Factory reset > Format data/factory reset`，等待进度跑完。

使用音量键和电源键返回到首页，再选择`Apply update > Apply from ADB`，之后使用电脑运行`adb -d sideload /path/to/zip`，请将`/path/to/zip`改为LineageOS官方包在你电脑中的实际路径。

> 通常，adb 报告 `Total xfer: 1.00x`，但在某些情况下，即使该过程成功，输出也可能停止在 47%，并显示 `adb: failed to read command: Success`。

可能你的手机上已经如下图所示了：

> [20250802_141951_proc4592×8160 621 KB](https://cdn3.ldstatic.com/original/4X/c/2/2/c22b4d19f3a44b3b3a917da3a8db29e70be12925.avif)

但是电脑上终端的输出依旧停留在

```
serving: 'lineage-23.2-20260805-nightly-akita-signed.zip'  (~47%)
```

这时候直接在手机上选择yes/no即可，之后电脑上的终端可能返回

```
adb: failed to read command: Success
```

由于我还要安装Gapps，故选择了yes。之后和上面一样，选择`Apply update > Apply from ADB`，执行`adb -d sideload /path/to/zip`，但此处应将`/path/to/zip`换成Gapps的包在你电脑上的实际路径。

> 附加组件未使用LineageOS的官方密钥签名，因此当它们被sideload时，Lineage Recovery会显示`Signature verfication failed Install anyway`，这是预期的，请点击 `yes`。

>

> 跑完之后，用音量键和电源键选择`Reboot system now`即可。

对于我，这次手动升级很顺利，成功进入系统了，接下来的操作就简单了，先在登录任何账号前装个Dhizuku，用APatch获取Root权限就好了。不过，开发者模式、USB调试等都需要重新开启。

后面分享下获取Root的经验，详细教程可见：

### [APatch Docs](https://apatch.dev)

A kernel-based root solution for Android devices.

在连接了手机的电脑的终端上输入`adb shell`，然后输入`zcat /proc/config.gz | grep CONFIG_KALLSYMS`



若返回内容中包含

```
CONFIG_KALLSYMS=y
CONFIG_KALLSYMS_ALL=y
```

则你的设备的内核是支持修补。



通过F-Droid或其他渠道安装APatch，由于LineageOS提供了每个构建版本的boot.img，可以直接去官网将对应版本的文件下载下来，在APatch主页中点击右上角的![](img/844edb8a039776d9a5a26ab8d7fcfda1.png)按钮，设定密钥进行修补，之后修补下载号的boot.img即可，注意应用内返回的内容，把修补好的boot.img传到电脑上。之后执行`adb reboot bootloader`，然后执行`fastboot flash boot PATH/TO/boot.img`，这里把`PATH/TO/boot.img`换成修补后的镜像在你电脑上的实际路径。等跑完后使用`fastboot reboot`重启设备。之后再去APatch里输入密钥就好了。
