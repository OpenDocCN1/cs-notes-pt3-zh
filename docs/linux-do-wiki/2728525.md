# 通过FNOS的热点成功激活CTExcel的过程(8月9日)



一、前景概要



因为windows电脑没有无线网卡，不想为了这个买个无线网卡，想起之前联想yogo14s刷了FNOS系统，问了Claude能否用FNOS的无线网卡实现通过UK节点拉起WIFI CALLING得到肯定回复且比WINDOWS更简单，就有了以下过程记录。

二、激活用到的工具

1. 笔记本带无线网卡的FNOS系统

2. 一个支持udp转发的英国节点

3. 一加 Ace 6T

4. 一张 ESTKme C (Beta)

三、过程步骤

1.让Claude参考之前论坛，Windows UK节点转发UDP的热点过程 [CTExcel 成功激活流程 - 文档共建 / 文档共建, Lv1 - LINUX DO](https://linux.do/t/topic/2718621/1)

今晚 **ESTKme** 到货后又重新检查一下，发现这个主要问题，让Claude修复

2.昨天提前下载好 **ESTKme** 应用

3.购买Ctexcel回国套餐 **五折优惠码失效** 只能用9折码 **心痛的捶胸口**

![a532a386e8fa384c4b43ccef805bc20a1101×1379 205 KB](https://cdn3.ldstatic.com/original/4X/0/b/c/0bc7a167f3aa5cb535a508baa8c1ae2d63b0ee5d.png)

4.收到Ctexcel的esim激活码邮件，截图保存到手机

![image1124×1210 205 KB](https://cdn3.ldstatic.com/original/4X/b/0/a/b0a5ff085aa0f15cc58d5db379ec6739c648b7b5.png)

5.将手机所有卡拔下来 **关闭定位** 连接 fnos-uk wifi 打开[http://ipleak.net](http://ipleak.net)、[https://cleanip.io](https://cleanip.io) 确认UK节点正常

6.手机 关机-开机 连接 fnos-uk wifi  **打开飞行模式** 打开[http://ipleak.net](http://ipleak.net)、[https://cleanip.io](https://cleanip.io) 确认UK节点正常, 插入 **ESTKme** sim2卡槽， 打开**ESTKme**软件 sim2 录入 Ctexcel的esim激活码截图 esim录入成功

7.手机 关机-开机 连接 fnos-uk wifi  **打开飞行模式** sim2卡的 **打开wifi通话** 等待wifi calling图标拉起

![5e585a0728f2cc4f31e85392980dba111272×2800 220 KB](https://cdn3.ldstatic.com/original/4X/0/1/3/0133014a68b5b7cf9726f29d5f6e89e769b1b8d6.jpeg)

8.发送 BAL 短信到 888 收到短信回复等待10分钟激活成功，以及激活邮件

![image869×1910 110 KB](https://cdn3.ldstatic.com/original/4X/b/9/7/b97f6d98aaebc7545c7f4d159ba13d518772622a.jpeg)

![400ac7fb348353964ab869a8bd0feffb591×411 5.69 KB](https://cdn3.ldstatic.com/original/4X/5/3/7/537746f072a8b5ab3df270d9c45ff87039a3a138.png)

9.Ctexcel公众号绑定号码，Ctexcel网站重置密码登录成功

![8aa9aa5dc9ba74047daf7cc31aa698a91272×2800 148 KB](https://cdn3.ldstatic.com/original/4X/1/0/7/1074c8ed39f6092b51dfe15b63d2b2858d9c5054.jpeg)

![b1ca09330603df286447d460b63729561836×474 110 KB](https://cdn3.ldstatic.com/original/4X/1/8/6/1868849191db737e27bdcc0549005ab503b8897d.png)
