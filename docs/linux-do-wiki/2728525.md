# 通过FNOS的热点成功激活CTExcel的过程(8月9日)



一、前景概要



因为windows电脑没有无线网卡，不想为了这个买个无线网卡，想起之前联想yogo14s刷了FNOS系统，问了Claude能否用FNOS的无线网卡实现通过UK节点拉起WIFI CALLING得到肯定回复且比WINDOWS更简单，就有了以下过程记录。

二、激活用到的工具

1. 笔记本带无线网卡的FNOS系统

2. 一个支持udp转发的英国节点

3. 一加 Ace 6T

4. 一张 ESTKme C (Beta)

三、过程步骤

1.让Claude参考之前论坛，Windows UK节点转发UDP的热点过程 [CTExcel 成功激活流程 - 文档共建 / 文档共建, Lv1 - LINUX DO](https://linux.do/t/topic/2718621/1)

![9a6f16cad5486f6d78d650585a07c8781163×1252 285 KB](img/c3664aa41abbaa8c31143787610734f3.png)

2.昨天提前下载好 **ESTKme** 应用

3.购买Ctexcel回国套餐 **五折优惠码失效** 只能用9折码 **心痛的捶胸口**

![a532a386e8fa384c4b43ccef805bc20a1101×1379 205 KB](img/17ef10bcef183224cd7d6cdef1f8ce81.png)

4.收到Ctexcel的esim激活码邮件，截图保存到手机

![image1124×1210 205 KB](img/3eb5ec8fae54e0cb0278dfeadd02c728.png)

5.将手机所有卡拔下来 **关闭定位** 连接 fnos-uk wifi 打开[http://ipleak.net](http://ipleak.net)、[https://cleanip.io](https://cleanip.io) 确认UK节点正常

6.手机 关机-开机 连接 fnos-uk wifi  **打开飞行模式** 打开[http://ipleak.net](http://ipleak.net)、[https://cleanip.io](https://cleanip.io) 确认UK节点正常, 插入 **ESTKme** sim2卡槽， 打开**ESTKme**软件 sim2 录入 Ctexcel的esim激活码截图 esim录入成功

7.手机 关机-开机 连接 fnos-uk wifi  **打开飞行模式** sim2卡的 **打开wifi通话** 等待wifi calling图标拉起

![5e585a0728f2cc4f31e85392980dba111272×2800 220 KB](img/52b7d128572baea9d5383778150e582b.png)

8.发送 BAL 短信到 888 收到短信回复等待10分钟激活成功，以及激活邮件

![image869×1910 110 KB](img/e1a0e5e2183d0b006bd68554848ef03a.png)

![400ac7fb348353964ab869a8bd0feffb591×411 5.69 KB](img/b1b14fe042c331f6ca1c7f43864c06e7.png)

9.Ctexcel公众号绑定号码，Ctexcel网站重置密码登录成功

![8aa9aa5dc9ba74047daf7cc31aa698a91272×2800 148 KB](img/d17cddec3b1d40b2dccf3eb67c1ee40a.png)

![b1ca09330603df286447d460b63729561836×474 110 KB](img/51f377cb8ba7d80bf545d04e6f00425b.png)

至此完成激活CTExcel的整个过程，等过两天就将GG卡携号转网过来！
