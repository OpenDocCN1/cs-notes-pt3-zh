# LINUX DO 发帖指南 V2.0

前情提要：
[【新人向】LINUX DO 论坛发帖指南](https://linux.do/t/topic/971800/) [

文档共建](/c/wiki/42)
> 为什么会有这条帖子
> 最近几天（其实是暑假的时候开始编辑）经常看到有新人发帖子，但是格式一团糟，能逼死强迫症的那种 ![bili_001](https://cdn3.ldstatic.com/original/3X/4/7/47438f4f7b27b13d4ec57b37ec7b7dcf5217de69.png?v=15)
> 所以做这么一条帖子教那些新人们怎么用 Markdown、BBCode、HTML（少量）发帖
> Markdown、BBCode、HTML 是什么？
> （按照发布顺序介绍）
> HTML （英语全称：HyperText Markup Language，超文本标记语言），…
格式什么的，还是能通用
针对最近出现的一些“情况”说一下：
1. 论坛内严禁任何形式的自动回复，用 Agent 的小心封号大礼包
2. 非必要不抽奖，抽奖前一定确认自己是否用得到，不要为了抽奖而抽奖（参与抽奖的帖子回复内容需要是说明你为何需要该福利之类的，与主贴存在明确相关性的有意义内容）
3. 回帖前一定，一定要读完整个帖子
4. *如果你怀疑某些用户是人机把这个链接丢过去：pow.linux.do*
5. 不喜欢这个论坛的你随时可以出去，以及有什么公益站相关的事请亲自跟站长私信，不要跟别人公开争论大半天
6. 不要转发一些有争议的新闻，或者说一些让社区乌烟瘴气的话（比如引流其它社区，等等）
7. 不要把高等级的帖子往低等级搬来给自己引流
Wiki 帖子可以自由编辑，如果你认为有什么缺漏可以自行来补上，不要乱改就好
