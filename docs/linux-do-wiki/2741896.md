# Java开发教程6-继承与方法重写



本期是Java开发教程系列的第六期,本期主要向各位介绍**继承**: 让一个类复用另一个类,并引出**方法重写**.若你已经熟悉 `extends`、`@Override`、`super`,可以跳过本期内容.

**一、为什么需要继承**

第 5 期我们把 `Student` 封装好了.现在又要写一个 `Teacher`,发现字段和方法有一大半和 `Student` 重复:名字、年龄、说话……如果把两类的公共部分抽出来,让 `Student` 和 `Teacher` 都**继承**它,就不用写两遍了.

**继承**（extends）的意义:

1. **代码复用**:子类自动拥有父类的字段和方法 (代码复用是好文明)

2. **扩展**:子类可以在父类基础上加新的字段和方法

3. **统一**:多个子类可以当作父类来用（这是下一期"多态"的基础）

---

**二、extends 继承**

```
public class Person {

    public String name;

    public void sayHello() {

        System.out.println("你好,我是 " + name);

    }

}
```

```
public class Student extends Person {

    public double score;   // 子类自己新增的字段

}
```

现在 `Student` 对象同时拥有 `name`（来自 `Person`）和 `score`（自己加的）,还能直接调 `sayHello()`:

```
Student s = new Student();

s.name = "小明";        // 父类的字段

s.score = 92;           // 自己的字段

s.sayHello();           // 父类的方法
```

- 被继承的类叫**父类**（超类/基类）,继承的类叫**子类**

- 子类是父类的一种:“学生是一个人”,所以 `Student extends Person` 顺理成章

- Java 一个类**只能继承一个父类**（单继承）,但可以层层继承:孙子继承儿子,儿子继承爷爷

---

**三、方法重写:@Override**

父类的方法写死了,子类想改个说法,怎么办?在子类里重新写一个**同名同参数**的方法,叫**重写**:

```
public class Student extends Person {

    public double score;

    @Override

    public void sayHello() {

        System.out.println("你好,我是学生 " + name);

    }

}
```

现在 `student.sayHello()` 会打印"你好,我是学生 小明",而不是父类的版本.

- 重写的方法签名（名字 + 参数列表）必须和父类**完全一样**

- `@Override` 是一个**注解**,写在方法上面,作用是告诉编译器"我这是在重写父类方法"——如果写错了方法名或参数,编译器会报错提醒,而不是默默给你新写一个方法

- 重写时的访问级别不能比父类更封闭（父类是 `public`,子类不能改成 `private`）——通常保持一致就行

**四、super:调用父类**

子类方法里想用父类的版本,用 `super`:

```
public class Student extends Person {

    public double score;

    @Override

    public void sayHello() {

        super.sayHello();              // 先调父类的 sayHello

        System.out.println("我是一名学生");   // 再补自己的话

    }

}
```

`super` 也可以调父类的**构造方法**,但必须写在构造方法**第一行**:

```
public class Person {

    public String name;

    public Person(String name) {     // 父类也加一个带参构造

        this.name = name;

    }

    public void sayHello() {

        System.out.println("你好,我是 " + name);

    }

}
```

```
public class Student extends Person {

    public double score;

    public Student(String name, double score) {

        super(name);        // 调父类 Person 的构造方法,必须在第一行

        this.score = score;

    }

}
```

如果父类有一个无参构造,子类构造里不写 `super(...)` 也能隐式调用;但父类只有有参构造时,子类必须显式 `super(...)` 传参,否则编译报错.

**六、小项目:形状的面积**

做一个形状继承体系:基类 `Shape`,两个子类 `Circle` 和 `Rectangle`,各自重写 `area()` 和 `describe()`.

文件一 `Shape.java`:

```
public class Shape {

    public double area() {

        return 0;

    }

    public void describe() {

        System.out.println("一个形状");

    }

}
```

文件二 `Circle.java`:

```
public class Circle extends Shape {

    public double radius;

    public Circle(double radius) {

        this.radius = radius;

    }

    @Override

    public double area() {

        return 3.1415926 * radius * radius;

    }

    @Override

    public void describe() {

        System.out.println("半径为 " + radius + " 的圆");

    }

}
```

文件三 `Rectangle.java`:

```
public class Rectangle extends Shape {

    public double width;

    public double height;

    public Rectangle(double width, double height) {

        this.width = width;

        this.height = height;

    }

    @Override

    public double area() {

        return width * height;

    }

    @Override

    public void describe() {

        System.out.println("宽 " + width + " 高 " + height + " 的长方形");

    }

}
```

文件四 `Main.java`:

```
public class Main {

    public static void main(String[] args) {

        Circle c = new Circle(5);

        Rectangle r = new Rectangle(3, 4);

        System.out.println("圆:面积 " + c.area());

        System.out.println("长方形:面积 " + r.area());

        c.describe();

        r.describe();

    }

}
```

运行结果:

```
圆:面积 78.539815

长方形:面积 12.0

半径为 5.0 的圆

宽 3.0 高 4.0 的长方形
```

三个类都写了 `area()` 和 `describe()`,但各自实现不同——这就是重写.`Circle` 和 `Rectangle` 继承自 `Shape`,只写了各自特有的几行,重复的"是形状"这个底子不用重来.

**朝花夕拾:重载再见面**

第 1 期我们学过方法重载:同一个类里,两个 `add`,参数个数不同,调用时自动匹配:

```
public static int add(int a, int b) {

    return a + b;

}

public static int add(int a, int b, int c) {

    return a + b + c;

}
```

今天又学了重写.两个词长得很像,区别在"**同类的兄弟** vs **父子之间**":重载是"同一类里同名不同参",重写是"子类覆盖父类的同名方法".本期第五节"重载 vs 重写"的对照表,建议多看几遍.

**总结**

本期学习了继承的基础:

- **extends 继承**:子类自动拥有父类的字段和方法,Java 是单继承

- **方法重写**:子类用 `@Override` 重写父类方法,签名要完全一致

- **super**:调用父类的方法;调父类构造时必须写在第一行

- **重载 vs 重写**:一个在同类里换参数,一个在父子间覆盖实现

下一期我们学习**接口、抽象类与多态**——把继承从"父子"扩展到"契约",让代码写得更灵活.
