# Java开发教程7-接口、抽象类和多态

本期是Java开发教程系列的第七期,本期主要向各位介绍**接口**、**抽象类**和**多态**——面向对象最灵活的部分.若你已经熟悉 `interface`/`abstract`/多态,可以跳过本期内容.

**一、抽象方法与抽象类**
第 6 期我们的 `Shape` 基类,`area()` 只能返回 0——因为"形状"太抽象,没法算出面积.这种"只声明、不实现"的方法叫**抽象方法**:
```
public abstract class Shape {
    public abstract double area();   // 只有声明,没有方法体

    public void describe() {         // 普通方法可以有实现
        System.out.println("一个形状");
    }
}
```
- `abstract` 修饰的方法只有声明,没有 `{}` 方法体,以分号结尾
- 有抽象方法的类必须是抽象类（`abstract class`）,不能 `new`——你不能"造一个形状对象",只能造具体子类
- **子类必须实现所有抽象方法**,否则子类自己也得是抽象类
- 抽象类可以有普通方法、字段、构造方法——它只是"不能被 new + 强制子类实现某些方法"
---
**二、接口:一份契约**
**接口**（interface）比抽象类更"纯粹":它只规定"能干什么",完全不规定"怎么干".接口里的方法默认都是 public 的抽象方法（简写省略 `public abstract`）:
```
public interface Flyable {
    void fly();       // 等价于 public abstract void fly();
}
```
> 小知点:Java 8 以后接口里还允许写带方法体的 `default`、`static` 方法（Java 9 起 `private`）,先留个印象,本系列用到时再讲.现在只要记住"接口里的普通方法默认是抽象的"就行.
```
public class Bird implements Flyable {
    @Override
    public void fly() {
        System.out.println("拍翅膀飞");
    }
}

public class Plane implements Flyable {
    @Override
    public void fly() {
        System.out.println("喷气起飞");
    }
}
```
- 用 `implements` 实现接口
- **一个类只能继承一个父类,但可以实现多个接口**——这是接口存在的最大意义:
```
// 假设我们已经定义了另一个接口 Singable
public interface Singable {
    void sing();
}

public class Bird implements Flyable, Singable {
    @Override
    public void fly() { System.out.println("拍翅膀飞"); }

    @Override
    public void sing() { System.out.println("叽叽喳喳"); }
}
```
- 接口的典型比喻是"**合同/契约**":你只要实现 `fly()`,任何代码都能把你当"会飞的东西"用
---
**三、接口 vs 抽象类**
|  | 抽象类 | 接口 |
| --- | --- | --- |
| 关键字 | `abstract class` | `interface` |
| 能不能 new | 不能 | 不能 |
| 方法 | 可以有普通实现 + 抽象方法 | 默认都是抽象方法 |
| 一个类 | 只能继承一个 | 可以实现多个 |
| 侧重 | “是什么”（is-a） | “能干什么”（契约） |
判断建议:能描述成"is-a 关系"用抽象类;"会做某件事"用接口.

**四、多态:一个引用,多种形态**
多态这个词听起来玄,其实就是一句话:**父类/接口的引用,可以指向子类/实现类的对象**:
```
Shape s = new Circle(5);        // 父类引用指向子类对象
Flyable f = new Bird();         // 接口引用指向实现类对象

System.out.println(s.area());   // 调用的是 Circle 的实现
f.fly();                        // 调用的是 Bird 的实现
```
调用方法时,真正执行的是**对象实际类型**的实现——这就是"同一个引用,表现出不同的行为".
多态最大的好处是**面向接口编程**:写代码时只依赖接口,不依赖具体类,将来换实现不用改调用方.
```
public class Zoo {
    // 只要是 Flyable,都能传进来,不管它是什么
    public void letItFly(Flyable thing) {
        thing.fly();
    }
}

Zoo zoo = new Zoo();
zoo.letItFly(new Bird());    // 拍翅膀飞
zoo.letItFly(new Plane());   // 喷气起飞
```
想加一种新的"会飞的东西"?写个新类实现 `Flyable` 就行,`Zoo` 一行都不用改.

**五、小项目:支付系统**
用接口做一个小支付系统:一个 `Payable` 接口,三个实现类,统一通过接口调用.
文件一 `Payable.java`:
```
public interface Payable {
    void pay(double amount);
}
```
文件二 `WechatPay.java`:
```
public class WechatPay implements Payable {
    private String account;

    public WechatPay(String account) {
        this.account = account;
    }

    @Override
    public void pay(double amount) {
        System.out.println("微信 " + account + " 支付 " + amount + " 元");
    }
}
```
文件三 `Alipay.java`:
```
public class Alipay implements Payable {
    private String account;

    public Alipay(String account) {
        this.account = account;
    }

    @Override
    public void pay(double amount) {
        System.out.println("支付宝 " + account + " 支付 " + amount + " 元");
    }
}
```
文件四 `BankCard.java`:
```
public class BankCard implements Payable {
    private String cardNo;

    public BankCard(String cardNo) {
        this.cardNo = cardNo;
    }

    @Override
    public void pay(double amount) {
        System.out.println("银行卡 " + cardNo + " 支付 " + amount + " 元");
    }
}
```
文件五 `Main.java`:
```
public class Main {
    public static void main(String[] args) {
        // 把三个实现类都当作 Payable 用
        Payable[] payList = new Payable[]{
                new WechatPay("13800000000"),
                new Alipay("abc@example.com"),
                new BankCard("6222 0000 1234 5678")
        };

        for (Payable p : payList) {
            p.pay(88);
        }
    }
}
```
运行结果:
```
微信 13800000000 支付 88.0 元
支付宝 abc@example.com 支付 88.0 元
银行卡 6222 0000 1234 5678 支付 88.0 元
```
重点看 `Main`:数组的类型是 `Payable[]`,循环里是 `Payable p`——全程只跟接口打交道,具体是哪个实现,数组里塞了才知道.这就是面向接口编程.

**朝花夕拾:原来第 1 期就用过多态**
第 1 期我们用 `List` 存东西:
```
import java.util.ArrayList;
import java.util.List;

List<String> items = new ArrayList<>();
```
现在你知道了:`List` 是一个**接口**,`ArrayList` 是实现它的类.`List<String> items = new ArrayList<>();` 正是"接口引用指向实现类对象"——多态.所以将来换成 `LinkedList` 实现,`items` 的用法一行都不用改.你从第 1 期起,就一直在用多态写代码.
---
**总结**
本期完成了面向对象最灵活的一块:
- **抽象类**:不能被 new,强制子类实现抽象方法;可以有普通方法
- **接口**:一份纯契约,一个类可以实现多个接口
- **多态**:父类/接口引用指向子类/实现类对象,调用执行的是实际类型的方法
- **面向接口编程**:只依赖接口,换实现不改调用方
