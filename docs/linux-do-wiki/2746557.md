# Java开发教程9-常用类与字符串

本期是Java开发教程系列的第九期,本期主要向各位介绍几个天天用的 JDK 类——**String**、**包装类**、**Math** 和 **Random**,以及控制循环的 `break`/`continue`.若你已经熟悉这些,可以跳过本期内容.

**一、String 不可变**
`String` 对象一旦创建,内容就**不能改**.看起来能"改"的操作,其实都是创建了新的字符串:
```
String s = "java";
s = s + "教程";   // 不是改了 s,而是造了一个新字符串 "java教程",再让 s 指向它
```
这带来一个性能陷阱——**在循环里拼接字符串**:
```
String result = "";
for (int i = 0; i < 10000; i++) {
    result = result + "a";   // 每循环一次都造一个新字符串,旧的丢给垃圾回收
}
```
循环 10000 次,`+` 在循环体内会被处理成"新建一个 StringBuilder、拼完再 toString",相当于每次都造新对象.虽然现代编译器对**单条语句里多层 +** 会自动合并成一个 StringBuilder,但**循环里的 result = result + ...** 优化不了,数据一大就明显变慢.
---
**二、StringBuilder**
要频繁拼接,用 `StringBuilder`——它是**可变的**,能原地追加:
```
StringBuilder sb = new StringBuilder();
for (int i = 0; i < 10000; i++) {
    sb.append("a");   // 原地追加,不造新对象
}
String result = sb.toString();   // 最后转成 String
```
- `append(...)` 把内容追加到末尾,可以连续调用:`sb.append("a").append("b").append(1);`
- 拼接次数少（几处 `+`）用普通字符串没问题;次数多（循环里）就用 `StringBuilder`
- 比较两个字符串**内容**用 `equals`,不是 `==`:
```
String a = "abc";
String b = new String("abc");
System.out.println(a.equals(b));  // true,内容相同
System.out.println(a == b);       // false,是两个不同对象
```
**String 的常用方法**,写代码天天碰到:
```
String s = " hello world ";

s.length();            // 13,字符个数(含空格)
s.trim();              // "hello world",去掉首尾空格(注意:返回新字符串,原 s 不变)
s.contains("world");   // true,是否包含子串
s.startsWith("he");    // true,是否以...开头
s.indexOf("o");        // 4,子串第一次出现的位置,找不到返回 -1
s.substring(1, 6);     // "hello",截取 [1,6) 的子串(左闭右开)
s.replace("l", "L");   // "heLLo worLd",替换所有匹配
s.split(",");          // 按逗号切成字符串数组(参数是正则表达式,第 11 期会细说)
```
> 重点记一条:**String 不可变,所以这些方法全都返回"改好的新字符串",原字符串不变**——`s.trim()` 不写 `s = s.trim()` 等于没改.这是新手最容易忘的一课.
**StringBuilder 的孪生兄弟:StringBuffer**
上面说 String 的方法"全都返回新字符串",`StringBuffer` 正好相反——它是**真正的原地修改**.它和 `StringBuilder` 的 API 完全一样,用法照搬,区别只有一条:`StringBuffer`

的每个方法都加了 `synchronized` 锁,**线程安全,但更慢**.所以平时用 `StringBuilder` 就够了;只有多个线程要同时改同一个缓冲时,才换成 `StringBuffer`(第 18 期讲多线程

时再回来看这句话).
它俩的内部结构也完全一样:
- 直接父类都是 `AbstractStringBuilder`
- 都实现了 `Serializable`,对象可以串行化(保存到文件、网络传输)
- 父类 `AbstractStringBuilder` 里有个 `char[] value`(JDK 8;JDK 9 起改成 `byte[]`),**不是 final 的**,内容可以原地改——这就是它比 `String` 拼接效率高的根本原因;而

`String` 的 `value` 是 `private final char[]`,改不了
- `StringBuffer` 和 `StringBuilder` 都是 `final` 类,不能被继承
初始化,三种方式:
```
StringBuffer sb1 = new StringBuffer();           // 默认容量 16 个字符
StringBuffer sb2 = new StringBuffer(100);        // 指定容量 100
StringBuffer sb3 = new StringBuffer("hello");    // 容量 = 字符串长度 + 16 = 21
```
注意**容量和长度是两回事**:`sb3.length()` 是内容长度 5,`sb3.capacity()` 才是容量 21.容量不够时会自动扩容,不用手动管.
和 `String` 互相转换:
```
// String -> StringBuffer
String str = "hello";
StringBuffer sb4 = new StringBuffer(str);               // 方式1:构造器
StringBuffer sb5 = new StringBuffer().append(str);      // 方式2:append

// StringBuffer -> String
String str2 = sb5.toString();                           // 方式1:toString
String str3 = new String(sb5);                          // 方式2:构造器
```
常用方法,和 `StringBuilder` 一一对应——增删改查插:
```
sb.append("a");         // 增:追加到末尾
sb.delete(1, 3);        // 删:删掉 [1,3),不含 3
sb.replace(1, 3, "xy"); // 改:把 [1,3) 替换成 "xy"
sb.indexOf("a");        // 查:第一次出现的位置,找不到返回 -1
sb.insert(2, "b");      // 插:在位置 2 插入
sb.length();            // 长度:当前内容有几个字符
```

**三、包装类与自动装箱**
基本类型（`int`、`double`…）不是对象,很多场合（比如放进集合）要对象.每个基本类型都有对应的**包装类**:
| 基本类型 | 包装类 |
| --- | --- |
| `int` | `Integer` |
| `long` | `Long` |
| `double` | `Double` |
| `float` | `Float` |
| `boolean` | `Boolean` |
| `char` | `Character` |
| `byte` | `Byte` |
| `short` | `Short` |
规律:**基本类型名首字母大写**就是包装类名,只有 `int→Integer` 和 `char→Character` 是"全名变了",这两个单独记.
Java 会自动在两者之间转换,叫**自动装箱/拆箱**:
```
Integer n = 5;        // int → Integer,自动装箱
int m = n;            // Integer → int,自动拆箱
```
`List<Integer>` 就靠自动装箱,`list.add(5)` 不用手动包一层.
包装类常用的静态方法——**字符串转数字**:
```
int num = Integer.parseInt("123");        // 123
double d = Double.parseDouble("3.14");    // 3.14
```
转不了就抛 `NumberFormatException`.

**四、Math**
`Math` 全是静态方法,直接类名调:
```
Math.abs(-5);     // 5,绝对值
Math.max(3, 7);   // 7,取大
Math.min(3, 7);   // 3,取小
Math.sqrt(16);    // 4.0,平方根
Math.pow(2, 10);  // 1024.0,2 的 10 次方
Math.round(3.6);  // 4,四舍五入
Math.random();    // [0,1) 的随机小数
```
---
**五、Random:真随机数**
`Math.random()` 能凑合,要更灵活用 `Random`:
```
import java.util.Random;

Random rand = new Random();

int dice = rand.nextInt(6) + 1;   // 1 到 6,模拟掷骰子
rand.nextInt(100);                // 0 到 99
rand.nextDouble();                // [0,1) 小数
```
`nextInt(n)` 生成 0 到 n-1,想得到 1 到 n 就 `+1`.

**六、补充:break 和 continue**
写循环时经常要"中途跳出"或"跳过这一次",用 `break` 和 `continue`:
```
for (int i = 0; i < 10; i++) {
    if (i == 3) {
        continue;   // 跳过这一次,i=3 不打印
    }
    if (i == 8) {
        break;      // 直接跳出整个循环,i=8 及之后不再执行
    }
    System.out.println(i);
}
```
输出（每个数字各占一行）:
```
0
1
2
4
5
6
7
```
`continue` 跳当前这一轮（i=3 那次没打印）,`break` 结束整个循环（i=8 及之后不再执行）.

**七、小项目:猜数字 + 抽奖**
先玩猜数字:程序想好一个 1 到 100 的数,你猜,大了/小了/对了都给提示.用到 `Random`、`Scanner`（键盘输入）和 `break`.
`GuessNumber.java`:
```
import java.util.Random;
import java.util.Scanner;

public class GuessNumber {
    public static void main(String[] args) {
        Random rand = new Random();
        int target = rand.nextInt(100) + 1;   // 1 到 100

        Scanner scanner = new Scanner(System.in);
        System.out.println("我选好了一个 1~100 的数,你来猜");

        while (true) {
            System.out.print("请输入: ");
            int guess = scanner.nextInt();

            if (guess > target) {
                System.out.println("大了");
            } else if (guess < target) {
                System.out.println("小了");
            } else {
                System.out.println("猜对了!");
                break;   // 猜对就跳出死循环
            }
        }
        scanner.close();
    }
}
```
`scanner.nextInt()` 读一个整数;`while(true)` 是死循环,靠 `break` 在猜对时跳出.
再写一个抽奖模拟:从候选名单里随机抽一个人.
`Lottery.java`:
```
import java.util.Random;

public class Lottery {
    public static void main(String[] args) {
        String[] names = {"小明", "小红", "小刚", "小丽", "小强"};

        Random rand = new Random();
        int index = rand.nextInt(names.length);   // 0 到 4
        System.out.println("恭喜 " + names[index] + " 中奖!");
    }
}
```
运行几次,中奖人每次都不同——这就是随机.

**朝花夕拾:字符串拼接的幕后**
第 1 期我们第一次写 `System.out.println("第 " + i + " 次循环")`,字符串加数字.现在知道了:Java 会把数字转成字符串再拼,背后创建的是新字符串.单次拼接无所谓,但要是把那个循环改成 `String result = ""; result += i;`,一万次就会慢得明显:这正是本期 `StringBuilder` 要解决的.以后在循环里拼字符串,先想想:要不要用 `StringBuilder`?
---
**总结**
本期学习了几个常用的类:
- **String 不可变**:拼接会造新对象,循环里拼用 `StringBuilder`(多线程共享才用 `StringBuffer`,同 API 但加了锁更慢);比内容用 `equals`
- **包装类与自动装箱**:`Integer`/`Double`… 基本类型和对象自动互转;`parseInt` 转数字
- **Math**:纯静态方法,绝对值、取大取小、次方、随机
- **Random**:`nextInt(n)` 造 [0,n) 随机数,`+1` 变 1 到 n
- **break/continue**:跳出循环、跳过当前轮;猜数字、随机抽奖小项目
