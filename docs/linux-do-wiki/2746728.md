**一、三种集合,什么时候用哪个**

第 1 期学过 `List` 和 `Map`,今天补上 `Set`,凑齐三大集合.选择很简单,连续问自己两个问题:

1. **要不要按键找值?** 要 → `Map`

2. **要不要去重（不允许重复元素）?** 要 → `Set`



两个问题都回答"不要"——就是要一个**有序列表**,用 `List`.

| 集合 | 特点 | 典型场景 |

| --- | --- | --- |

| `List` | 有序,可重复,按下标取 | 列表、排行、待办 |

| `Set` | 不重复,自动去重 | 记录"已经来过的人" |

| `Map` | 键值对,按键取 | 字典、统计、配置 |

**二、Set:自动去重**

```
import java.util.HashSet;
import java.util.Set;

Set<String> names = new HashSet<>();

names.add("小明");
names.add("小红");
names.add("小明");   // 重复添加,会被忽略

System.out.println(names.size());           // 2,不是 3
System.out.println(names.contains("小明")); // true
names.remove("小红");
```

- `add` 重复元素会被**自动忽略**,`Set` 里不会有重复

- 常用的实现是 `HashSet`,`contains` 很快

- `Set` **没有下标**,不能 `get(0)`,只能遍历或用 `contains` 判断

**三、遍历的几种写法**

以 `List` 为例,常用两种:

```
List<String> list = new ArrayList<>();
list.add("a");
list.add("b");
list.add("c");

// 写法一:下标 for
for (int i = 0; i < list.size(); i++) {
    System.out.println(list.get(i));
}

// 写法二:增强 for(最常用)
for (String s : list) {
    System.out.println(s);
}
```

遍历 `Map` 用 `keySet()` 拿所有键,再按键取值:

```
Map<String, Integer> map = new HashMap<>();
map.put("钻石", 5);
map.put("铁", 12);

for (String key : map.keySet()) {
    System.out.println(key + ":" + map.get(key));
}
```

**四、排序:让类实现 Comparable**

对自定义类排序,先让类实现 `Comparable<T>`,重写 `compareTo`——定义"谁大谁小"的规则:

```
public class Student implements Comparable<Student> {
    public String name;
    public double score;

    public Student(String name, double score) {
        this.name = name;
        this.score = score;
    }

    // 返回负数/0/正数,表示 this 小于/等于/大于 other
    @Override
    public int compareTo(Student other) {
        if (this.score < other.score) return -1;
        if (this.score > other.score) return 1;
        return 0;
    }
}
```

然后 `Collections.sort(list)` 就能按成绩从小到大排:

```
Collections.sort(list);
```

`String`、`Integer` 这些 JDK 类自带 `compareTo`,所以 `Collections.sort` 可以直接排字符串/数字列表.

---

**五、排序:不想改类,用 Comparator**

有时不想改动类本身（或是别人写的类）,或者想用不同的排序规则,用 `Comparator`:

```
import java.util.Comparator;

// 单独写一个"按姓名排序"的比较器
public class NameComparator implements Comparator<Student> {
    @Override
    public int compare(Student a, Student b) {
        return a.name.compareTo(b.name);   // 姓名按字典序
    }
}
```

调用时把比较器传进去:

```
Collections.sort(list, new NameComparator());   // 按姓名排
Collections.sort(list);                          // 默认按 compareTo 排
```

`Comparable` 是"类自己会排",`Comparator` 是"外面另立一套规则".同一个类,想用几种规则排就写几个 `Comparator`.

**六、Collections 工具类**

`Collections` 是一堆操作集合的静态方法:

```
Collections.sort(list);              // 排序
Collections.reverse(list);           // 反转顺序
Collections.shuffle(list);           // 打乱
Collections.max(list);               // 最大元素
Collections.min(list);               // 最小元素
```

**七、小项目:成绩排行榜**

把学生存进 `List`,按成绩排序,输出前 3 名.

文件一 `Student.java`:

```
public class Student implements Comparable<Student> {
    public String name;
    public double score;

    public Student(String name, double score) {
        this.name = name;
        this.score = score;
    }

    @Override
    public int compareTo(Student other) {
        if (this.score < other.score) return -1;
        if (this.score > other.score) return 1;
        return 0;
    }
}
```

文件二 `Main.java`:

```
import java.util.ArrayList;
import java.util.Collections;
import java.util.List;

public class Main {
    public static void main(String[] args) {
        List<Student> list = new ArrayList<>();
        list.add(new Student("小明", 92));
        list.add(new Student("小红", 58));
        list.add(new Student("小刚", 76));
        list.add(new Student("小丽", 88));

        // 按成绩从小到大排
        Collections.sort(list);

        // 反转,让成绩从大到小,再取前 3
        Collections.reverse(list);

        System.out.println("排行榜前三名:");
        for (int i = 0; i < 3; i++) {
            Student s = list.get(i);
            System.out.println("第 " + (i + 1) + " 名:" + s.name + " " + s.score);
        }
    }
}
```

运行结果:

```
排行榜前三名:
第 1 名:小明 92.0
第 2 名:小丽 88.0
第 3 名:小刚 76.0
```

或者让 `compareTo` 反过来写（成绩大的算小）,直接 `sort` 就是降序,不用 `reverse`.两种都能达到效果,体会一下"规则由 compareTo 定义".
