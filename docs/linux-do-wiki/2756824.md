# Java开发教程11-文件读写

本期是Java开发教程系列的第十一期,本期主要向各位介绍**文件读写**——把数据保存到磁盘,再从磁盘读回来.若你已经熟悉各种 `Reader`/`Writer` 和流,可以跳过本期内容.
**每期叠甲**:

时间仓促,水平有限,文中难免存在缺点和错误,恳请广大开发者和从业者指正.
---
**一、流:数据进出程序的路**
Java 把"读文件""写文件"统一抽象成**流**（stream）——想象成一根管道,数据从源头流向目的地.按两个维度分类:
- **方向**:输入流（读,从文件进程序）/ 输出流（写,从程序到文件）
- **单位**:字节流（读写图片、音频等二进制）/ 字符流（读写文本,自动处理编码）

文本文件用字符流,其他用字节流.
---
**二、字符流:FileWriter 和 FileReader**
**写文件**用 `FileWriter`:
```
import java.io.FileWriter;

FileWriter writer = new FileWriter("notes.txt");   // 默认覆盖写
writer.write("第一行\n");
writer.write("第二行\n");
writer.close();   // 一定要关!
```
- 第二个参数传 `true` 表示**追加**:`new FileWriter("notes.txt", true)`,不覆盖原来的
- `\n` 是换行符;`close()` 不写会丢数据——写文件要先关（刷新）才落盘
- 文件不存在会自动创建

**读文件**用 `FileReader`:
```
import java.io.FileReader;

FileReader reader = new FileReader("notes.txt");
int ch = reader.read();        // 读一个字符,读不到返回 -1
while (ch != -1) {
    System.out.print((char) ch);
    ch = reader.read();
}
reader.close();
```
`FileReader` 一次读一个字符,太啰嗦,实际很少直接用,一般用下节的 `BufferedReader`.
---
**三、缓冲区:BufferedReader / BufferedWriter**
**BufferedReader** 一次读一整行,是读文本的主角:
```
import java.io.BufferedReader;
import java.io.FileReader;

BufferedReader reader = new BufferedReader(new FileReader("notes.txt"));
String line;
while ((line = reader.readLine()) != null) {   // 读一行,文件读完返回 null
    System.out.println(line);
}
reader.close();
```
`readLine()` 每次读一行（不含换行符）,返回 null 表示读完.`(line = reader.readLine()) != null` 是"先赋值给 line,再判断是不是 null"的简写,循环里很常见.
**BufferedWriter** 写入快,还有 `newLine()` 自动补换行:
```
import java.io.BufferedWriter;
import java.io.FileWriter;

BufferedWriter writer = new BufferedWriter(new FileWriter("notes.txt"));
writer.write("第一行");
writer.newLine();
writer.write("第二行");
writer.newLine();
writer.close();
```
---
**四、字节流:FileInputStream / FileOutputStream**
复制一个文件（比如图片）,用字节流:
```
import java.io.FileInputStream;
import java.io.FileOutputStream;

FileInputStream in = new FileInputStream("photo.jpg");
FileOutputStream out = new FileOutputStream("copy.jpg");

byte[] buffer = new byte[4096];   // 一次读一块
int len;
while ((len = in.read(buffer)) != -1) {
    out.write(buffer, 0, len);
}

in.close();
out.close();
```
文本用字符流,图片/音频/视频/压缩包一律用字节流——用字符流处理二进制会乱码/损坏.
---
**五、try-with-resources:自动关闭**
每次手动 `close()`,要是中途抛异常,资源可能关不上.用 **try-with-resources**——`try` 后面的括号里声明资源,代码块结束自动 `close`:
```
try (BufferedReader reader = new BufferedReader(new FileReader("notes.txt"))) {
    String line;
    while ((line = reader.readLine()) != null) {
        System.out.println(line);
    }
} catch (Exception e) {
    System.out.println("读文件出错:" + e.getMessage());
}
```
- 括号里声明的资源,结束后**自动关闭**,不用自己写 `close()`
- 现在读写文件一律用这种方式,简洁又安全
- 能自动关闭的资源实现了 `AutoCloseable` 接口——先记住"能 close 的都放括号里"就行
- 注意:自动关闭管的是"不用写 `close`",但**构造资源时如果会抛受检异常,照样要 catch 或 throws**.上面例子里 `new FileReader("notes.txt")` 文件不存在会抛 `FileNotFoundException`（第 8 期学过的受检异常）,所以这段要么像示例这样 `catch (Exception e)` 接住,要么把方法签名写成 `throws FileNotFoundException`——try-with-resources 不会替你直接"屏蔽"受检异常.

**六、小项目:学生通讯录存档**
做一个通讯录:把联系人存进文件,下次运行再读回来.
文件一 `Contact.java`:
```
public class Contact {
    public String name;
    public String phone;

    public Contact(String name, String phone) {
        this.name = name;
        this.phone = phone;
    }
}
```
文件二 `Main.java`:
```
import java.io.BufferedReader;
import java.io.BufferedWriter;
import java.io.FileReader;
import java.io.FileWriter;
import java.util.ArrayList;
import java.util.List;

public class Main {

    // 保存:一行一个人,格式 姓名,电话
    static void save(List<Contact> contacts) throws Exception {
        try (BufferedWriter writer = new BufferedWriter(new FileWriter("contacts.txt"))) {
            for (Contact c : contacts) {
                writer.write(c.name + "," + c.phone);
                writer.newLine();
            }
        }
    }

    // 读取:把文件内容恢复成 List
    static List<Contact> load() throws Exception {
        List<Contact> contacts = new ArrayList<>();
        try (BufferedReader reader = new BufferedReader(new FileReader("contacts.txt"))) {
            String line;
            while ((line = reader.readLine()) != null) {
                String[] parts = line.split(",");   // 按逗号切开
                contacts.add(new Contact(parts[0], parts[1]));
            }
        }
        return contacts;
    }

    public static void main(String[] args) throws Exception {
        // 第一次运行:存几个联系人
        List<Contact> contacts = new ArrayList<>();
        contacts.add(new Contact("小明", "13800000000"));
        contacts.add(new Contact("小红", "13900000000"));
        save(contacts);

        // 读回来,模拟"下次运行"
        List<Contact> loaded = load();
        System.out.println("通讯录里有 " + loaded.size() + " 个联系人:");
        for (Contact c : loaded) {
            System.out.println(c.name + " " + c.phone);
        }
    }
}
```
运行结果:
```
通讯录里有 2 个联系人:
小明 13800000000
小红 13900000000
```
项目目录下会生成 `contacts.txt`,里面是:
```
小明,13800000000
小红,13900000000
```
`split(",")` 把一行按逗号切开返回字符串数组,是本例唯一的新语法,一句话就能记住.它属于 `String` 的方法,签名是 `String[] split(String regex)`——**参数其实是正则表达式**,只是这里逗号在正则里没特殊含义、当普通字符用.有两点提醒:
- 如果分隔符是正则里有特殊意义的字符（比如 `.`、`|`、`$`）,要么转义 `split("\\.")`,要么改用 `Pattern.quote(...)`;
- 本例用逗号分隔姓名和电话,**前提是姓名和电话里都不会出现逗号**,否则一切就切错.真正的存档格式遇到字段里可能含分隔符时,会改用专门的库（如 CSV/JSON）,后面进阶用到再说.

**朝花夕拾:第 1 期那句"后面会讲"的兑现**
第 1 期末尾我们埋了个钩子,原话是:
> `File` 并不代表"文件内容",它只是对文件或目录**路径**的抽象.真正读写文件内容是后面会讲到的 `FileInputStream`、`FileWriter` 等.
今天终于填坑了:`File` 负责"指路"（路径）,本期学的 `FileWriter`/`BufferedReader` 这些**流**才负责"搬货"（真正读写数据）.从第 1 期到第 11 期,这个钩子收上了.

**总结**
本期学会了把数据存到磁盘:
- **流分两类**:字符流管文本、字节流管二进制;方向分输入/输出
- **字符流**:`FileWriter` 写、`BufferedReader` 读,`readLine()` 读一行
- **字节流**:`FileInputStream`/`FileOutputStream` 拷贝图片等二进制文件
- **try-with-resources**:资源放 `try (...)` 里,自动关闭
- 通讯录存文件再读回,一个迷你存档系统
