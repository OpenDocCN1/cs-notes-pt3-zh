# Java开发教程12-简单需求与代码的组织

本期是Java开发教程系列的第十二期,本期以组织代码为主,顺着写一个完整的**学生成绩管理系统**——练习"怎么把一个稍大的程序拆成类和方法".过程中会顺带补一个新知识点 `toString`（下文解释）,其余全是第 2–11 期学过的东西.
**每期叠甲**:

时间仓促,水平有限,文中难免存在缺点和错误,恳请广大开发者和从业者指正.
---
**一、先看需求**
我们要做一个命令行下的成绩管理程序,支持:
1. 添加学生（姓名 + 成绩）
2. 删除学生（按姓名）
3. 修改成绩（按姓名）
4. 查看全部（按成绩从高到低）
5. 统计（平均分 / 最高分 / 最低分）
6. 保存到文件,启动时自动加载
功能不难,难的是**组织**:这点量级的代码如果全塞在 `main` 里,几百行谁都看不下去.所以先拆.
---
**二、怎么拆**
拆的原则:每个类只干一件事.
| 类 | 职责 | 用到的知识 |
| --- | --- | --- |
| `Student` | 描述一个学生:字段 + getter/setter | 第 2 期类与对象、第 5 期封装 |
| `StudentManager` | 管所有学生的增删改查 + 统计 | 第 10 期集合与排序 |
| `FileStore` | 把数据存进文件 / 从文件读回 | 第 11 期文件读写 |
| `Main` | 菜单循环,跟用户交互 | 第 8–9 期 Scanner、第 9 期 break |
类之间只通过公开方法打交道,内部怎么改都不互相影响——这就是封装的意义.

**三、代码实现**
文件一 `Student.java`:
```
public class Student implements Comparable<Student> {
    private String name;
    private double score;

    public Student(String name, double score) {
        this.name = name;
        this.score = score;
    }

    public String getName() {
        return name;
    }

    public double getScore() {
        return score;
    }

    public void setScore(double score) {
        this.score = score;
    }

    // 成绩高的排前面(降序)
    @Override
    public int compareTo(Student other) {
        if (this.score < other.score) return 1;
        if (this.score > other.score) return -1;
        return 0;
    }

    @Override
    public String toString() {
        return name + " " + score;
    }
}
```
`toString()` 是每个类都继承自 `Object` 的方法,重写它可以让 `System.out.println(student)` 直接打印友好内容.
文件二 `StudentManager.java`:
```
import java.util.ArrayList;
import java.util.Collections;
import java.util.List;

public class StudentManager {
    private List<Student> students = new ArrayList<>();

    // 添加
    public void add(Student s) {
        students.add(s);
    }

    // 删除:按姓名,删掉第一个匹配的
    // 注意:这里在增强 for 循环里直接 students.remove(s) 之所以不抛并发修改异常,
    //       是因为后面立刻 return 退出了循环,没有再继续迭代.
    //       如果要一次删多个,不能这么写,得改用 Iterator 的 remove(),或从后往前用下标删.
    public boolean remove(String name) {
        for (Student s : students) {
            if (s.getName().equals(name)) {
                students.remove(s);
                return true;
            }
        }
        return false;
    }

    // 修改成绩:按姓名
    public boolean updateScore(String name, double newScore) {
        for (Student s : students) {
            if (s.getName().equals(name)) {
                s.setScore(newScore);
                return true;
            }
        }
        return false;
    }

    // 按成绩降序后的全部学生
    public List<Student> sorted() {
        List<Student> copy = new ArrayList<>(students);   // 复制一份,别动原数据
        Collections.sort(copy);
        return copy;
    }

    // 统计
    public double average() {
        if (students.size() == 0) return 0;
        double sum = 0;
        for (Student s : students) sum += s.getScore();
        return sum / students.size();
    }

    public double max() {
        if (students.size() == 0) return 0;   // 空列表时和 average 保持一致,返回 0
        Student best = students.get(0);
        for (Student s : students) {
            if (s.getScore() > best.getScore()) best = s;
        }
        return best.getScore();
    }

    public double min() {
        if (students.size() == 0) return 0;   // 同上,空列表兜底,避免 get(0) 越界
        Student worst = students.get(0);
        for (Student s : students) {
            if (s.getScore() < worst.getScore()) worst = s;
        }
        return worst.getScore();
    }

    // 给 FileStore 用:拿原始列表
    public List<Student> all() {
        return students;
    }
}
```
`new ArrayList<>(students)` 复制一份列表,排序时不改动原来的数据——这个习惯叫"不破坏原数据",写代码时多想想.
文件三 `FileStore.java`:
```
import java.io.BufferedReader;
import java.io.BufferedWriter;
import java.io.FileReader;
import java.io.FileWriter;
import java.util.ArrayList;
import java.util.List;

public class FileStore {

    // 保存:一行一个学生,格式 姓名,成绩
    public static void save(List<Student> students) throws Exception {
        try (BufferedWriter writer = new BufferedWriter(new FileWriter("students.txt"))) {
            for (Student s : students) {
                writer.write(s.getName() + "," + s.getScore());
                writer.newLine();
            }
        }
    }

    // 读取:恢复成学生列表
    public static List<Student> load() throws Exception {
        List<Student> list = new ArrayList<>();
        try (BufferedReader reader = new BufferedReader(new FileReader("students.txt"))) {
            String line;
            while ((line = reader.readLine()) != null) {
                String[] parts = line.split(",");
                list.add(new Student(parts[0], Double.parseDouble(parts[1])));
            }
        }
        return list;
    }
}
```
文件四 `Main.java`:
> 关于 `Scanner`:第 9 期我们用过 `scanner.nextInt()` 读整数.本期还会用到 `scanner.next()` 读一个**不含空格的词**（以空白分隔）、以及 `scanner.nextDouble()` 读小数,方法名一目了然.**注意 next() 遇到姓名里含空格会读不全**,那种情况要改用 `nextLine()` 读一整行——本例姓名没有空格,用 `next()` 就够了.
```
import java.util.List;
import java.util.Scanner;

public class Main {
    public static void main(String[] args) throws Exception {
        StudentManager manager = new StudentManager();

        // 启动时加载存档(文件不存在也无所谓)
        try {
            List<Student> saved = FileStore.load();
            for (Student s : saved) manager.add(s);
            System.out.println("已加载 " + saved.size() + " 条记录");
        } catch (Exception e) {
            System.out.println("没有存档,从空开始");
        }

        Scanner scanner = new Scanner(System.in);
        while (true) {
            System.out.println("\n===== 学生成绩管理系统 =====");
            System.out.println("1 添加  2 删除  3 改成绩  4 查看  5 统计  6 保存并退出");
            System.out.print("请选择:");
            int choice = scanner.nextInt();

            if (choice == 1) {
                System.out.print("姓名:");
                String name = scanner.next();
                System.out.print("成绩:");
                double score = scanner.nextDouble();
                manager.add(new Student(name, score));
                System.out.println("已添加");

            } else if (choice == 2) {
                System.out.print("姓名:");
                String name = scanner.next();
                System.out.println(manager.remove(name) ? "已删除" : "没找到这个人");

            } else if (choice == 3) {
                System.out.print("姓名:");
                String name = scanner.next();
                System.out.print("新成绩:");
                double score = scanner.nextDouble();
                System.out.println(manager.updateScore(name, score) ? "已修改" : "没找到这个人");

            } else if (choice == 4) {
                List<Student> list = manager.sorted();
                for (int i = 0; i < list.size(); i++) {
                    System.out.println("第 " + (i + 1) + " 名:" + list.get(i));
                }

            } else if (choice == 5) {
                System.out.println("平均分:" + manager.average());
                System.out.println("最高分:" + manager.max());
                System.out.println("最低分:" + manager.min());

            } else if (choice == 6) {
                FileStore.save(manager.all());
                System.out.println("已保存,再见");
                break;

            } else {
                System.out.println("无效选项");
            }
        }
        scanner.close();
    }
}
```

**四、运行流程**
1. 第一次运行:没存档 → 提示"从空开始"
2. 选1添加几个学生,选4查看排行,选5看统计

4. 再运行:自动加载上次的学生,不用重新录入

**总结**
本期以组织代码为主,顺带补了 `toString` 重写这个小知识点,主菜是"怎么组织一个稍大的程序":
- **拆类**:一个类只干一件事,`Student`/`StudentManager`/`FileStore`/`Main` 各司其职
- **依赖公开接口**:类之间只调公开方法,内部随便改
- **复用**:增删改查、排序、统计、存取文件,全是前几期的知识
- 一个完整可运行的**学生成绩管理系统**
