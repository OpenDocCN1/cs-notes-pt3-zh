# 各家coding plan发票问题统计（wiki贴，大家可直接编辑）

想要问一下各位佬友，目前国内主流codingplan或者api充值的发票所开金额是否可自行决定，以及相关发票名称/类型。
**deepseek api**：可自选金额（比如充了300块，可以选择只开200块的发票）    发票为：技术服务费

**火山方舟**：企业发票需在职证明 + 企业盖章声明函 （开票巨麻烦）

**Kimi**：一次性年费会员充值不支持自选金额

**claude/openAI/gemini**：国外provider暂不支持发票

**cursor**：可以开invoice，一般都支持，可以先问问公司

**kiro**：管理页面、进入设置、选择 “Account & Billing”麻烦的很
