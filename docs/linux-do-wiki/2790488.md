# CachyOS 安装及调优指南



目前从 Windows 转到 CachyOS 已经一个多月了，体验下来挺不错的，目前我还没有遇到过崩溃的情况，现在我的 Windows 只用来打游戏了。最近在 L 站也看到了不少 linux 的帖子，于是我打算写下这篇教程，也算是对自己折腾的总结吧。

> [!attention] 注意

>

> CachyOS 基于 ArchLinux，滚动更新，追求性能，面向游戏和生产力

>

> 其安装过程还挺简单的，主要是后面的各种美化和配置需要折腾不少，如果不想折腾还是不太推荐安装的；如果你想要美化桌面、紧跟最新软件版本还是比较推荐的

# CachyOS 安装

首先要准备一个 U 盘和 CachyOS 的系统镜像，先去 [CachyOS 官网](https://cachyos.org/)安装桌面版的 iso，然后将其写入 U 盘制作启动盘，这里推荐一个制作可启动 U 盘的工具 [Ventoy](https://www.ventoy.net/cn/index.html)，具体介绍可以看官网的描述。

准备好后就可以开始安装了，下面我会在虚拟机中做演示，因为虚拟机的原因图片中分辨率可能有些问题

> [!attention] 注意

>

> 如果要安装双系统，要提前进入 BIOS 关闭安全启动

# 配置调优

因为已经将近 1 个月了，所以有的配置都忘了，想起啥写啥吧，后面也会补充，也欢迎各位来补充。

有什么配置问题可以去翻 [ArchWiki](https://wiki.archlinux.org/title/Main_page)，或者装完 Agent 工具让 AI 来帮你配置，但是一定要注意不要让 AI 瞎搞，防止搞崩溃，你可以让 AI 给你配置步骤，自己手动走一遍。

CachyOS 默认 Shell 用的是 fish，想用其他的可以自己更换，我比较习惯 zsh 就换去 zsh 了。

第一个命令，更新包命令

```
sudo pacman -Syu
```

## 快照

当文件系统选择 `btrfs` 时 CachyOS 默认会装 btrfs 助手和 snapper（用于系统快照），你可以打开 btrfs 助手自己调整快照设置，默认只会在安装、升级、删除包时创建快照

## [archlinuxcn 源](https://www.archlinuxcn.org/archlinux-cn-repo-and-mirror/)

CachyOS 默认会自动选用适合本地的镜像源，但是默认是没有 archlinuxcn 源的，推荐加入该源

```
sudo vim /etc/pacman.conf
```

在最后加上

```
[archlinuxcn]
Server = https://mirrors.ustc.edu.cn/archlinuxcn/$arch
Server = https://mirrors.tuna.tsinghua.edu.cn/archlinuxcn/$arch
Server = https://mirrors.hit.edu.cn/archlinuxcn/$arch
Server = https://repo.huaweicloud.com/archlinuxcn/$arch
Server = https://repo.archlinuxcn.org/$arch
```

Server 一个就行，自选，然后安装 `archlinuxcn-keyring`，并同步更新软件源数据库

```
sudo pacman -S archlinuxcn-keyring
sudo pacman -Syu
```

## yay

推荐安装 `yay`（AUR 助手），具体介绍可以自行搜索

```
sudo pacman -S yay
```

注意使用 `yay` 时不用在前面加 `sudo`，安装 `yay` 后基本没再手动用过 `pacman` 了

每日更新变为

```
yay -Syu
```

## 网络代理

一个比较折磨的问题就是 aur 下载慢甚至下载不下来，此时就需要用到代理软件了，archlinuxcn 源里有打包好的 clash 系软件，用 `yay -Ss clash` 搜索，然后安装自己想用的

```
yay -S clash-verge-rev
# 或者
yay -S flclash
```

> [!attention] 注意

>

> archlinuxcn 源的 clash-verge-rev 可能存在 bug，我当时安装完打开安装虚拟网卡时一直循环输入密码认证，最后还用不了，临时解决方法是循环完手动在命令行执行 `sudo clash-verge-service-uninstall` 和 `sudo clash-verge-service-install`，但是下次打开软件仍出现循环问题还是桌面环境的问题，不知道是不是我当时安装的那个版本的问题，后面我就去用 aur 上安装的了

>

> 安装命令为 `yay -S clash-verge-rev-bin`，不用代理应该会卡住

v2rayn 只在 aur 中有，下载下来感觉在 linux 上不太好用，就没用过

```
yay -S v2rayn-bin
```

这里说一下软件包后啥也不带、带 `-bin` 或带 `-git` 三者在一般情况下的区别，推荐安装带 `-bin` 的版本：

- 啥也不带会下载软件正式版的源码压缩包进行本地编译构建

- 带 `-bin` 的是下载软件正式版的预编译程序，不用本地编译构建

- 带 `-git` 的是下载软件 git 仓库最新源码进行本地编译构建

有的包不带 `-bin` 也是安装的软件正式版的预编译程序，比如未开源的软件

## QQ

安装命令

```
yay -S linuxqq
```

因为用的 Electron，所以在 linux 上存在一些问题，默认是以 XWayland 启动的，我用时如果输入法输入太快就会导致输入法漏字符，修复方法就是用 Wayland 启动，配置 `~/.config/qq-flags.conf`，添加以下内容

```
--ozone-platform=wayland
--enable-wayland-ime
--wayland-text-input-version=3
```

## VS Code

安装命令

```
yay -S visual-studio-code-bin
```

在我 niri 的桌面环境下存在密钥环服务无法自动识别的问题（其他应用貌似也有），修改 `~/.vscode/argv.json` 将 `password-store` 手动设置为 `gnome-libsecret` 就没问题了

## 剪贴板

安装 `wl-clip-persist` 解决复制完内容，把源程序一关，复制内容失效无法再粘贴的问题

安装 `comalot-clipsync-git` 解决在 X11 应用复制完内容无法同步到 Wayland 上的问题

```
yay -S wl-clip-persist comalot-clipsync-git
```

记得设置自动启动，`wl-clip-persist` 我用的是 niri 桌面的自动启动，配置 `spawn-at-startup "wl-clip-persist" "--clipboard" "regular"`，`comalot-clipsync-git` 用命令 `systemctl --user enable --now clipsync`

## 输入法

> ai 的有些知识还是比较旧，尤其近几年 linux 输入法相关的环境在从 x11 迁移到 wayland。

>

> 可以参考一下我的配置

> `~/.config/environment.d/ime-env.conf`

> `# 配置fcitx # xwayland应用 环境变量 XMODIFIERS=@im=fcitx # 处理微信的输入法问题 QT_IM_MODULES="wayland;fcitx;ibus" # QT_IM_MODULE=fcitx WPS需要单独设置环境变量 `

> `~/.config/gtk-3.0/settings.ini` 和 `~/.config/gtk-4.0/settings.ini`

> `[Settings] gtk-im-module=fcitx `

> 还可以参考

> [安全检查](https://wiki.archlinuxcn.org/wiki/Fcitx_5#Wayland) [Using Fcitx 5 on Wayland - Fcitx](https://fcitx-im.org/wiki/Using_Fcitx_5_on_Wayland)

我用的 fcitx5 + fcitx5‑rime + rime‑ice，根据佬友的回复做了一些调整

```
yay -S fcitx5 fcitx5-rime fcitx5-configtool fcitx5-gtk fcitx5-qt rime-ice-git
```

我的 `~/.local/share/fcitx5/rime/default.custom.yaml` 配置如下

```
patch:
  # 仅使用「雾凇拼音」的默认配置，配置此行即可
  __include: rime_ice_suggestion:/
  # 以下根据自己所需自行定义，仅做参考。
  # 针对对应处方的定制条目，请使用 <recipe>.custom.yaml 中配置，例如 rime_ice.custom.yaml
  __patch:
    menu/page_size: 8
    key_binder/select_first_character: "comma"
    key_binder/select_last_character: "period"
    key_binder/bindings/+:
      - { when: paging, accept: bracketleft, send: Page_Up }
      - { when: has_menu, accept: bracketright, send: Page_Down }
```

同时配置环境变量，编辑 `~/.config/environment.d/ime-env.conf` 并保存

```
QT_IM_MODULES="wayland;fcitx;ibus"
QT_IM_MODULE="fcitx"
XMODIFIERS="@im=fcitx"
SDL_IM_MODULE="fcitx"
```

配置 `~/.config/gtk-3.0/settings.ini` 和 `~/.config/gtk-4.0/settings.ini` 并保存

```
[Settings]
gtk-im-module=fcitx
```

可以用命令 `fcitx5-diagnose` 自查输入法问题

配置打字时按 `shift` 提交原始字符串，打开 fcitx5-configtool，选择中州韵，点开配置，将切换输入法时的行为改成提交原始字符串

## 字体

我用的以下字体及配置，仅作参考，可以自己调整

```
yay -S inter-font noto-fonts-cjk noto-fonts-emoji ttf-sarasa-gothic ttf-lxgw-wenkai ttf-jetbrains-mono-nerd ttf-caladea
```

配置 `~/.config/fontconfig/fonts.conf`

```
<?xml version="1.0"?>
<!DOCTYPE fontconfig SYSTEM "urn:fontconfig:fonts.dtd">
<fontconfig>

  <match target="font">
    <edit name="antialias" mode="assign"><bool>true</bool></edit>
  </match>

  <alias binding="strong">
    <family>sans-serif</family>
    <prefer>
      <family>Inter</family>
      <family>更纱黑体 UI SC</family>
      <family>更纱黑体 SC</family>
      <family>思源黑体 CN</family>
      <family>Noto Sans CJK SC</family>
    </prefer>
  </alias>

  <alias binding="strong">
    <family>serif</family>
    <prefer>
      <family>霞鹜文楷</family>
      <family>Noto Serif CJK SC</family>
    </prefer>
  </alias>

  <alias binding="strong">
    <family>monospace</family>
    <prefer>
      <family>JetBrainsMonoNL Nerd Font</family>
      <family>JetBrainsMonoNL Nerd Font Mono</family>
      <family>Sarasa Term SC</family>
      <family>等距更纱黑体 SC</family>
      <family>Sarasa Fixed SC</family>
    </prefer>
  </alias>

  <match target="pattern">
    <test name="lang" compare="contains"><string>zh</string></test>
    <edit name="family" mode="append" binding="strong"><string>更纱黑体 SC</string></edit>
  </match>

</fontconfig>
```

配置 `/etc/fonts/conf.d`，其中文件都是软链接，默认应该有链接到 `/usr/share/fontconfig/conf.default` 中的 41 个，我自己又添加了 `/usr/share/fontconfig/conf.avail` 中的 2 个，命令如下：

```
sudo ln -s \
/usr/share/fontconfig/conf.avail/10-sub-pixel-rgb.conf \
/usr/share/fontconfig/conf.avail/70-no-bitmaps-except-emoji.conf \
/etc/fonts/conf.d/
```
