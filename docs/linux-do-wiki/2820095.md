# 【考研】【408】关于 DRAM 与突发传输的知识随记

## 知识随记
> 相关知识点在王道408计组-2027年的 P84 附近
SRAM 不需要刷新、不是破坏性读取
DRAM 使用栅极电容，是易失性介质，需要定时通电（刷新）。且 DRAM 是破坏性读入，读完后数据就没了
为了加快 DRAM 的刷新，所以 DRAM 一次刷新一整行
为了快速读入读出这一整行的数据，又使用了行缓存器。它能存放一整行的数据
为了充分利用行缓存器，有了 `突发传输` 的功能。突发传输指的是，只要给出首位（首个字节）的地址，后面多个相邻的数据可以一起读出，不再需要给出多个地址
由于使用了行缓冲器，所以突发传输也有一些限制，比如一次只能读取同一行内的数据，如果首地址恰好在最后一列或者数据有多行，就不能一次性读取了
