## 具体流程

1. **先准备申请主体**



个人不能直接申请新 gTLD，申请人需要是合法实体，例如公司、机构、政府或非政府组织等。实践上你最好专门设一家负责这个 TLD 的公司，我们就叫LINUXDO Registry Limited吧



这家公司以后就是 `.ld` 的 Registry Operator，也就是注册局运营主体。ICANN 会调查公司及关键人员背景，所以公司需要处于正常状态，关键人员也会经过背景审查（建议你让佬们都入职，（顺便让佬们赚点钱 ![:face_savoring_food:](img/68e985d3b4eaeedd21711931dc3ba7a2.png)））。

2. **决定申请什么字符串**



这个我们有了，我们来申请 `.ld`



要提前看一下：是否已经存在、是不是 ICANN 保留名称、有没有地理名称问题、有没有明显商标冲突、有没有其他公司很可能同时申请。

3. **确定运营模式**



你要先决定它属于哪一种。



比如我们自用：



`index.ld`



`bohe.ld`



`neo.ld`

4. **找一个通过 ICANN 评估的 RSP**



这一点特别重要。你不需要自己写整个顶级域名注册局系统（如果你懒的话）



可以直接找 RSP,让他们帮我们来负责：



DNS / DNSSEC、EPP、RDAP、注册数据库、数据托管、注册生命周期、ICANN 技术接口等。



ICANN 2026 轮明确要求新的 gTLD 使用经过评估的 RSP。（这个你自己找，我没找 ![:face_savoring_food:](img/68e985d3b4eaeedd21711931dc3ba7a2.png)）



这是最省事的路线。

5. **注册 ICANN Account，然后进入 TAMS。**



真正申请是通过 ICANN 的 **TLD Application Management System，TAMS** 完成。



这里是他们注册页 [Create an ICANN Account](https://account.icann.org/registeraccount)

6. **填写公司和关键人员资料**



TAMS 里面先填写 Organization。



![image2926×1520 434 KB](https://cdn3.ldstatic.com/original/4X/5/1/5/515bad69db09b2803952ef7a2e766e52fe93422b.png)



至少包括公司基本资料、关键利益相关人员、主要用户、账单联系人和 Financial Capability。ICANN 当前 TAMS 要求至少两个 primary users 和一个 billing point of contact。(这些我们注册linuxdo域名公司之后会有）

7. **准备财务能力材料**



ICANN 会评估这个公司有没有能力长期运营顶级域名。标准申请者需要提交财务模板，包括：



注册数量预测、资金来源、现金储备、预计支出、运营成本、风险情况等。



所以一个比较正常的申请公司最好提前准备好：



公司账户、启动资金、财务报表、资金来源说明、3～5 年 Registry 财务模型、RSP 合同/报价。（这个我们一定可以！！！ ![:rofl:](img/8429225fe271ae2ca366815bfc05f49c.png)）

8. **填写 .ld 本身的申请**



接下来才是具体的 gTLD Application。



ICANN 把申请主要分成两部分：



Organization & Financial Information和gTLD Application Information



并要求回答全部必填问题、上传支持文件。



比如你需要说明 `.ld` 是做什么的、谁可以注册、如何运营、安全和滥用治理怎么做、RSP 是谁等。



这些内容我们佬们可以发挥一下

9. **提交申请并交钱**



当前 2026 轮标准 gTLD Evaluation Fee是$227,000



![image460×326 14.2 KB](https://cdn3.ldstatic.com/original/4X/3/3/2/3320abb7705cad5c37634c00ddb0cb49f77fd21a.png)



提交之后，申请主体、利益相关人和财务信息会被锁定；再修改一般需要走 Change Request。



也就是说最关键的一步就是：



**Submit Application → ICANN 开票 → 支付 $227,000。**

10. **ICANN 公布申请**



提交窗口结束后会进入 Pre-Evaluation。



ICANN 会公布部分申请信息，也就是大家会知道谁申请了什么 TLD。2026 轮流程还包含 Reveal Day、符合条件的 String Replacement Period 和 String Confirmation Day。

11. **进入公众意见、异议阶段**



这时候可能有人针对我们的 `.ld` 提出意见或正式异议。



典型风险例如：商标权、社区权利、公共利益、字符串混淆。



当然我们LINUXDO暂时没有什么大争议。。。吧？ ![:squinting_face_with_tongue:](img/910b3d6da24b8a16f8770bf2e7eb02cc.png)

12. **String Evaluation。**



接下来ICANN 会评估你申请的字符串本身是否符合政策和技术要求。



例如是否容易造成 DNS 混淆、是否涉及保留字符串、IDN/变体是否合法等。

13. **ICANN 审你这个公司。**



Applicant Evaluation 主要包括两块：



**Background Screening**和**Financial & Operational Evaluation**



也就是审NEO/版主他们的背景，以及公司到底有没有能力长期运营注册局。

14. **审核全部通过后，跟 ICANN 签 Registry Agreement。**



你会签 **2026 Base Registry Agreement**，里面规定 `.ld` 注册局的权利、义务、技术要求以及持续合规责任。

15. **技术 Onboarding。**



签合同之后，你和 RSP 接入 ICANN 系统，并完成技术测试。



包括注册局技术系统、DNS、DNSSEC、RDAP、数据托管等。ICANN 明确要求完成 onboarding 和 technical testing 后才能进入运营阶段。

16. **Delegation 到 DNS Root。**



这是最关键也是历史性的一刻



`.ld` 被添加到互联网根 DNS：



ROOT



└── .ld

从这一天起 index.ld 就是我们linuxdo倾注心血和你努力很久之后的结果

17. **开始发域名。**



可以通过我们的 Registry 创建：



`index.ld`



`neo.ld`



`idcflare.ld`

万事大吉
