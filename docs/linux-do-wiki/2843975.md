# Readest-Lite部署教程

部署其实也是非常简单的，通常情况下，只需要一条命令即可

**快速开始**

一条命令拉起，30 秒后访问 [http://localhost:8225](http://localhost:8225/)。
```
docker run -d \
  --name readest-lite \
  -p 8225:8225 \
  -v readest-data:/data \
  -e ADMIN_EMAIL=admin@example.com \
  -e ADMIN_PASSWORD=changeme \
  -e ADMIN_USERNAME=Admin \
  -e PUBLIC_BASE_URL=https://read.yourdomain.com \
  --restart unless-stopped \
  ghcr.io/cshdotcom/readest-lite:latest
```
> [!warning]
>
> 请务必修改默认密码，生产环境使用 16 位以上随机字符串。
> [!note]
>
> CLI 方式环境变量说明~~
>
> 通过 docker run -e 传递，常用 env：~~
> ADMIN_EMAIL（必填）：管理员邮箱，首次启动自动创建账号~~
>
> ADMIN_PASSWORD（必填）：管理员密码，建议 16+ 位随机字符串~~
>
> ADMIN_USERNAME（可选，v8.1 新增）：管理员显示名，用户列表里展示用。未设置时回退到邮箱
>
> PUBLIC_BASE_URL（可选，反向代理场景必填）：对外访问 URL，用于生成上传/下载文件的签名 URL。例如 [https://read.yourdomain.com](https://read.yourdomain.com/)。未设置时默认 [http://localhost:8225](http://localhost:8225/)，浏览器外不可达
>
> PORT（可选，默认 8225）：容器内监听端口，一般不需修改
>
> DEEPL_ENABLED=true（可选）：启用 DeepL 翻译，需配合 DEEPL_FREE_API_KEYS 或 DEEPL_PRO_API_KEYS
- 指定特定版本：[ghcr.io/cshdotcom/readest-lite:8.16.0（每个版本都有对应](http://ghcr.io/cshdotcom/readest-lite:8.16.0%EF%BC%88%E6%AF%8F%E4%B8%AA%E7%89%88%E6%9C%AC%E9%83%BD%E6%9C%89%E5%AF%B9%E5%BA%94) git tag，详见 GitHub Releases）。
