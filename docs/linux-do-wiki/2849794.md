# 【来时路】如何获取到更多 LDC 积分？



青春版账号没有 LDC 权限。

来时路：快问快答解决方案 + 发布回复 + 解决佬友问题 + 积分乐园兑换

解决佬友问题是获取到单笔最高的，每笔流转平均 500LDC。

## **前置总结**

1. 关注 [快问快答](/tag/1436-tag/1436)，回复被标记为解决方案后，+10LDC；

2. 关注 [积分乐园](/tag/2193-tag/2193)，如果可以满足佬友的需求，则可以回复或者私信佬友提供解决方案及对应流转链接；

3. 关注 LDC、红包等关键字，部分佬友会分发红包，或者悬赏；

4. 阅读 [社区准则](https://linux.do/guidelines)，遇见不符合社区准则的举报，成功后 +10LDC，需要注意乱举报会影响自身账号；



关注新人贴，遇见凑字数/特别水/不符合规范，建议先提醒



关注多个推广标签，不符合规则的，建议先提醒



回复中遇见无意义或者偏移主题的

5. 发布值得他人称赞的话题/回复，并且话题不一定有回复获取到的多；

6. 通过 [cdk.linux.do](http://cdk.linux.do) 分发，或者 [ldcstore.com](http://ldcstore.com) 发布商品；

## **实际操作**

### 如何关注标签

[https://linux.do/my/preferences/tracking](https://linux.do/my/preferences/tracking)

在标签中关注第一个帖子：快问快答

在类别中关注第一个帖子：积分乐园

### 如何关注 LDC、红包等关键字

[https://linux.do/my/preferences/saved-searches](https://linux.do/my/preferences/saved-searches)

添加：cdk，立即

添加：红包，立即

添加：LDC，立即

添加：新人，立即

添加：报道，立即

### 如何创建流转/收佬友的 LDC

### [LINUX DO Credit](https://credit.linux.do/login?callbackUrl=%2Fmerchant)

Linux Do 社区积分服务平台

创建应用-在线流转-创建服务-复制链接

### 如何创建 cdk 分发

### [实时数据 - LINUX DO CDK](https://cdk.linux.do/dashboard)

Linux Do 社区 CDK 快速分享平台 - 让分享变得更简单

悬浮工具栏，点击加号，创建

需要注意：最低社区等级和最低社区分数，以及领取消耗积分

## **Why？**

### 为什么没有到账？

7-14天，具体查看[LINUX DO Credit](https://credit.linux.do/balance) 鼠标悬浮到状态后面的小灯泡

可以查看自己的手续费：[LINUX DO Credit](https://credit.linux.do/settings/profile)
