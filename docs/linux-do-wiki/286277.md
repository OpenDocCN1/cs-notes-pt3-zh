# 【长期Wiki】人工智能发展时间线，了解AI发展的新闻和历史



## 人工智能发展时间线

- **2025年2月18日:** 马斯克旗下人工智能公司 **xAI** 正式发布了新一代生成式 AI 模型 [Grok3](https://en.wikipedia.org/wiki/Grok_(chatbot))。据悉，**Grok3** 采用了约 20 万块英伟达 H100 GPU 进行训练，其整体算力比前代 **Grok2** 提升了 10 倍。

- **2025年2月6日:** [李飞飞团队](https://arxiv.org/pdf/2501.19393) 发布了最新论文 [s1: Simple test‐time scaling](https://arxiv.org/pdf/2501.19393)，该论文提出了一种通过测试时扩展（Budget Forcing）技术，在仅使用 1000 个高质量样本的情况下，对基于 [Qwen2.5-32B-Instruct](https://arxiv.org/pdf/2501.19393) 预训练模型进行监督微调，从而在数学和编程推理任务上实现与 **OpenAI o1** 和 **DeepSeek-R1** 媲美的性能。同时，团队同步开源了论文、代码和数据集，标志着低成本高效推理模型训练新范式的探索。

- **2025年2月3日:** **OpenAI** 发布了 [Deep Research](https://en.wikipedia.org/wiki/2025_in_artificial_intelligence) 工具，集成于 ChatGPT 中，支持自动实时信息搜索并生成带引用的专家级分析报告。

- **2025年1月31日:** OpenAI 正式发布了新一代轻量级推理模型[o3-mini](https://en.wikipedia.org/wiki/OpenAI_o3)，该模型通过强化推理技术在数学、编程和科学等复杂任务上表现出色，并已向所有 ChatGPT 用户（包括免费用户）和部分 API 用户开放使用。

- **2025年1月21日:** 特朗普政府联合 **OpenAI**、软银、甲骨文与 MGX 宣布启动 [星际之门计划](https://zh.wikipedia.org/zh-hans/%E6%98%9F%E9%99%85%E4%B9%8B%E9%97%A8%E8%AE%A1%E5%88%92)，计划未来四年内投资 5000 亿美元建设人工智能基础设施。

- **2025年1月20日:** [DeepSeek](https://zh.wikipedia.org/wiki/DeepSeek) 公司推出了最新的推理模型 [DeepSeek-R1](https://zh.wikipedia.org/wiki/DeepSeek-R1)，并同步开源模型权重。该模型在数学、代码和自然语言推理等任务上性能比肩 **OpenAI o1 正式版**。

- **2024年12月26日:** [DeepSeek](https://zh.wikipedia.org/wiki/DeepSeek) 公司推出了全新系列模型 [DeepSeek-V3](https://zh.wikipedia.org/wiki/DeepSeek-V3)，并同步开源。

- **2024年12月12日:** **ChatGPT 视频语音功能** 正式发布，**OpenAI** 推出高级语音模式（Advanced Voice Mode），支持用户通过视频与 ChatGPT 实时互动并共享屏幕内容，此功能向 ChatGPT Plus 与 ChatGPT Pro 用户开放。

- **2024年12月9日:** [Sora 模型](https://zh.wikipedia.org/wiki/Sora_(%E4%BA%BA%E5%B7%A5%E6%99%BA%E8%83%BD%E6%A8%A1%E5%9E%8B)) 公开试用版发布，**OpenAI** 向 ChatGPT Plus 与 ChatGPT Pro 用户正式推出 Sora 的试用版本，付费用户可以开始使用这一视频生成功能。

- **2024年12月6日:** [o1 正式版](https://zh.wikipedia.org/zh-hans/OpenAI_o1) 发布，成为 ChatGPT Pro 计划的核心技术，标志 AI 推理技术迈入新纪元。

- **2024年10月22日:** **Anthropic** 公布了 **3.5 Haiku** 以及升级版本的 **3.5 Sonnet** 模型。

- **2024年10月9日:** [DeepMind](https://zh.wikipedia.org/wiki/DeepMind) 联合创始人 [Demis Hassabis](https://zh.wikipedia.org/wiki/Demis_Hassabis) 利用人工智能技术开发出革命性的 [AlphaFold](https://zh.wikipedia.org/wiki/AlphaFold) 系统，精准预测蛋白质的三维结构，成功破解了悬而未决 50 年的“蛋白质折叠问题”，因此与 [John Jumper](https://zh.wikipedia.org/wiki/John_M._Jumper) 及 [David Baker](https://zh.wikipedia.org/wiki/David_Baker_(biochemist)) 共同荣获 2024 年诺贝尔化学奖。

- **2024年10月8日:** John J. Hopfield 与 Geoffrey E. Hinton 因“对使人工神经网络机器学习成为可能的基础性发现和发明”共同获得 [2024 年诺贝尔物理学奖](https://www.nobelprize.org/prizes/physics/2024/summary/)。

- **2024年9月13日:** **OpenAI** 推出 [o1-preview](https://zh.wikipedia.org/zh-hans/OpenAI_o1) 与 [o1-mini](https://zh.wikipedia.org/zh-hans/OpenAI_o1) 模型，展示其强大的推理能力。

- **2024年6月21日:** [Claude-3.5-Sonnet](https://zh.wikipedia.org/wiki/Claude_(%E8%AF%AD%E8%A8%80%E6%A8%A1%E5%9E%8B)) 正式发布，这是 **Anthropic** 公布的 Claude 3.5 系列首个模型，据称相较于 3.0 Opus 带来两倍性能提升，并在代码与视觉能力上显著改进。

- **2024年5月13日:** [GPT-4o](https://zh.wikipedia.org/wiki/GPT-4o) 正式发布，**OpenAI** 推出这一多模态大型语言模型，具备处理文本、图像与音频的能力，其运行速度为前代的两倍，成本降低 50%，并向所有用户免费开放。

- **2024年5月:** [DeepSeek](https://zh.wikipedia.org/wiki/DeepSeek) 公司发布并开源旗下大模型 [DeepSeek-V2](https://zh.wikipedia.org/wiki/DeepSeek-V2)，其 API 定价为每百万 tokens 输入 1 元、输出 2 元，仅为 GPT-4 Turbo 定价的百分之一。

- **2023年12月6日:** 谷歌发布 [Gemini](https://zh.wikipedia.org/zh-cn/Gemini_(%E8%81%8A%E5%A4%A9%E6%A9%9F%E5%99%A8%E4%BA%BA))，具备处理多种信息类型的能力。

- **2023年11月20日:** [Ollama](https://ollama.com/) 推出本地大语言模型平台，实现无需云端支持即可在个人设备上高效运行多种大型语言模型。

- **2023年10月28日:** [DeepSeek](https://zh.wikipedia.org/wiki/DeepSeek) 公司发布其首个大模型 [DeepSeek-Coder](https://zh.wikipedia.org/wiki/DeepSeek-Coder)。

- **2023年7月12日:** [Elon Musk（伊隆·马斯克）](https://zh.wikipedia.org/wiki/%E5%9F%83%E9%9A%86%C2%B7%E9%A9%AC%E6%96%AF%E5%85%8B) 创办人工智能初创企业 **xAI**，正式成立 **xAI 公司**。

- **2023年7月:** [DeepSeek](https://zh.wikipedia.org/wiki/DeepSeek) 公司成立，由量化资管公司幻方量化创立，专注于人工智能技术研发，致力于开发先进大语言模型（LLM）及相关技术。

- **2022年3月21日:** **NVIDIA H100 芯片** 正式发布，NVIDIA 推出基于 [Hopper 架构](https://zh.wikipedia.org/wiki/Hopper_(microarchitecture)) 的 H100 GPU，以满足数据中心对高性能计算与人工智能的需求。

- **2023年3月20日:** 百度通过官方微信公布，[文心一言](https://zh.wikipedia.org/wiki/%E6%96%87%E5%BF%83%E4%B8%80%E8%A8%80) 云服务将于 3 月 27 日上线。

- **2023年3月15日:** **Anthropic** 公司正式发布其首个大型语言模型 [Claude](https://zh.wikipedia.org/wiki/Claude_(%E8%81%8A%E5%A4%A9%E6%A9%9F%E5%99%A8%E4%BA%BA))。

- **2023年3月14日:** **OpenAI** 发布 [GPT-4](https://zh.wikipedia.org/wiki/GPT-4)，即生成型预训练变换模型 4（Generative Pre-trained Transformer 4，简称 GPT-4），其性能全面优于 GPT-3 与 GPT-3.5。

- **2023年2月6日:** 谷歌宣布推出人工智能聊天机器人 [Bard](https://zh.wikipedia.org/wiki/Gemini_(%E8%81%8A%E5%A4%A9%E6%A9%9F%E5%99%A8%E4%BA%BA))。

- **2023年2月:** **Meta** 发布 [LLaMA](https://zh.wikipedia.org/wiki/LLaMA)（Large Language Model Meta AI），一系列基础大语言模型，旨在为学术研究提供更开放的 AI 模型。

- **2022年11月30日:** **OpenAI** 发布 [ChatGPT](https://zh.wikipedia.org/wiki/ChatGPT)，基于 GPT-3.5 架构，提供用户与 AI 对话的功能，迅速引起全球关注。

- **2022年9月21日:** **OpenAI** 开源了语音识别系统 [Whisper](https://zh.wikipedia.org/wiki/Whisper_(speech_recognition_system))。

- **2022年8月22日:** [Stability AI](https://zh.wikipedia.org/wiki/Stability_AI) 推出开源图像生成模型 [Stable Diffusion](https://zh.wikipedia.org/zh-hans/Stable_Diffusion)，极大降低生成艺术作品门槛，并迅速在创意设计领域获得广泛关注。

- **2022年4月:** Google 首次宣布 [PaLM](https://zh.wikipedia.org/wiki/PaLM) 语言模型。

- **2022年3月:** [Midjourney](https://zh.wikipedia.org/wiki/Midjourney) 推出其创新 AI 艺术生成平台，迅速在数字创意领域引起热议；**2022年7月12日**，平台进入公开测试阶段，用户可通过 Discord 机器人体验前沿技术。

- **2021年:** [Anthropic PBC](https://zh.wikipedia.org/wiki/Anthropic) 成立，这是一家总部位于美国的公益型 AI 创业公司。

- **2021年:** **OpenAI** 发布 [Codex](https://zh.wikipedia.org/wiki/OpenAI_Codex) 模型，推动了编程辅助工具（如 GitHub Copilot）的诞生，加速了自然语言与代码之间的转换应用。

- **2021年1月5日:** [OpenAI](https://zh.wikipedia.org/wiki/OpenAI) 发布 [DALL·E](https://zh.wikipedia.org/zh-hans/DALL-E) 模型，这是一种基于深度学习的生成模型，能够根据文本描述生成图像，标志生成式艺术新时代的到来。

- **2020年9月22日:** 微软获得 [GPT-3](https://zh.wikipedia.org/wiki/GPT-3) 独家授权。

- **2020年6月11日:** **OpenAI** 宣布了 [GPT-3](https://zh.wikipedia.org/wiki/GPT-3) 语言模型。

- **2020年5月14日:** [NVIDIA A100 GPU](https://zh.wikipedia.org/wiki/Ampere_(microarchitecture)#A100_accelerator_and_DGX_A100) 正式发布，**NVIDIA** 推出基于 Ampere 架构的 A100 GPU，该芯片专为高性能计算、深度学习训练与推理设计，提供了比前代 V100 更高的计算能力与效率。

- **2019年7月22日:** **微软** 投资 **OpenAI** 10 亿美元，双方携手在 Azure 云平台上推进 AI 技术发展。

- **2019年3月27日:** Yoshua Bengio、Geoffrey Hinton 与 Yann LeCun 因“使深度神经网络成为计算关键组成部分的重大突破”共同获得 [2018 年 ACM A.M. 图灵奖](https://www.nsfc.gov.cn/csc/20340/20289/36905/index.html)。

- **2019年3月1日:** 成立 [OpenAI LP](https://openai.com/index/openai-lp/) 子公司，旨在实现营利性运作。

- **2019年2月14日:** [OpenAI](https://zh.wikipedia.org/zh-hans/GPT-2) 发布 [GPT-2](https://zh.wikipedia.org/zh-hans/GPT-2) 模型，这是一款拥有 15 亿参数的生成式预训练语言模型，其代码和部分模型权重均已开源，供开发者免费使用。

- **2019年1月:** [DeepMind](https://zh.wikipedia.org/wiki/DeepMind) 公司推出 [AlphaStar](https://zh.wikipedia.org/wiki/AlphaStar_(software)) 模型，在《星际争霸 II》中展现出超越人类的策略决策能力，证明了强化学习在复杂环境中的巨大应用潜力。

- **2019年:** [蓝脑计划](https://zh.wikipedia.org/zh-cn/%E8%97%8D%E8%85%A6%E8%A8%88%E7%95%AB) 完成了小鼠大脑整体虚拟皮层构建，并准备开展虚拟 EEG 实验；同时，由于模型对超算负载过重，团队开始探索以人工神经网络表示神经元的新方法。

- **2018年2月:** [Elon Musk（伊隆·马斯克）](https://zh.wikipedia.org/zh-cn/%E5%9F%83%E9%9A%86%C2%B7%E9%A9%AC%E6%96%AF%E5%85%8B) 辞去 **OpenAI** 董事会席位，理由为其在特斯拉的职位可能产生未来利益冲突。

- **2018年:** Google 发布 [BERT](https://zh.wikipedia.org/zh-cn/BERT) 模型，采用双向 Transformer 编码器，在多项 NLP 任务上取得领先成绩。

- **2017年5月:** [AlphaGo](https://zh.wikipedia.org/wiki/AlphaGo) 在中国乌镇围棋峰会上 **击败** 世界排名第一的中国棋手 **柯洁**。

- **2017年:** 谷歌大脑团队推出 [Transformer 模型](https://zh.wikipedia.org/wiki/Transformer%E6%A8%A1%E5%9E%8B)（即“变换器”），为自然语言处理奠定基础。

- **2016年3月:** Google DeepMind 的 [AlphaGo](https://zh.wikipedia.org/wiki/AlphaGo) 在对阵围棋冠军 **李世乭** 时取得胜利，展示了强化学习在复杂策略游戏中的强大能力。

- **2016年:** [Hugging Face](https://zh.wikipedia.org/wiki/Hugging_Face) 公司成立，由克莱门特·德朗格、朱利安·肖蒙与托马斯·沃尔夫创立，最初专注于面向青少年的聊天机器人应用。

- **2015年底:** 萨姆·阿尔特曼、格雷格·布洛克曼、里德·霍夫曼、杰西卡·利文斯顿、彼得·蒂尔、[Elon Musk（伊隆·马斯克）](https://zh.wikipedia.org/zh-cn/%E5%9F%83%E9%9A%86%C2%B7%E9%A9%AC%E6%96%AF%E5%85%8B)、亚马逊云计算（AWS）、印孚瑟斯及 YC Research 联合宣布成立 [OpenAI](https://zh.wikipedia.org/zh-cn/OpenAI)。

- **2015年:** [残差神经网络（ResNet）](https://zh.wikipedia.org/wiki/%E6%AE%8B%E5%B7%AE%E7%A5%9E%E7%BB%8F%E7%BD%91%E7%BB%9C) 由何恺明、张祥雨、任少卿与孙剑开发，在 ImageNet 大规模视觉识别挑战赛中夺冠，其创新设计解决了深层网络“性能退化”的问题。

- **2014年:** Ian Goodfellow 等人提出 [生成对抗网络（GAN）](https://zh.wikipedia.org/wiki/%E7%94%9F%E6%88%90%E5%AF%B9%E6%8A%97%E7%BD%91%E7%BB%9C)，开启了生成模型新时代。

- **2014年1月26日:** Google 宣布已同意收购 [DeepMind 科技](https://zh.wikipedia.org/wiki/Google_DeepMind)。

- **2014年:** [Seq2Seq 模型](https://zh.wikipedia.org/wiki/Seq2Seq%E6%A8%A1%E5%9E%8B) 被提出，用于机器翻译等任务，推动了循环神经网络（RNN）的应用。

- **2013年3月:** [杰弗里·辛顿](https://zh.wikipedia.org/wiki/%E6%9D%B0%E5%BC%97%E9%87%8C%C2%B7%E8%BE%9B%E9%A1%BF) 加入 Google，同时 Google 并购了其创办的 DNNresearch 公司。

- **2012年:** [AlexNet](https://zh.wikipedia.org/wiki/AlexNet) 在 ImageNet 图像分类竞赛中夺冠，标志着深度学习在计算机视觉领域的崛起。

- **2010年11月:** [DeepMind](https://zh.wikipedia.org/wiki/Google_DeepMind) 由 Demis Hassabis、Shane Legg 与 Mustafa Suleyman 创立。

- **2009年:** **李飞飞团队** 在美国佛罗里达州计算机视觉与模式识别会议（CVPR）上首次以学术海报形式展示 [ImageNet 数据库](https://zh.wikipedia.org/wiki/ImageNet)。

- **2007年2月15日:** [CUDA](https://zh.wikipedia.org/wiki/CUDA) 首个软件开发包（SDK）发布，支持 Microsoft Windows 与 Linux。

- **2005年:** 斯坦福大学开发的机器人在 [DARPA 挑战赛](https://zh.wikipedia.org/wiki/DARPA_Robotics_Challenge) 中成功自动行驶 131 英里，赢得头奖。

- **1997年:** [长短期记忆（LSTM）](https://zh.wikipedia.org/wiki/%E9%95%B7%E7%9F%AD%E6%9C%9F%E8%A8%98%E6%86%B6) 论文首次发表，提出了适用于处理与预测长间隔时间序列的循环神经网络模型。

- **1997年:** IBM 的 [深蓝](https://zh.wikipedia.org/wiki/%E6%B7%B1%E8%97%8D_(%E8%B6%85%E7%B4%9A%E9%9B%BB%E8%85%A6)) 在国际象棋比赛中 **击败** 世界冠军卡斯帕罗夫，展示了 AI 在特定任务中的强大能力。

- **1993年:** [第二次 AI 低谷结束](https://zh.wikipedia.org/wiki/%E4%BA%BA%E5%B7%A5%E6%99%BA%E8%83%BD%E5%8F%B2#%E7%AC%AC%E4%BA%8C%E6%AC%A1AI%E4%BD%8E%E8%B0%B7%EF%BC%9A1987%E2%80%941993) —— 尽管面临财政困境与技术问题，AI 领域仍不断前进，部分研究者如 Rodney Brooks 与 Hans Moravec 提出全新 AI 方案，为未来技术突破奠定基础。

- **1992年:** [波士顿动力公司](https://zh.wikipedia.org/wiki/Boston_Dynamics) 成立，作为麻省理工学院的分支机构。

- **1991年:** 日本 [第五代电脑计划](https://zh.wikipedia.org/wiki/%E7%AC%AC%E4%BA%94%E4%BB%A3%E9%9B%BB%E8%85%A6) 未能实现目标，进一步打击了 AI 研究资金。

- **1987年:** [第二次 AI 低谷开始](https://zh.wikipedia.org/wiki/%E4%BA%BA%E5%B7%A5%E6%99%BA%E8%83%BD%E5%8F%B2#%E7%AC%AC%E4%BA%8C%E6%AC%A1AI%E4%BD%8E%E8%B0%B7%EF%BC%9A1987%E2%80%941993) 因 Apple 与 IBM 台式机性能超越昂贵的 Lisp 机，加之专家系统维护成本高、升级困难，导致市场崩溃与资金大幅削减。

- **1986年:** Rumelhart 与 McClelland 主编的《分布式并行处理》问世，推动了神经网络的发展。

- **1986年:** 大卫·E·鲁梅哈特、杰弗里·E·辛顿与罗纳德·J·威廉姆斯重新提出并详细阐述了 [反向传播算法](https://zh.wikipedia.org/wiki/%E5%8F%8D%E5%90%91%E4%BC%A0%E6%92%AD%E7%AE%97%E6%B3%95)，有效解决了多层神经网络训练问题，使深度神经网络成为可能。

- **1982年:** 约翰·霍普菲尔德提出 **Hopfield 网络**，推动了神经网络研究的新发展。

- **1981年:** 日本启动 [第五代计算机](https://zh.wikipedia.org/wiki/%E7%AC%AC%E4%BA%94%E4%BB%A3%E9%9B%BB%E8%85%A6) 项目，投入大量资金支持 AI 研究。

- **1980年:** [专家系统](https://zh.wikipedia.org/wiki/%E4%B8%93%E5%AE%B6%E7%B3%BB%E7%BB%9F) 开始广泛应用，Edward Feigenbaum 与其团队开发的 Dendral 与 MYCIN 展示了专家系统的实用性。

- **1980年:** [第一次 AI 低谷结束](https://zh.wikipedia.org/wiki/%E4%BA%BA%E5%B7%A5%E6%99%BA%E8%83%BD%E5%8F%B2#%E7%AC%AC%E4%B8%80%E6%AC%A1AI%E4%BD%8E%E8%B0%B7%EF%BC%9A1974_-_1980) —— 尽管遭遇资金困难与公众误解，AI 在逻辑编程和常识推理领域取得突破，为后续发展奠定基础。

- **1976年:** 汉斯·莫拉维克指出计算能力不足以实现 AI 目标，提出 [莫拉维克悖论](https://zh.wikipedia.org/zh-cn/%E8%8E%AB%E6%8B%89%E7%B6%AD%E5%85%8B%E6%82%96%E8%AB%96)。

- **1974年:** [第一次 AI 低谷开始](https://zh.wikipedia.org/wiki/%E4%BA%BA%E5%B7%A5%E6%99%BA%E8%83%BD%E5%8F%B2#%E7%AC%AC%E4%B8%80%E6%AC%A1AI%E4%BD%8E%E8%B0%B7%EF%BC%9A1974_-_1980)，美国 DARPA 削减对 AI 的资助，导致研究经费骤减。

- **1974年:** 保罗·韦尔博斯在博士论文《Beyond Regression》中首次提出 [反向传播算法](https://zh.wikipedia.org/wiki/%E5%8F%8D%E5%90%91%E4%BC%A0%E6%92%AD%E7%AE%97%E6%B3%95) 概念，主张通过误差反向传播训练人工神经网络。

- **1973年:** 詹姆斯·莱特希尔爵士的报告批评英国 AI 研究，导致资金大幅削减。

- **1972年:** 理查德·卡普证明许多 AI 问题只能在指数时间内解决，揭示了计算复杂性难题。

- **1964年至1967年:** Joseph Weizenbaum 在麻省理工学院开发早期自然语言处理程序 [ELIZA](https://zh.wikipedia.org/wiki/ELIZA)。

- **1959年:** John McCarthy 在论文 “Programs with Common Sense” 中提出 [Advice Taker](https://en.wikipedia.org/wiki/Advice_taker) 概念。

- **1957年:** 弗兰克·罗森布拉特在康奈尔航空实验室发明 [感知器](https://zh.wikipedia.org/wiki/%E6%84%9F%E7%9F%A5%E5%99%A8)，这是最简单的前馈神经网络，也是最早的二元线性分类器。

- **1956年:** 马文·明斯基、约翰·麦卡锡、克劳德·香农及内森·罗彻斯特在达特茅斯召开 [达特茅斯会议](https://zh.wikipedia.org/wiki/%E4%BA%BA%E5%B7%A5%E6%99%BA%E8%83%BD%E5%8F%B2#1956%E5%B9%B4%E8%BE%BE%E7%89%B9%E8%8C%85%E6%96%AF%E4%BC%9A%E8%AE%AE%EF%BC%9AAI%E7%9A%84%E8%AF%9E%E7%94%9F)，正式提出了“人工智能”概念及研究任务。

- **1955年至1956年:** 艾伦·纽厄尔、司马贺及约翰·克里夫·肖开发了计算机程序 [逻辑理论家](https://zh.wikipedia.org/wiki/%E9%80%BB%E8%BE%91%E7%90%86%E8%AE%BA%E5%AE%B6)，被视为首个 AI 程序，证明了《数学原理》中多项定理的正确性。

- **1951年:** 克里斯托弗·斯特雷奇在曼彻斯特大学的 [Ferranti Mark 1](https://en.wikipedia.org/wiki/Ferranti_Mark_1) 上编写 **西洋跳棋程序**，迪特里希·普林茨编写了 **国际象棋程序**。

- **1951年2月:** [Ferranti Mark 1](https://en.wikipedia.org/wiki/Ferranti_Mark_1) 的首台机器交付曼彻斯特大学，并于当年 7 月公开演示，成为世界上首台商用通用电子存储程序数字计算机。

- **1951年:** Marvin Minsky 与 Dean Edmonds 建造了首台神经网络机 [SNARC](https://zh.wikipedia.org/wiki/Stochastic_Neural_Analog_Reinforcement_Calculator)。

- **1950年:** [艾伦·图灵（Alan Turing）](https://zh.wikipedia.org/wiki/%E8%89%BE%E4%BC%A6%C2%B7%E5%9B%BE%E7%81%B5) 发表论文《计算机器与智能》，提出 [图灵测试](https://zh.wikipedia.org/wiki/%E5%9B%BE%E7%81%B5%E6%B5%8B%E8%AF%95)，奠定了人工智能哲学的基础。

- **1949年:** [亚瑟·李·塞谬尔](https://zh.wikipedia.org/zh-cn/%E4%BA%9E%E7%91%9F%C2%B7%E6%9D%8E%C2%B7%E5%A1%9E%E8%AC%96%E7%88%BE) 加入 [IBM](https://www.ibm.com/)，并为 IBM 701 编写跳棋程序，展示了计算机硬件与程序设计的潜力。

- **1943年:** Walter Pitts 与 Warren McCulloch 分析了理想化的 [人工神经元网络](https://zh.wikipedia.org/wiki/%E4%BA%BA%E5%B7%A5%E7%A5%9E%E7%BB%8F%E7%BD%91%E7%BB%9C)，首次描述了神经网络的概念及其逻辑运算机制，为后续发展奠定基础。

- **1936年:** [图灵机](https://zh.wikipedia.org/wiki/%E5%9B%BE%E7%81%B5%E6%9C%BA) 由英国数学家 [艾伦·图灵（Alan Turing）](https://zh.wikipedia.org/wiki/%E8%89%BE%E4%BC%A6%C2%B7%E5%9B%BE%E7%81%B5) 提出，是将人类计算行为抽象化的计算模型，具备模拟任何有限逻辑数学过程的能力。

- **1232-1315年:** 马略卡哲学家 [拉蒙·柳利](https://zh.wikipedia.org/wiki/%E6%8B%89%E8%92%99%C2%B7%E6%9F%B3%E5%88%A9) 开发了“逻辑机”，试图通过机械逻辑操作生成所有可能的知识，其思想对莱布尼兹产生了深远影响。
