# 整理一下谷歌全家桶被封后第一时间要做的事情



如题 最近用了十年了的谷歌老号莫名其妙被封掉了，近三年在上面订过正价gptPro plus claude一大堆，愤怒提交了申诉已经两天了还没动静，只能按最坏结果打算。



邮箱 日历，密码管理器，f2a，还有数不清登陆的第三方网站或APP，google play和谷歌云盘等 本来数据需要确认迁移/趁着登陆态缓存没失效进行保存，然而更坑爹的是封号后登录走了一次接码，第二次还要原号码，直接登不上了。

整理一份被封后的快速行动清单，欢迎佬友们共建

1.转移谷歌身份验证器



找到侧边栏-转移动态密码-生成转移二维码即可导入到另一个谷歌验证器

2.Chrome书签



需要电脑版登录，在页面右上角搜索框旁边，点那三个点，选择导出书签，它会生成一个标准的HTML网页文件存到本地。如果是手机版就只能走官方数据下载中心了打开设置，

3.Chrome本地历史记录



MAC系统~/Library/Application Support/Google/Chrome/Default/ 里history



win %LOCALAPPDATA%\Google\Chrome\User Data\Default\

4.密码填充和通行密钥



在Chrome浏览器或安卓手机的我的谷歌账号里。找到 密码管理器，里面有导出为文件选项

[10002769801080×2376 147 KB](https://cdn3.ldstatic.com/original/4X/3/8/4/3840afb854fc82905f6bba4229d7ee2131a60f54.jpeg)

5.开发者gcp相关



我目前只开过一个试用gcp 其中300已过期和一个oath拿来做自己服务的快捷登录 以及一个薅域名的workspace



目前看来独立的workspace账号不会跟着封掉，这是比较幸运的 但是如果你创建了关联的google auth服务也会跟着挂掉
