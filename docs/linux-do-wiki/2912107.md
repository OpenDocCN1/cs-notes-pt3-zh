# 关闭helium的新建页链接

记录一个小技巧。我很喜欢用Helium浏览器，极简风格，非常轻量，需要的功能又齐备，跟随chromium 同步进化，但剔除了所有累赘部件。
最近在新Mac上安装后发现一个很烦人的地方，开启默认页面中间都是网站链接图标，跟极简的风格完全不搭。找了很久设置项无法关闭。问过AI，也查了社区帖子，都没有好的办法，可以修改默认页面为 about：blank 解决，但不够优雅。而且AI说这是作者的设计选择，社区有人吐槽，但一直没有修改。
最终我找到了设置项，完美解决。在 customize helium 里关闭 show shortcuts 即可。
非常小众的一个设置。记录一下。如果不知道的很难找到。全网搜索也没有头绪。
