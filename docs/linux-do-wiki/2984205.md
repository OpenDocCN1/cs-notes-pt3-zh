# 截止26年10月5日，openai订阅各套餐的实际额度一览

这个帖子之后，希望不要有那么多问额度的问题了。
首先我们需要有一个基准，无论是什么套餐，都是这个基准的多少倍，这个基准就是plus

以下计算额度的定价统一采用官方api定价，无上下文分档
plus：

gpt-5系模型 120刀

gpt-6系模型 70刀
pro 5x(pro100):

gpt-5系模型 600刀

gpt-6系模型 350刀
pro 10x(pro200):

gpt-5系模型 1200刀

gpt-6系模型 700刀
pro 20x(旧订阅pro20x):

gpt-5系模型 2400刀

gpt-6系模型 1400刀
pro 25x(pro500):

gpt-5系模型 2400刀

gpt-6系模型 1400刀
注意，由于具体还存在某种细微倍率，实际额度会在这个基础上浮动一些，比如pro5x跑5系模型有时可以到700左右，pro20x跑6系有时只有1200多

如果你的额度差异很大，不用想，是出bug了

和号的体质什么完全无关，纯bug，就像以前的bug free一样
