# 二、理论技巧篇
## 透明色的简写
通常我们写透明色，会使用诸如 `transparent` 关键字 或者 `rgba(r,g,b,0)` 。
其实可以直接使用 16进制 简写：`#0000`。
> 使用 `#0000`来表示透明，`#000` 与 `#000000`是相等的，最后的`0`表示透明度为0，`#0000`其实就是`#00000000`的简写。就像`80`透明度代表`50%`
## 渐变背景的叠加
在我以往的一些画图中，都是用到过。
这里说一下：背景渐变的叠加优先级是 **上层覆盖下层**。
> 最上层的背景拥有更高的层级，也就是会盖住下面的，可理解为`PS`的图层
## 巧妙利用checkbox
checkbox的两种状态，可以很好的利用来实现一些只有两种状态的交互。例如侧边栏的展收、手风琴样式的菜单等。
需要配合其它选择器：`:not()`、`:has()`。
参见案例 [利用 checkbox 来实现一些小功能](https://linux.do/t/topic/320115)
## 善于使用三角函数
在一些特殊的运动轨迹中，我们可以很好的利用圆周运动的特性，如正弦函数与余弦函数。利用振幅乘以系数来扩大半径等。
> `圆的其中一个特性就是，圆周上任何一点到圆点的距离相等。`
参见案例 [【动画而已】手摸手带你实现 WINDOWS 加载动画](https://linux.do/t/topic/166764/)
## 使用选择器嵌套
我们有时候的一些需求，可能不是一个选择器能够完成的，这个时候我们就应当条件反射地想起选择器的嵌套。
使用 `:not()` 来排除，使用 `:has()` 来筛选等等。
参见案例 [🔥应吾皇催更 - 简单说说 :nth-child() 选择器！](https://linux.do/t/294829)
## 使用 :is() 和 :where() 简化代码
在以前的一些相似结构样式中，我们需要重复的写相同的父级，现在我们可以直接使用 `:is()` 或者 `:where()` 来简化代码。
```
.main .box,
.siderbar .box,
.footer .box {
  background:red;
}
//-------------------
:is(.main,.siderbar,.footer) .box{
  background:red;
}
// or
:where(.main,.siderbar,.footer) .box{
  background:red;
}
```
## 利用阴影模拟边框
对一些特殊的边框需求，使用传统的边框无法满足需求，这个时候我们可以使用阴影来模拟边框来达到要求。
