# 学习算法-day01-1. 两数之和



### 题目

给定一个整数数组 `nums` 和一个整数目标值 `target`，请你在该数组中找出 **和为目标值** *target* 的那 **两个** 整数，并返回它们的数组下标。

你可以假设每种输入只会对应一个答案。但是，数组中同一个元素在答案里不能重复出现。

你可以按任意顺序返回答案。

**示例 1：**

> **输入：** nums = [2,7,11,15], target = 9

>

> **输出：** [0,1]

>

> **解释：** 因为 nums[0] + nums[1] == 9 ，返回 [0, 1] 。

**示例 2：**

> **输入：** nums = [3,2,4], target = 6

>

> **输出：** [1,2]

**示例 3：**

> **输入：** nums = [3,3], target = 6

>

> **输出：** [0,1]

**提示：**

- `2 <= nums.length <= 104`

- `-109 <= nums[i] <= 109`

- `-109 <= target <= 109`

- **只会存在一个有效答案**

**进阶：** 你可以想出一个时间复杂度小于 O(n^2) 的算法吗？

### 解题思路

#### 方法一：暴力枚举

逻辑过于简单直接上代码。

#### ![:chestnut:](img/ecdb6eb10d47c25186c8736488d13d7a.png) 代码示例

```
public int[] twoSum(int[] nums, int target) {
    // 外层循环，用于遍历数组nums中的每一个元素，从索引0开始
    for (int i = 0; i < nums.length; i++) {
        // 内层循环，从外层循环当前元素的下一个位置（索引i + 1）开始遍历，这样可以避免重复计算已经组合过的元素对
        for (int j = i + 1; j < nums.length; j++) {
            // 判断当前两个元素（nums[i]和nums[j]）的和是否等于目标值target
            if (target == nums[i] + nums[j]) {
                // 如果找到了满足条件的元素对，就返回一个包含这两个元素索引的新数组
                return new int[]{i, j};
            }
        }
    }
    // 如果遍历完整个数组都没有找到满足条件的元素对，就返回一个长度为0的空数组
    return new int[0];
}
```

#### 方法二：哈希表

注意到方法一的时间复杂度较高的原因是寻找 `target - x` 的时间复杂度过高。因此，我们需要一种更优秀的方法，能够快速寻找数组中是否存在目标元素。如果存在，我们需要找出它的索引。

使用哈希表，可以将寻找 `target - x` 的时间复杂度降低到从  O(N)﻿  降低到 O(1)。

这样我们创建一个哈希表，对于每一个 `x`，我们首先查询哈希表中是否存在 `target - x`，然后将 `x` 插入到哈希表中，即可保证不会让 `x` 和自己匹配。

相比于前面的双层循环暴力解法，时间复杂度更低，它只需遍历一次数组就能尝试找到满足两数之和等于给定目标值的两个元素的索引，整体的时间复杂度是  O(N)﻿

#### ![:chestnut:](img/ecdb6eb10d47c25186c8736488d13d7a.png)代码示例

```
public int[] twoSum(int[] nums, int target) {
    // 创建一个HashMap，用于存储数组元素的值以及其对应的索引。
    // 这里键为数组中的元素值，值为该元素在数组中的索引位置
    HashMap<Integer, Integer> map = new HashMap<>();

    // 遍历给定的整数数组nums
    for (int i = 0; i < nums.length; i++) {
        // 检查map中是否已经存在（目标值 - 当前元素值）这样的键
        // 也就是看之前遍历过的元素中，有没有某个元素与当前元素相加能等于目标值target
        if (map.containsKey(target - nums[i])) {
            // 如果存在，说明找到了满足两数之和等于目标值的两个元素
            // 则返回一个包含这两个元素索引的新数组，其中一个索引从map中获取（之前存储的那个能与当前元素凑成目标值的元素索引），另一个就是当前元素的索引i
            return new int[]{map.get(target - nums[i]), i};
        }
        // 如果不存在满足条件的元素，就将当前元素及其索引存入map中，方便后续继续查找
        map.put(nums[i], i);
    }
    // 如果遍历完整个数组都没有找到满足条件的两个元素，就返回一个长度为0的空数组
    return new int[0];
}
```
