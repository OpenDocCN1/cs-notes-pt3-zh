# 算法学习-day02-2. 两数相加



### 题目

给你两个 **非空** 的链表，表示两个非负的整数。它们每位数字都是按照 **逆序** 的方式存储的，并且每个节点只能存储 **一位** 数字。

请你将两个数相加，并以相同形式返回一个表示和的链表。

你可以假设除了数字 0 之外，这两个数都不会以 0 开头。

**示例 1：**

[network-asset-addtwonumber1-20240613104808-l9z25rc483×342 19.2 KB](https://cdn3.ldstatic.com/original/4X/7/6/5/76573134389be1ebcef2639498ad0c51e2f87c31.jpeg)

> **输入：** `l1 = [2,4,3], l2 = [5,6,4]`

>

> **输入：**`[7,0,8]`

>

> **解释：** `342 + 465 = 807.`

**示例 2：**

> **输入：**`l1 = [0], l2 = [0]`

>

> **输出：**`[0]`

**示例 3：**

> **输入：**`l1 = [9,9,9,9,9,9,9], l2 = [9,9,9,9]`

>

> **输出：**`[8,9,9,9,0,0,0,1]`

**提示：**

- 每个链表中的节点数在范围 `[1, 100]` 内

- `0 <= Node.val <= 9`

- 题目数据保证列表表示的数字不含前导零

### 解题思路

#### 方法一：循环相加

我们同时遍历两个链表，逐位计算它们的和，并与当前位置的进位值相加。

如果当前两个链表处相应位置的数字为 n1,n2，进位值为 carry ，则它们的和为 n1+n2+carry；其中，答案链表处相应位置的数字为 (n1+n2+carry) mod 10 ，而新的进位值为 \frac {n1+n2+carry} {10}

如果两个链表的长度不同，则可以认为长度短的链表的后面有若干个 0 。

此外，如果链表遍历结束后，有 carry>0，还需要在答案链表的后面附加一个节点，节点的值为 carry 。

[image-20240613134936-akc4ksg1501×1324 122 KB](https://cdn3.ldstatic.com/original/4X/d/d/9/dd9108f4d64f989132075ea9d87d9ef08f29732b.png)

循环条件当两个链表都指向null结束。需要新建两个链表，一个保存头节点也就是完整链表，一个链表负责循环拼接。

#### ![:chestnut:](img/ecdb6eb10d47c25186c8736488d13d7a.png)代码示例

```
  public ListNode addTwoNumbers(ListNode l1, ListNode l2) {

        int carry = 0;
        // 定义头节点方便返回
        ListNode head = null, cur = null;

        while (l1 != null || l2 != null) {
            // 取出节点的值，null则为0
            int x = l1 == null ? 0 : l1.val;
            int y = l2 == null ? 0 : l2.val;
            // 求和
            int sum = x + y + carry;

            // 头节点为null时初始化head和next
            if (head == null) {
                head = cur = new ListNode(sum % 10);
            } else {
                cur.next = new ListNode(sum % 10);
                cur = cur.next;
            }
			// 更新进位值
            carry = sum / 10;

			// 指向下一个节点
            if (l1 != null) {
                l1 = l1.next;
            }
            if (l2 != null) {
                l2 = l2.next;
            }
        }
        if (carry > 0) {
            cur.next = new ListNode(carry);
        }
        return head;
    }
```

#### 方法二：递归

递归的逻辑就简单明了了。

#### ![:chestnut:](img/ecdb6eb10d47c25186c8736488d13d7a.png)代码示例

```
 /**
     *  递归实现
     * @param l1 第一个链表，表示一个整数。
     * @param l2 第二个链表，表示另一个整数。
     * @return 返回一个新的链表，表示两个输入链表相加的结果。
     */
    public ListNode addTwoNumbers2(ListNode l1, ListNode l2) {

        return addTwoNumbers(l1, l2, 0);

    }

    private ListNode addTwoNumbers(ListNode l1, ListNode l2, int carry) {

        if (l1 == null && l2 == null && carry == 0) {
            return null;
        }
        // 获取当前位的值，如果链表已空则默认为0
        int x = l1 == null ? 0 : l1.val;
        int y = l2 == null ? 0 : l2.val;

        // 计算当前位的和，包括进位
        int sum = x + y + carry;

        ListNode listNode = new ListNode(sum % 10);

        // 移动第一个链表的指针
        if (l1 != null) {
            l1 = l1.next;
        }
        // 移动第二个链表的指针
        if (l2 != null) {
            l2 = l2.next;
        }
        listNode.next = addTwoNumbers(l1, l2, sum / 10);
        return listNode;

    }
```
