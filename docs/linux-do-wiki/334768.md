# Navicat 简易教程



**数据无小事，操作需谨慎。**

**一键误操作，千里难追回。**

### 一、安装与启动

1. 从 Navicat 官网下载 Navicat 17 的安装包，根据你的操作系统选择适合的版本（Windows、macOS 或 Linux）。下载完成后，运行安装程序并按照提示完成安装。

2. 安装完成后，双击桌面上的 Navicat 图标启动程序。

![image](https://cdn3.ldstatic.com/original/4X/0/2/7/02724b521d1a6eebc4917599390d0eedee66236c.png)

### 二、创建数据库连接

1. 启动 Navicat 后，点击左上角的“连接”按钮，选择你要连接的数据库类型（如 MySQL、PostgreSQL、Oracle 等）。

[image1739×820 26 KB](https://cdn3.ldstatic.com/original/4X/8/e/6/8e6c70bf1d69c3bff0684bca8f58fc9eb62f5c55.png)

1. 选择 mysql 点击下一步

[image1110×901 61.6 KB](https://cdn3.ldstatic.com/original/4X/b/1/9/b19ad6ea654161d5e8afe3c2e70ba152eeee2b68.png)

1. 填写连接信息

- **连接名** ：为连接命名（如“MyLocalDB”）。

- **主机名/IP地址** ：输入数据库服务器的地址（如 `localhost` 或 `127.0.0.1` ）。

- **端口** ：输入数据库端口号（如 MySQL 默认端口是 `3306` ）。

- **用户名和密码** ：输入数据库的用户名和密码。

- **测试连接** ：点击“测试连接”按钮，确保连接信息正确无误。

- **保存连接** ：点击“确定”保存连接。

[image1110×901 17.1 KB](https://cdn3.ldstatic.com/original/4X/2/b/9/2b935627c009233020bc6594248670a089ec6bb4.png)

### 三、管理数据库

1. **打开连接** ：在左侧的连接列表中，双击你刚刚创建的连接，打开数据库。

[image1519×774 24.5 KB](https://cdn3.ldstatic.com/original/4X/2/4/7/2473c99ff119c897bda7ec88e81a1d94f766096d.png)

1. **查看数据库对象** ：连接成功后，你可以看到数据库中的表、视图、存储过程等对象。

2. **创建新数据库** ：右键点击连接名称，选择“新建数据库”，输入数据库名称并选择字符集和排序规则，点击“确定”创建。



[image1617×941 34.6 KB](https://cdn3.ldstatic.com/original/4X/d/8/f/d8fc98993289a60ef001fa4111fc9f07f1a0e4f1.png)

[image544×482 9.16 KB](https://cdn3.ldstatic.com/original/4X/9/a/a/9aa12609c7ff5e2e26007bffe9e0737e1dc38f0a.png)

### 四、操作数据表

1. 双击刚刚创建的数据库

[image1642×903 29.9 KB](https://cdn3.ldstatic.com/original/4X/1/d/1/1d1c97aab6e58efa3ea229346a8911a40fc6e541.png)

1. **创建表** ：在数据库下右键点击“表”，选择“新建表”。在表设计器中，添加字段并设置字段类型、长度、主键等属性，完成后点击“保存”，弹出“另存为”的界面输入表名完成后点击“保存”

[image1555×909 21.3 KB](https://cdn3.ldstatic.com/original/4X/f/1/9/f191680b1850900ea07faaab1b58295ac3443201.png)

1. **插入数据** ：双击打开表，点击“+”按钮添加新记录，填写数据后按回车保存。



[image957×1162 11.5 KB](https://cdn3.ldstatic.com/original/4X/7/1/a/71ab146e39be0eb1c27852794b023dcd820a2a75.png)

2. **查询数据** ：点击工具栏上的“查询”按钮，新建一个查询窗口，输入 SQL 语句（如 `SELECT * FROM 表名` ），点击“运行”按钮执行查询。

[image1616×982 38.4 KB](https://cdn3.ldstatic.com/original/4X/d/a/9/da9bf957eb3e7b2e91b5fcb22c70eb20ed1ebc75.png)

[image1003×981 15.4 KB](https://cdn3.ldstatic.com/original/4X/4/7/e/47e60a94b006b7504e0a57cc02e3c74268a5770e.png)

### 五、导入与导出数据

1. **导入数据** ：右键点击表，选择“导入向导”，选择数据源（如 Excel、CSV、sql 文件），按照向导步骤完成数据导入。

2. **导出数据** ：右键点击表或查询结果，选择“导出向导”，选择导出格式（如 SQL 、Excel 、sql等），按照向导步骤完成数据导出。

### 六、备份与恢复数据库

1. **备份数据库** ：右键点击数据库，选择“转储SQL文件” → “结构和数据”，选择保存路径并点击“保存”开始备份。

2. **恢复数据库** ：右键点击数据库，选择“运行SQL文件”，选择之前备份的 SQL 文件并点击“开始”进行恢复。

[image691×482 10.2 KB](https://cdn3.ldstatic.com/original/4X/c/e/2/ce2239fd9a16e9e65906ae95ab0dd76f8dc44d9c.png)

### 七、其他功能

- **数据同步** ：Navicat 提供了数据同步功能，可以将两个数据库之间的数据进行同步。

- **数据建模** ：使用 Navicat 的模型工具，可以创建数据库的 ER 图，帮助设计数据库结构。

- **任务调度** ：通过 Navicat 的任务调度功能，可以定期自动执行备份、数据同步等任务。
