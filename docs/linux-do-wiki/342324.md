# 使用 discobot 的一些注意事项



一部分用户初始的设置中界面语言是英文，比如我。在界面语言是英文的状态下 discobot 会[对中文命令提示使用 @discobot display help](https://linux.do/t/topic/4400/281)，然而[却又不能响应英文命令](https://linux.do/t/topic/4400/282)。

解决方法是将论坛界面语言切换到中文并使用中文命令。依次点击右上角头像 → 右下角 Profile → Preferences → 上方 Interface，修改 Interface language 为简体中文即可。

主要是 [已授权](https://linux.do/badges/101/-) [徽章](https://linux.do/t/topic/4400)必须使用 `@discobot 开始 高级教程`  命令[获取](https://linux.do/t/topic/4400)。

另外如果要在命令后面写额外内容需要空一行，前面则不用，比如：

```
before
@discobot 引用

after
```
