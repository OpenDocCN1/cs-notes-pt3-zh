# linux LVM常用操作
LVM（Logical Volume Manager）是Linux中的逻辑卷管理器，用于管理磁盘存储。它将物理硬盘分区抽象为物理卷（PV），并组合成卷组（VG），再从卷组中划分逻辑卷（LV）。LVM支持动态调整卷大小、快照、条带化等功能，提供灵活的存储管理。
## 创建lv、挂载演示
### 1. 前提条件
想要使用LVM在线扩容文件系统，首先被扩容的文件系统是通过LVM创建出来的。
如果linux服务器上没有lvm命令，可以通过如下命令安装：
```
#debian系
apt install lvm2
#红帽系
yum install lvm2 或 dnf install lvm2
```
### 2.实现环境准备
虚拟化平台：vmware workstation

虚拟机操作系统：Rockylinux 9.4

虚拟机添加一块硬盘用于LVM实验，在vmware workstation下，关闭虚拟机，添加硬盘。
添加好硬盘后，使用命令**lsblk**查看当前的硬盘，**nvme0n2**就是我新添加的硬盘
```
[root@localhost ~]# lsblk
NAME        MAJ:MIN RM  SIZE RO TYPE MOUNTPOINTS
sr0          11:0    1  1.5G  0 rom
nvme0n1     259:0    0   20G  0 disk
├─nvme0n1p1 259:1    0    1G  0 part /boot
└─nvme0n1p2 259:2    0   19G  0 part
  └─rl-root 253:0    0   19G  0 lvm  /
nvme0n2     259:3    0   20G  0 disk
```
### 3.创建pv（物理卷）
使用命令**pvcreate**创建物理卷，创建成功后可以通过**pvs**查看所有物理卷
```
[root@localhost ~]# pvcreate /dev/nvme0n2
  Physical volume "/dev/nvme0n2" successfully created.
[root@localhost ~]# pvs
  PV             VG Fmt  Attr PSize   PFree
  /dev/nvme0n1p2 rl lvm2 a--  <19.00g     0
  /dev/nvme0n2      lvm2 ---   20.00g 20.00g
```
- **/dev/nvme0n2**：新添加的硬盘
### 4.创建vg（卷组）
使用命令**vgcreate**创建卷组，创建成功后可以通过**vgs**查看所有卷组
```
[root@localhost ~]# vgcreate appvg /dev/nvme0n2
  Volume group "appvg" successfully created
[root@localhost ~]# vgs
  VG    #PV #LV #SN Attr   VSize   VFree
  appvg   1   0   0 wz--n- <20.00g <20.00g
  rl      1   1   0 wz--n- <19.00g      0
```
- **appvg**：卷组的名字，可以随便取。
- **/dev/nvme0n2**：新创建的pv
### 5.创建lv（逻辑卷）
使用命令l**lvcreate**创建逻辑卷，创建成功后可以通过**lvs**查看所有逻辑卷
```
[root@localhost ~]# lvcreate -L 10G -n applv appvg
  Logical volume "applv" created.
[root@localhost ~]# lvs
  LV    VG    Attr       LSize   Pool Origin Data%  Meta%  Move Log Cpy%Sync Convert
  applv appvg -wi-a-----  10.00g
  root  rl    -wi-ao---- <19.00g
```
- **-L**：指定创建的lv大小，我这里给了10G，如果要按百分比分配请使用 **-l**
- **-n**：指定lv的名字，我这里lv名字叫applv
- **appvg**：指定卷组名称，从哪个卷组创建lv，我这里是从**appvg**卷组创建
### 6.格式化lv
```
[root@localhost ~]# mkfs.xfs /dev/appvg/applv
meta-data=/dev/appvg/applv       isize=512    agcount=4, agsize=655360 blks
         =                       sectsz=512   attr=2, projid32bit=1
         =                       crc=1        finobt=1, sparse=1, rmapbt=0
         =                       reflink=1    bigtime=1 inobtcount=1 nrext64=0
data     =                       bsize=4096   blocks=2621440, imaxpct=25
         =                       sunit=0      swidth=0 blks
naming   =version 2              bsize=4096   ascii-ci=0, ftype=1
log      =internal log           bsize=4096   blocks=16384, version=2
         =                       sectsz=512   sunit=0 blks, lazy-count=1
realtime =none                   extsz=4096   blocks=0, rtextents=0
```
- **mkfs.xfs**：格式化为xfs类型的文件系统
### 7.创建一个目录（挂载点）
我这里创建一个/app目录，用于挂载逻辑卷applv
```
[root@localhost ~]# mkdir /app
```
### 8.挂载逻辑卷
/etc/fstab 是 Linux 系统中的配置文件，用于定义磁盘分区、存储设备或远程文件系统的挂载信息。系统启动时会读取该文件，自动挂载指定的文件系统。

编辑/etc/fstab，在最后一行加入以下内容
```
[root@localhost ~]# vim /etc/fstab
[root@localhost ~]# tail -n 1 /etc/fstab
/dev/appvg/applv        /app                    xfs     defaults        0 0
```
- **/dev/appvg/applv**：逻辑卷的位置
- **/app**：挂载位置
- **xfs**：文件系统类型
- **defaults**：挂载默认选项，包含读写、执行等常用选项
- **0 0**：第一个0表示该文件系统不需要被 dump 工具备份；第二个0表示系统启动时不需要fsck检查文件系统

保存后执行以下命令生效
```
[root@localhost ~]# mount -a
[root@localhost ~]# df -h
Filesystem               Size  Used Avail Use% Mounted on
devtmpfs                 4.0M     0  4.0M   0% /dev
tmpfs                    1.8G     0  1.8G   0% /dev/shm
tmpfs                    726M  9.1M  717M   2% /run
/dev/mapper/rl-root       19G  1.8G   18G  10% /
/dev/nvme0n1p1          1014M  302M  713M  30% /boot
tmpfs                    363M     0  363M   0% /run/user/0
/dev/mapper/appvg-applv   10G  104M  9.9G   2% /app
```
### 9.测试
进入/app目录下进行读写操作
```
[root@localhost app]# echo 'hello world' > test.txt
[root@localhost app]# cat test.txt
hello world
```
能正常写入读写，没有问题
## LVM在线扩容
### 1.逻辑卷（lv）所在卷组(vg)有剩余空间
在这种情况下直接使用命令**lvextend**进行扩容即可。
```
[root@localhost app]# lvextend -l +100%free /dev/appvg/applv
  Size of logical volume appvg/applv changed from 10.00 GiB (2560 extents) to <20.00 GiB (5119 extents).
  Logical volume appvg/applv successfully resized.
[root@localhost app]# lvs
  LV    VG    Attr       LSize   Pool Origin Data%  Meta%  Move Log Cpy%Sync Convert
  applv appvg -wi-ao---- <20.00g
  root  rl    -wi-ao---- <19.00g
```
- **-l +100%free**：将vg中剩余的空间都扩容到applv
扩容文件系统
```
[root@localhost app]# xfs_growfs /app
meta-data=/dev/mapper/appvg-applv isize=512    agcount=4, agsize=655360 blks
         =                       sectsz=512   attr=2, projid32bit=1
         =                       crc=1        finobt=1, sparse=1, rmapbt=0
         =                       reflink=1    bigtime=1 inobtcount=1 nrext64=0
data     =                       bsize=4096   blocks=2621440, imaxpct=25
         =                       sunit=0      swidth=0 blks
naming   =version 2              bsize=4096   ascii-ci=0, ftype=1
log      =internal log           bsize=4096   blocks=16384, version=2
         =                       sectsz=512   sunit=0 blks, lazy-count=1
realtime =none                   extsz=4096   blocks=0, rtextents=0
data blocks changed from 2621440 to 5241856
[root@localhost app]# df -h
Filesystem               Size  Used Avail Use% Mounted on
devtmpfs                 4.0M     0  4.0M   0% /dev
tmpfs                    1.8G     0  1.8G   0% /dev/shm
tmpfs                    726M  9.1M  717M   2% /run
/dev/mapper/rl-root       19G  1.8G   18G  10% /
/dev/nvme0n1p1          1014M  302M  713M  30% /boot
tmpfs                    363M     0  363M   0% /run/user/0
/dev/mapper/appvg-applv   20G  175M   20G   1% /app
```
- **xfs_growfs**：用来来调整xfs文件系统大小，以使用新增的空间。
- **/app**：被扩容的文件系统挂载点
### 2.当前卷组（vg）没有剩余空间
1. 在这种情况下我们需要添加硬盘，然后将硬盘创建成物理卷（pv）
```
[root@localhost ~]# lsblk
NAME          MAJ:MIN RM  SIZE RO TYPE MOUNTPOINTS
sr0            11:0    1  1.5G  0 rom
nvme0n1       259:0    0   20G  0 disk
├─nvme0n1p1   259:1    0    1G  0 part /boot
└─nvme0n1p2   259:2    0   19G  0 part
  └─rl-root   253:0    0   19G  0 lvm  /
nvme0n2       259:3    0   20G  0 disk
└─appvg-applv 253:1    0   20G  0 lvm  /app
nvme0n3       259:4    0    5G  0 disk
```
- **nvme0n3**：我这里添加了一块5g大小的盘，名称是nvme0n3
```
[root@localhost ~]# pvcreate /dev/nvme0n3  #创建逻辑卷
  Physical volume "/dev/nvme0n3" successfully created.
[root@localhost ~]# pvs
  PV             VG    Fmt  Attr PSize   PFree
  /dev/nvme0n1p2 rl    lvm2 a--  <19.00g    0
  /dev/nvme0n2   appvg lvm2 a--  <20.00g    0
  /dev/nvme0n3         lvm2 ---    5.00g 5.00g
```
1. 然后再将物理卷（pv）添加到逻辑卷（lv）所在的卷组（vg）

通过命令**vgextend**扩容卷组
```
[root@localhost ~]# vgextend appvg /dev/nvme0n3
  Volume group "appvg" successfully extended
[root@localhost ~]# vgs
  VG    #PV #LV #SN Attr   VSize   VFree
  appvg   2   1   0 wz--n-  24.99g <5.00g
  rl      1   1   0 wz--n- <19.00g     0
```
可以看到**appvg**有了**5g**的剩余空间，说明扩容成功。
