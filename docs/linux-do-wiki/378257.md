# 慢图浏览0.1.36-beta23 分享



建议朋友们尽快更新，该版本修复了多项错误，增加了更多的安全措施。

下载地址:  [慢图浏览的个人小站](https://relaxpic.com/#/download)

[image1183×2532 675 KB](https://cdn3.ldstatic.com/original/4X/5/b/b/5bb65c120cc748272a0e518c60d76d3be3ab7289.jpeg)

1. 修复隐私相机连拍可能丢失照片的问题

2. 修复加载超大图片可能出现的崩溃

3. 修复从后台进入慢图后部分设备出现的卡顿

4. 修复重命名相册将相册移动到DCIM目录的BUG

5. 修复各种由于安卓版本碎片化导致的显示异常

6. 新增相册置顶入口(点击相册->右上角菜单->点击置顶)

7. 新增支持按照照片原尺寸比例加载缩略图

8. 新增支持隐藏隐私空间相册的封面(隐私空间->右上角菜单->隐藏相册封面)

9. 新增支持隐藏隐私空间多任务预览图(隐私空间->右上角菜单->隐藏多任务预览图)

10. 新增双击相册进入无缝浏览模式(设置 → 浏览设置 → 双击相册进入无缝浏览)

11. 优化相册的复制、移动、相册重命名操作后保持和原图修改时间一致

12. 优化相册时间线的排序，时间线优先使用拍摄时间排序、修改时间排序

13. 支持通过Exif修复照片的拍摄时间来纠正相册排序

14. 视频支持3倍速播放
