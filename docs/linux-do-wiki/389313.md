# drg,dip,集采改革后的三方影响
| 利益方 | 改革前 | 改革后 |
| --- | --- | --- |
| 医保局 | • 医疗支出较高，面临较大的支付压力 • 对药品价格的控制力度有限 | • 医疗支出可能降低，通过集采、DRG/DIP政策控制医疗费用 • 对药品价格的控制力增强，通过集采压低药品价格 |
| 医生 | • 收入与开药量和高价药挂钩，有动力开高价药，造成过度医疗 | • 收入可能受限，因为DRG/DIP政策限制了医疗费用，超出部分可能需医生承担 • 工作量增加，需要病历本控制，像会计一样计算病人费用 • 在临床面临与医保局"斗智斗勇"的局面，需要在效率和确证诊效间平衡 • 可能倾向于开价格较低的仿制药 |
| 患者 | • 医疗费用较高，可能因过度医疗而增加负担 • 可以使用原研药，疗效有一定保障 • 可以通过医保报销部分原研药费用 | • 医疗费用可能降低，因为集采和DRG/DIP政策导致药品价格下降 • 可能面临仿制药替代原研药的情况，对疗效产生担忧 • 用药选择可能受限，医生可能优先开仿制药 • 住院时间可能缩短，影响康复 • 如果需要使用原研药或更好的医疗服务，可能需要自费或选择私立医院/特需部门，增加经济负担 |
# .医保购买的相关意见建议
**由@diping 佬友补充**
| 保险类型 | 建议预算 | 重点关注 | 特殊说明 |
| --- | --- | --- | --- |
| 总体预算 | • 家庭收入的10-20% • 可支配收入的5-10% | • 量入为出 • 可以先买保额小的，后续补充 | 优先级顺序：医疗>意外>重疾>寿险 |
| 医疗险 | • 年轻人：几百块-3k • 高端：数万元 • 老年人：5k+ | • 普通百万医疗 • 中端医疗 • 高端医疗（外资私人医院） | • 老年人可考虑惠民险(百余元/年) • 高端医疗通常由公司提供 |
| 意外险 | 较低，性价比高 | • 意外医疗保障 • 免赔额设置 • 医院限制 • 医保分类 | • 未满10周岁保额上限20万 • 10-18周岁保额上限50万 |
| 重疾险 | 费用占比最大 | • 核心保障疾病种类 • 理赔条件 • 是否带储蓄功能 | • 消费型：不理赔即失效 • 储蓄型：价格贵1/3-1/2 |
| 寿险 | 视家庭情况而定 | • 身故/残疾保障 • 保额参考家庭贷款总额 | 建议家庭主要收入来源人员购买 |
| 儿童保险 | 几百元 | • 重点关注意外医疗 • 注意保额限制 | 推荐产品：平安小顽童等 |
| 老年保险 | • 惠民保：百余元 • 医疗险：5k+ | • 惠民保建议配置到顶 • 根据预算选择保障范围 | 建议优先考虑惠民保 |
