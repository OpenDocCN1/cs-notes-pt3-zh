# [知识分享]什么是知识蒸馏(Knowledge Distillation)?



最近deepseek蒸馏openai的事情有点沸沸扬扬。看了一下L站好像没有专门讲知识蒸馏这玩意到底是什么的帖子。今晚看了一些资料打算分享一下自己的收获，也方便佬友评判deepseek这件事。

**太长不看版本**



简单来说就是我有一个训练好的大模型，但是大模型在某些场景下不太方便，如搬到汽车自动驾驶上但是汽车的芯片算力有限。在这种情况下我们会想训练一个小模型，比如说拥有更少的中间层。我们会拿大模型的训练数据来训练小模型，但是同时我们也会把大模型的结果同样喂给小模型（类似于知识）使小模型尽量接近大模型的输出结果。知识蒸馏也可以用来训练另一个大模型。同样的，把一个训练好的大模型A的训练集拿去训练另一个大模型B，同时把大模型A的结果也喂给B，这样能节省很多成本比如时间，也可以减少原本大模型A中冗杂的地方。

**正文**



大模型对于许多应用场景来说显得有些过大了，比如说汽车自动驾驶。如果我们直接把大模型下放到汽车的话，汽车的芯片很难去运行并且储存也是大问题。那么这个时候我们可以训练一个小一些模型，通过学习已经被训练过的大模型，以达到相同的效果。

一般来说我们会在softmax的运算中加入温度T（图4），具体有什么作用之后会讲。但是可以看出T越高最终得到的概率就越平均

![图41134×579 106 KB](https://cdn3.ldstatic.com/original/4X/0/3/0/03068f4bfc1015b52d3bfcc9b9f96d51da27af8c.jpeg)

最后概率最大的类别就是大模型对这样的图片的判断（这里class1经过中间层之后的概率最高，所以大模型最终判断这张输入的图片属于class1）

而经过无数次训练，中间层的权重大概稳定了下来，得到的输出大致会不变，相当于大模型已经调好了训练完成了。此时我们再把训练过的大模型作为教师模型（teacher model）来训练我们的小模型（student model）关系如下图

![图51203×694 45.2 KB](https://cdn3.ldstatic.com/original/4X/f/4/a/f4a35edd783a5fca376d39b9b678d8fe98ab382e.jpeg)

有了提前训练过的大模型我们要怎么把知识给到我们的小模型呢？我会先把流程说一遍再慢慢讲里面的细节。

我们会把相同的训练数据同时丢给教师模型和学生模型，分别得到一个output layer，再经过softmax层输出概率。这个softmax层的温度T要调高，并且teacher model和student model的T要是一样的。最后我们拿teacher model的预测（每个类别的概率，称之为软标记）和产生的分类（把这个图片分到哪一类，称之为硬标记）去和student model的预测和分类去对比。对比完我们有一个损失函数（loss function）而小模型的任务就是不断去调整自己中间层去减少这个损失函数，相当于学习了大模型的知识。

然后我们先从损失函数细讲（见图6）。不需要知道具体是怎么计算的（因为本文仅作科普），只需要知道损失函数由两部分组成：1.LKD: softmax层两个模型的区别 2.LCE 最后分类两个模型的区别。我们student model的任务就是不断调整自己的参数来使损失函数降低。损失函数越低，表示我们的student model对每个类型的概率判断，以及最后的分类，越接近teacher model。也就是我们的student model已经学到了teacher model的知识。

![图6946×283 15.1 KB](https://cdn3.ldstatic.com/original/4X/b/6/5/b653e4ae6c5886efde648a7c2190550e6f4c89de.png)

如果我们不考虑最后的分类，那么我们的student model可能在某些方面学了teacher model，但是最后的结果是错的。如果我们不考虑最后的两个模型的概率上的区别，哪怕student model可能训练后得出的结果和teacher model一样但是其实啥都没学会（类似于蒙的都对，但是实战就完蛋）然后我们需要一个权重λ来权衡两者。

还记得我提到过要调高softmax层的温度T来训练吗？如果我们不调高温度T训练，我们的student model就会变得很自信，学不到不同类别之间的关系。可能这里有点难以理解。如果我调高了teacher model的温度，最后的输出概率就会变软（参考图4）那么当student model在学习的时候它就不会大幅度修改自己的中间层，它会变得谨慎。举个例子，T=2时：类别2（0.42276112）和类别3（0.25641758）差的不是很多（相比其他类别），我不能鲁莽的肯定这张图片绝对是类别2，我需要更加谨慎。我从输入的图片发现这两个类别差不多说不定有什么特征是这两个类别共有的。 可以看到我们的student model好像感觉到了不同类别之间的关系。

在我们的student model训练完之后，我们再把温度T调回1使它正常输出。可以发现我们的小模型运用了更小结构就达到了类似于大模型的效果（有的时候大模型内部可能过于复杂，有一些冗杂的地方）。我们可能是拿小模型学习了大模型特定的地方用在特定的场所（因为我们只需要特定的功能）

我觉得我这种也类似于一种知识蒸馏。读者大概知道了知识蒸馏是什么，但是其中的细节像是公式中每一项的含义以及推导的过程是不太清楚的。但是好处是省了很多成本。如果有我的知识再去看原始文章（训练集）学起来就会快很多。
