# 甲骨文云永久免费资源详解（翻译）

## Oracle Cloud Infrastructure 永久免费资源详解
**引言 (Introduction)**
Oracle Cloud Infrastructure (OCI) 为所有账户（无论是免费账户还是付费账户）在其租户的**归属区域 (home region)** 提供一系列永久免费的云资源。这些资源在 Oracle 云控制台中会被标记为“**Always Free-eligible**”（符合永久免费条件）
**一、基础设施 (Infrastructure)**
- **证书 (Certificates)**

每个租户均可免费获取 **5 个证书颁发机构 (CA)** 以及 **150 个数字证书**。
- **计算 (Compute)**

**重要提示：** 创建永久免费计算实例时，如果遇到“主机容量不足 (out of host capacity)”错误，表示您所在归属区域暂时缺乏相应的免费实例规格。您可以尝试在不同的可用性域 (availability domain) 中创建，或者稍后再试。您也可以选择升级到付费账户以获得更多计算资源选择。升级后，Oracle 不会对您的永久免费资源收费，仅对超出免费限额的资源用量收费。您可以使用**配额 (quota)** 来控制账户内的资源消耗。

**可用的实例规格 (Available Shapes)**
**Micro 实例 (微型实例) (基于 AMD 处理器)**: 每个租户最多可创建两个采用 `VM.Standard.E2.1.Micro` 规格的永久免费虚拟机 (VM) 实例，该实例搭载 AMD 处理器。
**OCI Ampere A1 计算实例 (基于 Arm 架构处理器):** 每个租户每月可免费获得采用 `VM.Standard.A1.Flex` 规格的虚拟机实例的首个 3,000 OCPU 小时和 18,000 GB 小时使用时间，该实例搭载 Arm 架构处理器。对于永久免费租户，这相当于 4 个 OCPU 和 24 GB 内存容量。- 明确“架构”概念。

在具有多个可用性域的区域：

您可以在任何可用性域中创建 OCI Ampere A1 计算实例。
使用 `VM.Standard.E2.1.Micro` 规格的实例只能在一个可用性域中创建。

**可创建的计算实例数量 (Number of Compute Instances Available to Your Account)**

根据您分配给每个 OCI Ampere A1 计算实例的启动卷大小和 OCPU 数量，您最多可以创建四个计算实例。每个实例的最小**启动卷 (boot volume)** 大小为 47 GB，与规格无关。您的账户附带 200 GB 的永久免费**块存储 (block volume)** 空间，可用于创建计算实例的启动卷。

**计算实例的 IP 地址 (IP Addresses for Compute Instances)**

您不必为租户中的每个计算实例都分配一个公共 IPv4 地址。您可以在公共子网中创建没有公共 IP 地址的计算实例，也可以在私有子网中创建实例。

**空闲计算实例 (Idle Compute Instances)**

**重要提示：Oracle 可能会回收空闲的永久免费计算实例。** 如果虚拟机和裸金属计算实例在 7 天内的以下指标均满足条件，则会被视为“空闲”：

CPU 利用率的第 95 百分位数低于 20%
网络利用率低于 20%
内存利用率低于 20%（仅适用于 **A1 规格**）
- **块存储 (Block Volume)**

每个租户可获得总共 **200 GB** 的块存储空间和 **5 个卷备份**。这些容量适用于启动卷和块卷的总和。创建计算实例时，实例会自动获得一个 50 GB 的启动卷用于存储。您还可以创建和附加块卷来扩展计算实例的存储容量。
**重要提示：**

要创建永久免费的块卷，必须在租户的**归属区域**中创建。在归属区域之外创建的卷将产生常规块卷费用。
对于有资格获得永久免费资源的付费账户或免费试用账户，同样可以获得 200 GB 的永久免费卷资源和 5 个永久免费卷备份资源。当您删除一个永久免费资源时，部分永久免费资源容量将变为可用。当您拥有可用的永久免费容量时，块存储服务会自动尝试将现有的付费资源转换为永久免费资源。例如，如果您有四个 50 GB 的永久免费卷和一个 50 GB 的付费卷，并且您删除了其中一个永久免费卷，则该服务会将付费卷转换为永久免费卷。
- **对象存储和归档存储 (Object and Archive Storage)**

每个租户可获得总共 **20 GB** 的永久免费对象存储空间。
- **保险库 (Vault)**

所有通过软件进行保护的主加密密钥均免费。每个租户可获取 **20 个密钥版本**，这些版本由硬件安全模块 (HSM) 提供保护，此外还可获得 **150 个永久免费的密钥库 (Vault) 机密信息**。您可以将这些密钥或机密信息分散存储在租户内的任意数量的密钥库中，但请注意，虚拟专用密钥库不在永久免费资源之列
- **资源管理器 (Resource Manager)**

所有租户均可在资源管理器服务中获取一系列永久免费资源，从而利用 Terraform 实现基础设施配置流程的自动化。
**二、数据库 (Database)**
**Oracle Autonomous Database 自治数据库:** 每个租户均可获取两个永久免费的 Oracle Autonomous Database 实例。这些数据库实例可用于事务处理、构建数据仓库、开发 Oracle APEX 应用程序或基于 JSON 的应用程序开发。
- **Oracle NoSQL Database:** 每个租户可获得一个 Oracle NoSQL Database，每月最多支持 1.33 亿次读取、1.33 亿次写入，以及 3 个表，每个表 25 GB 存储空间。
- **Oracle HeatWave:** 每个租户在归属区域中获得一个独立的 HeatWave 数据库系统，其中包含一个单节点 HeatWave 集群。永久免费的数据库系统具有 50 GB 的存储空间来存储数据和日志文件。还提供额外的 50 GB 备份存储空间。
**三、网络 (Networking)**
- **集群放置组 (Cluster Placement Groups)**

根据服务的定价模式，每个租户在一个区域中可以获得 10 到 50 个永久免费的集群放置组。
- **负载均衡 (Load Balancing)**
对于 2020 年 12 月 15 日及之后创建的所有 Oracle Cloud Infrastructure 租户，均可获取一个永久免费的灵活负载均衡器实例，该实例的最小和最大带宽均设置为 10 Mbps。
- **网络负载均衡器 (Network Load Balancer)**

作为永久免费资源的一部分，您将获得一个网络负载均衡器。
- **虚拟云网络 (VCNs)**

免费套餐租户（非付费且没有免费试用额度的租户）最多可以拥有 2 个虚拟云网络 (VCN)。VCN 是您在特定区域的 Oracle Cloud Infrastructure 数据中心中设置的软件定义网络。VCN 包括 IPv4 和 IPv6 支持。
默认情况下，不允许租户通过出站 TCP 端口 25 向 Internet 发送电子邮件。如果您需要从您的租户发送电子邮件，请**提交服务限额申请 (open a service limits request)** 以获得豁免。
- **VCN 流日志 (VCN Flow Logs)**

为了帮助您审核进出 VCN 中虚拟网络接口卡 (VNIC) 的流量，并对您的**安全列表 (security lists)** 进行故障排除，您可以设置 *VCN 流日志*。流日志记录根据安全列表规则已接受或拒绝的流量的详细信息。免费套餐租户每月可获得最多 10GB 的共享 OCI **日志记录服务 (Logging service)** 流量。
- **站点到站点 VPN (Site-to-Site VPN)**

站点到站点 VPN 在您的本地网络和虚拟云网络 (VCN) 之间提供站点到站点的 IPSec 连接。您的免费套餐账户最多可以使用 50 个 IPSec 连接。
**四、可观察性和管理 (Observability and Management)**
- **应用性能监控 (Application Performance Monitoring)**

每个租户可获得每小时 1000 个应用性能监控跟踪事件和 10 次综合监控运行。
- **连接器中心 (Connector Hub)**

每个租户可获得 2 个永久免费的**连接器**。连接器中心帮助云工程师管理数据并在 Oracle Cloud Infrastructure (OCI) 服务之间以及从 OCI 到第三方服务之间移动数据。
- **控制台仪表板 (Console Dashboards)**

每个租户可获得 100 个仪表板。
- **电子邮件交付 (Email Delivery)**

作为永久免费资源的一部分，您每月可以免费发送 3000 封电子邮件。
- **队列应用程序管理 (Fleet Application Management)**

作为永久免费资源的一部分，所有租户每月均有权免费管理前 25 个资源（涵盖计算实例和数据库等）的系统生命周期操作
- **监控 (Monitoring)**

每个租户可获得 5 亿个监控服务摄取数据点和 10 亿个检索数据点。
- **通知 (Notifications)**

作为永久免费资源的一部分，您每月可以发送 100 万个 https 通知和 1000 个电子邮件通知。
**五、附加服务 (Additional Services)**
- **出站数据传输 (Outbound Data Transfer)**

作为永久免费资源的一部分，您每月可获得 10 TB 的出站数据流量。
- **日志记录 (Logging)**

日志记录为您的租户中的所有日志提供了一个高度可扩展且完全托管的单一管理平台。
- **堡垒机 (Bastion)**

OCI 的堡垒机服务为没有公共端点的目标资源提供受限且有时间限制的安全 Shell 协议 (SSH) 访问。堡垒机对免费账户和付费账户都是免费的。
**六、服务用量和限制 (Service Usage and Limits)**
您可以在 Oracle 云控制台中查看您租户的永久免费资源限额。要查看这些限额：打开导航菜单并单击 **治理和管理 (Governance & Administration)**。在 **租户管理 (Tenancy Management)** 下，单击 **限额、配额和用量 (Limits, Quotas and Usage)**
