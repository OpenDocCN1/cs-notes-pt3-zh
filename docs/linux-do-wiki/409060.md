6、魔搭modelscope，如果![:ladder:](https://linux.do/images/emoji/twemoji/ladder.png?v=12)不给力HF下不动才需要考虑这个



[Deepseek-r1](https://www.modelscope.cn/models/deepseek-ai/DeepSeek-R1)



[Deepseek-v3](https://www.modelscope.cn/models/deepseek-ai/DeepSeek-V3)

7、Ollama部署，在以上两个非量化模型私有化部署时候遇到困难的，比如说显存太小ollama都是4bit量化模型，显存需求量只有原生非量化模型的1/4，比如说没有N卡，只有A卡、M系列的苹果电脑、甚至只有CPU



[Deepseek-r1](https://ollama.com/library/deepseek-r1)



[Deepseek-v3](https://ollama.com/library/deepseek-v3)

8、论文，想要学习训练思想的可以看看



[[2501.12948] DeepSeek-R1：通过强化学习激励 LLM 中的推理能力](https://arxiv.org/abs/2501.12948)



[Paper page - DeepSeek-R1 | hugging face](https://huggingface.co/papers/2501.12948)

其他注意事项：



v3版本只有671b模型，如果自己N卡配置不够¥300万的就可以直接忽略了。按说能关注这个的佬也不惜的看这种扫盲贴了。
