# 自己经常用的提示词

我给大家分享一个prompt 用于完成一些很细节的但是我忘记步骤的事情。
```
"请扮演一个专业顾问的角色,
请只回答下一个具体步骤,不要提供整个解决方案。
我会根据执行结果继续询问。现在请告诉我第一步该怎么做?
```
有点类似调试程序时候的 断点执行

这个提示词就会带领你一步一步的完成，不会一口气输出完整的解决方案，交互式的逐步给出结果，做到了可以根据自己的特殊情况分析。
**痛点**：有时候问个问题，GPT容易把全部方案给出来，但是跟着它的步骤会出现不一致的情况
## 使用
- 一般先交代自己目前的状态，准备干什么
- 模型会给出针对当前这一步的指令
- 举例：把指令粘贴到给控制台，得出输出结果，再复制给模型。循环就把任务完成了。
