# 基础知识

- 大饼：BTC，比特币，市值最高的加密货币，也是最早的加密货币

- 二饼：ETH，以太坊

- 山寨币（Altcoin）：除了比特币以外的代币都算作山寨币，一般不带有贬义

- 垃圾币（Shitcoin）：指表现不好的山寨币，带有贬义

- 稳定币：价值以某些方式锚定美元USD的币，是用来锁定收益的重要工具。目前使用最广的是USDT，常见的还有USDC。

- 币对：币对是交易市场中两种加密货币之间的交易对，比如BTC/USDT，币对可以是稳定币本位（如USDT），也可以是币本位（如BTC、ETH）的交易对。

- 币本位：以数字货币作为结算的方式，例如BTC、ETH，例如ETH/BTC。

- U本位：一般指以 USDT 作为结算的方式，例如BTC/USDT

- MEME币/迷因币/模因币：meme在英文中的意思类似于中文的“梗”，这类币种一般是炒作某个话题或热点的，最早的有马斯克多次发推文支持的DOGE（狗狗币），源自doge狗头表情包，还有近期的TRUMP币。这些币大多没有任何实用价值，发币门槛较低，完全是用来炒作用的，风险极大，绝大多数币种在发行之后会**归零**。

- VC币：指“雷声大，雨点小”的币，一般在宣传的时候夸大实际价值，而在上线之后表现很差的币，价格连续下跌的币。

- 交易所：一般指中心化的加密货币交易地点，类似于股票的券商。常见的有币安、欧易、Coinbase、Bybit等

- 入金/出金：从交易所转入/转出资金，实现法币和虚拟货币互换的行为

- USDT：如上所述的稳定币，一般以此为单位进行交易活动，简称 **U**

- 热钱包：能够连接网络的钱包，一般指交易所内的钱包

- 冷钱包：可以不联网的钱包，一般用于离线储存或安全性

# 交易

- C2C/P2P：指在平台中可以和其他用户买u卖u的操作

- 现货：指某链的代币本身（平台可能也支持杠杆）

- 合约：分为永续合约和交割合约，其中永续合约通常被圈内玩家用来开高倍杠杆（例如币安最高可达125x，部分小平台有更高的杠杆）

- 爆仓：上杠杆后（尤其是玩合约）被强制平仓，本金几乎被亏光的情况。（新手最好远离高倍合约，不要问我怎么知道的）

- HODL：意为长期持有加密货币不抛售，也指囤币、囤仓的投资策略

- 多头/空头 (头寸)：多头看涨市场，预期价格会上涨，通过低买高卖获利；空头则相反

- 锁仓：为了锁定利润或减少亏损的行动，例如在做空了上涨中的币，这时候再开一个多头仓位来抵消空头仓位的亏损（但是会失去两倍手续费，因为开了两个仓）

- 蚂蚁仓：指一个特别小的仓位，一般用于探路或开着玩

- 跟单：平台提供的功能，可以通过复制其他**交易员**的操作，是一种投资管理工具，但会产生一定费用（将盈利分润给交易员）

- 客损：指交易员会故意操作，让跟单的人亏损，从而成为 平台或交易员的盈利(也不完全一定)

- 资金费率： 锚定永续合约价格，防止价格偏离现货过大的机制。永续合约中多头头寸和空头头寸每隔一段进行一次费率往来，因为永续合约没有到期日，如果一直持有会导致价格偏离现货，所以会有资金费率

- 套利：买入低价资产卖出高价资产的行为。在合约中，如果资金费率为正，可以通过**做空**，买入现货来盈利，反之同理；在不同的平台间，币的价格也可能略有不同，也可以通过这点来实现套利

# 行情

- FOMO：“Fear of Missing Out”，害怕错过的意思，很多时候人们因为害怕错过下一波市场的大行情而盲目跟随热度的行为

- 踏空：指行情突然上升或下跌，但自己并没有建立头寸的情况

- 瀑布：指行情突然下跌，像瀑布一样，飞流直下，一般伴随着跌幅逐步扩大的特点。

- 归零：指币价跌去绝大部分的情况，跌幅可以超过-99%甚至更多，在未来几乎不可能重回高点。

- 黑天鹅：一般指圈内币种短时间暴跌的行情，部分山寨币可暴跌30-50%

- ATH：All Time High，指历史高点

- 插针：指价格短时向一个方向运动，后续又迅速收回的行情，留下长上/下影线的行情。这种行情往往使得一些高杠杆仓位止损或是爆仓，清理杠杆

- 天地针：和插针相似，但是天地针一般会走出向上向下的极端趋势，一般清理掉高倍杠杆

# 空投

- 空投（AirDrop）：项目方免费发放代币给特定用户群体，以获得关注的营销行为

- 撸毛：一般指工作室或者使用自动化脚本进行大量获取**空投**获利的行为

- 女巫（地址）：被项目方检测到疑似一个用户控制多个**空投**地址以获取额外利益的行为

- 指纹浏览器：也称为防关联浏览器，是一种专门设计用于隐藏或修改浏览器指纹，防止被项目方关联其他账号（也就是反女巫）

# 区块链

- 区块链：一种**去中心化的分布式账本技术**，使用密码学和共识机制来安全地存储交易数据。

- 地址：地址是一个**唯一的标识符**，由一串字母和数字组成，用于在区块链网络中识别一个加密货币钱包，类似于银行账户号码。

- 钱包：管理区块链密钥和地址的工具，使用户能够管理自己的区块链账户，并与去中心化应用（dApp）交互。常见的有MetaMask、OKX钱包等。

- 锁仓：锁定一部分加密货币资产，在一段时间内不能进行交易或转移

- 挖矿：挖矿是指消耗巨大算力，通过计算复杂的数学难题来验证交易，并将新的交易数据添加到区块链上的过程。

- 矿工：使用大量设备或资源进行挖矿的角色

- 智能合约：以信息化方式传播、验证或执行合同的计算机协议，实际上是一种基于区块链的计算机程序。常用的智能合约编程语言有Solidity（以太坊）。

- CA（地址）：每个智能合约在部署到区块链时都会生成一个唯一的地址。CA地址用于标识某个智能合约。

- Pow证明（Proof of Work）：又称工作量证明，通过计算复杂的数学运算获取记账权，并获取奖励

- Pos证明（Proof of Stack）：又称权益证明，通过质押更多的代币，提高成为"验证者"的概率，来负责验证和创建交易/区块（如果行为不端，则可能会失去一定或全部质押的代币）

- 质押：代币持有者可以通过"质押"来一定时间，维持区块链网络运营 (Pos权益证明)，并获取一定的奖励

- 链上：指区块链上。一般和中心化交易所（CEX）相对，指在区块链上进行交易的行为

- 流动性：加密货币资产能够快速、轻松地以接近其市场价值的价格进行交易或交换的能力

- NFT（非同质化代币）：是一种基于区块链技术的数字资产，例如数字藏品，数字艺术品等

- DeFi：去中心化金融。一般在去中心化交易所（DEX）或其他协议中进行交互

- gas费/燃料费：用于完成链上交易的手续费，支付给区块链的验证者（如挖矿者）价格和链上拥挤程度呈正相关，可用此衡量链上交易的活跃程度

- 跨链桥：不同的区块链之间进行信息和价值传递的技术，让两个孤立的区块链能够交互

- 打狗：在链上进行meme币投机的行为

- 土狗：泛指meme币

- 金狗：表现较好，没有短期归零，在短时间内市值突破一定量级，甚至能上一些中心化交易所的币种。

- PVP：因为链上进行meme币投机行为风险极大，近乎是零和博弈，因此这类行为被称作PVP
