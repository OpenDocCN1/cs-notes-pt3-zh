# 愚人节，带你走进愚者的世界



如果你没看过《诡秘之主》，也没有听过《诡秘之主》，那就容我介绍一下。

《诡秘之主》是一部由爱潜水的乌贼所著的奇幻小说，讲述了在一个充满神秘力量的世界中，人们通过各种途径获得超凡能力的故事。通过特定的途径和仪式获得了超越常人能力的个体被称为**超凡者**，而**途径**和**序列**是构成超凡体系的核心概念，它们是超凡者获得力量的方式和升级的品阶。**愚者途径**是其中一种重要途径，它具有独特的序列和晋升方式。其核心权柄即是愚弄，愚弄又可分为隐秘和重组。下面是它的序列介绍和能力。

| 序列9 | 小丑 | 小丑是愚者途径的起始序列，他们通常拥有一定的表演能力和操控气氛的能力。小丑们擅长通过幽默和戏谑来缓解紧张的气氛，同时也能在一定程度上影响他人的情绪。 | 操控一定范围内的气氛，使人们感到愉快或者放松；通过表演吸引他人的注意力。 |

| 序列8 | 魔术师 | 魔术师是愚者途径的第二个序列，他们不仅继承了小丑的表演能力，还开始掌握一些基础的魔法技巧。魔术师们能够通过魔术表演来掩盖他们的超凡能力，使得他们的行动更加隐秘。 | 进行基础的魔法表演，如制造幻象、操控小物体等；通过表演来掩盖自己的超凡行为。 |

| 序列7 | 无面者 | 无面者是愚者途径的第三个序列，他们开始能够改变自己的外貌，甚至模仿他人的声音和举止。无面者擅长潜入和间谍活动，能够在不同的场合中隐藏自己的真实身份。 | 改变自己的外貌和声音，模仿他人；在一定程度上读取他人的情绪和意图。 |

| 序列6 | 秘法师 | 秘法师是愚者途径的第四个序列，他们对神秘学和奥秘有着深刻的理解。秘法师们能够解读复杂的神秘符号和咒语，甚至能够创造出自己的神秘仪式。 | 解读和创造神秘符号；进行复杂的神秘仪式，获得特定的超凡效果。 |

| 序列5 | 守秘人 | 守秘人是愚者途径的第五个序列，他们拥有守护秘密和知识的能力。守秘人们能够将重要的信息和知识隐藏在他们的神秘空间中，防止被他人发现。 | 创建和维护一个神秘的空间，用以保存秘密和知识；在一定程度上抵抗精神入侵和探测。 |

| 序列4 | 秘仪导师 | 秘仪导师是愚者途径的第六个序列，他们不仅能够传授神秘知识，还能够引导他人完成神秘的仪式和晋升。秘仪导师们在神秘学界拥有崇高的地位。 | 传授神秘知识，引导他人完成神秘仪式；在一定程度上预知未来的事件。 |

| 序列3 | 秘术大师 | 秘术大师是愚者途径的第七个序列，他们掌握了大量高级的神秘技巧和魔法。秘术大师们能够运用他们的知识和能力来影响世界的运行。 | 掌握和运用高级的神秘技巧和魔法；在一定程度上改变现实。 |

| 序列2 | 隐者 | 隐者是愚者途径的第八个序列，他们能够隐匿自己和他人的存在，甚至能够从世界的感知中消失。隐者们通常过着隐居的生活，避免与外界的接触。 | 隐匿自己和他人的存在；从世界的感知中消失，避免被探测。 |

| 序列1 | 神秘学者 | 神秘学者是愚者途径的第九个序列，他们对神秘学和奥秘有着极致的理解。神秘学者们能够解读宇宙的秘密，甚至能够与高等存在进行交流。 | 解读宇宙的秘密，与高等存在进行交流；掌握和运用极端高级的神秘技巧。 |

| 序列0 | 愚者 | 愚者是愚者途径的最终序列，他们拥有无与伦比的智慧和知识。愚者们能够看穿一切虚妄，理解宇宙的真理。他们的存在本身就是一种神秘的象征。 | 看穿虚妄，理解宇宙的真理；掌握和运用至高的神秘力量。 |
