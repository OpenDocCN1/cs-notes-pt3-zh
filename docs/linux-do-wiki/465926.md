# OpenVPN服务端搭建，带GUI管理界面【Docker】



# 简介

本来打算使用k3s组一个集群, 由于龟壳的amd服务器性能非常差，作为master节点负担有点重，所以打算用家里的j1900和龟壳组VPN搭集群，于是去摸索VPN搭建就有了这个教程。



目前市面上常见的组建vpn网络技术主要有wireguard和openvpn。但是wireguard仅支持udp进行传输，在国内某些地区传输可能并不稳定，尤其是在组建跨国网络时，实测下来连接效果非常感人。

本教程基于项目

# 服务端搭建

## compose文件创建

教程采用docker-compose的方式进行部署，在此之前附上一个私有网络地址表

![Clip_2025-03-02_12-47-49716×262 47.5 KB](https://cdn3.ldstatic.com/original/4X/a/b/b/abb4bd61c74f689d5d07df7acbd118956ddae145.jpeg)

如果你已经有部署tailscale，则不要使用10.0.0.0/8网段，这里我使用的是172.20.0.0/16网段

注意下这里的三个变量

`TRUST_SUB`：这是你组建vpn的虚拟网段，vpn组建完成后每个主机都会在这个网段下分配一个IP

`GUEST_SUB`：作用如其名

`HOME_SUB`： 打个比方如果你路由器安装openvpn，这里如果填写路由器所在的真实ip网段，那么连接到vpn的主机可以通过路由器访问到这个网段下的其他主机，如果你不想用这个功能可以随意填写到一个不存在的网段

![image552×106 8.18 KB](https://cdn3.ldstatic.com/original/4X/2/6/d/26de8762b6fac5e82510317fa46dbdbe85ae7122.png)

```
---
version: "3.5"

services:
    openvpn:
       container_name: openvpn
       image: d3vilh/openvpn-server:latest
       privileged: true
       ports:
          - "1194:1194/tcp"
       environment:
           TRUST_SUB: 172.20.0.0/24  # 已修改为你需要的子网
           GUEST_SUB: 172.20.1.0/24  # 也可以修改，保持与主子网不冲突
           HOME_SUB: 192.168.88.0/24  # 这是你的家庭网络，可能不需要修改
       volumes:
           - ./pki:/etc/openvpn/pki
           - ./clients:/etc/openvpn/clients
           - ./config:/etc/openvpn/config
           - ./staticclients:/etc/openvpn/staticclients
           - ./log:/var/log/openvpn
           - ./fw-rules.sh:/opt/app/fw-rules.sh
           - ./server.conf:/etc/openvpn/server.conf
       cap_add:
           - NET_ADMIN
       restart: always

    openvpn-ui:
       container_name: openvpn-ui
       image: d3vilh/openvpn-ui:latest
       environment:
           - OPENVPN_ADMIN_USERNAME=admin
           - OPENVPN_ADMIN_PASSWORD=gagaZush
       privileged: true
       ports:
           - "8080:8080/tcp"
       volumes:
           - ./:/etc/openvpn
           - ./db:/opt/openvpn-ui/db
           - ./pki:/usr/share/easy-rsa/pki
           - /var/run/docker.sock:/var/run/docker.sock:ro
       restart: always
```

## 配置文件生成

```
nano server.conf
```

```
management 0.0.0.0 2080  # Don't change this line. OpenVPN UI uses this feature to manage the server

dev tun
port 1194
proto tcp

topology subnet
keepalive 10 120
max-clients 100

persist-key
persist-tun
explicit-exit-notify 1

user nobody
group nogroup

client-config-dir /etc/openvpn/staticclients
ifconfig-pool-persist pki/ipp.txt

ca pki/ca.crt
cert pki/issued/server.crt
key pki/private/server.key
crl-verify pki/crl.pem
dh pki/dh.pem

tls-crypt pki/ta.key
tls-version-min 1.2
remote-cert-tls client

cipher AES-256-GCM
# ncp-ciphers AES-256-GCM:AES-192-GCM:AES-128-GCM   # Deprecated since ver. 0.9.3. We have to use data-ciphers below instead
data-ciphers AES-256-GCM:AES-192-GCM:AES-128-GCM

auth SHA512

server 172.20.0.0 255.255.255.0           # Trusted VPN subnet
route 172.20.1.0 255.255.255.0            # Route to Guest VPN subnet
push "route 192.168.6.0 255.255.255.0"     # Route to Home VPN subnet
push "dhcp-option DNS 8.8.8.8"             # DNS1 server for VPN clients
push "dhcp-option DNS 1.0.0.1"             # DNS2 server for VPN clients
push "redirect-gateway def1 bypass-dhcp"    # Redirect gateway for VPN clients

log /var/log/openvpn/openvpn.log
verb 3
status /var/log/openvpn/openvpn-status.log
status-version 2

# Custom Option One
# Custom Option Two
# client-to-client
# Custom Option Three
# push "route 0.0.0.0 255.255.255.255 net_gateway"
# push block-outside-dns

# Auto generated by OpenVPN-UI v.0.9.5.6
```

# 客户端连接

在Certificates点击用户名下载ovpn文件，需要的话可以使用记事本进行编辑

```
client
dev tun
proto tcp
remote 192.168.61.109 1194 tcp
...
```

remote可以根据需求进行修改，内网穿透则直接填写穿透地址

windows直接操作即可，这里补充一下linux的使用方法

参考文档[OpenVPN3Linux – OpenVPN Community](https://community.openvpn.net/openvpn/wiki/OpenVPN3Linux)将openvpn3安装到服务器

1. 导入配置文件

```
openvpn3 config-import --config /path/to/your/config.ovpn
```

1. 连接vpn

**2.1 使用配置文件路径连接vpn**

`openvpn3 session-start --config /path/to/your/config.ovpn `

2.2 **使用导入后的配置标识符**

`# 列出所有已导入的配置 openvpn3 configs-list  # 使用配置名称或路径标识符连接 openvpn3 session-start --config-path /net/openvpn/v3/configuration/d45d4263-d7d6-4911-b4e3-b25e31f8f7ab `

2. 管理连接状态

```
openvpn3 sessions-list
openvpn3 session-stats --path /net/openvpn/v3/session/27adb21f-0393-4be6-9f3e-c1f9386c8dd7
```

1. 断开连接

```
# 使用会话路径断开
openvpn3 session-manage --disconnect --path /net/openvpn/v3/session/27adb21f-0393-4be6-9f3e-c1f9386c8dd7

# 或者如果只有一个活动会话
openvpn3 session-manage --disconnect
```

1. 删除连接信息

```
openvpn3 config-remove --path /net/openvpn/v3/configuration/d45d4263-d7d6-4911-b4e3-b25e31f8f7ab
```

1. 自动连接

```
# 首先创建一个systemd服务文件
sudo nano /etc/systemd/system/openvpn3-session.service

# 添加以下内容
[Unit]
Description=OpenVPN3 Session
After=network-online.target

[Service]
Type=simple
ExecStart=/usr/bin/openvpn3 session-start --config /path/to/your/config.ovpn
Restart=on-failure

[Install]
WantedBy=multi-user.target

# 保存并启用服务
sudo systemctl enable openvpn3-session.service
sudo systemctl start openvpn3-session.service
```

1. 日志查看

```
openvpn3 log --session-path /net/openvpn/v3/session/27adb21f-0393-4be6-9f3e-c1f9386c8dd7
```
