# Gmail注册指北



## **Part 0 前言及前期准备**

本指南适用于目前居住地点在国内且没有高度纯净的节点的佬友

所需准备：

1. 中国国内的带电话卡手机或其他能够收到短信的工具

2. 可使用的电脑，目前仅支持Windows操作系统

3. 不限纯净度的节点*1，能访问外网就行(注册时最好处于该地区时间午夜左右，即当地时间AM两三点）
