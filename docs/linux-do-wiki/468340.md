### **第1章：Markdown简介与基础语法**

---

#### **1.1 什么是Markdown？**

Markdown 是一种轻量级标记语言，通过简单的符号（如 `#`、`*`、`>`）快速格式化文本，可转换为HTML或其他格式。它的核心目标是：

- **易读易写**：纯文本中直接添加格式，无需复杂代码。

- **跨平台兼容**：支持几乎所有编辑器、协作工具（如GitHub、Notion）和静态网站生成器（如Hexo、Hugo）。

---

#### **1.2 为什么选择Markdown？**

- **高效**：比Word等富文本编辑器更专注于内容创作。

- **通用性**：兼容代码仓库文档（README.md）、笔记软件（Obsidian）、博客写作等场景。

- **未来友好**：纯文本永不过时，且可版本控制（如Git）。

---

#### **1.3 基础语法示例**

##### **1.3.1 标题**

```
# 一级标题
## 二级标题
### 三级标题
```

效果：

# 一级标题

## 二级标题

### 三级标题

##### **1.3.2 段落与换行**

- **段落**：直接输入文字，段落间空一行。

- **换行**：行尾添加两个空格或空一行。

#### 段落

段落是指一段连续的文字内容。要创建一个新的段落，请在两个段落之间**空一行** 。例如：

这是第一个段落。



它包含了一些文字内容，描述了段落的基本定义和用法。

这是第二个段落。



通过在两个段落之间空一行，可以清晰地分隔不同的内容。

#### 换行

换行是指在同一段落内，将文字分成两行显示。要实现换行，可以在行尾添加**两个空格** ，或者直接空一行。以下是两种方法的示例：

##### 方法1：行尾添加两个空格

这是第一行文字，行尾有两个空格（看不到，但它们存在）。



这是第二行文字，它会紧接在第一行之后显示。

##### 方法2：空一行

这是第一行文字。

这是第二行文字，通过空一行实现了换行效果。

```
这是第一段（末尾无空格）
这是同一段的强制换行（末尾两空格）

这是新段落（空一行分隔）
```

##### **1.3.3 粗体与斜体**

```
**粗体文本** 或 __粗体文本__
*斜体文本* 或 _斜体文本_
***粗体且斜体***
```

效果：



**粗体文本** *斜体文本* *粗体且斜体*
