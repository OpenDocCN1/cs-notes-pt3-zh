# 打算给上大一的侄女外甥写篇《网络生存指南》系列教程，大家觉得应该写什么？



侄女和外甥今年都大一，这俩一个北邮一个中财，而且以后和互联网打交道的几率极大，感觉他们还有很多东西不会，而且我估计很多东西学校永远也不会教，考虑给他们写个教程，以下是暂定章节：



1、科学上网，拥抱更广阔的世界（远离百度）：



说说科学上网那些事儿，以及把我的个人配置和节点共享给他们。



2、不是所有的信息都是好信息（广告、垃圾网站、内容农场屏蔽）



说说广告屏蔽和内容农场屏蔽的方法。



3、内外网络冲浪指南（多看少说，注意甄别）



说说一些外网的大概情况，告诉他们网络并非法外之地，即便是外网也一样，游走在灰色地带要注意安全，更要保护自己。



4、网络时代的数据安全指南



说说个人账号的密码设计、密码保护之类的事情。



5、搜索引擎使用指南



大概就是说说谷歌的用法，以及一些小功能。



6、信息时代的纷扰与自我隔离



说说信息时代的过量信息如何过滤，一些比较好的信息类网站等等



7、那些很强也很麻烦的AI们



说说如何使用现在最强的AI，以及如何使用工具高效利用它们（NOI，cherry studio）



外篇、男生女生那些事儿



嗯，说说某些网站，咳咳，你们懂的，他们反正成年人了，与其让他们自己乱找各种不靠谱的，不如给他们推荐一下，这个我还在纠结，我是长辈嘛。



通用类的感觉就这些，剩下的就是他们想要了解什么领域，就给他们写什么教程了。
