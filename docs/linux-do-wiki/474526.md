# 把本地电脑上txt,md,pdf文档加入cherry studio知识库

第一步：安装python。

下载地址：[Download Python | Python.org](https://www.python.org/downloads/)

第二步：让ai写个python脚本：要求把本地目录里的所有txt,md,pdf文件，以文件名创建xml格式的站点地图，给出具体python脚本。

下面是ai给出的脚本。

[generate_enhanced_sitemap.zip](/uploads/short-url/pgML4mpuLQa1Iqn7ReoDLyLKeXK.zip) (783 字节)
第三步：把脚本放到要生成站点地图的目录。

第四步：在上面地址栏输入cmd打开命令行。

第五步：运行脚本生成站点地图文件： python generate_enhanced_sitemap.py

第六步：运行一个简单http服务：python -m http.server 8000

第七步：把站点地图添加到cherry studio知识库,

地址：[http://127.0.0.1:8000/sitemap_enhanced.xml](http://127.0.0.1:8000/sitemap_enhanced.xml)
