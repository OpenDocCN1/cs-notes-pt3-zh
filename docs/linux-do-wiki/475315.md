# vscode 快捷键推荐



这里记录一些个人认为好用的**vscode特色的键盘/鼠标快捷键**，像保存文件、查找、替换之类，在其他软件中较为常见的，这里就不多赘述了。

更改快捷键位置：

![image552×393 62.1 KB](https://cdn3.ldstatic.com/original/4X/4/1/5/415af0427b6c1c48adfc1648e691f77fd2cf47dd.png)

查看vscode中指定快捷键的功能：

![image1966×144 46 KB](https://cdn3.ldstatic.com/original/4X/7/0/5/7056596ac7f74a5e7e87b8ff8f7be7fd5ac793b2.png)

| 功能 | 快捷键 |

| --- | --- |

| 打开命令面板 | Ctrl + Shift + P |

| 快速打开文件 | Ctrl + P |

| 最近打开过的项目 | Ctrl + R |

| 复制并创建相同的代码行（duplicate） | Shift + Alt + ↓/↑ |

| 移动代码行 | Alt + ↓/↑ |

| 多行编辑 | 鼠标中键拖动 \| Ctrl + Alt + ↑ / ↓ \| Alt + 分别鼠标点击 |

| 选中光标所在词（按一次额外多选一个同名的） | Ctrl + D |

| 注释/取消注释 | Ctrl + / |

| 转到定义 | Ctrl + 鼠标左键点击 \| F12 |

| 删除整行 | 自定义（我使用Alt + D） |

| 打开（收起）/ 创建底部终端 | Ctrl + J / Ctrl + ~ |

| 撤销刚刚关闭的文件（和浏览器一样） | Ctrl + Shift + T |

| 快速复制/剪切整行 | Ctrl + C / Ctrl + X （前提是光标没有选中字符） |

| 快速全局搜索 | Ctrl + Shift + F |

| 调整当前行的缩进 | Ctrl + [ / Ctrl + ] |

| 快速跳转文件开头/末尾 | Ctrl + Home / End |

| 快速横向移动光标（实际上是跳转到词首/词尾） | Ctrl + ← / → |

Cursor 专属：

| 功能 | 快捷键 |

| --- | --- |

| Ctrl + K | 对选中的字段进行AI修改 |

| Ctrl + L | 打开/收起对话窗口 |

| Ctrl + Enter | 对话以codebase模式发送（让AI参考所有文件） |

快捷键这个东西，个人觉得不需要强求，选自己用的顺手的就行了！欢迎佬友补充！
