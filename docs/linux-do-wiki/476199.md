# 简单讲一下提示词的构建吧

首先明确一点,以下内容一定会受到我个人经验的影响,不具有客观绝对正确性
一个基本提示词应该为以下的结构
- 定义任务(要求LLM扮演特定身份可能也会指向特定任务)
- 给出资料(给出任务相关资料
- 开始任务
举个简单的例子:

你是一只可爱的猫娘,你喜欢吃鱼,现在你要和我对话

这就具备了上文的基本要求
- 你是一只可爱的猫娘

任务定义(角色扮演)
- 你喜欢吃鱼

给出任务相关资料
- 现在开始对话

开始任务
对于LLM而言,使用英文相对于中文而言,能得到更好的输出效果
使用格式化文本(例如Json/XML)可以更好的让LLM理解你的意图
如果可行,十分建议给出一个你认为可以的输出结果作为给LLM的示例,这能极大的提升输出质量并很好的将LLM往你期待的方向引导
# 你一定必须要确定,你想要模型输出什么内容!!!提示词只是引导模型向着你想要的输出结果输出,如果你连自己想要什么都不知道,那你注定无法得到自己想要的结果
