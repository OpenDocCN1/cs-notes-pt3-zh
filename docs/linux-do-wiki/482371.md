# 使用国内镜像安装pytorch GPU加速版本



NJU提供了pytorch GPU加速版本的国内镜像。

例如安装cuda12.6版本适配的pytorch

项目中的配置如下。

```
[[tool.uv.index]]
name = "nju"
url = "https://mirror.nju.edu.cn/pypi/web/simple"

[[tool.uv.index]]
name = "pytorch"
url = "https://mirror.nju.edu.cn/pytorch/whl/cu126"

[tool.uv.sources]
torch = { index = "pytorch" }
torchvision = { index = "pytorch" }
torchaudio = { index = "pytorch" }
```

此镜像同样可以加速pip
