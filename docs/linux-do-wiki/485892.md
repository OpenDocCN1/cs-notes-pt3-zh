# OpenGauss 容器版主备库搭建总结

#### **1. 概述**
本文档总结了在两台物理机上使用 Docker 部署 OpenGauss 主备库的详细过程，包括遇到的问题及其解决方案。主备架构旨在实现高可用性和数据同步，主库负责处理读写请求，而备库保持与主库的数据同步，以备主库故障时接管服务。
---
#### **2. 环境配置**
##### **2.1 目标架构**
| **角色** | **物理机 IP** | **容器名称** | **数据库服务端口** | **宿主机端口** | **挂载目录** |
| --- | --- | --- | --- | --- | --- |
| 主库 | `10.128.244.182` | `opengauss_primary` | `5432` | `5432` | `/opt/platform/opengauss/data` |
| 从库 1 | `10.128.244.183` | `opengauss_standby1` | `5432` | `5432` | `/opt/platform/opengauss/data` |
##### **2.2 软件版本**
- **镜像**: enmotech/opengauss:3.1.1
- **Docker**: 3.4.4
- **操作系统**: openeuler 22.03
##### **2.3 前置要求**
1. 确保三台物理机之间网络互通。
2. 安装 Docker 并启动服务。
3. 开放防火墙端口：
```
firewall-cmd --add-port=5432/tcp --permanent
firewall-cmd --add-port=5434/tcp --permanent
firewall-cmd --reload
```
---
#### **3. 搭建主备库的过程**
##### **3.1 启动主库容器**
在主库物理机（`10.128.244.182`）上运行以下命令：
```
docker run --name opengauss_primary -h opengauss_primary \
--privileged=true \
--network=host \
-v /opt/platform/opengauss/data:/var/lib/opengauss/data \
-e GS_PORT=5432 \
-e OG_SUBNET="10.128.244.0/24" \
-e GS_PASSWORD=Enmo@123 \
-e NODE_NAME=opengauss_primary \
-e REPL_CONN_INFO="replconninfo1 = 'localhost=10.128.244.182 localport=5434 localservice=5432 remotehost=10.128.244.183 remoteport=5434 remoteservice=5432'\n" \
-d enmotech/opengauss:3.1.1 -M primary
```
##### **3.2 启动从库容器**
在从库物理机（`10.128.244.183`）上运行以下命令：
```
docker run --name opengauss_standby1 -h opengauss_standby1 \
--privileged=true \
--network=host \
-v /opt/platform/opengauss/data:/var/lib/opengauss/data \
-e GS_PORT=5432 \
-e OG_SUBNET="10.128.244.0/24" \
-e GS_PASSWORD=Enmo@123 \
-e NODE_NAME=opengauss_standby1 \
-e REPL_CONN_INFO="replconninfo1 = 'localhost=10.128.244.183 localport=5434 localservice=5432 remotehost=10.128.244.182 remoteport=5434 remoteservice=5432'\n" \
-d enmotech/opengauss:3.1.1 -M standby
```

#### **4. 遇到的问题及解决方案**
##### **4.1 无法绑定端口（Port binding failed）**
- **问题描述**：

在启动容器时，日志提示无法绑定 `5434` 端口：
`could not bind IPv4 socket at the 0 time: Cannot assign requested address `
- **原因分析**：

端口冲突或者网络配置不正确。
- **解决方案**：

检查端口是否被占用：

`netstat -tuln | grep 5434 lsof -i:5434 `
##### **4.2 主从同步失败**
- **问题描述**：

主库无法检测到从库，`pg_stat_replication` 中没有任何记录。
- **原因分析**：

`REPL_CONN_INFO` 配置错误。
主从库之间的网络不通。
- **解决方案**：

确保 `REPL_CONN_INFO` 中的 IP 和端口配置正确。
检查主从库之间的网络连通性：

` ping 10.128.244.183 `
##### **4.3 从库无法启动**
- **问题描述**：

从库容器启动后立即退出。
- **原因分析**：

从库的数据目录未正确初始化。
- **解决方案**：

删除从库的数据目录并重新启动容器。
确保主库运行正常，并且主库的复制配置正确。
---
#### **5. 总结**
通过本文档，您可以了解如何使用 Docker 快速部署 OpenGauss 主备库，并应对常见问题。以下是关键点总结：
1. **网络配置**：

使用 `--network host` 简化主从库之间的通信配置。
2. **主从同步**：

配置 `REPL_CONN_INFO` 参数时，务必确保 IP 地址和端口正确。
3. **验证同步状态**：

使用 `pg_stat_replication` 检查主库的复制状态，确保主从库同步正常。
