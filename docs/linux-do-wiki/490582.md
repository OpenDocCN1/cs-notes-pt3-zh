# 分享日用软件，第一期，密码管理



分享日用软件，第一期，密码管理

**结论：使用KeePassDX+KeePassXC组合**

**介绍：**



KeePass是一个免费开源的密码管理器应用程序，而KeePassXC，KeePassDX是KeePass的分支，可以看作是更现代化，更容易用的版本，分别对应电脑和android版本。

KeePass使用.kdbx文件储存密码文件，通过设置的**主密码**作为打开KeePass文件的锁匙，每次重启后需要先输入一次主密码，其后可以选择使用 生物识别解锁。

**使用KeePass的好处**：



只需要记忆主密码，其他密码可以使用由KeePass生成的复杂密码，并进行自动填充，不必记忆复杂密码。

软件下载：



手机端：[KeePassDX](https://github.com/Kunzisoft/KeePassDX/releases)



电脑端：[KeePassXC](https://github.com/keepassxreboot/keepassxc/releases) +[KeePassXC浏览器插件](https://chromewebstore.google.com/detail/keepassxc-browser/oboonakemofpalcgghocfoadofidjkkk)



同步软件：[坚果云(PC)](https://www.jianguoyun.com/) + [davx5(手机)](https://github.com/bitfireAT/davx5-ose)

同步方案 ：

1. 坚果云自动备份本地的密钥文件.kbdx

2. 设置坚果云WebDAV的密钥([教程](https://help.jianguoyun.com/?p=2064))

3. 手机安装davx5软件把WebDAV挂载到文件系统



[288e70d6c4c9a54755022ecf35ae0761080×649 72.9 KB](https://cdn3.ldstatic.com/original/4X/4/7/a/47a588f71f05ee107d7fe8e375d0447808236ef4.jpeg)

4. 手机KeepassDX打开现有储存库，选择WebDAV，并选择对应的.kbdx文件。



[b8026b69f705885198c53c1c00c8629900×209 35.2 KB](https://cdn3.ldstatic.com/original/4X/3/4/d/34d9545643cee2574122a1f656ba6b879df2be99.jpeg)

同步效果：



手机和电脑双向同步，电脑修改后，坚果云会自动同步到云端。而davx5挂载的方法会直接修改云端的数据，通过坚果云同步到电脑。
