## 食用

[GITHUB获取](https://github.com/3q-u/rime-trans)

`lua` 文件复制到用户目录下



`out-mingw` 复制到程序目录下

> 均可右键Rime快捷打开

>

> ps: out-mingw根据自己的系统选择

在您的输入方案配置文件（如 `<方案名>.schema.yaml`）中添加以下内容：

```
engine:
  filters:
    - lua_filter@*input_text   # 候选词翻译
```

## 目录结构

```
Rime
-- 用户文件夹/lua
      - input_text.lua
      - json.lua
      - trans-all.lua
      - log.lua(可选)
-- 小狼毫程序文件夹
      - simplehttp
```
