# android最新版3.2.10小鹤音形修改编码提示和候选字数

1. 改的原因：有时打不常用的音形会忘，就2个候选也没点提示，就把编码和字数放出来
2. 目前小鹤音形的软件不像以前可以直接修改rime的配置文件了，所以需要访问应用软件内的数据并进行修改。
## 步骤一：启用手机开发者选项，
> 可以自行百度
1. 打开手机的"设置"应用
2. 滚动到底部，找到"关于手机"选项
3. 多次点击"版本号"(通常是连续点击7次)，直到看到"您已成为开发者"提示
4. 返回设置主页，现在应该可以看到"开发者选项"
5. 进入开发者选项，启用"USB调试"
## 步骤二：在Mac上安装必要工具，因为我是在mac上修改的
1. 安装Homebrew(使用国内镜像源加速)：
```
/bin/bash -c "$(curl -fsSL https://gitee.com/cunkai/HomebrewCN/raw/master/Homebrew.sh)"
```
1. 使用Homebrew安装ADB工具：
```
brew install android-platform-tools
```
## 步骤三：连接手机与电脑
1. 用USB数据线连接手机和电脑
2. 手机上会弹出USB调试权限请求，选择"允许"，就能看到设备了
## 步骤四：访问输入法配置文件
1. 打开弹出的文件目录，点开/Android/data目录找到 com.flypy.input,如图

将圈出来的修改成注释里的，比如我想总是提示编码就把hint设置成1,然后候选词数量修改成7,其他也可以自定义
