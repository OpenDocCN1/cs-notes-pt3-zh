# Ollama 模型国内加速下载镜像源



其实 ollama 官方下载地址用的 cloudflare r2 cdn 的下载速度也非常快了，如果你跑不满网速的话可能是走了你的梯子，关掉代理重新下载就行。

Ollama 也支持断点续传，如果速度变慢了，Ctrl + C 停止下载，然后重新运行 pull 命令下载就会继续满速下载了。

下面是国内镜像教程：

```
ollama pull modelscope.cn/unsloth/gemma-3-27b-it-GGUF
```

在 [https://modelscope.cn/models](https://modelscope.cn/models)



找到想要的模型，注意搜 GGUF 格式的，然后点击模型名字右侧的复制按钮，替换`unsloth/gemma-3-27b-it-GGUF`。比如下载 Deepseek 模型

```
ollama pull modelscope.cn/models/unsloth/DeepSeek-R1-Distill-Qwen-32B-GGUF
```
