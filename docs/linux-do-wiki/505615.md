# Warp Terminal 文件上传优化攻略



在 Warp 终端中复刻经典体验：打造超流畅的 zmodem 文件传输

在 Windows 上使用 Xshell 的用户，Linux 上使用 Konsole 的用户应该都对他们 zmodem 文件上传的体验记忆犹新。通过简单的快捷键操作即可实现拖拽式文件传输，这种丝滑体验已然成为终端老玩家的标杆记忆。如今，作为下一代 AI 驱动的智能终端工具，Warp 通过兼容 trzsz 协议的神奇组合，打造了超越经典的文件传输新范式。

## 一、环境部署三部曲

### 1. 安装传输核心组件

```
paru -S tssh  # Arch/Manjaro 用户
# 或通过源码编译安装其他发行版用户
go install github.com/trzsz/trzsz-ssh@latest
```

### 2. 智能 SSH 替换方案（二选一）

- 彻底替换方案 （适用于个人设备）

```
sudo ln -sfv $(which tssh) /usr/local/bin/ssh
```

- 临时别名方案（推荐多用户环境）

```
# 在.zshrc/bashrc 中添加
alias ssh='tssh --color=always --prompt "🌐 \h@\u>"'
```

### 3. 开启传输引擎

```
# ~/.ssh/config
Host *
    EnableZmodem yes    # 解除注释唤醒传输能力
    Compression yes     # 启用 SSH 压缩提升大文件效率
```

> 如果想在拖拽文件时使用 rz 上传，请将 `DragFileUploadCommand` 配置为 `rz`

> `Host xxx # 如果配置在 ~/.ssh/config 中，可以加上 `#!!` 前缀，以兼容标准 ssh   EnableDragFile Yes   DragFileUploadCommand rz `

## 二、魔法时刻：实机演示

```
ssh your_server  # 体验与原生 ssh 完全一致的连接方式
```

连接成功后，见证革命性传输效率：

- 上传文件



`rz -be` 触发可视化选择器（支持拖拽 / 多选）

- 下载文件



`sz file1 file2` 享受多线程传输加速

## 三、进阶整合：系统级融合

### Dolphin 右键

在Linux里面是没warp右键的，可以通过下面的命令来创建Dophin的右键菜单

```
# 创建专属服务菜单
sudo tee /usr/share/kio/servicemenus/open-in-warp.desktop <<EOF
[Desktop Entry]
Type=Service
ServiceTypes=KonqPopupMenu/Plugin
MimeType=inode/directory;
Actions=OpenInWarp;
Icon=dev.warp.Warp

[Desktop Action OpenInWarp]
Name=在Warp中打开
Exec=xdg-open "warp://action/new_tab?path=%u"
EOF
```

可以通过修改~/.tssh.conf~/.tssh.conf（ Windows 是 C:\Users\your_name.tssh.conf ）实现tssh的行为

```
# SSH 配置路径，默认为 ~/.ssh/config
ConfigPath = ~/.ssh/config

# 扩展配置路径，默认为 ~/.ssh/password
ExConfigPath = ~/.ssh/password

# trz 上传时，对话框打开的路径，为空时打开上次的路径， 默认为空
DefaultUploadPath = ~/Downloads

# tsz 下载时，自动保存的路径，为空时弹出对话框手工选择，默认为空
DefaultDownloadPath = ~/Downloads

# 全局的拖拽文件上传命令，注意 ~/.ssh/config 中配置的优先级更高
DragFileUploadCommand = trz -y

# trzsz 进度条将从第一种颜色渐变到第二种颜色。注意不要带 `#`。
ProgressColorPair = B14FFF 00FFA3

# tssh 搜索和选择服务器时，配置主题风格和自定义颜色
PromptThemeLayout = simple
PromptThemeColors = {"active_host": "magenta|bold", "inactive_host": "magenta"}

# tssh 搜索和选择服务器时，每页显示的记录数，默认为 10
PromptPageSize = 10

# tssh 搜索和选择服务器时，默认是类似 vim 的 normal 模式，想默认进入搜索模式可如下配置：
PromptDefaultMode = search

# tssh 搜索和选择服务器时，详情中显示的配置列表，默认如下：
PromptDetailItems = Alias Host Port User GroupLabels IdentityFile ProxyCommand ProxyJump RemoteCommand

# tssh 搜索和选择服务器时，可以自定义光标和选中的图标：
PromptCursorIcon = 🧨
PromptSelectedIcon = 🍺

# 登录后自动设置终端标题，退出后不会重置，你需要参考下文在本地 shell 中设置 PROMPT_COMMAND
SetTerminalTitle = Yes
```

## 四、为什么选择这个方案？

| 特性 | 传统方案 | Warp+trzsz |

| --- | --- | --- |

| 传输协议 | Zmodem | 改良 trzsz 协议 |

| 断点续传 | 不支持 | ![:white_check_mark:](https://linux.do/images/emoji/twemoji/white_check_mark.png?v=15) 支持 |

| 目录传输 | ![:cross_mark:](https://linux.do/images/emoji/twemoji/cross_mark.png?v=15) 单文件 | ![:white_check_mark:](https://linux.do/images/emoji/twemoji/white_check_mark.png?v=15) 递归传输 |

| 传输速率 | 约 25MB/s | 可突破 100MB/s |

| 进度可视化 | 文本进度条 | ![:bullseye:](https://linux.do/images/emoji/twemoji/bullseye.png?v=15) 图形化展示 |
