# 个人看剧不完全指南



# 1.在线观看

有些人会喜欢在线观看的方式，比如[低端影视](https://ddys.one/)等等，但我尝试过几次，**有时候会找不到资源**，使用不是很愉快，后面就逐渐习惯了下载后播放。有一些佬友会直接用一些网站在线观看，但对我来说，**影视站里面的资源大部分都插入了广告，并且清晰度很低**，我个人是不喜欢的。

# 2.网盘

网盘就不讲了，这种方式很简单。大家应该都会，不过这种方式一般要求需要对应网盘的会员，不然会限制清晰度或者流畅度。

# 3.Emby

一些佬友可能第一次听到这个词，可能想问什么是Emby？ `Emby是一款优秀的媒体服务器软件，致力于为用户提供丰富的多媒体体验。`Emby就像是Clash一样，是一款播放器，你需要将服务器信息导入，就可以实现类似于爱优腾等一样的效果。服务器提供商会在后台自动帮你更新资源，不需要你操心。



图片是infuse（第三方Emby） 配合 某Emby服

![QQ_1743061540505569×1128 189 KB](https://cdn3.ldstatic.com/original/4X/9/f/9/9f9525be3a9c65107ff96bd255422fe69cfe511f.jpeg)

不同的Emby也有不同的特点，一些会有18+，一些主要为动漫资源，一些主要是电影和电视剧等等。Emby又分为**公益服**和**公费服**：

公益服是免费的，但是需要一定的条件保号（比如签到，或多少天内有观看记录。）



公费服交钱就可以，不同的公费服收费也不同，价格一般在五六元左右，也有一些好的Emby服收费到15~20。**公费服可能随时跑路，建议月付。**



当然公益服由于人数众多，而且不收费，经常会卡顿，而且有的时候对网络有要求。公费服相较于公益服体验上要好很多。

如果你想了解Emby，那么你必须关注下面几个频道，这可以说是所有使用Emby用户都要关注的几个频道，也是在聊天中经常会提到的一些频道：



[Emby星空指南](https://t.me/embyxk)（俗称星空）比较全面，各方面的知识都有，适合新手入门学习；



[Emby公益不完全指北](https://t.me/FreeEmbyGuide)（俗称指北）收集了大量的公益服，可以格局自己的需求来选择。



[Emby 学习小秘](https://t.me/EmbyNoisyX)： Android/Win/TV系统客户端推荐， 官方APP修改版。 已经清空频道

# 4.本地观看

如果要找一些资源发布有一段时间的资源，这种资源直接去磁力站、种子站搜索就可以了，一些以前的美剧可以去[人人影视分享站](https://yyets.click/home)。我自己比较喜欢用[btsow](https://tellme.pw/btsow)，用了很多年了还不错，就是**搜索结果经常出来一些18+，还会弹广告**，这里可以找其他的磁力站。

一些磁力站的整理：[分享非常好用我自用多年的磁力网站，欧美影视剧和日本动漫都能胜任。 - #43，来自 PandaFiredoge](https://linux.do/t/topic/154795/43)

一些小tips:



1.搜索资源的时候 加上`高清影视之家`几个字，可以快速找到高清资源，并且大部分资源有多种清晰度。



2.不管是中国的还是外国的影片，都搜索资源的英文名称。

**如果是最新的电影/美剧，没有人发布带字幕版本的怎么办呢？这时候就是进阶用法了，虽然麻烦，但是适用于所有的电影和电视剧：**

1.先去豆瓣找对应的IMDb号或者资源的英文名称，例如图中的资源IMDb就是 **tt31589662**，英文名称就是 **Georgie & Mandy’s First Marriage**

![QQ_17429966274521131×539 153 KB](https://cdn3.ldstatic.com/original/4X/5/6/1/5618a323c0bdaf71cb373efcb6b158ed346bef71.png)

2.接着去[RARBG镜像站](https://github.com/wesharebytes/RARBG-Proxy-List)、[海盗湾](https://github.com/proxyninja/Pirateproxy)搜索资源的英文名称或者IMDb号。（RARBG死亡重生后好像就没有办法搜索IMDb号了）

![image1941×840 97.2 KB](https://cdn3.ldstatic.com/original/4X/6/9/0/690bb070c453391a1e925dcb47ce6ac5555cd2fb.png)

![image1384×845 106 KB](https://cdn3.ldstatic.com/original/4X/4/5/a/45af0c07dafc87866f2ed5e7b1b21369ae7a3bba.png)

3.找好资源后，去字幕站（目前比较火的是[SubHD](https://subhd.tv/)）。如图，注意资源匹配的版本，以及字幕来源（机翻/人工翻译），下载后将字幕和资源放到一起或者用播放器导入就可以观看了。
