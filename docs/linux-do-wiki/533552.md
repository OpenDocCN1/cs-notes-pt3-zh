# ZED编辑器配置solidity lsp（实现代码自动补全）



lsp我用了solidity-ls，github：[GitHub - qiuxiang/solidity-ls: Solidity language server.](https://github.com/qiuxiang/solidity-ls)

安装一下这个lsp

```
npm install -g solidity-ls
```

然后`where solidity-ls`看一下安装路径，假设这个路径在你的电脑上是`/xxx/xxx/bin/solidity-ls`。

安装完lsp，还需要安装`solc`，可以参考这个：[https://docs.soliditylang.org/en/latest/installing-solidity.html，](https://docs.soliditylang.org/en/latest/installing-solidity.html%EF%BC%8C) 比如，macos就是按照这一段来安装的：

[image1546×580 42.2 KB](https://cdn3.ldstatic.com/original/4X/d/0/7/d07030704fdb63624ebaf266a2a2e5e625aa2fa5.png)

这样操作完，就可以通过`solc --version`来检查一下是否安装成功了。然后用`where solc`看看solc的安装路径，假设是： `/opt/homebrew/bin/solc`

在zed的settings.json中添加下面这段配置：

```
{
  // ...这是你的其他配置，不用动
  // 下面这些是你要添加的配置
  "lsp": {
    "solidity": {
      "initialization_options": {
        "solc": "/opt/homebrew/bin/solc"
      },
      "binary": {
        "path": "/xxx/xxx/bin/solidity-ls",
        "arguments": ["--stdio"]
      }
    }
  },
  "languages": {
    "Solidity": {
      "language_servers": ["solidity"]
    },
  }
}
```

整个配置就完成了，然后在打开.sol文件之后进行编码就可以有代码补全了，另外，代码高亮参考zed extention，zed-solidity ([GitHub - zarifpour/zed-solidity: 💠 Solidity language support for Zed.](https://github.com/zarifpour/zed-solidity)) ，zed ui界面也能直接搜出来。
