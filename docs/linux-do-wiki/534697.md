# eSTK历史版本盘点

eSTK经过接近两年的发展，中间出现了多个版本的硬件。接下来我将按照从前往后的顺序逐步盘点。
eSTK工程验证版：使用淡黄色环氧树脂玻纤混合基底（就是贴了fpc的PCB板），存世量极小，基本只用在早期开发验证，LPA开发者和极早鸟客户。使用STM32主控和iPhone 11拆机eSIM芯片，存在一定可靠性问题，但存世量较少而且基本仅在开发者和极早期用户手中。
eSTK早期量产版：使用白色塑胶封装，类似平时常用sim卡，此版本存在严重可靠性问题极易损坏，不建议日常使用。为早期探索量产工艺的产物，产量200左右，存世量100？，硬件也为STM32和iPhone拆机eSIM，应该已经为全体客户无需寄回发放eSTK 400k
eSTK-400K：第一代正式采用SIP工艺（类似于芯片封装的工艺）的卡片，可靠性较好，产量大，同时开设官网正是售卖，也采用STM32和iPhone拆机eSIM，容量420kb左右，无Profile数量限制。但是仍然存在少量炸卡问题，似乎与静电和iPhone拆机片有关系。这一版本采用的工艺标准较高，可耐受5000M海拔的气压变化，且pin面沉金较厚（识别特征就是沉金不是后面版本的明显反光而是哑光）。
eSTK-ECO：第二代卡片，对接口增加保护，炸卡率较低，SIP标准降低，pin面改为镀金。仍然为iPhone拆机eSIM配合疑似国产替代的arm主控。容量420Kb。

这一代推出了Lite版本，价格较低，阉割了功能并限制Profile数量，可付费升级完整版。
eSTK-MEG&ESS&Air&Dro：第三代卡片，采用定制主控和GD（iPhone同款eSIM厂家）全新eSIM芯片，与第二代同标准的SIP封装，全新RLPA2功能（ios高速稳定下载Profile）。这一代目前共有四个版本。
eSTK-MEG：售价199港币。支持ios写卡切卡，容量800kb，使用GD的ST33J，但是此eSIM芯片似乎存在一定bug，在下载15-20个Profile时可能出现仍有充足容量但无法继续下载的问题（这问题跟自带eSIM的iPhone 12有点类似）。
eSTK-ESS：售价159港币，支持ios写卡切卡，容量440kb，使用GD（iPhone同款eSIM厂家）的ST33G，此芯片较为完美，可以基本用满容量，不存在ST33J的问题。
eSTK-Air：售价69港币。ESS同款硬件，支持2个Profile写入切换，支持ESS具有的全部功能，仅在Profile数量上做了软限制。未来可付费升级ESS。
eSTK-Dro：售价129港版。ESS同款硬件，不限制Profile数量，阉割了ios下卡切卡功能，适合纯安卓使用。未来可付费升级ESS。
ESTKme-FOO：EID组合为89049032+89044045，最强兼容性，高可信EID+高容量EID，提供2M+容量
ESTKme-APR：EID 89044045 x2，最强3M+容量
