# 慢图浏览0.1.40-beta01发布

慢图浏览是一款安卓的第三方相册，提供了多项隐私保护功能，本次版本有大量的优化，建议更新。
下载地址:   [https://www.123684.com/s/gBTtVv-bTTsd](https://www.123684.com/s/gBTtVv-bTTsd)

官方网站:   [https://relaxpic.com](https://relaxpic.com)
### 0.1.40(2025-04-05)
1. 优化照片加载速度
2. 优化应用内存占用
3. 优化创建相册、重命名照片时名称合法性的校验
4. 支持扫描指定文件夹、排除指定文件夹不扫描(入口在设置 → 媒体过滤,原有排除相册的功能依然可用)
5. 增加GIF、RAW 虚拟相册的支持
6. 在移动和复制相册时不再显示已经排除的相册
