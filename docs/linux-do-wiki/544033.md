# MCP的交互流程

```
MCP实际交互流程：
1. 用户输入请求
用户直接向大模型（LLM）发起请求（例如通过聊天界面），此时用户并不知道MCP的存在。

2.LLM触发MCP流程
如果LLM判断需要工具（如计算、搜索、API调用等），它会通过集成的MCP Client向MCP Server请求工具栏表（动态或预加载的）。

3.工具选择与执行
MCP Client将工具栏表和用户需求发送回LLM，由LLM选择工具。
MCP Client调用选定的工具（通过MCP Server），并返回原始结果给LLM。

4. 生成最终回复
LLM将工具结果转化为自然语言，返回给用户。
```
