# 头号玩家播客-同仁医院系列-骨质疏松/钙维D吸收专题笔记

## 本文作为单纯的记录，没有核实，有问题尽请见谅。
# 播客：头号玩家；[https://podcasts.apple.com/cn/podcast/头号玩家-最燃生活攻略/id1412670166](https://podcasts.apple.com/cn/podcast/%E5%A4%B4%E5%8F%B7%E7%8E%A9%E5%AE%B6-%E6%9C%80%E7%87%83%E7%94%9F%E6%B4%BB%E6%94%BB%E7%95%A5/id1412670166)
# 省流【为什么要补钙D】：
- **没有足够的维D**，**约等于没补钙**；
- 食物摄入的**90%**的钙就没法被人体吸收，随肠道排除
- 维D除了维护骨骼的作用，能抗感染，抗肿瘤等很好地效果；
- 绝经后的女性，雌激素断崖式下降，每年钙流失1%左右；男性的激素是缓慢下降的，每年钙流失0.5%左右；
# 极端例子（一个28岁备孕的女生）；
- 不运动（没有维D），吃素（没有蛋白质），喝咖啡，抹防晒霜→直接英年早骨质疏松；
- 怀孕不容易，胎儿一定是从母体吸取钙，**哺乳期也是钙质流失的过程**；
# 如何补钙D：
- 省流：高钙低盐适当蛋白质富含维生素C、E、A、K，维D靠晒太阳；
- 维D：

中午11:00-下午3:00的太阳，暴露自己的面部和前臂，晒15-20min就满足一天的维D （一天1千单位）。
没法晒够太阳，那就有意识地补充维生素D3，一天800-1000（国际）单位；
如果工作日晒不了，可以周末集中晒。维D作为脂溶性维生素，会存在皮下脂肪缓慢释放，半衰期在**29-30**天，通过日照皮肤生成维生素D时，即使长时间的日光照射，也不会有维生素D过量担忧；
但**不能隔着玻璃晒**，也**不能抹防晒霜**（**sfp15**的防晒霜足以让阳光失效，这里应该特指晒阳光生成维D）
- 钙：

尽量补充奶制品，因为**钙磷比**很好，牛奶、酸奶、奶酪；

**豆制品**含有钙，但不好吸收；**芹菜、油菜、紫皮洋葱**都高钙低草酸的，高钙高草酸的容易形成结石；但**它们都是奶制品的补充**，因为不好吸收；
**1ml牛奶含有1mg的钙【简单换算公式，具体可以参考牛奶的营养成功表，100ml含110-125mg不等】**，一升牛奶就够了，然后喝700ml牛奶的话，其他靠食物补充也够了；

钙片，一天需要1k毫克的元素钙。可以根据日常的摄入算摄入钙量，不足的吃钙片；
不要多吃，特别是注意不要保健品叠加【过量只会增加身体代谢负担】；
# 日常避雷：
- 不良饮料：

碳酸饮料：太多磷没有钙，钙磷比失衡影响钙的吸收；
咖啡：不能喝过量的咖啡（每天一两杯还行）；
骨头汤：骨头汤不补钙，且会导致高尿酸血症， 骨髓都是**脂肪**；
- 不要纯食素；
- 小结：现代人全都是富贵病、生活习惯病；
# 补充
- **抗阻运动**（健身、举重）对骨骼很好，有氧运动其实效果一般；
- 体检可以检查骨骼情况。
- 峰值骨量70%和遗传相关，30%是后天因素；
- 降低尿酸到300以下，一年，骨刺可以溶解回去；
- 60岁以上老人可以打肺炎疫苗，**老人要防止跌倒**；
