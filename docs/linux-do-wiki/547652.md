# 折腾键盘⌨️

# 折腾键盘
我目前用的键盘是 Anne Pro 2D，我已经后悔再买一把这块键盘了，官方的改键工具最后一次更新是在 2023 年 9 月，现在我使用这个改键工具时各种闪退各种不能保存各种改键不成功。如果别的人没有遇到我这种问题，那很有可能是因为用的不是同一个操作系统。
我现在转变了想法，改键分层或许可以用软件来做。比如说终端的删除行首行尾等等快捷键是和 GUI 的快捷键不同的，

可编程键盘可能最小化改动也很好，一切复杂的操作都留给三大操作系统上特定的软件来做。除非键盘上有一个专门的开关来切换用于不同操作系统的配置文件。（HHKB 吗？早知道还是 HHKB，不过这个价位我对 filco minila 更感兴趣，不过这年头我估计可以能花更少的钱买到类似的产品了）可我只有手上这块我并不满意的键盘。
折腾这些都是单纯的为了偷懒为了便利，折腾完 60 配列后面就要再去折腾矮轴键盘，然后就是折腾分体键盘，然后就是矮轴分体键盘…
和折腾窗口管理器，输入法，键盘布局，非 qwerty 键盘布局下的输入法等等如出一辙。花几十块钱买个鼠标吧。如果人类有三只手的话，就不用把时间花在这种事情上了。
閒話休提。
这个视频 [ How I Programed the Most Productive MacOS Keyboard Setup Ever: Karabiner Elements（用 Karabiner Elements 实现分层）](https://www.youtube.com/watch?v=j4b_uQX3Vu0)
**按住** Hyper 键，再**按住**一个字符键比如 J，就进入了 `Hyper-J 层`，然后再按另外一个键，实现某个效果。
实际上似乎就是增加了更多的修饰键，原本是按 `Ctrl + Shift + 字符`，现在是按`Hyper + 字符 + 字符`（当然做不到按`Hyper + J + J`)
我记得我之前装 IdeaVim 的时候似乎也有类似的概念。
感觉把某个用不到的 F13~F24 放到好的位置体验更好，能按两个键触发，当然就不愿意按三个键触发。哪来的那么多快捷键需要你按了？
视频中的方法的我感觉优势在于语义性更强，以及更通用，比如笔记本键盘。
