## Nginx
配置Nginx
```
server {
    listen 80;
    server_name 123.com www.123.com;  # 替换为你的域名
    return 301 https://$host$request_uri;     # 将HTTP重定向到HTTPS
}

server {
    listen 443 ssl http2;
    server_name 123.com www.123.com;  # 替换为你的域名
    root /var/www/123.com   # 替换为Hugo生成的public目录的实际路径
    index index.html;

    # SSL证书配置
    ssl_certificate /etc/letsencrypt/live/123.com/fullchain.pem;      # 替换为你的证书路径
    ssl_certificate_key /etc/letsencrypt/live/123.com/privkey.pem;    # 替换为你的私钥路径
    ssl_protocols TLSv1.2 TLSv1.3;
    ssl_prefer_server_ciphers on;
    ssl_ciphers ECDHE-RSA-AES256-GCM-SHA512:DHE-RSA-AES256-GCM-SHA512:ECDHE-RSA-AES256-GCM-SHA384;

    # HSTS设置
    add_header Strict-Transport-Security "max-age=31536000; includeSubDomains" always;

    # 其他安全头
    add_header X-Content-Type-Options nosniff;
    add_header X-Frame-Options SAMEORIGIN;
    add_header X-XSS-Protection "1; mode=block";

    # 设置日志
    access_log /var/log/nginx/123.com.access.log;
    error_log /var/log/nginx/123.com.error.log;

    # 启用GZIP压缩
    gzip on;
    gzip_types text/plain text/css application/javascript application/json;

    # 处理静态文件
    location ~* \.(css|js|jpg|jpeg|png|gif|ico|svg|pdf)$ {
        expires 30d;
        add_header Cache-Control "public, no-transform";
    }

    # 主要内容
    location / {
        try_files $uri $uri/ =404;
    }

    # 错误页
    error_page 404 /404.html;
    location = /404.html {
        internal;
    }
}
```
启用Nginx
```
sudo ln -s /etc/nginx/sites-available/123.com /etc/nginx/sites-enabled/
sudo nginx -t  # 测试配置文件语法
sudo systemctl reload nginx  # 重新加载Nginx
```
## 运行
```
# 在Hugo网站目录下生成静态文件
hugo
# 将生成的静态文件复制到Nginx网站目录
sudo mkdir -p /var/www/123.com
sudo cp -r public/* /var/www/123.com/
```
## 更新页面
之后如有修改页面，重新运行如下即可生效
```
hugo
sudo cp -r public/* /var/www/123.com/
```
## Tips
调试时需要把cloudflare清除缓存，同时改成开发者模式，否则缓存未更新，页面修改后不会立即生效：

`cloudflare点击你的域名，左侧栏Caching，点击Configuration，点击Purge Cache，点击Purge Everything，确认。`
`Caching- Configuration - Development Mode关闭。`
网址上线再关闭cloudflare开发者模式，提升访问速度。
