# 如何像滑动变阻器一样丝滑地降智——OAI有感



> 滑动变阻器是电路元件，它可以通过来改变自身的电阻，从而起到控制电路的作用。

大家都知道OpenAI降智是很「高级」的，千人千面，你可能一不小心就被降智了。今天我们就来看一看，**假如OAI将降智神功练至大成，你的ChatGPT使用会是怎么样的**。

## 降智的原理

降智的原因就是你的账户所谓「风险」，包括但不限于你的IP、语言、使用时间段、付款方式等等都会影响你的账户风险值。降智是一个介于封号和滥用之间的权衡手段，他不会造成任何普通一般用户的显著知觉——但这显然瞒不住佬友。

> `0x08f50b`

这个是一个POW值，一般用来量化你账号的「降智」风险，值越小风险越大，一般来说5位数字即为正常（例如`0x08f50b`），四位以下基本就可以认为降智了（例如`0x00f450`）。

## 怎么做

### 大语言模型

对于**非推理**模型，一般来说就是以下三招：

1. 禁用开销较大的模型原生多模态输入，变为工具执行（ChatGPT中以Analyzing为标志）

2. 禁用多模态输出（例如4o原生画图变为DALL·E）

3. 回退到上一个版本的模型（通常配合1）

4. 回退到Turbo版本的模型（免费用户直接变为mini系列的模型）

对于**推理**模型，这才到了滑动变阻器的地步：

1. 限制思考长度（o1的思维链可长可短）

> 我出个主意，自动根据公式  l = \frac{\lambda}{d}  （ l 为思维链长度，\lambda 为固定系数，d 为POW的难度）动态调整思维链长短

1. 限制回复长度，思维模型的回复经常很长，限制这个可以有效砍Token

### 图片模型

1. 减少Steps，降低原生分辨率，后期放大（精准控制到底滑倒哪里）

2. Turbo模型

### 视频模型

这里我不知道怎么搞，但有一个设想：训练一个原生10fps的模型，小一点，慢一点，然后后期插帧

1. 检测到可疑操作比较多？直接`The network connection was lost`。

2. 故意给你卡顿一下，有概率在画图的时候或者是思考的时候`The request timed out`。

3. 开通会员/续费会员第二天就`Oops! Account deactivated`（也正因如此，苹果商店充值的会比较稳定一些——因为奥特曼知道你能退款）。
