# 使用claw run免费搭建Akile Monitor



免费版的流量只有10g，搭个探针还是绰绰有余的

用到项目：

- [GitHub - akile-network/akile_monitor: Akile Monitor](https://github.com/akile-network/akile_monitor)

- [第三方 Akile Monitor 监控端使用](https://linux.do/t/topic/284517)

你需要自备：

- 一个域名

## 后端部署

打开[ClawCloud Run](https://console.run.claw.cloud/) 【无aff放心点击】，使用github账号登录即可获得5刀余额



选择`App Launchpad` → `Create App`，自定义一个名称，让后配置如下，docker镜像名称填`niliaerith/akile_monitor_server`：

![image1671×1557 109 KB](https://cdn3.ldstatic.com/original/4X/4/5/0/4506dd61ace11e9b430cf6b14f02f3a0f1965853.png)

每天`$0.16`，可以用一个月，注意，自定义域名需要解析到cname并生效后才能点击确定

在下方Configmaps里添加一个配置文件：



file name为`/app/config.json`



file content如下：

```
{
  "auth_secret": "你的自定义密钥",
  "listen": ":3000",
  "enable_tg": false,
  "tg_token": "your_telegram_bot_token",
  "hook_uri": "/hook",
  "update_uri": "/monitor",
  "web_uri": "/ws",
  "hook_token": "hook_token",
  "tg_chat_id": 0
}
```

完成后部署即可。

## 前端部署

到 [Releases · akile-network/akile_monitor_fe · GitHub](https://github.com/akile-network/akile_monitor_fe/releases) 下载前端文件，修改config为你后端的自定义域名，示例如下，你可以把前端部署到cf pages等免费托管平台

```
{
  "socket": "wss://akile.example.com/ws",
  "apiURL": "https://akile.example.com"
}
```

## agent配置

主要按照下面的来就行，注意主端地址直接写你后端的域名不要带端口号，示例如下

```
./ak_monitor_client_rs -s akile.example.com -a 你的自定义密钥
```
