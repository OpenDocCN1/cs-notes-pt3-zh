# L站专有名词指北

**关于本站的名词解释**

帖子越来越多，同时名词也层出不穷，另外前几天还有看到有新佬问始皇是谁，于是想着把一些看似平常的问题记录下来，拉齐**基础认知**，不至于看完帖子一头雾水 ![:see_no_evil:](https://cdn.ldstatic.com/images/emoji/twemoji/see_no_evil.png?v=15)以下为示例：
1. L站： [即本站](https://linux.do)
2. 始皇：[@neo](/u/neo) 源于佬的签名，后期也是大家对其的爱称，表示高度的认可
3. 佬友：为论坛前期投票得出 [论坛群体自称的问题](https://linux.do/t/topic/5973)
4. 何为c（crack）: [有一个问题想请教高人 - #4，来自 neo](https://linux.do/t/topic/27843/4)
5. cf : cloudflare (佬友戏称 ‘大善人’)
6. 官转和逆向：[各位佬，管转、逆向，什么意思什么区别 - #4，来自 pengzhile](https://linux.do/t/topic/55088/4)
7. GV:  Google Voice
