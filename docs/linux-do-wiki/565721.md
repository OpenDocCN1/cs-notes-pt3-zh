# 逆向工具 Rizin / radare2 (Cutter - Iaito) 时间线



1. radare/radare2发布

2. Cutter作为radare/radare2的GUI发布

3. 因为radare2社区对radare2主要开发者的一些习惯（喜欢在代码里夹带脏话）感到不满，于是一部分开发者fork了radare2, 改名为Rizin

4. Cutter的主要开发者跟随Rizin

5. 此时radare2没有GUI了（因为Cutter已经归属到Rizin）

6. radare2团队又fork了Cutter并叫做Iaito

---

备注：

- 因为radare2和radare只是一个版本号变动，没有涉及人员分散，所以放在一起

- TLDR: 如果你希望你用的软件开发者认真对待，去用Cutter和Rizin

- 若有错误欢迎指出
