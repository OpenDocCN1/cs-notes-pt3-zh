# 整理了几个不常见，非常实用的邮箱功能

**1：邮箱共享：**

为企业高管或同事之间，提供查看、回复、转发邮件等操作。
**2：水印设置 ：**

降低信息泄漏风险，防止截屏、拍照泄密。
**3：异常行为预警：****

创建异常行为规则，触发时实时预警，确保异常行为及时被发现。

**4：邮件备份或邮件监控：**

可设置监控某个用户的收发邮件，符合监控条件的都会转发一份邮件至监控员的邮箱。一个监控员邮箱下可设置多个被监控邮箱。

**5：邮件审核**：

可设置审核某个用户的收发邮件，触发审核规则的邮件，审核员的邮箱会收到“待审核的通知邮件”。

**6：邮件追踪：**

追踪邮件是否阅读,收件人只需要点开邮件，就能看到其阅读状态，甚至是阅读时间。**

**7：邮件加密：**

在发送重要或涉密邮件时，通过邮件加密添加邮件独立密码，收件人需通过密码解锁才能读取邮件正文和附件（密码联系发件方获取）。
