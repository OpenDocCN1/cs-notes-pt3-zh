# 【笔记】Docker数据目录迁移到/home

# Docker 数据目录迁移与验证笔记备份
---
## ![:delivery_truck:](https://linux.do/images/emoji/twemoji/delivery_truck.png?v=15) 数据迁移步骤
### 1. 停止原有 Docker 服务
```
systemctl stop docker
```
---
### 2. 创建新的 Docker 目录
```
mkdir -p /home/docker
```
---
### 3. 同步原有数据（可选，若已有数据）
```
rsync -avz /var/lib/docker/ /home/docker/
```
---
### 4. 备份原始目录
```
mv /var/lib/docker /var/lib/docker.bak
```
---
### 5. 创建 Docker 配置目录（若未存在）
```
mkdir -p /etc/docker
```
---
### 6. 修改 Docker 配置文件 `daemon.json`
```
cat > /etc/docker/daemon.json << 'EOF'
{
  "data-root": "/home/docker",
  "registry-mirrors": [
    "https://docker.1panelproxy.com",
    "https://mirror.ccs.tencentyun.com",
    "https://docker.mirrors.sjtug.sjtu.edu.cn",
    "https://docker.m.daocloud.io",
    "https://docker.itelyou.cf",
    "https://noohub.ru",
    "https://docker.fxxk.dedyn.io",
    "https://huecker.io",
    "https://dockerhub.timeweb.cloud",
    "https://registry.cn-hangzhou.aliyuncs.com",
    "https://registry.cn-shanghai.aliyuncs.com",
    "https://registry.docker-cn.com",
    "https://docker.mirrors.ustc.edu.cn",
    "https://hub-mirror.c.163.com"
  ]
}
EOF
```
---
### 7. 重新加载并启动 Docker
```
systemctl daemon-reload
systemctl start docker
```
---
### 8. 验证新的数据目录是否生效
```
docker info | grep "Docker Root Dir"
```
---
### 9. 验证一切正常后可删除旧目录（可选）
```
# rm -rf /var/lib/docker.bak
```
---
## ![:white_check_mark:](https://linux.do/images/emoji/twemoji/white_check_mark.png?v=15) 迁移后验证
- 检查 Docker 状态：
```
systemctl status docker
```
- 检查 Docker 根目录是否变更成功：
```
docker info | grep "Docker Root Dir"
```
- 测试 Docker 是否正常运行：
```
docker run hello-world
```
---
## ![:red_exclamation_mark:](https://linux.do/images/emoji/twemoji/red_exclamation_mark.png?v=15) 迁移失败时的回滚方案
如果迁移失败，可以执行以下步骤恢复：
### 1. 停止 Docker 服务
```
systemctl stop docker
```
---
### 2. 恢复原目录
```
mv /var/lib/docker.bak /var/lib/docker
```
---
### 3. 删除 `daemon.json` 配置文件
```
rm /etc/docker/daemon.json
```
---
### 4. 重启 Docker
```
systemctl daemon-reload
systemctl start docker
```
