# 【笔记】Docker安装elasticsearch+kibana



# Elasticsearch + Kibana Docker 部署笔记备份

---

## ![:card_index_dividers:](img/3272069ec2dfef6555ba70c73ab6299a.png) 1. 创建相关目录

```
mkdir -p /home/mydata/elasticsearch/{config,data,plugins}
```

---

## ![:locked_with_key:](img/0cc5052688b256c26a3d0ebb0e772c0c.png) 2. 设置目录权限

```
chmod -R 777 /home/mydata/elasticsearch/
```

---

## ![:gear:](img/6b0193eb51443fadb6361e8d9588876f.png) 3. 创建 elasticsearch.yml 配置文件

```
cat > /home/mydata/elasticsearch/config/elasticsearch.yml << 'EOF'
http.host: 0.0.0.0
http.cors.enabled: true
http.cors.allow-origin: "*"
http.cors.allow-headers: Authorization,X-Requested-With,Content-Type,Content-Length
EOF
```

---

## ![:spouting_whale:](img/de9b54c49153ced907b213b01e6e82cc.png) 4. 创建 docker-compose.yml 文件

```
cat > /home/mydata/elasticsearch/docker-compose.yml << 'EOF'
services:
  elasticsearch:
    image: elasticsearch:8.17.0
    container_name: elasticsearch
    environment:
      - "cluster.name=docker-cluster"
      - "discovery.type=single-node"
      - "ES_JAVA_OPTS=-Xms512m -Xmx512m"
      - "xpack.security.enabled=true"
      - "ELASTIC_PASSWORD=20181490"
    volumes:
      - \${PWD}/config/elasticsearch.yml:/usr/share/elasticsearch/config/elasticsearch.yml
      - \${PWD}/data:/usr/share/elasticsearch/data
      - \${PWD}/plugins:/usr/share/elasticsearch/plugins
    ports:
      - 40214:9200
      - 40215:9300
    networks:
      - elastic
    ulimits:
      memlock:
        soft: -1
        hard: -1
    restart: unless-stopped

  kibana:
    image: kibana:8.17.0
    container_name: kibana
    environment:
      - ELASTICSEARCH_HOSTS=http://elasticsearch:9200
      - ELASTICSEARCH_SERVICEACCOUNTTOKEN=AAEAAWVsYXN0aWMva2liYW5hL3Rva2VuX3ZqLVQ4cE1CajRVb3czVDJocEUxOm14NWtnRzJ1U29HVmxqR0k1ZGRUYWc
    ports:
      - 40216:5601
    depends_on:
      - elasticsearch
    networks:
      - elastic
    restart: unless-stopped

networks:
  elastic:
    driver: bridge
EOF
```

## ![:play_button:](img/0571485024162bfa4a8904cdcf6beb04.png) 5. 启动服务

```
cd /home/mydata/elasticsearch/
docker-compose up -d
```

---

## ![:white_check_mark:](img/f86349611d6094c730e6a1116c851813.png) 6. 检查服务状态

```
docker-compose ps
```

---

## ![:hammer_and_wrench:](img/1d0479e1b307bf22369d8c905a50f7d2.png) 7. 可选：补充一键脚本 tools.sh

```
cat > /home/mydata/elasticsearch/tools.sh << 'EOF'
#!/bin/bash

case "$1" in
  up)
    docker-compose up -d
    ;;
  down)
    docker-compose down
    ;;
  logs)
    docker-compose logs -f
    ;;
  backup)
    tar czvf elasticsearch-backup.tar.gz .
    ;;
  restore)
    tar xzvf elasticsearch-backup.tar.gz
    ;;
  *)
    echo "用法: ./tools.sh [up|down|logs|backup|restore]"
    ;;
esac
EOF

chmod +x /home/mydata/elasticsearch/tools.sh
```

脚本的使用：

```
./tools.sh up       # 启动服务
./tools.sh logs     # 查看日志
./tools.sh backup   # 打包当前目录
./tools.sh restore  # 解包并恢复
```
