# Outlook 日历事件自动推送至Microsoft Todo



Microsoft ToDo 是一款任务管理软件，平时用起来是很好用的，但是依然有个缺点，就是无法与Outlook 日历联动。

这就让我经常在两个软件上纠结，如果我确定了一个日常事件，

比如**去运动，** 那我是放到outlook的日历中好呢？还是放在ToDo创建循环任务好呢？

放到日历里我没法方便地标记是否完成以及标记事件的完成情况，并且与ToDo的任务管理脱节，每次复盘的时候还是两个软件跳转。放到ToDo里又会有一堆日常的事件挤在“我的一天”里，导致我无法聚焦到主要的任务。下图就是一堆现在并不需要做的事情，我的下一件事实际上是“和曾老师吃饭”，但是一堆我晚上要做的事情却冒了出来。

![image1090×682 42.2 KB](img/4c67d1863c55d09273dffe4ff66fdeb2.png)

那我就设想了，我能不能让outlook里的事件在开始的时候自动推送到我的ToDo里呢？这样就能在任务要开始的时候再冒出来。

设想挺好，那么如何实现呢？答案是使用Zapier。

Zapier是一个自动化任务平台，可以固定outlook事件开始时在Microsoft To Do里自动创建任务，Wow，Fantastic！

![image725×458 21.6 KB](img/8c79bb67f8260a4e41efc7cc4dcd5697.png)

实现效果是什么呢？如下图所示，就是某个事件开始的时候，我的任务列表里会弹出来一个新的任务，就像有管家帮我创建一样，很爽。

![image256×138 4.16 KB](img/af733ef03fdd531e4107036e42d454fc.png)

![image1096×466 104 KB](img/3dfa50b96e546b6c880ac8a5db272831.png)

并且我仔细调研了市面上的软件，几乎没有软件能实现我这个需求，包括滴答清单也没法自动将一个事件自动地插入某个列表中。
