# Notion 博客搭建的几种方法



- 为什么选择Notion搭建博客？



优点：



无需维护任何东西，Notion即博客

Notion编辑体验无敌，同时附带很多功能比如历史记录啥的。

教育版体验很好，很多文件可以直接上传，我们很多大学应该可以直接使用。



缺点：



毕竟不是专门为博客设计的，可能有些乱七八糟的功能没有。不过基础的评论还是有的。

Notion本身访问速度可能受到很多方面影响会变慢。



下面我根据时间列一些质量比较好的开源仓库，大家选择自己喜欢的使用即可。我着重写一下Osmium的教程，因为我需要用到它的”使用手册“博客布局。

极简风格博客



**Nobelium:** 作为一个完整的博客生成器，它负责以下工作：



从 Notion 获取你的博客数据（通过 Notion API 或公共分享）。

利用 Next.js 进行静态生成，将 Notion 数据转化为静态网页文件。

在生成过程中，调用 `react-notion-x` 来处理 Notion 页面内容的渲染部分。

添加博客所需的其他功能，如评论、搜索、标签、SEO 等。

将生成的静态文件部署到 Vercel 上。



Demo: [https://nobelium.vercel.app/](https://nobelium.vercel.app/)
