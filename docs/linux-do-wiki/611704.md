# 【科普】GV 与 Talkatone

最近有好多佬友在咨询或者准备获得这两个号码，但是有不是很明白，我今天就遇到了两个，正好五一不想干活，就简单写一下，不足之处，各位大佬可以指正和补充！

4. 实用的注册技巧。

**序言：为什么我们需要这些服务？**
在很多场景下，我们可能不希望使用自己的真实手机号：
- 注册一些国内/国外的服务，不想暴露主号。
- 需要一个临时的号码收个验证码。
- 做海外业务，需要一个美国/加拿大号码。
- 想省点国际长途费。
- 有多个身份/用途，想用不同的号码区分。
**一、初识 GV 与 Talkatone：它们是什么？**
简单来说，Google Voice 和 Talkatone 都是提供**基于互联网的虚拟电话号码**的服务（属于 VoIP 技术）。它们能让你在没有实体 SIM 卡的情况下，拥有一个可以接打、收发短信的美国或加拿大号码。
- **Google Voice (GV):** 谷歌出品，提供一个免费的美国或加拿大号码，功能强大且稳定，深度整合谷歌生态。
- **Talkatone:** 另一款提供免费美国号码的服务，主要通过 App 使用，获取门槛相对较低。
**二、Google Voice (GV) **
GV 是很多老玩家的首选，一旦拥有，功能非常强大。
**2.1 GV 的核心能力**
- **免费美国/加拿大号码：** 这是基础，可以用来接打电话、收发短信。
- **国际通话：** 免费拨打美国和加拿大号码。拨打其他国家/地区的费率通常很低，比传统运营商划算不少。
- **来电管理：** 可以将来电转接到你的其他手机号，设置个性化语音邮件，骚扰电话过滤等。
- **语音邮件转文字：** 这个功能非常赞！GV 会尝试将收到的语音邮件转录成文字，方便你快速浏览。
- **跨平台使用：** 支持网页版、iOS 和 Android App，随时随地都能用。
- **与 Google 生态整合：** 和 Gmail、Google Duo 等服务联动方便。
**2.2 如何获取一个 GV 号码？**
这是 GV 最让国内用户头疼的地方。

**核心要求：
1.需要一个** **“真正”的美国或加拿大电话号码来接收验证码
- **传统方法：** 需要你在美国或加拿大，用当地运营商的手机号来验证。
- **曲线救国：**

请在美国或加拿大的亲友帮忙接收验证码。
尝试一些提供临时美国号码用于注册的服务，如接码平台，站里就可以搜到。
早期可能有一些更简单的注册方法，但现在这些漏洞基本都被堵上了。
- **获取难度：** 正因为这个验证门槛，GV 的获取难度远大于Talkatone
**2.3 GV保号策略 (必看！)**

官方政策要求：[Voice Acceptable Use Policy - Google Voice Help](https://support.google.com/voice/answer/9230450?hl=zh-Hans)

- **不建议使用app或者网页端收发短信**
- **注册完后建议永远不要登陆GV，只使用邮箱接收和发送短信**
- **三个月**发送一次短信**或**打电话，建议直接发短信
**2.4 GV 的优缺点**
- **优点：** 免费、功能强大、稳定、语音邮件转文字实用、国际长途费率低、与谷歌生态整合。
- **缺点：** 获取门槛高（需要美国/加拿大真号验证）、作为 VoIP 号码可能无法用于所有服务的验证、号码长时间不用可能被回收（回收政策相对宽松）。
**三、Talkatone **
相较于 GV，Talkatone 在获取门槛上友好很多，适合新手或需要快速获得美国号码的用户。
**3.1 Talkatone 简介与优势 **
- **注册超简单：** 最大的优势！只需要一个**纯净的美国 IP 地址**，通常就能直接在 App 里注册并获得一个免费号码（无需实体手机号验证）
- **获取速度快：** 流程简单，号码即得。
- **基础功能：** 提供免费拨打和接收美国、加拿大号码的电话和短信功能（基于数据网络）。
- **低成本：** 号码免费。可以免费接收几次短信（应该是五次）
- **充值 $0.99** ，可获得60积分。理论上积分不归零号码就一直在
- **plus不建议充值**，实用性为0.01，哪怕plus人家照样封你
- **可打 +86**等国际号码，可能有 Bug 并且会扣除积分，不建议使用。
**3.2 Talkatone 注册**
- **IP 纯净度是王道：** 注册成功与否，很大程度上取决于你使用的美国 IP 地址是否“干净”，没有被滥用过。
- **设备指纹与 IP 限制：** 同一个设备在同一个 IP 下，短时间内（可能几周）只能注册一个 Talkatone 账号。想注册多个需要更换设备、IP 或等待。
- **玄学加成？：** 使用苹果设备 (iOS) 注册似乎更容易成功。
**3.3 Talkatone 号码保号策略 (必看！)**
Talkatone 的号码是会过期回收的，保号机制比 GV 要严格一点。
- **积分保号：** Talkatone 有一个积分系统（初始 60 分）。如果你的号码在一个自然月内**没有任何主动使用行为**（发出电话或短信），会在下个月初**扣除 30 积分**。
- **回收判定：** 积分扣完（归零）后，你的号码就会被 Talkatone 收回。
- **如何保号：**

1.确保你的 Talkatone 号码**每个自然月内**至少有一次**成功发送的短信**或**成功拨打的电话**。

给自己的另一个号码（如 GV 号）、或者朋友的美国/加拿大号码发送一条短信，或者拨打一个免费的美国/加拿大电话（微软、谷歌等电话）。
关键在于**成功发出**或**成功接通**。

**四、GV vs Talkatone
| 特性 | Google Voice (GV) | Talkatone |
| --- | --- | --- |
| **获取难度** | 高 (需美国/加拿大真号验证) | 低 (需纯净美国 IP，无真号要求) |
| **号码归属** | 美国/加拿大 | 美国 |
| **主要平台** | App & 网页版 | App |
| **功能丰富度** | 高 (语音转文字、转接、费率低国际长途等) | 基础 (免费美加通话/短信，可能带广告) |
| **稳定性** | 较高 | 相对较低，通话质量可能波动 |
| **盈利模式** | Google 生态/付费国际长途 | **广告**为主 |
| **号码持久性** | 较好 (不常用回收周期较长，需偶尔登录) | 较差 (不常用回收快，**需每月主动使用**保号) |
| **验证码接收** | 有一定成功率，但非 100% (VoIP 都可能被屏蔽) | 成功率相对更低 (更容易被屏蔽) |
| **注册 IP 要求** | **纯净美国 家宽** | 要求**纯净美国 IP** |
| **保号时间** | **三个月** 发短信或打电话** | ** 每个月** 发短信或打电话 |
**共同注意事项：**
- **都是 VoIP：** 它们都依赖数据网络，没有网络就无法使用。也意味着它们无法拨打紧急服务电话（如 911）。
- **验证码玄学：** **任何 VoIP 号码都无法保证能成功接收所有服务的验证码**。很多银行、支付、社交平台会屏蔽 VoIP 号码。
- **政策变动：** 免费服务政策随时可能调整，且用且珍惜。
**五、结语**
Google Voice 和 Talkatone 都是非常有用的虚拟号码工具，它们各有特点，适用于不同的场景和需求。
无论使用哪一个，记得保号。
