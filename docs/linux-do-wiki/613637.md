# 主板维修指南(植锡篇）



## 主板植锡教程

**工具：** 植锡网，锡浆（183中温锡），植锡刀。

**准备工作：**



植锡刀撬起锡浆，用纸巾和无尘布稍微去一下锡浆里面的助焊剂，锡浆不能太稀太干，手稍微捏着感觉有点硬就OK了，芯片下面准备对着的纸巾，防止cpu走位。

**植锡步骤：**

1. 使用钢网，

2. 对准芯片焊点，对位好，（强灯下正放钢网，直到灯光下看见每个锡点，）

3. 再抹上锡浆（不要大力去刮，容易导致芯片错位，抹锡浆，锡刀是反复正反旋转的推的，10度-15度的手法）

4. 用无尘布把钢网上的锡浆擦干净（刮刀刮的干净就可以不用纸巾去擦，但一般都要用的，没擦干净就会导致后面有锡点很大，如果出现大锡点不要硬掰，先吹化，不然芯片 掉点）

5. 注：钢网对位芯片，风枪吹的时候，钢网周边可以翘起，但CPU芯片中心不可以，如果出现就停止，可以掰周围钢

6. （注意换手法）使用风枪（280度=中温锡+100度，370400也行比较快，达到熔点就可以了）

7. 把锡浆吹成锡球（从边缘外慢慢往中间吹，风枪是倾斜40度~50度拿的吹，肉眼可以看见锡浆变成锡球，见后面吹锡球图片）

8. 稍微冷却一下（大概3-5秒）取下钢网（力度不要太大，可以用镊子稍微推一下）

9. 打一点焊油（助焊剂），再用风枪再吹一下，让锡点归位（确保每个锡点都是均匀的）

> 注：清理cpu和钢网

1. 烙铁直接清理CPU上面的锡球（不要加吸锡带去，不然太平整不好对钢网）

2. 烙铁清理后，用棉球包裹镊子沾洗板水去清洗芯片，清洗完后用风枪吹一下，吹干水分才可以植锡（有洗板水植锡会炸锡哦）

3. 植完锡的钢网用洗板水加无尘布清理干净，同样风枪风干处理，植锡的时候看一下钢网上面有没有脏东西，有就去掉（透着光去看）
