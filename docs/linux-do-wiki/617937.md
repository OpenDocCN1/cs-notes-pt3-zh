# AlpineLinux安装NaiveProxy使用Caddy forward_proxy



### [GitHub - klzgrad/naiveproxy: Make a fortune quietly](https://github.com/klzgrad/naiveproxy)

Make a fortune quietly

# 注意

你需要一个域名并解析到该主机，不可通过cdn

安装完效果如同浏览网页，速度相比其他不会快，但是很稳。延迟也低

不使用singbox是因为只支持入站，不支持出站分流。所以没必要，

# 安装caddy

```
#主程序
apk add caddy

#开机启动
rc-update add caddy

#端口管理
apk add libcap

#给予绑定端口权限
setcap cap_net_bind_service=+ep $(which caddy)

# 获取带插件的caddy
wget https://github.com/klzgrad/forwardproxy/releases/latest/download/caddy-forwardproxy-naive.tar.xz

# 解压
tar -xf caddy-forwardproxy-naive.tar.xz

# 替换 /usr/sbin/caddy
mv caddy-forwardproxy-naive/caddy /usr/sbin/caddy
chmod +x /usr/sbin/caddy
```

# 编辑caddy配置

不可使用自签证书，让caddy自动签名获取新证书

```
vi /etc/caddy/Caddyfile
```

修改`my.domain`,`user`,`pass`

```
{
        admin off
        order forward_proxy before file_server
}

:443, my.domain {
        route {
                forward_proxy {
                        basic_auth user pass
                        hide_ip
                        hide_via
                        probe_resistance
                }
                reverse_proxy https://demo.cloudreve.org {
                        header_up Host {upstream_hostport}
                        header_up X-Forwarded-Host {host}
                }
        }
}
```

# 优化 sysctl.conf

编辑 `vi /etc/sysctl.conf`

填入

```
net.ipv4.tcp_congestion_control = bbr
net.core.default_qdisc = fq
net.ipv4.tcp_slow_start_after_idle=0
net.ipv4.tcp_notsent_lowat=131072
net.ipv4.tcp_fastopen = 0n
```

应用 `sysctl -p`
