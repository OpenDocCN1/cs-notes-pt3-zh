# 论如何在 FireFox 使用混合字体



嗯，想必大家都看过标题了，很简单，小白们手拉手，我和你一起走！.

1. 先准备好一些字体。它们应该满足一组一种文字到一种字体的映射关系。



比如我选的是：



文字

字体



简体中文

[霞鹜文楷 GB](https://github.com/lxgw/LxgwWenkaiGB)



拉丁字母

[MapleMono-NF](https://github.com/subframe7536/maple-font)



然后把它们安装到系统中。我也不会怎么做，在文件管理器中打开/右键 TTF 文件一般就会有安装提示。

2. 打开about:preferences#general，搜索“高级”。



![如此这般909×274 9.74 KB](https://cdn3.ldstatic.com/original/4X/0/e/9/0e923609f0082167b33bb29658d5f6c22d73c3f4.png)

3. 点击“高级”。



![高级哒么726×560 10.7 KB](https://cdn3.ldstatic.com/original/4X/f/3/6/f368872c031c238d7cd2d1d32bf27c931d4de5cc.png)

4. 选择位置，形如上图示的“拉丁字母”位置，点击它，选择你要设置字体的。



小tips：输入首字母可以更快找到字体。

5. 选择其他语言文字按步骤3重复操作。



![简中的哒726×560 11.7 KB](https://cdn3.ldstatic.com/original/4X/4/4/c/44c2aa8c0e47666b889d46f6e53dc8fddc94f535.png)

补充小知识：

- **比例衬线字体**: 常用于传统印刷。

- **比例无衬线字体**: 常用于现代网页。

- **等宽衬线字体**: 老式打印机，不常用。

- **等宽无衬线字体**: 现代编程首选。

我这里偷懒用了重复的配置，你可以根据需要自己调哦~
