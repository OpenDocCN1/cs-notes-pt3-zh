# Cursor 三种常见用户类型： `Pro Trial`，`Free`，`Pro`



# 三种类型

上网这么多年，今天才发现似乎有部分用户没有分清用户付费计划的各种情况。



以 “cursor” 为例，只谈常见的三种类型。



当然，其他软件也大都如此。

## 1.  `Pro Trial`

没有氪金的，介于 `free` 和 `pro` 之间的短暂状态，甚至可能更短，也就是说试用期间 **有可能突然被赋予 “封杀令”，也就是 “掉试用” 了**

![image612×147 8.44 KB](https://cdn3.ldstatic.com/original/4X/3/b/0/3b0fc046456161dd1f18302477ba3308a86153c1.png)

## 2. `Free`

没有氪金的长期状态，当然没有氪金的不一定都是 `free`

![image763×302 9.48 KB](https://cdn3.ldstatic.com/original/4X/6/9/7/697957e6d8208bdb49f4d69e41bb67325f575424.png)

## 3. `Pro`

正经充钱的，或者是不正经的，总之你是正式成为 `pro` 了，一般是长期状态。当然，同样存在 “封杀令” 。

![image](img/9aa42c0370aeb236c7a68f8e617d9183.png)
