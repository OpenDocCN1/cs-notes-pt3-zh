# 恶意IP名单共建



# 介绍

想必在L站各位都有个自己的网站、在线服务，而面向公网的服务又总是不可避免的会遇到一些网络暴徒，它们或许是频繁扫描端口、尝试暴力破解密码、漫天发送各种垃圾邮件、疯狂DDoS它们盯上的目标。

虽然我希望大家不要遇见这样的倒霉事，但如果毫无防备遇上了恶意攻击很有可能会造成极大的损失，为此我决定发起文档共建，让社区里的佬友们一起共建恶意IP列表，大家一同建立恶意IP列表，利用社区的力量共同防御网络威胁。

## 恶意IP分类

目前恶意IP的分类有：

1. DDoS，作为最常见的网络攻击手段，DDoS往往是由多个僵尸网络组成的攻击小组，由无数个IP发起的攻击，极难从中区分出普通用户

2. 端口扫描，不停扫描互联网上开放的端口，随后…

3. 恶意爆破，比如爆破SSH连接、X-UI密码等等

4. 垃圾邮件，其实现在的邮件系统的垃圾邮件过滤已经很完善了，此分类主要面向诈骗、钓鱼邮件发件人
