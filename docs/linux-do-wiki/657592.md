## 0x03 Hexo常见命令

```
hexo init
hexo deploy
hexo generate
hexo new "文章名称"
hexo new page "页面名称"
hexo clean
```

### 0x03.01 用途

1. `hexo init`



在所在文件夹初始化hexo并创建相关文件

2. `hexo deploy`



使用指定在`_config.yml`的部署方式部署

3. `hexo generate`



生成静态文件，与`hexo deploy`共用

4. `hexo clean`



清除上次生成的文件

5. `hexo new "文章名称"`



在`博客目录/source/_post`目录下生成一篇名称为`文章名称.md`的文件

6. `hexo new page "页面名称"`



在`博客目录/source/页面名称`目录下生成一篇名为`index.md`的文件

更多命令请参照[Hexo文档](https://hexo.io/zh-cn/docs/commands)

### 0x03.02 命令缩写

可缩写的命令（格式：`原命令 -> 新命令`）

```
hexo deploy -> hexo d
hexo generate -> hexo g
```

## 0x04 标准文章格式

当你执行了`hexo new "文章名称"`时，你的`博客目录/source/_post`下的`文章名称.md`会出现以下内容：

```
---
title: 文章名称
date: 你的时间戳
tags:
---
```

你可以通过在这个文件中输入一些markdown文本来写一篇文章（已经存在的东西**不能删**，否则会报错的）

特殊标签：`<!-- more -->`，使用后会在你的博客首页上显示这篇文章时出现这个按钮（用的别人的图）
