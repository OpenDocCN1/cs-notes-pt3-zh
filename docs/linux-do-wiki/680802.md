# 关于 Navidrome/Subsonic 的Windows客户端体验报告



## 1. 前情提要

原本我经常用的 navidrome Windows 客户端一直是音流，但是从 1.3.6 版本后 Windows 上播放就一直出问题，一直到现在也没解决，并且开发版停滞已经一个月了，不清楚出了什么问题，于是开始搜罗各种 navidrome/subsonic 支持的 Windows 客户端来体验，也欢迎大家来贡献你用过的客户端。



以下客户端不分次序，仅为体验顺序，随时更新

## 2. 体验报告

### 2.1 Feishin

Feishin 是 [navidome 官方推荐的 Windows 客户端](https://www.navidrome.org/docs/overview/#apps) 之一，项目地址：[GitHub - jeffvli/feishin: A modern self-hosted music player.](https://github.com/jeffvli/feishin)



是我目前主要使用的客户端

#### 优点：

- 功能几乎与 navidrome 官方同步，支持的官方特性也非常多，如智能播放列表自定义、回放增益调整、歌曲切换淡入淡出、硬件转码等

- 尤其指出能自定义智能播放列表，无需手动调整 JSON 文件了，这也是我主要使用它的理由![image.png2114×1297 213 KB](https://cdn3.ldstatic.com/original/4X/1/e/1/1e1ce2d66389aa04779c53357adf9602af15830e.jpeg)

#### 缺点：

- 默认界面充满了工业风（程序员代码风），并且窗口顶栏无法更换颜色，导致界面看上去非常割裂。不过有提供自定义 CSS 功能，我还没有尝试过。另外默认设置对于我的 2k 屏幕显示字体太小了，但是设置中可以调整缩放率为 120，效果就是上图的样子

- 功能分区非常乱，不整洁，也缺乏功能分区之间的间隔，一眼看上去乱糟糟的，菜单层级太多

- 部分常见功能隐藏在设置页中，并默认禁用，比如 “保存播放队列 “，如果不开启你每次退出客户端都无法保存上次的播放进度，需要重新添加播放列表

- 双语歌词无法两行显示

- 界面点击偶尔会有迟滞

- 无桌面歌词功能

### 2.2 Aonsoku

也是 navidrome 官方推荐的客户端之一，项目地址：[GitHub - victoralvesf/aonsoku: A modern desktop client for Navidrome/Subsonic servers built with React and Rust.](https://github.com/victoralvesf/aonsoku)

#### 优点：

- 界面比 Feishin 整洁漂亮一些，主要使用 React 和 Rust 构建（这能算优点吗）

- 内置了丰富的主题![image.png1716×1198 178 KB](https://cdn3.ldstatic.com/original/4X/5/9/c/59c895f7c6fec879891e10b32167d856319577df.jpeg)

- 有回放增益功能

- 双语歌词可以分两行显示

#### 缺点：

- 侧边栏不能展开，只能显示小图标，用着很不习惯

- 不支持创建智能播放列表，但已创建的智能播放列表识别正常

- 我最厌恶的播放页与歌词页分栏显示，整个界面就显得非常不整齐，头重脚轻

- 无桌面歌词功能

### 2.3 netPlayer-Next

应该是华人开发者制作的一个客户端，使用 Flutter 构建，项目地址：[GitHub - Zhoucheng133/netPlayer-Next: A Subsonic & Navidrome based music player](https://github.com/Zhoucheng133/netPlayer-Next)

#### 优点：

- 极度简洁的界面，感觉很舒服，极简爱好者可能会喜欢

- 播放信息与歌词在同一页面，歌词可以简单调整字号

- 支持自定义 WebSocket 服务的功能，适合直播展示歌曲信息、进度等，具体查看文档 [GitHub - Zhoucheng133/netPlayer-Next: A Subsonic & Navidrome based music player](https://github.com/Zhoucheng133/netPlayer-Next?tab=readme-ov-file#websocket%E6%9C%8D%E5%8A%A1)

#### 缺点：

- 成也简洁，负也简洁，大概极简风格就都是这样。歌曲、专辑、艺人等都不能显示预览图

- 歌曲信息不全，没有音频格式、音轨、文件大小等信息显示

- 播放页面无法调整封面显示大小，界面利用率很低

- 没有播放增益、桌面歌词等功能，也无法自定义主题

- 无法使用本地内置歌词，只能依赖网络搜索，且不稳定
