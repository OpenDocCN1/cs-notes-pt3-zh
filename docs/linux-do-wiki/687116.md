# Alpine Linux创建Cloudflare Tunnel守护程序OpenRC

不想搞反向代理也可以这样用。服务器还不怕被打，因为全走cloudflare 流量
![](https://cdn3.ldstatic.com/optimized/4X/a/e/d/aededae05019b09a560af62edcac4e22b5ddb6fc_2_690x345.png)
### [Releases · cloudflare/cloudflared](https://github.com/cloudflare/cloudflared/releases/)
Cloudflare Tunnel client. Contribute to cloudflare/cloudflared development by creating an account on GitHub.
下载适合你的最新发行版。并存放在 /usr/sbin/cloudflared
# 创建 服务项 /etc/init.d/cloudflared
```
touch /etc/init.d/cloudflared
vi /etc/init.d/cloudflared
```
粘贴以下内容进去 并修改token值
```
#!/sbin/openrc-run

command="/usr/sbin/cloudflared"
command_args="tunnel --no-autoupdate --edge-ip-version auto --protocol auto run --token eyJhIjoiM2IwMjJiN2VkYWVjZTEzMmUzMWE1
pidfile="/run/cloudflared.pid"
name="cloudflared"
description="Cloudflare Tunnel daemon"
command_background=true
```
赋予权限
```
chmod +x /etc/init.d/cloudflared
```
# 开机启动
```
rc-update add cloudflared
rc-status
```
