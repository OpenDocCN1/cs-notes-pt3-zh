# 个人使用cloudflare R2做图床，支持转换格式和压缩 s3-image-port

### [GitHub - yy4382/s3-image-port: A dashboard to manage your images in S3 buckets....](https://github.com/yy4382/s3-image-port)
A dashboard to manage your images in S3 buckets. Can be used as a image hosting service.
先前有Cloudflare imgbad项目太重了。随后找到轻量化纯前端。 s3-image-port
1. 自定义CDN前缀
2. 格式转换
3. 图片有损压缩
4. 自部署无服务器serverless
作者提供了使用前端。只需要在后台添加自己的S3存储即可，
# 创建R2桶和API令牌。
创建一个`标准`R2桶，位置可选 `apac 亚太地区`
创建一个`User API`的  `对象读和写` 权限的令牌
# 按照创建的令牌填入 上传前端界面

# 自部署
github项目仓库提供了Vercel部署方式，当然也可以部署在cloudflare。
有服务器使用常规方式映射网页目录
无服务器下载github releases的static.tar.gz文件并解压

在cloudflare pages创建并上传`public`文件夹下的内容
# cros 跨域问题
[https://your.domian](https://your.domian) 替换成你的前端地址
```
[
  {
    "AllowedOrigins": [
      "https://your.domian"
    ],
    "AllowedMethods": [
      "GET",
      "PUT",
      "DELETE"
    ],
    "AllowedHeaders": [
      "*"
    ]
  }
]
```
# 缓存配置
这个改为你的r2桶自定义域名 `img.your.domian/*`
在你的域名下 找到 页面规则。添加页面规则
