## 0x02 能做什么？
那既然要学一个东西，那肯定要先搞清楚它到底能做什么？或者说，他与大模型的关系，和大模型有什么区别？
上一章也讲了，LLM翻译过来是大语言模型，那从名字来看，那就是基于语言的，也就是文本。最常见的大模型就是通过聊天对话的方式进行交互，也就是用户输入文字，模型也是使用文本的方式进行回答问题，当然现在也有许多的多模态模型，也就是能支持图像、音频甚至是视频的输入输出，但是最常见的还是以文本形式进行交互的。

在图中呢，我就举了一个很简单的例子，左边的图就是常规的大模型，只能进行基本的对话，问题询问等。
而右边的图，模型可以通过使用工具，帮助用户获取邮箱信息，或者回复邮箱，这就好像人和动物的区别（人类会使用工具）。
当然Agent能做的事情远不止回复邮件这么简单的事情，帮你写代码，帮你规划旅行等，可以好好发挥想象力。

接下来再定义一个LLMConfig类，用来存储一些大模型的一些配置，包括API信息以及模型参数信息
```
# File -> mrai/agent/llm/llm_config.py
class LLMConfig(BaseModel):

    base_url: str = Field(default="https://api.openai.com/v1", description="The base URL for the OpenAI API")
    api_key: str = Field(..., description="The API key for the OpenAI API")
    model: str = Field(..., description="The model to use for the OpenAI API")
    temperature: float = Field(default=0.5, description="The temperature for the OpenAI API")
    max_tokens: int = Field(default=1000, description="The maximum number of tokens for the OpenAI API")
    top_p: float = Field(default=1.0, description="The top P for the OpenAI API")
    frequency_penalty: float = Field(default=0.0, description="The frequency penalty for the OpenAI API")
    api_type: Literal["openai", "azure"] = Field(default="openai", description="The type of API to use")
    reasoning_effort: Literal["low", "high"] | None = Field(default=None, description="The effort for the OpenAI API")
    seed: int = Field(default=None, description="The seed for the OpenAI API")
```
再稍微说明一下这些参数分别的意义
- base_url: 模型服务提供方的API地址，例如OpenAI的是[https://api.openai.com/v1](https://api.openai.com/v1)
- api_key: 服务提供方的密钥
- model: 模型名称，例如gpt-4o、deepseek-v3
- temperature: 模型的温度，范围0-1，越大模型的回复约具有创造性，但也更不可控
- max_tokens: 模型的最大上下文长度
- top_p: 也叫做 nucleus sampling，用于控制模型回复的随机性
- frequency_penalty: 用来惩罚出现过多次的词
- reasoning_effort: 对于推理模型的设置，控制推理的思维链的长度

```
class LLM:

    def __init__(self, config: LLMConfig):
        # validate config
		# ...

    @staticmethod
    def format_messages(messages: Sequence[Union[str, dict, Message]]) -> List[ChatCompletionMessageParam]:
		# 格式化传入的消息
        # ...

    @staticmethod
    def _process_tool_call(tool_call, tools: List[Tool]) -> ToolCall:
        """Process a single tool call and return a ToolCall object"""
        # 处理返回结果中的tool call，并结构化
		# ...

	# 模型调用方法
    async def chat(self, messages: Sequence[Union[str, dict, Message]], tools: list[Tool] = []) -> Message:
        dict_messages: List[ChatCompletionMessageParam] = self.format_messages(messages)

        # 构建请求参数
        params = {
            "model": self.config.model,
            "messages": dict_messages,
            "temperature": self.config.temperature,
            "max_tokens": self.config.max_tokens,
            "top_p": self.config.top_p
        }
        if self.config.seed is not None:
            params["seed"] = self.config.seed

        # 如果有工具，则添加工具相关参数
        if tools:
            params["tools"] = cast(Iterable[ChatCompletionToolParam], [tool.to_dict() for tool in tools])
            params["tool_choice"] = "auto"

        response = await self.client.chat.completions.create(**params)
        if not response.choices:
            raise ValueError("No response from OpenAI")

        tool_calls: list[ToolCall] = []
        content: str = ""
        if not response.choices[0]:
            raise ValueError("No response from OpenAI")
        # default use the first choice
        choice = response.choices[0]
        if choice.message.content:
            content = choice.message.content
        if choice.message.tool_calls and tools:
            tool_calls.extend(
                self._process_tool_call(tool_call, tools)
                for tool_call in choice.message.tool_calls
            )

        assistant_message = Message(
            role=choice.message.role,
            content=content,
            tool_calls=tool_calls
        )
        return assistant_message

    async def stream_chat(
        self, messages: Sequence[Union[str, dict, Message]],
        tools: list[Tool] = [],
        flag: bool = False
    ) -> AsyncIterator[str]:
        dict_messages: List[ChatCompletionMessageParam] = self.format_messages(messages)

        # 构建请求参数
        params = {
            "model": self.config.model,
            "messages": dict_messages,
            "temperature": self.config.temperature,
            "max_tokens": self.config.max_tokens,
            "top_p": self.config.top_p,
            "stream": True
        }
        if self.config.seed is not None:
            params["seed"] = self.config.seed

        # 如果有工具，则添加工具相关参数
        if tools:
            params["tools"] = cast(Iterable[ChatCompletionToolParam], [tool.to_dict() for tool in tools])
            params["tool_choice"] = "auto"

        async for chunk in await self.client.chat.completions.create(**params):
            if chunk.choices[0].delta.content:
                if flag:
                    yield "content::" + chunk.choices[0].delta.content
                else:
                    yield chunk.choices[0].delta.content
            if chunk.choices[0].delta.model_extra:
                for key, value in chunk.choices[0].delta.model_extra.items():
                    if value:
                        if flag:
                            yield f"{key}::{value}"
                        else:
                            yield value
```
其中chat、及stream_chat方法就是最重要的方法，通过传入消息以及可以调用的工具，即可发起对模型的调用。
如果不是很熟悉大模型调用API的，可能一看这么多代码，一下子就懵了，让我用一个简单的例子说明一下。
[image3002×650 94.9 KB](https://cdn3.ldstatic.com/original/4X/3/1/7/3178092170a5bde3f1d357814cc67156140e50bd.png)
这是用标准的OpenAI API调用模型接口的例子，这里的OpenAI指的并不是这家公司本身，而指的是OpenAI公司定义的一套API协议，所以实际上就是一个接口，同时如果在请求体里加上加上"stream": true的参数，接口则会以流式响应的方式返回内容，有兴趣的可以自己尝试一下。
在接口的请求体中，包含了messages、model等参数，messages定义了模型输入的上下文，模型就会基于上下文进行回答，那model则定义了到底是调用的哪一个模型。
