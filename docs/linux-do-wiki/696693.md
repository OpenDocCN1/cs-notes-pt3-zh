# 在住房无网线飞牛OS玩转PT



我的NAS是自己组的一台主机，系统装的是飞牛OS安装详情如下：[飞牛私有云 fnOS（免费NAS系统）安装_飞牛nas安装教程-CSDN博客](https://blog.csdn.net/weixin_64931825/article/details/145128984)

选择无网线估计也跟我一样只有一台笔记本，可以买一个采集卡连接笔记本当成显示屏来用，采集卡几十块钱的就可以了。

买了服务器之后准备工作就做的差不多了。

笔记本下载个ssh工具，我用的是FinalShell。



进入阿里云点右上角控制台然后点你的服务器，进去重置密码

[微信截图_20250603153713414×140 15.5 KB](https://cdn3.ldstatic.com/original/4X/8/1/1/81185960c54dd71068616f55de7894e144e1139d.jpeg)

然后接着点【安全组】进去把你的端口放行出来，要是嫌麻烦直接把所有端口都放出来。

然后用FinalShell，新建连接输入服务器ip，root加上你重置的密码进入服务器。



下载frp安装教程： [使用 systemd | frp](https://gofrp.org/zh-cn/docs/setup/systemd/) 发布页：[Releases · fatedier/frp](https://github.com/fatedier/frp/releases)



把下载的frps跟frps.toml放到服务器上就可以。一般是 linux_amd64.tar.gz，下载这个就可以版本不要太低之外无所谓



frps.toml的配置如下

```
bindAddr = "0.0.0.0"
bindPort = 7000

auth.token = "随便填，这是认证的字符串"
```

**systemd**里面配置的ExecStart = /path/to/frps -c /path/to/frps.toml



要根据你frps放的地方来改

[微信截图_202506031615191038×465 132 KB](https://cdn3.ldstatic.com/original/4X/a/2/8/a28b85c56d19d09c0ba55a685f0cad3a7a684fef.jpeg)

```
ExecStart = /root/frp/frps -c /root/frp/frps.toml
```

然后看一下你的服务器有没有开防火墙，有开的话记得把你要的端口放行

一般要开端口就两个地方都要一个是服务器里面的防火墙，一个是阿里云的安全组

启动成功后查看状态如下

[成功状态640×196 112 KB](https://cdn3.ldstatic.com/original/4X/5/2/4/524a6e0eae62154acca9c6d6f02dc99cc93d22e6.jpeg)

服务器暂时告一段落。

笔记本连NAS一样的WiFi，通过飞牛OS给的ip跟端口用浏览器登录WEB页面。打开系统设置里的安全性，看看http端口，要改也可以。

[飞牛端口1096×633 51.9 KB](https://cdn3.ldstatic.com/original/4X/7/1/f/71fdc113a91c378977ef54963af10cf5fc01cfdf.jpeg)

去文件管理创建文件夹跟上传一下frpc.toml文件

[fprc配置1083×619 94.3 KB](https://cdn3.ldstatic.com/original/4X/0/b/a/0ba120bd34fc9ea17733490255655bfb3ca37f14.jpeg)

frpc.toml配置如下

```
serverAddr = "你的服务器ip"
serverPort = 7000

auth.token = "上面fprs设置的认证的字符串"

[[proxies]]
 name = "Nas"
 type = "tcp"
 localIP = "127.0.0.1"
 localPort = 9002
 remotePort = 9002
```

端口根据你的飞牛os的设置写

打开docker去镜像仓库查frpc，装这个，然后去本地镜像创建容器。

[微信截图_20250603155640664×537 57.2 KB](https://cdn3.ldstatic.com/original/4X/2/b/5/2b5418275dcff0916485b0de87e634fa6b7cc578.jpeg)

[微信截图_20250603155724629×339 32 KB](https://cdn3.ldstatic.com/original/4X/1/5/d/15d8c99974baa27a89e863832891ac6ef50783b7.jpeg)

如果网络选不了host，先把其他勾选的取消掉然后可以选了。

最好启动两个容器，一个是飞牛端口的穿透，一个是其他程序的穿透。不然每次创建别的容器要把端口穿透出来改完配置都要重启frpc容器的。

然后就要到的安装QB了，可以用飞牛OS整的qb也可以去Docker安装，简单整我就直接默认用飞牛的。

qb默认端口是8085，飞牛的是不能改这个端口，docker的是可以改。



用frp将8085穿透出来，加配置重启容器

```
[[proxies]]
 name = "QB"
 type = "tcp"
 localIP = "127.0.0.1"
 localPort = 8085
 remotePort = 8085
```

进到qb用刚刚设置的密码，账号是admin登录进去。



现在你可以用种子直接下载了，但是会发现无法上传，这时候就要用代理服务器。

现在回到服务器，要下载gost： [GOST | GOST v2](https://v2.gost.run/)  发布页：[Releases · ginuerzh/gost · GitHub](https://github.com/ginuerzh/gost/releases)

跟frp一样下载完程序直接放服务器上，命令如下

```
./gost -L=socks5://用户名:密码@0.0.0.0:8081?udp=true&udpBufferSize=4096

这条命令只是测试用的
```

建议跟frp一样用 **systemd**

```
vim /etc/systemd/system/gost.service
```

配置如下

```
[Unit]
# 服务名称，可自定义
Description = gost server
After = network.target syslog.target
Wants = network.target

[Service]
Type = simple
# 启动gost的命令，需修改为您的frps的安装路径
ExecStart = /root/gost/gost -L=socks5://用户名:密码@0.0.0.0:10000?udp=true&udpBufferSize=4096

[Install]
WantedBy = multi-user.target
```

启动停止跟查看状态命令跟frp一样，只是把frp改成gost

接下来我们回到qb

打开设置，点连接。完成结果如下图

[微信截图_20250603162124698×682 125 KB](https://cdn3.ldstatic.com/original/4X/0/d/6/0d6256225478439a6ab9bd20c2c71660db082189.jpeg)

在frpc.toml把传入连接的端口放行出来，tcp跟udp

```
 [[proxies]]
 name = "QBListenTCP"
 type = "tcp"
 localIP = "127.0.0.1"
 localPort = 63219
 remotePort = 63219

[[proxies]]
 name = "QBListenUDP"
 type = "udp"
 localIP = "127.0.0.1"
 localPort = 63219
 remotePort = 63219
```

主机就是你的服务器ip或域名
