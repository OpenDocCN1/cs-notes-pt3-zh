# VS Code扩展



# 预览

Image preview：预览图片



Live Server：实时查看html页面



Color Highinght：颜色高亮显示



Error Lens：将错误显示在行内

# 补全

npm Intellisensenpm：根据 package.json 自动补全 import 语句中的 npm 模块名



path-intellisense：补全文件路径



AutoScssStruct4Vue：根据Vue结构，右键点击，生成scss文件



Auto import：自动引入

# 检查

Code Spell Checker：拼写检查

# 代码片段

javascript-es6-snippets：es6代码片段



ES7 React/Redux/GraphQL/React-Native snippets



Vue VSCode Snippets：片段更多，内容更合理，持续更新中

# 转跳

CSS Navigation：ctrl点击类名跳转样式

# Vue 框架

Vue 2：Vetur



Vue 3：Vue - Official 1070MB

# uni-app 框架

uni-helper：集合包，实现代码高亮、代码片段

# 格式化

Prettier：格式化工具

# Git

Git History：提交历史记录，回退提交



GitLens：工具

# 语言包

indent-rainbow：缩进颜色显示



ESLint：格式化js为规范



Quokka.js：预览纯js文件，React收费



Stylelint：辅助CSS属性书写顺序，减少回流提高可维护性



stagewise：指定页面的元素让ai修改



GitHub Copilot  350MB



koroFileHeader：添加函数注释，快捷键无占用的情况下无反应

uniapp小程序扩展：悬停查看文档，很少用
