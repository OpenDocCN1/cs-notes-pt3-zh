# Windows使用虚拟硬盘替代硬盘分区



## 一、原因

现在的Windows电脑，尤其是笔记本电脑，大多只会配备一个硬盘位，而且大多数人应该也就用一块硬盘。虽然很多人说，以现在固态硬盘的性能，其实没有必要分区，但是不分区在重装系统和文件整理方面还是不是很方便。在我的实际使用中，分区有以下优点和问题

- 优点：



分类方便，可以设置系统、软件、数据、开发等多个分区，简洁明了

重装系统方便，直接格式化C盘，不必担心数据丢失

- 问题：



如果一开始没有预估好分区大小，后续调整前面的硬盘分区如C盘扩容会比较困难

正好前段时间看到并尝试了一下Windows 11的 [开发驱动器](https://learn.microsoft.com/zh-cn/windows/dev-drive/)，除了创建新分区方式，也可以创建vhdx虚拟硬盘来使用。在经过了一番搜索后，使用vhdx对硬盘性能的损失并不大，而且vhdx能够非常方便地进行动态扩容和压缩，而且在跨电脑的迁移中有着无法比拟的优势，直接迁移vhdx文件本身即可。

于是，我做出了以下尝试。

### 3. 关于开发者驱动器

通过虚拟硬盘文件方式创建开发者驱动器，和我上面的内容没有太大区别。主要多干了两件事

1. 格式化为ReFS格式而不是NFS格式

2. 在Windows Defender中为对应驱动器开启专用的filter，不会实时进行杀毒，性能会更好。

## 三、优势

1. 不用再关心硬盘分区大小

2. 迁移到新电脑只需迁移对应的vhdx文件即可，不必担心丢失数据

3. 如果要重装系统，可以直接通过对C盘执行压缩卷，创建一个新分区，把vhdx文件移动过去，即可格式化C盘进行重装

## 四、缺点

1. 有一点点操作门槛

2. 硬盘性能会有一点损失

3. 如果是挂载到目录下使用，部分程序可能会有问题，比如chromium无法直接在这个目录下运行，不太清楚原因。

数据安全上我不太清楚会不会有什么问题，如果系统突然坏了，我进PE应当也是能够把虚拟硬盘文件迁出来的，如果硬盘直接坏了，鉴于我也就一块硬盘，本来能救不了的话现在也救不了。
