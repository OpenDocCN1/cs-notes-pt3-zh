# 公共云盘存储私密文件的审视



根据最近的alist事件，让我想起了阿里云盘当初可以查看他人图片的bug，包括各种私密照。重新审视了公共云盘存储个人私密资料的问题

私密文件包括不限于：

- 包含个人信息的图片

- 存储个人资料文件

- 文件中包含个人信息

存储在公共云盘上的文件或多或少会因为云盘服务提供商的问题或者自己的问题导致泄露：

- 公共云盘服务商泄露：公共云盘漏洞，导致被非法访问

- 自己问题导致的泄露：授权的第三方应用出现问题，比如目前的alist

如何应对：

- 使用公共云盘提供商开发的手机软件默认一般都会开启相册备份，微信文件备份，初次使用请小心确认，否则会后台上传

- 桌面备份备份文件夹：很多情况都是直接备份文件夹，因此做好文件夹分类，做到备份的文件夹不包含个人信息

- 公共云盘第三方应用：因为alist的爆火，现在的很多公共云盘都开放了第三方应用，使用这些第三方应用授权的时候注意

补救措施：

- 如果是第三方应用出现问题，可能导致泄露或者发现已经爆出该应用出现问题，到云盘授权中心解绑授权

- 像alist中挂载的网盘没有授权，使用cookie登录的，登录对应的云盘，退出所有设备，让cookie失效

最重要的：

- 不存储个人私密文件

- 公共云盘在我看来只适合存储一些不太重要的文件，比如软件，文档，像个人照片，微信聊天记录这些都不适合存储在公共云盘
