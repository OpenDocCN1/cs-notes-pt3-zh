# 📚【c++从入门到入睡】const与类型转换

# ◢ 声明与定义
声明是表明**符号存在**。
```
extern int a;  // 有一个名为a的int类型符号
void fun();    // 隐式extern，有一个名为fun的函数类ing符号
```
定义则是**声明+声明的实现**。
- 对于`typedef`，声明就是实现`typedef int INT;  // 定义INT为int的别名 `
- 对于函数，**包含函数体**即定义`int fun();  // 声明  int fun(){  // 定义     return 0; } `
- 对于非函数变量，**分配对应内存**空间即定义`extern int a;  // 声明，extern表明定义在别处，不会分配空间 int a; // 定义 `
## ❖ 初始化
自动存储期对象（后面会讲）定义分配的空间中的值是以前使用遗留下来的垃圾值，需要进行**初始化**。
```
int a;     // 定义未初始化，有垃圾值
int b = 1; // 定义并初始化为值1
```
定义时初始化会直接在目标空间上生成，**没有垃圾值中间态**。
## ❖ 重复性
不能重定义。

可以重声明，但必须指向同一个实体。
```
extern int x;
int x = 10; // OK
extern int x; // OK
```
# ◢ 常量
常量的值不可改。
主要有两种，**const常量**和**宏常量**。
```
const int a = 1;  // const常量
#define A 1       // 宏常量
```
宏常量只是在预处理期（后面帖子会讲）进行文本替换，**没有类型安全检查**。
一般情况下写代码时将const常量作为宏常量的上位替代，仅在两种场景使用宏常量：
- 头文件保护（后面帖子会讲）
- 条件编译
## ❖ 初始化
常量一旦具有值则不可改，那么**常量定义时必须初始化**。
const常量本质是一个**只读的变量**，特殊情况下可以转换成非const变量来更改值。
# ◢ 类型转换
C++提供4种类型转换：
- const_cast常量转换

将非原生const类型转为非const类型，以**const定义的变量不能去除const限定符**。
- dynamic_cast动态转换

在运行期进行的继承体系内的安全转换（后面会讲）。
- reinterpret_cast位重解释

通过重新解释底层位模式在类型间转换，慎用。
剩余的转换要么可以隐式转换，要么就可以用`static_cast`进行转换。
## ❖ 目标类型
类型转换的使用格式为`关键字<目标类型>(源变量)`。

`const_cast` 和 `dynamic_cast` 要求目标类型是**指针或引用**。
# ◢ constexpr
特殊的const，要求常量初始化的表达式编译期可求值（即使可能不会那么做）。
```
constexpr int a = 1;  // OK
constexpr int b = time(nullptr);  // 运行时才能计算，error
```
## ❖ 要求编译期就确定值的常用场景
- 类型推导

数组声明

`int arr[10];  // 10处的变量必须编译期时可求值 `

枚举值定义

`// 枚举值处的变量必须编译期时可求值 enum Color { Red = 1, Green = Red + 1 }; `

模板类型推导

`std::array<int, 256> arr;  // 256处的变量必须编译期时可求值 `

模板非类型参数

`template<int N> struct A {}; A<256> r;  // 256处的变量必须编译期时可求值 `
- `switch`表达式的`case`标签`switch(code) { case CONST_VAL:   ...      // CONST_VAL 必须编译期可求 } `
# ◢ 最佳实践
- 能用`constexpr`的地方就使用。
- 需要运行时确定的常量再使用`const`。
