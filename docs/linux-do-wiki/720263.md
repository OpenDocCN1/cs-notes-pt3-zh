# **当个AI提问**

也可以在地址栏输入 选择chat。

## Personalize 四个选项我的理解

- 第一项看起来是品味。 我不太理解，大概是你喜欢什么品牌、作家等的风格吧。比如鲁迅分、川普风。![:monkey:](img/7ef765a493bc7325ed37f7861060daef.png)

- 第二项那里，如果你常看见他时不时出来英文，也可以在这里提醒他 speak chinese。 具体描述你喜欢什么形式内容更容易接受。比如分段落展示、脑图、图标等等。

- 第三项 我理解是输出的风格、形式等吧。比如加不加emoji。

- 第四项是关于编程偏好的设定，比如你用什么语言、什么架构、什么框架等等等。

在arc里感觉分屏好爽。但在这里我接受dia的操作很难受。

如果在当前访问的页面中想点击其他链接并分屏展示，按住`option` 点击链接。

拖拽可以实现分屏，但才做不当就是拖成了单tab窗口。![:downcast_face_with_sweat:](img/1c5ae7b99a34088156fdd2b9934e3940.png)

组合的分屏，右键其他tab选择 `Open as Split` 可能更舒服吧。

## 事实核查

```
Read this page and provide:
## Skills
1. 理解网页内容并提炼关键信息。
2. 识别和分析作者的观点与事实。
3. 查询相关数据以验证观点的准确性。
4. 评估观点的积极性或消极性。
## Background
准确核查作者的观点对于了解论据的可靠性和有效性至关重要，通过比较观点与现实情况，可以更好地理解其重要性。
## Goals
1. 优化提示词，使其不仅提炼信息，而且检查事实的准确性。
2. 识别作者观点是否为主流意见。
3. 评估描述的事实是否真实且有数据支持。
Keep it under 400 words total. speak Chinese.
```
