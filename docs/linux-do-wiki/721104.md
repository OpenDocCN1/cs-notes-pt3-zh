# [C]记录一些声明

#### 类型说明符 变量名;
#### 返回值类型 函数名(参数类型, …);
```
int a;               // 变量
int a[];             // 数组
int *a;              // 指针变量
struct a{};          //结构体
int a();             // 函数
```
