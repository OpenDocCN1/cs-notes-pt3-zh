## ![:gear:](https://linux.do/images/emoji/twemoji/gear.png?v=15) 构建生产包（关键步骤！）
### ![:play_button:](https://linux.do/images/emoji/twemoji/play_button.png?v=15) 步骤 1：获取源码
```
git clone https://github.com/lobehub/lobe-chat.git
cd lobe-chat
```
> ![:light_bulb:](https://linux.do/images/emoji/twemoji/light_bulb.png?v=15) 手残党替代方案：直接下载 [GitHub 仓库 ZIP](https://github.com/lobehub/lobe-chat/archive/refs/heads/main.zip)
### ![:play_button:](https://linux.do/images/emoji/twemoji/play_button.png?v=15) 步骤 2：防爆内存补丁（低内存必看！）
修改 `package.json` 中的构建命令：
```
"build:docker":
- "npm run prebuild && DOCKER=true cross-env next build && npm run build-sitemap"
+ "npm run prebuild && DOCKER=true cross-env NODE_OPTIONS=--max-old-space-size=12288 next build && npm run build-sitemap"
```
> ![:sparkles:](https://linux.do/images/emoji/twemoji/sparkles.png?v=15) 原理：给 Node.js 喂 12GB 内存饲料，避免构建时撑死，这里根据你的环境内存来，注意一定要改，否则16G以下内存必定卡死
### ![:play_button:](https://linux.do/images/emoji/twemoji/play_button.png?v=15) 步骤 3：启动魔法构建
```
bun install    # 用Bun安装依赖（强烈推荐bun比pnpm更防玄学，不信邪的可以自己试试pnpm）
bun build:docker # 开始构建！
```
![:hot_beverage:](https://linux.do/images/emoji/twemoji/hot_beverage.png?v=15) 趁机喝杯咖啡（构建约 5-10 分钟）
### ![:play_button:](https://linux.do/images/emoji/twemoji/play_button.png?v=15) 步骤 4：打包胜利果实
```
zip -r archive.zip .next/standalone
```
得到 `archive.zip` 即为部署文件！
