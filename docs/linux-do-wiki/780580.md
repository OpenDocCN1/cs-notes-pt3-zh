## 1. 平时我们vibe coding的习惯

平时我们都是直接打字文本让AI帮我们自动生成代码，比如

- 需要分析代码，你会发`帮我查看当前项目的代码，并分析它的架构和技术栈...`

- 需要用特定框架写代码， 你会发`请使用react和typescript实现todo list`

## 2. SuperClaude的角色方式

如果每次都这样写会效率相对比较低，如果我设置好每个开发环节的角色的话，然后通过关键词就可以快速开始按照要求进行开发，缩短vibe coding描述开发需求的速度，同时规范的预设了开发中的不同角色的，SuperClaude提供了9种专业化的思维模式（Personas）

- **architect**：系统设计和可扩展性

- **frontend**：用户体验和React开发

- **backend**：API开发和性能优化

- **security**：威胁建模和安全代码

- **analyzer**：根因分析和调试

- **mentor**：教学和指导

- **refactorer**：代码质量和简化

- **performance**：性能优化

- **qa**：质量保证和测试

## 命令格式

SuperClaude 有丰富的命令可以处理不同工程流程中的任务，举几个例子

```
# 解释下面的任务：
# 1. 使用react开发项目
# 2. 使用tdd模式进行开发
# 3. 开发角色为前端工程师
/build --react --tdd --persona-frontend
```

通用的格式

```
/命令名 --标志1 --标志2 --persona-角色名 "任务描述"
```

## 3. SuperClaude 的外部依赖

SuperClaude依赖了下面的mcp server

- Context7: 文档查找 | 官方源验证

- Sequential: 复杂分析 | 系统化思考

- Magic: UI组件 | 设计系统集成

- Puppeteer: 浏览器自动化 | E2E测试

所以需要用下面的命令为claude code 安装 mcp

```
# Context7
claude mcp add --transport http context7 https://mcp.context7.com/mcp

# sequential-thinking
claude mcp add sequential-thinking npx @modelcontextprotocol/server-sequential-thinking

# puppeteer
claude mcp add puppeteer npx @modelcontextprotocol/server-puppeteer

# magic (https://21st.dev/magic)
claude mcp add magic npx @21st-dev/magic@latest --env API_KEY=<your-api-key>
```

**magic是不错的UI设计工具，它会给你生成不同样式的UI方案给你选择，之前看到有佬说Claude开发出来的页面太偏爱紫色和很重的Claude风格样式，用magic的话可以去Claude UI化。所以强烈推荐，下面是用magic生成superclaude命令页面的截图：**
