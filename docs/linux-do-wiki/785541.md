# 拒绝技术无知！两句话让你理解微服务！知道它是个什么东西！



微服务的核心思想是把传统软件内的个个小功能拆分成一个个的独立的小应用，并通过规定小应用的调用方法传递的参数和输出使一个个小应用串联起来成大应用，比如现在有一个电商网站和播客网站都需要图片上传压缩功能，传统开发是两个网站独立开发一次的图片压缩功能，微服务则是单独写一个图片压缩的小应用部署到服务器上（或者函数计算），电商和博客网站只需要按图片压缩的微服务模块文档调用这个图片压缩的小功能就可以了实现图片压缩的功能。
