# 💥【图文教程】无需服务器，搭建自己的导航站

示例站点:[https://nav.maodeyu.fun](https://nav.maodeyu.fun)
> [!Danger]  2.0更新 ，推荐升级，修复密钥问题 **前端代码不再包含任何敏感信息**
# 升级步骤
- fork 仓库
- 修改cf配置的环境变量，新建变量不要带 github 跟admin_pass的vite前缀
- 从新部署

# 前置条件
- Github 账号
- Vercel 或 Cloudflare账号
- 域名(可有可无。没有只能用部署站自带的域名)
# 部署流程
## 1.fork工程
- 登录你的[Github](https://github.com)账户
- 访问并fork[猫猫导航工程](https://github.com/maodeyu180/mao_nav)(如果可以，点个Star吧)

[局部截取_20250715_1329541651×1119 126 KB](https://cdn3.ldstatic.com/original/4X/8/4/7/847712825cd58c15f62156d6b5bdf673e6396b0c.png)
## 2.创建github_token(可选，如需admin增删改查)
- 访问[Sign in to GitHub · GitHub](https://github.com/settings/personal-access-tokens)
- 新建token输入参数，过期时间选不过期，**授权只选刚才fork的工程，只授权 Repository permissions 的Contents 的读写权限跟 metadata的读权限， token泄露也只会影响当前仓库。**

[局部截取_20250715_133237874×1269 62 KB](https://cdn3.ldstatic.com/original/4X/9/a/f/9afa58711aa04694eb0091ce45264e34493a7a50.png)

[局部截取_20250715_1336361003×1108 78 KB](https://cdn3.ldstatic.com/original/4X/2/a/1/2a1251c8273312e4c04c036dd79de6e6fe74d269.png)
- 点击Generate Token 复制token 存起来后续需要用到。
## 3.部署到cf,Vercel流程也类似。
- 访问cf dash面板 [https://dash.cloudflare.com/](https://dash.cloudflare.com/)
- 选择Workers&Pages → 选择Pages标签 → Get Started

[局部截取_20250715_1340381728×1183 93.7 KB](https://cdn3.ldstatic.com/original/4X/9/1/7/917f956067832e33ffcb342cfc9fb27b12d0fa92.png)
- 关联你的github仓库,也是推荐只授权你需要的仓库

[局部截取_20250715_1341551094×1011 45.7 KB](https://cdn3.ldstatic.com/original/4X/a/5/8/a5841b8032dc69375955e25530e8610227972521.png)
- 选择工程点击Begin setup
- 框架选择Vue, Build command 输入“npm run build”; output dir 输入“dist”
[局部截取_20250715_1343381123×1128 29.3 KB](https://cdn3.ldstatic.com/original/4X/c/b/3/cb3e277155ea6e98e5340d4f32aacd3ae2a9fe2e.png)
- 如需admin界面添加环境变量，不需要直接点击保存部署即可
- 环境变量示例如下图
```
VITE_ADMIN_PASSWORD 是你进入admin界面需要输入的密钥
VITE_GITHUB_OWNER 是你github 用户名
假如你fork仓库后你仓库的地址是 https://github.com/xxx/mao_nav
VITE_GITHUB_OWNER 就输入 xxx  VITE_GITHUB_REPO 就输入mao_nav
```
[局部截取_20250715_1346491098×967 30 KB](https://cdn3.ldstatic.com/original/4X/9/4/0/9405112f1b1794618421c0c44394c57417afca50.png)
- 等待部署完成点击Visit即可访问

[局部截取_20250715_1350561445×701 32.5 KB](https://cdn3.ldstatic.com/original/4X/7/1/9/719adbce35dee3f14618e9c4cb950c5ca0f76bee.png)
- 点击custom domains 输入你的二级域名，cname到提供的地址即可通过自己的域名实现访问

[局部截取_20250715_1351501401×634 28.6 KB](https://cdn3.ldstatic.com/original/4X/c/d/8/cd8a608ffbcae591c7599dd4a6c1d1065b9b6d97.png)
# 自定义站点分类。
## 1.部署了admin
访问站点/admin 输入环境变量配置的密码即可进行站点编辑
## 2.直接修改仓库
直接修改仓库 /src/mock/mock_data.js 文件
## 修改后需等cf 或 vercel 自动编译部署，成功后即可展示新的导航内容。
# 结尾
站点是根据个人喜好编写，喜欢的佬可以尝试部署玩一玩。

欢迎佬提意见，改进完善。

