# 【开源项目文档翻译】做了一个半自动化的文档翻译工具，并打算维护一些开源项目的中文文档，大家有什么想要的中文文档吗。



因为很多开源项目的都只提供英文文档，虽然谷歌翻译，沉浸式翻译之后的也能看，但总感觉不太舒服。所以设计了这个翻译工具。目前维护了几个ai开发相关的文档，langchain/langgraph/agno。



**佬友们有想看的中文文档也可以和我说，我加上。**
