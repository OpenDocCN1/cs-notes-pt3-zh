# 国际数学奥林匹克 IMO 2025 澳大利亚



国际数学奥林匹克（IMO）是所有国际奥林匹克竞赛中规模最大、最负盛名的赛事，参赛国家从最初的七个发展到如今的一百多个国家。IMO汇聚了来自世界各地最聪明的年轻人，代表着多年来数学探索和数百次解题尝试的巅峰。
