# 通过Github Action 编译rustdesk

## 偶然刷到一个大佬的教程，结合自己的实际操作交给AI总结了一下，留下了这个文档。

大佬原贴：

[RustDesk通过API防止服务器被滥用 自动编译将服务器等信息内置客户端](https://www.smianao.com/1414.html)
### ![:wrench:](https://linux.do/images/emoji/twemoji/wrench.png?v=15) **完整操作步骤**
#### ![:gear:](https://linux.do/images/emoji/twemoji/gear.png?v=15) 1. **Fork 主项目和子模块**
- 主项目 (rustdesk)：

在 GitHub 页面点击 `Fork`，生成你的副本 `https://github.com/你的用户名/rustdesk`。
- 子模块 (hbb_common)：

同样 Fork 到你的账户：`https://github.com/你的用户名/hbb_common`。
#### ![:laptop:](https://linux.do/images/emoji/twemoji/laptop.png?v=15) 2. **克隆主项目并配置子模块**
```
# 克隆你的主项目副本
git clone https://github.com/你的用户名/rustdesk
cd rustdesk

# 修改 .gitmodules 中的子模块 URL
git config -f .gitmodules submodule.libs/hbb_common.url https://github.com/你的用户名/hbb_common.git

#.gitmodules内容如下
[submodule "libs/hbb_common"]
	path = libs/hbb_common
	url = <替换为我们fork的hbb_common项目地址>

# 初始化并同步子模块
git submodule sync
git submodule update --init --recursive
```
- **验证**：运行 `git config -f .gitmodules --get submodule.libs/hbb_common.url`，确认 URL 已更新为你的仓库。
#### ![:hammer_and_wrench:](https://linux.do/images/emoji/twemoji/hammer_and_wrench.png?v=15) 3. **修改代码**
- 主项目文件：

修改 `src/common.rs` 和 `flutter/lib/desktop/pages/connection_page.dart`。

`##API服务器修改方法： 打开src\common.rs    #在947行替换API地址 可以通过搜索get_api_server_，然后往下翻找到.to_owned()，替换前面的URL即可  ##删除客户端广告提示 打开flutter/lib/desktop/pages/connection_page.dart #81-110行代码替换如下：     Widget setupServerWidget() => Flexible(        child: Offstage(          offstage: !(!_svcStopped.value &&              stateGlobal.svcStatus.value == SvcStatus.ready &&              _svcIsUsingPublicServer.value),          child: Row(            crossAxisAlignment: CrossAxisAlignment.center,            children: [],           ),        ),      );             #原代码为：     setupServerWidget() => Flexible(           child: Offstage(             offstage: !(!_svcStopped.value &&                 stateGlobal.svcStatus.value == SvcStatus.ready &&                 _svcIsUsingPublicServer.value),             child: Row(               crossAxisAlignment: CrossAxisAlignment.center,               children: [                 Text(', ', style: TextStyle(fontSize: em)),                 Flexible(                   child: InkWell(                     onTap: onUsePublicServerGuide,                     child: Row(                       children: [                         Flexible(                           child: Text(                             translate('setup_server_tip'),                             style: TextStyle(                                 decoration: TextDecoration.underline,                                 fontSize: em),                           ),                         ),                       ],                     ),                   ),                 )               ],             ),           ),         ); `
- 子模块文件：

进入子模块目录：`cd libs/hbb_common`

修改 `src/config.rs`并提交：
`打开src/config.rs文件   #修改该文件的101-102行，分别是服务器及KEY pub const RENDEZVOUS_SERVERS: &[&str] = &["<自己的id_server>，不带端口"]; pub const RS_PUB_KEY: &str = "<自己的id_ed25519.pub>";   原代码： pub const RENDEZVOUS_SERVERS: &[&str] = &["rs-ny.rustdesk.com"]; pub const RS_PUB_KEY: &str = "OeVuKk5nlHiXp+APNn0Y3pC1Iwpwn44JGqrQCsWqmBw="; `
提交
`git checkout -b fix-branch  # 建议新建分支 git add src/config.rs git commit -m "修改 config.rs" git push origin fix-branch   # 推送到你的 hbb_common 仓库 `
#### ![:link:](https://linux.do/images/emoji/twemoji/link.png?v=15) 4. **同步子模块到主项目**
```
# 返回主项目目录
cd ../..

# 更新主项目对子模块的引用（指向子模块的最新提交）
git add libs/hbb_common
git commit -m "更新子模块 hbb_common 到修改后的版本"
```
#### ![:label:](https://linux.do/images/emoji/twemoji/label.png?v=15) 5. **创建 Tag v1.4.2**
```
# 确保所有修改已提交到主分支
git checkout master  # 或你的目标分支

# 创建附注标签（包含修改记录）
git tag -a v1.4.2 -m "Release 1.4.2 with custom fixes"
```
- **验证**：运行 `git show v1.4.2`，检查提交是否包含子模块更新和文件修改。
#### ![:outbox_tray:](https://linux.do/images/emoji/twemoji/outbox_tray.png?v=15) 6. **推送所有更改到远程仓库**
```
# 推送主项目代码和标签
git push origin master
git push origin v1.4.2

# 推送子模块分支（确保修改被主项目引用）
cd libs/hbb_common
git push origin fix-branch
```
### ![:gem_stone:](https://linux.do/images/emoji/twemoji/gem_stone.png?v=15)开始编译
在Action页面中，选择Flutter Nightly Build，然后编译标签选择v1.4.2即可。
![:pushpin:](https://linux.do/images/emoji/twemoji/pushpin.png?v=15)附一个Rustdesk中继服务器部署的docker-compose文件
```
 networks:
   rustdesk-net:
     external: false
 services:
   rustdesk:
     ports:
       - 21114:21114
       - 21115:21115
       - 21116:21116
       - 21116:21116/udp
       - 21117:21117
       - 21118:21118
       - 21119:21119
     image: lejianwen/rustdesk-server-s6:latest
     environment:
       - RELAY=<relay_server[:port]>
       - ENCRYPTED_ONLY=1
       - MUST_LOGIN=Y
       - TZ=Asia/Shanghai
       - RUSTDESK_API_RUSTDESK_ID_SERVER=<id_server[:21116]>
       - RUSTDESK_API_RUSTDESK_RELAY_SERVER=<relay_server[:21117]>
       - RUSTDESK_API_RUSTDESK_API_SERVER=http://<api_server[:21114]>
       - RUSTDESK_API_KEY_FILE=/data/id_ed25519.pub
       - RUSTDESK_API_JWT_KEY=xxxxxx #自己随机一个字符串出来
     volumes:
       - ./data/rustdesk/server:/data
       - ./data/rustdesk/api:/app/data #将数据库挂载
     networks:
       - rustdesk-net
     restart: unless-stopped
```
参数提示：
```
RELAY=<relay_server[:port]> #中继服务器:21117
MUST_LOGIN=N #默认为N，设置为Y 则必须登录才能链接
RUSTDESK_API_RUSTDESK_ID_SERVER=<id_server[:21116]> #ID服务器
RUSTDESK_API_RUSTDESK_RELAY_SERVER=<relay_server[:21117]> #中继服务器
RUSTDESK_API_RUSTDESK_API_SERVER=http://<api_server[:21114]> #API服务器
RUSTDESK_API_JWT_KEY=xxxxxx #随便设置个字符串
/data/rustdesk/server #查看 key
```
