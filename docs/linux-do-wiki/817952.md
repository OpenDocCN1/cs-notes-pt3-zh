# 【72 的软件 001】Rime 输入法引擎+ 万象拼音输入方案 懒人配置



# 一、下载 Rime 输入法引擎

[下載 小狼毫 0.17.4](https://github.com/rime/weasel/releases/download/0.17.4/weasel-0.17.4.0-installer.exe)，默认下一步直至安装完成。

# 二、下载万象拼音输入方案

版本 v12.2.7

## 2.1 标准版输入方案

[rime-wanxiang-base.zip](https://github.com/amzxyz/rime_wanxiang/releases/download/v12.2.7/rime-wanxiang-base.zip)

## 2.2 语法模型

[wanxiang-lts-zh-hans.gram](https://github.com/amzxyz/RIME-LMDG/releases/download/LTS/wanxiang-lts-zh-hans.gram)

# 三、部署用户配置

## 3.1 切换到小狼毫输入法

点击任务栏输入法图标，切换到小狼毫输入法

[image736×510 52.3 KB](https://cdn3.ldstatic.com/original/4X/f/d/2/fd29ee5e20a326c05220cc336bae2b896d0e03c6.jpeg)

## 3.2 打开用户配置目录

除了下图菜单打开目录，也可以在资源管理器输入：`%AppData%\Rime` 来快速打开目录

[image404×650 42.8 KB](https://cdn3.ldstatic.com/original/4X/2/1/2/2121e6e2f647c18a6a80dffa1469830759bca208.png)

## 3.3 放入语法模型文件

将 「**2.2 语法模型**」下载的文件放入用户配置目录下

[image914×656 34.6 KB](https://cdn3.ldstatic.com/original/4X/e/f/b/efb6e69c4ae3820bf5001e1cd8fee3e6d8ca96a0.png)

## 3.4 放入标准版输入方案

将 「**2.1 标准版输入方案**」下载的输入方案解压到用户配置目录下

[image1392×752 51.7 KB](https://cdn3.ldstatic.com/original/4X/3/2/2/322d925edc9bb10808aa0f38ba84755131674700.png)

## 3.5 重新部署

右键「**中**」，选择「**重新部署**」，等待 1~2 分钟部署完成

## 3.6 切换到万象拼音

右键「**中**」图标，点击「**输入法设定**」，勾选「**万象拼音**」，取消勾选不需要的其他方案项目，「**确认**」

## 3.7 修改用户输入类型配置

在任意输入框输入以下指令(斜杠引导)切换为对应的双拼/全拼，切换后按照提示再次「**重新部署**」



/flypy		→ 小鹤双拼



/mspy		→ 微软双拼



/zrm		→ 自然码



/sogou		→ 搜狗双拼



/abc		→ 智能ABC



/ziguang	→ 紫光双拼



/pyjj		→ 拼音加加



/gbpy		→ 国标双拼



/lxsq		→ 乱序17



/pinyin		→ 全拼

## 3.8 配置自定义短语（建议）

自定义短语添加到用户配置目录下的 custom_phrase.txt，再次「**重新部署**」即可

> 注意短语、输入码、序号之间使用 Tab 分隔
