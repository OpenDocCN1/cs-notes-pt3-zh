# 个人英语学习方式分享



被丢到英国了说是



将学习英语分为学习语法与单词



这里先从单词讲起,个人将记住一个单词分为

- 记住读音

- 记住拼写

- 记住意思

# 怎么读

其中由于“自然拼读”(看到一个单词/读音就大概知道怎么读/写)的存在,可以把“记住拼写”省略掉,从而省去最费时间和脑子的单词拼写,从而更快更轻松的记下单词(ps:要做到自然拼读就是多读,读多了你就大概知道特定组合该怎么拼).举个例子,international ,in/ter/na/tio/nal

# 怎么记什么意思

你可以把单词近似的看作短语，举个简单的例子,unbelievable ,un(不能)believe(相信)able(的),也就是构词法,个人认为你不需要过于死板的一个个去记什么后缀前缀的,你只需要知道主干,也就是beliebe,结合上下文就能大概知道含义

# 补充

对于单词的拆分不仅可以按照读音/含义进行拆分，实际上还可以怎么舒服怎么拆分，关键是读的顺口,比如 library 我就会拆成 lib/rar/y ,读的越顺口,记得越轻松

# 语法

对于语法,我个人是没有多么高超的技巧的,但还是能稍微的给几个建议

- 最轻松的记忆方式是多读,多用,然后你自然就懂了

- 较为吃脑子的方式就是全部的词语翻译一遍然后拼成句子

- 比较不吃脑子的就是抓整体,把一个句子拆成若干较小的整体,能更好的方便理解带有that/which等词语的长难句(很抱歉我暂时想不出例句帮助理解)

- 邪修: 抛弃句子中一切与形容相关的玩意（形容词/副词/时间/地点),只用主谓宾来理解句子

# 其他的小建议

## 不背没必要的单词

当一个单词考试和交流都用不上的时候，我记住他一个der用?浪费时间浪费脑子



如果是以应试为目的,个人认为自己手动整理高频词表比对着那些单词背有用至少4倍

## 复习是必不可少的

永远不要觉得你现在我“记住”的单词是真的”记住”了,打个比方就是你验证码输完后,过几分钟就会立刻忘记。而防止这个的方法就是按照以下的方法来记单词（个人方法）



假设我们有4批单词A，B，C，D，那么我们每次就背诵两批,



[A],[A,B],[B,C],[C,D],[D,A]



个人认为这对于记忆单词的效率/效果提升很大

## 应付考试的技巧

核心就是关键词比对啦,找那个看起来像是关键词的家伙,然后在文本中找到长得和选项差不多的玩意就可以了

## 听力技巧

首先说明,这个技巧很折磨自己,是种邪修,具体的就是用高于正常速度的方法读文本,当你适应了2倍速的文本阅读速度的时候,1倍速就是慢放

# 总结

要想要轻松的方法，多用,用多了就会理所应当的会了(即使你可能没发现)



想要快一点的方法,手动总结规律

# 如何开始

上面的内容可以说是对英语有一定基础的人的捷径,但对于初学者还是很有难度,个人建议初学者一定一定要把音标摸透,以 Good Good G-oo-d Good，好的令人愉快的 的这种方式来读出单词,配合上面提到的复习相关的内容来使用,最重要的是要常读！！！
