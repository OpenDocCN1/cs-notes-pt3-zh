# ArchLinux下用systemd-resolved配置来使用公共DNS时过慢的可能的解决措施（经验分享+吐槽）

可能是多个网络连接导致，如同时连接了某个路由器的无线、有线网络而其中一个脱了后腿。断开其中一个连接可能可以以正常速率解析DNS。
另外，要注意对DoT进行设置。目前在我的电脑上测试发现只有阿里的公共DNS支持DoT。虽然我目前搜集到的消息是DNSPod（鹅厂提供）、Alidns（阿里提供）以及360提供的DNS （不知道360的DNS的称呼，这里就直接这样写了） 都支持DoT，但个人实测发现只有Alidns能正常使用DoT（也许只是我这里是这样？不知道大家是不是也是这样）。如果想开启DoT可能需要删除另外俩DNS。
感谢ArchLinux社区的各位提供帮助。
这个DoT的问题就当是我信息搜集能力不足吧，我忍了。但当我配了半天的网络才发现问题在于路由器的无线路由功能有缺陷而不是软件的配置的时候我是崩溃的……我也不知道为什么路由和DNS这俩完全没关系的东西会有关系啊！我在路由器上也没设DNS啊，我把DNS的任务都交给我的笔记本了啊，为什么问题会出在路由器上？
