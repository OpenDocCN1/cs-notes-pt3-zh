# wayland环境fcitx5在vscode终端中输入中文偶尔卡停



大家好, 我想求助一个问题:



我在wayland环境下使用fcitx5在vscode内部的终端输入中文会面临偶尔被卡住的情况.



具体情况是:



我在正常的输入中文, 但是突然在某个毫无征兆的时刻, 在我敲击空格时, 我敲出的文字没有被输出到终端中. 我发现当出现这个情况的时候多敲击一下空格, 然后再删掉空格就又能继续敲中文了. 但是仍然有可能在敲击几个汉字后突然重复出现无法输出汉字的情况.
