**大多数人初次遇到这道题想必会一条一条打**  后来还衍生出了用C++写C++ 图案输出的壮举



***But 其实还可以直接 Ctr + C  Ctr + V  ***  *那就是原始字符串字面量输出（Raw String* Literals） 也就是他能包含换行符号（原始数据）直接输出 不必在哪里疯狂的\n了 ![:grin:](https://linux.do/images/emoji/twemoji/grin.png?v=15)

```
#include<bits/stdc++.h>
using namespace std;
int main(){
      cout<<R"(                ********
               ************
               ####....#.
             #..###.....##....
             ###.......######              ###            ###
                ...........               #...#          #...#
               ##*#######                 #.#.#          #.#.#
            ####*******######             #.#.#          #.#.#
           ...#***.****.*###....          #...#          #...#
           ....**********##.....           ###            ###
           ....****    *****....
             ####        ####
           ######        ######
##############################################################
#...#......#.##...#......#.##...#......#.##------------------#
###########################################------------------#
#..#....#....##..#....#....##..#....#....#####################
##########################################    #----------#

##########################################    #----------#
#.#..#....#..##.#..#....#..##.#..#....#..#    #----------#
##########################################    ############
)"<<endl;
}
```
