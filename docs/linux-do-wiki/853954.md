# 【工具分享】「沉浸式翻译」的一些替代品



# 一、开源方案

## ReadFrog

官网： [陪读蛙](https://www.readfrog.app/zh)



Chrome 插件地址：[https://chromewebstore.google.com/detail/read-frog-open-source-imm/modkelfkcfjpgbfmnbnllalkiogfofhb?utm_source=official](https://chromewebstore.google.com/detail/read-frog-open-source-imm/modkelfkcfjpgbfmnbnllalkiogfofhb?utm_source=official)

### 特点

- 翻译 & 总结网页内容

- 支持自定义提示词

- 自定义 API - 设置选项中的 高级选项下可以自定义 Host

- **注意事项**： 慎用一键全文翻译，看起来并发数比较高，对于部分中转商可能会触发 IP 限制。

## FluentReader：

地址： [GitHub - FluentRead/FluentRead: An open-source browser extension for bilingual translation. 一款开源的浏览器双语翻译插件。 · GitHub](https://github.com/Bistutu/FluentRead)

### 特点

- 配置简单

- 支持自定义 API

- 支持划词翻译

- 支持快捷键翻译

- 内置多种样式

- 支持自定义提示词(选择 「AI 翻译」分组下的服务）

## Kiss Translator:

地址：[GitHub - fishjar/kiss-translator: A simple, open source bilingual translation extension & Greasemonkey script (一个简约、开源的 双语对照翻译扩展 & 油猴脚本) · GitHub](https://github.com/fishjar/kiss-translator)

### 特点：

- 支持 WebDAV 同步设置 ([【工具分享】两款支持 Web DAV 的网盘](https://linux.do/t/topic/854248))

- 支持自己配置规则

- 支持自定义 API

- 支持收藏单词

- 支持划词翻译

- 快捷键设置 → `chrome://extensions/shortcuts` 找到 Kiss Translator 可以设置。 感谢佬友提供的方案 [@Sakyvo](/u/sakyvo)

- 自定义提示词



配置方法：[@J4mes](/u/j4mes) 佬友分享的 [[求助] 有没有能替代沉浸式翻译得插件 - #22，来自 J4mes](https://linux.do/t/topic/852722/22)

- 自定义样式



样式可以参考佬友分享的 CSS: [沉浸式翻译的开源类似物 - #42，来自 duckduckgogo](https://linux.do/t/topic/853137/42)

# 二、闭源或商业方案

## Lulu Translator(欧陆翻译）: 欧陆词典推出的翻译服务，欧陆词典 - 词典届的大哥大了

地址：[https://chromewebstore.google.com/detail/欧路翻译-沉浸网页划词翻译工具/djbfechcnkppbknmlhfcaoifgnicolin?hl=en-US&utm_source=ext_sidebar](https://chromewebstore.google.com/detail/%E6%AC%A7%E8%B7%AF%E7%BF%BB%E8%AF%91-%E6%B2%89%E6%B5%B8%E7%BD%91%E9%A1%B5%E5%88%92%E8%AF%8D%E7%BF%BB%E8%AF%91%E5%B7%A5%E5%85%B7/djbfechcnkppbknmlhfcaoifgnicolin?hl=en-US&utm_source=ext_sidebar)

### 特点

- 支持自定义 API

- 支持视频字幕（需要在设置中手动开启）

- 支持同步生词到 「欧陆词典」

- 默认设置几种默认翻译风格，（目前无法自定义提示词、无法自定义翻译风格）

# 三、其他部分划词翻译类工具

## 划词翻译

### [定价说明 | 划词翻译](https://www.hcfy.ai/docs/pricing/)

免费使用

## 沙拉词典

### [Saladict 沙拉查词](https://saladict.crimx.com/)

Saladict 沙拉查词 聚合词典划词翻译 是一款专业划词翻译扩展，为交叉阅读而生。大量权威词典涵盖中英日韩法德西语，支持复杂的划词操作、生词本、以及 PDF 划词。

## Online dict helper

### [Online Dictionary Helper - Chrome Web Store](https://chromewebstore.google.com/detail/online-dictionary-helper/lppjdajkacanlmpbbcdkccjkdbpllajb?hl=en-US&utm_source=ext_sidebar)

A translation popup tool to show online dictionary content (with anki support)

- 可以划词之后制作 Anki card
