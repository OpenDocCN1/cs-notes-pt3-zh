# Rclone + NSSM 将 Cloudflare R2 挂载为 Windows 本地磁盘

早上花了一个多小时折腾R2挂载 简单记录一下自己折腾的过程
## 创建CloudflareR2 储存桶
应该是最不容易翻车的一步，注意R2的免费额度需要绑卡，只有10G 读写次数很多 可以当作用不完 无流量费 注意防止被反薅
**创建访问密钥** 注意设置令牌权限 指定储存桶 权限要允许读写

## 开始配置
### Rclone
1. 打开 PowerShell（或 CMD），进入你存放 rclone 的目录。
2. 运行配置命令：`.\rclone.exe config`
3. 接下来，rclone 会通过问答的形式进行配置：
- `n) New remote` → 输入 `n`，回车。
- `name>` → 给你的 R2 仓库起个名字，比如 `CF`。
- `Storage>` → 选择 `S3` 协议。
- `provider>` → 选择 `Cloudflare`。
- `access_key_id` & `secret_access_key` → 输入你刚刚获取的访问信息
- `endpoint>` → 输入新建访问密钥时显示的endpoint
- `use advanced configs` →  输入`n`
1. 最后确认无误，输入 `y` 保存配置。
### 配置nsmm
1. 将nssm.exe 放置到rclone.exe的同目录下，打开 PowerShell（或 CMD），进入你存放 rclone 的目录。
2. 运行配置命令：`.\rclone.exe config`
3. 创建服务 `.\nssm.exe install rclone-mount`
4. 此时会弹出一个图形配置界面，你需要填写：
- **Application选项卡:**

`Path`: 点击 `...` 按钮，选择你的 `rclone.exe` 的完整路径。
`Startup directory`: 必须是 `rclone.exe` 所在的文件夹路径（应该会自动填入）。
`Arguments`: `mount CF:<你的储存桶名称> R: --vfs-cache-mode full --links --config "C:\Users\<你的用户名>\AppData\Roaming\rclone\rclone.conf`
1. 启动服务 以后该服务就会开机自启 `.\nssm.exe start rclone-mount`
