# 【教程分享】macOS 26 beta5、6 Spotlight 内存泄露 问题修复



1. `sudo mdutil -X /;`

2. `sudo mdutil -X /System/Volumes/Preboot;`

3. `sudo mdutil -X /System/Volumes/Data`

删除所有 spotlight 索引，我这里之前已经索引完成了，命令执行之后是立即生效了，内存从90G 占用直接降到 1G，如果有的佬友不生效的话可以等待系统索引完成，应该就不会再有问题了。

希望 Apple 早日修复。。。
