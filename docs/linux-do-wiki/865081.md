# AI聊天
主流的AI聊天应用有ChatGPT，Claude，Grok等，通过账号登录即可直接和大模型对话。

另外，Chatbox，Cherry Studio，SillyTavern（酒馆）等应用，支持接入第三方API调用任何模型。参见【客户端】部分。
## [ChatGPT](https://chatgpt.com)
OpenAI推出的著名聊天应用，可以免费使用，付费解锁更多模型和用量。

模型可联网搜索。

Google/Apple登录，目前已经不用手机号验证。

现已更新到GPT-5，付费用户也可以回滚到传统模型。

**降智现象：不好的IP等种种原因均可导致模型质量变差，不思考等问题。原因尚未完全明确，遇到了也不容易解决。IP质量检测工具：🎉一站式ChatGPT增强工具ChatGPT Helper来了!支持检测降智等功能**

**免费版只能自动路由，次数用完后只能用mini模型**

白嫖会员方法：[https://linux.do/t/topic/865050](https://linux.do/t/topic/865050)
## [Claude](https://claude.ai)
注册较麻烦，可能需要使用手机号验证，IP不稳定等因素可能直接封号。

相关工具，始皇亲作：[【v0.4.1】闲来无事搓的一个小玩具](https://linux.do/t/topic/131611) （反向代理Claude官网，[始皇的Demo站](https://demo.fuclaude.com)）

部分免费用户可以使用Claude 4.1 Opus但是非常少。

工具调用、代码等能力较强。

模型现在已经可以联网搜索。

**免费版砍上下文**

**免费版次数较少**
## [Grok](https://grok.com)
Google/X账号直接登录，免费可用Grok 3和少量Grok 4。

模型可联网搜索，可以搜索X上的帖子。

免费版即可使用计划、项目等功能。

付费版可以使用更多Grok 4以及Grok 4 Heavy。

**没有或者较少的NSFW等限制**
## [Gemini](https://gemini.google.com)
Google账号登录，免费使用，网页版体验较差。[Google 官方的神级提示词 / 自信的 Gemini](https://linux.do/t/topic/773437)

部分国家可以通过学生认证白嫖专业版。[Gemini 学生优惠活动又开始啦！截止到10月6日，支持美国、巴西、印度尼西亚、日本、墨西哥、韩国](https://linux.do/t/topic/848074)
# API
通过API可以在很多应用中调用各个厂商的大模型。
## [Azure](https://ai.azure.com)
OpenAI全部模型和其他一些开源模型，稳定，部署较麻烦。

之前国内可以开出模型来，可以用学生的100刀或者新号的200刀白嫖，现在开不出来了。企业用户不影响。[Azure 开始遣返 CN OpenAI 用户了？](https://linux.do/t/topic/689609)

之前开出来的模型应该还可以用。

企业用户推荐使用。
## [Gemini](https://aistudio.google.com/)
免费，Google账号登录。

近期截断/429（Rate Limit）/封号等情况较多，官方已开始风控。

防断流工具：[https://linux.do/t/topic/836702](https://linux.do/t/topic/836702)

Docker版：[[Gemini防断流] （移步新帖）燃尽了... | Docker一键部署](https://linux.do/t/topic/864242)

新玩法：在公开代码中查找Gemini的key并使用负载均衡工具调用，俗称“打野”。

打野：[https://linux.do/t/topic/818860](https://linux.do/t/topic/818860)

负载均衡工具：[【T佬】GPT-Load 1.0正式版发布，支持多渠道Key池轮询代理服务！](https://linux.do/t/topic/789409)
## [OpenRouter](https://openrouter.ai)
二道贩子，模型聚合平台，可以找到模型在各个渠道上的定价。

提供免费模型，无需绑卡，Google等平台账号登录。

免费DeepSeek R1，Kimi K2，GLM 4.5 Air。
## [ModelScope 魔搭](https://modelscope.cn)
阿里云旗下，提供一些开源模型（主要为国内），每天2000次API请求。

免费Qwen3，DeepSeek R1，GLM 4.5：[Qwen3-Coder 的食用方法（建议从魔搭每日免费 500 次请求开始——魔搭将免费额度从 1k 砍到了 500），改了 30 次帖子了！）](https://linux.do/t/topic/809617)
## [Groq](https://groq.com)
做推理芯片的厂商，速度非常快，提供Llama 4/gpt-oss/Kimi K2等开源模型，也有OpenAI Whisper语音识别模型。

免费使用，有速率限制。
## [硅基流动](https://siliconflow.cn)
国内平台，注册送14元key，提供开源模型，有Qwen 3/DeepSeek R1/Kimi K2/GLM 4.5等。

刷邀请可以获得更多额度，现在必须使用手机号。
## [智谱](https://bigmodel.cn)
GLM系列模型，注册送免费token额度，**提供Claude格式接口方便接入Claude Code**。
## [DeepSeek](https://platform.deepseek.com)
提供DeepSeek模型，速度偏慢。错峰时段价格打折。
# 编程工具
接入API或付费订阅，一般具有Agent功能，可以进行代码修改、补全等。
## [Claude Code](https://www.anthropic.com/claude-code)
最著名的编程工具，终端中使用。
```
npm install -g @anthropic-ai/claude-code
```
默认接入Claude，可以使用Claude Code Router接入其他模型：[【Claude Code】使用 claude-code-router 快速配置第三方模型(新增Qwen3示例)](https://linux.do/t/topic/787270)

此外智谱和New API也提供Claude格式接口，可以直接接入。[在 New API 使用 Claude Code 再也不用便秘💩了](https://linux.do/t/topic/852752)

接入方法：
```
export ANTHROPIC_BASE_URL=https://your-api-domain/
export ANTHROPIC_AUTH_TOKEN=your-api-key
```
## [Gemini CLI](https://github.com/google-gemini/gemini-cli)
开源的Agent工具，Google登录/API密钥鉴权，免费版每天50次Gemini 2.5 Pro。

衍生项目：[Qwen Code](https://github.com/QwenLM/qwen-code)，每天2000次免费请求。

基于VS Code，迁移较为方便。

**老号仍然可以使用ZFB续费**
