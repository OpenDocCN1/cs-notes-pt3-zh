# shopee兑换GPT plus 踩坑指北



兄弟们，历经不懈的努力，终于撸到了三个月的ChatPlus会员，并且成功兑换。下面讲一讲我踩过的坑。其实说是10块-20块撸三个月会员指的是你已经撸过，对流程比较熟悉。对于新人来说其实隐形成本是有点高的，我来罗列一下隐形成本。

**前提**



我注册、付款购买ShopeeVIP 全程用的是美国节点（搬瓦工VPS搭建的vmess），只有在兑换时才用的是印尼节点。

- whatsapp接码需要不停的试，找到一个能正常注册的手机号，其次注册完在登录shopee时有概率秒封。下面是我用的接码网站 **grizzlysms** ， 我这里是注册了两次whatsapp，基本上是花了大概0.7美刀差不多，这个接不到码是不会扣费的。有最低充值要求2美刀，大家自辩。（**成本14元**）



![image1557×715 58.2 KB](https://cdn3.ldstatic.com/original/4X/3/6/0/360bafd7db113595db206a485ced098aeb803cfd.png)

- 下载印尼区shopee，我是苹果用户，这里必须使用印尼区的ID下载，我试过香港、台湾的都不行。苹果用户可以去官网修改地区为印度尼西亚（成本0元）

- 付款，这里我要讲一下，我本来是有一张visa卡的，在shopee中绑定了我的visa卡后发现无法支付，转而使用wise进行国际汇款。wise注册流程按照官网的来就好了，整体没什么难度，注册完了之后添加visa充值印尼盾，汇款到shopee（visa最低充值3美刀，然后记得一定要往shopee里汇入大于28000印尼盾，最好是3w印尼盾（一定不要卡在14900印尼盾的到账金额），手续费扣的有点多。不要像我一样第一次没汇够，第二次又充值3美刀购买印尼盾）这里成本是6美刀（42元）

- 最后一步激活，这里一定要用到印尼节点，我是购买的 **云通** 按量付费的节点，**成本1元** 最后也是成功注册了。上截图
