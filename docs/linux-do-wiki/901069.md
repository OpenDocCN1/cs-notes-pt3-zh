# 教程：Firefox 设置快捷搜索图标



所谓快捷搜索就是地址栏输入几个字母+空格+关键词就能方便地调用不同搜索引擎。



![屏幕截图](img/c50163bf75d8306432ecdafa174d35d6.png)

![屏幕截图957×347 17.6 KB](img/b69a8fd885b77ff90a995d60dec4f865.png)

如图，Firefox 的快捷搜索似乎不支持自定义图标。

注意到 Firefox 配置根目录有个文件叫 search.json.mozlz4，search.json 被加密了，可能是为了防止流氓软件篡改。

[jusw85/mozlz4](https://github.com/jusw85/mozlz4) 可以解密这个，

```
mozlz4-win64.exe -x search.json.mozlz4 search.json
```

然后把搜索引擎的 _iconURL 字段改为一个图标 URL，比如设为`https://github.com/favicon.ico`。

最后加密

```
mozlz4-win64.exe -z search.json search.json.mozlz4
```

覆盖原文件再重启浏览器就会生效。



![屏幕截图 2025-08-26 231209](img/03178ef921a55eeabc9aef5e75bee899.png)

**千万不要修改 id 字段，否则重启后 search.json 可能被重置！**
