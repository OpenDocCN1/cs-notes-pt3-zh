### 讯飞、搜狗、百度、苹果、微软、谷歌语音输入法，免费的不是挺好的吗？
这些输入法的识别率，大概排到第五梯队

如果只是聊天、发短信，识别率高低影响不大，用这些免费的语音输入法也凑合

如果是写文章、写笔记，写作业或者工作邮件等严肃场合，听写识别率就很重要了

免费的往往是最贵的，免费的代价就是用户的时间和效率，比如说一个人月薪8000块，他一小时的时薪就是50，如果AI语音输入法每个月能节省一小时，就价值50

我用AI输入法量很大，每个月能为我节省上百小时的时间

比如写1000字，用讯飞语音输入法，你输入之后的修改时间，加上录入时间，可能是第一梯队输入法的三到五倍。换而言之，讯飞输入法算上修改时间，可能与打字速度差不多

## 主机的选择：Macbook最佳
现阶段只有Mac上面最好的语音输入法，能达到最高识别率，是第一梯队(听写强润色强有提成)

## AI语音输入法的选择：VoiceInk最佳，Spokenly第二，SuperWhisper第三
### 三者共通优点
都支持最强听写模型4o-transcribe和elevenlabs-scribe API

都支持最强润色模型gemini-2.5-pro或sonnet-4 API

功能大同小异，各有所长
### VoiceInk(Mac)⁵
#### 主要优点
可以双开或者三开VoiceInk APP，方法详见后面内容

软件本身是开源免费的，但是要从GitHub上下载DMG才是免费的，也没有包月会员

支持GPT-4o-transcribe和elevenlabs-scribe API

一旦听写失败，可以手动重新识别并重新润色

上传文件识别，可以自动润色

elevenlabs-scribe没有明显时长限制
#### 主要缺点
4o-transcribe限制25分钟或2000字，这是模型本身的限制，但VoiceInk没有做音频自动切割，来突破这个限制。

没有iOS/Win/安卓版
### Spokenly(Mac)⁵
#### 主要优点
是唯一支持GPT-4o-Transcribe和elevenlabs-scribe不限量包月的语音输入法。

其他语音输入法都要自备API

有iOS版，但是严重缩水

不买包月只是包月模型不能用，可以使用API以及所有功能。

一旦听写失败，可以重新识别，但并不会润色

上传文件识别时，不能用包月模型，限制50m(约25分钟)，只能手动开启润色

Mac版选elevenlabs-scribe有1400秒(23分钟)限制，长录音或者会议肯定超过23分钟，模型本身限制是10小时，这个限制应该是Spokenly加的，用来节省成本

Mac版4o-transcribe貌似也有限制

iOS无此时间限制
#### 主要缺点
不支持多开

没有Win/安卓版，作者也明确近期不打算移植
### SuperWhisper(Mac)⁵
#### 主要优点
可双开或三开

有iOS版和Windows版，但是严重缩水。没有按照版
#### 主要缺点
使用API Key也要包月，8美元，每月不hold

听写API只能用官网的GPT-4o-transcribe的Key，不能用中转站，也不支持ElevenLabs
## 润色模型的选择
### Ⓐgemini-2.5-pro(推荐)
**主要优点**：没有缩写的问题。 一般输出到32K都是可以的

GCP300或中转站都很便宜
### Ⓑsonnet-4
**主要优点**：没有缩写的问题。 一般输出到32K都是可以的

**主要缺点**：没有很便宜又保真的API
### ⒸGrok-4
**主要优点**：没有缩写的问题，我实测最多一次输出到17万字

**主要缺点**：没有很便宜又保真的API
### Ⓓgpt-5(不推荐)
**主要优点**：智力高

如果用4o-transcribe，可以共用Azure试用账号Key

**主要缺点**：但是如果录音比较长，它经常会缩写，这是OpenAI模型的老毛病了，所有OpenAI模型都不同程度的有这个问题

例如我昨天听写一段6000字的内容，它给我缩写到3000字，而且没有任何提示，你不仔细去数字数的话，你根本就不会注意到它给你缩写了，仅从外观上看，3000字也是一大堆，6000字也是一大堆。 很难直接看出来
### ⒺDeepSeek3.1/r1(不推荐)
**主要缺点**：可能容易有缩写的问题

速度慢，听写对推理速度要求很高，尤其是不双开轮流录的情况下
## 听写模型的选择：elevenlabs-scribe最佳
### Ⓐelevenlabs-scribe⁵(推荐)
base_url/model_id：一般不需要填
#### 主要优点
老牌AI语音专业公司

没有繁简体，标点符号，幻觉问题

连续录音最大10小时
#### 主要缺点
本身不接受提示词，必须配合润色模型
### Ⓑ4o-transcribe⁵
base_url填：[https://api.xxx.com/v1/audio/transcriptions](https://api.xxx.com/v1/audio/transcriptions)

或[https://api.openao.com/v1/audio/transcriptions](https://api.openao.com/v1/audio/transcriptions)

model_id填：gpt-4o-transcribe
#### 主要优点
识别率与elevenlabs-scribe相当，但是小毛病多点

支持输入听写提示词(不是润色提示词)，但仅VoiceInk支持该功能，Spokenly和SuperWhisper都不支持

就是说可以不用润色模型，就可以自己润色，当然没有推理效果肯定比不上2.5pro和gpt-5，估计和2.5flash相当。

也可以配合润色模型，听写模型润色一次，润色模型再润色一次，双保险

连续录音最大25分钟或2000token的限制，超时直接失败，超token后面的截断

有些其他输入法可以突破此限制，例如Spokenly iOS版，是因为把音频自动切割为10分钟一段再上传

经常繁简体不分，没有标点符号，中英标点符号混用，这些都可以由润色模型修正

有时末尾有幻觉

### ⒸSoniox⁵

base_url填：[https://api.soniox.com/v1](https://api.soniox.com/v1)

model_id填：stt-async-preview
#### 主要优点
官价便宜：¥0.75/小时，参考4o-transcribe和elevenlabs-scribe官价¥2.7左右

#### 主要优点
便宜，第三方云¥0.2/小时

开源，可以本地运行

没有明显连续录音时长限制

## 润色开推理，速度很慢，怎么办？
不同的场景，可以用不同的听写设置，不同的快捷键，一般至少两类听写场景

第一种是快速听写，录音一般几秒到几十秒，识别+润色一般几秒，要求速度快，质量要求不高，例如聊天，论坛，修改编辑等

第二种是慢速听写，录音一般几分钟到几十分钟，识别+润色一般几十秒到几分钟，要求质量高，可以后台润色，例如写文章，写笔记，写邮件

但是通常AI语音输入法并不支持多个录音快捷键启用不同模型，所以一般需要双开或三开。

前三里只有Spokenly原生支持多个录音快捷键对应不同模型
### 推理为什么慢？
推理虽然慢，但质量是明显好于不开推理的

2.5-pro和gpt-5默认推理强度的润色token消耗，一般是录音字数的10~20倍，就是比如录音5分钟500字，润色需5~10kt，

倍数并不是固定的，取决于：

①模型的推理强度，前三语音输入法都不支持自定义推理强度，就只能用默认的，例如2.5-pro默认貌似是8k

有些中转站把参数加到了模型名里，可以设置推理强度，官网或OpenRouter肯定没有这个功能。例如gemini-2.5-pro-thinking-32000，或者gemini-2.5-pro-nothinking

②提示词复杂程度

③gpt5提示词里是否要求推理，可能会影响推理强度

④录音的长度，因为思考token有限制，录50分钟，思考token并不是录5分钟的10倍
### 慢速听写：多开输入法，轮流录入
Mac访达 → 应用 → 在VoiceInk按右键 → 复制 → 把复制的改名VoiceInk2

在Enhancement → Prompt里 → 新建一个"慢速" → 模型设为2.5-pro → 提示词自己填好

在VoiceInk1 → Settings → 录音快捷键设为比如F1，窗口在菜单栏。

在VoiceInk2 → Settings → 录音快捷键设为比如F2，窗口在mini window（以免窗口重叠）

除此以外所有设置都想同

使用时：按F1开始录音 → 按F1结束录音并润色不管他 → 按F2开始录音 → 按F2结束录音并润色 → 按F1循环

注意每次关机或彻底关闭APP，再启动时1和2的设置会同步，要重新设一下快捷键

这个方法对VoiceInk和SuperWhisper有效，对Spokenly无效
### 快速听写
Mac访达 → 应用 → 在VoiceInk按右键 → 复制 → 把复制的改名VoiceInk3

在Enhancement → Prompt里 → 新建一个"快速" → 模型设为2.5-flash → 提示词从慢速里粘贴过来就行
