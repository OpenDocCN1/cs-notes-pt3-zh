# 《数字货币从入门到出门》

- 注: 全章安装应用 / 插件默认以 Google Play / App Store / Chrome 应用商店 作为安装渠道。
# Chapter 1 - 从万物起源——钱包开始
1. 首先你得明白你需要的是什么——

是 **「我只是想玩玩罢了」** 还是 **「我有交易和使用特殊钱包的需求」**

如果是前者，请看 2.。如果是后者，请看 3.
2. **我只是想玩玩罢了**

2.1. 在你的手机 / Chromium 内核浏览器上安装应用 / 插件 MetaMask。

如果没有特别需求，手机也可以考虑使用 Phantom。

2.2. 创建一个新钱包——请**务必保管**好你创建的任何密码以及生成的助记词。当然如果你已经有钱包了直接拿助记词导入即可。

如果发送给他人或者丢失，不仅仅会遗失财产，更会带来不可预料的后果如自己的数字货币被盗刷。

2.3. 如果你可以看到你的钱包地址，恭喜你——你成功的获取了一个数字货币钱包。
> Tips: 然而，凡事都是玩玩就好了。我相信你可不想成为《文字游戏》中那个居住在克里皮的人一样，从只想每天搬纸箱，变成了励志打败魔龙的家伙。
>
> ——《锟斤拷传》尚未以任何形式公开
1. **我有交易和使用特殊钱包的需求**

如题，比如 TRC20 主网就不能用 MetaMask 或者 Phantom 连接。此处使用「欧易 OKX」钱包作为演示。

3.1. 在你的手机上安装应用「欧易」。

3.2. 同 2.2. 创建或导入钱包。

3.3. 完成……了吧？
2. 不管怎样，总之——恭喜！

# Chapter 2 - 买币和通过钱包地址打款 / 收款
- 注: 本章默认以欧易 OKX 钱包交易。
## 买币篇
1. 在上方切换「Web3 钱包」到「交易所」。
2. 进行身份认证，**注意这里理论上要满 18 周岁。** 认证完毕后会给你发最高 50 USDT 的**返佣券**，然后就可以充值了。
- 注: 本人没有已认证账户（因部分原因无法进行认证），故还请各位指出错误以及编辑。
## 打款 / 收款篇
1. 返回「Web3 钱包」，点击「发送」，选择你的货币和主网，再输入对面的钱包地址和金额即可打款。**此种方式可以把你在欧易 OKX 钱包的财产转移到 MetaMask 或者 Phantom 钱包，但如果有钱包多用的需求也可以共用一个助记词。**
2. 点击「接收」，这里可以选择提币，看个人选择，这里介绍用钱包地址接收。选择货币和主网，即可获得钱包地址。

# Chapter 2.1 番外篇 - 如何使用 USDT 在 Dupay 或者 Zebec 开卡？
- 注: Dupay 默认使用欧易 OKX 钱包交易。Zebec 默认使用 MetaMask 或是 Phantom 钱包交易。
## Dupay
1. 在 Dupay 注册账户，最好是在手机下载其 App。
2. 点击「钱包」，「充币」，选择 USDT，选择主网，「Polygon」就是 Ethereum 主网，「TRC20」就是 TRON 主网

你会得到一个充值地址，用 Chapter 2 的方式打款过去即可。
## Zebec
1. 在 Zebec（Instant Card）注册账户，在控制台点击「Connect Wallet」，连接你的 MetaMask 或是 Phantom 钱包。
2. 点击「Buy Instant Card」，选择国家，再选你需要的卡，然后下方输入充值金额即可，**注意此处不是开卡费，这些钱会移送到你的虚拟或是实体 Zebec 卡里。**
