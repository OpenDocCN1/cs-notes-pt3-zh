# What（定义）

## 什么是Mac语音控制？

本文即使用Mac语音控制 + 16键自定义键盘 + VoiceInk语音输入法所写，完全没有使用Mac键盘



语音控制是MacOS自带的语音控制键盘+听写功能



Mac语音控制功能在系统设置 → 辅助 → 语音控制里面开启



语音控制是不需要关闭的，随叫随到，AI输入法按需要用语音命令（例如设为开始录音）或快捷键开启，他俩可以同时运行，最佳拍档



语音控制有命令模式（只控制键盘，不听写）和听写模式（类似输入法，速度快，识别率低），建议只用命令模式（说"命令模式"），因为听写模式与语音输入法一起开有冲突，会输出2次

## Mac语音控制 vs Mac听写 vs 第三方语音输入法

Mac语音控制和Mac听写是MacOS自带的



第三方输入法，全平台三强是VoiceInk，Spokenly(Mac版)，SuperWhisper(Mac版)，需要包月或自备听写模型+润色模型API Key

### 控制功能

Mac语音控制可以控制键盘上下左右，退格回车，复制粘贴，说按钮旁边的数字点击按钮等



Mac听写和语音输入法只能打字，完全没有控制键盘和功能

### 听写识别率

语音输入法开推理 > 语音输入法不开推理 > Mac听写 > Mac语音控制也可以听写



Mac语音控制听写的识别率，比最先进语音输入法落后5年以上，只能作为语音输入法的搭档，做语音输入法无法实现的那10%键盘功能，而不能代替语音输入法

### 常驻后台

Mac语音控制可以只要你不关掉他，就一直有效。



Mac听写在离开文本框就会自动关闭



语音输入法需要手动按键启动和关闭

### 以后语音输入法有可能实现语音控制那种控制键盘的功能吗？

我认为没有可能，因为控制键盘是系统级的权限，苹果不会开放给第三方的

## 不同的场景适合不同的语音输入法

### Ⓐ录入短语/修改：用Mac语音控制，录音几秒，润色1秒

最好与小键盘配合使用，来输入小键盘难以覆盖的内容。

### Ⓑ录入句子或段落：用快速语音输入法，录音几秒到几十秒，润色几秒

听写用elevenlabs-scribe或4o-transcribe



润色用gemini-2.5-flash，gpt-5无推理，sonnet-4无推理



边写边改，类似我们打字写作，但这种方式，实际上是把发散（创造）环节和收敛（自我审查/修改）环节，放在了一起，比较适合事实性/研究性写作。



对于创意写作，这样可能会严重影响思维流畅性



例如所有的头脑风暴规则，都严格禁止在头脑风暴阶段，对点子的价值/可行性等，进行评估和批评，因为会严重损害点子速度，数量，质量，脑洞和热情

### Ⓒ录入整篇文章：用慢速语音输入法，录音几分钟到几十分钟，润色几十秒到几分钟

听写用elevenlabs-scribe或4o-transcribe



润色用gemini-2.5-pro，gpt-5推理，sonnet-4推理



创意写作，推荐用这种方法，写作阶段不修改，不评估，闭着眼或看风景录最好，干扰最少

## Mac语音控制 vs 键盘

### ⒶMac语音控制 + 无键盘 + 触控板 + 语音输入法²

#### 主要优点

完全没有键盘，但是并不是说就不占用手了，因为还需要用手来控制触摸板



适合双手被占用的场合下录音，例如骑车，手里拎东西，劳动，抱孩子，拿无人机遥控器，拿摄影器材，医疗等场景

#### 主要缺点

速度和准确性还是要比键盘差很多。

### ⒷMac键盘 + 触控板 + 语音输入法³

#### 主要优点

不用额外花钱。

#### 主要缺点

大部分的按键都是浪费的。



手感差，快捷键分散，难以盲打



只能坐在桌子上使用。移动中很难使用，电挂在脖子上或者装在挎包里掀起盖子。也没法盲打。

### Ⓒ自定义小键盘 + 触控板 + 语音输入法⁴

#### 主要优点

节省空间，可以移动中使用，面积20×8，比手机略大，只有Macbook Air键盘面积的25%



只有16键，很快就可以盲打，速度快，误打率低

#### 主要缺点

键盘按键数有限。虽然可以切换多层，但是层多了就记不住了，一般也就能记住两层，即30个键。



虽然可以用提示词来进行替换专有名词替换。但是占用上下文，而且对于一些非推理模型来说，指令遵从也不是特别好，可靠性不高。



有些输入法，例如VoiceInk，可以用程序进行文本替换。不使用提示词。这种可靠性高，不消耗Token，同时也节约了推理预算，可以留给更重要的功能

### ![:white_check_mark:](img/f86349611d6094c730e6a1116c851813.png)ⒹMac语音控制 + 小键盘 + 语音输入法⁵：最佳方案

#### 定义

高频按键放小键盘，例如：上下左右/退格/回车/剪切/粘贴/撤销等



低频但是语音输入法打不出来的，用Mac语音控制，例如：最小化/全选/笔记软件里的快捷键

#### 主要优点

Mac语音控制可以弥补小键盘的键数比较少的缺点。

## Mac语音控制 vs 触控板

语音控制可以基本代替键盘，但是很难代替触控板



语音控制可以开启按钮数字功能，用说数字的方式点击按钮，但是远没有触控板方便

### 触控板的选择

Ⓐ用Macbook原配，不能移动中使用



Ⓑ用单买妙控触摸板但体积偏大，不太便携，勉强可以移动中使用



Ⓒ也可以买罗技的Casa Pop-up套装里的触控板：可以手持，挂脖，或固定在手臂上，移动中使用



¥400，体积小12×8，手感我觉得比苹果Macbook Air的还好

#### 对语音控制的命令，用语音输入法无法替代

开始/停止听取（语音控制的总开关）



显示/隐藏数字（按钮显示数字后，说这个数字=点击，如果有触控板就不要开启，界面比较乱）



添加到词条

#### 正常需要按键盘才做的，用语音输入法无法替代

空格键，换行（回车不行），退格/退n格/向后删除，上移/下移/左移/右移



按下a键[n次]（可配合搜狗自定义短语，反应速度y > yyy > yi > yin，1与E容易混淆）



按下command键a键（必须是组合键，“按下a键b键”无效，Option很难识别出来，办法：修改快捷键避开Option）

#### 正常需要组合键或菜单操作的，用语音输入法无法替代

以下一般都可以用上面键盘指令组合键代替别，但是直接说指令速度更快更准



剪切/拷贝/粘贴/删除该内容（先选区，复制不行）



撤销/重做该操作



最小化窗口，进入全屏幕



显示/隐藏键盘（指虚拟键盘）



将该内容设为粗体，给该内容加下划线（删除线不行）



在该内容两边添加双引号/双湾引号/单引号/圆括号/方括号



删除[/上一个/前n个]字符/词/句子/行/段落，



移到词/句子/段落的开头/结尾（必须有"的"字，句子的分割是句号，直接说移到开头在过一会儿。）



将aaa替换为bbb



选择字符/字词/句子/行/段落，选择上n/下n个字符…

#### 输入文本，用语音输入法自定义提示词可以替代

输入aaa（在听写模式下可以省略“输入”）



逗号，句号，冒号，问号，叹号，斜杠，加号，减号，星号（乘号不行），除号，括号/右括号（是英文括号）

#### 需要自己定义的

ⓐ在语音控制 → 设置 → 最下面命令 → 左下角加号



ⓑ用搜狗输入法，例如`ss=（`



括号=`（`，右括号=`）`（这会覆盖原来的英文括号，英文可用“圆括号/右原括号”输入）



组合键

#### 语音输入法控制

输入法里设`录音1=按键F1`，语音控制里设`录音1=按键 → F1`



语音控制不支持单按Command等键，这与VoiceInk的多开冲突，VoiceInk只有设为Command等单控制键，多开时才不会自动同步快捷键，如果2个分身录音设为F1F2会自动同步为F1。即语音控制只能调用一个VoiceInk，无法调用其他分身，只能手动按键调用昨天把电话撂出来呀

# How（方法）

## 语音控制与语音输入法识别两次的问题

### ![:white_check_mark:](img/f86349611d6094c730e6a1116c851813.png)Ⓐ开语音控制 → 说命令模式 → 开始录音

#### 方法

自定义命令 → 我说`开始录音` → 按键`F1` → 在语音输入法里录音键设为`F1`



自定义命令 → 取消录音 → 按键`F5` → 在语音输入法里取消录音键设为`F5`。只有部分语音输入法支持自定义取消键，例如VoiceInk和SuperWhisper可以，Spokenly不行

#### 主要优点

#### 主要缺点

命令模式也可以输入文字，前面必须加`输入`，例如`输入aaa`，但很难录入长句，录入短语还凑合，



而听写模式前面可以不加`输入`，说话也没有长度限制，中间也可以随便停顿

### ![:yellow_circle:](img/20ed15305b0d60ecc1af5bb8acbbc67c.png)Ⓑ开语音控制 → 说开始录音 + 停止听取

说`VoiceInk停止听取`，就会先启动VoiceInk，再停止语音控制

#### 主要优点

打字方便

#### 主要缺点

每次录音都要关闭语音控制

### ![:yellow_circle:](img/20ed15305b0d60ecc1af5bb8acbbc67c.png)Ⓒ开语音控制 → 用同一快捷键停止听取 + 开始录音

然后再VoiceInk停止录音 + 开始听取



快捷键默认开启/关闭方法是口述“开始听取/停止听取”，但对“开始听取”有时候没反应



系统自带的自动化都找不到“停止听写”这个菜单项



只能用⊚Keyboard Maestro或⊚Better Touch Tool来模拟鼠标点击菜单，但是可能有菜单位置不固定的问题，考虑调整开机启动顺服，或者调整图标位置的插件
