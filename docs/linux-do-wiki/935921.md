# 记一下在真机上安装Kali Linux所踩的坑

先说配置 联想2022款拯救者Y9000X
i7-12700H + RTX 3060 Laptop
我装Kali Linux主要是想测试一些东西，个人偏好KDE环境，折腾了好久才装好，存个记录档吧，以下以本人的电脑和配置为例，也有可能漏了些东西，请见谅！
## 安装系统时在选择并安装软件后出错
试过了`kali-linux-2025.2-installer-amd64.iso`这个镜像会提示在选择并安装软件的那一步骤失败
换`kali-linux-2025-W36-installer-amd64.iso`这个Weekly版解决
## 显卡驱动问题
我是最开始用的笔记本的混合显卡模式来装Kali Linux的，但是后面发现显卡好像没跑？得装个显卡驱动吧，搜了一下，按照这个教程装
[https://www.kali.org/docs/general-use/install-nvidia-drivers-on-kali-linux/](https://www.kali.org/docs/general-use/install-nvidia-drivers-on-kali-linux/)
好像官方的教程里面不会安装
```
sudo apt install nvidia-driver nvidia-settings nvidia-xconfig
```
这些东西来着（？装完之后补上（我也不知道是否有必要，但是我在折腾的过程中补上了
然后创建`/etc/X11/xorg.conf/`文件
里面写上这些内容
```
Section "Device"
    Identifier     "Device0"
    Driver         "nvidia"
    Option         "PrimaryGPU" "yes"
EndSection

Section "Screen"
    Identifier     "Screen0"
    Device         "Device0"
    Monitor        "Monitor0"
    DefaultDepth    24
    SubSection     "Display"
        Depth       24
    EndSubSection
EndSection
```
保存
然后再打开`/etc/default/grub`，大概第9行的位置改为
```
GRUB_CMDLINE_LINUX_DEFAULT="quiet nvidia-drm.modeset=1"
```
去掉splash，不然会卡开机（至少在我这里会）
保存，然后运行
```
sudo update-initramfs -u
sudo update-grub
```
会生成grub配置文件，用`sudo nano /boot/grub/grub.cfg`打开
删掉所有找到的`splash`
重启电脑，切独显直连
然后应该能启动了吧（？
（后面我也没试过混合显示模式能不能启动了） 混合显示模式也能用，但是肯定没有独显直连流畅啦
## KDE Connect
打开设置，发现KDE Connect没有运行，搜了一下，运行
```
sudo mv /usr/share/dbus-1/services/org.kde.kdeconnect.service.original /usr/share/dbus-1/services/org.kde.kdeconnect.service
```
应该就可以了
