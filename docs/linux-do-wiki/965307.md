# 手机输入法使用体验



# 安卓输入法体验评价

*今年换了几个相对更能保障隐私的输入法，小企鹅、同文、雨燕、Gboard，以下简述使用体验。*

## 小企鹅

目前的主力输入法，常用功能里有如下优势：

- 可以导入现成的**雾凇**和其他㞢配置，常用词基本能覆盖到

- 支持`uU`拆字，比如输入`uUweiwenchangnv`可以得到“嫠”

- 支持`v`模式通过首字母输入特殊字符和符号，如`vfjz`得到“⸺”

- 删除键左划快速删除

- 空格键滑动移动光标，有候选窗口时可以在拼音间移动修改

- 官方文档推荐了两个语音输入法可以协同工作，试了下能用，缺点后述

- 支持上划输入按键次级符号

缺点：

- 候选词无法滑动查找，下拉窗口第一行候选词和后面的不对齐，不太好找到想要的候选词

- 没有云词库（开源基本都不支持）有时候匹配到的不是自己想要的词

- 没有联想预测功能，起码我没找到

- 修改输入的拼音时无法点击插入光标修改指定位置，空格划动来定位精度略显不足

- 标点符号输入里缺失**破折号、分号**

- 安装语音输入后，在语音和按键输入间切换时会触发重新部署，不能立刻输入

- 语音输入会占据右上角的收起键盘按钮，希望能通过长按空格键唤起语音输入

- 主题比较简洁且不可定制，官方有宣布会添加主题自定义支持，但是半年了也没见上，在小众的**㞢**里更小众的安卓输入法，支持力度不会太大![:face_exhaling:](https://linux.do/images/emoji/twemoji/face_exhaling.png?v=15)

## 同文

优势：

- 可以自定义主题和键盘布局

- 具备常用复制黏贴功能，且可以无缝迁移㞢配置

- 支持常用标点符号，标点功能花样多

缺点：

- 不支持语音输入

- 没有工具栏，复制黏贴需要长按对应按键，也无法用其他输入法都有的光标调节界面，太过简洁

- 预设主题和其他输入法差异太大难适应，标准输入法布局和其他输入法基本相同。输入法自定义配置会破坏性更新，导致新版本不兼容以前的主题，而本身又太过小众，其他主题作者适配积极性不高

- 稳定性不高，偶尔会崩溃，虽然我短期体验对使用的影响不大

## 雨燕

之前安装了雨燕，最大的亮点是主题和搜狗等商业输入法布局类似，切换后的学习成本较低不需要重新适应键位。

不过不知道为什么我找不到app图标（不记得有没有卸载）还能在输入法切换里切过去，可能常驻内存？

优势：

- 开箱即用，满足基本输入功能

- 主题现代化，能快速适应

- 支持空格划动移动光标，不支持修改输入的拼音

- 方便输入常用标点符号

- 支持键盘尺寸调节、单手模式、悬浮键盘、繁体输入、单独列出数字键区、常用语快捷输入、火星文输入

- 底部有输入法切换和剪贴板工具栏，错开上划返回，增高按键区，输入握持更舒适

- 有支持语音输入的版本，需要联网权限

- 支持上划输入按键次级符号

缺点：

- 不能导入其他rime配置，不能自定义词库，需要从零开始适配自己的输入习惯

## Gboard

*大厂支持就是不一样，功能齐全，基本你会用到的都有。*

优势：

- 按键布局和主题美观度都不错

- 常用符号输入方便

- 支持划行输入、手写输入、语音输入，拼音纠错和邻键纠错准确度较高，语音输入识别灵敏

缺点：

- 不支持上划输入次级符号，只能长按

- 虽然能自定义键盘区域，但是底部会空出一块浪费寸土寸金的屏幕空间，如果能放**雨燕输入法**那种输入法切换和剪贴板按键就好了，能自定义功能更好，小米自带输入法就支持

- 没有收起键盘的按钮，右上角是语音输入，这点和**小企鹅输入法**安装语音输入法之后的问题一样

- 候选栏日文支持左右划动查看候选词，中文不支持

- 词库比较老且很久不更新，日常词语不顺手，虽然可以导入自定义词库
