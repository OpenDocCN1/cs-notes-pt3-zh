### Markdown、BBCode、HTML 是什么？
（按照发布顺序介绍）

**HTML** （英语全称：**H**yper**T**ext **M**arkup **L**anguage，超文本标记语言），是一种用于创建网页的标记语言
**BBCode**（英语全称： **B**ulletin **B**oard **Code**），属于一种轻量级的标记语言，比 HTML 更简单
**Markdown** 是一种更为易读易写的轻量级标记语言，对于图片、数学公式（使用 LaTeX、KaTeX 语法）等支持友好

## 摘要
本指南涵盖：
- 支持的 Markdown 语法
- 支持的 BBCode 标签
- 支持且安全的 HTML 标签和属性
## 最佳实践
- 主要使用 Markdown，因为它简单易读。
- 仅在必要时混合使用 Markdown 和 BBCode，并保持用法一致。
- 限制使用 HTML，仅使用简单、安全的标签，以避免格式问题并确保帖子安全。
## 支持的 Markdown
Discourse 使用 [markdown-it](https://github.com/markdown-it/markdown-it) 实现 Markdown 功能。
一些常用的 Markdown 功能包括：
- **粗体**：`**文本**`
- *斜体*：`*文本*`
- [链接](https://example.com)：`[标题](https://example.com)`
- `行内代码`：``代码``
- 高亮：`<mark></mark>`
- 代码块：
```
```
代码块
```
```
在较长的帖子（例如本文）中，使用标题添加结构也很有帮助：
```
# 标题 1
## 标题 2
### 标题 3
```
注意：上传图片后，系统会自动生成引用图片的 Markdown 语法。
```
![image|500x500, 100%](upload://image.jpeg)
```
有关 Markdown 功能的完整列表，请参阅[交互式指南](https://markdown-it.github.io/)。 ## 支持的 BBCode

Discourse 支持部分常用的 BBCode 标签，其中一些标签会自动生成以支持特殊格式，例如在回复中引用帖子时：
> 引用的文本
```
[quote="user"]引用的文本[/quote]
```
您还可以使用 BBCode 将文本标记为剧透或详细信息：
剧透文本
```
[spoiler]剧透文本[/spoiler]
```
隐藏文本
```
[details="点击展开"]隐藏文本[/details]
```
Markdown 支持的简单格式 BBCode 标签也受支持：
- `[b]粗体[/b]`
- `[i]斜体[/i]`
- `[u]下划线[/u]`
- `[s]删除线[/s]`
- `[ul][li]选项一[/li][/ul]`
- `[img]http://example.com/image.png[/img]`
- `[url]http://example.com[/url]`
- `[code]代码[/code]`
有关所有支持的 BBCode 标签和示例的完整列表，请查看 [Discourse BBCode 测试](https://github.com/discourse/discourse/blob/main/app/assets/javascripts/discourse/tests/unit/lib/pretty-text-test.js)。
## 支持的 HTML
Discourse 支持一部分安全的 HTML 标签。虽然您可以将 HTML 与 Markdown 混合使用，但为了确保安全性和样式一致性，只允许使用特定的 HTML 标签和属性。一些允许使用的 HTML 标签包括：
- `<a href="https://example.com">链接</a>`
- `<strong>粗体文本</strong>`
- `<em>斜体文本</em>`
- `<ul><li>列表项</li></ul>`
- `<img src="https://example.com/image.png" alt="描述">`
有关允许使用的 HTML 标签和属性的详细列表，请参阅 [Discourse 的允许列表](https://github.com/discourse/discourse/blob/main/frontend/pretty-text/addon/allow-lister.js#L115)。
![:information_source:](https://cdn.ldstatic.com/images/emoji/twemoji/information_source.png?v=15) **注意：** 不支持内联样式，例如 `<span style="color:red">彩色文本</span>`。如需自定义样式，请参阅 [自定义帖子内容](https://meta.discourse.org/t/customize-posts-contents-with-your-own-styles/257738)。
## 常见问题及解决方案
- **BBCode 或 HTML 标签不起作用：** 确保您使用的标签属于支持的标签子集。
- **内联样式被移除：** 出于安全原因，Discourse 不支持内联样式。如有需要，请使用自定义样式或插件。
- **从其他编辑器粘贴后格式发生变化：** 某些富文本格式可能无法正确渲染。请使用 Markdown 来保持文本格式的一致性。
## 常见问题解答
**问：我可以在 Discourse 中使用表格吗？**

答：可以，您可以使用 Markdown 创建表格。更多信息，请参阅 [此表格指南](https://meta.discourse.org/t/add-a-table-to-your-post-using-markdown/66544)。
**问：为什么我的内联样式不起作用？**

答：出于安全原因，Discourse 不支持 HTML 中的内联样式。请考虑使用自定义 BBCode 或 Discourse 自定义样式指南。
**问：我可以添加自定义 BBCode 标签吗？**

答：可以，您可以添加自定义 BBCode 标签。更多信息，请参阅 [Discourse BBCode 插件](https://meta.discourse.org/t/discourse-bbcode/65425)。
