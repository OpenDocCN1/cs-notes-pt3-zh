# 禁止网页版 B 站直播的 PCDN

广告拦截静态规则：
```
||api.live.bilibili.com/xlive/open-interface/v2/tracker/*
||tracker.chat.bilibili.com
```
默认 tracker 的域名是从第一个地址获取的，比如 [cn-hnld-ccc-live-tracker-03.chat.bilibili.com](http://cn-hnld-ccc-live-tracker-03.chat.bilibili.com)；第二个域名是无法获取默认 tracker 时会用的。
这会导致浏览器每隔十秒重连一次 tracker，所以其实[禁用 WebRTC](https://linux.do/t/topic/494374/18) 更好。
