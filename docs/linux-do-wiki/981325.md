# Debian 13 Desktop 踩坑记录

因为intellij对于在wsl2 下用gradle配置的项目的的支持非常之差，所以我之前被迫直接在wsl2中直接安装linux版本的intellij。虽然大部分时间上用起来非常舒服，但是仍有不小的不适感，如在wayland版本下剪切板在休眠过后可能会无法使用，如右键菜单可能会超出窗口范围，如在x11版本下界面高糊，最终决定直接使用linux桌面试试。于是有了如下踩坑记录。安装选择的是Debian 13，GNOME桌面。
1. 音响问题以及其继而导致的nvidia驱动问题

第一个问题是发现音响没有声音。我的音响是通过显示器连接，之前无论是windows台式机或者mac笔记本都可以正常使用。但是切换到linux之后，用不了了。但是巧合在我有两个显示器，另外一个显示器连着耳机，于是我有了很好的对比对象，连着耳机的这个是能正常发出声音的。那么我通过俺寻思之力，发现两个显示器，一个是用hdmi，一个是用dp连接，那么是不是切换一下试试呢？于是我就把两根线换了过来，试了下之后，果然好了。之后我又再切换回来，还是好的。于是这个问题就神奇的解决了。

在这期间我还尝试了安装各种版本的nvidia驱动，安装之后的结果是系统直接进不了了。只能通过safe mode把驱动给完全删掉.
2. Wayland下各种快捷键无法使用

日常使用肯定脱不了要剪切板管理器，截图贴图之类的工具，所以安装了ulauncher,copyq和snipaste。然后发现设置了快捷键之后，完全没法使用。所幸我安装了ulauncher，在他的设置界面有说在wayland系统下需要额外安装一些配置才能使用快捷键。基于我懒得折腾的性格，直接切换到了x11。问题解决。
3. nix安装的部分软件无法正常打开或者无法正常使用rime进行中文输入

我有一套home-manager的配置，在wsl2和mac下都能正常的使用，于是很自然地我也选择了在linux下继续使用（没有用nixos是因为不想大改我的配置，不确定哪些东西要改）。然后我就发现我安装的一些gui软件没法正常打开，如wezterm，tabby等。不知道为什么，直接改成了Flatpak之后解决。对于那些能打开的软件，如slack，vscode，我又发现rime的输入法切换失败了。无论怎么切换，都只能输入英文。索性都改成了Flatpak安装gui软件。
4. Flatpak下IDE无法正常使用我的shell

发现无论是intellij还是vscode，都无法正常使用我自己定义的shell，我的shell是通过home-manager配置的，但是这些完全无法使用，只能使用`/bin/bash`。懒得折腾，直接官网下载安装包完事。
