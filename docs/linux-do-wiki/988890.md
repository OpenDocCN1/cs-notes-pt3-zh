### A. Be Positive

> [!abstract] 题目大意

>

> 有一个由-1、0、1组成的数组，能将任意元素任意次加一，求乘积为正所需的最小操作次数

> [!todo]解题思路

>

> 只需要将所有的0变成1，如果有奇数个-1将其中一个-1变成1即可

> [!danger] 代码

> `void solve() {     int n;     cin >> n;     int y = 0;     int z = 0;     rep(i, 0, n)     {         int x;         cin >> x;         if (x < 0)         {             y++;         }         else if (x == 0)         {             z++;         }     }     ll ans = 0;     ans += z;     if (y % 2 != 0)     {         ans += 2;     }     cout << ans << "\n"; } `

### B. Unconventional Pairs

> [!abstract] 题目大意

>

> 有偶数个数字，希望两两配对，使得每个配对的差最小，输出差

> [!todo]解题思路

>

> 排序后按顺序配对即可

> [!danger] 代码

> `void solve() {     int n;     cin >> n;     vll a(n);     for (auto &x : a)         cin >> x;     sort(all(a));     ll ans = 0;     rep(i, 0, n - 1)     {         ans = max(ans, a[i + 1] - a[i]);     }     cout << ans << "\n"; } `

### C. MEX rose

> [!abstract]题目大意

>

> 有一个数组A和一个K，每次可以修改一个数组中的数，求使得 Mex（A）= K 时的最小修改次数

> [!todo]解题思路

>

> 题目没说有无法完成的情况，认为给定的数据都是可以成功修改的。Mex（A）= K，这说明

>

> A里面没有等于 K的数

> 且1到K-1的数A里面都存在

>

> 满足条件1需要count(k)次操作

>

> 满足条件2需要len(set(i for i in a if i < k))次

>

> 不过发现一次操作可以使得两个条件同时满足，故取最大值即可

> [!danger] 代码

> `void solve() {     int n, k;     cin >> n >> k;     set<ll> s;     ll cnt = 0;     rep(i, 0, n)     {         ll x;         cin >> x;         if (x < k)         {             s.insert(x);         }         else if (x == k)         {             cnt++;         }     }     cout << max((ll)k - sz(s), cnt) << "\n"; } `

### D. A and B

> [!abstract]题目大意

>

> 有一个仅由a、b组成的字符串，只能交换相邻的两个字符，求使得a或b恰好全部连续聚集在一起所需的操作数

> [!todo]解题思路

>

> 分类讨论，对a、b分别计算操作次数，取最小值

>

> 对于每一个a，假设第一个a移动到了第u位，那么后续的第二个a必须在u+1，第三个a必须在u+2

>

> 记 index(i) 表示第i个a在字符串中的位置

>

> 那么聚集a的最小代价就是 \sum_{i=1}^{k} |(index(i) - (i-1)) - u|

>

> 根据中位数定理

>

> 在一维数轴上，到一组点距离之和最小的点是这些点的中位数

>

> 记 c(i) = (index(i) - (i-1))

>

> 那么 u 就是 c(i) 的中位数

>

> 接着计算出a和b的代价并取最小值即可

> [!danger] 代码

> `ll f(const vi &p) {     if (sz(p) <= 1)     {         return 0;     }     vll c;     c.reserve(sz(p));     rep(i, 0, sz(p))     {         c.pb((ll)p[i] - i);     }      auto mid = sz(c) / 2;     nth_element(all(c), c.begin() + mid);     ll u = c[mid];      ll ans = 0;     for (ll ci : c)     {         ans += abs(ci - u);     }      return ans; }  void solve() {     int n;     cin >> n;     string s;     cin >> s;      vi pa;     vi pb;      rep(i, 0, n)     {         if (s[i] == 'a')         {             pa.pb(i);         }         else         {             pb.pb(i);         }     }      ll ca = f(pa);     ll cb = f(pb);      cout << min(ca, cb) << "\n"; } `

### E. Hidden Knowledge of the Ancients

> [!abstract]题目大意

>

> 有一个数组，找到长度在l、r之间的连续子数组，使得该子数组恰好有k个不同数字，求子数组的个数

> [!todo]解题思路

>

> 恰好计算含有k个不同数组有些麻烦，但是计算含有最多k个不同数字的子数组个数则简单很多

>

> 那么答案就等于 最多k个不同数字的子数组个数 - 最多k-1个不同数字的子数组个数

>

> 怎么计算最多k个不同数字的子数组个数呢？用两个指针维护一个区间ll、rr，一个map维护区间中不同数字的个数，一个 int p 表示当前区间的不同数字的个数

>

> rr每次递增1，并累计该区间的子数组个数，如果不同数字的个数超过了k，那么先++ll，再计算贡献

>

> 贡献怎么计算？我们现在已经有了一个区间ll，rr，其中含有最多k个不同数字，题目说长度还要满足在l和r之间。我们设区间uu，rr是满足条件的子数组，那么 max(ll, rr - r + 1) <= uu <= rr - l + 1，贡献的子数组个数就是 rr - l + 1 - max(ll, rr - r + 1) + 1

>

> 接着将贡献累计起来就是最多k个不同数字的子数组个数，最多k-1个的也同理

>

> 计算出来后一减就是答案

> [!danger] 代码

> `ll cal(vi &a, int k, int l, int r) {     if (k < 0)         return 0;     if (k == 0)         return 0;     int n = sz(a);     map<int, int> f;     int lll = 0, p = 0;     ll ans = 0;     rep(rrr, 0, n)     {         f[a[rrr]]++;         if (f[a[rrr]] == 1)             p++;         while (p > k)         {             f[a[lll]]--;             if (f[a[lll]] == 0)                 p--;             lll++;         }         int mnj = max(lll, rrr - r + 1);         int mxj = rrr - l + 1;         if (mnj <= mxj)         {             ans += (mxj - mnj + 1);         }     }     return ans; }  void solve() {     int n, k, l, r;     cin >> n >> k >> l >> r;     vi a(n);     rep(i, 0, n) cin >> a[i];     cout << (cal(a, k, l, r) - cal(a, k - 1, l, r)) << "\n"; } `

### F. Nezuko in the Clearing

> [!abstract]题目大意

>

> 祢豆子在数轴的0点，现在她有h点生命。每回合她可以做两件事情，休息或者移动一格。休息能让她的生命值增加1；移动则会减少生命值，如果是第i次连续移动，那么生命值会减少i。求到达d的最小回合数

> [!todo]解题思路

>

> 虽然直接计算最小回合数很困难，但是计算猜测的一个回合数能否让祢豆子成功到达d点是O(n)的

>

> 那么和猜数字游戏一样，我们可以二分猜测答案

>

> 首先搭一个二分查找框架

>

> 接着实现check函数，判断这个回合数能满足条件

>

> 如果我们休息r次，需要走d格，那么这d格就分解为了r+1次移动，其中有z=d%r次移动y=d/c+1格（整除），而r+1-z次移动x=d/c格，结果祢豆子走完这d格，扣除了z*(x+1)*(x+2)/2+(r+1-z)*x*(x+1)/2点血量，将其和h+mid-1做比较，即可判断是否成功

> [!danger] 代码

> `ll cal(ll d, ll r) {     ll c = r + 1, x = d / c, z = d % c;     ll ans = z * (x + 1) * (x + 2) / 2 + (c - z) * x * (x + 1) / 2;     return ans; } bool check(ll d, ll mid, ll a) {     return cal(d, mid) <= a + mid - 1; } void solve() {     ll h, d;     cin >> h >> d;     ll l = 0, r = d, ans = d;     while (l <= r)     {         ll mid = (l + r) / 2;         if (check(d, mid, h))         {             ans = mid;             r = mid - 1;         }         else             l = mid + 1;     }     cout << d + ans << endl; } `

### G. Buratsuta 3

> [!abstract]题目大意

>

> 我们有一个长为n的数组，和q个查询，我们需要找到该数组中出现次数严格大于 ⌊(r - l + 1) / 3⌋ 的数字

> [!todo]解题思路

>

> 仔细观察题目，会发现这种数字最多不超过2个。

>

> 证明，设数字个数为x，k=r-l+1 则 j*(⌊k/3⌋+1) <= k

>

> x <= k/(⌊k/3⌋+1)

>

> 可知 x <= 2.

>

> 然后，我们想快速知道某个数字在区间l、r出现的次数

>

> 选择什么数据结构呢，前缀和？不行，太耗费空间了。用升级版：可持久化线段树，即主席树

>

> 接着看题目，我们会发现数字的范围是1-1e9，太大了，很可能超出空间限制。此时需要使用离散化将数字之间的空隙挤掉

>

> 这个森林看起来是什么样的？它有n个树根，对于第一个树根，它表示的节点[L, R]代表的是数值的范围。比如离散化后，我们有 m 个不同的数，那么根节点就代表数值范围[1, m]，它的左儿子代表[1, m/2]，右儿子代表[m/2+1, m]，以此类推。叶子节点储存这个数的出现个数，而父节点储存这个区间的数的个数的总和

>

> 对于之后的树根，如果该区间没有变化，那么直接复用上一颗树的节点，如果变化了，那么就创建新的一串节点，并修改每个节点的sum。这样节省了时空复杂度

>

> 最后，在查询的时候，我们只需要把这对应的两颗树取出来，接着快速比较下哪些数字变化了，即可回应查询

>

> 有些细节可能还是没说明白，可以看注释

>

> 这题好像是原题呢 [CF840D Destiny - 洛谷](https://www.luogu.com.cn/problem/CF840D)

>

     // 主席树节点的左孩子 int right_child[MAX_NODES];     // 主席树节点的右孩子 int node_count[MAX_NODES];      // 主席树节点存储的计数（在该子树范围内的元素个数） int node_counter;               // 全局节点计数器，用于创建新节点 vector<int> unique_values;     }     return p; }  void query(int root_r, int root_l_minus_1, int l, int r, int k, vi &result) {     // 通过两个版本的节点信息相减，得到区间 [l, r] 内当前范围元素的个数     int count_in_range = node_count[root_r] - node_count[root_l_minus_1];     }      int mid = (l + r) >> 1;     // 递归查询左右子树     query(left_child[root_r], left_child[root_l_minus_1], l, mid, k, result);     query(right_child[root_r], right_child[root_l_minus_1], mid + 1, r, k, result); }  void solve() {     int n, q;     cin >> n >> q;      // 1. 读取输入并收集所有值用于离散化     unique_values.clear();     rep(i, 1, n + 1)     {         cin >> arr[i];         unique_values.pb(arr[i]);     }      // 2. 离散化     sort(all(unique_values));     unique_values.erase(unique(all(unique_values)), unique_values.end());     int m = sz(unique_values); // 离散化后不同值的数量      // 3. 构建主席树     node_counter = 0;     roots[0] = 0; // 版本0是空树     left_child[0] = right_child[0] = node_count[0] = 0;     rep(i, 1, n + 1)     {         // 基于上一个版本 roots[i-1]，插入当前元素 arr[i] 的排名，得到新版本 roots[i]         roots[i] = update(roots[i - 1], 1, m, get_rank(arr[i]));     }      // 4. 处理查询     rep(i, 0, q)     {         int l, r;         cin >> l >> r;         // 题目要求：找到出现次数 > (r-l+1)/3 的数         int k = (r - l + 1) / 3;          vi result;         if (m > 0) // 仅当有元素时才查询         {             // 在版本 r 和版本 l-1 的树上查询             query(roots[r], roots[l - 1], 1, m, k, result);         }          if (result.empty())         {             cout << -1 << "\n";         }         else         {             sort(all(result)); // 按题目要求排序输出             rep(j, 0, sz(result))             {                 cout << result[j] << (j == sz(result) - 1 ? "" : " ");             }             cout << "\n";         }     } } `
