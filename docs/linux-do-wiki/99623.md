## Fuclaude
## [demo.fuclaude.com](https://demo.fuclaude.com/)
在[demo.fuclaude.com](https://demo.fuclaude.com/)邮箱登录，[https://demo.fuclaude.com/api/auth/session](https://demo.fuclaude.com/api/auth/session)获取sessionKey。
或者采用如下方式获取：

*Mac*: 从*[https://github.com/wozulong/fuclaude/releases](https://github.com/wozulong/fuclaude/releases)下载包，解压(密码:linux.do)，运行fuclaude；打开[https://claude.ai](https://claude.ai)，按F12，点击应用-Cookie-https:claude.ai-SessionKey，复制sk开头的SessionKey；浏览器输入[http://127.0.0.1:8181/](http://127.0.0.1:8181/)，粘贴SessionKey。

*Win/Linux 采用Docker*: 运行`docker run -d --name Fuclaude --restart=always -p 14300:8181 pengzhile/fuclaude:latest`；复制和粘贴SessionKey方法同上。

### [yourprefix.fuclaude.oaifree.com ](https://yourprefix.fuclaude.oaifree.com/)
demo.fuclaude.com的通配子域名。 “yourprefix”可替换为满足域名规则的任意字符，比如：neo，得到[neo.fuclaude.oaifree.com](https://neo.fuclaude.oaifree.com/)。子域名互相之间Cookie是隔离的。

### [yourprefix.new.oaifree.com ](https://yourprefix.new.oaifree.com/)
new.oaifree.com通配子域名。“yourprefix”可替换为满足域名规则的任意字符，比如： [neo.new.oaifree.com ](https://neo.new.oaifree.com/)，事实上 *.new.oaifree.com 前缀你可以随便输入，选一个你喜欢的。不同域名，cookie是不通用的，应该一定程度防止一些阻断。
[new.oaifree.com 现已支持通配子域名 ](https://linux.do/t/topic/100333)
## [demo.oaifree.com](http://demo.oaifree.com)
恢复旧版 Pandora 的样子，带你回到以前。功能和new.oaifree.com相同，只是不能使用 GPTs。

# Token ![:racehorse:](https://linux.do/images/emoji/twemoji/racehorse.png?v=15)
## [token.oaifree.com/auth](https://token.oaifree.com/auth)
获取ChatGPT的Access Token和Refresh Token。也可从OpenAI官网获取 [chatgpt.com/api/auth/session](https://chatgpt.com/api/auth/session)。
[整理自己的代码发现一个古早物件 ](https://linux.do/t/topic/40591)

[手把手教你用refresh roken获取access token](https://linux.do/t/topic/41113)
## [chat.oaifree.com/token](https://chat.oaifree.com/token)
获取Share Token。可帮助你安全地分享你的Access Token，获取到的Share Token，你可以分享作会话隔离使用。[chat.oaifree.com](https://chat.oaifree.com/) 对chatgpt.com相关接口进行直接转发，可以在此基础上编程、套UI等等。由于官方相关接口有cf盾等各种限制，越过了这些。
[“久负盛名”的Share Token回来了](https://linux.do/t/topic/52127)

# API ![:whale:](https://linux.do/images/emoji/twemoji/whale.png?v=15)
## [api.deeplx.org](https://linux.do/t/topic/111737)
DeepLX  免费API。配置沉浸翻译：从论坛左侧栏-外部链接-[Connect](https://connect.linux.do/)-获取DeepLX Api Key，替换`https://api.deeplx.org/<api-key>/translate中的<api-key>`形成api链接待用；下载安装沉浸式翻译浏览器插件[https://immersivetranslate.com/](https://immersivetranslate.com/)，点击插件-设置-开发者设置（左下角）-开启Beta测试特性；点击翻译服务（左上角）-点击DeepLX(Beta) 设置，填入api链接-返回打开DeepLX(Beta)开关。
## [api.oaifree.com](https://api.oaifree.com/)
是对chatgpt.com相关接口进行转换，模拟成部分官方API格式。比如对话、tts、whisper、画图。因为是模拟的，所以功能和参数并不全面。
[实话实说，你们的论坛账号更值钱了，已支持gizmo、出图](https://linux.do/t/topic/40928)
## [api.oaipro.com](https://api.oaipro.com/)
对 [api.openai.com](http://api.openai.com/) 的代理转发，官方同价使用官方API。为不方便充值官方API或者怕官方封号的人提供便利。

基于One API的二次开发版本。
