# # Commands

# ## File and Directory

+   - `ls` — list files/dirs  
+     e.g. `>ls -l`
+   - `mkdir` — create a dir  
+     e.g. `>mkdir test`
+   - `cd` — change dir  
+     e.g. `>cd test`
+   - `rm` — remove files/dirs  
+     e.g. `>rm -f a.txt`
+   - `cp` — copy files/dirs  
+     e.g. `>cp a.txt b.txt`
+   - `mv` — move files/dirs  
+     e.g. `>mv a.txt c.txt`
+   - `pwd` — show current path  
+     e.g. `>pwd`
+   - `du` — estimate files/dirs space usage  
+     e.g. `>du -c -h test`
+   - `df` — report free disk space  
+     e.g. `>df`
