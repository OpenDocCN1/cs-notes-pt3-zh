# Addressing Mode

| Type | Form | Operand value | Name |
|---|---|---|---|
| Immediate | $Imm | Imm | Immediate |
| Register | Eₐ | R[Eₐ] | Register |
| Memory | Imm | M[Imm] | Absolute |
| Memory | (Eₐ) | M[R[Eₐ]] | Indirect |
| Memory | Imm(Eᵦ) | M[Imm+ R[Eᵦ]] | Base+displacement |
| Memory | (Eᵦ, Eᵢ) | M[R[Eᵦ]+ R[Eᵢ]*s] | Indexed |
| Memory | Imm(Eᵦ, Eᵢ) | M[Imm+ R[Eᵦ]+ R[Eᵢ]] | Scaled indexed |
| Memory | (, Eᵢ, s) | M[R[Eᵢ]*s] | Scaled indexed |
| Memory | (Eᵦ, Eᵢ, s) | M[R[Eᵦ]+ R[Eᵢ]*s] | Scaled indexed |
| Memory | Imm(Eᵦ, Eᵢ, s) | M[Imm+ R[Eᵦ]+ R[Eᵢ]*s] | Scaled indexed |
