# Call using Jump

```
long scount = 0

void swap_c(long a[], int i)
{
    swap(&a[i], &a[i+1]);
}
```

+   - Directly return from swap
+   - Possible since swap is a “tail call”

```
swap_c:
    movslq %esi,%rsi        # Sign extend
    leaq (%rdi,%rsi,8), %rdi # &a[i]
    leaq 8(%rdi, rsi,8), %rsi # &a[i+1]
    jmp swap # swap()
```
