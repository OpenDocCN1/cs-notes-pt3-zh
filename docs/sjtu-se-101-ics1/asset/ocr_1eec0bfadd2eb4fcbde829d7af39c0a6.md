# # FinRL 深度强化学习实战

FinRL 是一个用于金融强化学习的开源框架，旨在弥合算法交易研究与实践之间的差距。它提供了统一的流水线，包括市场环境搭建、智能体训练、回测与部署，助力研究者与从业者快速构建稳健的交易策略。

+   - 数据获取与预处理
+   - 环境构建与特征工程
+   - 强化学习智能体训练
+   - 回测与绩效评估
+   - 策略部署与实盘交易

| 模块 | 说明 |
|------|------|
| data | 数据下载与清洗 |
| env | 交易环境封装 |
| agent | 强化学习算法实现 |
| backtest | 回测引擎 |
| deploy | 实盘对接模块 |
