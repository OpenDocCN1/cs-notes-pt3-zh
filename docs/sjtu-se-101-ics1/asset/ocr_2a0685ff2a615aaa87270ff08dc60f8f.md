# Command-line Arguments

$ echo   hello, world    argv:

$ hello, world

![](bbox=[0.52, 0.18, 0.95, 0.48])

```
#include <stdio.h>
/* echo command-line arguments */
main(int argc, char *argv[])
{
    int i ;
    for ( i = 1; i < argc ; i++)
        printf("%s%s", argv[i], (i < argc-1) ? " " : "");
    printf("\n") ;
    return 0;
}
```
