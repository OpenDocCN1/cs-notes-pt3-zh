# Instructions

+   - Long word l (4 Bytes) ↔ Quad word q (8 Bytes)

+   - New Instructions
+     - `movl` → `movq`
+     - `addl` → `addq`
+     - `sall` → `salq`
+     - etc.

+   - 32 - bit instructions generate 32 - bit results
+     - Set higher order bits of destination register to 0
+     - Example: `addl`
