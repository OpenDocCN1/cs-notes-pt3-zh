# IEEE Floating-Point Representation

+   - Encoding
+     - `s` | `exp` | `frac`
+     - `s` is sign bit
+     - `exp` field encodes *E*
+     - `frac` field encodes *M*

+   - Sizes
+     - Single precision (32 bits): 8 exp bits, 23 frac bits
+     - Double precision (64 bits): 11 exp bits, 52 frac bits
