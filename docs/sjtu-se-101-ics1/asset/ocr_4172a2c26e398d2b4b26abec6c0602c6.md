# Example: swap()

# Swap long int in 64-bit

```
void
swap(long int *xp,
    long int *yp)
{
    long int t0 = *xp;
    long int t1 = *yp;
    *xp = t1;
    *yp = t0;
}
```

```
swap:
movq (%rdi), %rdx
movq (%rsi), %rax
movq %rax, (%rdi)
movq %rdx, (%rsi)
retq
```

64-bit data

Data held in registers %rax and %rdx

movq operation

"q" stands for quar-word
