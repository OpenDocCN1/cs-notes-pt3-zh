# VERSION CONTROL

+   - SVN (SubVersioN)
+     - Client Command
+       - show status
+         e.g. >svn status -q
+       - diff file
+         e.g. >svn diff b.txt
+       - resolve conflict
+         e.g. >vi a.c  //manually remove conflict
+         >svn resolved a.c

*svn resource link: http://subversion.tigris.org/
