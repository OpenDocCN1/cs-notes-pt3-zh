# Stride-N reference pattern

```
int sumarraycols(int a[M][N]) (M=2,N=3)
{
    int i, j, sum = 0 ;

    for (j = 0 ; j < N ; j++)
        for ( i = 0 ; i < M ; i++ )
            sum += a[i][j] ;
    return sum ;
}
```

| Access order | 1 | 3 | 5 | 2 | 4 | 6 |
