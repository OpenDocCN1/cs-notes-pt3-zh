# Locality

```
sum = 0;
for (i = 0; i < n; i++)
    sum += a[i];
return sum;
```

+   - Data references
+     - Reference array elements in succession
+       Spatial locality
+     - Reference variable `sum` each iteration
+       Temporal locality
+   - Instruction references
+     - Reference instructions in sequence.
+       Spatial locality
+     - Cycle through loop repeatedly
+       Temporal locality
