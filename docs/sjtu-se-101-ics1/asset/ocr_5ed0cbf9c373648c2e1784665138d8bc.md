# Disk access time

+   - **Rotational latency**
+     - Time waiting for first bit of target sector to pass under r/w head.
+     - Tₐᵥg rotation = 1/2 × 1/RPMs × 60 sec/1 min
+   - **Transfer time**
+     - Time to read the bits in the target sector.
+     - Tₐᵥg transfer = 1/(avg # sectors/track) × 1/RPM × 60 secs/1 min.
