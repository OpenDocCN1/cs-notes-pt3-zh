# C operators

| Operators | Associativity |
|---|---|
| () [] -> . ++ -- | left to right |
| ! ~ ++ -- + - * & (type) sizeof | right to left |
| * / % | left to right |
| + - | left to right |
| << >> | left to right |
| < <= > >= | left to right |
| == != | left to right |
| & | left to right |
| ^ | left to right |
| | | left to right |
| && | left to right |
| || | left to right |
| ?: | right to left |
| = += -= *= /= %= &= ^= != <<= >>= | right to left |
| , | left to right |

Note: Unary +, -, and * have higher precedence than binary forms
