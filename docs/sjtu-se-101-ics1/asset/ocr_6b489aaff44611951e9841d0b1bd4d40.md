# X86-64 Swap

```
```c
void swap(long *xp, long *yp)
{
    long t0 = *xp;
    long t1 = *yp;
    *xp = t1;
    *yp = t0;
}
```
```

```
```asm
swap:
    movq (%rdi), %rdx
    movq (%rsi), %rax
    movq %rax, (%rdi)
    movq %rdx, (%rsi)
    ret
```
```

+   - Operands passed in registers
+     - First (xp) in %rdi, second (yp) in %rsi
+   - No stack operations required (except ret)
+   - Avoid stack
+     - Can hold all local information in registers
