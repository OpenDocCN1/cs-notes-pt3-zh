# From Two's Complement to Binary

+   - If nonnegative
+     - Nothing changes
+   - If negative, its binary representation is
+     $1x_{w-2}\cdots x_{1}x_{0}$
+   - Its value is x
+     - Assume its absolute value is y = -x
+     - The binary representation of y is
+     $0y_{w-2}\cdots y_{1}y_{0}$
