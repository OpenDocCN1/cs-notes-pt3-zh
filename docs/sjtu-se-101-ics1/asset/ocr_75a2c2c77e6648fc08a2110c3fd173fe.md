# Structure

+   - References to structure elements
+     - Using offsets as displacements

r->j = r->i   (Copy element r->i to element r->j)

r is in register %edx.

```
1 movl    (%edx), %eax    Get r->i
2 movl    %eax,    4(%edx)  Store in r->j
```

| Offset | 0 | 4 | 8 | 20 |
| Contents | i | j | a[0] | a[1] | a[2] | p |
