# Without Stack Frame

```
```c
long s_count = 0

void swap_b(long a[], int i)
{
    swap(&a[i], &a[i+1]);
    s_count++
}
```
```

+   - No value held while swap being invoked
+   - No callee save registers needed

```
```asm
swap_b:
movslq %esi,%rsi          # sign extend
leaq (%rdi,%rsi,8), %rdi  # &a[i]
leaq 8(%rdi,%rsi,8),%rsi  # &a[i+1]
call swap                 # swap()
incq s_count(%rip)        # s_count++;
ret
```
