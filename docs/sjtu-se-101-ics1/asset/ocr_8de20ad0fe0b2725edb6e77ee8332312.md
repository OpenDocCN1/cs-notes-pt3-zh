# Code Reuse Attack

+   - **Return-oriented Programming**
+     - Find code gadgets in existed code base (e.g. libc)
+     - Push address of gadgets on the stack
+     - Leverage 'ret' to connect code gadgets
+     - No code injection
+   - **Solutions**
+     - Return-less kernels
+     - Heuristic means
+   - **New Attacks: Jump-oriented**
+     - Use gadget as dispatcher
