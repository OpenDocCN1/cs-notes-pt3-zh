# Example: swap()

Operands passed in registers

+   - First (xp) in %rdi
+   - Second (yp) in %rsi
+   - 64-bit pointers

```
swap:
movl (%rdi), %edx
movl (%rsi), %eax
movl %eax, (%rdi)
movl %edx, (%rsi)
retq
```

No stack operation required

32-bit data

+   - Data held in register %eax and %edx
+   - movl operation
