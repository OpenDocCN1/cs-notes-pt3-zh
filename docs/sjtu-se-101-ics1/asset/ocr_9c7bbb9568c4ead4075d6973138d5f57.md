+   - CPIO (CoPy files In and Out archives)
+     - cpio file format
+     - Suffix:
+       - .cpio
+         e.g. >cpio -id < test.cpio
+       - .cpgz / .cpio.gz
+         e.g. >find . -depth -print | cpio -o > x.cpio
+         >gzip -9 x.cpio
