# Power-of-2 Multiply with Shift

+   - Operation
+     - u << k gives u * 2^k
+     - Both signed and unsigned
+   - Examples
+     - u << 3 == u * 8
+     - u << 5 - u << 3 == u * 24
+     - Most machines shift and add much faster than multiply
+       - Compiler will generate this code automatically
