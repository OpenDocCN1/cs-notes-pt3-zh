# Conditional Move

# (a) Original C code

```
1 int absdiff(int x, int y) {
2   return x < y ? y-x : x-y;
3 }
```

# (b) Implementation using conditional assignment

```
1 int cmovdiff(int x, int y) {
2   int tval = y-x;
3   int rval = x-y;
4   int test = x < y;
5   /* Line below requires
6     single instruction: */
7   if (test) rval = tval;
8   return rval;
9 }
```
