# Representing Strings

+   - Strings in C
+     - Represented by array of characters
+     - Each character encoded in ASCII format
+     - String should be null-terminated
+       Final character = 0
+     - \a \b \f \n \r \t \v
+     - \\ \? \' \" \000 \xhh

```
char S[6] = "12345";
```
