# Switch Statements

+   - x86-64
+     - Same general idea, adapted to 64-bit code
+     - Table entries 64 bits (pointers)

```
.section .rodata
    .align 4
.L8:
    .long .L1 # x = 0
    .long .L2 # x = 1
    .long .L3 # x = 2
    .long .L4 # x = 3
    .long .L5 # x = 4
    .long .L6 # x = 5
    .long .L7 # x = 6
```

IA32

```
.section .rodata
    .align 8
.L8:
    .quad .L1 # x = 0
    .quad .L2 # x = 1
    .quad .L3 # x = 2
    .quad .L4 # x = 3
    .quad .L5 # x = 4
    .quad .L6 # x = 5
```
