# Procedures - Register

+   - X86-64/Linux Register Usage
+     - Arguments passed via regs
+       - %rcx %rdx %rsi %rdi %r8 %r9
+       - If more than 6 integer parameters, then pass rest on stack
+     - Return value by %rax
+     - No frame pointer
+     - Special
+       - %rsp stack pointer
+       - %r11 used for linking

| %rax ret | %r8 arg#5 |
| %rbx | %r9 arg#6 |
| %rcx arg#4 | %r10 |
| %rdx arg#3 | %r11 link |
| %rsi arg#2 | %r12 |
| %rdi arg#1 | %r13 |
| %rsp stack | %r14 |
| %rbp | %r15 |
