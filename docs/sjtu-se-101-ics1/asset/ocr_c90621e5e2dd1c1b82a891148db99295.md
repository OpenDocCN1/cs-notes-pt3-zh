# VERSION CONTROL

+   - SVN (SubVersioN)
+     - Client Command
+       - checkout
+         e.g. >svn co svn://10.132.143.1/truck truck
+         --username=rong
+       - update      e.g. >svn update
+       - commit      e.g. >svn ci a.c -message=".."
+       - add file e.g. >svn add b.c
+         >svn ci b.c -message=".."
+       - del file e.g. >svn del b.c
+         >svn ci b.c -message=".."
