# Search

+   - **whereis** - locate special files for a command (binary, src and manual file)
+     e.g. >whereis cp
+   - **find** - search for files/dirs in a dir hierarchy
+     e.g. >find . -name "c.txt"
+   - **locate** - locate files/dirs by name in system based on a database
+     e.g. >locate test
+   - **grep** - text search utility
+     e.g. >grep "abc" . -R
