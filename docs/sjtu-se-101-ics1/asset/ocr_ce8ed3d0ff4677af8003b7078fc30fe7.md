# X86 family

+   - *Core i7: (2008, 781 M transistors).*  
+     - Incorporated both hyperthreading and multi-core  
+     - the initial version supporting two executing programs on each core
+   - *Core i7: (2011.11, 2.27B transistors)*  
+     - 6 cores on each chip  
+     - 3.3G  
+     - 6*256 KB (L2), 15M (L3)
