# Stack Operations

```
pushl rA   a 0 rA F
```

+   - Decrement %esp by 4
+   - Store word from rA to memory at %esp
+   - Like IA32 (pushl %esp → save old %esp)

```
popl rA   b 0 rA F
```

+   - Read word from memory at %esp
+   - Save in rA
+   - Increment %esp by 4
+   - Like IA32 (popl %esp → movl (%esp) %esp)
