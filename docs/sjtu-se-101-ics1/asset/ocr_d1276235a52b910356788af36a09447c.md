# Local Variable

+   - **Allocation**
+     - Below saved regs or old `%ebp`
+     - `move/sub %esp` (e.g., `subl $4, %esp`)
+   - **De-allocation**
+     - `move/add %esp` (e.g., `addl $4, %esp`)
+   - **Usage**
+     - Relative to `%esp`/`%ebp`, (e.g., `movl %eax, 8(%esp)`)
