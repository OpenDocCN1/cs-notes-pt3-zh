# sbrk() Function

+   - `#include <unistd.h>`
+   - `void *sbrk(int incr)`
+     - If successful
+       - It returns the old value of brk
+     - If unsuccessful
+       - It returns −1
+       - It sets errno to ENOMEM
+     - If incr is zero
+       - It returns the current value
+     - incr can be a negative number
