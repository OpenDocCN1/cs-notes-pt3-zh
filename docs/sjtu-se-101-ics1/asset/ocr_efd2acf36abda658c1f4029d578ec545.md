# Standardization of C

| C version gcc | command line option |
|---|---|
| GNU 89 | *none*, -std=gnu89 |
| ANSI, ISO C90 | -ansi, -std=c89 |
| ISO C99 | -std=c99 |
| GNU 99 | -std=gnu99 |

+   - **ACM:**
+     - Association of Computing Machinery
+   - **IEEE:**
+     - Institute of Electrical and Electronics Engineers
