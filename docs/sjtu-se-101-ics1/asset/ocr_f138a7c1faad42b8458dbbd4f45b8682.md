# Types of ROMs

+   - Programmable ROM (PROM)
+     - Write once
+   - Erasable programmable ROM (EPROM)
+     - Erase by ultraviolet light
+     - Write by a special device
+     - About 1000 times
+   - Electrically erasable PROM (EEPROM)
+     - Reprogramming in-place on printed circuit cards
+   - Flash memory
+     - Based on EEPROM
