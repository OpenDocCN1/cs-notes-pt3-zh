# Denormalized Values

+   - Cases
+     - `exp = 000...0, frac = 000...0`
+       - Represents value 0
+       - Note that have distinct values +0 and -0
+     - `exp = 000...0, frac ≠ 000...0`
+       - Numbers very close to 0.0
+       - Lose precision as get smaller
+       - "Gradual underflow"
