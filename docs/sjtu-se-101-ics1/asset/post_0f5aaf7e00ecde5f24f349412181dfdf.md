## Enduring concepts
- Computer systems consist hardware and systems software that work together to run programs
- Specific implementations of systems change over time
- But the underlying concepts do not
- All computer systems have similar hardware and software components that perform similar functions

## From Programmer's Perspective
- Rather than system designer's perspective
  - Few students would have the opportunity to build a computer system
  - It's wasteful to teach every computer scientist how to design a microprocessor
  - Knowledge of how to build does not transfer to knowledge of how to use
