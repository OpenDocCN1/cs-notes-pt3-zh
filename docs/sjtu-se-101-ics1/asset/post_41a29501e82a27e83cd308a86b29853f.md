## Recursion Example

```
1 int fib_rec(int n)
2 {
3     int prev_val, val;
4
5     if (n <= 2)
6         return 1;
7     prev_val = fib_rec(n-2);
8     val = fib_rec(n-1);
9     return prev_val + val;
10 }
```

## Setup code

```asm
fib_rec:
pushl %ebp
movl %esp,%ebp
subl $16,%esp
pushl %esi
pushl %ebx
```

Save old %ebp  
Set %ebp as *frame pointer*  
Allocate 16 bytes on stack  
Save %esi (offset -20)  
Save %ebx (offset -24)
