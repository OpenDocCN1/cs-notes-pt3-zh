## Executable Object Files

- ELF header
  - Overall information
  - Entry point
- .init section
  - A small function _init
  - Initialization
- Segment header table
  - page size, virtual addresses for memory segments (sections), segment sizes.

## .init section

- Startup code
  - At the _start address defined in the crt1.o
  - Same for all C program

2. call _libc_init_first
3. call _init
4. call atexit

## Example (Symbol Table) (Hw 7.6)

```
extern int buf[];
int *bufp0 = &buf[0];
static int *bufp1;

static void incr()
{
    static int count=0;
    count++;
}
```

## Example (Symbol Table) (Hw 7.6)

```
void swap()
{
    int temp;

    incr();
    bufp1 = &buf[1];
    temp = *bufp0;
    *bufp0 = *bufp1;
    *bufp1 = temp;
}
```
