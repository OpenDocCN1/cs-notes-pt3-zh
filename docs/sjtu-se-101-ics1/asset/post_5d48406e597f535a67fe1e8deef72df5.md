## Commands
- MOST IMPORTANT
  - Search Path: `/bin, /usr/bin, ...`
  - Command is case sensitive
  - `man` - display the on-line manual pages
    e.g. `>man man`
  - `whatis` - search the whatis database for complete words
    e.g. `>whatis passwd`
