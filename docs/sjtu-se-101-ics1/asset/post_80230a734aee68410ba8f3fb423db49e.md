# Can we do it more efficiently and safely?

- Defuse bomb using GDB
  - set breakpoint on the critical path
  - watch registers and/or memories
  - terminate program on demand
  - single step execution

# Command

- **GDB**
  - `gdb <file>`
  - `break FUNC | *ADDR`
  - `run`
  - `print</?> $REG | ADDR`
  - `continue | stepi | nexti`
  - `quit`
