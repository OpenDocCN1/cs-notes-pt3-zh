> provides a complete system platform which supports the execution of a complete operating system
>

## INSTALL
- Step 2: Create VM
  - Select a Guest Operating System
    - Debian 6 / Other Linux 2.6.x kernel
  - Set name and location
  - Network connection
    - Bridge (separate IP) or NAT (internal IP)
  - Disk capacity
    - 20G (engross on demand)
  - Done !

> Tips: VMware Workstation
> Benefit
> hosted, popular, graphic
> easy, stable, checkpointed

## INSTALL
- Step 3: Configure VM
  - Insert ISO image
    - "VM -> Settings -> CD-ROM : Use ISO Image"
    - ISO Image: "debian-6.0.3-i386-CD-1.iso"
  - Configure Hardware
    - Memory Size
    - #CPU / #Core
    - Ethnet Mode
  - Power On  Let’s go !

> Tips: hard Disk in Linux
> 
> Naming: sd[x][y]
> sda1 - the 1st section of 1st HD
> sdb3 - the 2nd section of 3rd HD
> 
> * sd: SCSI disk / hd: IDE disk
