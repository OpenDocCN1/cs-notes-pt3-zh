
## Addressing caches

Address A:

```
t bits    s bits    b bits
m-1                                 0
<tag>   <set index>   <block offset>
```

set 0:

The word at address A is in the cache if the tag bits in one of the `<valid>` lines in set `<set index>` match `<tag>`.

The word contents begin at offset `<block offset>` bytes from the beginning of the block.

## Direct-mapped cache

- Simplest kind of cache
- Characterized by exactly one line per set.

## Line Replacement on Misses in Direct-Mapped Caches

- If cache misses
  - Retrieve the requested block from the next level in the memory hierarchy
  - Store the new block in one of the cache lines of the set indicated by the set index bits
- If the set is full of valid cache lines
  - One of the existing lines must be evicted
- For a direct-mapped cache
  - Each set contains only one line
  - Current line is replaced by the newly fetched line
