## 逻辑与物理之间的映射

- 唯一性
  - 每种位模式代表唯一的整数值
  - 每个可表示整数都有唯一的位编码

## 逻辑与物理之间的映射

- 反转映射（从逻辑到物理）
  - `U2B(x) = B2U⁻¹(x)`
    - 无符号整数的位模式
  - `T2B(x) = B2T⁻¹(x)`
    - 二进制补码整数的位模式

## C 中的整型数据类型

- 有符号类型（用于整数）
  - char, short [int], int, long [int]
- 无符号类型（用于非负数）
  - unsigned char, unsigned short [int],
    unsigned [int], unsigned long [int]
- Java 没有无符号数据类型
  - 使用 byte 替代 char

## 从有符号到无符号的类型转换

```
short int          x = 12345;
unsigned short int ux = (unsigned short) x;
short int          y = -12345;
unsigned short int uy = (unsigned short) y;
```

- 结果值
  - 位表示不变
  - 非负值保持不变
    - ux = 12345
  - 负值变为（大）正值
    - uy = 53191

## C 中的无符号常量

- 默认情况下
  - 常量被视为有符号整数
- 若后缀为 “U” 则为无符号
  - 0U, 4294967259U
