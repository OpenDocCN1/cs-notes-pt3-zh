# RISC 与 CISC

+   - ISA
+     - 指令集架构
+       - 特定处理器支持的指令
+       - 它们的字节级编码
+   - CISC
+     - 复杂指令集计算机
+   - RISC
+     - 精简指令集计算机

# CISC

+   - 从最早的计算机演变而来
+   - 大型机和小型机
+     - 到20世纪80年代初
+     - 它们的指令集已经变得相当庞大
+       - 操作环形缓冲区
+       - 执行十进制运算
+       - 计算多项式
+   - 微型计算机
+     - 出现于20世纪70年代，指令集有限
+       - 受限于单芯片上的晶体管数量
+     - 到20世纪80年代初，走上了扩展指令集的道路

# RISC

+   - 发展于20世纪80年代初
+     - 理念
+       - 对于更简单的指令集形式，人们能够生成高效的代码
+       - 复杂指令难以用编译器生成且很少使用
+     - 约翰·科克（1925-2002），1987年ACM图灵奖
+     - 大卫·帕特森，加州大学伯克利分校
+     - 约翰·亨尼西，斯坦福大学

# RISC 与 CISC

| CISC | 早期 RISC |
|---|---|
| 指令数量庞大 | 指令数量少得多（<100） |
| 部分指令执行时间长 | 没有执行时间长的指令 |
| 变长编码 | 定长编码 |
| 操作数指定格式多样 | 简单的寻址格式 |
| 算术和逻辑运算可应用于内存和寄存器操作数 | 算术和逻辑运算仅使用寄存器操作数。*加载/存储架构* |

# RISC

+   - **早期 RISC 的缺点**
+     - 指令更多
+     - 多周期
+     - 不向机器级程序暴露实现细节
+   - **RISC 的优点**
+     - 非常适合流水线（高效实现）
+   - **X86 融合了 RISC 特性**
+     - 将 CISC 指令动态翻译为类似 RISC 的操作并采用流水线架构
+     - X86-64 引入了更多 RISC 特性
