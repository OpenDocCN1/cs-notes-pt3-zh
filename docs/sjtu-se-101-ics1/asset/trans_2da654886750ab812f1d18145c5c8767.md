## 命令
- 最重要
  - 搜索路径：`/bin, /usr/bin, ...`
  - 命令区分大小写
  - `man` - 显示在线手册页
    e.g. `>man man`
  - `whatis` - 在 whatis 数据库中搜索完整单词
    e.g. `>whatis passwd`
