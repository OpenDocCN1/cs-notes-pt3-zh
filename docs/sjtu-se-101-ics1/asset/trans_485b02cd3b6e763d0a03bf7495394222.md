## 汇编指令中的操作

- 仅执行非常基础的操作
- 通常按顺序逐条执行
- 操作存储在寄存器中的数据
- 在内存和寄存器之间传输数据
- 有条件地分支到新的指令地址

## 理解机器执行

- 指令序列存储在哪里？
  - 在虚拟内存中
  - 代码区
- 指令如何执行？
  - %eip 存储内存的地址，从该地址，
  - 机器可以一次性读取整条指令
  - 然后执行它
  - 增加 %eip
    - %eip 也称为程序计数器 PC

## 数据布局

- 汇编中的对象模型
  - 一个大型的、按字节寻址的数组
  - 甚至有符号或无符号整数之间也没有区别
  - 代码、用户数据、操作系统数据
  - 用于管理过程调用和返回的运行时栈
  - 由用户分配的内存块

## 示例 C 代码

```
```c

    return t;
