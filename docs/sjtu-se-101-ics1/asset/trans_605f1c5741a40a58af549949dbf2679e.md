

## 结构体
```
int area (struct rect *rp)
{
    return (*rp).width * (*rp).height;
}

void rotate_left (struct rect *rp)
{
    /* Exchange width and height */
    int t = rp->height;
    rp->height = rp->width;
    rp->width = t;
}
```

## 结构体
- 内存布局
  - 所有组成部分都存储在连续的内存区域中
  - 指向结构体的指针是其第一个字节的地址

## 结构体
- 对结构体元素的引用
  - 使用偏移量作为位移量

r->j = r->i （将元素 r->i 复制到元素 r->j）

r 位于寄存器 %edx 中。

```
1 movl    (%edx), %eax    Get r->i
2 movl    %eax,    4(%edx)  Store in r->j
```

| 偏移量 | 0 | 4 | 8 | 20 |
| 内容 | i | j | a[0] | a[1] | a[2] | p |

## 结构体
&(r->a[i])

r 在 %eax 中，i 在 %edx 中：

```
1 leal 8(%eax,%edx,4),%ecx Generate &(r->a[i])
```

## 联合体
- 单个对象可以通过使用不同的数据类型来引用
- 联合体声明的语法与结构体完全相同，但其语义却大不相同
- 不同的字段并非引用不同的内存块，而是全部引用同一块内存

## 联合体
```
struct NODE {
    struct NODE *left;
    struct NODE *right;
    double data;
};

union NODE {
    struct {
        union NODE *left;
        union NODE *right;
    } internal;
    double data;
};
```

## 联合体
```
struct NODE {
    int is_leaf;
    union {
        struct {
            struct NODE *left;
            struct NODE *right;
        } internal;
        double data;
    } info;
};
```

## 对齐
- 对齐限制
  - 某些类型对象的地址必须是某个值 k 的倍数（通常为 2、4 或 8）
  - 简化处理器与内存系统之间接口的硬件设计

## 对齐
- 在 IA32 中
  - 无论数据是否对齐，硬件都能正常工作
  - 对齐的数据可以提高内存系统的性能

## 对齐
- Linux 的对齐限制
  - 1 字节数据类型可以具有任意地址
  - 2 字节数据类型的地址必须是 2 的倍数
  - 任何更大的数据类型的地址必须是 4 的倍数

## 对齐
- 对齐是通过以下方式实现的
  - 确保每种数据类型的组织和分配方式都使得该类型中的每个对象满足其对齐限制。
- malloc()
  - 返回一个 void * 类型的通用指针
  - 其对齐要求为 4

## 对齐
- 结构体数据类型
  - 可能需要在字段分配中插入间隔
  - 可能需要在结构体的末尾添加填充
