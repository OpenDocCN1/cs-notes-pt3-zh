

## 静态链接

- 输入
  - 可重定位目标文件和命令行参数
- 输出
  - 可加载和运行的完全链接的可执行目标文件

## 静态链接

- 目标文件
  - 各种代码和数据节
  - 指令位于一个节中
  - 已初始化的全局变量位于一个节中
  - 未初始化的全局变量位于一个节中

## 静态链接

- 重定位
  - 将*符号*从 .o 文件中的相对位置重定位到可执行文件中的新绝对位置。
  - 更新对这些符号的所有引用以反映其新位置。
- *引用*可以在代码或数据中
  - 代码：a(); /* 对符号 a 的引用 */
  - 数据：int *xp=&x; /* 对符号 x 的引用 */

## 代码示例

```
C code
int accum = 0;
int sum(int x, int y)
{
    int t = x+y;
    accum += t;
    return t;
}
```

使用命令获取

```
gcc -O2 -S code.c
```

汇编文件 code.s

```
_sum:
    pushl %ebp
    movl %esp,%ebp
    movl 12(%ebp),%eax
    addl 8(%ebp),%eax
    addl %eax, accum
    movl %ebp,%esp
    popl %ebp
    ret
```

## 目标文件

- 可重定位目标文件
  - 包含二进制代码和数据，其形式可与其他可重定位目标文件组合以创建可执行文件
- 可执行目标文件
  - 包含二进制代码和数据，其形式可直接复制到内存并执行

## 目标文件

- 共享目标文件
  - 一种特殊类型的可重定位目标文件，可在加载时或运行时加载到内存并动态链接

## EFI 目标文件格式

- .text 节
  - 代码
- .data 节
  - 已初始化的（静态）数据
- .bss 节
  - 未初始化的（静态）数据
  - “由符号开始的块”
  - “更好地节省空间”
  - 有节头但不占用空间

## EFI 目标文件格式

- .rel.data 节
  - .data 节的重定位信息
  - 在合并后的可执行文件中需要修改的指针数据地址
- .debug 节
  - 调试符号表、局部变量和 typedef、全局变量、原始 C 源文件（gcc -g）

## EFI 目标文件格式

- .line 节：
  - 原始 C 源程序中的行号与 .text 节中机器码指令之间的映射。
- .strtab 节：
  - 用于符号表和节名称的字符串表。

## 符号

- 三种符号
  - 已定义的全局符号
  - 被引用的全局符号
  - 局部符号

## 符号

- 已定义的全局符号
  - 由模块 m 定义，可被其他模块引用
    - 非静态 C 函数
    - 未使用 C static 属性定义的全局变量

## 符号

- 被引用的全局符号
  - 由模块 m 引用，但由其他模块定义
    - 在其他模块中定义的 C 函数和变量
- 局部符号
  - 仅由模块 m 定义和引用。
    - 带有 static 属性的 C 函数和全局变量
