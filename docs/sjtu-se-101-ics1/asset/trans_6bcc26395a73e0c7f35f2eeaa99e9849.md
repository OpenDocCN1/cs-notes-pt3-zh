

## 直接映射缓存中的冲突未命中

```
1 float dotprod(float x[8], float y[8])
2 {
3     float sum = 0.0;
4     int i;
5
6     for (i = 0; i < 8; i++)
7         sum += x[i] * y[i];
8     return sum;
9 }
```

- **x 和 y 的假设**
  - x 加载到从地址 0 开始的 32 字节连续内存中
  - y 紧跟在 x 之后从地址 32 开始
- **缓存的假设**
  - 一个块为 16 字节
    - 足以容纳四个浮点数
  - 缓存由两组组成
    - 总缓存大小为 32 字节

- 置换
  - 读取 x[0] 会将 x[0] ~ x[3] 加载到缓存中
  - 读取 y[0] 会用 y[0] ~ y[3] 覆盖缓存行

## 为什么使用中间位作为索引？

- 高位索引
  - 相邻的内存行会映射到同一个缓存条目
  - 空间局部性的利用不佳
- 中间位索引
  - 连续的内存行映射到不同的缓存行
  - 可以在一次缓存中容纳地址空间的 C 字节区域
