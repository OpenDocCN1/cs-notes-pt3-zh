## 要求

- 处理任意请求序列
- 对请求做出即时响应
- 仅使用堆
- 对齐块
- 不修改已分配的块

## 目标

- 给定一系列 malloc 和 free 请求：
- $R_0, R_1, ..., R_k, ..., R_{n-1}$
- 希望最大化吞吐量和峰值内存利用率。
- 这些目标通常是冲突的

## 性能目标：吞吐量

- 单位时间内完成的请求数
- 示例：
- 5,00 malloc 调用和 5,00 free 调用在 1 秒内
- 吞吐量为 1,000 次操作/秒。

## 性能目标：峰值内存利用率

- 给定一系列 malloc 和 free 请求：
- $R_0, R_1, ..., R_k, ..., R_{n-1}$
- 定义：聚合有效载荷 $P_k$：
- malloc(p) 产生一个有效载荷为 p 字节的块。
- 在请求 $R_k$ 完成后，聚合有效载荷 $P_k$ 是当前已分配有效载荷的总和。

## 性能目标：峰值内存利用率

- 定义：当前堆大小用 Hₖ 表示
- 注意 Hₖ 是单调不减的（可以放宽）
- 定义：峰值内存利用率：
- 在 k 个请求后，峰值内存利用率为：
- Uₖ = ( maxᵢ≤ₖ Pᵢ ) / Hₖ

## 碎片

- 由碎片引起的内存利用率低下
- 碎片有两种形式
- 内部碎片
- 外部碎片

## 内部碎片

- 内部碎片
- 对于某个块，内部碎片是块大小与有效载荷大小之间的差值

![](img/b3f8b91675c485f1e811aa092ebbf3d4_949_0.png)

## 内部碎片

- 内部碎片
- 由维护堆数据结构的开销、对齐目的的填充，或显式策略决策（例如不拆分块）引起。
- 仅取决于先前请求的模式，因此易于测量。

## 外部碎片

- 当有足够的聚合堆内存，但没有单个空闲块足够大时发生

```
p1 = malloc(4*sizeof(long))
```

```
p2 = malloc(5*sizeof(long))
```

```
p3 = malloc(6*sizeof(long))
```

```
free(p2)
```

```
p4 = malloc(6*sizeof(long))
```

## 外部碎片

- 外部碎片取决于
- 未来请求的模式
- 因此难以测量

## 知道要释放多少

- 标准方法
- 在结构前一个字中保存结构的长度
- 该字通常称为头部字段或头
- 每个已分配结构需要一个额外的字
