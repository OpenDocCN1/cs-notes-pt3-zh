## 指针

- 每个指针都有一个类型
  - 如果对象类型为 T
    - 指向该对象的指针类型为 T *
  - 特殊的 void * 类型
    - 表示通用指针
    - malloc 返回通用指针
- 每个指针都有一个值

## 指针

- 指针通过 & 运算符创建
  - 应用于左值表达式
    - 左值表达式可以出现在赋值的左侧
- 指针通过 * 运算符解引用
  - 结果是具有指针关联类型的数值
- 数组和指针密切相关
  - 数组名可视为指针常量
  - ip[0] 等价于 *ip

## 指针算术

- 加法和减法
  - p+i , p-i （结果为指针）
  - p-q （结果为 int）
- 取址与解引用
  - *p, &E
- 下标访问
  - A[i], *(A+i)

## 指针可以指向函数

- void (*f)(int *)
- f 是指向函数的指针
- 该函数以 int * 作为参数
- 函数的返回类型为 void
- 赋值使 f 指向 func
  - f = func
- 注意运算符的优先级
  - void *f(int *) 声明 f 为函数
    - (void *) f(int *)

## 指针声明

- char **argv ;
- int (*daytab)[13]
- int (*comp)()
- char (*(*x())[])()
  - 返回指向数组[ ] 的指针的函数，该数组元素是指向返回 char 的函数的指针
- char (*(*x[3])())[5]
  - 数组[3] 的元素是指向返回指向 char 数组[5] 的指针的函数的指针

## 越界内存引用

```

2 pushl    %ebp                Save %ebp on stack
3 movl     %esp, %ebp
4 pushl    %ebx                Save %ebx
5 subl     $20, %esp           Allocate 20 bytes on stack
6 leal     -12(%ebp), %ebx     Compute buf as %ebp-12
7 movl     %ebx, (%esp)        Store buf at top of stack
8 call     gets                Call gets
9 movl     %ebx, (%esp)        Store buf at top of stack
10 call    puts                Call puts
11 addl    $20, %esp           Deallocate stack space
12 popl    %ebx                Restore %ebx
13 popl    %ebp                Restore %ebp
```
