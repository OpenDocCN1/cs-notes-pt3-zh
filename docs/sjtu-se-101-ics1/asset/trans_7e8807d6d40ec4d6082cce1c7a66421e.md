## 移动指令

- 格式
  - mov src, dest
  - src 和 dest 只能是以下之一
    - 立即数
    - 寄存器
    - 内存

## 移动指令

- 格式
  - (src, dest) 的唯一可能组合是
    - （立即数，寄存器）
    - （内存，寄存器）加载
    - （寄存器，寄存器）
    - （立即数，内存）存储
    - （寄存器，内存）存储

## 数据移动示例

```
movl $0x4050, %eax      immediate register
movl %ebp, %esp         register   register
movl (%edx, %ecx), %eax memory    register
movl $-17, (%esp)       immediate memory
movl %eax, -12(%ebp)    register   memory
```

- 移动数据指令
  - mov（通用）
  - movb（移动字节）
  - movw（移动字）
  - movl（移动双字）

## 栈操作

- 有两个栈操作指令
  - Push 和 Pop
- Push
  - 减小 %esp（扩大栈）
  - 将寄存器中的值存储到栈中
- Pop
  - 将栈顶的值存储到寄存器中
  - 增加 %esp（缩小栈）

- 在 C 中，一个对象可能是
  - 一个整数
  - 一个结构或

## C 中的指针

- 在 C 中，指针的值是
  - 某个存储块第一字节的虚拟地址
  - 类型信息用于
    - 识别对象的长度
    - 解释对象 *p
- 生成指针
  p = &obj

## 数据移动示例

```
int exchange(int *xp, int y)
{
    /* operator * performs deferencing */
    int x = *xp ;
    *xp = y ;
    return x ;
}
```
