

# 分数二进制数

- “二进制点”右侧的位表示 2 的分数次幂
- 表示有理数：∑_{i=-n}^{m} b_i 2^i

# 分数到二进制位

```
unsigned result_bits=0, current_bit=0x80000000
for (i=0;i<32;i++) {
    x *= 2
    if ( x >= 1 ) {
        result_bits |= current_bit ;
        if ( x == 1 )
            break ;
        x -= 1 ;
    }
    current_bit >> 1 ;
}
```

# 编码有理数

- 直到 1980 年代
  - 许多特有的格式，速度快，实现简单，精度较低
- IEEE 754
  - 由 W. Kahan 为 Intel 处理器设计（图灵奖 1989）
  - 基于少量一致的原则，优雅、易于理解，很难使其变快

# IEEE 浮点表示

- 数值形式
  - V=(-1)^s × M × 2^E
  - 符号位 s 决定数字是负数还是正数
  - 尾数 M 通常是范围 [1.0,2.0) 中的分数值。
  - 指数 E 以 2 的幂加权值

# IEEE 浮点表示

- 编码
  - `s` | `exp` | `frac`
  - `s` 是符号位
  - `exp` 字段编码 *E*
  - `frac` 字段编码 *M*

- 大小
  - 单精度（32 位）：8 个 exp 位，23 个 frac 位
  - 双精度（64 位）：11 个 exp 位，52 个 frac 位

# 规范化值

- **条件**
  - exp ≠ 000...0 且 exp ≠ 111...1
- **指数编码为有偏值**
  - *E = Exp - Bias*
    - *Exp*: exp 表示的无符号值
    - *Bias*: 偏置值
      - 单精度：127（Exp: 1...254，E: -126...127）
      - 双精度：1023（Exp: 1...2046，E: -1022 ...1023）
  - 一般：*Bias = 2^{m-1} - 1*，其中 m 是指数位数

# 规范化值

- 尾数编码带隐含前导 1
  - m = 1.xxx...x₂
  - xxx...x: frac 的位
  - 最小时为 000...0（M = 1.0）
  - 最大时为 111...1（M = 2.0 - ）
  - 获得额外的前导位“免费”

# 非规范化值

- **条件**
  - exp = 000...0
- **值**
  - 指数值：E = 1 - Bias
  - 显著值 m = 0.xxx...x₂
    - xxx...x: frac 的位

# 非规范化值

- 情况
  - `exp = 000...0, frac = 000...0`
    - 表示值 0
    - 注意有不同的值 +0 和 -0
  - `exp = 000...0, frac ≠ 000...0`
    - 非常接近 0.0 的数
    - 越小精度越低
    - “渐进下溢”

# 特殊值

- `exp = 111...1, frac = 000...0`
  - 表示值（无穷大）
  - 溢出的操作
  - 正负皆有
  - 例如，1.0/0.0 = 1.0/ 0.0 = + , 1.0/ 0.0 =

# 特殊值

- `exp = 111...1, frac ≠ 000...0`
  - 非数字（NaN）
  - 表示无法确定数值的情况
  - 例如，sqrt(-1)，
