

## 类型转换约定

- 表达式求值
  - 如果在单个表达式中混合使用无符号和有符号
    - 有符号值会隐式转换为无符号
  - 包括比较操作 <, >, ==, <=, >=
  - W = 32 的示例

## 类型转换约定

| 常量1 | 常量2 | 关系 | 求值 |
|---|---|---|---|
| 0 | 0U | == | unsigned |
| -1 | 0 | < | signed |
| -1 | 0U | > | unsigned |
| 2147483647 | -2147483648 | > | signed |
| 2147483647U | -2147483648 | < | unsigned |
| -1 | -2 | > | signed |
| (unsigned)-1 | -2 | > | unsigned |

## 从短整型到长整型

```
short int x = 12345;
```

```
int ix = (int) x;
```

```
short int y = -12345;
```

```
int iy = (int) y;
```

- • 我们需要扩展数据大小
- • 无符号类型之间的转换是正常的
- • 有符号类型之间的转换是棘手的

## 从短整型到长整型

```
int fun1(unsigned word) {
    return (int)((word << 24) >> 24);
}
```

```
int fun2(unsigned word) {
    return ((int) word << 24) >> 24;
}
```

| w | fun1(w) | fun2(w) |
|---|---|---|
| 0x00000076 | 00000076 | 00000076 |
| 0x87654321 | 00000021 | 00000021 |
| 0x000000C9 | 000000C9 | FFFFFFFC9 |
| 0xEDCBA987 | 00000087 | FFFFFF87 |

用文字描述这两个函数执行的实用计算。

## 从长整型到短整型

```
int      x = 53191;
short int sx = x;
int      y = -12345;
short int sy = y;
```

- 我们需要截断数据大小
- 从长整型到短整型的转换是棘手的

## 截断数字

- 无符号截断
  $B2U_w([x_w, x_{w-1}, \cdots, x_0]) \bmod 2^k = B2U_k([x_k, x_{k-1}, \cdots x_0])$
- 有符号截断
  $B2T_k([x_k, x_{k-1}, \cdots x_0]) = U2T_k(B2U_w([x_w, x_{w-1}, \cdots, x_0]) \bmod 2^k)$
