

## FP 加法
- 操作数
  - $(-1)^{s1}\ M1\ 2^{E1}$
  - $(-1)^{s2}\ M2\ 2^{E2}$
  - 假设 $E1 > E2$
- 精确结果
  - $(-1)^{s}\ M\ 2^{E}$
  - 符号 $s$，尾数 $M$：
    - 有符号对齐与相加的结果
  - 指数 $E$ : $E1$

## FP 加法
- 修正
  - 如果 $M \geqslant 2$，将 $M$ 右移，$E$ 递增
  - 如果 $M < 1$，将 $M$ 左移 $k$ 位，$E$ 递减 $k$
  - 如果 $E$ 超出范围则溢出
  - 将 $M$ 舍入以适应 `frac` 精度

## C 中的浮点数
- *C 保证两种级别*
  - float    单精度
  - double   双精度

## 浮点数难题
- int x = ...;
- float f = ...;
- double d = ...;
- 假设 d 和 f 都不是 NAN 或无穷大

## 浮点数难题的答案
- `x == (int)(float) x` — 否：24 位尾数
- `x == (int)(double) x` — 是：53 位尾数
- `f == (float)(double) f` — 是：精度提高
- `d == (float) d` — 否：丢失精度
- `f == -( -f);` — 是：仅改变符号位
- `2/3 == 2/3.0` — 否：`2/3 == 0`
- `d < 0.0 ⇒ ((d*2) < 0.0)` — 是！
- `d > f ⇒ -f < -d` — 是
- `d * d >= 0.0` — 是！
- `(d+f)-d == f` — 否：不满足结合律

## 浮点数难题的答案
- **转换**
  - 在 int、float 和 double 之间进行强制转换会改变数值
  - Double 或 float 转 int
    - 截断小数部分
    - 类似于向零舍入
    - 超出范围时未定义
      - *通常饱和到 TMin 或 TMax*
  - int 转 double
    - 只要 int 的字长 ≤ 53 位，转换就是精确的
  - int 转 float
    - 将根据舍入模式进行舍入

## 什么是链接器
- 链接是
  - 将各种代码和数据片段收集并组合成单个可执行文件的过程
- 可执行文件
  - 可以被加载（复制）到内存中并执行。

## 什么是链接器
- 链接可以
  - 在编译时执行，当源代码由链接器翻译成机器代码时
  - 在加载时执行，当程序被加载到内存并由加载器执行时
  - 在运行时，由应用程序执行。

## 为什么学习链接
- 构建大型程序
  - 避免遗漏模块，尤其是库
- 避免危险的编程错误
  - 定义多个全局变量
- 理解作用域规则
  - Extern 和 static 与 auto 和 register 的区别

## 示例
- 两个函数
  - main() 和 swap()
- 三个全局变量
  - buf、bufp0 被显式初始化
  - bufp1 隐式初始化为 0

## 编译器驱动程序
- 协调翻译和链接过程中的所有步骤
  - 通常包含在每个编译系统（例如 gcc）中
  - 调用
    - 预处理器（cpp）
    - 编译器（cc1）
    - 汇编器（as）
    - 链接器（ld）。
  - 将命令行参数传递给相应的阶段

## 示例

```
unix> gcc -O2 -g -o p main.c swap.c
cpp [args] main.c /tmp/main.i
cc1 /tmp/main.i main.c -O2 [args] -o /tmp/main.s
as [args] -o /tmp/main.o /tmp/main.s
<similar process for swap.c>
ld -o p [system obj files] /tmp/main.o /tmp/swap.o
unix>
```
