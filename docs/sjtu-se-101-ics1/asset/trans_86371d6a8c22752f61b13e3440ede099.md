

## 栈帧的特性
- 一次性分配整个帧
  - 所有栈访问都可以相对于 %rsp
  - 通过递减栈指针实现
  - 可以延迟分配
- 简单的释放
  - 递增栈指针
  - 无需基/帧指针

## Y86 处理器状态
- 程序寄存器
  - 与 IA32 相同，共 8 个。每个 32 位
- 条件码
  - 由算术或逻辑指令设置的单比特标志
    - OF：溢出  ZF：零  SF：负数
- 程序计数器
  - 指示指令的地址
- 内存
  - 字节可寻址存储数组
  - 词以小端字节序存储

## Y86 指令
- 格式
  - 从内存读取 1--6 字节的信息
    - 可以根据第一个字节确定指令长度
    - 指令类型不如 IA32 多，且编码更简单
  - 每个指令访问并修改程序状态的某些部分

## 指令示例

### • 加法指令

通用形式

编码表示

```
addl rA, rB    6  0  rA rB
```

- 将寄存器 rA 中的值加到寄存器 rB 中
  - 将结果存储在寄存器 rB 中
  - 注意 Y86 只允许对寄存器数据进行加法
- 根据结果设置条件码
