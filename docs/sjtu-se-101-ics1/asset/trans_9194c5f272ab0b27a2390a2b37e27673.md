

## 虚拟空间

- 一个线性字节数组
  - 每个都有其唯一的地址（数组索引），从零开始

![](img/b3f8b91675c485f1e811aa092ebbf3d4_274_0.png)

## 内存引用

- 数组的名称标注为 M
- 如果 addr 是一个内存地址
- M[addr] 是从 addr 开始的内存内容
- addr 用作数组索引
- M[addr] 中有多少字节？
  - 取决于上下文

## 索引寻址模式

- 一个表达式用于
  - 内存地址（或数组索引）
- 最一般形式
  - Imm(E_b, E_i, s)
  - 常量“位移” Imm：1、2 或 4 字节
  - 基址寄存器 E_b：任意 8 个整数寄存器之一
  - 索引寄存器 E_i：任意，除了 %esp
  - S：比例因子：1、2、4 或 8

## 内存寻址模式

- 上述形式表示的地址
  - imm + R[E_b] + R[E_i] * s
- 它给出值
  - M[imm + R[E_b] + R[E_i] * s]

## 寻址模式

| 类型 | 形式 | 操作数值 | 名称 |
|---|---|---|---|
| 立即数 | $Imm | Imm | 立即数 |
| 寄存器 | Eₐ | R[Eₐ] | 寄存器 |
| 内存 | Imm | M[Imm] | 绝对寻址 |
| 内存 | (Eₐ) | M[R[Eₐ]] | 间接寻址 |
| 内存 | Imm(Eᵦ) | M[Imm + R[Eᵦ]] | 基址+位移 |
| 内存 | (Eᵦ, Eᵢ) | M[R[Eᵦ] + R[Eᵢ]*s] | 索引寻址 |
| 内存 | Imm(Eᵦ, Eᵢ) | M[Imm + R[Eᵦ] + R[Eᵢ]] | 缩放索引寻址 |
| 内存 | (, Eᵢ, s) | M[R[Eᵢ]*s] | 缩放索引寻址 |
| 内存 | (Eᵦ, Eᵢ, s) | M[R[Eᵦ] + R[Eᵢ]*s] | 缩放索引寻址 |

## 代码示例

```
C code
int accum = 0;
int sum(int x, int y)
{
    int t = x+y;
    accum += t;
    return t;
}
```

```
_sum:
    pushl %ebp
    movl %esp,%ebp
    movl 12(%ebp),%eax
    addl 8(%ebp),%eax
    addl %eax, accum
    movl %ebp,%esp
    popl %ebp
    ret
```

使用命令获取
    gcc -O2 -S code.c
汇编文件 code.s

## 目标代码

- 3 字节指令
- 存储在地址 0x80483ba
- 0x80483ba:  03 45 08

## 汇编指令中的操作

- 仅执行非常基础的操作
- 通常按顺序一个接一个执行
- 操作存储在寄存器中的数据
- 在内存和寄存器之间传输数据
- 有条件地分支到新的指令地址

## 理解机器执行

- 指令序列存储在哪里？
  - 在虚拟内存中
  - 代码区
- 指令如何执行？
  - %eip 存储内存地址，从该地址，
  - 机器可以一次读取整条指令
  - 然后执行它
  - 增加 %eip
    - %eip 也称为程序计数器（PC）

## 数据布局

- 汇编中的对象模型
  - 一个大型的、按字节寻址的数组
  - 甚至有符号或无符号整数之间也没有区别
  - 代码、用户数据、操作系统数据
  - 用于管理过程调用和返回的运行时栈
  - 由用户分配的内存块
