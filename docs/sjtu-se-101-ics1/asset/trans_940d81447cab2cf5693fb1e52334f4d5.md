地址 A：

```
t bits    s bits    b bits
m-1                                 0
<tag>   <set index>   <block offset>
```

如果 `<set index>` 中某条 `<valid>` 行的标签位与 `<tag>` 匹配，则地址 A 处的字在缓存中。

字内容从块开头偏移 `<block offset>` 字节处开始。

## 直接映射缓存

- 最简单的缓存类型
- 以每个集合恰好有一行来表征。

## 直接映射缓存中未命中时的行替换

- 如果缓存未命中
  - 从内存层次结构中的下一级检索请求的块
  - 将新块存储在由集合索引位指示的集合的其中一条缓存行中
- 如果集合已满有效缓存行
  - 必须驱逐其中一条现有行
- 对于直接映射缓存
  - 每个集合仅包含一行
  - 当前行被新获取的行替换
