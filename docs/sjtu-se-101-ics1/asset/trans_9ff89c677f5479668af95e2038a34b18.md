

## 为什么使用中间位作为索引？

4行缓存

- 高位索引
  - 相邻的内存行会映射到同一个缓存条目
  - 空间局部性利用不佳
- 中间位索引
  - 连续的内存行映射到不同的缓存行
  - 可以在缓存中同时容纳地址空间的 C 字节区域

## 通用缓存存储器组织

缓存是一个集合数组。

每个集合包含一个或多个行。

每行保存一块数据。

每行 1 个有效位
每行标签位
B = 2^b 字节/缓存块

## 缓存存储器

| **基本参数** |  |
|---|---|
| **参数** | **描述** |
| S = 2ˢ | 集合数 |
| E | 每个集合的行数 |
| B = 2ᵇ | 块大小（字节） |
| m = log₂(M) | 物理（主存）地址位数 |

## 缓存存储器

| **派生量** |  |
|---|---|
| **参数** | **描述** |
| M=2^m | 最大唯一内存地址数 |
| s=log2(S) | 集合索引位数 |
| b=log2(B) | 块偏移位数 |
| t=m−(s+b) | 标签位数 |
| C=B×E×S | 缓存大小（字节）不包括有效位和标签位等开销 |
