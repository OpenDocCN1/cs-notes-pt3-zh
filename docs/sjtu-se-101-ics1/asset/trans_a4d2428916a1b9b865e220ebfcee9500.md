## 缓存

- 存储层次结构的根本思想：
  - 对于每个 K，第 K 层的更快、更小的设备作为第 K+1 层更大、更慢的设备的缓存。
- 为什么存储层次结构有效？
  - 因为局部性，程序倾向于比访问第 k+1 层的数据更频繁地访问第 k 层的数据。
  - 因此，第 k+1 层的存储可以更慢，从而更大且每位更便宜。

大思想：存储层次结构创建了一个大存储池，其成本与底部附近的廉价存储相同，但以顶部附近的快速存储的速度向程序提供数据。

## 存储层次结构

- 存储技术和计算机软件的基本属性
  - 不同的存储技术具有截然不同的访问时间
  - 更快的技术每字节成本更高且容量更小
  - CPU 与主内存速度之间的差距正在扩大
  - 编写良好的程序往往表现出良好的局部性

## 一个示例存储层次结构

更小、更快、每字节更昂贵的存储设备

更大、更慢、每字节更便宜的存储设备

L0：寄存器
CPU 寄存器保存从缓存内存检索的字。

L1：片上 L1 缓存（SRAM）
L1 缓存保存从 L2 缓存检索的缓存行。

L2：片外 L2 缓存（SRAM）
L2 缓存保存从内存检索的缓存行。

L3：主内存（DRAM）
主内存保存从本地磁盘检索的磁盘块。

L4：本地二级存储（本地磁盘）
本地磁盘保存从远程网络服务器上的磁盘检索的文件。

L5：远程二级存储（分布式文件系统、Web 服务器）
