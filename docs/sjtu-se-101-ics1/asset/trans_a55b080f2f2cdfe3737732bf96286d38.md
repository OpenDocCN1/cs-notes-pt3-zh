## 布尔代数
- 由乔治·布尔(1815-1864)创立
  - 逻辑的代数表示
    - 将“真”编码为 1
    - 将“假”编码为 0
- 克劳德·香农(1916-2001)创立了信息理论
  - 建立了布尔代数与数字逻辑之间的联系
- 在数字系统的设计和分析中起着核心作用

## Xor 的妙用
- 按位异或是一种加法形式
- 具有每个值都是其自身加法逆元的额外属性
  - A ^ A = 0

## Xor 的妙用

```
int inplace_swap(int *x, int *y)
{
    *x = *x ^ *y;  /* #1 */
    *y = *x ^ *y;  /* #2 */
    *x = *x ^ *y;  /* #3 */
}
```

| Step | *x | *y |
|---|---|---|
| Begin | A | B |
| 1 | A^B | B |
| 2 | A^B | (A^B)^B = A^(B^B) = A^0 = A |
| 3 | (A^B)^A = (B^A)^A = B^(A^A) = B^0 = B | A |
| End | B | A |

## 掩码操作
- 编写适用于任意字长 w ≥ 8 的 C 表达式
- 对于 x = 0x87654321，w = 32
- x 的最低有效字节，其余位全部设为 0
- [0x00000021]。

## 掩码操作
- 除最低有效字节外全部取反，最低有效字节保持不变
  - [0x789ABC21]
- 将最低有效字节设为全 1，其余字节保持不变
  - [0x876543FF]。

## Bis & Bic
- bis (int x, int m) (bit set)
  - 将结果 z 在 m 为 1 的每个位位置设为 1
- bic(int x, int m) (bit clear)
  - 将结果 z 在 m 为 1 的每个位位置设为 0
- 数字设备公司 VAX
- 使用 bis 和 bic 实现
  - Or(int x, int y)
  - Xor(int x, int y)
