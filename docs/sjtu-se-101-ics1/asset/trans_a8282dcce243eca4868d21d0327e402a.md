

## 条件码

- 条件码
  - 一组单比特位
  - 维护在条件码寄存器中
  - 描述最近一次算术或逻辑操作的属性

- EFLAGS
  - CF: 进位标志
    - 最近一次操作在最高有效位产生进位输出
    - 用于检测无符号操作的溢出
  - OF: 溢出标志
    - 最近一次操作导致了二进制补码溢出——正或负
  - ZF: 零标志
    - 最近一次操作结果为零
  - SF: 符号标志
    - 最近一次操作结果为负值

## 设置条件码

- 由算术操作隐式设置

  `addl Src,Dest`

  C 类比: t = a+b

  - CF 在最高有效位有进位输出时置位
    - 用于检测无符号溢出
  - ZF 在 t == 0 时置位
  - SF 在 t < 0 时置位
  - OF 在二进制补码溢出时置位

    `(a>0 && b>0 && t<0) || (a<0 && b<0 && t>=0)`

- `lea` 指令
  - 对条件码没有影响

- `xorl` 指令
  - 进位标志和溢出标志被置为 0

- 移位指令
  - 进位标志被置为最后移出的位
  - 溢出标志被置为 0

- 由比较指令显式设置
  - `cmpl Src2,Src1`
  - `cmpl b,a` 类似于计算 a-b 但不设置目标
  - CF 在最高有效位有进位输出时置位
    - 用于无符号比较
  - ZF 在 a == b 时置位
  - SF 在 (a-b) < 0 时置位
  - OF 在二进制补码溢出时置位

    ```
    (a>0 && b<0 && (a-b)<0) ||
    (a<0 && b>0 && (a-b)>0)
    ```

- 由测试指令显式设置
  - `testl Src2,Src1`
  - 根据 *Src1* & *Src2* 的值设置条件码
    - 有用的一种做法是让其中一个操作数为掩码
  - `testl b,a` 类似于计算 `a&b` 但不设置目标
  - ZF 在 `a&b == 0` 时置位
  - SF 在 `a&b < 0` 时置位

## 访问条件码

- 条件码不能直接读取
- 访问它们的常用方法之一是
  - 基于条件码的某种组合设置整数寄存器
  - Set 命令

- 每个 set 命令执行后
  - 得到一个单字节，置为 0 或 1
- 不同 set 命令的描述适用于
  - 比较指令已执行的情况

| 指令 | 同义词 | 效果 | 置位条件 |
|---|---|---|---|
| Sete | Setz | ZF | 相等/零 |
| Setne | Setnz | ~ZF | 不相等/非零 |
| Sets |  | SF | 负数 |
| Setns |  | ~SF | 非负数 |
| Setl | Setnge | SF^OF | 小于 |
| Setle | Setng | (SF^OF)\|ZF | 小于或等于 |
| Setg | Setnle | ~(SF^OF)&~ZF | 大于 |
| Setge | Setnl | ~(SF^OF) | 大于或等于 |
| Seta | Setnbe | ~CF&~ZF | 高于 |
| Setae | Setnb | ~CF | 高于或等于 |
| Setb | Setnae | CF | 低于 |
| Setbe | Setna | CF\|ZF | 低于或等于 |

初始时 a 在 `%edx` 中，b 在 `%eax` 中

```assembly
1 cmpl %eax, %edx    #compare a:b
2 setl         %al    #set low order byte to 0 or 1
3 movzbl %al, %eax
                   #set remaining bytes of %eax to 0
```
