## 局部性

- **局部性原理：** 程序倾向于使用与最近使用过的地址相近或相同的地址的数据和指令
  - 时间局部性
    - 最近被引用的项目在不久的将来很可能再次被引用
  - 空间局部性
    - 地址相近的项目倾向于在时间上接近被引用

## 局部性

- 现代计算机系统的所有层级都旨在利用局部性
  - 硬件
    - 缓存存储器（加快主存访问速度）
  - 操作系统
    - 使用主存加快虚拟地址空间访问速度
    - 使用主存加快磁盘文件访问速度
  - 应用程序
    - Web 浏览器通过将最近引用的文档缓存到本地磁盘来利用时间局部性

## 局部性

- 示例中的局部性
  - sum：时间局部性
  - v：空间局部性
    - 步长为 1 的引用模式
- 步长为 k 的引用模式
  - 访问连续向量的每第 k 个元素
  - 随着步长的增加，空间局部性降低

## 步长为 1 的引用模式

```
int sumarrayrows(int a[M][N])
{
    int i, j, sum = 0 ;

    for (i = 0 ; i < M ; i++)
        for ( j = 0 ; j < N ; j++ )
            sum += a[i][j] ;
    return sum ;
}
```

| 访问顺序 | 1 | 2 | 3 | 4 | 5 | 6 |

## 步长为 N 的引用模式

```
int sumarraycols(int a[M][N]) (M=2,N=3)
{
    int i, j, sum = 0 ;

    for (j = 0 ; j < N ; j++)
        for ( i = 0 ; i < M ; i++ )
            sum += a[i][j] ;
    return sum ;
}
```

## 局部性

- 指令获取的局部性
  - 空间局部性
    - 在大多数情况下，程序按顺序执行
  - 时间局部性
    - 循环中的指令可能被执行多次

- 数据引用
  - 连续引用数组元素

  - 每次迭代引用变量 `sum`

  - 按顺序引用指令。

## 内存层次结构

- 存储技术和计算机软件的基本特性
  - 不同存储技术具有截然不同的访问时间
  - 更快的技术每字节成本更高且容量更小
  - CPU 与主存速度之间的差距在扩大
  - 编写良好的程序倾向于表现出良好的局部性
