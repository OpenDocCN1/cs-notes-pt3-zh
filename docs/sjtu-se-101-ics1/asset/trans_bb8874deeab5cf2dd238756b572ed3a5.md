## 访问组相联缓存

+   - 行匹配和字选择
+     - 必须将所选组中每个有效行的标记与地址中的标记进行比较。

=1时？(1) 有效位必须为1。

所选组 (1)：

(2) 某个缓存行的标记位必须与地址中的标记位匹配。

(3) 如果(1)和(2)都成立，则为缓存命中，块偏移选择起始字节。
