

## 字节序

- 大对象应如何存储在内存中？
- 对于跨多个字节的程序对象
  - 对象的地址会是什么？
  - 我们如何在内存中排列字节？
- 多字节对象存储为
  - 一段连续的字节序列
  - 对象的地址由所使用的字节的最小地址给出

- 小端序
  - 最低有效字节具有最低地址
  - Intel
- 大端序
  - 最低有效字节具有最高地址
  - Sun, IBM
- 双端序
  - 机器可以配置为小端或大端运行
  - 许多近期微处理器

## 如何访问对象

- C 编译器生成的实际机器级程序
  - 只是将每个程序对象视为一串字节
- C 中指针的值
  - 是上述存储块的第一个字节的虚拟地址

- C 编译器
  - 为每个指针关联类型信息
  - 生成不同的机器级代码来访问指向的值
    - 存储在指针指定的位置，具体取决于该值的类型
- C 编译器生成的实际机器级程序
  - 没有关于数据类型的任何信息

## 打印字节表示的代码

```c
void show_int(int x) {
    show_bytes((byte_pointer) &x, sizeof(int));
}
```

```c
void show_float(float x) {
    show_bytes((byte_pointer) &x, sizeof(float));
}
```

```c
void show_pointer(void *x) {
    show_bytes((byte_pointer) &x, sizeof(void *));
}
```

## C 中的特性

- typedef
  - 为一种类型命名
  - 语法与声明变量完全相同
- printf
  - 格式字符串：`%d`, `%c`, `%x`, `%f`, `%p`
- sizeof
  - `sizeof(T)` 返回存储类型 T 的对象所需的字节数
  - 朝着编写可在不同机器类型间移植的代码迈出一步

- 指针和数组
  - start 被声明为指针
  - 它被引用为数组 `start[i]`
- 指针创建和解引用
  - 取地址运算符 `&`
  - `&x`
- 类型转换
  - `(byte_pointer) &x`

## 打印字节表示的代码

```c
void test_show_bytes(int val) {
    int ival = val;
    float fval = (float) ival;
    int *pval = &ival;
    show_int(ival);
    show_float(fval);
    show_pointer(pval);
}
```

## 字节序变得可见

- 绕过正常的类型系统
  - 强制类型转换

## 表示字符串

- C 中的字符串
  - 由字符数组表示
  - 每个字符以 ASCII 格式编码
  - 字符串应以空字符结尾
    - 最后一个字符 = 0
  - `\a \b \f \n \r \t \v`
  - `\\ \? \' \" \000 \xhh`

char S[6] = "12345";
