

## 'float' 不是真正的数字

- 正数集合的乘积为正数
- 溢出和下溢
- 结合律不成立
  - (3.14+1e20)-1e20 = 0.0
  - 3.14+(1e20-1e20) = 3.14

## C 中的整型数据类型

- C 中有几种数据类型表示整数
- 区别在于整数的大小
- 它反映了硬件的实现

| C 声明 | 典型大小 |
|---|---|
| char | 1 字节 |
| short | 2 字节 |
| int | 4 字节 |
| long long | 8 字节 |
