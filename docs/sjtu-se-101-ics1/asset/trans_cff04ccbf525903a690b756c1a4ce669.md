## Hello 程序

- C 程序被翻译成
  - 一系列低级机器语言指令
- 这些指令随后被打包成一种形式
  - 称为目标程序
- 目标程序存储为二进制磁盘文件
  - 也称为可执行目标文件

## 源代码和汇编代码

```
int accum = 0;
int sum(int x, int y)
{
    int t = x+y;
    accum += t;
    return t;
}
```

```
_sum:
    pushl %ebp
    movl %esp,%ebp
    movl 12(%ebp),%eax
    addl 8(%ebp),%eax
    addl %eax, accum
    movl %ebp,%esp
    popl %ebp
    ret
```

gcc -O2 -S code.c

## C 的标准化

## 布尔代数

- 由 George Boole 在 19 世纪创立
  - 逻辑的代数表示
    - 将“真”编码为 1
    - 将“假”编码为 0

## 布尔代数

## 与

A&B = 1 当且仅当 A=1 且 B=1

| & | 0 | 1 |
|---|---|---|
| 0 | 0 | 0 |
| 1 | 0 | 1 |

## 或

A|B = 1 当 A=1 或 B=1 时

| | | 0 | 1 |
|---|---|---|
| 0 | | 0 | 1 |
| 1 | | 1 | 1 |

## 非

~A = 1 当 A=0 时

| ~ |  |
|---|---|
| 0 | 1 |
| 1 | 0 |

## 异或

A^B = 1 当 A=1 或 B=1 时，但不同时

| ^ | 0 | 1 |
|---|---|---|
| 0 | 0 | 1 |
| 1 | 1 | 0 |

## 一般布尔代数

- 对位向量操作
  - 操作按位应用

```
01101001
& 01010101
---------
01000001

01101001
| 01010101
---------
01111101

01101001
^ 01010101
---------
00111100

~ 01010101
---------
10101010
```

## 一般布尔代数

- 集合的表示
  - 宽度为 w 的位向量表示 {0, ..., w-1} 的子集
  - a_j = 1 如果 j ∈ A
    - 01101001    {0, 3, 5, 6}
    - 01010101    {0, 2, 4, 6}
  - & 交集        01000001 {0, 6}
  - | 并集                01111101 {0, 2, 3, 4, 5, 6}
  - ^ 对称差 00111100 {2, 3, 4, 5}
  - ~补集           10101010 {1, 3, 5, 7}
