## 调用被调函数

- 指令
  - `call label`（直接）
  - `call *operand`（间接）
- 行为描述（由硬件执行）
  - 将*返回地址*保存到栈中
  - 跳转到被调函数的*入口*

call = push + jmp

```
push retaddr
jmp callee
```

## 返回到调用者

- 指令
  - `ret`

- 行为描述（由硬件执行）
  - 从栈中弹出*返回地址*
  - 跳转到调用者中的*返回地址*

ret = pop + jmp

```
pop retaddr
jmp retaddr
```

## 栈帧结构

- 为某个过程分配的那部分栈空间
- 一个栈帧由以下两个指针界定
  - 帧指针 %ebp
  - 栈指针 %esp
- 当过程正在执行时，栈指针可以移动（动态）
- 帧指针是静态的

## 栈帧结构

- call：将*返回地址*保存到栈中
- ret：从栈中弹出*返回地址*
  - 调用者栈帧的末尾

## 恢复调用者的 %ebp

- 指令
  - `leave`

- 行为描述（由硬件执行）
  - 将 %esp 调整为被调函数的 %ebp
  - 从栈中弹出*调用者的 %ebp*

leave = mov + pop

```
mov %ebp, %esp
pop %ebp
```

## call 与 ret 的执行

```
//beginning of function sum
1.08048394 <sum>:
2. 8048394: 55              push   %ebp
             . . .
3. 80483a4:                  ret

//call to sum from main
4. 80483dc: e8 b3 ff ff ff  call   8048394<sum>
5. 80483e1: 83 c4 14       add    $0x14, %esp
```

| 执行 call | call 之后 | ret 之后 |
|---|---|---|
| `%eip` `0x080483dc` | `%eip` `0x08048394` | `%eip` `0x080483e1` |
| `%esp` `0xff9bc960` | `%esp` `0xff9bc95c` | `%esp` `0xff9bc960` |
| `ret` `-` | `ret` `0x080483e1` | `ret` `-` |

## 调用约定

- 寄存器是所有过程共享的单一资源
  - 同一时刻只能有一个过程处于活动状态
  - 在调用者与被调函数之间划分寄存器
    - 调用者保存寄存器
    - 被调函数保存寄存器
  - 只考虑该过程用到的寄存器

## 调用约定

- 调用者保存寄存器
  - %eax、%edx、%ecx
  - 由调用者保存
  - 被调函数可以自由使用这些寄存器
  - 返回后这些寄存器中的内容可能会被改变
  - 如果调用者在调用后还要使用这些寄存器，则必须恢复它们
