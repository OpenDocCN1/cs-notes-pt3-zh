

## 通用缓存概念：未命中

![](img/b3f8b91675c485f1e811aa092ebbf3d4_1139_0.png)

请求：12

需要块 b 中的数据

块 b 不在缓存中：

**未命中！**

从内存中取出块 b

将块 b 存入缓存

- **放置策略：** 决定 b 放在哪里
- **替换策略：** 决定哪个块被驱逐（牺牲块）

## 缓存未命中的类型

- 冷（强制）未命中
  - 冷未命中是因为缓存为空而发生。
- 容量未命中
  - 当活动缓存块集合（工作集）大于缓存容量时发生。
- 冲突未命中
  - 大多数缓存将第 k+1 层的块限制在第 k 层块位置的一个小子集（有时是单元素集合）中。
    - 例如，第 k+1 层的块 i 必须放在第 k 层的块 (i mod 4) 中。
  - 当第 k 层缓存足够大，但多个数据对象都映射到同一个第 k 层块时，就会发生冲突未命中。
    - 例如，访问块 0、8、0、8、0、8、…… 时，每次都会未命中。

## 缓存存储器

- 历史
  - 最初只有 3 层
    - 寄存器、主存、磁盘存储
  - 10 年后，4 层
    - 寄存器、SRAM 缓存、主 DRAM 内存、磁盘存储
  - 现代处理器，5~6 层
    - 寄存器、SRAM L1、L2（、L3）缓存、主 DRAM 内存、磁盘存储
  - 缓存存储器
    - 小型、快速的基于 SRAM 的存储器
    - 由硬件自动管理
    - 可以在芯片上、晶粒上或芯片外

## 在 CPU 与主存之间插入 L1 缓存

CPU 寄存器堆与缓存之间的传输单位是一个 **4 字节**块。

微小且极快的 CPU 寄存器堆可容纳四个 4 字节的字。

小而快的 L1 缓存可容纳两个 8 字的块。

缓存与主存之间的传输单位是一个 **8 字**块（32 字节）。

大而慢的主存可容纳许多 8 字的块。

## 通用缓存存储器组织

缓存是集合（set）的数组。

每个集合包含一行或多行。

每行保存一个数据块。

```
1 valid bit per line
tag bits per line
B = 2^b bytes per cache block

S = 2^s sets

set 0:
  valid tag 0 1 ... B-1
  ...
  valid tag 0 1 ... B-1
  E lines per set

set 1:
  valid tag 0 1 ... B-1
  ...
  valid tag 0 1 ... B-1

set S-1:
  valid tag 0 1 ... B-1
  ...
  valid tag 0 1 ... B-1
```

## 缓存存储器

### 基本参数

| 参数 | 描述 |
|---|---|
| S = 2^s | 集合数 |
| E | 每个集合的行数 |
| B = 2^b | 块大小（字节） |
| m = log₂(M) | 物理（主存）地址位数 |

### 派生量

| 参数 | 描述 |
|---|---|
| M = 2^m | 唯一内存地址的最大数量 |
| s = log₂(S) | 集合索引位数 |
| b = log₂(B) | 块偏移位数 |
| t = m - (s + b) | 标记位数 |
| C = B × E × S | 缓存大小（字节），不包括有效位和标记位等开销 |
