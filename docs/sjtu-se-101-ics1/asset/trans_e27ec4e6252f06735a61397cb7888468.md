## 动态内存分配

- 显式与隐式内存分配器
  - 显式：应用程序分配并释放空间
    - 例如，C 中的 `malloc` 和 `free`
  - 隐式：应用程序分配，但不释放空间
    - 例如 Java、ML 或 Lisp 中的垃圾回收

## Malloc 包

- `#include <stdlib.h>`
- `void *malloc(size_t size)`
  - 如果成功：
    - 返回指向至少 size 字节的内存块的指针，按 8 字节边界对齐。
    - 如果 size==0，则返回 NULL
  - 如果不成功：返回 NULL
- `void free(void *p)`
  - 将 p 指向的块返回到可用内存池
  - p 必须来自之前的 malloc、calloc 或 realloc 调用。
