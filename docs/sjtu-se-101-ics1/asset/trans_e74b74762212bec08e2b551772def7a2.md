

## C 语言中的逻辑运算

- 逻辑运算符
  - &&, ||, !
  - 将 0 视为 “False”
  - 任何非零值视为 “True”
  - 始终返回 0 或 1
  - 提前终止（短路）

## C 语言中的逻辑运算

- 示例（char 数据类型）
  - `!0x41  -->  0x00`
  - `!0x00  -->  0x01`
  - `!!0x41 -->  0x01`
  - `0x69 && 0x55  -->  0x01`
  - `0x69 || 0x55  -->  0x01`

## 逻辑运算中的短路

- a && 5/a
  - 如果 a 为零，则 5/a 的求值会被停止
  - 避免除零
- 仅使用位级和逻辑运算
  - 实现 x == y
  - 当 x 和 y 相等时返回 1，否则返回 0

## C 语言中的移位运算

- 左移：x << y
  - 将位向量 x 左移 y 位
  - 丢弃左侧多余的位
  - 右侧用 0 填充

| 参数 x | 01100010 |
| << 3 | 00010000 |

| 参数 x | 10100010 |
| << 3 | 00010000 |

## C 语言中的移位运算

- 右移：x >> y
  - 将位向量 x 右移 y 位
    - 丢弃右侧多余的位
  - 逻辑移位
    - 左侧用 0 填充
  - 算术移位
    - 在右侧复制最高有效位
    - 对二进制补码整数表示很有用（尤其是负数）

| 参数 x | 01100010 |
| Log. >> 2 | 00011000 |
| Arith. >> 2 | 00011000 |

| 参数 x | 10100010 |
| Log. >> 2 | 00101000 |
| Arith. >> 2 | 11101000 |

## C 语言中的移位运算

- 会发生什么？
  - `int lval = 0xFEDCBA98 << 32;`
  - `int aval = 0xFEDCBA98 >> 36;`
  - `unsigned uval = 0xFEDCBA98u >> 40;`

- 可能为
  - lval     0xFEDCBA98    (0)
  - aval     0xFFEDCBA9    (4)
  - uval     0x00FEDCBA    (8)

- 需要注意
  - `1<<2 + 3<<4` 表示 `1<<(2 + 3)<<4`

## bitCount

- 返回字中 1 的个数
- 示例：bitCount(5) = 2, bitCount(7) = 3
- 合法操作：! ~ & ^ | + << >>
- 最大操作数：40

## 求和 8 组每组 4 位

```
int bitCount(int x) {
    int m1 = 0x11 | (0x11 << 8);
    int mask = m1 | (m1 << 16);
    int s = x & mask;
    s += x>>1 & mask;
    s += x>>2 & mask;
    s += x>>3 & mask;
```

## 合并求和

```
/* Now combine high and low order sums */
s = s + (s >> 16);

/* Low order 16 bits now consists of 4 sums.
   Split into two groups and sum */
mask = 0xF | (0xF << 8);
s = (s & mask) + ((s >> 4) & mask);
return (s + (s>>8)) & 0x3F;
}
```

## 模具的失效形式与寿命

### 一、模具的失效

模具的失效是指模具失去正常工作的能力。模具的失效分为非正常失效和正常失效两类。非正常失效(早期失效)是指模具未达到一定寿命时的失效。正常失效是指模具经过大量的生产制件后,因缓慢地塑性变形或磨损等而最终失效。

模具的失效形式有断裂、塑性变形、磨损、疲劳等。断裂是指模具出现裂纹或开裂,是模具最严重的失效形式;塑性变形是指模具在受力过程中发生屈服,导致尺寸变化;磨损是指模具表面材料逐渐损失,影响制件精度;疲劳是指模具在循环应力作用下产生裂纹并扩展。

不同失效形式之间存在相互联系,如磨损和疲劳往往同时发生。模具的失效过程与其材料、热处理、使用条件等因素密切相关。

### 二、模具的寿命

模具的寿命是指模具在正常使用条件下,从开始使用到失效所能完成的制件总数。模具寿命的高低直接影响制件成本和模具费用。

提高模具寿命的途径包括:合理选择模具材料、优化模具结构设计、改进制造工艺、合理使用与维护等。

### 三、影响模具寿命的因素

影响模具寿命的因素主要有:模具材料、模具结构、加工精度、热处理质量、使用条件及维护保养等。

| 模具类型 | 寿命(万次) |
|---------|-----------|
| 冲裁模 | 50~100 |
| 弯曲模 | 100~200 |
| 拉深模 | 20~50 |
| 塑料模 | 10~50 |
