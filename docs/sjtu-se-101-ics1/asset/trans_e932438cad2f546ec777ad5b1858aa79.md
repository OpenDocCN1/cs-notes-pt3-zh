
# 命令

## 文件和目录

- `ls` — 列出文件/目录  
  例如：`>ls -l`
- `mkdir` — 创建目录  
  例如：`>mkdir test`
- `cd` — 更改目录  
  例如：`>cd test`
- `rm` — 删除文件/目录  
  例如：`>rm -f a.txt`
- `cp` — 复制文件/目录  
  例如：`>cp a.txt b.txt`
- `mv` — 移动文件/目录  
  例如：`>mv a.txt c.txt`
- `pwd` — 显示当前路径  
  例如：`>pwd`
- `du` — 估算文件/目录的空间占用  
  例如：`>du -c -h test`
- `df` — 报告空闲磁盘空间  
  例如：`>df`

- 文件和目录
  - `chmod` - 更改文件/目录的权限模式
    例如：`>chmod 777 test`
  - `chown` - 更改文件/目录的所有者
    例如：`>chown rong edit`
  - `chgrp` - 更改文件/目录的所属组
    例如：`>chgrp guest draft -R`

## 搜索

- **whereis** - 定位命令的特殊文件（二进制、源码和手册文件）
  例如：`>whereis cp`
- **find** - 在目录层次结构中搜索文件/目录
  例如：`>find . -name "c.txt"`
- **locate** - 基于数据库按名称在系统中定位文件/目录
  例如：`>locate test`
- **grep** - 文本搜索工具
  例如：`>grep "abc" . -R`

## 用户账户

- **useradd** - 创建新用户
  例如：`>useradd rong`
- **userdel** - 删除用户账户
  例如：`>userdel rong`
- **passwd** - 基于数据库设置用户账户的密码
  例如：`>passwd rong`
- **users** - 打印当前登录的用户名
  例如：`>users`

- 文本
  - `cat` - 连接并打印文件
    例如：`>cat b.txt`
  - `head` - 输出文件的开头部分
    例如：`>head -n 4 b.txt`
  - `tail` - 输出文件的结尾部分
    例如：`>tail -c 50 b.txt`
  - `wc` - 打印文件中的换行数、单词数和字节数
    例如：`>wc b.txt`
  - `cut` - 删除文件每行中的指定部分
    例如：`>cut -c 4-10 b.txt`

## 其他

- **echo** - 显示一行文本
  例如：`>echo $PATH`
- **mount** - 挂载文件系统
  例如：`>mount /dev/sda3 /mnt`
- **umount** - 卸载文件系统
  例如：`>umount /mnt`
- **ping** - 向网络主机发送 ICMP ECHO_REQUEST
  例如：`>ping 10.132.143.100`
- **date** - 打印或设置系统日期和时间
  例如：`>date "%m/%d/%y"`
- **time** - 为简单命令计时
  例如：`>time locate mapreduce`

## 其他

- `;` -- 在一行中连接两条命令
  例如：`>echo $PATH; whereis echo`
- `< > >>` -- 重定向输入和输出
  例如：`>cat b.txt >> c.txt`
- `|` -- 将前一个命令的输出作为后一个命令的输入
  例如：`>cat b.txt | grep "abc"`
- `&` -- 在新进程中执行命令
  例如：`>cat b.txt &`

# 版本控制

- APT（高级软件包工具）
  - 软件包管理系统
  - APT 的软件包资源列表：
    - `/etc/apt/sources.list`

```
$ cat /etc/apt/source.list
...
deb http://ftp.sjtu.edu.cn/debian/ squeeze main
deb-src http://ftp.sjtu.edu.cn/debian/ squeeze main
type URI of source dist comp
URI type: http, ftp, cdrom, file, ssh ...
```

| deb | http://ftp.sjtu.edu.cn/debian/ | squeeze | main |
|---|---|---|---|
| deb-src | http://ftp.sjtu.edu.cn/debian/ | squeeze | main |
| 类型 | 源 URI | 发行版 | 组件 |

- APT（高级软件包工具）
  - apt-get：*命令行工具*
    - **update** 例如：`>apt-get update`
    - **install** 例如：`>apt-get install htop`
    - **remove** 例如：`>apt-get remove htop`
    - **upgrade** 例如：`>apt-get upgrade htop`
  - apt-cache：*缓存管理器*
    - **search** 例如：`>apt-cache search htop`
    - **showpkg** 例如：`>apt-cache showpkg htop`
