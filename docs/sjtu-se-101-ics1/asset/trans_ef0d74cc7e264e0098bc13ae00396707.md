

# 整合

+   - **n-4.** 将返回值保存在 %eax  %esp
+   - **n-3.** 释放局部变量
+   - **n-2.** 恢复被调用者保存寄存器
+   - **n-1.** 恢复调用者 %ebp
+   - **n.** Ret 指令
+     - 弹出返回地址
+     - 将控制权转移给调用者

![](img/b3f8b91675c485f1e811aa092ebbf3d4_494_0.png)

# 示例

```
1 int swap_add(int *xp, int *yp)
2 {
3     int x = *xp;
4     int y = *yp;
5
6     *xp = y;
7     *yp = x;
8     return x + y;
9 }
```

# 示例

```
11 int caller()
12 {
13     int arg1 = 534;
14     int arg2 = 1057;
15     int sum = swap_add(&arg1, &arg2);
16     int diff = arg1 - arg2;
17
18     return sum * diff;
19 }
```
