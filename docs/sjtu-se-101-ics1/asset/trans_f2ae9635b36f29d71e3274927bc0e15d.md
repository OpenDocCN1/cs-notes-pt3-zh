# sbrk() 函数

- `#include <unistd.h>`
- `void *sbrk(int incr)`
  - If successful
    - It returns the old value of brk
  - If unsuccessful
    - It returns −1
    - It sets errno to ENOMEM
  - If incr is zero
    - It returns the current value
  - incr can be a negative number

# 要求

- 处理任意请求序列
- 对请求做出即时响应
- 仅使用堆
- 对齐块
- 不修改已分配的块

# 目标

- 给定一些 malloc 和 free 请求序列：
  - $R_0, R_1, ..., R_k, ... , R_{n-1}$
- 希望最大化吞吐量和峰值内存利用率。
  - 这些目标通常是冲突的

# 性能目标：峰值内存利用率

- 给定一些 malloc 和 free 请求序列：
  - $R_0, R_1, ..., R_k, ..., R_{n-1}$
- 定义：聚合有效载荷 $P_k$：
  - malloc(p) 会产生一个有效载荷为 p 字节的块。
  - 在请求 $R_k$ 完成后，聚合有效载荷 $P_k$ 是当前已分配有效载荷的总和。

# 性能目标：峰值内存利用率

- *定义：当前堆大小用 Hₖ 表示*
  - 注意 Hₖ 是单调不减的（可以放宽）
- *定义：峰值内存利用率：*
  - 在 k 个请求之后，峰值内存利用率为：
    - *Uₖ = ( maxᵢ≤ₖ Pᵢ ) / Hₖ*

# 碎片

- 由碎片引起的内存利用率低下
- 碎片有两种形式
  - 内部碎片
  - 外部碎片

# 内部碎片

- 内部碎片
  - 对于某个块，内部碎片是块大小与有效载荷大小之间的差值

![](img/b3f8b91675c485f1e811aa092ebbf3d4_992_0.png)

# 内部碎片

- 内部碎片
  - 由维护堆数据结构的开销、对齐目的的填充，或显式策略决策（例如不拆分块）引起。
  - 仅取决于之前的请求模式，因此易于测量。
