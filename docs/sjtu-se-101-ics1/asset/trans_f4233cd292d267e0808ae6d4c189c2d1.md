## FIFA世界杯历史

国际足联世界杯是由国际足球联合会（FIFA），即该项运动的全球管理机构的成员的男子成年国家队参加的国际足球比赛。该锦标赛自1930年首届锦标赛以来每四年颁发一次，除了1942年和1946年因第二次世界大战而未举行。

该锦标赛包括一个资格赛阶段，在此之前三年举行，以确定哪些球队有资格参加锦标赛阶段。在锦标赛阶段，32支球队在东道主国家的场地内在一个月左右的时间内争夺冠军。

### 历史

首届世界杯于1930年在乌拉圭举行。东道主国家以4-2战胜阿根廷赢得决赛。比赛的早期几年，欧洲和南美球队主导了锦标赛。奖杯由法国艺术家阿贝尔·拉弗勒设计，由镀金纯银制成。

- 1930: 乌拉圭 — 冠军：乌拉圭
- 1934: 意大利 — 冠军：意大利
- 1938: 法国 — 冠军：意大利
- 1950: 巴西 — 冠军：乌拉圭
- 1954: 瑞士 — 冠军：西德
- 1958: 瑞典 — 冠军：巴西
- 1962: 智利 — 冠军：巴西

## 示例（符号表）（Hw 7.6）
```
extern int buf[];
int *bufp0 = &buf[0];
static int *bufp1;

static void incr()
{
    static int count=0;
    count++;
}
```

```
void swap()
{
    int temp;

    incr();
    bufp1 = &buf[1];
    temp = *bufp0;
    *bufp0 = *bufp1;
    *bufp1 = temp;
}
```
