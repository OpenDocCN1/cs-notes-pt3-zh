

## 调用者保存寄存器

```
push %eax
push argument N
...
push argument 1
call callee
```

![](img/b3f8b91675c485f1e811aa092ebbf3d4_472_0.png)

## 调用约定

- 被调用者保存寄存器
  - %ebx、%esi、%edi
  - 由被调用者保存
  - 调用者可以自由使用这些寄存器
  - 被调用者在使用前必须保存它们
  - 被调用者必须在返回前恢复它们

## 被调用者保存寄存器

```
call callee
push %ebp
mov %esp, %ebp
push %ebx
...
```

![](img/b3f8b91675c485f1e811aa092ebbf3d4_474_0.png)

## 过程/函数实现

- ✔ 调用被调用者：call（新指令）
- ✔ 返回调用者：ret（新指令）
- ✔ 传递数据：栈、寄存器
- ✔ 寄存器：调用约定
- ? 局部变量：栈

## 局部变量

- 为什么不用寄存器存储局部变量？
  - 没有足够的寄存器
  - 数组和结构体（例如 a[2]）
  - 需要取地址（例如 &a）

## 局部变量

- **分配**
  - 在已保存的寄存器或旧`%ebp`之下
  - `move/sub %esp`（例如 `subl $4, %esp`）
- **释放**
  - `move/add %esp`（例如 `addl $4, %esp`）
- **使用**
  - 相对于`%esp`/`%ebp`（例如 `movl %eax, 8(%esp)`）
