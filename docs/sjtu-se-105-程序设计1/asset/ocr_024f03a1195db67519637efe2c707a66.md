+   编写文法的方式很直接：
+   1. 区分规则和符号
+   2. 将规则按顺序排列
+   3. 表达可选模式
+   4. 表达重复模式
+   5. 识别文法规则
+   list:
+   "{" Sequence "}"
+   Sequence:
+   Element
+   Element "," Sequence
+   Element:
+   "A"
+   "B"
+   {A}
+   {B}
+   {A,B}
+   {A,A,A,A,B}
+   {}
+   A
+   {A,A,A,A,B
+   {A,A,C,A,B}
+   {A B C}
