# 实例-计算质数

+   - 第五版本

```
#include <math.h>
#include "std_lib_facilities.h"

int main()
{
    int primeNumbers[50];
    int sizeOfPn = 0;
    for (int i=2;i<=100;i++){
        bool pn=true;
        for (int j=2; j<=sqrt((double)i); j++)
            if (i%j == 0) {
                pn=false;
                break;
            }
        if (pn==true){
            primeNumbers[sizeOfPn] = i;
            sizeOfPn++;
        }
    }
    keep_window_open();
}
```
