> “... I realized that from now on a large part of my life would be spent finding and correcting my own mistakes.”  
> — Maurice Wilkes, 1949

+   - 当我们编写程序时，出错是很自然的，也是很难避免的
+   - 问题是：如何处理它们呢？
+     - 将软件组织好，以最小化错误
+     - 消除大部分错误
+       - 调试
+       - 测试
+     - 确保遗留的错误不严重

+   - Bjarne Stroustrup 估计避免、查找和纠正错误的代价占到重要软件的开发总代价的95%以上
+     - 在小程序开发中你可以做得更好
+       - 也可能更差，如果你偷懒的话
