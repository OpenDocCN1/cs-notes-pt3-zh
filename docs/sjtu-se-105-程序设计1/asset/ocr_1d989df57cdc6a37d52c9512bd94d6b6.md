+   - 因此，我们需要某种方式能够将符号“放回去”！
+     - 放回到哪里？
+     - 当然是“输入”；也就是说，我们需要一种特殊的符号输入流

```
double expression()      // 处理+ 和-
{
    double left = term();
    while (true) {
        Token t = ts.get();    // 从“符号流”获取下一个符号
        switch (t.kind) {
        case '+':   left += term(); break;
        case '-':   left -= term(); break;
        default:    ts.putback(t); // 将未使用的符号放回到输入流中
                    return left;
        }
    }
}
```
