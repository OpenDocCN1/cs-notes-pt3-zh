# 字符串

+   - 字符串字面常量由零个或多个用双引号括起来的字符组成
+   - 不可打印字符可以由相应的转义序列来表示
+   - 一个字符串文字可以扩展到多行，在一行的最后加上一个反斜杠表明字符串文字在下一行继续

+   - "" (空字符串)
+   - "a"
+   - "\nCC\toptions\tfile.[cC]\n"
+   - "a multi-line \
+   string literal signals its \
+   continuation with a backslash "
+   - cout << "\nCC\toptions\tfile.[cC]\n";
