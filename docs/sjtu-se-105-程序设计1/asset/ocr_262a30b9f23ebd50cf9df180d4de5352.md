# Struct和类

+   - 类成员缺省情况下是私有的private:
+     ```
+     class X {
+         int mf();
+         // ...
+     };
+     ```

+   - 这表示
+     ```
+     class X {
+     private:
+         int mf();
+         // ...
+     };
+     ```

+   - 所以
+     ```
+     X x;          // variable x of type X
+     int y = x.mf();  // error: mf is private (i.e., inaccessible)
+     ```
