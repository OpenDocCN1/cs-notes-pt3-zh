# 用图绘制函数

+   - 我们从简单的开始
+     - 总是 “Hello, World!”
+   - 我们可以用图绘制函数
+     - 这些函数根据一个参数算出一个值
+     - Plot (x, f(x))   x 在区间[r1,r2)内取值
+   - 让我们来绘制下面三个简单的函数：
+     double one(double x) { return 1; }    // y==1
+     double slope(double x) { return x/2; }    // y==x/2
+     double square(double x) { return x*x; }    // y==x*x
