# 类模板的static成员

+   - 类模板可以声明static成员
+     ```
+     template <class T> class Foo {
+     public:
+         static std::size_t count() {return ctr;}
+         .....
+     private:
+         static std::size_t ctr;
+         .....
+     }
+     ```

+   - Foo类的每个实例都有自己的static成员

+   - 给定实例的所有对象都共享一个static成员

+   - Foo<int>的static成员有别于Foo<string>的static成员
