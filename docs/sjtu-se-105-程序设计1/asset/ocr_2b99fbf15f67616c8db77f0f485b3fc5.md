# 继承的优点

+   - 接口继承
+     - 需要 Shape 对象参数(通常作为一个引用参数 Shape &) 的函数可接受任何 Shape 派生类对象作为参数
+     - 使用简单
+       - 有时候，这种简化很明显
+     - 我们可以将从 Shape 派生的类添加到一个程序，而无需重新编写用户代码
+       - 添加新的代码而无须触碰老的代码，这对编程而言是一项 “必杀技”
+   - 实现继承
+     - 简化派生类的实现
+       - 可以在一处提供公共的功能
+       - 一处改变全局生效
+         - 另一项 “必杀技”
