# 递归的执行

+   - Main 函数用参数 3 调用 factorial 函数，调用时：
+     - 计算实参的值
+     - 创建一条活动记录
+     - 将实参的值复制给形参
+     - 赋值发生在 main 函数的第三行

![](bbox=[0.69, 0.36, 0.93, 0.49])

+   - 在 factorial 函数体中：
+     - n 不等于 0
+     - 于是执行 if 语句的另一条分支
+     - `return 3*factorial(2)`

![](bbox=[0.69, 0.54, 0.93, 0.73])

因此，factorial 函数必须调用 factorial 函数
