# I/O错误处理

+   - 错误源
+     - 人犯错
+     - 文件不符合规格说明
+     - 规格说明与现实不匹配
+     - 程序错误
+     - 等等

+   - `iostream` 将所有错误归纳为四种状态之一
+     - `good()`  // *the operation succeeded*
+     - `eof()`   // *we hit the end of input (“end of file”)*
+     - `fail()`  // *something unexpected happened*
+     - `bad()`   // *something unexpected and serious happened*
