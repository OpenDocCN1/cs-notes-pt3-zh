# 模板形参

+   - 用作模板形参的名字不能在模板内部重用：
+   
+   ```cpp
+   template <class T> T calc(const T &a, const T &b)
+   {
+       typedef double T;
+       T tmp = a;
+       return tmp
+   }
+   ```
+   
+   - 模板形参的名字只能在同一个模板形参中使用一次
+   
+   ```cpp
+   template <class V, class V> V calc(const V&, const V&)
+   ```
+   
+   - 模板形参的名字可以在不同的模板中重用
+   
+   ```cpp
+   template <class T> T calc(const T&, const T&)
+   template <class T> int compare(const T&, const T&)
+   ```
