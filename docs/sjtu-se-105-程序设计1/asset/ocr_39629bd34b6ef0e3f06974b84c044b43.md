+   - 我们程序设计的理念是用代码直接描述应用领域中的概念
+     - 如果你理解应用领域，你就能理解代码，反之亦然。例如：
+       - Window – 一个视窗，就像操作系统呈现的窗口一样
+       - Line – 一条线，就如你在屏幕上所见
+       - Point – 一个坐标点
+       - Color – 颜色，就如你在屏幕上所见
+       - Shape – 以我们的图形/GUI视角来看待世界时，所见到的所有形状的统称
+   - 最后一个例子Shape与其他例子不同
+     - 我们不能创建一个仅仅是Shape的对象
+     - 它是泛化的纯抽象概念
