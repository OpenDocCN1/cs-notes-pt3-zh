+   - 例如，对于下面的结构 game_t:
+   ```c
+   struct game_t {
+       board_t board;
+       deck_t chance;
+       deck_t chest;
+       unsigned int numPlayers; // Total number of players
+       player_t players[MAXPLAYERS];
+       unsigned int rounds  // Rounds remaining to play
+       bool isSim; // True->no move-by-move output
+   };
+   ```
+   - 每个函数都确切地知道所有有关游戏是如何表示的细节
+   - 对游戏定义的修改需要重新编译所有代码
+     - 有可能会引起贯穿整个程序的修改
