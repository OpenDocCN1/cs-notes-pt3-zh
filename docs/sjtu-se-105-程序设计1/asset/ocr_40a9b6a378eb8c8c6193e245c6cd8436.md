// 当心: C++ 不会阻止你在初始化变量之前使用它
// (尽管编译器通常会警告)

```
int main()
{
    int x;        // x 得到一个“随机”初始值
    char c;       // c 得到一个“随机”初始值
    double d;     // d 得到一个“随机”初始值
                  //   — 并非每一种位模式对浮点数都是有效的
    double dd = d;      // 潜在错误: 某些实现无法复制无效的浮点数
    cout << " x: " << x << " c: " << c << " d: " << d << "\n";
}
```

+   - 总是初始化变量
