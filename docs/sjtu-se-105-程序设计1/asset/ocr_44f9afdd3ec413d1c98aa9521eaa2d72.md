# # 数字与字符串

+   - **字符串**
+     - `cin >>` 读入（直至遇到空白符）
+     - `cout <<` 写出
+     - `+` 连接
+     - `+= s` 将字符串 s 追加到末尾
+     - `++` 不支持该操作
+     - `--` 不支持该操作
+     - `...`

+   - **整数与浮点数**
+     - `cin >>` 读入一个数字
+     - `cout <<` 写出
+     - `+` 加
+     - `+= n` 加上 int n
+     - `++` 自增 1
+     - `--` 减法
+     - `...`

变量的类型决定了哪些操作是合法的，以及这些操作对于该类型具有何种含义

> （这被成为“重载 overloading”或“操作符重载 operator overloading”）
