# 操作符

+   - 表达式是由操作符(operator)和操作符(operand)构成的
+     - 操作符指定要做什么
+     - 操作数指定操作符操作的数据

+   - 布尔类型: bool (true 和 false)
+     - 判等操作符: == (相等), != (不等)
+     - 逻辑操作符: && (与), || (或), ! (非)
+     - 关系操作符: < (小于), > (大于), <=, >=

+   - 字符类型: char (e.g., ‘a’, ‘7’, 与 '@')

+   - 整数类型: short, int, long
+     - 算术操作符: +, -, *, /, % (取余)

+   - 浮点类型: e.g., float, double (e.g., 12.45 and 1.234e3)
+     - 算术操作符: +, -, *, /
