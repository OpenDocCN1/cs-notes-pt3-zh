+   - 主要操作
+     - 缺省构造函数 (缺省情况：无参数)
+       - 如果声明了任何其他的构造函数，就不会有缺省构造函数
+       - 复制构造函数 (缺省情况：复制成员)
+     - 赋值 (缺省情况：复制成员)
+     - 析构器 (缺省情况: 无参数)
+   - 例如

```
Date d;      // error: no default constructor
Date d2 = d; // ok: copy initialized (copy the elements)
d = d2;      // ok: copy assignment (copy the elements)
```
