# 字符串输入

```
```cpp
// 读入 first和second:
int main()
{
    cout << "please enter your first and second names\\n";
    string first;
    string second;
    cin >> first >> second;                 // 读入两个字符串
    string name = first + ' ' + second;     // 连接字符串，用空格分开
    cout << "Hello, " << name << '\\n';
}

// 省略了 #include “std_lib_facilities.h” 以节省空间
