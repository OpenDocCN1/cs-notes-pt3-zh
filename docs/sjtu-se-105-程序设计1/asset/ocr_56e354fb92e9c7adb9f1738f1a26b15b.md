# 类型安全

+   - 类型安全事关重大
+     - 要十分仔细，不能违反它
+     - 在编程时，编译器是最好的朋友
+   - C++ 不是(完全)静态类型安全
+     - 没有一种广泛使用的语言是(完全)静态类型安全的
+     - 要做到完全静态类型安全，可能会影响你表达思想
+   - C++ 不是(完全)动态类型安全
+     - 许多语言都是动态类型安全的
+     - 要做到完全静态类型安全，可能会影响你表达思想
+     - 并且经常会使得产生的代码量很大或者运行速度很慢
+   - 这里要学习的大多数内容都是类型安全
+     - 我们会提到所有类型不安全的做法
