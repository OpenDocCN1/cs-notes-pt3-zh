# 程序编辑

+   - 源程序
+     - 程序员编辑的程序，存放在*.cpp文件中
+     - .h文件是头文件，用来提供函数声明、常量定义、全局数据声明等等
+       - #include 指示符读入指定文件的内容，头文件通过include 预处理器指示符而成为我们程序的一部分。
+         - `#include <some_file.h>`
+         - `#include "my_file.h"`
+     - 预处理器指示符用#号标识，这个符号将放在程序中该行的最起始一列上。处理这些指示符的程序被叫做预处理器
+       - `#include, #ifdef, #define`
