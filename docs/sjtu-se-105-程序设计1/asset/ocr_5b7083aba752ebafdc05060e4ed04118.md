# Shape类

+   - Shape类
+     virtual void draw_lines() const;  // draw the appropriate lines
+   - Circle类
+     void draw_lines() const { /* draw the Circle */ }
+   - Text 类
+     void draw_lines() const { /* draw the Text */ }
+   - Circle、Text 和其他的类

+     - 可以 “覆盖” draw_lines()
