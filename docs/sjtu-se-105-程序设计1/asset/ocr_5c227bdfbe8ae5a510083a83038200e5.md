如何告知表达式输入结束和退出程序？

```
int main()
{
    double val = 0;
    while (cin) {
        Token t = ts.get(); // 不是使用get_token()
        if (t.kind == 'q') break;                // 'q' for "quit"
        if (t.kind == ';')                       // ';' for "print now"
            cout << val << '\n';                // print result
        else
            ts.putback(t);                      // 将符号放回到输入流中
        val = expression();                      // 计算
    }
    keep_window_open();
}
// ... 异常处理...
```
