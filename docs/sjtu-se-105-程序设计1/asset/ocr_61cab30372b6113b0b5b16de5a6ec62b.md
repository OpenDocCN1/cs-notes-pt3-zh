# 效率

+   - 到目前为止，不用担心“效率”
+     - 聚焦在代码的正确性和简洁性上
+   
+   - C++ 是从 C 派生的，而 C 是一种系统编程语言
+     - C++的内置类型直接映射到计算机的主存上
+       - 一个 `char` 存储在一个 byte 中
+       - 一个 `int` 存储在一个 word 中
+       - 一个 `double` 适合浮点寄存器
+     - C++的内置操作直接映射到机器指令上
+       - 一个整数 `+` 是由一个整数加法操作实现的
+       - 一个整数 `−` 是由一个复制操作实现的
+     - C++ 提供对大部分现代硬件设备提供的工具进行直接访问的能力
+   
+   - C++ 帮助用户使用内置类型和操作构建更安全、更优雅、更高效的新类型和新操作
+     - 例如：字符串 string
+     - 最终，我们将展示它是如何做到的
