# 字符

+   - 我们也可以读入单个字符

```
char ch;
while (cin>>ch) {    // read into ch, skipping whitespace characters
    if (isalpha(ch)) {
        // do something
    }
}
```

```
while (cin.get(ch)) { // read into ch, don't skip whitespace characters
    if (isspace(ch)) {
        // do something
    }
    else if (isalpha(ch)) {
        // do something else
    }
}
```
