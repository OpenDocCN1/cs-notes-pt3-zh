# 处理 *, / 和 %

+   - 现在以同样的方式修改 term()

```
double term()    // 处理 * 和 /
{
    double left = primary();
    while (true) {
        Token t = ts.get();// 从输入中获取下一个符号
        switch (t.kind) {
        case '*':
            // 处理*
        case '/':
            // 处理/
        default:
            ts.putback(t);    // 将未使用的符号放回到输入流中
            return left;
        }
    }
}
```
