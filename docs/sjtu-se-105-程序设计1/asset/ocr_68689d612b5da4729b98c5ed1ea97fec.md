# 函数模板特化

+   - 模板特化的作用域

```
template <class T>

int compare(const T& t1, const T& t2) { ...... }

int main() {
    // uses the generic template definition
    int i = compare("hello", "world");
}

// invalid program: explicit specialization after call
template <>
int compare<const char*>( const char* const & v1,
                          const char* const &v2)
{ ...... }
```
