# 类型 vs. 行

+   - 读一个字符串

```
string name;
cin >> name;        // input: Dennis Ritchie
cout << name << '\n';  // output: Dennis
```

+   - 读一行

```
string name;
getline(cin,name);       // input: Dennis Ritchie
cout << name << '\n';    // output: Dennis Ritchie
// now what?
// maybe:
```
