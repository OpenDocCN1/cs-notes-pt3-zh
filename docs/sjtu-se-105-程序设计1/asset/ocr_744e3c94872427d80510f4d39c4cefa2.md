# 使用函数

+   - 通过使用函数，使每个函数职责都更加明晰

```
int main()
try {
    calculate();
    keep_window_open();  // cope with Windows console mode
    return 0;
}
catch (runtime_error& e) {
    cerr << e.what() << endl;
    keep_window_open("~~");
    return 1; }
catch (...) {
    cerr << "exception \n";
    keep_window_open("~~");
    return 2; }
```
