# 怎样重载一个函数名

+   - 编译器按如下步骤解释多次出现的函数名
+     - 如果两个函数的参数表相同，但是返回类型不同，则第二个声明被视为第一个的错误重复声明，会被标记为编译错误。（编译报错）

```
unsigned int max( int i1, int i2 );
int max( int, int ); //错误：只有返回类型不同
```

+   - 如果在两个函数的参数表中只有缺省实参不同，则第二个声明被视为第一个的重复声明（编译不报错）

```
int max( int *ia, int sz );
int max( int *, int = 10 );
```
