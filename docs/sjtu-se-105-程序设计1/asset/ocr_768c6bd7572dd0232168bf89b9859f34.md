# Private的好处

+   - 在发布之后，我们仍能修改我们的实现
+   - 我们不向用户暴露在表示中使用到的 FLTK类型
+     - 我们可以在不影响用户代码的情况下，用其他的库来替换FLTK
+   - 我们可以在访问函数中提供检查功能
+     - 但是我们还没有系统化地实现这一功能(以后完成?)
+   - 功能性接口对阅读和使用都显得更加友好化
+     - 比如, s.add(x) 比 s.points.push_back(x) 更友好
+   - 我们强制执行shape的不变性
+     - 仅仅是颜色和风格的变化;而不是点的相对位置的改变
+     - const 成员函数
+   - 这种封装性的价值因应用领域的不同而有所不同
+     - 经常会变得更有价值
+     - 它是一种理念
+     - 隐藏表示，除非你有充分的理由不这么做
