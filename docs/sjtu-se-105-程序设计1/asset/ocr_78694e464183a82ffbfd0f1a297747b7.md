# 什么是符号

+   - 我们可以将输入看做是一个符号流
+     - 我们读入字符 1 + 4*(4.5-6)（包含13个字符，其中2个是空格）
+     - 在这个表达式中包含 9 个符号: 1 + 4 * ( 4.5 - 6 )
+     - 6种符号: 数字 + * ( - )

+   - 我们认为每一个符号都包含两个部分
+     - “种类”; e.g., 数字 number
+     - 值; e.g., 4.5

+   - 我们需要一种类型来表示“符号”
+     - get_token() 从输入中获取下一个符号
+     - t.kind 获取符号的类型
+     - t.value 获取符号的值
