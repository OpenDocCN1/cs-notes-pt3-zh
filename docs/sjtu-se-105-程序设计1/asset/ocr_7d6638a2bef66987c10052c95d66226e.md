# 变量

+   - 计算机内存中放置输入值的空间被称为对象(Object)
+     - 具名的对象被称为变量(variable)
+     - 变量具有某种类型(type)
+     - 变量中存储的数据项称为值(value)

定义变量的语句被称为变量定义(definition)

+   - 定义变量时将在内存中分配一块空间给标量
+   - 定义变量时可以给变量赋初值（这往往是个好习惯）

```
string name = "Annemarie ";
int number_of_steps = 39;
```
