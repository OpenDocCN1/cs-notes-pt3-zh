+   - “有效日期”是有 效值这一概念的重要特例
+   - 我们尝试设计自己的类型，以保证值都是有效的
+     - 或者必须随时随刻检查有效性
+   - 构成有效值的规则被称为“不变式”
+     - Date 的不变式 (“Date 必须表示过去、现在或将来的某个日期”) 非常难准确地描述出来
+       - 例如，闰年的二月只有 28 天
+   - 如果我们无法设计出良好的不变式，那么有可能正在处理的只是普通数据
+     - 如果是这样，就使用 struct
+     - 努力尝试为你的类设计良好的不变式
+       - 这可以 将你从 bug 遍地的代码中拯救出来
