+   - 编程相当简单
+     - 只是声明机器该做些什么
+   - 那么为什么编程又那么难呢？
+     - 我们想让 “机器” 做更复杂的事情
+       - 计算机又是非常挑剔、无情和愚蠢的东西
+     - 世界远比我们想象的要复杂
+       - 因此我们不能总是知道我们想要的意味着什么
+     - “编程需要领悟”
+       - 当你对某个任务编程时，你首先需要理解它
+       - 当你编程时，你需要花大量的时间去理解想要自动化执行的任务
+     - 编程需要理论联系实践
+       - 如果只是实践，那就会产生不可扩展和不可维护的程序
+       - 如果只是理论，那就只能编写出过家家一样的程序
