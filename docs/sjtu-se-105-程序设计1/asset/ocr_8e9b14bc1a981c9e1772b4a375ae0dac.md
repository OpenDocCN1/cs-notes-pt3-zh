# 抽象类

+   - `.h` 文件中的函数要定义成 static 的：
+   
+     ```cpp
+     static IntSet *getIntSet();
+     ```
+   
+     ```cpp
+     // EFFECTS: returns a pointer to the IntSet
+     ```

+   - Static 作用于类的成员
+     - 数据成员和函数成员
+     - 表示这些成员不属于某个特有的对象
+     - 而是所有这个类的对象都具有的属性
+     - 因此，不需要创建任何对象，即可在类上调用
+     - `IntSet* s = IntSet::getIntSet()`
