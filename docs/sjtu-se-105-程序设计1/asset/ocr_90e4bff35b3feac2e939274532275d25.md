# 源文件-陷阱

![](bbox=[0.057, 0.153, 0.943, 0.732])

```
```cpp
// a.h
//definitions:
int get(){ /* ... */ }
void set(int i){ /* ... */ }
...
```
```

```
```cpp
// b.cpp
#include “a.h”
...
int i = get();
set(i);
...
```
```

```
```cpp
// c.cpp
#include “a.h”
...
set(get());
...
```
```

+   - 头文件 (a.h) 定义了用户代码和实现代码之间的接口的**实现**
+   - 在两个 .cpp 文件中使用相同的 #include 声明会造成**重复定义**
