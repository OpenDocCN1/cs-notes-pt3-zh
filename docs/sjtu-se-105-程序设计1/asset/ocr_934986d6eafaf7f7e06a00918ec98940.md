# 从错误中恢复

+   - 将计算任务从main()中分离
+     - main() 只执行初始化和清理

```
int main()    // step 1
try {
    calculate();
    keep_window_open();        // cope with Windows console mode
    return 0;
}
catch (exception& e) {        // errors we understand something about
    cerr << e.what() << endl;
    keep_window_open("~~");
    return 1;
}
catch (...) {                 // other errors
    cerr << "exception \n";
    keep_window_open("~~");
    return 2;
}
```
