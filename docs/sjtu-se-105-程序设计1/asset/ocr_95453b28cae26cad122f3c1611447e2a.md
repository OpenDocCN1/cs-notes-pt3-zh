# 类型安全准则－隐式窄化

```
```cpp
// 当心: C++ 不会阻止你将一个可能导致溢出的值赋给一个变量
// 尽管编译器有可能会警告

int main()
{
    int a = 20000;
    char c = a;
    int b = c;
    if (a != b)              // != 表示“不等于”
        cout << "oops!: " << a << " != " << b << '\n';
    else
        cout << "Wow! We have large characters\n";
}
