# 头文件和预处理器

+   - 头文件持有函数、类型、常量和其他程序组成部分的声明
+   - 下面的结构
+     `#include "../../std_lib_facilities.h"`
+     是一个“预处理器指令”，它会将声明添加到程序中
+     - 典型地，头文件只是一个文本(源代码)文件
+   - 头文件赋予我们对在自己的代码中需要访问的函数和类型的访问权
+     - 通常，我们不需要关心这些函数和类型是如何编写的
+     - 实际的函数和类型是在其它源文件中定义的
+       - 经常是库的一部分

```
#include "../../std_lib_facilities.h"
```
