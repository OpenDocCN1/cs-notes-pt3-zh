# IntSet示例

+   - 这个函数没有任何返回类型，因为它不需要返回任何值
+   - 在这个例子中，它也没有参数
+   - 但是可以保证它是第一个被调用的函数
+     - 在创建对象后立即被调用
+     - 并且向其提供了未初始化的IntSet
+     - 用于向其中构建符合表达式不变式的IntSet
+   - 下面是构造器代码：
+   
+     ```cpp
+     IntSet::IntSet(): numElts(0)
+     {
+     }
+     ```
+   
+   - 这种语法被成为“初始化语法(initialization syntax)”
