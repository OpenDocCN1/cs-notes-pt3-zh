# 定义类模板

+   - Queue类的实现
+     - 使用链表来实现
+     - 分成两个类
+     - QueueItem类：表示Queue链表中的节点
+       - 包含两个数据成员：item和next
+       - item保存Queue中元素的值，它的类型随Queue的每个实例而变化
+       - next是指向队列中下一个元素的指针
+       - Queue中的每个元素保存在一个QueueItem对象中
+     - Queue类：表示队列
+       - 包含两个数据成员：head和tail
+       - 都是指向QueueItem类型的指针
