+   - 什么是文法(grammar)?
+     - 关于表达式的一系列(语法)规则
+     - 这些规则描述了如何分析(“解析parse”)表达式
+     - 有些就像是我们脑子中固有的一样
+     - 例如，我们知道下面表达式的意义
+       - 2*3+4/2
+       - birds fly but fish swim
+     - 我们知道下面的表达式是错误的
+       - 2 * + 3 4/2
+       - fly birds fish but swim
+     - 为什么表达式是正确的/错误的?
+     - 我们如何知道的?
+     - 我们如何将所知道的教给计算机呢?
