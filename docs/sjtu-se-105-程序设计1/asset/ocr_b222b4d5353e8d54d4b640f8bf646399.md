# IntSet示例

+   - 接下来考虑其他三个函数
+     - query: 在数组中查找某个指定的数字
+     - remove: 在数组中查找某个数字，如果该数字存在，则移除它
+     - insert: 在数组中查找某个数字，如果该数字不存在，则插入它
+   - 所有这些函数的共同点就是都有“查找”部分
+   - 大家可能会想到使用 query 来编写 insert 和 remove
+     - 但是这对 remove 行不通
+     - query 只能告诉我们元素是否存在，但是不能告诉我们其位置
+   - 因此，我们还需要一个方法
+     - indexOf(int v): 如果 v 在集中，则返回 v 在集合中的位置
