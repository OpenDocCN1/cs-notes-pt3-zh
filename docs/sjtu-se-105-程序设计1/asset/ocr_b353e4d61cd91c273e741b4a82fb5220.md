# 表达式

```
```cpp
// 计算面积:
int length = 20;                 // 最简单的表达式: 字面常量 (这里的 20)
                                 // (这里初始化了一个变量)
int width = 40;
int area = length*width;          // 一个乘法
int average = (length+width)/2;  // 加法和除法
```
```

+   - 计算将遵循常见的数学意义上的运算次序
+     `a*b+c/d` 表示 `(a*b)+(c/d)` 而不是 `a*(b+c)/d`
+   - 如果有质疑，就加括号；如果计算复杂，也加括号
+   - 但是，不要书写过于复杂的表达式:
+     `a*b+c/d*(e-f/g)/h+7`  // 太复杂了！
+   - 常量表达式：选择有意义的名字表示常量
+     `const pi = 3.1415926;`
