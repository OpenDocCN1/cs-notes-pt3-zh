+   - 精度(缺省为位)
+     - 普通格式- 精度是所有数字的个数
+       - 注意: 普通指示符不是标准规定的, 只是在std_lib_facilities.h中规定的
+     - 科学计数法- 精度是小数点之后的位数
+     - 固定位数- 精度是小数点之后的位数

```
// example:
cout << 1234.56789 << '\t' << fixed << 1234.56789 << '\t'
    << scientific << 1234.56789 << '\n';
cout << general << setprecision(5)
    << 1234.56789 << '\t' << fixed << 1234.56789 << '\t'
    << scientific << 1234.56789 << '\n';
cout << general << setprecision(8)
    << 1234.56789 << '\t' << fixed << 1234.56789 << '\t'
    << scientific << 1234.56789 << '\n';
```
