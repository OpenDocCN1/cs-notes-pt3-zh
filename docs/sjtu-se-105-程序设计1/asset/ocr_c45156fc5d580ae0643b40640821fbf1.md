# 数组类型

+   - 数组可以被显式地用一组数来初始化
+     - `const int array_size = 3;`
+       `int ia[array_size] = { 0, 1, 2 };`
+     - `int ia[] = { 0, 1, 2 };`
+     - `const int array_size = 5;`
+       `int ia[array_size] = { 0, 1, 2 };`  // `ia[] = { 0, 1, 2, 0, 0 }`
+     - `const char ca1[] = { 'C', '+', '+' };`  // 维数是3
+     - `const char ca2[] = "C++";`  // 维数是4
+     - `const char ch3[6] = "Daniel";`  // 错误: "Daniel"是7个元素
