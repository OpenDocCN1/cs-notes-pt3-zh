# 二分搜索

```
int BinarySearch(int *arr,int length,int num){
    int begin = 0;
    int end = length - 1;
    int mid;
    while(begin <= end){
        mid = begin + (end - begin)/2;
        if (arr[mid] == num)
            return mid;
        if (arr[mid] < num)
            begin = mid + 1;
        else
            end = mid - 1;
    }
    return -1;
}
```
