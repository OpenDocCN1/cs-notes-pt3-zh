# 调试

+   - 按照指定的步骤通查程序
+     - 假设你就是执行程序的计算机
+     - 输出是否与你的预期匹配？
+     - 如果输出信息不够，可以添加一些调试用的输出语句
+     `cerr << "x == " << x << ", y == " << y << '\n';`
+   - 非常仔细地
+     - 检查程序程序指定的行为，而不是你认为它应该表现的行为
+       - 听起来容易，做起来难
