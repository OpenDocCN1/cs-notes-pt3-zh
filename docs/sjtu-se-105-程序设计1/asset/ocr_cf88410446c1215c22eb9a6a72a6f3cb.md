# 类模板特化

+   - 在类特化外部定义成员时，成员之前不能加template<>标记
+     ```cpp
+     void Queue<const char*>::push(const char* val)
+     {
+         return real_queue.push(val);
+     }
+     ```
+   - 这个函数隐式地复制了val指向的字符数组
+     - 该调用从const char*实参创建了一个新的string对象
+     - const char*实参使用了以const char*为参数的string构造函数
+     - string 构造函数将val所指的数组中的字符复制到未命名的string对象
+     - 该对象被存储在push到real_queue的元素中
