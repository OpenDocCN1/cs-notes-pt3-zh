# 重载与函数模板

```
// calls compare(T,T) with T bound to char*
compare(ch_arr1, ch_arr2);
// calls compare(T,T) with T bound to char*
compare(p1,p2);
// calls ordinary function taking const char* parameter
compare(const_arr1, const_arr2);
const char *cp1 = const_arr1, *cp2 = const_arr2;
// calls ordinary function taking const char* parameter
compare(cp1, cp2);
```
