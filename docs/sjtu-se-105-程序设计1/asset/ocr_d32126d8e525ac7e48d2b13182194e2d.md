# 从错误中恢复

+   - 将处理异常的代码从error() 移入calculate()

```
int main()    // step 2
try {
    calculate();
    keep_window_open();    // cope with Windows console mode
    return 0;
}
catch (...) {    // other errors (don’t try to recover)
    cerr << "exception \n";
    keep_window_open("~~");
    return 2;
}
```
