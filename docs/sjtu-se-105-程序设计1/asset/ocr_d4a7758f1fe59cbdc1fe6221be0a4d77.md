# 作用域

+   - 作用域是一个程序文本区域
+     - 例如
+       - 全局作用域 (在任何语言结构的外部)
+       - 类作用域 (在类的内部)
+       - 局部作用域 (在 { ... } 之间)
+       - 语句作用域 (例如， for语句)

+   - 在一个作用域中的名字可以在这个作用域中以及嵌套在其中的作用域中被访问
+     - 在名字被声明之后 ("无法向前看 can't look ahead" 规则)

+   - 作用域可以让 “事物” 保持局部性
+     - 防止我的变量和函数等与你的变量和函数之间互相干扰
+     - 记住: 真实的程序可能会有成千上万的实体
+     - 局部性非常好!
+       - 尽量使名字是局部的
