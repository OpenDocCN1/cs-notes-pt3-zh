# 函数

+   - 尽量避免(非常量)引用参数
+     - 在你忘记那些引元可以修改时，它们会导致难以琢磨的缺陷
+     - `int incr1(int a) { return a+1; }`
+     - `void incr2(int& a) { ++a; }`
+     - `int x = 7;`
+     - `x = incr1(x); // pretty obvious`
+     - `incr2(x); // pretty obscure`

+   - 那么为什么需要引用参数呢?
+     - 有时，它们很有用
+       - 例如，用于修改多个值
+       - 用于操作容器，例如vector
+     - 常量引用参数显得很有用
