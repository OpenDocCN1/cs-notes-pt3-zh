# 编译时错误

+   - 编译器只能发现十分简单的问题
+     - 拼写错误
+     - 语句不完整

+   - 语法错误
+     - `int area(int length, int width);` // 计算矩形的面积
+     - `int s1 = area(7;` // error: ) 缺失
+     - `int s1 = area(7)` // error: ; 缺失
+     - `Int s3 = area(7);` // error: Int 不是一种类型
+     - `int s4 = area('7);` // error: 非终止字符 ' 缺失
