```
// 读入名字和年龄
int main()
{
    cout << "please enter your first name and age\n";
    string first_name;        // 字符串变量
    int age;                  // 整数变量
    cin >> first_name >> age;    // 读入
    cout << "Hello, " << first_name << " age " << age << '\n';
}
```

+   - >> 是对类型敏感的
+     - 根据读入的变量类型来读取输入值
+     - 输入 22 Carlos 会如何？
+     - 对变量赋初值可以防止这种错误
