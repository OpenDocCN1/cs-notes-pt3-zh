# 表达式语法

+   - 编写一种文法-专家的做法：
+     Expression :
+       Term
+       Expression ‘+’ Term        e.g., 1+2,  (1-2)+3,  2*3+1
+       Expression ‘-’ Term
+     Term :
+       Primary
+       Term ‘*’ Primary           e.g., 1*2,  (1-2)*3.5
+       Term ‘/’ Primary
+       Term ‘%’ Primary
+     Primary :
+       Number                     e.g., 1,  3.5
+       ‘(’ Expression ‘)’         e.g., (1+2*3)
+     Number :
+       floating-point literal     e.g., 3.14, 0.274e1

+   - 程序就是由符号(token) 构建出来的(e.g., numbers and operators).
