# 冒泡排序

```
void BubbleSort(int* r,int length){
    int i,j,tmp;
    for(i = 0; i < length; i++){
        for(j = i+1; j < length; j++)
            if(r[i] > r[j]){
                tmp = r[i];
                r[i] = r[j];
                r[j] = tmp;
            }
    }
}

int main(){
    int a[10] = {2,4,6,8,10,1,3,5,7,9};
    BubbleSort(a,10);
}
```
