# 静态局部对象

```
#include <iostream>
int traceGcd( int v1, int v2 )
{
    static int depth = 1;
    cout << "depth #" << depth++ << endl;
    if ( v2 == 0 ) {
        depth = 1;
        return v1;
    }
    return traceGcd( v2, v1%v2 );
}
```

假设 v1 = 15, v2 = 123

| Times | depth | depth' | v1 | v2 |
|---|---|---|---|---|
| 1 | 1 | 2 | 15 | 123 |
| 2 | 2 | 3 | 123 | 15 |
| 3 | 3 | 4 | 15 | 3 |
| 4 | 4 | 5 | 3 | 0 |
