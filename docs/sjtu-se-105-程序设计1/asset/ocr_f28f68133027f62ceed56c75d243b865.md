# 用于解析的函数

+   - 我们需要下面的函数来匹配文法规则
+     get() // 读入字符，并组装符号
+     // 调用 cin 输入
+     expression() // 处理 + 和 -
+     // 调用 term() 和 get()
+     term () // 处理 *, / 和 %
+     // 调用 primary() 和 get()
+     primary() // 处理数字和括号
+     // 调用 expression() 和 get()

+   - 注意：每个函数处理表达式中的特定部分，并将其他部分留给其他函数处理，这可以简化每个函数

+   - 类比：将一组人群聚在一起解决复杂问题时，每个人指出了他的专业部分，将其他部分留给同事处理
