+   - 在C++程序中的名字
+     - 以字母开头，包含字母、数字和下划线While
+       - x, number_of_elements, Fourier_transform, z2
+       - 不合法的名字
+         - 12x
+         - time$to$market
+         - main line
+       - 不要以下划线开头: _foo
+         - 这类名字为保留名
+     - 用户使用关键字来定义名字
+       - 例如:
+         - int
+         - if
+         - while
+         - double
