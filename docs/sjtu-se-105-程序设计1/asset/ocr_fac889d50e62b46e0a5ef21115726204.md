# 编译时错误

+   - 编译器只能发现十分简单的问题
+     - 拼写错误
+     - 语句不完整

+   - 警告错误
+     - `int area(int length, int width);` // 计算矩形的面积

```
int x4 = area(10,-7); // OK: 但是宽度为-7的矩形面积是多少呢？
int x5 = area(10.7,9.3); // OK: 会以area(10,9)的形式调用
char x6 = area(100,9999); // OK: 但是会对结果截尾
```
