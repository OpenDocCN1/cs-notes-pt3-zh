## 负数

```
double primary()
{ Token t = ts.get();
  switch (t.kind) {
  case '(':        // handle '(' expression ')'
    { double d = expression();
      t = ts.get();
      if (t.kind != ')') error("')' expected");
      return d;
    }
  case '8':        // we use '8' to represent a number
    return t.value;  // return the number's value
  case '-':
    return - primary();
  case '+':
    return primary();
  default:
    error("primary expected");
  }
}
```

## 移除魔幻常量

- 但是，“魔幻常量”有什么错呢？
  - 每个人都知道 3.14159265358979323846264, 12, -1, 365, 24, 2.7182818284590, 299792458, 2.54, 1.61, -273.15, 6.6260693e-34, 0.5291772108e-10, 6.0221415e23 和 42!
  - 不，当然不是
- “魔幻”对身心健康不利！
  - 让你没完没了地熬夜找 bug
  - 让你走向自我否定和自我毁灭
- 如果一个“常量”可以变化(在程序维护期间)或者某人不认识它，那么就使用表征常量
  - 精度变化是经常碰到的一种变化 3.14!=3.14159265
  - 0 和 1 通常不需要解释，但是 -1 和 2 就需要了
  - 12 可能可行(一年中月份的数量),但也可能不行 (see Chapter 10).
- 如果某个常量会用到多次，那么它就应该是表征常量
  - 这样我们就只需要在一个地方修改
