## 计算机结构

- 我们看书学习的过程：
- 人 - CPU
- 书桌 - 内存
- 书架 - 硬盘
- 书与笔记 - 数据
- 书需要放到书桌上才能被人阅读 - 数据在内存中被CPU处理
- 书桌每天晚上都要清空 - 内存中的数据关机后清零
- 书需要放到书架上妥善保存 - 数据需要存储到硬盘上
- 书摆放到书架和书桌的某个位置 - 数据在硬盘和内存中都有地址

- 我们烧菜的过程:
- 人 - CPU
- 锅和案板 - 内存
- 电冰箱 - 硬盘
- 食材 - 数据
- 食材需要放到案板和锅上才能被人烹饪 - 数据在内存中被CPU处理
- 做完饭案板和锅要清洗干净 - 内存中的数据关机后清零
- 食材需要放到冰箱中妥善保存 - 数据需要存储到硬盘上
- 食材摆放到冰箱和案板的某个位置 - 数据在硬盘和内存中都有地址

## 程序设计方法：过程化程序设计方法

- 一个问题可直接由一组算法来建立模型
- Fortran、C 和 Pascal 是三种著名的过程语言，C++也支持过程化程序设计单独的过程

![](img/d2d3f908f0e1c0f8ca98d9dfbe006a9f_36_0.png)

- Example:
- 公共图书馆的资料借阅/登记（check out/check in）系统

```
void check_in();
void check_out ();
void over_due ();
void fine ();

int main(){
    check_in();
    check_out();
    over_due();
    fine();
}
```

- 程序 = 算法+抽象数据类型
- 抽象数据类型
- 数据结构+对数据的相关操作（读入、输出、打印...）
- 在对象化程序设计过程中，人们需要采用抽象数据类型描述数据结构
- 可维护性、可重用性...
- 算法是基于抽象数据类型的

- 例如：将日期作为一个抽象的数据类型
- 日期的数据类型描述
- 日期 的内在的数据组织
- 年、月、日
- 日期 的外在操作
- 设定日期
- 读取日期
- 比较日期
- 判断日期合法性
- 输出日期
- 算法1：为某项活动预定日程
- 算法2：为某项活动更改日程
