## 为什么选择C++？

- 学习编程必须选择一种编程语言
- 编程语言的目的是让我们能够用代码来表示自己的思想
- C++ 能够让我们在绝大多数应用领域表示自己的思想
- C++ 是在工程领域应用得最广的编程语言之一
  - http://www.research.att.com/~bs/applications.html

- C++ 由ISO标准准确而全面地定义
  - 而该标准几乎被一致接受
- C++ 可以在几乎所有类型的计算机上使用
- 在使用C++学习到的编程概念可以直接应用于其他语言
  - 包括C、Java、C# 和 Fortran

## 为什么编程？

- 软件是无形的
  - 软件是运行于计算机上的程序集
- 我们的文明运行于软件之上
  - 大部分工程活动都涉及软件
- 大部分程序运行在看起来不像PC的计算机上
  - PC有显示器、键盘和主机
  - 许多程序都是运行在嵌入式系统中
- 每一部计算机都需要运行程序
  - 否则就是一堆无用的昂贵的电子元件
