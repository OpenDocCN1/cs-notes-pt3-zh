# 5、B树和B+树

· B树和B+树

# 3、B树的查找代价分析：

+   • 设关键字的总数为 N，求 m 阶 B 树的最大层次 L。
+   
+   故：L=⌈log_{m/2}((N+1)/2)⌉+1
+   
+   设 N=1000，且 m=256，则 L<=3；最多3次访问外存可找到所有的记录。

# 4、B树的插入操作

+   1、确定插入位置，将结点插入到第 L 层（注意：第 L+1 层为叶子结点）
+   
+   2、找到插入位置，将关键字和其它信息按序插入。
+   
+   3、若被插入结点的关键字个数 >m-1，则该结点溢满。必须分裂成两个结点。否则不满结束。

如结点原为：

(m-1，A₀，(K₁,A₁)，(K₂,A₂)，……，(Kₘ₋₁,Aₘ₋₁))

插入一个关键字之后变为：

(m，A₀，(K₁,A₁)，(K₂,A₂)，……，(Kₘ,Aₘ))

该结点将进行分裂：

……………… (K_{m/2}，p′) ………………

p

(m/2-1，A₀，(K₁,A₁)，……，(K_{m/2-1},A_{m/2-1}))

p′

(m-m/2，A_{m/2}，……，(Kₘ,Aₘ))

生成新结点 p′，将原结点的后半部分复制过去。若分裂一直进行到根结点，树可能长高一层。
