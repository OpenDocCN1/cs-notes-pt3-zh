+   - 4. An array of size N contains number 0, 1, 2, ..., N-1 in a random order. When sorting, you are only allowed to swap number 0 with other elements. Describe your algorithm to sort the array.

```
p = find(0)
for i = 1 to N-1:
    swap a[p], a[i]
    p = find(i)
    swap a[p], a[i]
```

```
swap 0 to a[0]
sort a[1..N-1] using swap(p, q):
    swap number p with 0
    swap number q with 0
    swap number p with 0
```
