# Lock overhead

| 操作 | 开销(单位为纳秒) |
| --- | --- |
| 整数指令 | 0.7 |
| 时钟周期 | 1.4 |
| 命中二级缓存（Cache） | 12.9 |
| 原子加 1 | 58.2 |
| 比较交换 (cmpxchg) 原子加 1 | 107.3 |
| 访问主存 | 162.4 |
| CPU 本地 lock | 163.7 |
| 缓存传输 | 170.4-360.9 |

在700MHz的奔腾III机器上的基本操作的开销，在该机器上一个时钟周期能够执行两条整数指令。在1.8GHz的奔腾4机器上，原子加1指令的开销要比700MHz的奔腾III机器慢75纳秒(ns)，尽管CPU速度快两倍多。
