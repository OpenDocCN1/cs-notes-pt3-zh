# Bubble Sort

+   - Simplest sorting algorithm
+   - Idea:
+     - 1. Set flag = false
+     - 2. Traverse the array and compare pairs of two elements
+       - 1.1 If E1 ≤ E2 - OK
+       - 1.2 If E1 > E2 then Switch(E1, E2) and set flag = true
+     - 3. If flag = true goto 1.
