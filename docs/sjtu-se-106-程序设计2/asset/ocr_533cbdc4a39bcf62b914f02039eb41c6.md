# 可变序列算法

+   - 可变序列算法
+     - 可以修改它们所操作的容器对象
+     - 包括对序列进行复制、删除、替换、倒序、旋转、交换、变换、分割、去重、填充、洗牌的算法及生成一个序列的算法
+   - 例：
+     ```
+     template<class ForwardIterator, class T>
+     InputIterator find_if(ForwardIterator first,
+       ForwardIterator last, const T& x);
+     ```
+     把[first, last)区间内的元素全部改写为x
