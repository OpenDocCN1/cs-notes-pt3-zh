# What are Smart Pointers?

These automated methods apply to such things as allocation and deallocation of resources in the effort of eliminating memory leaks.

```
template <class T> class auto_ptr
{
    T* ptr;
public:
    explicit auto_ptr(T* p = 0) : ptr(p) {}
    ~auto_ptr()           {delete ptr;}
    T& operator*()        {return *ptr;}
    T* operator->()       {return ptr;}
};
```
