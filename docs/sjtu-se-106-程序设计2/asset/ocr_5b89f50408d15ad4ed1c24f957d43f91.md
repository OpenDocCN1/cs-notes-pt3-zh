# Tail recursion vs nested recursion.

+   - **Tail recursion:**
+     - Recursive call is the last step in the method.
+     - Easier to understand because don’t have to “go back” after call.

+   - **Nested recursion:**
+     - Recursive call is in the middle.
+     - Have to go back to previous call to finish it off
+     - Example: Print an “onion”: ( ( ( ( ( ( ) ) ) ) ) )

```
void onion(int layers) {
    cout<<"(";
    if (layers > 1) onion(layers-1);
    cout<<")";
}
```
