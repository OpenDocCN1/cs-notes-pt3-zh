# 容器的通用功能

+   - 容器的通用功能
+     - 用默认构造函数构造空容器
+     - 支持关系运算符：==、!=、<、<=、>、>=
+     - begin()、end(): 获得容器首、尾迭代器
+     - clear(): 将容器清空
+     - empty(): 判断容器是否为空
+     - size(): 得到容器元素个数
+     - s1.swap(s2): 将s1和s2两容器内容交换
+   - 相关数据类型（S表示容器类型）
+     - S::iterator: 指向容器元素的迭代器类型
+     - S::const_iterator: 常迭代器类型
