# 时间复杂性的分析：

+   - 时间复杂性的分析：建堆的时间耗费 + 排序的时间耗费
+   - 排序的时间耗费：

| 节点个数 | 高度 | 比较次数最多 |
|---|---|---|
| j=2 | ⌊log2⌋ + 1 | <= 2×⌊log2⌋ |
| j=3 | ⌊log3⌋ + 1 | <= 2×⌊log3⌋ |
| j=4 | ⌊log4⌋ + 1 | <= 2×⌊log4⌋ |
| ... | ... | ... |
| j=n | ⌊logn⌋ + 1 | <= 2×⌊logn⌋ |

所以： T(n) <= 2( log2 + log3 + ...... + logn ) = 2log(n!)

T(n) = O ( nlogn )
