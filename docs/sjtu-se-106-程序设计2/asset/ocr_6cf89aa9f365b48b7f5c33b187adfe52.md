# Sample class: one-dimen. points

```
class Pt {
    public:
        Pt(int xv);
        Pt(Pt* pv);
        int getX();
        virtual void move(int dx);
    protected:
        void setX(int xv);
    private:
        int x;
};

Overloaded constructor
Public read access to private data
Virtual function
```
