# 8、树的计数

# 1、互不相似的二叉树的棵数的计算

计算要点：

+   - 设二叉树的前序的序列为 1、2、3 …… n
+   - 不同的中序序列的对应着不同树形的二叉树
+   - 不同的中序序列的总数是不同树形的二叉树的总和
+   - 不同的中序序列在中序周游时和相应的进出栈序列一一对应。
+   - 不同的进出栈序列的总数是不同树形的二叉树的总和
