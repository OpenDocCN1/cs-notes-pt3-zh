# An Example of Smart Pointers

For auto_ptr, this is solved by setting its pointer to NULL when it is copied:

```
template <class T>
auto_ptr<T>& auto_ptr<T>::operator=(auto_ptr<T>& rhs)
{
    if (this != &rhs)
    {
        delete ptr;
        ptr = rhs.ptr;
        rhs.ptr = NULL;
    }
    return *this;
}
```
