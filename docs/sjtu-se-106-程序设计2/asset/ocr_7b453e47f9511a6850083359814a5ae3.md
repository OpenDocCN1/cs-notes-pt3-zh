# Convert power() to Tail-recursive

```
int power_helper(int x, int n, int result)
{
    if (n>0)
        return power_helper(x, n-1, x*result);

    return result;
}
int power(int x, int n)
{
    return power_helper(x, n, 1);
}
```

+   A non-tail recursive method can be converted to a tail-recursive method by means of an "auxiliary" parameter used to form the result.

+   The technique is usually used in conjunction with an "auxiliary" function.
