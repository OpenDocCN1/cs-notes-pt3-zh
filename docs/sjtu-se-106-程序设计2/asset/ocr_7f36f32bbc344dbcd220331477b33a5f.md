# 遍历递归算法– Too easy!

```
void BiTree::Preorder(NodeType*p)
{ if(p!=NULL)
  {  cout<<p->data<<" ";
    preorder(p->lch);
    preorder(p->rch);
  }
}
```

```
void BiTree::inorder(NodeType*p)
{if(p!=NULL)
  { inorder(p->lch);
    cout<<p->data<<" ";
    inorder(p->rch);
  }
}
```
