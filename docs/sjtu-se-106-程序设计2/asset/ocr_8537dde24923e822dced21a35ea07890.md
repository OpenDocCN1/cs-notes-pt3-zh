# Example Linear (Closed) Hashing

+   - D=8, keys a,b,c,d have hash values h(a)=3, h(b)=0, h(c)=4, h(d)=3
+     - Where do we insert d? 3 already filled
+     - Probe sequence using linear hashing:
+       - h1(d) = (h(d)+1)%8 = 4%8 = 4
+       - h2(d) = (h(d)+2)%8 = 5%8 = 5*
+       - h3(d) = (h(d)+3)%8 = 6%8 = 6
+       - etc.
+       - 7, 0, 1, 2
+     - Wraps around the beginning of the table!
