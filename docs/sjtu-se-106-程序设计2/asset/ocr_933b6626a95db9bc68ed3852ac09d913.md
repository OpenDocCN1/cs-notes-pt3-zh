# Resource Acquisition Is Initialization (RAII)

+   - Also referred to as the “Guard Idiom”
+     - However, the term “RAII” is more widely used in C++
+   - Relies on the fact that in C++ a stack object’s destructor is called when stack frame pops
+   - Idea: we can use a stack object to hold the ownership of a heap object, or any other resource that requires explicit clean up
+     - Initialize stack object when the resource is allocated
+     - De-allocate resource in the stack object’s destructor
