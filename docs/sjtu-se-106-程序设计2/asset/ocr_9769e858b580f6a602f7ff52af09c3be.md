# # IEEE 754 单精度浮点数

32位浮点数（**float类型**）

![](bbox=[0.1, 0.32, 0.85, 0.48])

| 指数 | 底数=0 | 底数≠0 | 公式 |
|---|---|---|---|
| `00_H` | ±0 | value | `(-1)^符号 × 2^{-126} × 0.尾数` |
| `01_H, ..., FE_H` | value |  | `(-1)^符号 × 2^{指数-127} × 1.尾数` |
| `FF_H` | ±infinity | NaN |  |

$(-1)^{sign}\left(1+\sum_{i=1}^{23}b_{23-i}2^{-i}\right)\times 2^{(e-127)}$
