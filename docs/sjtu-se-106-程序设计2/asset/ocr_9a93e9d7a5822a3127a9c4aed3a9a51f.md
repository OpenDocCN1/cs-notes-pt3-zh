# Repair to previous example

+   Rewrite class C to call A::f explicitly

```
class C : public A, public B {
    public:
        void virtual f() {
            A::f();  // Call A::f(), not B::f();
        }
}
```

+   Reasonable solution

+   - This eliminates ambiguity
+   - Preserves dependence on A
+     - Changes to A::f will change C::f
