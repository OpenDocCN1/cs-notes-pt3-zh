# Summary: Memory Management Tips

+   - Know what goes where in memory
+   - Understand mechanics of stack and heap allocation
+   - Watch for simple (and complex) lifetime errors
+   - Think about shallow copy vs. deep copy (problems and performance trade-offs)
+   - Master useful idioms for C++ memory management
+     - Learn how they work
+     - Understand when to apply them
+     - Look for ways to apply them in the labs and beyond
+     - C++11 smart pointers (especially shared_ptr) very helpful
