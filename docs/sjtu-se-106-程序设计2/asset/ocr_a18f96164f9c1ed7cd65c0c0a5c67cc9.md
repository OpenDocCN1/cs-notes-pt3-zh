# vtable for Multiple Inheritance

```
class A {
    public:
        int x;
        virtual void f();
};
class B {
    public:
        int y;
        virtual void g();
        virtual void f();
};
```

```
class C: public A, public B {
    public:
        int z;
        virtual void f();
};
C *pc = new C;
B *pb = pc;
A *pa = pc;
```

Three pointers to same object, but different static types.
