# Some useful standard headers

+   - `<iostream>` I/O streams, cout, cin, ...
+   - `<fstream>` file streams
+   - `<algorithm>` sort, copy, ...
+   - `<numeric>` accumulate, inner_product, ...
+   - `<functional>` function objects
+   - `<string>`
+   - `<vector>`
+   - `<map>`
+   - `<list>`
+   - `<set>`
