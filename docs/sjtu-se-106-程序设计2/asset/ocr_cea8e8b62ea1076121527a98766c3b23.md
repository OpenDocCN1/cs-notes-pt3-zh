# Closed Hashing

+   - Associated with closed hashing is a *rehash strategy*:
+     “If we try to place x in bucket h(x) and find it occupied, find alternative location h₁(x), h₂(x), etc. Try each in order, if none empty table is full,”
+   - h(x) is called *home bucket*
+   - Simplest rehash strategy is called *linear hashing*
+     hᵢ(x) = (h(x) + i) % D
+   - In general, collision resolution strategy is to generate a sequence of hash table slots (probe sequence) that can hold the record; test each slot until find empty one (probing)
