# Implementing Selection Brackets

+   - Another powerful (but easily abused) feature of C++ is the ability to redefine the standard operators so that they invoke particular methods in a class.
+   - Each operator in C++ has a corresponding identifier that typically consists of the keyword `operator` followed by the characters that make up the operator.
+   - As an example, the identifier name of the + operator typically used to indicate addition is `operator+`. By defining a method with the name `operator+`, the C++ `string` class can use this same operator to indicate concatenation.
+   - For the `Vector` class, it is convenient to provide a method definition for `operator[]`, which is the bracketing selection operator. Doing so makes it possible to use array-selection notations on `Vector` objects.
