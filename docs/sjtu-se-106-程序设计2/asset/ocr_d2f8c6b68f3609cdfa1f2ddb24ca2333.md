# Where Are We Heading?

+   - In Assignment #5, your task is to implement an interpreter for the BASIC programming language. In doing so, you will learn a little bit about how interpreters and compilers work that will almost certainly prove useful as you write your own programs.
+   - The goal for the next two courses is to give you a sense of how a compiler can make sense of an arithmetic expression like
+   
+     `y = 3 * (x + 1)`
+   - To accomplish that goal, I will talk about several ideas that initially might seem unrelated:
+     - Tree structures
+     - Class hierarchies
+     - The recursive nature of expressions
+   - Taken together, these ideas will make it possible to define data structures that represent arithmetic expressions.
