# Calls to virtual functions

+   One member function may call another

```
class A {
    public:
        virtual int f(int x);
        virtual int g(int y);
};
int A::f(int x) { ... g(i) ...;}
int A::g(int y) { ... f(j) ...;}
```

+   How does body of f call the right g?

+   If g is redefined in derived class B, then inherited f must call B::g
