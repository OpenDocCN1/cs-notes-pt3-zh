# 3、二叉树遍历

1、遍历二叉树：设 N 代表根节点，L 代表左子树，R 代表右子树。

+   a. 前序（或先序）：如果二叉树为空，则操作为空；否则访问根结点；前序遍历左子树；前序遍历右子树。记为：NLR。

+   b. 中序：如果二叉树为空，则操作为空；否则中序遍历左子树；访问根结点；中序遍历右子树。记为：LNR。

+   c. 后序：如果二叉树为空，则操作为空；否则后序遍历左子树；后序遍历右子树；访问根结点。记为：LRN。

前序： A、L、B、E、C、D、W、X
中序： B、L、E、A、C、W、X、D
后序： B、E、L、X、W、D、C、A
