# 最小化堆简介

3、赫夫曼算法的实现：首先简单介绍一下最小化堆以及最小化堆的使用。

+   - 堆的定义：n 个元素的序列 {k₁, k₂, …… , kₙ}，当且仅当满足以下关系时，称之为堆：
+     { kᵢ <= k₂ᵢ
+       kᵢ <= k₂ᵢ₊₁ } 或 { kᵢ >= k₂ᵢ
+       kᵢ >= k₂ᵢ₊₁ }
+     (i = 1,2,……, ⌊n/2⌋)
+     且分别称之为最小化堆和最大化堆。

e.g: 序列 {96,83,27,11,9} 最大化堆

{ 12, 36, 24, 85, 47, 30, 53, 91} 最小化堆
