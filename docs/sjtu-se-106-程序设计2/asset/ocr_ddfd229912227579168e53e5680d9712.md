# 4、红黑树

红黑树

新的插入法：上述插入法中可能引起子树根结点为红结点，从而向上波及，最坏情况下，波及到根结点。使得结点S不会是红结点，可避免这种情况。即排除掉的二种情况。

+   新法要点：从根结点开始，自上而下的插入法。
+   1、遇到结点X的二个孩子结点是红结点时，就将结点X着色为红色，而将它的二个孩子着色为黑色结点。
+   2、如果结点X的父结点是红色的，就会导致二个连续的红色结点。但是，即使在这种情况下，算法要进行的调整变换也仅仅是老插入法的第 3 种情况。如：下图不可能出现，X 的父结点的兄弟结点不可能为红结点。
