# Kinds of Recursion

+   - Tail recursion vs nested recursion
+     - Tail: recursive call is the last step in a method
+       ⇒ don’t have to “go back” and do more.
+     - Nested: recursive call is in the middle
+       ⇒ action … recursive call … more actions

+   - Single recursion vs multiple recursion
+     - Single: method only makes one recursive call
+     - Multiple: method makes more than one recursive call
