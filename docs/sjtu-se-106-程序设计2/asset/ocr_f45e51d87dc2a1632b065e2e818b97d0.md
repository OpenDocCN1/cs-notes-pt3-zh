# Implement Bubble Sort with an Array

```
void bubbleSort (Array S, length n) {
    boolean isSorted = false;
    while(!isSorted) {
        isSorted = true;
        for(i = 0; i<n; i++) {
            if(S[i] > S[i+1]) {
                int aux = S[i];
                S[i] = S[i+1];
                S[i+1] = aux;
                isSorted = false;
            }
        }
    }
}
```
