# String concatenation

+   Write a function that will accept two strings and combine them to create a third string, such that the third string is the shortest string containing both the input strings as sub-strings.

+   In case more than one such string is possible, print the string that contains the first string first.

Input: abcd afgd
Output: abcdafgd

Input: efgh cdef
Output: cdefgh

Input: abcd bc
Output: abcd

Input: abcdefg bcikabc
Output: bcikabcdefg
