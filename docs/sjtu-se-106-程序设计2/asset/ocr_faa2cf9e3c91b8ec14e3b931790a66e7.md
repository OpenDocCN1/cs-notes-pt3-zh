# Independent classes not subtypes

```
class Point {
    public:
        int getX();
        void move(int);
    protected:  ...
    private:    ...
};
```

```
class ColorPoint {
    public:
        int getX();
        void move(int);
        int getColor();
        void darken(int);
    protected:  ...
    private:    ...
};
```

C++ does not treat ColorPoint <: Point as written
