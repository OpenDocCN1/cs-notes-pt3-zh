
## 转换为无符号整数进行排序

![](img/af430dff16b82a0fe61ce7dee05dcf9c_803_0.png)

- 强制转换为uint32_t f
- 对于正数
  - f = f + (1 << 31)
- 对于负数
  - f = ~f

- 综上，对于任意数字f
  - f = f ^ (((int32_t)f >> 31) | (1 << 31))

## 排序后转换回浮点数

![](img/af430dff16b82a0fe61ce7dee05dcf9c_804_0.png)

- uint32_t f
- 对于负数
  - f = f - (1 << 31)
- 对于正数
  - f = ~f

- 综上，对于任意数字f
  - f = f ^ (((f >> 31) - 1) | (1 << 31))

## 分层遍历二叉树

- 维护一个队列
- 先把二叉树的根节点放入队列
- 每次从队列中取出一个节点
  - 打印该节点
  - 把它的左右儿子入队
- 重复该步骤直到队列为空

## 求相距最远的两个节点的距离

- 在以某节点N为根的子树中，相距最远的两个节点可能
  - 都在它的左子树中
  - 都在它的右子树中
  - 是左子树中最深的叶子节点和右子树中最深的叶子节点
- 用递归的方式从树的根节点开始即可

## 参考代码

```
void getMaxDist(Node* root, int& maxDepth, int& maxDist)
{
    if (root == NULL)
    {
        maxDepth = maxDist = 0;
        return;
    }
    int leftDepth, leftDist, rightDepth, rightDist;
    getMaxDist(root->left, leftDepth, leftDist);
    getMaxDist(root->right, rightDepth, rightDist);
    maxDepth = max(leftDepth, rightDepth) + 1;
    maxDist = max(max(leftDist, rightDist), leftDepth + rightDepth + 1);
}
```

## 3. Given a stack ADT, explain how can use it to implement a queue ADT.

- Use two stack instance to implement queue.
- When enque, always push to first stack.
- When deque, if the second stack is empty, pop all element from first stack and push them into the second stack. When the second stack is not empty, pop one element from second stack and return.
