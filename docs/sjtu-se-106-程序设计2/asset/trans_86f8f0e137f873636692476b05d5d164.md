

## 尾递归 vs 嵌套递归

- **尾递归：**
  - 递归调用是方法中的最后一步。
  - 更容易理解，因为调用后不需要“返回”。

- **嵌套递归：**
  - 递归调用在中间。
  - 需要返回到之前的调用以完成它
  - 示例：打印一个“洋葱”：( ( ( ( ( ( ) ) ) ) ) )

```
void onion(int layers) {
    cout<<"(";
    if (layers > 1) onion(layers-1);
    cout<<")";
}
```

## power() 是尾递归的吗？

```
int power(int x, int n)
{
    if (n>0)
        return power(x, n-1)*x;
    else
        return 1;
}
```

- 从递归调用返回时，仍有一个待处理的运算（乘法）。
  - 因此，power 不是一个尾递归函数。

## 将 power() 转换为尾递归

```
int power_helper(int x, int n, int result)
{
    if (n>0)
        return power_helper(x, n-1, x*result);

    return result;
}
int power(int x, int n)
{
    return power_helper(x, n, 1);
}
```

- 一个非尾递归方法可以通过使用一个“辅助”参数来形成结果的方式转换为尾递归方法。

- 该技术通常与“辅助”函数一起使用。

## 尾递归的优势

- 函数的激活记录只需要保留到还有计算剩余为止
  - 一旦返回值已知——激活记录就可以被丢弃
- 对于尾递归
  - 递归后不需要计算
  - 因此，原来的栈帧其实并不需要
  - 递归被调用方可以重用调用方的栈帧——节省空间

## 递归的类型

- 尾递归 vs 嵌套递归
  - 尾递归：递归调用是方法中的最后一步
    ⇒ 不需要“返回”再做更多事。
  - 嵌套递归：递归调用在中间
    ⇒ 动作 … 递归调用 … 更多动作

- 单递归 vs 多递归
  - 单递归：方法只进行一次递归调用
  - 多递归：方法进行一次以上递归调用

## 有多少只兔子？

- 兔子永不死亡
- 一只兔子可以在出生后的第三个月开始繁殖
- 兔子总是成雌雄一对出生。每个月开始时，每只成熟的雌兔都会生下一对雌雄兔。
- 所以，如果我们从 1 对新生兔子开始：
  - 第 1 个月：1 对
  - 第 2 个月：1 对
  - 第 3 个月：2 对——原始的这对生了
  - 第 4 个月：3 对——原始的这对再次生了
  - 第 5 个月：5 对——原始的这对和它的第一个后代都生了
  - 第 6 个月：8 对——第 4 个月存活的 3 对生了

## 斐波那契数

- 定义
  - Fₙ = Fₙ₋₁ + Fₙ₋₂
  - F₀ = F₁ = 1
- 我们如何递归求解？
  - 计算 fibonacci(n-1)
  - 计算 fibonacci(n-2)
  - 将两者相加
- 问题被简化为更小的问题
- 有明确的停止点

```
int fibonacci (int n) {
    int f1, f2;
    if (n <= 1) {
        return (1);
    } else {
        f1 = fibonacci(n-1);
        f2 = fibonacci(n-2);
        return (f1+f2);
    }
}
```

## 将非尾递归转换为尾递归

- 一个尾递归的斐波那契方法可以通过使用两个辅助参数来累积结果来实现。

auxiliary parameters!

```
int fib_aux ( int n , int next, int result)
{
    if (n == 0)
        return result;
    return fib_aux(n - 1, next + result, next);
}
```

要计算 fib(n)，调用 fib_aux(n,1,0)

## 将尾递归转换为迭代

```
F(x)
{
    if (P(x))
        return G(x);
    return F(H(x));
}
```

P(x) 为真时，F(x) 的值是某个其他函数 G(x) 的值。否则，F(x) 的值是函数 F 在某个其他值 H(x) 上的值

```
F(x) {
    int temp_x = x;
    while (P(x) is not true) {
        temp_x = x;
        x = H(temp_x);
    }
    return G(x);
}
```
