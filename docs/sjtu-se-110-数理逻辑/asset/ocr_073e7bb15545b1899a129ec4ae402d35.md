# Cartesian Products

+   - Ordered n-tuples
+     - (a₁,a₂,...,aₙ)
+     - (a₁,a₂,...,aₙ)=(b₁,b₂,...,bₙ) iff aᵢ=bᵢ for i=1,2,...,n
+     - Ordered pair: (a,b), (c,d)

+   - Cartesian product of sets A and B
+     - Denoted by A×B
+     - A×B = {(a,b) | a ∈ A ∧ b ∈ B} It is a Set of ordered pairs
+     - Rene Descartes
