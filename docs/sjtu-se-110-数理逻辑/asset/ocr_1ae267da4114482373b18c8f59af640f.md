# Set Identities

+   - Identity laws: A ∩ U = A, A ∪ ∅ = A
+   - Domination laws: A ∩ ∅ = ∅ , A ∪ U = U
+   - Idempotent laws: A ∩ A = A, A ∪ A = A
+   - Complementiation law: \overline{\overline{A}} = A
+   - Commutative laws: A ∪ B = B ∪ A
+   - Associative laws: (A ∪ B) ∪ C = A ∪ (B ∪ C)
+   - Distributive laws: A ∪ (B ∩ C) = (A ∪ B) ∩ (A ∪ C)
+   - De Morgen’s laws: \overline{A ∪ B} = \overline{A} ∩ \overline{B}
+   - Absorption laws: A ∪ (A ∩ B) = A
+   - Complement laws: A ∪ \overline{A} = U
