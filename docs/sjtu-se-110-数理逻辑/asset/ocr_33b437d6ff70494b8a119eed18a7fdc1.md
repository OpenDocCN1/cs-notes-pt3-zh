# Lattice

+   - Let (S, ≤) be a lattice, Define
+     - meet operation (∧): a ∧ b = glb(a,b)
+     - join operation (∨): a ∨ b = lub(a,b)
+   - for all elements x,y,z of lattice S
+     - x ∧ y = y ∧ x, x ∨ y = y ∨ x (commutative law)
+     - (x ∧ y) ∧ z = x ∧ (y ∧ z) (associative law)
+     - x ∧ (x ∨ y) = x, x ∨ (x ∧ y) = x (absorption law)
+     - x ∧ x = x, x ∨ x = x (idempotent law)
