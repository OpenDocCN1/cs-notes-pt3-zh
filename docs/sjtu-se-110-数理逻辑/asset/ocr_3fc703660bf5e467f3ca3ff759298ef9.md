# # Quantifiers

+   - We do not always have to insert specific values. We can make propositions for general values in a *domain* (or *universe of discourse*):
+   - This is called: *quantification.*

+   - **_Universal Quantification:_** P(x) is true for all values of x in the domain: ∀x P(x)

+   - **_Existential Quantification:_** There exists an element x in the domain such that P(x) is true: ∃x P(x)
