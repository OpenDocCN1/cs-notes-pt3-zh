# Cartesian Products

+   - Cartesian product of sets A₁,A₂,...,Aₙ
+     - Denoted by A₁xA₂x...xAₙ
+     - A₁xA₂x...xAₙ = {(a₁,a₂,...,aₙ) | aᵢ ∈ Aᵢ for i=1,2,...,n}

+   - Example
+     - A={1,2}, B={a,b,c}
+       AxB={(1,a), (1,b), (1,c), (2,a), (2,b), (2,c)}
+       BxA={(a,1), (b,1), (c,1), (a,2), (b,2), (c,2)}
+     - A= ∅  then AxB = ∅
