# Example2

+   - Prove
+     - “A student is this class has not read the book” and “Everyone in this class passed the quiz” imply “someone who passed the quiz has not read the book”
+   - Let
+     - C(x)=x is in this class;
+     - B(x)=x has read the book;
+     - P(x)=x passed the quiz;
+     - Premises: ∃x(C(x) ∧ ¬B(x)); ∀x(C(x)→P(x))
+     - Conclusion: ∃x(P(x) ∧ ¬B(x));
