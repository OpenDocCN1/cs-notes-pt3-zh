# Using matrices

+   - Suppose that R is a relation from A={a₁,a₂,…,aₘ} to B={b₁,b₂,…,bₙ}.
+     - the elements have been listed in an arbitrary order (if A=B, then the order is the same).
+   - use matrix M_R=[mᵢⱼ] to represent R

$$M_{ij}=\begin{cases}1\ldots\text{if }(a_i,b_j)\in R\\0\ldots\text{if }(a_i,b_j)\notin R\end{cases}$$
