# Relations on a set

+   - Relation on the set A is a relation from A to A
+   - Example
+     - A={1,2,3,4}, Give the relation R on set A
+       R={(a,b)|a divides b}
+       R={(1,1), (1,2), (1,3), (1,4), (2,2), (2,4), (3,3), (4,4)}
+     - How many relations are there on a set with n elements??
