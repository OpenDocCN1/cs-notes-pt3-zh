# Compound Propositions

+   - **Definition**
+     - New propositions formed by existing propositions and logical operators

+   - **Logical Operators**
+     - ¬ — not
+     - ∧ — and
+     - ∨ — or
+     - ⊕ — xor
+     - → — implies
+     - ↔ — biconditional
+     - *(negation/conjunction/disjunction/exclusive or/implication/biconditional implication)*
