# Boolean Function

+   - Boolean variable
+   - Boolean function of degree n
+     - From Bⁿ to B
+     - B={0,1}, Bⁿ={(x₁,x₂,...xₙ)|xᵢ ∈ B}
+   - Boolean expression
+     - Are defined recursively as
+       - 0,1, x₁,x₂,...xₙ are boolean expression
+       - If E is boolean expression, the complement of E is boolean expression
+       - If E₁,E₂ are boolean expression then E₁E₂, E₁+E₂ are boolean expression
