# Using Predictions and Quantifiers

+   - Logic programming
+     - Prolog language
+     - Facts and rules
+     - Example:
+       - instructor (john, math202)
+       - enrolled (tom, math202)
+       - enrolled (jack, math202)
+       - teacher (P,S) :- instructor (P,C), enrolled (S,C)
+       - ?enrolled (tom, math202)      yes
+       - ?enrolled (X, math202)
+       - ?teacher (X, tom)
