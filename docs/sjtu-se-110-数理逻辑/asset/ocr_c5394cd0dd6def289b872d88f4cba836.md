# Method of Proving theorems

+   - To proof the implication p → q
+     - Direct Proof: Assume p is true and use rules of inference to prove that q must be true.
+     - Indirect Proof: ¬q → ¬p ≡ p → q, proof by contraposition
+     - Vacuous Proof: to proof p is always false
+     - Trivial Proof: to proof q is always true
