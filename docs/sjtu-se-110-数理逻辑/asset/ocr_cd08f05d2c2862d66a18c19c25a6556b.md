# 前束范式

+   - ¬ ∀ xA(x) ≡ ∃ x¬A(x)
+   - ¬ ∃ xA(x) ≡ ∀ x¬A(x)
+   - A ∧ QxB(x) ≡ Qx(A ∧ B(x)), x不在A中出现
+   - A ∨ QxB(x) ≡ Qx(A ∨ B(x)), x不在A中出现
+   - ∀ xA(x) ∧ ∀ xB(x) ≡ ∀ x (A(x) ∧ B(x))
+   - ∃ xA(x) ∨ ∃ xB(x) ≡ ∃ x (A(x) ∨ B(x))
+   - Q₁xA(x) ∨ Q₂yB(y) ≡ Q₁xQ₂y(A(x) ∨ B(y))
+   - Q₁xA(x) ∧ Q₂yB(y) ≡ Q₁xQ₂y(A(x) ∧ B(y))
