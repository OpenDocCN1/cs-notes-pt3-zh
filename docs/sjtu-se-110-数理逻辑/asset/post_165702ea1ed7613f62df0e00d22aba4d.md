
## Hasse Diagrams

- Given a directed graph of a finite poset:
  - Since every vertex has a loop, we can delete them (reflexive).
  - Since many edges must be present because it is transitive, we can remove them.
  - Arrange each edge so that its initial vertex is below its terminal vertex; then we can remove the arrows.
- Finally, we get a Hasse diagram.

- **Examples**:
  - \((\mathbb{Z}, \leq)\)
  - \((\{2, 3, 6, 12, 24, 36\}, \mid)\)
  - \((\text{power set of } \{a,b\}, \subseteq)\)

## Lattice

- A poset \((S, \le)\) is called a lattice if every pair of elements has both a least upper bound and a greatest lower bound.

- **Examples**: which is a lattice?
  - \((\mathbb{Z}^+, |)\)
  - \((\{1,2,3,4,5\}, |)\)
  - \((\{1,2,4,8,16\}, |)\)
  - \((P(S), \subseteq)\), \(S\) is a set

- Let \((S, \le)\) be a lattice. Define
  - meet operation \((\land)\): \(a \land b = \mathrm{glb}(a,b)\)
  - join operation \((\lor)\): \(a \lor b = \mathrm{lub}(a,b)\)
- For all elements \(x, y, z\) of the lattice \(S\):
  - \(x \land y = y \land x\), \(x \lor y = y \lor x\) (commutative law)
  - \((x \land y) \land z = x \land (y \land z)\) (associative law)
  - \(x \land (x \lor y) = x\), \(x \lor (x \land y) = x\) (absorption law)
  - \(x \land x = x\), \(x \lor x = x\) (idempotent law)

## Lattice & Algebra Structure

- A lattice \((S, \le)\).
- \((S, \lor, \land)\) is an algebra structure derived from the lattice.
  - The \(\lor, \land\) operations have the properties of commutative laws, associative laws, absorption laws, and idempotent laws.

## Distributive Lattice

- Given a lattice \((S, \le)\), for all \(a, b, c \in S\):
  - \(a \lor (b \land c) \le (a \lor b) \land (a \lor c)\)
  - \((a \land b) \lor (a \land c) \le a \land (b \lor c)\)
- If
  - \(a \lor (b \land c) = (a \lor b) \land (a \lor c)\)
  - \((a \land b) \lor (a \land c) = a \land (b \lor c)\)
  then \((S, \le)\) is distributive.

- **Examples**: which lattice is distributive?
  - \((\mathbb{Z}^+, |)\)
  - \((P(S), \subseteq)\), \(S\) is a set
  - \((S, \subseteq)\), \(S = \{\varnothing, \{1\}, \{2\}, \{3\}, \{1,2\}, \{2,3\}, \{1,2,3\}\}\)

## Bounded Lattice

- Given a lattice \((S, \le)\).
- If there is an upper bound, denoted by \(1\), such that \(a \le 1\) for all \(a \in S\), and if there is a lower bound, denoted by \(0\), such that \(0 \le a\) for all \(a \in S\), then this lattice is bounded.
  - \(a \lor 1 = 1;\quad a \land 1 = a\)
  - \(a \lor 0 = a;\quad a \land 0 = 0\)

## Complement & Bounded Lattice

- Given a bounded lattice \((S, \le)\).
- A complement of an element \(a\) is an element \(b\) such that
  - \(a \lor b = 1;\quad a \land b = 0\)
- A lattice is complemented if every element has a complement.
