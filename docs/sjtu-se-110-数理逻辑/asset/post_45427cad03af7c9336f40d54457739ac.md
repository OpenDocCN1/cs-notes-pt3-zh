
## Resolution (rule of inference)

- Tautology: ((p ∨ q) ∧ (¬p ∨ r)) → (q ∨ r)
- Important in programming languages based on rules of logic, like Prolog
- *Clause*: disjunction of variables or their negations
- Example: prove (p ∧ q) ∨ r, r → s imply p ∨ s
  - (p ∨ r) ∧ (q ∨ r) ∧ (¬r ∨ s)

## Fallacies

- Not based on tautology
- Formal fallacies
  - fallacy of denying hypothesis
  - fallacy of affirming conclusion

## Inference for Quantified Statements

- ∀x P(x)  
  ∴ P(c) for arbitrary c  
  Universal instantiation

- P(c) for arbitrary c  
  ∴ ∀x P(x)  
  Universal generalization

- ∃x P(x)  
  ∴ P(c) for some element c  
  Existential instantiation

- P(c) for some element c  
  ∴ ∃x P(x)  
  Existential generalization

## Example 1

- Prove:
  - Everyone in this math class has taken a CS course; Marla is in this math class; Therefore Marla has taken a CS course
- Let:
  - D(x) = x is in this math class
  - C(x) = x has taken a CS class
  - Premises: ∀x (D(x)→C(x)); D(Marla)
  - Conclusion: C(Marla)
- Proof:
  1. ∀x(D(x) → C(x))    Premise
  2. D(Marla) → C(Marla)    Universal instantiation (1)
  3. D(Marla)    Premise
  4. C(Marla)    Modus ponens (2)(3)

## Example 2

- Prove:
  - “A student in this class has not read the book” and “Everyone in this class passed the quiz” imply “someone who passed the quiz has not read the book”
- Let:
  - C(x) = x is in this class;
  - B(x) = x has read the book;
  - P(x) = x passed the quiz;
  - Premises: ∃x(C(x) ∧ ¬B(x)); ∀x(C(x)→P(x))
  - Conclusion: ∃x(P(x) ∧ ¬B(x));
- Proof:
  1. ∃x(C(x) ∧ ¬B(x))    premise
  2. C(a) ∧ ¬B(a)    existential instantiation (1)
  3. ∀x(C(x)→P(x))    premise
  4. C(a)→P(a)    universal instantiation (3)
  5. C(a)    simplification from (2)
  6. P(a)    modus ponens (4)(5)
  7. ¬B(a)    simplification (2)
  8. P(a) ∧ ¬B(a)    conjunction (6)(7)
  9. ∃x(P(x) ∧ ¬B(x))    existential generalization (8)

## Method of Proving Theorems

- To prove the implication p → q:
  - **Direct Proof**: Assume p is true and use rules of inference to prove that q must be true.
  - **Indirect Proof**: ¬q → ¬p ≡ p → q, proof by contraposition
  - **Vacuous Proof**: to prove p is always false
  - **Trivial Proof**: to prove q is always true
- Proof by contradiction:
  - If ¬p → F can be proved, then p is true
- Proof by cases:
  - (p₁∨p₂∨...∨pₙ) → q ≡ (p₁→q) ∧ (p₂→q) ∧ ... ∧ (pₙ→q)
- Proof of equivalence:
  - p↔q ≡ (p→q) ∧ (q→p)
- Existence proofs:
  - Constructive
  - Non-constructive
- Uniqueness proofs:
  - Existence & Uniqueness
- Counterexamples:
  - To show ∀x P(x) is false

## Proof Strategy

- Include:
  - Forward and backward reasoning
  - Leveraging proof by cases
  - Adapting existing proofs
  - Conjecture / proof / counterexample
