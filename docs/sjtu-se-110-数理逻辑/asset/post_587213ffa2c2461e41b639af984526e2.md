$\overline{A \cap B} = \{x \mid x \notin A \cap B\}$

$\neg(x \in (A \cap B))$

$\neg(x \in A \land x \in B)$

$x \notin A \lor x \notin B$

$x \in \overline{A} \lor x \in \overline{B}$

$x \in \overline{A} \cup \overline{B}$

> De Morgan’s laws
> for logical equivalence

# Generalized Unions and intersection

- **Generalized Union**: The union of a collection of sets
  \[
  \bigcup_{i=1}^{n} A_i = A_1 \cup A_2 \cup \cdots \cup A_n
  \]

- **Generalized intersection**: The intersection of a collection of sets
  \[
  \bigcap_{i=1}^{n} A_i = A_1 \cap A_2 \cap \cdots \cap A_n
  \]

- **Example**
  - \(A_i = \{i, i+1, i+2, \ldots\}\)
  - \(\displaystyle\bigcup_{i=1}^{n} A_i = \{1,2,3,\ldots\}\)
  - \(\displaystyle\bigcap_{i=1}^{n} A_i = \{n,n+1,n+2,\ldots\}\)

# Computer representation of sets

- Store the elements of the set in an unordered fashion
  - Computing Union/intersection/difference of two sets would be time-consuming

- Store elements using an arbitrary ordering of the elements of the universal set U, for instance a₁,a₂,...,aₙ
  - Represent a subset of U with a bit string of length n (bitmap)

# Computer representation of sets

# Functions

- If f1 and f2 are two functions from A to **R** (real numbers), then g=f1+f2 and h=f1*f2 are also functions from A to **R** defined by:
  - (f1+f2)(x) = f1(x) + f2(x)
  - (f1*f2)(x) = f1(x)*f2(x)

- Example: f1(x) = x, f2(x) = x^2.
  - (f1+f2)(x) = x+x^2
  - (f1*f2)(x) = x^3.

# One-to-one function

# ▪ **One-to-one or injective function:**

- ▪ A function *f* is one-to-one if and only if *f(x)=f(y)* implies *x=y* for all *x, y* in the domain of *f*.

$\forall x\forall y(f(x)=f(y)\to x=y)$

$\forall x\forall y(x\ne y\to f(x)\ne f(y))$

equivalent since:  $(p\to q)\equiv(\neg q\to\neg p)$

Example: f:ℤ→ℤ, f(x)=x^2 one-to-one?
No! x=-1 & x=1 map both to f(1)=f(-1)=1.
