

## 否定嵌套量词

- ∀x∃y (x+y=0)
- ¬∀x∃y (x+y=0)
  ≡ ∃x ¬∃y (x+y=0)
  ≡ ∃x∀y ¬(x+y=0)
  ≡ ∃x∀y (x+y≠0)

## 量词的顺序

- 下列复合命题恒为真；左右等价。
  - ∀ x ∀ y p(x,y) ↔ ∀ y ∀ x p(x,y)
  - ∃ x ∃ y p(x,y) ↔ ∃ y ∃ x p(x,y)

## 将量化视为循环

- **提示：** 你可以将带量词的表达式视为计算机程序中执行的“循环”
  - ∃ y ∀ x p(x,y)
  - 先对 y 循环，对每一个 y 再对 x 循环；对每一个 y 的取值，检查 p(x,y) 是否对所有 x 都为真。如果找到了一个“y”，则该命题必须为真。

## 证明

### 定义

- *定理*：可以被证明的陈述
- *证明*：一系列陈述，用以证明定理为真
- *公理/公设*：证明所基于的基本假设
- *推理规则*：用于从其他断言得出结论

## 证明

- 定义
  - _引理_：用于证明其他定理的简单定理
  - _推论_：直接由你刚刚证明的定理得出的结果
  - _猜想_：真值未知的陈述

## 推理规则 (命题逻辑)

- 基础：分离规则（假言推理）
- (p ∧ (p → q)) → q 是一个重言式

![](img/596a7ad0af4b255f7c4ff59547a2dbb3_67_0.png)

That is: if the premises p and p→q are both true, then q can only be true.

## 推理规则

- **示例**
  - 今天下雪。
  - 如果今天下雪，我们就去滑雪。
  - 因此：我们去滑雪。

```
p
p → q
────
∴ q
```

## 推理规则

**附加**

p → (p ∨ q)

```
p
────
∴ p ∨ q
```

**合取**

(p) ∧ (q) → (p ∧ q)

```
p
q
────
∴ p ∧ q
```

**化简**

p ∧ q → p

```
p ∧ q
────
∴ p
```

**否定后件**

[¬q ∧ (p → q)] → ¬p

```
¬q
p → q
────
∴ ¬p
```

**假言三段论**

[(p → q) ∧ (q → r)] → (p → r)

```
p → q
q → r
────
∴ p → r
```

**析取三段论**

[(p ∨ q) ∧ ¬p] → q

```
p ∨ q
¬p
────────
∴ q
```

**归结**

[(p ∨ q) ∧ (¬p ∨ r)] → (q ∨ r)

```
p ∨ q
¬p ∨ r
────────────
∴ q ∨ r
```

## 有效论证

- 若所有前提都为真，则结论也为真的论证形式称为有效。
  - 证明 q 由假设 p₁, p₂, ..., pₙ 推出，等价于证明蕴涵式 (p₁ ∧ p₂ ∧ ... ∧ pₙ) → q 为真。

*要使一个论证为真，所有前提都必须为真；*
*需要使用若干推理规则。*

## 有效论证 (示例)

- 假设
  - 如果你爱我，那么你就会跟我走。
  - 如果你不爱我，那么你就会跟他走。
  - 如果你跟他走，那么我会哭。
- 结论
  - 如果你没有跟我走，那么我会哭。

## 有效论证 (示例)

- p: 你爱我
- q: 你会跟我走
- r: 你会跟他走
- s: 我会哭
- 假设：p→q, ¬p→r, r→s
- 结论：¬q→s

## 有效论证 (示例)

- 假设：p→q, ¬p→r, r→s
- 结论：¬q→s

| 步骤 | 陈述 | 原因 |
|---|---|---|
| 1 | p→q | 假设 |
| 2 | ¬q→¬p | 第 1 步的逆否命题 |
| 3 | ¬p→r | 假设 |
| 4 | ¬q→r | 假言三段论 (2, 3) |
| 5 | r→s | 假设 |
| 6 | ¬q→s | 假言三段论 (4, 5) |
