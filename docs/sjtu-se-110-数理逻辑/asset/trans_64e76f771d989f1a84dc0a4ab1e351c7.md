## 命题等价

- **重言式：** *总是为真的命题。* 例如：P OR (NOT P)。
- **矛盾式：** *总是为假的命题。* 例如：P AND (NOT P)。
- 其他：*或然命题。*

## 逻辑等价

- 两个命题是 *逻辑等价* 的，如果 P ↔ Q 总是为真（重言式）。
- 这表示为 P ≡ Q。
- 示例：德摩根定律

$\neg(P \lor Q) \equiv \neg P \land \neg Q$

| $P$ | $Q$ | $\neg(P \lor Q)$ | $\neg P \land \neg Q$ |
|---|---|---|---|
| T | T | F | F |
| T | F | F | F |
| F | T | F | F |
| F | F | T | T |

- 恒等律：p ∧ T ≡ p, p ∨ F ≡ p
- 支配律：p ∧ F ≡ F, p ∨ T ≡ T
- 幂等律：p ∧ p ≡ p, p ∨ p ≡ p
- 双重否定律：¬(¬p) ≡ p
- 交换律：p ∨ q ≡ q ∨ p
- 结合律：(p ∨ q) ∨ r ≡ p ∨ (q ∨ r)
- 分配律：p ∨ (q ∧ r) ≡ (p ∨ q) ∧ (p ∨ r)
- 德摩根律：¬(p ∨ q) ≡ ¬p ∧ ¬q
- 吸收律：p ∨ (p ∧ q) ≡ p
- 否定律：p ∨ ¬p ≡ T
- 仅包含 ¬、∧、∨ 的复合命题的对偶是通过将每个 ∧ 替换为 ∨，每个 ∨ 替换为 ∧，每个 T 替换为 F，每个 F 替换为 T 得到命题，记为 $p^*$。
- 如果 $p \equiv q$ 则 $p^* \equiv q^*$。
- p → q ≡ ¬p ∨ q
- p ↔ q ≡ (p → q) ∧ (q → p)
- p ∨ q ≡ ¬p → q
- p ∧ q ≡ ¬(p → ¬q)
- (p → q) ∧ (p → r) ≡ p → (q ∧ r)
- (p → r) ∨ (q → r) ≡ (p ∧ q) → r

## 谓词

- 考虑包含 *变量* 的陈述：x > 3
    - x 是主语。
    - > 3 是主语的 *谓词* 或属性。
- 我们引入一个 *命题函数* P(x) 表示 x > 3。
- 如果 x 是一个特定数字，函数就变成一个命题（T 或 F）。例如：P(2) = F, P(4) = T。
- P 被称为 *谓词*。
- 更一般地，我们可以有多个变量的“函数”。
- 对于每个输入值，它赋值为 T 或 F。
- 示例：Q(x, y) = (x = y + 3)。
    - Q(1, 2) = (1 = 2 + 3) = F
    - Q(3, 0) = (3 = 0 + 3) = T

## 量词

- 我们不总是必须插入特定值。我们可以在一个 *域*（或 *论域*）中对一般值做出命题：
- 这称为：*量化。*
- **全称量化：** P(x) 对域中 x 的所有值都为真：∀x P(x)
- **存在量化：** 域中存在一个元素 x 使得 P(x) 为真：∃x P(x)
