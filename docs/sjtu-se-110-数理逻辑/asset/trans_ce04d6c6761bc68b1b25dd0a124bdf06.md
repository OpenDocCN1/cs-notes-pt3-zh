

## 演绎推理规则

- 重言式：((p ∨ q) ∧ (¬p ∨ r)) → (q ∨ r)
- 对基于逻辑规则的编程语言很重要，如 Prolog
- *子句*：变量或其否定词的析取
- 示例：证明 (p ∧ q) ∨ r，r → s 蕴含 p ∨ s
  - (p ∨ r) ∧ (q ∨ r) ∧ (¬r ∨ s)

## 谬误

- 不基于重言式
- 形式谬误
  - 否定前件谬误
  - 肯定后件谬误

```
p → q
p
____
∴ q
正确

p → q
¬p
____
∴ ¬q
错误

p → q
q
____
∴ p
错误
```

## 量化语句的推理

- ∀x P(x)  
  ∴ P(c) 对任意 c  
  全称实例化

- P(c) 对任意 c  
  ∴ ∀x P(x)  
  全称概括

- ∃x P(x)  
  ∴ P(c) 对某个元素 c  
  存在实例化

- P(c) 对某个元素 c  
  ∴ ∃x P(x)  
  存在概括

## 示例 1

- 证明：
  - 这个数学班里的每个人都上过 CS 课程；Marla 在这个数学班里；因此 Marla 上过 CS 课程
- 设：
  - D(x) = x 在这个数学班里
  - C(x) = x 上过 CS 课程
  - 前提：∀x (D(x)→C(x))；D(Marla)
  - 结论：C(Marla)
- 证明：
  1. ∀x(D(x) → C(x))    前提
  2. D(Marla) → C(Marla)    全称实例化 (1)
  3. D(Marla)    前提
  4. C(Marla)    假言推理 (2)(3)

## 示例 2

- 证明：
  - “这个班里有一个学生没有读过这本书”并且“这个班里的每个人都通过了测验”蕴含“有一个通过测验的人没有读过这本书”
- 设：
  - C(x) = x 在这个班里；
  - B(x) = x 读过这本书；
  - P(x) = x 通过了测验；
  - 前提：∃x(C(x) ∧ ¬B(x))；∀x(C(x)→P(x))
  - 结论：∃x(P(x) ∧ ¬B(x))；
- 证明：
  1. ∃x(C(x) ∧ ¬B(x))    前提
  2. C(a) ∧ ¬B(a)    存在实例化 (1)
  3. ∀x(C(x)→P(x))    前提
  4. C(a)→P(a)    全称实例化 (3)
  5. C(a)    从 (2) 简化
  6. P(a)    假言推理 (4)(5)
  7. ¬B(a)    简化 (2)
  8. P(a) ∧ ¬B(a)    合取 (6)(7)
  9. ∃x(P(x) ∧ ¬B(x))    存在概括 (8)

## 证明定理的方法

- 要证明蕴含式 p → q：
  - **直接证明**：假设 p 为真并使用推理规则证明 q 必须为真。
  - **间接证明**：¬q → ¬p ≡ p → q，反证法
  - **空真证明**：证明 p 恒为假
  - **平凡证明**：证明 q 恒为真
- 反证法：
  - 如果能证明 ¬p → F，则 p 为真
- 分情况证明：
  - (p₁∨p₂∨...∨pₙ) → q ≡ (p₁→q) ∧ (p₂→q) ∧ ... ∧ (pₙ→q)
- 等价性证明：
  - p↔q ≡ (p→q) ∧ (q→p)
- 存在性证明：
  - 构造性
  - 非构造性
- 唯一性证明：
  - 存在性与唯一性
- 反例：
  - 用来证明 ∀x P(x) 为假
