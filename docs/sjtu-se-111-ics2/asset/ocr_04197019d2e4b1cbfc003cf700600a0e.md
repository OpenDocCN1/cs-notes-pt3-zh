# Data Dependencies: No Nop

```
# demo-h0.ys
0x000: irmovl $10,%edx
0x006: irmovl $3,%eax
0x00c: addl %edx,%eax
0x00e: halt
```

+   - Register %edx
+     - Generated by ALU during previous cycle
+     - Forward from M stage as valA
+   - Register %eax
+     - Value just generated by ALU
+     - Forward from E stage as valB
