# Decode &
Write Back Logic

+   - Control Logic
+     - srcA: read port address for valA {rA, %esp}
+     - srcB: read port address for valB {rB, %esp}
+     - dstE: write port address for valE {rB, %esp}
+     - dstM: write port address for valM {rA}
+     - Cnd: used to decide whether set valE (cmovXX)
