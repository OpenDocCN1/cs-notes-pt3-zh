# Y86 Instruction Set

| Instruction | Encoding |
|---|---|
| `jXX Dest` | `7 fn` + `Dest` |
| `call Dest` | `8 0` + `Dest` |
| `ret` | `9 0` |
| `pushl rA` | `A 0 rA F` |
| `popl rA` | `B 0 rA F` |

Byte positions: `0 1 2 3 4 5`

Jump-function encodings:

| Instruction | Code |
|---|---|
| `jmp` | `7 0` |
| `jle` | `7 1` |
| `jl` | `7 2` |
| `je` | `7 3` |
| `jne` | `7 4` |
| `jge` | `7 5` |
| `jg` | `7 6` |
