# Executing pushl

```
`pushl rA`  `a 0 rA F`
```

+   - **Fetch**
+     - Read 2 bytes
+   - **Decode**
+     - Read stack pointer and register rA
+   - **Execute**
+     - Decrement stack pointer by 4

+   - **Memory**
+     - Store valA at the address of new stack pointer
+   - **Write back**
+     - Update stack pointer
+   - **PC Update**
+     - Increment PC by 2
