# Executing `cmovXX`

![](bbox=[0.18, 0.23, 0.81, 0.35])

+   - **Fetch**
+     - Read 2 bytes
+   - **Decode**
+     - Read operand register rA
+   - **Execute**
+     - Determine whether to move

+   - **Memory**
+     - Do nothing
+   - **Write back**
+     - Update register rB if move taken
+   - **PC Update**
+     - Increment PC by 2
