# Multi-functional Units

+   - Multiple Instructions Can Execute in Parallel
+     - Nehalem CPU (Core i7)
+       - 1 load, with address computation
+       - 1 store, with address computation
+       - 2 simple integer (one may be branch)
+       - 1 complex integer (multiply/divide)
+       - 1 FP Multiply
+       - 1 FP Add
