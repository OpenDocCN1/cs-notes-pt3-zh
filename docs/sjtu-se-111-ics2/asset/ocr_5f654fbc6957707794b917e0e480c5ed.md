# Load Performance

+   - load unit can only initiate one load operation every clock cycle (Issue=1.0)

```
typedef struct ELE {
    struct ELE *next ;
    int data ;
} list_ele, *list_ptr ;

int list_len(list_ptr ls) {
    int len = 0 ;
    while (ls) {
        len++ ;
        ls = ls->next;
    }
    return len ;
}
```

```
len in %eax, ls in %rdi
.L11:
    addl $1, %eax
    movq(%rdi), %rdi
    testq %rdi, %rdi
    jne .L11
```

| Function | CPE |
|---|---|
| list_len | 4.0 |
| load latency | 4.0 |
