# (1,1) Correlating Predictor

```
if (d == 0)
    d = 1;
if (d == 1)
{ ... }

BNEZ  R1, L1      ; branch b1
DADDUI R1, R0, #1
L1: DADDUI R3, R1, #-1
BNEZ  R3, L2      ; branch b2
...
L2:
```

|  | b1 | b2 |
|---|---|---|
| 0 | NT | NT |
| 1 | T | NT |
| 2 | T | T |
