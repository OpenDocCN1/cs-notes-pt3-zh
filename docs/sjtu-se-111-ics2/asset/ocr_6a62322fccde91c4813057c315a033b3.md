# At glance of MIPS

+   - Operations

+   - Arithmetic/logical instructions R-type

```
DADDU R1, R2, R3
    Regs[R1] ← Regs[R2] + Regs[R3]
```

```
DADDIU R1, R2, #3
    Regs[R1] ← Regs[R2] + 3
```

```
DSLL R1, R2, #5
    Regs[R1] ← Regs[R2] << 5
```

```
SLT R1, R2, R3
    Regs[R1] ← (Regs[R2]<Regs[R3]) ? 1 : 0
```
