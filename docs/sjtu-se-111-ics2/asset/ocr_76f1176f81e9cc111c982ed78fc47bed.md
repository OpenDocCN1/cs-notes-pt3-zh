# Avoiding Load/Use Hazard

```
#demo-luh.ys
0x000: irmovl $128, %edx
0x006: irmovl $3, %ecx
0x00c: rmmovl %ecx, 0(%edx)
0x012: irmovl $10, %ebx
#Load %eax
0x018: mrmovl 0(%edx), %eax
#Use %eax
0x10e: addl %ebx, %eax
0x020: halt
```

+   - Stall using instruction for one cycle
+   - Can then pick up loaded value by forwarding from memory
