# Obtaining Process ID’s

```
```c
#include <unistd.h>
#include <sys/types.h>
pid_t getpid(void);
pid_t getppid(void);
```
```

returns: PID of either the caller or the parent

+   - The **getpid** and **getppid** routines return an integer value of type **pid_t**
+   - **pid_t**
+     - Defined in **types.h** as an **int** on Linux systems
