# Encoding Registers

+   - Each register has 4-bit ID
+     - Same encoding as in IA32, but IA32 using only 3-bit ID

| %eax | 0 |
| %ecx | 1 |
| %edx | 2 |
| %ebx | 3 |

| %esi | 6 |
| %edi | 7 |
| %esp | 4 |
| %ebp | 5 |

+   - Register ID "F" indicates "no register"
+     - Will use this in our hardware design in multiple places
