# Executing popl

```
popl rA
b 0 rA F
```

+   - Fetch
+     - Read 2 bytes
+   - Decode
+     - Read stack pointer
+   - Execute
+     - Increment stack pointer by 4

+   - Memory
+     - Read from old stack pointer
+   - Write back
+     - Update stack pointer
+     - Update register rA
+   - PC Update
+     - Increment PC by 2
