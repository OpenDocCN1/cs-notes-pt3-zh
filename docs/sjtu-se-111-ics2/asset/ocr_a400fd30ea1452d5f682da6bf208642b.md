# Y86 Instructions

+   - Format (P259)
+     - 1--6 bytes of info. read from memory
+       - Can determine inst. length from 1st byte
+       - Not as many inst. types, and simpler encoding than with IA32
+     - Each accesses and modifies some part(s) of the program state
