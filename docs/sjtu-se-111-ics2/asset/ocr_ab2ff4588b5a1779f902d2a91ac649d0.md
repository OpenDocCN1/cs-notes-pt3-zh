+   - B <<< N (less than)
+   - B is called blocking factor
+   - B x B submatrix of Y and a row of length B of Z can fit in cache. Thus called B x B Blocking

```
for (kk = 0; kk < N; kk+B)
    for (jj = 0; jj < N; jj+B)
        for (i = 0; i < N; i++)
            for (k = kk; k < min(kk+B-1,N); k++)
                r = X(i,k);
                for (j = jj; j < min(jj+B-1,N); j++)
                    Z(i,j) += r*Y(k,j);
```
