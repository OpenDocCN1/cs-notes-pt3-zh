# Address Translation

+   - V = {0, 1, ..., N-1} virtual address space
+   - P = {0, 1, ..., M-1} physical address space
+   - N > M
+   - Address Translation
+   - MAP: V → P ∪ {∅} address mapping function
+   - MAP(a) = a' if data at virtual address a is present at physical address a' in P
+     = ∅ if data at virtual address a is not present in P (invalid or on disk)
