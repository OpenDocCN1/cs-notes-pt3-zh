# Executing call

+   - Fetch
+     - Read 5 bytes
+     - Increment PC by 5
+   - Decode
+     - Read stack pointer
+   - Execute
+     - Decrement stack pointer by 4
+   - Memory
+     - Write incremented PC to new value of stack pointer
+   - Write back
+     - Update stack pointer
+   - PC Update
+     - Set PC to Dest
