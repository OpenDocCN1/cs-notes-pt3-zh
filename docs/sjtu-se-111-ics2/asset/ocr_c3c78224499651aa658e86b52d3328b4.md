# Simple Memory System TLB

+   - **TLB**
+     - 16 entries
+     - 4-way associative (2-bit)

+   - **Addressing**
+     - 14-bit virtual addresses
+     - 12-bit physical address
+     - Page size = 64 bits (6-bit)
