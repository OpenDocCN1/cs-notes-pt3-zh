# Instruction Execution Stages

+   - Fetch
+     - Read instruction from instruction memory
+   - Decode
+     - Read program registers
+   - Execute
+     - Compute value or address
+   - Memory
+     - Read or write data
+   - Write Back
+     - Write program registers
+   - PC
+     - Update program counter
