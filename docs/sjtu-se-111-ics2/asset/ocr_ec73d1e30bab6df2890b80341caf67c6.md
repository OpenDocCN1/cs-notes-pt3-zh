# Store Performance

+   - store unit can only initiate one store operation every clock cycle (Issue=1.0)

```
void array_clear_4(int *dest, int n)
{
    int i;
    int limit = n-3;
    for (i = 0; i < limit; i+=4) {
        dest[i] = 0;
        dest[i+1] = 0;
        dest[i+2] = 0;
        dest[i+3] = 0;
    }
    for ( ; i < n; i++)
        dest[i] = 0;
}
```
