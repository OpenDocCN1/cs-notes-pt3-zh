```c
int mem_addr = [

               ICALL, IMRMOVL } : valE;

];
```

## Memory Read

| Instruction | Memory operation | Description |
|---|---|---|
| `op1 rA, rB` | No operation |  |
| `rmmovl rA, D(rB)` | `M₄[valE] ← valA` | Write value to memory |
| `popl rA` | `valM ← M₄[valA]` | Read from stack |
| `jxx Dest` | No operation |  |
| `call Dest` | `M₄[valE] ← valP` | Write return value on stack |
| `ret` | `valM ← M₄[valA]` | Read return address |

## PC Update

| Instruction | PC update | Description |
|---|---|---|
| `op1 rA, rB` | `PC ← valP` | Update PC |
| `rmmovl rA, D(rB)` | `PC ← valP` | Update PC |
| `popl rA` | `PC ← valP` | Update PC |
| `jxx Dest` | `PC ← Cnd ? valC : valP` | Update PC |
| `call Dest` | `PC ← valC` | Set PC to destination |
| `ret` | `PC ← valM` | Set PC to return address |

## SEQ Summary

- Implementation
  - Express every instruction as a series of simple steps
  - Follow the same general flow for each instruction type
  - Assemble registers, memories, predesigned combinational blocks
  - Connect with control logic

## SEQ Summary

- Limitations
  - Too slow to be practical
  - In one cycle, must propagate through instruction memory, register file, ALU, and data memory
  - Would need to run the clock very slowly
  - Hardware units are only active for a fraction of the clock cycle

## Problem of SEQ

- Too slow
  - Too many tasks are needed to finish in one clock cycle
  - Signals need a long time to propagate through all of the stages
  - The clock must run slowly enough
- Does not make good use of hardware units
  - Every unit is active for part of the total clock cycle

## 3-Way Pipelined Version

![](img/9bd5f6161cb6607b56d2fb964d1b8794_176_0.png)

- System
  - Divide combinational logic into 3 blocks of 100 ps each
  - Can begin a new operation as soon as the previous one passes through stage A
    - Begin a new operation every 120 ps
  - Overall latency increases
    - 360 ps from start to finish

## Limitations: Nonuniform Delays

- Throughput limited by the slowest stage
- Other stages sit idle for much of the time
- Challenging to partition the system into balanced stages
