## 保持异常顺序

| W | stat | icode | valE | valM | dstE | dstM |
|---|---|---|---|---|---|---|
| M | stat | icode | Cnd | valE | valA | dstE | dstM |
| E | stat | icode | ifun | valC | valA | valB | dstE | dstM | srcA | srcB |
| D | stat | icode | ifun | rA | rB | valC | valP |
| F | predPC |

- 向流水线寄存器添加异常状态字段
- 取指阶段将其设置为“ AOK ”、“ ADR ”（当取指地址错误时）、“ HLT ”（停机指令）或“ INS ”（非法指令）
- 解码和执行阶段传递值
- 存储器阶段要么传递通过，要么设置为“ ADR ”
- 只有当指令到达写回阶段时才触发异常

## 异常处理逻辑

```c
int Stat = [
    # SBUB in earlier stages indicates bubble
    W_stat == SBUB : SAOK;
    1 : W_stat;
];
```

写回阶段

```c
# Update the status
int m_stat = [
    dmem_error : SADR;
    1 : M_stat;
];
```

存储器阶段

```c
# Determine status code for fetched instruction
int f_stat = [
    imem_error: SADR;
    !instr_valid : SINS;
    f_icode == IHALT : SHLT;
    1 : SAOK;
];
```

## 管道处理器中的副作用

```asm
# demo-exc3.ys
irmovl $100,%eax
rmmovl %eax,0x10000(%eax) # invalid address
addl %eax,%eax             # Sets condition codes
```

![](img/9bd5f6161cb6607b56d2fb964d1b8794_283_0.png)

- **期望行为**
  - `rmmovl` 应导致异常
  - 后续指令不应产生任何效果

## 避免副作用

- 异常的存在应禁用状态更新
  - 当在存储器阶段检测到异常时
    - 禁用执行阶段的条件码设置
    - 必须在同一时钟周期内发生
  - 当异常传递到写回阶段时
    - 禁用存储器阶段的内存写入
    - 禁用执行阶段的条件码（CC）设置
- 实现
  - 硬连线到 PIPE 模拟器的设计中
  - 你无法控制此项

## 避免副作用

- 异常的存在应禁用状态更新
  - 无效指令被转换为流水线气泡
    - 除 `stat` 指示异常状态的指令外
  - 数据存储器不会写入无效地址
  - 防止条件码的无效更新
    - 在存储器阶段检测异常
    - 禁用执行阶段的条件码设置
    - 必须在同一时钟周期内发生

## 避免副作用

- 异常的存在应禁用状态更新
  - 在最后阶段处理异常
    - 当在存储器阶段检测到异常时
      - 从下一周期开始向存储器阶段注入气泡
    - 当在写回阶段检测到异常时
      - 停滞异常指令
  - 包含在 HCL 代码中

## 设置条件码

```c
// Should the condition codes be updated?
bool set_cc = (E_icode == IOPL)
             // State changes only during normal operation
             && !m_stat in { SADR, SINS, SHLT }
             && !W_stat in { SADR, SINS, SHLT };
```

## 阶段控制

- 也控制内存的更新

```c
// Start injecting bubbles as soon as exception passes
// through memory stage
bool M_bubble = m_stat in { SADR, SINS, SHLT }
              || W_stat in { SADR, SINS, SHLT };

// Stall pipeline register W when exception encountered
bool W_stall = W_stat in { SADR, SINS, SHLT };
```
