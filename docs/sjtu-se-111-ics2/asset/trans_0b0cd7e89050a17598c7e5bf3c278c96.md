## 旁路路径

- 解码阶段
- 转发逻辑选择 valA 和 valB
- 通常来自寄存器文件
- 转发：从后续流水线阶段获取 valA 或 valB
- 转发源
- 执行：valE
- 记忆：valE, valM
- 写回：valE, valM

## 数据相关：无 Nop

```
# demo-h0.ys
0x000: irmovl $10,%edx
0x006: irmovl $3,%eax
0x00c: addl %edx,%eax
0x00e: halt
```

- 寄存器 %edx
- 由上一周期 ALU 生成
- 从 M 阶段转发作为 valA
- 寄存器 %eax
- 值刚由 ALU 生成
- 从 E 阶段转发作为 valB

![](img/9bd5f6161cb6607b56d2fb964d1b8794_233_0.png)

## 实现转发

```
## A 值应该是什么？
int new_E_valA = [
    # 使用递增的 PC
    D_icode in { ICALL, IJXX } : D_valP;
    # 从执行转发 valE
    d_srcA == E_dstE : e_valE;
    # 从记忆转发 valM
    d_srcA == M_dstM : m_valM;
    # 从记忆转发 valE
    d_srcA == M_dstE : M_valE;
    # 从写回转发 valM
    d_srcA == W_dstM : W_valM;
    # 从写回转发 valE
    d_srcA == W_dstE : W_valE;
    # 使用从寄存器文件读取的值
    1 : d_rvalA;
];
```

## 转发的局限性

```
#demo-luh.ys
0x000: irmovl $128, %edx
0x006: irmovl $3, %ecx
0x00c: rmmovl %ecx, 0(%edx)
0x012: irmovl $10, %ebx
#Load %eax
0x018: mrmovl 0(%edx), %eax
#Use %eax
0x10e: addl %ebx, %eax
0x020: halt
```

- Load-use 相关
- 值在第 7 周期 D 阶段结束时需要
- 值在第 8 周期 M 阶段从内存读取

| Cycle 7 | Cycle 8 |
|---|---|
| Memory | Memory |
| M_dstE=%ebx<br>M_valE=10 | M_dstM=%eax<br>m_valM <- M[128]=3 |
| : | |
| Decode | |
| valB<-M_valE=10<br>valA<-R[%eax]=0 | |

## 避免 Load/Use 冒险

```
#demo-luh.ys
0x000: irmovl $128, %edx
0x006: irmovl $3, %ecx
0x00c: rmmovl %ecx, 0(%edx)
0x012: irmovl $10, %ebx
#Load %eax
0x018: mrmovl 0(%edx), %eax
#Use %eax
0x10e: addl %ebx, %eax
0x020: halt
```

- 使用一条指令停顿一个周期
- 然后可以通过从内存转发获取加载的值
