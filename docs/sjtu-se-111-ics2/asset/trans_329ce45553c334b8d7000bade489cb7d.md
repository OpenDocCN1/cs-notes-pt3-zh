## 字多路选择器

- HCL 表示
  - 根据控制信号 s 选择输入字 A 或 B
  - HCL 表示
    - 分支表达式
    - 一系列 测试:值 对（不需要互斥）
- 第一个成功测试的输出值

```
int Out = [
  s : A;
  1 : B;
];
default case
```

## HCL 表示

```
int Min3 = [
  A < B && A < C : A;
  B < A && B < C : B;
  1               : C;
];
```

- 找出三个输入字中的最小值
- HCL 分支表达式
- 最后一个分支保证匹配

![](img/9bd5f6161cb6607b56d2fb964d1b8794_32_0.png)

## HCL 表示

```
int Out4 = [
  !s1&&!s0: D0;
  !s1      : D1;
  !s0      : D2;
  1        : D3;
];
```

- 基于两个控制位选择四个输入之一
- HCL 分支表达式
- 通过假设顺序匹配来简化测试

## 存储

- 随机访问存储器
  - 例如：寄存器文件、存储器
  - 保存多个字
    - 地址输入指定要读或写的字
  - 可能有多个读或写端口
  - 当地址输入改变时读字
  - 时钟上升时写字

## 寄存器文件

![](img/9bd5f6161cb6607b56d2fb964d1b8794_47_0.png)

- 寄存器文件
  - 保存程序寄存器的值
  - %eax、%esp 等
  - 寄存器标识符用作地址
    - 标识 "F" 表示不执行读或写
- 多端口
  - 可以在一个周期内读取和/或写入多个字
    - 每个端口都有独立的地址和数据输入/输出

## 寄存器文件时序

- 读
  - 类似组合逻辑
  - 输出数据根据输入地址生成（经过一定延迟）
- 写
  - 类似寄存器
  - 仅在时钟上升时更新
