
-   因此，主存中访问的字数为 2N^3/B + N^2。
-   B 越大，性能提升越大？
    -   选择一个合适的分块因子，使缓存完全被可复用的数据占据。
-   是的，但并不总是如此。
-   对于采用 LRU 策略的全关联缓存，这是正确的。
    -   缓存被完全使用。
-   在实践中，缓存要么是直接映射的，要么至多具有较低的组相联度。
    -   将矩阵的多行映射到同一缓存行，使得尝试充分利用缓存变得不可行。
-   此外，性能增益随矩阵大小而剧烈变化。
