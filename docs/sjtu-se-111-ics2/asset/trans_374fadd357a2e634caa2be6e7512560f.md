

## Fork 函数

- **复制但独立**的地址空间
  - 在 `fork` 函数于每个进程中返回后，每个进程的地址空间是相同的。
    - 当 `fork` 函数在第 8 行返回时，局部变量 x 在父进程和子进程中的值都为 1。

```
1 #include "csapp.h"
2 
3 int main()
4 {
5     pid_t pid;
6     int x = 1;
7 
8     pid = Fork();
9     if (pid == 0) { /* child */
10        printf("child : x=%d\n", ++x);
11        exit(0);
12    }
13 
14    /* parent */
15    printf("parent: x=%d\n", --x);
16    exit(0);
17 }
```

- **复制但独立**的地址空间。
  - 父进程和子进程是独立的进程
    - 它们各自拥有自己的**私有**地址空间。
    - 父进程或子进程之后对 x 所做的任何更改
      - 是私有的
      - 不会反映在另一个进程的内存中。

- 复制但独立的地址空间
  - 当父进程和子进程调用各自的 printf 语句时，变量 x 在两者中的值不同。
- 共享文件
  - 如 stdout
  - 子进程与父进程之间的通信

```
2

4 {
5     Fork();
6     printf("hello!\n");

```

## 僵尸进程

- 进程终止后，内核不会立即将其从系统中移除
- 该进程会以终止状态保留，直到其父进程将其回收。

- 当父进程回收已终止的子进程时
  - 内核会将子进程的退出状态传递给父进程，
  - 然后丢弃该终止进程，此时它不再存在。
- 尚未被回收的终止进程称为**僵尸进程**。

- 如果父进程
  - 在未回收其僵尸子进程的情况下终止，
  - 内核会安排 `init` 进程来回收它们。
- `init` 进程
  - PID 为 1
  - 由内核在系统初始化期间创建。

## Wait_pid 函数

```c
#include <sys/types.h>

#include <sys/wait.h>

pid_t waitpid(pid_t pid, int *status, int options);
pid_t wait(int *status);
```

返回值：成功时返回子进程的 PID，若设置了 WNOHANG 则返回 0，出错时返回 -1

```
pid_t waitpid(pid_t pid, int *status, int options);
```

- pid > 0
  - 等待集合是单个子进程
    - 其进程 ID 等于 pid
- pid = -1
  - 等待集合包含父进程的所有子进程

- waitpid 函数
  - 如果调用进程没有子进程
    - 返回 -1
    - 将 errno 设置为 ECHILD
  - 如果被信号中断
    - 返回 -1
    - 将 errno 设置为 EINTR

```
`pid_t waitpid(pid_t pid, int *status, int options);`
```

- `options = 0`
  - waitpid 会挂起调用进程的执行，直到其等待集合中的某个子进程终止
  - 如果调用时等待集合中已有进程终止，则 waitpid 立即返回
  - waitpid 返回导致 waitpid 返回的那个已终止子进程的 PID
  - 该已终止子进程会从系统中移除
