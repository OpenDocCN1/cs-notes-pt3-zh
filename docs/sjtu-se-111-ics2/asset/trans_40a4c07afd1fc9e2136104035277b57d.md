

## 编码寄存器

- 每个寄存器有 4 位 ID
  - 与 IA32 中的编码相同，但 IA32 仅使用 3 位 ID

| 寄存器 | ID |
|---|---|
| %eax | 0 |
| %ecx | 1 |
| %edx | 2 |
| %ebx | 3 |
| %esi | 6 |
| %edi | 7 |
| %esp | 4 |
| %ebp | 5 |

- 寄存器 ID “F” 表示“无寄存器”
  - 我们将在硬件设计的多个地方用到它

## 逻辑设计与 HCL

## 逻辑设计

- 数字电路
  - 什么是数字电路？
  - 了解 CPU 将基于什么？
- 硬件控制语言（HCL）
  - 一种简单且功能性的语言，用于描述我们的 CPU 实现
  - 语法类似 C

## 电路类别

- 模拟电路
  - 使用信号的全范围
  - 大部分是放大器
  - 难以建模和自动设计
  - 以晶体管和电容为基础
  - 此处不讨论

## 电路类别

- 数字电路
  - 只有两个值：0 和 1
  - 易于建模和设计
  - 使用真值表等工具进行分析
  - 以门电路为基础
  - 不同电路中的 1 电压不同
    - 例如，TTL 电路以 5 伏电压作为 1

## 数字信号

![](img/9bd5f6161cb6607b56d2fb964d1b8794_19_0.png)

- 使用电压阈值从连续信号中提取离散值
- 最简单的形式：1 位信号
  - 要么是高范围（1），要么是低范围（0）
  - 两者之间有保护范围
- 不易受噪声或低质量电路元件的影响
  - 可以使电路简单、小巧且快速

## 逻辑设计概述

- 基本硬件需求
  - 通信
    - 如何将值从一个地方传输到另一个地方
  - 计算
  - 存储（内存）
  - 时钟信号

## 逻辑设计概述

- 位是我们的朋友
  - 一切都用值 0 和 1 表示
  - 通信
    - 电线上的低或高电压
  - 计算
    - 计算布尔函数
  - 存储
  - 时钟信号

## 数字电路类别

- 组合电路
  - 无内存，因此电路不能有状态。任何相同输入在任何时候都会得到相同输出。
  - 不需要时钟信号
  - 典型应用：ALU

## 数字电路类别

- 时序电路
  - = 组合电路 + 内存和时钟信号
  - 有状态。两个相同输入可能不会产生相同输出。
  - 使用时钟信号控制电路运行。
  - 典型应用：CPU

## 位相等

![](img/9bd5f6161cb6607b56d2fb964d1b8794_26_0.png)

HCL 表达式

```
bool eq = (a&&b) || (!a&&!b)
```

- 如果 a 和 b 相等则生成 1
- 硬件控制语言（HCL）
  - 非常简单的硬件描述语言
    - 布尔运算的语法类似于 C 语言中的逻辑运算
  - 我们将用它来描述处理器的控制逻辑

## 位级多路选择器

![](img/9bd5f6161cb6607b56d2fb964d1b8794_28_0.png)

### HCL 表达式

```
bool out = (s&&a) || (!s&&b)
```

- 控制信号 s
- 数据信号 a 和 b
- 当 s=1 时输出 a，当 s=0 时输出 b
- 名称：MUX
- 用途：从多个信号中选择一个信号
