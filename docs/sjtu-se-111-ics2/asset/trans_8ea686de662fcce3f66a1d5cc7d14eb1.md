## 处理器总结
- **设计技术**
  - 为所有指令创建统一框架
    - 希望在指令之间共享硬件
  - 用控制逻辑的位连接标准逻辑块
- **操作**
  - 状态保存在存储器和时钟寄存器中
  - 计算由组合逻辑完成
  - 对寄存器/存储器的时钟控制足以控制整体行为
- **提高性能**
  - 流水线提高吞吐量并改善资源利用率
  - 必须确保保持 ISA 行为

## 性能指标
- 时钟频率
  - 以吉赫兹为单位测量
  - 是阶段划分和电路设计的功能
    - 保持每个阶段的工作量小
- 指令执行的速率
  - CPI：每条指令的周期数
  - 平均而言，每条指令需要多少个时钟周期？
  - 是流水线设计和基准程序的功能
    - 例如，分支预测错误发生的频率如何？

## CPI for PIPE (Cont.)
• LP：由于 load/use 冒险停顿造成的惩罚
– 是负载指令的指令比例  
  0.25
– 需要停顿的负载指令比例  
  0.20
– 每次注入的气泡数  
  1
⇒ LP = 0.25 × 0.20 × 1 = **0.05**
• MP：由于分支预测错误造成的惩罚
– 是条件跳转的指令比例  
  0.20
– 条件跳转预测错误的比例  
  0.40
– 每次注入的气泡数  
  2
⇒ MP = 0.20 × 0.40 × 2 = **0.16**

void combine1(vec_ptr v, data_t *dest)
{
    long int i;
    *dest = IDENT;

    for (i = 0; i < vec_length(v); i++) {
        data_t val;
        get_vec_element(v, i, &val);
        *dest = *dest OP val;
    }
}
```
```
void combine4(vec_ptr v, data_t *dest)
{
    long int i;
    long int length = vec_length(v);
    data_t *data = get_vec_start(v);
    data_t x = IDENT;

    for (i = 0; i < length; i++)
        x = x OP data[i];
    *dest = x;
}
