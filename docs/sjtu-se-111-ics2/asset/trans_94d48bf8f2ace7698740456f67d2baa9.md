## 地址转换

- V = {0, 1, ..., N-1} 虚拟地址空间
- P = {0, 1, ..., M-1} 物理地址空间
- N > M
- 地址转换
- MAP：V → P ∪ {∅} 地址映射函数
- MAP(a) = a' 表示虚拟地址 a 处的数据存在于物理地址 a'（在 P 中）
  = ∅ 表示虚拟地址 a 处的数据不存在于 P 中（无效或位于磁盘上）

## 地址转换

- 基本参数
  - N = 2^n = 虚拟地址限制
  - M = 2^m = 物理地址限制
  - P = 2^p = 页面大小（字节）。

## 地址转换

- 基本参数
  - N = 2ⁿ = 虚拟地址限制
  - M = 2ᵐ = 物理地址限制
  - P = 2ᵖ = 页面大小（字节）。
- 虚拟地址（VA）的组成部分
  - VPO：虚拟页偏移量
  - VPN：虚拟页号
- 物理地址（PA）的组成部分
  - PPO：物理页偏移量（与 VPO 相同）
  - PPN：物理页号

## 页命中

VA：虚拟地址
PTEA：页表项地址
PTE：页表项
PA：物理地址

![](img/9bd5f6161cb6607b56d2fb964d1b8794_965_0.png)

- 1. 处理器将虚拟地址发送给 MMU
- 2–3. MMU 从内存中的页表获取 PTE
- 4. MMU 将物理地址发送给缓存/内存
- 5. 缓存/内存将数据字发送给处理器
