## 上下文切换

- 上下文切换何时发生？
  - 内核代表用户执行系统调用，例如
    - `read`、`sleep` 等，这将导致调用进程被阻塞
  - 即使系统调用不阻塞，内核也可以决定执行上下文切换而不是将控制权返回给调用进程
  - 由于中断发生
    - 定时器中断

## 系统调用错误处理

- Unix 系统级函数遇到错误
  - 通常返回 -1
  - 设置全局整数变量 `errno`
    - 以指示出了什么问题

## 获取进程 ID

- **进程 ID**
  - PID
  - 每个进程都有一个唯一的正 PID
- **Getpid()**
  - 返回调用进程的 PID
- **Getppid()**
  - 返回其父进程的 PID
    - 创建调用进程的进程

## 获取进程 ID

```
```c
#include <unistd.h>
#include <sys/types.h>
pid_t getpid(void);
pid_t getppid(void);
```
```

返回：调用者或父进程的 PID

- **getpid** 和 **getppid** 例程返回类型为 **pid_t** 的整数值
- **pid_t**
  - 在 Linux 系统上定义为 **types.h** 中的 **int**

## Fork 函数

- 一个父进程
  - 通过调用 `fork` 函数
  - 创建一个新的运行中的子进程

```
```c
#include <unistd.h>
#include <sys/types.h>
pid_t fork(void);
```

返回：对子进程返回 0，对父进程返回子进程 PID，错误时返回 -1
```

## Fork 函数

- 新创建的子进程与父进程
  - **几乎**相同，但并不完全相同。
- 父进程和新创建的子进程具有不同的 PID。

## Fork 函数

- 子进程
  - 获得父进程用户级虚拟地址空间的相同但独立的副本
    - 包括文本、数据和 bss 段、堆和用户栈。
  - 还获得父进程所有打开文件描述符的相同副本
    - 这意味着子进程可以读写父进程在调用 fork 时打开的任何文件。

## Fork 函数

- 调用一次
  - 在父进程中
- 返回两次：
  - 在父进程中
    - 返回子进程的 PID
  - 在新创建的子进程中。
    - 返回 0

## Fork 函数

- 返回值提供了一种无歧义的方式
  - 判断程序是在父进程还是子进程中执行。

## Fork 函数

```
1 #include "csapp.h"
2 
3 int main()
4 {
5     pid_t pid;
6     int x = 1;
7 
8     pid = Fork();
9     if (pid == 0) { /* child */
10        printf("child : x=%d\n", ++x);
11        exit(0);
12    }
13 
14    /* parent */
15    printf("parent: x=%d\n", --x);
16    exit(0);
17 }
```

## Fork 函数

- 调用 _一次_，返回 _两次_。
  - 如前所述
  - 对于创建单个子进程的程序来说，这相当直接。
  - 包含多个 `fork` 实例的程序
    - 可能会令人困惑
    - 需要仔细推理
