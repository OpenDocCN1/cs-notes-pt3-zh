## 循环优化

Oct. 2013

## 大纲

- 为什么进行循环优化
- 常见技术
- 分块 vs. 展开
- 分块示例

## 为什么

- 循环：尤其是科学程序（如图像处理）中的主要瓶颈。
- 重复执行：稍微改进一下就能大幅提速

## 定义

- 循环优化可以被视为将一系列特定的循环变换应用于源代码或中间表示
- 合法性：程序的结果应保持不变。

## 循环展开

- 在课堂上多次提到，也称为循环解绕
- 试图消除的开销：
  - 指针运算
  - 循环结束测试

## 简单示例

| 普通循环 | 循环展开后 |
|---|---|
| ```
int x;
for (x = 0; x < 100; x++)
{
    delete(x);
}
``` | ```
int x;
for (x = 0; x < 100; x+=5)
{
    delete(x);
    delete(x+1);
    delete(x+2);
    delete(x+3);
    delete(x+4);
}
``` |

## 示例

- 现在我们以矩阵乘法为例。
- 你在上学期“缓存友好代码”讲座中遇到过它
- 这次，更具体一些。

- 两个矩阵 X * Y = Z 每个矩阵都是 N x N
- 看看最内层循环。 （另外为什么先分配寄存器？）

```
for(i = 0; i < N; i++)
    for(k = 0; k < N; k++)
        r = X(i,k); /*register allocated*/
        for(j = 0; j < N; j++)
            Z(i,j) += r*Y(k,j);
```

![](img/9bd5f6161cb6607b56d2fb964d1b8794_1143_0.png)

- 如果缓存足够大……一切都会很顺利！
  - 多亏了预取，所有 Z 和 Y 项都会被重用。
- 如果缓存容不下一个 N x N 矩阵怎么办？
  - 数据 Y 会在被重用前被替换
- 如果缓存甚至容不下 Z 中的一行怎么办？
  - 缓存中的 Z 数据无法被重用

- 最坏情况是什么？
- 在 N^3 次迭代中，需要从内存读取 2N^3 + N^2 个字的数据

```
for(i = 0; i < N; i++)
    for(k = 0; k < N; k++)
        r = X(i,k); /*register allocated*/
        for(j = 0; j < N; j++)
            Z(i,j) += r*Y(k,j);
```

- 尝试将矩阵分块成小块，这样缓存可以容纳该小块。然后循环局部性就会恢复。

## 分块代码

```c
for(i = 0; i < N; i++)
    for(k = 0; k < N; k++)
        r = X(i,k); /* register allocated */
        for(j = 0; j < N; j++)
            Z(i,j) += r*Y(k,j);
```

```c
for(kk = 0; kk < N; kk+B)
    for(jj = 0; jj < N; jj+B)
        for(i = 0; i < N; i++)
            for(k = kk; k < min(kk+B-1,N); k++)
                r = X(i,k);
                for(j = jj; j < min(jj+B-1,N); j++)
                    Z(i,j) += r*Y(k,j);
```

```cpp
for(kk = 0; kk < N; kk+=B)
    for(jj = 0; jj < N; jj+=B)
        for(i = 0; i < N; i++)
            for(k = kk; k < min(kk+B-1,N); k++)
                r = X(i,k);
                for(j = jj; j < min(jj+B-1,N); j++)
                    Z(i,j) += r*Y(k,j);
```

![](img/9bd5f6161cb6607b56d2fb964d1b8794_1148_0.png)

- B <<< N（小于）
- B 称为分块因子
- Y 的 B x B 子矩阵和 Z 的长度为 B 的一行可以放入缓存。因此称为 B x B 分块

```
for (kk = 0; kk < N; kk+B)
    for (jj = 0; jj < N; jj+B)
        for (i = 0; i < N; i++)
            for (k = kk; k < min(kk+B-1,N); k++)
                r = X(i,k);
                for (j = jj; j < min(jj+B-1,N); j++)
                    Z(i,j) += r*Y(k,j);
```
