

## Fork 函数

- 并发执行
  - 父进程和子进程是运行并发的独立进程。
  - 它们逻辑控制流中的指令可以由内核以任意方式交错。
  - 我们永远不能对不同进程中指令的交错做出假设。

## Fork 函数

- 复制但独立的地址空间

- 在每个进程中 fork 函数返回后立即，每个进程的地址空间是相同的。

- 当在第 8 行 fork 函数返回时，局部变量 x 在父进程和子进程中的值都为 1。

## Fork 函数

```
1 #include "csapp.h"
2
3 int main()
4 {
5     pid_t pid;
6     int x = 1;
7
8     pid = Fork();
9     if (pid == 0) { /* child */
10        printf("child : x=%d\n", ++x);
11        exit(0);
12    }
13
14    /* parent */
15    printf("parent: x=%d\n", --x);
16    exit(0);
17 }
```

## Fork 函数

- _复制_ 但 _独立_ 的地址空间。
  - 父进程和子进程是独立的进程
    - 它们各自拥有私有的地址空间。
    - 父进程或子进程对 x 做的任何后续更改
      - 私有的
      - 不会反映在另一个进程的内存中。

## Fork 函数

- 父进程
  - 通过调用 fork 函数
  - 创建一个新的运行中的子进程

```
#include <unistd.h>
#include <sys/types.h>
pid_t fork(void);
Returns: 0 to child, PID of child to parent, -1 on error
```

## Fork 函数

- 新创建的子进程
  - 几乎与父进程相同，但不完全相同。
- 父进程和新创建的子进程具有不同的 PID。

## Fork 函数

- 子进程
  - 获得父进程用户级虚拟地址空间的相同（但独立）副本
    - 包括文本、数据和 bss 段、堆和用户栈。
  - 还获得父进程所有打开文件描述符的相同副本
    - 这意味着子进程可以读写父进程在调用 fork 时打开的任何文件。

## Fork 函数

- 返回值提供了一种无歧义的方式
  - 判断程序是在父进程还是子进程中执行。

## Fork 函数

```
1 #include "csapp.h"
2 
3 int main()
4 {
5     pid_t pid;
6     int x = 1;
7 
8     pid = Fork();
9     if (pid == 0) { /* child */
10        printf("child : x=%d\n", ++x);
11        exit(0);
12    }
13 
14    /* parent */
15    printf("parent: x=%d\n", --x);
16    exit(0);
17 }
```

## Fork 函数

- 调用 _一次_，返回 _两次_。
  - 如前所述
  - 对于创建单个子进程的程序来说，这相当直接。
  - 具有多个 `fork` 实例的程序
    - 可能令人困惑
    - 需要仔细推理
