

# 进程

- 定义：*进程* 是正在运行的程序的一个实例。
- 进程是计算机科学中最深刻的概念之一。
- 系统中的每个程序都在某个进程的上下文中运行

# 何时创建新进程

- 每次用户运行一个程序时
  - 通过在 shell 中输入可执行对象文件的名称，
- shell 会创建一个新进程
- 然后在该新进程的上下文中运行可执行对象文件

# 何时创建新进程

- 应用程序也可以
  - 创建新进程
  - 并在
    - 其自身
    - 或其他应用程序
  - 的新进程上下文中运行

# 进程

- 进程为每个程序提供两个关键抽象：
  - 逻辑控制流
    - 让每个程序产生它独占使用 CPU 的错觉。
  - 私有地址空间
    - 让每个程序产生它独占使用主内存的错觉

# 进程

- 这种错觉是如何维持的？
  - 进程执行被交错进行（多任务处理）
  - 地址空间由虚拟内存系统管理

# 进程

- 并发
  - 多个进程可以并发运行
  - 一个进程的指令与另一个进程的指令交错进行

# 逻辑控制流

- 每个进程都有自己的逻辑控制流
  - 不会影响任何其他进程的状态
- 被抢占
- 时间片

# 并发进程

- 两个进程并发运行
  - 如果它们的时间流在时间上重叠，则为并发。
- 否则，它们是顺序的。
- 示例：
  - 并发：A & B，A&C
  - 顺序：B & C

![](img/9bd5f6161cb6607b56d2fb964d1b8794_396_0.png)

# 并发进程的用户视图

- 并发进程的控制流在物理上在时间上是分离的。
- 然而，我们可以认为并发进程彼此并行运行。
- 多任务处理或时间片

![](img/9bd5f6161cb6607b56d2fb964d1b8794_397_0.png)

# 进程的上下文

- 上下文由程序正确运行所需的全部状态组成
- 该状态包括
  - 程序的代码和数据存储在内存中
  - 它的栈
  - 它的通用寄存器的内容
  - 它的程序计数器
  - 环境变量
  - 以及打开的文件描述符集合

# 虚拟内存

- 一个抽象
  - 每个进程似乎独占使用主内存
  - 虚拟地址空间
    - 程序代码和数据（全局变量）
    - 堆
    - 共享库（标准库和数学库）
    - 栈（函数调用）
    - 内核（操作系统）
  - 硬件支持虚拟地址的转换

- 这个序列是系统的物理控制流（或控制流）。
