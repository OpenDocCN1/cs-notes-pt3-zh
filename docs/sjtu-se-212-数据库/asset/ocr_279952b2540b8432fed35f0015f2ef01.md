# Trigger

```
create trigger `timeslot_check2` after delete on time_slot
referencing old row as orow
for each row
when (orow.time_slot_id not in (
                         select time_slot_id
                         from time_slot)
     and orow.time_slot_id in (
                         select time_slot_id
                         from section))
begin
    rollback
end;
```
