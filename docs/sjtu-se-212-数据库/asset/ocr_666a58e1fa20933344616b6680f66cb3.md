# 范式分解

R = (A, B, C)
F = {A→B, B→C}

Can be decomposed in two different ways

– R1 = (A, B),    R2 = (B, C)

Lossless-join decomposition:

R1 ∩ R2 = {B} and B→BC

Dependency preserving

– R1 = (A, B),    R2 = (A, C)

Lossless-join decomposition:

R1 ∩ R2 = {A} and A→AB

Not dependency preserving
(cannot check B→C without computing R1 ⋈ R2)
