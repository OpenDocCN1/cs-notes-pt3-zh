

## DDL：数据类型
- **numeric(p,d)**
  - 定点数，用户指定精度为 p 位，小数点右侧有 d 位。
  - 例如 numeric(3,1)，44.5
- **real, double precision**
  - 浮点数和双精度浮点数，精度取决于机器。
- **float(n)**
  - 浮点数，用户指定精度至少为 n 位。

## DDL：数据类型
- **Date**
  - 日期，包含（4 位）年、月和日
  - 示例：date '2005-7-27'
- **Time**
  - 一天中的时间，以小时、分钟和秒表示。
  - 示例：time '09:00:30' time '09:00:30.75'
- **Timestamp**
  - 日期加上一天中的时间
  - 示例：timestamp '2005-7-27 09:00:30.75'

## DDL：数据类型
- **Interval**
  - 时间段
  - 示例：interval '1' day
  - 从另一个值中减去一个日期/时间/时间戳值会得到一个区间值
  - 区间值可以加到日期/时间/时间戳值上

## DML：查询，聚合
统计软件学院男女生平均年龄及人数

```sql
SELECT gende, AVG(age), COUNT(*)
FROM student
WHERE dept = 'SE'
GROUP BY dept, gende
```

## DML：查询，多集合
- 列出所有师生的编号（工号或学号）、姓名

```sql
SELECT id,name
FROM instructor
UNION ALL
SELECT id,name
FROM student
```

## DML：查询，多集合
r有m个元组，s有n个元组，则结果集中的元组数：

- `r union s`
  `m+n`
- `r intersect s`
  `min(m,n)`
- `r except s`
  `max(0,m-n)`

# 关联变量（Correlation Variables）

## 子查询
列出选过02号课程的学生姓名

```sql
SELECT  sname
FROM    student
WHERE   sno in ( SELECT  sno
                FROM    SC
                WHERE   cno = '02' )
```

## 子查询
找出年龄最大的学生

```sql
SELECT *
FROM  student
WHERE age >= ALL ( SELECT  age
                  FROM  student )
```

## 子查询
找出年龄不是最大的学生

```sql
SELECT *
FROM  student
WHERE age <= SOME (SELECT  age
FROM  student )
```

SOME = ANY

## 子查询
找出选修了SE开设的所有课程的学生

```sql
SELECT   *
FROM     student s
WHERE    not exist (SELECT cno
                    FROM   course
                    WHERE  dept = 'SE')
         except
         (SELECT cno
          FROM   SC
          WHERE  SC.sno = s.sno)
```
