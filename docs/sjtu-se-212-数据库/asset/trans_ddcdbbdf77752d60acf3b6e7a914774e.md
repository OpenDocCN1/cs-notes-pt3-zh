## FD

设 R 为关系模式
α ⊆ R 且 β ⊆ R

函数依赖 α → β 在 R 上成立当且仅当对于 R 的任意合法关系 r(R)，每当 r 的任意两个元组 t₁ 和 t₂ 在属性 α 上一致时，它们也在属性 β 上一致。

即，

t₁[α] = t₂ [α]
t₁[β] = t₂ [β]

## FD，示例

- 考虑 r ( A, B ) 具有 r 的以下实例。

- FD 本质是约束，描述属性间的约束

## 键

- K ⊆ R

- K 是关系模式 R 的超键当且仅当 K → R

- K 是 R 的候选键当且仅当
  - K → R, 且
  - 对于任意 K' ⊂ K，K' → R 不成立

## 平凡 FD

- 函数依赖如果对关系的任意实例都成立，则为 **平凡** 的

- 示例：

ID, name → ID

- 一般地，α → β 如果 β ⊆ α 则为平凡

## Armstrong 公理

- 若 β ⊆ α，则 α → β （自反律）
- 若 α → β，则 γα → γβ （增补律）
- 若 α → β，且 β → γ，则 α → γ （传递律）

- 附加规则：
  - 若 α → β 且 α → γ，则 α → βγ （合并律）
  - 若 α → βγ，则 α → β 且 α → γ （分解律）
  - 若 α → β 且 γβ → δ，则 αγ → δ （伪传递律）

## NF 的分解

- 分解的要求
  - 无损连接分解
    $R_1 \cap R_2 \rightarrow R_1$
    $R_1 \cap R_2 \rightarrow R_2$
  - 依赖保持
    $(F_1 \cup F_2 \cup \cdots \cup F_n)^+ = F^+$
  - NF 要求

## 正则覆盖

- F 的一个正则覆盖是与 F 等价的 **“最小”** 函数依赖集合，没有冗余的依赖或依赖的冗余部分
- 正则覆盖的特征
  - 左边是唯一的，右边多属性合并
  - 两边均不含无关属性(extraneous)
- 用于校验依赖保持

## 无关属性的判断

- For
- 测试属性 A 在 α → β 中是否无关
  1. 使用 F 中的依赖计算 (α - A)+
  2. 检查 (α - A)+ 是否包含 β；如果包含，则 A 在 α 中无关
- 测试属性 A 在 α → β 中是否无关
  1. 使用仅 F' = (F - {α → β}) ∪ {(α - A) → β} 中的依赖计算 β+
  2. 检查 β+ 是否包含 A；如果包含，则 A 在 β 中无关

## 正则覆盖

- R = (A, B, C)
  F = {A → BC, B → C, A → B, AB → C}
- F = {A → BC, B → C, AB → C}
- F = {A → BC, B → C}
- F = {A → B, B → C}

## 范式分解

1) 对 R，求 Key，找出违反范式要求的 FD，A → B;
2) 求 A⁺
3) R1 = {A⁺} √
   R2 = {A ∪ ( R - A⁺ )}
4) 对 R2 重复 1-3，直至均满足范式要求

- R1 ∩ R2 ⊆ R1, 无损连接
- 验证 (F₁ F₂ ... Fₙ)⁺ = F⁺
- 亦可验证 Fc

## 范式分解

R = (A, B, C)
F = {A→B, B→C}

可以分解为两种不同方式

- R1 = (A, B),    R2 = (B, C)

无损连接分解：

R1 ∩ R2 = {B} 且 B→BC

依赖保持

- R1 = (A, B),    R2 = (A, C)

无损连接分解：

R1 ∩ R2 = {A} 且 A→AB

不依赖保持
（无法在不计算 R1 ⋈ R2 的情况下检查 B→C）
