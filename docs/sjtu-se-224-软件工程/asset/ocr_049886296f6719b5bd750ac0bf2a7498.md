# 案例分析—上网助手

例：实名收到3721个邮件的邮件名，这个软件的缺点是什么？

+   • “功能” 有太多人使用，信息不全是信息，信息太多？
+   • “一键” 可能导致误操作，如用户不小心点击了“删除”按钮，所有邮件将被删除。
+   • 用户不知道界面是复杂，功能太多，难以使用。

![](bbox=[0.1, 0.47, 0.42, 0.6])

![](bbox=[0.5, 0.43, 0.9, 0.6])

+   1) 在“上网助手”页面中，导航栏不清晰，用户难以找到所需功能。
+   2) 页面布局混乱，信息过载，用户难以快速获取信息。
+   3) “下载”按钮位置不明显，用户难以找到下载入口。

![](bbox=[0.1, 0.72, 0.42, 0.85])

上网助手中的“首页”以及其他Tab页面的“功能介绍”存在，其信息布局和信息，用户难以快速找到所需信息。

![](bbox=[0.52, 0.72, 0.88, 0.85])

在 Toolbar 栏中，一般不会下拉菜单（下拉菜单的弹出会遮挡内容）。如果要下拉菜单，应该在 Toolbar 栏中设置下拉菜单的弹出位置，避免遮挡内容。
