# 增量型（Incremental）

+   - 构造一系列可执行的中間版本(Version by Version)

![](bbox=[0.15, 0.25, 0.45, 0.45])

# 增量型需考虑的风险

+   - 需求未被很好地理解
+   - 一次要求所有功能
+   - 需求迅速发生变化
+   - 事先打算采用的技术迅速发生变化
+   - 长期内仅有有限的资源（人员/资金）

# 增量型适用时机

+   - 需要早期获得功能；
+   - 中间产品可以提供使用；
+   - 系统被自然地分割成增量；
+   - 工作人员/资金可以逐步增加。

# 演化型(Evolutionary)

+   - 表现：
+     需求常常在软件开发过程中发生改变，想要一次迭代开发交付的最终产品是不可能的
+   - 解决办法：演化模型
+     解决办法的原则是使软件可以分若干次交付一个完整的软件产品
+   - 特点：
+     软件的开发方法，渐进式开发可多次迭代。逐步完善软件产品，每个版本都开发、开发过程中活动和任务都集中或与重量平衡进行开发
+     与增量模型的区别是：需要在开发早期不能确定了所有的需求在开发的每个阶段又开发被重新了，潜在每个增量的版本中都确定
