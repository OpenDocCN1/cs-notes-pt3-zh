# 过程设计

+   目的
+   - 确定模块采用的算法和模块数据结构
+   任务：编写软件的“过程设计说明书”
+   - 为每个模块确定采用的算法
+   - 确定每个模块使用的数据结构
+   - 确定模块接口的细节

# 过程设计原则

+   - 清楚第一的设计风格
+   - 结构化的控制结构
+   - 逐步细化的实现方法

# 过程设计工具

+   - 流程图（Flow Diagram）
+   - N-S图
+   - PAD图（Problem Analysis Diagram）
+   - PDL语言
