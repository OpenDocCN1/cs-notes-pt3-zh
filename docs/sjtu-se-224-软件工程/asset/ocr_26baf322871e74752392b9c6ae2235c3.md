# 挑战

+   - 尺寸小
+     - 同时无法展示丰富的内容，界面应简单，只显示重要的内容，操作步骤简单
+     - 根据用户的行为特点和位置信息，智能地显示或推荐用户喜欢的信息
+     - 尽可能减少不必要的文本输入
+   - 移动设备种类多，界面尺寸不同
+     - 要求界面具有自适应性
+   - 用户的层次、爱好和习惯众多
+     - 易用性要求更高
+     - 支持个性化定制，提供个性化服务
