# 根据用户的特点设计人机界面

+   - 用户分类：
+     - 外行型：不熟悉计算机操作，对系统很少或毫无认识
+     - 初学型：对计算机有一些经验，对新系统不熟悉，需要相当多的支持
+     - 熟练型：对系统有丰富的使用经验，能熟练操作，但不了解系统的内部结构，不能纠正意外错误
+     - 不够充实系统的能力
+     - 专家型：了解系统内部的结构，有系统工作机制的专门知识，具有维护和修改系统的能力，希望为他们提供具备修改和扩充系统能力的复杂界面
