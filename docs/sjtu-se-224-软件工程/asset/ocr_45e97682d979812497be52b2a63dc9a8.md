# Use Case间的关系

+   - Include 包含
+   - Extend 扩展
+   - Generalization 泛化

# 什么是Include 关系？

+   - 基本用例包含某个包含用例
+   - 包含用例定义的行为将显式插入基本用例

# Include 关系示例

Get Quote Use Case
1. Include "Identify Customer" to verify customer's identity
2. Display options. Customer selects "Get Quote"
3. ...

Identify Customer Use Case
1. Log on
2. Validate logon
3. Enter password
4. Verify password
A1: Not valid logon
A2: Wrong password
A3: ...

# 执行Include

+   - 到达插入点时执行包含用例

# 什么是Extend关系？

+   - 从基本用例到扩展用例的联接
+   - 将扩展用例的行为插入基本用例
+   - 只有当扩展条件为真时才进行插入
+   - 在一个命令的扩展点插入基本用例
