# 白盒测试

+   - 白盒测试把被测软件看作一个透明的白盒子，测试人员可以完全了解软件的设计或代码，按照软件内部逻辑进行测试。
+   - 白盒测试又称玻璃盒测试。

# 1）语句覆盖法

+   - 使得程序中的每一个语句至少被遍历一次
+   - 举例：对下列子程序进行测试

```
procedure example(y,z:real;var x:real);
begin
    if (y>1) and (z=0) then x:=x/y;
    if (y=2) or (x>1) then x:=x+1;
end;
```
