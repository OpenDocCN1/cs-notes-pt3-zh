# 当前软件实践的问题

+   - 软件直到测试阶段仅仅是忽略质量的现代技术。典型地说，软件工程师
+     - 没有计划他们的工作
+     - 匆匆地走过需求和设计
+     - 在编码时再进行设计
+   - 这些实践引入了大量的缺陷
+     - 有经验的工程师每7-10行代码就引入一个缺陷
+     - 平均中等规模的系统存在着上千个缺陷
+     - 这些缺陷的大多数会累积到发现
+     - 通常需要花去一倍以上的开发时间
+   - 目前大多数的工作方式还像30年前一样——“code-fix”

# 软件事故

+   - 1981年，由计算机程序变更而导致1/67的时间停运，使航天飞机STS-5的计算机不能同步运行。这个错误导致了航天飞机发射失败。
+   - 1986年，1台Therac25机器错误致命剂量的辐射，致使两名医院病人死亡。原因是一个软件出现了问题，导致设备机器错误。
+   - 化学银行一个晚上从10多万撤离客户上，错误地扣除了大约1500万美元的存款。原因是一个软件的闰使ATM的每一笔业务重复记两次。
+   - 小事故：计算机一个月停机几次，不得不随时进行数据备份；定期重装机器；病毒四溢。

# 中国的软件产业现状

+   - 软件作坊 vs. 软件工厂

+   - 规模小，大多数在50人以下
+   - 生产率低
