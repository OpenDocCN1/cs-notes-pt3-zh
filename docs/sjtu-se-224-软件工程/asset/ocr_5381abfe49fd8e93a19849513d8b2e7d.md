# 软件的定义

**软件是**

- 能够完成预定功能和性能的可执行的指令（计算机程序）；
- 使得程序能够适当地操作信息的数据结构；
- 描述程序的操作和使用的文档。

现在，被普遍接受的软件的定义是：

软件（software）是计算机系统中与硬件（hardware）相互依存的另一部分，它包括程序（program）、相关数据（data）及说明文档（document）。

# 软件特征

+   - 软件开发不同于硬件设计
+     - 与硬件设计相比，软件更依赖于开发人员的业务素养、智力，以及人的组织、合作和管理。同时软硬件同样有设计成本，但软件在产品成本中的一小部分，而软件开发占整个产品成本的大部分。
+   - 软件生产不同于硬件制造
+     - 硬件设计完成后就投入批量制造，制造也是一个复杂的过程，其间可能犯下质量问题；而软件成为产品之后，其制造只是简单的拷贝而已，软件的制造和运输也非常简单。
+   - 软件维护不同于硬件维修
+     - 软件在运行的初期有较高的故障率，在错误修正后的一段时间中，故障率会降到一个较低且稳定的水平。随着时间的迁移，故障率将再次升高，这是因为硬件不会受到摩损等因素，而软件是发生在程序逻辑中，软件是能够不断的更换和升级的，但不会损耗使用过之后软件的缺陷可能会变得比以前更严重。如果软件内部的逻辑关系比较复杂，在维护过程中还可能产生新的错误。
