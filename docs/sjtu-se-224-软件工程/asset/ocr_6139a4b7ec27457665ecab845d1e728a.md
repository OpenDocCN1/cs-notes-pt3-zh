# 分析模型

对需求进行分析，并进行图形建模，形成分析模型（平台无关模型 PIM）。

+   ◆ 结构化分析模型
+     - 数据流图（DFD）
+     - 控制流图（CFD）
+     - 数据字典（DD）
+     - 实体—关系图（ERD）
+     - 状态变迁图（STD）
+     - 加工说明（PSPEC）
+     - 控制说明（CSPEC）
+   
+   ◆ 面向对象分析模型
+     - 用例图
+     - 活动图
+     - 类图
+     - 时序图
+     - 通信图
+     - 状态机图
