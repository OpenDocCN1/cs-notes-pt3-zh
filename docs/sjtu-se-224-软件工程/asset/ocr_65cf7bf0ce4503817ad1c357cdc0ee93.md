# Definitions: States

+   - A state is the condition of an object at a moment between events
+   - Kinds of States

| State Kind | Description | Notation |
|---|---|---|
| **simple state** | A state with no substructure | `S` |
| **orthogonal state** | A state that is divided into two or more regions. One direct substate from each region is concurrently active when the composite state is active. | Orthogonal state diagram |
| **nonorthogonal state** | A composite state that contains one or more direct substates, exactly one of which is active at one time when the composite state is active | Nonorthogonal state diagram |
