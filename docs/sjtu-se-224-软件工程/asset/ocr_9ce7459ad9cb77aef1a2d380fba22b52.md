# 安装测试

+   - 安装测试（installation testing）用以确认该软件在各种支持的平台下、各种允许的安装情况下，都能成功安装。
+   - 首次安装、升级、完整的或自定义的安装等
+   - 除了安装软件，通常还需要安装用户文档以及初始化数据，这些同样需要进行检查。

# 回归测试（regression testing）

+   - 为了保证软件返工时没有引入新的错误，要全部或部分地重复以前做过的测试。
+   - 在集成测试、缺陷纠正后的重新测试、迭代开发的后继代码测试中常常回到回归测试。
+   - 回归测试可以手工执行，也可以使使用自动化的回归测试工具（又称功能测试工具）。回归测试工具使软件工程师能够监测测试工具、然后进行测试，然后进行回归比较。
+   - 影响测试或重新执行所有已进行的测试，或对受到影响的软件部分进行局部回归测试。仅针对修改的软件部分进行重新测试常常不够的。

# 测试过程

测试计划 测试条件、资源、进度
测试设计 设计测试用例（确定主功能测试）
测试开发（设计脚本、根据模型构造环境）
测试执行 构建测试环境、运行被测对象、执行测试
测试评估 对测试结果进行总结和评估
• 测试计划、测试设计和测试开发必须在软件开发完成前进行
• 测试执行需要软件开发完成才能进行
