# 系统工程 (System Engineering)

+   - 在软件开发之前，必须了解该软件所外的外部“系统”
+   - 计算系统包括计算机硬件、软件、人员、数据库、文档、规程等系统元素。
+   - 系统工程的任务：
+     - 系统建模 —— 系统模型
+     - 系统仿真
+   - 系统工程的表现形式
+     - 信息系统、关社企业、业务流程图——业务模型
+     - 联合式系统、关注产品、产品结构——产品模型
+     - 多媒体系统、关注内容、内容工程——脚本

# 需求 (Requirement)

+   - 目的：澄清用户的需求。
+   - 描述：软件人员和用户沟通，充分理解和获取用户的需求，并进行分析，形成《软件需求规格》文档和分析模型。
+   - 任务：
+     - 需求获取
+     - 需求分析和建模
+     - 需求定义
+     - 需求确认
+     - 需求管理

# 设计 (Design)

+   - 目的：建立软件的设计蓝图，是需求到代码的桥梁。
+   - 任务：软件人员依据软件需求，进行设计，形成《软件架构》文档和设计模型。
+   - 内容
+     - 架构设计
+     - 详细设计

重点在How

# 编码 (Coding)

+   - 任务:依据设计说明书为每个模块编写程序
+   - 交付程序
+     - 程序内部含有必要的注释
+     - 不含有语法错误
+   - 交付这样的程序就是编码阶段完成的里程碑
