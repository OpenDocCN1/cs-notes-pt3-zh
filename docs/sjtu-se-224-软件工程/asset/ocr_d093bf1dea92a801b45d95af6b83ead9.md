# GOTO语句是有害的

+   - 尽可能避免使用GOTO语句。
+   - 使用语言中的顺序、选择、重复等有限的基本控制结构表示程序逻辑。

例：打印A, B, C三数中最小者排序

![](bbox=[0.15, 0.325, 0.42, 0.47])

# 程序1

```
if (A < B) goto 120;
if (B < C) goto 110;
100 write (C);
goto 140;
110 write (B);
goto 140;
120 if (A < C) goto 130;
goto 100;
130 write (A);
140 end
```

# 程序2

```
if (A < B) and (A < C) then
    write (A)
else
    if (A ≥ B) and (B < C) then
        write (B)
    else
        write (C)
    endif
endif
```

# 源程序的文档化（code documentation）

+   - 有意义的变量名称
+   - 适当的注释
+   - 标准的书写格式

+   - 用分层缩进的写法显示嵌套结构的层次；
+   - 在注释段与程序段、以及不同程序段之间插入空行；
+   - 每一行只写一条语句；
+   - 字符表达式时，适当用空格或圆括号等隔离符号；

好的源程序本身就是详细设计文档！
