# Add Activities and Actions

# Activities

+   - Associated with a state
+   - Start when the state is enter
+   - Take time to complete
+   - Interruptible

# Actions

+   - Associated with a transition
+   - Take an insignificant amount of time to complete
+   - Non-interruptible
