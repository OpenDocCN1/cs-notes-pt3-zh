# 面向对象方法

+   - 九十年代以来的主流开发方法
+   - 符合人类对客观世界的认知规律
+   - 开发的系统结构易于理解、易于维护
+   - 继承机制有良好支持软件复用
+   - 常见的面向对象方法
+     - Booch method 1984
+     - Coad and Yourdon method 1991
+     - Rumbaugh method -- OMT 1991
+     - Jacobson method -- OOSE 1992
+     - Wirfs-Brock method 1990
+     - ……
+   - 国际标准统一建模语言 UML 1997
