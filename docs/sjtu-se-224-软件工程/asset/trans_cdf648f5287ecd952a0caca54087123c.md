

## 定义方法

- 什么是方法？
  - 描述 **操作实现**
- 目的
  - 定义操作实现中的特殊方面
- 需要考虑的事项：
  - 特殊的 **算法**
  - 要使用的其他对象和操作
  - 属性和参数如何实现和使用
  - 关系如何实现和使用

- 转换描述了对事件接收的响应会发生什么

## 添加活动和动作

### Activities

- 与状态相关联
- 在进入状态时开始
- 需要时间完成
- 可中断

### Actions

- 与转换相关联
- 完成所需时间可忽略不计
- 不可中断

## 哪些对象具有显著的状态？

- 其角色通过状态转换得以明确的对象
- 复杂的使用案例，其为 **状态控制**
- 并 **不是** 需要建模所有对象
  - 与实现有直接映射的对象
  - 不是状态控制的对象
  - 只有 **一个** 计算状态的对象

## 状态图如何映射到模型的其余部分？

- 事件可能映射到操作
- 方法应使用特定状态的信息进行更新
- 状态通常使用属性表示
  - 这作为输入到“定义属性”步骤

## 属性：你如何找到它们？

- 检查方法描述
- 检查状态
- 类本身需要维护的任何信息

## 属性表示

- 指定名称、类型和可选的默认值
  - **attributeName : Type = Default**
- 遵循实现语言和项目的命名约定
- 类型应为实现语言中的基本数据类型
  - 内置数据类型、用户定义数据类型或用户定义类
- 指定可见性
  - 公共：‘+’
  - 私有：‘-’
  - 受保护：‘#’

## 派生属性

- 什么是派生属性？
  - 其值可基于其他属性的值计算得出的属性
- 何时使用它们？
  - 当每次需要时重新计算值的时间不足时
  - 在运行时性能与所需内存之间进行权衡
