# 2.3 Relations

+   - **Definition:**
+   Given two sets A and B, a relation R is a subset of the Cartesian product A × B.

# A relation R ⊆ A × A is

Reflexive: iff for all a ∈ A, <a, a> ∈ R

Symmetric : iff <a, b> ∈ R ⇒ <b, a> ∈ R

Antisymmetric: <a, b>, <b, a> ∈ R ⇒ a = b

Transitive: iff <a, b>, <b, c> ∈ R ⇒ <a, c> ∈ R:
