# Limitations of Boundary Value Analysis

+   - Boundary value analysis works well when the program to be tested is a function of several independent variables that represent bounded physical quantities.
+   - Why?
+   1. the variables need to be described by a true ordering relation.
+   2. value analysis presumes the variables to be truly independent.
+   3. no consideration of the nature of the function, nor of the semantic meaning of the variables.
