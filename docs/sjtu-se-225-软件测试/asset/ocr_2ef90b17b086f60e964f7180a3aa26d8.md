# Paths and Semipaths

(directed) path: a sequence of edges such that, for any adjacent pair of edges ei, ej in the sequence, the terminal node of the first edge is the initial node of the second edge.

Cycle: a directed path that begins and ends at the same node.

Chain: a sequence of nodes such that each interior node has indegree = 1 and outdegree = 1.

(directed) semipath: a sequence of edges such that for at least one adjacent pair of edges ei, ej in the sequence, the initial node of the first edge is the initial node of the second edge or the terminal node of the first edge is the terminal node of the second edge.

# For example:

A path from n1 to n6; A semipath between n1 and n3;

A semipath between n2 and n4; A semipath between n5 and n6
