# 2.2 Functions

+   Definition

Given sets A and B, a function f is a subset of A × B such that for

a_i, a_j ∈ A,  b_i, b_j ∈ B, and f(a_i)=b_i, f(a_j)=b_j,

If b_i ≠ b_j ⇒ a_i ≠ a_j

or f: A→B
f ⊆ A×B

+   Function Types

f is a function from A onto B iff f(A) = B (上函数)

f is a function from A into B iff f(A) ⊂ B (note the proper subset here! 中函数)
