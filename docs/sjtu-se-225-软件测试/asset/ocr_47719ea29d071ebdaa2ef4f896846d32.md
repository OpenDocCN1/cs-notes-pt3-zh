# 2.4 Propositional Logic

+   - **Definition:**
+     A proposition is a sentence that is either true or false.
+     For example: 6>2、 Earth is a star;
+     but: water is cold, The mountain is very high, are not propositions.

+   - **Logical Operators**
+     and : ∧
+     or : ∨
+     not : ¬
+     exclusive-or : ⊕
+     IF-THEN: →
