# 5 independent paths:

+   P1: A, B, C, G;
+   P2: A, B, C, B, C, G;
+   P3: A, B, E, F, G;
+   P4: A, D, E, F, G;
+   P5: A, D, F, G。

Any path could be a combination of 5 independent paths.

Example : A、B、C、B、E、F、G = P2+P3-P1

其中，加法是一条路径后接一条路径；乘法是路径的重复，而减法则只有数学上去除边的含义，而缺少实际意义。

=A, B, C, B, C, G+ A, B, E, F, G- A, B, C, G ;
AB+BC+CB+BC+CG+AB+BE+EF+FG-AB-BC-CG
= A、B、C、B、E、F、G
