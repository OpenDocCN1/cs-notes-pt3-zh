JDK共有3个版本，分别为：

+   - SE(Jave SE), standard edition, 标准版
+   - EE(Jave EE), enterprise edition, 企业版
+   - ME(Jave ME), micro edition, 主要用于移动设备、嵌入式设备上的java应用程序

目前JDK的最新版本为： Java SE Development Kit 8u51。
