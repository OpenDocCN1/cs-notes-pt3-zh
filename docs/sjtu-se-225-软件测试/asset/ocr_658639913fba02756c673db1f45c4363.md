+   3. Node n ∈ G(P) is a usage node of the variable v ∈ V, written as USE(v, n), if and only if the value of the variable v is used as the statement fragment corresponding to node n.
+   4. A usage node USE(v, n) is a predicate use (denoted as P-use) if and only if the statement n is a predicate statement; otherwise, USE(v, n) is a computation use (denoted C-use).
+   5. A definition/use path with respect to a variable v (denoted du-path) is a path in PATHS(P) such that, for some v ∈ V, there are define and usage nodes DEF(v, m) and USE(v, n) such that m and n are the initial and final nodes of the path.
