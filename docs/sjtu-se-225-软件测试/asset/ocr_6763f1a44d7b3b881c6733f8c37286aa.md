# 6.3.3 ISO27001

# 什么是ISO27001

信息安全管理标准

它来源于英国标准协会（British Standards Institute, BSI）于1995年2月制定的信息安全管理标准--BS7799, BS7799分两个 分,

+   - BS7799-1, 信息安全管理实施规则
+   - BS7799-2, 信息安全管理体系规范。

其第一 分于2000年被ISO组织 纳, 正式成为ISO/IEC 17799标准。该标准2005年经 最新改版, 发展成为 ISO/IEC 17799:2005标准。

BS7799标准的第二 分经 时 讨论修订, 也于2005年成为正式的ISO标准, 即ISO/IEC 27001:2005。
