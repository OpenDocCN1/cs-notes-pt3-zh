# Adjacency Matrices:

The adjacency matrix of a graph G = (V, E) with m nodes is an m × m matrix, where the element in row i, column j is a 1 if and only if an edge exists between node i and node j; otherwise, the element is 0.

| | n1 | n2 | n3 | n4 | n5 | n6 |
|---|---|---|---|---|---|---|
| n1 | 0 | 1 | 0 | 1 | 0 | 0 |
| n2 | 1 | 0 | 0 | 0 | 0 | 1 |
| n3 | 0 | 0 | 0 | 1 | 0 | 0 |
| n4 | 1 | 0 | 1 | 0 | 1 | 0 |
| n5 | 0 | 0 | 0 | 1 | 0 | 0 |
| n6 | 0 | 1 | 0 | 0 | 0 | 0 |
