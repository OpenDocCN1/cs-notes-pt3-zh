# 1.3测试范围

本次系统测试将 用开发相关测试 件和利用成熟的测试工具相结合的 方式，现场对系统 行测试。按照系统 求任务书的要求，分别 行系统的功能测试、性能测试、故 测试以及安全性测试等相关内 容。

本次测试的主要目标包括：

+   系统 件单元功能测试——根据 件详细设计文档的要求，完成各个 件模块的单元功能测试工作；
+   系统 件  成功能测试——根据 件 求规格说明的要求，完成 件功 能测试工作；
+   系统 件性能测试——根据技术协议书和 件 求规格说明的要求，完 成 件性能测试工作；
+   系统故 测试——对 件系统在网络故 、数据库故 等异常情况下 行测试工作；
+   安全性测试——对系统用户登 、密码保护等安全管理 行测试工作。
