# 2.1 Set Theory

+   - **Set Definition**
+     A={elements list}; B={elements list};
+     a ∈ A,  b ∉ B;
+   - **Set Operations:**
+     A ∩ B = {x: x ∈ A ∧ x ∈ B};
+     A ∪ B = {x: x ∈ A ∨ x ∈ B}.
+     A' = {x: x ∉ A};
+     A−B={x∈A∧x ∉ B};
+     A ⊕ B=(A∪B)−(A∩B);
+     A × B={<x, y>:x∈A∧y∈B}
