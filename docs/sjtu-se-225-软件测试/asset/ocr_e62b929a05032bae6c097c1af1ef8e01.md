# Define/Use Test Coverage Metrics

+   All-Defs criterion: for the program P if and only if for every variable v ∈ V, T contains definition-clear paths from every defining node of v to a use of v.

+   All-Uses criterion: for the program P if and only if for every variable v ∈ V, T contains definition-clear paths from some defining node of v to every use of v, and to the successor node of each USE(v, n).

+   All-P-Uses/Some C-Uses criterion: for the program P if and only if for every variable v ∈ V, T contains definition-clear paths from every defining node of v to every predicate use of v; and if a definition of v has no P-uses, a definition-clear path leads to at least one computation use.

+   All-C-Uses/Some P-Uses criterion: for the program P if and only if for every variable v ∈ V, T contains definition clear paths from every defining node of v to every computation use of v; and if a definition of v has no C-uses, a definition-clear path leads to at least one predicate use.
