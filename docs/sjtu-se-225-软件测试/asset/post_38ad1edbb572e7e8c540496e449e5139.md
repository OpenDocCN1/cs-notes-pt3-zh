### 2.1 Set Theory

- **Set Definition**
  - A = {elements list}; B = {elements list};
  - a ∈ A, b ∉ B;
- **Set Operations**
  - A ∩ B = {x: x ∈ A ∧ x ∈ B};
  - A ∪ B = {x: x ∈ A ∨ x ∈ B};
  - A′ = {x: x ∉ A};
  - A − B = {x: x ∈ A ∧ x ∉ B};
  - A ⊕ B = (A ∪ B) − (A ∩ B);
  - A × B = {<x, y>: x ∈ A ∧ y ∈ B}

### 2.2 Functions

**Definition**

Given sets A and B, a function f is a subset of A × B such that for a_i, a_j ∈ A, b_i, b_j ∈ B, and f(a_i) = b_i, f(a_j) = b_j,

if b_i ≠ b_j ⇒ a_i ≠ a_j

or f: A → B, f ⊆ A × B.

**Function Types**

- f is a function from A onto B iff f(A) = B (上函数)
- f is a function from A into B iff f(A) ⊂ B (note the proper subset here! 中函数)
- f is a one-to-one function from A to B iff, for all a_i, a_j ∈ A, a_i ≠ a_j ⇒ f(a_i) ≠ f(a_j)
- f is a many-to-one function from A to B iff, there exists a_i, a_j ∈ A, a_i ≠ a_j such that f(a_i) = f(a_j)
