
## Equivalence Class Test Cases for the NextDate Function

## NextDate

Three variables: month, day, and year. Valid values are defined as follows:

- M1（月）= 1~12
- D1（日）= 1~31
- Y1（年）= 1812~2012

The invalid equivalence classes are:

- M2 = {month: month < 1}, M3 = {month: month > 12}
- D2 = {day: day < 1}, D3 = {day: day > 31}
- Y2 = {year: year < 1812}, Y3 = {year: year > 2012}

Strong robust equivalence class testing needs to consider the Cartesian product of all the equivalence classes. No more explanation here.

Further analysis: months include long months (31 days), short months (30 days), and February (28 days); end-of-month days include 29, 30, and 31; and the year may be a leap year or a common year.

M1 = {month has 30 days}, M2 = {month has 31 days}

M3 = {month is February}

D1 = {1 ≤ day ≤ 28}, D2 = {day = 29}, D3 = {day = 30}, D4 = {day = 31}

Y1 = {year = 2000}, Y2 = {year is a non-century leap year}, Y3 = {year is a common year}
