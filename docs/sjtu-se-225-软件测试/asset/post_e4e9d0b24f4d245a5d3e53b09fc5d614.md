
## 2.3 Relations

- **Definition:**
Given two sets A and B, a relation R is a subset of the Cartesian product A × B.

A relation R ⊆ A × A is

Reflexive: iff for all a ∈ A, <a, a> ∈ R

Symmetric : iff <a, b> ∈ R ⇒ <b, a> ∈ R

Antisymmetric: <a, b>, <b, a> ∈ R ⇒ a = b

Transitive: iff <a, b>, <b, c> ∈ R ⇒ <a, c> ∈ R:

A relation R ⊆ A × A is an ordering relation if R is reflexive, antisymmetric, and transitive.
For example: ≥

A relation R ⊆ A × A is an equivalence relation if R is reflexive, symmetric, and transitive.
For example:
(classmates, roommates)

## 2.5 Probability Theory

### Definition

The probability that a proposition p is true, denoted Pr(p), is

|T(p)|/|U|.

T(p), is the set of all elements in the universe U for which p is true.

## Paths and Semipaths

(directed) path: a sequence of edges such that, for any adjacent pair of edges ei, ej in the sequence, the terminal node of the first edge is the initial node of the second edge.

Cycle: a directed path that begins and ends at the same node.

Chain: a sequence of nodes such that each interior node has indegree = 1 and outdegree = 1.

(directed) semipath: a sequence of edges such that for at least one adjacent pair of edges ei, ej in the sequence, the initial node of the first edge is the initial node of the second edge or the terminal node of the first edge is the terminal node of the second edge.

For example:

A path from n1 to n6; A semipath between n1 and n3;

A semipath between n2 and n4; A semipath between n5 and n6

## n-Connectedness

0-connected: iff no path exists between ni and nj.

1-connected: iff a semipath but no path exists between ni and nj.

2-connected: iff a path exists between ni and nj.

3-connected: iff a path goes from ni to nj and a path goes from nj to ni.
