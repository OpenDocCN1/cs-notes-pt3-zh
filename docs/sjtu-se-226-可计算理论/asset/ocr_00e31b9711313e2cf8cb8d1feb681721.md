# Effective Denumerable Set

A number x ∈ ℕ has a unique expression as

x = Σ_{i=0}^{∞} α_i 2^i

where α_i is either 0 or 1 for all i ≥ 0.

+   1. The function α(i, x) = α_i is primitive recursive:
+   
+   α(i, x) = rm(2, qt(2^i, x)).

+   2. The function ℓ(x) = if x > 0 then k else 0 is primitive recursive:
+   
+   ℓ(x) = Σ_{i < x} α(i, x).
