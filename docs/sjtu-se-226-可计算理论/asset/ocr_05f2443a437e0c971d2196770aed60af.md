# Effectiveness of Set Operation

# Proposition

There is a total computable function s(x, y) such that W_{s(x,y)} = W_x ∪ W_y.

# Proof

Let

f(x, y, z) = { 1, if z ∈ W_x or z ∈ W_y, undefined, otherwise. }

By S-m-n Theorem there is a total function s(x, y) such that φ_{s(x,y)}(z) ≃ f(x, y, z). Clearly W_{s(x,y)} = W_x ∪ W_y.
