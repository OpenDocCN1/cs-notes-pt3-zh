# Proof in Detail

The function σₙ can be defined as follows:

σₙ(e, x̃, 0) = π(2¹ 3¹ 2 ... pₙ^{aₙ}, 1),
σₙ(e, x̃, t + 1) = π(config(e, σₙ(e, x̃, t)), next(e, σₙ(e, x̃, t)),)

where config(e, π(c, j)) is the new configuration, and next(e, π(c, j)) is the number of the next instruction, after the j-th instruction has been executed upon c.
