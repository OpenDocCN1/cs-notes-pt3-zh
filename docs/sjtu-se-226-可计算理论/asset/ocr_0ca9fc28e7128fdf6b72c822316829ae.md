# Recursion

Suppose that $f(\vec{x})$ is an $n$-ary function and $g(\vec{x}, y, z)$ is an $(n+2)$-ary function.

The recursion function $h(\vec{x}, y)$ is defined by

$h(\vec{x}, 0) \;=\; f(\vec{x}), \quad (1)$
$h(\vec{x}, y + 1) \;=\; g(\vec{x}, y, h(\vec{x}, y)). \quad (2)$

Clearly there is a unique function that satisfies (1) and (2).
