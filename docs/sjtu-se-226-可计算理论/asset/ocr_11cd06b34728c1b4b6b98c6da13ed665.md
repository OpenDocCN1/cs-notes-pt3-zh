# Problem III

Consider the function $g$ defined as follows:

$$g(n)=\begin{cases}1, & \text{if there is a run of exactly } n \text{ consecutive 7's in the decimal expansion of } \pi,\\0, & \text{otherwise.}\end{cases}$$

It is known that $\pi$ can be calculated by $4\left(1-\frac{1}{3}+\frac{1}{5}-\frac{1}{7}+\cdots\right)$. Is $g$ computable?

We do not know whether it is computable or not.
