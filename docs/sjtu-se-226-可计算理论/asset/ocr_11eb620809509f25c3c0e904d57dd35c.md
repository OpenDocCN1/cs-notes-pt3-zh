# An Example

Q = {q_r, q_h, q_1, q_2, q_3}, Γ = {0, 1, □, ▷}.

and δ is as follows:

| p ∈ Q | σ ∈ Γ | δ(p, σ) |
|---|---|---|
| q_r | 0 | (q_r, 0, →) |
| q_r | 1 | (q_r, 1, →) |
| q_r | □ | (q_1, □, ←) |
| q_r | ▷ | (q_1, ▷, →) |
| q_1 | 0 | (q_2, □, →) |
| q_1 | 1 | (q_3, □, →) |
| q_1 | □ | (q_1, □, →) |
| q_1 | ▷ | (q_h, ▷, →) |
| q_2 | 0 | (q_r, 0, ←) |
| q_2 | 1 | (q_r, 0, ←) |
| q_2 | □ | (q_r, 0, ←) |
| q_2 | ▷ | (q_h, ▷, →) |
| q_3 | 0 | (q_r, 1, ←) |
| q_3 | 1 | (q_r, 1, ←) |
| q_3 | □ | (q_r, 1, ←) |
| q_3 | ▷ | (q_h, ▷, →) |

Start the machine with input 010

+   - q_r, □010
+   - q_r, b010
