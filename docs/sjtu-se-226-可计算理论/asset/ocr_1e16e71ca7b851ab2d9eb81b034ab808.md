# Creative Set

Theorem. Suppose that $\mathcal{A} \subseteq \mathcal{C}$ and let $A = \{x \mid \phi_x \in \mathcal{A}\}$. If $A$ is r.e. and $A \neq \emptyset, \mathbb{N}$, then $A$ is creative.

Proof. Suppose $A$ is r.e. and $A \neq \emptyset, \mathbb{N}$. If $f_0 \in \mathcal{A}$, then $A$ is productive by a previous theorem. This is a contradiction.

So $\overline{A}$ is productive by the same theorem. Hence $A$ is creative.
