# S-m-n Theorem

Proof

Given $e, x_1, \ldots, x_m$, we can effectively construct the following program and its index

```
$$\begin{aligned}
T(n,m+n)\\
\vdots\\
T(1,m+1)\\
Q(1,x_1)\\
\vdots\\
Q(m,x_m)\\
P_e
\end{aligned}$$
```

where $Q(i,x_i)$ is the program $Z(i), S(i), \ldots, S(i)$

$\hspace{5.5em}\text{m times}$

The injectivity is achieved by padding enough useless instructions.
