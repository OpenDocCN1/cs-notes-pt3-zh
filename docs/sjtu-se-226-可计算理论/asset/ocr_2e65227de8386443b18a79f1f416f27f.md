# Primitive Recursive Predicate

Suppose $M(x_1, ..., x_n)$ is an $n$-ary predicate of natural numbers. The characteristic function $c_M(\hat{x})$, where $\hat{x} = x_1, ..., x_n$, is

$c_M(a_1, ..., a_n) = \begin{cases} 1, & \text{if } M(a_1, ..., a_n) \text{ holds}, \\ 0, & \text{if otherwise.} \end{cases}$

The predicate $M(\hat{x})$ is primitive recursive if $c_M$ is primitive recursive.
