# Ackermann is not Primitive Recursive

# Lemma 6.

Let f(\vec{x}) be a k-ary primitive recursive function. Then there exists some J such that for all n1, ..., nk we have that

f(n1, ..., nk) < ω(J, Σ_{i=1}^k n_i).

Proof. The proof is by structural induction.

+   (i) f is one of the initial functions. In this case take J to be 1.
