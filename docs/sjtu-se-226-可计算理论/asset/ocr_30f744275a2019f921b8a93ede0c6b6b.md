# Undecidability Result

# Theorem

The problem ‘φₑ = 0’ is undecidable.

# Proof

Consider the function f defined by

f(x, y) = { 0, if x ∈ Wₑ,
undefined, if x ∉ Wₑ. }

By s-m-n theorem there is some total computable function k(x) such that φₖ₍ₓ₎(y) ≃ f(x, y).

It is clear that φₖ₍ₓ₎ = 0 iff x ∈ Wₑ.
