# Enumeration Theorem

For each $n$, the universal function $\varphi_{e}^{(n)}$ is computable.

# Proof

Given a number $e$, decode the number to get the program $P_e$, and then simulate the program $P_e$. If the simulation ever terminates, then return the number in $R_1$. By Church-Turing Thesis, $\varphi_{e}^{(n)}$ is computable.
