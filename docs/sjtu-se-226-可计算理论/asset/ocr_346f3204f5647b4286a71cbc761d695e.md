# Proof in Detail

ln(e) = the number of instructions in Pₑ;

gn(e,j) = { the code of Iⱼ in Pₑ, if 1 ≤ j ≤ ln(e); 0, otherwise. }

ch(c,z) = the resulting configuration when the configuration c is operated on by the instruction with code number z.

v(c,j,z) = { the number j' of the next instruction when the configuration c is operated on by the jth instruction with code z if j > 0, 0, if j = 0. }
