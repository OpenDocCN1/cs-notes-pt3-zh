# Primitive Recursive Predicate

Suppose $M(x_1,\dots,x_n)$ is an $n$-ary predicate of natural numbers. The characteristic function $c_M(\vec{x})$, where $\vec{x}=x_1,\dots,x_n$, is

$c_M(a_1,\dots,a_n)=\begin{cases}1,&\text{if }M(a_1,\dots,a_n)\text{ holds},\\0,&\text{if otherwise.}\end{cases}$

The predicate $M(\vec{x})$ is primitive recursive if $c_M$ is primitive recursive.
