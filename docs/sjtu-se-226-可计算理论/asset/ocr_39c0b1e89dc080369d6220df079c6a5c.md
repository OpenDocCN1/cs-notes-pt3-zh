# Effective Denumerable Set

Fact. ⋃_{k≥0} ℕ^k is effectively denumerable.

Proof. A bijection τ : ⋃_{k>0} ℕ^k → ℕ is defined by

```
τ(a₁, …, aₖ) ≜ 2^{a₁} + 2^{a₁+a₂+1} + 2^{a₁+a₂+a₃+2} + … + 2^{a₁+…+a_{k-1}+k-1} − 1.
```

Now given x it is easy to find b₁ < b₂ < … < b_ℓ such that

```
2^{b₁} + 2^{b₂} + 2^{b₃} + … + 2^{b_ℓ} = x + 1.
```

It is then clear how to calculate a₁, a₂, a₃, …, aₖ. Details are next.
