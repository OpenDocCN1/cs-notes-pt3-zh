# Ackermann is not Primitive Recursive

(iii) Suppose $f$ is defined by the recursion:

$f(\tilde{x},0) \simeq h(\tilde{x}),$
$f(\tilde{x},y+1) \simeq g(\tilde{x},y,f(\tilde{x},y)).$

Then $h(\tilde{n}) < \psi(J_h, \sum \tilde{n})$ and $g(\tilde{n},m,p) < \psi(J_g, \sum \tilde{n} + m + p).$

It is easy to prove

$f(n_1,\ldots,n_k,m) < \psi\left(J_s,\sum_{i=1}^{k} n_k + m\right)$

by induction on $m$.
