# Proof of Rice-Shapiro Theorem

(⇐): Suppose f is a computable function and there is a finite θ ∈ A such that θ ⊆ f and f ∉ A.

Define the computable function g(z, t) by

g(z, t) ≃ { f(t), if t ∈ Dom(θ) ∨ z ∈ K, ↑, otherwise. }

According to the S-m-n Theorem, there is an injective primitive recursive function s(z) such that g(z, t) ≈ φ_{s(z)}(t).

z ∈ K ⇒ φ_{s(z)} = f ⇒ s(z) ∉ A;

z ∉ K ⇒ φ_{s(z)} = θ ⇒ s(z) ∈ A;
