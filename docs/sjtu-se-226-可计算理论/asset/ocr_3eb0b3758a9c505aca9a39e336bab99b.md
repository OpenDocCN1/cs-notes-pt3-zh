# Proof in Detail

If the computation of $P_e(\tilde{x})$ stops, it does so in $\mu t\{j_n(e,\tilde{x},t)=0\}$ steps.

Then the final configuration is $c_n(e,\tilde{x},\mu t\{j_n(e,\tilde{x},t)=0\})$.

We conclude that the value of the computation $P_e(\tilde{x})$ is $(c_n(e,\tilde{x},\mu t\{j_n(e,\tilde{x},t)=0\}))_1$.
