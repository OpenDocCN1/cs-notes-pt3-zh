# URM-Computable Function

Suppose *P* is the program of a URM and $a_1, ..., a_n, b \in \mathbb{N}$.

The computation $P(a_1, ..., a_n)$ converges to $b$ if $P(a_1, ..., a_n) \downarrow$ and $r_1 = b$ in the final configuration.

In this case we write $P(a_1, ..., a_n) \downarrow b$.

*P* URM-computes *f* iff, for all $a_1, ..., a_n, b \in \mathbb{N}$, $P(a_1, ..., a_n) \downarrow b$ iff $f(a_1, ..., a_n) = b$.

The function *f* is URM-definable if there is a program that URM-computes *f*.
