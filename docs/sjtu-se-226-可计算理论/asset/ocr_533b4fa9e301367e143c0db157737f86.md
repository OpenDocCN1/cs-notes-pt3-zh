# Some Notation

Suppose P is the program of a URM and a₁, a₂, a₃, ... are the numbers stored in the registers.

+   - P(a₁, a₂, ..., aₘ) is P(a₁, a₂, ..., aₘ, 0, 0, ...).
+   - P(a₁, a₂, a₃, ...) is the initial configuration.
+   - P(a₁, a₂, a₃, ...) ↓ means that the computation converges.
+   - P(a₁, a₂, a₃, ...) ↑ means that the computation diverges.
