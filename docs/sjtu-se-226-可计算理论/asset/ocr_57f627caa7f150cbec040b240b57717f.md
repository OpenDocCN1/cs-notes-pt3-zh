# Turing Machine

The machine is described by a tuple (Γ, Q, δ) containing

+   - A finite set Γ, called alphabet, of symbols. It contains a blank symbol □, a start symbol ▷, and the digits 0 and 1.

+   - A finite set Q of states. It contains a start state q_s and a halting state q_h.

+   - A transition function δ : Q × Γ^k → Q × Γ^{k-1} × {←, -, →}^k, describing the rules of each computation step.
