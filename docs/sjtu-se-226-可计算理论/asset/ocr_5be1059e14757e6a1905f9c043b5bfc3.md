# Undecidability Result

# Corollary

There is a computable function $h$ such that both `$x \in Dom(h)$` and `$x \in Ran(h)$` are undecidable.

# Proof

Let

$h(x) = \begin{cases} x, & \text{if } x \in W_x, \\ \text{undefined}, & \text{if } x \notin W_x. \end{cases}$

Clearly $x \in Dom(h)$ iff $x \in W_x$ iff $x \in Ran(h)$.
