# An Example

Q = {q_s, q_h, q1, q2, q3}, Γ = {0, 1, □, ▷}.

and δ is as follows:

| p ∈ Q | σ ∈ Γ | δ(p, σ) |
|---|---|---|
| q_s | 0 | (q_r, 0, →) |
| q_s | 1 | (q_r, 1, →) |
| q_s | □ | (q1, □, ←) |
| q_s | ▷ | (q_s, ▷, →) |
| q1 | 0 | (q2, □, →) |
| q1 | 1 | (q3, □, →) |
| q1 | □ | (q1, □, →) |
| q1 | ▷ | (q_h, ▷, →) |
| q2 | 0 | (q_r, 0, ←) |
| q2 | 1 | (q_r, 0, ←) |
| q2 | □ | (q_h, 0, ←) |
| q2 | ▷ | (q_h, ▷, →) |
| q3 | 0 | (q_r, 1, ←) |
| q3 | 1 | (q_r, 1, ←) |
| q3 | □ | (q_r, 1, ←) |
| q3 | ▷ | (q_h, ▷, →) |

Start the machine with input 010
