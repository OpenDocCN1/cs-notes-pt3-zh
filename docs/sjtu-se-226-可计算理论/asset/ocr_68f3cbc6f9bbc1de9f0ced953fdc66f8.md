# Closure Property

The following statements are valid:

+   - If R(\hat{x}) is decidable, then so is ¬R(\hat{x}).
+   - If R(\hat{x}), S(\hat{x}) are (partially) decidable, then the following predicates are (partially) decidable:
+     - R(\hat{x}) ∧ S(\hat{x});
+     - R(\hat{x}) ∨ S(\hat{x}).
+   - If R(\hat{x}, y) is (partially) decidable, then the following predicates are (partially) decidable:
+     - ∀z < y, R(\hat{x}, y);
+     - ∃z < y, R(\hat{x}, y).
