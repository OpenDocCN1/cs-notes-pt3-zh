3. If x > 0 then it has a unique expression as

x = 2^{b_k} + 2^{b_{k-1}} + ... + 2^{b_1},

where 1 ≤ k and 0 ≤ b_1 < b_2 < ... < b_k.

The function b(i,x) = if (x > 0) ∧ (1 ≤ i ≤ ℓ(x)) then b_i else 0 is primitive recursive:

b(i,x) = { μy ≤ x (∑_{k ≤ y} α(k,x) = i), if (x > 0) ∧ (1 ≤ i ≤ ℓ(x)); 0, otherwise. }
