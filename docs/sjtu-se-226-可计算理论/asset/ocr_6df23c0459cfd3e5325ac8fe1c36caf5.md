# Proof in Detail

If the computation of $P_c(X)$ stops, it does so in

$$\mu t(J_n(e,\tilde{x},t)=0)$$

steps.

Then the final configuration is

$$c_n(e,\tilde{x},\mu t(J_n(e,\tilde{x},t)=0)).$$

We conclude that the value of the computation $P_c(X)$ is

$$\{c_n(e,\tilde{x},\mu t(J_n(e,\tilde{x},t)=0))\}.$$
