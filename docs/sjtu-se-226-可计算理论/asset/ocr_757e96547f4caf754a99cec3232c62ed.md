# Applications of the Rice-Shapiro Theorem

Both Tot and Tot̅ are not r.e.

Tot = { x | φₓ is total }

# Proof

We apply the Rice-Shapiro theorem on Tot. For no f ∈ Tot is there a finite θ ⊆ f with θ ∈ Tot.

If f is any total computable function, f ∉ Tot̅, but every finite function on θ ⊆ f in Tot̅.
