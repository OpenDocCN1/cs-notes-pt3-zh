# The Most Hard Recursively Enumerable Set

Fact. If A ≤ₘ B and B is r.e. then A is r.e..

Theorem. A is r.e. iff A ≤₁ K.

Proof. Suppose A is r.e. Let f(x, y) be defined by

```
f(x, y) = { 1, if x ∈ A, ↑, if x ∉ A }
```

By S-m-n Theorem there is an injective primitive recursive function s(x) s.t. f(x, y) = φ_{s(x)}(y). It is clear that x ∈ A iff s(x) ∈ K

Comment. No r.e. set is more difficult than K.
