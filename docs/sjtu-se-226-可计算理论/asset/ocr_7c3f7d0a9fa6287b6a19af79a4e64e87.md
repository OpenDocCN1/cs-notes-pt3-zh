# What Rice-Shapiro Theorem Can Do

Can we apply Rice-Shapiro Theorem to show that any of the following sets is non-r.e.:

+   - *Fin* = { x | W_x is finite }
+   - *Inf* = { x | W_x is infinite }
+   - *Tot* = { x | φ_x is total }
+   - *Con* = { x | φ_x is total and constant }
+   - *Cof* = { x | W_x is cofinite }
+   - *Rec* = { x | W_x is recursive }
+   - *Ext* = { x | φ_x is extensible to a total recursive function }
