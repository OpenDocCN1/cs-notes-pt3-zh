# Problem III

Consider the function g defined as follows:

g(n) = { 1, if there is a run of exactly n consecutive 7's in the decimal expansion of π, 0, otherwise. }

It is known that π can be calculated by 4(1 − 1/3 + 1/5 − 1/7 + …).

Is g computable?

We do not know whether it is computable or not.
