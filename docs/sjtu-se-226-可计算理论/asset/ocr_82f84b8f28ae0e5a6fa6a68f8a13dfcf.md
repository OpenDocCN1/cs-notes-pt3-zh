# More Arithmetic Functions

The following functions are primitive recursive.

+   1. D(x) = the number of divisors of x:
+   2. Pr(x) = { 1, if x is prime, 0, if x is not prime. }
+   3. pₓ = the x-th prime number;
+   4. (x)ᵧ = { k, k is the exponent of p_y in the prime factorisation of x, for x, y > 0, 0, if x = 0 or y = 0. }
