# Ackermann Function is Recursive

A finite set $S$ of triples is said to be suitable if the followings hold:

+   (i) if $(0,y,z)\in S$ then $z=y+1$;  
+   (ii) if $(x+1,0,z)\in S$ then $(x,1,z)\in S$;  
+   (iii) if $(x+1,y+1,z)\in S$ then $\exists u.((x+1,y,u)\in S\land(x,u,z)\in S)$.

A triple $(x,y,z)$ can be coded up by $2^x3^y5^z$.

A set $\{u_1,\ldots,u_k\}$ can be coded up by $p_{u_1}\cdots p_{u_k}$.

Let $R(x,y,z)$ be “$z$ is a legal code and $\exists i\,\forall(x,y,z)\in S$”.

The Ackermann function $\psi(x,y)=\mu z\{(x,y,z)\in S\land\mu_R(x,y,z)\}$.
