# Dummy Parameter

**Proposition**

Suppose that $f(y_1,\ldots,y_k)$ is a primitive recursive and that $x_{i_1},\ldots,x_{i_k}$ is a sequence of variables from $x_1,\ldots,x_n$ (possibly with repetition).
Then the function $h$ given by

$$h(x_1,\ldots,x_n)=f(x_{i_1},\ldots,x_{i_k})$$

is primitive recursive.

**Proof**

$h(\vec{x})=f(U_{i_1}^{n}(\vec{x}),\ldots,U_{i_k}^{n}(\vec{x}))$.
