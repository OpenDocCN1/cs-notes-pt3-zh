# An Example

Q = {q₀, qₕ, q₁, q₂, q₃}. Γ = {0, 1, □, ▷}.

and δ is as follows:

| p ∈ Q | σ ∈ Γ | δ(p, σ) |
|---|---|---|
| q₀ | 0 | (q₁, 0, →) |
| q₀ | 1 | (q₁, 1, →) |
| q₀ | □ | (q₁, □, ←) |
| q₀ | ▷ | (qₕ, ▷, →) |
| q₁ | 0 | (q₂, □, →) |
| q₁ | 1 | (q₁, □, →) |
| q₁ | □ | (q₁, □, →) |
| q₁ | ▷ | (qₕ, ▷, →) |
| q₂ | 0 | (q₁, 0, ←) |
| q₂ | 1 | (q₁, 0, ←) |
| q₂ | □ | (q₁, 0, ←) |
| q₂ | ▷ | (qₕ, ▷, →) |
| q₃ | 0 | (q₁, 1, ←) |
| q₃ | 1 | (q₁, 1, ←) |
| q₃ | □ | (q₁, 1, ←) |
| q₃ | ▷ | (qₕ, ▷, →) |

Start the machine with input 010

+   - q₁,1⊐010
+   - q₁,1⊐010
+   - q₁,1⊐010
+   - q₁,1⊐010
