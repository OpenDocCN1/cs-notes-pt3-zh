# Many-One Reduction

The set $A$ is many-one reducible, or m-reducible, to the set $B$ if there is a total computable function $f$ such that

$x \in A \text{ iff } f(x) \in B$

for all $x$. We shall write $A \le_m B$ or more explicitly $f : A \le_m B$.

If $f$ is injective, then it is a one-one reducibility, denoted by $\le_1$.
