# Enumeration Theorem

For each $n$, the universal function $\psi_U^{(n)}$ is computable.

# Proof

Given a number $e$, decode the number to get the program $P_e$; and then simulate the program $P_e$. If the simulation ever terminates, then return the number in $R_1$. By Church-Turing Thesis, $\psi_U^{(m)}$ is computable.
