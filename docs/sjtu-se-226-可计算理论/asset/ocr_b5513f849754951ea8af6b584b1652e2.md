# Proof in Detail

The states of the computation of the program $P_e(x)$ can be described by a configuration and an instruction number.

A state can be coded up by the number

$o = \pi(i,j);$

where $c$ is the configuration that codes up the current values in the registers

$c = 2^{r_1}3^{r_2}\cdots = \prod_{i>1} p_i^{r_i},$

and $j$ is the next instruction number.
