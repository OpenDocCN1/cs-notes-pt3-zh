# Undecidability

# Proposition

The problem ‘φₑ is total’ is undecidable.

# Proof

If ‘φₑ is total’ were decidable, then by Church-Turing Thesis

```
f(x) = { ψₑ(x, x) + 1, if φₑ is total,
 0, if φₑ is not total. }
```

would be a total computable function that differs from every total computable function.
