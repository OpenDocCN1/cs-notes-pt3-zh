# Undecidability

# Proposition

The problem ‘φₓ is total’ is undecidable.

# Proof

If ‘φₓ is total’ were decidable, then by Church-Turing Thesis

f(x) = { ψ_U(x,x) + 1, if φₓ is total,
0, if φₓ is not total. }

would be a total computable function that differs from every total computable function.
