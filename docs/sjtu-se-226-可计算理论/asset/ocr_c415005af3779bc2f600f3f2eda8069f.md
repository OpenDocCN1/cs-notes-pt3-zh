# Property of Productive Set

# Theorem. A productive set contains an infinite r.e. subset.

# Proof. Suppose p is a production function for A.

Take e₀ to be some index for ∅. Then p(e₀) ∈ A by definition.

By the Lemma there is a primitive recursive function k such that for all x, Wₖ₍ₓ₎ = Wₓ ∪ {p(x)}.

Apparently {e₀, ..., kⁿ(e₀), ...} is r.e.

Consequently {p(e₀), ..., p(kⁿ(e₀)), ...} is a r.e. subset of A, which must be infinite by the definition of k.
