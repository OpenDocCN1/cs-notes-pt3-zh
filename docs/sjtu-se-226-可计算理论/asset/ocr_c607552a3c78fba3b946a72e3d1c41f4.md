# More Arithmetic Functions

Proof

+   1. $D(x) = \sum_{y \nmid x} \operatorname{div}(y, x)$.

+   2. $Pr(x) = \operatorname{sg}(|D(x) - 2|)$.

+   3. $p_i$ can be recursively defined as follows:
+   
+   $p_0 = 0,$
+   
+   $p_{i+1} = \mu z < (1 + p_i)(1 - (z - p_i)) Pr(z) = 0$.

+   4. $(x)_s = \mu z < x (\operatorname{div}(p_s^{z+1}, x) = 0)$.
