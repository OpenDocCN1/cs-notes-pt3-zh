# URM-Computable Function

Suppose P is the program of a URM and a₁, ..., aₙ, b ∈ ℕ.

The computation P(a₁, ..., aₙ) converges to b if P(a₁, ..., aₙ) ↓ and r₁ = b in the final configuration.

In this case we write P(a₁, ..., aₙ) ↓ b.

P URM-computes f iff, for all a₁, ..., aₙ, b ∈ ℕ, P(a₁, ..., aₙ) ↓ b iff f(a₁, ..., aₙ) = b.

The function f is URM-definable if there is a program that URM-computes f.
