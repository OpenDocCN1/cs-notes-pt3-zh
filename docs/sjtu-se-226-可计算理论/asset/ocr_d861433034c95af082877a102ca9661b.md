# Proposition

Suppose that $f(y_1, ..., y_k)$ is a primitive recursive and that $x_{i_1}, ..., x_{i_k}$ is a sequence of $k$ variables from $x_1, ..., x_n$ (possibly with repetition). Then the function $h$ given by

```
h(x_1, ..., x_n) = f(x_{i_1}, ..., x_{i_k})
```

is primitive recursive.

# Proof

h(\vec{x}) = f(U_{i_1}^h(\vec{x}), ..., U_{i_k}^h(\vec{x})).
