# The Second Example

Q = {q_s, q_h, q_1}, Γ = {0, 1, □, ▷}, and δ is as follows:

| p ∈ Q | σ ∈ Γ | δ(p, σ) |
|---|---|---|
| q_s | 0 | (q_1, 0, →) |
| q_s | 1 | (q_1, 1, →) |
| q_s | □ | (q_1, □, →) |
| q_s | ▷ | (q_h, ▷, →) |
| q_h | 0 | (q_h, 1, →) |
| q_1 | 1 | (q_1, 0, →) |
| q_1 | ▷ | (q_h, ▷, →) |
