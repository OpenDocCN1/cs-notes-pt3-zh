# Property of Productive Set

Lemma. Suppose that g is a total computable function. Then there is a primitive recursive function p such that for all x, W_{p(x)} = W_x ∪ {g(x)}.

Proof. Using S-m-n Theorem, take p(x) to be a primitive recursive function such that

φ_{p(x)}(y) = { 1, if y ∈ W_x ∨ y = g(x), ↑, otherwise }
