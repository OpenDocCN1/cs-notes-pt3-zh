# Partially Decidable Predicate

A predicate $M(\bar{x})$ of natural number is partially decidable if its partial characteristic function

$\chi_M(\bar{x}) = \begin{cases} 1, & \text{if } M(\bar{x}) \text{ holds}, \\ \uparrow, & \text{if } M(\bar{x}) \text{ does not hold}, \end{cases}$

is computable.
