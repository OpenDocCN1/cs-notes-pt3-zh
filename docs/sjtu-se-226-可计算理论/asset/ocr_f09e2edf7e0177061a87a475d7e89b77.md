# Proof in Detail (ch)

The following function

ch(c, z) = the resulting configuration when the configuration c is operated on by the instruction with code number z.

is primitive recursive if

ch(c, z) = { zero(c, u₂(z)), if rm(4, z) = 0, succ(c, u₂(z)), if rm(4, z) = 1, tran(c, u₁(z), u₂(z)), if rm(4, z) = 2, c, if rm(4, z) = 3 }
