# Simple Sets

**Theorem.** There is a simple set.

*Proof.* Define $f(x)=\phi_x(\mu_x(\phi_x(\ge 2x)))$. Let $A$ be $\operatorname{Ran}(f)$.

+   1. $A$ is r.e.
+   2. $\overline{A}$ is infinite. This is because $A\cap\{0,1,\ldots,2n\}$ contains at most the elements $\{f(0),f(1),\ldots,f(n-1)\}$.
+   3. Suppose $B$ is an infinite r.e. set. Then there is a total computable function $\phi_B$ such that $B=E_{\phi_B}$. Since $\phi_B$ is total, $f(b)$ is defined and $f(b)\in A$. Hence $B\subseteq A$.
