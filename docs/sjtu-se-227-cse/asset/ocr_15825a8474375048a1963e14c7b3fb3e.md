# System Call: Entry Point in Kernel Mode

+   - **Assume passing parameters in registers**
+     EntryPoint:
+     switch to kernel stack
+     save context
+     check R₀
+     call the real code pointed by R₀
+     restore context
+     switch to user stack
+     iret (change to user mode and return)
