# Implementing YIELD()

+   - Assumptions
+     - A fixed number of threads, e.g., 7
+     - Fewer processors than threads
+     - Threads share memory address space
+     - Threads are already running
+       - Don't care creating or terminating
+   - 4 Procedures
+     - ENTER_PROCESSOR_LAYER, GET_THREAD_ID, EXIT_PROCESSOR_LAYER, SCHEDULER()
+   - 2 Tables
+     - *processor_table*: record current thread ID
+     - *thread_table*: record thread SP
+       - Protected by *thread_table_lock*
