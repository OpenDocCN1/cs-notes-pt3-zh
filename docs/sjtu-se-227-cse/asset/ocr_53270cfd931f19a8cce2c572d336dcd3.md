# Single Sender and Single Receiver

```
procedure SEND (buffer reference p, message m)
    AWAIT (p.out, p.in = N)
    p.message[READ(p.in) modulo N] ← msg
    ADVANCE (p.in)

procedure RECEIVE (buffer reference p)
    AWAIT (p.in, p.out)
    msg ← p.message[READ(p.out) modulo N]
    ADVANCE (p.out)
    return msg
```
