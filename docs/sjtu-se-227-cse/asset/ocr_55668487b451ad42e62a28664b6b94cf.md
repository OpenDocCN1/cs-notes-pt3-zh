# Allocate a Thread

+   - thread_id ← ALLOCATE_THREAD (starting_procedure, address_space_id)
+     - Allocate a new thread in address space *address_space_id*
+     - The new thread is to begin with a call to the procedure specified in the argument *starting_procedure*
+     - Return
+       - An identifier that names the just-created thread.
+       - An error
