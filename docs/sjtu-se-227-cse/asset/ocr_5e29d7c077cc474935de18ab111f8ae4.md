# Marshal / Unmarshal

+   - Marshal
+     - Convert an object into an array of bytes with enough annotation so that the unmarshall procedure can convert it back into an object
+   - Why Marshal?
+     - Serialization is not easy
+     - E.g., big endian VS. little endian
+       - 0x89ABCDEF on POWER and Intel
+       - Big endian on network:
+         - htons(), ntohs()
+     - What about an array?
+     - What about a pointer?
