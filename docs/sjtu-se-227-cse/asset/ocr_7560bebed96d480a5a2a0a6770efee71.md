# Approach 3: Fine-grained Locking + Holding Both Locks

```
move(dir1, dir2, filename):
    acquire(dir1.lock)
        acquire(dir2.lock)
    unlink(dir1, filename)
    link(dir2, filename)
        release(dir1.lock)
    release(dir2.lock)
```

A: move(M, N, file1.txt)
B: move(N, M, file2.txt) // M and N swapped
