# DMA Example

```
R1 ← 11742; R2 ← 3328; R3 ← 256; R4 ← 1;
STORE 121,R1                // set sector number
STORE 122,R2                // set memory address register
STORE 123,R3                // set byte count
STORE 124,R4                // start disk controller running
```
