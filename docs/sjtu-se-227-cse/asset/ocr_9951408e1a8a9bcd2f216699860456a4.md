# Transport Layer

+   - Entities
+     - Sender and receiver
+     - Proxy, firewall, etc.
+     - End-to-end connection
+   - Name space: *port number*
+   - Protocols: TCP, UDP, etc.
+   - What to care?
+     - TCP: Retransmit packet if lost
+     - UDP: nothing
