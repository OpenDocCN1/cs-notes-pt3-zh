# Race Condition

+   - Race condition
+     - Timing dependent error involving shared state
+     - Whether it happens depends on how threads scheduled
+     - Considering “i++” by 2 threads concurrently, with i =0:

| Thread 1 | Thread 2 |  | Integer value |
|---|---|---|---|
|  |  |  | 0 |
| read value |  | ← | 0 |
| increase value |  |  | 0 |
| write back |  | → | 1 |
|  | read value | ← | 1 |
|  | increase value |  | 1 |
|  | write back | → | 2 |

| Thread 1 | Thread 2 |  | Integer value |
|---|---|---|---|
|  |  |  | 0 |

|  | read value | ← | 0 |
| increase value |  |  | 0 |
|  | increase value |  | 0 |
