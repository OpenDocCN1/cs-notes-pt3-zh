# Send with wait(bb.full, bb.lock)

```
send(bb, m):
    acquire(bb.lock)
    while True:
        if bb.in − bb.out < N:
            bb.buff[bb.in mod N] ← m
            bb.in ← bb.in + 1
            release(bb.lock)
            notify(bb.empty)
            return
        release(bb.lock)
        wait(bb.full)
        acquire(bb.lock)
```
