# Send with wait/notify (Incorrect)

```
send(bb, m):
    acquire(bb.lock)
    while True:
        if bb.in − bb.out < N:
            bb.buf[bb.in mod N] ← m
            bb.in ← bb.in + 1
            release(bb.lock)
            return
        release(bb.lock)
        yield()
        acquire(bb.lock)
```

```
send(bb, m):
    acquire(bb.lock)
    while True:
        if bb.in − bb.out < N:
            bb.buf[bb.in mod N] ← m
            bb.in ← bb.in + 1
            release(bb.lock)
            notify(bb.empty)
            return
        release(bb.lock)
        wait(bb.full)
        acquire(bb.lock)
```
