# No Cycle for LINK

| Path name | File name | Inode num | File (inode) | Block num | Disk Block |

+   - /a/b is a directory
+   - The refcnt of a is 1
+   - a’s inode num is 25

+   - LINK ("/a/b/c", "a")
+   - Cause a cycle!
+   - Refcnt of a is 2

+   - UNLINK ("/a")
+   - Refcnt of a is 1, so the inode 25 is not deleted
+   - Now inode 25 is disconnected from graph
