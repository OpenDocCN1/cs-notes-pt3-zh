# Corner Case 2: Delete After Open

Program 1 on client 1

Program 2 on client 2

Time

```
1
2   UNLINK ("f")
3   fd ← OPEN ("f", CREATE)
4
```

```
fd ← OPEN ("f", READONLY)

READ (fd, buf, n)
```

+   - UNIX spec:
+     - On local FS, program 2 will read the old file
+   - How to avoid program 2 reading new file?
+     - Generation number
+     - "stale file handler"
+   - Not the same as UNIX spec! It's a tradeoff.
