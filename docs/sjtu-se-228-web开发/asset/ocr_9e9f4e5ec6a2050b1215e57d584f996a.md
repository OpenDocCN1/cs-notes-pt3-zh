# PreparedStatement

```
// ParameterMetaData
PreparedStatement pstmt = con.prepareStatement(
"SELECT * FROM tbl_user WHERE id = ?
    and username = ?");
pstmt.setInt(1, 3);
pstmt.setString(2, "Guest");
pstmt.execute();
ParameterMetaData pmd = pstmt.getParameterMetaData();
int number = pmd.getParameterCount();
```
