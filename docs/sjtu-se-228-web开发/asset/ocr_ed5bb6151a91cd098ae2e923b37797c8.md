+   - Yii is a high-performance PHP framework best for developing Web 2.0 applications.
+   - Download Yii v1.1.14
+     - And unzip the archive,
+     - Copy the directory `/framework` and `/requirements` to
+       - `Apache/htdocs`, or
+       - `Eclipse/Workspace`
+     - Run yiic.bat in `/framework` to generate your web application
+       - `yiic webapp <app-path> [<vcs>]`
+     - Where,
+       - app-path: required, the directory where the new application will be created.
+       - vcs: optional, version control system you're going to use in the new project.
