# Easiness results

# Polynomial Approximation Scheme (PAS, or PTAS)

Given any ε = 1/k for some positive integer k, we can construct an approximation algorithm for Knapsack problem with R < 1+ε, and the algorithm runs in time that is polynomial in the length of the input instance.

# Fully Polynomial Approximation Scheme (FPTAS)

Given any ε = 1/k for some positive integer k, we can construct an approximation algorithm for Subset sum problem with R < 1+ε, and the algorithm runs in time that is polynomial in the length of the input instance and k.
