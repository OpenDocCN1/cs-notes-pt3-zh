# Minimum Cut

Definition: Cut
A cut {S,T} is a partition of the vertex set V into two subsets S and T such that s ∈ S and t ∈ T.
The capacity of the cut {S,T}, denoted by c(S,T), is
c(S,T) = Σ_{u∈S, v∈T} c(u,v)

![](bbox=[0.28, 0.45, 0.78, 0.78])

Lemma
For any cut {S,T} and a flow f, |f| = f(S,T) ≤ c(S,T).
