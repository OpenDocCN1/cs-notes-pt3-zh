# Correctness

**Theorem (GeneralMSTAlgorithm)**
Let *A* be a subset of E that is included in some MST for *G*, let {*V*, *S-V*} be any cut of G that respects A, and let (*u,v*) be a lightest edge crossing V, S-V.
Then, A ∪ {(*u,v*)} is included in some MST.

**Theorem**
Kruskal algorithm and Prim algorithm correctly find a minimum cost spanning tree.
