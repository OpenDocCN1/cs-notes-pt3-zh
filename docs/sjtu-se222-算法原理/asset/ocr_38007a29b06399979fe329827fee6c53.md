# Simplified Master Theorem

Let $a \ge 1$, $b > 1$ and $c,d,w \ge 0$ be constants, and let $T(n)$ be defined on the nonnegative integers by the recurrence

```
f(n) = { w               if n = 1
          a f(n/b) + c n^d   if n > 1 }
```

Then

```
f(n) = { Θ(n^d)          if a < b^d
          Θ(n^d log n)    if a = b^d
          Θ(n^{log_b a})  if a > b^d }
```
