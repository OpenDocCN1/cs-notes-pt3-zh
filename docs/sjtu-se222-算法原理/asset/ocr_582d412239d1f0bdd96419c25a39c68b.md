# Dynamic programming

+   - **What:**
+     1. write the paradigm: Problems -> subproblems
+     2. solve it in a bottom-up way
+   - **When:** subproblems overlap
+   - **Examples:** Dijkstra, Knapsack, LCS, Matrix chain ......
+   - **Test:** *Longest increasing subsequence*
