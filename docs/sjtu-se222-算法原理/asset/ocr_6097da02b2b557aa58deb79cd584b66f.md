# Quiz

```
Algorithm 1.9 Count3
Input: n = 2^{2^k}, k is a positive integer.
Output: count = number of times Step 6 is executed.

1. count ← 0;
2. for i ← 1 to n
3.     j ← 2;
4.     while j ≤ n
5.         j ← j²;
6.         count ← count + 1
7.     end while
8. end for
9. return count
```

+   A. Θ(n²)
+   B. Θ(n).
+   C. Θ(n log n)
+   D. none of above
