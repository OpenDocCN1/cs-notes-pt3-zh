# Construct

+   - *Node*
+     - Is Leaf? (Is End?)
+     - Edge.
+   
+   - *Find word*
+     - Edge of next letter?
+       - Exist: jump to next Node.
+       - Not exist: return false.
+     - Is end of the word?
+   
+   - *Add word*
+     - Edge of next letter?
+       - Exist: jump to next Node.
+       - Not exist: add new Node, jump to it.
+     - Is end of the word?
+       - Mark.
