# Theorem (CorrectnessOfDijkstraAlgorithm)

In Algorithm Dijkstra, when a vertex u is chosen in Step 7, if its label λ[u] is finite then λ[u] = δ[u].

Assume u is chosen in Step 7, and

+   1. λ[u] > δ[u]
+   2. s ⇒ x → y ⇒ u is the shortest path

![](bbox=[0.13, 0.6, 0.48, 0.88])

δ[u] = δ[x] + w(x,y) + w(p2)
= λ[x] + w(x,y) + w(p2)
≥ λ[x] + w(x,y)
≥ λ[y] ≥ λ[u]
