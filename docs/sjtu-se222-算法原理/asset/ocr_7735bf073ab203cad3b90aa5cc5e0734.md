# Quiz

```
Algorithm 1.7 Count1
Input: n = 2^k, for some positive integer k.
Output: count = number of times Step 4 is executed.
1. count ← 0;
2. while n ≥ 1
3.   for j ← 1 to n
4.     count ← count + 1
5.   end for
6.   n ← n/2
7. end while
8. return count
```

+   B. Θ(n).
+   C. Θ(nlogn)
