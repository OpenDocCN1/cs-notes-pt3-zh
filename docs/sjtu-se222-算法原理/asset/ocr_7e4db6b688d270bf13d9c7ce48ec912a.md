# MERGE(A,p,q,r)

A ..., 2, 13, 43, 45, 89, 6, 24, 51, 90, 93, ...
    p          q                r

```
1. s ← p; t ← q + 1; k ← p
2. while s ≤ q and t ≤ r
3.   if A[s] ≤ A[t] then
4.     B[k] ← A[s]
5.     s ← s + 1
6.   else
7.     B[k] ← A[t]
8.     t ← t + 1
9.   end if
10.  k ← k + 1
11. end while
12. if s = q + 1 then B[k..r] ← A[t..r]
13. else B[k..] ← A[s..q]
13. end if
13. A[p..r] ← B[p..r]
```
