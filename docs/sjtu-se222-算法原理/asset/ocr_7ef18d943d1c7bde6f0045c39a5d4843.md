# Shortest path

| Single-source | Graph types | Complexity |
|---|---|---|
| Dijkstra | Positive weight | O(m log n) |
| Bellman-Ford | Any | O(mn) |
| Topological sort | DAG | O(m+n) |

| All-pairs | Floyd-Warshall | Any | O(n³) |
