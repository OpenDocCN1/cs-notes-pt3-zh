# Huffman code

Algorithm 8.6 Huffman

Input: A set C = {c₁, c₂, …, cₙ} of n characters and their frequencies {f(c₁), f(c₂), …, f(cₙ)}.

Output: A Huffman tree (V, T) for C.

+   1. Insert all characters into a min-heap H according to their frequencies.
+   2. V ← C; T ← ∅
+   3. for j ← 1 to n − 1
+   4. c ← DeleteMin(H)
+   5. c′ ← DeleteMin(H)
+   6. f(v) ← f(c) + f(c′)
+   7. Insert(H, v)
+   8. V ← V ∪ {v}
+   9. T ← T ∪ {(v, c), (v, c′)}
+   10. end for
