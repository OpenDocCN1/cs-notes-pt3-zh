# NP complete:
The hardest problem in NP

**Definition: NP-Complete**
A decision problem \(\pi\) is said to be *NP-complete* if the following two properties hold:

+   1. \(\pi \in \mathrm{NP}\) and
+   2. for every problem \(\pi' \in \mathrm{NP}\), \(\pi' \leq_p \pi\).
