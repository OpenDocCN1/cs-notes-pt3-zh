# Breadth-first search

Repeat until queue is empty:

+   - Remove vertex *v* from queue.
+   - Add to queue all unmarked vertices adjacent to *v* and mark them.

![](bbox=[0.13, 0.38, 0.62, 0.75])

| queue | v | edgeTo[v] |
|---|---|---|
|  | 0 | - |
|  | 1 | 0 |
|  | 2 | 0 |
|  | 3 | 2 |
| 4 | 4 | 2 |
| 3 | 5 | 0 |
