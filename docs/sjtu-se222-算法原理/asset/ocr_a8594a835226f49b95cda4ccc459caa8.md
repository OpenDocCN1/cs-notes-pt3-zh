# Delete-maximum: SiftDown

![](bbox=[0.13, 0.32, 0.38, 0.64])

O(2 log n)

```
SiftDown(H,i)
1. done ← false
2. if 2i > n then exit
3. repeat
4.   i ← 2i
5.   if i + 1 ≤ n and key(H[i + 1]) > key(H[i])
6.   then i ← i + 1
7.   if key(H[⌊i/2⌋]) < key(H[i])
8.   then interchange H[i] and H[⌊i/2⌋]
9.   else done ← true
10. until 2i > n or done
```
