# Floyd-Warshall algorithm

# Algorithm 7.3 Floyd

Input: An n × n matrix l[1..n, 1..n] such that l[i,j] is the length of the edge (i,j) in a directed graph G = ({1,...,n},E).

Output: A matrix D with D[i,j] = the distance from i to j.

+   1. D ← l
+   2. for k ← 1 to n
+   3.   for i ← 1 to n
+   4.     for j ← 1 to n
+   5.       D[i,j] = min{D[i,j], D[i,k] + D[k,j]}
+   6.     end for
+   7.   end for
+   8. end for
