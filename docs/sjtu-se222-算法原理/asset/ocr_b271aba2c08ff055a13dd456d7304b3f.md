# Amortized analysis

```
1. for j ← 1 to n
2.   x ← A[j]
3.   Append x to the list
4.   if x is even then
5.     while pred(x) is odd do delete pred(x)
6.   end if
7. end for
```

The total number of `append` is *n*.
The total number of `delete` is between *0* and *n-1*.
So the time complexity is *O(n)*.
