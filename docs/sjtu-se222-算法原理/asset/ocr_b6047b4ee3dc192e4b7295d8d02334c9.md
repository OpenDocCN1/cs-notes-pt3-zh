# All-pairs shortest path

Define dᵏᵢ,ⱼ to be the length of a shortest path from i to j that does not pass any vertex in {k + 1, k + 2, ..., n}. Clearly

```
dᵏᵢ,ⱼ = { l[i,j]               if k = 0
          min{dᵏ⁻¹ᵢ,ⱼ , dᵏ⁻¹ᵢ,ₖ + dᵏ⁻¹ₖ,ⱼ}   if 1 ≤ k ≤ n }
```
