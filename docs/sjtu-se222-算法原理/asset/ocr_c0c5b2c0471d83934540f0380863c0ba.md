# APP_SUBSETSUM

We construct a new instance I′ and apply the subset-sum algorithm to it:

$K = C/(2(k+1)n)$  
$C' \overset{def}{=} \lfloor C/K \rfloor$  
$s'_j \overset{def}{=} \lfloor s_j/K \rfloor$

Time complexity: O(nC/K) = O(kn²)
