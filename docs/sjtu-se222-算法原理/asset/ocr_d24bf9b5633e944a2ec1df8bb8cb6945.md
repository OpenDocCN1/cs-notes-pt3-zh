# Integer Exponential

Problem: IntegerExponetial
Input: a real number x and a nonnegative integer n.
Output: xⁿ

```
Algorithm 5.4 ExpRec
Input: A real number x and a nonnegative integer n.
Output: xⁿ.

1. power(x, n)

Procedure power(x, m)
1. if m ≡ 0 then y ← 1
2. else
3.   y ← power(x, ⌊m/2⌋)
4.   y ← y²
5.   if m is odd then y ← x y
6. end if
7. return y
```
