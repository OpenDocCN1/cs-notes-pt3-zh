# 算术编码的压缩效率

我们知道，表示一个 [0,1) 的小数，至少需要 $-\log_2\varepsilon$ 二进制位。假设 $\lambda$ 为我们最终得到的子区间长度，那么我们所需的那个数就可以用 $-\log_2\lambda$ 个二进制位表示，为什么呢？假设最终的区间为 [0.101100，0.101101)，那么区间长度为 0.000001。我们至少需要 $-\log_2\lambda$ 个二进制位表示，而我们最终需要的 0.10110 位数比 0.00000 少，故而可以用 $-\log_2\lambda$ 个二进制位表示。

$$L_N=\prod_{i=1}^{N}p(s_i)$$

其中 $p(s_i)$ 表示我们编码的第 $i$ 个字符的频率。

故而我们每个字符平均需要的位数 $B_s=\frac{-\log_2\lambda+\sigma}{N}$，其中 $\sigma$ 是个常数因为你编码中必须得存一下字符频率等相关信息，这些信息也是占用空间的。
