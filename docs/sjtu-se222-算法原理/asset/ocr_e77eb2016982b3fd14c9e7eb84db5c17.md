Algorithm 3.3 Insert

Input: A heap H[1..n] and a heap element x.

Output: A new heap H[1..n + 1] with x being one of its elements.

+   1. n ← n + 1
+   2. H[n] ← x
+   3. SiftUp(H, n)

SiftUp(H,i)

+   1. done ← false
+   2. if i = 1 then exit
+   3. repeat
+   4. if key(H[i]) > key(H[⌊i/2⌋])
+   5. then interchange H[i] and H[⌊i/2⌋]
+   6. else done ← true
+   7. i ← ⌊i/2⌋
+   8. until i = 1 or done
