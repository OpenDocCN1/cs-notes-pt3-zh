# Algorithm 7.1 LCS

Input: Two strings A and B of length n and m over Σ.

Output: The length of the longest common subsequence of A, B.

+   1. for i ← 0 to n do L[i,0] ← 0 end for
+   2. for j ← 0 to m do L[0,j] ← 0 end for
+   3. for i ← 1 to n
+   4. for j ← 1 to m
+   5. if a_i = b_j then L[i,j] ← L[i-1,j-1] + 1
+   6. else L[i,j] ← max{L[i-1,j], L[i,j-1}}
+   7. end if
+   8. end for
+   9. end for
+   10. return L[n,m]

Time: Θ(mn)
Space: Θ(max{m,n})
