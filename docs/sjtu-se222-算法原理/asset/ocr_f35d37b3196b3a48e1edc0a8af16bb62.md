# The first NPC problem

DecisionProblem: SAT
Input: A boolean formula
Output: Is this formula satisfiable?

2-SAT: (x ∨ y) ∧ (x ∨ z̄) ∧ (y ∨ z)

3-SAT: (x ∨ y ∨ z) ∧ (x ∨ ȳ ∨ z̄) ∧ (x̄ ∨ y ∨ z) ∧ (y ∨ ȳ ∨ z̄)

Cook-Levin Theorem [Cook, 1971; Levin, 1973]
SAT is NP-complete
