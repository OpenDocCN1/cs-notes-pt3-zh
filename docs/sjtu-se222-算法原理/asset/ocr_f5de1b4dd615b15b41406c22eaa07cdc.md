# Divide-and-conquer

+   - **What:** Divide-conquer-combine
+   - **When:** Non-overlapping subproblems
+   - **Examples:** Quicksort, mergesort, Select, Closest pair......
+   - **Test:**
+     *Given a sorted array of distinct integers* `A[1, ..., n]`, *you want to find out whether there is an index* `i` *for which* `A[i] = i`.
