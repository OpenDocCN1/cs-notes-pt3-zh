## Integer Exponential

Problem: Integer Exponential

Input: a real number x and a nonnegative integer n.

Output: xⁿ

```text
Algorithm 5.4 ExpRec
Input: A real number x and a nonnegative integer n.
Output: xⁿ.

1. power(x, n)

Procedure power(x, m)
1. if m ≡ 0 then y ← 1
2. else
3.   y ← power(x, ⌊m/2⌋)
4.   y ← y²
5.   if m is odd then y ← x y
6. end if
7. return y
```

## Divide-and-conquer

- **Divide Step**: the input is partitioned into *p* ≥ 1 parts, each of which is strictly less than *n*.
- **Conquer Step**: *p* recursive call(s) of the smaller parts.
- **Combine Step**: combine the solved parts to obtain the desired output.

## Master theorem

### Simplified Master Theorem

Let $a \ge 1$, $b > 1$ and $c,d,w \ge 0$ be constants, and let $T(n)$ be defined on the nonnegative integers by the recurrence

```text
f(n) = { w               if n = 1
          a f(n/b) + c n^d   if n > 1 }
```

Then

```text
f(n) = { Θ(n^d)          if a < b^d
          Θ(n^d log n)    if a = b^d
          Θ(n^{log_b a})  if a > b^d }
```
