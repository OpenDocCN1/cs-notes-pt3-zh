## Knapsack problem

```
Algorithm 7.4 Knapsack
1. for i ← 0 to n do V[i, 0] ← 0
2. for j ← 0 to C do V[0, j] ← 0
3. for i ← 1 to n
4.   for j ← 1 to C
5.     V[i, j] ← V[i − 1, j]
6.     if sᵢ ≤ j then V[i, j] ← max{V[i, j], V[i − 1, j − sᵢ] + vᵢ}
7.   end for
8. end for
9. return V[n, C]
```

Time: Θ(nC)
Space: Θ(nC)

Psuedo-polynomial algorithm

## Longest common subsequence

Problem: LCS
Input: Two strings A=a1a2...an and B=b1b2...bm
Output: The longest common subsequence of A and B

L[i,j]: length of the longest common subsequence of A[1..i] and B[1..j]

ababe

abcabc

Solution: L[n,m]

L[i,j] = { 0 if i = 0 or j = 0
L[i - 1, j - 1] + 1 if i > 0, j > 0 and a_i = b_j
max[L[i - 1, j], L[i, j - 1}] if i > 0, j > 0 and a_i ≠ b_j }

## LCS

L[i,j] = { 0 if i = 0 or j = 0
L[i-1,j-1] + 1 if i > 0, j > 0 and a_i = b_j
max{L[i-1,j], L[i,j-1]} if i > 0, j > 0 and a_i ≠ b_j }

## LCS

### Algorithm 7.1 LCS

Input: Two strings A and B of length n and m over Σ.

Output: The length of the longest common subsequence of A, B.

1. for i ← 0 to n do L[i,0] ← 0 end for
2. for j ← 0 to m do L[0,j] ← 0 end for
3. for i ← 1 to n
4. for j ← 1 to m
5. if a_i = b_j then L[i,j] ← L[i-1,j-1] + 1
6. else L[i,j] ← max{L[i-1,j], L[i,j-1]}
7. end if
8. end for
9. end for
10. return L[n,m]

Time: Θ(mn)
Space: Θ(max{m,n})

## Longest common substring?

L[i,j]: length of longest common sub-postfix of a[1..i] and b[1..j].

L[i,j] = { 0 if i = 0 or j = 0
L[i-1,j-1] + 1 if i > 0, j > 0 and a_i = b_j
0 if i > 0, j > 0 and a_i ≠ b_j }

Solution: the maximum L[i,j] for all i>0 and j>0

## Matrix chain multiplication

Problem: MCM
Input: A matrix chain M₁M₂...Mₙ with rank r₁r₂..rₙrₙ₊₁
Output: Minimal cost of the multiplication

| (A × B) × (C × D) | 50·20·1 + 1·10·100 + 50·1·100 | 7,000 |

## Dynamic programming

C[i,j]: the minimal cost of the multiplication MiMi+1 ... Mj

```
C[i,j] = min_{i<k≤j}{C[i,k-1] + C[k,j] + r_i r_k r_{j+1}}
```

## MCM

### Algorithm 7.2 MatChain

1. for i ← 1 to n
2. C[i,i] ← 0
3. end for
4. for d ← 1 to n − 1
5. for i ← 1 to n − d
6. j ← i + d
7. C[i,j] ← ∞
8. for k ← i + 1 to j
9. C[i,j] ← min{C[i,j], C[i,k−1] + C[k,j] + r[i]r[k]r[j+1]}
10. end for
11. end for
12. end for
13. return C[1,n]

∑_{d=1}^{n−1} ∑_{i=1}^{n−d} ∑_{k=1}^{d} c = (c n³ − c n)/6 = Θ(n³)
