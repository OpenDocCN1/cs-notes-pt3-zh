
## Algorithm 9.1 DFS

**Input:** A directed or undirected graph G = (V, E).

**Output:** Preordering and postordering of the vertices in the corresponding depth-first tree.

```text
predfn ← 0; postdfn ← 0
time ← 0
for each vertex v ∈ V
    mark v unvisited
    v.pre ← infinity
    v.post ← infinity
end for
for each vertex v ∈ V
    if v is marked unvisited then dfs(v)
end for
```

### Procedure dfs(v)

```text
mark v visited
predfn ← predfn + 1
time ← time + 1
v.pre ← time
for each edge (v, w) ∈ E
    if w is marked unvisited then dfs(w)
end for
postdfn ← postdfn + 1
time ← time + 1
v.post ← time
```

## Algorithm 9.4 BFS

**Input:** A directed or undirected graph G = (V, E).

**Output:** Numbering of the vertices in breadth-first search order.

```text
bfn ← 0
for each vertex v ∈ V
    mark v unvisited
end for
for each vertex v ∈ V
    if v is marked unvisited then bfs(v)
end for
```

### Procedure bfs(v)

```text
Q ← {v}
mark v visited
while Q ≠ ∅
    v ← Pop(Q)
    bfn ← bfn + 1
    for each edge (v, w) ∈ E
        if w is marked unvisited then
            Push(w, Q)
            mark w visited
        end if
    end for
end while
```

## Connectivity

**Definition**  
An undirected graph is **connected**, if there is a path between any pair of vertices.  
A **connected component** is a subgraph that is internally connected but has no edges to the remaining vertices.
