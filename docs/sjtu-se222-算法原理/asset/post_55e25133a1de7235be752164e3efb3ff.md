## Correctness

### Theorem (Correctness of Dijkstra Algorithm)

In Algorithm Dijkstra, when a vertex \(u\) is chosen in Step 7, if its label \(\lambda[u]\) is finite then \(\lambda[u] = \delta[u]\).

Assume \(u\) is chosen in Step 7, and

1. \(\lambda[u] > \delta[u]\)
2. \(s \Rightarrow x \rightarrow y \Rightarrow u\) is the shortest path

![](img/a8f1b433a70f1e5c410c8b43e41b650e_625_0.png)

\[
\delta[u] = \delta[x] + w(x,y) + w(p_2)
          = \lambda[x] + w(x,y) + w(p_2)
          \ge \lambda[x] + w(x,y)
          \ge \lambda[y] \ge \lambda[u]
\]

## All-pairs shortest path

Define \(d^k_{i,j}\) to be the length of a shortest path from \(i\) to \(j\) that does not pass any vertex in \(\{k+1, k+2, \ldots, n\}\). Clearly,

\[
d^k_{i,j} =
\begin{cases}
l[i,j], & \text{if } k = 0,\\
\min\left\{d^{k-1}_{i,j},\ d^{k-1}_{i,k} + d^{k-1}_{k,j}\right\}, & \text{if } 1 \le k \le n.
\end{cases}
\]

## Floyd-Warshall algorithm

![](img/a8f1b433a70f1e5c410c8b43e41b650e_632_0.png)

### Algorithm 7.3 Floyd

Input: An \(n \times n\) matrix \(l[1..n, 1..n]\) such that \(l[i,j]\) is the length of the edge \((i,j)\) in a directed graph \(G = (\{1,\ldots,n\}, E)\).

Output: A matrix \(D\) with \(D[i,j] =\) the distance from \(i\) to \(j\).

```
1. D ← l
2. for k ← 1 to n
3.   for i ← 1 to n
4.     for j ← 1 to n
5.       D[i,j] = min{D[i,j], D[i,k] + D[k,j]}
6.     end for
7.   end for
8. end for
```

## Conclusion

**Dijkstra’s algorithm.**

- Nearly linear-time when weights are nonnegative.

**Acyclic edge-weighted digraphs.**

- Faster than Dijkstra’s algorithm.
- Negative weights are no problem.

**Negative weights and negative cycles.**

- If no negative cycles, can find shortest paths via Bellman-Ford.
- If negative cycles, can find one via Bellman-Ford.

**All-pairs shortest path.**

- can be solved via Floyd-Warshall
- Floyd-Warshall can also compute the transitive closure of directed graph.
