## Optimal Binary search tree

Problem: BinarySearching
Input: A sorted integer array K[1...n], and an integer x
Output: Does x exist in A?

Binary Search Tree (BST)

Given the possibilities that a search will lie in the intervals:

| <k1 | k1 | >k1,<k2 | k2 | >k2,<k3 | ... | kn | >kn |
|---|---|---|---|---|---|---|---|
| q0 | p1 | q1 | p2 | q2 | ... | pn | qn |

∑ᵢ₌₀ⁿ qᵢ + ∑ᵢ₌₁ⁿ pᵢ = 1

## OPT BST

Optimal substructure & overlapping subproblems

e[i,j]: The cost of optimal binary search tree for $k_i, k_{i+1}, ..., k_j$

| d0 | k1 | d1 | k2 | d2 | k3 | d3 | k4 | d4 | k5 | d5 |
|---|---|---|---|---|---|---|---|---|---|---|
| 0.05 | 0.15 | 0.10 | 0.10 | 0.05 | 0.05 | 0.05 | 0.10 | 0.05 | 0.20 | 0.10 |

e[i,j] = q_j if j = i-1

e[i,j] = min_{i<=r<=j}{e[i,r-1] + e[r+1,j] + w[i,j]} if j >= i

where

w[i,j] = q_i if j = i-1

w[i,j] = w[i,r-1] + w[r+1,j] + p_r if j >= i

## Subset sum problem

Problem: SubsetSum
Input: A set of numbers A={a₁,a₂,...,aₙ}, and a sum s
Output: Yes, if there exists a subset B ⊆ A such that the sum of B equals to s; No, otherwise.

L[i,j]: Does there exists a subset B of {a₁,...,aᵢ} such that the sum of B equals to j

L[i,j] = { 0 if i = 0
1 if j = 0
L[i-1,j] if i > 0, j > 0, j < aᵢ
L[i-1,j-aᵢ] ∨ L[i-1,j] if i > 0, j > 0, j ≥ aᵢ }

Solution: L[n,s]

## Editing distance

snowy --> sunny

![](img/a8f1b433a70f1e5c410c8b43e41b650e_826_0.png)

The edit distance between two strings is the cost of their best possible alignment.

E[i,j]: edit distance of a1...ai and b1...bj

```
E[i,j] = { j if i = 0
 i if j = 0
 min E[i-1,j-1], E[i-1,j]+1, E[i,j-1]+1 if i,j > 0 and a_i = b_i
 min E[i-1,j-1]+1, E[i-1,j]+1, E[i,j-1]+1 if i,j > 0 and a_i ≠ b_i }
```
