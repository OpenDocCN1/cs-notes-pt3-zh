**Def.** A spanning tree of G is a subgraph T that is connected and acyclic.

## Minimum spanning tree

**Problem:** MinSpanning
**Input:** A connected undirected graph G = (V, E) in which each edge has a weighted length
**Output:** A spanning tree of G that has minimum cost

![](img/a8f1b433a70f1e5c410c8b43e41b650e_757_0.png)

## Cut property

![](img/a8f1b433a70f1e5c410c8b43e41b650e_758_0.png)

**Definition: Cut**
A cut {S, T} is a partition of the vertex set V into two subsets S and T.

**Theorem (Cut property)** Given any cut, the crossing edge of min weight is in some MST.

## Kruskal algorithm

(h, g), (c, i), (g, f), (a, b), (c, f), (c, d), (i, g), (i, h), (b, c), (a, h), (d, e), (e, f), (b, h)

![](img/a8f1b433a70f1e5c410c8b43e41b650e_759_0.png)

### Algorithm 8.3 Kruskal

```text
Input: A weighted connected undirected graph G = (V, E) with n vertices.
Output: The set of the edges T of a minimum cost spanning tree for G.

1. Sort the edges in E by nondecreasing weight.
2. for each vertex v ∈ V do Makeset({v}) end for
3. T = {}
4. while |T| < n − 1
5.   Let (x, y) be the next edge in E
6.   if Find(x) ≠ Find(y) then
7.     Add(x, y) to T
8.     Union(x, y)
9.   end if
10. end while
```

## Prim algorithm

![](img/a8f1b433a70f1e5c410c8b43e41b650e_761_0.png)

### Algorithm 8.4 Prim

```text
Input: A weighted connected undirected graph G = (V, E), where V = {1, 2, …, n}.
Output: The set of edges T of minimum cost spanning tree for G.

1. T ← {}; X ← {1}; Y ← V \ {1}
2. for y ← 2 to n
3.   if y is adjacent to 1 then
4.     N[y] ← 1
5.     C[y] ← c[1, y]
6.   else C[y] ← ∞
7.   end if
8. end for
9. for j ← 1 to n − 1
10.   Let y be such that C[y] is minimum
11.   T ← T ∪ {(y, N[y])}
12.   X ← X ∪ {y}
13.   Y ← Y \ {y}
14.   for each edge (y, w) such that w ∈ Y
15.     if c[y, w] < C[w] then
16.       N[w] ← y
17.       C[w] ← c[y, w]
18.     end if
19.   end for
20. end for
```

Θ(n²)

Heap: Θ(m log n)

## Dense graph

- dense: $m = n^{1+\varepsilon}$, $\varepsilon$ is not too small.
- d-heap, $d = m/n$
- complexity: $O(nd\log_d n + m\log_d n) = O(m)$

## Correctness

**Theorem (GeneralMSTAlgorithm)**
Let A be a subset of E that is included in some MST for G, let {S, V − S} be any cut of G that respects A, and let (u, v) be a lightest edge crossing S, V − S.
Then, A ∪ {(u, v)} is included in some MST.

**Theorem**
Kruskal algorithm and Prim algorithm correctly find a minimum cost spanning tree.
