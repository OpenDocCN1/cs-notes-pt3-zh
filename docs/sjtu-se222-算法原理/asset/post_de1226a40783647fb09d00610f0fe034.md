## MERGE(A,p,q,r)

A ..., 2, 13, 43, 45, 89, 6, 24, 51, 90, 93, ...
    p          q                r

```
1. s ← p; t ← q + 1; k ← p
2. while s ≤ q and t ≤ r
3.   if A[s] ≤ A[t] then
4.     B[k] ← A[s]
5.     s ← s + 1
6.   else
7.     B[k] ← A[t]
8.     t ← t + 1
9.   end if
10.  k ← k + 1
11. end while
12. if s = q + 1 then B[k..r] ← A[t..r]
13. else B[k..r] ← A[s..q]
14. end if
15. A[p..r] ← B[p..r]
```

## Bottom-up merge sort

```
Input: An array A[1..n] of n elements.
Output: A[1..n] sorted in nondecreasing order.

1. t ← 1
2. while t < n
3.   s ← t; t ← 2s; i ← 0
4.   while i + t ≤ n
5.     Merge(A, i + 1, i + s, i + t)
6.     i ← i + t
7.   end while
8.   if i + s < n then Merge(A, i + 1, i + s, n)
9. end while
```
