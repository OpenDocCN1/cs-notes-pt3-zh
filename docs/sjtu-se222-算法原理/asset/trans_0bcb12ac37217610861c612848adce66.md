

## Dijkstra 算法

- 按与 *s* 的距离递增顺序考虑顶点（即 `distTo[]` 值最小的非树顶点）。
- 将该顶点加入树中，并松弛所有与该顶点关联的边。

![](img/a8f1b433a70f1e5c410c8b43e41b650e_716_0.png)

| v | distTo[] | edgeTo[] |
|---|---|---|
| 0 | 0.0 | - |
| 1 | 5.0 | 0→1 |
| 2 | 14.0 | 5→2 |
| 3 | 17.0 | 2→3 |
| 4 | 9.0 | 0→4 |
| 5 | 13.0 | 4→5 |
| 6 | 25.0 | 2→6 |
| 7 | 8.0 | 0→7 |
