# 键索引计数法的假设

假设：键是 0 到 R - 1 之间的整数。

含义：可以将键用作数组索引。

应用：

- 按首字母对字符串排序。
- 按组别对班级名册排序。
- 按区号对电话号码排序。
- 作为排序算法中的子程序。
