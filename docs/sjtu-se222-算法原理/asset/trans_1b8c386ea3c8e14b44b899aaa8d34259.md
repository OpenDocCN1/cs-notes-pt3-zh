

## 快速排序分区

重复直到 i 和 j 指针交叉。

- 从左到右扫描 i，只要 `a[i] < a[lo]`。
- 从右到左扫描 j，只要 `a[j] > a[lo]`。
- 交换 `a[i]` 与 `a[j]`。

当指针交叉时。

- 交换 `a[lo]` 与 `a[j]`。

## Dijkstra 三路分区

![](img/a8f1b433a70f1e5c410c8b43e41b650e_174_0.png)

- 设 `v` 为分区项 `a[lo]`。
- 从左到右扫描 `i`。
  - `(a[i] < v)`: 交换 `a[lt]` 与 `a[i]` 并同时递增 `lt` 和 `i`
  - `(a[i] > v)`: 交换 `a[gt]` 与 `a[i]` 并递减 `gt`
  - `(a[i] == v)`: 递增 `i`
