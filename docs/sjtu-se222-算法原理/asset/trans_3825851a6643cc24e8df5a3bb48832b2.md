

## 算法 9.1 DFS

**输入：** 有向图或无向图 G = (V, E)。

**输出：** 对应深度优先树中顶点的先序和后序。

```text
predfn ← 0; postdfn ← 0
time ← 0
for each vertex v ∈ V
    mark v unvisited
    v.pre ← infinity
    v.post ← infinity
end for
for each vertex v ∈ V
    if v is marked unvisited then dfs(v)
end for
```

### 过程 dfs(v)

```text
mark v visited
predfn ← predfn + 1
time ← time + 1
v.pre ← time
for each edge (v, w) ∈ E
    if w is marked unvisited then dfs(w)
end for
postdfn ← postdfn + 1
time ← time + 1
v.post ← time
```

## 算法 9.4 BFS

**输入：** 有向图或无向图 G = (V, E)。

**输出：** 顶点在广度优先搜索顺序中的编号。

```text
bfn ← 0
for each vertex v ∈ V
    mark v unvisited
end for
for each vertex v ∈ V
    if v is marked unvisited then bfs(v)
end for
```

### 过程 bfs(v)

```text
Q ← {v}
mark v visited
while Q ≠ ∅
    v ← Pop(Q)
    bfn ← bfn + 1
    for each edge (v, w) ∈ E
        if w is marked unvisited then
            Push(w, Q)
            mark w visited
        end if
    end for
end while
```

## 连通性

**定义**  
无向图是**连通的**，如果任意一对顶点之间存在路径。  
**连通分量**是内部连通但与剩余顶点没有边的子图。

\#trees == \#connected components
