

# 基于键索引的计数演示

目标。对数组 a[] 中的 N 个整数进行排序，范围在 0 到 R - 1 之间。

- 使用键作为索引统计每个字母的频率。
- 计算频率累加和以指定目标位置。
- 使用键作为索引访问累加和以移动元素。
- 复制回原始数组。

```
int N = a.length;
int[] count = new int[R+1];

for (int i = 0; i < N; i++)
    count[a[i]+1]++;

for (int r = 0; r < R; r++)
    count[r+1] += count[r];

for (int i = 0; i < N; i++)
    aux[count[a[i]]++] = a[i];

for (int i = 0; i < N; i++)
    a[i] = aux[i];
```
