

## 测验

```
**算法1.9** Count3  
**输入：** $n = 2^{2^k}$，$k$ 是一个正整数。  
**输出：** $count$ = 步骤6被执行的次数。  

1. $count \leftarrow 0;$
2. **for** $i \leftarrow 1$ **to** $n$
3.     $j \leftarrow 2;$
4.     **while** $j \leq n$
5.         $j \leftarrow j^2;$
6.         $count \leftarrow count + 1$
7.     **end while**
8. **end for**
9. **return** $count$
```

- A. $\Theta(n^2)$  
- B. $\Theta(n)$.  
- C. $\Theta(n\log n)$  
- D. *以上都不是*

## 摊还分析

```
1. for j ← 1 to n
2.   x ← A[j]
3.   Append x to the list
4.   if x is even then
5.     while pred(x) is odd do delete pred(x)
6.   end if
7. end for
```

`append` 的总次数为 *n*。
`delete` 的总次数在 *0* 到 *n-1* 之间。
因此时间复杂度为 *O(n)*。

## 排列 1

算法5.7 排列1

输入：一个正整数 n。

输出：数字 1,2,...,n 的所有排列。

- 1. for j ← 1 to n
- 2. P[j] ← j
- 3. end for
- 4. perm1(1)

过程 perm1(m)

- 1. if m = n then output P[1..n]
- 2. else
- 3. for j ← m to n
- 4. interchange P[j] and P[m]
- 5. perm1(m + 1)
- 6. interchange P[j] and P[m]
- 7. comment: 此时 P[m..n] = m, m + 1, ..., n。
- 8. end for
- 9. end if

## 排列 2

算法5.8 排列2

输入：一个正整数 n。

输出：数字 1, 2, …, n 的所有排列。

- 1. for j ← 1 to n
- 2. P[j] ← 0
- 3. end for
- 4. perm2(n)

# 过程 perm2(m)

- 1. if m = 0 then output P[1..n]
- 2. else
- 3. for j ← 1 to n
- 4. if P[j] = 0 then
- 5. P[j] ← m
- 6. perm2(m − 1)
- 7. P[j] ← 0
- 8. end if
- 8. end for
- 9. end if
