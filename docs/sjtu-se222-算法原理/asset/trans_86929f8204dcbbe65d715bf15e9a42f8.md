

## S3: 加权合并

Find(p, q)。检查 p 和 q 是否具有相同的根。

```
Union(p, q):
    if size[root(p)] <= size[root(q)]
        then id[root(p)] = id[root(q)]
    else id[root(q)] = id[root(p)]
```
