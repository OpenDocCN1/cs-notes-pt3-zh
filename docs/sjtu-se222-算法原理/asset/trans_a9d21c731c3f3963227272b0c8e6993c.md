## 流网络

![](img/a8f1b433a70f1e5c410c8b43e41b650e_838_0.png)

*流网络* 是

- 1. 有向图 G<V,E>，
- 2. 边上的权重表示 *容量*。
- 3. 两个特殊顶点：s 和 t，表示 *源点* 和 *汇点*。

定义: *st-流* 函数 f: V×V→R 是 *st-流 (流)* 如果满足：

∀ u,v∈V. f(u,v) = -f(v,u).
∀ u,v∈V. f(u,v) ≤ c(u,v).
∀ u ∈ V\{s,t}. Σv∈V f(u,v) = 0.
∀ v∈V. f(v,v)=0.

流 f 的 *值*：

|f| = f(s,V) = Σv∈V f(s,v)
|f| ≥ 0

## 最小割

定义: 割
割 {S,T} 是将顶点集 V 分成两个子集 S 和 T 的划分，使得 s ∈ S 且 t ∈ T。
割 {S,T} 的容量，记为 c(S,T)，为
c(S,T) = Σ_{u∈S, v∈T} c(u,v)

![](img/a8f1b433a70f1e5c410c8b43e41b650e_840_0.png)

引理
对于任意割 {S,T} 和流 f，|f| = f(S,T) ≤ c(S,T)。
