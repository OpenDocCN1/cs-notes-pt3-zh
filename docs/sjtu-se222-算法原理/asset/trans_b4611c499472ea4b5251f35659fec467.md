

## Dijkstra 三路划分
- 设 v 为划分项 a[lo]。
- 从左到右扫描 i。
  - (a[i] < v): 将 a[lt] 与 a[i] 交换并同时递增 lt 和 i
  - (a[i] > v): 将 a[gt] 与 a[i] 交换并递减 gt
  - (a[i] == v): 递增 i

## Bentley-McIlroy 三路划分

重复直到 i 和 j 指针交叉。

- 从左到右扫描 i，只要 a[i] < a[lo]。
- 从右到左扫描 j，只要 a[j] > a[lo]。
- 将 a[i] 与 a[j] 交换。
- 如果 a[i] == a[lo]，将 a[i] 与 a[p] 交换并递增 p。
- 如果 a[j] == a[lo]，将 a[j] 与 a[q] 交换并递减 q。
