

## Bentley-McIlroy 三路划分

重复直到 *i* 和 *j* 指针交叉。

- 从左到右扫描 *i*，只要 `a[i] < a[lo]`。
- 从右到左扫描 *j*，只要 `a[j] > a[lo]`。
- 交换 `a[i]` 与 `a[j]`。
- 如果 `a[i] == a[lo]`，交换 `a[i]` 与 `a[p]` 并递增 `p`。
- 如果 `a[j] == a[lo]`，交换 `a[j]` 与 `a[q]` 并递减 `q`。
