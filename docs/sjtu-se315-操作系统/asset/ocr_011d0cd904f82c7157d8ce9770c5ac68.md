# Example: CPUState

```
static struct {
    uint32 GPR[16];
    uint32 LR;
    uint32 PC;
    int    IE;
    int    IRQ;
} CPUState;

void CPU_CLI(void)
{
    CPUState.IE = 0;
}

void CPU_STI(void)
{
    CPUState.IE = 1;
}
```

+   - Goal for CPU virtualization techniques
+     - Process normal instructions as fast as possible
+     - Forward privileged instructions to emulation routines
