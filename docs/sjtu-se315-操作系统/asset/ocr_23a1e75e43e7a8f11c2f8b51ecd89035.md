# Recap: Basic Implementation

```
writerStart() {
    lock(lockRW);

    while(numReaders > 0||
        numWriters >0){
        wait(lockRW,condRW);
    };

    numWriters++;

    unlock(lockRW);
}
```

```
writerFinish() {
    lock(lockRW);

    numWriters--;

    broadcast(lockRW,condRW);

    unlock(lockRW);
}
```
