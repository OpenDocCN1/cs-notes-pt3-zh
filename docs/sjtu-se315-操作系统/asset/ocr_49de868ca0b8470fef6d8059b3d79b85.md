# Softirqs

+   - **Statically** allocated: specified at kernel compile time
+   - Limited number:
+     *Priority*  *Type*
+     0  High-priority tasklets
+     1  Timer interrupts
+     2  Network transmission
+     3  Network reception
+     4  Block devices
+     5  Regular tasklets

| Priority | Type |
|---|---|
| 0 | High-priority tasklets |
| 1 | Timer interrupts |
| 2 | Network transmission |
| 3 | Network reception |
| 4 | Block devices |
| 5 | Regular tasklets |
