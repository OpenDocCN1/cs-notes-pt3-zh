# Multi-Variable Concurrency Bug Example

```
Thread 1
js_FlushPropertyCache ( ... ) {
    memset ( cache->table, 0, SIZE );
    ...
    cache->empty = TRUE;
}
```

```
Thread 2
js_PropertyCacheFill ( ... ) {
    cache->table[indx] = obj;
    ...
    cache->empty = FALSE;
}
```

Control the order among accesses to any one variable can not guarantee the bug manifestation
