# Recap: Better Implementation

```
readerStart() {
    lock(lockRW);

    while(numWriters > 0){
        wait(lockRW,condRW);
    };

    numReaders++;

    unlock(lockRW);
}
```

```
readerFinish() {
    lock(lockRW);
    numReaders--;
    if(numReaders == 0){
        signal(lockRW,condWR);
    };
    unlock(lockRW);
}
```
