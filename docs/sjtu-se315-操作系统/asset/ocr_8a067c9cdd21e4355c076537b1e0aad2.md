# Early Boards

+   - PIC (Programmable Interrupt Controller)
+     - picirq.c
+     - 8259A chip
+     - Each PIC handles 8 interrupts, and multiplex them on the interrupt pin of the processor
+     - PIC can be cascaded
+       - Master: 0 to 7
+       - Slave: 8 to 15
+     - Read timer.c for timer init
