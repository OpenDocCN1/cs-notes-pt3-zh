# Cache simulation

+   - Approximates an AMD Athlon hierarchy
+     - I1, D1, inclusive L2
+     - Write-allocate
+     - LRU replacement
+   - Each cache is command-line configurable:
+     - Cache size
+     - Line size
+     - Associativity
+   - On x86/AMD64 can use CPUID to auto-detect these parameters
+   - Simulation can be replaced easily
