# Lockset

```
connect() {
  lock(a);      { a }
  open_conn();  { a }
  send();       { a, b }, { a, c }
}
```

```
{ a, b }, { a, c }
```

summary:
{ a } ➔ { a, b }, { a, c }

```
open_conn() {
  if (x)          { a }
    lock(b);      { a, b }
  else            { a }
    lock(c);      { a, c }
}

{ a, b }, { a, c }
```
