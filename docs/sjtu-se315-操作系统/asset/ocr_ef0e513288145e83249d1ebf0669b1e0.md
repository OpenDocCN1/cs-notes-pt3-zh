# Xv6 FS Design

+   - Implements a minimal Unix file system interface
+     - Superblock
+     - Inode
+     - Dentry
+   - Limitations
+     - not pay attention to file system layout
+     - doesn't do any disk scheduling.
+     - Its cache is write-through
+       - simplifies keeping disk data structures consistent
+       - bad for performance.
