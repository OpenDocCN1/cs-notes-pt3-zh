## 半虚拟化（例如 Xen）

+   - 修改操作系统，让操作系统与 VMM 协作
+     - 让操作系统运行在 Ring1，用户应用程序运行在 Ring3
+     - 将敏感指令改为对 VMM 的显式调用
+     - 无需捕获和模拟

## 虚拟化 CR3/页表

+   - 术语：现在有 3 种地址
+     - GVA->GPA->HPA（客户机虚拟地址、客户机物理地址、主机物理地址）
+     - 客户机 VM 的页表包含客户机物理地址
+     - 硬件页表必须指向主机物理地址
+   - 将 CR3 设置为指向客户机页表是行不通的
+     - 客户机 VM 中的进程可能会访问主机物理地址 0~1GB
+     - 但这些 HPA 可能不属于该客户机 VM
