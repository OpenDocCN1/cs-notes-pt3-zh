# 为什么操作系统重要？

这里的操作系统术语

广义定义，包括 hypervisor、操作系统、
运行时环境

操作系统管理并隐藏应用程序的资源

- 隐藏繁琐复杂的低级细节
- 为应用程序提供执行环境

在许多情况下，操作系统决定应用程序性能

许多应用程序花费大量时间在系统软件中
