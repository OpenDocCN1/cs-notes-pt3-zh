

## 主文件表

- 主文件表 (MFT)
  - 一个关系型数据库
  - 行：文件记录
  - 列：文件属性
  - 包含每个文件的至少一个条目
- 元数据文件
  - 描述 MFT
  - MFT 的前 16 条记录为元数据文件
  - 以美元符号开头。例如 $Mft, $MftMirr, $LogFile, ...

## MFT 中的元数据文件

| 系统文件 | 名称 | Rec | 文件用途 |
|---|---|---|---|
| 主文件表 | $Mft | 0 | 包含 NTFS 卷上每个文件和文件夹的文件记录。 |
| 主文件表镜像 | $MftMirr | 1 | MFT 前四条记录的重复映像 |
| 日志文件 | $LogFile | 2 | 用于快速恢复而恢复元数据 |
| 卷文件 | $Volume | 3 | 包含有关卷的信息 |
| 属性定义 | $AttrDef | 4 | 列出属性名称、编号和描述 |
| 根文件名索引 | . | 5 | 根文件 |
| 簇位图 | $Bitmap | 6 | 通过显示空闲和未使用的簇来表示卷。 |

## MFT 区域

- MFT 包含卷上每个文件和文件夹的记录
  - 文件和文件夹记录各为 1KB
- MFT 区域
  - MFT 的专用使用
  - 防止碎片化
  - 默认占用卷的 12.5%
  - 按需分配额外的 MFT 区域

## NTFS 文件记录属性

- 文件属性
  - 将每个文件和文件夹视为一组文件属性
  - 驻留属性 vs. 非驻留属性
    - 小文件和文件夹完全包含在文件 MFT 记录内 (*通常，小于 900 字节*)
  - 类型：
    - 标准信息：访问模式、时间戳、链接计数 …
    - 属性列表：所有非驻留属性的位置
    - 文件名：长文件名和短文件名
    - 数据 / 索引：文件的数据或文件夹的索引
    - 对象 ID：卷唯一的标识符
    - …

## NTFS 文件记录属性

- 文件夹索引
  - 文件夹记录包含索引信息（目录项）
  - 大文件夹采用组织良好的 B 树结构
- 最后访问时间
  - 最新的 LAT 始终存储在内存中
  - 写入磁盘
    - 位置：文件的属性 AND 文件的目录项
    - 时间：超过一小时 OR 更新其他文件属性

## 启动过程

- **BIOS** 和 CPU 启动加电自检
- BIOS 找到启动设备
- BIOS 加载第一个物理扇区 (**MBR**)
- 转移 C...
- MBR 扫描...
- 加载活动分区的 **Boot Sector** 副本
- 将 CPU 执行转移到 Boot Sector

## 文件命名

- Windows Server 2003 中的文件名
  - 支持长文件名，最长 255 个字符
  - NTFS 生成一个 8.3 短文件名
- 如何生成短文件名
  - 删除所有不支持的字符 *(例如 空格)*
  - 删除所有多余的句点 *(abc.def.txt)*
  - 将文件名截断为六个字符并附加波浪号(~)和一个数字
  - 将文件名和扩展名中的所有字符转换为大写
  "This is test 1.txt" -> "THISIS~1.TXT"
