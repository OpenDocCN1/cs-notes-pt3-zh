  - 其他的只是等待轮到自己

  - 将缓冲区 b 添加到队列末尾

## Recap: Free-Space List Bit Vector

- 将空闲块列表表示为位向量：
  - 111111111111111001110101011101111...
  - 如果位 i = 0 则块 i 是空闲的，否则已被分配
- 使用简单但这可能是一个很大的向量：
  - 160GB 磁盘 -> 40M 块 -> 5MB 的位
  - 然而，如果空闲扇区在磁盘上均匀分布
  - 那么在找到一个“0”之前必须扫描的位的期望数量是 n/r，其中
    - n = 磁盘上的总块数
    - r = 空闲块数
  - 如果磁盘已使用 90%，那么平均需要扫描的位数为 10，与磁盘大小无关
