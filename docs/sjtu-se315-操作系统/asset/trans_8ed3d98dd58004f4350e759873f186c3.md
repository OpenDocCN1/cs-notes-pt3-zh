

## 折叠现象的理解

关键点：带有修改缓存行的读取必须从持有者那里获取数据
一致性消息按顺序处理

锁持有者修改缓存，该缓存持有锁

等待者正在尝试读取锁

它们从锁持有者那里获取锁的值
更多的读取者意味着下一个锁持有者需要等待更长时间才能获得锁

分配一个票号
读取当前票号并自旋

```
void spin_lock(spinlock_t *lock)
{
    t = atomic_inc(lock->next_ticket);
    while (t != lock->current_ticket)
        ; /* Spin */
}
```

```
void spin_unlock(spinlock_t *lock)
{
    lock->current_ticket++;
}
```

```
struct spinlock_t {
    int current_ticket;
    int next_ticket;
}
```
