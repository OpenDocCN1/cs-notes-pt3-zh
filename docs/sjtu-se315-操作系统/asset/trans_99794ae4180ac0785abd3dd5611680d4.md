

## 从列表到B树

- ext4和NTFS将目录编码为B树，以将查找时间优化至O(log N)
- B树是一种为磁盘存储优化的平衡树
  - 条目按排序顺序存储在块中
- 假设条目*i*和*j*位于树的根节点中
  - 根节点必须有3个子节点，因为它有2个条目
  - 三个子组分别包含条目*a* < *i*、*i* < *a* < *j*和*a* > *j*

## B树示例

  - H代表哈希（有时称为B+树）

## ext4：优点与缺点

- 优点——ext4（以及NTFS）支持：
  - 我们所需的所有基本文件系统功能
  - 相比ext3块组的性能提升
  - 通过extent和B树目录文件带来的额外性能增益
- 缺点：
  - 下一代文件系统拥有更出色的特性
    - 写时复制语义（btrfs和ZFS）

## FAT文件系统

## 簇与扇区

- 扇区：磁盘上的最小存储单元
  - 512字节
- 簇：分配给文件的最小磁盘空间单位
  - 数据簇位于分区元数据之后
  - 簇大小随卷大小不同而变化

| 卷大小 | FAT32簇大小 |
|---|---|
| <32MB | 不支持 |
| 32MB ~ 64MB | 512字节 |
| 65MB ~ 128MB | 1KB |
| 129MB ~ 256MB | 2KB |
| 257MB ~ 8GB | 4KB |
| 8GB ~ 16GB | 8KB |
| 16GB ~ 32GB | 16KB |

默认FAT簇大小

## FAT卷的布局

| 引导扇区 | 保留扇区 | FAT 1 | FAT 2（副本） | 根文件夹 | 其他文件夹和所有文件 |

- 引导扇区
  - 卷的布局
  - 文件系统结构
  - 引导代码

- 根文件夹
  - 描述分区根目录下的文件和文件夹

- FAT 1
  - 原始FAT

- FAT 2（副本）
  - FAT的备份副本

- 其他文件夹和所有文件
  - 包含文件系统内文件和文件夹的数据。

- 存储文件系统的基本信息
  - FAT版本、引导文件位置
  - 总块数
  - FAT中根目录的索引

- 文件分配表（FAT）
  - 标记哪些块是空闲的或正在使用
  - **链表结构**用于管理大文件

- 存储文件和目录数据
  - 每个块大小固定（4KB – 64KB）
  - 文件可能跨越多个块

## FAT引导扇区

- FAT引导扇区
  - 位于每个分区的第一个逻辑扇区
  - 格式化卷时创建
  - 以2字节扇区标记结尾（始终为0x55AA）
- 组成部分
  - x86架构CPU跳转指令
  - 原始设备制造商标识（OEM ID）
  - BIOS参数块（BPB）
  - 扩展BPB
  - 可执行引导代码

## 引导扇区的组成

![](img/53ee1e3b0eba43505c7d530851f32f6f_572_0.png)

- 跳转指令：跳过接下来的若干非可执行字节
- OEM ID：一串字符
  - 格式化卷的操作系统的名称和版本号
- BPB与扩展BPB：卷的信息
  - 每扇区字节数、每簇扇区数、FAT数量、根目录项数、介质描述符、每FAT扇区数……
- 引导代码：启动操作系统的可执行代码
- 标记：引导扇区的结尾

## FAT 1与FAT 2

- 文件分配表
  - 将所有簇标识为：
    - 未使用、被文件占用的簇、坏簇、
      文件中的最后一个簇
  - FAT 2用于一致性检查程序

## FAT根文件夹

- FAT根文件夹结构

| 根文件夹条目 | 大小 | 描述 |
|---|---|---|
| 名称 | 11B | 8.3格式的名称 |
| 属性字节 | 1B | 关于条目的信息（例如存档、系统、隐藏和只读） |
| 创建时间与日期 | 5B | 文件创建的时间和日期 |
| 最后访问日期 | 2B | 文件最后访问的日期 |
| 最后修改时间与日期 | 4B | 文件最后修改的时间和日期 |
| 起始簇 | 2B | 文件分配表中的起始簇号 |
| 文件大小 | 4B | 文件的大小 |
