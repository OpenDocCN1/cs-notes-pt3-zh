## 内存模型

- 8086：16 位微处理器
  - 实模式：*物理地址 = 16 \* 段 + 偏移量*
  - 空间：64KB
- 外部地址扩展到 20 位
  - 空间：1MB
  - 额外的 4 位来自*段寄存器*
    - CS：代码段，用于 EIP
    - SS：栈段，用于 SP 和 BP
    - DS：数据段，用于通过其他寄存器进行加载/存储
    - ES：另一个数据段，字符串操作的目的地
    - *例如 CS=f000 IP=fff0 => 地址：fffff*

## 内存模型

- 80386：32 位数据和总线地址
  - 保护模式
- 现在：向 64 位地址过渡
- 向后兼容：
  - 以 16 位实模式启动，然后切换到 32 位保护模式
    - 参见：*boot/boot.S*
