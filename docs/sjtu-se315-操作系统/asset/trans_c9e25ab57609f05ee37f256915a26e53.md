## APIC、IO-APIC、LAPIC

- 高级 PIC（APIC）用于 SMP 系统
  - 用于所有现代系统
  - 中断通过系统总线“路由”到 CPU
  - IPI：处理器间中断
- 局部 APIC（LAPIC）与“前端” IO-APIC 的区别
  - 设备连接到前端 IO-APIC
  - IO-APIC 通过总线与局部 APIC 通信
- 中断路由
  - 允许广播或选择性路由中断
  - 能够分配中断处理负载
  - 路由到最低优先级进程
    - 特殊寄存器：任务优先级寄存器（TPR），即锁定
  - 若优先级相等则仲裁（轮询）

## 中断优先级

- 当不同类型中断（即软件、NMI、INTR 或异常）同时发生时，优先级最高的一个先被处理。Intel 微处理器使用以下优先级顺序：

| 中断类型 | 优先级 |
|---|---|
| 除法错误中断，INT n，INT0 | 最高 |
| NMI | ↕ |
| INTR | |
| TRAP 标志（单步） | 最低 |

## 为设备分配 IRQ

- IRQ 分配取决于硬件
  - 有时是硬连线的，有时是物理设置的，有时是可编程的
  - PCI 总线通常在启动时分配 IRQ
- 一些 IRQ 由架构固定
  - IRQ0：间隔定时器
  - IRQ2：8259A 的级联引脚
- Linux 设备驱动程序在设备打开时请求 IRQ
  - 注意：对于动态加载的驱动程序尤其有用，例如 USB 或 PCMCIA 设备
  - 两个不同时使用的设备可以共享一个 IRQ，即使硬件不支持同时共享

## 为 IRQ 分配向量

- 向量：中断描述符表中的索引（0-255）
- 向量通常为 IRQ# + 32
  - 32 以下保留给不可屏蔽中断和异常
  - 可屏蔽中断可按需分配
  - 向量 128 用于系统调用
  - 向量 251-255 用于 IPI

## 最大化并行性

- 你希望所有 I/O 设备尽可能保持忙碌
- 通常，中断表示操作的结束；应尽快发出另一个请求
- 大多数设备不会干扰彼此的数据结构；没有理由屏蔽其他设备
