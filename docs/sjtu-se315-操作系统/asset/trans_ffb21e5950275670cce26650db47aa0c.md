## 主机架构权衡

- 优点
  - 如同应用程序一样安装
    - 无需磁盘分区
    - 虚拟磁盘是主机文件系统上的文件
    - 无需主机重启
  - 如同应用程序一样运行
    - 使用主机调度器
- 缺点
  - I/O 路径缓慢
    - 需要世界切换
  - 依赖主机调度
    - 可能不适合密集型虚拟机工作负载

## 超visor

- 硬件支持的单用途监视器
- 特征
  - 体积小
  - 在特殊硬件模式下运行
  - 客户操作系统在正常特权级别运行
- 用途
  - 安全性
  - 系统管理
  - 容错

## CPU 虚拟化

## 回顾：CPU 组织

- 指令集架构 (ISA)
  定义：
  - 程序员可见的状态
    - 寄存器和内存
  - 操作状态的指令
- ISA 通常分为 2 部分
  - 用户 ISA
    - 主要用于计算
  - 系统 ISA
    - 主要用于系统资源管理
