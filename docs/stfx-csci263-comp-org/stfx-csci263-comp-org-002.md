# 002：数制与布尔代数入门





在本节课中，我们将要学习数字系统（数制）的基础知识，包括二进制和十六进制，以及布尔代数的核心概念。理解这些是学习计算机如何表示和处理数据的基石。



## 数制基础

上一节我们介绍了课程概述，本节中我们来看看数字系统是如何工作的。我们最熟悉的是十进制（基数为10），它使用0到9这十个符号。每个数字的位置决定了它的值，这被称为“位值”。





例如，数字 **123** 可以分解为：
*   1 × 10² = 100
*   2 × 10¹ = 20
*   3 × 10⁰ = 3
总和为 100 + 20 + 3 = **123**。



这个模式适用于任何基数。在二进制（基数为2）中，我们只使用0和1两个符号，位值是2的幂次方。


## 二进制详解


理解了十进制的位置概念后，二进制就变得简单了。它的位值从右向左依次是1、2、4、8、16……，即2的幂。


考虑二进制数 **1010**。它的计算方式是：
*   最右边的0：0 × 2⁰ = 0
*   向右第二位1：1 × 2¹ = 2
*   向右第三位0：0 × 2² = 0
*   最左边的1：1 × 2³ = 8
总和为 0 + 2 + 0 + 8 = **10**（十进制）。

一个有趣的应用是，你可以用一只手以二进制数到31。每个手指代表一个位值（1, 2, 4, 8, 16），弯曲的手指代表1，伸直的代表0。


## 十六进制介绍


除了二进制，计算机科学中另一个常用的系统是十六进制（基数为16）。它使用16个符号：0-9 和 A-F（其中A=10, B=11, ..., F=15）。


使用大于10的基数时，我们需要额外的符号，字母A-F正好满足这个需求。在十六进制中，**10** 表示的是十进制数16（1×16¹ + 0×16⁰）。

例如，十六进制数 **7B** 转换为十进制：
*   B 代表 11：11 × 16⁰ = 11
*   7 代表 7：7 × 16¹ = 112
总和为 11 + 112 = **123**。



## 数制间的转换

我们经常需要在不同进制间转换数字，尤其是转换为人类熟悉的十进制。



**从任意进制转换为十进制**：通用公式是，对于一个基数为B的数字 `D_n ... D_2 D_1 D_0`，其十进制值为：
`值 = D_n × B^n + ... + D_2 × B² + D_1 × B¹ + D_0 × B⁰`



**从十进制转换为其他进制**：一个常用的方法是“除基取余法”。要将十进制数123转换为二进制，不断除以2并记录余数：
1.  123 ÷ 2 = 61 ... 余 **1**
2.  61 ÷ 2 = 30 ... 余 **1**
3.  30 ÷ 2 = 15 ... 余 **0**
4.  15 ÷ 2 = 7 ... 余 **1**
5.  7 ÷ 2 = 3 ... 余 **1**
6.  3 ÷ 2 = 1 ... 余 **1**
7.  1 ÷ 2 = 0 ... 余 **1**
将余数从下往上排列，得到二进制数 **1111011**。


## 二进制与十六进制的快捷转换



当两个进制基数成幂关系时（如2⁴=16），转换会非常简便。四位二进制数正好可以表示一位十六进制数。

以下是二进制到十六进制的快速对照：



| 二进制 | 十六进制 |
| :----- | :------- |
| 0000   | 0        |
| 0001   | 1        |
| 0010   | 2        |
| 0011   | 3        |
| 0100   | 4        |
| 0101   | 5        |
| 0110   | 6        |
| 0111   | 7        |
| 1000   | 8        |
| 1001   | 9        |
| 1010   | A        |
| 1011   | B        |
| 1100   | C        |
| 1101   | D        |
| 1110   | E        |
| 1111   | F        |


转换时，只需将二进制数从右向左每四位一组，直接替换为对应的十六进制符号即可。例如：
二进制 `0111 1011` -> 十六进制 **7B**。

## 布尔代数入门



了解了数字的表示后，我们来看看计算机用于逻辑运算的基础——布尔代数。布尔代数处理的是布尔值，它只有两种状态：**真（True）** 或 **假（False）**。在电路中，它们常表示为 **1** 或 **0**、**高电平** 或 **低电平**。


以下是三个基本的布尔运算符：





**NOT（非）**：这是一个一元运算符，它对单个布尔值取反。
*   `NOT True = False`
*   `NOT False = True`
在逻辑表达式中常用符号 `¬A` 或 `!A` 表示。

**AND（与）**：这是一个二元运算符，当且仅当两个输入都为真时，结果才为真。
*   `True AND True = True`
*   `True AND False = False`
*   `False AND True = False`
*   `False AND False = False`
在逻辑表达式中常用符号 `A ∧ B` 表示。

**OR（或）**：这也是一个二元运算符，只要至少有一个输入为真，结果就为真。
*   `True OR True = True`
*   `True OR False = True`
*   `False OR True = True`
*   `False OR False = False`
在逻辑表达式中常用符号 `A ∨ B` 表示。



这些运算符是构建所有数字逻辑电路（如加法器、存储器）的基础。



## 总结



本节课中我们一起学习了计算机科学中最核心的两种表示系统：数制和布尔代数。
*   我们探讨了**二进制**和**十六进制**的原理、表示方法以及它们之间高效的转换技巧。
*   我们学习了**布尔代数**的三种基本运算（NOT, AND, OR），理解了真值（1/0）如何通过逻辑运算符进行计算。
