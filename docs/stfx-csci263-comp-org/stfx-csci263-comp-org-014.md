# 014：全加器与补码

## 概述
在本节课中，我们将要学习如何通过全加器构建多位数加法器，并探讨在计算机中表示负数的方法。我们将从简单的符号位表示法开始，逐步分析其问题，最终引出并深入理解现代计算机广泛使用的**补码**表示法。

## 全加器与加法器链

上一节我们介绍了半加器，它无法处理来自低位的进位。本节中我们来看看功能更完整的全加器。

全加器有三个输入：两个待相加的位 `A` 和 `B`，以及一个来自低位的进位输入 `C_in`。它产生两个输出：和 `S` 以及向高位的进位输出 `C_out`。

以下是全加器的逻辑：
*   **和位 `S`**：当输入中 `1` 的个数为奇数时，和为 `1`；为偶数时，和为 `0`。这可以用异或运算表示：`S = A XOR B XOR C_in`。
*   **进位位 `C_out`**：当至少有两个输入为 `1` 时，产生进位。其逻辑表达式可以简化为：`C_out = (A AND B) OR ((A XOR B) AND C_in)`。

全加器的关键优势在于其**可扩展性**。由于它同时具备进位输入和进位输出，我们可以将多个全加器串联起来，构建任意位宽的加法器。

以下是构建一个4位加法器的步骤：
1.  将第一个全加器的进位输入 `C_in` 置为 `0`（用于最低位加法）。
2.  将其进位输出 `C_out` 连接到下一个全加器的进位输入 `C_in`。
3.  重复此过程，将四个全加器首尾相连。
4.  最终，整个4位加法器也会产生一个进位输出，用于指示最高位的溢出。

## 负数的表示问题

现在我们已经能够对二进制数进行加法运算，但到目前为止，我们只处理了**正整数**（无符号整数）。计算机显然也需要处理负数。

一个直观的想法是使用**符号位**：将最高位（最左侧的位）专门用来表示符号，`0` 代表正数，`1` 代表负数，其余位表示数值的大小（称为**原码**表示法）。

例如，在一个4位系统中：
*   `0011` 表示 `+3`
*   `1011` 表示 `-3`（这里假设最高位 `1` 是符号位）

然而，符号位表示法存在几个严重问题：
1.  **存在 `+0` 和 `-0`**：`0000` 和 `1000` 都表示零，这浪费了一个宝贵的编码空间。
2.  **算术运算复杂**：直接对带有符号位的数字进行加法，结果不正确。例如，`+3` (`0011`) 加上 `-3` (`1011`) 按照二进制加法得到 `1110`（即 `-6` 或 `14`，取决于解释），而不是 `0`。
3.  **硬件设计复杂**：需要额外的电路来判断符号并决定进行加法还是减法。

为了解决这些问题，我们需要一种更好的负数编码方案。

## 补码：一种优雅的解决方案

为了克服符号位的缺点，计算机科学家引入了**补码**。补码的生成规则非常简单：要得到一个负数 `-X` 的补码表示，只需对 `X` 的二进制表示执行以下两步操作：
1.  **按位取反**（得到反码）。
2.  **然后加 `1`**。

用公式描述，对于一个 `n` 位的数 `X`，其补码表示为：`-X = (~X) + 1`，其中 `~` 表示按位取反。

让我们看一个4位系统的例子：
*   `+3` 的二进制是 `0011`。
*   要得到 `-3`：
    *   按位取反：`1100`
    *   再加 `1`：`1101`
    *   因此，`-3` 的补码是 `1101`。

补码表示法具有以下卓越特性：
*   **唯一的零**：`0000` 的补码是 `1111 + 1 = (1)0000`，忽略最高位溢出后仍是 `0000`。`-0` 消失了。
*   **自然的算术运算**：**补码的神奇之处在于，使用相同的加法器电路，无需任何修改，就可以直接对正数和负数进行加法（实质上是加减法）运算**。例如：
    *   `3 + (-3)` = `0011 + 1101` = `(1)0000` = `0`（忽略进位）。
*   **表示范围不对称**：对于 `n` 位补码，可表示的范围是 `[-2^(n-1), 2^(n-1)-1]`。例如，4位补码的范围是 `-8` 到 `+7`。负数比正数多一个（因为 `0` 占用了正数区间的一个编码）。

为了帮助你理解补码的数值，以下是其转换规律：
*   **最高位权重为负**：在补码中，最高位（符号位）的权重是 `-2^(n-1)`。对于4位数，最高位权重是 `-8`。
*   **快速计算数值**：对于一个补码数，如果最高位是 `0`，其值就是后面二进制位的正值。如果最高位是 `1`，其值等于 `-2^(n-1) + (后面二进制位的正值)`。
    *   例如：`1101` = `-8 + (4+1)` = `-3`。

## 总结
本节课中我们一起学习了计算机算术的核心基础。
1.  我们首先回顾了**全加器**的原理，并了解了如何通过级联全加器来构建一个多位的二进制加法器。
2.  接着，我们探讨了在计算机中表示负数的需求，并分析了简单的**符号位（原码）** 表示法所带来的问题，如存在两个零和算术运算的复杂性。
3.  最后，我们引入了**补码**这一关键概念。补码通过 **“按位取反再加1”** 的规则来表示负数，它完美地解决了原码的问题，使得**使用同一套加法器电路就能无缝处理正数和负数的加减法运算**，这极大地简化了计算机硬件的设计。补码是现代计算机中整数表示的标准方式。
