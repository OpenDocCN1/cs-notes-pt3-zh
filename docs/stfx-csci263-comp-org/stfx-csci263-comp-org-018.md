# 018：七段数码管与输出系统

![](img/04edf1e97227756b908d73a9ed2b3b62_1.png)

在本节课中，我们将学习如何为我们的计算机设计一个易于理解的输出系统。我们将探讨如何使用七段数码管来显示十进制数字，并解决从二进制数据到显示模式转换的核心问题。

## 数据移动与计算回顾

上一节我们介绍了ALU、寄存器和RAM如何协同工作。本节中我们来看看如何通过控制信号移动数据并执行计算。

我们之前构建的系统包含一个ALU（可执行加法和减法）、两个寄存器、一个RAM和一个地址寄存器。

![](img/04edf1e97227756b908d73a9ed2b3b62_1.png)

为了演示，让我们执行一个简单的操作。这个过程可能有些繁琐，因为它涉及手动输入数据。首先，我们将地址寄存器设置为0，即内存地址0。虽然电路启动时可能默认为0，但在实践中，我们不应假设初始状态。

![](img/04edf1e97227756b908d73a9ed2b3b62_3.png)

![](img/04edf1e97227756b908d73a9ed2b3b62_5.png)

以下是操作步骤：
1.  将值0放入地址寄存器，并发送时钟脉冲。
2.  将值3放入RAM的数据总线，并执行“Ram in”和时钟脉冲操作，将3存入地址0。
3.  将地址寄存器改为1，并发送时钟脉冲。
4.  将值10放入RAM的数据总线，并执行“Ram in”和时钟脉冲操作，将10存入地址1。
5.  现在，地址0存储着3，地址1存储着10。

接下来，我们将这两个值相加。首先，将地址切回0，执行“Ram out”将值3输出到数据总线，然后执行“B in”和时钟脉冲，将3存入B寄存器。接着，将地址切回1，执行“Ram out”将值10输出到数据总线，然后执行“A in”和时钟脉冲，将10存入A寄存器。此时，ALU显示结果应为13（A+B）。

最后，我们将结果13存入内存地址2。将地址寄存器设为2，发送时钟脉冲。然后将ALU的输出（13）放到数据总线上，执行“Ram in”和时钟脉冲，将13存入地址2。

![](img/04edf1e97227756b908d73a9ed2b3b62_7.png)

![](img/04edf1e97227756b908d73a9ed2b3b62_9.png)

我们也可以尝试减法，例如计算10-3。将ALU设置为减法模式，结果应为7。我们可以将这个结果存入另一个内存地址。

![](img/04edf1e97227756b908d73a9ed2b3b62_3.png)

操作完成后，可以右键点击RAM组件进行验证。

![](img/04ed1e97227756b908d73a9ed2b3b62_5.png)

这个演示的关键在于，我们仅仅通过操控高/低电平信号，就实现了数据的移动和基本的加减法计算，这就是计算的本质。这些信号具有不同的含义：有些是实际的数据（如数字3和10），有些是指令数据（如要访问的内存地址），还有一些是控制信号（用于决定哪个组件进行输入或输出）。它们虽然都是0和1，但根据使用场景的不同，意义完全不同。

![](img/04edf1e97227756b908d73a9ed2b3b62_11.png)

![](img/04edf1e97227756b908d73a9ed2b3b62_13.png)

![](img/04edf1e97227756b908d73a9ed2b3b62_7.png)

## 引入输出需求：七段数码管

到目前为止，我们的输出只是数据总线底部的二进制模式。虽然二进制没有错，但对于人类来说，直接解读像“01001011”这样的模式并快速理解其代表的十进制数值（例如75）是困难的。因此，我们需要一个更友好的输出方式，这就是七段数码管。

七段数码管可以清晰地显示十进制数字。此外，当前数据总线上的值是瞬态的，会随着每个时钟脉冲改变。为了稳定地输出一个值，我们需要像使用地址寄存器一样，使用一个专用的输出寄存器来保存要显示的值。

![](img/04edf1e97227756b908d73a9ed2b3b62_16.png)

然而，直接将二进制数输出到七段数码管会遇到问题。

## 七段数码管的工作原理

一个七段数码管实际上由8个段组成（7个数字段加1个小数点），通常标记为A、B、C、D、E、F、G、H（H代表小数点）。每个段独立控制，通电则亮，断电则灭。

![](img/04edf1e97227756b908d73a9ed2b3b62_18.png)
![](img/04edf1e97227756b908d73a9ed2b3b62_19.png)

![](img/04edf1e97227756b908d73a9ed2b3b62_24.png)

![](img/04edf1e97227756b908d73a9ed2b3b62_26.png)

![](img/04edf1e97227756b908d73a9ed2b3b62_27.png)

例如，要显示数字“1”，需要点亮B段和C段；显示数字“8”，则需要点亮A、B、C、D、E、F、G段。

![](img/04edf1e97227756b908d73a9ed2b3b62_29.png)

![](img/04edf1e97227756b908d73a9ed2b3b62_21.png)
![](img/04edf1e97227756b908d73a9ed2b3b62_22.png)

![](img/04edf1e97227756b908d73a9ed2b3b62_31.png)

问题在于，二进制数的位模式与点亮特定段的模式并不直接对应。例如，数字1的8位二进制是 `00000001`。如果我们简单地将这8位信号按顺序连接到A到H，那么只有H段（假设H是最低位）会亮起，这显然不是数字1。因此，我们需要一个**转换器**或**解码器**，将表示数值的二进制代码，转换为控制数码管各段亮灭的显示代码。

![](img/04edf1e97227756b908d73a9ed2b3b62_24.png)

8个段可以产生2^8=256种亮灭组合，但我们只关心其中能形成0-9这10个数字的少数几种组合。

![](img/04edf1e97227756b908d73a9ed2b3b62_33.png)

![](img/04edf1e97227756b908d73a9ed2b3b62_26.png)
![](img/04edf1e97227756b908d73a9ed2b3b62_27.png)

![](img/04edf1e97227756b908d73a9ed2b3b62_35.png)

## 二进制到显示码的映射

![](img/04edf1e97227756b908d73a9ed2b3b62_37.png)

我们需要一个系统来将二进制数（例如数字9的 `00001001`）转换为其对应的七段显示码。这是一个编码到另一种编码的映射过程。我们可以定义一种映射关系，例如，规定输出字节的每一位对应一个段（A为最低位）。

![](img/04edf1e97227756b908d73a9ed2b3b62_39.png)

![](img/04edf1e97227756b908d73a9ed2b3b62_41.png)

以下是部分数字的映射示例（十六进制形式）：
*   数字 0 → 显示码 `0x3F` (二进制 `00111111`，点亮A,B,C,D,E,F段)
*   数字 1 → 显示码 `0x06` (二进制 `00000110`，点亮B,C段)
*   数字 7 → 显示码 `0x07` (二进制 `00000111`，点亮A,B,C段)。有趣的是，数字7的显示码恰好也是7，但这只是我们特定映射规则下的巧合。

![](img/04edf1e97227756b908d73a9ed2b3b62_29.png)

![](img/04edf1e97227756b908d73a9ed2b3b62_43.png)

## 处理多位数与负数

![](img/04edf1e97227756b908d73a9ed2b3b62_45.png)

我们的系统使用8位数，可以表示0-255（或-128到127）的范围。一个数码管只能显示一位数字，因此要显示像“123”这样的数，我们需要三个数码管。这意味着，一个8位的输入值，需要映射到3个8位的显示码输出（共24位），分别对应百位、十位和个位。

![](img/04edf1e97227756b908d73a9ed2b3b62_31.png)

如果考虑使用二进制补码表示的负数，我们还需要第四个符号位（例如一个单独的段来显示负号“-”）。这样，总共可能需要最多25位的输出模式（3*8位数字码 + 1位符号码）。

## 实现映射：从PLA到查找表

![](img/04edf1e97227756b908d73a9ed2b3b62_56.png)

如何实现这种映射呢？我们之前学过的**可编程逻辑阵列（PLA）** 理论上可以完成任意输入到输出的逻辑映射。对于4位输入到8位输出（一个数码管）的小型映射，PLA是可行的。

![](img/04edf1e97227756b908d73a9ed2b3b62_58.png)

![](img/04edf1e97227756b908d73a9ed2b3b62_35.png)

![](img/04edf1e97227756b908d73a9ed2b3b62_60.png)

![](img/04edf1e97227756b908d73a9ed2b3b62_62.png)

![](img/04edf1e97227756b908d73a9ed2b3b62_63.png)

![](img/04edf1e97227756b908d73a9ed2b3b62_65.png)

但是，PLA的规模随输入位数呈指数级增长。对于8位输入到25位输出的映射，PLA将变得异常庞大和复杂，难以手动构建。

![](img/04edf1e97227756b908d73a9ed2b3b62_67.png)

![](img/04edf1e97227756b908d73a9ed2b3b62_69.png)

![](img/04edf1e97227756b908d73a9ed2b3b62_37.png)

![](img/04edf1e97227756b908d73a9ed2b3b62_71.png)

更好的解决方案是使用**查找表（Look-up Table, LUT）**。查找表本质上是一块预存了所有输入输出对应关系的内存。对于8位输入，有256种可能，我们只需要创建一个有256行的表，每行存储对应的25位输出模式。

![](img/04edf1e97227756b908d73a9ed2b3b62_39.png)

在Digital仿真软件中，可以方便地使用查找表组件。我们可以手动填写这个256x25的表，但这同样非常繁琐。更实际的方法是**编写一个程序来生成这个查找表的内容文件（通常是.hex格式）**。程序根据我们定义的转换规则（如如何将十进制数分解为三个数字，再分别查表转换为段码），自动计算出所有256种输入对应的25位输出值。

![](img/04edf1e97227756b908d73a9ed2b3b62_73.png)

![](img/04edf1e97227756b908d73a9ed2b3b62_41.png)

![](img/04edf1e97227756b908d73a9ed2b3b62_75.png)

![](img/04edf1e97227756b908d73a9ed2b3b62_77.png)

.hex文件的第一行有固定格式，随后的每一行对应一个输入值的输出模式。通过加载这个由程序生成的.hex文件，查找表就能完整实现我们所需的解码功能。

![](img/04edf1e97227756b908d73a9ed2b3b62_79.png)

![](img/04edf1e97227756b908d73a9ed2b3b62_43.png)

![](img/04edf1e97227756b908d73a9ed2b3b62_81.png)

## 总结

![](img/04edf1e97227756b908d73a9ed2b3b62_83.png)

![](img/04edf1e97227756b908d73a9ed2b3b62_85.png)

本节课中我们一起学习了如何为计算机设计输出系统。我们回顾了通过控制信号在寄存器、ALU和RAM间移动数据的过程。然后，我们引入了七段数码管作为用户友好的输出设备，并指出了直接将二进制数连接到数码管的问题。核心解决方案是建立一个**解码器**，将表示数值的二进制码转换为控制数码管各段亮灭的显示码。对于多位数和负数的显示，需要将单个输入映射到多个输出段码。我们分析了使用可编程逻辑阵列（PLA）的局限性，并确定了使用**查找表（LUT）** 配合程序生成映射文件是实现这一复杂映射的实用且高效的方法。这为我们的计算机提供了清晰的可视化输出能力。
