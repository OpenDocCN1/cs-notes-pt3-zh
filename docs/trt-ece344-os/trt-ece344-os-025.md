# 025：磁盘与持久化存储

![](img/e8076b93d9bf5a1b5182d6b590e34c2d_1.png)

在本节课中，我们将要学习操作系统如何管理持久化存储设备。我们将重点介绍两种现代存储技术：固态硬盘（SSD）的工作原理及其独特约束，以及如何通过磁盘阵列（RAID）技术来提升存储的性能和可靠性。

## 固态硬盘（SSD）的工作原理与约束

上一节我们介绍了持久化存储的重要性。本节中，我们来看看现代计算机中最常见的持久化存储设备——固态硬盘（SSD）。

与使用磁性盘片和机械臂的传统硬盘驱动器（HDD）不同，SSD使用晶体管电路来存储数据。其核心优势在于没有活动部件，因此速度更快、更节能、体积更小。然而，SSD在软件层面有一些独特的操作规则。

从高层次看，一个SSD芯片的组织结构是分层的：
*   **芯片（Die）**：存储所有数据的物理芯片。
*   **平面（Plane）**：一个芯片包含多个平面。
*   **块（Block）**：一个平面包含多个块，**块是擦除操作的最小单位**。
*   **页（Page）**：一个块包含多个页（通常为4KB或8KB），**页是读取和写入操作的最小单位**。

以下是SSD的关键操作特性，用速度公式表示：
*   **读取一个页**：约 **10 微秒**。
*   **写入一个页**：约 **100 微秒**（比读取慢10倍）。
*   **擦除一个块**：约 **1 毫秒**（比写入慢10倍，比读取慢100倍）。

SSD必须遵守两条核心规则，用伪代码描述其约束：
1.  只能向** freshly erased page**（刚被擦除的页）写入数据，无法直接覆盖已有数据的页。
2.  擦除操作只能在**块级别**进行，一次擦除整个块（包含多个页）。

这些规则带来了“写放大”等问题。为了优化性能，SSD自身会进行**垃圾回收**：将某个块中仍在使用（live）的页移动到新擦除的块中，以便回收旧块。操作系统可以通过 **`TRIM` 命令** 通知SSD哪些数据块已不再使用，帮助SSD在后台提前进行擦除，避免在写入时遭遇性能惩罚。

## 磁盘阵列（RAID）技术

到目前为止，我们讨论的都是单个存储设备。但如果单个硬盘损坏，所有数据都会丢失。为了解决这个问题，我们可以使用多个物理磁盘来构建一个逻辑磁盘，这就是**独立磁盘冗余阵列（RAID）**。RAID通过**数据分布**和**冗余**，在**提升性能**和**防止数据丢失**之间进行权衡。以下是几种常见的RAID级别。

### RAID 0：条带卷（仅性能）

![](img/e8076b93d9bf5a1b5182d6b590e34c2d_5.png)

![](img/e8076b93d9bf5a1b5182d6b590e34c2d_7.png)

如果你只追求极致性能，可以使用RAID 0。

以下是RAID 0的特点：
*   **原理**：将数据**分条带**均匀分布到所有磁盘上。
*   **性能**：读写速度接近单盘的N倍（N为磁盘数）。
*   **可靠性**：**任何一块磁盘损坏，都会导致所有数据丢失**。故障点更多。
*   **空间利用率**：所有磁盘空间均可用于存储（例如，两块10TB磁盘可提供20TB空间）。

![](img/e8076b93d9bf5a1b5182d6b590e34c2d_9.png)

### RAID 1：镜像卷（高可靠性）

![](img/e8076b93d9bf5a1b5182d6b590e34c2d_11.png)

![](img/e8076b93d9bf5a1b5182d6b590e34c2d_13.png)

![](img/e8076b93d9bf5a1b5182d6b590e34c2d_15.png)

与RAID 0完全相反，RAID 1追求极高的可靠性。

以下是RAID 1的特点：
*   **原理**：将所有磁盘做成彼此的**完全镜像**（克隆）。
*   **性能**：读性能可达单盘的N倍（可从多个镜像并行读）。写性能与单盘相同（需写入所有磁盘）。
*   **可靠性**：可以容忍**（N-1）** 块磁盘损坏而不丢失数据（只要有一块盘存活即可）。
*   **空间利用率**：极低。总存储空间等于单块磁盘的容量（例如，两块10TB磁盘只能提供10TB可用空间）。

![](img/e8076b93d9bf5a1b5182d6b590e34c2d_17.png)

### RAID 4：带专用校验盘的条带

![](img/e8076b93d9bf5a1b5182d6b590e34c2d_19.png)

RAID 4是一种折中方案，它像RAID 0一样条带化数据，但额外使用一块专用磁盘来存储**奇偶校验（Parity）** 信息，用于数据恢复。

![](img/e8076b93d9bf5a1b5182d6b590e34c2d_21.png)

奇偶校验位通过对其他所有数据盘上对应位进行**异或（XOR）** 运算得到：
`parity = data_disk1 XOR data_disk2 XOR data_disk3 ...`
如果一块数据盘损坏，可以通过存活的数据盘和校验盘重新计算出丢失的数据。

以下是RAID 4的特点：
*   **原理**：数据条带化分布在（N-1）块盘上，第N块盘专门存储校验信息。
*   **性能**：读写性能约为（N-1）倍单盘速度（数据部分相当于RAID 0）。
*   **可靠性**：可以容忍**任意一块**磁盘损坏（包括校验盘）而不丢失数据。
*   **空间利用率**：总存储空间为（N-1）块磁盘的容量。
*   **缺点**：所有写入操作都需要更新校验盘，使其成为性能瓶颈且更容易磨损。

### RAID 5：分布式校验

RAID 5解决了RAID 4的校验盘瓶颈问题。

![](img/e8076b93d9bf5a1b5182d6b590e34c2d_23.png)

![](img/e8076b93d9bf5a1b5182d6b590e34c2d_25.png)

以下是RAID 5的特点：
*   **原理**：与RAID 4类似，但**将校验信息均匀分布到所有磁盘上**，而非专用一块盘。
*   **优点**：继承了RAID 4的所有优点，同时将写入负载均匀分散，避免了单一校验盘的瓶颈。
*   **性能与可靠性**：与RAID 4基本相同。

![](img/e8076b93d9bf5a1b5182d6b590e34c2d_27.png)

### RAID 6：双重容错

![](img/e8076b93d9bf5a1b5182d6b590e34c2d_29.png)

![](img/e8076b93d9bf5a1b5182d6b590e34c2d_31.png)

RAID 6为了更高的可靠性，允许同时损坏两块磁盘。

![](img/e8076b93d9bf5a1b5182d6b590e34c2d_33.png)

![](img/e8076b93d9bf5a1b5182d6b590e34c2d_35.png)

以下是RAID 6的特点：
*   **原理**：在RAID 5的基础上，增加**第二种校验算法**（如基于伽罗华域），形成两份独立的校验信息。
*   **可靠性**：可以容忍**任意两块**磁盘同时损坏而不丢失数据。
*   **代价**：需要至少4块磁盘，可用空间为（N-2）块磁盘的容量，写性能略低于RAID 5。

### 嵌套RAID（如RAID 10）

![](img/e8076b93d9bf5a1b5182d6b590e34c2d_37.png)

我们可以组合不同的RAID级别。常见的组合是RAID 1+0（或RAID 10）。

![](img/e8076b93d9bf5a1b5182d6b590e34c2d_39.png)

以下是RAID 10的构建与特点：
*   **原理**：先创建多个RAID 1镜像对，再将这些镜像对组成一个RAID 0条带卷。
*   **性能**：兼具RAID 0的读写速度和RAID 1的高可靠性。
*   **可靠性**：可以容忍**至少一块、至多（N/2）块**磁盘损坏（取决于损坏的磁盘是否属于同一个镜像对）。
*   **重建优势**：当一块磁盘损坏后，重建阵列只需从镜像对另一成员复制数据，速度非常快，无需复杂计算。

## 总结

本节课中我们一起学习了操作系统管理持久化存储的两个核心主题。

首先，我们深入了解了**固态硬盘（SSD）**。它像RAM一样以页为单位访问，但有其独特约束：只能写入刚被擦除的页，且擦除必须以块为单位进行。因此，操作系统需要通过`TRIM`命令等机制与SSD协作，以实现最佳性能。

![](img/e8076b93d9bf5a1b5182d6b590e34c2d_41.png)

![](img/e8076b93d9bf5a1b5182d6b590e34c2d_43.png)

其次，我们探讨了**独立磁盘冗余阵列（RAID）** 技术。通过将数据分布到多个磁盘并结合冗余信息（如镜像或奇偶校验），RAID能够在提升I/O性能和提高数据可靠性之间提供多种配置选择（如RAID 0, 1, 5, 6, 10等），从而满足从个人电脑到大型数据中心的多样化存储需求。
