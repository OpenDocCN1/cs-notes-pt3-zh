# 002：使用调试器 🐛

![](img/1d095a81a56817284a009bb44bebba87_1.png)

在本节课中，我们将学习如何使用调试器来检查程序在运行时的状态。调试器是定位和修复代码问题的强大工具。

调试器允许你在程序运行时检查其执行过程。



![](img/1d095a81a56817284a009bb44bebba87_3.png)

上一节我们介绍了调试器的基本概念，本节中我们来看看如何开始使用它。

![](img/1d095a81a56817284a009bb44bebba87_4.png)

使用调试器的第一步总是设置一个断点。

![](img/1d095a81a56817284a009bb44bebba87_6.png)

断点会告知集成开发环境，你希望程序执行到该断点时暂停。



![](img/1d095a81a56817284a009bb44bebba87_8.png)

在我们的案例中，我将把断点设置在代码的第24行。



然后再次点击绿色箭头，但这次选择调试选项。



执行此操作后，我们会看到该行代码被高亮显示为蓝色。

这意味着程序执行在该行暂停。在下方的面板中，

![](img/1d095a81a56817284a009bb44bebba87_10.png)

![](img/1d095a81a56817284a009bb44bebba87_11.png)

我们可以看到当前作用域内的所有变量。例如，我们的 `deed` 变量，

以及 `sealCitizen` 变量。如果我们点击这个箭头，还可以看到 `sealCitizen` 对象拥有的属性。



![](img/1d095a81a56817284a009bb44bebba87_13.png)

如果我们想继续执行程序，可以通过几个选项来控制。使用这个箭头，

我们可以“步入”当前行正在调用的方法。在我们的例子中，就是 `checkHistoryWithCode` 方法。



![](img/1d095a81a56817284a009bb44bebba87_15.png)

我将点击一次，现在我们进入了这个方法内部。

![](img/1d095a81a56817284a009bb44bebba87_16.png)

我想进一步进入 `searchWithCode` 方法。

所以我将再次点击同一个箭头。



![](img/1d095a81a56817284a009bb44bebba87_18.png)

在这里，我们已经能看出为什么返回 `null`，因为我们正在检查所有公民，但没有一个代码匹配。



![](img/1d095a81a56817284a009bb44bebba87_20.png)

在这种情况下，我们可以在这行代码上设置另一个断点，然后点击绿色箭头让程序继续运行，直到命中下一个断点。



现在我们停在这里，可以清楚地看到，它确实返回了 `null`。既然我们知道了这一点，

![](img/1d095a81a56817284a009bb44bebba87_22.png)

就可以再次“步出”这个方法。



![](img/1d095a81a56817284a009bb44bebba87_24.png)

并返回到上层调用。现在我们可以“单步跳过”这一行。



这基本上意味着直接执行完当前行，然后跳到下一行。

![](img/1d095a81a56817284a009bb44bebba87_26.png)

我们可以在下方的变量面板中看到 `citizen` 的值是 `null`。



![](img/1d095a81a56817284a009bb44bebba87_28.png)

这告诉我们，因为我们在一个 `null` 的 `citizen` 上调用了 `printHistory` 方法，所以会得到一个空指针异常。



![](img/1d095a81a56817284a009bb44bebba87_30.png)

我们可以通过恢复程序运行来验证这一点。



![](img/1d095a81a56817284a009bb44bebba87_32.png)

然后控制台会输出和之前一样的错误信息。



现在我们知道，在这一行代码中，我们必须确保检查 `citizen` 不为 `null`。如果它是 `null`，

那么我们需要执行其他操作，例如，打印一条“未找到海豹”的消息。



![](img/1d095a81a56817284a009bb44bebba87_34.png)

如果在调试之后，你仍然不清楚代码为何失败，

当然也应该检查 ArtIS 上的讨论，或者询问你的导师。



![](img/1d095a81a56817284a009bb44bebba87_36.png)

本节课中我们一起学习了调试器的基本使用方法：如何设置断点、如何控制程序执行（步入、步出、单步跳过、恢复），以及如何利用变量面板检查程序状态。掌握这些技能对于高效地诊断和修复代码问题至关重要。
