# 操作系统设计与实现：第5讲：操作系统启动过程 🚀

在本节课中，我们将要学习计算机从按下电源键到操作系统完全启动的详细过程。这是一个多步骤的流程，涉及硬件自检、固件引导、分区查找、引导加载程序加载内核，以及最终启动系统服务。理解这个过程对于后续深入操作系统内部机制至关重要。

## 启动过程概述

计算机的启动是一个复杂的六步过程。从硬件加电开始，到操作系统内核加载并启动所有系统服务结束。我们将逐一拆解这些步骤。

## 步骤一：BIOS启动 🔌

上一节我们概述了启动流程，本节中我们来看看第一步的具体工作。

当您打开计算机电源时，首先运行的是基本输入输出系统。这是一段存储在固件中的代码，负责执行最底层的硬件初始化和检查。

BIOS的主要职责包括：
*   执行加电自检，检查关键硬件组件。
*   初始化内存。
*   检测和识别连接的硬件设备，如磁盘驱动器。
*   完成检查后，开始启动过程的下一步。

BIOS是操作系统用于与设备、外围硬件通信的底层软件层。它存储在只读存储器中，专为特定主板设计，使用中断等低级机制与硬件交互。

## 步骤二：主引导记录

在BIOS完成其工作后，接下来需要找到可以启动操作系统的磁盘和分区。这是通过读取主引导记录实现的。

主引导记录位于每个磁盘的第一个扇区。它包含一小段引导代码和一个分区表。

以下是主引导记录的结构：
*   **引导代码**：前446字节，用于启动引导过程。
*   **分区表**：占用后续空间，最多可描述4个分区。每个条目包含分区的起始地址、结束地址、大小等信息。

分区提供了灵活性，例如：
*   在同一磁盘上安装多个操作系统。
*   将操作系统文件与用户数据分离。
*   为不同分区使用不同的文件系统。

BIOS会读取并执行主引导记录中的引导代码。这段代码会扫描分区表，找到标记为“活动”或“可引导”的分区，然后跳转到该分区继续启动。

## 步骤三：卷引导记录

找到活动分区后，启动过程将进入该分区。每个分区的第一个扇区被称为卷引导记录。

卷引导记录的结构与主引导记录类似，也包含引导代码和该分区的信息。主引导记录的引导代码会跳转到活动分区的卷引导记录，并执行其中的代码。

这段代码的职责是指向操作系统内核的位置，或者更常见的是，指向一个更强大的引导加载程序。

## 步骤四：引导加载程序

卷引导记录中的代码通常过于简单，无法直接加载复杂的内核。因此，我们引入了引导加载程序作为“第二阶段”引导器。

引导加载程序的主要功能是提供一个菜单，让用户选择要启动的操作系统或内核版本，并负责加载最终的内核。

引导加载程序需要完成以下任务：
1.  **加载基本文件系统驱动**：为了读取磁盘上的内核和配置文件，引导加载程序需要理解分区所使用的文件系统。
2.  **读取配置文件**：配置文件定义了可用的启动选项和参数。
3.  **显示启动菜单**：为用户提供选择界面。
4.  **加载所选内核**：根据用户选择或默认设置，将操作系统内核加载到内存中。

例如，在Linux中广泛使用的GRUB引导加载程序，其配置文件可能包含多个内核条目，允许用户在稳定内核和开发内核之间进行选择，这对于内核开发至关重要。

## 步骤五：内核启动与初始内存磁盘

当引导加载程序将控制权交给内核后，真正的操作系统启动开始了。然而，此时内核可能还无法直接访问根文件系统。

为了解决这个问题，内核会先加载一个名为“初始内存磁盘”的小型文件系统镜像到内存中。

初始内存磁盘是一个存储在内存中的临时文件系统，它包含了内核启动所必需的核心模块、驱动程序和工具。内核会先挂载这个内存文件系统，并从中获取启动真实根文件系统所需的一切。

一旦借助初始内存磁盘中的工具挂载了真实的根文件系统，内核就可以访问磁盘上的所有文件，并进入启动的最后阶段。

## 步骤六：初始化系统与服务启动

操作系统内核运行起来后，还需要启动各种系统服务（如网络、登录管理等）。这个任务由初始化系统完成。

在传统的Unix系统中，这个进程是`init`。它是内核启动的第一个用户级进程，也是所有其他进程的祖先。

`init`根据**运行级别**来决定启动哪些服务。运行级别是一个数字，代表不同的系统状态。

常见的运行级别包括：
*   **运行级别 1**：单用户模式，仅允许root用户进行系统维护。
*   **运行级别 3**：多用户文本模式，允许多用户登录，但不启动图形界面。
*   **运行级别 5**：多用户图形模式，启动图形登录界面。

每个运行级别对应一个目录，其中存放着启动或停止服务的脚本。`init`会根据设定的运行级别，按顺序执行对应目录中的所有启动脚本，从而拉起所有必要的系统服务。

## 启动过程总结

本节课中我们一起学习了操作系统从加电到完全可用的完整启动旅程。我们回顾了关键的六个步骤：

1.  **BIOS**：硬件初始化和自检。
2.  **主引导记录**：定位磁盘和活动分区。
3.  **卷引导记录**：进入活动分区。
4.  **引导加载程序**：提供启动菜单并加载内核。
5.  **内核与初始内存磁盘**：内核启动并挂载临时根文件系统，为访问真实根文件系统做准备。
6.  **初始化系统**：启动所有系统服务，使操作系统进入可用状态。

对于操作系统开发者而言，最需要关注的是第4步之后的过程。然而，了解整个链条如何运作，对于调试和深入理解系统行为非常有帮助。这个过程虽然有些机械和繁琐，但却是构建和掌控操作系统知识的坚实基础。
