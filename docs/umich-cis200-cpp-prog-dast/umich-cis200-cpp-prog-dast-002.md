在熟悉了导航命令后，接下来学习如何创建和管理文件与目录。

以下是相关命令列表：
*   `mkdir [目录名]`：创建新目录。
*   `cp [源文件] [目标路径]`：复制文件。
*   `mv [源文件] [目标路径]`：移动文件，也可用于重命名。
*   `rm [文件名]`：删除文件。（**警告**：请谨慎使用，尤其是`rm -rf`命令会强制递归删除，非常危险）。
*   `rmdir [目录名]`：删除空目录。

**安全提示**：操作文件时，建议先使用`cp`命令复制，确认无误后再用`rm`删除原文件，这比直接使用`mv`更安全。

### 文本编辑与程序编译

![](img/c0f058e449443410ad2f6fd63351f587_35.png)

![](img/c0f058e449443410ad2f6fd63351f587_36.png)

管理好文件后，我们可能需要创建或编辑文本文件，例如编写C++代码。

Unix系统自带了`vi`或`vim`文本编辑器。它有两种模式：
*   **命令模式**：用于执行保存、退出等操作。
*   **插入模式**：用于输入文本。按 `i` 键进入插入模式。

编辑完成后，按 `Esc` 键返回命令模式，然后输入：
*   `:w`：保存文件。
*   `:q`：退出编辑器。
*   `:wq`：保存并退出。

要编译C++程序，使用`g++`编译器：
```bash
g++ [源代码文件.cpp] -o [输出程序名]
```
例如：`g++ hello.cpp -o hello`。编译成功后，使用 `./[程序名]` 来运行，例如 `./hello`。

## C++面向对象编程入门

在掌握了Unix环境的基本操作后，我们将把焦点转回C++，开始学习面向对象编程的核心思想。

面向对象编程（OOP）是一种编程范式，它使用“对象”来模拟现实世界中的事物。对象包含**属性**（数据）和**方法**（函数）。**类**是创建对象的蓝图。

### 创建一个类：PowerballTicket

我们将通过创建一个模拟强力球彩票的类来实践OOP概念。

类的定义通常放在头文件（.h）中。我们创建一个`PowerballTicket`类。

**核心概念**：
*   **属性（成员变量）**：存储彩票的号码。我们使用`vector<int>`来存储。
*   **构造函数**：用于初始化对象。我们创建两个：一个生成随机号码，一个接受指定号码。
*   **成员函数**：提供操作数据的方法，例如获取号码、将彩票转换为字符串、计算奖金。

![](img/c0f058e449443410ad2f6fd63351f587_38.png)

![](img/c0f058e449443410ad2f6fd63351f587_40.png)

![](img/c0f058e449443410ad2f6fd63351f587_42.png)

以下是`PowerballTicket`类的基本框架代码：
```cpp
// PowerballTicket.h
#include <vector>
#include <string>
using namespace std;

class PowerballTicket {
private:
    vector<int> numbers; // 私有属性，存储号码

![](img/c0f058e449443410ad2f6fd63351f587_46.png)

public:
    // 构造函数1：生成随机号码
    PowerballTicket();
    // 构造函数2：使用指定号码
    PowerballTicket(vector<int> givenNumbers);

    // 成员函数：获取号码
    vector<int> getNumbers() const;
    // 成员函数：将对象转换为字符串表示
    string toString() const;
    // 成员函数：与中奖彩票对比，计算奖金
    int getWinnings(const PowerballTicket& winningTicket) const;
};
```

### 实现类功能

![](img/c0f058e449443410ad2f6fd63351f587_50.png)

![](img/c0f058e449443410ad2f6fd63351f587_52.png)

定义了类的框架后，我们需要在源文件中实现具体的功能。

**1. 构造函数的实现**：
*   默认构造函数需要生成不重复的随机白球号码（1-69）和一个红球号码（1-26）。
*   带参数的构造函数直接将传入的号码向量赋值给成员变量。

**2. `getWinnings` 函数的实现**：
此函数是业务逻辑的核心。它需要：
*   比较当前彩票与中奖彩票的号码。
*   根据匹配的白球和红球数量，按照强力球规则确定奖金金额。
*   返回对应的奖金值（例如，匹配所有号码返回1,000,000,000）。

### 使用类

最后，我们在主程序（main函数）中使用我们创建的类。

![](img/c0f058e449443410ad2f6fd63351f587_58.png)

以下是使用示例的步骤：
1.  **包含头文件**：`#include "PowerballTicket.h"`
2.  **创建对象**：
    ```cpp
    PowerballTicket winningTicket; // 随机生成一张作为中奖彩票
    PowerballTicket myTicket({1, 2, 3, 4, 5, 6}); // 创建一张指定号码的彩票
    ```
3.  **调用成员函数**：
    ```cpp
    cout << "Winning Numbers: " << winningTicket.toString() << endl;
    cout << "My Ticket: " << myTicket.toString() << endl;
    int prize = myTicket.getWinnings(winningTicket);
    cout << "You won: $" << prize << endl;
    ```
