## 异常处理 🛡️



上一节我们介绍了类的基本概念。本节中，我们来看看如何通过异常来保护类的完整性。当调用者试图执行非法操作（例如，为椅子设置负高度）时，类不应简单地打印错误，而应抛出异常，强制调用者处理。

### 抛出异常

![](img/ca0731a6e5357153f1812b304e484111_18.png)

在类的方法中，如果检测到无效参数，可以使用 `throw` 关键字抛出异常。例如，在设置椅子高度的方法中：

![](img/ca0731a6e5357153f1812b304e484111_20.png)

![](img/ca0731a6e5357153f1812b304e484111_22.png)

![](img/ca0731a6e5357153f1812b304e484111_24.png)


```cpp
void Chair::setHeightInCentimeters(int height) {
    if (height <= 0) {
        throw std::invalid_argument("高度不能为负数或零。");
    }
    this->height = height;
}
```


抛出异常后，当前函数的执行会立即停止，控制权转移到调用者。




![](img/ca0731a6e5357153f1812b304e484111_34.png)

![](img/ca0731a6e5357153f1812b304e484111_36.png)

### 捕获与处理异常

![](img/ca0731a6e5357153f1812b304e484111_38.png)

调用可能抛出异常的代码时，应使用 `try-catch` 块来捕获并处理异常，防止程序崩溃。

![](img/ca0731a6e5357153f1812b304e484111_40.png)



以下是处理用户输入时捕获异常的示例：

![](img/ca0731a6e5357153f1812b304e484111_46.png)

```cpp
int main() {
    Chair ericsChair;
    int height;
    while (true) {
        std::cout << "请输入椅子高度（厘米）：";
        std::cin >> height;
        try {
            ericsChair.setHeightInCentimeters(height);
            break; // 如果成功，跳出循环
        } catch (const std::invalid_argument& ex) {
            std::cout << "输入无效：" << ex.what() << " 请重新输入。\n";
        } catch (const std::runtime_error& ex) {
            std::cout << "运行时错误：" << ex.what() << "\n";
        }
    }
    return 0;
}
```

![](img/ca0731a6e5357153f1812b304e484111_48.png)

![](img/ca0731a6e5357153f1812b304e484111_50.png)

![](img/ca0731a6e5357153f1812b304e484111_52.png)

**关键点**：
*   `try` 块包含可能抛出异常的代码。
*   `catch` 块按顺序匹配异常类型。可以捕获多个不同类型的异常。
*   使用 `ex.what()` 可以获取异常信息。
*   处理异常后，程序会从 `catch` 块后继续执行。

## 指针基础 🧭




理解了如何通过异常进行通信后，我们进入另一个核心主题：指针。指针是C++中强大但容易出错的工具，它存储的是内存地址，而不是直接的值。




### 指针的声明与使用


![](img/ca0731a6e5357153f1812b304e484111_70.png)

指针使用 `*` 符号声明。初始化指针时，最好将其设为 `nullptr`（空指针），表示它当前不指向任何有效内存。

![](img/ca0731a6e5357153f1812b304e484111_72.png)


![](img/ca0731a6e5357153f1812b304e484111_75.png)

```cpp
int number = 42;          // 普通整型变量
int* anotherNumber = nullptr; // 整型指针，初始化为空
anotherNumber = &number;  // 将指针指向 number 的内存地址
```



*   `&` 运算符：获取变量的内存地址（取址）。
*   `*` 运算符（在声明外使用）：解引用指针，获取它指向地址中存储的值。



```cpp
std::cout << number;           // 输出: 42
std::cout << anotherNumber;    // 输出: 0x7ffdf5a3c2bc (number的内存地址)
std::cout << *anotherNumber;   // 输出: 42 (解引用)
*anotherNumber = 77;           // 通过指针修改值
std::cout << number;           // 输出: 77 (原始变量也被修改)
```






### 动态内存分配






指针最重要的用途之一是管理**堆（Heap）**内存，这与函数调用使用的**栈（Stack）**内存不同。堆内存允许我们在运行时动态分配大量内存。

![](img/ca0731a6e5357153f1812b304e484111_102.png)

![](img/ca0731a6e5357153f1812b304e484111_103.png)



使用 `new` 运算符在堆上分配内存：










![](img/ca0731a6e5357153f1812b304e484111_124.png)

```cpp
int numValues;
std::cout << "你需要存储多少个整数？";
std::cin >> numValues;

// 动态分配一个整数数组
int* values = new int[numValues];

for (int i = 0; i < numValues; ++i) {
    std::cout << "输入值 " << i + 1 << ": ";
    std::cin >> values[i]; // 像普通数组一样使用
}
// 使用完毕后，必须用 delete[] 释放内存
delete[] values;
values = nullptr; // 好习惯：释放后将指针置空
```

![](img/ca0731a6e5357153f1812b304e484111_126.png)

**重要警告**：忘记使用 `delete` 释放动态分配的内存会导致**内存泄漏**。程序会持续占用内存，直到崩溃或操作系统干预。




### 指针与类对象




我们也可以创建指向类对象的指针，这在管理大量对象或需要在堆上分配对象时非常有用。






![](img/ca0731a6e5357153f1812b304e484111_148.png)

```cpp
// 在栈上创建对象
Rectangle smallRect(2, 3);
std::cout << smallRect.getLength(); // 使用点运算符 .
// 在堆上动态创建对象
Rectangle* bigRect = new Rectangle(5, 10);
std::cout << bigRect->getLength(); // 使用箭头运算符 ->
// 等价于 (*bigRect).getLength();

// 使用完毕后删除对象
delete bigRect;
bigRect = nullptr;
```

![](img/ca0731a6e5357153f1812b304e484111_150.png)

**关键点**：
*   使用 `new ClassName(...)` 在堆上创建对象。
*   通过指针访问对象成员时，使用 `->` 运算符。
*   必须使用 `delete` 释放单个对象。

### 指针算术与数组

数组名本质上是一个指向数组首元素的常量指针。指针算术允许我们通过增减内存地址来遍历数组。

![](img/ca0731a6e5357153f1812b304e484111_152.png)

![](img/ca0731a6e5357153f1812b304e484111_154.png)

![](img/ca0731a6e5357153f1812b304e484111_156.png)


![](img/ca0731a6e5357153f1812b304e484111_158.png)




```cpp
int* values = new int[5]{10, 20, 30, 40, 50};
int* current = values; // current 指向数组开头
for (int i = 0; i < 5; ++i) {
    std::cout << *current << " "; // 输出当前指向的值
    current++; // 指针向前移动一个‘int’大小的内存单元
}
// 输出: 10 20 30 40 50
```


![](img/ca0731a6e5357153f1812b304e484111_168.png)

![](img/ca0731a6e5357153f1812b304e484111_170.png)

`values[i]` 等价于 `*(values + i)`。指针算术依赖于所指向类型的大小。

## 总结 📚

本节课中我们一起学习了：
1.  **异常处理**：使用 `throw` 在类中抛出异常，使用 `try-catch` 块在调用处捕获和处理异常，从而编写更健壮、安全的代码。
2.  **指针**：
    *   指针存储内存地址，使用 `&` 取址，使用 `*` 解引用。
    *   使用 `new` 和 `delete`（或 `delete[]`）在堆上进行动态内存分配和释放，**务必防止内存泄漏**。
    *   使用指针操作数组和类对象，注意 `->` 运算符的使用。
