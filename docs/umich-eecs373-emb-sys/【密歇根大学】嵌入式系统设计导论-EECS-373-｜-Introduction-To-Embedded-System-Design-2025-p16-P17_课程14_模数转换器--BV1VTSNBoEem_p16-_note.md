# 嵌入式系统设计导论：14：模数转换器

在本节课中，我们将要学习模数转换器的基本原理、几种常见的架构及其优缺点，并通过一个温度传感器的例子来实践如何将ADC读数转换为实际的工程单位。

## 概述

上一节我们介绍了模拟信号与数字信号的基本概念，以及如何从模拟世界转换到数字世界。本节中，我们将深入探讨模数转换器的具体工作原理，包括采样保持电路和三种主要的ADC架构：闪存型、斜率积分型和逐次逼近型。我们还将学习如何在实际应用中，将ADC的原始计数值转换为有意义的物理量。

## 从模拟到数字的转换

上一节我们介绍了模拟信号与数字信号之间的转换关系，可以将其想象为一个“二进制阶梯”。我们的一侧是电压值，另一侧是二进制值，目标是建立一个从模拟值到数字值的传递函数。

这个传递函数可以用公式来描述。对于一个理想的ADC，其传递函数是将电压范围离散化为 `2^n` 个步长。然而，这种模型存在一个问题：几乎不可能读出最高位的值。

为了解决这个问题，大多数制造商会将整个阶梯偏移半个最低有效位。这意味着电压范围的两端会各损失半个步长，但可以确保在整个范围内都能获得有效的数字输出。此时的传递函数公式为：
`数字值 = floor( (模拟输入电压 / 参考电压) * (2^n) + 0.5 )`

这个公式表明，转换结果会进行向下取整。

接下来，我们讨论一下分辨率。分辨率指的是最低有效位所代表的电压范围大小，它决定了ADC测量微小电压变化的能力。分辨率通常是一个关键指标，用于评估ADC的精度。其计算公式为：
`分辨率 = V_ref / (2^n)`
更精确的公式是：
`分辨率 = V_ref / (2^n - 1)`
但由于`n`通常较大（如8位到16位），这两个公式的差异很小，在数据手册中通常使用前者。

在嵌入式系统中，我们经常需要测量物理现象（如温度、气压）。这个过程通常涉及：物理现象 -> 传感器（换能器，输出电压/电流）-> ADC（输出原始计数值）-> 软件（转换为工程单位）。

![](img/1fbff5fab56a7b3b6b543c8d10b37485_12.png)

![](img/1fbff5fab56a7b3b6b543c8d10b37485_13.png)

![](img/1fbff5fab56a7b3b6b543c8d10b37485_15.png)

以下是完成这个转换过程的步骤。

![](img/1fbff5fab56a7b3b6b543c8d10b37485_17.png)

我们将使用一个基本的温度传感器，它有三个引脚：地、电源和模拟电压输出。其数据手册显示，输出电压与温度成正比。

![](img/1fbff5fab56a7b3b6b543c8d10b37485_19.png)

![](img/1fbff5fab56a7b3b6b543c8d10b37485_21.png)

假设我们使用一个10位ADC，电压范围为0到3.3伏。我们的任务是：
1.  计算ADC的最小电压步长（分辨率）。
2.  推导出从ADC原始值到温度（摄氏度）的传递函数。
3.  计算当ADC读数为某一特定值（例如361）时对应的温度。

**第一步：计算分辨率**
分辨率 = 参考电压 / 2^n = 3.3V / 1024 ≈ 3.22 mV
这是ADC能够分辨的最小电压变化。

**第二步：推导传递函数**
我们需要结合两个关系：
1.  传感器电压-温度关系（从数据手册获得，假设为线性：`V_temp = a * T + b`，其中a和b为常数）。
2.  ADC电压-数字值关系：`ADC_value = (V_in / V_ref) * (2^n)` （此处忽略偏移以简化）。

通过联立方程，将`V_temp`代入`V_in`，可以解出温度`T`关于`ADC_value`的函数：
`T = ( (ADC_value / 2^n) * V_ref - b ) / a`

**第三步：计算温度**
将ADC值（例如361）、V_ref（3.3V）、以及从数据手册得到的a和b常数代入上述公式，即可计算出对应的温度值。

![](img/1fbff5fab56a7b3b6b543c8d10b37485_23.png)

![](img/1fbff5fab56a7b3b6b543c8d10b37485_25.png)

关于采样频率的选择，需要根据信号变化的快慢来决定。对于温度这种变化缓慢的信号，1 Hz甚至更低的采样率通常是足够的。

## 采样保持电路

![](img/1fbff5fab56a7b3b6b543c8d10b37485_27.png)

上一节我们介绍了ADC的基本概念和转换练习。本节中我们来看看ADC的一个关键前置模块：采样保持电路。

采样保持电路的作用是捕获并保持一个快速变化的模拟信号值。这是因为某些ADC架构完成一次转换需要一定时间。如果没有采样保持，在转换期间输入的模拟信号可能已经发生变化，导致测量错误。

![](img/1fbff5fab56a7b3b6b543c8d10b37485_29.png)

![](img/1fbff5fab56a7b3b6b543c8d10b37485_31.png)

![](img/1fbff5fab56a7b3b6b543c8d10b37485_33.png)

![](img/1fbff5fab56a7b3b6b543c8d10b37485_35.png)

其基本工作原理是：当采样开关闭合时，输入电压对电容充电；当开关断开时，电容将保持断开瞬间的电压值。一个运算放大器配置为电压跟随器模式，可以高阻抗地读取电容上的电压，并驱动输出，而不会使电容放电。

在现实世界中，采样保持电路需要考虑充电时间（由信号源内阻和电容构成的RC时间常数决定）和电容的电荷泄漏。因此，电路设计必须确保ADC的转换时间远小于电容的放电时间。在STM32等微控制器中，通常可以软件配置采样时间，以适应不同内阻的信号源。

## ADC架构比较

接下来，我们将介绍三种常见的ADC架构，并比较它们的优缺点。理解这些差异有助于在实际项目中为特定应用选择合适的ADC。

![](img/1fbff5fab56a7b3b6b543c8d10b37485_37.png)

![](img/1fbff5fab56a7b3b6b543c8d10b37485_39.png)

### 闪存型ADC

![](img/1fbff5fab56a7b3b6b543c8d10b37485_41.png)

闪存型ADC采用并行比较架构。它使用一系列电阻构成分压网络，产生多个等间距的参考电压。每个参考电压连接一个比较器，与输入电压进行比较。

![](img/1fbff5fab56a7b3b6b543c8d10b37485_43.png)

所有比较器同时工作，产生一个“温度计码”输出（所有低于输入电压的比较器输出高电平，高于的输出低电平）。然后，一个优先级编码器将这个“温度计码”转换为二进制数字输出。

![](img/1fbff5fab56a7b3b6b543c8d10b37485_45.png)

**优点**：
*   **速度极快**：转换在一个时钟周期内完成，适合高速应用。
*   **结构相对直接**。

![](img/1fbff5fab56a7b3b6b543c8d10b37485_47.png)

**缺点**：
*   **分辨率受限**：需要 `2^n` 个电阻和比较器。当位数n增加时，芯片面积和功耗急剧增加。
*   **功耗较高**：所有比较器始终在工作。
*   **对电阻匹配精度要求高**：影响线性度和精度。

### 斜率积分型ADC

![](img/1fbff5fab56a7b3b6b543c8d10b37485_49.png)

斜率积分型ADC采用时间测量架构。它使用一个已知斜率的斜坡电压（通常由恒流源对电容充电产生）与待测输入电压进行比较。

![](img/1fbff5fab56a7b3b6b543c8d10b37485_51.png)

![](img/1fbff5fab56a7b3b6b543c8d10b37485_52.png)

一个计数器在斜坡开始时计数。当斜坡电压上升到与输入电压相等时，比较器翻转，计数器停止。计数器的值就代表了输入电压的大小。

**优点**：
*   **分辨率可以非常高**：通过提高计数时钟频率，可以增加计数步数，从而提高分辨率。
*   **精度高**：对元件绝对值的依赖较小，更多依赖于时间的测量精度。
*   **功耗较低**：电路相对简单。
*   **成本较低**：不需要大量精密电阻。

**缺点**：
*   **速度非常慢**：转换时间与输入电压成正比，最大转换时间可能需要很多个时钟周期。
*   **需要精密的斜坡发生器和稳定的时钟**。

**双斜率积分型ADC**是改进型，它先对输入电压积分一段时间，再对参考电压反向积分。这种方法可以抵消积分电容和时钟频率的误差，进一步提高精度，是数字万用表中常用的技术。

### 逐次逼近型ADC

逐次逼近型ADC是微控制器中最常见的类型，它结合了前两种架构的一些思想。它包含一个采样保持电路、一个比较器、一个数模转换器和一个逐次逼近寄存器。

![](img/1fbff5fab56a7b3b6b543c8d10b37485_54.png)

![](img/1fbff5fab56a7b3b6b543c8d10b37485_56.png)

其工作方式类似于二进制搜索算法：
1.  SAR首先输出一个中间值（例如，对于8位ADC，输出10000000，即半量程）。
2.  DAC将这个数字值转换为模拟电压，与采样保持的输入电压在比较器中进行比较。
3.  如果DAC电压低于输入电压，则SAR保持最高位为1，并尝试设置次高位为1（变为11000000）；如果高于，则清除最高位，并尝试设置次高位为1（变为01000000）。
4.  重复此过程，从最高位到最低位依次确定每一位是1还是0，直到所有位都确定。

![](img/1fbff5fab56a7b3b6b543c8d10b37485_58.png)

**优点**：
*   **良好的折衷**：在速度、分辨率和复杂度之间取得平衡。
*   **速度中等偏快**：转换需要n个时钟周期（n为位数），远快于斜率积分型。
*   **分辨率较高**：可以达到16位或更高。
*   **面积和功耗相对较小**：只需要一个比较器和一个DAC。

**缺点**：
*   **需要复杂的控制逻辑**。
*   **转换速度低于闪存型**。

在STM32等MCU中，SAR ADC通常允许用户在分辨率和采样速率之间进行权衡（例如，降低分辨率以获得更高的采样率）。

## 总结

本节课中我们一起学习了模数转换器的核心知识。我们首先回顾了模拟到数字转换的数学模型，并通过一个温度传感器的例子实践了从ADC原始值到工程单位的转换流程。接着，我们探讨了采样保持电路的必要性及其工作原理。

最后，我们详细分析了三种主流的ADC架构：
*   **闪存型ADC**：速度最快，但分辨率低、功耗和面积大。
*   **斜率积分型ADC**：精度和分辨率最高，速度最慢，常用于高精度仪表。
*   **逐次逼近型ADC**：在速度、精度和成本之间取得了良好平衡，是嵌入式系统中最常见的类型。

![](img/1fbff5fab56a7b3b6b543c8d10b37485_60.png)

理解这些架构的优缺点，对于在未来的项目或工作中根据具体需求（如速度、精度、功耗、成本）选择合适的ADC至关重要。
