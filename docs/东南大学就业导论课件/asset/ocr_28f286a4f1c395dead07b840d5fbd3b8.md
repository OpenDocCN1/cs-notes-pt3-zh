| 问题 | 传统模式 | 变化后的模式 |
|---|---|---|
| 环境特征 | 稳定性 | 动态性 |
| 职业选择 | 在职业早期选择一次 | 在不同发展阶段多次选择 |
| 主要职业责任 | 组织 | 个人 |
| 工作地点 | 一个组织 | 多个组织 |
| 工作时间 | 长期 | 短期 |
| 雇主期望 | 忠诚和义务 | 责任感、灵活性、适应性 |
| 雇主给予 | 工作安全保证 | 工作技能的获得 |
| 流程标准 | 任期长短决定升迁 | 根据结果和知识获得晋升 |
| 成功标志 | 在等级阶梯中获得升迁 | 内心的成就感 |
| 培训 | 正式程序，培养通才 | 根据工作性质、公司的特殊需要而定 |
| 价值观 | 忠诚、稳定、家长式作风 | 个体差异、多重功能性 |
