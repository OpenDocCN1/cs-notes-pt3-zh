# 远期目标/愿景：生涯幻游

![](bbox=[0.03, 0.32, 0.34, 0.72])

+   1. 个人必须要有被带领的经验，才能感受到较细腻的部分。
+   2. 每一俱场景必须要有足够的时间，让受试都感受，宁慢勿快。
+   3. 场景的转换或者角色的转换也需要有足够的时间。
+   4. 指导语可以录音播放，也可以现场带领，
+   5. 幻游的结束十分重要。
+      a) 回到第一个场景。
+      b) 由第一个场景倒数计时，回到现场。
+      c) 接触实物或人物。
+      d) 轻微的伸展四肢或摆动身体。
