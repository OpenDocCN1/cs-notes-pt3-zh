# 岗位特质:

+   - 你需要在一个注重合作、没有压力和人际关系安定的环境中,与其他富有创造性和情感的同事一起工作
+   - 工作能够符合你的价值观,能够帮助他人成长和克服,挖掘他们的潜力
+   - 你需要在一个没有太多限制、灵活的机构中工作,有足够的私人的空间和时间
+   - 工作允许你深入地与他人沟通和合作,理解、帮助、激励他人,并有机会接触到你尊敬的人

# 优势:

+   - 你能够... 
+   - 你考虑... 
+   - 你会... 有余 
+   - 你天生... 的谊义 
+   - 你有声

+   - 你需要可以发挥创造力的工作条件,并能够得到鼓励和奖励,不断提升自己的能力
+   - 工作时间上要留给你足够的时间来消化你的想法,并为实现它而稳定地工作

# 不足与改善:

+   - 过于追求完美,会花费长时间酝酿自己的想法,常常忽略现实和具体现实,行动力较弱,有时做事会无序,很难把事情的优先识别。因此,你要留意练习主观力去关注重要的细节,遵守必要的秩序,重视资源条件、现实资源和逻辑推理,增强办事的计划性和条理性,以及保持推动工作的物性。
+   - 你比较固执,经常局限在自己的想法里,沉浸于梦想,对外界的需要具体事物没有兴趣,当意识到自己理想与现实之间的差距时,你就容易灰心丧气。你要避免感情用事,恰当地理解梦想和现实的关系,尝试新方法时考虑方法的现实性和可行性,避免过于理想化。
