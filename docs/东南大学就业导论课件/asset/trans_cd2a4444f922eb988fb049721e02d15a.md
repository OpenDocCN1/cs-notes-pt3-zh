![](img/c049f03a753af28f4965561c0dbd43b8_271_0.png)

1. 个人必须要有被带领的经验，才能感受到较细腻的部分。
2. 每一个场景必须要有足够的时间，让受试者感受，宁慢勿快。

4. 指导语可以录音播放，也可以现场带领。

   a) 回到第一个场景。
   b) 由第一个场景倒数计时，回到现场。
   c) 接触实物或人物。
   d) 轻微地伸展四肢或摆动身体。

### 目标设立的SMART原则

- **Specific**：具体的，明确的，不能含糊不清
- **Measurable**：可以量化的，能够明确评估
- **Achievable but challenging**：可实现性，同时具有一定挑战
- **Rewarding**：有意义，有价值，积极的，服务于某个大目标
- **Time-bound**：有明确时间限制的

### 寻找工作机会

- 机会无处不在
- 告诉所有你认识的人，你正在找工作
- 对未知领域保持兴趣
- 长远目标与近期目标相结合
- 再一次明确：我要什么
- 把找工作本身看做一项工作

### 寻找工作机会更好的方法

- 找目标单位内部且了解你的人介绍
- 找认识的人推荐企业职位
- 直接调查目标单位情况，然后主动上门
- 想办法到目标单位去实习或者兼职
- 任何自发的、有创造性的方法

### 求职前的准备

- 这份工作的内容，对人的能力要求
- 公司发展历史和发展潜力
- 产品和服务
- 地点

- 主要竞争者
- 组织的所有权，家族所有权对潜在进步的影响
- 管理风格、组织文化

### 一些关于简历的数字

- 雇主们在每份简历上所花的平均时间为15秒；
- 每245份简历中有1份获得面试机会；
- 有的大公司每年会收到超过100000份简历；
- 雇主们在报纸上登出一个招聘职位，通常会收到200份左右的简历；
- 在所有简历中约有85%-95%最终的结局都是被扔进了垃圾桶。
