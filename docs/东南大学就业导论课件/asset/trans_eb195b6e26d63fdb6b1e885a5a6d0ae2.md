## 岗位特质:

+   - 你需要在一个注重合作、没有压力和人际关系安定的环境中,与其他富有创造性和情感的同事一起工作
+   - 工作能够符合你的价值观,能够帮助他人成长和克服,挖掘他们的潜力
+   - 你需要在一个没有太多限制、灵活的机构中工作,有足够的私人的空间和时间
+   - 工作允许你深入地与他人沟通和合作,理解、帮助、激励他人,并有机会接触到你尊敬的人

## 优势:

+   - 你能够... 
+   - 你考虑... 
+   - 你会... 有余 
+   - 你天生... 的谊义 
+   - 你有声

+   - 你需要可以发挥创造力的工作条件,并能够得到鼓励和奖励,不断提升自己的能力
+   - 工作时间上要留给你足够的时间来消化你的想法,并为实现它而稳定地工作

## 不足与改善:

+   - 过于追求完美,会花费长时间酝酿自己的想法,常常忽略现实和具体现实,行动力较弱,有时做事会无序,很难把事情的优先识别。因此,你要留意练习主观力去关注重要的细节,遵守必要的秩序,重视资源条件、现实资源和逻辑推理,增强办事的计划性和条理性,以及保持推动工作的物性。
+   - 你比较固执,经常局限在自己的想法里,沉浸于梦想,对外界的需要具体事物没有兴趣,当意识到自己理想与现实之间的差距时,你就容易灰心丧气。你要避免感情用事,恰当地理解梦想和现实的关系,尝试新方法时考虑方法的现实性和可行性,避免过于理想化。

## # 工作世界的宏观现状

![](img/c049f03a753af28f4965561c0dbd43b8_205_0.png)

## 结构性失业问题突出

+   > 毕业生 “宁要北京一张床，不要西部一套房”
+   > 考研热：07年128.2万，08年120.0万，09年124.6万，10年140.6万，11年151.1万，12年165.6万
+   > 考公务员热
+   > 基层就业冷，自主创业少

![](img/c049f03a753af28f4965561c0dbd43b8_207_0.png)

## 没有技术意味着没有工作

+   > 科技化与自动化，导致工作内涵变化，需要从业人员具备技术基础与广博知识。
+   > 研究与发展的工作将日趋重要。

## 培训和再教育成为常事

+   > 知识与信息的保质期越来越短
+   > 知识、信息的瀑涨，使得即时更新成为生存的必要技能
+   > “在信息社会中，唯一不变的就是‘变’，我们不能只期望单一的教育形态来帮助我们渡过一生，没有任何一种教育和技能，可以在未来的社会中一成不变，这是二十一世纪的人必须具有的信念。”

## # 京东管培生培训方式

> > “每年7月1日入职；
> > 军训+团队熔炼一个月；
> > 5个月轮岗，可以了解京东所有内部流程；
> > 第二年1月1日第一次选择岗位；
> > 之后半年定岗培训。
> > 第二年7月1日正式结业！
> > 可以第二次选择岗位。
> > 期间向CEO提交周工作报告+旁听半年管理层晨会！
> > 可以随时向CEO汇报工作或者找我交流！
> > 介绍完毕！”
