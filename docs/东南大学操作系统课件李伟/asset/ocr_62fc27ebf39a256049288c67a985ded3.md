# pthread_create

```
int pthread_create(tid, attr, function, arg);
```

+   - `pthread_t *tid`
+     - handle of created thread
+   - `const pthread_attr_t *attr`
+     - attributes of thread to be created
+   - `void *(*function) (void*)`
+     - function to be mapped to thread
+   - `void *arg`
+     - single argument to function
