# Critical Section of n Processes

+   - **Shared data:**
+     - semaphore mutex; //initially *mutex* = 1
+   - **Process Pᵢ:**
+     ```
+     do {
+         wait(mutex);
+             critical section
+         signal(mutex);
+             remainder section
+     } while (1);
+     ```
