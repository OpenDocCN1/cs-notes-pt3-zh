# # Condition Signal

+   - Consider the released process and the signalling process

+     - There are **two** processes executing in the monitor, and mutual exclusion is violated!

+   - Approaches to address this problem

+     - The released process takes the monitor and the signalling process waits somewhere.（唤醒并等待）

+     - The released process waits somewhere and the signalling process continues to use the monitor.（唤醒并继续）
