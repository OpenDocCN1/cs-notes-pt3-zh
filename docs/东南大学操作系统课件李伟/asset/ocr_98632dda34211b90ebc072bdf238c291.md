# Satisfying Three Conditions with TestAndSet

Initially Boolean waiting[i] = false; lock=false

# Enter Critical Section

```
waiting[ i ] = true;
key = true;
while (waiting[ i ] && key)
    key = TestAndSet(lock);
waiting[i] = false;
```

# Leave Critical Section

```
j = (i+1)%n
while ((j!=i) && !waiting[j])
    j = (j+1)%n;
if (j == i)
    lock = false;
else
    waiting[ j ] = false;
```
