# # Semaphore as a General
# Synchronization Tool

+   - Execute *B* in *P*<sub>j</sub> only after *A* executed in *P*<sub>i</sub>
+   - Use semaphore *flag* initialized to 0
+   - Code:

```
Pᵢ                         Pⱼ
⋮                          ⋮
A                    wait(flag)

signal(flag)               B
```
