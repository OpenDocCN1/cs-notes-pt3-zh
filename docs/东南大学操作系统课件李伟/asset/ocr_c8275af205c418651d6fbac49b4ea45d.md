# # Bounded-Buffer

+   - The statement “**count++**” may be implemented in machine language as:
+     - **register₁ = counter**
+     - **register₁ = register₁ + 1**
+     - **counter = register₁**
+   - The statement “**count--**” may be implemented as:
+     - **register₂ = counter**
+     - **register₂ = register₂ − 1**
+     - **counter = register₂**
