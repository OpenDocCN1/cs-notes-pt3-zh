# Monitors

+   - **High-level synchronization construct** that allows the safe sharing of an abstract data type among concurrent processes.

```
monitor monitor-name
{
  shared variable declarations
  procedure body P1(...) {
    ...
  }
  procedure body P2(...) {
    ...
  }
  procedure body Pn(...) {
    ...
  }
  { initialization code}
}
```
