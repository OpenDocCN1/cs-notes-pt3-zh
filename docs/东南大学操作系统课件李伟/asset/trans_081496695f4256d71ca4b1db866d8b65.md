

## Pthreads

- POSIX 标准（IEEE 1003.1c）用于线程创建和同步的 API。
- API 指定线程库的行为，实现由库的开发决定。
- 在 UNIX 操作系统中很常见。

## pthread_create

```
int pthread_create(tid, attr, function, arg);
```

- `pthread_t *tid`
  - 创建的线程句柄
- `const pthread_attr_t *attr`
  - 待创建线程的属性
- `void *(*function) (void*)`
  - 映射到线程的函数
- `void *arg`
  - 传递给函数的单个参数

## pthread_create 解释

- 启动一个运行指定函数的线程
- 线程句柄通过 pthread_t 结构返回
- 指定 *NULL* 以使用默认属性
- 向函数发送单个参数
  - 如果函数不需要参数，指定 *NULL*
- 检查错误代码（返回值）！

> **EAGAIN** – 资源不足无法创建线程  
> **EINVAL** – 属性无效

## 线程状态

- pthread 线程有两种状态
  - 可连接和分离
- 线程默认是可连接的
  - 资源在 *pthread_join* 之前一直保留
  - 可通过属性或 API 调用重置
- 分离线程无法被连接
  - 资源可在终止时回收
  - 不能重置为 *可连接*

## 等待线程

```
int pthread_join(tid, val_ptr);
```

- pthread_t *tid
  - 可连接线程的句柄
- void **val_ptr
  - 被连接线程返回的退出值

## pthread_join 解释

- 调用线程等待句柄为 tid 的线程终止
- 只能连接一个线程
- 线程必须是可连接的
  - 退出值从被连接线程返回
  - 返回类型为 (void *)
  - 如果不期望返回值，使用 NULL

ESRCH – 未找到线程
EINVAL – 线程不可连接

## 示例：多个线程

```
#include <stdio.h>
#include <pthread.h>
const int numThreads = 4;

void *helloFunc(void * pArg)
{ printf("Hello Thread\n"); }

main()
{ pthread_t hThread[numThreads];
for (int i = 0; i < numThreads; i++)
    pthread_create(&hThread[i], NULL, helloFunc, NULL);
for (int i = 0; i < numThreads; i++)
    pthread_join(hThread[i], NULL);
return 0;
}
```

## 挂起和恢复线程

- 每个线程都有挂起计数
- 只有当挂起计数 == 0 时才能执行
- 线程可以以挂起状态创建

```
DWORD ResumeThread (HANDLE hThread)
DWORD SuspendThread(HANDLE hThread)
```

两个函数都返回挂起计数或在失败时返回 0xFFFFFFFF

## 示例：线程创建

```
#include <stdio.h>
#include <windows.h>

DWORD WINAPI helloFunc(LPVOID arg ) {
    printf("Hello Thread\n");
    return 0;
}

main() {
    HANDLE hThread =
        CreateThread(NULL, 0, helloFunc,
            NULL, 0, NULL );
}
```
