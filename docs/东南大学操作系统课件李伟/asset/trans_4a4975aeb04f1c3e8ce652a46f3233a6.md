
## 从逻辑上组织目录，可以获得

- **效率**——快速定位文件。
- **命名**——方便用户使用。
  - 两个用户可以为不同的文件使用相同的名称。
  - 同一个文件可以有多个不同的名称。
- **分组**——按属性对文件进行逻辑分组，  
  （例如，所有 Java 程序、所有游戏……）

### 树形结构目录

- 高效搜索
- 分组能力
- 当前目录（工作目录）
  - `cd /spell/mail/prog`
- 绝对路径名或相对路径名
- 新文件在当前目录中创建
- 删除文件
  - `rm <file-name>`
- 新子目录在当前目录中创建。

```
mkdir <dir-name>
```

示例：如果当前目录为 /mail

```
mkdir count
```

### 文件共享

- 多用户系统上的文件共享是可取的。
- 共享可以通过*保护*方案来实现。
- 在分布式系统中，文件可以通过网络共享。
- 网络文件系统（NFS）是一种常见的分布式文件共享方法。

### 保护

- 文件的所有者/创建者应能够控制：
  - 谁可以执行哪些操作
- 访问类型
  - 读
  - 写
  - 执行
  - 追加
  - 删除
  - 列出

### 访问列表和组

- 访问模式：读、写、执行
- 三类用户 RWX
  - a) 所有者访问权 7 ⇒ 1 1 1
  - b) 组访问权 6 ⇒ 1 1 0
  - c) 公共访问权 1 ⇒ 0 0 1
- 请管理员创建一个组（唯一名称），例如 G，并向该组添加一些用户。
- 对于特定文件（例如 *game*）或子目录，定义适当的访问权限。
