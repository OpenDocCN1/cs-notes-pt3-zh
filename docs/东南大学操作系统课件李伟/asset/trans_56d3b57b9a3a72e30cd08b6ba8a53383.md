## 操作系统设计与实现

- 设计目标
  - 用户目标 – 操作系统应方便使用、易于学习、可靠、安全且快速
  - 系统目标 – 操作系统应易于设计、实现和维护，同时具有灵活性、可靠性、无错误和高效性

## 操作系统设计与实现

- 重要原则是分离
  - 策略：做什么？
  - 机制：怎么做？
  - 将策略与机制分离是一个非常重要的原则，如果以后要更改策略决策，它允许最大程度的灵活性

## 操作系统设计与实现

- 大部分用 C 或 C++ 编写
  - 优点 — 更易于移植
  - 缺点 — 速度降低且存储需求增加
- 一些小的汇编代码部分用于设备驱动程序以及保存和恢复寄存器状态

## 进程特征

- Dynamic (动态性)
- Independency (独立性)
- Concurrence (并发性)
- Structure (结构化)

## 进程状态

- 随着进程执行，其状态会发生变化 *state*
  - **New**: 进程正在被创建。
  - **Ready**: 进程正在等待分配处理器。
  - **Running**: 正在执行指令。
  - **Waiting**: 进程正在等待某个事件发生。
  - **Terminated**: 进程已完成执行。
