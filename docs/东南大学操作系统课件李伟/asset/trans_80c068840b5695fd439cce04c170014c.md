## 虚拟文件系统

- 虚拟文件系统（VFS）提供了一种面向对象的文件系统实现方式。
- VFS 允许对不同类型的文件系统使用相同的系统调用接口（API）。
- API 面向 VFS 接口，而非任何特定类型的文件系统。

## 分配方法

- 分配方法是指磁盘块为文件分配的方式
  - 连续分配
  - 链接分配
  - 索引分配

### 连续分配

- 每个文件占据磁盘上的一组连续块。
- 简单 – 只需要起始位置（块号）和长度（块数）。
- 随机访问（顺序 + 直接）
- 空间浪费（动态存储分配问题）。
- 文件无法增长。
