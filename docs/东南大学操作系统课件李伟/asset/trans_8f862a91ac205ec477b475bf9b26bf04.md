### 有界缓冲区问题

**生产者进程**

```
do {
    ...
    produce an item in nextp
    ...
    wait(empty);
    wait(mutex);
    ...
    add nextp to buffer
    ...
    signal(mutex);
    signal(full);
} while (1);
```

**消费者进程**

```
do {
    wait(full);
    wait(mutex);
    ...
    remove an item from buffer to nextc
    ...
    signal(mutex);
    signal(empty);
    ...
    consume the item in nextc
    ...
} while (1);
```

### 读者-写者问题

- 一个数据集在多个并发进程之间共享
  - 读者——只读数据集，不进行任何更新
  - 写者——既可以读也可以写。
- **问题**——允许多个读者同时读取。但同一时刻只允许一个写者访问共享数据。
  - 第一个读者-写者问题——**读者优先**
  - 第二个读者-写者问题——**写者优先**

### 第一个读者-写者问题

**写者进程**

```
do {
    wait(wrt);
    ...
    writing is performed
    ...
    signal(wrt);
} while (1);
```

**读者进程**

```
do {
    wait(mutex);
    readcount++;
    if (readcount == 1)
        wait(wrt);
    signal(mutex);

    ...
    reading is performed
    ...

    wait(mutex);
    readcount--;
    if (readcount == 0)
        signal(wrt);
    signal(mutex);
} while (1);
```

## 信号量存在的问题

- 信号量操作的不正确使用
  - `signal(mutex) ... wait(mutex)`
  - `wait(mutex) ... wait(mutex)`
  - 省略 `wait(mutex)` 或 `signal(mutex)`（或两者）

## 管程

- **高级同步构造**，允许并发进程之间安全共享抽象数据类型。

```
monitor monitor-name
{
  shared variable declarations
  procedure body P1(...) {
    ...
  }
  procedure body P2(...) {
    ...
  }
  procedure body Pn(...) {
    ...
  }
  { initialization code}
}
```

### 管程：互斥

- *最多一个进程*可以在管程*内部*执行。因此，管程内保证了*互斥*。
- 当一个进程调用管程过程并成功进入管程时，它是*唯一*在管程内执行的进程。
- 当一个进程调用管程过程而管程中已有进程在运行时，调用者将被*阻塞在管程之外*。
