

## 解决问题的初始尝试

- 仅有 2 个进程，*P*₀ 和 *P*₁
- 进程 *P*ᵢ 的通用结构（另一个进程 *P*ⱼ）

```c
do {
    entry section
    critical section
    exit section
    remainder section
} while (1);
```

- 进程可能共享一些公共变量以同步其动作。

## 算法 1

- 共享变量：
  - int turn; 初始时 turn = i （或 turn = j）
- 进程 *P*ᵢ：

```c
do {
    while (turn != i) ;
    critical section
    turn = j;
    remainder section
} while (1);
```

- 进程被强制以交替方式运行。
- 满足互斥，但不满足进展。

## 算法 2

共享变量

- boolean flag[2]; 初始时 flag[0] = flag[1] = false.
- flag[i] = true ⇒ *P*ᵢ 准备进入其临界区
- 进程 *P*ᵢ：

```c
do {
    flag[i] = true;
    while (flag[j]);
    critical section
    flag[i] = false;
    remainder section
} while (1);
```

- 满足互斥，但不满足进展。

## 下列算法正确吗？

- 进程 *P*ᵢ：

```c
do {
    while (flag[j]);
    flag[i] = true;
    critical section
    flag[i] = false;
    remainder section
} while (1);
```

## 算法 3——Peterson 的解决方案

- 结合了算法 1、2 的共享变量。
- 进程 *P*ᵢ：

```c
do {
    flag[i] = true;
    turn = j;
    while (flag[j] and turn == j);
    critical section
    flag[i] = false;
    remainder section
} while (1);
```

- 满足全部三个要求；解决了 **两个进程** 的临界区问题。

## Bakery 算法

### n 个进程的临界区

- 在进入其临界区之前，进程会获得一个号码。持有最小号码的进程进入临界区。
- 如果进程 *P*ᵢ 和 *P*ⱼ 获得相同的号码，若 *i < j*，则 *P*ᵢ 先被服务；否则 *P*ⱼ 先被服务。
- 编号方案始终按枚举的递增顺序生成数字；即 1,2,3,3,3,3,4,5...

```c
do {
    choosing[i] = true;
    number[i] = max(number[0], number[1], ..., number[n - 1]) + 1;
    choosing[i] = false;
    for (j = 0; j < n; j++) {
        while (choosing[j]);
        while ((number[j] != 0) && ((number[j], j) < (number[i], i)));
    }
    critical section
    number[i] = 0;
    remainder section
} while (1);
```

## 硬件支持

- 有两种类型的硬件同步支持
  - 禁用/启用中断
    - 这在多处理器系统上实现缓慢且困难。
  - 特殊机器指令
    - TestAndSet (TS)
    - Swap

## 中断禁用

```c
do {
    disable interrupts
    critical section
    enable interrupts
} while (1);
```

- 由于中断被禁用，临界区内不会发生上下文切换。
- 在多处理器系统中不可行，因为必须通知所有 CPU。
- 依赖于中断的一些功能（例如，时钟）可能无法正常工作。

## TestAndSet

- 原子地测试并修改一个字的內容

```c
boolean TestAndSet(boolean *target)
{
    boolean rv = *target;
    *target = true;
    return rv;
}
```

## 使用 TestAndSet 实现互斥

- 共享数据：

```c
boolean lock = false;
```

- 进程 *P*ᵢ：

```c
do {
    while (TestAndSet(&lock));
    critical section
    lock = false;
    remainder section
} while (1);
```

## Swap

- 原子地交换两个变量。

```c
void Swap(boolean *a, boolean *b)
{
    boolean temp = *a;
    *a = *b;
    *b = temp;
}
```
