

## 基于区段的系统

- 许多较新的文件系统（例如，Veritas 文件系统）使用修改后的连续分配方案。
- 基于区段的文件系统以区段为单位分配磁盘块。
- 区段是一组连续的块。
  - 区段用于文件分配。
  - 一个文件由一个或多个区段组成。

## 链接分配

- 每个文件都是磁盘块的链表。
- 块可以散布在磁盘的任何位置。

![](img/0f9477f9dd9e571abf0b2ce4550a9e88_705_0.png)

- 简单 – 只需起始地址和结束地址
- 空闲空间管理系统 – 不浪费空间
- 文件可以增长
- 不支持随机访问
- 每个块包含一个指针，浪费空间
- 块散布各处，可能需要大量磁盘寻道
- 可靠性：如果指针丢失或损坏怎么办？

## 空闲空间管理

- 我们如何跟踪磁盘上的空闲块？
- 维护一个空闲空间列表。当请求新块时，我们搜索此列表以找到一个。
- 常用技术如下：
  - 位向量
  - 链表
  - 链表 + 分组
  - 链表 + 地址 + 计数

## 位向量

- 位向量（n 个块）

![](img/0f9477f9dd9e571abf0b2ce4550a9e88_716_0.png)

```
bit[i] = {
    1 ⇒ block[i] free
    0 ⇒ block[i] occupied
}
```

### 块号计算

```
(number of bits per word) *
(number of 0-value words) +
offset of first 1 bit
```

## 分组

- 第一个空闲块包含其他 *n* 个空闲块的地址。
- 对于每个组，前 *n-1* 个块实际上是空闲的，最后一个（即第 *n* 个）块包含下一组的地址。
- 这样，我们可以快速定位空闲块。

![](img/0f9477f9dd9e571abf0b2ce4550a9e88_719_0.png)

## 效率和性能

- **效率取决于：**
  - 磁盘分配和目录管理算法
  - 文件目录项中保存的数据类型
- **性能：**
  - 磁盘缓存 – 为频繁使用的块专门划分的主内存区域
  - free-behind（马上释放）和 read-ahead（预先读取） – 优化顺序访问的技术
  - 通过将内存的一部分作为虚拟磁盘或 RAM 磁盘专用，来提高 PC 性能
