# 示例

```
BEGIN TRAN
read A
A←A−S
if A < 0 then    /* A款不足 */
    begin
        display “A款不足”
        ROLLBACK  /*出口1*/
    end
else
    begin
        B←B+S
        display "拨款完成"
        COMMIT    /*出口2*/
    end
```

ROLLBACK 撤销事务的影响，相当于 “do nothing”

COMMIT 提交，相当于 “do all”。只有在COMMIT之后，事务对数据库产生的变化才对其它事务开放。
