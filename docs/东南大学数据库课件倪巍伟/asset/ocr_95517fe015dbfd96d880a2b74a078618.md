# 常用转换规则

+   1. $\sigma_{c1\ AND\ c2...\ AND\ cn}(R) \equiv \sigma_{c1}(\sigma_{c2}(...(\sigma_{cn}(R))...))$
+   2. $\sigma_{c1}(\sigma_{c2}(R)) \equiv \sigma_{c2}(\sigma_{c1}(R))$
+   3. $\prod_{list_1}(\prod_{list_2}(...(\prod_{list_n}(R))...)) = \prod_{list1}(R),$ 
+      $list_1 \subseteq list_2 \subseteq ... \subseteq list_n$
+   4. $\prod_{A1,A2,...,An}(\sigma_c(R)) \equiv \sigma_c(\prod_{A1,A2,...,An}(R))$
+      $Attr(C) \subseteq \{A1, A2,..., An\}$
