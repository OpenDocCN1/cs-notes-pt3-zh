# 5.9.1 Transforming a Forest into a Binary Tree

Definition: If T₁,..., Tₙ is a forest of trees, then the binary tree corresponding to it, denoted by B(T₁,..., Tₙ),

+   (1) is empty if n=0

+   (2) has root equal to root(T₁); has left subtree equal to B(T₁₁,..., T₁ₘ), where T₁₁,..., T₁ₘ are the subtrees of root(T₁); and has right subtree B(T₂,..., Tₙ).
