+   - a list of records (R₁, R₂, ..., Rₙ)
+   - each Rᵢ has key value Kᵢ
+   - assume an ordering relation (<) on the keys, so that for any 2 key values x and y, x=y or x<y or x>y. < is transitive.

The **sorting problem** is that of finding a permutation, σ, such that K₍σ(i)₎ ≤ K₍σ(i+1)₎ , 1≤i≤n-1. The desired ordering is (R₍σ(1)₎, R₍σ(2)₎, ..., R₍σ(n)₎).
