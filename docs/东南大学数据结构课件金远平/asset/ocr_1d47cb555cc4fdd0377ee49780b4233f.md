# From the definition of f, we have the following rule for pattern matching:

If a partial match is found such that s_{i-j}...s_{i-1} = p_0 p_1...p_{j-1} and s_i ≠ p_j then matching may be resumed by comparing s_i and p_{f(j-1)+1} if j ≠ 0. If j=0, then we may continue by comparing s_{i+1} and p_0.

The failure function is represented by an array of integers f, which is a private data member of String.
