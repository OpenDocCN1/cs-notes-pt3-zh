To split the node, assume that following the insertion, p has the format

$m, A_0, (E_1, A_1), \ldots, (E_m, A_m)$ and $E_i \leq E_{i+1},\ K$, $1 \leq i \leq m$.

The node is split into 2 nodes, p and q, with the following formats:

node p: $\lceil m/2 \rceil - 1,\ A_0, (E_1, A_1), \ldots, (E_{\lceil m/2 \rceil - 1}, A_{\lceil m/2 \rceil - 1})$ \hfill (11.5)

node q: $m - \lceil m/2 \rceil,\ A_{\lceil m/2 \rceil}, (E_{\lceil m/2 \rceil + 1}, A_{\lceil m/2 \rceil + 1}), \ldots, (E_m, A_m)$

And the tuple $(E_{\lceil m/2 \rceil}, q)$ is to be inserted into the parent of p.
