# Analysis of SimpleUnion and SimpleFind:

Given $S=\{i\}$, $0 \le i < n$, do

Union(0,1), Union(1,2), ..., Union(n-2,n-1), Find(0), Find(1), ..., Find(n-1)    get

$n-1$ unions take $O(n)$

$n$ finds take $O\left(\sum_{i=1}^{n} i\right)=O(n^2)$.

Performance not very good:
to improve by avoiding the
creation of degenerate trees.
