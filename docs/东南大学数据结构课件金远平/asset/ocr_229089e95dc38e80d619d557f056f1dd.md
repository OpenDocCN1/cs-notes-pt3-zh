# Analysis of MergeSort:

Makes several passes. After the 1st pass, the result sublists are of size 2=2¹. After the ith pass, the size is 2ⁱ. Consequently, a total of ⌈log₂n⌉ passes are made, each takes o(n), the total time is O(n log n).

It is easy to verify that MergeSort is stable.
