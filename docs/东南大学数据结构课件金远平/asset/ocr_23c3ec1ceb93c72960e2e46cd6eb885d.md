# 5.3.2 Inorder Traversal

```
```cpp
template <class T>
void Tree<T>::Inorder()
{ // driver as a public member
    Inorder(root);
}
```
```

```
```cpp
template <class T>
void Tree<T>::Inorder (TreeNode<T>* currentNode)
{ // workhorse as a private member of Tree
    if (currentNode) {
        Inorder(currentNode→leftChild);
        Visit(currentNode)
        Inorder(currentNode→rightChild);
    }
}
```
