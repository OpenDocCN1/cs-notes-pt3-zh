# 7.3 Quick Sort

The quick-sort has the best average behavior among the sorting methods we shall be studying.

**Idea:** given a list (R_left, R_left+1, ..., R_right), select a pivot record from among R_i (left ≤ i ≤ right), put the pivot in the correct spot s(pivot) such that after the positioning,

R_j ≤ R_s(pivot)    for j<s(pivot)
R_j ≥ R_s(pivot)    for j>s(pivot)
