Then

$a_r=i,\ (1\le r\le n)$

$b_1,\ldots,b_{r-1}=i+1,\ i+2,\ldots,\ i+r-1,$

$c_1,\ldots,c_{n-r}=i+r,\ i+r+1,\ldots,j.$

Now with $i,i+1,\ldots,j$, we can get the inorder permutation through a stack.

First, put $a_r=i$ into the stack, then by induction hypothesis, with $b_1,\ldots,b_{r-1}=i+1,\ i+2,\ldots,i+r-1$, we can get $a_1,a_2,\ldots,a_{r-1}$. Pop $i$, we get $a_1,a_2,\ldots,a_{r-1},a_r$. Finally, with $c_1,\ldots,c_{n-r}=i+r,\ i+r+1,\ldots,j$, we can get $a_{r+1},\ldots,a_n$, following $a_1,a_2,\ldots,a_{r-1},a_r$, we get
