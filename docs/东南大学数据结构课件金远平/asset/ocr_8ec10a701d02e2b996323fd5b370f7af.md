# First, a very slow growing function

$\alpha(p,q)=\min\{z\ge 1\mid A(z,\lfloor p/q\rfloor)>\log_2 q\},\ p\ge q\ge 1$

And Ackermann’s function $A(i,j)$ is defined as:

+   $A(1,j)=2^j$ &nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; for $j\ge1$  
+   $A(i,1)=A(i-1,2)$ &nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; for $i\ge2$  
+   $A(i,j)=A(i-1,A(i,j-1))$ &nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; for $i,j\ge2$
