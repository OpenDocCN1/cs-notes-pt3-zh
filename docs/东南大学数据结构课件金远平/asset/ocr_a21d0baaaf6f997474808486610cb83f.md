# 11.2.2 Number of Elements in a B-tree

Let t be a B-tree of order m in which all external nodes are at level l+1, and let N the number of keys in t. Then

+   (1) N ≤ m^l-1 (upper bound).
+   (2) N ≥ 2⌈m/2⌉^l-1 -1 (lower bound).
