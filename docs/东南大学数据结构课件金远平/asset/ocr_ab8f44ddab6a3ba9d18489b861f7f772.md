# 5.1.1 Terminology

**Definition:** A tree is a finite set of one or more nodes such that
(1) There is a specially designated node called **root**.
(2) The remaining nodes are partitioned into n≥0 disjoint sets T₁,..., Tₙ, where each of these sets is a tree. T₁,..., Tₙ are called **subtrees** of the root.
