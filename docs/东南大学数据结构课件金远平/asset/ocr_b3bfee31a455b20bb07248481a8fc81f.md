Let a be the number of nodes in tree j and m-a that in tree k. without loss of generality, assume 1 ≤ a ≤ m/2. Then the height of T is either the same as that of k or is 1 + that of j.

![](bbox=[0.603, 0.049, 0.931, 0.544])

If the former is the case, the height of T ≤ ⌈log₂(m-a)⌉+1 ≤ ⌈log₂ m⌉+1.

If the latter is the case, the height of T ≤ ⌈log₂ a⌉+2 ≤ ⌈log₂ m/2⌉+2 ≤ ⌈log₂ m⌉+1.
