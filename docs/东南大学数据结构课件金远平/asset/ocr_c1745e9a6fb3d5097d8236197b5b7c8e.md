For large k (say, k ≥ 6), to select the smallest from the k possibilities, we can use a loser tree with k leaves.

The total time needed per level of the merge tree is O(n log₂k).

The merge tree has O(logₖm) levels, the total internal merge time is

O(n log₂k logₖm) = O(n log₂m)

which is independent of k!
