+   - internal nodes --- the circular nodes.
+   - external nodes --- the square nodes.

Given n runs, there are n external nodes in the merge tree. Let the external nodes numbered 1 to n, qᵢ be the size of the run node i represents, dᵢ be the distance from the root to the external node i, 1≤i≤n. Then the total merge time is

$$E_w = \sum_{1\le i\le n} q_i d_i$$

The E_w is called the weighted external path length.
