# Proof:

Let n₁ be the number of nodes of degree 1 and n the total number of nodes, we have

n = n₀ + n₁ + n₂      (5.1)

Each node except for the root has a branch leading into it. If B is the number of branches, then n = B+1. And also B = n₁ + 2n₂, hence

n = n₁ + 2n₂ + 1      (5.2)

(5.1) − (5.2): 0 = n₀ − n₂ −1, i.e., n₀ = n₂ +1.
