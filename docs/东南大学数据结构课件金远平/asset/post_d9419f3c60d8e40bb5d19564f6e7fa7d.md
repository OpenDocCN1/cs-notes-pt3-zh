## First, a very slow growing function

$\alpha(p,q)=\min\{z\ge 1\mid A(z,\lfloor p/q\rfloor)>\log_2 q\},\ p\ge q\ge 1$

And Ackermann’s function $A(i,j)$ is defined as:

+   $A(1,j)=2^j$          for $j\ge1$  
+   $A(i,1)=A(i-1,2)$          for $i\ge2$  
+   $A(i,j)=A(i-1,A(i,j-1))$          for $i,j\ge2$

A(1, 2) = 2²

A(3,1) = A(2, 2) = A(1, A(2, 1)) = A(1, A(1, 2))
    = 2²² = 16

A(4,1) = A(3, 2) = A(2, A(3, 1)) = A(2, 16)
    = A(1, A(2, 15)) = 2^{A(2, 15)}
    = 2^{2^{A(2, 14)}} = ... = 2^{2^{...^{2}}} 16   (very big !)

So for any practical p and q, α(p,q) ≤ 4.

## Lemma 5.6 [Tarjan and Van Leeuwen]: Assume we start with a forest of trees, each having one node. Let T(f, u) be the maximum time required to process any intermixed sequence of f finds and u unions. Assume u ≥ n/2, then

$$k_1(n+f\,\alpha(f+n,n)) \le T(f,u) \le k_2(n+f\,\alpha(f+n,n))$$

For some positive constants $k_1$ and $k_2$.

Note T(f, u) is not linear even though $\alpha(f+n,n)$ grows very slow.

The space requirements are one node for each element.

## 5.10.3 Application to Equivalent Classes

equivalence classes ⇔ disjoint sets

Initially, parent[i] = -1, 0 ≤ i ≤ n-1.

To process i ≡ j,

Let x = find(i), y = find(j) --- 2 finds

If x ≠ y then union(x, y) --- at most 1 union

Thus if we have n elements and m equivalence pairs, we needs 2m finds and min {n-1, m} unions. The total time is O(n+2m α(n+2m,n)).
