# Section 2 Specification of a Simple Type Checker

+   1. A simple language

+   2) The part of a translation scheme that saves the type of an identifier.

+   - P→D;E

+   - D→D;D

+   - D→ id:T    {addtype(id.entry, T.type)}

+   - T→char    {T.type=char}

+   - T→ integer    {T.type=integer}

+   - T→ array [num] of T    {T.type=array(1..num,T₁.type)}

+   - T→ ^T₁    {T.type=pointer(T₁.type)}
