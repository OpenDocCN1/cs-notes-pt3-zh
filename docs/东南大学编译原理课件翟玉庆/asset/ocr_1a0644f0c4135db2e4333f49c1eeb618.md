# Chapter 5 Syntax-Directed Translation
Section 1 Syntax-Directed Definitions

# 3、 Attribute grammar

A syntax-directed definition in which the functions in semantic rules cannot have side effects.

Notes: (1)Functions in semantic rules will often be written as expressions.

(2) Occasionally, semantic rules are written as procedure calls or program fragments (in the time, we name the attribute of non-terminal as a dummy attribute)

(3)Values for attributes of terminals are usually supplied by the lexical analyzer
