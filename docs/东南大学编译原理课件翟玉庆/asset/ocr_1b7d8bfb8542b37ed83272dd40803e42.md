# 4) Stack allocation for nested procedures

```
Program M;
var A,B:integer
function F(N:integer):integer;
    if N<=2 then teturn(N)
    else return (N*F(N-1));
begin
    read(A);      /*Let A=5*/
    B:=F(A);
    write (B);
end.
```
