# Section 5  LR parsers

# 7、The algorithm

— If $action[S_m,a_i]=reduce\ A\to\alpha$, then the parser executes a reduce move. If the length of α is γ, then delete γ states from the stack, so that the state at the top of the stack is $S_{m-γ}$. Push the state $S'=GOTO[S_{m-γ},A]$ and non-terminal A into the stack. The input symbol does not change.
