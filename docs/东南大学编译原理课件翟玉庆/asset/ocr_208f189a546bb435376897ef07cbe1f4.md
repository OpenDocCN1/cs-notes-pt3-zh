# 2. Type Systems

+   - A type system is a collection of rules for assigning type expressions to the various parts of a program.

+   Note:
+   1) A type checker implements a type system
+   2) The type systems are specified in a syntax-directed manner
+   3) Different type systems may be used by different compilers or processors of the same language
