# 2、Grammar Simplification

**Example:** Simplify the following grammar

```
(0)S → Be    (1)S → Ec    (2)A → Ae    (3)A → e
(4)A → A     (5)B → Ce    (6)B → Af    (7)C → Cf
(8)D → f
```

**Result:**

```
(0) S → Be       (1)A → Ae       (2)A →e
(3)B → Af
```
