Section 7 Regular Grammar to an NFA

# 1、Basic properties

+   - For each regular grammar G=(V_N,V_T,P,S), there is an FA M=(Q,Σ,f,q0,Z), and L(G)=L(M).
+   - For each FA M, there is a right-linear grammar and a left-linear grammar recognize the same language. L(M)=L(G_R)=L(G_L)
