# 1、Constructing a grammar from a language

Example 2: Let $L_2=\{a^i b^j c^k\mid i,j,k\geq 1\text{ and }a,b,c\in V_T\}$

Try to construct the grammar $G_2$ from $L_2$

```
S → aS　　　　　　S → aB
B → bB　　　　　　B → bC
C → cC | c
```
