# Section 1 Syntax-Directed Definitions

# 10、 L-attributed Definition

+   1) L-attributes can always be evaluated in depth-first order
+   
+   2) “L” means “left”, because L-attribute information appears to flow from left to right
+   
+   3) Every S-attributed definition is L-attributed, because the restrictions in the definition apply only to inherited attributes.
