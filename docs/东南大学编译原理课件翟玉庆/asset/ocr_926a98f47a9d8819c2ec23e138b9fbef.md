# 7. Translation methods of Flow of control statements in Short-circuit code

3)Examples

(2)while a<b do

if c<d then x=y+z

else x=y-z

```
L1: if a<b goto L2
goto Lnext
L2: if c<d goto L3
goto L4
L3:t1=y+z
x=t1
goto L1
L4:t2=y-z
x=t2
goto L1
Lnext:
```
