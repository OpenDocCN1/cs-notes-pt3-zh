# Section 2 Specification of a Simple Type Checker

# 2. Type Checking of Expressions

+   - `E → literal`       `{E.type=char}`
+   - `E → num`          `{E.type=integer}`
+   - `E → id`            `{E.type=lookup(id.entry)}`
+   - `E → E₁ mod E₂`
+     - `{E.type= if (E₁.type==integer) && (E₁.type==integer) integer else type_error}`
