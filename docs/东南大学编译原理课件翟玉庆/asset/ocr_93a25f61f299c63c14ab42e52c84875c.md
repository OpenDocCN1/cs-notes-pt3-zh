# CHAPTER 4 SYNTAX ANALYSIS

# Section 5 LR parsers

# 13、 LR(1) item

+   - How to rule out invalid reductions?
+     - By splitting states when necessary, we can arrange to have each state of an LR parser indicate exactly which input symbols can follow a handle α for which there is a possible reduction to A.

+   - Item (A→α•β,a) is an LR(1) item, “1” refers to the length of the second component, called the look-ahead of the item.
