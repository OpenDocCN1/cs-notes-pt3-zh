# 1、Basic concepts

# a、Grammar

Grammar is the formal production rules
describing the construction of syntax elements.

Notes:  1) Syntax elements include sentences and
words in sentences, a language is composed of
sentences.

2) The form of a production rule is as following:

left-side→right-side (that can be read as “left-
side is defined as right-side”, “left-side derives
right-side”,or “left-side produces right-side”, it
expresses the relation between the two sides)
