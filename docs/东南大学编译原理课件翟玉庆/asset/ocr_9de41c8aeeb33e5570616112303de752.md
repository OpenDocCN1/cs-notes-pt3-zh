# Section 5  LR parsers

# 18、An easy, but space-consuming LALR table construction

— (4) If J is the union of one or more sets of LR(1) items, that is, J = I₁ ∪ I₂ ∪ … ∪ Iₖ, then the cores of goto(I₁, X), goto(I₂, X), …, goto(Iₖ, X) are the same, since I₁, I₂, …, Iₙ all have the same core. Let K be the union of all sets of items having the same core as goto(I₁, X), then goto(J, X) = K.
