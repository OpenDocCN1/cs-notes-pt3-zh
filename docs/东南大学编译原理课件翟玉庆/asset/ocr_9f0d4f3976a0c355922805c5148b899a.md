# 5、 Notational Short-hands

+   a) One or more instances
+     ( r )+   digit+

+   b) Zero or one instance
+     r? is a shorthand for r|ε   (E(+|-)?digits)?

+   c) Character classes
+     [a-z] denotes a|b|c|...|z
+     [A-Za-z] [A-Za-z0-9]
