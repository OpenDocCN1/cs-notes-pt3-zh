# Section 3  Grammar construction and simplification

# 1、Constructing a grammar from a language

Example 1: Let L₁={a²ⁿbⁿ|n>=1 and a,b ∈ Vₜ}

Try to construct the grammar G₁ from L₁

+   Let n=1,  L₁=aab
+   n=2,  L₁=aaaabb
+   n=3,  L₁=aaaaaabbb
+   ……

So we have:

```
S → aaSb
S → aab
```
