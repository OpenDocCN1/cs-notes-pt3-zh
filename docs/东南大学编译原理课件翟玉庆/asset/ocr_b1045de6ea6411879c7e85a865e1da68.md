# Section 4 Finite automata

# 3、 Deterministic FA (DFA)

DFA is a quintuple, M(S,Σ,move,s₀,F)

+   - S: a set of *states*
+   - Σ: the input symbol alphabet
+   - move: a transition function, mapping from S×Σ to S, *move(s,a)=s′*
+   - s₀: the *start* state, s₀ ∈ S
+   - F: a set of states F distinguished as *accepting* states, F⊆S
