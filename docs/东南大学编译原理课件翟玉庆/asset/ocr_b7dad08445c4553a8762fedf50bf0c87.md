# Section 4  Operator-precedence parsing

5、Construct the operator-precedence relationship table

FIRSTVT(P) =

$\{a\mid P\rightarrow a\cdots\text{ or }P\rightarrow Qa\cdots,\ a\in V_T;\ P,Q\in V_N\}$

LASTVT(P) =

$\{a\mid P\rightarrow\cdots a\text{ or }P\rightarrow\cdots aQ,\ a\in V_T;\ P,Q\in V_N\}$

> Note: Using these two sets and the productions, we can specify the < and > relation easily.
