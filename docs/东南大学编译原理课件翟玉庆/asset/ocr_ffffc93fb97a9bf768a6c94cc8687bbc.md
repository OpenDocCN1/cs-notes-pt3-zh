# (4) Phrase

A string of end-symbol sequence from left to right in a sub-tree is called a phrase relating to the root of the sub-tree.

+   - **Simple phrase (Direct phrase):** If a phrase is derived by 1 step from the root of a sub-tree, the phrase is called a simple phrase relating to the root of the sub-tree.
+   - **Phrase in a sentential form:** A phrase to a sub-tree relating to the sentential form
