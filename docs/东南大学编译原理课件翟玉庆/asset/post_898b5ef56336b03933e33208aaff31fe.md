##### (4) displays

- Faster access to global than with access links can be obtained using an array d of pointers to activation records, called a display.

- Suppose control is in an activation of a procedure pj at nesting depth j, then the display of activation of pj is:

|  |  |
|---|---|
| j | Sp for pj |
| j−1 | Sp for pj-1 |
|  | ...... |
| 0 | Sp for p0 |
|  | d[j+1] |

- When a new activation record for a procedure at nesting depth i is setup, we
- A) save the value of d[i] in the new activation record;
- B) set d[i] to point to the new activation record.

##### (5) non-displays

non-display of current procedure = non-display of caller + start address of current local activation record
