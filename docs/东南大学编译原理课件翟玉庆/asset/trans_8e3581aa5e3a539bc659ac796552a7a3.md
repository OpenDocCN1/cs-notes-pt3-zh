

## 第5章 语法制导翻译
### 第2节 S-属性定义的自底向上求值
### 1、 基本思想

- 在输入被解析时由自底向上分析器求值。
- 分析器在其栈上保存与文法符号相关联的综合属性值。
- 当进行规约时，新综合属性的值由规约产生式右侧文法符号在栈上出现的属性计算得出。

Notes:
1) S-属性定义的翻译器通常可以用 LR 分析器实现
2) 栈用于保存已解析的子树的有关信息。
3) 我们可以在分析器栈中使用额外字段来保存综合属性的值

E.g.

| State | Symbol | Val |
| --- | --- | --- |
| ... |  | ... |
|  | X | X.val |
|  | Y | Y.val |
| ... |  | ... |

## 第6章 类型检查
### 第1节 类型系统

1. Type Expressions
  - 表示语言构造的类型
  - 1) 基本类型是类型表达式。
  - 2) 类型名是类型表达式。
  - 3) 应用于类型表达式的类型构造器是类型表达式。构造器包括：
    - 数组、乘积、记录、指针、函数
  - 4) 类型表达式可能包含其值是类型表达式的变量。
