# 3)属性的类型

+   - 综合属性
+     - 分析树中某节点上的综合属性值是由该节点的子节点上的属性值计算得到的。

+   - 继承属性
+     - 继承属性的值是由该节点的兄弟节点和父节点上的属性值计算得到的。
