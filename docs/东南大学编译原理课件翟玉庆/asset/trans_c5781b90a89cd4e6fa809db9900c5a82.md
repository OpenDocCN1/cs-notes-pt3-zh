##### (4) 显示表

- 与访问链接相比，使用一个指向活动记录的指针数组 d（称为显示表）可以更快地访问全局变量。

- 假设控制权位于嵌套深度为 j 的过程 pj 的一次活动中，则 pj 活动的显示表为：

|  |  |
|---|---|
| j | pj 的 Sp |
| j−1 | pj-1 的 Sp |
|  | ...... |
| 0 | p0 的 Sp |
|  | d[j+1] |

- 当为嵌套深度为 i 的过程建立一个新的活动记录时，我们需要
- A) 将 d[i] 的值保存在新的活动记录中；
- B) 设置 d[i] 指向新的活动记录。

##### (5) 非显示表

当前过程的非显示表 = 调用者的非显示表 + 当前局部活动记录的起始地址
