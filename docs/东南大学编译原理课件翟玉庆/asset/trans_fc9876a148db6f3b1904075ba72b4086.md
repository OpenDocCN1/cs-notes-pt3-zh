**2) 语义规则**

```text
C → if E then   { BACKPATCH(E•TC, NXINSTR);
                  C•CHAIN = E•FC; }

S → C S⁽¹⁾      { S•CHAIN = MERG(C•CHAIN, S⁽¹⁾•CHAIN); }
```

### 第3节 四元式

**1. 三地址语句的实现**

- 四元式
  - (op, arg1, arg2, result)
- 三元式
  - (n) (op, arg1, arg2)
  - (m) (op, (n), arg)

**注意：**三地址语句是中间代码的一种抽象形式。

**2. 四元式的优点**

- 易于生成目标代码
- 有利于优化

**3. 仅含标识符的赋值语句**

**1) 函数**

```text
NEWTEMP()
GEN(OP, ARG₁, ARG₂, RESULT)
```

**2) 四元式代码生成的语义规则**

```text
(1) A → i = E   { GEN(=, E•PLACE, _, i.entry); }

(2) E → - E⁽¹⁾ { T = NEWTEMP();
                  GEN(@, E⁽¹⁾•PLACE, _, T);
                  E•PLACE = T; }

(3) E → E⁽¹⁾ * E⁽²⁾ { T = NEWTEMP();
                       GEN(*, E⁽¹⁾•PLACE, E⁽²⁾•PLACE, T);
                       E•PLACE = T; }

(4) E → E⁽¹⁾ + E⁽²⁾ { T = NEWTEMP();
                       GEN(+, E⁽¹⁾•PLACE, E⁽²⁾•PLACE, T);
                       E•PLACE = T; }

(5) E → ( E⁽¹⁾ ) { E•PLACE = E⁽¹⁾•PLACE; }

(6) E → i        { E•PLACE = i.entry; }
```

**4. 数组元素寻址的翻译方案**

**1) 文法**

```text
A → V := E
V → i [ Elist ] | i
Elist → Elist , E | E
E → E op E | ( E ) | V
```

**2) 文法的重写**

```text
A → V := E
V → Elist ] | i
Elist → Elist⁽¹⁾ , E | i [ E
E → E op E | ( E ) | V
```

**注意：**这种重写的目的是，当我们把下标表达式归并为 Elist 时，数组的各维界限 n_j 是可用的。
