# 1.5 Basic Program Execution Registers

# The low 12 bits of EFLAG

![](bbox=[0.05, 0.19, 0.88, 0.32])

| Flag | Name | Description |
|---|---|---|
| DF | direction flag | Setting the DF flag causes the string instructions to auto-decrement. Clearing the DF flag causes the string instructions to auto-increment. |
| OF | Overflow flag | Set if the integer result is too large a positive number or too small a negative number (excluding the sign-bit) to fit in the destination operand; cleared otherwise. |
