# String Comparisons Instruction

Example:

Compare SOURCE and DESTIN, if not same, load the first char in SOURCE that not match into AL register

```
...
LEA SI, SOURCE
LEA DI, DESTIN
CLD
MOV CX,100
REPZ CMPSB
JCXZ MATCH
DEC SI ; When terminal the loop, (E)SI and
; (E)DI point to the next position
LODSB
...
```
