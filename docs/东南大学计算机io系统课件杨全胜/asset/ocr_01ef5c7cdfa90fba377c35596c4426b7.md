# 2.6.3 Logic Instructions

# Shift and Rotate Instruction

# Example

Convert ASCII string ‘96’ to packed BCD 96H

ASC
‘9’
‘6’ → BCD
96H

```
MOV AL, ASC        ; AL<--39H (‘9’)
MOV CL, 4
SHL AL, CL         ; 39H->90H
MOV BL, AL         ; BL<--90H
MOV AL, ASC+1      ; AL<--36H (‘6’)
AND AL, 0FH        ; AL<--06H
OR  BL, AL         ; BL<--96H
MOV BCD, BL
```
