# 2.6.7 Procedure Instructions

# Procedure Define

```
LABEL PROC [attributes]
...; procedure body
RET
...; procedure body
LABEL ENDP
```

+   - Procedure body always follows a .CODE directive.
+   - Procedure body is bracketed by two directives, PROC and ENDP
+   - Label gives the name of the procedure.
+   - Attributes: near or far
+   - At least has one RET instruction
