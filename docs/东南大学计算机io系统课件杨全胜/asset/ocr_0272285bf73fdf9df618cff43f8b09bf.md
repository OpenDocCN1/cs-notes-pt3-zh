# Conditional Jump (Jcc)

Example:

```
CMP AX,0FFFFH
JLE P3    ; AX≤-1
CMP AX,1
JL  P2    ; AX<1
MOV AX, 1 ;AX≥1
JMP DONE
P2: MOV AX, 0
JMP DONE
P3: MOV AX,-1
DONE:
```
