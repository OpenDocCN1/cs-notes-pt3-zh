# 2.6.2 Arithmetic Instructions

Suppose X, Y, Z, V are 16-bit signed number, calculate (V-(X*Y+Z))/X. Quotient in AX, Remainder in DX

```
MOV  AX, X
IMUL Y                 ; X*Y
MOV  CX, AX
MOV  BX, DX            ; store in BX: CX
MOV  AX, Z
CWD                    ; signed extend the Z
ADD  CX, AX            ; X*Y+Z
ADC  BX, DX
MOV  AX, V
CWD                    ; signed extend the V
SUB  AX, CX            ; -
SBB  DX, BX
IDIV X                 ; Divided by X
```
