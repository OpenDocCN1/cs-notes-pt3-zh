# 2.6.6 String Instructions

# String Comparisons Instruction

# SCAS Instruction

Compare a byte, word, or double word from the data segment location addressed by (E)DI with AL, AX, or EAX.

| Assemble Language | Operation |
|---|---|
| SCASB | ES:[DI]-AL; if (DF=0) DI=DI+1 else DI=DI-1 |
| SCASW | ES:[DI]-AX; if (DF=0) DI=DI+2 else DI=DI-2 |
| SCASD | ES:[DI]-EAX; if (DF=0) DI=DI+4 else DI=DI-4 |
