# 7.3 RS-232 Standard

# RS-232 (Recommended Standard 232)

# Signals

| DB-25pin | Abbreviation | Name | Direction |
|---|---|---|---|
| 1 | PG | Protective Ground | Common |
| 2 | TxD, SD | Transmitted Data | DTE→DCE |
| 3 | RxD | Received Data | DCE→DTE |
| 4 | RTS, RS | Request To Send | DTE→DCE |
| 5 | CTS, CS | Clear To Send | DCE→DTE |
| 6 | DSR, MR | Data Set Ready | DCE→DTE |
| 7 | GND | Common Ground | Common |
| 8 | RLSD, DCD | Data Carrier Detect | DCE→DTE |
| 20 | DTR | Data Terminal Ready | DTE→DCE |
| 22 | RI | Ring Indicator | DCE→DTE |
