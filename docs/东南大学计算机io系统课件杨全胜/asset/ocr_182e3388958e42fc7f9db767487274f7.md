# 4.2 8259A PIC

# Operation and commands

+   - **Port Address**
+     - Only two port address.
+   - **Command**
+     - Initialization Command Words
+       - ICW1, ICW2, ICW3 and ICW4
+     - Operation Command Words
+       - OCW1, OCW2, OCW3
+   - **Status can be read**
+     - IRR, ISR, IMR, Status Word
+   - **The way that use a few addresses to read/write more commands and status**
+     - Data has free bits: Characteristic bit(CHB)
+     - Data has no free bits: Timing sequence(TS); R/W
