# Using Simplified Segment Directives

# Create Data Segment

```
.DATA
```

+   The .DATA directive creates a near the initialized data segment (with segment name _DATA) and ends the previous segment, if any. The .DATA segment should contain all global data that have initial values.

+   The .DATA segment can occupy up to 64K in MS-DOS or 512 megabytes under flat model in Windows.

+   You can use @data to determine the group of the data segment.
