# Numeric Data Types

# Integer

# Unsigned Integers

+   - Unsigned integers are unsigned binary numbers contained in a byte, word, doubleword, and quadword.
+   - Unsigned integers are sometimes referred to as ordinals.

# Signed Integers

+   - Signed integers are signed binary numbers held in a byte, word, doubleword, or quadword.
+   - All operations on signed integers assume a two's complement representation.
