# 5.2 Structure and pins of 8254

# Operation and Command

+   Method of read data from T/C

+   Read state by Read-Back Command(A1A0=11)

+   Status word

| D7 | D6 | D5 | D4 | D3 | D2 | D1 | D0 |
|---|---|---|---|---|---|---|---|
| OUTPUT | NULL COUNT | RW1 | RW0 | M2 | M1 | M0 | BCD |

D7 1 = Out Pin is 1
0 = Out Pin is 0
D6 1 = Null count
0 = Count available for reading
D5-D0 Counter Programmed Mode

```
MOV AL, 11100100B ; T/C₁, latch the state
OUT 43H, AL
```

```
IN AL, 41H ; Suppose AL=00110101, means T/C₁ in mode 2 ; BCD, least significant byte first, out pin = 0
```

```
MOV AL, 11100010B ; T/C₀, latch the state
OUT 43H, AL
```

```
IN AL, 40 ; if AL=00010110, means T/C₀ in mode 3, Binary ; least significant byte only, out pin = 0
```
