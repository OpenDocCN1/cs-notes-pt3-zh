# String Data Transfer Instructions

# MOVS Instruction example for 16-bit program

```
.8086                ; create 16 bit code
.model small         ; 16 bit memory model
.data
lpstring DWORD ?
buff1  BYTE "HELLO,WORD!",13,10,'$'
buff2  BYTE 20 DUP('$')
.code
start:
    mov ax,@data
    mov ds,ax
    mov es,ax
```

```
mov si,offset buff1
mov di,offset buff2
mov cx,14
cld
rep movsb
mov dx,offset buff2
mov ah,9
int 21h   ; print string
mov ax,4c00h
int 21h   ; exit
end start
```
