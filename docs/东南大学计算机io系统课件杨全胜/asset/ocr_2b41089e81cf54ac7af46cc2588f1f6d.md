# 5.4 8254 in PCH

# Counter 1, Refresh Request Signal

+   - Frequency of CLK1 is 1.1931816MHz; initial count is 18.
+   - This counter provides the refresh request signal and is typically programmed for Mode 2 operation and only impacts the period of the REF_TOGGLE bit in Port 61.
+   - OUT1 connect DREQ0 in 8237, every 15.08µs have a width of 838ns pulse for RAM refresh.
