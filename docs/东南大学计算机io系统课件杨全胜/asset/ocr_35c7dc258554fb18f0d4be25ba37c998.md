# Comparison Instruction (CMP)

A CMP is normally followed by a conditional jump instruction, which tests the condition of the flag bits.

+   - For unsigned comparison
+     - if ZF=1, then DST = SRC
+     - if CF=0, then DST ≥ SRC
+     - if CF=1, then DST < SRC

+   - For signed comparison
+     - if ZF=1, then DST = SRC
+     - if SF=OF, then DST ≥ SRC
+     - if SF<>OF, then DST < SRC
