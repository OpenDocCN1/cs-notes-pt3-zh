# Control Word Format

| D7 | D6 | D5 | D4 | D3 | D2 | D1 | D0 |
| SC1 | SC0 | RW1 | RW0 | M2 | M1 | M0 | BCD |

M — MODE:

| M2 | M1 | M0 | |
| 0 | 0 | 0 | Mode 0 |
| 0 | 0 | 1 | Mode 1 |
| X | 1 | 0 | Mode 2 |
| X | 1 | 1 | Mode 3 |
| 1 | 0 | 0 | Mode 4 |
| 1 | 0 | 1 | Mode 5 |

BCD:

|  | |
| 0 | Binary Counter 16-bits |
| 1 | Binary Coded Decimal (BCD) Counter (4 Decades) |

```
e.g.: MOV AL, 01110100B ; T/C₁, least significant byte first
OUT 43H, AL ; mode 2, Binary
```
