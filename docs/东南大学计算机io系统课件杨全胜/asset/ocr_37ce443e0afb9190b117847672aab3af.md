# 2.6.7 Procedure Instructions

# ■ Procedure Define

**Define a procedure to output CRLF to screen. (16bit program use)**

```
CRLF  PROC NEAR    ; output Carriage Return and Line Feed
      PUSH AX
      PUSH DX
      MOV  DL, 0DH    ; Carriage Return
      MOV  AH, 2
      INT  21H       ; output char in DL
      MOV  DL, 0AH    ; Line Feed
      MOV  AH, 2
      INT  21H       ; output char in DL
      POP  DX
      POP  AX
      RET
CRLF  ENDP
```
