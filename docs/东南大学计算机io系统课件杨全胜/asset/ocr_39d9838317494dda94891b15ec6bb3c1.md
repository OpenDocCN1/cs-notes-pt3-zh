# Square Wave Generator that Duty cycle is 4:9

The frequency of the CLK0 in 8254 is 8KHz, then

+   1) What is the maximum period of OUT0?

+   2) Now wish the port address of 8254 is 90H, 92H, 94H and 96H, please design the decoding circuit by 74LS138 and some Gate.

+   3) Now want to generate the square wave which period is 9s and the duty cycle is 4:9. Please complete the above circuit the realize the decoder, and programming it.

Answer:
1) T_CLK0=1/f_CLK0=1/8000=0.125ms
Maximum period =65536×0.125ms=8.192 second
or: f_CLK0/f_OUT=65536=>T_max=1/f_OUT=65536/ f_clk0 =65536/8000=8.192 second
