In order to ensure the transmission of asynchronous serial communication is correct:

+   1) Opposite polarity of the start bit and stop bit / idle bit to provide an accurate time base

+   2) Receiver using a higher frequency than the baud rate clock to control the sampling time to improve the sampling resolution and anti-jamming capability.

+   3) Receiver sample in the center of each bit to get the maximum of the transmit / receive clock frequency
