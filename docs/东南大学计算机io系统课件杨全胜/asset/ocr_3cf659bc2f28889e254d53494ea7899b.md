# The Query Word

| D7 | D6 | D5 | D4 | D3 | D2 | D1 | D0 |
|---|---|---|---|---|---|---|---|
| I | - | - | - | - | W2 | W1 | W0 |

+   - **W2 – W0**: Binary code of the highest priority level requesting service.
+   - **I**: Equal to "1" if there is an interrupt.
