# 2.6.1 Data Movement Instructions

# Miscellaneous data transfer instructions

# XCHG Instruction

+   - Exchanges the contents of a register with the contents of any other register or memory location.
+   - Can’t exchange segment registers or memory-to-memory data

| Symbolic | Example |
|---|---|
| XCHG *reg8/16/32*, *reg8/16/32* | XCHG AL,CL |
| XCHG *reg8/16/32*, *mem8/16/32* | XCHG AX,DATA1 |
| XCHG *mem8/16/32*, *reg8/16/32* | XCHG DATA2, EAX |
