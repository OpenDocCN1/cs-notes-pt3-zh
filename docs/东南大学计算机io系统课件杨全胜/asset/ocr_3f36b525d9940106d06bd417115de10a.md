# 4.4 Interrupt process in Modern PC

# Interrupt-handling routine programming

+   - Save the context
+     - The register will be used in interrupt-handling routine must be push in stack.

+   - Avoid DOS reentrant in the interrupt handler for non-software interrupt
+     - You can not use DOS system calls(int 21h) in the interrupt handler. But BIOS calls can be used.

+   - The interrupt handler must small and execute quickly.
+     - The execute time of interrupt handler must less than the minimum time interval of interrupts.
+     - You can't use long loop and the human-computer interaction in interrupt handler.
