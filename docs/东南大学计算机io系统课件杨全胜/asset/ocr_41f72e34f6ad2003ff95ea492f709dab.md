# 2.6.7 Procedure Instructions

**Main program:**

```
LEA BX,ARRAY    ; parameter in stack
PUSH BX
LEA BX,COUNT
PUSH BX
LEA BX,SUM
PUSH BX
CALL PROSUM
......

PROSUM PROC NEAR
    PUSH BP
    MOV BP,SP
    PUSH AX
    PUSH CX
    PUSH SI
    PUSH DI
```
