# 3.5 Personal Computer I/O Map

+   - I/O Port Address
+     - I/O Port number
+       - Registers in the I/O modules are numbered, this number is called the ports number
+     - I/O Ports Address
+       - I/O Ports Address = the base address of I/O module(Interface) + Ports number
+     - Note:
+       - There are many ports in one I/O module(Interface)
+       - One I/O port address can receive a variety of command, corresponding to multiple registers.
