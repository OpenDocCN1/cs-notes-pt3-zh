# 2.6.3 Logic Instructions

# ▪ Basic Logic Instructions

```
AND  DST, SRC  ; (DST) <-- (DST) & (SRC)
OR   DST, SRC  ; (DST) <-- (DST) | (SRC)
XOR  DST, SRC  ; (DST) <-- (DST) xor (SRC)
```
