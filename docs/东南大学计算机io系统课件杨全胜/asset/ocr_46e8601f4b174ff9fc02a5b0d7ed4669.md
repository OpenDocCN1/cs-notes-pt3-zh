# Loop Instructions

Example2

Find the first none-zero byte in a byte string

Suppose the fist address of string in DI, and the last one in BX

```
SUB BX, DI          ; length of string →BX
INC BX
MOV CX, BX          ; length of string →CX
DEC DI
AGAIN: INC DI       ; modify pointer
CMP BYTE PTR [DI], 0 ; =0?
LOOPZ AGAIN         ; loop until found or to the
                    ; end of string
JNZ FOUND           ; found
......
FOUND:
```
