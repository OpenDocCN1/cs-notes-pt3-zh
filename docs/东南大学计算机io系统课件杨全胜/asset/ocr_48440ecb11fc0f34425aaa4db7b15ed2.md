# Interrupt-handling routine programming

# Template of interrupt handler

(suppose the vector number is 0CH)

```
; interrupt handler
SERVICE PROC FAR
    PUSHA      ; push register
    PUSH DS
    STI        ; set IF
    .....      ; main function in handler
    CLI        ; clear IF
    MOV AL, 20H
    OUT 20H, AL ; sent EOI
    POP DS      ; resume
    POPA
    IRET
SERVICE ENDP
```
