# 2.6.7 Procedure Instructions

```
.8086
.MODEL SMALL
.DATA
    ARRAY  WORD 10 DUP(?)
    COUNT  WORD 10
    SUM    WORD ?
    STRING BYTE 6 DUP(?)
.STACK 1024
.CODE
START:
    MOV   AX,@DATA
    MOV   DS,AX
    LEA   DI,ARRAY
    MOV   CX,10
LP: CALL  DECIBIN
    CALL  CRLF
    MOV   [DI],BX
```
