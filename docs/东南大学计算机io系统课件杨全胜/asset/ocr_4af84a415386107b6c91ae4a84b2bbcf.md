# SCAS Instruction

SCAS with a REPNZ/REPNE prefix

+   REPNZ/REPNE prefix cause the SCAS instruction to repeat until either CX decrement 1 each time to reach 0, or until an equal condition exist as the outcome of the SCAS instruction’s comparison.

SCAS with a REPZ/REPE prefix

+   REPZ/REPE prefix cause the SCAS instruction to repeat until either CX decrement 1 each time to reach 0, or until an equal condition NOT exist as the outcome of the SCAS instruction’s comparison.

With either repeat prefix, the content of CX decrement without affecting the flag bits.
