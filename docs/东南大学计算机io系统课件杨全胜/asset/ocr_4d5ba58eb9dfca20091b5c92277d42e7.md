# 1.3 Real-address mode memory model

# Fundamental

+   - The memory cell is addressing by byte.
+   - A multi-byte object is stored as a contiguous sequence of bytes, with the address of the object given by the smallest address of the bytes used.
+   - For ordering the bytes representing an object, there are two common conventions.
+     - little endian: where the least significant byte comes first, it store at the smallest address.
+     - Big endian: where the most significant byte comes first, it store at the smallest address.
+   - X86 CPU use little endian.
