# 3.2 Principal I/O techniques

+   - Programmed I/O
+     1. When the processor is executing a program and encounters an instruction relating to I/O, it executes that instruction by issuing a command to the appropriate I/O module.
+     2. With programmed I/O, the I/O module will perform the requested action.
+     3. Then there are 2 different ways:
+        - Unconditional transfer
+          - we suppose the device is always ready.
+          - Processor do not care the status of I/O module
+        - Conditional transfer
+          - After perform the action, I/O module set the appropriate bits in the I/O status register.
+          - Processor periodically to check the status in I/O module until finds that the operation is complete
