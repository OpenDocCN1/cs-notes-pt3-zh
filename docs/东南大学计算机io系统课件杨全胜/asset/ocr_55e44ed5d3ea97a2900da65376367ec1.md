# 2.5 User Interface Programming

# Output a string to screen

```
```asm
.DATA
    MSG BYTE "Hello world!",0Ah,0Dh,'$'
.CODE
START:
    MOV AX, DATA
    MOV DS, AX
    MOV DX, OFFSET MSG
    MOV AH, 09H
    INT 21H
    MOV AH, 4CH
    INT 21H
END START
```
```

> **Tips:**  
> In order to output a carriage return and line feed (`\r\n` in C), you can define a string as follows:  
> `CR DB 0AH,0DH,'$'`
