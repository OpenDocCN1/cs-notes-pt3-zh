# Branch Structure Programming

Input a number, according to the number 0 ~ 9, and the jump table, jump to the correct address. If input is non-numeric, exit the program.

```
.DATA
TABLE WORD ROUTINE_0
WORD ROUTINE_1
WORD ROUTINE_2
WORD ROUTINE_3
WORD ROUTINE_4
WORD ROUTINE_5
WORD ROUTINE_6
WORD ROUTINE_7
WORD ROUTINE_8
WORD ROUTINE_9
```

```
.CODE
......
ROUTINE_1: MOV AX,0
......
ROUTINE_2: CMP AL, 3
......
......
ROUTINE_9: CLI
```
