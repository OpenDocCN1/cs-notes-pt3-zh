# 2.6.7 Procedure Instructions

# Procedure Instructions

◆ call (.model flat for 80386 or above)

```
CALL  procname
```

☞ Direct call

+   1. ESP←(ESP)-4
+   2. ((ESP)+3,(ESP)+2,(ESP)+1,(ESP))←(EIP)
+   3. EIP←(EIP)+disp32

```
CALL  reg/mem32
```

☞ Indirect call

+   1. ESP←(ESP)-4
+   2. ((ESP)+3,(ESP)+2,(ESP)+1,(ESP))←(EIP)
+   3. EIP←reg32 or EIP←mem32
