# ◆ Shift Instructions

Y is a number of byte, how to calculate (Y)*10?
We know: (Y)*10=(Y)*(8+2)=(Y)*2+(Y)*8 (Why do this?)

```
MOV AL, Y     ; AL<--(Y)
MOV AH, 0
SHL AX, 1      ; (Y)*2
MOV BX, AX
SHL AX, 1      ; (Y)*4
SHL AX, 1      ; (Y)*8
ADD AX, BX     ; (Y)*10
```
