# Minimum Mode

+   - Is the least expensive way to operate the 8086/8088
+   - All the control signals for the memory or I/O are generated by CPU.
+   - This mode operation is obtained by connected mode selection pin MN/MX to +5V.
+   - ALL our experiment base on minimum mode.
