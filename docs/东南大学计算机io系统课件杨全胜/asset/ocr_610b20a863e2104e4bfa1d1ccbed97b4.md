# Arithmetic Operators

+   - Arithmetic operators can be used for numeric expressions or address expressions
+   - For the address expressions, the result must be physically meaningful.
+     - Address + constant = address
+     - Address - constant = address
+     - Address − Address = constant

Example1:
MOV DX, BLOCK+(6-1)*2 ;
