# 3.5 Personal Computer I/O Map

+   - I/O Address Space in PC

| I/O module(interface) | Address space |
|---|---|
| LPT1 | 0370-037FH |
| LPT2 | 0270-027FH |
| COM1 | 03F8-03FFH |
| COM2 | 02F8-02FFH |
| MDA | 03B0-03BFH |
| CGA | 03D0-03DFH |
| EGA/VGA | 03C0-03CFH |
| Floppy disk | 03F0-03FFH |
| Hard disk | 01F0-01FFH |
