# 1.6.1 Operand Addressing Modes

# Register Addressing

Source and destination operands in a register, the register ID encoded in the instruction

![](bbox=[0.14, 0.4, 0.75, 0.62])

Examples:

+   - MOV AH, BL    ; (BL)->AH
+   - MOV DS, AX    ; (AX)->DS
+   - MOV SI, AX    ; (AX)->SI
+   - MOV ECX, EDX  ; (EDX)->ECX
