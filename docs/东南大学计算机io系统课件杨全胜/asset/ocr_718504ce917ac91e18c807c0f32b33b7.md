# 2.6.1 Data Movement Instructions

# POP Instruction

| Symbolic | Example |
|---|---|
| `POP reg16/32` | `POP AX, POP EBX` |
| `POP mem16/32` | `POP WORD PTR[EBX+2] , POP VAR` |
| `POP seg` | `POP DS` |
| `POPA` | `POPA; pops di, si, bp, sp, bx, dx, cx, ax` |
| `POPAD` | `POPAD; pops edi, esi, ebp, esp, ebx, edx, ecx, eax` |
| `POPF` | `Pop flags` |
| `POPFD` | `Pop EFLAGS` |

> Note: Can't pop CS
