# 3.1 I/O Module

# What is I/O module

+   - The computer’s I/O modules is its interface to the outside world.
+   - Each module interfaces to the system bus or central switch and control one or more peripheral devices.
+   - The I/O module contains logic for performing a communication function between the peripheral and bus.
