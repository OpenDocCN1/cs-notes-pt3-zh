# Procedure Instructions

Far call to different segment (.model small for 8086)

```
CALL FAR PTR procname
```

Direct call

+   1. SP<--(SP)-2
+   2. ((SP)+1,(SP))<--(CS)
+   3. SP<--(SP)-2
+   4. ((SP)+1,(SP))<--(IP)
+   5. IP<-- offset of procname
+   6. CS<-- seg of procname
