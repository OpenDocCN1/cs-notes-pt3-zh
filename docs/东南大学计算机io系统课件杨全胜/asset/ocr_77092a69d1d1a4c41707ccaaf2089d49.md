# Passing Parameters in 16-bit program

by register

Define a procedure “PINT” to output a decimal number in AX, the offset of convert buffer in DI.

```
PINT    PROC    NEAR
    PUSH    DX
    PUSH    DI
    PUSH    CX
    MOV     CX, 5
CLEAR_BUF:MOV BYTE PTR[DI], ' '
    INC     DI
    LOOP    CLEAR_BUF
    MOV     BYTE PTR[DI], '$'
    DEC     DI
    MOV     CX, 10
CHANGE: MOV DX, 0
    DIV     CX
```

```
ADD     DL, 30H
MOV     BYTE PTR[DI], DL
DEC     DI
CMP     AX, 0
JNZ     CHANGE
INC     DI
MOV     DX, DI
MOV     AH, 9
INT     21H
POP     CX
POP     DI
POP     DX
RET
PINT    ENDP
```
