# 4.2 8259A PIC

# Modes of Operation

# ◆ Poll Mode

In this mode, the INT output function as it normally does, but the microprocessor should ignore this output. Service to devices is achieved by software using a Poll command.

# ◆ Nested Mode

# Full nested mode

+   • While the ISR bit is set, all further interrupts of the same or lower priority are inhibited.

# Special Fully-Nested Mode

+   • While the ISR bit is set, all further interrupts of the lower priority are inhibited.
