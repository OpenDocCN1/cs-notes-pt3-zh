# ASCII Adjust AL After Subtraction

# AAS

+   - Adjusts the result of the subtraction of two unpacked BCD values to create a unpacked BCD result.

```
if (AL&0FH)>9 or (AF)=1
then (AL)-6 -->AL
    (AH)-1-->AH
    (AL)&0FH-->AL
    1-->AF, AF-->CF
else (AL)&0FH-->AL
    0-->AF, (AF)-->CF
```
