# 2.6.5 Loop Instructions

+   Loop structure Programming

+   Loop like "for(i=1 ;i<n; i++)"

Calculate: S=1+2+3+…+50; save result in AX register

```
NUM      DW 1  ;
......
MOV      CX,0   ; 初始化
MOV      AX,0
ROTATE:
ADD      AX, NUM  ; 累加
INC      WORD PTR[NUM]
INC      CX
CMP      CX,50
JNZ      ROTATE
MOV      S,AX
......
```
