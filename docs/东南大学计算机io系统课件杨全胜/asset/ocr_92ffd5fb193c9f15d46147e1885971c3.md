# 3.1 I/O Module

# I/O module Function

+   - **Control and timing**
+     - To coordinate the flow of traffic between the system BUS and peripherals.
+   - **Processor communication**
+     - **Command decoding.** Accepts commands on control bus from the processor and decode them.
+     - **Data transfer.** Exchange the data between the processor and I/O module.
+     - **Status reporting.** Transfer the status of the I/O module and peripherals to the system bus.
+     - **Address recognition.** I/O module must recognize one unique address for each peripheral it controls.
