# 3.5 Personal Computer I/O Map

+   - I/O Address Space in PC

| I/O chip | Address space |
|---|---|
| DMAC1 | 0000-001FH |
| DMAC2 | 00C0-00DFH |
| DMA page register | 0080-009FH |
| PIC1 | 0020-003FH |
| PIC2 | 00A0-00BFH |
| Timer | 0040-005FH |
| PPI | 0060-006FH |
| RT/CMOS RAM | 0070-007FH |
| Coprocessor(Reserve) | 00F0-00FFH |
