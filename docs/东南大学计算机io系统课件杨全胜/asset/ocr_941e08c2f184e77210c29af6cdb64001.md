# 7.3 RS-232 Standard

# Electrical signal characteristics

# Voltage levels

+   - Valid signals are ±3 ~15 volts
+   - For data transmission lines
+     - Logic one is defined as a negative voltage (-3V~ -15V), the signal condition is called marking.
+     - Logic zero is positive (+3V~+15V) and the signal condition is termed spacing.
+   - For Control signals
+     - When one of these signals is active, the voltage on the line will be between +3 to +15 volts.
+     - The inactive state for these signals is the opposite voltage condition, between -3 and -15 volts.
