# 7.4 16550 UART

# Interrupt Identification Register(IIR)

| ID2 | ID1 | ID0 | Interrupt source | Priority |
|---|---|---|---|---|
| 0 | 1 | 1 | Receiver Line Status: Overrun Error or Parity Error or Framing Error or Break Interrupt | highest |
| 0 | 1 | 0 | Receiver Data Available or Trigger Level Reached | second |
| 1 | 1 | 0 | No Characters Have Been Removed From or Input to the RCVR FIFO During the Last 4 Char Times and There Is at Least 1 Char in It During This Time. | second |
| 0 | 0 | 1 | Transmitter Holding Register Empty | third |
| 0 | 0 | 0 | MODEM Status (CTS、DSR、RI和RLSD) changed | fourth |
