# Decimal Adjust AL after Subtraction

# DAS

+   - Adjusts the result of the subtraction of two packed BCD values to create a packed BCD result.

```
if (AL&0FH)>9 or (AF)=1
    then (AL)-6-->AL
         1-->AF
if (AL)>9FH or (CF)=1
    then (AL)-60H-->AL
         1-->CF
```
