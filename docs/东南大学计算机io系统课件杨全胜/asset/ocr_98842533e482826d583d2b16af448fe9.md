# 1.5 Basic Program Execution Registers

The low 12 bits of EFLAG

| b15 |  |  |  | OF | DF | IF | TF | SF | ZF |  | AF |  | PF |  | CF | b0 |
|---|---|---|---|---|---|---|---|---|---|---|---|---|---|---|---|---|
| SF | Sign flag | Set equal to the most-significant bit of the result, which is the sign bit of a signed integer. |
| TF | Trap flag | Set to enable single-step mode for debugging; clear to disable single-step mode. |
| IF | Interrupt enable flag | Set to respond to maskable interrupts; cleared to inhibit maskable interrupts. |
