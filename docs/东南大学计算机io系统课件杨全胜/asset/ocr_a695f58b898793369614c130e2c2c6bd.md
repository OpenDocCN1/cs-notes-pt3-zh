# 6.5 Application

+   1) The Port address of this 82C55 is:
+   320H、321H、322H和323H。

+   2) Port A – mode 0, output, Port B – mode 0, input, so Control Word is 10000010b=82H

+   3) MOV AL, 82H ;write control word
+   MOV DX, 323H ;
+   OUT DX, AL
+   L1: MOV DX, 321H ;
+   IN AL, DX ;input switches state
+   NOT AL ;
+   MOV DX, 320H ;
+   OUT DX, AL ;output
+   JMP L1
