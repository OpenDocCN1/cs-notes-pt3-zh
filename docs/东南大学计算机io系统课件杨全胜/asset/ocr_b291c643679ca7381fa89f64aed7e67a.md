# 4.2 8259A PIC

# Modes of Operation

# Mask Mode

# Normal Mask Mode

+   - Each bit in the IMR masks one interrupt channel if it is set (1). Bit 0 masks IR0, Bit 1 masks IR1 and so forth.

# Special Mask Mode

+   - When a mask bit is set in OCW1, it inhibits further interrupts at that level and enables interrupts from all other levels (lower as well as higher) that are not masked.
