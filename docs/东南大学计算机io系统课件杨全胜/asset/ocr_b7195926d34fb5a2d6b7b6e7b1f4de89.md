# Registers

|---|---|---|
| 0 | 000 | Receiver Buffer (R); Transmitter Holding Register (W) |
| 0 | 001 | Interrupt Enable Register |
| 1 | 000 | Divisor Latch (least significant byte) |
| 1 | 001 | Divisor Latch (most significant byte) |
| X | 010 | Interrupt Identification Register(R); FIFO Control (W) |
| X | 011 | Line Control Register |
| X | 100 | MODEM Control Register |
| X | 101 | Line Status Register |
| X | 110 | MODEM Status Register |
| X | 111 | Scratch Register |
