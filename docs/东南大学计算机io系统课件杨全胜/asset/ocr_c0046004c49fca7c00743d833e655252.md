# 3.2 Principal I/O techniques

# Programmed I/O

I/O command that an I/O module may receive when it is addressed by a processor

+   - Control: Used to active a peripheral and tell it what to do.

+   - Test: Used to test various status conditions associated with an I/O module and its peripherals.

+   - Read: Cause the I/O module to obtain an item of data from the peripheral and place it in an internal buffer. The processor can then obtain the data item by requesting that the I/O module place it on the data bus.

+   - Write: Cause the I/O module to take an item of data from the data bus and subsequently transmit that data item to the peripheral.
