# 3.5 Personal Computer I/O Map

# I/O Address Space in PC

+   - 64k 8-bit port address space, or 32k 16-bit port address space, or 16k 32-bit port address space.
+     - 00~0FFH is normally reserved for the computer system in main-board.
+     - 100H~3FFH is normally reserved for the ISA bus.
+     - 400H~0FFFH are generally available for user application, main-board function and the PCI bus.
+   - Port address must be aligned.
