# 2.6.2 Arithmetic Instructions

# Multiplication and Division

+   - Unsigned Division
+     - `DIV SRC`

+   - Signed Division
+     - `IDIV SRC`

# Errors occur during division

+   - An attempt to divide by zero;
+   - A quotient that is too large to fit in the single-length destination
+     - 2468AH ÷ 2 = 12345H
+     - 0FFFFFFFH ÷ 1 = 0FFFFFFFFH

The division instructions may destroy previously set values of AF, CF, OF, PF, SF and ZF, but undefined.
