# 2.6.2 Arithmetic Instructions

# Addition, Subtraction, and Comparison

# Addition-with-Carry

```
ADC DST, SRC
```

DST ← (DST) + (SRC) + Carry

This instruction have an affect on CF, SF, OF, PF, ZF and AF

# Increment Addition

```
INC DST
```

DST ← (DST) + 1

This instruction have an affect on SF, OF, PF, ZF and AF, no affect on CF

| Symbolic | Example |
|---|---|
| INC reg8/16/32 | INC CX |
| INC mem8/16/32 | INC BYTE PTR[BX] |
