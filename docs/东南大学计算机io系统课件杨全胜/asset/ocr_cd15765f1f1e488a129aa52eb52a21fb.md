# 2.6.1 Data Movement Instructions

# MOV Instruction

# Legal or illegal?

```
val1 byte 100
val2 byte 200
number equ 100
```

```
mov val1 , val2
mov number , val2
mov val2, number
mov ds, offset val1
mov ax, offset val1
mov al, -40
```

```
mov al, ds
mov ds, ax
mov es, ds
mov ax, es
mov val, al
mov al, 0D8h
```
