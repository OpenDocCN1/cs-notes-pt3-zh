# 4.2 8259A PIC

# Modes of Operation

# Edge and Level Triggered Mode

# Edge Triggered mode

+   - An interrupt request will be recognized by a low-to-high transition on the corresponding IRQ input.

# Level Triggered mode

+   - An interrupt request will be recognized by a high level on the corresponding IRQ input and there is no need for an edge detection.

In both the edge and level triggered modes, the IRQ inputs must remain active until after the falling edge of the first internal INTA#. If the IRQ input goes inactive before this time, a default IRQ7 vector number is returned.
