# 2.5 User Interface Programming

# Example

Print character ‘S’ to printer

```
MOV  AH, 1    ; initial the printer
MOV  DX, 0    ; Printer number
INT  17H      ;
MOV  AH, 0    ; print a character
MOV  DX, 0    ; printer number
MOV  AL, 'S'  ; character that will be print
INT  17H      ; print ‘S’
```
