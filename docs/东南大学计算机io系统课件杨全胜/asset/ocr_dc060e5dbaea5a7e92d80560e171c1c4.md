# BCD and ASCII Arithmetic

# ASCII Adjust After Addition

# AAA

+   - Adjusts the sum of two unpacked BCD values to create an unpacked BCD result.

```
if (AL&0FH)>9 or (AF)=1
then (AL)+6-->AL
(AH)+1-->AH
1-->AF, AF-->CF
(AL)&0FH-->AL
else (AL)&0FH-->AL
0-->AF, (AF)-->CF
```
