# 3.6 I/O Port Address Decoding

+   - Adjustable port address decoding

+     - Using 3 74LS136 XOR Gates

![](bbox=[0.12, 0.32, 0.53, 0.71])

# Logic:

3=1 ⊕ 2;  6=4⊕ 5;
8=9⊕ 10;  11=12⊕ 13;

# Connection:

The input of the XOR gates respectively connected to the address line and switch line.

CS#: OR Operation on all output of XOR Gates
