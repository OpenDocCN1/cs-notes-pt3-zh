# 1.4 Data Type

# Bit Field Data Type

+   - is a contiguous sequence of bits.
+   - It can begin at any bit position of any byte in memory and can contain up to 32 bits.

# String Data Types

+   - Strings are continuous sequences of bits, bytes, words, or doublewords.
+   - A bit string can begin at any bit position of any byte and can contain up to 2³²-1 bits.
+   - A byte string can contain bytes, words, or doublewords and can range from zero to 2³² -1 bytes (4 GBytes).
