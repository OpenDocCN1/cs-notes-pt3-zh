# 5.2 Structure and pins of 8254

# Operation and Command

Method of read data from T/C

Counter Latch Command (A1A0=11)

+   - CHB: D7D6=00~01, D5D4=00

e.g.:

```
MOV   AL, 01000101B  ; T/C1, latch, least significant
                         ; byte first, mode2, BCD
OUT   43H, AL
IN    AL, 41H
MOV   AH, AL
IN    AL, 41H
XCHG  AH, AL  ; AX is initial count for T/C1
```
