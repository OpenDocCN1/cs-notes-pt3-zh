# Segment Override

When storing data in memory or loading data from memory, the DS segment default can be overridden to allow other segments to be accessed. Within an assembler, the segment override is generally handled with a colon “:” operator.

# Example:

```
MOV AX, [10H]    ; Data in DS Segment
MOV AX, ES:[10H] ; Data in ES Segment
```
