# 1.6.1 Operand Addressing Modes

# Memory Operands Addressing

Source and destination operands in memory are referenced by means of a segment address and an offset.

# Memory Operands

+   - Direct Data Addressing
+   - Register Indirect Addressing
+   - Register Relative Addressing
+     - Base-Plus-Displacement Addressing
+     - Index-Plus-Displacement Addressing
+   - Base-Plus-Index Addressing
+   - Base Relative-Plus Index Addressing
+   - Scaled-Index Addressing
