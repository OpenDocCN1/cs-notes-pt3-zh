# 2.6.4 Jump Instructions

+   - Unconditional Jump (JMP)
+     - Far Jump

```
JMP FAR PTR OPR
```

Example

```
; segment C1
......
JMP FAR PTR NEXT
......
; segment C2
......
NEXT: MOV AL,10H
...
```
