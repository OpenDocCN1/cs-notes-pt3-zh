# 2.6.2 Arithmetic Instructions

+   - Addition, Subtraction, and Comparison

+   - Decrement Subtraction

```
DEC DST
```

DST←(DST) - 1

This instruction have an affect on SF, OF, PF, ZF and AF, no affect on CF

+   - Two’s complement

```
NEG DST;
```

DST←0-(DST)

| Symbolic | Example |
|---|---|
| DEC reg/mem8/16/32 | DEC CX ; DEC BYTE PTR[SI] |
| NEG reg/mem8/16/32 | NEG WORD PTR[DI] |
