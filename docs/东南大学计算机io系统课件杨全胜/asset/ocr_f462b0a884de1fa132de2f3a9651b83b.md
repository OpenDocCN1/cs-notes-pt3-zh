# 7.5 COM in IA-32

# What is COM in communication?

+   - COM is the original, yet still common, name of the serial port interface on IBM PC-compatible computers.
+   - It might not only refer to physical ports, but also to virtual ports, such as ports created by bluetooth or USB-to-Serial adapters.
+   - COM in IA-32
+     - COM1: I/O port 0x3F8, IRQ 4
+     - COM2: I/O port 0x2F8, IRQ 3
+     - COM3: I/O port 0x3E8, IRQ 4
+     - COM4: I/O port 0x2E8, IRQ 3
