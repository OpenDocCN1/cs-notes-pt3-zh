# 3.2 Principal I/O techniques

# I/O Channels

+   - The I/O module is enhanced to become an processor in its own right, with a specialized instruction set tailored for I/O. This I/O module is often referred to as an I/O channel.
+   - The I/O channel has the ability to execution the I/O instructions, which gives it complete control over I/O operations.
+   - The CPU dose not execute I/O instructions, such instructions are stored in the main memory to be executed by a special-purpose processor in the I/O channel itself.
