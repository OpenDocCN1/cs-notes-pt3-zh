# Programming Communication with interrupt

# Interrupt handler

+   - **At first, read IIR**, judge the interrupt source, then jump to the routine. Judge the interrupt source should be in accordance with the order of interrupt priority levels.
+   - When D2D1 in IIR=11, means **receive error**, need to **read LSR** to know what’s wrong, and process it.
+   - Maybe more than one interrupt are come. **So, when a interrupt handler is complete, the IIR must be read again** to check whether the D0 is “0”, when D0=0, you must to judge the interrupt source and process again.
+   - **The conditions for return from the interrupt routine is D0 of IIR is 1.**
