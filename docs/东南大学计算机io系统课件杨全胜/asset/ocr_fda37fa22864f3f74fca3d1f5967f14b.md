# 3.3 The type of the I/O address space

# Isolated I/O

+   - The address for isolated I/O device, called ports address, is separate from the memory address space.
+   - The user can expand the memory to its full size without using any of memory space for I/O device.
+   - Disadvantage:
+     - Data transfer between I/O and CPU must be accessed by the specialized I/O instructions.
+     - Need specialized the control signal(M/IO,WR,RD)
+   - X86-based system used.
