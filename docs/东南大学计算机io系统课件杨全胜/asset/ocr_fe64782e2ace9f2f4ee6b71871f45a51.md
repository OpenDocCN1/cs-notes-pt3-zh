# Pointer Data Types

+   - Pointers are addresses of locations in memory
+   - In non-64-bit modes, the architecture defines two types of pointers: a near pointer and a far pointer.
+   - In 16-bit mode
+     - A near pointer is a 16-bit offset (also called an effective address) within a segment.
+     - A far pointer is a logical address, consisting of a 16-bit segment base address and a 16-bit offset.
+   - In 32-bit mode
+     - A near pointer is a 32-bit offset (also called an effective address) within a segment.
+     - A far pointer is a logical address, consisting of a 16-bit segment selector and a 32-bit offset.
