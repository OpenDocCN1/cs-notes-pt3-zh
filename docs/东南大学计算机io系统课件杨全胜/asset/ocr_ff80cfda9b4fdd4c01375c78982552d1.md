# 1.5 Basic Program Execution Registers

ESI — Pointer to data in the segment pointed to by the DS register; source pointer for string operations (Index Register)

EDI — Pointer to data (or destination) in the segment pointed to by the ES register; destination pointer for string operations (Index Register)

ESP — Stack pointer (in the SS segment)

EBP — Pointer to data on the stack (in the SS segment) (Base Register)

+   - The lower 16 bits of these 4 registers map directly to the register set and can be referenced with the names SI, DI, SP, and BP.
