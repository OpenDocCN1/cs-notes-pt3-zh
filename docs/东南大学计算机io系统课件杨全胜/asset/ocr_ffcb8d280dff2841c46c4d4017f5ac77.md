# 7.5 COM in IA-32

# 16550 initialize

```
mov     al,00011011b ; even parity,
                ; 1 stop, 8-bit data
mov     dx,3fbh   ; LCR
out     dx,al
mov     al,03h    ; DTR, RTS
mov     dx,3fch   ; MCR
out     dx,al
mov     al,0      ; Disable interrupt
mov     dx,3f9h   ; IER
out     dx,al
```
