
## 2.6.6 String Instructions

### String Data Transfer Instructions

#### STOS Instruction

Stores AL, AX or EAX at the extra segment memory location addressed by the (E)DI register.

| Assembly Language | Operation |
|---|---|
| STOSB | ES:[DI]=AL; if (DF=0) DI=DI+1 else DI=DI-1 |
| STOSW | ES:[DI]=AX; if (DF=0) DI=DI+2 else DI=DI-2 |
| STOSD | ES:[DI]=EAX; if (DF=0) DI=DI+4 else DI=DI-4 |

#### STOS with a REP prefix

- The REP prefix causes (E)CX to be decremented by 1 each time the string instruction executes. Then the string instruction repeats. If (E)CX reaches a value of 0, the instruction terminates and the program continues with the next sequential instruction.

#### STOS Instruction example

Clear the buffer

```asm
.DATA
BUFF DB 1000 DUP(?)  ; define the buffer
.CODE
        ......
CLD                    ; DF=0
LEA  DI, BUFF          ; address of buff-->DI
MOV  CX, 1000          ; the number of repetitions
MOV  AL, 0             ; 0-->AL
REP  STOSB             ; store 0 to clear
```

#### MOVS Instruction

- Transfers a byte, word, or doubleword from the data segment location addressed by (E)SI to the extra segment location addressed by (E)DI.
- MOVS can also be used with a REP prefix.

| Assembly Language | Operation |
|---|---|
| MOVSB | ES:[DI]=DS:[SI]; if (DF=0) {SI=SI+1; DI=DI+1} else {SI=SI-1; DI=DI-1} |
| MOVSW | ES:[DI]=DS:[SI]; if (DF=0) {SI=SI+2; DI=DI+2} else {SI=SI-2; DI=DI-2} |
| MOVSD | ES:[DI]=DS:[SI]; if (DF=0) {SI=SI+4; DI=DI+4} else {SI=SI-4; DI=DI-4} |

#### MOVS Instruction example for 16-bit program

```asm
.8086                ; create 16 bit code
.model small         ; 16 bit memory model
.data
lpstring DWORD ?
buff1  BYTE "HELLO,WORLD!",13,10,'$'
buff2  BYTE 20 DUP('$')
.code
start:
    mov ax,@data
    mov ds,ax
    mov es,ax

    mov si,offset buff1
    mov di,offset buff2
    mov cx,14
    cld
    rep movsb
    mov dx,offset buff2
    mov ah,9
    int 21h   ; print string
    mov ax,4c00h
    int 21h   ; exit
end start
```

#### INS Instruction

- Transfers a byte, word, or doubleword of data from an I/O device into the extra segment location addressed by the (E)DI register.
- I/O address in the DX register.
- INS can also be used with a REP prefix.

| Assembly Language | Operation |
|---|---|
| INSB | ES:[DI]=[DX]; if (DF=0) DI=DI+1 else DI=DI-1 |
| INSW | ES:[DI]=[DX]; if (DF=0) DI=DI+2 else DI=DI-2 |
| INSD | ES:[DI]=[DX]; if (DF=0) DI=DI+4 else DI=DI-4 |

#### OUTS Instruction

- Transfers a byte, word, or doubleword of data from the DATA segment location addressed by the (E)SI register to an I/O device.
- I/O address in the DX register.
- OUTS can also be used with a REP prefix.

| Assembly Language | Operation |
|---|---|
| OUTSB | [DX] = DS:[SI]; if (DF=0) SI=SI+1 else SI=SI-1 |
| OUTSW | [DX] = DS:[SI]; if (DF=0) SI=SI+2 else SI=SI-2 |
| OUTSD | [DX] = DS:[SI]; if (DF=0) SI=SI+4 else SI=SI-4 |

### String Comparison Instructions

#### SCAS Instruction

Compare a byte, word, or double word from the data segment location addressed by (E)DI with AL, AX, or EAX.

| Assembly Language | Operation |
|---|---|
| SCASB | ES:[DI]-AL; if (DF=0) DI=DI+1 else DI=DI-1 |
| SCASW | ES:[DI]-AX; if (DF=0) DI=DI+2 else DI=DI-2 |
| SCASD | ES:[DI]-EAX; if (DF=0) DI=DI+4 else DI=DI-4 |

#### SCAS with a REPNZ/REPNE prefix

- The REPNZ/REPNE prefix causes the SCAS instruction to repeat until either CX, decremented by 1 each time, reaches 0, or until an equal condition exists as the outcome of the SCAS instruction's comparison.

#### SCAS with a REPZ/REPE prefix

- The REPZ/REPE prefix causes the SCAS instruction to repeat until either CX, decremented by 1 each time, reaches 0, or until an equal condition does NOT exist as the outcome of the SCAS instruction's comparison.

With either repeat prefix, the content of CX is decremented without affecting the flag bits.
