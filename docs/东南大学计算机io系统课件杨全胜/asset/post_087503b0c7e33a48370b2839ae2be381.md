### 1.1 Computer Components

At a top level, a computer consists of CPU, memory and I/O components, with one or more modules of each type.

![](img/d7c975450dfbe59120092c2721be78c6_9_0.png)

Such a design is referred to as the *von Neumann architecture* and is based on three key concepts:

- Data and instruction are stored in a single read-write memory.
- The contents of this memory are addressable by location, without regard to the type of data contained there.
- Execution occurs in a sequential fashion (unless explicitly modified) from one instruction to the next.
