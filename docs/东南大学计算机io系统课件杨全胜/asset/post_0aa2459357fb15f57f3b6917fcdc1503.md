
## 2.6.1 Data Movement Instructions

## MOV Instruction

```
MOV DST , SRC
```

DST<--(SRC) ; Copy data from SRC to DST

| Symbolic | Example |
|---|---|
| MOV reg8/16/32, imm8/16/32 | MOV EAX, 7327FAB2H |
| MOV reg8/16/32, reg8/16/32 | MOV AH, DL |
| MOV reg8/16/32, mem8/16/32 | MOV DX, WORD PTR[BX] |
| MOV mem8/16/32, reg8/16/32 | MOV BYTE PTR[DI], AL |
| MOV mem8/16/32, imm8/16/32 | MOV BYTE PTR[DI], 30 |
| MOV seg, reg16 | MOV DS, AX |
| MOV reg16, seg | MOV AX, DS |
| MOV seg, mem16 | MOV DS, WORD PTR[BX] |
| MOV mem16, seg | MOV WORD PTR[BX], DS |

- Unavailable combinations of source and destination operands
  - Both src. and dest. in memory
  - Immediate src. to segment register
  - Move to or from the flag register
  - Move to the instruction pointer register
  - Move to the CS
  - Move from one segment register to another segment register
  - The operands are not the same size
  - A move of several objects

## PUSH Instruction

```
PUSH SRC
```

- Save data to LIFO stack
- For 16-bit
  1. SP<--(SP)-2
  2. ((SP)+1,(SP))<--(SRC)
- For 32-bit
  1. ESP←(ESP)-4
  2. ((ESP)+3,(ESP)+2,(ESP)+1,(ESP))←(SRC)

Example:

PUSH AX

before execution

AX
3125H

Lower addr.
SP →
52500H

after execution

AX
3125H

Lower addr.
SP →
25H 524FEH
31H 524FFH
52500H

## POP Instruction

```
POP DST
```

- Retrieve data from LIFO stack
- For 16-bit
  1. DST<--((SP)+1,(SP))
  2. SP<--(SP)+2
- For 32-bit
  1. DST←((ESP)+3,(ESP)+2,(ESP)+1,(ESP))
  2. (ESP)←(ESP)+4

Example:

POP BX

before execution

75C1H

after execution

| Symbolic | Example |
|---|---|
| `POP reg16/32` | `POP AX, POP EBX` |
| `POP mem16/32` | `POP WORD PTR[EBX+2] , POP VAR` |
| `POP seg` | `POP DS` |
| `POPA` | `POPA; pops di, si, bp, sp, bx, dx, cx, ax` |
| `POPAD` | `POPAD; pops edi, esi, ebp, esp, ebx, edx, ecx, eax` |
| `POPF` | `Pop flags` |
| `POPFD` | `Pop EFLAGS` |

> Note: Can't pop CS

## Load-Effective Address Instructions

```
LEA reg16/32, mem8/16/32
```

Loads a 16- or 32-bit register with the offset address of the data specified by the operand.

![](img/d7c975450dfbe59120092c2721be78c6_154_0.png)

### LEA Instruction

**LEA DI, BUFFER**  
; Transfer the effective address of BUFFER to DI

DI `1234H`

BUFFER → 2000H:1234H

**MOV DI, BUFFER**  
; Transfer the contents of address BUFFER to DI

DI `5678H`

|  | Value |
|---|---|
| 5H | 56H |
|  | 78H |

# What is the different between LEA and OFFSET?

```
LDS  reg16/32, mem32/48
LES  reg16/32, mem32/48
LFS  reg16/32, mem32/48
LGS  reg16/32, mem32/48
LSS  reg16/32, mem32/48
```

- Load any 16- or 32-bit register with an offset address and DS, ES, FS, GS, or SS segment register with segment address.
- Use any of memory-addressing modes to access a 32- or 48-bit section of memory that contains segment and offset address.

## Miscellaneous data transfer instructions

### XCHG Instruction

- Exchanges the contents of a register with the contents of any other register or memory location.
- Can’t exchange segment registers or memory-to-memory data

| Symbolic | Example |
|---|---|
| XCHG *reg8/16/32*, *reg8/16/32* | XCHG AL,CL |
| XCHG *reg8/16/32*, *mem8/16/32* | XCHG AX,DATA1 |
| XCHG *mem8/16/32*, *reg8/16/32* | XCHG DATA2, EAX |
