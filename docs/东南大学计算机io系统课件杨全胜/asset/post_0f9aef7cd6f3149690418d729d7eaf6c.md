### Mode of Operation
#### Real-address mode
- In 8086/8088, this is the only mode.
- In 80286 or above, this mode implements the programming environment of the Intel 8086 processor with extensions (such as the ability to switch to protected or system management mode).
- The processor is placed in real-address mode following power-up or a reset.
- Allow microprocessor to address only the first 1M byte of memory space

#### Protected mode (80286 or above)
- This mode is the native state of the processor.
- Support multi-tasking operations, and to protect the data and procedures for each task
- This mode allows applications to access physical memory greater than 4 GByte using PAE (Physical Address Extensions, 80386 or above).
- Virtual address space=64TB (2^46)
- Protected mode is where Windows operates.

#### Virtual-8086 mode (IA-32 or above)
Among the capabilities of protected mode is the ability to directly execute “real-address mode” 8086 software in a protected, multi-tasking environment.

This feature is called virtual-8086 mode, although it is not actually a processor mode. Virtual-8086 mode is actually a protected mode attribute that can be enabled for any task.

#### System management mode (SMM) (IA-32 or above)
- This mode provides an operating system or executive with a transparent mechanism for implementing platform specific functions such as power management and system security.
- In SMM, the processor switches to a separate address space while saving the basic context of the currently running program or task. SMM-specific code may then be executed transparently.
- Upon returning from SMM, the processor is placed back into its state prior to the system management interrupt.

#### IA-32e mode (Intel64 or above)
##### Compatibility mode (sub-mode of IA-32e mode)
- Compatibility mode permits most legacy 16-bit and 32-bit applications to run without re-compilation under a 64-bit operating system.
- Legacy applications that run in Virtual 8086 mode or use hardware task management will not work in this mode.
- Applications access only the first 4 GByte of linear-address space. Compatibility mode uses 16-bit and 32-bit address and operand sizes.

##### 64-bit mode (sub-mode of IA-32e mode)
- This mode enables a 64-bit operating system to run applications written to access 64-bit linear address space.
- 64-bit mode extends the number of general purpose registers and SIMD extension registers from 8 to 16.
- General purpose registers are widened to 64 bits. The mode also introduces a new opcode prefix (REX) to access the register extensions.

## 1.3 Real-address mode memory model
### Fundamental
- The memory cell is addressed by byte.
- A multi-byte object is stored as a contiguous sequence of bytes, with the address of the object given by the smallest address of the bytes used.
- For ordering the bytes representing an object, there are two common conventions.
  - little endian: where the least significant byte comes first, it stores at the smallest address.
  - Big endian: where the most significant byte comes first, it stores at the smallest address.
- X86 CPU use little endian.
