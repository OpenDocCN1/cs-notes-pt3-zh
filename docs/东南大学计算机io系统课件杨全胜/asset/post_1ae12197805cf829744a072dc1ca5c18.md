
## 7.5 COM in IA-32
### 16550 initialize

```
mov     dx,3fbh    ; LCR
mov     al,80h
out     dx,al       ; DLAB=1

mov     dx,3f8h    ; Divisor latch Lsb
mov     al,78h     ; 9600 Baud rate
out     dx,al
mov     al,00      ; Divisor latch MSb
inc     dx
out     dx,al
```

```
mov     al,00011011b ; even parity,
                ; 1 stop, 8-bit data
mov     dx,3fbh   ; LCR
out     dx,al
mov     al,03h    ; DTR, RTS
mov     dx,3fch   ; MCR
out     dx,al
mov     al,0      ; Disable interrupt
mov     dx,3f9h   ; IER
out     dx,al
```

### Programming Communication with interrupt

Initialization

- Modify the interrupt vector, According to COM1 or COM2, set the correct interrupt vector.
- Determine the operation mode of 16550, set the IER and enable the interrupt ( set D3 in MCR = 1 at the same time).
- Set the baud rate and format of data (DL and LCR).
- Enable the interrupt, Set the OCW1 of 8259A, enable IRQ4 or IRQ3. Set IF =1 in EFLAGS

### Interrupt handler

- **At first, read IIR**, judge the interrupt source, then jump to the routine. Judge the interrupt source should be in accordance with the order of interrupt priority levels.
- When D2D1 in IIR=11, means **receive error**, need to **read LSR** to know what’s wrong, and process it.
- Maybe more than one interrupt are come. **So, when a interrupt handler is complete, the IIR must be read again** to check whether the D0 is “0”, when D0=0, you must to judge the interrupt source and process again.
- **The conditions for return from the interrupt routine is D0 of IIR is 1.**
