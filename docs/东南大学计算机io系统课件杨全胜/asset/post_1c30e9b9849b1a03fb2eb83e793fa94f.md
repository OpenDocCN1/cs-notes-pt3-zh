
## 2.6.2 Arithmetic Instructions
### Addition, Subtraction, and Comparison
### Addition-with-Carry

```
ADC DST, SRC
```

DST ← (DST) + (SRC) + Carry

This instruction has an effect on CF, SF, OF, PF, ZF and AF

### Increment Addition

```
INC DST
```

DST ← (DST) + 1

This instruction has an effect on SF, OF, PF, ZF and AF, no effect on CF

| Symbolic | Example |
|---|---|
| INC reg8/16/32 | INC CX |
| INC mem8/16/32 | INC BYTE PTR[BX] |

### Addition, Subtraction, and Comparison
### Subtraction instruction

```
SUB DST, SRC
```

DST←(DST) - (SRC)

This instruction has an effect on CF, SF, OF, PF, ZF and AF

| Symbolic | Example |
|---|---|
| SUB reg8/16/32, imm8/16/32 | SUB AX,837FH |
| SUB reg8/16/32, reg8/16/32 | SUB EAX, EBX |
| SUB reg8/16/32, mem8/16/32 | SUB CX, WORD PTR[SI] |
| SUB mem8/16/32, reg8/16/32 | SUB BYTE PTR[DI],DL |
| SUB mem8/16/32, imm8/16/32 | SUB BYTE PTR[DI], 23 |

### Addition, Subtraction, and Comparison
### Subtraction-with-Borrow

```
SBB DST, SRC
```

DST <-- (DST) - (SRC) - Carry

This instruction has an effect on CF, SF, OF, PF, ZF and AF

### Addition, Subtraction, and Comparison
### Comparison Instruction

```
CMP DST, SRC
```

- (DST) – (SRC)
- This instruction has an effect on CF, SF, OF, PF, ZF and AF
- The DST never change

| Symbolic | Example |
|---|---|
| CMP reg8/16/32, imm8/16/32 | CMP AX,837FH |
| CMP reg8/16/32, reg8/16/32 | CMP EAX, EBX |
| CMP reg8/16/32, mem8/16/32 | CMP CX, WORD PTR[SI] |
| CMP mem8/16/32, reg8/16/32 | CMP BYTE PTR[DI],DL |
| CMP mem8/16/32, imm8/16/32 | CMP BYTE PTR[DI], 23 |

### Addition, Subtraction, and Comparison
### Comparison Instruction (CMP)

A CMP is normally followed by a conditional jump instruction, which tests the condition of the flag bits.

- For unsigned comparison
  - if ZF=1, then DST = SRC
  - if CF=0, then DST ≥ SRC
  - if CF=1, then DST < SRC

- For signed comparison
  - if ZF=1, then DST = SRC
  - if SF=OF, then DST ≥ SRC
  - if SF<>OF, then DST < SRC

### CMP Example1

CMP AL, BL

(AL)=-64    (BL)=10

- 64
- 10
------
- 74

OF=0  SF=1

Result: (DST)<(SRC)

### CMP Example2

CMP CL, [100H]

(CL)=-100    (DS:100)=-110

-100
- (-110)
------
10

OF=0  SF=0

Result: (DST)>(SRC)
