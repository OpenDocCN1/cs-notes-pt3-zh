
## 4.4 Interrupt process in Modern PC

### Interrupt response

When the processor finishes execution of the current instruction, CPU response the interrupt, (maskable interrupt response according to whether the IF in EFLAGS is 1).

Step of the respond

- 1. Save the return address
  - Clear the IF and TF in EFLAGS
  - Push EFLAGS, CS and EIP in stack.
- 2. Obtain the interrupt vector number
  - For the external hardware interrupt, the number obtain from 8259A in PCH in the second INTA#.
  - Other kind of interrupt do not need this step
- 3. **Obtain the entry location of interrupt-handling program**
  - Query the Interrupt Vector Table or Interrupt Descriptor Table with the vector number to get the address via the vector number.
- 4. **The processor now transfer control to the interrupt routine.**
  - loads the program counter with the entry location of interrupt-handling program
  - processes the interrupt
- 5. **Return to the breakpoint**
  - Pop EIP, CS, EFLAGS

### Hardware/Software Interrupt Sequence

![](img/d7c975450dfbe59120092c2721be78c6_395_0.png)

- 4. Upon observing its own interrupt acknowledge cycle on PCI, the PCH converts it into the two cycles that the internal 8259 pair can respond to. Each cycle appears as an interrupt acknowledge pulse on the internal INTA# pin of the cascaded interrupt controllers.
- 5. Upon receiving the first internally generated INTA# pulse, the highest priority ISR bit is set and the corresponding IRR bit is reset. On the trailing edge of the first pulse, a slave identification code is broadcast by the master to the slave on a private, internal three bit wide bus. The slave controller uses these bits to determine if it must respond with an interrupt vector number during the second INTA# pulse.
- 6. Upon receiving the second internally generated INTA# pulse, the PIC returns the interrupt vector number. If no interrupt request is present because the request was too short in duration, the PIC returns vector number 7 from the master controller.
- 7. This completes the interrupt cycle. In AEOI mode the ISR bit is reset at the end of the second INTA# pulse. Otherwise, the ISR bit remains set until an appropriate EOI command is issued at the end of the interrupt subroutine.

### Interrupt Vector Table(IVT) in real mode

- **Interrupt vector(IV)**
  - The address of interrupt-handling program corresponding to the vector number.
  - Four bytes for each interrupt vector.
- **Interrupt Vector Table(IVT)**
  - The storage area which store the interrupt vector in order of the interrupt vector number.
  - Beginning from the address 0000: 0000,1KB range.
- **Interrupt Vector Pointer(IVP)**
  - IVP = Vector × 4

### Interrupt-handling routine programming

- 1) Write the IVT directly.

```
CLI                     ; disable the maskable interrupt
MOV AX, 0
MOV ES, AX              ; ES= 0000H(segment address of IVT)
MOV SI, 0CH*4           ; 4 bytes for each interrupt vector
MOV AX, OFFSET SERVICE  ; EA of routine
MOV ES:[SI], AX
MOV AX, SEG SERVICE     ; segment address of routine
MOV ES:[SI+2], AX
STI                     ; enable the interrupt
......
; interrupt-handling routine
SERVICE PROC FAR
......
```

- 2) use DOS system calls

```
MOV AX, SEG SERVICE
MOV DS, AX
MOV DX, OFFSET SERVICE
MOV AX, 250CH
INT 21H
```
