
## 2.6.7 Procedure Instructions

### Procedure Define

```
LABEL PROC [attributes]
...; procedure body
RET
...; procedure body
LABEL ENDP
```

- Procedure body always follows a .CODE directive.
- Procedure body is bracketed by two directives, PROC and ENDP
- Label gives the name of the procedure.
- Attributes: near or far
- At least has one RET instruction

### Procedure Define

**Define a procedure to output CRLF to screen. (16bit program use)**

```
CRLF  PROC NEAR    ; output Carriage Return and Line Feed
      PUSH AX
      PUSH DX
      MOV  DL, 0DH    ; Carriage Return
      MOV  AH, 2
      INT  21H       ; output char in DL
      MOV  DL, 0AH    ; Line Feed
      MOV  AH, 2
      INT  21H       ; output char in DL
      POP  DX
      POP  AX
      RET
CRLF  ENDP
```

Define a procedure “DECIBIN” to input a decimal number from keyboard, the number return by BX.

```
DECIBIN PROC NEAR
    PUSH  AX
    PUSH  CX
    MOV   BX, 0 ; initial
NEWCHAR:MOV AH, 1
    INT   21H ; ASCII in AL
    SUB   AL, 30H
    JL    EXIT   ; < 0
    CMP   AL, 9
    JG    EXIT   ; > 9
    CBW
```

```
XCHG  AX, BX
MOV   CX, 10
MUL   CX   ; old value *10
XCHG  AX, BX
ADD   BX, AX ;add new value
JMP   NEWCHAR
EXIT: POP   CX
      POP   AX
      RET
DECIBIN ENDP
```

### Passing Parameters

- Passing Parameters in 16-bit program
  - by stack

**Define a procedure “PROSUM” to calculate the sum of WORD array. The number of element in COUNT, the result will in SUM.**

```asm
.DATA
    ARRAY  WORD 10 DUP(?)
    COUNT  WORD 10
    SUM    WORD ?
```
**Main program:**

```
LEA BX,ARRAY    ; parameter in stack
PUSH BX
LEA BX,COUNT
PUSH BX
LEA BX,SUM
PUSH BX
CALL PROSUM
......

PROSUM PROC NEAR
    PUSH BP
    MOV BP,SP
    PUSH AX
    PUSH CX
    PUSH SI
    PUSH DI
```

### Example

**Input** 10 numbers in an array, then calculate the sum of is elements.

```asm
.8086
.MODEL SMALL
.DATA
    ARRAY  WORD 10 DUP(?)
    COUNT  WORD 10
    SUM    WORD ?
    STRING BYTE 6 DUP(?)
.STACK 1024
```

```
.8086
.MODEL SMALL
.DATA
    ARRAY  WORD 10 DUP(?)
    COUNT  WORD 10
    SUM    WORD ?
    STRING BYTE 6 DUP(?)
.STACK 1024
.CODE
START:
    MOV   AX,@DATA
    MOV   DS,AX
    LEA   DI,ARRAY
    MOV   CX,10
LP: CALL  DECIBIN
    CALL  CRLF
    MOV   [DI],BX
```

```
ADD   DI,2
LOOP  LP ;input 10 numbers
LEA   BX,ARRAY
PUSH  BX
LEA   BX,COUNT
PUSH  BX
LEA   BX,SUM
PUSH  BX
CALL  PROSUM
MOV   AX,SUM
LEA   DI,STRING
CALL  PINT
CALL  CRLF
MOV   AX,4C00H
INT   21H
......   ; subroutine
END START
```
