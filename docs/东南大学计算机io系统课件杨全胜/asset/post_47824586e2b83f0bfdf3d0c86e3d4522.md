
## 2.6.2 Arithmetic Instructions
## Multiplication and Division

- Unsigned Multiplication
  - `MUL SRC`
- Signed Multiplication
  - `IMUL SRC`

| Symbolic | Operation |
|---|---|
| `MUL/IMUL reg/mem8` | `AX ← AL * reg/mem8` |
| `MUL/IMUL reg/mem16` | `DX:AX ← AX * reg/mem16` |
| `MUL/IMUL reg/mem32` | `EDX:EAX ← EAX * reg/mem32` |

### Unsigned Multiplication

```
MUL SRC
```

### Signed Multiplication

```
IMUL SRC
```

The product after a multiplication is always a double-width product.

This instruction have an affect on CF and OF

- CF=OF=1: indicates that the high order half of the product is not zero
- CF=OF=0: indicates that the high order half of the product is zero
- No meaning on changing other flags

## Multiplication and Division

### A special signed Multiplication

```
IMUL REG, SRC
IMUL REG, SRC, IMM
```

Product, REG and SRC are the same size, 16-bit or 32-bit

| Symbolic | Operation |
|---|---|
| IMUL *reg16/32, reg/mem16/32* | Reg16/32=reg16/32*reg/mem16/32 |
| IMUL *reg16/32, reg/mem16/32, imm8* | Reg16/32=reg/mem16/32*sign-extended imm8 |
| IMUL *reg16, reg/mem16, imm16* | Reg16=reg/mem16*sign-extended imm16 |
| IMUL *reg32, reg/mem32, imm32* | Reg32=reg/mem32*sign-extended imm32 |

- Unsigned Division
  - DIV SRC
- Signed Division
  - IDIV SRC

| Symbolic | Operation |
|---|---|
| DIV/IDIV reg/mem8 | AX divided by reg/mem8<br>AL←Quotient, AH←Remainder |
| DIV/IDIV reg/mem16 | DX:AX divided by reg/mem16<br>AX←Quotient, DX←Remainder |
| DIV/IDIV reg/mem32 | EDX:EAX divided by reg/mem32<br>EAX←Quotient, EDX←Remainder |

### Unsigned Division
`DIV SRC`

### Signed Division
`IDIV SRC`

### Errors occur during division

- An attempt to divide by zero;
- A quotient that is too large to fit in the single-length destination
  - 2468AH ÷ 2 = 12345H
  - 0FFFFFFFH ÷ 1 = 0FFFFFFFFH

The division instructions may destroy previously set values of AF, CF, OF, PF, SF and ZF, but undefined.

### Multiplication and Division

- Unsigned Division

```
DIV SRC
```

- Signed Division

```
IDIV SRC
```

- The sign of the quotient is determined by the sign of the dividend and divisor using the ordinary rules of signs;
- The sign of the remainder is always the same as the sign of the dividend

### ■ Multiplication and Division

- ◆ Unsigned Division
  `DIV SRC`
- ◆ Signed Division
  `IDIV SRC`

The dividend is always a double-width dividend
that is divided by the operand.

- • For unsigned division,
  - Extend zero in high part
- • For signed division,
  - Extend sign bit to high part

### Sign extend instructions

|  |  |
|---|---|
| CBW | : AL to AX |
| CWD | : AX to DX:AX |
| CWDE | : AX to EAX |
| CDQ | : EAX to EDX:EAX |

```
RESILT DB ?
.....
MOV AL, -127    ; Dividend(81H)
CBW             ; Byte extend to word
MOV BL, 15      ; Divisor
IDIV BL         ; -127/15
MOV RESULT, AL  ; Quotient
```

```
N1  WORD  ?
N2  WORD  ?

......
MOV  AX, 2012      ; Dividend=2012
MOV  DX, 0         ; Zero Extend to DX:AX
MOV  BX, 1000      ; Divisor = 1000
DIV  BX            ; 10000H/100H
MOV  N1, AX        ; Quotient
MOV  N2, DX        ; Remainder
```

Suppose X, Y, Z, V are 16-bit signed number, calculate (V-(X*Y+Z))/X. Quotient in AX, Remainder in DX

```
MOV  AX, X
IMUL Y                 ; X*Y
MOV  CX, AX
MOV  BX, DX            ; store in BX: CX
MOV  AX, Z
CWD                    ; signed extend the Z
ADD  CX, AX            ; X*Y+Z
ADC  BX, DX
MOV  AX, V
CWD                    ; signed extend the V
SUB  AX, CX            ; -
SBB  DX, BX
IDIV X                 ; Divided by X
```
