
## 4.2 8259A PIC
### Operation and commands

- **Port Address**
  - Only two port address.
- **Command**
  - Initialization Command Words
    - ICW1, ICW2, ICW3 and ICW4
  - Operation Command Words
    - OCW1, OCW2, OCW3
- **Status can be read**
  - IRR, ISR, IMR, Status Word
- **The way that use a few addresses to read/write more commands and status**
  - Data has free bits: Characteristic bit(CHB)
  - Data has no free bits: Timing sequence(TS); R/W

| PIC1 in x86 | PIC2 in x86 | R/W | Content | CHB D4 D3 D2 | Time sequence |
|---|---|---|---|---|---|
| 20H | 0A0H | write | ICW1 | 1 × × | - |
|  |  |  | OCW2 | 00 × |  |
|  |  |  | OCW3 | 01 × |  |
| 21H | 0A1H | write | ICW2~ICW4 | 无 | After ICW1, ICW2→ICW4 |
|  |  |  | OCW1 |  | In normal state |
| 20H | 0A0H | read | IRR, ISR Status Word | 无 | Determine by OCW3 |
| 21H | 0A1H | read | IMR | - | - |

Notes: ICW x only be used during the initialization.

### Initialization Command Words 1(ICW1)

| A0 | D7 | D6 | D5 | D4 | D3 | D2 | D1 | D0 |
|---|---|---|---|---|---|---|---|---|
| 0 | 0 | 0 | 0 | 1 | LTIM | ADI | SNGL | IC4 |

Invalid: D7 D6 D5
CHB: D4
Invalid: D2
IC4: =0: No ICW4 needed
=1: ICW4 needed
SNGL: =0: Cascade mode
=1: Single
LTIM: =0: Edge triggered mode
=1: Level triggered mode

If SNGL = 1, no ICW3 will be issued.

### Initialization Command Words 2(ICW2)

| A0 | D7 | D6 | D5 | D4 | D3 | D2 | D1 | D0 |
|---|---|---|---|---|---|---|---|---|
| 1 | T7 | T6 | T5 | T4 | T3 | 0 | 0 | 0 |

Leftmost 5 bits of the interrupt vector number    Invalid

Sequence: ICW1 → ICW2 → [ICW3] → [ICW4]

interrupt vector number of IRi = [7:3] of ICW2 + i

e.g. if ICW2 = 08H then
the interrupt vector number of IR3 = 08H + 03H = 0BH

### Initialization Command Words 3(ICW3)

| A0 | D7 | D6 | D5 | D4 | D3 | D2 | D1 | D0 |
|---|---|---|---|---|---|---|---|---|
| 1 | S7 | S6 | S5 | S4 | S3 | S2 | S1 | S0 |

ICW3 of master controller

| A0 | D7 | D6 | D5 | D4 | D3 | D2 | D1 | D0 |
|---|---|---|---|---|---|---|---|---|
| 1 | × | × | × | × | × | ID2 | ID1 | ID0 |

ICW3 of slave controller

For the master controller, ICW3 is used to indicate which IRQ input line is used to cascade the slave controller. The corresponding bit in ICW3 is set to a 1.

For the slave controller, ICW3 is the slave identification code used during an interrupt acknowledge cycle.

### Initialization Command Words 4(ICW4)

| A0 | D7 | D6 | D5 | D4 | D3 | D2 | D1 | D0 |
|---|---|---|---|---|---|---|---|---|
| 1 | 0 | 0 | 0 | SFNM | BUF | M/S# | AEOI | µPM |

- D0: 1 = 8086/8088 MODE; 0 = MCS-8080 MODE
- D1: 1 = AUTO EOI MODE; 0 = NORMAL EOI
- D3D2: 0X = NON BUFFERED MODE; 10 = BUFFERED MODE/SLAVE; 11 = BUFFERED MODE/MASTER
- D4: 1 = SPECIAL FULLY NESTED MODE; 0 = FULL NESTED MODE

### Operation Control Word 1 (OCW1)

| A0 | D7 | D6 | D5 | D4 | D3 | D2 | D1 | D0 |
|---|---|---|---|---|---|---|---|---|
| 1 | M7 | M6 | M5 | M4 | M3 | M2 | M1 | M0 |

1=masked 0=enable

OCW1 sets and clears the mask bits in the Interrupt Mask Register (IMR).

M7~M0 represent the eight mask bits.

- M = 1 indicates the channel is masked (inhibited),
- M = 0 indicates the channel is enabled.
