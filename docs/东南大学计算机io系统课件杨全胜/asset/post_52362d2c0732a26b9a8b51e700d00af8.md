### Square Wave Generator that Duty cycle is 4:9

The frequency of the CLK0 in 8254 is 8KHz, then

- 1) What is the maximum period of OUT0?
- 2) Now wish the port address of 8254 is 90H, 92H, 94H and 96H, please design the decoding circuit by 74LS138 and some Gate.
- 3) Now want to generate the square wave which period is 9s and the duty cycle is 4:9. Please complete the above circuit the realize the decoder, and programming it.

Answer:
1) T_CLK0=1/f_CLK0=1/8000=0.125ms
Maximum period =65536×0.125ms=8.192 second
or: f_CLK0/f_OUT=65536=>T_max=1/f_OUT=65536/ f_clk0 =65536/8000=8.192 second

## 5.4 8254 in PCH

![](img/d7c975450dfbe59120092c2721be78c6_438_0.png)

### Counter 0, System Timer

- Frequency of CLK0 is 1.1931816MHz; Initial count is 65536
- This counter functions as the system timer by controlling the state of IRQ0 and is typically programmed for Mode 3 operation.
- OUT0 generate the square wave which frequency is 18.2Hz to IRQ0 in Master 8259A.
- The counter asserts IRQ0 when the count value reaches 0, reloads the initial count value, and repeats the cycle, alternately asserting and negating IRQ0.

### Counter 1, Refresh Request Signal

- Frequency of CLK1 is 1.1931816MHz; initial count is 18.
- This counter provides the refresh request signal and is typically programmed for Mode 2 operation and only impacts the period of the REF_TOGGLE bit in Port 61.
- OUT1 connect DREQ0 in 8237, every 15.08µs have a width of 838ns pulse for RAM refresh.

### Counter 2, Speaker Tone

- Frequency of CLK1 is 1.1931816MHz; initial count is sent in software.
- This counter provides the speaker tone and is typically programmed for Mode 3 operation
- The counter provides a speaker frequency equal to the counter clock frequency (1.193 MHz) divided by the initial count value.
  - Initial count = frequency of CLK2 / frequency of sound
- The speaker must be enabled by a write to port 61h
