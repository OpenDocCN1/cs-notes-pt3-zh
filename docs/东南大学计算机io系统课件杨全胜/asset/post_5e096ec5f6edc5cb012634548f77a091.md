## 7.4 16550 UART

### Divisor Latch (DL)

DLAB=1, A2A1A0=001(MSB) or 000(LSB)

The UART contains a programmable Baud Generator that is capable of taking any clock input from DC to 24 MHz and dividing it by any divisor

Value_Divisor Latch = (frequency_XOUT) ÷ (baud rate × 16)

16550 use 18.432MHz crystal as a timing source in PC. if 240 is programmed into the Baud rate divisor. The Baud rate is (18.432MHz ÷16) ×240 = 4800 Baud

## 7.5 COM in IA-32

### What is COM in communication?

- COM is the original, yet still common, name of the serial port interface on IBM PC-compatible computers.
- It might not only refer to physical ports, but also to virtual ports, such as ports created by bluetooth or USB-to-Serial adapters.
- COM in IA-32
  - COM1: I/O port 0x3F8, IRQ 4
  - COM2: I/O port 0x2F8, IRQ 3
  - COM3: I/O port 0x3E8, IRQ 4
  - COM4: I/O port 0x2E8, IRQ 3

## 7.5 COM in IA-32

### 16550 initialize

- 1. Write the divisor latch DL(port 0 and 1) to set baud rate.
- 2. Write the line control register LCR(port 3) to set the format of the asynchronous data communications exchange.
- 3. Write the MODEM control register MCR( port 4) to set the MODEM control word.
- 4. Write Interrupt enable register IER(port 1) to set the interrupt enable word.
