## 3.4 8086/8088 Hardware
### Pin-outs and the Pin Function
### 8086 pin we will use

- CLK : I, The clock pin provides the basic timing signal to the microprocessor.
- AD0~15 : O/IO, address/data bus. When ALE is 1, transfer the rightmost 16 bits of the memory address or I/O port number; when ALE=0, transfer the data. In 8088 is AD0~7 and A8~15
- A16~19 : O, When ALE is 1, transfer the leftmost 4 bits of the memory address.
- M/IO* : O, when this signal is a logic 1, means the address bus contains the memory address, otherwise, it contains the I/O port number.

* A or A# means signal A is active when it is 0 value.

## 3.4 8086/8088 Hardware
### Pin-outs and the Pin Function
### 8086 pin we will use

- RD̅ : O, When the read signal is a logic 0, the data bus is receptive to data from the memory or I/O device.
- WR̅ : O, When the write signal is a logic 0, the data bus contains valid data that 8086 outputting to the memory or I/O device.
- ALE : O, Address latch Enable shows that 8086 AD₀-15 contains address information.
- INTR : I, Interrupt request is used to request a hardware interrupt.
- INTA̅ : O, The interrupt acknowledge signal is a response to the INTR input pin.

## 3.5 Personal Computer I/O Map

- I/O Port Address
  - I/O Port number
    - Registers in the I/O modules are numbered, this number is called the ports number
  - I/O Ports Address
    - I/O Ports Address = the base address of I/O module(Interface) + Ports number
  - Note:
    - There are many ports in one I/O module(Interface)
    - One I/O port address can receive a variety of command, corresponding to multiple registers.

## 3.5 Personal Computer I/O Map
### I/O Address Space in PC

- 64k 8-bit port address space, or 32k 16-bit port address space, or 16k 32-bit port address space.
  - 00~0FFH is normally reserved for the computer system in main-board.
  - 100H~3FFH is normally reserved for the ISA bus.
  - 400H~0FFFH are generally available for user application, main-board function and the PCI bus.
- Port address must be aligned.
