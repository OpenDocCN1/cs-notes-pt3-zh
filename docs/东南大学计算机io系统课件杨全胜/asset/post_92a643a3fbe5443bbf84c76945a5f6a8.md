
## 4.4 Interrupt process in Modern PC
## Interrupt-handling routine programming

- Save the context
  - The register will be used in interrupt-handling routine must be push in stack.

- Avoid DOS reentrant in the interrupt handler for non-software interrupt
  - You can not use DOS system calls(int 21h) in the interrupt handler. But BIOS calls can be used.

- The interrupt handler must small and execute quickly.
  - The execute time of interrupt handler must less than the minimum time interval of interrupts.
  - You can't use long loop and the human-computer interaction in interrupt handler.

## 4.4 Interrupt process in Modern PC
## Interrupt-handling routine programming

- **Set or clear the IF**
  - The IF was cleared when the interrupt be responded.
  - You can set IF to allow the interrupt nested, but remember to clear the IF before return from interrupt handler.

- **Process the EOI, and return**
  - If the interrupt is from 8259, and 8259 run in EOI mode, you must sent EOI command.
  ```asm
  MOV  AL, 20H
  OUT  20H, AL    ; sent EOI to master 8259
  OUT  0A0H, AL   ; sent EOI to slave 8259
  ```

- Resume the register saved before.
- Execute the IRET instruction to return.

### ◆ Template of interrupt handler

(suppose the vector number is 0CH)

```asm
; main procedure
OLDDOC    DWORD     ?
......
CODE      SEGMENT

    ......
    MOV     AX, 350CH       ; Save the original 0CH interrupt vector
    INT     21H
    MOV     WORD PTR OLDDOC, BX
    MOV     WORD PTR OLDDOC+2, ES
    MOV     AX, SEG SERVICE  ; set new 0CH interrupt vector
    MOV     DS, AX
    MOV     DX, OFFSET SERVICE
    MOV     AX, 250CH
    INT     21H
    ......                    ; others
```

## 4.4 Interrupt process in Modern PC
## Interrupt-handling routine programming
### Template of interrupt handler

(suppose the vector number is 0CH)

```asm
; interrupt handler
SERVICE PROC FAR
    PUSHA      ; push register
    PUSH DS
    STI        ; set IF
    .....      ; main function in handler
    CLI        ; clear IF
    MOV AL, 20H
    OUT 20H, AL ; sent EOI
    POP DS      ; resume
    POPA
    IRET
SERVICE ENDP
```
