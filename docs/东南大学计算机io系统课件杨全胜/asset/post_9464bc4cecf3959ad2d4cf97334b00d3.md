
## 2.6.1 Data Movement Instructions
### Miscellaneous data transfer instructions

- LAHF Instruction
  - Transfers the rightmost eight bits of the flag register into the AH register.
- SAHF Instruction
  - Transfers the AH register into the rightmost eight bits of the flag register.

### XLAT Instruction

- Converts the contents of the AL register into a number stored in a memory table.
- The offset of the table must in the (E)BX register.
- The type of table is byte.

**Example:**

```asm
MOV BX, OFFSET TABLE
     ; EA of table to BX
MOV AL, 4
     ; index in AL
XLAT
```

| TABLE | Value |
|---|---|
| +0 | 30H |
| +1 | 31H |
| +2 | 32H |
| +3 | 33H |
| +4 | 34H |
| +5 | 35H |
| +6 | 36H |
| +7 | 37H |

### IN and OUT Instruction

- IN instruction transfers data from an external I/O device into AL, AX, or EAX.
- OUT instruction transfers data from AL, AX, or EAX to an external I/O device.
- Two forms of I/O device (port) addressing exist
- Fixed-port addressing allows data transfer between AL, AX, EAX using 8-bit I/O port address with immediate addressing(direct addressing).
- Variable-port addressing allows data transfer between AL, AX, EAX using 16-bit I/O port address. The I/O port number is stored in register DX.

| Symbol | Example |
|---|---|
| IN AL/AX/EAX, p8 | IN AX, 52H; input a word from 52H port |
| IN AL/AX/EAX, DX | IN AL, DX; input a byte from (DX) port |
| OUT p8, AL/AX/EAX | OUT 40H, AL; output a byte to 40H port |
| OUT DX, AL/AX/EAX | OUT DX, AX; output a word to (DX) port |

```

### MOVSX and MOVZX Instruction

- Both of them are found in the 80386-Core instructions Set.
- These instructions move data, and at the same time either sign- (MOVSX) or zero- (MOVZX) extend it.

| Symbolic | Example |
|---|---|
| MOVSX reg16/32, reg8/16 | MOVSX CX, BL |
| MOVSX reg16/32,mem8/16 | MOVSX ECX, [EDI] |
| MOVZX reg16/32, reg8/16 | MOVZX EAX, BX |
| MOVZX reg16/32,mem8/16 | MOVZX CX, BYTE PTR[DI] |

Example:
if (CL)=0ABH,
MOVSX AX, CL
    after execution (AX)=0FFABH   ; Sign-extend
MOVZX AX, CL
    after execution (AX)=00ABH    ; Zero-extend
if (DATA) = 78ADH
MOVSX EAX, DATA
    after execution (AX)=000078ADH ; Sign-extend
MOVZX EAX, DATA
    after execution (AX)=000087ADH ; Zero-extend

## 2.6.2 Arithmetic Instructions

- Addition, Subtraction, and Comparison

### Addition, Subtraction, and Comparison
### Addition instruction

```
ADD DST, SRC
```

- DST←(DST)+(SRC)
- This instruction have an affect on CF, SF, OF, PF, ZF and AF

| Symbolic | Example |
|---|---|
| ADD reg8/16/32, imm8/16/32 | ADD AX,837FH |
| ADD reg8/16/32, reg8/16/32 | ADD EAX, EBX |
| ADD reg8/16/32, mem8/16/32 | ADD CX, WORD PTR[SI] |
| ADD mem8/16/32, reg8/16/32 | ADD BYTE PTR[DI],DL |
| ADD mem8/16/32, imm8/16/32 | ADD BYTE PTR[DI], 23 |
