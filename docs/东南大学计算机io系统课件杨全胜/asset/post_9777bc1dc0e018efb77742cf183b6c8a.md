
## 2.6.3 Logic Instructions

### Shift and Rotate Instruction

◆ Rotate Instructions

```
OP DST, CNT: OP is ROL, RCL, ROR, RCR
```

- **OP is**
  - `ROL` - DST rotates left CNT times
  - `RCL` - DST rotates left through CF CNT times
  - `ROR` - DST rotates right CNT times
  - `RCR` - DST rotates right through CF CNT times

- **DST is** a data in register or in memory

- **CNT is**
  - `1`
  - `CL`
  - `Imm8 (80386 or above only)`

### Rotate Instructions

Sent LSb of AL to the LSb of BL, keep the AL no changed.

```
ror bl,1
ror al,1
rcl bl,1
rol al,1
```

### Only affect OF and CF

- last bit shifted out goes to CF
- The OF flag is defined only for the 1-bit rotates; if the sign changed, OF=1

### Example

### Unconditional Jump (JMP)

### Short Jump

```
JMP SHORT OPR
```

- Relative short jump in current segment
- New address is
  - (E)IP=(E)IP+8-bit displacement
    - Displacement is a one-byte signed number whose value range between +127~-128
- We can use a label (a symbolic name for a memory address) with the short jump instruction

### Unconditional Jump (JMP)

### Near Jump

```
JMP OPR
```

- Relative near jump in current segment
- In real mode
  - (E)IP=(E)IP+16-bit displacement
    - Displacement is a 2-byte signed number whose value range between +32767~-32768
- In protected mode for 80386 or above
  - EIP=EIP+32-bit displacement
    - Displacement is a 4-byte signed number whose value range between +2G~-2G
- We can use a label too.

### Unconditional Jump (JMP)

◆ Far Jump

```
JMP FAR PTR OPR
```

- Obtains a new segment and offset address to accomplish the jump

- New address is
  - (E)IP = Byte 2 and 3 of this 5-byte instruction
  - CS = Byte 4 and 5 of this 5-byte instruction
  - In protected mode for 80286 or above
    - EIP may be 32 bits

We can use a label too.
