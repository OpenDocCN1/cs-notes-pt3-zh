### The Query Word

| D7 | D6 | D5 | D4 | D3 | D2 | D1 | D0 |
|---|---|---|---|---|---|---|---|
| I | - | - | - | - | W2 | W1 | W0 |

- **W2 – W0**: Binary code of the highest priority level requesting service.
- **I**: Equal to "1" if there is an interrupt.

### SMM operation

| A0 | D7 | D6 | D5 | D4 | D3 | D2 | D1 | D0 |
|---|---|---|---|---|---|---|---|---|
| 0 | × | ESMM | SMM | 0 | 1 | P | RR | RIS |

| ESMM | SMM | Function |
|---|---|---|
| 0 | × | No Action |
| 1 | 0 | Reset special mask |
| 1 | 1 | Set special mask |

## 4.3 Interrupt in x86 System

### Interrupt and Exception Classification

### Non-Maskable Interrupt (NMI)

- Hardware, non-maskable, and Vector interrupt
- Interrupt request signal sent to the NMI pin.
- interrupt vector number: 2
- No need interrupt recognition.
- When NMI signal transition from 0 to 1, then maintain high level at least four processor clock cycles, an NMI interrupt will be recognized.
- NMI transition from 1 to 0 and maintain low level at least four processor clock cycles, a new NMI interrupt can be identified.

### Software-Generated Interrupts

- Software, non-maskable, and Vector interrupt
- The INT n instruction permits interrupts to be generated from within software by supplying an interrupt vector number as an operand.
- interrupt vector number: Operand in INT n
- No need interrupt recognition.
- BIOS interrupt
  - INT 10H, INT 13H, INT 16H, ...
- DOS interrupt
  - INT 20H, INT 21H, INT 24H,...

### Interrupt instruction
