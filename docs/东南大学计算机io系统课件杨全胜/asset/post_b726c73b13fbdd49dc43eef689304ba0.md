
## 4.2 8259A PIC

## General Description of the 8259A

PIC: Programmable Interrupt controller

## Function

- Accept extern interrupt request;
- Manage the interrupt request (queued, priority, mask, nested);
- Sends the interrupt request signal(INTR) and interrupt vector number to the microprocessor;
- Processes the end of interrupt;
- Accept the command come from the processor and return the status.

## General Description of the 8259A

## Response of the interrupt in 8259A

- When 8259 sent INT signal to processor, it will wait two INTA# pulse from processor for acknowledge.
- The PIC uses the first INTA# pulse to freeze the state of the interrupts for priority resolution. Additionally, the ISR for the interrupt is set, the IRR for the interrupt is cleared.
- On the second INTA# pulse, the PIC sends the interrupt vector number to the processor. The ISR bit be cleared when:
  - if in AEOI mode, on the trailing edge of the second INTA#;
  - if in Normally mode, the processor issues an EOI command immediately before returning from the service routine.

## 4.2 8259A PIC

## Modes of Operation

## Edge and Level Triggered Mode

### Edge Triggered mode

- An interrupt request will be recognized by a low-to-high transition on the corresponding IRQ input.

### Level Triggered mode

- An interrupt request will be recognized by a high level on the corresponding IRQ input and there is no need for an edge detection.

In both the edge and level triggered modes, the IRQ inputs must remain active until after the falling edge of the first internal INTA#. If the IRQ input goes inactive before this time, a default IRQ7 vector number is returned.

## 4.2 8259A PIC

## Modes of Operation

### Poll Mode

In this mode, the INT output function as it normally does, but the microprocessor should ignore this output. Service to devices is achieved by software using a Poll command.

### Nested Mode

#### Full nested mode

- While the ISR bit is set, all further interrupts of the same or lower priority are inhibited.

#### Special Fully-Nested Mode

- While the ISR bit is set, all further interrupts of the lower priority are inhibited.

## 4.2 8259A PIC

## Modes of Operation

### Buffered Mode

- When the 8259A is used in a large system where bus driving buffers are required on the data bus, it will structure the 8259A to send an enable signal on SP#/EN# to enable the buffers.
- This modification forces the use of software programming to determine whether the 8259A is a master or a slave.

### Non-buffered Mode

- SP#/EN# = 1; 8259A is the master controller
- SP#/EN# = 0; 8259A is the slave controller

## 4.2 8259A PIC

## Modes of Operation

### Mask Mode

#### Normal Mask Mode

- Each bit in the IMR masks one interrupt channel if it is set (1). Bit 0 masks IR0, Bit 1 masks IR1 and so forth.

#### Special Mask Mode

- When a mask bit is set in OCW1, it inhibits further interrupts at that level and enables interrupts from all other levels (lower as well as higher) that are not masked.

## 4.2 8259A PIC

## Modes of Operation

### Priority Mode

#### Fixed Priority

- The interrupt requests are ordered in priority from 0 through 7 (0 highest).

#### Rotation Priority

(The IR0 ~ IR7 priority as a circular queue.)

- Automatic Rotation
  - In this mode a device, after being serviced, receives the lowest priority.

- Specific Rotation
  - The programmer can change priorities by programming the bottom priority and thus fixing all other priorities; i.e., if IR4 is programmed as the bottom priority device, then IR5 will have the highest

## 4.2 8259A PIC

## Modes of Operation

### End of Interrupt

#### Normally Mode

- The ISR bit can be reset by an EOI command that must be issued to the 8259A before returning from a service routine.
  - When a Non-Specific EOI command is issued the 8259A will automatically reset the highest IS bit of those that are set.
  - Specific EOI command includes the IS level to be reset as part of the command.

#### Automatic End of Interrupt (AEOI) Mode

- The 8259A will automatically perform a non-specific EOI operation at the trailing edge of the last INTA#
