
## 1.3 Real-address mode memory model

### Alignment of Words, Doublewords, and Quadwords

- The natural boundaries for words, double words, and quadwords are even-numbered addresses, addresses evenly divisible by four, and addresses evenly divisible by eight, respectively.
- To improve the performance of programs, data structures (especially stacks) should be aligned on natural boundaries whenever possible.
- The reason for this is that the processor requires two memory accesses to make an unaligned memory access; aligned accesses require only one memory access.

### Real mode memory addressing

- All real mode physical memory address are 20 bits wide.
- All real mode logical memory addresses must consist of a segment address plus an offset address.

- **Segment address (16 bits):** located within one of segment register, defines the beginning address of any 64K-byte memory segment.
- **Offset address (16 bits):** selects any location within the 64K-byte memory segment.
- Writing as **Segment address : Offset address**

### Numeric Data Types

### Integer

### Unsigned Integers

- Unsigned integers are unsigned binary numbers contained in a byte, word, doubleword, and quadword.
- Unsigned integers are sometimes referred to as ordinals.

### Signed Integers

- Signed integers are signed binary numbers held in a byte, word, doubleword, or quadword.
- All operations on signed integers assume a two's complement representation.

- The sign bit is located in most significant bit(MSb).

### Floating-Point Data Types

The IA-32 architecture defines and operates on three floating-point data types:

- single-precision floating-point
- double-precision floating-point
- double-extended precision floating-point

The data formats for these data types correspond directly to formats specified in the IEEE Standard 754 for Binary Floating-Point Arithmetic.

| Data Type | Sign | Biased Exponent | Mantissa | Approximate Normalized Range |
|---|---|---|---|---|
| single-precision | 1 | 8 | 24 | 1.18×10⁻³⁸ ~ 3.40 ×10³⁸ |
| Double Precision | 1 | 11 | 53 | 2.23×10⁻³⁰⁸ ~ 1.79×10³⁰⁸ |
| Double Extended Precision | 1 | 16 | 64 | 3.37×10⁻⁴⁹³² ~ 1.18×10⁴⁹³² |

Mantissa contains an implied(hidden) one-bit, the hidden bit is the first bit of the normalized real number.

### Pointer Data Types

- Pointers are addresses of locations in memory
- In non-64-bit modes, the architecture defines two types of pointers: a near pointer and a far pointer.
- In 16-bit mode
  - A near pointer is a 16-bit offset (also called an effective address) within a segment.
  - A far pointer is a logical address, consisting of a 16-bit segment base address and a 16-bit offset.
- In 32-bit mode
  - A near pointer is a 32-bit offset (also called an effective address) within a segment.
  - A far pointer is a logical address, consisting of a 16-bit segment selector and a 32-bit offset.
