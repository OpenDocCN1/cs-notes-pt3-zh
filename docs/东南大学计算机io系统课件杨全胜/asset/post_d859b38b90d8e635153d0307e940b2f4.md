
## 2.4 Assembly Language Source Code
### Using Simplified Segment Directives

- MASM programs consist of modules made up of segments.
- Every program written only in MASM has one main module, where program execution begins.
- Main module can contain code, data, or stack segments defined with all of the simplified segment directives.
  - `.MODEL`, `.CODE`, `.CONST`, `.DATA`, `.DATA?`, `.FARDATA`, `.FARDATA?`, `.STACK`, `.STARTUP`, and `.EXIT`.

### Using Simplified Segment Directives
### .MODEL

```
`.MODEL memorymodel [[, langtype]] [[, stackoption]]`
```

- Initializes the program memory model.
- You must place `.MODEL` in your source file before any other simplified segment directive.
- The *memorymodel* can be **TINY, SMALL, COMPACT, MEDIUM, LARGE, HUGE,** or **FLAT**. If you are writing an assembler routine for a high-level language, this option should match the memory model used by the compiler or interpreter.

### Using Simplified Segment Directives
### .MODEL

```
`.MODEL memorymodel [[, langtype]] [[, stackoption]]`
```

- The *langtype* can be **C, BASIC, FORTRAN, PASCAL, SYSCALL**, or **STDCALL**. Instructs the assembler to follow the naming, calling, and return conventions for the indicated language.
- The *stackoption* can be **NEARSTACK** (if SS equals DS) or **FARSTACK** (if SS is not equal to DS). **NEARSTACK** is the default.

### Using Simplified Segment Directives
### Create Data Segment

```
.DATA
```

The .DATA directive creates a near initialized data segment (with segment name _DATA) and ends the previous segment, if any. The .DATA segment should contain all global data that have initial values.

The .DATA segment can occupy up to 64K in MS-DOS or 512 megabytes under flat model in Windows.

You can use @data to determine the group of the data segment.

### Using Simplified Segment Directives
### Create Data Segment

```
.CONST
```

Starts a constant data segment and ends the previous segment, if any. This segment should contain all strings, real numbers, and other constant data accessed by a high-level language. It has the READONLY attribute.

```
.DATA?
```

The .DATA? directive starts the uninitialized data segment (with segment name _BSS) and ends the previous segment, if any. Place all uninitialized data in the .DATA? segment.

### Using Simplified Segment Directives
### Create Data Segment

```
.STACK [SIZE]
```

defines a stack segment (with segment name STACK). The optional size specifies the number of bytes for the stack (default 1,024).

## 2.4 Assembly Language Source Code
### Simplified Segment
### End the Source File

```
END [ADDRESS]
```

Marks the end of a source file and optionally indicates the program load address. The optional <address> is a label or expression identifying where program execution begins.

END also closes the last segment in the source file.
