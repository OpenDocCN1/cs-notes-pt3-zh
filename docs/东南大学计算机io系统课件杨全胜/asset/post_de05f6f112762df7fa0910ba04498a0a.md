## 2.3 Directives

### OFFSET and SEG Operator

- An address constant is consists of an offset or segment value.
  - **The OFFSET Operator**
    - returns the offset of a memory location.
  - **The SEG Operator**
    - returns the segment address of a memory location

```
str  BYTE "Hello!", 13, 10, 0
...
mov ax, SEG str      ; Load segment address
mov es, ax
mov bx, OFFSET var ; Load offset address
```

## 2.3 Directives

### Arithmetic Operators

- expression1 + expression2
  - Returns expression1 plus expression2
- expression1 − expression2
  - Returns expression1 minus expression2
- expression1 * expression2
  - Returns expression1 times expression2
- expression1 / expression2
  - Returns expression1 divided by expression2
- −expression
  - Reverses the sign of expression.
- expression1 MOD expression2
  - Returns the integer value of the remainder (modulo) when dividing expression1 by expression2

## 2.3 Directives

### PTR Operator

```
[type|distance] PTR expression
```

- Forces the expression to be treated as having the specified type.
- type is BYTE, WORD, DWORD, FWORD, QWORD or TBYTE.

```
Mask BYTE 70H,80H,16H,55H
Task WORD 1234H,9ABCH
MOV DX, WORD PTR Mask ; (DX)← 8070H
MOV AL, BYTE PTR Task ; AL←34H
MOV BYTE PTR[BX], 10 ;
```

- distance is near or far

```
JMP FAR PTR begin
```

## 2.3 Directives

### SHORT Operator

```
SHORT label
```

- Sets the type of *label* to short. All jumps to *short label* must be a short jump (within the range −128 to +127 bytes from the jump instruction to *label*).

### EQU and = Operator

```
name EQU expression
name = expression
```

- EQU and = evaluates the numeric value of <expression> and assigns the resulting constant value to <name>.
- Unlike =, EQU does not allow numeric equates to be redefined.
- If <expression> cannot be evaluated, EQU treats <expression> as text.

## 2.4 Assembly Language Source Code

### Select Instruction Set

- .8086 using 8086 instruction set
- .286 using 80286 instruction set
- .286P using 80286 instruction set in protect mode
- .386 using 80386 instruction set
- .386P using 80386 instruction set in protect mode
- .486 using 80486 instruction set
- .486P using 80486 instruction set in protect mode
- .586 using Pentium instruction set
- .586P using Pentium instruction set
- .MMX using MMX instruction set
- .XMM using SSE instruction set
