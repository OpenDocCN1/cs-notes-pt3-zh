
## 1.4 Data Type

### Bit Field Data Type

- A bit field is a contiguous sequence of bits.
- It can begin at any bit position of any byte in memory and can contain up to 32 bits.

### String Data Types

- Strings are continuous sequences of bits, bytes, words, or doublewords.
- A bit string can begin at any bit position of any byte and can contain up to 2³²-1 bits.
- A byte string can contain bytes, words, or doublewords and can range from zero to 2³²-1 bytes (4 GBytes).

### BCD and Packed BCD Integers

- Binary-coded decimal integers (BCD integers) are unsigned 4-bit integers with valid values ranging from 0 to 9.

- When operating on BCD integers in general-purpose registers, the BCD values can be unpacked (one BCD digit per byte) or packed (two BCD digits per byte).

Unpacked BCD:

| Bits 7–4 | Bits 3–0 |
|----------|----------|
| 0000     | BCD      |

Packed BCD:

| Bits 7–4 | Bits 3–0 |
|----------|----------|
| BCD      | BCD      |

> e.g. Convert decimal integer 21 to BCD is 0000001000000001, packed BCD is 00100001

## 1.5 Basic Program Execution Registers

- 16 basic program execution registers for use in general system and application programming.
- These registers can be grouped as follows:
  - General-purpose registers
  - Segment registers
  - (E)FLAGS (program status and control) register
  - (E)IP (instruction pointer) register.

### General-Purpose Registers

- Operands for logical and arithmetic operations
- Operands for address calculations
- Memory pointers

| 32-bit | 16-bit | High byte | Low byte |
|--------|--------|-----------|----------|
| EAX | AX | AH | AL |
| EBX | BX | BH | BL |
| ECX | CX | CH | CL |
| EDX | DX | DH | DL |
| ESP | SP | — | — |
| EBP | BP | — | — |
| EDI | DI | — | — |
| ESI | SI | — | — |

- **EAX** — Accumulator for operands and results data
- **EBX** — Pointer to data in the DS segment (**Base Register**)
- **ECX** — Counter for string and loop operations
- **EDX** — I/O pointer

- The lower 16 bits of these 4 registers map directly to the register set and can be referenced with the names AX, BX, CX, and DX.
- Each of the lower two bytes of these 4 registers can be referenced by the names AH, BH, CH, and DH (high bytes) and AL, BL, CL, and DL (low bytes).

- **ESI** — Pointer to data in the segment pointed to by the DS register; source pointer for string operations (Index Register)
- **EDI** — Pointer to data (or destination) in the segment pointed to by the ES register; destination pointer for string operations (Index Register)
- **ESP** — Stack pointer (in the SS segment)
- **EBP** — Pointer to data on the stack (in the SS segment) (Base Register)

- The lower 16 bits of these 4 registers map directly to the register set and can be referenced with the names SI, DI, SP, and BP.

### Segment Registers

The segment registers hold 16-bit segment selectors. A segment selector is a special pointer that identifies a segment in memory.

- CS — points to the code segment
- SS — points to the stack segment
- DS — points to the data segment
- ES — points to the data segment
- FS, GS — point to the data segment
  - FS and GS are not used in 16-bit assembler
