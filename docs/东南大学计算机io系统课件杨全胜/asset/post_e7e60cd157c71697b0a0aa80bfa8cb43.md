
## 5.2 Structure and pins of 8254
### Operation and Command
### Control Word Format

| D7 | D6 | D5 | D4 | D3 | D2 | D1 | D0 |
| SC1 | SC0 | RW1 | RW0 | M2 | M1 | M0 | BCD |

SC — Select Counter:

| SC1 | SC0 |  |
| 0 | 0 | Select Counter 0 |
| 0 | 1 | Select Counter 1 |
| 1 | 0 | Select Counter 2 |
| 1 | 1 | Read-Back Command (See Read Operations) |

RW — Read/Write:

| RW1 | RW0 |  |
| 0 | 0 | Counter Latch Command (see Read Operations) |
| 0 | 1 | Read/Write least significant byte only. |
| 1 | 0 | Read/Write most significant byte only. |
| 1 | 1 | Read/Write least significant byte first, then most significant byte. |

M — MODE:

| M2 | M1 | M0 |  |
| 0 | 0 | 0 | Mode 0 |
| 0 | 0 | 1 | Mode 1 |
| X | 1 | 0 | Mode 2 |
| X | 1 | 1 | Mode 3 |
| 1 | 0 | 0 | Mode 4 |
| 1 | 0 | 1 | Mode 5 |

BCD:

|  |  |
| 0 | Binary Counter 16-bits |
| 1 | Binary Coded Decimal (BCD) Counter (4 Decades) |

```
e.g.: MOV AL, 01110100B ; T/C1, least significant byte first
OUT 43H, AL ; mode 2, Binary
```

### Initial count

The initial count for different counter must be write to different address.

| A1A0 | Timer/counter |
| 0 0 | T/C0 |
| 0 1 | T/C1 |
| 1 0 | T/C2 |

- Write one byte by each time

- The range of initial count is:

- Binary: 65536(0000H)、65535(FFFFH)~1(0001H)。

- BCD: 10000(0000H)、9999(9999H)~1(0001H)。

### Initial the Timer/count

- 1) For each Counter, the Control Word must be written before the initial count is written.

- 2) The initial count must follow the count format specified in the Control Word

```
e.g. MOV AL, 01110101B; T/C1, least significant byte first, mode 2, BCD
OUT 43H, AL
MOV AX, 2000H ; initial count = 2000
OUT 41H, AL ;
MOV AL, AH
OUT 41H, AL ;
MOV AL, 00010110B; T/C0, least significant byte only, mode3, Binary
OUT 43H, AL
MOV AL, 50H ; ; initial count = 50H (80)
OUT 40H, AL
```

### Method of read data from T/C

Counter Latch Command (A1A0=11)

- CHB: D7D6=00~01, D5D4=00

e.g.:

```
MOV   AL, 01000101B  ; T/C1, latch, least significant
                         ; byte first, mode2, BCD
OUT   43H, AL
IN    AL, 41H
MOV   AH, AL
IN    AL, 41H
XCHG  AH, AL  ; AX is initial count for T/C1
```

- Method of read data from T/C

- Read current data by Read-Back Command (A1A0=11)

| D7 | D6 | D5 | D4 | D3 | D2 | D1 | D0 |
|---|---|---|---|---|---|---|---|
| 1 | 1 | COUNT | STATUS | CNT 2 | CNT 1 | CNT 0 | 0 |

D5: 0 = Latch count of selected counter(s)

D4: 0 = Latch status of selected counter(s)

D3: 1 = Select counter 2

D2: 1 = Select counter 1

D1: 1 = Select counter 0

D0: Reserved for future expansion; must be 0

- Count latch command can only latch one counter

- Read-back command can latch multiple counter at the same time

```
e.g.: MOV AL, 11010100B    ; T/C1
OUT 43H, AL
IN  AL, 41H;
MOV AH, AL
IN  AL, 41H
XCHG AH, AL            ; AX is current count of CT1
MOV AL, 11011010B       ; T/C0 and T/C2
OUT 43H, AL
IN  AL, 40H;
MOV AH, AL
IN  AL, 40H
XCHG AH, AL            ; AX is current count of CT0
MOV BX, AX             ;
IN  AL, 42H;
MOV AH, AL
IN  AL, 42H
XCHG AH, AL            ; AX is current count of CT2
```

- Method of read data from T/C

- Read state by Read-Back Command(A1A0=11)

- Status word

| D7 | D6 | D5 | D4 | D3 | D2 | D1 | D0 |
|---|---|---|---|---|---|---|---|
| OUTPUT | NULL COUNT | RW1 | RW0 | M2 | M1 | M0 | BCD |

D7 1 = Out Pin is 1
0 = Out Pin is 0
D6 1 = Null count
0 = Count available for reading
D5-D0 Counter Programmed Mode

```
MOV AL, 11100100B ; T/C1, latch the state
OUT 43H, AL
```

```
IN AL, 41H ; Suppose AL=00110101, means T/C1 in mode 2 ; BCD, least significant byte first, out pin = 0
```

```
MOV AL, 11100010B ; T/C0, latch the state
OUT 43H, AL
```

```
IN AL, 40 ; if AL=00010110, means T/C0 in mode 3, Binary ; least significant byte only, out pin = 0
```
