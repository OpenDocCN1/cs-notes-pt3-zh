### 3.1 I/O Module

#### What is I/O module

- The computer’s I/O modules is its interface to the outside world.
- Each module interfaces to the system bus or central switch and control one or more peripheral devices.
- The I/O module contains logic for performing a communication function between the peripheral and bus.

![](img/d7c975450dfbe59120092c2721be78c6_290_0.png)

### 3.1 I/O Module

▪ Why one does not connect peripherals directly to the system bus? (Why an I/O module is needed?)

- There are a wide variety of peripherals with various methods of operation.
- The data transfer rate of peripherals is often much slower than that of the memory or processor.
- On the other hand, the data transfer rate of some peripherals is faster than that of the memory or processor.
- Peripherals often use different data format and word lengths than the computer to which they are attached.

### 3.1 I/O Module

#### I/O module Function

- **Control and timing**
  - To coordinate the flow of traffic between the system BUS and peripherals.
- **Processor communication**
  - **Command decoding.** Accepts commands on control bus from the processor and decode them.
  - **Data transfer.** Exchange the data between the processor and I/O module.
  - **Status reporting.** Transfer the status of the I/O module and peripherals to the system bus.
  - **Address recognition.** I/O module must recognize one unique address for each peripheral it controls.

### 3.1 I/O Module

#### I/O module Function

- Device communication

- Control signals. Determine the function that the device will perform, such as:

  - Send data to the peripheral.(OUTPUT)
  - Accept data from the peripheral.(INPUT)
  - Device report status, or I/O module perform some control function particular to the device.

- Data transfer. In the form of a set of bits to be sent or received from the peripheral.

- Status signals. Indicate the state of the device.

- Data buffering

  - The data is buffered(by latch) in the I/O module and then send to device at its rate.

- Error detection and reports error to the processor

### 3.2 Principal I/O techniques

- Programmed I/O
  1. When the processor is executing a program and encounters an instruction relating to I/O, it executes that instruction by issuing a command to the appropriate I/O module.
  2. With programmed I/O, the I/O module will perform the requested action.
  3. Then there are 2 different ways:
     - Unconditional transfer
       - we suppose the device is always ready.
       - Processor do not care the status of I/O module
     - Conditional transfer
       - After perform the action, I/O module set the appropriate bits in the I/O status register.
       - Processor periodically to check the status in I/O module until finds that the operation is complete
