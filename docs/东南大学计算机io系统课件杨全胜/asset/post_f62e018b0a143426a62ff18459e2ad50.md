
## 2.6.5 Loop Instructions

- Loop Instructions

```
LOOP       LABEL     : LOOP
LOOPZ/LOOPE LABEL     : Condition LOOP
LOOPNZ/LOOPNE LABEL    : Condition LOOP
```

| Assembly | Operation | function |
|---|---|---|
| **LOOP** | (E)CX <-- (E)CX - 1<br>if ((E)CX) <> 0, then loop | loop until (E)CX=0 |
| **LOOPZ**<br>**LOOPE** | (E)CX <-- (E)CX - 1<br>if ((E)CX) <> 0 and ZF=1, then loop | loop until (E)CX=0<br>or not equal |
| **LOOPNZ**<br>**LOOPNE** | (E)CX <-- (E)CX - 1<br>if ((E)CX) <> 0 and ZF=0, then loop | loop until (E)CX=0<br>or equal |

### Loop Instructions

**Example1:**
Calculate the sum of all elements in byte array which has 10 elements, save the result into TOTAL

```
LEA SI, ARRAY       ; base address of array → SI
MOV CX, 10          ; Length of array → CX
MOV AX, 0
AGAIN: ADD AL, [SI] ; calculate sum
      ADC AH, 0
      INC SI         ; modify the pointer
      LOOP AGAIN
      MOV TOTAL, AX   ; save the result
```

### The basic of string Instruction

- The follow instructions allow data process either a single byte, word or double word, or if repeated, a block of bytes, words or double words.
- LODS, STOS, MOVS, INS, OUTS, SCAS, CMPS

- All the instruction has 3 styles with suffix B, W or D for byte, word or double word operation.
- LODSB, LODSW, LODSD
- STOSB, STOSW, STOSD
- MOVSB, MOVSW, MOVSD
- INSB, INSW, INSD
- OUTSB, OUTSW, OUTSD
- SCASB, SCASW, SCASD
- CMPSB, CMPSW, CMPSD

### The basic of string Instruction

Automatically change (E)SI & (E)DI

Although each string instruction operates on only one string element at a time, it always gets ready to operate on the next element. This is done by changing the register (E)SI & (E)DI.

DF (located in flag register) determine the direction

- **DF=0** (CLD instruction clear it)
  - (E)DI&(E)SI will be incremented by 1(byte), 2(word), 4(double word)

- **DF=1** (STD instruction set it)
  - (E)DI&(E)SI will be decremented by 1(byte), 2(word), 4(double word)

### LODS Instruction

Loads AL, AX or EAX with data stored at the data segment offset address indexed by the (E)SI register.

| Assemble Language | Operation |
| LODSB | AL=DS:[SI]; if (DF=0) SI=SI+1 else SI=SI-1 |
| LODSW | AX=DS:[SI]; if (DF=0) SI=SI+2 else SI=SI-2 |
| LODSD | EAX=DS:[SI]; if (DF=0) SI=SI+4 else SI=SI-4 |
