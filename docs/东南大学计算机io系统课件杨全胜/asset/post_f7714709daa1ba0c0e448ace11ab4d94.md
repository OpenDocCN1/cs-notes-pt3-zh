
## 2.3 Directives
### Data Define
### Syntax

```
[name] type initializer [, initializer]...
```

- **Name:** Symbol name assigned to the variable. If no name is assigned, the memory space is allocated, but the starting address of the variable has no symbolic name.
- **Initializer:** A type shown in the table on page 11, constant integer expression, `?`, or `DUP` expression. Separate multiple values with commas or use the `DUP` operator.

These directives allocate and optionally initialize one or more bytes of global data.

The abbreviations (such as DB, DW, DD) are limited forms of the data-declaration directives; they cannot be used as types. They are included for compatibility with previous versions of the assembler (just like MASM 5.0).

String initializes, available with the BYTE directive, allocate a byte for each character of the string. The characters are stored with the leftmost character in the lowest memory location

### Data define
### Declaring Integer Variables

Allocating Memory and initialize for Integer Variables

```
X1    BYTE    16          ; Initialize byte to 16
S2    SBYTE   -16         ; Initialize signed byte to -16
X3    WORD    4*3         ; Initialize word to 12
S4    SWORD   4*5         ; Initialize signed word to 20
X5    DWORD   ?           ; Allocate uninitialized int
LT    DWORD   4294967295  ; Initialize double word (int) to
                         ; 4,294,967,295
QX    QWORD   ?           ; Allocate uninitialized long
         BYTE 1, 2, 3, 4, 5, 6 ; Initialize 6 unnamed bytes
X7    TBYTE (120+50)/10   ; Initialize 10-byte binary
                         ; number 17
```

### Data define
### Declaring and Referencing Arrays

- Array elements occupy memory contiguously, so a program references each element relative to the start of the array.
- To declare an array, supply a label name, the element type, and a series of initializing values or ? placeholders.

```
warray WORD 1, 2, 3, 4
xarray DWORD 0FFFFFFFFh, 789ABCDEh
var1 BYTE 10, 20, 30
    BYTE 40, 50, 60
    BYTE 70, 80, 90
sarray WORD ?, 40, ?
```

### Data define
### Declaring and Referencing Arrays
### The DUP Operator

```
count DUP (initializer [, initializer]...)
```

- You can also declare an array with the DUP operator.
- The **count** value sets the number of times to repeat all values within the parentheses.
- The initialvalue can be an *integer*, *character constant*, or *another DUP operator*, and must always appear within parentheses.

```
VAR1 WORD 2 DUP(2, 4), 1476H
```

```
VAR2 BYTE 2 DUP(? , 2 DUP('A', 'B'))
```

### Data define
### Declaring and Referencing Arrays
### LENGTHOF, SIZEOF, and TYPE for Arrays

```
array WORD 40 DUP (5)
larray EQU LENGTHOF array ; 40 elements
sarray EQU SIZEOF array      ; 80 bytes
tarray EQU TYPE array        ; 2 bytes per element
num DWORD 4, 5, 6, 7, 8, 9, 10, 11
lnum EQU LENGTHOF num        ; 8 elements
snum EQU SIZEOF num          ; 32 bytes
t num EQU TYPE num           ; 4 bytes per element
warray WORD 40 DUP (40 DUP (5))
len EQU LENGTHOF warray      ; 1600 elements
siz EQU SIZEOF warray        ; 3200 bytes
typ EQU TYPE warray          ; 2 bytes per element
```

### Data define
### Declaring and Initializing Strings

- A string is an array of characters.
- Initializing a string like "Hello, there" allocates and initializes 1 byte for each character in the string.
- An initialized string can be no longer than 255 characters.
- Strings must be enclosed in single (') or double (") quotation marks.
