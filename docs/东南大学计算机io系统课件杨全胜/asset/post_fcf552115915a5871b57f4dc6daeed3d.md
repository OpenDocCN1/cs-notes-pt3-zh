
## 7.1 Serial Communication

### Baud Rate

The number of information bits that can be transmitted in one second (bit/s or bps), also known as the data bit rate. It is an important indicator to measure the rate of serial communication.

### Receiver/sender clock

- Directly determine the rate of data transmission on line.
- It is usually the 1, 16, 32 or 64 times baud rate.
- For asynchronous communication, it is 16 times baud rate

## 7.2 Asynchronous serial communication

### Asynchronous serial communication

- Asynchronous serial communication describes an asynchronous, serial transmission protocol in which a start signal is sent prior to each byte, character or code word and a stop signal is sent after each code word.
- Data transmitted and received without a clock or timing signal.

## 7.2 Asynchronous serial communication

### Exercise

Asynchronous serial data is 7-bit ASCII code, If you need a data transfer rate of 240 characters per sec, 1 bit parity and 1 bit stop is used, then:

- 1) What is baud rate?
- 2) How many data bits are valid in one second?
- 3) How about the transmit efficiency?

- 1) Baud rate is
  (7-bit data+1 bit start+1 bit parity+1 bit stop)×240
  =2400b/s

- 2) Valid data bits in one second is 7×240=1680 bits

- 3) Transmit efficiency is 1680/2400=70%

## 7.3 RS-232 Standard

- RS-232 (Recommended Standard 232)
  - In telecommunications, RS-232 is the traditional name for a series of standards for serial binary single-ended data and control signals connecting between a DTE and a DCE. It is commonly used in computer serial ports.
  - DTE-Data Terminal Equipment
  - DCE- Data Communication Equipment
  - Some RS-232 devices are still found especially in industrial machines or scientific instruments.
  - Many modern personal computers have no RS-232 ports and must use an external converter to connect to older peripherals.

## 7.3 RS-232 Standard

### Electrical signal characteristics

### Voltage levels

- Valid signals are ±3 ~15 volts
- For data transmission lines
  - Logic one is defined as a negative voltage (-3V~ -15V), the signal condition is called marking.
  - Logic zero is positive (+3V~+15V) and the signal condition is termed spacing.
- For Control signals
  - When one of these signals is active, the voltage on the line will be between +3 to +15 volts.
  - The inactive state for these signals is the opposite voltage condition, between -3 and -15 volts.
