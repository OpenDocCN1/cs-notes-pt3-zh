

## 2.6.3 逻辑指令

### 移位和旋转指令

◆ 旋转指令

```
OP DST, CNT: OP is ROL, RCL, ROR, RCR
```

- **OP is**
  - `ROL` - DST 左旋转 CNT 次
  - `RCL` - DST 通过 CF 左旋转 CNT 次
  - `ROR` - DST 右旋转 CNT 次
  - `RCR` - DST 通过 CF 右旋转 CNT 次

- **DST is** 一个寄存器或内存中的数据

- **CNT is**
  - `1`
  - `CL`
  - `Imm8 (80386 或以上仅限)`

### 旋转指令

将 AL 的 LSb 发送到 BL 的 LSb，保持 AL 不变。

```
ror bl,1
ror al,1
rcl bl,1
rol al,1
```

### 仅影响 OF 和 CF

- 移出的最后一位进入 CF
- OF 标志仅对 1 位旋转有定义；如果符号改变，则 OF=1

### 示例

将 ASCII 字符串 ‘96’ 转换为压缩 BCD 96H

```
MOV AL, ASC        ; AL<--39H (‘9’)

MOV BCD, BL
```

### 无条件跳转 (JMP)

### 短跳转

```
JMP SHORT OPR
```

- 当前段内的相对短跳转
- 新地址为
  - (E)IP=(E)IP+8 位位移
    - 位移是一个一字节有符号数，其值范围在 +127~-128 之间
- 我们可以使用标签（内存地址的符号名）与短跳转指令一起使用

### 无条件跳转 (JMP)

### 近跳转

```
JMP OPR
```

- 当前段内的相对近跳转
- 在实模式下
  - (E)IP=(E)IP+16 位位移
    - 位移是一个 2 字节有符号数，其值范围在 +32767~-32768 之间
- 在 80386 或以上处理器的保护模式下
  - EIP=EIP+32 位位移
    - 位移是一个 4 字节有符号数，其值范围在 +2G~-2G 之间
- 我们也可以使用标签。

### 无条件跳转 (JMP)

◆ 远跳转

```
JMP FAR PTR OPR
```

- 获取新的段和偏移地址以完成跳转

- 新地址为
  - (E)IP = 该 5 字节指令的第 2 和第 3 字节
  - CS = 该 5 字节指令的第 4 和第 5 字节
  - 在 80286 或以上处理器的保护模式下
    - EIP 可能为 32 位

我们也可以使用标签。
