

## 2.6.3 逻辑指令
### AND 示例

```
MOV AL, 32H
AND AL, 0FH        ; clear the high 4 bits in AL
```

|        | AL       |
|--------|----------|
| 执行前 | 00110010 |
| 执行后  | 00000010 |

### OR 示例

```
MOV AL, 02H
OR  AL, 0F0H       ; set the high 4 bits in AL
```

|        | AL       |
|--------|----------|
| 执行前 | 00000010 |
| 执行后  | 11110010 |

### XOR 示例

| 指令 | 值      |
|-------------|------------|
| MOV AL, 0B6H | 1011 0110 |
| XOR AL, 0FH  | 0000 1111 |
| 结果       | 1011 1001 |

无变化    取反

## 2.6.3 逻辑指令
### 基本逻辑指令

```
TEST OPR1, OPR2 ; (OPR1) & (OPR2)
```

- 与 AND 指令相同但不改变目的操作数
- AND、OR、XOR、TEST 会影响标志寄存器。
  - CF=0
  - OF=0
  - AF: 未定义
  - PF、SF、ZF: 由结果的值设置。

> **下面指令是什么意思？**
> 
> **AND AX,AX;** 清除标志寄存器中的 CF 和 OF
> 
> **XOR AX,AX;** AX=0, CF=0 且 OF=0

## 2.6.3 逻辑指令
### TEST 示例

判断 (AL) 是否为奇数，如果为真则跳转

```
TEST AL, 01H
JNZ NEXT        ; ZF=0, jump
```

### TEST 示例2

判断 (AX) 是否为正数，如果为真则跳转

```
TEST AX, 8000H
JZ THERE        ; ZF=1转
```

NOT DST : 非操作

- 求补，逻辑反转。
- 真值表
- NOT r/m8/16/32

| A | T |
|---|---|

```
MOV AL, 52H
NOT AL
before  AL  01010010
after   AL  10101101
```

```
MOV AL, 1 ; 1-->AL
NOT AL ; 求反
INC AL ;
```

## 2.6.3 逻辑指令
### 移位和循环指令

- 移位和循环指令在二进制位级别上操作二进制数，与 AND、OR、异或和 NOT 指令相同。
- 移位和循环在用于控制 I/O 设备的底层软件中最常见。
- 微处理器包含一套完整的移位和循环指令，用于移位或循环任何内存数据或寄存器。

### ◆ 移位指令

假设 (AL)=0B4H, (CF)=1，分析执行后的结果

| 指令 | CF | AL |
|---|---:|---|
| 执行前 | 1 | 10110100 |
| (1) SAL AL, 1 | 1 | 01101000 |
| (2) SHL AL, 1 | 1 | 01101000 |
| (3) SAR AL, 1 | 0 | 11011010 |

左移的结果都相同。
两种算术右移得到不同的结果。

## 2.6.3 逻辑指令
### 移位和循环指令

- 移位指令会改变标志：
  - CF: 由移出的位改变
  - OF:
    - 多位移位：未定义
    - 单位移位
      - 0: 如果结果的符号位与原始操作数字符号位相同。
      - 1: 它们不同
  - ZF、PF: 根据结果赋值
  - AF: 未设计
