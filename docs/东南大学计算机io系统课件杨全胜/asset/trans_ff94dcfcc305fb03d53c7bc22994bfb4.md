

## 1.6.1 操作数寻址方式
### 存储器操作数寻址
+ 指定偏移量

将位移量、基址、变址和比例因子相加得到的偏移量称为有效地址（EA）。

```
EA=Base + ( Index*Scale factor ) + Displacement
```

| 组成 | 16 位偏移量 | 32 位偏移量 |
|---|---|---|
| 位移量 | 0、8、16 位 | 0、8、32 位 |
| 基址寄存器 | BX、BP | 任意 32 位通用寄存器 |
| 变址寄存器 | SI、DI | 除 ESP 外的 32 位通用寄存器 |
| 比例因子 | 不使用 | 1、2、4、8 |
