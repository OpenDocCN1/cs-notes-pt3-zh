# C（控制字段）：S（监控帧）

| 帧类型 | 0 | 1 | 2 | 3 | 4 | 5 | 6 | 7 |
|---|---|---|---|---|---|---|---|---|
| 信息帧（I） | 0 | Ns |  |  | P/F | Nr |  |  |
| 监控帧（S） | 1 | 0 | Type |  | P/F | Nr |  |  |
| 无编号帧（U） | 1 | 1 | M1 |  | P/F | M2 |  |  |

S（监控帧）：用于表示接收状态，

+   1. **Type=00，接收准备就绪（RR）**，准备接收编号为 Nr 的帧；
+   2. **Type=10，未准备就绪（RNR）**，告诉对方已经收妥 Nr 以前的所有帧，但希望对方暂缓发送 Nr 帧；
+   3. **Type=01，拒绝接收（REJ）**，告诉对方已经收妥 Nr 以前的所有帧，但编号为 Nr 的帧有差错，希望对方重发编号为 Nr 及其以后的所有帧；
+   4. **Type=11，选择接收（SREJ）**，类似 REJ 监控帧，但希望对方仅重发第 Nr 帧。
