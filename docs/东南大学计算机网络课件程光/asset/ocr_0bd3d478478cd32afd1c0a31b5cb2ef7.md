# 传输媒体

★ 光纤（光缆）：具有误码率低、频带宽、绝缘性能高、抗干扰能力强，体积小和重量轻的特点。

+   - 单模光纤：支持激光传输，距离可达100公里；
+   - 多模光纤：支持荧光传输，距离一般在2公里以内。

实验传输速率可达50Tbps，实用速率已达10Gbps。
