# 如何充分利用通信信道？

+   - **多路复用技术：** 静态分配信道
+     - 频分多路复用（不同频段对应不同路信号）；
+     - 时分多路复用（不同时间片对应不同路信号）；
+     - 波分多路复用（不同波长对应不同路信号），光纤信道；
+   - **集中传输技术：** 动态分配信道
+     - 频段/时间片/波长动态分配给需要的用户对，进一步提升信道利用率。
+     - 要求附加信息以便区分不同路的信号；
+     - 要求缓存能力以防多用户数据超载时的数据丢失；
