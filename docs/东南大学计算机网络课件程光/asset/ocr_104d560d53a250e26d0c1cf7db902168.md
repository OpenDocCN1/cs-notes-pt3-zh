# （2）DIX规范

V2.0—以太网：数据链路层和物理层规范。

描述方法：速率，传输技术，最大段长；

相关标准：10Base5和10Base2。

基本指标：

10Base5：粗缆，10Mbps，基带，单段线缆<500米，5段，DIX接口；

10Base2：细缆，10Mbps，基带，单段线缆<200米，5段，BNC接口；

同时的基本长度换算公式：1米细缆=3米粗缆
