# OSI/RM的物理映射

OSI/RM从理论上规范了计算机网络实现的方法。

具体实现： 3/1/3（低3层/第4层/高3层）结构

OSI/RM的低3层： 主要提供信息传输服务，保证一个站点发出的信息可以通过一系列中间结点的合作传输到另一个站点。

实现时一般加载到一个独立的硬件设备（结点机、路由器等）（通信子网）
