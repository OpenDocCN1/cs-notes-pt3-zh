# # 光纤分布数字接口(FDDI)

# ## FDDI的特点：

+   1. FDDI双环的拓扑

+   2. 多帧传输：获得令牌的结点，在发完数据帧之后，立即释放令牌，任一时刻，环中允许有多个数据帧被传输。多帧传输，可以提高网络带宽的利用率。

+   3. 传输编码：FDDI采用4b/5b编码和不归0交替编码，可以以125MHz的时钟频率获得100Mbps的数据带宽，既降低成本，又提高速率。

+   4. 长距离通信：主要传输媒体为光纤，多模光纤可达2km，单模光纤可达100km

+   5. 高可靠性：FDDI除采用双环结构外，还采用双归宿冗余设计（即每个设备可以挂接到两个环路结点上），提高网络的可靠性；
