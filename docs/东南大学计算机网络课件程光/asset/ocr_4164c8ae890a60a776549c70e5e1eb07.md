# 关于地址映射（物理地址→IP地址）

——RARP（反向地址解析协议）使只知道自己硬件地址的主机能够知道其IP地址）

# 1、无盘工作站：

+   - 网卡上增加了特殊的ROM模块
+   - 服务器引导（BOOTP），其IP地址保留在服务器上。
+   - 当主机加电时，ROM模块中驻留的软件（以广播的方式）发出携带本结点物理地址的RARP请求，
+   - 服务器给予响应，返回该结点的IP地址，保存在内存中。
