# C（控制字段）：用于区分帧的类型

| 帧类型 | 0 | 1 | 2 | 3 | 4 | 5 | 6 | 7 |
|---|---|---|---|---|---|---|---|---|
| 信息帧（I） | 0 |  | Ns |  | P/F | Nr |  |  |
| 监控帧（S） | 1 | 0 | Type |  | P/F | Nr |  |  |
| 无编号帧（U） | 1 | 1 | M1 |  | P/F | M2 |  |  |

信息帧（I帧），C的第一位为“0”

用于传输用户数据

允许双向同时发送和接收数据

Ns（发送帧序号）说明本帧对应的帧序号（采用模8计数），每发一帧，Ns模8计数一次；

Nr（待收帧序号）：希望接收对方帧的序号，（采用模8计数）；

Nr隐含指示该序号之前的所有帧已被正确接收；
