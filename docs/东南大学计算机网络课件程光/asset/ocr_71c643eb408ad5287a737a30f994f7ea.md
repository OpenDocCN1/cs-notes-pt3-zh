| S-CON. req | —→ | S-CON. ind; | 会话连接（包括选择功能 |

| S-ACT_START. req | —→ | S-ACT_START. ind ; | 活动开始 |
| S-DATA. req | —> | S-DATA. ind | ；传输一块数据 |
| S-SYNC-MINOR. req | —→ | S-SYNC-MINOR. ind; | 检验数据完整性 |
| S-SYNC-MINOR. cnf | ←— | S-SYNC-MINOR. rsp | （同步点） |
| S-DATA. req | —→ | S-DATA. ind | ；传输一块数据 |
| S-SYNC-MINOR. req | —→ | S-SYNC-MINOR. ind; | 检验数据完整性 |
