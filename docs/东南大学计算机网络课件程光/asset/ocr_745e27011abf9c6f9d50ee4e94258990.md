# ATM接口和信元格式：

接口方式： 用户端 — UNI — 交换机 — NNI — 交换机 — UNI — 用户端

# ATM信元格式：

| 接口 | B1 | B2 | B3 | B4 | B5 |
|---|---|---|---|---|---|
| UNI | GFC | VPI | VCI |  | HEC |
| NNI |  | VPI（虚拟路径标识） | VCI（虚拟通道标识） |  | HEC |

GFC：常规流量控制
