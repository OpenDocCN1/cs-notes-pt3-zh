# 准同步数字体系（PDH）

目的：将一“群”用户的信息复用到一条线路上传输，

基群（基本的群）速率：最基本的复用速率

逐级复用的技术

|  | 基群 | 二次群 | 三次群 | 四次群 |
|---|---|---|---|---|
| 欧洲，中国 | 2.048Mbps/E1 | 8.848Mbps/E2 | 34.304Mbps/E3 | 138.264M |
| （复用话路） | 32路 | 4×E1=128路 | 4×E2=512路 | 4×E3=2048路 |
| 北美 | 1.544Mbps/T1 | 6.312Mbps/T2 | 44.736Mbps/T3 | 274.716Mb |
| （复用话路） | 24路 | 4×T1=96路 | 6×T2=576路 | 7×T3=4032路 |
| 日本 | 1.544Mbps/T1 | 6.312Mbps/T2 | 32.064Mbps/T3 | 97.728Mbps |
| （复用话路） | 24路 | 4×T1=96路 | 4×T2=384路 | 3×T3=1152路 |
