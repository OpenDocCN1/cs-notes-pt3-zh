# 用户点击鼠标后所发生的事件

+   1. 浏览器分析超链指向页面的 URL。
+   2. 浏览器向 DNS 请求解析 www.tsinghua.edu.cn 的 IP 地址。
+   3. 域名系统 DNS 解析出清华大学服务器的 IP 地址。
+   4. 浏览器与服务器建立 TCP 连接。
+   5. 浏览器发出取文件命令：
+      `GET /chn/yxsz/index.htm`。
+   6. 服务器给出响应，把文件 index.htm 发给浏览器。
+   7. TCP 连接释放。
+   8. 浏览器显示“清华大学院系设置”文件 index.htm 中的所有文本。
