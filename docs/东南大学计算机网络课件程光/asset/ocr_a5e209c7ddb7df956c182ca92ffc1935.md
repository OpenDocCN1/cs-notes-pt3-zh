# 摘要技术—也称散列技术

原理：对报文进行某种运算，形成与报文密切相关、且长度有限的摘要值，有时也称为报文的指纹（Fingerprint）;

要求：不同内容的报文形成相同摘要值的概率几乎为零；
根据摘要值无法还原原报文；

典型的摘要算法：

CRC校验算法—利用该算法可检测传输过程中产生的差错；
采用不同的产生式可以形成特定长度的校验和；

+   报文摘要算法（MD2）—RFC1319，产生128位的摘要值；
+   报文摘要算法（MD4）—RFC1320，产生128位的摘要值；
+   报文摘要算法（MD5）—RFC1321，产生128位的摘要值；
+   完全散列算法（SHA-1）—RFC2202
+   产生160位的摘要值，1997年9月。

摘要技术可用于提供网络安全中的内容完整性服务。
