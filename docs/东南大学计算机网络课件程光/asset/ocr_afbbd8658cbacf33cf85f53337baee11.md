# ★ 工作过程（发送）

```
高层有数据发送（LLC）
↓
封装MAC帧
↓
侦听媒体
↓
媒体上有无数据在传输？
├─ 有 → 按策略退避 → 退避时间是否到？
│       ├─ 未到 → 继续等待
│       └─ 已到 → 退避次数是否超过？
│                 ├─ 未超过 → 继续侦听媒体
│                 └─ 已超过 → 通知LLC网络太忙
└─ 无 → 等待9.6us仍空闲？
        ├─ 否 → 继续侦听媒体
        └─ 是 → 发送数据
                ↓
             发送数据是否冲突？
             ├─ 冲突 → 强化冲突 → 返回侦听媒体
             └─ 无冲突 → 等待Ack
                         ├─ 超时 → 超时2次？
                         │         ├─ 否 → 重新发送数据
                         │         └─ 是 → 发送失败
                         └─ 收到Ack → 发送成功
```
