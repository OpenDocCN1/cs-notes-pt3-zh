# 二进制指数退避算法：

退避时间计算：信号在媒体上的往返时间 * 随机数；

随机数(r)的取值范围依赖于冲突的次数(i)； 0≤r<2^i

思路：错开等待时间，使之随失败次数增多而增加。

| 冲突次数 | 随机数（r）取值范围 |
|---|---|
| 第1次： 0, 1 （2^1-1） | |
| 第2次： 0, 1, 2, 3 （2^2-1） | |
| 第3次： 0, 1.....7 （2^3-1） | |
| ... | |
| 第i次： 0, 1, ......, 2^i-1 | |

第10次冲突后，等待时间随失败次数增多而增加，将时间错开。

第16次后，向上层报错。
