# 网桥实例—以太网交换器（交换式集线器）

简化的网桥，用于以太网的互连。由于网络的网络具有相同的协议，交换机无需进行协议转换，延迟小，交换速度快。

+   **特点：**
+   1. 支持少量的存储能力（缓冲）、
+   2. 少量的地址表（提高查表速度）
+   3. 处理相同的帧格式（相同类型的网络互连）。
+   4. 具有分割子网的功能，
+   5. 每个端口独享指定的带宽。
+   6. 支持多个独立的数据流，具有较多的吞吐量
+   7. 硬件交换，交换速度快。

一般的网桥：同一时刻只有一对端口通信
　　　　　　　通过软件实现协议转换
交换器：同一时刻可有多对端口在通信
