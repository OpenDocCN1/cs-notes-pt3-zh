# # 网络管理的体系结构

系统管理应用进程（SMAP）：负责管理整个系统的资源，并提供控制和监测的能力。

**两类实体：**
- **管理员：**负责对整个网络的资源进行管理。
- **代理：**则驻留在被管对象上，响应管理员的指令。
管理员和代理之间遵循公共管理信息协议（CMIP）。
