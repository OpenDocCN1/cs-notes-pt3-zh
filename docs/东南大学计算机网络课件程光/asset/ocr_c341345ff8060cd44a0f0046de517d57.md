# 人机交互和机/媒体匹配：

字符编码、图文编码等（如ASCII码），以便人机交互；

# ASCII码（美国信息交换标准码）：

7单位编码，b₆b₅b₄b₃b₂b₁（简记X/Y）；

+   - 图形字符：数字、字母、运算符号、语句符号等
+   - 控制字符：传输控制、格式控制、信息分隔字符等。

![](bbox=[0.237, 0.444, 0.708, 0.633])

通信编码：特定电平信号表示数字信号，数字信号在端口的体现；

| RS232编码、不归0交替编码 | 曼彻斯特编码、4b/5b编码 |
|---|---|
| 无同步信息，易产生累计误差； | 含同步信号，可避免累计误差； |
| 不适合批量数据的传输 | 适合批量数据的传输； |
| （原因：发收脉冲无法精确同步） | （原因：根据同步信号调整接收脉冲） |
