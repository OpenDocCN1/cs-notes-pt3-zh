# LAN的相关标准：

+   - IEEE 802.1A--综述和体系结构；
+   - IEEE 802.1B—寻址、网络管理和网络互连；
+   - IEEE 802.2---逻辑链路控制协议（LLC）；
+   - IEEE 802.3---载波侦听多路访问/冲突检测（CSMA/CD）访问控制方法和物理层规范；
+   - IEEE 802.4---令牌总线访问控制方法和物理层规范；
+   - IEEE 802.5---令牌环访问控制方法和物理层规范；
+   - IEEE 802.6---城域网（双队列双总线）
+   - IEEE 802.9---等时网（Isochronous LAN）
+   - IEEE 802.11—无线LAN
+   - IEEE 802.15—个人域网（PAN，蓝牙）
+   - …… ……

802.3 之后的标准均含物理层和媒体访问控制层（MAC）的内容。
