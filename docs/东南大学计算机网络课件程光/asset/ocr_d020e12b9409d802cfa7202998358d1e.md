# ★ 因特网域名的取值

因特网定义了域名的格式和主要域名的取值，\n任何组织均可根据域名语法构造本组织内部的域名。

**一级域名**（因特网规定了一些国际通用的域名）\n\n`.com`　`.edu`　`.gov`　`.mil`　`.net`　`.org`　`.int`\n国家名　`.cn`　`.ca`　`……`

**域名注册：**\nCNNIC——中国域名注册管理机构\n\n**www.cnnic.net.cn**

**结点主机：** 因特网上的计算机，\n**主机名.域名**（主机所在域）\nwww.seu.edu.cn

**因特网用户名：** 结点主机上的用户“帐号”\n用户名@结点主机\nyji@seu.edu.cn
