# # 专用IP地址

RFC1918定义的**专用IP地址**：

+   - `10.0.0.0 — 10.255.255.255`　　1个A类地址；
+   - `172.16.0.0 — 172.31.255.255`　　16个连续的B类地址；
+   - `192.168.0.0 — 192.168.255.255`　　256个连续的C类地址。

业界支持：**大多数路由器不转发携带本地IP地址的分组。**

软件学院教师：
　网络地址：`10.3.10.0`
　子网掩码：`255.255.252.0`
　默认网关：`10.3.10.1`

学生机房：
　网络地址：`10.3.0.0, 10.3.1.0, 10.3.2.0`
　子网掩码：`255.255.252.0`
