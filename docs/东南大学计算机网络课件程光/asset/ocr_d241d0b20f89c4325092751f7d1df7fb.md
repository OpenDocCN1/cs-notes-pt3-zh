# 江苏省计算机网络技术重点实验室

+   - 实验室现有科研人员（包括客座研究人员）29人，其中教授8人（博士生导师4人），副教授17人，讲师3人。实验室的主要研究方向包括网络安全、网络管理、网络测量与网络行为学、网络体系结构、信息安全、网络应用技术、网络工程实验等。
+   - 实验室从自建立以来共承担了20多项各类国家级课题，863、973、自然基金、教育部项目、CNGI等。
+   - 实验室现拥有机房和办公用房近600平方米，配备了各类工作站和网络服务器30多台，各类微机100多台。
+   - 实验室与烽火安网公司、华为-3Com公司、港湾公司等国内高科技企业建立起了良好的合作关系。
