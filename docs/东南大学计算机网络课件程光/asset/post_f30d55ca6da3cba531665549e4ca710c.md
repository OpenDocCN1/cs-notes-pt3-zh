
## 虚拟网络

### 在实际联网中为什么会使用VLAN？

- 1、减少因网络成员的变化所带来的开销
  - 减少因用户的增加、删除、移动等工作产生的隐含开销。
- 2、虚拟工作组
  - 某一部门或分支机构的成员可以在虚拟工作组模式下共享同一个“局域网”，把绝大多数的网络流量限制在VLAN广播域内部。
- 3、减少了路由器的使用
  - 支持虚拟网的交换机可以在没有路由器的情况下很好的控制广播流量。
  - 在VLAN中，从服务器到客户端的广播信息只会在连接本虚拟网客户机的交换机端口上被复制，而在其他端口上广播信息被终止。
  - 只有那些需要跨越虚拟网的数据包才会穿过路由器。在这种方式下交换机扮演了路由器的角色。
- 4、局域网的安全性

### 虚拟网络的划分

划分VLAN的方法主要有两种：静态和动态。

**静态：** VLAN由交换机本身的特征信息定义，通常包括插槽、端口或端口组等。

**动态：** VLAN通常由节点的某些特征信息定义，可以是节点的MAC地址、正在使用的协议、甚至是某些认证信息（如名字与口令等）。

三种常用的划分方法：

1. 根据端口划分VLAN（配置交换）
2. 根据MAC地址划分VLAN（帧交换）
3. 根据网络层定义划分VLAN

### 根据端口划分VLAN（配置交换）

利用交换机的端口划分VLAN成员，在一个交换机上进行虚网划分。

例：1、3、6、7端口：VLAN1，4端口：VLAN3，2、5、8端口：VLAN4。若100M交换机的上行端口为A，则在该交换机中的配置为：

```
set trunk A
set vlan 1 1,3,6,7
set vlan 3 4
set vlan 4 2,5,8
```

![](img/0761188ee01704e55ea71e6a97539d38_612_0.png)

允许跨越多个交换机的多个不同端口划分VLAN，不同交换机上的若干个端口可组成同一个虚拟网。

**特点：**

1. 配置过程简单。
2. 跨交换机的虚网交互通过路由器或三层交换机进行。
3. 用户从一个端口的虚网移到另一端口所在的虚网，需要进行重新设置。

![](img/0761188ee01704e55ea71e6a97539d38_613_0.png)

### 根据MAC地址划分VLAN（帧交换）

交换机根据节点的MAC地址，决定将其放置于哪个VLAN中。

MAC地址是捆绑在网络接口卡上的，这种VLAN的划分方法与连接到交换机上的设备有关，可以允许网络用户从一个物理位置移动到另一个物理位置上，并且自动保留其所属虚拟网段的成员身份。

该VLAN的划分方法独立于网络的高层协议（如TCP/IP、IP、IPX等）。

**缺点：** 所有的用户必须被明确的分配到一个VLAN中，网卡换了，必须修改虚网配置。

![](img/0761188ee01704e55ea71e6a97539d38_614_0.png)

### 根据网络层定义划分VLAN

交换机还可以根据使用的协议或网络层地址（如TCP/IP中的子网段地址）来确定网络成员（VLAN）的划分。

```
财务系统服务器、一卡通系统服务器
九龙湖校区财务办公室
四牌楼校区财务处
丁家桥校区财务办公室
校园网主干
202.119.2.0
```

**优点：**

1. 可以按传输协议划分网段；
2. 用户可以在子网内部自由移动而不用重新配置自己的工作站；
3. 可以减少由于协议转换而造成的网络延迟。

**缺点：**

基于网络层的虚拟网需要分析协议的地址格式并进行相应的转换，影响交换机的速度。

### VLAN之间的互连

VLAN与VLAN之间的互连需要通过路由器进行，或者具有三层交换功能（路由）的交换机进行。

- 交换机：
  - 普通交换机
  - 带虚网划分功能的交换机
  - 带三层交换功能的交换机
- 网络互连设备：
  - 转发器（集线器）
  - 网桥（二层交换机）
  - 路由器（三层交换）
  - 网关（Gateway）

### 网关（Gateway）

执行互连OSI运输层及其以上的各层协议的转换，或者实现不同体系结构的网络协议转换的互连设备。

![](img/0761188ee01704e55ea71e6a97539d38_618_0.png)

### 网关的应用

凡是在应用层协议不相同的两个网络系统的互连都需要使用网关。

- FTAM —— FTP
- MHS —— SMTP
- TCP/IP —— SPX/IPX
- WAP —— TCP/IP
- 银行的支付网关（跨行支付）银联

### 一般的企业网络

企业网通常采用层次结构，由主干网和分支网组成。

- 主干网辐射到各个部门，分支网连接部门内的各台计算机。
- 主干网通常采用高速以太网；分支网通常采用以太网等。
- 主要网络设备：
  - 网络适配器、共享式集线器（HUB）、交换器（Switch）、路由器（Router）

### 企业组网的一般方式

- 小规模企业（几十台计算机）
  - 可直接使用交换机连接，形成局域网。
- 中等规模企业（几百台计算机）
  - 交换器，形成局域网。
- 稍大规模企业（近千台计算机）
  - 主交换机＋交换器；形成园区网。
- 大规模企业
  - 主交换机构成主干网，通过交换器辐射园区网。
- 与外部连接：
  - 增加路由器，接入广域网。

### 本章小结

1. 网络互连的目的是分割子网和互连子网；
2. 网络互连部件首先是子网上的一个部件，执行该子网的协议；同时，进行子网低层协议的转换（帧或分组的解封/封装）。
3. 网络互连部件根据处理的对象可分类为：转发器、桥接器、路由器和网关；
4. 原则上，网关可以互连各类子网；为提高效率酌情选用路由器、桥接器和转发器；
5. 互连部件转发的对象是数据，某个子网特有的控制信息不应转发到其它子网（子网特有性能损失）；
6. 桥接器设计/设置应解决的问题：广播风暴（基于自学习方式的地址映射表）和冗余循环（生成树算法）。
