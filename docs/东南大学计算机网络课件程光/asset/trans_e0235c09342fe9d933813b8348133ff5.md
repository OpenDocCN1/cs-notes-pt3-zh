

## ATM物理层

• 物理媒体子层（PM）：
主要定义物理媒体与物理设备之间的接口（包括光电转换的准则），以及线路上的传输编码，最终支持位流在媒体上的传输。

• 传输汇聚子层（TC）： 主要定义控制线路的方法。
（1） 线路空闲时使用的闲置信元，用于双方TC实体保持同步；
（2） 物理层操作和管理信元（PLOAM）的功能，对物理媒体进行性能监控、故障探测和传输差错报告等。
（3） 将来自PM子层的比特流或者字节流识别为信元。
（4） 提供信元头校验功能

## ATM 层

定义信元头的结构，以及使用物理链路的方法。

- ATM层的功能

（1）**信元的汇集和分捡**：负责将多个输入端口的信元分捡到不同的输出端口；当多个输入端口的信元选择了相同的输出端口时，对信元进行必要的队列处理（**汇集**）；
（2）**VPI/VCI的管理**：经过不同的交换机，信元头要有变化，需要重填写。
（3）**信元头的增删**：发送方增加信元头，接收方删除。
（4）**信元速率调整**：不同的链路需要不同的信元速率，

## ATM适配层（AAL）

将高层的信息转换成适合ATM网络传输要求的格式，对不同的信息采取不同的定义。

ATM网络可以支持的业务种类：

- CLASS A：支持源/宿之间具有实时要求的恒定位速率（CBR）业务，例如：支持恒定位速率为64Kbps的话音传输。采用面向连接的工作方式；
- CLASS B：支持源/宿之间具有实时性要求的可变位速率（VBR）业务，例如：支持可变位速率的视频传输。采用面向连接的工作方式；
- CLASS C：支持源/宿之间无实时性要求的可变位速率（VBR）业务，例如：面向连接的数据传输业务，高速数据传输等；
- CLASS D：支持面向无连接的数据传输服务。

## ATM适配层（AAL）协议类型

AAL层又可分为两个子层：

- **汇聚子层（CS）**：面向不同应用要求，为高层的信息分段进行准备工作。
- **分段/组装子层（SAR）**：将高层数据分段成信元负载域的格式，或者将多个信元负载域中的信息组装成高层数据。

- **AAL1**：支持CLASS A业务
- **AAL2**：支持CLASS B业务
- **AAL3/4**：支持CLASS C和D类业务
- **AAL5**：简单高效的适配层（SEAL），AAL3/4简化，可以同时支持CLASS C和CLASS D业务

## ATM网络的应用

ATM具有带宽预约的功能，是专为多媒体应用设计的网络；

ATM技术可以构建局域网和广域网；

## 宽带用户接入方式

1、高速数字用户线接入（xDSL）：借助复用和调制技术，利用电话线支持用户高速接入方式的统称；

### 基本思路：

在质量和距离（<55km）的限制下，用户端电话线约有11MHz的带宽，通常只用4KHz的带宽支持语音传输，可以利用高频段，提高线路的利用率；

## 宽带用户接入方式

xDSL将11MHz的带宽划分为256个4.3125Khz的子带宽，分别用于支持语音和数据传输；

![](img/0761188ee01704e55ea71e6a97539d38_541_0.png)

0道—语音传输，1-5道—保留，6-N—上行，N+1-255—下行；

## 非对称数字用户环路（ADSL）

### ADSL技术的特点

- 1、 可直接利用现有用户电话线，节省投资；
- 2、 可享受超高速的网络服务，为用户提供上、下行不对称的传输带宽。
- 3、 节省费用，上网同时可以打电话，互不影响，而且上网时不需要另交电话费。
- 4、 安装简单，不需要另外申请增加线路，只需要在普通电话线上加装 ADSL MODEM，在电脑上装上网卡即可。
