# Computing Earned Value

+   - The *budgeted cost of work scheduled* (BCWS) is determined for each work task represented in the schedule.
+     - BCWSᵢ is the effort planned for work task *i*.
+     - To determine progress at a given point along the project schedule, the value of BCWS is the sum of the BCWSᵢ values for all work tasks that should have been completed by that point in time on the project schedule.
+   - The BCWS values for all work tasks are summed to derive the *budget at completion*, BAC. Hence,
+     - BAC = Σ (BCWSₖ) for all tasks *k*
