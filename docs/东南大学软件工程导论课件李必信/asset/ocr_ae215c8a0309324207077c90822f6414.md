# 2.1 认识软件、软件开发、软件工程

+   - **A program** is a sequence of instructions that can be executed by a computer (CPU) that performs a certain task intentioned by the programmer.
+   - **Software** is the set of directions that enables computer hardware to perform useful work.

+   - 计算观—计算的实质就是寻找一种可机械执行的算法。例如，著名的计算模型：图灵机（被公认为现代计算机的祖先）。
+   - 组成观—软件可以用两个简单的算式来概括：
+     - （1）软件=程序+文档
+     - （2）程序=算法+数据结构
