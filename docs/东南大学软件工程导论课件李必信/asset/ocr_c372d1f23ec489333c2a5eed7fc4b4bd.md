# 1.2.1 How It All Started

![](bbox=[0.024, 0.349, 0.266, 0.796])

+   - The earliest **practical form** of programming was probably done by **Jacquard (1804, France)**. He designed a loom that performed predefined tasks through feeding **punched cards** (穿孔卡) into a reading contraption(装置). This new technology allowed carpets (地毯) and tissues (纺织品) to be manufactured with lower skills and even with fewer people. The little kid sitting under the loom changing rods (杆) and other things vanished. One single person could now handle a loom.
