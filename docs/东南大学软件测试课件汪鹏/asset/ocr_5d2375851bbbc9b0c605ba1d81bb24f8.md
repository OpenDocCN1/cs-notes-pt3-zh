# 正交数组测试原理

# A和B的取值组合

A₁ B₁ C₁  A₁ B₂ C₂  A₁ B₃ C₃
A₂ B₁ C₂  A₂ B₃ C₁  A₂ B₂ C₃
A₃ B₁ C₃  A₃ B₂ C₁  A₃ B₃ C₂

# A和C的取值组合

A₁ B₁ C₁  A₁ B₂ C₂  A₁ B₃ C₃
A₂ B₁ C₂  A₂ B₃ C₁  A₂ B₂ C₃
A₃ B₁ C₃  A₃ B₂ C₁  A₃ B₃ C₂

# B和C的取值组合

A₁ B₁ C₁  A₁ B₂ C₂  A₁ B₃ C₃
A₂ B₁ C₂  A₂ B₃ C₁  A₂ B₂ C₃
A₃ B₁ C₃  A₃ B₂ C₁  A₃ B₃ C₂

# 特点1：任意两个输入的所有组合均被包含
