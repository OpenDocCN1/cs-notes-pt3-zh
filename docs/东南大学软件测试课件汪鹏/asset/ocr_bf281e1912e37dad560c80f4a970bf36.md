# 4.生成决策表

原因——决策表中的条件

结果——决策表中的行动

原因与结果的组合——决策规则

决策表示例

|  | 1 | 2 | 3 | 4 | 5 | 6 |
|---|---|---|---|---|---|---|
| 条件 C1 | 0 | 0 | 0 | 0 | 1 | 1 |
| 条件 C2 | 0 | 0 | 1 | 1 | 0 | 0 |
| 条件 C3 | 0 | 1 | 0 | 1 | 0 | 1 |
| 行动 A1 | 0 | 0 | 0 | 1 | 0 | 1 |
| 行动 A2 | 1 | 1 | 0 | 0 | 0 | 0 |
| 行动 A3 | 1 | 0 | 1 | 0 | 1 | 0 |
