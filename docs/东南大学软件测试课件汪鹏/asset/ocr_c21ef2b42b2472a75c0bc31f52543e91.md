# 打印幻灯片、讲义和备注

执行以下任一操作：

# 单击一张或多张幻灯片

+   1. 在"文件"菜单上，单击"打印"。
+   2. 在"幻灯片"的旁边，单击"从"，然后在"从"和"到"框中，键入要打印的幻灯片的编号
+      注意 如果看不到此选项，请单击箭头 以展开"打印"对话框。
+   3. 单击"打印"。

# 打印所选幻灯片

+   1. 在"视图"菜单上，单击"幻灯片浏览"。
+      注意 您还可以从普通视图的导航窗格中打印多张幻灯片。
+   2. 选择要打印的幻灯片。
+      若要选择多张幻灯片，请在单击幻灯片时按住 。
+   3. 在"文件"菜单上，单击"打印"。
+   4. 在"幻灯片"下，单击"所选幻灯片"。
+      注意 如果看不到此选项，请单击箭头 以展开"打印"对话框。
