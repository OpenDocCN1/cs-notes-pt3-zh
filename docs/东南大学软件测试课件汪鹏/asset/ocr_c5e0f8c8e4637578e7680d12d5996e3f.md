# LoadRunner——脚本录制与开发

# ■ Vuser Script录制流程

# URL-based script:

捕获所有由用户产生的HTTP请求

特点：详细、伸缩性强

```
web_url("MercuryWebTours",
        "URL=http://localhost/MercuryWebTours/",
        "Resource=0",
        "RecContentType=text/html",
        "Referer=",
        "Snapshot=t1.inf",
        "Mode=HTTP",
        LAST);

web_concurrent_start(NULL);

web_url("header.html",
        "URL=http://localhost/MercuryWebTours/header.html",
        "Resource=0",
        "RecContentType=text/html",
        "Referer=http://localhost/MercuryWebTours/",
        "Snapshot=t2.inf",
        "Mode=HTTP",
        LAST);
```
