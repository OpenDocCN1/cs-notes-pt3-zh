| **ID:** LG0101002  
**用例名称:** 验证输入错误密码后提示是否正确  
**测试项:** 用户邮件地址和密码  
**环境要求:** Windows XP SP3和Firefox 3.0.2  
**参考文档:** 软件规格说明书SpecLG01.doc  
**优先级:** 高  
**层次:** 2（即LG0101）的子用例  
**依赖的测试用例:** LG0101001  
**步骤:**  
1. 打开浏览器，进入Google页面  
2. 单击页面右上角“登录”链接，出现登陆界面  
3. 在电子邮件的输入框中输入：test@gmail.com  
4. 在口令输入框中输入：xxxabc  
5. 单击“登录”按钮  
**期望结果:**  
登录失败，页面重新回到登录界面，并提示“用户密码错误” |
