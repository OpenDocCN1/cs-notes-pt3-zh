
# 黑盒测试方法——等价划分

## 等价类划分指南

+   1. 布尔值

数据类型：布尔值、条件

划分方法：

+   1个有效等价类
+   1个无效等价类

例: 是否学习过《软件工程》
是否双面打印

## 等价类划分指南

+   2. 取值范围

数据类型：连续取值范围（通常是线性）

划分方法：

+   1 个有效等价类
+   2 个无效等价类

例：输入的考试成绩在0-100之间

有效等价类是：0 ≤ 成绩 ≤ 100
无效等价类是：成绩<0 和 成绩>100

## 等价类划分指南

+   3. 数据个数

数据类型：输入有个数约束

划分方法：

+   1个有效等价类
+   2个无效等价类

例：构成三角形的3条边

有效等价类：输入边数 = 3

无效等价类：输入边数 < 3 和 输入边数 > 3

+   4. 集合

数据类型：符合特定规则的子集

划分方法：

## 等价类划分指南

+   5. 需分别处理的数据

数据类型：一组列表

划分方法：

N个有效等价类

1个无效等价类

例：中国的直辖市

有效等价类：北京、上海、天津、重庆

无效等价类：非直辖市

## 等价类划分指南

+   6. 符合规则的数据

数据类型：规则

划分方法：

N个有效等价类

M个无效等价类

例：正确的电子邮件：含有@ 后跟x.y 不含#&

有效等价类：字母+@x.y 数字+@x.y

无效等价类：不含@ @后不是x.y 含#

| 输入数据类型 | 划分等价类规则 |
|---|---|
| 布尔值 | 1个有效等价类： TRUE | 1个无效等价类： FALSE |
| 连续取值范围 | 1个有效等价类： 正确取值范围 | 2个无效等价类： 大于和小于取值范围 |
| 数据个数 | 1个有效等价类： 正确数据个数 | 2个无效等价类： 大于和小于数据个数 |
| 集合 | 1个有效等价类： 正确的集合取值 | 1个或多个无效等价类 |
| 需分别处理的输入数据 | 多个有效等价类： 每个输入数据为1个等价类 | 1个无效等价类 |
| 符合某些规则的输入 | 多个有效等价类： 符合某个规则的输入数据为1个等价类 | 若干个无效等价类 |

## 等价类划分测试步骤

+   1. **Step1:** 选择划分准则（范围、取值、布尔…）
+   2. **Step2:** 根据准则确定有效和无效等价类
+   3. **Step3:** 从等价类中选取样本数据
+   4. **Step4:** 根据需求写预期结果
+   5. **Step5:** 加入特殊值
+   6. **Step6:** 执行测试
