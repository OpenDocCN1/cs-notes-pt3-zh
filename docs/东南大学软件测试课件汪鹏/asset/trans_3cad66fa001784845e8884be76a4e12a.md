

## 黑盒测试方法——等价划分

### 等价类划分总结

- 非冗余性：尽可能使等价类间没有交叉，保证测试用例不存在冗余
- 完整性：等价类的并集等于输入/输出域
- 局限：忽略边界位置的测试用例

## 黑盒测试方法——边界值分析

### 边界值分析原理

- 软件的两个主要缺陷源
  - （1）条件
  - （2）边界

条件：变量取值决定控制流走向

边界：变量值的“极限”

- **边界值分析**：能有效捕获出现在边界处的缺陷的一种测试方法；利用了缺陷更容易出现在边界处的事实。

![](img/88f667f5480db09ef600e4e177b09268_209_0.png)

缺陷易出现在边界处的原因：

- （1）使用比较操作符时未仔细分析
- （2）循环和条件检查方法引起的困惑
- （3）对边界附近需求的理解不够

### 边界值类型

- 边界值数据类型
  - 数值、速度、字符、地点
  - 位置、尺寸、数量……
- 边界特征
  - 第一个/最后一个、最小值/最大值
  - 开始/完成、空/满、最短/最长
  - 最慢/最快、最早/最迟、最大/最小

### 次边界条件/隐性边界

- 各种数据类型的极限
- `int, unsigned int, long, char, …`——一般是2的幂次
- ASCII、Unicode 字符
- 空白，空值，零值，无输入
- 屏幕分辨率决定的光标/鼠标运动范围
- ……

特点：产品说明书中没有，外部用户看不到

### 边界值确定

|  | 边界值附近数据 | 测试用例设计思路 |
|---|---|---|
| 字符 | Min-1, Min, Min+1<br>Max-1, Max, Max+1 | 文本框允许输入1-255个字符：0,1,2,254,255,256 |
| 数值范围 | Min-1, Min, Min+1<br>Max-1, Max, Max+1 | 输入数据允许1-999：0,1,2,998,999,1000 |
| 集合空间 | 0, Min, Min+1<br>Max-1, Max, Max+1 | 图片大小不能超过50k：0,1k,49k,50k,51k |

### 边界值测试用例确定方法

**独立参数的单变量的边界值**

n：存在边界值的参数个数

**方法一：基本边界测试**

对每个参数取4个边界值

- Min, Min+1
- Max-1, Max

计算公式：4n+1

> Paul C. Jorgensen, Software Testing: A Craftsman’s Approach (1995)

**方法二：健壮性边界测试**

对每个参数取6个边界值

- Min-1, Min, Min+1
- Max-1, Max, Max+1

计算公式：6n+1

> Paul C. Jorgensen, Software Testing: A Craftsman’s Approach (1995)

**非独立参数的多变量的边界值**

m：边界条件的数量

**方法三：边界条件测试**

确定边界条件，对每个边界条件取 3 个边界值

BC-1, BC, BC+1

计算公式：3m
