# 饮料自动售货机规格说明

![](img/88f667f5480db09ef600e4e177b09268_259_0.png)

+   1. 自动售货机有两种饮料（橙汁和啤酒）供人们选择，售价均为5角。
+   2. 售货机可以接收5角钱或1元钱的硬币，需要找零钱。
