# Influencing Factors

+   - Technical and organizational Factors
+     - Quality requirements from target domain
+     - Technical environment
+   - Business Factors
+     - Overall business goals
+   - System Stakeholders
+     - Management “Low cost, keep people employed”
+     - Marketing “Neat features, low cost, time-to-market”
+     - End user “behavior, performance, reliable”
+     - Maintenance org “modifiable, understandable”
+     - Customer “Low cost, timely delivery”
+   - Other quality requirements.
