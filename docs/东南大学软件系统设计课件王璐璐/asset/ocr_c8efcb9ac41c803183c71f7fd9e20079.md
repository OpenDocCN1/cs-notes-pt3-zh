# 构造重用…

```
```cpp
Person::Person(char *name, int age)
{
    Person::name=new char[strlen(name)+1];
    strcpy(Person::name, name);
    Person::age=age;
    cout<<"Construct Person"<<name<<", "<<age<<"\n";
    return;
}

Person::~Person()
{
    cout<<"Destruct Person"<<name<<", "<<age<<"\n";
    delete name;
    return;
}
