# 使用SOA进行服务组合实例

假设股票行业存在以下6个服务：

+   - **Country ()**
+     输入参数：国家编码。输出项：国家名称和其他信息。
+   - **YellowPages ()**
+     输入参数：公司名称；输出项：企业代码，所在国家等其他信息。
+   - **NewYorkStock ()**
+     输入参数：公司代码，时间；输出项：该公司在纽约的股票价格（美元）。
+   - **LondonStock ()**
+     输入参数：公司代码，时间；输出项：该公司在伦敦的股票价格。
+   - **USToRMB ()**
+     输入参数：美元价格，时间；输出项：对应的人民币价格。
+   - **UKToRMB ()**
+     输入参数：英镑价格，时间；输出项：对应的人民币价格。
