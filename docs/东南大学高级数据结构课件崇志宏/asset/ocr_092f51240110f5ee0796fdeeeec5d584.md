# Potential function

Define the potential function Φ:{L_i} → ℝ by

Φ(L_i) = 2 · |{(x, y) : x ≺_{L_i} y and y ≺_{L_i * x} }|
= 2 · # inversions.

Note that

+   - Φ(L_i) ≥ 0 for i = 0, 1, ...,
+   - Φ(L_0) = 0 if MTF and OPT start with the same list.

How much does Φ change from 1 transpose?

+   - A transpose creates/destroys 1 inversion.
+   - ΔΦ = ±2.
