# 3 Major Steps

Starting the processing from the end of list **L**:

+   1. **Step 1:** Construct **conditional pattern base** for each item in the header table
+   2. **Step 2:** Construct **conditional FP-tree** from each conditional pattern base
+   3. **Step 3:** **Recursively mine** conditional FP-trees and grow frequent patterns obtained so far. If the conditional FP-tree contains a _single path_, simply enumerate all the patterns
