# Deletion

To remove an item with key x from a skip list, we proceed as follows:

+   - We search for x in the skip list and find the positions p₀, p₁, ..., pᵢ of the items with key x, where position pⱼ is in list Sⱼ
+   - We remove positions p₀, p₁, ..., pᵢ from the lists S₀, S₁, ..., Sᵢ
+   - We remove all but one list containing only the two special keys
