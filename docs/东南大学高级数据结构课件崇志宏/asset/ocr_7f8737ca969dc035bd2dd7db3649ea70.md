# Potential function

Define the potential function \(\Phi: \{L\} \to \mathbb{R}\) by

\[\Phi(L_i)=2\cdot |\{(x,y): x\prec_{L_i} y\text{ and }y\prec_{L_i^*}x\}|\]
\[\qquad\quad=2\cdot \#\ \textit{inversions}.\]
