# Consistent Hashing

+   - The consistent hash function assigns each node and key an *m*-bit *identifier* using a base hash function such as [SHA-1](SHA-1).
+   - Identifiers are ordered in an *identifier circle* modulo 2^m.
+   - Key *k* is assigned to the first node whose identifier is equal to or follows *k* in the identifier space. This node is called the *successor node* of key *k*.
+   - If identifiers are represented as a cycle of numbers from 0 to 2^m − 1, then *successor(k )* is the first node clockwise from *k*.
