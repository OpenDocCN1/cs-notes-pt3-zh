# Main Idea

+   - Consider
+     - single counter X
+     - hash function h(i): {1, 2, ..., N} → {-1, +1}
+   - Input element i → update counter X += Z_i = h(i)
+   - For each r, use XZ_r as estimator of m_r

# Theorem: E[XZ_r] = m_r

Proof

+   - X = Σ_i m_i Z_i
+   - E[XZ_r] = E[Σ_i m_i Z_i Z_r] = Σ_i m_i E[Z_i Z_r] = m_r E[Z_r²] = m_r
+   - Cross-terms cancel
