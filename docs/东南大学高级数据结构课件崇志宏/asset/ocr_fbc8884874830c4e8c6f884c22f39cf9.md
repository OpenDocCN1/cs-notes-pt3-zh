# Lemma 1 The amortized cost of a splay step on node x is ≤ 3(r′(x) − r(x)) + 1, where r is rank before the splay step and r′ is rank after the splay step. Furthermore, the amortized cost of the rr, ll, lr, and rl splay steps is ≤ 3(r′(x) − r(x)).
