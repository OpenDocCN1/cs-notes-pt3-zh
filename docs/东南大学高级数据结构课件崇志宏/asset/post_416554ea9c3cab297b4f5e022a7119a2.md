
## Potential function

Define the potential function \(\Phi:\{L_i\}\to\mathbb{R}\) by

\[
\Phi(L_i)=2\cdot |\{(x,y): x\prec_{L_i} y \text{ and } y\prec_{L_i^*} x\}|=2\cdot \#\text{ inversions}.
\]

### Example

![](img/e8cfdb0a049dc5ab9d802234ebc2190e_47_0.png)

\[
\Phi(L_i)=2\cdot |\{(E,C),(E,A),(E,D),(E,B),(D,B)\}|=10.
\]

Note that

- \(\Phi(L_i)\ge 0\) for \(i=0,1,\dots\).
- \(\Phi(L_0)=0\) if MTF and OPT start with the same list.

### How much does \(\Phi\) change from 1 transpose?

- A transpose creates/destroys 1 inversion.
- \(\Delta\Phi=\pm 2\).

## What happens on an access?

Suppose that operation \(i\) accesses element \(x\), and define

\[
A=\{y\in L_{i-1}: y\prec_{L_{i-1}} x \text{ and } y\prec_{L_{i-1}^*} x\},
\]

\[
B=\{y\in L_{i-1}: y\prec_{L_{i-1}} x \text{ and } y\succ_{L_{i-1}^*} x\},
\]

\[
C=\{y\in L_{i-1}: y\succ_{L_{i-1}} x \text{ and } y\prec_{L_{i-1}^*} x\},
\]

\[
D=\{y\in L_{i-1}: y\succ_{L_{i-1}} x \text{ and } y\succ_{L_{i-1}^*} x\}.
\]

![](img/e8cfdb0a049dc5ab9d802234ebc2190e_51_0.png)

| List | Order around \(x\) | Rank |
|---|---|---|
| \(L_{i-1}\) | \(A \cup B,\; x,\; C \cup D\) | \(r=\operatorname{rank}_{L_{i-1}}(x)\) |
| \(L_{i-1}^*\) | \(A \cup C,\; x,\; B \cup D\) | \(r^*=\operatorname{rank}_{L_{i-1}^*}(x)\) |

We have \(r=|A|+|B|+1\) and \(r^*=|A|+|C|+1\).

When MTF moves \(x\) to the front, it creates \(|A|\) inversions and destroys \(|B|\) inversions. Each transpose by OPT creates at most 1 inversion. Thus,

\[
\Phi(L_i)-\Phi(L_{i-1})\le 2(|A|-|B|+t_i).
\]

## Amortized cost

The amortized cost for the \(i\)th operation of MTF with respect to \(\Phi\) is

\[
\hat{c}_i=c_i+\Phi(L_i)-\Phi(L_{i-1}).
\]

Then

\[
\begin{aligned}
\hat{c}_i
&\le 2r+2(|A|-|B|+t_i)\\
&=2r+2(|A|-(r-1-|A|)+t_i) && \text{(since } r=|A|+|B|+1\text{)}\\
&=2r+4|A|-2r+2+2t_i\\
&=4|A|+2+2t_i\\
&\le 4(r^*+t_i) && \text{(since } r^*=|A|+|C|+1\ge |A|+1\text{)}.
\end{aligned}
\]
