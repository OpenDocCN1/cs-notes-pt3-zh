# 6.9 程序举例

例6.6 用 π /4≈1-1/ 3+1/5-1/7+1/9... 求 π 的近似值。直到最后一项的绝对值小于10^-6为止。

```
#include "math.h"
main()
{ int sign=1;
  float n=1,t=1,sum=0, pi;
  while(fabs(t)>=1.e-6)//fabs()求绝对值的函数
  {  sum=sum+t;
     n=n+2;
     sign*= -1;
     t=sign/n;
  }
  pi=sum*4;
  printf("pi=%f\n",pi);
}
```

运行结果:
pi=3.141594
