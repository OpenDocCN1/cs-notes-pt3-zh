# 将while和do-while循环做一下比较：

| while 循环 | do-while 循环 |
|---|---|
| ```c
#include<stdio.h>
void main()
{
    int i; long sum=1;
    scanf("%d", &i);
    while (i<=10)
    {
        sum=sum*i;
        i++;
    }
    printf("%ld\\n",sum);
}
``` | ```c
#include<stdio.h>
void main()
{
    int i; long sum=1;
    scanf("%d", &i);
    do
    {
        sum=sum*i;
        i++;
    }while (i<=10);
    printf("%ld\\n",sum);
}
``` |

| 输入：9 | 输入：11 | 输入：9 | 输入：11 |
|---|---|---|---|
| 输出：90 | 输出：1 | 输出：90 | 输出：11 |
