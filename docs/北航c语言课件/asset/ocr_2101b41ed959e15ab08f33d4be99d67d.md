# 3.5.4字符串常量(Character string constant)

1.定义：括在一对双引号 “...”之内的字符序列或转义字符序列称为字符串常量。

例如：“How are you!” “a” “*abc\n\t”

2.存储：字符串中的字符依次存储在内存中一块连续的区域内，并且把空操作字符 ‘\0’自动附加到字符串的尾部作为字符串的结束标志。故字符个数为n的字符串在内存中应占n+1个字节。

例：char c[6]="china";
char *s="china";
