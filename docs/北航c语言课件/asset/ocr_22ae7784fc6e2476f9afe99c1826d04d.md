# 一维数组的数组元素及地址运算
（各班战士及地址运算）

0班长地址          a[0]   *(a+0)

0班j战士的地址   *(a+0)+j

0班j战士 *(*(a+0)+j) | a[0][0]  a[0][1]  a[0][2] a[0][3]

1班长地址          a[1]   *(a+1)

1班j战士的地址   *(a+1)+j

1班j战士 *(*(a+1)+j) | a[1][0]  a[1][1]  a[1][2] a[1][3]

2班长地址          a[2]   *(a+2)

2班j战士的地址   *(a+2)+j

2班j战士 *(*(a+2)+j) | a[2][0]  a[2][1]  a[2][2] a[2][3]
