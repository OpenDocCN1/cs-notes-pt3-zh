已知：一位数码a和要组成的最大重码数tn的位数n。

求：各重码数的累加和sn。

算法：对给定的a和n，从i=1～n依次作：

+   1. 求第i个重码数tn = tn * 10 + a。
+      （其中tn的初值应是0）
+   2. 求累加和　sn = sn + tn。

```
main()
{
    int sn,a,n,i,tn;
    long sn,tn;
    printf("\na, n=");
    scanf("%d%d",&a,&n);
```

for(tn=0,sn=0,i=1;i<=n;i++)
