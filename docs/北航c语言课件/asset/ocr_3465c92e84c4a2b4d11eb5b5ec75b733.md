double f(double x)

# 求 xpoint(x1,x2) 函数流程图：

![](bbox=[0.004, 0.667, 0.488, 0.925])

```
/*定义xpoint函数的源程序*/
double xpoint (double x1, double x2)
{
    double x;
    x=(x1*f(x2)-x2*f(x1))/(f(x2)-f(x1));
    return (x);
}
```
