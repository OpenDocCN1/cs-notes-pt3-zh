# 程序举例：将字符串a复制为字符串b。

```
char a[]="I am a Chinese.", b[20];
......
string_copy(a,b);
puts(b);
......
void string_copy(char *a,char *b)
{
    int i=0;
    do
    {
        *(b+i)=*(a+i);
        i++;
    }while(*(a+i)!='\0');
    b[i]='\0';
}
```

其中，循环语句可改为

```
for(i=0;*(a+i)!='\0';i++)
    *(b+i)=*(a+i);
```
