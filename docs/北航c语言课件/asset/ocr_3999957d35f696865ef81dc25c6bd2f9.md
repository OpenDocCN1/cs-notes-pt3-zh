# 习题10.14： 将n个数按输入时顺序的逆序排列，用函数实现。Arrange n digits in inverse sequence to their import.

```
void inverse(int *a,int n);
main()
{ int i,a[10]={2,4,1,6,7,32,45,75,450,89};
for(puts(" "), i=0;i<10;i++) printf("%5d",a[i]);
inverse(a,10);
for(puts(" "), i=0;i<10;i++) printf("%5d",a[i]);
}
void inverse(int *x,int n)
{ int *i=x,*j=x+n-1,t;
for(;i<j;i++,j--)
{ t=*i; *i=*j; *j=t; }
}
```
