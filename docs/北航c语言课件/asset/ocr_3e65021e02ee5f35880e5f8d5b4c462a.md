# 例7.5： 求3*4数组中的最大值及其下标。

```
main()
{
    int max,row,colum,i,j;
    int a[][4]={{1,2,3,4},{9,8,7,6},{-10,10,-5,2}};
    max=a[0][0];
    for(i=0;i<3;i++)
        for(j=0;j<4;j++)
            if(a[i][j]>max)
            {
                max=a[i][j];
                row=i;
                colum=j;
            }
    printf("max=%d,row=%d,colum=%d",max,row,colum);
}
```
