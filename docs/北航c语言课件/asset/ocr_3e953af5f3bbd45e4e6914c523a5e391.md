# C字符集（续）

|  | * | asterisk | 星号 |
|  | - | Minus sign | 减号 |
|  | + | Plus sign | 加号 |
|  | < | Opening angle bracket (or less than sign) | 左尖括号（或小于号） |
|  | > | closing angle bracket (or more than sign) | 右尖括号（或大于号） |
|  | ( | Left parenthesis | 左圆括号 |
|  | ) | Right parenthesis | 右圆括号 |
|  | [ | Left bracket | 左方括号 |
|  | ] | Right bracket | 右方括号 |
|  | { | Left brace | 左大（花）括号 |
|  | } | Right brace | 右大（花）括号 |
|  | # | Number sign | 井号 |
