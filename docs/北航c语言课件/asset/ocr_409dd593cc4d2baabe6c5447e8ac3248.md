# 4. 字符串复制strcpy()函数

使用形式： strcpy(字符数组1，字符串2)

功能： 将字符串2复制到字符数组1中
（其后自动加一个 ‘\0’）。

说明： (1)字符数组1必须足够大以便能够容纳被复制的字符串。

(2)不能用赋值语句将一个字符串常量或字符数组直接赋值给一个字符数组。

```
例如： char str1[20], str2[20];
strcpy(str1,"hello world");
strcpy(str2,str1);
```

```
例如： char str1[20], str2[20];
str1={"hello"};
str2=str1;
```
