# 4、自增、自减运算符 （++、--）

**作用：**使变量的值增1或减1，如：

+   - `i++、++i` 等于 `i=i+1`
+   - `i--、--i` 等于 `i=i-1`

+   - `++i、--i` ⇔ **先执行** `i=i+1 (i=i-1)`，**后使用** i 的值
+   - `i++、i--` ⇔ **先使用** i 的值，**后执行** `i=i+1 (i=i-1)`

# 举例：

```
int j,i=3;

① j=++i;      /* i的值为4，j为4 */
② j=i++;      /* j的值为3,然后i的值变为4 */
③ j=i++;      /* j的值-3，然后i的值变为4 */
④ printf("%d",i++); /* 输出的值3，然后i的值变为4 */
```
