# 习题10.16：输入一个字符串，将其中的数字串转换成数值送数组a。

```
void main()
{
  char s[128],*ps=s;
  int a[100], i, n;
  gets(s);//"abc987def6543ghijk210"
  for(i=0,n=0;*ps;ps++)//如果*ps='\0'=0，循环终止
    if(*ps>='0' && *ps<='9')
      n=n*10+*ps-'0';
    else//遇到非数字时，数字转换完成
      { if(n>0) a[i++]=n;//将数值存入数组a
        n=0;//重新将n置零
      }
  if(n>0) a[i++]=n;//将字符串末尾的数值存入数组
  for(n=0; n<i; n++) printf("%6d",a[n]);
}
```
