# 引例。

```
```c
#define PI 3.1415926
main()
{
    float l,s,r,v;
    printf("input radius :");
    scanf("%f",&r);
    l=2.0*PI*r;//l=2.0*3.1415926*r;
    s=PI*r*r;//s=3.1415926*r*r;
    v=3.0/4*PI*r*r*r;//v=3.0/4*3.1415926*r*r*r
    printf("l=%10.4f\ns=%10.4f\nv=%10.4f\n",l,s,v);
}
```
```

其中 `#define PI 3.1415926`

作用是指定标识符PI代表“3.1415926”
