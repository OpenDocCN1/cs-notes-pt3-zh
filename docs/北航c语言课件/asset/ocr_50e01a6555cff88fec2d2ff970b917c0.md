# 二、用goto语句和 if 语句构成循环

例：计算10！并输出结果。

```
void main()
{
int i=1, sum=1;
loop: if (i<=10)
{
    sum=sum*i;
    i++;
    goto loop;
}
printf("10!=%d\n",sum);
}
```

```
void main()
{
int i=1; long sum=1;
loop: if (i<=10)
{
    sum=sum*i;
    i++;
    goto loop;
}
printf("10!=%ld\n",sum);
}
```

运行结果：10!=24320

本应是：10!=3628800
