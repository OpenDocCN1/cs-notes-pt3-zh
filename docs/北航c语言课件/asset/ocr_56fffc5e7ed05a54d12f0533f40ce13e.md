# 五、字符串数组应用举例

例1：（例题7.8）统计字符串中的单词数。

```
```c
#include <stdio.h>
main()
{
    char string[81],c;
    int i,num=0,word=0;
    gets(string);
    for(i=0;string[i]!='\0';i++)
        if(string[i]==' ') word=0;
        else if(word==0)
            {word=1;num++;}
    printf("\nThere are %d words.", num);
}
