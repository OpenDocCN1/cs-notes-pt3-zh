# （二）、字符串处理函数

# 1. 求字符串长度strlen()函数

使用形式：`strlen(字符数组)`

功能：计算字符串长度，函数值是字符串中‘\0’之前的字符个数（不包括‘\0’字符）。

```
例如：char str4[20]={ “ab\n\012/\\” }；
printf(“%d”,strlen(str))；
输出：10  (a,b,\n,\0,1,2,/,\”,)
```

```
char str5[20]={ “ab\n\0y\012/\\” }；
printf(“%d”,strlen(str))；
输出：3
```
