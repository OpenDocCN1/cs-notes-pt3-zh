# 例7.2：用数组来处理求斐波纳契数列：
1, 1, 2, 3, 5, 8...的前20个数。

数学表示： f(0)=f(1)=1, f(n)=f(n-2)+f(n-1)

```
main()
{
    int f[20]={1,1};
    for(i=2 ; i<20 ; i++) /*f[2]是数组第3个元素*/
        f[i]=f[i-2]+f[i-1]; // f[2]=f[0]+f[1];
    for(i=0 ; i<20 ; i++)// f[3]=f[1]+f[2];
    {
        printf("%10d",f[i]);
        if(i%2==1) printf("\n"); /*每行打印2个数*/
    }
}
```
