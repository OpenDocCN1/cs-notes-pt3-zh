# 说明：

else与if的匹配原则是：一个else应与其之前距离最近且没有与其它else配对的if配对。

```
if(n>=18)
    if(n<60)
        printf("adult");
    else
        printf("minor");
```

```
if (n>=18)
{
    if (n<60) printf("adult");
}
else
    printf("minor");
```

```
if (n>=18)
    if (n<60)
        printf("adult");
    else ;
else
    printf("minor");
```
