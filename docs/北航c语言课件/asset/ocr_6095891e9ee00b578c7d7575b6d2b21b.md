# 8.3 函数参数和函数的值

# 一、形式参数和实际参数

形式参数：在定义函数时函数名后面小括弧中的变量名，简称形参。

实际参数：在调用函数时函数名后面小括弧中的表达式，简称实参。

```
main()
{
    int a,b,c;
    scanf("%d%d",&a,&b);
    c=max(a,b);
    printf("Max is %d",c);
}
```

```
int max(int x, int y)
{
    int z;
    z=x>y? x:y;
    return(z);
}
```
