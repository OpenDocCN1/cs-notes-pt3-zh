# 二、if 语句的嵌套

在 if 语句中又包含一个或多个 if 语句，称为

if 语句的嵌套。

一般形式：

```
if(条件1)
    if(条件2)语句1
    else 语句2
else
    if(条件3)语句3
    else 语句4
```

内嵌 if

内嵌 if

如：

```
if(x>0)
    if(y>0)
        printf("x>0,y>0");
    else
        printf("x>0, y<=0");
else
    if(y>0)
        printf("x<=0, y>0");
    else
        printf("x<=0, y<=0");
```
