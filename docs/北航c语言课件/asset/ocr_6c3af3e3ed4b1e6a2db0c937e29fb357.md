# 3.6 变量赋初值（Variable initialization）

1. **初始化：** 在定义变量的同时为变量赋初值

2. **形式：** 类型标识符　变量名=常量或常量表达式

例如：

```
int  x=10；double sum=0.;
char  ch='a'；
```

+   - 变量赋初值允许使用符号常量
+   
+     例如：`#define PI 3.1415926`
+   
+     `......float x=PI；......`

+   - 可对被定义的变量的一部分赋初值
+   
+     例如：`int a，b，c=1，d=2;`
+   
+     `float r=2，l，s;`

+   - 可对几个变量赋以同一个初值
+   
+     例如：`int a=6，b=6，c=6;`
+   
+     或可写为：`int a=b=c=6;`
