# 3.2 常量与变量 (Constant and Variable)

# 3.2.1 常量 (Constant)

1. 定义: 在程序执行期间, 其值不发生变化的量称为常量

2. 类型:

+   - **直接常量 (Direct ~)** 又称 **字面常量**。分为
+     - 整型常量: `123, -321, 0, 654321, +78`
+     - 实型常量: `2.68, 3.14, 2.718, 1.38e12`
+     - 单字符常量: `'a', 'C', 'z'`
+     - 字符串常量: `"china", "student", "class number"`
