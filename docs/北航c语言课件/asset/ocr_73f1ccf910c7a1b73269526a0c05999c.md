# 2.4.6 用计算机语言表示算法

例4：求 1 − 1/2 + 1/3 − 1/4 + … + 1/99 − 1/100。

+   S1: 1 ⇒ sign
+   
+   S2: 2 ⇒ deno
+   
+   S3: 1 ⇒ sum
+   
+   S4: (-1)*sign ⇒ sign
+   
+   S5: sign*(1/deno) ⇒ term
+   
+   S6: sum+term ⇒ sum
+   
+   S7: deno+1 ⇒ deno
+   
+   S8: 若 deno ≤100 返回 S4；否则算法结束。

```
main()
{
    int sign=1;
    float deno=2.0，sum=1.0，term;
    while (deno<=100)
    {
        sign = -sign;
        term=sign/deno;
        sum=sum+term;
        deno=deno+1;
    }
    printf(“%f”，sum);
}
```
