# （二）指针的赋值运算（=） Assignment to pointer

指针的赋值运算：就是把地址赋值给指针变量。

指针的赋值运算可以是以下三种方式：

+   (1) 使用取地址运算符，把地址值赋值给指针变量。

```
如： int i, *pi ;  pi=&i ;
```

+   (2) 把指针变量的值赋给另一个指针变量。

```
如： int i,*pa,*pb;  pa=&i ; pb=pa;
```

+   (3) 给指针变量赋值为符号常量NULL。

```
如： int *pi ;  pi=NULL ;
```

说明：NULL是一个空指针，表示该指针变量的值没有意义。作用是为了避免对没有被初始化的指针变量的非法引用。NULL 的定义在 “stdio.h”中。
