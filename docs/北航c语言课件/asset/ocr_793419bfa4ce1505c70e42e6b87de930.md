# • 当循环体至少执行一次时，用do-while语句；反之，如果循环体可能一次也不执行，用while语句。

（循环体至少执行一次）

（循环体可能一次不执行）

```
/*只有当用户键入q或Q,才结束循环*/
char c
do
{
    c=getchar();
    printf("%c",c);
}while(c!='q'&&c!='Q');
```

```
/*只有不是q或Q的字符才被打印*/
char c;
c=getchar();
while (c!='q'&&c!='Q');
{
    printf("%c",c);
    c=getchar();
}
```

注意：!(a&&b)==!a||!b

!(a||b)==!a&&!b

所以： c!='q'&&c!='Q'    <==>    !(c=='q'||c=='Q')
