# 习题10.11：对10个等长的字符串排序并输出。

```
void sort(char (*p)[60]);
main()
{
    char s[10][60],i;
    for(i=0; i<10; i++) gets(s+i);
    sort(s);
    for(i=0; i<10; i++) puts(s+i);
}

void sort(char (*p)[60])
{
    int i,j;
    char s[60];
    for(i=0; i<9; i++)
        for(j=i+1; j<10; j++) //冒泡法
            if(strcmp(p[i],p[j])>0)
            {
                strcpy(s,p[i]); strcpy(p[i],p[j]); strcpy(p[j],s);
            }
}
```
