# 例：用指针数组指向动态内存，进行字符串的排序。

```
void sort(char *ps[],int n);
#define N 5
main()
{
    char *ps[100],i;
    for(i=0;i<N;i++)
        ps[i]=(char*)malloc(60);
    for(i=0;i<N;i++)
        gets(ps[i]);
    sort(ps,N);
    for(i=0;i<N;i++)
        puts(ps[i]);
}
```
