# 原程序段

```
If (T>=180&&M1>=60&&M2>=60 || T>=200)
    printf(" Admitted\n");
else
    printf(" Not admitted\n");
```

不使用采用复合运算表达式，改写上述程序段。

# 修改一

```
If (T>=200)
    printf(" Admitted\n");
else if(T>=180)
    if(M1>=60)
        if(M2>=60)
            printf(" Admitted\n");
        else
            printf(" Not admitted\n");
    else
        printf(" Not admitted\n");
else
    printf(" Not admitted\n");
```
