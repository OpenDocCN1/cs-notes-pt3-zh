# 习题10.8：输入一行文字，找出其中大写字母、小写字母、空格、数字以及其他字符各有多少？

```
void main()
{ char s[100],*p;
    int lowc=0, upc=0, space=0, num=0,other=0;
    gets(s);
    p=s;
    while(*p)
    { if(*p>='A' && *p<='Z') upc++;
      else if(*p>='a' && *p<='z') lowc++;
      else if(*p>='0' && *p<='9') num++;
      else if(*p==' ') space++;
      else other++;
      p++;
    }
    printf("\n upc=%d lowc=%d num=%d space=%d other=%d", upc, lowc, num, space,other);
}
```
