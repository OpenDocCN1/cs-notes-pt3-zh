# 求root(x1,x2)函数流程图：

实参的值传给形参x1,x2

求y1=f(x1)

求x=xpoint(x1,x2)；y=f(x)

y*y1>0

是

否

y1=y；x1=x

x2=x

是

fabs(y)≥ε

否

返回

```
/*定义root函数的源程序*/
double root (double x1, double x2)
{double x, y, y1;
    y1=f (x1);
    do
    {  x=xpoint(x1, x2);
        y=f(x);
        if (y*y1>0)
        {y1=y; x1=x; }
        else x2=x;
    }while(fabs(y)>=0.0001 );
    return (x);
}
```
