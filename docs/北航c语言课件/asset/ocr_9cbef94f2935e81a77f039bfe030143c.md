在C语言中，变量之所以要强制定义，其目的：

+   1、避免在使用时输错：`int student; student=30;`
+   2、每一个变量被指定为一个确定的类型，在编译时就能为其分配相应的存储单元。
+   3、指定每一个变量为一个确定的类型，在编译时据此检查该变量所进行的运算是否合法。

例如：如果有

```
double x,y；int z;
```

对于运算：

```
z=x*y;
```

在编译时系统就会提示该运算类型不匹配：

```
warning C4244: '=': conversion from 'double' to 'int', possible loss of
data
```
