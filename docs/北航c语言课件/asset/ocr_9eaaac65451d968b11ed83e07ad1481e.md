# 例6.10 译密码。密码规律为：每个字母用其后第四个字母代替，26个字母循环排列。

```
#include "stdio.h"
main()
{
    char c,c1;
    while((c=getchar())!='\n')
    {
        if((c>='a'&&c<='v') || (c>='A'&& c<='V')) c=c+4;
        else if((c>='w'&&c<='z') || (c>='W'&&c<='Z')) c=c-22;
        printf("%c",c);
    }
}
```
