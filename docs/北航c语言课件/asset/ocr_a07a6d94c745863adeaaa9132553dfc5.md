# 二、指针数组的应用

+   1. 利用指针数组处理多个字符串

方法(1): 先用指针数组指向字符数组，再处理。

```
main()
{
    char name[][80]={"aaa","bbb","ccc","ddd","eee"};
    char *pname[10], i ;
    for(i=0;i<5;i++) pname[i]=name[i];
    for(i=0;i<5;i++) puts(pname[i]);
}
```

```
main() /*与用行指针解决上述问题比较*/
{
    char name[][80]={"aaa","bbb","ccc","ddd","eee"};
    char (*pname)[80]=name, i ;
    for(i=0;i<5;i++) puts(pname[i]); //pname[i]=pname+i
}
```
