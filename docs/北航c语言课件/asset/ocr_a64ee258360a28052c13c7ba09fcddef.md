# 例：将上面计算10！并输出结果的程序用
while语句写出：

```
//用goto语句
void main()
{
    int i=1;
    long int sum=1;
    loop: if (i<=10)
    {
        sum=sum*i;
        i++;
        goto loop;
    }
    printf("10!=%ld\n",sum);
}
```

```
//用while循环语句
void main()
{
    int i=1;
    long int sum=1;
    while (i<=10)
    {
        sum=sum*i;
        i++;
    }
    printf("10!=%ld\n",sum);
}
```
