# 四、 fputs函数 和 fgets函数

这两个函数是以字符串为单位进行文件读写的函数。

+   1. fputs函数

一般调用形式： fputs(字符串,文件指针);

功能： 向指定文件输出一个字符串。

例如： fputs(str,fp); (其中str是字符数组名)
含义： 向fp 所指向的文件中输出str中的字符串。

+   2. fgets函数

调用形式： fgets(字符数组,字符串长度,文件指针);

功能： 从指定文件中读入一个字符串。

例如： fgets(str,n,fp); (其中str是字符数组名)
含义： 从fp指向的文件读取长度为n-1的字符串，最后加一个 ‘\0’存入字符数组str中。
