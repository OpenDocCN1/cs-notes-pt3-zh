# 程序举例：输出10个元素数组中的全部元素。

# 方法一：下标法。(by subscripts)

```
main()
{ int a[10]={54,65,8,2,3,56,8,21,57,98}, i;
  for(i=0;i<10;i++) printf("%4d",a[i]);
}
```

# 方法二：通过数组名计算数组元素地址，找出元素的值。(by array name and the integer)

```
main()
{ int a[10]={54,65,8,2,3,56,8,21,57,98},i;
  for(i=0;i<10;i++) printf("%4d",*(a+i));
}
```
