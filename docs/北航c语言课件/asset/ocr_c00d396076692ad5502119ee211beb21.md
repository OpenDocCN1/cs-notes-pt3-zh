设：`leap`代表闰年信息，`leap=1`闰年，`leap=0`非闰年

# 编程一（采用复合运算表达式）：

```
```c
main()
{
    int year, leap=0;
    scanf("%d", &year);  /* 输入年份值 */
    if ((year%4==0&&year%100!=0)||(year%400==0))
        leap=1;
    else leap=0;
    if(leap == 1) printf("%d is leap", year);
    else printf("%d is not leap", year);
}
