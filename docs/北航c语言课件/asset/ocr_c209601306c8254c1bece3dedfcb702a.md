• **宏替换(宏展开)**：用宏内容（字符串）原样代替程序中的所有宏名字的过程。

**说明：**
(1) 宏替换由编译程序预先进行；
(2) 宏替换范围是除字符串以外的所有宏名字；
(3) 若替换后文本串中仍含有宏名字，将再次进行替换，直到程序中不含宏名字为止。

```
```c
#define PI 3.1415926
#define R 3.0
#define L 2*PI*R
#define S PI*R*R
```
```

```
```c
main()
{
    printf("L=%f\nS=%f\n",L,S);
}
```
```

**第一次替换：** `printf("L=%f\nS=%f", 2*PI*R, PI*R*R);`

**第二次：** `printf("L=%f\nS=%f", 2*3.1415926*3.0, 3.1415926*3.0*3.0);`
