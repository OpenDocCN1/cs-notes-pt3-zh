# 函数调用例：

```
void main()              /* 主函数 */
{
    print_star();       /*调用print_star函数打印*****/
    print_message();    /*调用print_message函数写字*/
    print_star();       /*调用print_star函数打印*****/
}

void print_star()       /*定义print_star函数*/
{
    printf("\n************");
}

void print_message()    /*定义print_message函数*/
{
    printf("\n Hello! ");
}
```
