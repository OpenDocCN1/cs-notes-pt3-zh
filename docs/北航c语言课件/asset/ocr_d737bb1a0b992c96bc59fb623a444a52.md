# 三、指针变量作为函数参数

指针可以用作函数参数，这在希望通过调用函数来改变主调函数的参数值时非常有用。

例如：用指针变量编写实现两个数的交换的函数

```
void swap(int *p1, int *p2);
main()
{int x1=100,x2=200;
printf("x1=%d,x2=%d\n",x1,x2);
swap(&x1,&x2);
printf("x1=%d,x2=%d\n",x1,x2);
}
```

```
void swap(int *p1, int *p2)
{
    int temp;
    temp=*p1;
    *p1=*p2;
    *p2=temp;
}
```
