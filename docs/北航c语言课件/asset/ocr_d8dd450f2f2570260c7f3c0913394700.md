# 说明：

+   1. %后的“*”附加说明符，用来表示跳过它相应的数据。
+   如： scanf("%2d ,%*3d , %2d",&a,&b);
+   输入： 12 , 456 , 67
+   结果： a=12 b=67

+   2. 输入数据时不能规定精度。
+   × scanf("%7.2f",&a);

+   3. 输入的字符、数值要与格式一致
+   scanf("a=%d, b=%d",&a,&b);
+   输入： a=12,b=13

+   4、 scanf("%c%c%c",&a,&b,&c);
+   输入： a _ b _ c
+   空格和转义字符都作为有效字符输入
