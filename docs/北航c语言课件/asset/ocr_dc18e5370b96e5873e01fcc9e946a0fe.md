例：阅读程序。

```
#include "stdio.h"
#define NULL 0
main()
{
    FILE *fp;
    int count=0; char c;
    if((fp=fopen("file.txt","r")) ==NULL)
        { printf("Can’t Open File \n"); exit(0); }
    do {c=fgetc(fp); count++;} while(c!=EOF);
    count--;
    printf("count=%d\n",count);
    fclose(fp);
}
```

这是读一个文本文件中字符，并判断文件是否结束的常用方法

若文件file.txt的内容是: abcd1234ABCD

输出结果： 12
