注意：用一般初始化方式：

```
char message[]={'H','e','l','l','o'};
```

结果： ‘H’ ‘e’ ‘l’ ‘l’ ‘o’

用字符串常量初始化：

```
char message[]={"Hello"};
```

结果： ‘H’ ‘e’ ‘l’ ‘l’ ‘o’ ‘\0’

说明：字符数组本身并不要求它的最后一个元素一定是 ‘\0’，例如： char ch[2]={‘A’,‘B’}; 是合法的。

为了与用字符串常量对字符数组赋初值的处理方法一致，在字符数组中也常常人为地加上一个值为 ‘\0’的元素。

如： char message[]={'H','e','l','l','o','\0'};
