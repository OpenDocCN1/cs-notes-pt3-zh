+   6. **x格式符**——以16进制数形式输出整数
+      同样不会出现负的十六进制数。

+   7. **u格式符**——以十进制形式输出unsigned型数据

如：

```
main()
{
    unsigned int a=65535;
    int b=-2;
    printf("a=%d,%o,%x,%u\n",a,a,a,a);
    printf("b=%d,%o,%x,%u\n",b,b,b,b);
}
```

输出结果：    **a=-1,177777,ffff,65535**

                 **b=-2,177776,fffe,65534**
