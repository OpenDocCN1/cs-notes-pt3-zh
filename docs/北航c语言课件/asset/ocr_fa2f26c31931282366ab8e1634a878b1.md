# 1.3 简单的C程序介绍

例1.3:从键盘输入两个整数,并将最大的数显示出来。

```
#include "stdio.h" /*包含预处理语句*/
void main() //主函数
{
    int a,b,c;
    printf("Please input two integers:\n");
    scanf("%d,%d", &a, &b);
    c=max(a,b);
    printf("max= %d\n", c);
}
int max(int x,int y)//子函数
{
    int z;
    if(x>y) z=x;
    else z=y;
    return(z);
}
```

程序运行情况:
Please input two integers:
8,5
max=8
