### 循环结构的程序流程是：

在满足给定条件时，反复执行某个程序段。

### C语言中可以用以下语句来实现循环：

- (1) 用goto语句和 if 语句构成循环；
- (2) 用while语句；
- (3) 用do_while语句；
- (4) 用for语句。

### 6.2 goto语句和goto语句构成的循环

### 一、goto 语句（Goto Sentence）

goto 语句为无条件转向语句，其作用为：使程序的执行无条件地转移到指定处。

**一般形式：**

```
goto 语句标号;
```

### 执行过程：执行语句时，程序转移到以标号（命名规则与变量相同）为前缀的语句处继续执行。

如：向前跳

```
goto label;
```

……

……

```
label:语句;
```

向后跳

如： √ goto label_1; × goto 123;

……

……

### 二、用goto语句和 if 语句构成循环

例：计算10！并输出结果。

```
void main()
{
int i=1, sum=1;
loop: if (i<=10)
{
    sum=sum*i;
    i++;
    goto loop;
}
printf("10!=%d\n",sum);
}
```

```
void main()
{
int i=1; long sum=1;
loop: if (i<=10)
{
    sum=sum*i;
    i++;
    goto loop;
}
printf("10!=%ld\n",sum);
}
```

运行结果：10!=24320

本应是：10!=3628800

### 6.3 while循环语句

一般形式：

```
while (表达式) 语句
```

执行过程：

![](img/7e3448331bc3f721cf3127b2b2f06002_282_0.png)

- 1. 先计算表达式的值；
- 2. 若表达式的值为真（非0）时执行循环体中的语句，然后重复上面步骤。若表达式的值为假（0），则结束循环。

### 例：将上面计算10！并输出结果的程序用
while语句写出：

```
//用goto语句
void main()
{
    int i=1;
    long int sum=1;
    loop: if (i<=10)
    {
        sum=sum*i;
        i++;
        goto loop;
    }
    printf("10!=%ld\n",sum);
}
```

```
//用while循环语句
void main()
{
    int i=1;
    long int sum=1;
    while (i<=10)
    {
        sum=sum*i;
        i++;
    }
    printf("10!=%ld\n",sum);
}
```

### 注意：

(1)循环条件中的表达式一般是逻辑表达式或关系表达式，也可以是算术表达式（非0为真，0为假）。一般表达式中应含有循环控制变量。

```
while (3)
```

```
while (0)
```

虽然从程序设计的角度上说是不合理的，但却是合法的。

| 语句 | 含义 |
|---|---|
| while (3) 语句 | 表示无限循环 |
| while (0) 语句 | 表示不进入循环体 |

### 6.4 do-while循环语句

一般形式：

```
do
语句
while(表达式);
```

分号不能少

执行过程：

![](img/7e3448331bc3f721cf3127b2b2f06002_288_0.png)

- (1)执行循环体中的语句；
- (2)计算表达式，测试循环条件，为真(非0)则重复上面步骤，为假(0)结束循环。

### 将while和do-while循环做一下比较：

| while 循环 | do-while 循环 |
|---|---|
| ```c
#include<stdio.h>
void main()
{
    int i; long sum=1;
    scanf("%d", &i);
    while (i<=10)
    {
        sum=sum*i;
        i++;
    }
    printf("%ld\\n",sum);
}
``` | ```c
#include<stdio.h>
void main()
{
    int i; long sum=1;
    scanf("%d", &i);
    do
    {
        sum=sum*i;
        i++;
    }while (i<=10);
    printf("%ld\\n",sum);
}
``` |

| 输入：9 | 输入：11 | 输入：9 | 输入：11 |
|---|---|---|---|
| 输出：90 | 输出：1 | 输出：90 | 输出：11 |
