## 习题6.7 (看书P120)

已知：正整数 1≤n≤1000

求：其中的“完数”，即一个数的所有因子之和等于该数本身的数。

算法：对于n=2～1000的每一个数，进行：

- ① 求出该数的所有因子并累加于sum（不保存这些因子）。
- （一个数n的所有因子的求法：只需用2~n/2 的所有数去除n,能整除的就是其因子。）

- ② 当能满足完数条件时（sum=n），重新求出该数的所有因子并打印。

```
#include<math.h>
main()
{
    int sum,n,i;
    for(n=2;n<=1000;n++)
    {  sum=0;
    for(i=1;i<=n/2;i++)
        if(fmod(n,i)==0) sum+=i;//求出n的因子,计算其和
    if(sum==n)
    {printf("\n%d :",n);//打印完数
    for(i=1;i<=n/2;i++)
        if(fmod(n,i)==0)
        printf("%d  ",i);//重新计算n的因子,并打印输出
    }
    }
}
```
