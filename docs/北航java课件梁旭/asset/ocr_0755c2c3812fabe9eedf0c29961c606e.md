# 7.2.1 用户Applet的定义

+   ■ 编写Applet步骤：
+   ■ 1、导入java.applet包中的类：
+     - import java.applet.*;
+     - 或 import java.applet.Applet;
+   ■ 2、类头定义：
+     - public class Myapplet extends Applet;
+   ■ 3、编写类体（编写几个常用方法，无main()方法）。
+   ■ 4、嵌入到html页面中，运行applet。
+     - <applet ......> ...... </applet>标签。
+   ■ 5、浏览器中执行Applet的步骤（见7.1.2）。
+     - 请求—发现—获取—验证—执行
