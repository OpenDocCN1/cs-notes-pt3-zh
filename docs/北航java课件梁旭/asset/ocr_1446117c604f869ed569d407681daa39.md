# 2.3 基本数据类型

+   - 三、字符型数据
+   - 特殊字符的常量表示法:
+     - 反斜线（Backslash） '\'
+     - 退格（Backspace） '\b'
+     - 回车（Carriage return） '\r'
+     - 进纸符（Form feed） '\f'
+     - 制表符（Form feed） '\t'
+     - 换行（New line） '\n'
+     - 单引号（Single quote） '\''
+     - 双引号（double quote） '\"'
+     - 八进制数（ '\0'～ '\377' ） '\DDD'
+     - Unicode字符 '\uHHHH'
