# 2.5 运算符和表达式

# ■ 运算符的优先次序

| 优先级 | 运算符类型 | 运算符 |
|---|---|---|
| 优先级最高 | 一元运算符 | `[]`、`.`、`()`（方法调用）<br>`!`、`~`、`++`、`--`、`+`、`-`、`new`<br>`()`（强制类型转换） |
| 优先级较高 | 算术运算符<br>位移运算符 | `*`、`/`、`%`、`+`、`-`<br>`<<`、`>>` |
| 优先级较低 | 关系运算符<br>位移运算符<br>逻辑运算符 | `<`、`<=`、`>`、`>=`、`==`、`!=`<br>`&`、`^`、`|`<br>`&&`、`||`<br>`? :`（三元判断运算符，例如：`A>B?X:Y`） |
| 优先级最低 | 赋值运算符 | `=`<br>`+=`、`-=`、`*=`、`/=`、`%=` |
