# 12.3.1 TCP客户端

创建TCP客户端程序的步骤：

+   - (1)创建Socket对象，连接服务器。
+     - Socket类构造方法：
+     - public Socket(InetAddress,String host,int port):
+       - InetAddress:主机IP地址；
+       - host:主机名；
+       - port:服务器端口号；
+       - 如本节测试： Socket("127.0.0.1",4444);

+   - (2)利用getInputStream()或getOutputStream()方法，收发信息；(即打开连接到Socket的I/O流).

+   - (3)处理I/O流， read()或write()方法；

+   - (4)关闭I/O流和Socket对象， close()方法；
