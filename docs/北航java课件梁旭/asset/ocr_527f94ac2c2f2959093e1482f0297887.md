# 10.1.2 I/O流类

+   2. OutputStream类
+   - OutputStream类层次关系图，图10.3。
+   - 主要方法：
+     - write(int b): 将一个整数输出到流中（只输出低位字节，为抽象方法）
+     - write(byte b[]): 将字节数组b中的数据输出到流中
+     - write(byte b[], int off, int len): 将数组b中从off指定的位置开始，长度为len的数据输出到流中
+     - flush(): 刷空输出流，并将缓冲区中的数据强制送出
+     - close(): 关闭流，释放资源。
