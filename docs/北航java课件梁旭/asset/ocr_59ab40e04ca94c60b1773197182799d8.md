# 5.3.3 对象的引用

+   - **引用对象的变量**
+   
+     格式：
+   
+     对象名.对象的变量;
+   
+     ```java
+     rect.origin = new Point(15, 37);
+     area = rect.height * rect.width;
+     ```

+   - **说明：**
+   - “.”称为成员运算符，在对象名和成员名之间起到连接作用，指明是哪个对象的成员。
+   - 可以像使用其它变量一样来使用对象的变量。例如：
+   
+     ```java
+     area = rect1.height * rect1.width;
+     ```
