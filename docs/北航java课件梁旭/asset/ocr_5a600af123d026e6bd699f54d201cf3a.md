# 一个简单的类

```
class Car{
    int car_number;
    void set_number(int car_num)
    {
        car_number=car_num;
    }
    void show_number()
    {
        System.out.println("My car No. is :"+car_number);
    }
}
public class CarDemo{
    public static void main(String args[])
    {
        Car DemoCar=new Car();
        DemoCar.set_number(3838);
        DemoCar.show_number();
    }
}
```

My car No. is : 3838
