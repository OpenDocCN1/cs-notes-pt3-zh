# 10.1 输入/输出流概述

+   - **10.1.2 I/O流类**
+   - 在Java开发环境中，主要是由包java.io中提供的一系列的类和接口来实现输入/输出处理。
+   - I/O类层次结构，图10.1。
+   - 按所读写的数据类型分两类：
+     - 字符流类（Character Streams）：用于向字符流读写16位二进制字符。多用于读写文本数据。
+     - 字节流类（Byte Streams）：用于读写字节流读写8位二进制的字节。一般地，字节流主要用于读写诸如图像或声音等的二进制数据。
+   - 基本I/O流类：InputStream和OutputStream类，都是字节流类，都是抽象类，不能直接创建对象。
