# 5.3.4 清除对象

+   - **finialize（）方法**
+     在一个对象被垃圾回收器回收之前，java解释器会自动调用对象的finalize（）方法。通常在该方法内包括了释放系统资源的代码段。

+   - **finalize()方法在类java.lang.Object中实现。**
+     如：

```
protected void finalize ( ) throws throwable
{
..... // clean up code for this class
super. finalize( ); //清除对象使用的所有资源，包括由于继
//承关系而获得的资源
}
```
