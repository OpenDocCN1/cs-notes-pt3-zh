# 7.4.3 播放声音

+   - Java支持的声音文件格式主要有：
+     - .au; .aif; .mid; .midi; .rfm; .wav; 等。

+   - 播放声音主要使用AudioClip接口。
+     - 使用getAudioClip(URL)方法获得AudioClip对象，其URL地址为由getCodeBase()方法得到的声音文件地址。(加入： import java.applet.AudioClip;)

+   - audioClip类有三种方法：
+     play():播放一次;
+     loop():循环播放;
+     stop():停止播放;
