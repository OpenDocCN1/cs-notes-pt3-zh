# 1.Thread类

+   - (2)静态方法
+     - void sleep(long millis): 让正在运行的线程休息millis毫秒再运行。产生InterruptException.

+   - (3)常用方法
+     - void start(): 启动已创建的线程对象。
+     - void run(): 最重要的方法，线程执行的起点，线程执行的具体操作都在此方法中编码。
+     - void destroy(): 销毁线程
+     - void stop(): 终止线程的执行
+     - void suspend() / void resume(): 挂起/恢复线程

+   - (4)静态常量
+     - 优先级表示：setPriority(int );
