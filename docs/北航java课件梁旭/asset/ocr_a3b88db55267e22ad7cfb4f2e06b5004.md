# ResultSet常用getXXX方法

| 返回值类型 | 方法名称 |
|---|---|
| boolean | getBoolean() |
| byte | getByte() |
| byte[] | getBytes() |
| java.sql.Date | getDate() |
| double | getDouble() |
| float | getFloat() |
| int | getInt() |
| long | getLong() |
| Object | getObject() |
| short | getShort() |
| java.lang.String | getString() |
| java.sql.Time | getTime() |

+   - 参数：int colIndex 或 String colName
