# 例7.5：

```
import java.awt.*;
import java.applet.*;
public class myapplet extends Applet{
    Image img1; //创建图片对象
    public void init()
    {
    img1=getImage(getDocumentBase(),"flag1.gif");
    //在init()中,给图片对象赋值
    }
    public void paint(Graphics g)
    {
    g.drawImage(img1,150,10,this); //输出图片
    }}
```
