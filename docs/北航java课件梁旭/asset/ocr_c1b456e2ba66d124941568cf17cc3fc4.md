# 方法的例子：

```
public class app03{
public static void main(String args[])
{
int n1,n2,s;
n1=10,n2=3;
s=SofRectangle(n1,n2); //方法调用,n1,n2是实际参数
System.out.println("以n1,n2为边的矩形面积为：" +s);
}
static int SofRectangle(int side1, int side2) //方法定义
{int s; //局部变量，以及： side1,side2是形式参数。
s=side1*side2;
return s; //方法的返回值
}}
```
