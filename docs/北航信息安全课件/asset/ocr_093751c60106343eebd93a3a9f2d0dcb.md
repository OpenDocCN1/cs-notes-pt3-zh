# 涉密项目管理（续）

# 项目流程：

+   1、首先填写《北京航空航天大学科研合同审批登记表》和《北京航空航天大学科技项目定密登记表》（或《北京航空航天大学科技项目定密审批表》），到所在学院科技管理部门办理审核手续；
+   2、经学院审查合格后，由项目负责人或课题组保密员到相关部门办理；到保密处办理涉密项目审批须提前半个工作日，审核设备、人员符合要求后给予办理；
+   3、所有参与涉密项目的研究生均要填写《北京航空航天大学研究生保密资格审查登记表》，其中接触涉密内容的研究生要定为涉密人员，对参与项目，但不接触涉密内容的研究生，导师须对其研究内容做降密处理；
+   4、研究生未定为涉密人员的，其学位论文内容不得涉密。
