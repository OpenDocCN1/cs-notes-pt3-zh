# 屏蔽子网防火墙

+   - 采用两个包过滤路由器和一个堡垒主机。
+   - 堡垒主机、信息服务器以及其他公用服务器放在“非军事区”网络中。“非军事区”网络处于因特网和内部网络之间。
+   - 内部路由器(阻塞路由器)位于内部网和“非军事区”之间，用于保护内部网不受“非军事区”和因特网的侵害，它执行了大部分的过滤工作。
+   - 外部路由器的一個主要功能是保护“非军事区”上的主机。  - 这种保护不是很必要，因为主要是通过堡垒主机来进行安全保护的。  - 外部路由器还可以防止部分IP欺骗，因为内部路由器分辨不出一个声称从“非军事区”来的数据包是否真的从“非军事区”来，而外部路由器很容易分辨出真伪。
