# 3.2.5 语句

语句是完整的句子或命令，JavaScript程序就是一些语句的集合。语句的形式多种多样：

+   1、表达式语句
+   在JavaScript中，最简单的语句莫过于表达式了。例如：
+   var a=0; a++;
+   2、复合语句
+   将一些语句用花括号括起来，就形成了一个复合语句，这样它就可以出现在需要使用单个语句的地方。例如：
+   {x = Math.PI; cx = Math.cos(x);}
+   注意：花括号的后面不需要有分号，而且这不是不良习惯。

```
var a=0; a++;
```

```
{x = Math.PI; cx = Math.cos(x);}
```
