# 3.2.2 数据类型和值

（2）转义字符

当字符串中需要无法直接出现的字符时（例如：字符串必须在一行中写完，因此不能直接出现换行符），就需要使用所谓的转义字符（转义：意思转变了）。转义字符以反斜线“\”开始，常用的转义字符包括：

| 转义字符 | 意义 | 转义字符 | 意义 |
|---|---|---|---|
| \0 | 空字符 | \r | 回车符 |
| \b | 退格符 | \" | 双引号 |
| \t | 水平制表符 | \' | 单引号 |
| \n | 换行符 | \\ | 反斜线 |
| \v | 垂直制表符 | \xXX | 两位16进制数XX表示的Latin-1字符 |
| \f | 换页符 | \uXXXX | 四位16进制数表示的Unicode字符 |

注意：如果“\”后面的字符不匹配，那就构不成转义字符，反斜线将被忽略。例如：\#等于#。
