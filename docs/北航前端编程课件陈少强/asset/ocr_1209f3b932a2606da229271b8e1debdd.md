# 3.2.5 语句

```
var obj = {x:1, y:2, z:3};
var ary = [1, 2, 3];
for(var prop in obj)
    document.write("name:"+prop+ "; value:"+obj[prop]+"<br>");
for(var prop in ary)
    document.write("index:"+prop+ "; value:"+ary[prop]+"<br>");
```

# 9、标签语句

任何语句都可以通过在它前面加上标识符和冒号来标记，成为带有标签的语句。这样在程序的任何地方都可以通过这个标签来引用它。由于标签名不同于变量名和函数名，所以标签名可以和变量或函数同名，且互不影响。标签语句的语法为：

标签： 语句

例如：

```
p1: for(i=0; i<10;i++){...};
```
