# 4.4.3 动画效果

其中的.is()方法前面已经讲过：它可接受一个选择符表达式，只要jQuery对象中有一个元素与选择符匹配，就返回true。这里:hidden是一个jQuery的自定义伪类选择符，用来检查匹配元素的可见性。

其实jQuery还提供了实现复合效果的方法。

例如，使用单参数的.toggle()方法就可以实现交替显示，效果与交替调用.show()和.hide()方法一样，而且也可以有时时间参数。

另一个复合方法是.slidetoggle()，该方法的效果与交替调用.slideDown()和.slideUp()方法一样，通过调节高度来显示或隐藏元素。
