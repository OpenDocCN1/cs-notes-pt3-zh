# 3.2.2 数据类型和值

+   1）对象的两种创建方式：
+   ① 使用构造函数。例如：
+   var o = new Object();
+   var now = new Date();
+   ② 使用对象常量初始化。例如：
+   var point = {x:2.3, y:-1.2}; // “=” 右边为对象常量
+   var rectangle = {upperLeft:{x:2,y:2},
+       lowerRight:{x:4,y:4}}; //嵌套
+   var square = {upperLeft:{x:point.x, y:point.y},
+       lowerRight:{x:(point.x+size),y:(point.y+size)}}; //使用表达式
+   2）对象的的使用
+   对象创建后，就可以使用它的属性了。例如：
+   point.z = 3.6; //添加属性
+   x=square.upperLeft.x; //使用属性
