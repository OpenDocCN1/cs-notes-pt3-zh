# 2.8 CSS页面布局与定位

1) 两列自适应宽度

```
<!DOCTYPE ...>
<!--例： 2-6.html-->
<html>
<head>
<title>网络编程技术</title>
<link rel="stylesheet" type="text/css" href="2-6.css">
</head>
<body>
<div id="left">左列</div>
<div id="right">右列</div>
</body>
</html>
```

```
/*例： 2-6.CSS*/
#left{
background-color:#ccc;
border:2px solid #333;
width:30%;
height:300px;
float:left;
}
#right{
background-color:#ccc;
border:2px solid #333;
width:60%;
height:300px;
float:left;
}
```
