# 3、页面(page)

页面是jQuery Mobile的主要单位。一个典型的页面包括页头、内容和页脚三个部分。通常只有内容部分是必不可少的。各个部分使用data-role属性指定。

```
```html
<div data-role="page">
    <div data-role="header">
    </div>
    <div data-role="content">
    </div>
    <div data-role="footer">
    </div>
</div>
```
```

当然，可以为每个部分指定不同的色样。
