# 2.4 CSS的使用方式

# 2.4.3 导入外部样式表：

将CSS文件导入到内部样式表，见下例，2-3.html：

```
<html>
<head>
<title>网络编程技术</title>
<style type="text/css">
@import url(2-3.css); <!--注意分号一定要-->
</style>
</head>
<body>
<h2>前台技术</h2>
<p>HTML</p>
<p>CSS</p>
<p>JavaScript</p>
</body>
</html>
/*2-3.css*/
h2{
font-size:30pt;
background-color:rgb(0,255,0)
}
p{background-color:rgb(255,0,0)}
```
