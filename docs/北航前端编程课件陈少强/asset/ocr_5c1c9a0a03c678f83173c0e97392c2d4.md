# 5.4.4 使用图片

每一行都可以用指定的图片来标记，而且可以添加两种不同类型的图片：图标和缩略图。

# 1、行图标

行图标是显示在列表项左侧的图标，而不是交互行右侧的箭头或分裂行列表中的图标。

行图标是位于标记中的一个 16*16 像素的图片（不是 jQuery Mobile 中所说的图标），由 ui-li-icon 类定义。例如：

```
```html
<li>
    <img src="/icons/email.png" class="ui-li-icon">
    Send by e-mail
```
```

行图标通常用于对可做操作的提示，例如：删除、编辑、共享等。
