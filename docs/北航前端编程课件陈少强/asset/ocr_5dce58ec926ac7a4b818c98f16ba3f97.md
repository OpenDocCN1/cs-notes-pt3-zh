# 2.3 层叠样式表（CSS）

网页设计最初是用HTML标记来定义网页的内容和简单效果。主要侧重于定义内容，并没有过多涉及排版和界面效果。当网页的页面变得越来越重要时，HTML就难以满足需求了。CSS的出现解决了这个问题。

CSS是Cascading Style Sheets（层叠样式表）的简称，也叫样式表。它专门用来实现排版及网页元素（由HTML标记表示）的显示样式。

由于有了CSS，实现了内容与表现的分离，即：

+   - HTML（或XHTML）用来表示网页内容及结构。
+   - CSS用来决定网页内容的排版和显示方式。
