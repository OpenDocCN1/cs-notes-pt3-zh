# 4.2.4 jQuery自定义选择符

```
/* 4-2-2.css */
.alt {
    background-color: #ccc;
}
/* 4-2-2.js */
$(document).ready(function() {
    //$('tr:even').addClass('alt');
    $('tr:nth-child(odd)').addClass('alt');
    $('td:contains(Henry)').addClass('highlight');
});
```

**注意：**

+   ① 这里使用的 **:nth-child()** 是 jQuery 中唯一从 1 开始计数的选择符。它的参数可以是数值、**odd** 或 **even**。
+   ② **contains()** 选择符区分大小写。
