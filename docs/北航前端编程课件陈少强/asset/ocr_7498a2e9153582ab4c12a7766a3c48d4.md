# 2.4 CSS的使用方式

# 2.4.1 内嵌样式：

即将样式作为标记的style属性值直接写在标记内，样式之间以“；”分割。见下例，2-1.html：

```
<!DOCTYPE...>
<html>
    <head>
        <title>网络编程技术</title>
    </head>
    <body>
        <h2 style="font-size:20pt">前台技术</h2>
        <p style="background-color:rgb(255,0,0)">HTML</p>
        <p style="background-color:#00ff00">CSS</p>
        <p style="background-color:#00f">JavaScript</p>
    </body>
</html>
```
