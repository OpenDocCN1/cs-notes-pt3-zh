# 3.2.4 表达式和运算符

2）运算数的类型

不同的运算符需要不同类型的运算数，计算结果的数据类型也不尽相同。在有尽可能的情况下，JavaScript会将运算数转换为适当的类型。例如：

```
"a**b"; //非法
```

```
"3**5"; //合法，结果为数字15
```

3）运算符的优先级

优先级控制执行操作的顺序。考虑表达式：

```
w = x+y*z;
```

由于乘法运算符“*”的优先级高于加法运算符“+”的优先级，所以先执行乘法，再执行加法。赋值运算符“=”的优先级最低，所以在右边的操作都结束后才会被执行。

使用括号可以提高运算符的优先级。例如：

```
w = (x+y)*z;
```

运算符的优先级定义符合常规，必要时可查阅手册。
