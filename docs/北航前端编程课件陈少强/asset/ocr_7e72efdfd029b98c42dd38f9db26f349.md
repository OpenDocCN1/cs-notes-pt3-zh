# 5.5.2 表单元素

8、轻弹切换开关

这种开关是一个布尔值（true或false）选择器。功能上与复选框类似，但用户界面完全不同。

它是第一个需要制定角色的表单控件： data-role="slider"。它是一个 select元素，其中只包含两个option子元素，第一个值为false，第二个值为true。

不指定域容器的话，开关将占满整个页面宽度。更常见的情况是将其放入一个域容器中。例如：

```
<label for="updated">Receive updates</label>
<select id="updated" name="updated" data-role="slider">
<option value="no">No</option>
<option value="yes">Yes</option>
</select>
```
