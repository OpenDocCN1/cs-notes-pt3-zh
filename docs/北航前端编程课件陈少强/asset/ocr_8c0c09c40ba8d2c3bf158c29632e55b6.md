# 2.6 CSS语法结构

# 2.6.1 CSS选择器

+   1）*：通用选择器举例：
+      p *{color:#ff0000}
+      p标记内的所有元素的文字都是红色。
+   2）标记选择器举例：
+      p {color:#ff0000}
+      p标记内的文字为红色。
+   3）群组选择器举例：
+      h1,h2,h3,p{font-size:12px; font-family:arial}
+      同时为多种选择器定义字体及大小
+   4）包含选择器举例：
+      h2 p{font-weight:bold}
+      为h2标记内的p元素（可能相隔几层）设置字体的粗细
