# 2.6.1 CSS选择器

+   5）子元素选择器举例：
+   
+   ```css
+   h2>p{font-weight:bold}
+   ```
+   
+   为以h2标记为父元素的p标记（只相差一级）设置字体的粗细

+   6）id选择器举例：
+   
+   ```css
+   #content{font-size:14px} /* <div id="content">...</div> */
+   ```
+   
+   为元素“content”设置字体大小。

+   7）class选择器举例：
+   
+   ```css
+   .p1 {                  /* <div class="p1">...</div> */
+   margin:10px;           /* <h2 class="p1">...</h2> */
+   background-color:blue /* <p class="p1">...</p> */
+   }
+   ```
+   
+   为具有属性class="p1"的元素（可能不仅属于p1）设置外边距和背景色。
