# 3.3.1 Web浏览器中的JavaScript

# 3) 事件处理程序

由于客户端JavaScript的事件是由HTML元素引发的，因此事件处理程序被定义为这些元素的属性值。例如：

```
```html
<html><!--3-3.html-->
<head>
    <title>Welcome to Sina!</title>
</head>
<body>
    <a href="http://www.sina.com"
       onclick="alert('You are cheated!'); return false;">
       Welcome to Sina!
    </a>
</body>
</html>
```
```
