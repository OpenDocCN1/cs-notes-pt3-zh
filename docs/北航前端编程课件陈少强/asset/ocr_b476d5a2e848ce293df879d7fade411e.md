# 4、复合效果

前面的例子经过修改可以实现显示与隐藏的切换。在例4-4-6.js中：

```
$(document).ready(function() {
    var $firstPara = $('p').eq(1);
    $firstPara.hide();
    $('a.more').click(function() {
        if ($firstPara.is(':hidden')) {
            $firstPara.fadeIn('slow');
            $(this).text('read less');
        }
        else {
            $firstPara.fadeOut('slow');
            $(this).text('read more');
        }
        return false;
    });});
```
