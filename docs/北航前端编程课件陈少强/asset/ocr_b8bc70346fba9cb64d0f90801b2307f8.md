# 5.4.7 使用计数气泡

计数气泡是一个在行的右侧显示的包含数字的圆圈，通常用于显示该交互行包含多少项。

要使用计数气泡，只需在列表项（li）中包含任意带ui-li-count类的html元素，例如span元素。例如：

```
```html
<li><a href="inbox.html">Inbox</a>
    <span class="ui-li-count">86</span>
```
```
