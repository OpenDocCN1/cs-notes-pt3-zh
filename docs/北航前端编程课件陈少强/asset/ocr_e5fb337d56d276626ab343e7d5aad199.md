# 5.5.2 表单元素

## 7、滑块
滑块用于输入处于某个范围的数字的值。它会提供一个接受数字的文本输入框，右侧会有一个水平滑块。滑块是一个 `<input type="range">` 的 HTML5 控件，它接受 min、max 以及 step 属性值。

可以使用 data-theme 和 data-track-theme 属性来分别控制滑块左右两个部分的色样。例如：

```
```html
<div data-role="fieldcontainter">
    <label for="qty">Quantity:</label>
    <input type="range" id="qty" name="qty" min="1" max="100"
           value="5" data-theme="e" data-track-theme="b">
</div>
```
