# 4.4.3 动画效果

# 2、淡入淡出

带速度参数的hide()和show()方法是在同时改变元素的高度、宽度和不透明度，但这种效果有时显得过于花哨。

为此jQuery提供了.fadeIn()和.fadeOut()方法。

在例4-4-4.js中：

```
$(document).ready(function() {
  $('p').eq(1).hide();
  $('a.more').click(function() {
    $('p').eq(1).fadeIn('slow');
    $(this).hide();
    return false;
  });
});
```

这两个方法与hide()和show()方法类似，但渐变的只有不透明度。
