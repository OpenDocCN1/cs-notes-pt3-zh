# 4.4.3 动画效果

# 3、滑上和滑下

使用.fadeIn()和.fadeOut()，有时会感到文档跳了一下。jQuery提供了.slideDown()和.slideUp()方法，它们仅渐进改变文档的高度，用于实现垂直滑入、滑出的效果。

在例4-4-5.js中：

```
$(document).ready(function() {
  $('p').eq(1).hide();
  $('a.more').click(function() {
    $('p').eq(1).slideDown('slow');
    $(this).hide();
    return false;
  });
});
```
