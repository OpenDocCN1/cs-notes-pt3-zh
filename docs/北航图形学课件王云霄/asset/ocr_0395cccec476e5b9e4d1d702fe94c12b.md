下半部分:(x_p, y_p),下一个点为(x_p, y_p -1)或者(x_p +1, y_p -1)
M = (x_p +0.5, y_p -1)
 d_2 = F(x_p +0.5, y_p -1) = b^2 (x_p +0.5)^2 + a^2 (y_p -1)^2 - a^2 b^2
 d_2 < 0,中点在椭圆内，取右下方像素
 d_2' = F(x_p +1.5, y_p -2) = b^2 (x_p +1.5)^2 + a^2 (y_p -2)^2 - a^2 b^2
 = d_2 + b^2 (2x_p +2) + a^2 (-2 y_p +3)
 d_2 ≥ 0,中点在椭圆外，取正下方像素
 d_2' = F(x_p +0.5, y_p -2) = b^2 (x_p +0.5)^2 + a^2 (y_p -2)^2 - a^2 b^2
 = d_2 + a^2 (-2 y_p +3)
 d_2初值 d_2^0 = F(x, y) = (b(x +0.5))^2 + (a(y -1))^2 - a^2 b^2
 (x, y)为交界点
