# 可以用齐次坐标验证，有：

$$[x\quad y\quad z\quad 1]\begin{bmatrix}1&0&0&0\\0&1&0&0\\\frac{x_0}{d}&\frac{y_0}{d}&0&\frac{1}{d}\\0&0&0&1\end{bmatrix}=\left[x+\frac{x_0z}{d}\quad y+\frac{y_0z}{d}\quad 0\quad \frac{z}{d}+1\right]$$

# 将结果规范化后得到齐次坐标为：

$$\left[x_0+\frac{d\bullet(x-x_0)}{z+d}\quad y_0+\frac{d\bullet(y-y_0)}{z+d}\quad 0\quad 1\right]$$
