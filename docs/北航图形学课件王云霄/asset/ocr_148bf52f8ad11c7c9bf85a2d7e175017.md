扫描线 y=α：
AET表中有AB, AC，
到AB时，Flag<sub>ABC</sub>=1，AB到AC一段用ABC的颜色作填充
到AC时，Flag<sub>ABC</sub>=0，

扫描线 y=β：
AET表中有四项AB, AC, FD, FEF，
到AB时，Flag<sub>ABC</sub>=1，AB到AC一段用ABC的颜色作填充
到AC时，Flag<sub>ABC</sub>=0，AC到FD之间填充背景色
到FD时，Flag<sub>DEF</sub>=1，FD到FE之间填充DEF颜色
到FE时，Flag<sub>DEF</sub>=0

扫描线 y=γ：
AET表中有四项AB, DE, CB, FE
到AB时，Flag<sub>ABC</sub>=1，AB到DE之间填ABC的颜色
到DE时，Flag<sub>DEF</sub>=1，做深度比较，求（x′，γ）的深度

```
$$z_{ABC}=\frac{-A_1x'-B_1y-D_1}{C_1},\quad z_{DEF}=\frac{-A_2x'-B_2y-D_2}{C_2}$$
```

若 z<sub>DEF</sub>＜z<sub>ABC</sub>，则DE到CB之间填DEF的颜色

到CB时，Flag<sub>ABC</sub>=0，BC到EF之间填DEF颜色
到FE时，Flag<sub>DEF</sub>=0
