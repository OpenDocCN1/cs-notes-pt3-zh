# 第二章 作业

P₂₆₋₃ 方法一：分几种情况来讨论

+   (1) 若 |m|<1, 则若 x₁ > x₂, 则 x₁ ↔ x₂, y₁ ↔ y₂
+   若 |m|>1, 则若 y₁ > y₂, 则 x₁ ↔ x₂, y₁ ↔ y₂

+   (2) 处理特殊情况(水平垂直线)
+   若 x₁ = x₂, 则 yₛ = min(y₁, y₂), yₑ = max(y₁, y₂)
+   for(y = yₛ; y <= yₑ; y++) 垂直线段
+   setpixel(x, y)
+   若 y₁ = y₂, 则 xₛ = min(x₁, x₂), xₑ = max(x₁, x₂)
+   for(x = xₛ; x <= xₑ; x++) 水平线段
+   setpixel(x, y)
