# 当$P<0$时，应选H点

$p_{i+1}=p_i+4x_i+6$

$\frac{p_{i+1}-1}{2}=\frac{p_i-1+4x_i+6}{2}$，令$e_i=\frac{p_{i+1}-1}{2}$，$e_{i+1}=e_i+2x_i+1+2$

令$u_i=2x_i+1$，$e_{i+1}=e_i+u_i+2$

$u_{i+1}=2x_{i+1}+1=2x_i+1+2=u_i+2$

$v_{i+1}=v_i+2$；

$p\geq0$时，令$e=\frac{p-1}{2}$，$e\geq0$时$v_{i+1}=v_i+4$，$u_{i+1}=u_i+2$

$p<0$时，$e<0$时$v_{i+1}=v_i+2$，$u_{i+1}=u_i+2$

$p=3-2R,e=\frac{p-1}{2}=1-R,p=2e+1$

$x_0=0,y_0=R,u_0=2x_0+1,v_0=2(x_0-y_0)+1=1-2R$
