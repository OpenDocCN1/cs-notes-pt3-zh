# 验证Bezier曲线分成前后两段的正确性，

P₀的系数为例，验证两端它的系数是相等的。

左端 = B₀,₃(t) = (1 - t)³
0 ≤ t ≤ 1/2

右端 = B₀,₃(2t) + 1/2 B₁,₃(2t) + 1/4 B₂,₃(2t) + 1/8 B₃,₃(2t)

= (1 - 2t)³ + 1/2 · 3 · 2t · (1 - 2t)² + 1/4 · 3 · (2t)² (1 - 2t) + 1/8 (2t)³

= (1 - 2t)³ + 3·t·(1 - 2t)² + 3·t²·(1 - 2t) + t³

= (1 - 2t + t)³

= (1 - t)³
1/2 ≤ t ≤ 1

右端 = 1/8 B₀,₃(2t - 1) = 1/8 (1 - (2t - 1))² = (1 - t)³
