# P<sub>26-7</sub> 填写ET表

输入：多边形的逆时针顶点序列

输出：ET表

算法，设输入顶点序列为P<sub>0</sub>, P<sub>1</sub>, …, P<sub>n</sub>的n+1个点

+   1. **[初始化]** ET各项置为空，P<sub>n+1</sub>←P<sub>0</sub>
+      S←P<sub>0</sub>, T←P<sub>1</sub>, Q←P<sub>n</sub>, U←P<sub>2</sub>, i←1
+   2. **[循环]** 若i>n+1，则算法结束，否则做以下各步
+      2.1 **[处理水平边和非极值点]**
+      若S.y=T.y，记录T，goto 2.3/P<sub>i-1</sub>P<sub>i</sub>是水平边

若Q.y≤S.y<T.y

则S.x←S.x+(T.x−S.x)/(T.y−S.y)，S.y←S.y+1

若S.y>T.y≥U.y，则T.x←T.x+(T.x−S.x)/(T.y−S.y)，T.y←T.y+1
