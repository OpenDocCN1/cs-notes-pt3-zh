# 两线段AB和CD交点的算法

1.〔计算行列式〕
Δ ← (x_b - x_a)(y_c - y_d) - (x_c - x_d)(y_b - y_a)
若 Δ =0, 则两线段重合或平行, 可算做无交点, 算法结束;

2.〔计算交点参数〕
λ ← ((x_c - x_a)(y_c - y_d) - (x_c - x_d)(y_c - y_a)) / Δ
若 λ <0 或 λ >1, 则无交点, 算法结束;
μ ← ((x_b - x_a)(y_c - y_a) - (x_c - x_a)(y_b - y_a)) / Δ
若 μ <0 或 μ >1, 则无交点, 算法结束;

3.〔计算交点〕
x ← x_a + λ (x_b - x_a), y ← y_a + λ (y_b - y_a), 输出交点 (x, y) 后算法结束;
