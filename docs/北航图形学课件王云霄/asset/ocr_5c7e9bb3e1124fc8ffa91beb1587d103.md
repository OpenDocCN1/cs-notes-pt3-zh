# 法向（A,B,C）

a......设D≠0,又∵A,B,C不能全为0,设A≠0,则（-D/A,0,0）是平面上的点

T(D/A,0,0)

b 做旋转变换使平面的法向量与z轴重合

Rₓ(α),令v=√(B²+C²),cosα=C/v,sinα=B/v

Rᵧ(β),令d=√(A²+B²+C²),cosβ=v/d,sinβ=-A/d

H = T(D/A,0,0) • Rₓ(α) • Rᵧ(β) = 
⎡ v/d   0   -A/d   0 ⎤
⎢ AB/(vd) C/v B/d 0 ⎥
⎢ AC/(vd) -B/v C/d 0 ⎥
