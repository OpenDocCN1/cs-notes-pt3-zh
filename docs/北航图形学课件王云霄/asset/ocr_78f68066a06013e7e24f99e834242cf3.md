# 最小三角剖分问题的求解适合采用动态规划方法。

顶点坐标序列V₀, V₁, ..., Vₙ₋₁给出的凸n边形, 求最小三角剖分的动态规划算法的填表过程：

+   1. 对j≤3, 对i=0到n-1, 令Cᵢ,ⱼ=0;
+   2. 对j=4到n-1, 循环做: 对i=0到n-1循环做:
+      2.1 对k=1到j-2
+      计算Cᵢ, k+1 + Cᵢ+k, s-k + D(VᵢVᵢ+k) + D(Vᵢ+kVᵢ+j-1)
+      2.2 Cᵢ, j ← 2.1步计算各值中的最小值;

以上过程完成填表, 其计算是利用公式Cᵢs。
