# Advance

S←P_{i-1}P_i × Q_{j-1}Q_j的z分量;分两种情况处理,然后算法就结束;

+   1. 若S≥0（前四种情况）,则做
+   若P_i在Q_{j-1}Q_j左并且Q_j在P_{i-1}P_i左,或者P_i在Q_{j-1}Q_j右并且Q_j在P_{i-1}P_i左（P前进）,则i前进1,否则j前进1（Q前进）;

+   2. 若S<0（后四种情况）,则做
+   若P_i在Q_{j-1}Q_j右并且Q_j在P_{i-1}P_i左,或者P_i在Q_{j-1}Q_j右并且Q_j在P_{i-1}P_i右（P前进）,则i前进1,否则j前进1（Q前进）;
+   算法中"i前进1",指若i<L,则前进1是i+1;若i=L,则前进1是1。这因为多边形P是首尾相接的。类似地"j前进1",j<m时是j+1;j=m时是1。i总在多边形P上前进,j在Q上前进。
