# 简单多边形包含性检验的算法：

+   1. （准备）xn←x0, yn←y0, m←−1, i←0;
+   2. （排除必不相交情形）若下列条件有一个成立，则到4。
+      2.1 xp<xi 并且 xp<xi+1：
+      2.2 xp≥xi 并且 xp≥xi+1；
+      2.3 yp<yi 并且 yp<yi+1；
+   3. （计算交点）y=yi+(xp−xi)(yi+1−yi)/(xi+1−xi)，分两种情形：
+      （1）若y=yp，则点P在多边形边界上，算法结束；
+      （2）若y<yp，则m←(−1)•m；
+   4. （结束判断）i←i+1，若i<n”，则返回到2，否则算法结束，此时若m=−1则点P在多边形外部，m=1则在内部。
