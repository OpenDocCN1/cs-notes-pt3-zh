# 算法的步骤如下：

+   1. [初始化]将堆栈置为空，将给定的种子点（x, y）压入堆栈

+   2. [出栈]如果堆栈为空，算法结束，否则取栈顶元素（x, y）作为种子点

+   3. [区段填充]从种子点（x, y）开始沿当前扫描线向左右两个方向逐个像素进行填充，直到遇到边界点为止

+   4. [定范围]用x l和xr分别表示在步骤3中填充的区段的左右两个端点的横坐标

+   5. [进栈]对当前扫描线上下相邻的两条扫描线从右向左的确定位于[x l, x r]区域内的像素段。如果区域内的像素已经填充或为边界则转到步骤2，否则取像素段的右端点作为种子点，压入堆栈，再转到步骤2。
