(3)  -1 < m < 0
(x_i, y_i) → (x_i + 1, y_i) 或者 (x_i + 1, y_i - 1)
|d₁| = |y - y_i| = y_i - y = y_i - (m x_{i+1} + b)
|d₂| = y - (y_i - 1) = m x_{i+1} + b - (y_i - 1)
|d₁| - |d₂| = -2 m x_{i+1} - 2 b + 2 y_i - 1
p_i = Δx (|d₁| - |d₂|) = -2 Δy x_i + 2 Δx y_i - 2 Δy - 2 b Δx - Δx
若 p_i ≥ 0， 下一个点应取 (x_i + 1, y_i - 1)
若 p_i < 0， 下一个点应取 (x_i + 1, y_i)
p_{i+1} - p_i = -2 Δy (x_{i+1} - x_i) + 2 Δx (y_{i+1} - y_i)
若 p_i ≥ 0, p_{i+1} = p_i - 2 Δy - 2 Δx
若 p_i < 0, p_{i+1} = p_i - 2 Δy
∵ -1 < m < 0, m = Δy / Δx, Δy < 0
p_i ≥ 0, p_{i+1} = p_i + 2 |Δy| - 2 |Δx|, 取 y_i - 1
若 p_i < 0, p_{i+1} = p_i + 2 |Δy|, 取 y_i
