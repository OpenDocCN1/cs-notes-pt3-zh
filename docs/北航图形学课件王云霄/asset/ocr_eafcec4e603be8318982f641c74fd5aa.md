# 第三节 计算机图形学的应用及发展趋势

# 1. 计算机图形学的主要应用领域

+   (1) 用户接口 (软件人性化设计)
+   (2) CAD/CAM. (精确易修改)
+   (3) 计算机仿真与动画 (电影特技和飞行员的太空模拟驾驶舱)
+   (4) 制图学方面 (人口分布图, 气象图, 股票走势图等)
+   (5) 过程控制 (铁路, 机场调度)
+   (6) 办公自动化 (多媒体技术, 可视电话, 视频会议)
+   (7) 艺术模拟 (艺术创作, 传统油画, 中国国画, 书法等)
+   (8) 科学计算可视化 (科学计算结果图形化)
+   (9) 虚拟现实 (虚拟校园模拟)
+   (10) 教育领域
