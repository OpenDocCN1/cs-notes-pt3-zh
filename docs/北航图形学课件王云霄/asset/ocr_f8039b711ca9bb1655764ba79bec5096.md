# P₂₆₋₆结合Bresenham画圆算法与行扫描填充算法

P₂₆₋₇

![](bbox=[0.18, 0.22, 0.48, 0.57])

d_H = (x_i + 1)² + y_i² - R²

d_D = R² - (x_i + 1)² - (y_i - 1)²

p_i = d_H - d_D

# 当P≥0时，应选D点

p_{i+1} = p_i + 4(x_i - y_i) + 10

(p_{i+1} - 1)/2 = (p_i - 1 + 4(x_i - y_i) + 10)/2, 令 e_i = (p_{i+1} - 1)/2, e_{i+1} = e_i + 2(x_i - y_i) + 1 + 4

令 v_i = 2(x_i - y_i) + 1, v_{i+1} = 2(x_{i+1} - y_{i+1}) + 1 = 2(x_i - y_i) + 1 + 4 = v_i + 4
