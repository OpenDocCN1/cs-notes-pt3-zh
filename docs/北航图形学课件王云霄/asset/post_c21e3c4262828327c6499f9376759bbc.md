## 第四节 Bezier曲线和曲面

### 1. Bezier曲线定义

给出型值点 P₀，P₁，…，Pₙ，它们所确定的 n 次 Bezier 曲线是：

$$P(t)=\sum_{i=0}^{n}B_{i,n}(t)\cdot P_i,\quad 0\le t\le 1$$

$B_{i,n}(t)$ 是Bernstein多项式，调和函数

$B_{i,n}(t)=C_n^i t^i (1-t)^{n-i}=\frac{n!}{i!(n-i)!}t^i\cdot(1-t)^{n-i}$

$i=0,1,\cdots,n$

涉及到的0!及0⁰，按约定均为1。

### 当n=1时

$P(t)=(1-t)P_0+tP_1\quad 0\le t\le1$

一次 bezier 曲线是直线段

### 在n=2时

P(t) = (1−t)² P₀ + 2t(1−t) P₁ + t² P₂

= (t²  t  1) ⎡1  −2  1⎤ ⎡P₀⎤
                 ⎢−2  2  0⎥ ⎢P₁⎥ ,  0 ≤ t ≤ 1
                 ⎣1   0  0⎦ ⎣P₂⎦

二次bezier曲线是抛物线

### 混和函数 $B_{i,n}(t)=C_n^i t^i (1-t)^{n-i}$ 的性质： $(0\le t\le 1)$

- ① $B_{i,n}(t)=\begin{cases}0 & t=0,1\text{且}i\neq0,n\text{时}\\\neq0 & t\neq0,1\text{时}\end{cases}$

- ② $0\le B_{i,n}(t)\le 1$

- ③ $B_{i,n}(t)=B_{n-i,n}(1-t)$

- ④ $\sum_{i=0}^{n} B_{i,n}(t)=1$

### 2. Bezier曲线的一些重要性质：

- ① 端点性质：$P(0)=P_0$，$P(1)=P_n$，曲线通过起点和终点。

- ② $P'(0)=n(P_1-P_0)$，$P'(1)=n(P_n-P_{n-1})$

$P′(t)=∑_{i=0}^{n} \frac{n!}{i!(n-i)!}(i·t^{i-1}·(1-t)^{n-i}-(n-i)·t^{i}·(1-t)^{n-i-1})P_i$
$= -\frac{n!}{(n-1)!}(1-t)^{n-1}P_0 + \frac{n!}{(n-1)!}(1-t)^{n-1}P_1$
$- \frac{n!}{(n-2)!}t(1-t)^{n-2}P_1 + \frac{n!}{(n-2)!}t(1-t)^{n-2}P_2 - \frac{n!}{2!(n-3)!}t^2(1-t)^{n-3}P_2$
$+⋯+ \frac{n!}{(n-2)!}t^{n-2}(1-t)P_{n-1} - \frac{n!}{(n-1)!}t^{n-1}P_{n-1} + \frac{n!}{(n-1)!}t^{n-1}P_n$
$= ∑_{i=0}^{n-1} \frac{n!}{i!(n-i-1)!}·t^{i}·(1-t)^{n-i-1}·(P_{i+1}-P_i)$

### ④曲线的凸包性

对给定的型值点P₀, P₁, ..., Pₙ

点集M = { Σᵢ₌₀ⁿ λᵢ Pᵢ | 0 ≤ λᵢ ≤ 1, Σᵢ₌₀ⁿ λᵢ = 1 }

称作n+1个点张成的凸包

Σᵢ₌₀ⁿ Bᵢ,ₙ(t) = 1, 0 ≤ Bᵢ,ₙ(t) ≤ 1

0 ≤ i ≤ n, 0 ≤ t ≤ 1

### 3. 三次Bezier曲线光滑拼接的条件

P₀P₁P₂P₃和Q₀Q₁Q₂Q₃，两个Bezier多边形

- ① 曲线在连接点处C⁰连续的条件是P₃=Q₀

- ② 曲线在连接点处G¹连续，Q'₀=aP'₃

Q'₀=3(Q₁-Q₀)， P'₃=3(P₃-P₂)，Q₁-Q₀=a(P₃-P₂)

于是知, P''(1)=6P₁−12P₂+6P₃, Q''(0)=6Q₀−12Q₁+6Q₂

要求, P''(1)=Q''(0)即 Q₀−2Q₁+Q₂=P₃−2P₂+P₁

注意到Q₀=P₃, 由此得：

Q₂−P₁=2(Q₁−P₂)⇒Q₁P₂//Q₂P₁且|Q₁P₂|=½|Q₂P₁|
