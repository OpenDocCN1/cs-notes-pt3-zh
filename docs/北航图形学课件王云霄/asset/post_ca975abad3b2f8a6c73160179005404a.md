
左端 = Σ (i=0 to n) B_{i,n}(t)·P_i
= C_n^0 (1 - t)^n P_0 + C_n^1 t^1 (1 - t)^{n-1} P_1 + … + C_n^n t^n P_n

右端 = (1 - t)· Σ (i=0 to n-1) C_{n-1}^i t^i (1 - t)^{n-i-1}·P_i + t· Σ (i=0 to n-1) C_{n-1}^i t^i (1 - t)^{n-i-1}·P_{i+1}
= (1 - t)[ (1 - t)^{n-1}·P_0 + Σ (i=1 to n-1) C_{n-1}^i t^i (1 - t)^{n-i-1}·P_i ]
+ t[ Σ (i=1 to n-1) C_{n-1}^{i-1} t^{i-1} (1 - t)^{n-i}·P_i + t^{n-1}·P_n ]
= (1 - t)^n P_0 + Σ (i=1 to n-1) C_{n-1}^i t^i (1 - t)^{n-i}·P_i + Σ (i=1 to n-1) C_{n-1}^{i-1} t^i (1 - t)^{n-i}·P_i + t^n·P_n
= (1 - t)^n·P_0 + Σ (i=1 to n-1) (C_{n-1}^i + C_{n-1}^{i-1}) t^i (1 - t)^{n-i}·P_i + t^n·P_n
= Σ (i=0 to n) C_n^i t^i (1 - t)^{n-i}·P_i
= 左端

P₀,ₙ(t) = P₀,ₙ₋₁(t) + t(P₁,ₙ(t) − P₀,ₙ₋₁(t))

设控制点 $P_0, P_1, \cdots P_n$, $t$ 的增量为 $0 \le \Delta t \le 1$
$t = 0, \cdots 1, t = t + \Delta t$
(1) $m \leftarrow n, i = 0 \cdots n, R_i \leftarrow P_i$
(2) 若 $m > 0$, 做 $(i)$ 至 $(iii)$
$(i) i = 0 \cdots m - 1, Q_i = R_i + t \left( R_{i+1} - R_i \right)$
$(ii) m \leftarrow m - 1$
$(iii) i = 0 \cdots m, R_i \leftarrow Q_i$
$goto(2)$
(3) $P(t) \leftarrow R_0$

## b. 分裂法

思想：将原控制点集分为两个点数相同的新控制点集，分别对应原曲线的前半段和后半段，新控制点集比原控制点集更接近直线，分裂过程继续进行，控制点集会迅速向曲线靠近，当满足某个允许的界限时，可依次连接各点的折线来表示曲线

设控制点序列P₀, P₁, …, Pₙ确定的n次Bezier曲线是P(t)，用如下递归方式计算另一组点集：

Pᵢᵏ = { Pᵢ, k=0, i=0,1,…,n
 1/2(Pᵢᵏ⁻¹+Pᵢ₋₁ᵏ⁻¹), k=1,2,…,n, i=k,k+1,…,n }

如果令Pₐ(s)和Pᵦ(s)分别是以控制点序列P₀⁰,P₁¹,…,Pₙⁿ，Pₙⁿ,Pₙ₋₁ⁿ⁻¹,…,P₀⁰确定的Bezier曲线，其中0≤s≤1，那么就有：

$$P(t)=\begin{cases} P_a(s)=\displaystyle\sum_{i=0}^{n}C_n^i\cdot s^i(1-s)^{n-i}\cdot P_1^i, & s=2t,\ 0\le t\le\frac{1}{2}\\[6pt] P_b(s)=\displaystyle\sum_{i=0}^{n}C_n^i\cdot s^i(1-s)^{n-i}\cdot P_n^{n-i}, & s=2t-1,\ \frac{1}{2}\le t\le1 \end{cases}$$

## 验证Bezier曲线分成前后两段的正确性，

P₀的系数为例，验证两端它的系数是相等的。

左端 = B₀,₃(t) = (1 - t)³
0 ≤ t ≤ 1/2

右端 = B₀,₃(2t) + 1/2 B₁,₃(2t) + 1/4 B₂,₃(2t) + 1/8 B₃,₃(2t)

= (1 - 2t)³ + 1/2 · 3 · 2t · (1 - 2t)² + 1/4 · 3 · (2t)² (1 - 2t) + 1/8 (2t)³

= (1 - 2t)³ + 3·t·(1 - 2t)² + 3·t²·(1 - 2t) + t³

= (1 - 2t + t)³

= (1 - t)³
1/2 ≤ t ≤ 1

右端 = 1/8 B₀,₃(2t - 1) = 1/8 (1 - (2t - 1))² = (1 - t)³

## P₁的系数：

左端 = B₁,₃(t) = 3t(1 - t)²
0 ≤ t ≤ 1/2

右端 = 1/2 B₁,₃(2t) + 1/2 B₂,₃(2t) + 3/8 B₃,₃(2t)
= 1/2 · 3 · 2t · (1 - 2t)² + 1/2 · 3 · (2t)²(1 - 2t) + 3/8 (2t)³
= 3·t·(1 - 2t)² + 6·t²·(1 - 2t) + 3t³
= 3t(1 - 2t + t²)
= 3t(1 - t)²
1/2 ≤ t ≤ 1

右端 = 3/8 B₀,₃(2t - 1) + 1/4 B₁,₃(2t - 1)
= 3/8 (1 - (2t - 1))³ + 1/4 · 3 · (2t - 1)(1 - (2t - 1))²
= 3(1 - t)³ + 3(2t - 1)(1 - t)²
= 3t(1 - t)²
