# 第五节 B样条曲线和曲面

一. B样条曲线（构造具有局部性的调和函数）

给定n+1个控制点P₀, P₁, …, Pₙ, 它们所确定的k阶B样条曲线是：

```
P(u) = Σ (i=0 to n) N_{i,k}(u)·P_i
```

其中N_{i,k}(u)递归定义如下：

$$N_{i,1}(u)=\begin{cases}1, & u_i\le u\le u_{i+1},\ 0\le i\le n+k-1\\0, & \text{其它}\end{cases}$$

$$N_{i,k}(u)=\frac{u-u_i}{u_{i+k-1}-u_i}N_{i,k-1}(u)+\frac{u_{i+k}-u}{u_{i+k}-u_{i+1}}N_{i+1,k-1}(u),\quad k>1,\ 0\le i\le n$$

这里 $u_0，u_1，\ldots，u_{n+k}$ 是一个**非递减**的序列，称为节点，$(u_0，u_1，\ldots，u_{n+k})$ 称为**节点向量**。定义中可能出现 $\frac{0}{0}$，这时约定为 0。

例一：选取，r=2，k=1，控制顶点是 P₀，P₁，P₂，这样应选择参数节点 r+k+1=4 个，设节点向量是 (u₀，u₁，u₂，u₃)，按式定义，可写出三个基函数：

$$N_{0,1}(u)=\begin{cases}1, & u_0\leq u\leq u_1\\0, & u_1\leq u\leq u_2\\0, & u_2\leq u\leq u_3\end{cases}$$

$$N_{1,1}(u)=\begin{cases}0, & u_0\leq u\leq u_1\\1, & u_1\leq u\leq u_2\\0, & u_2\leq u\leq u_3\end{cases}$$

$$N_{2,1}(u)=\begin{cases}0, & u_0\leq u\leq u_1\\0, & u_1\leq u\leq u_2\\1, & u_2\leq u\leq u_3\end{cases}$$

# 由公式可知所定义的B样条曲线是

P(u) = N_{0,1}(u)P_0 + N_{1,1}(u)P_1 + N_{2,1}(u)P_2
= { P_0,  u_0 ≤ u ≤ u_1
  P_1,  u_1 ≤ u ≤ u_2
  P_2,  u_2 ≤ u ≤ u_3 }

任意一阶B样条曲线是控制点本身，可以看作是0次多项式

例二. 选取 $r=3，k=2$，于是有四个控制顶点 $P_0，P_1，P_2，P_3$，应有参数节点 $r+k+1=6$ 个，设节点向量是 $(0，0，1，2，3，3)$，试画出所确定的 $2$ 阶 B 样条曲线。

取 $u=0.5$，进行计算。因为 $0.5\in[0，1]=[u_1，u_2]$，因此 $N_{1,1}(0.5)=1$，而其它的 $N_{i,1}(0.5)=0，i\ne1$。

$N_{0,2}(0.5)=\frac{0.5-0}{0-0}\cdot0+\frac{1-0.5}{1-0}\cdot1=0.5$

$N_{1,2}(0.5)=\frac{0.5-0}{1-0}\cdot1+\frac{2-0.5}{2-1}\cdot0=0.5$

P(0.5) = N_{0, 2}(0.5)·P_0 + N_{1, 2}(0.5)·P_1
+ N_{2, 2}(0.5)·P_2 + N_{3, 2}(0.5)·P_3
= 0.5·(P_0 + P_1)
