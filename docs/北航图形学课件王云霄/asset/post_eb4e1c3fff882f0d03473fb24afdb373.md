
## 5.液晶显示器LCD (Liquid Crystal Display)

LCD是靠后方一组日光灯管发光，然后经由一组菱镜片与背光模块，将光源均匀地传送到前方，依照所接收的影像讯号，液晶画素玻璃层内的液晶分子会作相对应的排列，决定哪些光线是需偏折或阻隔的

对每一个像素计算判别式$d$，根据它的符号确定下一像素。
$d\ge 0$ 时，取正右方像素$P_1$，判断再下一个像素应取哪个，应计算
$d_1 = F\left( x_i+2\ ,\ y_i+0.5 \right) = a\left( x_i+2 \right) + b\left( y_i+0.5 \right) +c = d + a$
故$d$的增量为$a$。
而若$d<0$，则取右上方向素$P_2$。要判断再下一个像素，则要计算

d₂ = F( xᵢ+2, yᵢ+1.5 )
= a( xᵢ+2 ) + b( yᵢ+1.5 ) + c
= d + a + b

故在第二种情况，d的增量为a + b

再看d的初始值。显然，第一个元素应取左端点(x₀, y₀)，相应的判别式值为

d₀ = F(x₀ +1, y₀ +0.5)
= (x₀ +1) + b(y₀ +0.5) + c
= a x₀ + b y₀ + c + a + 0.5b
= F(x₀, y₀) + a + 0.5b
但由于(x₀, y₀)在直线上，故 F(x₀, y₀)=0。
因此，d的初始值为 d₀ = a+0.5b

考虑用2d来代替d的计算

## 3. Bresenham画线算法

斜率m在0到1之间，并且x₂ > x₁。设在第 i 步已经确定第 i 个像素点是 (xᵢ, yᵢ)，它是直线上点 (ẋᵢ, ẏᵢ) 的最接近位置，ẋᵢ = xᵢ，现在看第 i+1 步如何确定第 i+1 个像素点的位置。

$d_1=y-\dot{y}_i=m(\dot{x}_i+1)+b-\dot{y}_i$

$d_2=(\dot{y}_i+1)-y=(\dot{y}+1)-m(\dot{x}_i+1)-b$

$d_1-d_2=2m(\dot{x}_i+1)-2\dot{y}_i+2b-1$

$d_1>d_2$，下一个象素点取 $(\dot{x}_i+1,\dot{y}_i+1)$

$d_1<d_2$，下一个象素点取 $(\dot{x}_i+1,\dot{y}_i)$

$d_1=d_2$，取两象素点中的任意一个

$p_i = \Delta x(d_1 - d_2)$

$= 2\Delta y \cdot \dot{x}_i - 2\Delta x \cdot \dot{y}_i + c$

$p_{i+1} = 2\Delta y \cdot \dot{x}_{i+1} - 2\Delta x \cdot \dot{y}_{i+1} + c$

$p_{i+1} - p_i = 2\Delta y - 2\Delta x(\dot{y}_{i+1} - \dot{y}_i)$

p_i ≥ 0 应取 ẏ_{i+1}=ẏ_i+1

p_{i+1} = p_i + 2(Δy − Δx)

p_i < 0 应取 ẏ_{i+1}=ẏ_i

p_{i+1} = p_i + 2Δy

初始值确定P₁，

ẋ₁ = x₁, ẏ₁ = y₁ = (Δy / Δx) x₁ + b

令 i=1，可计算求出：

p₁ = 2Δy − Δx
