## 第七节 区域分割算法（图像空间算法）

区域相关性：位于适当大小区域内的所有像素，实际上表示同一个表面。

形体中多边形的投影多边形与待考察区域之间的关系：

- 1. 包围的多边形
- 2. 相交的多边形
- 3. 被包含的多边形
- 4. 分离的多边形

![](img/4628856fffb4db710a3ae3a299935a63_608_0.png)

## 区域不需要分割的几种情况：

- 1. 所有多边形都与区域分离，因此区域内只需显示背景值。
- 2. 只有一个相交的多边形，或只有一个被包含的多边形。此时可先在区域内填充背景值，然后对该多边形进行扫描转换。（对于相交多边形，只对被包含的部分做扫描转换。）
- 3. 只有一个包围的多边形，没有其他多边形。整个区域填充该多边形的像素值。
  - （第 1、2、3 种情况使用范围检查）
- 4. 有多个多边形与区域相交、包围区域或被区域包含，且其中一个包围多边形位于其他所有多边形的最前面；区域填充为该多边形的颜色。（深度检查）
