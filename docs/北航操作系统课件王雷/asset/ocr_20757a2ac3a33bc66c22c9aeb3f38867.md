# Main components of Intel Chipset: Pentium 4

+   - **Northbridge:**
+     - Handles memory
+     - Graphics
+   - **Southbridge: I/O**
+     - PCI bus
+     - Disk controllers
+     - USB controllers
+     - Audio
+     - Serial I/O
+     - Interrupt controller
+     - Timers
