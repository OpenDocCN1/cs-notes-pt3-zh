| 地址 | 内容 |
|---|---|
| 80000000 | 系统代码（Ntoskrnl，HAL）和一些系统中初始的未分页缓冲池 |
| A0000000 | 系统映射视图（例如，Win32k.sys）或会话空间 |
| A4000000 | 附加的系统PTE（高速缓存可以映射到这里） |
| C0000000 | 进程的页表和页目录 |
| C0400000 | 超级用户进程工作集列表 |
| C0800000 | 没有使用，不可访问 |
| C0C00000 | 系统工作集列表 |
| C1000000 | 系统高速缓存 |
| E1000000 | 分页缓冲池 |
| EB000000 | 系统PTE |
| EFC00000 | 未分页缓冲池扩充 |
| FFBE0000 | 故障转储信息 |
| FFC00000 | HAL使用 |
