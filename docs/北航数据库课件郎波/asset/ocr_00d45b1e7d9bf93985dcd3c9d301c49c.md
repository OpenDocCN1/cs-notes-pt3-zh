+   Armstrong公理完备性的证明
+   - 公理的完备性：F所蕴含的函数依赖的全体中的每一个函数依赖，必定可以由F根据Armstrong公理导出

+   - 设X→Y不能用Armstrong公理导出，并建立关系r。
