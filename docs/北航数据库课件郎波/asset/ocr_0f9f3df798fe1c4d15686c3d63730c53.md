# 元组演算与关系代数的等价性

用关系演算表达五种基本运算：

+   - 并： R∪S={ t | R(t) ∨ S(t) }

+   - 差： R−S={ t | R(t) ∧ ¬ S(t) }

+   - 笛卡儿积：
+   R × S = { t^(n+m) | (∃u^(n))(∃v^(m))(R(u) ∧ S(v) ∧ t[1] = u[1] ∧ ... ∧ t[n] = u[n] ∧ t[n+1] = v[1] ∧ ... ∧ t[n+m] = v[m]) }

+   - 投影：
+   ∏_{i1,i2,...,ik} ( R ) = { t^(k) | (∃u)(R(u) ∧ t[1] = u[i1] ∧ ... ∧ t[k] = u[ik] ) }

+   - 选取： σ_F(R) = { t | R(t) ∧ F' }，F'是F用t[i]代替原运算对象i得到的等价公式。
