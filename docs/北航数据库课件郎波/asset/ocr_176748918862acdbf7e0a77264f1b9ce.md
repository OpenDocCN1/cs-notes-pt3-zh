# 修改、删除基本表定义

+   - 修改基本表
+     - 语法： Alter Table <表名>
+       [Add <新列名><数据类型>[<完整性约束>]]
+       [Drop <完整性约束名>]
+       [Modify <列名><数据类型>]
+     - 示例
+       - 例1： S表增加 “入学时间” 属性
+         Alter Table S Add Scome Date ;
+       - 例2： 将SA的数据类型改为半字长整数
+         Alter Table S Modify SA Smallint

+   - 删除基本表
+     - 语法: Drop Table <表名>
+     - 示例: Drop Table S;
