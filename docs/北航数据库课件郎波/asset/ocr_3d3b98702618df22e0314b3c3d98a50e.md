# 关系示例

以MAN、WOMAN、CHILD三个域的笛卡儿积的子集构造FAMILY关系：

FAMILY (MAN, WOMAN, CHILD)

其中MAN—丈夫，WOMAN—妻子，CHILD—这对夫妇的子女。假设M1、W1、C1，M2、W2、C2，C3是两个家庭，则FAMILY关系为：

| MAN | WOMAN | CHILD |
| --- | --- | --- |
| M₁ | W₁ | C₁ |
| M₂ | W₂ | C₂ |
| M₂ | W₂ | C₃ |
