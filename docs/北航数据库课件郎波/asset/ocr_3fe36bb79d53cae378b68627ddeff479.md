# 局部E-R图的合并（2）

# (3) 结构冲突：

+   - 同一对象在不同应用中有不同抽象。如在一应用中为实体，在另一应用中为属性。
+   
+     解决——遵守实体与属性的划分原则，把属性变为实体或实体变为属性，使同一对象具有相同的抽象。

+   - 同一实体在不同分E-R图中属性个数、次序不同。
+   
+     解决——同一实体的属性通常取分E-R图中属性的并，再适当调整次序。

+   - 实体之间的联系在不同分E-R图中呈现不同类型。
+   
+     解决——根据语义加以综合或调整。
