# 关系代数—专门的关系运算

+   - 除法

定义：设关系 R (X, Y) 与关系 S (Z)，其中 Y 和 Z 具有相同的属性数，且对应属性出自相同域。关系 R 除以关系 S 所得的商关系是关系 R 在属性 X 上投影的一个子集，该子集和 S (Z) 的笛卡儿积必须包含在 R (X, Y) 中。

记为：

```
R ÷ S = { t | t ∈ Πₓ(R) ∧ s ∈ S ∧ < t, s > ∈ R }
```
