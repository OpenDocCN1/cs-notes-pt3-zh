# 函数依赖集F的极小化处理

**一定理：** 每个函数依赖集F均等价于一个极小函
数依赖集Fm，此Fm为F的最小依赖集。

# F的极小化算法：

+   - 逐个检查F中各函数依赖FDᵢ：X→Y，若Y=A₁A₂…Aₖ，k≥2，则用{X→Aᵢ|i=1,2,…,k}代替X→Y。
+   - 逐个检查F中各函数依赖X→A，设X=B₁…Bₘ，逐个考查Bᵢ，若A∈(X−Bᵢ)⁺<sub>F</sub>，则以(X−Bᵢ)取代X。直到F不再改变。
+   - 逐个检查F中各函数依赖X→A，令G=F−{X→A}，若A∈(X)⁺<sub>G</sub>，则从F中去掉该函数依赖，直到F不再改变。
