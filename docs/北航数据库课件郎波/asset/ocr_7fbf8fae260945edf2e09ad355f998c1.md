# 用户级权限与角色的授予与收回

+   在SQL语言中，通过Grant语句授予用户用户级权限或角色，其语法格式
+   Grant <用户级权限>|<角色> [{,<用户级权限>|<角色>}]
+   To <用户名>|<角色>|public [{,<用户名>|<角色>}]
+   [With Grant Option]

数据库中的全部用户

允许被授权的用户将指定的用户级权限或角色授予其他用户

+   当要取消一个用户或角色的权限时，可以使用REVOKE语句将其收回：
+   Revoke <用户级权限>|<角色> [{,<用户级权限>|<角色>}]
+   From <用户名>|<角色>|public [{,<用户名>|<角色>}]
