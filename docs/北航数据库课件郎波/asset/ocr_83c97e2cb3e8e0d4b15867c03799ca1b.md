# 示例

例：设关系 R，S，W，求如下元组表达式的结果：

| R | A1 | A2 | A3 |
|---|---|---|---|
|   | a | e | 8 |
|   | c | f | 6 |
|   | d | b | 4 |
|   | d | f | 3 |

| S | A1 | A2 | A3 |
|---|---|---|---|
|   | a | e | 8 |
|   | b | c | 5 |
|   | d | b | 4 |
|   | d | f | 6 |

| W | B1 | B2 |
|---|---|---|
|   | 4 | x |
|   | 5 | d |

+   (1) R1={t|R(t) ∧ t[3] ≥4};
+   (2) R2={t | (∃u)(R(t) ∧ W(u) ∧ t[3]<u[1])};
+   (3) R3 = {t|R(t) ∧ S(t)};

结果： R1

| A1 | A2 | A3 |
|---|---|---|
| a | e | 8 |
| c | f | 6 |
| d | b | 4 |

R2

| A1 | A2 | A3 |
|---|---|---|
| d | b | 4 |
| d | f | 3 |
