# 投影（Projection）

定义：从关系 R(U) 中取若干属性列并删去重复行，组成新的关系。记作：

$\Pi_A(R)=\{t[A]\mid t\in R,\ A\subseteq U\}$

```
S(S#,SN,SA,SD);
C(C#,CN,PC#);
SC(S#,C#,G)
```
