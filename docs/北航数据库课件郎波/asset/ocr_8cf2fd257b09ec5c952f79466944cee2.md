# 连接查询的优化

+   - 半连接：使用半连接来缩减关系（或片段）进而节省传输开销。

+   - 半连接法定义： R ⋉ₐ=ʙ S = R ⋈ₐ=ʙ (Πʙ (S))

例：

# R1

| A | B |
| --- | --- |
| a1 | b1 |
| a2 | b1 |
| a2 | b3 |
| a2 | b4 |
| a3 | b3 |

⋈

# R2

| B | C |
| --- | --- |
| b1 | c1 |
| b2 | c2 |
| b5 | c1 |
| b5 | c2 |
| b6 | c4 |
| b7 | c2 |
| b8 | c3 |

=

# R1 ⋈ R2

| A | B |
| --- | --- |
| a1 | b1 |
| a2 | b1 |
