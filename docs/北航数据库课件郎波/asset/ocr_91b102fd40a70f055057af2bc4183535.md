# 关系代数—专门的关系运算

+   - 连接(Join)

定义：关系R和S在属性X和Y上的连接（X、Y是连接属性，即X、Y包含同等数量的属性，且相应的属性均具有共同的域），是从两个关系的广义笛卡儿积 R×S 中选取给定属性间满足θ比较条件的元组。记作：

```
R ⋈ S = { t | t = < r, s > ∧ r∈R ∧ s∈S ∧ r[X] θ s[Y] }
X θ Y
```

其中：⋈是连接运算符；

θ是算术比较运算符，该连接也称为θ连接

+   - 当θ为“=”时，称为等值连接；
+   - 当θ为“<”时，称为小于连接；
+   - 当θ为“>”时，称为大于连接；
