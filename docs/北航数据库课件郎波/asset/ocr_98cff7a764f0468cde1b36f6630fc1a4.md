# 非结构化数据的构成

+   • 每种数据组成复杂
+     – 多模态
+     – 多张性强

| 语义项 | 描述 |
|---|---|
| 图像表示 | 极其复杂的语义类型，如长度、宽度、亮度等 |
| 拍摄者 | 图像的拍摄者 |
| 拍摄时间 | 图像的拍摄时间 |
| 拍摄地点 | 图像的拍摄地点 |
| 感兴趣区域 | 图像中用户感兴趣区域的描述 |
| 内容描述 | 图像的内容描述 |
| 类别 | 预定义的图像类别，如动物、植物、交通等 |
| 用户评论 | 用户对图像的评论 |
| 宽度 | 图像的宽度 |
| 高度 | 图像的高度 |
| 关键词 | 反映图像内容的关键词 |
| 标题 | 图像内容的标题 |
| 文件类型 | 图像文件的后缀类型，如 jpg、png 等 |
