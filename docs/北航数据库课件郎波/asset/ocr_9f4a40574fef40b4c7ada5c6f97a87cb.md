子女实体存在依赖于职工实体的存在，则称子女实体是弱实体。

如果实体不能由它自己的属性来唯一标识，而必须通过与它相联系的另一实体一起来标识，那么称该实体标识依赖于另一个实体。

+   - 子类可继承父类的属性，子类也可以附加某些属性；
+   - 子类之间的交不一定为空。
