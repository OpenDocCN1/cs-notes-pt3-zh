# • 不能重复读 (Non-Repeatable Read)

事务 T₁ 读取数据后，事务 T₂ 执行更新（修改、插入、删除）操作，使 T₁ 无法再现前一次读取的结果。

| T₁ | T₂ |
|---|---|
| READ(A) | |
| READ(B) | |
| Sum=A+B | |
| | READ(B) |
| | B=B*2 |
| | WRITE(B) |
| READ(A) | |
| READ(B) | |
| Sum=A+B | |
