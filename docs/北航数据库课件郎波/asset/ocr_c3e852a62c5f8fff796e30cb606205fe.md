# 分布透明性示例

执行查询操作：检索所有学生的学号和年龄。

+   - 若系统具有分片透明性，则执行操作：
+     SELECT S#,SA
+     FROM S

+   - 若系统具有位置透明性，不具有分片透明性，则可执行操作：
+     SELECT S#, SA
+     FROM  S_A
+     UNION
+     SELECT S#, SA
+     FROM  S_B

+   - 若系统只具有局部数据模型的透明性，不具有位置透明性与分片透明性，在执行操作：
+     SELECT S#, SA
+     FROM S_A AT SITE-1
+     UNION
+     SELECT S#, SA
+     FROM S_B AT SITE-3
