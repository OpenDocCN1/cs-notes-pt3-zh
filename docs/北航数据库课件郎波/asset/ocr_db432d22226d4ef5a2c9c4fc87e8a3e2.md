# 代数优化（1）

+   - 选择与并的分配律
+     \[
+     \sigma_F(E_1 \cup E_2)=\sigma_F(E_1)\cup\sigma_F(E_2)
+     \]

+   - 选择与差的分配律
+     \[
+     \sigma_F(E_1-E_2)=\sigma_F(E_1)-\sigma_F(E_2)
+     \]

+   - 选择对自然连接的分配律
+     \[
+     \sigma_F(E_1\bowtie E_2)=\sigma_F(E_1)\bowtie\sigma_F(E_2)
+     \]

+   - 投影与笛卡尔积的分配律
+     \[
+     \pi_{A_1,A_2,\ldots,A_n,B_1,B_2,\ldots,B_m}(E_1\times E_2)=\pi_{A_1,A_2,\ldots,A_n}(E_1)\times\pi_{B_1,B_2,\ldots,B_m}(E_2)
+     \]

+   - 投影与并的分配律
+     \[
+     \pi_{A_1,A_2,\ldots,A_n}(E_1\cup E_2)=\pi_{A_1,A_2,\ldots,A_n}(E_1)\cup\pi_{A_1,A_2,\ldots,A_n}(E_2)
+     \]
