# 分组检索（2）

S(S#,SN,SA,SD);
C(C#,CN,PC#);
SC(S#,C#,G)

例1：检索至少选修三门课程的学生学号和选课门数。

```
SELECT S#, COUNT (*)
FROM SC
GROUP BY S#
HAVING COUNT (*) >=3;
```

例2：求选修四门以上课程的学生学号和总成绩（不统计不及格的课程）。最后按降序列出总成绩排序名单。

```
SELECT S#, SUM (G)
FROM SC
WHERE G>=60
GROUP BY S#
HAVING COUNT (*) >=4
ORDER BY SUM(G) DESC;
```
