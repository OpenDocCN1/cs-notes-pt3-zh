# 候选码的图论判定方法（2）

定义2：在一个函数依赖图中有如下术语：

+   - 原始点：只有引出线而无引入线的节点，表示L类属性；
+   - 终结点：只有引入线而无引出线的节点，表示R类属性；
+   - 途中点：既有引出线又有引入线的节点，表示LR类属性；
+   - 孤立点：既无引出线又无引入线的节点，表示N类属性；
+   - 关键点：原始点和孤立点统称为关键点；
+   - 关键属性：关键点对应的属性；
+   - 独立回路：不能由其他节点到达的回路。

回路：有向图G=(V,E)中，若边序列P=(e_i1, e_i2, …, e_iq)，如果e_iq的终点也是e_i1的始点，则称P是G的一条有向回路。
