# 代数优化（1）

+   - 投影的串接定律
+     π_{A1,A2,...,An}(π_{B1,B2,...,Bm}(E)) ≡ π_{A1,A2,...,An}(E)
+     其中{A1,A2,...,An}是{B1,B2,...,Bm}的子集
+   - 选择的串接定律
+     σ_{F1}(σ_{F2}(E)) ≡ σ_{F1∧F2}(E)
+   - 选择与投影的交换律
+     σ_F(π_{A1,A2,...,An}(E)) ≡ π_{A1,A2,...,An}(σ_F(E))
+   - 选择与笛卡尔积交换律
+     - F中只有E1的属性： σ_F(E1 × E2) ≡ σ_F(E1) × E2
+     - F=F1∧F2，且F1只有E1的属性、F2中只有E2的属性： σ_F(E1 × E2) ≡ σ_{F1}(E1) × σ_{F2}(E2)
+     - F1只有E1的属性，F2有E1和E2的属性： σ_F(E1 × E2) ≡ σ_{F2}(σ_{F1}(E1) × E2)
