

## Armstrong 公理的完备性

### 证明（2）

| $X_F^+$ | $U - X_F^+$ |
|---|---|
| t 11...1 | 00...0 |
| s 11...1 | 11...1 |

（1）设 V→W 是 F 中任一函数依赖，则有两种情况：

- a) 若 V ⊆ $X_F^+$。因为 V ⊆ $X_F^+$，所以有 X→V；于是 X→W 成立，所以 W ⊆ $X_F^+$。由于 r 中 $X_F^+$ 上的值全相等，因此 V→W 在 r 上成立。

- b) 若 V ⊈ $X_F^+$。如果 V 不完全属于 $X_F^+$，则 V 在元组 t 和 s 上的取值必不相等，因此 V→W 在 r 上成立。

所以，在关系 r 中，F 的每一个函数依赖都成立。

### 证明（3）

| $X_F^+$ | $U - X_F^+$ |
|---|---|
| t 11...1 | 00...0 |
| s 11...1 | 11...1 |

（2）因为 X→Y 不能用公理从 F 推出，所以 Y⊈$X_F^+$，而 X⊆$X_F^+$，那么 r 中元组 t、s 在 X 上的值相等，而在 Y 上的值不等，因此 X→Y 在 r 上不成立。

结论：凡不能用公理推出的函数依赖都不被 F 逻辑蕴涵；反之，凡被 F 逻辑蕴涵的函数依赖都能用 Armstrong 公理从 F 导出。
— Armstrong 公理是完备的。

## 闭包的计算

### 求 $X_F^+$ 的算法

```text
Input: X, F
Output: $X_F^+$
$X_F^+ := X$;
do
  for any $A \subseteq X_F^+$ do
    if 在F中存在函数依赖 $A \rightarrow B$
      then $X_F^+ = X_F^+ \cup B$
while ( $X_F^+$ 发生变化且 $X_F^+ \neq U$ )
```

### 示例（1）

- 求 $X_F^+$ 的示例1：R<U, F>，U = (A, B, C, D, E)，F = {AB→C, B→D, C→E, CE→B, AC→B}，计算 $(AB)_F^+$。

| 所用依赖 | $(AB)_F^+$ |
|---|---|
|  | AB |
| AB→C | ABC |
| B→D | ABCD |
| C→E | ABCDE |

$(AB)_F^+ = ABCDE$

### 示例（2）

| 所用依赖 | $(AG)_F^+$ |
|---|---|
|  | AG |
| A→B | AGB |
| A→C | AGBC |
| CG→H | AGBCH |
| CG→I | AGBCHI |
|  | $(AG)_F^+ = AGBCHI$ |

### 示例（3）

## 函数依赖集等价与覆盖

- 函数依赖集等价
  - 对于函数依赖集 F、G，若 $F^+ = G^+$，则称 F 与 G 等价。
  - 如果 F 和 G 等价，则称 F 覆盖 G，同时 G 也覆盖 F。
  - $F^+ = G^+ \iff F \subseteq G^+，G \subseteq F^+$

## 函数依赖集的最小依赖集

- 最小依赖集
  - 定义：若函数依赖集 F 满足下列条件，则称 F 为一个极小函数依赖集，也称为最小依赖集或最小覆盖：
    - F 中任一函数依赖 X→A，A 必是单属性。（右部单属性化）
    - F 中不存在这样的函数依赖 X→A，使得 F 与 F−{X→A} 等价。（没有多余的函数依赖）
    - F 中不存在这样的函数依赖 X→A，在 X 中有其子集 Z，使得 F 与 F−{X→A}∪{Z→A} 等价。（每个函数依赖的左部没有多余属性）

## 函数依赖集 F 的极小化处理

**定理：** 每个函数依赖集 F 均等价于一个极小函数依赖集 Fm，此 Fm 为 F 的最小依赖集。

### F 的极小化算法

- 逐个检查 F 中各函数依赖 $FD_i$：X→Y，若 $Y=A_1A_2…A_k$，k≥2，则用 $\{X→A_i | i=1,2,…,k\}$ 代替 X→Y。
- 逐个检查 F 中各函数依赖 X→A，设 $X=B_1…B_m$，逐个考查 $B_i$，若 $A \in (X−B_i)^+_F$，则以 $(X−B_i)$ 取代 X。直到 F 不再改变。
- 逐个检查 F 中各函数依赖 X→A，令 G=F−{X→A}，若 $A \in (X)^+_G$，则从 F 中去掉该函数依赖，直到 F 不再改变。

### 示例

- 示例1

F = {A→B，B→A，A→C，B→C}，求 Fm。

Fm = {A→B，B→A，B→C}

或者

Fm = {A→B，B→A，A→C}

- 示例2

F = {C→A，A→G，CG→B，B→A}，求 Fm。

Fm = {A→G，C→B，B→A}

## 范式的概念（1）

- 如果一个关系满足某个指定的约束集，则称它属于某种特定的范式（Normal Form）；
- 满足最低要求约束的称为第一范式，简称为 1NF。当一个关系只包含原子值这一约束时，称为 1NF。原子值是指二维表的每一行和每一列的交叉位置上总是精确地存在一个值，而不是一个值集。也就是说不能“表中有表”；
- 满足“原子值”这一约束条件的关系称为规范化关系，简称为范式。在关系数据库中，都是规范化的关系。

## 范式的概念（2）

- 范式理论的发展过程：
  - 1971—1972 年，科德（Codd）系统地提出了 1NF、2NF、3NF 的概念，讨论了进一步规范化的问题。
  - 1974 年，科德（Codd）和博伊斯（Boyce）提出了 BCNF。
  - 1976 年，费金（Fagin）提出了 4NF，后来又提出了“投影-连接范式”PJNF，也称 5NF。

- 各级范式间的联系：
  $1NF \supset 2NF \supset 3NF \supset BCNF \supset 4NF \supset 5NF$

- 一个低一级范式的关系模式，通过模式分解可以转换为若干个高级范式的关系模式的集合，这一过程称作规范化。

## 2NF（1）

- 定义：若 R∈1NF，且每个非主属性完全依赖于码，则称 R∈2NF；
- 注意：
  - 如果关系 R 的全体属性都是 R 的主属性，那么 R∈2NF；
  - 从 1NF 中消除非主属性对码的部分函数依赖，则可获得 2NF 关系；
  - 在 2NF 中，允许主属性部分函数依赖于码。

## 2NF（4）

- 2NF 存在的弊病
  - SG=UN[S#, CN, G] ∈2NF
  - SDM=UN[S#, SDN, MN] ∈2NF
- 插入异常有所改善，但还是存在：如果系中没有学生，则有关该系的信息就无法插入。
- 删除异常：如果删除学生的信息，所在系的信息也随之删除了。
- 数据冗余得到一定改善：每个学生都存储了所在系的系主任的信息。

## 3NF（1）

- 定义：关系模式 R<U, F> 中，若不存在这样的码 X、属性组 Y 及非主属性 Z（Z⊄Y），使得下式成立：X→Y，Y→Z，且 Y 不函数依赖于 X，则称 R∈3NF。
- 或定义为：
  - 若关系模式 R∈2NF，且每个非主属性都不传递依赖于 R 的任何码，则 R∈3NF。
