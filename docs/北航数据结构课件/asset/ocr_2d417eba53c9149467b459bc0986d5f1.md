# 5. 在线性链表中第i(i>0)个结点后面插入一个数据信息为item的新结点

```
procedure INSERTLINK3( list, i, item )
q←list
for j←1 to i-1 do
    q←link(q)
    if (q=nil) then
        [ call ERROR(‘There is no node !’)
          return ]    //链表中不存在第i个结点//
end
call GETNODE(p)          //申请一个新结点//
data(p)←item
link(p)←link(q)
link(q)←p               //插入到第i个结点的后面//
end
```
