# 求关键活动的思路

e(i) —— 活动 aᵢ 的最早开始时间  
l(i) —— 活动 aᵢ 的最迟开始时间  
若 l(i)−e(i)=0，则说明活动 aᵢ 为一个关键活动。

ee(k) —— 事件 k 的最早发生时间

![](bbox=[0.682, 0.412, 0.884, 0.481])

le(k) —— 事件 k 的最迟发生时间

![](bbox=[0.682, 0.411, 0.885, 0.594])

# 结论

事件 k 的最早发生时间 ee(k)  →  活动的 aᵢ 最早开始时间 e(i)  
事件 k 的最迟发生时间 le(k)  →  活动的 aᵢ 最迟开始时间 l(i)

aᵢ 为关键活动

求 e(i) = l(i)
