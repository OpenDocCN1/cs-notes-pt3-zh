# 合并算法

将两个位置相邻且按值有序序列合并为一个按值有序的序列

```
procedure MERGE( X, s, t, u, Z )
	i←s
j←t+1
q←s
while ( i≤t and j≤u ) do
    if (X[i]≤X[j]) then
        [ Z[q]←X[i]
          i←i+1 ]
    else
        [ Z[q]←X[j]
          j←j+1 ]
    q←q+1
end
while (i≤t) do
    Z[q]←X[i]
    i←i+1
    q←q+1
end
while (j≤u) do
    Z[q]←X[j]
    j←j+1
    q←q+1
end
end
```
