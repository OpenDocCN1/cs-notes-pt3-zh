# 四. 算法(用自然语言表达)

+   1. 确定dist、S、path三个数组的初值。
+   2. 利用S数组与dist数组在那些尚未找到最短路径的顶点中确定一个与源点最近的顶点u, 并置S[u]为1，同时将顶点u加入path[u].
+   3. 根据顶点u修改源点到所有尚未找到最短路径的顶点的路径长度。即
+      1）将源点v到顶点u的(最短)路径长度分别加到源点v通过顶点u可以直接到达、且尚未找到最短路径那些的顶点的路径长度上;若加后的长度小于原来v到某顶点r的路径长度，则用加后的长度替代原来的长度，否则不替代。
+      2）若替代，将源点v到顶点u的路径(最短路径)上经过的所有顶点替换path[r].
+   4. 重复上述过程的第2至第3步n−1次。

```
for i←1 to n do
  dist[i]←cost[v, i]
  S[i]←0
  path[i]←{ v }
end
S[v]←1
```
