# 算法

```
procedure CIRCULATE(A, n, k)
  for t←1 to k do
    temp←A[n-1]      // 保存数组最后一个元素 //
    for j←n-2 downto 0 do
      A[j+1]←A[j]
    end
    A[0]←temp
  end
end
```

数组的所有元素右移1位

```
for t←1 to k do
  temp←A[0]      //保存数组第一个元素//
  for j←n-1 downto 1 do
    A[(j+1) MOD n]←A[j]
  end
  A[1]←temp
end
```
