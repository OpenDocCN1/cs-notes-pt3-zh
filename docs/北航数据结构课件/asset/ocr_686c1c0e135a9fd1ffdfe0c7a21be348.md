# 一、什么是稀疏矩阵？

一个较大的矩阵中，零元素的个数相对于整个矩阵元素的总个数所占比例较大时，可以称该矩阵为一个稀疏矩阵。

0 & 0 & 0 & 0 & 0 & 0\\
91 & 0 & 0 & 0 & 0 & 0\\
0 & 0 & 28 & 0 & 0 & 0
\end{pmatrix}
\]
