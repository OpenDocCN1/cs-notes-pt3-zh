# 三元多项式

$P(x,y,z)=x^{10}y^3z^2+2x^8y^3z^2+3x^8y^2z^2+x^4y^4z+6x^2y^4z+2yz$

$=((x^{10}+2x^8)y^3+3x^8y^2)z^2+((x^4+6x^2)y^4+2y)z$

$P(z)=Az^2+Bz$

其中：

$A(x,y)=(x^{10}+2x^8)y^3+3x^8y^2$

$B(x,y)=(x^4+6x^2)y^4+2y$

$A(y)=Cy^3+Dy^2$

$B(y)=Ey^4+Fy$

$C(x)=x^{10}+2x^8$

$E(x)=x^4+6x^2$

$D(x)=3x^8$

$F(x)=2x^0$
