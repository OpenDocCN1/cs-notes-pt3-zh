# 算法

```
procedure INSERTD( list, x, item )
    q←rlink(list)                // q 初值时指向头结点的下一个结点 //
    while (q≠list and data(q)≠x) do
        q←rlink(q)
    end                         // 寻找满足条件的链结点 //
    if (q=list) then
    [ print(‘There is no this node !’)
      return ]                  // 没有找到满足条件的结点 //
    call GETNODE(p)              // 申请一个新的结点 //
    data(p)←item
    llink(p)←q
    rlink(p)←rlink(q)
    llink(rlink(q))←p
    rlink(q)←p
end
```
