# # 算法

```
procedure SHELLSORT(K, n)
d←n
while (d>1) do
    d←⌊d/2⌋
    repeat
        flag←0
        for i←1 to n-d do
            j←i+d
            if (K[i]>K[j]) then
                [
                    temp←K[i]
                    K[i]←K[j]
                    K[j]←temp
                    flag←1
                ]
            end
        until flag=0
    end
end
```

经过 Shell 排序

O(nlogn)

非稳定性排序方法
