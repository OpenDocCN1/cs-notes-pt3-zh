# 例

```
procedure MATRIX( A, B, C, n )
    for i←1 to n do ----------------------------- n+1
        for j←1 to n do ------------------- n(n+1)
            C[i, j]←0 ----------------------------- n²
            for k←1 to n do ---------- n²(n+1)
                C[i, j]←C[i, j]+A[i, k]×B[k, j] --- n³
            end
        end
    end
end
```

求两个n阶矩阵的乘积

# 算法的频度：

f(n) = n+1 + n(n+1) + n² + n²(n+1) + n³
= 2n³ + 3n² + 2n + 1
