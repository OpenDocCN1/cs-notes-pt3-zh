# 三. 删除(退栈)算法

![](bbox=[0.09, 0.22, 0.88, 0.42])

```
procedure POP_LINK_STACK( top, item )
if (top = nil) then
    call STACK_EMPTY( 'Stack is empty!' )
else
    [ p←top                //暂时保存栈顶节点的地址//
      item←data(top)       //保存被删栈顶的数据信息//
      top←link(top)        //删去栈顶节点//
      call RET(p) ]        //释放被删节点//
end
```
