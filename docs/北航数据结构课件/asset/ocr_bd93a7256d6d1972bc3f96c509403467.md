# 二、几个名词概念

+   1. **子串**：串中若干个连续的字符组成的子序列。
+   
+      例如：
+      `S='Beijing&Shanghai'`
+      `T='jing'`

+   2. **主串**：包含子串的串。

+   3. **位置**：
+      (1). 单个字符在主串中的位置被定义为该字符在串中的序号。
+      (2). 子串在主串中的位置被定义为主串中首次出现的该子串的第一个字符在主串中的位置。
+   
+      例如：
+      `S='Beijing&Nanjing&Shanghai'`
+      `T='jing'`
+   
+      位置为4
