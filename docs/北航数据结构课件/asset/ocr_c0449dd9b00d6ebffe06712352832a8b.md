# 算法

```
procedure DELETEELIST(A, n, i)
    if (i<1) or (i>n) then
        call ERROR (‘The position is not exist!’)
    else
        [   for j←i+1 to n do
                A[j−1]←A[j]
            end                         // 数据元素依次前移一个位置 //
            n←n−1                       // 线性表的长度减1 //
        ]
    end
```
