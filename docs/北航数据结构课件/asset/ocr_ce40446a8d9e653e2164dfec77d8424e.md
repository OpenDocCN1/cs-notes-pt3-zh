# 非递归算法

功能: 将一个数据元素item 插入到根为T的二叉排序树中。

```
procedure INSERT(T, item)
call GETNODE(p)
data(p)←item
lchild(p)←nil
rchild(p)←nil
if (T=nil) then
  T←p
else
```

```
[ q←T
loop
  if (item<data(q)) then
    if (lchild(q)=nil) then
      [ lchild(q)←p
        exit ]
    else
      q←lchild(q)
  else
    if (rchild(q)=nil) then
      [ rchild(q)←p
        exit ]
    else
      q←rchild(q)
  forever ]
end
```
