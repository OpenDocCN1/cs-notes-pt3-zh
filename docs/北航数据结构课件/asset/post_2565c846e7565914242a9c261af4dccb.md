### 二、B树的查找

首先将给定的关键字k在B树的根结点的关键字集合中采用顺序查找法或者折半查找法进行匹配查找，若有key=k，则查找成功，根据相应的指针取得记录。否则，若k在keyᵢ与keyᵢ₊₁之间，则在指针pᵢ所指的结点中重复上述查找过程，直到在某结点中查找成功，或者在某结点中出现pᵢ=nil，查找失败。

### 例

例如，查找关键字k=23 查找失败！

原则: (1) k=key_i 查找成功 (2) key_i<k<key_{i+1} p_i

### 算法

```
procedure MBSEARCH(T, k)
  ptr←T
  qtr←nil
  A[0]←-max
  while (ptr≠nil) do
    n ←keynum(ptr)
    A[n+1]←+max
    for j←1 to n do
      A[j]←key(ptr,j)
    end
    for j←0 to n do
      B[j]←pointer(ptr, j)
    end
    i←SEQSEARCH(A, k)
    if (key(ptr,i)=k) then
      return(ptr, i, 1)
    qtr←ptr
    ptr←B[i]
  end
  return(qtr, i, 0)
end
```

```
function SEQSEARCH(A,k)
  j←1
  loop
    if (k<A[j]) then
      return(j-1)
    j←j+1
  forever
end
```

### 2. 哈希冲突

对于不同的关键字 kᵢ、kⱼ，经过散列得到相同的散列地址，即有

H(kᵢ) = H(kⱼ)

这种现象称为哈希冲突。

> 称 kᵢ 与 kⱼ 为“同义词”

### 3. 什么是哈希文件？

根据构造的散列函数与处理冲突的方法将一组关键字映射到一个有限的连续地址集合上，并以关键字在该集合中的“象”作为记录的存储位置，按照这种方法组织起来文件称为杂凑文件，或称哈希文件，或称散列文件；建立文件的过程称为哈希造表或者散列，得到的存储位置称为杂凑地址或者散列地址。

### 2. 步骤

- 确定散列的地址空间（地址范围）；
- 构造合适的散列函数；
- 选择处理冲突的方法。

### 三. 冲突的处理方法

所谓处理冲突，是在发生冲突时，为冲突的元素找到另一个杂凑地址以存放该元素。如果找到的地址仍然发生冲突，则继续为发生冲突的这个元素寻找另一个地址，直到不再发生冲突。

#### 1. 开放地址法（闭散列方法）

所谓开放地址法是在散列表中的“空”地址向处理冲突开放。即当散列表未满时，处理冲突需要的“下一个”地址在该散列表中解决。

Dᵢ = ( H(k)+dᵢ ) MOD m        i=1, 2, 3, ...

其中，H(k)为哈希函数，m为表的长度，dᵢ为地址增量，有：

- (1) dᵢ=1, 2, 3, ..., m-1        称为线性再散列
- (2) dᵢ=1², 2², ..., (m-1)²        称为二次再散列
- (3) dᵢ=伪随机数序列        称为伪随机再散列
