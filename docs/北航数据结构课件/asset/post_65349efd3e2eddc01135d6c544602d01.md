procedure SELECTSORT(K, n)

for i←1 to n-1 do
    d←i
    for j←i+1 to n do
        if (K[j]<K[d]) then
            d←j
    end
    if (d≠i) then // 最小值元素非未排序元素的第一个元素 //
    [  temp←K[i]

        K[d]←temp  ]

procedure BUBBLESORT( K, n )
    flag←1
    i←n-1
    while (i>0 and flag=1) do
        flag←0
        for j←1 to i do
            if (K[j]>K[j+1]) then
            [  temp←K[j]
            K[j]←K[j+1]
            K[j+1]←temp      // 交换两个元素的位置 //
            flag←1  ]
        end
        i←i-1

## 10.5 谢尔(Shell)排序法

### 核心思想

首先确定一个元素的间隔数 d。将参加排序的元素按照 d 分隔成若干个子序列（即分别把那些位置相隔为 d 的元素看作一个子序列），然后对各个子序列采用某一种排序方法进行排序。此后减少 d 值，重复上述过程，直到 d<1 为止。

减少 d 的方法之一：

\[
 d_1 = \lfloor n/2 \rfloor
\]
\[
 d_i = \lfloor d_{i-1}/2 \rfloor, \quad i=2,3,4,\ldots
\]

### 例

### 采用泡沫排序方法

| d=2 | 25  65  13  27  49  97  38  50  76<br>13  27  25  50  38  65  49  97  76 |
| d=1 | 13  27  25  50  38  65  49  97  76<br>13  25  27  38  49  50  65  76  97 |

## 算法

```
procedure SHELLSORT(K, n)
d←n
while (d>1) do
    d←⌊d/2⌋
    repeat
        flag←0
        for i←1 to n-d do
            j←i+d
            if (K[i]>K[j]) then
                [
                    temp←K[i]
                    K[i]←K[j]
                    K[j]←temp
                    flag←1
                ]
            end
        until flag=0
    end
end
```

## 10.6 快速排序法

### 一、核心思想

可以选第一个或者最后一个、或位置居中的那个元素作为分界元素

从当前参加排序的元素中任选一个元素（通常称之为分界元素）与当前参加排序的那些元素进行比较，凡是小于分界元素的元素都移到分界元素的前面，凡是大于分界元的元素都移到分界元素的后面，分界元素将当前参加排序的元素分成前后两个部分，而分界元素处在排序的最终位置。然后，分别对这两部分中大小大于1的部分重复上述过程，直到排序结束。

递归过程

### 二. 算法步骤

#### 方法一

#### 算法中用到的变量：

s：当前参加排序的那些元素的第一个元素在序列中的位置，初始值为1。

t：当前参加排序的那些元素的最后一个元素在序列中的位置，初始值为n。

temp: 保存分界元素。

i, j：两个位置变量，初始值分别为s 与t+1。

![](img/f94080b0b6a6124b22e8484de896d7b7_459_0.png)

### 步骤

- 1. 反复执行动作 i←i+1，直到 temp≤K[i] 或者 i=t。
- 反复执行动作 j←j-1，直到 temp≥K[j] 或者 j=s。
- 2. 若 i<j，则 K[i] 与 K[j] 交换位置，转到第 1 步。
- 3. 若 i≥j，则 K[s] 与 K[j] 交换位置，到此，分界元素 K[s] 的最终位置已经确定，然后对被 K[s] 分成的两部分中大小大于 1 的部分重复上述过程，直到排序结束。

### 例

49　38　65　97　76　27　13　50

### 步骤

- 1. 反复执行动作 i←i+1，直到 temp≥K[i] 或者 i=t。
反复执行动作 j←j−1，直到 temp≤K[j] 或者 j=s。
- 2. 若 i<j，则 K[i] 与 K[j] 交换位置，转到第1步。
- 3. 若 i≥j，则 K[s] 与 K[j] 交换位置，到此，分界元素 K[s] 的最终位置已经确定，然后对被 K[s] 分成的两部分中大小大于1的部分重复上述过程，直到排序结束。

```
procedure QUICKSORT( K, s, t )
if (s<t) then
[
 i←s
 j←t+1
 temp←K[s]
 loop
  repeat
   i←i+1
  until (temp≤K[i] or i=t)
  repeat
   j←j-1
  until (temp≥K[j] or j=s)
  if (i<j) then
   call SWAP( K[i], K[j] )
  else
   exit
 forever
call SWAP( K[s], K[j] )
call QUICKSORT( K, s, j-1 )
call QUICKSORT( K, j+1, t ) ]
end
```

## 10.7 堆积排序法

### 一. 堆积的定义

- 1. n个元素的序列（k₁, k₂, ..., kₙ），当且仅当满足条件

(1) { kᵢ ≥ k₂ᵢ
kᵢ ≥ k₂ᵢ₊₁ } 或者 (2) { kᵢ ≤ k₂ᵢ
kᵢ ≤ k₂ᵢ₊₁ }
i=1, 2, 3, ..., ⌊n/2⌋

称该序列为一个堆积(heap)。

称满足条件(1)的堆积为大顶堆积，称满足条件(2)的堆积为小顶堆积。

本课程选择(1)
