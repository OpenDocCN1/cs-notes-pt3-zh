
## 链接点：

data link

## 用PASCAL 语言描述：

```
TYPE

nodetype=RECORD
data : datatype;
link : nodeptr;
end;
VAR
list, p : nodeptr;
```

## 用C 语言描述：

```
struct node {
    datatype  data;
    struct node  *link;
};

struct node  *list, *p;
```

## 二. 关于符号说明

若指针变量p为指向链表中某结点的指针(即 p的内容为链表中某链结点的地址))，则

data(p)

若出现在表达式中，表示由p指的链结点的数据域中的内容；否则，表示由p所指的那个链结点的数据域(位置)。

![](img/f94080b0b6a6124b22e8484de896d7b7_70_0.png)

link(p)

若出现在表达式中，表示由p指的链结点的指针域的内容，即p所指的链结点的下一个链结点的地址，否则，表示由p所指的那个链结点的指针域(位置)。

p←link(p)：将指针变量 p 由指向链表中某一个链结点改变为指向下一个链结点。

![](img/f94080b0b6a6124b22e8484de896d7b7_71_0.png)

p←link(p)

## 算法

```
function LENGTH( list )
    p←list
    n←0                // 链表的长度置初值0 //
    while (p≠nil) do
        p←link(p)
        n←n+1
    end
    return(n)           // 返回链表的长度n //
end
```

```
struct node {
    datatype data;
    struct node *link;
};
struct node *list;
struct node *p;
```

## C程序

```
int LENGTH(struct node *list )
{
    struct node *p;
    int n;
    p=list;
    n=0;              // 链表的长度置初值0 //
    while (p!=NULL)
    {
        p=p->link;
        n++;
    }
    return(n);        // 返回链表的长度n //
}
```

## 5. 在线性链表中第i(i>0)个结点后面插入一个数据信息为item的新结点

```
procedure INSERTLINK3( list, i, item )
q←list
for j←1 to i-1 do
    q←link(q)
    if (q=nil) then
        [ call ERROR(‘There is no node !’)
          return ]    //链表中不存在第i个结点//
end
call GETNODE(p)          //申请一个新结点//
data(p)←item
link(p)←link(q)
link(q)←p               //插入到第i个结点的后面//
end

    if (q=list) then

    else
