# 算法

```
procedure ADDLINKQUEUE( front, rear, item )
call GETNODE(p)        // 申请一个链结点 //
data(p)←item
link(p)←nil
if (front = nil) then
    front←p                // 插入空队的情况 //
else
    link(rear)←p
rear←p                  // 插入非空队的情况 //
end
```

# 算法

```
procedure CHANGE( num )
    top←0
    while (num ≠ 0) do
        top←top+1
        STACK[top]← num MOD 8    // 余数进栈 //
        num←⌊num/8⌋
    end
    while (top ≠ 0) do
        print( STACK[top] )
        top←top-1                // 退栈 //
    end
```

# 例2

对任意给定的正整数m,n,计算下列递归函数的值：
f(m, n) = { m+n+1 当m×n=0时
f(m-1, f(m, n-1)) 当m×n≠0时 }

# 递归算法：

```
function F( m, n )
if (m×n=0) then
return( m+n+1 )
else
return( F( m-1, F(m, n-1)) )
end
```

$$f(m,n)=\begin{cases}m+n+1,&\text{当 }m\times n=0\text{ 时}\\f(m-1,f(m,n-1)),&\text{当 }m\times n\ne0\text{ 时}\end{cases}$$

以 $m=2,n=1$ 为例，该函数的计算过程：

```
f(2, 1) = f(1, f(2, 0))
      = f(1, 3)
      = f(0, f(1, 2))
      = f(0, f(0, f(1, 1)))
      = f(0, f(0, f(0, f(1, 0))))
      = f(0, f(0, f(0, 2)))
      = f(0, f(0, 3))
      = f(0, 4)
      = 5
```

# 非递归算法：

```
function F( m, n )
    top←0
    repeat
        if (m×n ≠ 0) then
        [   top←top+1
            STACK[top]←m−1        // 进栈 //
            n←n−1   ]
        else
        [   f←m+n+1
            if (top>0) then
                m←STACK[top]        // 退栈 //
                top←top-1
                n←f   ]
    until top= −1
    return( f )
end
```

# 5.1 广义表的概念

# 广义表的定义

一个长度为 n≥0 的广义表是一个数据结构

LS = (a₁, a₂, ……，aₙ₋₁, aₙ)

其中，LS 为广义表的名字，aᵢ 为表中元素；aᵢ 可以是原子元素，也可以是一个子表。n 为表的长度，长度为 0 的表称为空表。

若 aᵢ 为不可再分割的原子元素，则称 aᵢ 为原子元素；若 aᵢ 为一个子表，则称 aᵢ 为表元素。这里，用小写字母表示原子元素，用大写字母表示表元素。

(a₁, a₂, a₃, ……，aₙ₋₁, aₙ)

# 5.2 广义表的存储结构

广义表一般采用链式存储结构，链结点的构造可以为

| flag | info | link |

其中，flag为标志位，令

flag = { 1 表示本结点为表结点
0 表示本结点为原子结点 }

当flag=0时，info域存放相应原子元素的信息；

当flag=1时，info域存放子表第一个元素对应的链结点的地址；

link域存放本元素同一层的下一个元素所在链接点的地址，当本元素为所在层的最后一个元素时, link域为nil。
