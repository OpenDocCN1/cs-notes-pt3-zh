## 四. 调整子算法

功能：将以编号为 i 的结点作为根的子树调整为一个堆积。

```
procedure ADJUST(K, i, n)
  temp ← K[i]
  j ← 2 × i
  while (j ≤ n) do
    if (j < n and K[j+1] > K[j]) then
      j ← j + 1
    if (temp ≥ K[j]) then
      [ K[⌊j/2⌋] ← temp
        return ]
    K[⌊j/2⌋] ← K[j]
    j ← 2 × j
  end
  K[⌊j/2⌋] ← temp
end
```

K：序列
i：被调整的二叉树的根的序号
n：被调整的二叉树的结点数目

## 六. 堆积排序算法

```
procedure HEAPSORT( K, n )
  for i←⌊n/2⌋ downto 1 do
    call ADJUST( K, i, n )
  end
  for i←n-1 downto 1 do
    temp←K[i+1]
    K[i+1]←K[1]
    K[1]←temp
    call ADJUST( K, 1, i )
  end
end
```

## 10.8 一路归并排序法

### 一、什么是二路归并？

将两个位置相邻、并且各自按值有序的子序列合并为一个按值有序的子序列的过程称为二路归并。

$(K_s, K_{s+1}, K_{s+2}, …… , K_t)\quad (K_{t+1}, K_{t+2}, K_{t+3}, …… , K_u)$

$(X_s, X_{s+1}, X_{s+2}, X_{s+3}, …… , X_u)$

$K_s \le K_{s+1} \le K_{s+2} \le \cdots \le K_t$

$K_{t+1} \le K_{t+2} \le K_{t+3} \le \cdots \le K_u$

$X_s \le X_{s+1} \le X_{s+2} \le X_{s+3} \le \cdots \le X_u$

## 合并算法

将两个位置相邻且按值有序序列合并为一个按值有序的序列

```
procedure MERGE( X, s, t, u, Z )
	i←s
j←t+1
q←s
while ( i≤t and j≤u ) do
    if (X[i]≤X[j]) then
        [ Z[q]←X[i]
          i←i+1 ]
    else
        [ Z[q]←X[j]
          j←j+1 ]
    q←q+1
end
while (i≤t) do
    Z[q]←X[i]
    i←i+1
    q←q+1
end
while (j≤u) do
    Z[q]←X[j]
    j←j+1
    q←q+1
end
end
```

## 二. 二路归并排序法的核心思想

第i趟排序将序列的⌊n/2^{i-1}⌋个长度为2^{i-1}的按值有序的子序列依次两两合并为⌊n/2^{i}⌋个长度为2^{i}的按值有序的子序列。
