## 4.2 堆栈的顺序存储结构

### 一. 构造原理

描述堆栈的顺序存储结构最简单的方法是利用一维数组 STACK[ 1: M ] 来表示, 同时定义一个整型变量( 不妨取名为 top ) 给出栈顶元素的位置。

STACK[1: M]

![](img/f94080b0b6a6124b22e8484de896d7b7_164_0.png)

数组：静态结构
堆栈：动态结构

## 溢出

上溢 — 当堆栈已满时做插入操作。 (top=M)
下溢 — 当堆栈为空时做删除操作。 (top=0)

## 二. 插入(进栈)算法

![](img/f94080b0b6a6124b22e8484de896d7b7_166_0.png)

```
procedure PUSH( STACK, top, item )
    if (top=M) then
        call STACK_FULL('Stack is full!')
    else
        [ top←top+1
          STACK[top]←item ]
end
```

## 三. 判断堆栈是否为空

在顺序存储结构下，判断堆栈为空的标志是 top=0

```
function EMPTY( top )
    if (top=0) then
        return(1)        // 堆栈为空 //
    else
        return(0)        // 堆栈非空 //
    end
```

## 四. 删除(退栈)算法

![](img/f94080b0b6a6124b22e8484de896d7b7_168_0.png)

```
procedure POP(STACK, top, item)
if (top = 0) then
    if (EMPTY(top)=1) then
    call STACK_EMPTY('Stack is empty!')
else
[
    item ← STACK[top]
    top ← top -1
]
end
```

## 二. 插入(进栈)算法

![](img/f94080b0b6a6124b22e8484de896d7b7_172_0.png)

```
procedure PUSH_LINK_STACK( top, item )
call GETNODE(p)        //申请一个新结点//
data(p)←item          //将item送新结点数据域//
link(p)←top           //将新节点插在链表最前面//
top←p                 //修改栈顶指针的指向//
end
```

## 三. 删除(退栈)算法

![](img/f94080b0b6a6124b22e8484de896d7b7_173_0.png)

```
procedure POP_LINK_STACK( top, item )
if (top = nil) then
    call STACK_EMPTY( 'Stack is empty!' )
else
    [ p←top                //暂时保存栈顶节点的地址//
      item←data(top)       //保存被删栈顶的数据信息//
      top←link(top)        //删去栈顶节点//
      call RET(p) ]        //释放被删节点//
end
```

## 4.5 队列的基本概念

### 一. 队列的定义

队列简称队。是一种只允许在表的一端进行插入操作，而在表的另一端进行删除操作的线性表。允许插入的一端称为队尾，队尾元素的位置由rear指出； 允许删除的一端称为队头，队头元素的位置由front指出。

## 二. 队列的基本操作

- 1. 队列的插入 ADDQ(Q, item)
- 2. 队列的删除 DELQ(Q)
- 3. 测试队列是否为空 EMPTY(Q)
- 4. 检索当前队头元素 FRONTQ(Q)
- 5. 创建一个空队 CREATQ(Q)

## 特殊性:

- 1. 其操作仅是一般线性表的操作的一个子集。
- 2. 插入和删除操作的位置受到限制。

## 4.6 队列的顺序存储结构

### 一. 构造原理

在实际程序设计过程中，通常借助一个一维数组QUEUE[1: M] 来描述队列的顺序存储结构，同时，设置两个变量 front与rear分别指出当前队头元素与队尾元素的位置。

# 算法

```
procedure DELO( QUEUE, front, rear, item )
// 删除队头元素并保存在变量item中 //
if (front=rear) then
  call QUEUE_EMPTY('Queue is empty!')
else
  [
    front←front+1
    item←QUEUE[front]
  ]
end
```
