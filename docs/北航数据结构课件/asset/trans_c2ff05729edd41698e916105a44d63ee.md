## 一. 双向链表的构造

所谓双向链表是指链表的每一个结点中除了数据域以外设置两个指针域，其中之一指向结点的直接前驱结点，另外一个指向结点的直接后继结点。链结点的实际构造可以形象地描述如下：

![](img/f94080b0b6a6124b22e8484de896d7b7_102_0.png)

其中，data 为数据域
llink , rlink 分别为指向该结点的直接前驱结点与直接后继结点的指针域

## 双向链表的几种形式

无头结点的双向链表

无头结点的双向循环链表

带头结点的双向循环链表

## 二. 双向链表的插入

功能 在带有头结点的非空双向循环链表中 第一个数据域的内容为x的链结点右边插入一个数据信息为item的新结点。

![](img/f94080b0b6a6124b22e8484de896d7b7_104_0.png)

需要做的工作：

- 1. 找到满足条件的结点；
- 2. 若找到，申请一个新的链结点；
- 3. 将新结点插到满足条件的结点后面。

- `rlink(q) ← p`

## 算法

```
procedure INSERTD( list, x, item )
    q←rlink(list)                // q 初值时指向头结点的下一个结点 //
    while (q≠list and data(q)≠x) do
        q←rlink(q)
    end                         // 寻找满足条件的链结点 //
    if (q=list) then
    [ print(‘There is no this node !’)
      return ]                  // 没有找到满足条件的结点 //
    call GETNODE(p)              // 申请一个新的结点 //
    data(p)←item
    llink(p)←q
    rlink(p)←rlink(q)
    llink(rlink(q))←p
    rlink(q)←p
end
```

## 算法

# 寻找满足条件的结点

```
procedure DELETED( list, x )
    q←rlink(list)                                      // q初值指向头结点的下一个结点
    while (q≠list and data(q)≠x) do
        q←rlink(q)
    end                                                   // 找满足条件的链结点 //
    if (q=list) then
        [   print (‘There is no this node’)
            return   ]                                   // 没有找到满足条件的结点 //
    rlink(link(q))←rlink(q)
    llink(rlink(q))←llink(q)
    call RET(q)                                           // 释放被删除的结点的存储空间 //
    end
```

## 习题课 1

## 练习1

已知长度为n的线性表A采用顺序存储结构，并且数据元素按值大小非递减排列。写一算法，删除线性表中值相同的多余元素。

a_i ≠ a_{i+1}

a_i ≤ a_{i+1}  1≤i≤n-1

a₁, a₂, a₃, …, a_i, a_{i+1}, a_{i+2}, …, a_n

依次前移一个位置

```
for j←i+1 to n do
A[j-1]←A[j]
end
n←n-1
```

## 需要做的工作

寻找满足条件的元素，即从表中第一个元素开始到最后那个元素，反复比较相邻的两个元素是否相同，若相同，删除其中一个，否则，比较下一对元素。

```
for j←i+1 to n do
    A[j−1]←A[j]
end
n←n−1
```

## 算法

O(n²)

O(n)

```
procedure DEL(A, n)
    i ← 1
    while (i < n) do
        if (A[i] ≠ A[i+1]) then
            i ← i + 1
        else
            [ for j ← i+1 to n do
              A[j-1] ← A[j]
              end
              n ← n - 1 ]
        end
    end
```

删除一个元素

## 改进后算法

```
procedure DEL(A, n)
if (n>1) then
[  k←1
for i←2 to n do
if (A[i]≠A[k]) then
[  k←k+1
A[k]←A[i]  ]
end
n←k  ]
end
```

```
procedure DEL( list )
    p←link(list)
    r←list
    while (p≠nil) do
        q←list
        while (q≠p) do
            if (data(q)=data(p)) then
                [ link(r)←link(p)
                  call RET(p)
                  p←link(r)
                  q←list ]
            else
                q←link(q)
        end
        r←p
        p←link(p)
    end
end
```

## 练习3

若已知非空线性链表第一个节点的指针为list，请写一个算法，将该链表中数据域值最小的那个点移到链表的最前端。

```
procedure REMOVE(list)  
    q←list  
    p←link(list)  
    r←list  
    while (p≠nil) do  
        if (data(p)<data(q)) then  
            [ s←r  
              q←p ]  
        r←p  
        p←link(p)  
    end  
    if (q≠list) then  
        [ link(s)←link(q)  
          link(q)←list  
          list←q ]  
    end
```
