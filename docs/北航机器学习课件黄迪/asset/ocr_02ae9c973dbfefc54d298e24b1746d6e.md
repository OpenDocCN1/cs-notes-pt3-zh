# 如何有效训练深度神经网络

+   - Batch normalization

+   - 对激活后的输出归一化

```
Input: Values of x over a mini-batch: B = {x1...m};
Parameters to be learned: γ, β
Output: {yi = BNγ,β(xi)}

μB ← 1/m Σᵢ=1^m xi          // mini-batch mean
σ²B ← 1/m Σᵢ=1^m (xi - μB)²    // mini-batch variance
x̂i ← (xi - μB) / √(σ²B + ε)    // normalize
yi ← γx̂i + β ≡ BNγ,β(xi)    // scale and shift
```

+   - 可以选择较大的学习率
+   - 可以减少或不使用dropout
+   - 缓解梯度消失/爆炸问题
