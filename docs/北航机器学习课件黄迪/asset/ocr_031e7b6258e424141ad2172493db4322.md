# 等距映射

+   ● ISO-Metric Mapping (ISOMAP)

保持数据点内在几何性质(测地距离)

对于给定数据 $X = \{x_1, x_2, ..., x_N\}$，构造图 $G = \{V, E\}$

$V$是顶点集合，$E$是边的集合

若 $d(i, j) = dist(x_i, x_j)$

$G = (V, E)$

小于某个值 $\epsilon$ ($\epsilon$ − ISOMAP)

或 $j$ 是 $i$ 的 $K$ 近邻 ($K$ − ISOMAP)

则顶点 $i$ 与 $j$ 的边权值设为 $d(i, j)$，否则为 $0$。
