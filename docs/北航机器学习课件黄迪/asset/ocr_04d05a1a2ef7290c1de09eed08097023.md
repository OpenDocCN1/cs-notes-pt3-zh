# Slice Sampling

+   - **Metropolis 方法的缺点：**
+     - 步长太短：走得太慢（可能随机散步）
+     - 步长太长：拒绝率很高，效率较差；

+   - **SLICE采样可以自适应调整步长**
+     - 将 $z$ 空间扩展成 $(z, u)$ 空间

$\hat{p}(z, u) = \begin{cases} 1/Z_p & \text{if } 0 \le u \le \tilde{p}(z) \\ 0 & \text{otherwise} \end{cases}$

$\int \hat{p}(z, u) du = \int_{0}^{\tilde{p}(z)} \frac{1}{Z_p} du = \frac{\tilde{p}(z)}{Z_p} = p(z)$
