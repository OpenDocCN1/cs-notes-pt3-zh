# Generative Adversarial Networks(GAN)

● 固定 D

C(G) = max_D V(G, D)
= 𝔼_{x∼p_r(x)}[log D*_G(x)] + 𝔼_{z∼p_z(z)}[log(1 − D*_G(G(z)))]
= 𝔼_{x∼p_r(x)}[log D*_G(x)] + 𝔼_{x∼p_G(x)}[log(1 − D*_G(x))]
= 𝔼_{x∼p_r(x)}[log p_r(x)/(p_r(x)+p_G(x))] + 𝔼_{x∼p_G(x)}[log p_G(x)/(p_r(x)+p_G(x))]

● 最优的 G 为

p_G = p_r
