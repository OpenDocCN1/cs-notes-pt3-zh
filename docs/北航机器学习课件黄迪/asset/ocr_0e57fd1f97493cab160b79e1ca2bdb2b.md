# 第2-1步:计算年龄的经验条件熵

年龄共分三个组：
青年、中年、老年
青年买与不买比例为128/256

|D₁₁(买)|=128
|D₁₂(不买)|=256
|D₁|=|D₁₁|+|D₁₂|=384

P₁₁=128/384
P₁₂=256/384

H(青年|年龄)
=-P₁₁ Log₂ P₁ -P₁₂ Log₂ P₂
=-(P₁₁ Log₂ P₁₁ + P₁₂ Log₂ P₁₂)
=0.9183
