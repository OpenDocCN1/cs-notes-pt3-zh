# 基本采样法 (Basic Sampling)

+   例子：标准柯西分布
+   已知 $z \sim U(0,1)$
+   求 $y = f(z)$
+   使 $p(y) = \frac{1}{\pi}\frac{1}{1+y^2}$

$h(y) = \int_{-\infty}^{y} p(\hat{y}) d\hat{y} = \frac{1}{\pi} \arctan y + \frac{1}{2}$

$y = h^{-1}(z) = \pi \tan\left(z - \frac{1}{2}\right)$
