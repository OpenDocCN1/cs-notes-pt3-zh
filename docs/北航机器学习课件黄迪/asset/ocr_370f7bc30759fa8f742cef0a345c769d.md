# # 重要性采样（Importance Sampling）

+   - 对于个变量 $z \sim p(z)$，一个关于 $z$ 函数 $f(z)$，预测 $f(z)$ 的期望值：
+   
+     $$\mathbb{E}(f)=\int f(z)p(z)\,dz$$

+   - $p(z)$ 很复杂，或者无法写出解析形式，但可以估算每个出现在 $z$ 的概率 $p(z)$。要估计
+   
+     $$\mathbb{E}(f)=\int f(z)p(z)\,dz$$

+   - 可以按如下方式计算-将空间网络化
+   
+     $$\mathbb{E}(f)\approx\sum_{l=1}^{L}p\left(z^{(l)}\right)f\left(z^{(l)}\right)$$
