# 逻辑回归(Logistic Regression)

# 将回归问题转为分类问题

逻辑回归是概率型非线性回归，但其本质是线性回归，只是在特征到结果的映射中加入了一层函数映射，即先把特征线性求和，然后使用函数 σ(z) 来预测。

p(C₁|x) = p(x|C₁)p(C₁) / [p(x|C₁)p(C₁)+p(x|C₂)p(C₂)] = 1 / [1+exp(-a)] = σ(a)   a = ln [p(x|C₁)p(C₁) / p(x|C₂)p(C₂)]

# Sigmoid函数性质：

+   ①可以將連續值映射到0和1区间上

+   ②对称性 σ(-a) = 1 - σ(a)

+   ③反转性 a = ln(σ / (1-σ))

+   ④可导性 dσ/da = σ(1 - σ)
