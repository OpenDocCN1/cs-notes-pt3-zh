# # 反向传播(BP)算法

+   🔴 **练习：**

对非线性 $y_k=h(a_k)=h\left(\sum_j w_{kj}x_j\right)$

计算 $\frac{\partial E_n}{\partial w_{jk}}$，其中 $E=\frac{1}{2}\sum_k(y_k-t_k)^2$

$\frac{\partial E}{\partial w_{jk}}=(y_k-t_k)\frac{\partial y_k}{\partial w_{jk}}$

$=(y_k-t_k)\frac{\partial y_k}{\partial h}\frac{\partial h}{\partial w_{jk}}$

$=(y_k-t_k)h'(a_k)x_j$
