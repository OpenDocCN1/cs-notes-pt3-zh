# 隐马尔可夫模型
(Hidden Markov Models)

假设有N个缸，每个缸中装有许多个彩球

| 缸 | 1 | 2 | 3 | ... |
|---|---|---|---|---|
| 颜色1 | m₁₁ | m₁₂ | m₁₃ |  |
| 颜色2 | m₂₁ | m₂₂ | m₂₃ | ... |
| 颜色3 | m₃₁ | m₃₂ | m₃₃ |  |
| ... |  |  |  |  |

按照以下方式实验

+   - 随机从N个缸中选取一个
+   - 从中随机抽出一个球，记录其颜色O₁，并放回
+   - 以概率pᵢ转移到缸i
+   - 重复以上步骤

最后得到一个球的观测序列 O = {O₁, O₂, ..., O_T}
