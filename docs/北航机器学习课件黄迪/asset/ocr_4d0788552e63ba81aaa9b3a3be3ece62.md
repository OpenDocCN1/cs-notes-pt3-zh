# # 回归模型

$y(\mathbf{x},\mathbf{w})=\sum_{j=0}^{M-1}w_j\phi_j(\mathbf{x})=\mathbf{w}^{\mathrm{T}}\boldsymbol{\phi}(\mathbf{x})$

最简单的情况下：$\phi_j(x)=x_j$

+   - **多项式基函数**  
+     $\phi_j(x)=x^j$

![](bbox=[0.094, 0.656, 0.321, 0.958])

+   - **高斯基函数**  
+     $\phi_j(x)=\exp\left\{-\frac{(x-\mu_j)^2}{2s^2}\right\}$

![](bbox=[0.421, 0.656, 0.641, 0.958])

+   - **Sigmoid基函数**  
+     $\phi_j(x)=\sigma\left(\frac{x-\mu_j}{s}\right)$，$\sigma(a)=\frac{1}{1+\exp(-a)}$

![](bbox=[0.735, 0.656, 0.959, 0.958])
