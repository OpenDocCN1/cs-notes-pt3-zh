# 非参数估计

直接用样本估计总体分布

p(x)为x的总体概率密度函数，N个样本 x={x₁, x₂, ..., x_N}从密度为p(x)的总体中独立抽取，估计 p̂(x) 近似 p(x)。

考虑随机向量 x 落入区域ℜ的概率 P_R = ∫_ℜ p(x)dx

k个样本落入该区域的概率符合二项分布 P_k = C_N^k P_R^k (1 - P_R)^{N - k}

E[k] = N P_R ⟶ P̂_R ≐ k / N

设p(x)连续，且区域体积V足够小，则有 P_R = ∫_ℜ p(x)dx = p(x)V

p̂(x) = k / (N V) 与总样本数、区域的体积及落入的样本数有关
