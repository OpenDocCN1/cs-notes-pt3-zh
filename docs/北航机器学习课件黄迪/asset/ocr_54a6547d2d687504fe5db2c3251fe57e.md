# # 拒绝采样（Rejection Sampling）

+   - 对一个很复杂的分布 $p(z)$ 进行采样，但又无法给出其具体的解析形式，但是每个 $z$ 可以计算其概率
+   
+     $$p(z)=\frac{1}{Z_p}\tilde{p}(z)$$
+   
+     其中 $\tilde{p}(z)$ 已知，$Z_p$ 未知。

+   - 借助一个容易采样的分布 $q(z)$ 去逼近 $\tilde{p}(z)$
+   
+     $q(z)$ 称为**建议分布**（proposal distribution）。
