# Metropolis-Hastings 方法

+   步骤：
+   1、 初始化马尔可夫链状态 $z = z_0$
+   2、 对 $\tau = 1,2,...$ 循环以下过程采样
+      1) 第 $\tau$ 个时刻马尔可夫链状态为 $z = z^{(\tau)}$ 采样 $z^* = q(z|z^{(\tau)})$ 
+      2) 从均匀分布中采样 $u \sim \text{uniform}[0,1]$
+      3) 如果 $u < a(z^{(\tau)}, z^*) = p(z^*) q(z^{(\tau)}|z^*)$ 则接受 $z^{(\tau+1)} = z^*$
+      4) 否则 $z^{(\tau+1)} = z^{(\tau)}$
+   
+   如果 $a(z^{(\tau)}, z)$ 过小，则采样效率较低！
