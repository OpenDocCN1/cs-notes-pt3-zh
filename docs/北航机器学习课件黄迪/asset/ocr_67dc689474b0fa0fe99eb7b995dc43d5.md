# # 序列最小优化算法

# ● 两个变量二次规划的解析方法

不失一般性，假设选择的两个变量是 $a_1$ 和 $a_2$，其他变量 $a_i$（$i=3,4,\ldots,N$）是固定的，原问题的子问题可以写成：

$$\begin{aligned}
\min_{a_1,a_2}\quad W(a_1,a_2)={}&\frac{1}{2}K_{11}a_1^2+\frac{1}{2}K_{22}a_2^2+t_1t_2K_{12}a_1a_2\\
&-(a_1+a_2)+t_1a_1\sum_{n=3}^{N}t_na_nK_{n1}+t_2a_2\sum_{n=3}^{N}t_na_nK_{n2}+const\\
\text{s.t.}\quad &a_1t_1+a_2t_2=-\sum_{n=3}^{N}t_na_n=\zeta\\
&0\leq a_n\leq C,\quad i=1,2
\end{aligned}$$

其中，$K_{mn}=K(x_m,x_n)$，$m,n=1,2,\ldots,N$，$\zeta$ 是常数。
