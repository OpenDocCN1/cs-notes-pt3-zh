# Markov Random Fields

+   - 分布形式化：
+     - 使用基于极大团的势函数（因子）
+       - 对于图中节点的一个子集，若其中任意两节点间都有边连接，则称该节点子集为一个“团”（clique）。若一个团中加入另外任何一个节点都不再形成团，则称该团为“极大团”（maximal clique）
+       - 图中{x₁, x₂}, {x₂, x₆}, {x₂, x₅, x₆}等为团
+       - 图中{x₂, x₆}不是极大团
+       - 每个节点至少出现在一个极大团中
+     - 多个变量之间的连续分布可基于团分解为多个因子的乘积
