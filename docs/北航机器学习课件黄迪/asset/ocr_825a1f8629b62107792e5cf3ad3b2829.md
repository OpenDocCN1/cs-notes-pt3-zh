# 布丰投针问题

1777年法国科学家布丰（Buffon）提出一种计算圆周率π的方法—随机投针法。

+   1、在平面上画上间距为a的平行线

+   2、取一根长度为l（l<a）的针，随机投掷于平面上，针与任一线相交的概率p为

p = 2l / (π a)

π的值可计算为：

π = 2l / (a p) ≈ 2l / a (N / n)

N为总的投针次数，n为与平行线相交次数
