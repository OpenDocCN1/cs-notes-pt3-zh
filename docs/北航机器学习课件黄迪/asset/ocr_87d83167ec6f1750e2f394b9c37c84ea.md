# 自适应拒绝采样
(Adaptive Rejection Sampling)

+   - 实际应用中，往往很难找到合适的 $q(z)$
+   - 特别地，当 $p(z)$ 为 log 凸函数时，可采用 ARS

$q(z) = k_i \lambda_i \exp\{-\lambda_i (z - z_{i-1})\} \quad z_{i-1} < z \le z_i$

$\ln q(z) = C - \lambda (z - z_{i-1}), \quad z_{i-1} < z \le z_i$
