# Markov Random Fields

+   - 极大团的势函数（因子）：
+     - 多个变量之间的连续分布可基于团分解为多个因子的乘积，每个因子只与一个团相关
+     - 对于 n 个变量 x = {x₁, x₂, ... xₙ}，所有团构成的集合为 C，与团 Q ∈ C 对应的变量集合记为 x_Q，则联合概率定义为：
+       $$P(\mathbf{x}) = \frac{1}{Z} \prod_{Q \in C} \psi_Q(\mathbf{x}_Q)$$ 
+     - 其中，ψ_Q 是于团 Q 对应的势函数
+     - 若变量问题较多，需要考虑极大团
