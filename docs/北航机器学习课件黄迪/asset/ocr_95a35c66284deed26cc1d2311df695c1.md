# 支持向量机

处理噪声和离群点

利用拉格朗日乘子法求解：

L(w, b, ξ, a, μ) = 1/2 ||w||² + C ∑_{n=1}^{N} ξ_n - ∑_{n=1}^{N} a_n {t_n y(x_n) - 1 + ξ_n} - ∑_{n=1}^{N} μ_n ξ_n

a_n ≥ 0; μ_n ≥ 0

# KKT条件：

+   a_n ≥ 0
+   t_n y(x_n) - 1 + ξ_n ≥ 0
+   a_n (t_n y(x_n) - 1 + ξ_n) = 0
+   μ_n ≥ 0
+   ξ_n ≥ 0
+   μ_n ξ_n = 0

# 优化w, b, {ξ_n}

+   ∂L/∂w = 0 ⇒ w = ∑_{n=1}^{N} a_n t_n x_n
+   ∂L/∂b = 0 ⇒ ∑_{n=1}^{N} a_n t_n = 0
+   ∂L/∂ξ_n = 0 ⇒ a_n = C - μ_n

# 代入L化简：

L̃(a) = ∑_{n=1}^{N} a_n - 1/2 ∑_{n=1}^{N} ∑_{m=1}^{N} a_n a_m t_n t_m x_n^T x_m
