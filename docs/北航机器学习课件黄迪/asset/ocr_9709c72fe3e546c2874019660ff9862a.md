# 线性支持向量机

样本集任意一点 $x_n$ 到分类面(满足 $t_n y(x_n) > 0$)的距离

$\frac{t_n y(x_n)}{\|w\|} = \frac{t_n (w^T x_n + b)}{\|w\|}$

优化 $w$ 和 $b$ 使 Margin 最大

$\arg\max_{w,b} \{ \frac{1}{\|w\|} \min_n [t_n (w^T x_n + b)] \}$

求解复杂

$w \to k w, b \to k b$

对于离超平面最近的点 $t_n (w^T x_n + b) = 1$

那么对于所有点满足 $t_n (w^T x_n + b) \ge 1$
