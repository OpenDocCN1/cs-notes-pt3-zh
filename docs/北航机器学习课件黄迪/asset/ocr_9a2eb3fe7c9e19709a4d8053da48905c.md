# # 生成式模型和判别式模型

# 🔴 生成式模型（Generative Model）

分别对各类的**类条件密度** $p(x|C_k)$ 和**先验概率** $p(C_k)$ 进行建模，之后利用贝叶斯定理计算**后验概率**

$$p(C_k|x)=\frac{p(x|C_k)p(C_k)}{\sum_j p(x|C_j)p(C_j)}$$

或者直接对**联合分布** $p(x,C_k)$ 建模得到后验概率
