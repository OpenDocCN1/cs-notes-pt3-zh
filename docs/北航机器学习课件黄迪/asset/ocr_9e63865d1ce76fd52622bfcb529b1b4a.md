# 最小二乘准则

求使 $J_S(a)$ 最小的 $a^*$ (最小二乘近似解/伪逆解/MSE解)

采用解析法求伪逆解 $J_S(a)=||e||^2=||Ya-b||^2=\sum_{}^{N}(a^T y_n-b_n)^2$

$\nabla J_S(a)=\sum_{n-1}^{N}2(a^T y_n-b_n)y_n=2Y^T(Ya-b)$

令 $\nabla J_S(a)=0$

得 $Y^T Y a^*=Y^T b$

矩阵 $Y^T Y$ 是 $\hat{d}\times\hat{d}$ 方阵一般非奇异

唯一解 $a^*=(Y^T Y)^{-1}Y^T b=Y^+ b$

其中 $\hat{d}\times N$ 矩阵 $Y^+=(Y^T Y)^{-1}Y^T$ 是 Y 的左逆矩阵

如何选 $b$?

$\boldsymbol{b}=\begin{bmatrix}N/N_1\\\cdots\\N/N_1\\N/N_2\\\cdots\\N/N_2\end{bmatrix}\begin{array}{c}N_1个\\N_2个\end{array}$

$a^*$ 等价于 Fisher 解

$g_0(x)=P(w_1|x)-P(w_2|x)$

$N\to\infty,\boldsymbol{b}=[1,1,\cdots,1]^T$ $N$ 个

以最小均方误差逼近贝叶斯判决函数
