# ## 第2-4步: 计算年龄的信息增益

年龄共分三个组：
青年、中年、老年
所占比例
青年组 384/1025=0.375
中年组 256/1024=0.25
老年组 384/1024=0.375

计算年龄的平均信息期望
H(年龄)=0.375*0.9183+
　　　　0.25*0+
　　　　0.375*0.9157
　　　　=0.6877
G(年龄信息增益)
　　　　=0.9537-0.6877
　　　　=0.2660
