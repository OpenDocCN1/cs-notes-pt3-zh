# 马尔可夫链（Markov Chain）

+   一个状态的边缘分布可以表示为
+   
+   $p(z^{(m+1)}) = \sum_{z^{(m)}} p(z^{(m+1)}|z^{(m)})p(z^{(m)})$

+   平稳性（Stationary，或不变性 Invariant）
+   
+   $p^*(z) = \sum_{z'} T(z',z)p^*(z')$

+   细致平稳（Detailed balance）-充分条件
+   
+   $p^*(z)T(z,z') = p^*(z')T(z',z)$
+   
+   $\sum_{z'} p^*(z')T(z',z) = \sum_{z'} p^*(z)T(z,z') = p^*(z)\sum_{z'} p(z'|z) = p^*(z)$
