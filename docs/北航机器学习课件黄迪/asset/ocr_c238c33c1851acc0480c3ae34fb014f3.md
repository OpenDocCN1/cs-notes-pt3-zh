# ID3算法-示例(2)

青年买与不买比例为128/256

| 计数 | 年龄 | 收入 | 学生 | 信誉 | 归类: 买计算机? |
|---|---|---|---|---|---|
| 64 | 青 | 高 | 否 | 良 | 不买 |
| 64 | 青 | 高 | 否 | 优 | 不买 |
| 128 | 青 | 中 | 否 | 良 | 不买 |
| 64 | 青 | 低 | 是 | 良 | 买 |
| 64 | 青 | 中 | 是 | 优 | 买 |

|D₁₁(买)|=128
|D₁₂(不买)|=256
|D₁|=|D₁₁|+|D₁₂|=384

P₁₁=128/384
P₁₂=256/384

H(青年|年龄)
=-P₁₁ Log₂ P₁ - P₁₂ Log₂ P₂
=-(P₁₁ Log₂ P₁₁ + P₁₂ Log₂ P₁₂)
=0.9183
