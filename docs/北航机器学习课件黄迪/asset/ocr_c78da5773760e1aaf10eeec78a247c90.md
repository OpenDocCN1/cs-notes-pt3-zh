# 广义线性判别函数

不适用于非凸和多连通区域划分

+   - 两类问题, X是一维样本空间
+   若 x < a 或 x > b, x ∈ w₁
+   若 a < x < b, x ∈ w₂
+   如果建立 g(x) = (x - a)(x - b)
+   决策规则 { g(x) > 0, x ∈ w₁
+   { g(x) < 0, x ∈ w₂
+   一般形式 g(x) = c₀ + c₁x + c₂x²
+   可转化为 g(x) = aᵀy = Σᵢ₌₁³ aᵢyᵢ
+   y = [y₁ y₂ y₃]ᵀ = [1 x x²]ᵀ    a = [a₁ a₂ a₃]ᵀ = [c₀ c₁ c₂]ᵀ
+   称 g(x) = aᵀy 广义线性判别函数
+    a 广义权向量

利用线性函数的简单性解决复杂问题

维数大大增加 → “维数灾难”
