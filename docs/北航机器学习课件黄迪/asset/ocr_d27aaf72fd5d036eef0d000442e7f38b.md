+   最大似然估计(w是确定量)

p(t|x,w,β)=∏_{n=1}^{N} N(t_n|y(x_n,w),β^{-1})

1/β_ML = 1/N ∑_{n=1}^{N} {y(x_n,w_ML)-t_n}^2

+   贝叶斯估计(w是随机量)

p(t|x,x,t)=∫ p(t|x,w)p(w|x,t)dw = N(t|m(x),s^2(x))

p(t|x,w,β)=N(t|y(x,w),β^{-1})

p(w|x,t,α,β) ∝ p(t|x,w,β)p(w|α)

m(x)=β φ(x)^T S ∑_{n=1}^{N} φ(x_n) t_n

s^2(x)=β^{-1}+φ(x)^T S φ(x)
