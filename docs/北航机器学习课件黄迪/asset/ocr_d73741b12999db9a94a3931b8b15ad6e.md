# 基本采样法 (Basic Sampling)

高斯分布：

z₁, z₂ ∼ U

p(z₁, z₂) = 1/π, (z₁ + z₂)² ≤ 1

y₁ = √(-2 ln z₁) cos(2π z₂)
y₂ = √(-2 ln z₁) sin(2π z₂)

y₁ = z₁ ((-2 ln z₁)/r²)^{1/2}
y₂ = z₂ ((-2 ln z₂)/r²)^{1/2}

r² = (z₁ + z₂)²

Box-Muller变换

p(y₁, y₂) = p(z₁, z₂) |∂(z₁, z₂)/∂(y₁, y₂)|

= [1/√(2π) exp(-y₁²/2)] [1/√(2π) exp(-y₂²/2)]
