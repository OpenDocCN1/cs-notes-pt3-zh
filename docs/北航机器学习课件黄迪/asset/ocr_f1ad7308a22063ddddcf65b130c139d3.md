# 基本采样法（Basic Sampling）

高斯分布：

![](bbox=[0.03, 0.33, 0.28, 0.68])

z1, z2 ~ U
p(z1, z2) = 1/π, (z1 + z2)² ≤ 1

y1 = √(-2 ln z1) cos(2π z2)
y2 = √(-2 ln z1) sin(2π z2)

y1 = z1 ((-2 ln z1)/r²)^{1/2}
y2 = z2 ((-2 ln z2)/r²)^{1/2}
r² = (z1 + z2)²

Box-Muller变换

p(y1, y2) = p(z1, z2) |∂(z1, z2)/∂(y1, y2)|
= [1/√(2π) exp(-y1²/2)] [1/√(2π) exp(-y2²/2)]
