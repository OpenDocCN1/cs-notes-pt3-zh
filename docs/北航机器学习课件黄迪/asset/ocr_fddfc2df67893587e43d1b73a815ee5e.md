# 序列最小优化算法

# SMO算法

输入：训练数据集 $T = (x_1, y_1), (x_2, y_2), ..., (x_N, y_N)$，其中 $x_i \in \mathcal{X} = R^n$，$y_i \in \mathcal{Y} = \{-1, +1\}, i = 1, 2, ..., N$，精度 $\epsilon$；

输出：近似解 $\hat{a}$。

+   (1) 取初值 $a^{(0)} = 0$，令 $k = 0$；

+   (2) 选取优化变量 $a_1^k, a_2^k$，解析求解两个变量的最优化问题，求得最优解 $a_1^{k+1}, a_2^{k+1}$，更新 $a$ 为 $a^{k+1}$；

+   (3) 若在精度 $\epsilon$ 范围内满足停止条件 其中， $g(x_i) = \sum_{j=1}^{N} a_j y_j K(x_j, x_i) + b$ 则转(4)；否则令 $k = k + 1$，转(2)；

$\sum_{i=1}^{N} a_i y_i = 0$  $0 \le a_i \le C, i = 1, 2, ..., N$  $y_i \cdot g(x_i) = \begin{cases} \ge 1, & \{x_i | a_i = 0\} \\ = 1, & \{x_i | 0 < a_i < C\} \\ \le 1, & \{x_i | a_i = C\} \end{cases}$

+   (4) 取 $\hat{a} = a^{(k+1)}$。
