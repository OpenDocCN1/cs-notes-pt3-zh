# Theorem 30.1 (Uniqueness of an interpolating polynomial)

For any set $\{(x_k, y_k)\}$ of $n$ point-value pairs, all the $x_k$ values are distinct, there is a unique polynomial $A(x)$ of degree-bound $n$ such that $y_k = A(x_k)$ for $k = 0,1,..., n - 1.$
