# Step 3: Computing the length of an LCS

X_m = <x₁, x₂, ..., x_m>
Y_n = <y₁, y₂, ..., y_n>

c[i, j] = 
{ 0 (if i = 0 or j = 0),
  c[i-1, j-1] + 1,
    (if i, j > 0 and x_i = y_j),
  max(c[i-1, j], c[i, j-1]),
    (if i, j > 0 and x_i ≠ y_j). }

Use table b[1..m, 1..n]
to simplify construction
of an optimal solution.
(使用b表构造最优解)

```
LCS-LENGTH(X, Y)        // X and Y as inputs
1  m ← length[X]
2  n ← length[Y]
3  for i ← 1 to m        // Table c[0..m, 0..n] stores c[i,j],
4    do c[i, 0] ← 0      // computed in row-major order.
5  for j ← 0 to n
6    do c[0, j] ← 0
7  for i ← 1 to m
8    for j ← 1 to n
9      if x_i = y_j
10       c[i, j] ← c[i-1, j-1] + 1
11       b[i, j] ← "↖"
12     else if c[i-1, j] ≥ c[i, j-1]  //use X_{i-1}, Y_j
13       c[i, j] ← c[i-1, j]
14       b[i, j] ← "↑"
15     else  c[i, j] ← c[i, j-1]
16       b[i, j] ← "←"
17 return c and b
```
