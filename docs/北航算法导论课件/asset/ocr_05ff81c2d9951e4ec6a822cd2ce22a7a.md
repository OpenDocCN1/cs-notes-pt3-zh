# 5.1.3 Randomized algorithms

+   - **Random number generator（随机数产生器）**
+     - Most random number generators generate a sequence of integers by the following recurrence
+     - X₀= a given integer (seed), Xᵢ₊₁ = aXᵢ mod M
+     - For example, for X₀=1, a=5, M=13, we have X₁=5%13=5, X₂=25%13=12, X₃=60%13=8. Each integer in the sequence lies in the range [0, M - 1].
