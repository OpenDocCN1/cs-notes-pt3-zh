# 34.7 Boolean Satisfiability

+   - **A logical (Boolean) variable** is a variable that may be assigned the value *true* (T or 1) or *false* (F or 0), e.g.,
+     - *p, q, r* and *s* are Boolean variables.
+   - **A literal (文字)** is a logical variable or the negation of a logical variable, e.g. *p* and ¬*q* are literals.
+     - If *p*=T, then ¬*p*=F. If *p*=F, then ¬*p*=T
+   - **A clause (子句)** is a disjunction (析取) of literals, e.g. (*p*∨*q*∨*s*) and (¬*q*∨*r*) are clauses.
+     - If *l*=T, then *l*∨*l*₁∨...∨*l*ₖ = T
+     - If *l*=F, then *l*∨*l*₁∨...∨*l*ₖ = *l*₁∨...∨*l*ₖ
