# 17.4.1 Table expansion - potential method

+   - potential function : Φ(T) = 2T.num − T.size
+     - Immediately after an expansion, we have T.num = T.size/2, thus Φ(T) = 0.
+     - Immediately before an expansion, we have T.num = T.size, thus Φ(T) = T.num.
+   - For the i-th TABLE-INSERT operation, the amortized cost is 3

![](bbox=[0.06, 0.42, 0.48, 0.92])

```
TABLE-EXPANSION(T, n)
T = NULL
for j←1 to n
TABLE-INSERT(T, x)
```
