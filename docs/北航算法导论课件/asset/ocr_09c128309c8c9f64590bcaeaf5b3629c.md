# Solution

# 15.4-4    $2\cdot\min(m,n)$

![](bbox=[0.052, 0.252, 0.451, 0.635])

Use table $c_{2\times(j+1)}$ to save the length # of an LCS. Red line show the order of computing.

```
MAXMIN-LENGTH(X, Y)
1  m ← length[X]
2  n ← length[Y]
3  if m ≥ n
4      LCS-LENGTH(X, m, Y, n)
5  else
6      LCS-LENGTH(Y, n, X, m)
```

```
LCS-LENGTH(X, m, Y, n)
1   for j ← 0 to n
2       c[0, j] ← 0
3   c[1, 0] ← 0
4   for i ← 1 to m
5       for j ← 1 to n
6           if xᵢ = yⱼ
7               c[1, j] ← c[0, j-1] + 1
8           else if c[0, j] ≥ c[1, j-1]
9               c[1, j] ← c[0, j]
10          else c[1, j] ← c[1, j-1]
11  for j ← 1 to n
12      c[0, j] ← c[1, j]
13  return c
```
