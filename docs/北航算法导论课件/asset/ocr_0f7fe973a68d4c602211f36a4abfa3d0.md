+   Store which choice we made in each subproblem in a table.
+   （求解最优问题时，将所选的子问题的选项存储在一个表中）

+   Assembly-line scheduling
+     Store in l_i[j] the station preceding S_{i,j} in a fastest way through S_{i,j}.
+     （l_i[j] 记录通过 S_{i,j} 的最快路径中的前一个 station 的行号）
+     Alternatively, having filled in the entire f_i[j] table, we could determine which station precedes S_{1,j} in a fastest way through S_{1,j}. If f1[j] = f1[j-1] + a_{1,j}, chose S_{1,j-1}. Otherwise, f1[j] = f2[j-1] + t_{2,j-1} + a_{1,j}, so S_{2,j-1} precedes S_{1,j}.

+   Reconstructing the predecessor stations takes only O(1) time per station, even without the l_i[j] table. （即使没有 l_i[j]，求通过每一个 station 的前一个 station 也仅需 O(1)）
