# 30.2.1 Complex roots of unity

# Lemma 30.3 (Cancellation lemma, 可约（相消）引理)
For any integers n≥0, k≥0, and d >0,

ω_{dn}^{dk} = ω_n^{k}.  (30.7)

Proof  ω_{dn}^{dk} = (e^{2πi / dn})^{dk} = (e^{2πi / n})^{k} = ω_n^{k}.

( ω_8^2 = ω_4^1,   ω_8^4 = ω_4^2,   ω_8^6 = ω_4^3,   ω_8^8 = ω_4^4 )

# Corollary (推论) 30.4 For any even integer n>0,

ω_n^{n/2} = ω_2 = -1.

ω_n^{n/2} = ω_{(n/2)·2}^{n/2} = ω_2 = e^{2πi /2} = cos π + i sin π = -1.
