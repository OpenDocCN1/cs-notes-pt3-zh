# Improving the code

+   - Given an algorithm, you can improve on the time or space it uses. （给定一个算法，可以考虑改进其时间和空间开销）
+   - Some changes can simplify the code and improve constant factors but yield no asymptotic improvement in performance. （一些改变能简化代码，改进其常系数，但不能改进渐近性能）
+   - For example, we can eliminate the b table when constructing an LCS. Each c[i,j] entry depends on only: c[i-1,j-1], c[i-1,j], and c[i,j-1]. Given the value of c[i,j], we can determine in O(1) time which of these three values was used to compute c[i,j], without inspecting table b. (Exercise 15.4-2) （例如，重构an LCS 可以仅使用表 c，......）
+   - Save Θ(mn) space by this method, the space requirement does not asymptotically decrease, since we need Θ(mn) space for the c table anyway. （不使用表 b 可以节省Θ(mn)的空间开销，但算法的空间开销不会渐近减少，因为表 c 需要Θ(mn)的存储空间）
