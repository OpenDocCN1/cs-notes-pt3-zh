# 15.3.1 Optimal substructure : Subtleties

+   What’s the big difference between shortest path and longest simple path?
+   （最短路径和最长简单路径的最大不同是什么？）

+   Shortest path has independent subproblems.

+   Independent: solution to one subproblem does not affect solution to another subproblem of the same problem.
+   （独立性：相同问题中，一个子问题的解不影响另一个子问题的解）

+   Longest simple path: subproblems are not independent.
