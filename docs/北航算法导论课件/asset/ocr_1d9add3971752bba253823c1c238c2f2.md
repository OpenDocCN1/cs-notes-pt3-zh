# 2.1 Insertion sort

```
INSERTION-SORT(A)
1   for(j = 2; j <= length[A]; j++) // loop header
2   {      key = A[j]
3       // Insert A[j] into the sorted sequence A[1 .. j-1]
4       i <- j-1
5       while(i > 0 && A[i] > key)
6       {      A[i+1] = A[i]
7           i = i-1
8       }
9       A[i+1] = key
10  }   // loop body below
```
