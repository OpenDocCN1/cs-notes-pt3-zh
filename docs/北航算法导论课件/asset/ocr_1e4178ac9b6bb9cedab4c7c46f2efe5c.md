# 15.4 Longest common subsequence

+   - Compare the DNA of two (or more) different organisms.
+     （比较两个不同生物体的 DNA）

+   - A strand of DNA: a string of molecules, bases (Adenine, Guanine, Cytosine（氧氮嘧啶）, Thymine)
+     （多个分子bases以不同的组合方式构成一个 DNA 串）
+     - a strand of DNA ∈ finite set {A, C, G, T}
+     - for example, two organism’s DNA
+       S₁= ACCGGTCGAGTGCGCGGAAGCCGGCCGAA
+       S₂= GTCGTTCGGAATGCCGTTGCTCTGTAAA

+   - Goal: how “similar” the two strands are?
+     （研究目标：确定两个DNA序列的相似程度）
