# 4.1.1 Making a good guess

+   Another way to make a good guess is to prove loose upper and lower bounds on the recurrence and then reduce the range of uncertainty.
+   （寻找松的上、下渐近界，范围缩小，逐步逼近）

For example

```
T(n) = 2T(⌊n/2⌋) + n      (4.4)
```

+   we might start with a lower bound of T(n) = Ω(n), since we have the term n in the recurrence,

+   and we can prove an initial upper bound T(n) = O(n²).

+   Then, we can gradually lower the upper bound and raise the lower bound until we converge on the correct, asymptotically tight solution of T(n) = Θ(n lg n).
