# To extend boundary conditions

T(n) = 2T(⌊n/2⌋) + n ;  T(n) = O(n lg n) , T(n) ≤ c n lg n

+   - An inductive hypothesis inconsistent with specific boundary condition, How to overcome the difficulty? (如何克服递归结果与边界条件不一致的问题？)

+   - asymptotic notation only requires us to prove T(n) ≤ c n lg n for n ≥ n₀, where n₀ is a constant.

+   - to remove the difficult boundary condition T(1) = 1

+   - Impose T(2) and T(3) as boundary conditions for the inductive proof.

+   - From the recurrence, we derive T(2) = 2*T(1) + 2 = 4 , T(3) = 2*T(1) + 3 = 5.

+   - The inductive proof that T(n) ≤ c n lg n can now be completed by choosing any c ≥ 2 so that T(2) = 4 ≤ c*2 lg 2 and T(3) = 5 ≤ c 3 lg 3.
