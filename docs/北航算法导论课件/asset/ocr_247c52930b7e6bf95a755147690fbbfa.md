# 16.1.2 A recursive solution

+   - Let $c[i, j]$ = size of maximum-size subset of mutually compatible activities in $S_{ij}$. ($c[i,j]$ 表示 $S_{ij}$ 相容的最大活动数)
+     $i \ge j \Rightarrow S_{ij} = \varnothing \Rightarrow c[i, j] = 0.$
+   - If $S_{ij} \ne \varnothing$, suppose that $a_k$ is used in a maximum-size subsets of mutually $S_{ij}$. Then $c[i, j] = c[i, k] + 1 + c[k, j]$.
+   - But of course we don’t know which $k$ to use, and so
+     $c[i, j] = \begin{cases} 0 & , \text{if } S_{ij} = \varnothing, \\ \max_{i<k<j}\{c[i,k]+c[k,j]+1\} & , \text{if } S_{ij} \ne \varnothing. \end{cases}$ (16.3)

Why this range of $k$? Because $S_{ij} = \{a_k \in S: f_i \le s_k < f_k \le s_j\} \Rightarrow a_k$ can’t be $a_i$ or $a_j$ ( if $k = i$, we have $c[i,j] = c[i,j] + 1$).
