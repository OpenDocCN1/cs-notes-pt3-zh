# 15.3.2 Overlapping subproblems

T(1) ≥ 1,
T(n) ≥ 1 + Σ_{k=1}^{n-1} (T(k) + T(n−k) + 1) = 2 Σ_{i=1}^{n-1} T(i) + n , for n > 1
T(n) ≥ Ω(2ⁿ),      T(n) ≥ 2^{n-1}
T(n) ≥ 2 Σ_{i=1}^{n-1} T(i) + n ≥ 2 Σ_{i=1}^{n-1} 2^{i-1} + n
    = 2 Σ_{i=0}^{n-2} 2^{i} + n = 2(2^{n-1} − 1) + n = (2^{n} − 2) + n = 2^{n} + n − 2
    ≥ 2^{n-1}

+   - Matrix-chain multiplication: Θ(n²) different subproblems
+   - Recursive algorithm: Ω(2ⁿ)
+   - Dynamic-programming algorithm: O(n³)
