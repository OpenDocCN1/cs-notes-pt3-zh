# 15.4 Longest common subsequence

+   - **How to define the similarity of $S_1$ and $S_2$?**
+     - $S_1$ and $S_2$ are similar if one is a substring of the other.
+     - （如果一个串是另一个串的子串，则$S_1$和$S_2$相似）
+     - $S_1=GTCGTCGGAA\qquad S_2=GTCGTCTCG$
+     - If the number of changes needed to turn one into the other is small. （将一个串变换为另一个串，变换数量少）
+     - $S_1=GACTAACG$
+     - $S_2=GTCGTACT$
