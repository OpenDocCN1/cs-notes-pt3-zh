T(n) = { 1 , if n = 1
2T(n/2) + n , if n > 1 } (4.1)

```
MERGE-SORT(A, p, r)                          cost
                                            T(n)
1   if p < r
2       Then q ← ⌊(p + r)/2⌋
3       MERGE-SORT(A, p, q)                  T(n/2)
4       MERGE-SORT(A, q+1, r)                T(n/2)
5       MERGE(A, p, q, r)                    n
```
