# Analysis of the hiring problem

We need to compute Pr{ candidate i is hired}?

+   i is hired ⇔ i is better than each of candidates 1, 2, ..., i-1.

+   Thus, E{X_i} = Pr{ candidate i is the best so far} = 1/i ?
