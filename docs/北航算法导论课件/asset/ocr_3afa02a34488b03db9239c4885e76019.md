# 2.2.1 Analysis of insertion sort

```
INSERTION-SORT(A)
1   for(j = 2; j <= length[A]; j++)
2   {   key = A[j]
3       // Insert A[j] into the sorted sequence A[1 .. j-1]
4       i = j-1
5       while(i > 0 && A[i] > key)
6       {   A[i+1] = A[i]
7           i = i-1
8       }
9       A[i+1] = key
10  }
```

| cost | times |
|------|-------|
| c₁ | n |
| c₂ | n-1 |
| 0 | n-1 |
| c₄ | n-1 |
| c₅ | Σⱼ=2ⁿ tⱼ |
| c₆ | Σⱼ=2ⁿ (tⱼ -1) |
| c₇ | Σⱼ=2ⁿ (tⱼ -1) |
| c₈ | n-1 |

T(n) = c₁ n + c₂ (n-1) + c₄ (n-1) + c₅ Σⱼ=2ⁿ tⱼ + c₆ Σⱼ=2ⁿ (tⱼ -1) + c₇ Σⱼ=2ⁿ (tⱼ -1) + c₈ (n-1)
