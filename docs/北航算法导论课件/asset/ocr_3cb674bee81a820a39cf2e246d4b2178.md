# 30.1.2 Point-value representation

+   - polynomial representation  $A(x)=\sum_{j=0}^{n-1} a_j x^j$
+     coefficient form $a = (a_0, a_1, ..., a_{n-1})^T$  evaluation  point-value form $\{(x_j, y_j)\}$  interpolation

+   - quite convenient for many operations on polynomials

+   - addition, if $C(x)=A(x)+B(x)$, then $C(x_k)=A(x_k)+B(x_k)$ for any point $x_k$.

+   - More precisely, if we have a point-value representation for $A : \{(x_0, y_0), (x_1, y_1), ..., (x_{n-1}, y_{n-1})\}$, and for $B : \{(x_0, z_0), (x_1, z_1), ..., (x_{n-1}, z_{n-1})\}$, then $C : \{(x_0, y_0+z_0), (x_1, y_1+z_1), ..., (x_{n-1}, y_{n-1}+z_{n-1})\}$

+   - takes time $\Theta(n)$.
