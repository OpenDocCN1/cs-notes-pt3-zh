# 15.3.1 Optimal substructure : Subtleties

+   - **Shortest path has optimal substructure.**
+     - Suppose *p* is shortest path *u* ↝ *v*.
+     - Let *w* be any vertex on *p*.
+     - Let *p₁* be the portion of *p*, *u* ↝ *w*.
+     - **Then *p₁* is a shortest path *u* ↝ *w*.**

**Proof.** Suppose there exists a shorter path *p′₁*, *u* ↝ *w*. cut out *p₁*, replace it with *p′₁*, get path *u* ↝ *w* ↝ *v* with fewer edges than *p*.

+   - **Same argument applies to *p₂*.**

Therefore, we can find shortest path *u* ↝ *v* by considering all intermediate vertices *w*, then finding shortest paths *u* ↝ *w* and *w* ↝ *v*.
