# 16.3.2 Constructing a Huffman code

Example:
Huffman's algorithm proceeds. 6 letters,
5 merge steps.
The final tree represents the optimal prefix code.

```
HUFFMAN(C)
1 n ← |C|
2 Q ← C
3 for i ← 1 to n - 1
4   allocate(分配) a new node z
5   left[z] ← x ← EXTRACT-MIN (Q)
6   right[z] ← y ← EXTRACT-MIN (Q)
7   f[z] ← f[x] + f[y]
8   INSERT(Q, z)
9 return EXTRACT-MIN(Q) //return the root of the tree.
```
