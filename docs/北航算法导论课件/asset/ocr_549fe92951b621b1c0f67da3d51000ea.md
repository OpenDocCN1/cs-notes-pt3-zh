# 3.1.1 Θ-notation: asymptotically tight bound (渐近紧界)

+   - What this notation T(n)=Θ(n²) means

For a given function g(n), we denote by Θ(g(n)) the set of functions Θ(g(n)) = {f(n): there exist positive constants c₁, c₂, and n₀ such that 0 ≤ c₁g(n) ≤ f(n) ≤ c₂g(n) for all n ≥ n₀}.

We could write “f(n) ∈ Θ(g(n))” to indicate that f(n) is a member of Θ(g(n)).

Instead, we will usually write “f(n)=Θ(g(n))” to express the same notion. The abuse may at first appear confusing, but it has advantages.
