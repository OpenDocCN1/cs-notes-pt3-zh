# 15.3.1 Optimal substructure

+   - Informally, **running time** depends on
+     (# of subproblems overall) × (# of choices for each subproblem)
+   - Assembly-line scheduling
+     Θ(n) subproblems, 2 choices for each ⇒ Θ(n) running time.
+   - Matrix-chain multiplication  A_i A_{i+1} … A_k A_{k+1} A_{k+2} … A_j
+     Θ(n²) subproblems overall, at most n-1 choices for each
+     ⇒ O(n³) running time.
