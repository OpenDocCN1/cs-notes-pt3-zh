# Polynomials multiplication（多项式相乘）

+   - $A(x), B(x)$, degree-bound $n$
+   - $C(x)=A(x)B(x)$, degree-bound $2n-1$

For example, multiply $A(x)=6x^3+7x^2-10x+9$ and $B(x)=-2x^3+4x-5$

```
        6x³ + 7x² − 10x + 9
×      −2x³       + 4x − 5
────────────────────────────
       30x³ − 35x² + 50x − 45
  24x⁴ + 28x³ − 40x² + 36x
− 12x⁶ − 14x⁵ + 20x⁴ − 18x³
────────────────────────────
− 12x⁶ − 14x⁵ + 44x⁴ − 20x³ − 75x² + 86x − 45
```

+   - **Running time:** $T(n)=\Theta(n^2)$
