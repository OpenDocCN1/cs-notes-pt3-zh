# 5.2 Indicator random variables（指示随机变量）

▪ **Lemma**

**For an event A, let X_A = 𝟙{A}. Then E[X_A] = Pr{A}.**

+   - **Slightly more complicated example:** Determine the expected number of heads when in *n* coin flips.
+   
+     （投 *n* 次硬币，正面向上的期望（平均数））
+   
+     - Let X be a random variable for the number of heads in *n* flips. （令随机变量 X 表示 *n* 次硬币正面向上的数）
+   
+     - Then, E[X] = ∑_{k=0}^{n} k · Pr{X = k}
+   
+       a slightly more complicated? Yes!
+   
+     - Instead, we'll use indicator random variables……
