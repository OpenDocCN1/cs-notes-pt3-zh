# 16.1.4 A recursive greedy algorithm

```
REC-ACTIVITY-SELECTOR(s, f, i, n)
1 m ← i+1
2 while m ≤ n and s_m < f_i  // Find first activity in S_{i,n+1}.
3     m ← m+1
4 if m ≤ n
5     return {a_m} ∪ REC-ACTIVITY-SELECTOR(s, f, m, n)
6 else return ∅
```

+   Time: Θ(n)—each activity examined exactly once.

T(n) = m₁ + T(n − m₁) = m₁ + m₂ + T(n − m₁ − m₂)
    = m₁ + m₂ + m₃ + T(n − m₁ − m₂ − m₃) = …
    = Σ m_k + T(n − Σ m_k)

basecase: n − Σ m_k = 1, then Σ m_k = n − 1, Σ m_k + T(1) = Θ(n)
