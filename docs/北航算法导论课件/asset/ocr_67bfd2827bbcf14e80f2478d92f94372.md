# 3.1.7 Comparison of functions

+   - **Reflexivity（自反性）**
+     $f(n) = \Theta(f(n))$,
+     $f(n) = O(f(n))$,
+     $f(n) = \Omega(f(n))$.

+   - **Symmetry（对称性）**
+     $f(n) = \Theta(g(n))$ if and only if $g(n) = \Theta(f(n))$.

+   - **Transpose symmetry（反对称性）**
+     $f(n) = O(g(n))$ if and only if $g(n) = \Omega(f(n))$,
+     $f(n) = o(g(n))$ if and only if $g(n) = \omega(f(n))$.
