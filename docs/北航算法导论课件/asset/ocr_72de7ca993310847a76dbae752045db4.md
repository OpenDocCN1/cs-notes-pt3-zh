# * 4.3 The recursion-tree method

+   - Drawing out a recursion tree, is a straightforward way to devise a good guess, and to show the iteration method intuitively.（画递归树可以从直观上表示迭代法，也有助 于猜想递归式的解）

+   - Recursion trees are particularly useful when the recurrence describes the running time of a divide-and-conquer algorithm.
