# 15.5 Optimal binary search trees

+   - Optimal BST : for a given set of probabilities, our goal is to construct a BST whose expected search cost is the smallest.

+   - Figure 15.7(b) shows an optimal BST's expected cost is 2.75

+   - An optimal BST is not necessarily a tree whose overall height is smallest. （不一定要要求树的高度最小）

+   - Nor can we necessarily construct an optimal BST by always putting the key with the greatest probability at the root. (The lowest expected cost of any BST with k5 (the greatest probability ) at the root is 2.85.) （不一定将概率最大的 key 放在树根，如...）
