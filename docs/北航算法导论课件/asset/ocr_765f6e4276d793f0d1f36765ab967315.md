# 30.2.3 The FFT

even, A^[0](x)=a₀+a₂x+a₄x²+...+aₙ₋₂xⁿ/2-1;

odd, A^[1](x)=a₁+a₃x+a₅x²+...+aₙ₋₁xⁿ/2-1.

A(x)=∑_{j=0}^{n-1} a_j x^j

A(x)=A^[0](x²)+xA^[1](x²)

ω_n^k      (ω_n^k)²=ω_{n/2}^k

A(ω_n^k)=A^[0](ω_{n/2}^k)+(ω_n^k)·A^[1](ω_{n/2}^k),

A(ω_n^{n/2+k})=A^[0](ω_{n/2}^k)-(ω_n^k)·A^[1](ω_{n/2}^k),

k=0,...,n/2−1

```
RECURSIVE-FFT(a)
1  n = a.length
2  if n == 1
3    return a
4  ω_n = e^{2πi/n}
5  ω = 1
6  a^[0] = (a₀, a₂, ..., a_{n-2})
7  a^[1] = (a₁, a₃, ..., a_{n-1})
8  y^[0] = RECURSIVE-FFT(a^[0])
9  y^[1] = RECURSIVE-FFT(a^[1])
10 for k = 0 to n/2 − 1
11   y_k = y_k^[0] + ω y_k^[1]
12   y_{k+(n/2)} = y_k^[0] − ω y_k^[1]
13   ω = ω ω_n
14 return y
```

in line 11-12, each y_k^[1] is multiplied by ω_n^k, the product is both added to and subtracted from y_k^[0]. each ω_n^k is used in both its positive and negative forms, ω_n^k is called twiddle factors.
