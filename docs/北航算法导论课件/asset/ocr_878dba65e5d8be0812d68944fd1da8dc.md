# 16.3.3  Correctness of Huffman’s algorithm

+   - Problem of determining an optimal prefix code exhibits the **greedy-choice** and **optimal-substructure** properties.

+   - **Lemma 16.2 (greedy-choice property)**
+   
+     Let $C$ be an alphabet, each character $c \in C$ has frequency $f[c]$.
+   
+     $x$ and $y \in C$, and having the lowest frequencies. Then there exists an optimal prefix code for $C$ in which the **codewords** for $x$ and $y$ have the same length and differ only in the last bit.
+   
+     *Proof idea:* take the tree $T$ representing an arbitrary optimal prefix code, and modify it to make a tree representing another optimal prefix code such that $x$ and $y$ appear as sibling leaves (姊妹叶) of maximum depth in the new tree.
