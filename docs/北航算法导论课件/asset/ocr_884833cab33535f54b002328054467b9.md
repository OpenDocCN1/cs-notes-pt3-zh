# RSA public-key cryptosystem

+   1. Select two large prime numbers p and q, p ≠ q.
+   2. Compute n = p q.
+   3. Compute φ(n) = (p - 1)(q - 1).
+   4. Select a small odd integer e, s.t., gcd(e, φ(n))=1.
+   5. Compute d, by the equation e d ≡ 1(mod φ(n))
+   6. Publish the pair P = (e, n) as his RSA public key.
+   7. Keep secret the pair S = (d, n) as his RSA secret key.

# RSA is correct

Theorem 31.36:
S(P(M)) = S( M^e (mod n) ) = (M^e (mod n) )^d (mod n) = M^{ed} (mod n)
= M^{1+k φ(n)} (mod n) = M M^{k φ(n)} (mod n) = M (M^{(p-1)})^{k(q-1)} (mod n) ... = M (mod n)
(by Theorem31.31, Fermat’s Theorem, if p is prime, M^{(p-1)} = 1 (mod n))
