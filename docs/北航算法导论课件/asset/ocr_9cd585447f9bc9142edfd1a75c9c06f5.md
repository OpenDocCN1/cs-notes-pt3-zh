# 15.4 Longest common subsequence

**Subsequence:** given a sequence $X=\langle x_1,x_2,\ldots,x_m\rangle$, another sequence $Z=\langle z_1,z_2,\ldots,z_k\rangle$ is a *subsequence* of $X$ if there exists a strictly increasing sequence $\langle i_1,i_2,\ldots,i_k\rangle$ of indices of $X$ such that for all $j=1,2,\ldots,k$, we have $x[i_j]=z_j$.

（给定序列 $X$，如果存在 $X$ 的索引的一个严格增序列 $\langle i_1,i_2,\ldots,i_k\rangle$，使得对所有的 $j=1,2,\ldots,k$，其中 $i_j\in\{1,2,\ldots,m\}$，且都有 $x[i_j]=z_j$，则称 $Z=\langle z_1,z_2,\ldots,z_k\rangle$ 是 $X$ 的子序列。）

For example, $Z=\langle B,C,D,B\rangle$ is a subsequence of $X=\langle A,B,C,B,D,A,B\rangle$ with corresponding index sequence $\langle i_1,i_2,i_3,i_4\rangle=\langle 2,3,5,7\rangle$.
