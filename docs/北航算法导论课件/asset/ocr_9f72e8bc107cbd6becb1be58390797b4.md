# 16.3.3 Correctness of Huffman’s algorithm

+   Lemma 16.3 (optimal-substructure property)

**Proof** : For each $c \in C - \{x, y\}$, we have $d_T(c) = d_{T'}(c)$, then $f[c]d_T(c) = f[c]d_{T'}(c)$. Since $d_T(x)=d_T(y)=d_{T'}(z)+1$, we have $f[x]d_T(x)+f[y]d_T(y)=(f[x]+f[y])(d_{T'}(z)+1)=f[z]d_{T'}(z)+(f[x]+f[y])$, from which we conclude that $B(T) = B(T') + f[x] + f[y]$. ($B(T)=f[x]d_T(x)+f[y]d_T(y)+f[c]d_T(c)$, $B(T')=f[z]d_{T'}(z)+f[c]d_{T'}(c)$)
