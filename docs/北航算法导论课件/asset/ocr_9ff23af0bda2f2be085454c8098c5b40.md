# 15.3.1 Optimal substructure

+   - **Make a choice**
+   - Leave one or more subproblems to solve
+   - Given a choice that leads to an optimal solution, determine which subproblems arise and how to **characterize** the resulting space of subproblems. （给定一个能产生最优解的选择，问：怎样的子问题出现？如何对子问题的解空间进行特 征化？）
+   - Show that the solutions to the subproblems used within the optimal solution must themselves be optimal. **Cut-and-paste**: （出现在‘原问题的最优解’中的‘子问题的解’必定是该子问题的最优解）
+     - Suppose that one of the subproblem solutions is not optimal.
+     - *Cut it out.*
+     - *Paste in an optimal solution.*
+     - Get a better solution to the original problem. Contradiction.
