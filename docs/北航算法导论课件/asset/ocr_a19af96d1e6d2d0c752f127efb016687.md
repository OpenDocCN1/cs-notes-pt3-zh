# 4.2 The iteration method

T(n) = n + 3T(⌊n / 4⌋) = n + 3(⌊n / 4⌋ + 3T(⌊n / 16⌋))
= n + 3(⌊n / 4⌋ + 3(⌊n / 16⌋ + 3T(⌊n / 64⌋)))
= n + 3⌊n / 4⌋ + 9⌊n / 16⌋ + 27T(⌊n / 64⌋),

+   How far must we iterate the recurrence?

+   The i-th term in the series is 3^i T(⌊n / 4^i⌋).

+   The iteration halts when ⌊n / 4^i⌋ = 1. By continuing the iteration until this point and using the bound ⌊n / 4^i⌋ ≤ n / 4^i, we get a decreasing geometric series:

T(n) ≤ n + 3n / 4 + 9n / 16 + 27n / 64 + ⋯ + 3^i T(n / 4^i)
≤ n ∑_{i=0}^{∞} (3 / 4)^i + Θ(n^{log_4 3}) = 4n + o(n) = O(n).
(n / 4^i = 1 ⇒ i = log_4 n ⇒ 3^i = 3^{log_4 n} = n^{log_4 3})
