# 16.1.1 Optimal substructure of activity selection

$$\text{if } f_0 \le f_1 \le f_2 \le \cdots \le f_n < f_{n+1}\ (\text{if } i \le j,\text{ then } f_i \le f_j)$$

$$\text{Then } i \ge j \Rightarrow S_{ij}=\varnothing$$

**Proof**  If there exists $a_k \in S_{ij}$, then

$$f_i \le s_k < f_k \le s_j < f_j \Rightarrow f_i < f_j.$$ 

But $i \ge j \Rightarrow f_i \ge f_j$. Contradiction.

+   - So only need to worry about $S_{ij}$ with $0 \le i < j \le n+1$.  
+     All other $S_{ij}$ are $\varnothing$.
