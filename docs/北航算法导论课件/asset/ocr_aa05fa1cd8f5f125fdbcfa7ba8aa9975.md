# 3.1.7 Comparison of functions

+   - An analogy between the asymptotic comparison of two functions and the comparison of two real numbers
+   
+     （函数渐近性比较与实数比较的类比）

f(n) = o(g(n)) ↔ f(n) < g(n) ↔ a < b,

f(n) = O(g(n)) ↔ f(n) ≤ g(n) ↔ a ≤ b,

f(n) = Θ(g(n)) ↔ f(n) = g(n) ↔ a = b,

f(n) = Ω(g(n)) ↔ f(n) ≥ g(n) ↔ a ≥ b,

f(n) = ω(g(n)) ↔ f(n) > g(n) ↔ a > b.
