```
$$m[i,j]=\begin{cases}0,&\text{if }i=j,\\\min_{i\le k<j}\{m[i,k]+m[k+1,j]+p_{i-1}p_kp_j\},&\text{if }i<j.\end{cases}$$
```

+   - **Storing choice is important.**
+   - **Matrix-chain multiplication**
+     - **Table $s[i,j]$ saves a significant amount of work.**
+     - By storing in $s[i,j]$ the index of the matrix at which we split $A_iA_{i+1}\cdots A_j$, reconstruct each choice in $O(1)$ time.
