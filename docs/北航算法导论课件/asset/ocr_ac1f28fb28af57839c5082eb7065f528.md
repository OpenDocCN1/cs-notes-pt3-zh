# Step 3: Computing the expected search cost

```
OPTIMAL-BST(p, q, n)
1 for i←1 to n+1
2   e[i, i-1]←q_{i-1}
3   w[i, i-1]←q_{i-1}
4 for l←1 to n
5   for i←1 to n-l+1      // n-l+1 times
6     j←i+l-1
7     e[i, j]←∞
8     w[i, j]←w[i, j-1]+p_j+q_j
9     for r←i to j   // j-i+1=i+l-1-i+1=l
10      t←e[i, r-1]+e[r+1, j]+w[i, j]
11      if t<e[i, j]
12        e[i, j]←t
13        root[i, j]←r
14 return e and root
```

# Running times:
Θ(n³)

Proof:
O(n³): for loops are nested three deep and each loop index takes on at most n values.

Ω(n³):
∑_{l=1}^{n} (n - l + 1) l = ∑_{l=1}^{n} (n + 1) l - ∑_{l=1}^{n} l²
= (n+1)(n+1)n / 2 - n(n+1)(2n+1) / 6
= n(n+1)(n+2) / 6 = Ω(n³)
