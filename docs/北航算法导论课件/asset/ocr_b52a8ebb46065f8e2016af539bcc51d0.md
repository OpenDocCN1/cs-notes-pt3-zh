Computing the convex hull of a set of points is an interesting problem in its own right. Moreover, algorithms for some other computational-geometry problems start by computing a convex hull. Consider, for example, the two-dimensional farthest-pair problem (Exer 33.3-3).

![](bbox=[0.26, 0.27, 0.75, 0.65])

Some algorithms that compute the convex hull of a set of n points:

+   - Graham's scan, runs in O(n lgn) time
+   - Jarvis's march, runs in O(nh) time, where h is the number of vertices of the convex hull.
+   - Additional several methods
+     - incremental method, O(n lg n)
+     - divide-and-conquer method, O(n lg n)
+     - prune-and-search method, O(n lg h)
