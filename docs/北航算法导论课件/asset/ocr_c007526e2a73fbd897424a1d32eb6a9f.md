# 15.3.1 Optimal substructure

+   Optimal substructure varies across problem domains:

+   How many choices ; How many subproblems

A_i A_{i+1} ... A_k A_{k+1} A_{k+2} ... A_j

+   Mmatrix-chain multiplication A_i A_{i+1}...A_j

+   j-i choices

We choose from among j-i candidates for the index k.

+   two optimal subproblems

For a given matrix A_k, two subproblems:
parenthesizing A_i A_{i+1}...A_k and parenthesizing A_{k+1} A_{k+2}...A_j,
How to solve both of them optimally?
