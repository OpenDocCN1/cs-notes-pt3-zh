# Stack operations

+   - **MULTIPOP(S, x)**: removes the k top objects of stack S, popping the entire stack if the stack contains fewer than k objects. (The stack has s objects.)

```
MULTIPOP(S, k)
1   while not STACK-EMPTY(S) and k > 0
2       POP(S)
3       k = k - 1
```

O(min(s, k))
