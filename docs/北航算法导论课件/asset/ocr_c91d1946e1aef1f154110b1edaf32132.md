# 2.3.1 The divide-and-conquer approach

+   - MERGE procedure as a subroutine.
+   - MERGE-SORT(A, p, r) sorts the elements in the subarray A[p .. r].
+   - If p ≥ r, the subarray has at most one element, already sorted, base case.
+   - Otherwise, the divide step computes an index q that partitions A[p .. r] into two subarrays: A[p .. q], containing ⌊n/2⌋ elements, and A[q+1 .. r], containing ⌈n/2⌉ elements.

```
MERGE-SORT(A, p, r)
1  if p < r
2    Then q ← ⌊(p+r)/2⌋
3      MERGE-SORT(A, p, q)
4      MERGE-SORT(A, q+1, r)
5      MERGE(A, p, q, r)
```
