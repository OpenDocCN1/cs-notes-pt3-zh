# Exam2  Multiplication of two integers（整数相乘）

two *n*-digit numbers X and Y, Complexity(X × Y) = ?

# Divide and Conquer algorithm

Let        X = a b ,        Y = c d
then       XY = (10^m a+b)(10^m c+d) = 10^(2m)ac + 10^m(bc+ad) + bd

```
Multiply(X; Y; n):
if n = 1
    return X×Y
else
    m = ⌈n/2⌉
    a = ⌊X/10^m⌋; b = X mod 10^m
    c = ⌊Y/10^m⌋; d = Y mod 10^m
    e = Multiply(a; c; m)
    f = Multiply(b; d; m)
    g = Multiply(b; c; m)
    h = Multiply(a; d; m)
    return 10^(2m)e + 10^m(g + h) + f
```

Complexity analysis:
T(1)=1,
T(n)=4T(⌈n/2⌉)+O(n).
Applying Master Theorem,
we have
T(n)=O(n^2).
