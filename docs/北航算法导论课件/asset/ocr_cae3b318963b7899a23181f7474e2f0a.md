# Solution

# 15.4-4　$\min(m,n)$

![](bbox=[0.076, 0.273, 0.472, 0.922])

Use $d_1$, $d_2$ and table $c[1..(j+1)]$ to save the length # of an LCS. Red line show the order of computing.

```
```text
MAXMIN-LENGTH(X, Y)
1  m ← length[X]
2  n ← length[Y]
3  if m ≥ n
4      LCS-LENGTH(X,m,Y,n)
5  else LCS-LENGTH(Y,n,X,m)
```
```

```
```text
LCS-LENGTH(X, m, Y, n)
1   for j ← 0 to n
2       c[j] ← 0
3   d₁ ← d₂ ← 0
4   for i ← 1 to m
5       for j ← 1 to n
6           if xᵢ = yⱼ
7               d₂ ← c[j-1] + 1
8           else if c[j] ≥ d₁
9               d₂ ← c[j]
10          else
11              d₂ ← d₁
12          if j ≥ 2  c[j-1] ← d₁
13          d₁ ← d₂
14  c[n] ← d₁
15  return c
```
