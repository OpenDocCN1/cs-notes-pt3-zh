$$m[i,j]=\begin{cases}0,&\text{if }i=j,\\\min_{i\le k<j}\{m[i,k]+m[k+1,j]+p_{i-1}p_kp_j\},&\text{if }i<j.\end{cases}$$

```
```text
MATRIX-CHAIN-ORDER(p)
1  n ← length[p] − 1
2  for i ← 1 to n
3      m[i, i] ← 0
4  for l ← 2 to n                 // l is the chain length.
5      for i ← 1 to n − l + 1
6          j ← i + l − 1
7          m[i, j] ← ∞
8          for k ← i to j − 1
9              q ← m[i, k] + m[k + 1, j] + pᵢ₋₁pₖpⱼ
10             if q < m[i, j]
11                 m[i, j] ← q
12                 s[i, j] ← k
13     return m and s
```
