# Exam3 Multiplication of two matrices (矩阵相乘)

two n×n matrices A and B, Complexity(C=A×B) = ?

+   - Divide and conquer (Strassen Algorithm)

An n×n matrix can be divided into four n/2×n/2 matrices,

A = [[A₁₁ A₁₂],[A₂₁ A₂₂]] , B = [[B₁₁ B₁₂],[B₂₁ B₂₂]] , C = [[C₁₁ C₁₂],[C₂₁ C₂₂]]

Define  P₁ = (A₁₁+A₂₂)(B₁₁+B₂₂)
P₂ = (A₁₁+A₂₂)B₁₁
P₃ = A₁₁(B₁₁−B₂₂)
P₄ = A₂₂(−B₁₁+B₂₂)
P₅ = (A₁₁+A₁₂)B₂₂
P₆ = (−A₁₁+A₂₁)(B₁₁+B₁₂)
P₇ = (A₁₂−A₂₂)(B₂₁+B₂₂)
Then  C₁₁=P₁+P₄−P₅+P₇,  C₁₂=P₃+P₅
C₂₁=P₂+P₄,          C₂₂=P₁+P₃−P₂+P₆

Complexity analysis:
Totally, 7 multiplications, and 18 additions.
T(1)=1,
T(n)=7T(⌈n/2⌉)+cn².
Applying Master Theorem,
T(n)=O(n^{log₂7})=O(n^{2.81})
