# 3.1.1 Θ-notation: asymptotically tight bound

Θ(g(n)) = {f(n): there exist positive constants c₁, c₂, and n₀ such that 0 ≤ c₁g(n) ≤ f(n) ≤ c₂g(n) for all n ≥ n₀}.

+   - How verify that $6n^3 \neq \Theta(n^2)$ ?

Suppose for the purpose of contradiction that $c_2$ and $n_0$ exist such that $6n^3 \le c_2 n^2$ for all $n \ge n_0$. But then $n \le c_2 / 6$, which cannot possibly hold for arbitrarily large $n$, since $c_2$ is constant.
