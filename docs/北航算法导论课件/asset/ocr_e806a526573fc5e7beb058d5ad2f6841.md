# 15.3.1 Optimal substructure : Subtleties

The big difference between shortest path and longest path

![](bbox=[0.79, 0.18, 0.92, 0.42])

+   Subproblems of longest simple paths: q ↝ r and r ↝ t.

+   Longest simple path q ↝ r uses s and t. [ q → s → t → r ]

+   Cannot use s and t to solve longest simple path r ↝ t , since if we do, the path isn’t simple.

+   But we have to use t to find longest simple path r ↝ t !

+   Using resources (vertices) to solve one subproblem renders them unavailable to solve the other subproblem.

（在一个子问题求解中使用一些资源导致这些资源在求解其他子问题时不可用，如最长简单子路径问题中的顶点）
