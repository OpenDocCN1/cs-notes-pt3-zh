# 30.3.1 An iterative FFT implementation

+   - iterative FFT algorithm

```
ITERATIVE-FFT (a)
1 BIT-REVERSE-COPY (a, A)          // Θ(n lg n)
2 n ← length[a] // n is a power of 2.
3 for s ← 1 to lg n               // lg n
4     m ← 2^s
5     ω_m ← e^(2πi / m)
6     for k ← 0 to n-1 by m       // n/m = n/2^s
7         ω ← 1
8         for j ← 0 to m/2 -1     // m/2 = 2^s/2 = 2^(s-1)
9             t ← ω A[k+j+m/2]
10            u ← A[k+j]
11            A[k+j] ← u + t
12            A[k+j+m/2] ← u - t
13            ω ← ω · ω_m
```

L(n) = Σ_{s=1}^{lg n} (n / 2^s) 2^{s-1}
     = Σ_{s=1}^{lg n} n / 2
     = Θ(n lg n)
