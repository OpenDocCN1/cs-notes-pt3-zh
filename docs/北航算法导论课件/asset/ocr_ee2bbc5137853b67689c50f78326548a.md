# Exam4 Finding Minimum and Maximum（MaxMin）

# Divide and conquer

# Example

+   - Find the min and max of {3,5,6,2,4,9,3,1}.
+     - A = {3,5,6,2} and B = {4,9,3,1}.
+     - min(A) = 2, min(B) = 1.
+     - max(A) = 6, max(B) = 9.
+     - min{min(A),min(B)} = 1.
+     - max{max(A), max(B)} = 9.

+   - 选苹果；挑运动员；……
