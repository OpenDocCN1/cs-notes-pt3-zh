# 30.2.1 Complex roots of unity

# Lemma 30.6 (Summation lemma, 求和引理)

For any integer $n\ge1$ and nonnegative integer $k$ not divisible by $n$, $(k \ne m\cdot n)$, we have

$$\sum_{j=0}^{n-1} (\omega_n^k)^j = 0.$$

# Proof

$$\sum_{j=0}^{n-1} (\omega_n^k)^j = \frac{(\omega_n^k)^n - 1}{\omega_n^k - 1} = \frac{(\omega_n^n)^k - 1}{\omega_n^k - 1} = \frac{(1)^k - 1}{\omega_n^k - 1} = 0,\ k \ne mn.$$

（证明思想：利用实数的等幂级数求和性质）
