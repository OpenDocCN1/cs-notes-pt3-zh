## 11 String Matching

- **String-matching problem**
    - Text
    - Pattern
- **A finite automaton $M$ is a 5-tuple $M = (Q, q_0, A, \Sigma, \delta)$**
    - $\Phi$: *final-state function*. $\Phi(\varepsilon) = q_0$, $\Phi(wa) = \delta(\Phi(w), a)$.
    - Suffix function $\sigma(x) = \max \{k : P_k \sqsupset x\}$.
- *string-matching automaton*
    - $Q = \{0, 1, \dots, m\}$; $q_0 = 0$; $A = \{m\}$;
    - $\delta(q, a) = \sigma(P_q a)$.
