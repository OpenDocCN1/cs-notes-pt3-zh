## 2 Growth of Functions

- **Asymptotic efficiency**
  - Θ-notation: asymptotically tight bound
  - O-notation: asymptotic upper bound
  - Ω-notation: asymptotic lower bound
  - o-notation: upper bound but not asymptotically tight
  - ω-notation: lower bound but not asymptotically tight
- **Comparison of functions**
  - Polynomials
  - Exponentials
  - Logarithms
  - Factorials

## 3 Recurrences

- Algorithm contains a recursive call to itself
- Four methods for solving recurrences
  - Substitution method: guess, mathematical induction
  - Iteration method: summation
  - Recursion-tree method
  - Master method: $T(n) = aT(n/b)+f(n)$

## 6 Dynamic Programming

- **Four steps, two elements**
  1. **Characterize** the structure of an optimal solution.
     - Optimal substructure
  2. **Recursively** define the value of an optimal solution.
  3. Compute the value of an optimal solution in a **bottom-up fashion**.
     - Overlapping subproblems
  4. Construct an optimal solution from computed information.
