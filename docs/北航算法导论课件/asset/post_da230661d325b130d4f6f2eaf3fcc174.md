
## 15.3.1 Optimal substructure : Subtleties

- **Shortest path has optimal substructure.**
  - Suppose *p* is shortest path *u* ↝ *v*.
  - Let *w* be any vertex on *p*.
  - Let *p₁* be the portion of *p*, *u* ↝ *w*.
  - **Then *p₁* is a shortest path *u* ↝ *w*.**

**Proof.** Suppose there exists a shorter path *p′₁*, *u* ↝ *w*. cut out *p₁*, replace it with *p′₁*, get path *u* ↝ *w* ↝ *v* with fewer edges than *p*.

- **Same argument applies to *p₂*.**

Therefore, we can find shortest path *u* ↝ *v* by considering all intermediate vertices *w*, then finding shortest paths *u* ↝ *w* and *w* ↝ *v*.

- **Does longest simple path have optimal substructure?**
  - It seems like it should.
  - It does *not*.

![](img/09c68ab421cfce4995ddad1430ef2637_375_0.png)

![](img/09c68ab421cfce4995ddad1430ef2637_375_1.png)

- Suppose $p$ is longest simple path $u \leadsto v$.
- $p_1$ mustn’t be a longest simple path $u \leadsto w$?
- $p_2$ mustn’t be a longest simple path $w \leadsto v$?
- No!

- Consider q → r → t = longest path q ⇝ t. Are its subpaths longest paths? No!
  - Subpath q ⇝ r is q → r.
  - Longest simple path q ⇝ r is q → s → t → r.
  - Subpath r ⇝ t is r → t.
  - Longest simple path r ⇝ t is r → q → s → t.
- Not only isn’t there optimal substructure, but we can’t even assemble a legal solution from solutions to subproblems.
  (没有最优子结构；且从子问题的解中不能构造出原问题的正确解)
- Combine longest simple subpaths to q → s → t → r → q → s → t
- Not simple!

![](img/09c68ab421cfce4995ddad1430ef2637_376_0.png)

- What’s the big difference between shortest path and longest simple path?
- （最短路径和最长简单路径的最大不同是什么？）

- Shortest path has independent subproblems.

- Independent: solution to one subproblem does not affect solution to another subproblem of the same problem.
  （独立性：相同问题中，一个子问题的解不影响另一个子问题的解）

- Longest simple path: subproblems are not independent.

![](img/09c68ab421cfce4995ddad1430ef2637_377_0.png)

The big difference between shortest path and longest path

![](img/09c68ab421cfce4995ddad1430ef2637_378_0.png)

- Subproblems of longest simple paths: q ↝ r and r ↝ t.

- Longest simple path q ↝ r uses s and t. [ q → s → t → r ]

- Cannot use s and t to solve longest simple path r ↝ t , since if we do, the path isn’t simple.

- But we have to use t to find longest simple path r ↝ t !

- Using resources (vertices) to solve one subproblem renders them unavailable to solve the other subproblem.

（在一个子问题求解中使用一些资源导致这些资源在求解其他子问题时不可用，如最长简单子路径问题中的顶点）

- **The big difference between shortest path and longest path**
  - For shortest paths, the subproblems do not share resources.
  - If we look at a shortest path $u \xrightarrow{p_1} w \xrightarrow{p_2} v$, $e$ edges, no vertex other than $w$ can appear in $p_1$ and $p_2$. Otherwise, we have a cycle, get rid of the cycle. This path from $u$ to $v$ has at most $e-2$ edges, contradiction.

（考察从 $u$ 到 $v$ 的最短路径 $p$，设其长度为 $e$，顶点 $w$ 将 $p$ 分为 $p_1$ 和 $p_2$，则除 $w$ 以外，路径 $p_1$ 和 $p_2$ 中不会再有相同的顶点出现，否则，路径 $p$ 中有周期子路径，从 $p$ 中去掉该周期子路径，得 $u$ 到 $v$ 的路径最多有 $e-2$ 条边，矛盾）
