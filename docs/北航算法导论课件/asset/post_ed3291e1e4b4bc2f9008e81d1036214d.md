### Lemma 16.2

Let $c \in C$ have frequency $f[c]$. Let $x, y \in C$ be the characters having the lowest frequencies. Then there exists an optimal prefix code for $C$ in which the codewords for $x$ and $y$ have the same length and differ only in the last bit.

$$
B(T) = \sum_{c \in C} f(c) d_T(c) \quad (16.5)
$$

**Proof.** Let $a$ and $b$ be sibling leaves of maximum depth in an optimal tree $T$. Assume that $f[a] \le f[b]$ and $f[x] \le f[y]$. Since $f[x]$ and $f[y]$ are the two lowest leaf frequencies, and $f[a]$, $f[b]$ are two arbitrary frequencies in order, we have $f[x] \le f[a]$ and $f[y] \le f[b]$. Exchange the positions in $T$ of $a$ and $x$ to produce a tree $T'$, and then exchange the positions in $T'$ of $b$ and $y$ to produce a tree $T''$. By (16.5), we have

$$
\begin{aligned}
B(T) - B(T') &= \sum_{c \in C} f(c) d_T(c) - \sum_{c \in C} f(c) d_{T'}(c) \\
&= f[x] d_T(x) + f[a] d_T(a) - f[x] d_{T'}(x) - f[a] d_{T'}(a) \\
&= f[x] d_T(x) + f[a] d_T(a) - f[x] d_T(a) - f[a] d_T(x) \\
&= (f[x] - f[a]) d_T(x) + (f[a] - f[x]) d_T(a) \\
&= (f[a] - f[x]) (d_T(a) - d_T(x)) \ge 0.
\end{aligned}
$$

Similarly, $B(T') - B(T'') \ge 0$; therefore, $B(T'') \le B(T)$. Since $T$ is optimal, $B(T) \le B(T'')$. Then $B(T'') = B(T)$. Thus, $T''$ is an optimal tree.

### Lemma 16.3 (optimal-substructure property)

Let alphabet $C$ be such that each character $c \in C$ has frequency $f[c]$. Let $x$ and $y \in C$ be the characters having the lowest frequencies. Set $C' = (C - \{x, y\}) \cup \{z\}$. Define $f$ for $C'$ as for $C$, except that $f[z] = f[x] + f[y]$. Let $T'$ be any tree representing an optimal prefix code for the alphabet $C'$. Then the tree $T$, obtained from $T'$ by replacing the leaf node for $z$ with an internal node having $x$ and $y$ as children, represents an optimal prefix code for $C$.

（给定字符集 $C$，每一个字符 $c \in C$ 的频率为 $f[c]$。$x$ 和 $y \in C$ 有最低频率。从 $C$ 中抽取字符 $x$ 和 $y$，但增加新字符 $z$ 到 $C$ 中，得到新的字符集 $C'$，即 $C' = (C - \{x, y\}) \cup \{z\}$。除 $f[z] = f[x] + f[y]$ 以外，$f$ 在 $C'$ 中的定义与在 $C$ 中相同。若 $T'$ 为 $C'$ 的最优前缀无关编码，则 $T$ 为关于 $C$ 的最优前缀无关编码，其中，$T$ 是把 $T'$ 的叶节点 $z$ 替换为以 $x$ 和 $y$ 作为叶节点的内部节点而得到的。）

![](img/09c68ab421cfce4995ddad1430ef2637_474_0.png)

$C : \{c_1, \ldots, c_m, x, y\}, \quad C' : \{c_1, \ldots, c_m, z\}, \quad T' \text{ optimal } \Rightarrow T \text{ optimal}$

**Proof.** For each $c \in C - \{x, y\}$, we have $d_T(c) = d_{T'}(c)$, and therefore $f[c]d_T(c) = f[c]d_{T'}(c)$. Since $d_T(x) = d_T(y) = d_{T'}(z) + 1$, we have

$$
f[x]d_T(x) + f[y]d_T(y) = (f[x] + f[y])(d_{T'}(z) + 1) = f[z]d_{T'}(z) + (f[x] + f[y]),
$$

from which we conclude that

$$
B(T) = B(T') + f[x] + f[y].
$$

Here

$$
B(T) = \sum_{c \in C-\{x,y\}} f[c]d_T(c) + f[x]d_T(x) + f[y]d_T(y), \qquad
B(T') = \sum_{c \in C-\{x,y\}} f[c]d_{T'}(c) + f[z]d_{T'}(z).
$$

$C : \{c_1, \ldots, c_m, x, y\}, \quad C' : \{c_1, \ldots, c_m, z\}, \quad T' \text{ optimal } \Rightarrow T \text{ optimal}$

![](img/09c68ab421cfce4995ddad1430ef2637_476_0.png)

Here, $B(T) = B(T') + f[x] + f[y]$.

Suppose that $T$ is not optimal, and let $T''$ be an optimal tree. Then $B(T'') < B(T)$. Without loss of generality (by Lemma 16.2), $T''$ has $x$ and $y$ as siblings. Let $T'''$ be the tree $T''$ with the common parent of $x$ and $y$ replaced by a leaf $z$ with frequency $f[z] = f[x] + f[y]$. Then

$$
B(T''') = B(T'') - f[x] - f[y] < B(T) - f[x] - f[y] = B(T'),
$$

yielding a contradiction to the assumption that $T'$ represents an optimal prefix code for $C'$. Thus, $T$ must represent an optimal prefix code for the alphabet $C$.

### Theorem 16.4

Procedure HUFFMAN produces an optimal prefix code.

**Proof.** Immediate from Lemma 16.2（每一次选择是贪婪的、是正确的）and Lemma 16.3（确保由子问题的最优解能导出原问题的最优解）。
