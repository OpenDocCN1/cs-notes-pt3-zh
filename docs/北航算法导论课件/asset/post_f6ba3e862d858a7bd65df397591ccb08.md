
## Step 2: A recursive solution

- Compute easily $f_1[1]$ and $f_2[1]$. Directly to station 1 on either line.
- 
- $f_1[1] = e_1 + a_{1,1}$,  (15.2)
- $f_2[1] = e_2 + a_{2,1}$.  (15.3)

![](img/09c68ab421cfce4995ddad1430ef2637_243_0.png)

- For $j = 2, 3, ..., n$ ($i = 1, 2$)

- First, for $f_1[j]$, the fastest way through $S_{1,j}$ is, either the fastest way through $S_{1,j-1}$, directly through $S_{1,j}$, then $f_1[j] = f_1[j-1] + a_{1,j}$; or the fastest way through $S_{2,j-1}$, transfer from line 2 to line 1, and through $S_{1,j}$, then $f_1[j] = f_2[j-1] + t_{2,j-1} + a_{1,j}$. Thus
- 
- $f_1[j] = \min(f_1[j-1] + a_{1,j}, f_2[j-1] + t_{2,j-1} + a_{1,j})$  (15.4)

- Symmetrically,
- 
- $f_2[j] = \min(f_2[j-1] + a_{2,j}, f_1[j-1] + t_{1,j-1} + a_{2,j})$  (15.5)

![](img/09c68ab421cfce4995ddad1430ef2637_244_0.png)

$f_1[1] = e_1 + a_{1,1}, \quad (15.2)$

$f_2[1] = e_2 + a_{2,1}. \quad (15.3)$

$f_1[j] = \min(f_1[j-1] + a_{1,j},\ f_2[j-1] + t_{2,j-1} + a_{1,j}) \quad (15.4)$

$f_2[j] = \min(f_2[j-1] + a_{2,j},\ f_1[j-1] + t_{1,j-1} + a_{2,j}) \quad (15.5)$

- • **By equations (15.2)–(15.5), obtain the recursive equations**

$f_1[j] = \begin{cases}
e_1 + a_{1,1}, & \text{if } j=1,\\
\min(f_1[j-1] + a_{1,j},\ f_2[j-1] + t_{2,j-1} + a_{1,j}), & \text{if } j\ge 2
\end{cases} \quad (15.6)$

$f_2[j] = \begin{cases}
e_2 + a_{2,1}, & \text{if } j=1,\\
\min(f_2[j-1] + a_{2,j},\ f_1[j-1] + t_{1,j-1} + a_{2,j}), & \text{if } j\ge 2
\end{cases} \quad (15.7)$

## Step 3: Computing the fastest times

f* = min(f₁[n] + x₁, f₂[n] + x₂)      (15.1)

f₁[j] = { e₁ + a₁,₁ , if j = 1,
          min(f₁[j-1] + a₁,j , f₂[j-1] + t₂,j-1 + a₁,j), if j ≥ 2 }      (15.6)

f₂[j] = { e₂ + a₂,₁ , if j = 1,
          min(f₂[j-1] + a₂,j , f₁[j-1] + t₁,j-1 + a₂,j), if j ≥ 2 }      (15.7)

- It is simple to write a recursive algorithm based on equation (15.1), (15.6) and (15.7), to compute the fastest way through the factory.
- （基于如上递归方程容易编写递归算法）

- But the algorithm’s running time is exponential in n.
- （但递归算法的时间复杂度为 n 的指数次方？……）

- Compute the $f_i[j]$ values in a different order from the recursion.
  （采用与递归不一样的顺序来计算$f_i[j]$）
  $f_i[j] = \begin{cases} e_i + a_{1,1} & ,\text{if } j=1, \\ \min(f_1[j-1]+a_{1,j},\ f_2[j-1]+t_{2,j-1}+a_{1,j}),\text{if } j\ge 2 \end{cases}$ (15.6)

- Observation: $f_i[j]$ depends only on $f_1[j-1]$ and $f_2[j-1]$ (for $j\ge2$).

- By computing the $f_i[j]$ values in order of increasing station numbers $j$ — from left to right.
  （以station数 $j$ 增加的方式来计算$f_i[j]$）

![](img/09c68ab421cfce4995ddad1430ef2637_250_0.png)

we can compute the fastest way through the factory, and the time it takes, in $\Theta(n)$ time.
（仅需要$\Theta(n)$时间就可以计算出通过完整工序的最快方法）

- The FASTEST-WAY procedure takes as input the values $a_{i,j}$, $t_{i,j}$, $e_i$, and $x_i$, as well as $n$, the number of stations in each assembly line.
  
  (以 $a_{i,j}$, $t_{i,j}$, $e_i$, $x_i$, $n$ 作为输入，可设计程序 FASTEST-WAY)

![](img/09c68ab421cfce4995ddad1430ef2637_251_0.png)

```
FASTEST-WAY(a, t, e, x, n)
1  f₁[1] ← e₁ + a₁,₁
2  f₂[1] ← e₂ + a₂,₁
3  for j ← 2 to n
4    do if f₁[j-1] + a₁,j ≤ f₂[j-1] + t₂,j-1 + a₁,j
5       then f₁[j] ← f₁[j-1] + a₁,j
6            l₁[j] ← 1
7       else f₁[j] ← f₂[j-1] + t₂,j-1 + a₁,j
8            l₁[j] ← 2
9       if f₂[j-1] + a₂,j ≤ f₁[j-1] + t₁,j-1 + a₂,j
10      then f₂[j] ← f₂[j-1] + a₂,j
11           l₂[j] ← 2
12      else f₂[j] ← f₁[j-1] + t₁,j-1 + a₂,j
13           l₂[j] ← 1
14  if f₁[n] + x₁ ≤ f₂[n] + x₂
15     then f* = f₁[n] + x₁
16          l* = 1
17     else f* = f₂[n] + x₂
18          l* = 2
```
