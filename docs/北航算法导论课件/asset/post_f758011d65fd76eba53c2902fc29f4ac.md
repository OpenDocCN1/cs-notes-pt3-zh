## 30.3.1 An iterative FFT implementation

- lines 10-13, RECURSIVE-FFT involves computing the value $\omega_n^k y_k^{[1]}$ **twice**, change the loop to compute it **only once**.

```
RECURSIVE-FFT(a)
1  n = a.length
2  if n = 1
3      return a
4  ωₙ = e^{2πi/n}
5  ω = 1
6  a^[0] = (a₀, a₂, …, aₙ₋₂)
7  a^[1] = (a₁, a₃, …, aₙ₋₁)
8  y^[0] = RECURSIVE-FFT(a^[0])
9  y^[1] = RECURSIVE-FFT(a^[1])
10 for k = 0 to n/2 − 1
11     yₖ = yₖ^[0] + ω yₖ^[1]
12     yₖ₊₍ₙ⁄₂₎ = yₖ^[0] − ω yₖ^[1]
13     ω = ω ωₙ
14 return y
```
