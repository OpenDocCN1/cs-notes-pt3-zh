
## 3.1.1 Θ-notation: asymptotically tight bound (渐近紧界)

- What this notation T(n)=Θ(n²) means

For a given function g(n), we denote by Θ(g(n)) the set of functions Θ(g(n)) = {f(n): there exist positive constants c₁, c₂, and n₀ such that 0 ≤ c₁g(n) ≤ f(n) ≤ c₂g(n) for all n ≥ n₀}.

We could write “f(n) ∈ Θ(g(n))” to indicate that f(n) is a member of Θ(g(n)).

Instead, we will usually write “f(n)=Θ(g(n))” to express the same notion. The abuse may at first appear confusing, but it has advantages.

- Example: How to show that n²/2-3n = Θ(n²)?
- We must determine positive constants c₁, c₂, and n₀ such that
- c₁n² ≤ n²/2 - 3n ≤ c₂n²
- ⇒ c₁ ≤ 1/2 - 3/n ≤ c₂
- by choosing c₁ = 1/14, c₂ = 1/2, and n₀ = 7, we can verify that n²/2 - 3n = Θ(n²)

- Other choices for the constants may exist. The key is some choice exists.

## 3.1.1 Θ-notation: asymptotically tight bound

Θ(g(n)) = {f(n): there exist positive constants c₁, c₂, and n₀ such that 0 ≤ c₁g(n) ≤ f(n) ≤ c₂g(n) for all n ≥ n₀}.

- The lower-order terms, the coefficient of the highest-order term can be ignored.

- Example: f(n) = a n² + b n + c , where a > 0, b, c are constants.
- Throwing away the lower-order terms and ignoring the constant yields f(n) = Θ(n²)

- In general, for any polynomial p(n) = Σᵢ₌₀ᵈ aᵢ nⁱ , where the aᵢ are constants and a_d > 0, we have p(n) = Θ(nᵈ).

- We can express any constant function as Θ(n⁰) or Θ(1).
- Θ(1) often mean either a constant or a constant function.

## 3.1.3 Ω-notation: asymptotic lower bound (渐近下界)

- Ω – notation: For a given function g(n), we denote by Ω(g(n)) the set of functions Ω(g(n)) = {f(n): there exist positive constants c and n₀ such that 0 ≤ c g(n) ≤ f(n) for all n ≥ n₀}.
