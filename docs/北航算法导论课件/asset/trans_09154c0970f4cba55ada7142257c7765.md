## Exam2 Multiplication of two integers（整数相乘）

两个 *n* 位数 X 和 Y，Complexity(X × Y) = ?

### 分治算法

设 X = a b , Y = c d
则 XY = (10^m a+b)(10^m c+d) = 10^(2m)ac + 10^m(bc+ad) + bd

```
Multiply(X; Y; n):
if n = 1
    return X×Y
else
    m = ⌈n/2⌉
    a = ⌊X/10^m⌋; b = X mod 10^m
    c = ⌊Y/10^m⌋; d = Y mod 10^m
    e = Multiply(a; c; m)
    f = Multiply(b; d; m)
    g = Multiply(b; c; m)
    h = Multiply(a; d; m)
    return 10^(2m)e + 10^m(g + h) + f
```

复杂度分析：
T(1)=1,
T(n)=4T(⌈n/2⌉)+O(n).
应用主定理，
我们有
T(n)=O(n^2).

## Exam2 Multiplication of two integers (整数相乘)

两个 n 位数 X 和 Y，Complexity(X × Y) = ?

- 分治法（Karatsuba 算法）

设 X = a b, Y = c d
则 XY = (10^m a + b)(10^m c + d) = 10^{2m} ac + 10^m (bc + ad) + bd

注意 bc + ad = ac + bd − (a − b)(c − d)。所以，我们有

```
FastMultiply(X; Y; n):
if n = 1
    return X×Y
else
    m = ⌈n/2⌉
    a = ⌊X/10^m⌋; b = X mod 10^m
    c = ⌊Y/10^m⌋; d = Y mod 10^m
    e = FastMultiply(a; c; m)
    f = FastMultiply(b; d; m)
    g = FastMultiply(a−b; c−d; m)
    return 10^{2m} e + 10^m (e + f − g) + f
```

复杂度分析：
T(1)=1,
T(n)=3T(⌈n/2⌉)+O(n).
应用主定理，我们有
T(n) = O(n^{log₂3}) = O(n^{1.59})

### Multiplication of two matrices（矩阵相乘问题）

      ⎜ …… ⎟      ⎜ …… ⎟
      ⎝ aₙ₁…aₙₙ ⎠      ⎝ bₙ₁…bₙₙ ⎠

设计一个算法求A×B，并分析计算复杂度。

说明：算法中“基本操作”约定为两个实数相乘，或两个实数相加。

## Exam3 Multiplication of two matrices（矩阵相乘）

两个 n × n 矩阵 A 和 B，Complexity(C=A × B) = ?

- **标准方法**

\(c_{ij}=\sum_{k=1}^{n}a_{ik}b_{kj}\)

```
MATRIX-MULTIPLY(A, B)
for i ← 1 to n
    for j ← 1 to n
        C[i, j] ← 0
        for k ← 1 to n
            C[i, j] ← C[i, j] + A[i, k] · B[k, j]
return C
```

**复杂度：**
\(O(n^3)\) 乘法和加法。
\(T(n)=O(n^3)\).

## Exam3 Multiplication of two matrices（矩阵相乘）

两个 *n* × *n* 矩阵 A 和 B，Complexity(C=A×B) = ?

- **分治法**

一个 *n* × *n* 矩阵可以划分为四个 *n*/2 × *n*/2 矩阵，

A = [[A₁₁, A₁₂], [A₂₁, A₂₂]],  B = [[B₁₁, B₁₂], [B₂₁, B₂₂]],  C = [[C₁₁, C₁₂], [C₂₁, C₂₂]]

C₁₁=A₁₁B₁₁+A₁₂B₂₁, C₁₂=A₁₁B₁₂+A₁₂B₂₂
C₂₁=A₂₁B₁₁+A₂₂B₂₁, C₂₂=A₂₁B₁₂+A₂₂B₂₂

**复杂度分析：**
总共，8 次乘法（子问题），和 4 次加法（*n*/2 × *n*/2 × 4）。
T(1)=1, T(*n*) = 8T(⌈*n*/2⌉)+*n*².
应用主定理，我们有
*T(n) = O(n³).*

## Exam3 Multiplication of two matrices (矩阵相乘)

两个 n×n 矩阵 A 和 B，Complexity(C=A×B) = ?

- 分治法（Strassen 算法）

一个 n×n 矩阵可以划分为四个 n/2×n/2 矩阵，

A = [[A₁₁ A₁₂],[A₂₁ A₂₂]] , B = [[B₁₁ B₁₂],[B₂₁ B₂₂]] , C = [[C₁₁ C₁₂],[C₂₁ C₂₂]]

定义  P₁ = (A₁₁+A₂₂)(B₁₁+B₂₂)
P₂ = (A₁₁+A₂₂)B₁₁
P₃ = A₁₁(B₁₁−B₂₂)
P₄ = A₂₂(−B₁₁+B₂₂)
P₅ = (A₁₁+A₁₂)B₂₂
P₆ = (−A₁₁+A₂₁)(B₁₁+B₁₂)
P₇ = (A₁₂−A₂₂)(B₂₁+B₂₂)
则  C₁₁=P₁+P₄−P₅+P₇,  C₁₂=P₃+P₅
C₂₁=P₂+P₄,          C₂₂=P₁+P₃−P₂+P₆

复杂度分析：
总共，7 次乘法，和 18 次加法。
T(1)=1,
T(n)=7T(⌈n/2⌉)+cn².
应用主定理，
T(n)=O(n^{log₂7})=O(n^{2.81})
