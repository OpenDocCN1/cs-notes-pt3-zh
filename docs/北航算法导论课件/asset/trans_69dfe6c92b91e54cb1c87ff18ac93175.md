## 11 字符串匹配

- **字符串匹配问题**
    - 文本
    - 模式
- **有限自动机 $M$ 是一个五元组 $M = (Q, q_0, A, \Sigma, \delta)$**
    - $\Phi$: *终态函数*。$\Phi(\varepsilon) = q_0$，$\Phi(wa) = \delta(\Phi(w), a)$。
    - 后缀函数 $\sigma(x) = \max \{k : P_k \sqsupset x\}$。
- *字符串匹配自动机*
    - $Q = \{0, 1, \dots, m\}$; $q_0 = 0$; $A = \{m\}$;
    - $\delta(q, a) = \sigma(P_q a)$。
