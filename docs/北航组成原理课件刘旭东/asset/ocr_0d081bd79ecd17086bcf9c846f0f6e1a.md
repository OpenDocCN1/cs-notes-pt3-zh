# ADD 2000H[BX], 1000H 指令执行的微操作流程

+   - 指令长度：48位，分三次读取
+   - 读取指令周期：机器周期M1内完成（读第一个16位）
+   - 读变址值周期：机器周期M2内完成
+   - 取操作数周期：机器周期M3内完成
+   - 取立即数,完成加法：机器周期M4内完成
+   - 执行周期：机器周期M5内完成
