# 2.4 存储器芯片的扩展

# 例：4Kx4 SRAM存储芯片构成 16Kx8的存储器

+   4K×4芯片：12个地址管脚 A11～A0，4个数据管脚 D3～D0，1个片选输入管脚 CS#，1个读写控制管脚 R/W#

+   芯片地址空间：000H～FFFH

+   CPU向存储器提供：
+   - 地址总线14根：AB13～AB0
+   - 数据总线8根：DB7～DB0
+   - 读写控制信号：R/W#

+   存储器地址空间：0000H～3FFFH

+   需要芯片数：（16K×8）/（4K×4）= 8片
