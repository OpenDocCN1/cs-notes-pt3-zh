# Example

Y=ax²+bx-c 假定a,b,c,x均为已知数，且存放在内存中，求y。

| 指令 | 操作码 | 说明 |
| --- | --- | --- |
| ADD | 00H | AC ← (AC)+Mem(Add) |
| LD | 01H | AC ← Mem(Add) |
| SUB | 02H | AC ← (AC) — Mem(Add) |
| MUL | 03H | AC ← (AC)×Mem(Add) |
| ST | 04H | Mem(Add) ← (AC) |
