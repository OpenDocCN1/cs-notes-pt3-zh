# 4.1 微程序原理

# 基本思路

+   指令的执行：按顺序执行一系列的微操作，每一个时钟周期（节拍）完成一个或多个微操作。

+   微操作：实际上是控制器送出的控制线，具有1和0两种状态。

+   将指令执行微操作序列中一个节拍内同时完成的微操作用一个二进制代码串来表示，这就是微指令。

+   微指令的执行：通过某种逻辑产生该微指令所表示的微操作控制信号，送控制总线，并维持一个时钟周期。

+   指令的执行 = 微指令的序列

+   微指令序列 = 微程序

+   一条机器指令对应一段微程序

+   将所有指令对应的微程序保存在存储器中（控制存储器）

+   基于这种思想构造的控制器：微程序控制器
