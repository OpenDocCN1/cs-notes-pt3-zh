# 3.3 微操作信号的综合

# 例1： IB ← MDR微操作控制信号的综合

+   Sₓ 表示源操作数是变址寻址, S_R 表示寄存器直接寻址（可以理解为译码器的输出端）

+   Dₓ 表示目的操作数是变址寻址

+   S_imm 表示源操作数是立即数寻址

+   OP_Mov, OP_Add 和 OP_Jne 表示操作码译码输出

| 指令 | IB←MDR有效的时间与条件 |  |  |  |  |
| --- | 时间节拍 | 操作码译码 | 源寻址译码 | 目寻址译码 | FR |
| 示例中的所有指令 | M1.T4 |  |  |  |  |
| MOV AX,1000H[BX] | M2.T4 | MOV | Sₓ | D_R |  |
| MOV 1000H[BX],AX | M2.T4 | MOV | S_R | Dₓ |  |
| ADD 2000H[BX], 1000H | M2.T4 | ADD | S_imm | Dₓ |  |
|  | M3.T4 | ADD | S_imm | Dₓ |  |
|  | M4.T4 | ADD | S_imm | Dₓ |  |
| JNE 1200 | M2.T4 | JNE |  |  |  |
