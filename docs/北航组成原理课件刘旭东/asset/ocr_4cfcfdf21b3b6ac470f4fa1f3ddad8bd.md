# 简单回顾—2的补码表示法

+   假设A由 a_{n-1} a_{n-2}...a_{1} a_{0} 表示

+   最高位 a_{n-1} 为符号位

+   a_{n-1}=0 表示A为正数

+   a_{n-1}=1 表示A为负数

+   A取值范围：[-2^{n-1}, 2^{n-1}-1]

A = -2^{n-1} a_{n-1} + \sum_{i=0}^{n-2} 2^{i} a_{i}

+   1) A ≥ 0 (即 a_{n-1}=0) A = \sum_{i=0}^{n-2} 2^{i} a_{i}

+   2) A < 0 (即 a_{n-1}=1) A = -2^{n-1} + \sum_{i=0}^{n-2} 2^{i} a_{i}
