# 3.1 原码除法（以定点整数正数为例）——恢复余数法

上述写成分步运算：

```
$$\begin{aligned}
R_0 &= 2B-Aq_{n-1}2^n\\
R_1 &= 2R_0-Aq_{n-2}2^n\\
&\vdots\\
R_i &= 2R_{i-1}-Aq_{n-i-1}2^n\\
&\vdots\\
R_{n-1} &= 2R_{n-2}-Aq_0 2^n
\end{aligned}$$
```

+   - **问题：**如何通过算法来确定商，即 $q_{n-1},q_{n-2},\ldots,q_0$
+   - **思路：**
+     - 每一步运算后的余数 $R_i$，都是真余数；
+     - 通过分析 $R_i$ 与 $q_{n-i-1}$ 的关系来确定每一位商的 $q_{n-i-1}$ 的取值。
