# JNE 1200 指令执行的微操作流程

+   - 指令长度：假定占32位，分两次读取
+   - 不相等时转移，相对寻址，目标地址＝（PC）＋1200
+   - 读取指令周期：机器周期M1内完成（读第一个16位）
+   - 读转移地址周期：机器周期M2内完成
