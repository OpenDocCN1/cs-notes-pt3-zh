# 3.3 CACHE与主存之间的映射

# 全相联映射的地址

+   主存的地址格式： Block Number | Offset

+   Cache的Tag内容：主存中与该Cache数据块对应的数据块的块地址。

# 全相联映射举例

+   主存：16M Bytes

+   Cache：64K Bytes

+   Block：16 Bytes

# 解答

+   主存块数：16M ÷ 16 = 2²⁰ Blocks

+   主存地址：24为，其中高20位为块地址，低4位为块内地址

+   Cache块数：64K ÷ 16 = 2¹² Blocks

+   Cache的Tag应该为20位。
