# 3.2 指令流程与微操作时间表

# ◆ MOV AX，1000H[BX] 指令执行的微操作流程

+   - 指令长度：32位，分两次读取
+   - 读取指令周期：机器周期M1内完成（读第一个16位）
+   - 读变址值周期：机器周期M2内完成
+   - 取操作数周期：机器周期M3内完成
+   - 执行周期：机器周期M4内完成

| 时间节拍 | 完成功能 | 需要的微操作信号 | 需要的写入脉冲 |
|---|---|---|---|
| M1.T1 | 指令地址送MAR | IB ← PC | CPMAR |
| M1.T2 | Read Memory | RD |  |
| M1.T3 | 指令送MDR | MDR ← DB | CPMDR |
|  | 调整PC | PC+ △ | CPPC |
| M1.T4 | MDR（指令）送IR | IB ← MDR | CPIR |
