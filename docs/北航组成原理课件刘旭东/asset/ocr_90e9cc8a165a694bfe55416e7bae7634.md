# 2.2 补码乘法（一位比较法，又称一位Booth法）

例：
1011×0111
B=11,011
-B=00101
A=0,111

| | 部分积 | 乘数 |
|---|---|---|
| 部分积初值 → | 00000 | 0111 0 |
| - B | 00101 | |
| 和 | 00101 | |
| 右移一位 | 00010 | 1 011 1 |
| + 0 | 00000 | |
| 和 | 00010 | |
| 右移一位 | 00001 | 01 01 1 |
| + 0 | 00000 | |
| 和 | 00001 | |
| 右移一位 | 00000 | 101 0 1 |
| + B | 11011 | |
| 和 | 11011 | |
| 右移一位 | 11101 | 1101 |
