# 2.1 无符号数乘法

M × Q = M * (Q_{n-1} 2^{n-1} + Q_{n-2} 2^{n-2} + ⋯ + Q_0 2^0)

= 1/2 Q_{n-1} M 2^n + 1/4 Q_{n-2} M 2^n + 1/8 Q_{n-3} M 2^n + ...... + 1/2^n Q_0 M 2^n

= 1/2 { Q_{n-1} M 2^n + 1/2 [ Q_{n-2} M 2^n + 1/2 ( Q_{n-3} M 2^n + ...... + 1/2 ( Q_1 M 2^n + 1/2 Q_0 M 2^n ) ) ... ] }

变成分步算式：

+   P_0 = 0
+   P_1 = 1/2 ( P_0 + Q_0 M 2^n )
+   P_2 = 1/2 ( P_1 + Q_1 M 2^n )
+   ⋮
+   P_i = 1/2 ( P_{i-1} + Q_{i-1} M 2^n )
+   ⋮
+   P_n = 1/2 ( P_{n-1} + Q_{n-1} M 2^n )
