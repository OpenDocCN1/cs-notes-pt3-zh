# 3.3 CACHE与主存之间的映射

# 直接映射

主存的地址格式：

| 区地址 | 区内块地址 | 块内偏移 |

Cache的Tag内容：主存中与该Cache数据块对应的数据块的区地址。

# 直接联映射举例

+   - 主存：16M Bytes
+   - Cache：64K Bytes
+   - Block：16 Bytes

# 解答

+   - 主存：2^20 Blocks，分成2^8个区，每个区2^12Blocks
+   - Cache：2^12 Blocks
+   - 主存地址：24位，其中高8位区地址，中间12位为区内块地址，低4位为块内地址
+   - Cache的Tag应该为8位。
