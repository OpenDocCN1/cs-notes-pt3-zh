# 5.2 页式虚拟存储系统

# 程序空间

+   - 一个大容量的存储空间，称为虚存空间
+   - 程序中的地址：虚拟地址、逻辑地址

# 页式虚拟存储器

+   - 虚存空间和主存空间按统一大小分成若干页，虚存称为虚页，主存称为实页。
+   - 程序按页调入内存（某一虚页装入内存入某一实页）
+   - 虚存的地址格式（逻辑地址格式）：虚页号 + 页内地址
+   - 实存的地址格式（物理地址格式）：实页号 + 页内地址
+   - 页表：虚页与实页的映射，实现虚实地址的转换，页表建立在内存中，操作系统为每道程序建立一个页表。
+   - 页表基址寄存器：保存页表在内存中的起始地址。
