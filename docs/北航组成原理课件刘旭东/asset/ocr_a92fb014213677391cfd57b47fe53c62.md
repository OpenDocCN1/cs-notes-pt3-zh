# 2.2 8086/8088指令系统·寄存器

# 通用寄存器：数据寄存器(Data Register)

+   - AX、BX、CX、DX（16位）；
+   - AH、AL、BH、BL、CH、CL、DH、DL（8位）
+   - 各寄存器原则上没有固定的应用
+   - AX：累加器
+   - BX：基址寄存器
+   - CX：计数器
+   - DX：数据寄存器

| 寄存器 | 高8位 | 低8位 |
|---|---|---|
| AX | AH | AL |
| BX | BH | BL |
| CX | CH | CL |
| DX | DH | DL |

两列均为 8 bits。
