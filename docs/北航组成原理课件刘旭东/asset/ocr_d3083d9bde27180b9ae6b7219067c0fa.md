# 变址寻址

+   - 操作数在存储器中，指令地址字段给出一变址寄存器和一形式地址，变址寄存器的内容与形式地址之和是操作数的内存地址。
+   - **EA = (Rx)+A, Operand = ((Rx)+A)**
+   - 有的系统中，变址寻址完成后，变址寄存器的内容将自动进行调整。  
+     **Rx ← (Rx) + Δ（操作数Data的字节数）**
+   - 例：**MOV AX, 1000H[DI]**
