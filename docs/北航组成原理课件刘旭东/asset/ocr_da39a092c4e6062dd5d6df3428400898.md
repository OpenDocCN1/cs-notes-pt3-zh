# 3.3 补码除法（加减交替法）

# 要求

+   ➢ 参加运算的操作数是补码形式
+   ➢ 得到的商和余数直接是补码形式

# 运算规则

+   1. 若被除数 [B]补 与除数 [A]补 同号，2[B]补−[A]补→R；
+      若被除数 [B]补 与除数 [A]补 异号，2[B]补+[A]补→R；
+      以上求得的 R 如果与 [B]补 同号，则除法溢出，停止运算。否则，按第 2 步继续进行。
+   2. 若 R 与 [A]补 同号，商 1，2R−[A]补→R；
+      若 R 与 [A]补 异号，商 0，2R+[A]补→R
+   3. 重复 2 步，直至最后一位商
+   4. 最后一位商恒置 1。
