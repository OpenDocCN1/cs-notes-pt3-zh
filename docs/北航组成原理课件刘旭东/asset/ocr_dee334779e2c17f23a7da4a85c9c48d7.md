# 1.4 计算机总线结构

# ❖ 总线结构

+   - 总线：符合一定的标准的一组公共数据通道
+   - 构成：地址总线、数据总线、控制总线
+   - 单总线结构
+   - 多总线结构

+   - ISA---Industry Standard Architecture（工业标准结构）
+   - EISA----Extended ISA（扩展工业标准结构）
+   - PCI----Peripheral Connection Interface（周边元件扩充接口）
+   - SCSI----Small Computer System Interface（小型计算机系统接口）
