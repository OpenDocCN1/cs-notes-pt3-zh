# 推导方法：从一个要识别的符号开始推导，即用相应规则的右部来替代规则的左部，每次仅用一条规则去进行推导。

<句子> => <主语><谓语>

=> <代词><谓语>

=> 我<谓语>

=> 我<动词><直接宾语>

=> 我是<直接宾语>

=> 我是<名词>

=> 我是大学生

+   <句子> ::= <主语><谓语>
+   <主语> ::= <代词>|<名词>
+   <代词> ::= 你|我|他
+   <名词> ::= 王民|大学生|工人|英语
+   <谓语> ::= <动词><直接宾语>
+   <动词> ::= 是|学习
+   <直接宾语> ::= <代词>|<名词>
