Type ↑t        t中放类型值

id ↑n        n中放变量名

填表动作符号也可带有属性：

@set_table↓t₁,n₁        ↓t₁,n₁ 可从前面得到，所以称为继承属性，继承前面的值

<变量表> ↓t₂        ↓t₂        同上

# 属性翻译文法：

+   1. <说明> → Type↑t id↑n @set_table↓t₁,n₁ <变量表>↓t₂        t₂,t₁ := t;   n₁ := n;

+   2. <变量表>↓t₂ → , id↑n @set_table↓t₁,n₁ <变量表>↓t₃        t₃,t₁ := t₂;   n₁ := n;

+   3. <变量表>↓t₂ → ε
