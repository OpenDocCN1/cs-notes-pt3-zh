# b) 数组信息向量表（模板）

功能：1、用于计算下标变量地址
2、检查下标是否越界

一般形式：

大小：3n + 2

| | |
|---|---|
| U(n) | 上界 |
| L(n) | 下界 |
| P(n) | 计算地址用常量 |
| ... | |
| .... | |
| U(1) | |
| L(1) | |
| P(1) | |
| n | |
| RC | |

注：1、数组模板所需的空间大小取决于数组的维数，即3n+2
∴无论是常界或变界数组，在编译时就能确定数组模板的大小
2、常界数组，在编译时就可造信息向量表；而变界数组信息向量表要在目标程序运行时才能造。编译程序要生成相应的指令
