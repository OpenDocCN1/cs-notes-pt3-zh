# 10.6 控制语句的处理

# 10.6.1 if语句

```
JMF, labA
IF <log_expr> THEN <stat list> labA:

JMF, labA
IF <log_expr> THEN <stat list> ELSE labA: <stat list> labB:
JMP, labB
```

# 其属性翻译文法及相应的语义动作程序：

+   1. <if_stat> → <if_head> ↑y <if_tail> ↓y
+   2. <if_head> ↓y → IF <log_expr> @brf ↑y THEN <stat list>
+   3. <if_tail> ↓y → @labprod ↓y | ELSE @br ↑z @labprod ↓y <stat_list> @labprod ↓z
