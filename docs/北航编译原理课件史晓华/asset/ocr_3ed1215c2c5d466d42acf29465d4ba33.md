# Compiler

for <id> := <expr1> to <expr2> by <expr3> do <stat list>

```
LDA, (<id>)
LOD, (expr1)
@initload
STN
JMP, start
@labgen
loop: ..........
LOD, (expr2)
@loadid
LOD, (id)
LOD, (expr3)
@compare
ADD
STO, (id)
LOD,(id)
BGT, end_loop
start: <statement>
...
@retbranch
JMP, loop
@labprod
end_loop:
```

+   1. <for loop> → <for head>↑a, f, r < rest of loop>↓a, f, r
+   2. <for head>↑a, f, r → for <id>↑a := <expr> @initload↑s to @labgen↑r <expr> by @loadid↓a <expr> @compare↓a, s↑f
+   3. <rest of loop>↓a, f, r → do <stat list> end for @retbranch↓r @labprod↓f
