```
<项>::=<因子>|*<因子>
<因子>::=<变量>|'('<表达式>')'
```

```
```pascal
PROCEDURE term;                    /*项*/
BEGIN
    factor;
    WHILE sym='*' DO
        BEGIN nextsym; factor END
END;
```

```
```pascal
PROCEDURE factor;                  /*因子*/
BEGIN
    IF sym='(' THEN
        BEGIN nextsym; expr;
            IF sym≠')'
            THEN error
            ELSE nextsym
        END
    ELSE var;
END
