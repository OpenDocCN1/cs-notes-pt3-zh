# DFA M所接受的符号串：

令 α = a₁a₂⋯aₙ，α ∈ Σ*，若 δ(δ(⋯δ(s₀, a₁), a₂)⋯)，aₙ₋₁)，aₙ) = sₙ，且 sₙ ∈ Z，则可以写成 δ(s₀, α) = sₙ，我们称 α 可为 M所接受。

$$\begin{aligned}
\delta(s_0,a_1)&=s_1\\
\delta(s_1,a_2)&=s_2\\
&\cdots\\
\delta(s_{n-2},a_{n-1})&=s_{n-1}\\
\delta(s_{n-1},a_n)&=s_n
\end{aligned}$$

> 换言之：若存在一条初始状态到某一终止状态的路径，且这条路径上能有弧的标记符号连接成符号串 α，则称 α 为DFA M（接受）识别。

DFA M所接受的语言为：L(M) = { α | δ(s₀, α) = sₙ，sₙ ∈ Z}
