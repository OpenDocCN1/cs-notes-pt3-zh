# U::=x1x2...xn

例：文法G[E]
E::= E + T | T
T::= T * F | F
F::= ( E ) | i

IF xi和xi+1均为终结符 THEN 置 xi=xi+1

IF i≤n-2，且xi和xi+2都为终结符号但xi+1为非终结符号THEN 置 xi=xi+2

IF xi为终结符号,xi+1为非终结符号 THEN
FOR FIRSTVT(xi+1)中的每个b DO 置xi<b

IF xi为非终结符号,xi+1为终结符号 THEN
FOR LASTVT(xi)中的每个a DO 置a>xi+1

FIRSTVT(E): + * ( i

LASTVT(E): + * ) i

FIRSTVT(T): * ( i

LASTVT(T): * ) i

FIRSTVT(F): ( i

LASTVT(F): ) i
