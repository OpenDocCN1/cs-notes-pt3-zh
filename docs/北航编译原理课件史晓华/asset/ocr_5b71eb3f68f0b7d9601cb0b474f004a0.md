# 10.7.2 过程调用处理

与调用有关的动作如下：

+   1. 检查该过程名是否已定义（过程名和函数名不能用错）实参和形参在类型、顺序、个数上是否一致。（查符号表）
+   2. 加载实参（值或地址）
+   3. 加载返回地址
+   4. 转入过程体入口地址

例：有过程调用：
`process_symb(symb, cursor, replacestr);`

```
LOD, (addr of symb )
LOD, (addr of cursor )
LOD, (addr of replacestr)
JSR, ( addr of process_symb)
<retaddr>:....
```

传值调用

若实参并非上例中所示变量，而是表达式，则应生成相应计算实参表达式值的指令序列。

JSR指令先把返回地址压入操作数栈，然后转到被调过程入口地址。
