# 临时寄存器池的使用方法：设EAX, EDX可用

全局寄存器分配结果：

|  |  |
|---|---|---|
| a | EBX |
| b | ESI |
| c | EDI |

临时变量在运行栈上的保存地址：

|  |  |
|---|---|---|
| t3 | ESP+10H |
| t2 | ESP+0CH |
| t1 | ESP+08H |

寄存器池：

t1 := -c

|  |  |
|---|---|---|
| t1 | EAX |
|  | EDX |

```
mov EAX, EDI
neg EAX
```

t2 := t1 - b

|  |  |
|---|---|---|
| t1 | EAX |
| t2 | EDX |

```
mov EDX, EAX
sub EDX, ESI
```

t3 := t2 + t2

|  |  |
|---|---|---|
| t3 | EAX |
| t2 | EDX |

```
mov [ESP+08H], EAX
mov EAX, EDX
add EAX, EAX
```

a := t3

|  |  |
|---|---|---|
| t3 | EAX |
| t2 | EDX |

```
mov EBX, EAX
```
