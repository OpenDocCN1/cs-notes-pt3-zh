# 通过循环交换（Loop Interchange）优化提高缓存命中率

```
for (j = 0; j < 100; j = j+1)
    for (i = 0; i < 5000; i = i+1)
        x[i][j] = 2 * x[i][j];
```

**x[0][0]**, x[0][1], …, x[0][99], **x[1][0]**, x[1][1], …, x[1][99], …, **x[4999][0]**, x[4999][1], …, x[4999][99]

```
for (i = 0; i < 5000; i = i+1)
    for (j = 0; j < 100; j = j+1)
        x[i][j] = 2 * x[i][j];
```

**x[0][0]**, x[0][1], …, x[0][99], x[1][0], x[1][1], …, x[1][99], …, x[4999][0], x[4999][1], …, x[4999][99]
