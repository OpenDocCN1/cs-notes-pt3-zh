+   1. `E ↑ₓ ⟶ E ↑q + T ↑r @ADD↓y,z,p` 
+      `x, p := NEWT    y := q    z := r`
+   2. `E ↑ₓ ⟶ T ↑p` 
+      `x := p`
+   3. `T ↑ₓ ⟶ T ↑q * F ↑r @MULT↓y,z,p` 
+      `x, p := NEWT    y := q    z := r`
+   4. `T ↑ₓ ⟶ F ↑p` 
+      `x := p`
+   5. `F ↑ₓ ⟶ (E ↑p)` 
+      `x := p`
+   6. `F ↑ₓ ⟶ Id ↑p` 
+      `x := p`

说明：

Id的综合属性是数据区地址，NEWT为系统过程，返回一个用来存放中间结果的新临时变量。
