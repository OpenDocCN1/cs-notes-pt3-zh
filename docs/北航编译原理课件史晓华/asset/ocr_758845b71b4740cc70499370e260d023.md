# 词法分析程序的分析过程

# 令输入字符串为aba...

+   (1) 吃进字符ab
+   (2) 按反序检查状态子集
+   检查前一次状态是否含有原 NFA的终止状态

| 读入字符 | 进入状态 |
|---|---|
| 开始 | {0,1,3,7} |
| a | {2,4,7} |
| b | {5,8} |
| a | 无后继状态(退掉输入字符a) |

·即检查{5,8},含有终态8，因此断定所识别的单词ab是属于a*bb*中的一个。

··若在状态子集中无NFA的终态，则要从识别的单词再退掉一个字符(b)，然后再检查上一个状态子集。

···若一旦吃进的字符都退完，则识别失败，调用出错程序，一般是跳过一个字符然后重新分析。（应打印出错信息）
