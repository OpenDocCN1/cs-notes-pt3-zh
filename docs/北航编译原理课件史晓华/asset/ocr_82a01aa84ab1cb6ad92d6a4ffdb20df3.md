<A> → a<sub>↑R</sub> <B><sub>↑S</sub> <C><sub>↓I</sub>, I := f(R, S)

<A> → a<sub>↑R</sub> <B><sub>↑S</sub> @ f<sub>↓I₁, I₂</sub>↑S₁ <C><sub>↓I</sub>,

I₁ := R, I₂ := S, S₁ := f(I₁, I₂), I := S₁。

该文法是简单赋值形式的L-ATG。

注意： 无参函数过程作为常数处理，如

〈A〉→〈B〉↑ₓ〈C〉↑ᵧ  x，y := NEWT
