# 算符优先函数值的确定方法

+   1. 对每个终结符a（包括#），令f(a)=g(a)=1（或其它整数）
+   2. 如果a>b，而f(a)≤g(b)则令f(a)=g(b)+1
+   3. 如果a<b，而f(a)≥g(b)则令g(b)=f(a)+1
+   4. 如果a=b，而f(a)≠f(b)则令min{f(a),g(b)}=max{f(a),g(b)}
+   5. 重复1～4直到过程收敛。如果重复过程中有一个值大于2*终结符数量，则表明该算符优先文法不存在算符优先函数。
