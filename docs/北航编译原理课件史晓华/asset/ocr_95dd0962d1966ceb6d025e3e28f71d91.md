# 下面是识别某语言单词符号的LEX源程序：

例：LEX 源程序

```
AUXILIARY    DEFINITIONS
    letter → A|B|⋯
    digit  → 0|1|⋯
%%
RECOGNITION RULES
    1.BEGIN                {RETURN(1,−)}
    2.END                  {RETURN(2,−)}
    3.FOR                  {RETURN(3,−)}
```

> RETURN是LEX过程，该过程将单词传给语法分析程序
> RETURN（C，LEXVAL）
> 其中C为单词类别编码
> LEXVAL：
> 　标识符：TOKEN（字符数组）
> 　整数常数：DTB（数值转换函数，将TOKEN中的数字串转换二进制值）
> 　其他单词：无定义
