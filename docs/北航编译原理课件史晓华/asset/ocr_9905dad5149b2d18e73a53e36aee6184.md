# 用lex建立yacc的词法分析器

lex源程序lexical.l:

```
number        [0-9]+\.?[0-9]*\.[0-9]+
%%
[ ]           { /* 跳过空格 */ }
{number}      { sscanf(yytext, "%lf", &yyval);
                return NUMBER; }
\n|.          { return yytext[0]; }
```

Yacc源程序第3部分的例程yylex()语句应由语句 #include “lex.yy.c” 替代，并键入如下命令生成台式计算器程序 a.out:

```
lex   lexical.l

yacc  translate.y

cc    y.tab.c  -ly  -ll
```
