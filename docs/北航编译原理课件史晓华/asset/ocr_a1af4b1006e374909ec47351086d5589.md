# 正则表达式的性质：

设 e1、e2 和 e3 均是某字母表上的正则表达式，则有：

+   单位正则表达式：ε　　　εe = eε = e
+   
+   交换律：　　 e1 | e2 = e2 | e1
+   
+   结合律：　　 e1 (e2 | e3) = (e1 | e2) | e3
+   　　　　　　 e1 (e2e3) = (e1e2)e3
+   
+   分配律：　　 e1(e2 | e3) = e1e2 | e1e3
+   　　　　　　 (e1 | e2)e3 = e1e3 | e2e3
+   
+   此外：　　　 r* = (r | ε)*　　　r** = r*
+   　　　　　　 (r | s)* = (r*s*)*
