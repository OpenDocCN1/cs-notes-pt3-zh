+   • 过程调用语句的实参：

继承属性：继承属性值

综合属性：属性变量名（传地址，返回时有值）

+   • 关于属性名的约定：

1）产生式左部的同名非终结符使用相同的属性名。

（递归下降分析法所必须） <L>↑a↓b → e↓j <R>↓j      <L>↑x↓y → e↓j <R>↓j
<L>↑x↓y → <H>↓z↓w      <L>↑x↓y → <H>↓z↓w

2）具有相同值的属性取相同的属性名。

具有简单赋值形式的属性变量名取相同的属性名，可删去属性求值规则。

<S> → I↓a <B>↓b <C>↓c  b,c:= a

<S> → I↓x <B>↓x <C>↓x
