# Compiler

+   - 循环一次执行5条语句才给一个变量赋初值。展开后，一条语句就能赋一个值，运行效率高。
+   - 必须知道循环的终值，初值及步长。
+   - 但并不是所有展开都是合适的。如上例中循环展开后节省执行了转移和测试语句： 2*30=60语句（其实，还不止节省60条）。
+     ∴增加29条省60条
+     但若循环体中不是一条而是40条语句，则展开后将有40*30条=1200，但省的仍是60条，就未必合算了。

∴判断准则：1. 主存资源丰富 处理机时间昂贵 2. 循环体语句越少越好
