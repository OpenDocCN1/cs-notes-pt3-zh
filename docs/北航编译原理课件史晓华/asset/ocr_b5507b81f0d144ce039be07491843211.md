# 提高数据局部性!

```
/* Before */
for (i = 0; i < N; i = i+1)
    for (j = 0; j < N; j = j+1)
    {
        r = 0;
        for (k = 0; k < N; k = k + 1)
            r = r + y[i][k] * z[k][j];
        x[i][j] = r;
    }
```

```
/* After */
for (jj = 0; jj < N; jj = jj+B)
for (kk = 0; kk < N; kk = kk+B)
for (i = 0; i < N; i = i+1)
    for (j = jj; j < min(jj+B,N); j = j+1)
    {
        r = 0;
        for (k = kk; k < min(kk+B,N); k = k + 1)
            r = r + y[i][k] * z[k][j];
        x[i][j] = x[i][j] + r;
    }
```
