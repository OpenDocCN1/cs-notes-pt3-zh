# 规则一：（提取因子）

规则二： U:: =x|y|......|z|Uv, 则U:: =(x|y|......|z){v}

规则三：右递归P:: =Pα|β, 则P:: =β P’, P’:: =αP’| ε

# 例1  E:: =E+T|T

右部无公因子，所以不能用规则一。

为了使用规则二，
令E:: =T|E+T

∴由规则二可以得到
E:: =T{+T}

# 例2  T:: =T*F|T/F|F

T:: =T(*F|/F) | F 规则一

T:: =F|T(*F|/F)

T:: =F{(*F|/F)}  规则二

即T:: =F{*F|/F}

# 右递归：

T ::= FT’

T’ ::= *FT’ | /FT’ | ε
