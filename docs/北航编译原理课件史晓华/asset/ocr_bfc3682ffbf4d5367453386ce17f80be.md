# 基本块的例子：划分基本块

```
（1）  prod := 0
（2）  i := 1
（3）  t1 := 4 * i
（4）  t2 := a[t1]
（5）  t3 := 4 * i
（6）  t4 := b[t3]
（7）  t5 := t2 * t4
（8）  t6 := prod + t5
（9）  prod := t6
（10） t7 := i + 1
（11） i := t7
（12） if i <= 20 goto (3)
（13） …
```

下列语句序列，哪些属于同一个基本块，哪些不属于？

+   （1）~（6）
+   （3）~（8）
+   （7）~（13）
