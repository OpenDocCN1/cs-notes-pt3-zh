# 设栈s

```
S: ARRAY[1…L] OF RECORD
    c: logical             /*常量标志*/
    i: integer             /*常数值*/
    j: integer             /*变量符号表地址*/
t: integer                /*s域指针*/
```

```
@enter1 ↓ⱼ                         /*变量入栈，j为符号表地址*/

    procedure enters1(j)

            j : integer;

        begin

            t := t+1;

            s(t).c := false;

            s(t).j := j;

        end;
```
