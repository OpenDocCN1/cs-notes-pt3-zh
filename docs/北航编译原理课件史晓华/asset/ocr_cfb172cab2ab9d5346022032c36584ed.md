动作程序@brf的功能是生成 JMF指令，并将转移标号返回给属性y

```
procedure brf;
    string labx;
    labx := genlab;
    /*产生一标号赋给labx*/
    emitl('JMF', labx);
    return (labx);
end;
```

动作程序@br是是生成JMP指令，并将转移标号返回给属性z

```
procedure br;
    string labz;
    labz := genlab;
    emitl('JMP', labz);
    return( labz);
end;
```

动作程序@labprod是把从继承属性y得到的标号设置到目标程序中

```
procedure labprod(y);
    string y;
    setlab(y);
    /*在目标程序当前位置设标号*/
end;
```
