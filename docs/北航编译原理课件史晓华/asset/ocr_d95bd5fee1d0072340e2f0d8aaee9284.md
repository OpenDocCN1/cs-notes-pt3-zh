# 定义：

（1）有穷自动机的多余状态：从该自动机的开始状态出发，任何输入串也不能到达那个状态

例：

| 状态 | 0 | 1 |
|---|---|---|
| S₀ | S₁ | S₅ |
| S₁ | S₂ | S₇ |
| S₂ | S₂ | S₅ |
| S₃ | S₅ | S₇ |
| S₄ | S₅ | S₆ |
| S₅ | S₃ | S₁ |
| S₆ | S₈ | S₀ |
| S₇ | S₀ | S₁ |
| S₈ | S₃ | S₆ |

画状态图可以看出 S₄、S₆、S₈ 为不可达状态应该删除

| S₂ | S₂ | S₅ |
| S₃ | S₅ | S₇ |
| S₅ | S₃ | S₁ |
| S₇ | S₀ | S₁ |
