例：有下列FORTRAN 程序段

```
real      MAXPRN, RATE
integer   IND1, IND2
real      PRINT(100), YPRINT(5,100), TOTINT
```

假设整数占4个字节大小，实数占8个字节大小，则符号表中各变量在数据区中所分配的地址为：

| 名字 | 类型 | 维数 | 地址 |
|---|---|---|---|
| MAXPRN | r | 0 | 264 |
| RATE | r | 0 | 272 |
| IND1 | i | 0 | 280 |
| IND2 | i | 0 | 284 |
| PRINT | r | 1 | 288 |
| YPRINT | r | 2 | 1088 |
| TOTINT | r | 0 | 5088 |

数据区

+8×100

+8×100×5
