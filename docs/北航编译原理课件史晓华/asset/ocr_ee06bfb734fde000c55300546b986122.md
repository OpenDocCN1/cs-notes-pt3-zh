# 4.2.4 用递归子程序法构造语法分析程序的例子

```
文法： <语句>:: = <变量> := <表达式>
                | IF <表达式> THEN <语句>
                | IF <表达式> THEN <语句> ELSE <语句>
<变量>:: = i | i '[' <表达式> ']'
<表达式>:: = <项> | <表达式> + <项>
<项>:: = <因子> | <项> * <因子>
<因子>:: = <变量> | '(' <表达式> ')'
```

```
改写文法： <语句>:: = <变量> := <表达式>
                | IF <表达式> THEN <语句> [ELSE <语句>]
<变量>:: = i ['<' <表达式> '>']
<表达式>:: = <项> {+ <项>}
<项>:: = <因子> {* <因子>}
<因子>:: = <变量> | '(' <表达式> ')'
```
