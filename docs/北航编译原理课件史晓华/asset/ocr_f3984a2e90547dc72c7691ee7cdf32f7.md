# 全局变量和过程声明:

```
CLASS;                 /* 存放单词类别码 */
TOKEN;                 /* 存放单词值 */
NEXTSYM;               /* 词法分析程序，每调用一次单词类别码 ⇒ CLASS，
                          单词值 ⇒ TOKEN，该符号指针指向下一个单词 */
```

# 主程序:

```
NEXTSYM;

PROCS(7);

if  CLASS  ≠  右界符      then      ERROR;

ACCEPT
```

# 过程

```
PROCS(R)

    R;                    /* 值形参数声明 */
```
