下面通过一个例子，较详细地介绍如何构造属性文法的递归下降翻译器。

# 例：有如下属性翻译文法G[< S>]

+   1. < S>↓R1 → a ↑T1 < A> ↑Q1 @ X ↓T2,R2 < S> ↓Q2
+      R2:= R1
+      T2:= T1
+      Q2:= Q1

+   2. < S>↓R1 → b @ Z↓R2,   R2 := R1

+   3. < A>↑P → C↑U1 @ Y↓U2 < A>↑Q < S>↓z @ V↓P b
+      U2 := U1, P := Q + U1, z := U1-3

+   4. < A>↑P → @ w    P := 8

对简单赋值形式的属性变量取相同的属性名，其求值规则可以删去。开始符号的继承属性 R1=7。
