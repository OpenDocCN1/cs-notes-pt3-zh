# 二、距离向量路由与RIP协议(1/7)

+   - 在自治系统背景下，Internet路由器协议可以分为两类：
+     - 内部网关协议IGP(Interior Gateway Protocol)
+       - 自治系统内部使用的路由选择协议
+       - 经常使用协议为RIP和OSPF协议
+     - 外部网关协议EGP(External Gateway Protocol)
+       - 若始点的目的网络在不同的自治系统中，当信息传递到一个自治系统的边界时，就需要使用EGP协议将信息传递到另一个自治系统中
+       - 经常使用的协议为BGP-4
+   - 自治系统之间的路由选择又称为域间路由选择(interdomain routing)
+   - 自治系统内部的路由选择又称为域内路由选择(intradomain routing)

# 距离向量路由(distance vector routing)简介

也称为Bellman-Ford路由算法和Ford-Fulkerson算法
最先用于ARPANET，RIP协议采用
距离向量路由的基本思想是：
每个路由器维护一张表，表中给出了到达目的地的已知路由的距离，并通过与邻居交换路由信息来更新表
路由器周期性地向所有相邻路由器发送它自己的距离表，同时它也接收到邻居路由器所发送的距离表
根据路由表X所发送的内容，X到路由X的距离为Xx，本路由器到该目的地的距离为m，则该路由X的距离为Xx+m，根据不同邻居发来的信息，计算Xx+m，并取最小值，更新本路由器的路由表

# 二、距离向量路由与RIP协议(4/7)

+   - RIP(Routing Information Protocol)协议
+     - 属于距离向量路由协议
+     - RFC1058: Routing Information Protocol
+     - 特点：简单，适用于小型网络中的路由
+     - RIP中的距离定义：路由器跳数(hop count)
+       - 优点：使得计算简单
+       - 缺点：只能找到开销路径中最短包含最多15个跳数的路由
+       - 路由跳数超过15时就认为是不可达
+       - 直连的网络的跳数为0
+     - RIP的三个要点
+       - 仅和相邻路由器交换信息
+       - 交换的信息是整个网络的路由信息，即自己的路由表
+       - 按照固定的时间间隔交换路由信息(每条目30秒)
