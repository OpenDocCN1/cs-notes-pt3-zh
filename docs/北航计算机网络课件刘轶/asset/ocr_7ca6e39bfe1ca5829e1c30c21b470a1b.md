# 6.1 套接字编程接口

+   - 网络子系统作为操作系统的一部分，以应用编程接口（API-Application Programming Interface）的形式向应用程序提供调用接口
+   - 套接字(socket)是最常用的应用层编程接口
+     - 名称源自Berkeley UNIX系统
+   - 经典的socket编程接口采用同步调用方式(又称阻塞式)
+     - 调用recv()时，调用进程被阻塞，直到数据报为止
+   - Windows这些基于事件驱动的系统，程序的执行由事件驱动，需要采用异步动作方式的套接字编程接口
+   - Microsoft推出WinSock编程接口，在阻塞式调用基础上，增加异步调用方式
+   - 在阻塞式调用模式下，WinSock与经典的socket兼容

# 常用socket接口函数

| 接口函数 | 功能 |
|---|---|
| SOCKET socket_s int af, int type, int protocol ) | 创建一个socket |
| int bind( SOCKET s, struct sockaddr *addr, int namelen ) | 绑定一个本地地址到socket确定 |
| int listen( SOCKET s, int backlog ) | 在指定端口监听并建立连接 |
| int connect( SOCKET s, struct sockaddr *name, int namelen ) | 名称指定的服务器建立连接请求 |
| SOCKET accept( SOCKET s, struct sockaddr *addr, int *addrlen ) | 接收并建立新的连接请求 |
| int send( SOCKET s, char *buf, int len, int flags ) | 在连接的socket上发送数据 |
| int recv( SOCKET s, char *buf, int len, int flags ) | 在连接的socket上接收数据 |
| int sendto( SOCKET s, char* buf, int len, int flags, struct sockaddr* to, int token ) | 向指定目的的网络发送数据报 |
| int recvfrom( SOCKET s, char* buf, int len, int flags, struct sockaddr* from, int *fromlen ) | 在socket上接收数据并记录地址 |
