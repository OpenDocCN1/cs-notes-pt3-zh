# 一、网络地址转换 NAT

+   - 当内部网络使用专用地址时，与Internet的通信需要通过NAT(Network Address Translation)

# 二、虚拟专用网 VPN

+   - VPN--Virtual Private Network 虚拟专用网
+   - 多个企业/机构的内部网络之间通信的实践方法
+     ○ 租用专用线路，形成专用网，或成本高
+     ○ 善于公用网络(Internet)，形成虚拟VPN
+   - VPN涉及的技术包括：隧道(tunnel)、加密、身份认证等
