# 5.2 用户数据报协议 UDP

# 一、UDP概述

+   - UDP 只在 IP 的数据报服务之上增加了很少一点的功能
+   - 端口和差错检测
+   - UDP 不是可靠传输协议，但具有自身特点，与TCP分别面对不同的应用
+   - UDP协议的特点
+     (1) 无连接，即发送数据之前不需要建立连接
+     (2) 尽最大努力交付，即不保证数据交付，同时也不使用拥塞控制
+     (3) 是面向报文的，收发数据时保留报文边界，很适合多媒体传输的要求
+     (4) 支持一对一、一对多、多对一和多对多的交互通信
+     (5) 首部开销小，只有 8 个字节

# 二、UDP首部格式

+   - UDP数据报包括2个字段：首部和数据字段
+   - 首部共4个字段，8字节
+   - 首部各字段
+     (1) 源端口：源端口号
+     (2) 目的端口：目的端口号
+     (3) 长度：UDP数据报长度
+     (4) 检验和：用于检测数据的正确性

# 注意要在网络传输过程中的表示：

+   - 两种字节序
+     Little endian：低字节在低地址处，高字节在前
+     Big endian：高字节在低地址处，低字节在前
+   - 网络中通常用 big endian
+     - 例如在发送字节序列时，编码时要注意使用转换字节序的函数：htons(), htons(), ntohl(), ntohs()

# 5.3 传输控制协议 TCP 概述

# 一、TCP的主要特点

+   (1) TCP是面向连接的运输层协议
+     传输数据前必须先建立连接，传输完毕后释放连接
+     (2) 每一条TCP连接只能有两个端点(endpoint)，每一条TCP连接只能是点对点的（一对一）
+     (3) TCP提供可靠交付服务
+     无差错、不丢失、不重复、按序到达
+     (4) TCP提供全双工通信
+     在一个连接上，通信的双方都可以同时发送数据
+     (5) 面向字节流
+     认为运输层传输的单位是字节流
+     发送方把数据流无缝分割成报文段，接收方则把收到的数据流再组装成报文段，但TCP并不保证其无结构的字节流
+     接收方收到的数据流可能与发送方发送的数据流不同，但保证顺序一致
