# 四、外部网关路由协议BGP

+   - **BGP(Border Gateway Protocol)简介**
+     - BGP是不同自治系统的路由之间交换路由信息的协议
+     - BGP-4，RFC4271～4278，2006年
+   - **BGP使用环境的特性**
+     - Internet的规模很大，AS之间的路由选择非常困难
+       - Internet主干网络由各国的网络前缀达到数百万
+       - 对于AS之间的路由选择，要寻找最佳路由是不现实的
+       - 不同AS路径复杂且标准不同
+     - AS之间的路由选择需要考虑多种因素
+       - 例1：AS1到AS6的数据经过AS3在技术上最慢，但AS3可能不同意
+       - 例2：出于国家安全的考虑，可能不希望数据经过某些国家
+   - BGP难以找到最佳路由，只能寻找一条能够到达目的网络且比较好的路由（不能兜圈子）

# 4.5 路由算法及协议

+   - **BGP发言人(speaker)**
+     - 每个AS都选择一个路由器作为“BGP speaker”
+     - 两个BGP发言人通过一个共享网络连接在一起
+     - BGP发言人一般是AS的边界路由器，但也可以不是
+     - BGP发言人与其他自治系统中的BGP发言人交换路由信息
+     - 随自治系统的交换通过TCP协议进行，两个发言人在TCP连接上交换BGP报文以建立BGP会话（session），利用BGP会话交换路由信息
+     - BGP发言人除了运行BGP协议外，还要运行AS的内部网关路由协议

# 4.5 路由算法及协议

+   - **BGP-使用四种报文**
+     ① OPEN报文：用来相邻的一方BGP发言人建立关系
+     ② UPDATE报文：用来发送一些路由的信息，以及列出需要撤销的多条路由
+     ③ KEEPALIVE报文：用来确认打开报文和周期性地证实邻站关系
+     ④ NOTIFICATION报文：用来发送检测到的错误
+     - BGP发言人通过OPEN报文与另一发言人建立会话，对方如果同意则回应KEEPALIVE报文
+     - 双方周期性发KEEPALIVE报文，以确认会话未中断
+     - 当信息发生变化时，发送UPDATE报文
+   - **BGP协议特点**
+     - 交换路由信息的结点数量必须与自治系统个数相当，大大少于这些自治系统中网络的网数
+     - 每个自治系统中BGP发言人（或边界路由器）的数目很少，使得自治系统间的路由选择方式较少
+     - BGP支持CIDR，因此BGP路由表包括目的网络前缀、下一跳路由器，以及到达该目的网络经过的各自治系统序列
+     - 在BGP四种报文中，知识交换报文的BGP报文；以后需要在发生变化时更新受影响部分，有利于节省网络带宽和减少处理开销

# 五、路由器(Router)

+   - 路由器是一种具有多个输入端口和多个输出端口的专用计算机，其任务是转发分组

![](bbox=[0.573, 0.605, 0.929, 0.67])

+   - Cisco 7304高端路由器
+     - LAN接口：2个10/100/1000M以太网
+     - WAN模块：OC-3或OC-48
+     - 包转发速率：3.5Mpps
+   - Cisco 2811多业务路由器
+     - LAN接口：2个10/100M以太网
+     - WAN模块：T1/E1/DSL等
+     - 集成防火墙、支持VPN、IP语音等功能

# 五、路由器(Router)

+   - 路由器包含两部分
+     - 路由选择部分：核心为路由选择处理机，它按照路由选择协议与其他路由器交换路由信息，构建路由表
+     - 分组转发部分：包含交换结构(switching fabric)、一组输入端口和输出端口
+       - 交换结构将分组转发到合适的线端口，每发送一个分组便转发到相应输出端口

# 五、路由器(Router)

+   - **路由器设计的关键之一是分组的高速转发**
+     - 决定报文转发速率的因素有：
+       - 输入/输出端口的处理性能
+       - 交换机构的性能
+       - 线速(line speed或wire speed)：分组的处理速率能够达到线路上分组的传输速率
+       - 衡量路由器性能的指标：pps(packet per second)
+       - 如OC-48链路(2.5Gb/s)，如分组长度为256字节，则线速转发意味着每秒处理分组>100万
