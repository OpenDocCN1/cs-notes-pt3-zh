# 2.6 宽带接入技术

# 一、xDSL技术(Digital Subscribe Line)

+   - “最后—英里(last mile)”
+   - 通信运营商运营商端局到家庭用户之间的本地回路
+   - 对此最后一段进行数字化改造成为宽带，对传统电话提供传输方式
+   - “最后—英里”被称作技术改造的瓶颈和心脏之一

xDSL技术不改变现有一类“电话线”作为传输媒体的情况下，通过改造现有的模拟电话用户线来提供高速率数据业务的接入技术。

+   - xDSL的几种类型
+   - ADSL(Asymmetric Digital Subscriber Line)
+   - HDSL(High speed DSL)
+   - SDSL(Single-line DSL)
+   - VDSL(Very high speed DSL)

+   - ADSL主要特点
+   - 仍然保留电话功能，无需对现有的电话系统进行改造
+   - 下行频率高于上行频率，频率分配使用不同，面向网络接入用户
+   - 上行
+   - 管理端，即运行于ISP下行(ISP→用户)业务不同，适应各种用户上网需求(多业务网，下载为主用)

# ADSL频谱分布

![](bbox=[0.08, 0.52, 0.48, 0.65])

+   - 高频多音频 DMT (Discrete Multi-Tone)调制技术
+   - 采用频分复用
+   - 将 40k~1.1MHz 的频谱频段划分为许多子信道，其中 25 个子信道用于上行，249 个子信道用于下行
+   - 每个子信道宽为 4kHz，并使用不同的载波(即不同的音调)
+   - 进行数字信号传输
+   - 用户线彼此差别很大(距离、线材等)，ADSL 采用自适应调制技术使用户端能够传输尽可能高的数据率

# 一、xDSL技术(Digital Subscribe Line)

+   - ADSL标准和传输速率
+   - 1999年，ADSL1形成国际标准ITU-T，下行8Mbps，上行1Mbps
+   - 2002年，ADSL2，下行12Mbps，上行1Mbps
+   - 2003年，ADSL2+，下行24Mbps，上行1Mbps

ADSL定义传输速率是可能达到的最高传输速率，实际传输速率与用户线路的质量和距离相关

# 二、HFC

+   - Hybrid Fiber Coax光纤混合同轴网
+   - 以有线电视网 CATV为基础的宽带接入技术
+   - 单向广播式传输 → 双向传输
+   - 传输数据信号 → 传输视频、语音、数据
+   - 以同轴电缆为主 → 光纤 + 同轴电缆

+   - 主要特点
+   - 主干线路采用光纤
+   - 采用点对点系统结构
+   - 其具有CATV网络原有的频谱，且具有双向传输功能
+   - 每个家庭安装一个用户接口盒UIB (User Interface Box)

同轴电缆连接到用户端，电缆调制解调器确定用户计算机
