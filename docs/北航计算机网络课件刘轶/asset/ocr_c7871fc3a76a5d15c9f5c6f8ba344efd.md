# 三、信道的极限容量

+   - 信道能够通过的频率范围
+   - 一个信道能够通过的频率范围总是有限的，高频分量往往不能通过信道
+   - 接收收到的信号波形失去了码元之间的清晰界限，即“码间串扰”
+   - 奈奎斯特(Nyquist)定理
+   - 理想低通信道最大数据传输速率 = 2H log2 V (bps)
+   - H——信道带宽，V——信号码元的级数(信号的电平数)
+   - 在信道传输中，码元传输速率越高上限制，否刚会出现码间串扰的现象，使接收端无法从收到的信号中恢复出原来的信号
+   - 信道频率带宽宽，能通过的信号高频分量越多，就可以用更快的速率传输码元而不出现码间串扰

# 2.2 数据通信的基础知识

+   - 信噪比
+   - 信号功率平均功率与噪声的平均功率之比，常记为S/N，以分贝(dB)为计算单位
+   - 信噪比 = 10log10(S/N) (dB)
+   - 例：S/N=10时，信噪比为10dB；S/N=1000时，30dB
+   - 1948年，信息论创始人香农(Shannon)推出了香农公式
+   - 信道的极限信息传输速率 C 可表示为：
+   C = W log2(1+S/N) b/s
+   W：信道带宽
+   S：信道原信号的平均功率
+   N：信道内部的高斯噪声功率
+   - 香农公式表明：信道带宽或信道中的信噪比越大，则信息的最大传输速率越高

# 一、导向传输介质(1/3)

+   - 双绞线(twisted pair)
+   - 通过将两根绝缘铜线绞合，减小相互干扰
+   - 分类
+   - 屏蔽双绞线 STP (Shielded Twisted Pair)
+   - 无屏蔽双绞线 UTP (Unshielded Twisted Pair)
+   - 在网络的布线时常采用屏蔽双绞线
+   - 价格便宜，使之安装使用，传输距离较短
+   - 局域网的双绞线使用芯线数双绞线的类别和带宽
+   - 局域网EIA/TIA-568标准定义了非屏蔽双绞线的类别和带宽
