
## 6.1 套接字编程接口

网络子系统作为操作系统的一部分，以应用编程接口（API-Application Programming Interface）的形式向应用程序提供调用接口
套接字(socket)是最常用的应用层编程接口
名称源自Berkeley UNIX系统
经典的socket编程接口采用同步调用方式(又称阻塞式)
调用recv()时，调用进程被阻塞，直到数据到达为止
Windows这些基于事件驱动的系统，程序的执行由事件驱动，需要采用异步动作方式的套接字编程接口
Microsoft推出WinSock编程接口，在阻塞式调用基础上，增加异步调用方式
在阻塞式调用模式下，WinSock与经典的socket兼容

## 6.2 域名系统 DNS

### 一、域名系统概述

域名系统 DNS（Domain Name System）是 Internet 使用的命名系统
RFC 1034：Domain Names - Concepts And Facilities
RFC 1035：Domain Names - Implementation and Specification
Internet 采用层次结构的命名树作为主机的名字，并使用分布式的域名系统 DNS
多个域名服务器共同运行专门的域名服务器程序，完成域名到 IP 地址的解析（resolve）
DNS 基于 UDP 协议实现
应用进程需要进行域名解析时，就调用域名解析程序（resolver），它成为 DNS 的一个客户
向本地域名服务器发送域名解析请求（通常包含待解析的域名）
本地域名服务器在查找域名后，返回应答报文，其中包含对应的 IP 地址

### 二、Internet的域名结构

Internet采用层次结构的命名方法
...顶级域名...二级域名...三级域名
顶级域名（TLD: Top Level Domain）
国家顶级域名，如：.cn 表示中国，.us 表示美国，.uk 表示英国，等等

### 三、域名服务器

域名服务器分为四类
根域名服务器
最高级的域名服务器，知道所有的顶级域名服务器的域名和 IP 地址
当本地域名服务器无法解析域名时，求助于根域名服务器
顶级域名服务器
负责管理该顶级域名服务器注册的所有二级域名
权限域名服务器
负责一个区（zone）的域名服务器
本地域名服务器
有时也称为默认域名服务器
域名服务器是相对独立地把收到几个域名服务器来保存，其中的一个是主域名服务器，其他的是辅助域名服务器

## 6.3 文件传送协议

RFC 959: File Transfer Protocol (FTP)
FTP使用客户/服务器方式
一个FTP服务器同时可为多个客户提供服务
FTP的服务模型是采用大端口小端口组成
一个主进程，负责监听新请求
若有新请求到来，则从主进程中派生一个从进程
主进程的工作步骤
打开服务器端端口(端口号为21)，使客户进程能够连接上
等待客户进程发出连接请求
启动从属进程处理客户进程发来的请求
从属进程和客户进程建立连接后可以单独工作
从属进程在运行过程中若接收到客户进程发来的一些请求
回到初始状态，继续接受其他客户进程发来的请求
主进程与从属进程的处理是并行进行的

FTP使用2个TCP连接：控制连接和数据连接

控制连接
在一个会话期间一直保持打开
FTP客户所发出的控制信息通过控制连接发送给服务器端的控制进程，但控制连接不传输数据
数据连接
收到FTP客户发来的文件传输请求后，服务器端控制进程创建“数据连接进程”如“数据传送”
数据连接用来传输文件的数据，传输完毕后关闭，“数据传送连接”并结束运行

2009年的一道考研题

FTP客户和服务器间传送FTP命令时，使用的是连接是 A. 建立在TCP之上的控制链接 B. 建立在TCP之上的数据链接 C. 建立在UDP之上的控制链接 D. 建立在UDP之上的数据链接

## 6.4 万维网WWW

一、万维网概述
WWW---World Wide Web
1989年，欧洲核子研究中心提出WWW
1993年，第一个浏览器Mosaic
1995年，Netscape Navigator上市
万维网是分布式的超媒体(hypermedia)系统，它是超文本(hypertext)系统的扩充
要解决的几个问题
怎样将分布在整个网络上的万维网文档？------URL
用什么协议实现万维网上传各种超链接的链接？------HTTP
如何存储和表示万维网文档？------HTML
