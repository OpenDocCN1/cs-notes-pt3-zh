# 1977年图灵奖获奖者John Warner Backus

![](bbox=[0.18, 0.24, 0.38, 0.52])

1924～

FORTRAN语言和backus范式(BNF)的发明人。因对可用的高级编程系统设计有深远和重大的影响而获奖。

Backus的重要论文有：

Reduction Languages and Variable Free Programming, 1972

图灵演讲：

Can Programming be Literated from the von Neumann Style?

A Functional Style and Its Algebra of Programs
