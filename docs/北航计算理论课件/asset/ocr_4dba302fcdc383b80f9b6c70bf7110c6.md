# 4.4 谓词Horn逻辑中的自动推理

推理过程如下；

+   1. 首先通过合一置换θ={Peter/x, Smith/z}，将目标与知识库中第一条规则的规则头匹配，得到新目标

```
father(Smith, y), father(y, Peter) →
```

+   2. 考察知识库中第二条和第三条规则，通过合一置换σ={John/y}与知识库中的事实匹配

```
→ father(Smith, John), → father(John, Peter)
```

因此查询目标成立，并且返回置换

```
θ ∘ σ={Peter/x, John/y, Smith/z}
```
