# 4.4 谓词Horn逻辑中的自动推理

将置换θ作用于表达式e的算法如下

```
Substitution(e, θ)
{
    if (e是常量符号)   then return e;
    if (e是变量符号x) then { if (t/x∈θ) then return t
                            else return e;
                        }
    if (e=f(t₁,...,tₙ)) then { t₁= Substitution(t₁, θ);
                            ...
                            tₙ= Substitution(tₙ, θ)
                            return f(t₁,...,tₙ)
                        }
}
```
