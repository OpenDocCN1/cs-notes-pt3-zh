# § 4.3 公理语义

# Hoare公理系统

+   - 赋值规则
+   
+     `{Q[E/x]}  x:=E  {Q}`

+   - 条件语句规则
+   
+     ```
+     {P ∧ b} s1 {Q}   {P ∧ ~b} s2 {Q}
+     ----------------------------------
+              {P} if (b, s1, s2) {Q}
+     ```

+   - 复合语句规则
+   
+     ```
+     {P} s1 {R}   {R} s2 {Q}
+     -----------------------
+           {P} s1;s2 {Q}
+     ```
