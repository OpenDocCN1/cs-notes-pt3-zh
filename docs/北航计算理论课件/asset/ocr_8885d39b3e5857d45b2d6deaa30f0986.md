# § 5.1 卫式命令

卫式命令gc的执行规则：

+   - <b, σ> → true
+     -----------------
+     <b→c, σ> → <c, σ>
+   - <b, σ> → false
+     -----------------
+     <b→c, σ> → fail
+   - <gc₀, σ> → <c₀, σ'>
+     -----------------------------
+     <gc₀ [] gc₁, σ> → <c₀, σ'>
+   - <gc₁, σ> → <c₁, σ'>
+     -----------------------------
+     <gc₀ [] gc₁, σ> → <c₁, σ'>
+   - <gc₀, σ> → fail  <gc₁, σ> → fail
+     ----------------------------------------
+              <gc₀ [] gc₁, σ> → fail
