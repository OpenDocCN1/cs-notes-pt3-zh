# § 5.2 CSP理论

卫式命令gc的执行规则：

```
<b, σ> → true
-------------------
< b ⇒ P, σ> → <P, σ>
```

```
<b, σ> → false
--------------------
< b ⇒ P, σ> → fail
```

```
<b, σ> → true
-----------------------------
< b;P?x ⇒ Q, σ> ⇝ⁿ <Q, σ [n/x]>
```

```
<b, σ> → false
-----------------------------
< b;P?x ⇒ Q, σ> → fail
```
