# 4.4 谓词Horn逻辑中的自动推理

+   - 谓词Horn逻辑的消解要复杂一些。消解方式如下。若有子句
+   
+     \(S_1: A_1,\ldots,A_n \to\)
+   
+     \(S_2: B_1,\ldots,B_m \to B\)，
+   
+     并且 \(A_i, B\) 具有合一置换 \(\theta\)，则归结后的子句为
+   
+     \(S_3: (A_1,\ldots,A_{i-1},B_1,\ldots,B_m,A_{i+1},\ldots,A_n)\theta \to\)

+   - 与命题Horn逻辑相比，需要考虑项的匹配，即合一问题。
