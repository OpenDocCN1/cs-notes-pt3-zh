# § 3.2 π演算

+   - 定义：fn(P)表示进程P中的自由名集
+     - fn(ν y(x).P) = {y} ∪ (fn(P) − {x})
+     - fn(ν xy.P) = {x,y} ∪ fn(P)
+     - fn((x)P) = fn(P) − {x}

+   - 结构等价：
+     - (x)(y)P ≡ (y)(x)P
+     - ((x)P | Q) ≡ (x)(P | Q)  if x ∉ fn(Q)
+     - x(y).P ≡ x(z).P[z/y]  if z ∉ fn(P)
+     - (y)P ≡ (z)P[z/y]  if z ∉ fn(P)
