# 2.3.2 下推自动机

例： M = ({q0, q1, q2}, {a, b}, {Z, A, B}, δ, q0, Z0, {q2}) 是一个 PDA，其中 δ 由以下各式定义：

δ(q0, a, Z0) = {<q0, AZ0>},

δ(q0, a, A) = {<q0, AA>, <q1, ε>},

δ(q0, a, B) = {<q0, AB>},

δ(q0, b, A) = {<q0, BA>},

δ(q0, b, B) = {<q0, BB>, <q1, ε>},

δ(q1, a, A) = {<q1, ε>}, δ(q1, b, B) = {<q1, ε>},

δ(q1, ε, Z0) = {<q2, ε>}
