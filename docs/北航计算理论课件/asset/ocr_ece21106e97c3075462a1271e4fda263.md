+   - 给定两个置换

$\theta=\{t_1/x_1,\ldots,t_n/x_n\}$

$\lambda=\{u_1/y_1,\ldots,u_m/y_m\}$

将集合

$\{t_1\lambda/x_1,\ldots,t_n\lambda/x_n,u_1/y_1,\ldots,u_m/y_m\}$

删去以下元素：

+   - $u_i/y_i$，当 $y_i\in\{x_1,\ldots,x_n\}$
+   - $t_i\lambda/x_i$，当 $t_i\lambda=x_i$

得到的新置换表示为 $\theta\cdot\lambda$，称为 $\theta$ 和 $\lambda$ 的复合。
