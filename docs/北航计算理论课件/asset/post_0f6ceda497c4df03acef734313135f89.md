# § 5.1 卫式命令

- 用于描述程序的不确定性，主要由算术表达式AExp和布尔表达式BExp组成。

- 形式：

```
gc ::= b → c | gc [] gc
c ::= skip | abort
      | x:=a | c;c
      | if gc fi | do gc od
```

其中 a∈ AExp，b∈BExp，符号 “[]” 称为选择构造符。

# § 5.1 卫式命令

- **定义1 状态 STATE**
  - 对偶（变量名，变量值）的表称为状态，一般用STATE表示。
  - 形式也可定义为：
  
    `STATE = (VAR × VAL)*`
  
    或
  
    `STATE = (VAR → VAL)`
  
    对变量 x 在当前状态 σ 中的值为 σ(x)

# § 5.1 卫式命令

定义2 卫式命令的一步执行 “→”
用格局<gc, σ>表示在当前状态σ中执行卫式命令gc，执行一步后形成新的格局或新的状态或者是特殊的fail和abortion。

- 例：
  <a, σ> → n
  -------------------
  <x := a, σ> → σ[n/x]

# § 5.1 卫式命令

卫式命令gc的执行规则：

- <b, σ> → true
  -----------------
  <b→c, σ> → <c, σ>
- <b, σ> → false
  -----------------
  <b→c, σ> → fail
- <gc₀, σ> → <c₀, σ'>
  -----------------------------
  <gc₀ [] gc₁, σ> → <c₀, σ'>
- <gc₁, σ> → <c₁, σ'>
  -----------------------------
  <gc₀ [] gc₁, σ> → <c₁, σ'>
- <gc₀, σ> → fail  <gc₁, σ> → fail
  ----------------------------------------
           <gc₀ [] gc₁, σ> → fail

# § 5.1 卫式命令

命令c的执行规则：

- <skip, σ> → σ

- <abort, σ> → abortion

- <a, σ> → n

- \(<gc, \sigma> \to <c, \sigma'>\)

# § 5.2 CSP理论

- CSP（Communicating Sequential Processes）：Hoare给出的一种描述并发与分布式计算的研究模型。
- CSP是一种命令式语言形式，描述对象是进程，进程是CSP的基本成分。以通信原语描述进程的通信机制。
- 通信原语与具体的通信介质无关。

# § 5.2 CSP理论

- 基本通信原语
  - 输入语句：
    P? x
    例如：
    <P? x, σ> --P?2--> σ[2/x]
  - 输出语句：
    Q! v
    例如：
    <Q!v, σ> --Q!2--> σ

# § 5.2 CSP理论

进程P ::
..
..
Q?x
..
..
Q!2x
..
..

进程Q ::
..
 y:=5
..
 P!y+1
..
..
..
 P?y

# § 5.2 CSP理论

- 约定：
  - 用符号λ表示 P?x、P!v 和 空标识 ε，表示从外界能够观察到的该进程的行为。
  - 为统一规则一步执行时格局的结构形式，约定 σ ≡ <skip, σ>，并且有：
    skip;P ≡ P
    P ≡ skip || P ≡ P || skip
    skip ≡ skip || skip

# § 5.2 CSP理论

# CSP进程P的执行规则：

- ⟨skip, σ⟩ → σ
- ⟨abort, σ⟩ → abortion
- ⟨a, σ⟩ → n
  ⟨x := a, σ⟩ → σ[n/x]
- ⟨P?x, σ⟩ \xrightarrow{P?n} σ[n/x]
- ⟨a, σ⟩ → n
  ⟨P!a, σ⟩ \xrightarrow{P!n} σ

# § 5.2 CSP理论

<gc, σ> --λ--> <P, σ'>
-----------------------------
< if gc fi, σ> --λ--> <P, σ'>

<gc, σ> --> fail
-----------------
< if gc fi, σ> --> σ

<gc, σ> --λ--> <P, σ'>
--------------------------------
< do gc od, σ> --λ--> <P; do gc od, σ'>

<gc, σ> --λ--> fail
-----------------
< do gc od, σ> --λ--> σ

<P₀, σ> --λ--> <P₀', σ'>
--------------------------------
< P₀; P₁, σ> --λ--> <P₀'; P₁, σ'>

<P₀, σ> --λ--> <P₀', σ'>
--------------------------------
< P₀ || P₁, σ> --λ--> <P₀' || P₁, σ'>

<P₁, σ> --λ--> <P₁', σ'>
--------------------------------
< P₀ || P₁, σ> --λ--> <P₀ || P₁', σ'>
