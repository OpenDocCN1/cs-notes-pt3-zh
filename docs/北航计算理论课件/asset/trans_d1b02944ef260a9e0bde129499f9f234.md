

## § 1.1 纯Lambda演算理论

- Lambda变换规则
  - η变换（保值变换）：`(λx.Mx) →η M`，其中 `x ∉ fv(M)`
- 归约基：

  β变换和η变换的左部分别称为β归约基和η归约基，统称为归约基。
- 特例：
  - `(λx. xx) (λx. xx)`
    - →ᵦ `(λx. xx) (λx. xx)`
    - →ᵦ …
  - `(λx.y) ((λx.xx) (λx.xx))`

## § 1.2 纯Lambda演算实例

- 布尔表达式
  - 布尔值
    - tru = λa.λb.a
    - fls = λa.λb.b
  - 布尔运算
    - and = λx.λy. x y fls
    - or = λx. λy. x tru y
    - not = λx. x fls tru
- 整数表达式:
  - 整数定义：λa. λb. a(a(...(ab)...)) = λa. λb. aⁿb
  - 0 = λa. λb. b
  - 1 = λa. λb. ab
  - 2 = λa. λb. a(ab)
  - ...
  - n = λa. λb. aⁿb

## § 1.3 纯Lambda演算的扩展

- 扩展λ-表达式
  - `E ::= true | false | n | f`
  - `| x | E₁ E₂ | λx.E | (E)`
  - `| (E₀ → E₁, E₂)`
  - `| let x = E₀ in E`
- 扩展λ-变换规则
- 扩展数据类型

### 图灵简介

图灵（Alan Mathison Turing），计算机逻辑的奠基者，许多人工智能的重要方法也源自于这位伟大的科学家。

他的重要贡献在于提出“图灵机”（Turing Machine）的概念，还提出了重要的机器智能衡量标准“图灵测试”。

![](img/ffda313724bb0d18f2f606b4f770e807_376_0.png)

1912～1954

图灵的重要论文有：

- On Computable Numbers with an Application to the Entscheidungs Problem
- Computer Machinery and Intelligence

### ACM简介

ACM (Association for Computing Machinery)，美国计算机学会，是全球历史最为悠久和最大的教育科学计算机学会。

自1947年开始，ACM就提供了一个影响巨大的论坛空间供大家进行信息、创意、和最新发现的交流，致力于发展在高级艺术、最新科学、工程技术和应用领域中的信息技术，强调在专业领域或在社会感兴趣的领域中培养、发展开放式的信息交换，推动高级的专业技术和通用标准的发展。

![](img/ffda313724bb0d18f2f606b4f770e807_377_0.png)

### 图灵奖的由来

图灵奖由ACM于1966年设立，又叫“A.C.M.图灵奖”，专门奖励那些对计算机事业作出重要贡献的个人。其名称取自计算机科学的先驱、英国科学家Alan Mathison Turing，这个奖设立的目的之一是纪念这位科学家。

![](img/ffda313724bb0d18f2f606b4f770e807_378_0.png)

![](img/ffda313724bb0d18f2f606b4f770e807_379_0.png)
