# UML的用例视图

+   - 从系统外部执行者的角度理解系统的功能：它描述执行者与系统的交互，其执行者可以是一个用户，也可以是另一个系统。
+   - 用例图面向客户、建模人员、开发人员和测试人员，是系统模型图的核心。
+   - 用例视图：用例图和活动图描述。
+   - 一张用例图是系统的一种用途的描述；一组用例图描述了整个系统所期望的用途。
