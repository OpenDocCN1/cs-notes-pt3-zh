+     - 人对现实事物的认知与其被认知的方式根本不同所造成的翻译过程的复杂性
+     - 人在构件软件过程中的认知的复杂性
+     - 软件开发过程中用户、开发者等涉众之间交互的复杂性
+     - 软件项目组织管理的复杂性
