# UML2.0

Infrastructure — Defines basic constructs to specify UML and to customize it for specific domains (e.g., real-time)

+   - UML规格说明是通过元模型方法来定义的（也就是，一个元模型用来定义包含UML的模型），这种方法采用了一些形式化的定义技术。
+   - 虽然这种方法缺乏一些形式化定义方法的严密性，但是对大多数执行人员和从业者来说，它具有更强的直观性和实效性。
