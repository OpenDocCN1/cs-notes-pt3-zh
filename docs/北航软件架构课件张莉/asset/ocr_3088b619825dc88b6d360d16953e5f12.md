# 软件工程进展

+   - 20世纪60年代末－70年代中期：
+     - 高级语言应用，结构化程序设计技术，支持工具
+   - 20世纪70年代中期－80年代：
+     - 计算机辅助软件工程（CASE），软件工程环境。
+   - 20世纪80年代中期－90年代：
+     - 出现面向对象语言和方法，并成为主流的软件开发技术
+     - 开展软件过程及软件过程改善的研究
+     - 软件构件技术、软件体系结构技术
