# 进程结构 - PROCESS STRUCTURE

| 目标 | 如何实现 |
| --- | --- |
| 实现从输入到输出的映射 | 每个进程都作为一个采样、输入、计算、输出的周期来实现 |
| 满足实时需求 | 通过进程结构确定进程，实现进程的非在线调度 |
| 及时提供运算量大的计算结果 | 后台计算，并在需要时将最新结果返回。 |
