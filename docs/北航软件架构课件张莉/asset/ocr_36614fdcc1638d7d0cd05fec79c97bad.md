# 四层元模型体系结构

| 层 | 描述 | 示例 |
|---|---|---|
| 元-元模型 (M3) | 元模型体系结构的基础结构，定义了规定元模型的语言。 | 元类、元属性、元操作 |
| 元模型 (M2) | 元-元模型的实例，定义了规定模型的语言 | 类、操作、构件 |
| 模型 (M1) | 元模型的实例，定义描述某一信息域的语言 | People |
| 用户对象 (数据) (M0) | 模型的实例，定义了特定领域的值。 | <name_张三> |

事实上，多层体系结构可以有无限多的层次。
