# UML2.5的目标

+   - 领导UML 2.5版本任务的主力军是来自微软的架构师Steve Cook
+   - **UML2.5的目标：简单化。** UML本身没有改变。
+   - 对之前的版本进行了大范围的重写，通过**消除冗余和提升清晰度**来使得它更易读。
+   - 没有使用包含合并。每个元类都在一个章节内完整的被定义。----**因此，章节是按照元类来组织的。**
+   - UML 2.5为也图表和模型的互换，第一次引入了正式规范。----解决不同工具实现之间的互换问题
