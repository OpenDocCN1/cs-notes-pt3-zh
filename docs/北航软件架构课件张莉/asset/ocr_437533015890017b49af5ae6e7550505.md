# 基础构造 (Infrastructure)

+   - 基础构造库提供了更精确的概念基础，以更好的支持 MDA。
+   - 基础构造库包括了建立元模型时所用到的核心概念，提供了 MOF、UML 等语言的共同核心。

# 基础构造

+   - 基础构造由基础构造库来描述。
+   - 基础结构包含定义了 UML 的可重用元语言核心与元模型扩展机制。
+     - 元语言核心能够用于制定各种元模型，包括 UML、MOF 和 CWM。
+     - 基础结构库还定义了一种外廓扩展机制，当某些平台和建模领域不具备元模型建模能力时，利用这种扩展机制可以为这些平台对 UML 进行定制。
