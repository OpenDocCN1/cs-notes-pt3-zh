# 在复杂系统中，决不可能以独立的方式实现质量属性。

+   - 任何一个质量的实现都会对其他质量属性的实现产生积极或消极的影响。
+   - 如：安全性和可维护性。
+   - 几乎每个质量属性都会对系统的性能产生消极的影响，如可移植性。

# ISO/IEC9126

McCall模型质量属性映射到ISO/IEC9126的六个特性：正确性、可维护性、可靠性、效率、易用性、完整性等

# ISO/IEC9126是McCall模型的继承模型。将软件质量分解为6个特性：

+   - 功能性
+   - 可靠性
+   - 易用性
+   - 可使用性
+   - 可维护性
+   - 可移植性

# 为了方便起见，从以下两个方面讨论质量属性：

+   - 通过运行可观察到的系统质量属性
+     - 在运行过程中，系统是否按照规格说明的要求工作？系统运行是否达到了预期的效果？系统的输出是否及时？执行是否正确？系统是否能按要求达到预期的精度及稳定温度？当与其他系统连接时，系统工作是否正常？
+   - 通过运行不可观察到的系统质量属性
+     - 系统复杂、如果修改软件的易用性如何？开发的成本有多少？是否在公共时间市场等？
