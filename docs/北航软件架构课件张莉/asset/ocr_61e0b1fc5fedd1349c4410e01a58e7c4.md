# 软件体系结构和质量属性

我们将从以下三个方面讨论：

+   - 系统的质量属性
+     - 能通过观察系统运行确定的质量属性
+     - 不能通过观察系统运行确定的质量属性
+   - 受系统结构影响的非商业属性
+   - 与软件体系结构本身相关联的一些质量属性，如概念完整性。

# 直接属性系统的运行属性

可在运行时观察确定的系统质量属性

+   - 性能
+   - 可靠性
+   - 可维护性
+   - 可扩展性
+   - 易用性

# 性能（Performance）

[定义]: 对外刺激（事件）做出响应所需要的时间或某个时间间隔内所处理的事件个数。

+   - 性能这一质量属性经常用在单位时间内所能完成的处理或计算量来表示为完成一个处理所需要消耗的时间表示。
+   - 由于通信所用的时间通常大于计算所用的时间，因此系统性能是通过系统中各个组件间进行通信或交互的数据量的函数——虽然还是软件体系结构问题。

# 安全性（Security）

[定义]:是衡量系统在合法用户正常提供服务的情况下，阻止企图非授权使用和拒绝服务攻击的能力。

+   包括：
+   - 指纹服务
+   - IP地址欺骗
+   软件体系结构策略：
+   - 认证系统
+   - 网络系统
+   - 防火墙
+   - 可信内核

# 可用性（Availability）

[定义]: 系统正常运行的时间比例。

+   - 可靠性——是否能保证系统正常运行的能力。通过
+   - 构件技术：
+     - 安全冗余
+     - 备份等

# 功能性

[定义]:系统能够完成所期望的工作的能力。
