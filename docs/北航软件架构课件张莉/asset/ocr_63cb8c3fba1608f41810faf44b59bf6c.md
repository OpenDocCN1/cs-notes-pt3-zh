# MOF的演化

+   - 1997年，OMG制定了MOF1.1规范
+   - 自1997年开始，OMG对MOF1.1进行过较小的修订，2002年4月MOF1.4正式被采用
+   - 2006年发布MOF2.0正式版。  
+     - 内容有了很大的变化。
+     - 受UML2.0的影响，与UML2.0共享核心包
+     - 优点：
+       - 简化元建模规则，统一建模概念（UML和MOF）
+       - 更多的工具支持，基本上支持UML的工具都支持MOF建模
