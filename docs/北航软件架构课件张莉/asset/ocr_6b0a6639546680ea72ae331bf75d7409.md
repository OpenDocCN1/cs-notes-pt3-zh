# 单元操作 (1)

+   - **分离**
+     - 性能、易用性、任务分配、可容错性、可移植性
+     - 统一分离
+       - 可以编译成独立的且有手动管理的功能
+       - 部分—整体
+       - 是一个二
+     - 复制
+       - 增强可靠性，提高性能
+       - 运行时间复制
+       - 跨节点复制

# 单元操作 (2)

+   - **抽象——创建一个虚拟机的操作**
+     - 简化创建和维护工作
+     - 虚拟机：模拟功能片断
+     - 一分层系统
+     - 公共接口
+   
+   - **分离和抽象**

# 单元操作 (3)

+   - **压缩**
+     - 一种分离相反
+     - 主要目的：
+       - 提高系统性能
+       - 在分层不能提供所需的服务时避免层次划分
+       - 加快系统的开发
+     - 常用技术：
+       - 宏
+       - 内嵌过程

# 单元操作 (4)

+   - **资源共享**
+     - 创建时一般要付出较高的代价
+     - 增强系统的可靠性、可移植性和可更改性
+     - 例子
+       - 数据库
+       - 黑板
+       - 集成软件工程工具环境
+       - 服务器
