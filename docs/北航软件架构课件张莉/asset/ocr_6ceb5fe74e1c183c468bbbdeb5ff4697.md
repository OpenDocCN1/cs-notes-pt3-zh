# IEEE 1471-2000

# 4个核心原则

+   - 每个系统都有自己的体系结构，每个都和其他的不同
+   - 软件体系结构和软件体系结构描述不同
+     - 软件体系结构描述是一组对体系结构进行编档的产品
+   - 无论是在研究中还是在实际应用中，软件体系结构、软件体系结构描述和开发过程是分离的。
+     - 可以独立研究和应用
+   - 在建立体系结构模型时预留下一定的自由空间，以便允许对具体的体系结构进行定制。
+     - 标准只给出了应该考虑什么，没有强制性要求。
