# 使用结构 - USES STRUCTURE

区分：

Use、 interaction、 call relation.

| 目标 | 如何实现 |
|---|---|
| 增量式逐步实现和测试系统的各个功能 | 为程序员创建“被允许使用”结构，限制每个程序员所能使用的过程 |
| 提高可移植性 | 以层次结构描述使用结构 |
| 生成规模合理的使用关系指南 | 在适当的情况下，将使用关系定义为模块间的关系 |
