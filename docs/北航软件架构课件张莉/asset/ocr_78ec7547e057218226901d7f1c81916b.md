# 下面讨论6个最常见的系统质量属性；

+   - 目的：
+     — 确定质量属性描述所使用的概念；
+     — 提供一个为该属性生成一般场景的方法

# 1、可⽤性（Availability）

+   - 可用性与系统故障及其相关后果有关。
+   - 当系统不能就其所承诺的服务时，或出现了系统故障。
+   - 系统的⽤户（⼈或其它系统）可以感知到此失效情况。

# 可用性

+   - 可用性所涉及的方面：
+     - 如何检测系统故障，
+     - 系统故障产生的原因，
+     - 此故障将发生什么样的问题，
+     - 为保证系统尽可能长时间正常运行，
+     - 什么时机可以安全地出现故障，
+     - 如何防止或缓解故障发生，
+     - 发生故障时如何进行通知等
+   - 系统出现故障后，一个重要概念
+     - 恢复所需的时间：从出现故障到用户看不到故障的时间。

# 可用性

+   - 系统的可用性：系统正常运行的时间比例。
+     例如：
+     “对于生产系统”
+     可用性标准：至少99.9%的可用性，0.1%的停机率。
+   - 区分：故障和错误
+   - 故障和错误的区别为允许自动恢复系统提供了可能。
+   - 注意：预先定的停止和时间不是故障。
