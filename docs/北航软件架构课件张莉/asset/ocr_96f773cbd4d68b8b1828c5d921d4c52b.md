# 模块结构

| 目标 | 如何实现 |
|---|---|
| 易于使用 | 信息隐藏 |
| 理解未来可能的改动 | 正式的评审过程，以吸取相关领域专家的经验 |
| 为各开发小组分配任务，使各小组之间的交流最少 | 按层次结构组织各模块，每个开发小组负责开发一个二级模块及其所有子模块。 |
