# 软件体系结构技术

+   - 主要讨论：设计师使用构造模式、体系结构模式、体系结构风格和设计时的“战术”。
+   - 概念：
+     - 战术：是影响质量属性的应对控制的设计决策；
+     - 一或多个集合，称为“体系结构策略”。
+   - 战术与体系结构模式：
+     - 设计师通常会选择一个精心设计的模式或模式集合，来实现一个模式；
+     - 因此，一个模式实现了多个战术，不管是否是所声明的。
+   - 战术与体系结构风格：
+     - 战术是设计的基本“构建块”。
