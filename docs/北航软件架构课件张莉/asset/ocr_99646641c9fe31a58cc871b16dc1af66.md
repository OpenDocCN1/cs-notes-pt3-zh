# OMG及其目标

+   - OMG – 对象管理组织，是一个独立于各厂商的非盈利性组织，全世界最大的软件联盟。
+     *The World's Best Standardization Process*
+   - OMG的目标是通过提供开放的、厂商独立的交互规范来帮助计算机用户解决集成和协同工作问题。
+     - Integration
+     - Interoperability
