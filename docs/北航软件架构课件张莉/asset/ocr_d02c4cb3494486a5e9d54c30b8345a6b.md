# 状态机图

+   ◆ 一个对象往往存在多个状态，比如电梯、ATM、飞机等等。
+   ◆ 状态机图显示了一个状态机，它强调从状态到状态的控制流。
+   ◆ 状态机在事件出现或动作产生时可能会发生转移。

# 状态机图

+   ◆ 状态机图通常包括：
+     ➢ 简单状态和组合状态
+     ➢ 转移、事件和动作。
+   ◆ 状态机图的价值在于：
+     ➢ 对任何可能发生于对象上的事件都指定一种应对行为。
+     ➢ 指出对象在某种状态下，对什么事件会有响应以及对什么事件没有响应。
+     ➢ 发现或确定定义对象状态所需的数据以及受状态改变影响的属性。
+     ➢ 有助于发现行为对系统内部的影响，而这些影响用基于交互的图是观察不到的。
