# 活动图

+   - 建造一座房子：
+     - 选择地址→委托建筑师设计→开发商开发→付款→拥有房子。
+   - 实际的工程是由多种活动及它们之间的协作组成的。
+   - 如何最好的模拟系统动态方面的工作流或操作？—— 活动图

# 活动图

+   - 活动图一般包括：
+     - 动作
+     - 活动节点
+     - 流
+     - 对象值
+   - 活动图的价值在于：
+     - 表述了实现系统行为所需要的逻辑。
+     - 可以描述设计所需的任何层次上的逻辑，从系统的工作流到单独的方法实现都可以。
+     - 非常简单，易于掌握。
+     - 用户对活动图相对而言比较熟悉。
