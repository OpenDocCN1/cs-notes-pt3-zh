# UML2.0

+   - OCL能用于若干不同目的：
+     - 作为一种查询语言
+     - 在类别模型中，规定对类别和类型的不变式
+     - 规定衍型的类型不变式
+     - 描述对操作和方法的前条件与后条件
+     - 描述守卫条件
+     - 为消息和动作规定目标（集）
+     - 规定对操作的约束
+     - 规定对属性的变化规则
+     - 用于UML模型中的任何表达式

+   - UML元模型没有定义一个标准方法来表现图的定义。
+   - 如果UML模型存储在一个UML工具中又被另一个不同的UML工具（或者甚至是同一个工具）用XML[UML]（XML Metadata Interchange）载入，那么所有的图信息就会丢失。
+   - 建议用一个附加的面向图形信息的包来扩展UML元模型解决，同时完全保留当前UML模型的完整性。
