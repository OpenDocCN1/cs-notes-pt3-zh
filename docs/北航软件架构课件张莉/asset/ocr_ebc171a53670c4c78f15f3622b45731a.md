# SAS Profile中主要建模概念

+   - <<SASComponent>>
+   主要侧重对构件功能性的描述，使设计人员可以不在考虑接口和行为为构件运行引入考虑的情况下了解构件在系统中的主要作用和职责
+   - <<关系>>
+   侧重于描述表达构件之间控制和数据上的相互联系，而不指示构件之间交互机制的具体细节
+   - <<协作>>
+   引入UML交互建模机制
+   分析验证控制和数据在构件之间的传递流程是否合理
+   不刻画控制和数据传递的具体细节
