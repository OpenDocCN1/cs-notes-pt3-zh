# 构件视图

构件视图主要说明系统开发完成后将得到哪些软件制品，即最终系统将生成哪些Exe、dll或其它，并在必要时表明其间的依赖关系。在系统开发之前构件视图的主要作用是对系统最终将开发的软件制品进行的规划，作为软件打包的指导策略。在系统开发完成后，应根据实际情况进行修改，以反映实际的打包结果，为系统产品的配置管理提供依据。构件视图通过UML的构件图来描述，面向系统配置管理人员
