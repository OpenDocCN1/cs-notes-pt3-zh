# Structural Patterns

+   - 结构性模式关注于如何将类和对象组合成更大的结构。结构类模式使用继承来组合接口或实现。
+     - Adapter
+     - Bridge
+     - Composite
+     - Decorator
+     - Facade
+     - Flyweight
+     - Proxy

# Adaptor

+   - 目的：
+     - 将类接口转化成用户所希望的接口。Adapter使原本由于不兼容接口而无法使用的类一同工作。
+   - 问题提出
