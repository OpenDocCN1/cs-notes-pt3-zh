# 描述分析机制特性

| 类 | 分析机制 | 特征 | 特征值 |
|---|---|---|---|
| 申请类 | 持久性 | 粒度 | 单个申请数据约1到5KB |
| 申请类 | 持久性 | 容量 | 每天约1000个申请，高峰时约5000个 |
| 申请类 | 持久性 | 访问频率 | 读取：每天5000次，写入：每天1000次，更新：每天1000次，删除：每天1000次 |
| 申请类 | 持久性 | 访问机制 | 主要按申请编号查询，也可能按申请日期、申请人、旅游团编号等信息进行查询 |
| 申请类 | 持久性 | 存储时间 | 永久保存，不删除，已完成的申请也需要保留历史信息 |
