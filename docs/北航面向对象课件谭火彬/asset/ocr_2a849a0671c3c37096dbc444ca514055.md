# 创建型模式

+   - ☑ 1 工厂方法 factory method
+     - 定义一个用于创建对象的接口，让子类决定实例化哪一个类
+   - ☑ 2 抽象工厂 abstract factory
+     - 提供一个接口，不必指定具体类即可创建一族相关的或相依赖的对象
+   - ☑ 3 生成器 builder
+     - 将一个复杂对象的构造与它的表示分离，从而同一构造过程可以创建不同的表示
+   - ☑ 4 原型 prototype
+     - 利用一个原型实例指定创建对象的类别，从而创建该原型的新的对象副本
+   - ☑ 5 单例 singleton
+     - 保证一个类只有一个实例，并提供访问它的一个全局访问点
