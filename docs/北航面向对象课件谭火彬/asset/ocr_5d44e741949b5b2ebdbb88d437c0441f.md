# 根据类图试写Button代码

```
public class Button {
    private Dialer myDialer;
    public Button(Dialer dialer)
    {
        myDialer = dialer;
    }
    public buttonPressed(String token)
        throws NumberFormatException
    {
        int digit = Integer.parseInt(token);
        dialer.digit(digit);
    }
}
```

Button与Dialer之间出现耦合，从而破坏了Button的可复用性

我们考虑增加一个间接层来解决？
