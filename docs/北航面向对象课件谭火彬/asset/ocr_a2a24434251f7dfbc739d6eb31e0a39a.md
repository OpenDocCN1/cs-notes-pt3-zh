# 新的需求......

需要手去开关冰箱......?

+   ✓ 为冰箱实现Excutable接口
+   ✓ 不需要修改任何原有的设计和代码

```
public class Refrigerator implements Excutable {
    private boolean _isOpen = false;
    public boolean isOpen() {
        return _isOpen;
    }
    public void open() {
        _isOpen = true;
    }
    public void close() {
        _isOpen = false;
    }
}
```
