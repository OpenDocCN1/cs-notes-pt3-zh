# # UML2.4 14种图-结构模型

+   ☑ **类模型**
+     - **类图**：类、接口以及它们之间的关系
+     - **包图**：包以及它们之间的依赖关系
+     - **对象图**：对象以及它们之间的链接关系

+   ☑ **构件模型**
+     - **构件图**：构件以及之间的依赖关系

+   ☑ **组合结构模型**
+     - **组合结构图**：系统某一部分（组合结构）的内部结构

+   ☑ **部署模型**
+     - **部署图**：构件在节点上的部署情况

+   ☑ **外廓模型**
+     - **外廓图**：外廓以及所包含构造型、标记值、约束和基类等
