# 行为型模式

+   ☑ 16 命令 command
+     ◆ 将一个请求封装为对象，从而以不同请求将客户程序参数化；
+     可以将请求排队或是记录请求日志，并支持undo操作

+   ☑ 17 迭代器 iterator
+     ◆ 提供一种方法顺序访问一个聚合对象中各个元素，而又不暴露该对象的内部表示

+   ☑ 18 中介者 mediator
+     ◆ 用一个中介者来封装一系列的对象交互。使各对象不需要显式的相互引用，从而使耦合松散，而且可以独立改变它们的交互

+   ☑ 19 备忘录 memento
+     ◆ 在不破坏封装性的前提下，获取对象的内部状态并将其外部化，从而对象可以在以后恢复到原状态
