# 俗语和术语间的对应

| 俗语 | 术语 | 例子 |
|---|---|---|
| 出了什么事？ | 用例 | 我的一个朋友结了婚。 |
| 具体事物 | 对象 | 我的一个朋友,他未婚妻... |
| 事物类型 | 类 | 小伙,姑娘,玫瑰,月老... |
| 属性 | 属性 | 年龄,体格,性情... |
| 能力 | 操作 | 牵线,追求,结婚... |
| 位置 | 部署 | 软件园,情侣路... |
| 整-部关系 | 聚合关系 | 恋人-小伙,恋人-姑娘 |
| 抽-具关系 | 继承关系 | 人-小伙,人-姑娘 |
| 协作关系 | 关联关系 | 小伙-姑娘,小伙-玫瑰 |
| 成事过程 | 用例实现 | 相识,相恋,缔婚... |
