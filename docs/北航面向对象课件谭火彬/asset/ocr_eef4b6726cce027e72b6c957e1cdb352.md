# 运用Command模式的Button

```
```java
interface Command { public void do(int signal); }

public class Button {
    Command cmd = null; int digit = 0;
    public Button(Command cmd) { this.cmd = cmd; }
    public Command setCommand(Command cmd) {
        Command old = this.cmd;
        this.cmd = cmd;
        return old;
    }
    public final void pressed() {
        cmd.do(digit);
    }
}
