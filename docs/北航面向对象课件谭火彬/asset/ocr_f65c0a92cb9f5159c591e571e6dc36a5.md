# UML是基于MOF四层模型

+   - 元元模型层(M3)
+     - 包含了定义建模语言所需的元素(UML基础结构)
+     - MetaClass, MetaAttribute, MetaOperation

+   - 元模型层(M2)
+     - 定义了一种建模语言的结构和语法(UML上层结构)
+     - 如UML: Class, Attribute, Operation

+   - 模型层(M1)
+     - 定义了一个具体的系统的模型
+     - 如采用UML表示的某系统模型

+   - 运行时(M0)
+     - 包含了一个模型的对象在运行时的状态等
+     - 如某系统运行时的对象和数据模型
