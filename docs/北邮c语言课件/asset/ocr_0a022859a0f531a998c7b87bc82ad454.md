# Switch语句的基本形式：

```
```c
switch(表达式)
{
    case 常量1：语句块1；
    case 常量2：语句块2；
    ……………………
    case 常量n：语句块n；
    default：语句块n+1；
}
```
```

其中每个语句块都可以是0到多条语句，可以有选择的包含或不包含结束语句break；注意：case后面的值不能为变量。

# 执行过程：

> 先计算表达式的值，判断与case后的哪个常量值相等，若与常量的值相等，则从语句块i开始执行，直到遇到第一条break语句结束，或执行完语句块n+1结束。若与任何一个常量的值都不相等，直接执行语句块n+1。
