# 例：

```
#include<stdio.h>
main()
{ int a=65,i= -2;char c='a';
float b=1.34576;double d=4.65;
unsigned j=65535;
printf("\n%s","hello");
printf("\n%d,%c,%d,%u,%u,%d",a,a,i,i,j,j);
printf("\n%.3f,%.4lf",b,d);
printf("\n%d,%d",a+i,i++);
}
```

输出：
hello
65,A,-2,65534 ,65535, -1
1.346,4.6500
64,-2

注意
printf语句输出参数表中的表达式是先从右到左运算，再从左到右输出。
