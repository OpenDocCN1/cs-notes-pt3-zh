# 2.字符输入函数

# int getchar(void)

从输入设备(一般为键盘)上输入一个字符。它每被调用一次，就从标准输入设备上取一个字符，返回值是该字符的ASCII编码值，可以赋给字符变量或整型变量。

注意 执行getchar()时输入字符以回车结束，同时回车字符也可以做为输入的字符。

```
例: #include<stdio.h>
main()
{ int i,j; char c;
 i=getchar(); putchar(i);
 j=getchar(); putchar(j);
 c=getchar(); putchar(c);
}
```
