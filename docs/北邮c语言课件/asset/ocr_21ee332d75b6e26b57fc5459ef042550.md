若将程序改为：

```
#include <stdio.h>
int a=2,b=4;        /*a, b为全局变量*/
void f1()
{ int t1,t2;
 t1 = a * 2;
 t2 = b * 3;
 b = 100;
 printf ( "t1=%d, t2=%d, b=%d\n" , t1, t2,b);
}
main()
{ int b=4;                /* 此b是局部变量，赋值 */
 f1();                   /* 调用函数f1() */
 printf ( "a=%d,b=%d" , a, b);
}
```

程序输出结果为：
t1=4, t2=12, b=100
a=2, b=4

结论:全局变量与局部变量同名时,局部变量起作用，全局变量被屏蔽（不影响）,应小心使用
