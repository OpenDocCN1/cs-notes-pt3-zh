# 程序：

```
```c
#include<stdio.h>

main()
{
    long a,i,t=0;

    scanf("%ld",&a);

    while(a>0)
    {
        i=a%10;
        t=t*10+i;
        a=a/10;
    }

    printf("\n%ld",t);
}
```
```

> 在这里由于a的值可能很大所以用到long型定义变量a,如果希望取到的值更大，可以用unsigned long型。
> 
> 问：如果a用double型，并把i=a%10改为i=(long)a%10;把a=a/10改为a=(long)a/10可以吗？
> 
> 答：不可以！！
