# 1. 省略表达式1：

```
#include<stdio.h>
main()
{
    int i=1,s=0;
    for(;i<=99;i++)
        s=s+i;
    printf("s=%d",s);
}
```

# 2. 省略表达式3：

```
#include<stdio.h>
main()
{
    int i,s=0;
    for(i=1;i<=99;)
    {s=s+i;i++;}
    printf("s=%d",s);
}
```

# 3. 同时省略表达式1、3

```
#include<stdio.h>
main()
{
    int i=1,s=0;
    for(;i<=99;)
    {s=s+i;i++;}
    printf("s=%d",s);
```

> 注意：表达式省略，分号不省略。

> 表达式2也可以省略
> 但在循环体中要借助
> break语句来实现循环
> 环的结束，我们将在
> 后面介绍。
