# 结构体类型声明的说明

+   - 说明
+     - 结构体类型与结构体变量概念不同
+       - 类型:不分配内存； 变量:分配内存
+       - 类型:不能赋值、存取、运算； 变量:可以

同变量名可相同，不会混淆

作用域与生存期

例 struct date
{
  int month;
  int day;
}
