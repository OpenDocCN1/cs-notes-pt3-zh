# 对数组初始化的几种方法：

①在定义数组时，对全部数组元素赋予初值。

```
int a[5]={0, 1, 2, 3, 4};
```

②在定义数组时，对部分数组元素赋予初值。

```
int a[5]={1, 2}; 等价 a[0]=1, a[1]=2; 其余赋0
```

③对全部数组元素赋初值时，可省数组长度，系统自动确定。

```
a[5]={0,1,2,3,4}
```

若不对auto数组进行初始化，则其初值是不可知的。

若一个static或外部数组未进行初始化，则对数值型数组元素，初值为0，而对字符型数组元素，初值为空字符 '\0'。

| a[0] | 0 |
| a[1] | 1 |
| a[2] | 2 |
| a[3] | 3 |
| a[4] | 4 |
