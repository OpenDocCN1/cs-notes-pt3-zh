# 例7.2 数组初始化与未初始化比较

```
#include <stdio.h>
main()
{int i,a[5]={3,4,5},b[5];
    printf("\narray a is:")
    for(i=0;i<5;i++) printf("%6d",a[i]);
    printf("\narray b is:")
    for(i=0;i<5;i++) printf("%6d",b[i]);
}
```

运行结果：

array a is:3    4    5    0    0

array b is:-32  1398  40  1170  454
