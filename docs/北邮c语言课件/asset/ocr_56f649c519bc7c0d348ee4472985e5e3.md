# 例2-1：

```
```c
main ()
{
    int x, y, z, w;    /*定义x，y，z，w为整型变量*/
    unsigned int k;    /*定义k为无符号整型变量*/
    x=10; y=-20; k=30;
    z=x+k; w=y+k;
    printf（“x+k=%d, y+k=%d\n”，z，w）；
}
```
```

程序运行结果为：

```
x+k=40, y+k=10
```

变量根据作用域的不同可分为局部变量和全局变量，根据存储方式的不同可分为静态存储变量和动态存储变量，这些我们将在第六章中详细介绍。
