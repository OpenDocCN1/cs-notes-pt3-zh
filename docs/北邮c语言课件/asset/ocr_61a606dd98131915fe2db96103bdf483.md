# 看一个简单的函数调用例子：

输出右图所示图形，其中，第一行为一个*，第二行为两个*，第n行为n个*。

算法：编写一个在一行输出x个*的函数。在主函数中调用此函数实现右边图形的输出。

```
void f( long x )
{ long I;
    for(I=1;I<=x;I++)
        printf("* ");
    printf("\n");
}
main()
{ long n,I;
    void f(long x);
    scanf("%ld",&n);
    for(I=1;I<=n;I++)
        f(I);
}
```

![](bbox=[0.708, 0.036, 0.969, 0.319])

> 在左边的程序中，f是一个自定义函数，实现的功能是输出x个*号，其中x的值由该函数被调用时赋予的值来确定。
> 
> main函数中，用I从1到n循环，每次调用f(I)，即把I的值赋给函数中的x，实现输出I个*的功能。
