# 例7.14 求数组元素的最大值与最小值，并把它们分别放在第一、第二个元素中

```
#include <stdio.h>
maxmin(int b[][4])
{int I,j,max,min;
max=min=b[0][0];
for(I=0;I<3;I++)
for(j=0;j<4;j++)
if (b[I][j]>max)max=b[I][j];
else if(b[I][j]<min)
min=b[I][j];
b[0][0]=max;b[0][1]=min;
return(max);
}
```

```
main()
{int a[3][4]={1,0,-32,21,10,4,
4,4,345,2,12,0};
printf("max=%d\n",maxmin(a));
printf("max=%d",a[0][0]);
printf("min=%d",a[0][1]);
}
```
