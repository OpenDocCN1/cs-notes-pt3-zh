为了操作方便，应记住TC中的一些常用功能键：

+   - F1：帮助。
+   - F2：将当前文件存盘。
+   - F3：装载原有文件或给新文件命名。
+   - F4：程序运行到光标所在行。
+   - F5：放大或缩小活动窗口切换。
+   - F6：开或关活动窗口切换。
+   - F7：单步运行程序，跟踪进入函数内部运行。
+   - F8：单步运行程序，不跟踪进入函数内部。
+   - F9：生成可执行文件。
+   - F10：菜单与活动窗口相互切换。
+   - CTRL+F9: 当前编辑环境下，进行编译、连接且运行程序。
+   - ALT+F5: 将窗口切换到DOS环境，用来查看程序运行结果。
