# 3. 字符串比较函数strcmp()

调用格式： strcmp(str1, str2);

功能： 若str1=str2，则函数返回值为0；
若str1>str2，则函数返回值为正整数；
若str1<str2，则函数值返回为负整数。

# 比较规则：

+   - 两个字符串自左至右逐个字符比较，直到出现不同字符或遇到 ‘\0’ 为止。

+   - 如字符全部相同，则两个字符串相等；
+     若出现不同字符，则遇到的第一对不同字符的ASCII大者为大。

比较两字符串是否相等一般用以下形式：

```
if (strcmp(str1, str2)==0) {...};
```

而 if(str1==str2) {...}; 是错误的。
