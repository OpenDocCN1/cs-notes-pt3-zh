# 17.0<a<b,a*b=2698,且a+b 最小，求b.

分析：用变量a从1到sqrt（2698）-1循环。变量s初值为6000。若2698%a==0,则b=2698/a,若s>a+b,则s=a+b,并保存b的值在变量t.

```
#include<math.h>
main()
{
    int a,b,s=6000,t;
    for(a=1;a<sqrt(2698);a++)
    {
        if(2698%a==0)
        {
            b=2698/a;
            if(s>(a+b))
            {
                s=a+b;
                t=b;
            }
        }
    }
    printf("\n%d",t);
}
```
