编程解决这样一个问题：

从键盘输入一百个学生的成绩，求总成绩。

从前面所学，有两种解决方法。

+   1. 设一百个变量，分别输入学生的成绩，然后求和。

这种方法浪费内存空间，显然不实际。

+   2. 设一个变量，每次输入一个学生成绩，累加后再输入下一个学生成绩，如下：

```
scanf("%f",&a);

s=s+a;
```

```
scanf("%f",&a);

s=s+a;
```

............

这样重复一百次，然后

输出s的值。

这样写显然非常麻烦。我们注意到程序中的

scanf("%f",&a);

s=s+a;

两句话是一直重复的，如果能用一种语句，使这两句话能自动的重复执行一百次，就可以简化了书写的麻烦，这就是循环语句。
