# 11. Sn=1-1/3+1/5-1/7+…+1/(2n-1) 求s(100)（保留4位小数）

分析：用变量求和，s初值为0。用变量n从1到100循环，如果n是奇数（n%2!=0），s=s+1/(2*n-1)，否则s=s-1/(2*n-1)。

```
```c
#include<stdio.h>

main()
{
    int n;
    float s=0;
    for(n=1;n<=100;n++)
        if(n%2!=0) s=s+1.0/(2*n-1)
        else s=s-1.0/(2*n-1);
    printf("\n%.4f",s);
}
