# 结构体概述（2）

+   • 定义结构体类型，描述下列数据
+   
+     (1) 学生情况：包含学生的学号、姓名、性别、年龄、C语言课程成绩：

```
struct student
{int no;                 /*学号*/
 char name[10];          /*姓名*/
 char sex;               /*性别*/
 int age;                /*年龄*/
 float score;            /*C成绩*/
};
```

注：‘;’不能省

> 结构体类型定义描述结构的组织形式，不分配内存
