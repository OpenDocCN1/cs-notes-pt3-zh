# 9.求s=1+1/3+(1*2)/(3*5)+...+(1*2*...*n)/(3*5*...*(2*n+1))当n=40时的值。（结果保留10位小数）

分析：用变量s求和，s初值为1。用变量a用来求项的分子，变量b求项的分母，a、b初值均为1。用变量n从1到40循环，a=a*n,b=b*(2*n+1),s=s+a/b。

```
main()
{ float s=1;
int n;
long int a=1,b=1;
for(n=1;n<=40;n++)
{ a=a*n;
b=b*(2*n+1);
s=s+(float)a/b;
}
printf("\ns=%.10f",s);
}
```
