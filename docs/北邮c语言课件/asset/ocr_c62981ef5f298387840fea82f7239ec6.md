10. 数列 1,1,2,3,5,8……有 f(n)=f(n-1)+f(n-2), f(1)=1, f(2)=1, 求 f(40)

分析：用变量 f1、f2、f 作为数列相邻的三项，初值 f1=1,f2=1。用变量 n 从3到40循环，f=f1+f2,f1=f2,f2=f。

```
```c
#include<stdio.h>

main()
{
    long int f1=1,f2=1,f,n;
    for( n=3;n<=40;n++)
    {
        f=f1+f2;
        f1=f2;
        f2=f;
    }
    printf("\nf=%ld",f);
}
```
```
