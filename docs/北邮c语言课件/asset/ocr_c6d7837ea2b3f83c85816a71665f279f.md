例如： fseek(fp,20L,0);

把文件指针从文件开头移到第20个字节处。

```
fseek(fp,-20L,2);
```

把文件指针从文件尾向前移动 20 个字节。

# ftell()函数：

调用形式为： ftell(文件类型指针)

函数的作用： 得到文件指针离开文件起点的字节数。若调用不成功，返回-1L，表示出错。

例如： long i;

```
i=ftell(fp); if(i==-1L) printf("error\n");
```

# rewind()函数：

调用形式为： rewind(文件类型指针)

函数的作用： 用于把文件指针移到文件的开头。移动成功时，返回值为0，否则返回一个非零值。
