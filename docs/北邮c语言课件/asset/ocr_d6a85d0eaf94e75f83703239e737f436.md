# 7.1.2 数组元素的引用

定义了数组以后，就可使用它了。\n但不能利用数组名来整体引用一个数组，只能单个的使用数组元素

数组元素的描述：由数组名加方括号中的下标组成，即：

**数组名[下标]**

下标：数组元素在数组中的顺序号，使用整型表达式。\n取值范围：从0到元素个数-1。C语言不作下标越界检查。

![](bbox=[0.431, 0.415, 0.851, 0.509])

若有定义：`int a[5];`\n则数组a的元素分别为：a[0]、a[1]、a[2]、a[3]、a[4]；但a[5]不是。\n每个元素都可作为一个整型变量来使用。如：

```
a[0]=5;  a[3]=a[1]+4;  a['D'-'B']=3;  scanf("%d",&a[4]);
```
