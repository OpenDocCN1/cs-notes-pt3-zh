# 四、标准文件的定位函数

文件中有一个位置指针，指向当前读写的位 置。我们可以使用有关函数来改变其位置，以完成文件的随机读写。

# fseek()函数：

调用形式为： fseek（文件类型指针，位移量，起始点）

说明： 位移量一般是long型数据；起始点用0、1或2表示；

| 起始点位置及其代表符号对应表 |
| 起始点具体位置 | 符号代表 | 数字代表 |
| 文件的开头 | SEEK-SET | 0 |
| 文件指针现行位置 | SEEK-CUR | 1 |
| 文件尾 | SEEK-END | 2 |

函数的作用： 是使文件指针移动到所需的位置；若调用成功，返回值为0；否则返回一个非零值。
