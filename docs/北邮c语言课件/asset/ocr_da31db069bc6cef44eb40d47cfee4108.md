# 一. 宏定义

+   - 简单宏定义

# 1. 一般形式为：

```
#define 宏名 串 (宏体)
```

如： #define PI 3.14159

```
/*定义后,可以用PI来代替串3.14159*/
```

# 2. 宏定义的作用

在宏定义之后,该程序中宏名就代表了该字符串。

# 3. 说明

+   ① 可以用 #undef 命令终止宏定义的作用域。例如： #undef PI

+   ② 宏定义的嵌套使用

```
# define R 3.0
# define PI 3.1415926
# define L 2*PI*R      /*宏体是表达式*/
# define S PI*R*R
```
