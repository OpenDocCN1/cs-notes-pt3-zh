12. 求1000以内最大的20个素数之和。
分析：用变量s求和，s初值为0。用变量I统计以求得素数的个数，I初值为0。用变量a从1000到1循环，如果a是素数，则s=s+a，I++。当值等于20时，跳出循环。

```
main()
{
    int a,s=0,I=0,j;
    for(a=1000;a>=1;a--)
    {
        for(j=2;j<a;j++)
            if(a%j==0) break;
        if(j==a)
        {
            s=s+a; I++;
            if(I==20) break;
        }
    }
    printf("\n%d",s);
}
```
