# 结构体类型变量的定义(1)

+   • 先定义结构体类型，再定义结构体变量

一般形式：

```
struct 结构体名
{
    类型标识符 成员名;
```

```
例 struct student
{
    int num;
    char name
    char sex;
    int age;
    float score
    char addr[
};
struct student
```

```
例 #define STUDENT struct student
STUDENT
{
    int num;
    char name[20];
    char sex;
    int age;
    float score;
    char addr[30];
};
STUDENT stu1,stu2;
```
