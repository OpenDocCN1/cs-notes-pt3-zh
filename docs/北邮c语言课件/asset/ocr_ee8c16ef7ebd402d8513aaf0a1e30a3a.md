13.[200,1000]的双胞胎数的对数。双胞胎数：两素数差为2称为双胞胎数。\n分析：用变量n统计以求得双胞胎数的对数，n初值为0。用变量a从200到998循环，如果a是素数，则令变量b=a+2；如果b也是素数，则n值增1。素数球法同前，用变量I循环

```
main()\n{\n    int a,b,n=0,I;\n    for(a=200;a<=998;a++)\n    {\n        for(I=2;I<a;I++)\n            if(a%I==0) break;\n        if(a==I)\n        {\n            b=a+2;\n            for(I=2;I<b;I++)\n                if(b%I==0) break;\n            if(b==I) n++;\n        }\n    }\n    printf("\\n%d",n);\n}
```
