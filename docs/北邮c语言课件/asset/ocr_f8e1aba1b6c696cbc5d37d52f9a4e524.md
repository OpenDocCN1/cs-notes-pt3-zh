# 7.2.3　二维护组的存储结构

设有定义 `int a[2][3];`　`float b[3][2];`

系统为数组在内存中分配一片连续的内存空间，将二维数组元素按行的顺序存放在所分配的内存区域。数组a与b的各元素的存储顺序如右图所示

| 元素 |
|---|
| a[0][0] |
| a[0][1] |
| a[0][2] |
| a[1][0] |
| a[1][1] |
| a[1][2] |

| 第0行 | 第1行 | 第2行 |
|---|---|---|
| B[0][0] | b[1][0] | b[2][0] |
| b[0][1] | b[1][1] | b[2][1] |

元素 `a[i][j]` 的地址：

`a + (i × n + j) × 元素字节数`
