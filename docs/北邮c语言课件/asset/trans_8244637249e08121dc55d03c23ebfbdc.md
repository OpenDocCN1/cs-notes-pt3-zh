

## 结构体概述（2）

- • 定义结构体类型，描述下列数据

  (1) 学生情况：包含学生的学号、姓名、性别、年龄、C语言课程成绩：

```
struct student
{int no;                 /*学号*/
 char name[10];          /*姓名*/
 char sex;               /*性别*/
 int age;                /*年龄*/
 float score;            /*C成绩*/
};
```

注：‘;’不能省

> 结构体类型定义描述结构的组织形式，不分配内存

如考虑10门课程成绩，加上总成绩与平均成绩，可作如下定义：

```
struct student
{int no;                 /*学号*/
char name [10] ;        /*姓名*/
char sex;               /*性别*/
int age;                /*年龄*/
float score [10] ;      /*10门课程成绩*/
float tcj, acj;         /*总成绩，平均成绩*/
};
```

- - 定义结构体类型，描述下列数据
  - (2)个人数据：包含姓名、性别、年龄、身高、体重、住址：

```
struct person
{char name [20] ;  /*姓名*/
char sex;          /*性别*/
int age;           /*年龄*/
float height;      /*身高*/
float weight;      /*体重*/
char addr [50] ;   /*住址*/
};
```

## 结构体类型声明的说明

- - 说明
  - 结构体类型与结构体变量概念不同
    - 类型:不分配内存； 变量:分配内存
    - 类型:不能赋值、存取、运算； 变量:可以

同变量名可相同，不会混淆

作用域与生存期

```
例 struct date
{
  int month;
  int day;
}
```

```

{
    类型标识符　成员名;
    类型标识符　成员名;
```
