# 运算符概览(5)

| 条件表达式 | `expr?expr:expr` |
|---|---|
| 前缀赋值 | `lvalue=expr` |
| 后缀赋值 | `lvalue*=expr` |
| 前置增量 | `++lvalue` |
| 后置增量 | `lvalue++` |
| 前置减量 | `--lvalue` |
| 后置减量 | `lvalue--` |
| 按位与赋值 | `lvalue&=expr` |
| 按位或赋值 | `lvalue|=expr` |
| 按位异或赋值 | `lvalue^=expr` |
| 左移赋值 | `lvalue<<=expr` |
| 右移赋值 | `lvalue>>=expr` |
| 逗号运算 | `expr,expr` |
| 抛出异常 | `throw expr` |
| 逗号（序列） | `expr,expr` |

# 运算符示例

```
a+b*c // a+(b*c)
*p++ //先取p所指向的数据的数值，然后p指针+1

一元运算符合赋值运算符是右结合的，其他运算符是左结合的
a=b=c // a=(b=c)
a=b+c // (a=b)+c

有不多的几条语法规则无法通过优先级和结合性来说明
a=b<c ? (d==e) : (f==g)
// a=((b<c)? (d==e) : (f==g))
```

# 6.2.1 结果

+   - 算术运算符的结果类型由一组称为“普通算术转换”的规则确定
+     - 例如：一元运算符有一个是浮点数，那么计算就将通过浮点数来进行；如果有一个long运算对象，那么运算结果用长整型来算，结果就是long，比int小的运算对象在运算作用之前将被转换到int
+   - 关系运算符，`==`、`<=`等产生布尔值
+   - `sizeof`的结果是一个无符号整型`size_t`，指针减的结果是一个有符号整型`ptrdiff_t`，这些类型在`<cstddef>`中定义
