# 9.4.1.1 程序终止

+   - 程序可以以多种方式终止
+   - 通过main()返回
+   - 通过调用exit(), 函数类型void exit(int)
+   - 通过调用abort()
+   - 通过抛出一不被捕获的异常
+   - 若程序通过exit()终止，所有已登记构造函数的静态对象和静态局部变量将被销毁(调用它们的析构函数及其调用对象的析构函数)；然而，如果程序使用abort()终止，那么析构函数就不会被调用
+   - 注意：析构函数里面调用exit()有可能导致无法递到

# 程序终止

+   - 调用exit(int)时，其参数将被作为程序的值返回给系统(一般用0表示程序成功结束)
+   - 一般情况下，最好通过抛出一异常的方式脱离一个环境，让异常处理器来决定该做什么
+   - 可以通过使用atexit函数让程序在终止之前执行一些代码
+   - exit(), abort(), atexit()在<cstdlib>里

# 9.5 忠告

+   - [1] 利用头文件去表示界面和源代码结构
+   - [2] 用#Include将头文件包含到实现有关功能的源文件里
+   - [3] 不要在不同编译单元里定义具有相同名字、意义类型但又不同的全局实体
+   - [4] 避免在头文件里定义非inline函数
+   - [5] 只在全局作用域和名字空间里使用#include
+   - [6] 只用#include包含完整的定义
+   - [7] 使用包含保护符

# 忠告

+   - [8] 用#include将C头文件包含到名字空间里，以避免全局名字
+   - [9] 将头文件做成自给自足的
+   - [10] 区分用户界面和实现界面
+   - [11] 区分一般用户界面和专家用户界面
+   - [12] 在有意向用于非C++程序组成部分的代码中，应避免需要运行时间初始化的非局部对象
