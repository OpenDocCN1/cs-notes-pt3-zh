# 15.2 多重继承

+   - 一个类可以有多个直接基类，采用多个直接基类的情况通常称为多重继承
+   - 假设Satellite从Task和Displayed多重继承，那么在实际应用中，就可以将一个Satellite传递给那些期望Task或者Displayed的函数
