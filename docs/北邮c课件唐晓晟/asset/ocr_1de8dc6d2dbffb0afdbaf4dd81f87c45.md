# 10.2.2 访问控制

通过struct Date声明，提供了 一组操作Date的函数，然而，它却没有清楚地说明这些函数就是直接依赖于Date表示的全部函数，而且也是仅有的能够直接访问Date类的对象的函数

这些限制可以通过用class替代struct而描述清楚

# 访问控制

结构public成员还各构成成分的两个部分，其中第一部分(在用符号{}分由组成或被限定。前一部分(由成员变量组成)形成了该类的对应的公共界面：struct也是class。不论此处的认识方式如何共同认识到各个成员界面

```
class Date { //成员变量声明
  int d, m, y;
  public:
    void init(Date& d, int, int, int);
    void Date::add_year(int n)
    {
      y += n;
    }
    void add_year(Date& d, int n);
    void add_month(Date& d, int n);
    void add_day(Date& d, int n);
};
```

# 访问控制

```
//非成员函数被禁止访问对象的成员
void timewrap(Date& d)
{
  d.y -= 200; // Error
}
```

这和预期的好结果。1 与声明的成员函数必然是由成员函数组成的 2 个普通的用于客户使用 一个类但必须要求变成成员函数定义 又 这样一个init函数的问题 1 有一个类被初始化的对象信息是有用的 2 数据的用途性和要求我们这么做

# 10.2.3 构造函数

采用init一类的函数提供对类对象的初始化，这么做既不优美又容易出错(比如说，忘记调用)

更好的途径是让程序员有能力去声明一个函数，其声明目的就是去完成对对象的初始化，此类函数称为构造函数

构造函数具有与类相同的名字
