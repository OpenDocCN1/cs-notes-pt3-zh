# 10.2.1 成员函数

考虑用struct实现日期

改进版本，将函数加入到struct中

在一个类中声明的成员函数做成员函数(struct也是一种类)

```
struct Date {
    int d,m,y;
};
void init_date(Date& d, int,int,int);
void add_year(Date& d,int n);
void add_month(Date& d,int n);
void add_day(Date& d,int n);
// 函数和数据之间没有任何联系
```

```
struct Date {
    void init_date(Date& d,int,int,int);
    void add_year(Date& d,int n);
    void add_month(Date& d,int n);
    void add_day(Date& d,int n);
};
// 这样做
```

# 成员函数

成员函数只能通过适当类型的特定变量，采用标准的结构成员访问语法形式调用

```
Date my_birthday;
void f() {
    today.init(16,10,1996);
    my_birthday.init(30,12,1950);
    Date tomorrow = today;
    tomorrow.add_day();
};
```

```
void Date::init(int dd,int mm,int yy) {
    d = dd; // 或直接用this->d
    m = mm;
    y = yy;
}
// d m y 是被函数调用期间的对象
// 每个对象成员
```

# 类定义

class X { ... }; 被称为一个类定义。因为它定义了一个新类型

由于历史的原因，一个类定义也常常被说成是一个类声明

就像其他不是定义的声明一样，类定义可以由于#include的使用而在不同的源文件里重复出现，这样的并不违反唯一定义规则
