# 5.2 数组

+   对于类型T, T[size]就是“具有size个类型元素的数组”类型，元素下标从0到size-1
+   数组元素的个数必须是一个常量表达式
+   多维数组就是表示为数组的数组

```
float v1[] = {v0, v1, v2}
char a[32]; // 32 个char的数组
// a[0] ... a[31]

int d2[10][20];
int bad[2,5]; // Error
```

```
void (int i)
{
  int v1[]; // Error
  vector<int> v2();
}
```

# 5.2.2 字符串字量

+   字符串字量是用双引号括起来的字符序列
+   一个字符串字量里包含的字符个数比它看起来多一个字符值是0，它总是由一个空字符\0结束，空字符值为0
+   例如: sizeof("test")=5. 但是strlen("test")=4
+   字符串字量的类型是常量字符指针const字符串的数组，所以“test”的类型是const char[5]。此为常数，而且只能静态分配
+   可以用字符串字量给一个char*赋值，若修改一个字符串，可以先将其复制到一个数组中去
