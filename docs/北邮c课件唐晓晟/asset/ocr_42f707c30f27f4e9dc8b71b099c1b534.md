# 5.7.1 类型等价

两个结构总是不一样的类型，即使它们有相同的成员。此外，结构类型与名字和基本类型不同，每个结构在程序里都是唯一的。

```
struct S1 { int a; };
struct S2 { int a; };

S1 x;
S2 y = x; // Error

int i = x; // Error
```

# 5.8 忠告

+   - [1] 避免非平凡的指针计算
+   - [2] 当心，不要超出数组的界限去写
+   - [3] 尽量使用00而不是NULL
+   - [4] 尽量使用vector代替array而不是数组
+   - [5] 尽量使用string而不是以0结尾的char数组
+   - [6] 尽量少用普通的函数参数
+   - [7] 避免void*，除了在某些极低级代码中
+   - [8] 避免在代码中使用非平凡的文字量(magic number)，相反，应该定义和使用符号常量
