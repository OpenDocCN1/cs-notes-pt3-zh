对于一个类构造器，这个类的所有对象的构造都通过类构造器进行。构造器可以完成对象的初始化工作，构造器可以完成对象的初始化工作，也可以完成对象的初始化工作。

```
class Date {
int d, m, y;
public:
Date(int, int);
Date(int,int,int); //构造日期的类表
Date(int);
Date();
}
```

# 构造函数

```
class Date {
int d, m, y;
public:
Date(int dd=0,
int mm=0, int yy=0);
//
};
Date::Date(int dd, int mm, int yy)
{
d = dd? dd : today.d;
m = mm? mm : today.m;
y = yy? yy : today.y;
}
```

也可以用带默认参数的函数来模拟重载函数

# 10.2.4 静态成员

+   - 为Date提供默认值的方式隐藏着一个重要问题：Date类现在依赖一个全局变量today
+   - 如果这是一个这样的变量，而只在Date类中使用，而用户会遇到很多意想不到的事情，而且维护工作也变得棘手
+   - 对此的解决办法是：创建一个static静态成员，可以以获得全局变量的方便，而又无需受到访问全局变量之累
+   - 对于所有对象，静态成员只有一个副本
+   - 使用一个静态成员，不必依赖任何对象

# 静态成员

```
class Date{
int d, m, y;
static Date default_date;
public:
Date(int dd=0,
int mm=0, int yy=0);
//
static void set_default(int,int,int);
};
```

```
void f()
{
Date::set_default(4,5,1945);
}
Date::Date(int dd, int mm, int yy)
{
d = dd? dd : default_date.d;
m = mm? mm : default_date.m;
y = yy? yy : default_date.y;
}//Date()相当于Date::default_date
```

```
void Date::set_default(int d,
int m, int y)
{
Date::default_date = Date(d,m,y);
}
```
