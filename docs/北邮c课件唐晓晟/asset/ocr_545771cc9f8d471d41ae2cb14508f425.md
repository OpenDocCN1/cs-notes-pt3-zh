char str[] = "this is a two

char str[] = "this is a two \n lines string";

可以, char alpha[] = "abcdefg hijklmn"
"opqrstuvwxyz";

# 5.3 到数组的指针

+   - 数组名字可以被用作它的开始元素的指针
+   - 注意：取得“开始元素之前的一个位置”没有任何意义，因为数组常常被分配在机器地址的边界上
+   - 数组名可以被隐式地转换或数组的开始元素的指针(这在C风格代码的函数调用中被广泛使用)，但是这将丢失数组的大小信息，vector和string没有此类问题

# 数组指针示例

```
int v[] = {1, 2, 3, 4};
int* p1 = v;
int* p2 = &v[0];
int* p3 = &v[4]
//最后一个元素的下一个位置

extern "C" int strlen(const char*); // string.h
void f()
{
    char v[] = "Annemarie";
    char* p = v; // 隐式地从char[]转换到char*
    strlen(p);
    strlen(v);   // 隐式地从char[]转换到char*
    v = p;       // Error: 不能赋值给数组值
}
```

# 5.3.1 在数组中漫游

```
void f(char v[])
{
    for(int i = 0; v[i] != 0; i++) use(v[i]);
}
等价于
void f(char v[])
{
    for(char* p = v; *p!=0; p++) use(*v[i]);
}

需要注意的是：普通数组(例如如char类型的数组)不具备有指针描述，当传递时，需要提供数组长度
```
