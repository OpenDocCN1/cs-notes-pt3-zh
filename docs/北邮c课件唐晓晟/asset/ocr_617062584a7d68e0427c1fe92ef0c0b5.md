# 10.2.7.1 物理的和逻辑的常量性

+   - 偶尔有这种情形，一个成员函数被在逻辑上是const，但它却仍然需要改变某个成员的值。对于用户而言，这个函数看似没有改变其对象的状态，然而，它却可能更新某些用户不能直接访问的细节，这通常被称为逻辑的常量性。
+   - 例如：Date类可能有一个函数，该日期的字符串表示，构造字符串是相对费时的，实现中可以为其保留一个副本。重复需要时返回该副本即可。

# 逻辑的常量性

```
class Date{
    string Date::string_rep() const
    {
        bool cache_valid;
        string cache;
        void compute_cache_value();
        //...
    public:
        string string_rep() const;
        //检查一次缓存是否有效
};

// 头文件解决一点点类似，也无法保证绝对能工作，例如
Date d1;
const Date d2;
string s1 = d1.string_rep(); // ok
string s2 = d2.string_rep(); // 不允许变为const
```

# 10.2.7.2 可变的—mutable

+   - 为了解决上述 const 资源去掉 const 的问题，可以将所涉及的变量声明为 mutable。

```
class Date{
    string Date::string_rep() const
    {
        mutable bool cache_valid;
        mutable string cache;
        void compute_cache_value();
        //...
    public:
        string string_rep() const;
    };

Date d1;
const Date d2;
string s1 = d1.string_rep(); // ok
string s2 = d2.string_rep(); // ok
```
