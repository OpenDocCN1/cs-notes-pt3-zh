# 4.1 类型

+   - C++中，每个名字都有一个与之相关联的类型，类型决定了可以对其进行怎样的操作，并决定这些操作如何解释
+   - 基本类型有：
+   - 布尔、字符、整数、浮点、枚举、void、指针、数组、引用、数据结构和类
+   - 可以分为内置类型和用户自定义类型

# 4.2 布尔量(bool)

+   - 布尔量bool，可以具有两个值false或者true，用于表示逻辑运算的结果。
+   - 根据定义true = 1，false = 0，实际上，非0即true
+   - bool变量和整数（包括指针）可以相互转换

```
void f(int a, int b)
{
  bool bl = a == b;
  // ...
}

bool b = 7;

int i = true;

void g()
{
  bool a = true;
  bool b = true;
  bool x = a + b;
  bool y = a + b;
}
```
