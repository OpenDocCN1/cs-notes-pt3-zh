# 避免名字冲突示例

```
///my.h
char f(char);
int f(int);
class String{
    /** ... */
};

//you.h
char f(char);
double f(double);
class String{
    /** ... */
};
```

```
解决方法：
namespace My{
    char f(char); int f(int);
    class String{ /** ... */ };
}
namespace You{
    char f(char); double f(double);
    class String{ /** ... */ };
}
使用时：
1 using My::f(char), You::f(double)
2 using My::f; using You::String;
3 using namespace My; 或者
  using namespace You;
```

一般情况下，第三方很难同时使用 my.h 和 you.h。

# 8.2.5.1 无名名字空间

+   - 有时，将一组声明包在一个名字空间内部就是为了避免可能的名字冲突
+   - 这样做的目的是为了保持代码的高阶性，而不是为了给用户提供界面
+   - 此时，我们可以使用无名名字空间

# 无名名字空间示例

```
#include "header.h"
namespace Mine{
    void f(){ /*...*/ }
    int g(){ /*...*/ }
}

//使用无名名字空间
#include "header.h"
namespace{
    int a;
    void f(){ /*...*/ }
    int g(){ /*...*/ }
}

相当于：
#include "header.h"
namespace $$${
    int a;
    void f(){ /*...*/ }
    int g(){ /*...*/ }
}
```

# 8.2.6 名字查找

+   - 一个取T类型参数的函数常与T类型本身定义在同一个名字空间中。如果在使用一个函数的环境中无法找到它，我们就去查看它的参数所在的名字空间

```
namespace Chrono{
class Date{
public:
    bool operator==(const Date&,
                    const Date&);
};
}

void f(Chrono::Date d, int){
    std::string s = format(d);
    //Error: 找不到使用int输入
    format(const Date&); //参数的format()版本
}
```
