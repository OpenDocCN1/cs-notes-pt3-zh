# 8.2 名字空间

+   - 名字空间是一种描述细节分组的机制，如果有一些声明按照某种规则在逻辑上属于同一个集团，就可
+   以将它们插入同一个名字空间内
+   - 名字空间描述了一程序的某些...一般和数据的具体实现是分离开来
+   - 成员可以在名字空间的定义里声明，而后再声明
+     namespace-name::member-name是限定
+   - 不在名字空间定义之外用限定前缀形式为名字空间引述新成员
+   - 概说，程序中的每个声明都必须位于某个名字空间内，但是main()函数例外

# 理想情况下，一个名字空间应该

+   - 描述一个具有逻辑统一性的特征集合
+   - 不为用户提供对无关特征的访问
+   - 不给用户强加任何明显的记述负担

# 示例

```
namespace Parser{
    double expr(bool);
    double prim(bool get(){...});
    double term(bool get(){...});
    double expr(bool get(){...});
    //声明和定义同时进行

namespace Parser{
    double expr(bool);
    double prim(bool);
    double term(bool);
}//实现与声明分离
double Parser::expr(bool get){...}
double Parser::prim(bool get){...}
double Parser::term(bool get){...}
```

名字空间的成员必须采用如下写法引入，
namespace name {
    //声明和定义
}
void Parser::logical(bool);
// Error, Parser中logical
// 也无法引入名字logical
void Parser::prim(int);
// Error, prim实现参数多

# 8.2.1 限定词的名字

+   - 名字空间是作用域，普通的作用域规则也对名字空间成立
+   - 如果一个名字先前已经在本名字空间里或者其外围作用域里声明过，就可以直接使用。
+   - 也可以使用来自另外一个名字空间的名字，但需要该名字所属的名字空间作为限定词
