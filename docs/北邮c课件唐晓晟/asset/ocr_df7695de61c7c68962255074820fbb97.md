# 13.6.3 继承关系

+   - 可以将类模板理解为一种有关如何生成特定类的规范
+   - 因此，类模板有时也被称作类型生成器 (type generator)
+   - 如果只考虑C++的规则，由同一个类模板生成的两个类之间并不存在任何关系

# 继承关系示例

```
class Shape{/*...*/};
class Circle:public Shape{/*...*/};
基于上述声明，人对会有疑问到set<Circle>* 当成 set<Shape>*
但这是错误的。Circle是Shape，但是Circle的集合并不构成Shape的集合
class Triangle:public Shape{/*...*/};
void f(set<Shape>* &s) {
  s.insert(new Triangle()); // 可以
}
void g(set<Circle>* &s) {
  f(s); // 错误。类类型不匹配，s.set<Circle>* 不能从 set<Shape>*
  // 不存在从内部的 set<Circle>* 到 set<Shape>* 的转换，也不应该
  // 有这种转换。set<Circle>* 应该能保证所存放就一定是Circle
```

# 13.6.3.1 模板转换

+   - 模板生成的各个类之间没有默认的关系。然而对于某些模板，我们可能希望能表达这种关系

```
template<class T> class Ptr{
  T* p;
public:
  Ptr(T*);
  Ptr(const Ptr&);
  template<class T2> operator Ptr<T2>();
  // 把Ptr<T>转换为Ptr<T2>
};
void f(Ptr<Circle>* pc) {
  Ptr<Shape>* ps = pc; // 允许进行
  Ptr<Circle>* pc2 = ps; // 请检查类型信息
}
```

# 模板转换

+   - 我们希望在上例中，具有当 Shape 是 Circle 的直接或间接派生类时才能进行指针的特化
+   - 如果下面，当且仅当 p 其类类型是 T* 可以作为 T2* 时，这个返回语句才能编译
+   template<class T> // 模板的模板参数表
+   template<class T2> // 模板成员的模板参数表
+   operator Ptr<T2>(){return Ptr<T2>(p);}

```
void f(Ptr<Circle> pc) {
  Ptr<Shape>* ps = pc; // 可以。Circle* 可以转换为 Shape*
  Ptr<Circle>* pc2 = ps; // 错误。Shape* 不能转换为 Circle*
}
```
