# 6.2.8 构造函数

+   从值 e 构造出一个类型 T 的值可以用函数记法 T(e) 表示，比如: int i = int(1.3)，这种结构有时被称作函数风格的强制
+   对于内部类型而言，T(e) 等价于 T{e}，不安全
+   构造函数记法 T() 用于描述类型 T 的默认值，例如: int j = int(); complex z = complex();
+   对于内部类型，得到的是将 0 转换到该类型
