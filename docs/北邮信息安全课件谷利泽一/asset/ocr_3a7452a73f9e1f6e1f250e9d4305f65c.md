# 计算机速度提高对算法处理能力的影响

下表列出在计算设备处理速度提高时对不同时间复杂性算法处理能力（即在1小时内可解的问题实例的最大规模）的影响。

| 时间复杂度 | 现在的计算机（10^6个基本操作/s） | 速度快100倍的计算机 | 速度快10000倍的计算机 |
|---|---|---|---|
| O(n) | N₁=3.6×10⁹ | 100N₁ | 10000N₁ |
| O(n²) | N₂=6×10⁴ | 10N₂ | 100N₂ |
| O(n³) | N₃≈1.5×10³ | 4.64N₃ | 21.5N₃ |
| O(2ⁿ) | N₄≈32 | N₄+6.64 | N₄+13.29 |

注：计算机的计算能力每18个月翻倍
