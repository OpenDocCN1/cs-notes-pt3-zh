# 认证中心（CA）组成

+   - **签名和加密服务器**
+     对于数字证书和被撤销的数字证书，应有认证机构的数字签名。
+   - **密钥管理服务器**
+     与签名加密服务器连接，按配置生成密钥、撤销密钥、恢复密钥和查询密钥。
+   - **证书管理服务器**
+     主要完成证书的生成、作废等操作控制。
+   - **证书发布和CRL发布服务器**
+     用于将证书信息按一定时间间隔对外发布，为客户提供证书下载和CRL下载等服务。
+   - **在线证书状态查询服务器**
+     证书用户随时都知道某个证书的最新状态。
+   - **Web服务器**
+     用于证书发布和有关数据认证系统政策的发布。
