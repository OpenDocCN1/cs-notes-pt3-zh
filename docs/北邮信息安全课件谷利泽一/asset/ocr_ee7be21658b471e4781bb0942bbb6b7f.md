# ElGamal公钥密码体制的举例

+   - 选取素数p=19，生成元g=13；
+   - 用户B选择一个整数x=10作为自己的私钥，计算用户B的公开密钥y： y=g^x mod p=13^10 mod 19=6
+   - 假设用户A想秘密地发送编码为m=11的消息给用户B，用户A将执行下述加密过程：
+   - 首先用户A选择一个随机数r，假设r=7，并计算： c1=g^r mod p=13^7 mod 19=10。同时，A还需要计算： c2=m y^r mod p=11*6^7 mod 19=4。最后，用户A把元组(10,4)发送给用户B。
+   - 用户B在接受到后，用户B计算： c2*(c1^x)^-1 mod 19=4*(10^10)^-1 mod 19=4*17 mod 19=11。
