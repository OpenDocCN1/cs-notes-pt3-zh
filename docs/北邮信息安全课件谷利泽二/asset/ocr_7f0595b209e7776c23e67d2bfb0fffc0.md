# VPN应用背景

随着信息时代的到来，企业内部和企业之间数据通信的数量在不断地增加，企业纷纷建立起自己的内部网络（Intranet），甚至企业之间也建立起专用的外部网（Extranet）以方便信息交换。传统的Internet在分支机构与中心网络的连接上，最早的方式是架设自己的专用线路，但是只是极少数企业能有这样的经济实力实现跨区域的远程连接。随着因特网的普及，主干网络速度越来越快，企业开始租用数据专线通过广域网实现连接，但租用专线的成本仍居高不下，而且总部与各分支机构都必须重用各自的专线才能实现连接和数据通信。因特网存在的安全问题同样会这样连接的Intranet产生影响。费用和安全因素成为限制企业Intranet发展的主要障碍。
