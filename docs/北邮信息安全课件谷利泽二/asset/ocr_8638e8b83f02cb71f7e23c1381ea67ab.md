# # 开放式系统互联参考模型（OSIRM）

| 功能层次 | 功能描述 | 其它 |
|---|---|---|
| **应用层** | 与用户应用进程的接口 | 做什么？Http、FTP协议等 |
| 表示层 | 数据格式的转换 | 对方看起来像什么？ |
| 会话层 | 会话的管理与数据传输的同步 | 轮到哪方传输，从何处开始传输？ |
| **传输层** | 从端对端经网络透明地传送报文 | 对方在何处？TCP、UDP协议等 |
| **网络层** | 分组传送、路由选择和流量的控制 | 数据如何到达对方？IP协议等 |
| 链路层 | 在链路上无差错的传送数据帧 | 每一步该怎么走？ |
| 物理层 | 将比特流送到物理媒体 | 信息实际如何传送？ |
