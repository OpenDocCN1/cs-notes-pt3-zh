# (2)后缀表明OpenGL命令的数据类型

| 后缀 | 类型 | 对应C变量 |
|---|---|---|
| b | 8bit int | signed char |
| s | 16bit int | short |
| i | 32bit int | long |
| f | 32bit float | float |
| d | 64bit float | double |
| ub | 8bit unsigned int | unsigned char |
| us | 16bit unsigned int | unsigned short |
| ui | 32bit unsigned int | unsigned long |
