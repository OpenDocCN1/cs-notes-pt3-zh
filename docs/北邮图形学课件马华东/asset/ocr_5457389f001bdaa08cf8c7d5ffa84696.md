+   - 若阴影线与棱边的交点是$(x_l,y_l)$，则
+   
+   $$egin{cases} x_l = \frac{x_p y_q - y_p x_q + b_j (x_q - x_p)}{(y_q - y_p) - k (x_q - x_p)} \ y_l = k x_l + b_j \end{cases}$$ 
+   - 因为不同的阴影线都需判断与每条棱边是否有交点,以决定相应的阴影线在填充时开始/终止于何处,因而有必要事先计算出所有棱边的两个端点按阴影线斜率引线的对应截距,方便每一次的判断,避免重复计算。
+   - 鉴于上述原因,定义数组B(2,MN)记录各棱边两端点按阴影线斜率引线产生的截距,并将两者中的较小值放在第一行。
