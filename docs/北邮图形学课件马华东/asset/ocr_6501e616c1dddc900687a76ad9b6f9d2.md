+   - 如求一条直线与裁剪空间上平面(如y=1)的交点，将y=1代入，得$t=\frac{1-y_1}{g}$，若t不在0到1的闭区间内，则交点在裁剪空间外，否则可求得：
+     $x=x_1+\frac{1-y_1}{g}$，$z=z_1+\frac{1-y_1}{g}$，这时三维线段与裁剪窗口的有效交点为$(x_1+\frac{1-y_1}{g},z_1+\frac{1-y_1}{g})$；
+   - 类似可求出其它5个面与直线段的有效交点,连续有效交点可得出落在裁剪窗口内的有效线段。
+   - 可以很方便得将二维裁剪中的Sutherland-Cohen算法与中点分割算法推广到三维裁剪。
