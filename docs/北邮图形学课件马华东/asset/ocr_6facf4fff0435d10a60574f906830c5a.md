# [方法2] 利用递推公式计算顶点坐标

+   - 设多边形相邻顶点所对的圆心角为α, 推导顶点 Pᵢ₊₁ 的坐标如下：
+     {
+       yᵢ₊₁ = y_c + r sin(θ + α) = y_c + (xᵢ - x_c) sin α + (yᵢ - y_c) cos α
+       xᵢ₊₁ = x_c + r cos(θ + α) = x_c + (xᵢ - x_c) cos α - (yᵢ - y_c) sin α
+     }
+   - 分析: 在上述递推公式中, 因为α是常数, cosα和 sinα 只要在开始时算一次, 这样求Pᵢ₊₁ 的坐标需要作4次乘法。
+   - 另外, 凡是利用递推公式计算时要注意误差是否稳定, 以免误差多次积累后严重偏离真解。可以证明, 上述递推公式对初始值的误差是稳定的。
+   - 可用2个处理器流水线处理: 一个求点, 一个画图.
