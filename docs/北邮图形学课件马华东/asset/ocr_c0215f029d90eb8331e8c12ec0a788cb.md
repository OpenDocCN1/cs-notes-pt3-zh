• 二次曲面纹理映射
可用极坐标把曲面的隐式方程改写为参数方程。
例1：圆柱面 x² + y² = 1 (0 <= z <= 1) 改写为：
{ x = cos(2πu)   0 ≤ u ≤ 1
  y = sin(2πu)   0 ≤ v ≤ 1
  z = v }
给定 u, v, 可以求出 x, y, z。
反之, 给定圆柱面上一点 (x, y, z), 可用下列公式求出参数 u, v。
(u, v) = { (y, z)          当 x = 0
           (x, z)          当 y = 0
           ( atan2(y, x) / 2π , z )   其它情况 }
