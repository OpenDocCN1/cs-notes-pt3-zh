# 6.2.1 Bézier曲线

# 一、Bézier曲线的定义

+   给定空间 $n+1$ 个点的位置矢量 $P_i (i=0,1,...,n)$，则称下面参数曲线为 $n$ 次 Bézier 曲线：
+   
+   $$P(t) = \sum_{i=0}^{n} P_i J_{i,n}(t),\ 0 \le t \le 1$$
+   
+   见图6.1。其中 $J_{i,n}(t)$ 是 Bernstein 基函数：
+   
+   $$J_{i,n}(t) = C_n^i t^i (1-t)^{n-i},\ i = 0,1,...,\ n$$
+   
+   $$C_n^i = \frac{n!}{i!(n-i)!}$$
+   
+   $J_{0,n}(t) = (1-t)^n$, $J_{n,n}(t) = t^n$

+   折线 $P_0P_1...P_n$ 为 $P(t)$ 的控制多边形，$P_0$, $P_1$, ..., $P_n$ 各点为 $P(t)$ 控制顶点。
