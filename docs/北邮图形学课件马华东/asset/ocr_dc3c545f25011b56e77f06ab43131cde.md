# 二、纹理函数

+   - 最常用的纹理为二维光亮度函数，可用数学模型定义或一幅平面图象表示。这种数学模型定义在单位正方形区域，称纹理空间，定义在纹理空间的函数即纹理函数。
+   - 实际上，纹理函数往往采用一些特殊函数。

例1：$g(u,v)=\begin{cases}b, \lfloor u\times 8\rfloor+\lfloor v\times 8\rfloor\text{为奇数}\\a, \lfloor u\times 8\rfloor+\lfloor v\times 8\rfloor\text{为偶数}\end{cases}$

其中$0<a<b<1$, $\lfloor X\rfloor$表示小于 X 的最大整数。

$g(u,v)$用于模拟国际象棋棋盘上的黑白相间方格。
