# 9.2.2 算法实现

+   - 首先确定 $\cos i$ 和 $\cos\theta$
+   
+     $$
+     \begin{cases}
+     \cos i=(\vec{L}_0\cdot\vec{N}_0)\\
+     \cos\theta=\vec{R}_0\cdot\vec{V}_0\approx(\vec{N}_0\cdot\vec{H}_0)
+     \end{cases}
+     $$
+   
+     其中 $\vec{L}_0,\vec{N}_0,\vec{R}_0,\vec{V}_0$ 是 $L,N,R,V$ 相应的单位向量，$\vec{H}_0$ 为光和 $V$ 的角平分线的单位向量。

+   - 使用 Phong 模型的扫描线绘制算法
