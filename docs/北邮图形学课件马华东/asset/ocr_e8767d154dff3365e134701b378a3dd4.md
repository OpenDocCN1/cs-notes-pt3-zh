# 二、Bézier曲线的性质

+   (1) 端点位置
+   
+   P₀，Pₙ为P(t)的端点：P(0)=P₀，P(1)=Pₙ
+   
+   (2) 端点切线
+   
+   P(t)在P₀点与边P₀P₁相切，在Pₙ点与边Pₙ₋₁Pₙ相切：
+   
+   P′(0)=n(P₁-P₀)，P′(1)=n(Pₙ-Pₙ₋₁)
+   
+   (3) 端点的曲率
+   
+   P(t)在P₀、Pₙ两端点曲率分别为：

$$K(0)=\frac{n-1}{n}\cdot\frac{\left|\overrightarrow{P_0P_1}\times\overrightarrow{P_1P_2}\right|}{\left|\overrightarrow{P_0P_1}\right|^3}$$

$$K(1)=\frac{n-1}{n}\cdot\frac{\left|\overrightarrow{P_{n-2}P_{n-1}}\times\overrightarrow{P_{n-1}P_n}\right|}{\left|\overrightarrow{P_{n-1}P_n}\right|^3}$$
