# 扫描线Z-buffer算法（）

```
```text
{
  建立多边形表；对每一个多边形根据顶点最小的值，将多边形置入多边形表。
  活化多边形表APT，活化边对表AET初始化为空。
  for (每条扫描线i, i从小到大)
  {
    1. 帧缓存CB置为背景色。
    2. 深度缓存ZB(一维数组)置为负无穷大。
    3. 将对应扫描线i的，多边形表中的多边形加入到活化多边形表APT中。
    4. 对新加入的多边形，生成其相应的边表。
    5. 对APT中每一个多边形，若其边表中对应扫描线i增加了新的边，将新边配对，
       加到活化边对表AET中。
    6. 对AET中的每一对边：
       6.1 对x_l<j<x_r的每一个像素，按增量公式z=z_l+Δz_x计算各点深度depth。
       6.2 与ZB对应量比较，depth>ZB(j)，则ZB(j)=depth，并计算颜色值，写帧缓存。
    7. 删除APT中多边形顶点最大y坐标为j的多边形，并删除相应的边。
    8. 对AET中的每一个边对，作如下处理：
       8.1 删除y_lmax或y_rmax已经等于i的边。
       8.2 用增量公式计算新的x_l、x_r和z_l。x_l=x_l+Δx_l x_r=x_r+Δx_r z_l=z_l+Δz_xΔz_y
  }
}
