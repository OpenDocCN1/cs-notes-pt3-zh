  $$|D(P_i)|=|x_i^2+y_i^2-R^2|$$
  is minimized at every step.

- Suppose \(P_{i-1}(x_{i-1},y_{i-1})\) has been selected as the point closest to the circular arc. For the next step, when \(x=x_{i-1}+1\), refer to Figure 3.5. It is necessary to determine whether T or S is closer to the ideal circular arc. Let
  $$D(S)=(x_{i-1}+1)^2+y_{i-1}^2-R^2$$
  $$D(T)=(x_{i-1}+1)^2+(y_{i-1}-1)^2-R^2$$

- Obviously, when \(|D(S)|>=|D(T)|\), point T should be selected; otherwise, point S should be selected. That is, if we define
  
  $d_i = |D(S)| - |D(T)|$
  
  then when \(d_i >=0\), point T is selected; otherwise, point S is selected.

![](img/c00b4e8ccb17d37f1489c44f2791c008_102_0.png)

- Use \(dᵢ=D(S)+D(T)\) instead as the decision criterion:
  dᵢ=D(S)+D(T)= 2(xᵢ₋₁+1)² + yᵢ₋₁² + (yᵢ₋₁-1)² -2R²
  dᵢ(R) is a decreasing function. (dᵢ=0 is the circle C for which the distances to S and T are approximately equal.)
  When dᵢ >=0, arc AB lies below circle C, so point T is selected; otherwise, point S is selected.
- Derive a recurrence formula to simplify the calculation of dᵢ:
  x₀=0; y₀=R; x₁ = x₀ +1;
  d₁=D(S)+D(T)=(1²+ y₀² -R²)+(1²+(y₀ -1)² - R²)
  =3 - 2 y₀= 3 - 2R;
  dᵢ = (xᵢ² + yᵢ₋₁² - R²)+(xᵢ² + (yᵢ₋₁-1)² - R²)
  =2xᵢ²+2yᵢ₋₁² -2yᵢ₋₁- 2R²+1
  dᵢ₊₁= (xᵢ+1)² + yᵢ² -R² + (xᵢ+1)² + (yᵢ -1)² - R²
  =2xᵢ²+4xᵢ+2yᵢ² -2yᵢ -2R² +3

- Conclusion:
  d₁ = 3 - 2R;
  if dᵢ < 0, select Pᵢ(xᵢ, yᵢ₋₁), and substitute yᵢ = yᵢ₋₁ to obtain dᵢ₊₁:
    dᵢ₊₁ = dᵢ + 4xᵢ + 2 = dᵢ + 4xᵢ₋₁ + 6
  if dᵢ >= 0, select Pᵢ(xᵢ, yᵢ₋₁ - 1), and substitute yᵢ = yᵢ₋₁ - 1 to obtain dᵢ₊₁:
    dᵢ₊₁ = dᵢ + 4xᵢ - 4yᵢ₋₁ + 6 = dᵢ + 4(xᵢ₋₁ - yᵢ₋₁) + 10

## 4) Algorithm Characteristics

The Bresenham circular-arc algorithm is one of the most effective algorithms. When generating a circle, it uses the upper one-eighth arc in the first quadrant and extends it symmetrically. The decision criterion used when selecting points is a recurrence expression, which can be calculated using only addition, subtraction, and shift operations, resulting in high algorithmic efficiency.

## 3.2.2 Sign Method (Point-by-Point Comparison Method)

- 1) Algorithm Idea
- 2) Algorithm Principle
- 3) Algorithm Characteristics

## 1）Algorithm Idea

- First, distinguish between circular arcs in different quadrants;
- Then, after selecting the starting point of the circular arc, during the process of outputting the arc, determine the direction of the next step according to the relationship between the current point and the ideal circular arc and according to the quadrant in which it lies. At each step, take a point by moving in only one direction (X or Y);
- In this way, the circular arc to be displayed is generated by approaching it step by step.

## 2) Algorithm Principle

- Suppose the center of the circle to be displayed is \(C(x_c, y_c)\), with radius \(R\).

- Take the drawing of circular arc AB in the first quadrant in Figure 3.7 as an example.

![](img/c00b4e8ccb17d37f1489c44f2791c008_110_0.png)

Figure 3.7 Schematic diagram of the sign method principle

- Let \(F(x,y)=(x-x_c)^2+(y-y_c)^2-R^2\). Then the equation of the circle is \(F(x,y)=0\).\
  When point \((x,y)\) is inside the circle, \(F(x,y)<0\); when point \((x,y)\) is outside the circle, \(F(x,y)>0\).

- Let \(P_0(x_0,y_0)\) be point A, that is, \(x_0=x_c，y_0=y_c+R\). After obtaining \(P_i(x_i,y_i)\), the principle for finding the next point \(P_{i+1}\) is as follows:\
  When \(F_i(x_i,y_i)<0\), move one step in the +X direction (toward the outside of the circle), taking\
  \(x_{i+1}=x_i+1，\ y_{i+1}=y_i\);\
  When \(F_i(x_i,y_i)\geq0\), move one step in the -Y direction (toward the inside of the circle), taking\
  \(x_{i+1}=x_i，\ y_{i+1}=y_i-1\).

- \(F(x,y)\) alternates between positive and negative values, which is the origin of the algorithm’s name.

- Derive a recurrence formula to simplify the decision criterion
  
  Note that \(F(x_0,y_0)=0\);
  
  When \(x_{i+1}=x_i+1,\ y_{i+1}=y_i\) (moving toward the outside of the circle),
  
  \[
  F(x_{i+1},y_{i+1})=(x_i+1-x_c)^2+(y_i-y_c)^2-R^2
  \]
  \[
  =(x_i-x_c)^2+(y_i-y_c)^2-R^2+2(x_i-x_c)+1
  \]
  \[
  =F(x_i,y_i)+2(x_i-x_c)+1
  \]
  
  When \(x_{i+1}=x_i,\ y_{i+1}=y_i-1\) (moving toward the inside of the circle),
  
  \[
  F(x_{i+1},y_{i+1})=(x_i-x_c)^2+(y_i-1-y_c)^2-R^2
  \]
  \[
  =F(x_i,y_i)-2(y_i-y_c)+1
  \]

- Conclusion:
  - Initial value of the decision criterion: \(F_0=0\);
  - When \(F_i<0\) (inside the circle), select \(P_{i+1}(x_i+1,y_i)\), and
    $$F_{i+1}=F_i+2(x_i-x_c)+1;$$
  - When \(F_i\geq0\) (outside the circle), select \(P_{i+1}(x_i,y_i-1)\), and
    $$F_{i+1}=F_i-2(y_i-y_c)+1.$$

## Algorithm Description

```
Procedure pnarc(r,xc,yc: integer);
  var x,y,f: integer;
  begin
    x:=xc; y:=yc+r; f:=0;
    while y>yc do {        //画1/4圆弧
      plot(x,y);
      if f>0 then { f:=f-2*(y-yc)+1;
                    y:=y-1 }    //向圆内走
      else { f:=f+2*(x-xc)+1;
             x:=x+1 }    //向圆外走
    }
    if (y=yc) plot(x,y)
  end
```

- Circular arcs in other quadrants and with different directions can be drawn similarly.
- General calculation rules

For the counterclockwise first and third quadrants and the clockwise second and fourth quadrants, the absolute value of X along the direction of motion continuously decreases, while the absolute value of Y continuously increases; therefore, their calculation rules are the same.  
For the clockwise first and third quadrants, the absolute value of X continuously increases while the absolute value of Y continuously decreases; their calculation rules are the same as those of the counterclockwise second and fourth quadrants.

## 3) Algorithm Characteristics

- When a computer uses the sign method to generate circular arcs, the operations consist only of addition, subtraction, and shifting (multiplication by 2), with no multiplication or division. Therefore, the computational efficiency is high, making it well suited for hardware implementation.
- Compared with the Bresenham algorithm, the sign method involves simpler calculations. However, for the same circular arc, because the sign method moves in only one direction at each step, it generates more points than the Bresenham algorithm.
