# Supplement: 管道应用示例

```
```c
#include<stdio.h>
main()
{
  int pid,fd[2];
  char buf[30],s[30];
  pipe(fd);
  while((pid=fork())==-1);
  if (pid==0) {
    sprintf(buf, "this is an example\n");
    write(fd[1],buf,30);
    exit(0);
  }
  else {
    wait(0);
    read(fd[0],s,30);
    printf("%s",s);
  }
}
