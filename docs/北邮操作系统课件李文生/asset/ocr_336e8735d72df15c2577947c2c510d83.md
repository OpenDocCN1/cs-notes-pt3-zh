# notation

+   Let X and Y be vectors of length n
+   X ≤ Y ⟺ X[i] ≤ Y[i] for all i=1,2,...,n

+   Each row in the matrices *allocation* and *need* can be treated as vectors and referred to as *allocation*ᵢ and *need*ᵢ

+   *Allocation*ᵢ specifies the resources currently allocated to process Pᵢ

+   *Need*ᵢ specifies the additional resources that process Pᵢ may still reaquest to complete its task.
