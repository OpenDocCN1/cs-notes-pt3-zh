# Computer System Components

+   1. Hardware
+   provides basic computing resources, such as CPU, memory, I/O devices.
+   2. Operating system
+   controls and coordinates the use of the hardware among the various application programs for the various users.
+   3. Applications programs
+   define the ways in which the system resources are used to solve user’s computing problems (compilers, DBMS, database systems, word processors, video games, business programs).
+   4. Users
+   people, machines, other computers
