# Pentium paging

+   - Allow a page size of either 4KB or 4MB
+   - For 4KB pages, the Pentium uses a two-level paging scheme.
+   - The linear address: 32-bit long
+     - 20-bit page number
+       - 10-bit page directory pointer (P1)
+       - 10-bit page table pointer (P2)
+     - 12-bit offset (d)
