# 8.6 Segmentation

Memory-management scheme that supports user view of memory.

A program is a collection of segments. A segment is a logical unit such as:

+   - main program,
+   - procedure,
+   - function,
+   - method,
+   - object,
+   - local variables, global variables,
+   - common block,
+   - stack,
+   - symbol table, arrays
