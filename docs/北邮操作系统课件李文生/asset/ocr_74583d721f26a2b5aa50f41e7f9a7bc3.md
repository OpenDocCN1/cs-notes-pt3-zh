# 3.4 Interprocess Communication

+   - **_Independent_** process cannot affect or be affected by the execution of another process.
+   - **_Cooperating_** process can affect or be affected by the execution of another process
+   - Advantages of process cooperation
+     - Information sharing
+     - Computation speed-up
+     - Modularity
+     - Convenience
+   - Two fundamental models
+     - Shared-memory
+     - Message passing
