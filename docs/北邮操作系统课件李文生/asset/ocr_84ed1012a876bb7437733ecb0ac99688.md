# Resource-Allocation Graph

+   - Deadlock can be described in terms of a System resource-allocation graph
+     - Directed graph
+     - A set of vertices *V* and a set of edges *E*.

+   - *V* is partitioned into two different types:
+     - *P* = {P₁, P₂, …, Pₙ}, the set consisting of all the processes in the system.
+     - *R* = {R₁, R₂, …, Rₘ}, the set consisting of all resource types in the system.

+   - *E* is classed into two different types:
+     - request edge – directed edge Pᵢ → Rⱼ. Process Pᵢ requested an instance of resource type Rⱼ, and is currently waiting for that resource.
+     - assignment edge – directed edge Rⱼ → Pᵢ. An instance of resource type Rⱼ has been allocated to process Pᵢ.
