# 7.2 Deadlock Characterization

+   - **Mutual exclusion:** only one process at a time can use a resource.
+   - **Hold and wait:** a process holding at least one resource is waiting to acquire additional resources held by other processes.
+   - **No preemption:** a resource can be released only voluntarily by the process holding it, after that process has completed its task.
+   - **Circular wait:** there exists a set {P₀, P₁, …, Pₙ} of waiting processes such that P₀ is waiting for a resource that is held by P₁, P₁ is waiting for a resource that is held by P₂, …, Pₙ₋₁ is waiting for a resource that is held by Pₙ, and Pₙ is waiting for a resource that is held by P₀.

A deadlock situation can arise if the above four conditions hold simultaneously.
