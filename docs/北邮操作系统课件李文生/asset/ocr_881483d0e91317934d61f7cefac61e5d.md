# Linux的命令控制界面

+   - 命令位置：/user/sbin、user/bin、/sbin、/bin
+   - Linux命令分类
+     - 系统维护及管理：如date, setenv等
+     - 文件操作及管理：如ls, find等
+     - 进程管理：如kill, at等
+     - 磁盘及设备管理：如df, du, mount等
+     - 用户管理：如adduser, userdel等
+     - 文档操作：如csplit, sort等
+     - 网络通信：如netstat, ifconfig等
+     - 程序开发：如cc, link等
+     - X Window管理：如startx, XE86Stup等
+   - man命令：显示某命令的联机帮助
