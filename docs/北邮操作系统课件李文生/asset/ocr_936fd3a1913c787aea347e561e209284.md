# Bounded Producer-Consumer Problem

```
void producer()
    char x;
    {
        while (true)
        {
            produce(x);
            append(x);
        }
    }

void consumer()
    char x;
    {
        while (true)
        {
            take(x);
            consume(x);
        }
    }
Void main()
    {
        Parbegin(producer,consumer);
    }
```
