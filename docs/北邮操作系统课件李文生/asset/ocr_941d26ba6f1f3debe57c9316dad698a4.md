# Access Methods (2/3)

+   - **Direct Access**
+     - read n
+     - write n
+     - position to n
+       - read next
+       - write next
+     - rewrite n
+   - n = relative block number

| sequential access | implementation for direct access |
|---|---|
| read | `cp = 0;` |
| read next | `read cp;`<br>`cp = cp + 1;` |
| write next | `write cp;`<br>`cp = cp + 1;` |
