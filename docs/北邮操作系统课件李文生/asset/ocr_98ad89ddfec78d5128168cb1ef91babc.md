# 举例——静态优先级、非剥夺式调度

某系统采用非剥夺式优先级调度算法，5个进程P₁、P₂、P₃、P₄、P₅依次进入就绪队列，其需要的CPU时间、到达时刻、及优先数如右。

| 进程 | CPU时间 | 到达时刻 | 优先数 |
|---|---:|---:|---:|
| P1 | 10 | 0 | 3 |
| P2 | 1 | 2 | 1 |
| P3 | 2 | 3 | 3 |
| P4 | 1 | 5 | 4 |
| p5 | 5 | 7 | 2 |

进程调度的甘特图如下：

+   - **Waiting time（等待时间）：**
+     - T1=0、T2=8、T3=13、T4=13、T5=4；average: TA=7.6
+   - **Turnaround time（周转时间）：**
+     - T1=10、T2=9、T3=15、T4=14、T5=9；average: TA=11.4
