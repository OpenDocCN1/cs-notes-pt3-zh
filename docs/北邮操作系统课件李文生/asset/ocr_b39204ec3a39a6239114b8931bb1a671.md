# Review: Types of instructions

+   - **Processor-memory**
+     - transfer data between processor and memory
+   - **Processor-I/O**
+     - data transferred to or from a peripheral device
+   - **Data processing**
+     - arithmetic or logic operation on data
+   - **Control**
+     - alter sequence of execution
