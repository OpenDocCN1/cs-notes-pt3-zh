# Dining Philosophers (Cont.)

void pickup(int i) {
    state[i] = hungry;
    test[i];
    if (state[i] != eating)
        self[i].wait();
}
```

```
void test(int i) {
    if ( (state[(i + 4) % 5] != eating)
        && (state[i] == hungry)
        && (state[(i + 1) % 5] != eating))
    {
        state[i] = eating;
        self[i].signal();
    }
}
```

```
void putdown(int i) {
    state[i] = thinking;
    test((i+4) % 5); // test left neighbors
    test((i+1) % 5); // test right neighbors
}
