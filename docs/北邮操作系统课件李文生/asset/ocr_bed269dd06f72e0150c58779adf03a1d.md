# Single Instance of Each Resource Type

![](bbox=[0.08, 0.15, 0.88, 0.68])

+   Maintain *wait-for* graph
+   - Nodes are processes.
+   - $P_i \rightarrow P_j$ if $P_i$ is waiting for $P_j$ to release a resource that $P_i$ needs.

$P_i \rightarrow P_j$ exists in wait-for graph $\leftrightarrow$ $\exists q$, $P_i \rightarrow R_q$ and $R_q \rightarrow P_j$ exist in resource-allocation graph.
