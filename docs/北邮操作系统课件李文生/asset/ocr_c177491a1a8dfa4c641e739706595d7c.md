# Usage

Critical Section of n Processes

+   - Shared data:
+     semaphore mutex; // initially mutex = 1

+   - Process Pi:
+     do {
+       wait(mutex);
+       critical section
+       signal(mutex);
+       remainder section
+     } while (1);

```
wait (S):
  while S ≤ 0 ;
  S--;
signal (S):
  S++;
```

Shared data:
Semaphore synch; // 0

P1:
  S1;
  signal(synch);
P2:
  wait(synch);
  S2;
