# Page Fault

+   - If there is ever a reference to a page, first reference will trap to OS ⇒ page fault
+   - OS looks at another internal table to decide:
+     - Invalid reference ⇒ abort.
+     - Just not in memory.
+   - Get empty frame.
+   - Swap page into frame.
+   - Reset tables, validation bit = 1.
+   - Restart instruction
