# File Structure

+   - **None** - sequence of words, bytes
+   - **Simple record structure**
+     - Lines
+     - Fixed length
+     - Variable length
+   - **Complex Structures**
+     - Formatted document
+     - Relocatable load file
+   - Can simulate last two with first method by inserting appropriate control characters.
+   - **Who decides?**
+     - Operating system
+     - Program
