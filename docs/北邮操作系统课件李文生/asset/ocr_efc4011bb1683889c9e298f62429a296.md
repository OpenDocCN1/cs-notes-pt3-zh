# Other Issues --Program structure

+   - Page size = 1024 words
+   - int A[][] = new int[1024][1024];
+   - Each row is stored in one page
+   - The OS allocates fewer than 1024 frames to the entire program
+   - Program 1:
+     ```
+     for (j = 0; j < 1024; j++)
+       for (i = 0; i < 1024; i++)
+         A[i,j] = 0;
+     ```
+     1024 × 1024 page faults
+   - Program 2:
+     ```
+     for (i = 0; i < 1024; i++)
+       for (j = 0; j < 1024; j++)
+         A[i,j] = 0;
+     ```
+     1024 page faults
