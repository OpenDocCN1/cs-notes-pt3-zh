

## 11.4 分配方法

- 分配方法是指为文件分配磁盘块的方式。
- 连续分配
- 链接分配
- 索引分配

### 补充：从逻辑到物理的映射

LA / block size → Q  
R

- 要访问的块 = Q + 起始地址
- 块内位移 = R
- 示例
  - 对于文本文件
  - 对于记录文件
- 问题
  - 难以为新文件找到空间
  - 外部碎片
  - 确定文件需要多少空间

### 基于 Extent 的系统

- 许多较新的文件系统（即 Veritas 文件系统）使用修改后的连续分配方案。
- 最初分配一块连续的空间，然后当该空间不足时，再向初始分配添加另一块连续空间，即 extent。
- 基于 extent 的文件系统以 extent 的形式分配磁盘块。
- Extent 是磁盘块的连续块。Extent 用于文件分配。文件由一个或多个 extent 组成。

### 链接分配

- 基于单个块的分配
- 每个文件都是磁盘块的链表：块可以分散在磁盘的任何位置。
- 目录包含指向文件第一块和最后一块的指针。
- 每个块包含指向链中下一块的指针。
- 没有外部碎片。
- 任何空闲空间列表上的空闲块都可用于满足请求。

### 链接分配（续）

- **缺点**
  - 无随机访问，指针占用空间，可靠性
- **从逻辑到物理的映射**
  - 要访问的块是表示文件的块链表中的第 Q 个块。
  - 块内位移 = R + ptr_space
  - LA / (block_size - ptr_space) → Q  
    R
- **文件分配表（FAT）**
  - MS-DOS 和 OS/2 使用的简单但高效的方法
  - 包含在每个分区的开头部分。
  - 每个块一个条目。
  - 按块号索引。
  - 缓存在内存中

### 索引分配

- 将所有指针集中到 *索引块* 中。
- 每个文件都有自己的索引块，它是一个磁盘块地址的数组。
- 目录包含索引块的块号。
- 逻辑视图。

![](img/9321d6c42b8369e67ceb1f1d7e27b09c_766_0.png)

### 索引分配（续）

- 需要索引表
- 随机访问
- 动态访问且无外部碎片，但有索引块的开销。
- 在最大文件大小为 256K 词且块大小为 512 词的文件中从逻辑到物理的映射。我们只需要 1 个块用于索引表。

LA / 512 → Q  
R

Q = 索引表内的位移

R = 块内的位移

### 索引分配 – 映射（续）

- 在文件长度无界的情况下从逻辑到物理的映射（块大小为 512 词）。
- 链接方案 – 链接索引表的块（大小无限制）。

LA / (512 × 511) → Q₁  
R₁

Q₁ = 索引表的块  
R₁ 按如下方式使用：

R₁ / 512 → Q₂  
R₂

Q₂ = 索引表块内的位移  
R₂ = 文件块内的位移
