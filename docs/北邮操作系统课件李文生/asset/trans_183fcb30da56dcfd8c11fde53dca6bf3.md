

## 其他问题 -- TLB 可达性

- TLB 可访问的内存量。
- **TLB 可达性 = (TLB 大小) × (页大小)**
- 理想情况下，每个进程的工作集都存储在 TLB 中。否则进程将花费大量时间在页表中解析内存引用，而不是在 TLB 中。
- **通过以下方式增加 TLB 可达性的大小**
  - **增加页大小。** 这可能导致碎片增加，因为并非所有应用程序都需要较大的页大小。
  - **提供多种页大小。** 这允许需要较大页大小的应用程序有机会使用它们，而不会增加碎片。

## 其他问题 -- 程序结构

- 页大小 = 1024 字
- int A[][] = new int[1024][1024];
- 每行存储在一个页中
- 操作系统为整个程序分配的帧数少于 1024
- 程序 1:
  ```
  for (j = 0; j < 1024; j++)
    for (i = 0; i < 1024; i++)
      A[i,j] = 0;
  ```
  1024 × 1024 次页错误
- 程序 2:
  ```
  for (i = 0; i < 1024; i++)
    for (j = 0; j < 1024; j++)
      A[i,j] = 0;
  ```
  1024 次页错误

## 其他问题 -- I/O 互锁

- 页面有时必须被锁定在内存中。
- 考虑 I/O。
- 切勿向用户内存执行 I/O。
  - I/O 仅在系统内存和 I/O 设备之间进行。
  - 数据在系统内存和用户内存之间复制。
- 允许页面被锁定在内存中。
  - 每个帧都关联一个锁位。
  - 锁定的页面不能被替换，I/O 完成后，解锁。
- 用于从设备复制文件的页面必须被锁定，以防止页面置换算法将其选为驱逐对象。
