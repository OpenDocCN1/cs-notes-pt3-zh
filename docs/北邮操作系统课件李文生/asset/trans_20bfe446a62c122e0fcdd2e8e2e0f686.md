    - 逻辑记录号

- **基本 I/O 函数以块为单位操作**

- **将逻辑地址映射到物理地址**
  - 逻辑块号

  - 块内偏移量

## 10.2 访问方法

- 反映不同的文件结构
- 存储和处理数据的不同方式
- 文件组织的标准

- 快速访问
  - 访问单个记录时需要
  - 批处理模式下不需要

- 更新的便捷性
  - CD-ROM 上的文件不会被更新，因此这不是问题

- 存储经济性
  - 数据中应具有最小冗余
  - 冗余可用于加速访问，例如索引

- 简单维护

- 可靠性

## 访问方法 (1/3)

- 顺序访问
  - 读下一个
  - 写下一个
  - 重置
  - 重写，末次写入后不读
- 顺序访问文件

![](img/9321d6c42b8369e67ceb1f1d7e27b09c_706_0.png)

## 访问方法 (2/3)

- **直接访问**
  - 读 n
  - 写 n
  - 定位到 n
    - 读下一个
    - 写下一个
  - 重写 n
- n = 相对块号

![](img/9321d6c42b8369e67ceb1f1d7e27b09c_707_0.png)

在直接访问文件上模拟顺序访问。

| 顺序访问 | 直接访问的实现 |
|---|---|
| 读 | `cp = 0;` |
| 读下一个 | `read cp;`<br>`cp = cp + 1;` |
| 写下一个 | `write cp;`<br>`cp = cp + 1;` |

## 10.3 目录结构

- 磁盘被划分为一个或多个分区。
  - 系统中的每个磁盘至少包含一个分区。
  - 有些系统允许分区大于一个磁盘，以将磁盘组合成一个逻辑结构。

![](img/9321d6c42b8369e67ceb1f1d7e27b09c_709_0.png)

- 每个分区包含有关其中文件的的信息
  - 名称、位置、大小和类型等信息保存在目录的条目中

## 补充：
目录条目中的信息

- 名称
- 类型
- 地址
- 当前长度
- 最大长度
- 最后访问日期（用于归档）
- 最后更新日期（用于转储）
- 所有者 ID（谁付费）
- 保护信息

## 对目录执行的操作

- 搜索文件
- 创建文件
- 删除文件
- 列出目录
- 重命名文件
- 遍历文件系统

## 补充：
组织目录（逻辑上）的对象

- **效率** – 快速定位文件。
- **命名** – 对用户方便。
  - 两个用户可以为不同的文件使用相同的名称。
  - 同一个文件可以有几个不同的名称。
- **分组** – 按属性对文件进行逻辑分组，（例如，所有 Java 程序，所有游戏，...）
