## 13.6 STREAMS

- **STREAM** – 用户级进程与设备之间的全双工通信通道
- 一个 STREAM 由以下部分组成：
  - **STREAM 头** 与用户进程接口
  - **驱动程序端** 与设备接口
  - 它们之间零个或多个 **STREAM 模块**。
- 每个模块包含一个读队列和一个写队列
- 使用消息传递在队列之间进行通信

## 13.7 性能

I/O 是系统性能的主要因素：

- 需要 CPU 执行设备驱动程序、内核 I/O 代码
- 由于中断导致上下文切换
- 数据复制
- 网络流量尤其具有压力

### 计算机间通信

![](img/9321d6c42b8369e67ceb1f1d7e27b09c_869_0.png)

### 提高性能

- 减少上下文切换次数
- 减少数据复制
- 通过使用大传输、智能控制器、轮询来减少中断
- 使用 DMA
- 平衡 CPU、内存、总线和 I/O 性能以获得最高吞吐量

## 补充：I/O 设备分类

- **人类可读：用于与用户通信**
  - 打印机
  - 视频显示终端：
    显示器、键盘、鼠标
- **机器可读：用于与电子设备通信**
  - 磁盘和磁带驱动器
  - 传感器（传感器）
  - 控制器
  - 致动器（传动器）
- **通信：用于与远程设备通信**
  - 数字线路驱动器
  - 调制解调器

### I/O 设备的差异

- **数据速率**
  - 数据传输速率之间可能相差几个数量级
- **应用**
  - 用于存储文件的磁盘需要文件管理软件
  - 用于存储虚拟内存页的磁盘需要特殊的硬件和软件来支持它
  - 系统管理员使用的终端可能具有更高的优先级
- **控制复杂性**
- **传输单元**
  - 数据可能作为终端的字节流传输，或作为磁盘的大块传输
- **数据表示**
  - 编码方案
- **错误条件**
  - 设备对错误的响应不同

### I/O 功能的演进

- 处理器直接控制外围设备
- 添加控制器或 I/O 模块
  - 处理器使用无中断的程序化 I/O
  - 处理器无需处理外部设备的细节
- 带中断的控制器或 I/O 模块
  - 处理器无需花费时间等待 I/O 操作执行
- 直接内存访问
  - 数据块在不涉及处理器的情况下移入内存
  - 处理器仅在开始和结束时参与
- I/O 模块是独立的处理器
- I/O 处理器
  - I/O 模块有自己的本地内存
  - 它本身就是一台计算机
