# 1.1 操作系统做什么？

+   - **操作系统是一种系统程序，充当计算机用户与计算机硬件之间的中介**
+     - 控制应用程序执行的程序
+     - 应用程序/用户与硬件之间的接口

+   - **操作系统的目标：**
+     - **方便性**
+       - 执行用户程序，使解决用户问题更加容易。
+       - 使计算机系统使用更方便
+     - **效率**
+       - 有效利用计算机硬件
+     - **演进能力**
+       - 允许在不影响服务的情况下，有效地开发、测试和引入新的系统功能

# 计算机系统组件

+   1. 硬件
+   提供基本计算资源，如 CPU、内存、I/O 设备。
+   2. 操作系统
+   控制并协调各应用程序和用户对硬件的使用。
+   3. 应用程序
+   定义如何使用系统资源来解决用户的计算问题（编译器、数据库管理系统、数据库系统、文字处理器、视频游戏、商业程序）。
+   4. 用户
+   人、机器、其他计算机

# 1.1.1 用户视角

+   - 根据所使用的界面而有所不同。
+   - 不同操作系统的设计目标
+     - 个人计算机
+       - 易用性、性能
+     - 大型机、小型机
+       - 最大化资源利用率
+     - 工作站
+       - 可用性和资源利用率
+     - 手持计算机
+       - 个人可用性、单位电池电量的性能
+     - 嵌入式计算机
+       - 几乎没有用户视角
