## 补充：调度类型

| 长期调度 | 将进程添加到待执行进程池的决定。 |
| 中期调度 | 将进程添加到部分或完全在主内存中的进程数量的决定。 |
| 短期调度 | 决定哪个可用进程将被处理器执行。 |
| I/O 调度 | 决定哪个进程的挂起 I/O 请求应由可用 I/O 设备处理。 |
