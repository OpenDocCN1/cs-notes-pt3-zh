

## 6.3 Peterson 解决方案

### 解决该问题的初步尝试

- 仅有两个进程 $P_0$ 和 $P_1$
- 进程 $P_i$ 的一般结构（另一进程 $P_j$）

```c
do {
    entry section
    critical section
    exit section
    remainder section
} while (1);
```

- 进程可以共享一些公共变量以同步它们的操作。

### 补充：算法 1

- 共享变量：
  - `int turn;` 初始 `turn = 0`
  - `turn = i` ⇒ $P_i$ 可以进入其临界区

**进程 $P_0$**

```c
do {
  while (turn != 0);
  critical section
  turn = 1;
  remainder section
} while (1);
```

**进程 $P_1$**

```c
do {
  while (turn != 1);
  critical section
  turn = 0;
  remainder section
} while (1);
```

- 互斥？√
- 有空让进？×
- 有限等待？×

### 补充：算法 2

- 互斥？√
- 有空让进？×
- 有限等待？×

**共享变量**

- `boolean flag[2];` 初始 `flag[0] = flag[1] = false`
- `flag[i] = true` ⇒ $P_i$ 准备进入其临界区

**进程 $P_0$**

```c
do {
  while (flag[1]);
  flag[0] := true;
  critical section
  flag[0] = false;
  remainder section
} while (1);
```

**进程 $P_1$**

```c
do {
  while (flag[0]);
  flag[1] := true;
  critical section
  flag[1] = false;
  remainder section
} while (1);
```

### 算法 3（Peterson 算法）

- 结合了算法 1 和算法 2 的共享变量。

**进程 $P_i$**

```c
do {
  flag[i] := true;
  turn = j;
  while (flag[j] and turn = j) ;
  critical section
  flag[i] = false;
  remainder section
} while (1);
```

- 互斥？√
- 有空让进？√
- 有限等待？√

## 6.4 同步硬件

- 许多系统为临界区代码提供硬件支持
- 单处理器——可以禁用中断
  - 当前运行的代码将不会被抢占执行
  - 在多处理器系统上通常过于低效
    - 采用此方法的操作系统可扩展性不强
- 现代机器提供特殊的原子硬件指令
  - 原子 = 不可中断
  - 测试内存字并设置值
  - 交换两个内存字的内容

### Test-and-Set 指令

- 原子地测试并修改一个字的内容

```c
boolean TestAndSet(boolean *target) {
    boolean rv = *target;
    *target = TRUE;

    return rv;
}
```

### 基于 Test-and-Set 的互斥

- 共享数据：
  - `boolean lock = false;`

**进程 $P_i$**

```c
do {
    while (TestAndSet(&lock));
    critical section
    lock = FALSE;
    remainder section
} while(TRUE)
```

- 互斥？√
- 有空让进？√
- 有限等待？×

### Swap 指令

- 原子地交换两个变量。

```c
void Swap(boolean *a, boolean *b) {
    boolean temp = *a;
    *a = *b;
    *b = temp;
}
```

### 基于 Swap 的互斥

- 共享数据（初始化为 false）：
  - `boolean lock;`

**进程 $P_i$**

```c
do {
    key = true;
    while (key == TRUE)
        Swap(&lock, &key);
    critical section
    lock = FALSE;
    remainder section
} while(TRUE)
```

- 互斥？√
- 有空让进？√
- 有限等待？×

**共享数据（初始化为 false）：**

- `boolean lock;`
- `boolean waiting[n];`

**进程 $P_i$**

```c
do {
    waiting[i] = TRUE;    key = TRUE;
    while (waiting[i] && key)  key = TestAndSet(&lock);
    waiting[i] = FALSE;

    critical section

    j = (i+1) % n;
    while ((j != i) && !waiting[j])    j = (j+1) % n;
    if (j == i)  lock = FALSE;
    else  waiting[j] = FALSE;

    remainder section
} while(TRUE);
```

- 互斥？✔
- 有空让进？✔
- 有限等待？✔

### 互斥的机器指令

**优点**

- 适用于任意数量的进程，无论是在单个处理器上还是在共享主存的多处理器上
- 它很简单，因此易于验证
- 它可以用来支持多个临界区

**缺点**

- 忙等待会消耗处理器时间
- 当一个进程离开临界区且不止一个进程在等待时，可能发生饥饿。
- 死锁
  - 如果一个低优先级进程占有临界区，而高优先级进程需要该临界区，高优先级进程将获得处理器并等待该临界区
