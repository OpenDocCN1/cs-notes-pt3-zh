## 4.1 概述

+   - **进程**
+     - 资源所有权——进程被分配一个虚拟地址空间来保存进程映像
+     - 调度/执行——遵循一条执行路径，该路径可能与其他进程交错（交叉）
+     - 这两个特性由操作系统独立处理
+   - 分派称为线程
+   - 资源所有权称为进程或任务

## 概述（续）

+   - 线程，称为轻量级进程（LWP），是CPU利用的基本单元。
+     - 包含线程ID、程序计数器、寄存器组和栈。
+     - 与属于同一进程的其他线程共享其代码段、数据段以及其他操作系统资源，如打开的文件和信号。
+   - 传统（或重量级）进程只有单一的控制线程。
+   - 如果进程有多个控制线程，它可以同时执行多个任务。

## 单线程与多线程进程

![](img/9321d6c42b8369e67ceb1f1d7e27b09c_254_0.png)

应用程序通常实现为具有多个控制线程的独立进程。

## 线程的优点

+   - 响应性
+   - 资源共享
+   - 经济性
+   - 多处理器架构的利用

## 补充：**线程使用示例**
在单用户多处理系统中

+   - **前台到后台工作**
+     - 网页浏览器
+   - **异步处理**
+     - Word，自动保存
+   - **加速执行**
+     - 数据接收、操作、保存、输出
+   - **模块化程序结构**

## 补充：线程

+   - 交换进程涉及交换该进程的所有线程
+   - 终止进程会终止该进程内的所有线程

因为所有线程共享同一地址空间

## 补充：线程状态

+   - 运行、就绪、等待
+   - 与线程状态变化相关的操作
+     - 生成：生成另一个线程
+     - 阻塞
+     - 解除阻塞
+     - 完成：释放寄存器上下文和栈

## 4.2 多线程模型

+   - 用户线程
+   - 内核线程
+   - 三种常见的线程实现类型
+     - 多对一
+     - 一对一
+     - 多对多

## 补充：**用户线程**

+   - 所有线程管理都由应用程序完成
+   - 内核不知道线程的存在
+   - 用户线程在内核之上受支持，并由用户级线程库实现。
+   - 该库为线程创建、调度和管理提供支持，无需内核支持。
+   - 三种主要的线程库：
+     - POSIX Pthreads
+     - Win32线程
+     - Java线程
