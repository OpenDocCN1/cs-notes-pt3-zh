

## 交换空间使用

- 取决于所使用的内存管理算法。
  - 使用交换空间保存整个进程映像
  - 存储被挤出内存的页面
- 所需交换空间的大小取决于
  - 物理内存的大小
  - 其所支持的虚拟内存量
  - 虚拟内存的使用方式

## 交换空间位置

- 交换空间可以位于以下两个位置之一：
  - 从普通文件系统中划分出来，一个大文件
  - 在单独的磁盘分区中，原始分区
- 一个大文件
  - 可以使用普通文件系统例程来创建它、命名它并分配其空间。
  - 效率低下
- 原始分区
  - 交换空间存储管理器进行分配和释放
  - 在磁盘分区期间创建固定量的交换空间；添加更多交换空间需要重新分区磁盘。

## 交换空间管理

- 4.3BSD 在进程启动时分配交换空间；保存 *text segment*（程序）和 *data segment*。
- 内核使用 *swap maps* 来跟踪交换空间的使用情况。
- Solaris 2 仅在页面被强制移出物理内存时才分配交换空间，而不是在虚拟内存页面首次创建时。

## I/O 设备控制

- 处理器向控制器发出命令和数据以完成 I/O 传输。
- I/O 指令控制设备
- 设备具有地址，由以下方式使用
  - 直接 I/O 指令
  - 内存映射 I/O

## I/O 端口

- **4 个寄存器**
  - 状态：包含可由主机读取的位。空闲、忙碌、就绪、错误
  - 控制：可由主机写入以启动命令或更改设备的模式。
  - 数据输入：由主机读取以获取输入
  - 数据输出：由主机写入以发送输出

数据寄存器通常为 1 到 4 字节大小。

一些控制器具有 FIFO 芯片以扩展控制器的容量，超出数据寄存器的大小。FIFO 芯片可保存若干字节的输入或输出数据。

## 执行 I/O 的技术

- **程序化 I/O**
  - 处理器在操作完成前处于忙等待状态
- **中断驱动 I/O**
  - 发出 I/O 命令
  - 处理器继续执行指令
  - I/O 模块完成后发送中断
- **直接内存访问（DMA）**
  - DMA 模块控制主内存与 I/O 设备之间的数据交换
  - 整个块传输完成后处理器才会被中断
