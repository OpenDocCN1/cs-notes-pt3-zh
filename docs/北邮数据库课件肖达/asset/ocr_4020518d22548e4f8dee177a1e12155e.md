# SQL Server的数据库备份和恢复

+   - 例：恢复“学生-课程数据库”至2009年4月1日前的状态
+     - 恢复数据库
+     - 恢复事务日志1
+     - 恢复事务日志2

```
RESTORE DATABASE StudentCourse
FROM MyBackup1
WITH NORECOVERY
```

```
RESTORE LOG StudentCourse
FROM MyBackupLog1
WITH NORECOVERY
```

```
RESTORE LOG StudentCourse
FROM MyBackupLog2
WITH RECOVERY, STOPAT = '4/1/2009'
```
