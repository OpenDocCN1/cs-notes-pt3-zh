# 关系数据模型的数据结构（续）

+   - **主码（Key）**
+     - 表中的某个属性组，它可以唯一确定一个元组。
+   - **域（Domain）**
+     - 属性的取值范围。
+   - **分量**
+     - 元组中的一个属性值。
+   - **关系模式**
+     - 对关系的描述
+     - 关系名（属性1，属性2，…，属性n）
+     - 学生（学号，姓名，年龄，性别，系，年级）
