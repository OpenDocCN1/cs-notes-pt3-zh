[例7] 查询至少选修1号课程和3号课程的学生号码

首先建立一个临时关系K：

| Cno |
| --- |
| 1 |
| 3 |

然后求： π_Sno,Cno(SC) ÷ K

| Sno | Cno |
| --- | --- |
| 200215121 | 1 |
| 200215121 | 2 |
| 200215121 | 3 |
| 200215122 | 2 |
| 200215122 | 3 |

200215121象集 {1, 2, 3}
200215122象集 {2, 3}
K={1, 3}
于是： π_Sno,Cno(SC) ÷ K = {200215121}
