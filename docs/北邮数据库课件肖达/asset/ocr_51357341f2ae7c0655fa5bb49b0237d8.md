# 带有EXISTS谓词的子查询(续)

+   - 用嵌套查询
+   
+     ```sql
+     SELECT Sname
+     FROM Student
+     WHERE EXISTS
+           (SELECT *
+            FROM SC
+            WHERE Sno=Student.Sno AND Cno='1');
+     ```

+   - 用连接运算
+   
+     ```sql
+     SELECT Sname
+     FROM Student, SC
+     WHERE Student.Sno=SC.Sno AND SC.Cno='1';
+     ```
