# SQL Server的权限管理

对象权限

| 对象 | 操作类型 |
| --- | --- |
| 表 | SELECT、INSERT、UPDATE、DELETE、REFERENCES |
| 视图 | SELECT、UPDATE、INSERT、DELETE |
| 存储过程 | EXECUTE |
| 列 | SELECT、UPDATE |

语句权限

|  |  |
| CREATE DATABASE | 创建数据库 |
| CREATE TABLE | 创建表 |
| CREATE VIEW | 创建视图 |
| CREATE RULE | 创建规则 |
| CREATE DEFAULT | 创建默认值 |
| CREATE PROCEDURE | 创建存储过程 |
| BACKUP DATABASE | 备份数据库 |
| BACKUP LOG | 备份日志 |
