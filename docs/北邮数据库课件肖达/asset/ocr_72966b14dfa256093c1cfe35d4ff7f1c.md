# 违约处理(续)

【例4】 显式说明参照完整性的违约处理示例

```
CREATE TABLE SC
    (Sno  CHAR(9)  NOT NULL,
     Cno  CHAR(4)  NOT NULL,
     Grade  SMALLINT,
     PRIMARY KEY (Sno, Cno),
     FOREIGN KEY (Sno) REFERENCES Student(Sno)
         ON DELETE CASCADE    /*级联删除SC表中相应的元组*/
         ON UPDATE CASCADE,   /*级联更新SC表中相应的元组*/
     FOREIGN KEY (Cno) REFERENCES Ccourse(Cno)
         ON DELETE NO ACTION
         /*当删除course表中的元组造成了与SC表不一致时拒绝删除*/
         ON UPDATE CASCADE
         /*当更新course表中的cno时，级联更新SC表中相应的元组*/
    );
```
