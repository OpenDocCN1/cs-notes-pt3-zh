# 3. 交（Intersection）

+   - **R和S**
+     - 具有相同的目 n
+     - 相应的属性取自同一个域

+   - **R∩S**
+     - 仍为 n 目关系，由既属于 R 又属于 S 的元组组成

R∩S = { t | t ∈ R ∧ t ∈ S }

| R |  |  |
|---|---|---|
| A | B | C |
| a₁ | b₁ | c₁ |
| a₁ | b₂ | c₂ |
| a₂ | b₂ | c₁ |

| S |  |  |
|---|---|---|
| A | B | C |
| a₁ | b₂ | c₂ |
| a₁ | b₃ | c₂ |
| a₂ | b₂ | c₁ |

| R∩S |  |  |
|---|---|---|
| A | B | C |
| a₁ | b₂ | c₂ |
| a₂ | b₂ | c₁ |
