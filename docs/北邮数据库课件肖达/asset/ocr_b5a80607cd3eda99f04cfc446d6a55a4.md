# 关系数据模型的数据结构（续）

+   - **关系（Relation）**
+     - 一个关系对应通常说的一张表
+   - **元组（Tuple）**
+     - 表中的一行即为一个元组
+   - **属性（Attribute）**
+     - 表中的一列即为一个属性，给每一个属性起一个名称即属性名
