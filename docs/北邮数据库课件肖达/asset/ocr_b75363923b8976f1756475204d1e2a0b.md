# 数据库管理员(DBA)

+   - 职责
+     - 1、决定数据库中的信息内容和结构
+     - 2、决定数据库的存储结构和存取策略
+     - 3、定义数据的安全性要求和完整性约束条件
+     - 4、监控数据库的使用和运行
+     - 5、数据库的改进和重组

+   - Oracle的官方网站上对DBA的说明
+     - Oracle DBA专家可以跟上如今日趋复杂的系统环境要求。最好的DBA们都在幕后工作，他们小心地维护着系统，使得系统可以每天都平稳地运转，并且防止意外灾难的发生。这项艰巨的任务需要对Oracle数据库的结构和运行方式有着广泛且深入的了解，并且有丰富的实战经验。
