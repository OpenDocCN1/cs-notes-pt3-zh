# 带有EXISTS谓词的子查询(续)

+   - 用NOT EXISTS谓词表示：

```
SELECT DISTINCT Sno
FROM SC SCX    //代表学生
WHERE NOT EXISTS
      (SELECT *
       FROM SC SCY    //代表课程
       WHERE SCY.Sno = '200215122' AND
             NOT EXISTS
             (SELECT *
              FROM SC SCZ
              WHERE SCZ.Sno=SCX.Sno AND
                    SCZ.Cno=SCY.Cno));
```
