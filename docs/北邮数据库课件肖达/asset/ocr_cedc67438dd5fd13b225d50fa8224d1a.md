# 一、等值与非等值连接查询

+   - 等值连接：连接运算符为 =

[例33] 查询每个学生及其选修课程的情况

```
SELECT Student.*, SC.*
FROM   Student, SC
WHERE  Student.Sno = SC.Sno;
```
