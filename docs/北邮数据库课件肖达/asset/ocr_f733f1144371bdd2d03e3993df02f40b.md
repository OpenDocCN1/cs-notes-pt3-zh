# 角色管理

+   > 用角色统一授予和管理权限
+   - 服务器角色

| 固定服务器角色名 | 角色的权限 |
|---|---|
| Sysadmin | 可在SQL Server 中执行任何操作 |
| Serveradmin | SQL Server服务器范围内的配置 |
| setupadmin | 增加、删除连接服务器，并执行某些系统存储过程 |
| Securityadmin | 管理管理数据库登录 |
| processadmin | 管理SQL Server进程 |
| dbcreator | 创建数据库并修改数据库 |
| diskadmin | 管理磁盘文件 |
| Bulkadmin | 执行BULK INSERT（大容量插入）操作 |
