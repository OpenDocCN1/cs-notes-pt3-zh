# 参照完整性定义(续)

例如，关系SC中一个元组表示一个学生选修的某门课程的成绩，（Sno，Cno）是主码。Sno，Cno分别参照引用Student表的主码和Course表的主码

# [例3] 定义SC中的参照完整性

```
CREATE TABLE SC
(Sno  CHAR(9) NOT NULL,
Cno  CHAR(4) NOT NULL,
Grade  SMALLINT,
PRIMARY KEY (Sno, Cno),  /*在表级定义实体完整性*/
FOREIGN KEY (Sno) REFERENCES Student(Sno),
/*在表级定义参照完整性*/
FOREIGN KEY (Cno) REFERENCES Course(Cno)
/*在表级定义参照完整性*/
);
```
