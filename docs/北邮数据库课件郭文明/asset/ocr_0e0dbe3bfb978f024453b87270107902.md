# 3.2.2 事务的调度

+   - 事务的调度：DBMS在处理用户提交事务时的策略，即事务调度。事务的执行顺序称为一个调度，表示事务的指令在系统中执行的时间顺序。  
+     - 一组事务的调度必须保证
+       - 包含了所有事务的操作指令
+       - 一个事务中指令的顺序必须保持不变。
+     - 串行调度
+       - 在串行调度中，属于同一事务的指令紧挨在一起。
+       - 对于有n个事务的事务组，可以有n！个有效调度。
+     - 并行调度
+       - 在并行调度中，来自不同事务的指令可以交叉执行。
+       - 当并行调度等价于某个串行调度时，则称它是正确的。
