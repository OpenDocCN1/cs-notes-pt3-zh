# 1.3.2 数据定义

+   - SQL的数据定义功能包括对模式（Schema）、表（关系，Table）、视图（View）和索引（Index）的创建、删除和修改操作。如下表所示。

| 操作对象 | 操作方式 |  |  |
|---|---|---|---|
|  | 创建 | 删除 | 修改 |
| 模式 | `CREATE SCHEMA` | `DROP SCHEMA` |  |
| 表 | `CREATE TABLE` | `DROP TABLE` | `ALTER TABLE` |
| 视图 | `CREATE VIEW` | `DROP VIEW` |  |
| 索引 | `CREATE INDEX` | `DROP INDEX` |  |
