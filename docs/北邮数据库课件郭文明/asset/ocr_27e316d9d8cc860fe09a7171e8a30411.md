# 3.1.4 错误处理

Whenever语句使我们在遇到出错和其他情况时，控制程序的运行：

```
EXEC SQL WHENEVER 条件 动作
```

条件可以是

+   - SQLERROR： 执行错误，如连接不成功等；
+   - NOT FOUND： 没有数据，如游标指针到头或到尾等；
+   - SQLWARNING： 警告错误。

动作可以是

+   - CONTINUE： 继续正常流程；
+   - GOTO 标号： 转移到标号行继续执行；
+   - STOP： 结束程序，撤消当前事务，并断开数据库连接；
+   - DO 函数： 触发一个对已经命名的函数的调用。
