# 4.3.1.2 ORACLE数据库碎片

- 分裂成了碎片的表空间

表空间变成碎片是由于运行错误或者表空间中的数据库对象的无计划撤消和重建造成的。表空间不会由于任何行级动作而变成碎片。

Oracle尽力帮助DBA进行空间分配和管理。例如假设一开始表空间有四个10MB表段，现在删除其中的两个表，这两个表都位于表空间的“中间”位置，SMON后台进程自动地把两个10MB的区间聚合为一个20MB区间。如果要删除的两个表不是位于表空间的“中间”位置，则形成表空间碎片。

表空间碎片会导致：表空间中的空间被分离且不能有效地使用。

DBA_FREE_SPACE和DBA_EXTENTS数据字典可以查询

数据库的每个表空间中有多少自由空间是可用的和最大自由区间的容量以及每个表空间中自由区间的数目。
