# 2.2.1 安全性

+   - 安全性控制保护数据库以防止不合法的使用所造成的数据泄露和破坏。其基本措施是存取控制：确保只授权给有资格的用户访问数据库的权限，同时令所有未被授权的人员无法接近数据。
+   - Grant语句是表所有者授予一个或一类用户访问表的各种权利的SQL命令。访问列的安全性可通过视图实现。Revoke语句撤消对一个表的权限。
+   - 表的所有者自动拥有所有权限，而且不能被取消。
