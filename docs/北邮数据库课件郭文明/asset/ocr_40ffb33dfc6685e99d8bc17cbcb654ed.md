# 3.4 中间件

+   - 多层驱动程序：多层驱动程序只处理应用程序的 ODBC函数调用和数据转换，它将SQL语句传递给数据源服务器，由DBMS解释执行SQL语句。SQL Server等数据库的DBS就属于这种。使用多层驱动程序，在数据库服务器上实现对数据库的各种操作，在网络中只传输用户请求和数据库处理结果。
+   - 应用程序的主要功能是:调用ODBC函数，递交SQL语句给DBMS，检索出结果并进行处理。应用程序的操作可包括：连接数据库；向数据库发送SQL语句；为SQL语句执行结果分配存储空间，定义所读取数据的格式；处理错误；向用户提交处理结果；请求事务的提交和回退操作；断开与数据源的连接。
