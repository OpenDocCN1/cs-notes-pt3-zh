# 3.1.5 指示变量

+   - 不管读取数据还是更新数据，都可以用指示变量的值-1代表空值。
+   
+     例：要将表 customers 的某一行的 discnt 值设置为空值，可以这样写：

```
cd_ind=-1
exec sql update customers
  set discnt=:cust_discnt
      indicator :cd_ind
  where cid=:cust_id;
```

+   - 实际上还可以进一步扩展指示变量的值，例如 DB2 UDB 的产品中，如果指示变量的值为-2，意味着是由于一个错误而不是数据库中存储的值而使检索到的值为空值。
