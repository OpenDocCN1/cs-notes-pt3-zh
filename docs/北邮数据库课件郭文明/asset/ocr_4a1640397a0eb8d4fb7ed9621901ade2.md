# 1. 4. 2. 3 PL/SQL、用户定义函数和方法

+   - 定义包含方法的对象

```
CREATE TYPE typename AS OBJECT
(attrname datatype [,attrname datatype...]
MEMBER FUNCTION methodname
[(param type [,param type...])]
RETURN datatype,
[,MEMBER FUNCTION methodname
[(param type [,param type...])]
RETURN datatype,...]);
```

在前面对象类型的基础上增加了MEMBER FUNCTION语句，定义对象的成员函数，即方法。
