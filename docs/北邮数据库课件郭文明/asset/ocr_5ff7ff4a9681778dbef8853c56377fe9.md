# 1.3.3.4 高级SQL语法

例：检索至少订购了一件价格低于0.5的商品的顾客姓名。

```
select distinct cname from
(orders o join products p on o.pid=p.pid)
join customers c on o.cid=c.cid
where p.price<0.5;
```

注：ORACLE仅提供左连和右连，而且语法与标准SQL也不同：

```
SELECT ... FROM T1,T2
WHERE [T1.c1[(+)]=T2.c2 | T1.c1=T2.c2[(+)] ] AND condition
```

T2保留所有行

与T1连不上的用NULL
