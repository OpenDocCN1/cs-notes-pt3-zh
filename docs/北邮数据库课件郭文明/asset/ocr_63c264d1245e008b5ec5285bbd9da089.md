# 1.4.1.2 类和类层次

+   - 类层次可以动态扩展，一个新的子类能从一个或多个已有类导出。
+   - 面向对象数据库中，类是“型”，对象是某一类的一个“值”。类属性的定义域可以是任何类（基本类或包含属性和方法的一般类）。
+   - 面向对象数据库模式是类的集合，类可能有多个类层次。

> 例如：一个学校应用的面向对象数据库，其中有教职员工和学生两个类，这两个类都有身份证号、姓名、性别、住址等属性，也有相同的方法和消息。统一定义教职员工和学生的公共属性、方法和消息部分，称为一个类“人”；分别定义各自的特殊属性、方法和消息部分，分别称为教职员工类和学生类，教职员工类和学生类定义为人的子类。
