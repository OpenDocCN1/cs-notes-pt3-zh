# 1.2.3关系代数综合例子

例4 找出没有被任何一个在北京的顾客通过在上海的代理商订购的所有商品。

在北京的顾客通过在上海的代理商订购的商品：
π_pid((π_cid(σ_city='北京'(C))∞O)∞σ_city='上海'(A))

从所有商品中剔除以上商品：
π_pid(P) — π_pid((π_cid(σ_city='北京'(C))∞O)∞σ_city='上海'(A))
