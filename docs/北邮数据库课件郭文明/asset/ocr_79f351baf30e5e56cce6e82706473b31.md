# 3.3.6 分布式数据库体系结构

+   - 基本特性
+     - 分布性：数据存储在不同场地上。与集中式数据库不同。
+     - 逻辑整体性：数据逻辑上是相互联系的一个整体。与分散在计算机网络不同站点上的一组没有相互联系的本地数据库区别开来。
+   - 定义
+     - DDBS(Distributed Data Base)是一个数据集合，这些数据，分布在计算机网络的不同计算机上，网络中每个节点具有独立处理的能力，可以执行局部应用，同时每个节点也能通过网络通讯支持全局应用。

分布式数据库强调场地自治性（局部应用）以及自治场地之间的协作性（全局应用）。

> “在自治的节点之间协同工作”
