# 3.1.3 通讯区

+   - SQLCODE：SQLCODE是SQLCA的结构一个成员。它是一个每次执行完SQL语句都被更新的整型变量。  - 如果执行成功，SQLCODE为0；  - 如果语句没有产生错误，但遇到了没有数据，SQLCODE为100；  - 除去成功返回0或没有数据返回100的情况，其他都是某种错误并返回一个负数。

+   - SQL-99和X/OpenSQL等标准提倡用SQLSTATE取代SQLCODE检测SQL的执行情况，并将SQLSTATE设置为标准，但在产品中还不一定支持。例如ORACLE中，预处理程序运行时必须设置MODE=ANSI才能支持SQLSTATE。
