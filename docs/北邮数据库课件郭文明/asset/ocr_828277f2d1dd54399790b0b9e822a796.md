# 1.3.3.2 子查询

NOT EXISTS 确实为我们带来了一些新的功能。not exists 能被用来实现关系代数的 MINUS 运算。如果 R 和 S 是两个兼容表（属性相同 A1…An），R-S 用 SQL 计算：

```
select A1…An from R
  where not exists (select * from S
    where S.A1=R.A1 and ……… and S.An=R.An);
```

例：找出没有通过代理商a03订货的顾客cid.

关系代数： π_cid(0) — π_cid(σ_aid=‘a03’(0))

```
select distinct cid from orders x where not exists
  (select * from orders where cid=x.cid and aid=‘a03’);
```
