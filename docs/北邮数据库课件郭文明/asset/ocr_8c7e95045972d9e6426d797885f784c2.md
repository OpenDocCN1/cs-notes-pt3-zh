# 2.2.1.3 角色

+   - ORACLE预先定义的8种角色:
+     CONNECT:连接到数据库,最终用户角色.
+     RESOURCE:申请资源创建对象,开发人员角色.
+     DBA:具有全部系统权限,可以创建用户.
+     IMP_FULL_DATABASE:装入全部数据库内容.
+     EXP_FULL_DATABASE:卸出全部数据库内容.
+     DELE_CATALOG_ROLE:能删除审计表中记录.
+     SELECT_CATALOG_ROLE:查询数据字典.
+     EXECUTE_CATALOG_ROLEE:执行过程和函数.
