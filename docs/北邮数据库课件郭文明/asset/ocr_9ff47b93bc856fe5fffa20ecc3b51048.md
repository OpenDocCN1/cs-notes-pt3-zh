# 1.2.1传统的集合运算

+   - 交 (Intersection): 关系R与关系S的交记作：
+     R∩S={ t | t∈R∧t∈S }
+     其结果仍为n目关系，由既属于R又属于S的元组组成。关系的交可以用差来表示，即R∩S=R-(R-S)。
+   - 广义笛卡尔积 (Extended Cartesian Product): 两个分别为n目和m目的关系R和S的广义笛卡尔积是一个(n+m)列的元组的集合。元组的前n列是关系R的一个元组，后m列是关系S的一个元组。若R有k1个元组，S有k2个元组，则关系R和关系S的广义笛卡尔积有k1×k2个元组。记作：
+     R×S={trts | tr∈R∧ts∈S }
