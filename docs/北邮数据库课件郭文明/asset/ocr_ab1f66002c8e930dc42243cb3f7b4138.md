# 5.1.1 规划

+   - 可行性分析应从经济方面、技术方面、系统运行方面（管理体制、人员的适应性及法律法规）进行分析和评价。**可行性研究报告的内容包括：**
+     - 1) 原来系统概况。包括企业目标、规模、组织结构、人员、设备、效益等。
+     - 2) 原来系统存在的主要问题和主要信息要求。
+     - 3) 待开发系统的总体方案（如前所述）。
+     - 4) 经济可行性分析包括系统的投资、运行费用、经济效益及社会效益。
+     - 5) 技术可行性分析主要包括对技术的评估。
+     - 6) 系统可行性分析分析系统运行对管理思想、管理体制和变革的要求，系统运行和有关法律法规的相互作用。
+     - 7) 结论。对可行性研究的简要总结。
