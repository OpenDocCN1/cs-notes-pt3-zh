# 4. 3. 3. 3 ORACLE热物理备份

+   - 热备份要求对Oracle和操作系统具有较高的专业知识。由于热备份的复杂性，必须事先测试备份策略。只有从一个测试系统中的大量失败中恢复出来时，热备份系统才被认为是可靠的。
+   - Oracle提供了两种热备份方法，一种用于命令行UNIX环境，另一种用于桌面（Windows）环境。

# - 热备份复杂性

Oracle基本存储单元是数据块。数据块中存储数据，数据块头存储包含在块中的数据的信息。数据库处于联机状态时，备份程序和Oracle可能都工作于同一个块上。假定当Oracle写新的数据和更新数据块头时，备份程序仅完成了对块头部分的备份，那么完成备份之后，该块具有老的块头和新的数据。这个数据块成为不纯的数据块。
