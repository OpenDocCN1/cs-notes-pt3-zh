# 外连接

• 定义1.2.5 外连接　表R（A1, A2, ..., An, B1, B2, ..., Bk）和S（B1, B2, ..., Bk, C1, C2, ..., Cm）的外连接R∞oS，行t属于表R∞oS，如果下列情况之一发生：

+   1）可连接的行u，v分别在R和S中，有 u[Bi]=v[Bi]（0<=i<=k）成立，此时 t[A]=u[A], t[B]=u[B], t[C]=v[C]。

+   2）表R中的一个行u使得S中没有一个可以与之连接的行，此时，t[A]=u[A], t[B]=u[B], t[C]=null。

+   3）表S中的一个行v使得R中没有一个可以与之连接的行，此时，t[A]=null, t[B]=v[B], t[C]=v[C]。
