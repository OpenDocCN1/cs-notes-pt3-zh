# 2.2.1.4 权限授予

+   - GRANT [系统权限|角色]
+     TO [用户|PUBLIC|角色]
+     [WITH ADMIN OPTION];
+     WITH ADMIN OPTION允许权限复制给其他用户.
+   - GRANT [ALL |对象权限[,对象权限...]|角色]
+     ON [TABLE] tablename|viewname
+     TO [PUBLIC|username[,username...]|角色]
+     [WITH GRANT OPTION];
+   - 系统权限、对象权限和角色均可用响应的 REVOKE语句收回.
