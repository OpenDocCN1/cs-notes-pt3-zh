# 1. 4. 2. 2 ORACLE集合类型

+   - 利用表的乘积可以消除表的嵌套。

显示职工号及其家属名：

```
select e.eid,d.name from employees e,
    table(e.dependents) d;
```

没有家属的eid不显示

```
select e.eid,d.name from employees e,
    table(e.dependents) (+) d;
```

(+)表示外连，没有家属的eid也显示

显示具有最大家属名的职工号及其家属名：

```
select e.eid,d1.name from employees e,
    table(e.dependents) d1 where d1.name=
    (select max(d2.name)
        from table(e.dependents) d2);
```
