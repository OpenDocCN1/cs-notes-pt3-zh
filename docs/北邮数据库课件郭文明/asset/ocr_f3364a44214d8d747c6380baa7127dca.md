# 5.2.1 ER模型的概念

+   - **弱实体**：如果实体的所有实例都通过一个联系 R 依赖于另一个实体的实例而存在，而且该实体标识码的部分或全部从其依赖的实体（父实体）中获得，那末这个实体就称为弱实体，而另一个实体称为强实体。
+   
+     例如人事系统中，社会关系实体是以职工实体存在为前提，社会关系实体是弱实体。

+   - **泛化层次**：泛化层次（generalization hierarchy）也称泛化联系（generalization relationship），是对对应于对象关系模型继承特性一个概念。其思想是多个有公共属性的实体可以泛化为一个更高层次的超类型实体，相反一个一般化实体可以分解成低层次的子类型实体。
