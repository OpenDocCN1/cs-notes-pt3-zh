# 1. 4. 2. 3 PL/SQL、用户定义函数和方法

+   - 对象成员函数的定义

```
CREATE [OR REPLACE] TYPE BODY typename [AS|IS]
  MEMBER FUNCTION methodname [(param type...)]
    RETURN type IS
    BEGIN    --PL/SQL语句开始
      statements
    END;    --PL/SQL语句结束
  [MEMBER FUNCTION methodname [(param type...)]
    RETURN type is
    BEGIN......]
END;
```

对于不同的DBMS，对象成员函数的处理过程使用的语句可能不同，带来移植的通用问题。
