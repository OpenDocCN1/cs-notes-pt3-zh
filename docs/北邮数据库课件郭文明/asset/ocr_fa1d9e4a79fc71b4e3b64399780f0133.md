# 3.1.1 C语言中嵌入式SQL

+   - 区分SQL语句与C语言语句
+     嵌入的SQL语句以 **EXEC SQL** 开始，以分号(;)结束。
+     例: exec sql select came,discnt
+     into :cust_name,:cust_discnt
+     from customers where cid=:cust_id;
+   - 嵌入SQL语句与C语言之间的数据传递
+     宿主变量(宿主变量出现于SQL语句中时，前面加 (:) 以区别列名)
+     C变量既可以用在C语句中，也可用在SQL语句中，用来在两者之间传递数据。
