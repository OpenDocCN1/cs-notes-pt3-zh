# 算法2 快速转置法 { O(n+t) }

引入两个辅助向量：

+   - num[1,...,a.n]: a中每列的非零元素个数
+   - cpot[1,...,a.n]: a中每列的第一个非零元素在b中的位置

a中的列号

| col | num[col] | cpot[col] |
|---|---|---|
| 1 | 2 | 1 |
| 2 | 1 | 3 |
| 3 | 2 | 4 |
| 4 | 2 | 6 |
| 5 | 0 | 8 |
| 6 | 1 | 8 |

转置

cpot[1]=1
cpot[col]=cpot[col-1]+num[col-1]
(2≤col≤n)
