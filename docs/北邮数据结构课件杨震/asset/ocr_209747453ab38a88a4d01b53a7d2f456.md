任何一个非空广义表 LS = ( α1, α2, ..., αn ) 均可分解为
表头 Head(LS) = α1 和
表尾 Tail(LS) = ( α2, ..., αn ) 两部分。

例如： D = ( E, F ) = ( (a, (b, c)), F )
Head( D ) = E      Tail( D ) = ( F )

Head( E ) = a      Tail( E ) = ( ( b, c ) )

Head( ( ( b, c ) ) ) = ( b, c )  Tail( ( ( b, c ) ) ) = ( )

Head( ( b, c ) ) = b      Tail( ( b, c ) ) = ( c )

Head( ( c ) ) = c      Tail( ( c ) ) = ( )
