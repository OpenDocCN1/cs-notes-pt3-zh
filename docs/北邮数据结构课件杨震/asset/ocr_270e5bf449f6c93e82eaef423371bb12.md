# 11.2.2 分配算法 （申请容量为n的存储空间）

+   假设采用首次分配法，为避免过多碎片，设一常数e
+   m-n ≤ e 将大小为m的块全部分出
+   > e 分出n大小，剩余留下

+   为使分配后剩余的小块均匀分布在链表中，可利用空间链表的头指针pav在每次分配之后，指向被分配块的后继块

+   假设header和footer各占一个字的空间

# [算法思想]

从p=pav开始查找一块容量≥n的空闲块，结果有三种情况

+   1) p^.size ≥n且p^.size -n≤e ： 分配p整块

+   置tag=1

+   从可利用空间表中删除此块

+   pav指向被分配块的后继块
