# 二维数组

```
elemtype a[1..m][1..n];
```

a = 
⎡ a11 a12 a13 … a1n ⎤
⎢ a21 a22 a23 … a2n ⎥
⎢  :   :   :   …   :  ⎥
⎣ am1 am2 am3 … amn ⎦
 m×n

![](bbox=[0.62, 0.22, 0.92, 0.75])

loc(a[i,j]) = b + [(i-1)*n + (j-1)]*c

= C0 + C1*i + C2*j

+   C2 = c
+   C1 = n* C2
+   C0 = b - C1 - C2

> 注： Pascal、C语言以行序为主序
> Fortran 语言以列序为主序
