# 多路(k路)平衡归并

# [通过简单比较进行归并存在的问题]

设记录总数为n，初始归并段的个数为m，

从k个记录中选择一个关键字最小的记录时的比较次数为c

则s趟内部归并总的比较次数为：

C=s×c(n-1)=⌈logₖm⌉×c×(n-1)=⌈log₂m/ log₂k⌉×c×(n-1)

矛盾

+   k↑， s↓， 可减少I/O次数；
+   k↑， c=(k-1)↑， 归并效率↓

![](bbox=[0.68, 0.52, 0.92, 0.68])

# [解决矛盾的方法]

——利用“败者树”选关键字最小的记录

此时c= log₂k

则 C=⌈log₂m⌉(n-1)， 与k无关
