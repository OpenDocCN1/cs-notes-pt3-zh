# [中序遍历算法]

```
void Inorder (BiTree T,
    void(*visit)( BiTree ))
{
    if (T)
    {
        Inorder(T->lc,visit);
        visit(T);
        Inorder(T->rc,visit);
    }
}
```

# [后序遍历算法]

```
void Postorder(BiTree T,
void(*visit)( BiTree ))
if (T)
{
    Postorder(T->lc,visit);
    Postorder(T->rc,visit);
    visit(T);
}
```
