# 例【人口问题】

已知：
每个人的净生殖率为r（净生殖率=出生率-死亡率）；
时间t；
t=0时的人口为N(0)；
求：
t时间的人口数。

+   1. 所求量  N(t).
+   2. 模型  1/N dN/dt = r.
+   3. 求解模型的算法  N(t) = N(0)e^{rt}.
+   4. 编制计算机程序

```
#include <cmath>  //for std::exp()
int population(int ini, double birth_rate,
               double time_at)
{
    return ini*std::exp(birth_rate*time_at);
}
```
