# 4.1 串的概念和基本操作

**串（字符串）**：是由零个或多个字符组成的有限序列。

记作：`s = ‘a₀a₁…aₙ₋₁’`　`(n≥0)`

串是特殊的线性表，数据元素是单个字符。

**串长**：串中字符的个数 n。

**子串和主串**：串中任意个连续的字符组成的子序列称为该串的子串。包含子串的串称为主串。

**串相等**：两个串长度相等，且对应位置的字符都相等。

**空串和空格串**：空串不包含任何字符，表示为 `φ`；空格串由一个或多个空格组成，如 ‘　’。

**C语言**：以 `\0` 结尾的字符数组。

**C++**：C语言中的数组继续有效，还提供 `std::string` 类。
