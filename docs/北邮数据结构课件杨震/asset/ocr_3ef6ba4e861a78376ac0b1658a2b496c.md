# 算法描述

```
void get_nextval(int *nextval, char const *p)
{
    int j=1; k=0; nextval[1]=0;
    while (j < strlen(p))
    {
        if (k==0 || p[j]==p[k])
            if (p[++j] != p[++k])
                nextval[j]=k;
            else
                nextval[j]=nextval[k];
        else
            k=nextval[k];
    }
}
```
