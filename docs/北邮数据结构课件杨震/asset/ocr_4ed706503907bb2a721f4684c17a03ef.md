# [哈夫曼树的存储结构]

+   - 初始有n个叶子结点，则构造出的哈夫曼树(属于严格二叉树)共有2n-1个结点。
+   - 用大小为2n-1的向量存储哈夫曼树—顺序存储。

| | 0 | 1 | i | j | n-1 | n | 2n-2 |
|---|---|---|---|---|---|---|---|
| weight |  |  |  |  |  |  |  |
| lch | 0 | 0 | ..... |  | 0 |  |  |
| rch | 0 | 0 | ..... |  | 0 |  |  |
| parent |  |  |  |  |  |  |  |

注：用0表示空指针
