# 顺序表的构造函数与析构函数

```
tempate<typename T>
struct Vector {
    T* elem; // T为数据元素    向量的基地址
    int size;                向量中实际元素个数
    int capacity;            向量能容纳的元素个数
    Vector(int n=0; T const& t=T())
    :elem(0),size(0),capacity(0)
    {
        elem=(T*)malloc(n*sizeof(T));
        uninitialized_fill(elem, elem+n,t);
        size=capacity=n;
    }
    virtual ~Vector() {  free(elem);}
}
```
