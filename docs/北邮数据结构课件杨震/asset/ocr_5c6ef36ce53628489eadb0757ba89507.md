# 【算法描述】

```
int binsearch ( int K, int v[ ], int n )
{
    int low, high, mid;
    low = 1;
    high = n;
    while ( low <= high )
    {
        mid = ( low + high ) / 2;
        if ( K < v[mid] )
            high = mid - 1;
        else if ( K > v[mid] )
            low = mid + 1;
        else /* 找到了匹配的值*/
            return mid;
    }
    return -1; /* 没有查到*/
}
```
