# [数据结构] 设图中的顶点个数为n

+   - 主： 邻接矩阵G[n][n] (或者邻接表)
+   - 辅：
+     - 一维数组S[1..n]: 记录相应顶点是否已被确定最短距离
+     - 一维数组D[1..n]: 记录源点到相应顶点路径长度
+     - 一维数组P[1..n]: 记录相应顶点的双亲顶点

例中各辅助数据结构初值如下：

| S |  |
|---|---|
| 1 | FALSE |
| ... |  |
| n | FALSE |

| D |  |
|---|---|
| 1 | 0 |
| 2 | 10 |
| 3 | ∞ |
| 4 | 30 |
| n | 100 |

| P |  |
|---|---|
| 1 | -1 |
| 2 | 1 |
| 3 | -1 |
| 4 | 1 |
| n | 1 |
