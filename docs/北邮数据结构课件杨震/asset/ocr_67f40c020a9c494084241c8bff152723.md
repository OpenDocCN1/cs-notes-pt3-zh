# 5.5.2 方法2—扩展的线性链表形式

# [类型定义]

```
typedef enum {ATOM, LIST} ElemTag;
/* ATOM=0，表示原子； LIST=1，表示子表 */
typedef struct GLNode
{
    ElemTag  tag;
    union
    {
        AtomType  data;
        struct GLNode * hp;
    };
    /* 原子节点的值域atom和表节点的表头指针域hp的联合体域 */
    struct GLNode * tp;
} *GList;
```

# 表结点

| tag=1 | hp | tp |

# 原子结点

| tag=0 | data | tp |

hp：指向表头的指针

tp：指向同一层的下一个节点
