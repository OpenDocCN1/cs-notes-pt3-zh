# 2）消除尾递归

例：顺序输出单链表中的结点数据

```
void linklist_output(pointer p){
    IF (p!=NULL)
    {  write(p->data);
    linklist_output(p->next);
    }
}
```

```
使用跳转语句：
void linklist_output1(pointer p){
}
```

```
使用循环语句：
void linklist_output2(pointer p){
    while (p!=nil)
    {  write(p->data);
    p:=p->next;
    }
}
```
