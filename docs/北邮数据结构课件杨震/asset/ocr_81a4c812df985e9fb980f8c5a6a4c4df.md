# 5.B-树删除过程

+   1、查找具有给定键值的关键字 Kᵢ
+   2、如果 在第 L 层，可直接删除（注意：第 L+1 层为叶子结点），转 4。
+   3、否则，则首先生成“替身”。用该关键字的右边子树中的最左面的结点的关键字取代。然后，删除第 L 层上的该关键字。
+   4、从第 L 层开始进行删除。

+   A、不动：若删除关键字值的那个节点的关键字的个数仍处于⌈m/2⌉-1 和 m-1 之间。则结束。
+   B、借：若删除关键字值的那个节点的关键字的个数原为⌈m/2⌉-1。而它们左右兄弟节点的关键字个数 > ⌈m/2⌉-1；则借一关键字过来，结束。
+   C、并：若该节点的左右兄弟节点的关键字的个数为⌈m/2⌉-1；则执行合并节点的操作。

如节点原为：

( ............ (Kᵢ, Aᵢ), (Kᵢ₊₁, Aᵢ₊₁), ............ )
( A₀', (K₁, A₁') ........ )
( A₀'', (K₁'', A₁'') ........ )
........ K₁ ........ → 第 L 层：找到了被删节点的替身。
