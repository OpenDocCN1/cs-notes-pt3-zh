# [数据结构] 设图中的顶点个数为n

+   主： 邻接矩阵cost[1..n][1..n]，注： cost[i,i]=0
+   辅：

+   A[1..n][1..n]: 记录最短路径长度
+   path[1..n][1..n]: 记录最短路径

# [算法描述]

```
算法主要过程
for ( i = 1; i <=n; i++ )
    for ( j = 1; j <= n; j++ )
        A[i, j]=cost[i, j];
for ( k = 1; k <= n; k++ )
    for ( i = 1; i <=n; i++ )
        for ( j = 1; j <=n; j++ )
            if ( A[i, k] + A[k, j] < A[i, j] )
                A[i, j] = A[i, k] + A[k, j];
```
