# 【方法二 算法思想】

![](bbox=[0.665, 0.187, 0.901, 0.379])

（利用深度优先遍历）

+   1) 访问顶点 v，并记录 v 已被访问
+   2) 依次从 v 的未访问的邻接点出发，深度优先拓扑排序图 G。
+   3)（递归返回时）输出顶点 v（此时 v 相当于无后继的顶点）

结论：用 DFS 遍历一个无环有向图，并在 DFS 算法退栈返回时打印相应的顶点，则输出的顶点序列是逆拓扑序列
