# 插装\(time()\)的计时程序

```
void TimeSearch()
{
    //在1..1000中搜索0,10,...,90,100,200,...,1000
    int a[1001], n[20];
    for (int j=1; j<=1000; j++)
        a[j] = j;        //a[1]=1, a[2]=2, …
    for (j=0; j<10; j++) {
        n[j] = 10*j;     //n[0]=0, n[1]=10, n[2]=20
        n[j+10] = 100*(j+1);
    }                    //n[10]=100, n[11]=200, n[12]=300 …
    cout << "n   time" << endl;
}
```
