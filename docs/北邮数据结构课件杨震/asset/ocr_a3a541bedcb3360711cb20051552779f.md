# 7.2 图的存储结构

# 1. 数组+邻接矩阵/加权邻接矩阵(顺序存储方式)

+   • 无权值的有向图的邻接矩阵

设有向图具有 n 个顶点，则用 n 行 n 列的布尔矩阵 A 表示该有向图；

并且 A[i,j] = 1，如果 i 至 j 有一条有向边；A[i,j] = 0 如果 i 至 j 没有一条有向边

注意：顶点 i 出度: 行之和。顶点 i 入度: i 列之和。
