# KMP算法描述

```
Int KMP-index(char const *t, char const *p, int const *next)
{
    int i=1; j=1;
    int n=strlen(t);m=strlen(p);
    while((i<=n) && (j<=m))
    {
        if ((t[i]==p[i] || j==0)
        {
            i++;
            j++;
        }
        else
            j=next[j];
    }
    if (j==m+1)
        return (i-m);
    else
        return 0;
}
```
