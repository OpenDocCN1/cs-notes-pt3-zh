# [查找算法]

```
Bitree SearchBST( BiTree T, KeyType key )
    // 在二叉分类树查找关键字之值为 key 的结点，找到返回该结
    // 点的地址，否则返回空。T 为根结点的指针。
{
    if (( T==NULL) || ( key==T ->data ))
        return ( T );
    else if (key <T ->data. key )
        return (SearchBST (T ->lc, key));
    else
        return (SearchBST ( T -> rc, key));
}
```
