# 5.5 广义表的存储结构

# 5.5.1 方法1—头尾链表形式

[类型定义]

```
typedef enum {ATOM, LIST} ElemTag;
/*ATOM=0,原子； LIST=1,子表 */
typedef struct GLNode
{
    ElemTag tag;
    /* 标志位tag用来区别原子结点和表结点 */
    union
    {
        AtomType data;
        /* 原子结点的值域data */
        struct { struct GLNode * hp, *tp; } ptr;
        /* 表结点的指针域ptr，包括表头和表尾指针域 */
    };
    /* 原子结点的值域atom和表结点的指针域htp的联合体域 */
} *GList;
```

表结点

| tag=1 | hp | tp |

原子结点

| tag=0 | data |

hp: 指示表头的指针

tp:指示表尾的指针
