# 12.6.2 倒排文件

# [组织方式]

主文件 (主关键字有序顺序文件，含有一个或多个次关键字链表) +主关键字非稠密索引+一个或多个次关键字倒排表(索引表)

次关键字 物理地址(或主关键字)序列
