# 算法（使用邻接表）

![](bbox=[0.126, 0.231, 0.439, 0.589])

+   算法的执行步骤：
+   
+   1. 用一个数组记录每个结点的入度。将入度为零的结点进栈。
+   2. 将栈中入度为零的结点 V 输出。
+   3. 根据邻接表找到结点 V 的所有的邻接结点，并将这些邻接点的入度减一。如果某一个结点的入度变为零，则进栈。
+   4. 反复执行 2、3；直至栈空为止。
+   
+   …………………
+   
+   次序执行结束，如果输出结点数等于图的结点总数，则有向图有环，否则有向图有环。
