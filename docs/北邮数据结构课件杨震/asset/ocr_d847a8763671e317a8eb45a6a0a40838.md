设关键字的总数为 N，求 m 阶 B_ 树的 最大层次 L。

| 层次 | 节点数 | 关键字的个数（最少） |
|---|---|---|
| 1 | 1 | 1 |
| 2 | 2 | 2(⌈m/2 -1⌉) |
| 3 | 2(⌈m/2⌉) | 2(⌈m/2⌉)(⌈m/2 -1⌉) |
| 4 | 2(⌈m/2⌉)² | 2(⌈m/2⌉)²(⌈m/2 -1⌉) |
| ... | ... | ... |
| L | 2(⌈m/2⌉)^{L-2} | 2(⌈m/2⌉)^{L-2}(⌈m/2 -1⌉) |
| L+1 | 2(⌈m/2⌉)^{L-1} |  |


所以，N = 2(⌈m/2⌉)^{L-1} - 1

故：L = log_{⌈m/2⌉}((N+1)/2) + 1

设 N =1000, 000 且 m=256 ，
则 L <= 3; 最多 3 次访问外存可找到所有的记录。
