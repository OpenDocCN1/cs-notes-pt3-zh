假设一个单循环链表，其结点含有三个域prev、data、next。其中data为数据域；prev为指针域，它的值为空指针（Null）；next为指针域，它指向后继结点。请设计算法，将此表改成双向循环链表。要求时间复杂度为O(n)

```
```c
void StoDouble (Link la)
{
    link p=la;
    while (p->next->prev==NULL)
    {
        p->next->pre=la;
        // 将结点p后继的prev指针指向p。
        p=p->next;    // la指针后移。
    }
}
