# 建堆的时间耗费：

S(n) <= Σ_{i=h-1}^{1} 2^{i-1} × (h - i) = Σ_{j=1}^{h-1} 2^{h-j} × j

将 h = ⌊log₂n⌋ + 1 代入有

则建堆的时间复杂度为 <= 4n = O(n)

# 堆调整的时间耗费：

| 节点个数 | 高度 | 比较次数最多 |
|---|---|---|
| j=2 | log2 + 1 | <= 2 × log2 |
| j=3 | log3 + 1 | <= 2 × log3 |
| ... | ... | ... |
| j=n | logn + 1 | <= 2 × logn |

所以： T(n) <= 2( log2 + log3 + ...... + logn ) = 2log(n!)

T(n) = O ( nlogn )
