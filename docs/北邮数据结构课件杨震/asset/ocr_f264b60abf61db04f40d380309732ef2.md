# 求next数组值

算法思想：利用递推

即已知next[1]=0，… next[i]=k；求next[i+1]

![](bbox=[0.09, 0.31, 0.91, 0.525])

# 算法描述

```
void get_next(int *next, char const *p) {
    int j=1, k=0; next[1]=0;
    while(j < strlen(p))
    {
        if ((k==0) || (p[k]==p[j])
            next[++j]=++k;
        else
            k=next[k];
    }
}
```
