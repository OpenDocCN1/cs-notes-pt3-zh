+   3. 调用下列函数f(n) 回答下列问题：
+   （1）试给出f(n)值的大小，并写出f(n) 值的推导过程；
+   （2）假定n=5，试指出f(5)值的大小和执行f(5)时的输出结果。

```
int f(int n)
{
    int i, j, k, sum= 0;
    for(i=1; i<n+1;i++)
    {
        for(j=n; j>i-1; j--)
            for(k=1; k<j+1; k++ )
                sum++;
        printf("sum=%d\n",sum);
    }
    return (sum);
}
```
