- 单循环链表是单链表的变形。
- 单循环链表最后一个节点的后继指针不为 0 (NULL)，而是指向了表的前端。

- 单循环链表的特点是：只要知道表中某一节点的地址，就可搜寻到所有其他节点的地址。

# 顺序表和链表的比较

- **空间**
  - 存储空间静态分配，需事先确定
  - 存储密度高(d=1) (不考虑空闲区)
  - **时间**
  - 是随机存取结构，可以根据序号直接定位
  - 插入/删除结点操作时数据元素要移动

- **空间**
  - 存储空间动态分配，可以按需要使用
  - 每一结点附加指针域 (d<1)
  - **时间**
  - 是非随机存取结构，定位需从头指针扫描
  - 插入/删除结点操作时通常只要修改指针
