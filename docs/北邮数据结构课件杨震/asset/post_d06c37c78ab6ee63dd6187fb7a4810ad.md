# 例【人口问题】

已知：
每个人的净生殖率为r（净生殖率=出生率-死亡率）；
时间t；
t=0时的人口为N(0)；
求：
t时间的人口数。

1. 所求量  N(t).
2. 模型  1/N dN/dt = r.
3. 求解模型的算法  N(t) = N(0)e^{rt}.
4. 编制计算机程序

```
#include <cmath>  //for std::exp()
int population(int ini, double birth_rate,
               double time_at)
{
    return ini*std::exp(birth_rate*time_at);
}
```

# 算法的概念

# 一个算法必须满足以下五个重要特性

- 有穷性：对任何合法输入执行有穷步后能结束。
- 确定性：每条指令必须有确切的含义。
- 可行性：算法的每一条指令均能执行。
- 输入：有零个或多个输入。
- 输出：有一个或多个输出。

# 顺序搜索（Sequential Search）

```
int seqsearch ( int a[], const int n,
                 const int x )    //a[0],...,a[n-1]
{
    int i = 0;
    while ( i < n && a[i] != x )
        i++;
    if ( i == n ) return -1;
    return i;
}
```

# 插装\(time()\)的计时程序

```
void TimeSearch()
{
    //在1..1000中搜索0,10,...,90,100,200,...,1000
    int a[1001], n[20];
    for (int j=1; j<=1000; j++)
        a[j] = j;        //a[1]=1, a[2]=2, …
    for (j=0; j<10; j++) {
        n[j] = 10*j;     //n[0]=0, n[1]=10, n[2]=20
        n[j+10] = 100*(j+1);
    }                    //n[10]=100, n[11]=200, n[12]=300 …
    cout << "n   time" << endl;
}
```
