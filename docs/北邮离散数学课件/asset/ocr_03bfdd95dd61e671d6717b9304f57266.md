Let D = [ d_ij ] be an m × p Boolean matrix, and let E = [ e_ij ] be a p × n Boolean matrix. We define the mod-2 Boolean product D * E as the m × n matrix F = [ f_ij ], where

f_ij = d_i1 · e_1j + d_i2 · e_2j + ⋯ + d_ip · e_pj,    1 ≤ i ≤ m,  1 ≤ j ≤ n.
