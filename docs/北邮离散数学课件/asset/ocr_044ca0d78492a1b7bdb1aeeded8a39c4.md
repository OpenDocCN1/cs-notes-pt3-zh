# # 4.1 运算、代数系统与特异元素

# ## 3. 分配律

+   - 一个代数结构若具有两个运算时，则分配律可建立这两个运算之间的某种联系。

+   - 给定<**S**,° ,◦>, 运算° 对于◦满足左分配律，或者° 对于◦是可左分配的，即：
+   
+     \( (\forall x)(\forall y)(\forall x)(x,y,z \in S \rightarrow x^\circ \, (y \circ z) = (x^\circ \, y) \circ (x^\circ \, z) \)

+   - 运算° 对于◦满足右分配律或者° 对于◦是可右分配的，即：
+   
+     \( (\forall x)(\forall y)(\forall x)(x,y,z \in S \rightarrow (y \circ z)^\circ \, x = (y^\circ \, x) \circ (z^\circ \, x) \)
