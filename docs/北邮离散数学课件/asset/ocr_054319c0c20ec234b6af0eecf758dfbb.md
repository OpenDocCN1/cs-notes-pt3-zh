+   - “when $p$, $q$”
+   - “whenever $p$, $q$”
+   - “$q$ if $p$”
+   - “$q$ when $p$”
+   - “$q$ whenever $p$”

+   - “$p$ only if $q$”
+   - “$p$ is sufficient for $q$”
+   - “$q$ is necessary for $p$”
+   - “$q$ follows from $p$”
+   - “$q$ is implied by $p$”
+   - “$q$ unless ¬ $p$”
