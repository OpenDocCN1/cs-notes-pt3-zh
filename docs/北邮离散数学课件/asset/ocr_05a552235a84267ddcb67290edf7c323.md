# Binary Modular Exponentiation Algorithm

+   The algorithm successively finds $b \mod m$, $b^2 \mod m$, $b^4 \mod m$, ..., $b^{2^{k-1}} \mod m$, and multiplies together the terms $b^{2^j}$ where $a_j = 1$.

```
procedure modular exponentiation(b: integer, n = (a_{k-1}a_{k-2}...a_1a_0)_2, m: positive integers)
  x := 1
  power := b mod m
  for i := 0 to k - 1
    if a_i = 1 then x := (x·power) mod m
    power := (power·power) mod m
  return x {x equals b^n mod m}
```

+   O((log m)^2 log n) bit operations are used to find $b^n \mod m$.
