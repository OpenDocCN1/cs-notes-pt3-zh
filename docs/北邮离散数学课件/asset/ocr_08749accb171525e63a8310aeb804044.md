# Proof: $x * \mathbf{H} = \mathbf{0} \iff x = e_H(b)$ for some $b \in B^m$

Conversely if $x = e_H(b)$, the equations in (I) can be rewritten by adding $x_i$ to both sides of the $i^{th}$ equation, $i = 1, 2, ..., n$, as

$b_1 \cdot h_{11} + b_2 \cdot h_{21} + ... + b_m \cdot h_{m1} + x_1 = 0$
$b_1 \cdot h_{12} + b_2 \cdot h_{22} + ... + b_m \cdot h_{m2} + x_2 = 0$
$\vdots$
$b_1 \cdot h_{1r} + b_2 \cdot h_{2r} + ... + b_m \cdot h_{mr} + x_r = 0$

which shows $x * \mathbf{H} = \mathbf{0}$
