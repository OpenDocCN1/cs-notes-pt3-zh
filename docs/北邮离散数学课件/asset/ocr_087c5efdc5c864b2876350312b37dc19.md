# Summation Notation

+   - Given a series {a_n}, an integer *lower bound* (or limit) *j*≥0, and an integer *upper bound* *k*≥j, then the *summation* of {a_n} from j to k is written and defined as follows:
+   
+     $$\sum_{i=j}^{k} a_i \triangleq a_j + a_{j+1} + ... + a_k$$
+   
+   - Here, *i* is called the *index of summation*.
