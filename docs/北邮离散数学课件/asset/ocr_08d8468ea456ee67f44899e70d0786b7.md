# Theorem 3

+   - Let L be a lattice. Then
+     - Idempotent Properties（等幂律）
+       - (a) a ∨ a = a
+       - (b) a ∧ a = a
+     - Commutative Properties（交换律）
+       - (a) a ∨ b = b ∨ a
+       - (b) a ∧ b = b ∧ a
+     - Associative Properties（结合律）
+       - (a) a ∨ (b ∨ c) = (a ∨ b) ∨ c
+       - (b) a ∧ (b ∧ c) = (a ∧ b) ∧ c
+     - Absorption Properties（吸收律）
+       - (a) a ∨ (a ∧ b) = a
+       - (b) a ∧ (a ∨ b) = a
