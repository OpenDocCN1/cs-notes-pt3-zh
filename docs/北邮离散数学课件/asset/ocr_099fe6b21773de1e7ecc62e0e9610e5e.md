# Matrix Products

+   For an *m×k* matrix A and a *k×n* matrix B, the product AB is the *m×n* matrix:
+   
+   AB = C = [c_{i,j}] ≡ \[
+   \sum_{\ell=1}^k a_{i,\ell} b_{\ell,j}
+   \]

i.e., the element of AB indexed (i,j) is given by the vector dot product of the jth row of A and the jth column of B (considered as vectors).

+   Note: Matrix multiplication is not commutative!
