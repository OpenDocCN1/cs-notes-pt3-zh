# Rules in Prolog

+   - A *rule* in Prolog represents a universally quantified proposition of the general form
+     ∀x: [∃y P(x,y)]→Q(x),
+     where x and y might be compound variables x=(z,w) and P,Q compound propositions.
+   - In Prolog, this is written as the rule:
+     q(X) :- p(X,Y).
+     i.e., the ∀,∃ quantifiers are
+   - Example: likable(X) :- likes(Y,X).

```
q(X) :- p(X,Y).
```

```
likable(X) :- likes(Y,X).
```

Variables must be capitalized
