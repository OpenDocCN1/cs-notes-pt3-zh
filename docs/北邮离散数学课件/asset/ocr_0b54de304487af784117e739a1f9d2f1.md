# Theorem 2 - Proof

# Left cancellation

Suppose that $ab = ac$.

$a^{-1}(ab) = a^{-1}(ac)$

$(a^{-1}a)b = (a^{-1}a)c \quad \text{by associativity}$

$eb = ec \quad \text{by the definition of an inverse}$

$b = c \quad \text{by definition of an identity.}$

# Right cancellation

The proof is similar to above.
