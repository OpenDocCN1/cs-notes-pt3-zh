# Matrices as Functions

+   - An $m\times n$ matrix **A** = $[a_{i,j}]$ of members of a set $S$ can be encoded as a partial function $f_A: \mathbf{N}\times\mathbf{N}\to S$, such that for $i<m$, $j<n$, $f_A(i,j)=a_{i,j}$.
+   - By extending the domain over which $f_A$ is defined, various types of infinite and/or multidimensional matrices can be obtained.
