# Example 2

Let B = {0, 1} be the group, where + is defined as above

Then Bⁿ = B × B × ... × B (n factors) is a group with operation ⊕ defined by

(x₁, x₂, ... xₙ) ⊕ (y₁, y₂, ... yₙ) = (x₁+y₁, x₂+y₂, ..., xₙ+yₙ).

The identity of Bⁿ is (0, 0, ..., 0), and every element is its own inverse.

|---|---|---|
| 0 | 0 | 1 |
| 1 | 1 | 0 |
