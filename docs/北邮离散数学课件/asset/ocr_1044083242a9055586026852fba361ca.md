# Direct Proof Example

+   - **Definition:** An integer *n* is called *odd* iff *n*=2*k*+1 for some integer *k*; *n* is *even* iff *n*=2*k* for some *k*.
+   - **Theorem:** Every integer is either odd or even.
+     - This can be proven from even simpler axioms.
+   - **Theorem:** (For all numbers *n*) If *n* is an odd integer, then *n*² is an odd integer.
+   - **Proof:** If *n* is odd, then *n* = 2*k*+1 for some integer *k*. Thus, *n*² = (2*k*+1)² = 4*k*² + 4*k* + 1 = 2(2*k*² + 2*k*) + 1. Therefore *n*² is of the form 2*j* + 1 (with *j* the integer 2*k*² + 2*k*), thus *n*² is odd. □
