# distinguishable objects and indistinguishable boxes

+   - How many ways are there put four different employees into three indistinguishable offices, when each office can contain any number of employees?
+   - We can put all four employees into one office in exactly one way, represented by {{A,B,C,D}}. We can put three employees into one office and the fourth employee into a different office in exactly four ways, represented by {{A,B,C}, {D}}, {{A,B,D}, {C}}, {{A,C,D}, {B}}, and {{B,C,D}, {A}}.
