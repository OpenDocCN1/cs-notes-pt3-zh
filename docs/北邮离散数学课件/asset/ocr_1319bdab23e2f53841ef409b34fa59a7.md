# 例

+   - 例2：求公式（P ∨ Q） → R 的析取范式和合取范式
+   - 解：
+     - （P ∨ Q） → R ⇔ ¬（P ∨ Q） ∨ R ⇔ （¬P ∧ ¬Q） ∨ R ⇔ （¬P ∨ R） ∧ （¬Q ∨ R） 合取范式
+     - 原式 ⇔ （¬P ∨ R） ∧ （¬Q ∨ R） ⇔ （（¬P ∨ R） ∧ （¬Q）） ∨ （（¬P ∨ R） ∧ R） ⇔ （¬P ∧ ¬Q） ∨ （R ∧ ¬Q） ∨ （¬P ∧ R） ∨ R 析取范式
+     - 原式 ⇔ （¬P ∧ ¬Q） ∨ （R ∧ ¬Q） ∨ R ⇔ （¬P ∧ ¬Q） ∨ R 析取范式
+     - 析取（合取）范式不唯一！
