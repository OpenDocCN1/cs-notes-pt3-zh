# The Chinese Remainder Theorem

Example: Consider the 3 congruences from Sun-Tsu’s problem:

x ≡ 2 ( mod 3), x ≡ 3 ( mod 5), x ≡ 2 ( mod 7).

+   - Let m = 3·5·7 = 105, M₁ = m/3 = 35, M₃ = m/5 = 21, M₃ = m/7 = 15.
+   - We see that
+     - 2 is an inverse of M₁ = 35 modulo 3 since 35·2 ≡ 2·2 ≡ 1 (mod 3)
+     - 1 is an inverse of M₂ = 21 modulo 5 since 21 ≡ 1 (mod 5)
+     - 1 is an inverse of M₃ = 15 modulo 7 since 15 ≡ 1 (mod 7)
+   - Hence,
+     x = a₁M₁y₁ + a₂M₂y₂ + a₃M₃y₃
+     = 2·35·2 + 3·21·1 + 2·15·1 = 233 ≡ 23 (mod 105)
+   - We have shown that 23 is the smallest positive integer that is a simultaneous solution. Check it!
