# # 4.1 运算、代数系统与特异元素

例4.1.10 给定\(<\{\alpha,\beta\},\circ>\)，表9.2.2，表9.2.3和表9.2.4分别给出\(\circ\) 的不同定义的运算表，试指出左幺元、右幺元及幺元。(表4.1.2)

| ∘ | α | β |
|---|---|---|
| α | α | β |
| β | β | α |

| ∘ | α | β |
|---|---|---|
| α | α | α |
| β | β | β |

| ∘ | α | β |
|---|---|---|
| α | β | β |
| β | α | β |

解\(\circ\) 如表4.1.2所定义，\(\alpha\)是\(\circ\) 的幺元；\(\circ\) 如表9.2.3所定义，\(\alpha\)和\(\beta\)是\(\circ\) 的右幺元；\(\circ\) 如表9.2.4所定义，\(\beta\)是\(\circ\) 的左幺元。
