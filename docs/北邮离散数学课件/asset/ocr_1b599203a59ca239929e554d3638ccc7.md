# Proof

+   - \(P = \{R(a) \mid a \in A\}\)
+     - Every element of \(A\) belongs to some relative set.
+       - Since reflexivity of \(R\), \(a \in R(a)\)
+     - If \(R(a)\) and \(R(b)\) are not identical, then \(R(a) \cap R(b) = \varnothing\)
+       - If \(R(a) \cap R(b) \neq \varnothing\), then \(R(a) = R(b)\).
+     - Contrapositive(换质位命题、对换式、逆反式)
