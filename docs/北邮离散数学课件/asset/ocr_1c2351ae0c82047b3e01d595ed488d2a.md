# Algorithm

+   - **procedure** *modular exponentiation* (b:integer, n=(a_{k-1}a_{k-2}a_{1}a_{0})_2, m:positive integer)
+     x := 1
+     power:=b mod m
+     **for** i:=0 to k-1
+     **if** a_i =1 **then** x:=(x· power) mod m
+     power:=(power·power) mod m
+     **end**
+     {x equals b^n mod m}

+   - It uses O((log m)² log n) bit operations
