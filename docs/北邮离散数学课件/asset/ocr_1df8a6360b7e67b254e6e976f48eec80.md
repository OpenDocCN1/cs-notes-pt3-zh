# Generalized Union

+   - Binary union operator: $A \cup B$
+   - $n$-ary union:
+     $A \cup A_2 \cup ... \cup A_n := ((...((A_1 \cup A_2) \cup ...) \cup A_n)$
+     (grouping & order is irrelevant)
+   - “Big U” notation: $\bigcup_{i=1}^{n} A_i$
+   - Or for infinite sets of sets: $\bigcup_{A \in X} A$
