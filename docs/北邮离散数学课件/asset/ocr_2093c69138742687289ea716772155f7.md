# Octal Expansions

The octal expansion (base 8) uses the digits {0,1,2,3,4,5,6,7}.

**Example**: What is the decimal expansion of the number with octal expansion (7016)₈?

**Solution**: 7·8³ + 0·8² + 1·8¹ + 6·8⁰ = 3598

**Example**: What is the decimal expansion of the number with octal expansion (111)₈?

**Solution**: 1·8² + 1·8¹ + 1·8⁰ = 64 + 8 + 1 = 73
