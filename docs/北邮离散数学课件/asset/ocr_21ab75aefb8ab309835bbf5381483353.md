# # Commutative - 交换律

+   - A binary operation on a set _A_ is said to be _commutative_ if _a_∗_b_=_b_∗_a_ for all elements _a_ and _b_ in _A_.

+   - Example:

+   - The binary operation of addition on _Z_ is commutative.

+   - The binary operation of subtraction on _Z_ is not commutative, since2-3≠3-2.
