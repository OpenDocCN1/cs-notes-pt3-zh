# # Logical Equivalences

+   - $P \to Q \Leftrightarrow \neg P \lor Q$　　 **Implication**（蕴涵等价式）
+   - $P \lor \neg P \Leftrightarrow T$　　 **Tautology**（排中律）
+   - $P \land \neg P \Leftrightarrow F$　　 **Contradiction**（矛盾律）
+   - $(P \to Q) \land (Q \to P) \Leftrightarrow (P \leftrightarrow Q)$　　 **Equivalence**
+   - $(P \to Q) \land (P \to \neg Q) \Leftrightarrow \neg P$　　 **Absurdity** 归谬论
