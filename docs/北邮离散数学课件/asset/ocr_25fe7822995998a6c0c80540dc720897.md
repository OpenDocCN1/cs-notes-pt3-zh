# Euclidean Algorithm

The Euclidean algorithm expressed in pseudocode is:

```
procedure gcd(a, b: positive integers)
x := a
x := b
while y ≠ 0
    r := x mod y
    x := y
    y := r
return x {gcd(a,b) is x}
```

In Section 5.3, we’ll see that the time complexity of the algorithm is O(log b), where a > b.
