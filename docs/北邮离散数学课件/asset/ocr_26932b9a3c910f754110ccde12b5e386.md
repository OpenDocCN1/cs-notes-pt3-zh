# Conjunctive Normal Form

Example: Put the following into CNF:

¬(p → q) ∨ (r → p)

# Solution:

+   1. Eliminate implication signs:
+      ¬(¬p ∨ q) ∨ (¬r ∨ p)

+   2. Move negation inwards; eliminate double negation:
+      (p ∧ ¬q) ∨ (¬r ∨ p)

+   3. Convert to CNF using associative/distributive laws
+      (p ∨ ¬r ∨ q) ∧ (¬q ∨ ¬r ∨ p)
