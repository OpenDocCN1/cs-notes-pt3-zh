# Traversal Algorithms

+   - Definition 2: Let $T$ be an ordered rooted tree with root $r$. If T consists only of $r$, then $r$ is the **inorder traversal** of T. Otherwise, suppose that $T_1, T_2, ..., T_n$ are subtrees at $r$ from left to right in $T$. The inorder traversal begins by traversing $T_1$ in inorder, then visiting $r$. It continues by traversing $T_2$ in inorder, and so on, until $T_n$ is traversed in inorder.
