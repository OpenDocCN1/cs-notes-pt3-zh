# # 4.1 运算、代数系统与特异元素

+   - 下面给出a<sup>m</sup>的归纳定义：
+   - 设有<**S**, ◦ >且a∈**S**. 对于m∈**I**<sub>+</sub>, 其中**I**<sub>+</sub>表示正整数集合, 可有：
+     (1)a<sup>1</sup>=a 
+     (2)a<sup>m+1</sup>=a<sup>m</sup>◦ a
+     由此利用归纳法不难证明指数定律：
+     (1) a<sup>m</sup>◦ a<sup>n</sup>=a<sup>m+n</sup> 
+     (2) (a<sup>m</sup>)<sup>n</sup>=a<sup>mn</sup>
+     这里, m, n ∈**I**<sub>+</sub>.
+   - 类似地定义某代数结构中的负幂和给出负指数定律.
