# Set Difference 差

+   - For sets *A*, *B*, the *difference of A and B*, written *A*−*B*, is the set of all elements that are in *A* but not *B*. Formally:
+     *A* − *B* := {*x* | *x*∈*A* ∧ *x*∉*B*}
+     = {*x* | ¬(*x*∈*A* → *x*∈*B*)}
+   - Also called:
+     The *complement of B with respect to A*.
