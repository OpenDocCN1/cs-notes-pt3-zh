# Cryptosystems

**Example:** Describe the family of shift ciphers as a cryptosystem.

**Solution:** Assume the messages are strings consisting of elements in Z₂₆.

+   - 𝒫 is the set of strings of elements in Z₂₆,
+   - C is the set of strings of elements in Z₂₆,
+   - 𝒦 = Z₂₆,
+   - ℰ consists of functions of the form Eₖ(p) = (p + k) mod 26 , and
+   - 𝒟 is the same as ℰ where Dₖ(p) = (p − k) mod 26 .
