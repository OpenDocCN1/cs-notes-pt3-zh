# Arithmetic Modulo *m*

+   - **Additive inverses:** If *a* ≠ 0 belongs to \(\mathbb{Z}_m\), then \(m-a\) is the additive inverse of a modulo m and 0 is its own additive inverse.
+     - \(a +_m (m-a) = 0\) and \(0 +_m 0 = 0\)
+   - **Distributivity:** If *a*, *b*, and *c* belong to \(\mathbb{Z}_m\), then
+     - \(a \cdot_m (b +_m c) = (a \cdot_m b) +_m (a \cdot_m c)\) and
+     - \((a +_m b) \cdot_m c = (a \cdot_m c) +_m (b \cdot_m c)\).
+   - Exercises 42–44 ask for proofs of these properties.
+   - Multiplicative inverses have not been included since they do not always exist. For example, there is no multiplicative inverse of 2 modulo 6.
+   - *(optional)* Using the terminology of abstract algebra, \(\mathbb{Z}_m\) with \(+_m\) is a commutative group and \(\mathbb{Z}_m\) with \(+_m\) and \(\cdot_m\) is a commutative ring.
