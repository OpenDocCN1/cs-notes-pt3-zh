# Facts in Prolog

+   - A fact in Prolog represents a simple, non-compound proposition in predicate logic.
+     - *e.g.*, “John likes Mary”
+       - can be written Likes(John,Mary) in predicate logic.
+       - can be written `likes(john,mary).` in Prolog!
+       - Lowercase symbols must be used for all constants and predicates, uppercase is reserved for variable names.
