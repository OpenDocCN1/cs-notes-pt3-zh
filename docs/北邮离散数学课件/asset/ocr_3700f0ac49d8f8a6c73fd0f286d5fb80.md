# Another Induction Example

+   - Prove that ∀n>0, n<2ⁿ. Let P(n)=(n<2ⁿ)
+     - Base case: P(1)=(1<2¹)=(1<2)=T.
+     - Inductive step: For n>0, prove P(n)→P(n+1).
+       - Assuming n<2ⁿ, prove n+1 < 2ⁿ⁺¹.
+       - Note n + 1 < 2ⁿ + 1 (by inductive hypothesis)
+         < 2ⁿ + 2ⁿ (because 1<2=2·2⁰≤2·2ⁿ⁻¹=2ⁿ)
+         = 2ⁿ⁺¹
+       - So n + 1 < 2ⁿ⁺¹, and we’re done.
