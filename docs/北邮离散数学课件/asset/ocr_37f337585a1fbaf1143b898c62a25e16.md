# Deduction Example

+   - Definitions: $H(x) :\equiv$ “x is human”; $M(x) :\equiv$ “x is mortal”; $G(x) :\equiv$ “x is a god”
+   - Premises:
+     - $\forall x\ H(x) \rightarrow M(x)$ (“Humans are mortal”) and
+     - $\forall x\ G(x) \rightarrow \neg M(x)$ (“Gods are immortal”).
+   - Show that $\neg\exists x\ (H(x) \land G(x))$ (“No human is a god.”)
