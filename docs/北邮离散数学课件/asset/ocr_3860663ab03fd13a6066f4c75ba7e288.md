# Example

+   - Show by mathematical induction that any finite, nonempty set is countable; that is, it can be arranged in a list.
+   - Solution
+     - Let P(n) be the predicate that if A is any set with |A|=n≥1, then A is countable.
+     - BS: n₀ =1, so we let A be any set with one element, say A={x}, In this case x forms a sequence all by itself whose set is A, so P(1) is true.
