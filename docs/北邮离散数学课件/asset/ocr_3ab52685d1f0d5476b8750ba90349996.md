# # Example 12

+   - Solution
+     - (a) The statement \( x \ y = y \ x \) must be true for all choices of \( x \) and \( y \). Since both \( 0 \ I \) and \( I \ 0 \) are I, is commutative.
+     - (b) The eight possible cases to be checked are left as an exercise. \( \nabla \)
+     - (c) \( (0 \ 0)*=0* = I \quad 0 * \nabla 0*=1 \nabla 1= I \).
+       \( (0 \ 1)*=1* = 0 \quad 0 * \nabla 1*=1 \nabla 0= 0 \).
+       \( (1 \ 1)*=0* = I \quad 1 * \nabla 1*=0 \nabla 0= 0 \).
+     The last pair shows that De Morgan's laws do not hold in this structure.
