# Number of Subsets of a Finite Set

**Inductive Hypothesis**: For an arbitrary nonnegative integer k, every set with k elements has 2^k subsets.

+   - Let T be a set with k + 1 elements. Then T = S ∪ {a}, where a ∈ T and S = T − {a}. Hence |T| = k.
+   - For each subset X of S, there are exactly two subsets of T, i.e., X and X ∪ {a}.

+   - By the inductive hypothesis S has 2^k subsets. Since there are two subsets of T for each subset of S, the number of subsets of T is 2 · 2^k = 2^{k+1}.
