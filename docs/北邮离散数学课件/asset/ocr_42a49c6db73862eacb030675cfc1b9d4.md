# Alternative proof, using equivalences

+   - ∀x H(x)→M(x) and ∀x G(x)→¬M(x).
+   - ∀x ¬M(x)→¬H(x) [Contrapositive.]
+   - ∀x [G(x)→¬M(x)] ∧ [¬M(x)→¬H(x)]
+   - ∀x G(x)→¬H(x) [Transitivity of →.]
+   - ∀x ¬G(x) ∨ ¬H(x) [Definition of →.]
+   - ∀x ¬(G(x) ∧ H(x)) [DeMorgan’s law.]
+   - ¬∃x G(x) ∧ H(x) [An equivalence law.]
