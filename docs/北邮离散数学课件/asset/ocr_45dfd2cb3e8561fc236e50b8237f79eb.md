# Directed Graphs

+   - Correspond to arbitrary binary relations \(R\), which need not be symmetric.
+   - A *directed graph* \((V,E)\) consists of a set of vertices \(V\) and a binary relation \(E\) on \(V\).
+   - *E.g.:* \(V\) = set of People,
+     \(E=\{(x,y) \mid x\ loves\ y\}\)
