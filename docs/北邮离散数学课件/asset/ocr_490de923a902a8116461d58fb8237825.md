# 极小项的记法

+   公式共有2ⁿ个赋值，每个对应赋值一个极小项。如极小项对应赋值a₁a₂a₃，把其看作二进制，化为十进制为k₀ ≤ k ≤ 2ⁿ-1，则该极小项记作mₐ₁ₐ₂ₐ₃，也记作mₖ

| 极小项 | 对应的赋值 | 十进制数 | 记法 |
|---|---|---|---|
| ¬P∧¬Q∧¬R | 000 | 0 | m₀₀₀或m₀ |
| ¬P∧¬Q∧R | 001 | 1 | m₀₀₁或m₁ |
| ¬P∧Q∧¬R | 010 | 2 | m₀₁₀或m₂ |
| ¬P∧Q∧R | 011 | 3 | m₀₁₁或m₃ |
| P∧¬Q∧¬R | 100 | 4 | m₁₀₀或m₄ |
| P∧¬Q∧R | 101 | 5 | m₁₀₁或m₅ |
| P∧Q∧¬R | 110 | 6 | m₁₁₀或m₆ |
| P∧Q∧R | 111 | 7 | m₁₁₁或m₇ |
