# Counting the reflexive relations

+   - How many reflexive relations are there on a set $A$ with $n$ elements?
+   - Consider the pairs $B:\{(x, x)$ with $x \in A\}$. There are $n$ such pairs. For every configuration of the pairs $(x, y)$ with $x \neq y$, one of the $2^n$ subsets of $B$ corresponds to a reflexive relation, and all others do not. So there is one reflexive relation for every $2^n$ relations, or $2^{n^2} / 2^n = 2^{n^2-n} = 2^{n(n-1)}$ total reflexive relations.
