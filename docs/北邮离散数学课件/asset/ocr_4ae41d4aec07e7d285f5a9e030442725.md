# Simple Transitive Closure Alg.

A procedure to compute $R^*$ with 0-1 matrices.

procedure transClosure($\mathbf{M}_R$:rank-$n$ 0-1 mat.)

```
A := B := M_R;
for i := 2 to n begin
    A := A ⊙ M_R;  B := B ∨ A    {join}
end    {note A represents R^i, B represents ⋃_{j=1}^i R^j }
return B {Alg. takes Θ(n^4) time}
```
