# Merge Routine

```
procedure merge(A, B: sorted lists)
    L = empty list
    i:=0, j:=0, k:=0
    while i<|A| ∧ j<|B|  {|A| is length of A}
        if i=|A| then L_k := B_j; j := j + 1
        else if j=|B| then L_k := A_i; i := i + 1
        else if A_i < B_j then L_k := A_i; i := i + 1
        else L_k := B_j; j := j + 1
        k := k+1
    return L
```

Takes Θ(|A|+|B|) time
