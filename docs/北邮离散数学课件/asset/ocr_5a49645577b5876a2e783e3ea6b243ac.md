# # Example 7,8

+   - Let \( M \) be the set of a1l \( n \times n \) Boolean matrices for a fixed \( n \). Define \( A * B \) as \( A \lor B \).
+     - * is a binary operation.
+     - This is also true of \( A \lor B \).

+   - Let \( L \) be a lattice. Define \( a * b \) as \( a \lor b \).
+     - * is a binary operation on \( L \).
+     - This is also true of \( a \lor b \).
