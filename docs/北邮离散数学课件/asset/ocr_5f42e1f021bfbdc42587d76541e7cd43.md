[定义2]：称 R ∪ Rᶜ 是 R 的对称闭包/symmetric closure of R，记为 s(R)。
[定理2]：设 R 是 A 上的二元关系，则 R ∪ Rᶜ 是对称的，包含 R 的最小关系，
（其中 Rᶜ 是 R 的逆关系）。
证明：若 (a, b) ∈ R ∪ Rᶜ，则
(a, b) ∈ R 或 (a, b) ∈ Rᶜ，
⇒ (b, a) ∈ Rᶜ 或 (b, a) ∈ R
故 (b, a) ∈ R ∪ Rᶜ（对称性），
若 R′ 为包含 R，对称的二元关系，
则对 ∀ (a, b) ∈ R ∪ Rᶜ，
若 (a, b) ∈ R ⇒ (a, b) ∈ R′；
若 (a, b) ∈ Rᶜ ⇒ (b, a) ∈ R，
⇒ (b, a) ∈ R′
又 R′ 具有对称性，(a, b) ∈ R′，
故 R ∪ Rᶜ ⊆ R′。
