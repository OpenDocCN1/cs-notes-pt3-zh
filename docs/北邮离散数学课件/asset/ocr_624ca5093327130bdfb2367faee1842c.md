# Which of these are tautologies?

+   1. $p \to (q \to p)$
+   2. $p \to (\lnot p \to p)$
+   3. $(q \to p) \to (p \to q)$
+   4. $(q \to p) \lor (p \to q)$
+   5. $(p \to (q \to r)) \to (q \to (p \to r))$

Please prove your claims, using truth tables.
(Hint: Ask what assignment of truth values to p,q, and r would falsify each formula).
