# Big-Theta Notation

**Example**: Show that $f(x) = 3x^2 + 8x \log x$ is $\Theta(x^2)$.

**Solution:**

+   - $3x^2 + 8x \log x \le 11x^2$ for $x > 1$, since $0 \le 8x \log x \le 8x^2$.

+   - Hence, $3x^2 + 8x \log x$ is $O(x^2)$.

+   - $x^2$ is clearly $O(3x^2 + 8x \log x)$

+   - Hence, $3x^2 + 8x \log x$ is $\Theta(x^2)$.
