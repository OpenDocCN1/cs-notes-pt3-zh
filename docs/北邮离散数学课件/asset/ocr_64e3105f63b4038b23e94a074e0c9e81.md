# A Specific Case

+   - Let $n=3$. Consider 1, 11, 111, 1111.
+     - 1 mod 3 = 1
+     - 11 mod 3 = 2
+     - 111 mod 3 = 0 ← Lucky extra solution.
+     - 1,111 mod 3 = 1
+   - 1,111 − 1 = 1,110 = 3·370.
+     - It has only 0’s and 1’s in its expansion.
+     - Its residue mod 3 = 0, so it’s a multiple of 3.
