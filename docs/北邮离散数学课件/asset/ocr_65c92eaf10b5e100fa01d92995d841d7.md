# Complement （补元）

+   - Let $L$ be a bounded lattice with greatest element $I$ and least element $0$, and let $a \in L$. An element $a' \in L$ is called a *complement of $a$* if
+     - $a \vee a' = I$ and $a \wedge a' = 0$
+   - Note that
+     - $0' = I$ and $I' = 0$.
+   - An element $a$ in a lattice need not have a complement, and it may have more than one complement.
