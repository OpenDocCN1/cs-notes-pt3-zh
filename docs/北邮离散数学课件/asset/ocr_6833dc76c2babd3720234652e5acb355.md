则按下列规定，定义 p_k 的下一个排列
p_{k+1} = b_1, b_2, ..., b_m, ..., b_n
(1) 寻找 a_m： m = max { j | a_j < a_{j+1} }
即 a_m, a_{m+1} 是最右面的顺序，自 a_{m+1} 开始均为逆序。
(2) 给出 b_i （ i = 1, 2, ..., n ）
a）第 m 项之前的项不变：
b_1 = a_1, b_2 = a_2, ..., b_{m-1} = a_{m-1}
b）b_m = min { a_p | a_p > a_m, p > m }
即在 a_m 右面大于 a_m 的项中选取最小的项作为 b_m。
c）把 a_m, a_{m+1}, ..., a_{p-1}, a_{p+1}, ..., a_n 从小到大排列，送入 b_{m+1}, b_{m+2}, ..., b_n。
