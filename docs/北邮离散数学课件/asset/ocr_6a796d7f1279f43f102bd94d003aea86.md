# Powers of a Relation

**Definition:** Let *R* be a binary relation on *A*. Then the powers *R*ⁿ of the relation *R* can be defined inductively by:

+   - Basis Step: *R*¹ = *R*
+   - Inductive Step: *R*ⁿ⁺¹ = *R*ⁿ ∘ *R*

*(see the slides for Section 9.3 for further insights)*

The powers of a transitive relation are subsets of the relation. This is established by the following theorem:

**Theorem 1:** The relation *R* on a set *A* is transitive iff *R*ⁿ ⊆ *R* for *n* = 1,2,3, ….
