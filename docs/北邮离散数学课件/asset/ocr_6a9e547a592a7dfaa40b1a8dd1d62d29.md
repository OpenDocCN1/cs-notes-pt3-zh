# Uncountability of Reals, cont’d

A postulated enumeration of the reals:

r₁ = 0.d₁,₁ d₁,₂ d₁,₃ d₁,₄ d₁,₅ d₁,₆ d₁,₇ d₁,₈…
r₂ = 0.d₂,₁ d₂,₂ d₂,₃ d₂,₄ d₂,₅ d₂,₆ d₂,₇ d₂,₈…
r₃ = 0.d₃,₁ d₃,₂ d₃,₃ d₃,₄ d₃,₅ d₃,₆ d₃,₇ d₃,₈…
r₄ = 0.d₄,₁ d₄,₂ d₄,₃ d₄,₄ d₄,₅ d₄,₆ d₄,₇ d₄,₈…

+   - Now, consider a real number generated by taking all the digits dᵢ,ᵢ that lie along the diagonal in this figure and replacing them with different digits.

That real doesn't appear in the list!
