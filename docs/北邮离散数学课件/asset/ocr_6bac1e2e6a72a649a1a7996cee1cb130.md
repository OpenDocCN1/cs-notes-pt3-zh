# # Asymmetric & Antisymmetry

+   - A binary relation $R$ on $A$ is *asymmetric*, if  
+     $(a,b)\in R \rightarrow (b,a)\notin R$.
+     - *E.g.*, $<$ is asymmetric, “likes” is not.
+     - “is married to” is symmetric, “likes” is not.

+   - A binary relation $R$ is *antisymmetric* if  
+     $\forall a\ne b,\ (a,b)\in R \rightarrow (b,a)\notin R$.
+     - **Examples:** $\leq$ is antisymmetric, “likes” is not.
+     - **Exercise:** prove this definition of antisymmetric is equivalent to the statement that $R\cap R^{-1}\subseteq I_A$.
