# # Example 18

Let
S = {a, b, c} and T = {x, y, z}.
It is easy to verify that S and T are semigroup.

Let
f(a) = y
f(b) = x
f(c) = z

| * | a | b | c |
|---|---|---|---|
| a | a | b | c |
| b | b | c | a |
| c | c | a | b |

| * | x | y | z |
|---|---|---|---|
| x | z | x | y |
| y | x | y | z |
| z | y | z | x |

Replacing the elements in S by their images
and rearranging the table, we obtain exactly
the table for T. Thus S and T are isomorphic
