# n-cubes (hypercubes)

+   - For any $n \in \mathbf{N}$, the hypercube $Q_n$ can be defined recursively as follows:
+     - $Q_0 = \{\{v_0\}, \varnothing\}$ (one node and no edges)
+     - For any $n \in \mathbf{N}$, if $Q_n = (V, E)$, where $V = \{v_1, ..., v_a\}$ and $E = \{e_1, ..., e_b\}$, then $Q_{n+1} = (V \cup \{v_1', ..., v_a'\}, E \cup \{e_1', ..., e_b'\} \cup \{\{v_1, v_1'\}, \{v_2, v_2'\}, ..., \{v_a, v_a'\}\})$ where $v_1', ..., v_a'$ are new vertices, and where if $e_i = \{v_j, v_k\}$ then $e_i' = \{v_j', v_k'\}$.
