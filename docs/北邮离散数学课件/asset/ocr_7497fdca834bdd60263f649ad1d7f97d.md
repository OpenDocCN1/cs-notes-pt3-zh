# # Example 3

Consider the semigroup \((\mathbb{Z}, +)\)
\(f(x) = x^2 - x - 2\).

Define
\(a R b \text{ if and only if } f(a) = f(b)\).

It is easy to verify that \(R\) is an equivalence relation,
but \(R\) is not a congruence relation

+   - \(-1 R 2\), since \(f(-1) = f(2) = 0\)
+   - \(-2 R 3\), since \(f(-2) = f(3) = 4\)
+   - but \((-1 + -2) \cancel{R} (2 + 3)\), since \(f(-3) = 10\) and \(f(5) = 18\)
