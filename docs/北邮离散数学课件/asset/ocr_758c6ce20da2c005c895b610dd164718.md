# Example 4

Let S be a fixed nonempty set, and let S<sup>s</sup> be
the set of all functions f : S→S. If f and g
are elements of S<sup>s</sup>, we define f *g as f g,
the composite function.

+   * is a binary operation on S<sup>s</sup>

+   * is associative.

+   (S<sup>s</sup>, *) is a semigroup.

+   The semigroup S<sup>s</sup> is not commutative.
