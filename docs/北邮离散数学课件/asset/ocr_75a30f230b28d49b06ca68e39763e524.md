# ## 7. 零元

给定<**S**,○ >及 θ<sub>l</sub>, θ<sub>r</sub>, θ∈**S**

θ<sub>l</sub>为关于○ 的左零元:=(∀**x**)(**x**∈**S**→θ<sub>l</sub>○ **x** = θ<sub>l</sub>).

θ<sub>r</sub>为关于○ 的右零元:=(∀**x**)(**x**∈**S**→**x**○ θ<sub>r</sub> = θ<sub>r</sub>).

θ为关于○ 的零元:=(∀**x**)(**x**∈**S**→**x**○ θ = **x**○ θ=θ).
