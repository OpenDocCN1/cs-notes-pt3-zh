# Extended Binary Trees

+   - A special case of rooted trees.
+   - Recursive definition of EBTs:
+     - The empty set ∅ is an extended binary tree.
+     - If T₁, T₂ are disjoint EBTs, then e₁ ∪ e₂ ∪ T₁ ∪ T₂ is an EBT, where e₁ = ∅ if T₁ = ∅, and e₁ = {(r, r₁)} if T₁ ≠ ∅ and has root r₁, and similarly for e₂.
