# # Identity – 单位元、幺元

An element \( e \) in a semigroup \( (S, *) \) is called an *identity* element if \( e*a = a*e = a \) for all \( a \in S \).

an identity element must be unique.

# ## Example 8,9

The number 0 is an identity in the semigroup \( (\mathbb{Z}, +) \).

The semigroup \( (\mathbb{Z}^+, +) \) has no identity element
