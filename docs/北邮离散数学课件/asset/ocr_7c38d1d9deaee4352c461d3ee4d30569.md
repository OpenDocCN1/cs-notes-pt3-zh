# Big-O Estimates for some Important Functions

Example: Use big-O notation to estimate the sum of the first n positive integers.

Solution: 1 + 2 + ⋯ + n ≤ n + n + ⋯ n = n²

1 + 2 + … + n is O(n²) taking C = 1 and k = 1.

Example: Use big-O notation to estimate the factorial function f(n) = n! = 1 × 2 × ⋯ × n.

Solution:

n! = 1 × 2 × ⋯ × n ≤ n × n × ⋯ × n = nⁿ

n! is O(nⁿ) taking C = 1 and k = 1.
