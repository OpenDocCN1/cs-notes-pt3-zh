# Theorem 1

+   - Prim’s algorithm produces a minimal spanning tree for the graph G.
+   - Proof
+     - Let G have n vertex. Let T be the spanning tree for G produced by Prim’s algorithm.
+     - Suppose that the edges of T are t₁, t₂, ..., tₙ₋₁ in the order of they were selected.
+     - we define Tᵢ (i=1 to n-1) to be the tree with t₁, t₂, ..., tᵢ and T₀={} Then T₀ ⊂ T₁ ... ⊂ Tₙ₋₁=T.
+     - We now proved that each Tᵢ is contained in a minimal spanning tree for G by mathematical induction.
