# Greatest (least ) element

+   - An element a A is called a **greatest element** of A if x ≤ a for all x ∈ A.
+   - An element a A is called a **least element** of A if a ≤ x for all x ∈ A.
+   - The greatest element of a poset, if it exists, is denoted by *I*, and is often called the **unit** element. Similarly, the least element is called **zero** element.
