# Generalizing Induction

+   - Rule can also be used to prove ∀ n ≥ c P(n) for a given constant c ∈ Z, where maybe c ≠ 0.
+     - In this circumstance, the base case is to prove P(c) rather than P(0), and the inductive step is to prove ∀ n ≥ c (P(n) → P(n+1)).
+   - Induction can also be used to prove ∀ n ≥ c P(aₙ) for any arbitrary series {aₙ}.
+   - Can reduce these to the form already shown.
