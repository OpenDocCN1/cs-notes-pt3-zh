# Finding the Maximum Element in a Finite Sequence

+   - The algorithm in pseudocode:

```
procedure $\mathit{max}(a_1, a_2, \ldots, a_n$: integers)
    $\mathit{max} := a_1$
    for $i := 2$ to $n$
        if $\mathit{max} < a_i$ then $\mathit{max} := a_i$
    return $\mathit{max}$ { $\mathit{max}$ is the largest element }
```
