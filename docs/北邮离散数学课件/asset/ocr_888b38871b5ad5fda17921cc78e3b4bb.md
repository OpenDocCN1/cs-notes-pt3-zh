# # Proof

+   ○ is a binary operation
+   Suppose that ([a], [b)) = ([a'], [b']).
+   a R a' and b R b',
+   a*b R a'*b', since R is a congruence relation.
+   Thus [a*b] = [a'*b'];
+   ○ is a function, is a binary operation on S/R.

+   ○ is an associative
+   [a]○ ([b]○ [c)) = [a]○ [b*c] = [a*(b*c)] = [(a*b)*c]
+   = [a*b]○ [c] = ([a]○ [b))○ [c].
+   Hence S/R is a semigroup.
