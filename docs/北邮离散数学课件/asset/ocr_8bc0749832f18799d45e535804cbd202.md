# Proof

+   - A path from $a$ to $b$ ($x_i = x_j = c$)
+     - $a, x_1, x_2, ..., x_{i-1}, c, x_{j+1}, ..., x_{m-1}, b$
+   - The length is $k = m - j + i$.
+   - The process can continue until $k \le n$, so we have
+     - $R^m \subseteq R^k$
+     - $\forall m\ (m>n \land (a, b) \in R^m \rightarrow \exists k\ (k\le n \land (a, b) \in R^k))$
+   - Therefore
+   
+     $R^{\infty} = \bigcup_{i=1}^{n} R^{i} = R \cup R^{2} \cup \cdots \cup R^{n}$
+     - QED
