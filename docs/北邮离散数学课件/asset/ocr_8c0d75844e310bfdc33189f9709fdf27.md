# Function Composition Operator

+   - For functions $g:A\to B$ and $f:B\to C$, there is a special operator called *compose* (“$igcirc$”).
+     - It _composes_ (creates) a new function out of $f$ and $g$ by applying $f$ to the result of applying $g$.
+     - We say $(f\bigcirc g):A\to C$, where $(f\bigcirc g)(a) := f(g(a))$.
+     - Note $g(a)\in B$, so $f(g(a))$ is defined and $\in C$.
+     - Note that $\bigcirc$ (like Cartesian $\times$, but unlike $+$, $\land$, $\cup$) is non-commuting. (Generally, $f\bigcirc g \neq g\bigcirc f$.)
