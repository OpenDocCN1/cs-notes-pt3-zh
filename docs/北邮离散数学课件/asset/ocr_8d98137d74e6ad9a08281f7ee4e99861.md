# Hamming distance – 海明距离

Let x and y be words in B^m. The *Hamming distance* δ(x, y) between x and y is the weight, |x⊕y|, of x ⊕ y.

The distance between x = x₁x₂...xₘ and y = y₁y₂...yₘ is the number of various of i such that xᵢ ≠ yᵢ, that is, the number of positions in which x and y differ.

Using the weight of x ⊕ y is a convenient way to count the number of different positions.
