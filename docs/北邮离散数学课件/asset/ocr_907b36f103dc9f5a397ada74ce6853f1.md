# ## 1. 结合律

给定<**S**,° >，运算 “ ° ” 满足结合律或者 “ ° ” 是可结合的，即  
(∀z)(x,y,z∈S→(x° y)° z=x(y° z).

例4.1.5. 给定<A,° >，且对任意a, b∈A有a° b=b.  
证明运算 “ ° ” 是可结合的.

证明 因为对任意a, b, c ∈ A,  
(a° b)c=b° c=c,  a° (b° c)=a° c=c

+   - 故(a° b)° c=a° (b° c)
