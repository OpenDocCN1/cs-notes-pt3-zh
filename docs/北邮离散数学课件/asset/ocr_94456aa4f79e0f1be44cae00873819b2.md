# # Big Theta Notation

**Example:** Show that the sum of the first *n* positive integers is Θ(*n*²).

**Solution:** Let *f(n)* = 1 + 2 + ··· + *n*.

+   - We have already shown that *f(n)* is O(*n*²).
+   - To show that *f(n)* is O(*n*²), we need a positive constant *C* such that *f(n)* > *Cn*² for sufficiently large *n*. Summing only the terms greater than *n*/2 we obtain the inequality
+   
+     1 + 2 + ··· + *n* ≥ ⌈*n*/2⌉ + (⌊*n*/2⌋ + 1) + ··· + *n*
+   
+     ≥ ⌈*n*/2⌉ + ⌈*n*/2⌉ + ··· + ⌈*n*/2⌉
+   
+     = (*n* − ⌈*n*/2⌉ + 1)⌈*n*/2⌉
+   
+     ≥ (*n*/2)(*n*/2) = *n*²/4
+   - Taking *C* = ¼, *f(n)* > *Cn*² for all positive integers *n*. Hence, *f(n)* is Ω(*n*²), and we can conclude that *f(n)* is Θ(*n*²).
