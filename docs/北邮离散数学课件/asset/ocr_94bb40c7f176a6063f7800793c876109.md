# 例3

+   - 假设有一个人被每一个喜欢某些人的人所喜欢，又假设没有不喜欢人的人。证明有一个人被所有的人喜欢。
+   - 令
+     - $L(x, y)$：x喜欢y
+   - 前提：
+     - $P_1$：$\exists y\forall x\,(\exists z\,L(z,y)\rightarrow L(x,y))$
+     - $P_2$：$\neg\exists x\forall y\,(\neg L(x,y))$
+   - 结论：
+     - $C$：$\exists x\forall y\,L(y,x)$
+   - 于是，要证明：
+     - $P_1\land P_2\rightarrow C$
