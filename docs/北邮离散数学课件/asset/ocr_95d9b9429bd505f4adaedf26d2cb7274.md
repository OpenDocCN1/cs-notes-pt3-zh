# More functions so far...

+   - A *predicate* can be viewed as a function from *objects* to *propositions* (or truth values): $P :\equiv$ “is 7 feet tall”;
+     $P$(Mike) = “Mike is 7 feet tall.” = **False**.
+   - A *bit string* $B$ of length $n$ can be viewed as a function from the numbers {$1,\dots,n$} (bit *positions*) to the *bits* {$0,1$}.
+     *E.g.,* $B=101$ ➔ $B(3)=1$.
