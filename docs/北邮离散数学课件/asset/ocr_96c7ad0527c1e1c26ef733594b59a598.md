# Theorem 4

+   - Let L be a lattice. Then for every a, b, and c in L,
+   - If a ≤ b, then
+     - a ∨ c ≤ b ∨ c.
+     - a ∧ c ≤ b ∧ c.
+   - a ≤ c and b ≤ c if and only if a ∨ b ≤ c.
+   - c ≤ a and c ≤ b if and only if c ≤ a ∧ b.
+   - If a ≤ b and c ≤ d, then
+     - a ∨ c ≤ b ∨ d.
+     - a ∧ c ≤ b ∧ d.
