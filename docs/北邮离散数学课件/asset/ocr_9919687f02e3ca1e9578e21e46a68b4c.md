# Incidence matrices

+   - Another common way to represent graphs is to use incidence matrices. Let G(V,E) be an undirected graph. Suppose that v₁,v₂,...vₙ are the vertices and e₁,e₂,...eₘ are edges of G. Then the incidence matrix with respect to this ordering of V and E is the nXm matrix M=[mᵢⱼ],where
+   
+   $m_{ij}=\begin{cases}1 & \text{when edge } e_j \text{ is incident with } v_i, \\ 0 & \text{otherwise.}\end{cases}$
