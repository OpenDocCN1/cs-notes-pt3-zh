# # Tables – 运算表

+   - If \( A = \{a_1, a_2, \dots, a_n\} \) is a *finite* set, we can define a binary operation on \( A \) by means of a table

| * | \( a_1 \) | \( a_2 \) | \( \cdots \) | \( a_j \) | \( \cdots \) | \( a_n \) |
|---|---|---|---|---|---|---|
| \( a_1 \) | | | | | | |
| \( a_2 \) | | | | | | |
| \( \vdots \) | | | | | | |
| \( a_i \) | | | | \( a_i * a_j \) | | |
| \( \vdots \) | | | | | | |
| \( a_n \) | | | | | | |
