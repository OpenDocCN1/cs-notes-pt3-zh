# Proof: $x * H = 0 \Rightarrow x = e_H(b)$ for some $b \in B^m$

Note that $x_i + x_i = 0$. So add $x_i$ to $i^{th}$ row and get

$x_i = y_1 \cdot h_{1i} + y_2 \cdot h_{2i} + ... + y_m \cdot h_{mi}$

Letting $b_1 = y_1$, $b_2 = y_2$,..., $b_m = y_m$, we see that $x_1$, $x_2$,..., $x_r$ satisfy the equations in (I). Thus $b = b_1 b_2 ... b_m \in B^m$ and $x = e_H(b)$
