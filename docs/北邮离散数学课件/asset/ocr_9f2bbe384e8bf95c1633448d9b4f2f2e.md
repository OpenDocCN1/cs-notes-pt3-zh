# Proof of Part 3)

+   - Now suppose $S$ is any transitive relation that contains $R$, show $S$ contains $R^\infty$ (that is $R^\infty$ is the smallest such relation).
+   - $R \subseteq S$ so $R^2 \subseteq S^2 \subseteq S$ since $S$ is transitive
+   - Therefore $R^n \subseteq S^n \subseteq S$ for all $n$. (why?)
+   - Hence $S$ must contain $R^\infty$ since it must also contain the union of all the powers of $R$.
+     - Q. E. D.
+     - In fact, we need only consider paths of length $n$ or less.
