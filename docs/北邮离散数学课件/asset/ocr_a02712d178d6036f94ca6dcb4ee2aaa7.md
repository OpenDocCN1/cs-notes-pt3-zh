# Example 8

+   - Let $R$ be the equivalence relation defined in congruence modulo 2, determine $R/A$.
+   - Solution
+     - $R(0)=\{..., -6, -4, -2, 0, 2, 4, 6, ...\}$
+     - $R(1)=\{..., -5, -3, -1, 1, 3, 5, 7, ...\}$
+     - Hence $A/R$ consists of the set of even integers and the set of odd integers
