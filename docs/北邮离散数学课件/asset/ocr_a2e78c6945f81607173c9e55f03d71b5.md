# # Monoid – 独异点、含幺半群

A _monoid_ is a semigroup (S, *) that has an identity.

# ## Example 10

The semigroup _P_(_S_) defined in Example 2 has the identity \(\varnothing\), since for any element \(A \in P(S)\).

\(\varnothing * A = \varnothing \cup A = A = A \cup \varnothing = A * \varnothing\)

Hence _P_(_S_) is a monoid.
