# Forward Reasoning

+   - Have premises *p*, and want to prove *q*.
+     - Find a *s₁* such that *p → s₁*.
+       - Then, modus ponens gives you *s₁*.
+     - Then, find an *s₂* (such that) *s₁ → s₂*.
+       - Then, modus ponens gives you *s₂*.
+     - And hope to eventually get to an *sₙ* ⊃ *sₙ → q*.
+   - The problem with this method is…
+     - It can be tough to see the path looking from *p*.
