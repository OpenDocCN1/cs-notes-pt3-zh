# Formal Proofs

+   - A formal proof of a conclusion C, given premises p₁, p₂, ..., pₙ consists of a sequence of *steps*, each of which applies some inference rule to premises or previously-proven statements (*antecedents*) to yield a new true statement (the *consequent*).
+   - A proof demonstrates that *if* the premises are true, *then* the conclusion is true.
