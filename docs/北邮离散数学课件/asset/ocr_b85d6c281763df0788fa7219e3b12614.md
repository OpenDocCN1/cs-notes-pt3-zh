# The language of propositional logic defined more properly

+   - Atoms: p1, p2, p3, ..

+   - Formulas:命题公式

+   - All atoms are formulas

+   - If α is a formula then ¬ α is a formula

+   - If α and β are formulas then the following are formulas: (α ∧ β), (α ∨ β), (α → β) (etc.)

+   - Examples of formulas:
+   (p1 ∨ ¬ p2), ¬ ¬ ¬(p9 → p8), (p1∧ (p2 ∨ p3))

+   - etc.
