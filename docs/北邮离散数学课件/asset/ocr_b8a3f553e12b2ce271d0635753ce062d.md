# [定理5]:

设 | A | = n， R 是 A 上二元关系，则存在正整数 k， k ≤ n，使 R* = R ∪ R² ∪ ... ∪ R^k。

# 证明：

对 ∀ ( x， y ) ∈ R*， ∃ k，使 ( x， y ) ∈ R^k，表明在 A 中存在不同元素 a₁， a₂， ...， a_{k-1}，使 ( x， a₁ )， ( a₁， a₂ )， ( a₂， a₃ )， ...， ( a_{k-1}， y ) ∈ R。

若 k > n，由鸽洞原理，则 a₁， a₂， ...， a_{k-1}， y 中至少有两个相同，不妨设 a_i = y， ( i ≤ k − 1 )。
