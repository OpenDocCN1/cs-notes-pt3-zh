# # Note

+   - It’s customary to denote binary operations
+   by a symbol such as *, instead of _f_, and to
+   denote the element assigned to (_a_, _b_) by
+   _a_*_b_ [instead of *(_a_, _b_)]
+   .

+   - _A_ is _closed_(封闭的) _under the operation_ * ,
+   if _a_ and _b_ are elements in _A_, _a_*_b_∈_A_.
