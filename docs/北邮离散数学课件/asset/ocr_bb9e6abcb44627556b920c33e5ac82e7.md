# Fibonacci Numbers

Example 4: Show that whenever n ≥ 3, fₙ > αⁿ⁻², where α = (1 + √5)/2.

Solution: Let P(n) be the statement fₙ > αⁿ⁻². Use strong induction to show that P(n) is true whenever n ≥ 3.

+   - BASIS STEP: P(3) holds since α < 2 = f₃
+     P(4) holds since α² = (3 + √5)/2 < 3 = f₄.

+   - INDUCTIVE STEP: Assume that P(j) holds, i.e., fⱼ > αʲ⁻² for all integers j with 3 ≤ j ≤ k, where k ≥ 4. Show that P(k + 1) holds, i.e., fₖ₊₁ > αᵏ⁻¹.

+   - Since α² = α + 1 (because α is a solution of x² − x − 1 = 0), αᵏ⁻¹ = α² · αᵏ⁻³ = (α + 1)·αᵏ⁻³ = α·αᵏ⁻³ + 1·αᵏ⁻³ = αᵏ⁻² + αᵏ⁻³

+   - By the inductive hypothesis, because k ≥ 4 we have fₖ₋₁ > αᵏ⁻³, fₖ₋₁ > αᵏ⁻².

+   - Therefore, it follows that fₖ₊₁ = fₖ + fₖ₋₁ > αᵏ⁻² + αᵏ⁻³ = αᵏ⁻¹.

+   - Hence, P(k + 1) is true.
