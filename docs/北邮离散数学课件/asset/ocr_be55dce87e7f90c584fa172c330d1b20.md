# 构造推理的证明(举例、续)

+   - 前提: ¬∃x(F(x)∧H(x)), ∀x(G(x)→H(x)), 结论: ∀x(G(x)→¬F(x))

+   - 证明: (1) ¬∃x(F(x)∧H(x)) 前提引入
+     (2) ∀x(¬F(x)∨¬H(x)) (1)置换
+     (3) ∀x(H(x)→¬F(x)) (2)置换
+     (4) H(y)→¬F(y) (3) UI
+     (5) ∀x(G(x)→H(x)) 前提引入
+     (6) G(y)→H(y) (5) UI
+     (7) G(y)→¬F(y) (4)(6)假言三段论
+     (8) ∀x(G(x)→¬F(x)) (7) UG
