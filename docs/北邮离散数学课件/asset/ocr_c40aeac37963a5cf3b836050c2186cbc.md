# # Limits on Proofs

+   - Some very simple statements of number theory haven’t been proved or disproved!
+     - _E.g. Goldbach’s conjecture_: Every integer \(n\ge2\) is exactly the average of some two primes.
+     - \(\forall n\ge2\ \exists\) primes \(p,q\): \(n=(p+q)/2\).

+   - There are true statements of number theory (or any sufficiently powerful system) that can _never_ be proved (or disproved) (Gödel).
