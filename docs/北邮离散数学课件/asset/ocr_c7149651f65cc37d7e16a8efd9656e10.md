# A Cool (Literally) Application

+   - In a computer, the function mapping the machine’s _state at clock cycle #t_ to its _state at clock cycle #t+1_ is called the computer’s _transition function_.
+   - If the transition function happens to be reversible (a bijection), then the computer’s operation, in theory, requires _no energy expenditure_.
+   - The study of practical low-power _reversible computing_ techniques based on this idea is an area of research.
