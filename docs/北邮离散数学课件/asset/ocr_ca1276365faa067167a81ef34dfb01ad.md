# Quantifier Equivalence Laws

+   - Expanding quantifiers: If u.d.=a,b,c,...
+     ∀x P(x) ↔ P(a) ∧ P(b) ∧ P(c) ∧ ...
+     ∃x P(x) ↔ P(a) ∨ P(b) ∨ P(c) ∨ ...
+   - From those, we can prove the laws:
+     ∀x P(x) ↔ ¬∃x ¬P(x)
+     ∃x P(x) ↔ ¬∀x ¬P(x)
+   - Which *propositional* equivalence laws can be used to prove this?
