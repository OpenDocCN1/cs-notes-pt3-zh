# Strong Induction

+   - In the strong form of mathematical induction, the preceding (前述的) Inductive Step
+     - For every *n*, *assume* that *S(n)* is true and *prove* that *S(n+1)* is true.
+   - is replaced by
+     - For every *n*, *assume* that *S(k)* is true *for all k < n + 1* and *prove* that *S(n+1)* is true.
