# Example: Geometric
Progression

+   - A *geometric progression* is a series of the form $a, ar, ar^2, ar^3, \ldots, ar^k$, where $a,r\in\mathbb{R}$.

+   - The sum of such a series is given by:

$$S=\sum_{i=0}^{k} ar^i$$

+   - We can reduce this to *closed form* via clever manipulation of summations...
