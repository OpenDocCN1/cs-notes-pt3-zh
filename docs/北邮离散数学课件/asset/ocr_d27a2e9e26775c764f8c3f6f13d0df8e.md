# 构造推理的证明(举例、续)

+   - 前提： ∀x(F(x)→G(x))， ∃xF(x)
+     结论： ∃xG(x)
+     证明： (1) ∃xF(x)          前提引入
+             (2) F(c)            (1) EI
+             (3) ∀x(F(x)→G(x))   前提引入
+             (4) F(c)→G(c)       (3) UI
+             (5) G(c)            (2)(4)假言推理
+             (6) ∃xG(x)          (5) EG
