# Remarks

+   - The problem we have been considering has a number of important variations. In one case, the edges may have *weights* representing distance, cost, and the like. The problem is then to find a Hamiltonian circuit (or path) for which the total sum of weights in the path is a minimum. For example, the vertices might represent cities, the edges, lines of transportation; and the weight of an edge, the cost of traveling along that edge. This version of the problem is often called *the traveling salesperson problem*.
