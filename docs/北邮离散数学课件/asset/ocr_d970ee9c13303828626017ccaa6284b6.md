# Proof of Part 1)

+   - Suppose $(x, y)$ and $(y, z)$ are in $R^\infty$. Show $(x, z)$ is in $R^\infty$.
+     - By definition of $R^\infty$, $(x, y)$ is in $R^m$ for some $m$ and $(y, z)$ is in $R^n$ for some $n$.
+     - Then $(x, z)$ is in $R^n\quad R^m = R^{m+n}$ which is contained in $R^\infty$.
+     - Hence, $R^\infty$ must be transitive.
