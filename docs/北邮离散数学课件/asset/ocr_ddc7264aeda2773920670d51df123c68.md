# Example : The Fibonacci numbers are defined as follows:

f₀ = 0
f₁ = 1
fₙ = fₙ₋₁ + fₙ₋₂

Find f₂, f₃, f₄, f₅.

+   - f₂ = f₁ + f₀ = 1 + 0 = 1
+   - f₃ = f₂ + f₁ = 1 + 1 = 2
+   - f₄ = f₃ + f₂ = 2 + 1 = 3
+   - f₅ = f₄ + f₃ = 3 + 2 = 5

In Chapter 8, we will use the Fibonacci numbers to model population growth of rabbits. This was an application described by Fibonacci himself.
