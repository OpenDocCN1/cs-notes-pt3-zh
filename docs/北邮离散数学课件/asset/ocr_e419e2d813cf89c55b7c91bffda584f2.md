# Hamiltonian Path Theorems

+   - **Dirac’s theorem:** If (but not only if) $G$ is connected, simple, has $n\geq3$ vertices, and $\forall v\ \text{deg}(v)\geq n/2$, then $G$ has a Hamilton circuit.
+     - **Ore’s corollary:** If $G$ is connected, simple, has $n\geq3$ nodes, and $\text{deg}(u)+\text{deg}(v)\geq n$ for every pair $u,v$ of non-adjacent nodes, then $G$ has a Hamilton circuit.
