# Uncountability of Reals, fin.

+   - *E.g.,* a postulated enumeration of the reals:
+     $r_1 = 0.301948571...$
+     $r_2 = 0.103918481...$
+     $r_3 = 0.039194193...$
+     $r_4 = 0.918237461...$

+   - OK, now let’s add 1 to each of the diagonal digits (mod 10), that is changing 9’s to 0.
+     $-0.4103...$ can’t be on the list anywhere!
