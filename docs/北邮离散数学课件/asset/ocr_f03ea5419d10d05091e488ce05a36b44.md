# Inverse Relations

+   - Any binary relation $R:A\times B$ has an *inverse* relation $R^{-1}:B\times A$, defined by
+     $$R^{-1}:=\{(b,a)\mid(a,b)\in R\}.$$ 
+     *E.g.,* $<^{-1}=\{(b,a)\mid a<b\}=\{(b,a)\mid b>a\}=>$.

+   - *E.g.,* if $R:\text{People}\to\text{Foods}$ is defined by
+     $$a\ R\ b\ \Leftrightarrow\ a\ eats\ b,$$
+     then:
+     $$b\ R^{-1}\ a\ \Leftrightarrow\ b\ is\ eaten\ by\ a.$$ (Passive voice.)
