# # Using the Definition of Big-O Notation

Example: Show that 7x² is O(x³).

Solution: When x > 7, 7x² < x³. Take C = 1 and k = 7 as witnesses to establish that 7x² is O(x³).

(Would C = 7 and k = 1 work?)

Example: Show that n² is not O(n).

Solution: Suppose there are constants C and k for which n² ≤ Cn, whenever n > k. Then (by dividing both sides of n² ≤ Cn by n, then n ≤ C must hold for all n > k. A contradiction!
