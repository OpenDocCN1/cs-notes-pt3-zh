# 求主合取范式的方法之二：等值演算法

+   - 利用十六个命题公式、命题定理用等值演算法的方法一步步将它化为主析取范式。
+   - 第一步：将公式化为合取范式，“消去”含有永真式的简单析取式，这是因为（P ∨ ¬P ∨ Q）∧ G ⇔ G，而P ∨ P用P代替。
+   - 第二步：若合取范式中的简单析取式项不是极大项，即该项中缺命题变项，则添加（Pᵢ ∧ ¬Pᵢ）再用分配律展开。  - 例如：公式中含P、Q、R，某析取项为P ∨ ¬R，缺Q。则P ∨ ¬R ⇔ P ∨ ¬R ∨（Q ∧ ¬Q） ⇔ （P ∨ Q ∨ ¬R） ∧ （P ∨ ¬Q ∨ ¬R）
+   - 第三步：用幂等律将重复的极大项删去，即Mᵢ ∨ Mᵢ ⇔ Mᵢ然后将各极大项按顺序排列。
