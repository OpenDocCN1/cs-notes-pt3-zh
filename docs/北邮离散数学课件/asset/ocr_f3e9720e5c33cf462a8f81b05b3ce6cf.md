# 例 1：

A = { 5 2 张扑克 }

R₁ = { ( a , b ) | a 与 b 同花， a ， b 是扑克 }

R₂ = { ( a , b ) | a 与 b 同点， a ， b 是扑克 }

则： R₁ 把 A 分为四类同花类，

R₂ 把 A 分为 1 3 类同点类。
