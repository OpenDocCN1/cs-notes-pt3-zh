# # Theorem 3

If \( m, n, r, \mathbf{H}, \) and \( f_H \) are as defined, then \( f_H \) is onto.

# ## Proof

Let \( b = b_1b_2\dots b_r \) be any element in \( B^r \).

Letting \( x = 0_1\dots 0_m b_1b_2\dots b_r \)

Then \( x^*\mathbf{H} = b \).

Thus \( f_H(x) = b \), so \( f_H \) is onto.

Q.E.D
