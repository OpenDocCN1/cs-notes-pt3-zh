# # Wheels

+   - For any \(n\ge 3\), a **wheel** \(W_n\), is a simple graph obtained by taking the cycle \(C_n\) and adding one extra vertex \(v_{\mathrm{hub}}\) and \(n\) extra edges \(\{\{v_{\mathrm{hub}},v_1\},\{v_{\mathrm{hub}},v_2\},\ldots,\{v_{\mathrm{hub}},v_n\}\}\).
