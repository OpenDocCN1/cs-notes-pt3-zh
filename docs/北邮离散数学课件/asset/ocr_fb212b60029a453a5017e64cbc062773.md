# Recursively Defined Functions

Definition: A *recursive* or *inductive* definition of a function consists of two steps.

+   - BASIS STEP: Specify the value of the function at zero.
+   - RECURSIVE STEP: Give a rule for finding its value at an integer from its values at smaller integers.

A function $f(n)$ is the same as a sequence $a_0$, $a_1$, ..., where $a_i$, where $f(i) = a_i$. This was done using recurrence relations in Section 2.4.
