# Theorem 4

+   - Suppose that $(A, \le)$ and $(A', \le')$ are isomorphic posets under the isomorphism $f: A \to A'$.
+     - If $a$ is a maximal (minimal) element of $(A, \le)$, then $f(a)$ is a maximal (minimal) element of $(A', \le')$.
+     - If $a$ is a greatest (least) element of $(A, \le)$, then $f(a)$ is a greatest (least) element of $(A', \le')$.
+     - If $a$ is an upper bound (lower bound, least upper bound, greatest lower bound) of $(A, \le)$, then $f(a)$ is an upper bound (lower bound, least upper bound, greatest lower bound) of $(A', \le')$.
+     - If every subset of $(A, \le)$ has a LUB (GLB), then every subset of $(A', \le')$ has a LUB (GLB).
