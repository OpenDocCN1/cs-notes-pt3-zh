# # 4.1 运算、代数系统与特异元素

# ## 6. 幺元或单位元

+   - 给定<**S**,○ >且，e<sub>l</sub>, e<sub>r</sub>, e∈**S**, 则  
+     e<sub>l</sub>: 为关于○ 的左幺元:=(∀x)(x∈**S**→ e<sub>l</sub>○ x=x)  
+     e<sub>r</sub>: 为关于○ 的右幺元:=(∀x)(x∈**S**→ x○ e<sub>r</sub>=x)

+   - 若e既为○ 的左幺元又为○ 的右幺元，称e为关于○ 的幺元. 亦可定义如下:  
+     e为关于○ 的幺元:=(∀x)(x∈**S**→e○ x=x○ e=x)
