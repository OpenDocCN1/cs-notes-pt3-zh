### Congruence relation – 同余关系

An equivalence relation _R_ on the semigroup (S, *) is called a **congruence relation** if _a R a'_ and _b R b'_ imply (_a_*_b_) _R_ (_a'_*_b'_)

### Example 1

Consider the semigroup \((\mathbb{Z}, +)\) and the equivalence relation \(R\) on \(\mathbb{Z}\) defined by
\(a R b \text{ if and only if } a \equiv b \pmod{2}\).
If \(a \equiv b \pmod{2}\), then \(2 \mid (a - b)\).
Show that this relation is a congruence relation.

### Example 1 - Solution

R is an equivalence relation (omitted).
R is a congruence relation

If \(a \equiv b \, (\text{mod } 2)\) and \(c \equiv d \, (\text{mod } 2)\)
\(2 \mid a-b\) and \(2 \mid c-d\).
So \(a-b = 2m\) and \(c-d = 2n\), where \(m\) and \(n\) are integers.
\((a-b) + (c-d) = 2m + 2n\)
\((a+c) - (b+d) = 2(m+n)\),
so \(a+c \equiv b+d \, (\text{mod } 2)\).
Hence the relation is a congruence relation.

### Example 3

Consider the semigroup \((\mathbb{Z}, +)\)
\(f(x) = x^2 - x - 2\).

Define
\(a R b \text{ if and only if } f(a) = f(b)\).

It is easy to verify that \(R\) is an equivalence relation,
but \(R\) is not a congruence relation

- \(-1 R 2\), since \(f(-1) = f(2) = 0\)
- \(-2 R 3\), since \(f(-2) = f(3) = 4\)
- but \((-1 + -2) \cancel{R} (2 + 3)\), since \(f(-3) = 10\) and \(f(5) = 18\)

## Theorem 2

Let _R_ be a congruence relation on the semigroup (S, *).

Consider the relation ◦ from S/R × S/R to S/R in which the ordered pair ([_a_], [_b_]) is, for _a_ and _b_ in S, related to [_a_*_b_].

◦([_a_], [_b_]) = [_a_]◦ [_b_] = [_a_*_b_], is a function from S/R×S/R to S/R

(S/R, ◦ ) is a semigroup. S/R is called the **_quotient semigroup(_商半群_)_ or _factor semigroup_**

### Proof

- ◦ is a binary operation
- Suppose that ([a], [b]) = ([a'], [b']).
- a R a' and b R b',
- a*b R a'*b', since R is a congruence relation.
- Thus [a*b] = [a'*b'];
- ◦ is a function, is a binary operation on S/R.

- ◦ is an associative
- [a]○ ([b]○ [c]) = [a]○ [b*c] = [a*(b*c)] = [(a*b)*c]
- = [a*b]○ [c] = ([a]○ [b])○ [c].
- Hence S/R is a semigroup.

### Corollary

Let _R_ be a congruence relation on the monoid (S, *). If we define the operation \(\odot\) in S/R by \([a]\odot [b]=[a*b]\), then \((S/R, \odot)\) is a monoid.

#### Proof

If _e_ is the identity in (S, *), then it is easy to verify that [_e_] is the identity in \((S/R, \odot)\).

## Theorem 3

Let
R be a congruence relation on a semigroup
(S, *), and
(S/R, ⊙ ) be the corresponding quotient
semigroup.
Then the function
f_R: S → S/R
defined by
f_R(a) = [a]
is an onto homomorphism, called the
natural homomorphism(自然同态).
