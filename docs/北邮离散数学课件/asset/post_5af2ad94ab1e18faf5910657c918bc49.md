
## Modular Exponentiation Problem (from § 4.2, p. 253)

- **Problem:** Given large integers *b* (base), *n* (exponent), and *m* (modulus), efficiently compute *bⁿ mod m*.
  - Note that *bⁿ* *itself* may be completely infeasible to compute and store directly.
  - *E.g.* if *n* is a 1,000-bit number, then *bⁿ* itself will have far more *digits* than there are atoms in the universe!
- Yet, this is a type of calculation that is commonly required in modern cryptographic algorithms!

## Example: To Compute 3¹¹

- 11 = (1011)₂, so 3¹¹ = 3⁸ · 3² · 3¹. First compute 3² = 9, and then 3⁴ = 9² = 81, and 3⁸ = (3⁴)² = (81)² = 6561, so 3¹¹ = 6561 · 9 · 3 = 177147.
- The algorithm successively finds \(b \bmod m\), \(b^2 \bmod m\), \(b^4 \bmod m\), ..., \(b^{2^{k-1}} \bmod m\), and multiplies together those terms.
- To compute 3¹¹ mod 7: 177147 mod 7 = 5.
- 3 mod 7 = 3; 3² mod 7 = 2; (3²)² mod 7 = 2 · 2 mod 7 = 4.
- ((3²)²)² mod 7 = 4 · 4 mod 7 = 2.
- 3¹¹ mod 7 = ((3⁸ mod 7) · (3² mod 7) · (3¹ mod 7)) mod 7 = 2 · 2 · 3 mod 7 = 5.

## Algorithm

```text
procedure modular exponentiation (b: integer, n = (a_{k-1}a_{k-2}\ldots a_1a_0)_2, m: positive integer)
  x := 1
  power := b mod m
  for i := 0 to k-1
    if a_i = 1 then x := (x · power) mod m
    power := (power · power) mod m
  end
{ x equals b^n mod m }
```

- It uses \(O((\log m)^2 \log n)\) bit operations.

## Example

- Compute \(3^{644} \bmod 645\).
  - First note that \(644 = (1010000100)_2\).
  - At the beginning, \(x = 1\), power = \(3 \bmod 645 = 3\).
  - \(i = 0\), \(a_0 = 0\), \(x = 1\), power = \(3^2 \bmod 645 = 9\).
  - \(i = 1\), \(a_1 = 0\), \(x = 1\), power = \(9^2 \bmod 645 = 81\).
  - \(i = 2\), \(a_2 = 1\), \(x = 1 \cdot 81 \bmod 645 = 81\), power = \(81^2 \bmod 645 = 6561 \bmod 645 = 111\).
  - \(i = 3\), \(a_3 = 0\), \(x = 81\), power = \(111^2 \bmod 645 = 12321 \bmod 645 = 66\).
  - \(i = 4\), \(a_4 = 0\), \(x = 81\), power = \(66^2 \bmod 645 = 4356 \bmod 645 = 486\).
  - \(i = 5\), \(a_5 = 0\), \(x = 81\), power = \(486^2 \bmod 645 = 236196 \bmod 645 = 126\).
  - \(i = 6\), \(a_6 = 0\), \(x = 81\), power = \(126^2 \bmod 645 = 15876 \bmod 645 = 396\).
  - \(i = 7\), \(a_7 = 1\), \(x = (81 \cdot 396) \bmod 645 = 471\), power = \(396^2 \bmod 645 = 156816 \bmod 645 = 81\).
  - \(i = 8\), \(a_8 = 0\), \(x = 471\), power = \(81^2 \bmod 645 = 6561 \bmod 645 = 111\).
  - \(i = 9\), \(a_9 = 1\), \(x = (471 \cdot 111) \bmod 645 = 36\).

\(3^{644} \bmod 645 = 36\)

## Modular Exponentiation

```text
procedure modularExponentiation(b: integer, n = (n_{k-1}...n_0)_2, m: positive integer)
  x := 1    {result will be accumulated here}
  b2i := b mod m    { b^{2^i} mod m; i=0 initially }
  for i := 0 to k-1    {go thru all k bits of n}
    if n_i = 1 then x := (x·b2i) mod m
    b2i := (b2i·b2i) mod m
  return x
```

\(b^{2^{i+1}} = b^{2 \cdot 2^{i}} = (b^{2^{i}}) \cdot (b^{2^{i}})\)

## Why That Algorithm Works

- Note that:
  \(b^n = b^{n_{k-1}2^{k-1}+n_{k-2}2^{k-2}+\cdots+n_0 2^0}\)
  \(= (b^{2^{k-1}})^{n_{k-1}} \times (b^{2^{k-2}})^{n_{k-2}} \times \cdots \times (b^{2^0})^{n_0}\), where \(n_{k-1}\cdots n_0\) is the binary expansion of \(n\).
  Also \(b^{2^0} = b^1 = b\).
- We can compute \(b\) to various powers of 2 by repeated squaring.
  - Then multiply them into the partial product, or not, depending on whether the corresponding \(n_i\) bit is 1.
- Crucially, we can do the **mod** \(m\) operations as we go along, because of the various identity laws of modular arithmetic. — All the numbers stay small.

## Example

- Compute 3⁶⁵⁴ mod 645.
- First note that 654 = (1010001110)₂.
- At the beginning, x = 1, power = 3 mod 645 = 3.
- i = 0, a₀ = 0, x = 1, power = 3² mod 645 = 9.
- i = 1, a₁ = 1, x = 1 · 9 mod 645 = 9, power = 9² mod 645 = 81.
- i = 2, a₂ = 1, x = 9 · 81 mod 645 = 84, power = 81² mod 645 = 6561 mod 645 = 111.
- i = 3, a₃ = 1, x = 84 · 111 mod 645 = 294, power = 111² mod 645 = 12321 mod 645 = 66.
- i = 4, a₄ = 0, x = 294, power = 66² mod 645 = 4356 mod 645 = 486.
- i = 5, a₅ = 0, x = 294, power = 486² mod 645 = 236196 mod 645 = 126.
- i = 6, a₆ = 0, x = 294, power = 126² mod 645 = 15876 mod 645 = 396.
- i = 7, a₇ = 1, x = (294 · 396) mod 645 = 324, power = 396² mod 645 = 156816 mod 645 = 81.
- i = 8, a₈ = 0, x = 324, power = 81² mod 645 = 6561 mod 645 = 111.
- i = 9, a₉ = 1, x = (324 · 111) mod 645 = 489.
- 3⁶⁵⁴ mod 645 = 489.
