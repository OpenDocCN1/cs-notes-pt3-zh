
## Induction Example (1st princ.)
- Prove that the sum of the first *n* odd positive integers is *n*². That is, prove:
  
  ∀*n* ≥ 1: Σ_{i=1}^{n} (2*i* − 1) = *n*²

- Proof by induction.
  - Base case: Let *n*=1. The sum of the first 1 odd positive integer is 1 which equals 1². (Cont…)

## Example cont.
- Inductive step: Prove ∀n≥1: P(n)→P(n+1).
  - Let n≥1, assume P(n), and prove P(n+1).

∑_{i=1}^{n+1} (2i − 1) = (∑_{i=1}^{n} (2i − 1)) + (2(n+1)−1)
= n² + 2n + 1
= (n+1)²

*By inductive hypothesis P(n)*

## Another Induction Example
- Prove that ∀n>0, n<2ⁿ. Let P(n)=(n<2ⁿ)
  - Base case: P(1)=(1<2¹)=(1<2)=T.
  - Inductive step: For n>0, prove P(n)→P(n+1).
    - Assuming n<2ⁿ, prove n+1 < 2ⁿ⁺¹.
    - Note n + 1 < 2ⁿ + 1 (by inductive hypothesis)
      < 2ⁿ + 2ⁿ (because 1<2=2·2⁰≤2·2ⁿ⁻¹=2ⁿ)
      = 2ⁿ⁺¹
    - So n + 1 < 2ⁿ⁺¹, and we’re done.

## Proof by Induction
- **Basis Step(基始)**. Prove that S(k) is true for some (small) value of k.
- **Inductive Step（归纳）**. For every *n*, *assume* that S(n) is true and *prove* that S(n+ 1) is true.
- Together, these prove ∀i ≥ k:P(i)

## Fibonacci Numbers（斐波那契数列）
- The Fibonacci sequence 0, 1, 1, 2, 3, 5, ... is defined by the following formula
  
  F(0) = 0
  
  F(1) = 1
  
  F(n) = F(n-1) + F(n-2)

## Fibonacci Sums
0+1 = 1
0+1+1 = 2
0+1+1+2 = 4
0+1+1+2+3 = 7
0+1+1+2+3+5 = 12
0+1+1+2+3+5+8 = 20

What’s the pattern?

∑_{i=0}^{n} F(i) = F(n + 2) − 1

## Fibonacci Sums
- Let’s verify （证明） this using induction:
  - We need to verify a base case
  - Then we assume the formula （公式） holds for n and show it holds for n+1.

## Base Case
N=0

∑_{i=0}^{n} F(i) = 0

F(n + 2) − 1 = 1 − 1

## Inductive Step
∑_{i=0}^{n+1} F(i)
= F(n + 1) + ∑_{i=0}^{n} F(i)
= F(n + 1) + F(n + 2) - 1
= F(n + 3) - 1

Assumption（假定）：
∑_{i=0}^{n} F(i) = F(n + 2) - 1

Conclusion（结论）
∑_{i=0}^{n+1} F(i) = F(n + 3) - 1

## Example 1
- Show,by mathematical induction,that for all n≥1,
  $1+2+3+\cdots+n = \frac{n(n+1)}{2}$
- Solution $1+2+3+\cdots+n = \frac{n(n+1)}{2}$
  - Let $p(n)$ be the predicate $1+2+3+\cdots+n = \frac{n(n+1)}{2}$
  - BS: $n_0=1$, $1 = \frac{1(1+1)}{2}$ $p(1)$ is true.
  - IS:assume for some fixed $k\ge1$, $p(k)$ is true.

1 + 2 + 3 + ⋯ + (k + 1)  the left-hand side of P(k+1)
= k(k + 1)/2 + (k + 1)      using(1) to replace 1+2+⋯+k
= (k + 1)[k/2 + 1]          factoring
= (k + 1)(k + 2)/2
= (k + 1)((k + 1) + 1)/2    the right-hand side of P(k+1)

- p(k+1) is true.
- By the principle of mathematical induction, p(n) is true for n≥1.
- Q.E.D

## Example 2
- Let $A_1, A_2 \dots, A_n$ be any $n$ sets. Show that
  
  $$\overline{\left(\bigcup_{i=1}^{n} A_i\right)} = \bigcap_{i=1}^{n} \overline{A_i}$$

- Solution
  - Let $P(n)$ be the predicate that the equality hold for any $n$ sets.

- BS: , P(1) is true.
- IS: $\overline{A_1} = \overline{A_1}$
$\overline{\left(\bigcup_{i=1}^{k+1} A_i\right)} = \overline{A_1 \cup A_2 \cup \cdots \cup A_k \cup A_{k+1}}$ left-hand side of P(k+1)
$= \overline{(A_1 \cup A_2 \cup \cdots \cup A_k) \cup A_{k+1}}$ associative property of $\cup$
$= \overline{(A_1 \cup A_2 \cup \cdots \cup A_k)} \cap \overline{A_{k+1}}$ by the De Morgan's law
$= \left(\bigcap_{i=1}^{k} \overline{A_i}\right) \cap \overline{A_{k+1}}$ using P(k)
- $P(k+1)$ is true. $= \bigcap_{i=1}^{k+1} \overline{A_i}$ right-hand side of P(k+1)
- By the principle of mathematical induction $P(n)$ is true for all $n \ge 1.$

## Number of Subsets of a Finite Set
**Example**: Use mathematical induction to show that if $S$ is a finite set with $n$ elements, where $n$ is a nonnegative integer, then $S$ has $2^n$ subsets.

* (Chapter 6 uses combinatorial methods to prove this result.)

**Solution**: Let $P(n)$ be the proposition that a set with $n$ elements has $2^n$ subsets.

- Basis Step: $P(0)$ is true, because the empty set has only itself as a subset and $2^0 = 1.$

- Inductive Step: Assume $P(k)$ is true for an arbitrary nonnegative integer $k.$
