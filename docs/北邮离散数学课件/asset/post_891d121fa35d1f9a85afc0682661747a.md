
## Shortest Path (Dijkstra’s) Algorithm

```text
**procedure Dijkstra**(G: weighted connected simple graph, with all weights positive)
{G has vertices a = v₀, v₁, ..., vₙ = z and weights w(vᵢ, vⱼ) where w(vᵢ, vⱼ)=∞ if {vᵢ, vⱼ} is not an edge in G}
**for** i:=1 to n
    L(vᵢ) := ∞
L(a) := 0
S := ∅
{the labels are now initialized so that the label of a is 0 and all other labels are ∞, and S is the empty set}
**while** z ∉ S
**begin**
    u := a vertex not in S with L(u) minimal
    S := S ∪ {u}
    **for** all vertices v not in S
        **if** L(u) + w(u, v) < L(v) **then** L(v) := L(u) + w(u, v)
    {this adds a vertex to S with minimal label and updates the labels of vertices not in S}
**end** {L(z) = length of a shortest path from a to z}
```

  - Electric power grid
  - Communicating network

## Problem

- There are two types of such problems
  - Determining the shortest path from a vertex to an assigned vertex.
  - Determining the shortest path of any two vertices in the graph.

## Dijkstra(迪杰斯特拉) Algorithm

- The algorithm is to find the shortest way from v₁ to vₙ, at the same time, it gets the shortest way from v₁ to each other vertices in the graph.

## Example 1

- Let $l_i$ represent the length from $v_1$ to $v_i$
- Let $d_{ij}$ represent the length of the edge $(v_i, v_j)$
- Find the shortest path from $v_1$ to $v_{11}$

![](img/c25dfd82fc242c2db53bc942dcad6885_1585_0.png)

![](img/c25dfd82fc242c2db53bc942dcad6885_1586_0.png)

- Find the set of adjacent vertices of $v_1$, which are $\{v_2, v_3, v_4\}$
- Find the length from $v_1$ to the vertices in the set.
  - $l_2 = d_{12} = 2$  $l_3 = d_{13} = 8$  $l_4 = d_{14} = 1$
- Find the shortest length of $l_2, l_3, l_4$
  - $\min\{l_2, l_3, l_4\} = l_4 = 1$
- Connect $v_1$ to $v_4$

![](img/c25dfd82fc242c2db53bc942dcad6885_1587_0.png)

- Find the set of adjacent vertices of {v₁, v₄} which are {v₂, v₃, v₇}
- Find the length from v₁ to the vertices in the set.
  - l₂ = 2
  - l₃ = 8
  - l₇ = l₄ + d₄₇ = 1 + 9 = 10
- Find the shortest length of l₂, l₃, l₇
  - Min{l₂, l₃, l₇} = l₂ = 2
- Connect v₁ to v₂

![](img/c25dfd82fc242c2db53bc942dcad6885_1588_0.png)

- Find the set of adjacent vertices of {v₁, v₂, v₄} which are {v₃, v₅, v₇}
- Find the length from v₁ to the vertices in the set.
  - l₃ = min{8, l₂ + d₂₃, l₄ + d₄₃} = min{8, 8, 8} = 8
  - l₅ = l₂ + d₂₅ = 3
  - l₇ = l₄ + d₄₇ = 10
- min{l₃, l₅, l₇} = l₅ = 3
- Connect v₂ to v₅

![](img/c25dfd82fc242c2db53bc942dcad6885_1589_0.png)

- Find the set of adjacent vertices of {v₁, v₂, v₄, v₅} which are {v₃, v₆, v₇, v₈, v₉}
- Find the length from v₁ to the vertices in the set.
  - l₃ = 8
  - l₆ = l₅ + d₅₆ = 6
  - l₇ = 10
  - l₈ = l₅ + d₅₈ = 5
  - l₉ = l₅ + d₅₉ = 12
- Min{l₃, l₆, l₇, l₈, l₉} = l₈ = 5
- Connect v₅ to v₈

### Step 5

![](img/c25dfd82fc242c2db53bc942dcad6885_1590_0.png)

- Find the set of adjacent vertices of {v₁, v₂, v₄, v₅, v₈} which are {v₃, v₆, v₇, v₉, v₁₁}
- Find the length from v₁ to the vertices in the set.
  - l₃ = 8
  - l₆ = l₅ + d₅₆ = 6
  - l₇ = 10
  - l₉ = l₈ + d₈₉ = 12
  - l₁₁ = l₈ + d_{8,11} = 14
- Min{l₃, l₆, l₇, l₉, l₁₁} = l₆ = 6
- Connect v₁ to v₆.
