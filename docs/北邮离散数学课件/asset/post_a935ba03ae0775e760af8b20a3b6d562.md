
## Associative（结合律）

- If \(\circ\) is a binary operation, then \(\circ\) is associative or has the associative property if \((x \circ y) \circ z = x \circ (y \circ z)\).
- Example
  - Set union is an associative operation, since \((A \cup B) \cup C = A \cup (B \cup C)\) is always true.

## Distributive property（分配律）

- If a mathematical structure has two binary operations, say \(\circ\) and \(\vee\), a distributive property has the following pattern:

\[
x \circ (y \vee z) = (x \circ y) \vee (x \circ z)
\]

- Example
  - (a) We are familiar with the distributive property for real numbers; if \(a\), \(b\), and \(c\) are real numbers, then
    \[
    a \cdot (b + c) = a \cdot b + a \cdot c
    \]
  - (b) The structure \([sets, \cup, \cap, {}^c]\) has two distributive properties:
    \[
    A \cup (B \cap C) = (A \cup B) \cap (A \cup C)
    \]
    and
    \[
    A \cap (B \cup C) = (A \cap B) \cup (A \cap C)
    \]

## De Morgan's laws（德·摩根定理）

- Several of the structures we have seen have a unary operation and two binary operations.
- If the unary operation is \(*\) and the binary operations are \(\wedge\) and \(\vee\), then De Morgan's laws are
  \[
  (x \wedge y)^* = x^* \vee y^* \quad \text{and} \quad (x \vee y)^* = x^* \wedge y^*.
  \]
- Example 9
  - (a) \(\overline{A \cup B} = \overline{A} \cap \overline{B}\) and \(\overline{A \cap B} = \overline{A} \cup \overline{B}\).
  - (b) The structure [real numbers, +, *, √] does not satisfy De Morgan's laws, since \(\sqrt{x + y} \neq \sqrt{x} + \sqrt{y}\).

## Identity for an operation（单位元）

- A structure with a binary operation \(\circ\) may contain a distinguished object \(e\), with the property \(x \circ e = e \circ x = x\) for all \(x\) in the collection.
  - We call \(e\) an identity for \(\circ\).
  - In fact, an identity for an operation must be unique.

## Theorem 1

- If \(e\) is an identity for a binary operation \(\circ\), then \(e\) is unique.
- Proof
  - Assume another object \(i\) also has the identity property, so \(x \circ i = i \circ x = x\).
  - Then \(e \circ i = e\), but since \(e\) is an identity for \(\circ\), \(i \circ e = e \circ i = i\).
  - Thus, \(i = e\).
  - There is at most one object with the identity property for \(\circ\).

## Example 10

- For \([n \times n \text{ matrices}, +, *, \text{T}]\), \(\mathbf{I}_n\) is the identity for matrix multiplication and the \(n \times n\) zero matrix is the identity for matrix addition.

## Inverse（逆元）

- If a binary operation \(\circ\) has an identity \(e\), we say \(y\) is a \(\circ\)-inverse of \(x\) if \(x \circ y = y \circ x = e\).

## Theorem 2

- If \(\circ\) is an associative operation and \(x\) has a \(\circ\)-inverse \(y\), then \(y\) is unique.
- Proof
  - Assume there is another \(\circ\)-inverse for \(x\), say \(z\).
  - Then \((z \circ x) \circ y = e \circ y = y\) and \(z \circ (x \circ y) = z \circ e = z\).
  - Since \(\circ\) is associative, \((z \circ x) \circ y = z \circ (x \circ y)\) and so \(y = z\).

## Example 11

- (a) In the structure [3 × 3 matrices, +, *, ᵀ], each matrix \(\mathbf{A} = [a_{ij}]\) has a \(+\)-inverse, or additive inverse, \(-\mathbf{A} = [-a_{ij}]\).
- (b) In the structure [integers, +, *], only the integers 1 and -1 have multiplicative inverses.

## Example 12

- Let \(\oplus\), \(\nabla\), and \(*\) be defined for the set \(\{0, 1\}\) by the following tables.

| \(\oplus\) | 0 | 1 |
|---|---|---|
| 0 | 0 | 1 |
| 1 | 1 | 0 |

| \(\nabla\) | 0 | 1 |
|---|---|---|
| 0 | 0 | 0 |
| 1 | 0 | 1 |

| \(x\) | \(x^*\) |
|---|---|
| 0 | 1 |
| 1 | 0 |

Thus \(1 \oplus 0 = 1\), \(0 \nabla 1 = 0\), and \(1^* = 0\). Determine if each of the following is true for \([\{0, 1\}, \oplus, \nabla, *]\).

- (a) \(\oplus\) is commutative.
- (b) \(\nabla\) is associative.
- (c) De Morgan's laws hold.
- (d) Two distributive properties hold for the structure.

- Solution
  - (a) The statement \(x \oplus y = y \oplus x\) must be true for all choices of \(x\) and \(y\). Since both \(0 \oplus 1\) and \(1 \oplus 0\) are 1, \(\oplus\) is commutative.
  - (b) The eight possible cases to be checked are left as an exercise. \(\nabla\)
  - (c) \((0 \oplus 0)^* = 0^* = 1\) and \(0^* \nabla 0^* = 1 \nabla 1 = 1\).
    \((0 \oplus 1)^* = 1^* = 0\) and \(0^* \nabla 1^* = 1 \nabla 0 = 0\).
    \((1 \oplus 1)^* = 0^* = 1\) and \(1^* \nabla 1^* = 0 \nabla 0 = 0\).
    The last pair shows that De Morgan's laws do not hold in this structure.
