
## Strings, more formally

- Let Σ be a finite set of *symbols*, *i.e.* an *alphabet*.
- A *string* s over alphabet Σ is any sequence {s_i} of symbols, s_i ∈ Σ, normally indexed by N or N−{0}.
- If a, b, c, ... are symbols, the string s = a, b, c, ... can also be written abc... (*i.e.*, without commas).
- If s is a finite string and t is any string, then the *concatenation* of s with t, written just st,
  - is simply the string consisting of the symbols in s, in sequence, followed by the symbols in t, in sequence.

## More Common String Notations

- The length |s| of a finite string s is its number of positions (i.e., its number of index values i).
- If s is a finite string and n∈N,
  - Then sⁿ denotes the concatenation of n copies of s.
- ε or "" denotes the empty string, the string of length 0.
  - This is fairly common, but the book uses λ instead.
- If Σ is an alphabet and n∈N,
  Σⁿ := {s | s is a string over Σ of length n}, and
  Σ* := {s | s is a finite string over Σ}.

## 设计和艺术创作与数列

- 调和数列： 调和数列变化特征是：具有女性优雅、细腻、柔美之感，同时还具有一种宁静之美。
- 费波纳齐数列(FIBONACCI)： 费波纳齐为意大利数学家。在自然界中螺旋形贝壳均属费波纳齐数列现象。其特征：这是一种不疾不徐，颇为中庸的数列，增加率具有规则性的平稳，令人感到愉快的、优美的数列。它兼有等差数列与等比数列的优点。
- 等比数列：特征：等比数列在开始时虽然变化不大，但是越往后面，其变化则越加剧烈，这是一个强有力的数列，其变化基于几何数列。美感在于大小可以急剧的增加或减少，造成一种剧烈火暴的感觉。如果能够活用等差数列的特征，则能创造出富于微妙变化的设计和画面。
- 例如：慕尼黑奥林匹克运动会的商标，日本万国博览会的商标等，都是在设计中运用了等比数列的例子，并取得了很好的视觉效果。
- 贝尔数列(BELL)： 特征：它与等差数列相同，美感也在于大小可以急剧的增加或减少之中。造成一种剧烈、火爆且强劲有力的感觉。

## Summations

## Summation Notation

- Given a series {a_n}, an integer *lower bound* (or limit) *j*≥0, and an integer *upper bound* *k*≥j, then the *summation* of {a_n} from j to k is written and defined as follows:

  $$\sum_{i=j}^{k} a_i \triangleq a_j + a_{j+1} + ... + a_k$$

- Here, *i* is called the *index of summation*.

## Generalized Summations

- For an infinite series, we may write:
  $$\sum_{i=j}^{\infty} a_i := a_j + a_{j+1} + \dots$$
- To sum a function over all members of a set $X = \{x_1, x_2, \dots\}$: $\sum_{x \in X} f(x) := f(x_1) + f(x_2) + \dots$
- Or, if $X = \{x \mid P(x)\}$, we may just write:
  $$\sum_{P(x)} f(x) := f(x_1) + f(x_2) + \dots$$

## Simple Summation Example

$\sum_{i=2}^{4} i^2 + 1 = (2^2 + 1) + (3^2 + 1) + (4^2 + 1)$

$= (4 + 1) + (9 + 1) + (16 + 1)$

$= 5 + 10 + 17$

$= 32$

## More Summation Examples

- An infinite series with a finite sum:
  $$\sum_{i=0}^{\infty} 2^{-i} = 2^{0} + 2^{-1} + ... = 1 + \frac{1}{2} + \frac{1}{4} + ... = 2$$
- Using a predicate to define a set of elements to sum over:
  $$\sum_{(x \text{ is prime}) \land x<10} x^{2} = 2^{2} + 3^{2} + 5^{2} + 7^{2} = 4 + 9 + 25 + 49 = 87$$

## Summation Manipulations

- Some handy identities for summations:

∑ₓ c f(x) = c ∑ₓ f(x)      (Distributive law.)

∑ₓ f(x) + g(x) = (∑ₓ f(x)) + ∑ₓ g(x)      (An application of commutativity.)

∑ᵢ₌ⱼᵏ f(i) = ∑ᵢ₌ⱼ₊ₙᵏ⁺ⁿ f(i − n)      (Index shifting.)

## More Summation Manipulations

- Other identities that are sometimes useful:

∑_{i=j}^{k} f(i) = (∑_{i=j}^{m} f(i)) + ∑_{i=m+1}^{k} f(i)   if j ≤ m < k
(Series splitting.)

∑_{i=0}^{k} f(i) = ∑_{i=0}^{k} f(k - i)
(Order reversal.)

∑_{i=0}^{2k} f(i) = ∑_{i=0}^{k} f(2i) + f(2i + 1)
(Grouping.)

## Euler’s Trick, Illustrated

- Consider the sum:
  1+2+…+(n/2)+((n/2)+1)+…+(n-1)+n

- We have *n/2* pairs of elements, each pair summing to *n+1*, for a total of *(n/2)(n+1)*.
