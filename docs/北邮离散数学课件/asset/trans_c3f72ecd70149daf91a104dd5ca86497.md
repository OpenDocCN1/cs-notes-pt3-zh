## Propositional Logic Not Enough

如果我们有：

“所有人都将死。”
“苏格拉底是人。”

那么是否可以推出“苏格拉底将死？”

无法用命题逻辑表示。需要一种谈论对象、它们的性质和它们的关系的语言。

稍后我们将看到如何进行推理。

## Introducing Predicate Logic

- 谓词逻辑使用以下新特性：
  - 变量：x, y, z
  - 谓词：P(x), M(x)
  - 量词（将在几页幻灯片后介绍）：
- 命题函数是对命题的推广。
  - 它们包含变量和谓词，例如 P(x)
  - 变量可以用其定义域中的元素替换。

## Propositional Functions

当命题函数的变量各自被定义域中的一个值替换（或如我们稍后将看到的那样被量词绑定）时，命题函数就成为命题（并具有真值）。

语句 $P(x)$ 被称为命题函数 $P$ 在 $x$ 处的值。

例如，设 $P(x)$ 表示“$x > 0$”，定义域为整数。则：
P(-3) 为假。
P(0) 为假。
P(3) 为真。

通常定义域用 $U$ 表示。所以在这个例子中 $U$ 是整数。

## Examples of Propositional Functions

设“x + y = z”用 R(x, y, z) 表示，且 U（对三个变量）为整数。求这些真值：
R(2,-1,5)
解：F
R(3,4,7)
解：T
R(x, 3, z)
解：不是命题

现在设“x - y = z”用 Q(x, y, z) 表示，U 为整数。求这些真值：
Q(2,-1,3)
解：T
Q(3,4,7)
解：F
Q(x, 3, z)
解：不是命题

## Compound Expressions

- 命题逻辑中的联结词被继承到谓词逻辑中。
- 若 $P(x)$ 表示“$x > 0$”，求这些真值：

| Expression | Solution |
|---|---|
| $P(3) \lor P(-1)$ | T |
| $P(3) \land P(-1)$ | F |
| $P(3) \to P(-1)$ | F |
| $P(3) \to P(-1)$ | T |

- 包含变量的表达式不是命题，因此没有真值。例如，

  $P(3) \land P(y)$

  $P(x) \to P(y)$

- 当与量词一起使用（将在下一节介绍）时，这些表达式（命题函数）就成为命题。

## Quantifiers

![](img/c25dfd82fc242c2db53bc942dcad6885_303_0.png)

Charles Peirce (1839-1914)

- 我们需要*量词*来表达英语中包括*所有*和*一些*的含义：
  - “所有人都将死。”
  - “有些猫没有毛。”
- 两个最重要的量词是：
  - *全称量词*，“对于所有”，符号：∀
  - *存在量词*，“存在”，符号：∃
- 我们写成 ∀x P(x) 和 ∃x P(x)。
- ∀x P(x) 断言 P(x) 对定义域中的*每一个* x 都为真。
- ∃x P(x) 断言 P(x) 对定义域中的*某个* x 为真。
- 量词据说在这些表达式中绑定变量 x。
