# DNS资源记录（RR）（1）

资源记录保存在DNS服务器中

```
RR 格式: (name, TTL, class, type, value)
```

Time-to-live, 有效期

+   - Type=A——地址资源记录
+     - Name= 主机的域名, Value= IP地址
+     - ns.buptnet.edu.cn 86400 IN A 202.112.10.37

IN, 因特网

+   - Type=NS——权威DNS服务器资源记录
+     - Name= 域(如 bupt.edu.cn)
+     - value= 此域的权威DNS 服务器的域名
+     - bupt.edu.cn 86400 IN NS ns.buptnet.edu.cn
