# RIP路由通告消息

发送给邻居节点

| 位 | 0 | 8 | 16 | 31 |
|---|---|---|---|---|
| 消息头 | 命令 | 版本号 | 全0 |
|  | 网络1的地址族标识 | 全0 |
| RIP表项1 | 网络1的IP地址 |
|  | 网络1的子网掩码 |
|  | 下一跳路由器地址 |
|  | 到网络1的距离 |
|  | 网络2的地址族标识 | 全0 |
| RIP表项2 | 网络2的子网掩码 |
|  | 下一跳路由器地址 |
|  | 到网络2的距离 |
|  | ...... |

+   命令（1-5）：1——请求，2——应答，3-4废弃，5——保留

+   版本号：1或2

+   地址族标识：标识网络层的地址类型，因特网为2

+   采用UDP传输，端口号520
