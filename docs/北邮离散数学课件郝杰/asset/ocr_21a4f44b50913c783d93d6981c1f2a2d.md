# 第二章总结

重点：掌握DNS、WWW、Email的应用层协议的要点和原理、FTP和Telnet的功能及主要概念

+   - 客户和服务器使用请求/应答消息进行交互
+     - 客户发送请求
+     - 服务器返回响应
+   - 消息格式
+     - 消息头：协议要处理的信息
+     - 数据：交付给用户的信息

# 重要概念:

+   - 集中式/分布式
+     - C/S vs P2P
+   - 传输要求：可靠/不可靠
+     - 选择TCP或UDP
+   - 控制信息vs. 数据信息
+     - 是否在同一条连接上传输
+   - 有状态/无状态
