# 主要的邮件头

| 邮件头字段分类 | 字段 | 含义描述 |
|---|---|---|
| 发信人相关字段 | From: | 建立邮件的用户Email地址 |
|  | Sender: | 发送邮件的用户Email地址 |
|  | Reply-to: | 回邮地址 |
| 收信地址相关字段 | To: | 一个或多个收信人地址 |
|  | Cc: | 抄送地址 |
|  | Bcc: | 暗送地址 |
| 发信时间 | Date: | 邮件发送的日期和时间 |
| 标识字段 | Message-Id: | 邮件的唯一标识 |
|  | References: | 其他相关标识 |
| 信息字段 | Subject: | 邮件摘要 |
|  | Keywords: | 发信人设置的关键字 |
| 跟踪字段 | Received: | 邮件所经过的邮件服务器列表 |
|  | Return-Path: | 回邮路径 |
