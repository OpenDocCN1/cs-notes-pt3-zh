# 缓存的更新：条件GET

+   问题：如果cache中的对象过期了（不是最新版本）怎么办？

+   Cache在HTTP请求中包含对象的最后更新时间：
+   If-modified-since:
+   <date>
+   该时间包含在上次访问时Server的HTTP响应中
+   Last-Modified: <date>

+   Server如果没有更新对象，则返回
+   HTTP/1.0 304 Not Modified
