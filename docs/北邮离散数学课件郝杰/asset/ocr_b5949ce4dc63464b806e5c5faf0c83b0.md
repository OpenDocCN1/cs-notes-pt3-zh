# ICMP的主要消息（RFC792）

+   - 差错报告消息
+     - 目的地不可达消息：到目的主机无连接、IP包超长且不能分段
+     - 超时消息：IP包TTL=0
+     - 参数错误：IP包头参数有问题
+   - 控制消息
+     - 源抑制消息：路由器或者目的主机的缓存不足，请求源主机降低发送速率，用于拥塞控制
+     - 重定向消息：要求源主机更换默认路由器，用于路由控制
+   - 查询消息：源主机请求、路由器和目的主机应答
+     - 回声请求/应答：测试路由器或目的主机是否可达
+     - 时间戳请求/应答：用于互联网上各个机器进行时钟同步的
