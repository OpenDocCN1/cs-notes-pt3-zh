# 控制字段

![](bbox=[0.18, 0.26, 0.95, 0.36])

置为1有效

紧急数据：要求接收端尽快处理，而不必在接收缓存中排队

Push：要求接收端立刻将现有缓存数据交付应用层，而不必等待后续数据

| 控制位 | 功能 |
| --- | --- |
| URG | 表示报文中携带了紧急数据，“紧急数据指针”包含紧急数据最后一字节的序号 |
| ACK | 表示“接收序号”有效 |
| PSH | 表示报文段中的数据应快速提交给应用层 |
| RST | 表示复位TCP连接 |
| SYN | 表示连接建立的请求或响应 |
| FIN | 表示连接释放的请求或响应 |
