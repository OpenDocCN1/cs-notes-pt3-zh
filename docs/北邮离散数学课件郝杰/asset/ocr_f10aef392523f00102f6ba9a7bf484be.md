# HDLC帧中的控制字段：监督帧

| bit | 1 | 1 | 2 | 1 | 3 |
|---|---|---|---|---|---|
|  | 1 | 0 | S | P/F | N(R) |

| S | 帧名 | 功能 |
| 00 | RR（接收准备就绪） | 准备接收下一帧
确认序号为N(R)-1及其以前的各帧 |
| 10 | RNR（接收未就绪） | 暂停接收下一帧
确认序号为N(R)-1及其以前的各帧 |
| 01 | REJ（拒绝） | 否认从N(R)起以后的所有帧 |
| 11 | SREJ（选择拒绝） | 只否认N(R)帧 |

RR和RNR具有流量控制作用。

REJ用于回退N帧ARQ协议；SREJ用于选择重发协议。
