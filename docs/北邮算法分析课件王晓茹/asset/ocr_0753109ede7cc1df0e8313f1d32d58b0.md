# # 0-1背包问题

设所给0-1背包问题的子问题

\(\max \sum_{k=i}^n v_k x_k\)

\(\left\{\begin{array}{l} \sum_{k=i}^n w_k x_k \leq j \end{array}\right.\)

算法复杂度分析：
从m(i, j)的递归式容易看出，算法需要O(nc)计算时间。当背包容量c很大时，算法需要的计算时间较多。例如，当c>2^n时，算法需要Ω(n2^n)计算时间。

\(m(i, j)=\left\{\begin{array}{ll} \max \{m(i+1, j), m(i+1, j-w_i)+v_i\} & j \geq w_i \\ m(i+1, j) & 0 \leq j < w_i \end{array}\right.\)

\(m(n, j)=\left\{\begin{array}{ll} v_n & j \geq w_n \\ 0 & 0 \leq j < w_n \end{array}\right.\)
