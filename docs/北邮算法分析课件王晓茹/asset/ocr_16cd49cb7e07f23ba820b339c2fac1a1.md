# # 算法复杂度分析

上述算法的主要计算量在于计算跳跃点集  
p[i] (1≤i≤n)。由于q[i+1]=p[i+1]⊕(w<sub>i</sub>, v<sub>i</sub>)，  
故计算q[i+1]需要0(|p[i+1]|)计算时间。合并  
p[i+1]和q[i+1]并清除受控跳跃点也需要  
0(|p[i+1]|)计算时间。从跳跃点集p[i]的定义  
可以看出，p[i]中的跳跃点相对于x<sub>i</sub>, ⋯, x<sub>n</sub>的0/1  
赋值。因此，p[i]中跳跃点个数不超过2<sup>n-i+1</sup>。由  
此可见，算法计算跳跃点集所花费的计算时  
间为  
[\sum_{i=2}^{n} |p[i]| \in O(2^n)]  
从而，改进后算法的计算时间复杂性为0(2<sup>n</sup>)。当  
所给物品的重量w<sub>i</sub> (1≤i≤n)是整数时，  
|p[i]| ≤ c+1, (1≤i≤n)。在这种情况下，改进  
后算法的计算时间复杂性为0(min{nc, 2<sup>n</sup>})。
