# 图的m着色问题

+   - 解向量：(x₁, x₂, …, xₙ)表示顶点i所着颜色x[i]
+   - 可行性约束函数：顶点i与已着色的相邻顶点颜色不重复。

```
void Color::Backtrack(int t)
{
    if (t>n) {
        sum++;
        for (int i=1; i<=n; i++)
            cout << x[i] << ' ';
        cout << endl;
    }
    else
        for (int i=1;i<=m;i++) {
            x[t]=i;
            if (Ok(t)) Backtrack(t+1);
        }
}
bool Color::Ok(int k)
{// 检查颜色可用性
    for (int j=1;j<=n;j++)
        if ((a[k][j]==1)&&(x[j]==x[k])) return false;
    return true;
}
```
