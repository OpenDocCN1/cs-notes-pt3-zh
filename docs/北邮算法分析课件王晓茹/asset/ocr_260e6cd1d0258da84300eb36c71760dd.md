# 例1 考虑线性变系数二阶齐次递推方程

(n-1) T(n) = (n-2) T(n-1) + 2 T(n-2) ， n ≥ 2

和初始条件 T(0)=0， T(1)=1。根据初始条件，可计算 T(2)=0， T(3)=T(1)=1。

设 {T(n)} 的母函数为：

A(x) = Σ_{n=0}^{∞} T(n) x^n

由于 T(0)=T(2)=0， T(1)=1，有：

A(x) = x + T(3) x^3 + T(4) x^4 + … + T(n) x^n + …

= x(1 + T(3) x^2 + T(4) x^3 + … + T(n) x^{n-1} + …)

令 B(x) = A(x)/x，即：

B(x) = 1 + T(3) x^2 + T(4) x^3 + … + T(n) x^{n-1} + …
