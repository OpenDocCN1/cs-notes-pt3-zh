# 选择下一个作业的量度标准

例 n=4, (p1, p2, p3, p4)=(100, 10, 15, 20)和  
(d1, d2, d3, d4)= (2, 1, 2, 1)

把目标函数 \(\sum p_i\) 作为量度。使用  
这一量度，下一个要计入的作业将是使得  
在满足所产生的J是一个可行解的限制条  
件下让 \(\sum p_i\) 得到最大增加的作业。

这就要求按p的非增次序来考虑这些作业。

则：  
开始时 \( J = \Phi \)， \(\sum_{i \in J} p_i = 0\)

\( J = \{1\}, \quad p_1 = 100 \)  
作业1有最大效益  

\( J = \{1, 4\} \quad p_1 + p_4 = 120 \)  
作业4有第二大效益  
作业3，2都被舍弃
