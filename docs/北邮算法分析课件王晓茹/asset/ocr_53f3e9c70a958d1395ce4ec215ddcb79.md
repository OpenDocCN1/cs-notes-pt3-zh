# 迭代法

方法的思想是迭代地展开递归方程的右端，使之成为一个非递归的和式，然后通过对和式的估计来达到对方程左端即方程的解的估计。

T(n) = 3T(⌈n/4⌉) + n

T(n) ≤ n + 3(n/4 + 3(n/4² + 3(n/4³ + ⋯ + 3(n/4ⁱ + 3T(0))⋯)))

= n + 3/4 n + 3²/4² n + 3³/4³ n + ⋯ + 3ⁱ/4ⁱ n + 3ⁱ⁺¹·T(0)

< 4n + 3ⁱ⁺¹·T(0)

知 i ≤ log₄ n ，从而

3ⁱ⁺¹ ≤ 3^{log₄ n +1} = 3^{log₃ 3 n log₄ 3 +1} = 3n^{log₄ 3}

代入

T(n) < 4n + 3^{log₄ 3}·T(0)

+   - 即，T(n)=O(n)
