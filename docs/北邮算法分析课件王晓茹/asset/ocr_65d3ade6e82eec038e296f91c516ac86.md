# 构造最优解

在类Loading中增加两个私有数据成员x和bestx。

+   » X记录从根至当前结点的路径,x[i]=0/1;[1 0 1 1 0]
+   » Bestx记录当前最优解，算法搜索到达一个叶子结点处，就修正besx的值。

```
class loading
{
    friend Type MaxLoading(Type [], Type int);
    //初始化操作
    private:
        void Backtrack( int i);//对解空间搜索
        int n; //集装箱数
        *x,//当前解,数组
        *bestx//当前最优解,数组
        Type *w, //集装箱重量数组
        c, //第一艘轮船的载重量
        cw,//当前载重量
        bestw;//当前最优载重量
        r;   //剩余集装箱的重量
};
```
