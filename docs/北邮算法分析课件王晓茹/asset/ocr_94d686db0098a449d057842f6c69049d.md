# § 4 Logarithms in the Running Time

# 【Example】 Exponentiation: computing X^N.

```
long int Pow( long int X, unsigned int N )
{
    long int P = 1;
    while ( N-- ) P *= X;
    return P;
}
T(N) = O(N)
```

X^N = { (X^2)^(N/2) if N is even or (X^2)^((N-1)/2) × X if N is odd }

```
long int Pow( long int X, unsigned int N )
{
    /* 1*/ if ( N == 0 )
    /* 2*/     return 1;
    /* 5*/ if ( IsEven( N ) )
    /* 6*/     return Pow( X * X, N / 2 );
    else
    /* 7*/     return Pow( X * X, N / 2 ) * X;
}
T(N) = O( log N )
```
