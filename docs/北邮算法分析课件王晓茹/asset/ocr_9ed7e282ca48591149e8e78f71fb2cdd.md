# # 问题描述：最大子段和求解

给定由n个整数(可能为负整数)组成的序列  
a₁,a₂,...,aₙ,求该序列形如 \(\sum_{k=i}^{j} a_k\) 的子段和的最  
大值。当所有整数均为负整数时定义其最大子  
段和为 0。依此定义，所求的最优值为：

\(max \left\{ 0, max_{1 \leq i \leq j \leq n} \sum_{k=i}^{j} a_k \right\}\)

例如当(a₁, a₂, a₃, a₄, a₅, a₆)=(-2, 11, -4, 13, -5, -2)时，  
最大子段和为 \(\sum_{k=2}^{4} a_k = 20\) 。
