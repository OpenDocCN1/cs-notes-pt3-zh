# # 算法描述和分析

```
int maxSum(int n, int * a)
{
    int sum=0, b=0;
    for (int i=1;i<=n;i++) {
    if (b>0) b+=a[i];
    else b=a[i];
    if (b>sum) sum=b;
    }
    return sum;
}
```


算法显然需要O(n)计算时间
