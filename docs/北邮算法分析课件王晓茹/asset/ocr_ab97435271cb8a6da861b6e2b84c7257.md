# # 1.最长公共子序列的结构

设序列X={x<sub>1</sub>,x<sub>2</sub>,...,x<sub>m</sub>}和Y={y<sub>1</sub>,y<sub>2</sub>,...,y<sub>n</sub>}的最长公共子序列为  
Z={z<sub>1</sub>,z<sub>2</sub>,...,z<sub>k</sub>} ，则

(1)若x<sub>m</sub>=y<sub>n</sub>，则z<sub>k</sub>=x<sub>m</sub>=y<sub>n</sub>，且Z<sub>k-1</sub>是x<sub>m-1</sub>和y<sub>n-1</sub>的最长公共子序列。

(2)若x<sub>m</sub>≠y<sub>n</sub>且z<sub>k</sub>≠x<sub>m</sub>，则Z是x<sub>m-1</sub>和Y的最长公共子序列。

(3)若x<sub>m</sub>≠y<sub>n</sub>且z<sub>k</sub>≠y<sub>n</sub>，则Z是X和y<sub>n-1</sub>的最长公共子序列。

由此可见，2个序列的最长公共子序列包含了这2个序列的前缀的最长公共子序列。因此，最长公共子序列问题具有最优子结构性质。
