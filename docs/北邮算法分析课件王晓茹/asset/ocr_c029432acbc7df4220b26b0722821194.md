```
void Knapsack(int n,float M,float v[],float w[],float x[])
{
    Sort(n,v,w);
    int i;
    for (i=1;i<n;i++) x[i]=0;
    float c=M;
    for (i=1;i<n;i++)
    {
        if (w[i]>c) break;
        x[i]=1;
        c-=w[i];
    }
    if (i<=n) x[i]=c/w[i];
}
```

算法
knapsack的主要
计算时间在于将
各种物品依其单
位重量的价值从
大到小排序。因
此，算法的计算
时间上界为
0（nlogn）。
