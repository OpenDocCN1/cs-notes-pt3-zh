# 代入法

猜测技术:对递推关系式估计一个上限，然后（用数学归纳法）证明它正确。

T(n) = 2T(n/2) + n  证明 T(n) = O(n log n)

+   - 推测 T(n) = O(n log n)，即推测存在正的常数 C 和自然数 n₀，使得当 n ≥ n₀ 时有
+     T(n) ≤ C n log n  (1-1)

+   - 假设假设当 2^{k-1} n₀ ≤ n ≤ 2^{k} n₀，k ≥ 1 时，(1-1) 成立。

+   - 那么，当 2^{k} n₀ ≤ n ≤ 2^{k+1} n₀ 时，有：
+     T(n) = 2T([n/2]) + n
+     ≤ 2C [n/2]·log([n/2]) + n
+     < 2C·n/2·log n/2 + n
+     = C n log n - C n + n
+     = C n log n - (C - 1)n
+     ≤ C n log n
