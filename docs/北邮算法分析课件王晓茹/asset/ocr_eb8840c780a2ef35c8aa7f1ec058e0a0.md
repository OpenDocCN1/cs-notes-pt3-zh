# 【Example】 Euclid's Algorithm: computing the greatest common divisor (Gcd).

```
unsigned int Gcd ( unsigned int M, unsigned int N )
{
    unsigned int Rem;
    /* 1*/ while ( N > 0 ) {
    /* 2*/     Rem = M % N;
    /* 3*/     M = N;
    /* 4*/     N = Rem;
    } /* end while */
    /* 5*/ return M;
}
```
