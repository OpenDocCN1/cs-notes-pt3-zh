```
void getMax(int a[],int n)
{
    int dp,tmp;
    dp=Max=a[n-1];
    tmp=n-1;
    B=n-1;
    E=n-1;
    for(int i=n-2;i>=0;i--)
    {
        if(dp>0)
        dp=dp+a[i];
        else
        {
        dp=a[i];
        tmp=i;
        }
        if(Max<=dp)
        {
        B=i;
        E=tmp;
        Max=dp; } } }

```

int B,E,Max;//B为子数组的起始点下标,E为子数组的结束点下标
//Max为最大子数组的和。
//getMax求数组a(元素个数为n,以下标0作为起始点)的最大子数组，外加起点下标与//结束点下标。

由于dp[i]只与dp[i+1]有关系，tmp[i]只与tmp[i+1]有关系，所以我们可以省略数组，改为变量dp,tmp。
