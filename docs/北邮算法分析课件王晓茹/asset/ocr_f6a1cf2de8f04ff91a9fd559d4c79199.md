```
template<class type>
void perm(type list[], int k, int m)
{ if (k==m)
    //输出一个排列
else
    for (int i=k ; i<=m; i++)
    { swap(list[k], list[i]);
      perm(list, k+1, m);
      swap(list[k], list[i]);
    }
}
```

eg: list[]={1, 2, 3, 4}
↑
k
输出结果：
1 2 3 4
1 2 4 3
1 3 2 4
1 3 4 2
......

函数调用： perm(list, 0, n-1)。求n个元素的排列，应有n!种，输出n!种排列时间性能n n!
