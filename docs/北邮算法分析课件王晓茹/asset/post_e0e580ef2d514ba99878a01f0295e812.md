## §2 Asymptotic Notation ( O, Ω, Θ, o ) 渐进性原理及表示符号

The point of counting the steps is to predict the growth in run time as the N change, and thereby compare the time complexities of two programs. So what we really want to know is the asymptotic behavior of T_p.

Suppose T_p1(N) = c1 N² + c2 N and T_p2(N) = c3 N. Which one is faster?

No matter what c1, c2, and c3 are, there will be an n0 such that T_p1(N) > T_p2(N) for all N > n0.

## 算法渐近复杂性

- - 衡量算法复杂性的档次/规模——阶， Rate/Order of growth
- - 对时间复杂度函数T(n)，有可能， T(n)→∞， as n→∞；
- - 例如，
- T(n) = 2n² + 4n + 1，  t(n)= 2n²
- - (T(n) - t(n)) / T(n) →0， as n→∞；
- , t(n)是T(n)的渐近性态，为算法的渐近复杂性。
- - 在数学上， t(n)是T(n)的渐近表达式，是T(n)略去低阶项留下主项。它比T(n)简单。

## § 2 Asymptotic Notation

【Definition】 T(N) = O(f(N)) if there are positive constants c and n0 such that T(N) ≤ c f(N) for all N ≥ n0.

【Definition】 T(N) = Ω(g(N)) if there are positive constants c and n0 such that T(N) ≥ c g(N) for all N ≥ n0.

【Definition】 T(N) = Θ(h(N)) if and only if T(N) = O(h(N)) and T(N) = Ω(h(N)).

【Definition】 T(N) = o(p(N)) if T(N) = O(p(N)) and T(N) ≠ Θ(p(N)).
