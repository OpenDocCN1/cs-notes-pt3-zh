# # 采用先行进位

# ## 每一位的进位公式：

C<sub>n+1</sub>=Y<sub>0</sub>+X<sub>0</sub>C<sub>n</sub>
C<sub>n+2</sub>=Y<sub>1</sub>+X<sub>1</sub>C<sub>n+1</sub>=Y<sub>1</sub>+Y<sub>0</sub>X<sub>1</sub>+X<sub>0</sub>X<sub>1</sub>C<sub>n</sub>
C<sub>n+3</sub>=Y<sub>2</sub>+X<sub>2</sub>C<sub>n+2</sub>=Y<sub>2</sub>+Y<sub>1</sub>X<sub>2</sub>+Y<sub>0</sub>X<sub>1</sub>X<sub>2</sub>+X<sub>0</sub>X<sub>1</sub>X<sub>2</sub>C<sub>n</sub>
C<sub>n+4</sub>=Y<sub>3</sub>+X<sub>3</sub>C<sub>n+3</sub>=Y<sub>3</sub>+Y<sub>2</sub>X<sub>3</sub>+Y<sub>1</sub>X<sub>2</sub>X<sub>3</sub>+Y<sub>0</sub>X<sub>1</sub>X<sub>2</sub>X<sub>3</sub>+X<sub>0</sub>X<sub>1</sub>X<sub>2</sub>X<sub>3</sub>C<sub>n</sub>
=G+PC<sub>n</sub>
其中，G=Y<sub>3</sub>+Y<sub>2</sub>X<sub>3</sub>+Y<sub>1</sub>X<sub>2</sub>X<sub>3</sub>+Y<sub>0</sub>X<sub>1</sub>X<sub>2</sub>X<sub>3</sub>，P=X<sub>0</sub>X<sub>1</sub>X<sub>2</sub>X<sub>3</sub>

+   - G为进位发生输出 P为进位传送输出

+   - P、G是为了实现多片ALU之间先行进位而设置的

从上式可以看出：第0位的进位输入C<sub>n</sub>可以直接传送到最高进位位上去，从而实现高速运算
