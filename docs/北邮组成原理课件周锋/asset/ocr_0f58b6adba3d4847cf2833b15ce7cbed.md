# # IEEE754的舍入处理

四种舍入（Rounding）方式：
■就近舍入（向偶数舍入）：若尾数超出规定的23位的多余位数共3位（形如1.xxyabc），若abc取值为001、010、011，则舍去；若取值为101、110、111，则向最低有效位进位；若取值为中间值100,则进一步判断最低有效位y，若为0，则舍去；否则，向最低有效位进位，最终结果为偶数。
■朝0舍入：即朝数轴原点方向舍入，就是把多余的位数简单的截去。截尾使取值的绝对值比原值的绝对值小。
■朝+∞舍入：对于正数，当多余位不全为0则向最低有效位进1；而对负数则是简单的截尾。
■朝-∞舍入：处理方法正好与朝+∞舍入情况相反。对于正数，当多余位不全为0则简单截尾；而对负数，则向最低有效位进1。
