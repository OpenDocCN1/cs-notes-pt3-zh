# # IEEE 754 32位浮点数 小结

# ## 对32位浮点数N：

+   - 若0 < E < 255，则  
+     N = (-1)ˢ × 1.M × 2ᴱ⁻¹²⁷，规格化数表示

+   - 若E = 0且M = 0，则  
+     N = (-1)ˢ 0，机器+0、-0表示

+   - 若E = 0且M ≠ 0，则  
+     N = (-1)ˢ × 0.M × 2¹⁻¹²⁷，非规格化数表示

+   - 若E = 255且M = 0，则  
+     N = (-1)ˢ∞（正无穷大，负无穷大）

+   - 若E = 255且M ≠ 0，则  
+     N = NaN，非数NaN（Not a Number）
