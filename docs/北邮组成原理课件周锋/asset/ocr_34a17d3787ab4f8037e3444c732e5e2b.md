# # 浮点数乘、除法

# ## 设有两个浮点数x = 2E<sub>x</sub>×M<sub>x</sub>

# y = 2E<sub>y</sub>×M<sub>y</sub>

+   - x × y = 2 (E<sub>x</sub> + E<sub>y</sub>) × (M<sub>x</sub> × M<sub>y</sub>)

+   - x ÷ y = 2 (E<sub>x</sub>-E<sub>y</sub>) × (M<sub>x</sub> ÷ M<sub>y</sub>)

# ## 算法

+   - 检查操作数是否为0

+   - 阶码加、减：乘：E<sub>X</sub>+E<sub>Y</sub>， 除： E<sub>X</sub>- E<sub>Y</sub>

+   - 对尾数进行乘、除法，求得结果

+   - 规格化、舍入处理（可能再次规格化）

+   - 进行溢出检查（阶码）
