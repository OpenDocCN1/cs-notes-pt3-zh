# # 定点数的表示方法

# ## 纯小数

| X₀ | X₁ | X₂ | ... | Xₙ₋₁ | Xₙ |
|---|---|---|---|---|---|

+   - X₀表示数的符号，数值0和1分别表示正号和负号，其余为代表数的量值
+   - 小数点位于X₀和X₁之间。
+   - 表示范围为0≤∣x∣≤1-2⁻ⁿ

# ## 纯整数

| X₀ | X₁ | X₂ | ... | Xₙ₋₁ | Xₙ |
|---|---|---|---|---|---|

+   - X₀表示数的符号，数值0和1分别表示正号和负号，其余为代表数的量值
+   - 小数点位于最低位Xₙ的右边
+   - 表示范围为0≤∣x∣≤2ⁿ-1
