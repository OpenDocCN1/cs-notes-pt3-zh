中ALU为16位的加法器(高电平工作)，

触发器组成，Q端输出，其读、写控制功
能见下表。

| 读控制 |  |  |  | 写控制 |  |  |  |

| R | RA0 | RA1 | 选择 | W | WA0 | WA1 | 选择 |
| 1 | 0 | 0 | R0 | 1 | 0 | 0 | R0 |
| 1 | 0 | 1 | R1 | 1 | 0 | 1 | R1 |
| 1 | 1 | 0 | R2 | 1 | 1 | 0 | R2 |
| 1 | 1 | 1 | R3 | 1 | 1 | 1 | R3 |
| 0 | * | * | 不读出 | 0 | * | * | 不写入 |
