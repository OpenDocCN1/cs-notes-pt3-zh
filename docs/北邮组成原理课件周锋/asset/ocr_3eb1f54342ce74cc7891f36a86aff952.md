# 2、流水技术原理

+   - 在流水线中必须是连续的任务
+     - 只有不断的提供任务才能充分发挥流水线的效率
+   - 把一个任务分解为几个有联系的子任务
+     - 每个子任务由一个专门的功能部件实现
+   - 同步或短板效应
+     - 每个功能部件之后都要有一个缓冲寄存器，或称为锁存器
+   - 各段的时间应该尽量相等
+     - 否则将会引起“堵塞”和“断流”的现象
+   - 需要有装入时间和排空时间
+     - 只有当流水线完全充满时，才能充分发挥效率
