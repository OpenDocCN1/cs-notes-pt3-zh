# 冯诺依曼体系结构-普林斯顿结构

对于图所示的单总线的CPU结构，写出执行以下带有间接访存寻址方式的指令的执行过程。

+   (1) ADD R1, (mem)
+   (2) STORE (mem), R1

答：(1) PC→MAR, 读
PC+1→PC
DBUS→MDR
MDR→IR
IR (地址段)→MAR, 读
DBUS→MDR
MDR→MAR, 读
DBUS→MDR
MDR→Y
R1+Y→Z
Z→R1

答：(2) PC→MAR, 读
PC+1→PC
DBUS→MDR
MDR→IR
IR (地址段)→MAR, 读
DBUS→MDR
MDR→MAR
R1→MDR, 写
