# # 证明 \([x]_\text{补} + [y]_\text{补} = [x+y]_\text{补}\) （2）

(3) \(r<0, y>0\)，则 \(r+y>0\) 或 \(r+y<0\)

这种情况和第2种情况一样，把 \(r\) 和 \(y\) 的位置对调即得证。

(4) \(r<0\)，\(y<0\)，则 \(r+y<0\)

相加两数都是负数，则其和也一定是负数。

\(\therefore [x]_\text{补} = 2 + x\), \([y]_\text{补} = 2 + y\)

\(\therefore [x]_\text{补} + [y]_\text{补} = 2 + x + 2 + y = \text{2} + (2 + x + y)\)

上式右边分为 “2” 和 \((2 + x + y)\) 两部分。既然 \((x + y)\) 是负数，而其绝对值又小于 1，那么 \((2 + x + y)\) 就一定是小于 2 而大于 1 的数，进位 “2” 必丢失。又因 \((x + y)<0\)，所以 \([x]_\text{补} + [y]_\text{补} = 2 + (x + y) = [x+y]_\text{补}\)
