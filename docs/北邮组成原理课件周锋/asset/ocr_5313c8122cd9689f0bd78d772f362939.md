# # TEC-8 控制操作模式

+   - 控制信号切换器实现控制信号的切换。转换开关拨到朝上位置时，TEC-8使用硬连线控制器产生的控制信号；拨到中间位置TEC-8各部件独立，控制信号通过开关来控制；拨到朝下位置时，TEC-8使用微程序控制器产生的控制信号。

+   - SWC、SWB、SWA确定的TEC-8的操作模式如图：

| 操作模式 | 实验功能 |
|----------|----------|
| 000 | 启动程序运行 |
| 001 | 写存储器 |
| 010 | 读存储器 |
| 011 | 读寄存器 |
| 100 | 写寄存器 |
| 101 | 运算器组成实验 |
| 110 | 双端口存储器实验 |
| 111 | 数据通路实验 |
