+   - **RD (I)** — 指令读命令
+   - **RD (D)** — 数存读命令
+   - **WE (D)** — 数存写命令

+   - **LDAR**—打入数存地址寄存器
+   - **LDDR**—打入数据缓冲寄存器
+   - **PC+1**—程序计数器加1
+   - **LDR2**—打入R1寄存器
