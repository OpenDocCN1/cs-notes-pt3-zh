# 存储器芯片性能改进

提高DRAM芯片访问速度的几种技术：

+   - 允许重复存取行缓冲区而无需增加另外的行存取时间
+     - 突发模式（Burst Mode）
+     - 快速页模式（Fast Page Mode）
+     - 扩展数据输出（EDO mode）
+     - 增强性EDRAM（Enhanced DRAM）
+   - 简化DRAM与CPU之间的接口
+     - 增加时钟信号来降低与控制器同步的开销
+     - SDRAM（同步DRAM）
+   - 在时钟的上升沿和下降沿都传输数据
+     - 双倍速率DDR（Double Data Rate）
+     - DDR2、DDR3、DDR4
