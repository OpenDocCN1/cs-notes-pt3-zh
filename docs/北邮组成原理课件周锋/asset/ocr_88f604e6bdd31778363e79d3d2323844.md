+   ◆ a' = 0.0...1₂ * 2¹⁻¹²⁷  
+     = 2⁻²³ * 2⁻¹²⁶  
+     = 2⁻¹⁴⁹

+   - 最大的正数： M=0.11...1₂

+   ◆ b'= 0.11...1₂ * 2 ¹⁻¹²⁷ = 0.11...1₂ * 2 ⁻¹²⁶  
+     = (1 - 2⁻²³) * 2⁻¹²⁶
