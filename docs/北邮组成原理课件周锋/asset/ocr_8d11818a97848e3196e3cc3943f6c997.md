# TEC-8 模型计算机的中断处理过程

除指令EI、DI外，每条指令执行过程的最后一条微指令都包含判断位P4，用于判断有无中断发生，根据中断信号INT是否为1决定微程序序分支。如果信号INT为1，则转微地址11H，进入中断处理；如果信号INT为0，则转微地址01H，继续取下一条指令然后执行。

```
if MF'event and MF = '1' then
EN_INT <= INTEN or (EN_INT and (not INTDI));
end if;
    INT <= EN_INT and PULSE;
end process;
```
