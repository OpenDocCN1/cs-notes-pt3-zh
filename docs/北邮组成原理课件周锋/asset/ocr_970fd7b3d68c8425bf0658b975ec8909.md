对文件进行操作之前，必须先打开该文件；使用完毕后应立即关闭，以免数据丢失。

C语言规定了标准输入输出函数，用fopen()函数打开一个文件，用fclose()函数关闭一个文件。

# 一、文件的打开——fopen()函数

+   1. 用法： FILE *fopen( const char * filename, const char * mode);

+   2. 功能：打开以filename所指向的字符串为文件名的文件，使之与一个流关联。返回一个指向FILE类型结构变量的指针（后称文件指针）。若打开失败，返回一个空指针NULL。

+   3. 函数原型：stdio.h。

+   4. FILE * fPtr;
+   fPtr = fopen ("clients.dat","wb"); //文件和程序在同一目录
+   fPtr = fopen ("C:\\temp\\clients.dat","wb");
+   //文件绝对路径。注意：路径中必须是"\\"而不是"\"
