# 5.2.1 指令周期的基本概念

+   ○ 指令周期：指取指令、分析指令到执行完该指令所需的全部时间。
+     ◆ 各种指令的指令周期相同吗？为什么？
+   ○ 机器周期/CPU周期/总线周期
+     ◆ 一般把一次存储器或IO访问的时间称为机器周期/总线周期
+     ◆ 主存的工作周期(存取周期)为基础来规定CPU周期，比如，可以用CPU读取一个指令字的最短时间来规定CPU周期
+     ◆ 通常把一条指令周期划分为若干个机器周期，每个机器周期完成一个基本操作
+     ◆ 不同的指令，可能包含不同数目的机器周期
+   ○ 时钟周期
+     ◆ 一个机器周期中，包含若干个时钟周期（节拍脉冲或T脉冲）
