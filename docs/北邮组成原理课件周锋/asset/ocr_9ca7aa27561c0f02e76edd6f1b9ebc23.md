# 6.5 典型总线-PCI

+   PCI总线采用的是隐含仲裁的方式，一次仲裁可以在上一次使用的同时进行，使得总线的仲裁不必占用总线的周期。

+   PCI V1.0定义了32位数据总线宽度，可扩展到64位，支持33MHz的时钟频率，最大传输速率可达到133MB / S。

+   PCI V2.2标准扩展到64位，允许PCI总线以66MHz的速度运行，能提供528MB / S的带宽。

+   PCI得到广泛应用的原因是因为支持PnP（Plug and Play，即插即用）。PnP能够在加电时，BIOS（Basic Input Output System，基本输入输出系统）自动检测机器配置，识别并自动配置各个外围设备，分配中断请求号、存储器的缓冲区等，从而避免了IRQ（中断请求）、DMA和I/O通道之间的冲突。
