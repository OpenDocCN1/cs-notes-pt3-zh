# # 补码表示法（2）

# ## 定点整数

| X₀ | X₁ | X₂ | ... | Xₙ₋₁ | Xₙ |
|---|---|---|---|---|---|

# ### 定义

[x]_补 = \begin{cases} x & 2^n > x \geq 0 \\ 2^{n+1} + x = 2^{n+1} - |x| & 0 \geq x \geq -2^n \end{cases} \quad (\text{mod } 2^{n+1})

# ### 举例

x = +0111001 ⟶ [x]_补 = 00111001

x = -0111001 ⟶

[x]_补 = 100000000 + x = 100000000 - 0111001 = 11000111
