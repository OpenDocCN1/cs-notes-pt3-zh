# # 算术/逻辑运算单元ALU（1）

# ## 基本思想

+   - 先将原全加器的输入A<sub>i</sub>、B<sub>i</sub>送至函数发生器进行处理

+   - S<sub>0</sub>、S<sub>1</sub>、S<sub>2</sub>、S<sub>3</sub>为函数发生器的控制信号

+   - 函数发生器的输出X<sub>i</sub>、Y<sub>i</sub>至全加器进行全加

+   - 由S<sub>0</sub>、S<sub>1</sub>、S<sub>2</sub>、S<sub>3</sub>来控制ALU所完成的运算
