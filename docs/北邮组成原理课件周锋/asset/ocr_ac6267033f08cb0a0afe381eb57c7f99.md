# 文件内容的解释方式

# 13.3 文件的打开与关闭

| 模式 |  |
|---|---|---|
| b | 二进制(binary)模式解释文件，被读写的字节不做任何转换。 unix下的唯一解释方式。 |
| t | 以windows文本(text)模式解释文件,windows下默认解释方式。将数据写入文件时，如果遇到换行符'\n'(ASII 值为10, 0A)，则会转换为回车—换行'\r\n'(ASII值为13-10, 0D0A)写入文件中；读取文件数据的时候，若遇到回车—换行，即连续的ASII值0D0A，则转换为换行符0A；遇到 Ctrl+Z会译为EOF。 |

在windows下，使用fopen函数开启文件，默认是text解释模式，若要以binary解释，必须加b。例： rb/wb/ab/r+b/w+b/a+b。
