# # 部分积

令：y=0.y₁y₂……yₙ

则：xy = x×(y₁×2⁻¹+ y₂×2⁻² +……+ yₙ×2⁻ⁿ)
= 2⁻¹ ×(xy₁+ xy₂×2⁻¹ +……+ xyₙ×2⁻ⁿ⁺¹)
= 2⁻¹ ×(xy₁+ 2⁻¹ (xy₂+ 2⁻¹ (xy₃+ ……+
2⁻¹(xyₙ+0))))

令：z₀=0

z₁=2⁻¹ (xyₙ+z₀)

z₂=2⁻¹ (xyₙ₋₁+z₁)

……

zᵢ=2⁻¹ (xyₙ₋ᵢ₊₁+zᵢ₋₁) ……

zₙ=2⁻¹ (xy₁+zₙ₋₁)=xy
