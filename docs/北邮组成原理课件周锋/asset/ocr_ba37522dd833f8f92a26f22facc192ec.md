# # 1位十进制（BCD）加法器设计

令Xi和Yi为两个一位BCD码。
■设Si为BCD码的和，Ci+1为BCD码的进位输出，Ci为进位输入。
■令S'i为修正之前的二进制和，C'i+1为修正之前的进位。

+   1）若0≤Xi + Yi + Ci<10,则C'i+1 = 0, 0≤S'i≤9  
+      Si = S'i , Ci+1=0

+   2）若10≤Xi + Yi + Ci≤15, 则C'i+1 = 0, 10≤S'i≤15  
+      Si = S'i + 6 (mod 16) , Ci+1=1

+   3）若16≤Xi + Yi + Ci≤19, 则C'i+1 = 1, 0≤S'i≤3  
+      Si = S'i + 6 (mod 16) , Ci+1=1
