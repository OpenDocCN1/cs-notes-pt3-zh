# 6.5 典型总线-PCI

+   ○ PCI Express，简称3GIO（Third-Generation Input/Output）
+   ○ 兼容PCI和PCI-X
+   ○ PCI Express导线数量比PCI减少近75%
+   ○ 数据不需要同步，在同一系统内能够以不同频率运行，而且能够延伸到系统之外，采用专用线缆可将各种外设直接与系统内的PCI Express总线连接在一起。
+   ○ 速度快
+     ✱ 连接可以由x1、x2、x4、x8、x12、x16、x32组成
+     ✱ 每个通道带宽为2.5Gb/s（可提升到5Gb/s）
+     ✱ 理论上最高连接带宽可达8-10GB/s
