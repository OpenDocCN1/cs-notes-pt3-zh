# 6.5 典型总线-PCI

+   ○ **ISA（Industrial Standard Architecture）**总线是IBM公司1984年为了推出PC系列机而制定的总线标准。
+   
+   ◆ **ISA-8**适用于IBM PC/XT微机（Intel 8088）。62针插座。
+   
+   ◆ **ISA-16**适用于IBM PC/AT微机（Intel 8086）。扩充了36针插座。

+   ○ **EISA（Extended Industrial Standard Architecture）**总线是1989年由Compaq等九家公司联合推出的32位总线标准。
+   
+   ◆ EISA总线完全兼容ISA总线信号。
+   
+   ◆ EISA总线支持CPU、DMA和总线设备对存储器的32位地址寻址。
