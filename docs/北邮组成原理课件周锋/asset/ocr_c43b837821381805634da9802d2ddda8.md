# 存取过程

+   1M×4位的EDRAM芯片
+   - 20位地址需分2次通过芯片提供的11条地址线引脚送入内部
+   - 在RAS信号的控制下，先送入高11位地址，选中DRAM一行（512×4位）送至SRAM中
+   - 在CAS信号的控制下，将低9位地址送入，选中SRAM中某一4位组
+   - 下次输入的行地址先与最后读出行地址进行比较，如果相同，则只输入的列地址从SRAM中选择某一位组送出即可，节省了读取的时间
+   - 以SRAM保存一行内容的办法，对成块传送非常有利
+   - 连续变动低9位地址，会使SRAM中相应位组连续读出，被称为“突发模式”（Burst Mode）
