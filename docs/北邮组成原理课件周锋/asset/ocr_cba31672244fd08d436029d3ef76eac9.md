# # C语言程序→汇编语言程序

```c
#include <stdio.h>
void sum(int x,int y,int* z){
    *z=x+y;
}
int main(void){
    int result;
    sum(100,200,&result);
    printf("100 + 200 = %d\n",result);
    return 0;
}
```
