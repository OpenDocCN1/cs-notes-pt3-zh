# 示例：文件的复制(2)

```
void copyFile(char * sourceFileName,char * destFileName)
{
    char buffer[81];
    FILE * infile,*outfile;
    if((infile=fopen(sourceFileName,"rb"))==NULL)
    { printf("can't open the source file\n");
      exit(0);}
    if((outfile=fopen(destFileName,"wb"))==NULL)
    { printf("can't open the dest file\n");
      exit(0);}
    while(fgets(buffer,81,infile)!=NULL)//逐字数据块读取
        fputs(buffer,outfile);  //将数据块写入目标文件
    fclose(infile);
    fclose(outfile);
}
```
