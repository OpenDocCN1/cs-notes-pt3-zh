# 输入输出重定向示例

```
#include<stdio.h>
main()
{
    int i;
    int a[5];
    printf("input 5 numbers:\n");
    for(i=0;i<=4;i++)
        scanf("%d",&a[i]);
    printf("the 5 numbers are:\n");
    for(i=0;i<=4;i++)
        printf("%d,",a[i]);
    system("pause");
    return 0;
}
```

# 运行结果

input 5 numbers:
10 20 30 40 50
the 5 numbers are:
10,20,30,40,50,请按任意键继续...

默认情况下，标准输入设备是键盘，标准输出设备是显示器
