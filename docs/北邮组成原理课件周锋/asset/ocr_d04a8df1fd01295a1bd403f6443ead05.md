# # 74182CLA的进位逻辑关系

C<sub>n+x</sub>=G<sub>0</sub>+P<sub>0</sub>C<sub>n</sub>

C<sub>n+y</sub>=G<sub>1</sub>+P<sub>1</sub>C<sub>n+x</sub>=G<sub>1</sub>+G<sub>0</sub>P<sub>1</sub>+P<sub>0</sub>P<sub>1</sub>C<sub>n</sub>

C<sub>n+z</sub>=G<sub>2</sub>+P<sub>2</sub>C<sub>n+y</sub>

=G<sub>2</sub>+G<sub>1</sub>P<sub>2</sub>+G<sub>0</sub>P<sub>1</sub>P<sub>2</sub>+P<sub>0</sub>P<sub>1</sub>P<sub>2</sub>C<sub>n</sub>

C<sub>n+4</sub>=G<sub>3</sub>+P<sub>3</sub>C<sub>n+z</sub>

=G<sub>3</sub>+G<sub>2</sub>P<sub>3</sub>+G<sub>1</sub>P<sub>2</sub>P<sub>3</sub>+G<sub>0</sub>P<sub>1</sub>P<sub>2</sub>P<sub>3</sub>+P<sub>0</sub>P<sub>1</sub>P<sub>2</sub>P<sub>3</sub>C<sub>n</sub>

=G*+P*C<sub>n</sub>

G*为成组先行进位发生输出

P*为成组先行进位传送输出
