# 7.6显示设备

○光栅扫描显示是通过读取帧缓冲器的强度值，并在屏幕的适当位置显示图像

+   ◆ 光栅显示的基本指令如下形式：
+   
+   ❖ `read(l,x,y,z)`读存储器的位置中z的内容
+   
+   　⊞ x和y是由l的地址确定的；
+   
+   　⊞ z中是颜色值或灰度等级值。
+   
+   ❖ `write(x,y,z)`指令完成屏幕上对应位置的显示。

+   ◆ 主要的显示循环是：
+   
+   ❖ 对所有存储器存储单元，执行：
+   
+   　⊞ `read(l,x,y,z)`;
+   
+   　⊞ `write(x,y,z)`。
+   
+   ❖ 每执行一次循环称为屏幕刷新。
+   
+   ❖ 如果N是刷新存储器的大小，那么显示控制器总是执行N对指令。
