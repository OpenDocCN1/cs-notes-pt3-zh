# # 计算机系统的层次结构

+   第1级为微程序（或硬布线）级M₁。是一个实际机器层，由硬件直接执行微指令。

+   第2级为一般机器级M₂。也是一个实际机器层，也称为传统机器级。用M₁的微程序解释并执行每一条机器指令（或硬件直接执行机器指令），即在M₂上直接执行机器语言程序

+   第3级为操作系统级M₃。用于对计算机系统的软硬件资源进行管理和调度。用M₂的机器语言解释操作系统程序。

+   第4级为汇编语言级M₄。汇编语言是为了便于编写和阅读程序而设计的语言。用汇编程序翻译成机器语言和操作系统程序广义指令（系统调用）。

+   第5级为高级语言级M₅。用编译程序翻译成M₄的汇编语言程序。
