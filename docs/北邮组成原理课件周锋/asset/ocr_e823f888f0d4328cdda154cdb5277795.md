# 1Gbit NAND Flash Memory

+   - **Technology** 0.13μm p-sub CMOS triple-well  
+     1poly, 1poly cide, 1W, 2Al
+   - **Cell size** 0.077μm2
+   - **Chip size** 125.2mm2
+   - **Organization** 2112 × 8b × 64 page × 1k block
+   - **Power supply** 2.7V–3.6V
+   - **Cycle time** 50ns
+   - **Read time** 25μs
+   - **Program time** 200μs / page
+   - **Erase time** 2ms / block
