# # Xi、Yi与控制参数和输入量的关系

| S₀ S₁ | Yᵢ | S₂ S₃ | Xᵢ |
|---|---|---|---|
| 0 0 | Āᵢ | 0 0 | 1 |
| 0 1 | ĀᵢBᵢ | 0 1 | Āᵢ+Bᵢ |
| 1 0 | ĀᵢBᵢ | 1 0 | Āᵢ+Bᵢ |
| 1 1 | 0 | 1 1 | Āᵢ |

Xᵢ = S₂S̄₃ + S₂S̄₃(Aᵢ + Bᵢ) + S₂S₃(Aᵢ + Bᵢ) + S₂S₃Aᵢ
= S₃AᵢBᵢ + S₂AᵢBᵢ

Yᵢ = S₀S̄₁Āᵢ + S₀S̄₁AᵢBᵢ + S₀S₁ĀᵢBᵢ
= Aᵢ + S₀Bᵢ + SᵢBᵢ

Xᵢ Yᵢ = Yᵢ ⇒ Cₙ₊ᵢ₊₁ = Yᵢ + XᵢCₙ₊ᵢ
