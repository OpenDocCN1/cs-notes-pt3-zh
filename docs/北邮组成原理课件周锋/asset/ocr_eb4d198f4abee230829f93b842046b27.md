# ## 若32位浮点数x在计算机中存储的数为(41360000)16，求其十进制值

解：首先将十六进制数展开，得到二进制格式

十六进制 4 1 3 6 0 0 0 0  
二进制 0100 0001 0011 0110 0000 0000 0000 0000  
S 阶码E 尾数Frac

x=(-1)S×1.Frac×2E-127  
x=(-1)0×(1.011011)×210000010-01111111  
x=+(1.011011)×23=+1011.011  
=11+0×2-1+1×2-2+1×2-3  
= 11.375
