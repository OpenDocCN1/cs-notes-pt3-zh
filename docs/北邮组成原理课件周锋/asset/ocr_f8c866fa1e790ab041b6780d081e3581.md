# 6.5 典型总线-PCI

PCI（Peripheral Component Interconnect，外设互连总线的简称）总线是INTEL公司于1992年推出的一种开放性局部总线。其特点如下：

+   - PCI支持突发性读写操作，可以同时支持多组外围设备。PCI不受处理器的限制，具有广泛的兼容性。
+   - PCI总线采用一种并行的仲裁机制。仲裁是基于访问而不是基于时间片的，任何主设备使用总线都必须提出仲裁请求。
+   - 总线仲裁器根据收到的请求信号和各个设备的优先级别以及当前总线的工作状态来决定哪一个主设备获得总线的控制权。取得总线控制权的总线主控制器可以使用总线进行一次总线操作。
