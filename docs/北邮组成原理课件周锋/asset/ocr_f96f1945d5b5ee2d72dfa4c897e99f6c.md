# # ALU的第i位逻辑表达式

⎧⎪⎪⎪⎪⎪⎪⎪⎪⎪⎪⎪⎪⎪⎪⎪⎪⎪⎪⎪⎪⎪⎪⎪⎪⎪⎪⎪⎪⎪⎪⎪⎨⎪⎪⎪⎪⎪⎪⎪⎪⎪⎪⎪⎪⎪⎪⎪⎪⎪⎪⎪⎪⎪⎪⎪⎪⎪⎪⎪⎪⎪⎩
Xi = S3AiBi + S2AiBi
Yi = Ai + S0Bi + S1Bi
Fi = Xi ⊕ Yi ⊕ Cn+i
Cn+i+1 = Yi + XiCn+i
例如：S3S2S0S1 = 0000
代入：
Xi = S3AiBi + S2AiBi = 0 + 0 = 1
Yi = Ai + S0Bi + S1Bi = Ai
Fi = Yi ⊕ Xi ⊕ Cn+1 = Ai ⊕ 1 ⊕ Cn+1 = Ai (设Cn+1 = 0)
所以，在S3~S0 = 0000的时候，输出结果为Ai
