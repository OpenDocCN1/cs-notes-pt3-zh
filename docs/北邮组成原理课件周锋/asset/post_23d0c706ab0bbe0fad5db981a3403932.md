![](img/3c43175b8c1aba80647f801257e6a5e9_879_0.png)

设过程段 Sᵢ所需的时间为 τᵢ，缓冲寄存器的延时为 τ₁，线性流水线的时钟周期定义为
τ = max{ τᵢ } + τ₁ = τₘ + τ₁
流水线处理的频率为 f = 1 / τ。

- 一个具有k 级过程段的流水线处理 n 个任务需要的时钟周期数为Tₖ = k + (n − 1)，
- 所需的时间为： T = Tₖ × τ
- 而同时，顺序完成的时间为： T = n × k × τ

- k级线性流水线的加速比：
- Cₖ = TL / Tk = n·k / k + (n − 1)

## 流水线的实现

一条指令最多需要以下5个时钟周期：

- 取指令周期（IF）
- IR ← Mem[PC]
- NPC ← PC+4

- 指令译码/读寄存器周期（ID）
- A ← Regs[rs]
- B ← Regs[rt]
- Imm ← （（IR₁₆）¹⁶##IR₁₆..₃₁）

指令的译码操作和读寄存器操作是并行进行的。

原因：在指令格式中，操作码字段以及rs、rt字段都是在固定的位置。

这种技术称为固定字段译码技术。

![](img/3c43175b8c1aba80647f801257e6a5e9_886_0.png)

◆ 执行/有效地址计算周期（EX）

不同指令所进行的操作不同：

- 存储器访问指令
- `ALU0←A + Imm`

- 寄存器－寄存器ALU指令
- `ALU0←A func B`

- 寄存器－立即值ALU指令
- `ALU0←A op Imm`

- 分支指令
- `ALU0←NPC+（Imm<<2）；`
- `cond←（A == 0）`

![](img/3c43175b8c1aba80647f801257e6a5e9_887_0.png)

存储器访问/分支完成周期（MEM）

- 所有指令都要在该周期对PC进行更新。
- 除了分支指令，其他指令都是做PC←NPC

- 在该周期内处理的指令仅仅有load、store和分支三种指令。

- 存储器访问指令
- LMD←Mem[ALUo] 或者 Mem[ALUo]←B

- 分支指令
- if (cond) PC ←ALUo else PC←NPC

## 流水的实现

每一个时钟周期完成的工作看作是流水线的一段，

每个时钟周期启动一条新的指令。

○ 流水实现的数据通路

- • 设置了缓冲器/流水寄存器
- • 段与段之间设置缓冲器/流水寄存器
- • 缓冲器/流水寄存器的命名用其相邻的两个段的名称拼合而成。

例如： ID段与EX段之间的流水寄存器用ID/EX表示

- • 每个缓冲器/流水寄存器是由若干个寄存器构成的

![](img/3c43175b8c1aba80647f801257e6a5e9_903_0.png)

## 流水线的实现

- ○ 寄存器的命名形式为： x. y
- ○ 所包含的字段的命名形式为： x. y[s]

其中： x: 流水寄存器名称; y: 具体寄存器名称; s: 字段名

例如： ID/EX. IR: 流水寄存器ID/EX中的子寄存器IR

IRID/EX. IR[op]: 该寄存器的op字段（即操作码字段）

- ○ 缓冲器/流水寄存器的作用
- ◆ 将各段的工作隔开，使得它们不会互相干扰。
- ◆ 保存相应段的处理结果。

例如： EX/MEM. ALUo： 保存EX段ALU的运算结果

MEM/WB. LMD： 保存MEM段从数据存储器读出的数据

◆向后传递后面将要用到的数据或者控制信息

所有有用的数据和控制信息每个时钟周期会随着指令在流水线中的流动往后流动一段。
