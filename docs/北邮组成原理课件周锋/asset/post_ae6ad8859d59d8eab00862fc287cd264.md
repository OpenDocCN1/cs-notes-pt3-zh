## 逻辑运算的应用需求

- 逻辑或： \( 1 \lor x=1, \quad 0 \lor x=x \)
  将一个数的某些指定比特置1，其他比特保持不变
  例如： \( a \lor 01000010 \leftrightarrow \) 将a的第1和第6位置1

- 逻辑与： \( 1 \land x=x, \quad 0 \land x=0 \)
  将一个数的某些指定比特清0，其他比特保持不变
  例如： \( a \land 10111101 \leftrightarrow \) 将a的第1和第6位清0

- 逻辑异或： \( 1 \oplus x=/x, \quad 0 \oplus x=x \)
  将一个数的某些指定比特取反，其他比特保持不变
  例如： \( a \oplus 01000010 \leftrightarrow \) 将a的第1和第6位取反

## 一位全加器FA

### 逻辑表达式

F<sub>i</sub> = A<sub>i</sub> ⊕ B<sub>i</sub> ⊕ C<sub>i</sub>

C<sub>i+1</sub>=A<sub>i</sub>B<sub>i</sub>+B<sub>i</sub>C<sub>i</sub>+C<sub>i</sub>A<sub>i</sub>

### 解决方法

为了实现多种算术逻辑运算，可将A<sub>i</sub>和B<sub>i</sub>输入一个函数发生器得到输出X<sub>i</sub>和Y<sub>i</sub>，再作为一位全加器的输入

![](img/3c43175b8c1aba80647f801257e6a5e9_188_0.png)

## 算术/逻辑运算单元ALU（1）

### 基本思想

- 先将原全加器的输入A<sub>i</sub>、B<sub>i</sub>送至函数发生器进行处理

- S<sub>0</sub>、S<sub>1</sub>、S<sub>2</sub>、S<sub>3</sub>为函数发生器的控制信号

- 函数发生器的输出X<sub>i</sub>、Y<sub>i</sub>至全加器进行全加

- 由S<sub>0</sub>、S<sub>1</sub>、S<sub>2</sub>、S<sub>3</sub>来控制ALU所完成的运算

![](img/3c43175b8c1aba80647f801257e6a5e9_189_0.png)

## 算术/逻辑运算单元ALU（2）

F_i = X_i \oplus Y_i \oplus C_{n+i}
C_{n+i+1} = X_i Y_i + Y_i C_{n+i} + X_i C_{n+i}

用n+i代替原来一位全加器C_i中的i，i表示在一片ALU芯片上二进制位数。对于一片4位ALU，i=0、1、2、3；n表示用多片ALU组成更多位数运算器时每片电路的进位输入。如果用4片4位ALU组成一个16位运算器，n=0、4、8、12

![](img/3c43175b8c1aba80647f801257e6a5e9_190_0.png)

## Xi、Yi与控制参数和输入量的关系

| S₀ S₁ | Yᵢ | S₂ S₃ | Xᵢ |
|---|---|---|---|
| 0 0 | Āᵢ | 0 0 | 1 |
| 0 1 | ĀᵢBᵢ | 0 1 | Āᵢ+Bᵢ |
| 1 0 | ĀᵢBᵢ | 1 0 | Āᵢ+Bᵢ |
| 1 1 | 0 | 1 1 | Āᵢ |

Xᵢ = S₂S̄₃ + S₂S̄₃(Aᵢ + Bᵢ) + S₂S₃(Aᵢ + Bᵢ) + S₂S₃Aᵢ
= S₃AᵢBᵢ + S₂AᵢBᵢ

Yᵢ = S₀S̄₁Āᵢ + S₀S̄₁AᵢBᵢ + S₀S₁ĀᵢBᵢ
= Aᵢ + S₀Bᵢ + SᵢBᵢ

Xᵢ Yᵢ = Yᵢ ⇒ Cₙ₊ᵢ₊₁ = Yᵢ + XᵢCₙ₊ᵢ

## ALU的第i位逻辑表达式

⎧⎪⎪⎪⎪⎪⎪⎪⎪⎪⎪⎪⎪⎪⎪⎪⎪⎪⎪⎪⎪⎪⎪⎪⎪⎪⎪⎪⎪⎪⎪⎪⎨⎪⎪⎪⎪⎪⎪⎪⎪⎪⎪⎪⎪⎪⎪⎪⎪⎪⎪⎪⎪⎪⎪⎪⎪⎪⎪⎪⎪⎪⎩
Xi = S3AiBi + S2AiBi
Yi = Ai + S0Bi + S1Bi
Fi = Xi ⊕ Yi ⊕ Cn+i
Cn+i+1 = Yi + XiCn+i
例如：S3S2S0S1 = 0000
代入：
Xi = S3AiBi + S2AiBi = 0 + 0 = 1
Yi = Ai + S0Bi + S1Bi = Ai
Fi = Yi ⊕ Xi ⊕ Cn+1 = Ai ⊕ 1 ⊕ Cn+1 = Ai (设Cn+1 = 0)
所以，在S3~S0 = 0000的时候，输出结果为Ai

## 采用先行进位

### 每一位的进位公式：

C<sub>n+1</sub>=Y<sub>0</sub>+X<sub>0</sub>C<sub>n</sub>
C<sub>n+2</sub>=Y<sub>1</sub>+X<sub>1</sub>C<sub>n+1</sub>=Y<sub>1</sub>+Y<sub>0</sub>X<sub>1</sub>+X<sub>0</sub>X<sub>1</sub>C<sub>n</sub>
C<sub>n+3</sub>=Y<sub>2</sub>+X<sub>2</sub>C<sub>n+2</sub>=Y<sub>2</sub>+Y<sub>1</sub>X<sub>2</sub>+Y<sub>0</sub>X<sub>1</sub>X<sub>2</sub>+X<sub>0</sub>X<sub>1</sub>X<sub>2</sub>C<sub>n</sub>
C<sub>n+4</sub>=Y<sub>3</sub>+X<sub>3</sub>C<sub>n+3</sub>=Y<sub>3</sub>+Y<sub>2</sub>X<sub>3</sub>+Y<sub>1</sub>X<sub>2</sub>X<sub>3</sub>+Y<sub>0</sub>X<sub>1</sub>X<sub>2</sub>X<sub>3</sub>+X<sub>0</sub>X<sub>1</sub>X<sub>2</sub>X<sub>3</sub>C<sub>n</sub>
=G+PC<sub>n</sub>
其中，G=Y<sub>3</sub>+Y<sub>2</sub>X<sub>3</sub>+Y<sub>1</sub>X<sub>2</sub>X<sub>3</sub>+Y<sub>0</sub>X<sub>1</sub>X<sub>2</sub>X<sub>3</sub>，P=X<sub>0</sub>X<sub>1</sub>X<sub>2</sub>X<sub>3</sub>

- G为进位发生输出 P为进位传送输出

- P、G是为了实现多片ALU之间先行进位而设置的

从上式可以看出：第0位的进位输入C<sub>n</sub>可以直接传送到最高进位位上去，从而实现高速运算
