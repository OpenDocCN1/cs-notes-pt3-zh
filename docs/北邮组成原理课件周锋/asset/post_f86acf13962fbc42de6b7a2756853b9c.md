## 判断文件末尾

## 如何判断文件读到末尾？

- 1、符号常量EOF（其值被定义为-1）

在对ASCII码文件执行读入操作时，如果遇到文件尾，则读操作函数返回一个文件结束标志EOF。

例： while((ch=fgetc(cfPtr)!=EOF) {...}

- 2、库函数feof(): int feof(FILE *stream);

功能：在执行读文件操作时，如果遇到文件尾，则函数返回逻辑真（1）；否则，则返回逻辑假（0）。feof()函数同时适用于ASCII码文件和二进制文件。

例： while ( !feof(cfPtr)) {...}

## 判断文件末尾时常见错误-测试程序

## 判断文件末尾问题解析

错误程序：

```
while(!feof(infp))
{
```

从文件1读；
向文件2写；}

结果最后一次读取的内容被复制了两遍。

```
int feof(FILE *fp){ return fp->flag;}
```

- 只有读取函数试图读并失败以后，feof()才返回真。
- 因此，最后一次有效读取时，读取的内容被写入第一次。返回while条件判断feof仍为假（上次读取有效），读取遇到文件末尾，失败导致保存读取结果的变量值不能被更新，上次的内容被写入第二次。返回while条件判断feof为真，跳出循环。

## 正确的判断文件末尾

正确程序：

```
while(!feof(infp))
{
    if (从文件1读 成功)
        向文件2写;
}
```

结果最后一次读取的内容只被复制一次。

## [例1]设计函数，将键盘上输入的字符串（以ctrl+Z 作为结束字符）逐个字符存储到指定文本文件中

```
void writeFileFromKeyboard(char * filename)
{
    char ch;
    FILE * fPtr=NULL;
    if((fPtr=fopen(filename,"w"))!=NULL){ //打开文件
        while((ch=getchar())!=EOF) //从键盘读取字符写入文件
            fputc(ch, fPtr);
        fclose(fPtr); //关闭文件。执行本语句后，数据将被写入文件中。
        //如果缓冲区未满且不关闭文件，则数据不会写入文件中。
    }
}
```

## 二、读 / 写一个字符串——fgets()和fputs()

- 1、库函数fputs()一向文本文件输出一个字符串

- 1）用法： int fputs(const char *s, FILE * stream);

- 2）功能：将s所指向的字符串写入stream所指向的流中('\0'不被写入)。同时将文件位置指针向前移动字符串长度个字节,指向下一写入位置。如果发生写错误，则函数返回EOF；否则，返回一个非负值。

![](img/3c43175b8c1aba80647f801257e6a5e9_1005_0.png)

fputs(s, stdout)等价于puts(s)，将s所指向的字符串写入到标准输出流。

## 二、读 / 写一个字符串——fgets()和fputs()

2、库函数fgets()—从文本文件读一个字符串

- 1）用法：

```
char * fgets(char * s, int n, FILE * stream);
```

- 2）功能：从stream指向的流中读取最多n-1个字符并放到s所指向的数组中，遇到下面情况不再往后读：1）读到新行符 ‘\n’ 或者文件结束符(新行符会被读入到s)；2) 或虽未遇新行符和文件结束符、但已读入n-1个字符。

最后一个字符读入数组后接着写入结束标志 ‘\0’，并将文件位置指针向前移动n-1（字符串长度）个字节。如果遇到文件结束符并且没有字符读入数组，则数组内容不变。详见书上467页。

fgets(s, sizeof(s), stdin)等价于gets(s)
