## 处理器内核高危漏洞

- Meltdown（熔断）
- Spectre（幽灵）
- 攻击者利用这两组漏洞，在一定条件下可绕过内存访问的安全隔离机制获取密钥等隐私信息
- 影响面：近20年的Intel、AMD、高通厂家和其它ARM处理器均受到影响
- 攻击原理：现代处理器采用推测执行（Speculative Execution）和间接分支预测（Indirect Branch Prediction）等技术加速程序执行，黑客可通过旁道攻击（Side Channel Attack）的方式获取到缓存的敏感内容（由于猜测不正确没有被回滚）

> 学习完本课程后，可以基本理解该漏洞的原理！

## 1.2 计算机发展简史

## 计算机的演进

- 第0代 机械时代（BC-1940）
- 第1代 电子管时代（1943-1959）

耗电高，体积大，定点计算，机器语言，汇编语言

- 第2代 晶体管时代（1960-1968）

变集中处理为分级处理，浮点运算、高级语言

- 第3代 集成电路时代（1969-1977）

存储容量大，运算速度快，几十至几百万次/秒

- 第4代 超大规模集成电路时代（1978 - 现在）
- 第5代 量子计算机、光计算机、生物计算机？

## IAS machine

- 也称为Von Neumann机。冯·诺依曼结构计算机
- 现代计算机体系结构的鼻祖：五大功能部件
- 将程序和数据存储在同一个存储器中
- 采用二进制数据：简化了存储器
- 字长40位，存储器地址12位，指令长度20位
- 只实现整数运算：任何有能力的数学家都能在头脑中记住小数点的位置
