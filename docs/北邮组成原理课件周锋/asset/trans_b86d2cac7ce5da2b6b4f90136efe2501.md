

## Microinstruction Format

| Microinstruction Field | Meaning |
|---|---|
| `NμA5~NμA0` | Next address; when microinstructions are executed in sequence, it is the address of the next microinstruction |
| `P0` | When =1, determine the address of the next microinstruction according to the successor microaddress NμA5~NμA0 and the mode switches SWC, SWB, SWA. |
| `P1` | When =1, determine the address of the next microinstruction according to the successor microaddress NμA5~NμA0 and the instruction opcode IR7~IR4. |
| `P2` | When =1, determine the address of the next microinstruction according to the successor microaddress NμA5~NμA0 and the carry C. |
| `P3` | When =1, determine the address of the next microinstruction according to the successor microaddress NμA5~NμA0 and the zero flag Z. |
| `P4` | When =1, determine the address of the next microinstruction according to the successor microaddress NμA5~NμA0 and the interrupt signal INT. In the model computer, the interrupt signal INT is generated by the timing generator after receiving the interrupt request signal. |
| `STOP` | When =1, after T3 ends, the timing generator stops outputting the clock pulses T1, T2, T3. |
| `LIAR` | When =1, at the rising edge of T3, write PC7~PC0 into the interrupt address register IAR. |
| `INTD` | When =1, set the interrupt enable flag (in the timing generator) to 0, prohibiting the TEC-8 model computer from responding to interrupt requests. |
| `INTEN` | When =1, set the interrupt enable flag (in the timing generator) to 1, allowing the TEC-8 model computer to respond to interrupt requests. |
| `IABUS` | When =1, send the address in the interrupt address register to the data bus DBUS. |
| `PCADD` | When =1, add the current PC value to the relative offset to generate a new PC. |

## Console Operating Modes

(SWC, SWB, SWA are the definition switches for console instructions)

| SWC | SWB | SWA | Operation |
| --- | --- | --- | --- |
| 0 | 0 | 0 | Instruction fetch |
| 0 | 0 | 1 | Write memory |
| 0 | 1 | 0 | Read memory |
| 0 | 1 | 1 | Read register |
| 1 | 0 | 0 | Write register |

## Experimental Tasks

- Familiarize yourself with the microprogram flowchart and the microprogram code table.
- Correctly set the mode switches SWC, SWB, SWA; use single-microinstruction mode (set the single-step switch DP to 1) to trace the execution of the console operations read register, write register, read memory, and write memory; record the microaddress μA5~μA0, decision bits P4~P0, and related control signal values at each step; write down the functions and usage methods of these four console operations.
- Correctly set the instruction opcode IR7~IR4; use single-microinstruction mode to trace the execution of all instructions except the halt instruction STP. Record the microaddress μA5~μA0, decision bits P4~P0, and related control signal values at each step. For the JZ instruction, trace both Z=1 and Z=0 cases; for the JC instruction, trace both C=1 and C=0 cases.

## Examples of Console Operation Microprogram Flow

### Write Memory (WRM)

Press the reset button CLR#, set SWC=0, SWB=0, SWA=1.

- ① Set the memory address in SW7~SW0, and press the QD button to load this address into AR.
- ② Set the data in SW7~SW0, press the QD button to write the data into the memory unit specified by AR, and then AR is incremented by 1.
- ③ Return to ②. Continue in this way until the reset button CLR# is pressed. This implements manual writing to RAM (mainly for programs and data written by yourself).

### Start Program (PR)

After pressing the reset button CLR#, the microaddress register is cleared. Set SWC=0, SWB=0, SWA=0, use the data switches SW7~SW0 to set the first address of the program in RAM, and after pressing the QD button, start the program execution. Observe the execution of the microprograms corresponding to different machine instructions.

## TEC-8 Model Computer Instruction Set

| Name | Mnemonic | Function | Instruction Format |
| --- | --- | --- | --- |
| Addition | ADD Rd, Rs | Rd ← Rd + Rs | 0001 Rd Rs |
| Subtraction | SUB Rd, Rs | Rd ← Rd - Rs | 0010 Rd Rs |
| Logical AND | AND Rd, Rs | Rd ← Rd and Rs | 0011 Rd Rs |
| Increment | INC Rd | Rd ← Rd + 1 | 0100 Rd XX |
| Load | LD Rd, [Rs] | Rd ← [Rs] | 0101 Rd Rs |
| Store | ST Rs, [Rd] | Rs → [Rd] | 0110 Rd Rs |
| Conditional jump on C | JC addr | If C=1, then PC ← PC + offset | 0111 offset |
| Conditional jump on Z | JZ addr | If Z=1, then PC ← PC + offset | 1000 offset |
| Unconditional jump | JMP [Rd] | PC ← Rd | 1001 Rd XX |
| Output | OUT Rs | DBUS ← Rs | 1010 XX Rs |
| Interrupt return | IRET | Return to breakpoint | 1011 XX XX |
| Disable interrupt | DI | Disable interrupts | 1100 XX XX |
| Enable interrupt | EI | Enable interrupts | 1101 XX XX |
| Halt | STP | Pause operation | 1110 XX XX |

- ① Set the memory address in SW7~SW0. Using single-step or continuous mode, press the QD button to load this address into AR, and observe the AR indicator light.
