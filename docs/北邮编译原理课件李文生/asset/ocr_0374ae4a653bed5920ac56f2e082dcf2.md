# 为数组元素赋值语句生成目标代码

+   - 考虑两种语句形式： a:=b[i] 和 a[i]:=b
+   - 假设数组采用静态存储分配
+     - 基址已知
+     - 下标i存放的位置不同，生成的目标代码也不同

| i的位置 | a:=b[i] | a[i]:=b |
|---|---|---|
| i在Rᵢ中 | MOV b(Rᵢ), R 2 | MOV b, a(Rᵢ) 3 |
| i在Mᵢ中 | MOV Mᵢ, R
MOV b(R), R 4 | MOV Mᵢ, R
MOV b, a(R) 5 |
| i在栈中 | MOV Sᵢ(A), R
MOV b(R), R 4 | MOV Sᵢ(A), R
MOV b, a(R) 5 |
