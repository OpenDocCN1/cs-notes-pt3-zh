# 例：构造如下文法G的LR(0)项目集规范族：

S→aA|bB  A→cA|d  B→cB|d  （文法4.7）

+   拓广文法G′：
+   S′→S  S→aA|bB  A→cA|d  B→cB|d

+   活前缀ε的有效项目集
+   I₀=closure({S′→•S})={ S′→•S， S→•aA， S→•bB }

+   从I₀出发的转移有
+   活前缀
+   I₁=go(I₀,S)=closure({S′→S•})={S′→S•}  ---S
+   I₂=go(I₀,a)=closure({S→a•A})
+   ={S→a•A， A→•cA， A→•d}  ---a
+   I₃=go(I₀,b)=closure({S→b•B})
+   ={S→b•B， B→•cB， B→•d}  ---b
