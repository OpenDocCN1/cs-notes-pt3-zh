# LL(1)文法

例：考虑如下映射程序设计语言中if语句的文法

S→iEtSS' | a
S'→eS | ε
E→b
（文法4.5）

构造各非终结符号的FIRST和FOLLOW函数：

| | S | S' | E |
|---|---|---|---|
| FIRST | i, a | e, ε | b |
| FOLLOW | $, e | $, e | t |

应用算法4.2，构造该文法的分析表：

| | a | b | e | i | t | $ |
|---|---|---|---|---|---|---|
| S | S→a |  |  | S→iEtSS' |  |  |
| S' |  |  | S'→eS
S'→ε |  |  | S'→ε |
| E |  | E→b |  |  |  |  |
