# 从函数体推导函数类型

```
type link=↑cell;
cell=record
    info:integer;
    next:link
end;
procedure example (nptr: link; proc: procedure);
begin
    while nptr<>nil do
    begin
        proc(nptr);
        nptr:=nptr↑.next
    end
end;
```

> proc是一个过程
> 变元的个数？
> 变元的类型？

> proc用于链表的每个元素
> 可以为表元中的整型变量
> 置初值、或打印其值等
> proc的类型必是link→void
