# 二、非嵌套过程的静态作用域

+   - 过程定义不允许嵌套
+     - 独立的
+     - 顺序的
+   - 声明语句的位置
+     - 过程/函数内部
+     - 所有过程之外
+   - 在一个过程中引用的名字
+     - 局部的
+     - 全局的

```
int a[11];
readarray()
{ ... a ... }
int partition(int y, int z)
{ ... a ... }
quicksort(int m, int n)
{ int i; ...
i=partition(m,n);
quicksort(m,i-1);
quicksort(i+1,n); }
main ()
{ readarray;
quicksort(0,10); }
```
