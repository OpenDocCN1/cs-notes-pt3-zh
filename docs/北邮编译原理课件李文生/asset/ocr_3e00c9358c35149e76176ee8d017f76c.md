# 对 3*5+4 进行分析的动作序列 (见表4.8)

| 步骤 | 输入 | 分析栈 | 分析动作 |
|---|---|---|---|
| (1) | 3*5+4$ | state: 0
val: - | 移进 5 |
| (2) | *5+4$ | state: 0 5
val: - 3 | 归约，用F→digit goto[0,F]=3 |
| (3) | *5+4$ | state: 0 3
val: - 3 | 归约，用T→F goto[0,T]=2 |
| (4) | *5+4$ | state: 0 2
val: - 3 | 移进 7 |
| (5) | 5+4$ | state: 0 2 7
val: - 3 - | 移进 5 |
| (6) | +4$ | state: 0 2 7 5
val: - 3 - 5 | 归约，用F→digit goto[7,F]=10 |
| (7) | +4$ | state: 0 2 7 10
val: - 3 - 5 | 归约，用T→T*F goto[0,T]=2 |
