# LR分析控制程序

+   核心部分，对所有的LR分析程序都是一样的。

+   LR分析控制程序的工作过程

+   - 分析开始时，初始的二元式为：(S₀, a₁a₂...aₙ$)

+   - 分析过程中每一步的结果，均可表示为如下的二元式：(S₀X₁S₁X₂...XₘSₘ, aᵢaᵢ₊₁...aₙ$)

+   - 若action[Sₘ, aᵢ]=shift S，并且 S=goto[Sₘ, aᵢ]，则二元式变为：(S₀X₁S₁X₂...XₘSₘaᵢS, aᵢ₊₁...aₙ$)

+   - 若action[Sₘ, aᵢ]=reduce by A→β，则二元式变为：(S₀X₁S₁X₂...Xₘ₋ᵣSₘ₋ᵣAS, aᵢaᵢ₊₁...aₙ$)

+   - 若action[Sₘ, aᵢ]=accept（接受），表示分析成功，二元式变化过程终止。

+   - 若action[Sₘ, aᵢ]=error（出错），表示发现错误，调用错误处理程序。
