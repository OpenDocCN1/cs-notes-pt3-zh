# 操作

+   插入
+   - 散列函数将变量名映射到散列表单元
+   - 是否存在冲突？该表单元是否为空？
+     - 无冲突:
+       - 将栈指针的值记入该散列表单元
+       - 将新记录推入栈顶
+     - 有冲突
+       - 检查冲突链中是否有同名变量
+         - 没有：将新记录插入冲突链的链头
+         - 有：检查同名变量是否属于当前子表
+           同名变量在栈中的位置 >= 块索引表顶端元素的值？
+           >=：在当前子表中，报告错误
+           <: 不在当前子表中，将新记录插入冲突链的链头
