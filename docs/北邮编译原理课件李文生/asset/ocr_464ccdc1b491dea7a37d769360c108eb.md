# 三、控制流优化

+   连续跳转的goto语句：
+     goto L₂
+     ...
+     L₁: goto L₂

+   条件转移语句：
+     if a<b goto L₂
+     ...
+     L₁: goto L₂

+   如果控制结构为：
+     goto L₁
+     ...
+     L₁: if a<b goto L₂
+     L₃: ...

+   如果只有一个转移到L₁，且L₁前边是一无条件转移指令：
+     if a<b goto L₂
+     goto L₃
+     ...
+     L₃: ...
