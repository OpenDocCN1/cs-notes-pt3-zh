# 静态存储分配策略的实现

+   - 编译器处理声明语句时，每遇到一个变量名就创建一个符号表条目，填入相应的属性，包括目标地址。
+   - 每个变量所需空间的大小由其类型确定，并且在编译时刻是已知的。
+   - 根据名字出现的先后顺序，连续分配空间

| name | type | address | ... | length |
|---|---|---|---|---|
| N₁ |  | 0 |  | n₁ |
| N₂ |  | n₁ |  | n₂ |
| N₃ |  | n₁+n₂ |  | n₃ |
| … | … | … | … |  |
