# 2. 名字等价

+   - 有些语言(如Pascal、C等)允许用户定义类型名
+   - C类型定义和变量声明（6.1）
+     ```
+     typedef struct {
+         int age;
+         char name[20];
+     } recA;
+     typedef recA *recP;
+     recP a;
+     recP b;
+     recA *c, *d;
+     recA *e;
+     ```

问题：a、b、c、d和e是否具有相同的类型？

关键：类型表达式recP和pointer(recA)是否等价

回答：依赖于具体的实现系统

原因：C语言报告中没有定义“类型等价”这个术语
