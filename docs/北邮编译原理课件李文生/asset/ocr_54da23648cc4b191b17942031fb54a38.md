# 例：分析符号串id+)

| 栈 | 输入 | 分析动作 |
|---|---|---|
| 0 | `id+)$` | shift |
| 0id3 | `+)$` | reduce by E→id |
| 0E1 | `+)$` | shift |
| 0E1+4 | `)$` | CALL e2 “括号不匹配”，删掉‘)’ |
| 0E1+4 | `$` | CALL e1 “缺少运算对象”，id压入栈 |
| 0E1+4id3 | `$` | reduce by E→id |
| 0E1+4E7 | `$` | reduce by E→E+E |
| 0E1 | `$` | accept |
