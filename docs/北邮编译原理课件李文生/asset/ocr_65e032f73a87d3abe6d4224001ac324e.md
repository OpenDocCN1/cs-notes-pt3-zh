# 三、表达式的类型检查

综合属性E.type，类型体制指派给E产生的表达式的类型表达式

```
E→literal { E.type=char }
```

```
E→num { E.type=integer }
```

```
E→id { E.type=lookup(id.entry) }
```

```
E→id₁>id₂ { if (lookup(id₁.entry)==integer) && (lookup(id₂.entry)==integer) || (lookup(id₁.entry)==char) && (lookup(id₂.entry)==char) E.type=boolean; else E.type=type_error; }
```
