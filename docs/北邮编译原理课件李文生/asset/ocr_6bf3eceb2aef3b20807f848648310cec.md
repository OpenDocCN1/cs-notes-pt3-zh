# 一、消除翻译方案中的左递归

# 例：考虑对简单表达式求值的语法制导定义

| 产生式 | 语义规则 |
|---|---|
| L→E | print(E.val) |
| E→E₁+T | E.val=E₁.val+T.val |
| E→T | E.val=T.val |
| T→T₁*F | T.val=T₁.val*F.val |
| T→F | T.val=F.val |
| F→(E) | F.val=E.val |
| F→digit | F.val=digit.val |

翻译方案：

(1) L→E { print(E.val) }

(2) E→E₁+T { E.val=E₁.val+T.val }

(3) E→T { E.val=T.val }

(4) T→T₁*F { T.val=T₁.val*F.val }

(5) T→F { T.val=F.val }

(6) F→(E) { F.val=E.val }

(7) F→digit { F.val=digit.val }

消除左递归的方法：

A→Aα | β

替换为：A→βR

R→αR | ε

由(2)和(3)有：

(2′) E→T {E.val=T.val} M

(3′) M→+T {E.val=E₁.val+T.val} M₁

(3″) M→ε

**继承属性** M.i：表示在M之前已经推导出的子表达式的值

**综合属性** M.s：表示在M完全展开之后得到的表达式的值
