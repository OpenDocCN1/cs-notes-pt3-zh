# 二、数值表示法

+   - 布尔表达式的求值类似于算术表达式的求值
+   - 例如： a or b and not c
+     ① not c
+     ② b and t₁
+     ③ a or t₂

+   - 三地址代码
+     t₁:=not c
+     t₂:=b and t₁
+     t₃:=a or t₂

+   - 关系表达式 a<b
+     等价于：
+       if a<b
+       then 1
+       else 0

+   - a<b的三地址代码：
+     100: if a<b goto 103
+     101: t:=0
+     102: goto 104
+     103: t:=1
+     104:
