# CASE语句的翻译

```
switch ▲ E
begin
case V₁ :▲ S₁
case Vᵢ :▲ Sᵢ
...
case Vₙ₋₁ :▲ Sₙ₋₁
default :▲ Sₙ
end ▲
```

+   1. 生成 test 和 next 两个标号
+   2. 建立一个临时变量 t

+   1. 生成对E求值的代码
+   2. 结果值存入临时变量t中
+   3. 产生指令 goto test

+   1. 建立一个新的标号 Lᵢ, 并把它存入符号表;
+   2. 建立一个栈, 令其为case栈, 存放每个 case对应的常量值及其标号在符号表的位置

+   1. 生成 Sᵢ 的代码, 并以 Lᵢ 标识它的第一条语句
+   2. 产生指令 goto next

+   1. 以 test 标识第一条测试语句
+   2. 从 case 栈底向栈顶的方向读取二元式 <值, 指针>, 生成测试语句
