# 为条件语句生成目标代码

+   if a<b goto L

实现：

+   a-b的结果送入寄存器R

+   判断R的值为正、负、还是零

+   若为负，则转移到L

+   利用条件码表示计算结果或存入寄存器R的值为正、负、还是零

如： if a<b goto L

目标代码：

```
CMP a, b
```

```
CJ< L
```

语句序列

```
x:=a+b
```

```
if x<0 goto L
```

目标代码：

```
MOV a, R₀
```

```
ADD b, R₀
```

```
MOV R₀, x
```

```
CJ< L
```
