# 二、确定标识符的类型

+   - 语言中的类型：
+     - 基本类型：
+       char、integer、和boolean
+       type_error和void
+     - 构造类型：
+       数组、指针和函数

+   - 假定：
+     - 数组下标从1开始
+       类型array[256] of char的类型表达式是：
+       array(1..256,char)
+     - 前缀算符↑用于建立指针类型
+       ↑integer的类型表达式是pointer(integer)
+     - 函数类型由定义域类型和值域类型确定
