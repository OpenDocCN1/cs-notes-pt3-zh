# 二、YACC对二义文法的处理

+   - **处理冲突的两条缺省规则**
+     - “归约-归约”冲突，选择排在前面的产生式进行归约
+     - “移进-归约”冲突，选择执行移进动作

+   - **处理移进-归约冲突的机制**
+     - 利用 `%left`、`-` 说明 `+` 和 `-` 具有同样的优先级，并且遵从左结合规则。
+     - 利用 `%right`、`↑` 声名算符 `↑`，遵从右结合规则。
+     - 利用 `%nonassoc`、`<` 说明某些二元运算符不具有结合性。
+     - 先出现的记号的优先级低
+     - 同一声明中的记号具有相同的优先级
