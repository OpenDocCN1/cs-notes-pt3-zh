# 例：非L属性定义的语法制导定义

| 产生式 | 语义规则 |
| --- | --- |
| A→LM | L. i=l(A. i)
M. i=m(L. s)
A. s=f(M. s) |
| A→QR | R. i=r(A. i)
Q. i=q(R. s)
A. s=f(Q. s) |
