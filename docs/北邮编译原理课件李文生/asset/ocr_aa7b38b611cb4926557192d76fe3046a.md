# 先引用后定义的情况

...
goto L
...
goto L
...

+   1. 根据标号L查找当前符号表
+   2. 若未找到，则：
+      将标号L插入符号表
+      生成目标地址未定义的goto语句
+      将该语句的地址p填入L的表项中
+   3. 若找到，则：
+      生成目标地址未定义的goto语句
+      将该语句的地址q插在链首

L: ↑ S

| name | type | exist | address |
| L | label | t | A |

+   1. 根据标号L查找当前符号表
+   2. 将“未定义”改为“已定义”
+   3. 用S的第一条三地址语句的地址 A 回填链表中的goto语句

q: (goto, —, —, A)
p: (goto, —, —, A)
