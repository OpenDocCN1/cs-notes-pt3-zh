e1：在状态0、2、4、5，期待输入符号为运算对象的首字符，即id或(，而输入中出现的却是运算符符号 ‘+’或 ‘*’，或是输入串结束标志 ‘$’。

+   - 策略：把一个假想的id压入栈，并将状态3推入栈顶。
+   - 诊断信息：“缺少运算对象”

e2：在状态0、1、2、4、5，期待输入符号为运算对象的首字符或运算符符号，但却遇到右括号。

+   - 策略：删掉输入的右括号
+   - 诊断信息：“括号不匹配”

e3：在状态1、6，期待输入符号为运算符符号或右括号，而遇到的却是运算对象（id或左括号）。

+   - 策略：把运算符符号 ‘+’压入栈，转移到状态4。
+   - 诊断信息：“缺少运算符符号”

e4：在状态6，期待输入符号为运算符符号或右括号，而遇到的却是输入串结束标志 ‘$’。

+   - 策略：把右括号压入栈，转移到状态9。
+   - 诊断信息：“缺少右括号”
