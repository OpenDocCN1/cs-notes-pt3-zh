# SLR(1)分析表的构造

+   - SLR分析方法的一个特征
+     - 如果文法的有效项目集中有冲突动作，多数冲突可通过考察有关非终结符号的FOLLOW集合而得到解决

+   - 如项目集： I={X→α·bβ， A→α·， B→α·}
+     - 存在移进-归约冲突
+     - 存在归约-归约冲突

+   - 冲突的解决方法，查看FOLLOW(A)和FOLLOW(B)
+     - FOLLOW(A)∩FOLLOW(B)=Φ
+     - b∉FOLLOW(A) 并且 b∉FOLLOW(B)
+     - 决策:
+       - 当a=b时，把b移进栈里;
+       - 当a∈FOLLOW(A)时，用产生式A→α进行归约;
+       - 当a∈FOLLOW(B)时，用产生式B→α进行归约。
