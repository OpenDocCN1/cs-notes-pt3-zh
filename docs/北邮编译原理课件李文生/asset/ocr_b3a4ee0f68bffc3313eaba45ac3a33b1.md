例：判断下面的文法是否为LL(1)文法？
若不是，可否改写为LL(1)文法？
S→(L) | a
L→L,S | S

+   文法含有左递归，故不是LL(1)文法

+   改写文法：消除左递归
+   S→(L) | a
+   L→SL'
+   L'→,SL' | ε

FIRST((L)) ∩ FIRST(a) = φ
FIRST(,SL') ∩ FOLLOW(L') = φ

| | FIRST | FOLLOW |
|---|---|---|
| S | ( a | $ , ) |
| L | ( a | ) |
| L' | , ε | ) |

| | a | ( | ) | , | $ |
|---|---|---|---|---|---|
| S | S→a | S→(L) |  |  |  |
| L | L→SL' | L→SL' |  |  |  |
| L' |  |  | L'→ε | L'→,SL' |  |
