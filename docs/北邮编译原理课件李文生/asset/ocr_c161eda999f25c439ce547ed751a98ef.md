# 例：构造如下文法的LR(1)项目集规范族：

（1）S→CC    （2）C→cC    （3）C→d    （文法4.9）

# 拓广文法：

（0）S'→S    （1）S→CC    （2）C→cC    （3）C→d

# 根据算法4.6构造其LR(1)项目集规范族。

I₀=closure({[S'→•S, $]})
={ [S'→•S, $] [S→•CC, $] [C→•cC, c/d] [C→•d, c/d] }

I₁=go(I₀, S)=closure({[S'→S•, $]})={[S'→S•, $]}

I₂=go(I₀, C)=closure({[S→C•C, $]})
={ [S→C•C, $] [C→•cC, $] [C→•d, $] }

I₃=go(I₀, c)=closure({[C→c•C, c/d]})
={ [C→c•C, c/d] [C→•cC, c/d] [C→•d, c/d] }

I₄=go(I₀, d)=closure({[C→d•, c/d]})={[C→d•, c/d]}
