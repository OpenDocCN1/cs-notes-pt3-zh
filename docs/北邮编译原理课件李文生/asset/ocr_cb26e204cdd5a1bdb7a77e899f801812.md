# 扩充分析栈

目的：使之能够保存综合属性

做法：在分析栈中增加一个域，来存放综合属性值

例：带有综合属性域的分析栈

|  |  |
|---|---|---|
| Z | Z.z |
| Y | Y.y |
| X | X.x |
| --- | --- |
| state | val |

top →

+   栈由一对数组state和val实现

+   state元素是指向LR(1)分析表中状态的指针（或索引）

+   如果state[i]对应的符号为A, val[i]中就存放分析树中与节点A对应的属性值。

+   假设综合属性刚好在每次归约前计算

A→XYZ对应的语义规则是A.a=f(X.x, Y.y, Z.z)
