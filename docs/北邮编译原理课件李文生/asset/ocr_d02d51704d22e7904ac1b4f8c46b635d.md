# 7.4 参数传递机制

过程之间通信的方式：

+   - 文件
+   - 非局部名字
+   - 参数

+   一、传值调用
+   二、引用调用
+   三、复制恢复
+   四、传名调用

```
program reference(input,output);
var a, b : integer;
procedure swap(x, y : integer);
  var temp : integer;
  begin
    temp:=x;
    x:=y;
    y:=temp
  end;
begin
  a:=1; b:=2;
  swap(a, b);
  writeln('a=', a);
  writeln('b=', b)
end.
```
