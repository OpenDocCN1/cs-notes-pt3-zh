# 三、符号表操作

+   - 最常执行的操作： 插入和检索
+   - 要求变量显式声明的强类型语言：
+     - 编译程序在处理声明语句时调用两种操作
+       - 检索：查重、确定新表目的位置
+       - 插入：建立新的表目
+     - 在程序中引用变量名时，调用检索操作
+       - 查找信息，进行语义分析、代码生成
+       - 可以发现未定义的名字
+   - 允许变量隐式声明的语言：
+     - 标识符的每次出现都按首次出现处理
+     - 检索：
+       - 已经声明，进行类型检查，...
+       - 首次出现，插入操作，从其作用推测出该变量的全部属性
