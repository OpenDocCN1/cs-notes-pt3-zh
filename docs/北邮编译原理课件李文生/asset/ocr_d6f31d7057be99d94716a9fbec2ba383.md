# L属性定义翻译方案设计举例

+   语法制导定义

| 产生式 | 语义规则 |
| --- | --- |
| D→TL | L. in=T. type |
| T→int | T. type=integer |
| T→real | T. type=real |
| L→L₁, id | L₁. in=L. in
addtype(id. entry, L. in) |
| L→id | addtype(id. entry, L. in) |

+   翻译方案

```
D→T { L.in=T.type } L
T→int { T.type=integer }
T→real { T.type=real }
L→{ L1.in=L.in } L₁,id { addtype(id.entry, L.in) }
L→id { addtype(id.entry, L.in) }
```
