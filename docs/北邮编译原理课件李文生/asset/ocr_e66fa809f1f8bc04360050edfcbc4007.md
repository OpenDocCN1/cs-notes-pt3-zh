# 实现翻译方案的函数

```
int M(int in) {
    int tval, i1, s1, s;
    char addoplexeme;
    if (lookahead==' +') { // 产生式M→+TM
        addoplexeme=lexval;
        match(' +');
        tval=T();
        i1=in+tval;
        s1=M(i1);
        s=s1;
    };
    else s=in; // 产生式M→ε
    return s
}
```
