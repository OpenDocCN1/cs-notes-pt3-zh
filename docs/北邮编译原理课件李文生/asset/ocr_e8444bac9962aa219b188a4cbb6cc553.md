# 例：为如下L属性定义设计翻译方案

| 产生式 | 语义规则 |
|---|---|
| S→B | B.ps=10<br>S.ht=B.ht |
| B→B₁B₂ | B₁.ps=B.ps<br>B₂.ps=B.ps<br>B.ht=max(B₁.ht,B₂.ht) |
| B→B₁subB₂ | B₁.ps=B.ps<br>B₂.ps=shrink(B.ps)<br>B.ht=disp(B₁.ht,B₂.ht) |
| B→text | B.ht=text.h×B.ps |

+   - L属性定义
+   - 唯一的继承属性是非终结符号B的ps属性
+     - 依赖于左部符号的继承属性，或者
+     - 常数
