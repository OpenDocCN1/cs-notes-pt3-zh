# 翻译规则部分

# 每条规则由一个产生式和有关的语义动作组成

+   产生式 A→α₁|α₂|…|αₙ，在 YACC 说明文件中写成
+   A : α₁ { 语义动作1 }
+   | α₂ { 语义动作2 }
+   …
+   | αₙ { 语义动作n }
+   ;

+   用单引号括起来的单个字符，如 ‘c’ ，是由终止符号 c 组成的记号

+   没有用引号括起来、也没有被说明成 token 类型的字母数字串是非终结符号

+   语义动作是用 C 语言描述的语句序列
+   - ‘$$’ 表示和产生式左部非终结符号相关的属性值， ‘$i’ 表示和产生式右部第 i 个文法符号相关的属性值。
