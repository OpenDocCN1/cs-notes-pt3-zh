## 为赋值语句产生语法树的语法制导定义

| 产生式 | 语义规则 |
|---|---|
| S→id:=E | S.nptr=manode(':=', mkleaf(id, id.entry), E.nptr) |
| E→E₁+T | E.nptr=makenode('+', E₁.nptr, T.nptr) |
| E→T | E.nptr=T.nptr |
| T→T₁*F | T.nptr=makenode('*', T₁.nptr, F.nptr) |
| T→F | T.nptr=F.nptr |
| F→(E) | F.nptr=E.nptr |
| F→id | F.nptr=makeleaf(id, id.entry) |
| F→num | F.nptr=makeleaf(num, num.val) |

## 二、三地址代码

- 三地址代码
  - 三地址语句组成的序列
  - 类似于汇编语言的代码
  - 语句可以有标号
  - 有控制流语句
- 三地址语句的形式： x:=y op z
  - x可以是名字、临时变量
  - op 代表运算符，如定点、浮点、或逻辑算符等
  - y、z 可以是名字、常数、或临时变量

## 三地址语句的种类

- 赋值语句
  x:=y op z
  x:=op y
  x:=y
- 转移语句
  goto L
  if x relop y  goto L
- 过程调用语句
  param x
  call p,n
- 数组赋值语句
  x:=y[i]
  x[i]:=y
- 指针赋值语句
  x:=&y
  x:=*y
  *x:=y

## 赋值语句 `a:=b*c+b*c` 的三地址代码

![](img/12b57169bd1d5004c5e7193ff0d478d5_567_0.png)

- ■ **对应语法树的代码**
  
  `t₁ := -c`
  
  `t₂ := b*t₁`
  
  `t₃ := -c`

  `t₅ := t₂+t₄`

- ▪ **对应 DAG 的代码**
  
  `t₁ := -c`
  
  `t₂ := b*t₁`
  
  `t₅ := t₂+t₂`
  
  `a := t₅`

## 三地址语句的实现——四元式

四元式
（op, arg1, arg2, result）
（op, arg1, , result）
（param, arg1, , ）
（goto, , , 语句标号）

赋值语句a:=b*-c+b*-c的四元式表示

|  | op | arg1 | arg2 | result |
|---|---|---|---|---|
| (14) | uminus | c |  | t₁ |
| (15) | * | b | t₁ | t₂ |
| (16) | uminus | c |  | t₃ |
| (17) | * | b | t₃ | t₄ |
| (18) | + | t₂ | t₄ | t₅ |
| (19) | := | t₅ |  | a |

## 三地址语句的实现——三元式

- 三元式：（op, arg1, arg2）
  - 为避免把临时变量名也存入符号表，可不引入临时变量
  - 把由一个语句计算出来的中间结果直接提供给引用它的语句
  - 用计算中间结果的语句的指针代替存放中间结果的临时变量

赋值语句a:=b*-c+b*-c的三元式表示

|  | op | arg1 | arg2 |
|---|---|---|---|
| (14) | uminus | c |  |
| (15) | * | b | (14) |
| (16) | uminus | c |  |
| (17) | * | b | (16) |
| (18) | + | (15) | (17) |
| (19) | := | a | (18) |

## 8.2 赋值语句的翻译

假设赋值语句出现的环境可用下面的文法描述：

- P→ M D; S
- M→ ε
- D→ D; D | D→ id: T | D→ proc id; N D; S
- N→ ε
- T→ integer | real | array [num] of T₁ | ↑T₁ | record D end
- S→ id:=E
- E→ E+E | E*E | -E | (E) | id
