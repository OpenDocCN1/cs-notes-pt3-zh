# 案例1

对于函数F（X,Y）,其输入变量X和Y的取值边界定义如下：

X ∈ [a, b) U [b, c) [c, d] ; Y ∈ [e, f) U [f, g]

可得到X,Y的等价类如下表

| 输入变量 | 有效等价类 | 编号 | 无效等价类 | 编号 |
|---|---|---|---|---|
| X | [a, b) | 1 | X<a | 6 |
|  | [b, c) | 2 |  |  |
|  | [c, d] | 3 | X>d | 7 |
| Y | [e, f) | 4 | Y<e | 8 |
|  | [f, g] | 5 | Y>g | 9 |
