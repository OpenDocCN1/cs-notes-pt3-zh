# 何时估算

估算不是一次性工作；它需要在整个项目生命周期中重复进行。

+   - 在WBS开发后
+   - 决定是否投标时
+   - 按管理项目以验证建议书估算时
+   - 开始项目的下一步工作时
+   - 假设证明无效时
+   - WBS改变以确定工作及与改变相关的费用时
+   - 资源、材料或服务得到批准进行改变时

# 估算流程

估算目标：

+   - 为什么要制定目标？
+   - 需要准确到什么程度？
+   - 谁是可能的用户？
+   - 何时需要估算？

估算项目详情：

+   - 确定准备估算所需的信息。

制定估算战略和方案：

+   - 确定估算人员。
+   - 制定估算方案来整合估算信息。
+   - 决定使用的估算验证类型。
+   - 回顾类似项目的历史记录。
