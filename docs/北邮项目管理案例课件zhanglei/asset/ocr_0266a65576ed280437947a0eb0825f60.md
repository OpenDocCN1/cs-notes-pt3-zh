# 确定客户需求

当确定客户需求时，要提向的问题包括：

+   - 交付件是什么？
+   - 有哪些相关人员？
+   - 成本是多少？
+   - 开发流程的期限有多长？
+   - 现有的基础设施能够支持吗？
+   - 需要哪些外部支持？
+   - 如何定义成功？
+   - 如何推广？
+   - 如何索赔？
+   - 它将持续多久？
+   - 正在开发或运行的设备中是否有类似产品？

# 确定和验证需求

+   - 项目开始或最初建议书时确定需求。
+   - 使用项目管理计划(PMP)。
+   - 验证需求时应该实现一些。
+   - 清楚陈述需求。
+   - 使用非语言显示方式(图形、模型)阐明需求。
+   - 把需求分为非需求项和排除项两大类。
+   - 获得问题细节的详细说明。
+   - 让客户和项目负责人再需求文档上签字。
+   - 预计和管理变更。
