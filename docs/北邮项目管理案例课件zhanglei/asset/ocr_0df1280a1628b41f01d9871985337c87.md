# 风险评估

+   分析项目风险时应考虑：
+   - 风险事件发生的可能性
+   - 每个确定的风险事件带来的损失或影响
+   - 风险的严重程度 (严重程度 = 可能性x影响)
+   - 评估因素包括：
+     - 优先顺序(此类风险以前是否发生过？)
+     - 操作的熟悉程度(以前是否开展过相关工作？)
+     - 资源和技能
+     - 时间、成本和质量
+     - 可能性 (风险发生的几率有多大？)
+     - 影响(对项目业务产生什么影响？)

# 定性分析

根据对项目的必要程度和复杂性对风险进行定性分析。

+   风险的定性评定应从以下方面进行：
+   - 风险对项目的影响
+   - 风险出现及不出现的几率
