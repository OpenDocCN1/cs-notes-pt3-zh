# 项目管理计划 (PMP)

+   使用PMP:
+   - 使项目经理能够全面地确定项目需求
+   - 确保在开始详细计划之前明确项目范围
+   - 在解决客户问题之前确定关键问题，避免工作小组徒劳无益
+   - 随着项目深入，确保PMP的评测标准用于控制项目的变更

# PMP内容

+   ◆介绍和汇总项目
+   ◆项目目标
+   ◆项目交付件
+   ◆主要阶段性工作
+   ◆假设
+   ◆风险
+   ◆资源需求
+   ◆局限性

+   ◆相关项目
+   ◆验收标准
+   ◆签署文件
+   ◆评审
+   ◆交流计划
+   ◆变更管理计划
+   ◆财务分析
+   ◆参考信息
