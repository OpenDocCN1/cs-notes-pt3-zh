# 项目控制概述

项目控制是在项目生命周期内重复执行的流程。

项目控制的目的是通过以下方面确保项目按期、在预算内完成，并符合规范：

+   - 验证为项目制订的基准
+   - 监视、分析和比较计划和实际的项目预测结果为核心
+   - 确定项目延期完成造成的偏差
+   - 及时调整计划，采取预防措施
