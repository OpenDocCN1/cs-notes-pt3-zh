# WBS 开发指南

+   - 开始先收集当前所有基准材料及与项目相关的信息，如：
+     - 项目管理计划
+     - 要求陈述
+     - 技术建议书
+     - 供应商建议书
+   - 与主要人员召开研讨会。
+   - 只将精力集中在WBS的第2或第3级别。
+   - 将责任具体到负责某各工作包的人员。
+   - 在开展活动前记录每项工作活动，包括其完成标准。
