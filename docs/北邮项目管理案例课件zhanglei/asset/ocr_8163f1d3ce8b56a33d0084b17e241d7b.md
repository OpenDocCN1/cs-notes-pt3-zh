|---|---|---|
| 如果被接受 | • 计划合并到系统中。
• 制定新基准。
• 修改进度表并分配资源。 | • 为客户/项目赞助者准备建议书，包括成本。

• 修订合同。 |
| 如果被拒绝 | 传递并记录决策。 | 传递并记录决策。 |

• 进行进一步分析
• 考虑替代方案

# 项目经理在变更管理中的作用

在变更管理中，项目经理应：

+   - 分析变更请求
+   - 管理范围
+   - 修订基准
