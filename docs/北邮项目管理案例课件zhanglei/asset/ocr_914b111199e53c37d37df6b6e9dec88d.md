# 组建项目组

组建项目组是一个流程：

+   - 为实现共同目标而分配的、与共同行为相关的一组人员。
+   - 促进有效的合作和项目组成员的满意。
+   - 组建有效的项目组，通过适当的人员和积极的团队精神，以实现理想结果。
+   - 有助于根据项目需求来组建并改组项目组。

# 如何组建项目组

|  |  |
|---|---|---|
| 计划 | 要组建什么样的项目组？
如何规划项目的建设？
如何组建项目组？
为项目选择哪些人？
项目的目标和是什么？ |
| 选择适当的项目组人员 | 审视
技术能力—知识、经验和能力
个人特征——一些、以及领导与指导、合作精神 |
| 组建项目组 | 不把项目人员分成小队
分配职责和任务
明确确定各自的角色和职责 |
| 建立沟通渠道 | 确保交换有效的信息
保持信息及时交流
定期举行进度状态会议，分享会议纪要 |
| 确保项目的投入 | 支持领导层最重要的资源，确保项目组对项目的投入 |
