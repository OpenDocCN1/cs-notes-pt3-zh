# 目标

完成本单元后，您能够：

+   - 设明项目进度的目的
+   - 定义基本的进度术语
+   - 识别制作网络图所用的不同类型的网络技巧
+   - 解释WBS与网络图之间的关系
+   - 解释如何构建网络图
+   - 定义主要路径方法中所用的术语和词汇
+   - 描述进度前置、落后，如何识别关键路径
+   - 说明如何审查项目进度，并使之与项目目标相一致
+   - 采用网络逻辑和进度安排的方法制定进度表

# 项目进度的目的

项目的进度主要用来：

+   - 跟踪项目的进展，将计划的与实际的操作相比较
+   - 确定会影响项目的潜在变更
+   - 向所有各方报告项目的进展状态，说明以下问题：
+     - 所进行的任务和活动是否会使项目成功完成
+     - 项目需要哪些资源
+     - 主要里程碑及时间
+     - 关键路径
