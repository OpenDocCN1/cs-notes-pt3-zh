# 总结

制现实的进度是一个很耗时的 工作。
由于以下原因，99% 的进度需要重新安排：

+   - 资源过度分配
+   - 时间表比要求更长

调整进度可能需要：

+   - 改变任务资源、任务开始时间或任务时长
+   - 将任务增加到 WBS，重新将认为必要的步骤制定成流程

重新计划步骤，直到产生有效的计划表，它对项目的成功至关重要。

# 总结 (续)

市场上许多商用的针对进度的项目管理工具。

项目管理工具可用来帮助你识别关键路径，但是：

+   - 不可盲目地使用工具
+   - 不是工具而是你管理项目
+   - 你对项目的成功负责，而不是工具。

项目启动有助项目达成目标，有助于团队一起工作，使工作在预算之内按时完成。
