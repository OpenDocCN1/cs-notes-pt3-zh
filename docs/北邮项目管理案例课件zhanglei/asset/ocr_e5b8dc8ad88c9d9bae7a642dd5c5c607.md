# 变更管理定义

变更管理是确保所有变化对项目产生最小影响的流程。

变更管理系统旨在通过跟踪和控制变化来降低执行、控制阶段的影响。

变更管理步骤如下：

+   > 确认并捕获每个变更请求
+   > 评估变更
+   > 描述是否接受、拒绝或延迟变更
+   > 执行、控制阶段接受的变更
