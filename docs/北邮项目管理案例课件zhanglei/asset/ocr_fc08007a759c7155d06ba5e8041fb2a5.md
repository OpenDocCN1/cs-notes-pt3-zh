# 项目审核总结

| A类： | 可控 |
|---|---|
|  | 可能存在小问题，但项目经理有备妥有效的方案来解决它，未发现现或潜在的大问题。 |
| B类： | 目前可控 |
|  | 必须解决现有或潜在问题以避免恶化。 |
| C类： | 主要问题 |
|  | 需要立即采取纠正方案，可能超过估计或预算值。强硬的管理活动是新获得控制的关键。 |
| D类： | 重要问题 |
|  | 严重负面影响，严重损害项目。激发客户或生产可接受负面影响时；需要进行彻底的管理评估，需要负责任地通知客户。 |

# 质量控制概述

质量控制包括：

+   - 监控特定的项目结果并决定它是否遵从相关的质量标准
+   - 确定消除不满意表现根源的方式

质量控制贯穿整个项目生命周期。
