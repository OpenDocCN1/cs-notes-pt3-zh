# （一）邻接表方法

设图G有k个结点，使用一个k*k的int型矩阵g表示图G，
矩阵g的第i行顺序列出与结点i直接相连的结点编号，最后以“-1”结尾。则图G表示成右图的邻接表。

|   | 1 | 2 | -1 |   |   |   |   |   |

| 0 | 1 | 2 | -1 |   |   |   |   |   |
| 1 | 0 | 3 | 4 | -1 |   |   |   |   |
| 2 | 0 | 4 | 5 | -1 |   |   |   |   |
| 3 | 1 | 4 | -1 |   |   |   |   |   |
| 4 | 1 | 2 | 3 | 6 | 7 | -1 |   |   |
| 5 | 2 | 6 | 7 | -1 |   |   |   |   |
| 6 | 4 | 5 | -1 |   |   |   |   |   |
| 7 | 4 | 5 | -1 |   |   |   |   |   |
