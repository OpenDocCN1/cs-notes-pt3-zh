考虑... x[i] 对 n[i] 的边界情况 n-1 递归求解和循环方程是:0。最下边的公式正好变成 a[i][i]*x[i]+... +a[i][n-1]*x[n-1]=a[i][n]

线性方程的解应该是：

```
x[i]=( a[i][n]-( a[i][i+1]*x[i+1] + ... + a[i][n-1]*x[n-1] ) )/a[i][i]
```

![](bbox=[0.01, 0.35, 0.99, 0.95])

开始

for(i=0;
i<n-1;
i++)

for(j=i+1;
j<n;
j++)

r=a[j][i]/a[i][i]

for(k=i;
k<=n;
k++)

a[j][k]=a[j][k]-a[i][k]*r

for(i=n-1;
i>=0;
i--)

r = 0

for(j=i+1;
j<=n-1;
j++)

r=r+a[i][j]*x[j]

x[i]=(a[i][n]-r)/a[i][i]

结束
