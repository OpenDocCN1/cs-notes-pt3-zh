# P的声明形式是：

类型符 **p

如下程序片段构造下图结构。

```
int **p, *s, v;
p = &s;
s = &v;
v=300;
```

其中声明符 “**p” 声明了指向指针变量的指针变量p。
使用s访问v内容的形式是
*s

使p访问v内容的格式是
**p
v=300。
这个间接寻址运算的意义是：
可以使指针变量s变量的值
可以被间接指向的指针变量p
量p装载变量”
三个语句解释：
*p 取上述p的内容，得到一个指针300；该指针值“指向int型变量”
**p即p=*(*p)再取上述“*p”的内容，得到一个int类型的值。
