# 表7-2 字符数组与字符指针变量的对比

|  | 字符数组 | 字符指针变量 |
|---|---|---|
| 存储空间 | 分配数组空间
`sizeof(char)*数组长度字节` | 分配指针空间
`4个字节` |
| 初始化 | 可以用字符串初始化。如 `char a[]="string"`;数组变量 a 有七个元素，把 string\0 这七个字符顺序分别放入数组 a 各元素中 | 可以用字符串初始化。`char *p="string"` 这时 "string" 是常量，p 指向该常量首地址。 |
| 赋值 | 可以对数组元素单个赋值 `a[2]='y'`
不允许对数组名赋值，因为数组名是指针常量，下述运算是错误的。
~~a = ...~~ | 可以让指针变量指向任意字符串。设有说明 “char a[10]”, 如下赋值运算都正确
`p="Hello";`
`p=a;` |
