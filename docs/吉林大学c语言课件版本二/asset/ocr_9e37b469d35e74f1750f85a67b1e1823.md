```
float x,y;
float f(float v,float w){
    return (w+v)/(7*v);
}
float p(float u){
    return ( f(u*0.3,x+u)+(u/2))/(2*x );
}
void main(){
    printf("please input x: ");
    scanf("%f",&x);
    y=(p(x)*p(x)+(5*x))/(p(x+5)-sqrt(x));
    printf("y(x)=%8.4f\n",y)
}
```

Return: 表达式的值作为函数值返回

函数定义说明符, 小括号()为形式参数表

{}内为函数p的函数体, 具体规定的操作和计算

P(x)称为函数调用

执行顺序:11→12→13（分别以x, x+5, x+2为实参调用函数p）→14
