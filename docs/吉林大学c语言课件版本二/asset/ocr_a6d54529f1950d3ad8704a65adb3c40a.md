# （二）邻接矩阵方法

设图G有k个结点，使用一个k*k的bool类型矩阵g表示图G
矩阵元素

g[i, j] = { true    表示从结点 i 到结点 j 有直接路；
            false   表示从结点 i 到结点 j 没有直接路； }

利用这种表示法，左图的网表示成右图8*8的bool矩阵。

| 1 | t  |    |    | t  | t  |    |    |    |
