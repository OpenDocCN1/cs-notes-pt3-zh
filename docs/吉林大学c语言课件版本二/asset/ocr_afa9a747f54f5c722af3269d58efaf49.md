# 例8-6 从n个整数中找出最大和最小

```
void max_min_value(
    int x[], int n,
    int *max, int *min){
    int *p;
    *max = *min = *x;
    for(p=x+1; p<x+n; p++){
        if (*p > *max)
            *max = *p;
        if (*p < *min)
            *min = *p;
    }
}
```

```
void main(){
    int a[10],
        max_value,min_value;
    max_min_value(a,10,
        &max_value,
        &min_value);
}
void main(){
    int a[10],
        max_value,min_value;
    int *ptr=a;
    max_min_value(ptr,10,
        &max_value,
        &min_value);
}
```
