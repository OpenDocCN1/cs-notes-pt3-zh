# 例7-9指向指针的指针、指针数组与数组的关系

```
void main(){
    int a[5]={23,24,25,26,27};
    int * n[5] , i;
    int **p=n;
    for( i=0; i<5; i++)
        n[i]=&(a[i]);
    for( i=0; i<5; i++,p++)
        printf("%4d",**p);
}
```
