# 例子

+   - vector[255]
+     vector 的编号为 255 (第256个)的成分，为 float 型变量
+   - v[2+3]
+     v 的编号为 5 (第6个)的成分，为 int 型变量
+   - t3[i+j*k]：
+     - 若 i+j*k 落在 0..25 之内
+       则是 t3 的编号为 i+j*k (第 i+j*k+1 个)的成分，是一个 bool 型变量；
+     - 否则 i+j*k 落在 0..25 之外，
+       则引起错误
+   - t4[0]
+     t4 的下标为 0 (第1个)的成分，为 char 型变量
