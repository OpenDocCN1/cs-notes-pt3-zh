
## 指针运算

### 求地址 &

“&”运算符用来求被操作对象的地址。

**例子：**

`&x` 表示变量 `x` 在内存中的存放地址；若 `x` 的地址为 `ABD0`，则 `&x` 的值为 `ABD0`。“&”的优先级为 15。

### 取内容 *

“*”与“&”互为逆运算。“*”运算访问地址表达式所指的变量。

**例子：**

- `x=*p` 是将指针 `p` 所指变量的值送入变量 `x` 中；
- `*p=5` 是将 5 送入指针 `p` 所指变量中。
- “*”的优先级也为 15。

### 赋值 =

可以把一个指针值赋值给某个指针变量。所谓指针值是指向某变量的指针（变量的地址）或函数的指针。

**例子：**

```c
int *px, x;
px=&x; /* 指针px指向变量x*/
px=NULL; /* 为px赋值空指针*/
px=(int*)4800; /* 将地址4800赋值给px，而不是整数类型4800 */
```

### 加 ++

如果指针值指向数组的一个成分，C 允许对相应指针值加上一个整数表达式。

- 设指针 `p` 指向数组 `a` 的一个成分。
- 把指针 `p` 与一个整数 `k` 相加，得到的结果值仍然是个指针值；
- 该值指向的是“数组 `a` 从 `p` 原来所指成分开始，向数组尾部移动 `k` 个成分后的成分”。

例如：

```c
int *p, *q, *r, a[100];
p=&(a[10]);
```

则 `p+3` 指向的实际地址是 `&(a[10])+3*sizeof(int)`，即 `a[13]` 的地址。若有 `q=p+3;`，将使得 `q` 指向 `a[13]`。与前文一样，“p++”表示“p=p+1”。

### 减 -（--）

指针的减法运算包括：

- 指针值减去一个整数表达式；
- 两个相容的指针值相减。

如果指针值指向数组的一个成分，C 允许对相应指针值减去一个整数表达式。

设指针 `p` 指向数组 `a` 的一个成分，把指针 `p` 与一个整数 `k` 相减，得到的结果值仍然是一个指针值；该值指向的是“数组 `a` 从 `p` 原来所指成分开始，向数组首部移动 `k` 个成分后的成分”。

例如：

```c
int *p, *q, *r, a[100];
p=&(a[10]);
```

则 `p-3` 指向的实际地址是 `&(a[10])-3*sizeof(int)`，即 `a[7]` 的地址。若有 `q=p-3;`，将使得 `q` 指向 `a[7]`。与前文一样，“p--”表示“p=p-1”。

- **指针值相容**，即所指的对象是同一个类型；
- 两个相容的指针则可以进行相减运算，所得结果是整型值，即两指针值间的距离。
- 例如：

```c
int *p,*q,*r, a[100];
p=&(a[10]);
q=&(a[15]);
```

则 `p-q` 得 `-5`；而 `q-p` 得 `5`。

### 指针加减运算限制

- 若指针 `p` 指向的不是数组成分，或 `p+k`、`p-k` 后超出数组定义范围，则其行为是未定义的，将产生不可预料的结果；
- 不能对函数指针、`void *` 类型指针进行加减运算；
- 不允许两个指针间进行加法运算。

### 判等运算和关系运算

C 中可以针对兼容类型的指针进行判等运算和关系运算，得到的结果是 `bool` 类型。

**关系运算包括：**

- 判断两个指针值是否相等或不相等：`==`、`!=`；
- 比较两个指针值的大小关系：`>`、`>=`、`<`、`<=`。

**例子：**

- `px<py` 判断 `px` 所指向的存储单元地址是否小于 `py` 所指向的存储单元地址。
- `px==py` 判断 `px` 与 `py` 是否指向同一个存储单元。
- `px==0`、`px!=0`、`px==NULL`、`px!=NULL` 都是判断 `px` 是否为空指针。

一定要注意，参与关系运算的指针值是否是兼容类型的。如果 `p` 指向一个 `int` 类型变量，而 `q` 指向一个 `float` 类型变量，进行 `p` 与 `q` 的比较是错误的。

### 例7-4 指针运算实例

```c
#include <stdio.h>
void main(){
    char str[255], *p;
    scanf("%s",str);
    p=str;
    while( *p!='\0' )
        p++;
    printf("The string length is %d \n", p-str);
}
```

程序运行若输入：

```
abcdef
```

则输出结果为：

```
The string length is 6
```

## 指针与数组

- **密切的关系**
  - 数组名是数组的首地址，即 `a[0]` 的地址；
  - 指针值也是一个地址。如果一个指针 `p` 指向数组 `a` 的首地址，即指向 `a[0]`，则 `p` 与 `a` 表示的是同一个对象。
- 事实上，在 C 中把指针和数组当作同一个概念看待，数组名是指针，指针也是数组。
- 可以认为数组名是常量指针。

### 用指针标识数组

例如：

```c
int a[5];
int *iptr;
iptr=a;  // 也可以使用 iptr=&(a[0])
```

如下操作等价：

- `a[i]`
- `*(a+i)`
- `iptr[i]`
- `*(iptr+i)`

### 例7-5 展示指针与数组间关系

```c
void main(){
    int a[5];
    int i, *p;
    for(i=0;i<5;i++){
        printf("a[%d]= ",i);
        scanf("%d", &(a[i]) );
    }
    for(i=0;i<5;i++)
        printf("%2d",a[i]);
    printf("\n");
    for(i=0;i<5;i++)
        printf("%2d",*(a+i));
    printf("\n");
    for(p=a;p<a+5;p++)
        printf("%2d",*p);
    printf("\n");
}
```

假设分别输入 `1、2、3、4、5`，在输出阶段：

```
a[0]= 1
a[1]= 2
a[2]= 3
a[3]= 4
a[4]= 5
```

执行第一个 for 语句输出结果：

```
1 2 3 4 5
```

执行第二个 for 语句输出结果：

```
1 2 3 4 5
```

执行第三个 for 语句输出结果：

```
1 2 3 4 5
```

### 数组名是指针常量

- 指针变量可以参与运算，比如例7-5中有语句：

  ```c
  for(p=a;p<a+5;p++)
      printf("%2d",*p);
  ```

  该语句中，对指针变量 `p` 不断进行增1运算。

- 虽然数组名也是指针，但对数组名却不能这样，因为数组名是指针常量。

- 对数组变量 `a` 的增1运算 `a++` 是非法的：

  ```c
  for( a=p; a<p+5; a++ )
      printf("%2d",*a);
  ```

### 指针变量的当前值

- 经常用指针变量表示数组。如有：

  ```c
  int a[10], *iptr;
  iptr=a;
  ```

- 若访问 `a` 数组的第 `i` 个元素，如下写法是等价的：
  - `a[i]`
  - `*(a+i)`
  - `iptr[i]`
  - `*(iptr+i)`

- 但是是否任何时刻这四种写法都等价，要看当前指针的值。

比如若有语句：

```c
iptr=&(a[2]);
```

被执行后，则上述 `iptr[i]`、`*(iptr+i)` 访问的是数组元素 `a[i+2]`，而不是 `a[i]`，它们与 `a[i+2]`、`*(a+i+2)` 等价。

写程序时要特别注意指针变量的当前值，有时由于忽略指针变量的当前值，会使程序产生严重错误，而且这种错误还十分难于查找。

例7-6说明该问题。该程序原想输入10个整数，再把它们打印出来，但是程序运行结果却不然。

### 例7-6 指针变量错误使用实例

```c
#include "stdio.h"
void main(){
    int i, *p, a[10];
    p=a;
    for( i=0; i<10; i++)
        scanf("%d", p++);
    for( i=0; i<10; i++){
        printf("%d\n", *p);
        p++;
    }
}
```

错误在于：当执行完输入语句后，`p` 已经指向数组的最后一个元素，执行输出时从 `a[9]` 开始的单元输出十个元素。

使用指针形式访问数组元素，是从指针变量当前所指的位置开始 “向前” 或 “向后” 计算，而不是从当初给指针变量赋的初值开始。

写程序时要特别注意指针变量的当前值，有时由于忽略指针变量的当前值，会使程序产生严重错误，而且这种错误还十分难于查找。

### 数组超界

- 数组超界是指访问不存在的数组元素。比如有如下声明：

  ```c
  int a[10], *aptr;
  ```

  声明数组 `a` 有10个元素，下标分别为0、1、...、9。但是如果要访问 `a[-5]` 或者 `a[10]` 显然是错误的。

- 这种明显的错误任何人都不容易犯。
