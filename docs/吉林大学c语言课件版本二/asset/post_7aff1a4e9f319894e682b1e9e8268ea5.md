## 递归程序执行过程

递归程序执行时，首先开辟新的运行环境，保存现场，进行参数结合，然后执行递归调用。递归调用结束后恢复现场，释放本函数的运行环境，返回上一层。

## 例 8-20

- 从前 n 个自然数 1, 2, 3, ..., n 中取 r 个数作组合，打印全部组合。
- 例如，n=5、r=3，便有如下10种组合。

|   |   |   |   |
|---|---|---|---|
| ① | 1 | 2 | 3 |
| ② | 1 | 2 | 4 |
| ③ | 1 | 2 | 5 |
| ④ | 1 | 3 | 4 |
| ⑤ | 1 | 3 | 5 |
| ⑥ | 1 | 4 | 5 |
| ⑦ | 2 | 3 | 4 |
| ⑧ | 2 | 3 | 5 |
| ⑨ | 2 | 4 | 5 |
| ⑩ | 3 | 4 | 5 |

解本题的一般想法是使用 r 重循环

```
for ( i1 = 1 ; i1 <= n-r+1 ; i1 ++ )
    for ( i2 = i1+1 ; i2 <= n-r+2 ; i2 ++ )
        ...
        ...
    for ( ir = i_{r-1}+1 ; ir <= n ; ir ++ )
        打印( i1 , ... , ir )
```

但是，由于 r 是可变的，所以循环嵌套层数亦是可变的，因此不知道应该用多少个 i 。只好从另一角度上想问题，自然想到递归。

### 从前 n 个自然数 1, 2, 3, ..., n 中取 r 个数作组合的问题可以分解成：

- 1. 先分别取这 n 个数中的一个数 i，只需要在前 n-r+1 个数中取 i；
- 2. 然后从该 i 后边的 n-i 个数中取 r-1 个数作组合 i+1, i+2, ..., n；
- 3. 最后把每组 r-1 个数的组合与前边的 i 合并，从而构成 r 个数的组合。

当然，从 i 后取 r-1 个数作组合的问题还可以用同样的方法来分解。

我们设想，若有一个函数 combination ( s , j ) 能够完成从自然数序列中，取 j 个数作组合 s , s+1 , s+2 , ... , n，则我们的原始问题可以写成函数调用：combination ( 1 , r )，而我们的分析算法则可以写成：

```
for i = 1 TO n-r+1 DO
    combination ( i+1 , r-1 )
```

把该算法抽象化，并考虑递归出口（当 j=1 时，不必再继续递归，只需打印已经形成的组合），得到函数：

```
void combination ( int s, int j ){
    int i ;
    for ( i=s ; i<=n-j+1 ; i++ )
        if ( j>1 )
            combination( i+1 , j-1 );
        else 打印每层递归进入本函数时的 i;
}
```

主程序中说明变量 n、r；输入 n、r 后以语句 combination(1,r) 调用该函数就是我们的分析算法，也就得到前边的 r 重循环程序。该程序无法在第 r 层递归调用时，访问（打印）前边诸层调用时的局部量 i。

显然每层的 i 必须：

- 或者在本层调用时打印；
- 或者用一全局数组变量，每层保存它，最后打印。

用全局数组变量 a 保存每层的 i，最后打印。解该问题的完整程序如下：

```
#include "stdio.h"
#define nn 10
int n, r;
int a[ nn ], k;
void combination( int s, int j ) {
    int i;                 /* △ */
    for ( i=s; i<=n-j+1; i++ ) {
        a[r-j]=i;           /* r-j不能用s */   /* ◇ */
        if ( j>1 )
            combination( i+1 , j-1 ); /* ☆ */
        else {
            for (k=0;k<r;k++)
                printf("%6d", a[k]);
            printf("\n");
        } /* □ */
    } /* $ */
}
int main (void) {          /* ◎ */
    printf("Enter n,r:");
    scanf("%d%d", &n, &r ); /* ◎ */
    combination( 1,r );      /* ※ */
}
```
