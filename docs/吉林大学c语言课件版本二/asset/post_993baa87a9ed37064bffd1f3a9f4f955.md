
## 函数原型的功能

- 满足了 C 标识符先定义后使用的要求
- 并向编译系统提供所调用函数的信息
  - 函数返回类型
  - 函数的参数个数
  - 函数参数特性等信息
- 程序设计风格
  - 最好把所有函数原型集中，放在主函数之前

```c
float x, y;
float f(float, float);
float p(float);
void main() {
    printf("please input x: ");
    scanf("%f", &x);
    y = (p(x) * p(x) + (5 * x)) / (p(x + 5 - sqrt(x)) * p(x + 2));
    printf("y(x)=%8.4f\n", y);
}

float f(float v, float w) {
    return (w + v) / (7 * v);
}

float p(float u) {
    return (f(u * 0.3, x + u) + (u / 2)) / (2 * x);
}
```

## 例4-3 生成伪随机数

### 生成伪随机数公式

$r_k = (\text{multiplier} * r_{k-1} + \text{increment}) \% \text{modulus}$

随机数序列的第 k-1 项

如下给定三个常数值，产生 65536 个随机数

- multiplier = 25173
- increment = 13849
- modulus = $2^{16}$ = 65536

```c
#define multiplier 25173
#define increment 13849
#define modulus 65536
int seed = 0;
int random(void) {
    seed = (multiplier * seed + increment) % modulus;
    return seed;
}
```

seed 是外部变量，在第一次调用该函数前必须给 seed 赋予初始值。

- 模拟掷骰子，函数修改成：

  ```c
  int random(void) {
      seed = (multiplier * seed + increment) % modulus;
      return seed % 6 + 1;
  }
  ```

- 产生 0 与 1 之间的实数型随机数序列，函数修改成：

  ```c
  float random(void) {
      seed = (multiplier * seed + increment) % modulus;
      return (float)seed / modulus;
  }
  ```
