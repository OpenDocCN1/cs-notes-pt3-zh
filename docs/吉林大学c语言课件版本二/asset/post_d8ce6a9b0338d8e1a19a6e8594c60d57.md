## 简单迭代方法使用条件

对于方程 x = f(x)，当任意 x ∈ (a, b)

存在 0 < L < 1，使

\|f'(x)\| ≤ L < 1

则方程 x = f(x) 在 (a, b) 上有唯一的根 x*

且对任意初值 x₀ ∈ (a, b) 时

迭代序列 xₖ₊₁ = f(xₖ) (k = 0, 1, ...) 收敛于 x*

在实际工作中，绝大部分计算都是近似计算，只要要求 X1≈X0 即 |X1 - X0| < ε 使用条件

g(x) = 2x³ + 0.5x² - x + 0.093 = 0

f(x) = 2x³ + 0.5x² + 0.093 = x
