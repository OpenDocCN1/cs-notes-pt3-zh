### 编程序，测定字母偶的出现频率

测定小写字符串中相邻字母偶出现频率。例如，针对 `the cat`，对 `th`、`he`、`ca`、`at` 计数。设有说明：

`int conmat[26][26];`

字母偶 `he` 的出现次数存入下标变量 `conmat['h'-'a']['e'-'a']`。

首先把该问题分解成如下几步：

1. 初始化计数器数组 `conmat`；
2. 统计每个字母偶的出现频率；
3. 输出统计结果。

![](img/e9111c49b068ca3c37fc762f47ecac61_754_0.png)

求精上述 PAD 中的每一个步骤：

初始化数组 `conmat`，显然应该一行一行地初始化；对于每行又应该一个元素一个元素地初始化。

![](img/e9111c49b068ca3c37fc762f47ecac61_755_0.png)

最后考虑输出部分，我们把结果输出成两个 26×13 的表，每个表元素是相应字母偶的出现次数：

|   | a | b | c | d | e | ... | m |
|---|---|---|---|---|---|---|---|
| a |   |   |   |   |   |   |   |
| b |   |   |   |   |   |   |   |
| ... |   |   |   |   |   |   |   |
| z |   |   |   |   |   |   |   |

|   | n | o | p | q | r | ... | z |
|---|---|---|---|---|---|---|---|
| a |   |   |   |   |   |   |   |
| b |   |   |   |   |   |   |   |
| ... |   |   |   |   |   |   |   |
| z |   |   |   |   |   |   |   |

```text
out
    输出 def
    outone('a', 'm')    /* 输出 a..m 部分 */
    outone('n', 'z')    /* 输出 n..z 部分 */
    结束
```

打印一个表（第一个表），显然应该先打印表头再打印下边各行。

![](img/e9111c49b068ca3c37fc762f47ecac61_759_0.png)

打印表头可以求精成先输出一个“*”；再顺序输出各个字符。顺序输出各个字符是一个循环。

```text
outone(beginch, endch)
    输出表头
        输出('*')
        for (c1 = beginch; c1 <= endch; c1++)
            输出(c1)
        输出("\n")
    打印表体
    结束
```

打印表体应该一行一行地打印，每行应该先打印行头，再打印本行各个元素；打印本行各个元素，应该一个元素一个元素地打印，是一个循环。

```text
outone(beginch, endch)
    输出('*')
    for (c1 = beginch; c1 <= endch; c1++)
        输出(c1)
    输出("\n")

    for (c1 = 'a'; c1 <= 'z'; c1++)    /* 打印表体 */
        输出(c1)
        for (c2 = beginch; c2 <= endch; c2++)
            输出(conmat[c1][c2])
        输出("\n")
    结束
```

### 三个齿轮啮合问题

设有三个齿轮互相衔接，求当三个齿轮的某两对齿互相衔接后，到下一次这两对齿再互相衔接，每个齿轮最少各转多少圈。

解：这是求最小公倍数的问题。每个齿轮需转圈数是三个齿轮齿数的最小公倍数除以自己的齿数。

设：

- 三个齿轮的齿数分别为：na、nb、nc；
- 啮合最小圈数分别为：ma、mb、mc；
- 三齿轮齿数的最小公倍数为 k3。
