## 十六进制数翻译

- 编一个函数convert，从终端读入一个十六进制数，把它翻译成十进制。
- 若翻译正确，则convert返回true
- 否则若翻译错误，则convert返回false

## 十六进制数的形式

- AB.1f
- . ef
- 12f
- 12f.

- 若intflag为真，打印整数值（n中保存）
- 否则，打印实数数值（f中保存）
- 打印 “successful!”

```c
    return (ch>='0')&&(ch<='9') ||
           (ch>='A')&&(ch<='F') ||
           (ch>='a')&&(ch<='f') ;
}
```

## 十六进制数字对应的十进制值

```c
int value(char ch){
    if((ch>='0')&&(ch<='9'))
        return (int)ch-'0';
    else
        if((ch>='A')&&(ch<='F'))
            return (int)ch-'A'+10;
        else
            return (int)ch-'a'+10;
}
```
