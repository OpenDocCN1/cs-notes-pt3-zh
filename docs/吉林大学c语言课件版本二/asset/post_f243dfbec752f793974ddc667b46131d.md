## 习题6.36

令整型指针p指向二维数组的第一个元素a[0][0]：

```c
int *p=&a[0][0];
```

函数：`sort(int col,int row,int *p)`

算法流程：

- `i=0;`
- 当 `i<col*row-1` 时重复：
  - 在 `*(p+i) ~ *(p+col*row-1)` 之间找最小元素 `*(p+j)`
    - `j=i;`
    - `k=i+1;`
    - 当 `k<col*row` 时重复：
      - 若 `*(p+k) < *(p+j)`，则 `j=k;`
      - `k++;`
  - 交换 `*(p+i)` 与 `*(p+j)`
  - `i++;`
- 结束

完整代码：

```c
void sort(int col,int row,int *p){
    int i,j,k,r;
    for(i=0;i<col*row-1;i++){
        j=i;
        for(k=i+1;k<col*row;k++)
            if(*(p+k)<*(p+j))
                j=k;
        r=*(p+i);
        *(p+i)=*(p+j);
        *(p+j)=r;
    }
}
```

## 习题7.19

### `char* reverse(char *str)`

算法步骤：

1. 确定tail和head的指针位置：
   - `head = tail = str;`
   - 当 `*tail != '\0'` 时，`tail++;`
   - `tail--;`
2. 交换 `*tail` 和 `*head` 的值：
   - 当 `tail != head` 时：
     - `tmp = *tail;`
     - `*tail = *head;`
     - `*head = tmp;`
     - `head++; tail--;`
3. `return str;`

完整代码：

```c
char* reverse(char str[]){
    char *head,*tail,tmp;
    head=tail=str;
    while(*tail!='\0')
        tail++;
    tail--;
    while(tail>head){
        tmp=*tail;
        *tail=*head;
        *head=tmp;
        tail--; head++;
    }
    return str;
}
```

调用示例：

```c
void main(){
    char sp[]="abcde";
    reverse(sp);
}

void main(){
    char sp[]="abcde";
    char *string=sp;
    reverse(string);
}

void main(){
    char *sp="abcde";
    reverse(sp);
}
```
