# 读数据块

函数原型：

```
int fread(void *buf, int size, int count, FILE *fp);
```

| 返回值 = { 实际读取的字段个数 | 操作成功 |
| EOF | 错误或文件结束 |

功能：

+   - 从fp所指的文件中读取count个字段，
+   - 每个字段为size个字节，把它们送到buf所指的缓冲数组中，
+   - 同时，将读写位置指针向前移动size* count个字节。
+   - 一般来讲，数组buf每个元素的尺寸为size，每个字段正好对应数组buf的一个元素；即读入count个字段送入数组buf的count个元素中。
