+   - 第一层循环确定排第几小的元素

+   - 循环次数 0..n-2，用i标识

+   - a[ 0 ]...a[ i-1 ] 已经排好序

+   - 第二层循环确定a[ i ]...a[ n-1 ]中最小元素a[j]

+   - a[j]是序列的第i小的元素

+   - 在a[ i ]...a[ n-1 ]找最小，j标识所找最小元素的下标

+   - 以a[i]为基准，j=i，令k: i+1...n-1

+   - 若某个a[ k ]<a[ j ] j=k

+   - 交换a[ i ]和a[ j ]的值

+   - a[ 0 ]...a[ i-1 ]、a[ i ] 已经排好序
