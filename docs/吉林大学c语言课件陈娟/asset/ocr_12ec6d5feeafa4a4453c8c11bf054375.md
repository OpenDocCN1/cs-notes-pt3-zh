# # 布尔类型(bool)

# ## bool类型

- false（假）、true（真）

- C中把bool类型看成整数类型分别用0，1表示false 和 true

# ## 运算

!（非） &&（与） ||（或）

| b₁ | b₂ | ! b₁ | b₁ && b₂ | b₁ || b₂ |
|---|---|---|---|---|
| false | false | true | false | false |
| false | true |  | false | true |
| true | false | false | false | true |
| true | true |  | true | true |
