# 例7-5 展示指针与数组间关系

```
void main(){
    int a[5];
    int i ,*p;
    for(i=0;i<5;i++){
        printf("a[%d]= ",i);
        scanf ( "%d",&(a[i]) );
    }
    for(i=0;i<5;i++)
        printf("%2d",a[i]);
    printf("\n");
    for(i=0;i<5;i++)
        printf("%2d",*(a+i));
    printf("\n");
    for(p=a;p<a+5;p++)
        printf("%2d",*p);
    printf("\n");
}
```
