在主程序中可能有如下程序片段：

```
typecardperson card;
int i ;

... ... ... ...
card.name = ...
card.birthdate.year = ...
card.birthdate.month = ...
card.birthdate.day = ...
card.sex = ...
if ( i=search_card(card) )
    printf("exist! the position is %d\n" , i );
else
    printf("not exist!\n" );
```

其中 if 语句的条件表达式 “i=search_card(card)” 以结构体类型变量card的值作实在参数调用函数search_card 。函数内形式参数变量current_card将取得该值，用该值参与进一步运算，进行检索。
