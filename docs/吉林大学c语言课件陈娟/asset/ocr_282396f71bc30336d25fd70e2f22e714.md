按这个想法，移动 64 片金片的问题可以被分解成：

+   1. 把 a 针上 63 片金片，从 a 针移到 c 针上，移动过程中 b 针可用；
+   2. 把 a 针上 一片金片移到 b 针上；
+   3. 把 c 针上 63 片金片，从 c 针移到 b 针上，移动过程中 a 针可用。

设若有一函数
move( n , x , y , z )
能够完成： “把 x 针上的 n 片金片，移动到 y 针上，移动过程中可以利用 z 针。” ，
则上述原始问题可以描述成对 move 的调用：

```
move( 64 , a , b , c )
move( 63 , a , c , b )
move( 63 , c , b , a )
```
