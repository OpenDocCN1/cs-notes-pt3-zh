# # 运算符优先级

| 记号 | 运算符 | 类别 | 结合关系 | 优先级 |
|---|---|---|---|---|
| 标识符、字面常量、(...) | 简单记号 | 基本表达式 | 无 | \multirow{7}{*}{16} |
| a[k] | 下标 | \multirow{6}{*}{后缀} | \multirow{6}{*}{从左到右} | |
| F(...) | 函数调用 | | | |
| . | 直接选择 | | | |
| -> | 间接选择 | | | |
| ++ -- | 自增 自减 | | | |
| (类型名){初始化列表} | 复合字面值 | | | |
