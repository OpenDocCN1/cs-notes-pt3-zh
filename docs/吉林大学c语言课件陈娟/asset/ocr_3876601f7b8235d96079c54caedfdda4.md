# 例8-12 错误应用

| 标识符 k 没有声明 | 标识符 x 在同一作用域中重复声明 |
|---|---|
| int i,j;
int f(void) {
    ... ...
    k=i+j;
} | float f( int x ) {
    int x ;
    ... ...
} |
| 标识符 c 同一作用域中重复声明 | 标识符 index , t2 先使用后声明 |
|---|---|
| #define c 2.0
typedef int t ;
t c,d,e;
... ... | #define c 2.0
t2 y [ index ] ;
typedef t2 float ;
#define index 10 |
