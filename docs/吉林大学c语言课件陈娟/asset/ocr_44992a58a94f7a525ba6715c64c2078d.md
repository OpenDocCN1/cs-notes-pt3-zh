```
int *iptr1, *iptr2;
char * cptr;
int x , y;
char ch = 'a';
```

在此基础上，有操作：

```
iptr1 = &x;
iptr2 = &y;
cptr = &ch;
x = 5;
y = 8;
```

如果再执行
iptr1=iptr2;

| 变量 | 地址 | 内存单元 |
|---|---|---|
| char型变量 ch | E9A0 | 'a' |
| int型变量 y | E99E | 8 |
| int型变量 x | E99C | 5 |
| 指针cptr | E998 | E9A0 |
| 指针iptr2 | E994 | E99E |
| 指针iptr1 | E990 | E99E |
