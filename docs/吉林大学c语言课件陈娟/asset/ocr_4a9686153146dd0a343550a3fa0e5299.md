# “二维数组a”，“指针数组 pa”和“指针p”之间关系图

![](bbox=[0.17, 0.12, 0.88, 0.52])

```
for( i=0; i<3; i++)
    printf("%d%d%d\n"
        , a[i][2+i], *(a[i]), *(*(a+i)+i) );
for( i=0; i<4; i++)
    printf("%d %d \n"
        ,*(pa[i]) , p[i] );
}
```
