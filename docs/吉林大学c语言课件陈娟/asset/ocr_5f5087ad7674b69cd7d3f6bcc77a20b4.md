# 例8-16 n 次勒让德多项式

pₙ(x) = { 1 当 n = 0
x 当 n = 1
((2n-1)x pₙ₋₁(x) - (n-1) pₙ₋₂(x))/n 当 n > 1 }

```
float r(int n,float x){
    if(n==0) return 1;
    if(n==1) return x;
    float f0=1,f1=x,f=f1;
    while(n>1){
        f=((2*n-1)*x*f1-(n-1)*f0)/n;
        f0=f1;
        f1=f;
        n--;
    }
    return f;
}
```
