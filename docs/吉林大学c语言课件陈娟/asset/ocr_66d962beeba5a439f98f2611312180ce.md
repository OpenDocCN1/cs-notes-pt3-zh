```
(1) char str[20]="I am a teacher";

```

```
(2) char str0[20], str[20]="I am a teacher";
str0=str;
// 错误，给指针常量赋值，数组不能整体赋值
```

```
(3) char str[20];
str="I am a teacher";
// 错误，给指针常量赋值，数组不能整体赋值
```

```
(4) char str[20];
str[]="I am a teacher";
// 错误，给指针常量赋值；
```
