# 例3-3 修改例3-2使之适用于任意长、宽、面积；并产生一个较好的输出格式。

```
#include "stdio.h"
#include "math.h"
void main(){
float x1,x2,b,d;
float length, width,area;
printf("please input length,width,area:\n");
scanf("%f%f%f",&length,&width,&area);
b = -2.0*(length+width);
d = sqrt(b*b-4.0*4.0*area);
x1=(-b+d)/(2*4);
x2=(-b-d)/(2*4);
printf("x1=%.1f x2=%.1f \n",x1,x2);
}
```
