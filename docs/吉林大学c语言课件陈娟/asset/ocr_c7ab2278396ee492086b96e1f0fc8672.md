# 例8-5 给定数组中的n个整数反序存放

```
void inv(int x[],int n){
    int temp,i,j;
    for(i=0;
        i<=(n-1)/2; i++){
        j=n-1-i;
        temp=x[i];
        x[i]=x[j];
        x[j]=temp;
    }
}
```

```
void main(){
    int a[10];
    inv(a,10);
}
void main(){
    int a[10];
    int *ptr=a;
    inv(ptr,10);
}
```
