# C参数传递规则

```
int u,v;

void p( int x , int y) {
    y = x+y;
    printf("%d %d\n”, x,y );
}

void main(void) {
    u = 3;
    v = 4;
    p( u , v );
    printf("%d %d\n”, u , v);
    p( 6, u+v );
    printf("%d %d %d\n”,
           u, v, u+v);
}
```
