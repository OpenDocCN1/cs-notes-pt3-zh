# 设有如下声明和运算：

```
int a[10], *ptr, v, *q, u;
v=5;
ptr = &(a[v]);
a[4]=40;
a[5]=50;
a[6]=60;
```

# 讨论如下运算的意义

+   ① ptr++
+   ② *(ptr++)
+   ③ (*ptr)++
+   ④ *ptr++
+   ⑤ ++ptr
+   ⑥ *(++ptr)
+   ⑦ *++ptr

⑥ 按刚才的叙述，“++ptr”的值是 a[6] 的地址，则

⑦ 由于运算符 “*” 和 “++” 优先级相同，结合方向是从右向左，因此该表达式相当于
    *(++ptr)

有关的运算与刚才讲述完全一致，最后 u 的值为 60。
