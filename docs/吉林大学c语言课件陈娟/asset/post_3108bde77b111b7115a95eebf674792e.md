## 求两数最大公因数

- 编程，输入两个正整数u 、v ，用欧几里德辗转相除法求它们的最大公因数并输出
- 欧几里德辗转相除法
  - u % v → R₁
  - v % R₁ → R₂
  - R₁ % R₂ → R₃
  - R₂ % R₃ → R₄
  - … … …
  - R_{n-1} % R_n → R_{n+1}=0
  - R_n 为正整数u 、v的最大公因数

## "百钱百鸡" 问题

- - 鸡翁一，值钱五；鸡母一，值钱三；鸡雏三，值钱一
- - 百钱买百鸡；问鸡翁、母、雏各几何
- - 设买x只公鸡，买y只母鸡，买z只鸡雏

-5x + 3y + z/3 = 100    /* 百钱 */
- x + y + z = 100    /* 百鸡 */

 x++)
```

x,y,z

结束
