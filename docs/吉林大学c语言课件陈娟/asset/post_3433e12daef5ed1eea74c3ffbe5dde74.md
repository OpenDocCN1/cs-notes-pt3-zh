
- 下标表达式实际是一个变量。
- 它是相应数组成分类型的一个变量。
- 程序中，下标表达式的地位、作用与相应数组成分类型的一般变量的地位、作用完全相同。
- 即凡是可使用数组成分类型变量的地方都可以使用下标表达式，有时也称下标表达式为“下标变量”。

## 需要注意的问题

### 运算

C 没有定义施于数组类型上的运算。数组类型的运算都是通过其成分实现。

例子：求整型数组 `t0`、`t1` 的差送入整型数组 `w` 中，应如下：

```c
for (m = 0; m <= 9; m++)
    w[m] = t0[m] - t1[m];
```

而不能写成：

```c
w = t0 - t1;
```

## 多维数组

### 二维数组声明符形式

`<标识符>[<赋值表达式>][<赋值表达式>]`

例子：`float a[10][5];`

### 多维数组声明符形式

数组标识符 `[赋值表达式1] ... [赋值表达式n]`

### 下标表达式形式

数组变量 `[表达式1][表达式2] ... [表达式k]`

```c
int a[2][2][2];
```

声明 `a` 是一个 3 维数组。它的成分类型是 `int` 型。

- 第维有 3 个成分
- 第二维有 3 个成分
- 第三维有 3 个成分

下标表达式：

- `a[0][1][1]` 是 `a` 的一个下标变量，类型是 `int` 型。

按语法，下标表达式中的表达式可写若干，则下标表达式：

- `a[0][1]` 类型是一个一维数组。
- `a[0]` 类型是一个二维数组。

## 例6-1 求两向量内积

设有向量 \(a_n\)、\(b_n\)，则其内积为：

\[
\sum_{i=0}^{n-1} a_i \cdot b_i
\]

![](img/2c9b154d61523ac3dc02daf316966b8e_453_0.png)

### 程序片断

```c
#define n 100
float a[n], b[n];

float innerproduct(void) {
    float e;
    int i;
    e = 0;
    for (i = 0; i < n; i++)
        e = e + a[i] * b[i];
    return e;
}
```

## 例6-2 求两矩阵乘积

设有矩阵 \(A_{mp}\)、\(B_{pn}\)，则其乘积矩阵 \(C_{mn}\) 的元素 \(C_{ij}\) 为：

\[
\sum_{k=0}^{p-1} A_{ik} \cdot B_{kj}
\]

若矩阵 A、B 分别放在二维数组 `a`、`b` 中，则求乘积矩阵 `c` 的算法如下：

```c
for (i = 0; i < m; i++)
    for (j = 0; j < n; j++) {
        e = 0;
        for (k = 0; k < p; k++)
            e = e + a[i][k] * b[k][j];
        c[i][j] = e;
    }
```

### 程序片段如下

```c
#define m 10
#define n 20
#define p 30
float a[m][p], b[p][n], c[m][n];

void matrixproduct(void) {
    float e;
    int i, j, k;
    for (i = 0; i < m; i++)
        for (j = 0; j < n; j++) {
            e = 0;
            for (k = 0; k < p; k++)
                e = e + a[i][k] * b[k][j];
            c[i][j] = e;
        }
}
```

\[
C_n^m = \frac{n!}{m!(n-m)!}

利用杨辉三角形的特性：


## 打印杨辉三角形

```c
for (i = 0; i < 10; i++) {
    for (j = 1; j < i; j++)
        a[j] = b[j - 1] + b[j];
    a[i] = 1;

    for (j = 0; j <= i; j++)
        b[j] = a[j];

    for (j = 0; j <= 40 - i * (wideword / 2); j++)
        printf("%c", ' ');

    for (j = 0; j <= i; j++)
        printf("%8d", a[j]);

    printf("\n");
}
```

假设把第 0 行的 1 输出在屏幕的第 40 列。各行数据中每个数占 8 位；第 i 行应从 \(40 - i \times 4\) 处开始显示。

![](img/2c9b154d61523ac3dc02daf316966b8e_461_0.png)

```c
#define n 10
#define wideword 8

void main() {
    int a[11], b[11], i, j;
    for (i = 0; i < n; i++) {
        for (j = 1; j < i; j++)        // 生成第 i 行 ①
            a[j] = b[j - 1] + b[j];
        a[i] = 1;
        for (j = 0; j <= i; j++)       // 形成下一次的第 i 行 ②
            b[j] = a[j];
        for (j = 0; j <= 40 - i * (wideword / 2); j++) // 打印第 i 行 ③
            printf("%c", ' ');
        for (j = 0; j <= i; j++)       // ④
            printf("%8d", a[j]);
        printf("\n");
    }
}
```
