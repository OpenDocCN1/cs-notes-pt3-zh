
## 例5.8 简单迭代法

等价变换

g(x) = 0 ↔ x = f(x)

采用迭代法方法求解x=f(x)方程的根

- ① 选定一个 x 的初值 x0；
- ② 以 x0 代入右端计算出一个值 x1=f(x0)
- ③ 若 x1 等于 x0，显然 x0 为根，转向 5
- ④ 否则若 x1≠x0 则令 x0=x1，转向 2
- ⑤ 结束，停止计算

## ■ 简单迭代方法使用条件

对于方程x=f(x)，当任意x∈(a, b)
存在0< L< 1， 使
|f'(x)|≤L<1
则方程x = f(x)在(a, b)上有唯一的根x*
且对任意初始值x0∈ (a, b)时
迭代序列xk+1=f (xk) (k = 0, 1, ...)收敛于x*

- ■ 在实际工作中，决大部分计算都是近似计算， 只要求 X1≈X0 即 |X1 - X0| <ε使用条件

g(x)=2x³+0.5x² -x+0.093=0

f(x)=2x³+0.5x²+0.093=x

开始

X1 = f(X0)

X0 = X1

X0≈X1

结束

X1 = 初值

do-while |X1-X0|>ε

结束

X0 = X1

X1 = f(X0)

```
#include "stdio.h"
#include "math.h"
#define eps 1e-6
void main(){
    float x0,x1;
    x0=0.0;
    x1=0.0;
    do{
        x0=x1;
        x1=2*x0*x0*x0 +0.5*x0*x0 +0.093;
    }while(fabs(x1-x0)>eps);
    printf("x=%f\n",x0);
}
