## 简单迭代法解方程

- 编程，解方程 2X³+0.5X²-X+0.093=0
- 变换X = 2X³ + 0.5X² + 0.093
- 若某个 X 代入右端后，计算结果正好是 X ，则这个 X 值就是方程的根

### 简单迭代法

### 等价变换

g(x) = 0 ⇄ x = f(x)

采用迭代法方法求解x=f(x)方程的根

1. 选定一个 x的初值 x0 ;
2. 以 x0 代入右端计算出一个值 x1=f(x0)
3. 若 x1 等于 x0 ，显然 x0 为根，转向 5
4. 否则若 x1≠x0 则令 x0=x1 ，转向 2
5. 结束，停止计算

### 简单迭代方法使用条件

对于方程x=f(x)，当任意x∈(a, b)
存在0< L< 1， 使
|f'(x)|≤L<1
则方程x = f(x)在(a, b)上有唯一的根x*
且对任意初始值x0∈ (a, b)时
迭代序列xk+1=f (xk) (k = 0, 1, ...)收敛于x*

■ 在实际工作中，绝大部分计算都是近似计算， 只要求 X1≈X0 即 |X1 - X0| <ε使用条件

![](img/2c9b154d61523ac3dc02daf316966b8e_249_0.png)

### 运行结果演示

```c
#include "stdio.h"
#include "math.h"
#define eps 1e-6
void main(){
    float x0,x1;
    x0=0.0;
    x1=0.0;
    do{
        x0=x1;
        x1=2*x0*x0*x0 +0.5*x0*x0 +0.093;
    }while(fabs(x1-x0)>eps);
    printf("x=%f\n",x0);
}
```

## 编程序，按公式求自然对数底 e 的近似值

$$e = 1 + \sum_{i=1}^{\infty} \frac{1}{i!}$$

$$r = \frac{1}{n!} < \varepsilon$$

$$r_n = r_{n-1} * \frac{1}{n}$$

## 编程序，统计以100为结束符的整数输入流中 -1、0、+1 的出现次数并输出

开始

```
i=0; j=0; k=0;
```

```
输入一个数 → num
```

```
while num != 100
```

```
输出 i,j,k
```

结束

```
num
-1
i++
0
j++
1
k++
输入一个数 → num
```

### 运行结果演示

```c
#include <stdio.h>
#define n 100
void main(void){
    int i , j , k , num ;
    i=0; j=0; k=0;
    printf("please input a integer :");
    scanf("%d",&num );
    while ( num != n ){
        switch(num) {
            case -1 : i++; break;
            case 0 : j++; break;
            case 1 : k++;
        }
        printf("please input a integer :");
        scanf("%d",&num );
    }
    printf("number of -1 : %d\n" , i );
    printf("number of 0 : %d\n" , j );
    printf("number of 1 : %d\n" , k );
}
```
