```cpp
template <typename T>
class Stack{
public:
    void push(T);
    T pop();
private:
    T *head;
};
```
```

这个类的类型是Stack<T>，其中T是模板参数。因此，当在声明中需要使用该类的类型时，你必须使用Stack<T>。例如，如果你要声明自己实现的拷贝构造函数和赋值运算符，那么应该这样编写：

```
```cpp
template <typename T>
class Stack {
//....
};
Stack<T>::Stack (Stack<T> const&);    //拷贝构造函数
Stack<T>& Stack<T>::operator= (Stack<T> const&); //赋值运算符
...
```
```

当使用类名而不是类的类型时，就应该只用Stack；譬如，当你指定类的名称、类的构造函数、析构函数时，就应该使用Stack。
