# 运算符重载

```
class aa{
    float a;  float b;
public:
    float &aaa(){return(a);}
    float &bbb(){return(b);}
    friend aa operator +(aa&,aa&,aa&);
};
```

```
aa operator +(aa & a,aa & b,aa & c)
{aa d;
    d.a=a.a+b.a+c.a;
    d.b=a.b+b.b+c.b;
    return(c);}
```

```
void main()
{ aa a,b;
    a.aaa()=1; a.bbb()=2;
    b.aaa()=3; b.bbb()=4;
    aa c=operator +(a,b,a);
    cout<<c.aaa()<<endl<<c.bbb();}
```

运算符重载时参数个数不可以超过原来数目
