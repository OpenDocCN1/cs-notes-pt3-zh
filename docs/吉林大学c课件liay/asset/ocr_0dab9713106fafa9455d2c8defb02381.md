# 模板的参数是非类型参数（表达式形参）

```
template <class T, int i>
int find(T a[],T k)
{
    for(int j=0;j<i;j++)
        if(a[j]==k)
            return(j);
    return(-1);
}
void main(){
int a[10]={0};
cout<<find<int,10>(a,1);
}
```

非类型参数

模板非类型参数:则形参的类型是某种具体的数据类型。

模板非类型参数表示该参数名代表了一个潜在的值,而该值代表了模板定义中的一个常量。

模板非类型参数被用作一个常量值出现在模板定义的余下部分。
它可以用在要求常量的地方，如数组声明中指定数组的大小或作为枚举常量的初始值。
