# //对象数组

```
class Student{
public:
    Student()
    { cin>>value;}
    ~Student()
    { cout<<value<<endl;}
protected:
    int value;
};
int main()
{
    Student *p=new Student[5];
    cout<<"Delete Begin"<<endl;
    delete [] p;
    return 0;
}
```

![](bbox=[0.68, 0.02, 0.99, 0.42])

对象数组不能通过参数传递初始化。要么默认构造函数，要么构造函数有默认参数。

```
Student a[10](20);
```
