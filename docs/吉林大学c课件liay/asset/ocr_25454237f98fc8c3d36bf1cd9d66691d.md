# 标准I/O:

C++不仅定义有现成的I/O类库供用户使用，而且还为了用户进行标准I/O操作,在iostream（输入、输出类的头文件）中定义了四个全局对象，它们分别是cin,cout,cerr和clog。

```
ostream cout;
    标准输出流    默认屏幕 //可以重定向
```

```
istream cin;
    标准输入流    默认键盘
```

```
ostream cerr;
标准错误流    默认屏幕 //不能重定向，不经过缓冲区
```

```
ostream clog;
标准错误流    默认屏幕（与cerr唯一区别就是经过缓冲区）
```
