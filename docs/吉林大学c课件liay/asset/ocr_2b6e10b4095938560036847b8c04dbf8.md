# 构造、析构函数

```
//构造函数重载
class Student{
public:
Student(string pName) {
    cout <<"姓名" <<pName <<endl;
    name = pName; }
Student(string pName,int i) {
    cout<<"姓名学时"<<endl;
    name = pName;   semesHours=i; }
Student(){}
protected:
string name; int semesHours;
};
void main(){
Student tt("Tom",60); Student ss("Jenny");
Student f;   } //不错
```

自定义无参构造函数将替代缺省构造函数的存在
