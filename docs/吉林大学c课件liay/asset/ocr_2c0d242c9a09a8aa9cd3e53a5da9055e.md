# 第五章：构造、析构函数

```
class Student{
    public:
        void p(void);
        float score;
    protected:
        char *name;
        int age;
};
Student a;
Student a={5.5,"abcds",6};
a.age=6;(相当于)
```

```
class Student{
    public:
        void p(void);
        float score=5.5;
    protected:
        char *name="abcds";
        int age=6;
};
```
