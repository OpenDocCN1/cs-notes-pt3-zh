# 双向关联

# 例

```
```cpp
class Female;
class Male{
public:
Female* &getWife() {return pWife;}
//其它方法及实现，略。
private:
Female* pWife;
};
```
```

# 题

```
```cpp
class Female {
public:
Male* &getHusband() { return pHusband; }
//其它方法及实现，略。
private:
Male* pHusband;
};
```
```

```
```cpp
Female a,c, Male b,d; a.getHusband()=&b; b.getWife()=&a;
```
