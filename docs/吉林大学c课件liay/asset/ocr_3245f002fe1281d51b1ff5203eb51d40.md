# 运算符重载

```
class aa{
    float a;  float b;
    public:
        float &aaa(){return(a);}
        float &bbb(){return(b);}
        aa operator +(aa& b)
        {aa c;
        c.a=this->a+b.a;  c.b=this->b+b.b;
        return(c);
        }
};
void main()
{  aa a,b;
    a.aaa()=1; a.bbb()=2;
    b.aaa()=3; b.bbb()=4;
    aa c=a+b;    //c=a.operator+(b)
    cout<<c.aaa()<<endl<<c.bbb();
}
```

运算符重载函数为成员函数
