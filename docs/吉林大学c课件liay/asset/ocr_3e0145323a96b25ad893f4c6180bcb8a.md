# 类名与其它变量名或函数名相同的情况

类名允许与其它变量名或函数名相同，通过如下方法来正确访问：

+   1) 如果一个非类名隐藏了类名，则类名通过加前缀即可。

```
class Sample
{/.....};
void fun(int Sample)
{
class Sample s; //定义一个对象要加前缀
Sample++;
//...
}
```

+   2) 如果一个类名隐藏了非类名，则用一般作用域规则即可。

```
int s=0;
void func()
{
class s{...};
s a;
::s=3;} // class作用域到此结束
int g=s;
```

在函数中定义的类称为局部类，不多见。
作用域在定义该类的函数内。

局部类的成员函数必须在类定义内部定义。
