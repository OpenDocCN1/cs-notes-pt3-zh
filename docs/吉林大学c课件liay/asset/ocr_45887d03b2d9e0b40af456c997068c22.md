# C++中类与结构的区别

```
```cpp
struct Savings
{
public :    //可省略
    float deposit(float amount)
    {
        balance+=amount;
        return balance;
    }

private:
    int accountnumber;
    float balance;
};
```
```

```
```cpp
class Savings
{
private: //可省略
    int accountnumber;
    float balance;

public:
    float deposit(float amount)
    {
        balance+=amount;
        return balance;
    }
};
```
```

# C++中类与结构的区别：

默认情况下，class定义的成员是private的，而struct定义的成员是public的。
