# 构造、析构函数

```
class A{
public:
    A(int k){s=k; cout<<k<<"A is constructing\n";};
    ~A(){cout<<s<<"~A\n";}
    int s;
};
int main(){
cout<<"main is running\n";
A s(1);
void f();
f();
f();
return 0;
}
void f(){
cout<<"f is running\n";
A s(2);
static A t(3);
}
```

局部对象的构造：控制线程每次通过对象的定义时，执行其构造函数。

所有函数之外定义的对象，在main()函数被激活之前初始化。
