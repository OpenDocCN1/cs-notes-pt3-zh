# 第四章： 类

1.从结构到类

结构：相关联的数据元素组成一个单独的统一体

```
struct Savings
{
    unsigned accountnumber; //账号
    float balance;//结算额
};
```

‘；’是必需的

struct Savings a,b;
或者 Savings a,b; 常用形式

结构分量称为成员，使用“.”操作符访问成员

```
void fn()
{
Savings a;
Savings b;
a.accountnumber=1;
b.accountnumber=2;
}
```

粗糙的数据类型，没有涉及复合数据的操作。
