# 构造、析构函数

```
//默认拷贝构造函数
//默认赋值运算符（函数）
class Student{
public:
    Student(int k):i(k){}
    Student (){}
    void p(){cout<<i<<endl;}
protected:
    int i;
}; //一旦显性给出 默认不再提供
```

```
int main()
{
    Student s(9818);
    s.p();
    Student t(s);
    t.p();
    Student m;
    m=t;//赋值
    m.p();
    return 0;
}
```
