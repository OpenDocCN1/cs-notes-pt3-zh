# 继承

```
class Student{
    int move_tel;
public:
    int id;
    string name;
protected:
    int tel;
};

class Master : protected Student{
    string topic;
public:
    string dept;
protected:
    string major;
};

void main()
{
    Master a;
}
```

> 当类的继承方式为保护继承时，基类的公有和保护成员都以保护成员身份出现在派生类中，而基类的私有成员不可访问。

> public: dept
> protected: id, name, tel, major;
> private: topic
> 不可访问：move_tel

> 和public继承相比
> 收缩了对外权限；
> 没有影响对内权限
