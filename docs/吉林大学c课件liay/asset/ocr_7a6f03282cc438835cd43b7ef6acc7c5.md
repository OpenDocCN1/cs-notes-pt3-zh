```
class Student{
public:
    Student();  // 构造函数的声明
    ~Student(); // 析构函数的声明；没有参数；不可以重载
protected:
    char *name;
    int age;
};
Student::Student()
{ age=5; }
Student::~Student()
{ cout<< "对象结束了"; }
int main(){
    Student a;
    Student b;
    return 0;
}//析构函数的调用顺序和对象构造的顺序相反
```

//对象生命周期结束时由系统自动调用

析构函数不是删除对象，而是在撤销对象占用的内存之前完成一些清理工作。还可以用来执行用户希望在对象生命周期结束时所执行的任何操作。
