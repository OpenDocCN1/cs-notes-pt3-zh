# 嵌套类

```
```cpp
class A{
    int a;
public:
    class B{
        int b;
    public:
        B(int i);
    };
    void f(){ pb->b=5;//error
    }
    B* pb;
};
A::B::B(int i):b(i){}//成员可以在体外定义
int main(){
    A a;
    A::B b(10);
}
```
```

在一个类中定义的类称为嵌套类，定义嵌套类的类称为外围类。

定义嵌套类的目的在于隐藏类名，减少全局的标识符，从而限制用户能否使用该类建立对象。这样可以提高类的抽象能力，并且强调了两个类(外围类和嵌套类)之间的主从关系。
