# 运算符重载

```
```cpp
class aa{
    float a;
    float b;
public:
    float &aaa(){return(a);}
    float &bbb(){return(b);}
    friend aa operator +(int&,int&);
};
aa operator +(int a,int & b)
{
    aa c;
    c.a=a+b;
    c.b=a+b;
    return(c);
}
void main()
{
    int i=6,j=7;
    aa c=i+j;
    cout<<c.aaa()<<endl<<c.bbb();
}
```
```

> 运算符重载时 参数类型不能全为基本类型，至少有一个操作对象是自定义类型
