包含：
一般的办法是将（函数、类）模板的整个定义都放在头文件中。

```
```cpp
// List.h
template<typename T>
class List {
public:
    void Set(T);
    T Get();
private:
    T i;
};

template<typename T>
void List<T>::Set(T k){i = k;}

template<typename T>
T List<T>::Get(){return(i);}
```
```

```
```cpp
// main.cpp
#include “List.h”
void main(){
    List<double> k;
    k.Set(1);
    cout<<k.Get()<<endl;
}
```
