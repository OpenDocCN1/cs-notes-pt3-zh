# //组合类对象的初始化困惑

```
class StudentID{
public:
    StudentID(int id=0)
    {  value=id;}
    ~StudentID() {}
protected:
    int value;
};
class Student{
public:
    Student(string pName="noName",int ssID=0)
    {  name = pName;
    }
private:
    string name;
    StudentID id (ssID); //错误
```

```
int main()
{
    Student s("Randy",9818);
    return 0;}
```

> 类成员定义时不允许初始化，因为类仅仅是一个类型，而没有空间分配
