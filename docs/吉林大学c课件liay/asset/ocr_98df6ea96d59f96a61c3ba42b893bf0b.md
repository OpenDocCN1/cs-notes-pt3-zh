//注意多个类型参数情况

//定做其中一部分类型参数为确定的类型，称为局部定做

```
template <typename T1,typename T2>
class A
{......};
```

```
template <typename T>
class A<T,T>{....};  //仍为类模板
```

```
template <typename T>
class A<T,Cat>
{......};
```

使用时：

```
A<int,Cat> aa1;
```

```
A<int,int> aa2;
```

```
A<Cat,Cat> aa3; //error
```
