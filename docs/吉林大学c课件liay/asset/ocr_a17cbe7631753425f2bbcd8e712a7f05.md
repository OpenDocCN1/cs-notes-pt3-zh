# （3）指向常量的指针常量(常量指针常量)

形式： const int *const p=&a; 定义时必须初始化
p与*p都是常量。他们都不能作为左值进行操作

```
int b[10];
const static int a[10]={0};
int * const p=a;          错误
const int *const p=a;    正确
const int *const q=b;    正确
p++;                     错误
*p=1;                    错误
*(a+2)=2;                错误
*q=5;                    错误
q++;                     错误
b[0]=5;                  正确
```
