# 2. 声明引用：声明引用格式如下：

格式：类型标识符& 别名；

例1：

```
int i=0;
int& ir=i;    //定义引用ir作为对象的别名
ir=2;
int* p=&ir;    //等同于int* p=&i;
```

如果： int j; int &i=j; 则i=j; &i==&j;

声明引用，不为之分配内存空间。

例2：

```
int a[10], *p=a;
int& ra1=a[6];    //ra1代表数组元素a[6]
int* & rp1=p;    //rp1代表指针变量p
int& rp2=*p;    //rp2代表p所指向的那个对象,
                //即数组元素a[0]
```
