# 匹配重载函数的顺序：

+   （1）严格匹配

+   （2）内部转换（相容类型匹配）

+   （3）通过用户定义的转换寻找求一个匹配。

```
void print(int);        void print(long);
void print(double);      void print(double);
void function()          void function()
{
    print(3);             int a;
    print(5.0);           print(a);//有二义性
    print('a');           }
    print(3.1415f);       print(long(a));
                          或者print(double(a));
```
