# 继承

```
class Student{
int move_tel;
public:
int id;
string name;
protected:
int tel;
};
class Master :private Student{
string topic;
public:
string dept;
protected:
string major;
};
void main()
{ Master a;
}
```

和public继承相比 收缩了对外权限； 影响后代对内权限

当类的继承方式为私有继承时，基类的公有和保护成员都以私有成员身份出现在派生类中，而基类的私有成员不可访问。

Public: dept  protected: major;  private:id, name,tel,topic
不可访问： move_tel
