# 异常处理

```
class A{
    char net[20];
public:
    virtual void x(){cout<<"网络错误";}
};
class B:public A{
    long card;
public:
void x(){cout<<"网卡错误";}
};
class C:public B{
    int port;
public:
void x(){cout<<"端口错误";}
};
void net()
{ throw B();}
--------------------------------
void net() throw(A,B,C); //异常申述(异常说明)
void main()
{
    try{net();}
    catch(A & s){s.x();} }
```

如果在函数的声明中没有包括异常接口声明，则此函数可以抛掷任何类型的异常，例如：

```
void net();
```

一个不抛掷任何类型异常的函数可以进行如下形式的声明：

```
void net() throw();
```
