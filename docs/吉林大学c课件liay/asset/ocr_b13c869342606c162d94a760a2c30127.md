# 析构函数

```
class aa {
public:
    aa(){f=new char[10];}
    ~aa(){delete []f;}
    char * f;
};
int main()
{aa p;
strcpy(p.f,"Computer");
cout<<p.f<<endl;
aa q(p);    // aa q=p;
cout<<q.f<<endl;
strcpy(p.f, "Software");
cout<<q.f<<p.f<<endl;
return 0;}
```

创建q时，
对象p被复制给了q，
但资源未复制，
使得p和q指向
同一个资源，
这称为浅拷贝。

同一个指针执行
两遍delete操作，
会发生什么？
灾难，可能会破坏该堆及自由内存表
