```

**重载函数：**

```
```cpp
int abs(int);
long abs(long);
double abs(double);
```
```

C++用一种函数名技术可准确的判断出应使用那一个函数。

```
```cpp
abs(-10);       //调用int abs(int);
abs(-1000000);  //调用long abs(long);
abs(12.3);      //调用double abs(double);
```
