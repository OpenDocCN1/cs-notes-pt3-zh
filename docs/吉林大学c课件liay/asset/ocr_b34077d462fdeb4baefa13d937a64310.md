对象的复制(拷贝)：用一个已知对象构造（初始化）一个新对象。

例：一个对象构造（初始化）另一对象

```
Student s1("Jenny"); Student s2=s1;即Student s2(s1);
```

```
Student fn(Student s){Student k;//...... ;return k}
```

```
void main()
{Student m,n; n=fn(m);}
```

使用Student (char* )不再合适，引入新的构造函数——拷贝构造函数：

```
Student (Student& s);或者是Student ( const Student& s);
```
