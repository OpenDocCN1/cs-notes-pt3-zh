# //构造函数重载

```
class Student{
public:
    Student(string pName)
    { cout <<"姓名" <<pName <<endl;
        name = pName;
    }
    Student(string pName,int i)
    { cout<< "姓名学时"<<endl;
        name = pName;
        semesHours=i;
    }
private:
    string name; int semesHours;
};
int main()
{ Student tt("Tom",60); Student ss("Jenny");
    Student f;    //错误  ?
    return 0;
}
```

如果手工定义了任何的构造函数，系统不再提供默认的无参构造函数。
