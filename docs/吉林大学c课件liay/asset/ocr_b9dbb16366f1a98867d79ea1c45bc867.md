# 继承和组合的关系

去掉继承关系
对象接口不变

```
class B{
public:
    void f() const{}
};
```

```
class D : public B{
public:
    void func() const{ f();}
};
```

```
void F(const B aB) {
    aB.f();
}
```

```
void main() {
    D d;
    d.func();
    F(d); }
```

```
class D {
public:
    void func() const{pb.f();}
    operator B(){return pb;}
private:
    B pb;
};
```

如果两个类设计的操作有很多共同点，用继承会好一些。

组合职责分明，调试方便。
