# 串流类

```
#include <iostream>
#include <strstream>
using namespace std;
void main(){
char a[128];
char c,d;
ostrstream oo(a,128);//关联的是内存的字符数组不需要打开和关闭
oo<<"Computer";
oo.put('\0');//向指定的输出流中插入一个结束字符。
cout<<a;
istrstream ii(a);
ii>>c;
ii.get(d);//从指定的输入流中提取一个字符。
cout<<endl<<c<<d;
}
```
