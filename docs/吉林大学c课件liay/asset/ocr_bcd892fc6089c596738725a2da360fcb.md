# 模板&类

```
template <typename T>
class Stack{
public:
void push( T );
    T pop();
private:
    T *head;
};
```

```
template <typename T>
void Stack<T>::push(T i)
{
    T *p=new T;
    *p = i;
    p->next=head;
    head=p;
}
```

```
template <typename T>
T Stack<T>::pop()
{T p=*head;
T *q=head;
head=head->next;
delete q;
return(p);}
```

//与普通类一样，类模板的成员函数也可以在类模板定义中定义具体实现，这时，该函数是内联的（inline）。
