# 静态成员

//静态数据成员的初始化及使用

```
StudentID.h
class StudentID{
    int value;
public:
    static int ID;
    StudentID();
    ~StudentID();
};
```

```
aa.cpp
#include "StudentID.h"
void main()
{ void xx();
StudentID s,t;//s的对象空间不包括ID
//类的静态数据成员只有一个拷贝
cout<<StudentID::ID;
xx();
cout<<StudentID::ID;
}//公共静态成员，可以被类的外部访问。
```

```
StudentID.cpp
#include "StudentID.h"
int StudentID::ID=0;
//前面没有static，类外初始化
StudentID::StudentID()
{ value=++ID;}
StudentID::~StudentID()
{ --ID;}
```

```
bb.cpp
#include "StudentID.h"
void xx()
{ StudentID::ID++;}
//初始化位置；初始化列表为静态数据成员初始化可不可以？
```
