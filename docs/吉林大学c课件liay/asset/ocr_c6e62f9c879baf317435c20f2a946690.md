# 5.用typedef 来简化函数指针

```
(1)typedef int (*FUN)(int a,int b);
```

```
int f(int,int);
```

```
FUN funp=f;
```

FUN 不是指针变量，是指针类型名。

```
(2)typedef int FUNC(int,int); //先定义函数类型
```

```
FUNC* funp=f;
```

# 6.函数的返回类型可以是函数指针

```
typedef int (*SIG) ();
```

```
typedef void (*SIGARG) ();
```

```
SIG signal (int,SIGARG);
```
