# 6.定义成员函数

（1）在类的内部定义成员函数

```
#include <iostream>
using namespace std;
class Tdate{
public:
void set (int m,int d,int y)
{month=m;day=d;year=y;}
int isleapyear()
{return (year%4==0&&year%100!=0)||(year%400==0);}
void print()
{cout <<month<<"/"<<day<<"/"<<year<<endl;}
private:
int month;
int day;
int year;
```

```
int main(){
Tdate a;
a.set(2,4,1998);
a.print();
if (a.isleapyear())
cout<<"is leapyear!"
else
cout<<"is not leapyear!";
return 0;}
```

Set 与month 全名

::作用域区分符、作用域运算符
