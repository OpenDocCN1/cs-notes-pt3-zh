# 9. 引入虚函数支持多态

```
class Automobile{
public:
//...
virtual void Run(){
    cout<< "机械变速" <<endl;
}
};

class Car:public Automobile{
public:
//...
virtual void Run(){
    cout<< "自动变速" <<endl;
}
};
```

```
void Fn(Automobile *p){
    p->Run();
}

void main(){
    Fn(new Automobile);
    Fn(new Car);
}
```

机械变速
自动变速

派生类中的函数只要原型相同，则自动具有虚函数性质，其virtual关键字可省略
