# 模板&类

//分离（多文件机制）
//例子

```
List.h
template<typename T>
class List {
public:
    void Set(T);
    T Get();
private:
    T i;
};
```

```
List.cpp
include "List.h"
template<typename U>
void List<U>::Set(U k){i = k;}
template<typename T>
T List<T>::Get(){return(i);}
```

```
main.cpp
include "List.h"
void main(){
List<double> k;
k.Set(1);
cout<<k.Get()<<endl;
}
```
