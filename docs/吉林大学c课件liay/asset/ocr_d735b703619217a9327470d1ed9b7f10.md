# 静态成员函数

```
class aa{
    int b;
    int GetB(){return b;}
public:
    static int a;
    void o(){cout<<a;cout<<this->a;cout<<b;}
    static void p(){cout<<a; cout<<this->a;}
    static void q(){cout<<b<<GetB();}
    static void r(aa &t){t.b=6;cout<<t.GetB();}
};
int aa::a=0;
void main()
{
    aa a; aa::p(); aa::q(); aa::r(a); a.o(); }
```

//不允许不指明对象访问非静态数据成员；不允许使用this
