# //运算符重载的格式

```
class aa{
public:
    float &&aaa(){return(a);}
    float &&bbb(){return(b);}
private:
    float a;  float b; };
aa operator +(aa & a,aa& b)
{aa c;
c.aaa()=a.aaa()+b.aaa();
c.bbb()=a.bbb()+b.bbb();
return(c); }
void main()
{ aa a,b;
a.aaa()=1; a.bbb()=2;
b.aaa()=3; b.bbb()=4;
aa c=a+b; //等价aa c=operator +(a,b);
cout<<c.aaa()<<endl<<c.bbb();}
```

使用运算符重载的一般格式为：
类型名 operator 运算符
（形参表）
{函数体}
其中operator是关键字，类型名为重载运算符的返回类型，即运算结果类型。

重载:用户根据自己的需要对C++已提供的运算符进行重载，赋予新的含义。

实现时，首先把指定的运算表达式转化为对运算符函数的调用，这个过程是在编译中完成的。

运算符重载不是必需的，为了编程的人性化描述。
