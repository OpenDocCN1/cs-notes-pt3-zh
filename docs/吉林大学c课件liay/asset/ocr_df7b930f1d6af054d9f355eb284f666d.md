# 二
名字空间

名字空间的作用是建立一些互相分隔的作用域，把一些全局实体分隔开来，避免产生名字冲突。

```
namespace zhs{
class aa {
public:
void aa1(int a=1){id=a;}
int id;
};
int age;
double score;
}
namespace ls{
class aa {
public:
int age;
};
}
```

```
void main(){
ls::aa a;
zhs::score=90.1;
zhs::aa b;
b.aa1(8);
a.age=5;
zhs::age=6;
cout<<a.age<<b.id<<endl;
}
```
