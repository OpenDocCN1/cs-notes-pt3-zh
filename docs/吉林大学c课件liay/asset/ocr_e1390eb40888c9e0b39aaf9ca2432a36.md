# 4.用指针处理数组元素

例：

```
int *p,i,a[6]={0,1,2,3,4,5};
p=a;
for(i=0;i<6;i++)
    printf("%d",_____);
```

a[i] *(a+i) p[i] *(p+i) *p++ *a++

考虑： []的作用 []和*的比较；越界访问 数组名和指针

+   (1)数组名的内涵在于其指代实体是一种数据结构，这种数据结构就是数组；
+   (2)数组名的外延在于其能够转换为指向其指代实体的指针，而且是个指针常量；
+   (3)数组名作为函数形参时，在函数体内，其失去了本身的内涵，仅仅只是个指针；
