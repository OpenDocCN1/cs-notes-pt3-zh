# 运算符重载

```
//重载单目运算符（前自增量）
class aa{
    float a;  float b;
public:
    float &aaa(){return(a);}
    float &bbb(){return(b);}
    aa & operator ++();
};
aa & aa::operator ++()
{ a=a+1; b=b+1; return(*this);}
void main()
{ aa a;
    a.aaa()=1; a.bbb()=2;
    cout<<(++a).aaa()<<endl;
    ++(++a);
    cout<<a.aaa()<<endl;}
```

前自增量运算符应该返回引用
