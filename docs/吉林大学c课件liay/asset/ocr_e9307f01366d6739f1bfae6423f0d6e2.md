# 静态成员

```
//静态数据成员的使用
StudentID.h
class StudentID{
public:
    static int ID;
    StudentID();
    ~StudentID();
protected:
    int value;
};
StudentID.cpp
#include"StudentID.h"
int StudentID::ID=0;
StudentID::StudentID()
{  value=++ID;}
StudentID::~StudentID()
{  --ID;}
```

```
aa.cpp
#include"StudentID.h"
void main()
{void xx();
StudentID s,t;
cout<<s.ID;
cout<<t.ID;
cout<<StudentID::ID;
xx();  //再次执行上三条的效果如何
}
//静态数据成员由这些对象所共享，可被任何一个对象所访问。
```
