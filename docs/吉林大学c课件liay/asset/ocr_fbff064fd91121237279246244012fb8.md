# 运算符重载

//重载单目运算符（后自增量）

```
class aa{
    float a;  float b;
public:
    float &&aaa(){return(a);}
    float &&bbb(){return(b);}
    aa operator ++(int);
};
aa aa::operator ++(int){
    aa m(*this); a=a+1; b=b+1; return(m);
}
void main()
{ aa a;
  a.aaa()=1; a.bbb()=2;
  cout << a++ .aaa() << endl;
  cout<<a.aaa()<<endl; }
```

int形参只是为了区别与前自增量运算符重载函数，除此之外没有任何作用。后自增量运算符必须返回 值
