## 7.成员函数的显式内联

```
class Date {
    int year, month, day;
    void set ( int y, int m, int d ) {    // 默认内联
        year=y; month=m; day=d;
    }
    bool isLeapYear ( );
};
inline bool Date::isLeapYear ( ) // 显式内联
{   return !( year%400 ) || !(year%4) &&( year%100);
}
```
