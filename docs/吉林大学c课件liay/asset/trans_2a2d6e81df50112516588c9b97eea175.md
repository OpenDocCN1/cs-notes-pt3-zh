

## 14. 避免虚函数误用

```cpp
class Base {
public:
    virtual void fn(int x) {
        cout << "in base class,int x=" << x << "\n";
    }
};

class Sub : public Base {
public:
    virtual void fn(double x) {
        cout << "in sub class,int x=" << x << "\n";
    }
};

void test(Base &b) {
    b.fn(2);
    b.fn(3.5);
}

void main() {
    test(Base());
    test(Sub());
    Sub f;
    f.fn(2);
    f.Base::fn(2.5);
}
```

```text
in base class,int x=2
in base class,int x=3
in base class,int x=2
in base class,int x=3
in sub class,int x=2
in base class,int x=2
```

## 多态注意事项

- 非成员、静态成员、内联函数不能是虚函数
- 构造函数、赋值运算符函数不能是虚函数
- 析构函数经常定义成虚函数 `delete p;`

## 15. 关于析构函数

```cpp
class A {
    char *p;

public:
    A() {
        p = new char[5];
    }
    virtual ~A() {
        delete[] p;
    }
};

class B : public A {
    char *q;

public:
    B() {
        q = new char[500];
    }
    ~B() {
        delete[] q;
    }
};

void f() {
    A *p;
    p = new B;
    delete p;
}

void main() {
    f();
    f();
    ... ...
}
```

析构函数为虚函数时，编译器进行运行绑定。析构函数的调用沿着继承树自下而上。

## 抽象类

纯虚函数：在基类中只声明虚函数而不给出具体的函数定义体，称此虚函数为纯虚函数。

纯虚函数的声明如下（注：要放在基类的定义体中）：

```cpp
virtual 函数原型 = 0;
```

声明了纯虚函数的类，称为抽象类（抽象基类）。

通过该基类的指针或引用就可以调用所有派生类的虚函数，基类的纯虚函数只是用于继承，仅作为一个接口，具体功能在派生类中实现。

## 继承 · 抽象类

```cpp
class Student {
public:
    Student(int i) {
        id = i;
    }
    virtual void p() = 0;
    int id;
};

class Master : public Student {
public:
    Master(char *p, int k) : Student(k) {
        dept = p;
    }
    virtual void p() {
        cout << "Master";
    }
    string dept;
};

class Mba : public Student {
public:
    Mba(char *p, int k) : Student(k) {
        position = p;
    }
    virtual void p() {
        cout << "Mba";
    }
    string position;
};

void main() {
    Master a("Software", 123);
    Mba b("商学院", 456);
    Student *m = &a;
    m->p();
    m = &b;
    m->p();
}
```

### 纯虚函数

如果没有纯虚函数则错误。因为 C++ 必须确认该类拥有该同名函数，才可以访问对应对象。

```cpp
class Student {
public:
    Student(int i) {
        id = i;
    }
    virtual int p() = 0;
    int id;
};

class Master : public Student {
public:
    Master(char *p, int k) : Student(k) {
        dept = p;
    }
    virtual int p() {
        cout << "Master";
    }
    string dept;
};

class Mba : public Student {
public:
    Mba(char *p, int k) : Student(k) {
        position = p;
    }
    virtual int p() {
        cout << "Mba";
    }
    string position;
};

void main() {
    Student t(9);                             //错误
    Student *p = new Master("Software", 9);   //正确
    Student &q = *p;                           //正确
}
//抽象类不可以实例化对象，但是可以定义指针和引用
//无意义的基类对象；基类设下纯虚函数，是为子类的多态行为留了一条口子。
