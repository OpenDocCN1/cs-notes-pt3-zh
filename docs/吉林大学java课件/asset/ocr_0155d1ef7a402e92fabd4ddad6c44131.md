# Socket通信 ——支持多Client

```
serverSocket = new ServerSocket(4444);
while (listening)
{
    Socket socket;
    socket = serverSocket.accept(); //程序将在此等候客户端的连接
    new MultiTalkServerThread(socket).start();
}
serverSocket.close();
```
