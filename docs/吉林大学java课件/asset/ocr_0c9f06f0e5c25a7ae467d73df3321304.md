# 一点扩展

假如日后报警门增加发短信的功能怎么办？

```
abstract class Door {
    abstract void open();
    abstract void close();
}
```

```
interface Alarm {
    void alarm();
}
```

```
interface SendMessage{
    void send();
}
```

```
class FunctionDoor extends Door implements Alarm,SendMessage {
    void open() { ... }
    void close() { ... }
    void alarm() { ... }
    void send(){...}
}
```
