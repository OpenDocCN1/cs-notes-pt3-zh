# 验证选择结构

```
public class IfDemo {
    public static void main(String[] args) {
        int x = 3;                  // 定义整型变量x
        int y = 10;                 // 定义整型变量y
        System.out.println("===== 比较开始 ====="); // 输出信息
        if (x > y) {                // 判断x是否比y大
            System.out.println("x比y大！");     // 输出信息
        }
        if (x < y) {                // 判断x是否比y小
            System.out.println("x比y小！");     // 输出信息
        }
        System.out.println("===== 比较完成 ====="); // 输出信息
    }
}
```
