# 新的实现

```
```java
public class Door implements Executable {
    private boolean _isOpen = false;
    public boolean isOpen() {
        return _isOpen;
    }
    public void open() {
        _isOpen = true;
    }
    public void close() {
        _isOpen = false;
    }
}
```

```java
public class Hand {
    public Executable item;
    void do() {
        if (item.isOpen())
            item.close();
        else
            item.open();
    }
}
