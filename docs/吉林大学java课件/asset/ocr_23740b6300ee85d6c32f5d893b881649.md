# 接口默认方法使用的几种情况

规则三：否则，直接调用指定接口的实现方法

```
interface A {
    default void doSth() {
        System.out.println("inside A");
    }
}
interface B {
    default void doSth() {
        System.out.println("inside B");
    }
}
class App implements B, A {

    public void doSth() {
        B.super.doSth();
    }

    public static void main(String[] args) {
        new App().doSth();
    }
}
```

运行结果： inside B
