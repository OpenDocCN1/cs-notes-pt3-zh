# 在删除文件中增加判断

```
package org.lxh.demo12.filedemo;
import java.io.File;
public class FileDemo05 {
    public static void main(String args[]) {
        File f = new File("d:"+File.separator+"test.txt") ; // 必须给出路径
        if(f.exists()){
            // 判断文件是否存在
            f.delete() ;
            // 如果存在，则删除文件
        }
    }
}
```
