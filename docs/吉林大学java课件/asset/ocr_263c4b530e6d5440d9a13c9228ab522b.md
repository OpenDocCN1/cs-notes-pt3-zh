# 取得数组长度

要特别注意的是，在Java中取得数组的长度（也就是数组元素的长度）可以利用“数组名称.length”完成，如下面的格式；

+   数组名称.length → 返回一个int型数据

```
public class ArrayDemo03 {
    public static void main(String[] args) {
        int score[] = new int[3];
        // 声明并实例化数组
        System.out.println("数组长度为" + score.length);    // 求出数组长度
    }
}
```
