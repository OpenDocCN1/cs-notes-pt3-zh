# 定义一个泛型方法

```
```java
// 可以接收任意类型的数
class Demo{
	public <T> T fun(T t){
		return t ;
	}
}

public class GenericsDemo26 {
	public static void main(String args[]){
		Demo d = new Demo() ;
		String str = d.fun("李兴华") ; // 传递字符串
		int i = d.fun(30) ; // 传递数字，自动装箱
		System.out.println(str) ; // 输出内容
		System.out.println(i) ; // 输出内容
	}
}
