# 例子

```
package com.oo.java;
/**
 * 普通人
 */
public class Person {
    private String _name; //姓名
    private Integer _money; //金钱
    public String getName() {
        return _name;
    }
    public Boolean pay(Integer money){
        //付款的逻辑由Person自己控制，例如判断当前的钱是否够支付
        if( money > _money){
            return false;
        }
        _money -= money;
        return true;
    }
}
```
