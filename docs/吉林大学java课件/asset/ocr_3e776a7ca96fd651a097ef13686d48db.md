# 测试字符和整型之间的相互转换

```
public class DataDemo04 {
    public static void main(String[] args) {
        char ch1 = 'a';                // 定义字符
        char ch2 = 97;                 // 定义字符，整型转字符
        System.out.println("ch1 = " + ch1);    // 打印输出
        System.out.println("ch2 = " + ch2);    // 打印输出
    }
}
```
