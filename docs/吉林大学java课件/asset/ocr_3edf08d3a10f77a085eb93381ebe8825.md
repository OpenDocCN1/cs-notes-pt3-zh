# 类String--用来处理不变的字符串常量

A、直接赋值

```
public class StringDemo01 {
    public static void main(String[] args) {
        String name = "LiXingHua";
        System.out.println("姓名: " + name);
    }
}
```

B、通过关键字new

```
public class StringDemo02 {
    public static void main(String[] args) {
        String name = new String("LiXingHua");
        System.out.println("姓名: " + name);
    }
}
```
