# 将整型的最大值加1和加2

```
```java
class DataDemo02 {
	public static void main(String[] args) {
		int max = Integer.MAX_VALUE;
		// 得到整型的最大值
		System.out.println("整型的最大值: " + max);
		// 输出最大值
		System.out.println("整型最大值 + 1:" + (max + 1));
		// 最大值加1
		System.out.println("整型最大值 + 2:" + (max + 2));
		// 最大值加2
	}
}
