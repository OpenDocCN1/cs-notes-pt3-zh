# 一点扩展

假如日后你家的车也需要报警功能怎么办？

```
abstract class Car {
  abstract void slowdown();
  abstract void speedup();
}
```

```
interface Alarm {
  void alarm();
}
```

```
class AlarmCar extends Car implements Alarm {
  void slowdown() { ... }
  void speedup() { ... }
  void alarm() { ... }
}
```

> AlarmCar, AlarmDoor 属于不相关的类，使用接口Alarm实现了它们的相同行为，但是是不用考虑它们的层次关系。
