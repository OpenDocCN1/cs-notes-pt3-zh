# 二维数组静态初始化

+   格式：
+   数据类型 数组名[][] = { {第0行初值},{第1行初值}, ...{第n行初值},};

+   声明二维数组：
+   int score[][] = { { 67, 61 }, { 78, 89, 83 }, { 99, 100, 98, 66, 95 } };

```
int score[][] = {
{ 67, 61 }, { 78, 89, 83 },
{ 99, 100, 98, 66, 95 }};
```

| 行\列 | 0 | 1 | 2 | 3 | 4 |
|---|---|---|---|---|---|
| 0 | 67 | 61 |  |  |  |
| 1 | 78 | 89 | 83 |  |  |
| 2 | 99 | 100 | 98 | 66 | 95 |
