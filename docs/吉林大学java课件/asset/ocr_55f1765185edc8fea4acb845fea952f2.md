# 定义一个抽象类

```
abstract class A{
    public static final String FLAG = "CHINA" ;
    private String name = "李兴华" ;
    public String getName() {
        return name;
    }
    public void setName(String name) {
        this.name = name;
    }
    public abstract void print() ;
}
// 设置姓名
// 取得姓名
// 定义抽象方法
```
