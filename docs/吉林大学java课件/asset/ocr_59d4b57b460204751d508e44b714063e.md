# 接口默认方法使用的几种情况

规则一： 定义在类中的方法优先于定义在接口的方法

```
```java
interface A {
	default void doSth(){
		System.out.println("inside A");
	}
}

class App implements A{
	public void doSth() {
		System.out.println("inside App");
	}
}

public static void main(String[] args) {
	new App().doSth();
}
```
```

运行结果： inside App。调用的是在类中定义的方法。
