# 存在return的try-catch-finally块

```
public void method(){
    try {
        // 代码段 1
        // 产生异常的代码段 2
    } catch (异常类型 ex) {
        // 对异常进行处理的代码段3
        return;
    } finally {
        // 代码段 4
    }
}
```
