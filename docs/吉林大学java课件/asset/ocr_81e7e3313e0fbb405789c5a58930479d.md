# 使用for循环完成累加操作

```
public class ForDemo {
    public static void main(String[] args) {        // 定义变量保存累加结果
        int sum = 0;                            // 定义变量保存累加结果
        for (int x = 1; x <= 10; x++) {         // 使用for循环
            sum += x;                           // 执行累加操作
        }
        System.out.println("1-->10累加结果为: " + sum);    // 输出累加结果
    }
}
```
