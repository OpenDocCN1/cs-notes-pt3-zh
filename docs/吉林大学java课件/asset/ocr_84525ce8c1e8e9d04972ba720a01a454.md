# 访问类中的属性和方法

访问属性：对象名称.属性名
访问方法：对象名称.方法名()

```
class Person {
    String name;
    int age;
    public void tell() {
        System.out.println("姓名: " + name + ", 年龄: " + age);
    }
}
public class ClassDemo03 {
    public static void main(String args[]){
        Person per = new Person();
        per.name = "张三";        // 为属性赋值
        per.age = 30;
        per.tell();              // 调用类中的方法
    }
}
```
