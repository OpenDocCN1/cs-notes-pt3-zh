# 引用数据类型

+   - 数组Array，类 class，接口interface属于引用类型。
+   - 引用类型的变量是所引用的对象的内存地址。

```
class MyDate {
    private int day = 1;
    private int month = 1;
    private int year = 2000;
    public MyDate( int day, int month, int year) { ... }
    public void print() { ... }
}
public class TestMyDate {
    public static void main( String[] args) {
        MyDate my_birth = new MyDate( 22, 7, 1964);    }
}
```
