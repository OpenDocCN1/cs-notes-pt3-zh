# 使用Object接收接口实例

```
interface A{
    public String getInfo() ;
}
// 定义接口A
// 定义抽象方法
class B implements A{
    public String getInfo(){
        return "Hello World!!!" ;
    }
}
// 子类实现接口
// 覆盖接口中的抽象方法
public class ObjectDemo04 {
    public static void main(String args[]) {
        A a = new B() ;
        Object obj = a ;
        A x = (A)obj ;
        System.out.println(x.getInfo()) ;
    }
}
// 为接口实例化
// 对象向上转型
// 对象向下转型
```
