# 简洁的表达式

| No. | 运算符 | 范例用法 | 说明 | 描述 |
|---|---|---|---|---|
| 1 | `+=` | `a += b` | `a + b`的值存放到`a`中 | `a = a + b` |
| 2 | `-=` | `a -= b` | `a - b`的值存放到`a`中 | `a = a - b` |
| 3 | `*=` | `a *= b` | `a * b`的值存放到`a`中 | `a = a * b` |
| 4 | `/=` | `a /= b` | `a / b`的值存放到`a`中 | `a = a / b` |
| 5 | `%=` | `a %= b` | `a % b`的值存放到`a`中 | `a = a % b` |
