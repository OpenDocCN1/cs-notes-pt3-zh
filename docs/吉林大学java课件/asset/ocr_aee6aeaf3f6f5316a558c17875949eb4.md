# 解决方案一

简单的在Door的定义中增加一个alarm方法，如下：

```
abstract class Door {
abstract void open();
abstract void close();
abstract void alarm();
}
```

那么具有报警功能的
AlarmDoor的定义方式如下：

```
class AlarmDoor extends Door {
void open() { ... }
void close() { ... }
void alarm() { ... }
}
```

或者

```
interface Door {
void open();
void close();
void alarm();
}
```

或者

```
class AlarmDoor implements Door {
void open() { ... }
void close() { ... }
void alarm() { ... }
}
```
