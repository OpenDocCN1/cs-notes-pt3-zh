# Jar工具以及其classpath环境变量设置

+   - java使用 “.jar” 文件存档 “.class” 文件，打包工具为 jar 命令。Jar工具可以在 java 安装目录的 bin 子目录中找到。

+   - jar的全称: JavaTM Archive (JAR) file, 是 java 存档文件。用于 java 的 class 等文件压缩打包。同同学们参见文档 “jar用法.doc” 自学

+   - 当使用 jar 工具将 “.class” 文件打包成 “.jar” 文件后, 如果想在你正在开发的类中引用它, 也须设置 classpath 环境变量。具体设置语法为 “完整路径+jar文件全名”, 例如 “D:\Program Files\Java\jdk1.6_06\lib\tools. jar” ;
