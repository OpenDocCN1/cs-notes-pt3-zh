# 显示单选钮

```
private JFrame frame = new JFrame("Welcome To MLDN");    // 定义窗口
private Container cont = frame.getContentPane();    // 得到窗口容器
private JRadioButton jrb1 = new JRadioButton("MLDN");    // 定义一个单选钮
private JRadioButton jrb2 = new JRadioButton("MLDNJAVA"); // 定义一个单选钮
private JRadioButton jrb3 = new JRadioButton("智囊团");    // 定义一个单选钮
private JPanel pan = new JPanel();    // 定义一个面板
public MyRadio() {    // 定义一个面板的边框显示条
pan.setBorder(BorderFactory.createTitledBorder("请选择最喜爱的网站"));
pan.setLayout(new GridLayout(1, 3));    // 定义排放，1行3列
pan.add(this.jrb1);    // 加入组件
pan.add(this.jrb2);    // 加入组件
pan.add(this.jrb3);    // 加入组件
cont.add(pan);    // 加入面板
this.frame.setSize(330,80);    // 定义窗体大小
this.frame.setVisible(true);    // 显示窗体
this.frame.addWindowListener(new WindowAdapter(){    // 加入事件监听
public void windowClosing(WindowEvent arg0) {// 覆盖窗口关闭方法
System.exit(1);
}
});
```
