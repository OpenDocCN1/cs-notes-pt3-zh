# 调用抽象类中指定参数的构造方法

```
abstract class Person{
    private String name ;                 // 定义抽象类Person
    private int age ;                     // 定义name属性
    public Person(String name,int age){   // 定义age属性
        this.setName(name) ;              // 在抽象类中定义构造方法
        this.setAge(age) ;                // 为name赋值
    }                                     // 为age赋值
    // setter、getter
    public abstract String getInfo() ;    // 取得信息，抽象方法
}
class Student extends Person{
    private String school ;               // 定义子类
    public Student(String name,int age,String school){  // 定义school属性
        super(name,age) ;                 // 调用父类中有两个参数的构造
        this.setSchool(school) ;          // 为school赋值
    }
    // setter、getter
    public String getInfo(){
        return "姓名:" + super.getName() +   // 覆盖抽象类中的抽象方法
               ", 年龄:" + super.getAge() +
               ", 学校:" + this.getSchool() ;
    }
}
```
