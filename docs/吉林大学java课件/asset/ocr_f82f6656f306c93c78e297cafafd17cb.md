# ## 单一职责原则实例



某基于Java的C/S系统的“登录功能” 通过如下登录类(Login)实现：

| 方法 | 返回类型 |
|------|----------|
| init() | void |
| display() | void |
| validate() | void |
| getConnection() | Connection |
| findUser(String userName, String userPassword) | boolean |
| main(String args[]) | void |

现使用单一职责原则对其进行重构。
