# 为程序打包

```
package org.lxh.demo08;    // 定义一个包
class Demo{                // 定义Demo类
    public String getInfo(){   // 返回信息
        return "Hello World!!!" ;
    }
}
public class PackageDemo01 {
    public static void main(String[] args) {
        System.out.println(new Demo().getInfo()) ;// 实例化本包对象
    }
}
```

程序编译： javac -d . PackageDemo01.java
