
## 注意：对象向下转型的要求

在以上的程序中读者已经了解了对象的向上和向下转型的基本概念，但是必须提醒读者的是，在进行对象的向下转型之前，必须首先发生对象向上转型才可以，否则将出现对象转换异常

## 错误的转型

```
class A{ // 定义类A
    public void fun1(){ // 定义fun1()方法
        System.out.println("A --> public void fun1(){ }");
    }
    public void fun2(){ // 定义fun2()方法
        this.fun1();
    }
};
class B extends A{ // 子类通过extends继承父类
    public void fun1(){ // 覆写父类中的fun1()方法
        System.out.println("B --> public void fun1(){ }");
    }
    public void fun3(){ // 子类自己定义的方法
        System.out.println("B --> public void fun3(){ }");
    }
};
public class PolDemo03 {
    public static void main(String[] args) {
        A a = new A(); // 此时声明的是父类对象
        B b = (B)a; // 此时发生了向下转型关系,错误
        b.fun1();
        b.fun2();
        b.fun3();
    }
}
```

## 多态性

多态性在面向对象中是一个最重要的概念，在java中面向对象主要由以下两种主要体现：

- 方法的重载
- 对象的多态性

## 多态的实现

### 继承实现的多态

- 方法的重写 : 派生类（子类）将继承超类（父类）所有的变量和方法，可根据需要来重新定义超类的变量和方法，甚至增加或者修改部分内容，以提供不同形式的实现。

## 多态的实现

### 接口实现的多态

- “interface”（接口）使抽象的概念更深入了一层，我们可将其想象为一个“纯”抽象类。

## 多态带来什么好处？

利用接口产生多态的效果。

打个比喻：电脑主机板（Main Board）上面能够插上 Intel 的 CPU，也能插上AMD 的 CPU，一切运作顺利，那是因为 Intel 的 CPU 和 AMD 的 CPU 都遵守该主机板要求的接口（interface）。这么一来，任何厂商只要能符合此接口，就能和该主机板搭配使用，主机板不需要做出任何修改。

多态的机制，让程序具备了动态的扩充性。

## 主板和CPU的例子

```
interface CPU
{
    void start();
    void stop();
}
class IntelCPU implements CPU
{
    public void start()
    {
        System.out.println("Intel Start");
    }
    public void stop()
    {
        System.out.println("Intel Stop.");
    }
}
```

CPU指明了多个类 (AmdCPU, IntelCPU 等) 需要实现的方法,例如 start, stop

## 主板和CPU的例子

```
class AmdCPU implements CPU
{
    public void start(){
        System.out.println("AMD Start");
    }
    public void stop(){
        System.out.println("AMD Stop.");
    }
}
class MainBoard
{
    public void useCPU(CPU p) {
        p.start();
        p.stop();
    }
}
```

> 方法useCPU只需了解接口CPU，不需要了解CPU对应的类，比如AmdCPU、IntelCPU等等

多态的机制，让程序具备了动态的扩充性。

## 多态的机制应用范围

- 多态的机制只用在方法上，对属性不适用；
- 多态的机制只用在非静态方法上，对静态方法不适用；

## 面向对象（高级）
—— Java8对接口的改变

## 接口（第一点改进）—增加了静态方法

```
public interface Calculator {

    //设计模式中的工厂方法
    static Calculator getInstance() {
        return new BasicCalculator();
    }

    int add(int first, int second);

    int subtract(int first, int second);

    int divide(int number, int divisor);

    int multiply(int first, int second);
}
```

## 接口——增加了静态方法

```
class BasicCalculator implements Calculator {

    public int add(int first, int second) {
        return first + second;
    }
    public int subtract(int first, int second) {
        return first - second;
    }
    public int divide(int number, int divisor) {
        if (divisor == 0) {
            throw new IllegalArgumentException("divisor can't be zero.");
        }
        return number / divisor;
    }
    public int multiply(int first, int second) {
        return first * second;
    }
}
```

## 接口—增加了静态方法

```
public class TestStatic {
public static void main(String[] args) {
Calculator t=Calculator.getInstance();
int i=t.add(1, 2);
System.out.print(i);
}
}
```

Java8中接口增加了静态方法，很大原因是为了工厂方法在接口中非常有意义。
