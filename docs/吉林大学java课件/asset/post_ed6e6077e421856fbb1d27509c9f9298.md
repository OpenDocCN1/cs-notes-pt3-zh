
## 继承抽象类

```java
abstract class A{
public static final String FLAG = "CHINA" ; // 设置姓名
private String name = "李兴华" ;
public String getName() {
return name;
} // 取得姓名
public void setName(String name) {
this.name = name;
} // 定义抽象方法
public abstract void print() ;
}
class B extends A{ // 继承抽象类，覆盖全部抽象方法
public void print() {
System.out.println("FLAG = " +FLAG) ;
System.out.println("姓名 = " + super.getName()) ;
}
}
public class AbstractDemo02{
public static void main(String args[]){
B b = new B() ;
b.print() ;
} // 实例化类对象
// 调用被子类覆写的方法
}
```

## 抽象类的思考

- □ 问题1：一个抽象类可以使用final关键字声明吗？
- □ 问题2：一个抽象类中可以定义构造方法吗？

## 回答

- 问题一：
  - 一个类如果使用了 final 关键字声明，则此类不能被子类继承，而抽象类又必须被子类覆盖，所以很明显，第一个问题的答案是：“一个抽象类不能使用 final 关键字声明”。
- 问题二：
  - 实际上在一个抽象类中是允许存在构造方法的，因为抽象类依然使用的是类的继承关系，而且抽象类中也存在各个属性，所以子类在实例化之前肯定是先要对父类进行实例化的。

## 调用抽象类中指定参数的构造方法

```java
abstract class Person{
    private String name ;                 // 定义抽象类Person
    private int age ;                     // 定义name属性
    public Person(String name,int age){   // 定义age属性
        this.setName(name) ;              // 在抽象类中定义构造方法
        this.setAge(age) ;                // 为name赋值
    }                                     // 为age赋值
    // setter、getter
    public abstract String getInfo() ;    // 取得信息，抽象方法
}
class Student extends Person{
    private String school ;               // 定义子类
    public Student(String name,int age,String school){  // 定义school属性
        super(name,age) ;                 // 调用父类中有两个参数的构造
        this.setSchool(school) ;          // 为school赋值
    }
    // setter、getter
    public String getInfo(){
        return "姓名:" + super.getName() +   // 覆盖抽象类中的抽象方法
               ", 年龄:" + super.getAge() +
               ", 学校:" + this.getSchool() ;
    }
}
```

## 抽象类的实际应用 —— 模板设计

来看下面的这样一种场景：“假设人分为学生和工人，学生和工人都可以说话，但是学生和工人说话的内容是不一样的，也就是说说话这个功能应该是一个具体功能，而说话的内容就要由学生或工人来决定了”，所以此时就可以使用抽象类实现这种场景

![](img/b706331eacf49a62651c2c9b2de81ca5_256_0.png)

## 代码实现 —— Person

```java
abstract class Person {
    private String name;                 // 定义name属性
    private int age;                     // 定义age属性
    public Person(String name, int age) { // 为属性初始化
        this.name = name;                // 为name属性赋值
        this.age = age;                  // 为age属性赋值
    }
    public String getName() {            // 取得name属性内容
        return name;
    }
    public int getAge() {                // 取得age属性内容
        return age;
    }
    public void say() {                  // 说话是具体功能，要定义成普通方法
        System.out.println(this.getContent());
    }
    public abstract String getContent(); // 说话的内容由子类决定
}
```

## 代码实现 —— Student

```java
class Student extends Person { // 定义Student类继承Person类
    private float score;
    public Student(String name, int age, float score) {
        super(name, age); // 调用父类的构造方法
        this.score = score;
    }
    public String getContent() { // 覆盖父类中的抽象方法
        return "学生信息 --> 姓名: " + super.getName() +
               "; 年龄: " + super.getAge()
               + "; 成绩: " + this.score;
    }
}
```

## 代码实现 —— Worker

```java
class Worker extends Person {          // 定义Worker类继承Person类
    private float salary;
    public Worker(String name, int age, float salary) {
        super(name, age);                  // 调用父类的构造方法
        this.salary = salary;
    }
    public String getContent() {           // 覆盖父类中的抽象方法
        return "工人信息 --> 姓名: " + super.getName() +
               "; 年龄: " + super.getAge()
               + "; 工资: " + this.salary;
}
```

## Employee

```java
public abstract class Employee {
    private String firstName;
    private String lastName;
    public Employee( String first, String last ) {
        firstName = first;
        lastName = last;
    }
    public String getFirstName() {
        return firstName;
    }
    public String getLastName() {
        return lastName;
    }
    public String toString() {
        return firstName + ' ' + lastName;
    }
    public abstract double earnings();
}
```
