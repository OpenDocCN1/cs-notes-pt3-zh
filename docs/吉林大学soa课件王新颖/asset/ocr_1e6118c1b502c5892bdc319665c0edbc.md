# Compile the Web Service

Create a myservice directory.

From the directory just above loanservice, run Java’s Annotation Processing Tool (APT):

```
C:\>apt -d myservice loanservice/LoanApprover.java
```

This populates a directory named myservice.
The directory holds the compiled package as well as a new directory (package) called jaxws.
The new jaxws package holds classes associated with the parameters to and from each web service method.
Use the -s switch to generate the source code.
