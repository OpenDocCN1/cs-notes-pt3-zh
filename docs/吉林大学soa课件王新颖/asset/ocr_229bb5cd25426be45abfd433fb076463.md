# Junit in eclipse - Setup

+   - In Eclipse
+     - Create a new project
+     - Open project’s property window (File -> Properties)
+     - Select: Java build path
+     - Select: libraries
+     - Add Library
+     - Select Junit
+       - Select the type 3.x or 4.x
