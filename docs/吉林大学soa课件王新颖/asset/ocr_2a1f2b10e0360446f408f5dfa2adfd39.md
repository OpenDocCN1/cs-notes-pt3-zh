# What is UDDI ?

+   - UDDI (Universal Description, Discovery and Integration) 是一个独立于平台的框架，用于通过使用 Internet 来描述服务，发现企业，并对企业服务进行集成
+     - UDDI 指的是通用描述、发现与集成服务
+     - UDDI 是一种用于存储有关 web services 的信息的目录
+     - UDDI 是一种由 WSDL 描述的 web services 界面的目录
+     - UDDI 经由 SOAP 进行通信
+     - UDDI 被构建入了微软的 .NET 平台
