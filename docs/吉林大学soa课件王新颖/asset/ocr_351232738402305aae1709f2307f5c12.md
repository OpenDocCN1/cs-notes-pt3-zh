# Library project

+   - Business Integration project type for storing artifacts shared between multiple modules
+   - Not a deployable unit
+   - Contains these artifacts
+     - Interfaces
+     - Business Objects
+     - Business Object Maps
+     - Relationships
+     - Web services
+   - Can be added to the dependency list for a module from the dependency editor
