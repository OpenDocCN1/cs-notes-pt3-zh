# Error Handling in REST

+   - Use HTTP codes (use the entity-body for more info)
+     - 200 OK
+     - 201 Created
+       - HTTP Location Header should have URI to new resource
+     - 400 Bad Request
+     - 404 Not Found
+     - 500 Internal Server Error
+     - 301 Moved Permanently
+     - 403 Forbidden
+     - 401 Unauthorized
+     - 409 Conflict
