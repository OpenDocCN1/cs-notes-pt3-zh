# Unit Testing Web Services

+   - Web services as a presentation layer of sorts
+     - Tested using an approach analogous to testing GUI
+     - Separating the presentation layer from the application logic
+     - Each method and behavior of the web service interface should have corresponding tests
+   - To validate how the service methods work "over the wire," it's not sufficient just to create an instance of the service interface class and invoke its methods directly.
+   - The service methods must be validated by calling them via the client interface, the same way they are called in the live application.
