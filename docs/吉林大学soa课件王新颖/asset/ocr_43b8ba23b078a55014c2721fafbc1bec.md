# What’s Arnetminer

+   - Arnetminer (arnetminer.org) is a system aiming to provide comprehensive search and mining services for researcher social networks.
+     - creating a semantic-based profile for each researcher by extracting information from the distributed Web
+     - integrating academic data (e.g., the bibliographic data and the researcher profiles) from multiple sources
+     - accurately searching the heterogeneous network
+     - analyzing and discovering interesting patterns from the built researcher social network.
