# # 元素

+   - 简单元素
+   
+   ```xml
+   <xs:element name="xxx" type="yyy"/>
+   ```

+   - 复合元素
+   
+   ```xml
+   <xs:element name="employee">
+   <xs:complexType>
+   <xs:sequence>
+   <xs:element name="firstname" type="xs:string"/>
+   <xs:element name="lastname" type="xs:string"/>
+   </xs:sequence>
+   </xs:complexType>
+   </xs:element>
+   ```
