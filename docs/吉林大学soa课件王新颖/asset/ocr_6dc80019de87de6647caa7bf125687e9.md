# Business Measures Model

+   - Defines what is monitored during the execution of the business process
+   - Key Performance Indicators (KPI’s) and Metrics can be defined both at a business process and activity level of granularity
+     - Example KPI - Percentage of Approved requests
+     - Example KPI – Average time to process requests from Gold customers
+   - Situation and situation outcomes can be defined in order to make KPI’s and metrics actionable
