# XML文档结构

+   - XML的声明:一般是XML文档的第一行
+     - version----文档符合XML1.0规范
+     - encoding----文档字符编码，默认使用 'UTF-8'
+     - standalone----文档定义是否在一个文件内
+   - 样式处理指令xml-stylesheet,该指令必须出现在序言部分，在根元素之前
+   - 根元素
+   - CDATA标记----用于把整段文本解释为纯字符数据而不是标记的情况
+     <![CDATA[ <P>Paragraphs can contain <EM>other</EM> tags.</P> ]>
