# SOA的特点

# 关注点

+   - SOA 服务专注于业务层面的活动和互动
+   - 以前，只专注于技术层面的子任务

# “用户”与“开发”的调和

+   - 业务人员和IT人员基于SOA讨论 (今天有63%的项目是由业务部门提出的)*
+   - 以前，业务人员与IT人员没有合适的沟通渠道和语言

# 标准

+   - 被广泛采用的 Web services 保证了有良好定义的接口.
+   - 以前，私有的 “标准 “限制了互操作性

# 连接

+   - SOA 服务是动态、灵活的连接
+   - 以前，服务之间的互操作是通过编程的且与应用本身相关的

# 重用性

+   - SOA 服务能被广泛的重用，从而提高资产利用率
+   - 以前，重用只能在某一应用内部实现
