# UDDI接口

| 接口 | 描述 |
|------|------|
| UDDI Inquiry | 定位和查找服务细节 |
| UDDI Publication | 发布和更新服务 |
| UDDI Security | UDDI注册表的访问控制 |
| UDDI Subscription | 允许客户端订阅UDDI注册表信息的变化 |
| UDDI Replication | 如何执行跨节点的信息复制 |
| UDDI Custody and Ownership transfer | 改变信息所有者，将其从一个节点转移到同以UDDI注册表中的另外节点 |
| UDDI Subscription Listener | 订阅信息API的客户端 |
| UDDI Value Set | 使用UDDI注册表提供的合法信息 |
