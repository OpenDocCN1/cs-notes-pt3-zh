# 案例剖析

+   - 搭建并开发定制了基础数据服务、数据信息服务总线和业务流程管理平台等应用集成平台。

+   - 在全省实现了办公自动化、专卖、营销、客户关系管理、财务、烟叶系统的单点登录、用户体验层面的集成和数据服务统一集成，以及与国家局重点项目的互联互通。

+   - 满足国家局行业平台的技术要求：集成平台采用省、市两级部署，与国家局生产经营决策管理系统平台一致；应用基础架构符合《烟草行业信息化建设统一技术平台要求》

+   - 信息系统初步体现集成整合优势。信息系统按统一的标准建设，系统可定制性增强，可适应一定程度的业务变化，系统生命周期有效延长，总体降低了信息化建设的成本
