## 阿里巴巴信息系统

- 案例特点
  - 建设类型：逐级建设
  - 实施类型：用户主导、厂商主导
  - 建设层次：多层次
- 业务背景
  - 成立于1999年的阿里巴巴，连续7次获得福布斯杂志授予的“最佳B2B网站”称号
  - 全球企业间（B2B）电子商务的著名品牌，在200余个国家和地区拥有超过数千万名会员，成为全球商人网络推广的首选网站

### 业务剖析

- 原有技术框架的问题
  - 建立了内部管理和客户管理，包括：人力资源系统、内部网络、CRM、财务、数据仓库等
  - 各应用系统相互独立运行，形成“信息孤岛”
  - 信息和数据的更新不同步甚至不一致，给企业中不同部门的人员在进行交流时带来问题
  - 众多的系统需要分散管理，很多信息需要重复输入，造成了人力和物力的浪费

### 整体解决方案

- 实施模式
  - 采用Sun JES（Java Enterprise System）咨询服务
- 技术方案
  - 基于JES中的Java System Composite Application Platform Suite（CAPS）实现人力资源、内网、CRM、财务、数据仓库等多个平台的开发和集成
- 实施方案
  - 采用Sun Java Composite Application Platform Suite（Java CAPS），作为Java企业系统的组成部分

### 采纳标准

- XML/XSLT/XPath/XQuery
- SOAP
- WSDL
- UDDI
- WS-BPEL 2.0
- SCA/SDO/WS-Policy
- WS-I Basic Profile
- WSRP

### 案例剖析

- 在采用Sun JES咨询服务之后，阿里巴巴实现了多应用集成和单点用户登录，连接“信息孤岛”实现数据共享和业务流程的共享
- 利用现有的IT系统和数据资源，减少了资源浪费，简化了内部流程，客户服务的信息准确性全面提高，方便了系统的维护和管理
- 基于Sun公司强大的软件产品家族，消除了信息孤岛，提高了系统的安全性

## 奇瑞汽车

### 面临的挑战

- 企业需要采用更有效的应用开发方法，因为现有的点对点方法过于复杂，难以维护
- 部署一个可支持原有系统的强大稳定的平台
- 提高开发过程的可视性
- 减轻IT部门员工开发与维护的压力，使其能更快地应对突发情况

### 奇瑞汽车采用Oracle SOA实现应用整合

针对奇瑞EAI平台的项目目标和具体需求，奇瑞汽车采用了Oracle融合中间件的SOA套件作为奇瑞EAI平台的基础系统平台。

在采用Oracle SOA套件来搭建EAI平台的建设过程中，遵循多配置少定制开发的原则，实现应用整合项目的接口集成。同时遵循接口应用集成的监控管理图形化展现的原则，对于各种不同的集成场景，采用直观的图形化的界面进行监控和展现。
