### What is **XSL**

- XSL (Extensible Stylesheet Language)：扩展样式表语言，XML 样式表，用于描述如何来显示 XML 文档。
- XSL 包括三部分规范：
  - XSLT：一种用于转换 XML 文档的语言。
  - XPath：一种用于在 XML 文档中导航的语言。
  - XSL-FO：一种用于格式化 XML 文档的语言。

## Lecture 4

### SOAP

### What is SOAP

- SOAP 指简易对象访问协议
- SOAP 是一种通信协议
- SOAP 用于应用程序之间的通信
- SOAP 是一种用于发送消息的格式
- SOAP 被设计用来通过因特网进行通信
- SOAP 独立于平台
- SOAP 独立于语言
- SOAP 基于 XML
- SOAP 很简单并可扩展
- SOAP 允许您绕过防火墙

### SOAP的主要功能

- 定义通信单元的机制
- 错误处理机制
- 可扩展性机制
- 灵活的数据表示机制
- 支持以文档为中心的方法
- 将 SOAP 消息绑定到 HTTP
- 远程过程调用（RPC）和作为响应的 SOAP 消息的约定

### SOAP的组成

- SOAP 是基于 XML 的协议，由四部分组成：
  - 信封（Envelope）
  - 编码规则（Encoding Rules）
  - 绑定（Binding）
  - RPC

![](img/431d4828d5c6073b7e23d9eca159cdeb_126_0.png)

```xml
<?xml version="1.0"?>
<soap:Envelope
xmlns:soap="http://www.w3.org/2001/12/soap-envelope"
soap:encodingStyle="http://www.w3.org/2001/12/soap-encoding">

<soap:Header>
    ...
    ...
</soap:Header>

<soap:Body>
    ...
    ...
    <soap:Fault>
        ...
        ...
    </soap:Fault>
</soap:Body>

</soap:Envelope>
```

```xml

    xmlns:SOAP-ENV="http://schemas.xmlsoap.org/soap/envelope/"
```
