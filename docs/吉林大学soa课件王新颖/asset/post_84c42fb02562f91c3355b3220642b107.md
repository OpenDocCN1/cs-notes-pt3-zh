## Lecture 2

## Web服务的基础——XML

- XML（Extensible Markup Language，可扩展的标记语言）是W3C制定的作为Internet上数据交换和表示的标准语言，是一种允许用户定义自己的标记的元标记语言。
- XML与HTML的区别：XML是用来存储数据的，重在数据本身；而HTML用来定义页面的组织结构，重在数据的显示模式。

## XML Sample

```
<?xml version="1.0" encoding="ISO-8859" standalone="yes" ?>
<?xml-stylesheet href="classic.xsl" type="text/xml"?>
<note>
    <to>Tove</to>
    <from>Jani</from>
    <heading>Reminder</heading>
    <body>Don't forget me this weekend!</body>
</note>
```

## XML文档结构

- XML的声明:一般是XML文档的第一行
  - version----文档符合XML1.0规范
  - encoding----文档字符编码，默认使用 'UTF-8'
  - standalone----文档定义是否在一个文件内
- 样式处理指令xml-stylesheet,该指令必须出现在序言部分，在根元素之前
- 根元素
- CDATA标记----用于把整段文本解释为纯字符数据而不是标记的情况
  <![CDATA[ <P>Paragraphs can contain <EM>other</EM> tags.</P> ]>

## 元素、属性、注释、处理指令与实体

- XML 文档必须包含在一个单一元素中。这个单一元素称为根元素，它包含文档中所有文本和所有其它元素。
- 元素是开始标记、结束标记以及位于二者之间的所有子元素；
- 属性是一个元素的开始标记中的名称-值对
- 注释<!--......-->
- 处理指令<?.....?>
- 实体<!ENTITY dw "developerWorks">

## XML文档定义

- XML有两种方法定义数据元素：
  - DTD
  - XML Schema
- 文档类型定义(Document Type Definition， DTD)
  - 元素(Element)的定义规则
  - 元素之间的关系规则
  - 属性(Attribute)的定义规则
- XML Schema： 是一种以XML语言为基础的，用于可替代DTD。

## XML Schema

- XML SCHEMA是W3C推荐的XML规范(2001.5)，是以XML语言为基础的，用于可替代DTD
- XML Schema内容比DTD丰富，功能也更强
  - 基于XML语法，可以用处理XML文档的工具来处理
  - 支持广泛的数据类型，支持自定义数据类型
  - 支持开放内容模型和命名空间集成
  - 支持元素的继承
  - 支持属性组
- XML Schema也被称为XML Schema Definition (XSD)

## XML Schema结构

- 注释
- 声明
  - 元素声明
  - 属性声明
  - 表示法声明
- 类型定义
  - 简单类型
  - 复杂类型
- 属性组
- 模型组

```
<?xml version="1.0"?> (1)
<xs:schema xmlns:xs="http://www.w3.org/2001/XMLSchema" targetNamespace="http://www.w3schools.com" xmlns="http://www.w3schools.com" elementFormDefault="qualified"> (2)
<xs:element name="note"> (3)
<xs:complexType> (4)
<xs:sequence> (5)
<xs:element name="to" type="xs:string"/> (6)
<xs:element name="from" type="xs:string"/> (7)
<xs:element name="heading" type="xs:string"/> (8)
<xs:element name="body" type="xs:string"/>
</xs:sequence>
</xs:complexType>
</xs:element>
</xs:schema>
```

## # 元素

- 简单元素

```xml
<xs:element name="xxx" type="yyy"/>
```

- 复合元素

```xml
<xs:element name="employee">
<xs:complexType>
<xs:sequence>
<xs:element name="firstname" type="xs:string"/>
<xs:element name="lastname" type="xs:string"/>
</xs:sequence>
</xs:complexType>
</xs:element>
```

```
<xsd:complexType name="PublicationType">
    <xsd:sequence>
        <xsd:element name="Title" type="xsd:string"/>
        <xsd:element name="Author" type="xsd:string" minOccurs="0" maxOccurs="unbounded"/>
        <xsd:element name="Date" type="xsd:gYear"/>
    </xsd:sequence>
</xsd:complexType>
<xsd:complexType name="BookType">
    <xsd:complexContent>
        <xsd:extension base="PublicationType">
            <xsd:sequence>
                <xsd:element name="ISBN" type="xsd:string"/>
                <xsd:element name="Publisher" type="xsd:string"/>
            </xsd:sequence>
        </xsd:extension>
    </xsd:complexContent>
</xsd:complexType>
<xsd:complexType name="MagazineType">
    <xsd:complexContent>
        <xsd:restriction base="PublicationType">
            <xsd:sequence>
                <xsd:element name="Title" type="xsd:string"/>
                <xsd:element name="Date" type="xsd:gYear"/>
            </xsd:sequence>
        </xsd:restriction>
    </xsd:complexContent>
</xsd:complexType>
```
