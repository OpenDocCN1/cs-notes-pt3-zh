## Web1.0：以静态、单向阅读为主

- Web1.0以编辑为特征，网站提供给用户的内容是网站编辑处理后提供的，这个过程是网站到用户的单向行为。
- 该时期的代表站点：新浪、搜狐、网易三大门户网站

![](img/431d4828d5c6073b7e23d9eca159cdeb_88_0.png)

## Web2.0：以分时为特征的实时网络

- Web2.0加强了网站与用户之间的互动，实现了网站与用户之间的双向交流与参与
- Web1.0是一个图书馆，Web2.0是一个社交圈
- 这个时期的典型代表：baidu、google、博客中国、中华英才网、人人网、校内网等

![](img/431d4828d5c6073b7e23d9eca159cdeb_89_0.png)

## Web2.0的特征

- 访问者可以对网页进行修改（如亚马逊网站 Amazon）
- 通过页面将用户联系起来（如 Facebook 和 MySpace 等社交网络）
- 高效的分享内容（如 YouTube、MetaCafe）
- 获取信息的有效途径（如 RSS，Really Simple Syndication）
- 除计算机外，人们还可以利用其它设备上网（如手机、视频游戏机、电视机……）

## 语义网 Web3.0

- Web3.0的最大价值不是提供信息，而是提供基于不同需求的过滤器，每一种过滤器都是基于一个市场需求。
- Web2.0解决了个性解放的问题，Web3.0则是解决信息社会机制的问题，即最优化信息聚合的问题。

![](img/431d4828d5c6073b7e23d9eca159cdeb_91_0.png)

## Web3.0特征分析

- Web3.0是建立在Web2.0基础上的，实现了更加“智能化的人与人、人与机器的交流”功能的互联网模式。
- 从广播电视媒体网络化角度，划分其四大特征：
  - 微内容（Widget）的自由整合与有效聚合
  - 适合多种终端平台，实现信息服务的普适性
  - 良好的个性化用户体验，以及基础性的个性化配置
  - 有效和有序的数字新技术
- Web3.0以网络化和个性化为特征，提供更多人工智能服务。

## Web3.0的发展趋势

- 基于用户的一个需求点，力图在一个平台上整合所有的互联网服务
  - 例如博客中国向综合阵营的靠拢，腾讯转型为综合性门户等
- 在用户个别需求点上进行深度挖掘，纵深发展
  - 淘宝、奇虎、Donews等公司仅就业务领域进行划分，并没有依据人群进行细分，其运作模式还是Web2.0的延续，信息散乱
- Web3.0关键在于提供用户偏好的个性化聚合服务

## Web4.0展望

- Web1.0——信息共享；Web2.0——信息共建；Web3.0——知识传承；Web4.0——知识分配。
- Radar Networks公司的Nova Spivack绘制了一份未来25年的网络进化图，他没有明确指出Web4.0具体的来临日期和所需技术，但每个阶段的发展以10年为期限是真实而可信的。
- 互联网下一次显著进化将使其成为一个包含语义网络的平台，这一理念是合情理的。

### SOA

| 视角 | 说明 |
|---|---|
| 业务模型 | 企业向其客户暴露的一系列业务——“服务” |
| Roles | 一种体系结构风格，包括服务的提供者、服务的使用者与服务中介。 |
| 体系结构 | 一组体系结构设计原则与模式，强调模块化、封装、松散耦合、分离关注点、可复用、可组合性、接口与实现分离等特性。 |
| 软件实现方式 | 一种编程模式，包括一系列的标准、开发工具、开发过程指南、运行时基础架构。 |
