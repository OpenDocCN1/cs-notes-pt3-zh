# 2) 标量逻辑时钟

每个进程P_i有一个逻辑时钟LC_i，LC_i被初始化为 init (init≥0)并且它是一个非减的整数序列。进程P_i发送的每个报文m都被标上LC_i的当前值和进程的标号i，从而形成一个三元组(m, LC_i, i)。

任何一个逻辑时钟LC_i基于以下两条规则更新它的逻辑时钟值：

+   a) 当发生一个事件（一个外部发送或内部事件）之前，我们更新LC_i： LC_i := LC_i +d (d>0)

+   b) 当收到一个带时间戳的报文(m, LC_j, j)时，我们更新LC_i： LC_i := max(LC_i, LC_j) +d (d>0)
