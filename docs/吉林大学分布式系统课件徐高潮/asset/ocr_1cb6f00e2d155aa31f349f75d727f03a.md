# 第二章 进程通信

# 2.2 不同节点上的进程间通信

◆ RPC实例2： DCE RPC

编写顾客和服务员程序过程：

+   1) 调用uuidgen程序，由该程序生成一个IDL范例文件。

+   2) 编辑uuidgen程序生成的IDL文件，在该文件中添加远程过程的名字和它们的参数。

+   3) 编译IDL文件。当IDL文件编辑完毕，使用IDL编译器进行编译，编译后生成如下三个文件：一个头文件（如 interface.h）；一个顾客代理(client stub)和一个服务员代理(server stub)。

+   4) 编写顾客和服务员程序代码，编译和连接，生成顾客可执行代码和服务员可执行代码。
