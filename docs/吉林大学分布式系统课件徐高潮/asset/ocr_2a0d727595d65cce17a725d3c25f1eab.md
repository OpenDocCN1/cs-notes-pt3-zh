2) 向量逻辑时钟

任何一个逻辑时钟LCᵢ基于以下两条规则更新它的逻辑时钟值：

+   a) 当发生一个事件（一个外部发送或内部事件）之前，Pᵢ更新LCᵢ[i]：
+   LCᵢ[i] := LCᵢ[i] + d      (d>0)

+   b) 每个报文捎带发送方在发送时的时钟向量，当收到一个带时间戳的报文(m, LCⱼ, j)时，Pᵢ更新LCᵢ：
+   LCᵢ[k] := max(LCᵢ[k], LCⱼ[k])    1≤k≤n
+   LCᵢ[i] := LCᵢ[i] + d      (d>0)
