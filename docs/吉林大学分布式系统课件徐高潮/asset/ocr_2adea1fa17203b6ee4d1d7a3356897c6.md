# 11.2 实现DSM的算法

# ◆读复制算法

对于一个当前不在本地的块中的一个数据项进行读操作时，先与远程节点通信以获得那个块的一个只读副本，然后再进行读操作。若被执行写操作的数据所在的块不在本地或在本地但主机无写权时，必须先使此块在其他节点的所有副本无效，之后再进行写操作。

| --- | --- |
| 如果数据块不在本地，则确定位置，发送请求 |  |
|  | 接收请求，发送块 |
| 接收块，广播“无效”报文 |  |
|  | 接收“无效”报文，使块无效 |
