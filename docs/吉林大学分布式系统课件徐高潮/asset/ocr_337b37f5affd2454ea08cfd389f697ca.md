# 第七章 分布式系统中容错技术

# 7.1 分布式系统中的故障模型

# 基本的故障模型

故障的基本处理方法：

+   (1) 主动复制。所有的复制模块协同进行，并且它们的状态紧密同步。
+   (2) 被动复制。只有一个模块处于动态，其他模块的交互状态由这一模块的检查点定期更新。
+   (3) 半主动复制。是主动复制和被动复制的混合方法。此种方法所需的恢复开销相对较低。

失效的检测可分为外部检测和内部检测两类：

+   1) 外部检测是指将检测节点失效的职责赋予被检测节点的外部附件。
+   2) 内部检测将节点的失效检测机制置于该节点内部，通常检测部件被假定为一个可以完全信赖的“硬核”。
