# 基于时间戳的并发控制

read(5, x, 5), write(6, x, 7), read(7, x, 9), read(8, x, 8), write(9, x, 8)

+   (1) read(5, x, 5)操作请求被拒绝，对应的事务处理5被取消，因为 ts=5<ts_WR(x)=6；

+   (2) write(6, x, 7)操作请求被接受，对应的事务处理6继续执行，ts_WR(x)更新为7；

+   (3) read(7, x, 9)被接受，对应的事务处理7继续执行，ts_RD(x)更新为9；
