# 10.2 静态调度

# 基于任务相互关系图的任务调度

嵌入：设想任务相互关系图和处理器图被各自看作Gₜ和Gₚ。为了通过Gₜ得到对Gₚ的有效模拟(emulation)，也就是在Gₚ中嵌入Gₜ。

嵌入的不同代价指标：

+   (1) Gₜ的边的膨胀。Gₜ的边的膨胀定义为被映射成Gₜ里的一条边的Gₚ中对应的路径的长度。嵌入的膨胀为Gₜ中的最大边膨胀。

+   (2) 嵌入的扩大。嵌入的扩大定义为Gₜ里的节点数对Gₚ里的节点数的比率。

+   (3) 嵌入的拥塞。嵌入的拥塞定义为包含Gₚ中的一条边的最大路径数，Gₚ中的每条路径表示Gₜ中的一条边。

+   (4) 嵌入的负载。嵌入的负载是Gₜ分配给Gₚ中任意处理器的进程的最大数目。
