# 共享内存

使用共享内存技术，不同进程可以同时访问相同的内存区域。能够通过共享它们地址空间的若干部分，然后对存储在共享内存中的数据进行读和写，从而实现彼此直接通信。

共享内存技术实现 进程通信

+   1) 由一个进程来创建 / 分配一个共享内存段，其大小和访问权限在其生成时设置。系统调用 shmget 建立一个新的共享内存区或者返回一个已经存在的共享内存区。

+   2) 进程可挂接此存储段，同时将其映射到自己当前的数据空间中。每个进程通过其挂接的地址访问共享内存段。系统调用 shmat 将一个共享内存区附加到进程的虚拟地址空间上。
