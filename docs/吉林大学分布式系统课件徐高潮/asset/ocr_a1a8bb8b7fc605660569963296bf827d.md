# # 第十章 分布式调度



+   - 基于任务优先图的任务调度

给定任务优先图G的粒度是: g(G) = min{g(x)} ∀x∈G

如果g(x)>1，合并x或分裂x就是粗粒度；否则就是细粒度。同样如果g(G)>1，图G就是粗粒度，否则就是细粒度。当表示一个应用程序的给定的有向无环图DAG(任务优先图)是粗粒度时，也就是它的一个链接上的通信代价小于分裂或者合并操作连接的相邻节点的计算代价，任何非线性聚类可以被转换成具有更少或相等执行时间的线性聚类。注意，上面的结论暗示了一个粗粒度程序的线性聚类性能优于任何非线性聚类。然而，对细粒度程序而言，可能存在也可能不存在一个非线性聚类优于线性聚类。
