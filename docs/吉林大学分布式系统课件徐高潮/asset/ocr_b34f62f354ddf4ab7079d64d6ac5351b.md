# 第十章 分布式调度

# 10.2 静态调度

基于任务相互关系图的任务调度

对分配M的评估：

+   1) 处理器p的计算负载为： $Comp(p)=\sum_{u\in V_t} w(u) | M(u)=p$

+   2) 处理器p的通信负载为： $Comm p(p)=\sum_{(u,v)\in E_t} w(u,v) | M(u)=p \neq M(v)$

+   3) 整个应用程序中总的计算量是：
+   
+   $Comp = \sum_{p\in V_p} Comp(p) = \sum_{p\in V_p} \sum_{u\in V_t} w(u) | M(u)=p$

+   4) 整个应用程序中总的通信量是：
+   
+   $Comm = \frac{1}{2} \sum_{p\in V_p} Comm p(p) = \frac{1}{2} \sum_{p\in V_p} \sum_{(u,v)\in E_t} w(u,v) | M(u)=p \neq M(v)$
