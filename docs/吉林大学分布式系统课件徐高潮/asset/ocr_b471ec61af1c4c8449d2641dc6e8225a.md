# GIOP 报文类型

| 报文类型 | 发送者 | 功能描述 |
|---|---|---|
| Request | 顾客 | 包含调用请求 |
| Reply | 服务员 | 包含对一个请求的响应 |
| LocateRequest | 顾客 | 请求一个对象的准确位置 |
| LocateReply | 服务员 | 包含一个对象的位置信息 |
| CancelRequest | 顾客 | 取消一个请求，不再希望得到对应的应答 |
| CloseConnection | 顾客或服务员 | 指出要关闭连接 |
| MessageError | 顾客或服务员 | 包含一个错误信息 |
| Fragment | 顾客或服务员 | 对大的报文进行分段 |
