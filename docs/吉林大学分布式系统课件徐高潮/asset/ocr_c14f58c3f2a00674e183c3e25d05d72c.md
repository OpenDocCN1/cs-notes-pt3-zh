# NFS 中一些推荐的文件参数

| 参数 | 功能描述 |
|---|---|
| ACL | 文件的访问控制表 |
| FILEHANDLE | 服 务员提供的该文件的文件句柄 |
| FILEID | 该文件在文件系统中唯一标识符 |
| FS_LOCATIONS | 文件所对应的文件系统在网络中的位置 |
| OWNER | 文件的属主的名字 |
| TIME_ACCESS | 最后一次访问该文件的时间 |
| TIME_MODIFY | 最后一次修改该文件的时间 |
| TIME_CREATE | 创建该文件的时间 |
