# 6.3 死锁的检测

# 层级式死锁检测

在层级式死锁检测算法中，站点被分层地放在一个树中。一个站点的死锁检测只涉及到它的下一级站点。例如，设A、B和C是控制器，而C是A和B的最低的公共祖先。假定节点Pᵢ出现在控制器A和B的局部等待图中，那么节点Pᵢ也必定出现在如下控制器的等待图中：

+   (1) C控制器；
+   (2) 所有位于从C到A的路径上的控制器；
+   (3) 所有位于从C到B的路径上的控制器。

而且，如果Pᵢ和Pⱼ出现在控制器D的等待图中，并且在D的一个下一级控制器（子控制器）的等待图中有条从Pᵢ到Pⱼ的路径，那么边(Pᵢ, Pⱼ)一定存在于D的等待图中。
