# 第五章 同步和互斥

# 5.1 分布式系统中的资源管理

多个服务员参加对同一资源进行控制的方式：

+   1) 顺序方式：按某种顺序，先由一个服务员控制一段时间，之后再由另一个服务员控制一段时间。

+   2) 分工方式：由不同的服务员并发或顺序地控制同一资源执行不同的活动。

+   3) 民主方式：所有服务员共同协商一致对同一资源执行每个管理活动。

说明各种多重管理形式的分散性的参数：

+   1) 一致性是指由所有服务员共同完成的对同一个资源管理的活动数目。

+   2) 所谓均等性是各服务员对同一资源进行某一控制活动时被分配的管理权限和责任的平等程度。

+   3) 参加每个活动的服务员数目。
