# # 第三章 分布式程序设计语言

# 3.6 分布式控制描述语言 DCDL

DCDL中的通信

+   1) 输出命令的形式为：

```
send message_list to destination
```

其中destination是一个进程名(一对一通信)或代表所有其他进程(一对所有通信)的关键字all。

+   2) 输入命令的形式为：

```
receive message_list from source
```

其中source是一个进程名，这个输入命令支持显式和隐式的报文接收。

隐式的报文接收表示为：

```
receive message_list
```
