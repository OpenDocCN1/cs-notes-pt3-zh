# 3.3 进程通信与同步的支持

# 报文传递

报文传递通信模式有：

+   1) 同步和异步点到点报文。在同步报文传递方式中，发送者在接收者接收报文前一直阻塞。这样，双方不仅交换了数据而且还达到同步。在异步报文传递方式中，发送者并不等待接收者准备好接收其报文，发送者在送出报文后立即继续工作。

+   2) 会合。在Ada中会合模型基于三个概念：项说明、项调用和接受语句。项说明和接受语句是服务员程序的一部分，项调用在顾客端。当进程S调用进程R的一项，R为此项执行accept语句时，在S和R之间发生了相互作用，叫做会合。

```
accept incr(X: int; Y: out int)
 do Y:=X+1;
end
```
