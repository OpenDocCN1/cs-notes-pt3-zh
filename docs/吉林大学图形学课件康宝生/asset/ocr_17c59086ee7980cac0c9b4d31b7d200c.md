设要绘制的圆的圆心为 C(x_c, y_c)，半径为 R。求圆的内接多边形的常用方法有以下两种。

# 方法 1.（基于圆的极坐标表示）设圆的内接多边形的第 i 个顶点是 P_i(x_i, y_i)，CP_i 的幅角是 θ_i，则：

x_i = x_c + R cos θ_i,  y_i = y_c + R sin θ_i

设多边形每条边所对应的圆心角为 α，那么下一个顶点 P_{i+1} (x_{i+1}, y_{i+1}) 的坐标是：

x_{i+1} = x_c + R cos(θ_i + α) = x_c + (x_i - x_c) cos α - (y_i - y_c) sin α
y_{i+1} = y_c + R sin(θ_i + α) = y_c + (x_i - x_c) sin α - (y_i - y_c) cos α
