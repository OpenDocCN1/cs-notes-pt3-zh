⎡ x̄ ⎤   ⎡ a₁₁  a₁₂  a₁₃ ⎤ ⎡ x - x₀ ⎤
⎢ ȳ ⎥ = ⎢ a₂₁  a₂₂  a₂₃ ⎥ · ⎢ y - y₀ ⎥
⎣ z̄ ⎦   ⎣ a₃₁  a₃₂  a₃₃ ⎦ ⎣ z - z₀ ⎦

写成齐次坐标形式，则有：

⎡ x̄ ⎤   ⎡ a₁₁  a₁₂  a₁₃  a₁₄ ⎤ ⎡ x ⎤
⎢ ȳ ⎥   ⎢ a₂₁  a₂₂  a₂₃  a₂₄ ⎥ ⎢ y ⎥
⎢ z̄ ⎥ = ⎢ a₃₁  a₃₂  a₃₃  a₃₄ ⎥ · ⎢ z ⎥
⎣ 1 ⎦   ⎣ 0    0    0    1   ⎦ ⎣ 1 ⎦

其中：

aᵢ₄ = -(aᵢ₁ x₀ + aᵢ₂ y₀ + aᵢ₃ z₀), i = 1, 2, 3
