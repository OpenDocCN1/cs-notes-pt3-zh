# Bézier 曲线只通过多边折线的起点和终点。

下面我们通过对基函数求导，来分析两端切矢的情况。由于

```
B'_{i,n}(t) = n[ B_{i-1,n-1}(t) - B_{i,n-1}(t) ]
```

得

```
P'(t) = n \sum_{i=0}^{n-1} P_i [ B_{i-1,n-1}(t) - B_{i,n-1}(t) ]
```

```
= n \sum_{i=0}^{n-1} (P_{i+1} - P_i) B_{i,n-1}(t)
```

从而，有：

```
P'(0) = n(P_1 - P_0),  P'(1) = n(P_n - P_{n-1})
```
