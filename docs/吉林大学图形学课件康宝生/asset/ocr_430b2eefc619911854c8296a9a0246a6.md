均匀 B 样条曲线定义域内节点的分布相同，差别仅在于两端节点。这样的节点矢量定义了准均匀 B 样条基函数，对应的 B 样条曲线称为准均匀 B 样条曲线。

# ▪ 分段 Bézier 曲线（Piecewise Bézier Curve）

节点序列中两端节点为 $k+1$ 重，所有内节点均为 $k$ 重节点，即 $u_0=u_1=\cdots=u_k$，$u_{L+k}=u_{L+k+1}=\cdots=u_{L+2k}$，且

```
$$\Delta_i=u_{i+1}-u_i=\begin{cases}>0, & i=\lambda k\\=0, & i=\lambda k+j,\ j=1,\cdots,k-1\end{cases},\quad \lambda=1,2,\cdots,\frac{L+k-1}{k}$$
```
