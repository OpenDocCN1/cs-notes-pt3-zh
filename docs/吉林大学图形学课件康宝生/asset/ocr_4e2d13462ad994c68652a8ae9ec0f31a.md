# 广泛应用的时期(1970～1980)

1970 年，美国 Applicon 公司第一个推出完整的 CAD 系统。此间出现了廉价的固体电路随机存储器、产生逼真图形的光栅扫描显示器、光笔、图形输入板等多种形式的图形输入设备，如美国 Tektronix 公司发展的基于存储管技术的 4006、4010、4012、4016等图形终端，其分辨率可达4096×3072，而价格还不到 IBM2250 的一半。因此，出现了面向中小企业的商品化 CAD/CAM 系统。整个 70 年代，CAD/CAM 技术的应用已相当广泛，许多功能强大的大型系统软件相继面世，如英国飞机公司的 CONSURF 系统、Renault 公司的 UNISURF 系统
