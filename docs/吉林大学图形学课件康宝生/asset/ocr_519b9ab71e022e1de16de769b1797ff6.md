# 程序 3.2.3 Bresenham 扫描转换算法

```
void line_BRES (int xs, int ys, int xe, int ye, int Color)
{ /* 设 0 ≤ m ≤ 1 */
    int dx = xe - xs, dy = ye - ys, x = xs, y = ys;
    int twoDX = 2*dx, twoDY = 2*dy, d = 2*dy - dx;
    DrawPixel(x, y, Color);
    while(x < xe) {
        if (d > 0) {y++; d -= twoDX;}
        x++;  d += twoDY;
        DrawPixel(x, y, Color);
    }
}
```
