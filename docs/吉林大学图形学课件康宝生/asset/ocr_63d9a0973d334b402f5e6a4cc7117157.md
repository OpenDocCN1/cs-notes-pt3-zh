S''(t₀) = 0, S''(tₘ) = 0

这相当于给定关系式：

2P₀' + P₁' = 3(P₁ - P₀)/Δ₁, Pₘ₋₁' + 2Pₘ' = 3(Pₘ - Pₘ₋₁)/Δₘ

             λₘ₋₁ 2 μₘ₋₁
                λₘ 2 ] [ P₀' 
                                   P₁' 
                                   P₂' 
                                   ⋮   
                                   Pₘ₋₂'
                                   Pₘ₋₁'
                                   Pₘ' ] = [ C₀
