绘一条长为 2πR 的直线花同样的时间。该方法亦可用于椭圆内接多边形的计算。设椭圆的长短半周分别为 a 和 b，中心点坐标为 C(x_c, y_c)，对称轴平行坐标轴，则该椭圆的参数方程是：

x - x_c = a cosθ,    y - y_c = b sinθ

设椭圆的内接多边形的第 i 个顶点为 P_i (x_i, y_i)，CP_i 的幅角是 θ_i，其中：

x_i - x_c = a cosθ_i, y_i - y_c = b sinθ_i

那么，第 i + 1 个顶点 P_{i+1} (x_{i+1}, y_{i+1}) 的坐标满足：

x_{i+1} - x_c = a cos(θ_i + α), y_{i+1} - y_c = b sin(θ_i + α)
