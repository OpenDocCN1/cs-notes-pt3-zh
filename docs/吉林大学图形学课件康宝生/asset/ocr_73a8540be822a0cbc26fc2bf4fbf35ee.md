显示页，显示这一页上的图形；而同时把另一页设置成活动页，但是非显示的，程序在该活动页上绘图。当活动页上绘完图后，在互换这两个页的设置。这就相当于在“后台”绘图，整个绘图过程在后台完成，然后拿到“前台”显示。在前台显示的已经是完整的画面，如此重复。这样，画面的连续性就会有所改善。

函数 setactivepage 和函数 setvisualpage 的调用格式如下：

```
setactivepage(int pagenum);  setactivepage(int pagenum)
```

形参 pagenum 为页号。对支持两个图形页的图形卡而言，页号为 0 和 1，系统默认值为 0。
