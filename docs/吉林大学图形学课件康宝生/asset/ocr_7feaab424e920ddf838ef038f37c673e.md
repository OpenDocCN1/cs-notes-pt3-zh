```
S̄ = [ (x̄₃'' - x̄₂'')⁻¹   0   0   0
      0   (ȳ₂'' - ȳ₁'')⁻¹   0   0
      0   0   (z̄_b - z̄_c)⁻¹   0
      0   0   0   1 ]
```

那么，从观察坐标系 oxyz 到规范化坐标系 oᵥxᵥyᵥzᵥ 的变换为

```
(xᵥ, yᵥ, zᵥ, 1)ᵀ = S̄ · SH̄ · TR̄ · (x̄, ȳ, z̄, 1)ᵀ
```

同样，当透视投影的三维观察体在世界坐标系中指定时，将上式和前面的坐标变换公式合并，亦可得到从世界坐标系到规范化坐标系 oᵥxᵥyᵥzᵥ 的变换公式。
