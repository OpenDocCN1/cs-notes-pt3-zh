分别为节点向量 $U = \{u0, u1, ..., un+k\}$ 和 $V = \{v0, v1, ..., vm+l\}$ 定义。权因子 $\omega_{ij}$ 满足条件： $\omega_{00}, \ \omega_{0n}, \ \omega_{m0}, \ \omega_{mn} > 0$。

$$R_{i,k,j,l}(u,v)=\frac{\omega_{ij}N_{ik}(u)N_{jl}(v)}{\sum_{i=0}^{m}\sum_{j=0}^{n}\omega_{ij}N_{ik}(u)N_{jl}(v)}$$

称为双变量有理基函数。
