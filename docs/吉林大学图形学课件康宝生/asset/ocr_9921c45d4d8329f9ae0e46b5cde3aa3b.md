# 程序 3.2.1 DDA 扫描转换算法

```
void Line_DDA(int x0, int y0, int x1, int y1, int Color)
{
    /*设 0 ≤ m ≤ 1*/
    int x, dy, dx;
    float y, m;

    dy = y1 - y0;
    dx = x1 - x0;
    m = (float)dy / dx;
    y = y0;
    for (x = x0; x <= x1; x++){
        DrawPixel(x, (int)(y + 0.5), Color); /*置像素值为 Color*/
        y += m;
    }
}
```
