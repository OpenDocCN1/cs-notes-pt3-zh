# 7.6.1 NURBS 曲面的定义

给定 $(n+1)\times(m+1)\,(n\ge k,\ m\ge l)$ 个空间点 $d_{ij}$ 和权因子 $\omega_{ij}$, $i=0,1,\cdots,n;\ j=0,1,\cdots,m$, 张量积参数曲面：

$R(u,v)=\frac{\sum_{i=0}^{n}\sum_{j=0}^{m}\omega_{ij}d_{ij}N_{ik}(u)N_{jl}(v)}{\sum_{i=0}^{n}\sum_{j=0}^{m}\omega_{ij}N_{ik}(u)N_{jl}(v)},\ u\in[u_{k-1},u_{n+1}],v\in[v_{l-1},u_{m+1}]$
