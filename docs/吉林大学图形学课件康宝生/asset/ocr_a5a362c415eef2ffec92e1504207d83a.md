一的限制是每对混合函数之和恒等于 1。

采用两对三次混合函数：

F₀(u) = 1 − 3u² + 2u³, F₁(u) = 3u² − 2u³

G₀(v) = 1 − 3v² + 2v³, G₁(v) = 3v² − 2v³

则得到局部双三次混合 Coons 曲面片：

P(u, v) = −[−1  F₀(u)  F₁(u)] [ 0  P(u,0)  P(u,1) ] [−1]  0 ≤ u, v ≤ 1
                                      [ P(0,v)  P(0,0)  P(0,1) ] [ G₀(v) ]
                                      [ P(1,v)  P(1,0)  P(1,1) ] [ G₁(v) ]

尽管 Coons 曲面片仍然由两个直纹面相加减去一个张量积
