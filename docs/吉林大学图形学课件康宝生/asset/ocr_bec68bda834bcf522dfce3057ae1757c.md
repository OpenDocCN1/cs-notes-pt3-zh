于是，值 P(u*) 可通过递推公式求得，这就是著名的 de Boor - Cox 算法。

运用 de Boor - Cox 算法，由控制顶点： d₀, d₁, …, dₙ 求值 P(u*) 的递推过程，可列表如下：

| | | | | |
|---|---|---|---|---|
| d_{j-k+1} | | | | |
| d_{j-k+2} | d^{[1]}_{j-k+2} | | | |
| d_{j-k+3} | d^{[1]}_{j-k+3} | d^{[2]}_{j-k+3} | | |
| ⋮ | ⋮ | ⋮ | ⋱ | |
| d_{j-1} | d^{[1]}_{j-1} | d^{[2]}_{j-1} | … | d^{[k-2]}_{j-1} |
| d_{j} | d^{[1]}_{j} | d^{[2]}_{j} | … | d^{[k-2]}_{j} | d^{[k-1]}_{j} |
