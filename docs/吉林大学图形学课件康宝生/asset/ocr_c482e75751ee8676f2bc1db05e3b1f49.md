$Q_L = -(\Delta x + \Delta z),\quad D_L = x_0 + z_0$\n$Q_T = \Delta y - \Delta z,\quad D_T = z_0 - y_0$\n$Q_R = \Delta x - \Delta z,\quad D_R = z_0 - x_0$\n$Q_F = -\Delta z,\quad D_F = z_0 - z_{\min}$\n$Q_B = -(\Delta y + \Delta z),\quad D_B = y_0 + z_0$\n$Q_{FB} = \Delta z,\quad D_{FB} = 1 - z_0$\n\n其中：\n\n$\Delta x = x_1 - x_0,\ \Delta y = y_1 - y_0,\ \Delta z = z_1 - z_0$\n\n那么，规范化观察体之相应边界面和直线段交点的参数为：\n\n$t_i = \dfrac{D_i}{Q_i},\ i = L,\ R,\ B,\ T,\ F,\ FB$
