令：

d_i^{[r]}(u*) = { d_i, r=0; (u* - u_i)/(u_{i+k-r} - u_i) d_i^{[r-1]} + (u_{i+k-r} - u*)/(u_{i+k-r} - u_i) d_{i-1}^{[r-1]}, r ≠ 0 }

i = j - k + r + 1, …, j, r = 1, 2, …, k - 1

则有：

P(u*) = Σ_{i=j-k+1}^{j} d_i N_{i,k}(u*) = Σ_{i=j-k+2}^{j} d_i^{[1]} N_{i,k-1}(u*)

上式是同一条曲线 P(u) 从 k 阶 B 样条表示到 k - 1 阶 B 样条表示的递推公式。反复运用此公式，得到：P(u*) = d_j^{[k-1]}(u*)。
