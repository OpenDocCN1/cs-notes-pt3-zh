减少八叉树表示所需空间存储量的一种有效措施是线性八叉树。

线性八叉树表示与八叉树表示类似，惟一的区别是存储方式。线性八叉树是用一可变长度的一维数组存储一棵八叉树，数组中仅存储八叉树的终端结点——即描述一个物体的大小小小的立方体。对于 2^N×2^N×2^N 的空间分割，每个结点在八叉树中位置可用一八进制数表示为：

Q = q_{n-1} 8^{n-1} + q_{n-2} 8^{n-2} + … + q_1 8 + q_0

式中 q_i， i = 0, 1, …, n - 1 为八进制数，即 q_i ∈ {0, 1, …, 7}。q_0 表示该结点在其兄弟结点中的序号, q_1 是它的父结点在同辈中的
