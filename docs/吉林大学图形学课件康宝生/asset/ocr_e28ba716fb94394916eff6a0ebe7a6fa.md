+     $$0,0,\cdots,0 \quad 1,1,\cdots,1$$
+     而无内节点的节点矢量定义的次 B 样条曲线。

+   - **光滑性** $k$ 次 B 样条曲线在定义域 $[u_{k-1},u_{n+1}]$ 内 $C^{k-r}$ 阶
