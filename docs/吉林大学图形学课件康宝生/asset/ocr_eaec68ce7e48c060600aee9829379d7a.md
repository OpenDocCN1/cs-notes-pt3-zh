颠倒所得的新顶点记为 P̂_i = P_{n-i}，那么得到一条与原曲线一样的 Bézier 曲线，惟一的不同是具有相反的定向，即

P̂(t) = ∑_{i=0}^{n} P̂_i B_{i,n}(t) = ∑_{i=0}^{n} P_{n-i} B_{i,n}(t) = P(1-t)

+   - 变差缩减性（VD性质） 任一平面与 Bézier 曲线的交点数目不多于平面与控制多边形的交点数目。
+   - 保形性 Bézier 曲线的形状酷似控制多边形的形状，特别，若控制多边形为一平面凸多边形，则定义的 Bézier 曲线是一条凸曲线。
+   - 线性精度 假设控制顶点 P_i, i = 0, 1, ..., n, 均匀分布在连
