# 方式0（计数结束中断方式）

+   - （1）结果特点
+   - 计数器减1为0时，OUT升高，向CPU发中断请求。
+   - （2）过程特点
+   - 1）控制字写入。OUT=0。当控制字写入控制字寄存器后，输出端OUT变成低电平。并且在计数値减到0之前一直保持低电平。
+   - 2）计数値写入。OUT不变，仍然为低电平（OUT=0）。
+   - 3）启动方式。写入计数値。写入计数値后，必须在下一个CLK时钟脉冲到来时，计数初値才由计数初値寄存器传送到减1计数器。这样，如果计数初値为n，若GATE=1，则输出端OUT要在计数初値写入后再过n+1个CLK时钟后，才升为高电平。
+   - 4）计数期间。OUT为低电平（OUT=0）。
