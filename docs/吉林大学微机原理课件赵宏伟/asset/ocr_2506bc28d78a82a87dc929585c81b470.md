# （2）乙机接收程序

```
DATA    SEGMENT
DD1:    DB      1024  DUP(0)
DATA    ENDS
CODE    SEGMENT
        ASSUME  CS:CODE, DS:DATA
START:  MOV     AX, DATA
        MOV     DS, AX
        MOV     AL, 098H
        OUT     66H, AL      ; 送 A 口方式 0 输入控制字
        MOV     AL, 01H     ;
        OUT     66H, AL      ; 置 ACK=1（PC0=1）
        LEA     BX, DD1     ; 取接收数据内存首址
        MOV     CX, 400H    ; 接收字节数，1K
```
