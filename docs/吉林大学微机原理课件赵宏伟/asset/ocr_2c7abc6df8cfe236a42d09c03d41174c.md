# 8259A的ICW3格式

D7 D6 D5 D4 D3 D2 D1 D0
S7 S6 S5 S4 S3 S2 S1 S0

Sx 对应 IRx 的连接从片的状态
1 = IR 输入有从片, 0 = IR 输入无从片

图 3.3.5 8259A 的 ICW3 主片格式 (A0=1)

不用

| IR1 | 0 | 0 | 1 |
| IR2 | 0 | 1 | 0 |
| IR3 | 0 | 1 | 1 |
| IR4 | 1 | 0 | 0 |
| IR5 | 1 | 0 | 1 |
| IR6 | 1 | 1 | 0 |
| IR7 | 1 | 1 | 1 |
