# 2. 循环优先级方式

+   - 循环优先级方式是8259A管理优先级相同的设备时采用的中断管理方式，它包括两种：自动循环优先级方式和特殊循环优先级方式。
+   - （1）自动循环
+   - 各设备优先级相同，当某一个设备受到服务之后，它的优先级就自动地排到最后。所谓各设备优先级相同，是指它们的地位相同，受服务机会均等，但是毕竟各中断源的优先级需要排出一个顺序，否则同时有多个中断源申请中断时计算机无法处理，于是排出这样一个优先级由高到低的顺序。
+   - （2）特殊循环
+   - 特殊循环优先级方式与自动循环优先级方式的不同之处在于：在自动循环优先级方式中，某一设备在被服务之后被确定为最低优先权；而在特殊循环优先级方式中，是通过编程来确定某一设备为最低优先级。如IR5被指定为最低优先级，则IR6的优先级最高。
