# 4. DAC 1210的典型连接

+   DAC 1210的典型连接是单极性单缓冲连接，如图7.3.7所示。图中DAC 1210高8位端口地址为81H，低4位端口地址为80H，12位传送端口地址为84H。

+   假设BX寄存器中低12位数据是待转换的12位数字量，则可编写如下程序，启动DAC 1210完成一次D/A转换：

+   X1: MOV CL, 4

+   SHL BX, CL

+   MOV AL, BH ; 高8位数据

+   OUT 81H, AL ; 送高8位

+   MOV AL, BL ; 低4位数据

+   OUT 80H, AL ; 送低4位

+   OUT 84H, AL ; 送12位数据
