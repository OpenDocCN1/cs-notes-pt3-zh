# 4.6.1 USB总线

+   - USB（Universal Serial Bus）通用串行总线是外部设备通用的接口标准，由Compaq、HP、Intel、Lucent、Microsoft、NEC和Philips七家公司联合推出。USB总线是一种连接外围设备的机外总线，最多可连接127个设备，为微机系统扩充和配置外部设备提供了方便。
+   - USB 1.0标准发布于1996年，但直到1998年USB 1.1标准的颁布和支持USB功能的Windows 98的推出，USB才真正得到广泛应用。USB 1.0和USB 1.1标准的最大数据传输速率是12Mb/s，2000年公布了USB 2.0标准，将最大数据传输速率提高了40倍，达到480Mb/s。
