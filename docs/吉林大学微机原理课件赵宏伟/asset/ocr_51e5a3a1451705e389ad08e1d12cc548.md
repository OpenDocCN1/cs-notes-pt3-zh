# 例7.3.2 利用DAC 1210设计锯齿波发生器

+   - 利用DAC 1210设计一个正向锯齿波发生器，要求设计接口电路，并编制相应的接口程序。
+   - 接口电路设计参考图7.3.7。锯齿波发生程序编制如下：

```
START:  MOV  SI, 00H
X1:     MOV  BX, SI
        MOV  CL, 4
        SHL  BX, CL
        MOV  AL, BH
        OUT  81H, AL
        MOV  AL, BL
        OUT  80H, AL
        OUT  84H, AL
        CALL DELAY
        INC  SI
        JMP  X1
```
