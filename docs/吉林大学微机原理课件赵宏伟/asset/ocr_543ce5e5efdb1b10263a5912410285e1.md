# (1) 软件译码静态显示接口

+   - 例8.2.1 某8086 CPU系统通过8255A与按键开关、LED七段显示器等外部设备相连接，电路原理如图8.2.4所示。
+   - 由图可知，8255A的端口A、端口B、端口C、控制端口的地址分别为C4H、C5H、C6H、C7H。8255A工作在方式0，端口A输入，端口B输出，能够正常工作的控制字为10010000B (90H)。
+   - 电路中的LED七段显示器采用共阳极显示器，静态工作方式。在LED七段显示器段码驱动时，采用了反向驱动，所以要注意正确配置段码表。电路连接了4个按键开关K3~K0。
+   - 4个按键开关K3~K0组成了4位二进制数值（K3对应高位，K0对应低位），并对应1位十六进制数。
