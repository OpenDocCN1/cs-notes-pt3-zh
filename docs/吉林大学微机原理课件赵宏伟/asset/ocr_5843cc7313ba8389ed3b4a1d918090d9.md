# 8253控制字的格式

| D7 | D6 | D5 | D4 | D3 | D2 | D1 | D0 |
|---|---|---|---|---|---|---|---|
| SC1 | SC0 | RL1 | RL0 | M2 | M1 | M0 | BCD |

| 计数器选择 |
|---|
| 00 = 计数器 0 |
| 01 = 计数器 1 |
| 10 = 计数器 2 |
| 11 = 非法 |

| 计数方式 |
|---|
| 0 = 二进制计数 |
| 1 = BCD 码计数 |

| 工作方式 |
|---|
| 000 = 方式 0 |
| 001 = 方式 1 |
| ×10 = 方式 2 |
| ×11 = 方式 3 |
| 100 = 方式 4 |
| 101 = 方式 5 |

| 读/写格式 |
|---|
| 00 = 锁存命令，计数值锁存 |
| 01 = 只读/写低 8 位，高 8 位清 0 |
| 10 = 只读/写高 8 位，低 8 位清 0 |
| 11 = 先读/写低 8 位，后读/写高 8 位 |
