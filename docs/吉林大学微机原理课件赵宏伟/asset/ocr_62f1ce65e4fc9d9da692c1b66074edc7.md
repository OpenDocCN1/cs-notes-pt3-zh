# 方式0（计数结束中断方式）

+   - 5）计数为0时。OUT升高（OUT=1），向CPU发中断请求（如果使用中断的话）。直到CPU写入新的控制字或计数数值时，才能使OUT=0。
+   - 6）计数期间写入新的计数数值。如果计数值是一个字节，则在写入后的下一个时钟脉冲，新的计数数值由计数初值寄存器送入减1计数器，开始新的计数。
+   - 如果计数值是两个字节，则写入第一个字节时中止计数，写入第二个字节后的下一个时钟脉冲时，新的计数数值由计数初值寄存器送入减1计数器，启动计数器按新的计数数值开始计数。
+   - 7）GATE作用。GATE=0时，禁止计数，计数器停止；GATE=1时，允许计数，此时计数器从刚才断的地方开始连续计数。
+   - 8）计数值有效期限。计数值一次有效。
