# 2. 图形显示方法

+   • 显示图像的最小单位是像素，而像素又以色彩为数据描述对象。图8.3.6所示为三种典型的不同的颜色数下的像素组合形式。
+   • 如果分辨率为320×200，则共计有64000个像素点。若用1位二进制数据代表一个像素，那么这种模式最多可描述2种颜色，8个像素点占用1个字节，总共占用64000/8=8000个字节的VRAM。
+   • 若用2位二进制数据代表一个像素，那么这种模式最多可描述4种颜色，4个像素点占用1个字节，总共占用64000/4=16000个字节的VRAM。
+   • 同理，若用4位二进制数据代表一个像素，那么这种模式最多可描述16种颜色，2个像素点占用1个字节，总共占用64000/2=32000个字节的VRAM。可见，图形方式下，分辨率和像素模式决定了VRAM的大小。像素点越多，VRAM越大。颜色数越多，VRAM越大。
