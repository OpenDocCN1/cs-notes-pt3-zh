# 例8.3.4 用BIOS功能调用INT 10H

+   例8.3.4 用BIOS功能调用INT 10H，AH=0H功能来设置屏幕为640×480彩色图形方式（显示方式AL=12H），并从屏幕第10行画1条有16种颜色像素点组成的线（用功能调用0CH）。程序结束时，显示器仍在12H下。

```
DATA    SEGMENT
YS      DB 16                ; 颜色初始值为 16
DATA    ENDS
CODE    SEGMENT
        ASSUME CS:CODE, DS:DATA
MAIN    PROC
START:  MOV AX, DATA
        MOV DA, AX
        MOV AH, 0            ; 选择功能调用 0，设置显示方式
        MOV AL, 12H          ; 设置显示方式 12H
        INT 10H
        MOV CX, 639          ; 共 640 列
```
