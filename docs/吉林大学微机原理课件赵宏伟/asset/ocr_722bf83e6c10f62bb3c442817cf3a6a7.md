# 段间转移方法小结

+   - （1）任务内的控制转移可分为同一特权级间的控制转移和不同特权级间的控制转移。
+   - （2）用JMP指令通过代码段描述符，可实现同一特权级间的直接控制转移。
+   - （3）用CALL指令通过代码段描述符，可实现同一特权级间的直接控制转移，通过调用门，可实现同一特权级间或更高特权级的间接控制转移。
+   - （4）用INT指令（包括异常中断和外部中断）通过中断门/陷阱门，可实现同一特权级间或更高特权级的间接控制转移。
+   - （5）将程序控制转移给同一代码段中的另一条指令，只须使用转移或调用指令即可，此时，只需要检查段长界限，以确保转移或调用的目标不会超过当前代码段的边界。
