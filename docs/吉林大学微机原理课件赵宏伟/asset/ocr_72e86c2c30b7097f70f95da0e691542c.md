# （4）三角波发生器

```
```asm
Z1:  MOV    AL, 00H
Z2:  OUT    78H, AL
     CALL   DELAY        ; 调延时子程序
     INC    AL
     JNZ    Z2
     DEC    AL           ; 使AL=FFH
     DEC    AL           ; 使AL=FEH，消除平顶
Z3:  OUT    78H, AL
     CALL   DELAY        ; 调延时子程序
     DEC    AL
     JNZ    Z3
     JMP    Z2
```
