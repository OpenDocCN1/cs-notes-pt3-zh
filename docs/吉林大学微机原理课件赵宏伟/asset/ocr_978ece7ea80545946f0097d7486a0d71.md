# 主程序

```
LEA  SI, AAA1    ; 发送数据块首址
LEA  DI, AAA2    ; 接收数据块首址
MOV  CX, 256     ; 发送与接收合在一起的字节数
MOV  AL, [SI]    ; 取第 1 个发送的数据
OUT  60H, AL     ; 发一字符
INC  SI          ; 下一个发送数据地址
DEC  CX          ; 字节数减 1
BBB2: STI        ; 开中断
HLT              ; 等待中断
CLI              ; 关中断
DEC  CX          ; 计数
JNZ  BBB2        ; 未完、继续
MOV  AH, 4CH     ; 已完, 退出
INT  21H         ; 返回 DOS
```
