# RS-232-C接口功能定义

| 引脚号 | 符号 | 信号名称 | 编号 | 描述 |
|---|---|---|---|---|
| 1 | AA | 保护地（屏蔽） | PB | 用于设备连 |
| 2 | BA | 发送数据 | TXD | 输出数据到 modem |
| 3 | BB | 接收数据 | RXD | 由 modem 输入数据 |
| 4 | CA | 请求发送 | RTS | 至 modem, 打开 modem 的发送器 |
| 5 | CB | 清除发送（允许发送） | CTS | 由 modem 来, 指示 modem 发送就绪 |
| 6 | CC | DCE 就绪 | DSR | 由 modem 来, 指示 modem 电源接通, 也在测试时 |
| 7 | AB | 信号地（公共回路） | SGND | |
| 8 | CF | 接收信号量检测器（载波检测） | DCD | 由 modem 来, 指示 modem 接收通信信道的信号 |
| 9 | | 测试信号 | | |
| 10 | | 测试信号 | | |
| 11 | | 未定义 | | |
| 12 | SCF | 第二接收线信号检测器 | | 由 modem 来, 指示 modem 接收通信信道的信号产生 |
| 13 | SCB | 第二清除发送 | | 由 modem 来, 指示 modem 通信发送就绪 |
| 14 | SBA | 第二发送数据 | | 至 modem, 输出低速率数据 |
| 15 | DB | 发送信号码元定时（DCE 源） | TXC | 由 modem 来, 指示接收或接口数据发送的时序 |
| 16 | SSB | 第二接收数据 | | 由 modem 来, 输入低速率数据 |
| 17 | ID | 接收信号码元定时 | RXC | 由 modem 来, 指示接收或接口数据接收的时序 |
| 18 | | 未定义 | | |
| 19 | SCA | 第二请求发送 | | 至 modem, 打开 modem 的第二通信发送器 |
| 20 | CD | DTE 就绪 | DTR | 至 modem, 准备 modem 载入通信信道, 开始发送数据 |
| 21 | CG | 信号质量检测 | SQD | 由 modem 来, 接收数据中的差错率高为零时才有效 |
| 22 | CE | 振铃检测 | RI | 由 modem 来, 指示通信线路输出振铃信号 |
| 23 | CH/CI | 数据速率选择 DTE 源/DCE 源 | | 至 modem/由 modem 来, 指示两个异步端之间的速率或速率范围 |
| 24 | DA | 发送信号码元定时（DTE 源） | TXC | 至 modem, 供给 modem 发送数据时序 |
| 25 | | 未定义 | | |
