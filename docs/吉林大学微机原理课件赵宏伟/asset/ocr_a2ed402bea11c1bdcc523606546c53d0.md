# 1. 数字信号的基带传输系统模型

+   - 从数据终端或计算机设备送出的原始数据信号一般包含很低的频率成分，甚至是含有直流分量。这些频率分量的范围就是电信号的基本频带，简称基带。换句话说，当终端设备把数据信息转换为适合传送的电信号时，这个电信号所固有的频带就是基带。相应地，这种原始的电信号就是基带信号。在计算机进行串行数据通信中，计算机或数据设备产生的0和1电信号脉冲序列就是基带信号，或称数据基带信号。

+   - 在某种场合的通信中，基带信号不需要调制而直接在某些传输介质中传送。这种直接传输基带信号的系统称为基带系统。基带系统是数据通信系统中的重要组成部分。基带传输是数据通信系统中最基本的传输方式。
