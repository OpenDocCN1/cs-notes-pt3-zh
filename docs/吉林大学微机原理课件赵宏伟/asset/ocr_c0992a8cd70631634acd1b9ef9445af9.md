# 1. 系统分析

+   - 8253与CPU的接线及端口地址译码电路的设计按常规方法进行，这里不再详细讨论，只按接口电路确定地址即可。
+   - 系统主要是控制发光二极管的亮灭，亮2秒灭2秒，恰好是一个方波周期，周期为4秒，因此可用8253的方式3。
+   - 考虑由两个通道级连来产生最后的方波，其中前一个通道的CLK接2MHz，工作于脉冲频率发生器方式，产生一个脉冲波，假设脉冲波周期为4ms（250HZ），于是它的计数值为4ms ÷ 0.5μs = 8000，它的OUT输出接后一个计数器通道的CLK输入，后一个计数器通道工作于方波发生器方式，产生周期为4秒的方波，于是它的计数值为4秒 ÷ 4ms = 1000。
