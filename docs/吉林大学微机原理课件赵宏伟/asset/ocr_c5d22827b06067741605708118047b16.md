# 显示适配器

+   • EGA (Enhanced Graphics Adapter)：增强图形适配器，显示标准完全兼容CGA和MDA各种显示方式，在图形方式下分辨率为640×350，16种颜色。

+   • VGA (Video Graphics Array)：视频图形阵列适配器，显示标准完全兼容EGA的显示标准，字符窗口为9×16点阵，图形方式下分辨率为640×480，16种颜色，或320×200，256种颜色。

+   • SVGA (Super VGA)：该标准除兼容MDA、CGA、EGA、VGA的显示方式外，还支持1280×1024像素，每像素点有224种颜色，刷新频率可达75MHz。

+   • MDA、CGA、EGA、VGA的显示方式如表8.3.1所示。MDA、CGA、EGA这三种视频标准目前已基本不用。
