# 4.6.8 Centronic总线

| 引脚号 | 引脚符号 | 对打印机方向 | 功能说明 |
|---|---|---|---|
| 1 | STB̅ | 输入 | 选通脉冲信号，低电平有效 |
| 2~9 | D7-D0 | 输入 | 8位数据信息 |
| 10 | ACK̅ | 输出 | 响应信号，低电平有效 |
| 11 | BUSY | 输出 | 忙状态，高电平指示“忙” |
| 12 | PE | 输出 | 缺纸状态，高电平有效 |
| 13 | SLCT | 输出 | 选中信号 |
| 14 | AUTO FEEDXT̅ | 输入 | 自动输纸信号 |
| 15 | NC |  | 不用 |
| 16 | 0 (V) |  | 逻辑地 |
| 17 | CHASSIS-GND |  | 机壳地 |
| 18 | NC |  | 不用 |
| 19~30 | GND |  | 对应1~12引脚的接地线 |
| 31 | INIT̅ | 输入 | 初始化信号 |
| 32 | ERROR̅ | 输出 | 出错信号 |
| 33 | GND |  | 地 |
| 34 | NC |  | 不用 |
| 35 | +5 (V) |  | 电源 |
| 36 | SLCTIN̅ | 输入 | 低电平时，打印机处于被选择状态 |
