# 方式5（硬件触发选通方式）

+   - 5）计数为0：计数器减1到0时，OUT输出端输出一个CLK周期的负脉冲波，然后OUT恢复输出高电平。
+   - 6）计数期间写入新的计数値：不影响本次计数，但影响GATE上跳沿启动后的计数过程。一旦GATE重新启动，将按新的计数初值开始计数。
+   - 7）GATE作用：无论GATE=0还是GATE=1均不影响计数过程，而当GATE有上跳沿时将重新启动计数过程，按最新计数値开始计数。
+   - 8）计数値有效期限：计数値多次有效。当计数器的计数値减到0后，将自动重新装入计数値（由计数初値寄存器装入减1计数器），但并不开始计数，而是在GATE信号的上跳沿才开始计数。
