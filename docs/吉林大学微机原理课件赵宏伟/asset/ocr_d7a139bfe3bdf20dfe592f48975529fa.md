|---|---|---|---|
| 00 | 0000 0000 0000 0000 | 返回链 BACK_LINK | 返回链接 |
| 04 |  | ESP0 |  |
| 08 |  | SS0 | CPL0、1、2 的堆栈 |
| 0C |  | ESP1 |  |
| 10 |  | SS1 |  |
| 14 |  | ESP2 |  |
| 18 |  | SS2 |  |
| 1C |  | CR3 | 地址映射保护 |
| 20 |  | EIP |  |
| 24 |  | EFLAGS |  |
| 28 |  | EAX |  |
| 2C |  | ECX |  |
| 30 |  | EDX |  |
| 34 |  | EBX |  |
| 38 |  | ESP |  |
| 3C |  | EBP | 当当前任务状态 |
| 40 |  | ESI | （寄存器保护） |
| 44 |  | EDI |  |
| 48 | 0000 0000 0000 0000 | ES |  |
| 4C | 0000 0000 0000 0000 | CS |  |
| 50 | 0000 0000 0000 0000 | SS |  |
| 54 | 0000 0000 0000 0000 | DS |  |
| 58 | 0000 0000 0000 0000 | FS |  |
| 5C | 0000 0000 0000 0000 | GS | 地址映射保护 |
| 60 | 0000 0000 0000 0000 | LDT 选择符 |  |
| 64 | I/O 位图偏移地址 | 0000000000000000 T |  |
|  | 系统状态缓冲区（用于操作系统） |  |  |
|  | I/O 许可位图 |  |  |
