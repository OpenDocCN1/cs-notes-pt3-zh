# 程序设计

```
CMP    AL, 00001110B
JNZ    X2          ; 不是单键 K0 按下，转
MOV    AH, 0       ; 设置 K0 的编码
JMP    XEND

X2:   CMP    AL, 00001101B
JNZ    X3          ; 不是单键 K1 按下，转
MOV    AH, 1
JMP    XEND

X3:   CMP    AL, 00001011B
JNZ    X4          ; 不是单键 K2 按下，转
MOV    AH, 2
JMP    XEND

X4:   CMP    AL, 00000111B
JNZ    X5          ; 不是单键 K3 按下，转
MOV    AH, 3
JMP    XEND
```
