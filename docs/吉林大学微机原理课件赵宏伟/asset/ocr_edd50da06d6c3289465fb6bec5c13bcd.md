# 系统段描述符中的类型TYPE字段的格式

| TYPE | 段的类型（用途） | TYPE | 段的类型（用途） |
|------|----------------|------|----------------|
| 0000 | 未定义（无效） | 1000 | 未定义（无效） |
| 0001 | 286 TSS 描述符，非忙 | 1001 | TSS 描述符,非忙 |
| 0010 | LDT描述符 | 1010 | 未定义（保留） |
| 0011 | 286 TSS 描述符，忙 | 1011 | TSS 描述符,忙 |
| 0100 | 286 调用门描述符 | 1100 | 调用门描述符 |
| 0101 | 任务门描述符 | 1101 | 未定义（保留） |
| 0110 | 286 中断门描述符 | 1110 | 中断门描述符 |
| 0111 | 286 陷阱门描述符 | 1111 | 陷阱门描述符 |
