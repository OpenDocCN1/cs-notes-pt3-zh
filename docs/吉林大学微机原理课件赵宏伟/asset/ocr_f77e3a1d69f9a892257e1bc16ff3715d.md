# 中断服务程序

```
ZZZ3:  MOV  AL, [SI]   ; 从内存取发送数据
       OUT  60H, AL      ; 输出
       INC  SI           ; 内存地址+1
ZZZ4:  MOV  AL, 09H     ; 置位 PC4，输入中断允许
       OUT  66H, AL
       MOV  AL, 0DH      ; 置位 PC6，输出中断允许
       OUT  66H, AL
       MOV  AL, 20H      ; 送 OCW2 中断结束
       OUT  20H, AL
       IRET              ; 中断返回。
ZZZ2  ENDP
CODE  ENDS
       END  BBB1
```
