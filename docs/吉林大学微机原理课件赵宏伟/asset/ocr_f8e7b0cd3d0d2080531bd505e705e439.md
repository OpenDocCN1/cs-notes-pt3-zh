# 4. DAC 0832的电压输出电路

+   - DAC 0832为电流输出型的D/A转换器，要获得电压输出，需要外加转换电路。图7.3.3为两极运算放大器组成的模拟输出电压。

VOUT = - ( V_A / R_2 + V_REF / R_1 ) × R_3 = - ( R_3 / R_2 × V_A + R_3 / R_1 × V_REF ) = - ( 2 V_A + V_REF ) = - [ 2 × ( - V_REF / 2^8 N ) + V_REF ] = N / 128 × V_REF - V_REF = ( N - 128 ) / 128 × V_REF

+   - 如果参考电压VREF为+5V，则（mV），此时

+   - 若N=00H，V

+   - 若N=80H，V

+   - 若N=FFH，V≈+5V

+   - 可见，从VOUT输出为双极性模拟电压。电压范围是-5V～+5V。
