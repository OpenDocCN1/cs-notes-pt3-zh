# （1）甲机发送程序

```
DATA    SEGMENT
SS1:    DB      1024  DUP (?)
DATA    ENDS
CODE    SEGMENT
        ASSUME  CS:CODE, DS:DATA
START:  MOV     AX, DATA
        MOV     DS, AX
        MOV     AL, 0A0H
        OUT     66H, AL     ; 送 A 口方式 1 输出控制字
        MOV     AL, 0DH     ; 置发送中断允许 INTEA=1
        OUT     66H, AL     ; PC6=1
        LEA     BX, SS1    ; 取发送数据内存首址
        MOV     CX, 400H   ; 发送字节数, 1K
        MOV     AL, [BX]   ; 向 A 口写第一个数, 产生第一个 OBF 信号
        OUT     60H, AL    ; 送给对方, 以便获取对方的 ACK 信号
        INC     BX         ; 发送数据内存地址加 1
        DEC     CX         ; 字节数减 1
```
