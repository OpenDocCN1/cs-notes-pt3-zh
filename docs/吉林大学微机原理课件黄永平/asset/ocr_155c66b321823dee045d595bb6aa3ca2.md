例4: 数组 ARRAY 为N字数组，要求将其中正数、0、负数的个数统计出来，分别存入寄存器 DI、SI、AX 中。

```
N EQU 6
ORG 100H
XOR BX, BX
XOR AX, AX
XOR SI, SI
XOR DI, DI
MOV CX, N
AGAIN:
    CMP ARRAY[BX], 0
    JL LESS
    JE EQUAL
    INC DI ;正
    JMP NEXT
LESS:
    INC AX ;负
    JMP NEXT
EQUAL:
    INC SI ;零
    JMP NEXT;可删除本指令
NEXT:
    ADD BX, 2
    DEC CX
    JNZ AGAIN
    RET
ARRAY DW 0A205H,1000H,2385H, 0290H,0000H,8000H
```
