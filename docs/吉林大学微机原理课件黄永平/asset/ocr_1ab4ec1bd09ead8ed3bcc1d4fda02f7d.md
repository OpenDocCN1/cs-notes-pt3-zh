# 六.控制转移指令

| 名称 | 格式 | 功能 |
|---|---|---|
| 无条件转移指令 | JMP d | 无条件转移 |
| 条件转移指令 | JNZ disp8（等） | 根据上一条指令设置的标志位的情况转移 |
| 循环控制指令 | LOOP disp8 | CX≠0循环 |
|  | LOOPE/LOOPZ disp8 | 相等/结果等于0时循环 |
|  | LOOPNE/LOOPNZ disp8 | 不相等/结果不等于0循环 |
|  | JCXZ disp8 | CX=0 则转移 |
| 子程序调用及返回指令 | CALL d | 调用子程序 |
|  | RET | 从子程序返回 |
| 中断指令 | INT n | 软中断 |
|  | INTO | 溢出时中断 |
|  | IRET | 中断返回 |
