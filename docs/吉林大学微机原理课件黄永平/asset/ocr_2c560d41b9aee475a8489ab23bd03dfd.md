# 二.指令系统

因为计算机只认得二进制数码,所以计算机指令系统中的所有指令,都必须以二进制编码的形式来表示.如前面例子。

+   ① 把第一个数从它所在的存储单元中取出,送至运算器;
+   ② 把第二个数从它所在的存储单元中取出,送至运算器;
+   ③ 相加;
+   ④ 把加完的结果送至存储器中指定的存储单元.

```
A0  00  20          MOV AL, [2000H]
A8  1E  01  20      MOV BL, [2001H]
00  D8              ADD AL, BL
A2  00  30          MOV [3000H], AL
```
