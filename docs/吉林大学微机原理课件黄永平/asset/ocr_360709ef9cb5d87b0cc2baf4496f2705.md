# 几点注意（变量名，地址标号名，过程名，段名）
HYPer

2.段名，其值为段值（加载时重定位）
如用XSEG表示DSEG、CSEG、SSEG时：

```
;*****1.开始定义数据段**********
DSEG    SEGMENT 'DATA'
DSEG    ENDS

;*****2.开始定义堆栈段**********
SSEG    SEGMENT STACK 'STACK'
SSEG    ENDS

;*****3.开始定义代码段**********
CSEG    SEGMENT 'CODE'
CSEG    ENDS
END     Main ;开始进程是Main
```

! 取XSEG段地址
MOV BX, XSEG

参见MASM5.0生成的LST文件
