# 例2：与 REP 指令配合传送100个数。

```
LEA SI, Souce
LEA DI, Dest
MOV CX, 100
CLD
Again: MOVSW
DEC CX
JNZ Again
HLT
```

```
LEA SI, Souce
LEA DI, Dest
MOV CX, 100
CLD
REP MOVSW

HLT
```

+   CX不为0时重复执行
+   ① 判断CX=0？是，传送完毕；否，进行②
+   ② CX-1 → CX
+   ③ 执行REP后的串操作。
+   ④ 重复①～③
