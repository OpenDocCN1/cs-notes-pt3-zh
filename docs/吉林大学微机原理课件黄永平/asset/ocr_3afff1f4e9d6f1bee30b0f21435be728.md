# 默认段寄存器和偏移寄存器

# 16位段+偏移寻址组合

| 段 | 偏移 | 主要用途 |
|---|---|---|
| CS | IP | 指令地址 |
| DS | BX, SI, DI, Disp8, Disp16 | 数据地址 |
| SS | SP, BP | 堆栈地址 |
| ES | DI | 串操作目标地址 |

# 32位段+偏移寻址组合

| 段 | 偏移 | 主要用途 |
|---|---|---|
| CS | EIP | 指令地址 |
| DS | EAX, EBX, ECX, EDX, ESI, EDI, Disp8, Disp32 | 数据地址 |
| SS | ESP, EBP | 堆栈地址 |
| ES | EDI | 串操作目标地址 |
| FS | 无默认 | 一般地址 |
| GS | 无默认 | 一般地址 |
