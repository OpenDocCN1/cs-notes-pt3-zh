# 2. 总线控制器 8288

![](bbox=[0.05, 0.1, 0.48, 0.65])

| S0 S1 S2 | 8088 的总线周期 | 8288 的命令输出 |
|---|---|---|
| 0 0 0 | 中断响应 | INTA |
| 0 0 1 | 读 I/O 口 | IORC |
| 0 1 0 | 写 I/O 口 | IOWC, AIOWC |
| 0 1 1 | 暂停 | — |
| 1 0 0 | 取指令代码 | MRDC |
| 1 0 1 | 读存储器 | MRDC |
| 1 1 0 | 写存储器 | MWTC, AMWC |
| 1 1 1 | 过渡状态 | — |

| 输入信号 | S0 S1 S2 | 8088的状态信号 |
|---|---|---|
|  | CLK | 时钟信号 |
|  | AEN | 地址输入允许信号 |
|  | CEN | 命令允许输出信号 |
|  | IOB | I/O总线方式控制信号 |

| 8288的控制输出 | |
|---|---|
| ALE | 地址锁存允许信号 |
| DT/R | 数据发送/接收信号 |
| DEN | 数据输出允许信号 |
| MCE/PDEN | 双功能引脚 |
