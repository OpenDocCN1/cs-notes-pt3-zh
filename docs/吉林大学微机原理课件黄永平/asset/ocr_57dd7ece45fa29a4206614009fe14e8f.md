# 3.源程序结构3

MASM 32环境, com

```
; COM文件格式
;Author: hyp@jlu.edu.cn , QQ:hyper/790516 , http://www.cnblogs.com/hyper99
;---模式设置--------------------------------------------------------
.MODEL TINY ;TINY为COM文件格式
.8086
;---数据段----------------------------------------------------------
.data
    msg db "Hello World!$"
;---代码段----------------------------------------------------------
.code
.startup
    MOV DX, offset msg
    MOV AH, 9
    INT 21H

loc_end: JMP loc_end
end
```
