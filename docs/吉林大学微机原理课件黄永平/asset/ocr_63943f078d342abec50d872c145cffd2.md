# 4.7.5 宏库的使用

语句格式: INCLUDE 库文件名
假设已建立一名为MACRO.LIB的宏库，其内容如下：

```
INPUT      MACRO A
           LEA     DX, A
           MOV     AH, 10 ; 10号系统功能调用
           INT     21H
           ENDM

PRINT      MACRO A
           LEA     DX, A
           MOV     AH, 9  ; 9号系统功能调用
           INT     21H
           ENDM
```
