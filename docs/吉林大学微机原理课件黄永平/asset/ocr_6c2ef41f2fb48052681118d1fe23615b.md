# (2)指针送寄存器及DS指令

```
LDS d, s    ; d←[s] ,  DS←[s+2]
```

Rc16 ← M[s]
DS ← M[s+2]

Load memory double word into word register and DS

把源操作数指定的内存的4个相继字节的内容送至指定寄存器及DS中

+   (1) 该指令完成一个32位地址指针的传送；
+   (2) 该指令通常指定 SI 作寄存器 REG。
