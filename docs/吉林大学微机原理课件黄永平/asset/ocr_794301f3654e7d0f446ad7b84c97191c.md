# 80386指令格式：

指令前缀 OP ...

Rc：

+   - AX, BX, CX, DX, SP, BP, SI, DI
+   - AH, BH, CH, DH
+   - AL, BL, CL, DL
+   - EAX, EBX, ECX, EDX, ESP, EBP, ESI, EDI

M： EA = {EAX EBX ECX EDX ESP EBP ESI EDI} + {EAX EBX ECX EDX ... EBP ESI EDI} {1 2 4 8} + Disp8,Disp32

*Note: 45种组合。P77

无论怎样 操作数位于： 指令中 R中 M中
