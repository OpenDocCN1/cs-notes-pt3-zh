# 例1: 某数X × 10

```
MOV AL, X
MOV BL, 10
MUL BL
```

> 移位前 000000100 = 4H
> 移位后 000001000 = 8H

```
MOV AL, X
SHL AL, 1 ; X*2
MOV BL, AL ; BL=X*2
SHL AL, 1 ; X*4
SHL AL, 1 ; X*8
ADD AL, BL ; X*8+X*2=X*10
```
