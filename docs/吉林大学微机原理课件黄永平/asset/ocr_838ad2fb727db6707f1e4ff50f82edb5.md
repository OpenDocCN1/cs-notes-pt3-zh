# 移位指令的作用:

移位指令通常用来做乘2或除2的操作:

+   左移一位    操作数×2;
+   右移一位    操作数÷2

+   • 算术移位指令适用于带符号数的运算。
+   • 逻辑移位指令适用于无符号数的运算。
