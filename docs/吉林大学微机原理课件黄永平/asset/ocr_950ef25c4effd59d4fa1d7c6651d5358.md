# 系统段描述符(LDT,TSS)

LDT、TSS描述符

| 段基址(32位) | 段限(20位) | 段属性(12位) |

段属性(12位)
(LDT, SST)

+   - P段存在位(段在内存/不在)
+   - DPL(2位)特权级：0~3
+   - S分类位(非系统段/系统段描述符)：0
+   - Type(4位)类型：
+     - LDT描述符
+     - TSS 描述符(忙)
+     - TSS 描述符(闲)
+   - G段限单位位(4KB/1B)
+   - D/B位(32/16长度位)：0
+   - 兼容位：0, 扩展用
+   - AVL系统可以位(系统软件可用本段/不可)：0
