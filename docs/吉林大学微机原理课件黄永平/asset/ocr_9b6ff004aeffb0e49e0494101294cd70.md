# 例6-1：数出长度为10的，以STRING为首地址的字符串中空格的个数。

```
N EQU 10
ORG 100H
LEA SI, string
MOV CX, N
MOV AL, 20H ;空格的ASCII码为20H
MOV AH, 0H ;结果在AH中
again:
CMP AL, [SI]
JNZ next
INC AH
next:
INC SI
LOOP again
RET
string DB 41h,42h,43h,20h,45h,46h,20h,48h,20h,49h
```
