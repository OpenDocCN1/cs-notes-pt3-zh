# 2.EXE源程序结构1

MASM 5.0, Emu8086环境

DS原指向PSP,PSP第1字节位置压栈

指向自己的数据段 DSEG。

```
或者
MOV AH, 4Ch
INT 21h
```

若用上边的代码结束，主过程开始3个指令可以不用。

```
;*****1.开始定义数据段**************************
DSEG SEGMENT 'DATA'
    X DB ...
    Y DW ...
DSEG ENDS
;*****2.开始定义堆栈段**************************
SSEG SEGMENT STACK 'STACK'
    DW 100h DUP(?) ;自己的堆栈,够用就行.
SSEG ENDS
;*****3.开始定义代码段**************************

CSEG SEGMENT 'CODE'
    ASSUME CS:CSEG,DS:DSEG,SS:SSEG
;------3.0主过程开始----------------------------
Main PROC FAR
    PUSH DS ;返回地址入栈，与RET对应
    MOV AX, 0
    PUSH AX
    MOV AX, DSEG ;指向自己的数据段DSEG
    MOV DS, AX
    ;!主过程代码
    RETF ;执行PSP头首位置的int 20H,返回DOS.
Main ENDP
;------3.1子过程开始----------------------------
P_Name PROC NEAR
    ;!子过程代码
    RET
P_Name ENDP
CSEG ENDS
END Main ;开始进程是Main
```
