# 七.向保护模式的转换过程

复位
(CR0. PE=0, 实模式)

初始化IDT
(至少有前32个有效的中断门)

初始化GDT
(第1项为空描述符；至少1个代码段、1个数据段、1个堆栈段描述符)

进入到保护模式
(CR0. PE=1)

真正进入保护模式
(段内JMP指令，跳到代码段)

复位
(CR0. PE=0, 实模式)

初始化IDT
(至少有前32个有效的中断门)

初始化GDT
(第1项为空描述符；至少1个代码段、1个数据段描述符；两个TSS描述符)

初始化TR
(指向1个TSS)

进入到保护模式
(CR0. PE=1)

真正进入保护模式
(段内JMP指令，跳到代码段，执行把TSS选择符装入TR中)
