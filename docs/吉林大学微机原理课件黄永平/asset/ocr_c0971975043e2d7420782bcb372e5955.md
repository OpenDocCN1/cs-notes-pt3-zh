# 80386~Pentium II描述符

|  |  | 0 |
|1|段限(15~0)| |
|3|段基址(15~0)|2|
|5|访问权限|段基址(23~16)|4|
|7|段基址(31~24)|G D 0 AV 段限(19~16)|6|

G=1，界限x4KB(尾部添000H)。允许段长为4KB~4GB

G=0，段长为0B~1MB

D=32位指令/16位指令

AV=段有效/段无效
