# 2. 数字表达式

把常数、标号、变量与运算符组合。运算符可以是算术运算符、逻辑运算符、移位运算符、关系运算符、返回值运算符，但结果必须是常数。

```
AAA1    EQU X
DATA1   DB 12H, 34H, 56H, 78H
AAA2:   MOV AX, LENGTH DATA1
        MOV BX, TYPE AAA2
        MOV DX, (AAA1 LT 3 AND 10H OR AAA1 GE 3 AND 0AFH) SHL 2
        ;40H,0BCH
```
