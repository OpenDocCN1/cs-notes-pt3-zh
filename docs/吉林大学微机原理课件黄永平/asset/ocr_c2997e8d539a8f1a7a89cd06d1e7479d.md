# 3. I/O传送指令

HYPer

PC机中，所有I/O端口与CPU之间的通信都有IN, OUT指令完成。

# (1)I/O输入指令

```
IN AL, port8
IN AL, DX
AL ← port8, DX
```

```
IN AX, port8
IN AX, DX
AX ← port8, DX
```

Input from port into AL or AX

# (2)I/O输出指令

```
OUT port8, AL
OUT DX, AL
port8, DX ← AL
```

```
OUT port8, AX
OUT DX, AX
port8, DX ← AX
```

Output from AL or AX To port
