# 例7：有一串n个字符的字符串（ABCDEFGH IJK）存储于首地址为ASC的存储区，要求查找空格的位置。

```
N EQU 10
ORG 100H
MOV CX, N
LEA SI, ASC -1
MOV AL, 20H
AGAIN:
    INC SI
    CMP AL, [SI]
    LOOPNZ AGAIN
    JZ EXIT
    MOV SI, 0;没找到
EXIT:
    RET
ASC DB 41h,42h,43h,44h,45h,46h,47h,48h,20h,49h
```

结果：若SI=0 表示没找到空格；SI ≠0，表示找到了，SI指向空格的单元。
