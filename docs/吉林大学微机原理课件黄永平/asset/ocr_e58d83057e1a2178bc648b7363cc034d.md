# HYPer

# 3. 常量名 与 变量名

```
! 常量N
N EQU 200h
...
MOV AL, N    ;立即寻址
MOV AL, [N]  ;直接寻址
二者不同
```

```
! 取X变量值(DB类型时)
X DB 20h, 30h, 40h, 50h

MOV AL, X        ;直接寻址
MOV AL, [X]      ;直接寻址
二者等效

MOV AL, X+1      ;直接寻址
MOV AL, [X+1]    ;直接寻址
二者等效
```
