# 4.写串指令(串存入指令)

| 名称 | 格式 | 功能 | 状态标志 | 控制标志 |
| --- | --- | --- | --- | --- |
|  |  |  | O S Z A P C | D I T |
| 写字节串指令 | STOSB | 字节串存入 | 不影响 | 设置D |
| 写字串指令 | STOSW | 字串存入 | 不影响 | 设置D |
| 重复前缀 | REP | 无条件重复 | 不影响 |  |

+   - D为方向标志（Direction Flag）：
+     D=1，串操作时地址自动减量，指令 STD； D=0，串操作时地址自动增量。指令 CLD
