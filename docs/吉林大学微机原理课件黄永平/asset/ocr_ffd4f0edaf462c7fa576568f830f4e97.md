# (4)子程序调用及返回指令

CALL <调用地址>
RET

| 分类 | 名称 | 指令 | 寻址方式 |
| --- | --- | --- | --- |
| 段内调用 | 相对调用 | CALL NEAR PTR disp16 | near-标号 |
|  | 间接转移 | CALL WORD PTR d1 | R_C16,M(16位) |
| 段间调用 | 直接调用 | CALL FAR PTR addr32 | far-标号 |
|  | 间接调用 | CALL DWORD PTR d2 | M(32位) |
| 返回 | 返回 | RET, RETF |  |
|  | 带参数返回 | RET n, RETF n |  |

```
CALL disp16,
CALL BX,
CALL far ptr addr32,
CALL DWORD PTR[BX]
```
