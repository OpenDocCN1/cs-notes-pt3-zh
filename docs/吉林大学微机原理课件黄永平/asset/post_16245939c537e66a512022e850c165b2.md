## 3.串扫描指令

![](img/d63acdb9d192b1c4466c984c4275a5a3_278_0.png)

| 名称 | 格式 | 功能 | 状态标志 | 控制标志 |
| --- | --- | --- | O S Z A P C | D I T |
| 字节串扫描指令 | SCASB | 字节串扫描 | O S Z A P C | 设置D |
| 字串扫描指令 | SCASW | 字串扫描 | O S Z A P C | 设置D |
|  | REPE/REPZ | 当相等/为零重复 | 不影响 |  |
|  | REPNE/REPNZ | 当不相等/不为零重复 | 不影响 |  |

-   - D为方向标志（Direction Flag）：
-     D=1，串操作时地址自动减量，指令 STD； D=0，串操作时地址自动增量。指令 CLD
-   - REPE和REPZ是同一条指令的两种不同表示形式。
-   - REPNE和REPNZ是同一条指令的两种不同表示形式。

## (1)字节串扫描指令 SCASB

```
; AL - ES:[DI] （→Flag）
DI ← DI ±1
```

Compare bytes: AL from ES:[DI].

## (2)字串扫描指令 SCASW

```
; AX - ES:[DI] （→Flag）
DI ← DI ±2
```

Compare words: AL from ES:[DI].

* SCAS = SCASB或SCASW

常用于在某一内存缓冲区中找指定字符

## 4.写串指令(串存入指令)

| 名称 | 格式 | 功能 | 状态标志 | 控制标志 |
| --- | --- | --- | --- | --- |
|  |  |  | O S Z A P C | D I T |
| 写字节串指令 | STOSB | 字节串存入 | 不影响 | 设置D |
| 写字串指令 | STOSW | 字串存入 | 不影响 | 设置D |
| 重复前缀 | REP | 无条件重复 | 不影响 |  |

-   - D为方向标志（Direction Flag）：
-     D=1，串操作时地址自动减量，指令 STD； D=0，串操作时地址自动增量。指令 CLD

```
(1)写字节串指令 STOSB
; ES:[DI] ← AL
DI ← DI ±1
```

Store byte in AL into ES:[DI].
Update DI

```
(2)写字串指令 STOSW
; ES:[DI] ← AX
DI ← DI ±2
```

Store word in AX into ES:[DI].
Update DI

常用初始化
某一内存缓冲区

* STOS = STOSB或STOSW

## 例5：初始化内存，使其内容全部位0。

```
LEA DI, dest
MOV AL, 0
MOV CX, 30
CLD
again: STOSB
DEC CX
JNZ again
HLT
```

DI ← DI + 1
