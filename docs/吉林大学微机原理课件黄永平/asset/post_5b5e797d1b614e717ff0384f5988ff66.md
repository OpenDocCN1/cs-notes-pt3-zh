# 移位指令的作用:

移位指令通常用来做乘2或除2的操作:

- 左移一位    操作数×2;
- 右移一位    操作数÷2

- • 算术移位指令适用于带符号数的运算。
- • 逻辑移位指令适用于无符号数的运算。

## 例3： 将 带符号数 89H 乘以2。

带符号：

```
MOV AL, 89H
SHL AL, 1
```

1 0 0 0,1 0 0 1      89H=(-77H)=-119D
0 0 0 1,0 0 1 0      12H= (12H)= 18D

OF=1
错！

## 例4： 将 带符号数 0F0H 乘以2。

带符号：

```
MOV AL, 0F0H
SHL AL, 1
```

1 1 1 1,0 0 0 0      F0H=(-10H)= -16D
1 1 1 0,0 0 0 0      E0H=(-20H)= -32D

OF=0
正确！

带符号数的运算结果的正确与否看溢出位：
OF=1 溢出，结果错； OF=0 没溢出，结果正确。
无符号数的运算结果的正确与否看进位位：
CF=1 有进位，结果错； CF=0 无进位，结果正确。
