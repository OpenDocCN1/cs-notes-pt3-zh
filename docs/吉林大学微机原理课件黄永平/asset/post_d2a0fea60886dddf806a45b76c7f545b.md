## 4.7.1 宏指令

在汇编语言程序设计过程中，可以将具有一定功能，需多次重复使用，且比较短的程序段定义成一条宏指令。

使用宏指令语句可以减少程序书写错误，缩短源程序长度，使源程序编写像高级语言一样清晰、简洁。特别是使用宏库后，可以提高编程效率。

## 4.7.2 宏指令的使用过程

- 1. 宏定义
- 2. 宏调用
- 3. 宏扩展

## 1. 宏定义

（1）带参宏定义

宏指令名 MACRO 形参1，形参2，......

宏体

```
ENDM
```

（2）无参宏定义

宏指令 MACRO

宏体

```
ENDM
```

## 2. 宏调用

格式：

宏指令名 [实参1, 实参2, ……]

例如：对上面的宏定义的三种调用形式为：

```

```

```

```

```
