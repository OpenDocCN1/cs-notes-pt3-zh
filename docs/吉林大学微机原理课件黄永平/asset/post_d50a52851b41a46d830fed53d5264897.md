
## 常用的软中断

> ** 系统功能调用指令
> 
> INT 21h
> 
> ; DOS操作系统所具有的功能，用于系统功能调用。DOS引导后才有。

AH←功能号
Rc←输入参数

INT 21h

输出

DOS引导后在内存中！

## *1) 输入字符(AH = 1, 7)

```
MOV AH, 1
INT 21h
```

AH=7 无回显

输出： AL = 键盘上输入的字符的ASCII码

; 等待敲击键盘,AL中得到ASCII码

## *2) 显示字符(AH = 2)

输入： DL = 要显示字符的ASCII码

```
MOV AH, 2
INT 21h
```

; 显示DL中的ASCII码

## *3)显示字符串(AH = 9)

输入： DS:DX = 串地址，指向’ $’结束字符串

```
MOV AH, 9
INT 21h
; 显示以$字符结束的字符串。
```

```
org 100h
MOV DX, offset msg
MOV AH, 9
INT 21h
RET
msg db "hello world$"
```

## *4)输入字符串(AH = 0Ah)

输入： DS:DX = 缓冲区首地址

(第1字节=缓冲区尺寸N，第2字节=实际输入字符数)

MOV AH, 0Ah

INT 21h

```
N EQU 10;缓冲区可容纳最大字符数
ORG 100H
;--1-- 输入字符串
MOV DX, OFFSET BUFFER
MOV AH, 0AH
INT 21H
;--2--显示字符串
XOR BX, BX
MOV BL, BUFFER[1] ;取实际字符数n
MOV BUFFER[BX+2], '$' ;最后加个 '$'
MOV DX, OFFSET BUFFER + 2
MOV AH, 9
INT 21H
RET
BUFFER DB N,?, N DUP(' ')
```

## *5)终止程序并返回DOS(AH = 4Ch)

```
MOV AH, 4Ch
INT  21h
```

Return control to the operating system (stop program).

## *6)终止程序并返回DOS

```
INT  20h  ;也属于DOS专用
```

## ** BIOS中断

# INT xxh

; 在BIOS中，在主板上。

- XXh=10h ---设置显示方式等
- 13h ---磁盘读写
- 14h ---串行通信
- 16H ----取键盘缓冲区
- 19h ---引导(0面0道1扇512字节送到0000:7C00,执行.)
- 1AH ---取系统时间
- ...

在主板的ROM中---ROM BIOS!

应用程序既可以用ROM BIOS中的中断,也可以用系统功能调用INT 21H.

## *1)BIOS中断---从键盘缓冲区取键盘ASCII码

```
MOV AH , 00h
INT 16h
AL=得到的ASCII码
; 等待敲击键盘,AL中得到ASCII码
```

其它AH=01,02,03,05…

## *1)BIOS中断---显示字符

```
MOV AL , ASCII码
MOV AH , 0Eh
INT 10h
; 显示AL中的ASCII码
```
