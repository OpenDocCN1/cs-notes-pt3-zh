### 2.EXE源程序结构1

MASM 5.0, Emu8086环境

DS原指向PSP,PSP第1字节位置压栈

指向自己的数据段 DSEG。

```
或者
MOV AH, 4Ch
INT 21h
```

若用上边的代码结束，主过程开始3个指令可以不用。

```
;*****1.开始定义数据段**************************
DSEG SEGMENT 'DATA'
    X DB ...
    Y DW ...
DSEG ENDS
;*****2.开始定义堆栈段**************************
SSEG SEGMENT STACK 'STACK'
    DW 100h DUP(?) ;自己的堆栈,够用就行.
SSEG ENDS
;*****3.开始定义代码段**************************

CSEG SEGMENT 'CODE'
    ASSUME CS:CSEG,DS:DSEG,SS:SSEG
;------3.0主过程开始----------------------------
Main PROC FAR
    PUSH DS ;返回地址入栈，与RET对应
    MOV AX, 0
    PUSH AX
    MOV AX, DSEG ;指向自己的数据段DSEG
    MOV DS, AX
    ;!主过程代码
    RETF ;执行PSP头首位置的int 20H,返回DOS.
Main ENDP
;------3.1子过程开始----------------------------
P_Name PROC NEAR
    ;!子过程代码
    RET
P_Name ENDP
CSEG ENDS
END Main ;开始进程是Main
```

### 3.源程序结构3

MASM 32环境, com

```
; COM文件格式
;Author: hyp@jlu.edu.cn , QQ:hyper/790516 , http://www.cnblogs.com/hyper99
;---模式设置--------------------------------------------------------
.MODEL TINY ;TINY为COM文件格式
.8086
;---数据段----------------------------------------------------------
.data
    msg db "Hello World!$"
;---代码段----------------------------------------------------------
.code
.startup
    MOV DX, offset msg
    MOV AH, 9
    INT 21H

loc_end: JMP loc_end
end
```

    mov dl, 'B'

## 六、关于makefile

### MASM5.0下的makefile.bat

;by hyper, http://www.cnblogs.com/hyper99

```
echo 设置文件名,不用扩展名
set file=my_source_file
```

```
set CC=masm.exe
set LD=link.exe
```

```
echo 编译
%CC% %file%.asm
```

```
echo 链接
%LD% %file%.obj
```

```
echo 运行
%file%.exe
pause
```
