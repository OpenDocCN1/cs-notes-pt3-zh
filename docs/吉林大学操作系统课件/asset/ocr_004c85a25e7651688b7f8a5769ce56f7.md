# 例3. 哲学家就餐问题

```
Type dining-philosophers=MONITOR
    Var fork:Array[0..4]Of(free,used);
        q:Array[0..4]Of condition;
    define pick_up, try_pick_up, put_down;
    Procedure pick_up(I:0..4);
        Begin
            If fork[I]=used Then
                wait(q[I]);
            fork[I]:=used
        End;
```
