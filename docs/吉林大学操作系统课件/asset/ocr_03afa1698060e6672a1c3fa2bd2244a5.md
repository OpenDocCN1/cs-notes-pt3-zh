# Lamport面包店算法

```
Boolean choosing[0,...,n-1]; (false)
Int number[0,...,n-1]; (0)
Pi 进入:
1. choosing[i]=true;
2. number[i]=max{number[0],...,number[n-1]}+1;
3. choosing[i]=false;
4. For(j=0;j<n;j++){
5.     While (choosing[j]) skip;
6.     While (number[j]!=0)and
7.         (number[j],j)<(number[i],i) skip;
8. }
```
