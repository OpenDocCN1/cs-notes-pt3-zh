# # 7.8 文件系统的界面

+   - 写文件

命令形式: **write(fd,nwt,buf)**

+   参数含义:
+   - fd: 文件描述符;
+   - nwt: 写出记录个数;
+   - buf: 内存起始位置.

+   执行步骤:
+   (1) 由fd查用户打开文件表, 找到对应的入口;
+   (2) 合法性检查(用户打开文件表中所记录的打开方式、存取方式);
+   (3) 查系统打开文件表, 找到文件的地址;
+   (4) 计算欲访问起始记录的位置(物理结构, offset);
+   (5) 如果需要, 申请存储块;
+   (6) 将内存中由buf起始的nwt个记录写到文件中由当前写指针所确定的区域（可能切换进程）.
