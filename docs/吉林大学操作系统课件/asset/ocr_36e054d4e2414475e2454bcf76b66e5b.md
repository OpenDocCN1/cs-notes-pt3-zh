# 13.7.2 有关文件的系统调用命令

+   - 创建文件 `fd=creat(path_name,mode)`
+     - 分配一个 **inode**
+     - 填写目录项
+     - 以写方式打开该文件
+     - 返回文件描述符
+   - 打开文件 `fd=open(path_name,mode)`
+     - 查目录找到 **inode**
+     - 权限检查(`mode, i_mode, i_uid, i_gid, u_uid, u_gid`)
+     - 在 **file** 表中分配一个表项，指向该内存 **inode**
+     - 在 **u_ofile** 中取一表目，指向 **file** 表中对应表目
+     - 返回文件描述符 **fd**
