# 3.1.2.2 中断类型与中断向量

+   - 强迫性中断
+     - 运行程序不期望的
+       - 时钟中断
+       - IO中断
+       - 控制台中断
+       - 硬件故障中断
+         - power failure
+         - 内存校验错
+     - 程序性中断
+       - 越界，越权
+       - 缺页
+       - 溢出，除0
+       - 非法指令

+   - 自愿性中断
+     - 运行程序期望的
+       - 系统调用
+       - 访管指令
+     - 系统调用
+       - fd=open(fname,mode)
+     - 访管指令
+       - 准备参数
+       - svc n
+       - 取返回值
