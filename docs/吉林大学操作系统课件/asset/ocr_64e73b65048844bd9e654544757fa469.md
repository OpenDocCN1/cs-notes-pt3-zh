# 8.9.1 RAID级别

How to organize data across multiple disks? Industry standards scheme

+   RAID级别：行业标准规定的数据在多个磁盘上的存放方法。

+   常见RAID级别: level0, ..., level5;

+   RAID分条(stripping)数据存储方式

+   位级分条(bit-level stripping)

+   块级分条(block-level stripping)

+   RAID衡量指标

+   速度: 是否支持多个访问同时进行;

+   可靠性: 是否能够发现和改正错误;

+   成本: 是否有额外的开销和开销的大小.
