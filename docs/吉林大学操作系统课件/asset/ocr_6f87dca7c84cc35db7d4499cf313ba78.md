# 优先级别

+   - **16个实时优先级（16-31）**
+     - 一些内核线程
+     - 应用程序提升为实时优先级需要有权限
+     - 不是真正意义上的实时调度
+   - **15个可变线程优先级（1-15）**
+     - 基本优先级 vs. 当前优先级
+       - 线程基本优先级继承进程基本优先级，可上下浮动2
+         - 如: 进程基本优先级4，其线程基本优先级2—6,
+       - 当前优先级在2—15范围内变动.
+     - 可动态提升
+     - 运行完一个quantum之后自动下降，不低于基本优先级
+   - **1个系统线程优先级（0）**
