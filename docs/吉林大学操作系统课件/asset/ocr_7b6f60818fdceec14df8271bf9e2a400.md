# 4.1.4 程序并发执行的条件

+   - 例如，有如下四条语句：
+     - S1: a:=x+y
+     - S2: b:=z+1
+     - S3: c:=a-b
+     - S4: w:=c+1

+   - R(S1)={x,y}， R(S2)={z}， R(S3)={a,b}， R(S4)={c}

+   - W(S1)={a}， W(S2)={b}， W(S3)={c}， W(S4)={w}

可见， R(S1)∩W(S2)∪R(S2)∩W(S1)∪W(S1)∩W(S2)=Φ，因而S1和S2可以并发执行；而S1和S3不能并发执行，因为W(S1)∩R(S3)={a}；S2和S3也不能并发执行，因为W(S2)∩R(S3)={b}；同样，S3和S4不能并发执行，因为W(S3)∩R(S4)={c}。
