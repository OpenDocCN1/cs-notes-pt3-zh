# bread a(dev,blkno,rablkno)

参数： dev:设备号， blkno:读块号， rablkno:预读块号

返回： blk缓冲块指针rbp

# 步骤：

+   - rbp=getblk(dev,blkno)

+   - if(信息无效)
+     - 启动设备读入(d_actf/d_actl链)

+   - rabp=getblk(dev,rablkno)

+   - if (B_DONE) //缓冲区从b链得到
+     - brelse(rabp) //入av链

+   - else //缓冲区从av链得到
+     - 启动设备读入(d_actf/d_actl链) //中断时入av链

+   - iowait(rbp)

+   - return(rbp)
