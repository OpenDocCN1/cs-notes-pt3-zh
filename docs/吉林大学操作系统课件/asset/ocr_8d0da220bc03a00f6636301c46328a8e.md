# 4.3.5 管程（Monitor）

+   - **PV操作：**
+     - 分散式同步机制：共享变量操作，PV操作，散在整个系统中或各个进程中。
+     - **缺点：**
+       - 可读性差；
+       - 正确性不易保证；
+       - 不易修改。
+     - **优点：**
+       - 高效，灵活。

+   - **管程：**
+     - 集中式同步工具：共享变量及其所有相关操作集中在一个模块中。
+     - **优点：**
+       - 可读性好；
+       - 正确性易于保证；
+       - 易于修改。
+     - **缺点：**
+       - 不甚灵活，效率略低。
