# 管程实现SCAN算法

```
Procedure require(dest:0..199);\nBegin\n    If busy Then\n    Begin\n        count[dest]:=count[dest]+1;\n        wait(cylinder[dest])\n    End;\n    busy:=true;\n    If dest<headpos Then\n        direction:=down\n    Else If dest>headpos Then\n        direction:=up;\n    headpos:=dest\nEnd;
```
