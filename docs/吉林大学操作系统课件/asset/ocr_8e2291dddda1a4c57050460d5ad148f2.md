# 6.6.1 Linux 存储管理(Cont.)

# (2) Buddy heap algorithm

+   分配：申请 fn个页框
+   ① 找到相应的块组 j；
+   ② 在块组 j 的第一个空闲块分配 2^i个页框( 2^(i-1)<fn≤2^i )；
+   ③ 调整块组 j 的空闲块链表；
+   ④ 若 2^j > 2^i, 则把2^j - 2^i个空闲页框加入到相应块组空闲链中；(若2^j - 2^i不是2的整数次幂, 则将其拆分成不同的整数次幂。)
+   ⑤ 修改位图。

+   释放：释放 2^i个页框
+   ① 释放的2^i个页框与相邻的空闲区按伙伴关系合并, 即两个相邻的伙伴合并为一个大的空闲区；
+   ② 把得到的空闲区加入到不同块组的空闲链中；
+   ③ 修改位图。
