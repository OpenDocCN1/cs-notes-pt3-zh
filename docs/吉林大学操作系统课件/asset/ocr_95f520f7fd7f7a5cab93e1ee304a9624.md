# 5.5 资源分配图

定义：$G=(V,E)$，$V=P\cup R$，$P=\{p1,p2,\ldots,pn\}$，
$R=\{r1,r2,\ldots,rm\}$，

$E=\{(p_i,r_j)\}\cup\{(r_j,p_i)\}$，$p_i\in P$，$r_j\in R$。

申请边($p_i,r_j$)：$p_i$申请$r_j$；

分配边($r_j,p_i$)：$r_j$分配给$p_i$；
