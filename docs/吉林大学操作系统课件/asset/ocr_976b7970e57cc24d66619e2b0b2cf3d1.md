# 例10. 寺庙问题

```
Young_monk()
{
    do{
        P(empty);
        P(bucket);
        走到井边;
        P(mutex_well);
        井中取水;
        V(mutex_well);
        走到寺庙;
        P(mutex_bigjar);
        水入缸中;
        V(mutex_bigjar);
        V(bucket);
        V(full);
    } while(1)
}
```

old_monk()
{

        P(full);

        P(mutex_bigjar);
