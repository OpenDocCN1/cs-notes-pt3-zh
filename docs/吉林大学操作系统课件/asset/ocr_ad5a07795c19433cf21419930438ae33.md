# 7.8 文件系统的界面

+   - 读文件
+   - 命令形式: read(fd,nrd,buf)
+   - 参数说明:
+     - fd: 文件描述符;
+     - nrd: 读入记录个数;
+     - buf: 内存起始位置.
+   - 步骤:
+     - (1) 由fd查用户打开文件表，找到对应的入口;
+     - (2) 合法性检查(用户打开文件表中所记录的打开方式、存取方式);
+     - (3) 查系统打开文件表，找到文件的地址;
+     - (4) 计算欲访问起始记录的位置(offset, 物理结构);
+     - (5) 将文件中由当前读指针所确定的nrd个记录读入内存中由buf起始的区域.
