# 3.1.2.2 中断类型与中断向量

| 地址 | 向量 | 描述 |
|---|---|---|
| 0000 | PSW1, PC1 | 时钟中断向量 |
| 0008 | PSW2, PC2 | I/O中断向量 |
| 0016 | PSW3, PC3 | console中断向量 |
| 0024 | PSW4, PC4 | 硬件故障 |
| 0030 | PSW5, PC5 | 程序错误 |
| ... | ... | ... |
| 0090 | PSWn, PCn | 访管中断向量 |

PC1: 时钟中断处理程序

PC2: I/O中断处理程序

PCn: 访管中断处理程序
