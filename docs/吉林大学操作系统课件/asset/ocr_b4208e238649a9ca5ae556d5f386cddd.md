# 5.11 有关问题的讨论

+   - 关于充要性算法
+     - 已知进程关于资源活动序列
+       - 困难: 程序中的分枝与循环
+     - 复杂度高(NP Complete)
+   - 生死资源问题
+     - 消息
+     - 消耗性资源与可重用资源并存
+   - 关于可剥夺资源问题
+     - 处理器：可以剥夺，不会引起死锁
+     - 存储器：不可剥夺，当占有一部分内存的过程申请新的内存资源时，有可能发生死锁。但实现虚拟存储后，利用外存实现虚拟存储，当占有内存的过程提出新的存储请求而系统无法满足时，不让进程等待，而是为它分配外存，进程之间不会因为竞争内存资源而发生死锁。但是，若外存空间也不足时也有可能发生死锁，但这一般很罕见，因为外存空间很大。
+   - 关于两阶段封锁
+     - 增长阶段有可能死锁
