# 例4-6 简单批处理

```
PROCESS printer;
    VAR line:lineimage;
    LOOP
        REGION ob WHEN outbuff.size>0 DO
            line := outbuff.slots[outbuff.head];
            outbuff.size := outbuff.size-1;
            outbuff.head := (outbuff.head+1)MOD n;
        ENDDO
        Print line on lineprinter;
    ENDLOOP
ENDPROCESS
COEND.
```
