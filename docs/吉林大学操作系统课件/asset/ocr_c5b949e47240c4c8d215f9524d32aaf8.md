```
Program producers_consumers;
Var B:Array[0,...,k-1]Of item;
    S1,S2,mutex:semaphore;
    in,out:0..k-1;
```

```
Procedure producer
    cycle
        produce a product
        P(S1);
        P(mutex);
        B[in]:=product;
        in:=(in+1)mod k;
        V(mutex);
        V(S2)
end
```

```
Procedure consumer
    cycle
        P(s2);
        P(mutex);
        x:=B[out];
        out:=(out+1)mod k;
        V(mutex);
        V(S1);
        consume x;
end;
```
