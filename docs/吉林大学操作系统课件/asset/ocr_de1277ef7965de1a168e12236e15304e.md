# 4.1.4 程序并发执行的条件

+   - 在失去封闭性的条件下，保持可再现性。
+     - **R(pi)={a1,a2,...,am}** 表示程序 pi 在执行期间所需读取的所有变量的集合，称为“读集”；
+     - **W(pi)={b1,b2,...,bn}** 表示程序 pi 在执行期间所需改变的所有变量的集合，称为“写集”。
+     - 若有两条语句 **c=a+b** 和 **v=c-1**，则它们的“读集”和“写集”分别为:
+       - **R(c:=a+b)={a,b},  R(v:=c-1)={c}**
+       - **W(c:=a+b)={c},  W(v:=c-1)={v}**
