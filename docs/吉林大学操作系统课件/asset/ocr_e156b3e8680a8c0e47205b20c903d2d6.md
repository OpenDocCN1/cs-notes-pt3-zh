# 6.6.1 Linux存储管理

+   - Physical memory-management（物理存储管理）
+     - Three level page table（三级页表）
+     - Buddy heap algorithm for managing memory pages (frames)（伙伴堆算法管理内存）
+   - Virtual Memory management（虚拟存储管理）
+     - Demand paging（请求调页）
+       - no pre-paging,（无预调）
+       - no working set.（无工作集）
