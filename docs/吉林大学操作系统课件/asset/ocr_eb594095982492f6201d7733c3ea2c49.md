# 例6. 生产线问题

工人1活动:
Do{
    加工一个车架
    P(S1)
    P(empty)
    车架放入箱中
    V(frame)
}while(1)

工人2活动:
Do{
    加工一个车轮
    P(S2)
    P(empty)
    车轮放入箱中
    V(wheel)
}while(1)

工人3活动:
Do{
    P(frame)
    箱中取一车架
    V(empty)
    V(S1)
    P(wheel)
    P(wheel)
    箱中取二车轮
    V(empty)
    V(empty)
    V(S2)
    V(S2)
    组装成一台车
}while(1)

semaphore S1; (初值k-2, 车架)

semaphore S2; (初值k-1, 车轮)
