## 互斥例子：借书系统(revisited)

```pascal
Var mutex:semaphore; (initial value is 1)
终端1:                终端2:
CYCLE                CYCLE
等待借书者;          等待借书者;

IF x>=1 Then         IF x>=1 Then
Begin                Begin
x:=x-1;              x:=x-1;

借书                 借书
End                  End
Else 无书;           Else 无书;
End                  End
```

## 互斥例子：借书系统(revisited)

```pascal
Var mutex:semaphore; (initial value is 1)

终端1:                     终端2:
CYCLE                     CYCLE
  等待借书者;              等待借书者;
  P(mutex)                 P(mutex)
  IF x>=1 Then             IF x>=1 Then
    Begin                  Begin
      x:=x-1;               x:=x-1;
      V(mutex)              V(mutex)
      借书                   借书
    End                    End
  Else V(mutex);无书;      Else V(mutex);无书;
End                       End
```

## 例1. 生产者/消费者问题

预备知识：

组合资源：若干相对独立的资源构成的资源集合，其中每个相对独立的资源称为子资源。

同种组合资源：相同类型子资源构成的组合资源。

管理： Var S:semaphore; (初值=子资源个数)

例子： 2台打印机

```pascal
Var S:semaphore; S.value=2;
```

申请： P (S) ;

释放： V (S) ;

## 程序

```pascal
Program producers_consumers;
Var B:Array[0..k-1] Of item;
    S1,S2,mutex:semaphore;
    in,out:0..k-1;
```

```pascal
Procedure producer
    cycle
        produce a product
        P(S1);
        P(mutex);
        B[in]:=product;
        in:=(in+1)mod k;
        V(mutex);
        V(S2)
end
```

```pascal
Procedure consumer
    cycle
        P(S2);
        P(mutex);
        x:=B[out];
        out:=(out+1)mod k;
        V(mutex);
        V(S1);
        consume x;
end;
```
