# Best Splits (Cont.)

Another measure of purity is the entropy measure, which is defined as

entropy (S) = − Σ_{i-1}^{k} p_i log₂ p_i

When a set S is split into multiple sets Si, i=1, 2, ..., r, we can measure the purity of the resultant set of sets as:

purity(S₁, S₂, ....., Sᵣ) = Σ_{i=1}^{r} |Sᵢ| / |S| purity (Sᵢ)

The information gain due to particular split of S into Sᵢ, i = 1, 2, ...., r
Information-gain (S, {S₁, S₂, ...., Sᵣ}) = purity(S ) − purity (S₁, S₂, ... Sᵣ)
