# Example

+   R = (A, B, C, G, H, I)
+   F = { A ⟶ B
+         B ⟶ HI
+         CG ⟶ H }

+   R is not in 4NF since A ⟶ B and A is not a superkey for R

+   Decomposition
+   a) R₁ = (A, B)          (R₁ is in 4NF)
+   b) R₂ = (A, C, G, H, I)  (R₂ is not in 4NF, decompose into R₃ and R₄)
+   c) R₃ = (C, G, H)       (R₃ is in 4NF)
+   d) R₄ = (A, C, G, I)    (R₄ is not in 4NF, decompose into R₅ and R₆)

+   A ⟶ B and B ⟶ HI ⇒ A ⟶ HI, (MVD transitivity), and

+   and hence A ⟶ I (MVD restriction to R₄)

+   e) R₅ = (A, I)         (R₅ is in 4NF)
+   f) R₆ = (A, C, G)       (R₆ is in 4NF)
