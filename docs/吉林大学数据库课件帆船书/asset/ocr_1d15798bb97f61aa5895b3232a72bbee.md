# Fragment-and-Replicate Join (Cont.)

+   - General case: reduces the sizes of the relations at each processor.
+     - r is partitioned into n partitions, r₀, r₁, ..., rₙ₋₁; s is partitioned into m partitions, s₀, s₁, ..., sₘ₋₁.
+     - Any partitioning technique may be used.
+     - There must be at least m * n processors.
+     - Label the processors as
+     - P₀,₀, P₀,₁, ..., P₀,ₘ₋₁, P₁,₀, ..., Pₙ₋₁ₘ₋₁.
+     - Pᵢ,ⱼ computes the join of rᵢ with sⱼ. In order to do so, rᵢ is replicated to Pᵢ,₀, Pᵢ,₁, ..., Pᵢ,ₘ₋₁, while sⱼ is replicated to P₀,ⱼ, P₁,ⱼ, ..., Pₙ₋₁,ⱼ
+     - Any join technique can be used at each processor Pᵢ,ⱼ.
