# Conflict Serializability (Cont.)

+   Example of a schedule that is not conflict serializable:

| T₃ | T₄ |
| --- | --- |
| read (Q) | |
| write (Q) | write (Q) |

+   We are unable to swap instructions in the above schedule to obtain either the serial schedule < T₃, T₄ >, or the serial schedule < T₄, T₃ >.
