# Example

+   - R = (A, B, C, G, H, I)
+     F = { A → B
+       A → C
+       CG → H
+       CG → I
+       B → H }

+   - some members of F⁺
+     - A → H
+       - by transitivity from A → B and B → H
+     - AG → I
+       - by augmenting A → C with G, to get AG → CG and then transitivity with CG → I
+     - CG → HI
+       - by augmenting CG → I to infer CG → CGI, and augmenting of CG → H to infer CGI → HI, and then transitivity
