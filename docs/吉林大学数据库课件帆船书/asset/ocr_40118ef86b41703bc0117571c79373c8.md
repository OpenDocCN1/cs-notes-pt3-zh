# Example of Attribute Set Closure

+   - $R = (A, B, C, G, H, I)$
+   - $F = \{A \rightarrow B$
+     $A \rightarrow C$
+     $CG \rightarrow H$
+     $CG \rightarrow I$
+     $B \rightarrow H\}$
+   - $(AG)^+$ 
+     1. result = AG
+     2. result = ABCG  $(A \rightarrow C \text{ and } A \rightarrow B)$
+     3. result = ABCGH  $(CG \rightarrow H \text{ and } CG \subseteq AGBC)$
+     4. result = ABCGHI  $(CG \rightarrow I \text{ and } CG \subseteq AGBCH)$
+   - Is AG a candidate key?
+     1. Is AG a super key?
+        1. Does $AG \rightarrow R$? == Is $(AG)^+ \supseteq R$
+     2. Is any subset of AG a superkey?
+        1. Does $A \rightarrow R$? == Is $(A)^+ \supseteq R$
+        2. Does $G \rightarrow R$? == Is $(G)^+ \supseteq R$
