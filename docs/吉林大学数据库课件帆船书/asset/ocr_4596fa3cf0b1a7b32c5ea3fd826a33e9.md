# Size Estimation (Cont.)

+   - **Outer join:**
+     - Estimated size of $r \mathbin{\triangleright\!\!\triangleleft} s$ = size of $r \bowtie s$ + size of $r$
+       - Case of right outer join is symmetric
+     - Estimated size of $r \mathbin{\triangleleft\!\!\triangleleft} s$ = size of $r \bowtie s$ + size of $r$ + size of $s$
