# Safety of Expressions

The expression:

```
{ < x₁, x₂, ..., xₙ > | P(x₁, x₂, ..., xₙ) }
```

is safe if all of the following hold:

+   1. All values that appear in tuples of the expression are values from dom(P) (that is, the values appear either in P or in a tuple of a relation mentioned in P).
+   2. For every “there exists” subformula of the form ∃ x (P₁(x)), the subformula is true if and only if there is a value of x in dom(P₁) such that P₁(x) is true.
+   3. For every “for all” subformula of the form ∀ₓ (P₁(x)), the subformula is true if and only if P₁(x) is true for all values x from dom(P₁).
