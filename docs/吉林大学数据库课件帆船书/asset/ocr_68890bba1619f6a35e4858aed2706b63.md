# Schedule 3

Let T₁ and T₂ be the transactions defined previously. The following schedule is not a serial schedule, but it is equivalent to Schedule 1.

| T₁ | T₂ |
|---|---|
| read (A)
A := A - 50
write (A) | |
| | read (A)
temp := A * 0.1
A := A - temp
write (A) |
| read (B)
B := B + 50
write (B)
commit | |
| | read (B)
B := B + temp
write (B)
commit |

Note -- In schedules 1, 2 and 3, the sum “A + B” is preserved.
