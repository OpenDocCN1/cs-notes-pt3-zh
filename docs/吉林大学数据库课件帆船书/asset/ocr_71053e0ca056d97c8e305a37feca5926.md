# Estimation of Number of Distinct Values

Selections: σθ(r)

+   - If θ forces A to take a specified value: V(A,σθ(r)) = 1.
+     - e.g., A = 3
+   - If θ forces A to take on one of a specified set of values: V(A,σθ(r)) = number of specified values.
+     - (e.g., (A = 1 ∨ A = 3 ∨ A = 4)),
+   - If the selection condition θ is of the form A op r estimated V(A,σθ(r)) = V(A.r) * s
+     - where s is the selectivity of the selection.
+   - In all the other cases: use approximate estimate of min(V(A,r), nσθ(r))
+     - More accurate estimate can be got using probability theory, but this one works fine generally
