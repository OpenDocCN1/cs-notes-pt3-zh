# Grouping and Aggregation

+   Nested queries are used for grouping

```
for $d in /university/department
return
  <department-total-salary>
    <dept_name> { $d/dept name } </dept_name>
    <total_salary> { fn:sum(
      for $i in /university/instructor[dept_name = $d/dept_name]
      return $i/salary
    ) }
    </total_salary>
  </department-total-salary>
```
