# Size Estimation of Complex Selections

The **selectivity** of a condition θᵢ is the probability that a tuple in the relation r satisfies θᵢ.

+   - If sᵢ is the number of satisfying tuples in r, the selectivity of θᵢ is given by sᵢ / nᵣ.

**Conjunction:** σ_{θ₁∧θ₂∧...∧θₙ}(r). Assuming independence, estimate of tuples in the result is: nᵣ * (s₁ * s₂ * ... * sₙ) / nᵣⁿ

**Disjunction:** σ_{θ₁∨θ₂∨...∨θₙ}(r). Estimated number of tuples: nᵣ * (1 - (1 - s₁/nᵣ) * (1 - s₂/nᵣ) * ... * (1 - sₙ/nᵣ))

**Negation:** σ_{¬θ}(r). Estimated number of tuples: nᵣ − size(σ_θ(r))
