# Schedule 1

+   - Let $T_1$ transfer $50 from $A$ to $B$, and $T_2$ transfer 10% of the balance from $A$ to $B$.
+   - An example of a **serial** schedule in which $T_1$ is followed by $T_2$ :

| $T_1$ | $T_2$ |
|---|---|
| read (A) | |
| $A := A - 50$ | |
| write (A) | |
| read (B) | |
| $B := B + 50$ | |
| write (B) | |
| commit | |
| | read (A) |
| | $temp := A * 0.1$ |
| | $A := A - temp$ |
| | write (A) |
| | read (B) |
| | $B := B + temp$ |
| | write (B) |
| | commit |
