# Other Operations : Set Operations

+   - **Set operations** (∪, ∩ and —): can either use variant of merge-join after sorting, or variant of hash-join.
+   - E.g., Set operations using hashing:
+     1. Partition both relations using the same hash function
+     2. Process each partition *i* as follows.
+        1. Using a different hashing function, build an in-memory hash index on *rᵢ*.
+        2. Process *sᵢ* as follows
+           - *r* ∪ *s*:
+             1. Add tuples in *sᵢ* to the hash index if they are not already in it.
+             2. At end of *sᵢ* add the tuples in the hash index to the result.
