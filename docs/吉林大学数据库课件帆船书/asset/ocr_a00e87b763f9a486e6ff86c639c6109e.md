# Deadlock Handling

![](bbox=[0.0, 0.04, 0.1, 0.15])

Consider the following two transactions and history, with item X and transaction T₁ at site 1, and item Y and transaction T₂ at site 2:

T₁: write (X)
write (Y)

T₂: write (Y)
write (X)

|  |  |
|---|---|---|
| X-lock on X
write (X)

Wait for X-lock on Y | X-lock on Y
write (Y)
wait for X-lock on X | |

Result: deadlock which cannot be detected locally at either site
