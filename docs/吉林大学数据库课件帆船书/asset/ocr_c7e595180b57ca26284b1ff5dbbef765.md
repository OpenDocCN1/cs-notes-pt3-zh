# More Complex Notions of Serializability

+   The schedule below produces the same outcome as the serial schedule < T₁, T₅ >, yet is not conflict equivalent or view equivalent to it.

| T₁ | T₅ |
|---|---|
| read (A)
A := A - 50
write (A) | |
| | read (B)
B := B - 10
write (B) |
| read (B)
B := B + 50
write (B) | |
| | read (A)
A := A + 10
write (A) |

+   If we start with A = 1000 and B = 2000, the final result is 960 and 2040

+   Determining such equivalence requires analysis of operations other than read and write.
