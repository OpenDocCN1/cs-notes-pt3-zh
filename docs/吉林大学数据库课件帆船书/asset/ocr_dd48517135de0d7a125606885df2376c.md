# Estimation of Distinct Values (Cont.)

Joins: r ⋈ s

+   If all attributes in A are from r
+       estimated V(A, r ⋈ s) = min (V(A,r), n_r ⋈ s)

+   If A contains attributes A1 from r and A2 from s, then estimated V(A,r ⋈ s) = 
+       min(V(A1,r)*V(A2 − A1,s), V(A1 − A2,r)*V(A2,s), n_r ⋈ s)

+   More accurate estimate can be got using probability theory, but this one works fine generally
