# Automatic Acquisition of Locks

+   - A transaction Tᵢ issues the standard read/write instruction, without explicit locking calls.
+   - The operation **read(D)** is processed as:
+     if Tᵢ has a lock on D
+     then
+       read(D)
+     else begin
+       if necessary wait until no other transaction has a **lock-X** on D
+       grant Tᵢ a **lock-S** on D;
+       read(D)
+     end
