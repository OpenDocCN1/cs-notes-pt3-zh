# Best Splits (Cont.)

+   - Measure of “cost” of a split:
+     Information-content (S, {S₁, S₂, ....., Sᵣ})) = - Σᵢ₌₁ʳ (|Sᵢ|/|S|) log₂ (|Sᵢ|/|S|)

+   - Information-gain ratio = Information-gain (S, {S₁, S₂, ......, Sᵣ}) / Information-content (S, {S₁, S₂, ....., Sᵣ})

+   - The best split is the one that gives the maximum information gain ratio
