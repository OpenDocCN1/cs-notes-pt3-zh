# Redundancy in 3NF

+   There is some redundancy in this schema

+   Example of problems due to redundancy in 3NF

+   R = (J, K, L)
+   F = {JK → L, L → K}

| J | L | K |
|---|---|---|
| j₁ | l₁ | k₁ |
| j₂ | l₁ | k₁ |
| j₃ | l₁ | k₁ |
| null | l₂ | k₂ |

+   repetition of information (e.g., the relationship l₁, k₁)

+   (i_ID, dept_name)

+   need to use null values (e.g., to represent the relationship l₂, k₂ where there is no corresponding value for J).

+   (i_ID, dept_name1) if there is no separate relation mapping instructors to departments
