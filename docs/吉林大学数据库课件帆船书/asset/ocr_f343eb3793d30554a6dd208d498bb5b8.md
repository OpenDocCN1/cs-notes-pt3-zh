# Relational Algebra

![](bbox=[0.0, 0.0, 0.09, 0.12])

+   - Procedural language
+   - Six basic operators
+     - select: σ
+     - project: Π
+     - union: ∪
+     - set difference: −
+     - Cartesian product: x
+     - rename: ρ
+   - The operators take one or two relations as inputs and produce a new relation as a result.
