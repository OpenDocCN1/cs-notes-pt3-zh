# 6.5.3 构造哈夫曼树算法

设有字符串：“AABBСBABDC“
则权值为w={3,4,2,1}

```
for(i=n+1;i<=m;++i)
{
    select(ht,i-1,s1,s2);
    ht[s1].parent=i;
    ht[s2].parent=i;
    ht[i].lchild=s1;
    ht[i].rchild=s2;
    ht[i].weight=
    ht[s1].weight+ht[s2].weight
}
```

| weight | parent | lchild | rchild |
|---|---|---|---|
| 3 | 6 | 0 | 0 |
| 4 | 7 | 0 | 0 |
| 2 | 5 | 0 | 0 |
| 1 | 5 | 0 | 0 |
| 3 | 6 | 3 | 4 |
| 6 | 7 | 1 | 5 |
| 10 | 0 | 2 | 6 |

注意：此时i=5
