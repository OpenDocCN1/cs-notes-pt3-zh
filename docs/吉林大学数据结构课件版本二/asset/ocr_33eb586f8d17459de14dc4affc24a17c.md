# 2、孩子表示法

孩子结点：

```
typedef struct CNode
{
    int child;
    struct cnode *next;
}*ChildPtr;
```

//该节点在表头数组中下标

//指向下一孩子结点

表头结点：

```
typedef struct
{
    TElemType data;      //数据域
    ChildPtr firstchild; //指向第一个孩子结点
}CTBox;
```

//数据域

//指向第一个孩子结点

```
typedef struct
{
    CTBox nodes[MAX_TREE_SIZE];
    int n ,r; //节点数和根的位置
}CTree;
```
