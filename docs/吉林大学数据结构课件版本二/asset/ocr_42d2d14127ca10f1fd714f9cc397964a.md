```
void bubble_sort(int a[],int n){
    for(i=n+1,change=true;i>1&&change;--i){
        change=false;
        for(j=0;j<i;++j)
            if(a[j]>a[j+1]){
                a[j] <-> a[j+1];
                change=true;
            }
    }
}
```

输入数据影响时间复杂度，如果a是递增序列，那么基本操作执行次数为0，如果a是递减序列，则基本操作的执行次数为n(n-1)/2
一般我们讨论的时间复杂度均指最坏情况。
