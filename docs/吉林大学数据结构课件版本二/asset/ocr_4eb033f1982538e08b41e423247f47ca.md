# 二叉树的中序遍历（L T R）的非递归算法

```
Status InorderTraverse(BiTree T)
{
    InitStack(S);
    Push(S,T);
    While(!StackEmpty(S))
    {
        While(GetTop(S,p)&&p)Push(S,p->lchild);
        Pop(S,p);
        if(!StackEmpty(S))
        {
            Pop(S,p);
            if(! Visit(p->data))  return ERROR;
            Push(S,p->rchild);
        }
    }
}
```
