# 二叉树的先序遍历（T L R）的非递归算法

```
Status PreorderTraverse(BiTree T)
{
    InitStack(S);
    p=T;
    While(p || !StackEmpty(S))
    {
        if(p)
        {
            if(! Visit(p->data))  return ERROR;
            Push(S,p);
            p=p->lchild;
        }
        else
        {Pop(S,p);      p=p->rchild ; }
    }
    return(OK);
}
```
