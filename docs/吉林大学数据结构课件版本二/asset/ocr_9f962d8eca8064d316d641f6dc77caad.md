# 双向循环链表插入（在i之前）算法

```
Status ListInsert ( DulinkList &L, int i, ElemType e )
{
    //第1个位置之后插入元素。
    if ( !(p == GetElemP_Dul(L,i)) )
        return error;
    //指针定位于插入位置
    if(! s = ( DuLinkList ) malloc ( sizeof ( DulNode ) ))
        return error;
    //分配结点
    s->data = e;
    s->prior = p->prior;    p->prior = s;
    //在前驱方向链入新结点
    s->next = p;            s->prior->next = s;
    //在后继方向链入新结点
    return OK;
}
```
