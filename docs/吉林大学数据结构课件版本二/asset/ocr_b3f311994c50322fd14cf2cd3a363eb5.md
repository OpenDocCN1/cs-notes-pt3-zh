# 6.4.1 树的存储结构

+   2、孩子表示法

+   多重链表：每个节点有多个指针域，分别指向其子树的根

+   节点同构：节点的指针个数相等，为树的度D

+   节点不同构：节点指针个数不等，为该节点的度d

| data | child1 | child2 | ........ | childD |

| data | degree | child1 | child2 | ........ | childd |

+   孩子链表：每个节点的孩子节点用单链表存储，再用含n个元素的结构数组指向每个孩子链表
