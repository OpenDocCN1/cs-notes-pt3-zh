# 二叉排序树的删除算法

被删除的结点左右子树均不空: else

Key =50

![](bbox=[0.045, 0.3, 0.52, 0.82])

```
q = p; s = p->lchild;
while (s->rchild)
{ q = s; s = s->rchild; }
```

// s 指向被删结点的前驱

```
p->data = s->data;
```

```
if (q != p)
q->rchild = s->lchild;
```

```
else
q->lchild = s->lchild;
```

// 重接*q的左子树

```
delete(s);
```
