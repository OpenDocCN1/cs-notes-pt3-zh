# 6.5.3 求哈夫曼编码算法

设有字符串： “AABBСBABDC“ 则权值为w={3,4,2,1}

```
start=n-1;
for(c=i;f=ht[i].parent;
f!=0;c=f,f= ht[f].parent)
if(ht[f].lchild==c)
cd[--start]="0";
else cd[--start]="1";
hc[i]=(char*)malloc
((n-start)*sizeof(char*));
Strcpy(hc[i],&cd[start]);
free(cd);}
```
