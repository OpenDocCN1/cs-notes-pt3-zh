# 二叉树的中序遍历（L T R）的非递归算法

```
Status InorderTraverse(BiTree T)
{
    InitStack(S);
    p=T;
    While(p || !StackEmpty(S))
    {
        if(p) {Push(S,p);  p=p->lchild;}
        else
        {
            Pop(S,p);
            if(! Visit(p->data))  return ERROR;
            p=p->rchild ;
        }
    }
    return(OK);
}
```
