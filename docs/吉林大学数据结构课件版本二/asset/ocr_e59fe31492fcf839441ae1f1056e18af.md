# 算法实现

+   - 以邻接表作存储结构
+   - 把邻接表中所有入度为0的顶点进栈
+   - 栈非空时，输出栈顶元素Vj并退栈；在邻接表中查找Vj的直接后继Vk，把Vk的入度减1；若Vk的入度为0则进栈
+   - 重复上述操作直至栈空为止。若栈空时输出的顶点个数不是n，则有向图有环；

```
邻接表结点:
typedef struct node
{
int vex; //顶点域
struct node *next; //链域
}JD;
```

```
表头结点:
typedef struct tnode
{
vextype data;
int in; //入度域
struct node *link; //链域
}TD;
TD g[M]; //g[0]不用
```
