# 双向循环链表插入 (在i之后)算法

```
Status Insert ( DulinkList &L, int i, ElemType e )
{
    //在第i个位置之后插入元素e
    if ( !(p=GetElemP_Dul(L,i)) )
        return ERROR;    //指针定位于插入位置
    if(!(s = ( DuLinkList ) malloc ( sizeof ( DulNode ) ));
        //分配结点
    s->data = e;
    s->prior = p;    p->next->prior = s;
        //在前驱方向链入新结点
    s->next = p->next;  p->next = s;
        //在后继方向链入新结点
    return OK;
}
```
