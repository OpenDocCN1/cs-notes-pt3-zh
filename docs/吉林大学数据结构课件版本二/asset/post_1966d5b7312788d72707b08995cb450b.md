### 应用一：数制的转换

例如 (1348)₁₀ = (2504)₈，其运算过程如下：

| n | n div 8 | n mod 8 |
| --- | --- | --- |
| 1348 | 168 | 4 |
| 168 | 21 | 0 |
| 21 | 2 | 5 |
| 2 | 0 | 2 |
| 0 | 0 | 0 |

八进制数如下：2 5 0 4

```c
void conversion() {
    InitStack(s);
    scanf("%d", &n);
    while (n) {
        Push(s, n % 8);
        n = n / 8;
    }
    while (!StackEmpty(s)) {
        Pop(s, e);
        printf("%d", e);
    }
}
```

### 应用二：括号匹配的检验

假设表达式中允许括号嵌套，则检验括号是否匹配的方法可用“期望的急迫程度”这个概念来描述。例：

( ( ) ( ) ( ( ) ) )

### 应用二：括号匹配的检验编程思想

- 设置一个栈 st，用 i 扫描表达式 exp
- 遇到 `"("`、`"{"`、`"["` 时，将其入栈
- 遇到 `")"`、`"}"`、`"]"` 时，要判断栈顶元素是不是和它匹配的括号
- 若不是，则退出扫描过程，返回 0
- 否则栈顶元素出栈
- 直到 exp 扫描完毕为止
- 若 top == 0，则匹配成功，返回 1

算法如下：

```c
int match(char *exp)
{
    top = 0; // 注意：与前面 top = -1 相比较
    i = 0;
    nomatch = 0;
    while (exp[i] != '\0' && nomatch == 0) {
        switch (exp[i]) {
            case '(':
                st[top] = exp[i];
                top++;
                break;
            case '[':
                st[top] = exp[i];
                top++;
                break;
            case '{':
                st[top] = exp[i];
                top++;
                break;
            case ')':
                if (st[top - 1] == '(') top--;
                else nomatch = 1;
                break;
            case ']':
                if (st[top - 1] == '[') top--;
                else nomatch = 1;
                break;
            case '}':
                if (st[top - 1] == '{') top--;
                else nomatch = 1;
                break;
        }
        i++;
    }
    if (nomatch == 0 && top == 0) return 1;
    else return 0;
}
```

### 应用三：行编辑程序

- 在编辑程序中，设立一个输入缓冲区，用于接受用户输入的一行字符，然后逐行存入用户数据区。允许用户输入错误，并在发现有误时可以及时更正。

### 应用三：行编辑程序——算法的基本思想

- 首先，初始化一个栈
- 当全文没有结束时，本行的输入也没有结束时
  - 当输入普通字符时，入栈；
  - 当输入字符如果是 `#` 则退栈；
  - 否则如果是 `@` 则清空栈；
- 重复执行直到本行的输入结束
- 如果该行结束但是全文没有结束，则重新清空栈并且重复执行直到全文结束

```c
void lineedit()
{
    InitStack(s);
    ch = getchar();
    while (ch != EOF) {
        while (ch != EOF && ch != '\n') {
            switch (ch) {
                case '#':
                    Pop(s, c);
                    break;
                case '@':
                    ClearStack(s);
                    break;
                default:
                    Push(s, ch);
                    break;
            }
            ch = getchar();
        }
        ClearStack(s);
        if (ch != EOF) ch = getchar();
    }
    DestroyStack(s);
}
```

### 应用四：表达式求值

```c
OperandType EvaluateExpression()
{
    InitStack(OPTR);
    Push(OPTR, '#');
    InitStack(OPND);
    c = getchar();
    while (c != '#' || GetTop(OPTR) != '#') {
        if (!In(c, OP)) { // 不是运算符则进栈
            Push(OPND, c);
            c = getchar();
        } else {
            switch (Precede(GetTop(OPTR), c)) {
                case '<':
                    Push(OPTR, c);
                    c = getchar();
                    break;
                case '=':
                    Pop(OPTR, x);
                    c = getchar();
                    break;
                case '>':
                    Pop(OPTR, theta);
                    Pop(OPND, b);
                    Pop(OPND, a);
                    Push(OPND, Operate(a, theta, b));
                    break;
            } // switch
        }
    } // while
    return GetTop(OPND);
}
```

n! = { 1, 当 n = 0 时

求解阶乘函数的递归算法

```c
long Fac(long n) {
    if (n == 0) return 1;
    else return n * Fac(n - 1);
}
```

## 队列

- **定义：**只允许在表的一端进行插入，而在另一端删除元素的线性表。
- 在队列中，允许插入的一端叫**队尾**（rear），允许删除的一端称为**队头**（front）。

有线性表（a₁，a₂，a₃，…，aₙ）采用队列的方式存储。

## 链队列：队列的链式表示

- 链队列中，有两个分别指示队头和队尾的指针。
- 链式队列在进队时无队满问题，但有队空问题。

## 链式队列的定义

```c
typedef struct QNode {
    QElemType data;      // 队列结点数据
    struct QNode *next;  // 结点链指针
} QNode, *QueuePtr;
```

```c
typedef struct {
    QueuePtr rear, front;
} LinkQueue;
```

## 链队列的主要操作

### 初始化

```c
void InitQueue(LinkQueue &Q)
{
    Q.rear = Q.front = (QueuePtr) malloc(sizeof(QNode));

    if (!Q.front) exit(OVERFLOW);

    Q.front->next = NULL;

    return OK;
}
```
