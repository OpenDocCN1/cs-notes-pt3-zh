int Insert ( LinkList& L, int i, ElemType e )

## 表头结点

- 表头结点位于表的最前端，本身不带数据，仅标志表头。
- 设置表头结点的目的:
  - 简化链表操作的实现
  - 空表和非空表的处理统一

int Listdelete_L( LinkList L, int i ,elemtype &e)
{
    //将链表第 i 号元素删去
    p = LocateElem_Sq( L, i-1 ); //寻找第i-1个结点
    if ( p == NULL || p->next == NULL) return 0;
    q = p->next;
    p->next = q->next;          //删除结点
    e=q->data;      free( q );      //释放
    return OK;
}

## 前插法建立单链表的基本思想

- 从一个空表开始，重复读入数据：
  - 生成新结点
  - 将读入数据存放到新结点的数据域中
  - 将该新结点插入到链表的前端
  - 直到读入n个数据为止。
