# 双向循环链表删除的算法

```
Status ListDelet_Dul ( DulinkList &L, int i ,ElemType &e)
{
    if (!(p = GetElemP_Dul ( L, i )))
        return ERROR;    // 指针位于删除结点位置
    
    e=p->data;
    p->prior->next = p->next;
    p->next->prior = p->prior;
    
    // 删除结点 p
    free ( p );    // 释放
    return OK;
}
```

# 顺序表与链表的比较

## 基于空间的比较

+   • **存储分配的方式**
+     - 顺序表的存储空间是静态分配的
+     - 链表的存储空间是动态分配的

+   • **存储密度** = 结点数据本身所占的存储量 / 结点结构所占的存储总量
+     - 顺序表的存储密度 = 1
+     - 链表的存储密度 < 1

# 顺序表与链表的比较

## 基于时间的比较

+   - 存取方式
+     - 顺序表随机存取
+     - 链表是顺序存取

+   - 插入/删除时移动元素个数
+     - 顺序表平均需要移动近一半元素
+     - 链表不需要移动元素，只需要修改指针
