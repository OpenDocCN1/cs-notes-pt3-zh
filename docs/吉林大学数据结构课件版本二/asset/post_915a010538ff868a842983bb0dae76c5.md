## 入队的基本思想

- 生成新结点，分配不成功，退出
- 否则，将读入数据存放到新结点的数据域中
- 将新结点加在链表的表尾；
- 尾指针rear后移 指向表中最后一个结点

## 链队列的主要操作

## 带头结点的出队的基本思想

- 首先判断队列是否空，若空，返回0。
- 否则，p指向队头，并保存队头的值。
- 删除队头结点，若删除的是队列中最后一个结点，则重置尾指针
- 释放被删除结点

## 出队

```
Status DeQueue(LinkQueue &Q, Qelemtype &e)
{
    //删除队头结点，并返回队头元素的值
    if (Q.front==Q.rear) return ERROR;    //判队空
    p = Q.front->next;
    e = p->data;                          //保存队头的值
    Q.front->next = p->next;              //新队头
    if (Q.front->next==NULL) Q.rear = Q.front;
    free(p);
    return OK;
}
```

注：与书中p62不同

## 循环队列 (Circular Queue)

- 队头、队尾指针加1，可用取模(余数)运算实现。
- 队头指针进1： front=(front+1) %MAXQSIZE;
- 队尾指针进1： rear =(rear+1) % MAXQSIZE;
- 队列初始化： front = rear = 0;

## 循环队列（Circular Queue）

- **判断队空队满的方法：**
  - 设一个布尔变量以区别队列的空和满；
  - 其二是少用一个元素的空间，约定入队前，测试尾指针在循环移动下加1后是否等于头指针，若相等则认为队满

## 循环队列 (Circular Queue)

- 队空条件： front == rear;
- 队满条件： (rear+1) % MAXQSIZE == front;

![](img/df7a4356658bc366c52d5e361f054231_241_0.png)

## 循环队列的类型定义

```
#define MAXQSIZE 100
```

```
Typedef struct{
QElemType *base;
int front;
int rear;
} SqQueue;
```

## 循环队列操作的实现

- 初始化队列

```
Status InitQueue ( SqQueue &Q )
{
//构造空队列
Q.base = (QElemType *)malloc(MAXQSIZE * sizeof(QElemType));
If(! Q.base) exit(OVERFLOW);
Q.rear = Q.front = 0;
Return OK;
}
```

- 判队空
```c
int QueueEmpty ( SqQueue Q )
{
    return Q.rear == Q.front;
}
```

- 判队满
```c
int QueueFull ( SqQueue Q )
{
    return (Q.rear+1) % MAXQSIZE == Q.front;
}
```

## 求队列的长度

- int Queuelength(SqQueue Q)
- {
- return(Q.rear-Q.front+MAXQSIZE)%
- MAXQSIZE;
- }

## 出队

```
Status DeQueue( SqQueue &Q, QElemType e )
{
    if ( QueueEmpty(Q) ) return ERROR;
    e = Q.base[Q.front];
    Q.front = ( Q.front+1 ) % MAXQSIZE;
    return OK;
}
```

## 队列的实际应用

- 一、打印机软件设计
计算机的打印机输出缓冲区应用了队列结构
- 二、在智能排队系统中的队列
智能排队系统是运用计算机软件构成虚拟队列，代替由真实的人员组成的各种长长短短的队列

## 应用实例：医院病人排队系统

- 设计一个程序，反映病人到医院看病，排队看医生的情景，请考虑一下几种情况：
  - 排队
  - 看医生
  - 察看排队
  - 医生下班
- 要求采用链式队列

## 应用实例：医院病人排队系统

- 首先创建一个空队列
- 利用switch语句判断以下四种情况:
- 医生下班: 提示病人明天看病，停止循环
- 排队: 分配一个新结点，存入患者姓名，入队
- 看医生: 判断队列是否为空，若空，输出没有病人，否则输出轮到看病的患者名，并且出队
- 察看排队: 判断队列是否为空，若空，输出没有病人，否则输出排队的患者名
