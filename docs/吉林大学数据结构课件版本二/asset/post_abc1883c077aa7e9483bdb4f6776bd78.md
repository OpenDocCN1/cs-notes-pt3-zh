## 三. 二叉树遍历的非递归算法
中序遍历（L T R）的非递归算法。

利用栈来实现：

- 1) 将根节点入栈，
- 2) 当栈顶指针非空时，应沿着左链遍历，将指向根节点的左孩子指针入栈。直到栈顶指针空。
- 3) 若栈顶纪录中的指针值空时，应退至上一层，
- 4) 若从左子树返回，则访问栈顶纪录中指针所指的根节点。
- 5) 若从右子树返回，表明当前层的遍历结束，应继续退栈

- - 首先分别求出左右子树的高度
- - 在此基础上得出该棵树的高度，即左右子树较大的高度值加1。

## 2 求二叉树的高度

```c
int hight(BTree BT)
{
 //h1和h2分别是以上BT为根的左右子树的高度
 if (BT==NULL) return 0;
 else {
 h1=hight(BT->lchild);
 h2=hight(BT->right);
 return max{h1,h2}+1;
 }
}
```
