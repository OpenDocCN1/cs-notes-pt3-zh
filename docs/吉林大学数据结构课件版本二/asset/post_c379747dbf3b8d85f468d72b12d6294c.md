## 后插法建立单链表

### 后插法建立单链表的基本思想

+   从一个空表开始，重复读入数据：
+   - 生成新结点
+   - 将读入数据存放到新结点的数据域中
+   - 每次将新结点加在链表的表尾；

尾指针 r ，总是指向表中最后一个结点，新结点插在它的后面

![](img/df7a4356658bc366c52d5e361f054231_106_0.png)

    L = (LinkList) malloc (sizeof (LNode));

## 单链表清空

```
Void make Empty ( LinkList L )
{
    //删除链表中除表头结点外的所有其它结点
    LNode *p;
    while ( L->next != NULL )
    {
        p = L->next;
        L->next = p->next;
        //将表头结点后第一个结点从链中摘下
        free( p );  //释放
    }
}
```

## 两个有序链表的合并的基本思想

pa与pb分别指向La和Lb的第一个元素，Lc指向La的头结点，pc始终指向表Lc的表尾，pa所指元素与pb所指元素相比较：

+   - 如果pa->data<=pb->data,则将pa所指元素插入到pc后，并且Pa、pc指针下移;
+   - 反之，则将pb所指元素插入到pc后，并且pb、pc指针下移.

+   - 最后，将剩余部分插入到pc;

+   - 释放Lb的头结点。

## 计算双向循环链表的长度

```
int Length ( DuLinkList L )
{
    //计算带表头结点的双向循环链表的长度
    DuLinkList p = L->next;
    int count = 0;
    while ( p != L )
    { p = p->next; count++; }
    return count;
}
```
