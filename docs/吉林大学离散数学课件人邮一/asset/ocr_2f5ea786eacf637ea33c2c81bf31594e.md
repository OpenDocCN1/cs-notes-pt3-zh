设命题公式A中含有n个命题变元，且A的主析取范式中含有k个小项 m_{j1}, m_{j2}, ..., m_{j_{2^n - k}}，则¬A的主析取范式中必含有2^n - k个小项，不妨含为 m_{j1}, m_{j2}, ..., m_{j_{2^n - k}}，即¬A ⇔ m_{j1} ∨ m_{j2} ∨ ... ∨ m_{j_{2^n - k}}。于是 A ⇔ ¬¬A ⇔ ¬( m_{j1} ∨ m_{j2} ∨ ... ∨ m_{j_{2^n - k}} ) ⇔ ¬m_{j1} ∧ ¬m_{j2} ∧ ... ∧ ¬m_{j_{2^n - k}} ⇔ M_{j1} ∧ M_{j2} ∧ ... ∧ M_{j_{2^n - k}}
