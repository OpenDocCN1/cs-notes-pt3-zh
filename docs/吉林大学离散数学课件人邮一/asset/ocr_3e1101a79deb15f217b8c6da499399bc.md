# 定义1.8.1

如果存在 $H_1，H_2，…，H_n，C$ 的一个指派，使得每个 $H_i(1\leq i\leq n)$ 为真而 $C$ 为假推理形式 $H_1，H_2，…，H_n\Rightarrow C$ 是无效的；否则，推理是有效的，此时称 $C$ 是 $H_1，H_2，…，H_n$ 的有效结论，或称 $C$ 是从前提 $H_1，H_2，…，H_n$ 逻辑推出的结论。

# 定理1.8.1

推理形式 $H_1，H_2，…，H_n\Rightarrow C$ 是有效的，当且仅当命题公式 $(H_1\land H_2\land …\land H_n)\Rightarrow C$ 是永真式，亦即 $(H_1\land H_2\land …\land H_n)\Rightarrow C$。
