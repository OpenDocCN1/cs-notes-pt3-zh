# 定理4.2.7 若 $R \subseteq A \times B$, $S \subseteq B \times C$, 则 $(R o S)^{-1} = S^{-1} o R^{-1}$

# 定理4.2.8 令 $R$, $S \subseteq A \times B$, 则

+   ① $(R^{-1})^{-1} = R$

+   ② $D(R^{-1}) = R(R)$, $R(R^{-1}) = D(R)$

+   ③ $(R \cup S)^{-1} = R^{-1} \cup S^{-1}$

+   ④ $(R \cap S)^{-1} = R^{-1} \cap S^{-1}$

+   ⑤ $(R - S)^{-1} = R^{-1} - S^{-1}$

+   ⑥ $R \subseteq S \Rightarrow R^{-1} \subseteq S^{-1}$
