# 定义1.5.2

称 $G$ 为联结词功能完全组，如果 $G$ 满足下列两条件：①由 $G$ 中联结词构成的公式能等价表示任意命题公式；②$G$ 中的任一联结词不能用其余下联结词等价表示。

可以证明，$\{\lnot,\lor\}$，$\{\lnot,\land\}$，$\{\lnot,\to\}$，$\{\uparrow\}$，$\{\downarrow\}$ 都是联结词功能完全组；而 $\{\lnot,\leftrightarrow\}$，$\{\lnot,\{\land\}$，$\{\land\}$，$\{\lor\}$，$\{\land,\lor\}$ 都不是联结词功能完全组，但为了表示方便，仍经常使用联结词组 $\{\lnot,\land,\lor\}$。
