# 定义9.6.2 形如 $x_1^{\delta_1} \circ x_2^{\delta_2} \circ ... \circ x_n^{\delta_n}$ 的布

尔表达式称为由变元 $x_1$, $x_2$, ..., $x_n$ 产生的小项，其中 $\delta_i \in \{0,\ 1\}$, 用 $x_i^1$ 表示 $x_i$, $x_i^0$ 表示 $x_i'$, $i \in \{1,\ 2,\ ...,\ n\}$, 并用 $m_{\delta_1 \delta_2 ... \delta_n}$ 表示该小项。

形如 $x_1^{\sigma_1} \oplus x_2^{\sigma_2} \oplus ... \oplus x_n^{\sigma_n}$ 的布尔表达式称为由变元 $x_1$, $x_2$, ..., $x_n$ 产生的大项，其中 $\sigma_i \in \{0,\ 1\}$, $x_i^1$ 表示 $x_i'$, $x_i^0$ 表示 $x_i$, $i \in \{1,\ 2,\ ...,\ n\}$, 并用 $M_{\sigma_1 \sigma_2 ... \sigma_n}$ 表示该大项。
