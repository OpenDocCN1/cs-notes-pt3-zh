# 定义7.5.2

给定集合$X$且$p_i,p_j\in P_X$，由$X$的元素先进行置换$p_i$后继之作置换$p_j$，所得到的置换，表示为$p_i\diamond p_j$。称$p_i\diamond p_j$是置换$p_i$和$p_j$的复合，$\diamond$是复合置换运算。

可以看出，若把置换看成一种特殊关系时，复合置换$p_i\diamond p_j$就是复合关系$p_j\circ p_i$，常称之为复合；又若把置换看成函数时，那么复合置换又可表成如下的复合函数即所谓左复合：

$p_i\diamond p_j=p_j\circ p_i$，其中$\circ$表示函数的复合

于是，对于$x\in X$有：

```
$(p_i\diamond p_j)(x)=(p_j\circ p_i)(x)=p_j(p_i(x))$
```
