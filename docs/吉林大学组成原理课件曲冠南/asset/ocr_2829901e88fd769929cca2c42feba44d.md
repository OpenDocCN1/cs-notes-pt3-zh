# 编译器优化 - 举例

循环融合 - 改进时间局部性

```
/* 修改前 */
    for ( i=0; i<N; i=i+1 )
        for ( j=0; j<N; j=j+1 )
            a[i][j]=1/b[i][j]*c[i][j];
    for ( i=0; i<N; i=i+1 )
        for ( j=0; j<N; j=j+1 )
            d[i][j]=a[i][j]+c[i][j];
/* 修改后 */
    for ( i=0; i<N; i=i+1 )
        for ( j=0; j<N; j=j+1 ) {
            a[i][j]=1/b[i][j]*c[i][j];
            d[i][j]=a[i][j]+c[i][j];
        }
```
