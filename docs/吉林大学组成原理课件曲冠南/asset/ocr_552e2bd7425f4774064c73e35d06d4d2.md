# 例 6.14 将 -58 表示成二进制定点数和浮点数，6.2 并写出它在定点机和浮点机中的三种机器数及阶码为移码、尾数为补码的形式（其他要求同上例）。

解： 设 x = -58

二进制形式      x = - 111010

定点表示        x = - 0000 111010

浮点规格化形式  x = - (0.1110100000) × 2¹¹⁰

定点机中

[x]原 = 1, 0000111010

[x]补 = 1, 1111000110

[x]反 = 1, 1111000101

浮点机中

[x]原 = 0, 0110; 1. 1110100000

[x]补 = 0, 0110; 1. 0001100000

[x]反 = 0, 0110; 1. 0001011111

[x]阶移、尾补 = 1, 0110; 1. 0001100000
