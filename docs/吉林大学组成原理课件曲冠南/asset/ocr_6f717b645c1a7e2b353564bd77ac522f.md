# (3) 双重分组跳跃进位链 大组进位分析

以第 8 小组为例

C₃ = d₃ + t₃ C₂ = d₃ + t₃ d₂ + t₃ t₂ d₁ + t₃ t₂ t₁ d₀ + t₃ t₂ t₁ t₀ C₋₁ = D₈ + T₈ C₋₁

D₈ 小组的本地进位 与外来进位无关

T₈ 小组的传送条件 与外来进位无关 传递外来进位

同理 第 7 小组 C₇ = D₇ + T₇ C₃

第 6 小组 C₁₁ = D₆ + T₆ C₇

第 5 小组 C₁₅ = D₅ + T₅ C₁₁

进一步展开得

C₃ = D₈ + T₈ C₋₁

C₇ = D₇ + T₇ C₃ = D₇ + T₇ D₈ + T₇ T₈ C₋₁

C₁₁ = D₆ + T₆ C₇ = D₆ + T₆ D₇ + T₆ T₇ D₈ + T₆ T₇ T₈ C₋₁

C₁₅ = D₅ + T₅ C₁₁ = D₅ + T₅ D₆ + T₅ T₆ D₇ + T₅ T₆ T₇ D₈ + T₅ T₆ T₇ T₈ C₋₁
