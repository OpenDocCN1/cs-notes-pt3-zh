# 二、加减法运算

# 1. 补码加减运算公式

# (1) 加法

整数 $[A]_{补} + [B]_{补} = [A+B]_{补} \（mod\ 2^{n+1}）$

小数 $[A]_{补} + [B]_{补} = [A+B]_{补} \（mod\ 2）$

# (2) 减法

$A-B = A+(-B)$

整数 $[A-B]_{补} = [A+(-B)]_{补} = [A]_{补} + [-B]_{补} \（mod\ 2^{n+1}）$

小数 $[A-B]_{补} = [A+(-B)]_{补} = [A]_{补} + [-B]_{补} \（mod\ 2）$

连同符号位一起相加，符号位产生的进位自然丢掉
