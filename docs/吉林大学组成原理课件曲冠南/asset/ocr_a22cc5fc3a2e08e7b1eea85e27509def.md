# 计算 $ax^2 + bx + c$ 程序清单

|  | 操作码 | 地址码 |  |

| 5 | 000010 | 0000001100 | 将$ax^2+bx+c$,存于主存单元 |
| 6 | 000101 | 0000001100 | 打印 |
| 7 | 000110 |  | 停机 |
| 8 |  | $x$ | 原始数据$x$ |
| 9 |  | $a$ | 原始数据$a$ |
| 10 |  | $b$ | 原始数据$b$ |
| 11 |  | $c$ | 原始数据$c$ |
| 12 |  |  | 存放结果 |
