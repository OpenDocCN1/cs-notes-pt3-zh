# 例　设数据块首地址为 **D**，求 **N** 个数的平均值

# 7.3

# 直接寻址

```
LDA   D
ADD   D + 1
ADD   D + 2
⋮
ADD   D + (N - 1)
DIV   # N
STA   ANS
```

共 **N + 2** 条指令

# 变址寻址

```
LDA   # 0
LDX   # 0        X 为变址寄存器
ADD   X, D       D 为形式地址
INX               (X) + 1 → X
CPX   # N        (X) 和 #N 比较
BNE   M          结果不为零则转
DIV   # N
STA   ANS
```

共 **8** 条指令
