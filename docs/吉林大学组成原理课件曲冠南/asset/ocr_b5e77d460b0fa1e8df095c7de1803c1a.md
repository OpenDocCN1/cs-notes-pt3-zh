# 静态指令调度：依靠编译器解决数据冲突

让编译器重新组织指令顺序来消除冲突，这种技术称为指令调度或流水线调度。

+   - 例如：采用典型的代码生成方法，
+     表达式A=B+C的代码会导致暂停

| LD Rb, B |  | IF | ID | EX | MEM | WB |  |  |  |  |
| LD Rc, C |  | IF | ID | EX | MEM | WB |  |  |  |  |
| DADD Ra, Rb, Rc |  |  |  | IF | ID | stall | EX | MEM | WB |  |
| SD Ra , A |  |  |  |  | IF | stall | ID | EX | MEM | WB |
