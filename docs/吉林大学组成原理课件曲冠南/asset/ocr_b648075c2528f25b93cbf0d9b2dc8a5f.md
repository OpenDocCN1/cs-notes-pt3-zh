# 例6.26 设 x = -0.1011 y = 0.1101 求 [x/y]补 并还原成真值

解： [x]补 = 1.0101 [y]补 = 0.1101 [-y]补 = 1.0011

| | | |
|---|---|---|
| 1.0101 | 0.0000 | |
| + 0.1101 | | 异号做加法 |
| 0.0010 | 1 | 同号上 “1” |
| 0.0100 | 1 | ←1 |
| + 1.0011 | | +[-y]补 |
| 1.0111 | 10 | 异号上 “0” |
| 0.1110 | 10 | ←1 |
| + 0.1101 | | +[y]补 |
| 1.1011 | 100 | 异号上 “0” |
| 1.0110 | 100 | ←1 |
| + 0.1101 | | +[y]补 |
| 0.0011 | 1001 | 同号上 “1” |
| 0.0110 | 10011 | ←1 未位恒置 “1” |

∴ [x/y]补 = 1.0011 则 x/y = -0.1101
