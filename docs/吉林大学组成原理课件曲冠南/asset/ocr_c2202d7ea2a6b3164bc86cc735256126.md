# 例6.27  x = 0.1101 × 2¹⁰   y = 0.1011 × 2⁰¹  6.4

求 x+y（除阶符、数符外，阶码取 3 位，尾数取 6 位）

[y]补 = 00, 001; 00.101100

∴ [y]补' = 00, 010; 00.010110

② 尾数求和

[S_x]补 = 00.110100
+ [S_y]补' = 00.010110
