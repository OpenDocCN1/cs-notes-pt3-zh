# (1) 恢复余数法

例6.24  x = −0.1011    y = −0.1101    求 [x / y]原

解：[x]原 = 1.1011  [y]原 = 1.1101  [y*]补 = 0.1101  [−y*]补 = 1.0011

① x₀ ⊕ y₀ = 1 ⊕ 1 = 0
