例如 x = 0.1101 × 2^01      y = (-0.1010) × 2^11

求 x + y

解： [x]补 = 00, 01; 00.1101      [y]补 = 00, 11; 11.0110

# 1. 对阶

① 求阶差  [Δj]补 = [j_x]补 − [j_y]补 = 00, 01
                 + 11, 01
                 --------
                   11, 10

阶差为负（−2）      ∴ S_x → 2    j_x + 2

② 对阶      [x]补′ = 00, 11; 00.0011

# 2. 尾数求和

[S_x]补′ = 00.0011      对阶后的[S_x]补′
+ [S_y]补 = 11.0110
----------------
        11.1001
∴ [x+y]补 = 00, 11; 11.1001
