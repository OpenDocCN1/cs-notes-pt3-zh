# (5) 补码除和原码除（加减交替法）比较 6.3

|  | 原码除 | 补码除 |
|---|---|---|
| 商符 | $x_0 \oplus y_0$ | 自然形成 |
| 操作数 | 绝对值补码 | 补码 |
| 上商原则 | 余数的正负 | 比较余数和除数的符号 |
| 上商次数 | $n + 1$ | $n + 1$ |
| 加法次数 | $n + 1$ | $n$ |
| 移位 | 逻辑左移 | 逻辑左移 |
| 移位次数 | $n$ | $n$ |
| 第一步操作 | $[x^*]_补 - [y^*]_补$ | 同号 $[x]_补 - [y]_补$ 异号 $[x]_补 + [y]_补$ |
