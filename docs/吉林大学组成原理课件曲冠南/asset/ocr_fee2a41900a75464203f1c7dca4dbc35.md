# 4. 补码除法

# (1) 商值的确定

① 比较被除数和除数绝对值的大小

x 与 y 同号

$x=0.1011$　　　　$[x]_{补}=0.1011$　　　　$[x]_{补}=0.1011$　　　　$x^* > y^*$

$y=0.0011$　　　　$[y]_{补}=0.0011$　　　　$+[-y]_{补}=1.1101$　　　　$[R_i]_{补}$与$[y]_{补}$同号

$[R_i]_{补}=0.1000$　　　　　　　　　“够减”

$x=-0.0011$　　　　$[x]_{补}=1.1101$　　　　$[x]_{补}=1.1101$　　　　$x^* < y^*$

$y=-0.1011$　　　　$[y]_{补}=1.0101$　　　　$+[-y]_{补}=0.1011$　　　　$[R_i]_{补}$与$[y]_{补}$异号

$[R_i]_{补}=0.1000$　　　　　　　　　“不够减”
