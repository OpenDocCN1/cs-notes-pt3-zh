## 阶码相加减 -- 若用移码

用移码加减规则

```
[jx+jy]移 = [jx]移 + [jy]补
[jx-jy]移 = [jx]移 + [-jy]补
```

- 1. 高位增加符号位，设为0；
- 2. 运算后，高位符号位为1，则有溢出
- 低位符号位为0，上溢（正正得负）;
- 低位符号位为1，下溢（负负得正）；

例如：阶码取3位（不包含符号位），对应的真值范围是-8 – 7。

当jx = +101, jy = +100

则有 [jx]移 =01,101； [jy]补 = 00,100

[jx+jy]移 = 01,101 + 00,100=10,001

（正正得负）

当jx = -101, jy = -100

则有 [jx]移 =00,011； [jy]补 = 11,100

[jx+jy]移 = 00,011 + 11,100=11,111

（负负得正）
