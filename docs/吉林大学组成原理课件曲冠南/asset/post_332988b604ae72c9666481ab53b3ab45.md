### 2. 算术逻辑操作

加、减、乘、除、增1、减1、求补、浮点运算、十进制运算

与、或、非、异或、位操作、位测试、位清除、位求反

如 8086 ADD SUB MUL DIV INC DEC CMP NEG AAA AAS AAM AAD AND OR NOT XOR TEST

算术类指令除了完成算术过程，还要完成测试操作

- ZF：零标志位，运算结果为零时ZF置1；
- AF：半进位，AF = 1，有半进位；
- PF：偶校验，1的个数为偶数时PF为1；
- SF：结果为负标志，若运算结果为负，则SF为1；
- CF：进位标志，若有进位时，CF为1；
- OF：溢出标志，若溢出时，OF为1。

逻辑运算类指令应用

- 逻辑乘的应用：实现字段截取；用自身产生标志位；按位清零；等
- 逻辑加的应用：某位置1；偶校验；等；
- 按位加（异或）：判全等；清零；求反；产生随机数；等。

### 二、数据寻址

| 操作码 | 寻址特征 | 形式地址 A |
|---|---|---|

形式地址 指令字中的地址

有效地址 操作数的真实地址（EA）

约定 指令字长 = 存储字长 = 机器字长

#### 1. 立即寻址

在指令中直接给出操作数

![](img/62645fe4f2a56f5ae4c9e02b9997cbad_445_0.png)

- 优点：指令执行阶段不访存
- 缺点：A 的位数限制了立即数的范围

#### 2. 直接寻址

在指令中直接给出操作数所在的内存地址

![](img/62645fe4f2a56f5ae4c9e02b9997cbad_446_0.png)

- 优点： 寻找操作数简单，执行阶段访存一次
- 缺点： A 的位数决定了该指令操作数的寻址范围

操作数的地址不易修改（必须修改A）

#### 3. 隐含寻址

操作数地址隐含在操作码中

![](img/62645fe4f2a56f5ae4c9e02b9997cbad_447_0.png)

另一个操作数
隐含在 ACC 中

如 8086

- MUL 指令 被乘数隐含在 AX（16位）或 AL（8位）中
- MOVS 指令 源操作数的地址隐含在 SI 寄存器中
- 目的操作数的地址隐含在 DI 寄存器中
- 指令字中少了一个地址字段，可缩短指令字长

#### 4. 间接寻址

地址指向 地址

寻址特征

主存

一次间址

寻址特征

主存

多次间址

多次访存

- 缺点： 执行指令阶段 2 次访存
- 优点： 可扩大寻址范围
  便于编制程序

#### 5. 寄存器寻址

EA = R_i   有效地址即为寄存器编号

![](img/62645fe4f2a56f5ae4c9e02b9997cbad_450_0.png)

优点：执行阶段不访存，只访问寄存器，执行速度快

寄存器个数有限，可缩短指令字长

#### 6. 寄存器间接寻址

寄存器 指向 地址

![](img/62645fe4f2a56f5ae4c9e02b9997cbad_451_0.png)

- 有效地址在寄存器中，操作数在存储器中，执行阶段访存
- 举例：数组访问

#### 7. 基址寻址

(1) 采用专用寄存器作基址寄存器

EA = ( BR ) + A      BR 为基址寄存器

![](img/62645fe4f2a56f5ae4c9e02b9997cbad_452_0.png)

- 可扩大寻址范围
- 有利于多道程序
- BR 内容由操作系统或管理程序确定
- 在程序的执行过程中 BR 内容不变，形式地址 A 可变

(2) 采用通用寄存器作基址寄存器

![](img/62645fe4f2a56f5ae4c9e02b9997cbad_453_0.png)

- 由用户指定哪个通用寄存器作为基址寄存器
- 基址寄存器的内容由操作系统确定
- 在程序的执行过程中 R₀ 内容不变，形式地址 A 可变

#### 8. 变址寻址

EA = (IX) + A    IX为变址寄存器（专用）
通用寄存器也可以作为变址寄存器

![](img/62645fe4f2a56f5ae4c9e02b9997cbad_454_0.png)

- 可扩大寻址范围
- IX 的内容由用户给定
- 在程序的执行过程中 IX 内容可变，形式地址 A 不变
- 便于处理数组问题

例 设数据块首地址为 **D**，求 **N** 个数的平均值

#### 9. 相对寻址

EA = (PC) + A

A 是相对于当前指令的位移量（可正可负，补码）

![](img/62645fe4f2a56f5ae4c9e02b9997cbad_456_0.png)

- A 的位数决定操作数的寻址范围
- 程序浮动
- 广泛用于转移指令

(1) 相对寻址举例

```
LDA  # 0
LDX  # 0
M    ADD  X, D
M+1  INX
M+2  CPX  # N
M+3  BNE  M
DIV  # N
STA  ANS
```

* 相对寻址特征

M 随程序所在存储空间的位置不同而不同

而指令 BNE *-3 与指令 ADD X, D 相对位移量不变

指令 BNE *-3 操作数的有效地址为

```
EA = ( M+3 ) - 3 = M
```
