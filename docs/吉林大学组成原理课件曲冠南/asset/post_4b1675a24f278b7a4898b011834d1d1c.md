### 2. 写出微操作命令的最简表达式

M ( MAR ) ⟶ MDR

= FE · T₁ + IND · T₁ ( ADD + STA + LDA + JMP + BAN )
    + EX · T₁ ( ADD + LDA )

= T₁ { FE + IND ( ADD + STA + LDA + JMP + BAN )
    + EX ( ADD + LDA ) }
