## 速记 原码除法 和 补码除法法则

## 原码除法：

符号位单独算；第一次减除数；余数为正，上1，左移，减；余数为负，上0，左移，加。加减n+1次，左移n次。

## 补码除法：

符号位一起算；第一次同号减，异号加；余数和减数同号，上1，左移，减；余数和减号异号，上0，左移，加；末尾恒置1。加减n次，移位n次。

## 6.4 浮点四则运算

## 一、浮点加减运算

步骤

- 1. 对阶（小阶向大阶看齐）
- 2. 尾数相加减
- 3. 规格化（正：0.1*****; 负：1.0*****, 负数有特例）
- 4. 舍入（0舍1入；恒1）
- 5. 判溢出（阶符 01 上溢（正正得负）； 10 下溢（负负得正））

## 1. 对阶

(1) 求阶差

```
Δj = j_x - j_y = { 
  = 0   j_x = j_y        已对齐
  > 0   j_x > j_y { x 向 y 看齐    S_x ←1, j_x−1
                     y 向 x 看齐  ✓ S_y →1, j_y+1 }
  < 0   j_x < j_y { x 向 y 看齐  ✓ S_x →1, j_x+1
                     y 向 x 看齐    S_y ←1, j_y−1 }
}
```

小阶向大阶看齐

例如 x = 0.1101 × 2^01      y = (-0.1010) × 2^11

求 x + y

解： [x]补 = 00, 01; 00.1101      [y]补 = 00, 11; 11.0110

## 1. 对阶

① 求阶差  [Δj]补 = [j_x]补 − [j_y]补 = 00, 01
                 + 11, 01
                 --------
                   11, 10

阶差为负（−2）      ∴ S_x → 2    j_x + 2

② 对阶      [x]补′ = 00, 11; 00.0011

## 2. 尾数求和

[S_x]补′ = 00.0011      对阶后的[S_x]补′
+ [S_y]补 = 11.0110
----------------
        11.1001
∴ [x+y]补 = 00, 11; 11.1001

## 3. 规格化

(1) 规格化数的定义

r = 2    1/2 ≤ |S| < 1

(2) 规格化数的判断

| S>0 | 规格化形式 | S<0 | 规格化形式 |
|---|---|---|---|
| 真值 | 0.1××…× | 真值 | −0.1××…× |
| 原码 | 0.1××…× | 原码 | 1.1××…× |
| 补码 | 0.1××…× | 补码 | 1.0××…× |
| 反码 | 0.1××…× | 反码 | 1.0××…× |

原码 不论正数、负数，第一数位为1

补码 符号位和第一数位不同

## 特例

[S]补 = 1.1 00···0

∴ [-1/2]补 不是规格化的数

∴ [-1]补 是规格化的数

## (3) 左规

尾数左移一位，阶码减 1，直到数符和第一数位不同为止

上例 [x+y]补 = 00, 11; 11.1001

左规后 [x+y]补 = 00, 10; 11.0010

∴ x + y = (-0.1110)×2¹⁰

## (4) 右规

当 尾数溢出（>1）时，需 右规

即尾数出现 01.×× …×或 10.×× …×时

尾数右移一位，阶码加 1
