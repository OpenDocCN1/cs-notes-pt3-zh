
## (1) 移码定义

[x]移 = 2^n + x （2^n > x ≥ -2^n）

x 为真值，n 为整数的位数

## 移码在数轴上的表示

![](img/62645fe4f2a56f5ae4c9e02b9997cbad_318_0.png)

如 x = 10100

[x]移 = 2^5 + 10100 = 1,10100

x = -10100

[x]移 = 2^5 - 10100 = 0,01100

用逗号将符号位和数值部分隔开

## (2) 移码和补码的比较

设    x = +1100100
[x]移 = 2⁷ + 1100100 = 1,1100100
[x]补 = 0,1100100

设    x = −1100100
[x]移 = 2⁷ − 1100100 = 0,0011100
[x]补 = 1,0011100

补码与移码只差一个符号位

## （4）移码的特点

- ➢ 当 $x=0$ 时
- 
- $[+0]_{移}=2^5+0=1,00000$
- 
- $[-0]_{移}=2^5-0=1,00000$
- 
- ∴ $[+0]_{移}=[-0]_{移}$

- ➢ 当 $n=5$ 时，最小的真值为 $-2^5=-100000$
- 
- $[-100000]_{移}=2^5-100000=000000$
- 
- 可见，最小真值的移码为全 0

用移码表示浮点数的阶码
能方便地判断浮点数的阶码大小

## 二、浮点表示

N = S×r^j 浮点数的一般形式

S 尾数 j 阶码 r 基数 (基值)

计算机中 r 取 2、4、8、16 等

当 r = 2 N = 11.0101 二进制表示

✓ = 0.110101 × 2^{10} 规格化数

= 1.10101 × 2^{1}

= 1101.01 × 2^{-10}

✓ = 0.00110101 × 2^{100} 规格化数

计算机中 S 小数、可正可负

j 整数、可正可负

## 机器零

- > 当浮点数尾数为 0 时，不论其阶码为何值按机器零处理
- > 当浮点数阶码等于或小于它所表示的最小数时，不论尾数为何值，按机器零处理

如 m = 4    n = 10

当阶码和尾数都用补码表示时，机器零为
X, X X X X;  0.0 0  ...  0
(阶码 = -16)  1, 0 0 0 0 0;  X.X X  ...  X

当阶码用移码，尾数用补码表示时，机器零为
0, 0 0 0 0;  0.0 0  ...  0

有利于机器中“判 0”电路的实现
