充分挖掘系统总线每个瞬间的潜力

一个总线传输周期

子周期1

主模块申请占用总线，使用完后即放弃总线的使用权

子周期2

从模块申请占用总线，将各种信息送至总线上

主模块

## 分离式通信特点

- 1. 各模块有权申请占用总线
- 2. 采用同步方式通信，不等对方回答
- 3. 各模块准备数据时，不占用总线
- 4. 总线被占用时，无空闲

充分提高了总线的有效占用

（1）当读操作时，第一个时钟周期接收地址，第二、三个为延时周期，另用4个周期传送一个块。读操作的总线传输速率是多少？

（2）当写操作时，第一个时钟周期接收地址，第二个为延时周期，另用4个周期传送一个块，写操作的总线传输速率是多少？

（3）设在全部的传输中，70%用于读，30%用于写，则该总线在本次传输中平均速率是多少？
