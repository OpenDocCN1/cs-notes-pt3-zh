### 机器速度与机器主频的关系

机器的主频 f 越快，机器的速度也越快

在机器周期所含时钟周期数相同的前提下，两机平均指令执行速度之比等于两机主频之比

MIPS₁ / MIPS₂ = f₁ / f₂

机器速度不仅与主频有关，还与机器周期中所含时钟周期（主频的倒数）数以及指令周期中所含的机器周期数有关
