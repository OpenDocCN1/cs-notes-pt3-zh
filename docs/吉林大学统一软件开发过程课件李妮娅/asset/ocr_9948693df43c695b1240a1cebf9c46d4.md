# # Inception Phase

# □ **Purpose**

+   - 为开发一个新系统或者变更一个旧系统建立一个商业用例 (*the business case*)
+   - 确定项目范围 (*the project scope*)

# □ **Outcome**

+   - 项目需求总览
+     - 10-20%的初始用例模型和领域模型
+   - 初始商业用例
+     - 成功结项标准（e.g., 收益预计）
+     - 初始风险评估
+     - 所需资源评估

# □ **Lifecycle Objectives Milestone**（生命周期目标里程碑）
