# III. 处理形式参数：

(ℓ, off) → Var ID:T → (ℓ, off+1)

(ℓ, off) → ID:T → (ℓ, off+ n_T )

# IV. 处理过程名及左括号之后：

(ℓ, off) → Proc p( → (ℓ+1, d)

(ℓ, off) → Func f( → (ℓ+1, d)

(ℓ, off) → Proc P( → (ℓ+1, d)

(ℓ, off) → Fucn F( → (ℓ+1, d)

注：小写字母的标识符表示实在标识符，大写字母的标识符则表示形参标识符。n_T 表示类型T的长度，off_1表示处理完形参部分（实在过程首部）时的偏移值，d表示活动记录控制信息所占的大小。
