# 7. 符号串集合的方幂

设A为符号串的集合，则称A^i为符号串集A的方幂。具体定义如下：

A^0 = { ε }
A^1 = A
A^2 = AA
.....
A^n = A^{n-1}A = AAA......A (n个)

例：A = { a, b } 则：

A^0 = { ε }
A^1 = { a, b }
A^2 = AA = { a, b }{ a, b } = { aa, ab, ba, bb }
A^3 = A^2A = { aa, ab, ba, bb }{ a, b }
    = { aaa, aab, aba, abb, baa, bab, bba, bbb }
.....
A^n = A^{n-1}A = AAA......A
