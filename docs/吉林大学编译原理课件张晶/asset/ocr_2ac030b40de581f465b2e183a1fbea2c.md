# 四元式到目标指令的翻译

+   ◆ 四元式种类
+     ■ 运算型: (op, A, B , T)
+     ■ 赋值: (Assig, A, size, B)
+     ■ 跳转和标号:
+       • (JMP/JMPF/JMPT, -, -, L)、(Label, -, -, L)、
+       • (THEN, t, -, -)、(ELSE, -, -, -)、(ENDIF, -, -, -)、
+       • (WHILE, -, -, -)、(DO, t, -, -)、(ENDWHILE, -, -, -)
+     ■ 函数相关
+       • (ENTRY, Lf, size, level)
+       • (ENDFUNC, _, _, _)
+       • (ValAct/VarAct, X.arg, offset, size)
+       • (CALL, Lf , true, result)
+       • (RETURN, -, -, t)
