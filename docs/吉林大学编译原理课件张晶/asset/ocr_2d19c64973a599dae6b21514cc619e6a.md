2.由于某非终极符的产生式的右部能推导出ε，且该非终极符的FOLLOW集中含有其某个产生式右部的FIRST集中的元素。

例：有如下文法G[S]:

S → aAS | b

A → bAS | ε | d

分析字符串ab。

First(bAS) ∩ First(ε) = ∅

First(bAS) ∩ First(d) = ∅

First(d) ∩ First(ε) = ∅

Follow(A) = {b,a}

Predict(A→ bAS) ∩ Predict(A→ ε) ≠ ∅

■至少有一个产生式被选择的条件是：
predict(A→ βₖ) ∩ predict(A→ βⱼ) = ∅，当k≠j

满足该条件的文法称为LL(1)文法，递归下降子程序文法。
