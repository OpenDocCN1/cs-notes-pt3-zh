# 1. 自底向上的语法分析

例子：

+   - E → E+T
+   - E → T
+   - T → T *F
+   - T → F
+   - F → ( E )
+   - F → i

分析 (a+t)*c

![](bbox=[0.3, 0.25, 0.68, 0.9])

| 符号栈 | 输入流 | 动作 |
|---|---|---|
| # | (a+t)*c# | 移入 |
| #( | a+t)*c# | 移入 |
| #(a | +t)*c# | 归约 |
| #(F | +t)*c# | 归约 |
| #(T | +t)*c# | 归约 |
| #(E | +t)*c# | 移入 |
| #(E+ | t)*c# | 移入 |
| #(E+t | )*c# | 归约 |
| ... | ... | ... |
| #E | # | 成功 |
