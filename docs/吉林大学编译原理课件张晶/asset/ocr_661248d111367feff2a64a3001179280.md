# 4. 计算Follow集

+   1: 对所有 A∈V_N 且 A 非开始符：
+      令 Follow(A):={ };
+      对开始符 S：令 Follow(S)={ # };
+   2: 若有产生式 A→xBy:
+      如果 ε ∈First(y) 则：
+      Follow(B)
+      = Follow(B) ∪ (First(y)—{ε}) ∪ Follow(A)
+      否则：
+      Follow(B)
+      = Follow(B) ∪ First(y)
+   3: 重复2，直至对所有 A∈V_N，Follow(A)收敛为止。
