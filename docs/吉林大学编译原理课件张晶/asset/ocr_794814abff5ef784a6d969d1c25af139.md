例：假设有文法

Z → a B a

B → b B | c

θ(aBa)

θ'(a); θ'( B); θ'(a)

Predict(Z→aBa)={a},

Predict(B→bB)={b}, Predict{B→c}={c}

则相应的递归子程序可如下：

```
procedure Z()
begin
if token=a then Match(a);
B;
Match(a)
else err(1)
end;
```

```
procedure B()
begin
if token = b then Match(b);
B;
else if token = c
then Match(c);
else err(2)
end;
```
