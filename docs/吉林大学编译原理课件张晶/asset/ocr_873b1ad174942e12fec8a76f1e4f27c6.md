# 非局部变量访问的实现：

假设Q的变量访问环境：

VarVisitEnv (LAR (Q))

= [LAR (M) ,…, LAR (P) , LAR (Q) ] ，在Q中有变量 XQ，YM，ZP，它们分别定义在过程Q、M和P中，则它们的存储单元地址可表示如下（其中<LAR (Q)>表示LAR (Q) 的始地址，其它类似）：

addr ( XQ ) = <LAR (Q) > + OffsetX

addr ( YM ) = <LAR (M) > + OffsetY

addr ( ZP ) = <LAR (P) > + OffseZ

结论：对于每个AR，只要知道了它的变量访问环境 VarVisitEnv (AR)，即可实现包括非局部变量在内的所有变量的访问。
