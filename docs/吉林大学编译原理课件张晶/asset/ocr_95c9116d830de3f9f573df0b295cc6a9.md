# 例： C语言的变量声明：

```
```c
int       x=10;
float     y;
float*    z;
```
```

变量标识符x、y和z的内部表示为（当前层为L，当前偏移量为off）：

| x | varKind | intPtr  | dir  | L | off   | ↑<10> |
|---|---------|---------|------|---|-------|-------|
| y | varKind | realPtr | dir  | L | off+1 | NULL  |
| z | varKind |         | indir| L | off+3 | NULL  |
