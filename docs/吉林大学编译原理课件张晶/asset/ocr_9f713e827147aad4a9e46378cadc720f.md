# 过程函数声明部分的四元式处理：
(ENDFUNC, -, -, -) / (return, -, -, t)

+   1: 生成一组读取命令，即恢复寄存器的现场信息
+   
+   2: 作废当前的活动记录，由两个指令完成，把当前的sp寄存给top，把动态链指针寄存给sp
+   
+   ST top , sp ; LD sp , *0(top)
+   
+   3: 产生一条返回指令，根据返回地址生成一个跳转指令。jmp *1 (top)

如果是返回语句(return, -, -, t)，则要增加一个操作，将返回结果存储到活动记录2 (top)中。

LD R , t;

ST *(top), R

+   寄存器状态
+   过程层数
+   返回值
+   返回地址
+   动态链指针
