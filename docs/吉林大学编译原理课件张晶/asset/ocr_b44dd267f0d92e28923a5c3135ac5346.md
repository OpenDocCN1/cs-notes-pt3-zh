# （1）简单的C语言符号表_驻留法

```
```c
int x,y;
void swap(int* a, int* b)
{
    int tmp;
    tmp = *a;
    *a = *b;
    *b = tmp;
}
void main()
{
    x = 10;
    y = 20;
    swap(&x,&y);
}
```
