例子P183-5 试写出下述程序段的目标代码，其中变量均为非形参实型变量。

```
while (x < y)
{
    y = y + 1;
        if (y > 0)    y = y-x;
        else while (y < 0)
            y = y + x;
}
```

(WHILE,-,-,-)

(THEN, t3,-,-)
(SUBF,y,x,t4)

(WHILE,-,-,-)
