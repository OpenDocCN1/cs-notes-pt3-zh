# 如何计算当前过程的变量访问环境

情况1

```
PROC P;
... ...
Begin
  P
End
```

情况2

```
PROC Q;
Begin
...
end
... ...
PROC P;
Begin
Q
End
```

情况3

```
PROC P;
... ...
PROC Q
Begin  End
... ...
Begin Q End
```

情况4

```
PROC Q;
... ...
PROC P;
Begin Q
End
Begin  End
```

情况4: P调用Q, P层数大于Q层数(N). (P是Q的内层过程才允许此种调用, 即P嵌在Q的内部)
DeclaChain(P)= (M, P₁, P₂, …, Pₙ₋₁, Q, …, P)
DeclaChain(Q)= (M, P₁, P₂, …, Pₙ₋₁, Q)
