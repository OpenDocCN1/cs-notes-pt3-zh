# 静态链的方法

问题的提出
例：假设有调用链(M, G , H, R, S )，并且有
Level (M)=0, Level (G)=1, Level (H)=2, Level (R)=3, Level (S)=3
则相应动态链的基本结构应如下：
[ AR₀(M), AR₁(G), AR₂(H), AR₃(R), AR₄(S) ]
如果用局部Display表方法，则Display表情况如下：
AR₀(M).Display = [ ar₀ ]
AR₁(G).Display = [ ar₀, ar₁ ]
AR₂(H).Display = [ ar₀, ar₁, ar₂ ]
AR₃(R).Display = [ ar₀, ar₁, ar₂, ar₃ ]
AR₄(S).Display = [ ar₀, ar₁, ar₂, ar₄ ]
