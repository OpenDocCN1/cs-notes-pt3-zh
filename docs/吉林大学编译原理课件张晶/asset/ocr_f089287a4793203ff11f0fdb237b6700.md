```
(ASSIG, 1, _, j)
(WHILE, _, _, _)
(LE, j, 1000, t1)
(DO, t1, _, _)
(SUBI, i, 1, t2)
(MULTI, t2, 1000, t3)
(AADD, a, t3, t4)
(SUBI, j, 1, t5)
(MULTI, t5, 1, t6)
(AADD, t4, t6, t7)
(ASSIG, 0, _, t7)
(ADDI, j, 1, t8)
(ASSIG, t8, _, j)
(ENDWHILE, _, _, _)
```

LoopDef={t1, t2, t3, t4, t5, t6, t7, t8, j}

# 优化后的四元式序列：

```
(ASSIG, 1, _, j)
(SUBI, i, 1, t2)
(MULTI, t2, 1000, t3)
(AADD, a, t3, t4)
(WHILE, _, _, _)
(LE, j, 1000, t1)
(DO, t1, _, _)
(SUBI, j, 1, t5)
(MULTI, t5, 1, t6)
(AADD, t4, t6, t7)
(ASSIG, 0, _, t7)
(ADDI, j, 1, t8)
(ASSIG, t8, _, j)
(ENDWHILE, _, _, _)
```

LoopDef={t1, t5, t6, t7, t8, j}

```
j:=1
while j<=1000 do
  begin a[i][j]:=0;
         j:=j+1;
  end;
```
