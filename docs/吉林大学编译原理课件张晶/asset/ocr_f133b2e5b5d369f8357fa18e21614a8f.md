# 2. 语法分析程序的构造

当产生式形如: A→β₁|β₂|…|βₙ, 则按下面的方法编写子程序A:

```
procedure A()
begin if token∈Predict(A→β₁) then θ(β₁) else
if token∈Predict(A→β₂) then θ(β₂) else
......
if token∈Predict(A→βₙ) then θ(βₙ) else
error()
end
```

其中对βᵢ=X₁X₂…Xₙ, θ(βᵢ)=θ'(X₁);θ'(X₂);…;θ'(Xₙ);

如果X∈Vₙ, θ'(X)= X();

如果X∈Vₜ, θ'(X)= Match(X); //即if(token==X) ReadToken();

如果X= ε, θ'(ε)= skip(空语句).
