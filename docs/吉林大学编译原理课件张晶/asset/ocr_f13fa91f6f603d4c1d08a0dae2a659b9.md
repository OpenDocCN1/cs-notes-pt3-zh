# 函数调用相关四元式的翻译

（CALL，f，true，Result）

+   1. 生成填写变量访问环境指令
+   2. 把机器状态（寄存器内容）保存到活动记录的寄存器状态区中，一般应生成一组存的指令
+   3. 要填写管理信息。首先填写过程层数。从过程的语义信息中取其层数，填入到3（top）中，生成指令为
+   
+      `LD R，sem[f].level`
+      `ST 3(top)，R`
+   
+      取出过程活动记录大小，填入off-size（top）中，生成指令为
+   
+      `LD R，sem[f].size`
+      `ST off-size(top)，R`
