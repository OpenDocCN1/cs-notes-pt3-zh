# 函数相关四元式的代码生成

+   ◆ 函数相关四元式
+   
+   (VALACT, a, off, size)
+   (VARACT, a, off, size)
+   (CALL, Lf, true/false, result)
+   (ENTRY, Label, size, Level)
+   (RETURN, -, -, t/-)
+   (ENDFUNC, -, -, -)

◆ 翻译时，需要加进一些额外的代码用于完成如下工作：

+   • 函数调用时：申请新AR空间，参数传递，保存寄存器状态信息，转向相应过程体
+   • 函数返回时：释放AR，恢复寄存器状态信息，传递返回值，按照返回地址返回
