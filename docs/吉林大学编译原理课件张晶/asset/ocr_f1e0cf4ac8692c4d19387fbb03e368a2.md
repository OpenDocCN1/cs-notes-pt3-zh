+   - 分析的初始格局（$S\#,\ a_1...a_n\#$）

设存在格局为（$X_1...X_m\#,\ a_1...a_n\#$）

+   - 若 $X_1\in V_T$ & $X_1=a_1$，则有（$X_2...X_m\#,\ a_2...a_n\#$）
+   - 若 $X_1\in V_N$ 则查表，若 $T(X_1,a_1)=X_1\to\alpha$，格局为（$\alpha X_2...X_m\#,\ a_1...a_n\#$），若 $T(X_1,a_1)=Error$，则报错。
+   - 若格局为（$\#,\ \#$），则分析成功
+   - 其他情况 报错
