# 过程调用和函数调用的动作文法

```
<ProcFunCall> → id #CallHead#
        ( <ParamList> ) #CallTail#
```

```
<ParamList> → ε | <ExpList>
```

```
<ExpList> → E #ActParam# <NextList>
```

```
<NextList> → ε | , <ExpList>
```

其中

+   CallHead: 当遇到过程 / 函数名 id 时，将其符号表地址压入 Sem 栈，令实参计数器为 0。

+   ActParam: 对每个实参 Eᵢ：产生它的中间代码，将结果的类型和语义信息压入 Sem 栈，实参计数器加 1。
