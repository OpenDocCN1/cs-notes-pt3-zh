# 如何计算当前过程的变量访问环境

情况1

```
PROC P;
... ...
Begin
  P
End
```

情况2

```
PROC Q;
Begin
...
end
... ...
PROC P;
Begin
Q
End
```

情况3

```
PROC P;
... ...
PROC Q
Begin  End
... ...
Begin Q End
```

情况4

```
PROC Q;
... ...
PROC P;
Begin Q
End
Begin  End
```

情况2： P调用Q, P层数等于Q层数N.（P,Q具有相同的直接外层才允许此种调用）
DeclaChain(P)= (M, P₁, P₂, …, Pₙ₋₁, P)
DeclaChain(Q)= (M, P₁, P₂, …, Pₙ₋₁, Q)
