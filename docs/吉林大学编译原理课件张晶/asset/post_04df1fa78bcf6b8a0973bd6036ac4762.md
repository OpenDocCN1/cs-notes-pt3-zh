## 1. 词法分析的基本功能

- 词法分析程序是编译程序的一部分，是整个编译过程的第一步工作。
- 词法分析器读取源程序的字符序列，逐个拼出单词并构造相应的内部表示。同时检查源程序中的词法错误。它的核心作用即为将字符序列转化为计算机内部表示。

## 1.3 单词类型的划分

常用程序设计语言的单词可以分为以下几类：

- **标识符：** 用来标识程序中各个对象的名称。它们由用户定义，用来表示变量名、常量名、数组名和函数名等。
- **保留字：** 保留字一般是由语言系统自身定义的，通常是由字母组成的字符串。如C语言中的 int, if, for, do等等。这些字在语言中具有固定的意义，是编译程序识别各类语法成分的依据。

## 1.3 单词类型的划分

- 常量：主要包括整数常量、实数常量、字符常量、字符串常量等。
- 特殊符号：包括运算符、界限符和控制符（格式符）。
  - 运算符是程序中表示算术运算、逻辑运算、字符运算、赋值运算的确定的字符或字符串。如各类语言通用的+、-、*、/、<、>=、<=等。
  - 界限符在语言中是作为语法上的分界符号使用的，如逗号、分号、单引号等。
  - 控制符主要用于控制语言的格式，如回车、空格等。

## 2.1 基本概念

- 1. 字母表（alphabet）

字母表是元素的非空有穷集合，字母表中的一个元素称为该字母表的一个字母（letter），也可叫做符号（symbol）或者字符（character）。

注意：字母表具有非空性和有穷性。

- 字母表有时也称为符号表，通常用Σ表示。

例如： Σ = {a, b, c, d}

## 2.1 基本概念

## 2. 符号串

由字母表中的符号组成的任何有穷序列称为字母表上的符号串。一般用α，β，…，x，y，z表示。

ε表示空串。对任一字母表Σ，都有ε是Σ上的符号串。

空串集{ε}不同于空集∅。

## 3. 符号串连接

设α和β 均是字母表Σ上的符号串， α和β的连接是把β的所有符号顺次地接在α的所有符号之后所得到的符号串。

记为： αβ。

例如：设 α = abc ， β = de ，则α和β的连接：

αβ = abcde

## 2.1 基本概念

## 4. 符号串的方幂

设 a 是字母表 Σ 上的符号串，把 a 自身连接 n 次得到的符号串 a'，称作符号串 a 的 n 次幂，记作 a' = aⁿ。

a⁰ = ε
a¹ = a
a² = a a
a³ = a² a = a a² = a a a
…
aⁿ = aⁿ⁻¹ a = a aⁿ⁻¹ = a a … a （n个 a）

## 2.1 基本概念

- 5. 符号串集合

若集合A中的所有元素都是某字母表Σ上的符号串，则称A为该字母表上的符号串集合。

- 6. 符号串集的乘积

设A、B 是两个符号串集合，AB表A与B的乘积，具体定义为：

AB = { xy | ( x∈A ) ∧ ( y∈B ) }

例 设 A = { a, bc } , B = { de, f } ,则：

AB = { ade, af, bcde, bcf }

特别有：1、ØA = AØ = Ø，其中Ø表示空集。

2、{ε}A = A{ε} = A

## 2.1 基本概念

## 7. 符号串集合的方幂

设A为符号串的集合，则称A^i为符号串集A的方幂。具体定义如下：

A^0 = { ε }
A^1 = A
A^2 = AA
.....
A^n = A^{n-1}A = AAA......A (n个)

例：A = { a, b } 则：

A^0 = { ε }
A^1 = { a, b }
A^2 = AA = { a, b }{ a, b } = { aa, ab, ba, bb }
A^3 = A^2A = { aa, ab, ba, bb }{ a, b }
    = { aaa, aab, aba, abb, baa, bab, bba, bbb }
.....
A^n = A^{n-1}A = AAA......A

## 2.1 基本概念

设A是字符串集合，则称A+是字符串集合A的正闭包 
A+=A¹ ∪ A² ∪ A³ ⋯ ∪ Aⁿ⋯

设A是字符串集合，则称A*是字符串集合A的星闭包 
A*=A⁰ ∪ A¹ ∪ A² ∪ A³ ⋯ ∪ Aⁿ⋯ 
⋯ ∪ Aⁿ⋯=A⁰ ∪ A+

## 2.1 基本概念

例:设A = {ab, cd}, 则：

A⁺ = {ab, cd, abab, abcd, cdab, cdcd, ababab, ababcd, … }

A* = {ε, ab, cd, abab, abcd, cdab, cdcd, ababab, ababcd, … }
