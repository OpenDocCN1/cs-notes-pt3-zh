## 2. 下标变量的中间代码生成

## 2.1 下标变量的地址计算

假设有数组类型的变量声明如下：
A :array [L₁..U₁] [L₂.. U₂]…
[Lₙ..Uₙ] of T ; (n ≥ 1)

+   - 数组A占单元大小：size(A)=D1*D2*…*Dn*α
+     其中Dᵢ=Uᵢ-Lᵢ+1，α为类型T所占单元数。
+   - 下标变量取址：a[i₁][i₂][i₃]…[iₙ]
+     =addr(a)+(i₁-L₁)*S₁+(i₂-L₂)*S₂+…+(iₙ-Lₙ)*Sₙ
+     //注：此处的Sᵢ不同于书中P130给出的Sᵢ，为第i层数组变量元素空间大小
