# 2. 媒体

媒体作为信息表示和传播的形式载体，根据信息被人们感知、表示、呈现、存储或传输的载体不同，ITU（International Telecommunication Union，国际电信联盟）建议将媒体分为下列5类：感觉媒体、表示媒体、表现媒体、存储媒体和传输媒体。
