# 例6.2 在一个有序表中查找指定值x

```
#include <stdio.h>
#define N 6
int main(void) {
    int v[N] = { 8, 14, 30, 45, 67, 89 }; //用一维数组v存放有序表
    int low = 0, high = N - 1, mid;    //low和high分别表示查找的上下界

    int x = 30;  //待查找的元素
    while (low <= high) {
        mid = (low + high) / 2;
        if (x < v[mid])
            high = mid - 1;  // 在前半部分查找
        else if (x > v[mid])
            low = mid + 1;   // 在后半部分查找
        else
            break;
    }
}
```
