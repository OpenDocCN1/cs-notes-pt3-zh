# 随机存储器

+   半导体存储器可分为随机存储器和只读存储器。随机存取存储器（Random Access Memory，简称RAM），其特点是可以读写，存取任一单元所需的时间相同，通电是存储器内的内容可以保持，断电后，存储的内容立即消失。

+   RAM可分为动态（Dynamic RAM）和静态（Static RAM）两大类。

+   动态随机存储器DRAM是用MOS电路和电容作存储元件。由于电容会放电，所以需要定时充电以维持存储内容的正确，如相隔2ms刷新一次，因此称这为动态存储器。

+   静态随机存储器SRAM是用双极型电路或MOS电路的触发器作存储元件，它没有电容放电造成的刷新问题。只要有电源正常供电，触发器就能稳定地存储数据。

+   DRAM的特点是集成密度高，主要用于大容量存储器。SRAM的特点是存取速度快，主要用于缓冲存储器。
