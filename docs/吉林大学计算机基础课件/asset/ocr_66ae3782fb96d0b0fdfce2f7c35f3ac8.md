# 第二节 Windows 7 的基本操作

# (5) 切换窗口

当打开多个窗口时，需要在各个窗口之间进行切换，下面是几种切换的方式：

+   - 在任务栏上单击要操作窗口的按钮，即可完成切换。或者当所选窗口处于非最小和最大化时，单击窗口的任意位置，标题栏的颜色变深，表明完成对窗口的切换。

+   - 用 <Alt> + <Tab> 组合键来完成切换，在键盘上按住 “<Alt>” 键不放，再按 “<Tab>” 键，从 “切换任务栏” 中选择所要打开的窗口，选中后再松开两个键，即可窗口的切换。

+   - 用户也可以使用 <Alt> + <Esc> 组合键，先按下 “<Alt>” 键，然后再通过按 “<Esc>” 键来选择所需要打开的窗口，但是它只能改变激活窗口的顺序，而不能使最小化窗口放大，所以，多用于切换已打开的多个窗口。
