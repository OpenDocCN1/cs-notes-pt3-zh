# 4.4.1 基于层次网络协议介绍

+   - 基于分层的网络设计思想将网络分解成一堆相互叠加的层，每一层都建立在其下一层的基础之上。每一层的目的都是向上一层提供特定的服务，而把如何实现这些服务的细节对上一层加以屏蔽。
+   - 计算机网络体系结构的核心就是如何合理地划分层次，并确定每个层次的特定功能及相邻层次之间的接口。
+   - 在计算机网络分层结构体系中，通常把每一层在通信中用到的规则与约定称为协议。
+   - 协议是一组形式化的描述，网络协议它是计算机网络软硬件开发的依据，是为进行网络中的数据交换而建立的规则、标准和约定，它由三个要素构成：语法、语义和同步。层和协议的集合就称为网络体系结构。
