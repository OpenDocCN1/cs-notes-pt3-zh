# 四、函数的结构

Excel中函数的结构以等号“=”开始，后面紧跟函数名称和在括号，然后以逗号分隔输入该函数的参数列表，最后是右括号。例如：“=SUN（3，6，A2：B4）”。

# 五、输入函数

+   ① 鼠标左键双击要使用函数的单元格，在单元格中按照函数的结构输入函数。
+   
+   ② 选择要使用函数的单元格→单击“编辑栏”上的“插入函数”按钮→“插入函数”对话框→选择函数的名称→设置函数的参数。
+   
+   图插入函数对话框
+   
+   ③ 左键单击“编辑组”→“求和按钮”右边小箭头→选择“其他函数”→“插入函数”对话框进行选择。

# 六、嵌套函数

Excel公式中可包含多达七级的嵌套函数。如公式MAX（AVERAGE（A1：A10），50），使用了嵌套的AVERAGE函数并将结果与值50进行了比较。
