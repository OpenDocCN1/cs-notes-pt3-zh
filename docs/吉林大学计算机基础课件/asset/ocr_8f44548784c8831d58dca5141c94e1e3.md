# 第三节 Windows 7 的文件管理

# 4. 文件或文件夹的复制与移动

# (1) 鼠标拖放法

先将需要复制的文件或文件夹选中，然后在选中的区域按下鼠标左键不放拖动选中的对象，直到复制的目的地放开鼠标即可完成文件的复制。默认情况下，在同一个磁盘分区中拖动是移动操作，不同分区之间拖动是复制操作。按下<Shift>键再拖动时，始终做的是移动操作；按下<Ctrl>键再拖动时，始终做的是复制操作。

# (2) 粘贴法

用鼠标选择将要复制的对象，单击【编辑】菜单，执行【复制】命令，然后在复制的目的地选择【编辑】菜单，执行【粘贴】命令就可以实现文件或文件夹的复制。也可用键盘上的组合键Ctrl+X、Ctrl+C和Ctrl+V来实现复制与移动。
