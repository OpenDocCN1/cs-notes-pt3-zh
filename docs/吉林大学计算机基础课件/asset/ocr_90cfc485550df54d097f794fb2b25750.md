# 3. 移动用户

+   - 可移动计算机，比如笔记本和PDA（Personal digital assistants，个人数字助理），是计算机工业中增长最为迅猛的分支之一，这些计算机的出现，使得无线网络成为热点。通过无线网络，移动办公变得非常方便，可以使用移动设备来发送或者接收电话、传真和电子邮件，或者浏览Web页面、访问远程文件、登录到远程计算机。
+   - 随着无线技术的不断普及，大量其他的无线应用不断涌出，例如无线停车计时器、无线水电气抄表器等；无线网络和PDA结合，利用WAP可以在小屏幕上访问Web，随机推动了移动商务(Mobile-Commerce，M-Commerce)的 发展、手机银行、手机支付等应用随即出现。
