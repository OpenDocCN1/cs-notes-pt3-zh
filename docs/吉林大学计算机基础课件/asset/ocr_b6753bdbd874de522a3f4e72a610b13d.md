# 二、数据筛选

+   1、自动筛选
+      1）选择要筛选的数据→“数据”选项卡→“排序和筛选”组→单击“筛选”按钮。
+      2）单击数据列标题中的箭头→筛选器选择列表对话框→设置筛选参数。

+   2、高级筛选
+      1）多列数据中筛选多个条件，条件间为“和”关系的情况。
+         ① 例如筛选条件布尔逻辑为：（部门 = “销售四部” AND 数量 > 800 AND 单价 < 20）

![](bbox=[0.065, 0.542, 0.887, 0.663])

② 单击要筛选数据区域中的任一单元格→“数据”选项卡→“排序和筛选”组→单击“高级”按钮→弹出“高级筛选”对话框→选择筛选方式（“在原有区域显示筛选结果”、“将筛选结果复制到其他位置”）→在“条件区域”框中，输入条件区域的引用→确定。
