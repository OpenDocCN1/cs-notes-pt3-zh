# 第三节  Windows 7 的文件管理

# （3）常用文件的扩展名

| 扩展名 | 文件类型 | 扩展名 | 文件类型 |
|---|---|---|---|
| .EXE | 可执行程序文件 | .JPG | 压缩图片文件 |
| .COM | 系统程序文件 | .BMP | 位图文件 |
| .BAT | 批处理文件 | .DOCX | Word2010文件 |
| .SYS | 系统文件 | .XLSX | Excel2010文件 |
| .BAK | 备份文件 | .PPTX | PowerPointer2010文件 |
| .ZIP | 压缩文档文件 | .ACCDB | ACCESS2010文件 |
| .GIF | 图像文件 | .TXT | 文本文件 |
