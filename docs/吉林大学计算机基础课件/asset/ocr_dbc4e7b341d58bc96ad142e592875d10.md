# 7.3.2　创建数据库

+   - 例7.1 建立“教学管理”空数据库，并将建好的数据库存
+     在D盘的database文件夹（事先建好的文件夹）中。
+   - 操作步骤如下：
+   - 1. 选择“文件”→“新建”，打开“新建”对话框，单
+     击“空数据库”选项，弹出“文件新建数据库”对话框，
+     如图7.1所示。
+   - 2. 在该对话框“保存位置”栏中找到D盘database文件夹，
+     并打开。
+   - 3. 在“文件名”文本框中输入“教学管理”，选择保存
+     类型为“Microsoft Access 2007数据库（*.accdb）”，单击确
+     定按钮。如图7.2所示。
+   - 4. 回到“新建”对话框后，单击“创建”按钮
