# 1.4 计算机中信息的表示

+   - 凡是按进位的方式计数的数制都被称为进位计数制，简称为进位制。数据无论使用哪种进位制表示，都涉及基数（Radix）与各位数的“权”（Weight）。
+     K=Kₙ₋₁×Rⁿ⁻¹+Kₙ₋₂×Rⁿ⁻²+…+K₁×R¹+K₀×R⁰+K₋₁×R⁻¹+K₋₂×R⁻²+…+K₋ₘ×R⁻ᵐ = Σᵢ₌₋ₘⁿ⁻¹ Kᵢ×Rⁱ
+   - 位置计数法的数制均有以下几个主要特点：
+   - 1) 数码个数等于基数，最大数码比基数小1。
+   - 2) 每个数码都要乘以基数的幂次，而该幂次是由每个数所在的位置决定的，即“位权”，简称权。
+   - 3) 低位向高位的进位是“逢基数进1”。
