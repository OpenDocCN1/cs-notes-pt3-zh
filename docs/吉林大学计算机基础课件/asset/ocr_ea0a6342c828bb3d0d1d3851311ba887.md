# 四、图表制作

+   1、建立图表

+   1）、选择要为其绘制图表的数据。

+   2）、“插入”选项卡→“图表”组→单击要使用的图表类型→弹出图表类型详细说明菜单→选择图表子类型。

+   3）若要查看所有可用的图表类型，单击“图表”组中右下角按钮→“插入图表”对话框。

+   2、更改图表的布局或样式

单击要设置格式的图表中的任意位置→“图表工具”。“图表工具”包含“设计”、“布局”和“格式”选项卡。

+   1）应用预定义图表布局

+   2）应用预定义图表样式

+   3）手动更改图表元素的布局

+   4）手动更改图表元素的格式

+   5）添加图表标题

+   6）添加坐标轴标题

+   7）显示或隐藏图例
