# 第一节 操作系统的概念

# (3) 分时操作系统

分时操作系统将CPU的时间划分成若干个片段，称为时间片。操作系统以时间片为单位，轮流为每个终端用户服务。每个用户轮流使用一个时间片而使每个用户并不感到有别的用户存在。分时系统具有多路性、交互性、独占性和及时性的特征。

# (4) 实时系统

实时系统主要分为两类：实时控制系统和实时处理系统。实时操作系统的主要特点在于有严格的时间限制，每个信息的接收、分析处理和发送过程必须在规定的时间范围内做出响应。在这种要求下操作系统的一些活动都必须在一个严格的时间控制程序下运行。实时系统应考虑的问题有实时时钟管理、连续人机对话、过载的防护、处理机调度策略、高可靠性等。
