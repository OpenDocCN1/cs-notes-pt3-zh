## 4.4.3 TCP/IP 参考模型

- TCP/IP参考模型是计算机网络的鼻祖ARPANET及其后继的Internet使用的参考模型。ARPANET是由美国国防部赞助的研究网络。它通过租用的电话线连接了数百所大学和政府部门。
- 当无线网络和卫星加入进来以后，原有的协议在和它们互连时出现了问题，所以需要一种新的参考体系结构。因此能够无缝的方式将多个网络连接起来，这是一开始就面临的主要设计目标之一，另一主要设计目标就是即使在子网硬件有丢失的情况下，网络必须还能够继续工作，原有的会话不会被打断。

## 4.4.4 OSI和TCP/IP模型比较

- OSI和TCP/IP参考模型有很多的共同点。两者都是以协议栈的概念为基础，并且协议栈的协议彼此相互独立。
- 而且两个模型中各层的功能也大体相似。例如，在两个模型中，传输层以及传输层以上的各层都为希望进行通信的进程提供了一种端到端的、与网络无关的服务。
- 这些层形成了传输提供方。另外，在这两个模型中，传输层之上的各层也都是传输服务的用户，并且是面向应用的用户。

## 4.5 因特网

- 因特网（Internet）是人类历史发展中的一个伟大的里程碑，它是未来信息高速公路的雏形，人类正由此进入一个前所未有的信息化社会。
- 因特网并不是单个网络，而是大量不同网络的集合，这些不同的网络使用同一组公共协议，并提供一组公共服务。因特网不是一个普通的系统，具有开放性，不是由任何一个人规划出来的，也不受任何人控制。
- 因特网可以这样定义：在全球范围，由采用 TCP/IP 协议族的众多计算机网相互连接而成的最大的开放式计算机网络。因特网的前身是美国的阿帕网(ARPANET)。

### 4.5.1 因特网的发展历程

- 因特网的发展大致经历了如下四个阶段：
- （1）因特网的起源
- （2）TCP/IP协议的产生
- （3）网络的“春秋战国”时代
- （4）Internet的基础——NSFNET

### 4.5.3 IP协议

- 当前因特网中主要使用网际协议IP进行互联，IP协议是因特网中的核心协议，IP协议是用来使互联起来的计算机网络能够通信。IP数据包含有个头部和一个正文部分。

### 4.5.4 IP地址

- 因特网上的每一台主机和路由器都有一个IP地址，IP地址包括网络号和主机号，并且这种组合是唯一的：原则上，因特网上的任何两台机器都不会有相同的IP地址。
- IP地址都是32位长，通常采用点分十进制记法，在这种格式中，4个字节中的每个字节用十进制表示，从0到255。
- 例如，32位的十六进制地址C0290614被写成192.41.6.20。

## 子网掩码

- 在1985年起在IP地址中增加一个“子网号字段”，从主机号中借用若干比特作为子网号，使二级IP地址变成三级IP地址。
- 为了实现对子网的支持，增加了“子网掩码”，在划分子网的情况下，网络地址（即子网地址）就是将主机号置为0的IP地址，具体地就是将子网掩码和IP地址逐比特相“与”的结果。
- 如果网络没有划分子网，网络就采用默认子网掩码，其中A类地址的默认子网掩码是255.0.0.0、B类地址默认的子网掩码是255.255.0.0、C类地址的默认子网掩码是255.255.255.0。

### 4.5.5 域名系统DNS

- 域名系统主要用途是将主机名或电子邮件目标地址映射成IP地址，这样使得人们能够采用具有实际意义的字符串（域名）来代替既不形象又难记忆的IP地址。
- 域名系统采用层次结构，按地理域或机构域进行分层。字符串的书写采用圆点将各个层次隔开，分为层次字段。从右到左依次为顶级域名、第二层域名等，最左的一个字段为主机名。例如,email.google.com代表谷歌公司的一台电子邮件服务器，其中email为服务器主机名，google为谷歌域名，com是商业公司顶级域名。顶级域名分为两大类：机构性和地理性域名。

### 4.5.6 Internet控制协议

- （1）因特网控制报文协议ICMP（Internet Control Message Protocol）
- （2）地址解析协议ARP（Address Resolution Protocol）
- （3）逆地址解析协议RARP（Reverse Address Resolution Protocol）
- （4）因特网组管理协议IGMP（Internet Group Management Protocol）

## 4.6 万维网与电子邮件

- 万维网（World Wide Web）并非特殊的计算机网络，它是一个大规模的、联机式的信息存储场所，简称为Web。
- Web是一个分布式的超媒体（hypermedia）系统，它是超文本（hypertext）系统的扩充。
- 万维网与因特网有着本质的区别。因特网（Internet）指的是一个硬件的网络，全球的所有电脑通过网络连接后便形成了因特网。而万维网更倾向于一种浏览网页的功能。

### 4.6.1 Web技术基础

- Web服务器，主要是功能是提供网上信息浏览服务。WWW 是 Internet 的多媒体信息查询工具，是 Internet 上近年才发展起来的服务，也是发展最快和目前用的最广泛的服务。
- Web客户通常指的是Web浏览器，当前比较流行的Web浏览器有Microsoft Internet Explorer、Mozilla的Firefox、Google的Chrome、Opera和Safari。

## HTML

- HTML是Web诞生与发展的要素之一，它旨在使得Web页面能显示在任何支持HTML的浏览器中，而与连网的机器平台无关。HTML并不是一个程序设计语言，而是一个标记语言，它所提供的标记是由SGML（Standard Generalized Markup Language，标准的通用标记语言）定义的。

## HTTP (Hyper Text Transfer Protocol)

- HTTP (Hyper Text Transfer Protocol、超文本传输协议) 是用来在互联网上传输文档的协议，它是Web上最常用也是最重要的协议，也是Web服务器和Web客户（如浏览器）之间传输Web页面的基础。HTTP是建立在TCP/IP之上的应用协议，但并不是面向连接的，而是一种请求/应答（Request/Response）式协议。

### 4.6.2 浏览器的基本使用

- 浏览器是指可以显示网页服务器或者文件系统的HTML文件内容，并让用户与这些文件交互的一种软件。
- 网页浏览器主要通过HTTP协议与网页服务器交互并获取网页，这些网页由URL指定，文件格式通常为HTML，并由MIME在HTTP协议中指明。一个网页中可以包括多个文档，每个文档都是分别从服务器获取的。

### 4.6.3 搜索引擎的使用

- 搜索引擎是指根据一定的策略、运用特定的计算机程序从互联网上搜集信息，在对信息进行组织和处理后，为用户提供检索服务，将用户检索相关的信息展示给用户的系统。
- 搜索引擎包括全文索引、目录索引、元搜索引擎、垂直搜索引擎、集合式搜索引擎、门户搜索引擎与免费链接列表等。
- 百度和谷歌等是搜索引擎的代表。

### 4.6.4 电子商务

- 电子商务通常是指在全球各地广泛的商业贸易活动中，在因特网开放的网络环境下，基于浏览器/服务器应用方式，买卖双方不谋面地进行各种商贸活动，实现消费者的网上购物、商户之间的网上交易和在线电子支付以及各种商务活动、交易活动、金融活动和相关的综合服务活动的一种新型的商业运营模式。
