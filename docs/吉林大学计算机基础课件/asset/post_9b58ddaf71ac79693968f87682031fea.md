## 3. 艺术字的编辑与格式设置

在Word 2010艺术字的字库中，提供了30种样式，用户根据需要选择样式，再确定艺术字的内容和字体大小，修饰格式会自动根据样式生成到目标内容上，减少了用户自行修饰和调整的工作量，提高了工作效率。

## 5.2.6 Word 2010中的常用工具

1. 格式刷

格式刷可快速复制选定对象或文本的格式（字体、字号、颜色、边界等），并将其应用到随后单击的文本或对象上，免除重复设置文本格式之苦，为统一格式化文档，提高文档编辑效率提供了一个非常方便的工具。使用格式刷的操作方法：

- 1. 选择希望复制其格式的文本或对象。
- 2. 单击快速工具栏上的格式刷（只能复制格式一次）；或者快速双击快速工具栏上的格式刷（可以多次复制格式）。
- 3. 选择希望应用该格式的文本或对象，格式将自动应用到该文本或对象上，以减少繁琐的格式设置，保证整篇文档格式风格的一致。

![](img/60882d3e569e0db30f34a44fdc73ab49_236_0.png)

## 3. 页眉和页脚

页眉和页脚使诸如文档标题和页号自动加入到每一个页。设置文档的页眉和页脚时，只需一次性输入文字信息，这些信息就会出现在文档的每一页中。通常总是把文档的标题放入页眉（页面顶部），把页号放入页脚（页面底部）。点击“插入”功能区，可以看到页眉页脚的设置选项

```
if (score >= 90)
    printf("A\n");
else if (score >= 70)
    printf("B\n");
else if (score >= 60)
    printf("C\n");
```

## 4. 分栏

所谓分栏就是将文档全部页面或选中的内容设置为多栏，从而呈现出报刊、杂志中经常使用的分栏排版效果。Word 2010默认提供了五种分栏：一栏、两栏、三栏、偏左、偏右。可以根据实际需要选择合适的分栏类型，也可以自定义word分栏。分栏方法：单击“页面布局”→“页面设置”→“分栏”→“更多分栏”。

使用分栏时，遇到左右两栏不齐的问题，比如左栏内容明显比右栏多出许多）。解决方法是：将光标移动到文章的末尾处，然后点击“页面布局”→“页面设置”→“分隔符”，勾选“连续”，确定即可。设置分隔线的方法：单击“页面布局”→“页面设置”→“分栏”→“更多分栏”，勾选“分隔线”，就可以在两栏之间显示一条直线分隔线。

![](img/60882d3e569e0db30f34a44fdc73ab49_239_0.png)

## 6. 水印

单击“页面布局”→“水印”，可以插入一些word内置的水印效果。

如果对这些系统默认的水印效果不满意，可以单击“自定义水印”，打开“水印”对话框。里面提供了图片水印和文字水印。

![](img/60882d3e569e0db30f34a44fdc73ab49_241_0.png)

如果是图片水印，可以选择电脑里的现有图片作为水印，对图片大小可行进行设置。如果勾选“冲蚀”，那么图片水印的显示效果会更加淡化。如果是文字水印，可以自己设置设置水印文字、字体字号颜色等等。如果需要删除已经插入的水印，再次单击水印面板，并单击“删除水印”按钮即可。

## 7. 超链接

文档中的任何内容都可以以附加超链接，当按住Ctrl键同时用鼠标点击该文字时，会看到一个手形（在网页上很常见），系统就会跳转到超链接指定的位置。

方法是：选择需要加超链接的文字，鼠标右键点击这段文字，选择超链接。选择需要跳转的位置，点击确定；也可以手工输入一个URL地址后点击确定。点击功能区“插入”的“链接”，可以看到设置选项，

![](img/60882d3e569e0db30f34a44fdc73ab49_242_0.png)

## 8．制作网页

Word 2010文档支持直接另存为网页，点击菜单栏“文件”→“另存为”，“保存类型”选择“单个网页文件（*.mht;*.mhtml）”、网页（*.htm;*.html）、筛选过的网页（*.htm;*.html）等选项即可。

## 9. Word 2010的多种视图

打开“视图”功能区，在“文档视图”小组里共有5种选项：页面视图、阅读版式视图、web版式视图、大纲视图、草稿视图。文档采用不同的显示方式，其意义是为了让使用者把精力集中在不同方面，更方便的完成工作。除此以外，还有“全屏显示”、“打印预览”、“显示比例设置”等功能选项，尤其在排版工作中，经常会根据需要用到不同的视图模式。

![](img/60882d3e569e0db30f34a44fdc73ab49_244_0.png)

（1）“页面视图”是 最常用的视图模式，它可以显示word文档的打印结果外观，主要包括页眉、页脚、图形对象、分栏设置、页面边距等元素，是最接近打印效果的页面视图。

（2）“阅读版式视图”以图书的分栏样式显示word文档，它主要用来供用户阅读文档，所以“文件”按钮、功能区等窗口元素被隐藏起来。在该视图模式中，还可以单击“工具”按钮选择各种阅读工具。

（3）“Web版式视图”就是以网页的形式显示word文档，主要适用于发送电子邮件和创建网页。

（4）“大纲视图”主要用于word整体文档的设置和显示层级结构，并可以方便的折叠和展开各种层级的文档。大纲视图广泛用于word长文档的快速浏览和设置中。

（5）“草稿视图”隐藏了页面边距、分栏、页眉页脚和图片等元素，仅显示标题和正文，是最节省计算机系统硬件资源的视图方式。当然现在计算机系统的硬件配置都比较高，基本上不存在由于硬件配置偏低而使word运行遇到障碍的问题。
