# An overview of Computer Network

– The history about internet

|  |  |
|---|---| 
| 1983 | ARPANET reaches 500 and becomes a truly **civilian-based** network, which marks the arrival of Internet |
| 1988 | The Internet grows to 60,000 hosts
Europe & North America are linked by fiber-optic cable
Internet Worm, **the 1st internet virus**, impacts 10% of the internet computers |
| 1990 | ARPANET is officially retired. (11 countries became new members of NSFNET) |
| 1993 | > 2 million hosts, 17 countries in **Africa**, **Asia**, ..., joined Internet |
| 1999 | > 16 million, **internet2**, US law establishes domain names as property, US Internet backbone reach the speed at 2.5Gbps |
| 2000/2001 | **IPv6** is used for internet2,
The push to implement **wireless** communication is on. |
