# Socket系统调用函数

主要的系统调用举例如下：

+   1. s=socket(domain,type,protocol);建立给定类型的TSAP.
+   2. bind(a,localaddr,addrlen);为前面创建的socket分配一个本地地址.
+   3. connect(s,server,serverlen);发起与远端socket的一个连接.
+   4. listen(s,n);建立一个连接请求从队列中移出或等待一个请求.
+   5. accept(S,from,fromlen);将一个连接请求从队列中移出或等待一个请求.
+   6. send(s,buf,buflen,flags);在给定的socket上发送一个报文(有连接).
+   7. recv(s,buf,buflen,flags);在给定的socket上接收一个报文(有连接).
+   8. close(s);拆除一个socket上的连接.
+   9. shutdown(s,how);终止一个socket上的连接.
+   10. sendto(s,buf,flags,to,tolen);在无连接的socket上发送一个报文.
+   11. recvfrom(s,buf,buflen,flags,from,fromlen);在无连接的socket上接收一个报文.
+   12. select(nfds,readfds,writefds,exceptfds,timeout);检查一组socket,看它们是否可读或可写.
