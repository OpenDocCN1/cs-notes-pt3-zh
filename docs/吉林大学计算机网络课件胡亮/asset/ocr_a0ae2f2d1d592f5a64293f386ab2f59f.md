# # TCP标志位

| 标志位 | 含义 |
|---|---|
| URG | 紧急指针有效 |
| ACK | 确认号有效 |
| PSH | 请求推送 |
| RST | 连接复位 |
| SYN | 同步 |
| FIN | 终止连接 |

| URG | ACK | PSH | RST | SYN | FIN |
|---|---|---|---|---|---|
|  | ✓ |  |  | ✓ | ✓ |

+   - **SYN同步标志**：该标志仅在三次握手建立TCP连接时有效。
+   - **ACK确认标志**：TCP报头内的确认编号栏内包含的确认编号为下一个预期的序列编号，同时提示远端系统已经成功接收所有数据。
