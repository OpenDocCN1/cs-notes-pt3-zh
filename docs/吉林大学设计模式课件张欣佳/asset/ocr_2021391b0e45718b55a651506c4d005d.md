# # 状态模式



环境类维持一个对抽象状态类的引用，典型代码如下所示：

```
```
class Context {
	private State state; //维持一个对抽象状态对象的引用
	private int value; //其他属性值，该属性值的变化可能会导致对象状态发生变化
	public void setState(State state) { //注入不同的具体状态对象
		this.state = state;
	}
	public void request() {
		//其他代码
		state.handle(); //调用状态对象的业务方法
		//其他代码
	}
}
