# 备忘录模式

# 模式分析

+   对于备忘录类Memento而言，它通常提供了与原发器相对应的属性（可以是全部，也可以是部分）用于存储原发器的状态，典型的备忘录类设计代码如下：

```
package dp.memento;
class Memento {
    private String state;
    public Memento(Originator o) {
        state = o.getState();
    }
    public void setState(String state) {
        this.state=state;
    }
    public String getState() {
        return this.state;
    }
}
```
