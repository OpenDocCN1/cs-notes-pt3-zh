# 进制

+   - 十进制：10个数(0, 1, 2...9)，逢10进位。
+   - 其它进制：十二进制，六十进制，十六进制（半斤八两）...
+   - 二进制：——共有2个数(0,1)，逢2进位。

|  | 10^1 (10) | (1) |
|---|---|---|
| 加数 | 0 | 7 |
| 被加数 | 0 | 4 |
| 和 | 1 | 1 |

|  | 2^3 (8) | 2^2 (4) | 2^1 (2) | 1 |
|---|---|---|---|---|
| 加数 | 0 | 1 | 1 | 1 |
| 被加数 | 0 | 1 | 0 | 0 |
| 和 | 1 | 0 | 1 | 1 |
