# # 字符数组的初始化

+   • 用字符型数据对数组进行初始化

```
char str[6] = {"C",'h','i','n','a','\0'};
```

+   • 用字符常量直接对数组初始化（更简单的方法）

```
char str[6] = "China";
```

```
char str[6] = "China";
```

```
char str[5] = "China"; 正确吗？
```

```
char str[] = "China";
```

+   • 二维字符数组

```
char week[][10] = {"Saturday","Sunday"};
```
