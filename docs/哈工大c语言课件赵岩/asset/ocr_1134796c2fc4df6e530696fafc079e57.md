# 文件格式化读写实例

Demo 4: format

```
1 /*格式化输出*/
2 FILE *fp = fopen("test.txt", "w+");
3 fprintf(fp, "%d\n",10000000);
4 fprintf(fp, "%5.2f",100.1234);
5 fclose(fp);
6 
7 /*格式化输入*/
8 float f;
9 int i;
10 FILE *fp = fopen("test.txt", "r+");
11 fscanf(fp, "%d",&i);
12 fscanf(fp, "%f", &f);  /*scanf不支持printf*/ fclose(fp);
```
