# 判断是否是质数-方法3

```
1 int m, i, k, flag = 1; /*标志变量flag初值为1*/
2 printf("Please enter a number:");
3 scanf("%d",&m);
4 k = sqrt(m);
5 for (i=2; i<=k && flag; i++){
6     if (m % i == 0)
7         flag = 0;
8 }
9 if (flag)
10 printf("Yes!\n");
11 else
12 printf("No!\n");
13 printf("Program is over!\n");
```
