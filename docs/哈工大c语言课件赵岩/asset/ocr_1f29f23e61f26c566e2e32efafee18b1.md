# 数组(array)定义

+   - 定义
+     - 存储属性 数据类型 数组名 [整型常量1] [整型常量2] ... [整型常量n];
+     - int a[5];
+       - 定义一个有5个元素的数组，每个元素的类型均为int
+       - 使用a[0], a[1], a[2], ..., a[4]这样的形式访问每个元素
+       - 它和指针变量没有任何区别
+       - 系统会在内存分配连续的5个int空间给此数组
+       - 数组下标(index)可以是整型表达式
+       - 直接访问a的访问，就是访问此数组的首地址
