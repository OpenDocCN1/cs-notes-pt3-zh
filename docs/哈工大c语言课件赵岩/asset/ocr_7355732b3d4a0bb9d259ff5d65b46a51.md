# 标准输入和输出重定向

```
1 int main(void) {
2     int c;
3     while ((c=getchar()) != EOF)
4         putchar(c);
5 }
```

+   - 无重定向
+     - prog.exe < STDIN > STDOUT
+   - 输入重定向
+     - prog.exe < input.txt
+   - 输出重定向
+     - prog.exe > output.txt
+   - 输入输出全部重定向
+     - prog.exe < input.txt > output.txt
