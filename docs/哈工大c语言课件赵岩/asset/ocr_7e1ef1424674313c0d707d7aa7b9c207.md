# 文件位置定位

+   - void rewind(FILE *fp)
+     - 使文件指针重新指向文件的开头位置。
+     - 此函数没有返回值

+   - int fseek(FILE *fp, long offset, int whence);
+     - 利用该函数可以改变文件指针的位置，从而实现随机读写
+     - offset: 文件指针的位移量，字节数，long型，加或减；
+     - from: 起始位置
+       - 0 — 文件开头，1 — 当前位置，2 — 文件末尾

+   - long ftell(FILE *fp)
+     - 获取文件指针的当前位置，用字节数，返回long类型
