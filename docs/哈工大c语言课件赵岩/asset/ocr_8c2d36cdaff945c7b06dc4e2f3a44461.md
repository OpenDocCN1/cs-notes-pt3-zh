# 内存分配函数

+   - `#include <stdlib.h>`
+   - `#include <alloc.h>`
+   - `void*类型`的指针可以转换成任意类型的变量
+   - `void* malloc(unsigned int size);`
+     - 向系统申请大小为size的内存块，把首地址返回。
+     - 申请不成功，返回NULL
+     - 不初始化
+   - `void* calloc(unsigned int num, unsigned int size);`
+     - 向系统申请num个size大小的内存块，把首地址返回。
+     - 如果申请不成功，返回NULL
+     - 初始化为0
+   - `void free(void* p);`
+     - 释放由malloc()和calloc()申请的内存块。
