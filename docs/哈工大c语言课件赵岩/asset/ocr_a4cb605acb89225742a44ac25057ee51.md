# 枚举常量

Demo 3: A simple example about enumeration

```
1 enum weeks {
2     MON, TUE, WED, THU, FRI, SAT, SUN
3 };
4 enum weeks today, tomorrow;
5
6 today = MON;
7 tomorrow = today + 1;
8 if (tomorrow == TUE)
9     printf("Tomorrow is Tuesday.\n");
10 else
11     printf("Tomorrow is NOT Tuesday.\n");
```
