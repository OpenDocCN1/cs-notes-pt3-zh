# 错误处理判断和策略

| 函数 | 当返回值 | 常用策略 |
|---|---|---|
| fopen() | ==NULL | 转移错误处理流程 |
| fprintf() | <0 |  |
| fputc()、putc() | ==EOF |  |
| fwrite() | <nmem b |  |
| fputs() | ==EOF |  |
| fgets() | ==NULL | 停止再次调用该函数，继续下一步 |
| fscanf() | ==0 或 ==EOF |  |
| fgetc()、getc() | ==EOF |  |
| fread() | <nmem b |  |
| fclose()、fflush() | ==EOF | 忽略 |
