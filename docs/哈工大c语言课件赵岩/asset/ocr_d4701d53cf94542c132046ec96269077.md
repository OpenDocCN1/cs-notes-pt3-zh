# 常见常量

+   - 整型常量
+     - 18, -31
+     - long int型常量123L, 123L, 123456l, 123456L
+     - unsigned int型常量123u, 123U
+   - 浮点常量
+     - 十进制小数形123.45, 456.78
+     - 指数形式1e-2, 4.5e3
+     - float型常量123.45f, 456.78F, 1e-2f, 4.5e3F
+     - long double型常量123.45l, 456.78L, 4.5e3L
+     - 缺省为double
+     - 因为字母和数字容易混淆，所以当用I做后缀时，常使用大写形式
