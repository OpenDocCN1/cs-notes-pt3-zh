# 文件格式化读写

```
1. fprintf(fp,format,arg1,arg2,...,argn);  
2. fscanf(fp,format,&arg1,&arg2,...,&argn);
```

+   - fprintf函数
+     - 将输出项arg1,arg2...argn按指定format格式写入fp所指的文件中,即输出到磁盘文件;
+     - 格式控制符与fprintf定义一致
+   - fscanf函数
+     - 按指定format格式从fp所指的文件中读取数据依次送入arg1,arg2...argn的内存单元;
+     - 格式控制符与scanf定义一致
