# 为什么使用数组

+   - 用简单变量，需50个不同变量名，要用很多个scanf命令
+   - 用数组，可共用一个scanf命令，并利用循环结构读取。

```
1 /* without array */
2 int score1,score2,...,score50;
3 scanf("%d,%d,%d",&score1,&score2,&score3);
4 scanf("%d,%d,%d",&score4,&score5,&score6);
5 ........
6 /* use array */
7 int score[50];, /* 优雅 */
8 for (i=0;i<50;i++)
9     scanf("%d",&score[i]);
```
