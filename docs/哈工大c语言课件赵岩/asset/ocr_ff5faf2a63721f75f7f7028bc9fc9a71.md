# 字符串与数值类型之间的转换实例

Demo 4: conversion of number and string

```
1  float f = 1234.5678f; double d;
2  char numstr[10] = "765.4321";
3  char str[10];
4
5  /* change number to string */
6  sprintf(str, "%9.4f", f);
7  printf("%s\n", str);
8  /* change string to number */
9  d = atof(numstr);
10 printf("%f\n", d);
```
