# 插入排序

```
```c
void Insert(int a[], int n, int x)
{
    int i, pos;

    for (i=0; (i < n) && (x > a[i]); i++)
    {
        pos = i; /*找到插入位置pos*/
        for (i = n-1; i >= pos; i--)
        {
            a[i+1] = a[i];      /*向后移动*/
        }
        a[pos] = x;             /*插入元素到位置pos*/
```
