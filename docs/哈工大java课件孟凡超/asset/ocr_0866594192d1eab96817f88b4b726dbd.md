# 位运算符

位运算符用来对二进制位进行操作，包括按位取反(~)、按位与(&)、按位或(|)、异或(^)、右移(>>)、左移(<<)及无符号右移(>>>)，位运算只能对整型和字符型数据进行操作。

```
byte b=30;
system.out.println(~b);
```
