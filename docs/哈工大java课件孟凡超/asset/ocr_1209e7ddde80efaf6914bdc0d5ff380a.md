➢JToggleButton的构造方法：

+   ✓JToggleButton()

+   ✓JToggleButton(Icon icon, boolean selected)
+   ✓JToggleButton(String text)
+   ✓JToggleButton(String text, boolean selected)
+   ✓JToggleButton(String text, Icon icon)
