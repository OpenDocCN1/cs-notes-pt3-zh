# 3.1 表达式

# 其它运算符

扩展赋值运算符：扩展赋值运算符是在赋值号(=)前面再加上其它运算符，是对表达式的一种简写形式。

+   “+=”. a+=4等价于a=a+4。

+   “-=”. a-=4等价于a=a-4。

+   “*=”. a*=4等价于a=a*4。

+   “/=”. a/=4等价于a=a/4。

+   “% =”. a%=4等价于a=a%4。

+   “&=”. a&=4等价于a=a&4。

+   “|=”. a|=4等价于a=a|4。

+   “^=”. a^=4等价于a=a^4。

+   “>>=”. a>>=4等价于a=a>>4。

+   “<<=”. a=a<<4。

+   “>>>=”. a>>>=4。

赋值语句：
var=var op expression
(其中，var是变量，op是算术运算符或位运算符，expression为表达式)
可以表示为
var op=expression
