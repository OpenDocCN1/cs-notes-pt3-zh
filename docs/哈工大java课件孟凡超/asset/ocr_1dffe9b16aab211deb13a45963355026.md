# 5.4子类

如果用instanceof运算符已判明父类的引用指向的是子类的实例，就可以转换该引用，恢复对象的全部功能。

```
public void m(Employee e){
    if(e instanceof Manager){
        //经理级人士
        Manager m=(Manager)e;
        System.out.println(m.department);
    }else if(e instanceof Contractor){
        //掌握公司机密的高层人士
    }else{
        //普通雇员
    }
}
```
