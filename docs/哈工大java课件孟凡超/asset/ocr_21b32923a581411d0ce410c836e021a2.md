# 4.3 字符串类型

# 几个特殊处理

连接： String类对象可以使用concat(String str)方法将str连接在当前字符串的尾部。另外，“+”可以实现字符串的连接操作。StringBuffer类对象使用append()方法实现连接。

```
String s1="This is the";
String s2=" String.";
String s3=s1.concat(s2);
System.out.println("s1="+s1);
System.out.println("s2="+s2);
System.out.println("s3="+s3);

String s4=s1+s2;
System.out.println("s4="+s4);

String s5=new StringBuffer("This is the").append(" String.").toString();
System.out.println("s5="+s5);
```
