# 10.2 基本字节数据流

# 对象流

+   > 能够输入输出对象的流称为对象流。

+   > 通过 ObjectInputStream 和 ObjectOutputStream 两个类实现对象流。

# 写对象数据流

```
Customer c=new Customer();
FileOutputStream f=new FileOutputStream("D:/java/f.txt");
ObjectOutputStream s=new ObjectOutputStream(f);
try{
    s.writeObject(c);
    s.close()
}catch(IOException e){
    e.printStackTrace();
}
```
