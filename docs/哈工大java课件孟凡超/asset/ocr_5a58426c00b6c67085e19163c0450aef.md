# 5.1 抽象数据类型

# ■1 概述

抽象数据类型：是指基于一个逻辑类型的数据类型以及这个个类型上的一组操作。

```
public class Date{
    private int day, month, year;//属性
    Date(){//构造方法
        //方法体
    }
    Date(int day, int month, int year){//带参数构造方法
        //方法体
    }
    Date(Date d){//带参数构造方法
        //方法体
    }
    public Date tomorrow(){//定义方法
        //方法体
    }
}
```

```
Date d=new Date(20,11,1998);
d.tomorrow();
```
