# 2.5 类和对象的初步介绍

Java对类类型变量的内存分配步骤：

对象引用：在内存中为其建立一个引用，并置初值null，表示不指向任何内存空间。

对象实例化：用new申请相应的内存空间，内存空间的大小依class的定义而定，并将该段内存的首地址赋给刚才建立的引用。

对象引用：

```
类名 变量名;
```

```
Point p;
Person zhanSan;
Person liSi;
```

对象实例化：

```
变量名=new 类名(参数列表);
```

```
p=new Point(10,20);
zhanSan=new Person();
liSi=new Person();
```

对象说明(引用+实例化)：

```
类名 变量名=new 类名(参数列表);
```

```
Point p=new Point(10,20);
Person zhanSan=new Person();
Person liSi=new Person();
```
