# 4.3 字符串类型

□字符串操作示例：

```
String s="This is a test String";
String t=s.toUpperCase();
System.out.println("s="+s);
System.out.println("t="+t);

char c=s.charAt(6);
System.out.println("c="+c);
String k=s.substring(0, 6);
System.out.println("k="+k);
System.out.println("s="+s);
System.out.println(s.replace(' ','*'));
```
