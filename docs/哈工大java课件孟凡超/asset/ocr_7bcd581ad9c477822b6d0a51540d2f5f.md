# 2.3 Java的基本数据类型

# 布尔类型---boolean

boolean有两个常量值:false和true，它们全是小写字母，在计算机内用8位表示。

Java是一种严格的类型语言，它不允许数值类型和布尔类型之间进行转换。

```
boolean a=true, b=false, c;
```

# 字符类型---char

单个字符用char类型表示，一个char表示一个Unicode字符，其值用16位无符号数表示，范围为0~2^16-1=65535。

char类型的常量值必须用一对单引号(' ')括起来。

```
char ch1='a', ch2='1', ch3='\t';
```
