# 使用Eclipse开发Java应用程序

步骤5(创建Java项目): 选择 “File” >“New” >“Project” 菜单，打开 “New Project” 窗口。在窗口下方的项目列表中单击 “Java”前面的 “+”号，展开该项目，单击选中 “Java Project”。

步骤6: 单击 “Next” 按钮，打开 “Create a Java Project” 窗口。在 “Project name” 编辑框中输入项目名称，如 “example”。
