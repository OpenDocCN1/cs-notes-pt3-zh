# 4.1 数组

动态初始化：使用运算符new为数组分配空间。数组说明的方括号中的数字表示数组元素个数。

```
type[] arrayName=new type[arraySize];
```

```
type arrayName[]=new type[arraySize];
```

String[] names=new String[3];//定义String类型数组

String names[]=new String[3];//给数组names分配//3个应用空间

```
names[0]="Zhang";
names[1]="Li";
names[2]="Wang";
```
