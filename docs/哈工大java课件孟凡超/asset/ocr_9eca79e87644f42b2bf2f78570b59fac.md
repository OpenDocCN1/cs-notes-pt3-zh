# 4.3 字符串类型

比较：String类中的比较方法有compareTo()、equals()、equalsIgnoreCase()、regionMatches()等。Java中也可以使用关系运算符 "==" 判定两个字符串是否相等。

```
String str1="This is the String.";
String str2="This is the String.";
System.out.println(str1.equals(str2));
System.out.println(str1.equals("This Is the String."));
System.out.println(str1.equalsIgnoreCase("This Is the String."));
System.out.println(str1.regionMatches(0, str2, 0, 4));

if(str1==str2){
    System.out.println("str1 is equale to str2.");
}else{
    System.out.println("str1 isn't equale to str2.");
}
```
