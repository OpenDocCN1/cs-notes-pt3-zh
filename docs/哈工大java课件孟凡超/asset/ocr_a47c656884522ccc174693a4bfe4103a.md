# 3. 表达的提升和转换

转换原则：变量和表达式可以转换为更一般的形式，而不能转换为更受限的形式。如果变量类型至少与表达式类型一样（即位数一样多），就可以认为表达式是赋值相容的。

```
long bigval=6;
int smallval=99L;
float z=12.414f;
float z1=12.414;

int squashed=(int)(bigval);
```

Type mismatch: cannot convert from long to int
2 quick fixes available:
Add cast to 'int'
Change type of 'smallval' to 'long'

Type mismatch: cannot convert from double to float
2 quick fixes available:
Add cast to 'float'
Change type of 'z1' to 'double'
