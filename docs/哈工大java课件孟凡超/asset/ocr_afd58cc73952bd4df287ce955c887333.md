# 5.10 接口

# 接口的实现

```
[类修饰符] class 类名 implements 接口名称 {
    //接口实现
    //其它内容
}
```

✓接口定义

```
interface Storage{
    Object storage[]=new Object[100];
    void put(Object o);//抽象方法
    Object get();        //抽象方法
}
```

✓接口实现

```
class StackStorage implements Storage{
    private int point=0;
    int objectnum=0;
    public void put(Object o){//方法实现
        storage[point++]=o;
        objectnum++;
    }
    public Object get(){//方法实现
        objectnum--;
        return storage[--point];
    }
}
```
