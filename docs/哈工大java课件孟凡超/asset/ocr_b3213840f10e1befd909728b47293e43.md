# 101 数据流基本概念

# ➢ OutputStream

+   • **void write(int i)**
+   
+   该方法的含义是将字节写入数据流中，它只输出低位字节。
+   
+   • **void write(byte[])**
+   
+   该方法的含义是将数组 b[] 中的全部 b.length 个字节写入数据流。
+   
+   • **void write(byte[], int off, int len)**
+   
+   该方法的含义是将数组 b[] 中从第 off 个字节开始的 len 个字节写入数据流。
+   
+   • **void close()**
+   
+   当结束对输出数据流的操作时应该将其关闭。
+   
+   • **void flush()**
+   
+   将缓冲区中不够一个批次的数据强制提交。
