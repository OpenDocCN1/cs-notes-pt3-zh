# 10.4 文件的处理

+   类 RandomAccessFile 来处理文件中随机内容的输入输出

+   创建一个随机访问文件

+   使用文件名

> 决定是以只读方式（"r"）还是以读写方式("rw")访问文件

```
myRAFile=new RandomAccessFile(String name, String mode);
myRAFile=new new RandomAccessFile("file1.txt", "r");
```

```
myRAFile=new RandomAccessFile(File file, String mode);
File myFile= new File("mymotd");
myRAFile=new RandomAccessFile(myFile, "rw");
```
