# 2.5 类和对象的初步介绍

4 类定义示例

```
public abstract class Shape {//抽象类
    Point position;
    abstract void draw();    //抽象方法
    Shape(Point p){          //构造方法
        position=p;
    }
}
abstract class Round extends Shape{//抽象类
    final double pi=3.14159265;    //最终属性
    abstract void draw();          //抽象方法
    abstract double area();        //抽象方法
    Round(Point p){                //构造方法
        /*子类不能从父类中继承构造方法，
        *在子类的构造方法中调用某一父类的构造方法
        */
        super(p);                  //调用父类的构造方法
    }
}
class Circle extends Round{
    int radius;
    void draw(){ //具体方法
        //方法体
    }
    double area(){//具体方法
        return pi*radius*radius;
    }
    Circle(Point p, int radius){
        super(p);//调用父类构造方法
        this.radius=radius;
    }
}
```
