# 5.11 内部类

# 内部类

内部类也称为嵌套类。内部类具有如下属性：

+   - 类名只能在定义的范围内被使用，内部类的名称必须区分于外部类。

+   - 内部类可以使用外部类的类变量和实例变量，也可以使外部类的局部变量。

+   - 内部类可以定义为abstract类型。

+   - 内部类可以被定义为private或protected类型。当一个类中嵌套另外一个类时，访问保护并不妨碍内部类使用外部类的成员。

+   - 被定义为static型的内部类将自动换化为顶层类，它们不再使用局部范围中或其它内部类中的数据变量。

+   - 内部类不能定义static型成员，而只有顶层类才能定义static型成员
