# 3.1 表达式

```
```java
int i=0;
int j=++i;
System.out.println("i="+i+", j="+j);
```
```

i=1, j=1

```
```java
int i=0;
int j=i++;
System.out.println("i="+i+", j="+j);
```
```

i=1, j=0

```
```java
int i=0;
int j=--i;
System.out.println("i="+i+", j="+j);
```
```

i=-1, j=-1

```
```java
int i=0;
int j=i--;
System.out.println("i="+i+", j="+j);
```
```

i=-1, j=0
