# 2.1 Java的基本语法单位

注释：程序中适当地加入注释会增加程序可读性。注释不能插在一个标识符或关键字之中，即要保证程序中最基本元素的完整性。

# 三种注释方式

+   (1) //在一行注释
+   (2) /*一行或多行注释 */
+   (3) /**文档注释 */

```
package example.Charpter_2;

/**
 * 点的定义
 * @author Fanchao Meng
 */
public class Point {
    int x, y;//点的x轴,y轴坐标
    /*
     * 带参数的构造方法
     */
    Point(int x1,int y1){
        x=x1;
        y=y1;
    }
    /*
     * 不带参数的构造方法
     */
    Point(){
        this(0,0);
    }
    /*
     * 点移动到 (x1,y1)
     */
    void moveto(int x1,int y1){
        /*将x1赋予x轴坐标，将y1赋予y轴坐标*/
        x=x1;
        y=y1;
    }
}
```
