# 5.8关键字final

# 终极变量

+   被标记为final的变量称为终极变量。终极变量是一个常量，企图改变终极变量的取值将会引起变异错误。

+   如果将一个引用类型的变量标记为final，那么这个变量不能再指向其它引用，但它所指对象的取值仍然是可以改变的。

```
class Const{
    final float PI=3.14f;
    final String language="Java";
    int number=1;
}
class UseConst{

    Const myConst
    myConst.PI=3.1415926f;

    myConst1=new Const();
}
```

> - The final field Const.PI cannot be assigned
> - Type mismatch: cannot convert from double to float

> The final local variable myConst1 cannot be assigned. It must be blank and not using a compound assignment
