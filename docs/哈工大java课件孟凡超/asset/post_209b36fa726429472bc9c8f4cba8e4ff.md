## 7.2 容器

## 7.2 容器

### 内容窗格

每个顶层容器都有一个内容窗格(ContentPane)，顶层容器中除菜单之外的组件都放在这个内容窗格中。

### 将组件放入内容窗格方法1：

通过顶层容器的getContentPane()方法获取默认的内容窗格，然后将组件添加到内容窗格中。

```
Container contentPane=frame.getContentPane();
contentPane.add(button, BorderLayout.CENTER);
```

```
frame.getContentPane().add(button, BorderLayout.CENTER);
```

## 7.2 容器

✓将组件放入内容窗格方法2：

创建新的内容窗格取代顶层容器默认的内容窗格。

JPanel contentPane=new JPanel();

## 7.2 容器

面板(JPanel)：面板不能独立存在，必须被添加到其他容器内部。

```
package example;
import java.awt.*;

public class FrameWithPanel {

    /**
     * @param args
     */
    public static void main(String[] args) {
        // TODO Auto-generated method stub
        JFrame frame=new JFrame("Frame with Panel");
        Container contentPane=frame.getContentPane();
        contentPane.setBackground(Color.CYAN);//将JFrame实例的背景设置为蓝绿色

        JPanel panel=new JPanel();//创建一个JPanel的实例
        panel.setBackground(Color.yellow);//将JPanel实例的背景设置为黄色
        JButton button=new JButton("Press me");//创建一个JButton的实例
        panel.add(button);//将JButton实例添加到JPanel中
        contentPane.add(panel,BorderLayout.SOUTH);//将JPanel实例添加到JFrame的南侧
        frame.setSize(300,200);
        frame.setVisible(true);
    }
}
```
