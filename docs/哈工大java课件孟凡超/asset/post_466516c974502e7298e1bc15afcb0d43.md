
## 10.2 基本字节数据流

### 管道数据流示例

```
package example.chapter_10;
import java.io.*;

public class PipedStreamDemo {
    public static void main(String[] args) {
        try{
            PipedOutputStream pos=new PipedOutputStream();
            PipedInputStream pis=new PipedInputStream();
            pis.connect(pos);
            byte b[]={65,66,67,68,69,70};
            System.out.println("\nNow I start work......\n");
            System.out.println("transfer data to pos. \n");
            pos.write(b);
            while(pis.available()>0){
                System.out.print((char)pis.read()+" ");
            }
            pis.close();
            pos.close();
        }catch(IOException e){
            System.out.println("Error;cannot read from file.");
        }
    }
}
```

### 对象流

- 能够输入输出对象的流称为对象流。
- 通过 ObjectInputStream 和 ObjectOutputStream 两个类实现对象流。

#### 写对象数据流

```
Customer c=new Customer();
FileOutputStream f=new FileOutputStream("D:/java/f.txt");
ObjectOutputStream s=new ObjectOutputStream(f);
try{
    s.writeObject(c);
    s.close();
}catch(IOException e){
    e.printStackTrace();
}
```

#### 读对象数据流

```
Customer c=null;
FileInputStream f=new FileInputStream("D:/java/f.txt");
ObjectInputStream s=new ObjectInputStream(f);
try{
    c=(Customer)s.readObject();
    s.close();
}catch(IOException e){
    e.printStackTrace();
}
```

### 可持续性

- **持续性：** 记录自己的状态以便将来再生的能力，叫做对象持续性。
- **持续化：** 对象通过写出描述自己状态的数值来记录自己的过程叫做持续化(或串行化)。
- **Serializable接口：** 当一个对象声明实现Serializable接口时，表明该类加入了对象串行化协议。
- **对象输出/输入流：** 要串行化一个对象，必须与特定的对象输出输入流联系起来，通过对象输出流将对象状态保存下来，之后再通过对象输入流将对象状态恢复，这一功能是通过ObjectOutputStream和ObjectInputStream实现的。

### 对象存储、恢复示例

1. 定义可持久化类：

```java
package example.chapter_10;
import java.io.*;
public class Student implements Serializable {
    int id;
    String name;
    int age;
    String department;
    public Student(int id,String name,int age,String department){
        this.id=id;
        this.name=name;
        this.age=age;
        this.department=department;
    }
}
```

2. 对象存储程序：

```
package example.chapter_10;
import java.io.*;
//对象的存储
public class ObjectSer {
    public static void main(String[] args) {
        Student stu1=new Student(981036,"Zhangsan",20,"CS");
        Student stu2=new Student(981037,"Lisi",21,"CS");
        Student stu3=new Student(981038,"Wanger",21,"CS");
        try{
            FileOutputStream fo=new FileOutputStream("D:/java/stu.ser");
            ObjectOutputStream so=new ObjectOutputStream(fo);
            so.writeObject(stu1);
            so.writeObject(stu2);
            so.writeObject(stu3);
            so.close();
        }catch(Exception e){
            e.printStackTrace();
        }
    }
}
```

3. 对象恢复程序：

```
package example.chapter_10;
import java.io.*;
//对象恢复
public class ObjectRecov {
    public static void main(String[] args) {
        Student stu1=null,stu2=null,stu3=null;
        try{
            FileInputStream fi=new FileInputStream("D:/java/stu.ser");
            ObjectInputStream si=new ObjectInputStream(fi);
            stu1=(Student)si.readObject();
            stu2=(Student)si.readObject();
            stu3=(Student)si.readObject();
        }catch(Exception e){
            e.printStackTrace();
        }
        System.out.println("id="+stu1.id+" name="+stu1.name+
                " age="+stu1.age+" department="+stu1.department);
        System.out.println("id="+stu2.id+" name="+stu2.name+
                " age="+stu2.age+" department="+stu2.department);
        System.out.println("id="+stu3.id+" name="+stu3.name+
                " age="+stu3.age+" department="+stu3.department);
    }
}
```

- 串行化只能保存对象的非静态成员变量，而不能保存任何成员方法和静态成员变量，而且保存的只是变量的值，对于变量任何修饰都不能保存。
- 对于不可持续化的成员变量，用关键字transient标记。
- 当数据变量是一个对象时，该对象的数据成员也可以被持久化。对象的数据结构或结构树，包括其子树在内，构成了这个对象的结构表。
