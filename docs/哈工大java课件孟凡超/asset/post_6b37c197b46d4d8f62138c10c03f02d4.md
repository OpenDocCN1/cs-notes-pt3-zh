## 组合框

组合框(JComboBox)是一个下拉式菜单，它有两种形式：不可编辑和可编辑。

- ✓ 对于不可编辑的JComboBox，用户只能在现有的选项列表中进行选择。
- ✓ 对于可编辑的JComboBox，用户既可以在现有选项中选择，也可以输入新的内容。

JComboBox的构造方法：

- ✓ JComboBox()
- ✓ JComboBox(Object[] items)

通过方法setEditable(boolean)设置是否可编辑，默认是不可编辑的。
