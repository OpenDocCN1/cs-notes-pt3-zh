### 10.1 数据流基本概念

**数据流(Data Stream)**

- 在Java中，把不同类型的输入、输出源抽象为流，而其中输入或输出的数据则称为数据流。
- 数据流是指一组有序的、有起点和终点的字节集合。

![](img/ca8bdf2cb3b7905fc97ee695aef3ed57_315_0.png)

数据流分为：输入数据流和输出数据流。输入数据流只能读不能写，而输出数据流只能写不能读。

![](img/ca8bdf2cb3b7905fc97ee695aef3ed57_316_0.png)

Meant for byte transfer (i.e. Binary)

Meant for character transfer (i.e. Text or ASCII)

**输入数据流(Input Stream)**

只能读不能写，用于向计算机内输入信息而用。

![](img/ca8bdf2cb3b7905fc97ee695aef3ed57_317_0.png)

**InputStream**

- `int read()`：它从输入流中读一个字节的二进制数据，然后以此数据为低位字节，配上一个全零字节，形成一个0-255之间的整数返回。当输入流读取结束时，它会得到-1，以标志数据流的结束。
- `int read(byte[] b)`：将多个字节读到数组中，填满整个数组。
- `int read(byte[] b, int off, int len)`：从数据流中读取长度为len的数据，从数组b中索引为off的位置开始放置读入的数据，读毕返回读取的字节数。
- `void close()`：当结束对一个数据流的操作时应该将其关闭，同时释放与该数据流相关的资源。
- `int available()`：该方法返回目前可以从数据流中读取的字节数。
- `long skip(long l)`：该方法跳过数据流中指定数量的字节不读，返回值表示实际跳过的字节数。
- `boolean markSupported()`：用于指示数据流是否支持回退操作，当一个数据流支持 mark() 和 reset() 方法时返回 true，否则返回 false。
- `void mark(int markarea)`：用于标记数据流的当前位置，并划出一个缓冲区，其大小至少为指定参数大小。
- `void reset()`：在执行完随后的 read() 操作后，调用方法 reset() 将回到输入数据流。

只能写不能读的流，用于从计算机中输出数据。

![](img/ca8bdf2cb3b7905fc97ee695aef3ed57_320_0.png)

**OutputStream**

- `void write(int i)`：该方法的含义是将字节写入数据流中，它只输出低位字节。
- `void write(byte[])`：该方法的含义是将数组 b[] 中的全部 b.length 个字节写入数据流。
- `void write(byte[], int off, int len)`：该方法的含义是将数组 b[] 中从第 off 个字节开始的 len 个字节写入数据流。
- `void close()`：当结束对输出数据流的操作时应该将其关闭。
- `void flush()`：将缓冲区中不够一个批次的数据强制提交。

### 10.2 基本字节数据流

```
file1.txt
read
输入流
write
输出流
file2.txt
```

```
import java.io.*;
public class FileStream {

    /**
     * @param args
     */
    public static void main(String[] args) {
        // TODO Auto-generated method stub
        try{
            FileInputStream in=new FileInputStream("file1.txt");
            FileOutputStream out=new FileOutputStream("file2.txt");
            int c;
            while((c=in.read())!=-1){
                out.write(c);
            }
            in.close();
            out.close();
        }catch(FileNotFoundException e){
            e.printStackTrace();
        }catch(IOException e){
            e.printStackTrace();
        }
    }
}
```
