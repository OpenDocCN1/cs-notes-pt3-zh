public void go(){
    p.add(tb1);

    frame.getContentPane().add(p,

                ta.append("\n JToggleButton3"+tb3.isSelected());
            }
        }
    };

    tb2.addItemListener(il);//注册事件监听器

## 复选按钮(JCheckBox)及单选按钮(JRadioButton)

- JCheckBox和JRadioButton是JToggleButton的子类，构造方法的格式与JToggleButton相同。
- JCheckBox和JRadioButton可以通过按钮组(ButtonGroup)进行分组，JCheckBox加入按钮组后只能单选，JRadioButton没有加入按钮组可以多选。
