
## 5.9 抽象类

### 抽象类示例

```
abstract class ObjectStorage{//抽象类
    int objectnum=0;
    Object storage[]=new Object[100];
    abstract void put(Object o);//抽象方法
    abstract Object get();        //抽象方法
}
```

```
class Stack extends ObjectStorage{
    private int point=0;
    public void put(Object o){//实现方法
        storage[point++]=o;
        objectnum++;
    }
    public Object get(){//实现方法
        objectnum--;
        return storage[--point];
    }
}
```

```
class Queue extends ObjectStorage{
    private int top=0;
    private int bottom=0;
    public void put(Object o){//实现方法
        storage[top++]=o;
        objectnum++;
    }
    public Object get(){//实现方法
        objectnum--;
        return storage[bottom++];
    }
}
```

## 5.11 内部类

### 内部类

内部类也称为嵌套类。内部类具有如下属性：

- 类名只能在定义的范围内被使用，内部类的名称必须区分于外部类。
- 内部类可以使用外部类的类变量和实例变量，也可以使外部类的局部变量。
- 内部类可以定义为abstract类型。
- 内部类可以被定义为private或protected类型。当一个类中嵌套另外一个类时，访问保护并不妨碍内部类使用外部类的成员。
- 被定义为static型的内部类将自动换化为顶层类，它们不再使用局部范围中或其它内部类中的数据变量。
- 内部类不能定义static型成员，而只有顶层类才能定义static型成员
