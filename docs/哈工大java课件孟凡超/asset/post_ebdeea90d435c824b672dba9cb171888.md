## 5.7类成员

如果类中包含类成员(类变量/类方法)，系统只在实例化该类的第一个对象的时候，为类成员分配内存，以后再生成该类得实例对象时，将不再为类成员分配内存，不同对象的类变量将共享同一内存空间。

![](img/ca8bdf2cb3b7905fc97ee695aef3ed57_205_0.png)

```
public class Count {
    int serialNumber;
    static int counter=0;
    public Count(){
        counter++;
        serialNumber=counter;
    }
}
```

```
public class UseStatic {
    /**
     * @param args
     */
    public static void main(String[] args) {
        // TODO Auto-generated method stub
        System.out.println("Count.counter="+Count.counter);
        Count Tom=new Count();
        Count John=new Count();
        System.out.println("Tom.serialNumber="+Tom.serialNumber);
        System.out.println("John.serialNumber="+John.serialNumber);
        System.out.println("Now Count.counter="+Count.counter);
    }
}
```

Count.counter=0
Tom.serialNumber=1
John.serialNumber=2
Now Count.counter=2

直接使用类名指向静态变量

### 类方法(静态方法)

在程序设计中，如果需要在尚未创建一个对象实例的时候就去引用它的程序代码，那么标记上关键字static，这样的方法称为类方法或静态方法。

```
public class GeneralFunction {
    public static int addUp(int x,int y){
        return x+y;
    }
    public static int centigradeToFahrenheit(int cent){
        return (cent*9/5+32);
    }
}
```

```
public class UseGeneral {
    int x;
    /**
     * @param args
     */
    public static void main
    // TODO Auto-generated method stub
    int a=9,b=10;
    int c=GeneralFunction.addUp(a,b);
    System.out.println("c="+c);
    x=10;
```

由于静态方法在没有定义它所属的类的对象的情况下加以调用，故不存在this值。

一个静态方法只能使用其内部定义的参数或静态变量，如果企图使用非静态变量将引起编译错误。

## 5.8关键字final

- final可以修饰类或类的成员(成员变量或成员方法)。
- 用final修饰的类或类成员是不能改变的。如果一个方法被定义为final，则不能被重写，如果一个类被定义为final，它不能有子类。

### 终极类

- 被标记为final的类称为终极类，其声明格式如下：

```
final class finalClassName{
    ...
}
```

终极类不能被继承

### 终极方法

被标记为final的方法称为终极方法，其声明格式如下：

```
final returnType finalMethod ([paramlist]){
    ...
}
```

终极方法不能被重写

```
class FinalMehodClass{
    final void finalMethod(){
        //代码
    }
}

class OverloadClass extends FinalMehodClass{
    final void finalMethod(){
        //代码
    }
}
```

- overrides example.chapter_4.chapter_43.FinalMehodClass.finalMethod
- Cannot override the final method from FinalMehodClass

### 终极变量

- 被标记为final的变量称为终极变量。终极变量是一个常量，企图改变终极变量的取值将会引起编译错误。
- 如果将一个引用类型的变量标记为final，那么这个变量不能再指向其它引用，但它所指对象的取值仍然是可以改变的。

## 5.9 抽象类

### 抽象类

- 在Java中可以通过关键字abstract把一个类定义为抽象类。
- 在抽象类中，每一个未被定义具体实现的方法也标记为abstract，称为抽象方法。
- 在程序中不能用抽象类作为模板来创建对象，必须生成抽象类的一个非抽象的子类后才能创建实例。
- 抽象类可以包含抽象方法和非抽象方法，反之，不能在非抽象类中声明抽象方法，即只有抽象类才能具有抽象方法。

### 抽象类定义：

```
[modifier] abstract AbstractClass{
    ...
}
```

### 抽象方法定义：

```
[modifier] abstract <returnType> <methodName>(参数列表);
```
