# 1.2 计算机网络互连

# 网络互连的基本方式（续）

一般来说，网络互连的方式主要有：

# （1）通过中继系统实现网络互连

由于主机和节点是组成网络的基本部分，因此这类互连主要有两种方式：

+   - 节点级互连（又称为分布式计算环境互连）
+   - 主机级互连（又称为数据终端设备DTE互连）

# （2）通过互连网进行网络互连

当互连网络的数目较多时，通常的做法是：先用网关构成一个互连网，并为其制定一个大家都遵守的数据格式（协议），再把各个网络连接到网关上，这样就形成了互连网络。这种方式在数据从源到目的地时进行了两次协议转换：源网络协议→互连网协议；互连网协议→目的网络协议。
