# Destination Unreachable错误消息

# Network Unreachable

+   - 报告Router的路由表中找不到通往目的网络的路径
+     - 试图连接一个私有网络地址
+     - 路由表被破坏
+     - 过时的Router
+   - 源系统和目的系统之间所有的Router都会产生该错误
+   - 只是说明出现了暂时性的路由错误(短期、可修复)

# Port Unreachable

+   - 目的主机上特定目的端口号不可使用
+     - 客户试图连接某个服务器的应用程序,而服务器没有安装该应用程序或没有使用客户期望的端口号
+   - 几乎都由UDP产生
