在最后一个响应报文首部的后面，服务器程序紧跟着图象后发送了一个空行。User-Agent是公有的客户端程序报文头，它用来标识客户端程序的类型。下面是一些公有的报文头的例子：

```
User-Agent: Mozilla/1.1N (Windows; I; 16bit)
User-Agent: NCSA Mosaic/2.6bl (X11;SunOS 5.4 sun4m) libwww/2.12 modified
```
