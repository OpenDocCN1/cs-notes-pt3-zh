# 4.4 差错报告机制ICMP

# Exceeded(超时)错误消息

+   - Time-To-Live Exceeded in Transit
+     - TTL为0, 而数据报还没有到达最终目的地
+     - Router不能转发TTL为0的数据报
+     - 缺省值为30或更多, 除非出现路由循环一般够用
+     - Traceroute
+   - Fragment Reassembly Time Exceeded
+     - 没有在规定时间内收到所有的分段(Unix, 60秒)
+   - 所有Time Exceeded错误消息必须报告给引发这个失败的传输层, 但传输层不该取消这个连接
