# 1.6 Internet的接入方式

# ISP（Internet Service Provider）

+   - 即Internet服务提供商的简称。
+   - ISP一般都建立自己的网络中心，使用专线接入Internet主干线路，提供Internet接入服务

# ICP（Internet Contents Provider）

+   - 即Internet 网页内容供应商
+   - 提供网页发布服务，一般不提供接入服务

# IAP（Internet Acception Provider）

+   - 即Internet接入供应商
+   - 为用户提供接入服务，与ISP基本功能相同。
