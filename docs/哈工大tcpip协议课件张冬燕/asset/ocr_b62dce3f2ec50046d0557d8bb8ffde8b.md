# 中国的顶级域名是cn，下属的二级域名分两类

+   ◆ **机构类别域名（最初为6个，1997年后增加为7个）：**
+     - `ac.cn`——用于科研机构
+     - `com.cn`——用于工、商、金融企业
+     - `edu.cn`——用于教育机构
+     - `org.cn`——用于非赢利组织
+     - `gov.cn`——用于政府部门
+     - `net.cn`——用于互联网

+   ◆ **行政区类别域名（34个）：**
+     适用于各省、市、直辖市，一般取地名前两个汉字的拼音缩写。如：
+     - `bj.cn`——北京
+     - `sh.cn`——上海
