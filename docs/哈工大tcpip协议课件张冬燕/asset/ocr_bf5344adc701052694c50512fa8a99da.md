# 接收Email的新协议IMAP

# IMAP的用途和特点

IMAP（Internet Message Access Protocol：Internet 信息接收协议）指从邮件服务器上直接收取邮件的协议，IMAP可以让用户远程拨号连接邮件服务器，并具有智能邮件存储功能，可在下载邮件之前预览信件主题和信件来源，并决定是否下载附件。用户可以在任何地方、任何机器上获取邮件信息。

由于不同厂商对最新版本的IMAP规范的解释有所不同，使得邮件客户机与服务器之间不一致，造成不同厂商产品之间的不兼容，故目前还没有大规模的使用，但IMAP由于其优越性，在将来不可避免地会得到迅速发展。目前IMAP与POP3共存使用。
