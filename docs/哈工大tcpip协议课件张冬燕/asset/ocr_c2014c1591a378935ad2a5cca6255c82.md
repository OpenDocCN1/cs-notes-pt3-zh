# # 进阶搜索（续）

查询某一类文件（往往带有同一扩展名）

语法： “filetype:”，现在已经可以搜索15种，

+   - Adobe Portable Document Format (pdf)
+   - Adobe PostScript (ps)
+   - Lotus 1-2-3 (wk1, wk2, wk3, wk4, wk5, wki, wks, wku)
+   - Lotus WordPro (lwp)
+   - MacWrite (mw)
+   - Microsoft Excel (xls)
+   - Microsoft PowerPoint (ppt)
+   - Microsoft Word (doc)
+   - Microsoft Works (wks, wps, wdb)
+   - Microsoft Write (wri)
+   - Rich Text Format (rtf)
+   - Shockwave Flash (swf)
+   - Text (ans, txt)
