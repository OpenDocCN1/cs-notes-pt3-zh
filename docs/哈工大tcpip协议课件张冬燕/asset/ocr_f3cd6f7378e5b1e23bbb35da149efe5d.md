# 1.5 Internet的组织管理与相关机构

+   6、WWW协会（W3C）
+   
+   WWW协会（简称：W3C；网址：www.w3c.org）是除了ISOC以外的另一个国际性的Internet组织，其任务在于确定和颁布有关WWW的应用标准。

+   7、中国互联网络信息中心（CNNIC）
+   
+   中国互联网络信息中心（简称：CNNIC；网址：www.cnnic.net.cn）是于1997年6月成立的非赢利的Internet管理与服务机构，行使中国国家互联网络信息中心的职责。
+   
+   主要任务是：1）注册服务（包括：域名注册、IP地址分配、自治系统号分配等）；2）目录数据库服务；3）信息服务；4）网站访问流量认证；5）代表我国与InternNIC、APNIC（亚太互联网络信息中心）等国际机构进行业务联系。
