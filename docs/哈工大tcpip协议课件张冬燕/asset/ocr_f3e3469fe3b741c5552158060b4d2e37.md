# Email的结构形式

# 在Email中常用的关键字及其含义：

+   - From
+     发信人地址（自动）
+   - To
+     收信人地址
+   - Cc（或抄送）
+     复制副本地址（Carbon copy）
+   - Bcc（或密件抄送）
+     盲复制副本地址（Blind Carbon copy）
+   - Subject
+     邮件主题
+   - Date
+     发送邮件日期时间（自动）
+   - Reply To
+     回复地址
+   - X-Charset
+     使用的字符集（通常为ASCII）
+   - X-Mailer
+     发送Email所使用的软件
+   - X-Sender
+     发送方地址的副本
