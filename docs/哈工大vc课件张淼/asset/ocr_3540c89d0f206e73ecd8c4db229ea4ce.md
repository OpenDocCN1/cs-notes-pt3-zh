|  | 用const声明符号常量 | 用#define声明符号常量 |
|---|---|---|
| 解释 | C++语言中广泛采用的声明符号常量的方法 | C语言中声明符号常量的方法。其中#define是预处理指令。缺点是不能显式声明常量的类型。 |
| 形式 | const 数据类型 常量名=常量值；
或：
数据类型 const 常量名=常量值； |  |
| 正确声明 | const double pi=3.1415926; | #define pi 3.1415926
最后不允许加 “；” |
| 错误声明 | const double pi; //错误
pi=3.1415926; //错误 |  |
