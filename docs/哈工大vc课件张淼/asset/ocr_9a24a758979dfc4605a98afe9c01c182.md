# 继承的访问控制

| 继承方式 | 基类特性 | 派生类特性 |
|---|---|---|
| 公有继承 public | public | public |
|  | protected | protected |
|  | private | 不可访问 |
| 私有继承 private | public | private |
|  | protected | private |
|  | private | 不可访问 |
| 保护继承 protected | public | protected |
|  | protected | protected |
|  | private | 不可访问 |
