
## 函数模板与函数重载

+   □ 可以定义相同名字但形参数目或类型不同的多个函数模板，也可以定义和函数模板有相同名字的普通非模板函数

函数模板和非模板函数重载的情况下，一个具体的函数调用，就有多个函数可供选择。具体的选择是根据函数调用所提供的参数进行的。

+   首先寻找函数名和参数能精确匹配的非模板函数
+   如果没有找到，选择参数可以匹配的函数模板
+   如果还不成功，通过参数自动转换，选择非模板函数

## 类模板

+   - [ ] 什么是类模板
     - 类模板是用户为类定义的一种模式，使类中的某些数据成员的类型、成员函数的参数或返回值能够使用任意的数据类型

## 类模板

+   □ 类模板的定义

```
template <class type1,class type2...>
class <类名>
{<类成员说明>};
```

+   ■ 关键字class可以用typename取代，效果完全相同
+   ■ 类型参数可以在成员函数和数据成员中作为数据类型使用

在类模板的外部定义类模板的成员函数时的格式：

+   - 首先要使用类模板的头部，以表明类模板定义了几个类型参数；
+   - 作用域运算符 “::” 前面的类名用类模板名代替，而且也要在尖括号中注明所有类模板的类型参数；
+   - 函数的参数表或者自动变量的定义，则是可以使用类型参数，也可以不使用。

在类外部定义成员函数的格式如下：

```
template < class T1, ......., class Tn>
返回值类型 类模板名< T1,......., Tn > ::
                成员函数名（参数表）
{函数体}
```

```
template <class T>
//类模板：实现对任意类型数据进行存取
class Store
{ private:
    T item;        // 用于存放任意类型的数据
    int haveValue; // 用于标记item是否已被存入内容
public:
    Store();   // 构造函数
    T GetElem(); //提取数据函数
    void PutElem(T x); //存入数据函数
};
```

```cpp
// 缺省构造函数的实现

template <class T>
Store<T>::Store(): haveValue(0) {}

// 提取数据函数的实现

template <class T>
T Store<T>::GetElem()
{
 // 如果试图提取未初始化的数据，则终止程序
 if (haveValue == 0)
 {
  cout << "No item present!" << endl;
  exit(1);
 }
}
return item; // 返回item中存放的数据
}
```

## // 存入数据函数的实现

```
template <class T>
void Store<T>::PutElem(T x)
{
    haveValue++;
    // 将haveValue 置为 TRUE，表示item中已存入数值
    item = x;    // 将x值存入item
}
```

## 类模板的实例化

+   □ 函数模板在调用它或用它对函数指针进行初始化或赋值时实例化。类模板的实例化则是对象的实例化一起完成的，且需显示实例化。
+   ■ 在类模板后面的尖括号中，表明取代类型参数的实际类型名；
+   ■ 再写对象名和构造对象所需要的实参数。
+   □ 一般化的格式如下：
+   ■ 类模板名<类型1,......, 类型n> 对象名(实参数);

## 例 类模板应用举例

```
#include <iostream.h>
#include <stdlib.h>

// 结构体Student

{
```

## // 缺省构造函数的实现

```
template <class T>
Store<T>::Store(): haveValue(0) {}
```

## // 提取数据函数的实现

```
template <class T>
T Store<T>::GetElem()
{

    if (haveValue == 0)
    {
        cout << "No item present!" << endl;
        exit(1);

    return item;   // 返回item中存放的数据

```

## // 存入数据函数的实现

```
template <class T>
void Store<T>::PutElem(T x)
{  haveValue++;
    // 将haveValue 置为 TRUE，表示item中已存入数值
    item = x;      // 将x值存入item
}
```

## 模板的复用

+   - 一个模板可以有很多实例，但是，是否实例化模板的某个实例要由使用情况来决定。
+   - 如果在一个源文件中未使用到一个模板的某个实例，则在相应的目标文件中，编译程序不会生成相应实例的代码。

```
//file2.h
template <class T>
class S  //类模板S的定义
{ T a;
    public:
        void f();
}
void sub();
```

```cpp
//file2.cpp

#include "file2.h"
template <class T>
void S<T>::f()    //类模板S的实现
{
...
}
void sub()
{
  //实例化 “s<float>”并创建该类的一个对象x。
  s<float> x;
  x.f();//ok
}
```

```
//file1.cpp

#include "file2.h"
int main()
{
    S<float>s1;
    s1.f();//ok
    S<int>s2;
    s2.f();//error,连接程序将指出 “void S<int>::f()”不存在

    sub();
    return 0;
}
```

## 模板的复用

+   - 解决办法：将模板的定义和实现都放在头文件中。

## 解决方法

```
//file2.h
template <class T>
class S  //类模板S的定义
{T a;
    public:
        void f();
}
template <class T>
void S<T>::f()  //类模板S的实现
{...
}
extern void sub();
```

## 包含编译模式

这种编译模式下，类模板的成员函数和静态成员的定义必须被包含在“要将它们实例化”的所有文件中，如果一个成员函数被定义在类模板定义之外，那么这些定义应该被放在含有该类模板定义的头文件中。
