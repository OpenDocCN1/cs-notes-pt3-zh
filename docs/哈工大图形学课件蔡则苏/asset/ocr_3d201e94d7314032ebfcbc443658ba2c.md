# # Bezier曲线的性质

p'(t)=n∑_{k=0}^n P_k (BEN_{k,n-1}(t)-BEN_{k,n-1}(t))

=n((P_0-P_0)BEN_{0,n-1}(t)+(P_2-P_1)BEN_{1,n-1}(t)+...+(P_n-P_{n-1})BEN_{n-1,n-1}(t))

=n∑_{k=1}^n (P_k-P_{k-1})BEN_{k-1,n-1}(t)

p'(0)=n∑_{k=1}^n (P_k - P_{k-1})BEN_{k-1,n-1}(0) = n(P_1 - P_0)

p'(1)=n∑_{k=1}^n (P_k - P_{k-1})BEN_{k-1,n-1}(0) = n(P_n - P_{n-1})
