# Create? Yield?

核心是Yield...

+   - 能切换了就知道切换时需要是个什么样子

+   - Create就是要制造出第一次切换时应该的样子

仔细看Yield，就是100跳到300

样子弄明白了，剩下的就是写程序实现这个样子了...

```
100:A()
{
    B();
    104:
}
200: B()
{
    Yield();
    204:
}
```

```
300:C()
{
    D();
    304:
}
400: D()
{
    Yield();
    404:
}
```
