# 用信号量解生产者-消费者问题

```
int fd = open("buffer.txt");
write(fd, 0, sizeof(int)); //写in
write(fd, 0, sizeof(int)); //写out
```

用文件定义共享缓冲区

```
semaphore full = 0;
semaphore empty = BUFFER_SIZE;
semaphore mutex = 1;
```

信号量的定义和初始化

```
Producer(item) {
    P(empty);
    P(mutex);
    读入in;将item写入到
in的位置上;
    V(mutex);
    V(full); }
```

```
Consumer() {
    P(full);
    P(mutex);
    读入out;从文件中的out
位置读出到item;打印item;
    V(mutex);
    V(empty); }
```
