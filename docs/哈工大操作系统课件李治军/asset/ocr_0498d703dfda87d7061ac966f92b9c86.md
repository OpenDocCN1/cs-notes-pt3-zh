# 死锁的4个必要条件

+   - 互斥使用(Mutual exclusion)
+     - 资源的固有特性，如道口

+   - 不可抢占(No preemption)
+     - 资源只能自愿放弃，如车开走以后

+   - 请求和保持(Hold and wait)
+     - 进程必须占有资源，再去申请

+   - 循环等待(Circular wait)
+     - 在资源分配图中存在一个环路
