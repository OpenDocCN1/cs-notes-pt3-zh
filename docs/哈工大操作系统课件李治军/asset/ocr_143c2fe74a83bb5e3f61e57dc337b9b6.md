# 用一个概念来回答问题：什么是操作系统接口？

系统调用! 就像电源插头一样...

先从认识“插头”开始，这是操作系统的常识

POSIX: Portable Operating System Interface of Unix(IEEE制定的一个标准族)

| 分类 | POSIX定义 | 描述 |
|------|----------|------|
| 任务管理 | fork | 创建一个进程 |
|  | exec | 运行一个可执行程序 |
|  | pthread_create | 创建一个线程 |
| 文件系统 | open | 打开一个文件或目录 |
|  | EACCES | 返回值，表示没有权限 |
|  | mode_t st_mode | 文件头结构: 文件属性 |
