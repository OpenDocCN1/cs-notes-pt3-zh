# 面包店算法的正确性

```
choosing[i] = true; num[i] = max(num[0], ..., num[n-1])+1;
choosing[i] = false; for(j=0; j<n; j++) { while(choosing[j]);
while ((num[j] != 0) && (num[j], j)<(num[i], i)); }
```

进程 P_i
临界区
num[i] = 0;

+   - **互斥进入**: P_i在临界区内，P_k试图进入，一定有(num[i], i)<(num[k],k)，P_k循环等待。
+   - **有空让进**: 如果没有进程在临界区中，最小序号的进程一定能够进入。
+   - **有限等待**: 离开临界区的进程再次进入一定排在最后(FIFO)，所以任一个想进入进程至多等n个进程
