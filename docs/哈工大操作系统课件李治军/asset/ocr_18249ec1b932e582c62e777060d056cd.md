# 处理中断page fault

```
//在linux/mm/page.s中
.globl _page_fault
    xchgl %eax, (%esp)
    pushl %ecx
    pushl %edx
    push %ds
    push %es
    push %fs
    movl $0x10, %edx
    mov %dx, %ds
    mov %dx, %es
    mov %dx, %fs
    movl %cr2, %edx

注释：错误码被压到了栈中
注释：页错误线性地址
```
