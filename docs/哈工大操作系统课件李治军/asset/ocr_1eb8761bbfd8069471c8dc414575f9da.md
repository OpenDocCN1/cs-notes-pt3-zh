# 从信号到信号量

+   不只是等待信号、发信号？ 对应睡眠和唤醒！

+   还应该能记录一些信息

+   能记录有 “2个进程等待” 就就可以了...

+   (1) 缓冲区满，P₁执行，P₁ sleep，记录下1个进程等待

+   (2) P₂执行，P₂ sleep，记录下2个进程等待

+   (3) C执行1次循环，发现2个进程等待，wakeup 1个

+   (4) C再执行1次循环，发现?个进程等待，再?

+   (5) C再执行1次循环，怎么办? 此时再来P₃怎么办?

什么是信号量？ 记录一些信息(量)，并根据这个信息决定睡眠还是唤醒(信号)。
