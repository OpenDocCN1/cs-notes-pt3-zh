# 可变分区造成的问题

+   发起请求reqSize=160K怎么办？

+   总空闲空间>160，但没有一个空闲分区>160，怎么办？

+   这就是内存碎片

+   将空闲分区合并，需要移动1个段(复制内容)：内存紧缩

+   内存紧缩需要花费大量时间，如果复制速度1M/1秒，则1G内存的紧缩时间为1000秒≈17分钟
