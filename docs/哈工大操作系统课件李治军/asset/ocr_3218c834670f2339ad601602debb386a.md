+   - 用户程序调用whoami，一个字符串 “lizhijun” 放在操作系统中(系统引导时载入)，取出来打印

+   - 不能随意的调用数据，不能随意的jmp。

+   - 可以看到root密码，可以修改它...

+   - 可以通过显存看到别人 100: “lizhijun” 人word里的内容...

```
main()
{ whoami(); }
```

```

{
  printf(100, 8);
}
```
