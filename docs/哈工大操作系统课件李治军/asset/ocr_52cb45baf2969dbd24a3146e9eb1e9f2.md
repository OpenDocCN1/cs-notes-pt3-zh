# 那就让首先程序进入内存

```
int main(int argc, char* argv[])
{ ...
```

```
.text
_entry: //入口地址
  call _main
  call _exit
_main:
  ...
  ret
```

```
_entry: //入口地址
  call 40
  call xx
_main: //偏移是40
  ...
```

内存地址 40
IP → 0
物理内存

```
...
_main: mov [300], 0
...
call xx
call 40
```
