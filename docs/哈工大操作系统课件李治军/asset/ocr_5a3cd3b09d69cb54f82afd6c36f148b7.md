# 内核线程switch_to的五段论

```
中断入口：(进入切换)
push ds;... pusha;
mov ds, 内核段号; ...
call 中断处理
???:
```

```
switch_to: (内核栈切换)
TCB[cur].esp=%esp;
%esp=TCB[next].esp;
ret
```

```
S、T非同一进程：(地址切换)
要首先切换地址映射表;
TCB[cur].ldtr=%ldtr
%ldtr=TCB[next].ldtr
//内存管理
```

```
中断处理：(引发切换)
启动磁盘读或时钟中断;
schedule();
}//ret
```

```
中断出口：(二级切换)
popa;...; pop ds;
iret
```

```
schedule: next=..;
call switch_to;
}//ret
```
