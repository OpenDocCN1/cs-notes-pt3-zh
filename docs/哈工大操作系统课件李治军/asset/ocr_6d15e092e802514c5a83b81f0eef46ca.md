# 从IBSYS到OS/360(1965-1980)

计算机开始进入多个行业： 科学计算(IBM 7094)， 银行(IBM 1401)

+   - 需要让一台计算机干多种事
+   - 多道程序(multiprogramming)
+   - 作业之间的切换和调度成为核心： 因为既有IO任务，又有计算任务，需要让CPU忙碌
+   - 典型代表： IBM OS/360(360表示全方位服务)， 开发周期5000个人年

> 多进程结构和进程管理概念萌芽！
