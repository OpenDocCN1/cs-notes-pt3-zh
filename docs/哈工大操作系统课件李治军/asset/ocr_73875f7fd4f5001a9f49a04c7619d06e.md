# 如果信号量这样使用

```
Producer(item) {
  P(empty);   mutex
  P(mutex); empty
  读入in;将item写入到
  in的位置上;
  V(mutex);
  V(full); }
```

```
Consumer() {
  P(full); mutex
  P(mutex); full
  读入out;从文件中的out
  位置读出到item;打印item;
  V(mutex);
  V(empty); }
```

问题：会出什么问题，举一个出现这种情况的例子？

我们将这种多个进程由于互相等待对方持有的资源而造成的谁都无法执行的情况叫死锁
