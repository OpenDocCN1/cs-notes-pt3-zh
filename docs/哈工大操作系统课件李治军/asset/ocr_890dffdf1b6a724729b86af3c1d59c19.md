# 从纸上到实际：生产者-消费者实例

共享数据

```
#define BUFFER_SIZE 10
typedef struct { ... } item;
item buffer[BUFFER_SIZE];
int in = out = counter = 0;
```

生产者进程

```
while (true) {
while(counter== BUFFER_SIZE)
;
buffer[in] = item;
in = (in + 1) % BUFFER_SIZE;
counter++;
}
```

消费者进程

```
while (true) {
while(counter== 0)
;
item = buffer[out];
out = (out + 1) % BUFFER_SIZE;
counter--;
}
```
