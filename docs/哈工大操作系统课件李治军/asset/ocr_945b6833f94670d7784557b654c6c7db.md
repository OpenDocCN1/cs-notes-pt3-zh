# 还要说一说Mac OS与iOS

+   - 1984年，苹果推出PC(麦金塔机，Macintosh)，简称Mac机，其处理器使用IBM、Intel或AMD等，核心在于屏幕、能耗等
+     - 与Mac机一起发布System X系统，一上来就是GUI
+     - 在System 7以后改名为Mac OS 8
+     - 2007年发布iOS，核心仍然是Mac OS，专为移动设备，如手势等
+     - Mac OS核心是UNIX，专注于界面、文件、媒体等和用户有关的内容
