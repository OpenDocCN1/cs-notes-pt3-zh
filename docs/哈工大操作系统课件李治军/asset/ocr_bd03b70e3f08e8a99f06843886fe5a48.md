# 只发信号还不能解决全部问题

```
生产者
while (true) {
if(counter== BUFFER_SIZE)
sleep();
...
counter = counter + 1;
if(counter ==1) wakeup(消费者);}
```

```
消费者
while (true) {
if(counter== 0) sleep();
...
counter = counter - 1;
if(counter == BUFFER_SIZE-1)
wakeup(生产者); }
```
