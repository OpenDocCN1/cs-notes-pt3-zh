# copy_process的细节：创建栈

```
p=(struct task_struct *)get_free_page();
    //申请内存空间
p->tss.esp0 = PAGE_SIZE + (long) p;
p->tss.ss0 = 0x10;
    //创建内核栈
p->tss.ss = ss & 0xffff;
p->tss.esp = esp;
    //创建用户栈(和父进程共用栈)
```

+   申请内存空间；
+   创建TCB；
+   创建内核栈和用户栈；
+   填充两个stack；
+   关联栈和TCB；
