# 3.2 二叉树（Cont.）

带表头节点的中序线索二叉树

![](bbox=[0.12, 0.26, 0.88, 0.62])

| lchild | ltag | data | rchild | rtag |

```
非空二叉树：
head->lchild = T;    （根）
head->ltag = TRUE ;
head->rchild = head ;
head->rtag = TRUE ;
```

```
空二叉树：
head->lchild = head ;
head->ltag = FALSE ;
head->rchild = head ;
head->rtag = TRUE ;
```
