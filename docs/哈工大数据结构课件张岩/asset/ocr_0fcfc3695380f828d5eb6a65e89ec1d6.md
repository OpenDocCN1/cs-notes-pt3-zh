# 2.2线性表的存储结构----链表（Cont.）

操作的实现---- ② Locate（ElemType x, LIST L）

```
position Locate ( Elementtype x, LIST L )
{
    position p;
    p = L;
    while ( p→next != NULL )
        if ( p→next→data == x )
            return p;
        else
            p = p→next;
    return p;
} //时间复杂性：O(n)
```
