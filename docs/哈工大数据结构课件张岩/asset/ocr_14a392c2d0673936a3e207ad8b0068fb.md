# 4.5 最短路径算法(cont.)



+   - Dijkstra提出按路径长度的递增次序，逐步产生最短路径的贪心算法---Dijkstra算法 (SPF算法) 。
+   - 首先求出长度最短的一条最短路径,再参照它求出长度次短的一条最短路径，依次类推，直到从顶点v到其它各顶点的最短路径全部求出为止。
