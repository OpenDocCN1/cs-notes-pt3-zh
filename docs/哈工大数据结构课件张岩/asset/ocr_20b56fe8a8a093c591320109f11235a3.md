# 6.4 直接选择排序 (cont.)

算法的实现

```
void SelectSort (int n, LIST A )
{
	keytype lowkey; //当前最小关键
	int i,j,lowindex; //当前最小关键的下标
	for(i=1; i<n; i++) { //在A[i...n]中选择最小的关键，与A[i]交换
		lowindex = i ;
		lowkey = A[i].key ;
		for ( j = i+1; j<=n; j++)
			if (A[j].key<lowkey) { //用当前最小关键与每个关键比较
				lowkey=A[j] ;
				lowindex = j ;
			}
		swap(A[i], A[lowindex]) ;
	}
}
```
