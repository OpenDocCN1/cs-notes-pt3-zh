# 4.6 拓扑排序算法(cont.)

拓扑排序算法——实质是广度优先搜索算法

```
void Topologicalsort( AdjGraph G )
{ QUEUE Q ; nodes = 0 ;
    MAKENUILL( Q ) ;
    for( v=1; v<=G.n ; ++v )
        if ( indegree[v] ==0 ) ENQUEUE( v, Q ) ;
    while ( !EMPTY( Q ) ) {
        v = FRONT(Q) ;
        DEQUEUE( Q ) ;
        cout << v ;  nodes ++ ;
        for( 邻接于 v 的每个顶点 w )
            if( !(--indegree[w])) ENQUEUE(w,Q) ;
    }
    if ( nodes < n ) cout<<"图中有环路" ;
}
```
