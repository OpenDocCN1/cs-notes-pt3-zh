# 2.2 线性表的存储结构----一元多项式(Cont.)

多项式加法：

```
polypointer PolyAdd( polypointer a , polypointer b )
{  polypointer p, q, d, c ;
    int y ;
    p = a→link ;  q = b→link ;
    c = new polynode ;  d = c ;
    while ( (p != NULL) && (q != NULL) )
        switch ( Compare ( p→exp, q→exp ) )
        { case ‘=’ :
                y = p→coef + q→coef ;
                if ( y )  d = Attch( y, p→exp, d ) ;
                p = p→link ; q = q→link ;
                break ;
            case ‘>’ :
                d = Attch( p→coef, p→exp, d );
```
