# 其他操作的实现

```
position Previous( position p , LIST L ) //⑤
{
    if ( ( p <= 1 ) || ( p > L.last ) )
        cout<< “前驱元素不存在”;
    else
        return ( p - 1 );
} //时间复杂性： O(1)
```

```
position Next( position p , LIST L ) //⑥
{
    if ( ( p < 1 ) || ( p >= L.last ) )
        cout<< “前驱元素不存在”;
    else
        return ( p + 1 );
} //时间复杂性： O(1)
```
