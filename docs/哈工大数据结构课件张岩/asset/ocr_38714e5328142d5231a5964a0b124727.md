# 5.4 分块查找（Cont.）

```
int index_search(keytype k, int last, int blocks, INDEX ix, LIST F, int L )
{ int i =0, j;
    while (( k > ix[i])&&( i < blocks)) /*查索引表,确定k 所在块i*/
        i++ ;
    if( i<blocks ) {
        j = i*L;  /* 第i 块的起始下标 */
        while(( k != F[j].key )&&( j <= (i+1)*L-1 )&&( j < last ))
            j = j + 1;
        if( k == F[ j ].key ) return  j ; /* 查找成功 */
    }
    return  -1 ; /* 查找失败 */
}
```
