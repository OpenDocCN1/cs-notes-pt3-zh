# 基于DFS的拓扑排序

```
void topodfs ( v )
{ PUSH( v ,S );
mark[v]=TRUE;
for ( L[v] 中的每一个顶点w )
    if ( mark[w] = FALSE )
        topodfs ( w );
printf ( top( S ) );
POP ( S );
}
```

```
void dfs-topo ( GRAPH L )
{ MAKENULL( S );
for( u=1;u<=n;u++ )
    mark[u]=FALSE;
for( u=1;u<=n;u++ )
    if ( !mark[u] )
        topodfs( u );
}
```

思想：借助栈，在DFS中，把第一次遇到的顶点入栈，到达某一顶点递归返回时，从栈中弹出顶点并输出。
