# 2.3.2 栈的指针实现---链栈(Cont.)

栈的操作的实现

```
①STACK MakeNull()
{
    STACK s;
    s=new node;
    /*s=(node *)malloc(sizeof(node));*/
    s->next=NULL;
    return s;
}
```

```
②boolean Empty(STACK stk)
{
    if (stk->next)
        return FALSE;
    else
        return TRUE;
}
```
