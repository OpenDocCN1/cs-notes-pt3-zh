# 4.4 最小生成树算法(cont.)

# 实现步骤：

+   1. 初始化两个辅助数组LOWCOST和CLOSSET；
+   2. 输出顶点v₁，将顶点v₁加入集合U中；
+   3. 重复执行下列操作n-1次
+      3.1 在LOWCOST中选取最短边，取CLOSSET中对应的顶点序号k；
+      3.2 输出顶点k和对应的权值；
+      3.3 将顶点k加入集合U中；
+      3.4 调整数组LOWCOST和CLOSSET；

```
{
LOWCOST[j]=min { cost (v_k, v_j) | v_j ∈ U }
CLOSSET[j]=k
}
```
