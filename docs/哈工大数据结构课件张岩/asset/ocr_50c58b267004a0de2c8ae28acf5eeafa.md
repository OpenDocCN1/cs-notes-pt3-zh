# 2.2线性表的存储结构---顺序表（Cont.）

时间性能分析

+   - 基本语句？
+   - 最好情况（ i=n+1 ）：
+     - 基本语句执行0次，时间复杂度为 O(1)。
+   - 最坏情况（ i=1 ）：
+     - 基本语句执行 n+1 次，时间复杂度为 O(n)。
+   - 平均情况（ 1≤i≤n+1 ）：
+     - ∑_{i=1}^{n+1} p_i (n - i +1)= 1/(n+1) ∑_{i=1}^{n+1} (n - i +1)= n/2 =O(n)
+   - 时间复杂度为 O(n)。
