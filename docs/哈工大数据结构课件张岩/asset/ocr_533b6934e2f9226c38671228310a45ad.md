# 3.2 二叉树（Cont.）

方法2：按先序序列建立二叉树的左右链存储结构。

+   如由图所示二叉树,输入:ABDH##I##E##CF#J##G##
+   其中：#表示空

```
void CreateBT(BTREE & T)
{ cin >> ch ;
    if ( ch == ‘#’ ) T = NULL ;
    else{
        T → data = ch ;
        CreateBT ( T → lchild ) ;
        CreateBT ( T → rchild ) ;
    }
}
```
