# 2.2 线性表的存储结构----单向环形链表(Cont.)

在表左端插入节点 LInsert(x,R) → Insert(x,First(R),R)

```
void LInsert( Elementtype x , LIST &R )
{
    celltype *p;
    p = new celltype;
    p→data = x;
    if ( R == NULL )
    { p→next = p; R = p; }
    else
    { p→next = R→next; R→next = p; }
}
```
