# 6.7 希尔排序---分组插入排序（cont.）

# 算法的实现

```
void ShellSort(int n, LIST A)
{
    int i, j, d;
    for (d=n/2; d>=1; d=d/2) {
        for (i=d+1; i<=n; i++) { //将A[i]插入到所属的子序列中
            A[0].key= A[i].key;   //暂存待插入记录
            j=i-d;               //j指向所属子序列的最后一个记录
            while (j>0 && A[0].key< A[j].key) {
                A[j+d]= A[j]; //记录后移d个位置
                j=j-d;   //比较同一子序列的前一个记录
            }
            A[j+d]= A[0];
        }
    }
}
```
