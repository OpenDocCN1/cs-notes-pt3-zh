# 6.1 基本概念

# 排序（sorting）也称分类：

假设给定一组n个记录序列{r₁, r₂, ......, rₙ}，其相应的关键字序列为{k₁, k₂, ......, kₙ}。排序是将这些记录排列成顺序为{rₛ₁, rₛ₂, ......, rₛₙ}的一个序列，使得相应的关键字的
值满足kₛ₁ ≤ kₛ₂ ≤ ...... ≤ kₛₙ（称为升序）或
kₛ₁ ≥ kₛ₂ ≥ ...... ≥ kₛₙ（称为降序）。

# 排序的目的：方便查询和处理。

# 排序算法的稳定性：

假设在待排序的记录集中，存在多个具有相同关键字值的记录，若经过排序，这些记录的相对次序仍然保持不变，即在原序列中，kᵢ=kⱼ且rᵢ在rⱼ之前，而在排序后的序列中，rᵢ仍在rⱼ之前，则称这种排序算法是稳定的；否则称为不稳定的。
