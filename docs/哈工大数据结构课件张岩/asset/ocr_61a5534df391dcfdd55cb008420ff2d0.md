# 2.5.3 模式匹配(Cont.)

# 思考的开始：

+   - 假设主串为 S₁S₂…Sₙ，模式串为 T₁T₂…Tₘ

+   - 无回溯匹配问题变为：当主串中的第 i 个字符和模式串中第 j 个字符出现不匹配，主串中的第 i 个字符应该与模式串中的哪个字符匹配（无回溯）？

# 进一步思考

+   - 假设主串中第 i 个字符与模式串第 k 个字符相比较，则应有
+     - T₁T₂…Tₖ₋₁ = Sᵢ₋₍ₖ₋₁₎Sᵢ₋₍ₖ₋₂₎…Sᵢ₋₁
+     - 问题可能有多个 k，取哪一个？

+   - 而根据已有的匹配，有
+     - Tⱼ₋₍ₖ₋₁₎Tⱼ₋₍ₖ₋₂₎…Tⱼ₋₁ = Sᵢ₋₍ₖ₋₁₎Sᵢ₋₍ₖ₋₂₎…Sᵢ₋₁

+   - 因此
+     - T₁T₂…Tₖ₋₁ = Tⱼ₋₍ₖ₋₁₎Tⱼ₋₍ₖ₋₂₎…Tⱼ₋₁
