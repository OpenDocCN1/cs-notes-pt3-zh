# 邻接矩阵（Adjacency Matrix）表示（数组表示法）

存储结构定义：假设图G有n个顶点e条边，则该图的存储需求为O(n+n²)=O(n²)，与边的条数e无关。

```
typedef struct {
    VertexData vertex[NumVertices]; //顶点表
    EdgeData edge[NumVertices][NumVertices];
    //邻接矩阵—边表，可视为边之间的关系
    int n, e; //图的顶点数与边数
} MTGraph;
```
