# 5.5 二叉查找树BST（Cont.）

二叉查找树的查找操作：

```
BSTNode * SearchBST( keytype k, BST F )
{  BSTNode * p = F;
    if( p == NULL || k == p->data.key ) /* 递归终止条件 */
        return  p;
    if( k < p->data.key )
        return ( SearchBST ( k, p->lchild ) ); /* 查找左子树 */
    else
        return ( SearchBST ( k, p->rchild ) ); /* 查找右子树 */
}
```
