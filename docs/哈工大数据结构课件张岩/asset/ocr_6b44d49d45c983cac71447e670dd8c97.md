# 2.3.1 栈的数组实现---顺序栈(Cont.)

```
③ ElemTtype Top( STACK S )
{ if ( Empty( S )
    return NULL;
    else
    return ( S.elements[ S.top ] );
}
```

```
④ void Pop( STACK &S )
{
    if ( Empty( S ) )
    cout<< "栈空";
    else
    S.top = S.top - 1 ;
}
```
