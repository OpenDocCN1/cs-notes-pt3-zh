# 3.6 森林(树)与二叉树间的转换（Cont.）

# 森林（树）转换成二叉树的递归算法

+   - F={T1,T2, …,Tn}  二叉树B(F)
+   - 若n=0，则B(F)为空；否则，n＞0，则
+     - B(F)的根就是root（T1）；
+     - B(F)的左子树是F的第一棵树T1的子树森林；
+     - B(F)的右子树F的其余子树森林。

# 二叉树转换成森林(树)的递归算法

+   - 若B为空，则F为空；若B不空，则
+     - F中的第一棵树T1的根对应二叉树B的根；
+     - T1中根结点的子树森林F1是由B的左子树转换来的；
+     - F中除T1之外其余子树组成的森林F’={T2,…Tn}是由B的右子树转换而来的。
