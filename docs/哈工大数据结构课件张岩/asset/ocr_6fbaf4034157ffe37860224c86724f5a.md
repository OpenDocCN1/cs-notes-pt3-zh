# 3.5 树（Cont.）

用树的基本操作写先序遍历的递归算法

```
void PreOrder(node n, TREE T)
{
    node c;
    visit( Data( T ) );
    c = LeftMostChild( n , T );
    while ( c != NULL ) {
        PreOrder( c , T );
        c = RightSibling( c , T );
    }
}
```
