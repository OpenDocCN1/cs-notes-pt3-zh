迷宫求解问题

N:(i-1, j)
NW:(i-1, j-1)
NE:(i-1, j+1)
W:(i, j-1)
E:(i, j+1)
SW:(i+1, j-1)
SE:(i+1, j+1)
S:(i+1, j)

| V | i | j | 说明 |
|---|---|---|------|
| 1 | 0 | 1 | E |
| 2 | 1 | 1 | SE |
| 3 | 1 | 0 | S |
| 4 | 1 | -1 | SW |
| 5 | 0 | -1 | W |
| 6 | -1 | -1 | NW |
| 7 | -1 | 0 | N |
| 8 | -1 | 1 | NE |

从(i, j)到(g, h)且 v = 2 (东南) 则有：

```
g = i + move[2, 1] = i + 1;
h = j + move[2, 2] = j + 1;
```
