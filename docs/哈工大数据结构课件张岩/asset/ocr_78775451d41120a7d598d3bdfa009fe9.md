# 二路归并排序的基本思想（自底向上的非递归算法）

+   - 将一个具有 n 个待排序记录的序列看成是 n 个长度为 1 的有序序列；
+   - 然后进行两两归并，得到 ⌈n/2⌉ 个长度为 2 的有序序列；
+   - 再进行两两归并，得到 ⌈n/4⌉ 个长度为 4 的有序序列；
+   - ……，
+   - 直至得到 1 个长度为 n 的有序序列为止。
