# 1.5 逐步求精的程序设计方法(Cont.)



```
void greedy(GRAPH G, SET newclr)
{ newclr=0 ; int found;
 v=G中第一个未着色的顶点;
 while (v!=0){ /*G中还有未着色的顶点v*/
 found=0;
 w=newclr中的第一个顶点; /*newclr中的顶点还没取尽*/
 while(w!=0){ /*newclr中的顶点还没取尽*/
 if(v和w相邻)
 found=1;
 w=newclr中的下一个顶点;
 }
 if(found==0){
 对v着色;
 将v放入newclr;
 }
 v=G中下一个未着色的顶点;
 }
}
```
