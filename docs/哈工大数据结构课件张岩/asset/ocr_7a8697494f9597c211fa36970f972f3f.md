# 3.7 树型结构的应用（Cont.）

用树结构表示集合

基本操作的实现

```
int Find(int i, MFSET parent)
{
    int tmp=i;
    while(parent[tmp]!=-1) /* >0, 未到根 */
        tmp=parent[tmp]; /* 上溯 */
    return tmp;
}//O(n)
```

```
void Initial(int x,MFSET parent)
{
    parent[x]=0;
}//O(1)
```
