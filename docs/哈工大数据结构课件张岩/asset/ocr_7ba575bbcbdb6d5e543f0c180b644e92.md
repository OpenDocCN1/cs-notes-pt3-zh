# 6.9 基数排序---多关键字排序（cont.）

# 算法的改进：

由于每个桶（箱）存放多少个关键字分量相同的记录个数无法预料，即队列Q[0]，Q[1]，..., Q[9]长度很难确定，故桶一般设计成链式排队，两个排队链在一起的方法如下：

```
void Concatenate(QUEUE Q1, QUEUE Q2)
{
    if (!EMPTY(Q2)) {
        Q1.rear->next=Q2.front->next;
        Q1.rear=Q2.rear;
    }
}
```
