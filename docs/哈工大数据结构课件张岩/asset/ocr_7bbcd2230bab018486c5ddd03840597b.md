# 2.2线性表的存储结构---链接表（Cont.）

操作的实现--- ⑤ position Previous(position p,LIST L)

```
position Previous ( position p, LIST L )
{ position q;
    if ( p == L→next )
        cout << “不存在前驱元素”；
    else {
        q = L;
        while ( q→next != p ) q = q→next ;
        return q;
    }
} //时间复杂度： O(n)
```
