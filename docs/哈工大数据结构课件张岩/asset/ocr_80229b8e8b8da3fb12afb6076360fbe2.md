# 3.2 二叉树（Cont.）

# 遍历算法应用举例

+   - 二叉树的遍历是二叉树各种操作和算法的基础，遍历算法中对每个结点的“访问”操作可以是对结点进行的各种处理

+   - 根据遍历算法的框架，适当修改访问操作的内容，可以派生出很多关于二叉树的应用程序算法。

+   - 因此，二叉树遍历算法是有关于二叉树算法中最核心的算法。

# 计算二叉树结点个数的递归算法。

```
int Count ( BTREE T )
{
    if ( T == NULL ) return 0;
    else return 1 + Count ( T->lchild )
        + Count ( T->rchild ); };
}
```

```
struct node {
    struct node *lchild ;
    struct node *rchild ;
    datatype data ;
};
typedef node * BTREE;
```
