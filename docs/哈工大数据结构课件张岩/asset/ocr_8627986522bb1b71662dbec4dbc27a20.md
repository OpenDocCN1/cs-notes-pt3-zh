# 3.7 树型结构的应用（Cont.）

哈夫曼树构造算法的实现步骤：

+   1 初始化：将T[0], ...T[2n-2]共 2n-1个结点的三个链域均置空(-1)，权值为 0；

+   2 输入权值：读入 n 个叶子的权值存于T的前 n 个单元 T[0], ...T[n]，它们是 n 个独立的根结点上的权值；

+   3 合并：对二叉树集合进行 n-1次合并：

+   3.1 在二叉树集合T[0], ...T[i-1]中选取权值最小和次最小的两个根结点T[p1]和T[p2]作为合并对象，这里 0<= p1， p2<= i-1；

+   3.2 将根为 T[p1]和T[p2]的两棵二叉树作为左、右子树合并为一棵新二叉树，新二叉树的根结点为T[i]。
