# B-树的插入操作与建立

+   此时必须把结点 p 分裂成两个结点 p 和 q，它们包含的信息分别为：

+   结点 p：
+   （⌈m/2⌉-1 A₀, K₁, A₁, …… , K⌈m/2⌉-1, A⌈m/2⌉-1）

+   结点 q：
+   （m - ⌈m/2⌉, A⌈m/2⌉, K⌈m/2⌉+1, A⌈m/2⌉+1, …… , Kₘ, Aₘ）

+   位于中间的关键字 K⌈m/2⌉ 与指向新结点 q 的指针形成一个二元组（K⌈m/2⌉, q），插入到这两个结点的双亲结点中去。

+   在插入该二元组之前，先将结点 p 和 q 写到磁盘上。
