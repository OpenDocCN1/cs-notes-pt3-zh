# 2.2线性表的存储结构---顺序表（Cont.）

其他操作的实现

```
position MakeNull( LIST &L ) //⑦
{  L.last = 0;
    return ( L.last +1 );
} //时间复杂度： O(1)
```

```
position First( LIST L ) //⑧
{ if ( L.last>0 )  return ( 1 );
  else cout<<“表为空”
} //复杂度： O(1)
```

```
position End( LIST L )  //⑨
{ return( L.last + 1 );
} // O(1)
```
