# 6.5 堆排序 (cont.)



把具有如下性质的数组A表示的完全二叉树称为（最小）堆：

+   ■ (1) 若2*i < n ，则A[i].key ≤ A[2*i].key ；
+   ■ (2) 若2*i+1 < n ，则A[i].key ≤ A[2*i+1].key 。

把具有如下性质的数组A表示的完全二叉树称为（最大）堆：

+   ■ (1) 若2*i < n ，则A[i].key ≥ A[2*i].key ；
+   ■ (2) 若2*i+1 < n ，则A[i].key ≥ A[2*i+1].key 。
