# 3.2 二叉树（Cont.）

按先序次序打印二叉树中的叶子结点的算法.

```
void PreOrder(BTREE T)
{
    if (T) {
        if (!T->lchild && !T->rchild)
            cout<<T->data;
        PreOrder(T->lchild);
        PreOrder(T->rchild);
    }
}
```

```
struct node {
    struct node *lchild ;
    struct node *rchild ;
    datatype data ;
};
typedef node * BTREE;
```
