# 1.5 逐步求精的程序设计方法(Cont.)

+   3.逐步求精：第三步求精：

```
void greedy(GRAPH G, SET newclr)
/*类型GRAPH和SET有待说明*/
{
    int found;
    elementtype v,w;/*elementtype可以自定义*/
    MAKENULL(newclr);
    v=FIRSTG(G);
    while(v!=NULL){
        found=0;
        w=FIRSTS(newclr);
        while(w!=NULL){
            if(EDGE(v,w,G))
                found=1;
            w=NEXTS(newclr);
        }
        v=NEXTG(G);
    }
}
```

# 4.ADT的实现：

按上述函数，最后一步工作就是给出类型elementtype的定义和实现抽象数据类型GRAPH及SET。此后，上述函数就是可执的程序了。
