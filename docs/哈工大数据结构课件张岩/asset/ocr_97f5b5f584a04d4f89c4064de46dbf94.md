# 2.2 线性表的存储结构---链接表（Cont.）

操作的实现----④删除操作

+   - q = p→next ;
+   - p→next = q→next ;
+   - delete q ;

```
void Delete ( position p, LIST &L )
{
  position q;
  if ( p→next != NULL ) {
    q = p →next ;
    p →next = q →next ;
    delete q ;
  }
}
```

时间复杂度： O（1）

（a）删除第一个元素

（b）删除中间元素

（c）删除表尾元素
