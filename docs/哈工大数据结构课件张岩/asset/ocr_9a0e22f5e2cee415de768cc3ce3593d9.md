# Floyd算法的应用----求有向图的中心点

+   顶点的偏心度：

设G=(V, E)是一个带权有向图，d[i][j]表示从 i 到 j 的最短距离。对任意一个顶点k, E(k) = max{ d[i][k] | i ∈ V }称作顶点k的偏心度。

+   图G的中心点：

称具有最小偏心度的顶点为图G的中心点。
