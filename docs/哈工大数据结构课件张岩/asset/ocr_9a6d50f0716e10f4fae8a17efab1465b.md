# 层序遍历算法

```
void LeverOrder (BTREE root)
{ front=rear=0; //采用顺序队列，并假设不会发生上溢
    if (root==NULL) return;
    Q[++rear]=root;
    while (front!=rear) {
        q=Q[++front];
        cout<<q->data;
        if (q->lchild!=NULL) Q[++rear]=q->lchild;
        if (q->rchild!=NULL) Q[++rear]=q->rchild;
    }
}
```
