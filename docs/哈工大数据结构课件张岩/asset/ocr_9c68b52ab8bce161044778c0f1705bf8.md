算法分析——例：编写求 n! 的程序，并分析其时间复杂性。

# 求 n! 的递归算法

```
long fact ( int n)
{
    if ( n==0 || ( n ==1 )
        return( 1 );
    else
        return( n * fact(n-1));
}
```

# 时间复杂性的递归方程

$$T(n)=\begin{cases} C, & \text{当 } n=0,\ n=1 \\ G+T(n-1), & \text{当 } n>1 \end{cases}$$

# 解递归方程：

$$T(n)=G+T(n-1)$$
$$T(n-1)=G+T(n-2)$$
$$T(n-2)=G+T(n-3)$$
……
$$T(2)=G+T(1)$$
$$+\ T(1)=C$$
因此：
$$T(n)=G(n-1)+C$$

取 $f(n)=n$
∴ $T(n)=O(f(n))$
　　 $=O(n)$
