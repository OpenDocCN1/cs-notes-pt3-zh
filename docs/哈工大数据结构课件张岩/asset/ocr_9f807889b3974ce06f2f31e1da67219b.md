# 6.5 堆排序（cont.）

堆排序的实现：

```
void HeapSort ( int n , LIST A )
{
    int i;
    for( i=n/2; i<=1; i++ ) /*初始建堆，从最右非叶结点开始*/
        PushDown( i, n ); /*整理堆，把以i为根，最大下标的叶为n*/
    for( i=n; i<=2; i-- ) {
        swap(A[1],A[i]); //堆顶与当前堆中的下标最大的叶结点交换
        PushDown( 1, i-1 );
        /*整理堆把以1为根，最大叶下标为i-1的完全二叉树整理成堆*/
    }
}
```
