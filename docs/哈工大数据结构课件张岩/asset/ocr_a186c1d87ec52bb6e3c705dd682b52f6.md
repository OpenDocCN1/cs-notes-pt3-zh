# 6.3 快速排序（cont.）

```
int Partition ( int i , int j , keytype pivot )
/*划分A[i],...,A[j]，是关键字 < pivot 的在左子序列，
关键字>=pivot 的在右子序列，返回有子序列的起始下标*/
{ int l , r ;
    do{
        for( l = i ; A[l].key < pivot ; l++ ) ;
        for( r = j ; A[r].key >= pivot ; r-- ) ;
        if( l < r ) swap(A[l],A[r]);
    } while( l <= r );
    return  l ;
}
```
