# 5.3 折半查找（Cont.）

折半查找的递归算法实现

```
int BinSearch2(LIST F, int low, int up, keytype k)
{ if (low>up) return 0;
    else {
        mid=(low+up)/2;
        if (k < F[mid].key )
            return BinSearch2(F, low, mid-1, k);
        else if (k>F[mid].key)
            return BinSearch2(F, mid+1, up, k);
        else return mid;
    }
} /* F必须是顺序有序表(此处为增序);时间复杂度 :O(log₂ n) */
```
