# 2.2.6 多项式的代数运算

多项式：$p(x)=3x^{14}+2x^8+1$

存储表示：采用单链表表示

示例：

![](bbox=[0.076, 0.317, 0.926, 0.383])

存储结构定义：

```
struct polynode {
    int coef;  //系数
    int exp;   //指数
    polynode *link;  //指向下一项的指针
}; //结点类型

typedef polynode *polypointer;  //多项式的类型
```
