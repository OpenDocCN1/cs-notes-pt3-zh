# 4.2 图的存储结构(cont.)

存储结构的建立---算法实现步骤：

+   1. 确定图的顶点个数n和边数；
+   2. 输入顶点信息存储在一维数组vertex中；
+   3. 初始化邻接矩阵；
+   4. 依次输入每条边存储在邻接矩阵edge中；
+      4.1 输入边依附的两个顶点的序号i, j；
+      4.2 将邻接矩阵的第i行第j列的元素值置为1；
+      4.3 将邻接矩阵的第j行第i列的元素值置为1。
