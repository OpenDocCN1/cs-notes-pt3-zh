# 2.1 线性表的逻辑结构（Cont.）

ADT应用举例：

+   设计函数 DeleteVal（LIST &L, ElemType d），其功能为删除 L 中所有值为 d 的元素。

```
void DeleteVal( LIST &L, ElemType d )
{
    position p;
    p = First( L );
    while ( p != End( L ) )
    {
        if ( Same( Retrieve( p, L ), d ))
            Delete(p, L );
        else
            p = Next(p, L );
    }
}
```
