# 4.3 图的搜索（遍历） (cont.)

从一个顶点出发的一次深度优先遍历算法：

```
void DFS1 (AdjGraph* G, int i)
//以v_i为出发点时邻接表表示的图G进行先深搜索
{
    EdgeNode *p;
    cout<<G→vexlist[i].vertex;
    visited[i]=TRUE;
    dfn[i]=count++;
    p=G→vexlist[i].firstedge;
    while( p ) {
        if( !visited[ p→adjvex ] )
            DFS1(G, p→adjvex);
        p=p→next;
    }
} //DFS1
```
