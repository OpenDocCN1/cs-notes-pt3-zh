# 4.6 拓扑排序算法(cont.)

拓扑排序算法——实质是广度优先搜索算法

输入：有向图的邻接表，输出：所有顶点组成的拓扑序列

算法实现步骤：（使用队列）

+   1. 建立入度为零的顶点排队
+   2. 扫描顶点表，将入度为0的顶点入队；
+   3. while（队列不空）{
+       输出队头结点；
+       记下输出结点的数目；
+       删除与之关联的出边；
+       若有入度为0的结点，入队
+   }
+   4. 若输出结点个数小于n，则输出有环路；否则拓扑排序正常结束。
