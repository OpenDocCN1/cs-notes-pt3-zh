# 5.8 散列技术（Cont.）

散列函数的构造

散列函数的构造方法----平方取中法

+   - 取 key² 的中间的几位数作为散列地址
+   - 扩大相近数的差别，然后根据表长取中间几位作为散列值，使地址值与关键字的每一位都相关。
+   - 散列地址的位数要根据 B 来确定，有时要设一个比例因子，限制地址越界。
+   - 适用情况：事先不知道关键码的分布且关键码的位数不是很大
