# 5.8 散列技术（Cont.）

散列查找的性能分析

+   几种不同处理冲突方法的平均查找长度

|  | ASL | 查找成功时 | 查找不成功时 |
|---|---|---|---|
| 处理冲突方法 |  |  |  |
| 线性探测法 |  | $\frac{1}{2}\left(1+\frac{1}{(1-\alpha)^2}\right)$ | $\frac{1}{2}\left(1+\frac{1}{1-\alpha^2}\right)$ |
| 二次探测法 |  | $-\frac{1}{\alpha}\ln(1+\alpha)$ | $\frac{1}{1-\alpha}$ |
| 拉链法 |  | $1+\frac{\alpha}{2}$ | $\alpha+e^{-\alpha}$ |
