# 6.8 （二路）归并排序 (cont.)

（二路）归并排序算法：如何控制二路归并的结束？

```
void MergeSort( int n, LIST A )
{
 /* 二路归并排序 */
 int h = 1 ;/* 当前归并子序列的长度，初始为1 */
 LIST B;
 while (h< n){
MergePass (n, h, A, B);
 h = 2*h ;
MergePass (n, h, B, A); /* A、B互换位置 */
 h = 2*h ;
}
}/* MergeSort */
```
