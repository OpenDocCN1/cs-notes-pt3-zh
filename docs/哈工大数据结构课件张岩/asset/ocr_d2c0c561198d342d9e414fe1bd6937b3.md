# 5.8 散列技术（Cont.）

# 散列函数的构造

+   散列函数的构造方法----折叠法

若关键字位数较多，可根据B的位数将关键字分割成位数相同的若干段（最后一段位数可以不同），然后将各段叠加和(舍去进位)作为散列地址。

示例：图书编号：0-442-20586-4
5864      5864      左：移位叠加
4220      0224      Hash( key ) = 0088
+   04    +   04      右：间界叠加
10088     6092      Hash( key ) = 6092

适用情况：关键码位数很多，事先不知道关键码的分布。
