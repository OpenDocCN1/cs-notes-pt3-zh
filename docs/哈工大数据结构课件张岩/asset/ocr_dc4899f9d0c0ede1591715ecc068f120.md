# 3.7 树型结构的应用

# 用树结构表示集合

# ADT集合MFSET

+   - 集合：
+     - 性质相同的元素所组成的整体（有限且互不相交）

+   - 集合上的基本操作
+     - Union( Si, Sj, S ): If Si ∩ Sj == Φ,  S = Si ∪ Sj;
+     - Find( i, S ): 求包含i的集合;
+     - Initial( A, x ): 建立集合A，使之只包含x。

例如，S1={1, 7, 8, 9}, S2={2, 5, 10 }, S3={3, 4, 6}, 则S1 ∪ S2={1, 2, 5, 7, 8, 9, 10}
