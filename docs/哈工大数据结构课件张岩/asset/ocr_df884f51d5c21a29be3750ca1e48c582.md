# 3.2 二叉树（Cont.）

算法2：利用 InNext 算法，中序遍历线索二叉树

算法实现：

```
void ThInOrder(TH TREE HEAD)
{ THTREE tmp;

tmp = HEAD ;

do {

tmp = InNext ( tmp );

if ( tmp != HEAD )
    visit ( tmp -> data );
} while ( tmp != HEAD );
}
```
