# 2.2线性表的存储结构---顺序表（Cont.）

```
④ void Delete( position p, LIST &L)
{ position q;
    if (( p > L.last ) || ( p < 1 ))
        cout<< "指定位置不存在" ;
    else{
        L.last = L.last - 1;
        for ( q = p ; q <= L.last ; q ++ )
            L.elements[ q ] = L.elements[ q + 1 ];
    }
}
```
