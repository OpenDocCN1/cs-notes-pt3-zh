# 非空森林的基本遍历

+   - 先根遍历
+     - 访问第一棵树的根结点；
+     - 按先根顺序遍历第一棵树的子树森林；
+     - 按先根顺序遍历其余子树森林。

+   - 后根遍历
+     - 按后根顺序遍历第一棵树的子树森林；
+     - 访问第一棵树的根结点；
+     - 按后根顺序遍历其余子树森林。
