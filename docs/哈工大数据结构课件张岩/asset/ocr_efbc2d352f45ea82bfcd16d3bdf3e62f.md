# 2.2 线性表的存储结构---静态链表

# 2.2.3 静态链表

静态链表：

+   举例：
+   - 线性表： L= ( a, b, c )
+   - 线性表： M= ( d, e )
+   - 空闲表： avail=9

把线性表的元素存放在数组的单元中（不一定按逻辑顺序连续存放），每个单元不仅存放元素本身，而且还要存放其后继元素所在的数组单元的下标（游标）。

|  | data | next |
|---|---|---|
| 0 | d | 6 |
| 1 |  | 5 |
| 2 | c | -1 |
| 3 | /--/ | 0 |
| 4 | a | 10 |
| 5 |  | 8 |
| 6 | e | -1 |
| 7 | /--/ | 4 |
| 8 |  | -1 |
| 9 | /--/ | 11 |
| 10 | b | 2 |
| 11 |  | 12 |
| 12 |  | 1 |

L=7

M=3

avail=9
