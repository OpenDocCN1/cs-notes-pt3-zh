# 1.4 算法及算法分析(Cont.)

算法分析----例:分析下述“气泡”排序程序的时间复杂度。

```
void BubbleSort( int A[], int n )
{
    int i, j, temp;
    for (i=0; i<n-1; i++)
        for (j=n-1; j>=i+1; j--)
            if (A[j-1]>A[j]) {
                temp=A[j-1];
                A[j-1]=A[j];
                A[j]=temp;
            }
}
```

O(∑_{i=0}^{n-2} (n - i - 1)) ≤ O(n(n - 1)/2) = O(n²)
