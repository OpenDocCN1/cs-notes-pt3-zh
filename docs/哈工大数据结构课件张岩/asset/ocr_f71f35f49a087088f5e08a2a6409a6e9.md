# 2.5.3 模式匹配(Cont.)

设主串S= “abab cabcacbab”，模式串T= “abcac”

第1趟匹配 主串 ababcabcacbab i=3
模式串 abc j=3 匹配失败

第2趟匹配 主串 ababcabcacbab i=2
模式串 abc j=1 匹配失败

第3趟匹配 主串 ababcabcacbab i=7
模式串 abcac j=5 匹配失败

第4趟匹配 主串 ababcabcacbab i=4
模式串 abc j=1 匹配失败

第5趟匹配 主串 ababcabcacbab i=5
模式串 abc j=1 匹配失败

第6趟匹配 主串 ababcabcacbab i=6
模式串 abcac j=6 匹配成功

特点:主串指针需回溯，模式串指针需复位。
