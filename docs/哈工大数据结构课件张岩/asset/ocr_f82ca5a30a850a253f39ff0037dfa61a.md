# 3.2 二叉树（Cont.）

方法3：建立二叉树的左右链存储结构的非递归算法。

```
struct node *s[max]; /* 辅助指针数组，存放二叉树结点指针 */
BTREE CreateBT( )
{ int i , j; datatype ch;
struct node *bt, *p; /* bt为根，p 用于建立结点 */
cin >> i>>ch ;
while ( i != 0 && ch != 0) {
p =new node;      p -> data=ch;
p -> lchild=NULL; p -> lchild=NULL;
s[ i]=p;
if ( i == 1 ) bt = p ;
else {  j=i /2;  /* 父结点的编号 */
if ( i %2==0 )  s[j]->lchild=p; /* i 是 j 的左儿子 */
else            s[j]->rchild=p; /* i 是 j 的右儿子 */
}cin >> i>>ch ;}
}
```
