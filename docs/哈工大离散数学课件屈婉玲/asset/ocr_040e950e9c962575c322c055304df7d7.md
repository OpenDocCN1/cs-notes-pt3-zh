# 平面图和平面嵌入(续)

+   - 按定义, 平面图不一定是平面嵌入. 但今后讨论性质时, 通常是针对平面嵌入的. 今后平面图均指它的一个平面嵌入.
+   - $K_5$和$K_{3,3}$是非平面图
+   - 设$G'\subseteq G$, 若$G$为平面图, 则$G'$也是平面图; 若$G'$为非平面图, 则$G$也是非平面图.
+   - $K_n(n\ge5)$, $K_{3,n}(n\ge3)$都是非平面图.
+   - 平行边与环不影响图的平面性.
