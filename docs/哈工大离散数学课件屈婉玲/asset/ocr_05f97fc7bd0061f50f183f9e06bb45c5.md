# 递归函数

定义 设$f$是$N$上的$m$元部分函数，如果图灵机$M$计算$f$的一进制表示，即$M$的输入字母表为$\{1\}$，$\forall x_1,...,x_m\in N$，从初始格局$\sigma_0 = q_0 1^{x_1} B 1^{x_2} B \cdots 1^{x_m} B$开始，若$f(x_1,...,x_m)=y$，则$M$的计算停机，且停机时带的<|message|>内容(不计$\{1\}$以外的字符)为$1^y$；若$f(x_1,...,x_m)\uparrow$，则$M$永不停机，那么称$M$以一进制方式计算$f$。

定义 图灵机$M$以一进制方式计算的$N$上的$m$元部分函数称作部分递归函数，或部分可计算函数；部分递归的全函数称作递归函数，或可计算函数。
