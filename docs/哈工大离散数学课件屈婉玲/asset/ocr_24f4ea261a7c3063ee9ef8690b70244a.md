# 实例

例2 设 $A = \{1, 2, 3\}$, $B = \{a, b\}$, 求 $B^A$.

解 $B^A = \{f_0, f_1, \dots, f_7\}$, 其中
$f_0 = \{<1,a>,<2,a>,<3,a>\}$, $f_1 = \{<1,a>,<2,a>,<3,b>\}$
$f_2 = \{<1,a>,<2,b>,<3,a>\}$, $f_3 = \{<1,a>,<2,b>,<3,b>\}$
$f_4 = \{<1,b>,<2,a>,<3,a>\}$, $f_5 = \{<1,b>,<2,a>,<3,b>\}$
$f_6 = \{<1,b>,<2,b>,<3,a>\}$, $f_7 = \{<1,b>,<2,b>,<3,b>\}$
