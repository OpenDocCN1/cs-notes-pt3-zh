# 格的实例（续）

例 判断下列偏序集是否构成格，并说明理由。

+   (1) <P(B),⊆>，其中P(B)是集合B的幂集。

+   (2) <Z, ≤>，其中Z是整数集，≤为小于等于关系。

+   (3) 偏序集的哈斯图分别在下图给出。

![](bbox=[0.15, 0.47, 0.26, 0.75])

![](bbox=[0.3, 0.47, 0.46, 0.75])

![](bbox=[0.52, 0.46, 0.68, 0.75])

![](bbox=[0.72, 0.46, 0.88, 0.75])

解 (1) 是格. 称<P(B),⊆>为B的幂集格。

(2) 是格。

(3) 都不是格。
