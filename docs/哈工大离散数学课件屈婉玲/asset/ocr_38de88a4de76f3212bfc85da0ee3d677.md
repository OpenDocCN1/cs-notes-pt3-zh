# 实例

例如 $A = \{1, 2, 3\}$, $B = \{a, b\}$, 则

$L_A = \{<1,1>, <1,2>, <1,3>, <2,2>, <2,3>, <3,3>\}$

$D_A = \{<1,1>, <1,2>, <1,3>, <2,2>, <3,3>\}$

$A = P(B) = \{\varnothing, \{a\}, \{b\}, \{a,b\}\}$, 则 $A$ 上的包含关系是

$R_\subseteq = \{<\varnothing,\varnothing>, <\varnothing,\{a\}>, <\varnothing,\{b\}>, <\varnothing,\{a,b\}>, <\{a\},\{a\}>, $

$<\{a\},\{a,b\}>, <\{b\},\{b\}>, <\{b\},\{a,b\}>, <\{a,b\},\{a,b\}>\}$
