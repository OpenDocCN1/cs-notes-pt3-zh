# 例题

判断下列集合和给定运算是否构成环、整环和域。

+   (1) $A = \{a + bi \mid a, b \in Q\}$, $i^2 = -1$, 运算为复数加法和乘法。
+   (2) $A = \{2z + 1 \mid z \in Z\}$, 运算为普通加法和乘法
+   (3) $A = \{2z \mid z \in Z\}$, 运算为普通加法和乘法
+   (4) $A = \{x \mid x \ge 0 \land x \in Z\}$, 运算为普通加法和乘法。
+   (5) $A = \{a + b\sqrt[4]{5} \mid a, b \in Q\}$, 运算为普通加法和乘法

解 (2), (4), (5) 不是环. 为什么？

+   (1) 是环, 是整环, 也是域。
+   (3) 是环, 不是整环和域。
