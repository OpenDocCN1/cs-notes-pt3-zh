# 集合运算的算律

| | ∪ | ∩ | ⊕ |
|---|---|---|---|
| 交换 | A∪B=B∪A | A∩B=B∩A | A⊕B=B⊕A |
| 结合 | (A∪B)∪C= A∪(B∪C) | (A∩B)∩C= A∩(B∩C) | (A⊕B)⊕C= A⊕(B⊕C) |
| 幂等 | A∪A=A | A∩A=A |  |


| | ∪与∩ | ∩与⊕ |
|---|---|---|
| 分配 | A∪(B∩C)=(A∪B)∩(A∪C) A∩(B∪C)=(A∩B)∪(A∩C) | A∩(B⊕C)=(A∩B)⊕(A∩C) |
| 吸收 | A∪(A∩B)=A A∩(A∪B)=A |  |


吸收律的前提：∪、∩可交换
