# 顶点的度数(续)

设D=<V,E>为有向图, v∈V,

v的出度 d⁺(v): v作为边的起点次数之和

v的入度 d⁻(v): v作为边的终点次数之和

v的度数(度) d(v): v作为边的端点次数之和

d(v)= d⁺(v)+ d⁻(v)

D的最大出度Δ⁺(D),最小出度δ⁺(D)

最大入度Δ⁻(D),最小入度δ⁻(D)

最大度Δ(D),最小度δ(D)

例如 d⁺(a)=4, d⁻(a)=1, d(a)=5,

d⁺(b)=0, d⁻(b)=3, d(b)=3,

Δ⁺(D)=4, δ⁺(D)=0, Δ⁻(D)=3,

δ⁻(D)=1, Δ(D)=5, δ(D)=3.
