# 群的性质---运算表排列规则

定理4 设 G 为有限群，则 G 的运算表中每行每列都是 G 中元素的一个置换，且不同的行（或列）的置换都不相同。

注意：必要条件，用于判断一个运算表不是群。

| | a | b | c | d |
|---|---|---|---|---|
| a | b | c | d | a |
| b | b | a | c | d |
| c | c | d | b | a |
| d | d | b | a | c |

| | a | b | c | d |
|---|---|---|---|---|
| a | a | b | c | d |
| b | c | d | a | b |
| c | b | c | d | a |
| d | d | a | b | c |
