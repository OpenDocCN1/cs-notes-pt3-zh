# 平面图和平面嵌入

定义 如果能将图G除顶点外边不相交地画在平面上，则称G是平面图。这个画出的无边相交的图称作G的平面嵌入。没有平面嵌入的图称作非平面图。

例如 下图中(1)~(4)是平面图, (2)是(1)的平面嵌入, (4)是(3)的平面嵌入. (5)是非平面图.
