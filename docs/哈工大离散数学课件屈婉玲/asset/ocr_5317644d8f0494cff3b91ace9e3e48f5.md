# 重要子群（续）

# 群$G$的中心$C$

设 $G$ 为群, 令 $C = \{ a \mid a \in G \land \forall x \in G (ax = xa) \}$, 则 $C$ 是 $G$ 的子群, 称为 $G$ 的中心.

证 $e \in C$. $C$ 是 $G$ 的非空子集.

任取 $a, b \in C$, 证明 $ab^{-1}$ 与 $G$ 中所有的元素都可交换.

$\forall x \in G$, 有

$(ab^{-1})x = ab^{-1}x = ab^{-1}(x^{-1})^{-1} = a(x^{-1}b)^{-1} = a(bx^{-1})^{-1}$
$= a(xb^{-1}) = (ax)b^{-1} = (xa)b^{-1} = x(ab^{-1})$

由判定定理可知 $C \leq G$.
