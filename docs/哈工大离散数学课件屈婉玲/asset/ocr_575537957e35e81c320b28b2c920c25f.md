# 有向图的邻接矩阵

定义 设有向图 D=<V,E>, V={v₁, v₂, ..., vₙ}, E={e₁, e₂, ..., eₘ}, 令 aᵢⱼ⁽¹⁾ 为顶点 vᵢ 邻接到顶点 vⱼ 边的条数, 称 aᵢⱼ⁽¹⁾ )ₘₓₙ 为 D 的邻接矩阵, 记作 A(D), 简记为 A.

性质

+   (1) ∑ⱼ=1ⁿ aᵢⱼ⁽¹⁾ = d⁺(vᵢ),  i = 1,2,...,n
+   (2) ∑ᵢ=1ⁿ aᵢⱼ⁽¹⁾ = d⁻(vⱼ),  j = 1,2,...,n
+   (3) ∑ᵢ,ⱼ aᵢⱼ⁽¹⁾ = m --- D 中长度为 1 的通路数
+   (4) ∑ᵢ=1ⁿ aᵢᵢ⁽¹⁾ --- D 中长度为 1 的回路数
