# 关系基本运算的性质（续）

定理2 设F, G, H是任意的关系, 则

+   (1) (F∘ G)∘ H = F∘ (G∘ H)
+   (2) (F∘ G)^{-1} = G^{-1}∘ F^{-1}

证 (1) 任取<x,y>,

<x,y> ∈ (F∘ G)∘ H

⇔ ∃t(<x,t> ∈ F∘ G ∧ <t,y> ∈ H)

⇔ ∃t (∃s(<x,s> ∈ F ∧ <s,t> ∈ G) ∧ <t,y> ∈ H)

⇔ ∃t ∃s (<x,s> ∈ F ∧ <s,t> ∈ G ∧ <t,y> ∈ H)

⇔ ∃s (<x,s> ∈ F ∧ ∃t (<s,t> ∈ G ∧ <t,y> ∈ H))

⇔ ∃s (<x,s> ∈ F ∧ <s,y> ∈ G∘ H)

⇔ <x,y> ∈ F∘ (G∘ H)

所以 (F∘ G)∘ H = F∘ (G∘ H)
