# 分解实例

例 设 S = { 1, 2, ..., 8 },
σ = ( 1 2 3 4 5 6 7 8 )
    ( 5 3 6 4 2 1 8 7 ),   τ = ( 1 2 3 4 5 6 7 8 )
                               ( 8 1 4 2 6 7 5 3 )

从 σ 中分解出来的第一个轮换式 (1 5 2 3 6)；第二个轮换为 (4)；第三个轮换为 (7 8)。σ 的轮换表示式

σ = (1 5 2 3 6) (4) (7 8) = (1 5 2 3 6) (7 8)

用同样的方法可以得到 τ 的分解式

τ = (1 8 3 4 2) (5 6 7)

注意：在轮换分解式中，1 阶轮换可以省略。
