# 关于运算的说明

+   - 运算顺序：~和幂集优先，其他由括号确定
+   - 并和交运算可以推广到有穷个集合上，即
+     $A_1 \cup A_2 \cup ... A_n = \{x \mid x \in A_1 \lor x \in A_2 \lor ... \lor x \in A_n\}$
+     $A_1 \cap A_2 \cap ... A_n = \{x \mid x \in A_1 \land x \in A_2 \land ... \land x \in A_n\}$
+   - 某些重要结果
+     $\varnothing \subseteq A - B \subseteq A$
+     $A \subseteq B \Leftrightarrow A - B = \varnothing$（后面证明）
+     $A \cap B = \varnothing \Leftrightarrow A - B = A$
