# 一个实例——模拟例2中的G₂

G₂ = <V,T,S,P>          G₂' = <V',T',S',P'>
V = {A,B,S}             V' = {A,B,S,S'}
T = {0,1}               T' = {0,1}
P: S → 1A              P': A → S1
    A → 0A              A → A0
    A → 1A              A → A1
    A → 0B              B → A0
    B → 0               S' → B0
                        S → ε

可删去G₂′中的S, 这实际上就是G₃
