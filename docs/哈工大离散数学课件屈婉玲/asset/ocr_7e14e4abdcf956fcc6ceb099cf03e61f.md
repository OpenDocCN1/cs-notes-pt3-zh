# 图的度数列

设无向图G的顶点集V={v₁, v₂, ..., vₙ}

G的度数列: d(v₁), d(v₂), ..., d(vₙ)

如右图度数列:4,4,2,1,3

![](bbox=[0.55, 0.1, 0.95, 0.5])

设有向图D的顶点集V={v₁, v₂, ..., vₙ}

D的度数列: d(v₁), d(v₂), ..., d(vₙ)

D的出度列: d⁺(v₁), d⁺(v₂), ..., d⁺(vₙ)

D的入度列: d⁻(v₁), d⁻(v₂), ..., d⁻(vₙ)

如右图度数列:5,3,3,3

出度列:4,0,2,1

入度列:1,3,1,2

![](bbox=[0.55, 0.52, 0.95, 0.92])
