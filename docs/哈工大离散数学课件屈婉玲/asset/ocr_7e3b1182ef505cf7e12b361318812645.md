# 惟一性定理（续）

定理 设。 为 S 上可结合的二元运算, e 为该运算的单位元, 对于 x∈S 如果存在左逆元 y_l 和右逆元 y_r, 则有 y_l = y_r = y, 且 y 是 x 的惟一的逆元.

证 由 y_l ° x = e 和 x ° y_r = e 得

y_l = y_l ° e = y_l ° (x ° y_r) = (y_l ° x) ° y_r = e ° y_r = y_r

令 y_l = y_r = y, 则 y 是 x 的逆元.

假若 y'∈S 也是 x 的逆元, 则

y' = y' ° e = y' ° (x ° y) = (y' ° x) ° y = e ° y = y

所以 y 是 x 惟一的逆元.
