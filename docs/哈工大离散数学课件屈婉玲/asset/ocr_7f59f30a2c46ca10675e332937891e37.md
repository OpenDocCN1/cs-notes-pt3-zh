# 惟一性定理

定理 设 。 为 S 上的二元运算， $e_l$ 和 $e_r$ 分别为 $S$ 中关于运算的左和右单位元，则 $e_l = e_r = e$ 为 $S$ 上关于 。 运算的惟一的单位元。

证 $e_l = e_l \circ e_r = e_l \circ e_r = e_r$

所以 $e_l = e_r$，将这个单位元记作 $e$。假设 $e'$ 也是 $S$ 中的单位元，则有

$e' = e \circ e' = e$.

惟一性得证。

类似地可以证明关于零元的惟一性定理。

注意：当 $|S| \ge 2$，单位元与零元是不同的；
当 $|S| = 1$ 时，这个元素既是单位元也是零元。
