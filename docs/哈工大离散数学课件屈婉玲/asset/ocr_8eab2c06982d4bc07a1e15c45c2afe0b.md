# 波兰符号法与逆波兰符号法

**行遍(周游)根树T**：对T的每个顶点访问且仅访问一次。
行遍2元有序正则树的方式：

+   ① 中序行遍法：左子树、根、右子树
+   ② 前序行遍法：根、左子树、右子树
+   ③ 后序行遍法：左子树、右子树、根

![](bbox=[0.696, 0.373, 0.923, 0.709])

例如，对图所示根树按中序、前序、后序行遍访问结果分别为：

中序：$b\ a\ (f\ d\ g)\ c\ e$

前序：$a\ b\ (c\ (d\ f\ g)\ e)$

后序：$b\ ((f\ g\ d)\ e\ c)\ a$

带下划线的是(子)树根，一对括号内是一棵子树
