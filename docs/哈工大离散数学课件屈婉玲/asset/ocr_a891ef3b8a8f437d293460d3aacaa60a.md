# 同态映射的实例（续）

例4 $V_1=\langle Z,+\rangle$, $V_2=\langle Z_n,\oplus\rangle$, $Z_n=\{0,1,...,n-1\}$, $\oplus$是模 $n$ 加. 令

$f: Z\to Z_n$, $f(x)=(x)\text{mod } n$

则 $f$ 是 $V_1$ 到 $V_2$ 的满同态. $\forall x,y\in Z$ 有

$f(x+y)=(x+y)\text{mod } n$
$= (x)\text{mod } n \oplus (y)\text{mod } n$
$= f(x) \oplus f(y)$
