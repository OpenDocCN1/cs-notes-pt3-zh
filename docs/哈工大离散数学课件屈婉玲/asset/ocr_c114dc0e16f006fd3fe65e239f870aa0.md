# 例（续）

B₂ = (s ∨ u) ∧ (¬u ∨ (p ∧ q)) ⇔ ((s ∧ ¬u) ∨ (p ∧ q ∧ s) ∨ (p ∧ q ∧ u)) （分配律）

B₁ ∧ B₂ ⇔ (¬p ∧ q ∧ ¬r ∧ s ∧ ¬u) ∨ (¬p ∧ ¬q ∧ r ∧ s ∧ ¬u) ∨ (q ∧ ¬r ∧ s ∧ ¬u) ∨ (p ∧ q ∧ ¬r ∧ s) ∨ (p ∧ q ∧ ¬r ∧ u)

再令 B₃ = ((r ∧ s) ∨ (¬r ∧ ¬s))

得 A ⇔ B₁ ∧ B₂ ∧ B₃ ⇔ (¬p ∧ ¬q ∧ r ∧ s ∧ ¬u) ∨ (p ∧ q ∧ ¬r ∧ ¬s ∧ u)

注意：在以上演算中多次用矛盾律
