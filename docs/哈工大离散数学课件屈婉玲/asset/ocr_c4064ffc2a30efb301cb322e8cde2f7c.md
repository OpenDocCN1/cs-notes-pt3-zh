# 真值函数

问题：含 *n* 个命题变项的所有公式共产生多少个互不相同的真值表？

答案为 $2^{2^n}$ 个，为什么？

定义 称定义域为{00...0, 00...1, ..., 11...1}，值域为{0,1}的函数是 *n* 元真值函数，定义域中的元素是长为 *n* 的 0,1 串. 常用 *F*:{0,1}^*n*→{0,1} 表示 *F* 是 *n* 元真值函数.

共有 $2^{2^n}$ 个 *n* 元真值函数.

例如 *F*:{0,1}^2→{0,1}，且 *F*(00)=*F*(01)=*F*(11)=0, *F*(01)=1，则 *F* 为一个确定的 2 元真值函数.
