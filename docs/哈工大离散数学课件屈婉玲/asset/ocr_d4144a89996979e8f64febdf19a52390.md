# 格的实例

例 设 $n$ 是正整数， $S_n$ 是 $n$ 的正因子的集合. $D$ 为整除关系，则偏序集 $<S_n, D>$ 构成格. $\forall x, y \in S_n$, $x \vee y$ 是 $\operatorname{lcm}(x, y)$，即 $x$ 与 $y$ 的最小公倍数. $x \wedge y$ 是 $\operatorname{gcd}(x, y)$，即 $x$ 与 $y$ 的最大公约数.
