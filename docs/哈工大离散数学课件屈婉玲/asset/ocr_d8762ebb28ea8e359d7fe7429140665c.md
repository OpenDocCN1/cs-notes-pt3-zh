# 推理的形式结构

定义 若对于每组赋值， $A_1 \land A_2 \land ... \land A_k$ 均为假，或当 $A_1 \land A_2 \land ... \land A_k$ 为真时，$B$ 也为真，则称由 $A_1, A_2, ..., A_k$ 推 $B$ 的推理正确，否则推理不正确（错误）。

“$A_1, A_2, ..., A_k$ 推 $B$” 的推理正确
当且仅当 $A_1 \land A_2 \land ... \land A_k \rightarrow B$ 为重言式。

推理的形式结构: $A_1 \land A_2 \land ... \land A_k \rightarrow B$ 或

+   前提： $A_1, A_2, ..., A_k$
+   结论： $B$

若推理正确，则记作： $A_1 \land A_2 \land ... \land A_k \Rightarrow B.$
