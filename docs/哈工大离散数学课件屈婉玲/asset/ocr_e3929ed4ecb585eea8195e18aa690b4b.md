# 布尔代数的等价定义

定义 设<B, *, ∘>是代数系统, * 和∘是二元运算. 若 * 和∘运算满足交换律、结合律、幂等律、吸收律, 即

+   (1) ∀a,b∈B 有 a* b = b* a, a∘b = b∘a
+   (2) ∀a,b,c∈B 有 a* (b∘c) = (a* b)∘(a* c), a∘(b* c) = (a∘b) * (a∘c)
+   (3) 即存在0,1∈B, 使得∀a∈B 有 a* 1 = a, a∘0 = a
+   (4) ∀a∈B, 存在 a'∈B 使得 a* a' = 0, a∘a' = 1

则称<B, *, ∘>是一个布尔代数.

可以证明，布尔代数的两种定义是等价的.
