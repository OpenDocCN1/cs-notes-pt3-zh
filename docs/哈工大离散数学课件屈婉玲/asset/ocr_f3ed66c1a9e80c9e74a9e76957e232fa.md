# 基本计数公式的应用（续）

# 例2 求1000！的末尾有多少个0？

解　1000! = 1000 × 999 × 998 × … × 2 × 1

将上面的每个因子分解，若分解式中共有 $i$ 个5，$j$ 个2，那么 $\min\{i,j\}$ 就是0的个数。

1，…，1000中有

+   - 500个是2的倍数，$j>500$；
+   - 200个是5的倍数，
+   - 40个是25的倍数（多加40个5），
+   - 8个是125的倍数（再多加8个5），
+   - 1个是625的倍数（再多加1个5）。

$i=200+40+8+1=249$。$\min\{i,j\}=249$。
