# Correctness proof by loop invariant

+   - Loop invariant:
+     每次迭代开始之前，子数组 i+1, i+2, ..., n 构成 heap 树。
+   - Proof by induction
+     - Initialization: i=[n/2]. i=[n/2]+1, [n/2]+2, ...
+       n 个节点，每个都是 1-element heap 树，性质成立。
+     - Maintenance:
+       假设在某次迭代开始时 i+1, ..., n 构成 heap 树。
+       执行 Max-Heapify(A, i) 后 i 成为 heap 树。
+       于是当 i-1 执行时，i, i+1, ..., n 构成 heap 树，性质保持。
+   - Termination: i=0, 于是 1, 2, ..., n 构成 heap 树，算法正确。

# Time complexity

running time = Σ_{h=0}^{⌊lg n⌋} #node(h)·O(h)
where #node(h) is the number of nodes rooted at which the subtree has height h
height = ⌊lg n⌋ where n = heap-size(A)
#node(h) ⌈n / 2^{h+1}⌉ Proof is Homework

Σ_{h=0}^{⌊lg n⌋} ⌈n / 2^{h+1}⌉ O(h) = O( n Σ_{h=0}^{⌊lg n⌋} h / 2^{h} ) = O(n)
because
Σ_{h=0}^{∞} h / 2^{h} = 1/2 / (1 - 1/2)^2 = 2
