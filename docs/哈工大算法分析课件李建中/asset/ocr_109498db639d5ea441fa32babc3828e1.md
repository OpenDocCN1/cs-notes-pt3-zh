# Merge 案例

5个列表：<g, h, i, j, k>, <a, b, c, d>, <f, e>
全部序列：<g, h, a, b, f, c, e, d, i, j, k>

Graham-Scan on <g, h, a, b, f, c, e, d, i, j, k>

# Merge(时间复杂度 O(n))

+   1. 取 L → A 的极点；
+   2. 在 CH(Q₂) 中找到 P 轴线最左和最小点及右和；
+   3. 构造以下三个序列：
+      (1) 按照斜方向的顺序列出 CH(Q₂) 全部顶点。
+      (2) 按照斜方向的顺序列出 CH(Q₂) 从左到右顶点。
+      (3) 按照斜方向的顺序列出 CH(Q₂) 从右到左顶点；
+   4. 合并这三个序列；
+   5. 依次合并列出 Graham-Scan。

# 时间复杂度

+   • Preprocessing阶段
+     -- O(1)
+   • Divide阶段(假设 O(n) 算法已知)
+     -- O(n)
+   • Conquer阶段
+     -- 2T(n/2)
+   • Merge阶段
+     -- O(n)

+   • 总时间复杂度
+     T(n)=2T(n/2)+O(n)
+   • 使用Master定理
+     T(n)=O(nlogn)
