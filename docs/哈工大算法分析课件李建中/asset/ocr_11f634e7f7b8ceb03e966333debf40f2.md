# What?

# Dynamic Programming 直译

+   - 把原问题分解成一系列子问题
+   - 解决每个子问题仅一次，并将结果保存起来供以后使用。一个子问题可能被解决多次，但只需计算一次，节省计算时间
+   - 自底而上地计算
+   - 适用范围
+     - 某些优化问题：可分解为多个子问题，子问题解被重复使用

# How?

# 使用 Dynamic Programming 的条件

+   - Optimal substructure（最优子结构）
+     某个问题的最优解包含其子问题的最优解。
+     针对同一个问题可以有不同的最优解。
+   - Subproblems（重叠子问题）
+     在问题的解剖过程中，某些子问题被反复使用

# Dynamic Programming 的实例

+   - 最短路径问题
+   - Dynamic Programming 求解过程

# 1: 对各 d(S,T) 同源有 5 个子问题

从 S 到 T 的最短路径长度为： d(S,T)=min{1+d(A,T), 2+d(B,T), 5+d(C,T)}

# 2: 对各 d(A,T), d(B,T), d(C,T) 各有 6 个子问题

# 3: 求解各子问题

d(A,T)=min{4+d(D,T), 11+d(E,T)}=min{22,24}=22 <A,D,T>
d(B,T)=min{9+d(D,T), 5+d(E,T), 16+d(F,T)}=min{27,18,18}=18 <B,E,T>
d(C,T)=min{2+d(F,T)}=4 <C,F,T>

# 4: 求最后从 S 到 T 的最短路径

d(S,T)=min{1+d(A,T), 2+d(B,T), 5+d(C,T)}=min{23,20,9}=9 <S,C,F,T>
