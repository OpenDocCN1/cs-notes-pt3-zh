# 问题的定义

+   - **输入**
+     - 一个正整数 $N$
+   - **输出**
+     - $N$ 是否素数

# 随机算法的设计

+   - **基本思想**
+     - 对 $N$ 进行 $m$ 次测试
+     - 如果有一次测试成功，则回答 $N$ 是合数
+     - 如果 $m$ 次测试均失败，则回答 $N$ 是素数
+     - 回答 $N$ 是合数时，答案百分之百正确
+     - 回答 $N$ 是素数时，答案正确的概率为 $1-2^{-m}$

+   - **随机算法**
+     1. 随机地选择 $m$ 个数 $(b_1,b_2,\ldots,b_m)$，满足 $1\le b_i\le N$
+     2. For $i=1$ To $m$
+     3. 　 If $W(b_i)$成立　Then　Return（$N$是合数）
+     4. Return（$N$是素数）
+   
+     $W(b_i)$定义如下：
+     1. $b_i^{N-1}\not\equiv 1\pmod N$，或
+     2. $\gcd(N-1)/2^k$ 是整数，$1<k$ 且 $\gcd$ 为最大的公因子 $<N$

例1．给定 $N=12$，选择测试数集 $\{2,3,7\}$。

测试 2：$2^{2^2-1}=2048\not\equiv 1\pmod{12}$，$W(2)$成立。
$N$是合数。

例2．给定 $N=11$，选择测试数集 $\{2,5,7\}$。
测试 2：$2^{10}=1024\equiv 1\pmod{11}$；
测试 5：$5^{10}=9765625\equiv 1\pmod{11}$；
测试 7：$7^{10}=282475249\equiv 1\pmod{11}$；
结论：11可能是素数。
答案正确的概率为 $1-2^{-3}$。

# 算法性能的分析

定理1．(1) 如果对于任意整数 $b<N$，$W(b)$成立，则 $N$ 是合数。
(2) 如果 $N$ 是合数，则至少有 $(N-1)/2$ 个 $b$ 使 $W(b)$ 成立。

(1) 说明算法是正确的。
(2) 说明，如果 $N$ 是合数，则至少一半 $b<N$ 使 $W(b)$ 成立。

定理2．算法的回答“$N$ 是素数”正确的概率是 $1-2^{-m}$。
