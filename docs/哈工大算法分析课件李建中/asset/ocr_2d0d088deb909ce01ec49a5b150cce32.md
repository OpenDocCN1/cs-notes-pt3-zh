# 问题定义

+   - 输入：
+     有限集X, X的有限子集族F, X=∪_{S∈F} S
+   - 输出：
+     C⊆F, 满足
+     (1). X=∪_{S∈C} S,
+     (2). C是最小的(1)中集合, 即|C|最小。

*最小集合覆盖问题是NP完全问题。
*最小集合覆盖问题是NP完全问题。

# 问题举例

X=12个元素, F={S₁,S₂,S₃,S₄,S₅,S₆}
取最小覆盖C={S₂,S₃,S₅}

# 近似算法的设计

+   - 基本思想
+     ---贪心策略是选择覆盖最多未被覆盖元素的集合

C={S₂,S₄,S₆,S₃}

# 算法

```
Greedy-Set-Cover(X, F)
1. U←X; /* U为X中未被覆盖的元素集合 */
2. C←∅
3. While U≠∅ Do
4.   Select S∈F 使|S∩U|最大;
   /* Greedy-算法一次选择覆盖最多未被U覆盖元素的S */
5.   U←U−S;
6.   C←C∪{S}; /* 将该X覆盖 */
7. Return C.
```

# 算法性能分析

+   - 时间复杂度
+     - 3-6循环执行最多min{|X|,|F|}次
+     - 计算|S∩U|需要O(|X|)
+     - 每次迭代需要O(|F||X|)
+     - T(X,F)=O(|F||X|·min{|X|,|F|})
