# 向最定义

+   - 输入：S={1, 2, ..., n}, F={ [s_i, f_i] }, n≥i≥1
+   - 解释：S 辅助最大权集合

# 设计与选择性质

+   - 个性质
+     当问题具有最优子结构性质时，取使f_i最小的活动，取使问题的解更易构造
+   - 贪心选择方法
+     - 选择：
+       - 每次取使剩余最小时间结束的活动f_i
+     - 剩余活动构造：
+       - S_i = { j∈S | s_j ≥ f_i }

# 优化解的构造

设 S={1,2,...,n} 是 n 个活动集合，[s_i, f_i] 表示活动 i 的开始结束时间，f_1≤f_2≤...≤f_n，S 的活动集合是问题的一个优化解也包含活动 1。
设 A 是一个集合，则称集合 A 中活动，设集合一个活动为 k，第二个活动为 j。
若 k=1，则取现活动。
若 k≠1，令 B=A-{k} ∪ {1}，
由 A 中活动知，f_1≤S_k, S_k 活动构造。
因 |B|=|A|，所以 B 是一个优化解，也包含活动 1。

定理1. 设 S={1,2,...,n} n 个活动集合，[s_i, f_i] 表示活动 i 的开始结束时间，f_1≤f_2≤...≤f_n, 则 A 是 S 的问题的一个优化解且包含活动 1。则 A⊆A-{1}。
若 S⊆{i | s_i ≥ f_j} 的活动则问题优化解。
注意，A' 活动集合是最大，
则优化量是明 A' 是最大。

# Greedy算法

定理2. 设 S={1,2,...,n} 是 n 个活动集合，f_i>0, f_1 是 S_i={j∈S | s_j ≥ f_i} 中最小结束时间活动。
如果 A 是 S 包含活动 i 的优化解，其中 f_j ≤ f_k ≤ ... ≤ f_n, 则 A={j0}。
设 |A|=k 时，
当 |A|=1 时，由引理1，令集合现，S_k={j∈S | s_j ≥ f_k}。
现 |A|≤k-1，设集合现，A={j1} ∪ A1, A1={j | s_j ≥ f_j0}。
当 |A|=k 时，每次取，A={j1} ∪ A1, A1={j | s_j ≥ f_j0}。
A_k 是 S_j={j∈S | s_j ≥ f_i} 优化解，
由归纳假设，A_k=∪_{i=1}^{k} B_i。子集，A_k=∪_{i=1}^{k} B_i。
