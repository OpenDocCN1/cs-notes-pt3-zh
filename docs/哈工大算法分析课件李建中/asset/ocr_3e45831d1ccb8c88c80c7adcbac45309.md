# Correctness Proof

# Loop Invariant

At the start of the loop of lines 3-6 for any k
1. if p ≤ k ≤ i, then A[k] ≤ x.
2. if i < k ≤ j, then A[k] > x.
3. if k = r, then A[k] = x.

# Initialization:

Prior the first iteration, i = p-1, j = r, condition 1 and 2 are trivially satisfied. Line 1 make condition 3 true.

```
Partition(A, p, r)
x ← A[r];
i ← p - 1;
for j ← p to r - 1
do if A[j] ≤ x
i ← i + 1;
exchange A[i] ↔ A[j];
exchange A[i + 1] ↔ A[r];
return i + 1;
```

Running time: Θ(n)

# Maintenance:

# Termination

At termination, i = r. We have three sets:
1. those less than or equal to x.
2. those greater than x.
3. a singleton set containing x.

After finishing the algorithm
The final two steps move the pivot into its position in the middle of the array by swapping it with the leftmost element that is greater than x.
