# Substitution方法II：上界下系

例 3. 求解 T(n) = 2T(n/2) + n.
解：首先证明 T(n) = Ω(n), T(n) = O(n²)
然后逐步地降低上界、提高下界。
Ω(n) 的上一个阶是 Ω(n log n),
O(n) 的下一个阶是 O(n log n)。

# Substitution方法III：变量替换

按变量替换把递推方程变换为熟悉的方程。
例 6. 求解 T(n) = 2T(√n) + lg n
解：令 m = lg n，则 n = 2^m, T(2^m) = 2T(2^{m/2}) + m.
令 S(m) = T(2^m) 则 T(2^{m/2}) = S(m/2)，于是，S(m) = 2S(m/2) + m
显然，S(m) = O(m lg m)，即 T(2^m) = Θ(m lg m)。
由于 2^m = n, m = lg n, T(n) = Θ(lg n × lg lg n)。

# 2.4.2 Iteration方法

方法：
简洁地展开递推方程，
把它转化为和式，
然后可使用和式技术解之。

例 1. T(n) = n + 3T([n/4]), T(1)=1
= n + 3[ n/4 + 3T([n/4^2]) ]
= n + 3[ n/4 + 3[ n/16 + 3T([n/4^3]) ] ]
= n + 3[ n/4 ] + 9[ n/16 ] + 27T([n/4^3])
= n + 3[ n/4 ] + 3^2[ n/4^2 ] + 3^3[ n/4^3 ] + ... + 3^i T([n/4^i])
[ n/4^i → 4^i → n => i = log_4 n ]
= n + 3[ n/4 ] + 3^2[ n/4^2 ] + 3^3[ n/4^3 ] + ... + 3^{log_4 n -1} T(1)
≤ Σ_{i=0}^{log_4 n} 3^i n/4^i ≤ n Σ_{i=0}^{∞} (3/4)^i = n × 1/(1 - 3/4) = 4n = O(n)

# 2.4.3 Master method

目的：求解 T(n) = aT(n/b) + f(n) 型方程，a ≥ 1, b > 0 是常数
f(n) 是正函数
方法：记住三种情况，则不用笔纸即可求解上述方程

# Master 定理

定理 2.4.1 设 a ≥ 1, b > 1 是常数，f(n) 是一个函数，T(n) 是定义在非负整数集上的递归式 T(n) = aT(n/b) + f(n)，T(n) 可以如下求解：
(1). 若 f(n) = O(n^{log_b a - ε}), ε > 0 是常数，则 T(n) = Θ(n^{log_b a})。
(2). 若 f(n) = Θ(n^{log_b a})，则 T(n) = Θ(n^{log_b a} lg n)。
(3). 若 f(n) = Ω(n^{log_b a + ε}), ε > 0 是常数，并且对于所有充分大的 n
a f(n/b) ≤ c f(n), c < 1 是常数，则 T(n) = Θ(f(n))。
