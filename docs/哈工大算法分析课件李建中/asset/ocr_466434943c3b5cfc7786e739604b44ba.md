E(g*(ξ_i)) = ∫_a^b g*(x) f(x) dx = ∫_a^b g(x) dx = I
—由强大数定律 Pr{lim_{n→∞} 1/n Σ_{i=1}^n s*(ξ_i) = I} = 1
—我们可以利用 { Σ_{i=1}^n s*(ξ_i) } 随机近似计算 I
⇒ f(x)=1/(b-a)  a ≤ x ≤ b
—求积分I可以由如下 I 来近似计算
I ≈ 1/n Σ_{i=1}^n s*(ξ_i) = Σ_{i=1}^n g(ξ_i)/f(ξ_i) = 1/n Σ_{i=1}^n (b-a)g(ξ_i)

蒙特卡罗法
I=0;
For i=1 To n
随机产生[a,b]中点x_i;
I=I+g(x_i);
Endfor
Return (b-a)*I/n
• 时间复杂性=O(n)
—不是输入的大小，而是随机样本的大小
—解的精确度
—随随机样本大小n增加而增加

# 8.3 Randomized Selection Algorithms

+   - 算法的性能分析

# 问题的定义

• 输入: S={x_1, x_2, ..., x_n},
整数k, 1≤k≤n
• 输出: S中第k最小元素
记号
Rank(Q, x) = 集合Q中元素的rank
min(Q, k) = 集合Q中第k最小元素

# 随机算法

基本思想
• 从S中随机地抽取n个样本存入R, 排序R
• S中第k最小元素可能成为R中x≈k/n最小元素
• 为了解决误差问题, 我们有置信区间 [x≈k/n, x≈k/n+1/2]
r1 ...... rL rL+1 ...... rH ...... rn
• 把S置于以 [H] 散装并入P
• 在P中寻找min(S, k)

+   LAZYSELECT(S, k)
+   1. R=独立, 均匀, 可放回地从S随机选取n^{3/4}元素;
+   2. 在O(n log n)时间内排序R;
+   3. x=k/n^{1/4}, H={y∈S | y≤x}, L={y∈S | y≥x};
+   4. l=max{1, √n - 0}, h=min{ n, [x+√n] n^{3/4} };
+   5. L_p=min(R, h), H_p=min(R, h), 且|R|≤5元素比较*;
+   6. L_p=Rank(S,L), H_p=Rank(S,H); 且|R|≤5元素比较*;
+   7. P={y∈S | L≤y≤H};
+   8. If min(S, k)∈P and |P|≤4n^{3/4}+1
+      Then max(S,k) 可由 P 归纳确定 *;
+   9. Then 推进 y=min(S, k)=min(P, (k-L_p)), 算法结束;
+   10. ELSE goto 1.
