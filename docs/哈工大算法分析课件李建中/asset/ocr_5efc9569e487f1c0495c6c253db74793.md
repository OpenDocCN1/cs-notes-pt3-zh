# 矩阵连乘计算量最小的问题 Dynamic Programming 算法

+   - 动态规划算法特征
+   - 递归地定义最优解的代价
+   - 递归地组成各子问题，直接不可解
+   - 自底向上解决各个子问题
+   - 计算最优解时保存其结构
+   - 根据构造最优解信息构造最优解

# 矩阵优化链的性质

+   - 两个例子
+     - A_i = A_i x A_{i+1} x ... x A_j
+     - cost(A_i...A_j)为其代价
+   - 优化链的性质
+     假设 计算A_1...A_n的优化链并拆开链，则
+     具有性质
+     问题的优化链可向左优化
+     即，问题子问题A_{k+1...m}的优化链是A_{k+1...m}的优化解。

# 递归地定义最优解的代价

+   - 假设
+     - m[i, j] = 计算A_i...A_j最小代价
+     - m[i, i] = 计算A_i最小代价
+     - A_i ... A_{i+k-1} ... A_j (k>=1) 最优解可拆成
+   - 递归解(A_1...A_k)(A_{k+1}...A_j)代价方程
+     m[i, j] = 计算A_i...A_j最小代价 i<j
+     m[i, j] = min_{k} { m[i, k] + m[k+1, j] + p_{i-1}p_kp_j }
+     其中 p_i p_{i+1}分别对应A_i x A_{i+1}所需数据。
+     A_i = p_{i-1} x p_i, A_j = p_{j-1} x p_j 构成。
+     A_i p_{i-1} p_i 构成。

考虑矩阵所有k，优化解的代价方程为
m[i, j] = 0 if i=j
m[i, j] = min_{k, i<=k<j} { m[i, k] + m[k+1, j] + p_{i-1}p_kp_j } if i<j
