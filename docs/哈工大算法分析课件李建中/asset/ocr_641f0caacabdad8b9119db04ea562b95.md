# 1. 考虑如下问题随机算法：

输入：S={s1,s2,...,sn | si∈R}
输出：min_k(S,k)→S 中第 k 小的元素
Random_Select(S,k)

+   1. 从 S 中随机选择一个元素 s_r
+   2. S1={s_i | s_i∈S, s_i<s_r}, S2={s_i | s_i∈S, s_i>s_r}
+   3. IF |S1|=k-1 THEN 返回 s_r
+   4. ELSE IF |S1|>k THEN 返回 Random_Select(S1,k)
+   5. ELSE 返回 Random_Select(S2,k-|S1|-1)

问题：
(1) 该算法属于哪一类随机算法？
(2) 证明：存在常数 b<1，使得算法递归过程中所考虑集合的大小的数学期望为 bn。
(3) 算法时间复杂度的数学期望里是 O(n)。

# 2. 考虑最小割问题的随机算法：

输入：一个多重无向连通图 G=(V,E)
输出：G 的一个最小边割。
Random_Mincut:

+   1. 为图 G 的任 意映射一个随机独立的正权值；
+   2. 找出 G 的最小生成树 T；
+   3. 删除 T 中权值最大的一条边得到两棵树 T1,T2；
+   4. 令 T1 的顶点集为 C，则 T2 的顶点集为 V-C；
+   5. cut={uv|u∈E, u∈C, v∈V-C}
+   6. 输出 cut。

证明：算法输出一个最小割的概率为 Ω(1/n²)。
提示：该算法与课堂上讲的算法关联起来。

# 3. 考虑带符号连通图 G=(V,E)上的最大独立子集问题的如下随机算法。

算法：IndependentSet()
输入：G=(V,E)
输出：I⊆V 使得 ∀v∈E 均有：u∈I 或 v∈I
过程：1. 为图中每个顶点随机分配 {1,2,...,|V|} 中唯一标签，不同顶点具有不同标签；

+   2. I←∅, S←V;
+   3. while S≠∅ do
+   4. u←S 中标签最小的顶点
+   5. I←I∪{u}
+   6. 从 S 中删除 u 和 u 的相邻顶点；
+   7. return I

将 IndependentSet 算法输出的集合记为 I_s。证明：
(1) I 是 G=(V,E) 的一个独立集；
(2) 对 ∀u∈V, u 在 I 中的概率等于 1/d_u，其中 d_u 表示 u 在 G 中的度。
