# 计算分支等式最小代价下界

+   - (4,6) 的代价为0, 所以等式最小代价下界为96.
+   - 我们的分支等式标记如下:
+   * 选一个解等式包括(4,6), 选色会一条4-6的路径通过和进入第6边过.
+   * 由此等式代价最小为0, 其最小代价在4处通过(4,1), 代价为32.
+   * 由此等式代价最小为0, 其最小代价在6处通过(5,6), 代价为0.
+   - 分支等式代价下界为: 96+32+0=128.
