(1) if f(n)=O(n^{log_b a + ε}) for some ε>0, then g(n)=O(n^{log_b a})

证明：(1) g(n)=O(∑_{j=0}^{log_b a - ε} a^j (n/b^j)^{log_b a + ε}) = n^{log_b a + ε} ∑_{j=0}^{log_b a - ε} (a b^{...}) ... = n^{log_b a} O(n^{ε}) = O(n^{log_b a})

(2) if f(n)=Θ(n^{log_b a}), then g(n)=Θ(n^{log_b a} lg n)

证明：(2) 由 f(n/b^j)=Θ(a^j / b^{j log_b a}) , g(n)=Θ(∑_{j=0}^{log_b a} a^j (n/b^j)^{log_b a}) ... ⇒ g(n)=Θ(n^{log_b a} lg n)

# (3) if a f(n/b) ≤ c f(n) for some 0<c<1 and all n≥b, then g(n)=Θ(f(n))

(3) g(n)中的所有项皆为正, 由上对 ∀ 0<c<1 and all n≥b, a f(n/b) ≤ c f(n), a f(n/b^2) ≤ c f(n/b), ... ⇒ a^j f(n/b^j) ≤ c^j f(n) ... g(n)=∑ a^j f(n/b^j) ≤ ∑ c^j f(n) = f(n) 1/(1-c)=Θ(f(n))

# Master定理的证明 (续)

引理3: a≥1, b>1, n=b^k, k 为正整数, 则 T(n) = { Θ(1) if n=1; a T(n/b)+f(n) if n=b^k } 的解为: (1) if f(n)=O(n^{log_b a - ε}) for some ε>0, then T(n)=Θ(n^{log_b a}) (2) if f(n)=Θ(n^{log_b a}), then T(n)=Θ(n^{log_b a} lg n) (3) if f(n)=Ω(n^{log_b a + ε}) for some ε>0, and if a f(n/b) ≤ c f(n) for some 0<c<1 and all 充分大的 n, then T(n)=Θ(f(n))

证明：(1) 由引理1 和引理2： T(n)=Θ(n^{log_b a})+O(n^{log_b a})=Θ(n^{log_b a}) (2) T(n)=Θ(n^{log_b a})+O(n^{log_b a} lg n)=Θ(n^{log_b a} lg n) (3) T(n)=Θ(n^{log_b a})+Θ(f(n))=Θ(f(n))

# Master定理的证明 (续)

当 n 不是 b 的幂时： 思路：若 n 满足递推 (平均递推类) • a T(⌈n/b⌉)+f(n) ≤ a T(n/b)+f(n) ≤ a T(⌈n/b⌉)+f(n) • 求 T(n)=a T(⌈n/b⌉)+f(n) 的上界, T(n)=a T(⌊n/b⌋)+f(n) 的下界 可得到 T(n) 的常数 • 求 T(n)=a T(⌈n/b⌉)+f(n) 的下界类比于求 T(n)=a T(⌊n/b⌋)+f(n) 的上界 所以我们可以求 T(n)=a T(⌈n/b⌉)+f(n) 的上界
