# Worst case time complexity of Quicksort

+   - Worst Case
+     - |A[p..q]|=1, |A[q+1..r]|=n-1
+     - The worst case happens in call to Partition Algorithm
+   - Time complexity
+     - T(1)=Θ(1)
+     - T(n)=T(n-1)+Θ(n)=Θ(n²)
