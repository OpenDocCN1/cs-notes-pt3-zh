# 2.1.2 似似高集合

定义2.1.2. 设f(n)与g(n)是正值函数. 如果 ∃c>0, n0, ∀n>n0, f(n)≤c g(n), 则称f(n)是g(n)似似或g(n)是f(n)的上界, 记作f(n)=O(g(n)).

O(g(n))可一视作下集合:
{f(n) | ∃c, n0, ∀n>n0, f(n)≤c g(n)}
被所有此g(n)似似的函数

# 思考题

用定义证明下列结论.

+   1. n=O(n²)
+   2. 如果f(n)=Θ(g(n)), 则f(n)=O(g(n))

# 2.1.3 希似高集合

定义2.1.3. 设f(n)与g(n)是正值函数. 如果 ∃c>0, n0, ∀n>n0, f(n)≥c g(n), 则称f(n)是g(n)希似或g(n)是f(n)的下界, 记作f(n)=Ω(g(n)).

Ω(g(n))可一视作下集合:
{f(n) | ∃c, n0, ∀n>n0, f(n)≥c g(n)}
被所有此g(n)希似的函数

# 思考题

用定义证明下列结论.

f(n)=Θ(g(n)) iff f(n)=O(g(n)) 且 f(n)=Ω(g(n))
