# 算法定义

定义1 (计算) 可由一个修复计算模型机械地执行的规则或算法步骤序列则称为被计算模型的一个计算。

+   - 注意
+     - 一个计算和模型是一个计算 (计算模型是计算如)
+     - 计算可能永远不停止……不是算法

定义2(算法)算法是一个满足下列条件的计算：
有限性：有步骤必须停止。
确定性：每步都是严格定义和明确的动作。
有效性：每个操作都是被精确地执行。
输入：具有清楚定义的输入和输出的输入。
输出：产生满足给定条件要求的输出。

算法帮助我们解决间题。
什么是问题？

定义3 (问题) 设Input和Output是两个集合。一个问题就是一个集合P, Input×Output, Input为问题P的输入集合, Input的每个元素都是问题P的一个输入。Output称为问题P的输出集合, Output的每个元素都是问题P的一个输出。

+   - 注意
+     - 问题定义了输入和输出的关系

例: SORT问题定义如下
输入: Input= {<a1,...,an>|ai是整数}
输出: Output= {<b1,...,bn>|bi是整数, b1≤...≤bn}
问题: SORT= {<a1,...,an>,<b1,...,bn>| <a1,...,an>∈Input, <b1,...,bn>∈Output, {a1,...,an}={b1,...,bn}}
