# 7.4 Personnel Assignment Problem

+   - 问题的定义\n- 指派的特殊问题\n- 解决问题的主要界限搜索算法

# 问题的定义

输入：\n一组对象 P={P₁, P₂, …, Pₙ}，以及集合 J={J₁, J₂, …, Jₙ}。

> 例：给定 P={P₁, P₂, P₃}，J={J₁, J₂, J₃}，J₁≤J₂≤J₃。P₁→J₁，P₂→J₂，P₃→J₃；P₁→J₁，P₂→J₃，P₃→J₂ 等不同指派。

目标：求解 P 的最优指派，使总成本最小。

# 指派问题的搜索空间

设有 n 个对象和 n 个任务，指派问题可以表示为排列组合。\n例如：给定若干对象及任务，搜索空间由所有可能的指派组成。

![](bbox=[0.126, 0.803, 0.268, 0.874])

搜索树节点序列示例：S₁, S₂, S₃, S₄, S₅, S₆, S₇, S₈, S₉。

# 问题的解空间

令 P₁→J₁，P₂→J₂，…，Pₙ→Jₙ 是一个可能的指派。所有可能的指派构成一个解空间。

> 问题的解空间是所有可能指派的集合，每个序列对应于一个可能的解。
