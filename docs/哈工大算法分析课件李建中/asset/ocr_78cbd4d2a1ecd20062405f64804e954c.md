# 9.6 The Subset-sum Problem

+   - 问题定义
+   - 指数时间算法
+   - 完全多项式时间近似格式

# 问题定义

+   - 输入：
+     (S, t), S={x1, x2, ..., xn},
+     x_i为的正整数
+   - 输出：
+     Σi∈A x_i 满足：
+     A⊆S, Σi∈A x_i ≤ t
+     Σi∈A x_i = max{ Σi∈B x_i | B⊆S }

# 指数时间算法

+   - 算法
+     (若S是集合, x是整数, 要求S+x={s+x | s ∈ S})
+     Exact-Subset-Sum(S={x1, x2, ..., xn}, t)
+     1. n←|S|;
+     2. L0←{0};
+     3. For i←1 To n Do
+     4. Li←Merge-List(Li-1, Li-1+xi);
+     5. 删除Li中所有大于t的元素;
+     6. Return Ln 中最大元素.

+   - 计算量：
+     - L0=<0>
+     - L1=<0, x1> 1*一个元素所组成的集合(大于等于1) *
+     - L2=<0, x1, x2, x1+x2> 1*两个元素所组成的集合(大于等于1) *
+     - L3=<0, x1, x2, x3, x1+x2, x1+x3, x2+x3, x1+x2+x3> 1*三个元素所组成的集合(大于等于1) *
+     - Li=第i个元素所组成的集合(大于等于1)
+     因此最坏情况如下个情况：
+     Ln=第n个元素所组成的集合(大于等于1)
