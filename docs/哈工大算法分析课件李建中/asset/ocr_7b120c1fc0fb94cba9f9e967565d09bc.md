# 算法

+   - 这一多项化使 n/2×n/2 矩阵的 10 个乘法和 7 个加法
+     M₁ = A₁₁(B₁₁ + B₁₂)
+     M₂ = (A₁₁ + A₁₂) B₂₂
+     M₃ = (A₁₁ + A₁₂) B₁₁
+     M₄ = A₁₂(B₂₁ + B₂₂)

+     M₇ = (A₁₁ - A₁₂)(B₁₁ + B₁₂)

# 算法

+   - 计算 C=AB 需要另外 8 次 n/2×n/2 矩阵加减
+     C₁₁ = M₁ + M₄ - M₅ + M₆
+     C₁₂ = M₁ + M₂
+     C₂₁ = M₃ + M₄
+     C₂₂ = M₂ + M₃ - M₁ - M₇

# 算法复杂性分析

+   - 18 个 n/2×n/2 矩阵加减，系数为常数，多个 O(n²)
+   - 7 个 n/2×n/2 矩阵乘法
+     - 这是递归过程
+       T(n)=O(1) n=2
+       T(n)=7T(n/2)+O(n²) n>2
+   - 根据 Master 定理求解 T(n)

# 问题定义

+   - 输入：Euclidean 空间上有 n 个点组成的集合 Q
+   - 输出：Pᵢ, Pⱼ ∈ Q
+     Dist(Pᵢ, Pⱼ)=Min{Dist(X, Y) | X, Y ∈ Q}
+   - Dist(X, Y) Euclidean 距离：
+     假设 X=(x₁, y₁), Y=(x₂, y₂)，则
+     Dist(X,Y)=√[(x₁ - x₂)² + (y₁ - y₂)²]
