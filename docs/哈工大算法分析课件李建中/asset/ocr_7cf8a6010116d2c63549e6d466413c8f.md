# Divide-and-Conquer 递归与分治

+   - 分治过程
+     - 递归地把子问题
+     - 征服
+   - 递归分程递归方法
+     - 假设问题大小为n, T(n)为时间复杂度
+     - 当n≤c, T(n)=Θ(1)

+   - Divide阶段的时间复杂度
+     - 划分为a个子问题
+     - 每个子问题大小为n/b
+     - 划分所花费的时间复杂度=D(n)
+   - Conquer阶段的时间复杂度
+     - 递归求解
+     - Conquer所花费=aT(n/b)
+   - Combine阶段的时间复杂度
+     - 将子问题合并=C(n)

+   - 假设
+     - T(n)=Θ(1) if n≤c
+     - T(n)=aT(n/b)+D(n)+C(n) otherwise
+   - 递归求解方程T(n)
+     - 使用常数递推方法
