# 一维空间算法(续)

+   - Divide-and-conquer算法

Preprocessing:

+   1. 若|Q|中包含2个点，则返回这两个点；
+   2. 查找Q中点坐标中位数m。

![](bbox=[0.18, 0.38, 0.42, 0.45])

# Divide:

3. 用Q中点坐标中位数m把Q划分为两个大小相等的集合
Q1 = {x∈Q | x≤m}, Q2 = {x∈Q | x>m}

![](bbox=[0.55, 0.35, 0.85, 0.42])

Conquer:

4. 递归地求Q1,Q2中最近点对或近点
(p1 p2) (q1 q2)

Merge:

![](bbox=[0.18, 0.7, 0.42, 0.78])

+   5. 考虑(p1 p2)、(q1 q2)之间的点(p3 q3)可能将产生更近的点对(x,y)。若p3是Q1中最大点,q3是Q2中最小点。(x,y)Q中最近点对。

+   - 时间复杂性

--Divide所需要量O(n)时间
--Conquer所需要量2T(n/2)时间
--Merge所需要量O(n)时间

递推方程
T(n)= O(1)      n=2
T(n)=2T(n/2)+O(n)   n≥3

--用Master定理求解T(n)
T(n)=O(nlogn)

# 二维空间算法

+   - Divide-and-conquer算法

Preprocessing:

+   1. 若|Q|中包含一个点，则返回该点；
+   2. 将配对Q中点按x坐标值由小到大排序。

![](bbox=[0.18, 0.88, 0.35, 0.98])

Divide:

+   3. 找到Q中点x坐标中位数m,
+   4. 用垂直L:x=m把Q划分为两个大小相等的集合
+   QL和QR。QL在直线L左侧,QR在直线L右侧。
