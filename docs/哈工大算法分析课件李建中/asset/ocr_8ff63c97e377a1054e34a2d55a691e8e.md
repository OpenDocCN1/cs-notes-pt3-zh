# 编码树T的条件

— 设C是字符集(或文件字符集)且字符集大小为n, ∀c∈C
f(c)是字符c对应的编码树码长
— d_T(c)是字符c在编码树T中码长, 即c的编码码长
— T的编码信息量为∑_{c∈C} f(c)d_T(c)
B(T)=∑_{c∈C} f(c)d_T(c)

# 优化编码树问题

+   - 给定：字符集 C = {c₁, c₂, ..., cₙ},
+   频率集 F = {f(c₁), f(c₂), ..., f(cₙ)}
+   问题：求满足B(T)最小的编码树
+   - 贪心策略：
+   将频率相同的字符合并成一个新字符，
+   在一棵树中，其和最小

# 设计哈夫曼编码方法

+   - 贪心方法：
+   - 每次取频率最小的两个字符x,y，
+   构造一个新节点
+   - 剩余问题规模缩小：
+   C' = C - {x, y} ∪ {z}

![](bbox=[0.25, 0.62, 0.35, 0.7])

# 优化哈夫曼树的分析

定义1. 设T是字符集C的哈夫曼树, ∀c∈C, f(c)是字符c出现的频率,取x,y∈A且有唯一的共同祖先节点z,记它为父亲节点,相对操作：
将频率f(z)=f(x)+f(y)合并, T'=T-{x,y}是字符集C'=C-{x,y}∪{z}的哈夫曼编码树

![](bbox=[0.55, 0.62, 0.88, 0.78])

# 证明思路

T' → T 合并过程示意图，f(z)=f(x)+f(y)

注, 令B(T)=B(T')+f(z)(d_T(x)+d_T(y))
B(T)=∑_{c∈C'} f(c)d_T(c)+f(x)d_T(x)+f(y)d_T(y)+∑_{c∈C'} f(c)d_T(c)
= f(x)(d_T(x)+d_T(y)+1)+f(y)(d_T(x)+d_T(y)+1)+∑_{c∈C'} f(c)d_T(c)
= f(x)(d_T(x)+d_T(y)+1)+f(y)(d_T(x)+d_T(y)+1)+∑_{c∈C'} f(c)d_T(c)
= f(x)(d_T(x)+d_T(y)+1)+f(y)(d_T(x)+d_T(y)+1)
= f(x)+f(y) f(z) f(c)
= f(x)+f(y) f(z) f(c) d_T(c)+∑_{c∈C'} f(c)d_T(c)=B(T')+f(z)f(x)f(y)
每次T'中频率最小的两个字符x,y合并成新字符z,构造新树T',则B(T')>B(T')
在字符集C'中,它们是最小的两个,合并其子孙合并为T',可得子孙, y,f(x) f(z)
则从C'中一个子集构造哈夫曼树T''
