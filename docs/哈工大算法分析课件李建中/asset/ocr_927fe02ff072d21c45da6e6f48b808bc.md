# 定金多项式近似模式

# 基本思想：

修剪时，如果有两个近似值，只留一个代表，保留小于某个阈值的

-设 δ(0<δ<1) 是修剪参数，修剪参数为 L：
(1). 从 L 中删除不满足条件的元素，
(2). 若 L 中存在两个元素 x_i 和 x_j 满足 x_i < x_j 且 x_j / x_i ≤ 1+δ，则保留 x_j，L' 最多一个元素 ≥δ，
(1-δ) ≤ y ≤5

-每次修剪操作后，L' 最多一个代表元素 y 和 L 中，而 y 与 L 中所有元素的相对误差是小于 δ。

# 修剪算法

```
Trim(L={y_1,y_2,...,y_m}, Φ) {y_i y_j y_i, 0<δ<1, 修剪参数为 L'}
m←|L|
L'←<y_1>
last←y_1
For i←2 To m Do
If last< (1-Φ) y_i
Then y_i → L' ; "将 y_i 加入 L'，若 L' 中有元素与 y_i 相近，则删除"
last←y_i;
Return L';
```

复杂度：O(|L|)=O(m)

# 定金多项式近似模式

输入：S={x_1,x_2,...,x_n}, t≥0, 0<ε<1
输出：近似解

```
Approx-Subset-Sum(S, t, ε)
1. n←|S|;
2. L_0←<∅>
3. For i←1 To n Do
4. L_i←Merge-List(L_{i-1}, L_{i-1}+x_i)
5. L_i←Trim(L_i, ε/n) "修剪参数：δ=ε/n"
6. 若 L_i 剩余元素太多则删除；
7. 令 z 为 L_n 中最大元素；
8. Return z;
```

# 性质与例

定理1. Approx-Subset-Sum 产生集合和问题的一个近似多项式时间近似方案。

设 P_0={0}, P_i={x | x∈P_{i-1}∪{x+y | x∈P_{i-1}, y∈{x_1,...,x_i}}}, 例如，
Δ={1,4,5}, 则
P_1={0,1},
P_2={0,1,4,5},
P_3={0,1,4,5,6,9,10}.

假设集合 S 可表示为 L_i, 若 P_i 中所有元素大于 t 则返回
相应的值。

L_i 第5步修剪后小于第6步删除时删除的元素的，修剪后 L_i⊆P_i，
对于第8步的输出 z 是 S 的一个子集和，满足如下性质
(1). C*(1-ε)z_0 ≤ C*(1-ε)z ≤ C* 是精确解，z 是近似解，
(2). 若 z 与 t 的相对误差小于 ε，则返回 z。
(2). 最优值是 |S|^(O(1/ε)) 时间和空间复杂度。
