# 算法实例

| yj | B | D | C | A | B | A | B |
|---|---|---|---|---|---|---|---|
| x_i | 0 | 0 | 0 | 0 | 0 | 0 | 0 |
| A | 0 | ↑0 | ↑0 | ↑0 | ←1 | ←1 | ↑1 |
| B | 0 | ↑1 | ←1 | ←1 | ↑1 | ↑2 | ←2 |
| C | 0 | ↑1 | ←1 | ←2 | ←2 | ↑2 | ↑2 |
| B | 0 | ↑1 | ↑1 | ↑2 | ↑2 | ←3 | ←3 |
| D | 0 | ↑1 | ↑2 | ↑2 | ↑2 | ↑3 | ↑3 |
| A | 0 | ↑1 | ↑2 | ↑2 | ←3 | ↑3 | ←4 |
| B | 0 | ↑1 | ↑2 | ↑2 | ↑3 | ←4 | ↑4 |

+   - C[i,j]=0, i=0 或 j=0
+   - C[i,j]=C[i-1,j-1]+1, x_i=y_j
+   - C[i,j]=Max(C[i-1,j],C[i,j-1]), x_i≠y_j

```
LCS-length(X, Y)
 m←length(X); n←length(Y);
 For i←1 To m Do C[i,0]←0;
 For j←1 To n Do C[0,j]←0;
 For i←1 To m Do
   For j←1 To n Do
     If x_i=y_j,
       Then C[i,j]←C[i-1,j-1]+1; B[i,j]←"↖";
     Else If C[i-1,j]≥C[i,j-1]
       Then C[i,j]←C[i-1,j]; B[i,j]←"↑";
       Else C[i,j]←C[i,j-1]; B[i,j]←"←";
 Return C and B.
```

# 构造化解

+   - 基本思想
+     - 从B[m,n]出发循着指针找到
+     - 若B[i,j]="↖", 则x_i=y_j, LCS有一个后缀
+     - 如此递归地"LCS"等于X的LCS的Inverse

```
Print-LCS(B, X, i, j)
 IF i=0 or j=0 THEN Return;
 IF B[i,j]="↖"
   THEN Print-LCS(B, X, i-1,j-1); Print x_j;
   ELSE IF B[i,j]="↑"
     THEN Print-LCS(B, X, i-1,j);
     ELSE Print-LCS(B, X, i,j-1).

Print-LCS(B, X, length(X), length(Y))
可打印出X与Y的LCS。
```

# 算法复杂性

+   - 时间复杂性
+     - 计算最长公共子序列时间
+       - (i,j)遍历矩阵, i跨m步, j跨n步
+       - O(mn)
+     - 构造最长公共子序列时间: O(m+n)
+     - 最长公共子序列总时间: O(mn)
+   - 空间复杂性
+     - 需要存储矩阵C和B
+     - 需要空间 O(mn)
