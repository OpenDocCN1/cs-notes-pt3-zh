# Greedy算法的基本思想

+   - 每一步都做出局部最优的选择，以期得到全局最优解
+   - 一步一步地构造解
+   - 决策点有当前最优的选择
+   - 需要证明该选择能够导致最终达到全局最优解
+   - Greedy算法不一定能产生全局最优解
+   - Greedy算法要满足的两个基本性质
+     - Greedy-choice-property
+     - Optimal substructure
