# 定理2. 设C是一个min-cut，其大小为k，在算法结束时，C中无边吸收缩过的概率大于2/m²。

证. A表示每一步没有选过C的边的，|S∩k-2|。
在第i步，选中的边的在C中的概率至多为k/(kn/2)=2/m，即 Pr(A_i) ≥ 2/m - 2/m。
在第2步，若A_4发生，则至少有k/m -1/2条边(每次收缩减少一个节点)，选中C中边的概率为2/(m-1)，即 Pr(A_4) ≥ 2/m - 2/(m-1)。
在第3步，若A_4发生，则有至少k/m -1/2节点，即至少有k(n-1)/2条边。于是
Pr(A_4 | A_1) ≥ ∏_{i=1}^{2} (1-2/(n-i+1)) = 2/(n-2) - 2/(n-1) > 2/n²。
最后我们有
Pr(∩_{i=1}^{2} A_i) ≥ ∏_{i=1}^{2} (1-2/(n-i+1)) = 2/(n-2) - 2/(n-1) > 2/n²。
