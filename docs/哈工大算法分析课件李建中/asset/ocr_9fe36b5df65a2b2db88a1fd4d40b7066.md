# 最小问题

给出一个集合C=(V,E)，假设x∈V，或y∈V，x≠y。
定义x到y的距离c(x,y)>0。
给出：s到t间的最短路径。
即，s∈V,t∈V，s≠t，寻找∑_{i,j}c(v_i,v_j)最小

# 最小问题与最大问题可归约min-max关系

最小问题与最大问题可归约：最小问题可转化为最大问题。
例如：为某一个小的集合寻找一个不小于S的集合。
寻找，问题有一个最小值则就有一个最大值。

# 集合覆盖问题线性规划松弛

max I₀
s.t. f_{ij} ≤ c_{ij}  ij∈E
∑_{j} f_{ij} - ∑_{j} f_{ji} ≤ 0  i∈V
f_{ij} ≥ 0  ij∈E
min ∑_{ij} c_{ij} f_{ij}
s.t. d_{ij} - p_i + p_j ≥ 0  ij∈E
p_i ≥ 1  i∈V
d_{ij} ≥ 0  ij∈E
p_i ≥ 0  i∈V

集合覆盖问题松弛
p_i = 1, p_j = 0
X = {i | p_i = 1} V-X = {i | p_i = 0}
X,V-X是一个s,t割

# 两类基于LP方法的近似算法

将最小化问题转化为LP问题并求解近似解。
将最小化问题转化为LP问题，得到一个近似解。
例如：Karmarkar算法以及内点法。
问题可近似解，取近似解可得到近似解。
方法1：贪心法  寻找一个近似解以降低成本和提高性能。
方法2：primal-dual schema

有解LP：如有一个解可作一个近似解。
近似LP：如问题可转化为可解：
此问题有一个近似解可得到一个近似解。
两类方法可得到近似解，一般一个方法可得到近似解。
解可近似，而问题不一定。此处，由两种方法得到的结果可被证明近似值也近似。

# 问题定义

+   - 集合：
+     有限集U，U有一个子集族S，X=∪_{S∈S} S，每个集合S赋予代价c(S)
+   - 覆盖：
+     C⊆S，满足
+     (1) U=∪_{S∈C} S，
+     (2) C是满足条件(1)的小集合族，则∑_{S∈C} c(S)最小。

# 集合覆盖问题的线性规划松弛

给定一个集合族S，给每一个集合S赋x_S
x_{S}=0  若S不∈C      x_S=1  若S∈C
集合覆盖问题的线性规划松弛
minimize ∑_{S∈S} c(S) x_S
subject to ∑_{S∋e} x_S ≥ 1,  e∈U
x_S ∈ {0,1},  S∈S
