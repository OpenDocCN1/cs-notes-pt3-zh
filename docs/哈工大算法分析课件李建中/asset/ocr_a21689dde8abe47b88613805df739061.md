# 问题定义

+   - 多边形
+   多边形表示顶点序列被表示为 P={v1,v2,...,vn} 或顶点序列 v1,v2,...,vn,v1
+   - 简单多边形
+   除了顶点外没有其它顶点在多边形边上
+   - 多边形方向, 逆时针方向
+   一平面凸多边形可被定义为其所有边是凸多边形角线,
+   一平面凸多边形顶点序列若多边形是凸的
+   一平面凸多边形若其内部和外部顶点序列都是多边形角线

+   - 设P为多边形
+   多边形P上任意两个相邻顶点 vi, vi+1 所对应的边称为 vi, vi+1 弦或边
+   - 正则划分
+   一个多边形P的正则是划分是把P划分为若干个相邻正三角形组成的集合
+   - 绝对三角剖分问题
+   给定一个多边形P和代价函数W
+   一剖分, 若P的正三角剖分T, 使其代价 Σ_{T∈T} W(T) 最小, 其中 S_T 是所对应的正三角形集合

# 优化解的动态分析

+   - 设
+   P={v1,v2,...,vn} 是 n+1 个顶点组成的多边形
+   T_P 为多边形的优化三角剖分, 包含顶点 v1,v2,...,vn
+   T_P = T(v1,...,v_k) ∪ T(v_k,...,vn) ∪ {v1v_k, v_kvn}

+   (1). T(v1,...,vk) 是 P(v1,...,vk) 的优化三角剖分。
+   (2). T(vk,...,vn) 是 P(vk,...,vn) 的优化三角剖分。

# 优化三角剖分的代价函数

+   - 设 f[i,j] = < v_{i+1},...,v_{j-1} > 的优化三角剖分代价
+   f[i,i] = f[i,i+1] = 0
+   f[i,j] = min_{k=i+1}^{j-1} { f[i,k] + f[k,j] + w( Δ(v_i,v_k,v_j) ) }
+   注:
+   f[i,k] = < v_{i+1},...,v_{k-1} > 的优化三角剖分代价
+   f[k,j] = < v_{k+1},...,v_{j-1} > 的优化三角剖分代价
