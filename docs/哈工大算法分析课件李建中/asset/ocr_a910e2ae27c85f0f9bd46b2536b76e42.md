# 数学基础

+   - 数学期望
+     - 离散随机变量 X 的数学期望 E[X] = Σx·P(X=i)
+     - 若函数 f(x) 在集合 S 上实现取值函数，则 E[f(X)] = Σf(i)·P(X=i)
+   - Markov 不等式
+     - P{Y ≥ t} ≤ E[Y]/t, 其中 Y 为非负随机变量, t > 0

# 方差的性质与 Chebyshev 不等式

+   - 方差 σ² = E[(X-μ)²], μ 为随机变量的数学期望
+   - σ 为标准差
+   - Chebyshev 不等式: P{|X-μ| ≥ rσ} ≤ 1/r²
+   - 随机变量 X 满足 P{X=1}=p, P{X=0}=1-p, 则 σ² = p(1-p)
+   - 若 X₁, X₂, ..., Xₙ 相互独立, Xᵢ 服从独立同分布
+   - 若随机变量满足 P{X=1}=p, P{X=0}=1-p, 则 σₙ² = np(1-p)
