# 算法的正确性分析

定义5(算法正确性).一个算法是正确的, 如果它对于每一个输入都终止止,而产生正确的输出。

+   - 什么算法是正确的算法?
+     ①从一个或多个输入上终止
+     ②对所有输入都终止, 并且对每一个输入产生正确的结果
+   - 什么称为算法/就算法的正确性?
+     ①算法对所有输入终止
+     ②产生正确的输出/产生更多的正确解

+   - 什么要素进行正确性证明?
+     - 正确性证明=终止性证明?
+       终止证明, 正确证明两者皆有!
+       只证明终止就无意义!!
+   - 如何证明算法的正确性?
+     - 证明算法对所有输入都终止
+     - 证明对每个输入产生正确结果
+   - 近似算法的正确性分析?
+     - 证明算法对所有输入都终止
+     - 分析算法的误差/提供正确性概率

+   - 复杂性分析能力

定义7(时间复杂性).一个算法对特定输入的时间复杂性是该算法对该输入产生结果所需的最少基本操作“步”数

+   - 说明
+     - 时间复杂性是输入大小的函数
+     - 我们假设一步操作所需时间都相同, 实际上下一步所需时间可能不同。

定义8(空间复杂性).一个算法对特定输入空间复杂性是该算法对该输入产生结果所需实际的存储空间大小。
