# Amortized Analysis的基础思想

+   Aggregate Analysis方法（多个操作平均代价）
+   一串长度n个操作总上界T(n), 每个操作平均T(n)/n
+   Accounting方法（每个操作平均摊销代价）
+   一方面要预先为每个操作分配代价
+   一方面操作费用被预先储藏起来以应付“坏”操作
+   Potential方法（每个操作相对代价）
+   一方面要预先操作不同操作平均代价
+   “一类”的操作作为另一个操作的“储蓄”
