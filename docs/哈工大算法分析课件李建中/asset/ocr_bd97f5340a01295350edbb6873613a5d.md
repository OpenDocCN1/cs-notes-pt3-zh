# 例3. 设对所有k≥0, a_{k+1}/a_k ≤ r <1, 求 ∑ a_k 的上界

解: a_k / a_0 ≤ r^k ⇒ a_k ≤ a_0 r^k,
 a_k / a_1 ≤ r^{k-1} ⇒ a_k ≤ a_1 r^{k-1},
 a_k / a_1 ≤ r^k ⇒ a_k ≤ a_1 r^k ……
 a_k / a_{k-1} ≤ r ⇒ a_k ≤ a_{k-1} r ≤ a_0 r^k
于是, ∑_{k=0}^{∞} a_k ≤ ∑_{k=0}^{∞} a_0 r^k = a_0 ∑_{k=0}^{∞} r^k = a_0 / (1 - r)

# 例4. 求 ∑_{k=1}^{∞} (k/3^k) 的界

# 2.4 递归方程

+   - 递归方程: 递归方程是使用具有较小输入值和相同方程来描述一个方程。

+   - 递归方程例: Merge-sort排序算法的递推性方程
+   T(n)=Θ(1) if n=1
+   T(n)=2T(n/2)+Θ(n) if n>1.
+   T(n) 解决是 Θ(n log n)

# 求解递归方程的三个主要方法

+   - Substitution方法:
+     - Guess first,
+     - 然后验证和证明方法证明.
+   - Iteration方法:
+     - 把方程转化为一个和式,
+     - 然后用估计和方程求解.
+   - Master方法:
+     - 求解型如 T(n)=aT(n/b)+f(n) 的递归方程
