# 2.1.5 严格高阶集合

定义2.1.4. 设f(n)和g(n)是正函数。若存在c>0, n0, ∀n>n0, f(n)>c g(n), 则称f(n)严格比g(n)高或g(n)是f(n)的严格下界, 记作f(n)=w(g(n))。

w(g(n))可记为下集合:
{f(n) | ∀c, n0, ∀n>n0, f(n)>c g(n)}
和所有比g(n)严格高阶的函数

# 思考题

用定义证明下列格论：

+   1. f(n)=w(g(n)) iff g(n)=o(f(n))
+   2. n^1/2=w(n)
+   3. n^1/2 o w(n^1/2)?
+   4. f'(n)=w(g(n)) ⇒ lim_{n→∞} f(n)/g(n)=∞

# 2.1.6 高阶的性质

A 传导性：

+   (a) f(n)=Θ(g(n)) ∧ g(n)=Θ(h(n)) ⇒ f(n)=Θ(h(n))
+   (b) f(n)=O(g(n)) ∧ g(n)=O(h(n)) ⇒ f(n)=O(h(n))
+   (c) f(n)=Ω(g(n)) ∧ g(n)=Ω(h(n)) ⇒ f(n)=Ω(h(n))
+   (d) f(n)=o(g(n)) ∧ g(n)=o(h(n)) ⇒ f(n)=o(h(n))
+   (e) f(n)=w(g(n)) ∧ g(n)=w(h(n)) ⇒ f(n)=w(h(n))

# 2.1.6 高阶的性质(续)

B 自反性：

+   (a) f(n)=Θ(f(n)),
+   (b) f(n)=O(f(n)),
+   (c) f(n)=Ω(f(n))

C 对称性
f(n)=Θ(g(n)) iff g(n)=Θ(f(n))

D 反对称性：
f(n)=Ω(g(n)) iff g(n)=O(f(n))
f(n)=o(g(n)) iff g(n)=w(f(n))
