# 算法举例

+   • 问题定义
+     - Input={<a1,...,an> | ai是整数}
+     - output={<b1,...,bn> | bi是整数, 且 b1≤...≤bn}
+     - P={(<a1,...,an>,<b1,...,bn>) | <a1,...,an>∈Input, <b1,...,bn>∈output, {a1,...,an}={b1,...,bn}}
+   • 算法思想
+     - 朴素插入排序

A[1,...,n] = 5,2,4,6,1,3
A[1,...,n] = 5
A[1,...,n] = 2,5
A[1,...,n] = 2,4,5
A[1,...,n] = 2,4,5,6
A[1,...,n] = 1,2,4,5,6
A[1,...,n] = 1,2,3,4,5,6

+   • 算法描述
+     - Insertion-sort(A)
+     - Input: A[1,...,n]=n个数
+     - output: A[1,...,n]=n个sorted数
+     - FOR j=2 To n Do
+     - key←A[j];
+     - i←j-1
+     - WHILE i>0 AND A[i]>key Do
+     - A[i+1]←A[i];
+     - i←i-1;
+     - A[i+1]←key;
