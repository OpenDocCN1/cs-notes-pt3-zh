# 算法正确性

引理1. Greedy算法的一个独立子集集合.
注. Greedy算法的集合A, 此时权值和构造.
若|A|=0时, A是空集, 由传递性, A是独立子集.
若|A|≤k时, A是独立集.
若|A|=k+1时, A由第4-5步骤得, 此时A=A∪{x}.
第4步 已知A∪{x}∈I, A=A∪{x}是独立子集.

注. 当x∈S是独立集时A的extension不是独立的extension.
当x∈S的extension, A∪{x}∈I, 由M的传递性.
{x}∈I, 称{x}是x的extension, 考虑.
根据1. 任何集是一个独立集的扩展, 则新集不会被选中.
根据2. Greedy算法不会产生由未考虑的独立集中的元素产生扩展集.
