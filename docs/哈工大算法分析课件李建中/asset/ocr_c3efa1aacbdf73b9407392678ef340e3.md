# 问题定义

输入：n位二进制矩阵X和Y
输出：X和Y的乘积
通常，计算X*Y的时间复杂度是O(n³)。
我们能否找到一个算法是O(n^2.81)的时间。

# 算法的数学基础

X = [A B] n/2 n/2   Y = [C D] n/2 n/2
XY = (A²n² + B)(C²n² + D)
= AC² + AD²n² + BC²n² + BD
= AC² + (A-B)(D-C)+AC+BD)²n² + BD

算法步骤
1. 划分A-B和D-C;
2. 计算n/2规模的AC、BD、(A-B)(D-C);
3. M=(A-B)(D-C)+AC+BD;
4. N=AC与BD，M=M与乘积n/2;
5. 计算XY=N+M+BD。

递归计算复杂性
T(n)=4T(n/2)+O(n²)

# 算法分析

+   - 建立递归方程
+     T(n)=Θ(1) if n=1
+     T(n)=3T(n/2)+O(n) if n>1
+   - 使用Master定理
+     T(n)=O(n^1.59)=O(n^1.59)

# 4.3 快速乘法

# 问题定义

输入：两个n×n矩阵A和B
输出：A和B的乘积
通常，计算AB的时间复杂度是O(n³)。
我们能否找到一个算法是O(n^2.81)的时间。

# 算法的数学基础

+   - 把C=A+D分成4个规模为n/2×n/2的子矩阵
+   - 每个子矩阵都是一个n/2×n/2矩阵

[C11 C12; C21 C22] = [A1; A2] [B11 B12; B21 B22]

递归计算复杂性
T(n)=8T(n/2) ω(n²)=O(n^ω)

矩阵乘法递归公式：
C11=A11B11+A12B21, C12=A11B12+A12B22
C21=A21B11+A22B21, C22=A21B12+A22B22
