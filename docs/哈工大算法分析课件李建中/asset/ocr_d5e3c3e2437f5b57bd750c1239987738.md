# Building a heap

+   - Lemma. Let n=length[A], then the elements in the subarray A[(⌊n/2⌋+1) .. n] are all leaves of the three.
+   Proof: Homework

![](bbox=[0.22, 0.32, 0.45, 0.48])

+   - Idea of the algorithm
+     - The elements in A[(⌊n/2⌋+1) .. n] are 1-element heap
+     - The algorithm goes through the rest nodes of the tree and runs Max-Heapify on each one.

![](bbox=[0.62, 0.32, 0.85, 0.48])

+   - Algorithm

```
Build-Max-Heap(A)
heap-size[A] ← length[A];
for i ← ⌊length[A]/2⌋ downto 1
do Max-Heapify(A, i);
```
