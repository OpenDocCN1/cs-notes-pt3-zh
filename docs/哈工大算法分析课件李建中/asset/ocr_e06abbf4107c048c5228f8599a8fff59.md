# Las Vegas算法

+   - 一旦找到一个解，该解一定是正确的
+   - 找到解的概率与算法执行时间成正比
+   - 增加对问题的反复求解次数，可以是求解无效的概率任意小

# Sherwood算法

+   - 一定能够获得一个正确解
+   - 确定算法的最好和平均复杂度差别大时，加入随机性，即得到Sherwood算法
+   - 消除算法行为与特殊实例的联系

# 随机算法的性能分析

+   - 仅依赖于随机选择，不依赖于输入的分布
+   - 确定算法的平均复杂度分析：
+     依赖于输入的分布
+   - 对于每一个输入都要考虑算法的概率性性能

# 随机算法的目标

+   - 平均的运行时间：时间复杂性变量的均值
+   - 取得正确解的概率
+   - 取得优化解的概率
+   - 解的精确度估计

# 计算值

# 一数学基础

一设有1个半径为a的圆及其外切四边形

+   - 向正方形随机地投掷n个点，设k个点落在圆内
+   - 按照点落在圆内的概率为 (πr²)/(4a²)=π/4
+   - 用k/n近似π/4,即k/n≈π/4,于是π≈4k/n.
+   - 我们可以用蒙特卡罗方法计算π

# 一算法

```
K=0;
For i=1 To n
  随机地产生正方形中的一点(x, y);
  If x²+y²≤1 Then k=k+1;
Endfor
Return (4k/n)
```

+   - 时间复杂度=O(n)
+     - 不是随输入的大小,而是随随机样本的大小
+   - 解的精确度
+     - 随着随机样本大小增加而增加
