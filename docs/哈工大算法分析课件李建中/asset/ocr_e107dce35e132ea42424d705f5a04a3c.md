# Divide-and-Conquer 技术设计

+   - 设计过程有三个步骤
+     - Divide: 将问题规模缩小为若干个子问题
+     - Conquer: 解决各子问题得到其解或证明无解
+     - Combine: 将各子问题的解，组合成原问题的解
