# 类似 Graham-Scan(Q)

/*S为栈,类似 Graham-Scan 构造凸包的顺序为 CH(Q) 的顶点*/

+   1. 若 Q 中 y 坐标最小的点为 p0；
+   2. 按极角 p0(或逆时针) 方向对 Q 中除去 p0 的点排序，得到 <p1 p2 ... pn>；
+   3. Push(p0, S); Push(p1, S); Push(p2, S);
+   4. FOR i=3 TO n DO
+   5. While Next-to-top(S), Top(S)与 p0 的形成左转 Do
+   6. Pop(S);
+   7. Push(pi, S);
+   8. Rerurn S.

+   • 时间复杂性
+     — 第1步 O(n) 排序
+     — 第2步 O(n log n) 排序
+     — 第3步 O(1) 时间
+     — 第4-7步 每次 O(1) 时间
+     — 总时间复杂度 T(n) = O(n log n)

# 正确性分析

假设 n 个不同的点构成 Q 是 Graham-Scan 算法输入，|Q|≥3, 其性质类似，则 S 自身即为凸包 CH(Q) 的顶点（按逆时针顺序）。
