+   - 字符序列
+     - X=(A, B, C, B, D, B)

+   - 公共子序列
+     - Z是X与Y的公共子序列 iff Z是X的子序列且是Y的子序列。

# 最长公共子序列（LCS）问题

输入： X = (x₁,x₂,...,xₙ), Y = (y₁,y₂,...,yₘ)
输出： X与Y的最长公共子序列 Z=(z₁,z₂,...,zₚ)

# 最长公共子序列结构分析

+   - 序列前缀
+     - 设X=(x₁,x₂,...,xₙ)是一个序列
+     - 则Xᵢ=(x₁,...,xᵢ)是X的前缀
+     例： X=(A,B,D,C,A), X₃=(A), X₅=(A,B), X₇=(A,B,D)

# 优化子结构

X与Y的LCS的优化子结构
LCSᵢⱼ = LCSᵢ₋₁,ⱼ₋₁ + 1 若 xᵢ = yⱼ
LCSᵢⱼ = LCSᵢ₋₁,ⱼ 若 xᵢ ≠ yⱼ 且 xᵢ > yⱼ
LCSᵢⱼ = LCSᵢ,ⱼ₋₁ 若 xᵢ ≠ yⱼ 且 xᵢ < yⱼ

# 优化子结构

定理1（优化子结构）设X=(x₁,...,xₘ), Y=(y₁,...,yₙ)
是两个序列，LCS(Xₘ,Yₙ)是X与Y的LCS。则有：
(1) 若xₘ=yₙ，则Zₘ₋₁,ₙ₋₁是Xₘ₋₁与Yₙ₋₁的LCS，则LCS(Xₘ,Yₙ)=LCS(Xₘ₋₁,Yₙ₋₁)+xₘ=yₙ。
(2) 若xₘ≠yₙ，则Zₘ₋₁,ₙ是Xₘ₋₁与Yₙ的LCS，则LCS(Xₘ,Yₙ)=LCS(Xₘ₋₁,Yₙ)。
(3) 若xₘ≠yₙ，则Zₘ,ₙ₋₁是Xₘ与Yₙ₋₁的LCS，则LCS(Xₘ,Yₙ)=LCS(Xₘ,Yₙ₋₁)。

# 证明

(1). X=x₁,...,xₘ₋₁,xₘ, Y=y₁,...,yₙ₋₁,yₙ，则LCS(Xₘ,Yₙ)=LCS(Xₘ₋₁,Yₙ₋₁)+<xₘ=yₙ>。
设Zₘ₋₁,ₙ₋₁是Xₘ₋₁与Yₙ₋₁的LCS，则|Zₘ₋₁,ₙ₋₁|是X与Y的最长公共子序列长度。
若Z是X与Y的LCS，则存在一个下标k使Xₖ=Yₖ。
设Zₖ是Xₘ₋₁与Yₙ₋₁的LCS，则|Zₖ|=|Zₘ₋₁,ₙ₋₁|。
则由 |Zₖ| < |LCS(Xₘ,Yₙ)|，
|Zₖ|=|Zₘ₋₁,ₙ₋₁|+|xₘ=yₙ| < |LCS(Xₘ,Yₙ)|+|xₘ=yₙ|，
故LCS(Xₘ,Yₙ)最优。
