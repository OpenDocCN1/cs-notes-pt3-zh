# Master定理的证明(续)

定义： n_i = { n if i=0; ⌈n_i-1 / b⌉ if i>0 }

引理4. n0 ≤ n, n_i ≤ n/b +1, n_i ≤ n/b^i + 1/b +1, n_i ≤ n/b^i + 1/b^i + 1/b +1 ... n_i ≤ n/b^i + Σ_{j=0}^{i-1} 1/b^j ≤ n/b^i + b/(b-1).

证：由⌈x⌉ ≤ x+1可证。

# Master定理的证明(续)

引理5：当 i = ⌈log_b n⌉ 时， n_i ≤ b + b/(b-1) = O(1)

证：由于 n_i ≤ n/b^i + b/(b-1)，我们有 n_{log_b n +1} ≤ n / b^{log_b n +1} + b/(b-1) ≤ n / b^{log_b n +1} + b/(b-1) = b + b/(b-1) = O(1)

# Master定理的证明(续)

引理6： T(n) = aT(n/b) + f(n) ≤ θ(n^{log_b a}) + Σ_{j=0}^{log_b n -1} a^j f(n / b^j)

证： T(n) = f(n_0) + aT(n_1) = f(n_0) + a f(n_1) + a^2 f(n_2) ≤ f(n_0) + a f(n_1) + a^2 f(n_2) + ... + a^{log_b n -1} f(n_{log_b n -1}) + a^{log_b n} T(n_{log_b n}) = θ(n^{log_b a}) + Σ_{j=0}^{log_b n -1} a^j f(n_j)

# Master定理的证明(续)

引理7： g(n) = Σ_{j=0}^{log_b n -1} a^j f(n_j) 如果假设如下： (1) If f(n) = O(n^{log_b a - ε}) for ε > 0, g(n) = O(n^{log_b a}). (2) If f(n) = θ(n^{log_b a}), then g(n) = θ(n^{log_b a} lg n). (3) If a f(⌈n/b⌉) ≤ c f(n) for 0<c<1 and all 充分大的 n, then g(n) = θ(f(n)).
