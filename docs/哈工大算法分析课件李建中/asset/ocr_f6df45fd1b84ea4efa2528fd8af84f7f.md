# 聚集方法动图

假设有n个独立/不相关操作，成本如下：
操作1：Cost=t₁
操作2：Cost=t₂
...
操作n：Cost=tₙ

T(n)=∑ᵢ tᵢ
平均成本：T(n)/n

每个操作被放在不同
内存，不存在依赖

# 聚集方法实例之一：栈操作序列

+   - 普通栈操作时间性能
+     - Push(S, x)：将元素x压入栈S
+     - Pop(S)：若非空则从S中弹出元素
+     - 每个操作都是常数时间O(1)
+     - 可执行n个操作栈操作序列总成本是O(n)
+     - n个Push和Pop操作序列总成本是O(n)
+     - n个操作按顺序进行时间总成本O(n)

# 新栈通过栈操作互换时间性能

- 新操作 Multipop(S, k)：
  从栈S中弹出k个元素。k≤|S|则操作是合法的
- 案例算法
  Multipop(S, k)
  1 While not STACK-EMPTY(S) and k>0 Do
  2   Pop(S);
  3   k←k-1.
- Multipop(S, k)操作复杂性(假设Pop操作看1)
  - Multipop操作成本min{|S|, k}

# 聚集方法实例之二：二进制计数器

- 问题定义，由n个计数值构成二进制计数器
  输入：n二进制计数器，初始值为0
  输出：x=i mod 2^k
  案例说明：
  A[0..k-1]存储计数器，若值为x
  x的值保存在A[0]中，最高位在A[k-1]中
  x = Σ_{i=0}^{k-1} A[i]·2^i
