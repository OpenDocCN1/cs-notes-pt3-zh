# 集合覆盖问题LP-随机舍入算法

+   LP-随机舍入算法
+   1. 通过求解松弛的LP-松弛问题得到解x*，s.t. Σ_{S∋e} x_S ≥ 1
+   2. C=∅
+   3. For ∀S∈S Do
+      生成随机数rand
+      IF rand > 1-x_S THEN C=C∪{S};
+      /* S以概率x_S被选中 */
+   4. 输出C

# Primal-dual schema

+   集合覆盖的Primal-dual Schema算法
+   1. x_i=0; /* 对每个集合S有一个变量x_S */
+   2. y_e=0; /* 对每个元素e有一个变量y_e */
+   3. F=∅; /* 被覆盖的集合集合 */
+   4. while F≠U Do
+   5.  e∈U\F;
+   6.  增大y_e，直到 Σ_{S∋e} c(S)x_S = c(S) 存在某个S∈S满足；
+   7.  将第6步中满足 Σ_{S∋e} c(S)x_S = c(S) 的集合S∈S，x_S=1, F=F∪S;
+   8. 输出x_S=1的集合中对应的集合；

引理2. 在上述算法中，while循环结束后，x_S与y_e满足可行性和对偶可行性。

引理3. 从上述算法中，while循环结束未被x_S与y_e满足如下两个条件：(1) 对∀S∈S，x_S>0 ⇒ Σ_{e∈S} y_e = c(S); (2) 对∀e∈U，y_e>0 ⇒ Σ_{S∋e} c(S)x_S ≤ c(S) (U未被覆盖最大频率)
