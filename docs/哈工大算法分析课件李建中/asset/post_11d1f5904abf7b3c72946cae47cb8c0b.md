
## 7.2 Basic Tree Searching Strategies

- Breadth-First Search
- Depth-First Search

## Breadth-First Search

- 算法
  1. 构造一个队列或队列Q;
  2. If Q中有一个节点x且目标节点. Then 停止;
  3. 从Q中取出x, 把x的所有子节点置入Q的末尾;
  4. If Q空 Then 失败 Else goto 2.

## Depth-First Search

- 算法
  1. 构造一个由栈构成的表或栈S;
  2. If Top(S)是目标节点. Then 停止;
  3. Pop(S), 把Top(S)所有子节点置入栈顶;
  4. If S空 Then 失败 Else goto 2.

## 7.3 Optimal Tree Searching Strategies

- Hill Climbing
- Best-First Search Strategy
- Branch-and-Bound Strategy

## Hill Climbing

- 基本思想
  - 从原点出发或随机出发，我们将遇到多个等价于可达的相邻状态，哪个状态是最好的？
  - 从山峰攀登者出发的方向决定移动的方向，是使优化函数值或代价函数值
  - 从山峰攀登者出发或随机出发是梯度上升的搜索

## Hill Climbing策略

1. 构造由根节点组成的单元素栈S;
2. If Top(S)是目标节点 Then 停止;
3. Pop(S);
4. S的各子节点按启发函数值由大到小顺序装入S;
5. If S空 Then 失败 Else goto 2.

## Best-First Search Strategy

- 基本思想
- 结合深度优先和广度优先的优点
- 根据一个待扩展节点, 并且产生它的所有子节点并将其具有最小估价函数值的节点进行扩展。
- 具有启发性信息, 而且是类似具有局部优化概念。

## Best-First Search 算法

- Best-First Search 算法
  1. 使用估价函数构造一个堆 H, 构成由根节点构成的优先队列;
  2. If H为空且目标节点 Then 停止;
  3. 从 H中删除, 把它的子节点插入 H;
  4. If H空 Then 失败 Else goto 2.

## Branch-and-Bound Strategy

- 基本思想
  - 上述方法都用于求解优化问题
  - 若求解结果可能有效地截止搜索优化问题
  - 就能使优化解一个界限
  - 缩小搜索空间, 提高搜索效率
- 举例说明分支限界搜索原理

## 7.4 Personnel Assignment Problem

- 问题的定义
- 指派的特殊问题
- 解决问题的主要界限搜索算法

## 问题的定义

输入：
一组对象 P={P₁, P₂, …, Pₙ}，以及集合 J={J₁, J₂, …, Jₙ}。

> 例：给定 P={P₁, P₂, P₃}，J={J₁, J₂, J₃}，J₁≤J₂≤J₃。P₁→J₁，P₂→J₂，P₃→J₃；P₁→J₁，P₂→J₃，P₃→J₂ 等不同指派。

目标：求解 P 的最优指派，使总成本最小。

## 指派问题的搜索空间

设有 n 个对象和 n 个任务，指派问题可以表示为排列组合。
例如：给定若干对象及任务，搜索空间由所有可能的指派组成。

![](img/9e822ee25d7fb44c33253ed3ff372fc1_81_1.png)

搜索树节点序列示例：S₁, S₂, S₃, S₄, S₅, S₆, S₇, S₈, S₉。

## 问题的解空间

令 P₁→J₁，P₂→J₂，…，Pₙ→Jₙ 是一个可能的指派。所有可能的指派构成一个解空间。

> 问题的解空间是所有可能指派的集合，每个序列对应于一个可能的解。
