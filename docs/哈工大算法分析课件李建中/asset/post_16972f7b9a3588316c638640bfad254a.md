
## 算法实例

| yj | B | D | C | A | B | A | B |
|---|---|---|---|---|---|---|---|
| x_i | 0 | 0 | 0 | 0 | 0 | 0 | 0 |
| A | 0 | ↑0 | ↑0 | ↑0 | ←1 | ←1 | ↑1 |
| B | 0 | ↑1 | ←1 | ←1 | ↑1 | ↑2 | ←2 |
| C | 0 | ↑1 | ←1 | ←2 | ←2 | ↑2 | ↑2 |
| B | 0 | ↑1 | ↑1 | ↑2 | ↑2 | ←3 | ←3 |
| D | 0 | ↑1 | ↑2 | ↑2 | ↑2 | ↑3 | ↑3 |
| A | 0 | ↑1 | ↑2 | ↑2 | ←3 | ↑3 | ←4 |
| B | 0 | ↑1 | ↑2 | ↑2 | ↑3 | ←4 | ↑4 |

- C[i,j]=0, i=0 或 j=0
- C[i,j]=C[i-1,j-1]+1, x_i=y_j
- C[i,j]=Max(C[i-1,j],C[i,j-1]), x_i≠y_j

```
LCS-length(X, Y)
 m←length(X); n←length(Y);
 For i←1 To m Do C[i,0]←0;
 For j←1 To n Do C[0,j]←0;
 For i←1 To m Do
   For j←1 To n Do
     If x_i=y_j,
       Then C[i,j]←C[i-1,j-1]+1; B[i,j]←"↖";
     Else If C[i-1,j]≥C[i,j-1]
       Then C[i,j]←C[i-1,j]; B[i,j]←"↑";
       Else C[i,j]←C[i,j-1]; B[i,j]←"←";
 Return C and B.
```

## 构造化解

- 基本思想
  - 从B[m,n]出发循着指针找到
  - 若B[i,j]="↖", 则x_i=y_j, LCS有一个后缀
  - 如此递归地"LCS"等于X的LCS的Inverse

```
Print-LCS(B, X, i, j)
 IF i=0 or j=0 THEN Return;
 IF B[i,j]="↖"
   THEN Print-LCS(B, X, i-1,j-1); Print x_j;
   ELSE IF B[i,j]="↑"
     THEN Print-LCS(B, X, i-1,j);
     ELSE Print-LCS(B, X, i,j-1).

Print-LCS(B, X, length(X), length(Y))
可打印出X与Y的LCS。
```

  - 最长公共子序列总时间: O(mn)

  - 需要存储矩阵C和B
  - 需要空间 O(mn)

## 5.5 0/1 Knapsack Problem

## 问题定义

你发现n种物品有一个背包，物品i的重量是w_i，价值v_i，背包重量为C，向内所能装入背包的物品，装入背包中的物品的总价值最大？
对于每种物品只能选择完全装入或不装入。
一个物品至多装入一次。

- 输入：C>0, w_i>0, v_i>0, 1≤i≤n
- 输出：(x_1, x_2, ..., x_n), x_i∈{0,1}, 确定 Σ_{i=1..n} w_i x_i ≤ C, Σ_{i=1..n} v_i x_i 最大

零件背包规划问题
max Σ_{i=1..n} v_i x_i
Σ_{i=1..n} w_i x_i ≤ C
x_i∈{0,1}, 1≤i≤n

## 优化解结构分析

定理(优化子结构) 假设(y_1, y_2, ..., y_n)是0-1背包问题的优化解，则(y_2, ..., y_n)是以下子问题的优化解：
max Σ_{i=2..n} v_i x_i
Σ_{i=2..n} w_i x_i ≤ C - w_1 y_1
x_i∈{0,1}, 2≤i≤n

证明：假设(y_2, ..., y_n)不是子问题的优化解，则存在(z_2, ..., z_n)是子问题的优化解。对于(y_1, z_2, ..., z_n)是原问题的优化解，矛盾。

## 递归优化解的递推方程

- 定义m(i,j)：
  背包容量为j，可选物品为x_1, x_2, ..., x_n，问题最优解的价值记为m(i,j)。
- 形式化
  问题
  max Σ_{k≤n} v_k x_k
  Σ_{k≤n} w_k x_k ≤ j
  x_k∈{0,1}, 1≤k≤n
  称最优解价值为m(i,j)。

## 递推方程

m(i, j) = m(i+1, j) 0≤j < w_i
m(i, j) = max{m(i+1, j), m(i+1, j-w_i)+v_j} j ≥ w_i
m(n, j) = 0 0 ≤ j < w_n
m(n, j) = v_n j ≥ w_n

## 自底向上计算顺序

m(i, j) = m(i+1, j), 0≤j < w_i
m(i, j) = max{m(i+1, j), m(i+1, j-w_i)+v_j}, j ≥ w_i
m(n, j) = 0, 0 ≤ j < w_n
m(n, j) = v_n, j ≥ w_n

令 w_i 整集, n=4

## 算法

For j=0 To min(w_n-1, C) Do
m[n, j] = 0;
For j=w_n To C Do
m[n, j] = v_n;
For i=n-1 To 2 Do
For j=0 To min(w_i-1, C) Do
m[i, j] = m[i+1, j];
For j=w_i To C Do
m[i, j]=max{m[i+1, j], m[i+1, j-w_i]+v_j};
If C < w_i Then m[i, C]=max[m[2, C], m[2, C-w_i]+v_j]; Else m[i, C]=max[m[2, C], m[2, C-w_i]+v_j];

## 构造优化解

- 1. m(1, C) 是优化解的值, 构造解计算如下:
  If m(1, C) = m(2, C)
  Then x_1 = 0;
  Else x_1 = 1;
- 2. 如果 x_i=0, 由 m(2, C) 构造递进解;
- 3. 如果 x_i=1, 由 m(2, C-w_i) 构造递进解.

## 算法复杂性

- 时间复杂性
  - 朴素优化解编码 O(Cn)
  - 构造解比较编码 O(Cn)
  - 最终问题最优解 O(n)
- 空间复杂性
  - 使用矩阵 m
  - 需要空间 O(Cn)
