## 7.6 The A* Algorithm

- A*算法的基本思想
- A*算法的规则

### A*算法的基本思想

- A*算法是启发式搜索的改进
- 启发式搜索是基于下界来估计最短路径从而优化搜索方式
- 启发式搜索的另一个概念是“极限”
- A*算法通过启发式函数和启发式搜索, 我们得到新的搜索一定是更优地, 才能停止
- A*算法改进而非地搜索, 启发式可以停止
- A*算法搜索者使用Best-first搜索算法进行优化

### A*算法是基于启发式

- 启发值等于h(n)
  - g(n)=从起点到n的实际代价
  - h*(n)=从n到目标的实际最短路径代价
  - f*(n)=g(n)+h*(n)是n最优代价
  - What is the value of h*(n)?
    - 未知
    - 估计, f(n)也未知
- 启发值h(n)
  - 很好分析法估计h*(n), 用h(n)来估计h*(n)的估计
  - h(n)<=h*(n)易满足
  - f(n)=g(n)+h(n)<=g(n)+h*(n)=f*(n)更易满足n代价

## A*算法寻找到一个最优解的优化解

定义1. 使用Best-first搜索策略, 而且A*算法的非最优解树为空树时, 则该算法是完备且最优解的。

证明

- 1. A*算法使用Best-first搜索, f(n)=g(n)+h(n)。
- 2. A*算法使用h(n)≤h*(n)估价函数, f(0)≤f(n)≤f*(n)。
- 3. f(n*)中有一个最优解节点, 令其为f(s)。
- 4. 若有f(s)≤f(s')。
- 5. f(s)=g(s)是一个可行解, g(0)≤f(s), f(s)=g(s)=f*(s)。

### A*算法的规则

- 1. 使用Best-first搜索策略；
- 2. 节点n的估价函数为f(n)=g(n)+h(n), g(n)是从初始节点到n的实际代价, h(n)是从n到目标节点的启发式估价函数；
- 3. 对于所有n, h(n)≤h*(n)；
- 4. 当找到目标节点且是最小节点时, 算法停止, 返回一个优化解。

### 随机算法的基本概念

#### 什么是随机算法

随机算法是一种用概率统计计算方法在算法执行过程中对于下一个步骤做出随机选择的算法

### 随机算法的优越性

- 对于有解问题：算法简单
- 对于有解问题：时间复杂度低
- 对于有解问题：时间和空间具有单调性和时间复杂性低

### 随机算法的随机性

- 对于同一实例的多次执行,效果可能完全不同
- 时间复杂度是一个随机变量
- 解的正确性和准确性也是随机的

### 随机算法的分类

#### 随机数值算法

- 主要用于数值问题求解
- 算法的输出往往是近似解
- 近似解的精确度与算法执行时间成正比

#### Monte Carlo算法

- 主要用于求解需要准确解的问题
- 算法可能给出错误解
- 获得精确解概率与算法执行时间成正比

#### Las Vegas算法

- 一旦找到一个解，该解一定是正确的
- 找到解的概率与算法执行时间成正比
- 增加对问题的反复求解次数，可以是求解无效的概率任意小

#### Sherwood算法

- 一定能够获得一个正确解
- 确定算法的最好和平均复杂度差别大时，加入随机性，即得到Sherwood算法
- 消除算法行为与特殊实例的联系

### 随机算法的性能分析

- 仅依赖于随机选择，不依赖于输入的分布
- 确定算法的平均复杂度分析：
  依赖于输入的分布
- 对于每一个输入都要考虑算法的概率性性能

### 随机算法的目标

- 平均的运行时间：时间复杂性变量的均值
- 取得正确解的概率
- 取得优化解的概率
- 解的精确度估计

### 8.2 Randomized Numerical Algorithms

- 计算数值

#### 计算值

##### 一数学基础

一设有1个半径为a的圆及其外切四边形

- 向正方形随机地投掷n个点，设k个点落在圆内
- 按照点落在圆内的概率为 (πr²)/(4a²)=π/4
- 用k/n近似π/4,即k/n≈π/4,于是π≈4k/n.
- 我们可以用蒙特卡罗方法计算π

##### 一算法

```
K=0;
For i=1 To n
  随机地产生正方形中的一点(x, y);
  If x²+y²≤1 Then k=k+1;
Endfor
Return (4k/n)
```

- 时间复杂度=O(n)
  - 不是随输入的大小,而是随随机样本的大小
- 解的精确度
  - 随着随机样本大小增加而增加
