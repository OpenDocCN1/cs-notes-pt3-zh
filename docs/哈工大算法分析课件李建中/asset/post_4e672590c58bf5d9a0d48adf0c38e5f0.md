
## 矩阵连乘计算量最小的问题 Dynamic Programming 算法

- 动态规划算法特征
- 递归地定义最优解的代价
- 递归地组成各子问题，直接不可解
- 自底向上解决各个子问题
- 计算最优解时保存其结构
- 根据构造最优解信息构造最优解

## 矩阵优化链的性质

- 两个例子
  - A_i = A_i x A_{i+1} x ... x A_j
  - cost(A_i...A_j)为其代价
- 优化链的性质
  假设 计算A_1...A_n的优化链并拆开链，则
  具有性质
  问题的优化链可向左优化
  即，问题子问题A_{k+1...m}的优化链是A_{k+1...m}的优化解。

## 递归地定义最优解的代价

- 假设
  - m[i, j] = 计算A_i...A_j最小代价
  - m[i, i] = 计算A_i最小代价
  - A_i ... A_{i+k-1} ... A_j (k>=1) 最优解可拆成
- 递归解(A_1...A_k)(A_{k+1}...A_j)代价方程
  m[i, j] = 计算A_i...A_j最小代价 i<j
  m[i, j] = min_{k} { m[i, k] + m[k+1, j] + p_{i-1}p_kp_j }
  其中 p_i p_{i+1}分别对应A_i x A_{i+1}所需数据。
  A_i = p_{i-1} x p_i, A_j = p_{j-1} x p_j 构成。
  A_i p_{i-1} p_i 构成。

考虑矩阵所有k，优化解的代价方程为
m[i, j] = 0 if i=j
m[i, j] = min_{k, i<=k<j} { m[i, k] + m[k+1, j] + p_{i-1}p_kp_j } if i<j

## 递归地对各子问题

## 自底向上计算优化解代码介绍

m[i,j]=min_{i≤k<j}{ m[i,k] + m[k+1,j] + p_i p_k p_j }

```
Matrix-Chain-Order(n)
FOR i=1 TO n DO
  m[i,i]=0;
FOR l=2 TO n DO
  FOR i=1 TO n-l+1 DO
    j=i+l-1;
    m[i,j]=∞;
    FOR k=i TO j-1 DO
      q=m[i,k]+m[k+1,j]+p_i p_k p_j
      IF q<m[i,j] THEN m[i,j]=q;
Return m.
```

## 向最短失配

- 字符序列

- 公共子序列
  - Z是X与Y的公共子序列 iff Z是X的子序列且是Y的子序列。

## 最长公共子序列（LCS）问题

输入： X = (x₁,x₂,...,xₙ), Y = (y₁,y₂,...,yₘ)
输出： X与Y的最长公共子序列 Z=(z₁,z₂,...,zₚ)

## 最长公共子序列结构分析

- 序列前缀
  - 设X=(x₁,x₂,...,xₙ)是一个序列
  - 则Xᵢ=(x₁,...,xᵢ)是X的前缀
  例： X=(A,B,D,C,A), X₃=(A), X₅=(A,B), X₇=(A,B,D)

## 优化子结构

X与Y的LCS的优化子结构
LCSᵢⱼ = LCSᵢ₋₁,ⱼ₋₁ + 1 若 xᵢ = yⱼ
LCSᵢⱼ = LCSᵢ₋₁,ⱼ 若 xᵢ ≠ yⱼ 且 xᵢ > yⱼ
LCSᵢⱼ = LCSᵢ,ⱼ₋₁ 若 xᵢ ≠ yⱼ 且 xᵢ < yⱼ

## 优化子结构

定理1（优化子结构）设X=(x₁,...,xₘ), Y=(y₁,...,yₙ)
是两个序列，LCS(Xₘ,Yₙ)是X与Y的LCS。则有：
(1) 若xₘ=yₙ，则Zₘ₋₁,ₙ₋₁是Xₘ₋₁与Yₙ₋₁的LCS，则LCS(Xₘ,Yₙ)=LCS(Xₘ₋₁,Yₙ₋₁)+xₘ=yₙ。
(2) 若xₘ≠yₙ，则Zₘ₋₁,ₙ是Xₘ₋₁与Yₙ的LCS，则LCS(Xₘ,Yₙ)=LCS(Xₘ₋₁,Yₙ)。
(3) 若xₘ≠yₙ，则Zₘ,ₙ₋₁是Xₘ与Yₙ₋₁的LCS，则LCS(Xₘ,Yₙ)=LCS(Xₘ,Yₙ₋₁)。

## 证明

(1). X=x₁,...,xₘ₋₁,xₘ, Y=y₁,...,yₙ₋₁,yₙ，则LCS(Xₘ,Yₙ)=LCS(Xₘ₋₁,Yₙ₋₁)+<xₘ=yₙ>。
设Zₘ₋₁,ₙ₋₁是Xₘ₋₁与Yₙ₋₁的LCS，则|Zₘ₋₁,ₙ₋₁|是X与Y的最长公共子序列长度。
若Z是X与Y的LCS，则存在一个下标k使Xₖ=Yₖ。
设Zₖ是Xₘ₋₁与Yₙ₋₁的LCS，则|Zₖ|=|Zₘ₋₁,ₙ₋₁|。
则由 |Zₖ| < |LCS(Xₘ,Yₙ)|，
|Zₖ|=|Zₘ₋₁,ₙ₋₁|+|xₘ=yₙ| < |LCS(Xₘ,Yₙ)|+|xₘ=yₙ|，
故LCS(Xₘ,Yₙ)最优。

## zhang

(2) X=x₁...xₘ, xₘ₊₁, Y=y₁...yₙ, yₙ₊₁, xₘ₊₁≠yₙ₊₁ 则 LCSₓᵧ = LCSₓₘᵧₙ
由子序列 Zₘ, Z = LCSₓᵧ 则 Z 与 Y 均是子序列。
或序列 Zₘ₊₁, Z 与 Y 均是 LCSₓₘ₊₁Y, Z 与 Y 均有一个公共子序列 W, W 也是 X 与 Y 的公共子序列, 则 W 也是 X 与 Y 的最长公共子序列, 所以 Z 与 LCS 考虑

## 递推 LCS 长度的递推方程

- C[i,j] 为 X₁..i 与 Y₁..j 的 LCS 长度
- LCS 长度的递推方程
  C[i,j]=0 if i=0 或 j=0
  C[i,j]=C[i-1,j-1]+1 if i,j>0 and xᵢ=yⱼ
  C[i,j]=Max(C[i,j-1], C[i-1,j]) if i,j>0 and xᵢ≠yⱼ

## 递推到与自底向上求解

- 基本思路
  C[i,j]=0 if i=0 或 j=0
  C[i,j]=C[i-1,j-1]+1 if i,j>0 and xᵢ=yⱼ
  C[i,j]=Max(C[i,j-1], C[i-1,j]) if i,j>0 and xᵢ≠yⱼ
