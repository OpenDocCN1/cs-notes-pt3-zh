## 8.3 Randomized Selection Algorithms

- 问题的定义
- 随机算法
- 算法的性能分析

### 问题的定义

• 输入: S={x_1, x_2, ..., x_n},
整数k, 1≤k≤n
• 输出: S中第k最小元素
记号
Rank(Q, x) = 集合Q中元素的rank
min(Q, k) = 集合Q中第k最小元素

### 随机算法

基本思想
• 从S中随机地抽取n个样本存入R, 排序R
• S中第k最小元素可能成为R中x≈k/n最小元素
• 为了解决误差问题, 我们有置信区间 [x≈k/n, x≈k/n+1/2]
r1 ...... rL rL+1 ...... rH ...... rn
• 把S置于以 [H] 散装并入P
• 在P中寻找min(S, k)

+   LAZYSELECT(S, k)
+   1. R=独立, 均匀, 可放回地从S随机选取n^{3/4}元素;
+   2. 在O(n log n)时间内排序R;
+   3. x=k/n^{1/4}, H={y∈S | y≤x}, L={y∈S | y≥x};
+   4. l=max{1, √n - 0}, h=min{ n, [x+√n] n^{3/4} };
+   5. L_p=min(R, h), H_p=min(R, h), 且|R|≤5元素比较*;
+   6. L_p=Rank(S,L), H_p=Rank(S,H); 且|R|≤5元素比较*;
+   7. P={y∈S | L≤y≤H};
+   8. If min(S, k)∈P and |P|≤4n^{3/4}+1
+      Then max(S,k) 可由 P 归纳确定 *;
+   9. Then 推进 y=min(S, k)=min(P, (k-L_p)), 算法结束;
+   10. ELSE goto 1.

### 算法的性能分析

### 数学基础

- 数学期望
  - 离散随机变量 X 的数学期望 E[X] = Σx·P(X=i)
  - 若函数 f(x) 在集合 S 上实现取值函数，则 E[f(X)] = Σf(i)·P(X=i)
- Markov 不等式
  - P{Y ≥ t} ≤ E[Y]/t, 其中 Y 为非负随机变量, t > 0

### 方差的性质与 Chebyshev 不等式

- 方差 σ² = E[(X-μ)²], μ 为随机变量的数学期望
- σ 为标准差
- Chebyshev 不等式: P{|X-μ| ≥ rσ} ≤ 1/r²
- 随机变量 X 满足 P{X=1}=p, P{X=0}=1-p, 则 σ² = p(1-p)
- 若 X₁, X₂, ..., Xₙ 相互独立, Xᵢ 服从独立同分布
- 若随机变量满足 P{X=1}=p, P{X=0}=1-p, 则 σₙ² = np(1-p)

### 算法的性能分析

定理: 算法执行 1~9 步一次通过可求出 min{S,k} 的概率是 1-O(n⁻⁴), 即算法执行 2n log n 次比较后可求出 min{S,k} 的概率是 1-O(n⁻⁴)

证明: 若算法执行 1~9 次通过可求出 min{S,k}, 则算法执行 2n 次比较, 其他步 O(n log n) 比较, 总计 2n+O(n log n) 比较。
算法执行 1~9 次通过可求出 min{S,k}, 条件的概率是 1-O(n⁻⁴)。
(1). min{S,k} ≥ k 且 P(Xᵢ ≥ k) 之间包围 min{S,k}, k), (2). P{dn < 4}, 我们先来计算上面这两个条件失败的概率。

条件 I 不成立当且仅当 L ≤ min{S,k} 或 H > min{S,k}, k1. 令 k₁ 为随机变量 X 的最小值 S, k₁, 否则为 0. X = min{S,k} 是期望为 k 的随机变量, 我们有 E[X] = k/n, Var(X) = k/n(1-k/n) ≤ 1/4, ...

如果 L < min{S,k}, Xₖ 如果 < min{S,k}, Xₖ ≥ 于是 P{L < min{S,k}} = P{Xₖ < min{S,k}} = P{Xₖ < k} = ... 应用 Chebyshev 不等式, 2n/σₙ², 我们有 P{|Xₙ - μₙ| ≥ ...} = O(n⁻⁴) 于是 P{L > min{S,k}} = P{H > min{S,k}} = O(n⁻⁴)

## 8.4 Randomized Algorithm to Test Whether Number is Prime

- 问题的定义
- 随机算法设计
- 算法的性能分析

### 问题的定义

- **输入**
  - 一个正整数 $N$
- **输出**
  - $N$ 是否素数

### 随机算法的设计

- **基本思想**
  - 对 $N$ 进行 $m$ 次测试
  - 如果有一次测试成功，则回答 $N$ 是合数
  - 如果 $m$ 次测试均失败，则回答 $N$ 是素数
  - 回答 $N$ 是合数时，答案百分之百正确
  - 回答 $N$ 是素数时，答案正确的概率为 $1-2^{-m}$

- **随机算法**
  1. 随机地选择 $m$ 个数 $(b_1,b_2,\ldots,b_m)$，满足 $1\le b_i\le N$
  2. For $i=1$ To $m$
  3. 　 If $W(b_i)$成立　Then　Return（$N$是合数）
  4. Return（$N$是素数）
  
  $W(b_i)$定义如下：
  1. $b_i^{N-1}\not\equiv 1\pmod N$，或
  2. $\gcd(N-1)/2^k$ 是整数，$1<k$ 且 $\gcd$ 为最大的公因子 $<N$

例1．给定 $N=12$，选择测试数集 $\{2,3,7\}$。

测试 2：$2^{2^2-1}=2048\not\equiv 1\pmod{12}$，$W(2)$成立。
$N$是合数。

例2．给定 $N=11$，选择测试数集 $\{2,5,7\}$。
测试 2：$2^{10}=1024\equiv 1\pmod{11}$；
测试 5：$5^{10}=9765625\equiv 1\pmod{11}$；
测试 7：$7^{10}=282475249\equiv 1\pmod{11}$；
结论：11可能是素数。
答案正确的概率为 $1-2^{-3}$。

### 算法性能的分析

定理1．(1) 如果对于任意整数 $b<N$，$W(b)$成立，则 $N$ 是合数。
(2) 如果 $N$ 是合数，则至少有 $(N-1)/2$ 个 $b$ 使 $W(b)$ 成立。

(1) 说明算法是正确的。
(2) 说明，如果 $N$ 是合数，则至少一半 $b<N$ 使 $W(b)$ 成立。

定理2．算法的回答“$N$ 是素数”正确的概率是 $1-2^{-m}$。

## 8.5 Randomized Sorting Algorithm

- 问题的定义
- 随机算法
- 算法性能的分析

### 问题的定义

输入
→ {x₁, x₂, ..., xₙ}
输出
→ 排序的S

### 随机算法

基本思想

- 采用随机抽样的方法确定集合的划分点
- 把集合划分成两个子集合
- 分别递归地在每个子集合上使用随机排序算法

### 算法

+   1. 均匀随机地在S中随机抽取一个样本y;
+   2. 比较S中各元素, 把S划分为如下两个集合: S_L = {x∈S, x≤y}, S_R = {x∈S, x≥y};
+   3. 递归地排序S_L和S_R;
+   4. 顺序地输出排序的S_L, y, S_R;

### 算法性能的分析

基本概念

- S_i表示S中第i小的元素
- S_1和S_n分别是最小和最大元素
- 随机变量X_ij定义如下: X_ij=1如果S_i和S_j在运行中被比较,否则为0
- X_p是S_i和S_j的比较次数
- 算法的比较次数为 Σ_{1≤i<j≤n} X_ij
- 算法的平均复杂性为 E[ Σ_{1≤i<j≤n} X_ij ] = Σ_{1≤i<j≤n} E[X_ij]

### 计算E[X_ij]

p_ij为S_i和S_j在运行中比较的概率,则 E[X_ij]=p_ij×1+(1-p_ij)×0=p_ij

关键问题为求p_ij
