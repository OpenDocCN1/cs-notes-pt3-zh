
## Substitution方法II：上界下系

例 3. 求解 T(n) = 2T(n/2) + n.
解：首先证明 T(n) = Ω(n), T(n) = O(n²)
然后逐步地降低上界、提高下界。
Ω(n) 的上一个阶是 Ω(n log n),
O(n) 的下一个阶是 O(n log n)。

## Substitution方法III：变量替换

按变量替换把递推方程变换为熟悉的方程。
例 6. 求解 T(n) = 2T(√n) + lg n
解：令 m = lg n，则 n = 2^m, T(2^m) = 2T(2^{m/2}) + m.
令 S(m) = T(2^m) 则 T(2^{m/2}) = S(m/2)，于是，S(m) = 2S(m/2) + m
显然，S(m) = O(m lg m)，即 T(2^m) = Θ(m lg m)。
由于 2^m = n, m = lg n, T(n) = Θ(lg n × lg lg n)。

## 2.4.2 Iteration方法

方法：
简洁地展开递推方程，
把它转化为和式，
然后可使用和式技术解之。

例 1. T(n) = n + 3T([n/4]), T(1)=1
= n + 3[ n/4 + 3T([n/4^2]) ]
= n + 3[ n/4 + 3[ n/16 + 3T([n/4^3]) ] ]
= n + 3[ n/4 ] + 9[ n/16 ] + 27T([n/4^3])
= n + 3[ n/4 ] + 3^2[ n/4^2 ] + 3^3[ n/4^3 ] + ... + 3^i T([n/4^i])
[ n/4^i → 4^i → n => i = log_4 n ]
= n + 3[ n/4 ] + 3^2[ n/4^2 ] + 3^3[ n/4^3 ] + ... + 3^{log_4 n -1} T(1)
≤ Σ_{i=0}^{log_4 n} 3^i n/4^i ≤ n Σ_{i=0}^{∞} (3/4)^i = n × 1/(1 - 3/4) = 4n = O(n)

## 2.4.3 Master method

目的：求解 T(n) = aT(n/b) + f(n) 型方程，a ≥ 1, b > 0 是常数
f(n) 是正函数
方法：记住三种情况，则不用笔纸即可求解上述方程

## Master 定理

定理 2.4.1 设 a ≥ 1, b > 1 是常数，f(n) 是一个函数，T(n) 是定义在非负整数集上的递归式 T(n) = aT(n/b) + f(n)，T(n) 可以如下求解：
(1). 若 f(n) = O(n^{log_b a - ε}), ε > 0 是常数，则 T(n) = Θ(n^{log_b a})。
(2). 若 f(n) = Θ(n^{log_b a})，则 T(n) = Θ(n^{log_b a} lg n)。
(3). 若 f(n) = Ω(n^{log_b a + ε}), ε > 0 是常数，并且对于所有充分大的 n
a f(n/b) ≤ c f(n), c < 1 是常数，则 T(n) = Θ(f(n))。

## 直观地：我们用 f(n) 与 n^{log_b a} 比较

(1). 若 f(n) 大，则 T(n) = Θ(f(n)) (2). 若 f(n) 大，则 T(n) = Θ(f(n)) (3). 若 f(n) 与 n^{log_b a} 同阶，则 T(n) = Θ(n^{log_b a} lg n) = Θ(f(n) lg n)

## 更进一步：

(1). 在第一种情况，f(n) 不仅小于 n^{log_b a}，必须多项式地小于。更对一个常数 ε>0，f(n)=O(n^{log_b a - ε})。 (2). 在第三种情况，f(n) 不仅大于 n^{log_b a}，必须多项式地大于。更对一个常数 ε>0，f(n)=Ω(n^{log_b a + ε})。

## Master 定理使用

## 例 1. 求解 T(n) = 9T(n/3) + n.

解：a=9, b=3, f(n)=n, n^{log_b a}=Θ(n^2) ∵ f(n)=n=O(n^{log_b a - ε}), ε=1 ∴ T(n)=Θ(n^{log_b a})=Θ(n^2)

## 例 2. 求解 T(n)=T(2n/3)+1.

解：a=1, b=(3/2), f(n)=1, n^{log_b a}=n^{log_{3/2}1}=n^0=1, f(n)=1=Θ(1)=Θ(n^{log_b a}), T(n)=Θ(n^{log_b a} lg n)=Θ(lg n)

## 例 3. 求解 T(n)=3T(n/4)+n lg n

解：a=3, b=4, f(n)=n lg n, n^{log_b a}=n^{log_4 3}=O(n^{0.79}) (1) f(n)=n lg n ≥ n^{n^{0.79}}, ε=0.2 (2) 对所有 n, a f(n/b)=3×(n/4) lg(n/4)=3/4 n lg n - 3/4 n lg 4 ≤ c f(n), c=3/4 于是，T(n)=Θ(f(n))=Θ(n lg n)

## 例 4. 求解 T(n)=2T(n/2)+n lg n.

解：a=2, b=2, f(n)=n lg n, n^{log_b a}=n, f(n)=n lg n 大于 n^{log_b a}=n, 但不够多项式地大于。Master 定理使用于该 T(n)。

## Master 定理证明

引理 1: 设 a≥1, b>1, n=b^k, k 是整数。则方程式 T(n) = { Θ(1) if n=1; aT(n/b)+f(n) if n=b^k } 的解为： T(n)=Θ(n^{log_b a})+∑_{i=0}^{k-1} a^i f(n/b^i)

## Master 定理证明(续)

引理 2: 设 a≥1, b>1, n=b^k, k 是整数。g(n)=∑_{i=0}^{log_b n -1} a^i f(n/b^i)。 (1) if f(n)=O(n^{log_b a - ε}) for ε>0, 则 g(n)=O(n^{log_b a - ε}) (2) if f(n)=Θ(n^{log_b a}), then g(n)=Θ(n^{log_b a} lg n) (3) if af(n/b) ≤ c f(n) for some 0<c<1 and all n≥b, then g(n)=Θ(f(n)).

## 引理2的证明

(1) if f(n)=O(n^{log_b a + ε}) for some ε>0, then g(n)=O(n^{log_b a})

证明：(1) g(n)=O(∑_{j=0}^{log_b a - ε} a^j (n/b^j)^{log_b a + ε}) = n^{log_b a + ε} ∑_{j=0}^{log_b a - ε} (a b^{...}) ... = n^{log_b a} O(n^{ε}) = O(n^{log_b a})

## 引理2的证明 (续)

(2) if f(n)=Θ(n^{log_b a}), then g(n)=Θ(n^{log_b a} lg n)

证明：(2) 由 f(n/b^j)=Θ(a^j / b^{j log_b a}) , g(n)=Θ(∑_{j=0}^{log_b a} a^j (n/b^j)^{log_b a}) ... ⇒ g(n)=Θ(n^{log_b a} lg n)

## (3) if a f(n/b) ≤ c f(n) for some 0<c<1 and all n≥b, then g(n)=Θ(f(n))

(3) g(n)中的所有项皆为正, 由上对 ∀ 0<c<1 and all n≥b, a f(n/b) ≤ c f(n), a f(n/b^2) ≤ c f(n/b), ... ⇒ a^j f(n/b^j) ≤ c^j f(n) ... g(n)=∑ a^j f(n/b^j) ≤ ∑ c^j f(n) = f(n) 1/(1-c)=Θ(f(n))

## Master定理的证明 (续)

引理3: a≥1, b>1, n=b^k, k 为正整数, 则 T(n) = { Θ(1) if n=1; a T(n/b)+f(n) if n=b^k } 的解为: (1) if f(n)=O(n^{log_b a - ε}) for some ε>0, then T(n)=Θ(n^{log_b a}) (2) if f(n)=Θ(n^{log_b a}), then T(n)=Θ(n^{log_b a} lg n) (3) if f(n)=Ω(n^{log_b a + ε}) for some ε>0, and if a f(n/b) ≤ c f(n) for some 0<c<1 and all 充分大的 n, then T(n)=Θ(f(n))

## 引理3的证明

证明：(1) 由引理1 和引理2： T(n)=Θ(n^{log_b a})+O(n^{log_b a})=Θ(n^{log_b a}) (2) T(n)=Θ(n^{log_b a})+O(n^{log_b a} lg n)=Θ(n^{log_b a} lg n) (3) T(n)=Θ(n^{log_b a})+Θ(f(n))=Θ(f(n))

## Master定理的证明 (续)

当 n 不是 b 的幂时： 思路：若 n 满足递推 (平均递推类) • a T(⌈n/b⌉)+f(n) ≤ a T(n/b)+f(n) ≤ a T(⌈n/b⌉)+f(n) • 求 T(n)=a T(⌈n/b⌉)+f(n) 的上界, T(n)=a T(⌊n/b⌋)+f(n) 的下界 可得到 T(n) 的常数 • 求 T(n)=a T(⌈n/b⌉)+f(n) 的下界类比于求 T(n)=a T(⌊n/b⌋)+f(n) 的上界 所以我们可以求 T(n)=a T(⌈n/b⌉)+f(n) 的上界
