
# 向最定义

- 输入：S={1, 2, ..., n}, F={ [s_i, f_i] }, n≥i≥1
- 解释：S 辅助最大权集合

# 设计与选择性质

- 个性质
  当问题具有最优子结构性质时，取使f_i最小的活动，取使问题的解更易构造
- 贪心选择方法
  - 选择：
    - 每次取使剩余最小时间结束的活动f_i
  - 剩余活动构造：
    - S_i = { j∈S | s_j ≥ f_i }

# 优化解的构造

设 S={1,2,...,n} 是 n 个活动集合，[s_i, f_i] 表示活动 i 的开始结束时间，f_1≤f_2≤...≤f_n，S 的活动集合是问题的一个优化解也包含活动 1。
设 A 是一个集合，则称集合 A 中活动，设集合一个活动为 k，第二个活动为 j。
若 k=1，则取现活动。
若 k≠1，令 B=A-{k} ∪ {1}，
由 A 中活动知，f_1≤S_k, S_k 活动构造。
因 |B|=|A|，所以 B 是一个优化解，也包含活动 1。

定理1. 设 S={1,2,...,n} n 个活动集合，[s_i, f_i] 表示活动 i 的开始结束时间，f_1≤f_2≤...≤f_n, 则 A 是 S 的问题的一个优化解且包含活动 1。则 A⊆A-{1}。
若 S⊆{i | s_i ≥ f_j} 的活动则问题优化解。
注意，A' 活动集合是最大，
则优化量是明 A' 是最大。

在问题说明活动时问题具有优化子结构

由式 |A|=|A'|+1, |B|=|B'|+|J>|A|+|J|=|A|, 均 A 集合大于等于

# 编码树T的条件

— 设C是字符集(或文件字符集)且字符集大小为n, ∀c∈C
f(c)是字符c对应的编码树码长
— d_T(c)是字符c在编码树T中码长, 即c的编码码长
— T的编码信息量为∑_{c∈C} f(c)d_T(c)
B(T)=∑_{c∈C} f(c)d_T(c)

# 优化编码树问题

- 给定：字符集 C = {c₁, c₂, ..., cₙ},
  频率集 F = {f(c₁), f(c₂), ..., f(cₙ)}
  问题：求满足B(T)最小的编码树
- 贪心策略：
  将频率相同的字符合并成一个新字符，
  在一棵树中，其和最小

# 设计哈夫曼编码方法

- 贪心方法：
- 每次取频率最小的两个字符x,y，
  构造一个新节点
- 剩余问题规模缩小：
  C' = C - {x, y} ∪ {z}

![](img/9e822ee25d7fb44c33253ed3ff372fc1_61_1.png)

# 优化哈夫曼树的分析

定义1. 设T是字符集C的哈夫曼树, ∀c∈C, f(c)是字符c出现的频率,取x,y∈A且有唯一的共同祖先节点z,记它为父亲节点,相对操作：
将频率f(z)=f(x)+f(y)合并, T'=T-{x,y}是字符集C'=C-{x,y}∪{z}的哈夫曼编码树

![](img/9e822ee25d7fb44c33253ed3ff372fc1_61_2.png)

# 证明思路

T' → T 合并过程示意图，f(z)=f(x)+f(y)

注, 令B(T)=B(T')+f(z)(d_T(x)+d_T(y))
B(T)=∑_{c∈C'} f(c)d_T(c)+f(x)d_T(x)+f(y)d_T(y)+∑_{c∈C'} f(c)d_T(c)
= f(x)(d_T(x)+d_T(y)+1)+f(y)(d_T(x)+d_T(y)+1)+∑_{c∈C'} f(c)d_T(c)
= f(x)(d_T(x)+d_T(y)+1)+f(y)(d_T(x)+d_T(y)+1)+∑_{c∈C'} f(c)d_T(c)
= f(x)(d_T(x)+d_T(y)+1)+f(y)(d_T(x)+d_T(y)+1)
= f(x)+f(y) f(z) f(c)
= f(x)+f(y) f(z) f(c) d_T(c)+∑_{c∈C'} f(c)d_T(c)=B(T')+f(z)f(x)f(y)
每次T'中频率最小的两个字符x,y合并成新字符z,构造新树T',则B(T')>B(T')
在字符集C'中,它们是最小的两个,合并其子孙合并为T',可得子孙, y,f(x) f(z)
则从C'中一个子集构造哈夫曼树T''

![](img/9e822ee25d7fb44c33253ed3ff372fc1_61_3.png)

![](img/9e822ee25d7fb44c33253ed3ff372fc1_62_0.png)

B(T''') = B(T'') + f(x) + f(y)
由于 B(T'') < B(T')
B(T''') = B(T'') + f(x) + f(y) < B(T') + f(x) + f(y) = B(T)
与 T 优化编码树，放 T' 是优化编码树。

# Greedy 选择性

定义2. 设 C 是字符串集，∀c∈C，c具有频率f(c)，x，y是 C 中具有最小频率的两个字符串，则存在一个 C 的优化前缀树，x 与 y 的编码具有相同最大长度，且仅在最末一位不同。

![](img/9e822ee25d7fb44c33253ed3ff372fc1_62_1.png)

证：若 T 是 C 的优化前缀树，则 x 和 y 具有最大深度 的两个兄弟节点，则命题成立。若不然，设 b 和 c 是具有最大深度的两个兄弟节点：
不失一般性，设 f(b) ≤ f(c)，f(x) ≤ f(y)。因 x 与 y 具有最 低频率的字符串，f(b) ≥ f(x)，f(c) ≥ f(y)。交换 b 和 x，从 T 构造 T'：
B(T') - B(T) = sum f(d_i) - sum f(c_i) = f(x)d(x) + f(b)d(b) - f(x)d(x) - f(b)d(b) - f(x)d(x) - f(b)d(b) + f(b)d(b) + f(x)d(x) + f(b)d(b) - f(x)d(x) - f(b)d(b) = f(b)f(x)(d(b) + d(x)) - f(x)f(b)(d(b) + d(x)) = 0
∴ B(T') - B(T) = 0, B(T') ≥ B(T)
同理可证 B(T'') ≥ B(T''')
由于 T 是最优的，所以 B(T) ≥ B(T'')
于是， B(T'') = B(T')， T' 是 C 的优化前缀树树。
于是，在 T'' 中， x 和 y 具有相同最大深度码，且仅最后一位不同。

![](img/9e822ee25d7fb44c33253ed3ff372fc1_62_2.png)

证 T' 是最优优化前缀树.
B(T') - B(T) = sum f(d_i) - sum f(c_i)
= f(x)d(x) + f(b)d(b) - f(x)d(x) - f(b)d(b) - f(x)d(x) - f(b)d(b) + f(b)d(b) + f(x)d(x) + f(b)d(b) - f(x)d(x) - f(b)d(b)
= f(b)f(x)(d(b) + d(x)) - f(x)f(b)(d(b) + d(x))
= f(b)f(x)(d(b) + d(x)) - f(x)f(b)(d(b) + d(x)) = 0
∴ B(T') - B(T) = 0, B(T') ≥ B(T)
同理可证 B(T'') ≥ B(T''')
由于 T 是最优的，所以 B(T) ≥ B(T'')
于是， B(T'') = B(T')， T' 是 C 的优化前缀树树。
于是，在 T'' 中， x 和 y 具有相同最大深度码，且仅最后一位不同。
