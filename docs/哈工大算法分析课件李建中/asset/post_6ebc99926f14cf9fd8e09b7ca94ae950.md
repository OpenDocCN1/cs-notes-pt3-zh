### 2.1.1 同阶函数

定义2.1.1. 设f(n)和g(n)是正值函数。如果存在c1, c2>0, n0, ∀n>n0, c1g(n)≤f(n)≤c2g(n), 则称f(n)与g(n)同阶, 记作f(n)=Θ(g(n))。

Θ(g(n))可记为如下集合:
{ f(n) | ∃c1, c2>0, n0, ∀n>n0, c1g(n)≤f(n)≤c2g(n) }
即所有与g(n)同阶函数的集合

## 思考题

用定义证明下列结论：

+   1. f(n)=an²+bn+c=Θ(n²)
+   2. Θ(n²)=Θ(n²+1)
+   3. p(n)=∑_{i=0}^{k} a_i n^i = Θ(n^k)

### 2.1.2 渐近上界集合

定义2.1.2. 设f(n)与g(n)是正值函数. 如果 ∃c>0, n0, ∀n>n0, f(n)≤c g(n), 则称f(n)是g(n)渐近或g(n)是f(n)的上界, 记作f(n)=O(g(n)).

O(g(n))可视为如下集合:
{f(n) | ∃c, n0, ∀n>n0, f(n)≤c g(n)}
被所有此g(n)渐近的函数

## 思考题

用定义证明下列结论.

+   1. n=O(n²)
+   2. 如果f(n)=Θ(g(n)), 则f(n)=O(g(n))

### 2.1.3 渐近下界集合

定义2.1.3. 设f(n)与g(n)是正值函数. 如果 ∃c>0, n0, ∀n>n0, f(n)≥c g(n), 则称f(n)是g(n)渐近或g(n)是f(n)的下界, 记作f(n)=Ω(g(n)).

Ω(g(n))可视为如下集合:
{f(n) | ∃c, n0, ∀n>n0, f(n)≥c g(n)}
被所有此g(n)渐近的函数

## 思考题

f(n)=Θ(g(n)) iff f(n)=O(g(n)) 且 f(n)=Ω(g(n))

o(g(n))可视为如下集合:

### 2.1.5 严格渐近下界集合

定义2.1.5. 设f(n)和g(n)是正函数。若存在c>0, n0, ∀n>n0, f(n)>c g(n), 则称f(n)严格比g(n)高或g(n)是f(n)的严格下界, 记作f(n)=ω(g(n))。

ω(g(n))可记为下集合:

### 2.1.6 高阶的性质

A 传导性：

+   (a) f(n)=Θ(g(n)) ∧ g(n)=Θ(h(n)) ⇒ f(n)=Θ(h(n))
+   (b) f(n)=O(g(n)) ∧ g(n)=O(h(n)) ⇒ f(n)=O(h(n))
+   (c) f(n)=Ω(g(n)) ∧ g(n)=Ω(h(n)) ⇒ f(n)=Ω(h(n))
+   (d) f(n)=o(g(n)) ∧ g(n)=o(h(n)) ⇒ f(n)=o(h(n))
+   (e) f(n)=ω(g(n)) ∧ g(n)=ω(h(n)) ⇒ f(n)=ω(h(n))

### 2.1.6 高阶的性质(续)

B 自反性：

+   (a) f(n)=Θ(f(n)),
+   (b) f(n)=O(f(n)),
+   (c) f(n)=Ω(f(n))

C 对称性
f(n)=Θ(g(n)) iff g(n)=Θ(f(n))

D 反对称性：
f(n)=Ω(g(n)) iff g(n)=O(f(n))
f(n)=o(g(n)) iff g(n)=ω(f(n))

## 例3. 设对所有k≥0, a_{k+1}/a_k ≤ r <1, 求 ∑ a_k 的上界

解: a_k / a_0 ≤ r^k ⇒ a_k ≤ a_0 r^k,

## 2.4 递归方程

+   - 递归方程: 递归方程是使用具有较小输入值和相同方程来描述一个方程。

+   - 递归方程例: Merge-sort排序算法的递推性方程
+   T(n)=Θ(1) if n=1
+   T(n)=2T(n/2)+Θ(n) if n>1.
+   T(n) 解决是 Θ(n log n)

## 求解递归方程的三个主要方法

+   - Substitution方法:
+     - Guess first,
+     - 然后验证和证明方法证明.
+   - Iteration方法:
+     - 把方程转化为一个和式,
+     - 然后用估计和方程求解.
+   - Master方法:
+     - 求解型如 T(n)=aT(n/b)+f(n) 的递归方程
