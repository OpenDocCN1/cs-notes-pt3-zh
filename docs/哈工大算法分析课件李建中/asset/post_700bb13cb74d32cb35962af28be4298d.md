### 非法的素覆盖

素覆盖：{b, e, c, f, d, g}

被覆盖：{b, e, d}

### 算法

```
APPROX-Vertex-Cover (G)
1. C=∅
2. E'=E[G];
3. While E'≠∅ DO
4.   任意(u, v)∈E';
5.   C=C∪{u, v};
6.   从E'中删除所有与u或v相邻的边;
7. Return C
```

### 算法的性能分析

### 精确解是多项式

### Ratio Bound

定理. Approx-Vertex-Cover的Ratio Bound为2.
证明. 令A={(u, v) | (u, v)是算法选取的每条边}.
若(u, v)∈A, 则与(u, v)有关的边都从E'中删除.
于是, A中元素两两独立.
第5步中, 算法对每个(u, v)加入C, |C|=2|A|.
若C*是此问题的最优解,
由A中任意一条边(u, v)至少有一个端点在一个最优解一个端点. 于是,
|A|≤|C*|, |C|=2|A|≤2|C*|, 即|C|/|C*|≤2.

## 问题定义

- 输入：

- 输出：
  - C⊆F, 满足

### 问题举例

X=12个元素, F={S₁,S₂,S₃,S₄,S₅,S₆}
取最小覆盖C={S₂,S₃,S₅}

### 近似算法的设计

- 基本思想
  - 贪心策略是选择覆盖最多未被覆盖元素的集合

C={S₂,S₄,S₆,S₃}

### 算法

```
Greedy-Set-Cover(X, F)
1. U←X; /* U为X中未被覆盖的元素集合 */
2. C←∅
3. While U≠∅ Do
4.   Select S∈F 使|S∩U|最大;
   /* Greedy-算法一次选择覆盖最多未被U覆盖元素的S */
5.   U←U−S;
6.   C←C∪{S}; /* 将该X覆盖 */
7. Return C.
```

### 算法性能分析

- 时间复杂度
  - 3-6循环执行最多min{|X|,|F|}次
  - 计算|S∩U|需要O(|X|)
  - 每次迭代需要O(|F||X|)
  - T(X,F)=O(|F||X|·min{|X|,|F|})

### Ration Bound

定理1. 若H(d)=∑_{i=1}^{d}1/i. Greedy-Set-Covers的近似比p(n)=这项算法, p(n)=H(max{|S| | S∈F}).
证明：设最优解为C*, C*的最小覆盖为C^G.
令S₁是Greedy-Set-Cover算法第一次选择的集合.
... 设S_i~S_j为第i次迭代选择的集合, 记为S_i, 每次迭代覆盖的未被覆盖元素数为... ∀x∈X, x属于第i次迭代时, 记x为第i次覆盖, 则 c_x = 1/[S_i − (S₁∪S₂∪...∪S_{i−1})]

## 集合覆盖问题

设C是集合族C中作为集合{Ci}的集合X所覆盖。由C*是最小X, 有
|C*| = Σ_{i∈C*} c_i ≤ Σ_{i∈S*} c_i
注：上式不等号是因为集合C*中每个集合的成本c_i满足了c_i ≤ H(S_i) ...

对于 V S∈F, Σ_{e∈S} c_e ≤ H(S) ... |C| ≤ Σ_{i∈S*} c_i ≤ H(max{|S| | S∈F}), 则 |C|/|C*| ≤ H(max{|S| | S∈F}), 证明完毕。
下此时的结论是：对于 V S∈F, Σ_{e∈S} c_e ≤ H(S).

对于 V S∈F, t=1,2,...,|C|, 令 u_t = S - (S1∪S2∪...∪S_{t-1})∩S_t, S1, S2, ..., S_k 按照贪心算法选择的顺序, S_t 是第 t 个被选择的集合, u_t 是其中未被覆盖的元素个数。
设 u_0=0, u_t 是第 t 个被选择的 S_t, S1, S2, ..., S_k, u_0, u_1, ..., u_k 满足递减关系。
Σ_{i∈S} c_i = Σ_{t=1}^k u_t * w_t ...

Σ_{i∈S} c_i = Σ_{t=1}^k u_t * w_t ... Greedy 算法：S1,S2,...,Sk 是贪心选择的顺序, 则 S 的第 t 个集合的成本 ...

Σ_{i=1}^k u_i ≤ Σ_{i=1}^k (u_{i-1} - u_i) * 1/u_{i-1} ... = H(u_0) - H(u_k) ... = H(|X|) - H(0) ...

### 复杂性分析

猜想1. Greedy-Set-Cover 是一个 O(ln|X|+1)-近似算法。
证. 由已知 H(n) ≤ ln(n+1) 可得 H(max{|S| | S∈F}) ≤ H(|X|) ≤ ln|X|+1.

### 非确定 Max-3-CNF 可满足性近似算法

- 基本概念
设 C, R 是随机近似算法 RAS 产生 的两个 P 随机近似解, 解代码为 C*, C* 是同 P 的随机解, n 是 P 的最大, 设 max{C/C*}, C*/C* ≤ p(n), 则称 RSA 是有概率 p(n) 的近似算法, 我们希望 RAS 是一个随机 p(n)-近似算法。

## Max-3-CNF问题定义

- 输入： 集合变量集 $\{x_1, x_2, ..., x_n\}$，
  每个子句具有至多三个变量，
  设有 $m$ 个子句和它们对应的一个个布尔公式中
  一个变量或其否定，最大化使至少 $1$ 个布尔公式为真
- 随机算法
Random-Max-3-CNF(CNF)
1. For 每个 $x$ 变量 $x$ 随机赋值 Do
2. 随机赋值 $x$：$x=0$ 概率为 $1/2$, $x=1$ 概率为 $1/2$;
3. Return.

### 性能分析

定理：Random-Max-3-CNF 是一个随机 $8/7$-近似算法。
证明：
设 $C$ 为 $>CNF$ 中有 $n$ 个变量，$m$ 个子句，每个子句最多包含 $3$ 个文字 $x_{i1} \vee x_{i2} \vee x_{i3}$，$i=1,2,...,m$，定义随机变量：
$Y_i=1$ 当第 $i$ 个子句被满足，$1$，否则 $Y_i=0$。
$Pr[Y_i=0]=Pr[x_{i1}=0]Pr[x_{i2}=0]Pr[x_{i3}=0]=(1/2)^3=1/8$。
$Pr[Y_i=1]=1-Pr[Y_i=0]=1-1/8=7/8$。
$E[Y_i]=7/8$。
$Y=Y_1+Y_2+...+Y_m$，$Y$ 为 $CNF$ 中被满足的子句个数。
$E[Y]=\sum_{i=1}^m E[Y_i]=\sum_{i=1}^m 7/8 m=7/8 m$。
直观，优化解至少满足 $m$，于是得到 $m/(m*7/8)=8/7$。

### 点权最小顶点覆盖问题的线性规划松弛

- 问题定义
  - 输入：无向图 $G=(V,E)$，每个节点具有权 $w(v)$。
  - 输出：$C \subseteq V$，满足
    - (1). $\forall (u,v) \in E, u \in C$ 或 $v \in C$
    - (2). $w(C)$ 最小，$w(C)=\sum_{v \in C} w(v)$。
  - 点权最小顶点覆盖与系统连通！

### 问题其它 0-1 整数规划问题 $P_{0-1}$

- 对每个 $v \in V$，定义 $x(v) \in \{0,1\}$ 如下：
  - 若 $v$ 被选中覆盖，则 $x(v)=1$，若被 $x(v)=0$。
  - $\forall (u,v) \in E$, $v \in V$，要求每个边至少被一个端点覆盖，则 $x(u)+x(v)\ge1$。
- 构造 0-1 整数规划问题 $P_{0-1}$
  - 优化目标：最小化 $\sum_{v \in V} w(v)x(v)$
  - 约束条件：$x(u)+x(v)\ge1$ for $\forall v \in V$
    $x(v)\in\{0,1\}$ for $\forall v \in V$
- 0-1 整数规划问题与 NP-完全问题同构
- 我们需要寻找近似算法

### 用线性规划问题解近似 0-1 整数规划问题

- 针对 $\forall v \in V$，定义 $x(v)\in[0,1]$
- $P_{0-1}$ 问题松弛为 $LP$
  - 优化目标：最小化 $\sum_{v \in V} w(v)x(v)$
  - 约束条件：$x(u)+x(v)\ge1$ for $\forall v \in V$
    $x(v)\in[0,1]$ for $\forall v \in V$
- 线性规划问题是可解的线性系统
- $P_{0-1}$ 可解解可被 $LP$ 解可解
- $P_{0-1}$ 解代价 $\ge LP$ 解代价

### 近似算法

- Approx-Min-VC$(G,w)$
1. $C=\emptyset$;
2. 针对 $LP$ 问题优化解；
3. For each $v \in V$ Do
4. If $x(v)\ge1/2$ Then $C=C\cup\{v\}$;
   /* 将 $x(v)$ 变量值映射到 $LP$ 解以得到 $P_{0-1}$ 解 */
5. Return $C$.
