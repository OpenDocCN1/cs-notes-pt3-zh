## 4.2 贪婪策略

### 问题定义

输入：n位二进制整数X和Y
输出：X和Y的乘积
通常，计算X*Y的时间复杂度是O(n³)。
我们能否找到一个算法是O(n^2.81)的时间。

### 算法的数学基础

X = [A B] n/2 n/2   Y = [C D] n/2 n/2
XY = (A²n² + B)(C²n² + D)
= AC² + AD²n² + BC²n² + BD
= AC² + (A-B)(D-C)+AC+BD)²n² + BD

算法步骤

1. 划分A-B和D-C;
2. 计算n/2规模的AC、BD、(A-B)(D-C);
3. M=(A-B)(D-C)+AC+BD;
4. N=AC与BD，M=M与乘积n/2;
5. 计算XY=N+M+BD。

递归计算复杂性
T(n)=4T(n/2)+O(n²)

### 算法分析

- 建立递归方程
  - T(n)=Θ(1) if n=1
  - T(n)=3T(n/2)+O(n) if n>1
- 使用Master定理
  - T(n)=O(n^1.59)=O(n^1.59)

## 4.3 快速乘法

### 问题定义

输入：两个n×n矩阵A和B
输出：A和B的乘积
通常，计算AB的时间复杂度是O(n³)。
我们能否找到一个算法是O(n^2.81)的时间。

### 算法的数学基础

- 把C=A+D分成4个规模为n/2×n/2的子矩阵
- 每个子矩阵都是一个n/2×n/2矩阵

[C11 C12; C21 C22] = [A1; A2] [B11 B12; B21 B22]

递归计算复杂性
T(n)=8T(n/2) ω(n²)=O(n^ω)

矩阵乘法递归公式：
C11=A11B11+A12B21, C12=A11B12+A12B22
C21=A21B11+A22B21, C22=A21B12+A22B22

### 算法

- 这一多项化使 n/2×n/2 矩阵的 10 个乘法和 7 个加法
  - M₁ = A₁₁(B₁₁ + B₁₂)
  - M₂ = (A₁₁ + A₁₂) B₂₂
  - M₃ = (A₁₁ + A₁₂) B₁₁
  - M₄ = A₁₂(B₂₁ + B₂₂)
  - M₅ = (A₂₁ + A₂₂)(B₁₁ + B₁₂)
  - M₆ = (A₂₁ - A₁₂)(B₁₁ + B₁₂)
  - M₇ = (A₁₁ - A₁₂)(B₁₁ + B₁₂)

### 算法

- 计算 C=AB 需要另外 8 次 n/2×n/2 矩阵加减
  - C₁₁ = M₁ + M₄ - M₅ + M₆
  - C₁₂ = M₁ + M₂
  - C₂₁ = M₃ + M₄
  - C₂₂ = M₂ + M₃ - M₁ - M₇

### 算法复杂性分析

- 18 个 n/2×n/2 矩阵加减，系数为常数，需要 O(n²)
- 7 个 n/2×n/2 矩阵乘法
  - 这是递归过程
    - T(n)=O(1) n=2
    - T(n)=7T(n/2)+O(n²) n>2
- 根据 Master 定理求解 T(n)
  - T(n)=O(n^log₂7) ≈O(n^2.81)

## 4.4 Finding the closest pair of points

Page 92 – 96

### 问题定义

- 输入：Euclidean 空间上有 n 个点组成的集合 Q
- 输出：Pᵢ, Pⱼ ∈ Q
  - Dist(Pᵢ, Pⱼ)=Min{Dist(X, Y) | X, Y ∈ Q}
- Dist(X, Y) Euclidean 距离：
  - 假设 X=(x₁, y₁), Y=(x₂, y₂)，则
  - Dist(X,Y)=√[(x₁ - x₂)² + (y₁ - y₂)²]

### 一维空间算法

- 利用排序算法
  - 排序
  - 如 Q 中点排序
  - 递归地求解两半的最近点对
  - 时间复杂度
    - T(n)=O(n log n)

### 一维空间算法(续)

- Divide-and-conquer算法

Preprocessing:

1. 若|Q|中包含2个点，则返回这两个点；
2. 查找Q中点坐标中位数m。

![img](img/9e822ee25d7fb44c33253ed3ff372fc1_37_0.png)

Divide:

3. 用Q中点坐标中位数m把Q划分为两个大小相等的集合
   Q1 = {x∈Q | x≤m}, Q2 = {x∈Q | x>m}

![img](img/9e822ee25d7fb44c33253ed3ff372fc1_37_1.png)

Conquer:

4. 递归地求Q1,Q2中最近点对或近点
   (p1 p2) (q1 q2)

Merge:

![img](img/9e822ee25d7fb44c33253ed3ff372fc1_37_2.png)

5. 考虑(p1 p2)、(q1 q2)之间的点(p3 q3)可能将产生更近的点对(x,y)。若p3是Q1中最大点,q3是Q2中最小点。(x,y)Q中最近点对。

- 时间复杂性
  - Divide所需要量O(n)时间
  - Conquer所需要量2T(n/2)时间
  - Merge所需要量O(n)时间

递推方程
T(n)= O(1)      n=2
T(n)=2T(n/2)+O(n)   n≥3

- 用Master定理求解T(n)
  - T(n)=O(nlogn)

### 二维空间算法

- Divide-and-conquer算法

Preprocessing:

1. 若|Q|中包含一个点，则返回该点；
2. 将配对Q中点按x坐标值由小到大排序。

![img](img/9e822ee25d7fb44c33253ed3ff372fc1_37_3.png)

Divide:

3. 找到Q中点x坐标中位数m,
4. 用垂直L:x=m把Q划分为两个大小相等的集合
   QL和QR。QL在直线L左侧,QR在直线L右侧。

![img](img/9e822ee25d7fb44c33253ed3ff372fc1_37_4.png)

![img](img/9e822ee25d7fb44c33253ed3ff372fc1_38_0.png)

### Conquer:

5. 递归地求Q_L、Q_R 中最近点对距离时：(p1,p2)∈Q_L, (q1,q2)∈Q_R
6. d=min{Dis(p1,p2), Dis(q1,q2)};

![img](img/9e822ee25d7fb44c33253ed3ff372fc1_38_1.png)

### Merge:

1. 依次考察条带中离直线L小于d的点(p_i,q_i), p_i∈Q_L, q_i∈Q_R;
2. 若点(p_i,q_i)从原序列中依次比较，每次比较(p_i,p_j)和(q_i,q_j)中离得最小的点与Q中最近点比较。
   若点(p_i,q_i)始终保持最近点对不变则结束

- (p_i,q_j)最近点算法
  1. 把原序列中所有点按x坐标划到直线L上；
  2. 同时从直线两边各取k个点，p_i-p_j每对互相比较两个（或每点最多6个），求Dis(p,q)<d时，取d=Dis(p,q)；
  3. 若点在直线附近，另有后续点d减小同时将(p_i,q_j)各点互相比较(p_i,q_j)。

- 时间复杂度
  - Divide阶段需要O(n)时间
  - Conquer阶段需要2T(n/2)时间
  - Merge阶段需要O(n)时间
  - 递归方程
    - T(n)=O(1) n=2
    - T(n)=2T(n/2)+O(n) n≥3
  - 用Master定理求解T(n)
    - T(n)=O(nlogn)
