
—我们用G(x, y)表示G的边(x, y)的收缩
—边集F⊂E收缩操作记为G/F
—图G/F的节点集合表示为V/F
—图G/F的节点集合表示为V/F

## 随机算法

- 1. H=G;
- 2. While |H|V|> 2 Do
- 3. 随机地从H(E)中选择一条边(x, y);
- 4. F←F∪{(x, y)};
- 5. H=H/(x, y);
- 6. Cut=连接H中两个元素的G的所有边。

## 例

Cut={(1,3), (2,3)}

## 算法的性能分析

定理1. 如果算法的输入是具有n个节点的多图，则算法的时间复杂性为O(n²)。
证明. 一次收缩需要O(n)时间。
至多进行O(n)次收缩。
于是，算法的时间复杂性为O(n²)。

注意1. 我们仅证明在O(n²)时间内算法能够求出一个Cut，但这个Cut不一定是优化的。

引理1. 如果最小cut的大小, 则G至少有kn/2条边。
证. 如果G(E) < kn/2, 则存在一个度小于k的节点p。
删除与p相关连的边, 把G分成两个连通分量, 其一是仅包含p。
于是, 与p相关连的边集合是一个cut。
但是这个cut的大小<k, 与min-cut大小为k矛盾。

引理2. 算法输出的cut连接两个剩余节点的没有被收缩缩边的集合。
证. 从算法定义可以看出, 算法输出的cut是连接两个剩余节点的没有收缩边的集合。

引理1. 如果k是图G的一个min-cut的大小, 则G至少有kn/2条边。
证. 如果G(E) < kn/2, 则存在一个度小于k的节点p。
删除与p相关连的边, 把G分成两个连通分量, 其一是仅包含p的连通分量。
于是, 与p相关连的边集合是一个cut。
但是这个cut的大小<k, 与min-cut大小为k矛盾。

## 定理2. 设C是一个min-cut，其大小为k，在算法结束时，C中无边吸收缩过的概率大于2/m²。

证. A表示每一步没有选过C的边的，|S∩k-2|。
在第i步，选中的边的在C中的概率至多为k/(kn/2)=2/m，即 Pr(A_i) ≥ 2/m - 2/m。
在第2步，若A_4发生，则至少有k/m -1/2条边(每次收缩减少一个节点)，选中C中边的概率为2/(m-1)，即 Pr(A_4) ≥ 2/m - 2/(m-1)。
在第3步，若A_4发生，则有至少k/m -1/2节点，即至少有k(n-1)/2条边。于是
Pr(A_4 | A_1) ≥ ∏_{i=1}^{2} (1-2/(n-i+1)) = 2/(n-2) - 2/(n-1) > 2/n²。
最后我们有
Pr(∩_{i=1}^{2} A_i) ≥ ∏_{i=1}^{2} (1-2/(n-i+1)) = 2/(n-2) - 2/(n-1) > 2/n²。

## 近似算法的基本概念
• 近似算法的应用背景
  - 很多实际问题属于NP-完全问题
  - NP-完全问题是很难找到多项式时间算法
  - 而解NP-完全问题算法：
    * 问题规模输入很小，可采用有最优解的算法直接解问题
    * 问题规模很大时，可采用近似算法
    * 许多问题与其它问题联系可采用近似解
• 什么叫近似算法
  - 能够找到一个优化问题的近似优化解的算法
  - 近似算法主要解决何问题

## 近似算法的性能分析
• 近似算法的性能度量
  - 一个算法解多项式时间可解最优解问题
• 近似算法的性能度量
  - 寻找解问题的近似解问题
  - 问题规模很大时，可采用近似算法
  - 我们的算法与最优解的比值
  - 一般算法多项式时间近似算法的性能比是性能比是

    * 相对误差
    * (1+ε)-近似

## Ratio Bound

定理1（Ratio Bound）#4：一个充分必要的结论。某点 A 具有 ratio bound p(n)，当且仅当 max{C/C', C'/C} ≤ p(n)。

- 对于问题规模为 n 的问题，max(C/C', C'/C)=C/C'
- 对于问题规模为 n 的问题，max(C/C', C'/C)=C/C'
- 若存在 C' 使得 C/C' > 1，Ratio Bound 为 4 个字节？
- Ratio Bound 越大，越高效

## 相对误差

定义2（相对误差）：对于给定解，定义所求解问题的最优解长度与 |C-C'|/C' 的关系。定义3（相对误差）：一个近似算法的相对误差是 ε(n)，如果 |C-C'|/C' ≤ ε(n)。

定理1：ε(n) ≤ p(n)-1。
证明：对于最坏情况，ε(n)=|C-C'|/C'=C/C'-1=p(n)-1；对于一般情况，ε(n)=|C-C'|/C'=(C-C')/C'=(C/C'-1)/(C'/C)=p(n)-1。

- 对于某些问题，ε(n) 即使存在，也可能非常小。
- 对于 NP-完全问题，通常无法保证最优解，因此近似算法的 Ratio Bound 可能较大。
- 问题越复杂，越难对 Ratio Bound 做出较好的估计。

## 近似模式

定义4（近似模式）：一个优化问题的近似模式是一个算法族，其性能比为一个关于输入规模的函数。一个近似模式可以是一个(1+ε)-近似算法。定义5：一个近似模式 A 的输出总是满足近似模式的要求，即对于给定 ε>0，A(I) 的运行时间是关于输入规模的多项式。定义6：一个近似模式的表现全部为关于输入规模的近似模式。
