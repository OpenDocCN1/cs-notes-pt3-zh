
# 4.5 Finding the convex hull

## 问题定义

输入：平面上给n个点集合Q
输出：CH(Q): Q的convex hull

Q的convex hull是一个最小凸多边形 P, Q均在其内部或边界上P向

凸多边形P是有其下所有顶点连形：连接P的任意两点的都包含P内

## Graham-Scan算法

- 基本思想
- 首先求Convex hull的初始顶点，最低点坐标
- 点按极角顺序从小到大排列，然后逆时针方向的遍历点。去除Convex hull顶点的点。
- 结束。

## 类似 Graham-Scan(Q)

/*S为栈,类似 Graham-Scan 构造凸包的顺序为 CH(Q) 的顶点*/

- 1. 若 Q 中 y 坐标最小的点为 p0；
- 2. 按极角 p0(或逆时针) 方向对 Q 中除去 p0 的点排序，得到 <p1 p2 ... pn>；
- 3. Push(p0, S); Push(p1, S); Push(p2, S);
- 4. FOR i=3 TO n DO
- 5. While Next-to-top(S), Top(S)与 p0 的形成左转 Do
- 6. Pop(S);
- 7. Push(pi, S);
- 8. Rerurn S.

- • 时间复杂性
  — 第1步 O(n) 排序
  — 第2步 O(n log n) 排序
  — 第3步 O(1) 时间
  — 第4-7步 每次 O(1) 时间
  — 总时间复杂度 T(n) = O(n log n)

## Divide-and-conquer 算法

## Merge(时间复杂度 O(n))

- 1. 取 L → A 的极点；
- 2. 在 CH(Q₂) 中找到 P 轴线最左和最小点及右和；
- 3. 构造以下三个序列：
  (1) 按照斜方向的顺序列出 CH(Q₂) 全部顶点。
  (2) 按照斜方向的顺序列出 CH(Q₂) 从左到右顶点。
  (3) 按照斜方向的顺序列出 CH(Q₂) 从右到左顶点；
- 4. 合并这三个序列；
- 5. 依次合并列出 Graham-Scan。

## 时间复杂度

- • Preprocessing阶段
  -- O(1)
- • Divide阶段(假设 O(n) 算法已知)
  -- O(n)
- • Conquer阶段
  -- 2T(n/2)
- • Merge阶段
  -- O(n)

- • 总时间复杂度
  T(n)=2T(n/2)+O(n)
- • 使用Master定理
  T(n)=O(nlogn)

## Why?

- Divide-and-conquer或不适合问题

问题：各子问题不是相互独立的，各部分解法往往需要付出公共子问题的重复求解。

优化问题的特征
一优化问题，你有一个待选集合，在解空间中寻找其具有最小或最大值的优化解
A1 x1 x2 x3
(A1 x1 x2) x3 ...

一优化问题的特征
一子问题与子问题的重叠，优化问题与子问题是相互依赖
一子问题的解可以重用

## What?

## Dynamic Programming 直译

- 把原问题分解成一系列子问题
- 解决每个子问题仅一次，并将结果保存起来供以后使用。一个子问题可能被解决多次，但只需计算一次，节省计算时间
- 自底而上地计算
- 适用范围
  - 某些优化问题：可分解为多个子问题，子问题解被重复使用

## How?

## 使用 Dynamic Programming 的条件

- Optimal substructure（最优子结构）
  某个问题的最优解包含其子问题的最优解。
  针对同一个问题可以有不同的最优解。
- Subproblems（重叠子问题）
  在问题的解剖过程中，某些子问题被反复使用

## 2: 对各 d(A,T), d(B,T), d(C,T) 各有 6 个子问题

## 3: 求解各子问题

d(A,T)=min{4+d(D,T), 11+d(E,T)}=min{22,24}=22 <A,D,T>
d(B,T)=min{9+d(D,T), 5+d(E,T), 16+d(F,T)}=min{27,18,18}=18 <B,E,T>

## Dynamic Programming 典型的四步骤

- 一开始把复杂问题分解：划分为子问题
- 逐步地从最简单问题开始
  d(S,T)=min{1+d(A,T), 2+d(B,T), 5+d(C,T)}
- 逐步地把子问题，重复不可避免
- 每个子问题只做一次向后
  - 只与前代问题相关
  - 其它问题无关的信息
- 根据最优子结构信息构造最优解

## 5.2 Matrix-chain Multiplication

## 问题定义

- 给定：<A1, A2, ..., An>, Ai 为 p_{i-1}×p_i 矩阵
- 问题：计算 A1×A2×...×An 的最小代价方法

矩阵乘法代价/乘积性质：乘法次数
若 A 是 p×q 矩阵，B 是 q×r 矩阵，则 A×B 乘积代价 O(pqr)

## Motivation

- 链乘法就是实现
  - 矩阵乘法是链乘法
- 链乘一个问题有多种可行的计算方法。
  例如，(A1×A2×A3×A4)
  = (A1×A2)×(A3×A4)
  = ((A1×A2)×(A3×A4))
  = ((A1×A2)×(A3×A4))
  ...
  = ((A1×A2)×A3)×A4

- 链乘法计算的计算代价与顺序有关
  - 设 A1=10×100 矩阵，A2=100×5 矩阵，A3=5×50 矩阵
  T((A1×A2)×A3)=10×100×5+10×5×50=7500
  T(A1×(A2×A3))=100×5×50+10×100×50=75000

结论：采用不同的顺序会导致代价差异

- 链乘法设计问题解空间
  - p(n)=计算 n 个矩阵链乘法的方案数
  - p(n)随 n 增长
    (A1×...×An) 有 (A1×...×An) 种划分

由此可见的解空间是无法用枚举方法穷举最优解的！
 p(n)=C(n-1)=Catalan数= 1/(n) * C(2n-2, n-1) = Ω(4^n / n^{3/2})
