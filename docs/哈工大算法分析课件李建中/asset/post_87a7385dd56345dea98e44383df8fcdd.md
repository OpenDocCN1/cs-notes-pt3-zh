# Amortized Analysis的基础思想

- 一串长度n个操作总上界T(n), 每个操作平均T(n)/n

- 一方面操作费用被预先储藏起来以应付“坏”操作
- Potential方法（每个操作相对代价）
- 一方面要预先操作不同操作平均代价
- “一类”的操作作为另一个操作的“储蓄”

# 聚集方法动图

假设有n个独立/不相关操作，成本如下：
操作1：Cost=t₁
操作2：Cost=t₂
...
操作n：Cost=tₙ

T(n)=∑ᵢ tᵢ
平均成本：T(n)/n

每个操作被放在不同
内存，不存在依赖

# 聚集方法实例之一：栈操作序列

- 普通栈操作时间性能
  - Push(S, x)：将元素x压入栈S
  - Pop(S)：若非空则从S中弹出元素
  - 每个操作都是常数时间O(1)
  - 可执行n个操作栈操作序列总成本是O(n)
  - n个Push和Pop操作序列总成本是O(n)
  - n个操作按顺序进行时间总成本O(n)

# 新栈通过栈操作互换时间性能

- 新操作 Multipop(S, k)：
  从栈S中弹出k个元素。k≤|S|则操作是合法的
- 案例算法
  Multipop(S, k)
  1 While not STACK-EMPTY(S) and k>0 Do
  2   Pop(S);
  3   k←k-1.
- Multipop(S, k)操作复杂性(假设Pop操作看1)
  - Multipop操作成本min{|S|, k}
