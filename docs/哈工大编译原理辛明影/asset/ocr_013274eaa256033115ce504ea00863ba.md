# 5.2.1 算符优先文法

+   - 定义5.1 假设G是一个不含ε-产生式的文法，A、B和C均是G的语法变量，G的任何一对终结符a和b之间的优先关系定义为：
+     (1) a≡b，当且仅当文法G中含有形如A→...ab...或A→...aBb...的产生式；
+     (2) a< b，当且仅当文法G中含有形如A→...aB...的产生式，而且B=>b...或B=>Cb...；
+     (3) a> b，当且仅当文法G中含有形如A→...Bb...的产生式，而且B=>...a或B=>...aC；
+     (4) a与b无关系，当且仅当a与b在G的任何句型中都不相邻。
