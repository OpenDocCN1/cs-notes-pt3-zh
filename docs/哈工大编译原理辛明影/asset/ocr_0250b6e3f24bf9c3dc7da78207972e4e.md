# 5 4.3 构造语法树的语法制导定义

| 产生式 | 语义规则 |
|---|---|
| $E \rightarrow E_1 + T$ | $E.nptr := mknode('+', E_1.nptr, T.nptr)$ |
| $E \rightarrow E_1 - T$ | $E.nptr := mknode('-', E_1.nptr, T.nptr)$ |
| $E \rightarrow T$ | $E.nptr := T.nptr$ |
| $T \rightarrow (E)$ | $T.nptr := E.nptr$ |
| $T \rightarrow id$ | $T.nptr := mkleaf(id, id.entry)$ |
| $T \rightarrow num$ | $T.nptr := mkleaf(num, num.val)$ |
