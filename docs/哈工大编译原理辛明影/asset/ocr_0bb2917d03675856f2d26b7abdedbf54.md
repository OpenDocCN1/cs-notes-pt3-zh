# LALR(1)分析法的基本思想：就是将 LR(1)项目集的同心集加以合并，以削减项目集的个数。

所谓合并同心集，就是将每个核相同的 LR(1)项目合并,向前搜索符号取它们的并集。

```
T->.F    + , * , )
F->.(E)  + , * , )
F->.id   + , * , )
```
