# 7.9 输入输出语句的翻译

```
S → (write| writeln) (Elist); { n:=0;
repeat
  move(Queue, iₙ);
  gencode('par', 'out', -, -);
  n:=n+1;
until Queue为空;
  gencode('call', 'SYSOUT', n, 'w')}
/*n为输出参数个数，w是输出操作类型*/
```

EList → E, K (ε|EList)

M → ε {gencode('prog', id, y, -)} /*y的值表示input,output或两者皆有*/

N → ε {设置一个语义队列Queue}

L → ε {T:=entry(id); add(Queue, T)}

K → ε {T:= E.addr; add(Queue, T)}
