# LL(1)文法的判定

算法4.3 计算FIRST(α)。
输入：文法 G=(V, T, P, S), α∈(V∪T)*, α= X1...Xn;
输出：FIRST(α);
步骤：

+   1. 计算FIRST(X1);
+   2. FIRST(α):= FIRST(X1)-{ε};
+   3. k:=1;
+   4. while (ε∈FIRST(Xk) and k<n) do begin
+   5. FIRST(α):= FIRST(α) ∪ (FIRST(Xk+1)-{ε});
+   6. k:=k+1 end
+   7. if (k=n and ε∈FIRST(Xk)) then FIRST(α):=FIRST(α) ∪ {ε};
