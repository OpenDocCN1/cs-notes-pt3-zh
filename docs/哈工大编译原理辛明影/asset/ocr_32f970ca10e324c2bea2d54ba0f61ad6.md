# 4.2.3 对上下文无关文法的改造

引入语法变量<unmathched_stmt>来表示不配对语句，<matched_stmt>表示配对语句

+   - <stmt>→ <matched_stmt>
+     | <unmathched_stmt>

+   - <matched_stmt>→ if <expr> then <matched_stmt> else <matched_stmt>
+     | other

+   - <unmathched_stmt>→ if <expr> then <stmt>
+     | if <expr> then <matched_stmt> else <unmathched_stmt>
