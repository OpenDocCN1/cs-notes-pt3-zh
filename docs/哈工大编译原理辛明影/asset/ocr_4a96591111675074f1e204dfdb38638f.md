# 对于par和call产生的目标代码

+   1) 每个 param xᵢ(i=1,2,...n) 可直接翻译成如下指令：
+      (i+3)[top] := xᵢ      （传值）
+      (i+3)[top] := addr(xᵢ) （传地址）

+   2) call p， n 被翻译成如下指令：
+      1[top] := sp （保护现行sp）
+      3[top] := n （传递参数个数）
+      JSR p      （转子指令）
