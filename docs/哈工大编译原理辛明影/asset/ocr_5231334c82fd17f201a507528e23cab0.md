# 例：考虑文法 G（S）：

$S\to CC$

$C\to cC\mid \varepsilon$

![](bbox=[0.657, 0.09, 0.926, 0.426])

# 因为有规范推导

$S\xRightarrow[r\,m]{*}ccCcd\xRightarrow[r\,m]{ }cccccd$

故项目 $[C\to c\cdot C,\ c]$ 对活前缀 $ccc$ 是有效的。
