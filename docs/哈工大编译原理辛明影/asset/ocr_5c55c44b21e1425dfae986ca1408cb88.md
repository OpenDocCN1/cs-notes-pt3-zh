# 7.10.2 类型转换

E → E₁ + E₂ 的语义子程序

```
{E.addr := newtemp
if E₁.type = integer and E₂.type = integer then begin
gencode(E.addr=E₁.addr int+E₂.addr);
E.type = integer
end
else if E₁.type = integer and E₂.type = real then begin
u := newtemp;
gencode(u=inttoreal E₁.addr);
gencode(E.addr=u real+ E₂.addr);
E.type = real
end ...}
```
