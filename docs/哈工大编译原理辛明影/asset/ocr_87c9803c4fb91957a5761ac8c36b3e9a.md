# 7.5.3 布尔表达式的控制流翻译

```
B → ( B₁ ) {B₁.true:=B.true; B₁.false:=B.false; B.code:=B₁.code}
```

```
B → E₁ relop E₂
{B.code:=gencode('if'E₁.addr relop E₂.addr 'goto'B.true); || gencode('goto' B.false)}
```

```
B → true  {B.code:=gencode( 'goto' B.true)}
```

```
B → false  {B.code:=gencode( 'goto' B.false)}
```
