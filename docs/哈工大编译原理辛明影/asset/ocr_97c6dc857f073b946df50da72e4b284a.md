# 句子的组成规则

+   - <赋值语句>→<左部量>=<右部表达式>
+   - <左部量>→<简单变量>
+   - <左部量>→<下标变量>
+   - <简单变量>→a
+   - <简单变量>→b
+   - <简单变量>→c
+   - <下标变量>→m[1]
+   - <下标变量>→m[2]
+   - <下标变量>→m[3]
+   - <右部表达式>→<简单变量><运算符><简单变量>
+   - <右部表达式>→<简单变量><运算符><下标变量>
+   - <右部表达式>→<下标变量><运算符><简单变量>
+   - <右部表达式>→<下标变量><运算符><下标变量>
+   - <运算符>→+
+   - <运算符>→-
