## 5.3.6 二义性文法的应用

任何二义文法都不是LR文法

某些二义文法对语言的说明和实现非常有用，如描述表达式的文法：

规定优先级和结合率

```
E→E+E|E*E|(E)|id
```

## 无二义文法：

```
E→E+T|T
```

```
T→T*F|F
```

```
F→(E)|id
```

## 例：描述if语句的文法：

规定匹配原则

```
stmt → if expr then stmt
/if expr then stmt else stmt
other
```

## 无二义文法

```
stmt → matched_stmt | unmatched_stmt
matched_stmt → if expr then matched_stmt else matched_stmt
| other
unmatched_stmt → if expr then matched_stmt else unmatched_stmt
| if expr then _stmt
```

## 5.3.7 LR分析中的出错处理

- - 出错情况：
- - 栈顶状态为s，当前输入符号为a，查表得 Action[s, a]=err.
- - 这表明语法出错了。
- - 错误处理：
- - 1。向栈内搜索非终结符A，它的归约前状态为S，将A前面的符号全部弹出栈。

## 5.3.7 LR分析中的出错处理

- - 2。不断地读入输入符号，直到读到
- - a ∈Follow(A)集为止,
- - 3。将goto[s, A] 压入栈
- - 整个过程就相当于完成了一次归约，只不过归约的不是句柄
- - 这样处理完后，就相当于从一个新的句子成分开始分析
