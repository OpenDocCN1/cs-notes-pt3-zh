# 浮点乘法

+   - $(-1)^{s1} M1\ 2^{E1} \times (-1)^{s2} M2\ 2^{E2}$
+   - 精确结果: $(-1)^{s} M\ 2^{E}$
+     - 符号(Sign) $s$: $s1 \wedge s2$
+     - 尾数(Significand) $M$: $M1 \times M2$
+     - 阶码(Exponent) $E$: $E1 + E2$

+   - 修正
+     - 如 $M \ge 2$, 将 $M$ 右移(1位), $E$ 加1
+     - 如 $E$ 超出范围，则溢出
+     - 将 $M$ 舍入，以符合小数部分的要求
