# 浮点数的表示

+   Normal format（规格化数形式）：
+   +/-1.xxxxxxxxx × R^Exponent

为了能表示更多有效数字，通常规定规格化数的小数点前为1！

+   32-bit 规格化数：

| 31 | 0 |
| S | Exponent | Significand |
| 1 bit | ? bits | ? bits |

S 是符号位（Sign）

Exponent 用移码（增码）来表示

Significand 表示 xxxxxxxxxxxxxx（部分尾数）

（基可以是 2/4/8/16，约定信息，无需显式表示）

+   早期的计算机，各自定义自己的浮点数格式
