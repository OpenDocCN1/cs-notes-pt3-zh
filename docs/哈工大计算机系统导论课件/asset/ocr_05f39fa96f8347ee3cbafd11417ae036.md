# HCL操作

+   - 根据返回值的类型分类

# 布尔表达式

+   - 逻辑操作
+     - a && b, a || b, !a

+   - 字的比较
+     - A == B, A != B, A < B, A <= B, A >= B, A > B

+   - 集合关系
+     - A in { B, C, D }
+     - 等同于 A == B || A == C || A == D

# 整数表达式

+   - 表达式实例
+     - 情况表达式 [ a : A; b : B; c : C ]
+     - 依次测试选择表达式 a, b, c, ...等等
+     - 当首个选择表达式测试通过后返回相应的情况 A, B 或 C, ...
