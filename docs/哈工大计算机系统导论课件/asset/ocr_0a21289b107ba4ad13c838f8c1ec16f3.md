# 存储器层次结构

更小
更快和
（每字节）
成本更高的存储设备

更大
更慢和
（每字节）
成本更低的存储设备

L0: 寄存器
CPU寄存器保存着从高速缓存存储器取出的字

L1: 高速缓存 (SRAM)
L1高速缓存保存着从L2高速缓存取出的缓存行

L2: 高速缓存 (SRAM)
L2高速缓存保存着从L3高速缓存取出的缓存行

L3: 高速缓存 (SRAM)
L3高速缓存保存着从主存高速取出 的缓存行

L4: 主存 (DRAM)
主存保存着从本地磁盘取出的磁盘块

L5: 本地二级存储 (本地磁盘)
本地磁盘保存着从远程网络服务器磁盘上取出的文件

L6: 远程二级存储
(分布式文件存储，Web服务器)
