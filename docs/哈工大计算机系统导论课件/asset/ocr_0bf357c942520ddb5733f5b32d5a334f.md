# 过程的机制

+   - 传递控制
+     - 调用：转到过程代码的起始处
+     - 结束：回到返回点

+   - 传递数据
+     - 过程参数
+     - 返回值

+   - 内存管理
+     - 过程运行期间申请
+     - 返回时解除分配

+   - 该机制全部由机器指令实现

+   - x86-64 过程的实现只是使用了这些机制

```
P(...) {
  ...
  y = Q(x);
  print(y)
  ...
}
```

  int t = 3*i;
