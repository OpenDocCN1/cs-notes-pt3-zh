# PIPE的CPI（续）

B/I = LP + MP + RP

# Typical Values

+   - LP:由加载/使用冒险停顿产生的处罚
+     - 加载指令的比例
+     - 加载指令需要停顿的比例
+     - 每次插入气泡的数量
+     - ⇒ LP = 0.25 * 0.20 * 1 = 0.05

+   - MP:由错误的分支预测产生的处罚
+     - 条件转移指令的比例
+     - 条件转移预测错误的比例
+     - 每次插入气泡的数量
+     - ⇒ MP = 0.20 * 0.40 * 2 = 0.16

+   - RP:由ret指令产生的处罚
+     - 返回指令站的比例
+     - 每次插入的气泡数量
+     - ⇒ RP = 0.02 * 3 = 0.06
