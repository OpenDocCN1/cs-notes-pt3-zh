# 浮点数习题答案

+   - x == (int)(float) x    No: 24 位尾数
+   - x == (int)(double) x    Yes: 53位尾数
+   - f == (float)(double) f    Yes: 增加精度
+   - d == (float) d    No: 损失精度
+   - f == -(-f);    Yes: 仅仅改变符号位
+   - 2/3 == 2/3.0    No: 2/3 == 0
+   - d < 0.0 ⇒ ((d*2) < 0.0)    Yes!
+   - d > f ⇒ -f < -d    Yes
+   - d *d >= 0.0    Yes!
+   - (d+f)-d == f    No: 不具备结合性
