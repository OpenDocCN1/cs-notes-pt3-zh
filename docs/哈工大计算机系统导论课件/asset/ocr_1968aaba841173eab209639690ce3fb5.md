# # Linux汇编程序——两种格式的语法对比

+   • 两种汇编格式: AT&T 汇编、Intel汇编

+   1、寄存器前缀%
+   AT&T: %eax
+   Intel: eax

+   2、源/目的操作数顺序
+   AT&T: movl %eax,%ebx
+   Intel: mov ebx,eax

+   3、常量/立即数的格式 $
+   AT&T: movl $_value, %ebx #把变量_value的地址放入ebx
+   movl $0xd00d, %ebx
+   Intel: mov eax, offset _value
+   mov ebx,0xd00d

+   4、操作数长度标识符:b-1字节, w-2 字节, l-4 字节,q-8字节
+   AT&T: movw var_x, %bx
+   Intel: mov bx, word ptr var_x
