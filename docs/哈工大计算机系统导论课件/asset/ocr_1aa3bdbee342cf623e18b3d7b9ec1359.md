# 特殊值

+   - 条件: exp = 111...1
+   - 情况3: exp = 111...1, frac = 000...0
+     - 表示 无穷(infinity) ∞
+     - 溢出的运算
+     - 正无穷、负无穷

浮点数除0的结果是 +/- ∞, 而不是溢出异常。(整数除0为异常)

为什么要这样处理? ∞ : infinity

+   - 可以利用+∞/-∞作比较。 例如：X/0>Y可作为有效比较

How to represent +/-/-∞?

+   - Exponent : all ones (11111111B = 255)
+   - Significand: all zeros

+∞ : 0 11111111 00000000000000000000000
-∞ : 1 11111111 00000000000000000000000

相关操作：

5.0 / 0 = +∞,      -5.0 / 0 = -∞
5+(+∞) = +∞,      (+∞)+(+∞) = +∞
5 - (+∞) = -∞,      (-∞) - (+∞) = -∞      etc
