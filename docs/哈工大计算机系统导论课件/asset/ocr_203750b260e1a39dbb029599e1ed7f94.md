# mov 的操作数组合

| 源 | 目的 | 源操作数，目的操作数 | C语言模拟 |
|---|---|---|---|
| movq | Imm | Reg | movq $0x4, %rax | temp = 0x4; |
|  |  | Mem | movq $-147, (%rax) | *p = -147; |
|  | Reg | Reg | movq %rax, %rdx | temp2 = temp1; |
|  |  | Mem | movq %rax, (%rdx) | *p = temp; |
|  | Mem | Reg | movq (%rax), %rdx | temp = *p; |

单条指令不能进行从内存到内存的数据传送
