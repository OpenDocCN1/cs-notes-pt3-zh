# # 复杂运算简化 Reduction in Strength

+   - 用更简单的方法替换昂贵的操作
+   - 移位，而不是是乘法或除法
+     16*x --> x << 4
+   - 基于机器的实际运用
+   - 取决于乘法或除法指令的成本
+     - 在Intel Nehalem,整数乘需要3个CPU周期

```
```c
for (i = 0; i < n; i++) {
  int ni = n*i;
  for (j = 0; j < n; j++)
    a[ni + j] = b[j];
}
```
```

```
```c
int ni = 0;
for (i = 0; i < n; i++) {
  for (j = 0; j < n; j++)
    a[ni + j] = b[j];
  ni += n;
}
```
