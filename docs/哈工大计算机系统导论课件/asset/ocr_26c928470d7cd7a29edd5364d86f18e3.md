# 性能目标：最大化内存利用率

+   - 给定n个分配和释放请求的某种顺序:
+     - $R_0, R_1, ..., R_k ..., R_{n-1}$

+   - 定义: 聚集有效载荷(Aggregate payload) $P_k$
+     - `malloc(p)` 分配一个有效载荷p字节的块
+     - 请求 $R_k$ 完成后, 聚集有效载荷 $P_k$ 为当前已分配的块的有效载荷之和

+   - 定义: 堆的当前的大小 $H_k$
+     - 假设 $H_k$ 是单调非递减的
+     - 比如, 只有分配器使用 sbrk 时堆才会增大或减小

+   - 定义: 前 k+1 个请求的峰值利用率
+     - $U_k = (\max_{i \le k} P_i) / H_k$
