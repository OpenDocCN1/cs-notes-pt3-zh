# Y86-64 代码生成示例 2

+   - 然后尝试
+     - 用 C 语言模仿 Y86-64 的代码

```
long len2(long *a){
    long ip = (long) a;
    long val = *(long *) ip;
    long len = 0;
    while (val) {
        ip += sizeof(long);
        len++;
        val = *(long *) ip;
    }
    return len;
}
```

+   - 结果
+     - 编译器生成和之前一模一样的代码
+     - 编译器将两个版本转换成相同的中间形式
