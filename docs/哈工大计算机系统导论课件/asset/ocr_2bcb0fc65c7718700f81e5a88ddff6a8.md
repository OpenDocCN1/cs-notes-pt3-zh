# 巧用异或

半加器： S = A ⊕ B
C = A B

+   - 按位异或是一种加的形式
+   - A ^ A = 0

```
int inplace_swap(int *x, int *y)
{
    *x = *x ^ *y;  /* #1 */
    *y = *x ^ *y;  /* #2 */
    *x = *x ^ *y;  /* #3 */
}
```

A^0 = A
A^1 = ¬ A

| Step | *x | *y |
|---|---|---|
| Begin | A | B |
| 1 | A^B | B |
| 2 | A^B | (A^B)^B = A^(B^B) = A^0 = A |
| 3 | (A^B)^A = (B^A)^A = B^(A^A) = B^0 = B | A |
| End | B | A |
