# 数据传送

+   - 无符号数的条件传送

+   - 用a、b、e、n、c分别表示：大于、小于、等、否、进位

+   - CPU用CF、ZF、PF实现判别

CMOVA/CMOVNBE      大于/小于或者不等于    (CF或者ZF)=0

CMOVAE/CMOVNB      大于或者等于/不小于    CF = 0

CMOVNC             无进位                CF = 0

CMOVB/CMOVNAE      小于/不大于            CF = 1

CMOVC              进位                  CF = 1

CMOVBE/CMOVNA      小于或者等于/不大于    (CF或ZF) = 1
