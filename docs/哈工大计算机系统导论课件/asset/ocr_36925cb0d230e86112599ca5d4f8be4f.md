# 用移位实现无符号数 “除以2的幂”

+   无符号数 “除以2的幂” 的商
+   - u >> k 得到⌊u / 2^k⌋
+   - 使用逻辑右移

操作数：
 u
 / 2^k
除法：
 u / 2^k
结果：
 ⌊u / 2^k⌋
