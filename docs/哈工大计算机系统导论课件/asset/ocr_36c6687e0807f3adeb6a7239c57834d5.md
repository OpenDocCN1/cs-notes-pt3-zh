# 计算序列: ret

|  | ret |  |
|---|---|---|
| 取指 | icode:ifun ← M₁[PC] | 读指令字节 |
| 译码 | valA ← R[%rsp]
valB ← R[%rsp] | 读操作数栈指针
读操作数栈指针 |
| 执行 | valE ← valB + 8 | 栈指针增加 |
| 访存 | valM ← M₈[valA] | 读返回地址 |
| 写回 | R[%rsp] ← valE | 更新栈指针 |
| 更新PC | PC ← valM | PC指向返回地址 |

+   - 从内存中读取返回地址
