# 内存中C数组的布局(回顾)

+   - **C 数组分配按行顺序**
+     - 每行在连续的内存位置
+   - **按行扫描:**
+     - `for (i = 0; i < N; i++)`
+       `sum += a[0][i];`
+     - 访问连续的元素
+     - 如果块大小 (B) > sizeof(a_ij)字节, 利用空间局部性
+       - 不命中率 = sizeof(a_ij) / B
+   - **按列扫描:**
+     - `for (i = 0; i < n; i++)`
+       `sum += a[i][0];`
+     - 访问远隔的元素
+     - 没有空间局部性!
+       - 不命中率 = 1 (i.e. 100%)
