# 嵌套数组行访问代码

![](bbox=[0.07, 0.2, 0.78, 0.32])

```
int *get_pgh_zip(int index){
    return pgh[index];
}
```

行索引

返回一个指针，
行地址

```
# %rdi = index
leaq (%rdi,%rdi,4),%rax      # 5 * index
leaq pgh,(%rax,4),%rax # pgh + (20 * index)
```

+   行向量

+   pgh[index]：有5个整数的数组

+   起始地址 pgh+20*index

+   机器代码

+   计算和返回地址: pgh + 4*(index+4*index)
