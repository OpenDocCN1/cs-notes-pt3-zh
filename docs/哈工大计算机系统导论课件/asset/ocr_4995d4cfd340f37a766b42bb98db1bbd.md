# IMUL指令的多操作数形式

+   IMUL指令的多操作数格式
+     双操作数：2个操作数的积保存到第2个操作数
+       IMUL r16/m16/imm8/imm16, r16
+       IMUL r32/m32/imm8/imm32, r32
+     三操作数：前2个操作数的积保存到第3个操作数
+       IMUL imm8/16, r16/m16, r16
+       IMUL imm8/32, r32/m32, r32

第三个操作数必须是寄存器

会根据目的操作数的大小裁减乘积

如果有效位丢失，则设置CF和OF

需要检查CF、OF，以防结果溢出
