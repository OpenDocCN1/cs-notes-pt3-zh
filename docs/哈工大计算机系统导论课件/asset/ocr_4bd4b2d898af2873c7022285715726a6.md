# ALU 操作

+   - **OPI rA, rB**
+     执行 valE ← valB OP valA
+     执行ALU的操作
+   
+   - **cmovXX rA, rB**
+     执行 valE ← 0 + valA
+     通过ALU传送数据A
+   
+   - **rmmovl rA, D(rB)**
+     执行 valE ← valB + valC
+     计算有效地址
+   
+   - **popq rA**
+     执行 valE ← valB + 8
+     增加栈指针的值
+   
+   - **jXX Dest**
+     执行 
+     无操作
+   
+   - **call Dest**
+     执行 valE ← valB + -8
+     减少栈指针的值
+   
+   - **ret**
+     执行 valE ← valB + 8
+     增加栈指针的值
