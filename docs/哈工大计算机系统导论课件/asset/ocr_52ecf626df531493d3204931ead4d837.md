# 与子进程同步：wait

+   - 父进程通过wait函数回收子进程
+   - int wait(int *child_status)
+     - 挂起当前进程的执行直到它的一个子进程终止
+     - 返回已终止子进程的 pid
+     - 如 child status != NULL, 则在该指针指向的整型量中写入关于终止原因和退出状态的信息):
+       - 用wait.h头文件中定义的宏来检查
+         - WIFEXITED, WEXITSTATUS, WIFSIGNALED, WTERMSIG, WIFSTOPPED, WSTOPSIG, WIFCONTINUED
