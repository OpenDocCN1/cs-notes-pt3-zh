# 2.1.7 C语言中的位级运算

+   C语言中的位运算： &, |, ~, ^

+   适用于任何整型数据类型： long, int, short, char, unsigned

+   将操作数视为位向量

+   将参数按位运算

# 例子(char 类型)

+   ~0x41 → 0xBE

+   ~01000001₂ →10111110₂

+   ~0x00 → 0xFF

+   ~00000000₂ →11111111₂

+   0x69 & 0x55 →0x41

+   01101001₂ & 01010101₂ →01000001₂

+   0x69 | 0x55 →0x7D

+   01101001₂ | 01010101₂ →01111101₂
