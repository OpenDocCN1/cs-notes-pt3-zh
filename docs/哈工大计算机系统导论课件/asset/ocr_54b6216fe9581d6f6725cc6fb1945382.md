# ① 串拷贝指令

```
.data
string1 : .asciz "this is a example\r\n"
count = . - string1 # 字串长度
.bss
.comm string2, count
.text
cld
mov $string1,%rsi # esi
lea string2,%rdi # edi
mov $count, %ecx
rep movsb
```

+   1. cld/std设定每次执行movsb指令时，rdi/edi, rsi/esi变化的方向；
+   2. rep: □先检测ecx>0?, 如=0则执行下一条指令, 否则ecx--, 执行movsb
+   3. movsb: 会自动将rdi/edi、rsi/esi值增加/减小
