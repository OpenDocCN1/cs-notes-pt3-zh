# 布尔代数(Boolean Algebra)

# 与(And)

+   当A=1 并且 B=1时， A&B = 1

| & | 0 | 1 |
|---|---|---|
| 0 | 0 | 0 |
| 1 | 0 | 1 |

# 或(Or)

+   当A=1 或 B=1时， A|B = 1

| | 0 | 1 |
|---|---|---|
| 0 | 0 | 1 |
| 1 | 1 | 1 |

# □(Not)

+   当A=0时， ~A = 1

| ~ | |
|---|---|
| 0 | 1 |
| 1 | 0 |

# 异或(Exclusive-Or,Xor)

+   当A=1 或 B=1且两者不同时为1， A^B = 1

| ^ | 0 | 1 |
|---|---|---|
| 0 | 0 | 1 |
| 1 | 1 | 0 |
