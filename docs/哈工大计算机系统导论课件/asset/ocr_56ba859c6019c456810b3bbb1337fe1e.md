# 正确的信号处理

+   - 必须回收所有终止的子进程
+   - 将 wait 放入一个循环回收所有终止的子进程

```
void child_handler2(int sig)
{
	int olderrno = errno;
	pid_t pid;
	while ((pid = wait(NULL)) > 0) {
		ccount--;
		Sio_puts("Handler reaped child ");
		Sio_putl((long)pid);
		Sio_puts("\n");
	}
	if (errno != ECHILD)
		Sio_error("wait error");
	errno = olderrno;
}
```
