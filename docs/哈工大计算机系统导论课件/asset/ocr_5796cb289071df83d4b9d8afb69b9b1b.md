# 浮点数的例子

```
int main()
{
    float f;

    for(;;)
    {
        printf("请输入一个浮点数:");
        scanf("%f",&f);
        printf("这个浮点数的值是:%f\n",f);
        if(f==0) break;
    }
    return 0;
}
```

61.419998和61.420002是两个可表示数，两者之间相差0.000004。当输入数据是一个不可表示数时，机器将其转换为最邻近的可表示数。
