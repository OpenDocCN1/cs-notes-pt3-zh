# 数据传送

+   - 传递指令
+     `movx src, dst`
+     *x*: 空白或b,w,l,q, 分别对应1/2/4/8字节操作数
+   - 操作数类型(三大类)
+     - 立即数(Immediate): 整型常数
+     - 寄存器(Register): 16个整数寄存器之一
+       - 不能用%rsp（系统保留）
+       - 其他特殊指令专用寄存器
+     - 内存(Memory): 多种寻址模式
+       `movb $1, %al`
+       `movw $1, %ax`
+       `movl $1, %eax`
+       `movq $1, %rax`
+       `movq $1, %r8`
