# 传送指令示例

X86-64

```
movq $0xabcd, %rdx
```

Y86-64

```
irmovq $0xabcd, %rdx
```

编码： 30 f2 cd ab 00 00 00 00 00 00

```
movq %rsp, %rbx
```

```
rrmovq %rsp, %rbx
```

编码： 20 43

```
movq -12(%rbp),%rcx
```

```
mrmovq -12(%rbp),%rcx
```

编码： 50 15 f4 ff ff ff ff ff ff ff

```
movq %rsi,0x41c(%rsp)
```

```
rmmovq %rsi,0x41c(%rsp)
```

编码： 40 64 1c 04 00 00 00 00 00 00
