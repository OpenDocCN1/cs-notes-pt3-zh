# 汇编器

+   - 将 .s 翻译成 .o
+   - 指令的二进制编码
+   - 几乎完整的可执行代码映像
+   - 缺少不同文件代码之间的联系

# 连接器

+   - 解析文件之间的引用
+   - 与静态运行库相结合
+     - 例如, malloc, printf的运行库
+   - 动态链接库
+     - 程序开始执行时，在进行链接
