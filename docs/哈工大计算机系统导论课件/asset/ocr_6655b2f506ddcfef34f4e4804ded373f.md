# 存储器层次结构

更小、
更快、
更贵
(每字节)
的存储设备

更大、
更慢、
更廉价
(每字节)

L0:
寄存器

L1:
L1 高速缓存
(SRAM)

L2:
L2 高速缓存
(SRAM)

L3:
L3 高速缓存
(SRAM)

L4:
主存
(DRAM)

L5:
本地二级存储
(本地磁盘)

L6:
远程二级存储
(分布式文件系统、Web 服务器)

CPU 寄存器保存着从L1高速缓存取出的字

L1 高速缓存保存着从L2高速缓存取出的缓存行

L2 高速缓存保存着从L3高速缓存取出的缓存行

L3 高速缓存保存着从主存取出的缓存行

主存保存着从磁盘取出的磁盘块

本地磁盘保存着从远程服务器磁盘上取出的文件
