# 数据A
送ALU

|  |  |  |
|---|---|---|
|  | OPq rA, rB | 执行ALU的操作 |
| 执行 | valE ← valB OP valA |  |
|  | cmovXX rA, rB | 通过ALU传送数据A |
| 执行 | valE ← 0 + valA |  |
|  | rmmovq rA, D(rB) | 计算有效地址 |
| 执行 | valE ← valB + valC |  |
|  | popq rA | 增加栈指针的值 |
| 执行 | valE ← valB + 8 |  |
|  | jXX Dest | 无操作 |
| 执行 |  |  |
|  | call Dest | 减少栈指针的值 |
| 执行 | valE ← valB + -8 |  |
|  | ret | 增加栈指针的值 |
| 执行 | valE ← valB + 8 |  |

```
int aluA = [
    icode in { IRRMOVQ, IOPQ } : valA;
    icode in { IIRMOVQ, IRMMOVQ, IMRMOVQ } : valC;
    icode in { ICALL, IPUSHQ } : -8;
    icode in { IRET, IPOPQ } : 8;
    # 其他指令不需要ALU
];
```
