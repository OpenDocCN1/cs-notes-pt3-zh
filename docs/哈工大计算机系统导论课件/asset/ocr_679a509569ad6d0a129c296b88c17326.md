# 数组的访问

# 基本准则

```
T A[L];
```

+   - 数据类型T、长度L的数组
+   - 标识符A可作为数组元素0的指针(常量): Type T*

```
int val[5];
```

![](bbox=[0.32, 0.42, 0.9, 0.58])

+   - 引用形式 类型 数值
+     val[4] int 3
+     val int * x
+     val+1 int * x + 4
+     &val[2] int * x + 8
+     val[5] int ??
+     *(val+1) int 5
+     val + i int * x + 4 i
