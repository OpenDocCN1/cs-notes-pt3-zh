# 核对金丝雀

调用gets后

| call_echo 的栈帧 |
| 返回地址 (8 bytes) |
|  |
| 金丝雀 (8 bytes) |
| 00 36 35 34 |
| 33 32 31 30 |

```
/* Echo Line */
void echo(){
    char buf[4]; /* Way too small! */
    gets(buf);
    puts(buf);
}
```

```
echo:
    ...
    movq 8(%rsp), %rax    # Retrieve from stack
    xorq %fs:40, %rax     # Compare to canary
    je   .L6              # If same, OK
    call __stack_chk_fail # FAIL
.L6:
    ...
```

buf ← %rsp

Input: 0123456
