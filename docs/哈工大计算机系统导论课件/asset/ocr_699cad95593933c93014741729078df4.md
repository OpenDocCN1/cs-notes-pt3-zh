# # 数据传送的例子

+   - 全局变量定义：
+   
+   ``` 
+   varx:
+   .int 124,-2345
+   ```

+   - 汇编指令
+   
+   ``` 
+   mov $ -1, %rax  # %rax = 0xffffffff ffffffff = -1
+   movq $varx, %rax  # %rax = 0x4000ac
+   mov varx, %ebx  # %rbx = 0x7c = 124
+   mov varx+4, %ecx  #%rcx = fffff6d7 = -2345
+   mov (%rax), %edx  # %rdx = 0x7c = 124
+   ```
