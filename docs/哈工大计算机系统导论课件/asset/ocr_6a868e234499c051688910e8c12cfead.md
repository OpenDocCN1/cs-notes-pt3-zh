# 非规格化数

v = (-1)^s M 2^E
E = 1 - Bias

+   - 条件: exp = 000...0
+     - 阶码(Exponent) 值: E = 1 - Bias (instead of E = 0 - Bias)
+     - 尾数(Significand)编码隐含先导数值0: M = 0.xxx...x2
+       - xxx...x:是 frac字段的数码

+   - 情况1: exp = 000...0, frac = 000...0
+     - 表示值0
+     - 注意有不同的数值 +0 和 -0 (why?)

+0: 0 00000000 00000000000000000000000
-0: 1 00000000 00000000000000000000000
