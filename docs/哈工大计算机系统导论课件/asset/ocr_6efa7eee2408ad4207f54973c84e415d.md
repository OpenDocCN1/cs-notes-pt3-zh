# 数组例子

```
#define ZLEN 5
typedef int zip_dig[ZLEN];
zip_dig cmu = { 1, 5, 2, 1, 3 };
zip_dig mit = { 0, 2, 1, 3, 9 };
zip_dig ucb = { 9, 4, 7, 2, 0 };
```

zip_dig cmu;

16 20 24 28 32 36

zip_dig mit;

36 40 44 48 52 56

zip_dig ucb;

56 60 64 68 72 76

+   声明 “zip_dig cmu”等价于 “int cmu[5]”

+   示例数组申请20个连续的内存字节(sizeof(cmu) or sizeof(zip_dig))
