# 可重定位目标文件格式

ELF 头

+   包括16字节标识信息、文件类型 (.o, exec, .so)、机器类型（如 IA-32）、节头表的偏移、节头表的表项大小以及表项个数

.text 节

+   编译后的代码部分

.rodata 节

+   只读数据，如 printf 格式串、switch 跳转表等

.data 节

+   已初始化的全局变量

.bss 节

+   未初始化全局变量，仅是占位符，不占据任何实际磁盘空间。区分初始化和非初始化是为了空间效率
