# 浮点数加法

+   - $(-1)^{s1} M1\ 2^{E1} + (-1)^{s2} M2\ 2^{E2}$
+     - 假设 $E1 > E2$

+   - 准确结果: $(-1)^{s} M\ 2^{E}$
+     - 符号 $s$, 尾数 $M$:
+       - 有符号数对齐、相加的结果
+     - 阶码(Exponent) $E$: $E1$

+   - 修正
+     - $M \ge 2$: 将 $M$ 右移(1位), $E$ 加1
+     - $M < 1$: 将 $M$ 左移 $k$ 位, $E$ 减 $k$
+     - $E$ 超范围: 溢出
+     - 将 $M$ 舍入, 以符合小数部分的要求
