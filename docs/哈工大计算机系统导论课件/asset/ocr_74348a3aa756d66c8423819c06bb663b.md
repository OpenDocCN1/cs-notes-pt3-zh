# 机器数转换为真值

已知float型变量x的机器数为BEE00000H，求x的值是多少？

```
1 011 11101 110 0000 0000 0000 0000 0000
```

(-1)^S x (1 + Significand) x 2^(Exponent-127)

+   • 数符: 1（负数）
+   • 阶（指数）：
+     • 阶码: 0111 1101B = 125
+     • 阶码的值: 125 - 127 = -2
+   • 尾数数值部分:
+     1 + 1x2^-1 + 1x2^-2 + 0x2^-3 + 0x2^-4 + 0x2^-5 +...
+     =1+2^-1 +2^-2 = 1+0.5 +0.25 = 1.75
+   • 真值: -1.75x2^-2 = - 0.4375

为避免混淆，用阶码表示阶的编码，用阶或指数表示阶码的值
