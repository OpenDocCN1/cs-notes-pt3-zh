# 读取条件码(续...)

+   - **setX 指令:**
+     - 根据条件码组合,设置单个字节的数值
+   - **可寻址的单字节寄存器**
+     - 不改变寄存器其他字节的数值
+     - 常用指令 `movzbl` 将单字节值零扩展至整个8字节寄存器
+       - 或者用32位指令将寄存器高位置0

```
int gt (long x, long y)
{ return x > y; }
```

```
cmpq %rsi, %rdi # Compare x:y
setg %al # Set when >
movzbl %al, %eax # Zero rest of %rax
ret
```

| 寄存器 | 用途 |
|---|---|
| %rdi | 参数x |
| %rsi | 参数y |
| %rax | 返回值 |
