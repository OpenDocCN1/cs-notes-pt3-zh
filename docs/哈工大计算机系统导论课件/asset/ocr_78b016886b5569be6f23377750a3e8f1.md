# 流水线功能单元

```
long mult_eg(long a, long b, long c) {
    long p1 = a*b;
    long p2 = a*c;
    long p3 = p1 * p2;
    return p3;
}
```

![](bbox=[0.68, 0.065, 0.935, 0.415])

| | Time |
| | 1 | 2 | 3 | 4 | 5 | 6 | 7 |
| 阶段 1 | a*b | a*c |  |  | p1*p2 |  |  |
| 阶段 2 |  | a*b | a*c |  |  | p1*p2 |  |
| 阶段 3 |  |  | a*b | a*c |  |  | p1*p2 |

+   - 把计算分解为多个阶段
+   - 一个阶段又一个阶段地通过各部件计算
+   - 一旦值传送给阶段 i+1，阶段 i 就能开始新的计算，
+   - 例如，即使每个乘法需要3个周期，在7个周期里完成3个乘法
