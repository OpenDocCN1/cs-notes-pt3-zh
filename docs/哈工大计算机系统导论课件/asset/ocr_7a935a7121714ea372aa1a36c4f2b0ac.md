# 程序示例: 向量数据结构

```
/* data structure for vectors */
typedef struct{
    size_t len;
    data_t *data;
} vec;
```

# 数据类型

+   - 使用 data_t的不同声明
+   - int
+   - long
+   - float
+   - double

```
/* retrieve vector element
and store at val */
int get_vec_element
(*vec v, size_t idx, data_t *val)
{
    if (idx >= v->len)
        return 0;
    *val = v->data[idx];
    return 1;
}
```
