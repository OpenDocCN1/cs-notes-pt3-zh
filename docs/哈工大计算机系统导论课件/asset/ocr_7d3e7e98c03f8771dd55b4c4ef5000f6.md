# Y86-64 处理器状态

RF: 程序寄存器
(Program registers)

| %rax | %rsp | %r8 | %r12 |
| %rcx | %rbp | %r9 | %r13 |
| %rdx | %rsi | %r10 | %r14 |
| %rbx | %rdi | %r11 |  |

CC: 条件码
(Condition codes)

ZF SF OF

PC

Stat: 程序状态
(Program status)

DMEM: 内存
(Memory)

+   - 程序寄存器
+     - 15 个寄存器(除了 %r15)，每个64位

+   - 条件码
+     - 由算术指令或逻辑指令设置的1-bit 标识(flag)
+       - ZF: 零(Zero)    SF:负（Negative）OF: 溢出(Overflow)
