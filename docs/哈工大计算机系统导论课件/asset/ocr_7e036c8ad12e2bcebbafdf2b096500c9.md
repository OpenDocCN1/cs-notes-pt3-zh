# 为什么用二进制？

+   - 十进制——适合人类使用
+     - 有10个手指的人类
+     - 1000年前源自印度、12世纪发展于阿拉伯、13世纪到西方
+   - 二进制——更适合机器使用
+     - 容易表示、存储
+       - 打孔纸带上是/否有空
+       - 磁场的顺时针/逆时针
+     - 容易传输
+       - 导线上的电压高/低
+       - 可以在有噪声、不精确的电路上可靠传输
