# 虚拟地址空间

Linux在X86上的虚拟地址空间（其他Unix系统的设计类似）

+   - 内核空间（Kernel）
+   - 用户栈（User Stack）
+   - 共享库（Shared Libraries）
+   - 堆（heap）
+   - 可读写数据（Read/Write Data）
+   - 只读数据（Read-only Data）
+   - 代码（Code）

问题：加载时是否真正从磁盘调入信息到主存？

实际上不会从磁盘调入，只是将虚拟页和磁盘上的数据代码建立对应关系，称为“映射”。
