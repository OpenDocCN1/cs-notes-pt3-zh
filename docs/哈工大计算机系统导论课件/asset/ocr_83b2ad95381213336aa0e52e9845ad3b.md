# 磁盘容量

+   - **容量(Capacity)**: 磁盘上可以存储的最大位数(bits)数。
+     - 制造商以千兆字节(GB)为单位来表达磁盘容量，这里
+       1 GB = 10^9 字节。

+   - **磁盘容量由以下技术因素决定：**
+     - **记录密度(Recording density)** (位/英寸): 磁道一英寸的段中可放入的位数。
+     - **磁道密度(Track density)** (道/英寸): 从盘片中心出发半径上一英寸的段内可以有的磁道数。
+     - **面密度(Areal density)** (位/平方英寸): 记录密度与磁道密度的乘积。
