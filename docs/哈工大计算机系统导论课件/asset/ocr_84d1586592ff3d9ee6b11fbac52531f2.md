# x86-64 Linux 内存布局

+   - 栈(Stack)
+     - 运行栈 (8MB limit)
+     - 涉及局部变量

+   - 堆(Heap)
+     - 按需动态分配
+     - 时机:调用malloc(), calloc(), new()时

+   - 数据(Data)
+     - 静态分配的内存中保存的数据
+     - 全局变量、 static变量、 字符串常量

+   - 代码/共享库(Text / Shared Libraries)
+     - 只读的可执行的机器指令
