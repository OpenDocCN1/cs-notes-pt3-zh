# 浮点数习题

+   - 针对下列c表达式:
+   - 证明对所有参数值都成立
+   - 或什么条件下不成立

```
int x = ...;
float f = ...;
double d = ...;
```

假设d和f都不是NaN

+   - x == (int)(float) x
+   - x == (int)(double) x
+   - f == (float)(double) f
+   - d == (double)(float) d
+   - f == -(-f);
+   - 2/3 == 2/3.0
+   - d < 0.0 ⇒ ((d*2) < 0.0)
+   - d > f ⇒ -f > -d
+   - d * d >= 0.0
+   - (d+f)-d == f
