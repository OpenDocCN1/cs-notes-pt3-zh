# RISC 指令集

+   - 精简指令集计算机
+   - IBM的内部项目，后来被 Hennessy (斯坦福大学) 和 Patterson (伯克利大学)推广
+   - **更少、更简单的指令**
+     - 需要用更多的指令来完成任务
+     - 可以用小且快速的硬件来执行
+   - **基于寄存器的指令集**
+     - 更多（一般32个）的寄存器
+     - 用于存储参数、返回指针和临时存储
+   - **仅加载（load）和存储(store)指令能够访存**
+     - 与Y86-64中的 mrmovq 和 rmmovq 类似
+   - **没有条件码：测试指令用寄存器返回0或1**
