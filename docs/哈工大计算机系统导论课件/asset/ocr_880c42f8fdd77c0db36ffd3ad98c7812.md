# 面向返回的编程攻击（ROP，return oriented programming）

+   - **挑战(对黑客)**
+     - 栈随机化使缓冲区位置难以预测。
+     - 标记栈为不可执行，很难插入二进制代码
+   - **替代策略**
+     - 使用已有代码
+       - 例如：stdlib的库代码
+     - 将片段串在一起以获得总体期望的结果。
+     - 不用克服栈金丝雀
+   - **从小工具构建攻击程序**
+     - 以ret结尾的指令序列
+       - 单字节编码为0xc3
+     - 每次运行，**代码的位置固定**
+     - **代码可执行**
