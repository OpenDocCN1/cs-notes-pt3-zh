# 16 X 16 矩阵的访问

+   数组元素 A[i][j]
+   地址: A + i * (C * K) + j * K
+   C = 16, K = 4

```
/* 获得元素a[i][j] */
int fix_ele(fix_matrix a, size_t i, size_t j) {
    return a[i][j];
}
```

```
# a in %rdi, i in %rsi, j in %rdx
salq $6, %rsi        # 64*i
addq %rsi, %rdi      # a + 64*i
movl (%rdi,%rdx,4), %eax # M[a + 64*i + 4*j]
ret
```
