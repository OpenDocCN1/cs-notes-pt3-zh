# 用移位实现有符号数“除以2的幂”

+   - **有符号数“除以2的幂”的商**
+     - `x >> k` 得到 `⌊x / 2^k⌋`
+     - 使用算术右移
+     - 当 `x < 0` 时，舍入方向出错
