# 特殊值

+   - 条件: exp = 111...1

+   - 情况4: exp = 111...1, frac ≠ 000...0

+   - 表示：不是一个数 Not-a-Number (NaN)

表示没有数值结果（非实数或无穷），例如：
sqrt(-1), ∞ - ∞, ∞ × 0      Sqrt (- 4.0) = ?      0/0 = ?
- 称为 Not a Number (NaN) - “非数”

How to represent NaN

Exponent = 255

Significand: nonzero

NaNs 可以帮助调试程序

相关操作：

sqrt (-4.0) = NaN        0/0 = NaN
op (NaN,x) = NaN        +∞ +(-∞) = NaN
+∞ - (+∞) = NaN        ∞/∞ = NaN
etc.
