# 分别累加的效果

| 方法 | Integer |  | Double FP |  |
| 操作 | + | * | + | * |
| Combine4 | 1.27 | 3.01 | 3.01 | 5.01 |
| Unroll 2x1 | 1.01 | 3.01 | 3.01 | 5.01 |
| Unroll 2x1a | 1.01 | 1.51 | 1.51 | 2.51 |
| Unroll 2x2 | 0.81 | 1.51 | 1.51 | 2.51 |
| 延迟界限 | 1.00 | 3.00 | 3.00 | 5.00 |
| 吞吐量界限 | 0.50 | 1.00 | 1.00 | 0.50 |

+   整数加 + 使用了两个加载单元

```
x0 = x0 OP d[i];
x1 = x1 OP d[i+1];
```

+   2倍速度提升： Int *, FP +, FP *
