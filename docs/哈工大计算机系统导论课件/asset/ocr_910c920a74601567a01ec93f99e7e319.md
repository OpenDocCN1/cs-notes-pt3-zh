# Review of Symbols符号回顾

+   - 基本参数
+     - N = 2^n: 虚拟地址空间中的地址数量
+     - M = 2^m: 物理地址空间中的地址数量
+     - P = 2^p: 页的大小 (bytes)
+   - 虚拟地址组成部分
+     - TLBI: TLB索引
+     - TLBT: TLB 标记
+     - VPO: 虚拟页面偏移量 (字节)
+     - VPN: 虚拟页号
+   - 物理地址组成部分
+     - PPO:物理页面偏移量 (same as VPO)
+     - PPN:物理页号
+     - CO: 缓冲块内的字节偏移量
+     - CI: Cache 索引
+     - CT: Cache 标记
