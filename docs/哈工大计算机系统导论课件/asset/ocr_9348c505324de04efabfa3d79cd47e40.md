# 递归函数的寄存器保存

```
/* Recursive pcount */
long pcount_r(unsigned long x) {
  if (x == 0)
    return 0;
  else
    return (x & 1) + pcount_r(x >> 1);
}
```

| 寄存器 | 用途 | 类型 |
|---|---|---|
| %rdi | x | 参数 |

![](bbox=[0.357, 0.691, 0.623, 0.947])

```
pcount_r:
  movl   $0, %eax
  testq  %rdi, %rdi
  je     .L6
  pushq  %rbx
  movq   %rdi, %rbx
  andl   $1, %ebx
  shrq   %rdi # (by 1)
  call   pcount_r
  addq   %rbx, %rax
  popq   %rbx
.L6:
  rep; ret
```
