# 2.2.5 C语言中的有符号数和无符号数

+   - **常量**
+     - 数字□认是有符号数
+     - 无符号数用后缀“U”
+       - `0U, 4294967259U`

+   - **类型转换**
+     - 显示的强制类型转换
+       ```c
+       int tx, ty;
+       unsigned ux, uy;
+       tx = (int) ux;
+       uy = (unsigned) ty;
+       ```
+     - 隐式的类型转换（赋值、函数调用等情况下发生）
+       ```c
+       tx = ux;
+       uy = ty;
+       ```
