# 2.1.9 C语言中的移位运算

+   - 左移： x << y
+   - 将位向量x向左移动 y位
+     - 扔掉左边多出(移出)的位
+     - 在右边补0
+   - 右移： x >> y
+   - 将位向量x向右移动 y位
+     - 扔掉右边多出(移出)的位
+   - 逻辑右移：在左边补0
+   - 算术右移：复制左边的最□位(y次)
+   - 未明确定义
+   - 移位数量 y< 0 或 y ≥ x 的字长(位数)
