# 示例:集合的表示与运算

+   - 表示：位向量表示有限集合
+     - 宽度 w 个比特的位向量[a_{w-1},..., a_1, a_0]表示集合 {0, ..., w-1} 的子集A
+     - a_j = 1 当且仅当 j ∈ A
+       - 01101001  {0, 3, 5, 6}
+         76543210
+       - 01010101  {0, 2, 4, 6}
+         76543210

+   - 运算
+     - &  交集(Intersection)  01000001  {0, 6}
+     - |  并集(Union)  01111101  {0, 2, 3, 4, 5, 6}
+     - ^  对称差集(Symmetric difference)  00111100  {2, 3, 4, 5}
+     - ~  补集(Complement)  10101010  {1, 3, 5, 7}
