# 计算序列: popq

|  | popq rA |  |
|---|---|---|
| 取指 | icode:ifun ← M₁[PC]
rA:rB ← M₁[PC+1]
valP ← PC+2 | 读指令字节
读寄存器字节
计算下一条PC |
| 译码 | valA ← R[%rsp]
valB ← R[%rsp] | 读栈指针
读栈指针 |
| 执行 | valE ← valB + 8 | 栈指针加8 |
| 访存 | valM ← M₈[valA] | 从栈里读数据 |
| 写回 | R[%rsp] ← valE
R[rA] ← valM | 更新栈指针
结果写回 |
| 更新PC | PC ← valP | 更新PC |

+   - 利用ALU来增加栈指针
+   - 必须更新两个寄存器
+     - 弹出的數據
+     - 新的栈指针
