# 加载时动态链接

gcc -c main.c
li bc.so无需明显指出
gcc -o myproc main.o ./myglib.so

调用关系 : main→myfunc1→printf

```
void myfunc1(void);
int main()
{
myfunc1();
return 0;
}
```

加载 myproc 时，加载器发现在其程序头表中有 .interp 段，其中包含了动态链接器路径名 ld-linux.so ，因而加载器根据指定路径加载并启动动态链接器运行。动态链接器完成相应的重定位工作后，再把控制权交给 myproc，启动其第一条指令执行。
