# # 简单的内存寻址模式



形式： (R) 含义： Mem[Reg[R]]

+   - 寄存器R指定内存地址

+   - 比较: C语言的指针解引用

```
movq (%rcx), %rax
```



形式： D(R) 含义： Mem[Reg[R]+D]

+   - 寄存器R指定内存区域的开始地址

+   - D: 常数位移量 “displacement”, 1, 2, or 4 字节指定偏移值 (offset)

```
movq 8(%rbp), %rdx
```

> Bryant and O'Hallaron, Computer Systems: A Programmer's Perspective, Third Edition
