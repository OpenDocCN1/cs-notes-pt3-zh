# 2.1.8 对比: C语言的逻辑运算

+   - C语言的逻辑运算符： &&, ||, !
+   - 将0 视作 逻辑“False(假)”
+   - 所有非0值视作逻辑 “True(真)”
+   - 计算结果总是0 或 1
+   - 提前终止(Early termination)、短路求值(short cut)
+   - 例子(char 数据类型)
+   - !0x41 → 0x00
+   - !0x00 → 0x01
+   - !!0x41 → 0x01
+   - 0x69 && 0x55 → 0x01
+   - 0x69 || 0x55 → 0x01
+   - p && *p (避免空指针访问)
