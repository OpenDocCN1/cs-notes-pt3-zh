# # 二进制制数的舍入

+   - 二进制小数的舍入
+   - “偶数”: 最低有效位值为0
+   - “中间值”: 舍入位置右侧的位都是0，即形如: XXX 100...2

# # 例子

| 数值 | 二进制制 | 舍入后 | 舍入动作 | 舍入后的值 |
|------|----------|--------|----------|------------|
| 2 3/32 | 10.000011₂ | 10.00₂ | (<1/2—down) | 2 |
| 2 3/16 | 10.00110₂ | 10.01₂ | (>1/2—up) | 2 1/4 |
| 2 7/8 | 10.11100₂ | 11.00₂ | ( 1/2—up) | 3 |
| 2 5/8 | 10.10100₂ | 10.10₂ | ( 1/2—down) | 2 1/2 |
