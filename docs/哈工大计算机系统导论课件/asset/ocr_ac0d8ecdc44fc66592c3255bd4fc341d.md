# Intel x86 处理器(续...)

# 机器的演变

+   - 386 1985 0.3M
+   - Pentium 1993 3.1M
+   - Pentium/MMX 1997 4.5M
+   - PentiumPro 1995 6.5M
+   - Pentium III 1999 8.2M
+   - Pentium 4 2001 42M
+   - Core 2 Duo 2006 291M
+   - Core i7 2008 731M

# 增加的特征

+   - 支持多媒体计算的指令
+   - 支持更高效的条件运算指令
+   - 从32位进化到64位
+   - 多核
