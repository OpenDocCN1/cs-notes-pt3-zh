# # 寄存器保存约定

+   - 当进程 `yoo` 调用 `who` 时：
+     - `yoo` 是调用者（caller）
+     - `who` 是被调用者（callee）

+   - 寄存器能否用于临时存储？

```
yoo:
    ...
    movq $15213, %rdx
    call who
    addq %rdx, %rax
    ...
    ret
```

```
who:
    ...
    subq $18213, %rdx
    ...
    ret
```

+   - 寄存器 `%rdx` 的内容被 `who` 覆盖写了

+   - 这样会有问题，如何解决？
+     - 需要调用者（caller）和被调用者（callee）之间的协调
