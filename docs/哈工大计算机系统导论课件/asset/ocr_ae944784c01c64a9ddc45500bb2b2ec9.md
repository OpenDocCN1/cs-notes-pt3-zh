# 数值范围

+   - 无符号数值
+     - UMin = 0
+       000...0
+     - UMax = 2^w − 1
+       111...1

+   - 补码数值
+     - TMin = −2^(w−1)
+       100...0
+     - TMax = 2^(w−1) − 1
+       011...1
+     - -1
+       111...1

# 位数W = 16时的数值

| | 十进制 | 16 进制 | 二进制 |
|---|---|---|---|
| UMax | 65535 | FF FF | 11111111 11111111 |
| TMax | 32767 | 7F FF | 01111111 11111111 |
| TMin | -32768 | 80 00 | 10000000 00000000 |
| -1 | -1 | FF FF | 11111111 11111111 |
| 0 | 0 | 00 00 | 00000000 00000000 |
