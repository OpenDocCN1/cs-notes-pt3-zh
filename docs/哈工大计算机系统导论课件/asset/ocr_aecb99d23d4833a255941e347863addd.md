# 跳转

jX 指令: 根据条件码跳转

| jX指令 | 条件 | 描述 |
|---|---|---|
| jmp | 1 | 无条件 |
| je | ZF | 相等 / 结果为0 |
| jne | ~ZF | 不相等 / 结果不为0 |
| js | SF | 结果为负数 |
| jns | ~SF | 结果为非负数 |
| jg | ~(SF^OF)&~ZF | 大于 (符号数) |
| jge | ~(SF^OF) | 大于等于 (符号数) |
| jl | (SF^OF) | 小于 (符号数) |
| jle | (SF^OF)|ZF | 小于等于 (符号数) |
| ja | ~CF&~ZF | 大于 (无符号数) |
| jb | CF | 小于 (无符号数) |
