# 一般的布尔代数

+   - 位向量操作(Operate on Bit Vectors)
+     - 按位运算
+       01101001 & 01010101
+       01000001
+       01101001 | 01010101
+       01111101
+       ~ 01010101
+       10101010
+       01101001 ^ 01010101
+       00111100

+   - 布尔代数的全部性质均适用
+     - 交换律
+     - 结合律
+     - 分配律：&对|，或者|对&的分配
+     - 加法逆元： a^a = 0(加法为^， a的逆元是它本身)
