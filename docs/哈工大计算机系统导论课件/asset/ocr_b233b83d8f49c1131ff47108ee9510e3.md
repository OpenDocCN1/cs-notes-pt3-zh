# 数组元素访问

# 嵌套数组

```
int get_pgh_digit
(size_t index, size_t digit)
{
    return pgh[index][digit];
}
```

# 多层次数组

```
int get_univ_digit
(size_t index, size_t digit)
{
    return univ[index][digit];
}
```

![](bbox=[0.015, 0.57, 0.97, 0.77])

与C相似，但地址的计算方式完全不同：

Mem[pgh+20*index+4*digit]

Mem[Mem[univ+8*index]+4*digit]
