# 作为预测分支

+   - 取出 2 条目标指令

当预测错误时取消

+   - **在执行阶段检测到未选择该分支**
+   - 在紧跟的指令周期中，将处于执行和译码阶段的指令用气泡替换掉
+   - **此时没有出现副作用**
