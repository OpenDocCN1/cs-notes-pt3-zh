# 跳转表

```
.section .rodata
.align 8
.L4:
    .quad .L8 # x = 0
    .quad .L3 # x = 1
    .quad .L5 # x = 2
    .quad .L9 # x = 3
    .quad .L8 # x = 4
    .quad .L7 # x = 5
    .quad .L7 # x = 6
```

汇编实现：

```
switch_eg:
    movq %rdx, %rcx
    cmpq $6, %rdi   # x:6
    ja  .L8         # Use default
    jmp *.L4(, %rdi, 8) # goto *JTab[x]
```
