# 三、字符串操作指令

+   - 数据串(数组): 以字节、字和双字为单位的多个数据存放在连续的主存区域中
+   - 源操作数：允许段跨越： DS:[ESI]
+   - 目的操作数：不允许段跨越： ES:[EDI]
+   - 每执行一次串操作： ESI和EDI自动±1/2/4/8
+     - 以字节为单位（用B结尾）操作： 地址指针±1
+     - 以字为单位（用W结尾）操作： 地址指针±2
+     - 以双字为单位（用D结尾）操作： 地址指针±4
+     - 以4字为单位（用Q结尾）操作： 地址指针±8
+     - DF=0(执行CLD指令): 地址指针增加（+）
+     - DF=1(执行STD指令): 地址指针减小（-）
