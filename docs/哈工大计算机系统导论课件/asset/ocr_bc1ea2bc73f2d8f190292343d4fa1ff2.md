# # 多重定义符号的解析举例

以下程序会发生链接出错吗？

+   - y一次强定义，一次弱定义
+   - z两次弱定义
+   - p1一次强定义，一次弱定义
+   - main一次强定义

```
```c
# include <stdio.h>
int y=100;
int z;
void p1(void);
int main()
{
z=1000;
p1();
printf( "y=%d, z=%d\n" , y, z);
return 0;
}
```
```

```
```c
int y;
int z;
void p1()
{
y=200;
z=2000;
}
```
```

问题：打印结果是什么？

y=200, z=2000

该例说明：在两个不同模块定义相同变量名，很可能发生意想不到的结果！
