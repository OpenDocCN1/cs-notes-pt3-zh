# 分支预测错误示例

demo-j.ys

```
0x000:    xorq %rax,%rax
0x002:    jne t            # Not taken
0x00b:    irmovq $1, %rax   # Fall through
0x015:    nop
0x016:    nop
0x017:    nop
0x018:    halt
0x019: t: irmovq $3, %rdx   # Target
0x023:    irmovq $4, %rcx   # Should not execute
0x02d:    irmovq $5, %rdx   # Should not execute
```

+   - 只能执行最早的8条指令
