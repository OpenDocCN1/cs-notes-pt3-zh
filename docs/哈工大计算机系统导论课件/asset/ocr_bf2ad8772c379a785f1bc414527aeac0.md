# # 常用用户库

# ## `libc.a`（C标准库）

+   - 4.6 MB 存档文件：1496 目标文件。
+   - I/O，存储器分配，信号处理，字符串处理，日期和时间，随机数，整数数学运算

# ## `libm.a`（C数学库）

+   - 2 MB 存档文件：444 object 目标文件
+   - 浮点数学运算（sin, cos, tan, log, exp, sqrt, ...）
