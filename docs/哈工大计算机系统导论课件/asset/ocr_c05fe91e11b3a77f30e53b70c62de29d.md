# 验证数的表示

+   打印数据字节表示的程序代码

+   将指针转换成unsigned char * 类型，从而按字节数组处理

```
typedef unsigned char *pointer;

void show_bytes(pointer start, size_t len){
    size_t i;
    for(i = 0; i < len; i++)
        printf("%0xp\t %.2x\n",start+i, start[i]);
    printf("\n");
}
```

printf 指令:
%p: 打印指针
%x: 16进制格式打印
