# 回忆: 内存引用的Bug示例

```
```c
typedef struct {
	int a[2];
	double d;
} struct_t;
double fun(int i) {
	volatile struct_t s;
	s.d = 3.14;
	s.a[i] = 1073741824; /* Possibly out of bounds */
	return s.d;
}
```
```

+   fun(1) → 3.14
+   fun(2) → 3.1399998664856
+   fun(3) → 2.00000061035156
+   fun(4) → 3.14
+   fun(6) → Segmentation fault

> 运行结果与系统有关

> Bryant and O'Hallaron, Computer Systems: A Programmer's Perspective, Third Edition
