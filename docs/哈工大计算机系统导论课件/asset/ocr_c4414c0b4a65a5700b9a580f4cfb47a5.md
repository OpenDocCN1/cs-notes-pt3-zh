# Intel的64位CPU发展史

+   - **2001: Intel激进地尝试从IA32跨到IA64**
+     - 采用完全不同的架构(Itanium)
+     - 仅将运行IA32程序作为一种遗产
+     - 性能令人失望
+   - **2003: AMD采用了进化的解决方案**
+     - x86-64 (现在称为 “AMD64”)
+   - **Intel 被动聚焦于IA64**
+     - 难以承认错误或承认AMD更好
+   - **2004: Intel 宣布了IA32的扩充EM64T**
+     - 64位技术的扩展内存
+     - 几乎和x86-64一样
+   - **除了低端x86处理器外，都支持x86-64**
+     - 很多程序依旧运行在32位模式
