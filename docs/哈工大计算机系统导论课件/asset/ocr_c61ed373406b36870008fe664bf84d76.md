# 在运行时的动态链接

```
```c
#include <stdio.h>
#include <stdlib.h>
#include <dlfcn.h>

int x[2] = {1, 2};
int y[2] = {3, 4};
int z[2];

int main()
{
    void *handle;
    void (*addvec) (int *, int *, int *, int);
    char *error;

    /*动态装入包含addvec()的共享库文件*/
    handle = dlopen("./libvector.so", RTLD_LAZY);
    if (!handle) {
        fprintf(stderr, "%s\n", dlerror());
        exit(1);
    }
}
```
```

> 可通过动态链接器提供的函数在运行时进行动态链接
> 
> 类UNIX系统中的动态链接器接口定义了相应的函数，如dlopen、dlsym、dlerror、dlclose等，其头文件为dlfcn.h
