# 基于栈的语言

+   支持递归的语言
+   - C、Pascal、Java
+   - 代码必须可重入“Reentrant”
+     - 单个过程有多个并发实例( simultaneous instantiations )
+   - 需要保存每个实例的状态
+     - 参数
+     - 局部变量
+     - 返回地址

+   栈的使用原则
+   - 有限时间内，保存给定程序的状态：从调用的发生到返回
+   - 被调用者先于调用者返回

+   栈分配单位——帧，栈中单个过程实例的状态数据

> Bryant and O'Hallaron, Computer Systems: A Programmer's Perspective, Third Edition
