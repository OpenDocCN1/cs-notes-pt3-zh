# 接收信号

+   - 假设内核正在从异常处理程序返回，并准备将控制权传递给进程p
+     - 内核检查 `pnb = pending & ~blocked`
+       - 进程p 的未被阻塞的待处理信号的集合
+     - If (pnb == 0) 如果集合为空
+       - 将控制传递到 p 的逻辑控制流中的下一条指令
+     - Else 不为空
+       - 选择集合pnb中最小的非零位k，强制p 接收信号k
+         - 收到信号会触发进程p采取某种行为
+       - 对所有的非零k重复
+       - 控制传递到p 的逻辑控制流中的下一条指令
