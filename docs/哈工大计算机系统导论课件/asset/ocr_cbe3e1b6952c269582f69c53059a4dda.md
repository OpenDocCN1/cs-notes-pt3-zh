# Implicit List: 合并

+   - 合并 (*coalesce*)：合并相邻的空闲块
+     - 和下一个空闲块合并

![](bbox=[0.256, 0.315, 0.843, 0.554])

```
void free_block(ptr p) {
    *p = *p & -2;          // clear allocated flag
    next = p + *p;         // find next allocated block
    if ((*next & 1) == 0)
        *p = *p + *next;   // add to this block if
                           //      not allocated
}
```
