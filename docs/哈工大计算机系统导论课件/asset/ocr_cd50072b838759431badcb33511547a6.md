# MIPS指令格式

所有指令都是32位宽，须按字地址对齐 字地址为4的倍数！

R-Type指令

有三种指令格式

+   - R-Type
+     6 bits 5 bits 5 bits 5 bits 5 bits 6 bits
+     两个操作数和结果都在寄存器的运算指令。如： sub rd, rs, rt

+   - I-Type
+     - 运算指令：一个寄存器、一个立即数。如： ori rt, rs, imm16
+     - LOAD和STORE指令。如： lw rt, rs, imm16
+     - 条件分支指令。如： beq rs, rt, imm16

I-Type指令

+   - J-Type
+     无条件跳转指令。如： j target
