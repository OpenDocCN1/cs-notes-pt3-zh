# x86-64对齐

+   - 1字节: char, ...
+     - 对地址无要求

+   - 2字节: short, ...
+     - 低字节地址必须偶数：******0₂

+   - 4字节: int, float, ...
+     - 低字节地址必须是4的倍数:******00₂

+   - 8字节: double, long, char *, ...
+     - 低字节地址必须是8的倍数:******000₂

+   - 16字节: long double (GCC on Linux)
+     - 低字节地址必须是16的倍数：******0000₂
