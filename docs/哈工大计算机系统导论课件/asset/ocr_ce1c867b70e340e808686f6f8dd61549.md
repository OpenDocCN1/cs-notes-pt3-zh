# 数组访问例子

zip_dig cmu;

![](bbox=[0.27, 0.24, 0.82, 0.36])

```
int get_digit
(zip_dig z, int digit)
{
    return z[digit];
}
```

IA32

```
# %rdi = z
# %rsi = digit
movl (%rdi,%rsi,4), %eax  # z[digit]
```

+   - 寄存器 %rdi 保存数组的起始地址
+   - 寄存器 %rsi 保存数组元素的下标(索引)
+   - 期望的数据地址： %rdi + 4*%rsi
+   - 内存寻址形式 (%rdi,%rsi,4)
