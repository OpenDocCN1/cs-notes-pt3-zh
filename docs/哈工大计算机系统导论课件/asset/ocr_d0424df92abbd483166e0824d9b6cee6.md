# 避免副作用

+   - 异常出现应该禁止状态更新
+     - 非法指令转换为流水线气泡
+       - 除非状态指示异常状态
+     - 数据不会被写入无效的地址
+     - 防止条件码进行无效更新
+       - 在访存阶段检测异常
+       - 在执行阶段禁止条件码更新
+       - 必须在相同的时钟周期内发生
+     - 在最后阶段处理异常
+       - 当在访存阶段探测到异常时
+         - 在下一个时钟周期将气泡插入访存阶段
+       - 当在写回阶段探测到异常时
+         - 停止异常指令
+     - 包含在HCL代码中
