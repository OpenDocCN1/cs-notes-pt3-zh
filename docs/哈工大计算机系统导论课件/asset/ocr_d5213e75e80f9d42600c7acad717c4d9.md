# 矩阵乘法的例子

+   描述:
+   - N x N 矩阵相乘
+   - 矩阵元素类型是 doubles (8 字节)
+   - 总共 O(N³) 个操作
+   - A、B中每个元素都要读 N 次
+   - 每个目标中都要对 N 个值求和
+     - 但也可以保持在寄存器中

```
/* ijk */
for (i=0; i<n; i++)
    for (j=0; j<n; j++) {
        sum = 0.0;
        for (k=0; k<n; k++)
            sum += a[i][k] * b[k][j];
        c[i][j] = sum;
    }
matmul/mm.c
```
