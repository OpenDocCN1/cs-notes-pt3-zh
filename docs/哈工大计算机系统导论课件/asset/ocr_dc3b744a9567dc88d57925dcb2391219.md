# 使用联合获取位模式

```
typedef union {
  float f;
  unsigned u;
} bit_float_t;
```

![](bbox=[0.55, 0.25, 0.7, 0.48])

```
float bit2float(unsigned u) {
  bit_float_t arg;
  arg.u = u;
  return arg.f;
}
```

```
unsigned float2bit(float f) {
  bit_float_t arg;
  arg.f = f;
  return arg.u;
}
```
