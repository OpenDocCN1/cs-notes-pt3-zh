# Mark and Sweep (cont.)

# Mark（标记）函数

```
ptr mark(ptr p) {
    if (!is_ptr(p)) return;    // 不指向一个已分配块则什么都不做
    if (markBitSet(p)) return;    // 检查是否已标记
    setMarkBit(p);                // 设置标记位
    for (i=0; i < length(p); i++) // 调用mark标记块中的每个字
        mark(p[i]);               // 标记节点p的所有未标记且可达的后继节点
    return;
}
```

# Sweep（清除）函数

```
ptr sweep(ptr p, ptr end) {
    while (p < end) {
        if markBitSet(p)
            clearMarkBit();
        else if (allocateBitSet(p))
            free(p);
        p += length(p);
    }
}
```
