# 寄存器编码

+   每个寄存器都有1个4-bit的 ID

| %rax | 0 |
| %rcx | 1 |
| %rdx | 2 |
| %rbx | 3 |
| %rsp | 4 |
| %rbp | 5 |
| %rsi | 6 |
| %rdi | 7 |

| %r8 | 8 |
| %r9 | 9 |
| %r10 | A |
| %r11 | B |
| %r12 | C |
| %r13 | D |
| %r14 | E |
| No Register | F |

+   和在 x86-64 编码一样

+   寄存器 ID 15 (0xF) 意味着 “无寄存器”

+   会在硬件设计中的许多地方用到
