# 硬件控制语言(HCL)字级示例

3个字的最小值

![](bbox=[0.045, 0.27, 0.28, 0.42])

```
int Min3 = [
  A < B && A < C : A;
  B < A && B < C : B;
  1         : C;
];
```

+   - 找到三位输入中最小的字
+   - HCL情况表达式
+   - 最后的情况：保证有一个匹配值

4路复用器

![](bbox=[0.04, 0.58, 0.28, 0.78])

```
int Out4 = [
  !s1 && !s0: D0;
  !s1       : D1;
  !s0       : D2;
  1         : D3;
];
```

+   - 根据两个控制位，从4个输入中选择一个（字）
+   - HCL情况表达式
+   - 通过假定顺序地匹配，简化测试
