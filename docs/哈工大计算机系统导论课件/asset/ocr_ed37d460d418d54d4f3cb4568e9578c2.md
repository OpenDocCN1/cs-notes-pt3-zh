# 条件分支(旧风格)

+   - 生成

shark> gcc -Og -S -fno-if-conversion control.c

```
long absdiff
(long x, long y)
{
    long result;
    if (x > y)
        result = x-y;
    else
        result = y-x;
    return result;
}
```

| 寄存器 | 用途 |
| --- | --- |
| %rdi | 参数x |
| %rsi | 参数y |
| %rax | 返回值 |

```
absdiff:
    cmpq  %rsi, %rdi # x:y
    jle   .L4
    movq  %rdi, %rax
    subq  %rsi, %rax
    ret
.L4:    # x <= y
    movq  %rsi, %rax
    subq  %rdi, %rax
    ret
```
