# CISC vs. RISC

+   - **起初的辩论**
+     - 激烈的观点
+     - CISC 支持者---容易编译, 代码的字节数更少
+     - RISC 支持者---能更好地优化编译器, 用简单的芯片设计能快速运行
+   - **目前的状态**
+     - 对于台式机处理器来说，指令集架构的选择不是技术问题
+     - 拥有足够的硬件，可以让任何程序快速运行
+     - 代码的兼容性更重要
+   - x86-64吸纳了很多RISC特性
+     - 更多的寄存器；用寄存器传递参数
+   - 对于嵌入式处理器, RISC 更适合
+     - 更小、更便宜、功耗更低
+     - 大部分手机用ARM处理器
