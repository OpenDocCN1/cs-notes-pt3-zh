# 自定义一个动态共享库文件

myproc1.c

```
# include <stdio.h>
void myfunc1()
{
    printf("%s", "This is myfunc1!\n");
}
```

PIC : Position Independent Code

位置无关代码

+   1) 保证共享库代码的位置可以是不确定的
+   2) 即使共享库代码的长度发生变化，也不会影响调用它的程序

myproc2.c

```
# include <stdio.h>
void myfunc2()
{
    printf("%s", "This is myfunc2\n");
}
```

gcc -c myproc1.c myproc2.c

gcc -shared -fPIC -o mylib.so myproc1.o myproc2.o
