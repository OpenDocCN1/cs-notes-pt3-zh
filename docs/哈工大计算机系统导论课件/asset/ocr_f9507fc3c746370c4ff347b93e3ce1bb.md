# 2.2 整数编码(Encoding Integers)

无符号数

有符号数——补码(Two’s Complement)

B2U(X) = Σ_{i=0}^{w-1} x_i · 2^i

B2T(X) = -x_{w-1}·2^{w-1} + Σ_{i=0}^{w-2} x_i·2^i

```
short int x = 15213;
short int y = -15213;
```

符号位

# C short : 2 字节

| | 10 进制 | 16 进制 | 2 进制 |
|---|---|---|---|
| x | 15213 | 3B 6D | 00111011 01101101 |

# 符号位

+   对于补码(2’s complement), 最□位表示符号

+   0 表示□负数（!= 正数），1 表示负数
