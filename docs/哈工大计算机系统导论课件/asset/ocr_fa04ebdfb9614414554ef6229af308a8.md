# While循环实现——例1

C代码

```
long pcount_while
(unsigned long x) {
    long result = 0;
    while (x) {
        result += x & 0x1;
        x >>= 1;
    }
    return result;
}
```

跳到中间版本

```
long pcount_goto_jtm
(unsigned long x) {
    long result = 0;
    goto test;
    loop:
    result += x & 0x1;
    x >>= 1;
    test:
    if(x) goto loop;
    return result;
}
```

+   - 与do-while版本的函数比较
+   - 第一个goto语句跳到test处启动循环
