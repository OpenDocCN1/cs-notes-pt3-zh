# 事例4：存储系统的性能

```
void copyij(int src[2048][2048],
    int dst[2048][2048])
{
    int i,j;
    for (i = 0; i < 2048; i++)
        for (j = 0; j < 2048; j++)
            dst[i][j] = src[i][j];
}
```

```
void copyji(int src[2048][2048],
    int dst[2048][2048])
{
    int i,j;
    for (j = 0; j < 2048; j++)
        for (i = 0; i < 2048; i++)
            dst[i][j] = src[i][j];
}
```

4.3ms
2.0 GHz Intel Core i7 Haswell
81.8ms

两个程序功能一样、算法一样, 时间空间复杂度一样, 执行时间why?

+   - 存储器的层次化组织
+   - 性能 依赖于访问模式
+     - 包括怎样遍历多维数组

理解该问题需要知道：

+   - 数组的存放方式
+   - Cache机制
+   - 访问局部性
