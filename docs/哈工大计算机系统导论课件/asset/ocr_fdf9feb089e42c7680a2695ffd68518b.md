# 处理器状态(x86-64, 一部分)

+   - 当前程序的运行状态信息

+   - 临时数据
+     (%rax, ...)

+   - 运行时栈的位置
+     (%rsp)

+   - 当前程序控制点位置
+     (%rip, ...)

+   - 条件码
+     - 状态标志位
+     - 最近测试的状态
+       ( CF, ZF, SF, OF )

Registers

| %rax | %r8 |
| %rbx | %r9 |
| %rcx | %r10 |
| %rdx | %r11 |
| %rsi | %r12 |
| %rdi | %r13 |
| %rsp | %r14 |
| %rbp | %r15 |

当前栈顶

%rip

指令指针

+   - CF
+   - ZF
+   - SF
+   - OF

条件码
