
## Y86-64 指令集

- 格式
  - 1-10字节的信息，从内存读取
    - 根据第一字节可判断指令长度
    - 比x86-64的指令类型少
    - 比x86-64的编码简单
- 每次存取更改程序状态的一些部分

## 寄存器编码

每个寄存器都有1个4-bit的 ID

| 寄存器 | ID |
|---|---|
| %rax | 0 |
| %rcx | 1 |
| %rdx | 2 |
| %rbx | 3 |
| %rsp | 4 |
| %rbp | 5 |
| %rsi | 6 |
| %rdi | 7 |
| %r8 | 8 |
| %r9 | 9 |
| %r10 | A |
| %r11 | B |
| %r12 | C |
| %r13 | D |
| %r14 | E |
| No Register | F |

- 和在 x86-64 编码一样
- 寄存器 ID 15 (0xF) 意味着“无寄存器”
- 会在硬件设计中的许多地方用到

## 指令示例

- 加法指令

![](img/7ab811dea080313a753fa0ae68528fa9_797_0.png)

- 将rA中的值加到rB中
- 结果存储到rB中
- 注意Y86-64仅允许在寄存器数据中应用加法
- 根据结果设置条件码
- e.g., addq %rax,%rsi 编码: 60 06
- 两字节编码
  - 第一字节指出指令类型
  - 第二字节指出源和目的寄存器

## 算数和逻辑操作

| 指令 | 指令码 | 功能码 | 字节1 |
|---|---|---|---|
| addq rA, rB | 6 | 0 | rA rB |
| subq rA, rB | 6 | 1 | rA rB |
| andq rA, rB | 6 | 2 | rA rB |
| xorq rA, rB | 6 | 3 | rA rB |

- 通常以“OPq”表述
- 编码区别仅在于“功能码”
  - 指令第一个字节的低4位
- 设置条件码作为指令执行的附带作用

- 与x86-64中movq指令类似
- 内存地址：更简单的格式
- 赋予不同名称，以保持他们的唯一性

## 传送指令示例

x86-64

```asm
movq $0xabcd, %rdx
```

Y86-64

```asm
irmovq $0xabcd, %rdx
```

编码：`30 f2 cd ab 00 00 00 00 00 00`

```asm
movq %rsp, %rbx
```

```asm
rrmovq %rsp, %rbx
```

编码：`20 43`

```asm
movq -12(%rbp),%rcx
```

```asm
mrmovq -12(%rbp),%rcx
```

编码：`50 15 f4 ff ff ff ff ff ff ff`

```asm
movq %rsi,0x41c(%rsp)
```

```asm
rmmovq %rsi,0x41c(%rsp)
```

编码：`40 64 1c 04 00 00 00 00 00 00`

## 条件传送指令

- 无条件传送：`rrmovq rA, rB` — 编码 `2 0 rA rB`
- 当小于或等于时传送：`cmovle rA, rB` — 编码 `2 1 rA rB`
- 当小于时传送：`cmovl rA, rB` — 编码 `2 2 rA rB`
- 当等于时传送：`cmove rA, rB` — 编码 `2 3 rA rB`
- 当不等于时传送：`cmovne rA, rB` — 编码 `2 4 rA rB`
- 当大于或等于时传送：`cmovge rA, rB` — 编码 `2 5 rA rB`
- 当大于时传送：`cmovg rA, rB` — 编码 `2 6 rA rB`

- 通常表示为“cmovXX”
- 指令编码仅在“功能码”上有区别
- 以条件码的值为依据
- rrmovq 指令的变体
  - (有条件地)从源寄存器复制到目的寄存器

## 跳转指令

- 跳转（有条件地）

![](img/7ab811dea080313a753fa0ae68528fa9_802_0.png)

- 通常表示为“jXX”
- 指令编码仅在“功能码”上有区别
- 以条件码的值为依据
- 和x86-64中的操作相同
- 对目的地址进行完整编码
  - 和x86-64中的PC相对地址编码不一样

```asm
4004d0: 48 89 f8    mov %rdi,%rax
4004d3: eb 03      jmp 4004d8 <loop+0x8>
4004d5: 48 d1 f8    sar %rax
4004d8: 48 85 c0    test %rax, %rax
4004db: 7f f8      jg 4004d5 <loop+0x5>
4004dd: f3 c3      repz retq
```

## 跳转指令

- 无条件跳转：`jmp Dest` — 编码 `7 0 Dest`
- 当小于或等于时跳转：`jle Dest` — 编码 `7 1 Dest`
- 当小于时跳转：`jl Dest` — 编码 `7 2 Dest`
- 当等于时跳转：`je Dest` — 编码 `7 3 Dest`
- 当不等于时跳转：`jne Dest` — 编码 `7 4 Dest`
- 当大于或等于时跳转：`jge Dest` — 编码 `7 5 Dest`
- 当大于时跳转：`jg Dest` — 编码 `7 6 Dest`

## Y86-64 程序栈

![](img/7ab811dea080313a753fa0ae68528fa9_804_0.png)

- 存储程序数据的内存区域
- 在 Y86-64 (和 x86-64)中用于支持过程调用
- %rsp指向栈顶
  - 栈顶元素的地址
- 栈向低地址的方向增长
  - 入栈操作必须先减小栈指针
  - 出栈操作后，增加栈指针
