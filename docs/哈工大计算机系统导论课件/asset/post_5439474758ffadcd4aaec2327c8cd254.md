
## 性能目标：最大化内存利用率

- 给定 n 个分配和释放请求的某种顺序：
  - $R_0, R_1, ..., R_k ..., R_{n-1}$

- 定义：聚集有效载荷 (Aggregate payload) $P_k$
  - `malloc(p)` 分配一个有效载荷 p 字节的块
  - 请求 $R_k$ 完成后，聚集有效载荷 $P_k$ 为当前已分配的块的有效载荷之和

- 定义：堆的当前大小 $H_k$
  - 假设 $H_k$ 是单调非递减的
  - 比如，只有分配器使用 sbrk 时堆才会增大或减小

- 定义：前 k+1 个请求的峰值利用率
  - $U_k = (\max_{i \le k} P_i) / H_k$

## 碎片

- **碎片化**导致内存利用率低
  - *内部*碎片
  - *外部*碎片

## 内部碎片

- 对一个给定块，当有效载荷小于块的大小时会产生内部碎片

![](img/7ab811dea080313a753fa0ae68528fa9_1453_0.png)

- 产生原因
  - 维护数据结构产生的开销
  - 增加块大小以满足对齐的约束条件
  - 显式的策略决定
    - (比如，返回一个大块以满足一个小的请求)

- 只取决于之前请求的模式
  - 易于量化

## Method 1: 隐式空闲链表

- 对于每个块我们都需要知道块的大小和分配状态

- Standard trick 标准技巧

  - 使用这些0位作为一个已分配/未分配的标志
  - 读块大小字段时，必须将其屏蔽掉

## 隐式链表法：找到一个空闲块

- 首次适配 (First fit):
  - 从头开始搜索空闲链表，选择第一个合适的空闲块:

```c
p = start;
while ((p < end) &&
      ((*p & 1) ||      // already allocated
       (*p <= len)))    // too small
  p = p + (*p & -2);    // goto next block (word addressed)
```

- 搜索时间与总块数（包括已分配和空闲块）成线性关系
- 在靠近链表起始处留下小空闲块的“碎片”

- 下一次适配 (Next fit):
  - 和首次适配相似，只是从链表中上一次查询结束的地方开始
  - 比首次适应更快：避免重复扫描那些无用块
  - 一些研究表明，下一次适配的内存利用率要比首次适配低得多

- 最佳适配 (Best fit):
  - 查询链表，选择一个最好的空闲块：适配，剩余最少空闲空间
  - 保证碎片最小——提高内存利用率
  - 通常运行速度会慢于首次适配

## 隐式链表----分配空闲块

- 分配空闲块：分割 (splitting)
  - 既然分配块比空闲块小，我们可以把空闲块分割成两部分

![](img/7ab811dea080313a753fa0ae68528fa9_1462_0.png)

`addblock(p, 4)`

![](img/7ab811dea080313a753fa0ae68528fa9_1462_1.png)

```c
void addblock(ptr p, int len) {
    int newsize = ((len + 1) >> 1) << 1;    // round up to even
    int oldsize = *p & -2;                  // mask out low bit
    *p = newsize | 1;                       // set new length
    if (newsize < oldsize)
        *(p+newsize) = oldsize - newsize;   // set length in remaining
                                        //   part of block
}
```

### Implicit List: 释放一个块

- **最简单的实现：**
  - 清除“已分配 (allocated)”标志

```c
void free_block(ptr p) { *p = *p & -2 }
```

## Implicit List: 合并

- 合并 (*coalesce*)：合并相邻的空闲块
  - 和下一个空闲块合并

![](img/7ab811dea080313a753fa0ae68528fa9_1464_0.png)

```c
void free_block(ptr p) {
    *p = *p & -2;          // clear allocated flag
    next = p + *p;         // find next allocated block
    if ((*next & 1) == 0)
        *p = *p + *next;   // add to this block if
                           //      not allocated
}
```
