跳转表

.quad .L9 # x = 3
.quad .L8 # x = 4
.quad .L7 # x = 5
.quad .L7 # x = 6
```

```
switch(x) {
case 1:    // .L3
    w = y*z;
    break;
case 2:    // .L5
    w = y/z;
    /* Fall Through */
case 3:    // .L9
    w += z;
    break;
case 5:
case 6:    // .L7
    w -= z;
    break;
default:   // .L8
    w = 2;
}
```

## x86-64 入栈指令: push

- 入栈指令 pushq
  - 格式:
    pushq Src
  - 从Src取操作数
  - 将%rsp减8
  - 将操作数写到%rsp指向的地址

![](img/7ab811dea080313a753fa0ae68528fa9_555_0.png)

## x86-64 出栈指令: pop

- 出栈指令 pushq
- 格式：
- popq Dst
- 从%rsp中保存的地址值读取数值
- 将 %rsp 加 8
- 将数值保存到Dst (必须是寄存器)

![](img/7ab811dea080313a753fa0ae68528fa9_556_0.png)
