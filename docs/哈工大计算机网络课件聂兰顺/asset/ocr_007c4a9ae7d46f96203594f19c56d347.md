# IP分组格式

| 位 | 0 | 4 | 8 | 16 | 19 | 24 | 31 |
|---|---|---|---|---|---|---|---|
|  | 版本号 | 首部长度 | 服务类型(TOS) |  | 总长度 |  |  |
|  |  | 标识 |  | 标志位 | 片偏移 |  |  |
|  | 生存时间(TTL) | 协议 |  | 首部检验和 |  |  |  |
|  |  | 源IP地址 |  |  |  |  |  |
|  |  | 目的IP地址 |  |  |  |  |  |
|  | 选项字段（长度可变） |  |  | 填充 |  |  |  |
|  | 数据 |  |  |  |  |  |  |

生存时间（TTL）字段占8位：IP分组在网络中可以通过的路由器数（或跳步数）

+   - 路由器转发一次分组，TTL减1
+   - 如果TTL=0，路由器则丢弃该IP分组
