# 案例：**ATM ABR**拥塞控制

+   - **ABR：available bit rate**
+     - “弹性服务”
+     - 如果发送方路径“underloaded”
+       - ⑩使用可用带宽
+     - 如果发送方路径拥塞
+       - ⑩将发送速率降到最低保障速率

+   - **RM(resource management) cells**
+     - 发送方发送
+     - 交换机设置RM cell位(网络辅助)
+       - NI bit: rate不许增长
+       - CI bit: 拥塞指示
+     - RM cell由接收方返回给发送方
