# HTTP请求消息

+   HTTP协议有两类消息
+   - 请求消息(request)
+   - 响应消息(response)

+   请求消息
+   - ASCII：人直接可读

request line (GET, POST, HEAD commands)

header lines

```
GET /somedirectory/page.html HTTP/1.1
Host: www.someschool.edu
User-agent: Mozilla/4.0
Connection: close
Accept-language: fr
```

Carriage return line feed indicates end of message

(extra carriage return, line feed)
