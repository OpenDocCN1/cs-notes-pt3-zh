# VLANs

虚拟局域网(Virtual Local Area Network)

支持VLAN划分的交换机，可以在一个物理LAN架构上配置、定义多个VLAN

基于端口的VLAN: 分组交换机端口(通过交换机管理软件)，于是，单一的物理交换机 ……

...就像多个虚拟交换机一样运行
