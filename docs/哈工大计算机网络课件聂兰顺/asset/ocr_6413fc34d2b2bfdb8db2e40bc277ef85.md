# 概述

+   **术语：**
+   
+   - 主机和路由器: 结点(nodes)
+   - 连接相邻结点的通信信道: 链路(links)
+     - 有线链路(wired links)
+     - 无线链路(wireless links)
+     - 局域网(LANs)
+   - 链路层(第2层)数据分组: 帧(frame), 封装网络层数据报
