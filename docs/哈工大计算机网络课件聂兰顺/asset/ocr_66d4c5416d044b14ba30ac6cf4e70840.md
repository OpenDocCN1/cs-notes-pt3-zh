# RIP

+   - 早于1982年随BSD-UNIX操作系统发布
+   - 距离向量路由算法
+     - 距离度量：跳步数（max = 15 hops），每条链路1个跳步
+     - 每隔30秒，邻居之间交换一次DV，成为通告（advertisement）
+     - 每次通告：最多25个目的子网（IP地址形式）
