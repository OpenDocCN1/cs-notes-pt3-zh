# ICMP的应用举例：Traceroute

源主机向目的主机发送一系列UDP数据报

+   - 第1组IP数据报TTL =1
+   - 第2组IP数据报TTL=2, etc.
+   - 目的端口号为不可能使用的端口号

当第n组数据报(TTL=n)到达第n个路由器时：

+   - 路由器丢弃数据报
+   - 向源主机发送ICMP报文(type=11, code=0)
+   - ICMP报文携带路由器名称和IP地址信息

当ICMP报文返回到源主机时，记录RTT

# 停止准则：

+   - UDP数据报最终到达目的主机
+   - 目的主机返回“目的端口不可达”ICMP报文(type=3, code=3)
+   - 源主机停止
