# IP分组格式

| 位 | 0 | 4 | 8 | 16 | 19 | 24 | 31 |
|---|---|---|---|---|---|---|---|
|  | 版本号 | 首部长度 | 服务类型(TOS) |  | 总长度 |  |  |
|  | 标识 |  | 标志位 | 片偏移 |  |  |  |
|  | 生存时间(TTL) | 协议 |  | 首部检验和 |  |  |  |
|  | 源IP地址 |  |  |  |  |  |  |
|  | 目的IP地址 |  |  |  |  |  |  |
|  | 选项字段（长度可变） | 填充 |  |  |  |  |  |
|  | 数据 |  |  |  |  |  |  |

协议字段占8位：指示IP分组封装的是哪个协议的数据包

+   - 实现复用/分解
+   - E.g. 6为TCP，表示封装的为TCP段；17为UDP，表示封装的是UDP数据报
