# # POP协议

+   ◆ 认证过程
+     ▪ 客户端命令
+       • User：声明用户名
+       • Pass：声明密码
+     ▪ 服务器响应
+       • +OK
+       • -ERR

+   ◆ 事务阶段
+     ▪ List：列出消息数量
+     ▪ Retr：用编号获取消息
+     ▪ Dele：删除消息
+     ▪ Quit

```
S: +OK POP3 server ready
C: user bob
S: +OK
C: pass hungry
S: +OK user successfully logged on

C: list
S: 1 498
S: 2 912
S: .
C: retr 1
S: <message 1 contents>
S: .
C: dele 1
C: retr 2
S: <message 1 contents>
S: .
C: dele 2
C: quit
S: +OK POP3 server signing off
```
