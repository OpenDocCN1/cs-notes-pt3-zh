# IP分组格式

| 位 | 0 | 4 | 8 | 16 | 19 | 24 | 31 |
|---|---|---|---|---|---|---|---|
| 版本号 | 首部长度 | 服务类型(TOS) | 总长度 |
| 标识 | 标志位 | 片偏移 |
| 生存时间(TTL) | 协议 | 首部检验和 |
| 源IP地址 |
| 目的IP地址 |
| 选项字段（长度可变） | 填充 |
| 数据 |

首部校验和字段占16位：实现对IP分组首部的差错检测

+   - 计算校验和时，该字段置全0
+   - 采用反码算术运算求和，和的反码作为首部校验和字段
+   - 逐跳计算、逐跳校验
