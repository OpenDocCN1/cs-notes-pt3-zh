# IEEE 802.11 MAC协议: CSMA/CA

# 802.11 sender

+   1 if 监听到信道空闲了 DIFS 时间 then
+   发送整个帧(无同时检测冲突，即 CD)

+   2 if 监听到信道忙 then
+   开始随机退避计时
+   当信道空闲时，计时器倒计时
+   当计时器超时时，发送帧
+   if 没有收到 ACK then
+   增加随机退避间隔时间
+   重复第2步

# 802.11 receiver

+   - if 正确接收帧
+   延迟 SIFS 时间后，向发送端发送 ACK
+   (由于存在隐藏站问题)
