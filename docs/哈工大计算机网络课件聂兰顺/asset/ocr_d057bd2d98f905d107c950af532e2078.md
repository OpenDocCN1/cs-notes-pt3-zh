# IP分组格式

| 位 | 0 | 4 | 8 | 16 | 19 | 24 | 31 |
|---|---|---|---|---|---|---|---|
|  | 版本号 | 首部长度 | 服务类型(TOS) |  | 总长度 |  |  |
|  | 标识 |  | 标志位 |  | 片偏移 |  |  |
|  | 生存时间(TTL) | 协议 |  | 首部检验和 |  |  |  |
|  | 源IP地址 |  |  |  |  |  |  |
|  | 目的IP地址 |  |  |  |  |  |  |
|  | 选项字段（长度可变） |  |  |  | 填充 |  |  |
|  | 数据 |  |  |  |  |  |  |

服务类型(TOS)字段占8位：指示期望获得哪种类型的服务

+   - 1998 年这个字段改名为区分服务
+   - 只有在网络提供区分服务(DiffServ)时使用
+   - 一般情况下不使用，通常IP分组的该字段(第2字节)的值为00H
