# Rdt 2.0: 产生位错误的信道

+   ◆ 底层信道可能翻转分组中的位(bit)
+     - 利用校验和检测位错误
+   ◆ 如何从错误中恢复？
+     - 确认机制(Acknowledgements, ACK): 接收方显式地告知发送方分组已正确接收
+     - NAK:接收方显式地告知发送方分组有错误
+     - 发送方收到NAK后，重传分组
+   ◆ 基于这种重传机制的rdt协议称为ARQ(Automatic Repeat reQuest)协议
+   ◆ Rdt 2.0中引入的新机制
+     - 差错检测
+     - 接收方反馈控制消息: ACK/NAK
+     - 重传
