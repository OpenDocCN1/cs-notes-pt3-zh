# TCP概述: RFCs-793, 1122, 1323, 2018, 2581

+   - 点对点
+     - 一个发送方，一个接收方
+   - 可靠的、按序的字节流
+   - 流水线机制
+     - TCP拥塞控制和流量控制机制
+       设置窗口尺寸
+   - 发送方/接收方缓存

![](bbox=[0.074, 0.693, 0.464, 0.811])

+   - 全双工(full-duplex)
+     - 同一连接中能够传输双向数据流
+   - 面向连接
+     - 通信双方在发送数据之前必须建立连接。
+     - 连接状态只在连接的两端中维护，在沿途节点中并不维持状态。
+     - TCP连接包括：两台主机上的缓存、连接状态变量、socket等
+   - 流量控制机制
