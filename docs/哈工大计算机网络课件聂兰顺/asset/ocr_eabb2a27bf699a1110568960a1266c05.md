# IP分组格式

| 位 | 0 | 4 | 8 | 16 | 19 | 24 | 31 |
|---|---|---|---|---|---|---|---|
| 版本号 | 首部长度 | 服务类型(TOS) | 总长度 |
| 标识 | 标志位 | 片偏移 |
| 生存时间(TTL) | 协议 | 首部检验和 |
| 源IP地址 |
| 目的IP地址 |
| 选项字段（长度可变） | 填充 |
| 数据 |

总长度字段占16位：IP分组的总字节数(首部+数据)

+   - 最大IP分组的总长度：65535B
+   - 最小的IP分组首部：20B
+   - IP分组可以封装的最大数据：65535-20=65515B
