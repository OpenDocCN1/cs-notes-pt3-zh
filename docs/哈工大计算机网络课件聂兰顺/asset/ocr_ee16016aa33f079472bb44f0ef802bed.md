# 数据报网络 or VC网络？

# Internet (数据报网络)

+   - 计算机之间的数据交换
+     - “弹性”服务，没有严格时间需求

+   - 链路类型众多
+     - 特点、性能各异
+     - 统一服务困难

+   - “智能”端系统 (计算机)
+     - 可以自适应、性能控制、差错恢复

简化网络，
复杂“边缘”

# ATM (VC网络)

+   - 电话网络演化而来

+   - 核心业务是实时对话：
+     - 严格的时间、可靠性需求
+     - 需要有保障的服务

+   - “哑(dumb)”端系统（非智能）
+     - 电话机
+     - 传真机

简化“边缘”，
复杂网络
