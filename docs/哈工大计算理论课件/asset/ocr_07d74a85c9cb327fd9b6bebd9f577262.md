# Sets

+   - **Complement of *A*** denotes all elements that are not belonging to set *A*  $4 \in \overline{A}$
+   - **Power Set of *A*** denotes set of all subset of *A*
+     power set of A  $P(A)$ or $2^A = \{\phi, \{1\}, \{2\}, \{3\}, \{1,2\}, \{1,3\}, \{2,3\}, \{1,2,3\}\}$
+   - **Empty Set** is a set with zero elements  $\phi = \{ \}$
