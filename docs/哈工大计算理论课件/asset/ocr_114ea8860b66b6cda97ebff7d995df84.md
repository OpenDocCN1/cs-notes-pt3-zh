# Example of pushdown automata

| input | 0 |  | 1 |  | ε |  |
| stack | 0 | $ | ε | 0 | $ | ε | 0 | $ | ε |
| q1 |  |  |  |  |  |  |  |  | {(q2, $)} |
| q2 |  | {(q2, 0)} | {(q3, ε)} |  |  |  |  |  |  |
| q3 |  |  | {(q3, ε)} |  |  |  | {(q4, ε)} |  |  |
| q4 |  |  |  |  |  |  |  |  |  |

We can see the PDA M₁ initially push a special symbol $ on the stack to allow the PDA to test for an empty stack.
