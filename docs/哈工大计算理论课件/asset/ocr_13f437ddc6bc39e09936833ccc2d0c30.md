# Proof by construction

+   - Example 1:
+     Prove for each even number $n$ greater than 2, there exists a 3-regular graph (a graph with degree 3 for all of its nodes) with $n$ nodes.
+   - Proof:
+     Let $n$ be an even number and $n > 2$. Construct graph $G = (V, E)$ with n nodes as follows. The set of nodes of $G$ is $V = \{0,1,\dots,n-1\}$, and the set of edges of $G$ is the set
+     $E = \{\{i,i+1\} \mid for\ 0 \le i \le n-2\} \cup \{\{n-1,0\}\} \cup \{\{i,i+n/2\} \mid for\ 0 \le i \le n/2-1\}$
