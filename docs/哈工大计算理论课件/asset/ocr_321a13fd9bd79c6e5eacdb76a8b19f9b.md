# Proof by contradiction

+   - Example:
+     Prove √2 is irrational.
+   - Proof:
+     Assume is a rational number and such that √2 = m / n where both m and n are integers.
+   
+     If both m and n are divisible by the same integer greater than 1, doing it does not change the value of the fraction. Now, at least one of m and n must be an odd number.
+   
+     Then, multiply both sides of the equation by n , n√2 = m
+   
+     and square both sides to obtain 2n² = m²
