# Complexity relationship among models

Theorem:

+   - Let t(n) be a function, where t(n) ≥ n. Then every t(n) time multitape Turing machine has an equivalent O(t²(n)) time single-tape Turing machine.

+   - Proof idea: the same as we have used to convert any multitape TM into a single-tape TM to simulates it.
