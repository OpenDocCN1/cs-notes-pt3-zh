# Class NP

The NTM for HAMPATH:

+   - $N_1 =$ “ On input <G,s,t> ... with nodes s and t:
+     1. Write a list of m numb of nodes in G. Each nu nondeterministically s
+     2. Check for repetitions in the list. If any are found, reject.
+     3. Check whether s = p₁ and t = pₘ. If either fail, reject.
+     4. For each i between 1 and m-1, check whether (pᵢ, pᵢ+1) is an edge of G. If any are not, reject. Otherwise, all tests have been passed, so accept.”

All stages runs in polynomial times, so the algorithm runs in nondeterministic polynomial time.
