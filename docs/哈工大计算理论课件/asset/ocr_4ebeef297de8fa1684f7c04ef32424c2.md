# Formal definition of computation of NFA

+   - Let $N = (Q, \Sigma, \delta, q_0, F)$ be a NFA and let $w = y_1 y_2 ... y_n$ be a string where each $y_i$ is a member of the alphabet $\Sigma_\varepsilon$. Then $N$ accepts $w$ if a sequence of states $r_0, r_1, ... r_m$ in $Q$ exists with three conditions:;
+     - $r_0 = q_0$
+     - $r_{i+1} \in \delta(r_i, y_{i+1})$, for $i = 0, ..., m-1$, and
+     - $r_m \in F$
+   - So we can say that $N$ recognizes language $A$ if $A = \{w \mid N \text{ accepts } w\}$
