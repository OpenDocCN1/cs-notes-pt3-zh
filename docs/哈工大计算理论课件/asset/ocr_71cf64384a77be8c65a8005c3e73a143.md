# Formal definition of NFA

**Example:**

$N_1=(Q,\Sigma,\delta,q_1,F)$, where

+   1. $Q=\{q_1,q_2,q_3,q_4\}$
+   2. $\Sigma=\{0,1\}$
+   3. $\delta$ is described as
+   4. $q_1$ is the start state, and
+   5. $F=\{q_4\}$

| $\delta$ | 0 | 1 | $\epsilon$ |
|---|---|---|---|
| $q_1$ | $\{q_1\}$ | $\{q_1,q_2\}$ | $\Phi$ |
| $q_2$ | $\{q_3\}$ | $\Phi$ | $\{q_3\}$ |
| $q_3$ | $\Phi$ | $\{q_4\}$ | $\Phi$ |
| $q_4$ | $\{q_4\}$ | $\{q_4\}$ | $\Phi$ |
