# The TQBF Problem

+   - TQBF = {< φ > | φ is a true fully quantified Boolean formula}
+     - E.g. For the universe of {0, 1}
+       φ = ∀x∃y[(x ∨ y) ∧ (x̄ ∨ ȳ)]
+     - E.g. For the universe of Natural Numbers
+       φ = ∀x(x + 1 > x)          φ = ∃y(y + y = 3)
+     - E.g. For the universe of Real Numbers
+       φ = ∃y(y + y = 3)
