# Self-reference

+   - Proof:
+   - We can take any string $w$ and construct Turing machine $P_w$ that build $w$ into a table, and simply output $w$ when started (on any input).
+   - $Q=$“On input string $w$:
+     1. Construct the following Turing machine $P_w$.
+        $P_w=$“On any input:
+        - Erase input.
+        - Write $w$ on the tape.
+        - Halt.
+     2. Output $<P_w>$.”
