# Proof by induction

+   - Proof:
+     **Basis:**
+     prove that the formula is true for $t = 0$, that is
+     (remark: $M^0=1$)
+     $$P_0 = P M^0 - Y\left(\frac{M^0 -1}{M -1}\right)=P$$
+     This holds true because we have defined $P_0 = P$. So, we have proved the basis of the induction is true.
