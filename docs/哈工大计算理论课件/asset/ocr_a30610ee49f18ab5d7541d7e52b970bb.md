# Regular operations

+   Example:
+   Σ = { a, b, ... , z }, A = { red, blue }, B = { dog, bird, cat }

+   A ∪ B = { red, blue, dog, bird, cat }

+   A ∘ B = { reddog, redbird, redcat, bluedog, bluebird, bluecat }

+   A* = { ε, red, blue, redred, redblue, bluered, blueblue, redredred, redredblue, redbluered, redblueblue, ... }
