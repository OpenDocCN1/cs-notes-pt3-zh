# Closure under the regular operations

N₁ = (Q₁, Σ, δ₁, q₁, F₁), N₂ = (Q₂, Σ, δ₂, q₂, F₂) and N = (Q, Σ, δ, q₀, F), thus

+   1. Q = {q₀} ∪ Q₁ ∪ Q₂
+   2. Σ
+   3. Transition function:
+      δ(q, a) = { δ₁(q, a)   q ∈ Q₁
+                  δ₂(q, a)   q ∈ Q₂
+                  {q₁, q₂}   q = q₀ and a = ε
+                  ∅          q = q₀ and a ≠ ε }
+   4. q₀
+   5. F = F₁ ∪ F₂
