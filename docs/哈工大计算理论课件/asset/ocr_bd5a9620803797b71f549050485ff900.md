# Context-free Grammars

Example 4: a context-free grammar $G_4=(V, \Sigma,R, <EXPR>)$ where
$V = \{<EXPR>, <TERM>, <FACTOR>\}$,
$\Sigma = \{A, +, \times, (, )\}$,
The rules are
$<EXPR> \rightarrow <EXPR> + <TERM> \mid <TERM>$
$<TERM> \rightarrow <TERM> \times <FACTOR> \mid <FACTOR>$
$<FACTOR> \rightarrow (<EXPR>) \mid a$
