# Graph

+   - If every two nodes have a path between them, the graph is **connected**.
+   - A graph is a **tree** if it is connected and has no simple cycles.
+     - Root, leaves.
+   - If the graph has arrows instead of lines, the graph is a directed graph.
+     - Outdegree, indegree.
+     - Directed path
+     - Strongly connected
