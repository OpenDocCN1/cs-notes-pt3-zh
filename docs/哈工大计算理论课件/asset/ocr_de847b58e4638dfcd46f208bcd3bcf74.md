# Post correspondence problem

Formally, PCP is a collection P of dominos:

P = { [t₁ / b₁], [t₂ / b₂], ..., [tₖ / bₖ] }

and a match is a sequence i₁, i₂, ..., iₗ, where tᵢ₁ tᵢ₂ ... tᵢₗ = bᵢ₁ bᵢ₂ ... bᵢₗ. The problem is to determine whether P has a match.

PCP = { <P> | P is an instance of the Post correspondence problem with a match }
