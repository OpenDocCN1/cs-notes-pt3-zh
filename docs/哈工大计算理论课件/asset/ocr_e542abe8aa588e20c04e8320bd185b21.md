# Reducibility

+   - **Example:**
+     - Problem *A*: measuring the area of a rectangle
+     - Problem *B*: measuring length and width of a rectangle.
+     - We can **reduce** *A* to *B*.
+   - **Example 2:**
+     - Problem *A*: solving a system of linear equations.
+     - Problem *B*: inverting a matrix.
+     - We can **reduce** *A* to *B*.
