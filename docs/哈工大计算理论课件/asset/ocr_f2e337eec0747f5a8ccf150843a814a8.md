# Regular operations

M₁ = (Q₁, Σ, δ₁, q₁, F₁), M₂ = (Q₂, Σ, δ₂, q₂, F₂) and M = (Q, Σ, δ, q₀, F), thus

+   1. Q = Q₁ × Q₂ = {(r₁, r₂) | r₁ ∈ Q₁ and r₂ ∈ Q₂}
+   2. We assume M₁ and M₂ have the same input alphabet Σ, so for M, the alphabet is still Σ
+   3. For each (r₁, r₂) ∈ Q and each a ∈ Σ, let 
+   δ((r₁, r₂), a) = (δ₁(r₁, a), δ₂(r₂, a))
+   4. q₀ = (q₁, q₂)
+   5. F = (F₁ × Q₂) ∪ (Q₁ × F₂) = {(r₁, r₂) | r₁ ∈ F₁ or r₂ ∈ F₂}
