# 开源云计算平台Hadoop

+   - Open Source Apache Project
+   - Hadoop Core includes:
+     - Distributed File System - distributes data
+     - Map/Reduce - distributes application
+   - Written in Java
+   - Runs on
+     - Linux, Mac OS/X, Windows, and Solaris
+     - Commodity hardware
