# # 7. JXTA-P2P Protocol

+   - What is JXTA Java?

+   - JXTA™ is a set of open, generalized peer-to-peer (P2P) protocols that allow any networked device

+   - sensors,

+   - Cell phones,

+   - PDAs,

+   - laptops,

+   - workstations,

+   - servers and

+   - supercomputers

to communicate and collaborate mutually as peers.
