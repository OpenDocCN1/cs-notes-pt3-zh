# Another Example-account management

有三个类，每个类都有一个验证方法

**Address**

| Field | Type |
|-------|------|
| address | String |
| city | String |
| state | String |
| isValid() | boolean |
| save() | boolean |
| getAddress() | String |
| getState() | String |

**Account**

| Field | Type |
|-------|------|
| firstName | String |
| lastName | String |
| isValid() | boolean |
| save() | boolean |
| getFirstName() | String |
| getLastName() | String |

**CreditCard**

| Field | Type |
|-------|------|
| cardType | String |
| cardNumber | String |
| cardExpDate | String |
| isValid() | String |
| save() | String |
| getCardType() | String |
| getCardNumber() | String |
| getCardExpDate() | String |

There exist 3 classes for validating Address, Account, and CreditCard info
