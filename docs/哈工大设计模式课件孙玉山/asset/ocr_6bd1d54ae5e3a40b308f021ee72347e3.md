# 1. Basic Concepts of Grid Computing

+   - 资源供应技术 Provisioning of Resources. Grid computing consists of a family of technologies for dynamically provisioning computing power from a pool of resources.
+   - **The resource pool can include:**
+     - computing cycles
+     - file and data storage
+     - Caching
+     - network bandwidth
+     - databases and
+     - data warehouses
+     - application software
