# Facade Pattern-sample code

```
public class TepreatureSensor {
	public void activate(){
		System.out.print("Activating TepreatureSensor.");
	}
	public void deactivate(){
		System.out.print("Deactivating eperatureSensor.");
	}
	public void trigger(){
		System.out.print(" TepreatureSensor has been triggered.");
	}
}
```
