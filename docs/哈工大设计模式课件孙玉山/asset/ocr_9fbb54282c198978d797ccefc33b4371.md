# Class Relations (类间关系)

+   - **Association relation (关联关系)**
+   - An association between two classes represents a collaboration between the classes or their corresponding instances. Association relation includes:

+   - Aggregation relation(聚合关系)
+     类B以一个实例化对象的形式作为A的一个属性

![](bbox=[0.43, 0.44, 0.92, 0.68])

+   - Dependency relation(依赖关系)
+     表现为类B作为参数被类A某个方法使用

![](bbox=[0.15, 0.8, 0.62, 0.96])
