# Query Software of Building Features

+   - **Benefits of the design**:
+   - **Responsibility separation**:
+   - The responsibility of selecting and instantiating an appropriate House/Condo implementer is moved out of application objects to a separate designated abstract factory class.
+   - **About BuildingFactory class**:
+   - It simply declares the required interface, leaving the actual implementation details of class selection and instantiation to its implementers.
