# Multi-dimension of Grid Computing

+   1. 网格种类 Grid Types. First dimension describes grid types:
+      - *data grid,*
+      - *computational grid*

+   2. 地理网格 Geographic grid. Second dimension describes a grid's geographic reach:
+      - *campus grid,*
+      - *statewide grid, and*
+      - *global grid.*
