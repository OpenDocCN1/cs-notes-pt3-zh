# Class and Object

```
public Class Person {
    private String name;
    private String sex;
    private int age;
    private String race;
    public Person( String sex, int age, String race ) {
        this.sex = sex;
        this.age = age;
        this.race = race;
    }
    String getName() {
        return name;
    }
    String getSex() {
        return sex;
    }
    String getAge() {
        return age;
    }
    String getRace() {
        return race;
    }
}
```

Data have been encapsulated(封装)

Functions are provided
