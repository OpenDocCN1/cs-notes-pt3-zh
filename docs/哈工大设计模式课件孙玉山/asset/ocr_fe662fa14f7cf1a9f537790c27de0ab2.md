# 应用桥模式设计的例子

# 抽象接口类

```
public interface TeaSize {
    public abstract float getPrice();
}
```

# 抽象部分子类

```
public class MediumCup implements TeaSize{
    private TeaKind tk;
    public MediumCup (TeaKind tKind){
        tk = tKind;
    }
    public float getPrice(){
        float teaPrice = tk.price();
        return teaPrice;
    }
}
```
