Here, the client program only invokes the FamilyFasade class, calling functions activate or deactivate (without having to know the complex functions in all the other classes behind).

## Facade Pattern-sample code
### Java源代码

```
public class Client {
    private static SecurityFacade security;
    public static void main(String[] args){
        security = new SecurityFacade();
        security.activate();
    }
}
```

## Facade Pattern - sample code

```
public class SecurityFacade {
private Camera camera1;
private Camera camera2;
private Light light1, light2, light3;
private SmokeSensor ss;
private TemperatureSensor ts;
private ChemicalSensor cs;
private HumidSensor hs;
private WindowSensor ws;
private WaterSafeSensor wss;
private PoliceCaller pc;
private HospitalCaller hc;
private FireCaller fc;
private Alarm alarm;
```

## Facade Pattern-sample code

```
public void activate() {
    camera1.turnOn();
    camera2.turnOn();
    light1.turnOn();
    light2.turnOn();
    light3.turnOn();
    ss.activate();
    ts.activate();
    cs.activate();
    hs.activate();
    ws.activate();
    wss.activate();
    pc.activate();
    hc.activate();
    fc.activate();
    alarm.activate();
}
```

## Facade Pattern-sample code

public void deactivate() {
    camera1.turnOff();

    light1.turnOff();
    light2.turnOff();
    light3.turnOff();
    ss.deactivate();
    ts.deactivate();
    hs.deactivate();
    ws.deactivate();
    wss.deactivate();
    pc.deactivate();
    hc.deactivate();
    fc.deactivate();
    alarm.deactivate();
