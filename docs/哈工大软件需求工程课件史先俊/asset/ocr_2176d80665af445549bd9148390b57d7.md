# CCB及角色

# 表17-1 变更管理活动中的可能的项目角色

| 角色 | 描述及责任 |
|------|-------------|
| 变更控制委员会主席 | 变更控制委员会的主席，在CCB意见不一致情况下可以独自做出决定 |
| CCB | 决定采纳或拒绝针对某项目所建议的变更请求的团体 |
| 评估者 | 应项目管理者要求分析所建议的变更带来影响的人员 |
| 修改者 | 负责实现已经被认可的请求变更，按时更新变更状态的人员 |
| 建议者 | 提交变更请求的人 |
| 项目管理者 | 负责指定评估者和修改者的人员 |
| 请求接受者 | 接受提交变更请求的人 |
| 验证者 | 负责决定变更是否正确执行的人 |
