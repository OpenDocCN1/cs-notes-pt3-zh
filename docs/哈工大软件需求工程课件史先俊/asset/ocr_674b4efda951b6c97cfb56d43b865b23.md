| 用例名称 | 网上申报 |
| 简要描述 | 接受纳税人提交的申报材料，审核处理，在有的地方需直接进行税款征收。 |
| 事件流 | 申报操作人员提交纳税申报资料时启动用例：
S1 系统读入纳税人基本信息资料
S2 基本信息资料检查
S3 系统读入纳税人申报资料
S4 审核申报资料
S5 逾期检查
S6 申报处理
S7 (征收)
S8 资料归档 |
| 可选事件流 | 在输入阶段如果操作人员按“取消”将终止用例执行 |
| 扩展点 | 征收 |
| 前置条件 | 纳税人经过登记
操作人员有相应权限 |
| 后置条件 | (略) |
| 业务规则 | S2 如果纳税人没有申请过网上申报则终止用例执行，并提示错误 |
|  | 误信息
S4 如果输入税额不正确则要求重新读入申报资料，并提示错误信息
S4 如果是申报资料已存在，则提示重复申报信息。问是否确认要重复申报
S5 如果是逾期申报则进行逾期申报处理
S7 只有满足条件的纳税人才能进行网上征收 |
