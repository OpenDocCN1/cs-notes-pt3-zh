# 用例说明例子

| 用例名称 | 综合申报 |
| 用例编号 |  |
| 创建人 | 李志明 | 创建日期: | 2002.5.27 |
| 版本号 | 1.4 |
| 主要参与者 | 前台受理人员、后台录入人员、电子申报纳税人、电子申报税务代理、银行受理人员 |
| 次要参与者 |  |
| 简要描述 | 税务机关受理纳税人的综合申报资料，并在本模块种录入某一普通税种的申报资料。普通税种指营业税、城建税、教育费附加、资源税等税种。录入资料后，根据企业具体情况计算应征税额、出现滞纳罚款时要同税款一起计算。 |
| 触发事件 | 纳税人提交普通税种的申报资料。 |
| 前置条件 | 纳税人已经办理了税务登记；
纳税人已经提交正确的纳税申报资料；
纳税人的申报资料中含有普通税种的资料；
操作人员具有相应的操作权限。 |
| 事件流 | S1: 操作人员进入综合申报的处理画面，如果操作人员是从集成申报中进入本模块的，直接跳转至 S4；
S2: 操作人员输入纳税人税务编号，或个人的证件号（如身份证号）、证件类型（如身份证），或选择临时申报（电子申报纳税人、电子申报税务代理、银行受理人员无此功能）；
S3: 系统搜索该纳税人的资料，取出税额核定资料，对欠申報、欠税、欠滞纳金等情况给予提示，并确定申报日期（一般为当天）；
S4: 操作人员输入详细申报数据：
S4.1: 操作人员输入税款所属时期和税种税目，若该税种在该所属时期已有资料（已申报过或本次申报已输入过），则给出提示，并可选择是否继续，若不继续则退出本模块；
S4.2: 纳税人的普通税种的申报资料（如计征金额等），系统在输入过程中对申报资料进行审核，并根据实际情况对不合理的输入采取禁止、自动修改、提示等措施；
S5: 系统根据纳税人的申报资料、登记资料、税额核定资料及减免税等批文自动计算应征税款；
S6: 系统参考纳税人的申报期限资料和延期申报批文等资料，如有逾期申报的，自动计算罚金和滞纳金数额，并根据需要打印罚单通知书；
S7: 系统将应征税额数据输出到集成申报模块或税款征收模块。 |
