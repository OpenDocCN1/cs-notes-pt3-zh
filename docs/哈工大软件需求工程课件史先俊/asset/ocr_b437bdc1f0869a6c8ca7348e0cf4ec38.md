# 举报受理的用例说明

| 名称 | 举报受理 |
| 简述 | 本用例（use case）描述了举报案件受理的过程，根据界面提示输入或接收相关举报案件的相关资料。 |
| 参与者 | 稽查机构的工作人员 |
| 前置条件 | 略 |
| 后置条件 | 略 |
| 基本事件流 | 1. 稽查机构的工作人员进入主页面并选中案件受理后启动用例。\n2. 稽查机构的工作人员将接到的举报人以书信、口头、电话或者其他形式举报的案件的，对举报人反映的偷税、逃避追缴欠税、骗税和虚开、伪造、非法提供、非法取得发票，以及其他税收违法行为，选择登记后要在《税务违法案件举报登记表》中进行登记有关内容，按提交申请请提交。\n3. 还可以通过网络或文件形式接收上下级或其他部门通过本软件转来的信息，可以对原始举报材料登记。\n4. 数据登记完以后点保存，确认无误后转举报案件请办。 |
| 可选事件流 | 2. 当检查机关工作人员选择“按受”案件时，直接跳到 3 |
| 非功能性需求 | 无 |
| 扩展点 | 无 |
