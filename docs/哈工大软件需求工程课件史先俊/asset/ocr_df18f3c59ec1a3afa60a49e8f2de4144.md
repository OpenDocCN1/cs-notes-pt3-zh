| 用例名称 | 个人所得税自行申报 |
| 用例编号 |  |
| 创建人 | 周昊 | 创建日期 | 2002.6.6 |
| 版本号 | 1.0 |  |  |
| 主要参与者 | 申报窗口受理人员；后台批量录入人员；银行窗口申报受理人员；使用电子申报的纳税人；使用电子申报的税务专员 |
| 重要参与者 |  |
| 简要描述 | 对受理的自行申报个人《个人所得税申报表》，创建、更新（发生变化时）时籍个人的人的档案，录入“申报表”，按照税法自动计算税额并保存。 |
| 触发事件 | 从“集成申报”进入；从“分税种申报”进入 |
| 前置条件 | 操作员具有相应的权限 |
| 事件流 | S1：如果从“集成申报”进入，转换 S3；
S2：如果从“分税种申报”进入，首先选择国籍，大陆居民输入身份证号码，外籍、港澳台居民输入护照号码，显示纳税号码【业务上暂时】；系统在全省国检档案该纳税人资料，如果到时显示（并非显示历史发生变化情况）。提示操作员核对资料是否匹配，如果匹配转 S3；如果不匹配，系统本次输入误则取消重新输入，如果输入档案对无误而是系统中原有存在的身份证号码、选择国籍等。操作员确认后系统标识原资料的状态为“待申报”，使用“纳税个人登记”为当前个人新建个人档案。
S3：如果申报方式为“上门申报”，系统弹出“纳税人通知事项”列表，如有通知事项及时通知纳税人。
S4：按申报表格式逐项录入所得项目、所得期间、人民币、外币收入额等，按税法规定自动带出减免额、应纳所得额、税率、速算扣除数、应纳税额等，已扣缴税额自动带出，可修改。按外已缴税额按时申报表中金额填写，系统自动计算应补退税额。另外要根据报税所属时期（所得期间）和延期申报资料自动申报中报、缴税期限。
S5：提交前操作员可随时使用“取消”按钮清除全部录入内容，或使用“退出”按钮退出当前操作面。全部项目录入完成后按保存按钮或使用功能键提交申报。提交成功后，若未清账，可直接对原录入内容进行修改后再次提交。对报交后的申报表可按“删除”按钮删除。
S6：如果需要立即进行税款征收，点击构成按钮，根据界面上选择的“缴款方式”使用相应的“税款征收”用例。 |
| 后置条件 |  |
| 可选事件流 | S5：系统如发现申报逾期日未经处理，中断提交过程，调用“逾期申报处理”用例；提交时系统检查相同纳税人是否存在税款所属时期交叉的同类申报，如存在则显示已存在的申报内容、求入人等信息，提示操作员确认是否要重复申报。 |
| 例外 |  |
| 非功能性需求 | 5. 一般项目输入响应时间<0.5s，特殊项目和提交响应时间<2s。
6. 全省平均每日申报量 xx 笔。
7. 全省高峰日期处理量 xx 笔。 |
