# Table 9-1. Sample RACI Chart

|  | GROUP A | GROUP B | GROUP C | GROUP D | GROUP E |
|---|---|---|---|---|---|
| Test Plans | R | A | C | C | I |
| Unit Test | C | I | R | A | I |
| Integration Test | A | R | I | C | C |
| System Test | I | C | A | I | R |
| User Acceptance Test | A | I | C | R | A |

R = Responsibility, only one R per task
A = Accountability
C = Consultation
I = Informed
