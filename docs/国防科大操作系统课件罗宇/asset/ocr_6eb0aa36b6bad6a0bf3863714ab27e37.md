# 按用途分类文件

+   - 系统文件
+   
+   如操作系统核心目标代码文件，驱动程序文件，注册库配置文件

如操作系统核心目标代码文件，驱动程序文件，注册库配置文件

+   - 库文件，实用程序文件
+   
+   如unix中的.so , ls、more等程序 windows中的 .dll, .exe

如unix中的.so , ls、more等程序 windows中的 .dll, .exe

+   - 其它文件
+   
+   如用户源程序文件，数据文件，各种应用程序用的数据文件。

如用户源程序文件，数据文件，各种应用程序用的数据文件。
