# 修改系统启动菜单

```
title Red Hat Linux (2.4.21)
root (hd0,0)
initrd /initrd-2.4.18-14.img
kernel /vmlinuz-2.4.21 ro
root=/dev/hda1"
```

换成你喜欢的名字，不能用中文，不能太长。

如果有这一行请删除

输入命令df，回车。可以看到：
Filesystem Used Available Use% Mounted on
/dev/hdc2 28030340 23% /
/dev/hdc1 76831 20% /boot
找到Mounted on / 这一行，令root=这一行的FileSystem
