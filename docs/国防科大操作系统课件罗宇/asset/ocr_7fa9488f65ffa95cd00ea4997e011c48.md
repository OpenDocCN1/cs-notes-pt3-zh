# 编写内核模块

+   - 请打开记事本（或其他文本编辑器）
+   - 输入右边的程序
+   - 保存为hello.c
+   - 注意第一行的 KERNEL前后各有两个下划线。

```
#define __KERNEL__
#define MODULE
#include <linux/module.h>
#include <linux/kernel.h>

MODULE_LICENSE("GPL");

int init_module()
{
    printk("Hello!\n");
    return 0;
}
void cleanup_module()
{
    printk("Quit...\n");
}
```
