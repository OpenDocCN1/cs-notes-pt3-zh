+   • shmget（）函数有一个参数指定共享内存区域的大小，该函数建立的共享内存区在内核中用shmid_kernel结构表示

```
struct shmid_kernel{
    struct kern_ipc_perm    shm_perm;
    struct file *           shm_file;
    int                     id;
    unsigned long shm_nattch;/*已建立映射的数目*/
    unsigned long shm_segsz;/*共享内存区的大小*/
    time_t                  shm_atim;
    time_t                  shm_dtim;
    time_t                  shm_ctim;
    pid_t                   shm_cprid;
    pid_t                   shm_lprid;
};
```
