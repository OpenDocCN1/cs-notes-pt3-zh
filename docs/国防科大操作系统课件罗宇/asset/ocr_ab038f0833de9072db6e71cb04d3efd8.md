# 4. 将线程变为独立状态

```
int pthread_detach(pthread_t tid);
```

线程或者是可汇合的（joinable）或者是独立的（detached）。当可汇合的线程终止时，其线程ID和退出状态将保留，直到另外一个线程调用pthread_join。独立的线程终止时，所有的资源都释放，我们不能等待它终止。如果一个线程需要知道另一个线程什么时候终止，最好保留第二个线程的可汇合性。

# 6. 加锁/解锁

```
int pthread_mutex_lock(pthread_mutex_t *mutex)
int pthread_mutex_unlock(pthread_mutex_t *mutex)
```

这两个函数用于对临界区的加锁和解锁。以保证对共享数据的互斥操作。Mutex是指向锁结构的地址。
