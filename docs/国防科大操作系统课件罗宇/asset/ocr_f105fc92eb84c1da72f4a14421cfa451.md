数组entries的每一项指向一个 kern_ipc_perm结构，kern_ipc_perm结构表示每一个IPC资源的属性，用来控制操作权限。

```
struct kern_ipc_perm {
    key_t      key;    /*用户提供的键值, 为XXXget()所用*/
    uid_t      uid;    /*创建者用户ID*/
    gid_t      gid;    /*创建者组ID*/
    uid_t      cuid;   /*所有者用户ID*/
    gid_t      cgid;   /*所有者组ID*/
    mode_t     mode;   /*操作权限, 包括读、写等*/
    unsigned long seq;
};
```

因为每个IPC资源描述符的第一个成员就是 kern_ipc_perm结构。因此，我们可以认为数组entries的每一非空项均指向一个IPC资源。
