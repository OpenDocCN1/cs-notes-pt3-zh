# Transitivity

+   - A relation is **transitive** if
+     - for all \(a, b, c \in A\), \(((a,b)\in R \land (b,c)\in R) \Rightarrow (a,c)\in R\)
+   - If \(a < b\) and \(b < c\), then \(a < c\)
+     - Thus, \(<\) is transitive
+   - If \(a = b\) and \(b = c\), then \(a = c\)
+     - Thus, \(=\) is transitive
