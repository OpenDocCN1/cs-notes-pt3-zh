# Symbols

+   Logical symbols:
+   - Truth constants: T, F
+   - Logical connectives: ¬, ∧, ∨, →, ↔
+   - Quantifiers: ∀, ∃
+   - Variables: x, y, z, ...
+   - Auxiliary symbols: '(', ')', ','

+   Non-logical symbols:
+   - Functions: f, g, h, ...
+     - Constants: a, b, c, ...
+   - Predicates: P, Q, R, ...
