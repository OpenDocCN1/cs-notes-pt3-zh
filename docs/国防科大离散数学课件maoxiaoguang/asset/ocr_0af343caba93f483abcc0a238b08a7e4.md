# 常用蕴含式

+   I1  P∧Q ⇒ P  化简式
+   I2  P∧Q ⇒ Q
+   I3  P ⇒ P∨Q  附加式
+   I4  Q ⇒ P∨Q
+   I5  ¬P ⇒ P→Q
+   I6  Q ⇒ P→Q
+   I7  ¬(P→Q) ⇒ P
+   I8  ¬(P→Q) ⇒ ¬Q
+   I9  P→Q ⇒ P∧R→Q∧R
+   I10 ¬P∧(P∨Q) ⇒ Q  析取三段论
+   I11 P∧(P→Q) ⇒ Q  假言推论
+   I12 ¬Q∧(P→Q) ⇒ ¬P  拒取式
+   I13 (P→Q)∧(Q→R) ⇒ P→R  假言三段论
+   I14 (P∨Q)∧(P→R)∧(Q→R) ⇒ R  二难推论
