# 解释

对合式公式 $G$ 的解释包括以下几点：

+   i) 指定一个非空集合 $D$，称为 $I$ 的论域，并称为 $D$ 上的解释；
+   
+   ii) 对 $G$ 中出现的每个个体常元和自由变元，指定 $D$ 中的一个元素；
+   
+   iii) 对 $G$ 中出现的每个 $n$ 元函数词，指定一个 $D$ 上的 $n$ 元函数；
+   
+   iv) 对 $G$ 中出现的每个命题词，指定一个真值 $T$ 或 $F$；
+   
+   v) 对 $G$ 中出现的每个 $n$ 元谓词，指定一个从 $D^n$ 到 $\{T,F\}$ 的函数；

$G_I$ 的真值为合式公式 $G$ 在 $I$ 下的真值。
