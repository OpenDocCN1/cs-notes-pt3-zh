# Further findings

+   If you realize that the above proof is valid for any valuation \(v\), then you see that the rule is truth preserving:
+   
+   \[
+   (A \lor I) \land (B \lor \neg I) \Rightarrow (A \lor B)
+   \]

+   Thus you obtained also a method of finding **logical consequences of a formula.**

+   Moreover:
+   
+   \[
+   (A \lor I) \land (B \lor \neg I) \Leftrightarrow (A \lor I) \land (B \lor \neg I) \land (A \lor B)
+   \]
