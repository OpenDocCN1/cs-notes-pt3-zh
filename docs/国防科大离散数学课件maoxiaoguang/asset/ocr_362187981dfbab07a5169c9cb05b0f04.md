# Example —
direct proof / forward reasoning

+   Prove that (¬q → p) ∧ (p ∨ r) ∧ (q → ¬r) logically entails p.

+   CNF: (q ∨ p) ∧ (p ∨ r) ∧ (¬q ∨ ¬r)

+   Direct proof: from facts to conclusion

(Proof:)

+   1. q ∨ p        fact

+   2. p ∨ r        fact

+   3. ¬q ∨ ¬r      fact

+   4. p ∨ ¬r       resolution: 1, 3

+   5. p            resolution: 2, 4
