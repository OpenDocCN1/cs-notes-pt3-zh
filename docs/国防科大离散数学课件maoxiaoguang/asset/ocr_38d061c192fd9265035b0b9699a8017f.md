# 自然推理系统的规则

10. →引入规则(→₊)
若Γ, A ⊢ B, 则Γ ⊢ A→B

11. →消除规则(→₋)
若Γ ⊢ A, A→B, 则Γ ⊢ B

12. ¬引入规则(¬₊)
若Γ, A ⊢ B, ¬B, 则Γ ⊢ ¬A

13. ¬消除规则(¬₋)
若Γ ⊢ A, ¬A, 则Γ ⊢ B

14. ¬¬引入规则(¬¬₊)
若Γ ⊢ A, 则Γ ⊢ ¬¬A

15. ¬¬消除规则(¬¬₋)
若Γ ⊢ ¬¬A, 则Γ ⊢ A

16. 引入规则(⇔₊)
若Γ, A ⊢ B且Γ, B ⊢ A, 则Γ ⊢ A ⇔ B

17. 消除规则(⇔₋)
若Γ ⊢ A ⇔ B, 则Γ ⊢ A→B, B→A
