# A simple example

Wff: ¬(p→q)

CNF: (¬p ∨ ¬q) ∧ (p ∨ ¬q) ∧ (p ∨ q)

DNF: (p ∧ ¬q)

If we construe a CCNF (CDNF) from a truth table, we take into account only those rows, where the function has the value F (T), and construct CED (CEC) in such a way that the CED (CEC) is false (true).

| p | q | ¬(p→q) | CNF | DNF |
| --- | --- | --- | --- | --- |
| T | T | F | ¬p∨¬q |  |
| T | F | T |  | p∧¬q |
| F | T | F | p∨¬q |  |
| F | F | F |  | p∨q |
