# Example of which to use

+   - Prove that if n is an integer and n³+5 is odd, then n is even

+   - Via direct proof
+     - n³+5 = 2k+1 for some integer k (definition of odd numbers)
+     - n³ = 2k-4
+     - Umm...      n = ∛(2k - 4)   ???

+   - So direct proof doesn’t work out. So: indirect proof
+     - Contrapositive: If n is odd, then n³+5 is even
+     - Assume n is odd, and show that n³+5 is even
+     - n=2k+1 for some integer k (definition of odd numbers)
+     - n³+5 = (2k+1)³+5 = 8k³+12k²+6k+6 = 2(4k³+6k²+3k+3)
+     - As 2(4k³+6k²+3k+3) is 2 times an integer, it is even
