# 一些重要的等价式和蕴含式

E25  (∃x)(A(x) ∨ B(x)) ⇔ (∃x)A(x) ∨ (∃x)B(x)

E26  (∀x)(A(x) ∧ B(x)) ⇔ (∀x)A(x) ∧ (∀x)B(x)

E27  ¬(∃x)A(x) ⇔ (∀x)(¬A(x))

E28  ¬(∀x)A(x) ⇔ (∃x)(¬A(x))

E29  (∀x)(A(x) ∨ P) ⇔ (∀x)A(x) ∨ P

E30  (∀x)(A(x) ∧ P) ⇔ (∀x)A(x) ∧ P

E31  (∃x)(A(x) ∨ P) ⇔ (∃x)A(x) ∨ P

E32  (∃x)(A(x) ∧ P) ⇔ (∃x)A(x) ∧ P
