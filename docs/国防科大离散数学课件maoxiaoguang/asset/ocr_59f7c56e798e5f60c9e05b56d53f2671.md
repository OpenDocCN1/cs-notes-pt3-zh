# Finding the transitive closure

Let M_R be the zero-one matrix of the relation R on a set with n elements. Then the zero-one matrix of the transitive closure R* is:

M_R* = M_R ∨ M_R^[2] ∨ M_R^[3] ∨ … ∨ M_R^[n]
