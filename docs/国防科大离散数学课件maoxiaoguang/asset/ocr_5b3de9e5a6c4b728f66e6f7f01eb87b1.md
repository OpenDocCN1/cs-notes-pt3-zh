# Summary of properties of relations

| reflexive | ∀a (a, a) ∈ R |
| irreflexive | ∀a (a, a) ∉ R |
| symmetric | ∀ a, b ∈ A, (a,b) ∈ R ⇒ (b,a) ∈ R |
| asymmetric | ∀ a, b ∈ A, (a,b) ∈ R ⇒ (b,a) ∉ R |
| antisymmetric | ∀ a, b ∈ A, ((a,b) ∈ R ∧ (b,a) ∈ R) ⇒ a=b
(*)for all a, b ∈ A, ((a,b) ∈ R ∧ a ≠ b) ⇒ (b,a) ∉ R |
| transitive | ∀ a, b, c ∈ A, ((a,b) ∈ R ∧ (b,c) ∈ R) ⇒ (a,c) ∈ R |
