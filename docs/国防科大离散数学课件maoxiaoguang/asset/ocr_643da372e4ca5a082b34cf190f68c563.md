# Sequence examples

aₙ = 3n

+   - The terms in the sequence are a₁, a₂, a₃, ...
+   - The sequence {aₙ} is { 3, 6, 9, 12, ... }

# Arithmetic Progression

+   - a, a+d, a+2d, ..., a+nd, ...
+   - aₙ = a + (n-1) d

bₙ = 2ⁿ

+   - The terms in the sequence are b₁, b₂, b₃, ...
+   - The sequence {bₙ} is { 2, 4, 8, 16, 32, ... }

# Geometric Progression

+   - a, ar, ar², ar³, ..., arⁿ⁻¹, ...
+   - aₙ = arⁿ⁻¹
