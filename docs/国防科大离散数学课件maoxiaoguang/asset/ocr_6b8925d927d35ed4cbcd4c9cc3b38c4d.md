# Proof by contradiction example 1

Theorem (by Euclid): There are infinitely many prime numbers.

(Proof) Assume there are finite number of primes

List them as follows: p₁, p₂ ..., pₙ.

Consider the number q = p₁p₂ ... pₙ + 1

+   - This number is not divisible by any of the listed primes
+     - If we divided pᵢ into q, there would result a remainder of 1
+   - We must conclude that q is a prime number, not among the primes listed above
+     - This contradicts our assumption that all primes are in the list p₁, p₂ ..., pₙ.
