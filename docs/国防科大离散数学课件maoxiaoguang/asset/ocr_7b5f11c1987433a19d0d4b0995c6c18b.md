# 一些两个量词的等价式和蕴含式

B1    (∀x)(∀y)P(x,y) ⇔ (∀y)(∀x)P(x,y)

B2    (∀x)(∀y)P(x,y) ⇒ (∃y)(∀x)P(x,y)

B3    (∀y)(∀x)P(x,y) ⇒ (∃x)(∀y)P(x,y)

B4    (∃y)(∀x)P(x,y) ⇒ (∀x)(∃y)P(x,y)

B5    (∃x)(∀y)P(x,y) ⇒ (∀y)(∃x)P(x,y)

B6    (∀x)(∃y)P(x,y) ⇒ (∃y)(∃x)P(x,y)

B7    (∀y)(∃x)P(x,y) ⇒ (∃x)(∃y)P(x,y)

B8    (∃x)(∃y)P(x,y) ⇔ (∃y)(∃x)P(x,y)
