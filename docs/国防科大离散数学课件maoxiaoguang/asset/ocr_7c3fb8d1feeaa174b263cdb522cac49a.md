# Resolution for propositional logic

+   Ground (propositional) resolution is a single sound inference rule that is applied to clauses.

+   A clause is a disjunction of literals.

+   Example, (p ∨ ¬q ∨ r) is a clause.

+   Resolution: (A ∨ p), (B ∨ ¬p)
+   (A ∨ B)

+   Example, (¬p ∨ q), (¬q ∨ r)
+   (¬p ∨ r)
