# 自然推理系统的规则

+   1. 肯定前提规则(∈)
+      Γ, A ⊢ A
+   2. 前提引入规则(∈₊)
+      若Γ ⊢ B, 则Γ, A ⊢ B
+   3. 前提消去规则(∈₋)
+      若Γ, A ⊢ B且Γ, ¬A ⊢ B, 则Γ ⊢ B
+   4. T规则
+      Γ ⊢ T
+   5. F规则
+      Γ ⊢ ¬F
+   6. ∨引入规则(∨₊)
+      若Γ ⊢ A, 则Γ ⊢ A∨B, B∨A
+   7. ∨消去规则(∨₋)
+      若Γ, A ⊢ C且Γ, B ⊢ C, 则Γ, A∨B ⊢ C
+   8. ∧引入规则(∧₊)
+      若Γ ⊢ A, B, 则Γ ⊢ A∧B
+   9. ∧消去规则(∧₋)
+      若Γ ⊢ A∧B, 则Γ ⊢ A, B
