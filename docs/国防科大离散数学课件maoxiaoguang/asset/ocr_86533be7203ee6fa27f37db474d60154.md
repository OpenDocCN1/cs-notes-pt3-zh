# 一些重要的等价式和蕴含式

E33  (∃x)(A(x)→P) ⇔ (∀x)A(x)→P

E34  (∀x)(A(x)→P) ⇔ (∃x)A(x)→P

E35  (∀x)(P→B(x)) ⇔ P→(∀x)B(x)

E36  (∃x)(P→B(x)) ⇔ P→(∃x)B(x)

E37  (∃x)(A(x)→B(x)) ⇔ (∀x)A(x)→(∃x)B(x)

I15  (∀x)A(x) ∨ (∀x)B(x) ⇒ (∀x)(A(x) ∨ B(x))

I16  (∃x)(A(x) ∧ B(x)) ⇒ (∃x)A(x) ∧ (∃x)B(x)

I17  (∃x)A(x)→(∀x)B(x) ⇒ (∀x)(A(x)→B(x))

I18  (∀x)A(x) ⇒ (∃x)A(x)
