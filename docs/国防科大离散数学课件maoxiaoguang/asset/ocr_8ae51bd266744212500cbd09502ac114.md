# Logical connectives

| Formal Name | Nick Name | Parity | Symbol |
|---|---|---|---|
| Negation | NOT | Unary | ¬ |
| Conjunction | AND | Binary | ∧ |
| Disjunction | OR | Binary | ∨ |
| Exclusive Or | XOR | Binary | ⊕ |
| Implication | IMPLIES | Binary | → |
| Bi-conditional | IFF | Binary | ↔ |

+   - p = "Today is Friday"
+   - q = "Today is my birthday"
