# Proof

+   - K₃,₃ has 6 vertices and 9 edges.
+   - Obviously, v ≥ 3 and there are no circuits of length 3.
+   - If K₃,₃ were planar, then e ≤ 2v − 4 would have to be true.
+   - 2v − 4 = 2*6 − 4 = 8
+   - So e must be ≤ 8.
+   - But e = 9.
+   - So K₃,₃ is nonplanar.
