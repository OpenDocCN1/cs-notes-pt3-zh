# Indirect proof example

+   - If n² is an odd integer then n is an odd integer
+   - Prove the contrapositive: if n is an even integer, then n² is an even integer

(Proof) Assume n is an even integer

n = 2k for some integer k (def. of even numbers)

n² = (2k)² = 4k² = 2(2k²)

Since n² is 2 times an integer, it is even
