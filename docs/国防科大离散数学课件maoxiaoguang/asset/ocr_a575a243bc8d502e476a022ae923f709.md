# Proof by cases example

+   Prove that |a/b| = |a|/|b|
+   Note that b ≠ 0

+   Cases:

+   Case 1: a ≥ 0 and b > 0
+   Then |a| = a, |b| = b, and
+   |a/b| = a/b = |a|/|b|

+   Case 2: a ≥ 0 and b < 0
+   Then |a| = a, |b| = -b, and
+   |a/b| = -a/-b = a/|b| = |a|/|b|

+   Case 3: a < 0 and b > 0
+   Then |a| = -a, |b| = b, and
+   |a/b| = -a/b = -a/b = |a|/|b|

+   Case 4: a < 0 and b < 0
+   Then |a| = -a, |b| = -b, and
+   |a/b| = a/b = -a/-b = |a|/|b|
