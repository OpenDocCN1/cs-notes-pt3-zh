# Evaluating sequences

∑⁵ₖ₌₁ (k+1) = 2 + 3 + 4 + 5 + 6 = 20

∑⁴ₖ₌₀ (−2)ᵏ
= (−2)⁰ + (−2)¹ + (−2)² + (−2)³ + (−2)⁴
= 11

∑¹⁰ₖ₌₁ 3
= 3 + 3 + 3 + 3 + 3 + 3 + 3 + 3 + 3 + 3
= 30

∑¹⁰ₖ₌₁ (2ᵏ − 2ᵏ⁻¹)
= (2¹−2⁰) + (2²−2¹) + (2³−2²) + … (2¹⁰−2⁹)
= 511

> Note that each term (except the first and last) is cancelled by another term
