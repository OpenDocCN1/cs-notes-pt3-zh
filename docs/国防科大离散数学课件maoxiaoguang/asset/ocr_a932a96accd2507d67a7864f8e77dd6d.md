# Operations on Graphs - Union

+   The union of two simple graphs G₁ = (V₁, E₁) and G₂ = (V₂, E₂) is the simple graph with vertex set V₁ ∪ V₂ and edge set E₁ ∪ E₂.

+   The union of G₁ and G₂ is denoted by G₁ ∪ G₂.
