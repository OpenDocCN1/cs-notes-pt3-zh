# 解一：

令： (论域为自然数域)

+   - Q(x): x是奇数；
+   - P(x): x是偶数；
+   - R(x): x能被2整除；

则上述命题被符号化为：

+   - 每一个自然数不是奇数就是偶数 ： (∀x)(Q(x)∨P(x)) ；
+   - 自然数偶数当且仅当它能被2整除 ： (∀x)(P(x)⇔R(x)) ；
+   - 并不是所有的自然数都能被2整除 ： ¬(∀x)R(x) ；
+   - 有的自然数是奇数 ： (∃x)Q(x) 。

于是，上述一段话等价于形式推理关系：

```
(∀x)(Q(x)∨P(x)), (∀x)(P(x)⇔R(x)), ¬(∀x)R(x) ⊢ (∃x)Q(x)
```
