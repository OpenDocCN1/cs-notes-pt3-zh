# Floor property proof

# Prove rule 4a: ⌊x+n⌋ = ⌊x⌋+n

+   - Where n is an integer
+   - Will use rule 1a: ⌊x⌋ = n if and only if n ≤ x < n+1

# Direct proof!

+   - Let m = ⌊x⌋
+   - Thus, m ≤ x < m+1 (by rule 1a)
+   - Add n to both sides: m+n ≤ x+n < m+n+1
+   - By rule 4a, m+n = ⌊x+n⌋
+   - Since m = ⌊x⌋, m+n also equals ⌊x⌋+n
+   - Thus, ⌊x⌋+n = m+n = ⌊x+n⌋
