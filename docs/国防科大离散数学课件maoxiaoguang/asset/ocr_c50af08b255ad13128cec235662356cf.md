# Negating multiple quantifiers 1

+   Recall negation rules for single quantifiers:
+   - ¬∀x P(x) = ∃x ¬P(x)
+   - ¬∃x P(x) = ∀x ¬P(x)
+   - Essentially, you change the quantifier(s), and negate what it’s quantifying

+   Examples:
+   - ¬(∀x∃y P(x,y)) = ∃x (¬∃y P(x,y))
+     = ∃x∀y(¬P(x,y))
+   - ¬(∀x∃y∀z P(x,y,z)) = ∃x (¬∃y∀z P(x,y,z))
+     = ∃x∀y(¬∀z P(x,y,z)) = ∃x∀y∃z (¬P(x,y,z))
