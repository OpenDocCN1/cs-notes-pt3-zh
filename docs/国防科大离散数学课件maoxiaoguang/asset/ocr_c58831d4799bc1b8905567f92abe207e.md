# Ceiling and floor properties

Let n be an integer

(1a) ⌊x⌋ = n if and only if n ≤ x < n+1

(1b) ⌈x⌉ = n if and only if n-1 < x ≤ n

(1c) ⌊x⌋ = n if and only if x-1 < n ≤ x

(1d) ⌈x⌉ = n if and only if x ≤ n < x+1

(2) x-1 < ⌊x⌋ ≤ x ≤ ⌈x⌉ < x+1

(3a) ⌊-x⌋ = -⌈x⌉

(3b) ⌈-x⌉ = -⌊x⌋

(4a) ⌊x+n⌋ = ⌊x⌋+n

(4b) ⌈x+n⌉ = ⌈x⌉+n
