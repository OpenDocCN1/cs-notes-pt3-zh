# Symmetric closure

+   - In order to find the symmetric closure of a relation $R$, we add an edge from $a$ to $b$, where there is already an edge from $b$ to $a$
+   - The symmetric closure of $R$, $s(R)$, is $R \cup R^{-1}$
+     - If $R = \{ (a,b) \mid \dots \}$
+     - Then $R^{-1} = \{ (b,a) \mid (a,b) \text{ in } R \}$
