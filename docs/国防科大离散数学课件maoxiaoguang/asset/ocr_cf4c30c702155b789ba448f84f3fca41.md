# 例

判定 (∃x)P(x) ∧ (∃x)Q(x) → (∃x)(P(x) ∧ Q(x)) 是否为永真式

分析： (∃x)P(x) ∧ (∃x)Q(x) → (∃x)(P(x) ∧ Q(x)) 为假

(∃x)P(x) ∧ (∃x)Q(x)      (∃x)(P(x) ∧ Q(x))
---------------------------
T                         F

(∃x)P(x)      (∃x)Q(x)      (∃x)(P(x) ∧ Q(x))
--------      --------      -------------------
T             T              F

证明：构造解释如下：

+   i) D = {1, 2}
+   ii) P(1) P(2)    Q(1) Q(2)
+        -----      ----
+         T   F      F   T

则(∃x)P(x)，(∃x)Q(x)在I下均为真，而(∃x)(P(x) ∧ Q(x))在I下为假。故非永真式。
