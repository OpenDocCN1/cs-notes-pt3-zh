# Proof using Logical Equivalence

(p → r) ∨ (q → r)

⇔ (¬ p ∨ r) ∨ (¬ q ∨ r)    Definition of implication

⇔ ¬ p ∨ r ∨ ¬ q ∨ r    Associative

⇔ ¬ p ∨ ¬ q ∨ r ∨ r    Commutative

⇔ (¬ p ∨ ¬ q) ∨ (r ∨ r)    Associative

⇔ ¬ (p ∧ q) ∨ r    De Morgan, Idempotent

⇔ (p ∧ q) → r    Definition of implication
