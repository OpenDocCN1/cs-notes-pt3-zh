# Complement sets

# Formal definition for the complement of a set:

Aᶜ = { x | x ∉ A } = Aᶜ

+   Or U − A, where U is the universal set

# Further examples (assuming U = Z)

+   {1, 2, 3}ᶜ = { ..., -2, -1, 0, 4, 5, 6, ... }

+   {a, b}ᶜ = Z ?

# Properties of complement sets

+   (Aᶜ)ᶜ = A
+   Complement law

+   A ∪ Aᶜ = U
+   Complement law

+   A ∩ Aᶜ = ∅
+   Complement law
