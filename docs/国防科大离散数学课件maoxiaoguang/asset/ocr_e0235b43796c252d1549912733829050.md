# Example –
indirect proof / backward reasoning

+   Prove that (¬q → p) ∧ (p ∨ r) ∧ (q → ¬r) logically entails p.

+   Convert to: Prove that the following wff is a contradiction:
+   (¬q → p) ∧ (p ∨ r) ∧ (q → ¬r) ∧ ¬p

+   CNF: (q ∨ p) ∧ (p ∨ r) ∧ (¬q ∨ ¬r) ∧ ¬p
+   (Proof by resolution:)

+   1. q ∨ p

+   2. p ∨ r

+   3. ¬q ∨ ¬r

+   4. ¬p

+   5. p ∨ ¬r        resolution: 1, 3

+   6. p             resolution: 2, 5

+   7.               4, 6
