# 自然推理系统的规则

+   18. ∀引入规则(∀+)
+   若Γ ⊢ A(x), 则Γ ⊢ (∀x)A(x),
+   其中x不是Γ中任何公式的自由变元。

+   19. ∀消除规则(∀-)
+   若Γ ⊢ (∀x)A(x), 则Γ ⊢ A(t),
+   其中项t对于A(x)中的x是可代入的。

+   20. ∃引入规则(∃+)
+   若Γ ⊢ A(t), 则Γ ⊢ (∃x)A(x),
+   其中项t对于A(x)中的x是可代入的。

+   21. ∃消除规则(∃-)
+   若Γ ⊢ (∃x)A(x)且Γ, A(b) ⊢ C, 则Γ ⊢ C,
+   其中b是在(∃x)A(x), C和Γ的每个公式中都不出现的个体常元。
