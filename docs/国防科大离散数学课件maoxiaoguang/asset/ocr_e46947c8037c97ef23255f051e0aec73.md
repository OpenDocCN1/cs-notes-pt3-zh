# Conversion to DNF with ⇔

+   ① Eliminate ⇔, replacing a ⇔ β with (a → β) ∧ (β → a).

+   ② Eliminate →, replacing a → β with ¬a ∨ β.

+   ③ Move ¬ inwards using de Morgan's rules and double-negation.
+     ▸ ¬(a∨β) ⇔ ¬a∧¬β
+     ▸ ¬(a∧β) ⇔ ¬a∨¬β
+     ▸ ¬¬a ⇔ a

+   ④ Apply distributive law (∨ over ∧) and flatten.
+     ▸ a∧(β∨γ) ⇔ (a∧β) ∨ (a∧γ)
