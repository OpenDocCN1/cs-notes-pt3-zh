# 左∃引入规则证明

+   1. Γ, A(x) ⊢ B 已知
+   2. Γ ⊢ A(x)→B (→₊) (1)
+   3. Γ ⊢ (∀x)(A(x)→B) (∀₊) (1)
+   4. Γ, (∃x)A(x) ⊢ (∃x)A(x) (∈)
+   5. Γ, (∃x)A(x), A(a) ⊢ A(a) (∈)
+   6. Γ, (∃x)A(x), A(a) ⊢ (∀x)(A(x)→B) (∈₊) (3)
+   7. Γ, (∃x)A(x), A(a) ⊢ A(a)→B (∀-) (6)
+   8. Γ, (∃x)A(x), A(a) ⊢ B (→-) (5, 7)
+   9. Γ, (∃x)A(x) ⊢ B (∃-) (4, 8)
