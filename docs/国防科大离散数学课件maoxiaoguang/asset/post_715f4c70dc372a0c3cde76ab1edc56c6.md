## 量词

量词：表示命题中个体数量的词。

∀ 全称量词 表示论域中全部元素

∃ 存在量词 ... 部分 ...

(∀x) ：关于x的全称量词

(∃x) ： ... 存在 ...

(∀x₁)…(∀xₙ)：简写为(∀x₁…xₙ)

* 量词后面的子wff除原子外需加括号。

## 全称量词

+   - ∀x读作 ‘对任意x’
+   - (∀x)(P(x))表示 ‘对一切x, P(x)为真’
+   - (∀x)(¬P(x))表示 ‘对一切x, ¬P(x)为真’
+   - ¬(∀x)(P(x)) 表示 ‘并非对任意x, P(x)是真’

## 存在量词

+   - ∃x读作 ‘至少有一个x’， ‘存在一个x’
+   - (∃x)(P(x)) 表示 ‘存在一个x，使P(x) 为真’
+   - (∃x)(¬P(x)) 表示 ‘存在一个x，使¬P(x) 为真’
+   - ¬(∃x)(P(x))表示 ‘并非存在一个x，使P(x)为真’

## 量词的语义

量词： 设P为论域D上的一个一元谓词，则

命题(∀x)P(x)的真值为T
iff
对每个a∈D，命题P(a)的真值皆为T；

命题(∃x)P(x)的真值为T
iff
有a∈D，使命题P(a)的真值为T。

若D = {a₁, a₂, ..., aₙ}，则
(∀x)P(x) ⇔ P(a₁) ∧ ... ∧ P(aₙ)
(∃x)P(x) ⇔ P(a₁) ∨ ... ∨ P(aₙ)

## 例

如果 R(x,y) 表示 “x 依赖 y”，列出下列公式的含义：

+   - ∀x(∃y R(x,y)) = 每个人都有某些人可依靠。
+   - ∃y(∀x R(x,y)) = 有些人被所有的人依赖。（包括自己）
+   - ∃x(∀y R(x,y)) = 有些人依赖所有的人。（包括自己）
+   - ∀y(∃x R(x,y)) = 每个人都被某些人依赖。
+   - ∀x(∀y R(x,y)) = 每个人都依赖所有的人。

## 命题符号化

对一个给定的命题，用上面介绍的形式符号（个体常元、个体变元、函词、谓词和量词）及逻辑联结词（¬、∧、∨、→和↔）正确地表示出来，称为对它的符号化。

## 符号化原则

+   1) 逐词翻译的原则；
+   2) 词性翻译；
+   3) 语义上理解后进行符号化；
+   4) 特性谓词；
+   5) 数学公式的符号化。

论域为全域 或 论域的子域内取值

在全称量词约束下用 “→”

在存在量词约束下用 “∧”

## 词性翻译

+   名词: → 个体常量
+   专有名词、普通名词、被名词所有格或物主代词修饰
+   代词: → 个体常量
+   人称代词、指示代词
+   形容词: → 谓词
+   动词: → 谓词
+   数量词: → 量词
+   全体概念、部分概念
+   副词和前置词: 与其它词类合并，不单独分析
+   连词: → 逻辑连接词
