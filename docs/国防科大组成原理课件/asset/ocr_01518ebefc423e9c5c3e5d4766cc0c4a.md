# 事务内存（Transaction Memory）

+   - 在多处理器中，由于同步次数较少、粒度较大，采用锁同步机制是较合适的；但是多核处理器中，同步次数多、粒度小，采用锁同步机制代价较大
+   - 事务定义：
+     - 将对共享变量访问的代码区域声明为一个事务（transaction）
+     - 事务执行并原子地提交所有结果到内存（如果事务成功），或中止并取消所有的结果（如果事务失败）
+   - 事务具有原子性（Atomicity），一致性（Consistency）和隔离性（Isolation）
+     - 原子性：事务中的所有指令，要么执行，要么不执行
+     - 一致性：任何时刻，内存处于一个一致的状态
+     - 隔离性：事务不能看见其他未提交事务所涉及到的内部对象的状态
