# 内存基本单元

+   - 由MOS管T和电容（存储单元）组成
+     - 电容C存储的电位决定存储单元的逻辑值
+     - 字线：根据地址译码，连接同一字的不同位
+     - 位线：读写的数据，连接不同字的同一位

+   - 读写过程
+     - 把位线预充到Vref=VCC/2
+     - 字线打开T管，C引起位线微小的电位差，感应放大器读出
+     - 此时C中的电位被破坏，感应放大器恢复原来的值，如果是写操作，字线上提供更大的电流重置感应放大器和位线的值
+     - 在下一次预充前感应放大器保持读出的值
