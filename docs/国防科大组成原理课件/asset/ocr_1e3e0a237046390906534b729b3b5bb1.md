# 基于锁的同步

+   - 将可能并发访问同一块数据的代码定义为临界区
+   - 进入临界区前先申请锁（并加锁）
+   - 申请失败者被阻塞
+   - 持有锁的线程离开临界区后释放锁
+   - 锁的类型
+     - 自旋锁：循环等待直至得到锁
+     - 互斥锁：如果加锁失败则休眠等待
+     - 读写锁：允许有多个读或者一个写

```
selfspin:
ll      t0, lock
bnez    t0, selfspin
nop
li      t1, 0x1
sc      t1, lock
beqz    t1, selfspin
nop
<Critical section>
sw      zero, lock
```
