# 从上述分析可以看出

+   - 简单操作和简单寻址方式用得最多
+     - 10种简单操作指令占96%
+     - 寄存器, 立即数, 偏移寻址, 寄存器间接寻址四种寻址方式
+   - 简单指令便于高效实现和使用
+     - load-store结构简化硬件设计，提高主频
+     - 定长简化译码
+     - 符合编译器 “常用的做得快，少用的只要对” 的原则
+   - 硬件优化应充分考虑兼容性
+     - 流水、多发射不改变指令系统
+     - 流水、多发射技术在load-store指令系统上容易实现
+   - 上述原因呼唤RISC系统结构
+     - 简单是最复杂的创新
