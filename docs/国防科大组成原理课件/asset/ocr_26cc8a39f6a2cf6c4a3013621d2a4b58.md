# # MIPS ABI示例一(3)

+   - 栈大小不定的非叶子函数

```
```c
int foo(int n)
{
    int arr[n];
    arr[0]=n;
    for (int i=1; i<n; i++)
        arr[i]=arr[i-1]+i;
    return arr[n-1];
}
```
