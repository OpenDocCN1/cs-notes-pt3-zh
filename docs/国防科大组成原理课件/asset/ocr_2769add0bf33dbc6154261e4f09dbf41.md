# 片上性能计数器

+   - 性能计数器（performance counter）是一种特殊的硬件寄存器，用于对处理器内部的硬件事件进行计数
+     - 用于在执行复杂的、真实的应用时捕获处理器的性能行为和应用的行为，如指令数目、Cache失效的次数、分支误预测的次数等
+     - 计数不会对应用和操作系统造成影响，但可以被读取
+     - 统计事件的数量超过性能计数器的范围，通过中断通知OS
+     - 主流高性能和嵌入式处理器，都在片上集成了硬件性能计数器
+   - 性能计数器可以实时地统计复杂应用的性能行为
+     - 比模拟器真实、准确，可以统计复杂应用
+     - 在处理器设计时就事先安排，不如模拟器灵活
