# IBM POWER性能分析方法和流程

+   - 在PowerPC 620、POWER4的研制中，开发了微体系结构探索的整套环境，称为MET（microarchitecture evaluation toolsets），主要用于微体系结构层面的功耗和性能建模
+     - 包括Turandot、Aria、Rondo、LeProf、eOak、PavaRotti、RAMP和PowerTimer等工具
+   - 在后续POWER7和POWER8处理器的设计中形成了更为完善的性能建模、验证和评估的方法
+     - 包括M1模型、核的建模、巢的建模、数千个硅前验证的性能测试程序集（PVPs）、Mesa仿真器、Awan仿真加速器、基于采样的方法、基于M1模型和加速器模型性能数据校验的方法等
