# Load/Store指令

+   - 对任何GPR和FPR进行存取操作
+     - 通常R0总是为0
+   - MIPS的例子

| OpCode | Description |
|--------|-------------|
| LB | Load Byte |
| LBU | Load Byte Unsigned |
| LH | Load Halfword |
| LHU | Load Halfword Unsigned |
| LW | Load Word |
| LWL | Load Word Left |
| LWR | Load Word Right |
| SB | Store Byte |
| SH | Store Halfword |
| SW | Store Word |
| SWL | Store Word Left |
| SWR | Store Word Right |
