# 指令队列

|  |
|---|
| DIV F0, F1, F2 |
| MUL F3, F0, F2 |
| ADD F0, F1, F2 |
| MUL F3, F0, F2 |
|  |
|  |

+   - DIV发射，F1,F2都准备好
+   - MUL1发射，F0等待3号保留站的结果
+   - ADD发射，F1,F2都准备好
+   - MUL2发射，F0等待6号保留站的结果
