# # 转移猜测的基本思想

通过大量应用程序分析可得出转移指令具有如下特性

+   转移指令出现很频繁

+   转移指令有较好的局部性

+   转移指令具有可预测性

转移指令的可预测性体现在

+   单个转移指令模式的重复性

+   for型循环: TT...TN （成功n次后跟一次不成功）

+   while型循环: NN...NT （不成功n次后跟一次成功）

不同转移指令之间存在方向相关、路径相关

```
```
Y: if (cond1)
:
X: if (cond1 AND cond2)
```
```

```
```
Z: if (cond1)
:
Y: if (cond2)
:
X: if (cond1 AND cond2)
```
```

```
```
Y: if (cond1) a = 2
:
X: if (a = 0)
