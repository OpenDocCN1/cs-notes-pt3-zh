# 迭代式硬件乘法（二）

+   - 如果参与运算的是补码？
+     - 先判断结果符号位
+     - 将补码转为原码进行运算
+     - 补上符号位，转换回补码
+   - 太麻烦，不如自行推导补码乘法算法
+     - 问题: 已知[X]补和[Y]补，求[X*Y]补。
+     - [X]补 + [Y]补 = [X+Y]补（方括号内为普通加法，方括号外为补码加法）
+     - 但[X]补 * [Y]补 != [X*Y]补
+     - 若[Y]补 = y31 y30 …… y1 y0，
+     - 则 Y = -y31 * 2^31 + y30 * 2^30 + …… + y1 * 2^1 + y0 * 2^0
