# Booth两位乘

```
1010×1001 (-6×-7)
        1010
    ×     1001
----------------
    +11111010 (010)
    -11010  (100)
----------------
    +11111010
    +00110
----------------
    100101010 (42)
```

```
1010×0101 (-6×5)
        1010
    ×     0101
----------------
    +11111010 (010)
    +111010 (010)
----------------
    +11111010
    +111010
----------------
    111100010 (-30)
```

+   - 循环次数降低一倍
+   - 每次循环算法一样
+   - [X]补只有移1位和补码加减运算

| y_{i+1} | y_i | y_{i-1} | 操作 |
|---|---|---|---|
| 0 | 0 | 0 | +0 |
| 0 | 0 | 1 | +[X]补 |
| 0 | 1 | 0 | +[X]补 |
| 0 | 1 | 1 | +2[X]补 |
| 1 | 0 | 0 | -2[X]补 |
| 1 | 0 | 1 | -[X]补 |
| 1 | 1 | 0 | -[X]补 |
| 1 | 1 | 1 | 0 |
