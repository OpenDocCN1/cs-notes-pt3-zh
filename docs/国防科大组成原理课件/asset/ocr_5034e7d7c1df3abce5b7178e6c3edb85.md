# # 最基本的MPI

+   - MPI编程模型
+     - 由一个或多个彼此通过调用库函数进行消息收、发通信的进程所组成

+   - MPI是复杂系统，但只要6个基本函数就能编写MPI程序

| 序号 | 函数名 | 用途 |
|------|--------|------|
| 1 | MPI_Init () | 初始化MPI执行环境 |
| 2 | MPI_Finalize | 结束MPI执行环境 |
| 3 | MPI_COMM_SIZE | 确定进程数 |
| 4 | MPI_COMM_RANK | 确定自己的进程标识符 |
| 5 | MPI_SEND | 发送一条消息 |
| 6 | MPI_RECV | 接收一条信息 |
