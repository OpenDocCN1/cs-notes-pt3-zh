# PCI配置过程

+   - 找到设备并访问其配置空间
+     - 配置访问在PCI初始化前可用，使用片选机制
+     - 主板上AD的高位与PCI槽的IDSEL相连
+     - 扫描AD高位，发配置访问，如果有响应则发现设备
