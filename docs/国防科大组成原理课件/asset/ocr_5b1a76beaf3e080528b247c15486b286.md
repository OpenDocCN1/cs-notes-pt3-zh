# 流程控制语句 – 示例1

+   - 当条件表达式t0等于0（BEQZ）时，跳转到标号1
+   - 标号2为公用的程序出口
+   - 本例的延迟槽使用空指令（NOP）进行填充

| // C if ~ else | ## ASM if ~ else |
|---|---|
| if (cond_exp) | move t0, cond_exp |
| <then_statement> | beqz t0, 1f   # label1 forward |
| else | nop           # delay slot |
| <else_statement> | <then_statement> |
| | b 2f          # label2 forward |
| | nop           # delay slot |
| | 1: |
| | <else_statement> |
| | 2: |
