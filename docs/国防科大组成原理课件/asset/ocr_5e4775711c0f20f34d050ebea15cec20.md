# POWER7性能建模、验证和评价

+   - **POWER7的性能分析覆盖晶体管级、处理器核、到全系统级**
+     - 不同精细度对应不同速度，M1模型
+     - 处理器核的模型（core model）和巢的模型（nest model）

+   - 通过性能模拟和分析，POWER7的工程师对各种参数变化的影响进行排序，逐渐改进设计，一直到最终完成设计
+     - 实践和认识的反复迭代

+   - 性能测试程序很重要
+     - 规模小，速度快；而且要具有代表性

+   - 通过芯片上集成的性能监测单元（PMU）对硅后POWER7芯片进行测量，构造精确的CPI分解栈，对阻塞条件进行剖析
+     - 又一轮从认识和实践的螺旋上升
