# FPGA加速模拟技术

+   - Patterson主持开发了RAMP（Research Accelerator for Multiple Processors）项目，由多个大学和单位完成
+     - 全部使用FPGA进行全系统模拟，目的在于研究16个核心以上的多处理器系统，是一个综合的软硬件平台，用于在多核环境下进行体系结构、编译器、操作系统和应用程序方面的研究。

+   - Chiou设计并实现FAST模拟器
+     - 将功能模拟和时序模拟分离开来，对于功能模拟部分使用软件模拟器QEMU来实现，而对于时序模拟部分使用FPGA来实现，FPGA模拟器模拟微结构，如分支预测、缓存状态等
+     - 功能级模拟器产生执行的踪迹信息，时序级模拟器从缓冲区中读出踪迹信息进行微结构模拟。
