# NPB-3.3

+   - NPB（NAS Parallel Benchmark）是美国国家航空航天局开发流体动力学计算的应用程序集，用于评测大规模并行机
+   - 包括OpenMP和MPI等版本
+   - 包括5个核心程序和3个模拟应用。每个程序有5类问题规模，分别为 A、B、C和S、W
