# POWER7性能监测

+   - **POWER7中集成了PMU用于性能监测、负载行为特性分析和系统的代码特性分析，包括6个线程层面的PMC**
+     - **PMC1-PMC4是可编程的**
+     - **PMC5统计非停顿的指令数**
+     - **PMC6统计非停顿的拍数**
+     - 每个核还包括4个HPMC（hypervisor PMC）
+   - 处理器和指令层面的性能事件的数目多达530种
+     - 失效率、单元利用率、线程平衡、冒险条件、地址转换相关失效、停滞原因分析、指令混合情况、L1指令和数据reload的原因，cache和内存的延迟
+   - 芯片级的PMU称为PMUlet
+     - 用于统计内存带宽、总线利用率和I/O带宽
