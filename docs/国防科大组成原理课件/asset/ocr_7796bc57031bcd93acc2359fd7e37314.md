# 内存总线——内存条接口信号

| 引脚名称 | 描述 | 引脚名称 | 描述 |
|---|---|---|---|
| A0~A15 | SDRAM地址线 | SCL | EEPROM I²C总线时钟 |
| BA0~BA3 | SDRAM bank地址 | SDA | EEPROM I²C总线数据线 |
| RAS# | SDRAM 行地址选通 | SA0~SA2 | EEPROM I²C设备地址 |
| CAS# | SDRAM 列地址选通 | VDD | SDRAM core电源 |
| WE# | SDRAM 写使能 | VDDQ | SDRAM IO输出电源 |
| SO#~S1# | SDRAM芯片选信号 | VrefDQ | SDRAM IO参考电源 |
| CKE0~CKE1 | SDRAM时钟使能信号 | VrefCA | SDRAM命令地址参考电源 |
| ODT0~ODT1 | SDRAM 终端匹配电阻控制信号 | VSS | 电源地信号 |
| DQ0~DQ63 | DIMM内存数据线 | VDDSPD | EEPROM电源 |
| CB0~CB7 | DIMM ECC数据线 | NC | 空闲引脚 |
| DQS0~DQS8 | DIMM数据选通线（差分对的正沿） | TEST | 测试引脚 |
| DQS0~DQS8 | SDRAM数据选通线（差分对的负沿） | RESET# | 复位引脚 |
| DM0~DM8 | SDRAM数据mask线 | EVENT# | 温度传感器引脚（可选） |
| CK0~CK8 | SDRAM时钟信号线（差分对的正沿） | VTT | SDRAM IO终端匹配电阻电源 |
| CK0~CK8 | SDRAM时钟信号线（差分对的负沿） | RSVD | 保留 |
