# 影响性能的因素

+   - 应用对性能的影响最大
+     - 如 “太湖之光” 运行 Office 不如通用处理器
+     - 通用处理器图形计算不如 GPU
+   - 算法影响很大
+     - 如冒泡排序复杂度为 O(N*N)，快速排序复杂度为 O(NlogN)
+   - 编译系统（GCC、JAVA、JS、QT 库等）影响
+     - 一般有几倍的差距
+   - 指令系统：复杂指令如三角函数、AES 等是否硬件实现
+   - 微结构：IPC（Instructions per cycle）
+     - 通过乱序执行、多发射、存储层次等提高 IPC
+   - 主频：受工艺和微结构（流水线）的影响
