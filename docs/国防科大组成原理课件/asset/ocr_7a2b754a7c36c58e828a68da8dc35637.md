# 冯诺依曼结构基本原理

+   - 存储程序和顺序执行
+     - 指令和数据都存在存储器中，计算机运行程序时，控制器从存储器中读取指令并按照程序规定的次序顺序执行
+     - 五大部分：控制器、运算器、存储器、输入设备、输出设备；在控制器的统一控制下，从输入设备读入程序和数据到存储器中，运算器从存储器中读入程序和数据进行计算并把中间结果存入存储器，输出设备将运算结果输出
+     - 存储程序和顺序执行给计算机设计带来的极大的便利，也带来了极大的瓶颈（计算和存储分离、顺序执行），喂不饱的运算器
+   - 冯诺依曼结构的演进
+     - 哈佛结构：数据存储和指令存储分开以缓解访存瓶颈
+     - 高速缓存、指令流水线、乱序执行、超标量……
