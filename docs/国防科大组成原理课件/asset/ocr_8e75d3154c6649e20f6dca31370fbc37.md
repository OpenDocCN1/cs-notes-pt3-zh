# 寻址方式

| 寻址方式 | 格式 | 含义 |
|---|---|---|
| Register | ADD R1, R2 | regs[R1]=regs[R1]+reg[R2] |
| Immediate | ADD R1, #2 | regs[R1]=regs[R1]+2 |
| Displacement | ADD R1, 100(R2) | regs[R1]=regs[R1]+mem[100+reg[R2]] |
| Reg. Indirect | ADD R1, (R2) | regs[R1]=regs[R1]+mem[reg[R2]] |
| Indexed | ADD R1, (R2+R3) | regs[R1]=regs[R1]+mem[reg[R2]+reg[R3]] |
| Absolute | ADD R1, (100) | regs[R1]=regs[R1]+mem[100] |
| Mem. Indirect | ADD R1, @(R2) | regs[R1]=regs[R1]+mem[mem[reg[R2]]] |
| Autoincrement | ADD R1, (R2)+ | regs[R1]=regs[R1]+mem[reg[R2]],
reg[R2]=reg[R2]+d |
| Autodecrement | ADD R1, -(R2) | reg[R2]=reg[R2]-d,
regs[R1]=regs[R1]+mem[reg[R2]] |
| Scaled | ADD R1, 100(R2)[R3] | regs[R1]=regs[R1]+
mem[100+reg[R2]+reg[R3]*d] |
