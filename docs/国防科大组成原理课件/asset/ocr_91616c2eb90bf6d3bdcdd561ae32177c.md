# 提高访存性能的方法

+   - 利用行缓冲局部性
+     - 利用输出端的行缓存，如果两次访问在同一行，可降低访问延迟
+     - Close page: 打开 -> 读写
+     - Open page: 读写（命中）、关行 -> 打开 -> 读写（不命中）
+   - 利用Bank级并行性
+     - DRAM芯片的多个Bank可以流水并行执行
+     - 要求连续的访问针对不同Bank
+   - 内存控制器的调度
+     - 内存控制器同时对几十个不同的访问进行调度
+     - 调度访问次序，利用行缓存局部性和Bank级并行性
+     - 支持多个Outstanding访问操作，读优先……
