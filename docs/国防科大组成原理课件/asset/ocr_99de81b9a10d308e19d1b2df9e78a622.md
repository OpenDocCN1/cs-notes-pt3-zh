# 补码(二)

+   - 补码的好处
+     - [X+Y]补 = [X]补 + [Y]补
+     - [X-Y]补 = [X]补 + [Y]补̅ + 1    [Y]补̅为[Y]补每个bit取反
+     - 比原码能多表示一个数（-2ⁿ）
+   - 以char类型（8bit）为例
+     - [-19]补 + [19]补 = 00010011 + 11101101 = 0（超出8bit部分舍弃）
+     - [19]补 - [-19]补 = 00010011 + 00010010 + 1 = 00100110（38）
+     - [-2⁸]补 = 10000000，转回原码 = 负（01111111+1）= -2⁸
