# Oprofile

+   - 类似 VTune 的一个功能强大的性能分析工具。分两部分
+     - 内核模块oprofile.ko：负责访问性能计数器或者注册基于时间采样的函数，并采集置于内核的缓冲区内
+     - 用户空间守护进程oprofiled：后台运行，从内核空间收集数据写入文件

+   - 支持两种采样方式
+     - 基于事件的采样：只记录特定事件（比如L2 cache miss）的发生次数；当达到用户设定的定值时oprofile 就记录一下（采一个样），这种方式需要CPU 内部有性能计数器(performance counter)；
+     - 基于时间的采样：借助OS 时钟中断的机制，每个时钟中断oprofile 都会记录一次(采一次样)，提供对没有性能计数器 CPU 的支持，其精度相对于基于事件的采样要低
