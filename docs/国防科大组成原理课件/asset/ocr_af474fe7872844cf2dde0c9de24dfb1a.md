# Booth二位一乘算法

+   - 对(-y₃₁*2³¹ + y₃₀*2³⁰ + ...... + y₁*2¹ + y₀*2⁰)进行变换
+   
+     (-y₃₁*2³¹ + y₃₀*2³⁰ + ...... + y₁*2¹ + y₀*2⁰)
+     = (y₂₉ + y₃₀ - 2*y₃₁) *2³⁰ + (y₂₇ + y₂₈ - 2*y₂₉) *2²⁸ + ...... + (y₁ + y₂ - 2*y₃) *2² + (y₋₁ + y₀ - 2*y₁) *2⁰

+   - 每次循环公式相同，最高位不需额外处理，只需N/2次循环

| yᵢ₊₁ | yᵢ | yᵢ₋₁ | 操作 |
|---|---|---|---|
| 0 | 0 | 0 | +0 |
| 0 | 0 | 1 | +[X]补 |
| 0 | 1 | 0 | +[X]补 |
| 0 | 1 | 1 | +2[X]补 |
| 1 | 0 | 0 | -2[X]补 |
| 1 | 0 | 1 | -[X]补 |
| 1 | 1 | 0 | -[X]补 |
| 1 | 1 | 1 | 0 |
