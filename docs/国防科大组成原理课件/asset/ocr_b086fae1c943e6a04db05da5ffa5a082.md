# 模拟器精度和校验

+   - 模拟器的精度表示该模拟器的模拟结果与真实机器接近的程度
+     - 对于已有系统，模拟器的精度可以通过和实际系统运行结果对比，对于正在实现的系统可以通过和RTL代码模拟结果对比
+   - 模拟器的精度受两方面影响
+     - 模拟器的模型是否与真实设计相匹配
+     - 模型的输入数据是否真实
+   - 结合真实结果对模拟器的参数进行校验
+     - 模拟器的精度是一个持续改进的过程
+   - 对未来的系统，模拟器可以用来进行设计方案的前期比较
+     - 一个模拟器的绝对误差是无法避免的，但模拟结果和真实系统的偏差是稳定的，同一个模拟器对不同系统模拟结果的相对值可以相对反映这些目标系统性能的差异
