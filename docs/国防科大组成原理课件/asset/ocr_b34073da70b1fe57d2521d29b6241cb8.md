# # OpenMP的制导-同步结构

+   - master编译制导语句: 表示一个只能被主线程执行的域
+     - 格式为: #pragma omp master newline

+   - critical编译制导语句: 表示域中代码一次只能由一个线程执行
+     - 格式为: #pragma omp critical[name] newline

+   - barrier编译指令语句: 同步线程队列中的所有线程
+     - 格式为: #pragma omp barrier newline

+   - atomic编译制导语句: 表示一个特别的存储单元只能原子的更新，而不允许让多个线程同时去写。
+     - 格式为: #pragma omp atomic newline
