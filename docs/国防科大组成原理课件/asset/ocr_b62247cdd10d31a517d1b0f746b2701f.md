# 一致性问题（cont.）

+   - 即使每个处理器核都根据程序序执行指令，仍可能导致错误

```
Process P1      Process P2      Process P3
STORE a,1  →   LOAD  R1,a      LOAD R2,b
               STORE b,1      LOAD R3,a
(Incorrect result: R1=1,R2=1, R3=0)
```

+   - 起因：从Write Atomic到Write Non-atomic
+   - 什么是写可分割系统中正确的执行?
+     - 存储一致性模型和Cache一致性协议
