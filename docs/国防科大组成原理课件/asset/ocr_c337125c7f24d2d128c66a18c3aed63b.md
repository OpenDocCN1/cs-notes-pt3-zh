# 解决WAW和WAR的办法

+   - 假设只考虑RAW相关，可能发生如下执行次序
+     - DIV发射，F1,F2都准备好
+     - MUL1发射，F6没准备好，所以没有读数据
+     - ADD发射，F3,F4都准备好
+     - MUL2发射，F8没有准备好，所以没有读数据
+     - ADD完成，F0写回
+     - F6准备好，MUL1读数据
+     - DIV完成，F0写回
+     - F8准备好，MUL2读数据

+   - DIV F0, F1, F2
+   - MUL F5, F0, F6
+   - ADD F0, F3, F4
+   - MUL F7, F0, F8
