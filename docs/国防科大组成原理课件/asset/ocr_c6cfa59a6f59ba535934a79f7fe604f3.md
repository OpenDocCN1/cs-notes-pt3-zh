# PCI配置头

+   - 设备信息
+     - 厂商号、设备号
+   - 状态与控制
+     - IO/MEM/DMA/中断使能
+     - 中断/能力/错误状态
+   - 基址
+     - 设备向系统声明所需要的空间
+     - 系统给设备分配基址
+     - [0]: MEM/IO, [3]:可预取
+     - 比所占空间高的位可写
+   - 扩展能力
