# （四）虚拟化

+   - 虚拟化：应用和实现的“桥梁”
+     - 用起来是这样的，实际上是那样的
+     - 逻辑上是这样的，物理上是那样的
+     - 宁愿自己多费点事，也要用尽量为用户提供一个好用的接口
+   - 计算机中的“桥梁”
+     - 操作系统对虚拟地址空间的支持（CPU中实现TLB）（特优）
+     - 多发射在维持串行编程模型的情况下提高了速度（优）
+     - 多线程和虚拟机技术在单一硬件上虚拟出多个CPU（优）
+     - Cache在维持一维的地址空间的情况下提高了速度（良）
+     - Cache一致性协议在分布存储的情况下提供统一编程空间（一般）
