# 芯片的成本

芯片成本 = (晶片的成本 + 测试成本 + 封装成本) / 最终成品率

晶片的成本 = 晶圆的成本 / (每片晶圆的芯片数 × 晶片成品率)

每个晶圆的芯片数 = π(晶圆的直径/2)² / 晶片的面积 - π×晶圆的直径 / √2·晶片面积

晶片成品率 = 晶圆的成品率 × (1 + 单位面积内的缺陷数目×晶片面积 / α)⁻ᵅ

+   - 封装成本跟功耗、引脚数目、材料相关
+   - 90nm工艺下每个12英寸晶圆的成本在3000-6000美元之间
+   - a是衡量工艺复杂程度的参数，在目前工艺下约为4
+   - 单位面积的缺陷数目与工艺相关，在目前的工艺下约为：0.4-0.8/平方厘米
