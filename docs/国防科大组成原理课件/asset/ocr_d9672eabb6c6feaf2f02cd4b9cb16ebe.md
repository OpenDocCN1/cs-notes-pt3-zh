# IBM MET （微体系结构探索工具集）

+   - **Turando:** 一个踪迹驱动的参数化的处理器模型
+   - **Aria:** 一个执行驱动的踪迹生成器，可生成用户级踪迹，翻译执行(1/40)
+   - **Rondo:** 一个踪迹驱动的工具，用于探索分支预测算法精度的工具
+   - **LeProf:** 一个踪迹驱动的工具，并包含一个PowerPC Cache结构的模型，能产生程序剖析的信息和程序的Cache行为
+   - **eOak:** 一个系统层面的模拟器，模拟PowerPC 403GCX嵌入式处理器，也能用于踪迹产生
+   - **PavaRotti:** 用于性能分析和验证的工具集合
+   - **RAMP:** 一个微体系结构功耗模型
+   - **PowerTimer:** 一个工具集，用于对微体系结构层面进行功耗和性能评估
