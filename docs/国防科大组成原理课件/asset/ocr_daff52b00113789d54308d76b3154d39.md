# MIPS ABI示例一(2)

+   - 非叶子函数

```
int foo(int a0, int a1, ... int a8)
{
    return add(a0,a1)+a2+...+a8;
}
```

foo(1, 2, 3, 4, 5, 6, 7, 8, 9);

```
foo:
    addiu sp, sp, -48
    sd ra, 40(sp)
    sw a0, 0(sp)
    ...
    sw a7, 28(sp)
    jal add
    nop
    lw v1, 8(sp)
    addiu v0, v0, v1
    ...
    lw v1, 48(sp)
    addiu v0, v0, v1
    ld ra, 40(sp)
    jr ra
    addiu sp, sp, 48
```
