# # 以网络收包为例—硬中断(1)

+   - 通用例外入口(180)
+     - 取出Cause，从例外出处理函数列表加载处理函数的指针
+   - 外部中断入口
+     - 保存进程上下文到内核栈
+     - 关IE，清EXL，切换到内核模式
+     - 转到平台相关处理
+   - 平台相关中断分发
+     - 读中断状态，算中断号
+   - do_IRQ
+     - 设置硬中断标记
+     - 调用挂载在对应中断号的处理程序
+     - 退出硬中断，检查并处理软中断
