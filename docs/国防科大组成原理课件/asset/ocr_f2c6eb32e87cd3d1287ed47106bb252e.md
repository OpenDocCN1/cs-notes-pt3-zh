# 以网络收包为例—软中断

+   - 通过软件优化，提高系统响应速度
+     - 在开中断状态下运行
+     - 处理硬中断期间所设置的处理任务
+     - 内核中预定义了10种软中断，一般驱动只能用基于软中断实现的tasklet机制

```
void irq_exit(void) {
    if (!in_interrupt() && local_softirq_pending())
        invoke_softirq();
}
static int stmmac_poll(struct napi_struct *napi, int budget)
{
    ...
    stmmac_tx(priv);
    work_done = stmmac_rx(priv, budget);
    if (work_done < budget) {
        napi_complete(napi);
        stmmac_enable_irq(priv);
    }
    return work_done;
}
```
