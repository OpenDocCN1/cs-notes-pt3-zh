# 数据并行编程-SIMD

+   - SIMD编程
+   - 一条SIMD指令可以同时对一组数据进行相同的计算
+   - 龙芯CPU： gsldxc1（向量读）、gssdxc1（向量写）、paddb（向量加）

```
for(i=0; i<8; i++)

```

C语言代码

```
gsldxc1 $f0, 0x0($src0, $0)
gsldxc1 $f2, 0x0($src1, $0)
paddb $f0, $f0, $f2
gssdxc1 $f0, 0x0($result, $0)
```
