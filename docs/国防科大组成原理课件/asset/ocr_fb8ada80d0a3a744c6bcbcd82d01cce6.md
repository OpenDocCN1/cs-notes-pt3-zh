# 补码乘法算法（四）

+   - 补码运算注意
+     - 符号位扩充到8位，结果保留8位
+     - 补码减法：按位取反加1（-11010000 = 00101111+1）

```
1010*1001 (-6*-7)
          1010
    *     1001
    ----------------
    +11111010
    +0000000
    +000000
    +00101111
    +00000001
    ----------------
          00101010 (+42)
```

```
1010*0101  (-6*5)
          1010
    *     0101
    ----------------
    +11111010
    +0000000
    +111010
    -00000
    ----------------
          11100010 (-30)
```
