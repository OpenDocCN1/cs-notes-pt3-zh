# 第一代到第四代：摩尔定律与结构进步

+   - 第一代：电子管计算机（1946-1958）：每秒几千到几万次
+     - 冯诺依曼结构
+   - 第二代：晶体管计算机（1958-1964）：每秒几十万次
+     - 高级程序语言出现：FORTRAN、COBOL等
+     - IBM7094、CDC1604等
+   - 第三代：中小规模IC计算机（1964-1975）：每秒几百万次
+     - 操作系统逐步成熟、小型机出现
+     - IBM360、PDP11、VAX11
+   - 第四代：大规模IC计算机（1975-）：每秒亿次以上
+     - 微处理器出现：Intel, AMD......
+     - 形成Wintel体系
