## 片外的硬件监测器

- 使用片外的硬件来进行硬件的监视和测量
- 片外硬件监测的方法受限于数据量大小，只能分析很短的片段
- AMD开发的SpeedTracer硬件监测平台，用于CPU研制
- 在每条指令的边界，Tracer中断处理器，每次中断发生时，CPU的状态被捕获，并传输到控制机器
- 采用逻辑分析仪进行片外的硬件测量
- 如采用泰克公司的TLA700逻辑分析仪用于AMD K6-2系统的3D图形工作负载分析

## 软件及微码测量

- 硬件性能计数器出现之前采用的软件及微码测量方法
- VAX中有一个T位，如置上则每条指令执行时引发陷阱例外
- 优势是容易实现，劣势是使得应用执行变慢（上千倍），例外服务程序的开销包括需要切换到数据收集进程以及执行必要的追踪
- 只能追踪用户态程序的活动，不能追踪操作系统的活动
- DEC公司在VAX和Alpha的结构设计中使用了微码测量方法
- 微码监测机制处于陷阱机制的下层，通过在指令陷阱发生时进行某些操作，记录所有指令和内存访问，记录放置在一个保留的内存位置
- 可以跟踪包括操作系统在内的所有进程的活动

## Perf

- **Perf 是内置于Linux 内核源码树中的性能分析工具**
- 随内核发行，应用比oprofile广
- 基于事件采样原理，以性能事件为基础，支持针对处理器相关性能指标与操作系统相关性能指标的性能剖析
- **Perf的采样事件大致可分为三类**
- **Hardware Event 是由硬件产生的事件，比如 cache 命中**
- **Software Event 是内核软件产生的事件，比如进程切换， tick 数等**
- **Tracepoint event 是内核中的静态 tracepoint 所触发的事件，如 slab 分配器的分配次数等**
