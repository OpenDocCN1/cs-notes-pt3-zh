- 优点：更为真实的应用，编译不能预计算，库的影响较小

  - 状态机操作，覆盖数据相关的分支

## 瑞士军刀 - LMbench

- HP以色列海法实验室开发的一套强大的微测试程序集，可测量许多和系统性能相关的重要因素
- 衡量两个关键特征：延迟和带宽
- 带宽就是系统中搬运数据的能力
  - 各级cache的带宽、内存的带宽、缓存的I/O带宽等
- 延迟是系统的反馈时间或者开销
  - 各级cache的访问延迟、内存访问的延迟和操作系统中某一项功能的开销

## SPEC和SPEC CPU测试程序

- SPEC是由计算机厂商、系统集成商、大学、研究机构、咨询等多家公司组成的非营利性组织
  - System Performance Evaluation Cooperative（网址: www.spec.org）
  - 随CPU性能提高已发展了5轮：1989、1992、1995、2000、2006
  - SPEC CPU2000：12个定点程序，14个浮点程序
  - SPEC CPU2006：12个定点程序，17个浮点程序
  - 为什么到SPEC CPU2006后没有新的推出？
- SPEC CPU系列测试程序集合，主要关注与CPU的性能
  - SPEC CPU中的SPECratio（单进程）分值主要反映PC系统性能
  - 衡量服务器的吞吐率通常采用SPECrate，在多CPU执行SPEC CPU的多份拷贝，并且把CPU的时间转换为比率（rate），即SPECrate
