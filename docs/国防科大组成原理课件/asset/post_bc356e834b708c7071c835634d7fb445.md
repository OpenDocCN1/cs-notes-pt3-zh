## 数制（二）

- 其他常见进制
- 二进制（Binary）
  - 只有0和1， 例如(127)10=(11111111)2  (1.25)10=(1.01)2

## 二进制适合计算机使用

## 补码

- 补码的定义
  - $[X]_{补} = 2^n + X \pmod{2^n}$
- 补码的简便算法
  - 正数的补码就是它的二进制值    此时$[X]_{补}=X$
  - 负数的补码，等于值按位取反再加1    此时$[X]_{补}=\overline{X}+1$
    （$\overline{X}$表示X的每个bit各自取反）
  - $[19]_{补}=00010011$
  - $[-19]_{补}=11101100+1=11101101$
- 最高位还是符号位
- 补码转换回原码的算法相同

## 补码(二)

- 补码的好处
  - [X+Y]补 = [X]补 + [Y]补
  - [X-Y]补 = [X]补 + [Y]补̅ + 1    [Y]补̅为[Y]补每个bit取反
  - 比原码能多表示一个数（-2ⁿ）
- 以char类型（8bit）为例
  - [-19]补 + [19]补 = 00010011 + 11101101 = 0（超出8bit部分舍弃）
  - [19]补 - [-19]补 = 00010011 + 00010010 + 1 = 00100110（38）
  - [-2⁸]补 = 10000000，转回原码 = 负（01111111+1）= -2⁸

## 溢出

- 有符号表示，且规定长度，运算可能溢出
- 只有同号相加或者异号相减会溢出
- 原码和补码运算都会溢出

[01000011]原 (67)      [10000011]补 (-125)
+[01000011]原 (67)      +[10000011]补 (-125)
10000110  (-6)          00000110  (6)

- 溢出就是运算的算术结果超出了表示范围
- 需要软件进行介入处理（发生异常）

## IEEE754标准

- 将浮点数标识为符号位S、尾数F和阶码E
  - 二进制小数 11.01₂ = (3.25₁₀)
  - 转为科学记数法 1.101 × 2¹
    （没有前导零，小数点左侧只有一个整数）
- 针对此数，规定：
  - 符号S为0表示正数
  - 尾数F为101 （省略了“1.”部分）
  - 阶码E使用移码表示，1+shift（shift偏移值）

| S | Exp. (8) | Fraction(23) |
| S | Exp. (11) | Fraction(52) |

## IEEE754标准（二）

- 数的位数
  - 单精度：1位S，8位E，23位F，共32位
  - 双精度：1位S，11位E，52位F，共64位
  - 其他...
- 尾数的设定—使用原码，后面补0
  - 如下例，单精度尾数为101000...000（共23bit）
  - 双精度尾数为101000...000（共52bit）
- 阶码移码的设定
  - 单精度移码127
  - 双精度移码1023

## IEEE754标准（三）

- （11.01）₂ = （3.25）₁₀
- 单精度表示：E = 1+127 = 128 = (10000000)₂
  - 0(S)10000000(E)10100000000000000000000(F)
  - 0x40500000
- 双精度表示：E = 1+1023 = 1024 = (10000000000)₂
  - 0x400A000000000000
