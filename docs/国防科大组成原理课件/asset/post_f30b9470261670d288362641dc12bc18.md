# 性能分析和评估的分类

- 性能分析就是测量平台及微结构和软件及数据结构之间的交互行为
- 性能建模
  - 基于分析和统计的建模：概率模型、队列模型、马科夫模型、Petri网模型
  - 基于模拟的建模：踪迹驱动模拟、执行驱动模拟、全系统模拟、事件驱动模拟、统计方法模拟
- 性能测量
  - 片上的硬件监测、片外的硬件监测、软件监测、微码插桩

# 性能建模和测量技术的特性要求

- 性能建模和测量结果要比较准确，直接影响设计权衡和选择
- 模型的速度要比较快，反之设计空间的探索范围就会变得有限
- 所执行的测试程序应该是目标代码
- 能捕获用户态和内核态的行为特性
- 需要能很好的利用多处理器系统资源
- 应该是非侵入式的
- 开销不能太大
- 应该很容易修改和扩展

# 分析建模的方法

# 分析建模的方法

- 分析模型独立地为处理器的各个部分建立分析模型，在忽略硬件实现细节的情况下考虑其对性能的影响，从而能够量化地分析影响处理器性能的因素
  - 具有速度快、灵活性高的特点，但结构因素太多，难以准确
  - 例如对内存平均访问延迟的建模： T = Thit + (1-h)*Tmiss
- 常用的分析建模理论
  - 概率论：描述随机过程（如访存指令/转移指令出现的概率）
  - 队列理论；预测任务在队列中等待时间，系统吞吐率
  - Petri网：网状信息流模型，含条件和事件两类结点，描述并发和同步
  - Markov模型：一个过程未来状态只依赖当前状态，与过去状态无关

# 分析建模示例

- 由程序并行度和机器并行度推导出IPC的值
  - D. B. Noonburg and J. P. Shen, Theoretical Modeling of Superscalar Processor Performance, Micro-27

- 程序并行性和机器并行性
  - P_c 和 P_d 分别表示程序中的控制并行性函数和数据并行性函数
  - M_B 表示机器中的分支并行度函数，M_F 表示取指并行度函数，M_I 表示发射并行度函数

- IPC是由5个并行度分布函数拟合而成（P_c, P_d, M_B, M_F, M_I）
  - 主成分分析法：忽略次要因素

P_C = P̂_C × M_B
M_F = M̂_F × P_C = M̂_F × P̂_C × M_B
P_D = P̂_D × M_F = P̂_D × M̂_F × P̂_C × M_B
M_I = M̂_I × P_D = M̂_I × P̂_D × M̂_F × P̂_C × M_B
IPC = ⟨M_I⟩ = Σ_{k=0}^{∞} k (M_I)_k

# 模拟建模的方法和模拟器

- 模拟器是体系结构研究和设计的重要工具
  - 使用软件的方式来模拟计算机系统硬件的功能和性能特性
  - 在学术界和工业界得到广泛使用
- 模拟器需要具有
  - 运行速度快、模拟精度高、配置修改灵活等特点
- 模拟器贯穿系统设计的整个流程
  - 初期阶段、中期阶段和系统完成之后
- 常用的模拟器包括:
  - Simplescalar、SimOS、GEM5，IBM的Mambo和Turandot，AMD的SimNow等

# 模拟器的基本原理

- 用软件模拟实现包括硬件在内的系统功能
  - 模拟器使用C、C++和Python等高级语言开发，利用这些串行结构化语言的函数或者类来模拟计算机系统部件的功能和行为
  - 将目标机器的每一个寄存器和标识位对应一个变量，目标机器的所有逻辑操作都可以被间接地翻译为变量的运算，目标机器上程序的所有操作都可以在原始机器上以软件模拟的形式复现出来
- 速度比真实机器慢，越精确越慢
  - 在进行详细模拟时，需在时钟周期级别上记录每条动态指令的运行结果、每一级流水线触发器的状态、内部各种队列的状态以及体系结构寄存器的状态、内存和cache的行为、分支预测器的状态等，其数据量巨大，从而导致详细模拟运行的速度缓慢
  - 可以忽略一些因素提高速度

# 模拟器类型

- 系统模拟器和部件模拟器
  - 系统模拟器对整个计算机系统进行模拟，常见的系统模拟器包括 SimOS、Simics、Mambo、QEMU等
  - 部件对计算机系统的某个部件进行细致模拟，提供多种配置参数，可以模拟多种类型的部件，通常以踪迹为输入，如内存模拟器 DRAMsim、磁盘模拟器 DiskSim 和能耗模拟器 Wattch 等
- 全系统模拟器和用户态模拟器
  - 全系统模拟器模拟系统态和用户态，真实系统中完整的软件栈可以不需要任何修改在模拟器上执行
  - 用户态模拟器模拟执行用户态程序，需要在模拟器上为用户程序提高包括系统调用、内存管理等操作系统功能，包括 Simplescalar、Augmint、Mambo、QEMU、SESC 等

# 模拟器的类型

- 执行驱动和踪迹驱动
  - 执行驱动是指模拟器的输入是真实的二进制代码，因此可以在执行驱动的模拟器运行完整的操作系统或者应用程序
  - 踪迹驱动则是指模拟器的输入是一些事先得到的踪迹，这些踪迹可以是真实系统或者驱动执行的模拟器上运行程序的踪迹，也可以是按某种分布函数所产生的伪踪迹
- 时钟驱动和事件驱动
  - 时钟驱动是在模拟器中维护一个软件时钟，每个时钟周期调用模拟函数推进一步
  - 事件驱动则是事先将所有的事件按时间戳顺序插入到列表中，模拟时按照列表中的事件推进模拟器

# 模拟器的类型

- 功能模拟器和时序模拟器
  - 功能模拟器只模拟指令功能，忽略微结构细节，主要用在系统软件开发、踪迹信息获取等方面。
  - 时序级模拟器对处理器微结构中的流水线、多发射、乱序执行、分支预测等操作和对内存系统中的缓存读写操作进行模拟，主要用在性能分析等方面。

# 时序优先（Timing-first）技术

- 性能模拟器需要模拟时序信息，如果将功能和时序模拟结合在一起，则模拟器实现过于复杂，调试维护难度增大

- 将功能模拟和时序模拟分开，时序模拟主要提高模拟器的精度，而功能模拟主要是保证模拟的正确性

- 时序模块模拟每个部件的微结构，根据微结构当前状态向功能级模拟器发出执行命令，由功能模拟模块完成具体的功能模拟

- 可以利用现有的功能级模拟器快速开发一个时钟级模拟器，并使模拟器的结构更加清晰，减轻了开发和调试负担。

- 使用时序优先技术的模拟器有TFsim，MASE等

# 采样模拟技术

- 采样模拟技术截取程序的一小部分进行模拟，并将其作为整个程序模拟结果的一个近似，以降低模拟时间

- 通常采样方法有随机采样、SMARTS和SimPoint. SMARTS是对整个程序进行周期采样，SimPoint首先找到程序执行的相位，然后采样能够代表每个相位的部分并进行模拟仿真。

- SMARTS的周期采样过程：k*U-W-U条指令功能模拟并用于预热，W条指令用于采样前详细模拟，U条指令详细模拟并作为采样单位
