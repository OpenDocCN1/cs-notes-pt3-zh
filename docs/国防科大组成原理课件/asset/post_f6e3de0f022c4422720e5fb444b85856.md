
# Booth二位一乘算法

- 对(-y₃₁*2³¹ + y₃₀*2³⁰ + ...... + y₁*2¹ + y₀*2⁰)进行变换

(-y₃₁*2³¹ + y₃₀*2³⁰ + ...... + y₁*2¹ + y₀*2⁰)
= (y₂₉ + y₃₀ - 2*y₃₁) *2³⁰ + (y₂₇ + y₂₈ - 2*y₂₉) *2²⁸ + ...... + (y₁ + y₂ - 2*y₃) *2² + (y₋₁ + y₀ - 2*y₁) *2⁰

- 每次循环公式相同，最高位不需额外处理，只需N/2次循环

| yᵢ₊₁ | yᵢ | yᵢ₋₁ | 操作 |
|---|---|---|---|
| 0 | 0 | 0 | +0 |
| 0 | 0 | 1 | +[X]补 |
| 0 | 1 | 0 | +[X]补 |
| 0 | 1 | 1 | +2[X]补 |
| 1 | 0 | 0 | -2[X]补 |
| 1 | 0 | 1 | -[X]补 |
| 1 | 1 | 0 | -[X]补 |
| 1 | 1 | 1 | 0 |

# Booth三位乘？

- **Booth三位一乘公式**
  $[X*Y]_{补}=\sum [X]_{补}*(y_{i-1}+y_i+2y_{i+1}-4y_{i+2})*2^i$
  $i=0$，每次循环$i+3$
- **Booth三位一乘可以进一步降低循环次数**
  - 但是不如两位一乘实用， why?
- **Booth两位一乘是最适合电路实现的两位一乘算法**

# Booth乘法小结

- 通过对补码乘法公式变形
  - 得到每一次循环统一的算法
  - 降低循环次数
- **Booth两位一乘算法**
  - 适合电路实现
  - 需要N/2次循环

# 华莱士树

- 串行把16个数相加, 需要15次加法时间
  - 对于64位乘法而言, 需要31次串行128bit的加法

- 用15个加法器组织成树状, 需要4次加法时间, 但浪费硬件
  - 对于64位乘法而言, 需要5次, 31个128bit加法器, 面积大

- 澳大利亚的华莱士士提出Wallace树
  - 基本思想: 利用全加器, 将部分积先合并, 再求和

# 多层全加器

- 如果有4个数据怎么办： A+B+D+E
- 多层串联： 4个4bit数的和，变成2个4bit数的“和”
- 第一层，先计算A + B + D， 生成内部的S_tmp和内部进位C_tmp
- 第二层：再计算S_tmp + (C_tmp<<1) + E，得到最终S和C
- A + B + D + E = S + (C << 1) （C3和C3’没有被用上）
- 依此类推……
