
## 补码运算

例3． A = -1101，B = -1010，求 [A+B]补

解：[A]补 = 10011，[B]补 = 10110

```text
       10011
+      10110
─────────────
       01001
```

结果为正溢出

## 溢出

- 溢出的概念

  两个数参加运算，结果超出了机器能表示的数的范围，称之为溢出。如果正数超过表示范围，则称为正溢出，如果负数超过范围称为负溢出。

- 数的范围

  如果用n位表示一个数，数值的部分为n-1位。对于补码表示，正数范围为1~2^{n-1}-1，负数为-1 ~ -2^{n-1}。10...0表示负数最小的数：-2^{n-1}。

- 补码运算的正溢出（设5位二进制表示一个数）

  正溢出：1100和0110相加

  ```text
  01100
  + 00110
  ------
  10010
  结果为正溢出
  ```

  正溢出的判断方法：加数和被加数符号位为0，结果符号位为1，则正溢出。

## 五、计算机的数值表示

- 计算机能直接处理的数据一般包含整数部分和小数部分，如何表示小数点成为问题
- 计算机内部规定小数点的位置隐含
- 根据小数点位置是否固定，将数分为定点表示和浮点表示两类

### 2. 数的浮点表示

一个数N的科学记数法形式可写成  
N = M × R<sup>E</sup>  
其中M代表尾数，E代表阶码，R代表基数

当尾数、阶码采用二进制，基数R=2时，  
就是计算机中的浮点数据表示，R不用表示

浮点数据表示用一对定点数表示

- 尾数M，通常是小数  
- 阶码E，通常是整数

#### 操作系统的定义

操作系统 (Operating System, OS) 是计算机中最重要的系统软件， 是对计算机硬件系统的第一次功能扩充。它负责有效地组织和管理计算机软、硬件资源；协调后台程序的执行；通过人—机交互界面向用户提供服务，使用户能够方便、灵活、高效的使用计算机。

操作系统是计算机系统的核心软件，是用户和其他软件与计算机硬件之间的桥梁。

#### 进程管理（一）—— 进程的定义

- 进程是指一个具有一定独立功能的程序使用系统分配的资源在一个具体数据集合上的一次动态执行过程。它是系统进行资源分配和调度运行的一个独立单位。
- 从软件构造的角度讲，进程是由程序、数据和进程控制块构成的。

#### 进程管理（二）——进程与程序的区别

- 程序是指令的集合，进程是指令集合的一次执行；
- 程序是静态的概念，进程是动态的概念；
- 程序是永久的，进程的生命是有限的；
- 程序与进程的组成不同（进程的组成包括程序、数据和进程控制块）；
- 程序存储需要介质，进程执行需要处理机；
- 进程与程序并不是一一对应的。
