

## 3.1 字符输入

- 插入：首先应设置插入点（即点即输入）
- 删除：Backspace键、Del键
- 改写：双击状态栏上的“改写”框 / 按 Insert键
- 手动替换：首先选择被替换范围，用键入的内容替换选定的文本。

## 3.2 符号的输入

- “视图\工具栏\符号栏” 命令
- 或 “插入\符号” 命令
- 或通过软键盘

组合键自动输入：

| --- | --- | --- | --- |
| (c) | © | :) | 😊 |
| (r) | ® | :| | 😐 |

| --> | → | <= > | ↔ |

## 3.3 插入日期和时间

- 单击 “插入\日期与时间” 命令
- 快捷键：
  - Alt+Shift+D键，可以输入当前日期
  - Alt+Shift+T键，可以输入当前时间
- 操作选项包括：
  - 使用全角字符
  - 自动更新

辅助输入（输入 “2006”或 “October”

## 4.2 文本、文本选择

| 功能 | 操作要领 |
|---|---|
| 大块文本 | 按住鼠标左键拖 |
| 一个单词或汉字 | 在所需的中文字、词组或英文单词中双击。 |
| 一句 | CTRL+在所需的语句中单击。 |
| 一行 | 将鼠标移至该行左侧，指针改变方向后单击。 |
| 多行文字 | 选择一行后拖动。 |

## 4.2 文本选择

| 功能 | 操作要领 |
|---|---|
| 一段 | 将鼠标移至该段左侧，指针改变方向后**双击**，或在该段中任意位置**三击**。 |
| 多段 | 选择一段后**拖动**。 |
| 全文 | 将鼠标移至文档中任意文字的右侧，指针改变方向后三击或 Ctrl+单击；或用快捷键 Ctrl+A；或通过“编辑全选”菜单。 |
| 矩形区域 | Alt+鼠标拖动。 |

## 4.3 复制和移动

- **鼠标左键**：拖动（移动）或按住Ctrl键拖动（复制）。
- **鼠标右键**：拖到目的地，从快捷菜单中选择。
- **菜单**：通过“编辑”菜单，或快捷菜单。
- **工具栏**：通过“常用”工具栏。
- **快捷键**：Ctrl+X（剪切）、Ctrl+C（复制）、Ctrl+V（粘贴）。

## 4.4 撤消和恢复

### 1、重复操作（重复上一次操作）

- “编辑\重复” 命令，或按F4。

### 2、撤消前面的操作

- “编辑\撤消” 命令，或单击 “撤消” 按钮旁的箭头。

### 3、恢复前面撤消的操作

- “编辑\恢复” 命令，或单击 “恢复” 按钮旁的箭头。

## 4.5 查找和替换
