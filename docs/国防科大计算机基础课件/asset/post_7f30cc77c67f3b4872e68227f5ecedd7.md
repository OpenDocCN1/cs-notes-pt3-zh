### 2、间距

- 段落间距：段落前后的距离
- 行间距：文本行之间垂向距离

### 3、段落对齐

- 通过“格式\段落”命令，或“格式”工具栏上的对齐按钮。

### 4、文字对齐

- 通过“格式\段落”命令，选择“中文版式”标签；

## 5.3 边框和底纹

“格式”菜单中，单击“边框和底纹”命令

- 文字边框和底纹（选定文字）
- 段落边框底纹（当前段落）
- 页面边框（全部文档或当前节）

## 5.4 样式的使用

### 3、创建样式

- 单击“格式\样式和格式”命令，然后单击“新样式”。

### 4、删除样式

- 单击“格式\样式和格式”命令，选择要删除的样式，单击其右端的下箭头，然后单击“删除”。

## 5.5 项目符号和编号

通过“格式\项目符号和编号”命令或单击“格式”工具栏上的“项目符号”或“编号”按钮

- 添加或删除列表中的项目符号或编号
- 自定义项目符号或编号
- 创建多级列表

## 5.6 页面设置

![](img/cc764fab5df2f51fd95ee56d3e8b72cf_329_0.png)

通过“文件|页面设置”命令；

或双击水平标尺、垂直标尺。

## 5.7 页眉和页脚

- 单击“视图”菜单上的“页眉和页脚”命令。
- 或双击文档中的页眉或页脚区域（如果有）。
- 通过“页眉和页脚”工具栏。
- “页面设置”时，单击“版式”中的“首页不同”或“奇偶页不同”复选框。
- 选定要删除的页眉或页脚，按Delete键。

## 5.8 分页

| 类型 | 自动分页符 | 人工分页符 |
|---|---|---|
| 建立 | 系统自动处理 | 用“插入分隔符”命令 |
| 编辑 | 系统自动处理 | 同一般文本编辑（移动、复制） |
| 取消 | 系统自动处理 | 选择分页符后，用Delete键 |

### 1、建立文档页码、设置页码格式

- □ 单击“插入”菜单的“页码”命令，再单击“格式”按钮。

### 2、删除页码

- □ “视图”菜单中的“页眉和页脚”命令。

## 5.9 分栏

### 1、设置

- 选择文本
- 在“格式”菜单中，单击“分栏”命令。
- 选择一种分栏格式，或选择“无”

### 2、修改分栏格式

- 选择已分栏文本
- 在“格式”菜单中，单击“分栏”命令。

## 5.11 建立文档目录

在“插入”菜单中，单击“引用索引和目录”命令。

| 项目 | 操作 |
|---|---|
| 创建 | 单击“目录”标签 |
| 更新 | 按F9键，或单击快捷菜单中的“更新域”命令 |
| 删除 | 选中目录，用Delete键 |

## 6.2 表格的建立和取消

| 操作 | 方法 |
|---|---|
| 快速建立表格 | “常用”工具栏中的“插入表格”按钮 |
| 创建复杂表格 | “表格\插入表格”命令 |
| 绘制自由表格 | “表格\绘制表格”命令 |
| 文本转换成表格 | “表格\转换\文本转换成表格”命令 |
| 取消表格 | “表格\转换\表格转换成文本”命令 |

## 6.3 表格的编辑

### 1、选定

| 一个单元格 | 连击三次或者单击单元格最左边 | “表格”菜单中的相应命令 |
|---|---|---|
| 一行 | 单击行左边的空白处 | |
| 一列 | 单击列顶端的边框 | |
| 整个表格 | 单击表格左上角的小框 | |
| 下一格中的文本 | 按TAB（从左至右，上至下） | |
| 上一格中的文本 | 按Shift+TAB | |

### 2、表格中内容的编辑

- 在表格中定位和输入
- 移动和复制
- 清除表格内容
- 文本对齐
  - 水平：同文本对齐方法
  - 垂直：“表格和边框”工具栏
- 文本的排列方式“格式\文字方向”

### 3、表格的编辑

- □ 插入单元格、行、列
  - ✓ 先选定单元格，再通过“表格|插入|...”菜单
    （如果选定多行或多列，则插入相同数目的行或列）
- □ 删除单元格、行、列
  - ✓ 先选定行或列，再通过“表格|删除|...”菜单
  - ✓ 先选定行或列，Backspace键
- □ 移动、复制

## 6.4 表格调整及格式设置

## 6.5 表格的特殊功能

### 行、列和单元格标识

- 行标识：1，2，3等数字。
- 列标识：a，b，c等英文字母。
- 单元格标识：b3表示第3行第b列的单元格。
- 区域标识：a1:c3表示1行a列到3行c列的单元格矩形区域

- □ 将插入点移到要插入图形的单元格中。
- □ 单击“插入\图片\...”命令。

- □ 将插入点移到要插入表格的单元格中。
- □ 选择菜单“表格\插入\表格”命令。

- □ 单击要放置计算结果的单元格
- □ 单击“表格”菜单中的“公式”命令。

## 6.5 表格的特殊功能

### 6、用表格数据建立图表

#### (1)、先创建图表再输入数据

- 单击“插入\图片\图表”，或单击“插入\对象”命令，然后选中“Microsoft Graph图表”。
- 修改表格中的数据并选择所需表格格式选项

#### (2)、根据数据创建图表

- 选定表格的部分或整体。
- 单击“插入\图片\图表”，或单击....。
- 选择所需格式选项。
