# § 6.1 UML概述

+   - **UML（Unified Modelling Language）表示法**
+     - UML的符号、文本语法、图形机制
+     - 用来表达应用问题在需求、设计和实现级的模型

+   - **UML语义**
+     - 用UML表示法描述UML的元模型
+     - 元模型为UML的所有语法元素的语义提供定义性说明

+   - **UML的可视化建模机制**分为静态和动态：
+     - 静态机制包括：用例图、类图、对象图、包图、构件图、配置图
+     - 动态机制包括：顺序图、合作图、状态图、活动图
