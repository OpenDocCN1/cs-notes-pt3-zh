# § 6.3.3 状态图

§ 6.3 UML动态建模机制

状态图刻划特定对象所有可能的状态及状态变迁

+   • **结点**：包含状态名，**活动**（Activity）
+     - **entry活动**：一旦对象进入该状态，相应的活动被触发执行
+     - **Exit活动**：一旦从该状态离去，相应的活动被触发执行
+     - **Do活动**：当对象位于该状态时，执行相应的活动，状态不变

+   • **状态转移**：状态转移由事件触发
+     - 如果状态转移边上没有事件，那么当状态中的所有活动执行
+     - 完成之后，自动立刻进行状态转移

+   • **状态转移动作**（action）具有原子性，活动则不然
