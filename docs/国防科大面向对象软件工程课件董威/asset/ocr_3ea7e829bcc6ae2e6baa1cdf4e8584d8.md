# 状态模型检查表（五）：健壮性

# 5. 模型规定了健壮行为

+   5.1 对没有被明确拒绝的事件， 有 一个明确规定的 错误处理和异常处理 机制；

+   5.2 对于一个非法消息的结果， 实现的 状态不会被错误地改变、被诽谤或没有被定义；

+   5.3 对每一个动作， 没有改变和这个动作相关的结果状态的副作用或异常；

+   5.4 对前置、后置条件， 不变式的冲突， 规定了明确的异常、错误注册和恢复机制；

+   5.5 对丢失或延迟的事件规定了明确的异常、错误注册和恢复机制；

+   5.6 对每一个超时， 规定了明确的异常、错误注册， 恢复机制；

+   5.7 被测系统的目标环境的主要和不重要的失败模式被分类， 对每个失败模式， 规定了一个明确的异常机制；

+   5.8 对每一失败模式， 指定了结果状态， 或硬性的终止状态；

+   5.9 重新开始机制被建模并定义了一个到 一个正常状态的路径。
