# Summary

# Analysis and Design Process with UML:

+   1. Identify actors and use cases
+   2. Realize use cases with sequence and / or collaboration diagrams
+   3. Describe classes and their relationships in the logical view
+   4. Create state diagrams for objects
+   5. Illustrate the organizations and dependencies among software components with component diagrams
+   6. Visualizes configuration and distribution with deployment diagrams
