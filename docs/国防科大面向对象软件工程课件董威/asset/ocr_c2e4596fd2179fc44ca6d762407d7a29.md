# 不变量边界

# □ 目标

- 为由复杂的和原始的数据类型组成的类、接口及构件选择能高效测试的测试值组合。

# □ 上下文和故障模型

- 在IUT的范围内为所有的变量提供值，随后运行一个测试；实例变量值的有效和无效的组合可被类的不变课指定。

# □ 策略

```
assert( (txCounter >=0 && txCount<=5000) &&
        (creditLimit>=99.99 && creditLimit<=1000000) &&
        ((!account1.isClosed() || !account2.isClosed()) );
```
