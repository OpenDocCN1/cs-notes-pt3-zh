# 5. 关联

![](bbox=[0.02, 0.04, 0.18, 0.24])

表示两个类之间语义上联系

+   ♣ 概念层：两个概念之间的联系
+   关联具有两个角色（Roles），可以对角色命名，匿名角色使用目标类作为名字

+   ♣ 规范层：隐含 类型之间的查询职责和关系维护职责

```
class Order { public Customer getCustomer();
                  public Enum enumOrderItems(); }
```

+   ♣ 实现层：隐含 两个类在各自的成员变量中相互包含或引用

```
class Order { private Customer       m_customer;
                  private ItemVector     m_orderItems; }
class Customer { private OrderVector m_orders; }
```
