## CRC

### Class CardReader

**Responsibilities**

- Tell ATM when card is inserted
- Read information from card
- Eject card
- Retain card

**Collaborators**

- ATM
- Card

### Class CashDispenser

*Boundary/entity objects*

**Responsibilities**

- Keep track of cash on hand, starting with initial amount
- Report whether enough cash is available
- Dispense cash

**Collaborators**

- Log

### Class EnvelopeAcceptor

*Boundary/entity objects*

**Responsibilities**

- Accept envelope from customer; report if timed out or cancelled

**Collaborators**

- Log

### Class Log

**Responsibilities**

- Log messages sent to bank
- Log responses from bank
- Log dispensing of cash
- Log receiving an envelope

**Collaborators**

### Class NetworkToBank

*Boundary/entity objects*

**Responsibilities**

- Initiate connection to bank at startup
- Send message to bank and wait for response
- Terminate connection to bank at shutdown

**Collaborators**

- Message
- Log

### Class OperatorPanel

*Boundary/entity objects*

**Responsibilities**

- Inform ATM of changes to state of switch
- Allow operator to specify amount of initial cash

**Collaborators**

- ATM

### Class ReceiptPrinter

*Boundary/entity objects*

**Responsibilities**

- Print receipt

**Collaborators**

- Receipt

### Abstract Class Transaction

**Responsibilities**

- Allow customer to choose a type of transaction
- Perform Transaction Use Case
- Perform invalid PIN extension

**Collaborators**

- ATM
- CustomerConsole
- Withdrawal
- Transfer
- Deposit
- Inquiry
- Message
- NetworkToBank
- ReceiptPrinter
- Session
- CardReader
