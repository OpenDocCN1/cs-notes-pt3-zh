# # 风险管理的策略(1/2)

# ## 危机管理

+   - 救火模式，风险造成麻烦后才着手进行处理

+   - 例如，小谢离开公司1个月后，其他小组需要小谢所负责子系统的模块以便进行集成和测试，但是相关代码还没写，此时已经影响其他小组计划和项目进度，为此抽调其他人接替小谢工作

# ## 失败处理

+   - 察觉到了风险之后采取措施，但只是在风险发生之后

+   - 例如，小谢出走的第二天，公司决定抽调其他人员来接替

# ## 风险缓解

+   - 识别了风险，并且事先制定好风险发生后的补救措施，但是不做任何防范措施。

+   - 例如，知道不好事件可能会发生，等它发生。小谢要走，小张接替
