# # 第6章 多态

```
// 主函数
int main(){
TwoDimensionalShape t;
t.show();
Square s(3);
s.show();
TwoDimensionalShape * members[2]; //二维图形指针数组
members[0]=&t;
members[1]=&s;
for(int i=0;i<2;i++)
members[i]->show();
return 0;
}
```
