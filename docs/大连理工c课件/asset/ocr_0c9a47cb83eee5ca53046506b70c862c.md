# ### 例3.13 普通函数作为多个类的友元函数

```
```cpp
class Point
{
private:
    double x, y;    //x,y 坐标
public:
    Point(double x=0.0, double y=0.0);
    void disp();
    friend double distance(Point p, Line l); //声明为Point的友元
};
Point::Point(double x, double y){
    this->x = x; this->y = y;
}
void Point::disp() { cout<<"点（"<<x<<","<<y<<")"; }
