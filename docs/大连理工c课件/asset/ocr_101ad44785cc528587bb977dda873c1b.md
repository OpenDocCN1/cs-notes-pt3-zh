# ## 3.9 const成员和const对象

# ### 函数参数为对象引用

一个对象的引用就是对象的别名。对象名和引用名都指向同一段内存单元；
如果形参为对象的引用名，实参为对象名，形参即为实参对象。

```
void f(Circle & r){
cout<<r. setRadius(10);
cout<< r.area();
}
```

```
void f(const Circle & r){
//cout<<r. setRadius(10);
非法
cout<< r.area(); }
}
```

函数调用：
Circle c1(1.2, 2.3, 4, 3.14);
f(c1);
