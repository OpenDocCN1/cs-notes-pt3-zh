# ## 引用访问

# ### 1. 引用声明

引用的声明格式：
类型标识符 &引用名=目标变量名；
int a;
int &ra=a; //定义引用ra，它是变量a的引用，即别名。

+   - 说明：
+   （1）&在此不是求地址运算，而是起标识作用。
+   （2）类型标识符是指目标变量的类型。
+   （3）声明引用时，必须同时对其进行初始化。
+   （4）引用声明完毕后，相当于目标变量名有两个名称，且不能再把该引用名作为其他变量名的别名。
+   （5）声明一个引用，不是新定义了一个变量，因此引用本身不占存储单元，系统也不给引用分配存储单元。故：对引用求地址，就是对目标变量求地址，&ra与&a相等。
+   - 使用引用变量的时候有一些限制：
+   （1）不能引用一个引用变量。
+   （2）不能创建一个指向引用的指针。
+   （3）不能建立数组的引用。
