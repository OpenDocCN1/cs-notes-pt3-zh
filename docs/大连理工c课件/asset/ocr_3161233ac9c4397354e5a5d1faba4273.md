# ## 3.11 类组合关系

类中的成员，可以为基本数据类型外，还可以是一个已定义类类型，称为类的组合或类的聚合，这样的类简称为组合。

```
```cpp
class Date {
private:
    int year,month,day;
public:
    Date(int yr,int mn,int dy)
    { year = yr; month =mn;
      day =dy;
      cout<<"constructor Date"<<endl;}
    Date(Date& d){ cout<<"copy constructor Date"<<endl;} };
```

class Student {
