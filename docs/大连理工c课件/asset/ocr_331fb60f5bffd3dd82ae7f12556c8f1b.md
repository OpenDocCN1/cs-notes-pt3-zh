# # 第3章 类与对象





对象的访问是指对对象成员的使用，可以通过成员运算符“.”和指向成员运算符“->”访问，针对对象、指针和引用：

+   1. 通过对象访问：
+   对象名.数据成员
+   对象名.成员函数（实参表）

```
clock1.setClock(6,15,24);
clock1.hour=6;
//此处不正确，hour私有
```

+   2. 通过指针访问：
+   指向对象的指针->数据成员
+   指向对象的指针->成员函数（实参表）
+   (*指向对象的指针).数据成员
+   (*指向对象的指针).成员函数（实参表）

```
Clock *p; p=&clock1;
p->setClock(6,15,24);
(*p).setClock(6,15,24);
```

+   3. 通过引用访问：
+   Clock &clock3=clock1;
+   clock3.setClock(6,15,24);
+   clock1.setClock(6,15,24);

```
Clock &clock3=clock1;
clock3.setClock(6,15,24);
clock1.setClock(6,15,24);
```
