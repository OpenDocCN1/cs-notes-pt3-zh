# # 第8章 异常处理

```
void main(){// 主函数
MyArray a(10);
for(int i=0;i<3;i++){
try {
if(i!=1) {
a[i]=i;
cout<<"a["<<i<<"]="<<a[i]<<endl;
}
else a[a.size()+10]=10;
}catch( ArrayIndexOutOfBounds &a ){ a.show(); }}
}
```

类对象来描述一个异常有这样的优点，异常的类型具有专一性，一个类对应了一种特定意义的异常，这些异常具有数据成员和函数成员，表现力更加丰富，使得程序的可读性更强。
