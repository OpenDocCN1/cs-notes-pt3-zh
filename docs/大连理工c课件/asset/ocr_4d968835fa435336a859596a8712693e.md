# ## 3.10 友元函数和友元类

# ## 例3.15 友元类

```
class Line
{
private:
    double a, b, c;    //直线为ax+by+c=0的系数
public:
    Line(double a=0.0, double b=0.0, double c=0.0);
    void disp( );    // 输出私有变量的成员函数
    friend class ComputeTools; //声明为Line的友元类
};
Line::Line(double a, double b, double c){
    this->a = a; this->b = b; this->c = c; }
void Line::disp( ){
    cout<<"线 ("<<a<<"x+"<<b<<"y+"<<c<<"=0 ) ";}

```
