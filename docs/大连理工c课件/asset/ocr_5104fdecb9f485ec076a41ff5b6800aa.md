# # 重载自增运算符

```
void main()
{
    Increase a, b, n;
    for ( int i = 0 ; i < 10 ; i ++ )
    a = n ++ ;
    cout <<"n= " ; n.display() ;
    cout <<"a= " ; a.display() ;
    for ( int i = 0 ; i < 10 ; i ++ )
    b = ++ n ;
    cout << "n= " ; n.display() ;
    cout << "b= " ; b.display() ;
}
```
