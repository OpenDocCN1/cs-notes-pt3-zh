# ## 友员函数重载++

```
class Increase
{
int value ;
public :
Increase ( ) { value=0; }
void display() const { cout<<<value<<'\n'; } ;
friend Increase& operator ++ ( Increase & ) ; // 前置
friend Increase& operator ++ ( Increase &, int ) ;
};
Increase& operator ++ ( Increase & a )
{ a.value ++ ; return a ; }
Increase& operator ++ ( Increase & a, int )
{ Increase temp(a); a.value ++ ; return temp; }
```
