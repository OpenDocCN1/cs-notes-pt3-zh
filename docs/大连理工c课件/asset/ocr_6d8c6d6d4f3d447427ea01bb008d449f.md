# 第3章 类与对象



数组元素不仅可以由简单类型组成（例如，整型数组的每一个元素都相当于一个整型变量），也可以由对象组成（对象数组的每一个元素都是同类型的对象）。

```
class Student{
private:
char name[20];
int age;
float score;
public:
Student(int s){
strcpy(name,"no name");
age=20;
score=s;
}
};
```

数组定义：
Student stud[3]={60,70,78};

构造函数只有一个参数 数组可以这样初始化;
