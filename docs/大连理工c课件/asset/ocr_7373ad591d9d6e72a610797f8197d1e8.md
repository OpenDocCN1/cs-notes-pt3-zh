# ## 7.3 类模板

template< typename T > 一个数组类模板

```
class Array
{
public:
    Array( int s );
    virtual ~Array();
    virtual const T& Entry( int index ) const;
    virtual void Enter( int index, const T& value );
    // T& operator[] (int index);
protected:
    int size;
    T* element;
};
```
