# 9.3 流操作

# iostream类的公有成员函数

| 函数 | 功能 |
|---|---|
| **read** | **无格式输入指定字节数** |
| get | 从流中提取字符，包括空格 |
| **getline** | **从流中提取一行字符** |

```
int get();

istream& get( char& rch );

istream& get( char* pch, int nCount, char delim = '\n' );
istream& getline( char* pch, int nCount, char delim = '\n' );
```
