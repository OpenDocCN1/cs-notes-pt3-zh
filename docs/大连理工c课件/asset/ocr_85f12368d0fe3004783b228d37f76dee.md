# ### 例3.14 成员函数作为类的友元函数

```
class Point
{
private:
    double x, y;    //x,y 坐标
public:
    Point(double x=0.0, double y=0.0);
    void disp( );
    double distance(Line l); //声明为Point的成员
};
Point::Point (double x, double y){
    this->x = x; this->y = y;
}
void Point::disp( ){ cout<<"点 ("<<x<<","<<y<<") "; }
```
