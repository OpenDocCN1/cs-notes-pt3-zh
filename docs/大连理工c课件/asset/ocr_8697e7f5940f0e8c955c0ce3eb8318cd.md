# 例5.2 访问私有继承的成员

```
class Student {
public: void input_data(
......
};
```

```
class CollegeStudent : private Student {
......
};
```

```
int main(){
    CollegeStudent cs;
    cs.input_data();
    cs.input_major();
    cs.print();
    return 0; }

```

> 对于CollegeStudent来说，它访问基类Student的能力没有变化，但是所有它所继承的成员其属性全部变为私有。事实上，在私有继承的情况下，通过派生类对象无法访问基类的任何成员。
