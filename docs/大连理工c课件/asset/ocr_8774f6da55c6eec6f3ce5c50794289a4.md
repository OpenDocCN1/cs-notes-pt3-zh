# 例3.2 两点距离（代码分离）

头文件point.h包含类定义：
//point.h
class Point
{
public:
double distance(Point & p);
void setX(double i);
void setY(double j);
private:
double x;
double y;
};

源文件point.cpp包含类实现：
//point.cpp
#include<iostream>
#include<cmath>
#include"point.h"
using namespace std;
double Point::distance(Point & p){
return sqrt((p.x-x)*(p.x-x)+(p.y-y)*(p.y-y)); }
void Point::setX(double i){x=i;}
void Point::setY(double j){y=j;}
