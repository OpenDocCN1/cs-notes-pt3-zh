# # 例9.11 随机文件读写

```
f.seekg(pos); //将指针移到 pos 所表示的位置
f.read((char*)&i, sizeof(int)); //读出一个数据
cout << "The data stored is " << i << endl
<< "file pointer pass: " << f.tellp()-pos<<endl;
//读文件后指针移动字节数
f.seekp( 0, ios::beg ); //指针移到文件开头
for( i = 0; i<40; i ++ ) //显示主部数据
{ f.read( (char*)&i, sizeof(int) );
cout << i << ends;
}
```
