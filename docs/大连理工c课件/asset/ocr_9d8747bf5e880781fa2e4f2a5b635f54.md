# ## 3.9 const成员和const对象

# ### const数据成员

```
```cpp
class Clock
{
private :
    const int hour;    //常量数据
    int minute, second;  //非常量数据
public :
    Clock (int h, int m, int s):hour(h),minute(m),second(s){ }
};
```
```
