# 文件无格式读写函数

+   • ostream 类中写入字节数据的成员函数

```
ostream & ostream :: write (char * buf, int n);
```

向流插入 buf 对象的由第二个参数指定数目的字节数据

```
ofstream outf("test.dat");
char str[10] = "Hello!";
outf.write(str, 10);
int a[10] = {1,2,3,4,5};
for(int i = 0; i < 10; i++)
outf.write( (char *)(&a[i]), sizeof(int) );
```

```
outf.write((reinterpret_cast<char*>(a), 10*sizeof(int));
```

> 注意类型转换
