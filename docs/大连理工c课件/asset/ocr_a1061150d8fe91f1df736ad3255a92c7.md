# # 第8章 异常处理

```
```cpp
void test(){
    Triangle tri1(1); Triangle tri2(2);
    tri1.set_sides(3,4,5); tri2.set_sides(1,4,5);
}
```
```

```
```cpp
void main()//主函数
{
    cout<<"main start"<<endl;
    cout<<"call test"<<endl;
    try{
        test();
    }catch(char* c){
        cout<<"异常: "<<c<<endl;
    }
    cout<<"main end"<<endl;
}
```
```

+   程序运行结果如下：
+   - main start
+   - call test
+   - 构造函数调用, num=1
+   - 构造函数调用, num=2
+   - 三角形1三边设置完毕
+   - 析构函数调用, num=2
+   - 析构函数调用, num=1
+   - 异常: 边长需满足三角不等式
+   - main end
