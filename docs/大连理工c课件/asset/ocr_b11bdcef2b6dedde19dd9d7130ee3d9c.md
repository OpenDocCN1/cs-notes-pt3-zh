# ## 7.4 范型程序设计及STL简介

+   - STL算法在数据集上进行操作，泛型算法不依赖于具体的容器。
+   - 泛型算法分类为
+     (1)不修改序列的操作
+       find()、cout()、equal()、mismatch()和search()等。
+     (2)修改序列的操作
+       swap()、copy()、transform()、replace()、remove()、reverse()、rotate()和fill()等。
+     (3)排序、合并和相关的操作
+       sort()、binary_search()、merge()、min()和max()等。
