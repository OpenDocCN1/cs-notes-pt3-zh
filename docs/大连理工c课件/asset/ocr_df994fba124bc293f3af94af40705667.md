# ## 重载运算符<<

```
class IntArray
{
public:
	IntArray(int s=0);
	~IntArray();
	int& operator[](int i);
	friend ostream& operator<< ( ostream& out, intArray&a );
private:
	int * pArr;
	int size;
};
```

```
ostream& operator<<
(ostream& out, IntArray& a)
{	for(int i = 1 ; i<=a.size ; i++)
		out<< a.pArr[i]<<' ' ;
	return out;
}
```
