# # 重载下标运算符[]

```
```cpp
class IntArray
{
public:
    IntArray(int s=0);
    ~IntArray();
    int& operator[](int i);
private:
    int * pArr;
    int size;
};
```
```

```
```cpp
int& IntArray::operator[](int i)
{
    if(i<1||i>size)
    {
        cout<<" Out of range!"<<endl;
        return pArr[0]; }
    return pArr[i];
}
```
