# ### 例3.17 父亲给儿子钱类的设计

```
int Father::pay(int m){
if(m<=0)
return 0;
if(money>=m) {
money=money-m;
return m;
}
else return 0;
}
```

```
Father f1("李四",10000);
Son s1(&f1," 李小四",100);
s1.receive(f1.pay(1000));
f1.print(); //name: 李四 money:9000
s1.print();//name: 李小四money:1100
```
