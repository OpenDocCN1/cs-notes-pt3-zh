# ## 2.自定义默认构造函数

# ### 一般在构造函数内部设置成员变量的值

```
```cpp
class Time
{
public:
    Time();
    void set_time(int, int, int);
    void show_time();
private:
    int hour, min, sec;
};
Time::Time()
{
    hour=0; min=0; sec = 0;
}
```
```

```
```cpp
#include <iostream.h>
int main()
{
    Time t;
    t.show_time();
    return 0;
}
```
