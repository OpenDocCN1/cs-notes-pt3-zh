```
class Time
{
public:
    Time(int, int, int);
    void display (Date &);
private:
    int hour, minute, sec;
};
```

```
class Date
{
    public:
        Date(int, int, int);
        void show();
        friend class Time;
    private:
        int month; int day;
        int year;
};
```

# 说明：

+   ✓友元关系是单向的；

+   ✓友元关系不能传递。
