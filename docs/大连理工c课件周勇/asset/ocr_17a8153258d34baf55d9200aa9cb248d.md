# # 1.默认构造函数

```
```cpp
class Time
{
public:
    Time() { }
    void set_time(int, int, int );
    void show_time( );
private:
    int hour;
    int min;
    int sec;
};
```
```

```
```cpp
#include
<iostream.h>
int main( )
{
    Time t1;
    t1.set_time( );
    t1.show_time( );

    Time t2;
    t2.show_time( );

    return 0;
}
```
```

初始化类对象的数据成员，在生成这个类的对象时自动调用。
