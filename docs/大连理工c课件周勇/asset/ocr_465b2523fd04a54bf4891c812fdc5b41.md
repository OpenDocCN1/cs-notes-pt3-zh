# # 例 友元函数的简单例子

```
class Time
{public:
    Time(int, int, int);
    friend void display(Time &);
private:
    int hour, minute, sec;
};

Time::Time(int h, int m, int s)
{   hour=h;   minute=m;   sec=s; }

void display( Time& t )
{
    cout<<t.hour<<" : "<<t.minute<<" : "<<t.sec<<endl; }

```

```
#include <iostream.h>
int main( )
{
    Time t1(10,13,56);
    display(t1);
    return 0;
}
```
