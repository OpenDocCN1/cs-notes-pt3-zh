# ## 2. 用户自定义类库的内部实现源文件

包括相关头文件包含和类中成员函数的定义。

这就形成类的实现方法。

```
```cpp
//date.cpp
#include<iostream.h>
#include "date.h"
void Date ::set(int m,int d,int y)
{
    month=m; day=d; year=y;
}
int Date :: isLeapYear( )
{
    return
    (year%4==0&&year%100!=0) || (year%400==0) ;
}
void Date :: print( )
{
    cout <<month <<"/" <<day <<"/" <<year <<endl;
}
