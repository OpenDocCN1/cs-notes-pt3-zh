# # 面向对象程序设计

# # 4. 多态性(polymorphism)

CPerson bush;
CDuck donald;
Roar (&bush);    < == >   bush.roar();
Roar (&donald);   < == >   donald.roar();

void Roar (CAnimal* pAnimal)
{
    pAnimal->roar();
}

利用多态性，用户可发送一个通用的信息，而将所有的实现细节都留给接受消息的对象自行决定。
