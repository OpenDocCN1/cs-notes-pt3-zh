# ## 2.自定义构造函数

# ### 一个类中只能有一个默认构造函数！

```
```cpp
class Time
{
public:
    Time();
    void set_time(int, int, int);
    void show_time();
private:
    int hour, min, sec;
};
Time::Time():hour(0)
{
    //hour=0;
    min=0; sec = 0;
}
```
```

+   1. 将变量hour置为0；
+   2. 这种初始化方法在构造函数执行以前进行。
+   3. 如何用这种方式初始化多个成员变量？
