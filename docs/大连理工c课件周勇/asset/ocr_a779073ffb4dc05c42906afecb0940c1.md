# 1. 默认构造函数

# ▪ 在构造函数处初始化成员

```
class Time
{
public:
  Time();
  void set_time(int, int, int);
  void show_time();
private:
  int hour, min, sec;
};
Time::Time():hour(0)
{
  //hour=0;
  min=0; sec = 0;
}
```

+   1. 将变量hour置为0；
+   2. 这种初始化方法在构造函数执行以前进行。
+   3. 如何用这种方式初始化多个成员变量？
+   4. 有些成员必须这样初始化！
