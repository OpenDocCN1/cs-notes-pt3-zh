# # 定义成员函数

# ## 1. 类外定义成员函数

```
void Clock :: setTime()
{
    cin>>hour;
    cin>>minute;
    cin>>sec;
}
void Clock:: showTime()
{ cout<<hour<<" :"
    <<minute<<" :"
    <<sec<<endl;
}
```

# ## 2.类内定义成员函数

```
class Clock
{
    public:
    void setTime()
    { cin>>hour>>minute>>sec;}
    void showTime()
    {   cout<<hour<<":"
    <<minute<<":"
    <<sec<<endl; }
    private:
    int hour, minute, sec;
};
```
