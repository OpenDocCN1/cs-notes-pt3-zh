# # 友元函数

```
class A
{
private:
    int num ;
public:
    void MemberFun(int) ;
    friend void FriendFun(A * , int) ;
} ;
```

```
void A:: MemberFun( int x )
{ this-> num = x ; }
```

```
void FriendFun( A * ptr, int x )
{ ptr -> num = x ; }
```
