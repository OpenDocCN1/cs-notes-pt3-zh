

## 类的封装性和信息隐蔽（自习）

### 公用接口与私有实现的分离

- 类中被操作的数据是私有的，实现细节对用户是隐蔽的，这种实现称为私有实现。
- 在声明了一个类以后，用户主要是通过调用公用的成员函数来实现类提供的功能。因此，公用成员函数是用户使用类的公用接口，或者说是类的对外接口。
- 软件工程的一个最基本的原则就是将接口与实现分离，信息隐蔽是软件工程中一个非常重要的概念。

### 类声明和成员函数定义的分离

#### 1. 自定义类库头文件.h

文件中有用户自行设计的类的定义，包括类的外部接口（公有成员函数的原型）。任何需要使用这些类的源程序，只要在文件中包含这些头文件即可。

```cpp
// date.h
class Date{
public:
    void set(int m,int d,int y);
    int isLeapYear();
    void print();
private:
    int month, day, year;
};
```

#### 2. 用户自定义类库的内部实现源文件

包括相关头文件包含和类中成员函数的定义。

这就形成类的实现方法。

```cpp
//date.cpp
#include<iostream.h>
#include "date.h"
void Date ::set(int m,int d,int y)
{
    month=m; day=d; year=y;
}
int Date :: isLeapYear( )
{
    return
    (year%4==0&&year%100!=0)||(year%400==0);
}
void Date :: print( )
{
    cout <<month <<"'/'" <<day <<"'/'" <<year <<endl;
}
```

#### 3. 唯一包含主函数的源文件

包括所有相关头文件及 main

```cpp
#include<iostream.h>
#include "date.h"

void main( )
{
    {
        Date a;
        a.set(2,4,1998);
        a.print( );
    }
}
```

### 构造函数

构造函数是一种用于创建对象特殊的成员函数；

- 特点：
  - 构造函数是与类同名的成员函数
  - 可有任意类型的参数，但没有返回类型
  - 不能由程序员调用，创建对象时自动执行

- 作用：
  - 为对象分配空间；
  - 对数据成员赋初值；
  - 请求其他资源。

### 构造函数种类

- 默认构造函数
- 有参构造函数
- 复制构造函数
