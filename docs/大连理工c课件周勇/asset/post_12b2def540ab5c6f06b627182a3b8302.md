

## const与类

### 1. const 对象

- 用 **const** 声明的对象称为常量对象。

```cpp
const Date d1;
Date::Date(const Date & d);
Date dQ(d1);
```

- **const** 对象只能调用它的 **const** 成员函数，
  而不能调用其他成员函数。

### 2. const 成员函数

- 使用**const**关键词说明的函数称为常量成员函数，说明格式如下：

  `<类型> <函数名>(<参数表>) const;`

- **const** 成员函数的定义格式如下：

  `<类型> <函数名>(<参数表>) const`
  
  `{ ...... }`

- 若成员函数**不修改对象**,则声明为**const.**

对于const 成员函数需要注意以下几点：

1. const是函数类型的一个组成部分，因此在实现部分也要带const关键词。
2. 常成员函数不更新对象的数据成员，也不能调用该类中非常成员函数。
3. const关键词可以参与区分重载函数。
   ```cpp
   void print();
   void print() const;
   ```
   则这是对print的有效重载。

```cpp
class Time
{
public:
    Time(int h = 0, int m = 0, int s = 0)
    :hour(h),minute(m),second(s) { }
    void setTime( int h, int m, int s)
    { hour=h; minute= m; second =s; }
    void show() const;
private:
    int hour, minute, second;
};
main()
{
    const Time t(20, 20, 20) ;
    t.show() ;
    t.setTime(30, 39, 39) ; //error
}
```

### 3. const 成员变量

- 用 const 声明的成员变量为常量成员变量

- const 成员变量只能由构造函数通过初始化列表对该数据成员进行初始化。

```cpp
class Time {
public:
    Time(int h = 0,int m = 0,int s = 0) ;
    void setTime( int, int, int );
    int setHour(int );
    int getHour();
    int getMinute();
    void print ();
private:
    const int hour;
    int minute; // 0
    int second; // 0
};
Time wakeUp( 6, 45, 0 );
wakeUp.setHour( 8 );
wakeUp.getHour();
wakeUp.print ();
```

### 2.对象数组

对象数组的元素为同类对象，即相同属性的不同实体构成对象数组。

对象数组的定义与初始化

```
类名 数组名[元素个数];
```

```
类名 数组名[元素个数] = {初始化列表} ;
```

> 为使对象数组合理初始化，应提供合适的构造函数：
> (1) 使用默认构造函数；
> (2) 若有用户自定义构造函数，则必须含有有一个不带参数或具有一个带默认参数的构造函数。

```cpp
class Box
{
public:
    Box(int = 0 ,int =0, int =0 );
    int volume();
private:
    int height; int width;int length;
};
```

```cpp
int main()
{ Box a[3]={ Box(10,12),
    Box(15,18,20)
};
for( int i = 0; i<3;i++)
    cout<<a[i].volume()<<endl;
Box *p =new Box[10];
delete [ ] p;
}
```
