## 友元类

- 当两个类关系极为密切时，可以将类声明为另一个类的友元。友元类通常设计为一种对数据操作或类之间传递消息的辅助类。

- 将一个类声明为另一个类的友元类定义的一般格式如下：

```
friend class 友元类名；
```

- 当一个类作为另一类的友元类时，类的所有成员函数都是另一类的友元函数。

## 友元类

说明：

- 友元关系不具有传递性。

  例如

  类A是类B的友元，类B是类C的友元，

  但并不表示A是C的友元。

- 友元关系不具有交换性。

  例如

  类A是类B的友元，但并不表示类B是类A的友元。

```cpp
class Time
{
public:
    Time(int, int, int);
    void display (Date &);
private:
    int hour, minute, sec;
};
```

```cpp
class Date
{
    public:
        Date(int, int, int);
        void show();
        friend class Time;
    private:
        int month; int day;
        int year;
};
```

说明：

- 友元关系是单向的；

- 友元关系不能传递。

## 友元 (friend)

- 友元可以访问与其有好友关系的类中的私有成员。

友元包括友元函数和友元类。

- 使用友员目的是基于程序的运行效率

运算符重载的某些场合需要使用友员

- 友员关系是单向和非传递的。

## 四、构造函数

### ➢作用

- 用于初始化对象的特殊成员函数：
- 为对象分配空间；对数据成员赋初值；请求其他资源。

### ➢特点

构造函数是与类同名的成员函数
可有任意类型的参数，但没有返回类型
不能由程序员调用，创建对象时自动执行
