## 成员函数

### 成员函数 vs. 一般函数

- 都有函数体，返回值和函数类型。

- 成员函数属于一个类的成员，出现在类体中

- 成员访问说明符限制private、public

  注意调用它的权限以及它的作用域

- 成员函数必须由对象句柄调用

- 成员函数和数据成员封装成一体

## 类对象的存储方式

用类去定义对象时，系统会为每一个对象分配存储空间。如果一个类包括了数据和函数，要分别为数据和函数的代码分配存储空间。

```cpp
Time t;
sizeof(Time) == sizeof(t)
```

## 4. 类的实例化-对象

### 定义对象有三种形式

#### （1）先声明类类型，后定义对象

```cpp
class Date d1,d2;
// 把class和Date合起来作为一个类名
Date d1,d2;
// 直接用类名定义对象。
```

### (2) 在声明类类型的同时定义对象

```cpp
class Date
{
    public:
        void Set(int m, int d, int y ){…}
        int IsLeapYear() {…}
        void Print( ) {…}
    private:
        int month;
        int day;
        int year;
} d1, d2;
```

### （3）不出现类名，直接定义对象

```cpp
class
{
    private:
    :
    public:
    :
}d1, d2;
//无类名
//声明以下部分为私有的
//声明以下部分为公用的
//定义了两个无类名的类对象
```

编译系统会为这个对象分配存储空间，以存放对象中的成员。

## 对象的使用

- 由于类和结构是等价的，对类的五种操作对结构也同样适用：

  （1）对象之间可以相互赋值。

  ```cpp
  Location locationA, locationB;
  locationA.set (5,6);
  locationB = locationA;
  ```

  （2）对象可以作为数组的元素。

  ```cpp
  Location arrayloc[100];
  ```

  （3）可以说明指向对象的指针，  
  但不能取私有数据成员的指针或成员函数的地址。

  ```cpp
  Location location[10];
  Location *pointLoc = &location[0];
  ```

  当pointLoc被加1后，它将指向下一个Location对象

  （4）对象可以作为函数的参数，  
  既可作值参也可以作引用参数。

  ```cpp
  void display(Location &location) { ... };
  ```

  （5）一个对象可以是另一个类的成员－类的组合

### 注意：

例：

## 5. 成员的访问

一般用对象访问成员引用形式

**成员访问**运算符“.”和“->”

- 数据成员  
  - 对象名.成员名  
  - 或 对象指针名->成员名  

- 成员函数  
  - 对象名.成员名（参数表）  
  - 或 对象指针名->成员名（参数表）

## 2. 成员的访问

- 通过指向对象的指针访问对象中的成员；

```cpp
Time t, *pTime;   //定义对象t和指针变量p
pTime =&t;        //使p指向对象t
cout << pTime ->hour << (*pTime).hour << t.hour ;
```

- 通过对象的引用变量访问对象中的成员。

```cpp
Time t1;   Time &t2=t1;
cout<<t2.hour;
void Fuction( Time& t);
```

## 2. 成员的访问

访问对象中的成员可以有3种方法：

- 通过对象名和成员运算符访问对象中的成员；

```cpp
class A
{
private :
    int m_a;
public:
    int m_b;
    void print(){ cout<<m_a<<m_b };
    int getA(){ return m_a ; }
};
```

```cpp
A a ;
× a.m_a = 5;
✓ a.m_b = 6;
✓ a.print() ;
```
