## 2. 类的声明与定义

- 类是用户定义的数据类型，用关键字class声明。
  类包含两种成员：数据成员和成员函数。
- 类的定义指包含成员实现的类声明
- 类使程序员可以构造对象的属性和行为或操作

类一般定义格式如下：

```cpp
class ClassName
{
private:
    data member & member function;
public:
    data member & member function;
};
Member function definition;
```

### 定义成员函数

**1. 类外定义成员函数**

```cpp
void Clock::setTime()
{
    cin>>hour;
    cin>>minute;
    cin>>sec;
}
void Clock::showTime()
{
    cout<<hour<<" :"
        <<minute<<" :"
        <<sec<<endl;
}
```

**2. 类内定义成员函数**

```cpp
class Clock
{
public:
    void setTime()
    { cin>>hour>>minute>>sec; }
    void showTime()
    {
        cout<<hour<<":"
            <<minute<<":"
            <<sec<<endl;
    }
private:
    int hour, minute, sec;
};
```

- 成员函数为描述对象的方法
- 在类的外部定义成员函数

```cpp
返回类型    类名::成员函数名(参数列表)
{
    函数定义体
}
```

- 在类内直接定义成员函数，默认创建为内联函数

如果成员函数在类体外定义，则要用inline声明为内联函数

### 成员函数 vs. 一般函数

- 都有函数体，返回值和函数类型。
- 成员函数属于一个类的成员，可出现在类体中；定义在类体外时要加类名和作用域解析符::
- 成员函数和数据成员封装成一体，可直接引用数据成员
- 成员函数只能由本类对象或者成员访问；访问说明符限制private、public

## 3. 访问控制

决定调用成员的权限以及它的作用域

### 成员访问说明符

- 公有 public:
  说明为公有的成员可以被程序中的任何代码访问；
- 私有 private:
  说明为私有的成员只能被类本身的成员函数及友元类的成员函数或友元函数访问，默认类的成员是私有；
- 保护 protected:
  除了类本身的成员函数和说明为友元函数或友元类的成员函数可以访问保护成员外，该类的派生类的成员也可以访问。

![](img/bf99340ecbaf09a3098cf7d9c4b141d1_56_0.png)

```cpp
class A
{
private:    // 首次出现时可以省略
    int m_a;
    void set( int a ) { m_a = a; }
public:    // 公有成员
    int m_b;
    void show();
};

void A::show(){ cout << m_a << m_b <<endl;}
```

```cpp
A a;    //定义A类的对象a
a.m_a;
a.m_b;
a.show();
a.set(5);
```

- private声明的数据和函数不能在类以外访问
- public声明的数据和函数可以在类以外访问
- 默认为private访问类型

```cpp
class A
{
public:
    int m_b;
    void show();
private:
    int m_a;
    void set(int a)
    {
        m_a = a;
    }
};
```
