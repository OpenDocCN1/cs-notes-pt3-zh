## 第四讲 构造函数

## 构造函数(constructor)

- 用于初始化对象的特殊成员函数：
- 为对象分配空间；
- 对数据成员赋初值；
- 生成类对象时， 调用构造函数；

## 构造函数

构造函数是一种用于创建对象特殊的成员函数；

- 特点：
  - 构造函数是与类同名的成员函数
  - 可有任意类型的参数，但没有返回类型
  - 不能由程序员调用，创建对象时自动执行

- 作用：
  - 为对象分配空间；
  - 对数据成员赋初值；
  - 请求其他资源。

## 构造函数种类

- 默认构造函数
- 自定义构造函数
- 带默认参数的构造函数
- 重载构造函数

### 1.默认构造函数

```cpp
class Time
{
public:
    Time() { }
    void set_time(int, int, int );
    void show_time( );
private:
    int hour;
    int min;
    int sec;
};
```

```cpp
#include <iostream.h>
int main( )
{
    Time t1;
    t1.set_time( );
    t1.show_time( );

    Time t2;
    t2.show_time( );

    return 0;
}
```

初始化类对象的数据成员，在生成这个类的对象时自动调用。

### 2.自定义默认构造函数

#### 一般在构造函数内部设置成员变量的值

```cpp
class Time
{
public:
    Time();
    void set_time(int, int, int);
    void show_time();
private:
    int hour, min, sec;
};
Time::Time()
{
    hour=0; min=0; sec = 0;
}
```

```cpp
#include <iostream.h>
int main()
{
    Time t;
    t.show_time();
    return 0;
}
```

### 2.自定义构造函数

#### 一个类中只能有一个默认构造函数！

```cpp
class Time
{
public:
    Time();
    void set_time(int, int, int);
    void show_time();
private:
    int hour, min, sec;
};
Time::Time():hour(0)
{
    //hour=0;
    min=0; sec = 0;
}
```

1. 将变量hour置为0；
2. 这种初始化方法在构造函数执行以前进行。
3. 如何用这种方式初始化多个成员变量？

## 3.带参数的构造函数

带参数的构造函数可以在创建对象时，用具体数值初始化数据成员和各种数据元素。可方便实现对不同对象进行初始化。

构造函数的首部：

构造函数名（形参列表）；

定义对象的一般格式：

类名 对象名（实参列表）

## 带参数的构造函数

```cpp
class Time
{
public:
    Time(int h, int m, int s )
private:
    int hour;   int min;   int sec;
};
```

```cpp
#include <iostream.h>
int main( )
{
    Time t2(8, 15, 16);
    t2.show_time( );
    return 0;
}
```

> 用参数初始化列表对数据成员初始化

## 3.重载构造函数

类的定义中可以有多个构造函数，但必须各个构造函数的形参个数或类型不一样，即重载构造函数。

在创建对象时会根据实参的类型及个数自动选择相应的构造函数。

每个对象创建时只调用1个构造函数

## 重载构造函数（代码模拟）

```cpp
class Time
{
public:
    Time(): hour(0), min(0), sec(0)
    {
    }
    Time(int h, int m, int s)
    {
        hour=h,min=m,sec=s;
    }
    ......
private:
    int hour;   int min;  int sec;
};
```

```cpp
#include <iostream.h>
int main()
{
    Time t1;
    t1.set_time();
    t1.show_time();

    Time t2(8,15,16);
    t2.show_time();

    return 0;
}
```
