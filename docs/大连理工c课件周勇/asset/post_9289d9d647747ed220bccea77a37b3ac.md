## 静态类成员数据

- 静态数据成员的使用方法如下：

1）静态数据成员的定义与一般数据成员相似，  
   但前面要加上static关键词。

2）静态数据成员的初始化与一般数据成员不同，  
   静态数据成员初始化的格式如下：
   `<类型> <类名>::<静态数据成员> = <值>;`

3）在引用静态数据成员时采用格式：
   `<类名>::<静态数据成员>`
   `<对象名>.<静态数据成员>`

## 静态类成员数据

```cpp
class A
{
    static int var;    //在类的内部声明
    ...
};
int A::var = 1;        //在类的外部定义

A :: var              //通过类名访问
a.var                 //通过对象名访问
pA->var               //通过指向对象的指针访问
```

## 静态类成员数据

### ➢ 静态数据成员 vs 全局变量

静态数据成员是各对象之间的数据沟通的渠道，  
实现数据共享。

全局变量破坏了封装的原则，不符合面向对象程序的要求。

公用静态数据成员与全局变量的作用域不同  
静态数据成员的作用域只限于定义该类的作用域内

## 静态成员函数

- 静态成员函数的定义是在一般函数定义前加上static 关键字。
- 静态成员函数不与某个具体的对象相联系，它是属于类的。
- 调用静态成员函数的格式如下：

<类名>::<静态成员函数名>（<参数表>）；或<对象名>.<静态成员函数名>（<参数表>）；

## 代码模拟一统计对象的数目

```cpp
#include<iostream.h>
class Counter
{
	static int num ;
	public :
		Counter() { num++; }
		~Counter() { num--; }
		void setnum ( int i ) { num = i ; }
		void shownum() { cout << num << '\t' ; }
		static int get() { return num ; }
} ;
int Counter :: num = 0 ;
void main ()
{
	Counter a ; a.shownum()
	Counter b ; b.shownum()
	cout<<Counter::get() <<endl;
}
```

## 静态成员函数

- 静态成员函数只能访问静态数据成员、静态成员函数和类以外的函数和数据。
- 静态成员函数不能访问类中的非静态数据成员。
- 因为没有this指针。
- 静态数据成员和静态成员函数可由任意访问权限许可的函数访问。
- 私有静态成员函数不能由外界访问。
