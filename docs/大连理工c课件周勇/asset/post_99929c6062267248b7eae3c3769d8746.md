

## 六、复制构造函数

### 调用

复制构造函数只适用于初始化：

- 用一个对象显式初始化另一个对象。
- 函数值传递
- 生成临时对象

### 深复制与浅复制

- 默认复制构造函数可以完成对象的数据成员值简单的复制；
- 对象的数据涉及资源时，显式定义复制构造函数

## 七、数据的共享和保护

### const

定义常对象、常引用、常成员函数和常数据成员，实现数据保护

### static

静态成员属于整个类，提供一种同类对象的共享机制。

### friend

一个类的友元可以直接访问该类各种成员。
