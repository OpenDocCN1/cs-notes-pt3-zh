
## 自定义默认构造函数

一般在构造函数内部设置成员变量的值

```cpp
class Time
{
public:
    Time();
    void set_time(int, int, int);
    void show_time();
private:
    int hour, min, sec;
};

Time::Time()
{
    hour = min = sec = 0;
}
```

### 1. 默认构造函数

在构造函数处初始化成员

```cpp
class Time
{
public:
    Time();
    void set_time(int, int, int);
    void show_time();
private:
    int hour, min, sec;
};

Time::Time() : hour(0)
{
    // hour = 0;
    min = 0;
    sec = 0;
}
```

- 将变量 `hour` 置为 0；
- 这种初始化方法在构造函数执行以前进行。
- 如何用这种方式初始化多个成员变量？
- 有些成员必须这样初始化！

### 2. 有参构造函数

- 带参数的构造函数可以在创建对象时，用具体数值初始化数据成员和各种数据元素。可方便实现对不同对象进行初始化。
- 构造函数的首部：`构造函数名（形参列表）；`
- 定义对象的一般格式：`类名 对象名（实参列表）`

### 带参数的构造函数

> 用参数初始化列表对数据成员初始化

```cpp
class Time
{
public:
    Time(int h, int m, int s) : hour(h), min(m), sec(s) {}
private:
    int hour;
    int min;
    int sec;
};
```

```cpp
#include <iostream.h>

int main()
{
    Time t2(8, 15, 16);
    t2.show_time();
    return 0;
}
```

### 3. 重载构造函数

类的定义中可以有多个构造函数，但必须各个构造函数的形参个数或类型不一样，即重载构造函数。

在创建对象时会根据实参的类型及个数自动选择相应的构造函数。每个对象创建时只调用 1 个构造函数。

### 4. 带默认参数的构造函数

- 默认构造函数

- 带默认参数的构造函数

- 在调用构造函数时没有提供实参，可按默认参数值对对象进行初始化。
- 在构造函数中使用默认参数，可提供建立对象时的多种选择，相当于多个重载构造函数。

```cpp
class Time
{
public:
    Time() : hour(0), min(0), sec(0) {}
    Time(int h = 0, int m = 0, int s = 0) { hour = h; min = m; sec = s; }
private:
    int hour;
    int min;
    int sec;
};
```

### 构造函数使用说明

- 默认构造函数/缺省构造函数（default constructor）。系统自动生成的构造函数和无参构造函数属于默认构造函数。一个类中只能有一个默认构造函数。
- 如果在建立对象时用无参构造函数，注意定义对象的语句。
  `Time t1, t2(1,2,3); // OK`
  `Time t(); // error`
- 定义每个对象时只执行多个构造函数中的一个。
- 当构造函数中有默认参数时，注意函数重载的二义性。
