# 3)已有算法描述分析

Rogers 描述：

+   采用 x = x + StepX , y = y + StepY,

+   逼近点并不是直线的一个最好的逼近；

D.Foley描述： 可能引起积累误差

+   未分析直线端点不在象素点上的情况；

+   只给出 0—45°第一个八卦限的描述。

为避免引起积累误差， D.Foley 描述中采用

```
double dx =xe-xs;
double dy =ye-ys;
double k =dy/dx; // 直线之斜率 k
```
