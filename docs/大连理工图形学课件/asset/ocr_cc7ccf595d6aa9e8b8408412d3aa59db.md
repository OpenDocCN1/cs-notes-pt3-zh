# ## 2.2.4 中点圆整数算法 ——原理

+   - 中点圆算法 的半径是整数 ，而用于该算法 符号判别的变量 d （ 初值 d=1.25- radius） 采用浮点运算 ，会花费较多的时间 。
+   - 为了将其改造成整数计算 ，定义新变量：
+     D =d - 0.25
+   - 那么判别式 d<0等价于 D<-0.25。
+   - 在 D为整数情况 下 ， D<-0.25和 D<0等价
+   - 仍将 D写成 d （ 新的初值 d=1-radius） ，可得到中点圆整数算法。
