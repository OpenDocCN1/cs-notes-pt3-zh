# ## 2.2.5中点圆整数优化算法 — 原理

+   - 用 Δd修正 d

+   - 1) 选择 T点 （ \( x_p \leftarrow x_p + 1 \) ）：

+   - d的增量 （ 一次差分 ）：

+   - \(\Delta d_T = 2x_p + 3\)

+   - \(\Delta d\)的增量 （ 二次差分 ）：

+   - \(\Delta^2 d_T = 2(x_p + 1) + 3 - (2x_p + 3) = 2\)

+   - \(\Delta^2 d_B = 2(x_p + 1) - 2y_p + 5 - (2x_p - 2y_p + 5) = 2\)
