# 数据操纵语言

+   - 插入数据-单条数据

```
INSERT INTO table
[(column [, column...])]
VALUES
(value [, value...]);
```

+   - **INTO子句**
+     指定要插入数据的表名及属性列，属性列的顺序可与表定义中的顺序不一致。
+     **若未指定属性列**：表示要插入的是一条完整的元组，即属性列属性与表定义中的顺序一致；否则，**若指定部分属性列**，插入的元组在其余属性列上取空值

+   - **VALUES子句**
+     提供的值必须与INTO子句匹配
+     - 值的个数
+     - 值的类型
