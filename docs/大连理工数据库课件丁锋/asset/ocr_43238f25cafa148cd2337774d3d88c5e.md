# # 关系数据结构

+   - **认识关系**
+   
+     **关系和笛卡尔积**
+   
+     关系是笛卡尔积的有限子集。无限关系在数据库系统中是无意义的。
+   
+     由于笛卡尔积不满足交换律：
+   
+     \[
+     (d_1,d_2,\ldots,d_n) \ne (d_2,d_1,\ldots,d_n)
+     \]
+   
+     但关系满足交换律，即
+   
+     \[
+     (d_1,d_2,\ldots,d_i,d_j,\ldots,d_n)=(d_1,d_2,\ldots,d_j,d_i,\ldots,d_n) \quad (i,j=1,2,\ldots,n)
+     \]

+   - **解决方法：**为关系的每个列附加一个属性名以取消关系元组的有序性
