# # 数据依赖

+   - 函数依赖

✽ (Sno, Cno) → Grade 非平凡的函数依赖  
✽ (Sno, Cno) → Cno 平凡的函数依赖

+   - 形式化定义  
+     X→Y,但Y ⊆ X则称X→Y是平凡的函数依赖。  
+     X→Y,但Y ⊈ X则称X→Y是非平凡的函数依赖。

+   - 对于任一关系模式，平凡函数依赖都是必然成立，它不反映新的语义。因此若不特别声明，总是讨论非平凡函数依赖。
