# # 视图

+   - 查询视图
+     - 从用户角度：查询视图与查询基本表相同
+     - DBMS实现视图查询的方法
+       - 实体化视图（View Materialization）
+         - 有效性检查：检查所查询的视图是否存在
+         - 执行视图定义，将视图临时实体化，生成临时表
+         - 查询视图转换为查询临时表
+         - 查询完毕删除被实体化的视图(临时表)
+       - 视图消解法（View Resolution）
+         - 进行有效性检查，检查查询的表、视图等是否存在。如果存在，则从数据字典中取出视图的定义
+         - 把视图定义中的子查询与用户的查询结合起来，转换成等价的对基本表的查询
+         - 执行修正后的查询
