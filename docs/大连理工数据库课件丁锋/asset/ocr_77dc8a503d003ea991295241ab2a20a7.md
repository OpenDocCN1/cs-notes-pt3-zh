# # 逻辑模型

+   - 层次模型
+     - 多对多联系在层次模型中如何表达
+       - 冗余节点
+       - 虚拟节点
+     - 层次模型的特点
+       - 优点
+         - 数据结构简单清晰
+         - 查询效率性能好
+         - 良好的完整性支持
+       - 缺点
+         - 对于非层次性联系（如多对多联系）表示麻烦
+         - 一个节点具有多个双亲时，表示麻烦，对插入、删除的限制较多，程序编写复杂
+         - 查询子女节点必须通过双亲节点
+         - 结构严谨、层次命令程序化
