# 嵌套查询（子查询）

+   - 例：将计算机科学全体学生的成绩置零。

```
UPDATE SC
SET Grade=0
WHERE exists (SELECT *
              FROM Student
              WHERE Student.Sno = SC.Sno
                    AND student.sdept='CS');
```

+   - 除了使用在嵌套式SELECT语句之中外，子查询还可以被放在 CREATE VIEW 语句中、CREATE TABLE 语句、UPDATE 语句、INSERT 语句和 DELETE 语句中。
