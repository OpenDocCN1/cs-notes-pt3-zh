# # 嵌套查询（子查询）

+   - 练习：查询其他系中比信息系所有学生年龄都小的学生姓名及年龄

```
```sql
SELECT Sname, Sage
FROM Student
WHERE Sage < ALL(SELECT Sage FROM Student
                WHERE Sdept= ' IS ')
AND Sdept <> ' IS ';
```
```

```
```sql
SELECT Sname, Sage
FROM Student
WHERE Sage <(SELECT MIN(Sage) FROM Student
                WHERE Sdept= ' IS ')
AND Sdept <> ' IS ';
```
