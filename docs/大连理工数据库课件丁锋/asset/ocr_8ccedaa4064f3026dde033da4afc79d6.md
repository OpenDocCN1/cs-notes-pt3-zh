# # DBMS的主要功能

+   - 数据定义功能  
+     提供数据定义语言(DDL)，定义数据库中的数据对象

+   - 数据组织、存储和管理  
+     提高存储空间利用率和方便存取，提供多种存取方法来提高存取效率

+   - 数据操纵功能  
+     提供数据操纵语言(DML)，实现对数据库的基本操作(查询、插入、删除和修改)

+   - 数据库的事务管理和运行管理  
+     保证数据的安全性、完整性，多用户对数据的并发使用，发生故障后的系统恢复

+   - 数据库的建立和维护功能  
+     数据库数据批量装载，数据库转储，介质故障恢复，数据库的重组织，性能监视等
