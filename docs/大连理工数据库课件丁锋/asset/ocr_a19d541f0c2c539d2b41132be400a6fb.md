+   - 相比于S-D，S-C，当前模式（S、D及S-C）具有如下优点：
+       - 如果一个系刚好成立但还没有招生
+           - 那么可以将系的信息放入模式D的实例中，而不必理会此系中有无学生。
+       - 若插入该系的信息（系名，系负责人）
+           - 不必理会学生信息如何表达
+       - 若某个系的学生全部毕业了，但系还要保留
+           - 这样可以删除模式S的实例中所有学生的记录，但模式D的实例中系的信息仍将存在。
+       - 避免了对每条学生记录都存储系名，系领导的信息，进一步减少了数据冗余。
+       - 另外，换系领导后，不必对所有学生的记录都要更新，减小了更新的复杂度。
