# # 数据库系统的组成

+   - 人员组成-数据库管理员(DBA)
+       - 决定数据库中的信息内容和结构
+       - 决定数据库的存储结构和存取策略
+       - 定义数据的安全性要求和完整性约束条件
+       - 数据库的改进和重组
+           - 性能监控和调优
+           - 数据重组
+       - 数据库重构

+   - 监控数据库的使用和运行
+       - 周期性转储数据库
+           - 数据文件
+           - 日志文件
+       - 系统故障恢复
+       - 介质故障恢复
+       - 监视审计文件
