# # 关系数据结构

+   - **域：**
+   具有相同数据类型的值的集合

+   - **笛卡儿积：**
+   给定一组域$D_1,D_2,...,D_n$ (可相同)，它们的笛卡儿积为：
+   
+   $D_1×D_2×...×D_n=\{(d_1,d_2,...,d_n)|d_i\in D_i,i=1,2,...,n\}$
+   其中每一个元素$(d_1,d_2,...,d_n)$叫做一个n元组。元素中的每个值$d_i$叫做一个分量。(所有域的所有取值的一个组合,不能重复)

+   - **若 $D_i$ 为有限集, 其基数为 $m_i$, 则 $D_1×D_2×...×D_n$ 的基数 $M$ 为：**
+   
+   $M = \prod_{i=1}^n m_i$
