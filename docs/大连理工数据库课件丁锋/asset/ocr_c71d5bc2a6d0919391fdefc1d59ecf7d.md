# # 概念模型

+   多个实体型间的一对多联系  
+   若实体集E1， E2， ...， En存在联系，对于实体集Ei（j=1， 2， ...， i-1， i+1， ...， n）中的给定实体，最多只和Ei中的一个实体相联系，则我们说Ei与E1， E2， ...， E<sub>i-1</sub>， E<sub>i+1</sub>， ...， En之间的联系是一对多的。

+   实例：  
+   课程、教师与参考书三个实体型，如果一门课程可以有若干个教师讲授，使用若干本参考书，每一个教师只讲授一门课程，每一本参考书只供一门课程使用，课程与教师、参考书之间的联系是一对多的
