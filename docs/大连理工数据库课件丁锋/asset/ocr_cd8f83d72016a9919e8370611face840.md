# SQL数据定义语言

+   - 例：建立一个“学生选课”表SC，它由学号Sno、课程号Cno、修课成绩Grade组成，其中(Sno, Cno)为主码。

```
CREATE TABLE SC(
        Sno CHAR(7) ,
        Cno CHAR(4) ,
        Grade int,
        Primary key (Sno, Cno),
        Foreign key (Sno) References student(Sno),
        Foreign key (Cno) References Course(Cno));
```
