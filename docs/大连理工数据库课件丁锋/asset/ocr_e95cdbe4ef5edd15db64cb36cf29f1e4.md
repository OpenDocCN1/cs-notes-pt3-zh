# # 关系数据结构

+   - 关系：
+     \( D_1 \times D_2 \times \dots \times D_n \) 的子集叫做在域 \( D_1, D_2, \dots, D_n \) 上的关系。
+     记为：\( R(D_1, D_2, \dots, D_n) \)
+     其中：
+     - R — 表示关系名
+     - n — 称为关系的目或度，1 单元关系，2 二元关系
+     - t — 表示关系中的元组。

+   - 元组：
+     关系是笛卡尔积的有限子集，所以是一个二维表，表的每行对应一个元组，每列对应一个域。

+   - 属性：
+     域可以相同，为了区分域，必须对每列起一个名字，称为属性（Attribute）。
