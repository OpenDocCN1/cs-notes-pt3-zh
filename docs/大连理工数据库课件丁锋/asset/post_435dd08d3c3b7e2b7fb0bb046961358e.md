
## 关系代数

### 传统集合运算-差

例：

R：

| A | B | C |
|---|---|---|
| a1 | b1 | c1 |
| a1 | b2 | c2 |
| a2 | b2 | c1 |

S：

| A | B | C |
|---|---|---|
| a1 | b2 | c2 |
| a1 | b3 | c2 |
| a2 | b2 | c1 |

R-S：

| A | B | C |
|---|---|---|
| a1 | b1 | c1 |

### 传统集合运算-交

关系R和关系S的交R∩S仍为n目关系，由既属于R又属于S的元组组成。

R∩S = { t | t ∈ R ∧ t ∈ S }

R∩S = R - (R - S)

例：

R：

| A | B | C |
|---|---|---|
| a1 | b1 | c1 |
| a1 | b2 | c2 |
| a2 | b2 | c1 |

S：

| A | B | C |
|---|---|---|
| a1 | b2 | c2 |
| a1 | b3 | c2 |
| a2 | b2 | c1 |

R∩S：

| A | B | C |
|---|---|---|
| a1 | b2 | c2 |
| a2 | b2 | c1 |

### 传统集合运算-笛卡尔积

设 R 为 n 目关系，k1 个元组；S 为 m 目关系，k2 个元组。则关系 R 和关系 S 的笛卡尔积 R×S 有：

- 列：（n+m）列的元组的集合
  - 元组的前 n 列是关系 R 的一个元组
  - 后 m 列是关系 S 的一个元组
- 行：k1×k2 个元组

R×S = { t_r t_s | t_r ∈ R ∧ t_s ∈ S }

### 专门的关系运算-选择

选择运算给出满足给定谓词（条件）的元组。

用小写希腊字母 σ 来表示选择运算，而将谓词写作 σ 的下标，并在 σ 后的括号中给出作为参数的关系。

例：找出成绩大于等于90分的成绩记录

σ_{Grade>=90}(SC)

通常允许在选择谓词中进行比较，使用的比较运算符是 =、≠、<、≤、> 和 ≥ 等。另外，还可以用连词 and（∧）和 or（∨）将多个谓词合并成一个较大的谓词。

例如：查询成绩大于等于60但小于75分的成绩记录

σ_{Grade>=60 ∧ Grade<75}(SC)

一般形式：

σ_F(R) = { t | t ∈ R ∧ F(t) = '真' }

F：选择条件，是一个逻辑表达式，基本形式为：

[¬(] X₁ θ Y₁ [)] [φ [¬(] X₂ θ Y₂ [)]]...

- θ：比较运算符（>, ≥, <, ≤, = 或 <>）
- X₁, Y₁ 等：属性名、常量、简单函数；属性名也可以用它的序号来代替；
- φ：逻辑运算符（∧ 或 ∨）
- [ ]：表示任选项
- ...：表示上述格式可以重复下去

### 专门的关系运算-投影

投影运算是一元运算，它返回作为参数的那个关系的部分属性构成的新关系。由于关系是一个集合，所以在结果关系中所有重复的行均被去除。

投影运算用希腊字母 Π 表示，所有希望在结果关系中出现的属性作为 Π 的下标，而作为参数的关系跟随在 Π 后的括号中。

例：对于成绩记录 SC，假设我们只想列出所有学生的学号和所选课的课程编号，而不关心成绩的具体值，投影运算便可以产生这样的结果。上述表示为：

Π_{Sno,Cno}(SC)

查询学生的姓名和所在系：

Π_{Sname, Sdept}(Student) 或 Π_{2,5}(Student)

查询学生关系 Student 中都有哪些系：

Π_{Sdept}(Student)

### 关系运算的组合

关系运算的结果仍然是一个关系。可以把多个关系代数运算组合成一个关系代数表达式。

问：以下的关系运算是什么含义？

Π_{Sno,Cno}(σ_{Grade≥60 ∧ Grade<75}(SC))

### 专门的关系运算-连接

从两个关系的笛卡儿积中选取属性间满足一定条件的元组的操作。

常用的连接：

- θ 连接：r ⋈_θ s = σ_θ(r × s)。θ 为一个条件。R ⋈_θ S = { t_r t_s | t_r ∈ R ∧ t_s ∈ S ∧ t_r[A] θ t_s[B] }
- 等值连接：当 θ 条件为“=”时的 θ 连接为等值连接。
- 自然连接：在等值连接中，如果相比较的分量是相同的属性组，并且在结果中去掉了重复的属性列，则称为自然连接。

自然连接是二元运算，可以将某些选择运算和笛卡儿积运算合并为一个运算，用“连接”符号 ⋈ 来表示：即 r ⋈ s。

自然连接运算首先形成它的两个参数的笛卡儿积；然后在笛卡儿积的结果上，基于两个参数的关系模式中都出现的属性进行属性相等的选择运算；最后还要去除重复属性，即结果的关系模式中相同的属性在连接结果中只保留一个。

自然连接特性：

- 关系代数表达式 `r ⋈ s` 与 `s ⋈ r` 等价，`(r ⋈ s) ⋈ p` 与 `r ⋈ (s ⋈ p)` 等价，也就是说自然连接运算满足交换律和结合律。
- 设 `r(R)` 和 `s(S)` 是没有任何公共属性的关系，即 `R∩S=∅`，那么 `r ⋈ s = r×s`。

一般的连接操作是从行的角度进行运算。
