# 基本概念

- 数据库（DB）
  - 存放数据的仓库
  - 长期存储在计算机内，有组织的，可共享的大量数据的集合
- 数据库系统（DBS）
  - 在计算机系统中引入数据库后的系统，一般由数据库、数据库管理系统（及其开发工具）、应用系统、数据库管理员构成
- 数据库管理系统（DBMS）
  - 用于科学地组织和存储数据，高效地获取和维护数据的系统软件
