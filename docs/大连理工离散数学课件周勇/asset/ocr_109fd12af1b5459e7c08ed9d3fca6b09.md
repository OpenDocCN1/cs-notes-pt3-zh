# 左陪集的定义与性质

设 $G$ 是群，$H$ 是 $G$ 的子群，$H$ 的**左陪集**，即

$$aH=\{ah\mid h\in H\},\quad a\in G$$

关于左陪集有下述性质：

+   1. $eH=H$
+   
+   2. $\forall a\in G,\quad a\in aH$
+   
+   3. $\forall a,b\in G,\quad a\in bH\Longleftrightarrow b^{-1}a\in H\Longleftrightarrow aH=bH$
+   
+   4. 若在 $G$ 上定义二元关系 $R$，
+      $$\forall a,b\in G,\quad \langle a,b\rangle\in R\Longleftrightarrow b^{-1}a\in H$$
+      则 $R$ 是 $G$ 上的等价关系，且 $[a]_R=aH$。
+   
+   5. $\forall a\in G,\quad H\approx aH$
