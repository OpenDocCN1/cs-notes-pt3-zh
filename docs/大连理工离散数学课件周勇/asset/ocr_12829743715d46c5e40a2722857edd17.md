# 函数的扩大和缩小

例：设 $X_1=\{0,1\},X_2=\{0,1,2\},Y=\{a,b,c,d\}$。定义从 $X_1^2$ 到 $Y$ 的函数为：

$f=\{\langle 0,0,a\rangle,\langle 0,1,b\rangle,\langle 1,0,c\rangle,\langle 1,1,b\rangle\}$。

$g=f\cup\{\langle 0,2,a\rangle,\langle 2,2,d\rangle\}$ 是从 $X_1^2\cup\{\langle 0,2\rangle,\langle 2,2\rangle\}$ 到 $Y$ 的函数。

于是 $f=g/X_1^2$，因此 $f$ 是 $g$ 在 $X_1^2$ 上的缩小（或称限制），$g$ 是 $f$ 到 $X_1^2\cup\{\langle 0,2\rangle,\langle 2,2\rangle\}$ 上的扩大（或称延拓）。
