# # 一、关系的合成

例：给定集合\(X=\{1,2,3,4\}\)，\(Y=\{2,3,4\}\)和\(Z=\{1,2,3\}\)。设\(R\)是从\(X\)到\(Y\)的关系，并且\(S\)是从\(Y\)到\(Z\)的关系，并且\(R\)和\(S\)给定成：
\(R = \{\langle x, y \rangle \mid x + y = 6\} = \{\langle 2,4\rangle,\langle 3,3\rangle,\langle 4,2\rangle\}\)
\(S = \{\langle y, z \rangle \mid y - z = 1\} = \{\langle 2,1\rangle,\langle 3,2\rangle,\langle 4,3\rangle\}\)

试求\(R\)和\(S\)的合成关系，并画出合成关系图给出合成关系的关系矩阵。

解：找出所有这样的偶对 \(\langle x, z \rangle\) ——对于某一个\(y\)来说，能有\(x+y=6\)和\(y-z=1\)，由上述的偶对就可构成从\(X\)到\(Z\)的关系\(R \circ S\)。

\(R \circ S = \{\langle 2,3\rangle,\langle 3,2\rangle,\langle 4,1\rangle\}\)
