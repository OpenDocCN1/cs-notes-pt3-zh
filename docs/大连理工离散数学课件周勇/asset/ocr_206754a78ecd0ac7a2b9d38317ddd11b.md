# 3.2 集合的运算

# 一、相交运算

定义：由集合 $A$ 和 $B$ 的所有公共元素所组成的集合，称为集合 $A$ 和 $B$ 的交集。记作 $A\cap B$

$$A\cap B=\{x\mid x\in A\land x\in B\}$$

例如：设 $A=\{a,b,c,d\}$，$B=\{d,f,a\}$，$C=\{e,f,g\}$

+   则
+   - $A\cap B=\{a,d\}$
+   - $B\cap C=\{f\}$
+   - $A\cap C=\varnothing$

可以看出

$$A\cap B\subseteq A,\ A\cap B\subseteq B$$
