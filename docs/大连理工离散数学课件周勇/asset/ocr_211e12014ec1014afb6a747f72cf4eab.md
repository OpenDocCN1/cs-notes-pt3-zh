# # 前置式表示

前置式可交换的二元运算\( f : X \times X \to X \)可表达成：
对于每一个\( x, y \in X \) 有\( f\langle x, y \rangle = f\langle y, x \rangle\)；可结合的二元运算可表达成：对于每一个\( x, y, z \in X \)
有\( f\langle f\langle x, y \rangle, z \rangle = f\langle x, f\langle y, z \rangle \rangle\)；对于运算\( g : X \times X \to X \)
是可分配的二元运算，\( f : X \times X \to X \)可表达成\( f\langle x, g\langle y, z \rangle \rangle = g\langle f\langle x, y \rangle, f\langle x, z \rangle \rangle\)。
