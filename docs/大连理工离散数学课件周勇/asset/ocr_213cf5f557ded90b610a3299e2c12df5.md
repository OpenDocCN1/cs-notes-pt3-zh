# # 四、关系的闭包运算

（ 2 ）先证明r(R) 是对称的。

由于 R 是 A 上的对称关系，所以有 R=R<sup>-1</sup> ，同时 I<sub>A</sub>=I<sub>A</sub><sup>-1</sup> ，从而可得

r(R)<sup>-1</sup>=(R∪I<sub>A</sub>)<sup>-1</sup>=R<sup>-1</sup>∪I<sub>A</sub><sup>-1</sup>=R∪I<sub>A</sub>=r(R)

因此，r(R) 是对称的。

之后证明 t(R) 是对称的，为了证明这个命题，需要证明若 R 是对称的，

则对于任意n∈N，都有 R<sup>n</sup> 是对称的。应用归纳法，

若 n=1，若 R<sup>1</sup>=R 是对称的。

假设 R<sup>n</sup> 是对称的，则对于任意⟨x,y⟩，

⟨x,y⟩∈R<sup>n+1</sup>⇔∃t(⟨x,t⟩∈R<sup>n</sup>∧⟨t,y⟩∈R)⇒∃t(⟨t,x⟩∈R<sup>n</sup>∧⟨y,t⟩∈R)⇒⟨y,x⟩∈R<sup>n+1</sup>

因此，R<sup>n+1</sup> 是对称的。

综上所述，对于任意n∈N，都有 R<sup>n</sup> 是对称的。

下面证明 t(R) 是对称的。任取⟨x,y⟩，

⟨x,y⟩∈t(R)⇒∃s(⟨x,y⟩∈R<sup>s</sup>)⇒∃s(⟨y,x⟩∈R<sup>s</sup>)⇒⟨y,x⟩∈t(R)

因此，t(R) 是对称的。
