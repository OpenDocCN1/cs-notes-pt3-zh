# 3.3包含排斥原理

定理3.4-1：设\(A_1,A_2\)是有限集合，\(|A_1|,|A_2|\)为其基数，则

\(|A_1 \cup A_2| = |A_1| + |A_2| - |A_1 \cap A_2|\)

证:(1)当\(A_1\)和\(A_2\)不相交，即\(A_1 \cap A_2 = \emptyset\)时，

\(|A_1 \cup A_2| = |A_1| + |A_2|\)

\(= |A_1| + |A_2| - |A_1 \cap A_2|\)

(2)当\(A_1 \cap A_2 \neq \emptyset\)，那么

\(|A_1| = |A_1 \cap \sim A_2| + |A_1 \cap A_2|\)

\(|A_2| = |\sim A_1 \cap A_2| + |A_1 \cap A_2|\)

所以\(|A_1| + |A_2| = |A_1 \cap \sim A_2| + |\sim A_1 \cap A_2| + 2|A_1 \cap A_2|\)

由于\(|A_1 \cap \sim A_2| + |\sim A_1 \cap A_2| + |A_1 \cap A_2| = |A_1 \cup A_2|\)

因此\(|A_1 \cup A_2| = |A_1| + |A_2| - |A_1 \cap A_2|\)
