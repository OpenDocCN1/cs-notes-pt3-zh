# 离散数学

# 练习1

1. 设 $A=\{1,2,3\}$，$R=\{\langle x,y\rangle\mid x,y\in A\ 且\ x+2y\le 6\}$，
   $S=\{\langle1,2\rangle,\langle1,3\rangle,\langle2,2\rangle\}$，

求：

+   1. $R$ 的集合表达式
+   2. $R^{-1}$
+   3. $\operatorname{dom} R$，$\operatorname{ran} R$，$\operatorname{fld} R$
+   4. $R\circ S$，$R^3$
+   5. $r(R)$，$s(R)$，$t(R)$
