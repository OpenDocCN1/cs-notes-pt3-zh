# 主合取范式

• 假定有 $P$、$Q$、$R$ 三个变元

|  |  |  |  |
|---|---:|---:|---|
| $P\lor Q\lor R$ | $000$ | 0 | $M_0$ |
| $P\lor Q\lor \neg R$ | $001$ | 1 | $M_1$ |
| $P\lor \neg Q\lor R$ | $010$ | 2 | $M_2$ |
| $P\lor \neg Q\lor \neg R$ | $011$ | 3 | $M_3$ |
| $\neg P\lor Q\lor R$ | $100$ | 4 | $M_4$ |
| $\neg P\lor Q\lor \neg R$ | $101$ | 5 | $M_5$ |
| $\neg P\lor \neg Q\lor R$ | $110$ | 6 | $M_6$ |
| $\neg P\lor \neg Q\lor \neg R$ | $111$ | 7 | $M_7$ |
