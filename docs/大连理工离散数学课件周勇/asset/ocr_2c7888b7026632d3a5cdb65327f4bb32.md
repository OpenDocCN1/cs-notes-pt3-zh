+   - 定理7.2.6 给定独异点\(<M,\ \odot>\)，

+   - 则存在\(T\subseteq M^M\)，使\(<M,\ \odot>\cong <T,\ \bigcirc>\)。

+   - 本定理表明，一个独异点可与复合运算下的一个函数独异点同构。

+   - 证明：取定理7.2.5中的\(ge(MM)^{M}\)，则\(g(M)\)是\(M\)在同态映射\(g\)作用下的像，

+   - 显然\(g(M)\subseteq M^M\)，且\(g\)是\(<M,\ \odot>\)

+   - 到\(<g(M),\ \bigcirc>\)的满同态，又因为\(<M,\ \odot>\)为独异点，故其运算表中的任两行和任两列均不相同，因此\(g\)又是双射，故\(g\)是从\(<M,\ \odot>\)

+   - 到\(<g(M),\ \bigcirc>\)的同构映射。取\(T=g(M)\)，则有\(<M,\ \odot>\cong <T,\ \bigcirc>\)。
