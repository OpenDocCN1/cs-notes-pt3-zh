# 等价关系与集合的划分

例：令 $R$ 是整数集合 $\mathbb{Z}$ 中的“模3同余”关系，$R$ 可给定成

$R=\{\langle x,y\rangle\mid x\in\mathbb{Z}\land y\in\mathbb{Z}\land (x-y)\text{被3整除}\}$

求 $\mathbb{Z}$ 的元素所生成的 $R$ 等价类。

解：等价类是

$[0]_R=\{\cdots,-6,-3,0,3,6,\cdots\}$

$[1]_R=\{\cdots,-5,-2,1,4,7,\cdots\}$

$[2]_R=\{\cdots,-4,-1,2,5,8,\cdots\}$

$\mathbb{Z}/R=\{[0]_R,[1]_R,[2]_R\}$

可以看出，等价关系可以造成集合的一个划分。
