# # 证明(1)中的交换律，(2)中的零元

+   (1) 任取\(<a_1,b_1>, <a_2,b_2>\in V_1 \times V_2\)，
+   \(<a_1,b_1>\cdot<a_2,b_2> = <a_1\circ a_2, b_1*b_2> = <a_2\circ a_1, b_2*b_1> = <a_2,b_2>\cdot<a_1,b_1>\)

+   (2)任取\(<a,b>\in V_1 \times V_2\)，
+   \(<a,b>\cdot<\theta_1,\theta_2> = <a\circ\theta_1, b*\theta_2> = <\theta_1,\theta_2>\)
+   \(<\theta_1,\theta_2>\cdot<a,b> = <\theta_1\circ a, \theta_2*b> = <\theta_1,\theta_2>\)

+   (3)任取\(<a,b>\in V_1 \times V_2\)，使得
+   \(<x,y>\cdot<a,b> = <e_1,e_2>\Rightarrow x\circ a=e_1\land y*b=e_2\Rightarrow a=x^{-1}\land b=y^{-1}\)
+   \(\Rightarrow<a,b>=<x^{-1},y^{-1}>\)
