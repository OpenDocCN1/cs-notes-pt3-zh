# 四、关系的闭包运算

例: 给定集合 X={a,b,c}, R和S是X中的关系, 给定

```
R = {(a,b),(a,c),(c,b)}
S = {(a,b),(b,c),(c,a)}
```

试求出 t(R),t(S), 并画出关系图

```
t(R) = R¹ ∪ R² ∪ R³ ∪… = R

t(S) = S¹ ∪ S² ∪ S³ ∪… = S¹ ∪ S² ∪ S³
```

```
{(a,b),(b,c),(c,a),(a,c),(b,a),(c,b),(a,a),(b,b),(c,c)}
```
