# # 量词分配律

+   - 全称量词对V，存在量词对∧ 不满足分配律。
+   例：个体域是人的集合。
+   
+   A(x)：x是女人。 B(x)：x是男人。
+   
+   (∀x)(A(x) ∨ B(x)) 为真；
+   (∀x)A(x) ∨ (∀x)B(x) 为假。
+   
+   (∃x)(A(x) ∧ B(x)) 为假。
+   (∃x)A(x) ∧ (∃x)B(x) 为真。

+   - 仅满足：
+   (∃x)(A(x) ∧ B(x)) ⇒ (∃x)A(x) ∧ (∃x)B(x)
+   (∀x)A(x) ∨ (∀x)B(x) ⇒ (∀x)(A(x) ∨ B(x))

+   - 为正确理解上面第二式。设
+   - A(x)：x会用左手拿筷子吃饭
+   - B(x)：x会用右手拿筷子吃饭
