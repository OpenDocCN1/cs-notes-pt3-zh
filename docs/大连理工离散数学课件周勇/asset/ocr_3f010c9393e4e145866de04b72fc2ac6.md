# # 函数的扩大和缩小

定义：给定函数\(f: X \to Y\)，且有\(A \subseteq X\)。

(1) 试构成一个从\(A\)到\(Y\)的函数

\(g = f \cap (A \times Y)\)

通常称\(g\)是函数\(f\)的**缩小**，并记作\(f|A\)。

(2) 如果\(g\)是\(f\)的缩小，则称\(f\)是\(g\)的**扩大**。

从定义可以看出，函数\(f|A: A \to Y\)的域是集合\(A\)，而函数\(f\)的域则是集合\(X\)。\(f|A\)和\(f\)的陪域均是集合\(Y\)。于是若\(g\)是\(f\)的缩小，则应有

\(\text{dom}g \subseteq \text{dom}f \text{ 且 } g \subseteq f\)

并且对于任何\(x \in \text{dom}g\)都有\(g(x) = (f|A)(x) = f(x)\)。
