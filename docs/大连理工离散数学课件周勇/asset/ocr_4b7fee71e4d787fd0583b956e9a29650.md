# # 路径和回路

# ## 注意：

+   • 单独一个结点 \(v\) 也是路径，它是长度为 0 的基本路径。  
+     因此，任何结点到其自身总存在路径。

+   • 在无向图中，若从结点 \(v\) 至结点 \(v'\) 存在路径，则从 \(v'\) 至 \(v\) 必存在路径。  
+     而在有向图中，从结点 \(v\) 至 \(v'\) 结点存在路径，而从 \(v'\) 至 \(v\) 却不一定存在路径。

设路径 \(P_1 = v_0 e_1 v_1 \cdots v_{n-1} e_n v_n\) 和 \(P_1 = v_n e'_1 v'_1 \cdots v'_{m-1} e'_m v'_m\)，  
用 \(P_1 P_2\) 记路径 \(v_0 e_1 v_1 \cdots v_{n-1} e_n v_n e'_1 v'_1 \cdots v'_{m-1} e'_m v'_m\)
