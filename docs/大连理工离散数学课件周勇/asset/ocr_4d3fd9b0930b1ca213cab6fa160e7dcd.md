# # 实例

+   考虑集合\(A=\{a_1,a_2,a_3\}\)，\(B=\{b_1,b_2,b_3,b_4\}\)，\(C=\{c_1,c_2,c_3\}\)。令  
+   \(f=\{<a_1,b_1>,<a_2,b_2>,<a_3,b_3>\}\)  
+   \(g=\{<b_1,c_1>,<b_2,c_2>,<b_3,c_3>,<b_4,c_3>\}\)  
+   \(g \circ f=\{<a_1,c_1>,<a_2,c_2>,<a_3,c_3>\}\)

+   那么\(f:A \rightarrow B\)和\(g \circ f:A \rightarrow C\)是单射的，但\(g:B \rightarrow C\)不是单射的。

+   考虑集合\(A=\{a_1,a_2,a_3\}\)，\(B=\{b_1,b_2,b_3\}\)，\(C=\{c_1,c_2\}\)。令  
+   \(f=\{<a_1,b_1>,<a_2,b_2>,<a_3,b_2>\}\)  
+   \(g=\{<b_1,c_1>,<b_2,c_2>,<b_3,c_2>\}\)  
+   \(g \circ f=\{<a_1,c_1>,<a_2,c_2>,<a_3,c_2>\}\)

+   那么\(g:B \rightarrow C\)和\(g \circ f:A \rightarrow C\)是满射的，但\(f:A \rightarrow B\)不是满射的。
