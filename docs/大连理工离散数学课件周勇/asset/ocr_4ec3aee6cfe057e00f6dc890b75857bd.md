# # n元运算

定义： 设是\(X\)一个集合，\(f\)是一个从\(X^n \rightarrow X\) 的映射。  
称\(f\)为\(X\)中的\(n\)元运算，整数\(n\)称为运算的阶。

\(X\)中的每个元素称为\(X\)中的零元运算。对于\(n=1\)来说，  
\(f: X \rightarrow X\)的映射，称为一元运算；对于\(n=2\)来说，\(f: X^2 \rightarrow X\)，称为二元运算。这里主要讨论一元运算和二元运算。一般来说，这种运算给每一个\(n\)重序元或序偶能指定\(X\)中的唯一的元素，当然这些\(n\)重序元或序偶的成员\(x\)也属于集合\(X\)。
