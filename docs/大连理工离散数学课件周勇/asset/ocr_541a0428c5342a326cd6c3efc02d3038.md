+   - 例7.2.3 给定独异点<**R**, **+**, **0**>和<**R**, **×**, **1**>，其中**R**是实数集合，**+**和**×**是一般加法和乘法，**0**和**1**分别为它们的幺元。令**f**∈**R**<sup>**R**</sup>：

+   - **f(x)**=**a**<sup>**x**</sup> 其中**a**>**0**, **x**∈**R**

+   - 问**f**是否为从<**R**, **+**, **0**>到<**R**, **×**, **1**>的独异点同态映射？

+   - 证明：因为对任何**x**,**y**∈**R**,

+   - **f(x+y)**=**a**<sup>**x+y**</sup>=**f(x)**×**f(y)**

+   - / *满足运算的象等于象的运算* /

+   - 又**f(0)**=**a**<sup>**0**</sup>=**1** /***1**是**×**的幺元* /

+   - 即**f**是独异点同态映射。
