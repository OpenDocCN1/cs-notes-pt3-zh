# # 永真蕴含式

试证明\((P \rightarrow Q) \land (Q \rightarrow R) \Rightarrow P \rightarrow R\)

证明1: 假定\((P \rightarrow Q) \land (Q \rightarrow R)\)的真值为\(T\)，那么\((P \rightarrow Q)\)为\(T\)并且\((Q \rightarrow R)\)为\(T\)，分两种情况讨论：

+   (1) 若\(P\)为\(T\)，则\(Q\)必然为\(T\)，因而\(R\)为\(T\)，于是有\((P \rightarrow R)\)为\(T\)；

+   (2) 若\(P\)为\(F\)，则此时无论\(R\)为\(T\)或\(F\)，都有\((P \rightarrow R)\)为\(T\)。

综上所述，假定前提\((P \rightarrow Q) \land (Q \rightarrow R)\)的真值为\(T\)，推出结论\(P \rightarrow R\)的真值为\(T\)，蕴含式成立。

证明2: 假定\(P \rightarrow R\)的真值为\(F\)，那么由定义可知\(P\)为\(T\)，并且\(R\)为\(F\)，分两种情况讨论：

+   (1) 若\(Q\)为\(T\)，则\((Q \rightarrow R)\)为\(F\)，于是有\((P \rightarrow Q) \land (Q \rightarrow R)\)为\(F\)；

+   (2) 若\(Q\)为\(F\)，则\((P \rightarrow Q)\)为\(F\)，于是有\((P \rightarrow Q) \land (Q \rightarrow R)\)为\(F\)。

综上所述，假定结论\(P \rightarrow R\)的真值为\(F\)，推出前提\((P \rightarrow Q) \land (Q \rightarrow R)\)的真值为\(F\)，蕴含式成立。
