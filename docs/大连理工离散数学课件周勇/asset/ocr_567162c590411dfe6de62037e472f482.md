# 证明(4)

(4) 证明思路：用归纳法证明 ∀_a_<sub>1</sub>, _a_<sub>2</sub>, ... , _a<sub>n</sub>_ 有

\((\sum_{i=1}^n a_i)b_j = \sum_{i=1}^n a_i b_j\)

同理可证，∀_b_<sub>1</sub>, _b_<sub>2</sub>, ... , _b<sub>m</sub>_ 有

\(a_i(\sum_{j=1}^m b_j) = \sum_{j=1}^m a_i b_j\)

于是 \((\sum_{i=1}^n a_i)(\sum_{j=1}^m b_j) = \sum_{i=1}^n a_i(\sum_{j=1}^m b_j) = \sum_{i=1}^n \sum_{j=1}^m a_i b_j\)
