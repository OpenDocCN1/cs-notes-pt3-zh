# 反证法

+   - **F规则**：如果前提集合和¬S不相容，那么可以从前提集合中推出S。
+   - **例**：证明¬(P∧Q)是¬P∧¬Q的有效结论。
+   - **解**：把¬ ¬(P∧Q)作为假设前提，并证明该假设前提导致一个永假式。
+   
+     – {1} (1)　　¬ ¬(P∧Q)　　　 P规则（假设前提）  
+     – {1} (2)　　P∧Q　　　　　 T规则，(1)和E₁₀  
+     – {1} (3)　　P　　　　　　 T规则，(2)和I₁  
+     – {4} (4)　　¬P∧¬Q　　　　 P规则  
+     – {4} (5)　　¬P　　　　　　 T规则，(4)和I₁  
+     – {1,4}(6)　 P∧¬P　　　　　T规则，(3)、(5)和I₁₆  
+     – {1,4}(7)　 ¬(P∧Q)　　　　F规则，(1)、(6)
