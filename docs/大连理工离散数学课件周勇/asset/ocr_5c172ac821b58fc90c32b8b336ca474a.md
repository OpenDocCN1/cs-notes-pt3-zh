# # 二、合成关系的矩阵表达和图解

设集合\(X=\{x_1,x_2,\cdots,x_m\},Y=\{y_1,y_2,\cdots,y_n\},Z=\{z_1,z_2,\cdots,z_p\}\),
\(R\)是从\(X\)到\(Y\)的关系，\(S\)是从\(Y\)到\(Z\)的关系，\(M_R\)和\(M_S\)第
\(i\)行第\(j\)列的元素分别是\(a_{ij}\)和\(b_{ij}\)，它们是0或者1。则合
成关系\(R \circ S\)关系矩阵上的元素为

\(c_{ij} = \bigvee_{k=1}^{n} a_{ik} \wedge b_{kj} \quad i=1,2,\cdots,m; j=1,2,\cdots,p\)

定义布尔运算：

\(0+0=0, \quad 1+0=0+1=1+1=1\)

\(1\cdot1=1, \quad 0\cdot1=1\cdot0=0\cdot0=0\)

对两个关系矩阵求其合成时，其运算法则与一般矩阵
的乘法是相同的，但其中的加法运算和乘法运算应改
为布尔加和布尔乘。
