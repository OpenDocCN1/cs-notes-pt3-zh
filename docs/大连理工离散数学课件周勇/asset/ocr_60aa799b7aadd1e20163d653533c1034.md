# 实例

$\mathbb{Z},\mathbb{Q},\mathbb{R}$分别为整数、有理数、实数集；$M_n(\mathbb{R})$为$n$阶实矩阵集合，$n\ge 2$；$P(B)$为幂集；$A^A$为从$A$到$A$的函数集，$|A|\ge 2$。

| 集合 | 运算 | 分配律 | 吸收律 |
|---|---|---|---|
| $\mathbb{Z},\mathbb{Q},\mathbb{R}$ | 普通加法$+$与乘法$\times$ | $\times$对$+$可分配<br>$+$对$\times$不分配 | 无 |
| $M_n(\mathbb{R})$ | 矩阵加法$+$与乘法$\times$ | $\times$对$+$可分配<br>$+$对$\times$不分配 | 无 |
| $P(B)$ | 并$\cup$与交$\cap$ | $\cup$对$\cap$可分配<br>$\cap$对$\cup$可分配 | 有 |
|  | 交$\cap$与对称差$\oplus$ | $\cap$对$\oplus$可分配 | 无 |
