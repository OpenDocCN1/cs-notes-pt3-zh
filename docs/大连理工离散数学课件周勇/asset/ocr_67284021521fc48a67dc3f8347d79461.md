+   - 定义7.2.2 若$g$是从$<S,\ \circ>$到$<S,\ \circ>$的半群同态映射，则称$g$为半群自同态映射；若$g$是从$<S,\ \circ>$到$<S,\ \circ>$的半群同构映射，则称$g$为半群自同构映射。

+   - 定理7.2.3 给定半群$<S,\ \circ>$，如果$A=\{g\mid g$为$<S,\ \circ>$到$<S,\ \circ>$的半群自同态映射$\}$且$\circ$是函数复合运算，则$<A,\ \circ>$为半群。

+   - 该定理是明显的，由前一个定理知$\circ$在$A$上是封闭的，函数的复合运算是可结合的。
