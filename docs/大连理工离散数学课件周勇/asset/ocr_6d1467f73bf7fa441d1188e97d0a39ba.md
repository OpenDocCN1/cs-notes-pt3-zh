# 函数的定义域和值域

设是从 $X$ 到 $Y$ 的函数，函数的定义域 $\mathrm{dom}f=X$，而不会是 $X$ 的真子集。函数的值域满足 $\mathrm{ran}f\subseteq Y$。对于函数 $f$，常用 $f(X)$ 表示 $\mathrm{ran}f$。集合 $Y$ 称作 $f$ 的陪域。

```
$$f(X)=\operatorname{ran}f=\{y\mid y\in Y\land(\exists x)(x\in X\land y=f(x))\}$$
```

也称 $f(x)$ 是函数的象点

**注意：** 函数的象点与自变量 $x$ 的象点是不同的。我们这里给出的函数的定义是全函数的定义，所以 $\mathrm{dom}f=X$。
