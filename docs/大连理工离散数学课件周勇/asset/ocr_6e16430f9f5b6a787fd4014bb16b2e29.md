11. 在整数环中定义* 和◇两个运算, ∀a,b∈Z 有  
a* b = a+b-1, a◇b = a+b-ab.  
证明<Z, * , ◇>构成环

证 ∀a,b∈Z有a* b, a◇b∈Z, 两个运算封闭. 任取a,b,c∈Z  
(a* b)* c = (a+b-1)* c = (a+b-1)+c-1 = a+b+c-2  
a* (b* c) = a* (b+c-1) = a+(b+c-1)-1 = a+b+c-2  
(a◇b)◇c = (a+b-ab)◇c = a+b+c- (ab+ac+bc)+abc  
a◇(b◇c) = a◇(b+c-bc) = a+b+c- (ab+ac+bc)+abc  
* 与◇可结合，1为* 的单位元. 2-a为a关于* 的逆元. Z关  
于* 构成交换群, 关于◇构成半群. ◇关于* 满足分配律.  
a◇(b* c) = a◇(b+c-1) = 2a+b+c-ab-ac-1  
(a◇b)* (a◇c) = 2a+b+c-ab-ac-1
