# ## 二、等价关系

定义：设\(X\)是任意集合，\(R\)是集合中的二元关系。如果\(R\)是自反的、对称的和可传递的，则称\(R\)是等价关系。即满足以下几点：

+   (a) \((\forall x)(x \in X \rightarrow xRx)\)

+   (b) \((\forall x)(\forall y)(x \in X \wedge y \in X \wedge xRy \rightarrow yRx)\)

+   (c) \((\forall x)(\forall y)(\forall z)(x \in X \wedge y \in X \wedge z \in X \wedge xRy \wedge yRz \rightarrow xRz)\)

如果\(R\)是集合\(X\)中的等价关系，则\(R\)的域是集合\(X\)自身，所以，称\(R\)是定义于集合\(X\)中的关系。

例如 数的相等关系是任何数集上的等价关系。

又例如一群人的集合中姓氏相同的关系也是等价关系。

但朋友关系不是等价关系，因为它不可传递。
