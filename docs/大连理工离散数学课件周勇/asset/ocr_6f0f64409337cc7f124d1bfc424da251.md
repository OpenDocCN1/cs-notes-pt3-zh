# 基本的等价公式

# 交换律

+   - E₁ P ∨ Q ⇔ Q ∨ P
+   - E₂ P ∧ Q ⇔ Q ∧ P
+   - E₃ P ↔ Q ⇔ Q ↔ P

# 结合律

+   - E₄ (P ∨ Q) ∨ R ⇔ P ∨ (Q ∨ R)
+   - E₅ (P ∧ Q) ∧ R ⇔ P ∧ (Q ∧ R)
+   - E₆ (P ↔ Q) ↔ R ⇔ P ↔ (Q ↔ R)

# 分配律

+   - E₇ P ∧ (Q ∨ R) ⇔ (P ∧ Q) ∨ (P ∧ R)
+   - E₈ P ∨ (Q ∧ R) ⇔ (P ∨ Q) ∧ (P ∨ R)

E₉ P → (Q → R) ⇔ (P → Q) → (P → R)
