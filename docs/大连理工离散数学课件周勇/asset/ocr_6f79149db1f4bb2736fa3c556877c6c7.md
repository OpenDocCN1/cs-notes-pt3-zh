+   由定义可知，同余关系是代数结构的集合中的等价关系，并且在运算的作用下，能够保持关系的等价类。即在\(x_1^\circ y_1\)中，如果用集合S中的与\(x_1\)等价的任何其它元素\(x_2\)代换\(x_1\)，并且用与\(y_1\)等价的任何其它元素\(y_2\)代换\(y_1\)，则所求的结果\(x_2^\circ y_2\)与\(x_1^\circ y_1\)位于同一等价类之中。亦即若\([x_1]_E = [x_2]_E\)并且\([y_1]_E = [y_2]_E\)，则\([x_1^\circ y_1]_E = [x_2^\circ y_2]_E\)。此外，同余关系与运算密切相关。
+   
+   如果一个代数结构中有多个运算，则需要考察等价关系对于所有这些运算是否都有代换性质。如果有，则说该代数结构存在同余关系；否则，同余关系不存在。
