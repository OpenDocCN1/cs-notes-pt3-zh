# 群的性质：消去律

定理：\(G\)为群，则\(G\)中适合消去律，即对任意\(a,b,c\in G\)有

+   1. 若 \(ab=ac\)，则 \(b=c\)。
+   2. 若 \(ba=ca\)，则 \(b=c\)。

证明略

例：设 \(G=\{a_1,a_2,\ldots,a_n\}\) 是 \(n\) 阶群，令

\[a_iG=\{a_ia_j\mid j=1,2,\ldots,n\}\]

证明 \(a_iG=G\)。

证 由群中运算的封闭性有 \(a_iG\subseteq G\)。假设 \(a_iG\subset G\)，即 \(|a_iG|<n\)。
必有 \(a_j,a_k\in G\) 使得

\[a_ia_j=a_ia_k\quad (j\ne k)\]

由消去律得 \(a_j=a_k\)，与 \(|G|=n\) 矛盾。
