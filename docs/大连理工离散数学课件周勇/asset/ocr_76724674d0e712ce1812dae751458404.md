# 解答

+   1. * 满足交换律，满足结合律，不满足幂等律。
+      - 不满足交换律，满足结合律，满足幂等律。
+      - 满足交换律，满足结合律，不满足幂等律。
+   2. * 的单位元为 $b$，没有零元，$a^{-1}=c,\ b^{-1}=b,c^{-1}=a$
+      - 的单位元和零元都不存在，没有可逆元素。
+      - 的单位元为 $a$，零元为 $c$，$a^{-1}=a,\ b,c$ 不是可逆元素。

说明：关于结合律的判断

需要针对运算元素的每种选择进行验证，若 $|A|=n$，一般需要验证 $n^3$ 个等式。

单位元和零元不必参与验证。

通过对具体运算性质的分析也可能简化验证的复杂性。
