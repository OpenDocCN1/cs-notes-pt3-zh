# # 谓词公式的翻译

+   - 任何整数都是实数。
+     - \( P(x): x\) 是整数；
+     - \( Q(x): x\) 是实数。
+     - 符号化为： \( (\forall x)(P(x) \rightarrow Q(x)) \)

+   - 没有不犯错误的人。
+     - \( P(x): x\) 是人；
+     - \( Q(x): x\) 犯错误。
+     - 符号化为： \( (\forall x)(P(x) \rightarrow Q(x)) \)
+     - 或符号化为： \( \neg (\exists x)(P(x) \land \neg Q(x)) \)
