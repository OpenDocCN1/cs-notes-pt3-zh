# 例7 设\(A\)为任意集合，则\(P(A) \sim \{0,1\}^A\)。

证 如下构造从\(P(A)\)到\(\{0,1\}^A\)的函数  
\(f: P(A) \to \{0,1\}^A, \quad f(A') = \Psi_{A'}, \quad \forall A' \in P(A)\)。  
其中\(\Psi_{A'}\)是集合\(A'\)的特征函数。易证\(f\)是单射的。  
对于任意的\(g \in \{0,1\}^A\)，那么有\(g: A \to \{0,1\}\)。令  
\(B = \{ x \mid x \in A \land g(x) = 1 \}\)  
则\(B \subseteq A\)，且\(\Psi_B = g\)，即\(\exists B \in P(A), \quad f(B) = g\)。从而证明了\(f\)是满射的。  
由等势定义得  
\(P(A) \sim \{0,1\}^A\)。
