# # 反证法

证充分性：由于 {H₁ ∧ H₂ ∧ ... ∧ Hₙ ∧ ¬C} 可以逻辑地推出一个矛盾，即 H₁ ∧ H₂ ∧ ... ∧ Hₙ ∧ ¬C ⇒ F 即

H₁ ∧ H₂ ∧ ... ∧ Hₙ ∧ ¬C → F 为永真式，即 H₁ ∧ H₂ ∧ ... ∧ Hₙ ∧ ¬C 为假，由假设知 {H₁，H₂，..., Hₙ} 是一致的，所以任何使 H₁ ∧ H₂ ∧ ... ∧ Hₙ 为真的命题变元的真值指派必然使 ¬C 为假，从而使 C 为真。故有

H₁ ∧ H₂ ∧ ... ∧ Hₙ ⇒ C

该定理说明用直接证明法可以证明的结论，用间接证明法都可以证明，反之亦然。
