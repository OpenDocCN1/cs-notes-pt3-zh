# 陪集定义与实例

**定义：** 设 $H$ 是 $G$ 的子群，$a\in G$。令

$$Ha=\{ha\mid h\in H\}$$

称 $Ha$ 是子群 $H$ 在 $G$ 中的**右陪集**。称 $a$ 为 $Ha$ 的**代表元素**。

**例：** （1）设 $G=\{e,a,b,c\}$ 是 Klein 四元群，$H=\langle a\rangle$ 是 $G$ 的子群。

$H$ 所有的右陪集是：

$$He=\{e,a\}=H,\quad Ha=\{a,e\}=H,\quad Hb=\{b,c\},\quad Hc=\{c,b\}$$

不同的右陪集只有两个，即 $H$ 和 $\{b,c\}$。
