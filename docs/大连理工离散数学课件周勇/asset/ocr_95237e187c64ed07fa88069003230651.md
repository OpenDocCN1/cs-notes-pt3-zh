# 函数的基本概念和性质

例：设 $E$ 是全集，$P(E)$ 是 $E$ 的幂集。对任何两个集合 $X,Y\in P(E)$，它们的并运算和相交运算都是从 $P(E)\times P(E)$ 到 $P(E)$ 的映射；对任何集合 $X\in P(E)$ 的求补运算，则是从 $P(E)$ 到 $P(E)$ 的映射。

例：试说明下列二元关系是否是函数？

+   1. $\mathrm{exp}=\{\langle x,e^x\rangle\mid x\in R\}$
+   2. $\mathrm{arcsin}=\{\langle x,y\rangle\mid x,y\in R\land \sin y=x\}$

$(1)$ 是函数，$(2)$ 不是函数
