# # 谓词逻辑求解实际问题

例11：所有的蜂鸟都五彩斑斓；没有大鸟以蜜为生；不以蜜为生的鸟都色彩单调；因此，蜂鸟都是小鸟。

解：定义谓词如下：

\( P(x): x \text{是只蜂鸟}；\)

\( Q(x): x \text{是大鸟}；\)

\( R(x): x \text{是以蜜为生的鸟}；\)

\( S(x): x \text{五彩斑斓}。\)

\(\forall x(P(x) \rightarrow S(x)), \quad \neg \exists x(Q(x) \wedge R(x)),\)

\(\forall x(\neg R(x) \rightarrow \neg S(x)) \Rightarrow \forall x(P(x) \rightarrow \neg Q(x))\)
