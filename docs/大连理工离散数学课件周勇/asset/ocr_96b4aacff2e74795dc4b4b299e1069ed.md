# 实例

(2) 设A={1,2,3}, f1,f2,...,f6是A上的双射函数。其中
f1={<1,1>,<2,2>,<3,3>}, f2={<1,2>,<2,1>,<3,3>}
f3={<1,3>,<2,2>,<3,1>}, f4={<1,1>,<2,3>,<3,2>}
f5={<1,2>,<2,3>,<3,1>}, f6={<1,3>,<2,1>,<3,2>}

令 G = {f1,f2,...,f6}, 则G关于函数的复合运算构成群。考虑 G 的子群H={f1,f2}。做出 H 的全体右陪集如下：

+   Hf1={f1°f1, f2°f1}=H, Hf2={f1°f2, f2°f2}=H
+   Hf3={f1°f3, f2°f3}={f3,f6}, Hf5={f1°f5, f2°f5}={f5,f4}
+   Hf4={f1°f4, f2°f4}={f4,f5}, Hf6={f1°f6, f2°f6}={f6,f3}

结论： Hf1=Hf2, Hf3=Hf6, Hf4=Hf5.
