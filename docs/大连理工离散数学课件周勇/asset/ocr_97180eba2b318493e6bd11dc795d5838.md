# # 偏序集合与哈斯图

定义： 设\(\langle P, \leq \rangle\)是一个偏序集合，并有 \(Q \subseteq P\)。

(a)如果 \(q \in Q\)，且不存在元素 \(q' \in Q\) 能使 \(q \neq q'\) 和 \(q' \leq q\)，则称 \(q\) 是 \(Q\) 的**极小元**。

(b)如果 \(q \in Q\)，且不存在元素 \(q' \in Q\) 能使 \(q \neq q'\) 和 \(q \leq q'\)，则称 \(q\) 是 \(Q\) 的**极大元**。

极大元和极小元都不是唯一的。不同的极大元(或不同的极小元)是不可比的。
