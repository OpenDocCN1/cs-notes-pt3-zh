# # 四、集合的基数

+   - 集合 \( A \) 中不同元素的个数叫集合 \( A \) 的基数，记作 \( \#A \) 或 \( |A| \)。

+   - 例如：\( A = \{2,3,4\}, \#A=3 \)，\( A \) 为有限集。
+     \( A = \{x \mid x \in \mathbb{Z}\}, \#A \) 无穷大，\( A \) 为无限集。
+     \( S = \{a, \{1,2\}, P, \{q\}\}, \#S=4 \).

# # 五、空集

+   - 不包含任何元素的集合为空集，记作 \( \varnothing \) 。

+   - 例如：\( A = \{x \mid x \in \mathbb{R} \text{ 且 } x^2+8=0\} = \varnothing \)

注意：\( \varnothing \) 与 \( \{\varnothing\}\) 的区别

\( \varnothing \neq \{\varnothing\} \qquad \varnothing \in \{\varnothing\} \)
