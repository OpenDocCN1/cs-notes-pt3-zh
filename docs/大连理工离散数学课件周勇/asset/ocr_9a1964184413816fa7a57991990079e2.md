# 谓词逻辑中的推理

**例1** 证明 $(\exists x)M(x)$ 是前提 $(\forall x)(H(x)\to M(x))$ 和 $(\exists x)H(x)$ 的逻辑结果。

# 证明：

|  | 公式 | 依据 | 实例 |
|---|---|---|---|
| (1) | $(\exists x)H(x)$ | $P$ | |
| (2) | $H(y)$ | $ES,(1)$ | $H(a)$ |
| (3) | $(\forall x)(H(x)\to M(x))$ | $P$ | |
| (4) | $H(y)\to M(y)$ | $US,(3)$ | $H(a)\to M(a)$ |
| (5) | $M(y)$ | $T,(2),(4)$ | $M(a)$ |
| (6) | $(\exists x)M(x)$ | $EG,(5)$ | |
