# 有限布尔代数的表示定理

# 定理8.9（有限布尔代数的表示定理）

设 $B$ 是有限布尔代数，$A$ 是 $B$ 的全体原子构成的集合，则 $B$ 同构于 $A$ 的幂集代数 $P(A)$。

# 实例：

(1) $S_{110}$ 关于 gcd，lcm 运算构成的布尔代数。它的原子是 $2,5$ 和 $11$，因此原子的集合 $A=\{2,5,11\}$。幂集

$P(A)=\{\varnothing,\{2\},\{5\},\{11\},\{2,5\},\{2,11\},\{5,11\},\{2,5,11\}\}$。

幂集代数是 $\langle P(A),\cap,\cup,\sim,\varnothing,A\rangle$。只要令 $f:S_{110}\to P(A)$，

$f(1)=\varnothing,\ f(2)=\{2\},\ f(5)=\{5\},\ f(11)=\{11\},$

$f(10)=\{2,5\},\ f(22)=\{2,11\},\ f(55)=\{5,11\},\ f(110)=A,$

那么 $f$ 就是从 $S_{110}$ 到幂集 $P(A)$ 的同构映射。
