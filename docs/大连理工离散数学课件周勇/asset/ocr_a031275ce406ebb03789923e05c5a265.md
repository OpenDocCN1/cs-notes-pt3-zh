# # 关系矩阵法寻找最大相容类

解：这里结点4是个孤立结点，故在矩阵中删除了相应的行和列。根据步骤(2)和(3)可有

(1) {4}
(2) {4}, {5,6}
(3) {4},{5,6},{3,5},{3,6}，合并后有{4},{3,5,6}
(4) {4},{3,5,6},{2,3}
(5) {4},{3,5,6},{2,3} ,{1,2},{1,3},{1,6}，合并后有
{4},{3,5,6},{1,2,3} ,{1,3,6} ，这里，相容偶对{1,3}, {1,6}
中的元素1，与相容类{3,5,6}中的部分元素有相容关
系，故组成了相容类{1,3,6}。
这些相容类都是最大相容类。
