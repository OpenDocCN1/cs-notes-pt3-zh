# ## 二、多重序元

定义：\(n\)重序元是一个序偶，它的第一元素是\((n-1)\)重序元。

3重序元：\(<<x,y>,z>\)，简单记作\(<x,y,z>\)

\(n\)重序元：\(<<x_1,x_2,\cdots,x_{n-1}>,x_n>\)

\(n\)重序元的相等：

\(\langle\langle x_1,x_2\cdots,x_{n-1}\rangle,x_n\rangle=\langle\langle a_1,a_2\cdots,a_{n-1}\rangle,a_n\rangle\Leftrightarrow((x_1=a_1)\wedge(x_2=a_2)\wedge\cdots\wedge(x_n=a_n))\)
