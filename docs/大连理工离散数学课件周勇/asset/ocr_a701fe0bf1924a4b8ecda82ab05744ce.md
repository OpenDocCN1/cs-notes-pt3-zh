# 集合定律

+   S₁  A ∩ B ⊆ A
+   S₂  A ∩ B ⊆ B
+   S₃  A ⊆ A ∪ B
+   S₄  B ⊆ A ∪ B
+   S₅  A − B ⊆ A
+   S₆  A ⊕ B ⊆ A ∪ B

+   S₇  A ∪ B = B ∪ A
+   S₈  A ∩ B = B ∩ A
+   S₉  A ⊕ B = B ⊕ A
+   交换律

+   S₁₀  A ∪ (B ∪ C) = (A ∪ B) ∪ C
+   S₁₁  (A ∩ B) ∩ C = A ∩ (B ∩ C)
+   S₁₂  (A ⊕ B) ⊕ C = A ⊕ (B ⊕ C)
+   结合律
