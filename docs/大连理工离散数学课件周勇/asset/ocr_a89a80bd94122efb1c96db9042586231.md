# # 反函数

例: 给定集合 X={1,2,3}, Y={a,b,c} 和 Z={α,β,γ} 设函数 f: X→Y 和 g: Y→Z 分别为: f={<1,c>,<2,a>,<3,b>}, g={<a, γ >,<b, β >,<c, a >} 试说明 (g ∘ f)^{-1}=f^{-1} ∘ g^{-1}。

解:

f^{-1} = {<a,2>,<b,3>,<c,1>}

g^{-1} = {<α, c>,<β, b>,<γ, a>}

g ∘ f = {<1,α>,<2,γ>,<3,β>}

(g ∘ f)^{-1} = {<α,1>,<β,3>,<γ,2>}

f^{-1} ∘ g^{-1} = {<α,1>,<β,3>,<γ,2>} = (g ∘ f)^{-1}
