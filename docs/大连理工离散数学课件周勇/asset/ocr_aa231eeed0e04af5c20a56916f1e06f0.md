# 四、关系的闭包运算

证明（3）：
任取x,y,z∈X，当<x,y>∈r(R)，<y,z>∈r(R)时，由于r(R)=R∪I_x
于是可得(<x,y>∈R或者<x,y>∈I_x)并且(<y,z>∈R或者<y,z>∈I_x)，组合可以得到四种情况：

+   (1) <x,y>∈R，<y,z>∈R，由R的传递性可知<x,z>∈R，于是<x,z>∈r(R)
+   (2)<x,y>∈I_x，<y,z>∈R，由I_x的性质可知，x=y，于是<x,z>∈R，得到<x,z>∈r(R)
+   (3)<x,y>∈R，<y,z>∈I_x，由I_x的性质可知，y=z，于是<x,z>∈R，得到<x,z>∈r(R)
+   (4)<x,y>∈I_x，<y,z>∈I_x，由I_x的性质可知，x=y=z，于是<x,z>∈I_x，得到<x,z>∈r(R)

由上可知，无论哪种情况，都有<x,z>∈r(R)
由x,y,z的任意性可知，r(R)是可传递的。
