6. 设\(<B,\wedge,\vee,\neg,0,1>\)是布尔代数，证明对于\(B\)中任意元素 \(a,b\)

(1) \(a \vee (a \wedge b) = a \vee b\)

(2) \(a \wedge \neg b = 0 \Leftrightarrow \neg a \vee b = 1 \Leftrightarrow a \leq b\)

证 (1) \(a \vee \neg(a \wedge b) = (a \vee \neg a) \wedge (a \vee b) = 1 \wedge (a \vee b) = a \vee b\)

(2) 由 \(a \wedge \neg b = 0\) 得 \(a \wedge \neg b = 1\)，即 \(\neg a \vee b = 1\)；反之也对。下面证明它们都等价于 \(a \leq b\)。由 \(\neg a \vee b = 1\) 得

\(a = a \wedge 1 = a \wedge (\neg a \vee b) = (a \wedge \neg a) \vee (a \wedge \neg b)\)

\(= 0 \vee (a \wedge \neg b) = a \wedge \neg b\)

即 \(a \leq b\)，又由 \(a \leq b\) 得

\(a \wedge \neg b = (a \wedge b) \wedge \neg b = a \wedge (b \wedge \neg b) = a \wedge 0 = 0\)
