# # 一、集合的划分和覆盖

定义： 给定非空集合\(S\)，设非空集合\(A=\{A_1,A_2,\dots,A_n\}\)，如果有

+   (a) \(A_i \subseteq S \ (i=1,2,\dots,n)\)

+   (b) \(A_i \cap A_j = \varnothing \ (i \neq j)\) 或 \(A_i \cap A_j \neq \varnothing \ (i = j)\)

+   (c) \(\bigcup_{i=1}^n A_i = S\)

则称集合\(A\)是集合\(S\)的一个划分。

划分中的元素\(A_i\)称为划分的类。

划分的类的数目叫划分的秩。

划分是覆盖的特定情况，即中元素互不相交的特定情况。
