# # 直接证法

例：证明\(\neg P\)是\(\neg(P \land \neg Q)\)，\(\neg Q \lor R\)，\(\neg R\)的有效结论。

解：{1} (1) \(\neg(P \land \neg Q)\) P规则

{1} (2) \(\neg P \lor Q\) T规则 (1)和E₁₁

{1} (3) \(P \rightarrow Q\) T规则 (2)和E₂₇

{4} (4) \(\neg Q \lor R\) P规则

{4} (5) \(Q \rightarrow R\) T规则 (4)和E₂₇

{1,4} (6) \(P \rightarrow R\) T，(3)，(5)和I₁₂

{7} (7) \(\neg R\) P规则

{1,4,7}(8) \(\neg P\) T,(6),(7)和I₁₂
