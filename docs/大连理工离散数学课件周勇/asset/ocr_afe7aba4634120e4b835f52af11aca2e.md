# 实例



(1) <Z+,+>, <N,+>, <Z,+>, <Q,+>, <R,+>都是半群, +是普通加法. 这些半群中除<Z+,+>外都是独异点.

(2) 设n是大于1的正整数, <M_n(R),+>和<M_n(R),·>都是半群, 也都是独异点. 其中+·分别表示矩阵加法和矩阵乘法

(3) <P(B),⊕>为半群, 也是独异点, 其中⊕为集合对称差运算

(4) <Z_n, ⊕>为半群, 也是独异点, 其中Z_n={0,1,...,n-1}, ⊕为模n加法

(5) <A^4, ◦>为半群, 也是独异点, 其中 ◦ 为函数的复合运算

(6) <R*, ◦>为半群, 其中R*为非零实数集合, ◦运算定义如下: ∀x,y∈R*, x ◦ y=y
