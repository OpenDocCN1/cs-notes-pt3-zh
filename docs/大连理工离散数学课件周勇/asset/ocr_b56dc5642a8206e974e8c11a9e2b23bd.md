# # 8.1 格的定义与性质

定义8.1 设\(<S, \prec>\)是偏序集，如果\(\forall x,y \in S\)，\(\{x,y\}\)都有最小上界和最大下界，则称\(S\)关于偏序\(\prec\) 作成一个格。
求\(\{x,y\}\) 最小上界和最大下界看成 \(x\) 与 \(y\) 的二元运算 \(\vee\) 和 \(\wedge\)，

例1 设\(n\)是正整数，\(S_n\)是\(n\)的正因子的集合。\(D\)为整除关系，则偏序集\(<Sn,D>\)构成格。\(\forall x,y \in S_n\)，\(x \vee y\)是\(\text{lcm}(x,y)\)，即\(x\)与\(y\)的最小公倍数。\(x \wedge y\)是\(\text{gcd}(x,y)\)，即\(x\)与\(y\)的最大公约数。
