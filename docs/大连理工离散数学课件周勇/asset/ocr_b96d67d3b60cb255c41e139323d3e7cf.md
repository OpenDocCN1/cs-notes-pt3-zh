# # 谓词公式的翻译

+   - 一切人不是一样高。
+     - \( P(x): x \) 是人。
+     - \( Q(x,y): x \) 与 \( y \) 一样高。
+     - \( R(x,y): x \) 与 \( y \) 是不一样。
+     - 符号化为：\( (\forall x)(\forall y)((P(x) \wedge P(y) \wedge R(x,y)) \rightarrow \neg Q(x,y)) \)

+   - 不是一切人都一样高。
+     - 符号化为：\( \neg \forall x \forall y ((P(x) \wedge P(y)) \rightarrow Q(x,y)) \)
+     - 或：\( \exists x \exists y (P(x) \wedge P(y) \wedge \neg Q(x,y)) \)
