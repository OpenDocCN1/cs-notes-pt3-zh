# # 1.3命题变元和合式公式

+   • 命题变元  
+     一个可以表示任意原子命题，且没有确定的真值指派的抽象命题，  
+     被称为命题变元

+   • 合式公式  
+     由命题变元、逻辑联接词及圆括号构成的有效字符串

+   • 合式公式递归定义

+   (1) 真值T和F是合式公式。  
+   (2) 原子命题公式是一个合式公式。  
+   (3) 如果A是合式的公式，那么¬A是合式的公式。  
+   (4) 如果A和B均是合式的公式，那么(A∧B)，(A∨B),(A→B)和  
+   (A↔B)都是合式的公式。  
+   (5) 当且仅当有限次地应用（1）至（4）条规则由逻辑联结词、圆  
+   括号所组成的有意义的符号串是合式的公式。

上面的定义成为递归定义法，（1）和（2）称为递归定义基础，（3）  
和（4）称为递归定义的归纳，（5）称为递归定义的界限。
