# ## 三、相容关系

定义： 给定集合\(X\)中的二元关系\(R\)，如果\(R\)是自反的，对称的，则称\(R\)是相容关系，记作\(\approx\)。也就是说，可以把\(R\)规定成：

+   (1) \((\forall x)(x \in X \rightarrow xRx)\)

+   (2) \((\forall x)(\forall y)(x \in X \land y \in X \land xRy \rightarrow yRx)\)

显然，所有的等价关系都是相容关系，但相容关系并不一定是等价关系。

例如，设集合\(X=\{2166,243,375,648,455\}\)，\(X\)中的关系\(R=\{\langle x,y\rangle | x,y \in X \land x\)和\(y\)有相同的数字\}，可以看出\(R\)是自反的和对称的，因此是一相容关系。
