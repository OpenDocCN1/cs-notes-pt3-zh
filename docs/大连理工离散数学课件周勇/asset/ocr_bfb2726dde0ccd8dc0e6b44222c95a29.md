# 析取范式和合取范式

例：求 ¬(P ∨ Q) ↔ (P ∧ Q) 的析取范式。

解：¬(P ∨ Q) ↔ (P ∧ Q)

⇔ ¬(P ∨ Q) ∧ (P ∧ Q) ∨ ¬(¬(P ∨ Q)) ∧ ¬(P ∧ Q)

⇔ (¬P ∧ ¬Q ∧ P ∧ Q) ∨ ((P ∨ Q) ∧ (¬P ∨ ¬Q))

⇔ F ∨ (P ∨ Q) ∧ (¬P ∨ ¬Q)

⇔ (P ∨ Q) ∧ (¬P ∨ ¬Q)

⇔ ((P ∨ Q) ∧ ¬P) ∨ (((P ∨ Q) ∧ ¬Q)

⇔ P ∧ ¬P ∨ ¬P ∧ Q ∨ P ∧ ¬Q ∨ Q ∧ ¬Q

⇔ F ∨ ¬P ∧ Q ∨ P ∧ ¬Q ∨ F

⇔ (¬P ∧ Q) ∨ (P ∧ ¬Q)
