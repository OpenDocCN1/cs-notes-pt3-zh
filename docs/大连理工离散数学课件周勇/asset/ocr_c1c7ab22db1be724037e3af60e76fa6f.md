# # 常用永真蕴含式

I₁：P∧Q⇒P， I₂： P⇒P∨Q， I₃： ¬P⇒P→Q

I₄： Q⇒P→Q, I₅： ¬(P→Q)⇒P， I₆： ¬(P→Q)⇒¬Q

I₇： P, Q⇒ P∧Q, I₈： ¬P, P∨Q⇒Q， I₉： P， P→Q
⇒Q

I₁₀： ¬Q, P→Q⇒¬P， I₁₁： P→Q, Q→R⇒P→R

I₁₂： P∨Q, P→R, Q→R⇒R

公式中 “,”代表 “∧” ，公式不必死记硬背，其证明均可从 “⇒” 的定义出发。例如对I₁₁前件为真时保证P→Q和Q→R都必为真， P→Q为真，则保证P为真时Q一定为真，而Q为真和Q→R为真则保证了R必为真，

P为真，R为真自然保证了P→R为真，问题得证。
