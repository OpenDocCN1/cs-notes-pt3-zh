# # 恒等函数

定义：给定集合X，并且有函数\(I_X: X \to X\)。对于所有的\(x \in X\)，有\(I_X(x) = x\)，亦即\(I_X = \{<x,x> | x \in X\}\)

则称\(I_X\)为恒等函数。

定理：给定集合X和Y。对于任何函数\(f: X \to Y\)，都有

\(f = f \circ I_X = I_Y \circ f\)

证明：设\(x \in X\)和\(y \in Y\)，根据定义\(I_X(x) = x\)，\(I_Y(y) = y\)

\((f \circ I_X)(x) = f(I_X(x)) = f(x)\)

\((I_Y \circ f)(x) = I_Y(f(x)) = f(x)\)

得证。
