# # 可约性

定理：设*是集合\(X\)中的二元运算，且*是可结合的。  
如果元素 \(a \in X\) 对于运算*是可逆的，则\(a\)也是可约的。

证：设 \(x, y \in X\)，且 \(a * x = a * y\)。由于\(a\)是可结合的，并且\(a\)是可逆的，因此可有

\(a^{-1} * (a * x) = (a^{-1} * a) * x = e * x = x\)
\(= a^{-1} * (a * y) = (a^{-1} * a) * y\)
\(= e * y = y\)

由定义知，元素\(a\)是左可约去的，同理可证\(a\)是右可约的，于是\(a\)是可约的。
