# 3.3包含排斥原理

例：某工厂装配30辆汽车，可供选择的设备是收音机、空气调节器和对讲机。已知其中15辆汽车有收音机、8辆有空气调节器，6辆有对讲机，而且其中有3辆这三种设备都有。我们希望知道有几辆汽车没有提供任何设备。

解：设\(A_1\)、\(A_2\)和\(A_3\)分别表示配有收音机、空气调节器和对讲机的汽车集合，因此由题设知

\(|A_1| = 15, |A_2| = 8, |A_3| = 6, |A_1 \cap A_2 \cap A_3| = 3\)

因为\(|A_1 \cap A_2| \geq |A_1 \cap A_2 \cap A_3| = 3\)
\(|A_1 \cap A_3| \geq |A_1 \cap A_2 \cap A_3| = 3\)
\(|A_2 \cap A_3| \geq |A_1 \cap A_2 \cap A_3| = 3\)

得
\(|A_1 \cup A_2 \cup A_3| = 15 + 8 + 6 - |A_1 \cap A_2| - |A_1 \cap A_3| - |A_2 \cap A_3| + 3\)
\(\leq 32 - 3 - 3 - 3 = 23\)
