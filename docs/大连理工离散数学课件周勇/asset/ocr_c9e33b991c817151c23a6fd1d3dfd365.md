# # 偏序集合与哈斯图

定义：设 \((P,\leq)\) 是一个偏序集合，并有 \(Q\subseteq P\)。

+   1. 如果 \(q\in Q\) 是 \(Q\) 的一个上界，且对于 \(Q\) 的每一个上界 \(q'\) 都有 \(q\leq q'\)，则称 \(q\) 是 \(Q\) 的**最小上界**，通常记作 **LUB**。

+   2. 如果 \(q\in Q\) 是 \(Q\) 的一个下界，且对于 \(Q\) 的每一个下界 \(q'\) 都有 \(q'\leq q\)，则称 \(q\) 是 \(Q\) 的**最大下界**，通常记作 **GLB**。

如果存在最小上界的话，它是唯一的；如果存在最大下界的话，它也是唯一的。
