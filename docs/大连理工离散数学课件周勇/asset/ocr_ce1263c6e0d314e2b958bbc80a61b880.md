# # 九、幂集

定理：如果有限集合\(A\)有\(n\)个元素，则它的幂集有\(2^n\)个元素。

证明：\(A\)的所有\(k\)个元素组成的子集数为从\(n\)个元素中取\(k\)个的组合数。

\(C_n^k = \frac{n(n-1)(n-2)\cdots(n-k+1)}{k!}\)

另外，因为\(\varnothing \subseteq A\) 因此\(P(A)\) 的总数\(N\)可表示为

\(N = 1 + C_n^1 + C_n^2 + \dots + C_n^k + \dots + C_n^n = \sum_{k=0}^n C_n^k\)

因为 \((x+y)^n = \sum_{k=0}^n C_n^k \cdot x^k \cdot y^{n-k}\)

令\(x=y=1\)，得 \(2^n = \sum_{k=0}^n C_n^k\)

故集合\(A\)的幂集的元素个数为\(2^n\)
