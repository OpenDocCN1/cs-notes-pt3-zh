# # 等价类的性质

设\(X\)是一集合，\(X\)是\(R\)中的等价关系

+   1. 如果\(x \in X\)，则\(x \in [x]_R\)。该性质是明显的，因为 \(R\) 是自反的，所以有 \(xRx\)，于是 \(x \in [x]_R\)

+   2. 对于所有的 \(x, y \in X\)，或者 \([x]_R = [y]_R\)，或者 \([x]_R \cap [y]_R = \varnothing\)  
+   证明：当 \(X = \varnothing\)，上述结论肯定为真。  
+   当 \(X \neq \varnothing\) 时，分两种情况讨论  
+      (1) \(xRy\)  
+      (2) \(xR'y\)
