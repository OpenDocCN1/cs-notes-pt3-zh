# # 4.5特殊关系

# ## 一、集合的划分和覆盖

定义：给定非空集合S，设非空集合\(A=\{A_1,A_2,\cdots,A_n\}\)，如果有

\((a) \quad A_i \subseteq S \quad (i=1,2,\cdots,n)\)

\((b) \quad \bigcup_{i=1}^n A_i = S\)

则称集合\(A\)是集合\(S\)的**覆盖**。

注意：集合的覆盖不唯一。

例如：\(S=\{a,b,c\}\)，\(A=\{\{a,b\},\{b,c\}\}\)，\(B=\{\{a\},\{b,c\}\}\)，\(A\)和\(B\)都是集合\(S\)的覆盖。
