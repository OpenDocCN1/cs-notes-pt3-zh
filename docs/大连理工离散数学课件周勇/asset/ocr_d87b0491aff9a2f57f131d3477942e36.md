# 可达性矩阵判断强分图

由路径矩阵 $P$ 可以求得含有给定图的任何特定结点的强分图。

设 $G=\langle V,E,\psi\rangle$ 是一个简单有向图，并且 $G\neq\Phi$。$P$ 是图 $G$ 的路径矩阵，$P^T$ 是矩阵 $P$ 的转置。设矩阵 $P$ 中的 $(i,j)$ 元素为 $p_{ij}$，而矩阵 $P^T$ 中的 $(i,j)$ 元素为 $p^T_{ij}$。试定义一个矩阵 $P\wedge P^T$，使得它的 $(i,j)$ 元素为 $p_{ij}p^T_{ij}$。于是，矩阵 $P\wedge P^T$ 中的第 $i$ 行，就确定了含有结点 $v_i$ 的强分图。
