# # 证明

证 (1) 显然 \(<a^{-1}> \subseteq G\)。
\(\forall a^k \in G\)，
\(a^k = (a^{-1})^{-k} \in <a^{-1}>\)，
因此 \(G \subseteq <a^{-1}>\)，
\(a^{-1}\) 是 \(G\) 的生成元。
再证明 \(G\) 只有 \(a\) 和 \(a^{-1}\) 这两个生成元。假设 \(b\) 也是 \(G\) 的生成元，
则 \(G = <b>\)。由 \(a \in G\) 可知存在整数 \(t\) 使得 \(a = b^t\)。由 \(b \in G = <a>\)
知存在整数 \(m\) 使得 \(b = a^m\)。从而得到
\(a = b^t = (a^m)^t = a^{mt}\)
由 \(G\) 中的消去律得
\(a^{mt-1} = e\)
因为 \(G\) 是无限群，必有 \(mt-1 = 0\)。从而证明了 \(m = t = 1\) 或 \(m = t = -1\)，
即 \(b = a\) 或 \(b = a^{-1}\)
