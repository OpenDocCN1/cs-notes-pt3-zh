# # 有界格的定义

定义8.6 设\(L\)是格，

(1) 若存在\(a \in L\)使得\(\forall x \in L\)有 \(a \leq x\)，则称\(a\)为\(L\)的**全下界**

(2) 若存在\(b \in L\)使得\(\forall x \in L\)有 \(x \leq b\)，则称\(b\)为\(L\)的**全上界**

说明：

+   - 格\(L\)若存在全下界或全上界，一定是惟一的。

+   - 一般将格\(L\)的全下界记为0，全上界记为1。

定义8.7 设\(L\)是格，若\(L\)的每个非空子集均有上下确界，则称其为**完全格**；若\(L\)存在全下界和全上界，则称其为**有界格**，一般将有界格\(L\)记为\(<L, \wedge, \vee, 0, 1>\)。
