# # 八、幂集

定义：给定集合\(A\)，由集合\(A\)的所有子集为元素组成的集合称为集合\(A\)的幂集，记为\(P(A)\)。

例：设\(A=\{a\}\)
则0个元素的子集：\(\varnothing\)
1个元素的子集：\(\{a\}\)
因此\(\rho(A)=\{\varnothing,\{a\}\}\)

设\(B=\{a,b\}\)
则0个元素的子集：\(\varnothing\)
1个元素的子集：\(\{a\},\{b\}\)
2个元素的子集：\(\{a,b\}\)
因此，\(P(B)=\{\varnothing,\{a\},\{b\},\{a,b\}\}\)

设\(C=\{a,b,c\}\)
则0个元素的子集：\(\varnothing\)；1个元素的子集：\(\{a\},\{b\},\{c\}\)
2个元素的子集：\(\{a,b\},\{a,c\},\{b,c\}\)
3个元素的子集：\(\{a,b,c\}\)
因此\(P(C)=\{\varnothing,\{a\},\{b\},\{c\},\{a,b\},\{a,c\},\{b,c\},\{a,b,c\}\}\)
