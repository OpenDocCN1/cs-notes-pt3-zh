# # 四、关系的闭包运算

闭包的定义：给定集合_X_，_R_是_X_中的二元关系。  
如果有另一个关系_R'_满足

+   （1）_R'_是自反的(对称的、可传递的);

+   （2）\( R' \supseteq R \)

+   （3）对于任何自反的(对称的、可传递的)关系\( R'' \)，如果\( R'' \supseteq R \)，则\( R'' \supseteq R' \)

则称关系 \( R' \) 为_R_的自反的(对称的，可传递的)闭包。并用_r_(_R_)表示的_R_自反闭包，用_s_(_R_)表示_R_的对称闭包，用_t_(_R_)表示_R_的可传递闭包。
