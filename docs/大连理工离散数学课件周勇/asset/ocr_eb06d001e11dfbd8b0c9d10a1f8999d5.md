# 量词交换式

+   1. $B_1\quad (\forall x)(\forall y)P(x,y) \Leftrightarrow (\forall y)(\forall x)P(x,y)$
+   2. $B_2\quad (\forall x)(\forall y)P(x,y) \Rightarrow (\exists y)(\forall x)P(x,y)$
+   3. $B_3\quad (\forall y)(\forall x)P(x,y) \Rightarrow (\exists x)(\forall y)P(x,y)$
+   4. $B_4\quad (\exists y)(\forall x)P(x,y) \Rightarrow (\forall x)(\exists y)P(x,y)$
+   5. $B_5\quad (\exists x)(\forall y)P(x,y) \Rightarrow (\forall y)(\exists x)P(x,y)$
+   6. $B_6\quad (\forall x)(\exists y)P(x,y) \Rightarrow (\exists y)(\exists x)P(x,y)$
+   7. $B_7\quad (\forall y)(\exists x)P(x,y) \Rightarrow (\exists x)(\exists y)P(x,y)$
+   8. $B_8\quad (\exists x)(\exists y)P(x,y) \Leftrightarrow (\exists y)(\exists x)P(x,y)$
