# # 真值表

+   - 设\(A\)为一命题公式，对其中出现的命题变元做所有可能的每一组真值指派\(S\)，连同公式\(A\)相应\(\mathcal{S}(A)\)的取值汇列成表，称为\(A\)的真值表。

+   - 给出命题公式 \(\neg((P \lor Q) \land P)\) 的真值表

| P | Q | \(P \lor Q\) | \((P \lor Q) \land P\) | \(\neg((P \lor Q) \land P)\) |
|---|---|-------------|----------------------|------------------------------|
| 0 | 0 | 0           | 0                    | 1                            |
| 0 | 1 | 1           | 0                    | 1                            |
| 1 | 0 | 1           | 1                    | 0                            |
| 1 | 1 | 1           | 1                    | 0                            |
