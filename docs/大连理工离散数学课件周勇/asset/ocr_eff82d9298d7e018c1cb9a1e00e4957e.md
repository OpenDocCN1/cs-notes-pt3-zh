# # 同类型与同种代数系统

# ## 定义9.7

(1) 如果两个代数系统中运算的个数相同，对应运算的元数相同，且代数常数的个数也相同，则称它们是**同类型的代数系统**。

(2) 如果两个同类型的代数系统规定的运算性质也相同，则称为**同种的代数系统**。

例如 \( V_1=<\mathbf{R}, +, \cdot, 0, 1> \)，\( V_2=<\{0,1\}, \lor, \land, 0, 1>, \theta \) 为 \( n \) 阶全0矩阵，\( E \) 为 \( n \) 阶单位矩阵，\( V_3=<P(B), \cup, \cap, \emptyset, B> \)

+   - \( V_1, V_2, V_3 \) 是同类型的代数系统，它们都含有2个二元运算，2个代数常数。

+   - \( V_2, V_3 \) 是同种的代数系统，\( V_2, V_3 \) 与 \( V_1 \) 不是同种的代数系统
