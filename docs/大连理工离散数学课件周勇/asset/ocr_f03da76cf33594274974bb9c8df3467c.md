# 一、相交运算

试证明 $(A\cap B)\cap C=A\cap(B\cap C)$。

证明：
\[
\begin{aligned}
(A\cap B)\cap C
&=\{x\mid x\in A\cap B\land x\in C\}\\
&=\{x\mid x\in A\land x\in B\land x\in C\}\\
&=\{x\mid x\in A\land(x\in B\land x\in C)\}\\
&=\{x\mid x\in A\land x\in B\cap C\}\\
&=\{x\mid x\in A\land x\in B\cap C\}
\end{aligned}
\]

类推至多个集合的情况，集合的交运算仍满足结合律。

假设有 $n$ 个集合 $A_1,A_2,\cdots,A_n$，那么这些集合的交集可表示为：

\[
P=A_1\cap A_2\cap\cdots\cap A_n
\]
\[
=\bigcap_{i=1}^{n}A_i
\]
