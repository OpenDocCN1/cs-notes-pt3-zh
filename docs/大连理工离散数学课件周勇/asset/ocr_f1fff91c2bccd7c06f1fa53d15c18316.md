# # 分配格的判别及性质

定理8.5 设 \( L \) 是格，则 \( L \) 是分配格当且仅当 \( L \) 不含有与钻石格或五角格同构的子格。

证明省略。

推论 (1) 小于五元的格都是分配格。

(2) 任何一条链都是分配格。

例6 说明图中的格是否为分配格，为什么？

解 都不是分配格。
{ \( a,b,c,d,e \) } 是 \( L_1 \) 的子格，同构于钻石格
{ \( a,b,c,e,f \) } 是 \( L_2 \) 的子格，同构于五角格；
{ \( a,c,b,e,f \) } 是 \( L_3 \) 的子格同构于钻石格。
