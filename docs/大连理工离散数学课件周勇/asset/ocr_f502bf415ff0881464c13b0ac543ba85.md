# # 量词转换律

¬(∀x)(A(x)) ⇔ (∃x)¬A(x)

¬(∃x)(A(x)) ⇔ (∀x)¬A(x) （其中A(x)是任意的公式）

# ## 证明

设个体域 \( E = \{ a_1, a_2, \cdots, a_n \} \) ,则

¬∀xA(x) ⇔ ¬(A(a₁) ∧ A(a₂) ∧ .... ∧ A(aₙ))

⇔ ¬A(a₁) ∨ ¬A(a₂) ∨ .... ∨ ¬A(aₙ)

⇔ ∃x¬A(x)

¬∃xA(x) ⇔ ¬(A(a₁) ∨ A(a₂) ∨ .... ∨ A(aₙ))

⇔ ¬A(a₁) ∧ ¬A(a₂) ∧ .... ∧ ¬A(aₙ)

⇔ ∀x¬A(x)
