# # 特殊函数

（2）合成函数g ∘ f: X→Z。设x<sub>i</sub>,x<sub>j</sub>∈X和x<sub>i</sub>≠x<sub>j</sub>。因为g ∘ f是单射的，所以应有
(x<sub>i</sub> ≠ x<sub>j</sub>) ⇒ (g ∘ f)(x<sub>i</sub>) ≠ (g ∘ f)(x<sub>j</sub>)
⇔ g(f(x<sub>i</sub>)) ≠ g(f(x<sub>j</sub>))
因为g是函数，所以象点不同时，原象一定不相同，即
g(f(x<sub>i</sub>)) ≠ g(f(x<sub>j</sub>)) ⇒ f(x<sub>i</sub>) ≠ f(x<sub>j</sub>)
根据永真蕴含关系的可传递性，应有
(x<sub>i</sub> ≠ x<sub>j</sub>) ⇒ f(x<sub>i</sub>) ≠ f(x<sub>j</sub>)
得证。
由（1）和（2）可知（3）成立。
