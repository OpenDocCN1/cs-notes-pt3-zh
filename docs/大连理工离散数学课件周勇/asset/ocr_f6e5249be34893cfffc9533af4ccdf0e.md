# # 典型子群的实例:子群的交

例: 设G是群, H,K是G的子群. 证明

(1) H∩K也是G的子群

(2) H∪K是G的子群当且仅当 H⊆K 或 K⊆H

证 (1) 由 e∈H∩K 知 H∩K 非空.

任取a, b∈H∩K, 则a∈H, a∈K, b∈H, b∈K.

必有ab^{-1}∈H 和 ab^{-1}∈K, 从而ab^{-1}∈H∩K. 因此H∩K≤G.

(2) 充分性显然, 只证必要性. 用反证法.

假设 H⊈K 且 K⊈H, 那么存在 h 和 k 使得

h∈H∧h∉K, k∈K∧k∉H

推出 hk ∉H. 否则由h^{-1}∈H 得 k=h^{-1}(hk)∈H, 与假设矛盾.

同理可证 hk ∉K. 从而得到 hk ∉H∪K. 与H∪K是子群矛盾.
