# # 四、对称差分运算

所以，\((A \oplus B) \oplus C\)
\(= (A \cap \sim B \cap \sim C) \cup (\sim A \cap B \cap \sim C) \cup (\sim A \cap \sim B \cap C)\)
\(\cup (A \cap B \cap C)\)

又因为，\(A \oplus (B \oplus C)\)
\(= (A \cap \sim (B \oplus C)) \cup (\sim A \cap (B \oplus C))\)
\(= (A \cap \sim ((B \cap \sim C) \cup (\sim B \cap C))) \cup (\sim A \cap ((B \cap \sim C) \cup (\sim B \cap C)))\)
\(= (A \cap (\sim B \cup C) \cap (B \cup \sim C)) \cup (\sim A \cap B \cap \sim C \cup \sim A \cap \sim B \cap C)\)
\(= A \cap \sim B \cap B \cup A \cap \sim B \cap \sim C \cup A \cap B \cap C \cup A \cap C \cap \sim C \cup \sim A \cap B \cap \sim C \cup \sim A \cap \sim B \cap C\)
\(= A \cap \sim B \cap \sim C \cup A \cap B \cap C \cup \sim A \cap B \cap \sim C \cup \sim A \cap \sim B \cap C\)

得证\((A \oplus B) \oplus C = A \oplus (B \oplus C)\)
