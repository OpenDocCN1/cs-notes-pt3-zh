# 路径和回路

**定理：** 设$v$和$v'$是图$G$中的结点。如果存在从$v$至$v'$的路径，则存在从$v$至$v'$的基本路径。

**证：** 设当从$v$至$v'$存在长度小于$l$的路径时，从$v$至$v'$必存在基本路径。
如果存在路径$v_0e_1v_1\cdots v_{l-1}e_lv_l$，其中$v_0=v,v_l=v'$，并且有$i$和$j$满足$0\leq i<j\leq l$且$v_i=v_j$，则$v_0e_1v_1\cdots v_i e_{j+1}v_{j+1}\cdots v_{l-1}e_lv_l$是从$v$至$v'$的长度为$l-j+i$的路径。根据归纳假设，存在从$v$至$v'$的基本路径。
