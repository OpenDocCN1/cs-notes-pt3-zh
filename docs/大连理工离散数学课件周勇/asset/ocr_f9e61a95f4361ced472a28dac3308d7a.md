# 反证法举例

**例5：**给定前提 $(\forall x)(A(x)\lor B(x))$，$(\forall x)(B(x)\to\neg C(x))$，$(\forall x)C(x)$，试推出结论：$(\forall x)A(x)$

# 证明：

| 步骤 | 公式 | 依据 |
|---|---|---|
| (1) | $\neg(\forall x)A(x)$ | $P$（假设前提） |
| (2) | $(\exists x)\neg A(x)$ | $T,(1)$ |
| (3) | $\neg A(a)$ | $ES,(2)$ |
| (4) | $(\forall x)(A(x)\lor B(x))$ | $P$ |
| (5) | $A(a)\lor B(a)$ | $US,(4)$ |
| (6) | $B(a)$ | $T,(3),(5)$ |
| (7) | $(\forall x)(B(x)\to\neg C(x))$ | $P$ |
| (8) | $B(a)\to\neg C(a)$ | $US,(7)$ |
| (9) | $\neg C(a)$ | $T,(6),(8)$ |
| (10) | $(\forall x)C(x)$ | $P$ |
