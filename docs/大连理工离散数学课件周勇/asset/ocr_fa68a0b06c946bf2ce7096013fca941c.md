# 二、关系矩阵

**例：** 设 $A=\{1,2,3\}$，$B=\{a,b,c\}$，$R$ 是 $A$ 到 $B$ 的二元关系，并且 $R=\{\langle1,a\rangle,\langle2,b\rangle,\langle3,c\rangle\}$，试画出 $R$ 的关系图，给出关系矩阵。

$$M_R=[r_{ij}]_{6\times6}=\begin{array}{c|cccccc}&1&2&3&a&b&c\\\hline 1&0&0&0&1&0&0\\ 2&0&0&0&0&1&0\\ 3&0&0&0&0&0&1\\ a&0&0&0&0&0&0\\ b&0&0&0&0&0&0\\ c&0&0&0&0&0&0\end{array}$$
