# 请问逻辑求解实际问题

$\forall x(P(x)\to S(x)),\ \neg\exists x(Q(x)\land R(x)),$

$\forall x(\neg R(x)\to \neg S(x))\Rightarrow \forall x(P(x)\to \neg Q(x))$

证明：

| 步骤 | 公式 | 依据 |
|---|---|---|
| (1) | $\forall x(P(x)\to S(x))$ | $P$ |
| (2) | $P(x)\to S(x)$ | $US,(1)$ |
| (3) | $\forall x(\neg R(x)\to \neg S(x))$ | $P$ |
| (4) | $\neg R(x)\to \neg S(x)$ | $US,(3)$ |
| (5) | $S(x)\to R(x)$ | $T,(4)$ |
| (6) | $\neg\exists x(Q(x)\land R(x))$ | $P$ |
| (7) | $\forall x(\neg Q(x)\lor \neg R(x))$ | $T,(6)$ |
| (8) | $\neg Q(x)\lor \neg R(x)$ | $US,(7)$ |
| (9) | $R(x)\to \neg Q(x)$ | $T,(8)$ |
| (10) | $P(x)\to R(x)$ | $T,(2)(5)$ |
| (11) | $P(x)\to \neg Q(x)$ | $T,(10)(9)$ |
| (12) | $\forall x(P(x)\to \neg Q(x))$ | $UG,(11)$ |
