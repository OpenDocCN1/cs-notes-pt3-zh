# 谓词逻辑中的推理

例2：试证明

$(\forall x)(P(x)\to Q(x)),\ (\forall x)(Q(x)\to R(x))\Rightarrow(\forall x)(P(x)\to R(x))$

# 证明：

+   1. $(\forall x)(P(x)\to Q(x))$　　　　　　　　　　　　　　　　　$P$
+   2. $P(x)\to Q(x)$　　　　　　　　　　　　　　　　　　　　$US,(1)$
+   3. $(\forall x)(Q(x)\to R(x))$　　　　　　　　　　　　　　　　$P$
+   4. $Q(x)\to R(x)$　　　　　　　　　　　　　　　　　　　　$US,(3)$
+   5. $P(x)\to R(x)$　　　　　　　　　　　　　　　　　　　　$T,(2),(4)$
+   6. $(\forall x)(P(x)\to R(x))$　　　　　　　　　　　　　　　　$UG,(5)$
