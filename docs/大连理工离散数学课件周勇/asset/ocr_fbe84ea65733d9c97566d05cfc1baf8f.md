# 证明

(2) 只须证明：对任何正整数 r (r≤n),
a^r 是 G 的生成元 ⇔ n 和 r 互素.

充分性. 设 r 和 n 互素, 且 r≤n, 那么存在整数 u 和 v 使得
ur + vn = 1

从而 a = a^{ur+vn} = (a^r)^u (a^n)^v = (a^r)^u

这就推出 ∀k a^k ∈ G, a^k = (a^r)^{uk} ∈ <a^r>, 即 G ⊆ <a^r>.

另一方面, 显然有 <a^r> ⊆ G. 从而 G = <a^r>.

必要性. 设 a^r 是 G 的生成元, 则 |a^r| = n. 令 r 和 n 的最大公约数为 d, 则存在正整数 t 使得 r = dt. 因此, |a^r| 是 n/d 的因子, 即 n 整除 n/d. 从而证明了 d = 1.
