# 3.2 集合的运算

## 一、相交运算

定义：由集合 $A$ 和 $B$ 的所有公共元素所组成的集合，称为集合 $A$ 和 $B$ 的交集。记作 $A\cap B$

$$A\cap B=\{x\mid x\in A\land x\in B\}$$

例如：设 $A=\{a,b,c,d\}$，$B=\{d,f,a\}$，$C=\{e,f,g\}$

- 则
  - $A\cap B=\{a,d\}$
  - $B\cap C=\{f\}$
  - $A\cap C=\varnothing$

可以看出

$$A\cap B\subseteq A,\ A\cap B\subseteq B$$

![](img/d475a943ed426379b80e793b9fe1f17d_265_0.png)

设 A ⊆ B, 求证A∩C ⊆ B∩C.

证明：若 x∈A则 x∈B 对任一 x∈A∩C 则 x∈A ， 即x∈C且 x∈B ，因此∈B∩C 。
A∩C ⊆ B∩C

- (a) A ∩ A = A
- (b) A ∩ ∅ = ∅
- (c) A ∩ E = A
- (d) A ∩ B = B ∩ A
- (e) (A∩B)∩C = A∩(B∩C)

![](img/d475a943ed426379b80e793b9fe1f17d_266_0.png)

试证明 $(A\cap B)\cap C=A\cap(B\cap C)$。

证明：
\[
\begin{aligned}
(A\cap B)\cap C
&=\{x\mid x\in A\cap B\land x\in C\}\\
&=\{x\mid x\in A\land x\in B\land x\in C\}\\
&=\{x\mid x\in A\land(x\in B\land x\in C)\}\\
&=\{x\mid x\in A\land x\in B\cap C\}\\
&=\{x\mid x\in A\land x\in B\cap C\}
\end{aligned}
\]

类推至多个集合的情况，集合的交运算仍满足结合律。

假设有 $n$ 个集合 $A_1,A_2,\cdots,A_n$，那么这些集合的交集可表示为：

\[
P=A_1\cap A_2\cap\cdots\cap A_n
\]
\[
=\bigcap_{i=1}^{n}A_i
\]

## 二、联合运算（集合的并）

定义：由集合 \(A\) 和 \(B\) 的所有元素组成的集合称为 \(A\) 和 \(B\) 的并集，记作 \(A \cup B\)

\(A \cup B = \{x \mid x \in A \lor x \in B\}\)

**例如** 设 \(A = \{a, b, c\}\), \(B = \{c, d, f\}\), \(C = \{b, e\}\)

那么 \(A \cup B = \{a, b, c, d, f\}\)

\(A \cup C = \{a, b, c, e\}\)

\(B \cup C = \{b, c, d, e, f\}\)

可以看出 \(A \subseteq A \cup B\), \(B \subseteq A \cup B\)

![](img/d475a943ed426379b80e793b9fe1f17d_268_0.png)

## 二、集合的并

### 集合的并运算具有如下性质：

- \( A \cup A = A \)
- \( A \cup E = E \)
- \( A \cup \varnothing = A \)
- \( A \cup B = B \cup A \)
- \( (A \cup B) \cup C = A \cup (B \cup C) \)

**注意：** 假设有 \( n \) 个集合 \( A_1, A_2, \dots, A_n \)，那么这些集合的并集可表示为：

\( W = A_1 \cup A_2 \cup \dots \cup A_n \)

\( = \bigcup_{i=1}^{n} A_i \)

## 二、集合的并

例1：假设 \( A \subseteq B, C \subseteq D \)，则 \( A \cup C \subseteq B \cup D \).

证明：对任意 \( x \in A \cup C \)，有 \( x \in A \lor x \in C \)，

若 \( x \in A \)，由 \( A \subseteq B \) 可得 \( x \in B \)，故 \( x \in B \cup D \);

若 \( x \in C \)，由 \( C \subseteq D \) 可得 \( x \in D \)，故 \( x \in B \cup D \).

因此，\( A \cup C \subseteq B \cup D \)

## 二、集合的并

例：设 \( A, B, C \) 为三个集合，那么

- (a) \( A \cap (B \cup C) = (A \cap B) \cup (A \cap C) \)
- (b) \( A \cup (B \cap C) = (A \cup B) \cap (A \cup C) \)

证明：对于任意的 \( x \)，若

\( x \in A \cap (B \cup C) \)

\(\Leftrightarrow x \in A \wedge x \in B \cup C \)

\(\Leftrightarrow x \in A \wedge (x \in B \lor x \in C) \)

\(\Leftrightarrow (x \in A \wedge x \in B) \lor (x \in A \wedge x \in C) \)

\(\Leftrightarrow x \in A \cap B \lor x \in A \cap C \)

\(\Leftrightarrow x \in (A \cap B) \cup (A \cap C) \)

由 \( x \) 的任意性可知 (a) 成立。

同理可以证明 (b)。

# 关于交集、并集的例子

老师讲完交集、并集的概念之后，提问学生：

- （1）设A={x｜x是参加百米赛跑的同学}，B={x｜x是参加跳高比赛的同学}，求A∩B。
- （2）设A={x｜x是红星农场的汽车}，B={x｜x是红星农场的拖拉机}，求A∪B。

一学生答道：

- （1）中A∩B={x｜x是参加百米障碍赛的同学}。
- （2）中A∪B={x｜x是红星农场的联合收割机}。

# 三、差分运算（集合的补）

设A,B是两个集合，所有属于A而不属于B的元素的组成的集合，称为A和B的差集或B对A的相对补集。记作A-B

```
A - B = {x | x ∈ A ∧ x ∉ B}
```

绝对补集：B对E的相对补集叫做绝对补集，简称补集，记作~B
