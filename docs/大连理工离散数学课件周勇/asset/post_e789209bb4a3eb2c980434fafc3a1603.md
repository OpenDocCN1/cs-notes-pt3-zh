
## 三、差分运算（集合的补）

集合的差分运算还具有如下性质：

- (a) \(\sim(\sim A)=A\)
- (b) \(\sim E=\varnothing\)
- (c) \(A\cup\sim A=E\)
- (d) \(A\cap\sim A=\varnothing\)

![](img/d475a943ed426379b80e793b9fe1f17d_280_0.png)

**定理 3.2-4**：设 \(A,B\) 为任意两个集合，则下列关系式成立。

- (a) \(\sim(A\cup B)=\sim A\cap\sim B\)
- (b) \(\sim(A\cap B)=\sim A\cup\sim B\)

证明：(a)

\[
\begin{aligned}
\sim(A\cup B)&=\{x\mid x\in\sim(A\cup B)\}\\
&=\{x\mid x\notin A\cup B\}\\
&=\{x\mid \neg(x\in A\cup B)\}\\
&=\{x\mid \neg(x\in A\lor x\in B)\}\\
&=\{x\mid \neg(x\in A)\land\neg(x\in B)\}\\
&=\{x\mid x\in\sim A\land x\in\sim B\}\\
&=\{x\mid x\in\sim A\cap\sim B\}\\
&=\sim A\cap\sim B
\end{aligned}
\]

**定理 3.2-5**：设 \(A,B\) 为任意两个集合，则下列关系式成立。

- (a) \(A-B=A\cap\sim B\)
- (b) \(A-B=A-(A\cap B)\)

证明：(b) 设 \(x\in A-B\)，即 \(x\in A\) 且 \(x\notin B\)。因为 \(x\notin B\)，则必有 \(x\notin A\cap B\)，故有 \(x\in A-(A\cap B)\)，即

\[
A-B\subseteq A-(A\cap B).
\]

设 \(x\in A-(A\cap B)\)，则 \(x\in A\) 且 \(x\notin A\cap B\)，即 \(x\in A\)，且（\(x\notin A\) 或 \(x\notin B\)）。显然只能 \(x\notin B\) 成立，即 \(x\in A-B\)。故

\[
A-(A\cap B)\subseteq A-B.
\]

**定理 3.2-6**：设 \(A,B,C\) 为任意三个集合，则下列关系式成立。

\[
A\cap(B-C)=(A\cap B)-(A\cap C)
\]

证：

\[
\begin{aligned}
A\cap(B-C)&=A\cap(B\cap\sim C)\\
&=A\cap B\cap\sim C
\end{aligned}
\]

又

\[
\begin{aligned}
(A\cap B)-(A\cap C)&=(A\cap B)\cap\sim(A\cap C)\\
&=(A\cap B)\cap(\sim A\cup\sim C)\\
&=(A\cap B\cap\sim A)\cup(A\cap B\cap\sim C)\\
&=A\cap B\cap\sim C
\end{aligned}
\]

因此，\(A\cap(B-C)=(A\cap B)-(A\cap C)\)。

**定理 3.2-7**：设 \(A,B\) 是任意两个集合，若 \(A\subseteq B\)，则

- (a) \(\sim B\subseteq\sim A\)
- (b) \((B-A)\cup A=B\)

证：(a) 若 \(x\in A\)，则 \(x\in B\)；因此，若 \(x\notin B\)，必有 \(x\notin A\)。即若 \(x\in\sim B\)，则 \(x\in\sim A\)，即 \(\sim B\subseteq\sim A\)。

证：(b)

\[
\begin{aligned}
(B-A)\cup A&=(B\cap\sim A)\cup A\\
&=(B\cup A)\cap(\sim A\cup A)\\
&=(B\cup A)\cap E\\
&=B\cup A
\end{aligned}
\]

因为 \(A\subseteq B\)，所以 \(B\cup A=B\)。(b) 得证。

## 四、对称差分运算

定义：设 \(A\)、\(B\) 为任意两个集合。属于 \(A\) 但不属于 \(B\) 的所有元素和属于 \(B\) 但不属于 \(A\) 的所有元素的并集，称为 \(A\) 和 \(B\) 的**对称差集**，记作 \(A\oplus B\)。

\[
\begin{aligned}
A\oplus B&=(A-B)\cup(B-A)\\
&=(A\cap\sim B)\cup(B\cap\sim A)\\
&=(A\cup B)-(A\cap B)
\end{aligned}
\]

**例如：** \(A=\{1,2,3\}\)，\(B=\{3,2,4\}\)，则 \(A\oplus B=\{1,4\}\)。

![](img/d475a943ed426379b80e793b9fe1f17d_285_0.png)

求证 \((A\oplus B)\oplus C=A\oplus(B\oplus C)\)。

证：

\[
\begin{aligned}
(A\oplus B)\oplus C&=((A\oplus B)\cap\sim C)\cup(\sim(A\oplus B)\cap C)\\
&=(((A\cap\sim B)\cup(\sim A\cap B))\cap\sim C)\\
&\quad\cup(\sim((A\cap\sim B)\cup(\sim A\cap B))\cap C)\\
&=A\cap\sim B\cap\sim C\cup\sim A\cap B\cap\sim C\\
&\quad\cup(\sim A\cup B)\cap(A\cup\sim B)\cap C
\end{aligned}
\]

由于

\[
\begin{aligned}
(\sim A\cup B)\cap(A\cup\sim B)\cap C
&=(((\sim A\cup B)\cap A)\cup((\sim A\cup B)\cap\sim B))\cap C\\
&=(((\sim A\cap A)\cup(A\cap B)\cup(\sim A\cap\sim B)\cup(B\cap\sim B))\cap C\\
&=(\varnothing\cup(A\cap B)\cup(\sim A\cap\sim B)\cup\varnothing)\cap C\\
&=(A\cap B\cap C)\cup(\sim A\cap\sim B\cap C)
\end{aligned}
\]

所以，

\[
\begin{aligned}
(A\oplus B)\oplus C&=(A\cap\sim B\cap\sim C)\cup(\sim A\cap B\cap\sim C)\\
&\quad\cup(\sim A\cap\sim B\cap C)\cup(A\cap B\cap C)
\end{aligned}
\]

又因为，

\[
\begin{aligned}
A\oplus(B\oplus C)&=(A\cap\sim(B\oplus C))\cup(\sim A\cap(B\oplus C))\\
&=(A\cap\sim((B\cap\sim C)\cup(\sim B\cap C)))\\
&\quad\cup(\sim A\cap((B\cap\sim C)\cup(\sim B\cap C)))\\
&=(A\cap(\sim B\cup C)\cap(B\cup\sim C))\\
&\quad\cup(\sim A\cap B\cap\sim C\cup\sim A\cap\sim B\cap C)\\
&=A\cap\sim B\cap B\cup A\cap\sim B\cap\sim C\cup A\cap B\cap C\\
&\quad\cup A\cap C\cap\sim C\cup\sim A\cap B\cap\sim C\cup\sim A\cap\sim B\cap C\\
&=A\cap\sim B\cap\sim C\cup A\cap B\cap C\\
&\quad\cup\sim A\cap B\cap\sim C\cup\sim A\cap\sim B\cap C
\end{aligned}
\]

得证 \((A\oplus B)\oplus C=A\oplus(B\oplus C)\)。

## 集合定律

- \(S_1\quad A\cap B\subseteq A\)
- \(S_2\quad A\cap B\subseteq B\)
- \(S_3\quad A\subseteq A\cup B\)
- \(S_4\quad B\subseteq A\cup B\)
- \(S_5\quad A-B\subseteq A\)
- \(S_6\quad A\oplus B\subseteq A\cup B\)

- \(S_7\quad A\cup B=B\cup A\)
- \(S_8\quad A\cap B=B\cap A\)
- \(S_9\quad A\oplus B=B\oplus A\)

- 交换律

- \(S_{10}\quad A\cup(B\cup C)=(A\cup B)\cup C\)
- \(S_{11}\quad (A\cap B)\cap C=A\cap(B\cap C)\)
- \(S_{12}\quad (A\oplus B)\oplus C=A\oplus(B\oplus C)\)

- 结合律
