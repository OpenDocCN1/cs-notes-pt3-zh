# Analysis of Prim

```
Θ(|V|) total
Q ← V
key[v] ← ∞ for all v ∈ V
key[s] ← 0 for some arbitrary s ∈ V
while Q ≠ ∅
|V| times
do u ← EXTRACT-MIN(Q)
|V| times degree(u) times
for each v ∈ Adj[u]
do if v ∈ Q and w(u, v) < key[v]
then key[v] ← w(u, v)
π[v] ← u
```

Handshaking Lemma ⇒ Θ(E) implicit DECREASE-KEY’s.
