# MERGE-SORT $A[1..n]$

+   1. If $n=1$, done.
+   2. Recursively sort $A[1..\lfloor n/2\rfloor]$ and $A[\lfloor n/2\rfloor+1..n]$.
+   3. “Merge” the 2 sorted lists

**Sloppiness:** Should be $T(\lceil n/2\rceil)+T(\lfloor n/2\rfloor)$, but it turns out not to matter asymptotically.
