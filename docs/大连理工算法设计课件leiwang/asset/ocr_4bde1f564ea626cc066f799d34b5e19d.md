# # Correctness of BFS

```
while Q ≠ ∅
    do u ← DEQUEUE(Q)
       for each v ∈ Adj[u]
           do if d[v] = ∞
                  then d[v] ← d[u] + 1
                       ENQUEUE(Q, v)
```

# Key idea:

The FIFO Q in breadth-first search mimics the priority queue Q in Dijkstra.

+   - **Invariant:** v comes after u in Q implies that d[v] = d[u] or d[v] = d[u] + 1.
