# # Paths in graphs

Consider a digraph \( G = (V, E) \) with edge-weight function \( w : E \rightarrow \mathbb{R} \). The **weight** of path \( p = v_1 \rightarrow v_2 \rightarrow \cdots \rightarrow v_k \) is defined to be

\( w(p) = \sum_{i=1}^{k-1} w(v_i, v_{i+1}) \).
