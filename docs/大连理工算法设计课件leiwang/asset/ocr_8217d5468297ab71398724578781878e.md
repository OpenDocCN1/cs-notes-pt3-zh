# # Search cost

The expected time for an **unsuccessful** search for a record with a given key is = Θ(1 + α). **search the list apply hash function and access slot**

Expected search time = Θ(1) if α = O(1), or equivalently, if n = O(m).

A **successful** search has same asymptotic bound, but a rigorous argument is a little more complicated. (See textbook.)
