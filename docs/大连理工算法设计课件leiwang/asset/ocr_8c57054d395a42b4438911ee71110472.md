# # o-notation and ω-notation

O-notation and Ω-notation are like ≤ and ≥.
o-notation and ω-notation are like < and >.

\(\omega(g(n)) = \{ f(n) : \text{for any constant } c > 0,\text{there is a constant } n_0 > 0\text{such that } 0 \le cg(n) < f(n)\text{for all } n \ge n_0 \}\)

**EXAMPLE:** \(\sqrt{n} = \omega(\lg n)\quad (n_0 = 1+1/c)\)
