# Strassen’s idea

+   • Multiply 2×2 matrices with only 7 recursive mults.

$$P_1=a\cdot(f-h)$$
$$P_2=(a+b)\cdot h$$
$$P_3=(c+d)\cdot e$$
$$P_4=d\cdot(g-e)$$
$$P_5=(a+d)\cdot(e+h)$$
$$P_6=(b-d)\cdot(g+h)$$
$$P_7=(a-c)\cdot(e+f)$$

$$r=P_5+P_4-P_2+P_6$$
$$s=P_1+P_2$$
$$t=P_3+P_4$$
$$u=P_5+P_1-P_3-P_7$$
