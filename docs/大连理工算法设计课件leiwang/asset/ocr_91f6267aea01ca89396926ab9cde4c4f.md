# # Proof of claim

$d_{ij}^{(m)}=\min_k\{d_{ik}^{(m-1)}+a_{kj}\}$

**Relaxation!**

for $k\leftarrow 1$ to $n$

do if $d_{ij}>d_{ik}+a_{kj}$

then $d_{ij}\leftarrow d_{ik}+a_{kj}$

**Note:** No negative-weight cycles implies

$\delta(i,j)=d_{ij}^{(n-1)}=d_{ij}^{(n)}=d_{ij}^{(n+1)}=\cdots$
