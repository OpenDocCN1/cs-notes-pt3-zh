# Analysis of the hiring problem

Assume that the candidates arrive in a random order. Let X be a random variable that equals the number of times we hire a new office assistant. Define indicator random variables X₁, X₂, ..., Xₙ, where Xᵢ = I{candidate i is hired}.



+   • X = X₁ + X₂ + ⋯ + Xₙ.

+   • Lemma ⇒ E[Xᵢ] = Pr(candidate i is hired).

+   • Pr(candidate i is the best so far) = 1/i, which implies E[Xᵢ] = 1/i.

+   • we get E[X] = E[∑_{i=1}^n X_i] = ∑_{i=1}^n E[X_i] = ∑_{i=1}^n 1/i ≈ ln n + O(1)
+   ⇒ the expected hiring cost is O(c_h ln n), much better than O(c_h n).
