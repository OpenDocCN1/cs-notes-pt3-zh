# # The sorting problem

**Input:** A sequence of \( n \) numbers \( \langle a_1, a_2, \ldots, a_n \rangle \).

**Output:** A permutation (reordering) \( \langle a'_1, a'_2, \ldots, a'_n \rangle \) of the input sequence such that \( a'_1 \leq a'_2 \leq \cdots \leq a'_n \).
