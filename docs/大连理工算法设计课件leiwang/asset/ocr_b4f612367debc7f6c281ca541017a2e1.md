# # Strassen's algorithm

+   1. **Divide**: Partition _A_ and _B_ into
+   (_n/_2)×(_n/_2) submatrices. Form terms
+   to be multiplied using + and - .

+   2. **Conquer**: Perform 7 multiplications of
+   (_n/_2)×(_n/_2) submatrices recursively.

+   3. **Combine**: Form _C_ using + and - on
+   (_n/_2)×(_n/_2) submatrices.

\(T(n) = 7 T(n/2) + \Theta(n^2)\)
