# # Analysis of expected time

The analysis follows that of randomized
quicksort, but it’s a little different.

Let _T_(_n_) = the random variable for the running
time of RAND-SELECT on an input of size _n_,
assuming random numbers are independent.

For _k_ = 0, 1, ..., _n_-1, define the **indicator**
**random variable**

\(X_k = \left\{ \begin{array}{ c c }
1 & \text{if PARTITION generates a } k : n-k-1 \text{ split,} \\
0 & \text{otherwise.}
\end{array}\right.\)
