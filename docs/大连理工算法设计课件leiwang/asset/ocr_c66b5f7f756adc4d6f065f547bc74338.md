# # Direct-access table

**IDEA:** Suppose that the keys are drawn from
the set \( U \subseteq \{0, 1, \dots, m-1\} \), and keys are
distinct. Set up an array \( T[0 \dots m-1] \):

\( T[k] = \begin{cases} x & \text{if } x \in K \text{ and } key[x] = k, \\ \text{NIL} & \text{otherwise.} \end{cases} \)

Then, operations take \( \Theta(1) \) time.

**Problem:** The range of keys can be large:
• 64-bit numbers (which represent
18,446,744,073,709,551,616 different keys),
• character strings (even larger!).
