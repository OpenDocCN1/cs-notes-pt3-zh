# # Proof (continued)

+   - We have $h' \ge h/2$, since at most half the leaves on any path are red.
+   - The number of leaves in each tree is $n+1$
+     - $\Rightarrow n+1 \ge 2^{h'}$
+     - $\Rightarrow \lg(n+1) \ge h' \ge h/2$
+     - $\Rightarrow h \le 2\lg(n+1)$.
