# # Example of open addressing

Search for key \( k = 496 \):
0. Probe \( h(496,0) \)
1. Probe \( h(496,1) \)
2. Probe \( h(496,2) \)

Search uses the same probe sequence, terminating successfully if it finds the key and unsuccessfully if it encounters an empty slot.
