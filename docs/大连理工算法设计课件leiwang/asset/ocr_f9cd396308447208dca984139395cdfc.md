# Recursive algorithm for LCS

```
$$\begin{aligned}
\mathrm{LCS}(x,y,i,j)\\
\quad\textbf{if }x[i]=y[j]\\
\qquad\textbf{then }c[i,j]\leftarrow \mathrm{LCS}(x,y,i-1,j-1)+1\\
\qquad\textbf{else }c[i,j]\leftarrow \max\{\mathrm{LCS}(x,y,i-1,j),\\
\hspace{6.7em}\mathrm{LCS}(x,y,i,j-1)\}
\end{aligned}$$
```
