# 2.2 词法记号的描述与识别

# 语言的运算

+   - 和：$L \cup M = \{s \mid s \in L \text{ 或 } s \in M\}$
+   - 连接：$LM = \{st \mid s \in L 且 t \in M\}$
+   - 指数：$L^0 = \{\varepsilon\}$，$L^i = L^{i-1}L$
+   - 闭包：$L^* = L^0 \cup L^1 \cup L^2 \cup \cdots$
+   - 正闭包：$L^+ = L^1 \cup L^2 \cup \cdots$
