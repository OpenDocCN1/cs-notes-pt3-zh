# # 3.5 LR分析器

| 栈    | 输入    | 动作    |
|---|---|---|
| 0    | id * id + id$    | 移进    |
| 0 id 5 | * id + id$    | 按\(F \to id\)归约    |
| 0 F 3  | * id + id$    | 按\(T \to F\)归约    |
| 0 T 2  | * id + id$    | 移进    |
| 0 T 2 *7 | id + id $    | 移进    |
| 0 T 2 *7 id 5 | + id $    | 按\(F \to id\)归约    |
| 0 T 2 *7 F 10 | + id $    | 按\(T \to T*F\)归约    |
| ...    | ...    | ...    |
