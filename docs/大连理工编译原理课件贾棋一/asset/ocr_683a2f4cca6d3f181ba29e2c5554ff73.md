# ## 2.2 词法记号的描述与识别

# ### 2.2.1 串和语言

+   - 字母表/字符类：符号（英文字母、标点符号等）的有限集合， 例：\(\Sigma = \{0, 1\}\)

+   - 串：符号的有穷序列，例：\(0110, \epsilon\)

+   - 语言：字母表上的一个串集  
+     \(\{\epsilon, 0, 00, 000, \dots\}, \{\epsilon\}, \emptyset\)

+   - 句子/字：属于语言的串
