# 3.2 语言和文法

+   - $L'_3=\{a^n b^n\mid n\geq 1\}$
+     
+     $S\rightarrow aSb\mid ab$
+   
+   - $L'_3$ 是不能用正规式描述的语言的一个范例
+   
+     - 若存在接受 $L'_3$ 的 DFA $D$，状态数为 $k$ 个。
+     - 设 $D$ 读完 $\varepsilon$、$a$、$aa$、...、$a^k$ 分别到达状态 $S_0$、$S_1$、...、$S_k$。
+     - 至少有两个状态相同，例如是 $S_i$ 和 $S_j$，则 $a^i b^i$ 属于 $L'_3$。
