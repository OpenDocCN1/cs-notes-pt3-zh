# 3.4 自下而上分析

![](bbox=[0.621, 0.012, 0.999, 0.182])

| 栈 | 输入 | 动作 |
|---|---|---|
| `$` | `id₁ * id₂ + id₃$` | 移进 |
| `$ id₁` | `* id₂ + id₃$` | 按 `E → id` 归约 |
| `$E` | `* id₂ + id₃$` | 移进 |
| `$E*` | `id₂ + id₃$` | 移进 |
| `$E* id₂` | `+ id₃$` | 按 `E → id` 归约 |
| `$E*E` | `+ id₃$` | 移进 |
| `$E*E+` | `id₃$` | 移进 |
| `$E*E+id₃` | `$` | 按 `E → id` 归约 |
| `$E*E+E` | `$` | 按 `E → E+E` 归约 |
| `$E*E` | `$` |  |
