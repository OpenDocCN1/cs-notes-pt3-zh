# 4.1 语法制导的定义

# 4.1.1 语法制导定义的形式

+   - 基础文法
+   - 每个文法符号有一组属性
+   - 每个文法产生式 $A \to \alpha$ 有一种形式为 $b := f(c_1, c_2, \ldots, c_k)$ 的语义规则，其中 $f$ 是函数，$b$ 和 $c_1, c_2, \ldots, c_k$ 是该产生式文法符号的属性。

+   - 综合属性：如果 $b$ 是 $A$ 的属性，$c_1, c_2, \ldots, c_k$ 是产生式右部文法符号的属性或 $A$ 的其它属性。
+   - 继承属性：如果 $b$ 是产生式右部某个文法符号 $X$ 的属性。
+   - 以上两种情况下，都说 $b$ 依赖于属性 $c_1, c_2, \ldots, c_k$。

> 属性值由分析树中它的子结点属性值来计算

> 属性值由结点的兄弟结点及父结点的属性值来计算。
