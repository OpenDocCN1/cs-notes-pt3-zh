# # 例 数学排版语言EQN

S → {B.ps := 10 } B {S.ht := B.ht}

B → {B₁.ps := B.ps } B₁ {B₂.ps := B.ps } B₂ {B.ht := max(B₁.ht, B₂.ht ) }

B → { B₁.ps :=B.ps } B₁ sub { B₂.ps := shrink(B.ps) } B₂ {B.ht := disp (B₁.ht, B₂.ht ) }

B → text{B.ht := text.h × B.ps }

1. 产生式右边的符号的继承属性必须在先于这个符号的动作中计算出来。 2. 一个动作不能引用这个动作右边的符号的综合属性。 3. 产生式左边非终结符的综合属性只有在它所引用的所有属性都计算出来以后才能计算。计算这种属性的动作通常放在产生式右端的末尾。
