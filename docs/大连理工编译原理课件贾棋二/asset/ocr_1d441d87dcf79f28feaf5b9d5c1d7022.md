# 缓冲区溢出攻击：

```
```c
char help[10];

void foo(const char *input)
{
    char buf[10];
    int i = 0;
    for (i = 0; i < 30; i++)
    {
        if (i % 4 == 0) printf("\\n");

        sprintf(help, "%08x", buf[i]);

        printf(" %s", help+6);
    }
    printf("\\n");
}
