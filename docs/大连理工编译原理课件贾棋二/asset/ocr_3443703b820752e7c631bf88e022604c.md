# # 一般方法

假设有翻译模式：

A→A₁Y　　{A.a:=g(A₁.a,Y.y)}
A→X　　　{A.a:=f(X.x)}

它的每个文法符号都有一个综合属性，用小写字母表示，g和f是任意函数。

+   - 消除左递归：
+     - A→XR
+     - R→YR | ε

R.i：R前面子表达式的值
R.s：分析完R时子表达式的值

+   - 翻译模式变为：
+     - A → X　　{R.i:=f(X.x)}
+     - R　　　　{A.a:=R.s}
+     - R → Y　　{R₁.i:=g(R.i,Y.y)}
+     - R₁　　　 {R.s:=R₁.s}
+     - R → ε　　{R.s:=R.i}
