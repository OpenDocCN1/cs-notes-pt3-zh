# 4.2 S属性定义的自下而上计算

台式计算器的语法制导定义改成栈操作代码

![](bbox=[0.025, 0.409, 0.286, 0.91])

| 产生式 | 代码段 |
|---|---|
| `L → En` | `print(val[top-1])` |
| `E → E₁ + T` | `val[top-2] := val[top-2] + val[top]` |
| `E → T` | `E.val := T.val` |
| `T → T₁ * F` | `T.val := T₁.val * F.val` |
| `T → F` | `T.val := F.val` |
| `F → (E)` | `F.val := E.val` |
| `F → digit` | `F.val := digit.lexval` |
