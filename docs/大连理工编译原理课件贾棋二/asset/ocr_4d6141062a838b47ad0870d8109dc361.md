# ε属性的自下而上计算

# 特殊情况一：删除翻译方案中嵌入的动作

+   - `E → T R`
+   - `R → + T {print('+')} R₁ | − T {print('−')} R₁ | ε`
+   - `T → num {print(num.val)}`

在文法中加入产生ε的标记非终结符，让每个嵌入动作由不同标记非终结符 M 代表，并把该动作放在产生式 M → ε 的右端。

+   - `E → T R`
+   - `R → + T M R₁ | − T N R₁ | ε`
+   - `T → num {print(num.val)}`
+   - `M → ε {print('+')}`
+   - `N → ε {print('−')}`
