# 遇到语法错误时

+   - 从栈中弹出状态，直到发现栈顶状态的项目集包含形为 $A \to \cdot error\ \alpha$ 的项目为止。
+   - 把虚构的终结符 error “移进”栈。
+   - 若 $\alpha$ 为 $\varepsilon$，直接进行产生式规约，并执行相关的语义动作，忽略若干输入符号，直至发现能回到正常处理的符号为止。
+   - 若 $\alpha$ 不为 $\varepsilon$，找到 $\alpha$，把 $\alpha$ 移进栈，把 error $\alpha$ 归约为 $A$，恢复正常分析。
