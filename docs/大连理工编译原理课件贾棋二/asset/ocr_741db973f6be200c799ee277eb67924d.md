# # 4.3 L属性定义的自上而下计算

例 数学排版语言EQN  
E sub 1 .val

![](bbox=[0.527, 0.266, 0.691, 0.348])

| 产生式 | 语义规则 |
|---|---|
| S → B | B.ps := 10; S.ht := B.ht |
| B → B₁ B₂ | B₁.ps := B.ps; B₂.ps := B.ps;  
B.ht := max(B₁.ht, B₂.ht) |
| B → B₁ sub B₂ | B₁.ps:=B.ps; B₂.ps:= shrink(B.ps);  
B.ht := disp (B₁.ht, B₂.ht) |
| B → text | B.ht := text.h × B.ps |
