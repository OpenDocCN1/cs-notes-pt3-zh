# L属性定义的自上而下计算

L属性定义的例子：变量类型声明的语法制导定义

| 产生式 | 语义规则 |
|---|---|
| $D \to TL$ | $L.in := T.type$ |
| $T \to int$ | $T.type := integer$ |
| $T \to real$ | $T.type := real$ |
| $L \to L_1,id$ | $L_1.in := L.in;$<br>$addtype(id.entry, L.in)$ |
| $L \to id$ | $addtype(id.entry, L.in)$ |
