# 4.2 S属性定义的自下而上计算

台式计算器的语法制导定义改成栈操作代码

![](bbox=[0.024, 0.409, 0.284, 0.923])

| 产生式 | 语义规则 |
|---|---|
| `L → E n` | `print (E.val)` |
| `E → E₁ + T` | `E.val := E₁.val + T.val` |
| `E → T` | `E.val := T.val` |
| `T → T₁ * F` | `T.val := T₁.val * F.val` |
| `T → F` | `T.val := F.val` |
| `F → (E)` | `F.val := E.val` |
| `F → digit` | `F.val := digit/lexval` |
