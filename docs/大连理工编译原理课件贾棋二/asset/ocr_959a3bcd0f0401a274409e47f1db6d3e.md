# ## 6.1.5 程序块

+   - 语法如{声明 语句}

+   - 本身含有局部变量声明的语句，可以嵌套

+   - 最接近的嵌套作用域规则

+   - 程序块B’ 中声明的作用域包括B

+   - 如果名字x没有在B中声明，那么B中x的出现是在外围程序块B’ 的x声明的作用域中，且满足

+   - B’ 有x的声明

+   - B’ 比其他任何包含x声明的程序块更接近被嵌套的B

+   - 并列程序块不会同时活跃

+   - 并列程序块的变量可以重叠分配。
