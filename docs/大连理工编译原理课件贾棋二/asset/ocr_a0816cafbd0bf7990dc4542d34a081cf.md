# 消除左递归，构造新的翻译模式

E → T　{R.i := T.val}
R　{E.val := R.s}

R → +
T　{R₁.i := R.i + T.val}
R₁　{R.s := R₁.s}

R → -
T　{R₁.i := R.i - T.val}
R₁　{R.s := R₁.s}

R → ε　{R.s := R.i}

T → ( E )　{T.val := E.val}

T → num　{T.val := num.val}

| 产生式 |
|---|
| E → T R |
| R → + T R₁ |
| R → - T R₁ |
| R → ε |
| T → ( E ) |
| T → num |

R.i：R 前面子表达式的值  
R.s：分析完 R 时子表达式的值
