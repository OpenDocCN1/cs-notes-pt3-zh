# 补充题 2

设计一个文法：字母表{$a, b$}上$a$和$b$的个数相等的所有串的集合

# 二义文法：

```
$$S \to aSbS \mid bSaS \mid \varepsilon$$
```

$\textcolor{limegreen}{a}bab$

# 二义文法：

```
$$\begin{aligned} S &\to aB \mid bA \mid \varepsilon \\ A &\to aS \mid bAA \\ B &\to bS \mid aBB \end{aligned}$$
```

$BB \to bSbS$的选择 $\textcolor{limegreen}{b}ba\textcolor{limegreen}{b}\quad \textcolor{limegreen}{bb}ab$

# 非二义文法：

```
$$\begin{aligned} S &\to aBS \mid bAS \mid \varepsilon \\ A &\to a \mid bAA \\ B &\to b \mid aBB \end{aligned}$$
```

$\textcolor{limegreen}{aabba}abab$
