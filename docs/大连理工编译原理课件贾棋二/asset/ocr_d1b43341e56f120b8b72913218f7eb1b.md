# 设计递归下降翻译器的方法

+   3. 每个产生式对应的程序代码中，按照从左到右的次序，对于单词符号（终结符）、非终结符和语义动作分别作以下工作：
+   
+    i) 对于带有综合属性 x 的终结符 X，把 x 的值存入为 X.x 设置的变量中。然后产生一个匹配 X 的调用，并继续读入一个输入符号。
+   
+    ii) 对于每个非终结符 B，产生一个右边带有函数调用的赋值语句 `c=B(b1,b2,...,bk)`，其中，b1,b2,...,bk 是为 B 的继承属性设置的变量，c 是为 B 的综合属性设置的变量。
+   
+    iii) 对于语义动作，把动作的代码抄进分析器中，用代表属性的变量来代替对属性的每一次引用。
