# NFA到DFA的转换——子集构造法

$A=\{0,1,2,4,7\}$  
$B=\{1,2,3,4,6,7,8\}$  
$C=\{1,2,4,5,6,7\}$  
$D=\{1,2,4,5,6,7,9\}$

| 状态 | 输入符号 |  |
|---|---|---|
|  | $a$ | $b$ |
| $A$ | $B$ | $C$ |
| $B$ | $B$ | $D$ |
| $C$ | $B$ | $C$ |
| $D$ | $B$ | $C$ |

> 只要含有NFA的终结状态就为DFA的终状态
