# # 词法记号的描述与识别

+   正规式的例子 \(\Sigma = \{a, b\}\)
+   
+   - \(a | b\)  \(\{a, b\}\)
+   - \((a | b)(a | b)\)  \(\{aa, ab, ba, bb\}\)
+   - \(aa | ab | ba | bb\)  \(\{aa, ab, ba, bb\}\)
+   - \(a^*\)  由字母 \(a\) 构成的所有串集
+   - \((a | b)^*\)  由 \(a\) 和 \(b\) 构成的所有串集

+   复杂的例子
+   
+   \((00 | 11 | ((01 | 10)(00 | 11)^*(01 | 10)))^*\)
+   
+   句子：010011010000100000010111001
