# 4.4 L属性的自下而上计算

| 产生式 | 代码段 |
|---|---|
| $S \to LB$ | `val[top−1] := val[top]` |
| $L \to \varepsilon$ | `val[top+1] := 10` |
| $B \to B_1MB_2$ | `B₁.ps := B.ps;  M.i := B.ps;`<br>`B₂.ps := M.s; B.ht := max(B₁.ht, B₂.ht)` |
| $M \to \varepsilon$ | `M.s := M.i` |
| $B \to B_1\ \mathrm{sub}\ NB_2$ | `B₁.ps := B.ps;  N.i := B.ps;`<br>`B₂.ps := N.s; B.ht := disp(B₁.ht, B₂.ht)` |
| $N \to \varepsilon$ | `N.s := shrink(N.i)` |
| $B \to \mathrm{text}$ | `B.ht := text.h × B.ps` |
