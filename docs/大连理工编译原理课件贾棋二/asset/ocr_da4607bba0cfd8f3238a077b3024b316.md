# # 4.4 L属性的自下而上计算

| 产生式 | 代码段 |
|---|---|
| S → LB | val[top−1] := val[top] |
| L → ε | val[top+1] := 10 |
| B → B₁ MB₂ | val[top−2] := max(val[top−2], val[top]) |
| M → ε | val[top+1] := val[top−1] |
| B → B₁ sub NB₂ | val[top−3]:= disp (val[top−3], val[top] ) |
| N → ε | val[top+1] := shrink(val[top−2]) |
| B → text | val[top] := val[top] × val[top−1] |
