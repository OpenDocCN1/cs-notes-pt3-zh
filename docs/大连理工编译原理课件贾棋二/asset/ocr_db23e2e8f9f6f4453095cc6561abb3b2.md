# 属性理解—例子

```
void D()
{
  T_temp = T();
  L_in = T_temp;
  L(L_in);
  return ;
}
```

```
int T()
{
  switch lookahead
  {
    case INT: return INTEGER;
    case REAL: return REAL;
    default: error;
  }
}
```

| 产生式 | 语义规则 |
|--------|----------|
| D → TL | L.in := T.type |
| T → int | T.type := integer |
| T → real | T.type := real |
| L → L₁, id | L₁.in := L.in;addtype (id.entry, L.in) |
| L → id | addtype (id.entry, L.in) |

```
void L(int L_in)
{
  L (L_in);
  match(', ');
  match(id);
  addtype(id.entry, L_in);
}
```
