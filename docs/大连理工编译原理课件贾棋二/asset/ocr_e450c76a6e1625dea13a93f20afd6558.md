# # 使用继承属性构造 a - 4 + c 的抽象语法树

```
E → T {R.i:=T.nptr} R {E.nptr:=R.s}
R → + T {R₁.i:=mknode('+',R.i,T.nptr)} R₁ {R.s:=R₁.s}
R → - T {R₁.i:=mknode('-',R.i,T.nptr)} R₁ {R.s:=R.s}
R → ε {R.s:=R.i}
T → ( E ) {T.nptr:=E.nptr}
T → id {T.nptr=mkleaf(id,id.entry)}
T → num {T nptr:=mkleaf(num,num.val)}
```
