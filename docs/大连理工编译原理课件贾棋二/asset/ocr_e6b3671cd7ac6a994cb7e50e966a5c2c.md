# ## 语法制导定义的形式

+   - 每个文法符号有一组属性

+   - 每个文法产生式\( A \rightarrow \alpha \)有一组形式为\( b := f(C_1, C_2, \ldots, C_k) \)的语义规则，其中\( f \)是函数，\( b \)和\( C_1, C_2, \ldots, C_k \)是该产生式文法符号的属性

+   - 综合属性：如果\( b \)是\( A \)的属性，\( C_1, C_2, \ldots, C_k \)是产生式右部文法符号的属性或\( A \)的其它属性。

+   - 继承属性：如果\( b \)是产生式右部某个文法符号\( X \)的属性。

+   - 以上两种情况下，都说\( b \)依赖于属性\( C_1, C_2, \ldots, C_k \)。
