# 例 题 5

# 给出对表达式求导数的语法制导定义(习题4.5)

| 产 生 式 | 语 义 规 则 |
| --- | --- |
| \( E' \to E \) | \( \text{print}(E.d) \) |
| \( E \to E_1 + T \) | \( E.d := E_1.d + T.d; \ E.exp := E_1.exp + T.exp \) |
| \( E \to T \) | \( E.d := T.d; \ E.exp := T.exp \) |
| \( T \to T_1 * F \) | \( T.d := T_1.d * F.exp + T_1.exp * F.d; \ T.exp := T_1.exp * F.exp \) |
| \( T \to F \) | \( T.d := F.d ; \ T.exp := F.exp \) |
| \( F \to (E) \) | \( F.d := E.d ; \ F.exp := (E.exp) \) |
| \( F \to x \) | \( F.d := 1; \ F.exp := x \) |
| \( F \to \text{num} \) | \( F.d := 0; \ F.exp := \text{num} \) |
