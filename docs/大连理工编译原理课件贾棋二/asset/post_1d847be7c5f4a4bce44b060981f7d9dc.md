
## 加入死状态后的DFA

先把状态集合分成非接受状态集{0, 1, 2, 3, 5}和接受状态集{4}这两个子集。

1. 集合{4}不能再分解，我们看集合{0, 1, 2, 3, 5}。

    move({0, 1, 2, 3, 5}, a) = {1, 2, 5}
    move({0, 1, 2, 3, 5}, b) = {3, 4, 5}

    由于b转换的结果{3, 4, 5}不是最初划分的某个集合的子集，因此{0, 1, 2, 3, 5}需要再分。由于状态1和状态2的b转换都到状态4，因此状态集合的进一步划分是：{1, 2}、{0, 3, 5}和{4}

2. 由于move({1, 2}, a) = {2, 5}，move({1, 2}, b) = {4}

    move({0, 3, 5}, a) = {1, 5}，move({0, 3, 5}, b) = {3, 5}

    显然{1, 2}和{0, 3, 5}需要再分，分别分成：{1}和{2}以及{0, 3}和{5}

3. 由于move({0, 3}, a) = {1}，move({0, 3}, b) = {3}

    因此不需要再分。这样状态0和状态3合并成一个状态，我们取0为代表，再删去死状态5，就得到该题的结果。

### 上下文无关文法与正规式比较

**上下文无关文法**

$$E \to EAE \mid (E) \mid -E \mid id$$

$$A \to + \mid *$$

- 上下文无关文法是一个四元组
- 最左推导、最右推导
- 二义性

**正规式定义**

- `letter → [A-Za-z]`
- `digit → [0-9]`
- `id → letter(letter|digit)*`
