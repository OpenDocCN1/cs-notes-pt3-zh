## 构造SLR分析表

### LR(0)项目（简称项目）

在右部的某个地方加点的产生式

例：A→XYZ对应有四个项目

A → ·XYZ  
A → X·YZ  
A → XY·Z  
A → XYZ·

例：A→ε只有一个项目和它对应

A → ·

![](img/4571939c0321e2c5dec9f0dd5554d04d_419_0.png)

### 从DFA构造SLR分析表

- 状态I构造，它的action函数如下确定：
  - 如果[A→α·aβ]在Iₙ中，并且goto(Iᵢ, a) = Iⱼ，那么置action[i, a]为sj。
  - 如果[A→α·]在Iᵢ中，那么对FOLLOW(A)中的所有a，置action[i, a]为rj，注明产生式 A→α的编号。
  - 如果[S'→S·]在Iᵢ中，那么置action[i, $]为接受acc。
- 如果出现动作冲突，那么该文法就不是SLR(1)的。
- 使用下面规则构造状态的goto函数：
  - 对所有的非终结符A，如果goto(Iᵢ, A) = Iⱼ，那么 goto[i, A] = j。

## 构造规范的LR分析表

1. 基于LR(1)项目来构造识别G'活前缀的DFA。
2. 构造LR(1)项目集规范族

I₀:  
S' → ·S, $

1. I的每个项目均加入closure(I)
2. 如果[A→α·Bβ, a]在closure(I)中，且B→η是产生式，那么如果项目[B→·η, b]还不在closure(I)中的话，那么把它加入（其中b属于FIRST(βa)）。

## 第四章 语法制导的定义

### 简单台式计算器的语法制导定义

| 产生式 | 语义规则 |
| --- | --- |
| $L \to E\ n$ | $print(E.val)$ |

| $T \to F$ | $T.val := F.val$ |
| $F \to (E)$ | $F.val := E.val$ |
| $F \to digit$ | $F.val := digit.lexval$ |
