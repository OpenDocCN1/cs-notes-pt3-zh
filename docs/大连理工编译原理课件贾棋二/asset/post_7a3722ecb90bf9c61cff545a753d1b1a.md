
## 语言和文法

### 消除左递归

- 文法左递归：\(A \rightarrow A\alpha\)
- 直接左递归：\(A \rightarrow A\alpha \mid \beta\)
  - 串的特点：\(\beta\alpha\ldots\alpha\)
- 消除直接左递归：
  - \(A \rightarrow \beta A'\)
  - \(A' \rightarrow \alpha A' \mid \varepsilon\)

- 非直接左递归：
  - \(S \rightarrow Aa \mid b\)
  - \(A \rightarrow Sd \mid \varepsilon\)
- 先变换成直接左递归：
  - \(S \rightarrow Aa \mid b\)
  - \(A \rightarrow Aad \mid bd \mid \varepsilon\)
- 再消除左递归：
  - \(S \rightarrow Aa \mid b\)
  - \(A \rightarrow bd A' \mid A'\)
  - \(A' \rightarrow adA' \mid \varepsilon\)

### 提左因子

- 有左因子的文法：
  - \(A \rightarrow \alpha\beta_1 \mid \alpha\beta_2\)
- 提左因子：
  - \(A \rightarrow \alpha A'\)
  - \(A' \rightarrow \beta_1 \mid \beta_2\)

### FIRST集、FOLLOW集

- \(\mathrm{FIRST}(\alpha) = \{a \mid \alpha \Rightarrow^* a\ldots,\ a \in V_T\}\)
  - 特别是，\(\alpha \Rightarrow^* \varepsilon\) 时，规定 \(\varepsilon \in \mathrm{FIRST}(\alpha)\)
- \(\mathrm{FOLLOW}(A) = \{a \mid S \Rightarrow^* \ldots Aa\ldots,\ a \in V_T\}\)
  - 如果 \(A\) 是某个句型的最右符号，那么 \(\$ \in \mathrm{FOLLOW}(A)\)

### FIRST集合及FOLLOW集合的计算方法

**FIRST集合计算方法**

- 若 \(X \rightarrow a\ldots\)，则将终结符 \(a\) 加入 \(\mathrm{FIRST}(X)\) 中。
- 若 \(X \rightarrow \varepsilon\)，则将 \(\varepsilon\) 加入 \(\mathrm{FIRST}(X)\) 中。
- 若 \(X \rightarrow Y\ldots\)，且 \(Y\) 属于非终结符，则将 \(\mathrm{FIRST}(Y) \setminus \{\varepsilon\}\) 加入到 \(\mathrm{FIRST}(X)\) 中。
- 若 \(X \rightarrow Y_1Y_2\ldots Y_k\)，且 \(Y_1,Y_2,\ldots,Y_{i-1}\) 都是非终结符，且 \(\mathrm{FIRST}(Y_1),\mathrm{FIRST}(Y_2),\ldots,\mathrm{FIRST}(Y_{i-1})\) 中均包含 \(\varepsilon\)，则将 \(\mathrm{FIRST}(Y_i)\) 的所有非 \(\varepsilon\) 元素加入到 \(\mathrm{FIRST}(X)\) 中。特别地，若 \(Y_1,Y_2,\ldots,Y_k\) 均有 \(\varepsilon\) 产生式，则将 \(\varepsilon\) 加到 \(\mathrm{FIRST}(X)\) 中。

**FOLLOW集合计算方法**

- 对文法开始符号 \(S\)，置 \(\$\) 于 \(\mathrm{FOLLOW}(S)\) 中。
- 若有 \(A \rightarrow \alpha B \beta\)，则将 \(\mathrm{FIRST}(\beta) \setminus \{\varepsilon\}\) 加入 \(\mathrm{FOLLOW}(B)\) 中。（此处 \(\alpha\) 可以为空）
- 若 \(A \rightarrow \alpha B\) 或 \(A \rightarrow \alpha B \beta\)，且 \(\beta \Rightarrow^* \varepsilon\)（即 \(\varepsilon \in \mathrm{FIRST}(\beta)\)），则将 \(\mathrm{FOLLOW}(A)\) 加入 \(\mathrm{FOLLOW}(B)\) 中。（此处 \(\alpha\) 可以为空）

**例**

文法：

```text
E → TE′
E′ → + TE′ | ε
T → FT′
T′ → * FT′ | ε
F → (E) | id
```

- \(\mathrm{FIRST}(E) = \mathrm{FIRST}(T) = \mathrm{FIRST}(F) = \{ (, \mathrm{id} \}\)
- \(\mathrm{FIRST}(E') = \{ +, \varepsilon \}\)
- \(\mathrm{FIRST}(T') = \{ *, \varepsilon \}\)
- \(\mathrm{FOLLOW}(E) = \mathrm{FOLLOW}(E') = \{ ), \$ \}\)
- \(\mathrm{FOLLOW}(T) = \mathrm{FOLLOW}(T') = \{ +, ), \$ \}\)
- \(\mathrm{FOLLOW}(F) = \{ +, *, ), \$ \}\)

### 自上而下分析

**LL(1)文法**

- 任何两个产生式 \(A \rightarrow \alpha \mid \beta\) 都满足下列条件：
  - \(\mathrm{FIRST}(\alpha) \cap \mathrm{FIRST}(\beta) = \varnothing\)
  - 若 \(\beta \Rightarrow^* \varepsilon\)，那么 \(\mathrm{FIRST}(\alpha) \cap \mathrm{FOLLOW}(A) = \varnothing\)

LL(1)文法有一些明显的性质：

- 没有公共左因子
- 不是二义的
- 不含左递归
