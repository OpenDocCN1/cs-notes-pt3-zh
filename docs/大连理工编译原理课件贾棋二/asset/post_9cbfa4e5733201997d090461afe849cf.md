

## L属性的自下而上计算

### 属性的位置不能预测

S → aAC    C.i := A.s  
S → bABC    C.i := A.s  
C → c    C.s := g(C.i)  

增加标记非终结符

S → aAC    C.i := A.s  
S → bABMC    M.i := A.s; C.i := M.s  
C → c    C.s := g(C.i)  
M → ε    M.s := M.i  

| S→aAC   |    |
|---|---|
| S→bABMC |    |
| C→c   | val [top]=g(val [top-1]) |
| M→ ε   | val [top+1]=val [top-1] |

### 模拟继承属性的计算

一般情况：模拟继承属性的计算  
继承属性是某个综合属性的一个函数  

S → aAC  
C → c  

C.i := f(A.s)  
C.s := g(C.i)  

增加标记非终结符，把f(A.s)的计算移到对标记非终结符归约时进行。  

S → aANC    N.i := A.s; C.i := N.s  
N → ε    N.s := f(N.i)  
C → c    C.s := g(C.i)  

> 这样，每次需要使用继承属性的时候，刚好都在本文法符号的正下方

写一个语法制导定义，它输出括号的对数。

S' → S  
S → (L)  
S → a  
L → L1,S

print(S.num)

## 例题 3

为文法  
S → (L) | a  
L → L;S | S  

写一个翻译方案，它输出括号嵌套的最大深度。  
例如，对于 (a,(a,a))，输出的结果是2。

```
S' → S {print(S.max)}
S → ( L ) {S.max:=L.max+1}
S → a {S.max=0}
L → L₁ ; S {L.max:=max(L₁.max, S.max)}
L → S {L.max:=S.max}
```

## 例题 4

为文法  
S → ( L ) | a  
L → L , S | S  

写一个翻译方案，它打印出每个 a 在句子中是第几个字符。  
例如，当句子是 ( a , ( a , ( a , a ) , ( a ) ) ) 时，打印的结果是 2 5 8 10 14。

```
S′ → {S.in := 0} S
S → ({L.in := S.in + 1} L) {S.num := L.num + 2}
S → a {S.num := 1; print (S.in+1)}
L → {L₁.in := L.in}{L₁,
    {S.in := L₁.in + L₁.num+1} S
    {L.num := L₁.num + S.num + 1}}
L → {S.in := L.in} S {L.num := S.num}
```

## 例题 6(4.7)

用S的综合属性val给出下面文法中S产生的二进制数的值。  
例如，输入101.101时，S.val=5.625。

S → L.L | L  
L → L B | B  
B → 0 | 1  

(1) 仅使用综合属性  

S → L₁.L₂    S.val=L₁.val+L₂.val /2^L₂.length  
S → L    S.val=L.val  
L → L B    L.val=L₁.val * 2+B.val;  
    L.length=L₁.length+1  
L → B    L.val=B.val; L.length=1  
B → 0    B.val=0  
B → 1    B.val=1  

(2) 用L属性决定S.val。B的唯一综合属性是c，它给出由B产生的位对最终值的贡献。  
eg:101.101最前和最后一位对5.625的贡献分别是4和0.125。

S → L.R    S.val=L₁.val+R.val  
S → L    S.val=L.val  
L → B L₁    B.i=L₁.c * 2; L.c=L₁.c * 2 ;  
    L.val=L₁.val+ B.c;  
L → B    B.i=1; L.c=1;L.val= B.c  
R → R₁ B    B.i=R₁.c / 2; R.c=R₁.c / 2 ;  
    R.val=R₁.val+ B.c;  
R → B    B.i=0.5; R.c=0.5;R.val= B.c  
B → 0    B.c=0  
B → 1    B.c=B.i  

## 第六部分 局部存储分配策略

### 活动记录

### 一般的活动记录的布局

| 活动记录字段 | 含义 |
|---|---|
| 返回值 | 本过程返回给调用过程的值 |
| 实在参数 | 调用过程传递给本过程的参数 |
| 控制链 | 指向调用过程的指针 |
| 访问链 | 用于引用存于其他活动记录的非局部数据 |
| 机器状态 | 用于保存本过程调用前的机器状态 |
| 局部数据 | 本过程内部定义的局部变量 |
| 临时数据 | 临时变量，中间结果 |
