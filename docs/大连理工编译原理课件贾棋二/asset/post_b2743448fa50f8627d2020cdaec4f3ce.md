## 有限自动机

确定的有限自动机（简称DFA）

一个数学模型，包括：

+   - 状态集合S；
+   - 输入字母表Σ；
+   - 转换函数 *move*: S × Σ → S；
+   - 唯一的初态 s∈S；
+   - 终态集合F⊆S；

识别语言 (a|b)*ab 的DFA

![](img/4571939c0321e2c5dec9f0dd5554d04d_340_0.png)

> 优点：1、输入字符不包括ε；2、一个状态对某个字符，只可能存在唯一一条输出边

## DFA的化简

### 方法

+   1. {A, B, C}, {D}
+      - `move({A, B, C}, a) = {B}`
+      - `move({A, B, C}, b) = {C, D}`
+   
+   2. {A, C}, {B}, {D}
+      - `move({A, C}, a) = {B}`
+      - `move({A, C}, b) = {C}`
