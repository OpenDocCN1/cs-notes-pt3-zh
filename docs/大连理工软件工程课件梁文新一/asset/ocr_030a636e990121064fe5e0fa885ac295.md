# # 例子2

+   C2：B1&(E3=E4)

+   其中，B1是布尔变量，E3和E4是算术表达式。  C2的条件约束形式为(D1， D2)，其中D1是“t”或“f”，D2是>、=或<。除了C2的第二个简单条件是关系表达式之外，C2和C1相同，因此，可以通过修改C1的约束集{(t, t), (f, t), (t, f)}得出C2的约束集。注意，对于(E3=E4)来说，“t”意味着“=”，而“f”意味着“<”或“>”，因此，分别用(t, =)和(f, =)替换(t, t)和(f, t)，并用(t, <)和(t, >)替换(t, f)，就得到C2的约束集{(t, =), (f, =), (t, <), (t, >)}。覆盖上述条件约束集的测试，保证可以发现C2中布尔算符和关系算符的错误
