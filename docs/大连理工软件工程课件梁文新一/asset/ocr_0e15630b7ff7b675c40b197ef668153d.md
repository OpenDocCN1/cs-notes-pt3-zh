# 4.4 Z语言(Z Notation)

+   ○ 假设电梯到达了某楼层，如果相应的楼层或电梯按钮已经打开，则此时它会关闭
+   ○ 如果相应的按钮未打开，则保持原状

```
┌────────────── Floor_Arrival ──────────────┐
△ Button_State

button? : Button
├───────────────────────────────────────────┤
(button? ∈ buttons) ∧
(((button? ∈ pushed) ∧ (pushed′ = pushed \\ {button?})) ∨
 ((button? ∉ pushed) ∧ (pushed′ = pushed)))
└───────────────────────────────────────────┘
```
