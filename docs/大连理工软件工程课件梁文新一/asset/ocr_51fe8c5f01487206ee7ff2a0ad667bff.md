# # 2.3 系统流程图(System Flowchart)

# ## 系统符号

| 符号 | 名称 | 说明 |
|---|---|---|
| 图例 | 穿孔卡片 | 表示用穿孔卡片输入或输出，也可表示一个穿孔卡片文件 |
| 图例 | 文档 | 通常表示打印输出，也可表示用打印终端输入数据 |
| 图例 | 磁带 | 磁带输入输出，或表示一个磁带文件 |
| 图例 | 联机存储 | 表示任何种类的联机存储，包括磁盘、磁鼓、软盘和海量存储器件等 |
| 图例 | 磁盘 | 磁盘输入输出，也可表示存储在磁盘上的文件或数据库 |
| 图例 | 磁鼓 | 磁鼓输入输出，也可表示存储在磁鼓上的文件或数据库 |
| 图例 | 显示 | CRT 终端或类似的显示部件，可用于输入或输出，也可既输入又输出 |
