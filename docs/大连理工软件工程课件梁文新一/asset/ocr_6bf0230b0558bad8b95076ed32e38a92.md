# # 1.语句覆盖(Statement Coverage)

语句覆盖的含义是，选择足够多的测试数据，使被测程序中每个语句至少执行一次

测试用例的设计格式如下  
【输入的(A, B, X)，输出的(A, B, X)】

为图例设计满足语句覆盖的测试用例是：  
【(2, 0, 4), (2, 0, 3)】
