# # 1.4.1 瀑布模型(Waterfall Model)

![](bbox=[0.027, 0.275, 0.324, 0.92])

+   - 由W. Royce (1929-1995) 1970年提出  
+     - “Managing the Development of Large Software Systems” (FTP上可下载原文)

+   - 又称线性顺序模型或软件生存周期模型

+   - 在20世纪80年代之前，唯一被广泛采用的生命周期模型，至今仍在软件工程中得以广泛应用

+   - 遵循软件生存期的划分，明确规定各个阶段的任务，各个阶段的工作自上而下、顺序展开，如同瀑布流水，逐级下落
