# # 4.4 Z语言(Z Notation)

# ## 4.4.1 简介

+   - 20世纪70年代由曾在牛津大学的Computing Laboratory的Programming Research Group工作的法国科学家J. R. Abrial 首次提出和其他地方的程序设计研究组开发出Z语言，它基于集合理论和一阶谓词逻辑

+   - “Z”得名于集合论的鼻祖，德国著名数学家 Zermelo(1871-1953) ， “Z”读作/zɛd/

+   - 用Z语言描述的最简单的形式化规格说明含有下述4个部分

+   - 给定的集合、数据类型及常数

+   - 状态定义

+   - 初始状态

+   - 操作
