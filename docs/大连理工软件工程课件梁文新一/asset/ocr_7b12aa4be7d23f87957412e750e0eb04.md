# # 1.基本路径测试

+   - 路径1：1-2-10-11-13
+   - 路径2：1-2-10-12-13
+   - 路径3：1-2-3-10-11-13
+   - 路径4：1-2-3-4-5-8-9-2-...
+   - 路径5：1-2-3-4-5-6-8-9-2-...
+   - 路径6：1-2-3-4-5-6-7-8-9-2-...

路径4、5、6后面的省略号(...)表示，以后接通过控制结构其余部分的任意路径(10-11-13或10-12-13)

通常在导出测试用例时，识别出判定节点是很有必要的。本例中节点2、3、5、6和10是判定节点
