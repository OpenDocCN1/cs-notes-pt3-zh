# 软件危机所带来的严重后果

+   - 仅有少数软件能够**及时**、**不超出预算**、**无差错**地交付，并且能**满足客户的需求**

+   - Standish Group对2000年完成的280,000个软件项目的分析报告
+     - 成功完成：28%
+     - 取消：23%
+     - 推迟完成、超出预算和/或功能缺失：49%

+   - Cutter Consortium在2002年的报告
+     - 有78%的信息技术组织卷入纠纷并最终以法律程序解决
+     - 其中67%因交付的软件产品的性能或功能无法达标
+     - 其中56%承诺的交付日期几次推迟
+     - 其中45%所交付的软件存在严重错误以至于无法使用
