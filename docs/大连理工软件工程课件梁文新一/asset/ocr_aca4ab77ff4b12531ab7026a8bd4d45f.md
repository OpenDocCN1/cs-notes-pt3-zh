# # 7.9.2 估算平均无故障时间的方法

# ## 4. 估计错误总数的方法

# ### A. 植入错误法

+   - 在测试之前由专人在程序中随机地植入一些错误，测试之后，根据测试小组发现的错误中原有的和植入的两种错误的比例，来估计程序中原有错误的总数E<sub>T</sub>。

+   - 假设人为地植入的错误数为N<sub>s</sub>，经过一段时间的测试之后发现n<sub>s</sub>个植入的错误，此外还发现了n个原有的错误。如果可以认为测试方案发现植入错误和发现原有错误的能力相同，则能够估计出程序中原有错误的总数为：  
+     [N' = \frac{n}{n'} * N_s]  
+     其中N'即是错误总数E<sub>T</sub>的估计值
