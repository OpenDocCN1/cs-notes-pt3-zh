# # 条件测试的准则

+   条件测试的目的不仅是检测程序条件中的错误，而且是检测程序中的其他错误。如果程序P的测试集能有效地检测P中条件的错误，则它很可能也可以有效地检测P中的其他错误

+   域测试要求对一个关系表达式执行3个或4个测试。对于形式为
+   
+   _E_<sub>1</sub>_<_关系算符_E_<sub>2</sub>
+   
+   的关系表达式来说，需要3个测试分别使_E_<sub>1</sub>的值大于、等于或小于_E_<sub>2</sub>的值。如果<关系算符>错误而_E_<sub>1</sub>和_E_<sub>2</sub>正确，则这3个测试能够发现关系算符的错误。为了发现_E_<sub>1</sub>和_E_<sub>2</sub>中的错误，让_E_<sub>1</sub>值大于或小于_E_<sub>2</sub>值的测试数据应该使这两个值之间的差别尽可能小（最好能在边界上取值）
