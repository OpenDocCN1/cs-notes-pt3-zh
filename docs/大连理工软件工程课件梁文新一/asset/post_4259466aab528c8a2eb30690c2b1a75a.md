S(U,e,f)+DC(e,f) ⇒ M(U,e,f+1)  
S(D,e,f)+DC(e,f) ⇒ M(D,e,f-1)  
S(N,e,f)+DC(e,f) ⇒ W(e,f)

### 4.2.3 评价

- 有穷状态机描述规格说明：
  - 当前状态+事件(+谓词) ⇒ 下个状态
- 优点：
  - 易于书写、易于验证、精确、易于理解
  - 可开发出CASE工具直接将规格说明转变为代码
- 缺点：
  - 开发大系统时三元组的数量会迅速增长
  - 无法处理定时需求（同步，竞争，死锁）

## 4.3 Petri网

### 4.3.1 概述

- 并发系统中遇到的一个主要问题是定时问题：同步、竞争、死锁
- Petri网是一种用于确定系统中隐含的定时问题的有效技术，可有效地描述并发活动

### History of Petri Nets

- 1962年，德国学者C.A.Petri在他的博士论文 (Communication with Automata) 中首次使用了网状结构模拟通信系统，这种模型后来就被称为Petri网
- **1970**: Project MAC Conf. on Concurrent Systems and Parallel Computation (MIT, USA)
- **1975**: Conf. on Petri Nets and Related Methods (MIT, USA)
- **1979**: Course on General Net Theory of Processes and Systems (Hamburg, Germany)
- **1980**: First European Workshop on Applications and Theory of Petri Nets (Strasbourg, France)
- **1985**: First International Workshop on Timed Petri Nets (Torino, Italy)

![](img/576b58d2c10334d3487443b8cc7c5551_234_0.png)

图4.5 Petri网的组成

- 包含元素
  - 位置 P
    - {P₁，P₂，P₃，P₄}
  - 转换 T
    - {t₁，t₂}
- 输入函数 I
  - I(t₁) = {P₂，P₄}
  - I(t₂) = {P₂}
- 输出函数 O
  - O(t₁) = {P₁}
  - O(t₂) = {P₃，P₃}

- 更形式化的Petri网结构，是一个四元组
  - **C = (P, T, I, O)**
  - 其中，
    - **P = {P₁, …, Pₙ}** 是一个有穷位置集，n ≥ 0
    - **T = {t₁, …, tₘ}** 是一个有穷变换集，m ≥ 0，且T和P不相交。
    - **I: T → P∞** 为输入函数，是由变换到位置无序单位组(bags)的映射。
    - **O: T → P∞** 为输出函数，是由变换到位置无序单位组的映射。

### Transition (Firing) Rule

- A transition t is *enabled* if each input place p has at least w(p,t) tokens
- An enabled transition may or may not *fire*
  - Nondeterminism
- A firing on an enabled transition t removes w(p,t) tokens from each input place p, and adds w(t,p’) tokens of every arc to each output place p’
