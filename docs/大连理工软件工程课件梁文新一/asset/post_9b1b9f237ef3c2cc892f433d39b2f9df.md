### 2、计算环形复杂度的方法

- (1) 流图中的区域数等于环形复杂度
- (2) 流图G的环形复杂度V（G）=E-N+2，其中E:边数，N:结点数
- (3) 流图G的环形复杂度V（G）=P+1，其中P:判定结点的数目

![](img/576b58d2c10334d3487443b8cc7c5551_430_0.png)

### 3、环形复杂度的用途

- 描述了程序控制流的复杂程度
- 对测试难度的一种定量度量
  - 基本路径测试（Basis Path Testing，Chap. 7）
- 对软件最终的可靠性给出某种预测
- 模块规模以 V（G）<=10 为宜

### McCabe方法的缺点

- 对于**不同种类**的控制流的复杂性不能区分
- 简单IF语句与循环语句的复杂性同等看待
- 嵌套IF语句与简单CASE语句的复杂性是一样的
- 模块间接口当成一个简单分支一样处理
- 一个具有1000行的顺序程序与一行语句的复杂性相同

## 6.5.2 Halstead方法（Halstead’s Metrics）

M. H. Halstead, et al., Elements of Software Science, Elsevier North Holland, pp. 54-67, 1977

根据程序中运算符和操作数（变量和常数）的总数度量程序的复杂度

N₁为程序中运算符出现的总次数，N₂为操作数出现的总次数，程序长度N定义为：N=N₁+N₂

运算符包括：

- 算术运算符
- 赋值符（=或:=）
- 逻辑运算符
- 分界符（，或；或：）
- 关系运算符
- 括号运算符
- 子程序调用符
- 数组操作符
- 循环操作符等

特别地，成对的运算符，例如“begin…end”、“for…to”、“repeat …until”、“while…do”、“if…then…else”、“（…）”等都当做单一运算符

设计完成后，可知程序中使用的不同的运算符（包括关键字）的个数$n_1$，不同操作数（变量和常数）的个数$n_2$，则Halstead预测程序长度为：

$$H = n_1\log_2 n_1 + n_2\log_2 n_2$$

Halstead预测程序包含错误的个数为：

$$E = N\log_2(n_1+n_2)/3000$$

有人曾对从300条到12000条语句范围内的程序核实了上述公式，发现预测的错误数与实际错误数相比误差在8%之内

例如，一个程序对75个数据库项共访问1300次，对150个运算符共使用了1200次，那么预测该程序的错误数：

$$E=(1200+1300)*\log_2(75+150)/3000\approx6.5$$

即预测该程序中可能包含6~7个错误

### 举例：预测程序长度

```
Z=0;

while X>0
    Z=Z+Y;
    X=X-1;
end while;
print(Z);
```

- 运算符：=；while-end while；+；-；print ()
- n₁=8
- 操作数（变量和常量）：Z，0，X，Y，1
- n₂=5

$$H=n_1\log_2n_1+n_2\log_2n_2$$

$$=8*3+5*2.32=35.6$$

### 举例：实际程序长度

```
Z=0;
while X>0
Z=Z+Y;
X=X-1;
end while;
print(Z);
```

| 运算符 | 个数 |
|---|---|
| = | 3 |
| ; | 5 |
| While end while | 1 |
| > | 1 |
| + | 1 |
| - | 1 |
| Print | 1 |
| () | 1 |

N₁=14

| 操作数 | 个数 |
|---|---|
| Z | 4 |
| 0 | 2 |
| X | 3 |
| Y | 1 |
| 1 | 1 |

N₂=11

N=N₁+N₂=25

预测的长度与实际长度的误差为：(35.6-25)/25=42.4%

### Halstead方法的缺点

- 没有区别不同人编写程序的差别：应将外部调用乘上一个大于1的常数Kf（应在1～5之间，它与文档资料的清晰度有关）
- 没有考虑非执行语句（如变量声明语句）：补救办法是在统计n₁、n₂、N₁、N₂时，把非执行语句中出现的运算对象、运算符统计在内
- 忽视了嵌套结构（嵌套的循环语句、嵌套IF语句、括号结构等）：一般地，运算符的嵌套序列，总比具有相同数量的运算符和运算对象的非嵌套序列要复杂得多。解决的办法是对嵌套结果乘上一个嵌套因子
- 没有注意调用的深度：Halstead公式应当对调用子程序的不同深度区别对待。在计算嵌套调用的运算符和运算对象时，应乘上一个调用深度因子。这样可以增大嵌套调用时的错误预测率
