# # UML的符号体系5

# ## 第五类：实现图——构件图和配置图中常用到的图符

| 可视化图符 | 名称 | 描述 |
|---|---|---|
| 节点 | 用于表示物理设备和在其上运行的软件系统 | |
| 构件 | 用于表示可执行的物理代码模块 | |
| 对象 | 用于表示类的一个实例 | |
| 接口界面 | 用于表示对外提供的可视操作和属性 | |
| 连接 | 用于表示节点之间的连接，表示系统之间进行的通信路径 | |
| 依赖关系 | 有两个类元素A和B，如果修改A则可能引起对另一个元素B的修改，则称B依赖A | |
| 注释体 | 用于对UML实体进行文字描述 | |
| 注释连接 | 将注释体与要描述的实体相连 | |
