# 11.7 设计任务管理子系统

# （5）确定协调任务

+   - 当系统中存在三个以上任务时，就应该增加一个任务，用它作为协调任务。
+   - 引入协调任务会**增加系统总开销**，但有助于把不同任务之间的协调控制封装起来。
+   - 这类任务**仅完成协调工作**，不承担其他服务工作。
+   - 状态转换矩阵（State Transition Matrix）
