# 11.3 软件重用

+   3. 典型的可重用软件成分
+   
+   （1）项目计划
+   
+   - 减少计划制定时间
+   
+   （2）成本估计
+   
+   - 类似功能的成本估计可重用
+   
+   （3）体系结构
+   
+   - 领域体系结构的重用
+   
+   （4）需求模型和规格说明
+   
+   - 类和对象模型的重用

+   （5）设计
+   
+   - 系统和对象设计都可被重用
+   
+   （6）源代码
+   
+   - 经过验证和测试的程序构件
+   
+   （7）用户文档和设计文档
+   
+   （8）用户界面
+   
+   - 最广泛被重用的部分
+   
+   （9）数据
+   
+   - 表、记录结构、文件及DB等
+   
+   （10）测试用例
+   
+   - 设计和代码构件所附带的测试用例
