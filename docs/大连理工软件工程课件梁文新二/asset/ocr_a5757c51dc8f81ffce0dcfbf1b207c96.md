# # 协作图—消息

在对象之间的静态链接关系上可标注消息，消息类型有简单消息、同步消息和异步消息三种。用标号表示消息执行的顺序。消息定义的格式如下：

消息类型 标号 控制信息：返回值：=消息名 参数表

# ## 标号有 3 种：

+   - 顺序执行：按整数大小执行。 1,2...
+   - 嵌套执行：标号中带小数点。 1.1， 1.2， 1.3， ...
+   - 并行执行：标号中带小写字母。 1.1.1a， 1.1.1b， ...

控制信息{ 条件控制信息 如： [ x > y ] 重复控制信息 如： * [ I = 1..n ]
