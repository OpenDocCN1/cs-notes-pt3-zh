# 9.1.2 面向对象方法学的主要优点

+   - 面向对象的设计方法使用现实世界的概念抽象地思考问题，从而自然地解决问题。
+   - 在面向对象的设计方法中，计算机的观点是不重要的，**现实世界的模型才是最重要的**。
+     - 它强调模拟现实世界中的概念而不强调算法。它鼓励开发者在软件开发的绝大部分过程中都用**应用领域的概念去思考**。
+   - 面向对象的软件开发过程从始至终都围绕着建立**问题领域的对象模型**来进行：
+     - 对问题领域进行自然的分解，确定需要使用的**对象和类**，建立适当的**类等级**。
+     - 在对象之间传递消息实现必要的联系，从而按照人们习惯的思维方式建立起问题领域的模型，模拟客观世界。
