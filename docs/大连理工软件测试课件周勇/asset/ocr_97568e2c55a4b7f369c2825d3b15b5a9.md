# # 单元测试技术

+   - 静态分析-走查
+     - 定义：
+       - 开发组内部进行的，采用讲解、讨论和模拟运行的方式进行的查找错误的活动。
+     - 经验：
+       - 限时
+         - 避免跑题
+       - 参加人员
+         - 经验丰富的开发人员
+         - 和本模块相关的开发人员
+         - 本项目组的新人
+       - 由本模块的开发者进行讲解、回答问题并记录
+         - 不要现场修改
+       - 检查要点
+         - 逻辑错误
+         - 代码标准/规范/风格
