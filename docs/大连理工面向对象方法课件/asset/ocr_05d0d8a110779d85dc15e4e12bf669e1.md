# 真正认识多态

所谓多态性是指同样的消息可以有完全不同的行为。
（对类的成员函数的调用） （不同的实现）
或者说相同的函数调用，却有不同的实现，即多态性。

# 1 向上映射(upcasting)

先看例子：

```
```cpp
// WIND2.cpp : Defines the entry point for the console application.
#include "stdafx.h"
#include <iostream.h>
using namespace std;

enum note { middleC, CSharp, CFlat }; // Etc.

class Instrument {

public:

    void play(note) const {

        cout << "Instrument::play" << endl;

    }

}; //const 在函数后面表示不修改成员数据的函数

// Wind objects are Instruments
// because they have the same interface:
class Wind : public Instrument {

public:

    // Redefine interface function:
    void play(note) const {

        cout << "Wind::play" << endl;

    }
```
