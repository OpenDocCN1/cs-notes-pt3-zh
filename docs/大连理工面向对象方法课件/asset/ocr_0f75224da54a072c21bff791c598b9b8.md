# 一. 引用参数

引用(reference)就是给变量起一别名（&）。（注意：引用和指针的区别）

+   • 引用参数的说明一般要立即初始化（引用创建时初始化，指针就不同）。

```
int value;
```

int& value1=value; //变量value1引用了value，或者说value1是对一个整形变量value的引用。

+   • 一个引用变量还可以被另一个变量再引用。例如：

```
int a;
int & r1=a;
int & r2=r1;
r2=10;
或者r2++;
```

//相当于修改原始变量。(但是r1,r2不能再是其他变量的别名，对别名的所有操作实际上都是对原始变量本身的操作。编译器并不为别名保留空间)。

要点：任何引用必须和存储单元联系，访问引用，就是访问那个存储单元。

+   • 简单变量的引用称为独立引用。

+   • 函数参数和返回类型亦可为引用类型(这才是引用的主要用场。这两种引用方式可以解决给函数传递对象和从函数中返回值的问题)。常用的方法中，采用引用可以具有传递指针的效率。
