# # OBSERVER（观察者）—对象行为型模式

# ## 1. 意图

定义对象间的一种**一对多**的依赖关系，当一个对象的状态发生改变时，  
所有依赖于它的对象都得到通知（notify）并被自动更新（update）。

# ## 2. 别名

依赖（Dependents），发布-订阅（Publish-Subscribe）

# ## 3. 动机

将一个系统分割成一系列相互协作的类有一个常见的副作用：需要维护相关  
对象间的一致性。我们不希望为了维持一致性而使各类紧密耦合，因为这样降低  
了它们的可重用性。

定义应用数据的类和负责界面表示的类可以各自独立地复用。当然它们也  
可一起工作。例如：一个表格对象和一个柱状图对象可使用不同的表示形式描述  
同一个应用数据对象的信息。  
具体为：  
（1）表格对象和柱状图对象互相并不知道对方的存在，这样可以根据需要  
单独复用表格或柱状图。  
（2）当用户改变表格中的信息时，柱状图能立即反映这一变化，反过来  
也是如此。
