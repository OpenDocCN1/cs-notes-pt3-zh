# 2. 关于 “::” 单目作用域运算符

对于成员函数的定义可以放在类定义体之外——这时应该加上类名及 “ :: ”，例如：

```
int Cstring::get_length() { ... }
```

另外，有时在局部变量和全局变量同名时，还用 “ :: ” 来区分他们。例如：

```
#include <iostream.h>
float vl=1.2;
main()
{
    int vl=7;
    cout<<vl<<'\n'<<::vl;
    return 0;
}
结果为
vl=7
vl=1.2
```
