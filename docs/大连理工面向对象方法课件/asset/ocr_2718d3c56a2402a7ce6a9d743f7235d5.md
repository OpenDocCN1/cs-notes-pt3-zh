# # Singleton(单件,单例，单态）模式

# ## 1. 意图

保证一个类仅有一个实例，并提供一个访问它的全局访问点。

# ## 2. 动机

对一些类来说，只有一个实例是很重要的。

例如一个会计系统只能专用于一个公司。在计算机系统中，需要管理的资源包括软件外部资源，譬如每台计算机可以有若干个打印机，但只能有一个打印机假脱机（Printer Spooler），以避免两个打印作业同时输出到打印机中。需要管理的资源包括软件内部资源，譬如，大多数的软件都有一个（甚至多个）属性（properties）文件存放系统配置。这样的系统应当由一个对象来管理一个属性文件。

每台计算机可以有若干传真卡，但是只应该有一个软件负责管理传真卡，以避免出现两份传真作业同时传到传真卡中的情况。每台计算机可以有若干通信端口，系统应当集中管理这些通信端口，以避免一个通信端口同时被两个请求同时调用。一个数字滤波器只能有一个A/D转换器，等等。

显然单例模式的要点有三个：

+   - 一是某个类只能有一个实例；
+   - 二是它必须自行创建这个实例；
+   - 三是它必须自行向整个系统提供这个实例。

# ## 3. 问题
