# 5. 参与者

+   - Component (Graphic)
+     — 为组合中的对象声明接口。
+     — 声明一个接口用于访问和管理Component的子组件。
+   - Leaf (Rectangle、Line、Text等)
+     — 在组合中表示叶节点对象，叶节点没有子节点。
+     — 在组合中定义图元对象的行为。
+   - Composite (Picture)
+     — 定义有子部件的那些部件的行为。
+     — 存储子部件。
+     — 在Component接口中实现与子部件有关的操作。
+   - Client
+     — 通过Component接口操纵组合部件的对象。

# 举例[1]：

一个文件系统（树结构）就是一个典型的合成模式系统。树的节点有两种：
1为树枝结点：目录节点，有内部树结构
2为树叶结点：文件节点，没有内部树结构

显然，把目录和文件当作同一种对象同等对待和处理，这也就是合成模式的应用。

# 6. 协作关系

用户使用Component类接口与组合结构中的对象进行交互：
（1）如果接收者是一个叶节点，则直接处理请求。
（2）如果接收者是Composite，它通常将请求发送给它的子部件。
