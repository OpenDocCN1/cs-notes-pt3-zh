# 2. 派生类的构造函数和析构函数

# （1）派生类的构造函数

基类往往有构造函数和析构函数，前面讲过，派生类的数据成员包含基类的数据成员和派生类中新定义的数据成员。因此在派生类的构造函数中，除了要初始化派生类自己定义的数据成员外，还要初始化基类中的数据成员。而派生类只能通过调用基类的构造函数来初始化基类的数据成员。

定义派生类构造函数的一般格式如下：

<派生类名>（<参数表>）：<基类的构造函数>(<实参>)

例如：

```
class dynmem
{
public:
    //......
    dynmem(int eps,int wsize);//基类构造函数
    //......
};
class relmem:dynmem
{
    //......
public:
    relmem(int nmas,int eps,int wsize);
    //声明时不用后缀基类的构造函数
};
relmem::relmem(int nmas,int eps,int wsize):dynmem(int eps,int wsize)
{
    //定义派生类的构造函数时后缀上基类的构造函数
    //......
}
```

在定义对象时构造函数的执行顺序是先基类，所有人（对象成员），后自己（派生类本身）。
