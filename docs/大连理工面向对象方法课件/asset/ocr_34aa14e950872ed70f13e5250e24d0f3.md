# 小结：

+   1. 若在main 中写成：t.hour（t.second, t.minute）错误？

不能访问类的私有成员。只能通过类的成员函数访问。

+   2. 提倡编写与实现无关的程序，如果与实现无关的代码所用到的类的实现发生了改变，那么使用他的代码无需改动（但需要重新编译）。

+   3. 要保持类的所有数据成员都是私有的，然后给客户提供设置或者获取私有数据成员值的公有成员函数，这样作者利于对客户隐藏类的实现。减少了意外的错误和提高了程序的可修改性。（类的客户可能是另一个类的成员函数或一个全局函数），类的客户不关心类的内部是怎样实现其功能的，他不能访问类的私有成员。
