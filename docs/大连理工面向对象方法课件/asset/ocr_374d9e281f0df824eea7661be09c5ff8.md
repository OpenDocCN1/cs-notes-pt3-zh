# 4.如何实现晚捆绑

a. 晚捆绑如何发生？所有的工作都由编译器在幕后完成。当我们告诉它去晚捆绑时  
（用创建虚函数告诉它），编译器安装必要的晚捆绑机制。  
b. 关键字virtual告诉编译器它不应当完成早捆绑，相反，它应当自动安装实  
现晚捆绑所必须的所有机制。

在程序最初创建时，即便我们没有发现合适的基类接口和虚函数，在稍后甚至更晚，当我

着一开始我们还没有所有的信息。由于C++严格的模块化，这并不是大问题。因为我们对系
