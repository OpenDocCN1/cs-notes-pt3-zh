# 注意：

不能声明引用的引用，也不能声明元素类型为引用的数组或指向引用的指针；

例：int &&rr; ×
int &Array[5]; ×
int& *pr; ×

当用&运算符取一个引用的地址时，表示为取引用变量的地址。

可以用一个引用初始化另一个引用。

引用不能针对void类型，但可使引用指向void类型的指针。

例：void &rv; //错
void *pv;

函数返回类型为引用时，注意不能返回一个引用参数本函数中自动的对象（局部变量）。返回这样的引用时它将与其所指对象一起被销毁。

注意：尽管引用很像指针，但它却不是指针，所以不能用于像分配动态内存等应用指针的地方。
