# 例2 利用引用参数交换二变量的值（独立引用）

```
#include <iostream.h>
void swap(int& x, int& y)
{
int temp;
temp=x;
x=y;
y=temp;
}
main()
{
int m=10,n=20;
swap(m,n);
cout<<" m="<<m<<" n="<<n<<endl;
}
```

结果：m=20，n=10(交换完成)，问：如果去掉&怎样？
如果去掉&符号，则m=10，n=20不变
