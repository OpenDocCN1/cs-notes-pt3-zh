# ## 三. 我们应该注意什么？

简单工厂模式（包括其他工厂）是用来创建实例对象的。所以以后在new（创建对象）时就要多个心眼，是否可以考虑使用工厂模式，虽然这样可能多做一些工作，但会给系统带来更大的可扩展性和尽量少的修改量。
