# 步骤 12：模型转换为工程

现在，我们又遇到一个新的问题，我们的代码所说的与模型所说的不相同。这时，我们需要进行工程转换，如图39所示。

![](bbox=[0.379, 0.127, 0.673, 0.283])

图39

选择 Add-Ins： Rational Rose 98： Reverse Engineering Wizard 菜单命令，打开向导窗口。选择需更新的模型。点击 OK 按钮。既然我们仅仅更新了 CourseOffering 类，因此我们只需转换这一个类，如图40所示。

![](bbox=[0.371, 0.411, 0.681, 0.567])

图40

点击 Forms 左边的复选框（checkbox），让 Forms 项不被选中。点击 Modules 左边的复选框，让 Modules 项不被选中。点击Class Modules左边的 + 号，将其展开。点击Course和Manager左边的复选框，让其不被选中。这时，我们只要点击一下 Finish 按钮，就可以使用默认的工具来完成工程过程（engineering process）的转换。在转换过程的作后，我们将会看到Summary窗口，所有的错误将被写入日志（log）中。如图41所示。
