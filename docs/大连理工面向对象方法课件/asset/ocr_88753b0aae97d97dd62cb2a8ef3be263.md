class y

    public:
    int make()
    { return x::a*y::a; } //注意a

{
    z z1;
    z1.x::make(10);
    z1.y::make(20);
    cout<<z1.make()<<"\n";//
    return 1;
}

现在分析一下：

+   (1) 注意a 行，缀上类名，为了避免二义性：如果y类中的变量a改成b，则可直接写  
+   return a*b;

+   (2) 派生类中可直接访问a,b

+   (3) main函数中，定义了类z的对象z1，因为定义z类时，采用的是对其基类的公有派生，  
+   因此基类中的公有成员在z类中也处于公有段，可以直接使用它。但要注意一个问  
+   题，在z类的两个基类中都含有make()函数，而且其返回类型及所带参数均相同，此  
+   时若只写成make(10)或make(20)的话，系统便无法确认是哪个基类中的make()函数，  
+   所以在make函数之前加上类名。但使用派生类对象自身的成员函数，类名科省略。
