# 四、继承性

在现实生活中，尽管许多概念和实体各不相同，千差万别，但也有一些具有共同的特性。如父类与子类，父亲将遗传基因给儿子，使得儿子像父亲，但遗传过程中也有变异，使得儿子与父亲有区别。人类在认识世界的过程中，建立了一整套成功的方法——分类方法，它有效的反映了这种相同和不同。

继承性在面向对象方法学中有两个含义：

其一 是指同一对象类的实例对象共享所属类的特征；

其二 是指类层次中子类自动继承全部父类的特性。以下讨论的继承性主要指后一种情况。

继承性是在类、子类以及对象之间自动地建立共享数据和方法的一种机制。他允许在设计新类是，只考虑与已有的类所不同的部分，而继承父类的内容作为自己的内容。

类层次：父类还可以继承其他的类，子类也可被别的类所继承，从而形成类的继承层次关系。

继承分为单继承和多继承。若一个子类只有一个父类，则称为单继承；这样建立起来的类层次形成了一个树。当一个子类有多于一个的父类时，则称为多继承。多继承大大地增加了构造子类的能力，这样建立起来的类称谓形成了一个DAG（有向无圈图）。

在实现继承时，子类能否访问父类中的实例变量就成为一个有争议的问题。如果允许，则将破坏父类的封装性；如果不允许，则怎样解决结构继承的问题？办法：

一般面向对象的语言（C++），对类所包含的成员分为三种类型 private, public and protected。

Private段能被继承但在子类中不可访问，protected段继承后可被直接访问，但对类的外部不可访问。
