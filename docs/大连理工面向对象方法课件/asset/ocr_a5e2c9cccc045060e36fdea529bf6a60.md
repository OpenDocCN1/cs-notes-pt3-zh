# # 抽象工厂模式

# ## 一．概念

抽象工厂模式是所有形态的工厂模式中最为抽象和最具一般性的一种形态。

抽象工厂模式的简略类图如下所示。

![](bbox=[0.2695, 0.2562, 0.7422, 0.4344])

左边的等级结构代表工厂等级结构；
右边的两个等级结构分别代表两个不同的产品的等级结构。

抽象工厂模式可以向客户端提供一个接口，使得客户端在不必指定产品的具体类型的情况下，创建多个产品族中的产品对象。这就是抽象工厂模式的用意。
