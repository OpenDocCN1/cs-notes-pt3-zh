构造函数的调用次序:
A::A(int )
B::B(int )
C::C(int )
其中, A::A(int )和B::B(int )的调用次序由类C定义中基类的说明次序所决定。实际上, 这个调用顺序就是派生类对象的内存对象中各类的出现顺序（except虚基类）。
