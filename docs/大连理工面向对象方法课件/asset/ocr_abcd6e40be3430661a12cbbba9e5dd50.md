# * 比较：类与对象

（1）比较之一：
对象由属性和操作构成：
属性：状态，特征，组成成员，
操作：修改属性，访问属性，执行命令

类是对具有相似特征的对象的抽象

# （2）比较之二

类是抽象的，对象是具体的；
类是类型，对象是变量；
类是模型，对象是实例。

# * 对象的创建

（1）直接创建变量
File f1, f2;

（2）动态创建变量
File *pFile;
pFile = new File;
......
delete pFile;

请注意：C中，程序设计的基本单位是函数；C++中程序设计的基本单位是类。对象是类的最终实例化。

# 三. 封装性

面向对象的封装是将表示状态的操作和属性包装成一个对象类型，使得对状态的访问或修改只能通过封装提供的接口进行。

主要包括以下几方面的内容：

a.所有对象内部软件范围具有清晰的边界；封装还包括了描述该对象与其它对象如何相互作用的一个接口。

b.接口是公有的，它定义了一个类所能完成的功能；

c.接口的实现是私有的或受保护的，它定义了类完成这些功能所作的具体操作。
