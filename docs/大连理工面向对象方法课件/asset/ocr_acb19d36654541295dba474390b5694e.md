# 第二次课　　面向对象的概念、机制和原理

面向对象方法学的中心概念是围绕着对象、类、消息、继承、多态性和动态绑定（编联）等概念、机制和原理展开的。

其中，

+   - **对象、类**是这一方法的核心；
+   - **消息**是连接它们的纽带；
+   - **继承性**是这一方法的独特贡献；
+   - **多态性**和动态编联使这一方法更加完美。

# 一、对象

**广义地讲，人们所关心的任何具有“生命”历程的事物都可以看作为对象。** 例如：一个人，一架飞机等都有从诞生到灭亡的过程，都是对象。世界是由对象构成的，对象是对现实世界基本成分的一种完美抽象。

对象既可以表示现实世界的实体，也可以表示某个概念，例如：附属、堆栈等；他既可以表示大型地球的宏观对象，也可以表示小到原子的微观的对象。简单的对象可以组成复杂的对象，甚至整个世界都可以看作是从一些最基本的对象开始，经过层层组合而形成的。

对象可由其所具有的特征加以描述，各种各样的**对象**，其**特征是千差万别**的，但是，对象的多种多样的性质从本质上可以划分为两大类：一类是对象自身所要维护的知识，称为**属性**，可用值来描述；另一类是通过对象的行为所表现出的特性，称为**操作**，可用这个**操作的执行来描述**。

因此，面向对象的方法学将对象定义为：

> > **对象是对一组信息及其上操作的描述。从动态的角度来看，对象可表示成一台封装了私有数据和一组相关操作的自动机。**

其中私有数据表示了对象的状态，该状态只能由定义在其上的操作来访问。每当需要访问对象的状态时，只能通过向该对象发送消息，对象选择适当的方法响应这条消息，完成一定的功能或者拒绝响应这条消息。

**对象还可以分为主动对象和被动对象**，那些只有在接受到消息后才被激活的对象称为**被动对象**；那些用来检测外部事件的发生比自主采取行动的对象称为**主动对象**。

**对象的值不是永远不变的**，如人的年龄在逐渐的变老，学历也在不断的变化，但是无论怎么变化这个人还是他自己，不会变成另外一个人，我们将**对象的这种特性称为对象的标识**（Object Identity——OID）。正是因为这样，我们才能将不同的对象区分开来。事实上，现实世界中的存在才可以视为对象。
