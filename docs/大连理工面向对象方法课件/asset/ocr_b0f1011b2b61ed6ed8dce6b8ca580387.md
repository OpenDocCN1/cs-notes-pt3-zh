# 1. 类及其成员变量和成员函数的声明和定义

这里以C++为例，存在三种类类型：类（重点内容）、结构和联合，它们分别使用三个关键字来声明和定义类：class、struct和union。表3.1给出了不同类类型之间的差别。

表3.1 三种不同类类型的类、结构和联合

|    | 类    | 结构    | 联合    |
|---|---|---|---|
| 声明和定义时使用的关键字 | class    | Struct    | union    |
| 默认的成员访问权限    | 私有    | 公有    | 公有    |
| 使用限制    | 无    | 无    | 同时只能使用一个成员 |

由于联合的特殊性，这里暂不多讲。下面给出一个使用class来定义类的示例：

```
class CCircle
{
public:
    unsigned Radius;
    CPoint Center;
};
```

下面我们使用关键字struct来定义类CPoint：

```
struct CPoint
{
    unsigned x;
    unsigned y;
};
```

注意：

+   1. 分号，否则编译时会出现一堆莫名其妙的错。

+   2. 在类CCircle的定义中我们使用了public关键字，而在类CPoint的定义中却没有使用。（因为有默认权限）

对于同一个类，可以使用关键字class来定义，也可以使用关键字struct来定义。对于上面的例子，我们将类CCircle改用关键字struct来定义同样可以。
