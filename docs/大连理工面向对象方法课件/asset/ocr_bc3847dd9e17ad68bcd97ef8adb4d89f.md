# ***** 含有虚基类时构造函数的调用次序

有虚基类的的派生类，其构造函数的调用次序为：**先虚基类、再非虚基类**。所有的**虚基类遵照深度优先，从左到右的原则**。非虚基类仍然按照前面讲的原则决定调用次序。
