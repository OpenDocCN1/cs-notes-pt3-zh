# 4. 适用性

迭代器模式可用来：

+   - 访问一个聚合对象的内容而无需暴露它的内部表示。
+   - 支持对聚合对象的多种遍历方式。
+   - 为遍历不同的聚合结构提供一个统一的接口（即，支持多态迭代）。
