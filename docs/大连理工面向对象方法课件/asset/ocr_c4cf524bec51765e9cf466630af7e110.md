# 3.2 面向对象方法的由来及发展

# 1. 面向对象程序设计语言的形成

面向对象的概念和方法是从面向对象的程序设计语言（OOPL）发展、演变而来的。

# 1. 首先要提到是 Larry Constantine(60 年代)，事实上，Larry 并

没有在面向对象的旗帜下做过任何事情，他一直致力于研究软件设计的基本准则，他
是最先提出软件在编程之前应该进行设计的几个人之一。他
的许多观点（如耦合和内聚）一直沿用到现在的面向对象领
域。

# 2. 60 年代末，由挪威计算机中心的科学家 Ole-Johan Dahl
and Kristen Nygaard 等人设计出来的 Simula 语言是用
于仿真的程序设计语言，其中引入的类概念和继承性机制等
已经初步形成了面向对象语言的雏形，被认为是面向对象语
言的先驱。

# 3. 具有里程碑意义的是 Xerox Palo Alto 研究中心
（PARC）在设计一个叫做 Dynabook 的系统时所开发的一种
Smalltalk 语言。这是由叫做 Kay 和 Goldberg 的两个人设
计成功的（1970 年左右）。
