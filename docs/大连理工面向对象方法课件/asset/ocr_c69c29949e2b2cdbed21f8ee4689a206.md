# 二、对象类（class）

对象类是面向对象方法中一个很重要的概念，对象类简称为类。

类是对具有相同或者相似属性和行为的一组对象的共同描述。类是对具有相似的对象建立的模板（template），它是一个抽象的概念，而每个对象则是指一个有意义的具体实体。

类是对同一组对象的抽象，是人们认识世界的过程中归纳方法的体现。例如：人们今天看见了一只狗，明天看见了另一只狗，这样，人们就逐步形成了对狗这类对象共同特性的认识。如有4条腿、肉食的爬行动物等。人类的这种抽象能力是认识世界的最重要的特征之一。

面向对象的方法主要是描述类而不是对象。类可以比拟为一个能“产生对象”的机器，每当要按照一定的条件生成一个对象时，只要向该类发出一个请求，他就能产生一个具有该类所有性质的对象。因此，常将对象称为某个类的实例对象（instance），而且软件系统中的每个对象一定是某个类的实例。

抽象的类：类还可以从已经有的类中抽象出共同的特征，形成更高层的类。如：东北虎和华南虎是两类不同类型的虎，但作为虎他们必然有共同的特征，因此，可以把虎抽象为更高一层的类——虎类，而将东北虎和华南虎分别作为虎的子类。同样虎类和猫类也可共同的特征，可以进一步抽象为更高的猫科类，还可以向上抽象为动物类。

小结：在往上层的类不能产生实例，我们称其为抽象的类。

类由数据和方法构成，它包括外部特性和内部实现两个方面。外部特性是该类所提供的外部访问该类数据的一组方法，通过它所能相应的一组消息及其对应的处理能力来描述；内部特性则通过描述内部状态的表示已定义在其上的一组方法的实现来定义。这使得类具有良好的模块性，为大系统的分析、设计与实现提供了先进的方法。

而且在构造系统时，能够使系统设计人员将主要精力用在系统一级（类之间）的设计上，而不用关心类内部的实现细节。
