如果用多态性来实现，则非常简单：

```
void show(Figure* obj)

}
```

当以后增加了体Triangle类后，非多态的实现必须增加一个TRIANGLE常量的定义，并在Show()函数中增加一条case语句。而多态性的实现程序根本就不用改变。

**更广泛的多态性的定义是：** 如果函数、过程以及它们的操作对象有多于一个的类型，则称为具有多态性。如“+”“算子”，可以表示整数、浮点数的相加，如果用不同符号来表示不同类型的数的加法是不自然的。**这种多态性可以进一步演化到函数**，即相同的函数名可以具有不同的参数。如**重载函数**：

```
int Max(int i,int j)
{
        return i>j?i:j;
}
float Max(float x, float y)
{
        return x>y?x:y;
}
```

当用Max(3,4)和Max(6.3,10.2)调用时，编译器可以判定出应该调用哪一个函数。**我们称这类多态性为重载**，是**根据所传递的参数的不同而调用不同函数表现出来的多态**，此外还有运算符重载等等也属于此。

+   - 与类和对象的多态不同，对于函数和运算符的多态，是在编译过程中完成的，因此我们将它们称为编译时多态（包含多态性）；
+   - 与此相对，将类和对象的多态称为运行时多态。
