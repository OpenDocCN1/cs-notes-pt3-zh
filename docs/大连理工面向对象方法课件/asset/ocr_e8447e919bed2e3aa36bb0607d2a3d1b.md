# # 实验 UML 的使用

# ## 1. 实验目的

学习使用Rational Rose 98的基本方法。

# ## 2. 实验工具

+   1. Rational Rose 98企业版或 Rational Rose 98 Visual Basic 专业版。

+   2. Visual Basic 5.0 / Visual Basic 6.0 。

# ## 3. 实验内容

通过为某大学建立一个课程注册系统模型来学习使用Rational Rose 98。

# ## 4. 实验要求

+   1. 硬件基本配置： Intel Pentium 120 CPU 或以上级别的CPU，大于 16Mb 的内存。

+   2. 软件要求：Windows95/98/2000/me操作系统， Office 97/2000 系统程序。

+   3. 实验学时12学时。

+   4. 绘制出注册系统模型。

# ## 5. 实验步骤

# ### 步骤1： 软件的安装和配置

+   1. 启动 Rational Rose  
+   如果你正在使用Rose的企业版，则不使用 Framework （在 Framework Wizard 上点击Cancel按钮）。

+   2. 设置默认语言为 Visual Basic  
+   在 tool 下拉菜单中点击 Options ；  
+   选择 Notation 标签；  
+   设置Default域（点击箭头下拉菜单可见选择 Visual Basic ）。

+   3. 关闭控制焦点  
+   在 tool 下拉菜单中点击 Options ；  
+   选择图标签。  
+   选中 Focus of Control 复选框。

+   4. 显示所有的属性和操作：  
+   在 tool 下拉菜单中点击 Options ；  
+   选择图标签。  
+   选中 Show all Attributes and Show all Operations 复选框。
