# 二、操作符new和delete

# 1. new

**语法：** `<指针变量>=new<类型>[参数]`（能返回所需分配类型的指针）

**语义：** 按new后面的类型及其参数分配适当大小（sizeof（<类型>[参数]）的内存。

```
例：
int *p=new int;

int *p1=new int(8);  //将初始数据8装入所分配的空间

int *p2=new char[10];  //在堆区分配含有10个元素的字符型空间
```

# 2. delete

**语法：** `delete[参数]<指针变量>;`

**语义：** 释放指针变量所指的内存空间。

```
例：delete p;

    delete p1;

    delete [10]p2;  //或delete []p2;  注意释放形式
```

**注意：** 用new分配的空间，使用结束后应该用也只能用delete显式地释放，否则这部分空间将不能回收而变成死空间。

# 三、void型指针

+   - void型作为指针的类型时，这种指针就是一种通用型指针。
+   - 当指针为通用型指针时，是指它可以接受任何类型指针的赋值，但对已获得的void型指针，对它再进行处理（如输出/传递指针值时），则必须再进行显式类型转换，否则将出错。

例3：

```
void *p;

int i=100;

p=&i;

cout<<*p;  //错误
```
