
## 实验 UML 的使用

### 1. 实验目的

学习使用 Rational Rose 98 的基本方法。

### 2. 实验工具

- 1. Rational Rose 98 企业版或 Rational Rose 98 Visual Basic 专业版。
- 2. Visual Basic 5.0 / Visual Basic 6.0。

### 3. 实验内容

通过为某大学建立一个课程注册系统模型来学习使用 Rational Rose 98。

### 4. 实验要求

- 1. 硬件基本配置：Intel Pentium 120 CPU 或以上级别的 CPU，大于 16MB 的内存。
- 2. 软件要求：Windows 95/98/2000/Me 操作系统，Office 97/2000 系统程序。
- 3. 实验学时 12 学时。
- 4. 绘制出注册系统模型。

### 5. 实验步骤

#### 步骤1：软件的安装和配置

- 1. 启动 Rational Rose。如果你正在使用 Rose 的企业版，则不使用 Framework（在 Framework Wizard 上点击 Cancel 按钮）。
- 2. 设置默认语言为 Visual Basic
  - 在 tool 下拉菜单中点击 Options；
  - 选择 Notation 标签；
  - 设置 Default 域（点击箭头下拉菜单可见选择 Visual Basic）。
- 3. 关闭控制焦点
  - 在 tool 下拉菜单中点击 Options；
  - 选择图标签；
  - 选中 Focus of Control 复选框。
- 4. 显示所有的属性和操作：
  - 在 tool 下拉菜单中点击 Options；
  - 选择图标签；
  - 选中 Show all Attributes and Show all Operations 复选框。

#### 步骤2：打开 Main Use Case Diagram

我们将通过生成一个 Use Case 图来开始为**课程注册问题**建模。这种图由许多因素，使用案例，和这些案例之间的关系构成。我们首先打开 Main Use Case Diagram，如图 1 所示。

- 1. 在左边导航栏中点击 Use Case View 文件夹旁边的 +。

#### 步骤3：添加 Actor

确定在开发时与系统相互作用的人或事物。对于我们这个问题来说，有四个 **Actor——Student, Professor, Registrar（登记员，注册员）和 Billing System（计费系统）。** 如图 2 所示。

![](img/3b4669cf00b2833fe526284506f3f342_1_0.png)

图 2

- 1. 从工具条上通过单击选择 Actor 图标（人的形状）。
- 2. 单击图形界面放置 Actor。
- 3. 在 Actor 处于被选中状态下，输入名字为 _Student_。
- 4. 对其他三个 Actor（_Professor, Registrar_ 和 _Billing System_）重复以上操作。

#### 步骤4：添加 Use Case（用例）

我们为每一个 **Actor** 确定 Use Case。Use Case 是系统提供的一项功能。你可以观察每一个 **Actor**，看它们和系统之间是如何相互作用的来确定 Use Case。在我们这个模型中，**Student** 要做的事情是 **Register for Courses**，**Billing System** 接收注册信息。**Professor** 要做的事情是 **Request Course Roster（花名册）**，最后，**Registrar** 要执行的操作为 **Manage Curriculum（管理课程）**。如图 3 所示。

![](img/3b4669cf00b2833fe526284506f3f342_1_1.png)

图 3

- 从工具条中通过单击选择 Use Case 图标（椭圆形的）。
- 单击图形界面放置 Use Case。
- 在 Use Case 处于被选中的状态下，输入名字 _Register for Courses_。
- 对其他的 Use Case（_Request Course Roster, Manage Curriculum_）重复以上步骤。

**Actor** 和 **Use Case** 之间的联系是画在它们中间的。一个单方向的箭头是用来表示信息传递的方向（显示了是谁创建了信息）。在课程注册系统中，**Student** 创建了 **Register for Courses Use Case**，这个 **Use Case** 又因此与 **Billing System** 通信。**Professor** 创建了 **Request Course Roster Use Case**，**Registrar** 创建了 **Manage Curriculum Use Case**，如图 4 所示。

- 从工具条中通过单击选中单向箭头（箭头形状）。
- 单击 Student Actor 并将鼠标拖至 Register for Courses Use Case。
- 从工具条中通过单击选择单向箭头。
- 单击 Register for Courses Use Case 并将鼠标拖至 Billing System Actor。

对其他的联系（Professor Actor 到 Request Course Roster Use Case，Registrar Actor 到 Manage Curriculum Use Case），重复以上步骤。

注意：如果你在选择单向箭头时始终按住 Shift 键不放，就可以不必每一次都到工具条中去选中。

![](img/3b4669cf00b2833fe526284506f3f342_2_0.png)

图 4

#### 步骤5：创建 Sequence 图

Use Case 功能可能被显示在一个 Sequence Diagram 中。这个图是通过 Use Case 事件流一条通道——例如，向课程中添加一个学生。Sequence Diagram 包括对象以及显示对象之间的行为是如何实现的消息。我们看一看“Register for Courses”的“Add a Course”Sequence Diagram，如图 5 所示。

![](img/3b4669cf00b2833fe526284506f3f342_2_1.png)

图 5

在左侧导航栏中，在 Register for Courses 用例上单击鼠标右键出现快捷菜单。在 New 的子菜单中选择 Sequence Diagram。这将在导航栏中添加一个名为 New 图的 Sequence Diagram。当新的图处于选中状态时，输入名字 Add a Course。

- 1. 我们然后将向图中添加对象和消息去执行需要的功能。我们通过在导航栏中的图处双击来打开图。既然这种情况是由 Student Actor 来创建的，我们就可以把这个 Actor 拖到图上。如果想要这个 Actor 更清楚一点，我们可以为它取一个名字，我们就称这个学生为“Joe”，如图 6 所示。

![](img/3b4669cf00b2833fe526284506f3f342_2_2.png)

图 6

- 2. 在导航栏中的 Sequence Diagram 上双击打开图。
- 3. 在导航栏中单击选择 Student Actor 并把它拖到 Sequence Diagram 中。
- 4. 在 Sequence Diagram 上单击选中 Actor 并输入名字——Joe。

在这种情况下，学生必须在注册表格中填入信息，然后提交表格。这意味着有一个注册表格对象，这个对象从学生那里接收信息。

我们将创建一个表格并添加两个消息，“fill in info”和“submit”，如图 7 所示。

![](img/3b4669cf00b2833fe526284506f3f342_3_0.png)

图 7

- 在工具条中单击选中对象图标（矩形的）。
- 在 Sequence Diagram 中单击放置对象。
- 当对象处于被选中的状态时，输入名字 registration form。
- 在工具条中单击选中对象消息图标（箭形）。
- 单击 Student Actor 的虚线并将箭头拖至 registration form 对象的虚线上。
- 当箭头处于被选中状态时，输入下面的消息：fill in information。
- 重复步骤 4 至步骤 6 来创建 submit 消息。
