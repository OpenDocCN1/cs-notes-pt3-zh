

# 比较：类与对象

## （1）比较之一

对象由属性和操作构成：

- 属性：状态，特征，组成成员
- 操作：修改属性，访问属性，执行命令

类是对具有相似特征的对象的抽象。

## （2）比较之二

- 类是抽象的，对象是具体的；
- 类是类型，对象是变量；
- 类是模型，对象是实例。

## 对象的创建

### 直接创建变量

File f1, f2;

### 动态创建变量

File *pFile;
pFile = new File;
......
delete pFile;

请注意：C中，程序设计的基本单位是函数；C++中程序设计的基本单位是类。对象是类的最终实例化。

# 三、封装性

面向对象的封装是将表示状态的操作和属性包装成一个对象类型，使得对状态的访问或修改只能通过封装提供的接口进行。

主要包括以下几方面的内容：

- 所有对象内部软件范围具有清晰的边界；封装还包括了描述该对象与其它对象如何相互作用的一个接口。
- 接口是公有的，它定义了一个类所能完成的功能；
- 接口的实现是私有的或受保护的，它定义了类完成这些功能所作的具体操作。
- 一个类在定义数据的同时也定义了对这些数据的操作，这些操作称方法（method）。方法就是对对象中的数据的访问。
- 访问一个方法的过程称为向这个对象发送一个消息（message），对象的工作是靠消息来激发的（消息调用了类中的公有函数），对象之间也是通过消息发生联系的，即请求其它对象做什么或响应其它对象的请求是通过发送或接收消息来实现的。
- 封装可避免许多维护性问题。

# 四、继承性

在现实生活中，尽管许多概念和实体各不相同，千差万别，但也有一些具有共同的特性。如父类与子类，父亲将遗传基因给儿子，使得儿子像父亲，但遗传过程中也有变异，使得儿子与父亲有区别。人类在认识世界的过程中，建立了一整套成功的方法——分类方法，它有效的反映了这种相同和不同。

继承性在面向对象方法学中有两个含义：

其一 是指同一对象类的实例对象共享所属类的特征；

其二 是指类层次中子类自动继承全部父类的特性。以下讨论的继承性主要指后一种情况。

继承性是在类、子类以及对象之间自动地建立共享数据和方法的一种机制。他允许在设计新类时，只考虑与已有的类所不同的部分，而继承父类的内容作为自己的内容。

类层次：父类还可以继承其他的类，子类也可被别的类所继承，从而形成类的继承层次关系。

继承分为单继承和多继承。若一个子类只有一个父类，则称为单继承；这样建立起来的类层次形成了一个树。当一个子类有多于一个的父类时，则称为多继承。多继承大大地增加了构造子类的能力，这样建立起来的类称谓形成了一个DAG（有向无圈图）。

在实现继承时，子类能否访问父类中的实例变量就成为一个有争议的问题。如果允许，则将破坏父类的封装性；如果不允许，则怎样解决结构继承的问题？办法：

一般面向对象的语言（C++），对类所包含的成员分为三种类型 private, public and protected。

Private段能被继承但在子类中不可访问，protected段继承后可被直接访问，但对类的外部不可访问。

**更广泛的多态性的定义是：** 如果函数、过程以及它们的操作对象有多于一个的类型，则称为具有多态性。如“+”“算子”，可以表示整数、浮点数的相加，如果用不同符号来表示不同类型的数的加法是不自然的。**这种多态性可以进一步演化到函数**，即相同的函数名可以具有不同的参数。如**重载函数**：

```cpp
int Max(int i,int j)
{
        return i>j?i:j;
}
float Max(float x, float y)
{
        return x>y?x:y;
}
```

当用Max(3,4)和Max(6.3,10.2)调用时，编译器可以判定出应该调用哪一个函数。**我们称这类多态性为重载**，是**根据所传递的参数的不同而调用不同函数表现出来的多态**，此外还有运算符重载等等也属于此。

- 与类和对象的多态不同，对于函数和运算符的多态，是在编译过程中完成的，因此我们将它们称为编译时多态（包含多态性）；
- 与此相对，将类和对象的多态称为运行时多态。

## 1. 类及其成员变量和成员函数的声明和定义

这里以C++为例，存在三种类类型：类（重点内容）、结构和联合，它们分别使用三个关键字来声明和定义类：class、struct和union。表3.1给出了不同类类型之间的差别。

表3.1 三种不同类类型的类、结构和联合

|    | 类    | 结构    | 联合    |
|---|---|---|---|
| 声明和定义时使用的关键字 | class    | Struct    | union    |
| 默认的成员访问权限    | 私有    | 公有    | 公有    |
| 使用限制    | 无    | 无    | 同时只能使用一个成员 |

由于联合的特殊性，这里暂不多讲。下面给出一个使用class来定义类的示例：

我们看到，在类CCircle中定义了类CPoint的实例对象Center，然而，在定义实例对象Center的时候，我们还没有给出类CPoint的定义，这时，在编译时就会出现错误。因此，我们应该采用下面的顺序：
