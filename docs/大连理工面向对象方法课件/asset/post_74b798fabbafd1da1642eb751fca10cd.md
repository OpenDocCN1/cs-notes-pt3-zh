问题：类的内存对象为？

![](img/3b4669cf00b2833fe526284506f3f342_189_0.png)

继承是虚基类的内存空间，虚基类将占用更小的内存空间。但是，如上所述，所有对虚基类子对象的操作都是对同一个子对象进行的，这在某些情况下正是我们所不期望的。另外，使用虚基类将会给程序带来额外的开销，虽然就一般情况下而言，这种开销对程序的运行效率所产生的影响非常之小。

由于在使用多重继承时，派生类可以以不同的途径来从基类中继承成员名，因此就有可能出现二义性。如下面的例子：

```cpp
#include <iostream.h>
#include <iomanip.h>
class A
{
public:
    int a()
    {
        return 1;
    }
};
class B
{
public:
    float a()
    {
        return float(1.2345);
    }
};
class C : public A, public B
{
};
void main()
{
    C c;
    cout<<c.a()<<endl;
}
```

由于在类A和类B中都包括了名为a的公有成员函数，而类C由类A和类B通过多重继承机制派生，这样，如果我们使用了**c.a()**这样的表达式，编译器无法知道我们想调用的究竟是由类A继承过来的函数a呢，还是从类B继承过来的函数a，这样就导致了二义性。在上面的这种情况下，编译器将生成一个错误。

### 解决方法：

使用类作用域限定符 `"::"` 来明确的告诉编译器调用的函数a是从类A继承的还是从类B继承的，在前面讲述虚基类时我们已经给出了一个这样的例子。按下面的方法来修改main函数的代码：

```cpp
void main()
{
    C c;
    cout<<c.A::a()<<endl;
    cout<<c.B::a()<<endl;
}
```

编译器能够正确的编译上面的代码，而且，程序的运行结果也是完全正确的。然而尽管可以使用作用域限定符来解决二义性的问题，

但是，在使用多重继承机制时**不建议这样做，最好还是保证所有的成员都不存在二义性问题。**

### 下面的代码仍然会导致二义性：

```cpp
#include <iostream.h>
#include <iomanip.h>
class A
{
private://注意私有类型
    int a()
    {
        return 1;
    }
};
class B
{
public:
    float a()
    {
        return float(1.2345);
    }
};
class C : public A, public B
{
};
void main()
{
    C c;
    cout<<c.a()<<endl;
}
```

- 并不因为在类C中无法访问类A中的成员函数a（因为该成员函数的访问权限被限定为private）而使得编译器调用从类B继承的成员函数a，编译器在编译上面的代码时仍将给出二义性的错误。
- **下面的代码不会导致二义性：**

```cpp
#include <iostream.h>
#include <iomanip.h>
class A
{
public:
    int a()
    {
        return 1;
    }
};
class B : virtual public A
{
public:
    float a()
    {
        return float(1.2345);
    }
};
class C : virtual public A
{
};
class D : public B, public C
{
};
void main()
{
    D d;
    cout<<d.a()<<endl;
}
```

- 如果同一个成员名在两个具有继承关系的类中进行了定义，那么，在派生类中所定义的成员名具有支配地位。在出现二义性时，如果存在具有支配地位的成员名，那么编译器将使用这一成员，而不是给出错误信息。以上面的代码为例，在类A和类B中都定义了具有相同参数的成员函数a，这样，尽管类C中可以以两种方式来解释成员函数名a——即来自类A的成员函数a和来自类B的成员函数a，但是，按照刚才所说的规则，类B的成员名a相比类A的成员名a（即是类C中的成员名a）处于支配地位，这样，编译器将调用类B的成员函数a，而不产生二义性的错误。

### 含有虚基类时构造函数的调用次序

有虚基类的派生类，其构造函数的调用次序为：**先虚基类、再非虚基类**。所有的**虚基类遵照深度优先，从左到右的原则**。非虚基类仍然按照前面讲的原则决定调用次序。

### 课堂练习：

```cpp
class A{{}};
class B{{}};
class C{{}};
class D{{}}:public A, virtual public C{{}};
class E{{}}:public B, virtual public C{{}};
class F{{}}:public D, virtual public E{{}};
当建立类F的对象时的构造函数调用次序，或F的内存对象布局？
```

```cpp
C::C()
B::B()
E::E()
A::A()
D::D()
F::F()
```

（注意：C::C() 只调用一次，因为是虚基类，内存中只维护一份拷贝）。

### 虚基类干什么用：

实际上就是解决一个基类被多次继承而产生的二义性问题。那么虚基类到底由谁来调用呢？它是由产生对象的那个派生类的构造函数来调用的（! ），因此相应的虚基类必须有缺省的构造函数或者无参数的构造函数。由于在类层次结构中，虚基类的子孙都可以产生对象，所以每个子孙类的构造函数都应该有对虚基类构造函数的调用。

## 第二次课　　面向对象的概念、机制和原理

面向对象方法学的中心概念是围绕着对象、类、消息、继承、多态性和动态绑定（编联）等概念、机制和原理展开的。

其中，

- **对象、类**是这一方法的核心；
- **消息**是连接它们的纽带；
- **继承性**是这一方法的独特贡献；
- **多态性**和动态编联使这一方法更加完美。

### 一、对象

**广义地讲，人们所关心的任何具有“生命”历程的事物都可以看作为对象。** 例如：一个人，一架飞机等都有从诞生到灭亡的过程，都是对象。世界是由对象构成的，对象是对现实世界基本成分的一种完美抽象。

对象既可以表示现实世界的实体，也可以表示某个概念，例如：附属、堆栈等；它既可以表示大至地球的宏观对象，也可以表示小到原子的微观的对象。简单的对象可以组成复杂的对象，甚至整个世界都可以看作是从一些最基本的对象开始，经过层层组合而形成的。

对象可由其所具有的特征加以描述，各种各样的**对象**，其**特征是千差万别**的，但是，对象的多种多样的性质从本质上可以划分为两大类：一类是对象自身所要维护的知识，称为**属性**，可用值来描述；另一类是通过对象的行为所表现出的特性，称为**操作**，可用这个**操作的执行来描述**。

因此，面向对象的方法学将对象定义为：

> > **对象是对一组信息及其上操作的描述。从动态的角度来看，对象可表示成一台封装了私有数据和一组相关操作的自动机。**

其中私有数据表示了对象的状态，该状态只能由定义在其上的操作来访问。每当需要访问对象的状态时，只能通过向该对象发送消息，对象选择适当的方法响应这条消息，完成一定的功能或者拒绝响应这条消息。

**对象还可以分为主动对象和被动对象**，那些只有在接受到消息后才被激活的对象称为**被动对象**；那些用来检测外部事件的发生并自主采取行动的对象称为**主动对象**。

**对象的值不是永远不变的**，如人的年龄在逐渐的变老，学历也在不断的变化，但是无论怎么变化这个人还是他自己，不会变成另外一个人，我们将**对象的这种特性称为对象的标识**（Object Identity——OID）。正是因为这样，我们才能将不同的对象区分开来。事实上，现实世界中的存在才可以视为对象。

### 小结：

- （1）对象的特性：
  - ①具有状态或属性（state）；
  - ②行为（behavior）；
  - ③标识（identity）。
- （2）对象的核心概念就是通常所说的“封装性”（encapsulation）、“继承性”（inheritance）和“多态性”（polymorphism）。

### 二、对象类（class）

对象类是面向对象方法中一个很重要的概念，对象类简称为类。

类是对具有相同或者相似属性和行为的一组对象的共同描述。类是对具有相似的对象建立的模板（template），它是一个抽象的概念，而每个对象则是指一个有意义的具体实体。

类是对同一组对象的抽象，是人们认识世界的过程中归纳方法的体现。例如：人们今天看见了一只狗，明天看见了另一只狗，这样，人们就逐步形成了对狗这类对象共同特性的认识。如有4条腿、肉食的爬行动物等。人类的这种抽象能力是认识世界的最重要的特征之一。

面向对象的方法主要是描述类而不是对象。类可以比拟为一个能“产生对象”的机器，每当要按照一定的条件生成一个对象时，只要向该类发出一个请求，它就能产生一个具有该类所有性质的对象。因此，常将对象称为某个类的实例对象（instance），而且软件系统中的每个对象一定是某个类的实例。

抽象的类：类还可以从已经有的类中抽象出共同的特征，形成更高层的类。如：东北虎和华南虎是两类不同类型的虎，但作为虎它们必然有共同的特征，因此，可以把虎抽象为更高一层的类——虎类，而将东北虎和华南虎分别作为虎的子类。同样虎类和猫类也有共同的特征，可以进一步抽象为更高的猫科类，还可以向上抽象为动物类。

小结：再往上层的类不能产生实例，我们称其为抽象的类。

类由数据和方法构成，它包括外部特性和内部实现两个方面。外部特性是该类所提供的外部访问该类数据的一组方法，通过它所能响应的一组消息及其对应的处理能力来描述；内部特性则通过描述内部状态的表示已定义在其上的一组方法的实现来定义。这使得类具有良好的模块性，为大系统的分析、设计与实现提供了先进的方法。

而且在构造系统时，能够使系统设计人员将主要精力用在系统一级（类之间）的设计上，而不用关心类内部的实现细节。
