
派生类继承了基类1、基类2、……、基类n的**所有数据成员和成员函数**。<access>只限定紧跟其后的基类（**缺省值为private**），规则与单继承相同。

要定义具有两个以上基类的派生类，基本定义方法相同，只需将要继承的多个基类使用逗号分隔即可。例如：

```cpp
class c : a, b
{
    //……
};
```

c是由a,b作为基类多重继承得来的派生类。在定义派生类时还可以定义它的访问控制。例如上述定义说明，**c类对于其基类a，b均为私有派生**。若将上述定义改为如下几种形式，类对于其基类将具有不同的派生类型：

```cpp
class c : public a, b
{
    //c类是对a类的公有派生，对b类的私有派生
    //……
};
```

```cpp
class c : a, public b
{
    //c类是对a类的私有派生，对b类的公有派生
    //……
};
```

```cpp
class c : public a, public b
{
    //c类是对a类及b类均为公有派生
    //……
};
```

在多继承中，公有派生和私有派生对于基类成员在派生类中的可访问性与单继承的规则相同。但要注意二义性。

举例讲：

```cpp
#include <iostream.h>
class x
{
    protected:
        int a;
    public:
        void make(int i){ a=i; }
};
class y
{
    protected:
        int a;
    public:
        void make(int i){ a=i; }
};
class z : public x, public y
{
    public:
        int make()
        {
            return x::a * y::a; //注意a
        }
};
main()
{
    z z1;
    z1.x::make(10);
    z1.y::make(20);
    cout<<z1.make()<<"\n";
    return 1;
}
```

现在分析一下：

- (1) 注意a行，缀上类名，为了避免二义性：如果y类中的变量a改成b，则可直接写`return a*b;`
- (2) 派生类中可直接访问a,b
- (3) main函数中，定义了类z的对象z1，因为定义z类时，采用的是对其基类的公有派生，因此基类中的公有成员在z类中也处于公有段，可以直接使用它。但要注意一个问题，在z类的两个基类中都含有make()函数，而且其返回类型及所带参数均相同，此时若只写成make(10)或make(20)的话，系统便无法确认是哪个基类中的make()函数，所以在make函数之前加上类名。但使用派生类对象自身的成员函数，类名可省略。

## 2. 多重继承的构造函数和析构函数

有多个基类的派生类的构造函数和析构函数，在定义和执行时都要和它们基类的构造函数和析构函数发生关系。

```cpp
int C::GetC()
{
    SetA(100); // right
    SetB(200); // right
    return c + GetA() + GetB(); // right
}
```

## 3. 虚基类

现在我们来看一种特殊情况，请观察下面的代码：

```cpp
#include <iostream.h>
#include <iomanip.h>
class A
{
protected:
    int a;
};
class B : public A
{
public:
    void SetA(int i)
    {
        a=i;
    }
    int GetA()
    {
        return a;
    }
};
class C : public A
{
public:
    void SetA(int i)
    {
        a=i;
    }
    int GetA()
    {
        return a;
    }
};
class D : public B, public C
{
};
void main()
{
    D d;
    d.B::SetA(3);
    d.C::SetA(1);
    cout<<d.B::GetA()<<endl;
    cout<<d.C::GetA()<<endl;
}
```

上例中类的继承结构：

```cpp
class A { ... };
class B : public A { ... };
class C : public A { ... };
class D : public B, public C { ... };
```

画出类图就是这样：

![](img/3b4669cf00b2833fe526284506f3f342_186_0.png)

**注意：** 上面的类D可以导致成员名的二义性，这是因为在类B和类C中包含了同名成员函数GetA和SetA。关于二义性的详细讨论将在本节的后面部分进行。

在上面的例子中，类B和类C都从类A派生，而类D从类B和类C通过多重继承机制派生。这样，类D的内存对象中就包括了两个不同的A类子对象。上面的程序的运行结果如下：

```
3
1
```

上面的结果表明，我们分别通过类B和类C的成员函数修改从其类继承的成员的内容时，它们是分别对两个不同的子对象进行的。很自然地想到，如果我们在main函数中使用如`d.a`之类的表达式将会导致二义性，因为编译器不知道应该访问的是来自类B的成员呢，还是来自类C的成员。

在很多情况下，我们并不需要（也不希望）两个类A的子对象。这时，可以将A声明为虚基类，从而保证在多重继承时，只有一个类A的子对象存在。声明派生类时通过在基类的前面加上`virtual`关键字可以将一个基类声明为虚基类。为了便于对比，我们给出修改后的代码如下：

```cpp
#include <iostream.h>
#include <iomanip.h>
class A
{
protected:
    int a;
};
class B : virtual public A
{
public:
    void SetA(int i)
    {
        a=i;
    }
    int GetA()
    {
        return a;
    }
};
class C : virtual public A
{
public:
    void SetA(int i)
    {
        a=i;
    }
    int GetA()
    {
        return a;
    }
};
class D : public B, public C
{
};
void main()
{
    D d;
    d.B::SetA(3);
    d.C::SetA(1);
    cout<<d.B::GetA()<<endl;
    cout<<d.C::GetA()<<endl;
}
```

上面的程序的运行结果如下：

```
1
1
```

同学们可以看到，无论是通过B还是类C的子对象来修改成员a的值，它们实际上都是对同一个子对象进行操作。**这时，如果使用d.a的表达式是不会导致二义性的，因为在类D的实例对象中只存在一个类型A的子对象（virtual指明了间接基类与派生类的单拷贝关系）**。

上例中类的继承结构：
