# # 矩阵式组织形式的优缺点

# ## 优点

+   - 项目组织是又有有关项目活动的焦点
+   - 项目经理拥有对拨给的人力、资金等资源的最大控制权
+   - 职能组织中专家的储备提供了人力利用的灵活性
+   - 对环境的变化及项目的需要能够迅速做出反应
+   - 项目人员有明确归宿
+   - 关键技术人员能够为各项目共用，充分利用了人力资源

# ## 缺点

+   - 职能组织与项目组织间的平衡需要持续的进行监视
+   - 在开始制定政策和方法时，需要花费较多的时间和工作量
+   - 每个项目独立进行，容易产生重复性的劳动
+   - 协调难度大，一个成员有两个上司，既难处，也难管
+   - 对时间、费用以及运行参数的平衡必须加以监控
