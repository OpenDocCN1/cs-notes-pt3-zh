# # 投资估算计算的内容和方法

# ## 流动资金的估算

流动资金是指项目投产运营后，为进行正常生产运营，用于购买原材料、燃料，支付工资及其他经营费用等所必不可少的周转资金。它伴随着固定资产投资而发生的永久性流动资产投资，等于项目投产运营后所需全部流动资产扣除流动负债后的余额。

+   - 流动资金构成：
+   
+     流动资产
+     ├── 流动资金
+     │   ├── 现金
+     │   ├── 应收帐款
+     │   └── 存货
+     └── 流动负债：应付帐款

+   - 流动资金估算方法：
+     - 分项详细估算法
+     - 扩大指标估算法
