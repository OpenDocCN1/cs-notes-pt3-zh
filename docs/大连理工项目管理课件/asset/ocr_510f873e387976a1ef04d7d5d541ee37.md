# 9.3 现代审计特征

+   - 审计成为一种社会政治和经济生活的真正需要：需要的程度决定审计发挥作用的范围程度，社会的民主与法律建设发展一定程度需要对社会各层次的经济责任履行情况进行监督时审计才能全面发挥；市场经济化越高不同主体之间以及与政府社会公众之间经济信息交流越多对作为经济信息可靠性保证手段之一的审计的要求会随之增加。
+   - 审计职业规范体系形成，审计方法适应时代需要：建立在内部控制基础上的抽样审计法，强调审计主体对审计结论的责任用风险基础审计方法体系，计算机网络方法
+   - 有一支具有现代知识素养和职业经验的审计队伍
