# 项目组织形式对项目的影响

| 特征 | 职能式 | 矩阵式 |  |  | 项目式 |
|---|---|---|---|---|---|
|  |  | 弱矩阵 | 平衡矩阵 | 强矩阵 |  |
| 项目经理的权限 | 没有 | 有限 | 小到中等 | 中等到大 | 基至全权 |
| 全职工作人员的比例 | 几乎没有 | 0%~25% | 15%~60% | 50%~95% | 85%~100% |
| 项目经理投入时间 | 几眼 | 半职 | 全职 | 全职 | 全职 |
| 项目经理的常用头衔 | 调员 | 调员 | 项目经理 | 项目经理 | 项目经理 |
| 项目管理行政人员 | 兼职 | 兼职 | 半职 | 全职 | 全职 |
