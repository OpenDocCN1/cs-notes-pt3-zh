# # 投资估算计算的内容和方法

| 名称 | 内容 | 估算方法 |
|---|---|---|
| 建筑工程费 | 为建造永久性建筑物和构筑物所需要的费用 | 单位建设工程投资估算法单位实体工程量投资估算法概算指标投资估算法 |
| 设备 | 购置或自制国产设备 | 标准设备 带有和不带有备件原价，计算时采用带有备件原价 |
| | 非标设备 | 成本计算估算法、系列设备插入估算法、部分组成估算法、定额估算法。 |
| 进口设备 | 进口设备货价FOB/CIF进口从属费用国内运杂费 | 具体计算公式 |
| 工器具购置费 | 不够成固定资产的设施费用 | 以设备购置费为计算基数乘以费率 |
| 安装工程费 | 设备装配费用、装备设施工程费用、调试费用 | 按安装工程定额、取费标准和指标估算 |
