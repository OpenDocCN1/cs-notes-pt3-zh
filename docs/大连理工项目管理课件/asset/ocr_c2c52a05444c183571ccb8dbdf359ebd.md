# # 11. 国民经济评价

+   - 编制国民经济评价报表
+   - 如果以项目的财务评价为基础进行国民经济评价时，应从财务效益和费用中剔除“转移支付”部分，编制项目、国内投资国民经济效益费用流量表
+     - 项目的某些财务收益和支出，从国民经济角度看并没有造成资源的实际增加或减少，而是国民经济内部的“转移支付”，不计做项目的国民经济效益和费用。
+   - 转移支付的主要内容包括：
+     - 国家和地方政府的税收
+     - 国内银行借款利息
+     - 国家和地方政府给予项目的补贴
+   - 计算国民经济评价指标并进行方案比选
+     - 指标：经济净现值、经济内部收益率
