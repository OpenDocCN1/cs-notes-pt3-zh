# # 3. 技术方案、设备方案和工程方案

+   - 设备方案：
+     - 设备方案选择是在研究和初步确定技术方案的基础上，对所需主要设备的规格型号、数量、来源价格等进行比选。
+       - 设备方案选择基本要求：与建设规模、产品方案相适应，设备之间相互配套，质量可靠稳定，经济合理
+     - 设备方案选择内容：
+       - 设备规格、型号、数量，设备来源与投资。
+       - 超大、超重、超高设备安装的技术措施
+     - 设备方案比选论证
+       - 比选内容：设备对建设方案的满足程度，对产品质量和生产工艺要求的保证程度，设备使用寿命，备品备件保证程度，设备投资等。
+       - 比选方法：运营成本比较、寿命周期费用比较、差额投资回收期
