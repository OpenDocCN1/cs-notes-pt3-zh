# ②质量保证的工具和方法

+   质量计划工具和技术

+   质量审核：质量审核是确定质量活动及其有关结果是否符合计划安排，以及这些安排是否有效贯彻。通过质量审核：

+   ——保证项目质量符合规定要求；

+   ——保证设计、实施与组织过程符合规定要求；

+   ——保证质量体系有效运行并不断完善，提高质量管理水平。

+   质量审核的分类包括：

+   ——质量体系审核

+   ——过程（工序）质量审核

+   ——内部质量审核

+   ——项目质量审核

+   ——监督审核

+   ——外部质量审核

+   质量审核可以是有计划的，也可以是随机的，它可以由专门的审计员或者是第三方质量系统注册组织审核。
