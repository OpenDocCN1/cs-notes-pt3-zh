# # 12.关于IPMP笔试

+   - IPMP C级(certificated project management professional)
+     - 以实际案例为导向
+     - 注重项目管理核心方法的考核
+     - 强调方法的应用
+     - 题型为问答题

+   - IPMP D级(certificated project management practitioner)
+     - 注重理论与案例相结合的考核
+     - 相对全面的综合考核
+     - 题型以选择题和问答题相结合
