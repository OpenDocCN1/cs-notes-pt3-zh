# Multiple lines in a block

+   - **Good Code Style** for the basic if statement:

```
if ( life <= 0 ) {
    cout << “Gasp......I am dead \n”;
    cout << “......goodbye cruel world..... \n”;
}
```

or

```
if ( life <= 0 )
{
    cout << “Gasp......I am dead \n”;
    cout << “......goodbye cruel world..... \n”;
}
```
