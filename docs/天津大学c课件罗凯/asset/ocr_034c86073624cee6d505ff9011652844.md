# # Swap Func. using Pointers (the C way)

```
void swap(char *ptr1, char *ptr2) {
    char c = *ptr1;
    *ptr1 = *ptr2;
    *ptr2 = c;
}
```

```
int main() {
    char a = 'y';
    char b = 'n';
    swap(&a, &b);
    cout << a << b << endl;
    return 0;
}
```

> > In C, there are no reference parameters.
> > -Pointers are used instead.
