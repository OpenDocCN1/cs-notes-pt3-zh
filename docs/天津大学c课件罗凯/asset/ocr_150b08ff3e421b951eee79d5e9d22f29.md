# The fix for a Dangling Else

+   - use `{ }` to force the compiler to use the else as you would like it to

```
life = 5, energyFromFood = 8;
......
if ( life > 0 ) {
    if ( energyFromFood <= 0)
        cout “wow, I'm pretty hungry.. \n\n”;
}
else
    cout << “....go on without me....... \n\n”;
```
