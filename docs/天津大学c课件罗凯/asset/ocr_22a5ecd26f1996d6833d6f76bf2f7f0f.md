# Function Overloading

```
```cpp
int main() {
    int a = 10;
    int b = 20;
    double x = 4.4;
    double y = 9.2;
    int c = min(a, b); // which function is used ?
    cout << "c is " << c << endl;

    int z = min(x, y); // which function is used ?
    cout << "z is " << z << endl;
    return 0;
}
