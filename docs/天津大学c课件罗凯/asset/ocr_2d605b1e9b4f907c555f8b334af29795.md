# Operators and order of operation
(precedence)

| Operators | Association |
|---|---|
| `( )` | left to right |
| `*`, `/`, `%` | left to right |
| `+`, `-` | left to right |
| `<<`, `>>` | left to right |
| `<`, `<=`, `>`, `>=` | left to right |
| `==`, `!=` | left to right |
| `?:` | right to left |
| `=` | right to left |
