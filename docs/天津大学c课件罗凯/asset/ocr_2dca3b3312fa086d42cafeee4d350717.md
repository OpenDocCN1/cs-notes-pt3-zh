# # Another Switch Example

```
int left, right;
char operator;
cout << "Enter simple math expression(+,-,*,/): ";
cin >> left >> operator >> right;
cout << left << " " << operator << " " << right << " = ";
switch (operator) {
case '+':
cout << left + right << endl;
break;
case '-':
cout << left - right << endl;
break;
case '*':
cout << left * right << endl;
break;
case '/':
cout << left / right << endl;
break;
default:
cout << "Illegal operation" << endl;
}
```
