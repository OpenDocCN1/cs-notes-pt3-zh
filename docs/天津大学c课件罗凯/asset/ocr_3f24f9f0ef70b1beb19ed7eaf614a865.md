# # Functions
## { Math vs Programming }

+   - Functions in math
+   
+   - Example:
+   
+     f(x) = 2x

- In math, there are no data types, so x is some number.

+   - Functions in C++
+     - the same math function could be written as...

```
int f ( int x ) {
    int num;
    num = x * 2;
    return num;
}
```

- C++ has different data types, and so we have to add this information
