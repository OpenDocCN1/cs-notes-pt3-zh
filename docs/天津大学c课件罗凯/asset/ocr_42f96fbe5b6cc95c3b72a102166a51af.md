# else if chain

+   - so instead it will often be written like this

```
if ( grd > 90 )
    cout << “ Grade: A \n”;
else if ( grd > 80 )
    cout << “ Grade: B \n”;
else if ( grd > 70 )
    cout << “ Grade: C \n”;
else if ( grd > 60 )
    cout << “ Grade: D \n”;
else
    cout << “ Grade: F \n”;
```

> The purpose of the *else if* chain is to find the **one** right answer
