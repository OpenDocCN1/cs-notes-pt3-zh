# Operators and order of operation (precedence)

| Operators | Association |
|---|---|
| `()` | left to right |
| `++, --, static_cast<>` | left to right (post) |
| `++, --, -` | right to left (pre) |
| `*, /, %` | left to right |
| `+, -` | left to right |
| `=, +=, -=, *=, /=, %=` | right to left |
