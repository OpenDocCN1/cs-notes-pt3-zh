# “Address of” Operator

+   - using the “address of“ operator

```
```cpp
int i = 1;
int j = 2;
int *ptr;

ptr = &i;      // ptr points to location of i
*ptr = 3;      // value of i are changed
ptr = &j;      // ptr points to location of j
*ptr = 4;      // value of j are changed
cout << i << " " << j << endl;
```
