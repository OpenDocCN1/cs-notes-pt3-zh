# Positive and Negative

+   - **Predecrement:** subtract one immediately

```
int i = 1;

cout << --i << endl;    // displays 0
```

+   - **Postdecrement:** do all the other commands
+     and then subtract one

```
int i = 1;

cout << i-- << endl;    // displays 1
cout << i << endl;      // displays 0
```
