# Example using search

```
```cpp
int values[SIZE];

// fill the values array
cin >> target;
int spot = search(values, numberValues, target);

if (spot != numberValues) {        // its there
    cout << values[spot]
         << " already in the array \n";
}
else {                             // its not there
    values[numberValues] = target;
    ++numberValues;
}
