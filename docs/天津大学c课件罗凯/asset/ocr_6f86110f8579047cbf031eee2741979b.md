# # cin Notes

+   >> operator will consume(eat) white space
+   white space (space, new line, tab)

+   >> operator will read as much as legally
+   possible into a variable

+   if given the wrong type of data, the input stream
+   (cin) will be corrupted (made bad)
+   - once a stream is corrupted, all extractions (reads)
+   will be skipped
