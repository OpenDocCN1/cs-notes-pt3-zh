# strlen: String Length for cstrings

cstring function to return the length of a cstring

```
int strlen( const char * cptr ) {
    int i;
    for ( i = 0; cptr[i] != '\0' ; i++ ) ;
        // empty loop
    return i;
}
```

What does strlen need to work?

A: the cstring must be null terminated ( end with a '\0' )
