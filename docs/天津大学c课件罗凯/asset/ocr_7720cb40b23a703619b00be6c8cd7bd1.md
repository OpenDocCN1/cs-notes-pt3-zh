# Using the constructor functions

```
```cpp
int main() {
    Time t(12, 30);        // uses 2 parameter constr
    Time t2(-1, 78);       // uses 2 parameter constr

    Time t3;               // uses default constr

    t.print();
    cout << endl;
    t2.print();

    cout << endl << endl;
    return 0;
}
