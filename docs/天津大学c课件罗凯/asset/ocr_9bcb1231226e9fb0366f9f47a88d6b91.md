# # Checking to see if a file opened

+   - Two ways to check to see if a file is read for use:
+     - fail() function – returns true if not ready to read
+     - if ( fin == false ) – fstream variable will be equal to false if not ready

```
```cpp
ifstream fin;
fin.open("myfile.txt");
if ( fin.fail() ) {
  // do something
}
```
