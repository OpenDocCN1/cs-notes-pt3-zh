# Stdlib Library

+   - Provides functions for generating pseudo-random numbers
+     - `rand()`
+       - Returns a pseudo-random *unsigned int* in the range of 0 to `RAND_MAX` (32,767)

```
```cpp
#include <iostream>
#include <cstdlib>
using namespace std;
int main() {
    int i = 1;
    while( i <= 5) {
        cout << rand() << endl;
        ++i;
    }
    return 0;
}
