# # Solution to Exercise

```
int studentScores [NUM_CLSS] [NUM_STDS];
int total , highestAve = 0, ave;

for ( int i = 0; i < NUM_CLSS; i++ ) {
    total = 0;
    for ( int j = 0; j < NUM_STDS; j++ ) {
        total += studentScores [ i ] [ j ];
    }
    ave = total / NUM_STDS;
    if ( ave > highestAve )
        highestAve = ave;
}

cout << "Highest Class Average: " << highestAve << endl;
```
