# Another use of break

+   - break will only exit out of **one** loop (if embedded)

```
for ( int row = 1; row < 10; row++ ) {

    for ( int col = 1; col < 10; col++) {
        // do something

        if ( ???? )
            break;    // this will stop the col loop
    }  // col loop

}  // row loop
```
