# Using

```
```cpp
int factorial(int n) {
    if (n == 1) {
        return 1;
    }
    else {
        return n * factorial(n-1);
    }
}
```
```

+   - C++ function mirrors the mathematical factorial definition
+     - If the value of `n` is 1, the value 1 is returned.
+     - Otherwise, the product of `n` and `factorial(n-1)` is returned.
