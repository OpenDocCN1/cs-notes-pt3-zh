# # Another Switch Example

```
cout << "Enter a simple math expression(+,-,*,/) : ";
int left;
int right;
char operator;

cin >> left >> operator >> right;
cout << left << " " << operator << " " << right << " = ";
switch (operator) {
case '+' : cout << left + right << endl; break;
case '-' : cout << left - right << endl; break;
case '*' : cout << left * right << endl; break;
case '/' : cout << left / right << endl; break;
default:
cout << "Illegal operation" << endl;
}
```
