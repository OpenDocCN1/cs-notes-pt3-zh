# # Giving file name at run time

+   We can use a string variable to hold the file name

```
```cpp
string fname;
cout << "Enter the name of the file to be opened: ";
cin >> fname;
```
```

```
```cpp
ifstream fin;
fin.open( fname.c_str() );
```
```

```
```cpp
if( fin.fail() ) {
    // do some thing
}
```
