# # Comparison

+   - Before OOP
+     - code was very closely connected
+       - like a rug

+   - With OOP
+     - program is a collection of objects that work with each other

+   - Hard to write and test

+   - Easier to write and test
+     - write and test one object at a time

+   - Harder to modify
+     - often easier to start over

+   - Easier to modify
+     - can swap objects
+       (even at run time)
