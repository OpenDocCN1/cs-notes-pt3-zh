# # Pre (before) or Post (after)

+   • **Preincrement**: add one immediately
+   
+   int i = 1;
+   
+   cout << ++i << endl;   // displays 2

+   • **Postincrement**: do all the other commands
+   and then add one
+   
+   int i = 1;
+   
+   cout << i++ << endl;   // displays 1
+   cout << i << endl;   // displays 2
