# # Character Constants

+   - Explicit characters within single quotes
+     - 'a', 'D', '*'

+   - Special characters - delineated by a backslash \
+     - Two character sequences (escape codes)
+       - Some important special escape codes
+         - '\t' a tab
+         - '\n' a new line
+         - '\\' a backslash
+         - '\'' a single quote
+         - '\"' a double quote
