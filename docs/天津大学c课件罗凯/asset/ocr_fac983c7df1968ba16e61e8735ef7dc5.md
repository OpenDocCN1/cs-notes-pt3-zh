# Using an instance

```
```cpp
int main() {
    Time t, t2;

    // t.hour = 12;        Can't access directly
    //                       hour is private
    t.setHour( 12 );       // set the hour of t
    t.setMin( 67 );
    t.print( );            // use the print function of t

    t2.print( );           // use the print function of t2
    cout << "\\n\\n";
    return 0;
}
