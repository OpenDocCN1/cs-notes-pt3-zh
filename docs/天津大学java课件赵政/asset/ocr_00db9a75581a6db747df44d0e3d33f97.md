# # 7.1.1 构造函数重载

+   - 除了重载正常的方法外，构造函数也能够重载。
+   - 最新版本的 Box 类的例子：

```
```cpp
class Box {
double width;
double height;
double depth;
// This is the constructor for Box.
Box(double w,  double h, double d) {
width = w;
height = h;
depth = d;
}
// compute and return volume
double volume() {
return width * height * depth;
}
}
```
