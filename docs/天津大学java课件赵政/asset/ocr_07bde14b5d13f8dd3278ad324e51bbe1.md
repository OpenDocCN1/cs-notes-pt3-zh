# # 4.2.3 右移运算符

+   - 右移运算符>>使指定值的所有位都右移规定的次数。
+   - 通用格式如下所示： value >> num
+   - 例：int a = 32;
+     a = a >> 2; // a now contains 8
+   - 例：int a = 35;
+     a = a >> 2; // a still contains 8
+     二进制表示该过程
+     00100011 35
+     >> 2
+     00001000 8
+   - 负数右移：符号位扩展（保留符号位）
+   - 例：-8 >> 1 是-4
+     11111000 -8
+     >> 1
+     11111100 -4
