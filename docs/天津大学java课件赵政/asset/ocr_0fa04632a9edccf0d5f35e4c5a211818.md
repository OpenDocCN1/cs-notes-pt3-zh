# 6.1.1 类的通用格式

+   - 可以通过指定它包含的数据和操作数据的代码来定义类。
+   - 类的代码定义了该类数据的接口。
+   - 类定义的通用格式如下所示：

```
class classname {
    type instance-variable1;    // 数据或变量被称为实例变量
    // ...
    type instance-variableN;
    type methodname1(parameter-list) {    // 代码包含在方法内

    // body of method
    }
    // ...
    Type methodnameN(parameter-list) {
    // body of method
    }
}
```
