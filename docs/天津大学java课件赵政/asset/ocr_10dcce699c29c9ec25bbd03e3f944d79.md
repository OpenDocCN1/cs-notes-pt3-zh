# # 3.8.2 动态初始化

+   - 允许在变量声明时使用任何有效的表达式来动态地初始化变量。

+   - 例如： 例 P37

```
```java
// Demonstrate dynamic initialization.
class DynInit {
public static void main(String args[]) {
double a = 3.0, b = 4.0;
// c is dynamically initialized
double c = Math.sqrt(a * a + b * b);
System.out.println("Hypotenuse is " + c);
}
}
```
