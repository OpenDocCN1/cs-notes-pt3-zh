# 4.1.2 模运算符

+   - 模运算符%，其运算结果是整数除法的余数。它能像整数类型一样被用于浮点类型（C/C++中模运算符%仅仅能用于整数类型）。

例 P52

```
```java
// Demonstrate the % operator.
class Modulus {
    public static void main(String args[]) {
        int x = 42;
        double y = 42.25;
        System.out.println("x mod 10 = " + x % 10);
        System.out.println("y mod 10 = " + y % 10);
    }
}
