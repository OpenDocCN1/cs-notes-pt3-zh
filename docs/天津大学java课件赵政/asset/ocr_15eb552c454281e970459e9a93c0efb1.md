# # 例 P88下 使程序执行返回到Java运行系统

```
```java
// Demonstrate return.
class Return {
public static void main(String args[]) {
boolean t = true;
System.out.println("Before the return.");
if(t) return; // return to caller
// Java 编译器将标记 （unreachable code） 错误
System.out.println("This won't execute.");
}
}
```
```

Ans:
Before the return.
