# # 5.2.1 while 语句

+   - while 语句是 Java 最基本的循环语句。
+   - 当它的控制表达式是真时， while 语句重复执行一个语句或语句块。
+   - 通用格式如下：
+     ```java
+     while(condition) {
+     // body of loop
+     }
+     ```
+   - 如果只有单个语句需要重复，大括号是不必要的。
+   - 若开始时条件为假，则循环体一次也不会执行。
+     ```java
+     int a = 10, b = 20;
+     while(a > b)
+     System.out.println("This will not be displayed");
+     ```
