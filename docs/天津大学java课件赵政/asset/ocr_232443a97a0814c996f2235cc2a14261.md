# # 3.11.1 一维数组

+   - 一维数组实质上是相同类型变量列表。
+   - 一维数组的声明格式是：
+     ```cpp
+     type var-name[ ];
+     int month_days[ ];
+     ```
+   - 用运算符 `new` 分配地址并把它赋给数组的形式如下：
+     ```cpp
+     var-name = new type[size];
+     month_days = new int[12];
+     ```
+   - 你可以在方括号内指定它的下标来访问数组中特定的元素。所有的数组下标从零开始
+     ```cpp
+     month_days[1] = 28; // 值28赋给数组的第2元素
+     ```
