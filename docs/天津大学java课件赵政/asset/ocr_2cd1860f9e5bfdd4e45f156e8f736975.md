# 例 P125　static方法和static变量b在它们的类之外被访问

```
```java
// static 方法和变量能独立于任何对象而被使用。
// 你只要在类的名字后面加点号运算符即可。
class StaticDemo {
    static int a = 42;
    static int b = 99;
    static void callme() {
        System.out.println("a = " + a);
    }
}
class StaticByName {
    public static void main(String args[]) {
        StaticDemo.callme();
        System.out.println("b = " + StaticDemo.b);
    }
}
```
