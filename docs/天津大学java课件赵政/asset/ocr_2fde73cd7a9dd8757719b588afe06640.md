# # 6.4.3 加入带自变量的方法

+   - 不带自变量的 square()： 返回数字 10 的平方  
+     int square()  
+     {  
+       return 10 * 10;  
+     }

+   - 带一个自变量的 square()： 返回任何的值的平方  
+     int square(int i)  
+     {  
+       return i * i;  
+     }

+   - 一个例子：  
+     int x, y;  
+     x = square(5); // x equals 25  
+     x = square(9); // x equals 81  
+     y = 2;  
+     x = square(y); // x equals 4
