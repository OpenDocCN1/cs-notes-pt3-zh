# # 12.10 本机方法

+   - Java调用不是用Java语言写的子程序。
+   - CPU所工作环境的执行代码——本机代码。
+   - Java提供了关键字native用来声明本机代码方法。
+   - 在方法前用native修饰符，但不定义方法体。例如：
+   
+     public native int meth() ;
+   - 把C代码结合到Java 的机制是调用Java Native Interface (JNI)。 (Java 1.1创建，Java 2增强)
+   - 所需执行的精确的步骤随Java 环境和版本的不同而不同，它还依赖于所要实现的本机方法使用的语言。
