# 3.11.3 另一种数组声明语法

+   - 声明数组还有第二种格式：
+     ```java
+     type[] var-name;
+     ```
+   - 下面的两个定义是等价的：
+     ```java
+     int a1[] = new int[3];
+     int[] a2 = new int[3];
+     ```
+   - 下面的两个定义也是等价的：
+     ```java
+     char twood1[][] = new char[3][4];
+     char[][] twood2 = new char[3][4];
+     ```
+   - 包含这种数组声明格式主要是为了方便。
