# # 创建一个实现Runnable 接口的类

+   - 通过实现Runnable接口的方法创建每一个对象的线程。

+   - 一个类仅需实现一个run()的简单方法： 该方法声明如下：
+   
+     public void run()
+   
+   // run() 可以调用其他方法，引用其他类，声明变量。
+   // 当 run() 返回时，该线程结束。

+   - 实现Runnable接口的类以后，在类内部实例化一个Thread类的对象：
+   
+     Thread(Runnable threadOb, String threadName)

+   - 调用start()方法，执行的是一个对run()的调用。
+   
+     Start （）方法声明如下：
+   
+     void start()
