# # 4.8 使用圆括号

+   - 圆括号提高了括在其中的运算的优先级。
+   - 3 加到变量 b，得到一个中间结果，然后将变量 a 右移该中间结果位：
+     ```
+     a >> b + 3
+     ```
+     或 `a >> (b + 3)`
+     而不是 `(a >> b) + 3`
+   - 括号有时被用来帮助澄清表达式的含义
+     ```
+     a | 4 + c >> b & 7
+     (a | ((((4 + c) >> b) & 7)))
+     ```
+   - 圆括号（不管是不是多余的）不会降低你程序的运行速度。
