# 6.3 给对象引用变量赋值

+   - 对象变量的赋值：
+     ```java
+     Box b1 = new Box();
+     Box b2 = b1;
+     ```
+   - 对象变量的赋值将引用同样的对象。
+   - 没有分配任何内存或对原对象做任何部分的拷贝。它们是同一个对象。如图所示。
+   - 脱离（unhook）初始对象
+     ```java
+     Box b1 = new Box();
+     Box b2 = b1;
+     // ...
+     b1 = null;
+     ```
