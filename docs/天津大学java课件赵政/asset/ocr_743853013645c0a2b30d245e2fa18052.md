# package 声明的通用形式：

+   - 创建了一个名为MyPackage的包：
+     ```java
+     package MyPackage;
+     ```
+   - Java用文件系统目录来存储包。
+   - 任何声明的MyPackage中类的.class文件被存储在一个MyPackage目录中。
+   - 目录名必须和包名严格匹配。
+   - 多个文件可以包含相同package声明。
+   - 多级包的声明：`package pkg1[.pkg2[.pkg3]];`
+   - 包层次要在Java开发系统的文件系统中有所反映。
+     例如：`package java.awt.image;`
+   - 注意：
+     - UNIX：`java/awt/image`
+     - Windows：`java\awt\image`
+     - Macintosh：`java:awt:image`
