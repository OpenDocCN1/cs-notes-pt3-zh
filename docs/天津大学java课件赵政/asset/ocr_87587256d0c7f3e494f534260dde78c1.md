# # 6.1.2 一个简单的类

+   - 定义了一个名为 box 的类，它定义了3个实例变量，不包含任何方法：
+     class Box {
+       double width;
+       double height;
+       double depth;
+     }

+   - 创建一个 Box 对象：
+     // create a Box object called mybox
+     Box mybox = new Box();

+   - 该对象包含它自己的由类定义的每个实例变量的拷贝。

+   - 使用点号 “.” 运算符访问这些变量
+     mybox.width = 100;
