# # 8.7 使用抽象类

+   - 定义一个超类，该超类定义了一种给定结构的抽象，但不提供任何完整的方法实现。
+   - 创建一个只定义一个被它的所有子类共享的通用形式，由每个子类自己去填写细节。
+   - 为了确保子类真正重写所有必须的方法，Java使用抽象方法(abstract method)。
+   - 声明一个抽象方法，通用形式：（不存在方法体）
+     ```java
+     abstract type name(parameter-list);
+     ```
+   - 抽象类没有对象，一个抽象类不能通过new操作符直接实例化。
+   - 抽象类的子类必须实现超类中的所有抽象方法或者是自己也声明成abstract。
