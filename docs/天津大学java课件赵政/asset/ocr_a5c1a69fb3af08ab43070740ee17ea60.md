# 在 for 循环中声明循环控制变量

+   - 控制for循环的变量经常只是用于该循环，而不用在程序的其他地方。
+   - 可以在循环的初始化部分中声明变量。
+   - 例 P80 中

```
```java
// Declare a loop control variable inside the for.
class ForTrick {
    public static void main(String args[]) {
        // here, n is declared inside of the for loop
        //在 for 循环外，变量 n 就不存在了
        for(int n=10; n>0; n--)
            System.out.println("tick " + n);
    }
}
```
