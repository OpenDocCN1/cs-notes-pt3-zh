# 使用同步

+   - 只需在 `call()` 定义前加上关键字 `synchronized`:
+   
+     ```java
+     class Callme {
+         synchronized void call(String msg) {
+             ...
+         }
+     }
+     ```
+   - 若有一方法或多方法操纵对象的内部状态，都必须用 `synchronized` 关键字来防止状态出现竟争。
+   - 该实例的其他不同步方法却仍然可以被调用。
