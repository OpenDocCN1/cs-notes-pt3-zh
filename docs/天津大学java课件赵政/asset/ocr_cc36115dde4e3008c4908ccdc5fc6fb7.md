# # 8.1 继承的基础

+   - 用 extends 关键字把一个类的定义合并到另一个中。
+   - 声明一个继承超类的类的通常形式如下：
+     ```
+     class subclass-name extends superclass-name {
+     // body of class
+     }
+     ```
+   - Java 不支持多超类的继承。
+   - 与 C++ 不同，在 C++ 中，你可以继承多个基础类。
+   - 子类B包括它的超类A中的所有成员。
+   - 尽管A是B的超类，它也是一个完全独立的类。
+   - 一个子类可以是另一个类的超类。
