# # 5.1.1 if 语句（续）

+   - 建一个程序块以包含更多的语句：
+   int bytesAvailable;
+   // ...
+   if (bytesAvailable > 0) {
+     ProcessData();
+     bytesAvailable -= n;
+   } else
+     waitForMoreData();

+   - 适当定义块：
+   int bytesAvailable;
+   // ...
+   if (bytesAvailable > 0) {
+     ProcessData();
+     bytesAvailable -= n;
+   } else {
+     waitForMoreData();
+     bytesAvailable = n;
+   }

```
int bytesAvailable;
// ...
if (bytesAvailable > 0) {
  ProcessData();
  bytesAvailable -= n;
} else {
  waitForMoreData();
  bytesAvailable = n;
}
```
