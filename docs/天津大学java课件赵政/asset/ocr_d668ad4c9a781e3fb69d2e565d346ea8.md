# Java 严格地检查数组越界

例  P45  运用一维数组来计算一组数字的平均数

```
```java
class Average {
    public static void main(String args[]) {
        double nums[] = {10.1, 11.2, 12.3, 13.4, 14.5};
        double result = 0;
        int i;
        for(i=0; i<5; i++)
            result = result + nums[i];
        System.out.println("Average is " + result / 5);
    }
}
```
```

Ans:

Average is 12.3
