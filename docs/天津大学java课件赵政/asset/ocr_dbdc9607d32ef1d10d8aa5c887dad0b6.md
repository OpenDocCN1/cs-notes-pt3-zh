# ## 7.8 介绍 final

+   - 一个变量可以声明为 final，这样做的目的是阻止它的内容被修改。
+   - 在声明 final 变量的时候，你必须初始化。
+   - 例如：
+     ```java
+     final int FILE_NEW = 1;
+     final int FILE_OPEN = 2;
+     final int FILE_SAVE = 3;
+     final int FILE_SAVEAS = 4;
+     final int FILE_QUIT = 5
+     ```
+   - final 变量的所有的字符一般都大写。
+   - 一个 final 变量实质上是一个常数。
