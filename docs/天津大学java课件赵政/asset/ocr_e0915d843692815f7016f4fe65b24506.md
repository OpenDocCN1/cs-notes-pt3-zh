# # 局部实现

+   - 如果类包含一个接口但不完全实现接口定义的方法，那么该类必须定义成 abstract 型。
+   - 例如：
+     ```java
+     abstract class Incomplete implements Callback {
+     int a, b;
+     void show() {
+     System.out.println(a + " " + b);
+     }
+     // ...
+     }
+     ```
+   - 任何继承Incomplete的类都必须实现 callback() 方法或者它自己定义成 abstract 类。
