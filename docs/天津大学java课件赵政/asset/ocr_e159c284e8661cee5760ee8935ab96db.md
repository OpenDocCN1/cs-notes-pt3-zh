# 运行程序：

+   - 文件 AccountBalance.java，存放在 MyPack 目录中。
+   - 编译文件。
+   - 确信结果文件.class在MyPack 目录中。
+   - 命令行执行 AccountBalance 类：
+     ```
+     java MyPack.AccountBalance
+     ```
+   - 执行该命令时必须在MyPack的上级目录，或者把类路径环境变量设置成合适的值。
+   - 不能用下面的命令行：
+     ```
+     java AccountBalance
+     ```
+   - AccountBalance必须和它的包名一起使用。
+   - JBuilder
