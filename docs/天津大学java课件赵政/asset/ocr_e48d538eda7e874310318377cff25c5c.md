# 12.7 Transient和volatile修饰符

+   - 用transient声明实例变量，当对象被写入一个持久的存储区域，它的值不需要维持。例如：
+   
+     ```java
+     class T {
+         transient int a;   // will not persist
+         int b;              // will persist
+     }
+     ```

+   - Volatile告诉编译器变量可以被程序的其他部分改变：
+     在多线程程序里，有时两个或更多的线程共享一个相同的实例变量，每个线程可以自己保存该共享变量的私有拷贝。告诉编译器必须总是使用volatile变量的主副本。
