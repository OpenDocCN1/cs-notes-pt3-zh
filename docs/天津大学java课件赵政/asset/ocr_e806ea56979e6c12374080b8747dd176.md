# 例 P100 创建一个自变量代表盒子尺寸的方法

```
// This program uses a parameterized method.
class Box {
  double width;
  double height;
  double depth;
  // compute and return volume
  double volume() {
    return width * height * depth;
  }
  // sets dimensions of box
  void setDim(double w, double h, double d) {
    width = w;
    height = h;
    depth = d;
  }
}
```
