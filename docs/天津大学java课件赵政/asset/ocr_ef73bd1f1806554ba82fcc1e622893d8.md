# 例 P102　简单的构造函数

```
/* Here, Box uses a constructor to initialize the
dimensions of a box.
*/
class Box {
   double width;
   double height;
   double depth;
   // This is the constructor for Box.
   Box() {
      System.out.println("Constructing Box");
      width = 10;
      height = 10;
      depth = 10;
   }
   // compute and return volume
   double volume() {
      return width * height * depth;
   }
}
```
