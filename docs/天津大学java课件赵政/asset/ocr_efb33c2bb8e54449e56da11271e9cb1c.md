# 1.1.2 对 C++ 的需要

+   - C 使用结构化方法，不超过 25 000~100 000 行代码。
+   - 面向对象编程（object-oriented programming，OOP）新方法解决了结构化方法的极限。
+   - 面向对象的编程是通过使用继承性、封装性和多态性来帮助组织复杂程序的编程方法。
+   - 1979年，Bjarne Stroustrup 发明了 C++。
+   - 新语言称为“带类的C”。1983年，改名为 C++。
+   - C++ 在1997年11月被标准化（ANSI/ISO）。
