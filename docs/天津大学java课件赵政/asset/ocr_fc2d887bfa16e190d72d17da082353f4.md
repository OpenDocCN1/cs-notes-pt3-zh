# 3.10 表达式中类型的自动提升

+   - 对中间值的精确要求有时超过任何一个操作数的范围。例如：
+   
+     ```java
+     byte a = 40;
+     byte b = 50;
+     byte c = 100;
+     int d = a * b / c;  // 自动提升byte型或short型操作数到int型。
+     ```

+   - 自动类型提升有好处，也会引起编译错误。例如：
+   
+     ```java
+     byte b = 50;  // 表达式求值时自动提升为int
+     b = b * 2;    // Error! Cannot assign an int to a byte!
+     ```

+   - 使用一个显式的强制类型转换，
+   
+     ```java
+     byte b = 50;
+     b = (byte)(b * 2);
+     ```
