
## 4.6 ? 运算符

- 二元运算符用于取代某个类型的 if-then-else 语句。
- 通用格式如下：

    `expression1 ? expression2 : expression3`

- exp1 是一个布尔表达式，exp2 和 exp3 是除了 void 以外的任何类型的表达式，且它们的类型必须相同。
- 例子：

    `ratio = denom == 0 ? 0 : num / denom;`

## 4.8 使用圆括号

- 圆括号提高了括在其中的运算的优先级。
- 3 加到变量 b，得到一个中间结果，然后将变量 a 右移该中间结果位：

    ```java
    a >> b + 3
    ```

    或 `a >> (b + 3)` 而不是 `(a >> b) + 3`

- 括号有时被用来帮助澄清表达式的含义：

    ```java
    a | 4 + c >> b & 7
    (a | ((((4 + c) >> b) & 7)))
    ```

- 圆括号（不管是不是多余的）不会降低你程序的运行速度。

## 第05章 程序控制语句

- 编程语言使用控制（control）语句来产生执行流，从而完成程序状态的改变。
- 重复：（Iteration）语句使程序能够重复执行一个或一个以上语句（也就是说，重复语句形成循环）。

### 5.1 Java 的选择语句

### 5.1.1 if 语句

- If 语句是 Java 中的条件分支语句。
- 完整格式如下：

    ```java
    if (condition) statement1;
    else statement2;
    ```

- 例子：

    ```java
    int a, b;
    // ...
    if(a < b) a = 0;
    else b = 0;
    ```

### 5.1.1 if 语句（续）

- 建一个程序块以包含更多的语句：

    ```java
    int bytesAvailable;
    // ...
    if (bytesAvailable > 0) {
      ProcessData();
      bytesAvailable -= n;
    } else
      waitForMoreData();
    ```

- 适当定义块：

    ```java
    int bytesAvailable;
    // ...
    if (bytesAvailable > 0) {
      ProcessData();
      bytesAvailable -= n;
    } else {
      waitForMoreData();
      bytesAvailable = n;
    }
    ```

### 嵌套 if 语句

- 嵌套 if 语句是指该 if 语句为另一个 if 或者 else 语句的对象。
- 一个 else 语句总是对应着和它在同一个块中的最近的 if 语句。
- 例子：

    ```java
    if(i == 10) {
      if(j < 20) a = b;
      if(k > 100) c = d;  // this if is
      else a = c;         // associated with this else
    }
    else a = d;           // this else refers to if(i == 10)
    ```

### if-else-if 阶梯

- 语法如下：

    ```java
    if(condition)
      statement;
    else if(condition)
      statement;
    else if(condition)
      statement;
    .
    .
    .
    else
      statement;
    ```

### 例 P71 使用if-else-if阶梯来确定某个月是什么季节

```java
// Demonstrate if-else-if statements.
class IfElse {
    public static void main(String args[]) {
        int month = 4; // April
        String season;
        if(month == 12 || month == 1 || month == 2)
            season = "Winter";
        else if(month == 3 || month == 4 || month == 5)
            season = "Spring";
        else if(month == 6 || month == 7 || month == 8)
            season = "Summer";
        else if(month == 9 || month == 10 || month == 11)
            season = "Autumn";
        else
            season = "Bogus Month";
        System.out.println("April is in the " + season + ".");
    }
}
```

Ans:

April is in the Spring.

### 5.1.2 switch语句

- 基于一个表达式的值来使程序执行不同部分的简单方法。
- 通用形式如下：

    ```java
    switch (expression) {    // exp 必须为 byte，short，int 或 char 类型
        case value1:          // value 必须是与表达式类型兼容的常量
            // statement sequence
            break;    // 当遇break时，程序将从switch后的第一行代码开始继续执行
        case value2:
            // statement sequence
            break;
        .
        .
        case valueN:
            // statement sequence
            break;
        default: // 若无case常量与值相匹配，则执行default语句。default是可选。
        // default statement sequence
    }
    ```

### 例 P72 使用switch语句的简单例子

```java
// A simple example of the switch.
class SampleSwitch {
    public static void main(String args[]) {
        for(int i=0; i<6; i++)
            switch(i) {
                case 0:
                    System.out.println("i is zero.");
                    break;
                case 1:
                    System.out.println("i is one.");
                    break;
                case 2:
                    System.out.println("i is two.");
                    break;
                case 3:
                    System.out.println("i is three.");
                    break;
                default:
                    System.out.println("i is greater than 3.");
            }
    }
}
```
