

## 7.8 介绍 final

- 一个变量可以声明为 final，这样做的目的是阻止它的内容被修改。
- 在声明 final 变量的时候，你必须初始化。
- 例如：
  ```java
  final int FILE_NEW = 1;
  final int FILE_OPEN = 2;
  final int FILE_SAVE = 3;
  final int FILE_SAVEAS = 4;
  final int FILE_QUIT = 5;
  ```
- final 变量的所有的字符一般都大写。
- 一个 final 变量实质上是一个常数。

## 7.9 重新温习数组

- 数组是作为对象来实现的。
- 数组的大小（一个数组能保存的元素的数目）可以在数组的 `length` 实例变量中找到。
- 所有的数组都有这个变量，并且它总是保存数组的大小。
- `length` 的值和数组实际使用的元素的个数没有关系。`Length` 仅反映了数组能够包含的元素的数目。

## 例 P126 上

### 数组的大小

```java
// This program demonstrates the length array member.
class Length {
public static void main(String args[]) {
int a1[] = new int[10];
int a2[] = { 3, 5, 7, 1, 8, 99, 44, -10 };
int a3[] = { 4, 3, 2, 1 };
System.out.println("length of a1 is " + a1.length);
System.out.println("length of a2 is " + a2.length);
System.out.println("length of a3 is " + a3.length);
}
}
```

### Ans:

length of a1 is 10
length of a2 is 8
length of a3 is 4

## 例 P126 下

### 任意长度的堆栈

```java
// Improved Stack class that uses the length array member.
class Stack {
    private int stck[];
    private int tos;
    // allocate and initialize stack
    Stack(int size) {
        stck = new int[size];
        tos = -1;
    }
    // Push an item onto the stack
    void push(int item) {
        // use length member, stck.length的值用来防止堆栈溢出。
        if(tos==stck.length-1)
            System.out.println("Stack is full.");
        else
            stck[++tos] = item;
    }
    // Pop an item from the stack
    int pop() {
        if(tos < 0) {
            System.out.println("Stack underflow.");
            return 0;
        }
        else return stck[tos--];
    }
}

class TestStack2 {
    public static void main(String args[]) {
        Stack mystack1 = new Stack(5);
        Stack mystack2 = new Stack(8);
        // push some numbers onto the stack
        for(int i=0; i<5; i++) mystack1.push(i);
        for(int i=0; i<8; i++) mystack2.push(i);
        // pop those numbers off the stack
        System.out.println("Stack in mystack1:");
        for(int i=0; i<5; i++)
            System.out.println(mystack1.pop());
        System.out.println("Stack in mystack2:");
        for(int i=0; i<8; i++)
            System.out.println(mystack2.pop());
    }
}
```

### Ans:

Stack in mystack1:
4
3
2
1
0
Stack in mystack2:
7
6
5
4
3
2
1
0

## 7.10 介绍嵌套类和内部类

- 在另一个类中定义的类就是嵌套类（nested classes）。
- 嵌套类可以访问包围类的成员，包括 private 成员。包围类不能访问嵌套类的成员。
- 前面加 static 标识符：只能通过对象来访问它包围类的成员，static 嵌套类很少使用。
- 前面不加 static 标识符（inner class）：可以访问它的包围类的所有变量和方法。
- 尽管嵌套类在日常的大多数编程中不使用，但当处理 applet 时是特别有帮助的。

## 例 P128上 如何定义和使用一个内部类

```java
// Demonstrate an inner class.
class Outer {
    int outer_x = 100;
    void test() {
        Inner inner = new Inner();
        inner.display();
    }
    // this is an inner class
    class Inner {
        void display() {
            System.out.println("display: outer_x = " + outer_x);
        }
    }
}
class InnerClassDemo {
    public static void main(String args[]) {
        Outer outer = new Outer();
        outer.test();
    }
}
```

### Ans:

display: outer_x = 100

## 例 P128下 内部类的成员不能被外部类使用

```java
// This program will not compile.
class Outer {
  int outer_x = 100;
  void test() {
    Inner inner = new Inner();
    inner.display();
  }
  // this is an inner class
  class Inner {
    int y = 10; // y is local to Inner
    void display() {
      System.out.println("display: outer_x = " + outer_x);
    }
  }
  void showy() {
    System.out.println(y);  // error, y not known here!
  }
}

class InnerClassDemo {
public static void main(String args[]) {
Outer outer = new Outer();
outer.test();
}
}
```

// y 是作为 Inner 的一个实例变量来声明的。这样对
// 于该类的外部它就是不可知的，因此不能被
// showy() 使用。
