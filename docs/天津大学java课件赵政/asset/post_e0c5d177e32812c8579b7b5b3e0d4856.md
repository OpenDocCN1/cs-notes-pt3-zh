

## 8.2 使用 super

- 创建一个超类，该超类可以保持它自己实现的细节（它保持私有的数据成员）。
- 子类没有办法直接访问或初始化它自己的这些变量。
- 子类若直接访问超类，可以用关键字 super 来实现。
- 第一种：调用超类的构造函数。
- 第二种：用来访问被子类的成员隐藏的超类成员。

## 例 P139

# Box Weight()的改进版本

```java
// Box Weight now uses super to initialize its Box attributes.

class BoxWeight extends Box {
    double weight;        // weight of box
    // initialize width, height, and depth using super()
    BoxWeight(double w, double h, double d, double m) {
        super(w, h, d); // call superclass constructor
        weight = m;
    }
}
// BoxWeight不再自己初始化width, height, and depth。
// 只需初始化它自己的特殊值：weight。
// 使Box可以自由的根据需要把这些值声明成private。
```

## 例 P140

# Box Weight()的完整的实现版本

```java
// A complete implementation of Box Weight.
class Box {
    private double width;
    private double height;
    private double depth;

    // construct clone of an object
    Box(Box ob) {       // pass object to constructor
        width = ob.width;
        height = ob.height;
        depth = ob.depth;
    }

    // constructor used when all dimensions specified
    Box(double w, double h, double d) {
        width = w;
        height = h;
        depth = d;
    }
}
```

```java
// constructor used when no dimensions specified
Box() {
    width = -1; // use -1 to indicate
    height = -1; // an uninitialized
    depth = -1; // box
}
// constructor used when cube is created
Box(double len) {
    width = height = depth = len;
}
// compute and return volume
double volume() {
    return width * height * depth;
}
}
```

```java
// Box Weight now fully implements all constructors.
class BoxWeight extends Box {
    double weight; // weight of box

    // construct clone of an object
    BoxWeight(BoxWeight ob) { // pass object to constructor
        super(ob);
        weight = ob.weight;
    }

    // constructor when all parameters are specified
    BoxWeight(double w, double h, double d, double m) {
        super(w, h, d); // call superclass constructor
        weight = m;
    }

    // default constructor
    BoxWeight() {
        super();
        weight = -1;
    }

    // constructor used when cube is created
    BoxWeight(double len, double m) {
        super(len);
        weight = m;
    }
}
```

```java
class DemoSuper {
public static void main(String args[]) {
BoxWeight mybox1 = new BoxWeight(10, 20, 15, 34.3);
```

## ## 8.2.2 Super的第2种用法

- 总是引用它所在子类的超类，它的行为有点像 this。
- 通用形式：
  ```
  super.member
  ```
  // member既可以是1个方法也可以是1个实例变量。
- 多数是用于超类成员名被子类中同样的成员名隐藏的情况。

## # 例 P142

// Using super to overcome name hiding.
class A {
int i;
}
class B extends A {
int i; // this i hides the i in A
B(int a, int b) {
super.i = a; // i in A
i = b; // i in B
}
void show() {
System.out.println("i in superclass: " + super.i);
System.out.println("i in subclass: " + i);
}
}
class UseSuper {
public static void main(String args[]) {
B subOb = new B(1, 2);
subOb.show();
}
}
