# # Bresenham Line Algorithm

+   - Let e as the error variable of y: \( e=-0.5 \)
+     \(\left\{\begin{array}{l} when \ e \geq 0 \ take \ (x+1, y+1) \\ when \ e < 0 \ take \ (x+1, y) \end{array}\right.\)

+   - The increment of error variable is simply the line slope \( k \), \( e=e+k \).

\( if \ e \geq 0 \ e=e-1 \)

![](bbox=[0.512, 0.233, 0.934, 0.514])

```
```cpp
BresenhamLine(x0,y0,x1,y1,color){
    dx=x1-x0; dy=y1-y0; k=dy/dx; e=-0.5; x=x0; y=y0;
    for(i=0; i<=dx; i++){
        drawpixel(x,y,color); x=x+1; e=e+k;
        if(e>=0){ y=y+1; e=e-1;}
    }
}
