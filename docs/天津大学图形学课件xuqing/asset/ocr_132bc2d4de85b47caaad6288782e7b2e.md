# # 2D Transformation

# ## 1. Translation

+   - Translation is an operation that displace points by a fixed distance in a given direction.

Move point P(x,y) to P'(x',y')

\(x' = x + \Delta x, y' = y + \Delta y\)

Then

\(\begin{bmatrix} x' \\ y' \end{bmatrix} = \begin{bmatrix} x \\ y \end{bmatrix} + \begin{bmatrix} \Delta x \\ \Delta y \end{bmatrix}\)
