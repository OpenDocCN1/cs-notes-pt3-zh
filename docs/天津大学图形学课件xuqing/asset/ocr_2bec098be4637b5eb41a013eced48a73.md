# # Drawing Geometry

+   - Vertices can define a variety of geometric objects, and different numbers of vertices are required depending on the object.

+   - We can group as many vertices as desired, using the functions glBegin() and glEnd()

+   - Types of primitives glBegin (GLenum primitiveType)

+   - Example:

```
```
glBegin (GL_POLYGON);
glVertex3f(-. 5f, -. 5f, -. 5f);
glVertex3f(. 5f, -. 5f, -. 5f);
glVertex3f(-. 5f, .5f, -. 5f);
glVertex3f(. 5f, .5f, -. 5f);
glEnd();
