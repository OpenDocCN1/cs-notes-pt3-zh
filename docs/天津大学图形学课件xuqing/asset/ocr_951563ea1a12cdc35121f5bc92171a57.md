# # DDA Algorithm

```
```c
DDALine(x0, y0, x1, y1, color)
int x0, y0, x1, y1, color;
{   int x;
    float dx, dy, k, y);
    dx = x1 - x0;
    dy = y1 - y0;
    k = dy/dx;
    y = y0;
    for(x=x0; x<=x1; x++)
    {   drawpixel(x, int(y+0.5),color);
        y = y + k;
    }
}
```
```

+   - Suitable for \(|k| \le 1\) , else the roles of x and y need to be swapped and the increment should be 1/k.

+   - y and k are float type numbers, it is hard to be implemented by hardware.
