# # OpenGL Utility Library GLU

+   - Utility library is a set of commonly used graphics routines
+     - built on top of OpenGL
+   - Uses lower level OpenGL commands for
+     - Setting up matrixes for viewing and projection
+     - Performing polygon tessellation
+       - concave polygons, polygons with holes, self- intersecting polygons, ..
+     - Rendering surfaces (spheres, cylinders, disks, ..)
+     - Mipmapping
+     - NURBS (Non-Uniform Rational B-Spline) curves
+     - Error handling
+   - This library is part of the OpenGL implementation
