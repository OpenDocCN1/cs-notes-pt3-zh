# # Spatial-Occupancy Enumeration

◆ The solid is decomposed into identical cells (called voxels) arranged in a fixed, regular grid.

![](bbox=[0.041, 0.389, 0.622, 0.88])

+   ◆ To represent an object, we need only to decide which cells are occupied and which are not.
+   
+   ◆ The object can be encoded by a unique and unambiguous list of occupied cells.
+
