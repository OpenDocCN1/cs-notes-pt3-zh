# # Illumination

# ## Elements of object appearance:

+   - Geometry
+   - Surface property
+   - Light source

# ## Basic illumination components

+   - Ambient
+     - Not from light source directly
+   - Diffuse
+     - From a light source, the reflection is spread to all hemisphere directions evenly
+   - Specular
+     - From a light source, the reflection is focused to some directions
