# # Flood Fill

![](bbox=[0.031, 0.344, 0.328, 0.727])

+   - If we can find an initial point(x.y) inside the polygon- a seed point - then we can look at its neighbors recursively, coloring them with the foreground color if they are not edge point.

```
```c
flood_fill(int x, int y)
{
    if(read_pixel(x,y)=WHITE)
    {
        write_pixel(x,y,BLACK);
        flood_fill(x-1,y);
        flood_fill(x+1,y);
        flood_fill(x,y-1);
        flood_fill(x,y+1);
    }
}
