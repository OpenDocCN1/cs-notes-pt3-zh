# # Spartial-Partitioning Representations

+   - A solid is decomposed into a collection of adjoining, nonintersecting solids that are more primitive than, although not necessary of the same type as, the original solid.
+   - Primitives may vary in type, size, position, parameterization and orientation, much like the different-shaped blocks in a child’s block set.
+   - Also called Decomposition Representation(D-reps)
