# # Z-Buffer Algorithm

+   - Advantages:
+     - easy to implement, in either hardware or software.
+     - compatible with pipeline architectures.
+     - can be regarded as part of the scan-conversion process.
+   - Z-Buffer, a depth buffer with same resolution as the frame buffer, each element in this buffer contains the distance along the ray corresponding to this location of the closest intersection point on any polygon found so far.
