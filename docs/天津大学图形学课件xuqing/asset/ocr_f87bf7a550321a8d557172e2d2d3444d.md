# # Octree

![](bbox=[0.128, 0.312, 0.448, 0.756])

# ## Advantages:

+   - Simple data structure
+   - Easy for set operation
+   - Easy for inspecting collision between solid objects
+   - Easy for calculating object’s properties such as volume, mass, and so on.

# ## Drawback:

+   - Still need large amount memory
+   - Difficult to do transformation
+   - Difficult to transfer to b-reps
