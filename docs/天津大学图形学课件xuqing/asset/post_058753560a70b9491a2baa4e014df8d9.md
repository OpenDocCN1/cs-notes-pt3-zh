

## 贝塞尔(Bezier)曲线

- 贝塞尔曲线可以拟合任何数目的控制点。
- n+1个控制点的贝塞尔曲线公式，P(u)表示曲线上各点位置
- p<sub>k</sub>(x<sub>k</sub>,y<sub>k</sub>,z<sub>k</sub>) 为控制点
- 贝塞尔多项式BEZ<sub>k,n</sub>(u) 为：
- 曲线坐标表示：

P(u)=\sum_{k=0}^np_kBEZ_{k,n}(u) 其中0≤u≤1u=K/N,0≤K≤N

BEZ_{k,n}(u)=C(n,k)u^k(1-u)^{n-k}C(n,k)=\frac{n!}{k!(n-k)!}

x(u)=\sum_{k=0}^nx_kBEZ_{k,n}(u)

y(u)=\sum_{k=0}^ny_kBEZ_{k,n}(u)

z(u)=\sum_{k=0}^nz_kBEZ_{k,n}(u)

- In general, a Bezier curve section can be fitted to any number of control points
- Bezier curve equations:
  - n+1 control point( \(p_k=(x_k,y_k,z_k)\) )
  - position, \(P(u)\)denoted as,
  - position vector,
  - \(P(u)=\sum_{k=0}^n p_k BEZ_{k,n}(u)\) 其中\(0 \le u \le 1\)
  - \(u=K/N, 0 \le K \le N\)
- Bezier blending functions: \(BEZ_{k,n}(u)\)
  - \(BEZ_{k,n}(u)=C(n,k)u^k(1-u)^{n-k}\)
  - are the Bernstein polynomials:
  - \(C(n,k)=\frac{n!}{k!(n-k)!}\)
- Individual curve coordinates:
  - \(x(u)=\sum_{k=0}^n x_k BEZ_{k,n}(u)\)
  - \(y(u)=\sum_{k=0}^n y_k BEZ_{k,n}(u)\)
  - \(z(u)=\sum_{k=0}^n z_k BEZ_{k,n}(u)\)

## 贝塞尔曲线（几何解释）

- 设想有一组控制点，我们要用它们产生一条平滑的曲线。简单的用直线连接这些点，得到的结果是不平滑的，它可能有尖角。想象通过切除尖角来“平滑”多边形，产生一个平滑一些的多边形，但从数学意义上依旧不“平滑”。我们可以重复这个过程，每次都产生一个平滑一些的多边形，如下图所示。在有限范围内，无限次重复上述过程就可以得到平滑的曲线。

## 贝塞尔曲线（OpenGL）

glMap1*(GL_MAP1_*, uMin, uMax, stride, nPts, *ctrlP); 定义一维曲线  
glEnable(GL_MAP1_*); 激活曲线  
glEvalCoord1*(nvalue); 曲线路径的位置

```
GLfloat ctrlpoints[4][3] =
{
    {-4.0, -4.0, 0.0},   {-2.0, 4.0, 0.0},
    {2.0, -4.0, 0.0},    {4.0, 4.0, 0.0}
};
```

```
glMap1f(GL_MAP1_VERTEX_3, 0.0,
        1.0, 3, 4, &ctrlpoints[0][0]);
glEnable(GL_MAP1_VERTEX_3);
```

```
glBegin (GL_LINE_STRIP);
    for (i = 0; i <= 100; i++)
        glEvalCoord1f((GLfloat) i/100.0);
glEnd();
```

## 贝塞尔曲面（OpenGL）

- `glMap2*(GL_MAP2_*, uMin, uMax, ustride, unPts, vMin, vMax, vstride, vnPts, *ctrlP);` 定义二维曲线
- `glEnable(GL_MAP2_*);` 激活曲线
- `glEvalCoord2*(nvalue);` 曲线路径的位置

```
GLfloat ctrlpoints[4][4][3] = {...}
glMap2f(GL_MAP2_VERTEX_3, 0, 1, 3, 4,
        0, 1, 12, 4, &ctrlpoints[0][0][0]);
glEnable(GL_MAP2_VERTEX_3);
```

```
for (j = 0; j <= 8; j++)
{
    glBegin(GL_LINE_STRIP);
        for (i = 0; i <= 30; i++)
            glEvalCoord2f((GLfloat)i/30.0, (GLfloat)j/8.0);
    glEnd();
    glBegin(GL_LINE_STRIP);
        for (i = 0; i <= 30; i++)
            glEvalCoord2f((GLfloat)j/8.0, (GLfloat)i/30.0);
    glEnd();
}
```

## OpenGl Bezier-Spline Surface

1: specify parameters and active the routines for Bezier-curve display with the OpenGL functions:

- `glMap2*(GL_MAP2_*, uMin, uMax, ustride, unPts, vMin, vMax, vstride, vnPts, *ctrlP);`
- `glEnable(GL_MAP2_*);`

2: A coordinate position along the curve path is calculated with:

- `glEvalCoord2f(nvalue);`

```
GLfloat ctrlpoints[4][4][3] = {...}
glMap2f(GL_MAP2_VERTEX_3, 0, 1, 3, 4,
        0, 1, 12, 4, &ctrlpoints[0][0][0]);
glEnable(GL_MAP2_VERTEX_3);
for (j = 0; j <= 8; j++)
{
    glBegin (GL_LINE_STRIP);
        for (i = 0; i <= 30; i++)
            glEvalCoord2f((GLfloat)i/30.0, (GLfloat)j/8.0);
    glEnd();
    glBegin (GL_LINE_STRIP);
        for (i = 0; i <= 30; i++)
            glEvalCoord2f((GLfloat)j/8.0, (GLfloat)i/30.0)
    glEnd();
}
```
