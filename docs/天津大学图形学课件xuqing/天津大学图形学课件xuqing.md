## Pixels and the Frame Buffer

- A picture is produced as an array - the **raster** - of picture elements, **pixels**, within the graphics system.
- **Resolution** - number of pixels in the frame buffer
  - determines the detail that you can see in the image.
- The converting of geometric entities to pixel assignments in the frame buffer is known as **scan conversion**, or **rasterization**.

## Problems with RGB

- Only a small range of all the colors humans are capable of perceiving (particularly for monitor RGB)
  - Have you ever seen magenta on a monitor?
- It isn’t easy for humans to say how much of RGB to use to make a given color
  - How much R, G and B is there in “brown”? (Answer: .64, .16, .16)
- Negative matches *c+rR=+gG+bB*
- Perceptually non-linear (non-uniform)
  - Two points a certain distance apart in one part of the space may be perceptually different
  - Two other points, the same distance apart in another part of the space, may be perceptually the same

## An Introduction

OpenGL, the standard software interface for graphics hardware, allows programmers to create interactive 2D and 3D graphics applications on a variety of systems. With OpenGL you can create high-quality color images. OpenGL makes it easy to build geometric models, change the viewing position, control the color and lighting of geometric primitives, and manipulate pixel and texture map images. This course will cover an immediately applicable subset of OpenGL, so that you can write a simple graphics program.

## OpenGL Command Syntax

## Polygon Meshes

A *mesh* is a set of polygons connected to form an object

- A mesh has **several components**, or geometric entities:
  - Faces
  - Edges, the boundary between faces
  - Vertices, the boundaries between edges, or where three or more faces meet
  - Normals, texture coordinates, colors, shading coefficients, etc
- Some components are implicit, given the others
  - For instance, given faces and vertices, we can determine edges
  - Euler’s formula: #Faces + #Vertices − #Edges = 2 − 2Genus, for *closed* polygon meshes

## Spatial-Partitioning Representations

## Some definitions

- In drafting terminology, a spline is a flexible strip used to produce a smooth curve through a designated set of points.
- In computer graphics, the term spline curve now refers to any composite curve formed with polynomial section satisfying any specified continuity conditions at the boundary of the pieces.
- A spline surface can be described with two sets of orthogonal spline curves.
- A polyline connecting the sequence of control points for an approximation spline curve is usually displayed to remind a designer of the control-point positions and ordering. This set of connected line segments is called the control graph for the curve

- 逼近样条曲线：选取的多项式使部分或全部控制点都不再生成的曲线上。

## Parametric Continuity Conditions

- Zero-order parametric continuity, represented as $C_0$ continuity, means simply that the curves meet.
- First-order parametric continuity, referred to as $C_1$ continuity, means that the first parametric derivatives (tangent lines) of the coordinate functions for two successive curve sections are equal at their joining point.
- Second-order parametric continuity, or $C_2$ continuity, means that both the first and second parametric derivatives of the two curve sections are the same at the intersection.

![](img/258e4144ed4b66c8fd4b0f298118df23_123_0.png)

## 几何连续性

- 几何连续性：表示相邻两个曲线段的另一种连续性，并不要求两条曲线段在相交处的参数导数相等，而只要成比例即可。
- 0阶几何连续性 $G_0$：两个曲线段在公共点处有相同的坐标位置。
- 一阶几何连续性 $G_1$：一阶导数在两个相邻曲线段的交点处成比例（相邻曲线段在交点处的切向量大小不一定相等）。
- 二阶几何连续性 $G_3$：表示两个曲线段在相交处的一阶和二阶导数均成比例（交点处曲率相等）。
- 曲率：表示曲线弯曲程度的量，曲率越大，表示曲线的弯曲程度越大。

## Geometric Continuity Conditions

- Geometric continuity as another method for joining two successive curve sections is to specify conditions. Require only that the parametric derivatives of the two sections are proportional to each other at their common boundary, instead of requiring equality.
- Zero-order geometric continuity, described as $G_0$ continuity, is the same as zero-order parametric continuity. That is, two successive curve sections must have the same coordinate position at the boundary point.
- First-order geometric continuity, or $G_1$ continuity, means that parametric first derivatives are proportional at the intersection of two successive sections.
- Second-order geometric continuity, or $G_3$ continuity, means that both the first and second parametric derivatives of the two curve sections are proportional at their boundary.





## 贝塞尔(Bezier)曲线

- 贝塞尔曲线可以拟合任何数目的控制点。
- n+1个控制点的贝塞尔曲线公式，P(u)表示曲线上各点位置
- p<sub>k</sub>(x<sub>k</sub>,y<sub>k</sub>,z<sub>k</sub>) 为控制点
- 贝塞尔多项式BEZ<sub>k,n</sub>(u) 为：
- 曲线坐标表示：

P(u)=\sum_{k=0}^np_kBEZ_{k,n}(u) 其中0≤u≤1u=K/N,0≤K≤N

BEZ_{k,n}(u)=C(n,k)u^k(1-u)^{n-k}C(n,k)=\frac{n!}{k!(n-k)!}

x(u)=\sum_{k=0}^nx_kBEZ_{k,n}(u)

y(u)=\sum_{k=0}^ny_kBEZ_{k,n}(u)

z(u)=\sum_{k=0}^nz_kBEZ_{k,n}(u)

- In general, a Bezier curve section can be fitted to any number of control points
- Bezier curve equations:
  - n+1 control point( \(p_k=(x_k,y_k,z_k)\) )
  - position, \(P(u)\)denoted as,
  - position vector,
  - \(P(u)=\sum_{k=0}^n p_k BEZ_{k,n}(u)\) 其中\(0 \le u \le 1\)
  - \(u=K/N, 0 \le K \le N\)
- Bezier blending functions: \(BEZ_{k,n}(u)\)
  - \(BEZ_{k,n}(u)=C(n,k)u^k(1-u)^{n-k}\)
  - are the Bernstein polynomials:
  - \(C(n,k)=\frac{n!}{k!(n-k)!}\)
- Individual curve coordinates:
  - \(x(u)=\sum_{k=0}^n x_k BEZ_{k,n}(u)\)
  - \(y(u)=\sum_{k=0}^n y_k BEZ_{k,n}(u)\)
  - \(z(u)=\sum_{k=0}^n z_k BEZ_{k,n}(u)\)

## B 样条曲线

- B样条曲线允许任意阶连续，可以通过任意数目点生成满足C₂或更高阶连续性的曲线，函数的一般形式为：

- 分类
  - 均匀B样条曲线。
  - 非均匀B样条曲线。
  - 非均匀有理B样条曲线。

$$P(u) = \sum_{k=0}^n p_k B_{k,d}(u)$$
$$u_{min} \leq u \leq u_{max}$$
$$2 \leq d \leq n+1 \text{ (阶数)}$$

$$B_{k,1}(u) = \begin{cases} 1 & u_k \leq u \leq u_{k+1} \\ 0 & otherwise \end{cases}$$

$$B_{k,d}(u) = \frac{u - u_k}{u_{k+d-1} - u_k} B_{k,d-1}(u) + \frac{u_{k+d} - u}{u_{k+d} - u_{k+1}} B_{k+1,d-1}(u)$$

## B-Spline Curves

- Continuity: C₂ or higher

- including
  - uniform
  - Non-uniform
  - NURBS

$$P(u) = \sum_{k=0}^n p_k B_{k,d}(u)$$
$$u_{min} \le u \le u_{max}$$
$$2 \le d \le n + 1$$

$$B_{k,1}(u) = \begin{cases} 1 & u_k \le u \le u_{k+1} \\ 0 & otherwise \end{cases}$$

$$B_{k,d}(u) = \frac{u - u_k}{u_{k+d-1} - u_k} B_{k,d-1}(u) + \frac{u_{k+d} - u}{u_{k+d} - u_{k+1}} B_{k+1,d-1}(u)$$

## 均匀B样条曲线

- 均匀线性B样条曲线(d=2)。
- 线性B样条曲线是通过2个一次多项式片断定义的。

$$B_{i,2}(t) = \begin{cases} u & i \leq t < i+1 \quad u = t - i \\ i - u & i+1 \leq t < i+2 \quad u = t - (i+1) \\ 0 & otherwise \end{cases}$$

$$P(u) = (i - u)p_i + u p_{i+1}$$

![](img/258e4144ed4b66c8fd4b0f298118df23_138_0.png)

## Uniform B-Spline Curves

- Uniform linearity B-Spline Curves(d=2)。

$$B_{i,2}(t) = \begin{cases} u & i \leq t < i+1 \quad u = t-i \\ i-u & i+1 \leq t < i+2 \quad u = t-(i+1) \\ 0 & otherwise \end{cases}$$

$$P(u) = (i-u)p_i + up_{i+1}$$

![](img/258e4144ed4b66c8fd4b0f298118df23_139_0.png)

## 均匀B样条曲线

- 均匀二次B样条曲线(d=3)。
- 线性B样条曲线是通过3个二次多项式片断定义的。

$$B_{i,3}(t)=\begin{cases}
\frac{1}{2}u^2, & i\le t<i+1,\quad u=t-i\\
-u^2+u+\frac{1}{2}, & i+1\le t<i+2,\quad u=t-(i+1)\\
\frac{1}{2}(i-u)^2, & i+2\le t<i+3,\quad u=t-(i+2)\\
0, & otherwise
\end{cases}$$

$$P(u)=\frac{1}{2}(i-u)^2p_i+(-u^2+u+\frac{1}{2})p_{i+1}+\frac{1}{2}u^2p_{i+2}$$

![](img/258e4144ed4b66c8fd4b0f298118df23_140_0.png)

## Uniform B-Spline Curves

- Uniform Quadratic B-Spline (d=3)。

$$B_{i,3}(t)=\begin{cases}
\frac{1}{2}u^2 & i\le t<i+1,\quad u=t-i\\
-u^2+u+\frac{1}{2} & i+1\le t<i+2,\quad u=t-(i+1)\\
\frac{1}{2}(i-u)^2 & i+2\le t<i+3,\quad u=t-(i+2)\\
0 & \text{otherwise}
\end{cases}$$

$$P(u)=\frac{1}{2}(i-u)^2p_i+\left(-u^2+u+\frac{1}{2}\right)p_{i+1}+\frac{1}{2}u^2p_{i+2}$$

![](img/258e4144ed4b66c8fd4b0f298118df23_141_0.png)

## 均匀B样条曲线

- 均匀三次B样条曲线(d=4)。
- 线性B样条曲线是通过4个三次多项式片断定义的。

$$B_{i,3}(t) = \left\{ \begin{array}{ll} \frac{1}{6}u^3 & \quad i \leq t < i+1 \quad u = t-i \\ \frac{1}{6}(-3u^3 + 3u^2 + 3u + 1) & \quad i+1 \leq t < i+2 \quad u = t-(i+1) \\ \frac{1}{6}(3u^3 - 6u^2 + 4) & \quad i+2 \leq t < i+3 \quad u = t-(i+2) \\ \frac{1}{6}(-u^3 + 3u^2 - 3u + 1) & \quad i+3 \leq t < i+4 \quad u = t-(i+3) \\ 0 & \quad otherwise \end{array} \right.$$

$$P(u) = \frac{1}{6}(-u^3 + 3u^2 - 3u + 1)p_i + \frac{1}{6}(3u^3 - 6u^2 + 4)p_{i+1} + \frac{1}{6}(-3u^3 + 3u^2 + 3u + 1)p_{i+2} + \frac{1}{6}u^3 p_{i+3}$$

![](img/258e4144ed4b66c8fd4b0f298118df23_142_0.png)

## Uniform B-Spline Curves

- Uniform Cubic B-Spline Curves (d=4)。

$$B_{i,4}(t) = \begin{cases} \frac{1}{6}u^3 & i \le t < i+1 \quad u=t-i \\ \frac{1}{6}(-3u^3 + 3u^2 + 3u + 1) & i+1 \le t < i+2 \quad u=t-(i+1) \\ \frac{1}{6}(3u^3 - 6u^2 + 4) & i+2 \le t < i+3 \quad u=t-(i+2) \\ \frac{1}{6}(-u^3 + 3u^2 - 3u + 1) & i+3 \le t < i+4 \quad u=t-(i+3) \\ 0 & otherwise \end{cases}$$

$$P(u) = \frac{1}{6}(-u^3 + 3u^2 - 3u + 1)p_i + \frac{1}{6}(3u^3 - 6u^2 + 4)p_{i+1} + \frac{1}{6}(-3u^3 + 3u^2 + 3u + 1)p_{i+2} + \frac{1}{6}u^3 p_{i+3}$$

![](img/258e4144ed4b66c8fd4b0f298118df23_143_0.png)

## 非均匀B样条曲线

- 非均匀B样条曲线通过在节点向量中取不同间距来实现。
- 使用类似于均匀B样条曲线中使用的方法，可以得到非均匀B样条曲线的混合函数。
- 实际中间距取0或1，以方便计算。

## 非均匀有理B样条曲线（NURBS）

- 虽然B样条曲线有很多优点，但是仍然有一些函数不能准确的用它们来表示。特别是B样条曲线不能表示圆锥的部分。
- 为了表示这样的曲线，采用了两个多项式的比例，用非均匀有理样条曲线表示分子和分母，最一般的形式是非均匀有理B样条曲线。
- 非均匀有理B样条把每一个控制点 $p_k$ 与一个权值 $h_k$ 相连，并对分子分母使用同样的B样条曲线。

$$P(u)=\frac{\sum_{k=1}^{n}h_k p_k B_{k,d}}{\sum_{k=1}^{n}h_k B_{k,d}}$$

\( z' = z \)

\[ \begin{bmatrix} \sin \alpha & 0 & \cos \alpha \\ 0 & 1 & 0 \\ \cos \alpha & 0 & -\sin \alpha \end{bmatrix} \quad , \quad \begin{bmatrix} 1 & 0 & 0 \\ 0 & \cos \alpha & -\sin \alpha \\ 0 & \sin \alpha & \cos \alpha \end{bmatrix} \]

## Ray Tracing

- Cast rays out from the eye, through each pixel, and determine what they hit first
  - Builds the image pixel by pixel, one at a time
- Cast additional rays from the hit point to determine the pixel color
  - Shadow rays toward each light. If they hit something, then the object is shadowed from that light, otherwise use “standard” model for the light
  - Reflection rays for mirror surfaces, to see what should be reflected in the mirror (ideally specular reflection)
  - Transmission rays to see what can be seen through transparent objects (ideally refraction)
  - Sum all the contributions to get the pixel color

void TraceRay(start, direction, depth, color)
{
    if (depth > MaxDepth)
        *color = Black;
    else {
        if (RayHit(start, direction, &hitPoint, &hitObject) == Nothing)
            *color = BackGround;
        else {
            Shade(hitObject, hitPoint, &localColor);
            CalculateReflection(hitObject, hitPoint, direction, &rDirection);
            CalculateTransmission(hitObject, hitPoint, direction, &tDirection);
            TraceRay(hitPoint, rDirection, depth + 1, &rColor);
            TraceRay(hitPoint, tDirection, depth + 1, &tColor);
            CombineColor(localColor, rColor, hitObject.ks, tColor,
                         hitObject.kt, color);
        }
    }
}

## Digital Differential Analyzer (DDA)

\(y = kx + B\)

`pixel[x, round(y)]`

\[

\]

\[

\[

\]

\[
= y_i + k
\]

Float increment

\[
k = \Delta y / \Delta x
\]

\[
(\Delta x = x_1 - x_0,\quad \Delta y = y_1 - y_0)
\]

## DDA Algorithm

```c
DDALine(x0, y0, x1, y1, color)
int x0, y0, x1, y1, color;
{   int x;
    float dx, dy, k, y;
    dx = x1 - x0;
    dy = y1 - y0;
    k = dy/dx;
    y = y0;
    for(x = x0; x <= x1; x++)
    {   drawpixel(x, int(y + 0.5), color);
        y = y + k;
    }
}
```

- Suitable for \(|k| \le 1\); otherwise the roles of x and y need to be swapped and the increment should be \(1/k\).
- y and k are float type numbers; it is hard to implement them by hardware.

## Bresenham Line Algorithm

- Let \(e\) be the error variable of \(y\): \(e = -0.5\)
  \[
  \begin{cases}
  \text{when } e \geq 0 & \text{take } (x+1, y+1) \\
  \text{when } e < 0 & \text{take } (x+1, y)
  \end{cases}
  \]
- The increment of error variable is simply the line slope \(k\), \(e = e + k\).

If \(e \geq 0\), \(e = e - 1\).

![](img/258e4144ed4b66c8fd4b0f298118df23_230_0.png)

```cpp
BresenhamLine(x0, y0, x1, y1, color) {
    dx = x1 - x0; dy = y1 - y0; k = dy/dx; e = -0.5; x = x0; y = y0;
    for(i = 0; i <= dx; i++) {
        drawpixel(x, y, color); x = x + 1; e = e + k;
        if(e >= 0) { y = y + 1; e = e - 1; }
    }
}
```

## Polygon Filling

- The basic rule for filling a polygon is:
  - If a point is inside the polygon, color it with the inside color.
- Polygon fill is a sorting problem, where we sort all the pixels in the frame buffer into those that are inside the polygon, and those that are not.
- Three possibilities:
  - Flood fill
  - Scan-line fill
  - Odd-even fill

## Flood Fill

![](img/258e4144ed4b66c8fd4b0f298118df23_232_0.png)

- If we can find an initial point (x, y) inside the polygon — a seed point — then we can look at its neighbors recursively, coloring them with the foreground color if they are not edge points.

```c
void flood_fill(int x, int y)
{
    if(read_pixel(x, y) == WHITE)
    {
        write_pixel(x, y, BLACK);
        flood_fill(x - 1, y);
        flood_fill(x + 1, y);
        flood_fill(x, y - 1);
        flood_fill(x, y + 1);
    }
}
```

## Cohen-Sutherland Clipping

• Each region can be assigned a unique 4-bit binary number, or **outcode** b₀b₁b₂b₃ (up, down, right, left).

$b_0 = \begin{cases}1 & \text{if } y > y_{max} \\ 0 & \text{otherwise}\end{cases}$

Likewise for $b_1, b_2, b_3$

$o_1 = outcode(x_1,y_1);\ o_2 = outcode(x_2,y_2)$

| $b_0$ | 1001 | 1000 | 1010 |
|---|---|---|---|
|  | 0001 | **0000** | 0010 |
| $b_1$ | 0101 | 0100 | 0110 |

中心区域为 0000；上方边界标记为 $y=y_{max}$，下方边界标记为 $y=y_{min}$，左侧边界为 $x=x_{min}$，右侧边界为 $x=x_{max}$。

1. $o_1=o_2=0$; **AB** (inside completely)
2. $o_1\ne0, o_2=0$; **CD** *(or vice versa)*
3. $o_1 \& o_2\ne0$; **EF** (outside completely)
4. $o_1 \& o_2=0$; **GH or IJ**

## Z-Buffer Algorithm

- Advantages:
  - easy to implement, in either hardware or software.
  - compatible with pipeline architectures.
  - can be regarded as part of the scan-conversion process.
- Z-Buffer, a depth buffer with same resolution as the frame buffer, each element in this buffer contains the distance along the ray corresponding to this location of the closest intersection point on any polygon found so far.

ax + by + cz + d = 0
Δx = x2 - x1
Δy = y2 - y1
Δz = z2 - z1
aΔx + bΔy + cΔz = 0
Δz = -a/c Δx

Incremental!

## The Z-buffer

- For each pixel on screen, have at least two buffers
  - Color buffer stores the current color of each pixel
    - The thing to ultimately display
  - Z-Buffer stores at each pixel the depth of the nearest thing seen so far
    - Also called the depth buffer

- Initialize this buffer to a value corresponding to the furthest point (z=1.0 for canonical and window space)

- As a polygon is filled in, compute the depth value of each pixel that is to be filled
  - if depth < z-buffer depth, fill in pixel color and new depth
  - else disregard

## The Z-buffer

- **Example:**
  With a z buffer with a range of 0 (at the image plane) to 10 (at the far clipping plane), and a 6x6 pixel image. For simplicity, all vertices of a polygon are at the same depth.
