# # Strict Alternation

```
```c
while (TRUE) {
    while (turn != 0)
        /* loop */;
    critical_region();
    turn = 1;
    noncritical_region();
}
```
```

```
```c
while (TRUE) {
    while (turn != 1)
        /* loop */;
    critical_region();
    turn = 0;
    noncritical_region();
}
```
```

A proposed solution to the critical region problem. (a) Process 0. (b) Process 1. In both cases, be sure to note the semicolons terminating the while statements.
