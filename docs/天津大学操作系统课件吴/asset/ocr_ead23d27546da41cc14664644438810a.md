# # Resource Acquisition (1)

```
typedef int semaphore;
semaphore resource__1;

void process__A(void) {
    down(&resource__1);
    use__resource__1();
    up(&resource__1);
}
```

```
typedef int semaphore;
semaphore resource__1;
semaphore resource__2;

void process__A(void) {
    down(&resource__1);
    down(&resource__2);
    use__both__resources();
    up(&resource__2);
    up(&resource__1);
}
```
