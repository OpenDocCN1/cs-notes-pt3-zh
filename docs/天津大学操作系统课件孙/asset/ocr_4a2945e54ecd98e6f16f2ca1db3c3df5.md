# # Logical volume commands

+   - `lvcreate -L <size> [-n <lv name>] <vg> [<pv>...]`
+     - Create a logical volume in a volume group

![](bbox=[0.068, 0.387, 0.864, 0.674])

+   - `lvdisplay <lv> [<lv>...]`
+     - Display information about a logical volume

+   - `lvremove <lv> [<lv>...]`
+     - Remove a logical volume
