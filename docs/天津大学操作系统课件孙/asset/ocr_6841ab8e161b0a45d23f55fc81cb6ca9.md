# # Permissions Notation

rwxrwxrwx

owner   group   other

| r   | read    |
| --- | ------- |
| w   | write   |
| x   | execute |

Regular files:
r   file is readable
w   file is writeable
x   file is executable ( if in an executable format )

Directories:
r   contents of directory can be listed (ls)
w   contents can be modified (add/delete files)
x   change into directory is possible (cd)
