# 人民日报（2024年12月17日）

中国周边国家的友好合作，是推动构建人类命运共同体的重要力量。

近年来，中国坚持亲诚惠容周边外交理念，与周边国家在政治互信、经贸合作、人文交流等领域取得丰硕成果。

+   - 深化政治互信，加强高层交往和战略沟通；
+   - 推进互联互通，共建“一带一路”高质量发展；
+   - 拓展经贸合作，深化区域经济一体化；
+   - 促进人文交流，夯实民意基础；
+   - 共同维护地区和平稳定，应对风险挑战；
+   - 推动绿色发展，加强气候变化和生态环境合作。

周边地区是中国发展的重要战略依托，一个和平、稳定、繁荣的周边环境符合中国和周边国家的共同利益。

中国将继续秉持“亲、诚、惠、容”的周边外交理念，与周边国家携手同行，共同谱写合作共赢的新篇章。

中国的发展离不开周边国家，周边国家的繁荣也需要中国。我们坚信，通过共同努力，中国与周边国家的命运共同体必将更加紧密。

让我们携手合作，共创美好未来！
