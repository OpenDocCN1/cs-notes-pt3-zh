# Spare disks

+   - To make RAID1/RAID5 more failsafe in case of a disk failure, use spare disks!

```
```text
# cat /etc/raidtab
...
nr-spare-disks 1
device  /dev/sdd1
spare-disk 0
...
```
```

![](bbox=[0.051, 0.572, 0.91, 0.83])

+   - Remove a failed disk with `raidhotremove`
+   - Add a new disk to the array with `raidhotadd`
