# # 多表查询 – 连接

● 查询s06001同学的选课信息，输出课程号、课程及学分  
SELECT 课程表.课号，课程表.课名，课程表.学分  
FROM 选课表，课程表  
WHERE 选课表.学号 = 's06001' AND  
选课表.课号 = 课程表.课号；
