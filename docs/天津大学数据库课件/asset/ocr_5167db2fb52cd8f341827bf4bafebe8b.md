# 人工管理阶段数据管理示例

+   - 例：两个C语言程序，分别求10个数据之和和最大值。

```
/* 程序1：求10个数之和 */
#include <stdio.h>
main()
{
    int i,s=0;
    int a[10]={66,55,75,42,86,77,96,89,78,56};
    for(i=0;i<10;i++)
        s=s+a[i];
    printf("%d",s);
}
```

```
/* 程序2：求10个数中的最大值 */
#include <stdio.h>
main()
{
    int i,s;
    int a[10]={66,55,75,42,86,77,96,89,78,56};
    s=a[0];
    for(i=1;i<10;i++)
        if(s<a[i]) s=a[i];
    printf("%d",s);
```
