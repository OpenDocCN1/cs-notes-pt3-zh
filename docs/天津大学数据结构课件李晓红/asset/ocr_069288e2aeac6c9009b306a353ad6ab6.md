# 折半查找的性能分析

+   • 判定树：描述查找过程的二叉树。
+   • 有 n 个结点的判定树的深度为 ⌊log₂ n⌋ + 1
+   • 折半查找法在查找过程中进行的比较次数最多不超过 ⌊log₂ n⌋ + 1

先看一个有11个元素的表的例子：n=11
