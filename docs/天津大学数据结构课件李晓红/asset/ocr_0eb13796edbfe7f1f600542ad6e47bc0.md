# ❖ 归并排序的主算法

```
void MergeSort ( SortData initList[ ], int n ) {\n//按对象排序码非递减的顺序对表中对象排序\n    SortData tempList[n];\n    int len = 1;\n    while ( len < n ) {\n        MergePass ( initList, tempList, len );\n        len *= 2;\n        MergePass ( tempList, initList, len );\n        len *= 2;\n    }\n}
```
