# # 各种排序方法的比较

| 排序方法 | 比较次数 | 移动次数 | 稳定性 | 附加存储 |
|---|---|---|---|---|
| 直接插入排序 | n | n^2 | 0 | n^2 | √ | 1 |
| 折半插入排序 | n log,n | 0 | n^2 | √ | 1 |
| 起泡排序 | n | n^2 | 0 | n^2 | √ | 1 |
| 快速排序 | nlog,n | n^2 | n log,n | n^2 | × | log,n | n^2 |
| 简单选择排序 | n^2 | 0 | n | × | 1 |
| 锦标赛排序 | n log,n | n log,n | √ | n |
| 堆排序 | n log,n | n log,n | × | 1 |
| 归并排序 | n log,n | n log,n | √ | n |
