# 折半查找算法实现

+   1. 设表长为 n，low、high 和 mid 分别指向待查元素所在区间的上界、下界和中点，k 为给定值。
+   2. 初始时，令
+      ```
+      low=1, high=n, mid=⌊(low+high)/2⌋
+      ```
+      让 k 与 mid 指向的记录比较：
+      - 若 k==r[mid].key，查找成功
+      - 若 k<r[mid].key，则 high=mid-1
+      - 若 k>r[mid].key，则 low=mid+1
+   3. 重复上述操作，直至 low>high 时，查找失败。
