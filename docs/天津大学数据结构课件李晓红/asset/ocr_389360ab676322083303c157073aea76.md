# 链队列的主要操作

+   - 初始化

```
void InitQueue ( LinkQueue *Q ) {
    Q->rear = Q->front = NULL;
}
```

+   - 队空

```
int QueueEmpty ( LinkQueue *Q ) {
    return Q->front == NULL;
}
```

+   - 取队头元素

```
int GetFront ( LinkQueue *Q, QueueData &x ) {
    if ( QueueEmpty (Q) ) return 0;
    x = Q->front->data;  return 1;
}
```
