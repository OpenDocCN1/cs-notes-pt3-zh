# # 性质5 如将一棵有n个结点的完全二叉树自顶向下，同一层自左向右连续给结点编号0, 1, 2, ..., n-1，则有以下关系：

+   - 若i = 0，则 i 无双亲  
+     若i > 0，则 i 的双亲为⌊(i - 1)/2⌋

+   - 若2*i+1 < n，则 i 的左子女为 2*i+1，若2*i+2 < n，则 i 的右子女为2*i+2

+   - 若结点编号i为偶数，且i!=0,则左兄弟结点i-1.

+   - 若结点编号i为奇数，且i!=n-1,则右兄弟结点为i+1.

+   - 结点i 所在层次为⌊log2(i+1) ⌋
