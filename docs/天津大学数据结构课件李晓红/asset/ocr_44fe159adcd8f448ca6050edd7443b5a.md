# 顺序表的插入

```
```cpp
int Insert ( SeqList &L, ListData x, int i ) {
//在表中第 i 个位置插入新元素 x
    if (i < 0 || i > L.length || L.length == ListSize)
        return 0;        //插入不成功
    else {
        for ( int j = L.length; j > i; j-- )
            L.data[j] = L.data[j-1];
        L.data[i] = x;  L.length++;

        return 1;       //插入成功
    }
}
