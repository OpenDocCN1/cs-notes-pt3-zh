# # 直接选择排序的算法

```
typedef int SortData;

void SelectSort ( SortData V[ ], int n ) {
    for ( int i = 0; i < n-1; i++ ) {
        int k = i;    //选择具有最小排序码的对象
        for ( int j = i+1; j < n; j++)
            if ( V[j] < V[k] )
                k = j;    //当前具最小排序码的对象
        if ( k != i )    //对换到第 i 个位置
            Swap ( V[i], V[k] );
    }
}
```
