# # 基数排序

# ## ·多关键字排序

例 对52张扑克牌按以下次序排序：
♣2<♣3<......<♣A<♦2<♦3<......<♦A<
♥2<♥3<......<♥A<♠2<♠3<......<♠A
两个关键字： 花色 （ ♣<♦<♥<♠ ）
面值 （2<3<......<A）
并且 “花色” 地位高于 “面值”

# ## ·多关键字排序方法

最高位优先法（MSD）： 先对最高位关键字k1（如花色）排序，将序列分成若干子序列，每个子序列有相同的k1值；然后让每个子序列对次关键字k2（如面值）排序，又分成若干更小的子序列；依次重复，直至就每个子序列对最低位关键字kd排序；最后将所有子序列依次连接在一起成为一个有序序列
