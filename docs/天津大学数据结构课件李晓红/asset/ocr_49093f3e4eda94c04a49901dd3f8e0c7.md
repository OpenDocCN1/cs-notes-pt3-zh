+   这两个递推公式的计算必须分别在拓扑有序及逆拓扑有序的前提下进行。

+   设活动 $a_k\ (k=1,2,\ldots,e)$ 在带权有向边 $<V_i,V_j>$ 上，其持续时间用 $dur(<V_i,V_j>)$ 表示，则有：
+   
+   $$
+   e[k] = Ve[i];
+   $$
+   
+   $$
+   l[k] = Vl[j] - dur(<V_i,V_j>);\quad k=1,2,\ldots,e
+   $$
+   
+   这样就得到计算关键路径的算法。

+   为了简化算法，假定在求关键路径之前已经对各顶点实现了拓扑排序，并按拓扑有序的顺序对各顶点重新进行了编号。
