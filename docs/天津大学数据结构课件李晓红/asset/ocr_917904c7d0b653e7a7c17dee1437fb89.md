# ## 判队空

```
int QueueEmpty ( SeqQueue *Q ) {
    return Q->rear == Q->front;
}
```

# ## 判队满

```
int QueueFull ( SeqQueue *Q ) {
    return (Q->rear+1) % QueueSize == Q->front;
}
```

# ## 入队

```
int EnQueue ( SeqQueue *Q, QueueData x ) {
    if ( QueueFull (Q) ) return 0;
    Q->data[Q->rear] = x;
    Q->rear = ( Q->rear+1 ) % MAXSIZE;
    return 1;
}
```
