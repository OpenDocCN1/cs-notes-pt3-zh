# Example 2. Composites numbers: Are there integers $k > 1$ and $p > 1$ such that $n = kp$?

```
int ComNum(int n)
{
    factor=0;
    for(j=2;j<n;j++)
    {
        if((n mod j)==0)
        {
            factor=j;
            break;
        }
    }
    return factor;
}
```

Time complexity: $T(n) = \Theta(n\log^2 n)$ is **pseudo** polynomial
