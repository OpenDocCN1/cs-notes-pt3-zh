# Example 2. Composites numbers: Are there integers $k > 1$ and $p > 1$ such that $n = kp$?

```text
int Consec(int n)
{
  factor=0;
  for(j=2; j<n; j++)
  {
    if (n%j==0)
    {
      factor=1;
      break;
    }
  }
  return factor;
}
```
```

Time complexity: $T(n) = \Theta(n\log^2 n)$ is pseudo polynomial

> **Proof.**
> 
> Input length $m = \log_2 n$
> 
> $n = 2^m$
> 
> $T(n) = \Theta(n\log^2 n) = \Theta(m^2 \times 2^m)$
