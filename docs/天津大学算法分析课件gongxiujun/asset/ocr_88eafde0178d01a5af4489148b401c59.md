# # Problem statements

Given n jobs and 1 processor, each job _ji_ has a 3-tuple (_pi_; _di_; _ti_) associated with it, where _ti_ is the number of units of processing time for job _ji_, _pi_ is a penalty if processing is not completed by deadline _di_.

Aiming at selecting a subset J of n jobs such that all jobs in J can be completed by their deadline and minimizing 3.

\(\sum_{j \notin J} p_j\) (3)
