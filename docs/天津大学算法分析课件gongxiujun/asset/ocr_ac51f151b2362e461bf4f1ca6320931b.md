# # DP approach for LCS

+   - Let's consider the prefixes of x and y
+     - x[1..i] jth prefix of x[1..m]
+     - y[1..j] jth prefix of y[1..n]
+   - Sub-problem: define c[i,j] = |LCS(x[1..i], y[1..j])|
+   - c[m,n] is our goal
+   - We have known that c[1,1]=1 if x<sub>1</sub> = y<sub>1</sub> otherwise 0
+   - To derive recursive relationship, we use the following theorem
+     - **Theorem**: Let X=x<sub>1</sub>x<sub>2</sub>...x<sub>m</sub>, and Y=y<sub>1</sub>y<sub>2</sub>...y<sub>n</sub> be two sequences, and Z=z<sub>1</sub>z<sub>2</sub>...z<sub>k</sub> be any LCS of X and Y, then
+   - If x<sub>m</sub> = y<sub>n</sub>, then z<sub>k</sub> = x<sub>m</sub> = y<sub>n</sub> and Z[1..k-1] is an LCS of X[1..m-1] and Y[1..n-1].
+   - If x<sub>m</sub> ≠ y<sub>n</sub>, then z<sub>k</sub> ≠ x<sub>m</sub> implies that Z is an LCS of X[1..m-1] and Y.
+   - If x<sub>m</sub> ≠ y<sub>n</sub>, then z<sub>k</sub> ≠ y<sub>n</sub> implies that Z is an LCS of X and Y[1..n-1].
