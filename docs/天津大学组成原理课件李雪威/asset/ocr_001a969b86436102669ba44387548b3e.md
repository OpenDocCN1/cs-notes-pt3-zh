# ## x86-64

```
```asm
# %rdi = z
# %rsi = digit
movl (%rdi,%rsi,4), %eax # z[digit]
```
```

+   - Register `%rdi` contains starting address of array
+   - Register `%rsi` contains array index
+   - Desired digit at `%rdi + 4*%rsi`
+   - Use memory reference `(%rdi,%rsi,4)`
