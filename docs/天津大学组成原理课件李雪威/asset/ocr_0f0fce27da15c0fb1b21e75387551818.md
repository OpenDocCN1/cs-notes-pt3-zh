# # Array Access

# ## Basic Principle

T A[L];

+   - Array of data type T and length L

+   - Identifier A can be used as a pointer to array element 0: Type T*

int val[5];

| Reference | Type | Value |
|---|---|---|
| val[4] | int | 3 |
| val | int * | x |
| val+1 | int * | x + 4 |
| &val[2] | int * | x + 8 |
| val[5] | int | ?? |
| *(val+1) | int | 5 //val[1] |
| val + i | int * | x + 4 * i //&val[i] |
