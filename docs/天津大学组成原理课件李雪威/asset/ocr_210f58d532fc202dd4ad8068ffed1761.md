# Register Saving Conventions

+   - When procedure `yoo` calls `who`:
+     - `yoo` is the *caller*
+     - `who` is the *callee*

+   - Can register be used for temporary storage?

```
yoo:
  • • •
  movq $15213, %rdx
  call who
  addq %rdx, %rax
  • • •
  ret
```

```
who:
  • • •
  subq $18213, %rdx
  • • •
  ret
```

+   - Contents of register `%rdx` overwritten by **who**
+   - This could be trouble → something should be done!
