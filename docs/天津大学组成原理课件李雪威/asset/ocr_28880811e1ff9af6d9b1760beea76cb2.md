# Using Union to Access Bit Patterns

```
```c
typedef union {
  float f;
  unsigned u;
} bit_float_t;
```
```

![](bbox=[0.533, 0.216, 0.681, 0.369])

```
```c
float bit2float(unsigned u)
{
  bit_float_t arg;
  arg.u = u;
  return arg.f;
}
```
```

```
```c
unsigned float2bit(float f)
{
  bit_float_t arg;
  arg.f = f;
  return arg.u;
}
```
