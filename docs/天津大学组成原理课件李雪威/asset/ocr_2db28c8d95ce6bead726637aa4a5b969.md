# # x86-64 Linux Register Usage #1

+   - **%rax**
+     - Return value
+     - Also caller-saved
+     - Can be modified by procedure
+   - **%rdi, ..., %r9**
+     - Arguments
+     - Also caller-saved
+     - Can be modified by procedure
+   - **%r10, %r11**
+     - Caller-saved
+     - Can be modified by procedure
