# # Jump Table Structure

# ## Switch Form

```
```c
switch (x) {
  case val_0:
    Block 0
  case val_1:
    Block 1
    ...
  case val_n-1:
    Block n-1
}
```
```

# ## Jump Table

```
```
jtab:  Targ0
       Targ1
       Targ2
        .
        .
        .
       Targn-1
```
```

# ## Jump Targets

```
```
Targ0:  Code Block
        0

Targ1:  Code Block
        1

Targ2:  Code Block
        2
        .
        .
        .

Targn-1: Code Block
         n-1
```
```

# ## Translation (Extended C)

```
```c
goto *JTab[x];
```
```
