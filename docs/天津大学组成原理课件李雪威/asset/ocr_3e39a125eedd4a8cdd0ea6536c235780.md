# # Union Allocation

+   - Allocate according to largest element
+   - Can only use one field at a time

```
```c
union U1 {
    char c;
    int i[2];
    double v;
} *up;
```
```

```
```c
struct S1 {
    char c;
    int i[2];
    double v;
} *sp;
```
