# Recall: Memory Referencing Bug Example

```
typedef struct {
  int a[2];
  double d;
} struct_t;

double fun(int i) {
  volatile struct_t s;
  s.a = 3.14;
  s.a[i] = 1073741824;  /* Possibly out of bounds */
  return s.d;
}
```

```
fun(0)  ->   3.14
fun(1)  ->   3.14
fun(2)  ->   3.1399998664856
fun(3)  ->   2.00000061035156
fun(4)  ->   3.14
fun(6)  ->   Segmentation fault
```

+   - Result is system specific
