# # Cache Miss Analysis

# ## Assume:

+   - Cache block = 8 doubles

+   - Cache size C << n (much smaller than n)

+   - Three blocks ■ fit into cache: 3B² < C

# ## Second (block) iteration:

+   - Same as first iteration

+   - 2n/B x B²/8 = nB/4

# ## Total misses:

+   - nB/4 * (n/B)² = n³/(4B)
