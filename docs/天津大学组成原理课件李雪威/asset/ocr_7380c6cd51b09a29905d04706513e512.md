# # Matrix Multiplication (kji)

```
```c
/* kji */
for (k=0; k<n; k++) {
    for (j=0; j<n; j++) {
        r = b[k][j];
        for (i=0; i<n; i++)
            c[i][j] += a[i][k] * r;
    }
}
```
```

Inner loop:
A: Column-wise
B: Fixed
C: Column-wise

# ## Misses per inner loop iteration:

|   | A   | B   | C   |
|---|-----|-----|-----|
|   | 1.0 | 0.0 | 1.0 |

Block size = 32B (four doubles)
