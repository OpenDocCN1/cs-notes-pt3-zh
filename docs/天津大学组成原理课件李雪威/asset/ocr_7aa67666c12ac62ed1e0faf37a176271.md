# # Expressing with Goto Code

+   - C allows goto statement

+   - Jump to position designated by label

```
```c
long absdiff
(long x, long y)
{
    long result;
    if (x > y)
    result = x-y;
    else
    result = y-x;
    return result;
}
```
```

```
```c
long absdiff_j
(long x, long y)
{
    long result;
    int ntest = x <= y;
    if (ntest) goto Else;
    result = x-y;
    goto Done;
Else:
    result = y-x;
Done:
    return result;
}
