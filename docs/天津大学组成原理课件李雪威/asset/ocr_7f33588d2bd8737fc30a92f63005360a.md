# # Denormalized Values

+   - Condition: exp = 000...0

+   - Exponent value: E = 1 – Bias (instead of E = 0 – Bias)

+   - Significand coded with implied leading 0: M = 0.xxx...x₂
+     - xxx...x: bits of frac

+   - Cases
+     - exp = 000...0, frac = 000...0
+       - Represents zero value
+       - Note distinct values: +0 and −0 (why?)
+     - exp = 000...0, frac ≠ 000...0
+       - Numbers closest to 0.0
+       - Equispaced
