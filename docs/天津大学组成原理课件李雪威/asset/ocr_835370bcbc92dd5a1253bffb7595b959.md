# Floating Point Operations: Basic Idea

+   - `x +_f y = Round(x + y)`
+   - `x ×_f y = Round(x × y)`

+   - **Basic idea**
+     - First **compute exact result**
+     - Make it fit into desired precision
+       - Possibly overflow if exponent too large
+       - Possibly **round to fit into** `frac`
