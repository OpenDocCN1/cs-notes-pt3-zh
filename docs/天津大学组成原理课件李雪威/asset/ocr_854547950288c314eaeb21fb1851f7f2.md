# Memory Aliasing

```
/* Sum rows is of n X n matrix a
   and store in vector b  */
void sum_rows1(double *a, double *b, long n) {
    long i, j;
    for (i = 0; i < n; i++) {
        b[i] = 0;
        for (j = 0; j < n; j++)
            b[i] += a[i*n + j];
    }
}
```

```
double A[9] =
  {  0,   1,   2,
     4,   8,  16,
    32,  64, 128};

double B[3] = A+3;

sum_rows1(A, B, 3);
```

```
double A[9] =
  {  0,   1,   2,
     3,  22, 224,
    32,  64, 128};
```

# Value of B:

+   - init: [4, 8, 16]
+   - i = 0: [3, 8, 16]
+   - i = 1: [3, 22, 16]
+   - i = 2: [3, 22, 224]

+   - Code updates `b[i]` on every iteration
+   - Must consider possibility that these updates will affect program behavior
