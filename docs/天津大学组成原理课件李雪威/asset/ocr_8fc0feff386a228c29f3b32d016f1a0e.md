# Example: Calling `incr` #2

```
```c
long call_incr() {
    long v1 = 15213;
    long v2 = incr(&v1, 3000);
    return v1+v2;
}
```
```

# Stack Structure

![](bbox=[0.565, 0.182, 0.761, 0.531])

```
```asm
call_incr:
    ...
    leaq    8(%rsp), %rdi
    call    incr
    addq    8(%rsp), %rax
    addq    $16, %rsp
    ret
```
```

| Register | Value |
|---|---:|
| `%rdi` | `&v1` |
| `%rsi` | `3000` |

Aside 2: **leaq 8(%rsp), %rdi**

- Computes `%rsp+8`
- Actually, used for what it is meant!
