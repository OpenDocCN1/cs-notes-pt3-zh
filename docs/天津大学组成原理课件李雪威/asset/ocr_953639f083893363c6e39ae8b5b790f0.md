# # Understanding Arithmetic Expression Example

```
```c
long arith
(long x, long y, long z)
{
    long t1 = x+y;
    long t2 = z+t1;
    long t3 = x+4;
    long t4 = y * 48;
    long t5 = t3 + t4;
    long rval = t2 * t5;
    return rval;
}
```
```

```
```asm
arith:
leaq    (%rdi,%rsi), %rax    # t1
addq    %rdx, %rax            # t2
leaq    (%rsi,%rsi,2), %rdx
salq    $4, %rdx              # t4
leaq    4(%rdi,%rdx), %rcx    # t5
imulq   %rcx, %rax            # rval
ret
```
```

| Register | Use(s) |
|---|---|
| `%rdi` | Argument **x** |
| `%rsi` | Argument **y** |
| `%rdx` | Argument **z**, **t4** |
| `%rax` | **t1**, **t2**, **rval** |
| `%rcx` | **t5** |
