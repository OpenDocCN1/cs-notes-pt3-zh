# # Byte Ordering Example

```
union {
    unsigned char c[8];
    unsigned short s[4];
    unsigned int i[2];
    unsigned long l[1];
} dw;
```

# ## How are the bytes inside short/int/long stored?

| 32-bit | c[0] | c[1] | c[2] | c[3] | c[4] | c[5] | c[6] | c[7] |
|---|---|---|---|---|---|---|---|---|
| | s[0] | | s[1] | | s[2] | | s[3] | |
| | i[0] | | | i[1] | | | |
| | l[0] | | | | | | | |

| 64-bit | c[0] | c[1] | c[2] | c[3] | c[4] | c[5] | c[6] | c[7] |
|---|---|---|---|---|---|---|---|---|
| | s[0] | | s[1] | | s[2] | | s[3] | |
| | i[0] | | | i[1] | | | |
| | l[0] | | | | | | | |
