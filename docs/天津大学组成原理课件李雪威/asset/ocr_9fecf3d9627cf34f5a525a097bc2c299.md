# “Do-While” Loop Example

# C Code

```
```c
long pcount_do
    (unsigned long x) {
    long result = 0;
    do {
        result += x & 0x1;
        x >>= 1;
    } while (x);
    return result;
}
```
```

# Goto Version

```
```c
long pcount_goto
    (unsigned long x) {
    long result = 0;
loop:
    result += x & 0x1;
    x >>= 1;
    if(x) goto loop;
    return result;
}
```
```

+   - Count number of 1’s in argument x (“popcount”)
+   - Use conditional branch to either continue looping or to exit loop
