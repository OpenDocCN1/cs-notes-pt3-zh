# # Multidimensional (Nested) Arrays

# ■ Declaration

$T\ A[R][C];$

+   - 2D array of data type $T$
+   - $R$ rows, $C$ columns
+   - Type $T$ element requires $K$ bytes

# ■ Array Size

+   - $R * C * K$ bytes

# ■ Arrangement

+   - Row-Major Ordering

