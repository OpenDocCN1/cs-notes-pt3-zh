# Example: Calling `incr` #2

```
```c
long call_incr() {
    long v1 = 15213;
    long v2 = incr(&v1, 3000);
    return v1+v2;
}
```
```

# Stack Structure

![](bbox=[0.565, 0.243, 0.94, 0.671])

```
```asm
call_incr:
movl    $3000, %esi
leaq    8(%rsp), %rdi
call    incr
addq    8(%rsp), %rax
addq    $16, %rsp
ret
```
```

| Register | Value |
|---|---|
| `%rdi` | `&v1` |
| `%rsi` | `3000` |

> **Aside 1: `movl $3000, %esi`**
> 
> - Remember, `movl` -> `%exx` zeros out high order 32 bits.
> - Why use `movl` instead of `movq`? 1 byte shorter.
