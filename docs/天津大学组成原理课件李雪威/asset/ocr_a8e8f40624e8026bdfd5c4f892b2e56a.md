# # Mechanisms in Procedures

# ## Passing control

+   - To beginning of procedure code
+   - Back to return point

# ## Passing data

+   - Procedure arguments
+   - Return value

# ## Memory management

+   - Allocate during procedure execution
+   - Deallocate upon return
