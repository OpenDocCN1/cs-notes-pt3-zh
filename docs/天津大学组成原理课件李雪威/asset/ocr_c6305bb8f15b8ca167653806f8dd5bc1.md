# # Understanding Swap()

### Registers

| Register | Value   |
|----------|---------|
| %rdi     | 0x120   |
| %rsi     | 0x100   |
| %rax     | 123     |
| %rdx     |         |

### Memory

| Address | Value |
|---------|-------|
| 0x120   | 123   |
| 0x118   |       |
| 0x110   |       |
| 0x108   |       |
| 0x100   | 456   |

A red arrow points from `%rax` (value 123) to the memory address `0x120` (value 123).

```
```
swap:
    movq  (%rdi), %rax    # t0 = *xp
    movq  (%rsi), %rdx    # t1 = *yp
    movq  %rdx, (%rdi)    # *xp = t1
    movq  %rax, (%rsi)    # *yp = t0
    ret
