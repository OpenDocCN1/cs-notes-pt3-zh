# # Array Element Accesses

# ## Nested array

```
```c
int get_pgh_digit
(size_t index, size_t digit)
{
    return pgh[index][digit];
}
```
```

# ## Multi-level array

```
```c
int get_univ_digit
(size_t index, size_t digit)
{
    return univ[index][digit];
}
```
```
