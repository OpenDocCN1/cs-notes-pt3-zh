# # Switch Statement Example

+   - Multiple case labels
+     - Here: 5 & 6
+   - Fall through cases
+     - Here: 2
+   - Missing cases
+     - Here: 4

```
```c
long switch_eg
(long x, long y, long z)
{
    long w = 1;
    switch(x) {
    case 1:
        w = y*z;
        break;
    case 2:
        w = y/z;
        /* Fall Through */
    case 3:
        w += z;
        break;
    case 5:
    case 6:
        w -= z;
        break;
    default:
        w = 2;
    }
    return w;
}
