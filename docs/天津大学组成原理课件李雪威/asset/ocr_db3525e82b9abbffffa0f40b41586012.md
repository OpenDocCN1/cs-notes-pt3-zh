# # Machine Instruction Example

# ## C Code

+   - Store value `t` where designated by `dest`

# ## Assembly

+   - Move 8-byte value to memory
+     - Quad words in x86-64 parlance
+   - Operands:
+     - `t`: Register `%rax`
+     - `dest`: Register `%rbx`
+     - `*dest`: Memory `M[%rbx]`

# ## Object Code

+   - 3-byte instruction
+   - Stored at address `0x40059e`

```
```c
*dest = t;
```
```

```
```asm
movq %rax, (%rbx)
```
```
