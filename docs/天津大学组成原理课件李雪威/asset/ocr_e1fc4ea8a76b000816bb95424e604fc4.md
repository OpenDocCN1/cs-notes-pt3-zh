# # Characterizing TAdd

+   - **Functionality**
+     - True sum requires *w*+1 bits
+     - Drop off MSB
+     - Treat remaining bits as 2’s comp. integer

![](bbox=[0.482, 0.222, 0.852, 0.592])

$$T_w(u,v)=\begin{cases}
u+v+2^w & u+v<T_w\quad\text{(NegOver)}\\
u+v & T_w\le u+v\le T_w\\
u+v-2^w & T_w<u+v\quad\text{(PosOver)}
\end{cases}$$
