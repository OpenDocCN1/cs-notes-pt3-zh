# # Setting Up Canary

# ## Before call to gets

![](bbox=[0.051, 0.193, 0.255, 0.73])

```
```c
/* Echo Line */
void echo()
{
    char buf[4];  /* Way too small! */
    gets(buf);
    puts(buf);
}
```
```

```
```asm
echo:
    . . .
    movq  %fs:40, %rax    # Get canary
    movq  %rax, 8(%rsp)   # Place on stack
    xorl  %eax, %eax      # Erase canary
    . . .
