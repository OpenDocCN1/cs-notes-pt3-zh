# # Power-of-2 Multiply with Shift

# ## Operation

+   - `u << k` gives `u * 2^k`

+   - Both signed and unsigned

Operands: w bits

True Product: w+k bits

Discard k bits: w bits

# ## Examples

+   - `u << 3` == `u * 8`

+   - `(u << 5) - (u << 3) == u * 24`

+   - Most machines shift and add faster than multiply

+   - Compiler generates this code automatically
