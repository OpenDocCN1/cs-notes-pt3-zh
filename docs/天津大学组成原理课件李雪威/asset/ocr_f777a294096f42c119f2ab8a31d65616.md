# “For” Loop Form

# General Form

```
for (Init; Test; Update)\n    Body
```

```
#define WSIZE 8*sizeof(int)
long pcount_for
    (unsigned long x)
{
    size_t i;
    long result = 0;
    for (i = 0; i < WSIZE; i++)
    {
        unsigned bit =
            (x >> i) & 0x1;
        result += bit;
    }
    return result;
}
```

# Init

```
i = 0
```

# Test

```
i < WSIZE
```

# Update

```
i++
```

# Body

```
{
    unsigned bit =
        (x >> i) & 0x1;
    result += bit;
}
```
