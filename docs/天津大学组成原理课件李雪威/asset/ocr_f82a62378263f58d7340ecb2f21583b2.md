# # Special Values

+   - **Condition: `exp = 111...1`**

+   - **Case: `exp = 111...1, frac = 000...0`**
+     - **Represents value ∞ (infinity)**
+     - Operation that overflows
+     - Both positive and negative
+     - E.g., `1.0/0.0 = +∞, 1.0/-0.0 = −∞`

+   - **Case: `exp = 111...1, frac ≠ 000...0`**
+     - **Not-a-Number (NaN)**
+     - Represents case when no numeric value can be determined
+     - E.g., `sqrt(−1), ∞ − ∞, ∞ × 0`
