# # Logic Operations in C

+   - **Logic Operations: &&, ||, !**
+     - View 0 as “False”
+     - Anything nonzero as “True”
+     - Always return 0 or 1
+     - Early termination

+   - **Examples (char data type)**
+     - !0x41 → 0x00
+     - !0x00 → 0x01
+     - !!0x41 → 0x01
+     - 0x69 && 0x55 → 0x01
+     - 0x69 || 0x55 → 0x01
+     - p && *p (avoids null pointer access)
