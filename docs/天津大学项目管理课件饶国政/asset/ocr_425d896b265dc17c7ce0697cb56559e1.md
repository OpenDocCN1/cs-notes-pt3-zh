# # 1. 项目管理的发展

+   - 1965年，以欧洲为主体的一些国家专门成立了国际项目管理协会（International Project Management Association，IPMA）。这个协会主要以各个国家的项目管理方面的组织为主体。
+     - 成员：国家级项目管理协会
+     - 职能：促进国际间项目管理发展
+     - 产品和服务：研究和发展，教育与培训，标准和资质认证
+     - 项目管理能力基础ICB (IPMA Competence Baseline)
+     - 42个知识和实践元素，其中核心元素28个，增加元素14个。
