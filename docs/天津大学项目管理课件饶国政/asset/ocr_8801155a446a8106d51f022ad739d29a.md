# # 编制网络图

编制网络图时要注意以下几个问题：
一个网络图只有一个开始点和一个结束点。如果几项活动
同时开始或者同时结束，在双号网络图中可以将这几
项活动的开始节点合并为一个节点；而在单号网络图
中可以设置一个虚拟开始（或者结束）活动，作为该
网络图的开始节点（或者结束节点）。
