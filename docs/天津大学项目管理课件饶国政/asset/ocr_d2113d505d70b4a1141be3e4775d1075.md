# # 1 项目管理的背景与定义

# # 1. 项目管理的发展

+   - 1969年成立的美国项目管理学术组织（Project Management Institute，PMI）也是一个国际性项目管理学会。
+     - 分会：245个
+     - 成员：企业、高校、研究单位
+     - 职能：促进国际间项目管理发展
+   - PMBOK（Project Management Body of Knowledge）
+   - 九个知识领域

+   - 1991年6月中国项目管理委员会（Project Management Research Committee China，PMRC）正式成立，促进了我国项目管理与国际项目管理专业领域的沟通与交流，促进了我国项目管理专业化和国际化的发展。 2001开始建立《中国项目管理知识体系和资格认证标准》工作。
