# # 3.3 项目组织类型

# ## 2. 影响组织选择的关键因素

| 组织结构影响因素 | 职能型 | 矩阵型 | 项目型 |
|---|---|---|---|
| 不确定性 | 低 | 高 | 高 |
| 所用技术 | 标准 | 复杂 | 新 |
| 复杂程度 | 低 | 中等 | 高 |
| 持续时间 | 短 | 中等 | 长 |
| 规模 | 小 | 中等 | 大 |
| 重要性 | 低 | 中等 | 高 |
| 客户类型 | 各种各样 | 中等 | 单一 |
| 对内部依赖性 | 弱 | 中等 | 强 |
| 对外部依赖性 | 强 | 中等 | 强 |
| 时间局限性 | 弱 | 中等 | 强 |
