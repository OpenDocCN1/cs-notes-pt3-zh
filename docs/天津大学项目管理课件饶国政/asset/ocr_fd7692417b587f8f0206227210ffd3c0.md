# ## 一. 甘特图

是表示项目各阶段任务开始时间与结束时间的图形，它把计划和进度安排组织在一起。

+   用水平线段表示阶段任务；

+   线段的起点和终点分别为对应于任务的开始时间和结束时间

+   线段的长度表示完成任务所需要的时间。
