# ## 2.12 Precedence and Order of Evaluation

+   - NOTICE:
+   
+     x=f() +g():
+   
+     1. evaluate f() --> evaluate g();
+   
+     2. evaluate g() --> evaluate f();
+   
+     Example:
+   
+     i=1;
+   
+     x=i + ++i;
+   
+     x have different results with different compliers (x=3 or 4)
