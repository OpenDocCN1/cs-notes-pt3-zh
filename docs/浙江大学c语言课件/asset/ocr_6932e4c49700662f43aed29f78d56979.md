# # 1.2 Variables and Arithmetic Expressions

The **printf** useful format:

+   - %d
+   print as decimal integer;
+   
+   - %6d
+   print as decimal integer, as at least 6
+   characters wide;
+   
+   - %f
+   print as floating point;
+   
+   - %6f
+   print as floating point, as at least 6
+   characters wide;
+   
+   - %.2f
+   print as floating point, 2 characters after
+   decimal point;
+   
+   - %6.2f
+   print as float, at least 6 wide and 2
+   characters after			decimal point;
+   
+   - %o
+   print as octal;
+   
+   - %x
+   print as hexadecimal;
+   
+   - %c
+   print as a character;
+   
+   - %s
+   print as character string;
+   
+   - %%
+   print % itself
