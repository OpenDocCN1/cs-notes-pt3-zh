# 5.5 Character Pointers and Functions

Examples of strcpy:

```
/* strcpy: array subscript version */
void strcpy(char *s, char *t)
{
    int i;
    i=0;
    while((s[i]=t[i]) != '\0')
        i++;
}
```

```
/* strcpy: pointer version 1 */
void strcpy(char *s, char *t)
{
    while((*s = *t) != '\0')
    {
        s++; i++;
    }
}
```

/* strcpy: pointer version 3 */
void strcpy(char *s, char *t)
