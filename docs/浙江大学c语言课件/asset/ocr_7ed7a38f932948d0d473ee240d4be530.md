# 6.1 Basics of Structures

```
member referring: structure-name.member

struct pointer pt;
printf("%d,%d", pt.x, pt.y);

double dist, sqrt(double);
dist = sqrt((double)pt.x * pt.x+ (double)pt.y * pt.y);
```

```
structures can be nested

struct rect {
    struct point pt1;
    struct point pt2;
};

struct rect screen;
screen.pt1.x
```
