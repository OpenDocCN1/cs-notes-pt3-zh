# # 6.7 Typedef

typedef: creating new data type name (not a new type)
purpose: (1) for portable (2) for better understanding

example:

```
char *s;
int strcmp(char *, char *);
```

```
typedef char *STRING;
STRING s;
int strcmp(STRING,STRING);
```

```
int (*strcmp)(char *, char *);
```

```
typedef int (*PFI)(char *,char *);
PFI strcmp;
```

```
struct tnode{
	char *word;
	int count;
	struct tnode *left;
	struct tnode *right;
};
struct tnode *tp;
struct tnode node;
```

```
typedef struct tnode *TREEPTR;
typedef struct tnode {
	char *word;
	int count;
	TREEPTR left;
	TREEPTR right;
} TREENODE;
TREEPTR tp;
TREENODE node;
```
