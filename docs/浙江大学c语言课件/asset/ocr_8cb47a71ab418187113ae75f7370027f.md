# # 7.2 Formatted Output-Printf

Conversion specifications: (int i=55; char s[]="hello, world";)

1 printf("%d", i); :55

2 printf("%5d", i); : 55

3 printf("%-5d", i); :55

4 printf(f, s); f are the following cases:

%s :hello, world;

%10s :hello, world;

%.10s :hello, wor;

%-10s :hello,world;

%.15s :hello, world;

%-15s :hello, world ;

%15.10s : hello, wor;

%-15.10s :hello, wor ;

5 printf("%%%d");
