# 4.11 The C Preprocessor

+   - `#`: parameter ➔ string
+   
+     `#define dprint(expr) printf(#expr “= %g\n”,expr)`
+   
+     `dprint(x/y): <==> printf(“x/y” “= %g\n”, x/y);`
+   
+   - `##`: concatenate the actual argument:
+   
+     `#define paste(front,back) front ## back`
+   
+     `paste(name,1) ===> name1`
