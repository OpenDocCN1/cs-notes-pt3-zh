# 2.6 relational and Logical Operators

The relational operators: >, >=, <, <=, ==, !=

# Precedence:

+   - `*`, `/`, `%`
+   - `+`, `-`
+   - `>`, `>=`, `<`, `<=`
+   - `==`, `!=`
+   - `||`

logical operators: && (与), || (或), ! (非)
