# 第10章　类与对象

# 例1：class Rectangle

```
```cpp
{
public:
    float width,height;
    float Area()
    {return width*height;}
    float Perimeter()
    {return 2*(width+height);}
}
Rectangle rect;
```
```

```
```cpp
rect.width=45;
rect.height=54.2;
cout<<rect.Area();
cout<<rect.Perimeter();
```
