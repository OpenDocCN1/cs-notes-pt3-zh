# 【例2-2】：使用浮点型变量

```
```java
public class Floats {
    public static void main(String args[]) {
        float a=35.45f;                 // 定义单精度变量a
        double b=3.56e18;               // 定义双精度变量b
        System.out.println("a="+a);    // 输出a
        System.out.println("b="+b);    // 输出b
    }
}
```
```

程序运行结果如下：

a=35.45

b=3.56E18
