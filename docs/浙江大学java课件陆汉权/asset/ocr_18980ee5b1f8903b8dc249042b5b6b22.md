# 循环结构 Demo2：【例3-10】

```
```java
public class Sum1 {  //例：计算1+3+5+...+99
    public static void main(String args[]) {
        int i=1, s=0;   // i循环变量，s存放结果

        do {
            s=s+i;       // 循环体
            i=i+2;
        } while (i<100);

        System.out.println("sum="+s);
    }
}
