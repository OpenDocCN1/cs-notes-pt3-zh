# # 13.1.2 Applet程序的运行过程

+   当浏览器装载有带Applet程序的网页时：
+   1）首先为Applet及其全程变量分配存储空间。
+   2）执行Applet的init()方法。
+   3）执行Applet的start()方法。
+   4）执行Applet的paint()方法。
+   当离开Applet网页，又重新激活时：
+   1）执行Applet的start()方法。
+   2）执行Applet的paint()方法。
+   当用户真正离开浏览器时：
+   1）执行Applet的stop()方法。
+   2）执行Applet的destroy()方法。
