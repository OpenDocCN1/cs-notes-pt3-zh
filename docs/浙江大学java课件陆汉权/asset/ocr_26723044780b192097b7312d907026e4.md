# 输入和输出

# 输入

+   - 命令行
+   - Scanner类中的方法
+     - `nextDouble()`, `nextFloat`, `nextInt()`, `nextLine()`……
+     - （JDK1.5以上）
+   - BufferedReader类的方法`read()`, `readLine()`
+   - JoptionPane类中的`showInputDialog`方法

# 输出

+   - Print()方法；Println()方法；Printf()方法
+     - （JDK1.5以上）
+   - JoptionPane类中的`showMessageDialog`方法
