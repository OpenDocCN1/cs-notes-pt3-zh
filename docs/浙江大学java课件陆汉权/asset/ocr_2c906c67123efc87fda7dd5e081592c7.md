# # Example

+   - 从控制台读取**10个数据**，写入整型数组**a**中，程序代码为：
+   
+   ```java
+   int [] a = new int[10];
+   Scanner in = new Scanner(System.in);
+   for(int i=0; i<10;i++)
+       a[i]=in.nextInt();
+   
+   System.out.println("数组元素为");
+   for (int i=0; i<a.length;i++)
+       System.out.print(a[i]+"  ");
+   ```
