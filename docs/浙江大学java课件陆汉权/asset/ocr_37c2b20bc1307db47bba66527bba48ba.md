# 题6 实验代码

```
```java
public class no6 {
    static int max(int x,int y){
        if (x<y)
            return y;
        else
            return x;
    }

    public static void main(String[] args) {
        int a=Integer.parseInt(args[0]);
        int b=Integer.parseInt(args[1]);

        int x=max(a,b);
        System.out.println(x);
    }
}
```
