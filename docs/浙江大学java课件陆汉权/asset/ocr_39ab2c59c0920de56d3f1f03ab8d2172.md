# 例6-1 定义一个二维平面上点的类

```
class Point {
private int x,y;
public void setPoint(int a,int b) {
x=a;
y=b;
}
public int getX() {
return x;
}
public int getY() {
return y;
}
public String toString() {
return "["+x+","+y+"]";
}
}
```

类名：Point

类变量成员：x，y

类的方法（1）：setPoint

类的方法（2）：getX取X坐标

类的方法（3）：getY 取Y坐标

类的方法（4）：toString 获取变量的字符串
