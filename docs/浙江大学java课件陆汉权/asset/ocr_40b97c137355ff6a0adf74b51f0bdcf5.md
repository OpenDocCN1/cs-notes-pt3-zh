# 例3-14：判断素数

+   - **素数** prime
+     - 除了1及自身外，不能被其它数整除的自然数。
+   - **判断素数的思路**
+     - 对于一个自然数k，与2~k-1之间的每个整数进行相除
+     - 如果没有一个能被整除，则k是素数；否则k不是素数
+   - **转为算法**
+     - 变量 i 从 2 开始，每次加 1，到 k-1 为止
+     - 每次用 k 去除 i，是否能够整除？——求余
+     - 判余数：为0，不是素数，终止循环
+     - m≠0，不能整除，进行下一次判断
+     - 判结束？正常结束（所有的数都判了，即i==k），是素数！
+     - 非正常结束，不是素数
