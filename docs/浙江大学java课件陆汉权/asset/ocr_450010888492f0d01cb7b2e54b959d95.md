# # 重载：形参个数、类型、顺序

重载方法中的参数表必然不同，表现为

+   - 参数个数不同，或

+   - 参数类型不同，或

+   - 参数顺序不同

# ## ≡正确的重载方法头

```
```java
public double area(double r)
public double area(int a, double b)
public double area(double a, int b)
```
```

# ## ≡不是正确的重载方法：

```
```java
public int volume(int a, int b)
public void volume(int x, int y)
```
```
