# # 6.2.2 类成员——变量和方法

# ## 类成员变量

+   - 使用static修饰的变量为类成员变量

+   - 没有使用static修饰的变量为实例成员变量，

```
```java
class Student {
    String name;        //实例成员变量
    String sex;         //实例成员变量
    static int count=0; //类成员变量
    public Student(String m, String s ) {
        name=m;         // 在本类， 对实例和类成员操作
        sex=s;
        count=count+1;
    }
}
```
```
