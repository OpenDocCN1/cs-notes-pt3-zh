# Java 控制台输入

+   - **Scanner**
+     - 属于 Java 标准输入流 `System.in`
+     - 在程序顶部加上语句：
+       ```java
+       import java.util.*; // Java 的工具包
+       ```

使用标准输入流

+   1. 定义一个 **Scanner** 对象
+      ```java
+      Scanner in = new Scanner(System.in);
+      ```
+   2. **Scanner** 类用法
+      用法很多，包括输入各种类型的数据
