# 例--一个包中包含多个类

在X1.java文件中定义bag包中的X1类。

```
```java
package bag;    //声明所在包为bag
public class X1
{
    int x,y;
    public X1(int i,int j)
    {
        x=i;
        y=j;
        System.out.println("x="+x+" "+"y="+y);
    }
    public void show()
    {
        System.out.println("This class is X1");
    }
}
```
