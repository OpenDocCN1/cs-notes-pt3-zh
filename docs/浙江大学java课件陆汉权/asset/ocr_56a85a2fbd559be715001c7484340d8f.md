# 使用多个构造方法

```
class Time1
{
    private int hour;          //0-23
    private int minute;        //0-59
    private int second;        //0-59
    public Time1()
    { setTime (0,0,0); }
    public Time1(int hh)
    { setTime (hh,0,0); }
    public Time1 (int hh, int mm)
    { setTime (hh,mm,0); }
    public Time1(int hh, int mm, int ss)
    { setTime (hh,mm,ss); }
```
