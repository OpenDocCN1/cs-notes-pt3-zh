# # 例：类成员方法和实例成员方法的对比

```
```java
class Course {
    String no;          //实例成员变量：课程编号
    int score;          //实例成员变量：成绩
    static int sum=0;   //类成员变量：总成绩

    public Course(String n, int s) { // Course的构造方法
        no=n;
        score=s;
    }

    //类方法：统计总成绩
    public static void summarize(int s) { // Course的类成员方法
        sum+=s;
    }
}// 类 Course结束
