# 顺序结构 Demo2，【例3-2】

```
// 华氏温度转换为摄氏温度： c=5(F-32)/9
public class Conversion{
    public static void main(String args[]) {
        float f, c;
        f=70.0f;
        c=5*(f-32)/9;
        System.out.println("Fahrenheit="+f);
        System.out.println("Centigrade="+c);
    }
}
```
