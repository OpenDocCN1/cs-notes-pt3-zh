# # 语句

# ## 语句，Statement

+   - 向计算机系统发出操作的代码

+   - 程序由一系列语句组成，语句以 “; ” 结束

# ## Java语句类型

+   - 表达式语句，如： total=math+phys+chem

+   - 空语句，只有一个 “;”

+   - 复合语句，用 “{}”将多条语句括起来作为一条语句使用，如：

+   - If (x>10)

+   - z=x+y;

+   - t=z/10;

+   - 方法调用语句： 方法名(参数); 如：

+   - System.out.println("Java Language");

+   - 控制语句，完成一定的控制功能，包括

+   - 选择语句

+   - 循环语句
