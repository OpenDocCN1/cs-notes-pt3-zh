```
public class Hello {
public static void main(String[] args) {
System.out.println(args[0]+" "+args[1]);
}
}
}
```

# 在Eclipse中执行：

+   单击“运行”按钮或者“运行”菜单的运行命令

+   在“(x)=自变量”选项卡中输入 Hello, Java！

+   即这个栏目就是代表——命令行参数

+   运行！

+   ——相当于“输入”数据

# System.out.println(args[0]+" "+args[1]);

+   其中的“+”，表示连接符
