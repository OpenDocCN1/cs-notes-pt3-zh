# 例：找素数

```
```java
public class PrimeNumber {
    public static void main(String args[]) {

        for(int i=2; i<=50; i++) {  // 外循环
            boolean flag=true;

            for(int j=2; j<=i/2; j++){  // 内循环
                if(i%j==0) {        // 条件成立：余数为0
                    flag=false;     // 不是质数
                    break;          // 结束本次内循环
                }
            }
            if(flag) System.out.print(i+" ");
        }
    }
}
