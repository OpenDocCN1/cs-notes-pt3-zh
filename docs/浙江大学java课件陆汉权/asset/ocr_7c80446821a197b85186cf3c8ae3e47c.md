# # Java —— super和this的使用

```
class Employee { // 类Employee
String name;
Employee(String name){
this.name=name;
}
public void showInfo(){
System.out.println("this is superClass call:"+name);
}
public void getInfo() {
showInfo();
}
} // 类Employee结束

class Manage extends Employee{ // 类Manage 继承了Employee
String name; // 注意与父类同名的成员变量
```
