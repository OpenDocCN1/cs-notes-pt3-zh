# # 【例2-4】：使用字符串类型数据

```
public class Samp2_5 {
public static void main(String args[]) {
String str1="abc"; // 定义字符串变量str1
String str2="\\n"; // 定义字符串变量str2
String str3= "123"; // 定义字符串变量str3
// 输出字符串变量时str1、 str2、 str3
System.out.println("str1="+str1+str2+"str3="+str3);
}
}
程序运行结果如下：
str1=abc
str3=123
```
