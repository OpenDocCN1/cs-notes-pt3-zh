# 例--利用read()语句暂停程序运行

```
```java
import java.io.IOException;
public class StandardIn2
{
    public static void main(String[] args)   throws IOException
    {
        for (int i=1; i<=5; i++)
        System.out.println(i);
        System.out.println("按回车键继续...");
        System.in.read();
        System.out.print("程序继续运行！");
    }
}
