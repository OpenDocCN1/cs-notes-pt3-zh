# # 顺序结构Demo3，【例3-3】

```
public class Root {
    public static void main(String args[]) {
        intt a, b, x;
        a=Integer.parseInt (args[0]); //命令行输入第一个数
        b=Float.parseFloat (args[1]); //命令行输入第二个数
        x=-b/a; // 求根 x
        System.out.println("a="+a); // Out Result
        System.out.println("b="+b);
        System.out.println("x="+x);
    }
}
```
