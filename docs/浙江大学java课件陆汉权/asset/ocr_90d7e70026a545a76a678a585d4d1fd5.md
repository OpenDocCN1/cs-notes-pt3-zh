# # 例--利用read()语句暂缓程序运行

```
import java.io.*;
public class E10_2{
public static void main(String []args)throws IOException{
int i;
for(i=1;i<=5;i++){
System.out.println(i);
System.out.println("按回车键继续..."); //回车是两个字符
System.in.read(); // \r
System.in.read(); // \n
}
System.out.println("程序结束!");
}
}
```
