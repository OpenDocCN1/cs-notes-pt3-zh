# # Java数据基本类型表——小结

| 关键字 | 数据类型 | 所占字节 | 表示范围 |
|---|---|---|---|
| long | 长整型 | 8 | 2^31-1 ~ -2^31 |
| int | 整型 | 4 | -2147483648~ 2147483647 |
| short | 短整型 | 2 | -32768~32767 |
| byte | 位 | 1 | -128~127 |
| char | 字符 | 1 | 0~256 |
| boolean | 布尔 | 1 | true 或 false |
| float | 单精度 | 4 | -3.4E38~ 3.4E38 |
| double | 双精度 | 8 | -1.7E308~ 1.7E308 |
