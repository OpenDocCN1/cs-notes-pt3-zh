# # 关系运算符

| 运算符 | 用例 | 功能 |
|---|---|---|
| > | a > b | 如果a > b成立，结果为true；否则，结果为false |
| >= | a >= b | 如果a ≥ b成立，结果为true；否则，结果为false |
| < | a < b | 如果a < b成立，结果为true；否则，结果为false |
| <= | a <= b | 如果a ≤ b成立，结果为true；否则，结果为false |
| == | a == b | 如果a = b成立，结果为true；否则，结果为false |
| != | a != b | 如果a ≠ b成立，结果为true；否则，结果为false |
