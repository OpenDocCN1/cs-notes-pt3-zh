# # 使用对话框输入

+   - 程序顶部加入语句
+     ```java
+     import javax.swing.*;
+     ```
+   - 在程序中使用： `JOptionPane.showInputDialog()`
+   - 例如：
+     ```java
+     String st = JOptionPane.showInputDialog("请输入:");
+     ```
+   - 使用对话框输入的也是字符串，需要 `Integer.ParseInt()`等转换

+   - 注意：使用对话框，会启动一个线程  
+     - 使用`System.exit(0);`可以结束线程
