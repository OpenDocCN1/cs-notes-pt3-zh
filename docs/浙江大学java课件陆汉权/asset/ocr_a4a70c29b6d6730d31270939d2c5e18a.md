# Java实例6-3——用构造方法初始化成员变量

```
```java
class Triangle {
    int x,y,z;
    public Triangle(int i,int j,int k) { //声明构造方法，方法名和类名相同
        x=i; y=j; z=k;                 //简单地将变量关联，i→x, j→y, k→z
    }
    public static boolean judge(Triangle m) { //判断是否为直角三角形
        //引用Math类库的sqrt()方法
        if ( Math.sqrt(m.x*m.x+ m.y*m.y)== Math.sqrt(m.z*m.z))
            return true;
        else
            return false;
    }
}
