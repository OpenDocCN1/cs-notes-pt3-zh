# 复合赋值运算符

由赋值运算符与算术运算符、逻辑运算符和位运算符组合成，使用方法：

| 运算符 | 用例 | 等价于 | 运算符 | 用例 | 等价于 |
|---|---|---|---|---|---|
| += | x += y | x=x+y | &= | x &= y | x=x&y |
| -= | x -= y | x=x-y | \|= | x \|= y | x=x\|y |
| *= | x *= y | x=x*y | ^= | x ^= y | x=x^y |
| /= | x /= y | x=x/y | <<= | x <<= y | x=x<<y |
| %= | x %= y | x=x%y | >>= | x >>= y | x=x>>y |
| >>>= | x >>>= y | x=x>>>y |  |  |  |
