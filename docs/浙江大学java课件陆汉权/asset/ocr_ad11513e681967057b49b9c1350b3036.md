# # 值传递的例子

+   ### 【例4-5】运行的结果
+   调用前：a=23 b=10  
+   交换前：x=23 y=10  
+   交换后：x=10 y=23  
+   调用后：a=23 b=10

+   ### 说明：
+   - 参数传递：a → x; b → y  
+   - 调用前后：a、b的值没有变  
+   - 交换前后：x、y的值改变了

```
```java
static void swap(int x, int y) {
    int temp = x; x = y; y = temp; // 交换
}
public static void main(String[] args) {
    int a = 23, b = 10;
    swap(a, b); // 调用 “方法”
}
