# 缺省构造方法的使用

所谓“缺省(Default)”构造方法，是在类中没有定义构造方法，Java默认的类成员方法初始化处理。
注意：Java中变量必须初始化，即赋初值才能使用变量

```
class Student {
    String name;    //成员变量
    String address; //成员变量
    int score;      //成员变量
    public void setMessage(String x1,String x2, int x3) {//成员方法
        name=x1;
        address=x2;
        score=x3;
    }
}
```
