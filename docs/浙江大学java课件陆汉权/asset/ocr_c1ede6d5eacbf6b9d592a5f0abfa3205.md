# # 字符类型

+   - 字符类型： char
+     - Unicode字符，1个字符占16位
+   - 字符类型数据表示方法
+     - 单引号括起来的单个字符
+     - 用Unicode码表示，前缀是“\u”
+   - Unicide字符集内的控制字符需要通过转义字符表示
+     - 转义符 → 符号的意义被转换了
+     - 转义后代表的是控制符

| 转义字符 | 功能   | Unicode码   |
|----------|--------|-------------|
| \b       | 退格   | \u0008      |
| \t       | 制表符 | \u0009      |
| \n       | 换行   | \u000a      |
| \f       | 换页   | \u000c      |
| \r       | 回车   | \u000d      |
