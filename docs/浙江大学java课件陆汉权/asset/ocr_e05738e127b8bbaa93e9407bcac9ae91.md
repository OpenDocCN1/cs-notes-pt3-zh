# 【例2-3】：使用字符类型变量

```
public class Characters {
    public static void main(String args[]) {
        char ch1='a';        // 定义字符变量 ch1
        char ch2='B';         // 定义字符变量 ch2
        System.out.println("ch1="+ch1);  // 输出字符变量ch1
        System.out.println("ch2="+ch2);  // 输出字符变量ch2
    }
}
```

程序运行结果如下：
ch1=a
ch4=B
