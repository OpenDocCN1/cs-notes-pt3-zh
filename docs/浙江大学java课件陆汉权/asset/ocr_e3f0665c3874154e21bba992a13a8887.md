# 2.3 运算符和表达式

+   - **运算符 operator**
+     - 表示各种运算的符号
+     - 参与运算的数据称为操作数

+   - **运算符分类：根据操作数的个数**
+     - 单目运算：只有一个操作数
+     - 双目运算：有两个操作数
+     - 多目运算符：多个操作数

+   - **根据运算性质，运算符分为**
+     - 算术运算符：+(加)、-(减)、*(乘)、/(除)、%(求余数)、++、--
+     - 关系运算符：>、<、>=、<=、==、!=
+     - 逻辑运算符：&(与)、|(或)、!(非)、^(异或)、&&(条件与)、||(条件或)
+     - 位运算符：~(反)、&(与)、|(或)、^(异或)、<<(左移)、>>(右移)、>>>(无符号右移)
