# # 创建对象和使用对象调用

```
public static void main(String args[])
{
    double x,y;
    Circle1 cir=new Circle1(); //创建Circle1类的对象cir
    cir.setR(12.35f); //引用cir对象的setR()方法
    x=cir.area(); //引用cir对象的area()方法
    y=cir.perimeter(); //引用cir对象的perimeter()方法
    System.out.println("圆面积="+x+"\n圆周长="+y);
}
}
```
