# 【例4-2】

```
public class SquareC{
    static int square(int x) {    // 计算平方的方法
        int s;
        s=x*x;
        return s;
    }

    public static void main(String[] args){
        int n = 5;
        int result = square(n);    // 调用“方法”
        System.out.println(result);
    }
}
```
