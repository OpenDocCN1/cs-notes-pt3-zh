# ## 对象的引用

```
```java
class Point {
private int x,y;
public void setPoint(int a,int b) {
x=a;
y=b;
}
public int getX() {
return x;
}
public int getY() {
return y;
}
public String toString() {
return "["+x+","+y+"]";
}
}
```
```

+   - 引用成员变量  
+     对象名.成员变量名  
+     例如：P1.x=3;  
+       P1.y=5;
+   
+   - 引用方法  
+     对象名.方法名(参数列表)  
+     例如：int n=P1.getX();  
+       int m=P1.getY();

```
```java
Point p1;
p1= new Point();
p1.setPoint(3, 5);
System.out.print(p1.getX());
System.out.print(" "+ p1.getY());
System.out.print(" "+ p1.toString());
```
