## if 语句嵌套

if 语句中可以包含if语句，形成嵌套

```
if（布尔表达式1）
    语句1
else if（布尔表达式2）
    语句2

    ……
        else if（布尔表达式n）
            语句n
```

```java
public class Function{
    public static void main(String args[]) {
        float x, y;
        x=Float.parseFloat(args[0]);
        if ( x<0 )
            y = 0;
        else if ( x >=0 && x <= 10 )
            y = x;
        else if ( x > 10 && x <= 20 )
            y = 10;
        else
            y = -0.5f * x + 20;
        System.out.println("x="+x);
        System.out.println("y="+y);
    }
}
```

| 例3-6 分段函数 |  |
|---|---|
| x | y |
| x<0 | 0 |
| 0<=x<=10 | x |
| 10<x<=20 | 10 |
| 20<x | 0.5x+20 |

## Switch语句

```java
switch (表达式) {
    case 值1: 语句块1; // 如果表达式值为值1，执行语句块1
        break; // 终止，结束switch语句
    case 值2: 语句块2;
        break; // 终止，结束switch语句
    ......
    case 值n: 语句块n; // 如果表达式值为值n，执行语句块n
        break; // 终止，结束switch语句
    default: // 如果表达式值与值1～值n都不同，执行语句块n+1
        语句块n+1;
}
```
