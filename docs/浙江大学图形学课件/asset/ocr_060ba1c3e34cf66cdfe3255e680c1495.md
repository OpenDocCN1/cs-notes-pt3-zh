For example, suppose you want to draw a circle with 100 line segments

```
drawCircle() {
    GLint i;
    GLfloat cosine, sine;
    glBegin(GL_POLYGON);
        for(i=0;i<100;i++){
            cosine=cos(i*2*PI/100.0);
            sine=sin(i*2*PI/100.0);
            glVertex2f(cosine,sine);
        }
    glEnd();
}
```
