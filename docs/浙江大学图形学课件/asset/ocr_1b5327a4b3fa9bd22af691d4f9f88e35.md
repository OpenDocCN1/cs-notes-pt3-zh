# Rotate around \((x_r, y_r)\)

```
$$\begin{aligned}
\mathrm{newx} &= x-x_r\\
\mathrm{newy} &= y-y_r\\
\mathrm{newx}' &= \mathrm{newx}\cos\theta-\mathrm{newy}\sin\theta\\
\mathrm{newy}' &= \mathrm{newy}\cos\theta+\mathrm{newx}\sin\theta\\[4pt]
x' &= \mathrm{newx}'+x_r\\
y' &= \mathrm{newy}'+y_r
\end{aligned}$$
```
