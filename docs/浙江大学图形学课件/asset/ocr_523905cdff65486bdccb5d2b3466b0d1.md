# Bézier--- De Casteljau algorithm

given the control points $P_0$, $P_1$, ... $P_n$, and $t$ of Bézier curve, let:

$P_i^r(t)=(1-t)P_i^{r-1}(t)+tP_{i+1}^{r-1}(t)$, 其中
\[
r=1,\ldots,n;\quad i=0,\ldots,n-r
\]
\[
P_i^0(u)=P_i
\]

then
\[
P_0^n(t)=C(t).
\]
