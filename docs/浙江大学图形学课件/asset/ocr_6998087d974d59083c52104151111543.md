# # Rotation about arbitrary axis

+   - Given:
+     Axis: (x₁,y₁,z₁) to (x₂,y₂,z₂)
+     Angle of rotation: θ
+   - Procedure
+     1. Transform so that the given axis coincides with the Z axis
+     2. Rotate by θ
+     3. Apply inverse of step 1. transforms
