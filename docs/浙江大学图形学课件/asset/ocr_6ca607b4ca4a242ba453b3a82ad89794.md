# # Using the Vertex Arrays

```
void glArrayElement( ith )
void glDrawElements(mode, count, type, *indices);
```

Defines a sequence of geometric primitives using count number of
elements, whose indices are stored in the array indices. Type indicates the
data type of the indices array. Mode specifies what kind of primitives are
constructed

```
void glDrawArrays(mode, first, count);
```

Constructs a sequence of geometric primitives using array elements starting
at first and ending at first+count-1 of each enabled array.
