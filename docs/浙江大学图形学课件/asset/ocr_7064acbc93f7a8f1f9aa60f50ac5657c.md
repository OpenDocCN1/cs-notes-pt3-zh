# # Homogeneous Co-ordinates

[x,y]→[x<sup>∗</sup>,y<sup>∗</sup>,a]

x=x<sup>∗</sup>/a,y=y<sup>∗</sup>/a

[x,y]→[x,y,1]

+   • Any point (x,y,z) in Cartesian co-ordinates is written as
+   (x * w, y * w, z * w, w), w ≠ 0

in <u>Homogeneous Co-ordinates</u>

+   • The point (x,y,z,w) represents (x<sub>w</sub>/​,y<sub>w</sub>/​,z<sub>w</sub>/​)
+   in Cartesian co-ordinates when w ≠ 0
