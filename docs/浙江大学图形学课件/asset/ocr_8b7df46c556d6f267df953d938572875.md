+   2. $x_{i+1}=x_i+1$
+      if $P_i>0$, then $y_{i+1}=y_i+1$, else $y_{i+1}=y_i$;
+   3. draw $(x_{i+1}, y_{i+1})$;
+   4. calculate $P_{i+1}$: if $P_i>0$, then $P_{i+1}=P_i+2dy-2dx$, else $P_{i+1}=P_i+2dy$;
+   5. $i=i+1$; if $i<dx+1$ then goto 2; else end.
