# # Bézier curve

# ## Bézier curve

\( C\left(t\right)=\sum_{i=0}^nP_iB_{i,n}\left(t\right),\quad t\in\left[0,1\right] \)

where, \(P_i\left(i=0,1,\dots,n\right)\) are control points.

\(B_{i,n}\left(t\right)=C_n^it^i\left(1-t\right)^{n-i},t\in\left[0,1\right]\) Bernstein basis

\(\left\{\begin{array}{ c }
X(t)=\sum_{i=0}^nx_iB_{i,t}(t) \\
Y(t)=\sum_{i=0}^ny_iB_{i,t}(t) \\
\end{array}\right.\)

\(C(t)=\left(\begin{array}{ c }
X(t) \\
Y(t)
\end{array}\right),\quad P_i=\left(\begin{array}{ c }
x_i \\
y_i
\end{array}\right)\)
