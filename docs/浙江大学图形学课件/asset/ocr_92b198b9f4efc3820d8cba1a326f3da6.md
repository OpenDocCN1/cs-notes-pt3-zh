# # Building Objects From Vertices

+   - Specify a primitive mode, and enclose a set of vertices in a glBegin / glEnd block
+   ```
+   glBegin( GL_POLYGON );
+   glVertex3f( 1.0, 2.0, 0.0 );
+   glVertex3f( 0.0, 0.0, 0.0 );
+   glVertex3f( 3.0, 0.0, 0.0 );
+   glVertex3f( 3.0, 2.0, 0.0 );
+   glEnd();
+   ```
