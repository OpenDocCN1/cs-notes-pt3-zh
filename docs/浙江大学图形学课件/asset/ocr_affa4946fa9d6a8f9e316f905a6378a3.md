# # Vector Operations (contd.)

+   • Dot (Inner) Product
+   u.v = u v cos(θ)

+   • Length (Norm) of Vector
+   ||v|| = sqrt(v.v)

+   • Normalization of a Vector

\(\mathbf{v}' = \frac{\mathbf{v}}{\|\mathbf{v}\|} = \frac{1}{\sqrt{v_1^2 + v_2^2 + \cdots + v_n^2}} \mathbf{v}\)
