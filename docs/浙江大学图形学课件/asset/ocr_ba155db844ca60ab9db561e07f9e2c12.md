# # PCI Express Bandwidth Improvements (NVIDIA)

+   - Improved Write Bandwidth is Critical for Rendering Directly to System Memory

|    | Bandwidth (GB/s) |
|---|---|
|    | READ¹ | WRITE² |
| AGP-8X | 2 | 0.2 |
| PCI Express x16 | 4 | 4 |

¹ READ from system memory to GPU  
² WRITE from GPU to system memory
