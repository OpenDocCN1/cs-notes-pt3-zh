# General Linear
Transformation

$x \rightarrow a*x + b*y + c*z$

$y \rightarrow d*x + e*y + f*z$

$z \rightarrow g*x + h*y + i*z$

or

\[
\begin{bmatrix}x\\y\\z\end{bmatrix}
=
\begin{bmatrix}a&b&c\\d&e&f\\g&h&i\end{bmatrix}
\begin{bmatrix}x\\y\\z\end{bmatrix}
\]

+     - Translation
+     - Scaling
+     - Rotation
