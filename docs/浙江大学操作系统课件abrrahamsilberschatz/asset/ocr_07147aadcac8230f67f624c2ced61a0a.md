# Layered Structure of the THE OS
THE OS的层次化结构

▪ A layered design was first used in THE operating system. Its six layers are as follows:
THE操作系统首先使用层次化设计。有如下六层：

+   1. layer 5: user programs
+   2. layer 4: buffering for input and output
+   3. layer 3: operator-console device driver
+   4. layer 2: memory management
+   5. layer 1: CPU scheduling
+   6. layer 0: hardware
