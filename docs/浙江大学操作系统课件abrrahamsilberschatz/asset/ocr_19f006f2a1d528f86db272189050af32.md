# # Common Functions of Interrupts
## 中断的常见功能

+   - The occurrence of an event is usually signaled by a interrupt from either hardware or the software. Software may trigger an interrupt by executing a special operation called a system call 系统调用 (monitor call).
+   - Modern operating system is *interrupt driven*.
+   - Events are almost always signaled by the occurrence of an interrupt or a trap.
+   - A *trap* (or exception) is a software-generated interrupt caused either by an error or a user request.

现代操作系统是中断驱动的
