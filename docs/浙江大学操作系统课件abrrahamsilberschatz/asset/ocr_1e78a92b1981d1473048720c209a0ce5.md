# Process Creation

Parent and child share no resources.

父进程和子进程无资源共享

+   - **Execution** 执行
+     - Parent and children execute concurrently.
+   
+       父进程和子进程并发执行
+     - Parent waits until children terminate.
+   
+       父进程等待，直到子进程终止

+   - **Address space** 地址空间
+     - Child duplicate of parent. 子女复制双亲
+     - Child has a program loaded into it.
+   
+       子女有一个程序被调入
