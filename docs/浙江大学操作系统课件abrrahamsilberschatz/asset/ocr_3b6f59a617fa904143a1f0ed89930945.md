# # 7.8.2 Windows 2000 Synchronization

+   - Uses interrupt(中断掩模)masks to protect access to global resources on uniprocessor systems.
+   - Uses spinlocks(自旋锁) on multiprocessor systems.
+   - Provides dispatcher objects (调度器对象) for thread synchronization outside of the kernel .
+   - Using a dispatcher objects, a thread can synchronize according to several different mechanisms include mutexes 、 semaphores and event. An event acts much like a condition variable.
+   - Dispatcher objects may be in either a signaled or nonsignaled state.
