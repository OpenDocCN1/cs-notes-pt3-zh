# ## 13.4 Buffering – store data in memory while transferring between devices

缓冲—当设备间传输数据的时候，暂时存放在内存中

+   - To cope with device speed mismatch
+     解决设备速度不匹配

+   - To cope with device transfer size mismatch
+     解决设备传输块的大小不匹配

+   - To maintain “copy semantics”
+     为了维持拷贝语句的语义要求
