# 4.5.4 Buffering 缓冲

+   Queue of messages attached to the link; implemented in one of three ways.
+   消息队列附加在连接上；采用三个之一的实现方案
+   1. Zero capacity ,a message system with no buffer – 0 messages , Sender must wait for receiver (rendezvous).
+   零容量 - 0 消息，发送者必须等待接收者
+   2. Bounded capacity – finite length of n messages , Sender must wait if link full. 有界容量 - n个消息有限长度，若连接满了发送者必须等待
+   3. Unbounded capacity – infinite length, Sender never waits.
+   无界容量 - 无限长度，发送者从不等待
