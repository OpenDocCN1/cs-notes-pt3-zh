# # 3.1.2 Main-Memory Management 主存管理

+   - Memory is a large array of words or bytes, each with its own address. It is a repository of quickly accessible data shared by the CPU and I/O devices. 存储器是字或字节的一个大数组，每一字或字节有自己的地址。它是一个可被CPU和I/O 共享、可快速存取数据的存放地

+   - Main memory is a volatile storage device. It loses its contents in the case of system failure. 主存储器是一个易失性存储设备。系统失败时，会丢失其内容
