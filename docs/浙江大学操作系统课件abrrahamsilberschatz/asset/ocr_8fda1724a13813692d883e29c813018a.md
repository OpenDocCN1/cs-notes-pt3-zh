# 14.8.3.3 Cost　成本

+   - Main memory is much more expensive than disk storage　主存比磁盘存储要贵很多。

+   - The cost per megabyte of hard disk storage is competitive with magnetic tape if only one tape is used per drive.　硬盘存储的每兆字节成本与磁带不相上下，如果每个驱动器只用一条磁带。

+   - The cheapest tape drives and the cheapest disk drives have had about the same storage capacity over the years. 近年来，最便宜的磁带驱动器和最便宜的磁盘驱动器的存储容量几乎一样。

+   - Tertiary storage gives a cost savings only when the number of cartridges is considerably larger than the number of drives.　只有当磁碟的数量远大于驱动器数量的时候，三级存储才能节约成本。
