# Computer System Components
计算机系统部件

+   1. **Hardware硬件** – provides basic computing resources (CPU, memory, I/O devices). 提供基本的计算资源

+   2. **Operating system操作系统** – controls and coordinates the use of the hardware among the various application programs for the various users.
+   在各种应用程序和用户之间控制与协调对硬件的使用

+   3. **Applications programs应用程序** – define the ways in which the system resources are used to solve the computing problems of the users (compilers, database systems, video games, business programs).
+   定义解决用户问题的资源使用方式（编译、数据库、视频游戏、事务程序等）

+   4. **Users用户** (people, machines, other computers).
