# # 8.1 The Deadlock Problem死锁问题

+   - A set of blocked processes each holding a resource and waiting to acquire a resource held by another process in the set.

一组等待的进程，其中每一个进程都持有资源，并且等待着由这个组中其他进程所持有的资源

+   - Example

+   - System has 2 tape drives.系统有两个磁带设备

+   - _P_<sub>1</sub> and _P_<sub>2</sub> each hold one tape drive and each needs another one.进程P1和P2各占有一个磁带设备并且实际需要两个磁带

+   - Example

+   - semaphores A and B, initialized to 1信号量A， B初始化为1

```
```
P<sub>0</sub>
wait (A);
wait (B);

P<sub>1</sub>
wait(B)
wait(A)
