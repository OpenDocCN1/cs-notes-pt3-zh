# 4.5.6 An Example例：Windows 2000

+   Windows 2000 -- an example of modern design that employs modularity to increase functionary and decrease the time needed to implement new features .
+   Windows 2000—使用模块化增加功能和实现新功能节约时间的现代设计的一个例子。

+   Windows 2000 provides support for multiple operating environments or subsystems, with which application programs communication via a message-passing mechanism ,that is called the local procedure call (LPC) facility . LPC is similar to the standard RPC mechanism that is widely used, but It is optimized for and specific to Windows 2000.
+   Windows 2000 为多重操作环境或子系统提供支持,应用程序经由消息传递机制与子系统通信,那消息传递机制被称为本地过程调用（ LPC ）设备 。 LPC 类似于广泛地被使用的标准 RPC 机制，但是它被优化为并且规范到Windows 2000中 。
