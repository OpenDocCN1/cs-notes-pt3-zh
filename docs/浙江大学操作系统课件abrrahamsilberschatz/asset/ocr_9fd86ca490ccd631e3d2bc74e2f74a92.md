# # Valid-Invalid Bit

+   With each page table entry a valid–invalid bit is associated (1 ⇒ in-memory, 0 ⇒ not-in-memory)

在每一个页表的表项有一个有效- 无效位相关联， 1表示在内存， 0表示不内存

+   Initially valid–invalid but is set to 0 on all entries. 在所有的表项， 这个位被初始化为0
