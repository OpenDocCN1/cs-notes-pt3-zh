# # Monitor Implementation Using Semaphores

+   - Variables

```
semaphore mutex;  // (initially = 1)
semaphore next;   // (initially = 0)
int next-count = 0;
```

+   - Each external procedure *F* will be replaced by

```
wait(mutex);

...
body of F;

...
if (next-count > 0)
    signal(next)
else
    signal(mutex);
```

+   - Mutual exclusion within a monitor is ensured.
