# # Page Fault

+   - If there is ever a reference to a page, first reference will trap to OS ⇒ page fault
+     如果有对一个页的访问，第一个访问要陷入OS⇒ 缺页

+   - OS looks at another table to decide:
+     OS查看另一个表来决定
+     - Invalid reference ⇒ abort.
+       无效引用 ⇒ 终止
+     - Just not in memory.
+       仅仅不在内存
