# # 9.3.1 Memory protection

+   Single-partition allocation(单一分区分配)
+   Relocation-register scheme used to protect user processes from each other, and from changing operating-system code and data.
+   （基址寄存器策略由来保护用户进程（同其他进程和改变的操作系统代码和数据分开。）
+   Relocation register contains value of smallest physical address; limit register contains range of logical addresses – each logical address must be less than the limit register. （基址寄存器包含最小物理地址的值； 限长寄存器包含逻辑地址的范围，每个逻辑地址必需比限长寄存器的值小。）
