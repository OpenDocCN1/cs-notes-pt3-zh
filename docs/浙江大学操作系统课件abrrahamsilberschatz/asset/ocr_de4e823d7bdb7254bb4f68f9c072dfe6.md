# # Operating System Definitions 操作系统定义

+   - Resource allocator 资源分配者– manages and allocates system resources.管理和分配系统资源

+   - Control program控制程序– controls the execution of user programs and operations of I/O devices . 控制用户程序的运行和I/O设备的操作

+   - Kernel内核– the one program running at all times (all else being application programs). 在全时运行的一个程序（其他的应用）

+   - An interface between the user and hardware人机接口

+   - Masks the details of the hardware
