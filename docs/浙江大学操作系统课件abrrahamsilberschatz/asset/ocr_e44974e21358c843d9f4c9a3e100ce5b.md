# # Demand Paging

+   - Bring a page into memory only when it is needed  
+     （只有在一个页需要的时候才把它换入内存）。  
+     - Less I/O needed（需要很少的I/O）  
+     - Less memory needed （需要很少的内存）  
+     - Faster response（快速响应）  
+     - More users（多用户）

+   - Page is needed ⇒ reference to it  
+     （需要页） （查阅此页）  
+     - invalid reference⇒ abort  
+     （无效的访问） （中止）  
+     - not-in-memory⇒ bring to memory  
+     （不在内存） （换入内存）
