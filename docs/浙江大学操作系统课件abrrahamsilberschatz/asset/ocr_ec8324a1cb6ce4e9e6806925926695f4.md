# # 7.4 Semaphores信号量

+   - Synchronization tool that does not require busy waiting.一种不需要忙等待的同步工具.
+   - Semaphore S – integer variable信号量S – 整型变量
+   - can only be accessed via two indivisible (atomic) operations
+   仅能通过两个不可分割的[原子]操作访问

```
wait (S):
    while S≤ 0 do no-op;
    S--;

signal (S):
    S++;
```
