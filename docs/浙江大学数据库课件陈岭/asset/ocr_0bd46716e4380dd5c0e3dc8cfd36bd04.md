# DECLARE

# Syntax

```
identifier [CONSTANT] datatype [NOT NULL]
          [:= | DEFAULT expr];
```

# Examples

> > Notice that PL/SQL includes
> > all SQL types, and more...

```
Declare
    birthday     DATE;
    age          NUMBER(2)  NOT NULL := 27;
    name         VARCHAR2(13) := 'Levi';
    magic        CONSTANT NUMBER := 77;
    valid        BOOLEAN NOT NULL := TRUE;
```
