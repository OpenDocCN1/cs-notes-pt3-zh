For a relation schema R(A,B,C,D) with F={AB→C, C→D, D→A}.

+   1) List all the candidate keys for the relation schema R.
+   
+   2) Decompose the relation schema R into a collection of BCNF relation schemas.
+   
+   3) Explain whether the decomposition of B2) is dependency preserving.

ANS:

1): (AB)⁺ = (ABCD) ⊇ R, (BC)⁺ = (ABCD) ⊇ R, D→A, BD→AB; AB→C; ∴ (BD)⁺ = (ABCD) ⊇ R, ∴ AB, BC, BD are candidate keys. And R is not in BCNF.

2): R1(C,D); R2(A,B,C),

(R1 is in BCNF, R2 is not BCNF; ∵ C→D, D→A, ∴ C→A, C is not key of R2);

R21(A,C), R22(B,C), R21 is in BCNF, R22 is in BCNF.

3): D→A, AB→C are not preserved
