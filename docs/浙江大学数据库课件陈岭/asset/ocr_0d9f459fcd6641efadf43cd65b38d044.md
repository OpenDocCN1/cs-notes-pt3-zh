# Example of Cartesian product

例如

$D_1=\text{导师集合}=\{张清玫，刘逸\}$

$D_2=\text{专业集合}=\{计算机，信息\}$

$D_3=\text{研究生集合}=\{李勇，刘晨，王名\}$

则 $D_1\times D_2\times D_3=$

+   1. (张清玫，计算机，李勇)
+   2. (张清玫，计算机，刘晨)
+   3. (张清玫，计算机，王名)
+   4. (张清玫，信息，李勇)
+   5. (张清玫，信息，刘晨)
+   6. (张清玫，信息，王名)
+   7. (刘逸，计算机，李勇)
+   8. (刘逸，计算机，刘晨)
+   9. (刘逸，计算机，王名)
+   10. (刘逸，信息，李勇)
+   11. (刘逸，信息，刘晨)
+   12. (刘逸，信息，王名)

共12个元组。
