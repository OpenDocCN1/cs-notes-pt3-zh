# (3) SQL (cont.)

SQL is the most widely used query language . There are three kinds of usage:

+   Use it directly in the interactive environment

+   SQL Server: Query Analyzer (查询分析器)

+   Oracle: Sql*Plus, Work Sheet

+   MySQL: mysql command line client

+   Use it by host language through ODBC (Open DataBase Connectivity), JDBC

+   Use it by host language with embedded-SQL
