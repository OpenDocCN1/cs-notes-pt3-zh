# # Data Manipulation Language(DML)

+   - Retrieve data from the database
+   - Insert / delete / update data in the database
+   - DML also known as query language

# ## Two classes of languages

+   - Procedural – user specifies what data is required and how to get those data (C, Pascal, Java, ...)
+   - Nonprocedural – user specifies what data is required without specifying how to get those data (SQL, Prolog)
