# # 3.3 Set Operations (cont.)

+   - Suppose a tuple occurs _m_ times in _r_ and _n_ times in _s_, then, it occurs:
+     - _m + n_ times in ( _r_ **union all** _s_ )
+     - min(_m,n_) times in ( _r_ **intersect all** _s_ )
+     - max(0, _m - n_) times in ( _r_ **except all** _s_ )

> > 当M < n

> > 当M > n
