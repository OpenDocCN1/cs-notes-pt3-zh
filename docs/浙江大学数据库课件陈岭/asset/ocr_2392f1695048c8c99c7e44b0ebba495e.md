# # Example- what does this do?

# ### Table mylog

| logon_num | who |
|---|---|
| 3 | Pete |
| 4 | John |
| 2 | Joe |

```
```
create or replace procedure
num_logged
(person IN mylog.who%TYPE,
num OUT mylog.logon_num%TYPE)
IS
BEGIN
	select logon_num
	into num
	from mylog
	where who = person;
END;
/
