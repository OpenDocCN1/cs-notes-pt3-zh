# ## 3) Dependency preservation （依赖保持）

+   - To check updates (to ensure not violate any FD) efficiently, allow updates validation in sub-relations R<sub>i</sub> respectively, without executing the join of them.

+   - Restriction of F to R<sub>i</sub> is: F<sub>i</sub> ⊆ F<sup>+</sup> , F<sub>i</sub> includes only attributes of R<sub>i</sub>

+   - (F<sub>1</sub> ∪ F<sub>2</sub> ∪ ... ∪ F<sub>n</sub>)<sup>+</sup> = F<sup>+</sup>, where F<sub>i</sub> be the set of dependencies in F<sup>+</sup> that include only attributes in R<sub>i</sub>.

# ## 4) No redundancy: The relations R<sub>i</sub> preferably should be in either Boyce-Codd Normal Form or Third Normal Form, i.t BCNF or 3NF.
