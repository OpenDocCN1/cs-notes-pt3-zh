# # 3NF Decomposition Algorithm

Let \( F_c \) be a canonical cover for \( F \); \( i := 0 \); for each functional dependency \( \alpha \rightarrow \beta \) in \( F_c \) do { if none of the schemas \( R_j, 1 \leq j \leq i \) contains \( \alpha \beta \) then begin \( i := i + 1 \); \( R_i := (\alpha \beta) \) end} if none of the schemas \( R_j, 1 \leq j \leq i \) contains a candidate key for \( R \) then begin \( i := i + 1 \); \( R_i := \) any candidate key for \( R \); end return \( (R_1, R_2, \dots, R_i) \)

> 将Fc中的每个\(\alpha \rightarrow \beta\)分解为子模式\( R_i := (\alpha, \beta) \)，从而保证 dependency-preserving

> 保证至少在一个\( R_i \)中存在\( R \)的候选码，从而保证 lossless-join
