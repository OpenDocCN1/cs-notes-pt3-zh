# # SUMMARY

1. The format of select statement:
SELECT <[DISTINCT] c1,c2,....> FROM <r1,....>
[WHERE <condition>]
[GROUP BY <c1,c2,.....> [HAVING <cond2>] ]
[ORDER BY <c1[DESC]][,c2[DESC|ASC],.....]>

2. The execution order of SELECT:
From → where →group (aggregate) →having
→select →order by

Note: Predicates in the having clause are applied
after the formation of groups, whereas predicates in
the where clause are applied before forming groups.

3. Aggregate functions cannot be used
in where clause directly.
