# # HTML简介

使用<标志名></标志名>来表示标志的开始和结束(例如<html></html>标志对)

+   - <head>和</head>构成Html文档的开头部分,是描述信息。

+   - <body></body>是Html文档的主体部分，在此标志对之间可包含<p>、</p>、<h1>、</h1>、<br>、<hr>等等众多的控制显示的标志，它们所定义的文本、图像等将会在浏览器的框内显示出来。

<html>
<head>
<title>显示在浏览器最上边蓝色条中的文本</title>
</head>
<body bgcolor="red" text="blue">
<h2>今天天气真好！</h2>
<font face="Arial, Helvetica"> Hello World! </font>
<p>珍惜每一天，远离游戏与毒品！ </p>
</body>
</html>

> 描述html文档相关信息的标志。其中<title></title>间的信息显示在浏览器顶部。
