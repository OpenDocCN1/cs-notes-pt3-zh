# # Stylus Studio XML Enterprise Suite

Stylus Studio® XML Enterprise Suite is an advanced XML Integrated Development Environment (XML IDE) consisting of hundreds of powerful XML tools in one all-inclusive suite, and high-performance Java & .NET components to design data integration applications.

Stylus Studio supports for working with Xquery, XML Pipeline, XSLT XSL:FO, EDI, XML Schema/DTD, XPath, XML & Databases, XHTML, XML mapping, XML publishing, Web services.
