# Deletion Examples

+   - Delete all account records in the Perryridge branch.
+   
+     *account* ← *account* − σ<sub>branch-name = “Perryridge”</sub>(*account*)

+   - Delete all loan records with amount in the range of 0 to 50.
+   
+     *loan* ← *loan* − σ<sub>amount ≥ 0 and amount ≤ 50</sub>(*loan*)

+   - Delete all accounts at branches located in Needham.
+   
+     *r*<sub>1</sub> ← σ<sub>branch-city = “Needham”</sub>(*account* ⋈ *branch*)
+   
+     *r*<sub>2</sub> ← Π<sub>branch-name, account-number, balance</sub>(*r*<sub>1</sub>)
+   
+     *r*<sub>3</sub> ← Π<sub>customer-name, account-number</sub>(*r*<sub>2</sub> ⋈ *depositor*)
+   
+     *account* ← *account* − *r*<sub>2</sub>
+   
+     *depositor* ← *depositor* − *r*<sub>3</sub>
