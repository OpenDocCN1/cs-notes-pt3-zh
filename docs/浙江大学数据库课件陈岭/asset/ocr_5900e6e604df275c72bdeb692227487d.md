# # Third Normal Form

■ **Definition:** A relation schema *R* is in third normal form (3NF) if for all α → β in F⁺ at least one of the following holds:

+   1. α → β is **trivial** (i.e., β ⊆ α)
+   2. α is a **superkey** for *R*
+   3. Each attribute *A* in β − α is contained in a **candidate key** for *R*.
+   
+   *NOTE: each attribute may be in a different candidate key*

■ If a relation is in BCNF, it is in 3NF (since in BCNF one of the first two conditions above must hold).

■ Third condition is a minimal relaxation of BCNF to ensure dependency preservation.

> 讨论：国内其他教材关于3NF的定义：不存在非主属性对码的部分依赖和传递依赖。
> 。该定义实际是说，当β为非主属性时，α必须是码；但当β为主属性时，则α无限制。
> 。二种定义本质上是一致的。
