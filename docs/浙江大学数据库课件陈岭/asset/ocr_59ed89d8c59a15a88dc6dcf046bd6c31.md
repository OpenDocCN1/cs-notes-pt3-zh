# # Decomposition(cont.)

# ## (2) desirable properties of decomp.(分解应有的特性)

1) All attributes of an original schema (**_R_**) must appear in the decomposition (**_R_1**, **_R_2**):
_R_ = _R_<sub>1</sub> ∪ _R_<sub>2</sub>

2) Lossless-join decomposition.
For all possible relations _r_ on schema _R_

+   - _r_ = Π<sub>_R_1</sub> (_r_) ⋈ Π<sub>_R_2</sub> (_r_)

+   - A decomposition of R into _R_<sub>1</sub> and _R_<sub>2</sub> is lossless-join if and only if at least one of the following dependencies are held in F<sup>+</sup> :

✦ {_R_<sub>1</sub> ∩ _R_<sub>2</sub> }→ _R_<sub>1</sub>
or
✦ {_R_<sub>1</sub> ∩ _R_<sub>2</sub> }→ _R_<sub>2</sub>

无损连接分解的条件：
分解后的二个子模式的共同属性必须是R1或R2的码。（适用于一分为二的分解）
