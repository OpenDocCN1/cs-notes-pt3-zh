# # 10.1 Introduction

+   - XML: Extensible Markup Language (可扩展标志语言)

+   - Defined by the WWW Consortium (W3C)

+   - Derived from SGML (Standard Generalized Markup Language), but simpler to use than SGML (通用标志语言标准)

+   - Documents have tags (标识) giving extra information about sections of the document

+   - E.g. <title> XML </title> , <slide> Introduction ...</slide>

+   - Extensible, unlike HTML

+   - HTML (Hypertext Markup Language， 超文本标记语言)

+   - HTML是一个定型的标记语言，它用固有的标记来描述要在网页上显示的内容。比如<H1>表示首行标题，有固定的尺寸。

+   - XML则没有固定的标记，XML不能直接描述网页具体的外观，内容，它只是描述内容的数据形式和结构。

+   - Users can add new tags, and separately specify how the tag should be handled for display
