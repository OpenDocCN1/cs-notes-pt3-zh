# Example 3: Find all customers who have both an account and a loan at the Perryridge branch.

```
Query1: select distinct *customer_name*\n        from *borrower A, loan B*\n        where *A.loan_number = B.loan_number* and\n        *branch_name* = “Perryridge” and\n        (*branch_name, customer_name*) in\n        (select *branch_name, customer_name*\n         from *depositor C, account D*\n         where *C.account_number = D.account_number*);
```

+   Note: Above query can be written in a much simpler manner. The formulation above is simply to illustrate SQL features.
