# # 7.1 First Normal Form (cont)

+   - How to deal with Non-atomic values's =>
+     - For composite attributes: use a number of attributes.
+     - For multi-value attribute:
+       - (1)Use multi fields, as person(pname, ... , phon1, phon2, phon3, ...);
+       - (2) Use a separate table, as phone(pname, phone);
+       - (3) Use single field, as person(pname, ..., phones,...)
+   - Drawbacks of non-atomic strategy: complicate storage; encourage redundant storage of data; complicated to query.
