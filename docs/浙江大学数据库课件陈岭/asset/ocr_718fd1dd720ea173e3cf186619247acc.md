# (4) Update of a View (cont.)

Updates on more complex views are difficult or impossible to translate, and hence are disallowed. e.g:

```
Create view all_customer as
select branch_name, customer_name from
account, depositor where …
union
select branch_name, customer_name from
loan, borrower where …;
```

+   - E.g: insert into all_customer values(`Second Bank’, `W. Bush’);
+   - delete from all_customer where …
