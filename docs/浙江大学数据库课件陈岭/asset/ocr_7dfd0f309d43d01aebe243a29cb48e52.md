# Comparison of BCNF and 3NF (Cont.)

# ■ Example of problems due to redundancy in 3NF

◉ **R** = (J, K, L)  
**F** = {JK → L, L → K}

| J | L | K |
|---|---|---|
| J₁ | l₁ | k₁ |
| J₂ | l₁ | k₁ |
| J₃ | l₁ | k₁ |
| null | l₂ | k₂ |

> J---student, K---course,  
> L---teacher（一门有多个教师，一个教师上一门课，一个学生选多门课，一门课有多个学生选）

A schema that is in **3NF** but not in **BCNF** has the problems of **repetition of information** (e.g., the relationship l₁, k₁), and may need to **use null values** (e.g., to represent the relationship l₂, k₂ where there is no corresponding value for J).
