# Definition of all Clause

▪ C <comp> all r ⇔ ∀ t ∈ r (C <comp> t)

(5< all \begin{bmatrix}0\\5\\6\end{bmatrix}) = false

(5< all \begin{bmatrix}6\\10\end{bmatrix}) = true

(5 = all \begin{bmatrix}4\\5\end{bmatrix}) = false

(5 ≠ all \begin{bmatrix}4\\6\end{bmatrix}) = true (since 5 ≠ 4 and 5 ≠ 6)

> (≠ all) = not in  
> However, (= all) ≠ in
