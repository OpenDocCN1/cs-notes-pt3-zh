# Set Operations (cont.)

+   - Example 3: Find all customers who have an account **but no loan.**

```
(SELECT *customer_name* FROM *depositor*)
**EXCEPT** (SELECT *customer_name* FROM *borrower*);
```

+   - In Oracle, use *union, union ALL, intersect and Minus;* **but no Intersect ALL and Minus ALL.**

+   - In SQL Server 2000, only support *Union, Union All.*
