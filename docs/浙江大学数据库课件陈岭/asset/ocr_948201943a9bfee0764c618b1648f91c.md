# （5）String Operations (cont.)

+   - SQL supports a variety of string operations such as
+     - concatenation (串联) (using “||”)
+       ```sql
+       select ‘客户名=’ || customer_name from customer where ...;
+       ```
+     - converting from upper to lower case (and vice versa), using Function: `lower()`, `upper()`
+     - finding string length, extracting substrings, etc. using Function

```
select ‘客户名=’ || customer_name from customer where ...;
```
