# # Definition of Some Clause

- C <comp> some r ⇔ ∃ t ∈ r (C <comp> t)
Where <comp> can be: < , ≤ , > , = , ≠

(5< some [0\n5\n6] ) = true   (read: 5 < some tuple in the relation)

(5< some [0\n5] ) = false

(5 = some [0\n5] ) = true

(5 ≠ some [0\n5] ) = true (since 0 ≠ 5)

(= some) ≡ in
However. (≠ some) ≠ not in
