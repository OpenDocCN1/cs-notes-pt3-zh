# # Testing for Dependency Preservation

To check if a dependency \(\alpha \rightarrow \beta\) is preserved in a decomposition of R into R₁, R₂, ..., Rₙ , we apply the following **simplified test**:

+   - result = α
+     while (changes to result) do
+     for each Rᵢ in the decomposition
+     t = (result ∩ Rᵢ)⁺ ∩ Rᵢ;
+     result = result ∪ t
+   - If result contains all attributes in β,
+     then the functional dependency \(\alpha \rightarrow \beta\) is preserved.
