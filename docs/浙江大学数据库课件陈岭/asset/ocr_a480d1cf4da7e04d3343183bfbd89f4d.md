# ## (4) the Rename Operation
### (a) Column rename

+   - `as is` optional.

❖ In SQL Server, allow: *new-name = column expression*, E.g.:

```
SELECT customer_name,
       loan_id = borrower.loan_number, amount
FROM borrower, loan;
```

```
SELECT customer_name,
       borrower.loan_number as loan_id, amount
FROM borrower, loan
WHERE borrower.loan_number = loan.loan_number;
```
