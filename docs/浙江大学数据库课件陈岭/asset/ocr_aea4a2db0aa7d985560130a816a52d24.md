# # Loops: Simple Cursor Loop

```
create table number_table(
    num NUMBER(10)
);
```

```
DECLARE
    cursor c is select * from number_table;
    cVal c%ROWTYPE;
BEGIN
    open c;
    LOOP
        fetch c into cVal;
        EXIT WHEN c%NOTFOUND;
        insert into doubles values(cVal.num*2);
    END LOOP;
END;
```
