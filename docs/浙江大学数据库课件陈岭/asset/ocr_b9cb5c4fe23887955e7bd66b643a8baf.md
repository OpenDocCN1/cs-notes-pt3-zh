# Suppose we have the following table:

```
create table mylog(
who varchar2(30),
logon_num number
);
```

| logon_num | who |
|-----------|-----|
| 3         | Peter |
| 4         | John |
| 2         | Moshe |

+   Want to keep track of how many times someone logged on to the DB

+   When running, if user is already in table, increment logon_num. Otherwise, insert user into table
