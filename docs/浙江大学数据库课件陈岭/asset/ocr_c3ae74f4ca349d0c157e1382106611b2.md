# Multivalued Dependencies (MVDs)

**Definition:** Let *R* be a relation schema and let α ⊆ *R* and β ⊆ *R*. The **multivalued dependency**

α ↠ β

holds on *R*, if in any legal relation *r(R)*, for all pairs of tuples *t₁* and *t₂* in *r* such that *t₁*[α] = *t₂*[α], there exist tuples *t₃* and *t₄* in *r* such that:

+   * *t₁*[α] = *t₂*[α] = *t₃*[α] = *t₄*[α]
+   * *t₃*[β] = *t₁*[β]
+   * *t₄*[β] = *t₂*[β]
+   * *t₃*[R − α − β] = *t₂*[R − α − β]
+   * *t₄*[R − α − β] = *t₁*[R − α − β]
