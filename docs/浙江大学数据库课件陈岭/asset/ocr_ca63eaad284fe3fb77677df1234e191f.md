# ## Exam2: R = (A, B, C), F={A → B, BC→ A}, which is candidate key ?

(BC)⁺=(BCA) ⊇ R. (AC)⁺=(ACB) ⊇ R. (AB)⁺=(AB) ⊋ R

∴ candidate key: BC, AC
