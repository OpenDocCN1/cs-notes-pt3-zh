# # Weak Entity Sets (Cont.)

+   - Note: the primary key of the strong entity set is **NOT explicitly stored with the weak entity set**, since it is implicit in the identifying relationship.

+   - If _loan-number_ were explicitly stored, _payment_ could be made a strong entity, but then the relationship between _payment_ and _loan_ would be **duplicated** by an implicit relationship defined by the attribute _loan-number_ common to _payment_ and _loan_
