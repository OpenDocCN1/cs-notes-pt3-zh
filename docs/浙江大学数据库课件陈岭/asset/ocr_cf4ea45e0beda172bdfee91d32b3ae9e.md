# example1

1. Given F = { AB → E, BE → I, E → G, GI → H }, using only Armstrong Axiom to prove AB → GH

ANS:

AB → E,  aug  AB → BE;  BE → I,  aug  BE → EI;

∴ AB → EI  ----(1)

E → G,  aug  EI → GI;  GI → H,  aug  GI → GH

∴ EI → GH  ----(2)

∴ (1), (2)  tran  AB → GH
