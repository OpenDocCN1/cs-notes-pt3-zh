# # (4.b) Redundancy of Tables (Cont.)

**(b) The table corresponding to a relationship set linking a weak entity set to its identifying strong entity set is redundant. （联系弱实体集及其标识性实体集的联系集对应的表是冗余的，即对应identifying relationship的表是多余的。）**

• E.g. The _payment_ table already contains the information that would appear in the _loan-payment_ table (i.e., the columns _loan-number_ and _payment-number_).
