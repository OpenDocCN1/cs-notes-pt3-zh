# # Canonical Cover (cont.)

对于情况（2），\(\alpha \rightarrow \mathbf{A}\beta'\)，等价于{\(\alpha \rightarrow \beta'\)，\(\alpha \rightarrow \mathbf{A}\)}，如果\(\alpha \rightarrow \mathbf{A}\)可以由其余的函数依赖所蕴涵，则说明\(\alpha \rightarrow \mathbf{A}\)多余，即\(\alpha \rightarrow \mathbf{A}\beta'\)中的**A**多余，只要保留\(\alpha \rightarrow \beta'\)就可以了。换句话说，如果我们把F中去掉\(\alpha \rightarrow \mathbf{A}\)之后余下的部分叫F'，即F' = (F - {\(\alpha \rightarrow \beta\)}) U {\(\alpha \rightarrow (\beta - \mathbf{A})\)})，则如果F'可以推出\(\alpha \rightarrow \mathbf{A}\)，这说明\(\alpha \rightarrow \mathbf{A}\)多余，只要保留F'就可以了。也就是说，如果F'蕴涵F，则右属性**A**可删除。
