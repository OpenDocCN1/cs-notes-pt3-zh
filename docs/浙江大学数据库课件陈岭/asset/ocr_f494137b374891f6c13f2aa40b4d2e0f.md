# 7.4 Decomposition（分解）

# (1) Goals of Normalization（规范化的目标）

+   - Judge whether a particular relation *R* is in “good” form. *(no redundant, insert/delete/update anomalies)*

+   - In the case that a relation *R* is **not in “good” form**, **decompose it** into a set of relations {*R₁, R₂, ..., Rₙ*} such that:

+     - the decomposition is a lossless-join decomposition.（无损连接分解）

+     - the decomposition is dependency preservation.（依赖保持）

+     - each relation *Rᵢ* is in good form
+       - BCNF or 3NF.
