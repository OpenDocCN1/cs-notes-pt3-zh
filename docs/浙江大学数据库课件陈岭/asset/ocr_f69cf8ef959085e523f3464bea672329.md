# Example

R = (A, B, C)
F = { A → B, B → C }
Key = {A}

Any relation schema with two attributes is in BCNF.

R is **not in BCNF** (∵ F⁺ = {A → B, B → C, A → C, …}, for B → C, **B is not a key**)

Decomposition R₁ = (A, B), R₂ = (B, C)

+   - **R₁ and R₂ in BCNF.** (A is the key for R₁, B is the key for R₂)
+   - **Lossless-join decomposition.** (R₁ ∩ R₂ = B, and B is the key for R₂)
+   - **Dependency preserving.** (F₁ = {A → B} holds on R₁, F₂ = {B → C} holds on R₂)
