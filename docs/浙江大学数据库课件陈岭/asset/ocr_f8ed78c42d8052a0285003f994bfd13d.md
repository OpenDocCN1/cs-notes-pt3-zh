# Constraints on a Single Relation

+   - not null
+   - primary key
+   - unique
+   - check (`P`), where `P` is a predicate

```
create table *branch2* (
    *branch_name* varchar (30) **primary key**,
    *branch_city* varchar(30),
    *assets* integer **not null**,
    **check** (*assets* >= 100) );
```
