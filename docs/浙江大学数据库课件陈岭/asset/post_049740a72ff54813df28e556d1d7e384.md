

## Joined Relations（Cont.）

▪ **E.g:** Find all customers who have either an account or a loan (**but not both**) at the bank.

```sql
select **customer_name**
from (**depositor** natural full outer join **borrower**)
where **account_number** is **null** or **loan_number** is **null**
```

Customer_name 为连接条件

## 主流商用数据库中外连接的表示

SQL Server（二种形式）：

```sql
(1) SELECT loan.loan_number, branch_name, amount,
    customer_name
    FROM loan left outer join borrower on
    loan.loan_number = borrower.loan_number;
```

```sql
(2) SELECT loan.loan_number, branch_name, amount,
    customer_name
    FROM loan, borrower
    WHERE loan.loan_number *= borrower.loan_number;
```

（注：Left join: *=，Right join: =*）

## 主流商用数据库中连接的表示(CONT.)

**ORACLE:**

```sql
SELECT loan.loan_number, branch_name, amount,
       customer_name
FROM loan, borrower
WHERE loan.loan_number = borrower.loan_number(+);
```

> 注：Right join:
> loan.loan_number(+) = borrower.loan_number
> [相当于在（+）侧附加一特殊空行与另一表中的连接属性匹配]
> Left join:
> loan.loan_number = borrower.loan_number(+)

## Example 2: Consider the student database below:

student ( student-no, student-name, sex, age, dept-name )

course ( course-no, course-name, credit )

study ( student-no, course-no, score )

Please give an expression in SQL for each of the following requirements:

- 1. Find the names of students who have studied course ‘Database System’ and sort results by ascending score.
- 2. Find the names of students who get the best score in course ‘Database System’.
- 3. Find the names of courses that have maximum average score.

```sql
(1) select student_name
from student S, study T, course C
where S.student_no=T.student_no and
T.course_no=C.course_no and
course_name='Database System'
order by score;
```

```sql
(2) select student_name
from student S, study T, course C
where S.student_no =T.student_no and
T.course_no=C.course_no   and
course_name='Database System' and
T.score >=
(select max(score) from study T, course C
where T.course_no=C.course_no and
course_name='Database System'
);
```

```sql
(3) select course_name
from course
where course_no in
(select course_no from study
group by course_no
having avg(score) >= all
(select avg(score) from study
group by course_no))
);
```

## (3) method2

```sql
with course_avg(course_no, score_avg) as
    select course_no, avg(score) from study
    group by course_no
select course_name from course
where course_no in
    (select course_no from course_avg
     where score_avg =
        (select max(score_avg) from course_avg)
    );
```
