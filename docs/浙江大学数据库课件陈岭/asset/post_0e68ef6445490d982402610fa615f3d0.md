

## User-Defined Exception

```plsql
DECLARE
    e_number1 EXCEPTION;
    cnt       NUMBER;
BEGIN
    SELECT COUNT(*)
      INTO cnt
      FROM number_table;

    IF cnt = 1 THEN
        RAISE e_number1;
    ELSE
        dbms_output.put_line(cnt);
    END IF;

EXCEPTION
    WHEN e_number1 THEN
        dbms_output.put_line('Count = 1');
END;
```

## Functions and Procedures

- Up until now, our code was in an anonymous block
- It was run immediately
- It is useful to put code in a function or procedure so it can be called several times
- Once we create a procedure or function in a Database, it will remain until deleted (like a table).

## Example- what does this do?

### Table mylog

| logon_num | who   |
|-----------|-------|
| 3         | Pete  |
| 4         | John  |
| 2         | Joe   |

```sql
create or replace procedure
num_logged
(person IN mylog.who%TYPE,
num OUT mylog.logon_num%TYPE)
IS
BEGIN
    select logon_num
    into num
    from mylog
    where who = person;
END;
/
```

## Calling the Procedure

```sql
declare
    howmany  mylog.logon_num%TYPE;
begin
    num_logged('John',howmany);
    dbms_output.put_line(howmany);
end;
/
```

## Errors in a Procedure

- When creating the procedure, if there are errors in its definition, they will not be shown
- To see the errors of a procedure called *myProcedure*, type
  ```sql
  SHOW ERRORS PROCEDURE myProcedure
  ```
  in the SQLPLUS prompt
- For functions, type
  ```sql
  SHOW ERRORS FUNCTION myFunction
  ```

## Creating a Function

Almost exactly like creating a procedure, but you supply a return type

```sql
CREATE [OR REPLACE] FUNCTION
function_name
[(parameter1 [mode1] datatype1,
   parameter2 [mode2] datatype2,
   ... )]
RETURN datatype
IS|AS
PL/SQL Block;
```

## Calling the function

## Creating a function:

```sql
create or replace function squareFunc(num in number)
return number
is
BEGIN
return num*num;
End;
/
```

## Using the function:

```sql
BEGIN
dbms_output.put_line(squareFunc(3.5));
END;
/
```

## 10.1 Introduction

- XML: Extensible Markup Language (可扩展标志语言)

- Defined by the WWW Consortium (W3C)

- Derived from SGML (Standard Generalized Markup Language), but simpler to use than SGML (通用标志语言标准)

- Documents have tags (标识) giving extra information about sections of the document

- E.g. <title> XML </title> , <slide> Introduction ...</slide>

- Extensible, unlike HTML

- HTML (Hypertext Markup Language， 超文本标记语言)

- HTML是一个定型的标记语言，它用固有的标记来描述要在网页上显示的内容。比如<H1>表示首行标题，有固定的尺寸。

- XML则没有固定的标记，XML不能直接描述网页具体的外观，内容，它只是描述内容的数据形式和结构。

- Users can add new tags, and separately specify how the tag should be handled for display

## XML Introduction (Cont.)

- The ability to specify new tags, and to create nested tag structures make XML a great way to exchange data, not just documents.
  
  - Much of the use of XML has been in data exchange applications, not as a replacement for HTML

- Tags make data (relatively) self-documenting (自描述的)
  
  - E.g: <bank>
    <account>
    <account_number> A-101 </account_number>
    <branch_name> Downtown </branch_name>
    <balance> 500 </balance>
    </account>
    <depositor>
    <account_number> A-101 </account_number>
    <customer_name> Johnson </customer_name>
    </depositor>
    </bank>
