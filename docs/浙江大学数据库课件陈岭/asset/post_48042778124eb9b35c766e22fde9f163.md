
## Additional Operations

- We define additional operations that do not add any power to the relational algebra, but that simplify common queries.
- Set intersection
- Natural join
- Division
- Assignment

## (8) Set-Intersection Operation

- **Notation:** $r \cap s$
- **Defined as:**
- $r \cap s = \{t \mid t \in r \text{ and } t \in s\}$
- **Assume:**
  - $r, s$ have the same arity
  - attributes of $r$ and $s$ are compatible
- **Note:** $r \cap s = r - (r - s)$

## (9) Natural-Join Operation

Notation: r ⋈ s

### Example:

R = (A, B, C, D); S = (E, B, D)

- Result schema of natural-join of r and s = (A, B, C, D, E);
- r ⋈ s = Π<sub>r.A, r.B, r.C, r.D, s.E</sub> (σ<sub>r.B = s.B ∧ r.D = s.D</sub> (r × s))

### Let r and s be relations on schemas R and S respectively.

Then, r ⋈ s is a relation on schema R ∪ S obtained as follows:

- Consider each pair of tuples t<sub>r</sub> from r and t<sub>s</sub> from s.
- If t<sub>r</sub> and t<sub>s</sub> have the same value on each of the attributes in R ∩ S, add a tuple t to the result, where
- t has the same value as t<sub>r</sub> on r
- t has the same value as t<sub>s</sub> on s

## (10) Division Operation

$r \div s$

### Let $r$ and $s$ be relations on schemas $R$ and $S$ respectively where

- $R = (A_1, \ldots, A_m, B_1, \ldots, B_n)$
- $S = (B_1, \ldots, B_n)$

The result of $r \div s$ is a relation on schema
$R-S = (A_1, \ldots, A_m)$

$r \div s = \{t \mid t \in \Pi_{R-S}(r) \land \forall u \in s\ (tu \in r)\}$

注：商来自于 $\Pi_{R-S}(r)$，并且其元组 $t$ 与 $s$ 所有元组的拼接被 $r$ 覆盖。
