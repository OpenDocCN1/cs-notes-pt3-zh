## Aggregate Functions - Having Clause

- **Example 4:** Find the names of all branches located in city Brooklyn where **the average account balance is more than $1,200.**

```sql
SELECT A.branch_name, avg(balance)
FROM account A, branch B
WHERE A.branch_name = B.branch_name
  and branch_city = 'Brooklyn'
GROUP BY A.branch_name
HAVING avg(balance) > 1200;
```

```text
branch(branch-name, branch-city, assets);
account(account-number, branch-name, balance);
```

**Note:** Attributes in **HAVING** clause outside of aggregate functions must appear in **GROUP BY** list.

## SUMMARY

1. The format of select statement:

   ```text
   SELECT <[DISTINCT] c1,c2,....> FROM <r1,....>
   [WHERE <condition>]
   [GROUP BY <c1,c2,.....> [HAVING <cond2>]]
   [ORDER BY <c1 [DESC] [, c2 [DESC|ASC], ...]>]
   ```

2. The execution order of SELECT:

   `From → where → group (aggregate) → having → select → order by`

   **Note:** Predicates in the HAVING clause are applied after the formation of groups, whereas predicates in the WHERE clause are applied before forming groups.

3. Aggregate functions cannot be used in the WHERE clause directly.

## 3.5 Null Values

- It is possible for tuples to have a null value, denoted by *null*, for some of their attributes.
- *null* signifies an **unknown value** or that a value **does not exist**.
- **The result of any arithmetic expression involving *null* is *null***.
  - E.g. `5 + null` returns null.
- Any comparison with *null* returns **unknown**.
  - E.g. `5 < null` or `null <> null` or `null = null`.
- The predicates `is null`, `is not null` can be used to check for null values.
  - E.g. Find all loan numbers which appear in the *loan* relation with null values for *amount*.

  ```sql
  select loan_number
  from loan
  where amount = null;
  ```

  ❌

  ```sql
  SELECT loan_number
  FROM loan
  WHERE amount IS NULL;
  ```

- `P is unknown` evaluates to true if predicate P evaluates to *unknown*.
- However, **aggregate functions simply ignore nulls**.

## Null Values and Aggregates

- **Total all loan amounts**

  ```sql
  select sum(amount)
  from loan;
  ```

  - The above statement ignores null amounts.
  - The result is null if there is no non-null amount, that is, **all values of *amount* in *loan* are null.**

- **All aggregate operations except `count(*)` ignore tuples with null values on the aggregated attributes.**

## Example 3: Find all customers who have both an account and a loan at the Perryridge branch.

**Query 1:**

```sql
select distinct customer_name
from borrower A, loan B
where A.loan_number = B.loan_number
  and branch_name = 'Perryridge'
  and (branch_name, customer_name) in
      (select branch_name, customer_name
       from depositor C, account D
       where C.account_number = D.account_number);
```

**Note:** The above query can be written in a much simpler manner. The formulation above is simply to illustrate SQL features.

## Query 3:

```sql
select distinct customer_name
from borrower B, loan as t
where B.loan_number = t.loan_number
  and branch_name = 'Perryridge'
  and customer_name in
      (select customer_name
       from depositor D, account A
       where D.account_number = A.account_number
         and branch_name = t.branch_name);
```
