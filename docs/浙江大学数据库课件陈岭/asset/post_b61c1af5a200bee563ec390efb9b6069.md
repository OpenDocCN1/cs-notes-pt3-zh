

## (3) The from Clause

- The from clause lists the relations involved in the query
  - corresponds to the Cartesian product operation of the relational algebra, if more than one relation is specified in the *from* clause.

- Find the Cartesian product:
  - *borrower* × *loan* -

```sql
SELECT * FROM borrower, loan;
```

## (3) The from Clause [cont.]

Example: Find the customer name, loan number and loan amount of all customers having a loan at the Perryridge branch.

Πcustomer_name,loan_number,amount (σbranch_name=‘Perryridge’ (borrower loan))

SELECT customer_name, borrower.loan_number, amount FROM borrower, loan WHERE borrower.loan_number = loan.loan_number and branch_name = ‘Perryridge’ ;

## (4) the Rename Operation

### (a) Column rename

- `as is` optional.

❖ In SQL Server, allow: *new-name = column expression*, E.g.:

```sql
SELECT customer_name,
       loan_id = borrower.loan_number, amount
FROM borrower, loan;
```

```sql
SELECT customer_name,
       borrower.loan_number as loan_id, amount
FROM borrower, loan
WHERE borrower.loan_number = loan.loan_number;
```

## (4) The Rename Operation [Cont.]

### (b) Relation rename - Tuple Variables

- Tuple variables are defined in the from clause via the use of the as clause.

- Example: Find the customer names, their loan numbers and amount for all customers of the bank.

```sql
SELECT customer_name, T.loan_number,
S.amount
FROM borrower as T, loan as S
WHERE T.loan_number = S.loan_number ;
```

## （5） String Operations

- SQL includes a **string-matching operator** for comparisons on character strings. Patterns are described using two special characters（通配符）:
  - `%` - matches any substring. (like `*` in file system)
  - `_` - matches any character. (like `?` in file system)

> 可实现模糊匹配
> （置于where中，且必须与LIKE连用）

## （5）String Operations [cont.]

- Exam: Find the names of all customers whose name includes the substring “泽” .

```sql
SELECT customer_name
FROM customer
WHERE customer_name LIKE ‘%泽%’ ;
```

- Match the name “Main%”(转义符)

LIKE ‘Main\%’ escape ‘\’

## （5）String Operations (cont.)

- SQL supports a variety of string operations such as
  - concatenation (串联) (using “||”)
    ```sql
    select ‘客户名=’ || customer_name from customer where ...;
    ```
  - converting from upper to lower case (and vice versa), using Function: `lower()`, `upper()`
  - finding string length, extracting substrings, etc. using Function

```sql
select ‘客户名=’ || customer_name from customer where ...;
```

## [6] Ordering the Display of Tuples

- Example: List in alphabetic order the names of all customers having a loan in Perryridge branch.

```sql
SELECT distinct *customer_name*
FROM    *borrower* A, *loan* B
WHERE A.loan_number = B.loan_number
      and *branch_name* = ‘Perryridge’
      **order by** *customer_name*;
```

## (6) Ordering the Display of Tuples (Cont.)

- We may specify **desc** for descending order or **asc** for ascending order, for each attribute; **ascending order is the default.**
  - E.g. order by _customer_name_ desc
  - E.g.
    ```sql
    SELECT * FROM customer
    ORDER BY customer_city,
    customer_street desc, customer_name;
    ```
