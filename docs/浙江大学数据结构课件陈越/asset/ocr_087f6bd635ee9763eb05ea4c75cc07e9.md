# 【分析】

**ASLs：** 查找表中关键词的平均查找比较次数（**其冲突次数加1**）

**ASL s=** (1+7+1+1+2+1+4+2+4) / 9 = **23/9 ≈ 2.56**

**ASLu：** 不在散列表中的关键词的平均查找次数（不成功）
一般方法：将不在散列表中的关键词分若干类。
如：根据H(key)值分类

**ASL u=** (3+2+1+2+1+1+1+9+8+7+6) / 11 = **41/11 ≈ 3.73**
