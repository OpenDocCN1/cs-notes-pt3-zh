# # Prim算法 — 让一棵小树长大

```
void Dijkstra( Vertex s )
{
    while (1) {
    V = 未收录顶点中dist最小者;
    if ( 这样的V不存在 )
    break;
    collected[V] = true;
    for ( V 的每个邻接点 W )
    if ( collected[W] == false )
    if ( dist[V]+E<v, w> < dist[W] ){
    dist[W] = dist[V] + E<v, w> ;
    path[W] = V;
    }
    }
}
```

```
void Prim()
{ MST = {s};
    while (1) {
    V = 未收录顶点中dist最小者;
    if ( 这样的V不存在 )
    break;
    将v收录进MST: dist[V] = 0;
    for ( V 的每个邻接点 W )
    if ( dist[W]!= 0 )
    if ( E<v, w> < dist[W] ){
    dist[W] = E<v, w> ;
    parent[W] = V;
    }
    }
    if ( MST中收的顶点不到|V|个 )
    Error ( “生成树不存在” );
}
```

dist[V] = E<sub>(s,v)</sub>或 正无穷

parent[s] = -1

T = O(|V|<sup>2</sup>)

稠密图合算
