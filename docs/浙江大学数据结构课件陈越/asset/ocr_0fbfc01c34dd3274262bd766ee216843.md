# # 图不连通怎么办？

```
void DFS ( Vertex V )
{
    visited[ V ] = true;
    for ( V 的每个邻接点 W )
        if ( !visited[ W ] )
            DFS( W );
}
```

```
void ListComponents ( Graph G )
{
    for ( each V in G )
        if ( !visited[V] ) {
            DFS( V ); /*or BFS( V )*/
        }
}
```

每调用一次DFS(V)，就把V所在的连通分量遍历了一遍。BFS也是一样。
