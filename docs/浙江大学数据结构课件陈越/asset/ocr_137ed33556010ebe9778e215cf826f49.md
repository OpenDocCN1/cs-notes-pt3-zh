# # 开放定址法（Open Addressing）

若发生了第 i 次冲突，试探的下一个地址将增加d<sub>i</sub>，基本公式是：
h<sub>i</sub>(key) = (h(key)+d<sub>i</sub>) mod TableSize （1≤i < TableSize ）

d<sub>i</sub> 决定了不同的解决冲突方案：线性探测、平方探测、双散列。

+   d<sub>i</sub> = i

+   d<sub>i</sub> = ± i<sup>2</sup>

+   d<sub>i</sub> = i<sup>∗</sup>h<sub>2</sub>(key)
