# # 算法思路

+   - 对每个节点，进行广度优先搜索
+   - 搜索过程中累计访问的节点数
+   - 需要记录“层”数，仅计算6层以内的节点数

```
void SDS()
{
    for ( each V in G ) {
        count = BFS( V );
        Output( count/N );
    }
}
```

```
int BFS ( Vertex V )
{
    visited[V] = true; count = 1;
    Enqueue( V, Q );
    while( !IsEmpty( Q ) ){
    V = Dequeue( Q );
    for ( V 的每个邻接点 W )
    if ( !visited[W] ) {
    visited[W] = true;
    Enqueue( W, Q ); count ++;
    }
    } return count;
}
```
