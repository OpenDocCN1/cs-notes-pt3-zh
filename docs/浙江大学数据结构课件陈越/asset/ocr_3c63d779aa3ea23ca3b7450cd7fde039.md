# ## 分而治之

什么是快速排序算法的最好情况？
每次正好中分 ➡️ T(N) = O( NlogN )

```
void Quicksort( ElementType A[], int N )
{
    ?pivot = 从A[]中选一个主元;
    ?将S = { A[] \ pivot } 分成2个独立子集:
        A1={ a∈S | a ≤ pivot } 和
        A2={ a∈S | a ≥ pivot };
    A[] = Quicksort(A1,N1)∪
        {pivot}∪
        Quicksort(A2,N2);
}
```
