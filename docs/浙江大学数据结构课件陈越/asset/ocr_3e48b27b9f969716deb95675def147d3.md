# ## 需要设计的主要函数：

+   - 读数据建搜索树T
+   - 判别一序列是否与T构成一样的搜索树

```
```c
int main()
{
    int N, L, i;
    Tree T;

    scanf("%d", &N);
    while (N) {
        scanf("%d", &L);
        T = MakeTree(N);
        for (i=0; i<L; i++) {
            if (Judge(T, N))printf("Yes\n");
            else printf("No\n");
            Reset(T); /*清除T中的标记flag*/
        }
        FreeTree(T);
        scanf("%d", &N);
    }

    return 0;
}
