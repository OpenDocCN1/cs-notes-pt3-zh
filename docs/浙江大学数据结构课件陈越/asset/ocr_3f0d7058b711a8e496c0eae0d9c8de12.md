# # 选择排序

```
void Selection_Sort ( ElementType A[], int N )
{
    for ( i = 0; i < N; i ++ ) {
        MinPosition = ScanForMin( A, i, N-1 );
        /* 从A[i]到A[N-1]中找最小元，并将其位置赋给MinPosition */
        Swap( A[i], A[MinPosition] );
        /* 将未排序部分的最小元换到有序部分的最后后位置 */
    }
}

```
