# # Kruskal算法 — 将森林合并成树

```
void Kruskal ( Graph G )
{
    MST = { } ;
    while ( MST 中不到 |V| -1 条边 && E 中还有边 ) {
    从 E 中取一条权重最小的边 E<sub>(v,w)</sub> ; /* 最小堆 */
    将 E<sub>(v,w)</sub> 从 E 中删除;
    if ( E<sub>(v,w)</sub>不在 MST 中构成回路) /* 并查集 */
    将 E<sub>(v,w)</sub> 加入 MST;
    else

    }

}
```

T = O(|E| log |E|)
