# # 无权图的单源最短路算法

```
void BFS ( Vertex S )
{
    visited[S] = true;
    Enqueue(S, Q);
    while(!IsEmpty(Q)){
    V = Dequeue(Q);
    for ( V 的每个邻接点 W )
    if ( !visited[W] ) {
    visited[W] = true;
    Enqueue(W, Q);
    }
    }
}
```

```
void Unweighted ( Vertex S )
{
    Enqueue(S, Q);
    while(!IsEmpty(Q)){
    V = Dequeue(Q);
    for ( V 的每个邻接点 W )
    if ( dist[W]==-1 ) {
    dist[W] = dist[V]+1;
    path[W] = V;
    Enqueue (W, Q) ;
    }
    }
}
T = O( |V| + |E| )
```

dist[W] = S到w的最短距离

dist[S] = 0

path[W] = S到W的路上经过的某顶点
