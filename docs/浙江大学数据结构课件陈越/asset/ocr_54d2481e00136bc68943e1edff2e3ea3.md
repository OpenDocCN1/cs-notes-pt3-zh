# 例3：写程序计算给定多项式在给定点x处的值

$f(x)=a_0+a_1x+\cdots+a_{n-1}x^{n-1}+a_nx^n$

```
double f( int n, double a[], double x )
{
  int i;
  double p = a[0];
  for ( i=1; i<=n; i++ )
    p += (a[i] * pow(x, i));
  return p;
}
```

$f(x)=a_0+x(a_1+x(\cdots(a_{n-1}+x(a_n))\cdots))$

```
double f( int n, double a[], double x )
{
  int i;
  double p = a[n];
  for ( i=n; i>0; i-- )
    p = a[i-1] + x*p;
  return p;
}
```
