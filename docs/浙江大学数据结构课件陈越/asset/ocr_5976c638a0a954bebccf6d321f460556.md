# # 1. 线性探测法的查找性能

可以证明，线性探测法的期望探测次数 满足下列公式：

\( p = \left\{ \begin{array}{ll} \frac{1}{2}\left[1+\frac{1}{(1-\alpha)^2}\right] & \text{（对插入和不成功查找而言）} \\ \frac{1}{2}\left(1+\frac{1}{1-\alpha}\right) & \text{（对成功查找而言）} \end{array} \right. \)

当α= 0.5时，

+   - 插入操作和不成功查找的期望 ASLu = 0.5*(1+1/(1-0.5)² ) = 2.5 次

+   - 成功查找的期望 ASLs = 0.5*(1+1/(1-0.5) ) = 1.5次
