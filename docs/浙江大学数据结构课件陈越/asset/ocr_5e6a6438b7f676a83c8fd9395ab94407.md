# 2. 查找

# （1）按序号查找: FindKth;

```
List FindKth( int K, List PtrL )
{
    List p = PtrL;
    int i = 1;
    while (p !=NULL && i < K){
        p = p->Next;
        i++;
    }
    if (i == K) return p;
    else return NULL;
}
```

# （2）按值查找: Find

```
List Find( ElementType X, List PtrL )
{
    List p = PtrL;
    while (p!=NULL && p->Data != X)
        p = p->Next;
    return p;
}
```

> 平均时间性能为 O(n)
