# # 按秩归并 最坏情况下的树高 = O(log N)

# ## 另一种做法：比规模

# ### 把小树贴到大树上 S[Root] = -元素个数；

```
void Union( SetType S, SetName Root1, SetName Root2 )
{
    if ( S[Root2]<S[Root1] ){
        S[Root2] += S[Root1];
        S[Root1] = Root2;
    }
    else {
        S[Root1] += S[Root2];
        S[Root2] = Root1;
    }
}
```

两种方法统称“按秩归并”
