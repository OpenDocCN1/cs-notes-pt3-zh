# ◆ 二叉树用于编码

用二叉树进行编码：
（1）左右分支：0、1
（2）字符只在叶结点上

四个字符的频率：a:4，u:1，x:2，z:1

![](bbox=[0.103, 0.421, 0.355, 0.658])

**Cost**（*aaxuaxz* → `0000001001001011`）
= 2×4 + 2×1 + 2×2 + 2×1 = 16

![](bbox=[0.574, 0.122, 0.828, 0.441])

**Cost**（*aaaxuaxz* → `00010110010111`）
= 1×4 + 3×1 + 2×2 + 3×1 = 14
