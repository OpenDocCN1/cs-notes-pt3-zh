# # 堆排序

# ## 算法2

```
void Heap_Sort ( ElementType A[], int N )
{
    for ( i=N/2-1; i>=0; i-- )/* BuildHeap */
    PercDown( A, i, N );
    for ( i=N-1; i>0; i-- ) {
    Swap( &A[0], &A[i] ); /* DeleteMax */
    PercDown( A, 0, i );
    }
}
```

+   - 定理：堆排序处理N个不同元素的随机排列的平均比较次数是  
+     2N logN – O(Nlog logN)。

+   - 虽然堆排序给出最佳平均时间复杂度，但实际效果不如用Sedgewick增量序列的希尔排序。
