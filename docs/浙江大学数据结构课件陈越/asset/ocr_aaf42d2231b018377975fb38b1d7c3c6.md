# 希尔增量序列

▪ 原始希尔排序　$D_M=\lfloor N/2\rfloor,\quad D_k=\lfloor D_{k+1}/2\rfloor$

```
```c
void Shell_sort( ElementType A[], int N )
{
  for ( D=N/2; D>0; D/=2 ) { /* 希尔增量序列 */
    for ( P=D; P<N; P++ ) { /* 插入排序 */
      Tmp = A[P];
      for ( i=P; i>=D && A[i-D]>Tmp; i-=D )
        A[i] = A[i-D];
      A[i] = Tmp;
    }
  }
}
```
```

最坏情况：$T=O(N^2)$
