# # 基数排序

假设我们有 \( N = 10 \) 个整数，每个整数的值在0到999之间（于是有 \( M = 1000 \) 个不同的值）。还有可能在线性时间内排序吗？

输入序列：64, 8, 216, 512, 27, 729, 0, 1, 343, 125  
用“次位优先”（Least Significant Digit）  
\( T = O(P(N+B)) \)
