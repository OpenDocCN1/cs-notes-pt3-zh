# ## 3. 插入操作实现

```
List Insert( ElementType X, int i, List PtrL )
{
    List p, s;
    if ( i == 1 ) {
        s = (List)malloc(sizeof(struct LNode));
        s->Data = X;
        s->Next = PtrL;
        return s;
    }
    p = FindKth( i-1, PtrL );
    if ( p == NULL ) {
        printf( " 参数i错 " );
        return NULL;
    }
    else {
        s = (List)malloc(sizeof(struct LNode));
        s->Data = X;
        s->Next = p->Next;
        p->Next = s;
        return PtrL;
    }
}
```
