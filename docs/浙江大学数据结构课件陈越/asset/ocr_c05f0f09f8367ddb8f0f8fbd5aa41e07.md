# 一个“好”的散列函数一般应考虑下列两个因素：

+   1. 计算简单，以便提高转换速度；
+   2. 关键词对应的地址空间分布均匀，以尽量减少冲突。

# 数字关键词的散列函数构造

+   1. 直接定址法

取关键词的某个线性函数值为散列地址，即  
h(key) = a × key + b   （a、b为常数）

| 地址h(key) | 出生年份(key) | 人数(attribute) |

| 0          | 1990          | 1285万          |
| 1          | 1991          | 1281万          |
| 2          | 1992          | 1280万          |
| ...        | ......        | ......          |
| 10         | 2000          | 1250万          |
| ...        | ......        | ......          |
| 21         | 2011          | 1180万          |

> h(key)=key-1990
