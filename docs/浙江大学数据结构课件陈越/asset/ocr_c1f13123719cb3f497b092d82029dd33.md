# # 队列的链式存储实现

队列的链式存储结构也可以用一个单链表实现。插入和删除操作分别在链表的两头进行； 队列指针front和rear应该分别指向链表的哪一头？

```
struct Node{
    ElementType Data;
    struct Node *Next;
};
struct QNode{    /* 链队列结构 */
    struct Node *rear;   /* 指向队尾结点 */
    struct Node *front;  /* 指向队头结点 */
};
typedef struct QNode *Queue;
Queue PtrQ;
```
