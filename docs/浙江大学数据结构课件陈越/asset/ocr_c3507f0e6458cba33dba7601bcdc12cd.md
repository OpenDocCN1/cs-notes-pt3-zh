# ## 分离链接法（Separate Chaining）

分离链接法：将相应位置上冲突的所有关键词存储在同一个单链表中

【例】设关键字序列为 47, 7, 29, 11, 16, 92, 22, 8, 3, 50, 37, 89, 94, 21；
散列函数取为：h(key) = key mod 11；
用分离链接法处理冲突。

```
struct HashTbl {
int TableSize;
List TheLists;
} *H;
```

+   - 表中有9个结点只需1次查找，
+   - 5个结点需要2次查找，
+   - 查找成功的平均查找次数：
+     ASL s=（9+5*2）/ 14 ≈ 1.36
