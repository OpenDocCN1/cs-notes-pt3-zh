# 采用数组存储形式

| 下标 | Data | Parent |
|---:|---:|---:|
| 0 | 1 | -1 |
| 1 | 2 | 0 |
| 2 | 3 | -1 |
| 3 | 4 | 0 |
| 4 | 5 | 2 |
| 5 | 6 | -1 |
| 6 | 7 | 0 |
| 7 | 8 | 2 |
| 8 | 9 | 5 |
| 9 | 10 | 5 |

数组中每个元素的类型描述为：

```
typedef struct {
    ElementType Data;
    int Parent;
} SetType;
```

![](bbox=[0.472, 0.465, 0.952, 0.671])

> 负数表示根结点；
> 非负数表示双亲结点的下标。
