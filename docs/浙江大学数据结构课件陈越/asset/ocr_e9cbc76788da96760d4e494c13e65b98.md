# # 字符关键词的散列函数构造

# ## 1. 一个简单的散列函数——ASCII码加和法

对字符型关键词key定义散列函数如下：
h(key) = (Σkey[i]) mod TableSize

# ## 2. 简单的改进——前3个字符移位法

h(key)=(key[0]×27² + key[1]×27 + key[2])mod TableSize

# ## 3. 好的散列函数——移位法

涉及关键词所有n个字符，并且分布得很好：
h (key) = (Σⁿ⁻¹₍ᵢ₌₀₎ key[n-i-1]×32ⁱ) mod TableSize

> 冲突严重：a3、b2、c1；eat、tea；

> 仍然冲突：string、street、strong、structure等等；空间浪费：3000/26³ ≈ 30%
