# （3）**后序遍历**

**遍历过程为：**

+   ① 后序遍历其左子树；
+   ② 后序遍历其右子树；
+   ③ 访问根结点。

**（DFB）（HGIC）A**

**后序**遍历=>　D E F B H G I C A

```
void PostOrderTraversal( BinTree BT )
{
    if( BT ) {
        PostOrderTraversal( BT->Left );
        PostOrderTraversal( BT->Right );
        printf("%d", BT->Data);
    }
}
```
