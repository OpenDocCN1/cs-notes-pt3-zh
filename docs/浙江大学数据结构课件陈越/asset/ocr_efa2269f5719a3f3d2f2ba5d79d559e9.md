# # 桶排序

假设我们有 \( N \) 个学生，他们的成绩是0到100之间的整数（于是有 \( M = 101 \) 个不同的成绩值）。如何在线性时间内将学生按成绩排序？

![](bbox=[0.137, 0.412, 0.447, 0.763])

```

    输出整个count[i]链表;

```

\( T(N, M) = O(M+N) \)
