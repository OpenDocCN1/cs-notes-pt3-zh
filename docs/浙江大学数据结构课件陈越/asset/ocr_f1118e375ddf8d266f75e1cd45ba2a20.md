# # 单链表的逆转

取巧：用顺序表存储，先排序，再直接逆序输出。

在“内存”里多加几个没用的结点，让你偷懒！

```
```c
Ptr Reverse( Ptr head, int K )
{
    cnt = 1;
    new = head->next;
    old = new->next;
    while ( cnt < K )
    {
        tmp = old->next;
        old->next = new;
        new = old; old = tmp;
        cnt++;
    }
    head->next->next = old;
    return new;
}
```
