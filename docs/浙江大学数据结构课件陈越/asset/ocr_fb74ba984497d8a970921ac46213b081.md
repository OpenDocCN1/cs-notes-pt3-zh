# 静态查找

# 方法1：顺序查找

![](bbox=[0.542, 0.075, 0.948, 0.619])

```
```c
int SequentialSearch (StaticTable *Tbl,
                     ElementType K)
{ /*在表Tbl[1]~Tbl[n]中查找关键字为K的数据元素*/
    int i;
    Tbl->Element[0] = K;   /*建立哨兵*/
    for(i = Tbl->Length; Tbl->Element[i] != K; i--);
    return i; /*查找成功返回所在单元下标，不成功返回0*/
}
```
```

顺序查找算法的时间复杂度为 **O(n)**。
