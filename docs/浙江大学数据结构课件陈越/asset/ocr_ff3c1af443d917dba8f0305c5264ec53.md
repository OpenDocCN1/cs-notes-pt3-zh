# 聪明的算法

+   随时将入度变为0的顶点放到一个容器里

```
void TopSort()
{
    for ( 图中每个顶点 V )
        if ( Indegree[V]==0 )
            Enqueue( V, Q );
    while ( !IsEmpty(Q) ) {
        V = Dequeue( Q );
        输出V，或者记录V的输出序号； cnt++;
        for ( V 的每个邻接点 W )
            if ( --Indegree[W]==0 )
                Enqueue( W, Q );
    }
    if ( cnt != |V| )
        Error(“图中有回路” );
}
```

T = O(|V| + |E|)

此算法可以用来检测有向图是否 DAG
