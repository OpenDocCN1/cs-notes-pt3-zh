# # 按秩归并

+   - 为什么树会越来越高？
+   - 应该把矮树贴到高树上！
+   - 树的高度存哪里？

S[Root] = -树高；

```
if ( Root2高度 > Root1高度 )
S[Root1] = Root2;
else {
if ( 两者等高 ) 树++;
S[Root2] = Root1;
}
```

```
if ( S[Root2] < S[Root1] )
S[Root1] = Root2;
else {
if ( S[Root1]==S[Root2] ) S[Root1]--;
S[Root2] = Root1;
}
```
