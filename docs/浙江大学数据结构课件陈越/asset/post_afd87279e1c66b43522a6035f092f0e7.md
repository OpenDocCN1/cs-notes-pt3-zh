```c
int WPL( HuffmanTree T, int Depth )
{
    if ( !T->Left && !T->Right )
        return (Depth*T->Weight);
    else /* 否则T一定有2个孩子 */
        return ( WPL(T->Left, Depth+1)
            + WPL(T->Right, Depth+1));
}
```

## 最短路径问题的抽象

- 在网络中，求两个不同顶点之间的所有路径中，边的权值之和最小的那一条路径
  - 这条路径就是两点之间的**最短路径**（Shortest Path）
  - 第一个顶点为**源点**（Source）
  - 最后一个顶点为**终点**（Destination）

## 无权图的单源最短路算法

```c
void BFS ( Vertex S )
{
    visited[S] = true;
    Enqueue(S, Q);
    while(!IsEmpty(Q)){
    V = Dequeue(Q);
    for ( V 的每个邻接点 W )
    if ( !visited[W] ) {
    visited[W] = true;
    Enqueue(W, Q);
    }
    }
}
```

```c
void Unweighted ( Vertex S )
{
    Enqueue(S, Q);
    while(!IsEmpty(Q)){
    V = Dequeue(Q);
    for ( V 的每个邻接点 W )
    if ( dist[W]==-1 ) {
    dist[W] = dist[V]+1;
    path[W] = V;
    Enqueue (W, Q) ;
    }
    }
}
T = O( |V| + |E| )
```

dist[W] = S到w的最短距离

dist[S] = 0

path[W] = S到W的路上经过的某顶点

## 有权图的单源最短路算法

### Dijkstra 算法

- 令S={源点s + 已经确定了最短路径的顶点v<sub>i</sub>}
- 对任一未收录的顶点v，定义dist[v]为s到v的最短路径长度，但该路径仅经过s中的顶点。即路径{s→(v<sub>i</sub>∈S)→v}的最小长度
- 若路径是按照递增（非递减）的顺序生成的，则
- 真正的最短路必须只经过s中的顶点（为什么？）
- 每次从未收录的顶点中选一个dist最小的收录（贪心）
- 增加一个v进入S，可能影响另外一个w的dist值！
- dist[w] = min{dist[w]，dist[v] + <v,w>的权重}

## 有权图的单源最短路算法

```c
void Dijkstra( Vertex s )
{
    while (1) {
    V = 未收录顶点中dist最小者;
    if ( 这样的V不存在 )
    break;
    collected[V] = true;
    for ( V 的每个邻接点 W )
    if ( collected[W] == false )
    if ( dist[V]+E<V,W> < dist[W] ) {
    dist[W] = dist[V] + E<V,W> ;
    path[W] = V;
    }
    }
}
/* 不能解决有负边的情况 */
```

## 有权图的单源最短路算法

- 方法1：直接扫描所有未收录顶点 - \( O(|V|) \)
  - \( T = O(|V|^2 + |E|) \) —— 对于稠密图效果好

- 方法2：将dist存在最小堆中 - \( O(\log|V|) \)
  - 更新dist[w]的值 - \( O(\log|V|) \)
  - \( T = O(|V|\log|V| + |E|\log|V|) = O(|E|\log|V|) \) —— 对于稀疏图效果好

## 多源最短路算法

### Floyd 算法

- \(D^k[i][j]\) = 路径\({i \to \{l \le k\} \to j}\)的最小长度
- \(D^0, D^1, \ldots, D^{|V|-1}[i][j]\)即给出了i到j的真正最短距离
- 最初的\(D^{-1}\)是什么？
- 当\(D^{k-1}\)已经完成，递推到\(D^k\)时：
  - 或者\(k \notin\)最短路径\({i \to \{l \le k\} \to j}\)，则\(D^k=D^{k-1}\)
  - 或者\(k \in\)最短路径\({i \to \{l \le k\} \to j}\)，则该路径必定由两段最短路径组成：\(D^k[i][j]=D^{k-1}[i][k]+D^{k-1}[k][j]\)

## 多源最短路算法

```c
void Floyd()
{
    for ( i = 0; i < N; i++ )
        for( j = 0; j < N; j++ ) {
            D[i][j] = G[i][j];
            path[i][j] = -1;
        }
    for( k = 0; k < N; k++ )
        for( i = 0; i < N; i++ )
            for( j = 0; j < N; j++ )
                if( D[i][k] + D[k][j] < D[i][j] ) {
                    D[i][j] = D[i][k] + D[k][j];
                    path[i][j] = k;
                }
}
```

$T = O(|V|^3)$
