# Example 2

What is the chromatic number of K<sub>n</sub>?

Solution:A coloring of K<sub>n</sub> can be constructed using n colors
by assigning a different color to each vertex.Is there a
coloring using fewer colors ?The answer is no.No two vertices
can be assigned the same color ,since every two vertices of
this graph are adjacent.Hence,the chromatic number of K<sub>n</sub>
=n.(Recall that K<sub>n</sub> is not planar when n≥5,so this result does
not contradict the four color theorem.)A coloring of K<sub>5</sub> using
