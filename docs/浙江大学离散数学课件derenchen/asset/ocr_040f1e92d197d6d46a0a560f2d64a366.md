# # 9.1.3 代数系统的零元、单位元和逆元

我们知道在数的乘法中，数“0”和“1”起着一种很特殊的作用，将之推广便可得代数系统中的零元和单位元。

定义9.7 设“○”是非空集合A上的二元运算，如果A中存在某一元素e，对任意的a∈A，有：e○a=a（或a○e=a），则称：e为代数(A；○)的左单位元(或右单位元)。

一个代数的左、右单位元一般可分别记为e<sub>l</sub>、e<sub>r</sub>。

例9.13 在实数集R中分别定义二元运算“□”：

(1) 对任意a、b∈R，a□b=a+bi(其中i<sup>2</sup>=1)。则：数0为二元运算“□”的右单位元，但它不是左单位元。

(2) 对任意a、b∈R，a□b=b。则：任何一个实数a都是二元运算“□”的左单位元，但该二元运算没有右单位元
