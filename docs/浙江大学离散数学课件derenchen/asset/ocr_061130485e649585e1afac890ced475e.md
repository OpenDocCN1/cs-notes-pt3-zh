# 例9.11

（1）整数集ℤ上的加法、乘法运算都满足结合律与交换律；而减法运算既不满足结合律，也不满足交换律。乘法对加法、减法都有左、右分配律。而加法、减法对乘法不满足分配律。

（2）设 Mₙ(ℝ) 为实数集ℝ上的 n 阶方阵，则矩阵的加法运算满足结合律与交换律；矩阵的乘法运算满足结合律，但不满足交换律。矩阵的乘法对加法有左、右分配律。

# 例9.12

非空集合S的幂集P(S)上的“∪”、“∩”、“\”运算满足结合律和交换律；而差运算既不满足结合律，也不满足交换律。

如果参与运算的每个元素都相同，则可定义该元素的幂。即：

$$aa\ldots a=a^n\ (n\text{为正整数})。$$
