# 例7.1 证明A×(B∪C)=(A×B)∪(A×C)。

证：任取 <x,y>，

<x,y>∈A×(B∪C) ⇔ xeA ∧ ye(B∪C)

⇔ xeA ∧ (yeB ∨ yeC)

⇔ (xeA ∧ yeB)∨(xeA ∧ yeC)

⇔ (<x,y> ∈ A×B)∨(<x,y> ∈ A×C)

⇔ <x,y> ∈ (A×B) ∪(A×C)

∴ A×(B∪C) = (A×B) ∪(A×C)
