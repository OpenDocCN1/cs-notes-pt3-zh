# # Boolean Algebra

例9.19 (1) 代数系统(R; +)中的任意一个元素a都有逆元，其逆元为a的相反数-a。即：a⁻¹=-a。因为a+(-a)=(-a)+a=0。

(2) 代数系统(R; ×)中，任意一个非零元素a，都有逆元，其逆元为a的倒数1/a。即：a⁻¹=1/a。因为a×(1/a)=(1/a)×a=1。而对于该系统的零元0，没有逆元。

例9.20 设R*是非零实数集，在R*中定义运算“○”：

对任意的a、b∈R*，a○b=ab/2。

试问：○是不是二元运算？它满足哪些性质？R*中的元素有没有逆元，逆元是什么？

解：(1) 对任意的(a, b)∈R*×R*，R*中存在唯一的非零实数与之对应，因此，“○”是R*上的二元运算。

(2) 二元运算“○”显然满足交换律。而对任意a、b、c∈R*，有：

(a○b)○c=(ab/2)○c=(abc)/4。

a○(b○c)=a○(bc/2)=(abc)/4。
