# 定理7.2 设F,G,H是关系，则

(1) (F∘G)∘H=F∘(G∘H);　(2) (F∘G)⁻¹=G⁻¹∘F⁻¹

证：(1) ∵ ⟨x,y⟩∈((F∘G)∘H) ⇔ ∃t(⟨x,t⟩∈(F∘G) ∧ ⟨t,y⟩∈H)
⇔ ∃t(∃s(⟨x,s⟩∈F ∧ ⟨s,t⟩∈G) ∧ ⟨t,y⟩∈H)
⇔ ∃t∃s(⟨x,s⟩∈F ∧ ⟨s,t⟩∈G) ∧ ⟨t,y⟩∈H)
⇔ ∃s(⟨x,s⟩∈F ∧ ∃t(⟨s,t⟩∈G ∧ ⟨t,y⟩∈H))
⇔ ∃s(⟨x,s⟩∈F ∧ ⟨s,y⟩∈(G∘H))
⇔ ⟨x,y⟩∈F∘(G∘H)
∴ (F∘G)∘H=F∘(G∘H)

(2) ∵ ⟨x,y⟩∈(F∘G)⁻¹ ⇔ ⟨y,x⟩∈F∘G
⇔ ∃t(⟨y,t⟩∈F ∧ ⟨t,x⟩∈G)
⇔ ∃t(⟨x,t⟩∈G⁻¹ ∧ ⟨t,y⟩∈F⁻¹)
⇔ ⟨x,y⟩∈(G⁻¹∘F⁻¹)
∴ (F∘G)⁻¹=G⁻¹∘F⁻¹
