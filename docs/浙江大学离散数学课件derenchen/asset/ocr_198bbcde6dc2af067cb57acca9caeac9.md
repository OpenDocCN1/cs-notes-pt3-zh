# # Relations关系

例1：A = { 1, 2, 3, 4 }，I 为整数集

R = { (a, b) | a, b ∈ A, \frac{a-b}{2} ∈ I } □

S = { (a, b) | a, b ∈ A, \frac{a-b}{3} ∈ I, a-b > 0 }

求：R ∪ S, R ∩ S, R̄, R - S, S - R, S ⊕ R ■

解：R 与 S 都是 A 上的二元关系

R = { (1, 1), (2, 2), (3, 3), (4, 4), (1, 3), (3, 1), (2, 4), (4, 2) }

S = { (4, 1) }

R ∪ S = { (1, 1), (2, 2), (3, 3), (4, 4), (1, 3), (3, 1), (2, 4), (4, 2), (4, 1) }
