# # Example 3

What is the chromatic number of the complete bipartite
graph K<sub>m,n</sub>, where m and n are positive integers?

_Solution:_The number of colors needed may seem to depend
on m and n .However,only two colors are needed.Color the
set of m vertices with one color and the set of n vertices with
a second color.Since edges connect only a vertex from the set
of m vertices and a vertex from the set of n vertices,no two
adjacent vertices have the same color.A coloring of K<sub>3,4</sub> with
