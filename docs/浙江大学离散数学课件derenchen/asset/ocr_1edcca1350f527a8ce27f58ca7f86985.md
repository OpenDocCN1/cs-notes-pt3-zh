# # 定理4（欧几里德定理）

所有质数组成的集合是一个无限集。

证明：若质数是有限的，则可将它们按顺序一个不漏地记为

p<sub>1</sub><p<sub>2</sub><...<p<sub>k</sub>，令n= p<sub>1</sub>·p<sub>2</sub>·...· p<sub>k</sub>+1，则n或者是个质数，如果n不是质数，则由算术基本定理，则它可以表示成质数的积，它的质因子不可能是p<sub>1</sub>， p<sub>2</sub>， ...， p<sub>k</sub>之一，这与p<sub>1</sub>， p<sub>2</sub>， ...， p<sub>k</sub>是所有的质数矛盾。
