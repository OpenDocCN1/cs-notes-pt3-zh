# 例4.4 将下列命题符号化，并讨论其真值。

+   (1) 所有的人都长着黑头发；

+   (2) 有的人登上过月球；

+   (3) 没有人登上过木星；

+   (4) 在美国留学的学生未必都是亚洲人。

解： 令 M(x): x 为人。

+   (1) 令F(x): x长着黑头发。则 ∀x (M(x)→ F(x))。命题为假。

+   (2) 令G(x): x登上过月球。则 ∃x (M(x)∧G(x))。命题为真。

+   (3) 令H(x): x登上过木星。则 ¬∃x (M(x)∧H(x))。命题为真。

+   (4) 令N(x): x是在美国留学的学生； K(x): x是亚洲人。则 ¬∀x (N(x)→ K(x))。命题为真。
