# 三. 等价类的性质

定理7.14 设 R 为非空集合 A 上的等价关系，则

+   (1) ∀x∈A, [x]是A的非空子集。
+   (2) ∀x, y∈A，如果xRy，则[x]=[y]
+   (3) ∀x, y∈A，如果x与y不具有关系 R，则[x]与[y]不相交。
+   (4) ⋃{[x]|x∈A}=A

证: (1) 显然。

(2) ∵ z∈[x] ⇒ <x, z>∈R
⇒ <z, x>∈R（R是对称的）
∴ <z, x>∈R ∧ <x, y>∈R
⇒ <z, y>∈R
⇒ <y, z>∈R
∴ z∈[y]，从而 [x]⊆[y]
同理可得，[y]⊆[x]。故 [x]=[y]
