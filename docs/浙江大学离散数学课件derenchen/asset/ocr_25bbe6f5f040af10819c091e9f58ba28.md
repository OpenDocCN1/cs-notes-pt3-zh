# 3）传递性：■

若（a，b），（b，c）∈ R，

则（a，c）∈ R，称 R 为传递的二元关系。

即： \( (\overline{r_{ij} \wedge r_{jk}}) \vee r_{ik} = 1 \) ■

注：r<sub>ij</sub>，r<sub>jk</sub>中有一个不是 1，

则 \( \overline{(r_{ij} \wedge r_{jk})} = 1 \)，r<sub>ik</sub>就可以任意。

即若(a，b),(c，d)中有1个不属于R，

则讨论（a,c)是否属于R，无意义。

即没有传递的条件，也不需传递的结果。如：

A = {a,b,c,d} ， R = { （a，b），（c，d） }
