# 例5.8　求下列各公式的前束范式

+   (1) ∀x F(x,y)→∃y G(x,y)
+   
+   (2) (∀x₁ F(x₁,x₂)→∃x₂ G(x₂))→∀x₁ H(x₁,x₂,x₃)

解：(1) ∀x F(x,y)→∃y G(x,y)

⇔ ∀t F(t,y)→∃w G(x,w)　　换名规则

⇔ ∃t (F(t,y)→∃w G(x,w))　　量词辖域扩张等值式

⇔ ∃t∃w (F(t,y)→G(x,w))　　量词辖域扩张等值式

或：　∀x F(x,y)→∃y G(x,y)

⇔ ∀x F(x,t)→∃y G(w,y)　　代替规则

⇔ ∃x (F(x,t)→∃y G(w,y))　　量词辖域扩张等值式

⇔ ∃x∃y (F(x,t)→G(w,y))　　量词辖域扩张等值式
