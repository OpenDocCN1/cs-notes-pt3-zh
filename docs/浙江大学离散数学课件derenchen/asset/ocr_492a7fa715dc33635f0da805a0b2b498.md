# # Example 5

There are certain things whose number is unknown. When
divided by 3,the remainder is 2;when divided by 5,the remainder is
3;and when divided by 7,the remainder is 2.what will be the
number of things?

This puzzle can be translated into the following question:What
are the solutions of the systems of congruences

x≡2(mod 3),
x≡3(mod 5),
x≡2(mod 7)?

We will solve this system, and with it Sun-Tsu’ puzzle,later in this
section.
