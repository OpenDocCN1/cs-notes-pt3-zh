# 排列/Permutations

# 排列的函数表示：

$|A|=n，\ B=\{1,2,\ldots,r\}，\ F:B\to A$

+   1. $F$ 是一个单射 $\Leftrightarrow A$ 的一个 $r$-排列
+   2. $B$ 到 $A$ 的所有单射总数 $\Leftrightarrow P(n,r)$

# 排列的球盒模型表示：

$|A|=n$　　　 $\Leftrightarrow$ $n$ 个盒子

$B=\{1,2,\ldots,r\}$　$\Leftrightarrow$ $r$ 个不同的球

$F:B\to A$ 且是单射 $\Leftrightarrow$ 每个盒子最多放一个球
　　　　　　　　　　 $\Leftrightarrow$ $A$ 的一个 $r$-排列

$B$ 到 $A$ 的所有单射总数 $\Leftrightarrow$ 球放入盒子的放法总数
　　　　　　　　　　 $\Leftrightarrow P(n,r)$
