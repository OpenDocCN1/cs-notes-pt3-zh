# 9.1.2 二元运算的性质

定义9.4 设“⊙”是非空集合A上的二元运算，如果对任意的a、b、c∈A，有：

$$(a\odot b)\odot c=a\odot(b\odot c)。$$

则称运算“⊙”满足集合律。

定义9.5 设“⊙”是非空集合A上的二元运算，如果对任意的a、b∈A，有：

$$a\odot b=b\odot a。$$

则称运算“⊙”满足交换律。

定义9.6 设(A；*，⊙)是一代数系统，如果对任意的a、b、c∈A，有：

+   1. $a*(b\odot c)=(a*b)\odot(a*c)$，则称：“*”对“⊙”有左分配律。
+   2. $(b\odot c)*a=(b*a)\odot(c*a)$，则称：“*”对“⊙”有右分配律。
