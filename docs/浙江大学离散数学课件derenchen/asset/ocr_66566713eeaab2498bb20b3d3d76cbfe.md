# 定理7.4 设F,G,H是关系，则

+   (1) F∘(G∪H) = F∘G ∪ F∘H；
+   (2) (G∪H)∘F = G∘F ∪ H∘F；
+   (3) F∘(G∩H) ⊆ F∘G∩F∘H；
+   (4) (G∩H)∘F ⊆ G∘F∩H∘F。

证：以(3)为例。

```
∵ <x,y> ∈ F∘(G∩H)

⇔ ∃t(<x,t>∈F ∧ <t,y>∈(G∩H))

⇔ ∃t(<x,t>∈F ∧ <t,y>∈G ∧ <t,y>∈H)

⇔ ∃t((<x,t>∈F ∧ <t,y>∈G) ∧ (<x,t>∈F ∧ <t,y>∈H))

⇔ ∃t(<x,t>∈F ∧ <t,y>∈G) ∧ ∃t(<x,t>∈F ∧ <t,y>∈H)

⇔ <x,y>∈F∘G ∧ <x,y>∈F∘H

⇔ <x,y>∈F∘G∩F∘H

∴ F∘(G∩H)=F∘G∩F∘H
```
