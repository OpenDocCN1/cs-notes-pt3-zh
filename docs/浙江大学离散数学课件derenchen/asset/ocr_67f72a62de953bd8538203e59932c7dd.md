# # DEFINITION 5.

The identity matrix of order n is the n × n matrix I<sub>n</sub>
= [ \(\delta_{ij}\) ], where \(\delta_{ij}=1\) if i = j and \(\delta_{ij} = 0\) if i ≠ j. Hence

\(I_n = \left[\begin{array}{ c c c c }
1 & 0 & \cdots & 0 \\
0 & 1 & \cdots & 0 \\
\cdots & \cdots & \cdots & \cdots \\
0 & 0 & \cdots & 1
\end{array}\right]\)
