# # Use set builder notation and logical equivalences to show that =

\(\overline{A \cap B} = \overline{A} \cup \overline{B}\)

\(\overline{A \cap B} = \{x \mid x \notin A \cap B\} = \{x \mid \neg(x \in (A \cap B))\} = \{x \mid \neg(x \in A \land x \in B)\} = \{x \mid x \notin A \lor \notin B\} = \{x \mid x \in \overline{A} \lor x \in \overline{B}\} = \{x \mid x \in A \cup B\}.\)
