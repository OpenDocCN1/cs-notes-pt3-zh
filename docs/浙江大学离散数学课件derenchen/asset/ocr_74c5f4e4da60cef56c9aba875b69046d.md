# ## 二. 关系的运算性质

关系是集合，故有关集合的所有运算性质对关系都成立。

# ### 定理7.1 设F是关系，则

+   (1) \( (F^{-1})^{-1} = F \);

+   (2) \( \text{dom } F^{-1} = \text{ran } F, \quad \text{ran } F^{-1} = \text{dom } F \).

证：(1) \(\because <x,y> \in (F^{-1})^{-1} \Leftrightarrow <y,x> \in F^{-1} \Leftrightarrow <x,y> \in F\)

\(\therefore (F^{-1})^{-1} = F\).

(2) \(\because x \in \text{dom } F^{-1} \Leftrightarrow \exists y(<x,y> \in F^{-1})\)

\(\Leftrightarrow \exists y(<y,x> \in F)\)

\(\Leftrightarrow x \in \text{ran } F\)

\(\therefore \text{dom } F^{-1} = \text{ran } F\).

同理可证 \(\text{ran } F^{-1} = \text{dom } F\).
