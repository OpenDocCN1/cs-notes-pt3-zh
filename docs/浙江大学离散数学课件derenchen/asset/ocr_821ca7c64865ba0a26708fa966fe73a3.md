# 四、商集

定义7.17 设R为非空集合A上的等价关系，以R的所有等价类作为元素，形成的集合称为A关于R的商集，记为A/R，即：

$$A/R=\{[x]_R\mid x\in A\}$$

例如：例7.16中等价关系形成的商集为：

$$A/R=\{\{1,4,7\},\{2,5,8\},\{3,6\}\}$$

# 五、集合的划分

定义7.18 设A为非空集合，若A的子集族π（π⊆P(A)，是由A的一些子集形成的集合）满足下列条件：

+   1. $\Phi\in\pi$
+   2. $\forall x\forall y(x,y\in\pi\land x\ne y\Rightarrow x\cap y=\Phi)$
+   3. $\bigcup_{x\in\pi}x=A$

则称π是A的一个划分，而π中的元素为A的划分块或类。
