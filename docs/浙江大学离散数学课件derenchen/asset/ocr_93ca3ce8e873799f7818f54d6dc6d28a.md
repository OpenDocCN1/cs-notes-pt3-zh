# Graphs/图论

如果 V₁ 与 Vₚ 相邻，显然成了环。不然，由于 V₁，Vₚ 仅与 { V₁， V₂， ...， Vₚ } 中顶点相邻， V₁， Vₚ 的次 ≤ p - 1 。不妨设 V₁ 的次为 k ≤ p - 1 ，分别记相邻顶点为 Vᵢ₁， Vᵢ₂， ...， Vᵢₖ，它们前面的顶点（指在基本道路 { V₁， V₂， ...， Vₚ } 中的序）为 Vᵢ₁₋₁，Vᵢ₂₋₁，...，Vᵢₖ₋₁， Vₚ 必与 Vᵢ₁₋₁，Vᵢ₂₋₁，...，Vᵢₖ₋₁ 中某顶点相邻，否则 Vₚ 的次 ≤ p - 1 - k ， V₁ 与 Vₚ 的次之和 ≤ k + p - 1 - k = p - 1 < n - 1 ，与任一对顶点次之和 ≥ n - 1 矛盾。
