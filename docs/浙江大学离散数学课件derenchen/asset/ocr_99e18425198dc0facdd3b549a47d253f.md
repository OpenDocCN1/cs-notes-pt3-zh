# 有限数学归纳法：对于 n₀ ≤ n ≤ nₖ 的 P(n)

有限数学归纳法的前推公式表示：

[P(n₀) ∧ ∀ n(n₀ ≤ n ≤ nₖ₋₁ ∧ P(n)) → P(n+1))] → ∀ n (n₀ ≤ n ≤ nₖ → P(n))

+   1、归纳基础：P(n₀)
+   2、归纳步骤：∀ n(n₀ ≤ n ≤ nₖ₋₁ ∧ P(n)) → P(n+1))

# 有限数学归纳法：对于 n₀ ≤ n ≤ nₖ 的 P(n)

有限数学归纳法的后推公式表示：

[P(nₖ) ∧ ∀ n(n₀+1 ≤ n ≤ nₖ ∧ P(n)) → P(n−1))] → ∀ n (n₀ ≤ n ≤ nₖ → P(n))

+   1、归纳基础：P(nₖ)
+   2、归纳步骤：∀ n(n₀+1 ≤ n ≤ nₖ ∧ P(n)) → P(n−1))
