# 定义7.12

设R是A上的关系，若

∀x∀y(x,y∈A∧⟨x,y⟩∈R→⟨y,x⟩∈R)，

则称R是A上的**对称关系**；若

∀x∀y(x,y∈A∧⟨x,y⟩∈R∧⟨y,x⟩∈R→x=y)，

则称R是A上的**反对称关系**。

# 例7.11

+   1. A上的全域关系E_A，恒等关系I_A，及空关系Φ都是A上的对称关系；I_A和Φ同时也是A上的反对称关系。
+   
+   2. 设A={1, 2, 3}，则
+   
+   - R₁={⟨1,1⟩,⟨2,2⟩}既是A上的对称关系，也是A上的反对称关系；
+   - R₂={⟨1,1⟩,⟨1,2⟩,⟨2,1⟩}是对称的，但不是反对称的；
+   - R₃={⟨1,2⟩,⟨1,3⟩}是反对称的，但不是对称的；
+   - R₄={⟨1,2⟩,⟨2,1⟩,⟨1,3⟩}既不是对称的也不是反对称的。
