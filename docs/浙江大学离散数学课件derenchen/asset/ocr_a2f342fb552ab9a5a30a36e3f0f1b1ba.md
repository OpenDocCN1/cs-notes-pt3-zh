# # 布尔代数

定义9.8 设(A; \(\circ\) )为一代数系统，如果存在\(e \in A\)，对任意的\(a \in A\)，都有：
\(e \circ a = a \circ e = a\)
则称e为该代数系统的单位元。

定义9.9 设“\(\circ\) ”是非空集合A上的二元运算，如果A中存在某一元素\(\theta\)，对任意的\(a \in A\)，有：\(\theta \circ a = \theta\)(或\(a \circ \theta = \theta\))。则称：\(\theta\)为代数(A; \(\circ\) )的左零元(或右零元)。
类似地，左、右零元可分别记为\(\theta_l\)、\(\theta_r\)。

例9.14 在实数集R中分别定义二元运算“\(\square\)”：
(1) 对任意\(a, b \in R\)，\(a \square b = a\)。则：任何一个实数a都是该二元运算的左零元，没有右零元。
(2) 对任意\(a, b \in R\)且\(a \neq 0\)，\(a \square b = b/a\)。则：0是该二元运算的右零元，没有左零元。
