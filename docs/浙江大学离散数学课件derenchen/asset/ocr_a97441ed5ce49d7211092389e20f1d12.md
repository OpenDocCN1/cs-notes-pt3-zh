# # Boolean Algebra 布尔代数

定义9.15 如果群G的元素只有有限个，则称群G为有限群。其元素个数称为群的阶，记作|G|。

定义9.16 设群G的单位元为e，a是G中的一个元素，使得a^k=e成立的最小正整数k称为a的阶。如果不存在这样的正整数k，则称a是无穷阶的。
有限阶的元素a，其阶可记为|a|。显然，群中单位元的阶为1。

例9.28 (1) 在群(Z; +)中，数0是一阶的，而其他元素都是无穷阶的。
(2) 对于群Z_n=([0], [1], ..., [n-1]),
(a) 当n=4时，||0||=1, ||1||=4, ||2||=2, ||3||=4。
(b) 当n=5时，||0||=1, ||1||=||2||=||3||=||4||=5。
