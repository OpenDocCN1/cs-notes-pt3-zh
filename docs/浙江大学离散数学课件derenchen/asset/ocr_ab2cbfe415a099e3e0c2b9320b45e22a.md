# Definition 2

数学归纳法的一般公式表示：

[P(k) ∧ ∀ m(m ≥ k ∧ P(m) → P(m+1))] → ∀ n P(n)

+   1、归纳基础： P(k)

+   2、归纳步骤： ∀ m (m ≥ k ∧ P(m) → P(m+1))

# 第二数学归纳法：

[P(n₀) ∧ ∀ k ( k > n₀ ∧ P(n₀) ∧ P(n₀+1) ∧ ... ∧ P(k) → P(k+1)) ]→ ∀ n P(n)

+   1、归纳基础： P(n₀)

+   2、归纳步骤： ∀ k ( k > n₀ ∧ P(n₀) ∧ P(n₀+1) ∧ ... ∧ P(k) → P(k+1))
