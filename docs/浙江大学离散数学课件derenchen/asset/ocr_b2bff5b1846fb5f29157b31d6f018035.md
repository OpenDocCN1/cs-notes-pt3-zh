# # Corollary 3

Generally, if every region of a planar connected graph has at least l edges, then:

\(\text{e} \leq \frac{l}{l-2}(\text{v}-2)\)

Proof: similarly, \(2\text{e} = 2\text{e} = \sum \text{deg(Ri)} \geq lr\) , this imply \(r \leq (2/l)\text{e}\),

Using Euler’s formula \(\text{e-v+2=r}\), we obtain

\(\text{e-v+2} \leq (2/l)\text{e}\), this shows that

\(\text{e} \leq \frac{l}{l-2}(\text{v}-2)\)
