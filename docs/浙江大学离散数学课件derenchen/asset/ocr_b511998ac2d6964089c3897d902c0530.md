# # 二项式系数与二项式定理

# # 计数原理

# ## 定理3（PASCAL’公式）：

对任意正整数n、k，其中\(n \geq k\)，则

\( C \, (n + 1, \, k) = C \, (n, \, k-1) + C \, (n, \, k) \)

# ## PASCAL三角形/杨辉三角形

\( C \, (n + 1, \, k) = C \, (n, \, k-1) + C \, (n, \, k) \)

\( n \geq k \geq 0, \quad n \, \, k = 0 \, \, 1 \, \, 2 \, \, 3 \, \, \dots \)
