# 4. 利用主析取范式和主合取式解决应用问题

例2.12 某单位欲从三人A, B, C中挑选1～2人出国进修。由于工作需要选派时要满足以下条件(1)若A去，则C同去；(2)若B去，则C不能去；(3)若C不去，则A或B可以去。问应如何选派？

解：设p：派A去；q：派B去；r：派C去

由条件得：(p→r)∧(q→ ¬r)∧( ¬r→(p∨q))

经演算得其主析取范式为：m₁∨m₂∨m₅

m₁= ¬p∧ ¬q∧r；

m₂= ¬p∧q∧ ¬r；

m₅=p∧ ¬q∧r

由此可知，有3种选派方案：

(1) C去，A, B都不去；(2) B去，A, C都不去；(3) A, C同去，B不去。
