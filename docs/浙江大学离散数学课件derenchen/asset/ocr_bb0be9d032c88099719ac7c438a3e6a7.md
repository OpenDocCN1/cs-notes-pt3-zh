# # Relations关系

(10) 证：

∀ (x, y) ∈ Rᶜ⇒ (y, x) ∈ R

⇒(y, x) ∈ s⇒ (x, y) ∈ Sᶜ

注：
R · T ∩ S · T ⊆ (R ∩ S) · T 不一定成立，
由于 (R ∩ S) · T ⊆ R · T ∩ S · T

若上式成立，
则 (R ∩ S) · T = R · T ∩ S · T

证明：等式不成立

若 ∀ a ∈ A，b₁，b₂ ∈ B，c ∈ C，且
(a, b₁) ∈ R，(a, b₂) ∈ S，
(b₁, c) ∉ S，(a, b₂) ∉ R，
(b₁, c) ∈ T，(b₂, c) ∈ T，

显然 (a c) ∈ R · T ∩ S · T

但 (a, c) ∉ (R ∩ S) · T
