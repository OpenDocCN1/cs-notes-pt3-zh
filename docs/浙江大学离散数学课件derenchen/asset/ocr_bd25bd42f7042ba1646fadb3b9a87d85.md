# 例5.5 证明下列等值式

+   (1) ¬∃x(M(x) ∧F(x) ⇔ ∀x(M(x) →¬F(x))

+   (2) ¬∀x(F(x)→G(x)) ⇔ ∃x(F(x) ∧¬G(x))

+   (3) ¬∀x∀y(F(x) ∧G(y)→H(x,y))⇔∃x∃y (F(x) ∧G(y) ∧¬H(x,y))

+   ∃x∃y (F(x) ∧G(y) ∧¬H(x,y))

+   证：(1) ¬∃x(M(x) ∧F(x))

+   ⇔∀x ¬(M(x) ∧F(x)) （量词否定等值式）

+   ⇔∀x (¬M(x) ∨¬F(x)) （德摩根律，置换规则）

+   ⇔∀x (M(x) →¬F(x)) （蕴含等值式，置换规则）
