# 例5.7 求下列各式的前束范式

(1) ∃x F(x) ∧ ∀x G(x); (2) ∀x F(x)→∃x G(x);

(3) ∃x F(x)→∀x G(x);

解： (1) ∃x F(x) ∧ ∀x G(x)

⇔∃y F(y) ∧ ∀x G(x) 换名规则

⇔∃y∀x(F(y) ∧ G(x)) 量词辖域扩张等值式

(2) ∀x F(x)→∃x G(x)

⇔∀y F(y)→∃x G(x) 换名规则

⇔∃y(F(y)→∃x G(x)) 量词辖域扩张等值式

⇔∃y∃x(F(y)→G(x)) 量词辖域扩张等值式

(3) ∃x F(x)→∀x G(x)

⇔ ∃y F(y)→∀x G(x) 换名规则

⇔ ∀y (F(y)→∀x G(x)) 量词辖域扩张等值式

⇔ ∀y ∀x (F(y)→G(x)) 量词辖域扩张等值式
