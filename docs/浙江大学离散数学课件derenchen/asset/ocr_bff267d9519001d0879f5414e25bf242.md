# # Boolean Algebra 布尔代数

例9.18 设S是非空集合，试求代数(P(S); U)、(P(S); ∩)的单位元和零元。

解：(1) 在代数系统(P(S); U)中，由于对任意的a∈P(S)，有：
a U φ=φ U a=a，因此，φ是该代数系统的单位元。
S U a=a U S=S，因此，S是该代数系统的零元。
(2) 同理可得，代数系统(P(S); ∩)的单位元和零元分别是S、φ。
一个代数系统(A; ○)，如果有单位元e和零元0，则该代数系统可记为(A; ○，e, 0)。

定义9.10 设(A; ○，e)是一个代数系统，如果对a∈A，存在b∈A，使得：
a○ b=e(或b○ a=e)。
则称：b是a的右逆元(或左逆元)。
