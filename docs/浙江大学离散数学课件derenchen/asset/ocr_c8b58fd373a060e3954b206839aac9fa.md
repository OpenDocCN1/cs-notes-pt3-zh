# # DEFINITION 9.

Let f be a one-to-one correspondence f from the set A to the set B. The **inverse function** of f is the function that assigns to an element b belonging to B the unique element a in A such that f (a) = b. The inverse function of f is denoted by f<sup>-1</sup>. Hence, f<sup>-1</sup>(b) = a when f(a)=b.

逆函数

Let g be a function from the set A to the set B and let f be a function from the set B to the set C. The **composition** of the functions f and g, denoted by f ◦ g, is defined by

(f ◦ g)(a) = f (g (a)).
