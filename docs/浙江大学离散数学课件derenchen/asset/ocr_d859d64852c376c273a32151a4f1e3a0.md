# 证明：

R是等价关系， ∀ a ∈ A，由 R的自反性，
（ a， a ）∈ R，即 a 与 a 属于同一等价类，
也即 ∃ i ， a ∈ A<sub>i</sub>

若 i ≠ j ， A<sub>i</sub>≠A<sub>j</sub>，而 A<sub>i</sub>∩A<sub>j</sub>≠Φ，则 ∃ c
∈ A<sub>i</sub>∩A<sub>j</sub>， c ∈ A<sub>i</sub>，且 c ∈ A<sub>j</sub>

对 ∀ a ∈ A<sub>i</sub>， a ~ c ， c ∈ A<sub>j</sub>

对 ∀ b ∈ A<sub>j</sub>， b ~ c ，即 c ~ b (对称性)

由 R 传递性， a ~ b

由 a ， b 的任意性，故 A<sub>i</sub> = A<sub>j</sub>
