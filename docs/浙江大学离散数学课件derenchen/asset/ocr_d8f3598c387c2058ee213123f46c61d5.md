# 定理7.6 设$R$为$A$上的关系，$m,n\in\mathbb{N}$，则

$(1)\quad R^m\circ R^n=R^{m+n};$

$(2)\quad (R^m)^n=R^{mn}$

证：(1) 对于任意取定的$m\in\mathbb{N}$，关于$n$作数学归纳法。

当$n=0$时，$R^m\circ R^0=R^m\circ I_A=R^m=R^{m+0}$

假设$R^m\circ R^n=R^{m+n}$，则

$R^m\circ R^{n+1}=R^m\circ(R^n\circ R)=(R^m\circ R^n)\circ R=R^{m+n}\circ R^1=R^{m+n+1}$

由归纳法原理，知命题成立。

(2) 对任意取定的$m\in\mathbb{N}$，关于$n$作数学归纳法。

当$n=0$时，$(R^m)^0=I_A=R^0=R^{m\cdot 0}$

假设$(R^m)^n=R^{mn}$，则$(R^m)^{n+1}=(R^m)^n\circ R^m=R^{mn}\circ R^m=R^{mn+m}=R^{m(n+1)}$

由归纳法原理，知命题成立。
