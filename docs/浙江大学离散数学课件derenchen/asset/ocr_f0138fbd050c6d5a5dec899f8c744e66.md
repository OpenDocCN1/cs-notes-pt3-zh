# Warshall算法：（1962）

设R是n个元素集合上的二元关系

+   (1) 是R的相关矩阵；
+   
+   (2) $i \leftarrow 1$；
+   
+   (3) **for** $j=1$ **to** $n$ **do**
+   
+   　　**if** $a_{j,i}=1$ **then do**
+   
+   　　　　**for** $k=1$ **to** $n$ **do**
+   
+   　　　　　　$a_{j,k}\leftarrow a_{j,k}\lor a_{i,k}$
+   
+   (4) $i=i+1$；
+   
+   (5) **if** $i\le n$，**then go** (3)
+   
+   　　**else stop**
