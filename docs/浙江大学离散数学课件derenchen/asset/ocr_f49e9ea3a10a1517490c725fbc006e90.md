# 例7.18 求 A={1, 2, 3} 上所有的等价关系。

解：先求出 A 的所有划分：

+   $\pi_1=\{\{1,2,3\}\}$；　　$\pi_2=\{\{1\},\{2,3\}\}$；
+   
+   $\pi_3=\{\{2\},\{1,3\}\}$；　　$\pi_4=\{\{3\},\{1,2\}\}$；
+   
+   $\pi_5=\{\{1\},\{2\},\{3\}\}$。

与这些划分一一对应的等价关系是：

+   $\pi_1：\to$ 全域关系 $E_A$
+   
+   $\pi_2：\to R_2=\{\langle2,3\rangle,\langle3,2\rangle\}\cup I_A$
+   
+   $\pi_3：\to R_3=\{\langle1,3\rangle,\langle3,1\rangle\}\cup I_A$
+   
+   $\pi_4：\to R_4=\{\langle1,2\rangle,\langle2,1\rangle\}\cup I_A$
+   
+   $\pi_5：\to$ 恒等关系 $I_A$
