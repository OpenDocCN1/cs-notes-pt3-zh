# 注：构造证明时的两个技巧：

+   1. 附加前提证明法：欲证 $(A_1\land A_2\land\ldots\land A_k)\Rightarrow(A\to B)$，可改证
+   
+      $(A_1\land A_2\land\ldots\land A_k\land A)\Rightarrow B$。道理如下：
+   
+      $(A_1\land A_2\land\ldots\land A_k)\to(A\to B)$
+   
+      $\Leftrightarrow\neg(A_1\land A_2\land\ldots\land A_k)\lor(\neg A\lor B)$
+   
+      $\Leftrightarrow(\neg A_1\lor\neg A_2\lor\ldots\lor\neg A_k\lor\neg A)\lor B$
+   
+      $\Leftrightarrow\neg(A_1\land A_2\land\ldots\land A_k\land A)\lor B$
+   
+      $\Leftrightarrow(A_1\land A_2\land\ldots\land A_k\land A)\to B$

+   2. 归谬法：欲证 $(A_1\land A_2\land\ldots\land A_k)\Rightarrow B$，若将 $\neg B$ 做为附加前提后能得出矛盾（比如得到 $A\land\neg A$），则说明原推理正确。道理如下：
+   
+      $(A_1\land A_2\land\ldots\land A_k)\to B$
+   
+      $\Leftrightarrow\neg(A_1\land A_2\land\ldots\land A_k)\lor B$
+   
+      $\Leftrightarrow\neg(A_1\land A_2\land\ldots\land A_k\land\neg B)$
+   
+      可见若 $A_1\land A_2\land\ldots\land A_k\land\neg B$ 为矛盾式，则 $A_1\land A_2\land\ldots\land A_k\to B$ 为重言式。
