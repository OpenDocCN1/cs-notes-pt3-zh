假设Rⁿ是对称的， 下证Rⁿ⁺¹ 的对称性。由于

<x, y>∈ Rⁿ⁺¹ => <x, y>∈ Rⁿ °R

=> ∃t (<x, t>∈Rⁿ)∧<t, y>∈R)

=> ∃t (<t, x>∈Rⁿ)∧<y, t>∈R)

=> <y, x>∈R °Rⁿ

=> <y, x>∈Rⁿ⁺¹

故 Rⁿ⁺¹ 是对称的。归纳法定成。

现在来证 t(R)的对称性。由于

<x, y>∈t(R) => ∃n(<x, y>∈Rⁿ)=> ∃n(<y, x>∈Rⁿ)=> <y, x>∈t(R)

因此t(R)是对称的。

注： 由于传递闭包运算和对称闭包运算不保持传递性，故在运算顺序上它们应放在自反闭包之后，即 t s r(R)=t(s(r(R)))。
