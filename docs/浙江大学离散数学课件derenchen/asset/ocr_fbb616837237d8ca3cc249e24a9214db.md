# (4)在树上任添一条边，产生唯一回路。

# (5)设T = (V, E)， | V | = v， | E | = e，则v = e + 1。

树是平面图，且无回路，区域数γ = 1，满足欧拉公式v - e + γ = 2，即v = e + 1。

也可用强归纳法证： （对V归纳）

+   (1) v ≤ 2，显然成立

+   (2) 假设v < p时成立，v = p时，先移去一条边，成了两棵树T₁和T₂，有v₁ = e₁ + 1，v₂ = e₂ + 1，且e₁ + e₂ = e - 1，故v = v₁ + v₂ = e₁ + 1 + e₂ + 1 = (e₁ + e₂ + 1) + 1 = e + 1。
