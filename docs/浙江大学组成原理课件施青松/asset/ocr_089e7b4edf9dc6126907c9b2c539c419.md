# # From a High-Level Language to the Language of Hardware

# ## The process of compiling and assembling

High-level language program (in C)

```
```
swap(int v[], int k)
{
int temp;
temp = v[k];
v[k] = v[k+1];
v[k+1] = temp;
}
