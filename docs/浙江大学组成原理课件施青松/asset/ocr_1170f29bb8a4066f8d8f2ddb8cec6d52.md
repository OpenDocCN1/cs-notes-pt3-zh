# 8.4 **Buses** and Other Connections between
Processors Memory, and I/O Devices

+   - Shared communication link (one or more wires)
+   - Difficult design:
+     - may be bottleneck
+     - length of the bus
+     - number of devices
+     - tradeoffs (fast bus accesses and high bandwidth)
+     - support for many different devices
+     - cost
