# # Step 3 (instruction dependent)

+   - ALU is performing one of three functions, based on instruction type
+   - Memory Reference ( lw / sw ):
+     ALUOut = A + sign-extend(IR[15-0]);
+   - R-type:
+     ALUOut = A op B;
+   - Branch:
+     if (A==B) PC = ALUOut;
+   - jump:
+     pc = pc31-28 + IR25-0 << 2
