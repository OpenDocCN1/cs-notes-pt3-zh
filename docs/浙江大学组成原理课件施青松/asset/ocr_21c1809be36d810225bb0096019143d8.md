# Signed multiplication

+   - **Basic approach:**
+     - Store the signs of the operands
+     - Convert signed numbers to unsigned numbers
+       - (most significant bit (MSB) = 0)
+     - Perform multiplication
+     - If sign bits of operands are equal
+       - sign bit = 0, else
+       - sign bit = 1
