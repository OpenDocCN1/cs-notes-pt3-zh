# # Shift operator

Move all the bits in a word to left or right, filling emptied bits with 0

Shifting left by _i_ is same result as multiplying by 2<sup>_i_</sup>

0000 0000 0000 0000 0000 0000 0000 1001 (9)<sub>10</sub>

Shift left 4 ←

0000 0000 0000 0000 0000 0000 1001 0000 (9×16=144)<sub>10</sub>

sll $t2, $s0, 4 #reg $t2=reg $s0<<4 bit
