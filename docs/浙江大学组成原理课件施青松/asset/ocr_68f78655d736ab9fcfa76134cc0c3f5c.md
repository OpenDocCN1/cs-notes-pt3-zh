# # Signed division

+   - Keep the signs in mind for Dividend and Remainder
+     - (+ 7) ÷(+ 2) = + 3 Remainder = +1
+     - 7 = 3 × 2 + (+1) = 6 + 1
+     - (- 7 ) ÷(+ 2) = - 3 Remainder = -1
+     - -7 = -3 × 2 + (-1) = - 6 - 1
+     - (+ 7 ) ÷(- 2) = - 3 Remainder = +1
+     - (- 7 ) ÷(- 2) = + 3 Remainder = -1
+   - One 64 bit register : Hi & Lo
+     - Hi: Remainder, Lo: Quotient
+   - Instructions: div, divu
+   - Divide by 0 → overflow : Check by software
