# Performance in Wider Main Memory

+   - With a main memory width of 2 words(64bits)

**The miss penalty:** 4words/Block

\[1+2\times(15+1)=33\text{ CLK}s\]

**Bandwidth:**

\[\frac{4\times4}{33}=\frac{16}{33}\approx0.48\]
