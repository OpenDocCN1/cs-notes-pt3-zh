# # For two-way associative

Number of cache set = 2<sup>12</sup> ÷ 2= 2<sup>11</sup>
Bits of index = 12-1=11 bits
Bits of Tag = (28-11) ×2×2×2K=17×2×2K=68 Kbits

# # For four-way associative

Number of cache set = 2<sup>12</sup> ÷ 4= 2<sup>10</sup>
Bits of index = 12-1=10 bits
Bits of Tag = (28-10) ×4×1K=18×4×1K=72 Kbits

# # For full associative

Number of cache set = 2<sup>12</sup> ÷ 2<sup>12</sup> = 2<sup>0</sup>
Bits of index = 12-12=0 bits
Bits of Tag = (28-0) ×4K×1=128 Kbits

|    | Direct | 2-way | 4-way | Fully |
|---|---|---|---|---|
| Index(bit) | 12 | 11 | 10 | 0 |
| Tag(bit) | 16 | 17 | 18 | 28 |
