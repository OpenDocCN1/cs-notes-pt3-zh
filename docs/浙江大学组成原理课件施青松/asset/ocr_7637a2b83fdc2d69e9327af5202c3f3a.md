# Procedure *sort*

# C code

```
sort ( int v[ ], int n )
{
        int i, j;
        for ( i = 0; i < n; i += 1 ) {
                for ( j = i - 1; j >= 0 && v[j] > v[j+1]; j -= 1 )
                        swap ( v, j );
        }
}
```
