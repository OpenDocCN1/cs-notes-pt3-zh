# # How Control Checks for Exceptions

+   - **add control signal**
+     - **CauseWrite** for CauseReg
+     - **EPCWrite** for EPC
+       - EPC = PC - 4 (completed by ALU)

+   - **process of control**
+     - CauseReg = 0 or 1
+     - EPC = PC - 4
+     - PC <--- address of process routine ( ex. c0000000 )
