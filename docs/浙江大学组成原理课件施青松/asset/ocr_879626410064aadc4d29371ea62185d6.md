# # Example for Decimal

+   - Aligning the two numbers
+   
+     `9.999 • 10¹`
+   
+     `0.01610 • 10¹ → 0.016 • 10¹` Truncation

+   - Addition
+   
+     ```text
+         9.999   • 10¹
+       + 0.016   • 10¹
+       ─────────────
+        10.015   • 10¹
+     ```

+   - Normalisation
+   
+     `1.0015 • 10²`

+   - Rounding
+   
+     `1.002 • 10²`
