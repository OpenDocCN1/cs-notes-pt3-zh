```
# **Outer loop**

```
```asm
move $s0, $zero    # $s0 ← $zero (i = 0)
for1tst:  slt  $t0, $s0, $s3    # test if $s0 >= $s3 (i >= n)
          beq  $t0, $zero, exit1 # go to exit1 if $s0 >= $s3 (i >= n)
```
