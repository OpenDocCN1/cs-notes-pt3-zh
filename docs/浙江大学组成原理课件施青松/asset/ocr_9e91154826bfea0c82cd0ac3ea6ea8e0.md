+   - To access data of disk:

+     - Seek: position read/write head over the proper track

+       - **minimum seek time**
+       - **maximum seek time**
+       - **average seek time (3 to 14 ms)**

+     - Rotational latency: wait for desired sector

+       - **average latency is the half-way round the disk.**

Average rotational latency = \(\frac{0.5\ rotation}{5400\ RPM}\) = \(\frac{0.5\ rotation}{5400\ RPM\left(\frac{60\ seconds}{minute}\right)}\) = **0.0056 seconds = 5.6 ms**

Average rotational latency = \(\frac{0.5\ rotation}{15000\ RPM}\) = \(\frac{0.5\ rotation}{15000\ RPM\left(\frac{60\ seconds}{minute}\right)}\) = **0.0020 seconds = 2.0 ms**
