# 2.5 Logical Operation

+   Operating some bits within word or individual bit

| Logic operations | C operators | Java operators | MIPS instructions |
|---|---|---|---|
| Shift left | `<<` | `<<` | **sll** |
| Shift right | `>>` | `>>>` | **srl** |
| Bit-by-bit AND | `&` | `&` | **And, andi** |
| Bit-by-bit OP | `\|` | `\|` | **Or, ori** |
| Bit-by-bit NOT | `~` | `~` | ***nor*** |
