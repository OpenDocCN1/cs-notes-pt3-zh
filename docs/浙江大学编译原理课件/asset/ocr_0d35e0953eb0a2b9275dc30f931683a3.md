# # 5.4.3 LALR(1) Parsing

# ## FIRST PRINCIPLE OF LALR(1) PARSING

The core of a state of the DFA of LR(l) items is
a state of the DFA of LR(0) items.

# ## SECOND PRINCIPLE OF LALR(1) PARSING

Given two states s₁ and s₂ of the DFA of LR(l)
items that have the same core, suppose there
is a transition on the symbol X from s₁ to a
state t₁. Then there is also a transition on X
from state s₂ to a state t₂, and the states t₁ and
t₂ have the same core.
