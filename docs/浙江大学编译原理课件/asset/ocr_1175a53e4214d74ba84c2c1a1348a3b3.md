# 4.1.2 Repetition and Choice: Using EBNF

+   - A recursive-descent calculator for the simple integer arithmetic of our grammar:

```
Function exp : integer;
  var temp: integer;
  begin
    temp:=term;
    while token= + or token = - do
      case token of
        + : match(+);
            temp:=temp+term;
        -: match(-);
           temp:=temp-term;
      end case;
    end while;
    return temp;
  end exp;
```
