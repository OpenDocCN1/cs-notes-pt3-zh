# # 3.6.1 A formal definition of context-free language

+   - Let G be a grammar as defined above, G = (T, N, P, S).
+   - A derivation step over G is of the form a A γ => a β γ,
+     where a and γ are elements of (T ∪ N)* and A → β is in P.

+   - **the set of symbols**: The union T ∪ N of the sets of terminals and nonterminals
+   - **a sentential form**: a string a in (T ∪ N)*.
