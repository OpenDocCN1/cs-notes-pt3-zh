# 7.3.1 Stack-Based Environments Without Local Procedures

# Example

```
```c
#include <stdio.h>
int x,y;
int gcd(int u,int v)
{ if (v==0) return u;
        else return gcd(v, u%v);
}

main()
{scanf("%d%d",&x,&y);
printf("%d\n",gcd(x,y));
return 0;
}
