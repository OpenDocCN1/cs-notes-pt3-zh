# # 4.2.1 The Basic Method of LL(1) Parsing

S → E + S | E
E → num | (S)

| Partly-derived String | Lookahead | parsed part unparsed part |
|---|---|---|
| S | | |
| ( | (1+2+(3+4))+5 | |
| ⇒ E+S | ( | (1+2+(3+4))+5 |
| ⇒ (S)+S | 1 | (1+2+(3+4))+5 |
| ⇒ (E+S)+S | 1 | (1+2+(3+4))+5 |
| ⇒ (1+S)+S | 2 | (1+2+(3+4))+5 |
| ⇒ (1+E+S)+S | 2 | (1+2+(3+4))+5 |
| ⇒ (1+2+S)+S | 2 | (1+2+(3+4))+5 |
| ⇒ (1+2+E)+S | ( | (1+2+(3+4))+5 |
| ⇒ (1+2+(S))+S | 3 | (1+2+(3+4))+5 |
| ⇒ (1+2+(E+S))+S | 3 | (1+2+(3+4))+5 |
