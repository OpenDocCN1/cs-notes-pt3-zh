# 3.6.1 A formal definition of context-free language

+   - **α ⇒* β** if and only if there is a sequence of 0 or more derivation steps (n >= 0)  
+     α₁ ⇒ α₂ ⇒ ... ⇒ αₙ₋₁ ⇒ αₙ such that α = α₁, and β = αₙ  
+     (If n = 0, then α = β)

+   - **A derivation over the grammar G is of the form S ⇒* w, where w ∈ T***  
+     w is a string of terminals only, called a **sentence**.  
+     S is the start symbol of G.
