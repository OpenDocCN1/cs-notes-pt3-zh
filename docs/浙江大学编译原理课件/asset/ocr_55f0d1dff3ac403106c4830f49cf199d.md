# 3.6.1 A formal definition of context-free language

• The **language generated by G**, written *L(G)*, is defined:

L(G) = {w ∈ T* | there exists a derivation S =>* w of G}.

• A **leftmost derivation** S =>*ₗₘ w is a derivation each derivation step a A γ => a β γ, is such that a ∈ T*; that is, a consists only of terminals.

• A **rightmost derivation** is one each derivation step a A γ => a β γ has the property that γ ∈ T*.
