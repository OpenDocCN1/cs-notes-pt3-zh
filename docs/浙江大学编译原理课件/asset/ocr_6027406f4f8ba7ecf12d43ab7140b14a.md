# 7.4.3 Heap Management

```
void free(void *ap)
{
    header *bp, *p, *prev;
        bp = (header *)ap −1;
        for (prev=memptr, p=memptr->s.next;
        (p!=bp) && (p!=memptr); prev=p, p=p->s.next);
        if (p!=bp) return;
              /* corrupted list, do nothing */
        prev->s.freesize +=p->s.usedsize + p->s.freesize;
        prev->s.next = p->s.next;
            memptr = prev;
}
```
