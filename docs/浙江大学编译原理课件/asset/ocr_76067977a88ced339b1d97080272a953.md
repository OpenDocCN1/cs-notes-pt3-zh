# 4.1.2 Repetition and Choice: Using EBNF

+   - the EBNF rule for term:
+   - `term → factor {mulop factor}`

```
Procedure term;
Begin
    factor;
    While token = * do
        match(token);
        factor;
    End while;
End exp;
```
