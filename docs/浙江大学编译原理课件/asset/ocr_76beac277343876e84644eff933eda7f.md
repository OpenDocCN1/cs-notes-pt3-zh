# 2.5 Implementation of a tiny scanner

```
```text
{ sample program
In TINY language  -
Computes  factorial
  }
read x; { input on integer }
if 0 < x then { don't compute if x <= 0 }
fact := 1 ;
repeat
fact := fact * x;
x := x - 1
until x = 0;
write fact { output factorial of x }
end
