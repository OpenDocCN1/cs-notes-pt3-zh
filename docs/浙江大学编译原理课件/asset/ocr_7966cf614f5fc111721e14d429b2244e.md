# 3.5 extended notations: EBNF and syntax diagrams

+   - Optional constructs in EBNF are indicated by surrounding them with square brackets [...].

```
statement → if-stmt | other
if-stmt → if ( exp ) statement [ else statement ]
exp → 0 | 1
```
