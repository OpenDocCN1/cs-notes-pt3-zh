# 4.2.3 left Recursion Removal and Left Factoring

**Example:**

```
exp → term⁺exp | term
exp → term exp′
exp′ → + exp | ε
```

Suppose we substitute term exp′ for exp:

```
exp → term exp′
exp′ → + term exp′ | ε
```

*this is identical to the grammar obtained from the left recursive rule by left recursion removal*
