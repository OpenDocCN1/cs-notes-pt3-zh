corresponding to the two leftmost derivations

```
exp => exp op exp
=> exp op exp op exp ,
=> **number** op exp op exp
=>**number** - exp op exp
=> **number** - **number** op exp
=> **number** - **number** * exp
=> **number** - **number** * **number**
```

```
exp=> exp op exp

=>**number** - exp
=>**number** - exp op exp
```
