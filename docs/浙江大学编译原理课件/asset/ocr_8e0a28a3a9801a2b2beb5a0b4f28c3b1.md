# # 5.4.3 LALR(1) Parsing

+   • A grammar is an LALR(I) grammar if no parsing conflicts arise in the LALR( I) parsing algorithm.

+   • If a grammar is LR(I), then the LALR(I) parsing table cannot have any shift-reduce conflicts, there may be reduce-reduce conflicts.
