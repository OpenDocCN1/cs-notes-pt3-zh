# # 1.3 The translation process

# ## 1. The scanner

Lexical analysis: input a stream of characters, output tokens

Example: a [index] = 4+2

Output:

+   a identifier
+   [ left bracket
+   index identifier
+   ] right bracket
+   = assignment
+   4 number
+   + plus sign
+   2 number

other operations: enter identifiers into the symbol table enter literals into the literal table
