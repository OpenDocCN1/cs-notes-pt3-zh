# # 5.1 OVERVIEW OF BOTTOM-UP PARSING

•Example. 5.2 Consider the following augmented grammar for arithmetic expressions (no parentheses and one operation):

+   •E’→E E→E + n | n

+   •A bottom-up parse of the string n + n

+   •the rightmost derivation E’ => E => E+n => n+n

|   | Parsing stack | Input | Action   |
|---|---------------|-------|----------|
| 1 | $             | n+n$  | Shift    |
| 2 | $n            | +n$   | Reduce E→n |
| 3 | $E            | +n$   | Shift    |
| 4 | $E+           | n$    | Shift    |
| 5 | $E+n          | $     | Reduce E → E+n |
| 6 | $E            | $     | Reduce E ’→ E |
| 7 | $E’           | $     | Accept   |
