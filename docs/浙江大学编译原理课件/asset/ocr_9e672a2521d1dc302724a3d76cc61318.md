# 6.2.2 Synthesized and inherited attributes

Example 6.12

```
void evaltype ( syntaxtree t )
{
    if(t->kind == decl)
    {
        syntaxtree p = t->rchild;
        p->dtype = t->lchild->dtype;
        while (p->sibling !=NULL)
        {p->sibling->dtype = p->dtype;
            p = p->sibling;
        }
    }
}
```
