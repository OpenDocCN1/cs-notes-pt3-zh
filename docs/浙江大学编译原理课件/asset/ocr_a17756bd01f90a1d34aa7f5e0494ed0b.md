# 6.2.2 Synthesized and inherited attributes

| Grammar Rule | Semantic Rules |
|---|---|
| **S → exp** | **exp.etype** = if **exp.isFloat** then **float** else **int**  
**S.val** = **exp.val** |
| **Exp1 → exp2 / exp3** | **exp1.isFloat** = **exp2.isFloat** or **exp3.isFloat**  
**exp2.etype** = **exp1.etype**  
**exp3.etype** = **exp1.etype**  
**exp1.val** = if **exp1.etype** = **int** then **exp2.val / exp3.val** else **exp2.val / exp3.val** |
| **exp → num** | **exp.isFloat** = **false**  
**exp.val** = if **exp.etype** = **int** then **num.val** else **Float(num.val)** |
| **exp → num.num** | **exp.isFloat** = **true**  
**exp.val** = **num.num.val** |
