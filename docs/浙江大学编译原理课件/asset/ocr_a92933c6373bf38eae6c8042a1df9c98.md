# 3.2.3 Derivations and the language defined by a grammar

figure 3.1 : a derivation

```
• exp → exp op exp | (exp) | **number**
• op → + | − | *
```

+   (1) exp => exp op exp
+   (2) => exp op **number**
+   (3) => exp * **number**
+   (4) => ( exp ) * **number**
+   (5) => { exp op exp ) * **number**
+   (6) => (exp op number) * **number**
+   (7) => (exp - number) * **number**
+   (8) => (number - number) * **number**

```
[exp → exp op exp]
[exp → number]
[op → *]
[exp → ( exp )]
[exp → exp op exp]
[exp → number]
[op → −]
[exp → number]
```
