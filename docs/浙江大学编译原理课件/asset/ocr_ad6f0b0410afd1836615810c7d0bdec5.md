# 4.3.1 First Sets

Let α= X<sub>1</sub>X<sub>2</sub>...X<sub>n</sub> be a string of terminals and non-terminals,. First(α) is defined as follows:

+   1.First(α) contains First(X<sub>1</sub>)-{ε};

+   2.For each i=2,...,n, if for all k=1,...,i-1, First(X<sub>k</sub>) contains ε, then First(α) constains First(X<sub>k</sub>)-{ε}.

+   3. If all the set First(X<sub>1</sub>)..First(X<sub>n</sub>) contain ε, the First(α) contains ε.
