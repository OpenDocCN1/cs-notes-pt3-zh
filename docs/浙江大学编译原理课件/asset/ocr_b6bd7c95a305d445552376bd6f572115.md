# 5.1 OVERVIEW OF BOTTOM-UP PARSING

+   - **Example 5.1** Consider the following augmented grammar for balanced parentheses:
+   - S′ → S
+   - S → (S)S|ε
+   - four steps of the rightmost derivation
+     S′ => S
+     => (S)S => (S) => ( )

|   | Parsing stack | Input | Action |
|---|---|---|---|
| 1 | `$` | `( ) $` | **Shift** |
| 2 | `$ (` | `) $` | **Reduce S → ε** |
| 3 | `$ (S` | `) $` | **Shift** |
| 4 | `$ (S )` | `$` | **Reduce S → ε** |
| 5 | `$ (S ) S` | `$` | **Reduce S → (S)S** |
| 6 | `$$` | `$` | **Reduce S′ → S** |
| 7 | `$$′` | `$` | **Accept** |
