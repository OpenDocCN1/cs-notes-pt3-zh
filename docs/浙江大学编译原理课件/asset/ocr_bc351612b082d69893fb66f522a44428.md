# # 4.3.1 First Sets

+   - Grammar for statement sequences:
+     stmt-sequence →stmt stmt-seq'
+     stmt-seq' →; stmt-sequence|ε
+     stmt→s

+   - list the production choices individually:
+     stmt-sequence →stmt stmt-seq'
+     stmt-seq' →; stmt-sequence
+     stmt-seq' →ε
+     stmt→s

+   - The First sets are as follows:
+     First(stmt-sequence)={s}
+     First(stmt-seq')={;, ε}
+     First(stmt)={s}
