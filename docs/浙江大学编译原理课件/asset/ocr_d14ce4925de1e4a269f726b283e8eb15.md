# Data Structures for the Implementation of Three-Address Code

```
Typedef enum { rd, gt, if_f, asn, lab, mul, sub, eq, wri, halt, ...} OpKind;
Typedef enum { Empty, IntConst, String } AddrKind;
Typedef struct
        { AddrKind kind;
          Union
             { int val;
               char * name;
             } contents;
        } Address;
Typedef struct
       { OpKind op;
         Address addr1, addr2,addr3;
       } Quad
```
