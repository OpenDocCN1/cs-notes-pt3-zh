# 4.3.3 Constructing LL(1) Parsing Tables

# Example: The simple expression grammar.

exp →term exp’
addop →+ | -
term’→mulop factor term’| ε
factor→(exp) | number

exp’→addop term exp’ | ε
term →factor term’
mulop→*

| First Sets |
|------------|
| First(exp) = { (,number} |
| First(exp’) = { +,-,ε } |
| First(term)= {(,number} |
| First(term’) = { *, ε } |
| First(factor)= {(,number } |
| First(addop)={ + ,- } |
| First(mulop)={ * } |

| Follow Sets |
|-------------|
| Follow(exp) = {$, )} |
| Follow (exp’) = {$, )} |
| Follow (term)= {$,+,-,) } |
| Follow (term’) = {$,+,-,) } |
| Follow (factor)= {$,+,-,*,)} |
| Follow (addop)={ (,number } |
| Follow (mulop)={(,number } |
