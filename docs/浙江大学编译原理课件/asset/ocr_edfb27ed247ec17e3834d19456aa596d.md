# # 7.1 Memory Organization During Program Execution

# ## Processor registers

+   - Processor registers are also part of the structure of the runtime environment.

+   - Special-purpose registers to keep track of execution

+   - PC program counter;
+   - SP stack pointer;
+   - FP frame pointer;
+   - AP argument pointer
