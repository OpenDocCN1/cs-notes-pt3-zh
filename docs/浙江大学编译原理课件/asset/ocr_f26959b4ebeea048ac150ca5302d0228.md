# Name equivalence

One complication in name equivalence:

type expressions can be allowed in variable declarations\nor subexpressions of type expressions.

a type expression may have no explicit name given to it,\na compiler will have to generate an internal name for the\ntype expression that is different from any other names.

```
x:array [10] of int;\ny:array [10] of int;
```

The variable x and y are assigned different ( and\nunique ) type names corresponding to the type\nexpression.

It is possible to retain structural equivalence in the\npresent of type names.
