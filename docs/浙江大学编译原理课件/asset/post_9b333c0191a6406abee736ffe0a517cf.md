## 2.3.3 Implementation of finite automata in Code

assumes :

- The transitions: are kept in a transition array T indexed by states and input characters;  
- the Boolean array Advance: The transitions that advance the input (i.e., those not marked with brackets in the tableware) are given by the Boolean array Advance, indexed also by states and input characters;  
- the Boolean array Accept: accepting states are given by the Boolean array Accept, indexed by states.

## 2.3.3 Implementation of finite automata in Code

```
state := 1;
ch := next input character;
while not Accept[state] and not error(state) do
    newstate := T[state,ch];
    if Advance[state,ch] then ch := next input char;
    state := newstate;
end while;
if Accept[state] then accept;
```

## 2.4.2 from an NFA to a DFA

The algorithm is called the subset construction.

- 1、 **the ε-closure of a Set of states:**  
  the ε-closure of a single state s is the set of states reachable by a series of zero or more ε-transitions.  
  the ε-closure of a set of states : the union of the ε-closures of each individual state.
