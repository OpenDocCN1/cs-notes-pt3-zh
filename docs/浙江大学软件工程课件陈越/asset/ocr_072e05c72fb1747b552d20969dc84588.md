# # 2.8 Increment and Decrement Operators

(increment operator) ++: adds 1 to its operand(自增）
(decrement operator) --: substract 1 from its operand(自减）

int i=3;
i++;   /* i=i+1 */
i++ and ++i are different (also i--, --i);
If n is 5,then
x=n++;   /* n=6,x=5 */
but: x=++n; /* n=6,x=6 */

void squeeze(char s[], int c)
{   int i, j;
for(i=j=0; s[i]!='\0'; i++)
if(s[i] != c) s[j++]=s[i];
s[j]='\0';
}
