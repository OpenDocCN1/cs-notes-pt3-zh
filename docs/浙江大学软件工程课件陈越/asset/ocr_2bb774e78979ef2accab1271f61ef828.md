# 6.3 Arrays of Structures

Example: count the occurences of each C keyword

```
struct key {
char *word;
int count;
} keytab[]={"auto", 0, "break", 0, "case", 0, ...,"while",0};
```

```
#include <stdio.h>
#include <ctype.h>
#include <string.h>
#define MAXWORD 100
int getword(char *, int);
int binsearch(char *, struct key *, int);
```
