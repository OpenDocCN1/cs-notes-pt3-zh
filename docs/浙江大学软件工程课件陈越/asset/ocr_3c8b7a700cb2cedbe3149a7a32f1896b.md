# 7.3 Variable-length Argument Lists

```
va_start(ap, fmt);
for(p=fmt; *p; p++) {
    if(*p!='%') {
        putchar(*p);
        continue;
    }
    switch(*++p) {
        case 'd': ival = va_arg(ap,int);
            printf("%d", ival);
            break;
        case 'f': dval=va_arg(ap,double);
            printf("%f", dval);
            break;
```
