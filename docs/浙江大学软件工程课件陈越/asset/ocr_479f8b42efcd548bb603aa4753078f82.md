+   - ☆ Left shift (<<)
+   - The x << n shifts the value of x left by n positions, filling vacated bits with zero.
+   - char a;
+   - a binary a << 1 a << 2
+   - 64 01000000 0 10000000 01 00000000
+   - 127 01111111 0 11111110 01 11111100
+   - i.e., 64<<1 = 0x80, 64<<2 = 0, 127<<1 = 0xfe, 127<<2 = 0xfc
