# 函数的递归（recursion）调用

☆ 在调用一个函数的过程中又出现直接或间接地调用该函数本身，称为函数的**递归调用**。

☆ C语言的特点之一就在于允许递归调用。

```
int f(int x)                         /* 直接调用本函数的例子 */
{
        int y, z;
        ……
        z = f(y);
        ……
        return(2*z);
}
```

```
/* 间接调用本函数的例子 */

int f1(int x)                         int f2(int t)
{                                     {
        int y, z;                             int a, c;
        ……                                    c = f1(a);
        z = f2(y);
        ……                                    return(3+c);
        return(2*z);}
                                      }
```

☆ 应当有能终止递归过程的条件出现，否则就会进入无穷递归。
