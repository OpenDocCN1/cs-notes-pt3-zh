# 6.7 Typedef

typedef: creating new data type name (not a new type)

purpose: (1) for portable (2) for better understanding

example:

```
char *s;
int strcmp(char *, char *);
```

```
int (*strcmp)(char *, char *);
```

```
struct tnode{
    char *word;
    int count;
    struct tnode *left;
    struct tnode *right;
};
struct tnode *tp;
struct tnode node;
```

```
typedef char *STRING;
STRING s;
int strcmp(STRING,STRING);
```

```
typedef int (*PFI)(char *,char *);
PFI strcmpp;
```

```
typedef struct tnode *TREEPTR;
typedef struct tnode {
    char *word;
    int count;
    TREEPTR left;
    TREEPTR right;
} TREENODE;
TREEPTR tp;
TREENODE node;
```
