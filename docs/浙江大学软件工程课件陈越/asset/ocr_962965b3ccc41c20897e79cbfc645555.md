# 2.10 Assignment Operators and Expressions

+   - assignment operators:

`=`, `+=`, `-=`, `*=`, `/=`, `%=`, `<<=`, `>>=`, `&=`, `^=`, `|=`

`expr1 op= expr2 <==> expr1 = (expr1) op (expr2)`

Example:

```
/* bitcount : count 1 bits in x */
int bitcount(unsigned x)
{
    int b;
    for(b=0; x!=0; x>>>=1)
        if(x&01)    b++;
    return b;
}
```
