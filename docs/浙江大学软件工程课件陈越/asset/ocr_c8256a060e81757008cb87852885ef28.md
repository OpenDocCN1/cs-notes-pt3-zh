# 7.3 Variable-length Argument Lists

The proper declaration for printf is

```
int printf(char *fmt, ...)
```

where the ... means that the number and types
of these arguments may vary. The ... can only
appear at the end of an argument list.

minprintf is a simple version of printf

```
#include <stdarg.h>

void minprintf(char *fmt, ...)
{
    va_list ap;
    char *p, *sval;
    int ival;
    double dval;
```
