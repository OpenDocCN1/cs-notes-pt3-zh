+   ② 确定task类型，并分配给适当的软件硬件去执行
+   
+   - **事件驱动型(event-driven)**：主要完成通信工作。
+     - event = 数据到达的 interrupt
+   - **时钟驱动型(clock-driven)**：完成周期性工作。
+   - **优先型(priority)**：将high priority或 low priority的任务专门分离出来先做或后做。
+   - **关键任务(key task)**：指关系系统成败的处理，要求高可靠性，应分离考虑，严格测试。
+   - **协调任务(coordinator)**：当系统中存在三个以上tasks时，应增设一个协调任务，用于封装不同tasks之间的协调控制。
