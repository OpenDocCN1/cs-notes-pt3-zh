

## 1.5 Character Input and Output

### Important View:

In C, the model of Input & Output are supported by the standard library, and NOT the statements of C. This is very different of PASCAL.

### Tow simplest I/O functions:

- .getchar() ——read on character at a time from text stream

```c
c=getchar();
```

- .putchar() ——write one character at a time from text stream

```c
putchar(c);
```

### File Copying Algorithm

Program:
```c
#include <stdio.h>
/* copy input to output; 1st version*/
main()
{
int c;
c=getchar();
while(c!=EOF){
putchar(c);
c=getchar();
}
}
```

> read a character  
> while( character is not end-of-file indicator)  
> output the character just read  
> read a character  

### File copying program (2nd version)

```c
#include <stdio.h>
/* copy input to output; 2nd version*/
main()
{
	int c;
	while((c=getchar())!=EOF)
		putchar( c);
}
```

> NOTE:  
> c=getchar()!=EOF  
> is eauivalent to  
> c=(getchar()!=EOF)

### Character Counting

#### Version 1

```c
#include <stdio.h>
main()
{
    long nc;
    nc=0;
    while(getchar()!=EOF)
        ++nc;
    printf("%ld\n",nc);
}
```

#### Version 2

```c
#include <stdio.h>
main()
{
    double nc;
    for(nc=0;getchar()!=EOF;++nc)
        ;
    printf("%.0f\n",nc);
}
```

++ means increment by one.

++nc → nc=nc+1

### Line Counting

```c
#include <stdio.h>

/* count lines in input */
main()
{
    int c, nl;
    nl=0;
    while(( c=getchar())!=EOF)
        if(c=='\n')
            ++nl;
    printf("%d\n",nl);
}
```

### Word Counting:

count lines, words and characters in input

```c
#include <stdio.h>
#define IN 1    /*inside a word */
#define OUT 0   /*outside a word */
main()
{
    int c, nl, nw, nc, state;
    state=OUT;
    nl=nw=nc=0;
    while((c=getchar())!=EOF){
    ++nc;
    if(c== '\n')        ++nl;
    if(c==' '||c=='\n'||c=='\t')   state=OUT;
    else if(state==OUT) {
        state=IN; ++nw; }
    }
    printf("%d %d %d\n",nl,nw,nc);
}
```

## 1.6 Arrays

Array Example: To count digits, white spaces, others.

```c
#include <stdio.h>
main()
{
	int c,i,nwhite,nother;
	int ndigit[10];
	nwhite=nother=0;
	for(i=0;i<10;++i)
		ndigit[i]=0;
	while((c=getchar())!=EOF)
		if(c>='0' && c <='9')
			++ndigit[c-'0'];
		else if(c==' ' && c=='\n'|| c=='\t')
			++nwhite;
		else
			++nother;
	printf("digits=");
	for(i=0;i<10;i++)
		printf ("%d", ndigit[i]);
	printf(", white space=%d, other=%d\n", nwhite,
		nother);
}
```

## 1.9 Character Arrays

**Example:** reads a set of text lines and prints the longest

### Algorithm:

while (there’s another line)  
if(it’s longer than the previous longest)  
save it  
save its length  
print longest line  

### Program:

```c
#include <stdio.h>
#define MAXLINE 1000 /*maximum input line size */
int getline (char line [], int maxline);
void copy(char to[ ], char from[ ]);
main()
{
        int len, max;
        char line [MAXLINE], longest [MAXLINE];
        max = 0;
        while(( len = getline (line, MAXLINE)) > 0
                if(len > max)
                        {max = len; copy (longest, line); }
                if(max > 0) /* there was a line */
                        printf("%s", longest);
        return 0;
}
```
