注：`ip`：指针变量；`*ip`：指针所指空间存放的内容。

### §8.3 指针的类型

一、指针的类型就是它所指的数据的类型。

如：

```cpp
int i;
int *ip = &i;  // ip是一个整型指针
```

二、两种特殊的指针

1. `NULL` 指针（空指针）：不指向任何类型的数据。（用地址0表示）

如：

```cpp
int *ip = NULL;
```

2. `void` 指针：可以指向任何类型的数据。

注：使用 `void` 指针时，首先应将其强制转换为具有某种具体的数据类型。

例：

```cpp
int a = 20;
void *pv = &a;
int *ip = (int *)pv;
cout << *ip;
cout << *((int *)pv);
```

### §8.4 用 const 来限定指针

一、指向常量的指针

1. 定义：在指针定义前加 `const`。

如：

```cpp
int i;
const int *ip = &i;
```

2. 含义：不能改变该指针所指的数据。

如：

```cpp
int i;
const int *ip = &i;
*ip = 25;  // ×
```

3. 三点注意：

（1）指向常量的指针只限制指针的间接访问操作，而不会限制指针变量本身的操作。

如：

```cpp
int i, j;
const int *ip = &i;
*ip = 25;  // ×
ip = &j;   // √
```

二、指针常量

1. 定义：在指针变量名前加 `const`。

如：

```cpp
int i;
int * const ip = &i;
```

2. 含义：不能改变指针变量本身的值，但是可以改变指针所指的数据。

如：

```cpp
int i, j;
int * const ip = &i;
ip = &j;  // ×
*ip = 32; // √
```

三、指向常量的指针常量

1. 定义：在指针定义前和变量名前各加一个 `const`。

如：

```cpp
int i;
const int * const ip = &i;
```

2. 含义：既不能改变指针变量本身的值，也不能改变指针所指的数据。

如：

```cpp
int i, j;
const int * const ip = &i;
ip = &j;  // ×
*ip = 32; // ×
```

### §8.5 指针与数组

一、一维数组的数组名是指向该数组首元素的指针。

```cpp
int array[5] = {10,20,30,40,50};
array == &array[0];
```

二、指向数组的指针可以当作数组名使用。

如：

```cpp
int array[100];
int *pArray = array;
```

则 `pArray` 为指向一维数组的指针，此时访问数组中第 `i+1` 个元素，下面两种方式是等价的：

`array[i]` ←→ `pArray[i]`

例：

```cpp
#include<iostream.h>
void main()
{
    int array[5];
    int *pArray = array;
    for(int i = 0; i < 5; i++)
    {
        array[i] = i;
        cout << pArray[i] << " "
             << array[i] << endl;
    }
}
```

此程序的运行结果为：

```text
0 0
1 1
2 2
3 3
4 4
```

三、数组名是指针常量，而不是指针变量。

如：

```cpp
int array[100];
```

则：

```cpp
array = &array[1];  // ×
```

四、指针的加减

1. 指针加减的含义：

- 指针 +1：指针向后移动一个数组元素。
- 指针 -1：指针向前移动一个数组元素。

如：

```cpp
int array[5] = {10,20,30,40,50};
int *pa = array;
```

![img](img/caa6e55d367968a29a6a558fa69d0413_807_0.png)

2. 指针的加减是以指针所指数据的类型大小为单位进行的。（例见181页—182页）

注：如果指针指向的是一个结构数组，则指针的运算就以一个结构元素所占内存空间大小为单位。（例见182页）

五、用指针对数组进行操作

1. 通过指针的加减来访问数组元素。（例见183页、184页）

3. 取数组中第 `i` 个元素地址的四种方式

若有：

```cpp
int array[5] = {10,20,30,40,50};
int *pa = array;
```

则有：

```text
&pa[i]
&array[i]
pa + i
array + i
```

4. 在对指针进行加减运算时，必须保证经过运算得到的新地址是程序能够支配的地址。

若有：

```cpp
int array[10];
int *pa = array;
```

则：

```cpp
pa + 20;  // ×
```

六、指针与字符串

1. 字符串：以 `'\0'` 为结束符的字符序列。

2. 可以将字符指针看成是一个字符串。

如：

```cpp
char *str = "a string";
```

![img](img/caa6e55d367968a29a6a558fa69d0413_813_0.png)

![img](img/caa6e55d367968a29a6a558fa69d0413_813_1.png)

3. 输出字符指针将输出整个字符串。

如：

```cpp
char *str = "a string";
cout << str;  // 输出：a string
```

4. 输出对一个字符指针的间接引用时，将会输出字符串的第一个字符。

如：

```cpp
cout << *str;  // 输出：a
```

### §8.6 动态内存申请

一、new 与 delete

1. 内存空间申请

（1）`new` 操作符：表示从堆内存中申请一块空间。

（2）返回值：

- 申请成功：返回所申请到的空间的首地址。
- 申请失败：返回空指针（NULL）。

（3）`new` 的三种格式：

- `new 数据类型`
- `new 数据类型（初始值）`
- `new 数据类型[常量表达式]`

例：

```cpp
int *ip1 = new int;
int *ip2 = new int(3);
int *str = new int[10];
```

几点说明：

★ `new` 与 `delete` 需要配套使用：

```text
new 数据类型
new 数据类型（初始化值）
delete 指针名
new 数据类型[常量表达式] ←→ delete [] 指针名
```

☆ 在用 `delete` 释放一个指针所指的空间时，必须保证这个指针所指的空间是用 `new` 申请的，并且只能释放这个空间一次。

例：

```cpp
int i;
int *ip = &i;
delete ip;  // ×

float *fp = new float(3.4);
delete fp;  // √
delete fp;  // ×
```

☆ 如果在程序中用 `new` 申请了空间，就应该在结束程序前释放所有申请的空间。

☆ 当一个指针没有指向合法的空间，或者指针所指的内存已经释放以后，最好将指针的值设为 `NULL`。

二、指针与动态数组

1. 若申请的是一个简单的数据空间，则可以通过间接访问操作符 `*` 来访问

```cpp
int *ip = new int;
*ip = 34;
cout << *ip;
```
