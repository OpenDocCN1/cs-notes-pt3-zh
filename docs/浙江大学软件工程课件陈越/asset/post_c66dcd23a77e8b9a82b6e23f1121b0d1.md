例5：根据整型变量 dayoftheweek(0-6) 值输出其表示的星期几的英语单词。

（无break语句）

```cpp
Switch(dayoftheweek)
{
    case 0: cout<< “Sunday”；
    case 1: cout<< “Monday”；
    case 2: cout<< “Tuesday”；
    case 3: cout<< “Wednesday”；
    case 4: cout<< “Thursday”；
    case 5: cout<< “Friday”；
    case 6: cout<< “Saturday”；
    default:cout<< “Unknown week day”；
}
```

若dayoftheweek的值为4，

则输出结果为：

ThursdayFridaySaturdayUnknown week day

（有break语句）

```cpp
Switch(dayoftheweek)
{
    case 0: cout<< “Sunday”; break;
    case 1: cout<< “Monday”; break;
    case 2: cout<< “Tuesday”; break;
    case 3: cout<< “Wednesday”; break;
    case 4: cout<< “Thursday”; break;
    case 5: cout<< “Friday”; break;
    case 6: cout<< “Saturday”; break;
    default:cout<< “Unknown week day”; break;
};
```

若 dayoftheweek 的值为 4，

则输出结果为：

Thursday

# 五、循环流程

## （一）while语句

1、格式：

```cpp
while（循环条件）
循环体
```

> 注：循环体是单个语句,或者是复合语句。

2、执行过程：
当循环条件为真时，执行循环体，否则退出循环。

3、流程图（见右上图）

![](img/caa6e55d367968a29a6a558fa69d0413_651_0.png)

例7：#include<iostream.h>
void main()
{int sum=0; int i=1;
while(I<=100)
{int sum=sum+i; i++;}
cout<< "sum="<<sum;
}

程序功能：计算并输出从1加到100的和。
输出结果：sum=5050

## （二）do...while语句

1、格式：

```cpp
do
    循环体
while（循环条件）；
```

2、执行过程：循环执行语句，直到循环条件为假时，退出循环。

3、流程图（见右上图）

![](img/caa6e55d367968a29a6a558fa69d0413_654_0.png)

例8：#include<iostream.h>
void main()
{int sum=0; int i=1;
do
{sum=sum+i; i++;
}
while(i<=100)
cout<<" sum="<<sum;
}

3、do...while语句与while语句唯一的区别：
while语句的循环体有可能一次不执行。
do...while语句的循环体至少执行一次。

## （三）for语句

### 1、格式：

for （循环初始化； 循环条件； 循环参数调整）循环体

2、执行过程：

（1）进行循环初始化；

（2）判断循环条件；

（3）如果循环条件为真，则执行循环体、对循环参数调整，然后转向步骤（2）；如果循环条件为假，则结束循环。

3、流程图：

![](img/caa6e55d367968a29a6a558fa69d0413_659_0.png)

例9：#include<iostream.h>

void main()
{int sum=0;
    for(int i=1; i<=100; i++)
        sum=sum+i;
        cout<<"sum="<<sum;
}

3、for语句和while语句的区别：

（1）for语句一般用于循环次数已知的情况；

（2）while语句不仅可以用于循环次数已知的情况，也可以用于循环次数未知的情况；

（3）一切用for语句实现的循环都可以用while语句来代替，反之不可以。

void main( )

int inval; // inval存放当前输入的整数
int num=0; // num存放输入的整数个数

## （二）continue语句（`continue;`）

功能：循环体中的continue语句表示结束当前的一次循环，跳转到循环开始处，继续执行下一次循环。

例11：从键盘输入若干个整数，计算并输出其中正数的平均值，以0作为输入的结束标志。
若从键盘输入10 -15 15 -30 20则输出：
sum/num=15.0

例11：#include<iostream.h>
void main()
{int sum=0; int inval; int num=0;
 while(1)
 {
  cin>>inval;
  if(inval==0)break;
  if(inval<0)continue;
  sum=sum+inval; num++;
 }
 cout<<"sum/num="<<(float)sum/num;
}
